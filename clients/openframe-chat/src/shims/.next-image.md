A lightweight mock/shim of Next.js's `Image` component that renders a standard HTML `<img>` element, stripping out Next.js-specific props for use in non-Next.js environments.

## Key Components

- **`ImageProps`** — Extends standard `React.ImgHTMLAttributes<HTMLImageElement>` with Next.js-specific props (`fill`, `priority`, `quality`, `placeholder`, `blurDataURL`, `unoptimized`)
- **`Image`** — A forwarded-ref component that accepts the full Next.js `Image` API but renders a plain `<img>`, omitting Next.js-only props from the DOM

## Usage Example

```typescript
import Image from './next-image';

// Drop-in replacement for next/image in non-Next.js contexts
const Avatar = () => (
  <Image
    src="https://cdn.example.com/avatar.png"
    alt="User avatar"
    width={64}
    height={64}
    priority   // accepted but ignored at runtime
    quality={80} // accepted but ignored at runtime
  />
);
```

## Notes

- Next.js-specific props (`fill`, `priority`, `quality`, `placeholder`, `blurDataURL`, `unoptimized`) are destructured and discarded to prevent unknown DOM attribute warnings
- All standard HTML `<img>` attributes pass through normally via `...props`
- `ref` forwarding is supported for direct DOM access
