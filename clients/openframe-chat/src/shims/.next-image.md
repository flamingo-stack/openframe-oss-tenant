A lightweight mock/stub of Next.js's `Image` component that renders a standard HTML `<img>` tag, stripping Next.js-specific props. Useful for testing environments or non-Next.js contexts.

## Key Components

- **`ImageProps`** — Extends standard `React.ImgHTMLAttributes<HTMLImageElement>` with Next.js-specific props (`fill`, `priority`, `quality`, `placeholder`, `blurDataURL`, `unoptimized`)
- **`Image`** — A forwarded-ref component that accepts Next.js `Image` props but renders a plain `<img>`, discarding framework-specific attributes

## Usage Example

```typescript
import Image from './next-image';

// Drop-in replacement for next/image in non-Next.js environments
const Avatar = () => (
  <Image
    src="/avatar.png"
    alt="User avatar"
    width={64}
    height={64}
    priority       // accepted but ignored
    quality={80}   // accepted but ignored
  />
);
```

> **Note:** This component silently drops all Next.js-specific optimisation props (`fill`, `priority`, `quality`, `placeholder`, `blurDataURL`, `unoptimized`). Standard HTML `<img>` attributes (e.g. `src`, `alt`, `width`, `height`) pass through normally via the spread.
