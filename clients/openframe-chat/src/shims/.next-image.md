A lightweight mock/shim for Next.js's `Image` component that renders a standard HTML `<img>` element, stripping Next.js-specific props for use in non-Next.js environments (e.g., Storybook, testing, or standalone React apps).

## Key Components

- **`ImageProps`** — Extends `React.ImgHTMLAttributes<HTMLImageElement>` with Next.js-specific props (`fill`, `priority`, `quality`, `placeholder`, `blurDataURL`, `unoptimized`)
- **`Image`** — A forwarded-ref component that omits Next.js-only props before delegating to a native `<img>` tag

## Usage Example

```typescript
import Image from './next-image';

// Drop-in replacement for next/image in non-Next.js contexts
function Avatar() {
  return (
    <Image
      src="/avatar.png"
      alt="User avatar"
      width={64}
      height={64}
      priority       // accepted but ignored
      quality={80}   // accepted but ignored
    />
  );
}
```

## Notes

- Next.js-specific props (`fill`, `priority`, `quality`, `placeholder`, `blurDataURL`, `unoptimized`) are destructured and discarded — they do not affect rendering
- All standard HTML `<img>` attributes (`src`, `alt`, `width`, `height`, `className`, etc.) pass through normally
- `React.forwardRef` support allows parent components to access the underlying DOM element via `ref`
- `displayName` is set to `'Image'` for clear identification in React DevTools
