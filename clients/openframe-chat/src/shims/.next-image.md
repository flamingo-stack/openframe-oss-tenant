A lightweight mock/polyfill for Next.js `Image` component that renders a standard HTML `<img>` element, stripping Next.js-specific props for compatibility in non-Next.js environments or testing contexts.

## Key Components

- **`ImageProps`** — Extended type combining standard `React.ImgHTMLAttributes<HTMLImageElement>` with Next.js-specific props (`fill`, `priority`, `quality`, `placeholder`, `blurDataURL`, `unoptimized`)
- **`Image`** — A `forwardRef` component that omits Next.js-only props and delegates to a native `<img>` tag

## Usage Example

```typescript
import Image from './next-image';

// Drop-in replacement for next/image in non-Next.js environments
const Avatar = () => (
  <Image
    src="/avatar.png"
    alt="User avatar"
    width={64}
    height={64}
    priority       // accepted but ignored at runtime
    quality={80}   // accepted but ignored at runtime
  />
);
```

> **Note:** This component is intended as a compatibility shim. Next.js-specific optimizations (`priority`, `quality`, `fill`, etc.) are accepted by the type signature but silently dropped — the underlying `<img>` renders without them.
