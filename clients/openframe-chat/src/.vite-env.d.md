TypeScript environment declaration file for Vite, extending the default Vite client types with static asset module declarations for common image formats.

## Key Components

| Declaration | Description |
|-------------|-------------|
| `vite/client` reference | Includes Vite's built-in client type definitions (e.g., `import.meta.env`, HMR API) |
| `*.png` module | Declares PNG imports as `string` (resolved asset URL) |
| `*.jpg` module | Declares JPG imports as `string` |
| `*.jpeg` module | Declares JPEG imports as `string` |
| `*.gif` module | Declares GIF imports as `string` |
| `*.svg` module | Declares SVG imports as `string` |

## Usage Example

These declarations allow TypeScript to resolve static asset imports without type errors:

```typescript
import logo from './assets/logo.svg';
import banner from './assets/banner.png';
import animation from './assets/loading.gif';

// All resolved as strings (public asset URLs at runtime)
const img = document.createElement('img');
img.src = logo; // e.g., "/assets/logo.abc123.svg"
```

> Without these declarations, TypeScript would throw `Cannot find module './assets/logo.svg'` errors during compilation.
