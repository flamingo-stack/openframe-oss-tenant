TypeScript ambient declarations file that extends Vite's client type definitions to add type support for static image asset imports.

## Key Components

- **`vite/client` reference** — Includes Vite's built-in client types (e.g., `import.meta.env`, HMR API)
- **Image module declarations** — Ambient module types for the following static asset formats:
  - `.png`
  - `.jpg`
  - `.jpeg`
  - `.gif`
  - `.svg`

Each module declaration exports a `string` as the default export, representing the resolved asset URL that Vite produces at build time.

## Usage Example

```typescript
// Import image assets with full TypeScript type safety
import logo from './assets/logo.svg';
import banner from './assets/banner.png';
import thumbnail from './assets/thumb.jpg';

// All resolve to string URLs — safe to use in src attributes
const img = document.createElement('img');
img.src = logo; // string ✓
```

> Without these declarations, TypeScript would throw `Cannot find module './assets/logo.svg'` errors when importing non-JS assets.
