TypeScript ambient declarations file that extends Vite's client type definitions with module declarations for static image assets.

## Key Components

- **`vite/client` reference** — Pulls in Vite's built-in client types (e.g., `import.meta.env`, `import.meta.hot`)
- **Image module declarations** — Ambient type declarations for the following static asset formats:
  - `.png`
  - `.jpg`
  - `.jpeg`
  - `.gif`
  - `.svg`

Each module declaration exports a `string` as the default export, representing the resolved URL of the asset after bundling.

## Usage Example

```typescript
// Import images directly in TypeScript/TSX files without type errors
import logo from './assets/logo.svg';
import banner from './assets/banner.png';
import thumbnail from './assets/photo.jpg';

const App = () => (
  <div>
    <img src={logo} alt="Logo" />
    <img src={banner} alt="Banner" />
  </div>
);
```

Without these declarations, TypeScript would throw `Cannot find module './assets/logo.svg'` errors when importing static image files. This file ensures all image imports are typed as `string` (the asset's public URL), aligning with how Vite resolves asset imports at build time.
