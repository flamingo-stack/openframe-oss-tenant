TypeScript environment declaration file for Vite that extends the default Vite client types with explicit module declarations for common static image asset formats.

## Key Components

| Declaration | Description |
|---|---|
| `/// <reference types="vite/client" />` | Includes Vite's built-in client type definitions (env variables, HMR API, etc.) |
| `declare module '*.png'` | Types PNG imports as `string` (resolved URL) |
| `declare module '*.jpg'` | Types JPG imports as `string` |
| `declare module '*.jpeg'` | Types JPEG imports as `string` |
| `declare module '*.gif'` | Types GIF imports as `string` |
| `declare module '*.svg'` | Types SVG imports as `string` |

## Usage Example

These declarations enable TypeScript to resolve static asset imports without errors:

```typescript
import logo from './assets/logo.svg';
import banner from './assets/banner.png';
import icon from './assets/icon.gif';

// All resolved to their public URL strings at build time
const imgElement = document.createElement('img');
imgElement.src = logo; // string ✅
```

With standard Vite config, these imports return the asset's resolved public URL at build time. Without these declarations, TypeScript would throw `Cannot find module` errors for image imports.

## Notes

- This file is auto-included by TypeScript via `tsconfig.json`'s `include` or `types` fields
- SVG imports here resolve to a URL string — if you need SVG as a React component, use `vite-plugin-svgr` and add a separate `?react` module declaration
