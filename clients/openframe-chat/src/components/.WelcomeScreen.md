Renders the initial onboarding/landing screen for the Fae AI assistant, introducing its capabilities to end users before they begin a support session.

## Key Components

- **`WelcomeScreen`** — Main export. A full-screen presentational component that displays Fae's avatar, a tagline, a feature list, and a "Get Started" CTA button.
- **`features`** — Static array defining three capability cards (instant fix, escalation, 24/7 availability) rendered via `FeatureList`.
- **`WelcomeScreenProps`** — Interface with a single `onGetStarted` callback, triggered when the user clicks the CTA.

## Usage Example

```typescript
import { WelcomeScreen } from './WelcomeScreen';

function App() {
  const handleGetStarted = () => {
    // Navigate to chat or initialize session
    setView('chat');
  };

  return <WelcomeScreen onGetStarted={handleGetStarted} />;
}
```

## Notes

- Uses ODS (OpenFrame Design System) tokens for spacing, color, and typography (e.g., `var(--ods-flamingo-pink-base)`, `text-ods-text-primary`).
- Feature icons are colored with `--ods-flamingo-pink-base` for brand consistency.
- Footer displays the Flamingo branding logo, indicating this is a client-facing surface powered by the Flamingo platform.
- The `onGetStarted` prop decouples navigation logic from the UI, keeping the component stateless and reusable.
