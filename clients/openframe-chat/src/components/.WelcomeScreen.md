The `WelcomeScreen` component renders the initial landing screen for the Fae AI assistant chat widget, displaying the assistant's branding, key feature highlights, MSP organization info, and a "Get Started" CTA.

## Key Components

| Element | Purpose |
|---|---|
| `WelcomeScreenProps` | Interface requiring an `onGetStarted` callback |
| `features` | Static array of three feature items (fix, escalate, 24/7) rendered via `FeatureList` |
| `useAssistantBranding` | Resolves assistant name and avatar from `AiSettings` |
| `useChatConfig` | Provides `aiSettings` including accent color for the CTA button |
| `useMspOrganization` | Supplies org name, website, and logo for the `MspOrganizationCard` |
| `getReadableTextColor` | Computes accessible label color for the accent-colored button |

## Usage Example

```typescript
import { WelcomeScreen } from './WelcomeScreen';

function ChatWidget() {
  const [started, setStarted] = useState(false);

  if (!started) {
    return <WelcomeScreen onGetStarted={() => setStarted(true)} />;
  }

  return <ChatInterface />;
}
```

## Loading States

The component handles two independent loading states gracefully:

- **Branding loading** — renders `Skeleton` placeholders for the avatar and headline until `assistantName`/`assistantAvatar` resolve, preventing a blank hero on cold start.
- **Org loading** — renders `MspOrganizationCardSkeleton` while org data fetches; omits the card entirely if no `orgName` is returned.

## Notes

- The accent color falls back to `#f357bb` (Flamingo pink) when `aiSettings.accentColor` is unset.
- The "Powered by Flamingo" footer is always visible and non-configurable.
