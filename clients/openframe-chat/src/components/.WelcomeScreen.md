Renders the onboarding welcome screen for the Fae AI assistant, introducing its core capabilities to end-users before they begin interacting with the chat interface.

## Key Components

- **`WelcomeScreen`** — Main export; a full-screen intro component displaying Fae's avatar, tagline, feature highlights, and a "Get Started" CTA button
- **`features`** — Static array defining three capability cards: instant fix, auto-escalation, and 24/7 availability
- **`WelcomeScreenProps`** — Interface with a single `onGetStarted` callback prop triggered when the user clicks the CTA

## Usage Example

```typescript
import { WelcomeScreen } from './WelcomeScreen';

function App() {
  const [started, setStarted] = useState(false);

  if (!started) {
    return <WelcomeScreen onGetStarted={() => setStarted(true)} />;
  }

  return <FaeChat />;
}
```

## Notes

- Uses ODS (OpenFrame Design System) tokens for spacing, color, and typography (e.g., `--ods-flamingo-pink-base`, `var(--spacing-system-lf)`)
- Feature icons are sourced from `@flamingo-stack/openframe-frontend-core/components/icons-v2`
- Displays a **Flamingo** branding footer at the bottom of the screen
- The component is stateless — all interaction state is managed by the parent via `onGetStarted`
