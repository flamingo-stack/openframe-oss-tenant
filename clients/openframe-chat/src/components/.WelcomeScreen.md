Renders the initial onboarding screen for Fae, Flamingo's AI IT assistant, introducing her capabilities to end-users before they begin a support session.

## Key Components

- **`WelcomeScreen`** — Full-screen welcome UI component that displays Fae's avatar, a headline, a feature list, and a "Get Started" CTA button
- **`features`** — Static array of three feature descriptors (instant fix, escalation, 24/7 availability) rendered via `FeatureList`
- **`WelcomeScreenProps`** — `onGetStarted: () => void` callback triggered when the user clicks the CTA

## Usage Example

```typescript
import { WelcomeScreen } from './WelcomeScreen';

function App() {
  const handleGetStarted = () => {
    // Navigate to chat or initialize session
  };

  return <WelcomeScreen onGetStarted={handleGetStarted} />;
}
```

## Notes

- Uses design system tokens (`--ods-flamingo-pink-base`, `--spacing-system-*`) for consistent theming
- Feature icons are rendered at `24px` in flamingo-pink accent color
- Footer displays the Flamingo branding with `FlamingoLogo` icon
- Layout is responsive via `max-w-ods-content-narrow` and centered flex column
