Renders the initial/welcome screen for the chat interface, displaying either a list of existing tickets or quick action shortcuts depending on whether the user has active tickets.

## Key Components

### `ChatInitialScreenProps`

| Prop | Type | Description |
|------|------|-------------|
| `tickets` | `ChatTicketItemData[]` | List of existing support tickets to display |
| `onTicketClick` | `(ticketId: string) => void \| Promise<void>` | Callback when a ticket is selected |
| `quickActions` | `QuickAction[]` | Predefined quick-help prompts |
| `onQuickAction` | `(text: string) => void` | Callback when a quick action is triggered |
| `isDisconnected` | `boolean` | Disables quick actions when chat is disconnected |

### Rendering Logic

- **Has tickets** → renders `ChatTicketList` with all active tickets
- **No tickets** → renders `ChatQuickAction` buttons (if any are configured)

## Usage Example

```typescript
import { ChatInitialScreen } from './ChatInitialScreen';

<ChatInitialScreen
  tickets={userTickets}
  onTicketClick={(id) => navigateToTicket(id)}
  quickActions={[
    { id: '1', text: 'My computer is slow' },
    { id: '2', text: 'I need software installed' },
  ]}
  onQuickAction={(text) => sendMessage(text)}
  isDisconnected={false}
/>
```

## Notes

- Quick help section only renders if `quickActions` is non-empty
- When tickets exist, quick actions are hidden — ticket list takes priority
- Styles use ODS design tokens (`--spacing-system-*`, `text-ods-text-secondary`) for consistent theming
