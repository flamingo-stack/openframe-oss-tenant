Renders the initial/welcome screen for the Flamingo chat interface, displaying either recent support tickets or quick-action prompts with scroll-aware gradient fade indicators.

## Key Components

### `ChatInitialScreen` (default export)
Main component that composes the welcome UI with dynamic scroll fade overlays.

**Props (`ChatInitialScreenProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `tickets` | `ChatTicketItemData[]` | Recent support tickets to display |
| `onTicketClick` | `(ticketId: string) => void \| Promise<void>` | Callback when a ticket is selected |
| `quickActions` | `QuickAction[]` | Predefined prompt suggestions |
| `onQuickAction` | `(text: string) => void` | Callback when a quick action is triggered |
| `isDisconnected` | `boolean` | Disables quick actions when chat is offline |

### Internal Logic

- **Scroll fade overlays** — Uses a `ResizeObserver` + `scroll` listener to track overflow state, toggling top/bottom gradient fades as the user scrolls through the content area.
- **Conditional content** — Renders `ChatTicketList` when tickets exist; falls back to the `quickHelp` quick-action panel when the ticket list is empty.

## Usage Example

```typescript
<ChatInitialScreen
  tickets={recentTickets}
  onTicketClick={(id) => openTicket(id)}
  quickActions={[
    { id: '1', text: 'My computer is slow' },
    { id: '2', text: 'I need a password reset' },
  ]}
  onQuickAction={(text) => sendMessage(text)}
  isDisconnected={false}
/>
```

> **Note:** When `tickets.length > 0`, quick actions are hidden. Both panels share the same `max-w-ods-content-narrow` constraint and centered layout from the ODS design system.
