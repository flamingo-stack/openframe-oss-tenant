The initial welcome screen for the chat interface, displaying a greeting prompt and a scrollable list of existing support tickets with scroll-fade overlay effects.

## Key Components

**`ChatInitialScreen`** — Default export component that renders the chat landing view.

| Prop | Type | Description |
|------|------|-------------|
| `tickets` | `ChatTicketItemData[]` | List of tickets to display |
| `onTicketClick` | `(ticketId: string) => void \| Promise<void>` | Callback when a ticket row is clicked |
| `isLoadingTickets` | `boolean` | When `true`, renders skeleton rows instead of the ticket list |

**Scroll fade logic** — Dynamically shows/hides top and bottom gradient overlays based on scroll position and overflow state, using a `ResizeObserver` to react to content size changes without layout thrashing.

## Usage Example

```typescript
import { ChatInitialScreen } from './ChatInitialScreen';

const tickets = [
  { id: 'ticket-1', title: 'VPN not connecting', status: 'open' },
  { id: 'ticket-2', title: 'Printer offline', status: 'pending' },
];

function ChatView() {
  const handleTicketClick = async (ticketId: string) => {
    await navigateToTicket(ticketId);
  };

  return (
    <ChatInitialScreen
      tickets={tickets}
      onTicketClick={handleTicketClick}
      isLoadingTickets={false}
    />
  );
}
```

**Scroll fade behaviour:** Top and bottom gradient overlays (`var(--color-bg)` → `transparent`) fade in/out as the user scrolls through the ticket list. Both overlays respect the active theme (`data-theme` dark/light) automatically.
