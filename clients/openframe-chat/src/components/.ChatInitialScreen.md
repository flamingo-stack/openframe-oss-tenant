Renders the chat welcome screen displayed before any conversation begins, showing a greeting, recent tickets (or quick-action shortcuts when no tickets exist), and scroll-fade overlays for overflow content.

## Key Components

**`ChatInitialScreen`** — Main exported component accepting:

| Prop | Type | Description |
|------|------|-------------|
| `tickets` | `ChatTicketItemData[]` | Recent support tickets to display |
| `onTicketClick` | `(ticketId: string) => void \| Promise<void>` | Callback when a ticket is selected |
| `quickActions` | `QuickAction[]` | Predefined prompt shortcuts |
| `onQuickAction` | `(text: string) => void` | Callback when a quick action is triggered |
| `isDisconnected` | `boolean` | Disables quick actions when chat is offline |

**Scroll fade logic** — Uses a `ResizeObserver` + scroll event listener to track overflow state, toggling top/bottom gradient overlays as the user scrolls through content.

**Content priority** — Tickets take precedence over quick actions: if `tickets.length > 0`, the ticket list renders; otherwise the "Quick Help" action buttons appear.

## Usage Example

```typescript
<ChatInitialScreen
  tickets={recentTickets}
  onTicketClick={(id) => openTicket(id)}
  quickActions={[
    { id: '1', text: 'My computer is slow' },
    { id: '2', text: 'I need a password reset' },
  ]}
  onQuickAction={(text) => sendMessage(text)}
  isDisconnected={!chatConnected}
/>
```
