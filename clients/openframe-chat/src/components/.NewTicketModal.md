Modal component for creating new support tickets with subject, description, and file attachment fields.

## Key Components

- **`NewTicketModal`** — Main modal component accepting `isOpen` and `onClose` props
- **`useCreateTicket`** — Hook providing form state, field setter, submission handler, and reset logic
- **`NewTicketModalProps`** — Interface defining `isOpen: boolean` and `onClose: () => void`

## Usage Example

```typescript
import { NewTicketModal } from './components/NewTicketModal';

function SupportPage() {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <>
      <Button onClick={() => setIsOpen(true)}>Open Ticket</Button>
      <NewTicketModal
        isOpen={isOpen}
        onClose={() => setIsOpen(false)}
      />
    </>
  );
}
```

## Behavior

- **Form fields:** Subject (`Input`), Description (`Textarea`), Attachments (`FileUpload`)
- **File uploads:** Supports up to 10 files, accepts window drag-and-drop, max list height of 200px
- **Submission:** `Create Ticket` button shows a loading state while `isSubmitting` is true; all fields are disabled during submission
- **Reset:** Calling `handleClose` resets the form state before invoking `onClose`, preventing stale data on reopen
- **Styling:** Uses OpenFrame design tokens (`--spacing-system-*`) for consistent padding and gaps; modal width constrained to `max-w-ods-content-narrow`
