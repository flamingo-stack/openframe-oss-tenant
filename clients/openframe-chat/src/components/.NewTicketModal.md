Modal component for creating new support tickets, combining subject input, file attachments, and problem description into a structured form dialog.

## Key Components

- **`NewTicketModal`** — Primary export; a controlled modal component driven by `isOpen`/`onClose` props
- **`useCreateTicket`** — Hook providing form state (`form`, `setField`), submission handling (`handleSubmit`, `isSubmitting`), and `resetForm`
- **`NewTicketModalProps`** — Interface defining `isOpen: boolean` and `onClose: () => void`

**Form Fields:**
| Field | Component | Notes |
|---|---|---|
| `subject` | `Input` | Text input for ticket title |
| `attachments` | `FileUpload` | Up to 10 files, accepts window drops |
| `description` | `Textarea` | 5-row freeform problem description |

## Usage Example

```typescript
import { NewTicketModal } from './components/NewTicketModal';
import { useState } from 'react';

export function SupportPage() {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <>
      <button onClick={() => setIsOpen(true)}>Open Ticket</button>

      <NewTicketModal
        isOpen={isOpen}
        onClose={() => setIsOpen(false)}
      />
    </>
  );
}
```

**Behaviour notes:**
- Form resets automatically on close via `handleClose` → `resetForm()`
- All fields are disabled while `isSubmitting` is `true`
- Submit button renders a loading spinner during submission (`variant="accent"`)
- Cancel triggers the same `handleClose` path, ensuring clean state on dismiss
