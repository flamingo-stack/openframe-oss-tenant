Modal component for creating new support tickets with subject, description, and file attachment fields.

## Key Components

- **`NewTicketModal`** — Controlled modal component that renders a ticket creation form
- **`NewTicketModalProps`** — Interface with `isOpen` (visibility toggle) and `onClose` (dismiss callback)
- **`useCreateTicket`** — Hook (imported) managing form state, submission logic, and reset behavior

## Form Fields

| Field | Component | Notes |
|-------|-----------|-------|
| Subject | `Input` | Plain text, required |
| Attachments | `FileUpload` | Multi-file, max 10, accepts window drops |
| Description | `Textarea` | 5 rows, freeform text |

## Usage Example

```typescript
import { NewTicketModal } from './NewTicketModal';
import { useState } from 'react';

function SupportPage() {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <>
      <button onClick={() => setIsOpen(true)}>Open Ticket</button>
      <NewTicketModal
        isOpen={isOpen}
        onClose={() => setIsOpen(false)}
      />
    </>
  );
}
```

## Behavior Notes

- Form resets via `resetForm()` on both **Cancel** and modal close (not just on successful submit)
- Submit button shows a loading spinner while `isSubmitting` is `true`
- All inputs are disabled during submission to prevent duplicate requests
- Attachments support both file picker and drag-and-drop onto the window (`acceptWindowDrops`)
