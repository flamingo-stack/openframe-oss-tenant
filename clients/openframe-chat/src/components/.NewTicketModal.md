Modal component for creating new support tickets, providing a form with subject, description, and file attachment fields.

## Key Components

- **`NewTicketModal`** — Main exported component that renders a controlled modal form for ticket creation
- **`NewTicketModalProps`** — Interface with `isOpen` (visibility toggle) and `onClose` (close callback) props
- **`useCreateTicket`** — Hook (imported) that manages form state, submission logic, and reset behavior

## Form Fields

| Field | Component | Details |
|---|---|---|
| Subject | `Input` | Plain text, required for ticket title |
| Attachments | `FileUpload` | Multi-file, up to 10 files, accepts window drops |
| Description | `Textarea` | 5-row freeform problem description |

## Usage Example

```typescript
import { NewTicketModal } from './components/NewTicketModal';
import { useState } from 'react';

function SupportPage() {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <>
      <button onClick={() => setIsOpen(true)}>Open Ticket</button>
      <NewTicketModal
        isOpen={isOpen}
        onClose={() => setIsOpen(false)}
      />
    </>
  );
}
```

## Behavior Notes

- Form state resets automatically on close via `resetForm()`
- Buttons and inputs are disabled during submission (`isSubmitting`)
- The **Create Ticket** button shows a loading indicator while submitting
- File uploads support drag-and-drop from the window with a scrollable list capped at `200px`
