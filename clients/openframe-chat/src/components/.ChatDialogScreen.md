A thin wrapper component that renders a paginated chat message list for a dialog screen, delegating rendering to `ChatMessageList` from the OpenFrame frontend core.

## Key Components

- **`ChatDialogScreen`** — Default export component that wraps `ChatMessageList` with dialog-specific props
- **`ChatDialogScreenProps`** — Interface defining the component's expected props

| Prop | Type | Description |
|------|------|-------------|
| `messages` | `Message[]` | Array of chat messages to display |
| `dialogId` | `string?` | Optional identifier for the current dialog |
| `isTyping` | `boolean` | Shows typing indicator when `true` |
| `isLoadingHistory` | `boolean` | Shows loading state while fetching history |
| `hasNextPage` | `boolean` | Indicates more messages are available to load |
| `isFetchingNextPage` | `boolean` | Indicates a page load is in progress |
| `onLoadMore` | `() => void` | Callback triggered to load the next page |

## Usage Example

```typescript
import { ChatDialogScreen } from './ChatDialogScreen';

<ChatDialogScreen
  messages={messages}
  dialogId="dialog-123"
  isTyping={false}
  isLoadingHistory={false}
  hasNextPage={true}
  isFetchingNextPage={false}
  onLoadMore={() => fetchNextPage()}
/>
```

> **Note:** `autoScroll` is hardcoded to `true`, meaning the list will always scroll to the latest message automatically. Override behavior requires modifying the component directly.
