A presentational screen component that renders a paginated chat message list for a dialog session, delegating rendering to `ChatMessageList` from the OpenFrame frontend core.

## Key Components

- **`ChatDialogScreen`** — Default exported functional component that wraps `ChatMessageList` with auto-scroll enabled
- **`ChatDialogScreenProps`** — Interface defining the component's props:
  - `messages` — Array of `Message` objects to display
  - `dialogId` — Optional identifier for the active dialog session
  - `isTyping` — Indicates if an AI typing indicator should be shown
  - `isLoadingHistory` — Controls loading state while fetching message history
  - `hasNextPage` / `isFetchingNextPage` — Pagination state for infinite scroll
  - `onLoadMore` — Callback triggered when the user scrolls to load older messages

## Usage Example

```typescript
import { ChatDialogScreen } from './ChatDialogScreen';

<ChatDialogScreen
  messages={messages}
  dialogId="dialog-abc123"
  isTyping={false}
  isLoadingHistory={false}
  hasNextPage={true}
  isFetchingNextPage={false}
  onLoadMore={() => fetchNextPage()}
/>
```

> `autoScroll` is hardcoded to `true` — the component always scrolls to the latest message on new content. Override behavior requires modifying the component directly or extending `ChatMessageList`.
