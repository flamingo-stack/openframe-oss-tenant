A thin wrapper component that renders a chat message list for a dialog screen, delegating all rendering to the `ChatMessageList` component from the OpenFrame frontend core library.

## Key Components

**`ChatDialogScreen`** — Default export functional component that composes `ChatMessageList` with auto-scroll enabled.

**`ChatDialogScreenProps`** — Interface defining the component's props:

| Prop | Type | Description |
|---|---|---|
| `messages` | `Message[]` | Array of chat messages to display |
| `dialogId` | `string?` | Optional identifier for the current dialog |
| `isTyping` | `boolean` | Whether the AI/agent is currently typing |
| `isLoadingHistory` | `boolean` | Whether historical messages are loading |
| `hasNextPage` | `boolean` | Whether more messages can be paginated |
| `isFetchingNextPage` | `boolean` | Whether the next page is currently being fetched |
| `onLoadMore` | `() => void` | Callback triggered to load additional message history |

## Usage Example

```typescript
import { ChatDialogScreen } from './ChatDialogScreen';

function MyChat() {
  return (
    <ChatDialogScreen
      messages={messages}
      dialogId="dialog-123"
      isTyping={false}
      isLoadingHistory={false}
      hasNextPage={true}
      isFetchingNextPage={false}
      onLoadMore={() => fetchNextPage()}
    />
  );
}
```

> **Note:** `autoScroll` is hardcoded to `true` in this component — the message list will always scroll to the latest message automatically.
