Singleton service that fetches and caches the list of AI models supported by the Flamingo platform, enabling model lookups by name across providers (Anthropic, OpenAI, Google Gemini).

## Key Components

**Interfaces**
- `SupportedModel` — Shape of a single model entry: `modelName`, `displayName`, `provider`, `contextWindow`
- `SupportedModelsResponse` — Typed API response grouped by provider (`anthropic`, `openai`, `google-gemini`)

**Class: `SupportedModelsService`**
| Method | Description |
|--------|-------------|
| `loadSupportedModels()` | Fetches models from `/chat/api/v1/ai-configuration/supported-models`; deduplicates concurrent calls via a shared promise |
| `getModelDisplayName(modelName)` | Returns human-readable display name, falls back to raw `modelName` |
| `getModel(modelName)` | Returns full `SupportedModel` object or `undefined` |
| `getAllModels()` | Returns all cached models as a flat array |
| `isModelSupported(modelName)` | Boolean check for model availability |
| `reset()` | Clears cache and resets load state (useful for testing or token refresh) |

**Singleton export**
- `supportedModelsService` — Pre-instantiated instance for app-wide use

## Usage Example

```typescript
import { supportedModelsService } from './supportedModelsService';

// Load once at app initialization
await supportedModelsService.loadSupportedModels();

// Resolve a display name for the UI
const label = supportedModelsService.getModelDisplayName('claude-3-5-sonnet-20241022');
// → "Claude 3.5 Sonnet" (or the raw model name if not found)

// Guard before sending a chat request
if (!supportedModelsService.isModelSupported(selectedModel)) {
  throw new Error(`Model "${selectedModel}" is not available.`);
}

// Populate a model picker
const options = supportedModelsService.getAllModels().map(m => ({
  value: m.modelName,
  label: m.displayName,
}));
```

> **Note:** `loadSupportedModels()` is idempotent — concurrent calls share a single in-flight request and subsequent calls return immediately once the cache is populated. Call `reset()` to force a re-fetch after a token change.
