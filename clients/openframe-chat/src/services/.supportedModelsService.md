Manages supported AI models from multiple providers (OpenAI, Anthropic, Google Gemini) with caching and authentication. Fetches model configurations including display names, context windows, and provider information from the API.

## Key Components

- **`SupportedModel`** - Interface defining model structure with name, display name, provider, and context window
- **`SupportedModelsResponse`** - API response structure organized by provider
- **`SupportedModelsService`** - Main service class with caching and model management
- **`loadSupportedModels()`** - Fetches and caches models from API with deduplication logic
- **`getModelDisplayName()`** - Returns user-friendly display name for a model
- **`getModel()` / `getAllModels()`** - Model retrieval methods
- **`isModelSupported()`** - Checks if a specific model is available
- **`reset()`** - Clears cache and forces reload on next access

## Usage Example

```typescript
import { supportedModelsService } from './supportedModelsService'

// Load models (automatically cached)
await supportedModelsService.loadSupportedModels()

// Get user-friendly display name
const displayName = supportedModelsService.getModelDisplayName('gpt-4-turbo')
console.log(displayName) // "GPT-4 Turbo"

// Check if model is supported
if (supportedModelsService.isModelSupported('claude-3-opus')) {
  const model = supportedModelsService.getModel('claude-3-opus')
  console.log(`Context window: ${model?.contextWindow}`)
}

// Get all available models
const allModels = supportedModelsService.getAllModels()
allModels.forEach(model => {
  console.log(`${model.displayName} (${model.provider})`)
})
```
