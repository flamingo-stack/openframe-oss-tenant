Singleton service that fetches and caches the list of AI models supported by the Flamingo platform, organized by provider (Anthropic, OpenAI, Google Gemini).

## Key Components

### Interfaces

| Interface | Description |
|-----------|-------------|
| `SupportedModel` | Describes a single model with `modelName`, `displayName`, `provider`, and `contextWindow` |
| `SupportedModelsResponse` | API response shape keyed by provider (`anthropic`, `openai`, `google-gemini`) |

### Class: `SupportedModelsService`

| Method | Description |
|--------|-------------|
| `loadSupportedModels()` | Fetches models from the API; deduplicates concurrent calls via a shared promise |
| `getModelDisplayName(modelName)` | Returns human-readable display name, falls back to `modelName` if not found |
| `getModel(modelName)` | Returns the full `SupportedModel` object or `undefined` |
| `getAllModels()` | Returns all cached models as a flat array |
| `isModelSupported(modelName)` | Checks whether a model exists in the cache |
| `reset()` | Clears the cache and resets load state (useful for testing or re-auth) |

### Exports

- `supportedModelsService` — pre-instantiated singleton
- `SupportedModel` — model descriptor interface
- `SupportedModelsResponse` — API response interface

## Usage Example

```typescript
import { supportedModelsService } from './supportedModelsService';

// Load models once (safe to call multiple times)
await supportedModelsService.loadSupportedModels();

// Resolve a display name for rendering in UI
const label = supportedModelsService.getModelDisplayName('claude-3-5-sonnet-20241022');
// → "Claude 3.5 Sonnet" (or falls back to the raw model name)

// Guard before passing a model to the AI pipeline
if (supportedModelsService.isModelSupported(selectedModel)) {
  const model = supportedModelsService.getModel(selectedModel);
  console.log(`Context window: ${model?.contextWindow} tokens`);
}

// List all available models for a selector component
const allModels = supportedModelsService.getAllModels();
```

> **Note:** `loadSupportedModels()` is a no-op if models are already cached and returns the in-flight promise if a fetch is already in progress, preventing duplicate network requests.
