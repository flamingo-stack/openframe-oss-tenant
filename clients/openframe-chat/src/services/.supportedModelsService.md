Singleton service that fetches and caches the list of AI models supported by the OpenFrame platform, enabling model lookups by name across Anthropic, OpenAI, and Google Gemini providers.

## Key Components

### Interfaces

| Interface | Description |
|---|---|
| `SupportedModel` | Model metadata: `modelName`, `displayName`, `provider`, `contextWindow` |
| `SupportedModelsResponse` | API response shape, keyed by provider (`anthropic`, `openai`, `google-gemini`) |

### Class: `SupportedModelsService`

| Method | Description |
|---|---|
| `loadSupportedModels()` | Fetches models from the API; deduplicates concurrent calls via a shared promise |
| `getModelDisplayName(modelName)` | Returns human-readable display name, falls back to `modelName` if not found |
| `getModel(modelName)` | Returns the full `SupportedModel` object or `undefined` |
| `getAllModels()` | Returns all cached models as a flat array |
| `isModelSupported(modelName)` | Checks whether a model is in the cache |
| `reset()` | Clears cache and resets load state (useful for testing or token refresh) |

### Singleton Export

`supportedModelsService` — pre-instantiated singleton for use across the application.

## Usage Example

```typescript
import { supportedModelsService } from './supportedModelsService';

// Load once at startup (safe to call multiple times)
await supportedModelsService.loadSupportedModels();

// Resolve a model's display name for UI rendering
const label = supportedModelsService.getModelDisplayName('claude-3-5-sonnet-20241022');
// → "Claude 3.5 Sonnet" (or falls back to the raw model name)

// Guard against unsupported model selections
if (!supportedModelsService.isModelSupported(selectedModel)) {
  console.warn('Model not available in this tenant');
}

// List all available models for a model picker
const allModels = supportedModelsService.getAllModels();
```

> **Note:** `loadSupportedModels()` is a no-op if models are already loaded, and concurrent calls share a single in-flight request to avoid duplicate API calls.
