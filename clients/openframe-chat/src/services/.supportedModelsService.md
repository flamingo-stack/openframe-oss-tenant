Service that manages supported AI models from the OpenFrame API, providing model metadata including display names, providers, and context windows.

## Key Components

- **SupportedModel interface** - Defines model metadata structure with name, display name, provider, and context window
- **SupportedModelsResponse interface** - API response format with models grouped by provider (Anthropic, OpenAI, Google Gemini)
- **SupportedModelsService class** - Singleton service that fetches and caches model information
- **loadSupportedModels()** - Async method to fetch models from API with built-in caching
- **getModelDisplayName()** - Returns human-readable display name for a model
- **getModel()** - Retrieves full model metadata by name
- **getAllModels()** - Returns array of all supported models
- **isModelSupported()** - Checks if a specific model is available

## Usage Example

```typescript
import { supportedModelsService } from './supportedModelsService'

// Load models from API (cached after first call)
await supportedModelsService.loadSupportedModels()

// Check if model is supported
const isSupported = supportedModelsService.isModelSupported('gpt-4')

// Get display name for UI
const displayName = supportedModelsService.getModelDisplayName('gpt-4')

// Get full model details
const model = supportedModelsService.getModel('gpt-4')
console.log(model?.contextWindow) // e.g., 8192

// Get all available models
const allModels = supportedModelsService.getAllModels()
```

The service automatically handles authentication via the tokenService and implements promise-based caching to prevent duplicate API calls during concurrent access.
