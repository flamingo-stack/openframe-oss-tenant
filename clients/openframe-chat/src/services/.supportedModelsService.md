Service for managing and accessing AI model configurations from the Flamingo platform. Provides centralized access to supported models from multiple providers (Anthropic, OpenAI, Google Gemini) with automatic loading and caching.

## Key Components

- **`SupportedModel`** - Interface defining model structure (name, display name, provider, context window)
- **`SupportedModelsResponse`** - API response interface organizing models by provider
- **`SupportedModelsService`** - Main service class with lazy loading and caching capabilities
- **`supportedModelsService`** - Singleton instance for application-wide use

### Core Methods
- `loadSupportedModels()` - Fetches models from API with promise caching
- `getModelDisplayName()` - Returns human-readable name for a model
- `getModel()` - Retrieves complete model configuration
- `getAllModels()` - Returns all cached models
- `isModelSupported()` - Checks if a model is available
- `reset()` - Clears cache and forces reload

## Usage Example

```typescript
import { supportedModelsService } from './supportedModelsService'

// Load models (automatically cached)
await supportedModelsService.loadSupportedModels()

// Check if a model is supported
if (supportedModelsService.isModelSupported('claude-3-sonnet')) {
  const model = supportedModelsService.getModel('claude-3-sonnet')
  console.log(`Context window: ${model?.contextWindow}`)
}

// Get display name for UI
const displayName = supportedModelsService.getModelDisplayName('gpt-4')
// Returns "GPT-4" instead of "gpt-4"

// Get all available models for dropdown
const allModels = supportedModelsService.getAllModels()
```

The service automatically handles authentication via `tokenService` and gracefully handles API failures with console warnings. Models are cached until manually reset or the application restarts.
