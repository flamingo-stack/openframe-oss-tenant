Fetches and caches the list of AI models supported by the Flamingo platform, providing lookup utilities for model metadata across providers (Anthropic, OpenAI, Google Gemini).

## Key Components

**Interfaces**
- `SupportedModel` — Shape of a single model entry (`modelName`, `displayName`, `provider`, `contextWindow`)
- `SupportedModelsResponse` — API response shape, keyed by provider (`anthropic`, `openai`, `google-gemini`)

**Class: `SupportedModelsService`**
| Method | Description |
|---|---|
| `loadSupportedModels()` | Fetches models from the API (deduplicates concurrent calls via a shared promise) |
| `getModelDisplayName(modelName)` | Returns human-friendly display name, falls back to raw `modelName` |
| `getModel(modelName)` | Returns full `SupportedModel` object or `undefined` |
| `getAllModels()` | Returns all cached models as a flat array |
| `isModelSupported(modelName)` | Boolean check for model existence in cache |
| `reset()` | Clears cache and load state (useful for testing or re-auth) |

**Singleton export:** `supportedModelsService`

## Usage Example

```typescript
import { supportedModelsService } from './supportedModelsService';

// Load once at app startup (safe to call multiple times)
await supportedModelsService.loadSupportedModels();

// Resolve a model's display name for UI rendering
const label = supportedModelsService.getModelDisplayName('claude-3-5-sonnet-20241022');
// → "Claude 3.5 Sonnet" (or raw model ID if not found)

// Check before sending a request
if (supportedModelsService.isModelSupported(selectedModel)) {
  const model = supportedModelsService.getModel(selectedModel);
  console.log(model?.provider, model?.contextWindow);
}

// List all available models for a picker
const allModels = supportedModelsService.getAllModels();
```

> **Note:** `loadSupportedModels()` is a no-op if models are already cached and uses a single in-flight promise to prevent duplicate API calls under concurrent invocations.
