Fetches AI assistant configuration (appearance, quick actions, and LLM provider settings) from the OpenFrame GraphQL API, merging `clientView` and `clientAiConfig` into a single flattened response for the chat interface.

## Key Components

**Interfaces**
- `AiQuickAction` — Represents a single quick action (`id`, `name`, `instructions`)
- `AiSettingsResponse` — Flattened chat-facing view combining appearance from `clientView` and AI config from `clientAiConfig`

**`AiSettingsService` (class)**
- `initializeClient()` — Lazily creates/reuses a `GraphQLClient` instance, refreshing auth headers on each call and recreating the client when the API base URL changes
- `request<T>()` — Thin wrapper around the GraphQL client's `request` method
- `fetchAiSettings(organizationId?)` — Primary public method; executes `ChatAiSettings` query and merges both root fields into `AiSettingsResponse`

**`aiSettingsService`** — Singleton export, used throughout the application

## Usage Example

```typescript
import { aiSettingsService } from './aiSettingsService';

// Fetch settings for the device's org (resolved from machine token)
const settings = await aiSettingsService.fetchAiSettings();

if (settings) {
  console.log(settings.assistantName);       // e.g. "Fae"
  console.log(settings.llmProvider);         // e.g. "openai"
  console.log(settings.providerModel);       // e.g. "gpt-4o"
  console.log(settings.quickActionsIsDefault); // true = use OpenFrame hub defaults
  console.log(settings.quickActions);          // null or custom actions array
}
```

> **Note:** `organizationId` defaults to `null`; the backend resolves the correct org automatically from the machine token. Pass an explicit ID only when querying on behalf of a specific organization.
