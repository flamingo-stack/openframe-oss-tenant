A service class for managing chat API operations, including dialog creation and message sending with automatic token management and dialog state tracking.

## Key Components

- **ChatApiService class**: Main service for chat operations with automatic token refresh handling
- **createDialog()**: Creates new chat dialogs and returns dialog ID
- **sendMessage()**: Sends messages to specific dialogs with CLIENT_CHAT type
- **onDialogIdUpdate()**: Observable pattern for dialog ID state changes
- **setDialogId()/getDialogId()**: Dialog state management
- **Debug mode**: Optional logging for troubleshooting API calls

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize with optional debug mode
const chatService = new ChatApiService(true)

// Listen for dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Current dialog:', dialogId)
})

// Create a new chat dialog
const dialogId = await chatService.createDialog()

// Send a message to the dialog
await chatService.sendMessage({
  dialogId,
  content: "Hello, how can I help you?",
  chatType: 'CLIENT_CHAT'
})

// Get current dialog ID
const currentDialog = chatService.getDialogId()

// Clean up when done
unsubscribe()
chatService.destroy()
```

The service automatically handles authentication tokens via the tokenService dependency and provides error handling with optional debug information for API failures.
