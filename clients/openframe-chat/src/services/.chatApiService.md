A service class that manages chat dialog creation and message sending through the Flamingo chat API, with automatic token management and dialog state tracking.

## Key Components

- **ChatApiService class** - Main service for chat operations with dialog lifecycle management
- **createDialog()** - Creates new chat dialogs and returns dialog ID
- **sendMessage()** - Sends messages to existing dialogs with CLIENT_CHAT type
- **onDialogIdUpdate()** - Subscribe to dialog ID changes with listener pattern
- **setDialogId()** - Updates current dialog ID and notifies listeners
- **Dialog state management** - Tracks current dialog ID with automatic listener notifications
- **Token integration** - Automatic token refresh and API URL updates via tokenService
- **Debug mode** - Optional logging for network requests and state changes

## Usage Example

```typescript
// Initialize the chat service
const chatService = new ChatApiService(true) // debug mode enabled

// Subscribe to dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID updated:', dialogId)
})

// Create a new chat dialog
try {
  const dialogId = await chatService.createDialog()
  console.log('Created dialog:', dialogId)

  // Send a message to the dialog
  await chatService.sendMessage({
    dialogId: dialogId,
    content: 'Hello, I need help with my setup',
    chatType: 'CLIENT_CHAT'
  })

  console.log('Message sent successfully')
} catch (error) {
  console.error('Chat operation failed:', error.message)
}

// Clean up when done
unsubscribe()
chatService.destroy()
```
