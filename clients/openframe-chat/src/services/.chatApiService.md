Service class for managing chat dialog operations and API communication in the Flamingo platform. Handles dialog creation, message sending, and dialog state management with automatic token and API URL synchronization.

## Key Components

- **ChatApiService** - Main service class for chat API operations
- **createDialog()** - Creates new chat dialogs and returns dialog ID
- **sendMessage()** - Sends messages to existing chat dialogs
- **onDialogIdUpdate()** - Subscribe to dialog ID changes
- **setDialogId()** - Updates current dialog ID and notifies listeners
- **reset()** - Clears current dialog state
- **destroy()** - Cleanup method for removing listeners

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize service with optional debug mode
const chatService = new ChatApiService(true)

// Listen for dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID updated:', dialogId)
})

// Create a new dialog
const dialogId = await chatService.createDialog()

// Send a message to the dialog
await chatService.sendMessage({
  dialogId: dialogId,
  content: 'Hello, how can I help you today?',
  chatType: 'CLIENT_CHAT'
})

// Get current dialog ID
const currentId = chatService.getDialogId()

// Reset dialog state
chatService.reset()

// Cleanup when done
unsubscribe()
chatService.destroy()
```

The service automatically handles authentication tokens and API URL updates through the tokenService integration, ensuring seamless communication with the Flamingo chat API endpoints.
