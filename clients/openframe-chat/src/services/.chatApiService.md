A service class for managing chat dialog operations and communication with the Flamingo chat API, including dialog creation, message sending, and dialog state management.

## Key Components

- **ChatApiService** - Main service class that manages chat dialogs and API communication
- **createDialog()** - Creates a new chat dialog and returns its ID
- **sendMessage()** - Sends a message to a specific dialog
- **onDialogIdUpdate()** - Registers listeners for dialog ID changes
- **setDialogId()** - Updates the current dialog ID and notifies listeners
- **Dialog state management** - Tracks current dialog ID with reactive updates
- **Token integration** - Automatically handles authentication via tokenService
- **Debug mode** - Optional logging for development and troubleshooting

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize the service
const chatService = new ChatApiService(true) // debug mode enabled

// Listen for dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID updated:', dialogId)
})

// Create a new dialog
try {
  const dialogId = await chatService.createDialog()
  console.log('Created dialog:', dialogId)
  
  // Send a message
  await chatService.sendMessage({
    dialogId,
    content: 'Hello, how can you help me?',
    chatType: 'CLIENT_CHAT'
  })
} catch (error) {
  console.error('Chat operation failed:', error)
}

// Cleanup
unsubscribe()
chatService.destroy()
```
