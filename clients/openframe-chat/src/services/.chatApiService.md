A service class for managing chat dialog operations with authentication and dialog state management through the OpenFrame chat API.

## Key Components

- **ChatApiService** - Main service class for chat operations with dialog ID state management
- **createDialog()** - Creates a new chat dialog and returns its ID
- **sendMessage()** - Sends messages to a specific dialog with chat type specification
- **onDialogIdUpdate()** - Registers callbacks for dialog ID changes with automatic cleanup
- **setDialogId() / getDialogId()** - Dialog state management with listener notifications
- **Debug mode** - Optional logging for network operations and state changes
- **Token integration** - Automatic token refresh handling via tokenService

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize with debug mode
const chatApi = new ChatApiService(true)

// Listen for dialog ID changes
const unsubscribe = chatApi.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID changed:', dialogId)
})

// Create a new dialog
const dialogId = await chatApi.createDialog()

// Send a message
await chatApi.sendMessage({
  dialogId,
  content: 'Hello, how can I help you today?',
  chatType: 'CLIENT_CHAT'
})

// Clean up
unsubscribe()
chatApi.destroy()
```

The service automatically handles authentication headers, API URL resolution, and provides error handling with optional debug information for network operations.
