A service class for managing chat dialogs and message sending, handling dialog creation, message posting, and dialog ID state management with authentication integration.

## Key Components

- **ChatApiService**: Main class providing chat API operations
- **createDialog()**: Creates a new chat dialog and returns the dialog ID
- **sendMessage()**: Sends messages to existing chat dialogs
- **onDialogIdUpdate()**: Subscribe to dialog ID changes with callback listeners
- **setDialogId()**: Updates current dialog ID and notifies listeners
- **destroy()**: Cleanup method for removing token service subscriptions

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize the service with optional debug mode
const chatService = new ChatApiService(true)

// Subscribe to dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Current dialog:', dialogId)
})

// Create a new dialog
const dialogId = await chatService.createDialog()

// Send a message to the dialog
await chatService.sendMessage({
  dialogId,
  content: 'Hello, how can you help me today?',
  chatType: 'CLIENT_CHAT'
})

// Get current dialog ID
const currentDialog = chatService.getDialogId()

// Reset dialog state
chatService.reset()

// Cleanup when done
unsubscribe()
chatService.destroy()
```

The service automatically handles authentication tokens through the `tokenService` integration and provides error handling with optional debug logging for network issues.
