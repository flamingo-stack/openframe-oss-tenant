A TypeScript service class that manages chat dialog operations through REST API calls, including dialog creation, message sending, and dialog ID state management with token-based authentication.

## Key Components

- **`ChatApiService`** - Main service class for chat operations
- **`createDialog()`** - Creates new chat dialogs and returns dialog ID
- **`sendMessage()`** - Sends messages to specific dialogs with chat type classification
- **`onDialogIdUpdate()`** - Subscribes to dialog ID changes with listener pattern
- **`setDialogId()`** - Updates current dialog ID and notifies listeners
- **Debug mode** - Optional logging for network operations and token updates
- **Token integration** - Automatic token refresh and API URL updates via `tokenService`

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize service with debug mode
const chatService = new ChatApiService(true)

// Subscribe to dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID changed:', dialogId)
})

// Create a new dialog
const dialogId = await chatService.createDialog()

// Send a message
await chatService.sendMessage({
  dialogId,
  content: "Hello, how can I help?",
  chatType: 'CLIENT_CHAT'
})

// Clean up
unsubscribe()
chatService.destroy()
```

The service handles token management automatically through the `tokenService` dependency and provides robust error handling with optional debug logging for development environments.
