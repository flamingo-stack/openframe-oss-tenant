Service class that manages chat API operations including dialog creation, message sending, and session management with token-based authentication. It provides reactive dialog ID tracking and integrates with the Flamingo chat API endpoints.

## Key Components

- **ChatApiService** - Main service class for chat API interactions
- **createDialog()** - Creates new chat dialogs and returns dialog ID
- **sendMessage()** - Sends messages to existing chat dialogs
- **onDialogIdUpdate()** - Reactive listener for dialog ID changes
- **setDialogId()** - Updates current dialog ID and notifies listeners
- **reset()** - Clears current dialog session
- **destroy()** - Cleanup method for service disposal

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize service with debug mode
const chatService = new ChatApiService(true)

// Listen for dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID updated:', dialogId)
})

// Create a new chat dialog
const dialogId = await chatService.createDialog()

// Send a message to the dialog
await chatService.sendMessage({
  dialogId,
  content: 'Hello, how can you help me?',
  chatType: 'CLIENT_CHAT'
})

// Reset session and cleanup
chatService.reset()
chatService.destroy()
unsubscribe()
```

The service automatically handles token management through the `tokenService` integration and provides error handling with optional debug logging for development environments.
