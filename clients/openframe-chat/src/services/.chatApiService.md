A service class that manages chat dialog creation and message sending for the Flamingo AI chat API, handling authentication tokens and providing reactive dialog state management.

## Key Components

- **ChatApiService** - Main service class for chat API operations
- **createDialog()** - Creates a new chat dialog and returns the dialog ID
- **sendMessage()** - Sends messages to a specific dialog
- **onDialogIdUpdate()** - Subscribe to dialog ID changes with reactive callbacks
- **setDialogId()** - Updates the current dialog ID and notifies listeners
- **reset()** - Clears the current dialog state
- **destroy()** - Cleanup method for removing event listeners

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize the service with optional debug mode
const chatService = new ChatApiService(true)

// Subscribe to dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID changed:', dialogId)
})

// Create a new chat dialog
const dialogId = await chatService.createDialog()

// Send a message to the dialog
await chatService.sendMessage({
  dialogId,
  content: 'Hello, AI assistant!',
  chatType: 'CLIENT_CHAT'
})

// Get current dialog ID
const currentDialog = chatService.getDialogId()

// Clean up when done
unsubscribe()
chatService.destroy()
```

The service integrates with `tokenService` for authentication and automatically handles token updates and API URL changes through reactive listeners.
