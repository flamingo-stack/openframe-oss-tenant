A service class that manages chat API operations for the Flamingo platform, including dialog creation, message sending, and authentication token management.

## Key Components

- **ChatApiService class** - Main service for chat API operations
- **createDialog()** - Creates new chat dialogs and returns dialog ID
- **sendMessage()** - Sends messages to existing dialogs
- **onDialogIdUpdate()** - Subscribes to dialog ID changes
- **setDialogId()** - Updates current dialog ID and notifies listeners
- **Token management** - Automatically handles authentication tokens via tokenService
- **Debug mode** - Optional logging for development and troubleshooting

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize with debug mode
const chatService = new ChatApiService(true)

// Listen for dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID changed:', dialogId)
})

// Create a new dialog
const dialogId = await chatService.createDialog()

// Send a message
await chatService.sendMessage({
  dialogId,
  content: "Hello, how can I help with MSP operations?",
  chatType: 'CLIENT_CHAT'
})

// Get current dialog ID
const currentDialog = chatService.getDialogId()

// Cleanup when done
chatService.destroy()
unsubscribe()
```

The service automatically handles authentication headers, API URL configuration, and provides robust error handling with optional debug logging for network operations.
