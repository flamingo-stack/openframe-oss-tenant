Service class for managing chat API interactions with dialog management and token-based authentication. Handles dialog creation, message sending, and provides reactive updates for dialog state changes.

## Key Components

- **ChatApiService** - Main service class with dialog lifecycle management
- **createDialog()** - Creates new chat dialogs and returns dialog ID
- **sendMessage()** - Sends messages to specific dialogs with chat type specification
- **onDialogIdUpdate()** - Subscribes to dialog ID changes with callback mechanism
- **setDialogId()** / **getDialogId()** - Dialog state management methods
- **Debug mode** - Optional logging for development and troubleshooting
- **Token integration** - Automatic token refresh handling via tokenService
- **Resource cleanup** - Proper subscription cleanup with destroy method

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize service with debug logging
const chatService = new ChatApiService(true)

// Listen for dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Current dialog:', dialogId)
})

// Create a new dialog
const dialogId = await chatService.createDialog()

// Send a message to the dialog
await chatService.sendMessage({
  dialogId,
  content: 'Hello, how can you help me today?',
  chatType: 'CLIENT_CHAT'
})

// Clean up when done
unsubscribe()
chatService.destroy()
```

The service automatically handles token management, API URL updates, and provides error handling with optional debug information for network requests.
