Service class that manages chat dialog creation and messaging for the Flamingo AI chat system, handling authentication, API communication, and dialog state management.

## Key Components

- **ChatApiService** - Main service class for chat operations
- **createDialog()** - Creates new chat dialogs and returns dialog ID
- **sendMessage()** - Sends messages to existing dialogs
- **onDialogIdUpdate()** - Subscribes to dialog ID changes
- **setDialogId()** - Updates current dialog ID and notifies listeners
- **getHeaders()** - Builds authenticated request headers
- **destroy()** - Cleanup method for removing event listeners

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize service with debug mode
const chatService = new ChatApiService(true)

// Subscribe to dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID updated:', dialogId)
})

// Create a new dialog
const dialogId = await chatService.createDialog()

// Send a message
await chatService.sendMessage({
  dialogId,
  content: 'Hello, how can you help me?',
  chatType: 'CLIENT_CHAT'
})

// Get current dialog ID
const currentDialog = chatService.getDialogId()

// Cleanup
unsubscribe()
chatService.destroy()
```

The service integrates with `tokenService` for authentication and automatically handles token updates, API URL changes, and error handling with optional debug logging.
