Service class for managing chat dialog operations and API communication with the Flamingo chat system. It handles dialog creation, message sending, and maintains dialog state with reactive updates.

## Key Components

- **ChatApiService class** - Main service for chat operations
- **dialogId management** - Tracks current dialog session with reactive listeners
- **createDialog()** - Creates new chat dialogs and returns dialog ID
- **sendMessage()** - Sends messages to specific dialogs
- **onDialogIdUpdate()** - Subscribes to dialog ID changes
- **Token integration** - Automatically handles authentication via tokenService
- **Debug mode** - Optional debugging with detailed error messages

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize service with optional debug mode
const chatService = new ChatApiService(true)

// Listen for dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID updated:', dialogId)
})

// Create a new dialog
const dialogId = await chatService.createDialog()

// Send a message to the dialog
await chatService.sendMessage({
  dialogId,
  content: 'Hello, how can you help me today?',
  chatType: 'CLIENT_CHAT'
})

// Reset dialog state
chatService.reset()

// Clean up when done
unsubscribe()
chatService.destroy()
```

The service automatically manages authentication tokens and API endpoints through the tokenService integration, providing a clean interface for chat operations within the Flamingo platform.
