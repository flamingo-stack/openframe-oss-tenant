Service class that manages chat dialog creation and message sending through the Flamingo chat API, with automatic token management and dialog ID tracking.

## Key Components

- **ChatApiService** - Main service class for chat operations
- **createDialog()** - Creates new chat dialogs and returns dialog ID
- **sendMessage()** - Sends messages to existing dialogs
- **onDialogIdUpdate()** - Subscribe to dialog ID changes
- **setDialogId()** / **getDialogId()** - Dialog ID management
- **Token Integration** - Automatic token refresh and API URL updates via tokenService
- **Debug Mode** - Optional logging for development and troubleshooting

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize service with debug mode
const chatService = new ChatApiService(true)

// Listen for dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID updated:', dialogId)
})

// Create a new dialog
const dialogId = await chatService.createDialog()
console.log('Created dialog:', dialogId)

// Send a message
await chatService.sendMessage({
  dialogId,
  content: 'Hello, I need help with my server setup',
  chatType: 'CLIENT_CHAT'
})

// Clean up
unsubscribe()
chatService.destroy()
```

The service automatically handles authentication through the tokenService and provides a reactive interface for tracking dialog state changes across the application.
