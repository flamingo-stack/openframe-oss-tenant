Manages chat dialog operations and API communications for the Flamingo chat system. Handles dialog creation, message sending, and maintains dialog state with reactive listeners.

## Key Components

### Main Class
- **`ChatApiService`** - Primary service class for chat API operations
  - `createDialog()` - Creates new chat dialog and returns dialog ID
  - `sendMessage()` - Sends messages to existing dialogs
  - `setDialogId()` / `getDialogId()` - Dialog state management
  - `onDialogIdUpdate()` - Subscribe to dialog ID changes
  - `setDebugMode()` - Toggle detailed error logging
  - `reset()` - Clear current dialog state
  - `destroy()` - Cleanup listeners and subscriptions

### Types
- **`CreateDialogResponse`** - API response structure for dialog creation

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize service with debug mode
const chatService = new ChatApiService(true)

// Subscribe to dialog ID updates
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID changed:', dialogId)
})

// Create new dialog
const dialogId = await chatService.createDialog()

// Send a message
await chatService.sendMessage({
  dialogId,
  content: 'Hello, how can I help?',
  chatType: 'CLIENT_CHAT'
})

// Cleanup when done
unsubscribe()
chatService.destroy()
```

The service integrates with `tokenService` for authentication and automatically handles token updates. It provides reactive state management for dialog IDs and includes comprehensive error handling with optional debug logging.
