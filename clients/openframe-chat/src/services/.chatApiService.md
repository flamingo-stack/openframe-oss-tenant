A service class for managing chat API operations including dialog creation, message sending, and authentication handling with automatic token management.

## Key Components

- **ChatApiService** - Main service class managing chat operations
- **createDialog()** - Creates new chat dialogs and returns dialog ID
- **sendMessage()** - Sends messages to existing dialogs
- **onDialogIdUpdate()** - Subscribes to dialog ID changes with callback system
- **setDialogId()** - Updates current dialog ID and notifies listeners
- **Token Integration** - Automatic token refresh and API URL management via tokenService
- **Debug Mode** - Optional logging for development and troubleshooting

## Usage Example

```typescript
// Initialize the service with debug mode
const chatService = new ChatApiService(true)

// Listen for dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID changed:', dialogId)
})

// Create a new dialog
const dialogId = await chatService.createDialog()
console.log('Created dialog:', dialogId)

// Send a message
await chatService.sendMessage({
  dialogId,
  content: 'Hello, I need help with my account',
  chatType: 'CLIENT_CHAT'
})

// Reset dialog when done
chatService.reset()

// Clean up when component unmounts
chatService.destroy()
unsubscribe()
```

The service automatically handles authentication tokens, API URL updates, and provides error handling with detailed debug information when enabled.
