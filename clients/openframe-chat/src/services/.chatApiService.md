Chat API service that manages dialog creation and message sending for the Flamingo chat system. Handles authentication tokens, API base URLs, and maintains dialog session state with event-driven updates.

## Key Components

- **ChatApiService** - Main service class for chat API operations
- **createDialog()** - Creates new chat dialog and returns dialog ID
- **sendMessage()** - Sends messages to existing dialog with specified chat type
- **onDialogIdUpdate()** - Subscribe to dialog ID changes with callback
- **setDialogId()** - Updates current dialog ID and notifies listeners
- **getApiBaseUrl()** / **getHeaders()** - Private methods for API configuration

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize service with debug mode
const chatService = new ChatApiService(true)

// Listen for dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID updated:', dialogId)
})

// Create a new dialog
try {
  const dialogId = await chatService.createDialog()
  
  // Send a message
  await chatService.sendMessage({
    dialogId,
    content: 'Hello, I need help with my IT setup',
    chatType: 'CLIENT_CHAT'
  })
  
  console.log('Message sent successfully')
} catch (error) {
  console.error('Chat operation failed:', error)
} finally {
  unsubscribe() // Clean up listener
  chatService.destroy() // Clean up service
}
```

The service integrates with `tokenService` for authentication and provides robust error handling with optional debug logging for troubleshooting API interactions.
