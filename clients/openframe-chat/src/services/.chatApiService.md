A service class that manages chat dialog creation and messaging, handling authentication tokens and API communication for client chat functionality.

## Key Components

- **ChatApiService class** - Main service for managing chat dialogs and messages
- **createDialog()** - Creates new chat dialogs and returns dialog ID
- **sendMessage()** - Sends messages to specific chat dialogs
- **onDialogIdUpdate()** - Subscribes to dialog ID changes with listener pattern
- **setDialogId() / getDialogId()** - Dialog ID state management
- **destroy()** - Cleanup method for token service subscriptions

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize service with optional debug mode
const chatService = new ChatApiService(true)

// Listen for dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID updated:', dialogId)
})

// Create a new chat dialog
const dialogId = await chatService.createDialog()

// Send a message to the dialog
await chatService.sendMessage({
  dialogId,
  content: 'Hello, how can I help?',
  chatType: 'CLIENT_CHAT'
})

// Clean up when done
unsubscribe()
chatService.destroy()
```

The service automatically handles token management through integration with `tokenService` and provides error handling for network requests and API responses.
