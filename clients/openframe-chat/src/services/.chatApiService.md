A service class that manages chat dialog creation and message sending for the Flamingo AI chat system, handling authentication tokens and API communication.

## Key Components

**ChatApiService Class**
- `createDialog()` - Creates a new chat dialog and returns its ID
- `sendMessage()` - Sends a message to a specific dialog with chat type
- `setDialogId()` / `getDialogId()` - Manages current dialog state
- `onDialogIdUpdate()` - Subscribe to dialog ID changes
- `reset()` - Clears current dialog
- `destroy()` - Cleanup method for token listeners

**Private Methods**
- `getApiBaseUrl()` - Retrieves API base URL from token service
- `getHeaders()` - Builds authorization headers with bearer token

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize the service with debug mode
const chatService = new ChatApiService(true)

// Listen for dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog changed:', dialogId)
})

// Create a new dialog
try {
  const dialogId = await chatService.createDialog()
  console.log('Created dialog:', dialogId)
  
  // Send a message
  await chatService.sendMessage({
    dialogId,
    content: 'Hello, I need help with my server',
    chatType: 'CLIENT_CHAT'
  })
} catch (error) {
  console.error('Chat error:', error)
}

// Cleanup when done
unsubscribe()
chatService.destroy()
```
