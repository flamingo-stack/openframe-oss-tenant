Manages HTTP communication with the OpenFrame chat API, handling dialog lifecycle (create, message send, stop generation) with reactive token and API URL awareness via `tokenService`.

## Key Components

| Member | Type | Description |
|---|---|---|
| `createDialog()` | `async method` | POSTs to `/chat/api/v1/dialogs`, stores returned ID, notifies listeners |
| `sendMessage()` | `async method` | POSTs a message to `/chat/api/v1/messages` for a given dialog |
| `stopGeneration()` | `async method` | POSTs to the dialog's `/stop` endpoint to halt streaming |
| `onDialogIdUpdate()` | `method` | Subscribes to dialog ID changes; immediately invokes callback with current value |
| `setDialogId()` | `method` | Updates internal dialog ID and fans out to all registered listeners |
| `destroy()` | `method` | Unsubscribes from `tokenService` listeners to prevent memory leaks |
| `reset()` | `method` | Clears the current dialog ID (sets to `null`) |

## Usage Example

```typescript
import { ChatApiService } from './chatApiService';

const chat = new ChatApiService(/* debug= */ true);

// React to dialog ID changes
const unsubscribe = chat.onDialogIdUpdate((id) => {
  console.log('Active dialog:', id);
});

// Create a new dialog and send a message
const dialogId = await chat.createDialog();

await chat.sendMessage({
  dialogId,
  content: 'Hello from Fae!',
  chatType: 'CLIENT_CHAT',
});

// Stop mid-stream if needed
await chat.stopGeneration({ dialogId, chatType: 'CLIENT_CHAT' });

// Cleanup
unsubscribe();
chat.destroy();
```

## Notes

- All API calls call `tokenService.ensureTokenReady()` before executing, guaranteeing a valid auth token on each request.
- `sendMessage` logs a masked token via `maskToken` for safe production log correlation.
- Network errors in `debugMode` include the target URL and dialog ID for easier tracing.
- Listener errors in `onDialogIdUpdate` / `setDialogId` are silently swallowed to prevent one bad subscriber from blocking others.
