A service class that manages chat dialog interactions with the Flamingo API, providing dialog creation, message sending, and state management with token-based authentication.

## Key Components

- **ChatApiService** - Main service class handling chat operations
- **createDialog()** - Creates new chat dialogs and returns dialog ID
- **sendMessage()** - Sends messages to existing dialogs
- **onDialogIdUpdate()** - Event listener for dialog ID changes
- **setDialogId()** - Updates current dialog ID and notifies listeners
- **getHeaders()** - Generates authenticated request headers
- **destroy()** - Cleanup method for proper resource disposal

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize the service with debug mode
const chatService = new ChatApiService(true)

// Listen for dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID updated:', dialogId)
})

// Create a new dialog
const dialogId = await chatService.createDialog()

// Send a message to the dialog
await chatService.sendMessage({
  dialogId,
  content: 'Hello, how can you help me?',
  chatType: 'CLIENT_CHAT'
})

// Get current dialog ID
const currentDialog = chatService.getDialogId()

// Clean up when done
unsubscribe()
chatService.destroy()
```

The service automatically handles token management through the `tokenService` dependency and provides error handling with optional debug logging for API interactions.
