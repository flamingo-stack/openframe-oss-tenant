Manages chat API operations for the Flamingo MSP platform, providing dialog creation, message sending, and real-time dialog ID tracking with automatic token management.

## Key Components

- **ChatApiService** - Main service class for chat API interactions
- **Dialog Management** - Creates and tracks chat dialog sessions
- **Message Operations** - Sends messages to active chat dialogs
- **Token Integration** - Automatic token refresh and API URL updates via `tokenService`
- **Event System** - Real-time listeners for dialog ID changes

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize the service
const chatService = new ChatApiService(true) // debug mode enabled

// Listen for dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID updated:', dialogId)
})

// Create a new chat dialog
const dialogId = await chatService.createDialog()

// Send a message to the dialog
await chatService.sendMessage({
  dialogId,
  content: 'Hello, I need help with my server setup',
  chatType: 'CLIENT_CHAT'
})

// Get current dialog ID
const currentDialog = chatService.getDialogId()

// Reset dialog state
chatService.reset()

// Clean up listeners
unsubscribe()
chatService.destroy()
```

The service automatically handles authentication tokens and API endpoint management through integration with the `tokenService`, making it ideal for OpenFrame's AI-powered chat features.
