Chat API service that manages dialog creation and message sending for the Flamingo platform, integrating with the token service for authentication and providing dialog state management with reactive listeners.

## Key Components

- **ChatApiService** - Main service class for chat operations
- **createDialog()** - Creates new chat dialogs and returns dialog ID
- **sendMessage()** - Sends messages to existing dialogs
- **onDialogIdUpdate()** - Reactive listener system for dialog ID changes
- **setDialogId()** - Updates current dialog ID and notifies listeners
- **destroy()** - Cleanup method for unsubscribing from token service

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize the service
const chatService = new ChatApiService(true) // Enable debug mode

// Listen for dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID changed:', dialogId)
})

// Create a new dialog
const dialogId = await chatService.createDialog()

// Send a message
await chatService.sendMessage({
  dialogId,
  content: 'Hello, how can I help?',
  chatType: 'CLIENT_CHAT'
})

// Get current dialog ID
const currentDialog = chatService.getDialogId()

// Cleanup
unsubscribe()
chatService.destroy()
```

The service automatically handles authentication tokens, API URL updates, and provides error handling with optional debug logging for troubleshooting network issues.
