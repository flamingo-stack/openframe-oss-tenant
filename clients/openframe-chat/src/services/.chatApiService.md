Service for managing chat API interactions including dialog creation, message sending, and dialog state management. Integrates with `tokenService` for authentication and provides reactive updates for dialog ID changes.

## Key Components

- **ChatApiService** - Main service class for chat API operations
- **createDialog()** - Creates a new chat dialog and returns its ID
- **sendMessage()** - Sends messages to a specific dialog
- **onDialogIdUpdate()** - Subscribes to dialog ID changes
- **setDialogId()** - Updates the current dialog ID and notifies listeners
- **reset()** - Clears the current dialog ID
- **destroy()** - Cleanup method for subscriptions

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize the service
const chatService = new ChatApiService(true) // debug mode enabled

// Subscribe to dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID updated:', dialogId)
})

// Create a new dialog
const dialogId = await chatService.createDialog()

// Send a message
await chatService.sendMessage({
  dialogId,
  content: 'Hello, how can you help me today?',
  chatType: 'CLIENT_CHAT'
})

// Cleanup when done
unsubscribe()
chatService.destroy()
```

The service automatically handles authentication through `tokenService` integration and provides error handling with optional debug logging for troubleshooting API interactions.
