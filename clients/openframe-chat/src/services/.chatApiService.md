Manages HTTP communication with the Flamingo chat API, handling dialog lifecycle and message operations with bearer token authentication via `tokenService`.

## Key Components

**`ChatApiService` class**
- `constructor(debug?)` — Initializes the service and subscribes to token/API URL updates from `tokenService`
- `createDialog()` — POSTs to `/chat/api/v1/dialogs`, stores and returns the new dialog ID
- `sendMessage(args)` — POSTs a message payload to `/chat/api/v1/messages` for a given dialog
- `stopGeneration(args)` — POSTs to `/chat/api/v1/dialogs/:id/stop` to halt an in-progress AI response
- `onDialogIdUpdate(callback)` — Subscribes to dialog ID changes; immediately calls callback with the current value; returns an unsubscribe function
- `setDialogId(id)` — Updates the stored dialog ID and notifies all registered listeners
- `reset()` — Clears the active dialog ID
- `destroy()` — Tears down token and API URL subscriptions to prevent memory leaks

## Usage Example

```typescript
import { ChatApiService } from './chatApiService';

const chatApi = new ChatApiService(/* debug */ true);

// Subscribe to dialog ID changes
const unsubscribe = chatApi.onDialogIdUpdate((id) => {
  console.log('Active dialog:', id);
});

// Create a new dialog and send a message
const dialogId = await chatApi.createDialog();

await chatApi.sendMessage({
  dialogId,
  content: 'How do I reset a user password?',
  chatType: 'CLIENT_CHAT',
});

// Stop AI generation mid-stream
await chatApi.stopGeneration({ dialogId, chatType: 'CLIENT_CHAT' });

// Cleanup
unsubscribe();
chatApi.destroy();
```

> **Note:** All API methods call `tokenService.ensureTokenReady()` before execution, ensuring authentication is valid before any request is dispatched.
