Service class that manages chat dialog creation and message sending operations for the Flamingo chat API, with built-in token management and dialog state tracking.

## Key Components

- **ChatApiService** - Main service class for chat API operations
- **createDialog()** - Creates new chat dialogs and manages dialog ID state
- **sendMessage()** - Sends messages to existing chat dialogs
- **onDialogIdUpdate()** - Subscribe to dialog ID changes with callback listeners
- **setDialogId()** / **getDialogId()** - Dialog ID state management
- **Token Integration** - Automatic token refresh and API URL updates via tokenService
- **Debug Mode** - Optional logging for development and troubleshooting

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize service with optional debug mode
const chatService = new ChatApiService(true)

// Subscribe to dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID updated:', dialogId)
})

// Create a new dialog
const dialogId = await chatService.createDialog()

// Send a message
await chatService.sendMessage({
  dialogId,
  content: 'Hello, I need help with my IT infrastructure',
  chatType: 'CLIENT_CHAT'
})

// Reset dialog state
chatService.reset()

// Clean up listeners
unsubscribe()
chatService.destroy()
```

The service automatically handles token authentication, API URL management, and provides error handling with detailed debug information when enabled. It maintains dialog state across the application and notifies listeners of changes.
