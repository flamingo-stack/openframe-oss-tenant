A service class that manages chat API interactions, handling dialog creation, message sending, and dialog state management with token authentication.

## Key Components

- **ChatApiService class**: Main service for chat operations
  - `createDialog()`: Creates a new chat dialog and returns the dialog ID
  - `sendMessage()`: Sends messages to a specific dialog
  - `setDialogId()` / `getDialogId()`: Manages current dialog state
  - `onDialogIdUpdate()`: Subscribes to dialog ID changes
  - `reset()`: Clears current dialog state
  - `destroy()`: Cleanup method for subscriptions

- **Private methods**: 
  - `getApiBaseUrl()`: Retrieves API base URL from token service
  - `getHeaders()`: Builds authorization headers with Bearer token

- **Debug support**: Optional debug mode for enhanced error logging and network debugging

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize service with debug mode
const chatService = new ChatApiService(true)

// Subscribe to dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID updated:', dialogId)
})

// Create a new dialog
const dialogId = await chatService.createDialog()

// Send a message
await chatService.sendMessage({
  dialogId,
  content: 'Hello, how can you help me?',
  chatType: 'CLIENT_CHAT'
})

// Reset dialog when done
chatService.reset()

// Cleanup
unsubscribe()
chatService.destroy()
```

The service integrates with `tokenService` for authentication and automatically handles token updates and API URL changes through event listeners.
