Manages chat dialog creation and message sending through the Flamingo chat API, providing real-time dialog state management and token-based authentication integration.

## Key Components

- **ChatApiService** - Main service class for chat operations with dialog lifecycle management
- **createDialog()** - Creates new chat dialogs and returns dialog ID
- **sendMessage()** - Sends messages to existing dialogs with CLIENT_CHAT type
- **onDialogIdUpdate()** - Subscribes to dialog ID changes with listener pattern
- **setDialogId()** - Updates current dialog ID and notifies all listeners
- **Debug mode** - Optional logging for API requests and token updates

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize service with debug mode
const chatService = new ChatApiService(true)

// Subscribe to dialog changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog updated:', dialogId)
})

// Create a new chat dialog
try {
  const dialogId = await chatService.createDialog()
  
  // Send a message to the dialog
  await chatService.sendMessage({
    dialogId,
    content: 'Hello, how can I help?',
    chatType: 'CLIENT_CHAT'
  })
  
  console.log('Current dialog:', chatService.getDialogId())
} catch (error) {
  console.error('Chat operation failed:', error)
}

// Cleanup when done
unsubscribe()
chatService.destroy()
```

The service automatically handles token management through `tokenService` integration and provides robust error handling with optional debug logging for development environments.
