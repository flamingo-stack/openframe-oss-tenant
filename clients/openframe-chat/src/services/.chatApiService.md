Service class that manages chat dialog creation and message sending with real-time state management and token-based authentication for the Flamingo AI chat system.

## Key Components

- **ChatApiService** - Main service class that handles chat operations
- **createDialog()** - Creates new chat dialogs and returns dialog ID
- **sendMessage()** - Sends messages to existing chat dialogs
- **onDialogIdUpdate()** - Subscribes to dialog ID changes with listener pattern
- **setDialogId()** - Updates current dialog ID and notifies all listeners
- **Token integration** - Automatic token management via tokenService dependency

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize service with debug mode
const chatService = new ChatApiService(true)

// Listen for dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID updated:', dialogId)
})

// Create a new chat dialog
const dialogId = await chatService.createDialog()

// Send a message to the dialog
await chatService.sendMessage({
  dialogId: dialogId,
  content: 'Hello, I need help with my network setup',
  chatType: 'CLIENT_CHAT'
})

// Get current dialog ID
const currentDialog = chatService.getDialogId()

// Clean up when done
unsubscribe()
chatService.destroy()
```

The service automatically handles authentication tokens, provides error handling with debug information, and maintains dialog state across the application with a reactive listener pattern.
