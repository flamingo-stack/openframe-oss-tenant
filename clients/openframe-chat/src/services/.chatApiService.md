Manages chat dialog operations and message sending through the Flamingo Chat API, providing dialog lifecycle management with authentication token integration.

## Key Components

- **ChatApiService** - Main service class handling chat dialogs and messages
- **createDialog()** - Creates new chat dialogs and returns dialog ID
- **sendMessage()** - Sends messages to specific dialogs
- **onDialogIdUpdate()** - Subscribes to dialog ID changes
- **setDialogId()** - Updates current dialog ID and notifies listeners
- **reset()** - Clears current dialog state
- **destroy()** - Cleanup method for token service subscriptions

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize service with debug mode
const chatService = new ChatApiService(true)

// Create a new dialog
const dialogId = await chatService.createDialog()
console.log('Created dialog:', dialogId)

// Send a message to the dialog
await chatService.sendMessage({
  dialogId,
  content: 'Hello, how can I help?',
  chatType: 'CLIENT_CHAT'
})

// Listen for dialog changes
const unsubscribe = chatService.onDialogIdUpdate((id) => {
  console.log('Dialog updated:', id)
})

// Cleanup when done
chatService.destroy()
unsubscribe()
```

The service automatically handles authentication tokens and API URL updates through the tokenService integration, providing a robust foundation for chat functionality in Flamingo applications.
