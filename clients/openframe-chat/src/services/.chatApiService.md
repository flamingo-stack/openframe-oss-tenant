Manages HTTP communication with the Flamingo chat API, handling dialog lifecycle (create, message, stop) and notifying subscribers of dialog ID changes via a listener pattern.

## Key Components

- **`ChatApiService`** — Main class wrapping all chat REST endpoints
- **`createDialog()`** — `POST /chat/api/v1/dialogs` — creates a new chat session and stores the returned dialog ID
- **`sendMessage()`** — `POST /chat/api/v1/messages` — sends a message within an existing dialog
- **`stopGeneration()`** — `POST /chat/api/v1/dialogs/:id/stop` — aborts an in-progress AI response
- **`onDialogIdUpdate()`** — subscribes to dialog ID changes; immediately fires with the current value and returns an unsubscribe function
- **`setDialogId()` / `getDialogId()`** — manually get/set the active dialog ID
- **`reset()`** — clears the current dialog ID and notifies all listeners
- **`destroy()`** — cleans up `tokenService` subscriptions to prevent memory leaks
- **`setDebugMode()`** — enables verbose error logging with URL and dialog context

## Usage Example

```typescript
import { ChatApiService } from './chatApiService';

const chatApi = new ChatApiService(/* debug */ true);

// Subscribe to dialog ID changes
const unsubscribe = chatApi.onDialogIdUpdate((dialogId) => {
  console.log('Active dialog:', dialogId);
});

// Create a dialog, then send a message
const dialogId = await chatApi.createDialog();

await chatApi.sendMessage({
  dialogId,
  content: 'Hello, Mingo!',
  chatType: 'CLIENT_CHAT',
});

// Stop AI generation mid-stream
await chatApi.stopGeneration({ dialogId, chatType: 'CLIENT_CHAT' });

// Cleanup
unsubscribe();
chatApi.destroy();
```

> **Note:** All methods call `tokenService.ensureTokenReady()` before making requests, ensuring auth headers are always populated before any API call is dispatched.
