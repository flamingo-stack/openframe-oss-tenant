Service class for managing chat dialog operations with the Flamingo chat API, handling dialog creation, message sending, and dialog state management with token-based authentication.

## Key Components

- **ChatApiService** - Main service class that provides chat functionality
- **createDialog()** - Creates a new chat dialog and returns its ID
- **sendMessage()** - Sends messages to existing dialogs
- **onDialogIdUpdate()** - Subscribes to dialog ID changes
- **setDialogId()** - Updates the current dialog ID and notifies listeners
- **reset()** - Clears the current dialog state
- **destroy()** - Cleanup method for unsubscribing from token service listeners

## Usage Example

```typescript
// Initialize the chat service
const chatService = new ChatApiService(true) // debug mode enabled

// Listen for dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID updated:', dialogId)
})

// Create a new chat dialog
const dialogId = await chatService.createDialog()
console.log('Created dialog:', dialogId)

// Send a message to the dialog
await chatService.sendMessage({
  dialogId,
  content: 'Hello, how can you help me?',
  chatType: 'CLIENT_CHAT'
})

// Clean up when done
unsubscribe()
chatService.destroy()
```

The service automatically handles authentication through the `tokenService` and provides error handling with optional debug logging. It maintains dialog state and notifies listeners when the current dialog changes.
