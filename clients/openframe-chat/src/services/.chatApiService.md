A service class that manages chat dialog creation and messaging through the Flamingo chat API, with token-based authentication and real-time dialog state management.

## Key Components

- **ChatApiService** - Main service class for chat operations
- **createDialog()** - Creates a new chat dialog and returns the dialog ID
- **sendMessage()** - Sends messages to a specific dialog
- **onDialogIdUpdate()** - Subscribes to dialog ID changes with listener pattern
- **setDialogId()** - Updates the current dialog ID and notifies listeners
- **getHeaders()** - Generates authenticated request headers using token service
- **destroy()** - Cleanup method to remove token service subscriptions

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize the service
const chatService = new ChatApiService(true) // debug mode enabled

// Listen for dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Current dialog:', dialogId)
})

// Create a new dialog
const dialogId = await chatService.createDialog()

// Send a message
await chatService.sendMessage({
  dialogId,
  content: 'Hello, I need help with my server',
  chatType: 'CLIENT_CHAT'
})

// Get current dialog ID
const currentDialog = chatService.getDialogId()

// Reset dialog state
chatService.reset()

// Cleanup when done
unsubscribe()
chatService.destroy()
```

The service automatically handles token management through the `tokenService` dependency and provides error handling with optional debug logging for network operations.
