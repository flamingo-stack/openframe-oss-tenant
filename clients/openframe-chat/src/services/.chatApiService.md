A service class that manages chat dialog operations including creation, messaging, and state management with token-based authentication. It provides reactive dialog ID updates and integrates with the token service for API authentication.

## Key Components

- **ChatApiService** - Main service class for chat operations
- **createDialog()** - Creates a new chat dialog and returns the dialog ID
- **sendMessage()** - Sends messages to a specific dialog
- **setDialogId()** / **getDialogId()** - Dialog ID state management
- **onDialogIdUpdate()** - Subscribe to dialog ID changes
- **reset()** - Clears current dialog state
- **destroy()** - Cleanup method for subscriptions

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize the service
const chatService = new ChatApiService(true) // debug mode enabled

// Listen for dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID updated:', dialogId)
})

// Create a new dialog
try {
  const dialogId = await chatService.createDialog()
  console.log('Created dialog:', dialogId)
  
  // Send a message
  await chatService.sendMessage({
    dialogId,
    content: 'Hello, how can you help me?',
    chatType: 'CLIENT_CHAT'
  })
  
  console.log('Message sent successfully')
} catch (error) {
  console.error('Chat operation failed:', error)
}

// Cleanup when done
unsubscribe()
chatService.destroy()
```

The service automatically handles token management through the `tokenService` integration and provides error handling with optional debug logging for troubleshooting API interactions.
