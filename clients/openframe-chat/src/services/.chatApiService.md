A service class for managing chat API operations including dialog creation, message sending, and dialog state management with token-based authentication.

## Key Components

- **ChatApiService**: Main service class that handles chat API interactions
- **createDialog()**: Creates a new chat dialog and returns the dialog ID
- **sendMessage()**: Sends messages to a specific dialog with chat type specification
- **onDialogIdUpdate()**: Subscribes to dialog ID changes with automatic cleanup
- **setDialogId()**: Updates the current dialog ID and notifies all listeners
- **getDialogId()**: Returns the current dialog ID
- **reset()**: Clears the current dialog ID
- **destroy()**: Cleanup method that removes token service subscriptions

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize the service with debug mode
const chatService = new ChatApiService(true)

// Subscribe to dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID updated:', dialogId)
})

// Create a new dialog
const dialogId = await chatService.createDialog()

// Send a message
await chatService.sendMessage({
  dialogId,
  content: 'Hello, how can you help me?',
  chatType: 'CLIENT_CHAT'
})

// Get current dialog ID
const currentDialog = chatService.getDialogId()

// Clean up when done
unsubscribe()
chatService.destroy()
```

The service automatically manages authentication tokens through the `tokenService` dependency and provides error handling with optional debug logging for network operations.
