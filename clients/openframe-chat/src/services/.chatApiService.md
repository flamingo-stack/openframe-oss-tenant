Manages chat dialog creation and message sending functionality for the Flamingo AI chat system, providing dialog lifecycle management and API communication with token-based authentication.

## Key Components

- **ChatApiService** - Main service class for chat operations
- **createDialog()** - Creates new chat dialogs and returns dialog ID
- **sendMessage()** - Sends messages to existing chat dialogs
- **onDialogIdUpdate()** - Event listener system for dialog ID changes
- **setDialogId()** - Updates current dialog ID and notifies listeners
- **reset()** - Clears current dialog state
- **destroy()** - Cleanup method for service disposal

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize service with optional debug mode
const chatService = new ChatApiService(true)

// Listen for dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID updated:', dialogId)
})

// Create a new dialog
try {
  const dialogId = await chatService.createDialog()
  console.log('Created dialog:', dialogId)
  
  // Send a message
  await chatService.sendMessage({
    dialogId,
    content: 'Hello, how can you help me?',
    chatType: 'CLIENT_CHAT'
  })
} catch (error) {
  console.error('Chat operation failed:', error)
}

// Clean up when done
unsubscribe()
chatService.destroy()
```

The service automatically handles token management through the `tokenService` integration and provides comprehensive error handling with optional debug logging for troubleshooting API communication issues.
