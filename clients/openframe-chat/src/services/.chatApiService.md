A service class that manages chat API operations for Flamingo's AI-powered client chat system, handling dialog creation, message sending, and authentication through the token service.

## Key Components

- **ChatApiService** - Main service class for chat API operations
- **createDialog()** - Creates new chat dialogs and returns dialog ID
- **sendMessage()** - Sends messages to existing dialogs
- **onDialogIdUpdate()** - Subscribes to dialog ID changes with callback
- **setDialogId()** - Updates current dialog ID and notifies listeners
- **getDialogId()** - Retrieves current dialog ID
- **reset()** - Clears current dialog state
- **destroy()** - Cleans up event listeners and subscriptions

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize the service with optional debug mode
const chatService = new ChatApiService(true)

// Listen for dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID updated:', dialogId)
})

// Create a new chat dialog
try {
  const dialogId = await chatService.createDialog()
  console.log('Created dialog:', dialogId)
  
  // Send a message to the dialog
  await chatService.sendMessage({
    dialogId,
    content: 'Hello, I need help with my IT setup',
    chatType: 'CLIENT_CHAT'
  })
  
  console.log('Message sent successfully')
} catch (error) {
  console.error('Chat operation failed:', error)
}

// Clean up when done
unsubscribe()
chatService.destroy()
```

The service automatically handles authentication through the token service and provides error handling with optional debug logging for troubleshooting API interactions.
