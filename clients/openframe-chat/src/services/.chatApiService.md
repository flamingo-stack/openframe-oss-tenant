A service class that manages chat dialog operations and messaging through the Flamingo chat API, handling dialog creation, message sending, and state management with token authentication.

## Key Components

**ChatApiService Class**
- `createDialog()` - Creates a new chat dialog and returns the dialog ID
- `sendMessage()` - Sends a message to a specific dialog with chat type specification
- `onDialogIdUpdate()` - Subscribes to dialog ID changes with callback registration
- `setDialogId()` - Updates the current dialog ID and notifies listeners
- `reset()` - Clears the current dialog ID
- `destroy()` - Cleans up token service subscriptions

**State Management**
- Dialog ID tracking with listener pattern
- Token service integration for authentication
- API URL management through token service
- Debug mode for enhanced error reporting

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize the service with debug mode
const chatService = new ChatApiService(true)

// Create a new dialog
const dialogId = await chatService.createDialog()

// Listen for dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((id) => {
  console.log('Dialog ID changed:', id)
})

// Send a message to the dialog
await chatService.sendMessage({
  dialogId,
  content: 'Hello, how can you help me today?',
  chatType: 'CLIENT_CHAT'
})

// Reset dialog when done
chatService.reset()

// Clean up listeners
unsubscribe()
chatService.destroy()
```
