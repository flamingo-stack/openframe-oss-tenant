Service class that manages chat API operations including dialog creation, message sending, and authentication for Flamingo's chat system.

## Key Components

- **ChatApiService** - Main service class for chat API interactions
- **createDialog()** - Creates new chat dialogs and manages dialog ID state
- **sendMessage()** - Sends messages to existing chat dialogs
- **onDialogIdUpdate()** - Listener system for dialog ID changes
- **setDialogId()/getDialogId()** - Dialog ID state management
- **reset()/destroy()** - Cleanup and resource management methods

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize service with optional debug mode
const chatService = new ChatApiService(true)

// Listen for dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID updated:', dialogId)
})

// Create a new chat dialog
const dialogId = await chatService.createDialog()

// Send a message to the dialog
await chatService.sendMessage({
  dialogId,
  content: 'Hello, how can I help?',
  chatType: 'CLIENT_CHAT'
})

// Get current dialog ID
const currentDialog = chatService.getDialogId()

// Clean up when done
unsubscribe()
chatService.destroy()
```

The service automatically handles authentication tokens through the tokenService dependency and provides error handling with optional debug logging for troubleshooting API issues.
