A service class that manages chat dialog interactions with a remote API, handling dialog creation, message sending, and dialog state management with token-based authentication.

## Key Components

- **`ChatApiService`** - Main service class that manages chat dialogs and API communications
- **`createDialog()`** - Creates a new chat dialog and returns the dialog ID
- **`sendMessage()`** - Sends messages to a specific dialog with chat type specification
- **`onDialogIdUpdate()`** - Subscribes to dialog ID changes with callback pattern
- **`setDialogId()`** - Updates the current dialog ID and notifies listeners
- **Dialog state management** - Tracks current dialog ID and notifies registered listeners of changes
- **Token integration** - Automatically handles authentication tokens via `tokenService`
- **Debug mode** - Optional logging for development and troubleshooting

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize service with debug mode
const chatService = new ChatApiService(true)

// Listen for dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Current dialog:', dialogId)
})

// Create a new chat dialog
const dialogId = await chatService.createDialog()

// Send a message to the dialog
await chatService.sendMessage({
  dialogId,
  content: 'Hello, I need help with my account',
  chatType: 'CLIENT_CHAT'
})

// Clean up when done
unsubscribe()
chatService.destroy()
```

The service automatically manages authentication headers, handles network errors with detailed debug information, and provides a clean subscription pattern for tracking dialog state changes across the application.
