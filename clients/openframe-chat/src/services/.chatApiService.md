Service class that manages chat API interactions, including dialog creation and message sending, with integrated authentication and real-time dialog state management.

## Key Components

- **ChatApiService** - Main service class for chat operations
- **createDialog()** - Creates a new chat dialog and returns the dialog ID
- **sendMessage()** - Sends messages to a specific dialog
- **onDialogIdUpdate()** - Subscribes to dialog ID changes with listener pattern
- **setDialogId()** - Updates the current dialog ID and notifies all listeners
- **Authentication integration** - Uses tokenService for API authentication
- **Debug mode** - Optional logging for development and troubleshooting

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize the service with debug mode enabled
const chatService = new ChatApiService(true)

// Subscribe to dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID updated:', dialogId)
})

// Create a new dialog
const dialogId = await chatService.createDialog()

// Send a message to the dialog
await chatService.sendMessage({
  dialogId,
  content: 'Hello, how can I help you?',
  chatType: 'CLIENT_CHAT'
})

// Clean up when done
unsubscribe()
chatService.destroy()
```

The service automatically handles token refresh, API URL updates, and maintains dialog state across the application lifecycle. It includes comprehensive error handling with detailed debug information when enabled.
