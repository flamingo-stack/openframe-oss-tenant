A service class that manages chat dialog creation and message sending for the Flamingo chat API, with automatic token management and dialog ID state tracking.

## Key Components

- **ChatApiService** - Main service class for chat API operations
- **createDialog()** - Creates a new chat dialog and returns the dialog ID
- **sendMessage()** - Sends messages to existing chat dialogs
- **onDialogIdUpdate()** - Subscribe to dialog ID changes with callback
- **setDialogId()** - Updates current dialog ID and notifies listeners
- **reset()** - Clears the current dialog ID
- **destroy()** - Cleanup method for removing event listeners

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize service with optional debug mode
const chatService = new ChatApiService(true)

// Subscribe to dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID updated:', dialogId)
})

// Create a new dialog
const dialogId = await chatService.createDialog()

// Send a message to the dialog
await chatService.sendMessage({
  dialogId,
  content: 'Hello, how can I help you?',
  chatType: 'CLIENT_CHAT'
})

// Reset dialog when done
chatService.reset()

// Cleanup
unsubscribe()
chatService.destroy()
```

The service automatically handles authentication tokens through the `tokenService` dependency and provides error handling with optional debug logging for network operations.
