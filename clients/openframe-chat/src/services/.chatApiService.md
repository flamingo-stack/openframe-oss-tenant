A service class that manages chat API interactions for the Flamingo platform, including dialog creation, message sending, and token-based authentication. It provides reactive dialog ID management with listener support and integrates with the token service for authentication.

## Key Components

- **ChatApiService** - Main service class for chat operations
- **createDialog()** - Creates new chat dialogs and returns dialog ID
- **sendMessage()** - Sends messages to existing dialogs
- **onDialogIdUpdate()** - Registers listeners for dialog ID changes
- **setDialogId()** - Updates current dialog ID and notifies listeners
- **Token Integration** - Automatic token refresh and API URL updates via tokenService

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize service with optional debug mode
const chatService = new ChatApiService(true)

// Listen for dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID updated:', dialogId)
})

// Create a new dialog
const dialogId = await chatService.createDialog()

// Send a message to the dialog
await chatService.sendMessage({
  dialogId,
  content: 'Hello from the client!',
  chatType: 'CLIENT_CHAT'
})

// Get current dialog ID
const currentDialog = chatService.getDialogId()

// Reset and cleanup
chatService.reset()
chatService.destroy()
unsubscribe()
```

The service handles authentication automatically through tokenService integration and provides comprehensive error handling with optional debug logging for development environments.
