A service class that handles chat dialog creation and message sending operations with the Flamingo chat API, managing dialog state and authentication tokens.

## Key Components

- **ChatApiService** - Main service class for chat operations
- **createDialog()** - Creates new chat dialogs and returns dialog ID
- **sendMessage()** - Sends messages to existing chat dialogs
- **onDialogIdUpdate()** - Subscribes to dialog ID changes
- **setDialogId()** - Updates current dialog ID and notifies listeners
- **getHeaders()** - Generates authenticated request headers
- **destroy()** - Cleanup method for token service subscriptions

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize the service with optional debug mode
const chatService = new ChatApiService(true)

// Create a new dialog
const dialogId = await chatService.createDialog()
console.log('Created dialog:', dialogId)

// Send a message
await chatService.sendMessage({
  dialogId: dialogId,
  content: 'Hello, how can you help me?',
  chatType: 'CLIENT_CHAT'
})

// Listen for dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((newDialogId) => {
  console.log('Dialog ID updated:', newDialogId)
})

// Cleanup when done
unsubscribe()
chatService.destroy()
```

The service automatically handles token management through the `tokenService` dependency and provides error handling with optional debug logging for API operations.
