A service class that manages chat dialog creation and message sending operations with authentication and real-time token management.

## Key Components

- **ChatApiService** - Main service class for chat operations
- **createDialog()** - Creates new chat dialogs and returns dialog ID
- **sendMessage()** - Sends messages to specific chat dialogs
- **onDialogIdUpdate()** - Subscribes to dialog ID changes
- **setDialogId()** - Updates current dialog ID and notifies listeners
- **Token Management** - Automatic token refresh and API URL updates via tokenService integration

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize service with optional debug mode
const chatService = new ChatApiService(true)

// Subscribe to dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID changed:', dialogId)
})

// Create a new chat dialog
const dialogId = await chatService.createDialog()
console.log('Created dialog:', dialogId)

// Send a message
await chatService.sendMessage({
  dialogId,
  content: 'Hello, how can I help you?',
  chatType: 'CLIENT_CHAT'
})

// Clean up when done
unsubscribe()
chatService.destroy()
```

The service automatically handles authentication tokens, provides error handling with debug information, and maintains dialog state with reactive updates to subscribers.
