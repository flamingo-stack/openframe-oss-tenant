Manages HTTP communication with the Flamingo chat API, handling dialog lifecycle (create, message, stop) with token-based authentication and reactive dialog ID state.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `ChatApiService` | `class` | Core service for chat API interactions |
| `createDialog()` | `method` | Creates a new chat dialog, stores and broadcasts the returned ID |
| `sendMessage()` | `method` | Posts a message to an existing dialog |
| `stopGeneration()` | `method` | Halts active AI generation for a dialog |
| `onDialogIdUpdate()` | `method` | Subscribes to dialog ID changes, returns unsubscribe function |
| `setDialogId()` | `method` | Manually sets dialog ID and notifies all listeners |
| `destroy()` | `method` | Cleans up token and API URL subscriptions |

## Usage Example

```typescript
import { ChatApiService } from './chatApiService';

const chatApi = new ChatApiService(/* debug */ true);

// Subscribe to dialog ID changes
const unsubscribe = chatApi.onDialogIdUpdate((dialogId) => {
  console.log('Active dialog:', dialogId);
});

// Start a conversation
const dialogId = await chatApi.createDialog();

// Send a message
await chatApi.sendMessage({
  dialogId,
  content: 'How do I reset a user password?',
  chatType: 'CLIENT_CHAT',
});

// Stop AI generation mid-response
await chatApi.stopGeneration({ dialogId, chatType: 'CLIENT_CHAT' });

// Cleanup
unsubscribe();
chatApi.destroy();
```

## Notes

- Depends on `tokenService` for Bearer token injection and base URL resolution; calls `ensureTokenReady()` before every request.
- Dialog ID state is observable via `onDialogIdUpdate()` — the callback fires immediately with the current value on subscription.
- Debug mode enriches thrown errors with URL and dialog ID context for easier troubleshooting.
