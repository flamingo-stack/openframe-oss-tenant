A service class that handles chat API operations including dialog management and message sending, with built-in token management and debug capabilities.

## Key Components

- **ChatApiService**: Main service class for chat operations
- **createDialog()**: Creates a new chat dialog and returns the dialog ID
- **sendMessage()**: Sends messages to a specific dialog
- **onDialogIdUpdate()**: Subscribe to dialog ID changes with callback pattern
- **setDialogId()**: Updates the current dialog ID and notifies listeners
- **Token Integration**: Automatically handles authentication via tokenService
- **Debug Mode**: Optional logging for development and troubleshooting

## Usage Example

```typescript
import { ChatApiService } from './chatApiService'

// Initialize service with debug mode
const chatService = new ChatApiService(true)

// Subscribe to dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID updated:', dialogId)
})

// Create a new dialog
const dialogId = await chatService.createDialog()

// Send a message
await chatService.sendMessage({
  dialogId,
  content: 'Hello, how can I help?',
  chatType: 'CLIENT_CHAT'
})

// Clean up when done
unsubscribe()
chatService.destroy()
```

The service automatically manages authentication tokens and API base URLs through the tokenService integration, making it easy to perform chat operations without manual token handling.
