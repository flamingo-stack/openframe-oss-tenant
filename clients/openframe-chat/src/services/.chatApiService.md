A service class for managing chat API interactions, including dialog creation, message sending, and state management with token-based authentication.

## Key Components

- **ChatApiService** - Main service class for chat operations
- **createDialog()** - Creates a new chat dialog and returns the dialog ID
- **sendMessage()** - Sends messages to existing dialogs with specified chat types
- **onDialogIdUpdate()** - Subscribes to dialog ID changes with callback pattern
- **setDialogId()** - Updates current dialog ID and notifies listeners
- **getHeaders()** - Builds authenticated request headers using token service
- **destroy()** - Cleanup method for unsubscribing from token service listeners

## Usage Example

```typescript
// Initialize the chat service
const chatService = new ChatApiService(true) // Enable debug mode

// Subscribe to dialog ID changes
const unsubscribe = chatService.onDialogIdUpdate((dialogId) => {
  console.log('Dialog ID updated:', dialogId)
})

// Create a new dialog
const dialogId = await chatService.createDialog()

// Send a message to the dialog
await chatService.sendMessage({
  dialogId,
  content: 'Hello, how can I help?',
  chatType: 'CLIENT_CHAT'
})

// Get current dialog ID
const currentDialog = chatService.getDialogId()

// Cleanup when done
unsubscribe()
chatService.destroy()
```

The service integrates with `tokenService` for authentication and provides event-driven dialog state management with proper error handling and debug logging capabilities.
