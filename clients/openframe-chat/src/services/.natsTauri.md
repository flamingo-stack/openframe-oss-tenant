Tauri-side NATS bridge client that owns a single `Channel<NatsEvent>` for the app lifetime, fanning out to React subscribers via rAF-coalesced event batching. Delegates the actual NATS WebSocket connection and JetStream/OrderedConsumer management to the Rust side (`nats_bridge.rs`).

## Key Components

### Types

| Type | Description |
|---|---|
| `ConnectionState` | Union of `'connecting' \| 'connected' \| 'disconnected'` |
| `NatsStatus` | Connection state + reconnect counter |
| `NatsEvent` | Single JetStream chunk with `dialogId`, `streamSeq`, and `payload` |

### `NatsBridgeClient` (class)

Internal singleton class. Key behaviors:

- **`init()`** — Idempotent initialization; registers Tauri event listeners (`nats:status`, `nats:subscribed`), snapshots current status via `nats_status` invoke, and wires the `Channel<NatsEvent>` for stream delivery.
- **`receive()`** — Buffers incoming events and flushes via `requestAnimationFrame` + 250 ms `setTimeout` fallback, collapsing chunk bursts into a single React update cycle.
- **`enqueueDialogOp()`** — Serializes `subscribeDialog`/`unsubscribeDialog` invocations to prevent race conditions where Rust executes subscribe/unsubscribe in inverted order.
- **`subscribeDialog(dialogId, optStartSeq)`** / **`unsubscribeDialog(dialogId)`** — Queued wrappers around `nats_subscribe_dialog` / `nats_unsubscribe_dialog` Tauri commands.

### Singleton Export

```typescript
export const natsBridge = new NatsBridgeClient();
```

### React Hooks

| Hook | Purpose |
|---|---|
| `useTauriBridgeLiveness()` | Returns `{ isConnected, reconnectionCount }` from live status updates |
| `useNatsNotificationsEnabled(enabled)` | Pushes OS notification feature flag to Rust; no-op outside Tauri |
| `useTauriDialogSubscription(opts)` | Full lifecycle hook for one dialog: subscribe, deduplicate by `streamSeq`, pipe events to `onEvent`, signal readiness via `onSubscribed`. Returns `{ isSubscribed }` |

## Usage Example

```typescript
// Connection liveness
function StatusBar() {
  const { isConnected, reconnectionCount } = useTauriBridgeLiveness();
  return <span>{isConnected ? 'Online' : `Reconnecting (${reconnectionCount})`}</span>;
}

// Per-dialog JetStream subscription
function ChatPane({ dialogId, startSeq }: { dialogId: string; startSeq: number }) {
  const { isSubscribed } = useTauriDialogSubscription({
    enabled: true,
    dialogId,
    optStartSeq: startSeq,
    onEvent: chunk => console.log('chunk', chunk),
    onSubscribed: () => console.log('consumer ready'),
  });
  return <div>{isSubscribed ? 'Live' : 'Connecting…'}</div>;
}
```

> **Note:** All hooks and bridge methods are no-ops when `isTauri` is `false`, allowing the same components to run in the Vite browser dev environment without modification.
