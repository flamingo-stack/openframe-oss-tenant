Manages authentication token and API base URL lifecycle in a Tauri desktop application, bridging Rust backend events with frontend subscribers via a singleton service.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `tokenService` | `TokenService` (singleton) | Pre-instantiated service instance for app-wide use |
| `requestToken()` | `async method` | Fetches token from Rust via Tauri `get_token` command, returns cached value if available |
| `refreshToken()` | `async method` | Forces a fresh token fetch from Rust, bypassing cache — used before NATS reconnection |
| `getCurrentToken()` | `method` | Returns the currently cached token or `null` |
| `onTokenUpdate()` | `method` | Subscribes to token changes; fires immediately if token already exists |
| `initApiUrl()` | `async method` | Fetches server URL from Rust via `get_server_url` Tauri command |
| `getCurrentApiBaseUrl()` | `method` | Returns the normalized API base URL or `null` |
| `onApiUrlUpdate()` | `method` | Subscribes to API URL changes; fires immediately if URL already set |
| `ensureTokenReady()` | `async method` | Throws if neither token nor API URL can be resolved — use as a pre-flight guard |

## Usage Example

```typescript
import { tokenService } from './services/tokenService';

// Guard before making API calls
await tokenService.ensureTokenReady();

// One-time read
const token = tokenService.getCurrentToken();
const apiUrl = tokenService.getCurrentApiBaseUrl();

// Reactive subscription (returns unsubscribe fn)
const unsubscribe = tokenService.onTokenUpdate((token) => {
  console.log('Token updated:', token);
});

// Force refresh before reconnecting to NATS
const freshToken = await tokenService.refreshToken();

// Cleanup on component unmount
unsubscribe();
```

> **Environment overrides:** Set `VITE_TOKEN` and `VITE_SERVER_URL` in your `.env` file to seed the service during development without a running Rust backend.
