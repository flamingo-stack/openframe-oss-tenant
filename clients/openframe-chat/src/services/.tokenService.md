Manages authentication token and API base URL state for the Tauri desktop application, bridging the Rust backend and frontend via Tauri commands and events.

## Key Components

### `TokenService` (class)

A singleton service that handles token lifecycle and API URL resolution with in-flight request deduplication.

| Member | Description |
|---|---|
| `requestToken()` | Fetches token from Rust via `get_token` command; deduplicates concurrent calls |
| `refreshToken()` | Bypasses cache and re-fetches token from Rust; used before NATS reconnection |
| `getCurrentToken()` | Returns the cached token synchronously |
| `onTokenUpdate(callback)` | Subscribes to token changes; fires immediately if token already exists; returns unsubscribe function |
| `initApiUrl()` | Resolves API base URL from Rust via `get_server_url`; deduplicates concurrent calls |
| `getCurrentApiBaseUrl()` | Returns the cached API base URL synchronously |
| `onApiUrlUpdate(callback)` | Subscribes to API URL changes; fires immediately if URL already exists; returns unsubscribe function |
| `ensureTokenReady()` | Throws if token or API URL cannot be resolved; use as a preflight guard |

### `tokenService` (singleton export)

Pre-constructed instance shared across the application.

## Usage Example

```typescript
import { tokenService } from './services/tokenService';

// One-time read
const token = tokenService.getCurrentToken();

// Subscribe to token updates (e.g. in a React hook)
useEffect(() => {
  const unsubscribe = tokenService.onTokenUpdate((token) => {
    setAuthToken(token);
  });
  return unsubscribe;
}, []);

// Preflight guard before making authenticated requests
await tokenService.ensureTokenReady();

// Force a fresh token before reconnecting to NATS
const freshToken = await tokenService.refreshToken();
```

> **Environment overrides:** Set `VITE_TOKEN` and `VITE_SERVER_URL` to seed the service at startup without a Rust daemon — useful for local development.
