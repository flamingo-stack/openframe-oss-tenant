Fetches and caches the authenticated tenant's (MSP organization) profile from the chat GraphQL endpoint, powering the welcome screen's organization display.

## Key Components

- **`TenantInfo`** — Exported interface describing the tenant profile: `id`, `name`, `website`, and an optional `image` object with `imageUrl` and `hash`
- **`TenantInfoService`** — Private singleton class that manages a lazily-initialized, endpoint-aware `GraphQLClient`; recreates the client automatically when the API base URL changes
- **`tenantInfoService`** — Exported singleton instance for use throughout the application
- **`fetchTenantInfo()`** — Public method that waits for a valid token, then queries `/chat/graphql` for the tenant profile; returns `null` if no record exists

## Usage Example

```typescript
import { tenantInfoService, type TenantInfo } from './tenantInfoService';

// Fetch the current tenant's profile for display on the welcome screen
const tenant: TenantInfo | null = await tenantInfoService.fetchTenantInfo();

if (tenant) {
  console.log(tenant.name);           // "Acme IT Solutions"
  console.log(tenant.website);        // "https://acmeit.com"
  console.log(tenant.image?.imageUrl); // "https://cdn.example.com/logo.png"
} else {
  console.log('No tenant profile configured.');
}
```

> **Note:** The client caches the `GraphQLClient` instance and refreshes the `Authorization` header on every call, but recreates the client entirely if the API base URL changes — ensuring requests never hit a stale server.
