GraphQL service for fetching dialog messages and token usage data from the Flamingo chat API, handling client initialization, authentication, and paginated message retrieval.

## Key Components

### `DialogGraphQlService` (class)
The main service class wrapping a `GraphQLClient` instance with lazy initialization and Bearer token authentication via `tokenService`.

| Method | Description |
|--------|-------------|
| `initializeClient()` | Lazily creates/reuses a `GraphQLClient` pointed at `{baseUrl}/chat/graphql`, refreshing auth headers on each call |
| `request<T>()` | Generic GraphQL request wrapper |
| `getDialogMessagesPage()` | Fetches a paginated, cursor-based page of `CLIENT_CHAT` messages, optionally including thinking data |
| `getDialogTokenUsage()` | Fetches token consumption metrics for a dialog, filtered to the `CLIENT_CHAT` type |
| `dispose()` | Tears down the client instance and clears the cached endpoint |

### Exported Types

| Type | Description |
|------|-------------|
| `DialogTokenUsage` | Input/output/total/context token counts for a dialog |
| `Message` | Extends `HistoricalMessage` with `dialogMode` and `lastChunkStreamSeq` |
| `MessagesConnection` | Relay-style paginated response with `edges` and `pageInfo` |
| `MessageEdge` / `PageInfo` | Standard cursor-pagination types |

### `dialogGraphQlService` (singleton)
Pre-instantiated export for application-wide use.

## Usage Example

```typescript
import { dialogGraphQlService } from './dialogGraphQLService';

// Fetch the first page of messages for a dialog
const connection = await dialogGraphQlService.getDialogMessagesPage(
  'dialog-123',
  null,   // no cursor = first page
  50,
  { includeThinking: true },
);

if (connection) {
  for (const { node } of connection.edges) {
    console.log(node.messageData);
  }

  if (connection.pageInfo.hasNextPage) {
    const nextPage = await dialogGraphQlService.getDialogMessagesPage(
      'dialog-123',
      connection.pageInfo.endCursor,
    );
  }
}

// Fetch token usage
const usage = await dialogGraphQlService.getDialogTokenUsage('dialog-123');
console.log(`Total tokens used: ${usage?.totalTokensSize}`);

// Cleanup when done
dialogGraphQlService.dispose();
```
