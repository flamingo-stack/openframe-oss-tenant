A GraphQL service that manages dialog and message data for Flamingo's chat system, providing methods to fetch resumable dialogs and their associated messages with pagination support.

## Key Components

- **DialogGraphQLService**: Main service class that handles GraphQL queries for dialogs and messages
- **ResumableDialog**: Interface for dialog metadata including status, ratings, and timestamps
- **Message/MessageData**: Extended message interfaces supporting various message types (text, tool execution, approval requests)
- **MessagesConnection**: Paginated message response with cursor-based pagination
- **GET_RESUMABLE_DIALOG_QUERY**: GraphQL query to fetch current resumable dialog
- **GET_DIALOG_MESSAGES_QUERY**: GraphQL query to fetch paginated messages with tool execution support

## Usage Example

```typescript
import { dialogGraphQLService } from './dialogGraphQLService'

// Get the current resumable dialog
const dialog = await dialogGraphQLService.getResumableDialog()
if (dialog) {
  console.log(`Dialog: ${dialog.title} (${dialog.status})`)
  
  // Fetch all messages for the dialog
  const messages = await dialogGraphQLService.getDialogMessages(dialog.id)
  if (messages) {
    messages.edges.forEach(edge => {
      const message = edge.node
      console.log(`${message.owner.type}: ${message.messageData.type}`)
      
      // Handle different message types
      if (message.messageData.type === 'TEXT') {
        console.log(message.messageData.text)
      } else if (message.messageData.type === 'EXECUTING_TOOL') {
        console.log(`Executing: ${message.messageData.toolFunction}`)
      }
    })
  }
}

// Clean up when done
dialogGraphQLService.dispose()
```

The service automatically handles authentication tokens, API endpoint configuration, and provides comprehensive error handling for GraphQL operations.
