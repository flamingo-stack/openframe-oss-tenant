GraphQL service for managing dialog data and message retrieval in the OpenFrame frontend, providing typed interfaces for chat dialogs and message pagination.

## Key Components

### Interfaces
- **`ResumableDialog`** - Dialog metadata with status, timestamps, and rating information
- **`Message`** - Extended message interface with dialog mode support
- **`MessagesConnection`** - Paginated message collection with cursor-based navigation
- **`MessageEdge`** / **`PageInfo`** - GraphQL cursor pagination interfaces

### DialogGraphQLService Class
- **`getResumableDialog()`** - Fetches the current resumable dialog with metadata
- **`getDialogMessages()`** - Retrieves paginated messages for a dialog with automatic pagination
- **`initializeClient()`** - Sets up GraphQL client with authentication headers
- **`dispose()`** - Cleanup method for service instance

### GraphQL Queries
- **`GET_RESUMABLE_DIALOG_QUERY`** - Query for dialog metadata and rating information
- **`GET_DIALOG_MESSAGES_QUERY`** - Comprehensive message query supporting multiple message types (text, tool execution, approvals, errors)

## Usage Example

```typescript
import { dialogGraphQLService } from './dialogGraphQLService'

// Get current resumable dialog
const dialog = await dialogGraphQLService.getResumableDialog()
if (dialog) {
  console.log(`Dialog: ${dialog.title} (${dialog.status})`)
}

// Fetch all messages for a dialog
const messages = await dialogGraphQLService.getDialogMessages('dialog-id-123')
if (messages) {
  messages.edges.forEach(edge => {
    const message = edge.node
    console.log(`${message.owner.type}: ${message.messageData}`)
  })
}

// Cleanup when done
dialogGraphQLService.dispose()
```

The service automatically handles authentication through `tokenService` integration and provides comprehensive error handling for GraphQL operations.
