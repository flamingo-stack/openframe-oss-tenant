A GraphQL service for managing dialog and message operations in the Flamingo OpenFrame platform, providing methods to fetch resumable dialogs and their associated messages with pagination support.

## Key Components

- **DialogGraphQLService**: Main service class that handles GraphQL client initialization and request management
- **ResumableDialog**: Interface for dialog metadata including status, timestamps, and ratings
- **Message/MessageData**: Extended message interfaces with dialog mode support
- **MessagesConnection**: Paginated message collection with cursor-based navigation
- **GET_RESUMABLE_DIALOG_QUERY**: GraphQL query for fetching dialog information
- **GET_DIALOG_MESSAGES_QUERY**: GraphQL query for retrieving paginated messages

## Usage Example

```typescript
import { dialogGraphQLService } from './dialogGraphQLService'

// Get the current resumable dialog
const dialog = await dialogGraphQLService.getResumableDialog()
if (dialog) {
  console.log(`Dialog: ${dialog.title}, Status: ${dialog.status}`)
}

// Fetch all messages for a dialog with pagination
const messages = await dialogGraphQLService.getDialogMessages(
  'dialog-123',
  null, // start cursor
  50    // limit per page
)

if (messages) {
  messages.edges.forEach(edge => {
    const message = edge.node
    console.log(`Message from ${message.owner.type}: ${message.messageData}`)
  })
}

// Clean up resources
dialogGraphQLService.dispose()
```

The service automatically handles authentication tokens, GraphQL client initialization, and provides error handling with fallback to null responses. It supports fetching complete message histories by automatically paginating through all available messages.
