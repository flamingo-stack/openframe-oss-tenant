A service class that handles GraphQL operations for dialog and message management in the Flamingo Stack OpenFrame platform, providing methods to fetch resumable dialogs and their associated messages with pagination support.

## Key Components

**Main Class:**
- `DialogGraphQLService` - Core service class with lazy-initialized GraphQL client

**Key Methods:**
- `getResumableDialog()` - Fetches the current resumable dialog with metadata
- `getDialogMessages()` - Retrieves paginated messages for a specific dialog with automatic pagination handling
- `initializeClient()` - Lazy initializes GraphQL client with authentication headers
- `dispose()` - Cleanup method for client resources

**Type Definitions:**
- `ResumableDialog` - Dialog metadata including status, timestamps, and rating
- `Message` - Extended message interface with dialog mode
- `MessagesConnection` - Paginated message results with cursor-based pagination
- `MessageData`, `DialogOwner` - Type aliases from OpenFrame core

**GraphQL Queries:**
- `GET_RESUMABLE_DIALOG_QUERY` - Fetches dialog metadata
- `GET_DIALOG_MESSAGES_QUERY` - Retrieves messages with support for various message types (text, tool execution, approvals, errors)

## Usage Example

```typescript
import { dialogGraphQLService } from './dialogGraphQLService'

// Fetch current resumable dialog
const dialog = await dialogGraphQLService.getResumableDialog()
if (dialog) {
  console.log(`Dialog: ${dialog.title} (${dialog.status})`)
  
  // Get all messages for the dialog
  const messages = await dialogGraphQLService.getDialogMessages(dialog.id)
  if (messages) {
    console.log(`Found ${messages.edges.length} messages`)
    
    // Process each message
    messages.edges.forEach(edge => {
      const message = edge.node
      console.log(`Message from ${message.owner.type}: ${message.messageData}`)
    })
  }
}

// Cleanup when done
dialogGraphQLService.dispose()
```

The service automatically handles authentication through the token service and includes error handling with fallback to null returns for failed operations.
