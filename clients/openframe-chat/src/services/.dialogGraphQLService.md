Service for managing GraphQL operations related to dialog conversations and messages in the Flamingo OpenFrame platform, handling authentication and pagination automatically.

## Key Components

- **DialogGraphQLService**: Main service class that manages GraphQL client initialization and API requests
- **ResumableDialog**: Interface for dialog metadata including status, timestamps, and ratings
- **Message/MessageData**: Extended message interfaces with dialog-specific properties
- **MessagesConnection**: Paginated message collection with cursor-based navigation
- **GraphQL Queries**: Pre-defined queries for fetching dialogs and messages with comprehensive message type support

## Usage Example

```typescript
import { dialogGraphQLService } from './dialogGraphQLService'

// Get current resumable dialog
const dialog = await dialogGraphQLService.getResumableDialog()
if (dialog) {
  console.log(`Dialog: ${dialog.title} (${dialog.status})`)
}

// Fetch all messages for a dialog with automatic pagination
const messages = await dialogGraphQLService.getDialogMessages('dialog-123')
if (messages) {
  messages.edges.forEach(edge => {
    const message = edge.node
    console.log(`${message.owner.type}: ${message.messageData.type}`)
  })
}

// Clean up resources
dialogGraphQLService.dispose()
```

The service automatically handles token refresh, client initialization, and fetches all paginated results in a single call. It supports various message types including text, tool executions, approval requests, and error messages.
