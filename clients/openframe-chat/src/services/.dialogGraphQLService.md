Service for managing GraphQL communication with dialog and message data endpoints, providing authenticated access to resumable dialogs and their associated message histories.

## Key Components

- **DialogGraphQLService**: Main service class handling GraphQL client initialization and authentication
- **ResumableDialog**: Interface defining dialog metadata including status, timestamps, and ratings
- **Message/MessageData**: Extended message interfaces with dialog-specific properties
- **MessagesConnection**: Paginated message collection with cursor-based navigation
- **GET_RESUMABLE_DIALOG_QUERY**: GraphQL query for fetching current resumable dialog
- **GET_DIALOG_MESSAGES_QUERY**: GraphQL query for retrieving paginated dialog messages

## Usage Example

```typescript
import { dialogGraphQLService } from './dialogGraphQLService'

// Get current resumable dialog
const dialog = await dialogGraphQLService.getResumableDialog()
if (dialog) {
  console.log(`Dialog: ${dialog.title} (Status: ${dialog.status})`)
  
  // Fetch all messages for the dialog
  const messages = await dialogGraphQLService.getDialogMessages(dialog.id)
  if (messages) {
    messages.edges.forEach(edge => {
      const message = edge.node
      console.log(`${message.owner.type}: ${message.messageData}`)
    })
  }
}

// Cleanup when done
dialogGraphQLService.dispose()
```

The service automatically handles token management, client initialization, and provides pagination support for large message sets. It integrates with the tokenService for authentication and supports various message types including text, tool execution, and approval workflows.
