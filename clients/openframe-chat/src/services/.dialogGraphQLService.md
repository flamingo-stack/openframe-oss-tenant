GraphQL service for fetching dialog messages and token usage from the Flamingo chat API, handling authentication via `tokenService` and pagination via cursor-based connections.

## Key Components

### Interfaces & Types

| Type | Description |
|------|-------------|
| `DialogTokenUsage` | Token consumption metrics (input, output, total, context sizes) |
| `Message` | Extends `HistoricalMessage` with `dialogMode` and stream sequence tracking |
| `MessagesConnection` | Cursor-based paginated result containing `MessageEdge[]` and `PageInfo` |
| `MessageEdge` | Wraps a `Message` node with its pagination cursor |
| `PageInfo` | Standard relay-style pagination metadata |

### `DialogGraphQlService` (class)

| Method | Description |
|--------|-------------|
| `getDialogMessagesPage()` | Fetches a paginated page of `CLIENT_CHAT` messages, sorted by `createdAt DESC`. Supports optional thinking data via `includeThinking` flag |
| `getDialogTokenUsage()` | Retrieves token usage stats for a dialog, filtered to the `CLIENT_CHAT` type entry |
| `dispose()` | Resets the internal GraphQL client and endpoint state |
| `initializeClient()` (private) | Lazily initializes `GraphQLClient` with Bearer token and API base URL from `tokenService` |

A singleton `dialogGraphQlService` instance is exported for shared use.

## Usage Example

```typescript
import { dialogGraphQlService } from './dialogGraphQLService';

// Fetch first page of messages
const connection = await dialogGraphQlService.getDialogMessagesPage(
  'dialog-123',
  null,   // no cursor = first page
  50,     // page size
  { includeThinking: true }
);

if (connection) {
  connection.edges.forEach(({ node }) => {
    console.log(node.dialogMode, node.messageData);
  });

  // Fetch next page using endCursor
  const nextPage = await dialogGraphQlService.getDialogMessagesPage(
    'dialog-123',
    connection.pageInfo.endCursor,
    50
  );
}

// Fetch token usage for a dialog
const usage = await dialogGraphQlService.getDialogTokenUsage('dialog-123');
console.log(`Total tokens used: ${usage?.totalTokensSize}`);

// Clean up client state
dialogGraphQlService.dispose();
```
