A GraphQL service client for managing dialog and message operations in the OpenFrame chat system, handling authentication, pagination, and various message types with automatic token management.

## Key Components

**Main Class:**
- `DialogGraphQLService` - Primary service class with GraphQL client management and authentication
- `dialogGraphQLService` - Singleton instance export

**Core Methods:**
- `getResumableDialog()` - Fetches current resumable dialog with status and rating
- `getDialogMessages()` - Retrieves all messages for a dialog with automatic pagination
- `initializeClient()` - Sets up authenticated GraphQL client with token service integration
- `dispose()` - Cleanup method for client disposal

**Type Definitions:**
- `ResumableDialog` - Dialog metadata with status tracking and rating
- `Message` - Extended message with dialog mode support
- `MessagesConnection` - GraphQL connection pattern for paginated messages
- `DialogOwner`, `MessageData` - Re-exported from core OpenFrame types

## Usage Example

```typescript
import { dialogGraphQLService } from './dialogGraphQLService'

// Get current resumable dialog
const dialog = await dialogGraphQLService.getResumableDialog()
if (dialog) {
  console.log(`Dialog: ${dialog.title} (${dialog.status})`)
}

// Fetch all messages for a dialog
const messages = await dialogGraphQLService.getDialogMessages(dialog.id)
if (messages) {
  messages.edges.forEach(edge => {
    const message = edge.node
    console.log(`${message.owner.type}: ${message.messageData}`)
  })
}

// Cleanup when done
dialogGraphQLService.dispose()
```

The service automatically handles authentication tokens, GraphQL endpoint configuration, and pagination for large message sets, making it simple to integrate chat functionality into OpenFrame applications.
