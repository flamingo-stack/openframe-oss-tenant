A GraphQL service for managing dialog operations in the Flamingo Stack, providing methods to fetch resumable dialogs and paginated message history with authentication handling.

## Key Components

**Main Class:**
- `DialogGraphQLService` - Primary service class with automatic GraphQL client initialization and token management

**Key Methods:**
- `getResumableDialog()` - Fetches the current resumable dialog with metadata
- `getDialogMessages()` - Retrieves paginated message history for a dialog with automatic pagination
- `initializeClient()` - Sets up GraphQL client with authentication headers
- `dispose()` - Cleanup method for client disposal

**Type Definitions:**
- `ResumableDialog` - Dialog metadata with status, ratings, and timestamps
- `Message` - Extended message interface with dialog mode
- `MessagesConnection` - GraphQL connection pattern for paginated messages
- `DialogOwner`, `MessageData` - Type aliases from OpenFrame core

## Usage Example

```typescript
import { dialogGraphQLService } from './dialogGraphQLService'

// Get current resumable dialog
const dialog = await dialogGraphQLService.getResumableDialog()
if (dialog) {
  console.log(`Dialog: ${dialog.title} (${dialog.status})`)
}

// Fetch all messages for a dialog
const messages = await dialogGraphQLService.getDialogMessages(dialog.id)
if (messages) {
  messages.edges.forEach(({ node }) => {
    console.log(`${node.owner.type}: ${node.messageData}`)
  })
}

// Cleanup when done
dialogGraphQLService.dispose()
```

The service automatically handles authentication via `tokenService` and implements cursor-based pagination to fetch complete message histories efficiently.
