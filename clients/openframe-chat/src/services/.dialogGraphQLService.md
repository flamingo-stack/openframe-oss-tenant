GraphQL service for fetching dialog messages and token usage data from the Flamingo chat API, handling authentication via `tokenService` and connection management.

## Key Components

### `DialogGraphQlService` (class)
The primary service class managing a lazy-initialized `GraphQLClient` instance.

| Method | Description |
|--------|-------------|
| `initializeClient()` | Lazily creates or refreshes the `GraphQLClient` with the current Bearer token and API base URL |
| `request<T>()` | Generic wrapper for executing GraphQL queries with typed responses |
| `getDialogMessagesPage()` | Fetches a paginated, cursor-based page of dialog messages filtered by `CLIENT_CHAT` type |
| `getDialogTokenUsage()` | Retrieves token consumption metrics (input, output, total, context) for a given dialog |
| `dispose()` | Clears the client and cached endpoint, useful for cleanup on logout or config changes |

### Exported Types

| Type | Description |
|------|-------------|
| `DialogTokenUsage` | Token consumption metrics for a dialog |
| `Message` | Extends `HistoricalMessage` with `dialogMode` and `lastChunkStreamSeq` |
| `MessagesConnection` | Paginated response containing `MessageEdge[]` and `PageInfo` |
| `MessageData` | Re-export of `CoreMessageData` from `openframe-frontend-core` |

### Singleton Export
`dialogGraphQlService` — pre-instantiated singleton for app-wide use.

## Usage Example

```typescript
import { dialogGraphQlService } from './dialogGraphQLService';

// Fetch first page of messages (with thinking blocks)
const connection = await dialogGraphQlService.getDialogMessagesPage(
  'dialog-123',
  null,          // no cursor = first page
  50,
  { includeThinking: true }
);

if (connection) {
  const messages = connection.edges.map(e => e.node);
  const { hasNextPage, endCursor } = connection.pageInfo;
}

// Fetch token usage for a dialog
const usage = await dialogGraphQlService.getDialogTokenUsage('dialog-123');
if (usage) {
  console.log(`Total tokens used: ${usage.totalTokensSize}`);
}

// Cleanup (e.g., on logout)
dialogGraphQlService.dispose();
```
