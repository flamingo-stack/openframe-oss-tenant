GraphQL service for managing dialog conversations and messages within the Flamingo OpenFrame platform. Provides a centralized interface for fetching resumable dialogs and their associated message history with automated token management and pagination.

## Key Components

- **DialogGraphQLService**: Main service class that handles GraphQL operations for dialog management
- **ResumableDialog**: Interface representing a dialog session with status tracking and rating information
- **Message/MessageData**: Extended message interfaces supporting various message types (text, tool execution, approvals, errors)
- **MessagesConnection**: Paginated message collection with cursor-based navigation
- **GraphQL Queries**: Pre-defined queries for fetching dialog data and messages

## Usage Example

```typescript
import { dialogGraphQLService } from './dialogGraphQLService'

// Get the current resumable dialog
const dialog = await dialogGraphQLService.getResumableDialog()
if (dialog) {
  console.log(`Dialog: ${dialog.title} (${dialog.status})`)
  
  // Fetch all messages for the dialog
  const messages = await dialogGraphQLService.getDialogMessages(dialog.id)
  if (messages) {
    messages.edges.forEach(edge => {
      const message = edge.node
      console.log(`${message.owner.type}: ${message.messageData}`)
    })
  }
}

// Clean up when done
dialogGraphQLService.dispose()
```

The service automatically handles authentication through the token service, implements automatic pagination for large message collections, and provides error handling with graceful fallbacks. It supports various message types including text messages, tool executions, approval workflows, and error notifications.
