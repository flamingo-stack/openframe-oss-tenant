A GraphQL service for managing dialog conversations and messages in the Flamingo Stack, providing authenticated access to resumable dialogs and their message history with automatic pagination.

## Key Components

- **DialogGraphQLService** - Main service class handling GraphQL operations with automatic client initialization and token management
- **ResumableDialog** - Interface for dialog metadata including status, timestamps, and ratings
- **Message/MessageData** - Extended message types supporting various content types (text, tool execution, approvals, errors)
- **MessagesConnection** - Paginated message collection with cursor-based navigation
- **GraphQL Queries** - Pre-defined queries for fetching dialogs and messages with comprehensive field selection

## Usage Example

```typescript
import { dialogGraphQLService } from './dialogGraphQLService'

// Get current resumable dialog
const dialog = await dialogGraphQLService.getResumableDialog()
if (dialog) {
  console.log(`Dialog: ${dialog.title} (${dialog.status})`)
  
  // Fetch all messages for the dialog
  const messages = await dialogGraphQLService.getDialogMessages(dialog.id)
  if (messages) {
    messages.edges.forEach(edge => {
      const message = edge.node
      console.log(`${message.owner.type}: ${message.messageData.type}`)
    })
  }
}

// Clean up when done
dialogGraphQLService.dispose()
```

The service automatically handles authentication via tokenService, supports various message types (text, tool executions, approvals), and implements cursor-based pagination to retrieve complete message histories efficiently.
