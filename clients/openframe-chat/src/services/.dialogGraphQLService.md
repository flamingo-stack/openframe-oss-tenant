A GraphQL service for managing dialog conversations and messages in the Flamingo AI platform, providing authentication-aware access to chat data with automatic pagination and token management.

## Key Components

**Main Service Class:**
- `DialogGraphQLService` - Core service handling GraphQL operations with automatic client initialization and token management

**Key Methods:**
- `getResumableDialog()` - Fetches active dialog metadata including status, ratings, and timestamps
- `getDialogMessages()` - Retrieves all messages for a dialog with automatic pagination
- `initializeClient()` - Sets up GraphQL client with proper authentication headers
- `dispose()` - Cleanup method for resource management

**Type Definitions:**
- `ResumableDialog` - Dialog metadata with status tracking and rating information
- `Message` - Extended message interface with dialog mode support
- `MessagesConnection` - Paginated message results with cursor-based navigation
- `DialogOwner` & `MessageData` - Type aliases extending core message types

## Usage Example

```typescript
import { dialogGraphQLService } from './dialogGraphQLService'

// Get current active dialog
const dialog = await dialogGraphQLService.getResumableDialog()
if (dialog) {
  console.log(`Dialog: ${dialog.title} (${dialog.status})`)
  
  // Fetch all messages for the dialog
  const messages = await dialogGraphQLService.getDialogMessages(dialog.id)
  if (messages) {
    messages.edges.forEach(edge => {
      const message = edge.node
      console.log(`${message.owner.type}: ${message.messageData.type}`)
    })
  }
}

// Cleanup when done
dialogGraphQLService.dispose()
```

The service automatically handles authentication token refresh, GraphQL client initialization, and complete message pagination to retrieve all conversation history.
