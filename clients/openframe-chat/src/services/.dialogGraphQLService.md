GraphQL service for fetching dialog messages and token usage data from the OpenFrame chat API, using bearer token authentication managed by the `tokenService`.

## Key Components

### Interfaces

| Interface | Description |
|---|---|
| `DialogTokenUsage` | Token consumption metrics (input, output, total, context sizes) |
| `Message` | Extends `HistoricalMessage` with `dialogMode` and stream sequence info |
| `MessagesConnection` | Paginated message result with edges and `PageInfo` |
| `MessageEdge` | Cursor-based edge wrapping a `Message` node |

### Class: `DialogGraphQlService`

| Method | Description |
|---|---|
| `initializeClient()` | Lazily initializes the `GraphQLClient` with the bearer token and API base URL |
| `request<T>()` | Generic authenticated GraphQL request wrapper |
| `getDialogMessagesPage()` | Fetches a paginated page of `CLIENT_CHAT` messages for a given dialog, sorted by `createdAt DESC` |
| `getDialogTokenUsage()` | Retrieves token usage stats for a dialog, filtered to the `CLIENT_CHAT` type |
| `dispose()` | Clears the cached client and endpoint |

A singleton instance `dialogGraphQlService` is exported for shared use.

## Usage Example

```typescript
import { dialogGraphQlService } from './dialogGraphQLService';

// Fetch the first page of messages for a dialog
const connection = await dialogGraphQlService.getDialogMessagesPage('dialog-123', null, 25);
if (connection) {
  const messages = connection.edges.map(e => e.node);
  const { hasNextPage, endCursor } = connection.pageInfo;
  // Fetch next page using endCursor
}

// Fetch token usage metrics
const usage = await dialogGraphQlService.getDialogTokenUsage('dialog-123');
if (usage) {
  console.log(`Total tokens used: ${usage.totalTokensSize}`);
}

// Clean up when done (e.g., on component unmount)
dialogGraphQlService.dispose();
```

> **Note:** The client re-uses a cached `GraphQLClient` instance but refreshes the `Authorization` header on each call via `tokenService.getCurrentToken()`, ensuring tokens are always up to date without re-initializing the underlying HTTP client.
