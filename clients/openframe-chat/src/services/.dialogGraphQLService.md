Service for managing GraphQL queries related to dialog and message data in the Flamingo platform. Provides methods to fetch resumable dialogs and paginated message history with automatic authentication handling.

## Key Components

**Main Class:**
- `DialogGraphQLService` - Core service class with authentication-aware GraphQL client management

**Key Methods:**
- `getResumableDialog()` - Fetches the current resumable dialog with metadata
- `getDialogMessages()` - Retrieves paginated message history for a dialog
- `initializeClient()` - Sets up authenticated GraphQL client
- `dispose()` - Cleanup method for service disposal

**Type Definitions:**
- `ResumableDialog` - Dialog metadata with status and rating information
- `Message` - Extended message interface with dialog mode
- `MessagesConnection` - Paginated message response structure
- `MessageData`, `DialogOwner` - Type aliases from core frontend types

**GraphQL Queries:**
- `GET_RESUMABLE_DIALOG_QUERY` - Fetches dialog metadata
- `GET_DIALOG_MESSAGES_QUERY` - Fetches paginated messages with tool execution data

## Usage Example

```typescript
import { dialogGraphQLService } from './dialogGraphQLService'

// Get current resumable dialog
const dialog = await dialogGraphQLService.getResumableDialog()
if (dialog) {
  console.log(`Dialog: ${dialog.title}, Status: ${dialog.status}`)
}

// Fetch dialog messages with pagination
const messages = await dialogGraphQLService.getDialogMessages(
  'dialog-id-123',
  null, // cursor
  50    // limit
)

if (messages) {
  messages.edges.forEach(({ node: message }) => {
    console.log(`${message.owner.type}: ${message.messageData}`)
  })
}

// Cleanup when done
dialogGraphQLService.dispose()
```

The service automatically handles token refresh and GraphQL client initialization, making it easy to query dialog data throughout the application.
