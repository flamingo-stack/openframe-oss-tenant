Service class for managing GraphQL communication with dialog and messaging APIs, handling authentication and providing type-safe interfaces for chat conversations and resumable dialogs.

## Key Components

- **DialogGraphQLService**: Main service class with singleton pattern for GraphQL operations
- **ResumableDialog**: Interface for dialog metadata including status, ratings, and timestamps
- **Message/MessageData**: Type definitions extending core message types with dialog-specific fields
- **MessagesConnection**: Paginated message collection with cursor-based pagination
- **GraphQL Queries**: Pre-defined queries for fetching dialogs and messages

## Usage Example

```typescript
import { dialogGraphQLService } from './dialogGraphQLService'

// Get current resumable dialog
const dialog = await dialogGraphQLService.getResumableDialog()
if (dialog) {
  console.log(`Dialog: ${dialog.title} (${dialog.status})`)
  
  // Fetch all messages for the dialog
  const messages = await dialogGraphQLService.getDialogMessages(dialog.id)
  if (messages) {
    console.log(`Found ${messages.edges.length} messages`)
    
    // Process messages
    messages.edges.forEach(edge => {
      const message = edge.node
      console.log(`${message.owner.type}: ${message.messageData.type}`)
    })
  }
}

// Clean up when done
dialogGraphQLService.dispose()
```

The service automatically handles authentication via `tokenService`, manages GraphQL client initialization, and provides automatic pagination for message retrieval. All methods include error handling and return null on failure.
