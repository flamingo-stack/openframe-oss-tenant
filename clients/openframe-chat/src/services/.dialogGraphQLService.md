Service for managing dialog-related GraphQL operations in the OpenFrame platform, providing methods to fetch resumable dialogs and their associated messages with pagination support.

## Key Components

- **DialogGraphQLService** - Main service class with GraphQL client management
- **Type Definitions** - TypeScript interfaces for dialog data structures:
  - `ResumableDialog` - Dialog metadata with status and rating information
  - `Message` - Extended message interface with dialog mode
  - `MessagesConnection` - Paginated message collection with cursor-based navigation
- **GraphQL Queries** - Pre-defined queries for dialog and message retrieval
- **Service Instance** - Exported singleton `dialogGraphQLService` for application use

## Usage Example

```typescript
import { dialogGraphQLService } from './dialogGraphQLService'

// Get current resumable dialog
const dialog = await dialogGraphQLService.getResumableDialog()
if (dialog) {
  console.log(`Dialog: ${dialog.title} (${dialog.status})`)
  
  // Fetch all messages for the dialog
  const messages = await dialogGraphQLService.getDialogMessages(dialog.id)
  if (messages) {
    messages.edges.forEach(edge => {
      const message = edge.node
      console.log(`${message.owner.type}: ${message.messageData}`)
    })
  }
}

// Clean up resources when done
dialogGraphQLService.dispose()
```

The service automatically handles authentication tokens, GraphQL client initialization, and implements pagination to fetch complete message histories efficiently.
