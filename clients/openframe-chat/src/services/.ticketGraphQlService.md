GraphQL service for managing tickets and temporary attachments via the Flamingo chat API, handling client initialization, authentication, and cursor-based pagination.

## Key Components

### Types
| Type | Description |
|------|-------------|
| `TicketNode` | Full ticket object with id, status, labels, dialog, and timestamps |
| `TicketEdge` | Cursor + node pair for paginated results |
| `TicketsConnection` | Paginated ticket list with `edges` and `pageInfo` |
| `CreateTicketInput` | Input shape for ticket creation (title, description, attachments) |
| `TempAttachment` | Upload URL and ID for pre-upload file staging |
| `UserError` | Field-level error returned from GraphQL mutations |

### `TicketGraphQlService` Methods

| Method | Description |
|--------|-------------|
| `getTickets(params)` | Fetches a paginated, filterable list of tickets with optional status filter and search |
| `getTicket(id)` | Fetches a single ticket by ID |
| `createTicket(input)` | Creates a new ticket; throws on `userErrors` or missing response |
| `createTempAttachmentUploadUrl(fileName, contentType?)` | Generates a pre-signed upload URL for a temporary attachment |
| `deleteTempAttachment(id)` | Deletes a staged temporary attachment by ID |
| `dispose()` | Clears the cached GraphQL client and endpoint |

## Usage Example

```typescript
import { ticketGraphQlService } from './ticketGraphQlService';

// Fetch paginated open tickets
const connection = await ticketGraphQlService.getTickets({
  statuses: ['OPEN'],
  limit: 10,
  search: 'network issue',
});

if (connection) {
  for (const { node } of connection.edges) {
    console.log(`#${node.ticketNumber}: ${node.title} [${node.status}]`);
  }

  const { endCursor, hasNextPage } = connection.pageInfo;
  if (hasNextPage) {
    const nextPage = await ticketGraphQlService.getTickets({
      statuses: ['OPEN'],
      cursor: endCursor,
      limit: 10,
    });
  }
}

// Create a ticket with a staged attachment
const attachment = await ticketGraphQlService.createTempAttachmentUploadUrl(
  'screenshot.png',
  'image/png'
);
// Upload file to attachment.uploadUrl, then reference attachment.id
const ticket = await ticketGraphQlService.createTicket({
  title: 'VPN not connecting',
  description: 'See attached screenshot for error.',
  tempAttachmentIds: [attachment.id],
});
```

> The service lazily initializes a single `GraphQLClient` instance per endpoint, refreshing the `Authorization` header from `tokenService` on each call to handle token rotation.
