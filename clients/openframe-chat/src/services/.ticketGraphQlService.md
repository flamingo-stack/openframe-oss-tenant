GraphQL service for ticket operations in the Flamingo platform, providing a typed client that wraps ticket queries and mutations with JWT-authenticated requests.

## Key Components

**Types**
- `TicketNode` — Core ticket shape including `id`, `ticketNumber`, `title`, `status`, optional `statusDefinition` (lifecycle custom statuses), `labels`, `dialog`, and timestamps
- `TicketsConnection` — Paginated result wrapper with `edges` and `pageInfo` (cursor-based pagination)
- `CreateTicketInput` — Input for ticket creation with optional `tempAttachmentIds`
- `TempAttachment` — Pre-signed upload URL container for file attachments
- `UserError` — Server-side validation error with optional `field` and `message`

**Class: `TicketGraphQlService`**
- `initializeClient()` — Lazily constructs a `GraphQLClient` from `tokenService`, refreshing the Bearer token on every call
- `getTickets(params)` — Paginated ticket list with optional status filter, cursor, search, and `lifecycle` flag (conditionally includes `statusDefinition`)
- `getTicket(id, lifecycle?)` — Fetches a single ticket by ID
- `createTicket(input)` — Runs the `CreateTicket` mutation; throws on `userErrors`
- `createTempAttachmentUploadUrl(fileName, contentType?)` — Generates a pre-signed S3-style upload URL
- `deleteTempAttachment(id)` — Removes a pending attachment, returns `boolean` success
- `dispose()` — Clears the cached client instance

## Usage Example

```typescript
import { ticketGraphQlService } from './ticketGraphQlService';

// Fetch paginated open tickets with lifecycle status details
const connection = await ticketGraphQlService.getTickets({
  statuses: ['open'],
  limit: 10,
  lifecycle: true,
});

connection?.edges.forEach(({ node }) => {
  console.log(node.ticketNumber, node.statusDefinition?.name);
});

// Create a ticket with an attachment
const attachment = await ticketGraphQlService.createTempAttachmentUploadUrl(
  'screenshot.png',
  'image/png'
);
// ... upload file to attachment.uploadUrl ...

const ticket = await ticketGraphQlService.createTicket({
  title: 'Printer offline in Room 4B',
  description: 'HP LaserJet not responding since 09:00',
  tempAttachmentIds: [attachment.id],
});
```

> The `lifecycle` flag uses a GraphQL `@include` directive so `statusDefinition` is only fetched when the corresponding feature flag is active, avoiding unnecessary data transfer.
