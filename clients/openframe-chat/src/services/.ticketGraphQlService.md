GraphQL service for managing support tickets, providing CRUD operations and temporary attachment handling via the Flamingo chat GraphQL API.

## Key Components

**Types**
- `TicketNode` — core ticket shape (id, title, status, labels, dialog, timestamps)
- `TicketStatusDefinition` — lifecycle status metadata (id, name, color, kind)
- `TicketsConnection` — paginated edges + `pageInfo` for cursor-based navigation
- `CreateTicketInput` — input shape for ticket creation
- `TempAttachment` — temporary upload attachment (id + pre-signed `uploadUrl`)
- `UserError` — field-level error returned from mutations

**GraphQL Documents**
- `GET_TICKETS_QUERY` — paginated ticket list with optional status/search filters and `@include(if: $lifecycle)` for status definitions
- `GET_TICKET_QUERY` — single ticket by ID, same lifecycle flag support
- `CREATE_TICKET_MUTATION` — creates a ticket with optional temp attachment IDs
- `CREATE_TEMP_ATTACHMENT_UPLOAD_URL` — generates a pre-signed upload URL
- `DELETE_TEMP_ATTACHMENT` — removes a temporary attachment by ID

**Class: `TicketGraphQlService`**
- `getTickets(params)` — fetch paginated tickets with optional `statuses`, `cursor`, `limit`, `search`, and `lifecycle` flags
- `getTicket(id, lifecycle?)` — fetch a single ticket by ID
- `createTicket(input)` — create a ticket, throws on `userErrors`
- `createTempAttachmentUploadUrl(fileName, contentType?)` — get a pre-signed S3-style upload URL
- `deleteTempAttachment(id)` — delete a temp attachment, returns boolean success
- `dispose()` — clears the cached GraphQL client instance

## Usage Example

```typescript
import { ticketGraphQlService } from './ticketGraphQlService';

// Fetch open tickets with lifecycle status definitions
const connection = await ticketGraphQlService.getTickets({
  statuses: ['open'],
  limit: 10,
  lifecycle: true,
});

// Create a ticket with a pre-uploaded attachment
const attachment = await ticketGraphQlService.createTempAttachmentUploadUrl(
  'screenshot.png',
  'image/png'
);

// Upload file to the pre-signed URL, then create the ticket
const ticket = await ticketGraphQlService.createTicket({
  title: 'Printer offline on 2nd floor',
  description: 'Device unreachable since 09:00 UTC',
  tempAttachmentIds: [attachment.id],
});

// Fetch a single ticket
const detail = await ticketGraphQlService.getTicket(ticket.id, true);

// Cleanup
ticketGraphQlService.dispose();
```

> The client lazily initializes and reuses a single `GraphQLClient` instance per endpoint, refreshing the `Authorization` header from `tokenService` on each request.
