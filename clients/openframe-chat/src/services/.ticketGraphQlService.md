GraphQL service for managing support tickets, providing CRUD operations and temporary attachment handling via a lazily-initialized, token-authenticated `GraphQLClient`.

## Key Components

### Exported Types

| Type | Description |
|---|---|
| `TicketNode` | Full ticket shape including status, labels, dialog, and optional `statusDefinition` |
| `TicketsConnection` | Paginated result with `edges` (cursor + node) and `pageInfo` |
| `CreateTicketInput` | Payload for ticket creation (`title`, `description`, `tempAttachmentIds`) |
| `TempAttachment` | Upload token returned before a file is committed to a ticket |
| `UserError` | Server-side validation error with `field` and `message` |

### `TicketGraphQlService` Methods

| Method | Description |
|---|---|
| `getTickets(params)` | Fetches a cursor-paginated ticket list with optional status filter and search |
| `getTicket(id)` | Fetches a single ticket by ID; returns `null` on error |
| `createTicket(input)` | Creates a ticket; throws on `userErrors` or missing response |
| `createTempAttachmentUploadUrl(fileName, contentType?)` | Requests a pre-signed upload URL for a file attachment |
| `deleteTempAttachment(id)` | Removes a temporary attachment; returns `false` on error |
| `dispose()` | Resets the internal client (useful for logout/teardown) |

The client is initialized lazily on first request and re-authenticates on each call by refreshing the `Authorization` header from `tokenService`.

## Usage Example

```typescript
import { ticketGraphQlService } from './ticketGraphQlService';

// Paginated fetch with status filter
const connection = await ticketGraphQlService.getTickets({
  statuses: ['open', 'in_progress'],
  limit: 10,
  search: 'printer',
});

// Create a ticket with a pre-uploaded attachment
const { id: attachmentId } = await ticketGraphQlService.createTempAttachmentUploadUrl(
  'screenshot.png',
  'image/png'
);

const ticket = await ticketGraphQlService.createTicket({
  title: 'Printer not responding',
  description: 'See attached screenshot.',
  tempAttachmentIds: [attachmentId],
});

// Cleanup on logout
ticketGraphQlService.dispose();
```

> **Error handling:** `getTickets` intentionally propagates errors so React Query can retry, while `getTicket` and `deleteTempAttachment` swallow errors and return `null`/`false` for non-critical read/cleanup paths.
