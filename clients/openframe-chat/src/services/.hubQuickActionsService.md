Fetches and maps the OpenFrame default quick actions for the Fae client chat from the Product Hub's public agent config endpoint, proxied through the tenant gateway.

## Key Components

### Interfaces

- **`HubQuickActionDto`** — Raw DTO returned by the hub's `/api/ai-agents/:slug` endpoint, with `label` and `prompt` as the raw field names.
- **`HubQuickAction`** *(exported)* — Chat-facing shape mapping `label → name` and `prompt → instructions`, matching the tenant `AiQuickAction` contract.

### Constants

- **`FAE_AGENT_SLUG`** — Hardcoded slug `'fae'` identifying the Fae agent in the Product Hub.

### Functions

- **`fetchHubDefaultQuickActions()`** *(exported)* — Resolves the current auth token and base URL via `tokenService`, calls the hub proxy route, and returns the mapped `HubQuickAction[]`. Throws on auth/network failure; used only while `clientAiConfig.quickActionsIsDefault` is `true`.

## Usage Example

```typescript
import { fetchHubDefaultQuickActions } from './hubQuickActionsService';

// Called during client chat initialization to load default chip actions
try {
  const quickActions = await fetchHubDefaultQuickActions();
  // quickActions[0] => { id, name, instructions, iconName?, iconUrl?, iconProps? }
  renderChatChips(quickActions);
} catch (err) {
  // Falls back to bundled default actions if the hub proxy is unavailable
  console.warn('Hub quick actions unavailable, using fallback:', err);
  renderChatChips(BUNDLED_FALLBACK_ACTIONS);
}
```

## Notes

- Auth is handled transparently by `tokenService.ensureTokenReady()` before the fetch.
- The hub proxy (`/chat/content/**`) shares the same Bearer token and base URL as all other chat requests — no separate credentials required.
- A non-`2xx` response logs a `console.warn` intentionally to prevent silent degradation when chips fall back to the bundled set.
