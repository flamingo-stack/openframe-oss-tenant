A React hook that manages chat approval workflows for technician commands and escalated requests in the OpenFrame AI chat system.

## Key Components

- **State Management**: Tracks approval statuses, pending requests, and technician response states
- **API Integration**: Handles approve/reject HTTP requests to the chat API endpoints
- **Message Processing**: Updates approval request segments within chat message arrays
- **Escalation Handling**: Manages escalated approvals that require technician intervention
- **Cleanup Utilities**: Provides methods to clear approval state between sessions

## Usage Example

```typescript
import { useChatApprovals } from './hooks/useChatApprovals'

function ChatInterface() {
  const {
    approvalStatuses,
    pendingApprovalRequests,
    awaitingTechnicianResponse,
    handleApproveRequest,
    handleRejectRequest,
    updateApprovalStatusInMessages,
    clearApprovals
  } = useChatApprovals()

  const handleCommandApproval = async (requestId: string) => {
    await handleApproveRequest(requestId)
    console.log('Approval status:', approvalStatuses[requestId])
  }

  const processMessages = (messages: Message[]) => {
    return updateApprovalStatusInMessages(messages, 'req-123', 'approved')
  }

  return (
    <div>
      {awaitingTechnicianResponse && (
        <div>Waiting for technician response...</div>
      )}
      <button onClick={() => clearApprovals()}>
        Clear All Approvals
      </button>
    </div>
  )
}
```

The hook integrates with the tokenService for authentication and handles both direct approvals and escalated approval workflows that require technician intervention.
