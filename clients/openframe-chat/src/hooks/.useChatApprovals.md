A React hook that manages chat approval workflows, handling approval states, technician escalations, and API interactions for command approvals in the OpenFrame chat system.

## Key Components

**State Management:**
- `approvalStatuses` - Tracks approval states ('pending', 'approved', 'rejected') by request ID
- `pendingApprovalRequests` - Stores escalated approval data awaiting technician response
- `awaitingTechnicianResponse` - Boolean flag for technician escalation state

**Core Functions:**
- `handleApproveRequest` / `handleRejectRequest` - API calls to approve/reject approval requests
- `updateApprovalStatusInMessages` - Updates message segments with new approval statuses
- `handleEscalatedApproval` - Manages escalated approvals requiring technician intervention
- `handleEscalatedApprovalResult` - Processes technician approval decisions
- `clearApprovals` - Resets all approval state

**Interfaces:**
- `ApprovalData` - Structure for approval request data (command, explanation, type)
