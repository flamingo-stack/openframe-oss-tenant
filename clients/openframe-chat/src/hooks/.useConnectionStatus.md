Manages real-time NATS connection state and AI configuration loading for the chat interface, exposing connection status, server URL, and AI model configuration to consuming components.

## Key Components

**Types**
- `ConnectionStatus` — Union type: `'connected' | 'disconnected' | 'connecting'`
- `AiConfiguration` — Shape of the AI config fetched from `/chat/api/v1/ai-configuration`
- `UseConnectionStatusReturn` — Return interface with `status`, `serverUrl`, `aiConfiguration`, and `isFullyLoaded`

**Hook: `useConnectionStatus`**
- Initializes API URL and auth token via `tokenService` on mount
- Fetches AI configuration and triggers `supportedModelsService.loadSupportedModels()` once credentials are available
- Subscribes to NATS via `useNatsDialogSubscription` using config from `useChatNatsConfig`
- Derives `status` from NATS `isConnected` state and credential availability
- Sets `isFullyLoaded` only after both AI config and supported models are successfully loaded

## Usage Example

```typescript
import { useConnectionStatus } from './useConnectionStatus';

function ChatStatusBar() {
  const { status, serverUrl, aiConfiguration, isFullyLoaded } = useConnectionStatus();

  if (!isFullyLoaded) return <span>Initializing...</span>;

  return (
    <div>
      <span>Status: {status}</span>
      <span>Server: {serverUrl}</span>
      <span>Model: {aiConfiguration?.modelName}</span>
    </div>
  );
}
```

> **Note:** The hook gates NATS subscription (`enabled` flag) on both `apiBaseUrl` and `token` being present, preventing premature connection attempts during credential initialization.
