React hook that manages the NATS connection lifecycle, credential initialization, and AI configuration loading for the chat interface.

## Key Components

**Types**
- `ConnectionStatus` — Union type: `'connected' | 'disconnected' | 'connecting'`
- `AiConfiguration` — Shape of the active AI provider config returned from `/chat/api/v1/ai-configuration`
- `UseConnectionStatusReturn` — Return interface exposing `status`, `serverUrl`, `aiConfiguration`, and `isFullyLoaded`

**Hook: `useConnectionStatus`**

Orchestrates three async concerns in parallel via `useEffect`:

| Concern | Trigger | Action |
|---|---|---|
| Credential init | `apiBaseUrl` / `token` change | Calls `tokenService.initApiUrl()` and `requestToken()` |
| AI config fetch | `apiBaseUrl` + `token` available | GETs `/chat/api/v1/ai-configuration`, loads supported models |
| NATS subscription | Both credentials present | Subscribes via `useNatsDialogSubscription`, reflects connection state |

## Usage Example

```typescript
import { useConnectionStatus } from './useConnectionStatus';

function ChatStatusBar() {
  const { status, serverUrl, aiConfiguration, isFullyLoaded } = useConnectionStatus();

  if (!isFullyLoaded) return <Spinner />;

  return (
    <div>
      <span>Status: {status}</span>
      <span>Server: {serverUrl}</span>
      <span>Model: {aiConfiguration?.modelName}</span>
    </div>
  );
}
```

> **Note:** The hook derives `serverUrl` by stripping the `https?://` protocol prefix from `apiBaseUrl`, ensuring a clean display value suitable for UI labels.
