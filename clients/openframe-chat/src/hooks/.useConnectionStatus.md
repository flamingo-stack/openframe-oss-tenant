Manages the real-time connection status for the OpenFrame chat client, handling both Tauri (desktop) and browser (WebSocket) environments while coordinating credential initialization and model catalog loading.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `ConnectionStatus` | Type | Union type: `'connected' \| 'disconnected' \| 'connecting'` |
| `UseConnectionStatusReturn` | Interface | Return shape: `status`, `serverUrl`, `isFullyLoaded` |
| `useConnectionStatus` | Hook | Primary hook managing full connection lifecycle |

## Internal State

- **`status`** — Current connection state, defaults to `'connecting'`
- **`serverUrl`** — Cleaned server hostname (strips `http(s)://` prefix)
- **`isFullyLoaded`** — `true` once the AI model display-name catalog has settled (success or failure)

## Runtime Branching

| Environment | Connection Source |
|-------------|------------------|
| Tauri (desktop) | `useTauriBridgeLiveness` — Rust process owns the NATS connection |
| Browser (Vite) | `useNatsDialogSubscription` with `dialogId: null` keep-alive over WebSocket |

## Usage Example

```typescript
import { useConnectionStatus } from './useConnectionStatus';

function StatusBar() {
  const { status, serverUrl, isFullyLoaded } = useConnectionStatus();

  if (!isFullyLoaded) return <Skeleton />;

  return (
    <Footer>
      <StatusIndicator state={status} />
      <span>{serverUrl ?? 'Connecting…'}</span>
    </Footer>
  );
}
```

## Side Effects (in order)

1. **Credential init** — Calls `tokenService.initApiUrl()` and `tokenService.requestToken()` if not already set
2. **Server URL** — Derives display hostname from `apiBaseUrl`
3. **Model catalog** — Loads `supportedModelsService.loadSupportedModels()` once credentials are ready; sets `isFullyLoaded` regardless of outcome to prevent infinite skeleton states
