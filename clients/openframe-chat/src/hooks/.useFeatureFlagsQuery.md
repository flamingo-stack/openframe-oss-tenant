Provides a React Query hook for fetching and caching feature flags from the remote feature flags service, merging results with default values.

## Key Components

- **`featureFlagsQueryKey`** — Stable query key constant `['featureFlags']` used for cache invalidation and lookup.
- **`useFeatureFlagsQuery`** — Custom hook wrapping `useQuery` that fetches all defined feature flags, falls back to `DEFAULT_FEATURE_FLAGS` for missing entries, and caches results for 30 minutes.

## Usage Example

```typescript
import { useFeatureFlagsQuery } from './useFeatureFlagsQuery';

function App({ isAuthenticated }: { isAuthenticated: boolean }) {
  const { data: flags, isLoading, isError } = useFeatureFlagsQuery({
    enabled: isAuthenticated, // only fetch when user is ready
  });

  if (isLoading) return <Spinner />;
  if (isError) return <ErrorBanner />;

  return flags?.myFeature ? <NewFeature /> : <LegacyFeature />;
}
```

## Behavior Notes

| Option | Value | Effect |
|---|---|---|
| `staleTime` | 30 minutes | Prevents redundant refetches across navigation |
| `retry` | 1 | Single retry on failure before surfacing error |
| `refetchOnWindowFocus` | `false` | Avoids background refetch noise |
| `enabled` | caller-supplied | Defers fetch until prerequisites are met (e.g. auth) |

Unknown flag names returned by the service are silently ignored; only keys present in `DEFAULT_FEATURE_FLAGS` are applied, ensuring type safety against the `FeatureFlags` interface.
