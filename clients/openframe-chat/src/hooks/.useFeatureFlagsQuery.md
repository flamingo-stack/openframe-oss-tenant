React Query hook that fetches and normalizes feature flags from the feature flags service, merging remote values over a set of default flags.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `featureFlagsQueryKey` | `const` | Stable query key tuple `['featureFlags']` for cache lookups and invalidation |
| `useFeatureFlagsQuery` | `function` | React Query hook that fetches all known feature flags and returns a typed `FeatureFlags` map |

**Query behavior:**
- **`staleTime`** — 30 minutes; flags are treated as fresh and won't re-fetch unnecessarily
- **`retry`** — 1 retry on failure before throwing
- **`refetchOnWindowFocus`** — disabled to prevent noisy refetches
- **`enabled`** — controlled externally, allowing the caller to defer fetching (e.g. until authenticated)

## Usage Example

```typescript
import { useFeatureFlagsQuery } from './useFeatureFlagsQuery';

function App({ isAuthenticated }: { isAuthenticated: boolean }) {
  const { data: flags, isLoading, isError } = useFeatureFlagsQuery({
    enabled: isAuthenticated,
  });

  if (isLoading) return <Spinner />;
  if (isError) return <ErrorBanner />;

  return flags?.myFeature ? <NewFeature /> : <LegacyFeature />;
}
```

**Manual cache invalidation:**

```typescript
import { useQueryClient } from '@tanstack/react-query';
import { featureFlagsQueryKey } from './useFeatureFlagsQuery';

const queryClient = useQueryClient();
queryClient.invalidateQueries({ queryKey: featureFlagsQueryKey });
```

> If the service returns `null` or an empty response, the hook throws and React Query triggers the single configured retry before surfacing an error state. Unknown flag names returned by the API are silently ignored — only names present in `DEFAULT_FEATURE_FLAGS` are applied.
