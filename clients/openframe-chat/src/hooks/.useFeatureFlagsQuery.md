React Query hook for fetching and normalizing feature flags from the remote feature flags service, merging results with default values.

## Key Components

- **`featureFlagsQueryKey`** — Stable query key constant `['featureFlags']` for cache identification and invalidation
- **`useFeatureFlagsQuery`** — Custom hook that fetches all defined feature flags, falls back to `DEFAULT_FEATURE_FLAGS` for missing entries, and returns a normalized `FeatureFlags` object

## Behavior & Configuration

| Option | Value | Notes |
|---|---|---|
| `retry` | `1` | Single retry on failure |
| `staleTime` | `30 min` | Avoids redundant refetches |
| `refetchOnWindowFocus` | `false` | Prevents refetch on tab focus |
| `enabled` | param | Caller controls when query runs |

## Usage Example

```typescript
import { useFeatureFlagsQuery } from './useFeatureFlagsQuery';

function App({ isAuthenticated }: { isAuthenticated: boolean }) {
  const { data: flags, isLoading, isError } = useFeatureFlagsQuery({
    enabled: isAuthenticated, // only fetch when user is logged in
  });

  if (isLoading) return <Spinner />;
  if (isError) return <ErrorBanner />;

  return flags?.myFeature ? <NewComponent /> : <LegacyComponent />;
}
```

> **Note:** Unknown flag names returned by the service are silently ignored — only keys present in `DEFAULT_FEATURE_FLAGS` are applied, ensuring type safety against `FeatureFlags`.
