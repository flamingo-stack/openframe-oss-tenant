React Query hook that fetches and normalizes feature flags from the remote feature flags service, merging results with default values.

## Key Components

- **`featureFlagsQueryKey`** — Stable query key constant (`['featureFlags']`) for cache identification and invalidation.
- **`useFeatureFlagsQuery`** — Custom hook wrapping `useQuery` that fetches all flags defined in `FEATURE_FLAG_NAMES`, merges them over `DEFAULT_FEATURE_FLAGS`, and returns the typed `FeatureFlags` object.

## Behavior

| Option | Value | Notes |
|---|---|---|
| `retry` | `1` | Single retry on failure |
| `staleTime` | 30 min | Minimizes redundant network calls |
| `refetchOnWindowFocus` | `false` | Prevents refetch on tab switch |
| `enabled` | caller-controlled | Allows conditional/deferred fetching |

## Usage Example

```typescript
import { useFeatureFlagsQuery } from './useFeatureFlagsQuery';

function App({ isAuthenticated }: { isAuthenticated: boolean }) {
  const { data: flags, isLoading, isError } = useFeatureFlagsQuery({
    enabled: isAuthenticated, // only fetch when user is logged in
  });

  if (isLoading) return <Spinner />;
  if (isError) return <ErrorBanner />;

  return flags?.myFeature ? <NewComponent /> : <LegacyComponent />;
}
```

> Unknown flag names returned by the service are silently ignored; only keys present in `DEFAULT_FEATURE_FLAGS` are applied to the result object.
