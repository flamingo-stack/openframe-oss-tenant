Manages welcome screen visibility state by persisting completion status in `localStorage`, ensuring the onboarding screen is only shown once per user session.

## Key Components

- **`WELCOME_COMPLETED_KEY`** — localStorage key (`'openframe-chat-welcome-completed'`) used to persist welcome screen state
- **`useWelcomeScreen()`** — Custom React hook that returns welcome screen state and a completion handler

### Return Values

| Property | Type | Description |
|----------|------|-------------|
| `showWelcome` | `boolean` | `true` if the welcome screen should be displayed |
| `completeWelcome` | `() => void` | Marks the welcome screen as completed, hiding it permanently |

## Usage Example

```typescript
import { useWelcomeScreen } from './useWelcomeScreen';

function ChatLayout() {
  const { showWelcome, completeWelcome } = useWelcomeScreen();

  if (showWelcome) {
    return <WelcomeScreen onComplete={completeWelcome} />;
  }

  return <ChatInterface />;
}
```

> Once `completeWelcome()` is called, `showWelcome` will return `false` on all subsequent renders and page loads, as the state is persisted via `localStorage`.
