Manages the welcome screen visibility state for the OpenFrame chat interface, persisting the user's completion status in local storage.

## Key Components

- **`WELCOME_COMPLETED_KEY`** — Local storage key (`'openframe-chat-welcome-completed'`) used to persist welcome screen state across sessions
- **`useWelcomeScreen()`** — Custom hook that returns welcome screen visibility and a completion handler

### Return Values

| Property | Type | Description |
|----------|------|-------------|
| `showWelcome` | `boolean` | `true` if the user has not yet completed the welcome screen |
| `completeWelcome` | `() => void` | Callback that marks the welcome screen as completed |

## Usage Example

```typescript
import { useWelcomeScreen } from './useWelcomeScreen';

function ChatApp() {
  const { showWelcome, completeWelcome } = useWelcomeScreen();

  if (showWelcome) {
    return <WelcomeScreen onComplete={completeWelcome} />;
  }

  return <ChatInterface />;
}
```

> Once `completeWelcome` is called, `showWelcome` becomes `false` and remains `false` on subsequent sessions since the value is persisted via `useLocalStorage`.
