Manages the welcome screen visibility state for the OpenFrame chat interface, persisting completion status to localStorage so the screen is only shown once per user.

## Key Components

- **`WELCOME_COMPLETED_KEY`** — localStorage key `'openframe-chat-welcome-completed'` used to persist state across sessions
- **`showWelcome`** — boolean derived from stored state; `true` when the welcome screen should be displayed
- **`completeWelcome`** — memoized callback that marks the welcome screen as completed, hiding it on subsequent visits

## Usage Example

```typescript
import { useWelcomeScreen } from './useWelcomeScreen';

function ChatApp() {
  const { showWelcome, completeWelcome } = useWelcomeScreen();

  if (showWelcome) {
    return <WelcomeScreen onComplete={completeWelcome} />;
  }

  return <ChatInterface />;
}
```
