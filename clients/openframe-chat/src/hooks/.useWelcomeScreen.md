Manages welcome screen visibility state using local storage persistence, tracking whether the user has completed the onboarding flow.

## Key Components

- **`WELCOME_COMPLETED_KEY`** — Local storage key (`'openframe-chat-welcome-completed'`) used to persist completion state across sessions
- **`useWelcomeScreen()`** — Custom React hook that returns:
  - `showWelcome` — Boolean flag; `true` when the welcome screen should be displayed
  - `completeWelcome` — Memoized callback that marks the welcome flow as completed

## Usage Example

```typescript
import { useWelcomeScreen } from './useWelcomeScreen';

function App() {
  const { showWelcome, completeWelcome } = useWelcomeScreen();

  if (showWelcome) {
    return <WelcomeScreen onComplete={completeWelcome} />;
  }

  return <MainApp />;
}
```

Once `completeWelcome` is called, the state is persisted to local storage so the welcome screen will not reappear on subsequent visits or page refreshes.
