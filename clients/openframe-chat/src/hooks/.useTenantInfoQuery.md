Provides a React Query hook that fetches and caches the current tenant's profile (name, website, logo) from the `/chat/graphql` endpoint, scoping the cache key to the active API base URL to prevent stale cross-connection data.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `tenantInfoQueryKey` | Function | Generates a connection-scoped React Query cache key using the active `apiBaseUrl` |
| `useTenantInfoQuery` | Hook | Fetches `TenantInfo` (or `null` if no record exists), gating execution until a valid token and API URL are available |
| `ConnectionState` | Interface | Internal state shape tracking `isReady` and `apiBaseUrl` derived from `tokenService` |

## Behavior Notes

- **Connection awareness** — subscribes to both `tokenService.onTokenUpdate` and `tokenService.onApiUrlUpdate`; re-evaluates readiness on every change and triggers a refetch when the API URL changes (cache miss by design).
- **Cache key scoping** — `tenantInfoQueryKey(apiBaseUrl)` ensures tenant info from a previous server or identity is never served after a connection switch.
- **Query config** — `staleTime: 5 minutes`, `retry: 1`, `refetchOnWindowFocus: false`; returns `null` when no tenant record exists yet.

## Usage Example

```typescript
import { useTenantInfoQuery } from './hooks/useTenantInfoQuery';

function WelcomeScreen() {
  const { data: tenantInfo, isLoading } = useTenantInfoQuery({ enabled: true });

  if (isLoading) return <Spinner />;
  if (!tenantInfo) return <p>No tenant profile configured.</p>;

  return (
    <div>
      <img src={tenantInfo.logoUrl} alt={tenantInfo.name} />
      <h1>{tenantInfo.name}</h1>
      <a href={tenantInfo.website}>{tenantInfo.website}</a>
    </div>
  );
}
```

Pass `enabled: false` to defer fetching (e.g., while an auth flow is in progress).
