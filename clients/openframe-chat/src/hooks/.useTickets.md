React hook that fetches, paginates, and exposes IT support ticket data via GraphQL, with helpers for retrieving associated dialog IDs, creation sources, and detailed ticket information.

## Key Components

**`formatTimeAgo(dateString)`** — Internal utility that converts an ISO date string into a human-readable relative time string (e.g., `"3h ago"`, `"5d ago"`).

**`ticketToItemData(ticket)`** — Internal mapper that transforms a raw `TicketNode` from the GraphQL service into a `ChatTicketItemData` shape, including optional status label/color/kind from the `ticket-statuses` feature flag.

**`useTickets()`** — Main exported hook. Uses `@tanstack/react-query` infinite query to paginate ticket data with the following return values:

| Return | Type | Description |
|---|---|---|
| `tickets` | `ChatTicketItemData[]` | Flattened, memoized list of all loaded tickets |
| `isLoading` | `boolean` | Initial load state |
| `hasNextPage` | `boolean` | Whether more pages are available |
| `isFetchingNextPage` | `boolean` | Pagination in-progress state |
| `fetchNextPage` | `function` | Triggers loading the next page |
| `getDialogId` | `(ticketId) => string \| null` | Looks up associated dialog ID from ref cache |
| `getCreationSource` | `(ticketId) => string \| null` | Looks up ticket creation source from ref cache |
| `getTicketDetails` | `async (ticketId) => object \| null` | Fetches full ticket details on demand |

## Usage Example

```typescript
import { useTickets } from './useTickets';

function TicketList() {
  const {
    tickets,
    isLoading,
    hasNextPage,
    isFetchingNextPage,
    fetchNextPage,
    getDialogId,
    getTicketDetails,
  } = useTickets();

  if (isLoading) return <Spinner />;

  return (
    <>
      {tickets.map(ticket => (
        <TicketItem
          key={ticket.id}
          ticket={ticket}
          dialogId={getDialogId(ticket.id)}
          onExpand={() => getTicketDetails(ticket.id)}
        />
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()} disabled={isFetchingNextPage}>
          Load more
        </button>
      )}
    </>
  );
}
```

> Ticket data is polled every 60 seconds (`refetchInterval`) and cached for 60 seconds (`staleTime`). The `ticket-statuses` feature flag controls whether status label/color/kind fields are included via a GraphQL `@include` directive.
