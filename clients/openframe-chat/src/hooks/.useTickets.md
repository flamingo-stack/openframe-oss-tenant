React hook for fetching and managing paginated ticket data via GraphQL, with helpers for accessing associated dialog IDs, creation sources, and detailed ticket information.

## Key Components

### Internal Utilities

- **`formatTimeAgo(dateString)`** — Converts an ISO date string into a human-readable relative time label (e.g., `5m ago`, `2h ago`, `3d ago`).
- **`ticketToItemData(ticket)`** — Maps a `TicketNode` GraphQL response into a `ChatTicketItemData` UI model.
- **`TICKET_STATUSES`** — Constant array of filtered statuses: `ACTIVE`, `TECH_REQUIRED`, `ON_HOLD`, `RESOLVED`.

### `useTickets()` — Main Export

Infinite-scroll hook backed by `@tanstack/react-query`. Fetches pages of 20 tickets, auto-refreshes every 60 seconds, and maintains ref-based side maps for dialog and creation source lookups.

**Returns:**

| Property | Type | Description |
|---|---|---|
| `tickets` | `ChatTicketItemData[]` | Flattened, formatted ticket list across all pages |
| `isLoading` | `boolean` | Initial load state |
| `hasNextPage` | `boolean` | Whether more pages are available |
| `isFetchingNextPage` | `boolean` | Pagination in-progress indicator |
| `fetchNextPage` | `function` | Triggers next page fetch |
| `getDialogId` | `(ticketId) => string \| null` | Looks up associated dialog ID |
| `getCreationSource` | `(ticketId) => string \| null` | Looks up ticket creation source |
| `getTicketDetails` | `async (ticketId) => details \| null` | Fetches full ticket detail on demand |

## Usage Example

```typescript
import { useTickets } from './useTickets';

function TicketList() {
  const {
    tickets,
    isLoading,
    hasNextPage,
    isFetchingNextPage,
    fetchNextPage,
    getDialogId,
    getTicketDetails,
  } = useTickets();

  if (isLoading) return <Spinner />;

  return (
    <>
      {tickets.map(ticket => (
        <TicketItem
          key={ticket.id}
          ticket={ticket}
          dialogId={getDialogId(ticket.id)}
        />
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()} disabled={isFetchingNextPage}>
          {isFetchingNextPage ? 'Loading...' : 'Load more'}
        </button>
      )}
    </>
  );
}
```
