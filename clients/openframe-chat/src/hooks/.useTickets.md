React hook for fetching and managing paginated ticket data via GraphQL, with support for infinite scrolling, feature-flag-gated status definitions, and auxiliary lookups for dialog IDs and creation sources.

## Key Components

**`formatTimeAgo(dateString)`** — Internal utility that converts an ISO date string into a human-readable relative time label (e.g., `"5m ago"`, `"2h ago"`, `"3d ago"`).

**`ticketToItemData(ticket)`** — Maps a raw `TicketNode` GraphQL response to a `ChatTicketItemData` shape, merging optional `statusDefinition` fields (label, color, kind) when the `ticket-statuses` feature flag is active.

**`useTickets()`** — Primary exported hook. Uses `useInfiniteQuery` to paginate tickets filtered by `TICKET_STATUSES` (`ACTIVE`, `TECH_REQUIRED`, `ON_HOLD`, `RESOLVED`), polling every 60 seconds. Maintains two `useRef` maps as side-channel caches to track `dialogId` and `creationSource` per ticket without triggering re-renders.

### Returned Values

| Property | Type | Description |
|---|---|---|
| `tickets` | `ChatTicketItemData[]` | Flattened, memoized list across all pages |
| `isLoading` | `boolean` | Initial load state |
| `hasNextPage` | `boolean` | Whether more pages are available |
| `isFetchingNextPage` | `boolean` | Pagination fetch in progress |
| `fetchNextPage` | `function` | Trigger next page load |
| `getDialogId` | `(id) => string \| null` | Look up associated dialog ID |
| `getCreationSource` | `(id) => string \| null` | Look up ticket creation source |
| `getTicketDetails` | `async (id) => object \| null` | Fetch full single-ticket details |

## Usage Example

```typescript
function TicketList() {
  const {
    tickets,
    isLoading,
    hasNextPage,
    fetchNextPage,
    getDialogId,
    getTicketDetails,
  } = useTickets();

  if (isLoading) return <Spinner />;

  return (
    <>
      {tickets.map(ticket => (
        <TicketItem
          key={ticket.id}
          ticket={ticket}
          dialogId={getDialogId(ticket.id)}
        />
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>Load more</button>
      )}
    </>
  );
}
```
