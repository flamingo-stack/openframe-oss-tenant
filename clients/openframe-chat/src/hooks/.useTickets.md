React hook for fetching, paginating, and managing MSP ticket data via GraphQL with token-gated infinite scrolling and 60-second polling.

## Key Components

### `TicketDetails` Interface
Detailed ticket metadata including status, dialog state, category, and human-readable time.

### `formatTimeAgo(dateString)`
Internal utility that converts an ISO date string into a relative time label (`just now`, `5m ago`, `3h ago`, etc.).

### `ticketToItemData(ticket)`
Internal mapper that transforms a `TicketNode` GraphQL response into a `ChatTicketItemData` UI model.

### `useTickets()` Hook
The primary export. Uses `useInfiniteQuery` from TanStack Query to page through tickets with these statuses: `ACTIVE`, `TECH_REQUIRED`, `ON_HOLD`, `RESOLVED`. Polling interval and stale time are both 60 seconds. The query is gated behind token availability — it won't fire until `tokenService` resolves a valid auth token.

**Returns:**

| Property | Type | Description |
|---|---|---|
| `tickets` | `ChatTicketItemData[]` | Flattened, paginated ticket list |
| `isLoading` | `boolean` | Initial load state |
| `hasNextPage` | `boolean` | Whether more pages exist |
| `isFetchingNextPage` | `boolean` | Pagination in-flight |
| `fetchNextPage` | `function` | Load next page |
| `getDialogId` | `(ticketId) => string \| null` | Lookup cached dialog ID |
| `getCreationSource` | `(ticketId) => string \| null` | Lookup cached creation source |
| `getTicketDetails` | `(ticketId) => Promise<TicketDetails \| null>` | Fetch full ticket details on demand |

## Usage Example

```typescript
import { useTickets } from './useTickets';

function TicketList() {
  const {
    tickets,
    isLoading,
    hasNextPage,
    isFetchingNextPage,
    fetchNextPage,
    getDialogId,
    getTicketDetails,
  } = useTickets();

  if (isLoading) return <Spinner />;

  return (
    <>
      {tickets.map(ticket => (
        <TicketItem
          key={ticket.id}
          ticket={ticket}
          dialogId={getDialogId(ticket.id)}
        />
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()} disabled={isFetchingNextPage}>
          Load more
        </button>
      )}
    </>
  );
}
```
