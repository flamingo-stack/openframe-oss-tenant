Provides MSP organization branding data (name, website, logo) for display in the welcome screen and chat header, handling authenticated logo loading and cross-environment URL opening.

## Key Components

### `useMspOrganization()`
Main hook that aggregates tenant branding from the API and resolves the logo via an authenticated fetch.

**Returns:**

| Property | Type | Description |
|---|---|---|
| `name` | `string \| undefined` | Trimmed MSP organization name |
| `website` | `string \| undefined` | Trimmed MSP website URL |
| `logoUrl` | `string \| undefined` | Object URL for the Bearer-protected logo image |
| `isLoading` | `boolean` | `true` until both tenant info and logo blob resolve |
| `openWebsite` | `(() => void) \| undefined` | Opens the MSP website; `undefined` if no website is set |

### `toExternalHref(site: string): string` *(internal)*
Ensures bare hostnames (e.g. `www.techflow.com`) are prefixed with `https://` before use as an absolute URL.

## Usage Example

```typescript
import { useMspOrganization } from './hooks/useMspOrganization';

function MspOrganizationCard() {
  const { name, website, logoUrl, isLoading, openWebsite } = useMspOrganization();

  if (isLoading) return <Skeleton />;

  return (
    <div>
      {logoUrl && <img src={logoUrl} alt={`${name} logo`} />}
      <h2>{name}</h2>
      {openWebsite && (
        <button onClick={openWebsite}>Visit Website</button>
      )}
    </div>
  );
}
```

## Notes

- **Tauri vs browser:** `openWebsite` uses [`@tauri-apps/plugin-opener`](https://github.com/flamingo-stack/openframe-oss-tenant) in desktop builds (where `window.open` is suppressed by WKWebView) and falls back to `window.open` in the browser dev environment.
- **Loading state:** `isLoading` stays `true` until *both* the tenant info query and the authenticated logo fetch complete, preventing skeleton-to-content flicker.
- **Authenticated logo:** Logo bytes are fetched with a Bearer token via `useAuthenticatedImage`, matching the same pattern used for the assistant avatar.
