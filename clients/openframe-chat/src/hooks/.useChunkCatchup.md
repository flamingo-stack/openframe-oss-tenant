React hook that wraps the core `useChunkCatchup` functionality, injecting Flamingo's token service for authenticated chunk retrieval from dialog streams.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `useChunkCatchup` | Hook | Fetches missed NATS message chunks for a dialog, authenticated via `tokenService` |
| `UseChunkCatchupOptions` | Interface | Hook input: `dialogId` and `onChunkReceived` callback |
| `ChunkData` | Re-export | Shape of an individual streamed chunk |
| `NatsMessageType` | Re-export | NATS message type discriminator |
| `UseChunkCatchupReturn` | Re-export | Return type from the core hook |

## Behavior

- Calls `tokenService.ensureTokenReady()` before each fetch to guarantee a valid JWT is present
- Targets `CLIENT` chat type only (`CHAT_TYPE.CLIENT`)
- Supports optional `fromSequenceId` for partial catchup (resume from a known sequence position)
- Returns empty array on HTTP errors rather than throwing, logging the failure via `console.error`

## Usage Example

```typescript
import { useChunkCatchup } from './useChunkCatchup';

function DialogStream({ dialogId }: { dialogId: string }) {
  const { startCatchup, stopCatchup } = useChunkCatchup({
    dialogId,
    onChunkReceived: (chunk, messageType) => {
      console.log('Received chunk:', chunk, 'type:', messageType);
    },
  });

  useEffect(() => {
    startCatchup();
    return () => stopCatchup();
  }, [dialogId]);
}
```

> **Note:** `dialogId` accepts `null` to allow safe hook initialization before a dialog is available — the core hook handles the null guard internally.
