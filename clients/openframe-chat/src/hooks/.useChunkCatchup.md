React hook that wraps the core `useChunkCatchup` from `@flamingo-stack/openframe-frontend-core`, injecting authentication context (token + API base URL) into the chunk-fetching logic for a specific dialog.

## Key Components

- **`useChunkCatchup`** — Main exported hook. Accepts a `dialogId` and an `onChunkReceived` callback, returns a `UseChunkCatchupReturn` handle.
- **`fetchChunks`** — Internal `useCallback` that resolves auth credentials via `tokenService`, then fetches missed chunks from `/chat/api/v1/dialogs/{dialogId}/chunks`.
- **`tokenService`** — Ensures the token is ready before each request and provides the current bearer token and API base URL.
- **Re-exported types** — `ChunkData`, `NatsMessageType`, `UseChunkCatchupReturn` are re-exported for consumer convenience.

## Usage Example

```typescript
import { useChunkCatchup, type ChunkData, type NatsMessageType } from './useChunkCatchup';

function ChatPanel({ dialogId }: { dialogId: string }) {
  const { startCatchup, stopCatchup } = useChunkCatchup({
    dialogId,
    onChunkReceived: (chunk: ChunkData, messageType: NatsMessageType) => {
      console.log('Received chunk:', chunk, 'type:', messageType);
    },
  });

  useEffect(() => {
    startCatchup();
    return () => stopCatchup();
  }, [startCatchup, stopCatchup]);
}
```

> **Note:** Only `CHAT_TYPE.CLIENT` chunks are fetched. The hook throws if the token or API URL is unavailable at request time; failed HTTP responses log a warning and return an empty array rather than throwing.
