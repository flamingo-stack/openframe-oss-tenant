React hook that wraps the core `useChunkCatchup` functionality, injecting authentication credentials and API base URL from the local `tokenService` to fetch missed chat message chunks for a given dialog.

## Key Components

- **`useChunkCatchup`** — Main exported hook that manages chunk catchup for client-side chat dialogs
- **`fetchChunks`** — Internal async callback that authenticates and fetches missed `ChunkData` from the REST API endpoint `/chat/api/v1/dialogs/{dialogId}/chunks`
- **`tokenService`** — Used to resolve the Bearer token and API base URL before each fetch
- **Re-exported types** — `ChunkData`, `NatsMessageType`, `UseChunkCatchupReturn` for consumer convenience

## Usage Example

```typescript
import { useChunkCatchup } from './useChunkCatchup';
import type { ChunkData, NatsMessageType } from './useChunkCatchup';

function ChatComponent({ dialogId }: { dialogId: string }) {
  const { startCatchup, stopCatchup } = useChunkCatchup({
    dialogId,
    onChunkReceived: (chunk: ChunkData, messageType: NatsMessageType) => {
      console.log('Received missed chunk:', chunk, messageType);
    },
  });

  useEffect(() => {
    startCatchup();
    return () => stopCatchup();
  }, [dialogId]);
}
```

## Notes

- Only fetches chunks for `CHAT_TYPE.CLIENT` — server/agent chat types are excluded
- Returns `[]` gracefully on HTTP errors rather than throwing
- `fetchChunks` is memoized with `useCallback([], [])` so it is stable across renders; token resolution happens at call time via `tokenService.ensureTokenReady()`
