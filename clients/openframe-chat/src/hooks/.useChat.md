A React hook that provides complete chat functionality with real-time message streaming, approvals handling, and NATS WebSocket integration for AI conversations.

## Key Components

- **State Management**: Manages typing state, NATS streaming status, dialog IDs, error handling, and message history
- **Real-time Processing**: Integrates with NATS WebSocket subscriptions for live message streaming and chunk processing
- **Message Handling**: Provides `sendMessage` for user input and `clearMessages` for conversation reset
- **Approvals System**: Handles approval requests and escalations through integrated approval management
- **History Loading**: Supports resuming incomplete conversations with proper state restoration
- **API Integration**: Works with ChatApiService for dialog creation and message sending

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const {
    messages,
    isTyping,
    sendMessage,
    clearMessages,
    error,
    quickActions
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model info:', metadata.modelName, metadata.providerName)
    }
  })

  const handleSend = async (text: string) => {
    await sendMessage(text)
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>AI is typing...</div>}
      {error && <div className="error">{error}</div>}
      <button onClick={() => clearMessages()}>Clear Chat</button>
    </div>
  )
}
```

The hook automatically handles NATS subscription management, chunk catch-up for missed messages, and maintains conversation continuity across sessions.
