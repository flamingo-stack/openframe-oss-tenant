Orchestrates the real-time AI chat experience for the Fae client interface, managing message streaming via NATS/JetStream, approval workflows, dialog history, and incremental chunk processing.

## Key Components

**Core State**
- `isTyping` / `natsStreaming` — tracks active stream and typing indicator states
- `natsDialogId` — active dialog session identifier for NATS subscriptions
- `allMessages` — merged view of historical (React Query) and live streaming messages
- `incompleteState` / `enhancedInitialState` — reconstructed mid-stream state for resumed dialogs

**Key Functions**
- `findLatestPendingApprovalId(msgs)` — scans messages newest-to-oldest to locate the most recent pending approval or batch, used for optimistic cancellation
- `realtimeCallbacks` — memoized handler map wired to the chunk processor: `onStreamStart`, `onStreamEnd`, `onSegmentsUpdate`, `onApprovalResolved`, `onToolExecuted`, `onDirectMessage`, `onDialogClosed`, `onSystemMessage`, etc.

**Composed Hooks**
- `useChatMessages` — live in-session message state
- `useDialogMessages` — paginated historical messages via React Query
- `useChatApprovals` — approval request/reject/escalation lifecycle
- `useChatNatsConfig` — NATS connection parameters
- `useRealtimeChunkProcessor` — streaming chunk ingestion
- `useChunkCatchup` — seq-based replay for missed chunks on reconnect

## Usage Example

```typescript
const {
  messages,
  isTyping,
  sendMessage,
  resetChat,
  approvals,
} = useChat({
  useApi: true,
  useNats: false,
  onMetadataUpdate: ({ modelName, providerName, contextWindow }) => {
    console.log(`Model: ${modelName} (${providerName}), ctx: ${contextWindow}`);
  },
  onTokenUsage: (data) => console.log('Tokens used:', data),
  onDialogClosed: () => navigate('/home'),
});

// Send a user message
await sendMessage('How do I reset a user password?');
```

> **Note:** `useJetstream` is derived from the `ai-streaming-jetstream` feature flag at mount time and selects between JetStream and core NATS subscriptions for chunk delivery.
