A comprehensive React hook that manages real-time chat functionality with AI assistants, handling message state, NATS subscriptions, and dialog resumption capabilities.

## Key Components

- **Message Management**: Integrates `useChatMessages` and `useChatApprovals` for handling conversation flow and approval workflows
- **Real-time Communication**: Uses NATS WebSocket subscriptions for streaming responses with chunk processing and catchup mechanisms
- **API Integration**: Manages `ChatApiService` instances for sending messages and creating dialogs
- **State Management**: Tracks typing indicators, streaming status, errors, and dialog resumption state
- **Token Management**: Automatically handles authentication token updates and API base URL changes

## Usage Example

```typescript
import { useChat } from './hooks/useChat'

function ChatComponent() {
  const { 
    messages, 
    isTyping, 
    sendMessage, 
    clearMessages,
    resumeDialog,
    error 
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model:', metadata.modelName, 'Provider:', metadata.providerName)
    }
  })

  const handleSendMessage = async () => {
    await sendMessage("Hello, how can you help me today?")
  }

  const handleResumeChat = async () => {
    const success = await resumeDialog('dialog-123')
    if (!success) {
      console.error('Failed to resume dialog')
    }
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Assistant is typing...</div>}
      {error && <div>Error: {error}</div>}
    </div>
  )
}
```
