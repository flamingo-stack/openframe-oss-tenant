This React hook provides a complete chat interface implementation with real-time messaging capabilities for AI conversations. It manages chat state, message handling, and integrates with both API and NATS streaming services.

## Key Components

**Core State Management:**
- `isTyping` - Tracks typing indicator state
- `natsStreaming` - Real-time streaming status
- `natsDialogId` - Current dialog session ID
- `error` - Error state management
- `isLoadingHistory` - History loading state

**Service Integrations:**
- `ChatApiService` - HTTP API communication
- `tokenService` - Authentication token management
- `useNatsDialogSubscription` - Real-time message streaming
- `useRealtimeChunkProcessor` - Processes incoming message chunks
- `useChatMessages` - Message state management
- `useChatApprovals` - Handles approval workflows

**Main Functions:**
- `sendMessage(text: string)` - Sends user messages and handles responses
- `handleQuickAction(actionText: string)` - Triggers predefined quick actions
- `clearMessages()` - Clears conversation history

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const { 
    messages, 
    isTyping, 
    sendMessage, 
    handleQuickAction,
    quickActions,
    error 
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model info:', metadata.modelName, metadata.providerName)
    }
  })

  return (
    <div>
      <div>
        {messages.map(msg => (
          <div key={msg.id}>{msg.content}</div>
        ))}
        {isTyping && <div>AI is typing...</div>}
      </div>
      
      <button onClick={() => sendMessage('Hello!')}>
        Send Message
      </button>
      
      {quickActions.map(action => (
        <button key={action} onClick={() => handleQuickAction(action)}>
          {action}
        </button>
      ))}
      
      {error && <div>Error: {error}</div>}
    </div>
  )
}
```
