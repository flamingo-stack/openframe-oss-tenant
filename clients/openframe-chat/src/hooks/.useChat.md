React hook that manages chat functionality with real-time messaging via NATS, message history, and approval workflows. Provides a complete chat interface with typing indicators, error handling, and integration with various chat services.

## Key Components

- **Core State Management**: Handles typing indicators, streaming status, errors, and dialog state
- **Message Management**: Integrates with `useChatMessages` and `useChatApprovals` hooks
- **Real-time Processing**: Uses NATS subscription for live message streaming and chunk processing
- **API Integration**: Manages chat API service with token authentication
- **Chunk Catchup**: Handles message synchronization when reconnecting to dialogs
- **Quick Actions**: Supports predefined chat actions from configuration

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const {
    messages,
    isTyping,
    error,
    sendMessage,
    handleQuickAction,
    clearMessages
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model info:', metadata.modelName, metadata.providerName)
    }
  })

  const handleSubmit = async (text: string) => {
    await sendMessage(text)
  }

  return (
    <div>
      {/* Message list */}
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      
      {/* Typing indicator */}
      {isTyping && <div>Assistant is typing...</div>}
      
      {/* Error display */}
      {error && <div className="error">{error}</div>}
      
      {/* Quick actions */}
      <button onClick={() => handleQuickAction('Help me debug this issue')}>
        Debug Help
      </button>
    </div>
  )
}
```
