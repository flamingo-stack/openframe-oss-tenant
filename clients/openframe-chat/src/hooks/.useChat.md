A comprehensive React hook that manages chat functionality including message handling, real-time streaming, and approval workflows. This hook provides the core chat interface for the Flamingo OpenFrame platform, supporting both API-based and NATS-based real-time communication.

## Key Components

- **Chat State Management**: Core state for typing indicators, streaming status, and error handling
- **Message Processing**: Integration with message management and approval workflows
- **Real-time Communication**: NATS WebSocket subscription for live message streaming
- **Chunk Processing**: Real-time chunk processing with catchup functionality
- **API Integration**: Chat API service integration with authentication
- **Approval System**: Client approval handling for sensitive operations

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const { 
    sendMessage, 
    messages, 
    isTyping, 
    clearMessages,
    approvals,
    error 
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model:', metadata.modelName)
    }
  })

  const handleSubmit = (text: string) => {
    sendMessage(text)
  }

  const handleApproval = (requestId: string) => {
    approvals.handleApproveRequest(requestId)
  }

  return (
    <div>
      {messages.messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Fae is typing...</div>}
      {error && <div className="error">{error}</div>}
    </div>
  )
}
```
