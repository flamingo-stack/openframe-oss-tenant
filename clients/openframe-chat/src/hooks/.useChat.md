A React hook that manages chat functionality including message handling, real-time communication via NATS, and approval workflows with support for both API and mock modes.

## Key Components

### Core State Management
- **Message State**: Manages chat messages, typing indicators, and error states
- **NATS Integration**: Real-time message streaming and subscription management
- **Approval System**: Handles command approvals and escalated approval workflows
- **Token Management**: Automatic token refresh and API URL configuration

### Custom Hooks Integration
- `useChatMessages`: Message state and operations
- `useChatApprovals`: Approval request handling
- `useChunkCatchup`: Real-time chunk processing and catchup
- `useRealtimeChunkProcessor`: Processes incoming message segments
- `useNatsDialogSubscription`: NATS WebSocket subscription management

### Key Methods
- `sendMessage()`: Sends user messages and handles assistant responses
- `handleQuickAction()`: Executes predefined quick actions
- `clearMessages()`: Resets chat state

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const { 
    messages, 
    sendMessage, 
    isTyping, 
    error, 
    quickActions,
    handleQuickAction 
  } = useChat({
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model info:', metadata.modelName, metadata.providerName)
    }
  })

  const handleSubmit = async (text: string) => {
    await sendMessage(text)
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Fae is typing...</div>}
      {error && <div className="error">{error}</div>}
    </div>
  )
}
```

The hook automatically handles dialog creation, NATS subscriptions, chunk processing, and maintains real-time synchronization with the backend services.
