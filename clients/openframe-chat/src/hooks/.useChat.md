A React hook that manages AI chat functionality with real-time messaging, approvals, and dialog history. It integrates multiple services for token management, NATS streaming, and chat API communication.

## Key Components

**Core State Management:**
- `isTyping` - Indicates when AI is generating a response
- `natsStreaming` - Tracks real-time streaming status
- `natsDialogId` - Current dialog session identifier
- `error` - Error state for failed operations
- `token` / `apiBaseUrl` - Authentication and API configuration

**Integrated Hooks:**
- `useChatMessages` - Message state and operations
- `useChatApprovals` - Command approval workflow
- `useChunkCatchup` - Handles message synchronization
- `useRealtimeChunkProcessor` - Processes streaming message chunks
- `useNatsDialogSubscription` - Real-time WebSocket connection

**Key Functions:**
- `sendMessage(text)` - Sends user message and initiates AI response
- `handleQuickAction(actionText)` - Processes predefined quick actions
- `clearMessages()` - Resets chat history (implementation appears cut off)

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const { 
    messages, 
    isTyping, 
    error, 
    sendMessage, 
    handleQuickAction,
    quickActions 
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model:', metadata.modelName)
    }
  })

  const handleSubmit = async (text: string) => {
    await sendMessage(text)
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>AI is typing...</div>}
      {error && <div>Error: {error}</div>}
    </div>
  )
}
```

The hook manages the complete chat lifecycle including message history, real-time streaming, approval workflows, and error handling, providing a comprehensive interface for AI chat applications.
