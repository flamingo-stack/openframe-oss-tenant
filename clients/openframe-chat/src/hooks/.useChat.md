A React hook that manages real-time chat functionality with AI assistants, integrating WebSocket connections, message streaming, and approval workflows for the Flamingo platform.

## Key Components

**Main Hook:**
- `useChat(options)` - Core chat management with configurable API/NATS integration

**State Management:**
- Message history and real-time streaming
- User approval workflows for AI actions
- Connection status and error handling
- Dialog session management

**Core Dependencies:**
- `useChatMessages` - Message state management
- `useChatApprovals` - Approval workflow handling
- `useRealtimeChunkProcessor` - Streaming message processing
- `useNatsDialogSubscription` - WebSocket connection management
- `useChunkCatchup` - Message synchronization

**Key Features:**
- Real-time message streaming via NATS WebSocket
- Automatic message chunk processing and catchup
- Approval request handling for AI actions
- Dialog session persistence and resumption
- Debug mode support

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const { 
    messages, 
    sendMessage, 
    isTyping, 
    error,
    clearMessages,
    handleQuickAction 
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log(`Model: ${metadata.modelName}`)
    }
  })

  const handleSubmit = async (text: string) => {
    await sendMessage(text)
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Fae is typing...</div>}
      {error && <div>Error: {error}</div>}
    </div>
  )
}
```

The hook automatically handles WebSocket subscriptions, message streaming, approval workflows, and maintains chat state across dialog sessions.
