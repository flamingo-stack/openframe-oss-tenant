A React hook that provides comprehensive chat functionality with real-time messaging, NATS streaming, and message management for the Flamingo platform's AI chat interface.

## Key Components

- **Core State Management**: Handles typing indicators, streaming states, error handling, and chat configuration
- **Real-time Processing**: Integrates NATS WebSocket subscriptions for live message streaming and chunk processing
- **Message Management**: Manages chat history, user/assistant messages, and message segments with approval workflows
- **API Integration**: Connects to chat services for sending messages and creating dialog sessions
- **Chunk Catchup**: Handles message synchronization and buffering for resumed conversations
- **Approval System**: Manages client-side approvals for AI actions and escalated permissions

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const { 
    sendMessage, 
    messages, 
    isTyping, 
    error,
    handleQuickAction,
    clearMessages 
  } = useChat({
    useNats: true,
    useApi: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model:', metadata.modelName, 'Provider:', metadata.providerName)
    }
  })

  const handleSubmit = async (text: string) => {
    await sendMessage(text)
  }

  return (
    <div>
      <MessageList messages={messages.messages} />
      {isTyping && <TypingIndicator />}
      {error && <ErrorDisplay error={error} />}
      <MessageInput onSubmit={handleSubmit} />
      <QuickActions onAction={handleQuickAction} />
    </div>
  )
}
```

The hook returns an object with message state, sending capabilities, quick actions, and UI state indicators for building interactive chat interfaces with real-time AI assistance.
