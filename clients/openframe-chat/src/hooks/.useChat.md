A comprehensive React hook that manages real-time chat functionality with support for message streaming, approvals, and dialog resumption in the Flamingo platform.

## Key Components

- **State Management**: Handles typing indicators, streaming status, error states, and dialog tracking
- **Real-time Communication**: Integrates NATS WebSocket subscriptions for live message streaming
- **Message Processing**: Processes both real-time chunks and historical messages with approval workflows
- **API Integration**: Manages chat API service with authentication token handling
- **Dialog Management**: Supports creating new dialogs and resuming existing conversations
- **Chunk Processing**: Handles streaming message segments with catchup mechanisms for missed data

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const {
    messages,
    isTyping,
    isStreaming,
    error,
    dialogId,
    sendMessage,
    handleQuickAction,
    clearMessages,
    resumeDialog
  } = useChat({
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log(`Model: ${metadata.modelName}, Provider: ${metadata.providerName}`)
    }
  })

  const handleSend = async (text: string) => {
    await sendMessage(text)
  }

  const handleResume = async (id: string) => {
    const success = await resumeDialog(id)
    if (!success) {
      console.error('Failed to resume dialog')
    }
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Assistant is typing...</div>}
      {error && <div>Error: {error}</div>}
    </div>
  )
}
```

The hook returns an object with message state, loading indicators, and functions for sending messages, handling quick actions, clearing chat history, and resuming previous conversations.
