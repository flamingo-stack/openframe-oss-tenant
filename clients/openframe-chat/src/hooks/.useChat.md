A comprehensive React hook that manages chat functionality with real-time messaging, dialog history, and approval workflows for the Flamingo platform.

## Key Components

**Core State Management:**
- `isTyping` - Tracks typing indicator state
- `natsStreaming` - Real-time streaming status via NATS
- `natsDialogId` - Current dialog session identifier
- `error` - Error state management
- `isLoadingHistory` - Loading state for dialog history
- `isResumedDialog` - Tracks if dialog was resumed from history

**Service Integration:**
- `ChatApiService` - API communication service
- `tokenService` - Authentication token management
- `dialogGraphQLService` - Dialog history retrieval
- NATS WebSocket subscription for real-time events

**Sub-hooks:**
- `useChatMessages` - Message state management
- `useChatApprovals` - Approval request handling
- `useRealtimeChunkProcessor` - Real-time message processing
- `useChunkCatchup` - Historical message synchronization
- `useNatsDialogSubscription` - NATS WebSocket subscription

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const {
    messages,
    isTyping,
    isStreaming,
    error,
    dialogId,
    sendMessage,
    handleQuickAction,
    clearMessages,
    resumeDialog
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model updated:', metadata.modelName)
    }
  })

  const handleSend = async (text: string) => {
    await sendMessage(text)
  }

  const handleResume = async (dialogId: string) => {
    const success = await resumeDialog(dialogId)
    if (!success) {
      console.error('Failed to resume dialog')
    }
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Fae is typing...</div>}
      {error && <div>Error: {error}</div>}
    </div>
  )
}
```

**Key Features:**
- Real-time messaging with NATS WebSocket connections
- Dialog history persistence and resumption
- Approval workflow management for sensitive operations
- Automatic token refresh and API service management
- Comprehensive error handling and loading states
