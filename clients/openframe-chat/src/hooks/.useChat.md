A React hook that manages comprehensive chat functionality with real-time messaging, approvals, and streaming capabilities for the OpenFrame chat interface.

## Key Components

- **State Management**: Handles typing indicators, NATS streaming status, error states, and dialog resumption
- **Real-time Communication**: Integrates NATS WebSocket subscriptions for live message streaming
- **Message Processing**: Processes historical messages and real-time chunks with approval workflows
- **API Integration**: Connects to ChatApiService for sending messages and creating dialogs
- **Token Management**: Handles authentication tokens and API base URL configuration
- **Chunk Catchup**: Manages message synchronization when reconnecting to ongoing conversations

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const {
    messages,
    isTyping,
    sendMessage,
    clearMessages,
    error,
    quickActions
  } = useChat({
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model info:', metadata.modelName, metadata.providerName)
    }
  })

  const handleSendMessage = async () => {
    await sendMessage("Hello, how can you help me today?")
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Assistant is typing...</div>}
      {error && <div>Error: {error}</div>}
      <button onClick={handleSendMessage}>Send Message</button>
    </div>
  )
}
```

The hook returns a comprehensive interface including message arrays, typing status, approval handlers, quick actions, and functions for sending messages and managing chat state.
