A React hook for managing real-time chat functionality in the Flamingo platform, handling message flow through NATS streaming, API services, and dialog management with approval workflows.

## Key Components

- **Core Chat State**: Manages typing indicators, streaming status, error states, and dialog lifecycle
- **Real-time Processing**: Integrates NATS WebSocket subscriptions for live message streaming with chunk processing
- **Message Management**: Utilizes `useChatMessages` and `useChatApprovals` for handling conversation flow and approval requests
- **API Integration**: Connects to `ChatApiService` and `dialogGraphQLService` for backend communication
- **Dialog Resumption**: Supports loading historical messages and resuming previous conversations
- **Chunk Catchup**: Handles message synchronization when reconnecting to ongoing conversations

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatInterface() {
  const {
    messages,
    isTyping,
    isStreaming,
    error,
    dialogId,
    sendMessage,
    clearMessages,
    resumeDialog
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log(`Using ${metadata.modelName} from ${metadata.providerName}`)
    }
  })

  const handleSendMessage = async () => {
    await sendMessage("Hello, Fae!")
  }

  const handleResumeDialog = async () => {
    const success = await resumeDialog("dialog-123")
    if (success) {
      console.log("Dialog resumed successfully")
    }
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Assistant is typing...</div>}
      {error && <div>Error: {error}</div>}
    </div>
  )
}
```

The hook manages complex real-time chat flows including NATS subscriptions, message chunking, approval workflows, and seamless dialog resumption with full historical context.
