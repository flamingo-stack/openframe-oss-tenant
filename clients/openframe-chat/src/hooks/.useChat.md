A custom React hook that manages chat functionality, including real-time messaging, NATS subscriptions, approval workflows, and message history processing. It provides a complete chat interface with typing indicators, error handling, and integration with the Flamingo Stack's OpenFrame frontend core.

## Key Components

- **State Management**: Handles typing indicators, streaming status, dialog IDs, error states, and message loading
- **Real-time Communication**: Manages NATS WebSocket subscriptions for live message streaming
- **Message Processing**: Integrates chunk processing, catchup mechanisms, and historical message handling
- **Approval System**: Provides approval/rejection workflows for escalated requests
- **API Integration**: Connects to ChatApiService for dialog creation and message sending
- **Token Management**: Automatically handles authentication tokens and API base URLs

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const { 
    messages, 
    sendMessage, 
    isTyping, 
    error, 
    clearMessages,
    handleQuickAction 
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model:', metadata.modelName, 'Provider:', metadata.providerName)
    }
  })

  const handleSend = async () => {
    await sendMessage("Hello Fae!")
  }

  return (
    <div>
      <div className="messages">
        {messages.messages.map(msg => (
          <div key={msg.id}>{msg.content}</div>
        ))}
      </div>
      {isTyping && <div>Fae is typing...</div>}
      {error && <div className="error">{error}</div>}
      <button onClick={handleSend}>Send Message</button>
    </div>
  )
}
```
