A React hook that provides comprehensive chat functionality with real-time messaging, message history, and approval workflows for the Flamingo AI assistant interface.

## Key Components

**State Management:**
- `isTyping` - Indicates when assistant is responding
- `natsStreaming` - Real-time message streaming status
- `natsDialogId` - Current dialog session identifier
- `error` - Error message display
- `isLoadingHistory` - Dialog history loading state

**Core Dependencies:**
- `useChatMessages` - Message list management
- `useChatApprovals` - User approval workflow handling
- `useRealtimeChunkProcessor` - Real-time message chunk processing
- `useNatsDialogSubscription` - NATS WebSocket subscription management
- `useChunkCatchup` - Message synchronization for resumed dialogs

**API Services:**
- `ChatApiService` - REST API communication
- `tokenService` - Authentication token management
- `dialogGraphQLService` - Dialog history retrieval

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const {
    messages,
    isTyping,
    isStreaming,
    error,
    sendMessage,
    clearMessages,
    resumeDialog
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model info:', metadata.modelName)
    }
  })

  const handleSend = async (text: string) => {
    await sendMessage(text)
  }

  const handleResume = async (dialogId: string) => {
    const success = await resumeDialog(dialogId)
    if (!success) {
      console.error('Failed to resume dialog')
    }
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Assistant is typing...</div>}
      {error && <div className="error">{error}</div>}
    </div>
  )
}
```

The hook manages the complete chat lifecycle including message sending, real-time streaming responses, dialog resumption, approval workflows, and error handling through a unified interface.
