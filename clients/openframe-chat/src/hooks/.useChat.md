React hook for managing chat functionality in the OpenFrame AI platform, providing a comprehensive interface for real-time messaging with AI assistants through NATS streaming and API integration.

## Key Components

- **Core State Management**: Handles typing indicators, streaming status, error states, and dialog management
- **Message Processing**: Integrates with `useChatMessages` and `useChatApprovals` for message handling and approval workflows
- **Real-time Streaming**: Uses NATS WebSocket subscription for live message updates with chunk processing and catchup functionality
- **API Integration**: Manages chat API service for sending messages and creating dialogs
- **Token Management**: Automatically handles authentication tokens and API base URL updates

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const {
    messages,
    sendMessage,
    isTyping,
    error,
    clearMessages,
    handleQuickAction,
    approvals,
    quickActions
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model updated:', metadata.modelName)
    }
  })

  const handleSubmit = async (text: string) => {
    try {
      await sendMessage(text)
    } catch (error) {
      console.error('Failed to send message:', error)
    }
  }

  return (
    <div>
      {messages.messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Assistant is typing...</div>}
      {error && <div className="error">{error}</div>}
      
      <input
        onKeyDown={(e) => {
          if (e.key === 'Enter') {
            handleSubmit(e.currentTarget.value)
            e.currentTarget.value = ''
          }
        }}
      />
      
      {quickActions.map(action => (
        <button
          key={action.id}
          onClick={() => handleQuickAction(action.text)}
        >
          {action.text}
        </button>
      ))}
    </div>
  )
}
```

The hook automatically manages NATS subscriptions, handles message streaming with real-time updates, processes approval requests, and maintains conversation state across component re-renders.
