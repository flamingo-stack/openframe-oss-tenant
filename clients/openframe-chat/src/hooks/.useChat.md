A React hook that manages chat functionality with real-time messaging, NATS streaming, and approval workflows for the Flamingo MSP platform.

## Key Components

- **State Management**: Handles typing indicators, streaming status, dialog IDs, and error states
- **Real-time Processing**: Integrates NATS WebSocket subscriptions for live message streaming
- **Message Management**: Uses `useChatMessages` and `useChatApprovals` for message and approval handling
- **API Integration**: Connects to ChatApiService for dialog creation and message sending
- **Chunk Processing**: Implements catch-up mechanisms for missed real-time chunks
- **Token Management**: Handles authentication tokens and API base URL updates

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const {
    messages,
    isTyping,
    sendMessage,
    clearMessages,
    quickActions,
    handleQuickAction,
    error
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log(`Using ${metadata.modelName} from ${metadata.providerName}`)
    }
  })

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Assistant is typing...</div>}
      <button onClick={() => sendMessage('Hello Fae!')}>
        Send Message
      </button>
      {error && <div className="error">{error}</div>}
    </div>
  )
}
```

The hook provides comprehensive chat functionality including message history loading, approval escalation handling, and seamless integration with the Flamingo real-time messaging infrastructure.
