A React hook that manages real-time chat functionality with AI assistants, handling message streaming, NATS subscriptions, and approval workflows.

## Key Components

- **useChat** - Main hook providing chat state management and real-time messaging
- **Core State Management** - Handles typing indicators, streaming status, and error states
- **NATS Integration** - Real-time message streaming via WebSocket subscriptions
- **Message Processing** - Chunk processing for streaming responses and historical message handling
- **Approval System** - Client-side approval workflow for sensitive operations
- **API Service** - HTTP API communication for dialog creation and message sending

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const {
    messages,
    sendMessage,
    isTyping,
    error,
    handleQuickAction,
    clearMessages,
    quickActions
  } = useChat({
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model:', metadata.modelName)
    }
  })

  const handleSubmit = async (text: string) => {
    await sendMessage(text)
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>AI is typing...</div>}
      {error && <div>Error: {error}</div>}
      
      <ChatInput onSend={handleSubmit} />
      
      <QuickActions 
        actions={quickActions}
        onAction={handleQuickAction}
      />
    </div>
  )
}
```

The hook integrates with multiple services including token management, debug mode context, and real-time chunk processing for a complete chat experience with Fae AI assistant.
