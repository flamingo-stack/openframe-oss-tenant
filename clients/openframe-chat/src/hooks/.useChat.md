A React hook that manages comprehensive chat functionality including real-time messaging, NATS streaming, message history, and user approvals for the OpenFrame chat interface.

## Key Components

**Main Hook**: `useChat()` - Central chat management with WebSocket streaming
**State Management**: Handles typing indicators, NATS connection status, and error states
**Message System**: Integrates with `useChatMessages` and `useChatApprovals` for full chat lifecycle
**Real-time Processing**: Uses NATS WebSocket subscriptions for live message streaming
**API Integration**: Manages chat API service with token authentication

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const {
    messages,
    sendMessage,
    isTyping,
    error,
    clearMessages,
    quickActions,
    handleQuickAction
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model:', metadata.modelName)
    }
  })

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Fae is typing...</div>}
      {error && <div className="error">{error}</div>}
      <button onClick={() => sendMessage('Hello!')}>
        Send Message
      </button>
      <button onClick={clearMessages}>Clear Chat</button>
    </div>
  )
}
```

The hook automatically handles message streaming via NATS, maintains chat history, processes approvals, and provides quick actions. It supports both mock and production modes with comprehensive error handling and real-time synchronization.
