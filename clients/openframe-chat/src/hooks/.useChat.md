A React hook that manages real-time chat functionality with WebSocket subscriptions, message streaming, and approval workflows. It integrates multiple services to handle dialog sessions, message history, and live updates via NATS messaging.

## Key Components

- **Core State Management**: Handles typing indicators, NATS streaming status, dialog IDs, and error states
- **Message Processing**: Integrates with `useChatMessages` and `useChatApprovals` for comprehensive chat functionality
- **Real-time Communication**: Uses NATS WebSocket subscriptions for live message streaming and chunk processing
- **API Integration**: Connects to ChatApiService for dialog creation and message sending
- **Catchup Mechanism**: Implements chunk catchup functionality to sync missed messages when reconnecting
- **Token Management**: Automatically handles authentication tokens and API base URL updates

## Usage Example

```typescript
import { useChat } from './hooks/useChat'

function ChatComponent() {
  const { 
    messages, 
    sendMessage, 
    isTyping, 
    clearMessages,
    handleQuickAction 
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model info:', metadata.modelName)
    }
  })

  return (
    <div>
      {messages.messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      
      {isTyping && <div>Fae is typing...</div>}
      
      <button onClick={() => sendMessage('Hello!')}>
        Send Message
      </button>
      
      <button onClick={() => handleQuickAction('Quick action text')}>
        Quick Action
      </button>
    </div>
  )
}
```

The hook automatically manages WebSocket connections, handles message approvals, processes real-time chunks, and maintains chat history with proper error handling and reconnection logic.
