A comprehensive React hook that manages chat functionality with real-time messaging support via NATS and historical message loading. Integrates multiple chat-related services including API communication, real-time chunk processing, approvals workflow, and debug mode support.

## Key Components

**Main Hook:**
- `useChat` - Primary hook managing chat state and message flow

**State Management:**
- Real-time streaming state (`isTyping`, `natsStreaming`)
- Dialog session tracking (`natsDialogId`, `isResumedDialog`)
- Error handling and loading states
- Token and API base URL management

**Service Integration:**
- `ChatApiService` - API communication for sending messages
- NATS WebSocket subscription for real-time message streaming
- `useRealtimeChunkProcessor` - Processes incoming message chunks
- `useChunkCatchup` - Handles message history synchronization
- `useChatMessages` & `useChatApprovals` - Message and approval state management

**Key Features:**
- Automatic token/API URL updates via `tokenService`
- Real-time message streaming with NATS WebSocket
- Approval workflow for escalated actions
- Debug mode integration
- Incomplete message state restoration for resumed dialogs

## Usage Example

```typescript
import { useChat } from './hooks/useChat'

function ChatComponent() {
  const { 
    messages, 
    sendMessage, 
    isTyping, 
    error, 
    clearMessages,
    handleQuickAction 
  } = useChat({
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model:', metadata.modelName, 'Provider:', metadata.providerName)
    }
  })

  const handleSubmit = (text: string) => {
    sendMessage(text)
  }

  return (
    <div>
      {error && <div className="error">{error}</div>}
      
      {messages.messages.map(msg => (
        <div key={msg.id}>
          <strong>{msg.name}:</strong> {msg.content}
        </div>
      ))}
      
      {isTyping && <div>Fae is typing...</div>}
      
      <button onClick={() => handleQuickAction('Help me get started')}>
        Quick Start
      </button>
      
      <button onClick={clearMessages}>Clear Chat</button>
    </div>
  )
}
```
