Provides chat functionality with real-time messaging, NATS subscription handling, and AI assistant interactions. Manages message state, approvals, streaming responses, and error handling for the Flamingo chat interface.

## Key Components

- **useChat** - Main hook providing chat state and methods
- **sendMessage** - Sends user messages and handles AI responses via NATS
- **Real-time Processing** - Manages streaming chunks and message updates
- **State Management** - Handles messages, approvals, typing indicators, and errors
- **NATS Integration** - WebSocket subscription for real-time communication
- **Dialog Management** - Creates and resumes chat dialogs with history

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const {
    messages,
    sendMessage,
    isTyping,
    error,
    handleQuickAction,
    clearMessages,
    isLoadingHistory
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('AI Model:', metadata.modelName)
    }
  })

  const handleSubmit = async (text: string) => {
    try {
      await sendMessage(text)
    } catch (error) {
      console.error('Failed to send message:', error)
    }
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Fae is typing...</div>}
      {error && <div className="error">{error}</div>}
    </div>
  )
}
```

The hook integrates with multiple services including token management, GraphQL dialogs, and real-time chunk processing to provide a complete chat experience with AI assistant "Fae".
