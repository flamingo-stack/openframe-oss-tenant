Custom React hook for managing AI chat functionality with real-time message streaming, approvals workflow, and dialog state management. Integrates with NATS WebSocket subscriptions for live message updates and supports both API and mock modes.

## Key Components

### Main Hook Export
- **`useChat(options)`** - Primary hook with configuration options for API usage, NATS streaming, and metadata callbacks

### Core State Management
- **Message State** - Handles chat messages, typing indicators, and error states
- **NATS Integration** - Real-time WebSocket subscription management for live streaming
- **Approval System** - Manages approval requests and escalated approval workflows
- **Token Management** - Automatic token refresh and API URL configuration

### Streaming & Real-time Features
- **Chunk Processing** - Real-time message segment processing with catchup mechanism
- **Dialog Resumption** - Restores incomplete message states when resuming conversations
- **Subscription Management** - Handles NATS WebSocket connection lifecycle

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const { 
    messages, 
    isTyping, 
    sendMessage, 
    clearMessages,
    quickActions,
    error 
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model info:', metadata.modelName, metadata.providerName)
    }
  })

  const handleSend = async (text: string) => {
    await sendMessage(text)
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Assistant is typing...</div>}
      {error && <div className="error">{error}</div>}
      <input onSubmit={(e) => handleSend(e.target.value)} />
    </div>
  )
}
```

The hook manages complex state synchronization between API calls, real-time streaming, and approval workflows while providing a simple interface for chat components.
