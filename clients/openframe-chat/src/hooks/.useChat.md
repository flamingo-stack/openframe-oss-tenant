A React hook that provides comprehensive chat functionality with support for real-time messaging, approvals, and NATS streaming. This hook orchestrates multiple chat-related services and manages the complete chat state lifecycle including message history, typing indicators, and error handling.

## Key Components

**Main Hook:**
- `useChat()` - Primary chat management hook with configurable options

**Core State Management:**
- Message state with `useChatMessages` and `useChatApprovals`
- Real-time streaming with NATS WebSocket subscription
- Chunk processing for handling streaming responses
- Error handling and loading states

**Key Features:**
- Real-time message streaming via NATS
- Approval workflow management
- Message history loading and resumption
- Token-based authentication
- Debug mode support

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const { 
    messages, 
    sendMessage, 
    isTyping, 
    error, 
    clearMessages,
    quickActions,
    handleQuickAction 
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model updated:', metadata.modelName)
    }
  })

  const handleSubmit = async (text: string) => {
    try {
      await sendMessage(text)
    } catch (err) {
      console.error('Failed to send message:', err)
    }
  }

  return (
    <div>
      <MessageList messages={messages.messages} />
      {isTyping && <TypingIndicator />}
      {error && <ErrorMessage error={error} />}
      <ChatInput onSubmit={handleSubmit} />
      <QuickActions 
        actions={quickActions} 
        onAction={handleQuickAction} 
      />
    </div>
  )
}
```

The hook integrates multiple specialized hooks for message management, approval workflows, and real-time communication, providing a complete chat solution with support for resuming interrupted conversations and handling complex approval processes.
