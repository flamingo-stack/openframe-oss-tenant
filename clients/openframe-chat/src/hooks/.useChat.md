A React hook that provides comprehensive chat functionality with real-time messaging, NATS integration, and approval workflows for the Flamingo AI assistant.

## Key Components

- **useChat()** - Main hook managing chat state, messaging, and real-time communication
- **sendMessage()** - Sends user messages and handles streaming responses via NATS
- **handleQuickAction()** - Executes predefined quick actions from chat config
- **clearMessages()** - Resets chat session and clears message history
- **Real-time processing** - Handles live message streaming and chunk processing
- **Approval system** - Manages escalated approvals for sensitive operations

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const {
    messages,
    isTyping,
    error,
    sendMessage,
    clearMessages,
    handleQuickAction
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model:', metadata.modelName)
    }
  })

  const handleSubmit = async (text: string) => {
    await sendMessage(text)
  }

  const handleQuickReply = () => {
    handleQuickAction('Show system status')
  }

  return (
    <div className="chat-container">
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Fae is typing...</div>}
      {error && <div className="error">{error}</div>}
      <button onClick={handleQuickReply}>Quick Status</button>
      <button onClick={clearMessages}>Clear Chat</button>
    </div>
  )
}
```

The hook integrates with multiple services including token management, GraphQL dialogs, and NATS real-time messaging to provide a complete chat experience with the Fae AI assistant.
