A custom React hook that provides comprehensive chat functionality for the Flamingo/OpenFrame platform, integrating real-time messaging, NATS streaming, message history, and approval workflows.

## Key Components

- **Core State Management**: Handles typing indicators, streaming status, dialog IDs, and error states
- **Message Management**: Integrates with `useChatMessages` and `useChatApprovals` for message handling and approval workflows
- **Real-time Communication**: Uses NATS WebSocket subscriptions for live message streaming and chunk processing
- **API Integration**: Manages chat API service with token authentication and configurable base URLs
- **Chunk Processing**: Implements catch-up mechanisms for missed real-time chunks and incomplete message state recovery
- **Quick Actions**: Provides predefined message shortcuts through chat configuration

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const {
    messages,
    isTyping,
    error,
    sendMessage,
    clearMessages,
    handleQuickAction,
    quickActions
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log(`Model: ${metadata.modelName}, Provider: ${metadata.providerName}`)
    }
  })

  const handleSubmit = async (text: string) => {
    await sendMessage(text)
  }

  return (
    <div>
      {messages.messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Fae is typing...</div>}
      {error && <div>Error: {error}</div>}
      
      {quickActions.map(action => (
        <button 
          key={action.id}
          onClick={() => handleQuickAction(action.text)}
        >
          {action.label}
        </button>
      ))}
    </div>
  )
}
```

The hook manages complex real-time chat workflows including message approvals, tool executions, and seamless reconnection with state recovery for interrupted conversations.
