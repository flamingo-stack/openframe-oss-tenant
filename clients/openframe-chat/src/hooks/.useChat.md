A React hook that manages AI chat functionality with real-time messaging, approvals, and NATS streaming support. It provides comprehensive chat state management including message handling, typing indicators, and integration with various backend services.

## Key Components

- **Core State Management**: Handles typing status, streaming state, error handling, and message history
- **NATS Integration**: Real-time messaging through WebSocket subscriptions with chunk processing and catch-up mechanisms
- **Message Processing**: Uses `useChatMessages` and `useChatApprovals` for message state and approval workflows
- **API Service**: Integrates with `ChatApiService` for dialog creation and message sending
- **Stream Handling**: Manages real-time chunk processing with incomplete message state recovery

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const { 
    messages, 
    sendMessage, 
    isTyping, 
    error,
    quickActions,
    handleQuickAction,
    clearMessages 
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model:', metadata.modelName)
    }
  })

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Assistant is typing...</div>}
      {error && <div>Error: {error}</div>}
      
      <button onClick={() => sendMessage('Hello!')}>
        Send Message
      </button>
      
      {quickActions.map(action => (
        <button 
          key={action.text}
          onClick={() => handleQuickAction(action.text)}
        >
          {action.text}
        </button>
      ))}
    </div>
  )
}
```
