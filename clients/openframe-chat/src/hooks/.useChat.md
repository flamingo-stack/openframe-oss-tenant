A comprehensive React hook that manages real-time chat functionality with AI assistants, handling message state, streaming responses via NATS, and user approvals. This hook integrates multiple chat-related services and provides a complete chat interface with typing indicators, error handling, and message history management.

## Key Components

- **Real-time Communication**: NATS WebSocket subscription for streaming AI responses
- **Message Management**: State handling for chat messages, segments, and approvals
- **API Integration**: Chat API service for sending messages and managing dialogs
- **Stream Processing**: Real-time chunk processing for incoming message segments
- **Catchup Logic**: Handles message synchronization when resuming dialogs
- **Token Management**: Authentication token handling and API base URL management
- **Error Handling**: Comprehensive error states and recovery mechanisms

## Usage Example

```typescript
import { useChat } from './hooks/useChat'

function ChatComponent() {
  const { 
    messages, 
    sendMessage, 
    isTyping, 
    error, 
    clearMessages,
    handleQuickAction,
    quickActions 
  } = useChat({
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model info:', metadata.modelName, metadata.providerName)
    }
  })

  const handleSubmit = async (text: string) => {
    await sendMessage(text)
  }

  return (
    <div>
      <MessageList messages={messages.messages} />
      {isTyping && <TypingIndicator />}
      {error && <ErrorMessage error={error} />}
      <MessageInput onSubmit={handleSubmit} />
      <QuickActions actions={quickActions} onAction={handleQuickAction} />
    </div>
  )
}
```

The hook manages complex state synchronization between local UI state, real-time NATS streams, and backend API calls, providing a seamless chat experience with proper error recovery and message persistence.
