A comprehensive React hook that manages real-time chat functionality with NATS streaming, message handling, approvals, and dialog management for the Flamingo AI assistant interface.

## Key Components

### Core State Management
- **Message State**: User and assistant messages with real-time updates
- **Streaming State**: NATS WebSocket connection and typing indicators
- **Dialog Management**: Resume existing conversations and create new dialogs
- **Error Handling**: Network errors and API failures
- **Approval System**: Client-side approval workflows for sensitive operations

### Services Integration
- **ChatApiService**: REST API communication for sending messages
- **TokenService**: Authentication token management
- **DialogGraphQLService**: Historical message retrieval
- **NATS Streaming**: Real-time message chunks and events

### Custom Hooks
- **useRealtimeChunkProcessor**: Processes streaming message segments
- **useChunkCatchup**: Handles message synchronization on reconnect
- **useChatMessages**: Message state management
- **useChatApprovals**: Approval request handling

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const {
    messages,
    isTyping,
    isStreaming,
    error,
    dialogId,
    sendMessage,
    handleQuickAction,
    clearMessages,
    resumeDialog
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model:', metadata.modelName, 'Provider:', metadata.providerName)
    }
  })

  const handleSend = async (text: string) => {
    await sendMessage(text)
  }

  const handleResume = async (id: string) => {
    const success = await resumeDialog(id)
    if (!success) console.error('Failed to resume dialog')
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Assistant is typing...</div>}
      {error && <div className="error">{error}</div>}
    </div>
  )
}
```

The hook manages the complete chat lifecycle including NATS subscription setup, message streaming, historical data loading, and approval workflows for the Fae AI assistant.
