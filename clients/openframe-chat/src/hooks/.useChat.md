A React hook that provides comprehensive chat functionality with realtime messaging, approvals, and NATS streaming support for the Flamingo/OpenFrame platform.

## Key Components

- **Core State Management**: Handles typing indicators, streaming status, error states, and chat history loading
- **Service Integration**: Integrates with ChatApiService, token management, and GraphQL services
- **Realtime Processing**: Uses NATS WebSocket subscriptions for live message streaming and chunk processing
- **Message Management**: Leverages `useChatMessages` and `useChatApprovals` hooks for state coordination
- **Catchup Logic**: Handles message synchronization when reconnecting to ongoing conversations
- **Quick Actions**: Supports predefined chat actions from configuration

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const { 
    messages, 
    sendMessage, 
    isTyping, 
    error, 
    quickActions,
    handleQuickAction 
  } = useChat({
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model:', metadata.modelName)
    }
  })

  const handleSubmit = async (text: string) => {
    await sendMessage(text)
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Fae is typing...</div>}
      {error && <div>Error: {error}</div>}
      <input onSubmit={handleSubmit} />
    </div>
  )
}
```

The hook automatically manages dialog creation, NATS subscriptions, message approval workflows, and error handling while providing a simple interface for chat functionality.
