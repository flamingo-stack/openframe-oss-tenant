A React hook that manages chat functionality with real-time messaging, approvals, and AI assistant interactions using NATS streaming and API services.

## Key Components

- **Core State Management**: Handles typing indicators, streaming status, dialog IDs, and error states
- **Message Management**: Integrates with `useChatMessages` and `useChatApprovals` for comprehensive chat state
- **Real-time Streaming**: Uses NATS WebSocket subscriptions for live message updates and chunk processing
- **API Integration**: Manages chat API service for sending messages and creating dialogs
- **Chunk Processing**: Handles real-time message chunks with catchup functionality for reconnection scenarios
- **Approval System**: Manages escalated approvals with different approval types (CLIENT, etc.)

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const { 
    sendMessage, 
    messages, 
    isTyping, 
    error,
    clearMessages,
    handleQuickAction 
  } = useChat({
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model info:', metadata.modelName, metadata.providerName)
    }
  })

  const handleSubmit = (text: string) => {
    sendMessage(text)
  }

  const handleClear = () => {
    clearMessages()
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>AI is typing...</div>}
      {error && <div>Error: {error}</div>}
    </div>
  )
}
```

The hook provides a complete chat interface with AI assistant capabilities, real-time streaming, approval workflows, and robust error handling for production chat applications.
