A React hook that provides comprehensive chat functionality for the Flamingo AI platform, managing real-time messaging, NATS streaming, approval workflows, and chat history.

## Key Components

- **Real-time messaging** - NATS WebSocket subscription for live chat streaming
- **Message management** - Full CRUD operations for chat messages and segments
- **Approval system** - Handles user approvals for AI actions with escalation
- **Stream processing** - Real-time chunk processing for streaming responses
- **Error handling** - Comprehensive error states and recovery mechanisms
- **Token management** - Automatic authentication token handling
- **Debug support** - Integration with debug mode context

## Usage Example

```typescript
import { useChat } from './hooks/useChat'

function ChatComponent() {
  const { 
    messages, 
    sendMessage, 
    isTyping, 
    clearMessages,
    error,
    isLoadingHistory,
    handleQuickAction
  } = useChat({
    useNats: true,
    useApi: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model:', metadata.modelName, 'Provider:', metadata.providerName)
    }
  })

  const handleSubmit = async (text: string) => {
    await sendMessage(text)
  }

  const handleClear = () => {
    clearMessages()
  }

  return (
    <div>
      <ChatMessages messages={messages.messages} />
      {isTyping && <TypingIndicator />}
      {error && <ErrorMessage error={error} />}
      <ChatInput onSubmit={handleSubmit} disabled={isTyping} />
      <QuickActions onAction={handleQuickAction} />
      <button onClick={handleClear}>Clear Chat</button>
    </div>
  )
}
```

## Key Features

- **Streaming Support** - Real-time message streaming via NATS WebSocket connections
- **Approval Workflows** - Built-in approval system for AI actions requiring user consent
- **Message Persistence** - Dialog history management with GraphQL integration
