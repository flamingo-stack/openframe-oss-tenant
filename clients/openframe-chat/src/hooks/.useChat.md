A comprehensive React hook that manages real-time chat functionality with NATS streaming, message history, and approval workflows for the Flamingo AI chat system.

## Key Components

- **State Management**: Handles typing indicators, streaming status, error states, and dialog resumption
- **Message Processing**: Integrates with `useChatMessages` and `useChatApprovals` for message and approval management
- **Real-time Communication**: Uses NATS WebSocket subscriptions for live message streaming
- **Chunk Processing**: Processes real-time message chunks with catchup functionality for missed messages
- **API Integration**: Communicates with ChatApiService for dialog creation and message sending
- **History Management**: Loads and processes historical messages when resuming dialogs

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const {
    messages,
    isTyping,
    isStreaming,
    error,
    dialogId,
    sendMessage,
    handleQuickAction,
    clearMessages,
    resumeDialog
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model:', metadata.modelName, 'Provider:', metadata.providerName)
    }
  })

  const handleSubmit = async (text: string) => {
    await sendMessage(text)
  }

  const handleResumeExistingDialog = async (dialogId: string) => {
    const success = await resumeDialog(dialogId)
    if (success) {
      console.log('Dialog resumed successfully')
    }
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Assistant is typing...</div>}
      {error && <div>Error: {error}</div>}
    </div>
  )
}
```

The hook provides a complete chat interface with real-time messaging, error handling, and the ability to resume previous conversations seamlessly.
