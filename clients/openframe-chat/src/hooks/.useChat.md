A React hook that manages real-time chat functionality with AI assistants, handling message streaming, approvals, and NATS subscriptions for live communication.

## Key Components

- **Chat State Management**: Core state for typing indicators, streaming status, and error handling
- **Real-time Processing**: NATS WebSocket subscription for live message streaming and chunk processing
- **Message Management**: Integration with `useChatMessages` and `useChatApprovals` hooks
- **API Service Integration**: Connection to backend chat services with token authentication
- **Stream Resumption**: Support for resuming interrupted conversations with incomplete message state
- **Approval System**: Handles escalated approvals and client-side approval requests

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const {
    messages,
    isTyping,
    sendMessage,
    clearMessages,
    quickActions,
    handleQuickAction,
    error
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log(`Using ${metadata.modelName} from ${metadata.providerName}`)
    }
  })

  const handleSubmit = async (text: string) => {
    await sendMessage(text)
  }

  return (
    <div>
      <div className="messages">
        {messages.messages.map(msg => (
          <div key={msg.id}>{msg.content}</div>
        ))}
      </div>
      {isTyping && <div>Fae is typing...</div>}
      {error && <div className="error">{error}</div>}
      <button onClick={() => clearMessages()}>Clear Chat</button>
    </div>
  )
}
```

The hook automatically handles NATS subscription management, message chunk processing, and maintains conversation state across reconnections.
