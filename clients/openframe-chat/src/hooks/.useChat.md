A custom React hook that manages real-time chat functionality with support for NATS streaming, message handling, and user approvals. This hook provides comprehensive chat state management including message history, typing indicators, and error handling.

## Key Components

- **Core State Management**: Handles typing status, NATS streaming, dialog IDs, and error states
- **Message Processing**: Integrates with `useChatMessages` and `useChatApprovals` for complete message lifecycle
- **Real-time Communication**: Uses NATS WebSocket subscription for live message streaming
- **API Integration**: Manages ChatApiService for dialog creation and message sending
- **Chunk Processing**: Handles real-time chunk processing and catch-up mechanisms
- **Token Management**: Integrates with tokenService for authentication

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const {
    messages,
    isTyping,
    error,
    sendMessage,
    clearMessages,
    quickActions
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model:', metadata.modelName)
    }
  })

  const handleSend = async (text: string) => {
    await sendMessage(text)
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Assistant is typing...</div>}
      {error && <div>Error: {error}</div>}
    </div>
  )
}
```

The hook returns a comprehensive chat interface including message state, UI controls, and real-time streaming capabilities with built-in error handling and approval workflows.
