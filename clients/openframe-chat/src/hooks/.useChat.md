This React hook provides a comprehensive chat interface implementation for the Flamingo OpenFrame platform, handling real-time messaging, NATS subscriptions, and approval workflows between users and Fae AI assistant.

## Key Components

- **State Management**: Manages typing indicators, NATS streaming, dialog IDs, errors, and authentication tokens
- **Real-time Processing**: Integrates NATS WebSocket subscriptions for live message streaming and chunk processing
- **Message Handling**: Coordinates with `useChatMessages` and `useChatApprovals` hooks for message state and approval workflows
- **API Integration**: Manages ChatApiService for dialog creation and message sending
- **Chunk Catchup**: Handles message synchronization when reconnecting to ongoing conversations
- **Token Management**: Automatically manages authentication tokens and API base URLs

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const { 
    sendMessage, 
    messages, 
    isTyping, 
    clearMessages,
    handleQuickAction 
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model:', metadata.modelName)
    }
  })

  const handleSend = async (text: string) => {
    await sendMessage(text)
  }

  return (
    <div>
      {messages.messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Fae is typing...</div>}
      <button onClick={() => handleSend("Hello!")}>
        Send Message
      </button>
    </div>
  )
}
```

The hook automatically handles message history loading, real-time streaming, approval escalations, and maintains connection state for seamless chat experiences.
