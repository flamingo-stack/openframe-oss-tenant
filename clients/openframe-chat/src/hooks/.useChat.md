A comprehensive React hook that manages chat functionality with real-time messaging, approvals, and message processing for the Flamingo/OpenFrame chat interface.

## Key Components

**Main Exports:**
- `useChat()` - Primary hook for chat functionality with configurable options
- `UseChatOptions` - Interface for hook configuration (mock, API, NATS settings)

**Core Features:**
- Real-time message streaming via NATS WebSocket
- Message approval workflows for sensitive operations
- Chat history loading and resumption
- Token-based authentication management
- Integration with multiple backend services

**State Management:**
- `isTyping` - Tracks assistant response state
- `natsStreaming` - Real-time connection status
- `messages` - Chat message collection via `useChatMessages`
- `approvals` - Approval request handling via `useChatApprovals`
- `error` - Error state management

**Service Integration:**
- `ChatApiService` - REST API communication
- `tokenService` - Authentication token management
- `dialogGraphQLService` - Dialog data persistence
- NATS WebSocket for real-time events

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const { 
    messages, 
    sendMessage, 
    isTyping, 
    error,
    clearMessages 
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model:', metadata.modelName)
    }
  })

  const handleSend = async (text: string) => {
    await sendMessage(text)
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Assistant is typing...</div>}
      {error && <div className="error">{error}</div>}
    </div>
  )
}
```

The hook handles complex real-time streaming, message chunking, approval escalations, and seamless reconnection for production chat applications.
