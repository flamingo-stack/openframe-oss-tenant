A React hook for managing chat functionality with real-time messaging, approval workflows, and history management in the Flamingo/OpenFrame platform. Provides comprehensive chat state management including NATS streaming, message processing, and approval handling.

## Key Components

- **Chat State Management**: Handles messages, typing indicators, streaming status, and error states
- **Real-time Integration**: NATS WebSocket subscription for live message streaming and chunk processing
- **Approval System**: Manages approval requests with escalation and status tracking
- **Message History**: Loads and processes historical chat messages with incomplete state recovery
- **API Integration**: Chat API service for sending messages and creating dialogs
- **Chunk Processing**: Real-time message chunk processing with catch-up mechanisms

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const {
    messages,
    isTyping,
    sendMessage,
    clearMessages,
    loadDialog,
    handleQuickAction,
    error
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model:', metadata.modelName)
    }
  })

  const handleSend = async (text: string) => {
    await sendMessage(text)
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Assistant is typing...</div>}
      {error && <div className="error">{error}</div>}
    </div>
  )
}
```

The hook returns comprehensive chat functionality including message management, real-time streaming status, approval handling, and utility functions for sending messages and managing dialog state.
