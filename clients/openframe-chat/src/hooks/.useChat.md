A React hook that provides complete chat functionality with real-time messaging, approvals, and NATS integration for the Flamingo AI platform.

## Key Components

- **Core Chat State** - Message management, typing indicators, error handling
- **Real-time Communication** - NATS WebSocket subscription and chunk processing
- **Message Processing** - Historical message loading and real-time updates
- **Approval System** - Handles user approvals for AI actions
- **API Integration** - Chat service integration with token management
- **Stream Management** - Handles incomplete message states and reconnection

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const { 
    messages, 
    sendMessage, 
    isTyping, 
    clearMessages,
    error,
    quickActions 
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model info:', metadata.modelName, metadata.providerName)
    }
  })

  return (
    <div>
      <div className="messages">
        {messages.map(msg => (
          <div key={msg.id}>{msg.content}</div>
        ))}
      </div>
      
      {isTyping && <div>Fae is typing...</div>}
      {error && <div className="error">{error}</div>}
      
      <button onClick={() => sendMessage('Hello Fae!')}>
        Send Message
      </button>
      
      <button onClick={clearMessages}>
        Clear Chat
      </button>
    </div>
  )
}
```

## Configuration Options

```typescript
interface UseChatOptions {
  useApi?: boolean      // Enable API communication
  useNats?: boolean     // Enable real-time NATS messaging
  apiToken?: string     // Override default token
  apiBaseUrl?: string   // Override API endpoint
  onMetadataUpdate?: (metadata: { 
    modelName: string
    providerName: string
    contextWindow: number 
  }) => void
}
```

The hook automatically handles token management, dialog creation, message chunking, approval workflows, and maintains connection state for seamless chat experiences.
