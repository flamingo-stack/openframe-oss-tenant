This React hook provides comprehensive chat functionality for the Flamingo/OpenFrame platform, managing real-time messaging, approvals, and NATS-based communication with intelligent error handling and state management.

## Key Components

- **Core State Management**: Handles typing indicators, streaming state, dialog IDs, errors, and token management
- **Real-time Communication**: Integrates NATS WebSocket subscriptions for live message streaming
- **Message Processing**: Uses chunk processors and catchup mechanisms for reliable message delivery
- **Approval System**: Manages escalated approvals and user permissions for commands
- **API Integration**: Connects to ChatApiService for backend communication
- **History Loading**: Supports resuming dialogs with incomplete message states

## Usage Example

```typescript
import { useChat } from './hooks/useChat'

function ChatComponent() {
  const { 
    messages, 
    sendMessage, 
    isTyping, 
    error,
    clearMessages,
    handleQuickAction 
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log(`Model: ${metadata.modelName}, Provider: ${metadata.providerName}`)
    }
  })

  const handleSend = async (text: string) => {
    await sendMessage(text)
  }

  return (
    <div>
      {error && <div className="error">{error}</div>}
      <MessageList messages={messages.messages} />
      {isTyping && <TypingIndicator />}
      <MessageInput onSend={handleSend} />
    </div>
  )
}
```

The hook automatically manages authentication tokens, establishes NATS connections for real-time updates, and provides a complete chat interface with approval workflows and error recovery.
