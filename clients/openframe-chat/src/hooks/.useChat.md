A comprehensive React hook for managing chat functionality with real-time messaging, dialog management, and approval workflows. Integrates multiple services including NATS streaming, GraphQL dialog history, and chunk processing for a complete chat experience.

## Key Components

- **Core State Management**: Handles typing indicators, streaming status, errors, and dialog state
- **Real-time Messaging**: NATS WebSocket subscription for live message streaming
- **Message Processing**: Chunk catchup, historical message loading, and segment updates
- **Approval Workflow**: Escalated approval system for client interactions
- **Dialog Management**: Create new dialogs or resume existing conversations
- **Service Integration**: Token management, API services, and GraphQL operations

## Usage Example

```typescript
import { useChat } from './hooks/useChat'

function ChatComponent() {
  const {
    messages,
    isTyping,
    isStreaming,
    error,
    dialogId,
    sendMessage,
    handleQuickAction,
    clearMessages,
    resumeDialog,
    isLoadingHistory,
    isResumedDialog,
    quickActions,
    approvalStatuses
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model info:', metadata.modelName, metadata.providerName)
    }
  })

  const handleSendMessage = async () => {
    await sendMessage("Hello, how can you help me?")
  }

  const handleResumeChat = async () => {
    const success = await resumeDialog('dialog-123')
    if (!success) {
      console.error('Failed to resume dialog')
    }
  }

  return (
    <div>
      {isLoadingHistory && <div>Loading chat history...</div>}
      {error && <div className="error">{error}</div>}
      
      <div className="messages">
        {messages.map(msg => (
          <div key={msg.id} className={msg.role}>
            {msg.content}
          </div>
        ))}
        {isTyping && <div>Assistant is typing...</div>}
      </div>

      <button onClick={handleSendMessage} disabled={isStreaming}>
        Send Message
      </button>
      <button onClick={clearMessages}>Clear Chat</button>
    </div>
  )
}
```

The hook returns comprehensive chat state including message history, real-time status indicators, approval workflows, and methods for sending messages, managing dialogs, and handling quick actions. It automatically handles NATS subscriptions, chunk processing, and error recovery.
