This React hook provides comprehensive chat functionality for the Flamingo OpenFrame platform, managing real-time messaging, NATS subscriptions, and message state with support for streaming responses and approval workflows.

## Key Components

- **Real-time Communication**: NATS WebSocket subscription for live message streaming
- **Message Management**: Full message lifecycle with segments, approvals, and error handling
- **API Integration**: Chat API service for dialog creation and message sending
- **Chunk Processing**: Real-time chunk processing with catchup functionality for missed messages
- **State Management**: Comprehensive state for typing indicators, streaming status, and dialog history
- **Token Management**: Automatic token refresh and API base URL management

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const { 
    sendMessage, 
    messages, 
    isTyping, 
    error, 
    clearMessages,
    handleQuickAction 
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model info:', metadata.modelName, metadata.providerName)
    }
  })

  const handleSend = async (text: string) => {
    await sendMessage(text)
  }

  return (
    <div>
      {messages.messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Fae is typing...</div>}
      {error && <div className="error">{error}</div>}
    </div>
  )
}
```

The hook integrates with the Flamingo Stack's OpenFrame core for message processing, supports resuming incomplete dialogs, and provides real-time streaming with approval workflows for secure command execution.
