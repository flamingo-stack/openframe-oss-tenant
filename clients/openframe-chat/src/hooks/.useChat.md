A React hook that manages chat functionality with real-time messaging, approvals, and AI assistance. Provides complete chat state management including message sending, NATS-based real-time updates, and user approval workflows.

## Key Components

- **Core State Management**: Handles typing indicators, streaming status, error states, and dialog management
- **Real-time Processing**: Integrates NATS WebSocket subscriptions for live message streaming
- **Message Management**: Leverages `useChatMessages` and `useChatApprovals` for comprehensive chat state
- **API Integration**: Uses `ChatApiService` for sending messages and creating dialogs
- **Chunk Processing**: Implements real-time chunk processing with catchup mechanisms for reliable message delivery
- **Token Management**: Automatically handles authentication tokens and API base URL updates

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const { 
    messages,
    isTyping,
    error,
    sendMessage,
    clearMessages,
    quickActions,
    handleQuickAction
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model updated:', metadata.modelName)
    }
  })

  const handleSend = async (text: string) => {
    await sendMessage(text)
  }

  return (
    <div>
      <div className="messages">
        {messages.messages.map(msg => (
          <div key={msg.id}>{msg.content}</div>
        ))}
        {isTyping && <div>Fae is typing...</div>}
      </div>
      
      {error && <div className="error">{error}</div>}
      
      <div className="quick-actions">
        {quickActions.map(action => (
          <button 
            key={action.id}
            onClick={() => handleQuickAction(action.text)}
          >
            {action.text}
          </button>
        ))}
      </div>
    </div>
  )
}
```

The hook automatically manages NATS subscriptions, handles incomplete message states for resumed dialogs, and provides seamless integration with the Flamingo AI assistant "Fae".
