A React hook that manages real-time chat functionality with NATS streaming, message history, and approval workflows for the Flamingo AI assistant platform.

## Key Components

- **Real-time Communication**: NATS WebSocket subscription for live message streaming
- **Message Management**: Full message lifecycle with user/assistant interactions
- **Approval System**: Handles escalated approvals for AI actions requiring user consent
- **Dialog Resume**: Loads and continues previous chat conversations
- **Chunk Processing**: Handles streaming message chunks and catch-up for missed messages
- **Error Handling**: Comprehensive error states and recovery mechanisms

## Usage Example

```typescript
import { useChat } from './hooks/useChat'

function ChatComponent() {
  const {
    messages,
    isTyping,
    isStreaming,
    error,
    dialogId,
    sendMessage,
    handleQuickAction,
    clearMessages,
    resumeDialog,
    isLoadingHistory,
    quickActions
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model info:', metadata.modelName, metadata.providerName)
    }
  })

  const handleSend = async (text: string) => {
    await sendMessage(text)
  }

  const handleResume = async (dialogId: string) => {
    const success = await resumeDialog(dialogId)
    if (success) {
      console.log('Dialog resumed successfully')
    }
  }

  return (
    <div>
      <MessageList messages={messages} isTyping={isTyping} />
      <ChatInput onSend={handleSend} disabled={isStreaming} />
      {error && <ErrorDisplay error={error} />}
      {quickActions.map(action => (
        <QuickActionButton
          key={action}
          onClick={() => handleQuickAction(action)}
          disabled={isStreaming}
        />
      ))}
    </div>
  )
}
```

The hook integrates with multiple services including token management, GraphQL for message history, and real-time NATS messaging for live chat functionality. It handles complex state synchronization between streaming updates and historical message loading.
