A React hook that provides comprehensive chat functionality with real-time message streaming, approval handling, and NATS-based communication. It manages chat state, message sending/receiving, and integrates with various chat services and processors.

## Key Components

**Core State Management:**
- `isTyping` - Tracks if assistant is currently responding
- `natsStreaming` - Indicates active NATS streaming status
- `natsDialogId` - Current dialog identifier for NATS subscription
- `error` - Error state for chat operations
- `isLoadingHistory` - Loading state for message history

**Service Integrations:**
- `ChatApiService` - API service for sending messages and creating dialogs
- `useRealtimeChunkProcessor` - Processes incoming message chunks
- `useNatsDialogSubscription` - Manages NATS WebSocket subscription
- `useChatMessages` - Message state management
- `useChatApprovals` - Approval workflow handling
- `useChunkCatchup` - Handles message catchup on reconnection

**Key Methods:**
- `sendMessage(text: string)` - Sends user message and initiates assistant response
- `handleQuickAction(actionText: string)` - Sends predefined quick action messages
- `clearMessages()` - Resets chat state and messages

## Usage Example

```typescript
import { useChat } from './hooks/useChat'

function ChatComponent() {
  const { 
    messages, 
    sendMessage, 
    isTyping, 
    error,
    quickActions,
    handleQuickAction 
  } = useChat({
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model info:', metadata.modelName, metadata.providerName)
    }
  })

  const handleSubmit = async (text: string) => {
    await sendMessage(text)
  }

  return (
    <div>
      {error && <div className="error">{error}</div>}
      <MessageList messages={messages.messages} />
      {isTyping && <TypingIndicator />}
      <ChatInput onSubmit={handleSubmit} disabled={isTyping} />
      <QuickActions 
        actions={quickActions} 
        onAction={handleQuickAction} 
      />
    </div>
  )
}
```

The hook provides a complete chat interface with real-time streaming, approval workflows, message history management, and error handling. It supports both API-based and NATS-based communication patterns for flexible deployment scenarios.
