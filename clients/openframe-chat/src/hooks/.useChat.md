This React hook manages the complete chat functionality for the Flamingo/OpenFrame chat system, providing real-time messaging, NATS streaming, and chat history management. It serves as the main orchestrator for all chat-related operations including message sending, receiving, and approvals.

## Key Components

- **Core State Management**: Controls typing indicators, streaming status, error states, and dialog session management
- **Service Integration**: Integrates with ChatApiService, tokenService, and dialogGraphQLService for backend communication
- **Real-time Processing**: Handles NATS WebSocket subscriptions for live message streaming and chunk processing
- **Message Management**: Orchestrates message display, segmentation, and historical message loading
- **Approval System**: Manages command approvals and escalated approval workflows
- **Chunk Catchup**: Ensures message consistency when reconnecting or resuming dialogs

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const {
    messages,
    sendMessage,
    isTyping,
    error,
    clearMessages,
    handleQuickAction
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model info:', metadata.modelName, metadata.providerName)
    }
  })

  const handleSubmit = (text: string) => {
    sendMessage(text)
  }

  return (
    <div>
      <MessageList messages={messages.messages} />
      {isTyping && <TypingIndicator />}
      {error && <ErrorDisplay error={error} />}
      <MessageInput onSubmit={handleSubmit} />
    </div>
  )
}
```

The hook automatically handles token management, NATS subscription lifecycle, message persistence, and provides a complete chat experience with support for both API-based and real-time messaging patterns.
