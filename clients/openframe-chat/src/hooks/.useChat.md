A comprehensive React hook that manages real-time chat functionality with message processing, NATS streaming, and approval workflows. Provides a complete chat interface with historical message loading, typing indicators, and error handling.

## Key Components

- **Core Chat State**: Manages typing indicators, streaming status, error states, and message history
- **Real-time Processing**: Integrates NATS WebSocket subscription with chunk processing for live message updates
- **Message Management**: Handles user/assistant messages, approvals, and escalated approval workflows
- **API Integration**: Manages chat API service with token authentication and dialog creation
- **Chunk Catchup**: Synchronizes missed chunks when resuming interrupted conversations
- **Quick Actions**: Supports predefined quick action buttons for common responses

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const {
    messages,
    isTyping,
    error,
    sendMessage,
    clearMessages,
    quickActions,
    handleQuickAction
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model info:', metadata.modelName, metadata.providerName)
    }
  })

  const handleSubmit = async (text: string) => {
    await sendMessage(text)
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Assistant is typing...</div>}
      {error && <div className="error">{error}</div>}
      <input onSubmit={handleSubmit} />
      {quickActions.map(action => (
        <button key={action.text} onClick={() => handleQuickAction(action.text)}>
          {action.label}
        </button>
      ))}
    </div>
  )
}
```

The hook returns message arrays, loading states, and functions for sending messages and handling quick actions, making it easy to build complete chat interfaces.
