A comprehensive React hook that manages chat functionality with real-time messaging capabilities, integrating WebSocket subscriptions, approval workflows, and message processing for the Flamingo AI-powered MSP platform.

## Key Components

**Core State Management:**
- `isTyping`, `natsStreaming` - UI state indicators
- `natsDialogId` - Current dialog session identifier
- `error` - Error state management
- `token`, `apiBaseUrl` - Authentication and API configuration

**Service Integrations:**
- `ChatApiService` - REST API communication
- NATS WebSocket subscription for real-time messaging
- `tokenService` - Authentication token management
- `dialogGraphQLService` - Dialog data operations

**Custom Hooks:**
- `useChatMessages` - Message state and operations
- `useChatApprovals` - Approval workflow management
- `useRealtimeChunkProcessor` - Stream processing
- `useChunkCatchup` - Message synchronization
- `useNatsDialogSubscription` - WebSocket connection management

**Key Functions:**
- `sendMessage()` - Sends user messages and handles responses
- `handleQuickAction()` - Processes predefined quick actions
- `clearMessages()` - Resets chat state

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const { 
    messages, 
    sendMessage, 
    isTyping, 
    error,
    clearMessages,
    handleQuickAction 
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model info:', metadata.modelName, metadata.providerName)
    }
  })

  const handleSend = async (text: string) => {
    await sendMessage(text)
  }

  return (
    <div>
      {messages.messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Fae is typing...</div>}
      {error && <div>Error: {error}</div>}
      <button onClick={() => handleQuickAction("Help me with...")}>
        Quick Action
      </button>
    </div>
  )
}
```
