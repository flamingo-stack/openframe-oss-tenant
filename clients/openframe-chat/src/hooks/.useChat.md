A React hook that provides comprehensive chat functionality including real-time messaging, NATS subscription management, message history handling, and approval workflows for the Flamingo OpenFrame chat interface.

## Key Components

**Core State Management:**
- `isTyping` - Tracks typing indicator state
- `natsStreaming` - Real-time streaming status
- `natsDialogId` - Current dialog session identifier
- `error` - Error state handling
- `isLoadingHistory` - History loading state

**Service Integrations:**
- `ChatApiService` - API communication service
- `tokenService` - Authentication token management
- `useRealtimeChunkProcessor` - Real-time message chunk processing
- `useNatsDialogSubscription` - NATS WebSocket subscription
- `useChatMessages` - Message state management
- `useChatApprovals` - Approval workflow handling

**Key Functions:**
- `sendMessage(text: string)` - Send new chat messages
- `handleQuickAction(actionText: string)` - Execute predefined quick actions
- `clearMessages()` - Clear message history
- `waitForNatsSubscription()` - Ensure NATS connection before messaging

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const {
    messages,
    isTyping,
    error,
    sendMessage,
    handleQuickAction,
    clearMessages,
    quickActions
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model metadata:', metadata)
    }
  })

  const handleSend = async (text: string) => {
    await sendMessage(text)
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Fae is typing...</div>}
      {error && <div>Error: {error}</div>}
      
      <button onClick={() => handleSend('Hello!')}>
        Send Message
      </button>
      <button onClick={clearMessages}>
        Clear Chat
      </button>
    </div>
  )
}
```

The hook manages complex real-time chat state, handles reconnections, processes message chunks, and provides a clean interface for chat interactions with the Fae AI assistant.
