A React hook that provides comprehensive chat functionality for the OpenFrame platform, managing real-time messaging, NATS streaming, approvals, and API communication with Fae AI assistant.

## Key Components

- **Core State Management**: `isTyping`, `natsStreaming`, `error`, `token`, `apiBaseUrl`
- **Message Handling**: Integration with `useChatMessages`, `useChatApprovals`, and `useRealtimeChunkProcessor`
- **NATS Integration**: Real-time WebSocket communication via `useNatsDialogSubscription`
- **API Service**: Chat operations through `ChatApiService` and `dialogGraphQLService`
- **Chunk Processing**: Message streaming with catchup functionality via `useChunkCatchup`
- **Main Functions**:
  - `sendMessage()` - Send user messages and handle responses
  - `handleQuickAction()` - Execute predefined chat actions
  - `clearMessages()` - Reset chat state
  - `loadDialogHistory()` - Load previous conversations

## Usage Example

```typescript
import { useChat } from './useChat'

function ChatComponent() {
  const { 
    messages, 
    sendMessage, 
    isTyping, 
    error,
    quickActions,
    handleQuickAction 
  } = useChat({
    useApi: true,
    useNats: true,
    onMetadataUpdate: (metadata) => {
      console.log('Model:', metadata.modelName)
    }
  })

  const handleSend = (text: string) => {
    sendMessage(text)
  }

  return (
    <div>
      {messages.messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Fae is typing...</div>}
      {error && <div className="error">{error}</div>}
    </div>
  )
}
```

The hook manages complex real-time chat state including message streaming, approval workflows, dialog resumption, and error handling for seamless AI assistant interactions.
