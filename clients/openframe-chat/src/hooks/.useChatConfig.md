Manages chat configuration state, specifically loading and updating quick action shortcuts from a static JSON config file.

## Key Components

- **`QuickAction`** — Interface defining a quick action shape with `id` (string) and `text` (string) fields
- **`useChatConfig()`** — Custom React hook that initializes quick actions from `quickActions.json` on mount and exposes an updater function

## Usage Example

```typescript
import { useChatConfig } from './hooks/useChatConfig';

function ChatPanel() {
  const { quickActions, updateQuickActions } = useChatConfig();

  return (
    <div>
      {quickActions.map(action => (
        <button key={action.id}>{action.text}</button>
      ))}
      <button onClick={() => updateQuickActions([{ id: 'new', text: 'New Action' }])}>
        Reset Actions
      </button>
    </div>
  );
}
```

## Notes

- Quick actions are seeded from `../config/quickActions.json` via `useEffect` on mount
- `updateQuickActions` replaces the full actions array in state; persistence (e.g. `localStorage`) is not implemented but noted as a future extension point
