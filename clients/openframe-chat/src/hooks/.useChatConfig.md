Manages chat configuration state, specifically loading and updating quick action shortcuts from a JSON config file.

## Key Components

- **`QuickAction`** — Interface defining a quick action with `id` (string) and `text` (string) fields
- **`useChatConfig`** — Custom React hook that initializes quick actions from `quickActions.json` and exposes an updater function

## Usage Example

```typescript
import { useChatConfig } from './hooks/useChatConfig';

function ChatToolbar() {
  const { quickActions, updateQuickActions } = useChatConfig();

  return (
    <div>
      {quickActions.map(action => (
        <button key={action.id}>{action.text}</button>
      ))}
      <button onClick={() => updateQuickActions([{ id: '1', text: 'New Action' }])}>
        Reset Actions
      </button>
    </div>
  );
}
```

## Notes

- Quick actions are seeded from `../config/quickActions.json` on mount via `useEffect`
- `updateQuickActions` replaces the current state in memory; persistence (e.g. `localStorage` or API) is not implemented and can be added as needed
