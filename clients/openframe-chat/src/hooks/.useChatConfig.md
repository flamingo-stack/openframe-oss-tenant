Manages chat configuration state, specifically loading and updating quick action shortcuts from a static JSON config file.

## Key Components

- **`QuickAction`** — Interface defining a quick action with `id` (string) and `text` (string) fields
- **`useChatConfig`** — Custom React hook that initializes and exposes quick actions state
  - `quickActions` — Current array of `QuickAction` items loaded from `quickActions.json`
  - `updateQuickActions` — Setter to replace the quick actions array at runtime

## Usage Example

```typescript
import { useChatConfig, QuickAction } from './useChatConfig';

function ChatToolbar() {
  const { quickActions, updateQuickActions } = useChatConfig();

  const addAction = (newAction: QuickAction) => {
    updateQuickActions([...quickActions, newAction]);
  };

  return (
    <div>
      {quickActions.map(action => (
        <button key={action.id}>{action.text}</button>
      ))}
    </div>
  );
}
```

## Notes

- Quick actions are seeded from `../config/quickActions.json` on mount via `useEffect`
- `updateQuickActions` performs an in-memory update only — persistence (e.g. `localStorage`) is not yet implemented
