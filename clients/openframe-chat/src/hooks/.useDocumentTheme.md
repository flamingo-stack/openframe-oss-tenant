Reactively tracks the resolved document theme by observing the `data-theme` attribute on `<html>`, returning `'light'` or `'dark'` and re-rendering on changes.

## Key Components

| Export | Type | Description |
|---|---|---|
| `DocumentTheme` | Type | Union type `'light' \| 'dark'` representing resolved theme values |
| `useDocumentTheme` | Hook | React hook that returns the current document theme and subscribes to changes |
| `readDocumentTheme` | Internal function | Reads `data-theme` from `document.documentElement`; defaults to `'dark'` if absent |

## Usage Example

```typescript
import { useDocumentTheme } from './useDocumentTheme';

function ThemedComponent() {
  const theme = useDocumentTheme();

  return (
    <div style={{ background: theme === 'dark' ? '#1a1a1a' : '#ffffff' }}>
      Current theme: {theme}
    </div>
  );
}
```

## Behavior Notes

- **Default**: Treats a missing `data-theme` attribute as `'dark'` (ODS default)
- **MutationObserver**: Subscribes to `attributefilter: ['data-theme']` on `<html>` so the hook re-renders on any theme switch — including SYSTEM mode following OS preference changes
- **Cleanup**: Observer is disconnected on component unmount to prevent memory leaks
- **Set by**: Designed to pair with `useApplyAiAppearance`, which writes the resolved `data-theme` value including SYSTEM resolution
