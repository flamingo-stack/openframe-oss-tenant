Custom React hook that manages the full lifecycle of creating a support ticket, including form state, file attachment uploads, GraphQL submission, and user feedback via toasts.

## Key Components

| Export | Type | Description |
|---|---|---|
| `useCreateTicket` | Hook | Primary hook managing ticket creation form state and submission logic |
| `CreateTicketForm` | Interface | Shape of the form state: `subject`, `description`, and `attachments` |
| `uploadAttachments` | Internal function | Sequentially uploads files via pre-signed PUT URLs, returns temp attachment IDs |

### Hook Return Values

| Value | Type | Description |
|---|---|---|
| `form` | `CreateTicketForm` | Current form state |
| `setField` | `(key, value) => void` | Typed field updater |
| `isSubmitting` | `boolean` | `true` while mutation is in-flight |
| `handleSubmit` | `() => void` | Validates and triggers ticket creation |
| `resetForm` | `() => void` | Resets all fields to initial state |

## Usage Example

```typescript
import { useCreateTicket } from './hooks/useCreateTicket';

function NewTicketForm() {
  const { form, setField, isSubmitting, handleSubmit } = useCreateTicket(() => {
    // Optional: navigate away or close modal on success
    router.push('/tickets');
  });

  return (
    <form onSubmit={(e) => { e.preventDefault(); handleSubmit(); }}>
      <input
        value={form.subject}
        onChange={(e) => setField('subject', e.target.value)}
        placeholder="Subject"
      />
      <textarea
        value={form.description}
        onChange={(e) => setField('description', e.target.value)}
        placeholder="Description"
      />
      <input
        type="file"
        multiple
        onChange={(e) => setField('attachments', Array.from(e.target.files ?? []))}
      />
      <button type="submit" disabled={isSubmitting}>
        {isSubmitting ? 'Submitting...' : 'Create Ticket'}
      </button>
    </form>
  );
}
```

> **Note:** File uploads use pre-signed `PUT` URLs via `ticketGraphQlService.createTempAttachmentUploadUrl`. Each file is uploaded individually and sequentially — if any upload fails, the entire submission is aborted with a descriptive error toast.
