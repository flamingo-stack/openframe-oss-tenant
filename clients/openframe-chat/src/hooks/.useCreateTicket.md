React hook that manages the full lifecycle of ticket creation, including form state, file attachment uploads, and submission with toast notifications.

## Key Components

- **`CreateTicketForm`** — Interface defining form shape: `subject`, `description`, and `attachments` (File array)
- **`uploadAttachments`** — Async helper that requests a pre-signed upload URL per file, PUTs each file directly to storage, and returns temp attachment IDs
- **`useCreateTicket(onSuccess?)`** — Main hook export; orchestrates form state, validation, mutation, and cache invalidation

## Usage Example

```typescript
import { useCreateTicket } from './hooks/useCreateTicket';

function CreateTicketModal({ onClose }: { onClose: () => void }) {
  const { form, setField, isSubmitting, handleSubmit } = useCreateTicket(onClose);

  return (
    <form onSubmit={(e) => { e.preventDefault(); handleSubmit(); }}>
      <input
        value={form.subject}
        onChange={(e) => setField('subject', e.target.value)}
        placeholder="Subject"
      />
      <textarea
        value={form.description}
        onChange={(e) => setField('description', e.target.value)}
      />
      <input
        type="file"
        multiple
        onChange={(e) => setField('attachments', Array.from(e.target.files ?? []))}
      />
      <button type="submit" disabled={isSubmitting}>
        {isSubmitting ? 'Submitting...' : 'Create Ticket'}
      </button>
    </form>
  );
}
```

## Behavior Notes

- **Validation** — `handleSubmit` guards against empty subjects before firing the mutation
- **Attachments** — Uploaded sequentially via pre-signed PUT URLs; any failure throws a user-friendly error surfaced via toast
- **Cache** — On success, invalidates the `['tickets']` React Query key to refresh ticket lists
- **Reset** — Form clears automatically on successful submission; `resetForm` is also exposed for manual control
