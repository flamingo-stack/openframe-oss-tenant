Manages ticket creation state and submission logic, including file attachment uploads, form validation, and cache invalidation via React Query.

## Key Components

- **`CreateTicketForm`** — Interface defining the form shape: `subject`, `description`, and `attachments` (File array)
- **`uploadAttachments(files)`** — Async helper that requests a pre-signed upload URL per file, PUTs each file directly, and returns temp attachment IDs
- **`useCreateTicket(onSuccess?)`** — Main hook exposing form state, field setter, submit handler, reset, and pending state

## Usage Example

```typescript
import { useCreateTicket } from './hooks/useCreateTicket';

function NewTicketForm() {
  const { form, setField, isSubmitting, handleSubmit, resetForm } = useCreateTicket(() => {
    console.log('Ticket created, closing modal...');
  });

  return (
    <form onSubmit={(e) => { e.preventDefault(); handleSubmit(); }}>
      <input
        value={form.subject}
        onChange={(e) => setField('subject', e.target.value)}
        placeholder="Subject"
      />
      <textarea
        value={form.description}
        onChange={(e) => setField('description', e.target.value)}
      />
      <input
        type="file"
        multiple
        onChange={(e) => setField('attachments', Array.from(e.target.files ?? []))}
      />
      <button type="submit" disabled={isSubmitting}>
        {isSubmitting ? 'Submitting...' : 'Create Ticket'}
      </button>
    </form>
  );
}
```

## Behavior Notes

- **Validation** — `handleSubmit` blocks submission if `subject` is empty, showing a destructive toast
- **Attachments** — Each file is uploaded individually via a pre-signed URL before the ticket is created; failures surface per-file error messages
- **Post-submit** — On success, invalidates the `tickets` React Query cache, shows a success toast, resets the form, and calls the optional `onSuccess` callback
- **Error handling** — Network and API errors are caught and surfaced through the toast system
