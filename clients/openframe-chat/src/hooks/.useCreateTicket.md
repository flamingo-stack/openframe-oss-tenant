Manages the full lifecycle of ticket creation, including form state, file attachment uploads to pre-signed URLs, and GraphQL mutation submission with toast notifications.

## Key Components

- **`CreateTicketForm`** — Interface defining form fields: `subject`, `description`, and `attachments` (File array)
- **`uploadAttachments(files)`** — Internal async helper that requests a pre-signed upload URL per file, uploads via `PUT` fetch, and returns an array of temporary attachment IDs
- **`useCreateTicket(onSuccess?)`** — Primary hook export; returns form state and handlers

### Hook Return Values

| Property | Type | Description |
|---|---|---|
| `form` | `CreateTicketForm` | Current form state |
| `setField` | `(key, value) => void` | Typed field updater |
| `isSubmitting` | `boolean` | Mutation pending state |
| `handleSubmit` | `() => void` | Validates and triggers mutation |
| `resetForm` | `() => void` | Resets form to initial state |

## Usage Example

```typescript
import { useCreateTicket } from './hooks/useCreateTicket';

function NewTicketForm() {
  const { form, setField, isSubmitting, handleSubmit } = useCreateTicket(() => {
    router.push('/tickets');
  });

  return (
    <form onSubmit={(e) => { e.preventDefault(); handleSubmit(); }}>
      <input
        value={form.subject}
        onChange={(e) => setField('subject', e.target.value)}
        placeholder="Subject"
      />
      <textarea
        value={form.description}
        onChange={(e) => setField('description', e.target.value)}
      />
      <input
        type="file"
        multiple
        onChange={(e) => setField('attachments', Array.from(e.target.files ?? []))}
      />
      <button type="submit" disabled={isSubmitting}>
        {isSubmitting ? 'Submitting...' : 'Create Ticket'}
      </button>
    </form>
  );
}
```

> On submit, attachments are uploaded sequentially before the ticket GraphQL mutation fires. Any upload or API failure surfaces as a destructive toast with the specific error message.
