Provides a single source of truth for NATS WebSocket connection configuration in the openframe-chat module, managing auth token state and URL construction for NATS consumers.

## Key Components

- **`CHAT_NATS_CLIENT_CONFIG`** — Static NATS client identity constants (`name`, `user`, `pass`)
- **`CHAT_NATS_RECONNECTION_BACKOFF`** — Reconnection timing constants (`fastRetries`, `fastRetryDelayMs`)
- **`ChatNatsConfig`** — Interface describing the hook's return shape
- **`useChatNatsConfig()`** — Primary hook that wires token state, WS URL building, and reconnect logic into a single memoized config object

## Usage Example

```typescript
import { useChatNatsConfig, CHAT_NATS_CLIENT_CONFIG } from './useChatNatsConfig';

function ChatProvider() {
  const { getWsUrl, onBeforeReconnect, apiBaseUrl, token } = useChatNatsConfig();

  // Pass to both useConnectionStatus and useChat
  const wsUrl = getWsUrl(); // null until credentials are loaded

  return (
    <NatsConnection
      clientConfig={CHAT_NATS_CLIENT_CONFIG}
      wsUrl={wsUrl}
      onBeforeReconnect={onBeforeReconnect}
    />
  );
}
```

## Notes

- Token and API base URL state are driven by `tokenService` subscriptions — updates propagate automatically via the module-level singleton's pub/sub
- `getWsUrl()` returns `null` until both `apiBaseUrl` and `token` are available, preventing premature connection attempts
- `onBeforeReconnect` calls `tokenService.refreshToken()` before each reconnect, ensuring stale tokens are rotated automatically
- Designed to be consumed by both `useConnectionStatus` and `useChat` to eliminate duplicated NATS config logic
