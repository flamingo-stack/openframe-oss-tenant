Provides a single source of truth for NATS WebSocket URL construction, authentication token plumbing, and reconnection handling for the OpenFrame chat module.

## Key Components

### Constants

- **`CHAT_NATS_CLIENT_CONFIG`** — Static NATS client identity (`name`, `user`, `pass`) shared across chat consumers.
- **`CHAT_NATS_RECONNECTION_BACKOFF`** — Reconnection retry policy: 3 fast retries at 200ms intervals.

### Interface

- **`ChatNatsConfig`** — Shape returned by the hook:
  - `getWsUrl` — Builds the NATS WS URL from current credentials; returns `null` if not yet loaded.
  - `onBeforeReconnect` — Async callback that refreshes the auth token via `tokenService` before each reconnect attempt.
  - `apiBaseUrl` — Current API base URL from `tokenService`, or `null`.
  - `token` — Current auth token, or `null`.

### Hook

- **`useChatNatsConfig()`** — Subscribes to `tokenService` updates for both `token` and `apiBaseUrl`, memoizes the WS URL builder and reconnect handler, and exposes them as a stable `ChatNatsConfig` object. Eliminates duplicate token subscription logic across `useConnectionStatus` and `useChat`.

## Usage Example

```typescript
import { useChatNatsConfig, CHAT_NATS_CLIENT_CONFIG } from './useChatNatsConfig';

function useChatConnection() {
  const { getWsUrl, onBeforeReconnect, token } = useChatNatsConfig();

  useEffect(() => {
    const url = getWsUrl();
    if (!url) return; // credentials not ready yet

    const nc = connectNats({
      ...CHAT_NATS_CLIENT_CONFIG,
      servers: [url],
    });

    return () => nc.close();
  }, [getWsUrl, token]);
}
```

> **Token sync:** Because `tokenService` is a module-level singleton with its own pub/sub, all hook consumers share the same token state automatically — no prop drilling or context required.
