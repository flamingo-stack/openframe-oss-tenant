Provides a single source of truth for NATS WebSocket connection configuration within the openframe-chat module, consolidating URL building, auth-token state management, and reconnection logic into one reusable React hook.

## Key Components

- **`CHAT_NATS_CLIENT_CONFIG`** — Static NATS client identity constants (`name`, `user`, `pass`).
- **`CHAT_NATS_RECONNECTION_BACKOFF`** — Reconnection timing constants (`fastRetries`, `fastRetryDelayMs`).
- **`ChatNatsConfig`** — Interface describing the hook's return shape: `getWsUrl`, `onBeforeReconnect`, `apiBaseUrl`, `token`.
- **`useChatNatsConfig()`** — Core hook that subscribes to `tokenService` updates and exposes memoized NATS config to consumers.

## Usage Example

```typescript
import { useChatNatsConfig, CHAT_NATS_CLIENT_CONFIG } from './useChatNatsConfig';

function ChatProvider() {
  const { getWsUrl, onBeforeReconnect, token } = useChatNatsConfig();

  useEffect(() => {
    const wsUrl = getWsUrl();
    if (!wsUrl) return; // credentials not yet loaded

    const client = connectNats({
      ...CHAT_NATS_CLIENT_CONFIG,
      servers: [wsUrl],
      reconnect: true,
      reconnectDelayHandler: onBeforeReconnect,
    });

    return () => client.close();
  }, [getWsUrl, onBeforeReconnect]);
}
```

## Notes

- Token state stays synchronized across all consumers because `tokenService` is a module-level singleton with its own pub/sub — both `useConnectionStatus` and `useChat` can safely consume this hook without diverging state.
- `getWsUrl` returns `null` until both `apiBaseUrl` and `token` are available, preventing premature connection attempts.
- `onBeforeReconnect` triggers a `tokenService.refreshToken()` call before each NATS reconnect, ensuring stale tokens are rotated automatically.
