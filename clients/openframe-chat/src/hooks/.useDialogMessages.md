Fetches and processes paginated dialog messages for a conversation thread, transforming raw GraphQL data into structured chat messages with tool call handling and approval state management.

## Key Components

- **`useDialogMessages(dialogId, options)`** — Main hook that wraps `useInfiniteQuery` to load paginated messages for a given dialog
- **`UseDialogMessagesOptions`** — Interface for configuring enable state, approval callbacks (`onApprove`, `onReject`), and current `approvalStatuses`
- **`historicalMessages`** — Processed `Message[]` array via `processHistoricalMessages`, enriched with Fae avatar and approval metadata
- **`escalatedApprovals`** — Map of pending `CLIENT`-type approvals keyed by request ID, including command, explanation, and tool call data
- **`initialOptStartSeq`** — Max `lastChunkStreamSeq` across all loaded pages, used to seed optimistic streaming continuation
- **`reset`** — Clears all cached dialog message queries from the React Query client

## Usage Example

```typescript
const {
  historicalMessages,
  escalatedApprovals,
  hasNextPage,
  fetchNextPage,
  isFetchingNextPage,
  isLoading,
  reset,
} = useDialogMessages(dialogId, {
  enabled: true,
  approvalStatuses,
  onApprove: async (requestId) => {
    await approveToolCall(requestId);
  },
  onReject: async (requestId) => {
    await rejectToolCall(requestId);
  },
});
```

> Pages are fetched oldest-first by reversing the paginated response before passing nodes to `processHistoricalMessages`. Batch approval behavior is controlled by the `batch-approval` feature flag.
