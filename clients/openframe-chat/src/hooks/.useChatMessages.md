Manages chat message state for the Fae AI assistant interface, handling message lifecycle including streaming text accumulation, tool execution segments, approval workflows, and cross-message state updates.

## Key Components

**`useChatMessages(options)`**
Main hook accepting optional `onApprove` and `onReject` callbacks for approval request handling.

**Returned API**

| Method | Description |
|---|---|
| `messages` / `hasMessages` | Current message array and presence flag |
| `addMessage` | Appends a new message to the list |
| `ensureAssistantMessage` | Creates a blank Fae assistant bubble if none exists as the last message |
| `appendTextToCurrentMessage` | Streams text into the current assistant message via segment accumulator |
| `addToolSegmentToCurrentMessage` | Merges a `tool_execution` segment into the current assistant message |
| `appendSegmentsToLastAssistant` | Replays/merges segments into the last assistant message, with special handling for `context_compaction` |
| `updateApprovalStatusById` | Cross-message: flips `approval_request` or `approval_batch` status by `requestId` |
| `updateToolExecutionById` | Cross-message: merges `EXECUTING_TOOL`/`EXECUTED_TOOL` results into the originating segment or batch slot |
| `addErrorMessage` | Adds an error bubble, replacing an empty trailing assistant message if present |
| `clearMessages` | Resets all messages and the segment accumulator |
| `updateSegments` / `resetCurrentMessageSegments` | Direct segment replay and accumulator reset |
| `segmentAccumulator` | Exposes the underlying accumulator instance for advanced use |

## Usage Example

```typescript
const {
  messages,
  ensureAssistantMessage,
  appendTextToCurrentMessage,
  addToolSegmentToCurrentMessage,
  updateApprovalStatusById,
  clearMessages,
} = useChatMessages({
  onApprove: async (requestId) => {
    await approveRequest(requestId);
  },
  onReject: async (requestId) => {
    await rejectRequest(requestId);
  },
});

// Start a streaming assistant response
ensureAssistantMessage();
appendTextToCurrentMessage('Checking your tickets...');

// Inject a tool execution segment mid-stream
addToolSegmentToCurrentMessage({
  type: 'tool_execution',
  data: { type: 'EXECUTING_TOOL', toolTitle: 'List Tickets', toolExecutionRequestId: 'req-123' },
});

// Resolve an approval from a previous message
updateApprovalStatusById('req-456', 'approved');
```
