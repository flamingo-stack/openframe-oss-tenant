React hook for managing chat message state in the Fae AI assistant interface, handling message accumulation, tool execution segments, and approval workflow state across the message history.

## Key Components

### `UseChatMessagesOptions`
Configuration interface accepting optional `onApprove` and `onReject` callbacks for approval request handling.

### `useChatMessages(options?)`
Primary hook returning a full message management API:

| Return Value | Description |
|---|---|
| `messages` | Current `Message[]` state array |
| `hasMessages` | Boolean shorthand for non-empty state |
| `addMessage` | Appends any `Message` to the list |
| `ensureAssistantMessage` | Creates a Fae assistant bubble if none exists at the tail |
| `appendTextToCurrentMessage` | Streams text into the current assistant segment accumulator |
| `addToolSegmentToCurrentMessage` | Inserts a `tool_execution` segment into the current message |
| `appendSegmentsToLastAssistant` | Merges segment arrays into the most recent assistant message, with special handling for `context_compaction` |
| `updateSegments` | Replays and replaces segments on the last assistant message |
| `updateApprovalStatusById` | Cross-message scan to flip `approval_request` / `approval_batch` status by `requestId` |
| `updateToolExecutionById` | Cross-message scan to merge `EXECUTING_TOOL` / `EXECUTED_TOOL` results into the originating segment or batch slot |
| `addErrorMessage` | Adds an error bubble, replacing an empty trailing assistant message if present |
| `clearMessages` | Resets message list and segment accumulator |
| `segmentAccumulator` | Direct ref to the underlying accumulator instance |

## Usage Example

```typescript
import { useChatMessages } from './useChatMessages';

function ChatWindow() {
  const {
    messages,
    addMessage,
    ensureAssistantMessage,
    appendTextToCurrentMessage,
    updateApprovalStatusById,
    clearMessages,
  } = useChatMessages({
    onApprove: async (requestId) => {
      await approvalApi.approve(requestId);
    },
    onReject: async (requestId) => {
      await approvalApi.reject(requestId);
    },
  });

  // When streaming a response from Fae
  const handleStreamChunk = (chunk: string) => {
    ensureAssistantMessage();         // create bubble once
    appendTextToCurrentMessage(chunk); // stream text into it
  };

  // When an approval result arrives out-of-band
  const handleApprovalResult = (id: string, approved: boolean) => {
    updateApprovalStatusById(id, approved ? 'approved' : 'rejected');
  };

  return <MessageList messages={messages} onClear={clearMessages} />;
}
```
