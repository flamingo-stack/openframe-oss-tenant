Manages the full lifecycle of chat messages for the Fae AI assistant interface, including streaming text accumulation, tool execution tracking, approval state, and cross-message segment mutation.

## Key Components

**`UseChatMessagesOptions`**
Configuration interface accepting optional `onApprove` and `onReject` callbacks used when approval request segments are rendered.

**`useChatMessages(options?)`**
Primary hook that owns the `messages` state array and a stable `segmentAccumulator` ref (from `createMessageSegmentAccumulator`). Returns the full message management API.

### Returned API

| Method | Description |
|---|---|
| `addMessage` | Appends any `Message` to the list |
| `ensureAssistantMessage` | Guarantees a trailing assistant bubble exists before streaming begins |
| `appendTextToCurrentMessage` | Feeds streamed text chunks through the accumulator and updates the last assistant message |
| `addToolSegmentToCurrentMessage` | Attaches a `tool_execution` segment to the current assistant message |
| `appendSegmentsToLastAssistant` | Merges a batch of segments (including compaction state) into the most recent assistant message |
| `updateSegments` | Replays a full segment array via the accumulator and replaces the last assistant message |
| `updateApprovalStatusById` | Cross-message scan — flips `approved`/`rejected` status on matching `approval_request` or `approval_batch` segments |
| `updateToolExecutionById` | Cross-message scan — merges `EXECUTING_TOOL`/`EXECUTED_TOOL` data into a standalone segment or a batch execution slot |
| `addErrorMessage` | Adds an error bubble, replacing an empty trailing assistant message if present |
| `clearMessages` | Resets state and the accumulator |
| `segmentAccumulator` | Exposes the raw accumulator for direct use |

## Usage Example

```typescript
const {
  messages,
  ensureAssistantMessage,
  appendTextToCurrentMessage,
  addToolSegmentToCurrentMessage,
  updateApprovalStatusById,
  addErrorMessage,
  clearMessages,
} = useChatMessages({
  onApprove: async (requestId) => await approveAction(requestId),
  onReject: async (requestId) => await rejectAction(requestId),
});

// Start a streamed response
ensureAssistantMessage();
appendTextToCurrentMessage('Here is your result...');

// Attach a tool execution mid-stream
addToolSegmentToCurrentMessage({
  type: 'tool_execution',
  data: { type: 'EXECUTING_TOOL', toolExecutionRequestId: 'req-1', toolTitle: 'Search' },
});

// Resolve an approval from a later event
updateApprovalStatusById('req-42', 'approved');
```
