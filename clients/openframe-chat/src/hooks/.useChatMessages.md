Manages chat message state for an AI assistant conversation UI, handling streaming text, tool executions, approval workflows, and message lifecycle operations.

## Key Components

| Export | Type | Description |
|---|---|---|
| `useChatMessages` | Hook | Primary hook returning message state and mutation helpers |
| `UseChatMessagesOptions` | Interface | Optional `onApprove`/`onReject` callbacks for approval requests |

### Returned Functions

| Function | Description |
|---|---|
| `messages` | Current `Message[]` state array |
| `addMessage` | Appends a new message to the list |
| `ensureAssistantMessage` | Creates a new assistant bubble if the last message isn't one |
| `addErrorMessage` | Appends (or replaces empty assistant bubble with) a generic error message |
| `clearMessages` | Resets message list and segment accumulator |
| `appendTextToCurrentMessage` | Streams text into the active assistant message via segment accumulator |
| `addToolSegmentToCurrentMessage` | Adds a `tool_execution` segment to the current assistant message |
| `appendSegmentsToLastAssistant` | Merges arbitrary segments into the last assistant bubble; handles context compaction upserts |
| `updateSegments` | Replays a full segment list into the last assistant message |
| `updateApprovalStatusById` | Cross-message update: flips approval status by `requestId` across the dialog |
| `updateToolExecutionById` | Cross-message update: merges `EXECUTING_TOOL`/`EXECUTED_TOOL` results into their originating segment |
| `resetCurrentMessageSegments` | Resets the in-flight segment accumulator without clearing messages |

## Usage Example

```typescript
function ChatPanel() {
  const {
    messages,
    addMessage,
    ensureAssistantMessage,
    appendTextToCurrentMessage,
    addErrorMessage,
    clearMessages,
    updateApprovalStatusById,
  } = useChatMessages({
    onApprove: async (requestId) => { /* call approve API */ },
    onReject:  async (requestId) => { /* call reject API */ },
  });

  async function handleSend(text: string) {
    addMessage({ id: `user-${Date.now()}`, role: 'user', content: text, timestamp: new Date() });
    ensureAssistantMessage();

    try {
      for await (const chunk of streamResponse(text)) {
        appendTextToCurrentMessage(chunk);
      }
    } catch {
      addErrorMessage();
    }
  }

  return <MessageList messages={messages} onClear={clearMessages} />;
}
```

## Notes

- Uses `createMessageSegmentAccumulator` from `@flamingo-stack/openframe-frontend-core` to handle segment deduplication and replay during streaming.
- `appendSegmentsToLastAssistant` implements `upsertTrailingCompaction` logic, replacing only the last `started` compaction segment rather than any compaction segment.
- `updateToolExecutionById` scans messages newest-first to avoid stale interrupted cards claiming current tool runs; appends a new segment when no match exists.
- Coordinates with [`useAssistantBranding`](https://github.com/flamingo-stack/openframe-oss-tenant/blob/main/src/hooks/useAssistantBranding.ts) for the assistant display name and avatar used in generated message objects.
