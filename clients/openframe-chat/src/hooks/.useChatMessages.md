A React hook for managing chat messages in Flamingo's OpenFrame frontend, specifically handling AI assistant conversations with support for streaming text, tool executions, and approval workflows.

## Key Components

- **useChatMessages**: Main hook that manages a messages array and provides methods for chat interactions
- **Message Management**: Functions to add, update, and clear messages in the conversation
- **Segment Accumulator**: Integration with OpenFrame's message segment system for handling streaming responses
- **Assistant Message Handling**: Specialized functions for managing AI assistant messages with streaming text and tool segments
- **Error Handling**: Built-in error message creation and display functionality
