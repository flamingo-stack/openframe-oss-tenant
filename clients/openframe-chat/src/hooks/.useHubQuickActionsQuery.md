Provides a React Query hook for fetching OpenFrame's default quick actions from the Product Hub via the gateway proxy, scoped to the active API connection.

## Key Components

- **`hubQuickActionsQueryKey`** — Cache key factory that scopes queries to the active `apiBaseUrl`, preventing stale data across connection switches.
- **`useHubQuickActionsQuery`** — Query hook that fetches `HubQuickAction[]` from the hub. Only runs when both the caller's `enabled` flag is `true` and the API connection is ready (`connection.isReady`).

## Behavior

| Option | Value | Reason |
|---|---|---|
| `retry` | `1` | Fail fast on hub unavailability |
| `staleTime` | 60 s | Hub defaults change rarely |
| `refetchOnWindowFocus` | `true` | Keeps actions fresh after tab switch |
| `refetchOnReconnect` | `true` | Recovers after network interruption |

The `enabled` prop is intended to be driven by the tenant config's `quickActionsIsDefault` flag — callers skip this query entirely when the tenant has custom quick actions configured.

## Usage Example

```typescript
function QuickActionsPanel({ quickActionsIsDefault }: { quickActionsIsDefault: boolean }) {
  const { data: quickActions, isLoading } = useHubQuickActionsQuery({
    enabled: quickActionsIsDefault,
  });

  if (isLoading) return <Spinner />;

  return (
    <ul>
      {quickActions?.map((action) => (
        <li key={action.id}>{action.label}</li>
      ))}
    </ul>
  );
}
```
