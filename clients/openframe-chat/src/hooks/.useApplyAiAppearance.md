Applies AI appearance settings (theme and accent color) to the document root by setting `data-theme` attributes and injecting ODS CSS custom properties, with localStorage persistence to prevent flash-of-unstyled-content on reload.

## Key Components

- **`useApplyAiAppearance`** — Main hook; reads `aiSettings` via `useChatConfig` and applies theme/accent changes to `document.documentElement`
- **`persistTheme`** — Writes the raw `applicationTheme` value (`LIGHT | DARK | SYSTEM`) to `localStorage` under `openframe-chat-theme`
- **`persistAccent`** — Serializes pre-computed accent CSS variable map to `localStorage` under `openframe-chat-accent` for the pre-paint script in `index.html`
- **`ACCENT_VAR_SHADES`** — Mapping of ODS CSS custom properties (`--ods-accent`, `--color-accent-*`, `--ods-flamingo-pink-*`) to their shade variant (`base`, `hover`, `active`)

## Behavior

| Setting | Effect |
|---|---|
| No `applicationTheme` | Removes `data-theme`; ODS defaults to dark |
| `LIGHT` / `DARK` | Sets `data-theme="light"` or `data-theme="dark"` |
| `SYSTEM` | Tracks `prefers-color-scheme` live; cleans up listener on unmount |
| No `accentColor` | Removes all accent CSS vars; ODS defaults apply |
| Custom `accentColor` | Derives hover/active shades + readable initials color; injects all vars |

## Usage Example

```typescript
// Drop into your chat app root — no props needed.
// Settings are pulled from useChatConfig() internally.
function ChatApp() {
  useApplyAiAppearance();
  return <ChatShell />;
}
```

> **Note:** The hook does nothing while `isSettingsLoading` or `settingsUnavailable` is `true`, preserving any pre-paint values already applied by `index.html` — only a successfully resolved "no customization" answer reverts to defaults and clears the persisted values.
