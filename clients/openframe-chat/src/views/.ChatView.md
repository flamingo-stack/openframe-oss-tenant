A React component that renders the main chat interface for the Flamingo Fae AI assistant, handling message display, user input, and conversation management including resumable dialogs and quick actions.

## Key Components

- **ChatView** - Main functional component providing the complete chat interface
- **State Management** - Manages current AI model configuration and resumable dialog state
- **Chat Integration** - Uses `useChat` hook for message handling and conversation flow
- **Connection Monitoring** - Integrates `useConnectionStatus` for real-time connection status
- **UI Layout** - Renders structured chat with header, content area, and footer sections

## Usage Example

```typescript
import { ChatView } from './ChatView'

// Basic usage - renders complete chat interface
function App() {
  return (
    <div className="h-screen">
      <ChatView />
    </div>
  )
}

// The component automatically handles:
// - Message sending and receiving
// - Connection status monitoring
// - Model configuration display
// - Resumable dialog management
// - Quick action interactions
```

The component provides two main states: an empty state with welcome message and quick actions, and an active conversation state with message history. It automatically fetches resumable dialogs on mount and updates the AI model display based on connection metadata.
