A React component that provides a complete chat interface for the Flamingo OpenFrame platform, handling real-time messaging, conversation resumption, and quick actions with AI models.

## Key Components

- **Main Component**: `ChatView` - Complete chat interface with header, content, and footer
- **State Management**: Manages current AI model, resumable dialogs, and chat metadata
- **Custom Hooks**: 
  - `useChat` - Handles messaging, streaming, and quick actions
  - `useConnectionStatus` - Monitors server connection status
- **Services Integration**: 
  - `supportedModelsService` - Model display name resolution
  - `dialogGraphQLService` - Resumable dialog management

## Usage Example

```typescript
import { ChatView } from './components/ChatView'

function App() {
  return (
    <div className="app">
      <ChatView />
    </div>
  )
}
```

The component automatically:
- Displays welcome screen with quick actions when no messages exist
- Shows resumable conversations from previous sessions
- Handles real-time messaging with typing indicators
- Manages AI model selection and display
- Provides connection status feedback
- Supports both API and NATS messaging (configurable via features)

The interface adapts its layout based on whether there are active messages, showing either a centered welcome screen or a full message list view.
