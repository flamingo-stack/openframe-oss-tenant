A React component that renders the main chat interface for Flamingo's AI assistant, managing conversation state, model information, and user interactions with support for resumable dialogs and quick actions.

## Key Components

- **ChatView** - Main component that orchestrates the chat interface
- **State Management** - Handles current model info and resumable dialog state
- **Chat Hooks** - Integrates `useChat` for messaging and `useConnectionStatus` for server connectivity
- **UI Components** - Uses OpenFrame frontend components for consistent chat layout
- **Resume Functionality** - Allows users to continue previous conversations
- **Quick Actions** - Provides predefined help options when no messages exist

## Usage Example

```typescript
import { ChatView } from './ChatView'

// Basic usage - renders complete chat interface
function App() {
  return (
    <div className="h-screen">
      <ChatView />
    </div>
  )
}

// The component handles all chat functionality internally:
// - Message sending/receiving
// - Model selection display
// - Connection status monitoring
// - Dialog resumption
// - Quick action handling
```

The component automatically adapts its layout based on conversation state - showing a welcome screen with quick actions when empty, or the full message list when active. It integrates with Flamingo's backend services for dialog management and supports both API and NATS messaging based on feature configuration.
