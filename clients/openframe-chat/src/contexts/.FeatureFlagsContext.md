Provides a React context for managing feature flags lifecycle, including async loading, error handling, and a 10-second fallback timeout that defaults to `DEFAULT_FEATURE_FLAGS` if flags cannot be fetched.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `FeatureFlagsProvider` | Component | Wraps the app; fetches flags once `tokenService` has a valid token and API URL |
| `FeatureFlagsGate` | Component | Renders `null` until flags are loaded — use to block rendering of flag-dependent UI |
| `useFeatureFlags` | Hook | Returns `{ flags, isLoaded, isError }` from context; throws if used outside provider |
| `FeatureFlagsContext` | Context | Internal context — consume via `useFeatureFlags` |

## Usage Example

```typescript
// Wrap your app with the provider
function App() {
  return (
    <FeatureFlagsProvider>
      <FeatureFlagsGate>
        <MainLayout />
      </FeatureFlagsGate>
    </FeatureFlagsProvider>
  );
}

// Consume flags in any child component
function MyFeature() {
  const { flags, isLoaded, isError } = useFeatureFlags();

  if (isError) return <p>Using default feature flags</p>;

  return flags.myNewFeature ? <NewUI /> : <LegacyUI />;
}
```

## Behavior Notes

- **Auth-gated fetching** — the query only fires after `tokenService` provides both a token and an API base URL, avoiding unauthenticated requests.
- **Fallback timeout** — if flags do not resolve within `10 000 ms`, defaults are applied and `isError` is set to `true`.
- **`FeatureFlagsGate`** — useful at route or layout level to prevent flickering before flags are known.
