Provides a React context for managing feature flags lifecycle, including async fetching, error handling, and a 10-second fallback timeout that defaults to `DEFAULT_FEATURE_FLAGS` if flags fail to load.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `FeatureFlagsProvider` | Component | Context provider that fetches flags once `tokenService` has a valid token and API URL |
| `FeatureFlagsGate` | Component | Renders `null` until flags are fully loaded — use to block UI until flags resolve |
| `useFeatureFlags` | Hook | Returns `{ flags, isLoaded, isError }` — throws if used outside the provider |

## Behavior Notes

- **Auth-aware:** Waits for `tokenService` to provide both a token and API base URL before triggering the flags query
- **Error recovery:** On query failure, falls back to `DEFAULT_FEATURE_FLAGS` and sets `isError: true`
- **Timeout safety:** If flags haven't loaded within 10 seconds, defaults are applied automatically

## Usage Example

```typescript
// Wrap your app with the provider
function App() {
  return (
    <FeatureFlagsProvider>
      <FeatureFlagsGate>
        <MainApp />
      </FeatureFlagsGate>
    </FeatureFlagsProvider>
  );
}

// Consume flags in any child component
function MyFeature() {
  const { flags, isLoaded, isError } = useFeatureFlags();

  if (isError) return <p>Running with default flags</p>;

  return flags.myFeatureEnabled ? <NewUI /> : <LegacyUI />;
}
```
