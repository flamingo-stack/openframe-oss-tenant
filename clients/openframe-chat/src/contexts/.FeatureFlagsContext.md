Provides a React context for managing feature flags, handling async loading with token-aware initialization, error fallback, and a 10-second safety timeout before defaulting to `DEFAULT_FEATURE_FLAGS`.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `FeatureFlagsProvider` | Component | Context provider that fetches flags once a token and API URL are available |
| `FeatureFlagsGate` | Component | Renders children only after flags have finished loading |
| `useFeatureFlags` | Hook | Returns `{ flags, isLoaded, isError }` from context; throws if used outside provider |

## Usage Example

```typescript
// Wrap your app with the provider
import { FeatureFlagsProvider, FeatureFlagsGate, useFeatureFlags } from './FeatureFlagsContext';

function App() {
  return (
    <FeatureFlagsProvider>
      <FeatureFlagsGate>
        <MainApp />
      </FeatureFlagsGate>
    </FeatureFlagsProvider>
  );
}

// Consume flags in any child component
function MainApp() {
  const { flags, isLoaded, isError } = useFeatureFlags();

  if (isError) {
    console.warn('Running with default feature flags');
  }

  return flags.newDashboard ? <NewDashboard /> : <LegacyDashboard />;
}
```

## Behavior Notes

- **Token-gated**: Flag fetching is deferred until both a token and API base URL are available via `tokenService`
- **Fallback timeout**: If flags fail to load within 10 seconds, defaults are applied and `isError` is set to `true`
- **`FeatureFlagsGate`**: Useful for preventing flicker by blocking renders until the flag state is resolved
