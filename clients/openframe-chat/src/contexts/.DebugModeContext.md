React context module that manages debug mode state for a Tauri desktop application, fetching the initial value from the Rust backend via IPC and exposing it to the component tree.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `DebugModeProvider` | Component | Context provider that fetches initial debug state from the Tauri `get_debug_mode` command on mount |
| `useDebugMode` | Hook | Consumes `DebugModeContext`; throws if used outside the provider |
| `DebugModeContextType` | Interface | Shape of the context value: `debugMode: boolean` and `setDebugMode` setter |

## Usage Example

```typescript
// Wrap your app (or subtree) with the provider
import { DebugModeProvider, useDebugMode } from './DebugModeContext';

function App() {
  return (
    <DebugModeProvider>
      <MyFeature />
    </DebugModeProvider>
  );
}

// Consume in any child component
function MyFeature() {
  const { debugMode, setDebugMode } = useDebugMode();

  return (
    <div>
      <p>Debug mode is {debugMode ? 'ON' : 'OFF'}</p>
      <button onClick={() => setDebugMode(!debugMode)}>
        Toggle Debug
      </button>
    </div>
  );
}
```

## Notes

- Initial state is fetched asynchronously from the Rust backend via `invoke('get_debug_mode')`. On failure, `debugMode` defaults to `false`.
- `setDebugMode` updates React state only — persisting the change back to the backend requires a separate Tauri `invoke` call in the consumer.
- `useDebugMode` throws a descriptive error when called outside `DebugModeProvider`, preventing silent context misuse.
