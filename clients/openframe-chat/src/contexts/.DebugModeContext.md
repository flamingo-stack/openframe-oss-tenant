React context module that manages debug mode state for a Tauri desktop application, initializing the flag by invoking the native `get_debug_mode` command on mount.

## Key Components

- **`DebugModeContextType`** — Interface defining `debugMode: boolean` and `setDebugMode` setter
- **`DebugModeProvider`** — Context provider that fetches the initial debug state from the Tauri backend via `invoke('get_debug_mode')` and exposes it to the component tree
- **`useDebugMode`** — Consumer hook that returns `{ debugMode, setDebugMode }`, throwing if used outside the provider

## Usage Example

```typescript
// Wrap your app (or subtree) with the provider
import { DebugModeProvider } from './DebugModeContext';

function App() {
  return (
    <DebugModeProvider>
      <MainLayout />
    </DebugModeProvider>
  );
}

// Consume in any child component
import { useDebugMode } from './DebugModeContext';

function DebugPanel() {
  const { debugMode, setDebugMode } = useDebugMode();

  return (
    <div>
      <p>Debug mode is {debugMode ? 'enabled' : 'disabled'}</p>
      <button onClick={() => setDebugMode(!debugMode)}>Toggle</button>
    </div>
  );
}
```

> **Note:** The initial value is always fetched from the Tauri backend. If the `get_debug_mode` invocation fails, `debugMode` defaults to `false` and the error is logged to the console. Manual calls to `setDebugMode` update React state only and do not persist back to the backend.
