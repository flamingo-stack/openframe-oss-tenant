React context that manages debug mode state, syncing its initial value from the Tauri backend via the `get_debug_mode` command on mount.

## Key Components

- **`DebugModeProvider`** — Context provider that fetches the initial debug mode state from the Tauri backend and exposes it to the component tree.
- **`useDebugMode`** — Custom hook that consumes `DebugModeContext`; throws if used outside of `DebugModeProvider`.
- **`DebugModeContextType`** — Interface defining `debugMode: boolean` and `setDebugMode` setter.

## Usage Example

```typescript
// Wrap your app or feature subtree
import { DebugModeProvider, useDebugMode } from './DebugModeContext';

function App() {
  return (
    <DebugModeProvider>
      <MyComponent />
    </DebugModeProvider>
  );
}

// Consume in any child component
function MyComponent() {
  const { debugMode, setDebugMode } = useDebugMode();

  return (
    <button onClick={() => setDebugMode(!debugMode)}>
      Debug is {debugMode ? 'ON' : 'OFF'}
    </button>
  );
}
```

## Notes

- Initial state is fetched once on mount via Tauri's `invoke('get_debug_mode')`; falls back to `false` on error.
- `setDebugMode` updates React state only — if persistence back to the Tauri backend is needed, extend the setter to call a corresponding Tauri command.
- Must be rendered above any component that calls `useDebugMode`, or the hook will throw.
