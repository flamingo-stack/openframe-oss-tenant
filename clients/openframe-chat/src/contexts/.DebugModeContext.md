React context module that manages debug mode state for a Tauri desktop application, syncing the initial value from the Rust backend via IPC on mount.

## Key Components

- **`DebugModeProvider`** — Context provider that fetches the initial debug mode state from the Tauri backend (`get_debug_mode` command) and exposes it to the component tree.
- **`useDebugMode`** — Custom hook that consumes the context, returning `{ debugMode, setDebugMode }`. Throws if used outside a `DebugModeProvider`.
- **`DebugModeContextType`** — Interface defining the context shape: a boolean `debugMode` flag and its setter.

## Usage Example

```typescript
// Wrap your app (or subtree) with the provider
import { DebugModeProvider } from './DebugModeContext';

function App() {
  return (
    <DebugModeProvider>
      <MainLayout />
    </DebugModeProvider>
  );
}

// Consume in any child component
import { useDebugMode } from './DebugModeContext';

function DiagnosticsPanel() {
  const { debugMode, setDebugMode } = useDebugMode();

  return (
    <div>
      <p>Debug mode is {debugMode ? 'ON' : 'OFF'}</p>
      <button onClick={() => setDebugMode(!debugMode)}>
        Toggle Debug Mode
      </button>
    </div>
  );
}
```

> **Note:** `setDebugMode` updates React state only. If you need the change to persist to the Tauri backend, call the corresponding `invoke` command alongside the state setter.
