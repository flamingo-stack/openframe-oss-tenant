Defines the feature flag system for the Flamingo platform, providing a strongly-typed registry of available feature flags and their default states.

## Key Components

- **`FEATURE_FLAG_NAMES`** — Const tuple of all valid feature flag identifiers (`thinking`, `batch-approval`, `ai-streaming-jetstream`, `ticket-statuses`)
- **`FeatureFlagName`** — Union type derived from the const tuple, ensuring type-safe flag references
- **`DEFAULT_FEATURE_FLAGS`** — Record mapping every flag to its default boolean state (all `false` by default)
- **`FeatureFlags`** — Type alias for a full `Record<FeatureFlagName, boolean>` map

## Usage Example

```typescript
import { DEFAULT_FEATURE_FLAGS, FeatureFlagName, FeatureFlags } from './features';

// Merge persisted flags with defaults
function resolveFlags(overrides: Partial<FeatureFlags>): FeatureFlags {
  return { ...DEFAULT_FEATURE_FLAGS, ...overrides };
}

// Type-safe flag check
function isEnabled(flags: FeatureFlags, name: FeatureFlagName): boolean {
  return flags[name];
}

const flags = resolveFlags({ thinking: true });
isEnabled(flags, 'thinking');       // true
isEnabled(flags, 'batch-approval'); // false
```

> **Adding a new flag:** append its name to `FEATURE_FLAG_NAMES` and add a default entry in `DEFAULT_FEATURE_FLAGS`. TypeScript will enforce consistency across both structures automatically.
