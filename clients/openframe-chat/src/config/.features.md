Defines the available feature flags for the Flamingo platform, providing a typed registry of feature toggles with their default states.

## Key Components

- **`FEATURE_FLAG_NAMES`** — Readonly tuple of all valid feature flag identifiers (`thinking`, `batch-approval`, `ai-streaming-jetstream`, `ticket-statuses`)
- **`FeatureFlagName`** — Union type derived from the flag names array, ensuring type-safe flag references
- **`DEFAULT_FEATURE_FLAGS`** — Record mapping every flag to its default boolean value (all `false` by default)
- **`FeatureFlags`** — Type alias for a full record of flag name → boolean mappings

## Usage Example

```typescript
import { DEFAULT_FEATURE_FLAGS, FeatureFlagName, FeatureFlags } from './features';

// Check a specific flag
const flags: FeatureFlags = { ...DEFAULT_FEATURE_FLAGS, thinking: true };

function isEnabled(flag: FeatureFlagName): boolean {
  return flags[flag];
}

isEnabled('thinking');        // true
isEnabled('batch-approval');  // false
```
