Defines the feature flag registry for the OpenFrame tenant, declaring all available feature flags and their default states.

## Key Components

- **`FEATURE_FLAG_NAMES`** — Readonly tuple of all valid feature flag identifiers (`'batch-approval'`, `'customer-ai-assistant-settings'`, `'notifications'`).
- **`FeatureFlagName`** — Union type derived from `FEATURE_FLAG_NAMES`, ensuring type-safe flag references.
- **`DEFAULT_FEATURE_FLAGS`** — Default state map for all flags; all flags default to `false`.
- **`FeatureFlags`** — Type alias for a complete record mapping every `FeatureFlagName` to a boolean.

## Usage Example

```typescript
import {
  DEFAULT_FEATURE_FLAGS,
  FeatureFlags,
  FeatureFlagName,
} from './features';

// Merge tenant-specific overrides with defaults
function resolveFlags(overrides: Partial<FeatureFlags>): FeatureFlags {
  return { ...DEFAULT_FEATURE_FLAGS, ...overrides };
}

// Type-safe flag check
function isEnabled(flags: FeatureFlags, name: FeatureFlagName): boolean {
  return flags[name];
}

const tenantFlags = resolveFlags({ notifications: true });
console.log(isEnabled(tenantFlags, 'notifications')); // true
console.log(isEnabled(tenantFlags, 'batch-approval')); // false
```

## Notes

- Adding a new flag requires updating **both** `FEATURE_FLAG_NAMES` and `DEFAULT_FEATURE_FLAGS` — TypeScript will enforce completeness via the `Record<FeatureFlagName, boolean>` constraint.
