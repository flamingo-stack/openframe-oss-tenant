React application entry point that bootstraps the app by mounting the root `App` component into the DOM using React 18's concurrent rendering API.

## Key Components

- **`ReactDom.createRoot`** — Initializes React 18's concurrent root on the `#root` DOM element
- **`React.StrictMode`** — Wraps the app to enable development-time warnings and checks
- **`App`** — Top-level application component imported from `./App`

## Usage Example

```typescript
// index.html must contain a root element:
// <div id="root"></div>

// main.tsx mounts the app automatically on page load
ReactDom.createRoot(document.getElementById('root')!).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>,
);
```

> This file is the standard Vite + React entry point and typically requires no modification. App-level providers (routing, state, themes) should be added inside `App.tsx` rather than here.
