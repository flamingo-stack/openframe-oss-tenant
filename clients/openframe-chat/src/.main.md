The application entry point that bootstraps the React app by mounting the root `App` component into the DOM.

## Key Components

- **`ReactDom.createRoot`** — Creates a React root attached to the `#root` DOM element
- **`React.StrictMode`** — Wraps the app to enable additional runtime warnings and checks during development
- **`App`** — The top-level application component rendered into the root

## Usage Example

```typescript
// index.html must contain a root element:
// <div id="root"></div>

// main.tsx mounts the app:
ReactDom.createRoot(document.getElementById('root')!).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>,
);
```

> This file is the Vite/React entry point and is typically not modified directly. Changes to app structure, routing, or global providers should be made in `App.tsx`.
