Entry point for the React application that mounts the root `App` component into the DOM.

## Key Components

- **`ReactDom.createRoot`** — Creates a React root using the DOM element with id `root`
- **`React.StrictMode`** — Wraps the app to enable additional runtime warnings and checks during development
- **`App`** — The top-level application component being rendered

## Usage Example

```typescript
// index.html must contain a root element:
// <div id="root"></div>

// main.tsx bootstraps the app:
ReactDom.createRoot(document.getElementById('root')!).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>,
);
```

> **Note:** The `!` non-null assertion on `getElementById('root')` assumes the root element always exists in the HTML. Ensure your `index.html` contains `<div id="root"></div>` to avoid runtime errors.
