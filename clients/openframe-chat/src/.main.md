The application entry point that bootstraps the React application by mounting the root `App` component into the DOM.

## Key Components

- **`ReactDom.createRoot`** – Creates a React root on the `#root` DOM element and renders the component tree
- **`React.StrictMode`** – Wraps the app to enable additional runtime warnings and checks during development
- **`App`** – The top-level application component imported from `./App`

## Usage Example

This file is executed automatically by the bundler (e.g. Vite) as the entry point. The corresponding `index.html` must contain a root element:

```html
<div id="root"></div>
```

The module then mounts the full React tree:

```typescript
ReactDom.createRoot(document.getElementById('root')!).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>,
);
```

> **Note:** The non-null assertion (`!`) assumes `#root` always exists in the HTML. If the element is missing at runtime, this will throw.
