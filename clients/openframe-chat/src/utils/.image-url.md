Utility module for constructing and cache-busting image URLs in the OpenFrame tenant client, using the current tenant's API base URL from `tokenService`.

## Key Components

| Export | Signature | Description |
|--------|-----------|-------------|
| `getFullImageUrl` | `(imageUrl, hash?) => string \| undefined` | Resolves a relative or absolute image path to a full URL prefixed with the tenant API host, with optional cache-busting |
| `appendImageHash` | `<T extends string \| null \| undefined>(imageUrl, hash?) => T` | Appends `?v=<hash>` (or `&v=<hash>`) to any URL for cache-busting without modifying the URL's base form |
| `getAiAvatarUrl` | `(clientViewId, hash?) => string \| undefined` | Builds the chat backend URL for an AI assistant avatar image, resolving to a presigned bucket redirect |
| `buildFullUrl` *(internal)* | `(imageUrl) => string` | Normalises relative paths (`/chat/...`, `/...`, or bare paths) by prepending the tenant host |

## Usage Example

```typescript
import { getFullImageUrl, appendImageHash, getAiAvatarUrl } from './image-url';

// Resolve a relative path to a full tenant URL with cache-busting
const logoUrl = getFullImageUrl('/logos/company.png', 'abc123');
// → "https://tenant.api.example.com/chat/logos/company.png?v=abc123"

// Add cache-busting to a URL the caller already resolved
const cachedUrl = appendImageHash('https://cdn.example.com/avatar.png', 'def456');
// → "https://cdn.example.com/avatar.png?v=def456"

// Get AI assistant avatar URL for a ClientView
const avatarUrl = getAiAvatarUrl('cv_789', 'xyz001');
// → "https://tenant.api.example.com/chat/images/client-agent-settings/cv_789/url?v=xyz001"

// Returns undefined safely when no URL is provided
const missing = getFullImageUrl(null); // → undefined
```

## Path Resolution Rules (`buildFullUrl`)

```text
Input form                    →  Resolved output
──────────────────────────────────────────────────
https://...  /  http://...   →  Used as-is (absolute URL)
/chat/images/foo.png         →  {tenantHost}/chat/images/foo.png
/images/foo.png              →  {tenantHost}/chat/images/foo.png
images/foo.png               →  {tenantHost}/chat/images/foo.png
```
