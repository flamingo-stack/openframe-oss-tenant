Normalizes tool execution display titles across paired `EXECUTING_TOOL` / `EXECUTED_TOOL` backend events, ensuring the human-readable `title` field persists through the full execution lifecycle instead of being overwritten by the raw `toolFunction` value on completion.

## Key Components

- **`ToolLike`** — Type describing a tool event payload with optional `type`, `title`, `toolFunction`, and `toolExecutionRequestId` fields.
- **`titleByExecutionId`** — In-memory `Map` (capped at 1,000 entries, LRU-evicts oldest) storing `toolExecutionRequestId → title` across event pairs.
- **`rememberTitle(id, title)`** — Internal helper that persists a title into the map, evicting the oldest entry when the size limit is reached.
- **`overrideToolTitle<T>(data)`** — Core transform: sets `toolFunction = title` on `EXECUTING_TOOL` events and replays the stored title on the matching `EXECUTED_TOOL` event.
- **`applyToolTitleToMessage<T>(message)`** — Convenience wrapper that applies `overrideToolTitle` to `messageData`, handling both array and single-object shapes.

## Usage Example

```typescript
import { overrideToolTitle, applyToolTitleToMessage } from './applyToolTitle';

// Single event override
const executing = overrideToolTitle({
  type: 'EXECUTING_TOOL',
  title: 'Fetch Open Tickets',
  toolFunction: 'get_tickets_raw',
  toolExecutionRequestId: 'req-123',
});
// → { ..., toolFunction: 'Fetch Open Tickets' }

const executed = overrideToolTitle({
  type: 'EXECUTED_TOOL',
  toolFunction: 'get_tickets_raw',
  toolExecutionRequestId: 'req-123',
});
// → { ..., toolFunction: 'Fetch Open Tickets' } (recalled from map)

// Applied to a full message payload
const message = applyToolTitleToMessage({
  messageData: [executing, executed],
});
```
