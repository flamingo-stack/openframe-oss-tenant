Normalizes tool execution block titles across paired `EXECUTING_TOOL` / `EXECUTED_TOOL` SSE payloads, ensuring the human-readable `title` field persists through the full execution lifecycle instead of being overwritten by the raw `toolFunction` value on completion.

## Key Components

- **`ToolLike`** — Interface describing tool execution payload shape with optional `type`, `title`, `toolFunction`, and `toolExecutionRequestId` fields
- **`titleByExecutionId`** — Module-level LRU-style `Map` (capped at 1 000 entries) storing `toolExecutionRequestId → title` for cross-event persistence
- **`rememberTitle(id, title)`** — Private helper that stores a title and evicts the oldest entry when the map is at capacity
- **`overrideToolTitle<T>(data)`** — Core transform; sets `toolFunction = title` on `EXECUTING_TOOL` events and re-applies the stored title on matching `EXECUTED_TOOL` events
- **`applyToolTitleToMessage<T>(message)`** — Top-level helper that applies `overrideToolTitle` to `messageData`, handling both array and single-object shapes

## Usage Example

```typescript
import { applyToolTitleToMessage, overrideToolTitle } from './applyToolTitle';

// Single payload transform
const executing = overrideToolTitle({
  type: 'EXECUTING_TOOL',
  title: 'Fetching device list',
  toolFunction: 'get_devices',
  toolExecutionRequestId: 'req-abc123',
});
// → { ..., toolFunction: 'Fetching device list' }

// Matching completion event — title is re-applied from cache
const executed = overrideToolTitle({
  type: 'EXECUTED_TOOL',
  toolFunction: 'get_devices',
  toolExecutionRequestId: 'req-abc123',
});
// → { ..., toolFunction: 'Fetching device list' }

// Applied to a full message object
const message = applyToolTitleToMessage({
  id: 'msg-1',
  messageData: [executingPayload, executedPayload],
});
```
