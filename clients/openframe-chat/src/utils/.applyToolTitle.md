Normalizes tool execution block titles across paired `EXECUTING_TOOL` and `EXECUTED_TOOL` SSE events, ensuring the human-readable `title` field persists after tool completion instead of being overwritten by the raw `toolFunction` value.

## Key Components

- **`ToolLike`** — Interface describing the shape of tool execution payloads, with optional `type`, `title`, `toolFunction`, and `toolExecutionRequestId` fields.
- **`titleByExecutionId`** — Module-level `Map` caching up to 1,000 `toolExecutionRequestId → title` entries using an LRU-style eviction strategy.
- **`rememberTitle(id, title)`** — Internal helper that stores a title by execution ID, evicting the oldest entry when the cache reaches `MAX_ENTRIES`.
- **`overrideToolTitle<T>(data)`** — Core transform. On `EXECUTING_TOOL`, caches the title and sets `toolFunction = title`. On `EXECUTED_TOOL`, replays the cached title onto `toolFunction`. Falls back to the original payload when no title is found.
- **`applyToolTitleToMessage<T>(message)`** — Convenience wrapper that applies `overrideToolTitle` to a message's `messageData`, handling both array and single-object shapes.

## Usage Example

```typescript
import { applyToolTitleToMessage, overrideToolTitle } from './applyToolTitle';

// Standalone payload transform
const executing = overrideToolTitle({
  type: 'EXECUTING_TOOL',
  title: 'Searching Knowledge Base',
  toolFunction: 'search_kb',
  toolExecutionRequestId: 'req-123',
});
// → { ..., toolFunction: 'Searching Knowledge Base' }

const executed = overrideToolTitle({
  type: 'EXECUTED_TOOL',
  toolFunction: 'search_kb',
  toolExecutionRequestId: 'req-123',
});
// → { ..., toolFunction: 'Searching Knowledge Base' }

// Message-level transform (handles array or object messageData)
const message = applyToolTitleToMessage({
  messageData: [
    { type: 'EXECUTED_TOOL', toolExecutionRequestId: 'req-123', toolFunction: 'search_kb' },
  ],
});
```
