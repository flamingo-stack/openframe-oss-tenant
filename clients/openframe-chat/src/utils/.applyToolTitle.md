Normalizes tool execution display titles across paired `EXECUTING_TOOL` / `EXECUTED_TOOL` backend events, ensuring the human-readable `title` field persists through both lifecycle stages instead of being overwritten by the raw `toolFunction` value.

## Key Components

- **`ToolLike`** — Interface describing the minimal shape of a tool event payload (`type`, `title`, `toolFunction`, `toolExecutionRequestId`).
- **`titleByExecutionId`** — In-memory `Map` caching `toolExecutionRequestId → title` with a bounded size of 1,000 entries (LRU-style eviction).
- **`rememberTitle(id, title)`** — Internal helper that stores a title by execution ID, evicting the oldest entry when the cache is full.
- **`overrideToolTitle<T>(data)`** — Core transform. On `EXECUTING_TOOL`, stores and applies the title. On `EXECUTED_TOOL`, retrieves and re-applies the cached title. Falls back to the original payload if no title is found.
- **`applyToolTitleToMessage<T>(message)`** — Convenience wrapper that applies `overrideToolTitle` to `messageData`, handling both array and single-object shapes.

## Usage Example

```typescript
import { applyToolTitleToMessage, overrideToolTitle } from './applyToolTitle';

// Single event
const executing = overrideToolTitle({
  type: 'EXECUTING_TOOL',
  title: 'Searching Knowledge Base',
  toolFunction: 'search_kb',
  toolExecutionRequestId: 'req-123',
});
// → { ..., toolFunction: 'Searching Knowledge Base' }

const executed = overrideToolTitle({
  type: 'EXECUTED_TOOL',
  toolFunction: 'search_kb',
  toolExecutionRequestId: 'req-123',
});
// → { ..., toolFunction: 'Searching Knowledge Base' }

// Applied to a full message object
const normalized = applyToolTitleToMessage({
  messageData: [executingPayload, executedPayload],
});
```
