Thin logging bridge that forwards structured log messages from the frontend to the Tauri Rust backend via IPC, with a no-op fallback when running outside a Tauri context.

## Key Components

- **`log`** — Primary export; an object with four methods (`info`, `warn`, `error`, `debug`) that accept a `scope` string, a message, and optional metadata arguments serialized to JSON.
- **`maskToken(token)`** — Utility that redacts a sensitive token string, preserving the first and last 4 characters (e.g. `abcd...wxyz`), or returning `****` for tokens of 8 characters or fewer.
- **`send(level, scope, message)`** — Internal dispatcher; invokes the `log_from_js` Tauri command and silently swallows errors to prevent logging failures from surfacing in the UI.
- **`fmt(meta)`** — Internal serializer that joins extra metadata arguments into a space-separated string, with a `[unserializable]` fallback for values that cannot be `JSON.stringify`-ed.

## Usage Example

```typescript
import { log, maskToken } from './log';

// Structured logging with scope and optional metadata
log.info('auth', 'User signed in', { userId: 42 });
log.warn('sync', 'Retrying request', { attempt: 3 });
log.error('api', 'Request failed', { status: 500, url: '/api/data' });
log.debug('ws', 'Socket message received', rawPayload);

// Redact tokens before logging
const token = 'sk-abcdefghijklmnopqrstuvwxyz1234';
log.info('auth', `Token accepted: ${maskToken(token)}`);
// → "Token accepted: sk-a...1234"
```

> **Note:** All `log.*` calls are silent no-ops in non-Tauri environments (e.g. a standard browser or unit test runner), making this safe to use across shared frontend code without environment guards.
