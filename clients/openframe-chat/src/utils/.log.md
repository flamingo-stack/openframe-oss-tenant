Lightweight logging utility that forwards structured log messages from the frontend to the Tauri backend via IPC, with a no-op fallback for non-Tauri environments.

## Key Components

- **`log`** — Exported object with four methods (`info`, `warn`, `error`, `debug`), each accepting a `scope` string, a primary message, and optional variadic metadata arguments.
- **`maskToken`** — Utility function that redacts a token string, preserving only the first and last 4 characters (e.g., `abcd...wxyz`). Returns `****` for tokens 8 characters or shorter.
- **`send`** — Internal function that invokes the Tauri `log_from_js` command with level, scope, and message. Silently swallows errors and is a no-op outside Tauri.
- **`fmt`** — Internal helper that serializes variadic metadata into a space-joined string, falling back to `[unserializable]` if `JSON.stringify` throws.
- **`isTauri`** — Runtime guard that checks for `__TAURI_INTERNALS__` on `window`, ensuring safe use in SSR or browser-only contexts.

## Usage Example

```typescript
import { log, maskToken } from './log';

// Structured logging with scope and metadata
log.info('auth', 'User signed in', { userId: 42 });
log.warn('sync', 'Retrying request', { attempt: 2 });
log.error('api', 'Request failed', { status: 500, url: '/endpoint' });
log.debug('cache', 'Cache miss for key', 'user:profile');

// Safely log tokens without exposing secrets
const token = 'eyJhbGciOiJIUzI1NiJ9.payload.signature';
log.info('auth', 'Token loaded', maskToken(token));
// → "eyJh...ture"
```
