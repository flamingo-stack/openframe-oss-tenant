Thin logging bridge that forwards structured log messages from the frontend to the Tauri Rust backend via IPC, with a no-op fallback when running outside a Tauri context.

## Key Components

- **`log`** — Main export object with four leveled methods (`info`, `warn`, `error`, `debug`), each accepting a `scope` string, a message, and optional metadata arguments.
- **`maskToken`** — Utility that redacts sensitive tokens, exposing only the first and last 4 characters (e.g. `abcd...wxyz`).
- **`send`** — Internal function that invokes the Tauri `log_from_js` command; silently no-ops outside Tauri.
- **`fmt`** — Internal formatter that serializes variadic metadata arguments into a single string; falls back to `[unserializable]` on `JSON.stringify` failure.

## Usage Example

```typescript
import { log, maskToken } from './log';

// Scoped, leveled logging with optional metadata
log.info('AuthService', 'User signed in', { userId: 42 });
log.warn('SyncJob', 'Retry attempt', { attempt: 3, maxRetries: 5 });
log.error('ApiClient', 'Request failed', { status: 500, url: '/api/data' });
log.debug('TokenStore', 'Loaded token', maskToken(rawToken));

// Mask a sensitive token before logging
const token = 'sk-abcdefghijklmnopqrstuvwxyz1234';
log.info('Config', `Using token: ${maskToken(token)}`);
// → "Using token: sk-a...1234"
```

> **Note:** All `log.*` calls are no-ops when running in a standard browser context (`window.__TAURI_INTERNALS__` absent), so this module is safe to import in non-Tauri environments without side effects.
