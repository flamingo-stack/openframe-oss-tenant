Thin logging bridge that forwards structured log messages from the frontend to the Tauri Rust backend via IPC, with a no-op fallback when running outside a Tauri context.

## Key Components

- **`log`** — Primary export object with four leveled methods (`info`, `warn`, `error`, `debug`), each accepting a `scope` string, a message, and optional variadic metadata
- **`send(level, scope, message)`** — Internal dispatcher that calls the Tauri `log_from_js` command; silently skips if not in a Tauri environment
- **`fmt(meta)`** — Serializes variadic metadata to a space-joined string, falling back to `[unserializable]` on JSON errors
- **`maskToken(token)`** — Utility that redacts a token string, preserving only the first and last 4 characters (e.g. `abcd...wxyz`); returns `****` for tokens ≤ 8 characters

## Usage Example

```typescript
import { log, maskToken } from './log';

// Scoped structured logging
log.info('auth', 'User signed in', { userId: 42 });
log.warn('sync', 'Retrying request', { attempt: 2 });
log.error('api', 'Request failed', { status: 500 });
log.debug('ws', 'Socket opened');

// Safe token display in logs
const token = 'sk-abcdefghijklmnop';
log.info('auth', `Using token: ${maskToken(token)}`);
// → "Using token: sk-a...mnop"
```

> **Note:** All `log.*` calls are silent no-ops in non-Tauri environments (e.g. browser dev server), so the same code is safe to use in both contexts without guards.
