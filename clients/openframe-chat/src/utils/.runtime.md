Detects whether the application is running inside a Tauri shell or a standalone Vite dev environment, used to branch NATS transport logic accordingly.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `isTauri` | `boolean` | `true` when `__TAURI_INTERNALS__` is present on `window`; `false` in Vite-only (`npm run frontend:dev`) mode |

## Usage Example

```typescript
import { isTauri } from './runtime';

if (isTauri) {
  // Delegate NATS messaging to the Rust bridge
  initTauriNatsTransport();
} else {
  // Fall back to core-lib WebSocket hooks
  initWsNatsTransport();
}
```

## Notes

- Safe in SSR/non-browser contexts — guards against `window` being `undefined` before checking for the Tauri global.
- No dependencies; evaluates once at module load time as a constant.
- Source: [`runtime.ts`](https://github.com/flamingo-stack/openframe-oss-tenant/blob/main/runtime.ts)
