Transforms raw GraphQL dialog messages into a normalized chat display format for the Fae AI assistant interface.

## Key Components

### `processHistoricalMessages(messages, onApprove?, onReject?)`

Converts an array of `GraphQlMessage` objects into UI-ready `Message[]` format by:

1. Mapping GraphQL messages to the `HistoricalMessage` schema expected by the core library
2. Delegating to `processHistoricalMessagesWithErrors` with Fae-specific configuration (name, type, avatar, client chat filter)
3. Normalizing the output, attaching the Fae avatar to `assistant` and `error` role messages

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `messages` | `GraphQlMessage[]` | Raw messages from the dialog GraphQL service |
| `onApprove` | `(requestId?: string) => Promise<void>` | Optional approval action handler |
| `onReject` | `(requestId?: string) => Promise<void>` | Optional rejection action handler |

**Returns:** `Message[]` — normalized messages ready for chat UI rendering

## Usage Example

```typescript
import { processHistoricalMessages } from './messageProcessor';

const rawMessages = await fetchDialogMessages(dialogId);

const chatMessages = processHistoricalMessages(
  rawMessages,
  async (requestId) => { await approveRequest(requestId); },
  async (requestId) => { await rejectRequest(requestId); },
);

// chatMessages is ready for direct binding to the chat component
renderChat(chatMessages);
```

## Notes

- Scoped to `CHAT_TYPE.CLIENT` — filters out non-client message types
- The Fae avatar is statically imported and applied to all `assistant` and `error` role messages
- Approval/rejection handlers are optional; omit for read-only message display
