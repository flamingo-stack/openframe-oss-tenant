A utility module that transforms GraphQL historical messages into a standardized chat display format for the Fae assistant interface. It processes raw message data from the backend into UI-ready message objects with proper avatars, filtering, and error handling.

## Key Components

- **`processHistoricalMessages`** - Main function that converts GraphQL messages to chat display format
- **`HistoricalMessage`** - Type imported from core for intermediate message structure
- **`Message`** - Type for final UI-ready message objects
- **`faeAvatar`** - Static asset reference for the Fae assistant's avatar image

## Usage Example

```typescript
import { processHistoricalMessages } from './messageProcessor'
import type { Message as GraphQLMessage } from '../services/dialogGraphQLService'

// Process messages with approval/rejection callbacks
const chatMessages = processHistoricalMessages(
  graphqlMessages,
  async (requestId) => {
    // Handle message approval
    await approveRequest(requestId)
  },
  async (requestId) => {
    // Handle message rejection
    await rejectRequest(requestId)
  }
)

// Use processed messages in chat component
setChatHistory(chatMessages)
```

The function automatically filters for client chat types, assigns the Fae avatar to assistant messages, and maintains proper message structure for display components. It leverages the core `processHistoricalMessagesWithErrors` utility while adding Fae-specific configurations and avatar handling.
