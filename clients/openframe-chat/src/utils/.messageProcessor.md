Processes historical chat messages from GraphQL into a standardized format for display in the Flamingo client interface, specifically configuring messages for Fae AI assistant interactions.

## Key Components

**Main Export:**
- `processHistoricalMessages()` - Transforms GraphQL messages into chat display format with Fae assistant configuration

**Dependencies:**
- `@flamingo-stack/openframe-frontend-core` - Core chat processing utilities and types
- `dialogGraphQLService` - GraphQL message type definitions
- `fae-avatar.png` - Avatar image for the Fae assistant

## Usage Example

```typescript
import { processHistoricalMessages } from './messageProcessor'
import type { Message as GraphQLMessage } from '../services/dialogGraphQLService'

// Process messages from GraphQL API
const graphqlMessages: GraphQLMessage[] = await fetchDialogHistory()

// Transform for chat display with approval handlers
const chatMessages = processHistoricalMessages(
  graphqlMessages,
  async (requestId) => {
    // Handle message approval
    await approveRequest(requestId)
  },
  async (requestId) => {
    // Handle message rejection
    await rejectRequest(requestId)
  }
)

// Use in chat component
<ChatDisplay messages={chatMessages} />
```

The processor filters messages to CLIENT chat type, applies Fae branding with avatar, and handles error states while preserving message metadata for approval workflows.
