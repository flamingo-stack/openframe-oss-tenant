This file provides functionality to convert GraphQL chat messages into the standardized chat display format used by the Flamingo OpenFrame frontend, specifically configured for the Fae AI assistant.

## Key Components

- **`processHistoricalMessages`** - Main function that transforms GraphQL messages into display-ready chat messages
- **Type imports** - Leverages core chat types and processing utilities from the OpenFrame frontend core
- **Fae configuration** - Pre-configured with Fae assistant branding and avatar

## Usage Example

```typescript
import { processHistoricalMessages } from './messageProcessor'
import type { Message as GraphQLMessage } from '../services/dialogGraphQLService'

// Transform GraphQL messages for chat display
const graphqlMessages: GraphQLMessage[] = await fetchChatHistory()

const displayMessages = processHistoricalMessages(
  graphqlMessages,
  async (requestId) => {
    // Handle message approval
    await approveRequest(requestId)
  },
  async (requestId) => {
    // Handle message rejection  
    await rejectRequest(requestId)
  }
)

// displayMessages are now ready for chat UI rendering
chatComponent.setMessages(displayMessages)
```

The function filters messages to CLIENT chat types only and ensures all assistant messages display with the Fae avatar for consistent branding across the chat interface.
