Tailwind CSS configuration file for the OpenFrame frontend application, extending the shared `@flamingo-stack/openframe-frontend-core` preset with animation support.

## Key Components

- **`openframeCorePreset`** — Imported from the shared OpenFrame core package, providing base theme tokens, colors, and design system defaults
- **`tailwindcssAnimate`** — Plugin enabling CSS animation utilities
- **`content`** — Scans local `src/**/*.{ts,tsx}`, `index.html`, and pre-built core package dist files for class purging
- **`config`** — Exported Tailwind `Config` object combining all settings

## Usage Example

```typescript
// tailwind.config.ts
import openframeCorePreset from '@flamingo-stack/openframe-frontend-core/tailwind.config.ts';
import type { Config } from 'tailwindcss';
import tailwindcssAnimate from 'tailwindcss-animate';

const config: Config = {
  content: [
    './src/**/*.{ts,tsx}',
    './index.html',
    './node_modules/@flamingo-stack/openframe-frontend-core/dist/**/*.{js,mjs,cjs}',
  ],
  plugins: [tailwindcssAnimate],
  presets: [openframeCorePreset],
};

export default config;
```

> **Note:** The core preset path in `node_modules` ensures Tailwind scans pre-compiled classes from the shared component library, preventing styles from being purged in production builds.
