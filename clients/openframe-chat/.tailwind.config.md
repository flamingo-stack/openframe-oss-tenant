Tailwind CSS configuration for the application, extending the OpenFrame core design system preset with animation support and content scanning paths.

## Key Components

- **`openframeCorePreset`** — Inherited preset from `@flamingo-stack/openframe-frontend-core` that provides shared design tokens, theme values, and utilities across the Flamingo/OpenFrame platform.
- **`tailwindcssAnimate`** — Plugin adding CSS animation utilities.
- **`content`** — Glob patterns covering local source files (`src/**/*.{ts,tsx}`, `index.html`) and pre-built core package assets for purge/JIT scanning.
- **`presets`** — Applies the OpenFrame core preset as the base configuration, ensuring design consistency with the broader platform.

## Usage Example

```typescript
// tailwind.config.ts
import openframeCorePreset from '@flamingo-stack/openframe-frontend-core/tailwind.config.ts';
import type { Config } from 'tailwindcss';
import tailwindcssAnimate from 'tailwindcss-animate';

const config: Config = {
  content: [
    './src/**/*.{ts,tsx}',
    './index.html',
    './node_modules/@flamingo-stack/openframe-frontend-core/dist/**/*.{js,mjs,cjs}',
  ],
  plugins: [tailwindcssAnimate],
  presets: [openframeCorePreset],
};

export default config;
```

> **Note:** The `content` array includes the compiled core package output so Tailwind can detect classes used in shared components and avoid stripping them during production builds.
