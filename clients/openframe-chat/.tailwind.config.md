Tailwind CSS configuration for the application, extending the shared `@flamingo-stack/openframe-frontend-core` preset with local content paths and animation support.

## Key Components

- **`openframeCorePreset`** — Inherited design system preset from the OpenFrame frontend core package, ensuring consistent theming across the Flamingo stack
- **`tailwindcssAnimate`** — Plugin enabling CSS animation utilities
- **`content`** — Scans local `src/` TypeScript/TSX files, `index.html`, and pre-built core package dist files for class purging

## Usage Example

```typescript
// tailwind.config.ts
import openframeCorePreset from '@flamingo-stack/openframe-frontend-core/tailwind.config.ts';
import type { Config } from 'tailwindcss';
import tailwindcssAnimate from 'tailwindcss-animate';

const config: Config = {
  content: [
    './src/**/*.{ts,tsx}',
    './index.html',
    './node_modules/@flamingo-stack/openframe-frontend-core/dist/**/*.{js,mjs,cjs}',
  ],
  plugins: [tailwindcssAnimate],
  presets: [openframeCorePreset],
};

export default config;
```

> **Note:** The core preset provides the base OpenFrame/Flamingo design tokens (colors, typography, spacing). Local overrides can be added directly to the `config` object alongside the preset — values defined here will merge with or override the preset as needed.
