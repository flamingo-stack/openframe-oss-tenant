Tailwind CSS configuration file for the OpenFrame OSS Tenant frontend, extending the shared `@flamingo-stack/openframe-frontend-core` preset with animation support.

## Key Components

| Property | Description |
|---|---|
| `openframeCorePreset` | Inherited preset from `@flamingo-stack/openframe-frontend-core` providing shared design tokens, theme, and utilities |
| `content` | Glob patterns covering local `src/` TypeScript/TSX files, `index.html`, and pre-built core component dist files |
| `tailwindcssAnimate` | Plugin enabling CSS animation utilities (e.g., `animate-in`, `animate-out`, `fade-in`) |

## Usage Example

```typescript
// tailwind.config.ts is consumed automatically by Vite/PostCSS.
// To extend with additional theme tokens or plugins:
import openframeCorePreset from '@flamingo-stack/openframe-frontend-core/tailwind.config.ts';
import type { Config } from 'tailwindcss';
import tailwindcssAnimate from 'tailwindcss-animate';

const config: Config = {
  content: [
    './src/**/*.{ts,tsx}',
    './index.html',
    './node_modules/@flamingo-stack/openframe-frontend-core/dist/**/*.{js,mjs,cjs}',
  ],
  plugins: [tailwindcssAnimate],
  presets: [openframeCorePreset],
  theme: {
    extend: {
      // Add tenant-specific overrides here
      colors: {
        brand: '#FF5A36',
      },
    },
  },
};

export default config;
```

> **Note:** The `content` array includes the core package's `dist/` output so Tailwind can detect class usage inside pre-compiled shared components and avoid purging those styles in production builds.
