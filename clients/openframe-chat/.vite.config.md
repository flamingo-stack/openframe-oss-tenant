Vite configuration file for the Flamingo desktop (Tauri) application, defining build settings, dev server options, and environment variable handling.

## Key Components

- **React plugin** — enables React support via `@vitejs/plugin-react`
- **`next/image` shim** — aliases `next/image` to a local shim (`src/shims/next-image.tsx`) for compatibility outside Next.js
- **`define`** — exposes `NODE_ENV` and `NEXT_PUBLIC_APP_TYPE` (defaults to `'flamingo'`) to the client bundle
- **`build`** — outputs to `dist/assets`, no sourcemaps, clears output dir on each build
- **`server`** — dev server bound to `127.0.0.1:3003` with `strictPort` (fails if port is unavailable)
- **`envPrefix`** — whitelists `VITE_`, `TAURI_`, and `NEXT_PUBLIC_` env variable prefixes for client exposure

## Usage Example

```bash
# Start dev server (port 3003)
npm run dev

# Build for production
npm run build
```

```typescript
// Override app type via environment variable before building
NEXT_PUBLIC_APP_TYPE=openframe npm run build
```

> **Note:** The `NEXT_PUBLIC_APP_TYPE` env var controls which app variant is bundled. Valid values include `'flamingo'` (default) and `'openframe'`. This is consumed at build time via `process.env.NEXT_PUBLIC_APP_TYPE` in application code.
