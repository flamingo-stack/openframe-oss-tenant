Vite configuration file for the Flamingo desktop application, defining build settings, dev server options, plugin setup, and environment variable handling for a React + Tauri project.

## Key Components

- **`react()` plugin** — Enables React Fast Refresh and JSX transformation via `@vitejs/plugin-react`
- **`resolve.alias`** — Shims `next/image` to a local compatibility component, allowing shared components originally written for Next.js to run in the Vite/Tauri context
- **`define`** — Injects `process.env.NODE_ENV` and `process.env.NEXT_PUBLIC_APP_TYPE` at build time; `NEXT_PUBLIC_APP_TYPE` defaults to `'flamingo'` if not set
- **`build`** — Outputs to `dist/assets`, disables sourcemaps, and clears the output directory on each build
- **`server`** — Dev server runs on `127.0.0.1:3003` with `strictPort` to prevent silent port fallback (required for Tauri's `devUrl` binding)
- **`envPrefix`** — Exposes `VITE_`, `TAURI_`, and `NEXT_PUBLIC_` prefixed variables to client-side code

## Usage Example

```bash
# Start dev server (used by Tauri in development)
npm run dev
# → Listening on http://127.0.0.1:3003

# Build for production
npm run build
# → Output: dist/
```

```typescript
// Override app type at build time
NEXT_PUBLIC_APP_TYPE=openframe npm run build
```

> **Note:** The `NEXT_PUBLIC_APP_TYPE` env var controls app branding/behaviour at runtime. Valid values are `'flamingo'` (default) and `'openframe'`. This must be set before build time as it is statically replaced via `define`.
