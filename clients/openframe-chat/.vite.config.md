Vite configuration file for the Flamingo desktop application (Tauri-based), setting up React plugin, path aliases, environment variable injection, and build/dev server options.

## Key Components

- **`react()` plugin** — Enables React fast-refresh and JSX transform via `@vitejs/plugin-react`
- **`resolve.alias`** — Shims `next/image` to a local compatibility layer, allowing shared Next.js components to run in the Vite/Tauri context
- **`define`** — Injects `process.env.NODE_ENV` and `process.env.NEXT_PUBLIC_APP_TYPE` (defaults to `'flamingo'`) at build time
- **`build`** — Outputs to `dist/assets`, no sourcemaps, clears output dir on each build
- **`server`** — Dev server bound to `127.0.0.1:3003` with `strictPort` to prevent silent port fallback
- **`envPrefix`** — Exposes variables prefixed with `VITE_`, `TAURI_`, or `NEXT_PUBLIC_` to client code
- **`clearScreen: false`** — Preserves Tauri CLI output in the terminal

## Usage Example

```bash
# Development (runs on http://127.0.0.1:3003)
NEXT_PUBLIC_APP_TYPE=flamingo vite dev

# Production build (output → dist/)
vite build
```

```typescript
// Accessing injected env vars in app code
const appType = process.env.NEXT_PUBLIC_APP_TYPE; // 'flamingo' | custom value
const env = process.env.NODE_ENV;                 // 'development' | 'production'
```

## Notes

- The `next/image` shim at `src/shims/next-image.tsx` is required when reusing Next.js UI components outside of Next.js
- Port `3003` is referenced by the Tauri `devUrl` configuration — changing it requires a matching update in `tauri.conf.json`
