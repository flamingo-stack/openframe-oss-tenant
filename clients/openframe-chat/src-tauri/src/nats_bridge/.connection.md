Manages the NATS WebSocket connection lifecycle for the Tauri desktop client, including credential waiting, initial connection, auth refresh callbacks with 401 backoff, reconnect delay policy, and connection state propagation.

## Key Components

### `NatsBridge::run`
Main async loop that waits for a valid server URL and token, builds `ConnectOptions` with auth/event callbacks, and establishes the WebSocket connection. Loops indefinitely on unrecoverable URL errors.

### `handle_nats_event`
Handles `async_nats::Event` variants — resets auth failure counters on `Connected`, triggers notification and dialog resubscription (with a client-availability guard), and updates `ConnectionState` on `Disconnected`.

### `backoff_ms`
Capped exponential backoff: `BASE_DELAY_MS × 2^exp`, clamped to `MAX_DELAY_MS` (30s). Used for both auth failures and reconnect delays.

### `reconnect_delay`
Delay policy injected into `ConnectOptions`: fast retries (3 × 200ms) then exponential backoff with ±50% jitter.

### `build_connect_url`
Converts an `http://`/`https://` server URL to a `ws://`/`wss://` WebSocket URL with a percent-encoded `authorization` query parameter.

### `mask_token` / `mask_connect_url`
Safe log helpers — truncate tokens to `first4...last4 (len N)` and redact the `authorization=` query param in URLs.

## Usage Example

```rust
// Connection is driven internally; callers only trigger run():
let bridge = NatsBridge::new(app_handle, token_source, server_url);
bridge.run().await; // blocks; returns once client is stored

// Inspect backoff values:
assert_eq!(backoff_ms(0), 1_000);   // 1s
assert_eq!(backoff_ms(5), 30_000);  // capped at 30s

// Safe token logging:
let display = mask_token("eyJhbGciOiJIUzI1NiJ9.payload.sig");
// → "eyJh...g.sig (len 36)"
```

## Configuration Constants

| Constant | Value | Purpose |
|---|---|---|
| `FAST_RETRIES` | 3 | Attempts before switching to exponential backoff |
| `FAST_DELAY_MS` | 200ms | Delay during fast retry phase |
| `MAX_DELAY_MS` | 30 000ms | Backoff ceiling |
| `PING_INTERVAL` | 10s | NATS keepalive ping |
