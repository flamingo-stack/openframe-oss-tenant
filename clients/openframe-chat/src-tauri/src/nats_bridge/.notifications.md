Subscribes to NATS machine notification subjects, parses notification envelopes, dispatches OS notifications, manages dock badge counts, and routes notification click events to the WebView across macOS and Windows platforms.

## Key Components

### `NotificationTarget`
Enum representing the WebView destination for a notification click — either a `Ticket` or `Dialog`, each with its corresponding ID. Converts to a `serde_json::Value` click payload via `click_payload()`.

### `NatsBridge` methods
- **`set_notifications_enabled(enabled)`** — Toggles the notifications feature flag; on macOS, triggers `UNUserNotificationCenter` authorization when enabled.
- **`on_main_window_focused()`** — Clears the unread dock badge when the main window gains focus.
- **`handle_notification_uri(uri)`** — Parses and dispatches `openframe-chat://notify` protocol URIs from Windows toast clicks (cold-start or single-instance forwarded).
- **`take_startup_click()`** — Called once by the WebView on mount; flips the readiness gate and drains any stashed cold-start click payload.

### Internal functions
- **`ensure_notification_subscription(inner)`** — Creates a NATS subscription on `machine.<machineId>.notification` under a write lock to prevent double-subscription.
- **`notification_router(inner, subscriber)`** — Async task consuming the NATS stream; parses JSON envelopes and calls `maybe_notify`.
- **`emit_or_stash(inner, payload)`** — Emits `notification:click` to the WebView or stashes it (under mutex) if the React listener is not yet mounted.
- **`deliver_click_payload(inner, payload)`** — Activates the main window and routes the click payload.
- **`parse_click_payload(uri)`** — Decodes `openframe-chat://notify?kind=...&id=...` URIs into JSON payloads.
- **`parse_notification(payload)`** — Extracts `title`, `body` (truncated to 140 chars), and `NotificationTarget` from a NATS envelope.

## Usage Example

```rust
// Enable notifications from frontend feature flag
nats_bridge.set_notifications_enabled(true);

// Handle a Windows protocol-activation URI (from single-instance argv)
let handled = nats_bridge.handle_notification_uri(
    "openframe-chat://notify?kind=ticket&id=TICK-123"
);

// WebView calls this once its listener is mounted
if let Some(payload) = nats_bridge.take_startup_click() {
    // payload: {"kind": "ticket", "id": "TICK-123"}
    // forward to React notification:click handler
}

// Window focus clears dock badge
nats_bridge.on_main_window_focused();
```
