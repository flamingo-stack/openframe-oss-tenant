Implements the `UNUserNotificationCenter` delegate backend for production macOS builds, enabling reliable notification delivery and click handling that persists across app restarts and cold launches.

## Key Components

### Public Functions

| Function | Description |
|---|---|
| `active() -> bool` | Returns whether the UN backend is initialized and operational |
| `init(inner: &Arc<Inner>)` | Installs the delegate and registers the notification action category; no-op in dev/unbundled builds |
| `ensure_authorized()` | Requests macOS notification permission once; idempotent |
| `fire(title, body, target)` | Dispatches a notification on a background thread with an optional click-target payload embedded in `userInfo` |

### Private Functions

| Function | Description |
|---|---|
| `register_category` | Registers the `openframe-chat-message` category with a foreground "Open" action |
| `payload_from_response` | Extracts the `of-click-payload` JSON value from a `UNNotificationResponse` |

### `NotificationDelegate` (ObjC Class)

Defined via `define_class!`, implements `UNUserNotificationCenterDelegate`:

- **`will_present_notification`** — Forces banner display when the app is frontmost (macOS silently drops notifications otherwise)
- **`did_receive_response`** — Handles all user clicks (live banner, Notification Center, cold launch) by routing the payload to `deliver_click_payload`

### Module-Level Statics

| Static | Purpose |
|---|---|
| `ROUTER: OnceLock<Arc<Inner>>` | Shared bridge state set once at `init`; survives process restarts |
| `ACTIVE: AtomicBool` | Guards all notification operations against dev/unbundled builds |

## Usage Example

```rust
// During Tauri app setup
let inner = Arc::new(Inner::new(...));
macos_un::init(&inner);

// When the frontend enables notifications
macos_un::ensure_authorized();

// Send a notification with a click target
macos_un::fire(
    "New message".to_string(),
    "Alice: Hey there!".to_string(),
    Some(NotificationTarget::Chat { conversation_id: "abc123".to_string() }),
);
```

> **Dev builds:** `init` exits immediately when `tauri::is_dev()` is true or no bundle identifier is present — `active()` returns `false` and all `fire` calls are silently dropped.
