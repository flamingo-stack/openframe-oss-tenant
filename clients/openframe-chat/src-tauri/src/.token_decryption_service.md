Provides AES-256-GCM decryption for encrypted tokens, handling base64 decoding, nonce extraction, and plaintext conversion.

## Key Components

### `TokenDecryptionService`
A cloneable service struct holding a 32-byte symmetric key used for AES-256-GCM decryption.

| Method | Description |
|--------|-------------|
| `new(secret: String)` | Constructs the service; validates the secret is exactly 32 bytes |
| `decrypt(encrypted_data: &str)` | Decodes base64 input, extracts the 12-byte nonce prefix, and decrypts the ciphertext |

**Expected ciphertext format:** `base64( nonce[12 bytes] || ciphertext )`

## Usage Example

```rust
use token_decryption_service::TokenDecryptionService;

fn main() -> Result<(), String> {
    // Secret must be exactly 32 bytes
    let secret = "my-super-secret-key-32-bytes!!".to_string();
    let svc = TokenDecryptionService::new(secret)?;

    // encrypted_data is a base64-encoded string: nonce (12 bytes) + AES-GCM ciphertext
    let encrypted_data = "base64encodedNoncePlusCiphertext==";
    let plaintext = svc.decrypt(encrypted_data)?;

    println!("Decrypted token: {}", plaintext);
    Ok(())
}
```

## Error Handling

All errors return `Result<_, String>` with descriptive messages. Failures are also emitted via `log::error!` for observability:

- Secret length ≠ 32 bytes → construction fails
- Invalid base64 → `decrypt` fails
- Payload shorter than 12 bytes → `decrypt` fails
- AES-GCM authentication failure → `decrypt` fails
- Non-UTF-8 plaintext → `decrypt` fails

## Notes

- The nonce is **prepended** to the ciphertext by the encrypting party and must follow the same convention for successful decryption.
- The service is `Clone`, making it safe to share across Actix handlers or other cloned application state.
