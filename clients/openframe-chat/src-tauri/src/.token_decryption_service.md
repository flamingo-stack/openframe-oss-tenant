Provides AES-256-GCM decryption for encrypted tokens, expecting a base64-encoded payload with a prepended 12-byte nonce.

## Key Components

### `TokenDecryptionService`
A cloneable service struct holding a 32-byte AES-256-GCM key.

| Method | Description |
|--------|-------------|
| `new(secret: String)` | Constructs the service; requires exactly 32-byte secret key |
| `decrypt(encrypted_data: &str)` | Decodes base64 input, splits nonce/ciphertext, and returns plaintext |

**Expected payload format:**

```text
[ 12-byte nonce ][ ciphertext + GCM auth tag ]
       ↑                    ↑
 AES-GCM nonce       Encrypted content
 (base64-encoded together as a single string)
```

## Usage Example

```rust
use token_decryption_service::TokenDecryptionService;

fn main() -> Result<(), String> {
    // Secret must be exactly 32 bytes
    let secret = "my_super_secret_key_32bytes_long".to_string();

    let service = TokenDecryptionService::new(secret)?;

    let encrypted = "base64encodedNoncePlusCiphertext==";
    let plaintext = service.decrypt(encrypted)?;

    println!("Decrypted token: {}", plaintext);
    Ok(())
}
```

## Error Handling

All errors are returned as `Result<_, String>` and logged via `log::error!` before propagation:

- **Invalid key length** — secret must be exactly 32 bytes
- **Base64 decode failure** — malformed input string
- **Payload too short** — fewer than 12 bytes after decode
- **Cipher init failure** — AES key setup error
- **Decryption failure** — authentication tag mismatch or corrupted ciphertext
- **UTF-8 conversion failure** — plaintext is not valid UTF-8
