Provides AES-256-GCM decryption for encrypted tokens, decoding base64-encoded payloads that contain a prepended 12-byte nonce followed by ciphertext.

## Key Components

### `TokenDecryptionService`
A cloneable service struct holding a 32-byte symmetric key.

| Method | Description |
|--------|-------------|
| `new(secret: String)` | Constructs the service; validates the secret is exactly 32 bytes |
| `decrypt(encrypted_data: &str)` | Decodes base64 input, splits nonce/ciphertext, and returns decrypted UTF-8 string |

**Decryption format expected:**

```text
[ nonce (12 bytes) | ciphertext (N bytes) ]  →  base64-encoded string
```

## Usage Example

```rust
use crate::token_decryption_service::TokenDecryptionService;

fn main() -> Result<(), String> {
    // Secret must be exactly 32 bytes
    let secret = "my_super_secret_key_32bytes_long".to_string();

    let service = TokenDecryptionService::new(secret)?;

    // encrypted_token is a base64 string: [12-byte nonce | AES-GCM ciphertext]
    let encrypted_token = "BASE64_ENCODED_ENCRYPTED_TOKEN";
    let plaintext = service.decrypt(encrypted_token)?;

    println!("Decrypted token: {}", plaintext);
    Ok(())
}
```

## Error Handling

All errors return `Err(String)` and are logged via `log::error!` before propagation:

- Secret length ≠ 32 bytes → rejected at construction
- Base64 decode failure → early return
- Payload shorter than 12 bytes → early return
- AES-GCM decryption failure (e.g. tampered ciphertext or wrong key) → early return
- Invalid UTF-8 in plaintext → early return
