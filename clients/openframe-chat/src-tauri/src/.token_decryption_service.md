Provides AES-256-GCM decryption for encrypted tokens, handling base64 decoding, nonce extraction, and plaintext conversion in a single service struct.

## Key Components

**`TokenDecryptionService`** — A cloneable service struct holding a 32-byte symmetric key.

- **`new(secret: String) -> Result<Self, String>`** — Constructs the service from a UTF-8 secret. Fails if the secret is not exactly 32 bytes.
- **`decrypt(encrypted_data: &str) -> Result<String, String>`** — Decrypts a base64-encoded ciphertext. Expects the first 12 bytes (after base64 decoding) to be the AES-GCM nonce, followed by the ciphertext.

## Encryption Format Expected

```text
base64( nonce[12 bytes] || ciphertext[N bytes] )
```

## Usage Example

```rust
use token_decryption_service::TokenDecryptionService;

fn main() -> Result<(), String> {
    // Secret must be exactly 32 characters/bytes
    let secret = "my-super-secret-key-32-bytes!!".to_string();
    let service = TokenDecryptionService::new(secret)?;

    // `encrypted_token` is a base64-encoded string: nonce (12 bytes) + ciphertext
    let encrypted_token = "base64encodedpayload==";
    let plaintext = service.decrypt(encrypted_token)?;

    println!("Decrypted token: {}", plaintext);
    Ok(())
}
```

## Notes

- Uses `aes-gcm` crate (`Aes256Gcm`) for authenticated decryption — ciphertext tampering will cause decryption to fail.
- All failure paths emit structured `log::error!` messages for observability before returning `Err`.
- The service is `Clone`, making it safe to share across Axum/Actix handlers or Arc-wrapped state.
