Tauri application entry point for the OpenFrame Chat desktop application, handling system tray setup, token watching, configuration loading, and platform-specific macOS/Windows behaviors.

## Key Components

### State Structs
- **`ServerUrlState`** — Thread-safe wrapper (`Arc<Mutex<Option<String>>>`) for the backend server URL
- **`DebugModeState`** — Thread-safe wrapper for the debug mode toggle flag

### Tauri Commands
- **`greet(name)`** — Basic greeting command (development utility)
- **`get_token()`** — Returns the current decrypted auth token from `TokenState`
- **`get_server_url()`** — Returns the configured server URL
- **`get_debug_mode()`** — Returns the current debug mode boolean
- **`log_from_js(level, scope, message)`** — Bridges frontend JS logs into the Rust `log` crate

### Platform-Specific Functions (macOS only)
- **`restore_dock_icon()`** — Reloads the `.icns` dock icon via `NSImage` (restores it after accessory-policy mode)
- **`on_application_should_terminate()`** — ObjC hook to intercept Dock quit and cancel it gracefully via `DOCK_QUIT_ACTION`

### `run()` — Main Entry Point
Bootstraps the Tauri app with:
- Config loaded via `config_reader::AppConfig::from_preferences()`
- `TokenWatcher` started if token path and secret are available
- `tauri-plugin-log` configured with file rotation (5 × 5 MB)
- System tray with platform-appropriate icons and menu items
- Windows `USERPROFILE` env var correction for SYSTEM-context launches

## Usage Example

```rust
// Invoked from main.rs
fn main() {
    openframe_chat_lib::run();
}
```

```typescript
// Frontend calling Rust commands
import { invoke } from "@tauri-apps/api/core";

const token = await invoke<string | null>("get_token");
const serverUrl = await invoke<string | null>("get_server_url");
const debugMode = await invoke<boolean>("get_debug_mode");

// Forward JS logs to Rust logger
await invoke("log_from_js", { level: "warn", scope: "auth", message: "Token missing" });
```
