Tauri application entry point for the OpenFrame Chat desktop app, wiring together system tray, token watching, configuration loading, and cross-platform IPC commands.

## Key Components

- **`run()`** — Main entry point that bootstraps the Tauri app: reads config via `AppConfig::from_preferences()`, starts the token watcher, registers the system tray icon/menu, and registers all Tauri commands.
- **`ServerUrlState` / `DebugModeState`** — Thread-safe `Arc<Mutex<...>>` state structs managed globally via Tauri's state system.
- **`get_token`** — Tauri command exposing the current decrypted auth token to the frontend.
- **`get_server_url`** — Tauri command returning the configured backend server URL.
- **`get_debug_mode`** — Tauri command returning whether debug mode is active.
- **`log_from_js`** — Tauri command bridging frontend `console.*` calls into the Rust `log` crate.
- **`restore_dock_icon()`** *(macOS only)* — Restores the app's dock icon from embedded `.icns` bytes using `objc2-app-kit`.
- **`register_app_id()`** *(Windows only)* — Sets the Windows AUMID (`com.openframe.chat`) for taskbar/notification grouping via `winreg`.
- **`on_application_should_terminate`** *(macOS only)* — ObjC hook that cancels dock-initiated quit, delegating to `DOCK_QUIT_ACTION`.

## Usage Example

```rust
// Called from main.rs
fn main() {
    openframe_chat_lib::run();
}
```

```typescript
// Frontend — invoke Tauri commands
import { invoke } from "@tauri-apps/api/core";

const token = await invoke<string | null>("get_token");
const serverUrl = await invoke<string | null>("get_server_url");
const debugMode = await invoke<boolean>("get_debug_mode");

// Forward JS logs to Rust logger
await invoke("log_from_js", { level: "warn", scope: "auth", message: "Token missing" });
```
