Tauri application entry point for the OpenFrame Chat desktop app, handling tray icon setup, token watching, configuration loading, and platform-specific initialization for macOS and Windows.

## Key Components

- **`ServerUrlState`** — Thread-safe shared state (`Arc<Mutex<Option<String>>>`) holding the configured server URL
- **`DebugModeState`** — Thread-safe shared state holding the debug mode flag
- **`greet`** *(Tauri command)* — Simple greeting command for frontend testing
- **`get_token`** *(Tauri command)* — Returns the current decrypted auth token from `TokenState`
- **`get_server_url`** *(Tauri command)* — Returns the configured server URL to the frontend
- **`get_debug_mode`** *(Tauri command)* — Returns the current debug mode flag
- **`log_from_js`** *(Tauri command)* — Bridges frontend JS log calls into the Rust `log` crate
- **`run()`** — Main entry point; initializes config, tray icon, token watcher, logging, and platform-specific hooks
- **`restore_dock_icon()`** *(macOS only)* — Restores the macOS Dock icon from embedded `.icns` bytes
- **`register_app_id()`** *(Windows only)* — Registers the AUMID and corrects `USERPROFILE` if launched as SYSTEM

## Usage Example

```rust
// Called from main.rs
fn main() {
    openframe_chat_lib::run();
}
```

```typescript
// Frontend calls exposed Tauri commands
import { invoke } from "@tauri-apps/api/core";

const token = await invoke<string | null>("get_token");
const serverUrl = await invoke<string | null>("get_server_url");
const debugMode = await invoke<boolean>("get_debug_mode");

// Forward JS logs to Rust logger
await invoke("log_from_js", {
  level: "info",
  scope: "auth",
  message: "User authenticated",
});
```
