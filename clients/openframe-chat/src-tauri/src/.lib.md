Tauri application entry point for the OpenFrame Chat desktop app, wiring together the system tray, NATS bridge, token management, platform-specific OS integrations, and IPC commands exposed to the frontend WebView.

## Key Components

| Symbol | Kind | Description |
|--------|------|-------------|
| `ServerUrlState` | Struct | Thread-safe shared state holding the configured server URL |
| `DebugModeState` | Struct | Thread-safe shared state for debug mode toggle |
| `activate_main_window` | Function | Shows, unminimizes, and focuses the main window; restores macOS dock icon |
| `apply_config` | Function | Applies `AppConfig` to shared states and starts the token watcher on first call |
| `greet` | Tauri command | Simple greeting IPC command |
| `get_token` | Tauri command | Returns the current decrypted auth token to the frontend |
| `get_server_url` | Tauri command | Returns the configured server URL to the frontend |
| `get_debug_mode` | Tauri command | Returns the debug mode flag |
| `log_from_js` | Tauri command | Routes frontend log messages into the Rust logger |
| `nats_status` | Tauri command | Returns current NATS connection status |
| `nats_set_notifications_enabled` | Tauri command | Toggles desktop notifications via the NATS bridge |
| `take_pending_notification_click` | Tauri command | Drains a buffered cold-start notification click |
| `nats_subscribe_dialog` / `nats_unsubscribe_dialog` | Tauri commands | Manage per-dialog NATS subscriptions |
| `on_application_should_terminate` | macOS ObjC hook | Intercepts Dock Quit; cancels it (stay in tray) unless a system shutdown/logout is in progress |
| `register_app_id` / `register_url_scheme` / `register_start_menu_shortcut` / `register_notification_icon` | Windows helpers | One-time Windows registry and shortcut setup for AUMID, toast icons, and the `openframe-chat://` URI scheme |

## Usage Example

```rust
// Tauri commands are invoked from the frontend WebView:
// TypeScript (frontend)
// const token = await invoke("get_token");
// const url   = await invoke("get_server_url");
// await invoke("log_from_js", { level: "warn", scope: "auth", message: "token missing" });

// On the Rust side, apply_config wires everything up at startup:
apply_config(&app_handle, AppConfig {
    server_url: Some("wss://example.openframe.ai".into()),
    debug_mode: false,
    token_path: Some("/var/run/openframe/token".into()),
    secret: Some("encryption-secret".into()),
});

// Activating the main window from any async context:
activate_main_window(&app_handle);
```

## Platform Notes

- **macOS** — Hooks `applicationShouldTerminate` to keep the app alive in the system tray on a plain Dock Quit, but allows logout/restart/shutdown to proceed via `is_system_quit()`.
- **Windows** — Registers an AUMID, `openframe-chat://` URI scheme, Start Menu shortcut, and materializes the embedded PNG icon to `AppData\Local` so Windows toast notifications display the correct logo.
