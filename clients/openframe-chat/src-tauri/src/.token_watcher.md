Watches a daemon-written token file for rotation, decrypting its contents and pushing `token-update` events to the Tauri WebView frontend via a background polling thread.

## Key Components

| Item | Description |
|------|-------------|
| `TokenSource` | Shared, `Arc<Mutex<>>`-backed handle to the encrypted token file and its decryptor. Starts empty; activated via `enable()` once config is available. |
| `TokenSource::enable` | Configures the token path and decryptor. Returns `true` only on first call — used as a once-guard to avoid starting multiple watcher threads across repeated `apply_config` calls. |
| `TokenSource::read_fresh` | Reads and decrypts the token file on demand (no cache). Used by the NATS reconnect path and `get_token` for up-to-date token access independent of poll timing. |
| `TokenWatcher` | Spawns a background thread that polls the token file every second using an mtime fast-path to avoid redundant decryption. |
| `TokenUpdateEvent` | Serializable event payload emitted to the `main` WebView window. A `None` token signals the frontend to drop its cached value. |

## Usage Example

```rust
// Build a shared source and enable it once config arrives
let source = TokenSource::new();
source.enable("/run/daemon/token.enc".to_string(), my_decryptor);

// Clone into the NATS bridge for on-demand reads
let nats_source = source.clone();
let token = nats_source.read_fresh(); // decrypts file now

// Start the watcher — emits "token-update" events to the WebView
TokenWatcher::start(source, app_handle);
```

## Behaviour Notes

- **mtime fast-path** — re-decryption is skipped when the file's modification time is unchanged, reducing CPU overhead on each 1-second tick.
- **Debounced clear** — a missing or undecryptable token must be observed for 3 consecutive polls before a `null` clear event is sent to the frontend, preventing spurious cache flushes during transient writes.
- **Emit target** — uses `emit_to("main", ...)` instead of a broadcast `emit` to avoid duplicate events when multiple Tauri event targets are registered.
