Watches for changes to an encrypted token file, decrypting and forwarding updated tokens to the Tauri frontend via events.

## Key Components

| Item | Type | Description |
|------|------|-------------|
| `TokenWatcher` | Struct | Core watcher that polls the token file every 5 seconds |
| `TokenState` | Struct | Shared Tauri state exposing the current decrypted token to commands |
| `TokenUpdateEvent` | Struct | Serializable payload emitted to the frontend on token change |
| `TokenWatcher::start()` | Method | Initializes the watcher and spawns the background polling thread |
| `read_and_decrypt_token()` | Method | Reads and decrypts the token file contents |
| `check_and_update_token()` | Method | Diffs current vs. new token and triggers emit on change |
| `emit_token_to_frontend()` | Method | Fires the `token-update` Tauri event with the new token |

## Usage Example

```rust
// In your Tauri app setup (main.rs or lib.rs)
let token_state = TokenWatcher::start(
    "/path/to/token.enc".to_string(),
    "your-decryption-secret".to_string(),
    app_handle.clone(),
);

// Register TokenState so Tauri commands can access the current token
app.manage(token_state);

// In a Tauri command
#[tauri::command]
fn get_token(state: tauri::State<TokenState>) -> Option<String> {
    state.current_token.lock().unwrap().clone()
}
```

## Behavior Notes

- Polls every **5 seconds** in a dedicated background thread
- Emits `token-update` frontend event **only on change** (first receipt or refresh)
- Silent on file-not-found; logs errors on decryption failure
- Returns an empty `TokenState` (token = `None`) if the `TokenDecryptionService` fails to initialize
