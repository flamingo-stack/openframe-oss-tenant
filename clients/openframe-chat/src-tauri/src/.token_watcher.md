Watches for changes to an encrypted token file, decrypting and broadcasting updates to the Tauri frontend via events.

## Key Components

- **`TokenWatcher`** — Core service struct that polls a token file every 5 seconds, decrypts its contents using `TokenDecryptionService`, and emits `token-update` events when the token changes
- **`TokenState`** — Shared Tauri state (`Arc<Mutex<Option<String>>>`) exposing the current decrypted token to Tauri commands
- **`TokenUpdateEvent`** — Serializable event payload emitted to the frontend containing the new token string
- **`TokenWatcher::start()`** — Static constructor that initializes the watcher and spawns the background polling loop, returning a `TokenState` for Tauri state management
- **`read_and_decrypt_token()`** — Reads the encrypted file and delegates decryption; returns `None` on missing/empty file or decryption failure
- **`check_and_update_token()`** — Compares the newly read token against the cached value and emits only on change (first receipt or refresh)
- **`emit_token_to_frontend()`** — Wraps token emission via `AppHandle::emit` with error logging

## Usage Example

```rust
// In your Tauri app setup (main.rs or lib.rs)
let token_state = TokenWatcher::start(
    "/var/run/flamingo/token.enc".to_string(),
    std::env::var("TOKEN_SECRET").unwrap(),
    app_handle.clone(),
);

// Register with Tauri so commands can access the current token
app.manage(token_state);

// In a Tauri command
#[tauri::command]
fn get_token(state: tauri::State<TokenState>) -> Option<String> {
    state.current_token.lock().unwrap().clone()
}
```

> The watcher only emits events on token transitions (`None → Some` or `Some → Some`). A `Some → None` transition (e.g. file deletion) silently updates internal state without notifying the frontend.
