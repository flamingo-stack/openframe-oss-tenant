Watches a shared encrypted token file for changes, decrypting and forwarding updated tokens to the Tauri frontend via events every 5 seconds.

## Key Components

- **`TokenWatcher`** — Core struct that polls the encrypted token file, decrypts its contents, and emits `token-update` events to the frontend on change
- **`TokenState`** — Tauri-managed shared state holding the current decrypted token behind an `Arc<Mutex<Option<String>>>`
- **`TokenUpdateEvent`** — Serializable event payload carrying the decrypted token string emitted to the frontend
- **`TokenWatcher::start()`** — Initializes the watcher and spawns a background thread polling every 5 seconds; returns a `TokenState` for use in Tauri commands
- **`read_and_decrypt_token()`** — Reads the encrypted file and delegates decryption to `TokenDecryptionService`
- **`check_and_update_token()`** — Diffs current vs. new token and triggers frontend emission only on actual changes
- **`emit_token_to_frontend()`** — Emits the `token-update` Tauri event with the decrypted token payload

## Usage Example

```rust
// In your Tauri app setup (main.rs or lib.rs)
let token_state = TokenWatcher::start(
    "/var/shared/token.enc".to_string(),
    std::env::var("TOKEN_SECRET").unwrap(),
    app_handle.clone(),
);

// Register with Tauri so commands can access the current token
app.manage(token_state);

// In a Tauri command
#[tauri::command]
fn get_token(state: tauri::State<TokenState>) -> Option<String> {
    state.current_token.lock().unwrap().clone()
}
```

On the frontend, listen for live token refreshes:

```typescript
import { listen } from "@tauri-apps/api/event";

await listen("token-update", (event) => {
  const { token } = event.payload;
  // store or apply the refreshed token
});
```

> **Note:** If the decryption service fails to initialize (e.g. invalid secret), `start()` returns an empty `TokenState` with `None` and logs the error — no panic or crash.
