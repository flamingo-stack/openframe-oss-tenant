Reads and resolves `AppConfig` at startup using platform-appropriate sources: macOS system preferences (`defaults` command) or CLI arguments on Windows/Linux.

## Key Components

**`AppConfig`** — Main configuration struct with fields:
- `token_path` — Path to the OpenFrame auth token file
- `secret` — OpenFrame secret key
- `server_url` — Target server URL
- `debug_mode` — Enables verbose/dev mode

**`AppConfig::from_preferences()`** — Platform-dispatched constructor; reads from macOS `defaults` or falls back to CLI args.

**`AppConfig::is_valid()`** — Returns `true` only when `token_path`, `secret`, and `server_url` are all populated.

**`macos` module** — Internal helpers wrapping the `defaults read com.openframe.chat <key>` subprocess:
- `read_string(key)` — Returns `Option<String>`, `None` on error or empty value
- `read_bool(key)` — Accepts `"1"` or `"true"` (case-insensitive)

## Usage Example

```rust
fn main() {
    let config = AppConfig::from_preferences();

    if !config.is_valid() {
        eprintln!("Missing required config fields");
        std::process::exit(1);
    }

    println!("Connecting to {}", config.server_url.unwrap());
}
```

**macOS** — Set values before launch:

```bash
defaults write com.openframe.chat openframe-token-path "/etc/openframe/token"
defaults write com.openframe.chat openframe-secret "my-secret"
defaults write com.openframe.chat serverUrl "https://app.openframe.ai"
defaults write com.openframe.chat devMode 1
```

**Windows / Linux** — Pass as CLI arguments:

```bash
./openframe \
  --openframe-token-path /etc/openframe/token \
  --openframe-secret my-secret \
  --serverUrl https://app.openframe.ai \
  --devMode
```
