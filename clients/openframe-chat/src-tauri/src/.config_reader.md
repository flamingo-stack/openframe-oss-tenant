Cross-platform configuration loader for the OpenFrame agent, reading startup parameters from macOS system preferences, Windows registry, or CLI arguments depending on the target OS.

## Key Components

### `AppConfig` (struct)
The main configuration container with fields:
- `token_path` — path to the OpenFrame authentication token file
- `secret` — shared secret for agent authentication
- `server_url` — OpenFrame server endpoint
- `machine_id` — unique identifier for this managed device
- `debug_mode` — enables verbose/dev logging

### `AppConfig::from_preferences()` (primary constructor)
Platform-dispatched loader:
- **macOS** → reads from `com.openframe.chat` via the `defaults` CLI tool
- **Windows** → parses CLI args first; falls back to `HKLM\SOFTWARE\OpenFrame\openframe-chat` registry if incomplete
- **Other** → parses CLI args only

### `AppConfig::from_args(args)` (public)
Parses the following flags from a `&[String]` slice:
`--openframe-token-path`, `--openframe-secret`, `--serverUrl`, `--machineId`, `--devMode`

### `AppConfig::is_valid()` (public)
Returns `true` when `token_path`, `secret`, and `server_url` are all present.

### `mod macos` / `mod windows` (private, platform-gated)
Platform-specific I/O helpers (`read_string`, `read_bool`) compiled only for their respective targets.

## Usage Example

```rust
use crate::config_reader::AppConfig;

fn main() {
    // Auto-selects the correct source for the current OS
    let config = AppConfig::from_preferences();

    if !config.is_valid() {
        eprintln!("Missing required config: token_path, secret, or server_url");
        std::process::exit(1);
    }

    println!("Connecting to {}", config.server_url.unwrap());
}
```

For testing or manual construction from CLI args:

```rust
let args = vec![
    "agent".to_string(),
    "--serverUrl".to_string(), "https://openframe.example.com".to_string(),
    "--openframe-secret".to_string(), "mysecret".to_string(),
    "--openframe-token-path".to_string(), "/etc/openframe/token".to_string(),
];
let config = AppConfig::from_args(&args);
assert!(config.is_valid());
```
