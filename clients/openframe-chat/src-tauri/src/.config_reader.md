Reads and exposes application configuration for the OpenFrame desktop agent, with platform-aware sourcing: macOS system preferences via `defaults read`, and CLI arguments on Windows/Linux.

## Key Components

**`AppConfig`** — Main configuration struct with four fields:
- `token_path` — Path to the OpenFrame auth token file
- `secret` — OpenFrame shared secret
- `server_url` — Target server URL
- `debug_mode` — Enables verbose/dev mode

**`AppConfig::from_preferences()`** — Platform-dispatched constructor; reads from macOS `NSUserDefaults` (bundle ID `com.openframe.chat`) or falls back to `from_cli_args()`.

**`AppConfig::from_cli_args()`** *(non-macOS only)* — Parses `--openframe-token-path`, `--openframe-secret`, `--serverUrl`, and `--devMode` from `std::env::args()`.

**`AppConfig::is_valid()`** — Returns `true` only when all three required `Option` fields (`token_path`, `secret`, `server_url`) are `Some`.

**`macos::read_string(key)`** — Shells out to `defaults read com.openframe.chat <key>`, returning `None` on error or empty output.

**`macos::read_bool(key)`** — Wraps `read_string`, treating `"1"` or `"true"` (case-insensitive) as `true`.

## Usage Example

```rust
fn main() {
    let config = AppConfig::from_preferences();

    if !config.is_valid() {
        eprintln!("Missing required configuration fields.");
        std::process::exit(1);
    }

    println!("Connecting to {}", config.server_url.unwrap());
}
```

**macOS defaults (manual setup):**
```bash
defaults write com.openframe.chat openframe-token-path "/etc/openframe/token"
defaults write com.openframe.chat openframe-secret "my-secret"
defaults write com.openframe.chat serverUrl "https://app.openframe.ai"
```

**Windows/Linux CLI:**
```bash
./openframe-agent \
  --openframe-token-path /etc/openframe/token \
  --openframe-secret my-secret \
  --serverUrl https://app.openframe.ai \
  --devMode
```
