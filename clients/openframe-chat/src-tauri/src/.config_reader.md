Reads and exposes application configuration for the OpenFrame desktop client, sourcing values from macOS system preferences (`defaults`) on Apple platforms or CLI arguments on Windows/Linux.

## Key Components

### `AppConfig` (struct)

The primary configuration container with four fields:

| Field | Type | Description |
|-------|------|-------------|
| `token_path` | `Option<String>` | Path to the OpenFrame authentication token |
| `secret` | `Option<String>` | OpenFrame client secret |
| `server_url` | `Option<String>` | Target OpenFrame server endpoint |
| `debug_mode` | `bool` | Enables verbose/dev mode |

### Methods

- **`from_preferences()`** — Platform-aware constructor. Reads from `com.openframe.chat` macOS defaults on Apple, falls back to `from_cli_args()` elsewhere. Logs presence of each field at startup.
- **`from_cli_args()`** *(non-macOS only)* — Walks `std::env::args()` looking for `--openframe-token-path`, `--openframe-secret`, `--serverUrl`, and `--devMode`.
- **`is_valid()`** — Returns `true` only when all three `Option` fields are populated.

### `macos` (private module)

Wraps the macOS `defaults read` CLI command:

- **`read_string(key)`** — Spawns `defaults read com.openframe.chat <key>`, returns trimmed stdout or `None` on failure.
- **`read_bool(key)`** — Calls `read_string`, interprets `"1"` or `"true"` (case-insensitive) as `true`.

## Usage Example

```rust
fn main() {
    let config = AppConfig::from_preferences();

    if !config.is_valid() {
        eprintln!("Missing required configuration fields.");
        std::process::exit(1);
    }

    println!("Connecting to {}", config.server_url.unwrap());
}
```

**CLI usage (Windows/Linux):**

```bash
openframe-client \
  --openframe-token-path /path/to/token \
  --openframe-secret my-secret \
  --serverUrl https://app.openframe.ai \
  --devMode
```
