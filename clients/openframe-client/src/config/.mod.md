Configuration module for the OpenFrame client, providing constants for service/process lifecycle management and a serializable `Configuration` struct with sensible defaults.

## Key Components

### `service_stop` Module
A collection of timing and retry constants governing how the client stops tool processes and OS services:

| Constant | Value | Purpose |
|---|---|---|
| `PROCESS_CHECK_INTERVAL_MS` | 500ms | Poll interval for process/service state |
| `GRACEFUL_SHUTDOWN_TIMEOUT_SECS` | 5s | Grace period before force-kill escalation |
| `FORCE_KILL_TIMEOUT_SECS` | 3s | Wait after force-kill for process exit |
| `MAX_KILL_RETRIES` | 3 | Force-kill attempts per process |
| `SERVICE_STOP_MAX_ATTEMPTS` | 20 | Polls waiting for Windows service STOPPED state |
| `SERVICE_FORCE_KILL_MAX_ATTEMPTS` | 6 | Force-kill rounds for a stuck service |
| `SERVICE_STOP_CALL_TIMEOUT_SECS` | 10s | Blocking SCM `stop()` cap (prevents ~4min hang) |
| `SERVICE_START_MAX_ATTEMPTS` | 3 | Start attempts before giving up |

### `Configuration`
Top-level config struct (serializable via serde).

### `LoggingConfig`
Nested logging settings: log level, JSON mode toggle, rotation size, and max file retention.

### `update_config` (submodule)
Re-exported via `pub mod update_config` — see [`update_config`](https://github.com/flamingo-stack/openframe-oss-tenant/blob/main/src/config/update_config.rs) for details.

## Usage Example

```rust
use crate::config::{Configuration, service_stop};

// Use default configuration
let config = Configuration::default();
assert_eq!(config.logging.level, "info");
assert_eq!(config.logging.max_files, 5);

// Reference service stop constants
println!(
    "Grace period: {}s, max kill retries: {}",
    service_stop::GRACEFUL_SHUTDOWN_TIMEOUT_SECS,
    service_stop::MAX_KILL_RETRIES
);
```
