Orchestrates the construction and persistence of the initial device configuration during the agent installation process, including optional local CA certificate resolution via `mkcert`.

## Key Components

### `InstallationInitialConfigService`
The primary service struct that wraps `InitialConfigurationService` to handle install-time config setup.

- **`new(directory_manager: DirectoryManager)`** — Constructs the service, initializing the underlying `InitialConfigurationService`.
- **`build_and_save(params: InstallConfigParams)`** — Validates required fields, builds an `InitialConfiguration`, optionally resolves the `mkcert` CA root path in local mode, and persists the config to disk.

### `InstallConfigParams`
A plain data struct carrying all installation parameters:

| Field | Type | Description |
|---|---|---|
| `server_url` | `Option<String>` | Remote server URL (required) |
| `initial_key` | `Option<String>` | Bootstrap auth key (required) |
| `org_id` | `Option<String>` | Organization identifier (required) |
| `local_mode` | `bool` | Enables local CA resolution via `mkcert` |
| `tags` | `Vec<String>` | Device tags applied at registration |

## Usage Example

```rust
let directory_manager = DirectoryManager::new()?;
let service = InstallationInitialConfigService::new(directory_manager)?;

let params = InstallConfigParams {
    server_url: Some("https://agent.example.com".into()),
    initial_key: Some("key-abc123".into()),
    org_id: Some("org-xyz".into()),
    local_mode: false,
    tags: vec!["production".into(), "linux".into()],
};

service.build_and_save(params)?;
```

> **Local mode note:** When `local_mode` is `true`, the service shells out to `mkcert -CAROOT` to locate `rootCA.pem`. The file must exist at that path or `build_and_save` returns an error.
