Orchestrates building and persisting the initial agent configuration during installation, including optional local CA certificate resolution via `mkcert` for local development mode.

## Key Components

### `InstallationInitialConfigService`
Main service struct that wraps `InitialConfigurationService` and handles installation-time configuration setup.

- **`new(directory_manager)`** — Constructs the service, initializing the underlying `InitialConfigurationService`.
- **`build_and_save(params)`** — Validates required install parameters, builds an `InitialConfiguration`, optionally resolves the `mkcert` CA root path for local mode, and persists the configuration to disk.

### `InstallConfigParams`
Parameter struct carrying all install-time configuration inputs:

| Field | Type | Description |
|---|---|---|
| `server_url` | `Option<String>` | Required OpenFrame server URL |
| `initial_key` | `Option<String>` | Required initial enrollment key |
| `org_id` | `Option<String>` | Required organization identifier |
| `local_mode` | `bool` | Enables local CA resolution via `mkcert` |
| `tags` | `Vec<String>` | Device tags parsed from CLI |

## Usage Example

```rust
use crate::services::InstallationInitialConfigService;
use crate::services::InstallConfigParams;

let service = InstallationInitialConfigService::new(directory_manager)?;

service.build_and_save(InstallConfigParams {
    server_url: Some("https://openframe.example.com".into()),
    initial_key: Some("ik_abc123".into()),
    org_id: Some("org_xyz".into()),
    local_mode: false,
    tags: vec!["prod".into(), "us-east".into()],
})?;
```

When `local_mode` is `true`, the service shells out to `mkcert -CAROOT` to locate `rootCA.pem` and stores the path in the saved configuration. The call fails fast if `mkcert` is not installed, returns a non-zero exit code, or the `rootCA.pem` file is absent.
