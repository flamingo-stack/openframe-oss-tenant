Orchestrates the construction and persistence of the initial device configuration during the Flamingo agent installation process.

## Key Components

### `InstallationInitialConfigService`
Main service struct wrapping `InitialConfigurationService` to handle install-time config setup.

- **`new(directory_manager)`** — Constructs the service, initializing the underlying `InitialConfigurationService`.
- **`build_and_save(params)`** — Validates required install parameters, builds an `InitialConfiguration`, resolves the local CA certificate path via `mkcert` (when `local_mode` is enabled), and persists the configuration to disk.

### `InstallConfigParams`
Parameter bag for installation configuration inputs.

| Field | Type | Description |
|---|---|---|
| `server_url` | `Option<String>` | Required remote server URL |
| `initial_key` | `Option<String>` | Required provisioning key |
| `org_id` | `Option<String>` | Required organization identifier |
| `local_mode` | `bool` | Enables local CA resolution via `mkcert` |
| `tags` | `Vec<String>` | Device tags to assign at install time |

## Usage Example

```rust
let directory_manager = DirectoryManager::new()?;
let service = InstallationInitialConfigService::new(directory_manager)?;

let params = InstallConfigParams {
    server_url: Some("https://api.flamingo.run".to_string()),
    initial_key: Some("abc123".to_string()),
    org_id: Some("org_xyz".to_string()),
    local_mode: false,
    tags: vec!["windows".to_string(), "workstation".to_string()],
};

service.build_and_save(params)?;
```

> **Note:** When `local_mode` is `true`, the service shells out to `mkcert -CAROOT` to locate `rootCA.pem`. Ensure `mkcert` is installed and the local CA has been initialized before calling `build_and_save`.
