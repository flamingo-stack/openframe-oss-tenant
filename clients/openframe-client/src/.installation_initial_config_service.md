Orchestrates the construction and persistence of an agent's initial configuration during installation, including parameter validation and optional local CA certificate resolution via `mkcert`.

## Key Components

### `InstallationInitialConfigService`
Main service struct wrapping `InitialConfigurationService`. Constructed via `new()` with a `DirectoryManager` dependency.

### `InstallConfigParams`
Input parameter struct carrying installation-time configuration:

| Field | Type | Description |
|---|---|---|
| `server_url` | `Option<String>` | Target server URL (required) |
| `initial_key` | `Option<String>` | Bootstrap authentication key (required) |
| `org_id` | `Option<String>` | Organization identifier (required) |
| `local_mode` | `bool` | Enables local CA cert resolution via `mkcert` |
| `tags` | `Vec<String>` | Device tags parsed from CLI |

### `build_and_save(params)`
Validates required fields, builds an `InitialConfiguration`, and persists it. In `local_mode`, invokes `mkcert -CAROOT` to locate and validate `rootCA.pem` before saving.

## Usage Example

```rust
use crate::services::InstallationInitialConfigService;
use crate::services::InstallConfigParams;
use crate::platform::DirectoryManager;

let dir_manager = DirectoryManager::new()?;
let svc = InstallationInitialConfigService::new(dir_manager)?;

let params = InstallConfigParams {
    server_url: Some("https://agent.example.com".into()),
    initial_key: Some("sk-abc123".into()),
    org_id: Some("org-xyz".into()),
    local_mode: true,
    tags: vec!["env:prod".into(), "region:us-east".into()],
};

svc.build_and_save(params)?;
```

> **Note:** When `local_mode` is `true`, `mkcert` must be installed and a valid `rootCA.pem` must exist under the path returned by `mkcert -CAROOT`, otherwise `build_and_save` returns an error.
