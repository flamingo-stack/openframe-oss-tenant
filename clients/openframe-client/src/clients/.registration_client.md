HTTP client responsible for registering or reinstalling an agent with the OpenFrame platform, routing to `/register` or `/reinstall` based on whether existing machine credentials are present.

## Key Components

### `RegistrationError` (enum)
Typed error returned by `register()`:
- `ClientSecretInvalid` — server rejected saved credentials on a reinstall attempt (HTTP 401 with `CLIENT_SECRET_*` error code)
- `Other(anyhow::Error)` — all other failures (network errors, validation, non-401 server errors)

### `RegistrationClient` (struct)
Cloneable HTTP client wrapping `reqwest::Client`.

| Method | Description |
|--------|-------------|
| `new(base_url, http_client)` | Constructs the client |
| `register(initial_key, machine_info, request)` | Sends a registration or reinstall POST request |

### `is_client_secret_error` (private fn)
Detects HTTP 401 responses with a `CLIENT_SECRET_*` error code in the JSON body, distinguishing credential failures from other 401s.

## Usage Example

```rust
let http_client = reqwest::Client::new();
let client = RegistrationClient::new("https://platform.example.com".into(), http_client)?;

// Fresh registration (no existing machine info)
match client.register(initial_key, None, registration_request).await {
    Ok(response) => println!("Registered: {:?}", response),
    Err(RegistrationError::ClientSecretInvalid) => {
        // Saved credentials rejected — re-register from scratch
    }
    Err(RegistrationError::Other(e)) => eprintln!("Registration failed: {e}"),
}

// Reinstall with existing credentials
let machine_info = Some(PersistedMachineInfo { client_secret, machine_id });
client.register(initial_key, machine_info, registration_request).await?;
```

**Request routing logic:**
- `machine_info = None` → `POST /clients/api/agents/register` with `X-Initial-Key` header
- `machine_info = Some(...)` → `POST /clients/api/agents/reinstall` with `X-Initial-Key`, `X-Client-Secret`, and `X-Machine-Id` headers
