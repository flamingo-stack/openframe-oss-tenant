HTTP client for OAuth2 token acquisition, supporting both client credentials and refresh token grant flows against the OpenFrame auth gateway.

## Key Components

### `AuthClient` (struct)

A cloneable HTTP client wrapping token exchange logic.

| Field | Type | Description |
|---|---|---|
| `http_client` | `Client` | Shared `reqwest` HTTP client |
| `base_url` | `String` | Auth gateway base URL |
| `deactivation` | `Arc<DeactivationService>` | Monitors gateway responses for deactivation signals |

### Methods

| Method | Description |
|---|---|
| `new(...)` | Constructs an `AuthClient` with the provided HTTP client, base URL, and deactivation service |
| `authenticate_with_secret(client_id, client_secret)` | Performs `client_credentials` OAuth2 grant; returns `AgentTokenResponse` |
| `authenticate_with_refresh_token(refresh_token)` | Performs `refresh_token` OAuth2 grant; returns a refreshed `AgentTokenResponse` |

Both authentication methods POST to `{base_url}/clients/oauth/token` as `application/x-www-form-urlencoded` and delegate every HTTP status code to `DeactivationService::on_gateway_status` before handling errors.

## Usage Example

```rust
use std::sync::Arc;
use reqwest::Client;
use crate::services::deactivation_service::DeactivationService;
use crate::clients::auth_client::AuthClient;

let http_client = Client::new();
let deactivation = Arc::new(DeactivationService::new());

let auth = AuthClient::new(
    "https://gateway.example.com".to_string(),
    http_client,
    deactivation,
);

// Client credentials flow
let token = auth
    .authenticate_with_secret("my_client_id".to_string(), "my_secret".to_string())
    .await?;

// Refresh token flow
let refreshed = auth
    .authenticate_with_refresh_token(token.refresh_token)
    .await?;
```

## Notes

- Returns `anyhow::Error` on non-2xx responses, including the HTTP status and response body (credentials flow only).
- `DeactivationService` is invoked on **every** response status, including failures, allowing the agent to react to gateway-level deactivation signals independently of token success/failure.
