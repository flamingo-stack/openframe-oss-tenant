Module index that re-exports the four HTTP client types used throughout the tenant service, providing a single import point for all external communication clients.

## Key Components

| Export | Source Module | Purpose |
|--------|--------------|---------|
| `AuthClient` | `auth_client` | Handles authentication requests |
| `RegistrationClient` | `registration_client` | Manages tenant registration flows |
| `RegistrationError` | `registration_client` | Error type for registration failures |
| `ToolAgentFileClient` | `tool_agent_file_client` | File operations via the tool agent |
| `ToolApiClient` | `tool_api_client` | General tool API communication |

## Usage Example

```rust
// Import all clients from a single path
use crate::clients::{
    AuthClient,
    RegistrationClient,
    RegistrationError,
    ToolAgentFileClient,
    ToolApiClient,
};
```
