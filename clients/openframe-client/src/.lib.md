Serves as the root library entry point for the OpenFrame agent client, wiring together all subsystems including registration, authentication, NATS messaging, tool management, and update handling into a single `Client` struct.

## Key Components

### Configuration Structs
- **`ClientConfiguration`** — Top-level config composing `ServerConfig`, `ClientConfig`, `MetricsConfig`, and `SecurityConfig` with sensible defaults (stable update channel, TLS verification enabled, 60s metrics interval)
- **`ServerConfig`** — API endpoint URL, poll interval, and optional update URL
- **`ClientConfig`** — Agent identity (UUID), log level, and update channel
- **`MetricsConfig`** — Metrics toggle and collection interval
- **`SecurityConfig`** — TLS verification flag and certificate path

### `Client` Struct
The primary runtime object. Holds `Arc<RwLock<ClientConfiguration>>` alongside all major service handles:
- `RegistrationProcessor` / `InitialAuthenticationProcessor` — device onboarding flow
- `NatsConnectionManager` — WebSocket/NATS messaging backbone
- `ToolInstallationMessageListener`, `OpenFrameClientUpdateListener`, `ToolAgentUpdateListener` — event-driven listeners
- `ToolRunManager`, `ToolConnectionProcessingManager` — tool lifecycle management
- `MachineHeartbeatRunManager`, `UpdateHandlerService` — health reporting and update orchestration

### Public Modules
`models`, `platform`, `clients`, `services`, `listener`, `logging`, `monitoring`, `service`, `service_adapter`, `system`, `updater`, `installation_initial_config_service`

## Usage Example

```rust
use openframe_agent::Client;

fn main() -> anyhow::Result<()> {
    // Respects OPENFRAME_DEV_MODE env var for local development
    let client = Client::new()?;
    // client.run().await  — starts all listeners and service loops
    Ok(())
}
```

> 💡 Set `OPENFRAME_DEV_MODE` to any value to switch to user-scoped directories and disable TLS certificate verification for local testing.
