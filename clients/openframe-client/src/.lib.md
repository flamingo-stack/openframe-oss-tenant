Crate root for the OpenFrame OSS tenant agent. It wires together all subsystems — configuration, authentication, registration, NATS messaging, tool lifecycle, execution, and update management — into a single `Client` struct that orchestrates the agent's runtime.

## Key Components

### Configuration Structs

| Struct | Purpose |
|---|---|
| `ClientConfiguration` | Root configuration with `Default` impl pointing to `https://api.openframe.org` |
| `ServerConfig` | Server URL, polling interval, and optional update URL |
| `ClientConfig` | Agent identity (UUID), log level, and update channel |
| `MetricsConfig` | Metrics toggle and collection interval |
| `SecurityConfig` | TLS verification flag and certificate path |

### `Client` Struct

The primary runtime object. Created via `Client::new()`, it owns `Arc`-wrapped shared services and composes:

- **Registration & Auth** — `RegistrationProcessor`, `InitialAuthenticationProcessor`, `TokenRefreshRunManager`
- **NATS Messaging** — `NatsConnectionManager`, `NatsMessagePublisher`, `ToolConnectionMessagePublisher`, `InstalledAgentMessagePublisher`
- **Listeners** — `ToolInstallationMessageListener`, `ToolUninstallMessageListener`, `ToolRestartMessageListener`, `OpenFrameClientUpdateListener`, `ToolAgentUpdateListener`, `ExecutionListener<T>` (command, script, scheduled script)
- **Tool Lifecycle** — `ToolInstallationService`, `ToolUninstallService`, `ToolRestartService`, `ToolRunManager`, `ToolConnectionProcessingManager`
- **Updates** — `UpdateHandlerService`, `UpdateStateService`, `UpdateCleanupService`, `LastKnownGoodService`
- **Health & Ops** — `MachineHeartbeatRunManager`, `ResultOutboxRunManager`, `MeshSelfHealService`, `DeactivationService`

### Public Modules

```text
models, platform, clients, services, listener   ← core runtime
banner, doctor, logging, monitoring             ← observability
service, service_adapter, system               ← OS integration
updater, installation_initial_config_service   ← lifecycle
executor                                       ← unix/windows only
utils
```

## Usage Example

```rust
use openframe_oss_tenant::Client;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    // Reads config from disk; honours OPENFRAME_DEV_MODE env var
    // for development directory layout and relaxed TLS.
    let client = Client::new()?;

    // client.run().await starts registration, auth, NATS listeners,
    // heartbeat, and all background managers.
    client.run().await
}
```

Set `OPENFRAME_DEV_MODE=1` to use user-local directories and disable TLS certificate verification for local development.
