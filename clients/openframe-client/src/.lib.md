Brief entry point for the OpenFrame agent client library, wiring together all major subsystems — configuration, registration, authentication, NATS messaging, tool management, and update services — into a single `Client` struct.

## Key Components

### Configuration Structs
- **`ClientConfiguration`** — Top-level agent config with `Default` impl pointing to `https://api.openframe.org`
- **`ServerConfig`** — Server URL, polling interval, and optional update URL
- **`ClientConfig`** — Agent identity (UUID), log level, and update channel
- **`MetricsConfig`** — Metrics toggle and collection interval
- **`SecurityConfig`** — TLS verification flag and certificate path

### Type Alias
- **`SessionBus`** — Platform-conditional type: `UnboundedReceiver<SessionEvent>` on Windows, `()` elsewhere; used to pass Windows session change events to `WindowsSessionManager`

### Primary Struct
- **`Client`** — Aggregates all runtime subsystems including `RegistrationProcessor`, `InitialAuthenticationProcessor`, `NatsConnectionManager`, `ToolRunManager`, `MachineHeartbeatRunManager`, `UpdateHandlerService`, and associated listeners

### Public Modules
`models`, `platform`, `clients`, `services`, `listener`, `banner`, `doctor`, `logging`, `monitoring`, `service`, `service_adapter`, `system`, `updater`, `installation_initial_config_service`, `utils`

## Usage Example

```rust
use openframe_agent::Client;

fn main() -> anyhow::Result<()> {
    // Pass None on non-Windows; provide SessionBus receiver on Windows
    let client = Client::new(None)?;
    // client is now fully wired with HTTP clients, NATS, auth,
    // tool management, and update services ready to start
    Ok(())
}
```

> **Dev mode:** Set the `OPENFRAME_DEV_MODE` environment variable to use user-space directories and disable TLS certificate verification — useful for local testing against a self-signed server.
