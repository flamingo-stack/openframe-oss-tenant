Core library entry point for the OpenFrame agent client, wiring together all services, clients, and managers needed to register, authenticate, connect, and operate a managed endpoint device.

## Key Components

### Configuration Structs
- **`ClientConfiguration`** — Top-level agent config (with `Default` impl) composing:
  - `ServerConfig` — API URL, poll interval, optional update URL
  - `ClientConfig` — Agent ID, log level, update channel
  - `MetricsConfig` — Metrics toggle and collection interval
  - `SecurityConfig` — TLS verification and certificate path

### `Client` Struct
Primary orchestrator holding `Arc<RwLock<ClientConfiguration>>` alongside all initialized subsystems:

| Field | Purpose |
|---|---|
| `directory_manager` | Platform-aware path resolution |
| `registration_processor` | Device registration flow |
| `auth_processor` | Initial authentication flow |
| `nats_connection_manager` | NATS/WebSocket connection lifecycle |
| `tool_installation_message_listener` | Listens for remote tool install commands |
| `machine_heartbeat_run_manager` | Periodic device heartbeat |
| `update_handler_service` | Agent/client update orchestration |
| `initial_key_service` | Bootstrap key provisioning |

### Platform Types
- **`SessionBus`** — Windows-only `UnboundedReceiver<SessionEvent>`; `()` on other platforms, keeping function signatures uniform across OS targets.

### Public Modules
`platform`, `clients`, `services`, `listener`, `models`, `system`, `updater`, `monitoring`, `service_adapter`, `logging`, `doctor`, `banner`, `utils`

## Usage Example

```rust
use openframe_agent::Client;

fn main() -> anyhow::Result<()> {
    // On Windows, pass Some(session_rx); on other platforms pass None
    let client = Client::new(None)?;

    // client is now fully wired with HTTP/NATS clients,
    // registration, auth, tool management, and heartbeat services
    Ok(())
}
```

> **Dev mode:** Set the `OPENFRAME_DEV_MODE` environment variable to use user-scoped directories and disable TLS certificate verification — useful for local testing against a self-signed backend.
