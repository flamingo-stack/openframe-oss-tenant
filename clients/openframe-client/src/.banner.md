Renders the Flamingo ASCII art banner with ANSI color styling to stdout.

## Key Components

- **`F`** — ANSI escape code for Flamingo pink (`rgb(243, 87, 187)`)
- **`W`** — ANSI escape code for bold white
- **`R`** — ANSI reset code
- **`print()`** — Public function that prints the full colored Flamingo logo banner

## Usage Example

```rust
fn main() {
    banner::print();
    // Continues with application startup...
}
```

**Output preview:** A stylized flamingo bird illustration in pink on the left, with the "Enternet" wordmark rendered in bold white on the right, followed by a reset to default terminal colors.
