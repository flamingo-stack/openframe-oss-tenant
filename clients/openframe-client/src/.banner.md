Renders a styled ASCII art banner for the OpenFrame/Flamingo application to the terminal using ANSI color codes.

## Key Components

- **`F`** — ANSI escape code for Flamingo pink (`rgb(243, 87, 187)`)
- **`W`** — ANSI escape code for bold white
- **`R`** — ANSI reset code
- **`print()`** — Public function that prints the full ASCII banner to stdout with color formatting

## Usage Example

```rust
use crate::banner;

fn main() {
    banner::print();
    // Continue with application startup...
}
```

**Terminal output:** Flamingo logo (pink) on the left with "OpenFrame" wordmark (white) on the right, automatically reset to default terminal colors after printing.
