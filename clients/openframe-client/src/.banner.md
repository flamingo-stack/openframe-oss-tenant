Renders the Flamingo ASCII art banner to stdout with ANSI color formatting — pink (`#F357BB`) for the logo mark and bold white for the "Flamingo" wordmark.

## Key Components

- **`F`** — ANSI escape code for Flamingo pink (RGB 243, 87, 187)
- **`W`** — ANSI escape code for bold white
- **`R`** — ANSI reset code
- **`print()`** — Public function that prints the full colored ASCII banner to stdout

## Usage Example

```rust
fn main() {
    banner::print(); // Prints the Flamingo ASCII logo on startup
}
```

> Typically called once at application startup before logging or CLI output begins. The banner uses true-color ANSI escapes (`\x1b[38;2;R;G;B;m`), so it renders best in terminals with 24-bit color support.
