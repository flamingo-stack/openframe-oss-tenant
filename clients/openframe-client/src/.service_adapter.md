Cross-platform service lifecycle manager that abstracts install, uninstall, start, and stop operations across macOS (launchd), Windows (SCM), and Linux (systemd) using the `service-manager` crate.

## Key Components

### Structs

- **`ServiceConfig`** — Full service descriptor: name, executable path, environment variables, logging paths, user/group identity, resource limits, and platform-specific options. Implements `Default` with sensible production defaults (`keep_alive: true`, `restart_throttle_seconds: 10`).
- **`RecoveryConfig`** — Windows SCM failure-action settings: restart delays (first/second/subsequent), reset period, and whether to recover on non-crash failures.
- **`CrossPlatformServiceManager`** — Primary entry point wrapping a `ServiceConfig`. Delegates to the native `ServiceManager` backend detected at runtime.

### Methods

| Method | Description |
|---|---|
| `new(name, display_name, description, exec_path)` | Minimal constructor with defaults |
| `with_config(config)` | Full-control constructor from a `ServiceConfig` |
| `set_stdout_path` / `set_stderr_path` | Builder-style log path setters |
| `set_working_directory` / `set_user` / `set_group` | Builder-style identity setters |
| `install()` | Installs service, applies platform config, creates log dirs, starts service; applies Windows recovery actions on Windows |
| `uninstall()` | Stops service, waits for process exit (Windows), removes platform files, uninstalls; tolerates "already deleted" / "doesn't exist" SCM errors |
| `start()` / `stop()` | Thin wrappers around the native manager's start/stop |

## Usage Example

```rust
use std::path::PathBuf;

let mut mgr = CrossPlatformServiceManager::new(
    "agent",
    "OpenFrame Agent",
    "OpenFrame background agent service",
    PathBuf::from("/usr/local/bin/openframe-agent"),
);

mgr.set_stdout_path(PathBuf::from("/var/log/openframe/agent.log"))
   .set_stderr_path(PathBuf::from("/var/log/openframe/agent.err"))
   .set_user("openframe")
   .set_restart_throttle(30);

// Install and auto-start
mgr.install()?;

// Later — clean removal
mgr.uninstall()?;
```

> **Note:** Service labels are automatically namespaced as `com.openframe.<name>`. On Windows, pass a `RecoveryConfig` via `ServiceConfig::recovery` before calling `install()` to configure SCM failure actions.
