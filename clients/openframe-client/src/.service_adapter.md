Provides a cross-platform service lifecycle adapter (install, start, stop, uninstall) that translates a unified `ServiceConfig` into platform-native service manager calls for macOS (launchd plist), Windows (SCM with recovery actions), and Linux (systemd).

## Key Components

### Structs
- **`ServiceConfig`** — Unified service configuration covering identity, process control, environment, logging, resource limits, and Windows recovery settings. Implements `Default`.
- **`RecoveryConfig`** — Windows SCM failure/recovery action parameters (restart delays, reset period, non-crash failure handling).
- **`CrossPlatformServiceManager`** — Primary entry point; wraps a `ServiceConfig` and delegates to the native `service_manager` backend.

### Methods on `CrossPlatformServiceManager`
| Method | Description |
|--------|-------------|
| `new(...)` | Constructs with minimal required fields |
| `with_config(config)` | Constructs from a fully populated `ServiceConfig` |
| `install()` | Registers the service, writes platform files, applies Windows recovery, then starts |
| `uninstall()` | Stops, waits for process termination (Windows), removes files, deregisters |
| `start()` / `stop()` | Lifecycle control via native manager |
| `set_stdout_path`, `set_stderr_path`, `set_working_directory`, `set_user`, `set_group`, `set_restart_throttle`, `set_file_limit`, `set_exit_timeout` | Builder-style config setters |

## Usage Example

```rust
use std::path::PathBuf;

let mut mgr = CrossPlatformServiceManager::new(
    "agent",
    "OpenFrame Agent",
    "Background telemetry agent",
    PathBuf::from("/usr/local/bin/of-agent"),
);

mgr.set_stdout_path(PathBuf::from("/var/log/of-agent.log"))
   .set_stderr_path(PathBuf::from("/var/log/of-agent.err"))
   .set_restart_throttle(30)
   .set_file_limit(1024);

mgr.install()?; // installs + starts the service
mgr.stop()?;
mgr.uninstall()?;
```

> Service labels are namespaced automatically as `com.openframe.<name>`. Windows error codes `1060` (service not found) and `1072` (marked for deletion) are silently ignored during uninstall.
