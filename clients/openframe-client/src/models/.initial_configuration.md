Defines the `InitialConfiguration` struct used to bootstrap tenant agent connections, holding server endpoint, authentication, and optional organizational metadata.

## Key Components

### `InitialConfiguration`

A serializable/deserializable configuration struct with the following fields:

| Field | Type | Description |
|-------|------|-------------|
| `server_host` | `String` | Remote server endpoint for the tenant agent to connect to |
| `initial_key` | `String` | Bootstrap authentication key for initial handshake |
| `local_mode` | `bool` | Enables local-only operation without remote server |
| `org_id` | `String` | Optional organization identifier (defaults to empty) |
| `local_ca_cert_path` | `String` | Optional path to a local CA certificate for TLS verification |
| `tags` | `Vec<DeviceTag>` | Optional device tags for categorization/filtering |

Fields marked with `#[serde(default)]` (`org_id`, `local_ca_cert_path`, `tags`) are optional in the serialized format and fall back to empty values when absent.

## Usage Example

```rust
use crate::config::InitialConfiguration;

// Deserialize from JSON/YAML config file
let config: InitialConfiguration = serde_json::from_str(r#"
{
    "server_host": "https://api.openframe.ai",
    "initial_key": "ik_abc123",
    "local_mode": false,
    "org_id": "org_flamingo",
    "tags": [{ "key": "env", "value": "production" }]
}
"#).unwrap();

// Or construct with defaults
let config = InitialConfiguration {
    server_host: "https://api.openframe.ai".to_string(),
    initial_key: "ik_abc123".to_string(),
    ..Default::default()
};
```

## Notes

- Implements `Clone`, `Debug`, `Serialize`, and `Deserialize` via derive macros
- `Default` impl produces an empty/disabled configuration suitable for programmatic construction
