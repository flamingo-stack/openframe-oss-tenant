Defines the `InitialConfiguration` struct, which holds bootstrap settings required to connect a device to the Flamingo/OpenFrame server at startup.

## Key Components

- **`InitialConfiguration`** — A serializable/deserializable configuration struct with the following fields:
  - `server_host` — Hostname or URL of the target server
  - `initial_key` — Authentication key used during device registration
  - `local_mode` — Flag to enable local/offline operation mode
  - `org_id` — Optional organization identifier (defaults to empty string)
  - `local_ca_cert_path` — Optional path to a local CA certificate for TLS (defaults to empty string)
  - `tags` — Optional list of [`DeviceTag`](super::DeviceTag) labels to associate with the device (defaults to empty vec)

- **`Default` impl** — Provides a zero-value baseline configuration with `local_mode` set to `false` and all strings/collections empty.

## Usage Example

```rust
use crate::config::InitialConfiguration;

// Deserialize from a config file (e.g., TOML/JSON)
let config: InitialConfiguration = serde_json::from_str(r#"
{
    "server_host": "https://api.flamingo.run",
    "initial_key": "abc123",
    "local_mode": false,
    "org_id": "org_xyz",
    "tags": []
}
"#).unwrap();

// Or use the default for testing / zero-config bootstrap
let config = InitialConfiguration::default();

println!("Connecting to: {}", config.server_host);
```
