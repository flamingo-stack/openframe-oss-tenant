Defines the `InitialConfiguration` struct used to bootstrap device registration and connection settings for the Flamingo agent.

## Key Components

### `InitialConfiguration`
A serializable/deserializable configuration struct containing:

| Field | Type | Description |
|-------|------|-------------|
| `server_host` | `String` | Target Flamingo server URL |
| `initial_key` | `String` | Bootstrap authentication key |
| `local_mode` | `bool` | Enables local-only operation mode |
| `org_id` | `String` | Organization identifier (defaults to empty) |
| `local_ca_cert_path` | `String` | Path to a local CA certificate (defaults to empty) |
| `tags` | `Vec<DeviceTag>` | Device tags applied at registration (defaults to empty) |

Fields annotated with `#[serde(default)]` are optional during deserialization and fall back to their `Default` values when absent.

## Usage Example

```rust
use serde_json;

// Deserialize from JSON config file
let config: InitialConfiguration = serde_json::from_str(r#"
{
    "server_host": "https://msp.flamingo.run",
    "initial_key": "reg_abc123",
    "local_mode": false,
    "org_id": "org_xyz",
    "tags": [{ "key": "site", "value": "headquarters" }]
}
"#).unwrap();

// Or construct with defaults
let config = InitialConfiguration {
    server_host: "https://msp.flamingo.run".to_string(),
    initial_key: "reg_abc123".to_string(),
    ..Default::default()
};
```
