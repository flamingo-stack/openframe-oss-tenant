Defines the `InitialConfiguration` struct used to bootstrap device-to-server connectivity, holding connection credentials, operational mode, and optional metadata.

## Key Components

### `InitialConfiguration`

A serializable/deserializable configuration struct with the following fields:

| Field | Type | Description |
|-------|------|-------------|
| `server_host` | `String` | Hostname or address of the target server |
| `initial_key` | `String` | Authentication key used during initial registration |
| `local_mode` | `bool` | Enables local-only operation when `true` |
| `org_id` | `String` | Optional organization identifier (defaults to empty) |
| `local_ca_cert_path` | `String` | Optional path to a local CA certificate for TLS verification |
| `tags` | `Vec<DeviceTag>` | Optional device tags for classification/filtering |

Fields `org_id`, `local_ca_cert_path`, and `tags` use `#[serde(default)]`, so they are optional in the serialized form (e.g. JSON/YAML config files).

## Usage Example

```rust
use serde_json;

// Deserialize from a config file
let config: InitialConfiguration = serde_json::from_str(r#"
{
    "server_host": "vpn.example.com",
    "initial_key": "abc123",
    "local_mode": false,
    "org_id": "org-42",
    "tags": [{ "key": "env", "value": "production" }]
}
"#).unwrap();

// Or use the default for a blank slate
let config = InitialConfiguration::default();
```
