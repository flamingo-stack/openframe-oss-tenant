Defines the core data structures for representing installed tools and their installation state within the OpenFrame tenant system.

## Key Components

### `Installation` (enum)
Tagged enum representing the installation type of a tool, serialized as `snake_case`:
- `Standard` — CLI/command-line tool with an optional executable path
- `GuiApp` — GUI application requiring a mandatory executable path and optional `bundle_id`
- `Service` — System service with a required `service_name` and optional executable path

**Methods:**
- `executable_path()` — Returns the executable path regardless of installation variant
- `is_standard()`, `is_gui_app()`, `is_service()` — Variant type guards

### `InstalledAsset` (struct)
Represents a binary/file asset bundled with an installed tool, tracking its `id`, `version`, and whether it is `executable`.

### `ToolRecordState` (enum)
Lifecycle state of a tool record: `Installing` or `Installed` (default).

### `InstalledTool` (struct)
The primary record for a tool installed on a tenant. Captures identity (`tool_id`, `tool_type`, `version`), runtime invocation (`run_command_args`, `tool_agent_id_command_args`), optional uninstallation commands, installation metadata, associated assets, and current state.

## Usage Example

```rust
use crate::installed_tool::{InstalledTool, Installation, ToolRecordState};

let tool = InstalledTool {
    tool_agent_id: "agent-001".into(),
    tool_id: "my-tool".into(),
    tool_type: "cli".into(),
    version: "1.2.3".into(),
    run_command_args: vec!["my-tool".into(), "--run".into()],
    tool_agent_id_command_args: vec![],
    installation: Installation::Service {
        service_name: "my-tool-svc".into(),
        executable_path: Some("/usr/bin/my-tool".into()),
    },
    state: ToolRecordState::Installing,
    ..Default::default()
};

assert!(tool.installation.is_service());
assert_eq!(tool.installation.executable_path(), Some("/usr/bin/my-tool"));
```
