Defines data structures for representing installed tools and their installation metadata within the Flamingo/OpenFrame tooling system.

## Key Components

### `Installation` (enum)
Tagged enum representing how a tool is installed, with three variants:
- `Standard` — CLI/command-line tool with an optional executable path
- `GuiApp` — GUI application requiring an executable path and optional bundle ID (macOS)
- `Service` — System service with a required service name and optional executable path

**Methods:**
- `executable_path()` — Returns the executable path across all variants
- `is_standard()`, `is_gui_app()`, `is_service()` — Type-check helpers

### `InstalledAsset` (struct)
Represents a single file/binary asset associated with a tool installation, tracking its `id`, `version`, and whether it is executable.

### `InstalledTool` (struct)
Top-level record describing a fully installed tool, including:
- Identity fields: `tool_agent_id`, `tool_id`, `tool_type`, `version`
- Runtime fields: `run_command_args`, `tool_agent_id_command_args`
- Optional `uninstallation_command_args`
- `installation` — the `Installation` variant describing how it was installed
- `assets` — list of associated `InstalledAsset` entries

All structs derive `Serialize`/`Deserialize` with snake_case conventions and `skip_serializing_if` guards on optional fields.

## Usage Example

```rust
use crate::installed_tool::{InstalledTool, Installation, InstalledAsset};

let tool = InstalledTool {
    tool_agent_id: "agent-123".into(),
    tool_id: "my-cli".into(),
    tool_type: "cli".into(),
    version: "1.0.0".into(),
    run_command_args: vec!["my-cli".into(), "--run".into()],
    installation: Installation::Standard {
        executable_path: Some("/usr/local/bin/my-cli".into()),
    },
    assets: vec![InstalledAsset {
        id: "binary-main".into(),
        version: "1.0.0".into(),
        executable: true,
    }],
    ..Default::default()
};

if let Some(path) = tool.installation.executable_path() {
    println!("Executable at: {}", path);
}
```
