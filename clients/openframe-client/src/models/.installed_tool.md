Data model representing installed tools on endpoints within the Flamingo MSP platform, tracking tool metadata, execution parameters, and installation status.

## Key Components

### ToolStatus Enum
- `Installed` - Indicates the tool is successfully installed and available
- Implements `Default` trait returning `Installed` status

### InstalledTool Struct
- `tool_agent_id` - Unique identifier for the tool agent instance
- `tool_id` - Identifier for the specific tool type
- `version` - Version string of the installed tool
- `session_type` - Execution context (from SessionType model)
- `run_command_args` - Command arguments for tool execution
- `tool_agent_id_command_args` - Agent-specific command parameters
- `uninstallation_command_args` - Optional removal command parameters
- `status` - Current installation status
- `executable_path` - Optional relative path to the tool executable

## Usage Example

```rust
use crate::models::{InstalledTool, ToolStatus, SessionType};

// Create a new installed tool entry
let tool = InstalledTool {
    tool_agent_id: "agent-123".to_string(),
    tool_id: "monitoring-tool".to_string(),
    tool_type: "system-monitor".to_string(),
    version: "2.1.0".to_string(),
    session_type: SessionType::Service,
    run_command_args: vec!["--daemon".to_string(), "--port=8080".to_string()],
    tool_agent_id_command_args: vec!["--agent-id=agent-123".to_string()],
    uninstallation_command_args: Some(vec!["uninstall".to_string(), "--force".to_string()]),
    status: ToolStatus::Installed,
    executable_path: Some("bin/monitor".to_string()),
};

// Serialize to JSON for API responses
let json = serde_json::to_string(&tool)?;
```
