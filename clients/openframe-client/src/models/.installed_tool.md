Defines the core data structures for representing installed tools and their installation types within the Flamingo/OpenFrame tool management system.

## Key Components

### `Installation` (enum)
Tagged enum representing how a tool is installed, with three variants:
- **`Standard`** — CLI tool with an optional executable path
- **`GuiApp`** — GUI application requiring an executable path and optional bundle ID (macOS)
- **`Service`** — System service with a required service name and optional executable path

Key methods:
- `executable_path()` — Returns the executable path regardless of variant
- `is_standard()` / `is_gui_app()` / `is_service()` — Type guard helpers

### `InstalledAsset`
Represents a file/binary asset associated with an installed tool, tracking its `id`, `version`, and whether it is directly `executable`.

### `InstalledTool`
Top-level struct representing a fully installed tool, containing:
- Identity fields: `tool_agent_id`, `tool_id`, `tool_type`, `version`
- Execution config: `run_command_args`, `tool_agent_id_command_args`
- Optional `uninstallation_command_args`
- An `Installation` variant and a list of `InstalledAsset`s

## Usage Example

```rust
let tool = InstalledTool {
    tool_agent_id: "agent-001".into(),
    tool_id: "my-tool".into(),
    tool_type: "cli".into(),
    version: "1.2.0".into(),
    run_command_args: vec!["run".into()],
    installation: Installation::Service {
        service_name: "my-tool-svc".into(),
        executable_path: Some("/usr/bin/my-tool".into()),
    },
    ..Default::default()
};

assert!(tool.installation.is_service());
assert_eq!(tool.installation.executable_path(), Some("/usr/bin/my-tool"));
```
