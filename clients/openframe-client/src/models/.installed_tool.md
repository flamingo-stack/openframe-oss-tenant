Defines data structures for representing installed tools and their installation metadata within the Flamingo/OpenFrame platform.

## Key Components

### `Installation` (enum)
Tagged enum describing how a tool is installed, with three variants:
- **`Standard`** — CLI/standard tool with an optional executable path
- **`GuiApp`** — GUI application with a required executable path and optional bundle ID (macOS)
- **`Service`** — System service with a required service name and optional executable path

**Methods:**
- `executable_path()` — Returns the executable path across all variants
- `is_standard()`, `is_gui_app()`, `is_service()` — Variant type guards

### `InstalledAsset` (struct)
Represents a single file asset associated with a tool installation, tracking its `id`, `version`, and whether it is `executable`.

### `InstalledTool` (struct)
Top-level record for a fully installed tool, containing:
- Identity fields: `tool_agent_id`, `tool_id`, `tool_type`, `version`
- Runtime fields: `run_command_args`, `tool_agent_id_command_args`, `uninstallation_command_args`
- Installation metadata: `installation` (typed via `Installation` enum), `assets`

## Usage Example

```rust
let tool = InstalledTool {
    tool_agent_id: "agent-123".into(),
    tool_id: "my-tool".into(),
    tool_type: "cli".into(),
    version: "1.0.0".into(),
    run_command_args: vec!["--run".into()],
    installation: Installation::Service {
        service_name: "my-tool-svc".into(),
        executable_path: Some("/usr/bin/my-tool".into()),
    },
    assets: vec![InstalledAsset {
        id: "binary".into(),
        version: "1.0.0".into(),
        executable: true,
    }],
    ..Default::default()
};

// Check installation type and retrieve executable
assert!(tool.installation.is_service());
assert_eq!(tool.installation.executable_path(), Some("/usr/bin/my-tool"));
```
