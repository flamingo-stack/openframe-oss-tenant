Root module for the OpenFrame agent messaging and configuration types, re-exporting all public structs, enums, and traits used across the agent lifecycle — from registration and configuration to tool management and execution.

## Key Components

### Registration & Configuration
| Export | Description |
|---|---|
| `AgentRegistrationRequest` / `AgentRegistrationResponse` | Handshake messages for agent onboarding |
| `AgentConfiguration` / `InitialConfiguration` | Runtime and bootstrap configuration |
| `AgentTokenResponse` | Auth token returned after registration |
| `DownloadConfiguration` / `InstallationType` | Asset download and install type definitions |

### Tool Management
| Export | Description |
|---|---|
| `ToolInstallationMessage` / `ToolInstallationResult` | Tool install lifecycle |
| `ToolConnectionMessage` / `ToolConnection` | Tool connectivity state |
| `ToolUninstallMessage` / `ToolRestartMessage` | Tool lifecycle control |
| `InstalledTool` / `Installation` / `InstalledAsset` / `ToolRecordState` | Installed tool records |
| `ToolAgentUpdateMessage` / `AssetUpdate` | Tool agent update payloads |

### Execution
| Export | Description |
|---|---|
| `ExecutionRequest` / `ExecutionMessage` / `RmmResult` | RMM command execution |
| `CommandMessage` / `ScriptMessage` | Command and script dispatch |
| `ScriptSpec` / `ScriptShell` / `ScriptEnvVar` | Script configuration |
| `ScriptScheduleExecutionMessage` / `ScriptScheduleExecutionItem` | Scheduled script execution |
| `PrivilegeLevel` | Execution privilege control |

### Heartbeat & Updates
| Export | Description |
|---|---|
| `MachineHeartbeatMessage` | Periodic device health signal |
| `OpenFrameClientUpdateMessage` / `OpenFrameClientInfo` | Client update and info |
| `UpdateState` / `UpdatePhase` | Update lifecycle tracking |
| `InstalledAgentMessage` | Agent installation report |
| `DeviceTag` | Device tagging metadata |

## Usage Example

```rust
use openframe_oss_tenant::models::{
    AgentRegistrationRequest,
    ExecutionRequest,
    PrivilegeLevel,
    MachineHeartbeatMessage,
    ToolInstallationMessage,
};

// Register an agent
let reg = AgentRegistrationRequest { /* .. */ };

// Dispatch a privileged script execution
let exec = ExecutionRequest {
    privilege_level: PrivilegeLevel::Admin,
    /* .. */
};
```
