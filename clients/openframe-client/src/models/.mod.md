Module index for the OpenFrame agent messaging and configuration types, re-exporting all public structs and enums used for agent lifecycle management, tool installation, and device communication.

## Key Components

| Export | Description |
|--------|-------------|
| `AgentRegistrationRequest/Response` | Handles agent registration handshake with the OpenFrame platform |
| `AgentConfiguration` / `InitialConfiguration` | Agent and bootstrap configuration structures |
| `AgentTokenResponse` | Authentication token returned after registration |
| `ToolInstallationMessage` / `ToolInstallationResult` | Tool install lifecycle messaging |
| `ToolConnectionMessage` / `ToolConnection` | Tool connectivity state and messaging |
| `InstalledTool`, `Installation`, `InstalledAsset` | Represents an installed tool and its assets |
| `OpenFrameClientUpdateMessage` / `OpenFrameClientInfo` | Client-side update messages and metadata |
| `ToolAgentUpdateMessage`, `AssetUpdate` | Tool agent update payloads |
| `MachineHeartbeatMessage` | Periodic heartbeat from managed devices |
| `DownloadConfiguration`, `InstallationType` | Download and install type configuration |
| `InstalledAgentMessage` | Reports installed agent state |
| `UpdateState`, `UpdatePhase` | Tracks multi-phase update progress |
| `DeviceTag` | Tag metadata associated with a managed device |

## Usage Example

```rust
use crate::models::{
    AgentRegistrationRequest,
    AgentConfiguration,
    MachineHeartbeatMessage,
    UpdateState,
    UpdatePhase,
    DeviceTag,
};

// Build a registration request
let request = AgentRegistrationRequest { /* fields */ };

// Track update progress
let state = UpdateState {
    phase: UpdatePhase::Downloading,
    // ...
};

// Tag a device
let tag = DeviceTag { /* fields */ };
```

> **Note:** All types in this module are part of the OpenFrame agent protocol layer. They are used by the Flamingo platform to manage device registration, tool deployment, and real-time status reporting across the MSP fleet.
