Central module aggregator for OpenFrame agent messaging and configuration types, re-exporting all public structs and enums used in agent lifecycle management, tool operations, and device communication.

## Key Components

| Export | Description |
|--------|-------------|
| `AgentRegistrationRequest/Response` | Handles agent registration handshake with the OpenFrame platform |
| `AgentConfiguration` / `InitialConfiguration` | Agent config and bootstrap configuration structures |
| `AgentTokenResponse` | Auth token payload returned after agent authentication |
| `ToolInstallationMessage` / `ToolInstallationResult` | Tool install lifecycle messaging and result reporting |
| `ToolConnectionMessage` / `ToolConnection` | Tool connectivity state and connection event messages |
| `InstalledTool` / `Installation` / `InstalledAsset` | Represents a fully installed tool with its assets and install metadata |
| `OpenFrameClientUpdateMessage` / `OpenFrameClientInfo` | Client update notification and client identity info |
| `ToolAgentUpdateMessage` / `AssetUpdate` | Tool agent update events including individual asset changes |
| `MachineHeartbeatMessage` | Periodic heartbeat payload sent from agent to platform |
| `DownloadConfiguration` / `InstallationType` | Download settings and installation type variants |
| `InstalledAgentMessage` | Message confirming agent installation status |
| `UpdateState` / `UpdatePhase` | Tracks the current state and phase of an ongoing update |
| `DeviceTag` | Tag metadata associated with a managed device |
