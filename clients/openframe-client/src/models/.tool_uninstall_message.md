Defines the `ToolUninstallMessage` struct used to deserialize incoming requests to uninstall a tool agent from the OpenFrame tenant.

## Key Components

- **`ToolUninstallMessage`** – A deserializable message struct containing the identifier of the tool agent to be uninstalled.
  - `tool_agent_id: String` – The unique ID of the tool agent targeted for removal. Deserialized from camelCase JSON (`toolAgentId`).

## Usage Example

```rust
use serde_json::json;
use crate::tool_uninstall_message::ToolUninstallMessage;

let payload = json!({ "toolAgentId": "agent-abc-123" });
let msg: ToolUninstallMessage = serde_json::from_value(payload).unwrap();

println!("Uninstalling agent: {}", msg.tool_agent_id);
```
