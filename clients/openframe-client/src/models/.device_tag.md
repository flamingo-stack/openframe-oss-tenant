Defines the `DeviceTag` struct and its CLI parsing logic, representing key-multi-value tag pairs used for device filtering and classification.

## Key Components

**`DeviceTag`**
A serializable struct with two fields:
- `key: String` — the tag name (e.g., `"site"`, `"env"`)
- `values: Vec<String>` — one or more values associated with that key

**`DeviceTag::parse_from_cli(raw_tags: Vec<String>) -> Vec<Self>`**
Parses raw CLI strings in `key=value` format into grouped `DeviceTag` entries. Multiple entries sharing the same key are merged into a single `DeviceTag` with multiple values. Invalid entries are silently skipped:
- Missing `=` separator
- Empty key or empty/whitespace-only value

## Usage Example

```rust
use device_tag::DeviceTag;

let raw = vec![
    "site=CHICAGO".to_string(),
    "site=NEW YORK".to_string(),
    "env=production".to_string(),
    "invalid_no_equals".to_string(), // skipped
    "empty=".to_string(),            // skipped
];

let tags = DeviceTag::parse_from_cli(raw);
// tags[site] => ["CHICAGO", "NEW YORK"]
// tags[env]  => ["production"]
```

## Parsing Behavior

| Input | Result |
|-------|--------|
| `"site=CHICAGO"` | `{ key: "site", values: ["CHICAGO"] }` |
| `"site=A"` + `"site=B"` | `{ key: "site", values: ["A", "B"] }` |
| `"invalid"` (no `=`) | Skipped |
| `"key="` or `"=val"` | Skipped |
| `"key=   "` (whitespace) | Skipped |
