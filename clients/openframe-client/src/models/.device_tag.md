Defines the `DeviceTag` struct and its CLI parsing logic for grouping key-value tag strings into structured tag objects used for device filtering and classification.

## Key Components

### `DeviceTag` (struct)
Represents a device tag with a single key and one or more associated values. Derives `Debug`, `Clone`, `Serialize`, `Deserialize`, and `PartialEq`.

| Field | Type | Description |
|-------|------|-------------|
| `key` | `String` | The tag key (e.g., `"site"`) |
| `values` | `Vec<String>` | One or more values associated with the key |

### `DeviceTag::parse_from_cli`
Parses a flat list of `"key=value"` strings into grouped `DeviceTag` instances. Multiple entries sharing the same key are merged into a single tag with multiple values. Invalid entries (missing `=`, empty key, or empty/whitespace-only value) are silently skipped.

## Usage Example

```rust
use device_tag::DeviceTag;

let raw = vec![
    "site=CHICAGO".to_string(),
    "site=NEW YORK".to_string(),
    "env=production".to_string(),
    "invalid_entry".to_string(), // skipped
    "empty=".to_string(),        // skipped
];

let tags = DeviceTag::parse_from_cli(raw);
// tags[0] => DeviceTag { key: "site", values: ["CHICAGO", "NEW YORK"] }
// tags[1] => DeviceTag { key: "env",  values: ["production"] }
```

## Parsing Rules

- Entries are split on the **first** `=` character only
- Keys and values are **trimmed** of surrounding whitespace
- Entries with an **empty key**, **empty value**, or **no `=`** are ignored
- Multiple entries with the **same key** are merged into one `DeviceTag`
