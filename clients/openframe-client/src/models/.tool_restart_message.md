Defines the `ToolRestartMessage` struct used to deserialize incoming restart requests targeting a specific tool agent.

## Key Components

- **`ToolRestartMessage`** — A deserializable message struct carrying the identifier of the tool agent to be restarted.

| Field | Type | Description |
|---|---|---|
| `tool_agent_id` | `String` | The unique ID of the tool agent to restart (camelCase in JSON: `toolAgentId`) |

## Usage Example

```rust
use serde_json;
use crate::ToolRestartMessage;

let json = r#"{ "toolAgentId": "agent-42" }"#;
let msg: ToolRestartMessage = serde_json::from_str(json).unwrap();

println!("Restarting agent: {}", msg.tool_agent_id);
```

## Notes

- The struct derives `Clone` and `Debug`, making it suitable for logging and passing across async task boundaries.
- JSON field names use `camelCase` via `#[serde(rename_all = "camelCase")]`, while Rust fields follow `snake_case` convention.
