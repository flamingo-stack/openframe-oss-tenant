Defines serializable message structures for tool agent update payloads, carrying version and download configuration data for agents and their associated assets.

## Key Components

### `ToolAgentUpdateMessage`
Top-level update message for a tool agent, containing:
- `tool_agent_id` — unique identifier for the agent being updated
- `version` — target version string for the update
- `download_configurations` — required list of [`DownloadConfiguration`](https://github.com/flamingo-stack/openframe-oss-tenant/blob/main/src/models/download_configuration.rs) entries
- `assets` — optional list of `AssetUpdate` entries associated with this agent

### `AssetUpdate`
Describes an individual asset included in the update:
- `asset_id` — unique identifier for the asset
- `version` — optional version override for the asset
- `executable` — whether the asset should be marked executable (defaults to `false`)
- `download_configurations` — optional per-asset download configurations

Both structs serialize/deserialize with `camelCase` field naming via `serde`.

## Usage Example

```rust
use crate::models::tool_agent_update_message::{AssetUpdate, ToolAgentUpdateMessage};
use crate::models::download_configuration::DownloadConfiguration;

let update = ToolAgentUpdateMessage {
    tool_agent_id: "agent-123".to_string(),
    version: "2.1.0".to_string(),
    download_configurations: vec![DownloadConfiguration { /* ... */ }],
    assets: Some(vec![
        AssetUpdate {
            asset_id: "binary-x64".to_string(),
            version: Some("2.1.0".to_string()),
            executable: true,
            download_configurations: None,
        },
    ]),
};

let json = serde_json::to_string(&update)?;
// Serializes to camelCase: { "toolAgentId": "agent-123", ... }
```
