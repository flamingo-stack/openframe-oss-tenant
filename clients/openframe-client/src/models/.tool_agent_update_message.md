Defines serializable message structures for communicating tool agent update payloads, including versioned asset metadata and download configuration details.

## Key Components

- **`ToolAgentUpdateMessage`** — Top-level message struct representing an update for a specific tool agent, carrying its ID, target version, required download configurations, and an optional list of asset updates.
- **`AssetUpdate`** — Nested struct describing an individual asset within an update, including its ID, optional version pin, executable flag (defaults to `false`), and optional per-asset download configurations.

Both structs derive `Debug`, `Clone`, `Serialize`, and `Deserialize`, with all fields serialized using `camelCase` naming via `serde`.

## Usage Example

```rust
use crate::models::tool_agent_update_message::{ToolAgentUpdateMessage, AssetUpdate};
use crate::models::download_configuration::DownloadConfiguration;

let message = ToolAgentUpdateMessage {
    tool_agent_id: "agent-123".to_string(),
    version: "2.1.0".to_string(),
    download_configurations: vec![DownloadConfiguration {
        url: "https://cdn.example.com/agent-2.1.0.tar.gz".to_string(),
        checksum: Some("sha256:abc123".to_string()),
    }],
    assets: Some(vec![AssetUpdate {
        asset_id: "plugin-x".to_string(),
        version: Some("1.0.5".to_string()),
        executable: true,
        download_configurations: None,
    }]),
};

let json = serde_json::to_string(&message)?;
// Serializes to camelCase JSON:
// {"toolAgentId":"agent-123","version":"2.1.0",...}
```
