Defines serializable message structures for delivering tool agent update payloads, including version metadata, download configurations, and optional asset updates.

## Key Components

### `ToolAgentUpdateMessage`
Top-level update message payload for a tool agent, containing:
- `tool_agent_id` — identifier of the agent being updated
- `version` — target version string
- `download_configurations` — required list of [`DownloadConfiguration`] entries
- `assets` — optional list of [`AssetUpdate`] entries for associated assets

### `AssetUpdate`
Describes an individual asset update within a tool agent update, containing:
- `asset_id` — identifier of the asset
- `version` — optional version override for the asset
- `executable` — whether the asset should be marked executable (defaults to `false`)
- `download_configurations` — optional asset-specific download configurations

Both structs implement `Debug`, `Clone`, `Serialize`, and `Deserialize`, with fields serialized using `camelCase` JSON keys.

## Usage Example

```rust
use crate::models::tool_agent_update_message::{AssetUpdate, ToolAgentUpdateMessage};
use crate::models::download_configuration::DownloadConfiguration;

let update = ToolAgentUpdateMessage {
    tool_agent_id: "agent-123".to_string(),
    version: "2.1.0".to_string(),
    download_configurations: vec![DownloadConfiguration { /* ... */ }],
    assets: Some(vec![AssetUpdate {
        asset_id: "asset-456".to_string(),
        version: Some("1.0.0".to_string()),
        executable: true,
        download_configurations: None,
    }]),
};

let json = serde_json::to_string(&update)?;
// Serializes with camelCase keys: { "toolAgentId": "agent-123", ... }
```
