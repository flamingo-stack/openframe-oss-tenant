Defines the serializable message structures used to communicate tool agent update payloads, including versioned download configurations and optional asset updates.

## Key Components

- **`ToolAgentUpdateMessage`** — Top-level update message carrying the target agent ID, version string, required download configurations, and an optional list of asset updates
- **`AssetUpdate`** — Describes an individual asset within an update, including its ID, optional version, executable flag (defaults to `false`), and optional per-asset download configurations
- Both structs implement `Debug`, `Clone`, `Serialize`, and `Deserialize` with camelCase JSON field naming via `#[serde(rename_all = "camelCase")]`

## Usage Example

```rust
use crate::models::tool_agent_update_message::{ToolAgentUpdateMessage, AssetUpdate};
use crate::models::download_configuration::DownloadConfiguration;

let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "agent-123".to_string(),
    version: "1.2.0".to_string(),
    download_configurations: vec![
        DownloadConfiguration { /* ... */ }
    ],
    assets: Some(vec![
        AssetUpdate {
            asset_id: "asset-abc".to_string(),
            version: Some("2.0.0".to_string()),
            executable: true,
            download_configurations: None,
        }
    ]),
};

// Serialize to JSON (fields rendered as camelCase)
let json = serde_json::to_string(&update_message)?;
// {"toolAgentId":"agent-123","version":"1.2.0",...}
```
