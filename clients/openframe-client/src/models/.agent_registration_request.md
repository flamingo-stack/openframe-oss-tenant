Serializable request payload for registering an agent with the Flamingo platform, containing device identity and metadata fields.

## Key Components

- **`AgentRegistrationRequest`** — Main struct representing the registration payload sent to the backend API
  - `hostname` — Device hostname
  - `agent_version` — Version string of the running agent
  - `organization_id` — Optional org identifier (omitted from JSON if empty)
  - `os_type` — Operating system type identifier
  - `tags` — Optional list of [`DeviceTag`](super::DeviceTag) labels (omitted from JSON if empty)

Serializes to `camelCase` JSON via `serde`.

## Usage Example

```rust
use crate::models::{AgentRegistrationRequest, DeviceTag};

let request = AgentRegistrationRequest {
    hostname: String::from("workstation-01"),
    agent_version: String::from("1.2.0"),
    organization_id: String::from("org_abc123"),
    os_type: String::from("linux"),
    tags: vec![
        DeviceTag { key: "env".into(), value: "production".into() },
    ],
};

// organization_id and tags are omitted from JSON when empty
let empty_request = AgentRegistrationRequest {
    hostname: String::from("workstation-02"),
    agent_version: String::from("1.2.0"),
    organization_id: String::new(),   // skipped in JSON
    os_type: String::from("windows"),
    tags: vec![],                      // skipped in JSON
};

let json = serde_json::to_string(&request)?;
// {"hostname":"workstation-01","agentVersion":"1.2.0",...}
```
