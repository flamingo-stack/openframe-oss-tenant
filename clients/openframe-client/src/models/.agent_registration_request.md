Serializable request payload for registering a new agent with the Flamingo platform, containing device identity and metadata fields.

## Key Components

- **`AgentRegistrationRequest`** – Public struct that represents the JSON body sent during agent registration. Fields are serialized in `camelCase`.

| Field | Type | Notes |
|---|---|---|
| `hostname` | `String` | Device hostname |
| `agent_version` | `String` | Version of the running agent |
| `organization_id` | `String` | Skipped if empty |
| `os_type` | `String` | Operating system type |
| `tags` | `Vec<DeviceTag>` | Skipped if empty |

## Usage Example

```rust
use crate::models::{AgentRegistrationRequest, DeviceTag};

let request = AgentRegistrationRequest {
    hostname: String::from("workstation-01"),
    agent_version: String::from("1.4.2"),
    organization_id: String::from("org_abc123"),
    os_type: String::from("linux"),
    tags: vec![
        DeviceTag { key: "env".into(), value: "production".into() },
    ],
};

// Serializes to camelCase JSON:
// {
//   "hostname": "workstation-01",
//   "agentVersion": "1.4.2",
//   "organizationId": "org_abc123",
//   "osType": "linux",
//   "tags": [{ "key": "env", "value": "production" }]
// }
let json = serde_json::to_string(&request)?;
```

> `organization_id` and `tags` are omitted from the serialized output when empty, keeping the payload minimal for agentless or untagged registrations.
