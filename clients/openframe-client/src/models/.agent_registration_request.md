Serializable request payload for registering an agent with the OpenFrame platform, containing device identity and metadata fields.

## Key Components

- **`AgentRegistrationRequest`** — Primary struct representing the registration payload sent to the OpenFrame API when a new agent comes online.

| Field | Type | Notes |
|---|---|---|
| `hostname` | `String` | Device hostname |
| `agent_version` | `String` | Version of the running agent |
| `organization_id` | `String` | Skipped if empty |
| `os_type` | `String` | Operating system type |
| `tags` | `Vec<DeviceTag>` | Skipped if empty |

**Serde behavior:**
- Fields are serialized using `camelCase` naming (e.g., `agent_version` → `agentVersion`)
- `organization_id` is omitted from JSON when empty
- `tags` is omitted from JSON when the vec is empty

## Usage Example

```rust
use crate::models::{AgentRegistrationRequest, DeviceTag};

let request = AgentRegistrationRequest {
    hostname: "workstation-01".to_string(),
    agent_version: "1.2.0".to_string(),
    organization_id: "org_abc123".to_string(),
    os_type: "windows".to_string(),
    tags: vec![DeviceTag {
        key: "env".to_string(),
        value: "production".to_string(),
    }],
};

let json = serde_json::to_string(&request)?;
// {"hostname":"workstation-01","agentVersion":"1.2.0","organizationId":"org_abc123","osType":"windows","tags":[...]}
```
