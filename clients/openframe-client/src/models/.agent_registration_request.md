Serializable request payload for registering an agent with the Flamingo platform, carrying device identity and metadata.

## Key Components

- **`AgentRegistrationRequest`** — Primary struct representing the registration payload sent to the server
  - `hostname` — The device's hostname
  - `agent_version` — Version string of the running agent
  - `organization_id` — Optional org identifier; omitted from serialization if empty
  - `os_type` — Operating system type of the device
  - `tags` — Optional list of `DeviceTag` labels; omitted from serialization if empty

## Serialization Behavior

- Serializes to **camelCase** JSON via `#[serde(rename_all = "camelCase")]`
- `organization_id` is **skipped** when empty (`skip_serializing_if = "String::is_empty"`)
- `tags` is **skipped** when empty (`skip_serializing_if = "Vec::is_empty"`)

## Usage Example

```rust
use crate::models::{AgentRegistrationRequest, DeviceTag};

let request = AgentRegistrationRequest {
    hostname: String::from("workstation-01"),
    agent_version: String::from("1.4.2"),
    organization_id: String::from("org_abc123"),
    os_type: String::from("linux"),
    tags: vec![
        DeviceTag { key: "env".into(), value: "production".into() },
    ],
};

let json = serde_json::to_string(&request).unwrap();
// {"hostname":"workstation-01","agentVersion":"1.4.2","organizationId":"org_abc123","osType":"linux","tags":[...]}
```
