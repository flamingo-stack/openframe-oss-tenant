Configuration structure for managing platform-specific file downloads with OS detection and path analysis capabilities.

## Key Components

- **DownloadConfiguration**: Main struct containing download metadata including OS target, file names, and download URL
- **is_folder_extraction()**: Determines if the target file requires full archive extraction based on path complexity
- **matches_current_os()**: Cross-platform OS detection method that compares configuration OS with current runtime environment

## Usage Example

```rust
use serde_json::from_str;

// Parse download configuration from JSON
let config: DownloadConfiguration = from_str(r#"
{
    "os": "windows",
    "fileName": "agent.zip",
    "targetFileName": "bin/agent.exe",
    "link": "https://releases.example.com/agent-windows.zip"
}
"#)?;

// Check if current platform matches
if config.matches_current_os() {
    println!("Compatible with current OS: {}", config.os);
    
    // Determine extraction method
    if config.is_folder_extraction() {
        println!("Requires full archive extraction to: {}", config.target_file_name);
    } else {
        println!("Single file extraction: {}", config.target_file_name);
    }
    
    // Proceed with download from config.link
}
```

The struct supports flexible JSON field naming through serde aliases (`agentFileName`, `assetFileName`) and provides camelCase serialization for API compatibility.
