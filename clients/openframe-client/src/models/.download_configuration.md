A configuration struct for managing cross-platform file downloads, with OS matching and extraction type detection capabilities.

## Key Components

- **`DownloadConfiguration`** - Main struct containing download metadata including OS target, file names, and download URL
- **`is_folder_extraction()`** - Determines if the target requires full archive extraction based on path complexity
- **`matches_current_os()`** - Cross-platform OS detection and matching logic

## Usage Example

```rust
use serde_json;

// Parse download config from JSON
let config: DownloadConfiguration = serde_json::from_str(r#"
{
    "os": "windows",
    "fileName": "agent-v1.0.zip",
    "targetFileName": "bin/agent.exe",
    "link": "https://releases.example.com/v1.0/windows.zip"
}
"#).unwrap();

// Check if this config applies to current system
if config.matches_current_os() {
    println!("Downloading: {}", config.link);
    
    // Determine extraction strategy
    if config.is_folder_extraction() {
        println!("Full archive extraction needed for: {}", config.target_file_name);
    } else {
        println!("Single file extraction: {}", config.target_file_name);
    }
}
```

The struct supports JSON deserialization with camelCase conversion and flexible field aliases (`agentFileName`, `assetFileName`) for backward compatibility.
