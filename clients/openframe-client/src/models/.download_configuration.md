Configuration struct for managing cross-platform software downloads with OS-specific targeting and file extraction handling.

## Key Components

- **`DownloadConfiguration`** - Main struct containing download metadata (OS, filenames, URL)
- **`is_folder_extraction()`** - Determines if the target file requires extracting from an archive based on path structure
- **`matches_current_os()`** - Cross-platform OS detection utility for filtering compatible downloads

## Usage Example

```rust
use serde_json::json;

// Create download config from JSON
let config: DownloadConfiguration = serde_json::from_value(json!({
    "os": "windows",
    "fileName": "installer.zip", 
    "targetFileName": "bin/agent.exe",
    "link": "https://releases.example.com/v1.0.0/installer.zip"
}))?;

// Check if this config applies to current system
if config.matches_current_os() {
    println!("Compatible with current OS: {}", config.os);
    
    // Determine extraction strategy
    if config.is_folder_extraction() {
        println!("Requires archive extraction to: {}", config.target_file_name);
    } else {
        println!("Simple file download: {}", config.file_name);
    }
}
```

The struct supports flexible JSON field naming through serde aliases (`agentFileName`, `assetFileName`) and uses camelCase serialization for API compatibility.
