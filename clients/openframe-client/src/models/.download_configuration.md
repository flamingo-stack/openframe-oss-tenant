A configuration structure that defines download parameters for OS-specific files, including archive extraction logic and OS matching capabilities.

## Key Components

- **`DownloadConfiguration`** - Main struct containing download metadata with OS, file names, and download link
- **`is_folder_extraction()`** - Determines if the target file name represents a nested path requiring full archive extraction
- **`matches_current_os()`** - Cross-platform OS detection that compares configuration OS against the current system

## Usage Example

```rust
use serde_json;

// Parse download configuration from JSON
let config_json = r#"
{
    "os": "linux",
    "fileName": "agent-v1.0.0-linux.tar.gz",
    "targetFileName": "bin/flamingo-agent",
    "link": "https://releases.example.com/agent-v1.0.0-linux.tar.gz"
}
"#;

let config: DownloadConfiguration = serde_json::from_str(config_json)?;

// Check if this config applies to current system
if config.matches_current_os() {
    println!("Downloading {} for current OS", config.file_name);
    
    // Determine extraction strategy
    if config.is_folder_extraction() {
        println!("Will extract entire archive to access: {}", config.target_file_name);
    } else {
        println!("Will extract single file: {}", config.target_file_name);
    }
}
```

The struct supports flexible JSON field naming through serde aliases (`agentFileName`, `assetFileName`) and provides platform-aware download logic for cross-platform deployment scenarios.
