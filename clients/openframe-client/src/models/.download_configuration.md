A configuration structure for managing cross-platform file downloads with OS-specific targeting and extraction behavior detection.

## Key Components

- **`DownloadConfiguration`** - Main struct containing download metadata (OS, file names, download link)
- **`is_folder_extraction()`** - Determines if the target requires full archive extraction based on path complexity
- **`matches_current_os()`** - Validates configuration compatibility with the current operating system

## Usage Example

```rust
use serde_json;

// Create a download configuration
let config = DownloadConfiguration {
    os: "linux".to_string(),
    file_name: "agent-v1.0.0.tar.gz".to_string(),
    target_file_name: "bin/agent".to_string(),
    link: "https://releases.example.com/agent-v1.0.0.tar.gz".to_string(),
};

// Check if this config matches current OS
if config.matches_current_os() {
    println!("Compatible with current OS");
}

// Determine extraction strategy
if config.is_folder_extraction() {
    println!("Requires full archive extraction");
} else {
    println!("Single file extraction");
}

// Deserialize from JSON with flexible field names
let json = r#"{
    "os": "windows",
    "fileName": "agent.exe",
    "agentFileName": "agent.exe",
    "link": "https://releases.example.com/agent.exe"
}"#;
let config: DownloadConfiguration = serde_json::from_str(json)?;
```

The struct supports flexible JSON deserialization with multiple field name aliases and provides platform detection for automated OS-specific downloads.
