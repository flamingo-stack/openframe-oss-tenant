A configuration structure for managing OS-specific file downloads with platform detection and path analysis capabilities.

## Key Components

- **`DownloadConfiguration`** - Main struct containing download metadata (OS, file names, download link)
- **`is_folder_extraction()`** - Determines if the target requires full archive extraction based on path depth
- **`matches_current_os()`** - Cross-platform OS detection matching configuration to runtime environment

## Usage Example

```rust
use serde_json;

// Parse download configuration from JSON
let config: DownloadConfiguration = serde_json::from_str(r#"
{
    "os": "linux",
    "fileName": "agent-v1.0.0-linux.tar.gz",
    "targetFileName": "bin/agent",
    "link": "https://releases.example.com/agent-v1.0.0-linux.tar.gz"
}
"#)?;

// Check if this config applies to current system
if config.matches_current_os() {
    println!("Downloading {} for current OS", config.file_name);
    
    // Determine extraction method
    if config.is_folder_extraction() {
        println!("Full archive extraction required for: {}", config.target_file_name);
    } else {
        println!("Single file extraction: {}", config.target_file_name);
    }
}
```

The struct supports flexible JSON field naming through serde aliases (`agentFileName`, `assetFileName`) and provides camelCase serialization for API compatibility.
