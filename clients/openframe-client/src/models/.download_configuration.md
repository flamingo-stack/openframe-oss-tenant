Defines a configuration structure for managing file downloads with OS-specific targeting and extraction requirements. Provides utilities for determining extraction behavior and OS compatibility matching.

## Key Components

- **`DownloadConfiguration`** - Serializable struct containing OS, file names, and download link
- **`is_folder_extraction()`** - Determines if the target requires full archive extraction based on path structure
- **`matches_current_os()`** - Validates configuration compatibility with the current operating system

## Usage Example

```rust
use serde_json;

// Parse download configuration from JSON
let config: DownloadConfiguration = serde_json::from_str(r#"
{
    "os": "linux",
    "fileName": "agent-v1.0.0-linux.tar.gz",
    "targetFileName": "bin/agent",
    "link": "https://releases.example.com/agent-v1.0.0-linux.tar.gz"
}
"#)?;

// Check if this config applies to current OS
if config.matches_current_os() {
    println!("Configuration matches current OS: {}", config.os);
}

// Determine extraction strategy
if config.is_folder_extraction() {
    println!("Requires full archive extraction for: {}", config.target_file_name);
} else {
    println!("Single file extraction: {}", config.target_file_name);
}
```

The struct supports flexible field naming through serde aliases (`agentFileName`, `assetFileName`) and uses camelCase serialization for JSON compatibility.
