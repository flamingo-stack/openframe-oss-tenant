Defines a configuration structure for managing file downloads across different operating systems with cross-platform compatibility checks and extraction type detection.

## Key Components

- **`DownloadConfiguration`** - Main struct containing OS type, file names, and download URL information
- **`is_folder_extraction()`** - Determines if the target file requires full archive extraction based on path structure
- **`matches_current_os()`** - Validates if the configuration is compatible with the current operating system

The struct uses serde for JSON serialization with camelCase conversion and supports multiple field name aliases for backward compatibility.

## Usage Example

```rust
use serde_json;

// Parse download configuration from JSON
let config_json = r#"{
    "os": "linux",
    "fileName": "agent.tar.gz",
    "targetFileName": "bin/flamingo-agent",
    "link": "https://releases.example.com/agent.tar.gz"
}"#;

let config: DownloadConfiguration = serde_json::from_str(config_json)?;

// Check if extraction is needed
if config.is_folder_extraction() {
    println!("Will extract archive to access: {}", config.target_file_name);
}

// Verify OS compatibility
if config.matches_current_os() {
    println!("Configuration matches current OS: {}", config.os);
    // Proceed with download from config.link
}
```

The configuration supports Windows, macOS, and Linux platforms with case-insensitive OS matching for robust cross-platform deployment scenarios.
