A serializable configuration struct that defines download parameters for cross-platform file distribution, including OS-specific targeting and extraction behavior detection.

## Key Components

- **`DownloadConfiguration`** - Main struct containing download metadata (OS, filenames, download link)
- **`is_folder_extraction()`** - Determines if the target file requires full archive extraction based on path complexity
- **`matches_current_os()`** - Cross-platform OS matching with case-insensitive comparison

## Usage Example

```rust
use serde_json;

// Parse download config from JSON
let config: DownloadConfiguration = serde_json::from_str(r#"
{
    "os": "Windows",
    "fileName": "agent-v1.0.0-win64.zip",
    "targetFileName": "bin/agent.exe",
    "link": "https://releases.example.com/agent-v1.0.0-win64.zip"
}
"#)?;

// Check if this config applies to current platform
if config.matches_current_os() {
    println!("Downloading: {}", config.link);
    
    // Determine extraction strategy
    if config.is_folder_extraction() {
        println!("Will extract archive to preserve directory structure");
    } else {
        println!("Simple file download");
    }
}
```

The struct supports flexible field aliases (`agentFileName`, `assetFileName`) for backward compatibility and uses camelCase JSON serialization for web API integration.
