Defines the configuration structure for downloading platform-specific files and provides utility methods for OS matching and extraction type detection.

## Key Components

- **`DownloadConfiguration`** - Main struct containing download metadata (OS, file names, download link)
- **`is_folder_extraction()`** - Determines if the target file requires archive extraction based on path components
- **`matches_current_os()`** - Cross-platform OS detection and matching utility

## Usage Example

```rust
use serde_json;

// Parse download configuration from JSON
let config_json = r#"{
    "os": "linux",
    "fileName": "agent-v1.0.tar.gz",
    "targetFileName": "bin/agent",
    "link": "https://releases.example.com/agent-v1.0-linux.tar.gz"
}"#;

let config: DownloadConfiguration = serde_json::from_str(config_json)?;

// Check if this config applies to current platform
if config.matches_current_os() {
    println!("Downloading for current OS: {}", config.os);
    
    // Determine extraction strategy
    if config.is_folder_extraction() {
        println!("Will extract archive to get: {}", config.target_file_name);
    } else {
        println!("Direct file download: {}", config.file_name);
    }
    
    // Download from config.link...
}
```

The struct supports flexible JSON field naming through serde aliases (`agentFileName`, `assetFileName`) and provides OS-agnostic platform detection for Windows, macOS, and Linux systems.
