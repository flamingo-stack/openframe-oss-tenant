Configuration structure for managing cross-platform file downloads, supporting OS-specific targeting and flexible file naming with archive extraction detection.

## Key Components

- **DownloadConfiguration** - Main configuration struct with OS targeting, file naming, and download URL management
- **is_folder_extraction()** - Detects if the target requires full archive extraction based on path complexity  
- **matches_current_os()** - Cross-platform OS detection and matching utility

## Usage Example

```rust
use serde_json;

// Parse download configuration from JSON
let config: DownloadConfiguration = serde_json::from_str(r#"
{
    "os": "linux",
    "fileName": "agent-v1.2.3-linux.tar.gz", 
    "targetFileName": "bin/flamingo-agent",
    "link": "https://releases.flamingo.run/agent/v1.2.3/linux.tar.gz"
}
"#).unwrap();

// Check if this config applies to current platform
if config.matches_current_os() {
    println!("Downloading: {}", config.link);
    
    // Determine extraction strategy
    if config.is_folder_extraction() {
        println!("Full archive extraction required for: {}", config.target_file_name);
    } else {
        println!("Direct file download: {}", config.target_file_name);
    }
}
```

The struct supports JSON serialization with camelCase field names and provides flexible field aliases (`agentFileName`, `assetFileName`) for backwards compatibility with different API formats.
