Configuration structure for managing cross-platform file downloads with OS-specific targeting and extraction handling.

## Key Components

- **`DownloadConfiguration`** - Main struct containing download metadata with camelCase JSON serialization
  - `os` - Target operating system identifier
  - `file_name` - Original filename of the download
  - `target_file_name` - Destination filename (supports legacy aliases)
  - `link` - Download URL

- **`is_folder_extraction()`** - Determines if the target requires full archive extraction based on path complexity
- **`matches_current_os()`** - Cross-platform OS detection and matching utility

## Usage Example

```rust
use serde_json;

// Create configuration from JSON
let config_json = r#"{
    "os": "linux",
    "fileName": "agent-v1.2.3.tar.gz",
    "targetFileName": "bin/agent",
    "link": "https://releases.example.com/agent-linux.tar.gz"
}"#;

let config: DownloadConfiguration = serde_json::from_str(config_json)?;

// Check if this config applies to current system
if config.matches_current_os() {
    // Determine extraction strategy
    if config.is_folder_extraction() {
        println!("Full archive extraction required for: {}", config.target_file_name);
    } else {
        println!("Single file download: {}", config.file_name);
    }
    
    // Proceed with download from config.link
}
```

The struct handles OS-specific download configurations with flexible JSON field naming and automatic platform detection for deployment scenarios.
