Configuration struct for managing platform-specific file downloads with OS detection and path validation capabilities.

## Key Components

- **`DownloadConfiguration`** - Main configuration struct containing download metadata (OS, file names, URLs)
- **`is_folder_extraction()`** - Determines if the target file path requires full archive extraction
- **`matches_current_os()`** - Validates if configuration is compatible with the current operating system

## Usage Example

```rust
use serde_json;

// Parse download configuration from JSON
let config_json = r#"{
    "os": "linux",
    "fileName": "agent-v1.2.3-linux.tar.gz",
    "targetFileName": "bin/agent",
    "link": "https://releases.example.com/agent-v1.2.3-linux.tar.gz"
}"#;

let config: DownloadConfiguration = serde_json::from_str(config_json)?;

// Check if this config applies to current OS
if config.matches_current_os() {
    println!("Downloading {} for {}", config.file_name, config.os);
    
    // Determine extraction method
    if config.is_folder_extraction() {
        println!("Will extract entire archive to access: {}", config.target_file_name);
    } else {
        println!("Single file download: {}", config.target_file_name);
    }
}
```

The struct supports flexible JSON field naming through serde aliases (`agentFileName`, `assetFileName`) and provides cross-platform OS detection for Windows, macOS, and Linux systems.
