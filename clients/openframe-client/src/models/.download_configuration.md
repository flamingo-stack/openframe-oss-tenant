Configuration structure for defining download parameters across different operating systems with automatic OS detection and path validation.

## Key Components

- **`DownloadConfiguration`** - Main struct containing OS-specific download metadata including target OS, file names, and download URLs
- **`is_folder_extraction()`** - Determines if the target file is a nested path requiring archive extraction
- **`matches_current_os()`** - Cross-platform OS matching with case-insensitive comparison

## Usage Example

```rust
use download_configuration::DownloadConfiguration;

// Create download config for Windows agent
let config = DownloadConfiguration {
    os: "Windows".to_string(),
    file_name: "agent-v1.2.3.zip".to_string(),
    target_file_name: "bin/agent.exe".to_string(),
    link: "https://releases.example.com/agent.zip".to_string(),
};

// Check if extraction is needed (true - nested path detected)
if config.is_folder_extraction() {
    println!("Archive extraction required");
}

// Verify OS compatibility
if config.matches_current_os() {
    println!("Compatible with current platform");
}
```

The struct supports JSON serialization with camelCase field names and provides aliases for backward compatibility with legacy field names (`agentFileName`, `assetFileName`).
