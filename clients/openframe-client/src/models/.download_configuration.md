Defines a configuration structure for managing file downloads across different operating systems, with utilities for OS matching and extraction type detection.

## Key Components

- **`DownloadConfiguration`** - Main struct containing OS, file names, and download URL
- **`is_folder_extraction()`** - Determines if the target file requires archive extraction
- **`matches_current_os()`** - Validates if the configuration applies to the current operating system

## Usage Example

```rust
use serde_json;

// Create download configuration from JSON
let config_json = r#"{
    "os": "linux",
    "fileName": "agent-v1.0.tar.gz",
    "targetFileName": "bin/agent",
    "link": "https://releases.example.com/agent-v1.0.tar.gz"
}"#;

let config: DownloadConfiguration = serde_json::from_str(config_json)?;

// Check if this config applies to current OS
if config.matches_current_os() {
    println!("Downloading: {}", config.link);
    
    // Check if we need to extract from archive
    if config.is_folder_extraction() {
        println!("Will extract {} from archive", config.target_file_name);
    } else {
        println!("Direct file download");
    }
}
```

The struct supports flexible JSON field naming through serde aliases (`agentFileName`, `assetFileName`) and uses camelCase serialization for API compatibility.
