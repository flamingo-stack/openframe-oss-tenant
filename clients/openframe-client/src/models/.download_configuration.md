Configuration structure for managing OS-specific file downloads with automatic OS detection and extraction type determination.

## Key Components

- **DownloadConfiguration**: Main struct containing download metadata including OS target, file names, and download URL
- **is_folder_extraction()**: Method to determine if the target requires full archive extraction based on path complexity
- **matches_current_os()**: Method to check if configuration matches the current operating system

## Usage Example

```rust
use serde_json;

// Create download configuration from JSON
let config_json = r#"{
    "os": "linux",
    "fileName": "agent-v1.0.0-linux.tar.gz",
    "agentFileName": "bin/agent",
    "link": "https://releases.example.com/agent-v1.0.0-linux.tar.gz"
}"#;

let config: DownloadConfiguration = serde_json::from_str(config_json)?;

// Check if this config applies to current OS
if config.matches_current_os() {
    println!("Using config for current OS: {}", config.os);
    
    // Determine extraction strategy
    if config.is_folder_extraction() {
        println!("Full archive extraction required for: {}", config.target_file_name);
    } else {
        println!("Single file extraction: {}", config.target_file_name);
    }
    
    // Download from the specified link
    println!("Downloading from: {}", config.link);
}
```

The struct supports flexible JSON field naming through serde aliases (`agentFileName`, `assetFileName`) and uses camelCase serialization for consistent API integration.
