Configuration structure for managing cross-platform software downloads with OS detection and extraction requirements validation.

## Key Components

- **`DownloadConfiguration`** - Serializable struct containing download metadata including OS target, file names, and download URL
- **`is_folder_extraction()`** - Determines if the target file is nested in a directory structure requiring full archive extraction
- **`matches_current_os()`** - Cross-platform OS detection method that compares configuration OS against the current runtime environment

## Usage Example

```rust
use serde_json;

// Parse download configuration from JSON
let config: DownloadConfiguration = serde_json::from_str(r#"
{
    "os": "windows",
    "fileName": "agent-installer.zip",
    "targetFileName": "bin/agent.exe",
    "link": "https://releases.example.com/agent-v1.0.zip"
}
"#).unwrap();

// Check if current platform is supported
if config.matches_current_os() {
    println!("Compatible with current OS: {}", config.os);
    
    // Determine extraction strategy
    if config.is_folder_extraction() {
        println!("Requires full archive extraction for: {}", config.target_file_name);
    } else {
        println!("Single file extraction: {}", config.target_file_name);
    }
}
```

The struct uses flexible JSON field mapping with `serde` aliases to support different naming conventions (`agentFileName`, `assetFileName`) while maintaining consistent internal representation.
