A configuration struct for handling cross-platform file downloads with OS-specific targeting and extraction path detection.

## Key Components

- **`DownloadConfiguration`** - Main struct containing download metadata (OS, filenames, URL)
- **`is_folder_extraction()`** - Detects if the target requires full archive extraction based on path depth
- **`matches_current_os()`** - Validates if the configuration applies to the current operating system

## Usage Example

```rust
use serde_json;

// Parse download configuration from JSON
let config_json = r#"
{
    "os": "linux",
    "fileName": "agent-v1.0.tar.gz",
    "targetFileName": "bin/agent",
    "link": "https://releases.example.com/agent-v1.0.tar.gz"
}
"#;

let config: DownloadConfiguration = serde_json::from_str(config_json)?;

// Check if this config applies to current OS
if config.matches_current_os() {
    println!("Downloading: {}", config.link);
    
    // Determine extraction strategy
    if config.is_folder_extraction() {
        println!("Full archive extraction required for: {}", config.target_file_name);
    } else {
        println!("Single file extraction: {}", config.target_file_name);
    }
}
```

The struct supports flexible JSON field naming through serde aliases (`agentFileName`, `assetFileName`) and provides utility methods for cross-platform deployment scenarios.
