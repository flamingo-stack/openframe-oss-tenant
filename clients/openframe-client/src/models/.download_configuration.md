A configuration structure for handling cross-platform software downloads with OS-specific settings and extraction logic.

## Key Components

- **`DownloadConfiguration`** - Main struct containing download metadata (OS, filenames, download link)
- **`is_folder_extraction()`** - Determines if the target file requires archive extraction based on path complexity
- **`matches_current_os()`** - Cross-platform OS detection and matching for the current system

## Usage Example

```rust
use serde_json::json;

// Create download configuration from JSON
let config_json = json!({
    "os": "linux",
    "fileName": "agent-v1.2.3.tar.gz",
    "targetFileName": "bin/agent",
    "link": "https://releases.example.com/agent-v1.2.3.tar.gz"
});

let config: DownloadConfiguration = serde_json::from_value(config_json).unwrap();

// Check if extraction is needed
if config.is_folder_extraction() {
    println!("Archive extraction required for: {}", config.target_file_name);
}

// Verify OS compatibility
if config.matches_current_os() {
    println!("Compatible with current OS: {}", config.os);
    // Proceed with download from config.link
}
```

The struct supports flexible JSON field naming through serde aliases (`agentFileName`, `assetFileName`) and provides utility methods for download workflow decisions in cross-platform deployment scenarios.
