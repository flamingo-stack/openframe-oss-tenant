Configuration structure for managing cross-platform file downloads with automatic OS detection and path validation capabilities.

## Key Components

- **DownloadConfiguration** - Main struct for storing download metadata including OS target, file names, and download links
- **is_folder_extraction()** - Method to determine if the target requires full archive extraction based on path structure
- **matches_current_os()** - Method to validate configuration compatibility with the current operating system

## Usage Example

```rust
use serde_json;

// Parse download configuration from JSON
let config: DownloadConfiguration = serde_json::from_str(r#"{
    "os": "linux",
    "fileName": "agent-v1.0.0.tar.gz",
    "targetFileName": "bin/agent",
    "link": "https://releases.example.com/agent-v1.0.0-linux.tar.gz"
}"#)?;

// Check if this config is for the current OS
if config.matches_current_os() {
    // Determine extraction strategy
    if config.is_folder_extraction() {
        println!("Need to extract archive to access: {}", config.target_file_name);
    } else {
        println!("Direct file download: {}", config.file_name);
    }
    
    // Download from config.link
    download_file(&config.link, &config.file_name).await?;
}
```

The struct supports flexible JSON field naming through serde aliases, making it compatible with various API response formats while maintaining consistent internal naming conventions.
