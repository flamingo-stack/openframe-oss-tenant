Configuration struct for managing platform-specific download settings with OS detection and path analysis capabilities for Flamingo's agent deployment system.

## Key Components

- **`DownloadConfiguration`** - Main configuration struct with OS, file names, and download link
- **`is_folder_extraction()`** - Determines if the target requires full archive extraction
- **`matches_current_os()`** - Cross-platform OS detection for selecting appropriate downloads

## Usage Example

```rust
use serde_json::json;

// Create download configuration from JSON
let config: DownloadConfiguration = serde_json::from_value(json!({
    "os": "linux",
    "fileName": "agent-linux.tar.gz",
    "targetFileName": "bin/flamingo-agent",
    "link": "https://releases.flamingo.run/agent/v1.0.0/linux.tar.gz"
}))?;

// Check if this config applies to current platform
if config.matches_current_os() {
    println!("Using {} for current OS", config.file_name);
    
    // Determine extraction strategy
    if config.is_folder_extraction() {
        println!("Will extract entire archive to get: {}", config.target_file_name);
    } else {
        println!("Single file download: {}", config.target_file_name);
    }
}
```

The struct supports flexible JSON field naming through serde aliases and provides cross-platform compatibility checks for automated agent deployment across Windows, macOS, and Linux environments.
