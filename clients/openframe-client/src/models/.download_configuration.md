A configuration struct for managing cross-platform software downloads with OS-specific targeting and extraction handling.

## Key Components

### DownloadConfiguration
Main configuration struct that defines download parameters:
- `os` - Target operating system (windows/macos/linux)
- `file_name` - Original filename of the download
- `target_file_name` - Desired filename after download (supports legacy aliases)
- `link` - Download URL

### Methods
- `is_folder_extraction()` - Detects if the target requires directory extraction based on path components
- `matches_current_os()` - Validates configuration against the current platform

## Usage Example

```rust
use serde_json;

// Create configuration for Windows agent
let config = DownloadConfiguration {
    os: "windows".to_string(),
    file_name: "agent-v1.0.0-windows.zip".to_string(),
    target_file_name: "bin/agent.exe".to_string(),
    link: "https://releases.example.com/agent-v1.0.0-windows.zip".to_string(),
};

// Check if extraction is needed
if config.is_folder_extraction() {
    println!("Will extract to subfolder: {}", config.target_file_name);
}

// Validate OS compatibility
if config.matches_current_os() {
    println!("Compatible with current platform");
}

// Deserialize from JSON with camelCase fields
let json = r#"{
    "os": "linux",
    "fileName": "app.tar.gz",
    "agentFileName": "usr/bin/app",
    "link": "https://example.com/app.tar.gz"
}"#;
let config: DownloadConfiguration = serde_json::from_str(json)?;
```
