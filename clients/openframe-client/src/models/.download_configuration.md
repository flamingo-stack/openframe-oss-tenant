A configuration struct for managing platform-specific file downloads with OS detection and path extraction capabilities.

## Key Components

- **`DownloadConfiguration`** - Main struct containing download metadata (OS, filenames, URLs)
- **`is_folder_extraction()`** - Method to determine if the target requires full archive extraction
- **`matches_current_os()`** - Method to check OS compatibility using compile-time detection

## Usage Example

```rust
use serde_json;

// Parse download configuration from JSON
let config: DownloadConfiguration = serde_json::from_str(r#"
{
    "os": "linux",
    "fileName": "agent-v1.2.3.tar.gz",
    "targetFileName": "bin/agent",
    "link": "https://releases.example.com/agent-v1.2.3.tar.gz"
}
"#)?;

// Check if this config matches current platform
if config.matches_current_os() {
    println!("Compatible with current OS: {}", config.os);
    
    // Determine extraction method
    if config.is_folder_extraction() {
        println!("Requires full archive extraction to: {}", config.target_file_name);
    } else {
        println!("Single file download: {}", config.target_file_name);
    }
    
    // Use the download link
    download_file(&config.link, &config.file_name).await?;
}
```

The struct supports JSON serialization with camelCase formatting and provides flexible field aliases for compatibility with different API schemas.
