Configuration structure for platform-specific download operations, supporting cross-platform file retrieval with automatic OS detection and path handling.

## Key Components

- **`DownloadConfiguration`** - Serializable struct containing download metadata including OS target, file names, and download URL
- **`is_folder_extraction()`** - Method to determine if the target requires full archive extraction based on path complexity
- **`matches_current_os()`** - Platform detection utility that compares configuration OS with the current system

## Usage Example

```rust
use serde_json;

// Create a download configuration
let config = DownloadConfiguration {
    os: "linux".to_string(),
    file_name: "agent.tar.gz".to_string(),
    target_file_name: "bin/agent".to_string(),
    link: "https://releases.example.com/agent-linux.tar.gz".to_string(),
};

// Check if this config matches current OS
if config.matches_current_os() {
    println!("Configuration matches current platform");
}

// Determine extraction strategy
if config.is_folder_extraction() {
    println!("Full archive extraction required for: {}", config.target_file_name);
} else {
    println!("Single file extraction for: {}", config.target_file_name);
}

// Serialize/deserialize from JSON (supports camelCase)
let json = serde_json::to_string(&config)?;
let parsed: DownloadConfiguration = serde_json::from_str(&json)?;
```

The struct supports flexible JSON deserialization with field aliases (`agentFileName`, `assetFileName`) and automatic camelCase conversion, making it suitable for cross-language configuration files.
