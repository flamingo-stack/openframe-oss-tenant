Configuration structure for managing platform-specific agent downloads with OS detection and path validation capabilities.

## Key Components

**DownloadConfiguration struct**
- `os`: Target operating system identifier
- `file_name`: Name of the download file
- `agent_file_name`: Path to the agent executable within archives
- `link`: Download URL for the agent

**Core methods:**
- `is_folder_extraction()`: Determines if the agent requires archive extraction based on path depth
- `matches_current_os()`: Cross-platform OS detection and matching

## Usage Example

```rust
use serde_json;

// Create download configuration
let config = DownloadConfiguration {
    os: "linux".to_string(),
    file_name: "agent-linux.tar.gz".to_string(),
    agent_file_name: "bin/flamingo-agent".to_string(),
    link: "https://releases.flamingo.run/agent/latest/linux".to_string(),
};

// Check if extraction is needed
if config.is_folder_extraction() {
    println!("Archive extraction required for: {}", config.agent_file_name);
}

// Verify OS compatibility
if config.matches_current_os() {
    println!("Configuration matches current platform");
}

// Serialize for API responses
let json = serde_json::to_string(&config)?;
```

The struct uses camelCase serialization for JSON compatibility and provides platform-agnostic download management for the Flamingo agent deployment system.
