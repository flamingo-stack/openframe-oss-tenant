Configuration structure for managing platform-specific file downloads with OS detection and path extraction logic.

## Key Components

- **`DownloadConfiguration`** - Main struct containing download metadata with fields for OS, filenames, and download URL
- **`is_folder_extraction()`** - Method to determine if the target file requires full archive extraction based on path complexity
- **`matches_current_os()`** - Method to check if the configuration is compatible with the current operating system

## Usage Example

```rust
use serde_json;

// Deserialize from JSON configuration
let config: DownloadConfiguration = serde_json::from_str(r#"
{
    "os": "linux",
    "fileName": "agent.tar.gz",
    "targetFileName": "bin/agent",
    "link": "https://releases.example.com/agent-linux.tar.gz"
}
"#)?;

// Check OS compatibility
if config.matches_current_os() {
    println!("Configuration matches current OS: {}", config.os);
}

// Determine extraction strategy
if config.is_folder_extraction() {
    println!("Full archive extraction required for: {}", config.target_file_name);
} else {
    println!("Single file extraction: {}", config.target_file_name);
}
```

The struct supports flexible JSON deserialization with field aliases (`agentFileName`, `assetFileName`) and provides utility methods for cross-platform download management. The OS detection covers Windows, macOS, and Linux platforms with case-insensitive matching.
