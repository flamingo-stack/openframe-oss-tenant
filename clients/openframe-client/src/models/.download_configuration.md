Configuration structure for handling cross-platform file downloads with OS-specific targeting and extraction capabilities.

## Key Components

- **DownloadConfiguration** - Main struct containing download metadata including OS target, file names, and download link
- **is_folder_extraction()** - Method to determine if the target requires full archive extraction based on path complexity
- **matches_current_os()** - Method to validate configuration compatibility with the current operating system

## Usage Example

```rust
use serde_json;

// Create download configuration from JSON
let config: DownloadConfiguration = serde_json::from_str(r#"
{
    "os": "linux",
    "fileName": "agent-v1.2.3.tar.gz",
    "targetFileName": "bin/agent",
    "link": "https://releases.example.com/agent-v1.2.3-linux.tar.gz"
}
"#)?;

// Check if this config applies to current system
if config.matches_current_os() {
    println!("Compatible with current OS: {}", config.os);
    
    // Determine extraction strategy
    if config.is_folder_extraction() {
        println!("Requires full archive extraction for: {}", config.target_file_name);
    } else {
        println!("Simple file download: {}", config.file_name);
    }
}
```

The struct supports flexible JSON field naming through serde aliases (`agentFileName`, `assetFileName`) and provides OS detection for Windows, macOS, and Linux platforms.
