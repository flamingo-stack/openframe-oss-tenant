A serializable configuration struct that defines download parameters for platform-specific files, with OS matching and path extraction detection capabilities.

## Key Components

- **`DownloadConfiguration`** - Main struct containing download metadata (OS, file names, download URL)
- **`is_folder_extraction()`** - Determines if the target file path requires full archive extraction
- **`matches_current_os()`** - Validates if the configuration applies to the current operating system

## Usage Example

```rust
use serde_json;

// Parse from JSON configuration
let config: DownloadConfiguration = serde_json::from_str(r#"
{
    "os": "linux",
    "fileName": "agent-v1.2.3-linux.tar.gz",
    "targetFileName": "bin/agent",
    "link": "https://releases.example.com/agent-v1.2.3-linux.tar.gz"
}
"#)?;

// Check if this config applies to current OS
if config.matches_current_os() {
    println!("Downloading: {}", config.link);
    
    // Check if we need to extract the entire archive
    if config.is_folder_extraction() {
        println!("Will extract to path: {}", config.target_file_name);
    } else {
        println!("Single file extraction: {}", config.target_file_name);
    }
}
```

The struct uses serde aliases to support multiple JSON field name formats (`agentFileName`, `assetFileName`, `targetFileName`) for backward compatibility.
