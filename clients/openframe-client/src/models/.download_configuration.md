Configuration structure for downloading platform-specific files with OS detection and path validation utilities.

## Key Components

- **`DownloadConfiguration`** - Main struct containing download metadata (OS, file names, download link)
- **`is_folder_extraction()`** - Determines if the target file requires full archive extraction based on path components
- **`matches_current_os()`** - Cross-platform OS detection to match configuration with current system

## Usage Example

```rust
use serde_json;

// Parse configuration from JSON
let config: DownloadConfiguration = serde_json::from_str(r#"
{
    "os": "linux",
    "fileName": "agent-v1.2.3-linux.tar.gz",
    "targetFileName": "bin/agent",
    "link": "https://releases.example.com/agent-v1.2.3-linux.tar.gz"
}
"#)?;

// Check if configuration applies to current system
if config.matches_current_os() {
    println!("Downloading {} for current OS", config.file_name);
    
    // Determine extraction strategy
    if config.is_folder_extraction() {
        println!("Will extract entire archive (nested path detected)");
    } else {
        println!("Will extract single file");
    }
}
```

The struct supports flexible JSON field naming through serde aliases (`agentFileName`, `assetFileName`) and provides OS-agnostic functionality for cross-platform deployment scenarios.
