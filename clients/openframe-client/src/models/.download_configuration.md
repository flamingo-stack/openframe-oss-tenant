Defines the data structures and logic for configuring agent/asset downloads, including OS targeting, installation type, and version resolution.

## Key Components

### `InstallationType` (enum)
Serialized as `SCREAMING_SNAKE_CASE`. Three variants:
- `Standard` *(default)* — standard file install
- `GuiApp` — macOS/desktop GUI application
- `Service` — system service installation

### `DownloadConfiguration` (struct)
Core download descriptor with fields:
- `os` — target OS string (`windows`, `macos`, `linux`)
- `file_name` — source archive/file name
- `target_file_name` — destination file name (aliases: `agentFileName`, `assetFileName`)
- `link` — download URL
- `installation_type` — defaults to `Standard`
- `bundle_id` — optional macOS bundle identifier
- `service_name` — optional service name for `Service` installs

### Methods
| Method | Description |
|---|---|
| `is_folder_extraction()` | Returns `true` if `target_file_name` is a path (multi-component), indicating full archive extraction |
| `with_version_override(original, override)` | Clones config with the download URL version string substituted; warns via `tracing` if the original version string is not found in the link |
| `matches_current_os()` | Case-insensitive check against the compile-time target OS |

## Usage Example

```rust
let config = DownloadConfiguration {
    os: "linux".to_string(),
    file_name: "agent-1.2.0.tar.gz".to_string(),
    target_file_name: "bin/agent".to_string(),
    link: "https://releases.example.com/agent/1.2.0/agent-1.2.0.tar.gz".to_string(),
    installation_type: InstallationType::Service,
    bundle_id: None,
    service_name: Some("flamingo-agent".to_string()),
};

// True — target path has multiple components
assert!(config.is_folder_extraction());

// Swap version in download URL
let updated = config.with_version_override("1.2.0", "1.3.0");
assert!(updated.link.contains("1.3.0"));

// Only proceeds on matching OS at runtime
if config.matches_current_os() {
    // trigger download
}
```
