A configuration struct that defines download parameters for different operating systems, including file paths, URLs, and platform-specific logic for software deployment.

## Key Components

- **`DownloadConfiguration`** - Main struct containing OS-specific download metadata with camelCase serialization
- **`is_folder_extraction()`** - Determines if the target file path requires full archive extraction based on path depth
- **`matches_current_os()`** - Cross-platform OS detection using compile-time cfg flags

## Usage Example

```rust
use serde_json;

// Parse download configuration from JSON
let config: DownloadConfiguration = serde_json::from_str(r#"
{
    "os": "windows",
    "fileName": "agent-installer.zip",
    "targetFileName": "bin/agent.exe", 
    "link": "https://releases.example.com/v1.0/agent-win.zip"
}
"#)?;

// Check if this config applies to current platform
if config.matches_current_os() {
    println!("Downloading {} for {}", config.file_name, config.os);
    
    // Determine extraction strategy
    if config.is_folder_extraction() {
        println!("Will extract full archive to preserve directory structure");
    } else {
        println!("Will extract single file: {}", config.target_file_name);
    }
}
```

The struct supports flexible JSON field naming through serde aliases (`agentFileName`, `assetFileName`) and provides cross-platform compatibility checks for automated deployment workflows.
