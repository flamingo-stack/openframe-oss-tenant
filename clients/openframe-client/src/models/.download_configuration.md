Configuration structure for managing platform-specific file downloads and installations. This struct handles download metadata including OS targeting, file paths, and extraction requirements.

## Key Components

- **`DownloadConfiguration`** - Main struct containing download metadata with OS, filenames, and download link
- **`is_folder_extraction()`** - Determines if the target file requires full archive extraction based on path complexity
- **`matches_current_os()`** - Validates if the configuration applies to the current operating system

## Usage Example

```rust
use serde_json;

// Create configuration for a Windows agent download
let config = DownloadConfiguration {
    os: "windows".to_string(),
    file_name: "agent-installer.zip".to_string(),
    target_file_name: "bin/agent.exe".to_string(),
    link: "https://releases.example.com/agent-v1.0.zip".to_string(),
};

// Check if this requires folder extraction
if config.is_folder_extraction() {
    println!("Will extract entire archive to access {}", config.target_file_name);
}

// Verify OS compatibility
if config.matches_current_os() {
    println!("Configuration matches current OS");
}

// Parse from JSON with camelCase support
let json = r#"{
    "os": "linux",
    "fileName": "agent.tar.gz", 
    "agentFileName": "agent",
    "link": "https://releases.example.com/linux-agent.tar.gz"
}"#;
let config: DownloadConfiguration = serde_json::from_str(json)?;
```

The struct supports flexible JSON field naming through serde aliases, making it compatible with various API response formats while providing OS-specific download logic for the Flamingo platform's agent deployment system.
