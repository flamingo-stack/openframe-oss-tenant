Defines configuration structure for OS-specific file downloads with path handling and platform detection capabilities.

## Key Components

- **DownloadConfiguration** - Main struct containing OS type, file names, and download URL
- **is_folder_extraction()** - Determines if target requires full archive extraction based on path depth
- **matches_current_os()** - Validates configuration compatibility with current operating system

## Usage Example

```rust
use serde_json;

// Parse download configuration from JSON
let config: DownloadConfiguration = serde_json::from_str(r#"
{
    "os": "windows",
    "fileName": "agent-v1.2.3.zip",
    "targetFileName": "bin/agent.exe",
    "link": "https://releases.example.com/agent-v1.2.3.zip"
}
"#)?;

// Check if this config applies to current OS
if config.matches_current_os() {
    println!("Compatible with current OS: {}", config.os);
    
    // Determine extraction strategy
    if config.is_folder_extraction() {
        println!("Requires full archive extraction for: {}", config.target_file_name);
    } else {
        println!("Single file download: {}", config.file_name);
    }
}
```

The struct supports flexible JSON field naming through serde aliases, making it compatible with various API response formats while providing OS detection and path analysis utilities for download orchestration.
