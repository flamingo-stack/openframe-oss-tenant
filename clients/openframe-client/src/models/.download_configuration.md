Configuration structure for managing cross-platform software downloads with OS detection and path validation capabilities.

## Key Components

- **`DownloadConfiguration`** - Main struct containing download metadata including OS target, file names, and download URL
- **`is_folder_extraction()`** - Determines if the target file path requires full archive extraction based on path depth
- **`matches_current_os()`** - Validates configuration compatibility with the current operating system

## Usage Example

```rust
use serde_json;

// Parse download configuration from JSON
let config_json = r#"
{
    "os": "linux",
    "fileName": "agent-v1.0.tar.gz",
    "targetFileName": "bin/agent",
    "link": "https://releases.example.com/agent-v1.0.tar.gz"
}
"#;

let config: DownloadConfiguration = serde_json::from_str(config_json)?;

// Check if this config applies to current system
if config.matches_current_os() {
    println!("Compatible with current OS: {}", config.os);
    
    // Determine extraction strategy
    if config.is_folder_extraction() {
        println!("Full archive extraction required for: {}", config.target_file_name);
    } else {
        println!("Single file download: {}", config.target_file_name);
    }
    
    // Download from the specified link
    println!("Downloading from: {}", config.link);
}
```

The struct uses camelCase serialization and supports multiple field aliases for backward compatibility with different JSON schemas.
