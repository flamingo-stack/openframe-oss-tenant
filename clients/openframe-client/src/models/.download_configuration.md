Defines download configuration settings for platform-specific file downloads, with utilities for OS matching and extraction type detection.

## Key Components

- **`DownloadConfiguration`** - Serializable struct containing download metadata (OS, filenames, download link)
- **`is_folder_extraction()`** - Determines if the target file requires full archive extraction based on path components
- **`matches_current_os()`** - Cross-platform OS detection that compares configuration OS with current runtime OS

## Usage Example

```rust
use serde_json;

// Create configuration for a Windows download
let config = DownloadConfiguration {
    os: "windows".to_string(),
    file_name: "agent-installer.zip".to_string(),
    target_file_name: "bin/agent.exe".to_string(),
    link: "https://releases.example.com/agent-v1.0.0-windows.zip".to_string(),
};

// Check if this config applies to current OS
if config.matches_current_os() {
    println!("Downloading for current OS: {}", config.os);
    
    // Determine extraction strategy
    if config.is_folder_extraction() {
        println!("Requires full archive extraction to: {}", config.target_file_name);
    } else {
        println!("Direct file extraction: {}", config.target_file_name);
    }
}

// Deserialize from JSON with flexible field names
let json = r#"{"os": "linux", "fileName": "agent.tar.gz", "agentFileName": "agent", "link": "https://..."}"#;
let config: DownloadConfiguration = serde_json::from_str(json)?;
```

The struct supports flexible JSON field naming through serde aliases, making it compatible with various API response formats while providing platform-aware download logic.
