Defines the `DownloadConfiguration` struct and `InstallationType` enum used to represent agent/asset download metadata, including OS targeting, file naming, download links, and installation behavior.

## Key Components

- **`InstallationType`** — Enum with three variants (`Standard`, `GuiApp`, `Service`) serialized as `SCREAMING_SNAKE_CASE`; defaults to `Standard`
- **`DownloadConfiguration`** — Core struct holding OS identifier, file names, download link, installation type, and optional `bundle_id`/`service_name` fields; `target_file_name` accepts `agentFileName` or `assetFileName` as JSON aliases
- **`is_folder_extraction()`** — Returns `true` when `target_file_name` contains a path with more than one component, indicating a full archive extraction is required
- **`with_version_override()`** — Returns a cloned config with the download link's version string replaced; emits a `tracing::warn` if the original version string is not found in the link
- **`matches_current_os()`** — Checks if the config's `os` field matches the compile-time target OS (`windows`, `macos`, or `linux`) using case-insensitive comparison

## Usage Example

```rust
let config = DownloadConfiguration {
    os: "linux".to_string(),
    file_name: "agent-1.2.0.tar.gz".to_string(),
    target_file_name: "bin/agent".to_string(),
    link: "https://releases.example.com/agent/1.2.0/agent-1.2.0.tar.gz".to_string(),
    installation_type: InstallationType::Service,
    bundle_id: None,
    service_name: Some("flamingo-agent".to_string()),
};

// Check if this config targets the current OS
if config.matches_current_os() {
    // "bin/agent" has 2 components → extract full archive
    let needs_full_extract = config.is_folder_extraction(); // true

    // Swap version in download link
    let updated = config.with_version_override("1.2.0", "1.3.0");
    println!("{}", updated.link); // .../agent/1.3.0/agent-1.3.0.tar.gz
}
```
