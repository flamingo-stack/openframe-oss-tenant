Defines the data structures and logic for configuring agent/asset downloads, including OS targeting, installation type, and version resolution.

## Key Components

### `InstallationType` (enum)
Serialized as `SCREAMING_SNAKE_CASE`. Variants:
- `Standard` *(default)* — standard file installation
- `GuiApp` — macOS-style GUI application bundle
- `Service` — system service installation

### `DownloadConfiguration` (struct)
Serialized as `camelCase`. Core fields:

| Field | Description |
|---|---|
| `os` | Target OS string (`windows`, `macos`, `linux`) |
| `file_name` | Source file name in the download archive |
| `target_file_name` | Destination file name (accepts `agentFileName` / `assetFileName` aliases) |
| `link` | Download URL |
| `installation_type` | `InstallationType` variant (defaults to `Standard`) |
| `bundle_id` | Optional macOS bundle identifier |
| `service_name` | Optional service name for `Service` installations |

### Methods

- **`is_folder_extraction()`** — Returns `true` if `target_file_name` contains a path separator, indicating the full archive must be extracted.
- **`with_version_override(original, override_version)`** — Returns a cloned config with the download URL's version string replaced. Emits a `tracing::warn` if the original version string is not found in the link.
- **`matches_current_os()`** — Case-insensitive check of `os` against the compile-time target OS.

## Usage Example

```rust
let config = DownloadConfiguration {
    os: "linux".to_string(),
    file_name: "agent-1.2.0.tar.gz".to_string(),
    target_file_name: "bin/agent".to_string(),
    link: "https://example.com/releases/1.2.0/agent.tar.gz".to_string(),
    installation_type: InstallationType::Service,
    bundle_id: None,
    service_name: Some("flamingo-agent".to_string()),
};

// Resolves to a path-based extraction
assert!(config.is_folder_extraction());

// Swap in a newer version
let updated = config.with_version_override("1.2.0", "1.3.0");
assert!(updated.link.contains("1.3.0"));

// Only runs the install step on matching OS
if config.matches_current_os() {
    // proceed with download
}
```
