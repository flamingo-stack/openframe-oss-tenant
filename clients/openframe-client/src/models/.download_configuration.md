Configuration structure for managing cross-platform file downloads with OS-specific targeting and path extraction logic. Part of the OpenFrame platform's automated deployment system.

## Key Components

- **`DownloadConfiguration`** - Main struct defining download parameters with OS, file names, and URLs
- **`is_folder_extraction()`** - Determines if the target requires full archive extraction based on path depth
- **`matches_current_os()`** - Cross-platform OS detection for conditional downloads

## Usage Example

```rust
use serde_json;

// Parse download configuration from JSON
let config: DownloadConfiguration = serde_json::from_str(r#"
{
    "os": "linux", 
    "fileName": "agent-v1.2.0.tar.gz",
    "targetFileName": "bin/flamingo-agent",
    "link": "https://releases.flamingo.run/agent/v1.2.0/linux.tar.gz"
}
"#)?;

// Check if this config applies to current system
if config.matches_current_os() {
    println!("Downloading: {}", config.link);
    
    // Determine extraction strategy
    if config.is_folder_extraction() {
        println!("Full archive extraction required for: {}", config.target_file_name);
    } else {
        println!("Single file download: {}", config.target_file_name);
    }
}
```

The struct supports flexible JSON field naming with serde aliases (`agentFileName`, `assetFileName`) for backward compatibility across different API versions.
