Configuration structure for managing platform-specific download settings and archive extraction behavior.

## Key Components

- **`DownloadConfiguration`** - Main struct containing download metadata with OS, file paths, and download URL
- **`is_folder_extraction()`** - Determines if the target requires full archive extraction based on path depth
- **`matches_current_os()`** - Cross-platform OS detection and matching for current runtime environment

## Usage Example

```rust
use serde_json;

// Parse download configuration from JSON
let config: DownloadConfiguration = serde_json::from_str(r#"
{
    "os": "linux",
    "fileName": "agent-v1.0.tar.gz",
    "targetFileName": "bin/agent",
    "link": "https://releases.example.com/agent-v1.0.tar.gz"
}
"#)?;

// Check if this config applies to current OS
if config.matches_current_os() {
    println!("Downloading {} for current platform", config.file_name);
    
    // Determine extraction strategy
    if config.is_folder_extraction() {
        println!("Will extract full archive to access: {}", config.target_file_name);
    } else {
        println!("Single file download: {}", config.target_file_name);
    }
}
```

The struct supports flexible JSON field naming through serde aliases (`agentFileName`, `assetFileName`) and provides platform-aware download logic for cross-platform deployment scenarios.
