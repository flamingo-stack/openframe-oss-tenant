Configuration structure for platform-specific file downloads with OS matching and path validation utilities.

## Key Components

- **`DownloadConfiguration`** - Serializable struct containing download metadata including OS target, file names, and download URL
- **`is_folder_extraction()`** - Method to determine if the target requires full archive extraction based on path depth
- **`matches_current_os()`** - Cross-platform OS detection method that compares configuration OS with runtime environment

## Usage Example

```rust
use serde_json;

// Deserialize from JSON configuration
let config: DownloadConfiguration = serde_json::from_str(r#"
{
    "os": "windows",
    "fileName": "agent.zip", 
    "targetFileName": "bin/agent.exe",
    "link": "https://releases.example.com/agent-windows.zip"
}
"#)?;

// Check if this config applies to current platform
if config.matches_current_os() {
    println!("Downloading {} for current OS", config.file_name);
    
    // Determine extraction strategy
    if config.is_folder_extraction() {
        println!("Full archive extraction required for: {}", config.target_file_name);
    } else {
        println!("Single file download: {}", config.target_file_name);
    }
}
```

The struct supports flexible JSON field naming through serde aliases (`agentFileName`, `assetFileName`) and uses camelCase serialization for API compatibility.
