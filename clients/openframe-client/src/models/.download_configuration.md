Represents configuration settings for downloading OS-specific files, with automatic platform detection and extraction type determination.

## Key Components

- **DownloadConfiguration** - Main struct containing download metadata including OS target, file names, and download URL
- **is_folder_extraction()** - Determines if the target requires full archive extraction based on path complexity
- **matches_current_os()** - Validates if the configuration is compatible with the current operating system

## Usage Example

```rust
use serde_json;

// Parse configuration from JSON
let config: DownloadConfiguration = serde_json::from_str(r#"
{
    "os": "windows",
    "fileName": "agent-v1.2.3.zip",
    "targetFileName": "bin/agent.exe",
    "link": "https://releases.example.com/agent-v1.2.3.zip"
}
"#)?;

// Check if this config applies to current system
if config.matches_current_os() {
    println!("Downloading {} for {}", config.file_name, config.os);
    
    // Determine extraction strategy
    if config.is_folder_extraction() {
        println!("Will extract full archive to access: {}", config.target_file_name);
    } else {
        println!("Single file extraction: {}", config.target_file_name);
    }
}
```

The struct supports flexible JSON field naming through serde aliases, making it compatible with various API response formats. The OS matching is case-insensitive and supports Windows, macOS, and Linux platforms.
