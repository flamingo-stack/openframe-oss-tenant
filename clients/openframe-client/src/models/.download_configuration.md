Configuration structure for managing cross-platform file downloads with OS-specific targeting and path extraction detection capabilities.

## Key Components

### `DownloadConfiguration` Struct
- **`os`** - Target operating system identifier (windows/macos/linux)
- **`file_name`** - Original filename of the download
- **`target_file_name`** - Destination filename after download/extraction
- **`link`** - Download URL for the file

### Methods
- **`is_folder_extraction()`** - Determines if the target requires full archive extraction based on path depth
- **`matches_current_os()`** - Validates if configuration applies to the current operating system

## Usage Example

```rust
use serde_json;

// Parse configuration from JSON
let config: DownloadConfiguration = serde_json::from_str(r#"
{
    "os": "linux",
    "fileName": "agent-v1.0.tar.gz",
    "targetFileName": "bin/flamingo-agent",
    "link": "https://releases.example.com/agent-v1.0-linux.tar.gz"
}
"#)?;

// Check if extraction is needed
if config.is_folder_extraction() {
    println!("Archive extraction required for: {}", config.target_file_name);
}

// Validate OS compatibility
if config.matches_current_os() {
    println!("Configuration matches current OS: {}", config.os);
    // Proceed with download using config.link
}
```

The struct supports JSON deserialization with camelCase field names and provides flexible field aliases for `target_file_name` to maintain compatibility across different API versions.
