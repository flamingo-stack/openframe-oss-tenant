Configuration structure for managing cross-platform software downloads with OS-specific targeting and file extraction handling.

## Key Components

### DownloadConfiguration Struct
- **`os`** - Target operating system (windows/macos/linux)
- **`file_name`** - Original filename of the download
- **`target_file_name`** - Final extracted filename or path
- **`link`** - Download URL

### Methods
- **`is_folder_extraction()`** - Determines if extraction requires full archive processing
- **`matches_current_os()`** - Validates configuration against current platform

## Usage Example

```rust
use serde_json;

// Parse download configuration from JSON
let config: DownloadConfiguration = serde_json::from_str(r#"
{
    "os": "linux",
    "fileName": "agent-v1.0.tar.gz", 
    "targetFileName": "bin/agent",
    "link": "https://releases.example.com/agent-v1.0-linux.tar.gz"
}
"#)?;

// Check if this config applies to current system
if config.matches_current_os() {
    println!("Downloading {} for current OS", config.file_name);
    
    // Determine extraction strategy
    if config.is_folder_extraction() {
        println!("Full archive extraction needed for path: {}", config.target_file_name);
    } else {
        println!("Single file extraction: {}", config.target_file_name);
    }
}
```

The struct uses serde field aliases to support multiple JSON naming conventions (`agentFileName`, `assetFileName`) and provides OS detection logic for cross-platform deployment scenarios.
