Configuration struct for handling cross-platform software downloads with OS detection and extraction logic for the Flamingo/OpenFrame platform.

## Key Components

- **DownloadConfiguration**: Main struct containing download metadata (OS, file names, download link)
- **is_folder_extraction()**: Determines if the target requires full archive extraction based on path complexity
- **matches_current_os()**: Cross-platform OS detection method that compares configuration OS with runtime environment

## Usage Example

```rust
use serde_json;

// Parse download configuration from JSON
let config_json = r#"
{
    "os": "linux",
    "fileName": "flamingo-agent-v1.2.0-linux.tar.gz",
    "targetFileName": "bin/flamingo-agent",
    "link": "https://releases.flamingo.run/agent/v1.2.0/linux.tar.gz"
}
"#;

let config: DownloadConfiguration = serde_json::from_str(config_json)?;

// Check if this config applies to current system
if config.matches_current_os() {
    println!("Compatible with current OS: {}", config.os);
    
    // Determine extraction strategy
    if config.is_folder_extraction() {
        println!("Requires full archive extraction to: {}", config.target_file_name);
    } else {
        println!("Single file download: {}", config.file_name);
    }
    
    // Download from config.link...
}
```

The struct supports flexible JSON field naming through serde aliases, making it compatible with various API response formats while providing OS-specific download logic for Flamingo's cross-platform deployment system.
