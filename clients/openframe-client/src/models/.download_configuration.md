A serializable configuration structure for managing platform-specific file downloads with OS detection and extraction path validation.

## Key Components

- **`DownloadConfiguration`** - Main struct containing download metadata (OS, filenames, URL)
- **`is_folder_extraction()`** - Determines if target requires full archive extraction
- **`matches_current_os()`** - Cross-platform OS compatibility checking

## Usage Example

```rust
use serde_json;

// Create download config
let config = DownloadConfiguration {
    os: "windows".to_string(),
    file_name: "agent.zip".to_string(),
    target_file_name: "bin/agent.exe".to_string(),
    link: "https://releases.example.com/agent.zip".to_string(),
};

// Check if extraction needed
if config.is_folder_extraction() {
    println!("Need to extract archive to get: {}", config.target_file_name);
}

// Verify OS compatibility
if config.matches_current_os() {
    println!("Compatible with current platform");
}

// Deserialize from JSON
let json = r#"{
    "os": "linux",
    "fileName": "agent.tar.gz",
    "agentFileName": "agent",
    "link": "https://releases.example.com/linux.tar.gz"
}"#;
let config: DownloadConfiguration = serde_json::from_str(json)?;
```

The struct supports flexible field naming via serde aliases (`agentFileName`, `assetFileName`) and uses camelCase serialization for JSON compatibility.
