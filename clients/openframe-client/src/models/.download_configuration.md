Configuration struct for managing cross-platform file downloads with OS-specific handling and flexible JSON deserialization.

## Key Components

- **`DownloadConfiguration`** - Main struct containing download metadata (OS, filenames, URL)
- **`is_folder_extraction()`** - Determines if the target requires extracting from an archive based on path structure
- **`matches_current_os()`** - Cross-platform OS detection for filtering relevant downloads

## Usage Example

```rust
use serde_json;

// Parse download configuration from JSON
let config_json = r#"{
    "os": "linux",
    "fileName": "agent-v1.0.tar.gz",
    "agentFileName": "bin/flamingo-agent",
    "link": "https://releases.example.com/agent-v1.0.tar.gz"
}"#;

let config: DownloadConfiguration = serde_json::from_str(config_json)?;

// Check if this download applies to current platform
if config.matches_current_os() {
    println!("Downloading {} for {}", config.file_name, config.os);
    
    // Determine extraction strategy
    if config.is_folder_extraction() {
        println!("Will extract {} from archive", config.target_file_name);
    } else {
        println!("Direct file download: {}", config.target_file_name);
    }
}
```

The struct supports flexible JSON field naming through serde aliases (`agentFileName`, `assetFileName`) and provides OS detection for Windows, macOS, and Linux platforms.
