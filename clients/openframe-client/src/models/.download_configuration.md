Configuration struct for managing cross-platform file downloads with OS detection and path analysis capabilities.

## Key Components

### `DownloadConfiguration` Struct
- **`os`** - Target operating system identifier (windows/macos/linux)
- **`file_name`** - Original downloaded file name
- **`target_file_name`** - Final extracted/renamed file name (supports legacy aliases)
- **`link`** - Download URL for the file

### Core Methods
- **`is_folder_extraction()`** - Determines if the target requires full archive extraction based on path complexity
- **`matches_current_os()`** - Cross-platform OS matching with case-insensitive comparison

## Usage Example

```rust
use serde_json;

// Parse download configuration from JSON
let config_json = r#"{
    "os": "linux",
    "fileName": "agent-v1.0.tar.gz",
    "targetFileName": "bin/agent",
    "link": "https://releases.example.com/agent-v1.0-linux.tar.gz"
}"#;

let config: DownloadConfiguration = serde_json::from_str(config_json)?;

// Check if this configuration applies to current system
if config.matches_current_os() {
    println!("Downloading {} for current OS", config.file_name);
    
    // Determine extraction strategy
    if config.is_folder_extraction() {
        println!("Will extract entire archive to access: {}", config.target_file_name);
    } else {
        println!("Single file extraction: {}", config.target_file_name);
    }
}
```

The struct uses serde with camelCase serialization and provides backward compatibility through field aliases, making it ideal for parsing external configuration files while maintaining type safety.
