A configuration structure for managing cross-platform file downloads with OS-specific targeting and extraction logic.

## Key Components

### DownloadConfiguration Struct
- **`os`** - Target operating system identifier (windows, macos, linux)
- **`file_name`** - Original filename of the download
- **`target_file_name`** - Destination filename after download (supports legacy aliases)
- **`link`** - Download URL

### Methods
- **`is_folder_extraction()`** - Determines if the target requires archive extraction based on path depth
- **`matches_current_os()`** - Cross-platform OS matching with case-insensitive comparison

## Usage Example

```rust
use serde_json;

// Deserialize from JSON configuration
let config_json = r#"{
    "os": "Windows",
    "fileName": "agent-v1.2.zip",
    "targetFileName": "bin/flamingo-agent.exe",
    "link": "https://releases.flamingo.run/agent-v1.2.zip"
}"#;

let config: DownloadConfiguration = serde_json::from_str(config_json)?;

// Check if this config applies to current system
if config.matches_current_os() {
    println!("Downloading {} for current OS", config.file_name);
    
    // Determine extraction strategy
    if config.is_folder_extraction() {
        println!("Will extract archive to: {}", config.target_file_name);
    } else {
        println!("Direct file download");
    }
}
```

The structure supports flexible JSON field naming through serde aliases and provides OS detection for automated deployment scenarios.
