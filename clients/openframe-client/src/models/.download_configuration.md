Configuration structure for managing cross-platform software downloads with OS detection and file extraction logic.

## Key Components

- **DownloadConfiguration**: Main struct containing download metadata (OS, filenames, URL)
- **is_folder_extraction()**: Determines if download requires full archive extraction
- **matches_current_os()**: Validates configuration against current operating system

## Usage Example

```rust
use serde_json;

// Parse download configuration from JSON
let config: DownloadConfiguration = serde_json::from_str(r#"
{
    "os": "linux",
    "fileName": "agent-v1.0.0-linux.tar.gz",
    "targetFileName": "bin/agent",
    "link": "https://releases.example.com/agent-v1.0.0-linux.tar.gz"
}
"#)?;

// Check if configuration matches current OS
if config.matches_current_os() {
    println!("Configuration is compatible with current OS");
    
    // Determine extraction strategy
    if config.is_folder_extraction() {
        println!("Requires full archive extraction to: {}", config.target_file_name);
    } else {
        println!("Single file extraction: {}", config.target_file_name);
    }
}
```

The struct supports flexible JSON field naming through serde aliases (`agentFileName`, `assetFileName`) and provides OS-agnostic path detection for determining whether downloaded files need directory-based extraction or single file handling.
