Defines the data structures and logic for configuring agent/asset downloads, including OS targeting, installation type, and version management.

## Key Components

### `InstallationType` (enum)
Represents how a downloaded asset should be installed. Variants:
- `Standard` (default) — standard file installation
- `GuiApp` — macOS/desktop GUI application
- `Service` — system service installation

Serializes to/from `SCREAMING_SNAKE_CASE` JSON keys.

### `DownloadConfiguration` (struct)
Core configuration for a downloadable asset with fields:
- `os` — target operating system string
- `file_name` — source filename on the remote
- `target_file_name` — local destination filename (accepts aliases `agentFileName`, `assetFileName`)
- `link` — download URL
- `installation_type` — defaults to `Standard`
- `bundle_id` — optional macOS bundle identifier
- `service_name` — optional service name for `Service` installations

### Methods
| Method | Description |
|---|---|
| `is_folder_extraction()` | Returns `true` if `target_file_name` contains a path separator, indicating full archive extraction is needed |
| `with_version_override(original, override)` | Returns a cloned config with the download link's version string replaced; warns via `tracing` if the original version string is not found |
| `matches_current_os()` | Case-insensitive check of `os` field against the compile-time target OS |

## Usage Example

```rust
let config = DownloadConfiguration {
    os: "windows".to_string(),
    file_name: "agent-1.2.0.zip".to_string(),
    target_file_name: "agent/agent.exe".to_string(),
    link: "https://example.com/releases/1.2.0/agent.zip".to_string(),
    installation_type: InstallationType::Service,
    bundle_id: None,
    service_name: Some("flamingo-agent".to_string()),
};

// Check if archive extraction is needed (path separator present)
assert!(config.is_folder_extraction());

// Override version in download link
let updated = config.with_version_override("1.2.0", "1.3.0");
assert!(updated.link.contains("1.3.0"));

// Check OS compatibility at runtime
if config.matches_current_os() {
    // proceed with download
}
```
