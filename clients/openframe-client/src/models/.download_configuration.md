Configuration structure for managing platform-specific download settings and file extraction logic in the Flamingo MSP platform.

## Key Components

**DownloadConfiguration struct** - Main configuration object with serialization support containing:
- `os` - Target operating system identifier 
- `file_name` - Original download file name
- `target_file_name` - Final extracted/renamed file (supports legacy aliases)
- `link` - Download URL

**Methods:**
- `is_folder_extraction()` - Detects if target requires full archive extraction based on path components
- `matches_current_os()` - Cross-platform OS matching with case-insensitive comparison

## Usage Example

```rust
use serde_json;

// Parse download config from JSON
let config: DownloadConfiguration = serde_json::from_str(r#"
{
    "os": "windows",
    "fileName": "agent-installer.zip", 
    "targetFileName": "bin/agent.exe",
    "link": "https://releases.flamingo.run/agent/v1.0.0/windows.zip"
}
"#)?;

// Check if we need full extraction vs single file
if config.is_folder_extraction() {
    println!("Extract entire archive to access: {}", config.target_file_name);
}

// Verify OS compatibility  
if config.matches_current_os() {
    println!("Compatible with current platform");
}
```

The struct uses camelCase JSON serialization and provides flexible field aliasing for backward compatibility with different naming conventions.
