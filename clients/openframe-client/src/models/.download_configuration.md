Configuration structure for managing cross-platform software downloads with OS detection and file extraction logic for the Flamingo MSP platform.

## Key Components

### DownloadConfiguration Struct
- `os`: Target operating system identifier (windows/macos/linux)
- `file_name`: Name of the downloaded file
- `target_file_name`: Final destination filename (supports legacy field aliases)
- `link`: Download URL for the software package

### Methods
- `is_folder_extraction()`: Determines if the target requires archive extraction based on path complexity
- `matches_current_os()`: Cross-platform OS detection using compile-time cfg attributes

## Usage Example

```rust
use serde_json;

// Parse download configuration from JSON
let config: DownloadConfiguration = serde_json::from_str(r#"
{
    "os": "windows",
    "fileName": "agent-installer.zip",
    "targetFileName": "bin/agent.exe",
    "link": "https://releases.flamingo.run/agent/windows/latest.zip"
}
"#)?;

// Check if this config applies to current system
if config.matches_current_os() {
    println!("Downloading {} for current OS", config.file_name);
    
    // Determine extraction method
    if config.is_folder_extraction() {
        println!("Will extract archive to: {}", config.target_file_name);
    } else {
        println!("Simple file download");
    }
}
```

The struct supports flexible JSON deserialization with field aliases for backward compatibility with different API versions.
