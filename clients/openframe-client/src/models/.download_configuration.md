Defines a serializable configuration structure for managing cross-platform file downloads with OS-specific targeting and path extraction detection.

## Key Components

- **DownloadConfiguration** - Main struct containing download metadata (OS, file names, download link)
- **is_folder_extraction()** - Detects if the target requires full archive extraction based on path components
- **matches_current_os()** - Validates configuration compatibility with the current operating system

## Usage Example

```rust
use serde_json;

// Create download configuration
let config = DownloadConfiguration {
    os: "windows".to_string(),
    file_name: "agent-v1.0.zip".to_string(),
    target_file_name: "bin/agent.exe".to_string(),
    link: "https://releases.example.com/agent-v1.0-windows.zip".to_string(),
};

// Check if extraction is needed
if config.is_folder_extraction() {
    println!("Will extract entire archive");
}

// Validate OS compatibility
if config.matches_current_os() {
    println!("Configuration matches current OS");
}

// Serialize/deserialize with camelCase JSON
let json = serde_json::to_string(&config)?;
let parsed: DownloadConfiguration = serde_json::from_str(&json)?;
```

The struct supports flexible JSON field naming through serde aliases (`agentFileName`, `assetFileName`) and provides OS detection for Windows, macOS, and Linux platforms.
