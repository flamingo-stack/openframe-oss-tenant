Configuration structure for managing OS-specific file downloads with automatic platform detection and extraction type determination.

## Key Components

- **`DownloadConfiguration`** - Main struct containing download metadata (OS, filenames, URL)
- **`is_folder_extraction()`** - Determines if the target requires full archive extraction
- **`matches_current_os()`** - Validates configuration against the current platform

## Usage Example

```rust
use serde_json;

// Parse download configuration from JSON
let config_json = r#"{
    "os": "linux",
    "fileName": "agent.tar.gz",
    "targetFileName": "bin/flamingo-agent",
    "link": "https://releases.example.com/agent.tar.gz"
}"#;

let config: DownloadConfiguration = serde_json::from_str(config_json)?;

// Check if this config applies to current OS
if config.matches_current_os() {
    println!("Using download: {}", config.link);
    
    // Determine extraction strategy
    if config.is_folder_extraction() {
        println!("Will extract full archive for: {}", config.target_file_name);
    } else {
        println!("Single file download: {}", config.file_name);
    }
}
```

The struct uses serde field aliases to handle different JSON naming conventions (`agentFileName`, `assetFileName`, `targetFileName`) and provides camelCase serialization for cross-platform compatibility.
