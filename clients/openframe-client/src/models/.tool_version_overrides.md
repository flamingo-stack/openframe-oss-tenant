Provides compile-time version override resolution for Flamingo/OpenFrame platform tools, returning statically embedded version strings based on enabled Cargo features.

## Key Components

### `lookup(tool_key: &str) -> Option<&'static str>`

Matches a tool identifier string against known platform tools and returns the version string baked in at compile time via `env!()`. Returns `None` if no override is configured for the given key or the corresponding feature flag is not enabled.

**Supported tool keys and their feature gates:**

| Tool Key | Feature Flag | Env Variable |
|---|---|---|
| `openframe-chat` | `openframe-chat-version` | `OPENFRAME_CHAT_VERSION` |
| `meshcentral-server` | `meshcentral-agent-version` | `MESHCENTRAL_AGENT_VERSION` |
| `fleetmdm-server` | `fleetmdm-agent-version` | `FLEETMDM_AGENT_VERSION` |
| `tactical-rmm` | `tacticalrmm-agent-version` | `TACTICALRMM_AGENT_VERSION` |
| `osqueryd` | `osquery-version` | `OSQUERY_VERSION` |

## Usage Example

```rust
// At runtime, look up whether a pinned version exists for a tool
if let Some(version) = tool_version_overrides::lookup("meshcentral-server") {
    println!("Using pinned MeshCentral version: {}", version);
} else {
    println!("No version override — using default resolution");
}

// For an unknown or feature-disabled tool key
assert_eq!(tool_version_overrides::lookup("unknown-tool"), None);
```

To activate an override, enable the feature and set the corresponding environment variable at build time:

```bash
MESHCENTRAL_AGENT_VERSION=2.1.0 cargo build --features meshcentral-agent-version
```
