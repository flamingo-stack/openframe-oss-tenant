Provides compile-time version override lookups for specific MSP tools in the Flamingo/OpenFrame stack, resolving pinned versions from environment variables when the corresponding Cargo feature flags are enabled.

## Key Components

- **`lookup(tool_key: &str) -> Option<&'static str>`** — Matches a tool identifier string against known tools and returns a statically embedded version string if the associated feature flag is active. Returns `None` for unknown keys or disabled features.

### Supported Tool Keys & Feature Flags

| Tool Key | Feature Flag | Env Variable |
|---|---|---|
| `openframe-chat` | `openframe-chat-version` | `OPENFRAME_CHAT_VERSION` |
| `meshcentral-server` | `meshcentral-agent-version` | `MESHCENTRAL_AGENT_VERSION` |
| `fleetmdm-server` | `fleetmdm-agent-version` | `FLEETMDM_AGENT_VERSION` |
| `tactical-rmm` | `tacticalrmm-agent-version` | `TACTICALRMM_AGENT_VERSION` |
| `osqueryd` | `osquery-version` | `OSQUERY_VERSION` |

## Usage Example

```rust
// With feature "osquery-version" enabled and OSQUERY_VERSION=5.10.2 set at build time:
if let Some(version) = tool_version_overrides::lookup("osqueryd") {
    println!("Pinned osquery version: {}", version); // "5.10.2"
}

// Unknown or feature-disabled key returns None, allowing fallback logic:
match tool_version_overrides::lookup("meshcentral-server") {
    Some(v) => install_with_version(v),
    None    => install_latest(),
}
```

> **Note:** Version strings are embedded at compile time via `env!()`. If a feature flag is enabled but the corresponding environment variable is not set, the build will fail with a compile-time error.
