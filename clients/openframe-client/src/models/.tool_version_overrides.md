Provides compile-time version override lookups for Flamingo/OpenFrame tool components, returning statically embedded version strings set via environment variables and Cargo features.

## Key Components

### `lookup(tool_key: &str) -> Option<&'static str>`

Matches a tool identifier string to its compile-time version override. Each arm is gated behind a Cargo feature flag — if the feature is not enabled, the arm is omitted and `None` is returned.

| Tool Key | Feature Flag | Env Variable |
|---|---|---|
| `openframe-chat` | `openframe-chat-version` | `OPENFRAME_CHAT_VERSION` |
| `meshcentral-server` | `meshcentral-agent-version` | `MESHCENTRAL_AGENT_VERSION` |
| `fleetmdm-server` | `fleetmdm-agent-version` | `FLEETMDM_AGENT_VERSION` |
| `tactical-rmm` | `tacticalrmm-agent-version` | `TACTICALRMM_AGENT_VERSION` |
| `osqueryd` | `osquery-version` | `OSQUERY_VERSION` |

## Usage Example

```rust
// Resolve a pinned version at runtime, falling back to a default
fn resolve_version(tool_key: &str) -> &str {
    tool_version_overrides::lookup(tool_key)
        .unwrap_or("latest")
}

let version = resolve_version("tactical-rmm");
// Returns pinned TACTICALRMM_AGENT_VERSION if feature is enabled,
// otherwise "latest"
```

## Notes

- `#[allow(unused_variables)]` suppresses warnings when all feature flags are disabled and `tool_key` goes unused.
- Version strings are embedded at **compile time** via `env!()` — the environment variables must be set during the build.
- To activate an override, enable the corresponding Cargo feature and export the matching env variable before building (e.g., `TACTICALRMM_AGENT_VERSION=0.20.1`).
