Provides compile-time version override resolution for specific OpenFrame/MSP tools, mapping tool keys to version strings injected via environment variables and Cargo features.

## Key Components

### `lookup(tool_key: &str) -> Option<&'static str>`

Accepts a tool key string and returns an optional static version string. Each match arm is conditionally compiled based on a corresponding Cargo feature flag, allowing version pinning to be selectively enabled per tool.

| Tool Key | Feature Flag | Env Variable |
|---|---|---|
| `openframe-chat` | `openframe-chat-version` | `OPENFRAME_CHAT_VERSION` |
| `meshcentral-server` | `meshcentral-agent-version` | `MESHCENTRAL_AGENT_VERSION` |
| `fleetmdm-server` | `fleetmdm-agent-version` | `FLEETMDM_AGENT_VERSION` |
| `osqueryd` | `osquery-version` | `OSQUERY_VERSION` |

Returns `None` if the tool key is unrecognized or if the relevant feature is not enabled at compile time.

## Usage Example

```rust
// With feature "osquery-version" enabled and OSQUERY_VERSION="5.12.1" set at build time:
if let Some(version) = lookup("osqueryd") {
    println!("Pinned osqueryd version: {}", version); // "5.12.1"
}

// Without the feature enabled, or for an unknown tool:
assert_eq!(lookup("unknown-tool"), None);
assert_eq!(lookup("osqueryd"), None); // feature not enabled
```

> **Note:** Version strings are resolved at compile time via `env!()`. The corresponding environment variable must be set during the build when the feature flag is active, otherwise the build will fail.
