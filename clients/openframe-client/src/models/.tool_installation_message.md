Defines the message structure for tool installation requests in the Flamingo platform, supporting cross-platform installation with configurable assets, download sources, and execution parameters.

## Key Components

- **`ToolInstallationMessage`** - Main struct containing tool metadata, installation commands, and optional assets
- **`SessionType`** - Enum defining execution contexts (Service, Console, User)
- **`Asset`** - Structure for tool assets with platform-specific configurations and download sources
- **`LocalFilenameConfig`** - Platform-specific filename mapping with OS detection utilities
- **`AssetSource`** - Enum for supported asset sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use tool_installation_message::{ToolInstallationMessage, SessionType, Asset, AssetSource};

// Create a tool installation message
let install_msg = ToolInstallationMessage {
    tool_agent_id: "msp-agent-001".to_string(),
    tool_id: "network-scanner".to_string(),
    tool_type: "monitoring".to_string(),
    version: "1.2.3".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Service),
    download_configurations: None,
    installation_command_args: Some(vec!["--silent".to_string()]),
    uninstallation_command_args: None,
    run_command_args: vec!["--scan".to_string(), "--output=json".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![
        Asset {
            id: "scanner-binary".to_string(),
            local_filename_configuration: vec![
                LocalFilenameConfig {
                    filename: "scanner.exe".to_string(),
                    os: "windows".to_string(),
                }
            ],
            source: AssetSource::Github,
            path: Some("/usr/local/bin".to_string()),
            executable: true,
            download_configurations: None,
            version: Some("1.2.3".to_string()),
        }
    ]),
};

// Check if filename config matches current OS
let config = LocalFilenameConfig {
    filename: "tool.exe".to_string(),
    os: "windows".to_string(),
};
let is_compatible = config.matches_current_os();
```
