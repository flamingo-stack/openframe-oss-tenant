Defines the data structures for tool installation messages and configuration used in the Flamingo MSP platform's tool management system. This struct represents the complete installation context including tool metadata, session configuration, and downloadable assets.

## Key Components

- **`ToolInstallationMessage`** - Main struct containing tool installation parameters including agent ID, version, installation commands, and optional assets
- **`SessionType`** - Enum defining execution contexts (Service, Console, User) for tool installation
- **`Asset`** - Represents downloadable tool assets with OS-specific filename configurations and source locations
- **`LocalFilenameConfig`** - OS-specific filename mapping with runtime OS detection capability
- **`AssetSource`** - Enum for asset download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use tool_installation_message::{ToolInstallationMessage, SessionType, Asset};

// Create a tool installation message
let install_msg = ToolInstallationMessage {
    tool_agent_id: "agent-123".to_string(),
    tool_id: "nginx".to_string(),
    tool_type: "web_server".to_string(),
    version: "1.21.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Service),
    download_configurations: None,
    installation_command_args: Some(vec!["--quiet".to_string()]),
    uninstallation_command_args: None,
    run_command_args: vec!["-c", "/etc/nginx/nginx.conf"].iter().map(|s| s.to_string()).collect(),
    tool_agent_id_command_args: None,
    assets: None,
};

// Check OS compatibility for filename config
let config = LocalFilenameConfig {
    filename: "nginx.exe".to_string(),
    os: "windows".to_string(),
};
let is_compatible = config.matches_current_os();
```
