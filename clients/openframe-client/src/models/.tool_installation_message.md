This Rust file defines data structures for tool installation messages in the Flamingo/OpenFrame MSP platform, handling cross-platform tool deployment and configuration through serializable message types.

## Key Components

- **`ToolInstallationMessage`** - Main struct containing tool metadata, installation parameters, and optional configurations for deploying tools across the MSP platform
- **`SessionType`** - Enum defining execution contexts (Service, Console, User) for tool deployment
- **`Asset`** - Struct representing downloadable tool assets with platform-specific configurations
- **`LocalFilenameConfig`** - Platform-specific filename mapping with OS detection capabilities
- **`AssetSource`** - Enum specifying where assets are sourced from (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use serde_json;

// Create a tool installation message for a cross-platform tool
let installation_msg = ToolInstallationMessage {
    tool_agent_id: "msp-agent-001".to_string(),
    tool_id: "kubectl".to_string(),
    tool_type: "kubernetes-cli".to_string(),
    version: "1.29.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::User),
    download_configurations: None,
    installation_command_args: Some(vec!["install".to_string(), "--verify".to_string()]),
    uninstallation_command_args: Some(vec!["uninstall".to_string()]),
    run_command_args: vec!["kubectl".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![
        Asset {
            id: "kubectl-binary".to_string(),
            local_filename_configuration: vec![
                LocalFilenameConfig {
                    filename: "kubectl.exe".to_string(),
                    os: "windows".to_string(),
                },
                LocalFilenameConfig {
                    filename: "kubectl".to_string(),
                    os: "linux".to_string(),
                }
            ],
            source: AssetSource::Github,
            path: Some("/usr/local/bin".to_string()),
            executable: true,
            download_configurations: None,
            version: Some("1.29.0".to_string()),
        }
    ]),
};

// Serialize for transmission
let json_msg = serde_json::to_string(&installation_msg)?;

// Check OS compatibility
let config = LocalFilenameConfig {
    filename: "tool.exe".to_string(),
    os: "windows".to_string(),
};
let is_compatible = config.matches_current_os();
```
