Defines the message structure for tool installation operations in the Flamingo platform, containing all necessary metadata for installing, managing, and running AI-powered MSP tools.

## Key Components

- **`ToolInstallationMessage`** - Main struct containing tool metadata, installation commands, and configuration options
- **`SessionType`** - Enum defining execution contexts: Service, Console, or User sessions
- **`Asset`** - Represents downloadable tool assets with platform-specific configurations
- **`LocalFilenameConfig`** - Platform-specific filename mapping with OS detection utility
- **`AssetSource`** - Enum for asset download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use serde_json;

// Create a tool installation message
let install_msg = ToolInstallationMessage {
    tool_agent_id: "mingo-ai-001".to_string(),
    tool_id: "network-scanner".to_string(),
    tool_type: "diagnostic".to_string(),
    version: "1.2.3".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Service),
    download_configurations: None,
    installation_command_args: Some(vec!["--quiet".to_string()]),
    uninstallation_command_args: None,
    run_command_args: vec!["scan".to_string(), "--target".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![
        Asset {
            id: "scanner-binary".to_string(),
            local_filename_configuration: vec![
                LocalFilenameConfig {
                    filename: "scanner.exe".to_string(),
                    os: "windows".to_string(),
                }
            ],
            source: AssetSource::Github,
            path: Some("/usr/local/bin".to_string()),
            executable: true,
            download_configurations: None,
            version: Some("1.2.3".to_string()),
        }
    ]),
};

// Serialize to JSON for transmission
let json = serde_json::to_string(&install_msg)?;

// Check OS compatibility
let config = LocalFilenameConfig {
    filename: "tool.exe".to_string(),
    os: "windows".to_string(),
};
let is_compatible = config.matches_current_os();
```
