A structured message type for handling tool installation requests in the Flamingo OpenFrame platform, containing tool metadata, installation commands, and asset configurations.

## Key Components

### Core Structures
- **`ToolInstallationMessage`** - Main message struct containing tool identification, installation commands, and optional assets
- **`Asset`** - Represents downloadable tool assets with OS-specific filename configurations
- **`LocalFilenameConfig`** - Maps filenames to specific operating systems with OS detection capability

### Enums
- **`SessionType`** - Defines execution context (Service, Console, User)
- **`AssetSource`** - Specifies asset download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use tool_installation_message::{ToolInstallationMessage, SessionType, Asset, AssetSource};

// Create a tool installation message
let install_msg = ToolInstallationMessage {
    tool_agent_id: "flamingo-agent-001".to_string(),
    tool_id: "kubectl".to_string(),
    tool_type: "kubernetes-cli".to_string(),
    version: "1.28.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Console),
    download_configurations: None,
    installation_command_args: Some(vec!["install".to_string(), "--quiet".to_string()]),
    uninstallation_command_args: Some(vec!["uninstall".to_string()]),
    run_command_args: vec!["kubectl".to_string(), "version".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![
        Asset {
            id: "kubectl-binary".to_string(),
            local_filename_configuration: vec![
                LocalFilenameConfig {
                    filename: "kubectl.exe".to_string(),
                    os: "windows".to_string(),
                },
                LocalFilenameConfig {
                    filename: "kubectl".to_string(),
                    os: "linux".to_string(),
                },
            ],
            source: AssetSource::Github,
            path: Some("/usr/local/bin".to_string()),
            executable: true,
            download_configurations: None,
            version: Some("1.28.0".to_string()),
        }
    ]),
};

// Check if a filename config matches current OS
let config = LocalFilenameConfig {
    filename: "tool.exe".to_string(),
    os: "windows".to_string(),
};
let is_current_os = config.matches_current_os();
```
