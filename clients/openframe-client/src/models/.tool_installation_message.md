A serializable message structure for managing tool installation operations in the Flamingo MSP platform, supporting cross-platform deployment with configurable assets and download sources.

## Key Components

- **`ToolInstallationMessage`** - Main structure containing tool metadata, installation/uninstallation commands, and optional assets
- **`SessionType`** - Enum defining execution contexts (Service, Console, User)
- **`Asset`** - Represents downloadable tool components with platform-specific configurations
- **`LocalFilenameConfig`** - Platform-specific filename mapping with OS detection
- **`AssetSource`** - Enum for asset download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use tool_installation_message::{ToolInstallationMessage, SessionType, Asset, AssetSource};

// Create a tool installation message
let message = ToolInstallationMessage {
    tool_agent_id: "kubectl-agent-001".to_string(),
    tool_id: "kubectl".to_string(),
    tool_type: "kubernetes-cli".to_string(),
    version: "1.28.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Console),
    run_command_args: vec!["kubectl".to_string()],
    assets: Some(vec![
        Asset {
            id: "kubectl-binary".to_string(),
            source: AssetSource::Github,
            executable: true,
            local_filename_configuration: vec![
                LocalFilenameConfig {
                    filename: "kubectl.exe".to_string(),
                    os: "windows".to_string(),
                },
                LocalFilenameConfig {
                    filename: "kubectl".to_string(),
                    os: "linux".to_string(),
                }
            ],
            // ... other fields
        }
    ]),
    // ... other optional fields
};

// Check if filename config matches current OS
let config = LocalFilenameConfig {
    filename: "tool.exe".to_string(),
    os: "windows".to_string(),
};
let matches = config.matches_current_os();
```
