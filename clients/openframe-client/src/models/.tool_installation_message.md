Defines the data structures for tool installation messages in the Flamingo MSP platform, handling tool deployment and asset management across different operating systems and session types.

## Key Components

- **`ToolInstallationMessage`** - Main struct containing tool installation configuration including agent ID, version, commands, and optional download configurations
- **`SessionType`** - Enum defining execution contexts (Service, Console, User) for tool installation
- **`Asset`** - Represents downloadable tool assets with OS-specific filename configurations and source information
- **`LocalFilenameConfig`** - Maps filenames to specific operating systems with OS detection capability
- **`AssetSource`** - Enum for asset download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use tool_installation_message::{ToolInstallationMessage, SessionType, Asset, AssetSource};

// Create a tool installation message
let install_msg = ToolInstallationMessage {
    tool_agent_id: "agent-123".to_string(),
    tool_id: "monitoring-tool".to_string(),
    tool_type: "monitor".to_string(),
    version: "1.2.3".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Service),
    download_configurations: None,
    installation_command_args: Some(vec!["--silent".to_string()]),
    uninstallation_command_args: None,
    run_command_args: vec!["start".to_string(), "--config=prod".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![Asset {
        id: "main-binary".to_string(),
        local_filename_configuration: vec![
            LocalFilenameConfig {
                filename: "tool.exe".to_string(),
                os: "windows".to_string(),
            }
        ],
        source: AssetSource::Github,
        path: Some("/usr/local/bin".to_string()),
        executable: true,
        download_configurations: None,
        version: None,
    }]),
};

// Check if filename config matches current OS
let config = LocalFilenameConfig {
    filename: "tool".to_string(),
    os: "linux".to_string(),
};
let is_current_os = config.matches_current_os();
```
