A serializable Rust data structure that defines the complete configuration for tool installation messages in the Flamingo platform, including asset management, session types, and OS-specific handling for MSP tool deployment.

## Key Components

- **`ToolInstallationMessage`** - Main struct containing tool metadata, version info, and installation/execution commands
- **`SessionType`** - Enum defining execution contexts: Service, Console, or User sessions
- **`Asset`** - Represents downloadable tool assets with platform-specific configurations
- **`LocalFilenameConfig`** - OS-specific filename mapping with current platform detection
- **`AssetSource`** - Enum for asset download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use tool_installation_message::{ToolInstallationMessage, SessionType, Asset, AssetSource};

// Create a tool installation message for a monitoring tool
let installation_msg = ToolInstallationMessage {
    tool_agent_id: "agent_001".to_string(),
    tool_id: "monitoring_tool".to_string(),
    tool_type: "system_monitor".to_string(),
    version: "1.2.3".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Service),
    download_configurations: None,
    installation_command_args: Some(vec!["install".to_string(), "--silent".to_string()]),
    uninstallation_command_args: Some(vec!["uninstall".to_string()]),
    run_command_args: vec!["run".to_string(), "--daemon".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![
        Asset {
            id: "main_binary".to_string(),
            local_filename_configuration: vec![
                LocalFilenameConfig {
                    filename: "monitor.exe".to_string(),
                    os: "windows".to_string(),
                },
                LocalFilenameConfig {
                    filename: "monitor".to_string(),
                    os: "linux".to_string(),
                }
            ],
            source: AssetSource::Github,
            path: Some("/usr/local/bin".to_string()),
            executable: true,
            download_configurations: None,
            version: None,
        }
    ]),
};

// Check if filename config matches current OS
let config = LocalFilenameConfig {
    filename: "tool.exe".to_string(),
    os: "windows".to_string(),
};
let is_current_os = config.matches_current_os();
```
