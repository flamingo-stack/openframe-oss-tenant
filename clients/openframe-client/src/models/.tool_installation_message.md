Defines the message structure for communicating tool installation and management operations between components in the Flamingo MSP platform.

## Key Components

- **`ToolInstallationMessage`** - Main message struct containing tool metadata, installation commands, and configuration
- **`SessionType`** - Enum defining execution contexts (Service, Console, User)
- **`Asset`** - Represents downloadable tool assets with OS-specific configurations
- **`LocalFilenameConfig`** - Maps filenames to operating systems with current OS matching logic
- **`AssetSource`** - Enum for different asset download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use tool_installation_message::{ToolInstallationMessage, SessionType, Asset, AssetSource};

// Create a tool installation message
let install_msg = ToolInstallationMessage {
    tool_agent_id: "agent-123".to_string(),
    tool_id: "docker".to_string(),
    tool_type: "container-runtime".to_string(),
    version: "24.0.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Service),
    download_configurations: None,
    installation_command_args: Some(vec!["apt-get".to_string(), "install".to_string()]),
    uninstallation_command_args: Some(vec!["apt-get".to_string(), "remove".to_string()]),
    run_command_args: vec!["docker".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![Asset {
        id: "docker-binary".to_string(),
        local_filename_configuration: vec![],
        source: AssetSource::Github,
        path: Some("/usr/bin/docker".to_string()),
        executable: true,
        download_configurations: None,
        version: None,
    }]),
};

// Check if filename config matches current OS
let config = LocalFilenameConfig {
    filename: "docker.exe".to_string(),
    os: "windows".to_string(),
};
let is_current_os = config.matches_current_os();
```
