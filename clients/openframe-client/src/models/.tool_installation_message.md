A structured message type for managing tool installation operations within the Flamingo MSP platform, including configuration for downloads, assets, and cross-platform compatibility.

## Key Components

- **`ToolInstallationMessage`** - Main structure containing tool metadata, installation parameters, and command arguments
- **`SessionType`** - Enum defining execution contexts (Service, Console, User)
- **`Asset`** - Represents downloadable tool components with platform-specific configurations
- **`LocalFilenameConfig`** - OS-specific filename mapping with current platform detection
- **`AssetSource`** - Enum for different asset download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use tool_installation_message::{ToolInstallationMessage, SessionType, Asset, AssetSource};

// Create a tool installation message
let installation_msg = ToolInstallationMessage {
    tool_agent_id: "agent-123".to_string(),
    tool_id: "monitoring-tool".to_string(),
    tool_type: "monitoring".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Service),
    download_configurations: None,
    installation_command_args: Some(vec!["--install".to_string()]),
    uninstallation_command_args: Some(vec!["--uninstall".to_string()]),
    run_command_args: vec!["--start".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![
        Asset {
            id: "main-binary".to_string(),
            local_filename_configuration: vec![
                LocalFilenameConfig {
                    filename: "tool.exe".to_string(),
                    os: "windows".to_string(),
                }
            ],
            source: AssetSource::Github,
            path: Some("/bin/tool".to_string()),
            executable: true,
            download_configurations: None,
            version: Some("1.0.0".to_string()),
        }
    ]),
};

// Check if filename config matches current OS
let config = LocalFilenameConfig {
    filename: "tool.exe".to_string(),
    os: "windows".to_string(),
};
let is_current_os = config.matches_current_os();
```
