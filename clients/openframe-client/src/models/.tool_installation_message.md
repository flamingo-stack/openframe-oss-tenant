A comprehensive data structure for managing tool installation messages in the Flamingo/OpenFrame MSP platform, handling tool deployment, configuration, and asset management across different operating systems and session types.

## Key Components

- **`ToolInstallationMessage`** - Main struct containing tool metadata, installation/uninstallation commands, and optional download configurations
- **`SessionType`** - Enum defining execution contexts (Service, Console, User)
- **`Asset`** - Struct representing downloadable tool assets with OS-specific filename configurations
- **`LocalFilenameConfig`** - OS-specific filename mapping with current OS detection
- **`AssetSource`** - Enum for asset download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use tool_installation_message::{ToolInstallationMessage, SessionType, Asset, AssetSource};

// Create a tool installation message
let installation_msg = ToolInstallationMessage {
    tool_agent_id: "agent-123".to_string(),
    tool_id: "kubectl".to_string(),
    tool_type: "kubernetes-cli".to_string(),
    version: "1.28.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Console),
    download_configurations: None,
    installation_command_args: Some(vec!["install".to_string(), "-y".to_string()]),
    uninstallation_command_args: Some(vec!["remove".to_string()]),
    run_command_args: vec!["kubectl".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![Asset {
        id: "kubectl-binary".to_string(),
        local_filename_configuration: vec![
            LocalFilenameConfig {
                filename: "kubectl.exe".to_string(),
                os: "windows".to_string(),
            }
        ],
        source: AssetSource::Github,
        path: Some("/usr/local/bin/kubectl".to_string()),
        executable: true,
        download_configurations: None,
        version: Some("1.28.0".to_string()),
    }]),
};

// Check if filename config matches current OS
let config = LocalFilenameConfig {
    filename: "tool.exe".to_string(),
    os: "windows".to_string(),
};
let matches = config.matches_current_os();
```
