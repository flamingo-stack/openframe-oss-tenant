A comprehensive data structure for orchestrating tool installation across the Flamingo platform, enabling automated deployment and management of AI-powered MSP tools with cross-platform support.

## Key Components

- **`ToolInstallationMessage`** - Main configuration struct containing tool metadata, installation parameters, and runtime configuration
- **`SessionType`** - Enum defining execution contexts (Service, Console, User) for tool deployment
- **`Asset`** - Represents downloadable components with platform-specific configurations and source definitions
- **`LocalFilenameConfig`** - Platform-specific filename mapping with OS detection capabilities
- **`AssetSource`** - Enum for supported download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use tool_installation_message::{ToolInstallationMessage, SessionType, Asset, AssetSource};

// Create a tool installation configuration
let installation_msg = ToolInstallationMessage {
    tool_agent_id: "mingo-ai-agent".to_string(),
    tool_id: "network-scanner".to_string(),
    tool_type: "diagnostic".to_string(),
    version: "1.2.3".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Service),
    download_configurations: None,
    installation_command_args: Some(vec!["--silent".to_string()]),
    uninstallation_command_args: None,
    run_command_args: vec!["--scan".to_string(), "--verbose".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![
        Asset {
            id: "scanner-binary".to_string(),
            local_filename_configuration: vec![
                LocalFilenameConfig {
                    filename: "scanner.exe".to_string(),
                    os: "windows".to_string(),
                },
                LocalFilenameConfig {
                    filename: "scanner".to_string(),
                    os: "linux".to_string(),
                },
            ],
            source: AssetSource::Github,
            path: Some("/usr/local/bin".to_string()),
            executable: true,
            download_configurations: None,
            version: None,
        }
    ]),
};

// Check if filename config matches current OS
let config = LocalFilenameConfig {
    filename: "tool.exe".to_string(),
    os: "windows".to_string(),
};
let is_compatible = config.matches_current_os();
```
