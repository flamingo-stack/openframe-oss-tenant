Defines message structures for tool installation and management operations within the Flamingo platform. This module handles serialization of tool deployment configurations, asset management, and cross-platform installation parameters.

## Key Components

- **`ToolInstallationMessage`** - Main structure containing tool metadata, installation/uninstallation commands, and optional download configurations
- **`SessionType`** - Enum defining execution contexts (Service, Console, User)
- **`Asset`** - Structure for downloadable tool assets with platform-specific filename configurations
- **`LocalFilenameConfig`** - Platform-specific filename mapping with OS detection utilities
- **`AssetSource`** - Enum specifying asset download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use tool_installation_message::*;

// Create a tool installation message
let install_msg = ToolInstallationMessage {
    tool_agent_id: "agent-123".to_string(),
    tool_id: "docker".to_string(),
    tool_type: "container".to_string(),
    version: "24.0.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Service),
    download_configurations: None,
    installation_command_args: Some(vec!["--install".to_string()]),
    uninstallation_command_args: Some(vec!["--remove".to_string()]),
    run_command_args: vec!["docker".to_string(), "run".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![
        Asset {
            id: "docker-binary".to_string(),
            local_filename_configuration: vec![
                LocalFilenameConfig {
                    filename: "docker.exe".to_string(),
                    os: "windows".to_string(),
                },
                LocalFilenameConfig {
                    filename: "docker".to_string(),
                    os: "linux".to_string(),
                },
            ],
            source: AssetSource::Github,
            path: Some("/usr/local/bin".to_string()),
            executable: true,
            download_configurations: None,
            version: Some("24.0.0".to_string()),
        }
    ]),
};

// Check if filename config matches current OS
let config = LocalFilenameConfig {
    filename: "tool.exe".to_string(),
    os: "windows".to_string(),
};
let is_current_platform = config.matches_current_os();
```
