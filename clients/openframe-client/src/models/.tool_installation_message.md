Defines the message structure for tool installation requests in the Flamingo MSP platform, containing configuration details for downloading, installing, and managing AI-powered tools and agents.

## Key Components

- **`ToolInstallationMessage`** - Main struct containing tool identification, installation parameters, and optional configurations for downloads, commands, and assets
- **`SessionType`** - Enum defining execution contexts (Service, Console, User) for tool installation
- **`Asset`** - Struct representing downloadable files with platform-specific filename configurations and source information
- **`LocalFilenameConfig`** - Platform-specific filename mapping with OS detection via `matches_current_os()`
- **`AssetSource`** - Enum defining supported download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use tool_installation_message::*;

// Create a tool installation message
let message = ToolInstallationMessage {
    tool_agent_id: "mingo-ai-agent".to_string(),
    tool_id: "diagnostic-scanner".to_string(),
    tool_type: "automation".to_string(),
    version: "1.2.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Service),
    download_configurations: None,
    installation_command_args: Some(vec!["--silent".to_string()]),
    uninstallation_command_args: Some(vec!["--force".to_string()]),
    run_command_args: vec!["scan".to_string(), "--deep".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![
        Asset {
            id: "scanner-binary".to_string(),
            local_filename_configuration: vec![
                LocalFilenameConfig {
                    filename: "scanner.exe".to_string(),
                    os: "windows".to_string(),
                },
                LocalFilenameConfig {
                    filename: "scanner".to_string(),
                    os: "linux".to_string(),
                }
            ],
            source: AssetSource::Github,
            path: Some("/opt/flamingo/tools/".to_string()),
            executable: true,
            download_configurations: None,
            version: Some("1.2.0".to_string()),
        }
    ]),
};

// Check OS compatibility for filename configuration
let config = LocalFilenameConfig {
    filename: "tool.exe".to_string(),
    os: "windows".to_string(),
};
let is_compatible = config.matches_current_os();
```
