A serializable data structure that defines tool installation messages in the Flamingo/OpenFrame AI-powered MSP platform, containing all necessary information for installing, configuring, and running tools across different operating systems and session types.

## Key Components

- **ToolInstallationMessage**: Main struct containing tool metadata, installation/uninstallation commands, and optional assets
- **SessionType**: Enum defining execution contexts (Service, Console, User)
- **Asset**: Represents downloadable tool assets with OS-specific filename configurations
- **LocalFilenameConfig**: Maps filenames to specific operating systems with OS detection capability
- **AssetSource**: Enum for asset download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use serde_json;

// Create a tool installation message
let install_msg = ToolInstallationMessage {
    tool_agent_id: "agent_123".to_string(),
    tool_id: "kubectl".to_string(),
    tool_type: "kubernetes_cli".to_string(),
    version: "1.28.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Console),
    download_configurations: None,
    installation_command_args: Some(vec!["--silent".to_string()]),
    uninstallation_command_args: None,
    run_command_args: vec!["version".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![Asset {
        id: "kubectl-binary".to_string(),
        local_filename_configuration: vec![
            LocalFilenameConfig {
                filename: "kubectl.exe".to_string(),
                os: "windows".to_string(),
            },
            LocalFilenameConfig {
                filename: "kubectl".to_string(),
                os: "linux".to_string(),
            },
        ],
        source: AssetSource::Github,
        path: Some("/usr/local/bin".to_string()),
        executable: true,
        download_configurations: None,
        version: Some("1.28.0".to_string()),
    }]),
};

// Check if filename matches current OS
let config = LocalFilenameConfig {
    filename: "kubectl".to_string(),
    os: "linux".to_string(),
};
let is_current_os = config.matches_current_os();

// Serialize to JSON
let json = serde_json::to_string(&install_msg)?;
```
