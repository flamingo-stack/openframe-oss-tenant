A serializable data structure that defines the configuration for installing tools on agent systems within the Flamingo MSP platform. This message contains all necessary information for tool deployment, including download sources, installation commands, and platform-specific assets.

## Key Components

- **`ToolInstallationMessage`** - Main struct containing tool identification, versioning, and installation configuration
- **`SessionType`** - Enum defining execution contexts (Service, Console, User)
- **`Asset`** - Represents downloadable tool components with platform-specific configurations
- **`LocalFilenameConfig`** - OS-specific filename mapping with current platform detection
- **`AssetSource`** - Enum for different download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use serde_json;

// Create a tool installation message for a cross-platform tool
let installation_msg = ToolInstallationMessage {
    tool_agent_id: "agent-123".to_string(),
    tool_id: "monitoring-tool".to_string(),
    tool_type: "system_monitor".to_string(),
    version: "2.1.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Service),
    download_configurations: None,
    installation_command_args: Some(vec!["--silent".to_string()]),
    uninstallation_command_args: Some(vec!["--force".to_string()]),
    run_command_args: vec!["--daemon".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![
        Asset {
            id: "main-binary".to_string(),
            local_filename_configuration: vec![
                LocalFilenameConfig {
                    filename: "monitor.exe".to_string(),
                    os: "windows".to_string(),
                },
                LocalFilenameConfig {
                    filename: "monitor".to_string(),
                    os: "linux".to_string(),
                }
            ],
            source: AssetSource::Github,
            path: Some("/usr/local/bin".to_string()),
            executable: true,
            download_configurations: None,
            version: None,
        }
    ]),
};

// Serialize to JSON for transmission
let json = serde_json::to_string(&installation_msg)?;

// Check if filename config matches current OS
let config = LocalFilenameConfig {
    filename: "tool.exe".to_string(),
    os: "windows".to_string(),
};
let is_current_os = config.matches_current_os();
```
