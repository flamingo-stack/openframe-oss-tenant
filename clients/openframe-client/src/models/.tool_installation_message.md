A comprehensive data structure for managing tool installation messages in the Flamingo MSP platform, supporting multi-platform tool deployment with configurable assets and execution parameters.

## Key Components

- **`ToolInstallationMessage`** - Main message structure containing tool metadata, installation commands, and optional download configurations
- **`SessionType`** - Enum defining execution contexts (Service, Console, User)
- **`Asset`** - Represents downloadable tool assets with platform-specific configurations
- **`LocalFilenameConfig`** - Platform-specific filename mapping with OS detection
- **`AssetSource`** - Enum for asset source types (Artifactory, ToolApi, Github)

## Usage Example

```rust
use tool_installation_message::{ToolInstallationMessage, SessionType, Asset, AssetSource};

// Create a tool installation message
let installation_msg = ToolInstallationMessage {
    tool_agent_id: "agent-001".to_string(),
    tool_id: "kubectl".to_string(),
    tool_type: "kubernetes".to_string(),
    version: "1.28.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Console),
    download_configurations: None,
    installation_command_args: Some(vec!["install".to_string()]),
    uninstallation_command_args: Some(vec!["uninstall".to_string()]),
    run_command_args: vec!["kubectl".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![
        Asset {
            id: "kubectl-binary".to_string(),
            local_filename_configuration: vec![
                LocalFilenameConfig {
                    filename: "kubectl.exe".to_string(),
                    os: "windows".to_string(),
                },
                LocalFilenameConfig {
                    filename: "kubectl".to_string(),
                    os: "linux".to_string(),
                }
            ],
            source: AssetSource::Github,
            path: Some("/usr/local/bin".to_string()),
            executable: true,
            download_configurations: None,
            version: Some("1.28.0".to_string()),
        }
    ]),
};

// Check if filename config matches current OS
let config = LocalFilenameConfig {
    filename: "kubectl".to_string(),
    os: "linux".to_string(),
};
let matches = config.matches_current_os();
```
