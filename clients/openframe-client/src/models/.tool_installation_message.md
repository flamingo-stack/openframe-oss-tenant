A Rust data structure for tool installation messaging that handles cross-platform tool deployment with configurable assets and command execution parameters.

## Key Components

- **ToolInstallationMessage**: Main struct containing tool metadata, installation parameters, and optional configurations
- **SessionType**: Enum defining execution contexts (Service, Console, User)
- **Asset**: Structure for managing downloadable tool assets with platform-specific configurations
- **LocalFilenameConfig**: Platform-specific filename configuration with OS matching logic
- **AssetSource**: Enum for different asset download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use tool_installation_message::{ToolInstallationMessage, SessionType, Asset, LocalFilenameConfig, AssetSource};

// Create a tool installation message
let installation_msg = ToolInstallationMessage {
    tool_agent_id: "agent-123".to_string(),
    tool_id: "my-tool".to_string(),
    tool_type: "cli".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Console),
    download_configurations: None,
    installation_command_args: Some(vec!["--install".to_string()]),
    uninstallation_command_args: Some(vec!["--uninstall".to_string()]),
    run_command_args: vec!["--run".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![Asset {
        id: "binary-asset".to_string(),
        local_filename_configuration: vec![
            LocalFilenameConfig {
                filename: "tool.exe".to_string(),
                os: "windows".to_string(),
            },
            LocalFilenameConfig {
                filename: "tool".to_string(),
                os: "linux".to_string(),
            },
        ],
        source: AssetSource::Github,
        path: Some("/usr/local/bin".to_string()),
        executable: true,
        download_configurations: None,
        version: Some("1.0.0".to_string()),
    }]),
};

// Check if a filename config matches current OS
let config = LocalFilenameConfig {
    filename: "tool.exe".to_string(),
    os: "windows".to_string(),
};
let matches = config.matches_current_os();
```
