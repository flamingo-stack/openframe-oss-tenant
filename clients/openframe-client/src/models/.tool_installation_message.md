This file defines data structures for managing tool installation messages in the Flamingo/OpenFrame MSP platform, facilitating the automated deployment and management of IT tools across different environments.

## Key Components

- **`ToolInstallationMessage`** - Main struct containing tool metadata, installation/uninstallation commands, and optional download configurations
- **`SessionType`** - Enum defining execution contexts (Service, Console, User) for tool sessions
- **`Asset`** - Struct representing downloadable tool assets with platform-specific configurations
- **`LocalFilenameConfig`** - Platform-specific filename mapping with OS detection capability
- **`AssetSource`** - Enum specifying asset download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use tool_installation_message::{ToolInstallationMessage, SessionType, Asset, AssetSource};

// Create a tool installation message
let installation_msg = ToolInstallationMessage {
    tool_agent_id: "agent_123".to_string(),
    tool_id: "kubectl".to_string(),
    tool_type: "kubernetes".to_string(),
    version: "1.28.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Console),
    download_configurations: None,
    installation_command_args: Some(vec!["install".to_string()]),
    uninstallation_command_args: Some(vec!["uninstall".to_string()]),
    run_command_args: vec!["kubectl".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![
        Asset {
            id: "kubectl_binary".to_string(),
            source: AssetSource::Github,
            executable: true,
            // ... other fields
        }
    ]),
};

// Check OS compatibility
let filename_config = LocalFilenameConfig {
    filename: "kubectl.exe".to_string(),
    os: "windows".to_string(),
};
let is_compatible = filename_config.matches_current_os();
```
