A message structure for communicating tool installation requirements and configurations within the Flamingo MSP platform's tool management system.

## Key Components

- **`ToolInstallationMessage`** - Main structure containing tool metadata, installation parameters, and asset configurations
- **`SessionType`** - Enum defining execution contexts (Service, Console, User)
- **`Asset`** - Structure for downloadable tool components with OS-specific configurations
- **`LocalFilenameConfig`** - OS-specific filename mapping with platform detection
- **`AssetSource`** - Enum for different asset download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use tool_installation_message::{ToolInstallationMessage, SessionType, Asset, AssetSource};

// Create a tool installation message
let installation_msg = ToolInstallationMessage {
    tool_agent_id: "agent-123".to_string(),
    tool_id: "powershell-core".to_string(),
    tool_type: "runtime".to_string(),
    version: "7.4.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Service),
    download_configurations: None,
    installation_command_args: Some(vec!["--quiet".to_string()]),
    uninstallation_command_args: Some(vec!["--force".to_string()]),
    run_command_args: vec!["pwsh".to_string()],
    tool_agent_id_command_args: None,
    assets: None,
};

// Create an asset with OS-specific configuration
let asset = Asset {
    id: "powershell-binary".to_string(),
    local_filename_configuration: vec![
        LocalFilenameConfig {
            filename: "powershell.exe".to_string(),
            os: "windows".to_string(),
        }
    ],
    source: AssetSource::Github,
    path: Some("/opt/powershell/".to_string()),
    executable: true,
    download_configurations: None,
    version: Some("7.4.0".to_string()),
};

// Check if filename config matches current OS
if asset.local_filename_configuration[0].matches_current_os() {
    println!("Using filename for current platform");
}
```
