This file defines data structures for managing tool installation messages and configurations in the OpenFrame AI-driven MSP platform. It provides serializable types for handling tool deployment, asset management, and cross-platform installation workflows.

## Key Components

**Main Structures:**
- `ToolInstallationMessage` - Core message structure containing tool metadata, installation commands, and configuration options
- `Asset` - Represents downloadable tool assets with platform-specific filename configurations
- `LocalFilenameConfig` - Maps filenames to specific operating systems with OS detection logic

**Enums:**
- `SessionType` - Defines execution contexts (Service, Console, User)
- `AssetSource` - Specifies asset download sources (Artifactory, ToolApi, GitHub)

## Usage Example

```rust
use tool_installation_message::{ToolInstallationMessage, SessionType, Asset, AssetSource};

// Create a tool installation message
let install_msg = ToolInstallationMessage {
    tool_agent_id: "agent-123".to_string(),
    tool_id: "docker-cli".to_string(),
    tool_type: "container".to_string(),
    version: "24.0.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Service),
    download_configurations: None,
    installation_command_args: Some(vec!["--quiet".to_string()]),
    uninstallation_command_args: None,
    run_command_args: vec!["docker".to_string(), "run".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![
        Asset {
            id: "docker-binary".to_string(),
            source: AssetSource::Github,
            path: Some("/usr/local/bin/docker".to_string()),
            executable: true,
            // ... other fields
        }
    ]),
};

// Check if filename config matches current OS
let config = LocalFilenameConfig {
    filename: "docker.exe".to_string(),
    os: "windows".to_string(),
};
let is_compatible = config.matches_current_os();
```
