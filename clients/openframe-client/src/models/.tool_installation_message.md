A structured message type for handling tool installation requests in the Flamingo AI-powered MSP platform, containing all necessary metadata for downloading, installing, and managing tools across different operating systems and session types.

## Key Components

### Primary Structures
- **`ToolInstallationMessage`** - Main message struct containing tool metadata, installation parameters, and optional configurations
- **`Asset`** - Represents downloadable tool assets with OS-specific filename configurations
- **`LocalFilenameConfig`** - Maps filenames to specific operating systems with current OS matching capability

### Enums
- **`SessionType`** - Defines execution contexts: Service, Console, or User sessions
- **`AssetSource`** - Specifies asset download sources: Artifactory, Tool API, or GitHub

### Key Features
- Cross-platform OS detection via `matches_current_os()` method
- Conditional serialization with `skip_serializing_if` for optional fields
- Integration with `DownloadConfiguration` for asset management

## Usage Example

```rust
use tool_installation_message::{ToolInstallationMessage, SessionType, Asset, AssetSource};

// Create a tool installation message
let installation_msg = ToolInstallationMessage {
    tool_agent_id: "agent-123".to_string(),
    tool_id: "monitoring-tool".to_string(),
    tool_type: "monitoring".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Service),
    download_configurations: None,
    installation_command_args: Some(vec!["--silent".to_string()]),
    uninstallation_command_args: None,
    run_command_args: vec!["start".to_string(), "--config=/etc/config".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![
        Asset {
            id: "main-binary".to_string(),
            local_filename_configuration: vec![
                LocalFilenameConfig {
                    filename: "tool.exe".to_string(),
                    os: "windows".to_string(),
                },
                LocalFilenameConfig {
                    filename: "tool".to_string(),
                    os: "linux".to_string(),
                },
            ],
            source: AssetSource::Github,
            path: Some("/usr/local/bin".to_string()),
            executable: true,
            download_configurations: None,
            version: None,
        }
    ]),
};

// Check if current OS matches a filename config
let config = LocalFilenameConfig {
    filename: "tool.exe".to_string(),
    os: "windows".to_string(),
};
let is_current_os = config.matches_current_os();
```
