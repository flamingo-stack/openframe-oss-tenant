Defines the data structures for tool installation messages in OpenFrame's AI-driven MSP platform. This module handles the serialization and configuration of tool deployment requests, including platform-specific asset management and session types.

## Key Components

- **`ToolInstallationMessage`** - Main struct containing all tool installation parameters including agent ID, version, commands, and optional configurations
- **`SessionType`** - Enum defining execution contexts (Service, Console, User) for tool operations
- **`Asset`** - Represents downloadable tool components with platform-specific filename configurations
- **`LocalFilenameConfig`** - OS-specific filename mapping with current platform detection
- **`AssetSource`** - Enum for asset download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use crate::ToolInstallationMessage;

// Create a tool installation message for a cross-platform deployment
let installation_msg = ToolInstallationMessage {
    tool_agent_id: "mingo-ai-tech-001".to_string(),
    tool_id: "kubectl".to_string(),
    tool_type: "kubernetes-cli".to_string(),
    version: "1.28.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Console),
    run_command_args: vec!["kubectl".to_string(), "version".to_string()],
    assets: Some(vec![
        Asset {
            id: "kubectl-binary".to_string(),
            local_filename_configuration: vec![
                LocalFilenameConfig { 
                    filename: "kubectl.exe".to_string(), 
                    os: "windows".to_string() 
                },
                LocalFilenameConfig { 
                    filename: "kubectl".to_string(), 
                    os: "linux".to_string() 
                }
            ],
            source: AssetSource::Github,
            executable: true,
            // ... other fields
        }
    ]),
    // ... other optional fields
};

// Check if a filename config matches current OS
let config = LocalFilenameConfig {
    filename: "tool.exe".to_string(),
    os: "windows".to_string()
};
let is_current_platform = config.matches_current_os();
```
