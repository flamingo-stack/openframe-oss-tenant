Defines the data structures for tool installation messages received by the agent, including the main installation payload and associated asset/configuration types.

## Key Components

### Structs

- **`ToolInstallationMessage`** — Primary message payload describing a tool to install or reinstall, including versioning, command arguments, optional download configurations, and an optional service name. Serializes to/from camelCase JSON.
- **`Asset`** — Represents a downloadable artifact associated with a tool, with per-OS filename mappings, source type, and optional version override support.
- **`LocalFilenameConfig`** — Maps a filename to a target OS string, used to resolve the correct local filename at runtime.

### Enums

- **`AssetSource`** — Discriminates the origin of an asset: `Artifactory`, `ToolApi`, or `Github`.

### Methods

| Method | Type | Description |
|---|---|---|
| `effective_version()` | `ToolInstallationMessage` | Returns the version from `tool_version_overrides` if present, otherwise falls back to `self.version` |
| `original_version()` | `Asset` | Returns `self.version` as `&str`, or empty string if `None` |
| `effective_version()` | `Asset` | Returns the override version for the asset ID, falling back to `original_version()` |
| `matches_current_os()` | `LocalFilenameConfig` | Returns `true` if `self.os` matches the compile-time target OS (case-insensitive) |

## Usage Example

```rust
use serde_json;

let json = r#"{
    "toolAgentId": "agent-42",
    "toolId": "my-tool",
    "toolType": "cli",
    "version": "1.2.3",
    "reinstall": false,
    "runCommandArgs": ["--config", "/etc/tool/config.yaml"]
}"#;

let msg: ToolInstallationMessage = serde_json::from_str(json).unwrap();

// Resolves override version or falls back to "1.2.3"
let version = msg.effective_version();

// Check if an asset's filename config applies to the current platform
if let Some(assets) = &msg.assets {
    for asset in assets {
        let filename = asset.local_filename_configuration
            .iter()
            .find(|c| c.matches_current_os())
            .map(|c| c.filename.as_str());
    }
}
```
