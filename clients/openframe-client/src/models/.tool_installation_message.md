A data structure that defines messages for tool installation operations in the Flamingo platform, including configuration details for downloads, assets, and cross-platform compatibility.

## Key Components

- **`ToolInstallationMessage`** - Main struct containing tool metadata, installation commands, and optional configurations
- **`SessionType`** - Enum defining execution contexts (Service, Console, User)
- **`Asset`** - Represents downloadable tool assets with OS-specific filename configurations
- **`LocalFilenameConfig`** - OS-specific file naming with current OS detection
- **`AssetSource`** - Enum for asset download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use tool_installation_message::{ToolInstallationMessage, SessionType, Asset, AssetSource};

// Create a tool installation message
let installation_msg = ToolInstallationMessage {
    tool_agent_id: "agent-123".to_string(),
    tool_id: "git".to_string(),
    tool_type: "version_control".to_string(),
    version: "2.40.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Console),
    download_configurations: None,
    installation_command_args: Some(vec!["install".to_string(), "--quiet".to_string()]),
    uninstallation_command_args: Some(vec!["uninstall".to_string()]),
    run_command_args: vec!["git".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![
        Asset {
            id: "git-binary".to_string(),
            local_filename_configuration: vec![
                LocalFilenameConfig {
                    filename: "git.exe".to_string(),
                    os: "windows".to_string(),
                }
            ],
            source: AssetSource::Github,
            path: Some("/usr/bin/git".to_string()),
            executable: true,
            download_configurations: None,
            version: Some("2.40.0".to_string()),
        }
    ]),
};

// Check if filename config matches current OS
let config = LocalFilenameConfig {
    filename: "git.exe".to_string(),
    os: "windows".to_string(),
};
let is_current_os = config.matches_current_os();
```
