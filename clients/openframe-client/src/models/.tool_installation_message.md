A serializable data structure that defines the configuration for installing and managing tools within the Flamingo AI MSP platform, supporting cross-platform deployment with flexible asset management and command execution parameters.

## Key Components

- **`ToolInstallationMessage`** - Main struct containing tool installation configuration including agent ID, version, session type, and command arguments
- **`SessionType`** - Enum defining execution contexts (Service, Console, User) for tool installation
- **`Asset`** - Struct representing downloadable tool assets with platform-specific configurations
- **`LocalFilenameConfig`** - Platform-specific filename mapping with OS detection utilities
- **`AssetSource`** - Enum specifying asset download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use tool_installation_message::{ToolInstallationMessage, SessionType, Asset, AssetSource};

// Create a tool installation message
let install_msg = ToolInstallationMessage {
    tool_agent_id: "agent-123".to_string(),
    tool_id: "monitoring-tool".to_string(),
    tool_type: "monitoring".to_string(),
    version: "1.2.3".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Service),
    download_configurations: None,
    installation_command_args: Some(vec!["--silent".to_string()]),
    uninstallation_command_args: Some(vec!["--force".to_string()]),
    run_command_args: vec!["--daemon".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![
        Asset {
            id: "main-binary".to_string(),
            local_filename_configuration: vec![
                LocalFilenameConfig {
                    filename: "tool.exe".to_string(),
                    os: "windows".to_string(),
                }
            ],
            source: AssetSource::Github,
            path: Some("/usr/local/bin".to_string()),
            executable: true,
            download_configurations: None,
            version: None,
        }
    ]),
};

// Serialize to JSON for transmission
let json = serde_json::to_string(&install_msg)?;
```
