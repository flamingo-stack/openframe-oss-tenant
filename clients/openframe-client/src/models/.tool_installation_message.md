Defines data structures for tool installation messaging in the Flamingo MSP platform, enabling automated deployment and management of MSP tools across different environments and operating systems.

## Key Components

- **`ToolInstallationMessage`** - Main structure containing tool metadata, installation parameters, and session configuration for automated tool deployment
- **`SessionType`** - Enum defining execution contexts (Service, Console, User) for tool installation
- **`Asset`** - Structure representing downloadable tool assets with OS-specific filename configurations
- **`LocalFilenameConfig`** - OS-specific filename mapping with current OS detection capability
- **`AssetSource`** - Enum for asset download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use tool_installation_message::{ToolInstallationMessage, SessionType, Asset, AssetSource};

// Create a tool installation message for cross-platform deployment
let installation_msg = ToolInstallationMessage {
    tool_agent_id: "msp-tool-001".to_string(),
    tool_id: "network-scanner".to_string(),
    tool_type: "diagnostic".to_string(),
    version: "2.1.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Service),
    download_configurations: None,
    installation_command_args: Some(vec!["--silent".to_string()]),
    uninstallation_command_args: Some(vec!["--force".to_string()]),
    run_command_args: vec!["scan".to_string(), "--network".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![
        Asset {
            id: "scanner-binary".to_string(),
            local_filename_configuration: vec![
                LocalFilenameConfig {
                    filename: "scanner.exe".to_string(),
                    os: "windows".to_string(),
                },
                LocalFilenameConfig {
                    filename: "scanner".to_string(),
                    os: "linux".to_string(),
                }
            ],
            source: AssetSource::Github,
            path: Some("/usr/local/bin".to_string()),
            executable: true,
            download_configurations: None,
            version: None,
        }
    ]),
};

// Check if filename config matches current OS
let config = LocalFilenameConfig {
    filename: "tool.exe".to_string(),
    os: "windows".to_string(),
};
let is_compatible = config.matches_current_os();
```
