A serializable message structure that defines tool installation configuration and requirements for the OpenFrame MSP platform, supporting cross-platform asset management and multiple session types.

## Key Components

- **`ToolInstallationMessage`** - Main struct containing tool metadata, installation parameters, and asset configurations
- **`SessionType`** - Enum defining execution contexts (Service, Console, User)
- **`Asset`** - Struct representing downloadable tool components with OS-specific filename configurations
- **`LocalFilenameConfig`** - OS-specific filename mapping with current platform detection
- **`AssetSource`** - Enum for supported download sources (Artifactory, ToolApi, Github)

## Usage Example

```rust
use serde_json;

// Create a tool installation message for a cross-platform utility
let installation_msg = ToolInstallationMessage {
    tool_agent_id: "agent_001".to_string(),
    tool_id: "monitoring_tool".to_string(),
    tool_type: "system_monitor".to_string(),
    version: "1.2.3".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Service),
    download_configurations: None,
    installation_command_args: Some(vec!["--silent".to_string()]),
    uninstallation_command_args: Some(vec!["--cleanup".to_string()]),
    run_command_args: vec!["--start".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![
        Asset {
            id: "main_binary".to_string(),
            local_filename_configuration: vec![
                LocalFilenameConfig {
                    filename: "monitor.exe".to_string(),
                    os: "windows".to_string(),
                },
                LocalFilenameConfig {
                    filename: "monitor".to_string(),
                    os: "linux".to_string(),
                },
            ],
            source: AssetSource::Github,
            path: Some("/usr/local/bin".to_string()),
            executable: true,
            download_configurations: None,
            version: None,
        }
    ]),
};

// Check if filename config matches current OS
let config = LocalFilenameConfig {
    filename: "tool.exe".to_string(),
    os: "windows".to_string(),
};
let is_current_os = config.matches_current_os();

// Serialize to JSON for transmission
let json = serde_json::to_string(&installation_msg).unwrap();
```
