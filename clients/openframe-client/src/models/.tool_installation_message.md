Defines the message structure for tool installation requests, including asset management and version resolution logic for MSP-managed tools.

## Key Components

- **`ToolInstallationMessage`** — Primary message struct representing a tool installation request, carrying agent/tool identifiers, version, reinstall flag, command args, and optional download/asset configuration. Serializes with `camelCase` field names.
  - `effective_version()` — Returns the resolved version, preferring any override from `tool_version_overrides` over the message-supplied version.

- **`Asset`** — Describes a downloadable asset associated with a tool, including source, local filename mappings, path, executable flag, and optional per-asset version and download configuration.
  - `original_version()` — Returns the raw version string or empty string if absent.
  - `effective_version()` — Returns the override-resolved version for this asset ID, falling back to `original_version()`.

- **`LocalFilenameConfig`** — Maps a filename to a target OS string, with `matches_current_os()` performing a case-insensitive match against the compile-time target OS (`windows`, `macos`, `linux`).

- **`AssetSource`** — Enum representing supported asset download sources: `Artifactory`, `ToolApi`, or `Github`.

## Usage Example

```rust
use serde_json;
use crate::messages::tool_installation_message::{ToolInstallationMessage, AssetSource};

let json = r#"{
    "toolAgentId": "agent-123",
    "toolId": "my-tool",
    "toolType": "agent",
    "version": "1.2.3",
    "reinstall": false,
    "runCommandArgs": ["--config", "/etc/tool/config.yaml"]
}"#;

let msg: ToolInstallationMessage = serde_json::from_str(json).unwrap();

// Resolves to an override version if one is registered, otherwise "1.2.3"
let version = msg.effective_version();
println!("Installing {} @ {}", msg.tool_id, version);
```
