This file defines the data structures for managing tool installation messages in the Flamingo MSP platform, including configuration for downloads, assets, and platform-specific deployment options.

## Key Components

- **`ToolInstallationMessage`** - Main struct containing tool metadata, installation/uninstallation commands, and optional assets for deployment
- **`SessionType`** - Enum defining execution contexts: Service, Console, or User sessions
- **`Asset`** - Represents downloadable tool components with platform-specific filename configurations
- **`LocalFilenameConfig`** - Maps filenames to specific operating systems with OS detection capability
- **`AssetSource`** - Enum for asset download sources: Artifactory, Tool API, or GitHub

## Usage Example

```rust
use tool_installation_message::{ToolInstallationMessage, SessionType, Asset, AssetSource};

// Create a tool installation message
let installation_msg = ToolInstallationMessage {
    tool_agent_id: "agent_001".to_string(),
    tool_id: "monitoring_tool".to_string(),
    tool_type: "system_monitor".to_string(),
    version: "1.2.3".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Service),
    download_configurations: None,
    installation_command_args: Some(vec!["install".to_string(), "--quiet".to_string()]),
    uninstallation_command_args: Some(vec!["uninstall".to_string()]),
    run_command_args: vec!["start".to_string(), "--daemon".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![
        Asset {
            id: "main_binary".to_string(),
            local_filename_configuration: vec![],
            source: AssetSource::Github,
            path: Some("/usr/local/bin/".to_string()),
            executable: true,
            download_configurations: None,
            version: Some("1.2.3".to_string()),
        }
    ]),
};

// Check OS compatibility
let filename_config = LocalFilenameConfig {
    filename: "tool.exe".to_string(),
    os: "windows".to_string(),
};
let is_compatible = filename_config.matches_current_os();
```
