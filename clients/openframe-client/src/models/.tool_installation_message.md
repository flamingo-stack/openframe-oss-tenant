A serializable message structure that defines tool installation requests and configurations for the Flamingo MSP platform's automated tool deployment system.

## Key Components

**ToolInstallationMessage**: Main structure containing tool metadata, installation parameters, and execution configurations with optional download settings and assets.

**SessionType**: Enum defining execution contexts - Service (background), Console (terminal), or User (interactive session).

**Asset**: Represents downloadable tool components with platform-specific filename configurations, source locations, and executable permissions.

**LocalFilenameConfig**: Platform-aware filename mapping with OS detection functionality via `matches_current_os()` method.

**AssetSource**: Enum for supported download sources including Artifactory, Tool API, and GitHub repositories.

## Usage Example

```rust
use tool_installation_message::*;

// Create installation message for a cross-platform tool
let message = ToolInstallationMessage {
    tool_agent_id: "agent-001".to_string(),
    tool_id: "kubectl".to_string(),
    tool_type: "kubernetes-cli".to_string(),
    version: "1.28.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Console),
    download_configurations: None,
    installation_command_args: Some(vec!["install".to_string()]),
    uninstallation_command_args: Some(vec!["uninstall".to_string()]),
    run_command_args: vec!["kubectl".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![
        Asset {
            id: "kubectl-binary".to_string(),
            local_filename_configuration: vec![
                LocalFilenameConfig {
                    filename: "kubectl.exe".to_string(),
                    os: "windows".to_string(),
                },
                LocalFilenameConfig {
                    filename: "kubectl".to_string(),
                    os: "linux".to_string(),
                },
            ],
            source: AssetSource::Github,
            path: Some("/usr/local/bin/kubectl".to_string()),
            executable: true,
            download_configurations: None,
            version: Some("1.28.0".to_string()),
        }
    ]),
};

// Check if filename config matches current OS
let config = LocalFilenameConfig {
    filename: "kubectl".to_string(),
    os: "linux".to_string(),
};
let is_compatible = config.matches_current_os();
```
