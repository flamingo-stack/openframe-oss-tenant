A serializable data structure that defines the complete configuration for installing and managing tools in the Flamingo MSP platform, including download sources, platform-specific assets, and execution parameters.

## Key Components

- **ToolInstallationMessage** - Main struct containing tool metadata, installation parameters, and optional assets
- **SessionType** - Enum defining execution contexts (Service, Console, User)
- **Asset** - Struct representing downloadable tool components with platform-specific configurations
- **LocalFilenameConfig** - Platform-specific filename mapping with OS detection
- **AssetSource** - Enum for different download sources (Artifactory, ToolApi, Github)

## Usage Example

```rust
use tool_installation_message::{ToolInstallationMessage, SessionType, Asset, AssetSource};

// Create a tool installation message
let installation_msg = ToolInstallationMessage {
    tool_agent_id: "agent-123".to_string(),
    tool_id: "monitoring-tool".to_string(),
    tool_type: "system-monitor".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Service),
    download_configurations: None,
    installation_command_args: Some(vec!["--install".to_string(), "--silent".to_string()]),
    uninstallation_command_args: Some(vec!["--uninstall".to_string()]),
    run_command_args: vec!["--start".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![Asset {
        id: "main-binary".to_string(),
        local_filename_configuration: vec![],
        source: AssetSource::Github,
        path: Some("/bin/monitor".to_string()),
        executable: true,
        download_configurations: None,
        version: Some("1.0.0".to_string()),
    }]),
};

// Check OS compatibility
let filename_config = LocalFilenameConfig {
    filename: "monitor.exe".to_string(),
    os: "windows".to_string(),
};
let is_compatible = filename_config.matches_current_os();
```

This structure enables the Flamingo platform to automatically install, configure, and manage MSP tools across different operating systems and deployment contexts.
