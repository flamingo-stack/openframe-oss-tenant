This file defines data structures for managing tool installation messages within the Flamingo MSP platform's agent system. It provides a comprehensive schema for handling tool deployment, configuration, and asset management across different operating systems and environments.

## Key Components

- **`ToolInstallationMessage`** - Main struct containing tool identification, versioning, command arguments, and download configurations for agent-based tool management
- **`SessionType`** - Enum defining execution contexts (Service, Console, User) for tool installation sessions
- **`Asset`** - Struct representing downloadable tool assets with OS-specific filename configurations and source definitions
- **`LocalFilenameConfig`** - OS-specific filename mapping with current OS detection capabilities
- **`AssetSource`** - Enum for different asset repository sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use crate::tool_installation_message::{ToolInstallationMessage, SessionType, Asset, AssetSource};

// Create a tool installation message
let install_msg = ToolInstallationMessage {
    tool_agent_id: "agent-001".to_string(),
    tool_id: "kubectl".to_string(),
    tool_type: "kubernetes-cli".to_string(),
    version: "1.28.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Console),
    download_configurations: None,
    installation_command_args: Some(vec!["install".to_string()]),
    uninstallation_command_args: Some(vec!["uninstall".to_string()]),
    run_command_args: vec!["version".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![
        Asset {
            id: "kubectl-binary".to_string(),
            local_filename_configuration: vec![
                LocalFilenameConfig {
                    filename: "kubectl.exe".to_string(),
                    os: "windows".to_string(),
                },
                LocalFilenameConfig {
                    filename: "kubectl".to_string(),
                    os: "linux".to_string(),
                }
            ],
            source: AssetSource::Github,
            path: Some("/usr/local/bin/kubectl".to_string()),
            executable: true,
            download_configurations: None,
            version: Some("1.28.0".to_string()),
        }
    ]),
};

// Check OS compatibility
let config = LocalFilenameConfig {
    filename: "kubectl".to_string(),
    os: "linux".to_string(),
};
let is_compatible = config.matches_current_os();
```
