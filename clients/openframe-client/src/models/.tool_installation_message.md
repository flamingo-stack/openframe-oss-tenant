Message structure for instructing tool agents to install, configure, and manage tools within the Flamingo MSP platform's automation system.

## Key Components

- **ToolInstallationMessage** - Main message struct containing tool installation metadata, commands, and optional assets
- **SessionType** - Enum defining execution context (Service, Console, User)
- **Asset** - Represents downloadable resources with platform-specific filename configurations
- **LocalFilenameConfig** - OS-specific filename mapping with current platform detection
- **AssetSource** - Enum for asset download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use tool_installation_message::{ToolInstallationMessage, SessionType, Asset, AssetSource};

// Create a tool installation message
let installation_msg = ToolInstallationMessage {
    tool_agent_id: "agent-123".to_string(),
    tool_id: "monitoring-tool".to_string(),
    tool_type: "system-monitor".to_string(),
    version: "1.2.3".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Service),
    download_configurations: None,
    installation_command_args: Some(vec!["install".to_string(), "--silent".to_string()]),
    uninstallation_command_args: Some(vec!["uninstall".to_string()]),
    run_command_args: vec!["start".to_string()],
    tool_agent_id_command_args: None,
    assets: None,
};

// Check if filename config matches current OS
let config = LocalFilenameConfig {
    filename: "tool.exe".to_string(),
    os: "windows".to_string(),
};
let is_compatible = config.matches_current_os();
```

This structure enables the OpenFrame platform to orchestrate tool deployments across different operating systems and execution contexts within the MSP infrastructure.
