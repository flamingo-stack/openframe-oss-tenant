A serializable data structure that defines tool installation messages within the Flamingo MSP platform, containing all necessary configuration and metadata for automated tool deployment and management across different environments.

## Key Components

- **`ToolInstallationMessage`** - Main struct containing tool metadata, installation commands, and optional assets
- **`SessionType`** - Enum defining execution contexts (Service, Console, User)
- **`Asset`** - Struct representing downloadable tool components with OS-specific configurations
- **`LocalFilenameConfig`** - OS-specific filename mapping with platform detection utilities
- **`AssetSource`** - Enum specifying download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use tool_installation_message::{ToolInstallationMessage, SessionType, Asset, AssetSource};

// Create a tool installation message
let installation_msg = ToolInstallationMessage {
    tool_agent_id: "agent-001".to_string(),
    tool_id: "kubectl".to_string(),
    tool_type: "kubernetes-cli".to_string(),
    version: "1.28.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Console),
    run_command_args: vec!["kubectl".to_string(), "version".to_string()],
    assets: Some(vec![Asset {
        id: "kubectl-binary".to_string(),
        source: AssetSource::Github,
        executable: true,
        // ... other fields
    }]),
    // ... other optional fields
};

// Check OS compatibility for filename configs
let config = LocalFilenameConfig {
    filename: "kubectl.exe".to_string(),
    os: "windows".to_string(),
};
let is_compatible = config.matches_current_os();
```

This structure enables the Flamingo platform to orchestrate tool installations across different operating systems and deployment contexts with proper serialization for API communication.
