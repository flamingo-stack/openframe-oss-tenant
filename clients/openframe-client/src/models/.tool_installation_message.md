A comprehensive data structure for handling tool installation messages in Flamingo's MSP automation platform, supporting cross-platform deployment with configurable assets and session management.

## Key Components

- **`ToolInstallationMessage`** - Main message struct containing tool metadata, installation parameters, and optional download configurations
- **`SessionType`** - Enum defining execution contexts (Service, Console, User) for different deployment scenarios  
- **`Asset`** - Represents downloadable tool assets with OS-specific filename configurations and source specifications
- **`LocalFilenameConfig`** - OS-specific filename mapping with current platform detection utility
- **`AssetSource`** - Enum for asset download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use tool_installation_message::{ToolInstallationMessage, SessionType, Asset, AssetSource};

// Create a tool installation message
let installation_msg = ToolInstallationMessage {
    tool_agent_id: "agent-001".to_string(),
    tool_id: "monitoring-tool".to_string(),
    tool_type: "monitoring".to_string(),
    version: "2.1.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Service),
    download_configurations: None,
    installation_command_args: Some(vec!["--quiet".to_string()]),
    uninstallation_command_args: Some(vec!["--force".to_string()]),
    run_command_args: vec!["start".to_string(), "--daemon".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![
        Asset {
            id: "binary".to_string(),
            local_filename_configuration: vec![
                LocalFilenameConfig {
                    filename: "monitor.exe".to_string(),
                    os: "windows".to_string(),
                },
                LocalFilenameConfig {
                    filename: "monitor".to_string(),
                    os: "linux".to_string(),
                }
            ],
            source: AssetSource::Github,
            path: Some("/usr/local/bin".to_string()),
            executable: true,
            download_configurations: None,
            version: Some("2.1.0".to_string()),
        }
    ]),
};

// Check if filename config matches current OS
let config = LocalFilenameConfig {
    filename: "tool.exe".to_string(),
    os: "windows".to_string(),
};
let is_compatible = config.matches_current_os();
```
