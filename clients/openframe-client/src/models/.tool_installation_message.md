A structured message format for tool installation operations in the Flamingo MSP platform, providing comprehensive configuration for tool deployment, asset management, and cross-platform compatibility.

## Key Components

- **`ToolInstallationMessage`** - Main message structure containing tool metadata, installation commands, and optional download configurations
- **`SessionType`** - Enum defining execution contexts (Service, Console, User) for tool deployment
- **`Asset`** - Represents downloadable tool assets with platform-specific filename configurations
- **`LocalFilenameConfig`** - Handles OS-specific filename mapping with `matches_current_os()` utility
- **`AssetSource`** - Enum for supported download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use tool_installation_message::{ToolInstallationMessage, SessionType, Asset, AssetSource};

// Create a tool installation message
let installation_msg = ToolInstallationMessage {
    tool_agent_id: "agent-001".to_string(),
    tool_id: "kubectl".to_string(),
    tool_type: "kubernetes-cli".to_string(),
    version: "1.28.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Console),
    run_command_args: vec!["kubectl".to_string(), "version".to_string()],
    assets: Some(vec![Asset {
        id: "kubectl-binary".to_string(),
        source: AssetSource::Github,
        executable: true,
        local_filename_configuration: vec![
            LocalFilenameConfig {
                filename: "kubectl.exe".to_string(),
                os: "windows".to_string(),
            },
            LocalFilenameConfig {
                filename: "kubectl".to_string(),
                os: "linux".to_string(),
            }
        ],
        // ... other fields
    }]),
    // ... other optional fields
};

// Serialize to JSON for transmission
let json_msg = serde_json::to_string(&installation_msg)?;
```
