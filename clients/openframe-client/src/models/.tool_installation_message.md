A comprehensive data structure for handling tool installation messages in the Flamingo MSP platform, defining all necessary parameters for downloading, installing, and managing IT tools across different operating systems.

## Key Components

- **`ToolInstallationMessage`** - Main struct containing complete installation metadata including tool identification, version, session type, and command arguments
- **`SessionType`** - Enum defining execution contexts (Service, Console, User) for tool deployment
- **`Asset`** - Represents downloadable files/binaries with OS-specific configurations and source locations
- **`LocalFilenameConfig`** - OS-specific filename mappings with `matches_current_os()` utility method
- **`AssetSource`** - Enum for supported download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use tool_installation_message::*;

// Create installation message for cross-platform tool
let installation_msg = ToolInstallationMessage {
    tool_agent_id: "mingo-ai-agent".to_string(),
    tool_id: "network-scanner".to_string(),
    tool_type: "diagnostic".to_string(),
    version: "1.2.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Service),
    run_command_args: vec!["scan".to_string(), "--network".to_string()],
    assets: Some(vec![Asset {
        id: "scanner-binary".to_string(),
        local_filename_configuration: vec![
            LocalFilenameConfig {
                filename: "scanner.exe".to_string(),
                os: "windows".to_string(),
            },
            LocalFilenameConfig {
                filename: "scanner".to_string(),
                os: "linux".to_string(),
            }
        ],
        source: AssetSource::Github,
        executable: true,
        ..Default::default()
    }]),
    ..Default::default()
};

// Check OS compatibility
let config = LocalFilenameConfig {
    filename: "tool.exe".to_string(),
    os: "windows".to_string(),
};
let is_compatible = config.matches_current_os();
```
