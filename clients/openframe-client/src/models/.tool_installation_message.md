Defines the message schema for tool installation payloads, including all metadata needed to install, run, or uninstall a managed tool agent on a target system.

## Key Components

### Structs

- **`ToolInstallationMessage`** — Top-level message containing tool identity (`tool_agent_id`, `tool_id`, `tool_type`), version, reinstall flag, download configs, command args, optional assets, and service name. Serializes to/from camelCase JSON.
  - `effective_version()` — Returns the active version, checking `tool_version_overrides` first before falling back to the message's own `version` field.

- **`Asset`** — Represents a binary or file asset associated with a tool, with source, path, executable flag, OS-specific filename configs, and optional per-asset download configurations.
  - `original_version()` — Returns the asset's declared version or an empty string.
  - `effective_version()` — Resolves version via `tool_version_overrides` by asset `id`, falling back to `original_version()`.

- **`LocalFilenameConfig`** — Maps a filename to a target OS string.
  - `matches_current_os()` — Returns `true` if the config's `os` field matches the compile-time target OS (`windows`, `macos`, or `linux`), using case-insensitive comparison.

### Enum

- **`AssetSource`** — Enumerates supported asset download origins: `Artifactory`, `ToolApi`, `Github`.

## Usage Example

```rust
let msg = ToolInstallationMessage {
    tool_agent_id: "agent-123".to_string(),
    tool_id: "my-tool".to_string(),
    tool_type: "agent".to_string(),
    version: "1.2.3".to_string(),
    reinstall: false,
    download_configurations: None,
    installation_command_args: Some(vec!["--silent".to_string()]),
    uninstallation_command_args: None,
    run_command_args: vec!["--start".to_string()],
    tool_agent_id_command_args: None,
    assets: None,
    service_name: Some("my-tool-svc".to_string()),
};

// Resolves override version if one is registered for "my-tool"
println!("Installing version: {}", msg.effective_version());

// Check if a filename config applies to the current OS
let config = LocalFilenameConfig {
    filename: "my-tool.exe".to_string(),
    os: "windows".to_string(),
};
if config.matches_current_os() {
    println!("Use filename: {}", config.filename);
}
```
