Defines message structures for tool installation requests in the Flamingo AI-powered MSP platform, enabling automated deployment and management of IT tools across different operating systems and session types.

## Key Components

- **`ToolInstallationMessage`** - Main struct containing tool installation metadata including agent ID, version, installation commands, and optional assets
- **`SessionType`** - Enum defining execution contexts: Service, Console, or User sessions  
- **`Asset`** - Represents downloadable tool components with platform-specific configurations
- **`LocalFilenameConfig`** - Cross-platform filename mapping with OS detection via `matches_current_os()`
- **`AssetSource`** - Enum for asset download sources: Artifactory, Tool API, or GitHub

## Usage Example

```rust
use serde_json;

// Create a tool installation message
let installation_msg = ToolInstallationMessage {
    tool_agent_id: "agent-001".to_string(),
    tool_id: "monitoring-tool".to_string(),
    tool_type: "monitoring".to_string(),
    version: "1.2.3".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Service),
    download_configurations: None,
    installation_command_args: Some(vec!["--silent".to_string()]),
    uninstallation_command_args: None,
    run_command_args: vec!["--daemon".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![
        Asset {
            id: "main-binary".to_string(),
            local_filename_configuration: vec![
                LocalFilenameConfig {
                    filename: "tool.exe".to_string(),
                    os: "windows".to_string(),
                }
            ],
            source: AssetSource::Github,
            path: Some("/usr/bin/tool".to_string()),
            executable: true,
            download_configurations: None,
            version: None,
        }
    ]),
};

// Serialize to JSON for transmission
let json = serde_json::to_string(&installation_msg)?;
```
