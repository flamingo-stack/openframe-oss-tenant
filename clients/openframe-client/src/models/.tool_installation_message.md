Serializable data structures for managing tool installation messages in the Flamingo MSP platform's automated deployment system.

## Key Components

- **ToolInstallationMessage** - Main struct containing complete tool installation configuration including agent ID, version, commands, and optional assets
- **SessionType** - Enum defining execution contexts (Service, Console, User) for tool installations
- **Asset** - Represents downloadable tool assets with platform-specific filename configurations and source information
- **LocalFilenameConfig** - OS-specific filename mapping with `matches_current_os()` helper for cross-platform compatibility
- **AssetSource** - Enum for asset download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use tool_installation_message::{ToolInstallationMessage, SessionType, Asset, LocalFilenameConfig, AssetSource};

// Create a tool installation message
let installation_msg = ToolInstallationMessage {
    tool_agent_id: "agent-123".to_string(),
    tool_id: "kubectl".to_string(),
    tool_type: "kubernetes-cli".to_string(),
    version: "1.28.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Console),
    download_configurations: None,
    installation_command_args: Some(vec!["install".to_string(), "--force".to_string()]),
    uninstallation_command_args: Some(vec!["uninstall".to_string()]),
    run_command_args: vec!["kubectl".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![Asset {
        id: "kubectl-binary".to_string(),
        local_filename_configuration: vec![
            LocalFilenameConfig {
                filename: "kubectl.exe".to_string(),
                os: "windows".to_string(),
            },
            LocalFilenameConfig {
                filename: "kubectl".to_string(),
                os: "linux".to_string(),
            }
        ],
        source: AssetSource::Github,
        path: Some("/usr/local/bin".to_string()),
        executable: true,
        download_configurations: None,
        version: None,
    }]),
};

// Check if filename config matches current OS
let config = LocalFilenameConfig {
    filename: "kubectl".to_string(),
    os: "linux".to_string(),
};
let is_current_os = config.matches_current_os();
```
