Defines data structures for tool installation messages used in the Flamingo MSP platform's agent orchestration system. This module handles serialization and deserialization of tool installation configurations, including download sources, command arguments, and cross-platform asset management.

## Key Components

- **`ToolInstallationMessage`** - Main struct containing tool installation details including agent ID, version, session type, and command arguments
- **`SessionType`** - Enum defining execution contexts (Service, Console, User) for tool installation
- **`Asset`** - Struct representing downloadable assets with platform-specific filename configurations
- **`LocalFilenameConfig`** - Platform-specific filename mapping with OS detection utilities
- **`AssetSource`** - Enum for asset download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use serde_json;

// Create a tool installation message
let installation_msg = ToolInstallationMessage {
    tool_agent_id: "agent-001".to_string(),
    tool_id: "kubectl".to_string(),
    tool_type: "kubernetes-cli".to_string(),
    version: "1.28.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::User),
    download_configurations: None,
    installation_command_args: Some(vec!["install".to_string(), "--force".to_string()]),
    uninstallation_command_args: None,
    run_command_args: vec!["kubectl".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![Asset {
        id: "kubectl-binary".to_string(),
        local_filename_configuration: vec![
            LocalFilenameConfig {
                filename: "kubectl.exe".to_string(),
                os: "windows".to_string(),
            },
            LocalFilenameConfig {
                filename: "kubectl".to_string(),
                os: "linux".to_string(),
            }
        ],
        source: AssetSource::Github,
        path: Some("/usr/local/bin/kubectl".to_string()),
        executable: true,
        download_configurations: None,
        version: Some("1.28.0".to_string()),
    }]),
};

// Serialize to JSON
let json = serde_json::to_string(&installation_msg).unwrap();

// Check if filename config matches current OS
let config = LocalFilenameConfig {
    filename: "tool.exe".to_string(),
    os: "windows".to_string(),
};
let matches = config.matches_current_os(); // true on Windows
```
