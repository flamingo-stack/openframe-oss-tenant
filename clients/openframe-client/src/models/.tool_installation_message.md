Defines the data structures for tool installation messages in the Flamingo platform, providing serializable configuration for deploying and managing tools across different agents and environments.

## Key Components

- **`ToolInstallationMessage`** - Main struct containing all tool installation configuration including agent ID, version, commands, and assets
- **`SessionType`** - Enum defining execution contexts (Service, Console, User) for tool deployment
- **`Asset`** - Represents downloadable resources with platform-specific configurations and source information
- **`LocalFilenameConfig`** - Platform-specific filename mapping with OS detection utilities
- **`AssetSource`** - Enum for different asset download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use tool_installation_message::{ToolInstallationMessage, SessionType, Asset, AssetSource};

// Create a tool installation message
let installation_msg = ToolInstallationMessage {
    tool_agent_id: "agent-001".to_string(),
    tool_id: "monitoring-tool".to_string(),
    tool_type: "system-monitor".to_string(),
    version: "1.2.3".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Service),
    download_configurations: None,
    installation_command_args: Some(vec!["--quiet".to_string()]),
    uninstallation_command_args: Some(vec!["--force".to_string()]),
    run_command_args: vec!["--daemon".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![Asset {
        id: "main-binary".to_string(),
        local_filename_configuration: vec![],
        source: AssetSource::Github,
        path: Some("/usr/local/bin/monitor".to_string()),
        executable: true,
        download_configurations: None,
        version: None,
    }]),
};

// Check OS compatibility
let config = LocalFilenameConfig {
    filename: "monitor.exe".to_string(),
    os: "windows".to_string(),
};
let is_compatible = config.matches_current_os();
```
