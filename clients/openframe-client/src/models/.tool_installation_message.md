Defines data structures for tool installation messages used in Flamingo's MSP platform to manage automated tool deployment and configuration across different operating systems.

## Key Components

- **`ToolInstallationMessage`** - Main struct containing tool installation metadata including agent ID, version, commands, and assets
- **`SessionType`** - Enum defining execution contexts (Service, Console, User)
- **`Asset`** - Struct representing downloadable tool assets with platform-specific configurations
- **`LocalFilenameConfig`** - OS-specific filename mapping with current platform detection
- **`AssetSource`** - Enum for asset download sources (Artifactory, ToolApi, Github)

## Usage Example

```rust
use tool_installation_message::*;

// Create a tool installation message
let install_msg = ToolInstallationMessage {
    tool_agent_id: "agent-123".to_string(),
    tool_id: "monitoring-tool".to_string(),
    tool_type: "system-monitor".to_string(),
    version: "1.2.3".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Service),
    download_configurations: None,
    installation_command_args: Some(vec!["--silent".to_string()]),
    uninstallation_command_args: Some(vec!["--force".to_string()]),
    run_command_args: vec!["start".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![
        Asset {
            id: "main-binary".to_string(),
            local_filename_configuration: vec![
                LocalFilenameConfig {
                    filename: "monitor.exe".to_string(),
                    os: "windows".to_string(),
                },
                LocalFilenameConfig {
                    filename: "monitor".to_string(),
                    os: "linux".to_string(),
                }
            ],
            source: AssetSource::Github,
            path: Some("/usr/local/bin".to_string()),
            executable: true,
            download_configurations: None,
            version: None,
        }
    ]),
};

// Check if filename config matches current OS
let config = LocalFilenameConfig {
    filename: "tool.exe".to_string(),
    os: "windows".to_string(),
};
let is_current_os = config.matches_current_os();
```

The message format uses camelCase JSON serialization and supports conditional field serialization for optional components, making it ideal for cross-platform tool deployment in MSP environments.
