A message structure that defines tool installation requests in the Flamingo platform, containing metadata, configuration options, and associated assets needed to install and run tools on agent systems.

## Key Components

- **`ToolInstallationMessage`** - Main struct containing tool identification, installation parameters, command arguments, and optional assets
- **`SessionType`** - Enum defining execution contexts (Service, Console, User) for tool sessions
- **`Asset`** - Represents downloadable resources with platform-specific filename configurations and source locations
- **`LocalFilenameConfig`** - OS-specific filename mapping with current platform detection capability
- **`AssetSource`** - Enum specifying where assets can be downloaded from (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use tool_installation_message::{ToolInstallationMessage, SessionType, Asset, AssetSource};

// Create a tool installation message
let install_msg = ToolInstallationMessage {
    tool_agent_id: "agent-123".to_string(),
    tool_id: "powershell-core".to_string(),
    tool_type: "runtime".to_string(),
    version: "7.4.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Console),
    download_configurations: None,
    installation_command_args: Some(vec!["--silent".to_string()]),
    uninstallation_command_args: Some(vec!["--uninstall".to_string()]),
    run_command_args: vec!["pwsh".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![
        Asset {
            id: "powershell-binary".to_string(),
            local_filename_configuration: vec![
                LocalFilenameConfig {
                    filename: "pwsh.exe".to_string(),
                    os: "windows".to_string(),
                }
            ],
            source: AssetSource::Github,
            path: Some("/usr/local/bin".to_string()),
            executable: true,
            download_configurations: None,
            version: Some("7.4.0".to_string()),
        }
    ]),
};

// Check if filename config matches current OS
let config = LocalFilenameConfig {
    filename: "pwsh".to_string(),
    os: "linux".to_string(),
};
let is_compatible = config.matches_current_os();
```
