Defines the data structure for tool installation messages in the Flamingo MSP platform, handling the configuration and metadata needed to install, manage, and run tools across different operating systems.

## Key Components

- **`ToolInstallationMessage`** - Main struct containing all tool installation configuration including IDs, commands, and optional assets
- **`SessionType`** - Enum defining execution contexts (Service, Console, User)
- **`Asset`** - Represents downloadable files or resources needed for tool installation
- **`LocalFilenameConfig`** - OS-specific filename configuration with current OS detection
- **`AssetSource`** - Enum for different asset download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use tool_installation_message::*;

// Create a tool installation message
let installation_msg = ToolInstallationMessage {
    tool_agent_id: "agent-123".to_string(),
    tool_id: "my-tool".to_string(),
    tool_type: "utility".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Console),
    download_configurations: None,
    installation_command_args: Some(vec!["install".to_string(), "--silent".to_string()]),
    uninstallation_command_args: Some(vec!["uninstall".to_string()]),
    run_command_args: vec!["run".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![
        Asset {
            id: "main-binary".to_string(),
            local_filename_configuration: vec![
                LocalFilenameConfig {
                    filename: "tool.exe".to_string(),
                    os: "windows".to_string(),
                },
                LocalFilenameConfig {
                    filename: "tool".to_string(),
                    os: "linux".to_string(),
                }
            ],
            source: AssetSource::Github,
            path: Some("/usr/local/bin".to_string()),
            executable: true,
            download_configurations: None,
            version: Some("1.0.0".to_string()),
        }
    ]),
};

// Check if filename config matches current OS
let config = LocalFilenameConfig {
    filename: "tool.exe".to_string(),
    os: "windows".to_string(),
};
let matches = config.matches_current_os();
```
