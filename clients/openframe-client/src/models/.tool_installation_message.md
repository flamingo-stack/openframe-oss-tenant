A serializable data structure that defines tool installation configuration and metadata for the Flamingo MSP platform's automated tool deployment system.

## Key Components

### Main Structures
- **`ToolInstallationMessage`** - Primary message containing tool installation parameters including agent ID, version, commands, and optional download configurations
- **`Asset`** - Represents downloadable tool assets with platform-specific filename configurations and source information
- **`LocalFilenameConfig`** - Platform-specific filename mapping with OS detection utility

### Enumerations
- **`SessionType`** - Execution context types (Service, Console, User) for tool installation sessions
- **`AssetSource`** - Asset download sources (Artifactory, Tool API, GitHub)

### Key Methods
- **`LocalFilenameConfig::matches_current_os()`** - Cross-platform OS detection for selecting appropriate filenames

## Usage Example

```rust
use tool_installation_message::{ToolInstallationMessage, SessionType, Asset, AssetSource};

// Create tool installation message
let installation_msg = ToolInstallationMessage {
    tool_agent_id: "agent-123".to_string(),
    tool_id: "monitoring-tool".to_string(),
    tool_type: "system_monitor".to_string(),
    version: "1.2.3".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Service),
    download_configurations: None,
    installation_command_args: Some(vec!["--quiet".to_string()]),
    uninstallation_command_args: None,
    run_command_args: vec!["--start".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![Asset {
        id: "binary-asset".to_string(),
        local_filename_configuration: vec![/* platform configs */],
        source: AssetSource::Github,
        path: Some("/usr/local/bin/".to_string()),
        executable: true,
        download_configurations: None,
        version: None,
    }]),
};
```

The structure uses camelCase serialization and includes optional fields with conditional serialization to minimize payload size during tool deployment operations.
