Defines the data structures for tool installation messages, representing the payload used to instruct agents on how to install, configure, and run managed tools.

## Key Components

### Structs

- **`ToolInstallationMessage`** — Top-level message describing a tool to be installed or reinstalled, including versioning, command arguments, and optional download configurations.
  - `effective_version()` — Returns the resolved version, applying any local overrides from `tool_version_overrides`.

- **`Asset`** — Represents a downloadable artifact associated with a tool (e.g., binary, config file), with per-asset version override support.
  - `original_version()` — Returns the raw version string or empty string if unset.
  - `effective_version()` — Returns the overridden version if available, falling back to `original_version()`.

- **`LocalFilenameConfig`** — Maps a filename to a target OS string.
  - `matches_current_os()` — Returns `true` if the config's `os` field matches the compile-time target OS (`windows`, `macos`, or `linux`), using case-insensitive comparison.

### Enums

- **`AssetSource`** — Indicates where an asset should be fetched from: `Artifactory`, `ToolApi`, or `Github`.

## Usage Example

```rust
let msg = ToolInstallationMessage {
    tool_agent_id: "agent-123".into(),
    tool_id: "my-tool".into(),
    tool_type: "cli".into(),
    version: "1.2.3".into(),
    reinstall: false,
    download_configurations: None,
    installation_command_args: Some(vec!["--silent".into()]),
    uninstallation_command_args: None,
    run_command_args: vec!["--start".into()],
    tool_agent_id_command_args: None,
    assets: None,
    service_name: None,
};

// Resolves version with any registered overrides
println!("Installing version: {}", msg.effective_version());

// Filter assets matching the current OS
if let Some(assets) = &msg.assets {
    for asset in assets {
        let local_name = asset.local_filename_configuration
            .iter()
            .find(|c| c.matches_current_os())
            .map(|c| c.filename.as_str())
            .unwrap_or("unknown");
        println!("Asset {} -> {}", asset.id, local_name);
    }
}
```
