A Rust data structure for managing tool installation messages within the OpenFrame platform, handling tool deployment configurations and asset management across different operating systems.

## Key Components

- **`ToolInstallationMessage`** - Main message struct containing tool metadata, installation commands, and asset configurations
- **`SessionType`** - Enum defining execution contexts (Service, Console, User)
- **`Asset`** - Struct representing downloadable tool assets with OS-specific configurations
- **`LocalFilenameConfig`** - OS-specific filename mapping with platform detection
- **`AssetSource`** - Enum for different asset download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use tool_installation_message::*;

// Create a tool installation message
let install_msg = ToolInstallationMessage {
    tool_agent_id: "agent-001".to_string(),
    tool_id: "kubectl".to_string(),
    tool_type: "kubernetes-cli".to_string(),
    version: "1.28.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Console),
    download_configurations: None,
    installation_command_args: Some(vec!["install".to_string()]),
    uninstallation_command_args: Some(vec!["uninstall".to_string()]),
    run_command_args: vec!["kubectl".to_string()],
    tool_agent_id_command_args: None,
    assets: Some(vec![
        Asset {
            id: "kubectl-binary".to_string(),
            local_filename_configuration: vec![
                LocalFilenameConfig {
                    filename: "kubectl.exe".to_string(),
                    os: "windows".to_string(),
                },
                LocalFilenameConfig {
                    filename: "kubectl".to_string(),
                    os: "linux".to_string(),
                }
            ],
            source: AssetSource::Github,
            path: Some("/usr/local/bin".to_string()),
            executable: true,
            download_configurations: None,
            version: Some("1.28.0".to_string()),
        }
    ]),
};

// Check if filename config matches current OS
let config = LocalFilenameConfig {
    filename: "kubectl".to_string(),
    os: "linux".to_string(),
};
let is_current_os = config.matches_current_os();
```
