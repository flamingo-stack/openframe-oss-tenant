A serializable data structure that defines tool installation messages for the Flamingo MSP platform, containing tool metadata, execution parameters, and asset configurations for cross-platform deployment.

## Key Components

- **`ToolInstallationMessage`** - Main struct containing tool installation details including ID, type, version, and command arguments
- **`SessionType`** - Enum defining execution contexts (Service, Console, User) for tool deployment
- **`Asset`** - Struct representing downloadable tool assets with platform-specific filename configurations
- **`LocalFilenameConfig`** - Platform-specific filename mapping with OS detection capability
- **`AssetSource`** - Enum specifying asset download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use tool_installation_message::{ToolInstallationMessage, SessionType, Asset, AssetSource};

// Create a tool installation message
let install_msg = ToolInstallationMessage {
    tool_agent_id: "agent-001".to_string(),
    tool_id: "monitoring-tool".to_string(),
    tool_type: "system-monitor".to_string(),
    version: "1.2.3".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Service),
    download_configurations: None,
    installation_command_args: Some(vec!["--install".to_string()]),
    uninstallation_command_args: Some(vec!["--uninstall".to_string()]),
    run_command_args: vec!["--start".to_string()],
    tool_agent_id_command_args: None,
    assets: None,
};

// Check if filename config matches current OS
let filename_config = LocalFilenameConfig {
    filename: "tool.exe".to_string(),
    os: "windows".to_string(),
};
let is_compatible = filename_config.matches_current_os();
```

The structure uses camelCase serialization and includes optional fields with conditional serialization to minimize payload size in API communications.
