Defines message structures for managing tool installations in the Flamingo platform, including configuration for downloads, assets, and platform-specific deployment parameters.

## Key Components

- **`ToolInstallationMessage`** - Main structure containing tool metadata, installation commands, and optional configurations for downloads and assets
- **`SessionType`** - Enum defining execution contexts (Service, Console, User) for tool deployment
- **`Asset`** - Structure for downloadable tool assets with platform-specific filename configurations
- **`LocalFilenameConfig`** - Platform-specific filename mapping with OS detection utility
- **`AssetSource`** - Enum for asset download sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use crate::tool_installation_message::{ToolInstallationMessage, SessionType, Asset};

// Create a tool installation message
let install_msg = ToolInstallationMessage {
    tool_agent_id: "agent-123".to_string(),
    tool_id: "docker".to_string(),
    tool_type: "container-runtime".to_string(),
    version: "24.0.0".to_string(),
    reinstall: false,
    session_type: Some(SessionType::Service),
    download_configurations: None,
    installation_command_args: Some(vec!["--install".to_string()]),
    uninstallation_command_args: Some(vec!["--remove".to_string()]),
    run_command_args: vec!["run".to_string(), "-d".to_string()],
    tool_agent_id_command_args: None,
    assets: None,
};

// Check if filename config matches current OS
let config = LocalFilenameConfig {
    filename: "docker.exe".to_string(),
    os: "windows".to_string(),
};
let matches = config.matches_current_os();
```
