Parses structured log files for the OpenFrame platform, supporting multiple log formats (OpenFrame tracing, Logrus) with incremental reading and deduplication of repeated entries.

## Key Components

**Structs**
- `LogEntry` — A single parsed log line with `level`, `ts` (timestamp), `msg`, and optional `count` for deduplicated entries
- `LogBatchMessage` — A batch payload associating a hostname/tenant with a collection of `LogEntry` values, ready for serialization

**Functions**
- `read_new_logs(path, position, max_count)` — Incrementally reads a log file from a byte offset, handling log rotation (truncation detection), and returns new entries plus the updated stream position
- `parse_log_line(line)` — Dispatches to format-specific parsers; supports OpenFrame tracing format and Logrus `time="..." level=... msg="..."` format (with optional `stdout:` prefix)
- `parse_tracing_format(line)` — Internal parser for ISO 8601 prefixed compact tracing output; validates timestamps via `chrono`

**Trait**
- `LogDeduplicator` — Implemented on `Vec<LogEntry>`; deduplicates consecutive tool-originated log messages by message content, incrementing a `count` field rather than emitting duplicates. Client logs (`openframe::` / `async_nats` prefixed) are always passed through unmodified.

## Usage Example

```rust
use log_parser::{read_new_logs, LogDeduplicator};
use std::path::PathBuf;

// Incrementally tail a log file
let path = PathBuf::from("/var/log/openframe/agent.log");
let (entries, new_position) = read_new_logs(&path, last_position, 500)?;

// Deduplicate repeated tool messages before forwarding
let batch = entries.deduplicate();

for entry in &batch {
    println!("[{}] {} — {}", entry.level, entry.ts, entry.msg);
    if let Some(n) = entry.count {
        println!("  (repeated {} times)", n);
    }
}

// Persist new_position for the next poll cycle
save_position(new_position);
```
