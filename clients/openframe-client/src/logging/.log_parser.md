Parses structured log lines from OpenFrame services, supporting multiple log formats (tracing compact, Logrus) and providing deduplication for repeated tool log entries.

## Key Components

### Structs
- **`LogEntry`** — Represents a single parsed log line with `level`, `ts` (timestamp), `msg`, and an optional `count` for deduplicated entries
- **`LogBatchMessage`** — Wraps a batch of `LogEntry` items with metadata (`machine_id`, `hostname`, `tenant_domain`) for transmission

### Functions
- **`read_new_logs(path, position, max_count)`** — Reads new log lines from a file starting at a byte offset; handles log rotation (truncation) by resetting to offset `0`
- **`parse_log_line(line)`** — Dispatches to format-specific parsers; supports OpenFrame tracing format and Logrus `time=`/`level=`/`msg=` format (with optional `stdout:` prefix)
- **`parse_tracing_format(line)`** *(private)* — Parses ISO 8601-prefixed compact tracing lines, validated with `chrono`

### Trait
- **`LogDeduplicator`** — Implemented on `Vec<LogEntry>`; collapses consecutive duplicate tool log messages into a single entry with an incremented `count`, while preserving all client-originated logs (prefixed `openframe::` or `async_nats`)

## Usage Example

```rust
use log_parser::{read_new_logs, LogDeduplicator};
use std::path::PathBuf;

// Read up to 100 new log lines from a file, resuming at a saved byte offset
let path = PathBuf::from("/var/log/openframe/agent.log");
let (entries, new_position) = read_new_logs(&path, last_position, 100)?;

// Deduplicate repeated tool messages before forwarding
let deduplicated = entries.deduplicate();

for entry in &deduplicated {
    println!("[{}] {} - {}", entry.level, entry.ts, entry.msg);
    if let Some(n) = entry.count {
        println!("  (repeated {} times)", n);
    }
}
```
