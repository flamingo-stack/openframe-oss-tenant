Parses and deduplicates log entries from OpenFrame log files, supporting multiple log formats (tracing compact, logrus) with incremental file reading and position tracking.

## Key Components

### Structs
- **`LogEntry`** — Represents a single parsed log entry with `level`, `ts` (timestamp), `msg`, and optional `count` for deduplicated occurrences
- **`LogBatchMessage`** — Wraps a batch of `LogEntry` items with host metadata (`machine_id`, `hostname`, `tenant_domain`) for transport

### Functions
- **`read_new_logs(path, position, max_count)`** — Reads new log lines from a file starting at a byte offset; handles log rotation (file truncation) by resetting to position `0`
- **`parse_log_line(line)`** — Dispatches to format-specific parsers; handles `stdout:` prefixes and logrus-style (`time="..." level=... msg="..."`) entries
- **`parse_tracing_format(line)`** — Parses OpenFrame's compact tracing format (ISO 8601 timestamp + level + message)

### Trait
- **`LogDeduplicator`** — Implemented on `Vec<LogEntry>`; collapses consecutive duplicate tool logs into a single entry with an incremented `count`, while leaving client-originating logs (prefixed `openframe::` or `async_nats`) unaffected

## Usage Example

```rust
use log_parser::{read_new_logs, LogDeduplicator};
use std::path::PathBuf;

// Read up to 100 new log entries since last known position
let path = PathBuf::from("/var/log/openframe/agent.log");
let (entries, new_position) = read_new_logs(&path, last_position, 100)?;

// Deduplicate repeated tool-level messages
let deduplicated = entries.deduplicate();

for entry in &deduplicated {
    println!("[{}] {} - {}", entry.level, entry.ts, entry.msg);
    if let Some(n) = entry.count {
        println!("  (repeated {} times)", n);
    }
}

// Persist new_position for the next polling cycle
save_position(new_position);
```
