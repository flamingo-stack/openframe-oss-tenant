Parses structured log files from OpenFrame services, supporting multiple log formats (tracing compact, Logrus) and providing deduplication for repeated tool-generated log entries.

## Key Components

- **`LogEntry`** — Serializable struct representing a single log entry with `level`, `ts` (timestamp), `msg`, and optional `count` for deduplicated occurrences.
- **`LogBatchMessage`** — Serializable batch wrapper containing log entries alongside host metadata (`hostname`, `tenant_domain`, optional `machine_id`).
- **`read_new_logs`** — Reads new log lines from a file starting at a given byte offset, handles file rotation (truncation), and returns parsed entries with the new stream position.
- **`parse_log_line`** — Dispatches line parsing across supported formats: OpenFrame tracing compact (ISO 8601 + level + message) and Logrus key-value format (`time=` / `level=` / `msg=`), with optional `stdout:` prefix stripping.
- **`LogDeduplicator` trait** — Implemented on `Vec<LogEntry>`, deduplicates consecutive identical tool/non-client log messages using an `IndexMap` while preserving all client-originated entries (prefixed `openframe::` or `async_nats`).

## Usage Example

```rust
use log_parser::{read_new_logs, parse_log_line, LogDeduplicator};
use std::path::PathBuf;

// Incrementally read up to 100 new log entries from a file
let path = PathBuf::from("/var/log/openframe/agent.log");
let (entries, new_position) = read_new_logs(&path, last_position, 100)?;

// Deduplicate repeated tool log noise before forwarding
let clean_entries = entries.deduplicate();

// Parse a single line directly
if let Some(entry) = parse_log_line("2026-03-18T15:44:15.099267Z  INFO openframe::core: ready") {
    println!("{}: {}", entry.level, entry.msg); // INFO: openframe::core: ready
}
```
