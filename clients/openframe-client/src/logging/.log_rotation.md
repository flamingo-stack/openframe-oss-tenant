Manages log file rotation with gzip compression for the OpenFrame log pipeline, triggering archival when all buffered log entries have been streamed and the file exceeds a size threshold.

## Key Components

**`LogRotationManager`** — Core struct managing rotation state via two tracked paths:
- `log_file_path` — active log file being monitored
- `offset_file_path` — persisted read offset for stream continuity

**Constants**
- `MAX_LOG_FILE_SIZE` — 10 MB rotation threshold
- `ARCHIVED_LOG_NAME` — fixed archive filename (`openframe.log.gz`)

**Methods**
| Method | Description |
|---|---|
| `new(log_file_path, offset_file_path)` | Constructs a new manager instance |
| `rotate_if_ready(current_offset)` | Triggers rotation when offset ≥ file size and size ≥ 10 MB |
| `load_offset()` | Reads persisted byte offset from disk, defaults to `0` |
| `save_offset(offset)` | Writes current byte offset to the offset file |
| `rotate()` (private) | Compresses log to `.gz`, removes prior archive, truncates source file |

## Usage Example

```rust
use std::path::PathBuf;
use log_rotation::LogRotationManager;

let manager = LogRotationManager::new(
    PathBuf::from("/var/log/openframe/openframe.log"),
    PathBuf::from("/var/log/openframe/.log_offset"),
);

// Restore streaming position across restarts
let mut offset = manager.load_offset();

// Called in your log-streaming loop after processing new entries
manager.rotate_if_ready(&mut offset);

// Persist updated offset after each read batch
manager.save_offset(offset);
```

> **Rotation behavior:** The file is only rotated once all bytes up to the current file size have been streamed (`current_offset >= file_size`), preventing data loss mid-stream. The prior `.gz` archive is replaced on each rotation cycle.
