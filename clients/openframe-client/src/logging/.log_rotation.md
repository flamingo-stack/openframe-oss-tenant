Manages log file rotation with gzip compression for the OpenFrame log pipeline, rotating the active log file once all entries have been streamed and the file exceeds a 10 MB size threshold.

## Key Components

**`LogRotationManager`** — Core struct managing rotation state via two paths:
- `log_file_path` — Path to the active log file being monitored
- `offset_file_path` — Path to the offset tracking file (persists read position across restarts)

**Constants:**
- `MAX_LOG_FILE_SIZE` — 10 MB rotation trigger threshold
- `ARCHIVED_LOG_NAME` — Fixed archive output name (`openframe.log.gz`)

**Public Methods:**
| Method | Description |
|--------|-------------|
| `new(log_file_path, offset_file_path)` | Constructs a new manager instance |
| `rotate_if_ready(&self, current_offset)` | Triggers rotation if offset ≥ file size and file ≥ 10 MB |
| `load_offset(&self) → u64` | Reads persisted byte offset from disk, defaults to `0` |
| `save_offset(&self, offset)` | Writes current byte offset to disk |

**Private Methods:**
- `rotate()` — Compresses the active log to `openframe.log.gz` via `GzEncoder`, then truncates the original file

## Usage Example

```rust
use std::path::PathBuf;

let manager = LogRotationManager::new(
    PathBuf::from("/var/log/openframe/openframe.log"),
    PathBuf::from("/var/log/openframe/.log_offset"),
);

// On startup, resume from last known position
let mut offset = manager.load_offset();

// After streaming a batch of log lines, advance offset and check rotation
offset += bytes_read;
manager.save_offset(offset);
manager.rotate_if_ready(&mut offset);
```

> **Note:** Rotation only triggers when `current_offset >= file_size` — ensuring no log lines are lost mid-stream before the file is compressed and truncated.
