Manages log file rotation for the OpenFrame tenant agent, compressing oversized log files into a gzip archive once all log entries have been streamed.

## Key Components

### `LogRotationManager`
Primary struct responsible for tracking log file state and triggering rotation.

| Member | Type | Description |
|---|---|---|
| `log_file_path` | `PathBuf` | Path to the active log file |
| `offset_file_path` | `PathBuf` | Path to the file storing the current read offset |

### Constants

| Constant | Value | Description |
|---|---|---|
| `MAX_LOG_FILE_SIZE` | 10 MB | Minimum file size threshold to trigger rotation |
| `ARCHIVED_LOG_NAME` | `openframe.log.gz` | Fixed name for the compressed archive |

### Methods

- **`new`** — Constructs a `LogRotationManager` with the given log and offset file paths.
- **`rotate_if_ready`** — Checks if the current offset has caught up to the file size and the file exceeds `MAX_LOG_FILE_SIZE`; triggers rotation if both conditions are met and resets the offset to `0`.
- **`load_offset`** — Reads the persisted byte offset from disk, defaulting to `0` on failure.
- **`save_offset`** — Persists the current byte offset to disk.
- **`rotate`** *(private)* — Compresses the active log file into `openframe.log.gz` using gzip, replaces any existing archive, then truncates the original log file.

## Usage Example

```rust
use std::path::PathBuf;
use crate::log_rotation::LogRotationManager;

let manager = LogRotationManager::new(
    PathBuf::from("/var/log/openframe/openframe.log"),
    PathBuf::from("/var/log/openframe/openframe.offset"),
);

// Restore previous streaming position
let mut offset = manager.load_offset();

// After streaming a batch of log lines, update and persist the offset
offset += bytes_read;
manager.save_offset(offset);

// Rotate once all logs are consumed and file is large enough
manager.rotate_if_ready(&mut offset);
```

> **Note:** Rotation only triggers when `current_offset >= file_size` AND `file_size >= 10 MB`, ensuring in-flight log entries are never lost mid-stream. The previous archive (`openframe.log.gz`) is always replaced on each rotation cycle.
