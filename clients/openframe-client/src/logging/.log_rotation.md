Manages log file rotation with gzip compression for the OpenFrame log streaming pipeline. Rotates logs only when all entries have been streamed and the file exceeds the configured size limit.

## Key Components

- **`LogRotationManager`** — Core struct managing rotation state via configurable log and offset file paths
- **`rotate_if_ready(current_offset)`** — Triggers rotation when the current read offset has reached the end of the file and the file exceeds `MAX_LOG_FILE_SIZE` (10 MB); resets offset to `0` on success
- **`load_offset()` / `save_offset()`** — Persists the current read position to disk for crash-safe resumption
- **`rotate()`** — Private method that gzip-compresses the current log into `openframe.log.gz` (replacing any prior archive), then truncates the original log file

## Usage Example

```rust
use std::path::PathBuf;
use log_rotation::LogRotationManager;

let manager = LogRotationManager::new(
    PathBuf::from("/var/log/openframe/openframe.log"),
    PathBuf::from("/var/log/openframe/openframe.offset"),
);

// Resume from last known position
let mut offset = manager.load_offset();

// After streaming a batch of log lines, update and persist offset
offset += bytes_read;
manager.save_offset(offset);

// Rotate if all logs consumed and file is large enough
manager.rotate_if_ready(&mut offset);
```

> **Note:** Rotation is intentionally conservative — it only triggers when `current_offset >= file_size`, ensuring no log entries are lost mid-stream before archiving.
