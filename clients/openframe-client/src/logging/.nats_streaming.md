Manages NATS JetStream log streaming for the OpenFrame agent, handling connection lifecycle, batched log publishing, and multi-source log discovery over WebSocket transport.

## Key Components

### `NatsLogConnection`
Wraps an `async_nats` JetStream context with WebSocket connectivity. Handles authentication via custom headers (`x-tenant-domain`, `x-initial-key`, `x-machine-id`), automatic reconnection with configurable delay, and publishes serialized `LogBatchMessage` payloads to the `agents.logs` subject with acknowledgment confirmation.

### `LogStreamingRunManager`
Orchestrates the full log streaming lifecycle. Resolves server host, tenant domain, and hostname at construction time, then on `start()`:
- Waits for an initial authentication key before connecting
- Builds a `LogSourceRegistry` seeded with the primary `openframe.log` source
- Spawns source discovery and delegates to `log_streaming_loop`

### `spawn_source_discovery` / `create_meshcentral_source`
Background task that polls every 30 seconds for a Meshcentral installation. When found, constructs a `FileLogSource` for its log file and sends it over an `mpsc` channel to the streaming loop for dynamic registration.

### `log_streaming_loop`
Core event loop ticking every 60 seconds. Drains newly discovered sources into the registry, reads up to 50 log entries, publishes a `LogBatchMessage`, then either commits or rolls back all source read positions based on publish success. Manages log rotation via `LogRotationManager`.

## Usage Example

```rust
let manager = LogStreamingRunManager::new(
    &initial_config_service,
    &agent_config_service,
    &installed_tools_service,
    &directory_manager,
)?;

// Spawns background task; returns immediately
manager.start().await?;
```

## Configuration Constants

| Constant | Value | Purpose |
|---|---|---|
| `BATCH_INTERVAL_SECS` | 60 | Publish cadence |
| `MAX_LOGS_PER_BATCH` | 50 | Per-tick log cap |
| `RECONNECT_DELAY_SECS` | 5 | Retry backoff |
| `SOURCE_DISCOVERY_INTERVAL_SECS` | 30 | Meshcentral poll rate |
