Manages NATS JetStream log streaming for the OpenFrame agent, handling connection lifecycle, log batch publishing, and multi-source log discovery over WebSocket.

## Key Components

### `NatsLogConnection`
Wraps an `async_nats` JetStream context with tenant-aware authentication headers. Handles WebSocket connection setup with automatic reconnection and publishes serialized `LogBatchMessage` batches to the `agents.logs` subject.

### `LogStreamingRunManager`
Orchestrates the full log streaming lifecycle. Waits for an initial authentication key, establishes the NATS connection, registers the primary OpenFrame log source, and spawns background tasks for source discovery and the main streaming loop.

### `log_streaming_loop`
Core async loop (60-second tick) that reads up to 50 log entries from all registered sources, builds a `LogBatchMessage`, publishes it, and commits or rolls back source offsets based on publish success.

### `spawn_source_discovery`
Background task that polls every 30 seconds for Meshcentral installation and dynamically registers its log source into the registry when found.

### `extract_tenant_domain`
Strips the `api.` prefix from the server host to derive the tenant domain.

## Usage Example

```rust
let manager = LogStreamingRunManager::new(
    &initial_config_service,
    &agent_config_service,
    &installed_tools_service,
    &directory_manager,
)?;

// Spawns background task: waits for auth key,
// connects to NATS, and begins streaming logs
manager.start().await?;
```

## Constants

| Constant | Value | Purpose |
|----------|-------|---------|
| `BATCH_INTERVAL_SECS` | `60` | Seconds between log flush cycles |
| `MAX_LOGS_PER_BATCH` | `50` | Max log entries per publish |
| `RECONNECT_DELAY_SECS` | `5` | Delay between NATS reconnect attempts |
| `SOURCE_DISCOVERY_INTERVAL_SECS` | `30` | Polling interval for new log sources |
