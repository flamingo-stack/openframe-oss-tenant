Manages NATS JetStream log streaming for the OpenFrame agent, handling connection lifecycle, log batching, and multi-source log discovery with automatic retry and offset tracking.

## Key Components

### `NatsLogConnection`
Wraps an `async_nats` JetStream context with WebSocket transport. Handles:
- Authenticated connection via custom headers (`x-tenant-domain`, `x-initial-key`, `x-machine-id`)
- Automatic reconnect with configurable delay
- Publishes `LogBatchMessage` payloads to the `agents.logs` subject with ACK confirmation

### `LogStreamingRunManager`
Orchestrates the full log streaming pipeline. Responsibilities:
- Waits for a valid initial key before connecting
- Builds the initial `LogSourceRegistry` (OpenFrame agent log)
- Spawns source discovery for dynamically installed tools (e.g., Meshcentral)
- Delegates to `log_streaming_loop` for continuous batched publishing

### `log_streaming_loop`
Core async loop that ticks every 60 seconds:
- Drains newly discovered log sources from an `mpsc` channel
- Reads up to 50 log entries across all registered sources
- Commits or rolls back source offsets based on publish success
- Rotates log files when thresholds are met

### `spawn_source_discovery`
Background task that polls every 30 seconds for newly installed tools (currently Meshcentral) and sends discovered `LogSource` instances to the streaming loop via channel.

## Usage Example

```rust
let manager = LogStreamingRunManager::new(
    &initial_config_service,
    &agent_config_service,
    &installed_tools_service,
    &directory_manager,
)?;

// Spawns background task: waits for key → connects → streams logs
manager.start().await?;
```

**Key constants:**

| Constant | Value |
|---|---|
| `BATCH_INTERVAL_SECS` | 60s |
| `MAX_LOGS_PER_BATCH` | 50 |
| `RECONNECT_DELAY_SECS` | 5s |
| `SOURCE_DISCOVERY_INTERVAL_SECS` | 30s |
