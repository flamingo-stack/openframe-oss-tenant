Manages log file reading with offset tracking and a multi-source registry for aggregating log entries across different OpenFrame and MeshCentral log files.

## Key Components

| Item | Kind | Description |
|------|------|-------------|
| `LogSourceKind` | Enum | Identifies log origin — `Openframe` or `Meshcentral` |
| `LogSource` | Trait | Core interface: `read`, `commit`, `rollback`, `name` |
| `FileLogSource` | Struct | File-backed `LogSource` with persistent byte-offset tracking |
| `LogSourceRegistry` | Struct | Aggregates multiple `LogSource` instances; distributes read quotas fairly across active sources |
| `read_log_file` | fn | Seeks to a stored byte offset, reads up to `max_count` parsed entries |
| `load_offset` / `save_offset` | fn | Persists read progress to a sidecar file |

## Usage Example

```rust
use std::path::PathBuf;
use crate::log_source::{FileLogSource, LogSourceKind, LogSourceRegistry};

// Create two file-backed sources
let openframe_source = FileLogSource::new(
    LogSourceKind::Openframe,
    PathBuf::from("/var/log/openframe/app.log"),
    PathBuf::from("/var/run/openframe.offset"),
);
let mesh_source = FileLogSource::new(
    LogSourceKind::Meshcentral,
    PathBuf::from("/var/log/meshcentral-agent/agent.log"),
    PathBuf::from("/var/run/meshcentral.offset"),
);

// Register and read up to 200 entries across both sources
let mut registry = LogSourceRegistry::new();
registry.register(Box::new(openframe_source));
registry.register(Box::new(mesh_source));

let entries = registry.read_all(200);

if entries.is_empty() {
    registry.rollback_all();
} else {
    // Process entries...
    registry.commit_all(); // persists offsets so re-reads are skipped
}
```

## Offset Lifecycle

Read progress is checkpointed as a raw byte position in a sidecar file. `commit_all` flushes offsets to disk; `rollback_all` resets in-memory state to the last committed position, allowing safe retry on downstream failure.
