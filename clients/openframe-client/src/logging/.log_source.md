Manages log source abstraction and registry for reading, tracking, and deduplicating log entries from file-based sources across multiple OpenFrame components.

## Key Components

**`LogSourceKind`** — Enum identifying supported log sources (`Openframe`, `Meshcentral`), implements `Display` for string labels used in offset tracking and naming.

**`LogSource` (trait)** — Core abstraction for log providers with four methods:
- `name()` — source identifier
- `read(max_count)` — fetch up to N new entries since last commit
- `commit()` — persist read progress
- `rollback()` — revert to last committed position

**`FileLogSource`** — Concrete `LogSource` implementation backed by a file path. Maintains a byte-offset cursor persisted to disk, enabling resumable reads across restarts. Supports atomic commit/rollback semantics.

**`LogSourceRegistry`** — Aggregates multiple `LogSource` instances. `read_all(max_total)` round-robins quota allocation across active sources until the cap is reached or all sources are exhausted, then deduplicates the merged result. `commit_all()` / `rollback_all()` propagate state transitions to every registered source.

## Usage Example

```rust
use std::path::PathBuf;

let log_path = PathBuf::from("/var/log/openframe/app.log");
let offset_path = PathBuf::from("/var/lib/flamingo/openframe.offset");

let source = FileLogSource::new(
    LogSourceKind::Openframe,
    log_path,
    offset_path,
);

let mut registry = LogSourceRegistry::new();
registry.register(Box::new(source));

// Read up to 200 log entries across all sources
let entries = registry.read_all(200);

if entries.is_empty() {
    registry.rollback_all();
} else {
    // process entries...
    registry.commit_all();
}
```
