Manages log source abstraction and registration for reading structured log entries from files, supporting offset-based tracking, commit/rollback semantics, and multi-source fan-out reads.

## Key Components

### `LogSourceKind` (enum)
Identifies the origin of a log source — `Openframe` or `Meshcentral` — and implements `Display` for use as a human-readable source name.

### `LogSource` (trait)
Core interface for all log sources. Requires `Send + Sync` and exposes:
- `name()` — source identifier
- `read(max_count)` — fetch up to N new log entries
- `commit()` — persist the current read offset
- `rollback()` — revert to the last committed offset

### `FileLogSource` (struct)
Implements `LogSource` for on-disk log files. Tracks a committed and pending byte offset to support transactional read semantics. Offset state is persisted to a sidecar file.

### `LogSourceRegistry` (struct)
Aggregates multiple `LogSource` instances and coordinates fan-out reads. Key methods:
- `register(source)` — add a source to the registry
- `read_all(max_total)` — distribute reads fairly across all active sources and return deduplicated `LogEntry` results
- `commit_all()` / `rollback_all()` — propagate commit or rollback to all registered sources

## Usage Example

```rust
let log_path = PathBuf::from("/var/log/openframe/openframe.log");
let offset_path = PathBuf::from("/var/lib/openframe/openframe.offset");

let source = FileLogSource::new(LogSourceKind::Openframe, log_path, offset_path);

let mut registry = LogSourceRegistry::new();
registry.register(Box::new(source));

let entries = registry.read_all(500);

if entries.is_empty() {
    registry.rollback_all();
} else {
    // process entries...
    registry.commit_all();
}
```
