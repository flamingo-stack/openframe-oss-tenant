Manages log file reading with offset tracking and multi-source aggregation for the OpenFrame log pipeline.

## Key Components

### `LogSourceKind` (enum)
Identifies the log source type — `Openframe` or `Meshcentral`. Implements `Display` for use as human-readable source names.

### `LogSource` (trait)
Core abstraction for any log provider. Requires:
- `read(max_count)` — fetch up to N new `LogEntry` items
- `commit()` — persist the current read offset
- `rollback()` — revert to the last committed offset

### `FileLogSource`
File-backed implementation of `LogSource`. Tracks byte offsets into a log file, persisting them to a separate offset file for crash-safe resumption. Handles log rotation by resetting to position 0 if the file shrinks.

### `LogSourceRegistry`
Manages a collection of `LogSource` instances and provides:
- `register(source)` — add a source
- `read_all(max_total)` — round-robin read across all sources up to a global cap, with deduplication via `LogDeduplicator`
- `commit_all()` / `rollback_all()` — bulk offset management

## Usage Example

```rust
use std::path::PathBuf;

let log_path = PathBuf::from("/var/log/openframe/openframe.log");
let offset_path = PathBuf::from("/var/lib/openframe/offsets/openframe.offset");

let source = FileLogSource::new(LogSourceKind::Openframe, log_path, offset_path);

let mut registry = LogSourceRegistry::new();
registry.register(Box::new(source));

let entries = registry.read_all(500);
if entries.is_empty() {
    registry.rollback_all();
} else {
    // process entries...
    registry.commit_all();
}
```
