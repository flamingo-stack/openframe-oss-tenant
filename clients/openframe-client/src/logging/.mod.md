Cross-platform logging initialization module for the OpenFrame agent, providing structured log output (text or JSON), log rotation, metrics collection, and fallback manual logging capabilities.

## Key Components

- **`init()`** — Primary entry point to initialize the tracing subscriber with file + stdout output
- **`init_file_only()`** — Initializes logging to file only (suppresses stdout), useful for daemon/service contexts
- **`manual_log()`** — Fallback direct-write logger used when the tracing system is unavailable
- **`JsonLayer`** — Custom `tracing_subscriber::Layer` that serializes events to structured JSON, updates metrics counters, and writes to stdout/stderr based on log level
- **`JsonVisitor`** — Field visitor that extracts `message`, `error`, and arbitrary key-value fields from tracing events
- **`LogEntry`** — Serde-serializable struct capturing full log context (timestamp, level, target, file, line, thread, message)
- **`LOG_FILE`** / **`LOG_GUARD`** — `OnceLock` globals holding the fallback file handle and non-blocking writer guard respectively
- **Submodules:** `log_parser`, `log_rotation`, `log_source`, `metrics`, `nats_streaming`, `shipping`

## Usage Example

```rust
use openframe_agent::logging;

fn main() -> std::io::Result<()> {
    // Standard init: logs to file + stdout
    logging::init(
        Some("https://logs.example.com".to_string()),
        Some("agent-abc123".to_string()),
    )?;

    tracing::info!("Agent started");
    tracing::warn!(component = "scheduler", "Task queue is backed up");

    // Fallback when tracing is unavailable
    logging::manual_log("ERROR", "Critical failure during startup");

    Ok(())
}
```

> Set `OPENFRAME_LOG_FORMAT=json` for structured JSON output (default: compact text one-liners).
> Set `OPENFRAME_DEV_MODE` to use user-writable log paths instead of system directories.
