Cross-platform logging initialization module for the OpenFrame agent. Provides structured log output (text or JSON), file-based persistence, metrics collection, and fallback manual logging.

## Key Components

| Component | Description |
|---|---|
| `init()` | Primary entry point — initializes the tracing subscriber with file output, env filter, and metrics |
| `init_file_only()` | Variant of `init()` that suppresses stdout output (used for daemon/service contexts) |
| `manual_log()` | Fallback logger writing directly to the log file when the tracing stack is unavailable |
| `JsonLayer` | Custom `tracing_subscriber::Layer` that serializes events to structured JSON with span context merging |
| `JsonVisitor` | Field visitor that extracts `message`, `error`, and arbitrary key-value fields from tracing events |
| `LogEntry` | Serializable struct capturing full log metadata: timestamp, level, target, file/line, thread, and context |
| `LOG_FILE` / `LOG_GUARD` | `OnceLock`-guarded globals holding the raw file handle and the non-blocking writer guard |
| `METRICS_STORE` | Global metrics store populated during `init_inner()`, accessible after initialization |

**Sub-modules:** `log_parser`, `log_rotation`, `log_source`, `metrics`, `nats_streaming`, `shipping`

## Usage Example

```rust
// Standard initialization (text format by default)
openframe_logging::init(
    Some("http://logs.example.com".to_string()),
    Some("agent-42".to_string()),
)?;

// Use structured JSON output
// Set OPENFRAME_LOG_FORMAT=json before calling init()
std::env::set_var("OPENFRAME_LOG_FORMAT", "json");
openframe_logging::init(None, None)?;

// Use file-only logging (e.g., inside a LaunchDaemon)
openframe_logging::init_file_only(None, Some("agent-42".to_string()))?;

// Emergency fallback when tracing is unavailable
openframe_logging::manual_log("ERROR", "Tracing not yet initialized");

// Emit logs normally via tracing macros after init
tracing::info!(tool_id = "tool-1", "Processing request");
tracing::error!(error = "timeout", "Request failed");
```

## Configuration

| Environment Variable | Default | Description |
|---|---|---|
| `OPENFRAME_LOG_FORMAT` | `text` | Set to `json` for structured JSON output |
| `OPENFRAME_DEV_MODE` | _(unset)_ | Uses user-scoped log directory to avoid permission issues |
| `RUST_LOG` | `info,async_nats=warn` | Standard `EnvFilter` directive |
