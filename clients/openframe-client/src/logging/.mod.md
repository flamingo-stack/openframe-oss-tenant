Cross-platform logging system initializer for the Flamingo/OpenFrame agent. Handles log file setup, format selection (text or JSON), non-blocking file writers, metrics integration, and fallback manual logging.

## Key Components

- **`init(log_endpoint, agent_id)`** — Primary entry point; initializes the global tracing subscriber with env-filter, metrics, and selected output format. Call once early in the application lifecycle.
- **`init_file_only(log_endpoint, agent_id)`** — Variant of `init` that suppresses stdout output; suitable for daemon/service contexts.
- **`manual_log(level, message)`** — Fallback direct-write logger used when the tracing subscriber is unavailable. Writes to both the global log file and stdout.
- **`JsonLayer`** — Custom `tracing_subscriber::Layer` that serializes log events to structured JSON, increments per-level metrics counters, and writes to both file and stdout/stderr.
- **`JsonVisitor`** — Field visitor that extracts `message`, `error`, and arbitrary key-value fields from tracing events into a `serde_json::Map`.
- **`LogEntry`** — Serializable struct representing a single structured log record (timestamp, level, target, file, line, thread, message, error, context).
- **Submodules** — `log_parser`, `log_rotation`, `log_source`, `metrics`, `nats_streaming`, `shipping`.

## Usage Example

```rust
use crate::logging;

fn main() -> std::io::Result<()> {
    // Standard init: logs to file + stdout in compact text format
    logging::init(None, Some("agent-001".to_string()))?;

    tracing::info!("Agent started");
    tracing::warn!("Low disk space detected");

    // Fallback when tracing subscriber may not be set up
    logging::manual_log("ERROR", "Critical failure in subsystem");

    Ok(())
}
```

**Format selection** is controlled via environment variable:

```bash
# Default: compact single-line text
OPENFRAME_LOG_FORMAT=text ./openframe-agent

# Structured JSON output
OPENFRAME_LOG_FORMAT=json ./openframe-agent

# Development mode: writes to user log dir (avoids permission issues)
OPENFRAME_DEV_MODE=1 ./openframe-agent
```
