Cross-platform logging system initialization and configuration module for the OpenFrame agent. Provides structured log output (text or JSON), metrics collection, log rotation, and optional log shipping.

## Key Components

| Component | Description |
|-----------|-------------|
| `init(log_endpoint, agent_id)` | Main entry point; initializes the global tracing subscriber, log file, format, and metrics layer |
| `JsonLayer` | Custom `tracing_subscriber::Layer` that writes structured JSON log entries to file and stdout/stderr |
| `JsonVisitor` | Implements `tracing::field::Visit` to extract field values from tracing events into JSON |
| `LogEntry` | Serializable struct representing a single structured log record with metadata |
| `manual_log(level, message)` | Fallback direct-write logger used when the tracing subscriber is unavailable |
| `metrics` | Submodule providing `MetricsLayer`, `MetricsStore`, and `MetricValue` for counter-based log metrics |
| `log_rotation` | Submodule handling automatic log file rotation and GZ compression |
| `shipping` | Submodule providing `LogShipper` for forwarding logs to a remote endpoint |
| `LOG_FILE` / `LOG_GUARD` | `OnceLock` globals preserving the raw file handle and non-blocking writer guard |

## Usage Example

```rust
// Standard initialization (text format, no remote shipping)
logging::init(None, None)?;

// JSON format with remote shipping
// Set OPENFRAME_LOG_FORMAT=json before calling init
logging::init(
    Some("https://logs.example.com/ingest".to_string()),
    Some("agent-abc123".to_string()),
)?;

// Fallback manual log when tracing subscriber is unavailable
logging::manual_log("WARN", "Tracing unavailable, writing directly");
```

> **Format selection:** Set `OPENFRAME_LOG_FORMAT=json` for structured JSON output. Defaults to compact single-line text. Set `OPENFRAME_DEV_MODE` to use user-space log directories instead of system paths.
