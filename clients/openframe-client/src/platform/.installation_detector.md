Detects whether a supported tool is already installed on the host system by inspecting platform-specific service registries.

## Key Components

**`detect_actual_installation`**
Public entry point that dispatches detection logic based on the tool's `InstallationType`. Currently only `Service` type performs active detection; `GuiApp` and `Standard` return `None`.

**`detect_service`** *(private)*
Platform-conditional service detection:
- **macOS** — checks for a `.plist` file under `/Library/LaunchDaemons/`
- **Windows** — runs `sc query <service_name>` and inspects the exit status
- **Other Unix** — no-op, returns `None`

On a positive match, resolves the expected executable path via `DirectoryManager` and returns an `Installation::Service` variant.

## Usage Example

```rust
let directory_manager = DirectoryManager::new();
let config = DownloadConfiguration {
    installation_type: InstallationType::Service,
    service_name: Some("com.example.mytool".to_string()),
    target_file_name: "mytool".to_string(),
    ..Default::default()
};

if let Some(installation) = detect_actual_installation("mytool", &config, &directory_manager) {
    match installation {
        Installation::Service { service_name, executable_path } => {
            println!("Found service '{}' at {:?}", service_name, executable_path);
        }
        _ => {}
    }
}
```

> **Note:** Linux/non-macOS Unix targets currently return `None` unconditionally. Service detection on those platforms is not yet implemented.
