Detects whether a tool is already installed on the host system by inspecting platform-specific service registries, returning a structured `Installation` value if found.

## Key Components

### `detect_actual_installation`
Public entry point that dispatches detection logic based on the `InstallationType` from a `DownloadConfiguration`:
- **`Service`** → delegates to `detect_service`
- **`GuiApp`** / **`Standard`** → returns `None` (not yet implemented)

### `detect_service` (private)
Platform-conditional service detection using `config.service_name`:

| Platform | Detection Method |
|----------|-----------------|
| **macOS** | Checks for `/Library/LaunchDaemons/<service_name>.plist` |
| **Windows** | Runs `sc query <service_name>` and checks exit status |
| **Linux/Other Unix** | No-op, returns `None` |

On a successful detection, resolves the executable path via `DirectoryManager::get_tool_executable_path` and returns an `Installation::Service` variant.

## Usage Example

```rust
let config = DownloadConfiguration {
    installation_type: InstallationType::Service,
    service_name: Some("my-agent".to_string()),
    target_file_name: "my-agent".to_string(),
    // ...
};

let directory_manager = DirectoryManager::new();

if let Some(installation) = detect_actual_installation("my-agent", &config, &directory_manager) {
    match installation {
        Installation::Service { service_name, executable_path } => {
            println!("Already installed: {} at {:?}", service_name, executable_path);
        }
        _ => {}
    }
}
```
