Detects whether a tool is already installed on the host system by inspecting platform-specific service registration points.

## Key Components

### `detect_actual_installation`
Public entry point that dispatches detection logic based on `InstallationType`. Currently returns `Some(Installation)` only for `Service` variants; `GuiApp` and `Standard` types always return `None`.

### `detect_service` (private)
Platform-conditional service detection:

| Platform | Detection Method |
|---|---|
| macOS | Checks for `.plist` file in `/Library/LaunchDaemons/` |
| Windows | Calls `crate::platform::system_service::service_exists()` |
| Other Unix | No-op (returns `None`) |

On a positive match, resolves the executable path via `DirectoryManager::get_tool_executable_path` and returns an `Installation::Service` variant.

## Usage Example

```rust
let dir_manager = DirectoryManager::new();
let config = DownloadConfiguration {
    installation_type: InstallationType::Service,
    service_name: Some("com.example.mytool".to_string()),
    target_file_name: "mytool".to_string(),
    // ...
};

if let Some(installation) = detect_actual_installation("mytool", &config, &dir_manager) {
    println!("Already installed: {:?}", installation);
} else {
    println!("Not installed — proceeding with fresh install");
}
```

## Notes

- Detection is **read-only** — no installation or mutation occurs
- Non-`Service` installation types (`GuiApp`, `Standard`) are stubs; detection for those types is not yet implemented
- On non-macOS Unix targets, the service check is explicitly a no-op (`let _ = ...`) to suppress unused variable warnings
