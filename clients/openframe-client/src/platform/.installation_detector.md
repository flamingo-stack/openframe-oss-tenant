Detects whether a tool is already installed on the current system by checking for platform-specific service registrations.

## Key Components

**`detect_actual_installation`** — Public entry point that dispatches detection logic based on the `InstallationType` variant in the provided `DownloadConfiguration`. Currently only `InstallationType::Service` performs active detection; `GuiApp` and `Standard` return `None`.

**`detect_service`** — Platform-conditional function that checks for an existing service installation:
- **macOS**: Checks for a `.plist` file under `/Library/LaunchDaemons/`
- **Windows**: Runs `sc query <service_name>` and checks for a successful exit code
- **Linux/other Unix**: No-op, always returns `None`

On a positive match, both paths resolve the executable path via `DirectoryManager::get_tool_executable_path` and return an `Installation::Service` variant.

## Usage Example

```rust
let config = DownloadConfiguration {
    installation_type: InstallationType::Service,
    service_name: Some("com.example.mytool".to_string()),
    target_file_name: "mytool".to_string(),
    // ...
};

let directory_manager = DirectoryManager::new();

if let Some(installation) = detect_actual_installation("mytool", &config, &directory_manager) {
    match installation {
        Installation::Service { service_name, executable_path } => {
            println!("Found existing service: {}", service_name);
        }
        _ => {}
    }
}
```

> **Note:** Linux service detection (e.g. via `systemctl`) is not yet implemented. The Unix non-macOS branch is explicitly a no-op placeholder.
