One-time Windows registry migration that repairs an incorrect `PATH` value type — converting `REG_SZ` back to `REG_EXPAND_SZ` to restore `%SystemRoot%` and other variable expansions broken by a previous OpenFrame version.

## Key Components

- **`run()`** — Public entry point, safe to call on every startup. Performs the full check-and-repair cycle, logging warnings on failure without panicking.

**Internal logic flow:**

1. Opens `HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Environment` with read/write access
2. Reads the raw `Path` value and checks its type
3. Exits early if already `REG_EXPAND_SZ` (no-op on healthy systems)
4. Decodes the UTF-16LE bytes and checks for `%` characters (unexpanded variables)
5. Re-encodes the string as `REG_EXPAND_SZ` with a proper null terminator and writes it back

## Usage Example

```rust
// Called once during OpenFrame agent startup (Windows only)
fn main() {
    windows_path_migration::run();
    // Safe to call every time — exits early if PATH type is correct
}
```

## Behavior Summary

| Condition | Action |
|---|---|
| `PATH` is `REG_EXPAND_SZ` | No-op, returns immediately |
| `PATH` is `REG_SZ`, no `%` vars | No-op, no repair needed |
| `PATH` is `REG_SZ` with `%vars%` | Repairs type → `REG_EXPAND_SZ` |
| Registry access fails | Logs `warn!`, does not panic |
