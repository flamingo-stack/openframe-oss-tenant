One-time startup migration that detects and repairs an incorrect Windows `PATH` registry value type, converting `REG_SZ` back to `REG_EXPAND_SZ` to restore `%SystemRoot%` variable expansion.

## Key Components

### `run() -> ()`

The sole public function. Idempotent — safe to call on every application startup. Performs the following steps:

1. Opens `HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Environment` with read/write access.
2. Reads the raw `Path` registry value and checks its type.
3. **Skips** if the type is already `REG_EXPAND_SZ` (no action needed).
4. **Skips** if the value contains no `%` characters (no variable expansion required).
5. Re-writes the value as `REG_EXPAND_SZ` with the same string content, preserving the null terminator.
6. Logs a warning (non-fatal) if any step fails.

## Background

Previous OpenFrame versions used `set_value()` from `winreg`, which silently downgrades `REG_EXPAND_SZ` to `REG_SZ`. This breaks Windows environment variable expansion in `PATH`, making system tools (`ping.exe`, `ipconfig.exe`, etc.) unreachable from the agent.

## Usage Example

```rust
// Call once at agent startup, before any process spawning.
windows_path_migration::run();
```

No return value or error propagation — failures are logged via `tracing::warn` and swallowed to avoid blocking startup.
