Cross-platform directory management module that provides a unified interface for handling platform-specific directories across Windows, macOS, and Linux, including application support, logs, and secured directories with proper permissions.

## Key Components

- **`DirectoryError`** - Error type for directory operations including creation failures, permission issues, and validation errors
- **`DirectoryManager`** - Main struct providing unified directory management with platform-specific implementations
- **Directory Functions** - Platform-specific path resolution functions (`get_app_support_directory`, `get_logs_directory`, `get_secured_directory`)
- **Permission Functions** - Platform-specific permission setting (`set_directory_permissions`, `set_secured_directory_permissions`)

## Usage Example

```rust
// Create a directory manager with default platform paths
let manager = DirectoryManager::new();

// For development with user directories only
let dev_manager = DirectoryManager::for_development();

// Create with custom paths
let custom_manager = DirectoryManager::with_custom_dirs(
    PathBuf::from("/custom/logs"),
    PathBuf::from("/custom/app"),
    PathBuf::from("/custom/secured")
);

// Get platform-specific directories
let logs_dir = get_logs_directory();
let app_dir = get_app_support_directory();

// Set appropriate permissions
set_directory_permissions(&logs_dir)?;
set_secured_directory_permissions(&secured_dir)?;
```

The module handles platform differences automatically - Windows uses ProgramData, macOS uses `/Library/Application Support`, and Linux uses `/var/lib` and `/var/log`. It also supports development mode using user directories and environment variable overrides for custom log paths.
