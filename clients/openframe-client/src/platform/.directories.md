Cross-platform directory management for OpenFrame, providing a unified API to resolve, create, and configure platform-specific application support, log, and secured directories on Windows, macOS, and Linux.

## Key Components

- **`DirectoryError`** — Error enum covering creation failures, permission denials, validation errors, and missing home directory
- **`get_app_support_directory()`** — Returns the platform-specific app data path (`ProgramData\OpenFrame`, `/Library/Application Support/OpenFrame`, `/var/lib/openframe`)
- **`get_logs_directory()`** — Returns the log path, respecting the `OPENFRAME_LOG_DIR` environment variable override
- **`get_secured_directory()`** — Returns the admin/root-only secured data path
- **`set_directory_permissions()`** — Applies standard `755` permissions (Unix) or system defaults (Windows)
- **`set_secured_directory_permissions()`** — Applies restrictive `700` permissions on Linux for secured directories
- **`DirectoryManager`** — Central struct managing all directory paths, with constructors for default, custom, user-scoped, and development modes

## Usage Example

```rust
// Standard system-wide installation
let mgr = DirectoryManager::new();

// Development mode — uses user home directories to avoid permission issues
let mgr = DirectoryManager::for_development();

// Custom paths for testing or non-standard deployments
let mgr = DirectoryManager::with_custom_dirs(
    PathBuf::from("/tmp/openframe/logs"),
    PathBuf::from("/tmp/openframe/app"),
    PathBuf::from("/tmp/openframe/secured"),
);

// Per-user log directory alongside system paths
let mgr = DirectoryManager::with_user_logs_dir();

// Resolve platform paths directly
let log_path = get_logs_directory(); // Honors $OPENFRAME_LOG_DIR override
let secured = get_secured_directory();
```

> **Note:** On Linux, `set_secured_directory_permissions` enforces `700` (`rwx------`) ownership under `root:root`. On Windows, directory ACLs are inherited from the system when running as Administrator — no explicit `chmod` equivalent is applied.
