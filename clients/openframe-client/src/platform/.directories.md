Cross-platform directory management for the OpenFrame platform. Provides a unified API for resolving, creating, and securing platform-specific directories (app support, logs, secured storage) across Windows, macOS, and Linux.

## Key Components

- **`DirectoryError`** — Error enum covering creation failures, permission denials, validation issues, and missing home directory
- **`get_app_support_directory()`** — Returns the platform-specific app support path (`ProgramData\OpenFrame`, `/Library/Application Support/OpenFrame`, `/var/lib/openframe`)
- **`get_logs_directory()`** — Returns the logs path, respecting the `OPENFRAME_LOG_DIR` environment variable override before falling back to platform defaults
- **`get_secured_directory()`** — Returns the admin/root-only secured storage path per platform
- **`set_directory_permissions(path)`** — Applies standard (`755`/`rwxr-xr-x`) permissions; uses `chown`/`chmod` on Unix, inherits system defaults on Windows
- **`set_secured_directory_permissions(path)`** — Applies restrictive (`700`/`rwx------`) permissions for secured directories on Linux; graceful fallback on macOS/Windows
- **`DirectoryManager`** — Central struct managing all directory paths with multiple construction modes

### `DirectoryManager` Constructors

| Method | Description |
|--------|-------------|
| `new()` | Default system paths |
| `with_custom_dirs(...)` | Inject custom paths |
| `with_user_logs_dir()` | Adds per-user log path alongside system paths |
| `for_development()` | All paths point to user directory to avoid permission issues |

## Usage Example

```rust
// Production: use system directories
let dirs = DirectoryManager::new();

// Development: avoid permission issues
let dirs = DirectoryManager::for_development();

// Override log directory via environment
// OPENFRAME_LOG_DIR=/tmp/openframe-logs ./openframe

// Get platform paths directly
let logs = get_logs_directory();
let app  = get_app_support_directory();

// Apply permissions after creating a directory
set_directory_permissions(&logs)?;
set_secured_directory_permissions(&get_secured_directory())?;
```
