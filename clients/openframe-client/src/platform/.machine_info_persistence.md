Provides cross-platform persistence of machine registration credentials (`machine_id` + `client_secret`) across uninstall/reinstall cycles, with per-OS secure storage backends and automatic permission repair.

## Key Components

### `PersistedMachineInfo`
Serializable struct holding the two identity fields. Implements a custom `Debug` that redacts `client_secret` to prevent accidental secret leakage in logs.

### `write(machine_info: &PersistedMachineInfo) -> Result<()>`
Validates completeness (rejects empty fields) then delegates to the platform-specific `write_impl`. Logs success via `tracing`.

### `read() -> Result<Option<PersistedMachineInfo>>`
Reads persisted credentials with a three-outcome contract:
- `Ok(Some(info))` — valid credentials found; safe to reuse for reinstall
- `Ok(None)` — no store exists; treat as a fresh install
- `Err(_)` — store exists but is unreadable (corrupt, partial, permission-denied)

Automatically calls `repair_permissions()` on a permission-denied error and retries once.

### `is_permission_denied(err: &anyhow::Error) -> bool`
Walks the full `anyhow` error chain checking for `io::ErrorKind::PermissionDenied`.

### Platform backends

| OS | Storage location | Security mechanism |
|---|---|---|
| Windows | `HKLM\SOFTWARE\OpenFrame` (`REG_SZ`) | DACL restricted to Administrators + SYSTEM via SDDL |
| macOS | `/Library/Preferences/com.openframe.client.plist` | `chmod 0600`; file deleted if it cannot be secured |
| Linux | `/etc/openframe/machine.json` | `0700` directory, `0600` file, atomic temp-file write |

## Usage Example

```rust
use machine_info_persistence::{PersistedMachineInfo, read, write};

// On first install: persist newly provisioned credentials
let info = PersistedMachineInfo {
    machine_id: "m-abc123".to_string(),
    client_secret: "s3cr3t".to_string(),
};
write(&info)?;

// On reinstall: recover existing credentials
match read()? {
    Some(info) => println!("Reusing machine_id: {}", info.machine_id),
    None => println!("No prior registration found; provisioning fresh"),
}
```
