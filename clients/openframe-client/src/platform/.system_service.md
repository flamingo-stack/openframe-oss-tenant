Cross-platform async service management utility that starts system services using the native service manager for each OS: `launchctl` on macOS, `sc` on Windows, and `systemctl` on Linux.

## Key Components

| Item | Description |
|------|-------------|
| `start_service(service_name)` | Async function (platform-specific via `#[cfg]`) that starts a named system service using the OS-native CLI tool |

**Platform behavior:**

| OS | Tool | Notes |
|----|------|-------|
| macOS | `sudo launchctl load` | Resolves plist at `/Library/LaunchDaemons/<name>.plist` |
| Windows | `sc start` | Silently ignores error code `1056` (service already running) |
| Linux | `sudo systemctl start` | Standard systemd unit start |

## Usage Example

```rust
use anyhow::Result;

#[tokio::main]
async fn main() -> Result<()> {
    // macOS: loads /Library/LaunchDaemons/com.example.agent.plist
    // Windows: sc start com.example.agent
    // Linux: systemctl start com.example.agent
    system_service::start_service("com.example.agent").await?;
    Ok(())
}
```

> **Note:** macOS and Linux variants invoke `sudo` — ensure the calling process has the necessary privileges or a passwordless `sudoers` entry for the target commands.
