Cross-platform async utility for starting system services using native OS service managers (`launchctl` on macOS, `sc` on Windows, `systemctl` on Linux).

## Key Components

| Item | Description |
|------|-------------|
| `start_service(service_name)` | Async function (platform-conditional) that starts a named system service using the OS-native CLI |

**Platform dispatch:**

| OS | Tool | Command |
|----|------|---------|
| macOS | `launchctl` | `sudo launchctl load /Library/LaunchDaemons/<name>.plist` |
| Windows | `sc` | `sc start <name>` (ignores error `1056` — already running) |
| Linux | `systemctl` | `sudo systemctl start <name>` |

## Usage Example

```rust
use system_service::start_service;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    // macOS: loads /Library/LaunchDaemons/com.example.agent.plist
    // Windows: runs sc start com.example.agent
    // Linux:   runs systemctl start com.example.agent
    start_service("com.example.agent").await?;
    Ok(())
}
```

## Notes

- All three implementations are **mutually exclusive** via `#[cfg(target_os = "...")]` — only the matching platform variant is compiled.
- Windows silently swallows the "already running" error code (`1056`) to make the call idempotent.
- macOS and Linux invoke commands via `sudo`; ensure the running process has the necessary privileges or a passwordless `sudoers` entry.
- Errors are propagated as `anyhow::Result` with contextual messages for easy debugging.
