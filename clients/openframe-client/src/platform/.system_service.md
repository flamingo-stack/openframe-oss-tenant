Cross-platform async utility for starting system services using the native service manager for each OS (`launchctl` on macOS, `sc` on Windows, `systemctl` on Linux).

## Key Components

- **`start_service(service_name: &str) -> Result<()>`** — Conditionally compiled per target OS:
  - **macOS** — Runs `sudo launchctl load /Library/LaunchDaemons/<name>.plist`
  - **Windows** — Runs `sc start <name>`, silently ignores error code `1056` (service already running)
  - **Linux** — Runs `sudo systemctl start <name>`

## Usage Example

```rust
use system_service::start_service;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    // On macOS: sudo launchctl load /Library/LaunchDaemons/com.example.agent.plist
    // On Windows: sc start com.example.agent
    // On Linux: sudo systemctl start com.example.agent
    start_service("com.example.agent").await?;
    Ok(())
}
```

## Notes

- All three implementations are `async`, delegating to `tokio::process::Command` for non-blocking subprocess execution
- Errors are propagated via `anyhow::Result` with contextual messages
- Windows-specific: error `1056` ("service already running") is treated as a non-fatal no-op
- macOS implementation assumes the `.plist` file exists under `/Library/LaunchDaemons/`
- Requires `sudo` privileges on macOS and Linux
