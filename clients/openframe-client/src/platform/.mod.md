Module declaration file that organizes and exports utilities for system operations, file management, and platform-specific functionality. Provides a clean interface for accessing directory management, permissions, file locking, and update operations across different operating systems.

## Key Components

**Submodules:**
- `directories` - Directory management and path utilities
- `file_lock` - File locking detection and management
- `permissions` - System permission utilities and capability checking
- `uninstall` - Safe directory removal with retry logic
- `update_scripts` - Update operation handling
- `updater_launcher` - Application update launching
- `user_session` - User session management

**Platform-specific (Windows only):**
- `windows_cleanup` - Windows-specific cleanup operations
- `powershell` - PowerShell integration utilities

**Re-exported Items:**
- `DirectoryManager`, `DirectoryError` - Core directory operations
- `PermissionUtils`, `Permissions`, `Capability` - Permission management
- `LockingProcess`, file locking utilities (Windows)
- `remove_directory_with_retry` - Safe removal function
- `get_powershell_path` - PowerShell path detection (Windows)

## Usage Example

```rust
use crate::utils::{
    DirectoryManager, 
    PermissionUtils, 
    remove_directory_with_retry,
    Capability
};

// Check system permissions
if PermissionUtils::has_capability(Capability::Admin) {
    println!("Running with admin privileges");
}

// Manage directories safely
let dir_manager = DirectoryManager::new();
if let Ok(temp_dir) = dir_manager.get_temp_directory() {
    // Perform operations...
    
    // Clean up with retry logic
    remove_directory_with_retry(&temp_dir)?;
}

// Platform-specific operations (Windows)
#[cfg(target_os = "windows")]
{
    use crate::utils::get_powershell_path;
    let ps_path = get_powershell_path();
}
```
