A module organizer that exports utilities for system operations, directory management, permissions handling, and platform-specific functionality for the Flamingo MSP platform's system integration layer.

## Key Components

### Core Modules
- **`directories`** - Directory management utilities (`DirectoryManager`, `DirectoryError`)
- **`file_lock`** - File locking detection and process management (Windows-specific)
- **`permissions`** - Permission handling (`Permissions`, `PermissionUtils`, `Capability`)
- **`uninstall`** - Safe directory removal with retry logic
- **`update_scripts`** - Update script management utilities
- **`updater_launcher`** - Application updater launch functionality
- **`user_session`** - User session management

### Platform-Specific Modules
- **`windows_cleanup`** - Windows-specific cleanup operations
- **`powershell`** - PowerShell integration utilities

### Re-exported Items
- `DirectoryManager`, `DirectoryError` from directories
- File locking utilities (Windows only)
- Permission management types
- `remove_directory_with_retry` for safe uninstalls
- `get_powershell_path` for PowerShell operations

## Usage Example

```rust
use crate::system::{
    DirectoryManager, 
    Permissions, 
    remove_directory_with_retry
};

#[cfg(target_os = "windows")]
use crate::system::{get_powershell_path, is_file_in_use_error};

// Cross-platform usage
let dir_manager = DirectoryManager::new()?;
let permissions = Permissions::current_user();

// Windows-specific functionality
#[cfg(target_os = "windows")]
let powershell = get_powershell_path()?;
```
