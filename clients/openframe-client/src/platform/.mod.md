Module declaration file that organizes system utility components for cross-platform file operations, permissions management, and application lifecycle tasks. Provides conditional Windows-specific functionality and re-exports commonly used items for simplified imports.

## Key Components

**Core Modules:**
- `directories` - Directory management utilities with `DirectoryManager` and `DirectoryError`
- `permissions` - Cross-platform permission handling with `PermissionUtils`, `Permissions`, and `Capability`
- `file_lock` - File locking detection and process management (Windows-only)
- `uninstall` - Safe directory removal with retry logic
- `update_scripts` - Application update script management
- `updater_launcher` - Update process launcher utilities
- `user_session` - User session management

**Windows-Specific Modules:**
- `windows_cleanup` - Windows-specific cleanup operations
- `powershell` - PowerShell path detection and utilities

**Re-exported Items:**
- `DirectoryManager`, `DirectoryError` from directories
- `PermissionUtils`, `Permissions`, `Capability`, `PermissionError` from permissions
- `remove_directory_with_retry` from uninstall
- Windows-only: file lock utilities and PowerShell path getter

## Usage Example

```rust
use crate::utils::{
    DirectoryManager, 
    PermissionUtils, 
    remove_directory_with_retry
};

#[cfg(target_os = "windows")]
use crate::utils::{get_powershell_path, get_locking_processes};

// Cross-platform usage
let dir_manager = DirectoryManager::new()?;
let has_permission = PermissionUtils::can_write_to_path(&path)?;
remove_directory_with_retry(&temp_dir, 3).await?;

// Windows-specific usage
#[cfg(target_os = "windows")]
{
    let ps_path = get_powershell_path()?;
    let processes = get_locking_processes(&file_path)?;
}
```
