This module serves as the main entry point for system utilities, providing platform-specific and cross-platform functionality for directory management, file operations, permissions, and system interactions.

## Key Components

### Cross-Platform Modules
- **`DirectoryManager`** - Handles directory operations and path management
- **`PermissionUtils`** - Manages file and directory permissions with capability-based access
- **`file_lock`** - Provides file locking mechanisms and process detection
- **`uninstall`** - Contains utilities for safe directory removal with retry logic
- **`update_scripts`** - Handles application update processes
- **`updater_launcher`** - Manages updater process launching
- **`user_session`** - Handles user session management

### Windows-Specific Modules
- **`windows_cleanup`** - Windows-specific cleanup operations
- **`powershell`** - PowerShell execution utilities

### Re-exported Types
- `DirectoryError`, `PermissionError` - Error types for robust error handling
- `Capability`, `Permissions` - Permission management types
- `LockingProcess` - File lock detection functionality

## Usage Example

```rust
use system_utils::{
    DirectoryManager, PermissionUtils, Capability,
    remove_directory_with_retry
};

#[cfg(target_os = "windows")]
use system_utils::{get_powershell_path, format_locking_processes};

// Cross-platform directory management
let dir_manager = DirectoryManager::new()?;
let app_dir = dir_manager.get_app_directory()?;

// Permission checking
let perms = PermissionUtils::new();
if perms.has_capability(Capability::WriteFiles)? {
    // Perform file operations
}

// Safe directory removal
remove_directory_with_retry(&app_dir)?;

// Windows-specific operations
#[cfg(target_os = "windows")]
{
    let ps_path = get_powershell_path()?;
    let locking_procs = format_locking_processes(&file_path);
}
```
