A module declaration file that organizes utility modules for system operations, file management, and platform-specific functionality. This serves as the main entry point for the utilities package, exposing commonly used types and functions through re-exports.

## Key Components

**Public Modules:**
- `directories` - Directory management and operations
- `file_lock` - File locking detection and handling (Windows-specific)
- `permissions` - Permission management and capability checking
- `uninstall` - Safe directory removal with retry logic
- `update_scripts` - Update script management
- `updater_launcher` - Application updater functionality
- `user_session` - User session management
- `windows_cleanup` - Windows-specific cleanup operations (Windows-only)
- `powershell` - PowerShell integration utilities (Windows-only)

**Re-exported Types:**
- `DirectoryError`, `DirectoryManager` - Directory operation types
- `LockingProcess`, file locking utilities - File lock management (Windows-only)
- `Capability`, `PermissionError`, `PermissionUtils`, `Permissions` - Permission system
- `remove_directory_with_retry` - Safe directory removal function
- `get_powershell_path` - PowerShell path resolution (Windows-only)

## Usage Example

```rust
use crate::utilities::{
    DirectoryManager, 
    PermissionUtils, 
    Permissions,
    remove_directory_with_retry
};

fn system_cleanup() -> Result<(), Box<dyn std::error::Error>> {
    // Check permissions before cleanup
    let perms = PermissionUtils::get_current_permissions()?;
    
    if perms.has_capability(&Capability::Write) {
        // Safe directory removal with retry logic
        remove_directory_with_retry("/tmp/cleanup_target")?;
    }
    
    Ok(())
}

#[cfg(target_os = "windows")]
fn windows_specific_operations() {
    use crate::utilities::{get_powershell_path, get_locking_processes};
    
    let ps_path = get_powershell_path();
    let locks = get_locking_processes("C:\\temp\\file.txt");
}
```
