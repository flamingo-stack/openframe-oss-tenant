Module entry point that organizes system utilities for managing directories, permissions, file operations, and platform-specific functionality.

## Key Components

### Core Modules
- **`directories`** - Directory management operations and error handling
- **`file_lock`** - File locking detection and process management  
- **`permissions`** - Permission handling with capability-based access control
- **`uninstall`** - Safe directory removal with retry logic
- **`update_scripts`** - Update operation utilities
- **`updater_launcher`** - Application updater launching functionality
- **`user_session`** - User session management

### Platform-Specific (Windows)
- **`windows_cleanup`** - Windows-specific cleanup operations
- **`powershell`** - PowerShell execution utilities

### Re-exported Items
- `DirectoryManager`, `DirectoryError` from directories
- `PermissionUtils`, `Permissions`, `Capability`, `PermissionError` from permissions
- File locking utilities (`LockingProcess`, `get_locking_processes`, etc.) on Windows
- `remove_directory_with_retry` from uninstall
- `get_powershell_path` on Windows

## Usage Example

```rust
use crate::system::{
    DirectoryManager, 
    PermissionUtils, 
    Capability,
    remove_directory_with_retry
};

#[cfg(target_os = "windows")]
use crate::system::{get_powershell_path, get_locking_processes};

// Create directory manager
let dir_manager = DirectoryManager::new()?;

// Check permissions
let has_admin = PermissionUtils::has_capability(Capability::Admin)?;

// Remove directory safely
remove_directory_with_retry(&temp_dir, 3)?;

#[cfg(target_os = "windows")]
{
    // Windows-specific operations
    let ps_path = get_powershell_path()?;
    let locking_procs = get_locking_processes(&file_path)?;
}
```
