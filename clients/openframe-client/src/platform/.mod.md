Main module that organizes and exposes core system utilities for file management, permissions, and platform-specific operations.

## Key Components

### Modules
- `directories` - Directory management and path utilities
- `file_lock` - File locking detection and process management
- `permissions` - Permission handling and capability management
- `uninstall` - Safe directory removal with retry logic
- `update_scripts` - Update script management
- `updater_launcher` - Updater process launching
- `user_session` - User session management

### Platform-Specific (Windows)
- `windows_cleanup` - Windows-specific cleanup operations
- `powershell` - PowerShell integration and path utilities

### Re-exported Items
- `DirectoryManager`, `DirectoryError` - Directory operations
- `PermissionUtils`, `Permissions`, `Capability`, `PermissionError` - Permission management
- `LockingProcess`, file lock utilities (Windows only)
- `remove_directory_with_retry` - Safe directory removal
- `get_powershell_path` - PowerShell path detection (Windows only)

## Usage Example

```rust
use flamingo_core::system::{
    DirectoryManager, 
    PermissionUtils, 
    remove_directory_with_retry
};

// Use directory management
let dir_manager = DirectoryManager::new();
let app_dir = dir_manager.get_app_directory()?;

// Check permissions
if PermissionUtils::has_admin_privileges() {
    // Perform privileged operation
}

// Safe directory removal
remove_directory_with_retry(&temp_dir)?;
```
