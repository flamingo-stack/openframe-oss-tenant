A module aggregator that organizes and re-exports system utilities for file management, permissions, updates, and platform-specific operations.

## Key Components

**Core Modules:**
- `directories` - Directory management utilities
- `file_lock` - File locking detection and management
- `permissions` - Permission handling and capability checks
- `uninstall` - Safe directory removal operations
- `update_scripts` - Update script management
- `updater_launcher` - Application updater functionality
- `user_session` - User session management

**Windows-Specific Modules:**
- `windows_cleanup` - Windows-specific cleanup operations
- `powershell` - PowerShell integration utilities

**Re-exported Items:**
- `DirectoryManager` and `DirectoryError` for directory operations
- `PermissionUtils`, `Permissions`, and permission-related types
- File locking utilities (Windows only)
- `remove_directory_with_retry` for safe uninstallation
- `get_powershell_path` for PowerShell access (Windows only)

## Usage Example

```rust
use crate::utils::{
    DirectoryManager, 
    PermissionUtils, 
    Permissions,
    remove_directory_with_retry
};

// Directory management
let dir_manager = DirectoryManager::new();

// Check permissions
let perms = PermissionUtils::check_capabilities();
if perms.contains(Permissions::WRITE) {
    // Safe directory removal
    remove_directory_with_retry(&target_path)?;
}

#[cfg(target_os = "windows")]
use crate::utils::{get_powershell_path, is_file_in_use_error};
```
