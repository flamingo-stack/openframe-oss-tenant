A module declaration file that organizes utility modules for system operations including directory management, file locking, permissions, and platform-specific functionality for the Flamingo MSP platform.

## Key Components

### Core Modules
- **`directories`** - Directory management utilities with `DirectoryManager` and `DirectoryError`
- **`file_lock`** - File locking detection and process management (Windows-specific)
- **`permissions`** - Permission handling with `Permissions`, `PermissionUtils`, and `Capability` types
- **`uninstall`** - Directory removal utilities with retry logic
- **`update_scripts`** - Update script management functionality
- **`updater_launcher`** - Updater process launching utilities
- **`user_session`** - User session management

### Platform-Specific Modules (Windows)
- **`windows_cleanup`** - Windows-specific cleanup operations
- **`powershell`** - PowerShell path resolution and utilities

## Usage Example

```rust
use utils::{
    DirectoryManager, DirectoryError,
    Permissions, PermissionError, Capability,
    remove_directory_with_retry
};

#[cfg(target_os = "windows")]
use utils::{get_powershell_path, is_file_in_use_error};

// Use directory management
let dir_manager = DirectoryManager::new();
let app_dir = dir_manager.get_app_directory()?;

// Check permissions
let perms = Permissions::new();
if perms.has_capability(Capability::WriteFiles) {
    remove_directory_with_retry(&app_dir)?;
}

// Windows-specific operations
#[cfg(target_os = "windows")]
let powershell_path = get_powershell_path();
```
