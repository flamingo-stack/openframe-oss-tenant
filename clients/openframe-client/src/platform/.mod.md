Root module for the OS-level installation and update utilities crate. It organizes platform-agnostic and platform-specific submodules, then re-exports commonly used types and functions for ergonomic downstream consumption.

## Key Components

**Cross-platform modules**
- `binary_writer` — writes and sets permissions on executable files
- `directories` — directory management and error types (`DirectoryManager`, `DirectoryError`)
- `dmg_extractor` — DMG archive extraction (`DmgExtractor`)
- `file_acl` / `file_lock` — file access control and lock detection
- `installation_detector` — detects existing installations (`detect_actual_installation`)
- `permissions` — capability and permission abstractions (`Permissions`, `PermissionUtils`, `Capability`, `PermissionError`)
- `system_service` — OS service management
- `tool_updater` — core update/migration logic (`ToolUpdater`, `create_updater`, `run_update`, `run_migration`, `needs_migration`)
- `uninstall` — uninstallation helpers (`orbit_dir`, `remove_directory_with_retry`)
- `update_scripts` / `updater_launcher` / `user_session` — update orchestration utilities

**Platform-specific modules**
- `preferences_writer` — macOS preference file management
- `windows_cleanup` / `windows_path_migration` / `powershell` — Windows-only cleanup, path migration, and PowerShell path resolution

## Usage Example

```rust
use your_crate::{
    DirectoryManager,
    PermissionUtils,
    create_updater,
    run_update,
    UpdateContext,
    detect_actual_installation,
};

// Detect current installation state
let install = detect_actual_installation(&install_dir)?;

// Build and run an updater
let updater = create_updater(deps);
let ctx = UpdateContext::new(version, target_dir);
run_update(&updater, &ctx).await?;

// Windows only: check for locked files before update
#[cfg(target_os = "windows")]
{
    use your_crate::{get_locking_processes, log_file_lock_info};
    let locks = get_locking_processes(&binary_path)?;
    log_file_lock_info(&locks);
}
```
