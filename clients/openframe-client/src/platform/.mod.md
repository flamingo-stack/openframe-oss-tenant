A module definition file that organizes and re-exports system utilities for file management, permissions, updates, and platform-specific operations in the Flamingo platform.

## Key Components

**Core Modules:**
- `directories` - Directory management utilities
- `file_lock` - File locking and process detection
- `permissions` - Permission handling and capability management
- `uninstall` - Safe directory removal with retry logic
- `update_scripts` - Update script management
- `updater_launcher` - Update process launcher
- `user_session` - User session management

**Windows-Specific Modules:**
- `windows_cleanup` - Windows-specific cleanup operations
- `powershell` - PowerShell integration utilities

**Re-exported Items:**
- `DirectoryError`, `DirectoryManager` from directories
- `LockingProcess`, file lock utilities (Windows only)
- `Capability`, `PermissionError`, `PermissionUtils`, `Permissions` from permissions
- `remove_directory_with_retry` from uninstall
- `get_powershell_path` (Windows only)

## Usage Example

```rust
use crate::utils::{
    DirectoryManager,
    PermissionUtils,
    remove_directory_with_retry,
};

#[cfg(target_os = "windows")]
use crate::utils::{get_powershell_path, get_locking_processes};

// Access directory management
let dir_manager = DirectoryManager::new();

// Check permissions
let permissions = PermissionUtils::check_admin_privileges()?;

// Safe directory removal
remove_directory_with_retry(&path)?;

// Windows-specific operations
#[cfg(target_os = "windows")]
{
    let powershell = get_powershell_path()?;
    let locks = get_locking_processes(&file_path)?;
}
```
