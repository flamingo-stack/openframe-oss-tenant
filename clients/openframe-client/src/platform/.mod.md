This module serves as the main entry point for system utilities, providing a centralized interface for directory management, file operations, permissions, and platform-specific functionality across different operating systems.

## Key Components

### Core Modules
- **`directories`** - Directory management and path utilities
- **`file_lock`** - File locking detection and process management
- **`permissions`** - Permission checking and capability management
- **`uninstall`** - Safe directory removal with retry logic
- **`update_scripts`** - Update process management
- **`updater_launcher`** - Application updater functionality
- **`user_session`** - User session management

### Platform-Specific Modules
- **`windows_cleanup`** - Windows-specific cleanup operations (Windows only)
- **`powershell`** - PowerShell integration utilities (Windows only)

### Re-exported Types
- `DirectoryManager`, `DirectoryError` - Directory operations
- `PermissionUtils`, `Permissions`, `Capability`, `PermissionError` - Permission management
- `LockingProcess` and related file lock utilities (Windows only)
- `remove_directory_with_retry` - Safe directory removal
- `get_powershell_path` - PowerShell path detection (Windows only)

## Usage Example

```rust
use system_utils::{DirectoryManager, PermissionUtils, Permissions};

// Directory management
let dir_manager = DirectoryManager::new();
let app_dir = dir_manager.get_app_directory()?;

// Permission checking
let perms = PermissionUtils::check_current_permissions()?;
if perms.contains(Permissions::ADMIN) {
    println!("Running with admin privileges");
}

// Safe directory removal
system_utils::remove_directory_with_retry(&temp_dir)?;

#[cfg(target_os = "windows")]
{
    // Windows-specific operations
    let ps_path = system_utils::get_powershell_path()?;
    let locking_procs = system_utils::get_locking_processes(&file_path)?;
}
```
