A module declaration file that organizes and re-exports utility modules for file operations, permissions, and platform-specific functionality in the Flamingo MSP platform's updater system.

## Key Components

**Public Modules:**
- `directories` - Directory management utilities
- `file_lock` - File locking detection and process identification
- `permissions` - Cross-platform permission handling
- `uninstall` - Safe directory removal with retry logic
- `update_scripts` - Update script execution utilities
- `updater_launcher` - Launcher functionality for the updater
- `user_session` - User session management

**Windows-Specific Modules:**
- `windows_cleanup` - Windows-specific cleanup operations
- `powershell` - PowerShell integration utilities

**Re-exported Items:**
- `DirectoryError`, `DirectoryManager` from directories
- `Capability`, `PermissionError`, `PermissionUtils`, `Permissions` from permissions
- `remove_directory_with_retry` from uninstall
- Windows-only: file locking utilities and PowerShell path resolver

## Usage Example

```rust
use crate::utils::{
    DirectoryManager, 
    PermissionUtils, 
    remove_directory_with_retry,
    Permissions
};

#[cfg(target_os = "windows")]
use crate::utils::{get_powershell_path, is_file_in_use_error};

// Use cross-platform utilities
let dir_manager = DirectoryManager::new();
let has_admin = PermissionUtils::has_capability(Permissions::Admin)?;

// Platform-specific functionality
#[cfg(target_os = "windows")]
let powershell = get_powershell_path()?;
```
