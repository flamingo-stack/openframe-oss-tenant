This module serves as the main entry point for platform-specific utilities and directory management functionality, organizing various system operations and re-exporting commonly used items for easier access.

## Key Components

### Modules
- **`directories`** - Directory management and path handling utilities
- **`file_lock`** - File locking detection and process management (Windows-specific)
- **`permissions`** - Permission handling and capability management
- **`uninstall`** - Directory removal utilities with retry logic
- **`update_scripts`** - Script management for application updates
- **`updater_launcher`** - Launcher utilities for update processes
- **`user_session`** - User session management functionality
- **`windows_cleanup`** - Windows-specific cleanup operations (Windows-only)
- **`powershell`** - PowerShell execution utilities (Windows-only)

### Re-exported Items
- `DirectoryError`, `DirectoryManager` - Core directory operations
- `LockingProcess`, file lock utilities - File lock detection (Windows)
- `Capability`, `PermissionError`, `PermissionUtils`, `Permissions` - Permission management
- `remove_directory_with_retry` - Robust directory removal
- `get_powershell_path` - PowerShell path resolution (Windows)

## Usage Example

```rust
use crate::platform_utils::{
    DirectoryManager, 
    PermissionUtils, 
    remove_directory_with_retry,
    Capability
};

fn cleanup_application() -> Result<(), Box<dyn std::error::Error>> {
    // Check permissions
    let permissions = PermissionUtils::current_user_permissions()?;
    
    // Remove application directory with retry logic
    let app_dir = DirectoryManager::get_app_directory()?;
    remove_directory_with_retry(&app_dir)?;
    
    Ok(())
}
```
