This module serves as the main entry point for the utilities package, organizing and re-exporting common system utilities including directory management, file operations, permissions, and platform-specific functionality.

## Key Components

### Modules
- **`directories`** - Directory creation, management, and path utilities
- **`file_lock`** - File locking detection and process management (Windows-specific)
- **`permissions`** - Permission checking, capability management, and access control
- **`uninstall`** - Safe directory removal with retry logic
- **`update_scripts`** - Update script management and execution
- **`updater_launcher`** - Application updater launch utilities
- **`user_session`** - User session management and detection

### Platform-Specific Modules
- **`windows_cleanup`** - Windows-specific cleanup operations
- **`powershell`** - PowerShell integration and path resolution

### Re-exported Types
- `DirectoryManager`, `DirectoryError` - Directory operations
- `PermissionUtils`, `Permissions`, `Capability` - Permission management
- `LockingProcess` and file lock utilities - Process detection (Windows)

## Usage Example

```rust
use utils::{
    DirectoryManager, 
    PermissionUtils, 
    Permissions,
    remove_directory_with_retry
};

#[cfg(target_os = "windows")]
use utils::{get_locking_processes, get_powershell_path};

// Directory management
let dir_manager = DirectoryManager::new();
dir_manager.ensure_directory_exists("/path/to/dir")?;

// Permission checking
let perms = PermissionUtils::get_current_permissions()?;
if perms.has_capability(Permissions::WRITE) {
    // Perform write operation
}

// Safe directory removal
remove_directory_with_retry("/temp/dir", 3).await?;
```
