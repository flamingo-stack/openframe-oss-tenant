Module aggregator for core utility functionality in the Flamingo platform, organizing file system operations, permissions management, and platform-specific utilities across multiple submodules.

## Key Components

### Core Modules
- **`directories`** - Directory management with `DirectoryManager` and `DirectoryError`
- **`file_lock`** - File locking detection and process management (Windows-specific)
- **`permissions`** - Permission handling with `PermissionUtils`, `Permissions`, and `Capability`
- **`uninstall`** - Safe directory removal with retry logic
- **`update_scripts`** - Update script management functionality
- **`updater_launcher`** - Application updater launcher utilities
- **`user_session`** - User session management

### Platform-Specific Modules (Windows)
- **`windows_cleanup`** - Windows-specific cleanup operations
- **`powershell`** - PowerShell integration and path resolution

### Re-exported Items
Common utilities are re-exported for easy access: `DirectoryManager`, `PermissionUtils`, `remove_directory_with_retry`, and Windows-specific file locking utilities.

## Usage Example

```rust
use crate::utils::{
    DirectoryManager, 
    PermissionUtils, 
    remove_directory_with_retry,
    Capability
};

// Use directory management
let dir_manager = DirectoryManager::new();
let app_dir = dir_manager.get_app_directory()?;

// Check permissions
if PermissionUtils::has_capability(Capability::FileWrite) {
    // Safe directory removal with retry
    remove_directory_with_retry(&app_dir)?;
}

#[cfg(target_os = "windows")]
use crate::utils::{get_locking_processes, get_powershell_path};

#[cfg(target_os = "windows")]
{
    let ps_path = get_powershell_path()?;
    let locks = get_locking_processes(&file_path)?;
}
```
