A module organization file that exports and re-exports utilities for system operations including directory management, file locking, permissions, and platform-specific functionality.

## Key Components

### Core Modules
- **`directories`** - Directory management utilities with `DirectoryManager` and error handling
- **`file_lock`** - File locking detection and process identification (Windows-specific)
- **`permissions`** - Cross-platform permission management with `PermissionUtils` and `Capability` types
- **`uninstall`** - Directory removal utilities with retry logic
- **`update_scripts`** - Update script management functionality
- **`updater_launcher`** - Application updater launching utilities
- **`user_session`** - User session management operations

### Platform-Specific Modules
- **`windows_cleanup`** - Windows-specific cleanup operations (Windows only)
- **`powershell`** - PowerShell path detection and utilities (Windows only)

### Re-exported Items
- `DirectoryError`, `DirectoryManager` from directories
- `LockingProcess`, file lock utilities from file_lock (Windows only)
- `Capability`, `PermissionError`, `PermissionUtils`, `Permissions` from permissions
- `remove_directory_with_retry` from uninstall
- `get_powershell_path` from powershell (Windows only)

## Usage Example

```rust
use crate::utils::{
    DirectoryManager, 
    PermissionUtils, 
    Capability,
    remove_directory_with_retry
};

#[cfg(target_os = "windows")]
use crate::utils::{get_powershell_path, is_file_in_use_error};

// Cross-platform usage
let dir_manager = DirectoryManager::new();
let has_admin = PermissionUtils::has_capability(Capability::Administrator)?;

// Windows-specific usage
#[cfg(target_os = "windows")]
let ps_path = get_powershell_path()?;
```
