A module aggregator that organizes and re-exports system utilities for file operations, permissions, updates, and platform-specific functionality. This module serves as the main entry point for system-level operations across different operating systems.

## Key Components

### Core Modules
- **directories** - Directory management utilities (`DirectoryError`, `DirectoryManager`)
- **file_lock** - File locking detection and process management (Windows-specific)
- **permissions** - Cross-platform permission handling (`Capability`, `PermissionError`, `PermissionUtils`, `Permissions`)
- **uninstall** - Safe directory removal with retry logic (`remove_directory_with_retry`)
- **update_scripts** - Update script management
- **updater_launcher** - Application updater functionality
- **user_session** - User session management

### Windows-Specific Modules
- **windows_cleanup** - Windows-specific cleanup operations
- **powershell** - PowerShell integration utilities (`get_powershell_path`)

## Usage Example

```rust
use system::{
    DirectoryManager, 
    PermissionUtils, 
    remove_directory_with_retry,
    Permissions
};

#[cfg(target_os = "windows")]
use system::{get_powershell_path, is_file_in_use_error};

// Cross-platform directory management
let dir_manager = DirectoryManager::new()?;
let app_dir = dir_manager.get_app_directory()?;

// Permission handling
let perms = PermissionUtils::check_write_access(&app_dir)?;

// Safe directory removal
remove_directory_with_retry(&old_install_path)?;

// Windows-specific operations
#[cfg(target_os = "windows")]
let powershell = get_powershell_path()?;
```
