This module serves as the main entry point for utility functions and types used throughout the Flamingo system, providing cross-platform file operations, directory management, and system utilities.

## Key Components

### Core Modules
- **`directories`** - Directory management and path utilities (`DirectoryManager`, `DirectoryError`)
- **`file_lock`** - File locking detection and process identification (Windows-specific)
- **`permissions`** - Permission handling and capability management (`PermissionUtils`, `Permissions`, `Capability`)
- **`uninstall`** - Safe directory removal with retry logic
- **`update_scripts`** - Update mechanism utilities
- **`updater_launcher`** - Application update launcher
- **`user_session`** - User session management

### Platform-Specific Modules
- **`windows_cleanup`** - Windows-specific cleanup operations
- **`powershell`** - PowerShell integration utilities

## Usage Example

```rust
use flamingo_utils::{DirectoryManager, PermissionUtils, Permissions};

// Directory management
let dir_manager = DirectoryManager::new();
let app_dir = dir_manager.get_app_directory()?;

// Permission handling
let perms = Permissions::new();
if PermissionUtils::check_capability(Capability::Write, &app_dir)? {
    // Perform file operations
}

// Windows-specific file lock detection
#[cfg(target_os = "windows")]
{
    use flamingo_utils::get_locking_processes;
    
    if let Some(processes) = get_locking_processes("app.exe")? {
        println!("File locked by: {:?}", processes);
    }
}
```
