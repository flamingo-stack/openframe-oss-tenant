This module serves as the main utilities module that organizes and re-exports common system utilities for directory management, permissions, file operations, and platform-specific functionality.

## Key Components

### Submodules
- **`directories`** - Directory management and path utilities
- **`file_lock`** - File locking detection and process management (Windows-specific)
- **`permissions`** - Permission checking and capability management
- **`uninstall`** - Directory removal with retry logic
- **`update_scripts`** - Update script handling utilities
- **`updater_launcher`** - Application updater launch functionality
- **`user_session`** - User session management
- **`windows_cleanup`** - Windows-specific cleanup operations (Windows-only)
- **`powershell`** - PowerShell integration utilities (Windows-only)

### Re-exported Types
- **`DirectoryManager`** - Main directory management interface
- **`PermissionUtils`** - Permission checking utilities
- **`Capability`** - System capability enumeration
- **Platform-specific exports** - File locking and PowerShell utilities on Windows

## Usage Example

```rust
use crate::utils::{
    DirectoryManager, 
    PermissionUtils, 
    Capability,
    remove_directory_with_retry
};

// Use directory management
let dir_manager = DirectoryManager::new()?;
let app_dir = dir_manager.get_app_directory()?;

// Check permissions
let has_admin = PermissionUtils::has_capability(Capability::Administrator)?;

// Remove directory with retry logic
remove_directory_with_retry(&app_dir, 3)?;

#[cfg(target_os = "windows")]
use crate::utils::{get_locking_processes, get_powershell_path};
```
