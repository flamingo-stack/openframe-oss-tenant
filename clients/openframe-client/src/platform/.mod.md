Module entry point that provides centralized access to system utilities for directory management, file operations, permissions, and platform-specific functionality. Serves as the main interface for the system utilities crate with conditional Windows-specific features.

## Key Components

**Modules:**
- `directories` - Directory management and operations
- `file_lock` - File locking detection and process management
- `permissions` - Permission validation and capability checking
- `uninstall` - Safe directory removal with retry logic
- `update_scripts` - Update script management
- `updater_launcher` - Updater process launching
- `user_session` - User session management
- `windows_cleanup` - Windows-specific cleanup operations (Windows only)
- `powershell` - PowerShell integration utilities (Windows only)

**Re-exported Types:**
- `DirectoryManager`, `DirectoryError` - Core directory operations
- `LockingProcess` and file lock utilities - File access management (Windows)
- `PermissionUtils`, `Permissions`, `Capability` - Permission system
- `remove_directory_with_retry` - Safe uninstall operations
- `get_powershell_path` - PowerShell path resolution (Windows)

## Usage Example

```rust
use system_utils::{
    DirectoryManager, 
    PermissionUtils, 
    remove_directory_with_retry
};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    // Create directory manager
    let dir_manager = DirectoryManager::new()?;
    
    // Check permissions
    let perms = PermissionUtils::check_admin_privileges()?;
    
    // Safe directory removal
    remove_directory_with_retry("/tmp/old_install")?;
    
    Ok(())
}
```
