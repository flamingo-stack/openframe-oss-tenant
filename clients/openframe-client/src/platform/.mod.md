A module entry point that organizes and exposes system utilities for file operations, permissions management, and platform-specific functionality across different operating systems.

## Key Components

### Public Modules
- **`directories`** - Directory management and path utilities
- **`file_lock`** - File locking detection and process identification
- **`permissions`** - Permission checking and capability management
- **`uninstall`** - Safe directory removal with retry logic
- **`update_scripts`** - Update mechanism handling
- **`updater_launcher`** - Launcher utilities for updates
- **`user_session`** - User session management

### Platform-Specific Modules (Windows)
- **`windows_cleanup`** - Windows-specific cleanup operations
- **`powershell`** - PowerShell integration utilities

### Re-exported Items
- `DirectoryManager`, `DirectoryError` - Core directory operations
- `PermissionUtils`, `Permissions`, `Capability` - Permission management
- `LockingProcess` and file lock utilities (Windows only)
- `remove_directory_with_retry` - Safe removal function
- `get_powershell_path` (Windows only)

## Usage Example

```rust
use crate::system_utils::{
    DirectoryManager, 
    PermissionUtils, 
    Permissions,
    remove_directory_with_retry
};

#[cfg(target_os = "windows")]
use crate::system_utils::{get_locking_processes, get_powershell_path};

// Cross-platform usage
let dir_manager = DirectoryManager::new()?;
let permissions = PermissionUtils::check_permissions()?;
remove_directory_with_retry(&path, 3)?;

// Windows-specific functionality
#[cfg(target_os = "windows")]
{
    let locking_procs = get_locking_processes(&file_path)?;
    let ps_path = get_powershell_path()?;
}
```
