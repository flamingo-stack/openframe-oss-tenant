This module serves as the main entry point for system utilities, organizing platform-specific and cross-platform functionality for directory management, file operations, permissions, and system updates.

## Key Components

**Cross-platform modules:**
- `directories` - Directory management utilities
- `file_lock` - File locking and process detection
- `permissions` - Permission handling and capability management
- `uninstall` - Safe directory removal with retry logic
- `update_scripts` - Update script management
- `updater_launcher` - Application updater functionality
- `user_session` - User session management

**Windows-specific modules:**
- `windows_cleanup` - Windows-specific cleanup operations
- `powershell` - PowerShell integration utilities

**Re-exported items:**
- `DirectoryManager` and `DirectoryError` from directories
- File locking utilities (Windows only)
- Permission types and utilities
- Directory removal functions
- PowerShell path utilities (Windows only)

## Usage Example

```rust
use crate::utils::{DirectoryManager, PermissionUtils, Permissions};

// Cross-platform directory management
let dir_manager = DirectoryManager::new()?;
let app_dir = dir_manager.get_app_directory()?;

// Permission checking
if PermissionUtils::has_capability(&Permissions::Administrator)? {
    println!("Running with admin privileges");
}

// Windows-specific functionality (when compiled on Windows)
#[cfg(target_os = "windows")]
{
    use crate::utils::get_powershell_path;
    let ps_path = get_powershell_path()?;
}
```
