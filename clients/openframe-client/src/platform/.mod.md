This module serves as the main entry point for platform-specific utilities and system operations, providing a centralized interface for directory management, file operations, permissions, and update functionality.

## Key Components

### Core Modules
- **`directories`** - Directory management and path utilities (`DirectoryManager`, `DirectoryError`)
- **`file_lock`** - File locking detection and process management (Windows-only)
- **`permissions`** - Permission handling and capability management (`PermissionUtils`, `Permissions`, `Capability`)
- **`uninstall`** - Safe directory removal with retry logic
- **`update_scripts`** - Update script management and execution
- **`updater_launcher`** - Application updater launcher functionality
- **`user_session`** - User session management utilities

### Windows-Specific Modules
- **`windows_cleanup`** - Windows-specific cleanup operations
- **`powershell`** - PowerShell path detection and utilities

## Usage Example

```rust
use crate::utils::{
    DirectoryManager, 
    PermissionUtils, 
    remove_directory_with_retry
};

#[cfg(target_os = "windows")]
use crate::utils::{get_locking_processes, get_powershell_path};

// Cross-platform usage
let dir_manager = DirectoryManager::new()?;
let has_permission = PermissionUtils::check_write_access(&path)?;

// Safe directory removal
remove_directory_with_retry(&old_version_path)?;

// Windows-specific operations
#[cfg(target_os = "windows")]
{
    let processes = get_locking_processes(&file_path)?;
    let ps_path = get_powershell_path()?;
}
```

The module uses conditional compilation (`#[cfg(target_os = "windows")]`) to include platform-specific functionality only when building for Windows, ensuring clean cross-platform compatibility.
