This module serves as the main entry point for system utilities, organizing platform-specific and cross-platform functionality for file management, permissions, and system operations.

## Key Components

### Core Modules
- `directories` - Directory management and path operations
- `file_lock` - File locking detection and process identification
- `permissions` - Permission management and capability checking
- `uninstall` - Safe directory removal with retry logic
- `update_scripts` - Update script handling and execution
- `updater_launcher` - Application updater launcher utilities
- `user_session` - User session management

### Windows-Specific Modules
- `windows_cleanup` - Windows-specific cleanup operations
- `powershell` - PowerShell integration and path resolution

### Re-exported Items
The module provides convenient access to commonly used types and functions without requiring deep imports.
