This module serves as the main entry point for system utilities, organizing platform-specific and cross-platform functionality for file operations, permissions, and system management tasks.

## Key Components

### Core Modules
- **`directories`** - Directory management and path utilities (`DirectoryManager`, `DirectoryError`)
- **`permissions`** - Permission handling and capability management (`PermissionUtils`, `Permissions`, `Capability`)
- **`file_lock`** - File locking detection and process management
- **`uninstall`** - Directory removal with retry logic
- **`update_scripts`** - Update script management utilities
- **`updater_launcher`** - Application updater launch functionality
- **`user_session`** - User session management

### Windows-Specific Modules
- **`windows_cleanup`** - Windows-specific cleanup operations
- **`powershell`** - PowerShell integration and path resolution

## Usage Example

```rust
use flamingo_utils::{
    DirectoryManager, 
    PermissionUtils, 
    remove_directory_with_retry
};

// Cross-platform directory management
let dir_manager = DirectoryManager::new()?;
let app_dir = dir_manager.get_app_directory()?;

// Check permissions
if PermissionUtils::has_write_access(&app_dir)? {
    // Safe to proceed with operations
}

// Remove directory with retry logic
remove_directory_with_retry(&old_install_path)?;

#[cfg(target_os = "windows")]
use flamingo_utils::get_powershell_path;

#[cfg(target_os = "windows")]
let powershell = get_powershell_path()?;
```

The module uses conditional compilation to include Windows-specific functionality only when targeting Windows platforms, ensuring cross-platform compatibility while providing platform-optimized features where needed.
