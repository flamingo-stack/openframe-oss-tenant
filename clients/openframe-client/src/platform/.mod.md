A Rust module file that organizes and re-exports filesystem utilities, permissions management, and platform-specific tools for an updater system.

## Key Components

### Modules
- **`directories`** - Directory management utilities
- **`file_lock`** - File locking detection and management (Windows only)
- **`permissions`** - Permission checking and capability management
- **`uninstall`** - Directory removal with retry logic
- **`update_scripts`** - Update script handling
- **`updater_launcher`** - Updater process launching
- **`user_session`** - User session management
- **`windows_cleanup`** - Windows-specific cleanup operations (Windows only)
- **`powershell`** - PowerShell integration utilities (Windows only)

### Re-exports
- `DirectoryError`, `DirectoryManager` - Directory operations
- `LockingProcess`, file locking utilities - File lock detection (Windows)
- `Capability`, `PermissionError`, `PermissionUtils`, `Permissions` - Permission system
- `remove_directory_with_retry` - Robust directory removal
- `get_powershell_path` - PowerShell executable detection (Windows)

## Usage Example

```rust
use updater_utils::{
    DirectoryManager, 
    PermissionUtils, 
    remove_directory_with_retry,
    Permissions
};

// Create directory manager
let dir_manager = DirectoryManager::new()?;

// Check permissions before update
let perms = PermissionUtils::check_write_permissions(&target_path)?;
if !perms.has_capability(Capability::WriteFiles) {
    return Err("Insufficient permissions for update".into());
}

// Clean up old installation
remove_directory_with_retry(&old_install_path, 3)?;

#[cfg(target_os = "windows")]
{
    use updater_utils::{is_file_in_use_error, get_powershell_path};
    
    // Handle Windows-specific file locking
    if is_file_in_use_error(&error) {
        log_file_lock_info(&locked_file);
    }
}
```
