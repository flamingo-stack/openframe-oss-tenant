This module serves as the main entry point for Flamingo's system utilities, organizing platform-specific and cross-platform functionality for file management, permissions, and system operations.

## Key Components

### Modules
- **`directories`** - Directory management and path utilities
- **`file_lock`** - File locking detection and process management (Windows only)
- **`permissions`** - Cross-platform permission handling and capability management
- **`uninstall`** - Safe directory removal with retry logic
- **`update_scripts`** - Update mechanism utilities
- **`updater_launcher`** - Application updater functionality
- **`user_session`** - User session management
- **`windows_cleanup`** - Windows-specific cleanup operations (Windows only)
- **`powershell`** - PowerShell integration utilities (Windows only)

### Re-exported Items
- `DirectoryError`, `DirectoryManager` from directories
- `LockingProcess`, file lock utilities from file_lock (Windows)
- `Capability`, `PermissionError`, `PermissionUtils`, `Permissions` from permissions
- `remove_directory_with_retry` from uninstall
- `get_powershell_path` from powershell (Windows)

## Usage Example

```rust
use flamingo_utils::{
    DirectoryManager, 
    PermissionUtils, 
    Capability,
    remove_directory_with_retry
};

#[cfg(target_os = "windows")]
use flamingo_utils::{get_powershell_path, is_file_in_use_error};

// Check permissions
if PermissionUtils::has_capability(Capability::WriteSystem) {
    // Perform system operations
    let dir_manager = DirectoryManager::new()?;
    remove_directory_with_retry(&temp_dir)?;
}

#[cfg(target_os = "windows")]
{
    let ps_path = get_powershell_path()?;
    // Use PowerShell for Windows operations
}
```
