Module aggregation file that organizes and re-exports utility functions for system operations including directory management, file permissions, and platform-specific features.

## Key Components

### Submodules
- `directories` - Directory management utilities
- `file_lock` - File locking detection and handling (Windows-only)
- `permissions` - Permission and capability management
- `uninstall` - Directory removal with retry logic
- `update_scripts` - Update script utilities
- `updater_launcher` - Updater launch functionality
- `user_session` - User session management
- `windows_cleanup` - Windows-specific cleanup (Windows-only)
- `powershell` - PowerShell path utilities (Windows-only)

### Key Re-exports
- `DirectoryManager` and `DirectoryError` for directory operations
- `PermissionUtils`, `Permissions`, and related types for permission handling
- `LockingProcess` and file lock utilities (Windows)
- `remove_directory_with_retry` for reliable directory removal
- `get_powershell_path` for PowerShell integration (Windows)

## Usage Example

```rust
use crate::utils::{
    DirectoryManager, 
    PermissionUtils, 
    remove_directory_with_retry
};

#[cfg(target_os = "windows")]
use crate::utils::{get_locking_processes, get_powershell_path};

// Use directory manager
let dir_manager = DirectoryManager::new();

// Check permissions
let perms = PermissionUtils::check_admin_privileges()?;

// Remove directory with retry logic
remove_directory_with_retry(&path)?;

// Windows-specific operations
#[cfg(target_os = "windows")]
{
    let processes = get_locking_processes(&file_path)?;
    let ps_path = get_powershell_path()?;
}
```
