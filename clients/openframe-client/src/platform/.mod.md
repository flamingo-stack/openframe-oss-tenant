This module serves as the main utility module for the Flamingo/OpenFrame system, organizing various system utilities and re-exporting commonly used functionality for easier access throughout the application.

## Key Components

**Modules:**
- `directories` - Directory management utilities
- `file_lock` - File locking and process detection (Windows-specific exports)
- `permissions` - Permission and capability management system
- `uninstall` - Directory removal utilities with retry logic
- `update_scripts` - Update script handling
- `updater_launcher` - Updater process management
- `user_session` - User session management

**Windows-Specific Modules:**
- `windows_cleanup` - Windows-specific cleanup operations
- `powershell` - PowerShell integration utilities

**Re-exported Items:**
- `DirectoryManager` and `DirectoryError` for directory operations
- `PermissionUtils`, `Permissions`, and permission-related types
- File locking utilities (Windows only)
- `remove_directory_with_retry` for robust directory removal

## Usage Example

```rust
use crate::utils::{
    DirectoryManager, 
    PermissionUtils, 
    Permissions,
    remove_directory_with_retry
};

// Use directory management
let dir_manager = DirectoryManager::new();

// Check permissions
if PermissionUtils::has_permission(Permissions::Admin) {
    // Perform admin operations
    remove_directory_with_retry(&temp_path)?;
}

#[cfg(target_os = "windows")]
{
    use crate::utils::{get_powershell_path, get_locking_processes};
    
    let ps_path = get_powershell_path();
    let processes = get_locking_processes(&file_path);
}
```
