This module serves as the main entry point for system utility functions, providing organized access to directory management, file operations, permissions, and platform-specific utilities across different operating systems.

## Key Components

- **directories** - Directory management utilities via `DirectoryManager` and `DirectoryError`
- **file_lock** - File locking detection and process management (Windows-specific)
- **permissions** - Permission handling with `PermissionUtils`, `Permissions`, and `Capability` types
- **uninstall** - Safe directory removal with retry logic
- **update_scripts** - Update script management utilities
- **updater_launcher** - Application updater launcher functionality
- **user_session** - User session management utilities
- **windows_cleanup** - Windows-specific cleanup operations (Windows-only)
- **powershell** - PowerShell path detection and utilities (Windows-only)

## Usage Example

```rust
use crate::utils::{
    DirectoryManager, 
    PermissionUtils, 
    remove_directory_with_retry
};

#[cfg(target_os = "windows")]
use crate::utils::{get_powershell_path, is_file_in_use_error};

// Cross-platform usage
let dir_manager = DirectoryManager::new();
let permissions = PermissionUtils::check_write_access("/path/to/file")?;
remove_directory_with_retry(&temp_dir)?;

#[cfg(target_os = "windows")]
```
