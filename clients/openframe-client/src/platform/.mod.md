This module serves as the main entry point for system utilities, organizing platform-specific and cross-platform functionality for directory management, file operations, permissions, and system maintenance tasks.

## Key Components

**Core Modules:**
- `directories` - Directory management with `DirectoryManager` and `DirectoryError`
- `permissions` - Permission handling with `PermissionUtils`, `Permissions`, `Capability`, and `PermissionError`
- `file_lock` - File locking utilities (Windows-only)
- `uninstall` - Directory removal with retry logic
- `update_scripts` - Update script management
- `updater_launcher` - Updater process launching
- `user_session` - User session management

**Windows-Specific Modules:**
- `windows_cleanup` - Windows-specific cleanup operations
- `powershell` - PowerShell path resolution
