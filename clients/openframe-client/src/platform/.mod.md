A module collection that provides system utilities for directory management, file operations, permissions handling, and platform-specific functionality for the application updater system.

## Key Components

**Core Modules:**
- `directories` - Directory management and path utilities
- `file_lock` - File locking detection and process identification  
- `permissions` - Permission checking and capability management
- `uninstall` - Safe directory removal with retry logic
- `update_scripts` - Update script generation and execution
- `updater_launcher` - Updater process launching functionality
- `user_session` - User session management utilities

**Windows-Specific Modules:**
- `windows_cleanup` - Windows-specific cleanup operations
- `powershell` - PowerShell integration and execution

**Re-exported Types:**
- `DirectoryManager`, `DirectoryError` - Directory operations
- `PermissionUtils`, `Permissions`, `Capability` - Permission management
- `LockingProcess` - File lock information (Windows)

## Usage Example

```rust
use crate::sys_utils::{
    DirectoryManager, 
    PermissionUtils, 
    remove_directory_with_retry
};

// Check if running with admin privileges
if !PermissionUtils::has_admin_privileges() {
    eprintln!("Admin privileges required");
    return;
}

// Manage application directories
let dir_manager = DirectoryManager::new()?;
let app_dir = dir_manager.get_app_directory()?;

// Safely remove directory with retry logic
remove_directory_with_retry(&app_dir)?;
```
