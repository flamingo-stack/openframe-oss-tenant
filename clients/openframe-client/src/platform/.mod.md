This module serves as the main entry point and public interface for system utility functionality, organizing platform-specific and cross-platform utilities for file operations, permissions, and system management.

## Key Components

### Modules
- **`directories`** - Directory management utilities with error handling
- **`file_lock`** - File locking detection and process management (Windows only)
- **`permissions`** - Cross-platform permission handling and capability management
- **`uninstall`** - Directory removal utilities with retry mechanisms
- **`update_scripts`** - Update script management functionality
- **`updater_launcher`** - Application updater launching utilities
- **`user_session`** - User session management tools
- **`windows_cleanup`** - Windows-specific cleanup operations (Windows only)
- **`powershell`** - PowerShell integration utilities (Windows only)

### Re-exported Items
- `DirectoryManager`, `DirectoryError` from directories
- `LockingProcess`, file lock utilities from file_lock (Windows)
- `PermissionUtils`, `Permissions`, `Capability`, `PermissionError` from permissions
- `remove_directory_with_retry` from uninstall
- `get_powershell_path` from powershell (Windows)

## Usage Example

```rust
use crate::utils::{
    DirectoryManager, 
    PermissionUtils, 
    Permissions,
    remove_directory_with_retry
};

// Use directory management
let dir_manager = DirectoryManager::new();

// Check permissions
if PermissionUtils::has_capability(&Permissions::Write, "/some/path") {
    // Safely remove directory with retry logic
    remove_directory_with_retry("/temp/cleanup")?;
}

// Windows-specific usage
#[cfg(target_os = "windows")]
use crate::utils::{get_powershell_path, is_file_in_use_error};
```
