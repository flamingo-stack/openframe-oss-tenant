This module serves as the main utility collection for Flamingo's system operations, providing cross-platform file management, permissions handling, and installation utilities with Windows-specific functionality.

## Key Components

**Core Modules:**
- `directories` - Directory management and path utilities (`DirectoryManager`, `DirectoryError`)
- `permissions` - Cross-platform permission handling (`PermissionUtils`, `Permissions`, `Capability`)
- `file_lock` - File locking detection and process management (Windows-only)
- `uninstall` - Safe directory removal with retry logic
- `update_scripts` - Update mechanism utilities
- `updater_launcher` - Application update launcher
- `user_session` - User session management

**Windows-Specific Modules:**
- `windows_cleanup` - Windows system cleanup operations
- `powershell` - PowerShell integration and path resolution

## Usage Example

```rust
use flamingo_utils::{
    DirectoryManager, 
    PermissionUtils, 
    Permissions,
    remove_directory_with_retry
};

// Cross-platform directory management
let dir_manager = DirectoryManager::new()?;
let app_dir = dir_manager.get_app_directory()?;

// Permission checking
let perms = PermissionUtils::check_permissions(&app_dir)?;
if perms.has_capability(Permissions::Write) {
    // Safe directory removal
    remove_directory_with_retry(&old_version_dir)?;
}

#[cfg(target_os = "windows")]
{
    use flamingo_utils::{get_locking_processes, get_powershell_path};
    
    // Windows-specific operations
    let ps_path = get_powershell_path()?;
    let locks = get_locking_processes(&file_path)?;
}
```
