This Rust module serves as the main entry point for system utilities, providing a unified interface to various OS-specific and cross-platform system operations including directory management, file permissions, and update mechanisms.

## Key Components

### Cross-Platform Modules
- **`directories`** - Directory management utilities with `DirectoryManager` and `DirectoryError`
- **`file_lock`** - File locking detection and process identification
- **`permissions`** - Permission handling with `Permissions`, `PermissionUtils`, and `Capability`
- **`uninstall`** - Safe directory removal with retry logic
- **`update_scripts`** - Update script management
- **`updater_launcher`** - Application updater functionality
- **`user_session`** - User session management

### Windows-Specific Modules
- **`windows_cleanup`** - Windows-specific cleanup operations
- **`powershell`** - PowerShell path resolution and utilities

### Re-exported Items
The module re-exports commonly used types and functions for convenient access, with Windows-specific items conditionally compiled.

## Usage Example

```rust
use system_utils::{DirectoryManager, PermissionUtils, remove_directory_with_retry};

#[cfg(target_os = "windows")]
use system_utils::{get_powershell_path, format_locking_processes};

// Cross-platform usage
let dir_manager = DirectoryManager::new();
let has_admin = PermissionUtils::has_admin_privileges();
remove_directory_with_retry(&path, 3)?;

// Windows-specific usage
#[cfg(target_os = "windows")]
{
    let ps_path = get_powershell_path()?;
    let processes = format_locking_processes(&file_path);
}
```
