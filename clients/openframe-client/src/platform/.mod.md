This module serves as the main entry point for system utilities, organizing platform-specific and cross-platform functionality for directory management, permissions, file operations, and system maintenance tasks.

## Key Components

### Modules
- **`directories`** - Directory management and path utilities
- **`file_lock`** - File locking detection and process management
- **`permissions`** - Permission handling and capability management
- **`uninstall`** - Safe directory removal with retry logic
- **`update_scripts`** - Update script execution utilities
- **`updater_launcher`** - Application updater launching functionality
- **`user_session`** - User session management

### Platform-Specific Modules (Windows Only)
- **`windows_cleanup`** - Windows-specific cleanup operations
- **`powershell`** - PowerShell integration and execution

### Re-exported Items
- `DirectoryManager`, `DirectoryError` from directories
- `PermissionUtils`, `Permissions`, `Capability`, `PermissionError` from permissions
- File locking utilities (Windows only): `format_locking_processes`, `get_locking_processes`, etc.
- `remove_directory_with_retry` from uninstall
- `get_powershell_path` (Windows only) from powershell
