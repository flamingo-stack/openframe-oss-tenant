Module declaration file that exposes utilities for system operations, directory management, and platform-specific functionality. This serves as the main entry point for the `utils` module, organizing submodules and providing convenient re-exports.

## Key Components

### Submodules
- **`directories`** - Directory management and path utilities
- **`file_lock`** - File locking detection and process management (Windows-specific)
- **`permissions`** - User permission checking and capability validation
- **`uninstall`** - Directory removal with retry logic
- **`update_scripts`** - Update script handling
- **`updater_launcher`** - Updater process launching
- **`user_session`** - User session management
- **`windows_cleanup`** - Windows-specific cleanup operations
- **`powershell`** - PowerShell path detection (Windows-specific)

### Re-exported Items
- `DirectoryManager`, `DirectoryError` - Core directory operations
- `PermissionUtils`, `Permissions`, `Capability` - Permission system
- `LockingProcess`, file locking utilities (Windows)
- `remove_directory_with_retry` - Robust directory removal
- `get_powershell_path` - PowerShell detection (Windows)

## Usage Example

```rust
use crate::utils::{
    DirectoryManager, 
    PermissionUtils, 
    remove_directory_with_retry
};

// Use directory management
let dir_manager = DirectoryManager::new();
let temp_path = dir_manager.get_temp_dir()?;

// Check permissions
if PermissionUtils::has_admin_rights() {
    println!("Running with administrative privileges");
}

// Remove directory with retry logic
remove_directory_with_retry(&temp_path)?;
```

The module uses conditional compilation (`#[cfg(target_os = "windows")]`) to include Windows-specific functionality only when building for Windows targets.
