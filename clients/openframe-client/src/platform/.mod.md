Module that organizes utility functionality for the Flamingo MSP platform updater, providing cross-platform system operations, directory management, permissions handling, and Windows-specific cleanup utilities.

## Key Components

- **directories**: Directory management and error handling via `DirectoryManager` and `DirectoryError`
- **file_lock**: File locking detection and process management (Windows-specific)
- **permissions**: Permission utilities with `Permissions`, `PermissionUtils`, and capability management
- **uninstall**: Safe directory removal with retry logic
- **update_scripts**: Update script handling functionality
- **updater_launcher**: Updater process launching utilities
- **user_session**: User session management operations
- **windows_cleanup**: Windows-specific cleanup operations (conditional compilation)
- **powershell**: PowerShell path detection for Windows operations (conditional compilation)

## Usage Example

```rust
use flamingo_updater_utils::{
    DirectoryManager, 
    Permissions, 
    remove_directory_with_retry,
    PermissionError
};

#[cfg(target_os = "windows")]
use flamingo_updater_utils::{
    get_powershell_path,
    is_file_in_use_error,
    format_locking_processes
};

// Cross-platform directory management
let dir_manager = DirectoryManager::new()?;
let permissions = Permissions::new();

// Safe directory removal with retry
remove_directory_with_retry("/path/to/directory")?;

// Windows-specific operations
#[cfg(target_os = "windows")]
{
    let powershell_path = get_powershell_path()?;
    if is_file_in_use_error(&error) {
        let processes = format_locking_processes(&file_path);
    }
}
```

This module serves as the main entry point for updater utilities, providing a clean API surface while keeping platform-specific code conditionally compiled for optimal cross-platform support.
