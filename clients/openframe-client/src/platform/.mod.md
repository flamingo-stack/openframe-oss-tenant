Module organization hub for system utilities and cross-platform filesystem operations. Centralizes imports and provides platform-specific functionality for Windows and Unix-like systems.

## Key Components

### Core Modules
- **directories** - Directory management and path utilities (`DirectoryManager`, `DirectoryError`)
- **permissions** - Permission handling and capability management (`PermissionUtils`, `Permissions`, `Capability`)
- **file_lock** - File locking detection and process identification (Windows-specific)
- **uninstall** - Safe directory removal with retry mechanisms
- **update_scripts** - Application update functionality
- **updater_launcher** - Update process orchestration
- **user_session** - User session management utilities

### Platform-Specific Modules
- **windows_cleanup** - Windows-specific cleanup operations
- **powershell** - PowerShell integration for Windows systems
