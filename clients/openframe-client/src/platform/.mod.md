This module serves as the main entry point for system utilities, providing cross-platform functionality for file operations, permissions management, and system maintenance tasks.

## Key Components

**Core Modules:**
- `directories` - Directory management and path utilities
- `file_lock` - File locking detection and process management  
- `permissions` - Cross-platform permission handling
- `uninstall` - Safe directory removal with retry logic
- `update_scripts` - Update mechanism utilities
- `updater_launcher` - Application updater functionality
- `user_session` - User session management

**Windows-Specific Modules:**
- `windows_cleanup` - Windows-specific cleanup operations
- `powershell` - PowerShell integration utilities

**Re-exported Types:**
- `DirectoryManager` and `DirectoryError` for directory operations
- `PermissionUtils`, `Permissions`, and `Capability` for permission management
- `LockingProcess` and file lock utilities (Windows only)
- `get_powershell_path` for PowerShell detection (Windows only)

## Usage Example

```rust
use crate::system_utils::{
    DirectoryManager, 
    PermissionUtils, 
    remove_directory_with_retry
};

// Directory management
let dir_manager = DirectoryManager::new()?;
let app_dir = dir_manager.get_app_directory()?;

// Permission checking
if PermissionUtils::has_admin_privileges() {
    println!("Running with admin privileges");
}

// Safe directory removal
remove_directory_with_retry(&app_dir, 3)?;
```

The module uses conditional compilation to include Windows-specific functionality only on Windows targets, ensuring clean cross-platform builds.
