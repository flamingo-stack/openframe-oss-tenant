A module definition file that organizes and re-exports utilities for system operations including directory management, file locking, permissions, and platform-specific functionality.

## Key Components

- **Core Modules**: `directories`, `file_lock`, `permissions`, `uninstall`, `update_scripts`, `updater_launcher`, `user_session`
- **Windows-specific Modules**: `windows_cleanup`, `powershell` (conditionally compiled)
- **Re-exported Types**: `DirectoryManager`, `PermissionUtils`, `Capability`, and Windows-specific file locking utilities
- **Cross-platform Design**: Uses conditional compilation for OS-specific features

## Usage Example

```rust
use flamingo_utils::{
    DirectoryManager, 
    PermissionUtils, 
    Permissions,
    remove_directory_with_retry
};

// Use directory management
let dir_manager = DirectoryManager::new()?;
let app_dir = dir_manager.get_app_directory()?;

// Check permissions
let perms = PermissionUtils::check_permissions(&app_dir)?;
if perms.has_capability(Capability::Write) {
    // Perform operations
}

// Clean up with retry logic
remove_directory_with_retry(&temp_dir)?;

#[cfg(target_os = "windows")]
{
    use flamingo_utils::{get_locking_processes, get_powershell_path};
    
    // Windows-specific operations
    let processes = get_locking_processes(&file_path)?;
    let ps_path = get_powershell_path()?;
}
```
