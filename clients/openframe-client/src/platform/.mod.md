Barrel module (mod.rs) for the platform utilities crate, organizing and re-exporting cross-platform and OS-specific modules for managing software installation, updates, permissions, and system services.

## Key Components

**Cross-platform modules:**
- `binary_writer` — `write_executable`, `set_executable_permissions`
- `directories` — `DirectoryManager`, `DirectoryError`
- `dmg_extractor` — `DmgExtractor` (macOS DMG handling)
- `file_acl` — File access control list utilities
- `file_lock` — File locking detection and process enumeration
- `installation_detector` — `detect_actual_installation`
- `permissions` — `Permissions`, `PermissionUtils`, `Capability`, `PermissionError`
- `system_service` — System service management
- `tool_updater` — `ToolUpdater`, `UpdateContext`, `create_updater`, `create_migrator`, `run_update`, `run_migration`, `needs_migration`
- `uninstall` — `orbit_dir`, `remove_directory_with_retry`
- `update_scripts` / `updater_launcher` / `user_session` — Update orchestration helpers

**macOS-only (`#[cfg(target_os = "macos")]`):**
- `preferences_writer` — macOS preferences plist management
- `remove_app_bundle`, `remove_app_bundle_path` from `directories`

**Windows-only (`#[cfg(target_os = "windows")]`):**
- `windows_cleanup`, `windows_path_migration`, `powershell`
- `get_powershell_path`, file lock diagnostics (`LockingProcess`, `get_locking_processes`, etc.)

## Usage Example

```rust
use platform_utils::{
    DirectoryManager,
    ToolUpdater,
    create_updater,
    run_update,
    UpdateContext,
    detect_actual_installation,
    write_executable,
};

// Detect existing installation
let install_path = detect_actual_installation(&config)?;

// Write and permission an executable
write_executable(&binary_bytes, &install_path)?;

// Build and run an updater
let updater = create_updater(deps);
run_update(&updater, &UpdateContext::new(version)).await?;

// Windows-only: check for file lock conflicts
#[cfg(target_os = "windows")]
{
    use platform_utils::{get_locking_processes, format_locking_processes};
    if let Some(procs) = get_locking_processes(&target_file) {
        eprintln!("{}", format_locking_processes(&procs));
    }
}
```
