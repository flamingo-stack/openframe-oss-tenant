A module organization file that exposes utility modules for system operations including directory management, file locking, permissions, and platform-specific functionality.

## Key Components

### Core Modules
- **directories** - Directory management utilities (exported as `DirectoryManager`, `DirectoryError`)
- **file_lock** - File locking detection and process management (Windows only)
- **permissions** - Permission handling with `PermissionUtils`, `Permissions`, and `Capability`
- **uninstall** - Directory removal utilities (exports `remove_directory_with_retry`)
- **update_scripts** - Update script management
- **updater_launcher** - Updater application launcher
- **user_session** - User session management

### Platform-Specific Modules (Windows)
- **windows_cleanup** - Windows-specific cleanup operations
- **powershell** - PowerShell utilities (exports `get_powershell_path`)

## Usage Example

```rust
use crate::utils::{
    DirectoryManager, 
    PermissionUtils, 
    remove_directory_with_retry
};

#[cfg(target_os = "windows")]
use crate::utils::{get_powershell_path, is_file_in_use_error};

// Cross-platform usage
let dir_manager = DirectoryManager::new();
let permissions = PermissionUtils::check_write_access("/path/to/dir")?;

// Windows-specific functionality
#[cfg(target_os = "windows")]
let powershell_path = get_powershell_path();
```

The module provides a clean interface for system utilities with automatic platform detection and appropriate feature gating for Windows-specific functionality.
