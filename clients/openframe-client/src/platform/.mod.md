Barrel module for platform utilities used in the Flamingo/OpenFrame installer and updater toolchain, re-exporting commonly used types and functions across OS-aware submodules.

## Key Components

| Module | Purpose |
|---|---|
| `binary_writer` | Write and chmod executable binaries |
| `console` | Terminal/console configuration |
| `directories` | Directory management and error types |
| `dmg_extractor` | macOS DMG archive extraction |
| `file_acl` | File access control lists |
| `file_lock` | Windows file lock detection and diagnostics |
| `installation_detector` | Detect existing installations on disk |
| `machine_info_persistence` | Persist machine metadata |
| `permissions` | Cross-platform permission utilities and capability model |
| `system_service` | OS-level service management |
| `tool_updater` | Core update/migration orchestration |
| `uninstall` | Directory removal with retry logic |
| `update_scripts` | Scripted update hooks |
| `updater_launcher` | Spawns the updater process |
| `user_session` | User session detection |
| `preferences_writer` | macOS preferences plist writer *(macOS only)* |
| `windows_cleanup` | Post-update cleanup *(Windows only)* |
| `windows_path_migration` | PATH variable migration *(Windows only)* |
| `powershell` | PowerShell path resolution *(Windows only)* |

## Usage Example

```rust
use crate::platform::{
    DirectoryManager,
    PermissionUtils,
    create_updater,
    run_update,
    UpdateContext,
};

// Resolve update context and run an update
let updater = create_updater(deps);
run_update(&updater, context).await?;

// Remove a directory with retry on locked files
use crate::platform::remove_directory_with_retry;
remove_directory_with_retry(&orbit_dir())?;

// Windows-only: inspect file locks before overwrite
#[cfg(target_os = "windows")]
{
    use crate::platform::{get_locking_processes, log_file_lock_info};
    let locks = get_locking_processes(&path)?;
    log_file_lock_info(&locks);
}
```

## Notes

- Platform-specific modules are gated with `#[cfg(target_os = "...")]` — compilation is safe across all targets.
- See [`tool_updater`](https://github.com/flamingo-stack/openframe-oss-tenant/blob/main/src/platform/tool_updater.rs) for the primary update/migration entry points.
