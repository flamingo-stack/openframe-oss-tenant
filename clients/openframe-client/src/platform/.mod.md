Module declaration file that exposes utility modules for system operations, directory management, and cross-platform compatibility. This serves as the main interface for accessing various system-level utilities with conditional compilation for Windows-specific functionality.

## Key Components

- **directories**: Directory management utilities with `DirectoryManager` and `DirectoryError`
- **file_lock**: File locking detection and process management (Windows-only)
- **permissions**: Cross-platform permission handling with `PermissionUtils` and `Capability`
- **uninstall**: Directory removal utilities with retry logic
- **update_scripts**: Update script management functionality
- **updater_launcher**: Launcher utilities for update processes
- **user_session**: User session management utilities
- **windows_cleanup**: Windows-specific cleanup operations (Windows-only)
- **powershell**: PowerShell path detection utilities (Windows-only)

## Usage Example

```rust
use crate::utils::{
    DirectoryManager,
    PermissionUtils,
    Permissions,
    remove_directory_with_retry
};

#[cfg(target_os = "windows")]
use crate::utils::{
    get_locking_processes,
    get_powershell_path,
    format_locking_processes
};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    // Cross-platform directory management
    let dir_manager = DirectoryManager::new()?;
    
    // Check permissions
    let perms = PermissionUtils::check_permissions("/some/path")?;
    
    // Remove directory with retry logic
    remove_directory_with_retry("/temp/dir")?;
    
    #[cfg(target_os = "windows")]
    {
        // Windows-specific operations
        let ps_path = get_powershell_path()?;
        let locking_procs = get_locking_processes("file.exe")?;
    }
    
    Ok(())
}
```
