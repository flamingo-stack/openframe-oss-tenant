This module serves as the main entry point for system utilities, providing cross-platform functionality for file operations, permissions, and system management with Windows-specific extensions.

## Key Components

**Core Modules:**
- `DirectoryManager` - Directory creation, validation, and management
- `PermissionUtils` - Cross-platform permission handling and capability checking
- `file_lock` - File locking detection and process management
- `updater_launcher` - Application update orchestration
- `user_session` - User session and environment management

**Windows-Specific Modules:**
- `windows_cleanup` - Windows-specific cleanup operations
- `powershell` - PowerShell execution and path resolution

**Re-exported Types:**
- `DirectoryError`, `PermissionError` - Error handling for system operations
- `Capability`, `Permissions` - Permission management abstractions
- `LockingProcess` - File lock process information

## Usage Example

```rust
use system_utils::{
    DirectoryManager, 
    PermissionUtils, 
    Permissions,
    remove_directory_with_retry
};

// Create and manage directories
let dir_manager = DirectoryManager::new();
dir_manager.ensure_directory_exists("/app/data")?;

// Check permissions
if PermissionUtils::has_capability(Permissions::WriteFiles) {
    // Perform file operations
    remove_directory_with_retry("/temp/old_data", 3)?;
}

#[cfg(target_os = "windows")]
{
    use system_utils::{get_powershell_path, get_locking_processes};
    
    // Windows-specific operations
    let ps_path = get_powershell_path()?;
    let processes = get_locking_processes("C:\\app\\config.json")?;
}
```
