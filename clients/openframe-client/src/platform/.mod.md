This module serves as the main entry point for system utility functions, organizing platform-specific and cross-platform utilities for file management, permissions, and system operations.

## Key Components

**Cross-platform modules:**
- `DirectoryManager` - Directory creation, validation, and management
- `PermissionUtils` - File/directory permission handling and capability checking
- `file_lock` - File locking detection and process identification
- `uninstall` - Safe directory removal with retry logic
- `update_scripts` - Update script management and execution
- `updater_launcher` - Application updater launching utilities
- `user_session` - User session management and detection

**Windows-specific modules:**
- `windows_cleanup` - Windows-specific cleanup operations
- `powershell` - PowerShell path detection and execution utilities

**Re-exported types:**
- `DirectoryError`, `PermissionError` - Common error types
- `Capability`, `Permissions` - Permission-related enums and structs
- `LockingProcess` - File lock information structure

## Usage Example

```rust
use system_utils::{
    DirectoryManager, 
    PermissionUtils, 
    Capability,
    remove_directory_with_retry
};

// Create and manage directories
let dir_manager = DirectoryManager::new();
dir_manager.ensure_directory("/path/to/app")?;

// Check permissions
if PermissionUtils::has_capability(Capability::WriteFile) {
    // Perform file operations
}

// Safe directory removal
remove_directory_with_retry("/tmp/old_install", 3)?;

#[cfg(target_os = "windows")]
use system_utils::{get_powershell_path, get_locking_processes};

#[cfg(target_os = "windows")]
{
    let ps_path = get_powershell_path()?;
    let processes = get_locking_processes("C:\\app\\file.exe")?;
}
```
