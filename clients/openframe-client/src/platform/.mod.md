Module registry for the system utilities library, aggregating submodules for installation, update, and platform-specific OS operations across macOS and Windows.

## Key Components

| Module | Description |
|--------|-------------|
| `binary_writer` | Writes and sets permissions on executable binaries |
| `directories` | Directory management and error handling (`DirectoryManager`, `DirectoryError`) |
| `dmg_extractor` | macOS DMG archive extraction |
| `file_lock` | Windows file locking detection and process inspection |
| `installation_detector` | Detects actual tool installation state |
| `permissions` | Cross-platform capability and permission management |
| `system_service` | OS-level service interactions |
| `tool_updater` | Core update/migration orchestration (`ToolUpdater`, `UpdateContext`) |
| `uninstall` | Safe directory removal with retry logic |
| `update_scripts` | Update script execution |
| `updater_launcher` | Launches the updater process |
| `user_session` | User session utilities |
| `preferences_writer` | macOS-only preferences file writer |
| `windows_cleanup` | Windows-only cleanup routines |
| `windows_path_migration` | Windows-only PATH migration helpers |
| `powershell` | Windows-only PowerShell path resolution |

## Usage Example

```rust
use crate::utils::{
    DirectoryManager,
    PermissionUtils,
    detect_actual_installation,
    create_updater,
    run_update,
    UpdateContext,
};

// Detect current installation state
let installed = detect_actual_installation(&install_path)?;

// Create and run an updater
let updater = create_updater(deps);
let ctx = UpdateContext { /* ... */ };
run_update(&updater, &ctx).await?;

// Windows-only: resolve PowerShell
#[cfg(target_os = "windows")]
let ps_path = get_powershell_path()?;
```

## Platform-Conditional Exports

Re-exports are gated via `#[cfg(...)]` to ensure only relevant symbols are exposed per target OS, preventing accidental cross-platform API misuse at compile time.
