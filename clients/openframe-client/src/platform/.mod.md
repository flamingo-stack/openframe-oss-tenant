This module serves as the main entry point for the utilities package, organizing system-level functionality and providing convenient re-exports of commonly used items across different operating system platforms.

## Key Components

- **directories**: Directory management operations with `DirectoryManager` and error handling
- **file_lock**: File locking detection and process identification (Windows-specific)
- **permissions**: Cross-platform permission utilities with `PermissionUtils` and capability checking
- **uninstall**: Safe directory removal with retry logic
- **update_scripts**: Update script management functionality
- **updater_launcher**: Application updater launching utilities
- **user_session**: User session management operations
- **windows_cleanup**: Windows-specific cleanup operations (conditional compilation)
- **powershell**: PowerShell path detection utilities (Windows-specific)

The module uses conditional compilation (`#[cfg(target_os = "windows")]`) to include Windows-specific functionality only when building for Windows targets.

## Usage Example

```rust
use utils::{
    DirectoryManager, 
    PermissionUtils, 
    Permissions,
    remove_directory_with_retry
};

#[cfg(target_os = "windows")]
use utils::{get_powershell_path, get_locking_processes};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    // Cross-platform directory management
    let dir_manager = DirectoryManager::new();
    
    // Check permissions
    let perms = PermissionUtils::check_current_permissions()?;
    if perms.contains(Permissions::WRITE) {
        remove_directory_with_retry("/tmp/old_data")?;
    }
    
    // Windows-specific operations
    #[cfg(target_os = "windows")]
    {
        let ps_path = get_powershell_path()?;
        println!("PowerShell found at: {}", ps_path);
    }
    
    Ok(())
}
```
