Cross-platform file permission management and privilege escalation utilities for Unix, macOS, Linux, and Windows systems.

## Key Components

### `PermissionError`
Enum covering all error variants: `Io`, `InvalidMode`, `InvalidPath`, `AdminCheckFailed`, `ElevationRequired`, and `CommandFailed`.

### `Permissions`
Struct holding a Unix-style octal `mode` value with cross-platform abstractions:
- `Permissions::directory()` — returns mode `0o755`
- `Permissions::file()` — returns mode `0o644`
- `apply(&self, path)` — sets permissions on a path (Unix: `PermissionsExt`; Windows: readonly flag)
- `verify(&self, path)` — checks if path matches expected permissions
- `from_path(path)` — reads current permissions from an existing path

### `PermissionUtils`
Stateless utility struct for privilege management:
- `is_admin()` — checks if process has root/admin privileges (Unix: `geteuid()`; Windows: `is_elevated`)
- `ensure_admin()` — requests elevation if not already admin; platform-specific mechanisms:
  - **macOS**: `osascript` with AppleScript GUI prompt
  - **Linux**: `pkexec` with `sudo` fallback
  - **Windows**: `ShellExecuteW` with `runas` verb (UAC)

### `ADMIN_PRIVILEGES_GRANTED`
`AtomicBool` flag caching whether elevation was already obtained in the current session, avoiding redundant privilege prompts.

## Usage Example

```rust
use std::path::Path;

// Check and request admin privileges
PermissionUtils::ensure_admin()?;

// Apply standard directory permissions
let path = Path::new("/opt/openframe/config");
Permissions::directory().apply(path)?;

// Apply standard file permissions
let file = Path::new("/opt/openframe/config/settings.toml");
Permissions::file().apply(file)?;

// Verify permissions match expected mode
let ok = Permissions::file().verify(file)?;
assert!(ok);

// Read permissions from an existing path
let perms = Permissions::from_path(file)?;
println!("Current mode: {:o}", perms.mode);
```
