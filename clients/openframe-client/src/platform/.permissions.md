Cross-platform file permission management and privilege escalation utilities for Unix, macOS, Windows, and Linux systems.

## Key Components

### `PermissionError`
An enum covering all failure modes: `Io`, `InvalidMode`, `InvalidPath`, `AdminCheckFailed`, `ElevationRequired`, and `CommandFailed`. Implements `std::error::Error` and converts from `io::Error`.

### `Permissions`
A struct wrapping a Unix-style octal mode (`u32`) with the following methods:

| Method | Description |
|---|---|
| `directory()` | Returns `0o755` (standard directory permissions) |
| `file()` | Returns `0o644` (standard file permissions) |
| `apply(&Path)` | Sets permissions on a path (Unix: `PermissionsExt`; Windows: readonly flag) |
| `verify(&Path)` | Checks if a path matches the expected mode |
| `from_path(&Path)` | Reads current permissions from an existing path |

### `PermissionUtils`
Stateless utility struct for privilege management:

| Method | Description |
|---|---|
| `is_admin()` | Returns `true` if running as root/admin (Unix: `geteuid()`; Windows: `is_elevated`) |
| `ensure_admin()` | Requests elevation if not already privileged (macOS: `osascript`; Linux: `pkexec`/`sudo`; Windows: `ShellExecuteW` with `runas`) |

### `ADMIN_PRIVILEGES_GRANTED`
A static `AtomicBool` used to cache privilege state within a session, avoiding redundant elevation prompts.

## Usage Example

```rust
use std::path::Path;
use permissions::{Permissions, PermissionUtils};

fn setup_config_file(path: &Path) -> Result<(), Box<dyn std::error::Error>> {
    // Ensure we have admin rights before touching system paths
    PermissionUtils::ensure_admin()?;

    // Apply standard file permissions (0o644)
    let perms = Permissions::file();
    perms.apply(path)?;

    // Verify they were set correctly
    if perms.verify(path)? {
        println!("Permissions set successfully");
    }

    Ok(())
}
```
