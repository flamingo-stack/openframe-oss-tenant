Cross-platform file permission management and privilege escalation utilities for Unix, macOS, Linux, and Windows systems.

## Key Components

### `PermissionError`
Enum covering all failure modes: `Io`, `InvalidMode`, `InvalidPath`, `AdminCheckFailed`, `ElevationRequired`, and `CommandFailed`.

### `Permissions`
Struct holding a Unix-style octal mode (`u32`) with platform-aware apply/verify logic.

| Method | Description |
|--------|-------------|
| `directory()` | Returns `0o755` standard directory permissions |
| `file()` | Returns `0o644` standard file permissions |
| `apply(&Path)` | Sets permissions on a path (Unix: `PermissionsExt`; Windows: readonly flag) |
| `verify(&Path)` | Checks whether current path permissions match the stored mode |
| `from_path(&Path)` | Reads permissions from an existing path into a `Permissions` instance |

### `PermissionUtils`
Stateless utility struct for privilege management, backed by a static `AtomicBool` (`ADMIN_PRIVILEGES_GRANTED`) to cache elevation state within a session.

| Method | Description |
|--------|-------------|
| `is_admin()` | Checks root/admin status via `libc::geteuid()` (Unix) or `is_elevated` (Windows) |
| `ensure_admin()` | Requests elevation if needed — `osascript` (macOS), `pkexec`/`sudo` (Linux), `ShellExecuteW` UAC (Windows) |

## Usage Example

```rust
use std::path::Path;

// Apply standard file permissions
let perms = Permissions::file();
perms.apply(Path::new("/etc/myapp/config.toml"))?;

// Verify permissions match expected mode
let ok = perms.verify(Path::new("/etc/myapp/config.toml"))?;

// Ensure the process has admin/root privileges before privileged operations
PermissionUtils::ensure_admin()?;

// Read existing permissions from a path
let existing = Permissions::from_path(Path::new("/var/log/app.log"))?;
println!("Current mode: {:o}", existing.mode);
```
