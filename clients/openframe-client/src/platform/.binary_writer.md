Async utility for writing binary executable files to disk with cross-platform permission handling and locked-file recovery.

## Key Components

### `write_executable(bytes: &[u8], path: &Path) -> Result<()>`
Writes raw bytes to a file path and marks it executable. Handles three scenarios:
- Creates any missing parent directories automatically
- On first write failure, attempts lock/permission recovery via `crate::platform::file_acl::ensure_writable`
- **Windows-specific:** Moves a locked file to `.old` before retrying creation

### `set_executable_permissions(path: &Path) -> Result<()>`
- **Unix:** Sets file mode to `0o755` (rwxr-xr-x)
- **Non-Unix:** No-op (suppresses unused variable warning)

## Usage Example

```rust
use std::path::Path;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let binary_data = std::fs::read("agent.bin")?;
    let target = Path::new("/usr/local/bin/mingo-agent");

    // Write binary and set executable permissions in one call
    write_executable(&binary_data, target).await?;

    // Or set permissions on an already-existing file
    set_executable_permissions(target).await?;

    Ok(())
}
```

## Notes

- Both functions are `async` and require a Tokio runtime
- Errors are enriched with path context via `anyhow`
- Recovery behavior is platform-gated at compile time (`#[cfg(target_os = "windows")]`, `#[cfg(target_family = "unix")]`)
- Write success is logged at `INFO` level; recovery attempts log at `WARN`
