Provides async utilities for writing binary executable files to disk, including directory creation and platform-appropriate permission setting.

## Key Components

### `write_executable(bytes, path) -> Result<()>`
Async function that writes raw bytes to the specified path as an executable file. Automatically creates any missing parent directories, writes the binary content, applies executable permissions, and logs the result.

### `set_executable_permissions(path) -> Result<()>`
Async function that sets executable permissions (`0o755`) on a file. Platform-aware via conditional compilation:
- **Unix**: Applies `rwxr-xr-x` permissions using `PermissionsExt`
- **Non-Unix (Windows)**: No-op, suppresses unused variable warning

## Usage Example

```rust
use std::path::Path;
use binary_writer::{write_executable, set_executable_permissions};

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let binary_bytes = std::fs::read("agent-binary")?;
    let target_path = Path::new("/usr/local/bin/my-agent");

    // Write bytes and auto-apply executable permissions
    write_executable(&binary_bytes, target_path).await?;

    // Or just fix permissions on an existing file
    set_executable_permissions(target_path).await?;

    Ok(())
}
```

## Notes

- Uses `tokio` for fully async I/O — must be called within a Tokio runtime
- Error messages include the target path for easy debugging via `anyhow::Context`
- Logs binary path and size at `INFO` level via `tracing` upon successful write
