Async utility for writing binary executable files to disk with cross-platform permission handling and locked-file recovery.

## Key Components

- **`write_executable(bytes, path)`** — Async function that writes raw bytes to a path as an executable. Handles parent directory creation, Windows locked-file recovery (renaming the existing file to `.old` before retrying), and sets executable permissions after writing.

- **`set_executable_permissions(path)`** — Sets Unix file permissions to `0o755` (rwxr-xr-x). No-ops silently on non-Unix platforms.

## Usage Example

```rust
use std::path::Path;
use binary_writer::{write_executable, set_executable_permissions};

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let binary_data = download_agent_binary().await?;
    let target = Path::new("/usr/local/bin/flamingo-agent");

    // Write bytes and auto-set executable permissions
    write_executable(&binary_data, target).await?;

    // Or set permissions on an already-existing file
    set_executable_permissions(target).await?;

    Ok(())
}
```

## Platform Behavior

| Platform | Locked file recovery | Permissions |
|----------|----------------------|-------------|
| Unix/macOS | ACL unlock via `ensure_writable` | `chmod 0o755` |
| Windows | Rename to `.old`, retry create | No-op |

## Notes

- Parent directories are created automatically via `create_dir_all`
- On Windows, if the target file is locked, it is moved to `<name>.old` before the write is retried
- All errors include contextual path information via `anyhow::Context`
