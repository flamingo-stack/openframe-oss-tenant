Async utility for writing binary executable files to disk with cross-platform permission handling and locked-file recovery.

## Key Components

### `write_executable(bytes, path) -> Result<()>`
Writes raw bytes to the specified path as an executable file. Handles:
- **Directory creation** — auto-creates missing parent directories
- **Lock/permission recovery** — on first write failure, calls `platform::file_acl::ensure_writable` and retries
- **Windows locked-file workaround** — renames the existing locked file to `.old` before creating a fresh file at the original path
- **Permission setting** — delegates to `set_executable_permissions` after a successful write

### `set_executable_permissions(path) -> Result<()>`
Sets Unix file permissions to `0o755` (rwxr-xr-x). Compiled out on non-Unix targets (no-op on Windows).

## Usage Example

```rust
use std::path::Path;

let binary_bytes = download_agent_binary().await?;
let target = Path::new("/usr/local/bin/flamingo-agent");

write_executable(&binary_bytes, target).await?;
// Parent dirs created, bytes written, chmod 755 applied (Unix)
```

```rust
// Standalone permission fix on an already-written file
let path = Path::new("/opt/openframe/bin/agent");
set_executable_permissions(path).await?;
```

## Notes

- Requires `tokio` async runtime
- Windows recovery path depends on `crate::platform::file_acl::ensure_writable`
- Failures at each stage include the file path in the error context for easy debugging
- All write/permission operations are logged via `tracing` (`info!` on success, `warn!` on recoverable errors)
