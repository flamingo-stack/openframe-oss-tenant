Cross-platform entry point for the updater launcher module, defining shared parameters and re-exporting the platform-specific `launch_updater` function for Windows, macOS, and Linux.

## Key Components

### `UpdaterParams`
A struct encapsulating all parameters required to launch the updater process:

| Field | Type | Description |
|---|---|---|
| `binary_path` | `PathBuf` | Path to the updater binary to execute |
| `target_exe` | `PathBuf` | Path to the executable being updated |
| `service_name` | `String` | Name of the service being managed |
| `update_state_path` | `String` | Path to the update state file |
| `target_version` | `String` | Version string to update to |
| `boot_marker_path` | `PathBuf` | Path to the boot marker file |
| `lkg_path` | `PathBuf` | Path to the Last Known Good (LKG) backup |
| `transcript_path` | `PathBuf` | Path for updater transcript/log output |
| `rollback_only` | `bool` | When `true`, performs rollback instead of update |

### `launch_updater` (platform-specific re-export)
Conditionally compiled and re-exported from `windows`, `macos`, or `linux` submodules depending on the build target.

## Usage Example

```rust
use std::path::PathBuf;
use crate::updater_launcher::{UpdaterParams, launch_updater};

let params = UpdaterParams {
    binary_path: PathBuf::from("/usr/local/bin/updater"),
    target_exe: PathBuf::from("/usr/local/bin/agent"),
    service_name: "openframe-agent".to_string(),
    update_state_path: "/var/lib/openframe/update_state.json".to_string(),
    target_version: "1.2.3".to_string(),
    boot_marker_path: PathBuf::from("/var/lib/openframe/.boot_marker"),
    lkg_path: PathBuf::from("/var/lib/openframe/lkg/agent"),
    transcript_path: PathBuf::from("/var/log/openframe/update.log"),
    rollback_only: false,
};

launch_updater(params)?;
```
