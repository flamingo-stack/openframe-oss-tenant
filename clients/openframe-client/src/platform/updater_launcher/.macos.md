Handles macOS-specific update execution by writing a bash updater script to a temp file and registering it as a one-shot `launchd` job, ensuring the update process survives the service being stopped.

## Key Components

### `launch_updater(params: UpdaterParams) -> Result<()>`

Async function that orchestrates the macOS update launch sequence:

1. Writes `UPDATE_SCRIPT_MACOS` to a UUID-named temp file (e.g., `openframe-updater-<uuid>.sh`) with `0o755` permissions
2. Populates `UPDATER_PLIST_TEMPLATE` with runtime parameters via string replacement
3. Removes any stale `com.openframe.updater` launchd job from a previous failed update
4. Writes the plist to `/tmp/com.openframe.updater.plist` and loads it via `launchctl load`

**Key template substitutions in the plist:**

| Placeholder | Source |
|---|---|
| `{SCRIPT_PATH}` | Temp script path |
| `{BINARY_PATH}` | `params.binary_path` |
| `{SERVICE_LABEL}` | `params.service_name` |
| `{TARGET_EXE}` | `params.target_exe` |
| `{UPDATE_STATE_PATH}` | `params.update_state_path` |
| `{BOOT_MARKER_WAIT_SECS}` | `BOOT_MARKER_WAIT_SECS` config constant |
| `{ROLLBACK_ONLY}` | `"1"` or `"0"` |

## Usage Example

```rust
use crate::platform::macos::launch_updater;
use crate::updater::UpdaterParams;

let params = UpdaterParams {
    binary_path: PathBuf::from("/usr/local/bin/openframe-new"),
    service_name: "com.openframe.agent".to_string(),
    target_exe: PathBuf::from("/usr/local/bin/openframe"),
    update_state_path: "/var/openframe/update.state".to_string(),
    target_version: "1.2.3".to_string(),
    boot_marker_path: PathBuf::from("/var/openframe/boot.marker"),
    lkg_path: PathBuf::from("/var/openframe/lkg"),
    transcript_path: PathBuf::from("/var/log/openframe/update.log"),
    rollback_only: false,
};

launch_updater(params).await?;
```

> **Note:** The launchd job approach is intentional — it decouples the update script lifetime from the running service, allowing the script to continue executing after `launchctl stop` terminates the agent.
