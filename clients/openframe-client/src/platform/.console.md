Provides cross-platform console configuration, enabling UTF-8 output and ANSI/virtual terminal processing on Windows while remaining a no-op on other platforms.

## Key Components

- **`configure_console()`** — Public function with two platform-specific implementations:
  - **Non-Windows:** Empty no-op stub (zero overhead).
  - **Windows:** Enables `ENABLE_VIRTUAL_TERMINAL_PROCESSING` on stdout (allowing ANSI escape codes/colors) and sets the console output code page to UTF-8 (`CP_UTF8` = 65001) via the `winapi` crate.

## Usage Example

```rust
use crate::console::configure_console;

fn main() {
    // Call once at startup before any terminal output
    configure_console();

    println!("\x1b[32mGreen text works on Windows too!\x1b[0m");
}
```

## Notes

- Must be called early in `main()` before any terminal output to ensure ANSI sequences render correctly.
- On Windows, uses `unsafe` FFI calls via [`winapi`](https://docs.rs/winapi) (`GetConsoleMode`, `SetConsoleMode`, `SetConsoleOutputCP`).
- Gracefully handles the case where stdout is not a console (e.g., piped output) — `GetConsoleMode` returning `0` skips the `SetConsoleMode` call.
