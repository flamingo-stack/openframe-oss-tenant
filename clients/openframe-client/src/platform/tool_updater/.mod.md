The tool updater module orchestrates the update and migration lifecycle for installed tools, providing a trait-based abstraction over different installation types (standard binaries, macOS GUI apps, and system services).

## Key Components

### Types & Traits

| Item | Description |
|------|-------------|
| `ToolUpdater` | Core async trait defining `prepare` → `apply` → `finalize` → `rollback` lifecycle |
| `UpdateContext` | Carries update state: optional backup path and restart flag |
| `ToolUpdaterDeps` | Dependency bundle injected into all updater implementations |
| `UnsupportedToolUpdater` | Non-macOS stub that bails immediately (non-macOS platforms only) |

### Public Exports

| Item | Source |
|------|--------|
| `StandardToolUpdater` | `standard` submodule |
| `GuiAppToolUpdater` | `gui_app` submodule (macOS only) |
| `ServiceToolUpdater` | `service` submodule |
| `ToolMigrator`, `MigrationContext`, `create_migrator`, `needs_migration` | `migration` submodule |

### Top-Level Functions

| Function | Description |
|----------|-------------|
| `create_updater` | Factory that dispatches to the correct updater based on `Installation` variant |
| `run_update` | Runs the full prepare → apply → finalize pipeline with automatic rollback on failure |
| `run_migration` | Runs the full migration pipeline between installation types with rollback |
| `backup_binary` | Copies an existing binary to `.backup` before replacement |
| `download_and_write_binary` | Downloads via GitHub service and writes an executable to disk |
| `cleanup_backup` | Removes a backup file after successful update |
| `restore_from_backup` | Copies backup back to target path and removes the backup file |

## Usage Example

```rust
use updater::{run_update, run_migration, ToolUpdaterDeps, create_updater};

// Standard update
let new_installation = run_update(&installed_tool, &download_config, deps.clone()).await?;

// Migration from Standard -> Service
let migrated = run_migration(
    &installed_tool,
    &download_config,
    InstallationType::Service,
    deps,
).await?;

// Manual updater dispatch
let updater = create_updater(&installed_tool.installation, deps);
let ctx = updater.prepare(&installed_tool).await?;
updater.apply(&installed_tool, &download_config, &ctx).await?;
updater.finalize(&installed_tool, &ctx).await?;
```

> **Platform note:** `GuiAppToolUpdater` is compiled only on macOS (`#[cfg(target_os = "macos")]`). On other platforms, `GuiApp` installations fall back to `StandardToolUpdater`.
