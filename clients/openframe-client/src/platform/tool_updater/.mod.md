Tool updater module that defines the core update/migration pipeline for installed tools, including the `ToolUpdater` trait, update context, and shared utility functions for binary backup, download, and restoration.

## Key Components

- **`ToolUpdater` trait** — Async trait defining the four-phase update lifecycle: `prepare`, `apply`, `finalize`, and `rollback`
- **`UpdateContext`** — Carries state between update phases (backup path, restart flag)
- **`ToolUpdaterDeps`** — Dependency bundle passed to all updater implementations (GitHub download, kill service, run manager, etc.)
- **`create_updater()`** — Factory that selects the appropriate updater based on `Installation` type (`Standard`, `GuiApp`, `Service`)
- **`run_update()`** — Orchestrates the full update pipeline with automatic rollback on failure
- **`run_migration()`** — Orchestrates installation-type migration (e.g. `Standard` → `Service`) with rollback support
- **`UnsupportedToolUpdater`** — Non-macOS stub that always returns an error (used for unimplemented platform variants)
- **Shared helpers** (`pub(crate)`) — `backup_binary`, `download_and_write_binary`, `cleanup_backup`, `restore_from_backup`

## Usage Example

```rust
// Run a standard tool update with automatic rollback on failure
let deps = ToolUpdaterDeps {
    github_download_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    command_params_resolver,
};

run_update(&installed_tool, &download_config, deps.clone()).await?;

// Migrate a tool from Standard to Service installation type
let new_installation = run_migration(
    &installed_tool,
    &download_config,
    InstallationType::Service,
    deps,
).await?;
```
