Implements the `GuiAppToolUpdater`, which handles the full update lifecycle (prepare → apply → finalize → rollback) for macOS GUI application bundles managed by the OpenFrame platform.

## Key Components

### `GuiAppToolUpdater`

A struct implementing the `ToolUpdater` trait for `Installation::GuiApp` tool types. Constructed via `new(deps: ToolUpdaterDeps)`.

### Trait Methods

| Method | Responsibility |
|---|---|
| `prepare` | Stops the running GUI app process; signals that a restart is needed |
| `apply` | Removes the old `.app` bundle, downloads and extracts the new version into `/Applications`, and returns the updated `Installation` |
| `finalize` | Waits for a console user session, resolves command argument placeholders, writes macOS preferences via `defaults`-style key-value pairs, then relaunches the app as the logged-in user |
| `rollback` | Emits a warning — no backup is taken for GUI apps, so reinstallation from the server is the recovery path |

### Notable Behaviors

- **`openframe-chat` special case:** When relaunching, the `--background` flag is injected exclusively for the `openframe-chat` agent ID.
- **Preference resolution:** Placeholder values (e.g., `${client.serverUrl}`) in `run_command_args` are resolved before being written as macOS app preferences via `write_preferences`.
- **Console user polling:** `finalize` loops with a 5-second sleep until `get_console_user()` returns a valid session before launching.

## Usage Example

```rust
let updater = GuiAppToolUpdater::new(deps);

let ctx = updater.prepare(&tool).await?;
let new_installation = updater.apply(&tool, &config, &ctx).await?;
updater.finalize(&tool, &ctx).await?;
```

## Tests

`test_find_app_bundle_path` verifies that `DirectoryManager::find_app_bundle_path` correctly resolves `.app` bundle roots from both bundle-root and deep binary paths, and returns `None` for non-bundle paths.
