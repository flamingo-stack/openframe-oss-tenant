Handles migration of installed tools from `Standard` binary installations to `GuiApp` installations, implementing the `ToolMigrator` trait with platform-specific logic for macOS and Windows.

## Key Components

- **`StandardToGuiAppMigrator`** — Main struct implementing `ToolMigrator` for the `Standard → GuiApp` migration path
- **`prepare`** — Stops the running tool process and sets migration context before any file operations begin
- **`migrate`** — Platform-dispatched migration: removes the old binary and installs a `.app` bundle to `/Applications` on macOS; downloads and writes a new binary on Windows
- **`finalize`** — Launches the newly installed `GuiApp` in the user session post-migration; writes macOS preferences via `bundle_id` if available; adds `--background` flag for `openframe-chat` to start in the system tray
- **`rollback`** — Emits a warning that the original binary may be lost and a reinstall is required; no automatic recovery is performed

## Usage Example

```rust
use crate::platform::tool_updater::ToolUpdaterDeps;
use crate::migrations::standard_to_gui_app::StandardToGuiAppMigrator;
use crate::migrations::ToolMigrator;

let migrator = StandardToGuiAppMigrator::new(deps);

// Verify migration path
assert_eq!(migrator.from_type(), InstallationType::Standard);
assert_eq!(migrator.to_type(),   InstallationType::GuiApp);

// Run migration pipeline
let ctx          = migrator.prepare(&installed_tool).await?;
let installation = migrator.migrate(&installed_tool, &download_config, &ctx).await?;
migrator.finalize(&installed_tool, &installation, &ctx).await?;
```

> **Rollback note:** If migration fails partway through, the original standard binary may already be deleted. A full reinstall is required to recover the tool.
