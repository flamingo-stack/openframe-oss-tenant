Handles the migration of tools from `Standard` (binary) installation type to `GuiApp` installation type, implementing the `ToolMigrator` trait with platform-specific logic for macOS and Windows.

## Key Components

**`StandardToGuiAppMigrator`** — Main struct implementing `ToolMigrator` for `Standard → GuiApp` migrations.

**Trait methods:**
- `prepare` — Stops the running tool process and signals that a restart is needed post-migration
- `migrate` — Dispatches to `migrate_macos` or `migrate_windows` based on compile target
- `finalize` — Launches the newly installed `GuiApp` after migration completes
- `rollback` — Warns that rollback is not recoverable (original binary may be lost); reinstall required

**macOS-specific (`migrate_macos` / `finalize_macos`):**
- Removes the old standard binary from the agent path
- Downloads and extracts the `.app` bundle into `/Applications`
- Resolves the executable path from the app bundle via `DirectoryManager::find_app_bundle_path`
- Writes `NSUserDefaults`-style preferences via `args_to_pairs` / `write_preferences`
- Launches the app in the console user session; passes `--background` for `openframe-chat`

**Windows-specific (`migrate_windows` / `finalize_windows`):**
- Downloads and writes the binary to the agent path using `download_and_write_binary`
- Launches the process in the active user session via `launch_process_in_user_session`
- Appends `--background` for `openframe-chat` to start minimized to the system tray
- Closes the process handle after launch (fire-and-forget; lifecycle picked up on next restart)

## Usage Example

```rust
let migrator = StandardToGuiAppMigrator::new(deps);

let ctx = migrator.prepare(&installed_tool).await?;
let new_installation = migrator.migrate(&installed_tool, &download_config, &ctx).await?;
migrator.finalize(&installed_tool, &new_installation, &ctx).await?;
```
