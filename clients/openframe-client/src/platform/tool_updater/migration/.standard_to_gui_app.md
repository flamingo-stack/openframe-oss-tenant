Handles the migration of an installed tool from `Standard` (plain binary) installation type to `GuiApp` (GUI application bundle) installation type, implementing the `ToolMigrator` trait with platform-specific logic for macOS and Windows.

## Key Components

- **`StandardToGuiAppMigrator`** — Main struct implementing `ToolMigrator` for the `Standard → GuiApp` migration path
- **`prepare`** — Stops the running tool process and marks the migration as requiring a post-migration start
- **`migrate`** — Dispatches to `migrate_macos` or `migrate_windows` based on compile target
- **`finalize`** — Launches the newly installed GUI app after migration completes
- **`rollback`** — Emits a warning that the original binary may be unrecoverable; reinstall is required
- **`migrate_macos`** — Removes the old standard binary, downloads and extracts the `.app` bundle to `/Applications`, and resolves the executable path
- **`finalize_macos`** — Writes macOS preferences via bundle ID, resolves the console user, and launches the app (with `--background` for `openframe-chat`)
- **`migrate_windows`** — Downloads and writes the new binary to the agent path
- **`finalize_windows`** — Resolves command args, appends `--background` for `openframe-chat`, and launches the process in the user session via `launch_process_in_user_session`

## Usage Example

```rust
let migrator = StandardToGuiAppMigrator::new(deps);

let ctx = migrator.prepare(&installed_tool).await?;
let new_installation = migrator.migrate(&installed_tool, &download_config, &ctx).await?;
migrator.finalize(&installed_tool, &new_installation, &ctx).await?;
```

## Notes

- On rollback, no automatic recovery is performed — the original standard binary may have been deleted before the migration failed
- The `openframe-chat` tool receives a `--background` flag on both platforms so it starts minimized to the system tray
