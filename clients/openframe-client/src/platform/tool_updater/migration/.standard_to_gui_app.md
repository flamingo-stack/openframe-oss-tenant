Handles the migration of a tool installation from `Standard` (plain binary) to `GuiApp` (platform-native application bundle) type, implementing the `ToolMigrator` trait with platform-specific logic for macOS and Windows.

## Key Components

**`StandardToGuiAppMigrator`** — Main struct implementing `ToolMigrator` with the following lifecycle steps:

| Method | Responsibility |
|--------|---------------|
| `prepare` | Stops the running tool process before migration begins |
| `migrate` | Dispatches to platform-specific install logic (`migrate_macos` / `migrate_windows`) |
| `finalize` | Launches the newly installed GUI app in the user session |
| `rollback` | Warns that the original binary may be unrecoverable; reinstall required |

**macOS-specific methods:**
- `migrate_macos` — Removes the old standard binary, downloads and extracts the `.app` bundle to `/Applications`, resolves the executable path
- `finalize_macos` — Writes preferences via `bundle_id`, then launches the app as the console user; passes `--background` for `openframe-chat`

**Windows-specific methods:**
- `migrate_windows` — Downloads and writes the binary to the agent path
- `finalize_windows` — Launches the executable in the user session (system tray visible); adds `--background` for `openframe-chat`, then closes the process handle (fire-and-forget)

## Usage Example

```rust
use crate::platform::tool_updater::StandardToGuiAppMigrator;

let migrator = StandardToGuiAppMigrator::new(deps);

// Used via the ToolMigrator trait
let ctx = migrator.prepare(&installed_tool).await?;
let new_installation = migrator.migrate(&installed_tool, &config, &ctx).await?;
migrator.finalize(&installed_tool, &new_installation, &ctx).await?;
```

> **Note:** Rollback does **not** restore the original binary. If migration fails mid-flight, a full reinstall of the tool is required.
