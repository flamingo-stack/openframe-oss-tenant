Implements the `ToolUpdater` trait for standard (non-system) tools, providing a stop → backup → download → finalize/rollback update lifecycle.

## Key Components

- **`StandardToolUpdater`** — Main struct holding `ToolUpdaterDeps` (kill service, directory manager, download utilities)
- **`prepare`** — Stops the running tool process and creates a binary backup before any changes
- **`apply`** — Downloads and writes the new binary to the agent path
- **`finalize`** — Cleans up the backup file; signals that the run manager will handle auto-restart
- **`rollback`** — Restores the original binary from backup if the update fails

## Usage Example

```rust
use your_crate::updater::standard::StandardToolUpdater;
use your_crate::updater::{ToolUpdater, ToolUpdaterDeps};

let updater = StandardToolUpdater::new(ToolUpdaterDeps {
    tool_kill_service,
    directory_manager,
    // ...other deps
});

// Orchestrate the full update cycle
let ctx = updater.prepare(&installed_tool).await?;

match updater.apply(&installed_tool, &download_config, &ctx).await {
    Ok(_) => updater.finalize(&installed_tool, &ctx).await?,
    Err(e) => {
        updater.rollback(&installed_tool, &ctx).await?;
        return Err(e);
    }
}
```

> The `needs_restart` flag in `UpdateContext` is always set to `true` for standard tools — the run manager is responsible for restarting the process after finalization rather than the updater itself.
