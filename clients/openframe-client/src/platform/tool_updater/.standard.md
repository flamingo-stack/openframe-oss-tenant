Implements the standard tool update strategy for self-contained agent binaries, handling the full update lifecycle: stop, backup, download, finalize, and rollback.

## Key Components

- **`StandardToolUpdater`** — Concrete implementation of the `ToolUpdater` trait for standard (non-service-managed) tools
- **`prepare()`** — Stops the running tool process and creates a binary backup before applying changes
- **`apply()`** — Downloads and writes the new binary to the agent path
- **`finalize()`** — Cleans up the backup file; logs that the tool will auto-restart via the run manager
- **`rollback()`** — Restores the backed-up binary if the update fails

## Usage Example

```rust
use crate::updater::standard::StandardToolUpdater;
use crate::updater::{ToolUpdater, ToolUpdaterDeps};

let updater = StandardToolUpdater::new(ToolUpdaterDeps {
    tool_kill_service,
    directory_manager,
    // ...other deps
});

// Full update lifecycle
let ctx = updater.prepare(&installed_tool).await?;

match updater.apply(&installed_tool, &download_config, &ctx).await {
    Ok(_) => updater.finalize(&installed_tool, &ctx).await?,
    Err(e) => {
        updater.rollback(&installed_tool, &ctx).await?;
        return Err(e);
    }
}
```

## Notes

- `needs_restart` is always `true` for standard tools; the run manager handles the actual process restart automatically after the binary is replaced
- Backup/restore and cleanup are delegated to shared helper functions (`backup_binary`, `restore_from_backup`, `cleanup_backup`) from the parent module
