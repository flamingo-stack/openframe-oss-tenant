Implements the standard tool update strategy for binary-based tools, handling the full update lifecycle: stopping the tool process, backing up the existing binary, downloading and writing the new binary, and rolling back on failure.

## Key Components

### `StandardToolUpdater`

A struct implementing the `ToolUpdater` trait for tools that follow the standard binary replacement pattern.

| Method | Description |
|--------|-------------|
| `new(deps)` | Constructs a new instance with the provided `ToolUpdaterDeps` |
| `prepare()` | Stops the running tool process and creates a backup of the current binary |
| `apply()` | Downloads and writes the new binary to the agent path |
| `finalize()` | Cleans up the backup; logs that the tool will auto-restart via the run manager |
| `rollback()` | Restores the previous binary from the backup path |

The `prepare` step sets `needs_restart: true` in the returned `UpdateContext`, signalling downstream components to restart the tool after the update completes.

## Usage Example

```rust
use crate::updaters::standard::StandardToolUpdater;
use crate::updaters::{ToolUpdater, ToolUpdaterDeps};

let updater = StandardToolUpdater::new(deps);

// Prepare: stops tool and backs up binary
let ctx = updater.prepare(&installed_tool).await?;

// Apply: downloads and writes new binary
updater.apply(&installed_tool, &download_config, &ctx).await?;

// Finalize: cleans up backup; tool auto-restarts
updater.finalize(&installed_tool, &ctx).await?;

// On failure, restore previous binary
updater.rollback(&installed_tool, &ctx).await?;
```
