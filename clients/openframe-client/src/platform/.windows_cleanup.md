Generates and executes a PowerShell-based cleanup script that removes the OpenFrame binary and associated directories from Windows systems after the current process exits.

## Key Components

### `generate_binary_cleanup_script`

Produces a self-contained PowerShell script string that performs post-exit cleanup:

- **Process wait loop** — polls for process exit by PID (max 30 seconds), force-kills if timeout is reached
- **Binary deletion with retry** — up to 5 attempts with exponential backoff; falls back to `takeown`/`icacls` for locked files
- **Directory pruning** — removes empty `bin` directory and its OpenFrame parent if also empty
- **PATH cleanup** — rewrites `HKLM` registry PATH entry as `REG_EXPAND_SZ` and broadcasts `WM_SETTINGCHANGE` to notify running processes

### `execute_binary_cleanup_script`

Writes the generated script to a UUID-named temp file and spawns it as a detached, windowless PowerShell process:

- On Windows: uses `CREATE_NO_WINDOW` creation flag and resolves the PowerShell path via `get_powershell_path()`
- On non-Windows: falls back to `powershell.exe` (for cross-compilation/testing scenarios)

## Usage Example

```rust
use std::path::PathBuf;

let install_path = PathBuf::from("C:\\Program Files\\OpenFrame\\bin\\openframe.exe");
let bin_dir = PathBuf::from("C:\\Program Files\\OpenFrame\\bin");

// Spawn background cleanup before the process exits
execute_binary_cleanup_script(&install_path, Some(&bin_dir))?;

// Process can now exit; the script handles the rest
```

> **Note:** This module is intended for Windows uninstall flows. The `generate_*` function is platform-independent (useful for testing), while `execute_*` requires PowerShell to be available at runtime.
