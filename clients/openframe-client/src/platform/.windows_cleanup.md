Handles post-uninstall cleanup of the OpenFrame binary on Windows by generating and executing a detached PowerShell script that removes the binary, empties parent directories, and strips the install path from the system `PATH` after the main process exits.

## Key Components

- **`generate_binary_cleanup_script`** — Builds a self-contained PowerShell script string that:
  - Waits up to 30 seconds for the given PID to exit (force-kills if timeout exceeded)
  - Deletes the binary with exponential-backoff retries (up to 5 attempts), falling back to `takeown`/`icacls` if standard removal fails
  - Removes empty `bin` and parent `OpenFrame` directories
  - Strips the `bin` directory from the system `PATH` registry key (`REG_EXPAND_SZ`) and broadcasts `WM_SETTINGCHANGE` to notify the shell

- **`execute_binary_cleanup_script`** — Writes the generated script to a UUID-named temp file and spawns it as a detached, windowless PowerShell process (`CREATE_NO_WINDOW` on Windows), then returns immediately

## Usage Example

```rust
use std::path::PathBuf;

let install_path = PathBuf::from(r"C:\Program Files\OpenFrame\bin\openframe.exe");
let bin_dir = PathBuf::from(r"C:\Program Files\OpenFrame\bin");

// Spawn the cleanup script in the background and return immediately.
// The script waits for this process to exit before deleting anything.
execute_binary_cleanup_script(&install_path, Some(&bin_dir))?;
```

> **Note:** `execute_binary_cleanup_script` is intended to be called just before the uninstaller process exits. The spawned PowerShell script runs independently and cleans up only after the parent PID is no longer active.
