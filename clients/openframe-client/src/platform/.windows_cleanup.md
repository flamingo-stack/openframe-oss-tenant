Handles post-uninstall cleanup of the OpenFrame binary on Windows by generating and executing a background PowerShell script that waits for the current process to exit before removing the binary, empty directories, and PATH entries.

## Key Components

### `generate_binary_cleanup_script`
Builds a PowerShell script string that performs the following cleanup steps after the parent process exits:
- **Process wait loop** — polls for PID exit up to 30 seconds, force-kills if timeout exceeded
- **Binary removal** — retries up to 5 times with exponential backoff; falls back to `takeown`/`icacls` if standard removal fails
- **Directory cleanup** — removes empty `bin` and parent `OpenFrame` directories with retry logic
- **PATH update** — removes the `bin` directory from the system `PATH` registry key (`HKLM`) and broadcasts a `WM_SETTINGCHANGE` message so running processes pick up the change

### `execute_binary_cleanup_script`
Writes the generated script to a UUID-named temp file and spawns it as a detached, windowless PowerShell process. On Windows, uses `CREATE_NO_WINDOW` via `CommandExt`; non-Windows falls back to plain `powershell.exe` (for cross-compilation scenarios).

## Usage Example

```rust
use std::path::PathBuf;

let install_path = PathBuf::from("C:\\Program Files\\OpenFrame\\bin\\openframe.exe");
let bin_dir = PathBuf::from("C:\\Program Files\\OpenFrame\\bin");

// Spawn the background cleanup script before the process exits
execute_binary_cleanup_script(&install_path, Some(&bin_dir))?;

// Process can now exit; the script will handle cleanup
```

> **Note:** `execute_binary_cleanup_script` is intended to be called just before the uninstaller process exits. The spawned PowerShell script is fully detached and requires no further interaction.
