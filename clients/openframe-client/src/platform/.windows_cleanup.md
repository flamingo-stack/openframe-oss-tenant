Generates and executes a detached PowerShell cleanup script that removes the OpenFrame binary, empty install directories, and PATH entries after the calling process exits on Windows.

## Key Components

### `generate_binary_cleanup_script`
Builds a PowerShell script string that:
- Polls for the calling PID to exit (up to 30 seconds, force-kills if timeout)
- Deletes the binary with exponential-backoff retry (up to 5 attempts), falling back to `takeown`/`icacls` on permission failures
- Removes empty `bin` and parent `OpenFrame` directories (up to 3 retries each)
- Strips the `bin` directory from the system `PATH` registry key (`HKLM`) and broadcasts `WM_SETTINGCHANGE` to notify running processes

### `execute_binary_cleanup_script`
Writes the generated script to a UUID-named temp file and spawns it detached via PowerShell (`CREATE_NO_WINDOW`, `Bypass` execution policy, no stdin/stdout/stderr). Compiles on non-Windows targets using `powershell.exe` directly.

## Usage Example

```rust
use std::path::PathBuf;

let install_path = PathBuf::from("C:\\Program Files\\OpenFrame\\bin\\openframe.exe");
let bin_dir = PathBuf::from("C:\\Program Files\\OpenFrame\\bin");

// Generate script content only (no execution)
let script = generate_binary_cleanup_script(&install_path, std::process::id(), Some(&bin_dir));

// Or generate + write + spawn in one call
execute_binary_cleanup_script(&install_path, Some(&bin_dir))
    .expect("Failed to launch cleanup script");

// The current process can now exit safely; the background
// PowerShell script handles all cleanup after PID is gone.
```

> **Note:** `execute_binary_cleanup_script` is intended to be called immediately before the process exits. The spawned PowerShell process is fully detached and will complete cleanup independently.
