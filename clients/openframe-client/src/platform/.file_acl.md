Provides cross-platform file ACL utilities for managing Windows file permissions and ownership, with no-op stubs for non-Windows platforms.

## Key Components

- **`ensure_writable(path: &Path)`** — Clears restrictive file attributes and grants full access to Administrators (`S-1-5-32-544`) and SYSTEM (`S-1-5-18`) on a path. Runs three sequential Windows commands:
  - `attrib` — removes Read-only, System, and Hidden flags recursively
  - `takeown` — takes recursive ownership of the path
  - `icacls` — grants full control to Administrators and SYSTEM

- **`harden_executable(path: &Path)`** — Locks down an executable to admin-only access by removing inherited permissions and applying a strict ACL:
  - SYSTEM: Full Control `(F)`
  - Administrators: Full Control `(F)`
  - Users: Read & Execute `(RX)` only

Both functions are gated with `#[cfg(target_os = "windows")]` and have silent no-op counterparts for Linux/macOS.

## Usage Example

```rust
use std::path::Path;

// Before installing or modifying a managed file
let target = Path::new("C:\\ProgramData\\flamingo\\agent.exe");

// Make writable before overwriting
ensure_writable(target).await?;

// Write new binary...

// Lock it down after installation
harden_executable(target).await?;
```

> **Note:** Both functions use `tokio::process::Command` for async subprocess execution and log warnings via `tracing` if any underlying system command fails, but they intentionally return `Ok(())` regardless — failures are non-fatal to avoid blocking the caller on permission edge cases.
