Provides cross-platform file ACL utilities for managing Windows filesystem permissions, with no-op stubs on non-Windows platforms.

## Key Components

- **`ensure_writable(path: &Path)`** — Makes a path fully writable by clearing read-only/system/hidden attributes (`attrib`), taking ownership (`takeown /R`), and granting full control to Administrators (SID `S-1-5-32-544`) and SYSTEM (SID `S-1-5-18`) recursively via `icacls`.
- **`harden_executable(path: &Path)`** — Locks down an executable to admin-only access by transferring ownership to the Administrators group and setting explicit ACL inheritance removal, granting full control to SYSTEM and Administrators, and read/execute only to Users (SID `S-1-5-32-545`).

Both functions are `async`, use `tokio::process::Command` to invoke Windows built-in CLI tools, and return `Ok(())` on non-Windows targets as no-ops.

## Usage Example

```rust
use std::path::Path;
use file_acl::{ensure_writable, harden_executable};

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let install_dir = Path::new("C:\\Program Files\\MyApp");
    let binary = Path::new("C:\\Program Files\\MyApp\\agent.exe");

    // Prepare directory for writing (e.g., before update/extraction)
    ensure_writable(install_dir).await?;

    // Lock down the installed binary after deployment
    harden_executable(binary).await?;

    Ok(())
}
```

> Failures from `attrib`, `takeown`, or `icacls` are logged as warnings but do **not** propagate as errors — the functions always return `Ok(())` to allow best-effort permission management without halting execution.
