Provides cross-platform file ACL utilities for managing Windows file permissions and ownership, with no-op implementations on non-Windows platforms.

## Key Components

- **`ensure_writable(path: &Path)`** — Makes a path fully writable by clearing read-only/system/hidden attributes (`attrib`), taking ownership of the path (`takeown`), and granting full control to Administrators (SID `S-1-5-32-544`) and SYSTEM (SID `S-1-5-18`) via `icacls`. Operates recursively (`/S /D /T`).

- **`harden_executable(path: &Path)`** — Locks down an executable to admin-only access by transferring ownership to the Administrators group, removing inherited ACEs, and setting explicit grants: full control for SYSTEM and Administrators, read+execute only for Users (`S-1-5-32-545`).

Both functions are gated with `#[cfg(target_os = "windows")]` and return `Ok(())` immediately on non-Windows targets.

## Usage Example

```rust
use std::path::Path;
use file_acl::{ensure_writable, harden_executable};

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let install_dir = Path::new(r"C:\ProgramData\MyApp");

    // Before extracting or writing files, ensure the directory is writable
    ensure_writable(install_dir).await?;

    // After placing the binary, restrict it to admin/SYSTEM only
    let exe_path = install_dir.join("agent.exe");
    harden_executable(&exe_path).await?;

    Ok(())
}
```

> **Note:** These functions are best-effort — individual `attrib`, `takeown`, and `icacls` failures are logged as warnings but do not propagate errors, allowing the caller to continue even if some ACL operations are skipped.
