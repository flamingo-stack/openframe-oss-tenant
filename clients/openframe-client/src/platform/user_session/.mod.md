This module provides platform-specific system user utilities, currently supporting macOS operations for user management and process launching.

## Key Components

- **`get_console_user`** - Retrieves the currently logged-in console user on macOS
- **`launch_as_user`** - Launches processes or applications as a specific user on macOS

The module uses conditional compilation to include macOS-specific functionality only when building for macOS targets, ensuring clean cross-platform compatibility.

## Usage Example

```rust
#[cfg(target_os = "macos")]
use your_crate::system_user::{get_console_user, launch_as_user};

#[cfg(target_os = "macos")]
fn example_usage() -> Result<(), Box<dyn std::error::Error>> {
    // Get the current console user
    let current_user = get_console_user()?;
    println!("Console user: {}", current_user);
    
    // Launch an application as the console user
    launch_as_user(&current_user, "/Applications/TextEdit.app")?;
    
    Ok(())
}
```

The module automatically selects the appropriate implementation based on the target platform during compilation, making it safe to use in cross-platform applications where macOS-specific functionality is only needed on Apple systems.
