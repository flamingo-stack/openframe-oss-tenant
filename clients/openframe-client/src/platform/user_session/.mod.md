Module that provides platform-specific user management functionality, currently supporting macOS with functions for retrieving console users and launching processes with specific user privileges.

## Key Components

- **Platform conditionals**: Uses `cfg` attributes to conditionally compile code based on target operating system
- **macOS module**: Contains macOS-specific implementations for user operations
- **Public exports**: Re-exports `get_console_user` and `launch_as_user` functions from the macOS implementation

## Usage Example

```rust
// This module is used internally by importing its functions
#[cfg(target_os = "macos")]
use crate::user::{get_console_user, launch_as_user};

#[cfg(target_os = "macos")]
fn example_usage() -> Result<(), Box<dyn std::error::Error>> {
    // Get the current console user
    let console_user = get_console_user()?;
    println!("Console user: {}", console_user);
    
    // Launch a process as the console user
    launch_as_user(&console_user, "/usr/bin/open", &["/Applications/Safari.app"])?;
    
    Ok(())
}
```

This module follows Rust's conditional compilation pattern, ensuring that platform-specific code is only included when building for the appropriate target OS. Currently only supports macOS, but the structure allows for easy extension to other platforms by adding additional `cfg` modules.
