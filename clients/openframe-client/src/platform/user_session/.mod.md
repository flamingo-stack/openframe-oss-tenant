A platform-specific module that provides user session management functionality, currently supporting macOS with conditional compilation for cross-platform compatibility.

## Key Components

- **Conditional compilation** - Uses `#[cfg(target_os = "macos")]` to include macOS-specific code only when building for macOS
- **`get_console_user`** - Function to retrieve the current console user information
- **`launch_as_user`** - Function to execute processes under a specific user context
- **Module re-exports** - Cleanly exposes platform-specific functionality through a unified interface

## Usage Example

```rust
// This code will only compile and work on macOS
#[cfg(target_os = "macos")]
use your_crate::{get_console_user, launch_as_user};

#[cfg(target_os = "macos")]
fn example_usage() {
    // Get the current console user
    if let Ok(user) = get_console_user() {
        println!("Current console user: {}", user);
        
        // Launch a process as that user
        if let Err(e) = launch_as_user(&user, "/usr/bin/whoami", &[]) {
            eprintln!("Failed to launch process: {}", e);
        }
    }
}

#[cfg(not(target_os = "macos"))]
fn example_usage() {
    println!("User session management not available on this platform");
}
```

This module follows Rust's idiomatic approach to platform-specific code, allowing the same codebase to compile across different operating systems while providing specialized functionality where available.
