Module entry point that provides platform-specific user session management functionality, currently supporting macOS with conditional compilation for cross-platform compatibility.

## Key Components

- **Conditional compilation**: Uses `#[cfg(target_os = "macos")]` to include macOS-specific code only when building for macOS
- **Public exports**: Re-exports `get_console_user` and `launch_as_user` functions from the macOS implementation
- **Platform abstraction**: Provides a clean interface that can be extended for other operating systems

## Usage Example

```rust
// This module automatically includes the correct platform implementation
use crate::user_session::{get_console_user, launch_as_user};

// Get the current console user (macOS only)
let user = get_console_user()?;
println!("Console user: {}", user);

// Launch a process as a specific user (macOS only) 
launch_as_user("username", "/path/to/executable", &["arg1", "arg2"])?;
```

The module uses Rust's conditional compilation features to ensure that platform-specific code is only included when building for the target platform, making it easy to add support for Windows, Linux, or other operating systems in the future by creating corresponding modules with the same public interface.
