Platform-specific module for user session management, currently providing macOS-specific implementations for console user operations and process launching.

## Key Components

- **Conditional compilation**: Uses `#[cfg(target_os = "macos")]` to include macOS-specific code only on macOS systems
- **`get_console_user`**: Function to retrieve the current console user information
- **`launch_as_user`**: Function to launch processes under a specific user context

## Usage Example

```rust
// This code will only compile and work on macOS
#[cfg(target_os = "macos")]
use your_crate::{get_console_user, launch_as_user};

#[cfg(target_os = "macos")]
fn example_usage() {
    // Get the current console user
    if let Ok(user) = get_console_user() {
        println!("Console user: {}", user);
        
        // Launch a process as that user
        if let Err(e) = launch_as_user(&user, "/usr/bin/whoami", &[]) {
            eprintln!("Failed to launch process: {}", e);
        }
    }
}
```

This module provides a clean interface for platform-specific user management operations, with the actual implementations contained in separate platform modules (currently only `macos.rs`).
