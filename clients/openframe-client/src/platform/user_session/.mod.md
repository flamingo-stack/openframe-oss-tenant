Platform-specific OS abstraction module that conditionally compiles and re-exports macOS-specific system utilities.

## Key Components

| Export | Description |
|--------|-------------|
| `get_console_user` | Retrieves the currently logged-in console user |
| `is_gui_session_ready` | Checks whether a GUI session is available and ready |
| `launch_as_user` | Launches a process in the context of a specific user |
| `is_process_running` | Checks if a given process is currently running |

All exports are gated behind `#[cfg(target_os = "macos")]` and sourced from the `macos` submodule.

## Usage Example

```rust
#[cfg(target_os = "macos")]
use crate::os::{get_console_user, is_gui_session_ready, launch_as_user, is_process_running};

#[cfg(target_os = "macos")]
fn main() {
    if let Some(user) = get_console_user() {
        println!("Console user: {}", user);
    }

    if is_gui_session_ready() {
        launch_as_user("myapp", &["--flag"]);
    }

    if is_process_running("agent") {
        println!("Agent is running");
    }
}
```

> **Note:** This module is only compiled on macOS targets. Calling these functions on other platforms will result in a compile-time error. Future platform support (e.g., Windows, Linux) would follow the same conditional module pattern.
