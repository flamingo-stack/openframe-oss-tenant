A platform-specific module that conditionally exposes macOS user management functionality based on the target operating system.

## Key Components

- **Conditional compilation**: Uses `cfg(target_os = "macos")` to only compile macOS-specific code on macOS systems
- **Module re-exports**: Exposes `get_console_user` and `launch_as_user` functions from the internal `macos` module
- **Platform abstraction**: Provides a clean interface for macOS-specific user operations

## Usage Example

```rust
// This code will only compile and work on macOS
#[cfg(target_os = "macos")]
use your_crate::{get_console_user, launch_as_user};

#[cfg(target_os = "macos")]
fn example_usage() -> Result<(), Box<dyn std::error::Error>> {
    // Get the current console user
    let user = get_console_user()?;
    println!("Console user: {}", user);
    
    // Launch a process as that user
    launch_as_user(&user, "/usr/bin/whoami", &[])?;
    
    Ok(())
}

// On non-macOS platforms, these functions won't be available
#[cfg(not(target_os = "macos"))]
fn example_usage() {
    println!("macOS-specific functionality not available on this platform");
}
```

This module serves as a platform gateway, ensuring macOS-specific user management code only exists when building for macOS targets, making the crate cross-platform compatible.
