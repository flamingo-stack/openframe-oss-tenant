Platform-specific OS abstraction module that conditionally compiles and re-exports macOS-specific system utilities for user session and process management.

## Key Components

| Export | Description |
|--------|-------------|
| `get_console_user` | Retrieves the currently logged-in console user |
| `is_gui_session_ready` | Checks whether a GUI session is available and ready |
| `launch_as_user` | Launches a process in the context of a specific user |
| `is_process_running` | Checks whether a given process is currently running |

All four items are conditionally compiled and exported only when targeting `macos`.

## Usage Example

```rust
#[cfg(target_os = "macos")]
use crate::os::{get_console_user, is_gui_session_ready, launch_as_user, is_process_running};

#[cfg(target_os = "macos")]
fn check_session() {
    if is_gui_session_ready() {
        if let Some(user) = get_console_user() {
            println!("Console user: {}", user);
        }
    }

    if is_process_running("Finder") {
        println!("Finder is running");
    }
}
```

## Notes

- The inner `macos` submodule lives at [`src/os/macos.rs`](https://github.com/flamingo-stack/openframe-oss-tenant/blob/main/src/os/macos.rs) (or `macos/mod.rs`).
- Adding support for a new platform (e.g., Linux or Windows) follows the same `#[cfg(target_os = "...")]` pattern — add a new submodule and mirror the `pub use` block.
- All symbols are re-exported at the `os` crate level, so callers import directly from `os::*` rather than `os::macos::*`.
