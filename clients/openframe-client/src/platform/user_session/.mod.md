This module provides platform-specific user session management functionality, currently supporting macOS with conditional compilation directives.

## Key Components

- **`macos` module** - Platform-specific implementation for macOS systems
- **`get_console_user`** - Function to retrieve the current console user (macOS only)
- **`launch_as_user`** - Function to launch processes as a specific user (macOS only)

## Usage Example

```rust
// Only available on macOS systems
#[cfg(target_os = "macos")]
use your_crate::{get_console_user, launch_as_user};

#[cfg(target_os = "macos")]
fn main() {
    // Get the current console user
    if let Ok(user) = get_console_user() {
        println!("Console user: {}", user);
        
        // Launch a process as that user
        if let Err(e) = launch_as_user(&user, "/usr/bin/whoami", &[]) {
            eprintln!("Failed to launch process: {}", e);
        }
    }
}
```

The module uses conditional compilation to ensure the macOS-specific code is only included when building for macOS targets, making the codebase portable across different operating systems while providing platform-optimized functionality where available.
