Platform-specific module dispatcher that provides user management functionality on macOS systems through conditional compilation.

## Key Components

- **Conditional compilation**: Uses `#[cfg(target_os = "macos")]` to include macOS-specific code only when building for macOS
- **Public exports**: Re-exports `get_console_user` and `launch_as_user` functions from the macOS implementation
- **Module organization**: Separates platform-specific implementations into dedicated submodules

## Usage Example

```rust
// Only available when compiled for macOS
#[cfg(target_os = "macos")]
use your_crate::{get_console_user, launch_as_user};

#[cfg(target_os = "macos")]
fn example_usage() {
    // Get the current console user
    if let Ok(user) = get_console_user() {
        println!("Current console user: {}", user);
        
        // Launch a process as that user
        launch_as_user(&user, "/usr/bin/whoami", &[]).ok();
    }
}

// Non-macOS platforms won't have access to these functions
#[cfg(not(target_os = "macos"))]
fn example_usage() {
    println!("User management functions not available on this platform");
}
```

This module follows Rust's conditional compilation patterns to provide platform-specific functionality while maintaining a clean public API that only exposes relevant functions on supported operating systems.
