A platform-specific module loader that conditionally exposes macOS user management functionality based on the target operating system.

## Key Components

- **Conditional compilation**: Uses `#[cfg(target_os = "macos")]` attributes to include macOS-specific code only when building for macOS
- **Module declaration**: Declares the `macos` submodule when on macOS
- **Public re-exports**: Exposes `get_console_user` and `launch_as_user` functions from the macos module

## Usage Example

```rust
// This code will only compile and be available on macOS
#[cfg(target_os = "macos")]
use your_crate::{get_console_user, launch_as_user};

#[cfg(target_os = "macos")]
fn main() {
    // Get the current console user
    if let Some(user) = get_console_user() {
        println!("Console user: {}", user);
        
        // Launch a process as that user
        launch_as_user(&user, "/usr/bin/open", &["/Applications/Calculator.app"]);
    }
}

// On non-macOS platforms, these functions won't be available
#[cfg(not(target_os = "macos"))]
fn main() {
    println!("User management functions not available on this platform");
}
```

This pattern enables cross-platform code while providing platform-specific functionality where needed, ensuring the crate only includes macOS dependencies when building for macOS targets.
