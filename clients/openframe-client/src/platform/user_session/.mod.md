This module provides platform-specific user management functionality, currently implementing macOS-specific operations for getting console user information and launching processes as different users.

## Key Components

- **`macos` module** - Contains macOS-specific implementations (conditionally compiled)
- **`get_console_user`** - Retrieves the current console user information on macOS
- **`launch_as_user`** - Launches processes with different user privileges on macOS

## Usage Example

```rust
#[cfg(target_os = "macos")]
use your_crate::get_console_user;
use your_crate::launch_as_user;

#[cfg(target_os = "macos")]
fn example_usage() -> Result<(), Box<dyn std::error::Error>> {
    // Get current console user
    let user_info = get_console_user()?;
    println!("Console user: {:?}", user_info);
    
    // Launch a process as a specific user
    launch_as_user("some_username", "/usr/bin/whoami", &[])?;
    
    Ok(())
}
```

This module uses conditional compilation (`#[cfg(target_os = "macos")]`) to only include macOS-specific code when building for macOS targets. The public API is re-exported from the platform-specific implementation, providing a clean interface for cross-platform user management operations.
