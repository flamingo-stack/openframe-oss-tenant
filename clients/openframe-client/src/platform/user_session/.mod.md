Module entry point that provides platform-specific user session management functionality, currently supporting macOS with conditional compilation for cross-platform compatibility.

## Key Components

- **Platform-specific modules**: Conditionally compiles `macos` module only on macOS systems
- **Public exports**: Re-exports `get_console_user` and `launch_as_user` functions from the macOS implementation
- **Conditional compilation**: Uses `#[cfg(target_os = "macos")]` attributes for platform detection

## Usage Example

```rust
// This module automatically selects the correct implementation based on target OS
use crate::user_session::{get_console_user, launch_as_user};

// Get the current console user (only available on macOS)
#[cfg(target_os = "macos")]
fn example_usage() {
    match get_console_user() {
        Ok(user) => {
            println!("Console user: {}", user);
            
            // Launch a process as that user
            if let Err(e) = launch_as_user(&user, "/path/to/app") {
                eprintln!("Failed to launch as user: {}", e);
            }
        }
        Err(e) => eprintln!("Failed to get console user: {}", e),
    }
}
```

This architecture allows for easy extension to other operating systems by adding similar conditional modules for Windows, Linux, etc., while maintaining a consistent public API across platforms.
