This module provides cross-platform user session management functionality, with macOS-specific implementations for launching processes as different users and retrieving console user information.

## Key Components

- **get_console_user()** - Retrieves the currently logged-in console user on macOS systems
- **launch_as_user()** - Launches processes under a specific user context on macOS systems

The module uses conditional compilation to only include macOS-specific code when building for macOS targets, ensuring clean cross-platform compatibility.

## Usage Example

```rust
#[cfg(target_os = "macos")]
use crate::user_session::{get_console_user, launch_as_user};

#[cfg(target_os = "macos")]
fn main() -> Result<(), Box<dyn std::error::Error>> {
    // Get the current console user
    let current_user = get_console_user()?;
    println!("Console user: {}", current_user);
    
    // Launch a process as a specific user
    launch_as_user("some_username", "/usr/bin/whoami", &[])?;
    
    Ok(())
}

#[cfg(not(target_os = "macos"))]
fn main() {
    println!("User session management only available on macOS");
}
```

The module is designed to be extended with additional platform-specific implementations (Windows, Linux) by adding corresponding conditional compilation blocks and platform modules.
