Platform-specific OS module that conditionally compiles and re-exports macOS system utility functions for user session and process management.

## Key Components

| Export | Description |
|--------|-------------|
| `get_console_user` | Retrieves the currently logged-in console user |
| `is_gui_session_ready` | Checks whether a GUI session is available and ready |
| `launch_as_user` | Launches a process in the context of a specific user |
| `is_process_running` | Checks whether a given process is currently running |

All exports are gated behind `#[cfg(target_os = "macos")]` and sourced from the `macos` submodule.

## Usage Example

```rust
#[cfg(target_os = "macos")]
use crate::os::{get_console_user, is_gui_session_ready, launch_as_user, is_process_running};

#[cfg(target_os = "macos")]
fn main() {
    if let Some(user) = get_console_user() {
        println!("Console user: {}", user);
    }

    if is_gui_session_ready() {
        launch_as_user("my_agent");
    }

    if is_process_running("my_agent") {
        println!("Agent is running.");
    }
}
```

> **Note:** This module only compiles on macOS. Referencing these exports on other platforms will result in a compile-time error. Wrap all call sites with `#[cfg(target_os = "macos")]` guards accordingly.
