This module provides platform-specific user management functionality, currently supporting macOS operations for console user detection and process launching.

## Key Components

- **`get_console_user`** - Retrieves the currently logged-in console user on macOS
- **`launch_as_user`** - Launches processes under a specific user context on macOS

The module uses conditional compilation to only include macOS-specific code when building for that target platform.

## Usage Example

```rust
#[cfg(target_os = "macos")]
use your_crate::user_management::{get_console_user, launch_as_user};

#[cfg(target_os = "macos")]
fn example_usage() {
    // Get the current console user
    match get_console_user() {
        Ok(user) => {
            println!("Console user: {}", user);
            
            // Launch a process as that user
            match launch_as_user(&user, "/usr/bin/whoami", &[]) {
                Ok(_) => println!("Process launched successfully"),
                Err(e) => eprintln!("Failed to launch process: {}", e),
            }
        }
        Err(e) => eprintln!("Failed to get console user: {}", e),
    }
}
```

This module follows a platform-conditional pattern, making it easy to extend with additional OS support (Linux, Windows) in the future while keeping the public API consistent across platforms.
