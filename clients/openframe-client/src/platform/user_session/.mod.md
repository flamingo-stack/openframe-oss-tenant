Cross-platform module for user management and process launching functionality, providing OS-specific implementations behind a unified interface.

## Key Components

- **Conditional compilation**: Uses `cfg` attributes to include platform-specific modules
- **macOS module**: Contains `get_console_user` and `launch_as_user` functions for macOS systems
- **Public re-exports**: Exposes platform-specific functionality through a common interface

## Usage Example

```rust
// Import the platform-specific functions
use crate::user::{get_console_user, launch_as_user};

// Get the current console user (macOS only)
#[cfg(target_os = "macos")]
fn example_usage() {
    // Get the currently logged-in console user
    if let Ok(user) = get_console_user() {
        println!("Console user: {}", user);
        
        // Launch a process as that user
        if let Err(e) = launch_as_user(&user, "/usr/bin/open", &["-a", "Safari"]) {
            eprintln!("Failed to launch process: {}", e);
        }
    }
}
```

This module acts as a facade, conditionally compiling and exposing the appropriate implementation based on the target operating system. Currently only supports macOS, but the structure allows for easy extension to other platforms by adding additional `cfg` modules.
