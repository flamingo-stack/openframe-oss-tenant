Platform-specific module declarations for user session management, providing cross-platform access to macOS-specific functionality for launching processes and retrieving user information.

## Key Components

- **Conditional compilation**: Uses `#[cfg(target_os = "macos")]` to include macOS-specific code only when building for macOS
- **Module re-exports**: Exposes `get_console_user` and `launch_as_user` functions from the internal `macos` module
- **Public API**: Provides a clean interface for user session operations on macOS systems

## Usage Example

```rust
// This module is automatically included when building on macOS
use crate::user_session::{get_console_user, launch_as_user};

#[cfg(target_os = "macos")]
fn example_usage() {
    // Get the current console user
    if let Some(user) = get_console_user() {
        println!("Current console user: {}", user);
        
        // Launch a process as that user
        launch_as_user(&user, "/usr/bin/whoami", &[]).expect("Failed to launch process");
    }
}

// On non-macOS platforms, these functions won't be available
#[cfg(not(target_os = "macos"))]
fn example_usage() {
    println!("User session management not available on this platform");
}
```

The module acts as a platform abstraction layer, ensuring that macOS-specific user session functionality is only compiled and available on compatible systems.
