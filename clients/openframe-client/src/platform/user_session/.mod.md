Platform-specific module dispatcher that conditionally compiles and re-exports macOS user session utilities.

## Key Components

| Export | Description |
|--------|-------------|
| `get_console_user` | Retrieves the currently logged-in console user |
| `is_gui_session_ready` | Checks whether the GUI session is available and ready |
| `launch_as_user` | Launches a process in the context of the current user |
| `is_process_running` | Checks if a given process is currently running |

All exports are gated behind `#[cfg(target_os = "macos")]` and sourced from the `macos` submodule.

## Usage Example

```rust
#[cfg(target_os = "macos")]
use crate::platform::{get_console_user, is_gui_session_ready, launch_as_user, is_process_running};

#[cfg(target_os = "macos")]
fn run() {
    if is_gui_session_ready() {
        if let Some(user) = get_console_user() {
            println!("Console user: {}", user);

            if !is_process_running("my_agent") {
                launch_as_user(&user, "/usr/local/bin/my_agent", &[]);
            }
        }
    }
}
```

> **Note:** This module and all its exports are only available when compiling for macOS. On other platforms, these symbols will not exist — guard all call sites with `#[cfg(target_os = "macos")]` to avoid compilation errors.
