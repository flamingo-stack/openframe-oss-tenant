Platform-specific module for user session management that provides macOS-specific functionality for getting the current console user and launching processes under that user context.

## Key Components

- **`macos` module** - Contains macOS-specific implementations (conditionally compiled)
- **`get_console_user()`** - Retrieves the currently logged-in console user on macOS
- **`launch_as_user()`** - Launches processes under a specific user's context on macOS

## Usage Example

```rust
#[cfg(target_os = "macos")]
use your_crate::user_session::{get_console_user, launch_as_user};

#[cfg(target_os = "macos")]
fn main() -> Result<(), Box<dyn std::error::Error>> {
    // Get the current console user
    let user = get_console_user()?;
    println!("Console user: {}", user);
    
    // Launch a process as that user
    launch_as_user(&user, "/usr/bin/open", &["-a", "Calculator"])?;
    
    Ok(())
}
```

This module uses conditional compilation to only include macOS functionality when building for macOS targets, making it safe to include in cross-platform applications while providing platform-specific capabilities where needed.
