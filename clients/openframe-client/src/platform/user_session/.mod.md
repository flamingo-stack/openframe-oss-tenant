This module provides platform-specific user management utilities, currently supporting macOS with cross-platform expansion capabilities through conditional compilation.

## Key Components

- **`macos` module** - macOS-specific implementations (conditionally compiled)
- **`get_console_user`** - Retrieves the currently logged-in console user
- **`launch_as_user`** - Launches processes with specific user privileges

## Usage Example

```rust
use crate::user_management::{get_console_user, launch_as_user};

// Get the current console user on macOS
#[cfg(target_os = "macos")]
fn check_current_user() -> Result<String, Error> {
    let user = get_console_user()?;
    println!("Console user: {}", user);
    Ok(user)
}

// Launch a process as a specific user
#[cfg(target_os = "macos")]
fn launch_user_process(command: &str, user: &str) -> Result<(), Error> {
    launch_as_user(command, user)?;
    Ok(())
}
```

The module uses conditional compilation (`#[cfg(target_os = "macos")]`) to ensure platform-specific code only compiles on supported systems. This architecture allows for easy extension to other operating systems by adding additional platform-specific modules (e.g., `windows.rs`, `linux.rs`) with similar conditional compilation attributes.
