This module provides platform-specific user session management functionality, currently supporting macOS systems for operations requiring user context switching.

## Key Components

- **`macos` module** - Contains macOS-specific implementations for user session operations
- **`get_console_user()`** - Retrieves the currently logged-in console user on macOS
- **`launch_as_user()`** - Launches processes under a specific user context on macOS

## Usage Example

```rust
use crate::user_session::{get_console_user, launch_as_user};

#[cfg(target_os = "macos")]
fn example_usage() -> Result<(), Box<dyn std::error::Error>> {
    // Get the current console user
    let current_user = get_console_user()?;
    println!("Console user: {}", current_user);
    
    // Launch a process as the console user
    launch_as_user(&current_user, "/usr/bin/open", &["-a", "TextEdit"])?;
    
    Ok(())
}
```

The module uses conditional compilation to include platform-specific code only when building for macOS (`target_os = "macos"`). This design allows for future expansion to other operating systems by adding similar conditional modules for Windows, Linux, etc.
