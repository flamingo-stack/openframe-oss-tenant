A module configuration file that provides platform-specific user management functionality, currently supporting macOS with conditional compilation.

## Key Components

- **`macos` module**: Platform-specific implementation for macOS user operations (conditionally compiled)
- **`get_console_user`**: Function to retrieve the current console user (macOS only)
- **`launch_as_user`**: Function to execute processes as a specific user (macOS only)

## Usage Example

This module acts as a platform abstraction layer. When compiled on macOS, it exposes user management functions:

```rust
// This code will only compile and be available on macOS
#[cfg(target_os = "macos")]
use crate::user_management::{get_console_user, launch_as_user};

#[cfg(target_os = "macos")]
fn example_usage() {
    // Get the current console user
    if let Ok(user) = get_console_user() {
        println!("Console user: {}", user);
        
        // Launch a process as that user
        launch_as_user(&user, "/usr/bin/whoami", &[]).ok();
    }
}
```

The conditional compilation ensures that macOS-specific code is only included when building for macOS targets, making the module safe to use in cross-platform projects.
