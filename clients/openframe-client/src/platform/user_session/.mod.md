Module exports platform-specific user management functionality, currently supporting macOS systems for console user operations and launching processes as specific users.

## Key Components

- **Conditional compilation**: Uses `cfg` attributes to include macOS-specific code only when targeting macOS
- **Public exports**: Re-exports `get_console_user` and `launch_as_user` functions from the macOS implementation
- **Platform abstraction**: Provides a clean interface layer for user management operations across different operating systems

## Usage Example

```rust
// This module automatically includes the appropriate implementation based on target OS
use crate::user_management::{get_console_user, launch_as_user};

#[cfg(target_os = "macos")]
fn example_usage() -> Result<(), Box<dyn std::error::Error>> {
    // Get the current console user
    let console_user = get_console_user()?;
    println!("Console user: {}", console_user);
    
    // Launch a process as a specific user
    launch_as_user("some_username", "/path/to/executable")?;
    
    Ok(())
}
```

The module currently only supports macOS, but the structure allows for easy extension to other operating systems by adding additional `cfg` conditional modules and exports.
