This module provides platform-specific user session management functionality, currently supporting macOS with conditional compilation directives.

## Key Components

- **Platform-specific modules**: Conditionally includes the `macos` module only when compiling for macOS targets
- **Public exports**: Re-exports `get_console_user` and `launch_as_user` functions from the macOS implementation
- **Conditional compilation**: Uses `#[cfg(target_os = "macos")]` attributes to ensure platform-appropriate code inclusion

## Usage Example

```rust
// This module is automatically configured based on target platform
// On macOS, these functions will be available:

use crate::session::{get_console_user, launch_as_user};

// Get the current console user on macOS
let user = get_console_user()?;
println!("Current console user: {}", user);

// Launch a process as a specific user on macOS
launch_as_user("username", "/path/to/executable", &["arg1", "arg2"])?;
```

The module acts as a platform abstraction layer, automatically providing the correct implementation based on the target operating system during compilation. Currently only macOS is supported, but the structure allows for easy extension to other platforms by adding additional conditional modules.
