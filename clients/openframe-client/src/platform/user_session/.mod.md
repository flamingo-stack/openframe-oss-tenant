This module provides platform-specific user session management functionality, currently implementing macOS-specific operations for getting console users and launching processes as specific users.

## Key Components

- **`macos` module** - Contains macOS-specific implementations (conditionally compiled)
- **`get_console_user`** - Function to retrieve the current console user on macOS
- **`launch_as_user`** - Function to launch processes with specific user privileges on macOS

## Usage Example

```rust
#[cfg(target_os = "macos")]
use crate::user_session::{get_console_user, launch_as_user};

#[cfg(target_os = "macos")]
fn main() -> Result<(), Box<dyn std::error::Error>> {
    // Get the current console user
    let console_user = get_console_user()?;
    println!("Console user: {}", console_user);
    
    // Launch an application as the console user
    launch_as_user("/Applications/SomeApp.app", &console_user)?;
    
    Ok(())
}
```

The module uses conditional compilation to only include macOS functionality when building for macOS targets, making it a platform-aware abstraction layer for user session operations.
