This module provides platform-specific user session management functionality, currently supporting macOS with conditional compilation for cross-platform compatibility.

## Key Components

- **Conditional Compilation**: Uses `cfg` attributes to include platform-specific modules only when building for the target operating system
- **macOS Module**: Contains native macOS user session functions when compiled on macOS
- **Public Re-exports**: Exposes `get_console_user` and `launch_as_user` functions from the platform-specific implementation

## Usage Example

```rust
// These functions are only available when compiled on macOS
#[cfg(target_os = "macos")]
use your_crate::{get_console_user, launch_as_user};

#[cfg(target_os = "macos")]
fn handle_user_session() -> Result<(), Box<dyn std::error::Error>> {
    // Get the current console user
    let user = get_console_user()?;
    println!("Current console user: {}", user);
    
    // Launch a process as the console user
    launch_as_user("some_command", &["arg1", "arg2"])?;
    
    Ok(())
}
```

The module structure allows for easy extension to other operating systems by adding similar conditional modules for Windows, Linux, etc., while maintaining a consistent public API across platforms.
