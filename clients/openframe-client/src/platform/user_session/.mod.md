This module provides platform-specific user session management functionality, currently supporting macOS systems for getting console user information and launching processes as specific users.

## Key Components

- **get_console_user** - Function to retrieve the current console user on macOS
- **launch_as_user** - Function to launch processes with specific user privileges on macOS
- **Conditional compilation** - Uses `#[cfg(target_os = "macos")]` to include macOS-specific implementations only when building for macOS

## Usage Example

```rust
// This module is automatically included when building for macOS
use crate::get_console_user;
use crate::launch_as_user;

// Get the current console user (macOS only)
if let Ok(user) = get_console_user() {
    println!("Console user: {}", user);
}

// Launch a process as a specific user (macOS only)
if let Err(e) = launch_as_user("username", "/path/to/executable") {
    eprintln!("Failed to launch process: {}", e);
}
```

This module follows Rust's conditional compilation pattern to provide platform-specific functionality while maintaining a clean cross-platform API. The actual implementations are contained in the `macos` submodule, which is only compiled when targeting macOS systems.
