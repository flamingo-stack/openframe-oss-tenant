Provides macOS-specific user management and process launching utilities, enabling applications to identify the current console user and spawn processes under their context rather than as root.

## Key Components

- **`ConsoleUser`** - Struct containing username and UID of the console user
- **`get_console_user()`** - Identifies the current console user by checking `/dev/console` ownership
- **`launch_as_user()`** - Launches executables as a specific user with fallback mechanisms
- **`launch_via_launchctl()`** - Uses macOS `launchctl asuser` for process launching (preferred method)
- **`launch_via_sudo()`** - Falls back to `sudo -u` if launchctl fails

## Usage Example

```rust
use anyhow::Result;

#[tokio::main]
async fn main() -> Result<()> {
    // Get the current console user
    if let Some(user) = get_console_user() {
        println!("Console user: {} (UID: {})", user.username, user.uid);
        
        // Launch an application as that user
        let args = vec!["--version".to_string()];
        let child = launch_as_user("/usr/bin/whoami", &args, &user).await?;
        
        // Process will run as the console user, not root
        let output = child.wait_with_output().await?;
        println!("Output: {}", String::from_utf8_lossy(&output.stdout));
    }
    
    Ok(())
}
```

The module implements a robust fallback system: first attempting to use macOS's native `launchctl asuser` command, then falling back to `sudo -u` if needed. This ensures processes can be launched with proper user context for GUI applications that require specific user sessions.
