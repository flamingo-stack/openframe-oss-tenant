This file provides macOS-specific utilities for detecting the current console user and launching processes as that user, essential for running GUI applications in the correct user context on macOS systems.

## Key Components

- **`ConsoleUser`**: Struct containing username and UID of the current console user
- **`get_console_user()`**: Detects the current logged-in user by checking `/dev/console` ownership
- **`launch_as_user()`**: Launches processes as the console user with fallback mechanisms
- **`launch_via_launchctl()`**: Uses macOS `launchctl asuser` for process launching (preferred method)
- **`launch_via_sudo()`**: Fallback method using `sudo -u` for process launching

## Usage Example

```rust
use anyhow::Result;

#[tokio::main]
async fn main() -> Result<()> {
    // Get the current console user
    let user = get_console_user()
        .ok_or_else(|| anyhow::anyhow!("No console user found"))?;
    
    println!("Console user: {} (UID: {})", user.username, user.uid);
    
    // Launch a GUI application as the console user
    let args = vec!["--help".to_string()];
    let child = launch_as_user("/Applications/Calculator.app/Contents/MacOS/Calculator", &args, &user)
        .await?;
    
    // Wait for the process to complete
    let status = child.wait_with_output().await?;
    println!("Process exited with status: {}", status.status);
    
    Ok(())
}
```

This module handles the complexity of running processes in the correct user context on macOS, automatically falling back from `launchctl asuser` to `sudo -u` if needed, which is particularly important for GUI applications that need to run in the user's desktop environment.
