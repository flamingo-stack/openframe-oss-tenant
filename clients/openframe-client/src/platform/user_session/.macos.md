MacOS-specific utilities for user management and process launching with proper user context switching.

## Key Components

- **`ConsoleUser`** - Structure representing a console user with username and UID
- **`get_console_user()`** - Detects the current console user by checking `/dev/console` ownership
- **`launch_as_user()`** - Launches executables as a specific user with fallback mechanisms
- **`launch_via_launchctl()`** - Primary launch method using macOS `launchctl asuser`
- **`launch_via_sudo()`** - Fallback launch method using `sudo -u`

## Usage Example

```rust
use your_crate::macos::{get_console_user, launch_as_user};

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    // Get the current console user
    let user = get_console_user()
        .ok_or_else(|| anyhow::anyhow!("No console user found"))?;
    
    println!("Console user: {} (UID: {})", user.username, user.uid);
    
    // Launch an application as that user
    let args = vec!["-some".to_string(), "args".to_string()];
    let mut child = launch_as_user("/Applications/MyApp.app/Contents/MacOS/MyApp", &args, &user).await?;
    
    // Wait for the process to complete
    let status = child.wait().await?;
    println!("Process exited with: {}", status);
    
    Ok(())
}
```

The module provides robust user detection and process launching specifically designed for macOS environments, with automatic fallback from `launchctl` to `sudo` for maximum compatibility.
