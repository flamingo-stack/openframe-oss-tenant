A macOS-specific utility module that provides functionality for detecting console users and launching processes with proper user context, essential for GUI applications that need to run under the logged-in user rather than root.

## Key Components

- **`ConsoleUser`** - Struct containing username and UID of the current console user
- **`get_console_user()`** - Detects the active console user by checking `/dev/console` ownership
- **`launch_as_user()`** - Launches executables as a specific user with fallback mechanisms
- **`launch_via_launchctl()`** - Primary launch method using macOS `launchctl asuser`
- **`launch_via_sudo()`** - Fallback launch method using `sudo -u`

## Usage Example

```rust
use anyhow::Result;

#[tokio::main]
async fn main() -> Result<()> {
    // Get the current console user
    let user = get_console_user()
        .ok_or_else(|| anyhow::anyhow!("No console user found"))?;
    
    println!("Console user: {} (UID: {})", user.username, user.uid);
    
    // Launch an application as the console user
    let args = vec!["-some".to_string(), "args".to_string()];
    let mut child = launch_as_user("/Applications/MyApp.app/Contents/MacOS/MyApp", &args, &user).await?;
    
    // Wait for the process to complete
    let status = child.wait().await?;
    println!("Process exited with: {:?}", status);
    
    Ok(())
}
```

This module is particularly useful for system services that need to launch GUI applications or user-specific processes while maintaining proper macOS security contexts and user permissions.
