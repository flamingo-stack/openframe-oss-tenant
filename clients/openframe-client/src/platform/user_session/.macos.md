Provides macOS-specific utilities for user identification and process launching, enabling applications to run commands as the currently logged-in console user rather than as root.

## Key Components

- **`ConsoleUser`** - Struct containing username and UID of the console user
- **`get_console_user()`** - Identifies the current console user by checking `/dev/console` ownership
- **`launch_as_user()`** - Launches executables as a specific user with fallback mechanisms
- **`launch_via_launchctl()`** - Primary method using macOS `launchctl asuser` command
- **`launch_via_sudo()`** - Fallback method using `sudo -u` for process launching

## Usage Example

```rust
use anyhow::Result;

#[tokio::main]
async fn main() -> Result<()> {
    // Get the current console user
    let user = get_console_user()
        .ok_or_else(|| anyhow::anyhow!("No console user found"))?;
    
    println!("Console user: {} (UID: {})", user.username, user.uid);
    
    // Launch an application as the console user
    let args = vec!["--version".to_string()];
    let child = launch_as_user("/usr/bin/whoami", &args, &user).await?;
    
    // Process will run as the console user, not root
    let output = child.wait_with_output().await?;
    println!("Output: {}", String::from_utf8_lossy(&output.stdout));
    
    Ok(())
}
```

The module automatically handles the complexity of privilege escalation on macOS, first attempting the preferred `launchctl asuser` method before falling back to `sudo -u` if needed.
