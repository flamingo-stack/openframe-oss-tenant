This module provides macOS-specific functionality for detecting the current console user and launching processes under their user context, essential for GUI applications that need to run with proper user permissions.

## Key Components

- **`ConsoleUser`** - Structure containing username and UID of the current console user
- **`get_console_user()`** - Detects the current console user by checking `/dev/console` ownership
- **`launch_as_user()`** - Launches executables as a specific user with fallback mechanisms
- **`launch_via_launchctl()`** - Uses macOS `launchctl asuser` for process launching
- **`launch_via_sudo()`** - Fallback method using `sudo -u` for process launching

## Usage Example

```rust
use tokio::process::Command;

// Get the current console user
if let Some(user) = get_console_user() {
    println!("Console user: {} (UID: {})", user.username, user.uid);
    
    // Launch an application as that user
    let args = vec!["--flag".to_string(), "value".to_string()];
    match launch_as_user("/Applications/MyApp.app/Contents/MacOS/MyApp", &args, &user).await {
        Ok(mut child) => {
            println!("Process launched with PID: {:?}", child.id());
            let _ = child.wait().await;
        },
        Err(e) => eprintln!("Failed to launch process: {}", e),
    }
}
```

The module automatically tries `launchctl asuser` first (preferred on macOS) and falls back to `sudo -u` if needed, ensuring reliable process launching across different macOS configurations.
