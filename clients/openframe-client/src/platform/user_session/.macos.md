Provides macOS-specific utilities for identifying console users and launching processes with user privileges, using both `launchctl` and `sudo` fallback mechanisms.

## Key Components

- **`ConsoleUser`** - Struct containing username and UID of the current console user
- **`get_console_user()`** - Identifies the active console user by checking `/dev/console` ownership
- **`launch_as_user()`** - Launches executables as a specific user with automatic fallback strategy
- **`launch_via_launchctl()`** - Primary launch method using macOS `launchctl asuser`
- **`launch_via_sudo()`** - Fallback launch method using `sudo -u`

## Usage Example

```rust
use crate::macos::{get_console_user, launch_as_user};

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    // Get the current console user
    let user = get_console_user()
        .ok_or_else(|| anyhow::anyhow!("No console user found"))?;
    
    println!("Console user: {} (UID: {})", user.username, user.uid);
    
    // Launch an application as that user
    let args = vec!["--version".to_string()];
    let mut child = launch_as_user("/usr/bin/whoami", &args, &user).await?;
    
    // Wait for completion
    let status = child.wait().await?;
    println!("Process exited with: {}", status);
    
    Ok(())
}
```

The module handles edge cases like missing executables and provides robust error handling with automatic fallback from `launchctl` to `sudo` when necessary.
