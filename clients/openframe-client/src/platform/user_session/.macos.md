This module provides macOS-specific utilities for detecting the current console user and launching processes under their account, essential for running GUI applications with proper user context in system-level services.

## Key Components

- **`ConsoleUser`** - Struct containing username and UID of the console user
- **`get_console_user()`** - Detects the active console user by examining `/dev/console` ownership
- **`launch_as_user()`** - Spawns processes as a specific user with fallback mechanisms
- **`launch_via_launchctl()`** - Primary launch method using macOS `launchctl asuser`
- **`launch_via_sudo()`** - Fallback launch method using `sudo -u`

## Usage Example

```rust
use anyhow::Result;

#[tokio::main]
async fn main() -> Result<()> {
    // Get the current console user
    if let Some(user) = get_console_user() {
        println!("Console user: {} (UID: {})", user.username, user.uid);
        
        // Launch an application as that user
        let args = vec!["--version".to_string()];
        let child = launch_as_user("/usr/bin/open", &args, &user).await?;
        
        // Wait for completion
        let status = child.wait_with_output().await?;
        println!("Process completed with status: {}", status.status);
    }
    
    Ok(())
}
```

The module automatically handles the complexity of user detection and process launching, trying `launchctl asuser` first (preferred for GUI apps) and falling back to `sudo -u` if needed. This ensures proper session context for applications that require user interaction or access to user-specific resources.
