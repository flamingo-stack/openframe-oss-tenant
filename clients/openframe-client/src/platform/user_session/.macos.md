macOS-specific utility functions for user session management and process launching with proper user context switching.

## Key Components

- **`ConsoleUser`** - Struct representing the currently logged-in console user with username and UID
- **`get_console_user()`** - Detects the active console user by checking `/dev/console` ownership
- **`launch_as_user()`** - Launches processes as a specific user with fallback mechanisms
- **`launch_via_launchctl()`** - Primary method using macOS `launchctl asuser` command
- **`launch_via_sudo()`** - Fallback method using `sudo -u` for user context switching

## Usage Example

```rust
use anyhow::Result;

#[tokio::main]
async fn main() -> Result<()> {
    // Get the current console user
    if let Some(user) = get_console_user() {
        println!("Console user: {} ({})", user.username, user.uid);
        
        // Launch an application as that user
        let args = vec!["--version".to_string()];
        let child = launch_as_user("/usr/bin/whoami", &args, &user).await?;
        
        // Process will run in user's session context
        let output = child.wait_with_output().await?;
        println!("Output: {}", String::from_utf8_lossy(&output.stdout));
    }
    
    Ok(())
}
```

This module handles the macOS-specific challenges of launching GUI applications and processes in the correct user session, which is essential for proper desktop integration and user experience in MSP automation tools.
