macOS-specific utilities for process management and user context operations, providing functionality to identify console users and launch processes with appropriate user privileges.

## Key Components

- **`ConsoleUser`** - Struct representing a macOS console user with username and UID
- **`get_console_user()`** - Identifies the current console user by examining `/dev/console` ownership
- **`launch_as_user()`** - Launches executables as a specific user with fallback mechanisms
- **`launch_via_launchctl()`** - Uses macOS `launchctl asuser` for process spawning (preferred method)
- **`launch_via_sudo()`** - Falls back to `sudo -u` when launchctl fails

## Usage Example

```rust
use anyhow::Result;

#[tokio::main]
async fn main() -> Result<()> {
    // Get the current console user
    if let Some(user) = get_console_user() {
        println!("Console user: {} (UID: {})", user.username, user.uid);
        
        // Launch an application as that user
        let args = vec!["--version".to_string()];
        let mut child = launch_as_user("/usr/bin/whoami", &args, &user).await?;
        
        // Wait for completion
        let status = child.wait().await?;
        println!("Process finished with status: {}", status);
    } else {
        println!("No regular user at console");
    }
    
    Ok(())
}
```

The module automatically handles privilege escalation fallbacks, attempting `launchctl asuser` first (macOS native) before falling back to `sudo -u` for maximum compatibility across different macOS configurations.
