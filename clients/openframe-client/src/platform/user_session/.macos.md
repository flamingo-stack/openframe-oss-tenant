Provides macOS-specific utilities for user detection and privilege management, enabling secure process launching under the correct user context in the OpenFrame platform.

## Key Components

- **`ConsoleUser`** - Struct containing username and UID of the current console user
- **`get_console_user()`** - Detects the active console user by querying `/dev/console` ownership
- **`launch_as_user()`** - Launches processes as a specific user with fallback mechanisms
- **`launch_via_launchctl()`** - Primary method using macOS `launchctl asuser` command
- **`launch_via_sudo()`** - Fallback method using `sudo -u` for process execution

## Usage Example

```rust
use anyhow::Result;

#[tokio::main]
async fn main() -> Result<()> {
    // Detect current console user
    if let Some(user) = get_console_user() {
        println!("Console user: {} (UID: {})", user.username, user.uid);
        
        // Launch application as that user
        let args = vec!["--version".to_string()];
        let child = launch_as_user("/usr/bin/whoami", &args, &user).await?;
        
        // Process will run under the detected user's context
        let output = child.wait_with_output().await?;
        println!("Output: {}", String::from_utf8_lossy(&output.stdout));
    }
    
    Ok(())
}
```

The module handles macOS-specific user privilege scenarios, attempting `launchctl asuser` first (preferred for GUI applications) before falling back to `sudo -u` if needed. This ensures proper user context for OpenFrame operations on macOS systems.
