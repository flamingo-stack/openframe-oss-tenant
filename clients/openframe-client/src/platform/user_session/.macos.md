macOS-specific utilities for managing console user sessions and launching processes under user context, providing fallback mechanisms between `launchctl` and `sudo` for cross-user process execution.

## Key Components

- **`ConsoleUser`** - Struct containing username and UID of the current console user
- **`get_console_user()`** - Identifies the active console user by querying `/dev/console` ownership
- **`launch_as_user()`** - Launches executables as a specific user with automatic fallback strategy
- **`launch_via_launchctl()`** - Primary method using macOS `launchctl asuser` for user context switching
- **`launch_via_sudo()`** - Fallback method using `sudo -u` when launchctl fails

## Usage Example

```rust
use anyhow::Result;

#[tokio::main]
async fn main() -> Result<()> {
    // Get the current console user
    if let Some(user) = get_console_user() {
        println!("Console user: {} (UID: {})", user.username, user.uid);
        
        // Launch an application as the console user
        let args = vec!["--version".to_string()];
        let child = launch_as_user("/usr/bin/whoami", &args, &user).await?;
        
        // Wait for the process to complete
        let output = child.wait_with_output().await?;
        println!("Output: {}", String::from_utf8_lossy(&output.stdout));
    } else {
        println!("No console user found");
    }
    
    Ok(())
}
```

The module automatically handles privilege escalation and user context switching, making it ideal for MSP tools that need to run GUI applications or user-specific commands on macOS systems while maintaining proper user session isolation.
