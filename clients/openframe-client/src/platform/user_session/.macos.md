Provides macOS-specific utilities for identifying the current console user and launching processes under their user context. This module handles privilege escalation and user switching operations commonly needed in macOS system administration.

## Key Components

- **ConsoleUser** - Structure containing username and UID of the console user
- **get_console_user()** - Identifies the current console user by checking `/dev/console` ownership
- **launch_as_user()** - Launches executables as a specific user with fallback mechanisms
- **launch_via_launchctl()** - Primary launch method using macOS `launchctl asuser`
- **launch_via_sudo()** - Fallback launch method using `sudo -u`

## Usage Example

```rust
use anyhow::Result;

#[tokio::main]
async fn main() -> Result<()> {
    // Get the current console user
    if let Some(user) = get_console_user() {
        println!("Console user: {} (UID: {})", user.username, user.uid);
        
        // Launch an application as the console user
        let args = vec!["--help".to_string()];
        let mut child = launch_as_user("/usr/bin/open", &args, &user).await?;
        
        // Wait for the process to complete
        let status = child.wait().await?;
        println!("Process finished with status: {:?}", status);
    } else {
        println!("No console user found");
    }
    
    Ok(())
}
```

The module automatically tries `launchctl asuser` first (preferred method) and falls back to `sudo -u` if needed, providing robust process launching capabilities across different macOS environments.
