macOS-specific utilities for detecting the current console user and launching processes under their privileges, essential for GUI applications that need to run with proper user context.

## Key Components

- **`ConsoleUser`** - Struct containing username and UID of the current console user
- **`get_console_user()`** - Detects the active console user by checking `/dev/console` ownership
- **`launch_as_user()`** - Launches executables as a specific user with fallback mechanisms
- **`launch_via_launchctl()`** - Primary launch method using macOS `launchctl asuser`
- **`launch_via_sudo()`** - Fallback launch method using `sudo -u`

## Usage Example

```rust
use anyhow::Result;

#[tokio::main]
async fn main() -> Result<()> {
    // Detect current console user
    let user = get_console_user()
        .ok_or_else(|| anyhow::anyhow!("No console user found"))?;
    
    println!("Console user: {} (UID: {})", user.username, user.uid);
    
    // Launch application as the console user
    let args = vec!["--version".to_string()];
    let mut child = launch_as_user("/usr/bin/whoami", &args, &user).await?;
    
    // Wait for process completion
    let status = child.wait().await?;
    println!("Process exited with: {}", status);
    
    Ok(())
}
```

The module automatically handles privilege escalation fallbacks, trying `launchctl asuser` first (preferred for GUI applications) then falling back to `sudo -u` if needed.
