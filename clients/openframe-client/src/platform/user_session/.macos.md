macOS-specific utilities for detecting the logged-in console user and launching processes in their GUI session context.

## Key Components

### `ConsoleUser`
A struct holding the `username` and `uid` of the currently active console user.

### Public Functions

| Function | Description |
|----------|-------------|
| `get_console_user()` | Reads `/dev/console` ownership via `stat` to identify the active GUI user; filters out `root` and system accounts (prefixed with `_`) |
| `launch_as_user()` | Launches an executable in the console user's session; tries `launchctl asuser` first, falls back to `sudo -u` |
| `is_gui_session_ready()` | Checks whether the user's GUI session is active by verifying `Dock` and `Finder` are running |
| `is_process_running()` | Uses `pgrep -f` to check if a process is already running by executable path |

### Private Helpers

| Function | Description |
|----------|-------------|
| `launch_via_launchctl()` | Launches via `launchctl asuser <uid>`; detects `.app` bundles and uses `open -a` accordingly |
| `launch_via_sudo()` | Fallback launcher using `sudo -u <username>` |
| `extract_app_bundle_path()` | Walks path ancestors to detect a `.app` bundle root |

## Usage Example

```rust
use macos::{get_console_user, is_gui_session_ready, launch_as_user};

async fn run() -> anyhow::Result<()> {
    let user = get_console_user().expect("No console user logged in");

    // Wait until Dock and Finder are up
    if !is_gui_session_ready(user.uid).await {
        anyhow::bail!("GUI session not ready for UID {}", user.uid);
    }

    // Launch an app bundle in the user's session
    let args = vec!["--background".to_string()];
    let child = launch_as_user(
        "/Applications/MyApp.app/Contents/MacOS/MyApp",
        &args,
        &user,
    ).await?;

    println!("Launched with PID: {:?}", child.id());
    Ok(())
}
```

> **Note:** `launchctl asuser` is preferred over `sudo -u` because it correctly inherits the user's GUI session environment, including `DISPLAY`, Keychain access, and launch services context — critical for `.app` bundles.
