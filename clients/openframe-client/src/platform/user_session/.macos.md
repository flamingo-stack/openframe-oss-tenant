Provides macOS-specific utilities for identifying the console user and launching processes under that user's context, essential for GUI applications that need to run with proper user permissions.

## Key Components

- **`ConsoleUser`** - Struct containing username and UID of the current console user
- **`get_console_user()`** - Identifies the active console user by checking `/dev/console` ownership
- **`launch_as_user()`** - Launches executables as a specific user with fallback mechanisms
- **`launch_via_launchctl()`** - Primary launch method using macOS `launchctl asuser`
- **`launch_via_sudo()`** - Fallback launch method using `sudo -u`

## Usage Example

```rust
use tokio::process::Command;

// Get the current console user
if let Some(user) = get_console_user() {
    println!("Console user: {} (UID: {})", user.username, user.uid);
    
    // Launch an application as that user
    let args = vec!["--version".to_string()];
    match launch_as_user("/usr/bin/open", &args, &user).await {
        Ok(mut child) => {
            println!("Process launched with PID: {:?}", child.id());
            let _ = child.wait().await;
        }
        Err(e) => eprintln!("Failed to launch: {}", e),
    }
} else {
    eprintln!("No console user found");
}
```

The module implements a robust fallback strategy, attempting `launchctl asuser` first (preferred for macOS) and falling back to `sudo -u` if needed, ensuring reliable process launching across different macOS configurations.
