This file provides macOS-specific utilities for detecting the console user and launching processes as that user, essential for GUI applications that need to run in the user's graphical session rather than as system services.

## Key Components

- **`ConsoleUser`** - Struct containing username and UID of the current console user
- **`get_console_user()`** - Detects the active console user by examining `/dev/console` ownership
- **`launch_as_user()`** - Primary function to launch processes as the console user with fallback mechanisms
- **`launch_via_launchctl()`** - Uses macOS `launchctl asuser` for proper user session context
- **`launch_via_sudo()`** - Fallback method using `sudo -u` when launchctl fails

## Usage Example

```rust
use anyhow::Result;

#[tokio::main]
async fn main() -> Result<()> {
    // Get the current console user
    let user = get_console_user()
        .ok_or_else(|| anyhow::anyhow!("No console user found"))?;
    
    println!("Console user: {} (UID: {})", user.username, user.uid);
    
    // Launch a GUI application as the console user
    let args = vec!["--version".to_string()];
    let mut child = launch_as_user("/usr/bin/open", &args, &user).await?;
    
    // Wait for the process to complete
    let status = child.wait().await?;
    println!("Process exited with: {:?}", status);
    
    Ok(())
}
```

The implementation prioritizes `launchctl asuser` for proper macOS user session handling, falling back to `sudo -u` if needed. This ensures GUI applications can access the user's desktop environment and display properly.
