This module provides macOS-specific utilities for user detection and process launching as different users. It handles identifying the current console user and launching executables under that user's context using native macOS tools.

## Key Components

- **`ConsoleUser`** - Structure representing a console user with username and UID
- **`get_console_user()`** - Detects the current console user by examining `/dev/console` ownership
- **`launch_as_user()`** - Launches an executable as a specific user with fallback mechanisms
- **`launch_via_launchctl()`** - Uses macOS `launchctl asuser` for process launching
- **`launch_via_sudo()`** - Fallback method using `sudo -u` for process launching

## Usage Example

```rust
use anyhow::Result;

#[tokio::main]
async fn main() -> Result<()> {
    // Get the current console user
    if let Some(user) = get_console_user() {
        println!("Console user: {} (UID: {})", user.username, user.uid);
        
        // Launch an application as that user
        let args = vec!["--help".to_string()];
        let child = launch_as_user("/usr/bin/whoami", &args, &user).await?;
        
        // Wait for the process to complete
        let output = child.wait_with_output().await?;
        println!("Output: {}", String::from_utf8_lossy(&output.stdout));
    } else {
        println!("No console user found");
    }
    
    Ok(())
}
```

The module implements a robust fallback strategy: it first attempts to use `launchctl asuser` (the preferred macOS method), and falls back to `sudo -u` if that fails. This ensures maximum compatibility across different macOS configurations and permission setups.
