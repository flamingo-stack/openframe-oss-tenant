macOS-specific utilities for launching processes as the current console user, with fallback mechanisms for privilege escalation.

## Key Components

**Structures:**
- `ConsoleUser` - Represents the current console user with username and UID

**Functions:**
- `get_console_user()` - Detects the current console user by checking `/dev/console` ownership
- `launch_as_user()` - Launches executables as the console user with automatic fallback
- `launch_via_launchctl()` - Primary launch method using macOS `launchctl asuser`
- `launch_via_sudo()` - Fallback launch method using `sudo -u`

## Usage Example

```rust
use anyhow::Result;

#[tokio::main]
async fn main() -> Result<()> {
    // Get the current console user
    let user = get_console_user()
        .ok_or_else(|| anyhow::anyhow!("No console user found"))?;
    
    println!("Console user: {} (UID: {})", user.username, user.uid);
    
    // Launch an application as the console user
    let args = vec!["--version".to_string()];
    let mut child = launch_as_user("/usr/bin/whoami", &args, &user).await?;
    
    // Wait for the process to complete
    let status = child.wait().await?;
    println!("Process exited with: {}", status);
    
    Ok(())
}
```

The module handles privilege escalation gracefully, attempting `launchctl asuser` first (recommended for GUI apps) before falling back to `sudo -u`. It includes validation to ensure executables exist and proper error handling for failed launches.
