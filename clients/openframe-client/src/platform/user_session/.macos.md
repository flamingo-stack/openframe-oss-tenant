Provides macOS-specific utilities for detecting the current console user and launching processes as that user, using either `launchctl` or `sudo` as fallback mechanisms.

## Key Components

### Types
- **`ConsoleUser`** - Structure containing username and UID of the console user

### Functions
- **`get_console_user()`** - Detects the current console user by checking `/dev/console` ownership
- **`launch_as_user()`** - Launches executable as specific user with fallback strategy
- **`launch_via_launchctl()`** - Uses macOS `launchctl asuser` for process launching
- **`launch_via_sudo()`** - Fallback method using `sudo -u` for process launching

## Usage Example

```rust
use anyhow::Result;

#[tokio::main]
async fn main() -> Result<()> {
    // Get the current console user
    if let Some(user) = get_console_user() {
        println!("Console user: {} (UID: {})", user.username, user.uid);
        
        // Launch an application as the console user
        let args = vec![String::from("--version")];
        let child = launch_as_user("/usr/bin/whoami", &args, &user).await?;
        
        // Wait for the process to complete
        let output = child.wait_with_output().await?;
        println!("Output: {}", String::from_utf8_lossy(&output.stdout));
    }
    
    Ok(())
}
```

The module automatically tries `launchctl asuser` first (preferred on macOS) and falls back to `sudo -u` if that fails, ensuring reliable process launching across different macOS configurations.
