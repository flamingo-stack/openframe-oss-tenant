Provides macOS-specific utilities for managing console user sessions and launching applications with appropriate user privileges through system commands.

## Key Components

- **`ConsoleUser`** - Structure containing username and UID of the current console user
- **`get_console_user()`** - Retrieves the active console user by examining `/dev/console` ownership
- **`launch_as_user()`** - Launches applications as a specific user with fallback mechanisms
- **`launch_via_launchctl()`** - Primary launch method using macOS `launchctl asuser`
- **`launch_via_sudo()`** - Fallback launch method using `sudo -u`

## Usage Example

```rust
use tokio::process::Child;

// Get the current console user
if let Some(user) = get_console_user() {
    println!("Console user: {} (UID: {})", user.username, user.uid);
    
    // Launch an application as that user
    let args = vec!["--version".to_string()];
    match launch_as_user("/usr/bin/whoami", &args, &user).await {
        Ok(mut child) => {
            let output = child.wait_with_output().await?;
            println!("Output: {}", String::from_utf8_lossy(&output.stdout));
        }
        Err(e) => eprintln!("Failed to launch: {}", e),
    }
} else {
    eprintln!("No regular user found at console");
}
```

The module implements a robust approach to user privilege management on macOS, first attempting to use `launchctl asuser` for proper session context, then falling back to `sudo` if needed. This ensures applications launch with the correct user environment and permissions.
