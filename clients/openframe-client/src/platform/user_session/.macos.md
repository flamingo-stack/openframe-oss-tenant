macOS-specific utilities for managing user sessions and launching processes as the console user, providing privilege escalation and user context switching functionality.

## Key Components

- **`ConsoleUser`** - Structure representing a console user with username and UID
- **`get_console_user()`** - Detects the current console user by checking `/dev/console` ownership
- **`launch_as_user()`** - Launches executables as a specific user with fallback mechanisms
- **`launch_via_launchctl()`** - Uses macOS `launchctl asuser` for process launching
- **`launch_via_sudo()`** - Fallback method using `sudo -u` for process launching

## Usage Example

```rust
use anyhow::Result;

#[tokio::main]
async fn main() -> Result<()> {
    // Get the current console user
    if let Some(user) = get_console_user() {
        println!("Console user: {} (UID: {})", user.username, user.uid);
        
        // Launch an application as the console user
        let args = vec!["--version".to_string()];
        let child = launch_as_user("/usr/bin/whoami", &args, &user).await?;
        
        // Wait for the process to complete
        let output = child.wait_with_output().await?;
        println!("Output: {}", String::from_utf8_lossy(&output.stdout));
    } else {
        println!("No console user found");
    }
    
    Ok(())
}
```

The module automatically falls back from `launchctl asuser` to `sudo -u` if the preferred method fails, ensuring reliable process launching across different macOS configurations.
