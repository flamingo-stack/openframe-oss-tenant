macOS-specific utilities for detecting console users and launching processes under user contexts, with fallback mechanisms for process spawning.

## Key Components

- **`ConsoleUser`** - Struct containing username and UID of the current console user
- **`get_console_user()`** - Detects the active console user by examining `/dev/console` ownership
- **`launch_as_user()`** - Launches executables as a specific user with automatic fallback between methods
- **`launch_via_launchctl()`** - Primary launch method using macOS `launchctl asuser`
- **`launch_via_sudo()`** - Fallback launch method using `sudo -u`

## Usage Example

```rust
use anyhow::Result;

#[tokio::main]
async fn main() -> Result<()> {
    // Get the current console user
    if let Some(user) = get_console_user() {
        println!("Console user: {} (UID: {})", user.username, user.uid);
        
        // Launch an application as that user
        let args = vec!["--version".to_string()];
        let child = launch_as_user("/usr/bin/whoami", &args, &user).await?;
        
        // Process will run with user privileges
        let output = child.wait_with_output().await?;
        println!("Output: {}", String::from_utf8_lossy(&output.stdout));
    } else {
        println!("No console user detected");
    }
    
    Ok(())
}
```

The module provides robust user detection and process launching with automatic fallback from `launchctl` to `sudo`, ensuring compatibility across different macOS configurations and security contexts.
