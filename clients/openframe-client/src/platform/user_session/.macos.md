This module provides macOS-specific utilities for identifying the current console user and launching processes under their privileges. It handles user detection by examining `/dev/console` ownership and offers two fallback mechanisms for process execution.

## Key Components

- **`ConsoleUser`** - Structure containing username and UID of the current console user
- **`get_console_user()`** - Detects the active console user by checking `/dev/console` ownership
- **`launch_as_user()`** - Public interface for launching processes as a specific user with fallback mechanisms
- **`launch_via_launchctl()`** - Primary launch method using macOS `launchctl asuser`
- **`launch_via_sudo()`** - Fallback launch method using `sudo -u`

## Usage Example

```rust
use anyhow::Result;

#[tokio::main]
async fn main() -> Result<()> {
    // Get the current console user
    let user = get_console_user()
        .ok_or_else(|| anyhow::anyhow!("No console user found"))?;
    
    println!("Console user: {} (UID: {})", user.username, user.uid);

    // Launch an application as that user
    let args = vec![String::from("--help")];
    let child = launch_as_user("/usr/bin/open", &args, &user).await?;
    
    // Wait for the process to complete
    let output = child.wait_with_output().await?;
    println!("Exit status: {}", output.status);
    
    Ok(())
}
```

The module automatically falls back from `launchctl asuser` to `sudo -u` if the primary method fails, ensuring robust process launching across different macOS configurations and permission contexts.
