Provides macOS-specific utilities for detecting the current console user and launching processes in their GUI session context, used by the Flamingo agent to run applications as the logged-in user from a privileged daemon.

## Key Components

- **`ConsoleUser`** — Struct holding the console user's `username` and `uid`, derived from `/dev/console` ownership
- **`get_console_user()`** — Detects the active console user via `stat`, filters out `root` and system accounts (prefixed with `_`), and resolves their UID via `id -u`
- **`launch_as_user()`** — Spawns a process in the console user's session; tries `launchctl asuser` first, falls back to `sudo -u`
- **`is_gui_session_ready()`** — Checks whether the user's GUI session is active by verifying `Dock` and `Finder` are running via `pgrep`
- **`is_process_running()`** — Checks if a process is already running by executable path using `pgrep -f`
- **`launch_via_launchctl()`** *(private)* — Handles `.app` bundles via `open -a` and plain executables directly under `launchctl asuser <uid>`
- **`extract_app_bundle_path()`** *(private)* — Walks path ancestors to detect if the executable lives inside a `.app` bundle
- **`launch_via_sudo()`** *(private)* — Fallback launcher using `sudo -u <username>`

## Usage Example

```rust
use crate::macos::{get_console_user, is_gui_session_ready, launch_as_user};

async fn start_agent_ui(executable: &str) -> anyhow::Result<()> {
    let user = get_console_user()
        .ok_or_else(|| anyhow::anyhow!("No console user found"))?;

    // Wait until Dock + Finder are up before launching
    if !is_gui_session_ready(user.uid).await {
        anyhow::bail!("GUI session not ready for UID {}", user.uid);
    }

    let args = vec!["--background".to_string()];
    let child = launch_as_user(executable, &args, &user).await?;

    println!("Launched PID: {:?}", child.id());
    Ok(())
}
```

> **Note:** `.app` bundles are detected automatically — pass the inner binary path and `launch_via_launchctl` will resolve the bundle root and invoke `open -a` instead of executing the binary directly.
