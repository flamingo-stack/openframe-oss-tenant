macOS-specific utilities for managing user processes and console sessions. Provides functionality to detect the current console user and launch applications as that user using native macOS tools.

## Key Components

- **`ConsoleUser`** - Struct containing username and UID of the console user
- **`get_console_user()`** - Detects the current console user by examining `/dev/console` ownership
- **`launch_as_user()`** - Launches executables as a specific user with fallback mechanisms
- **`launch_via_launchctl()`** - Uses macOS `launchctl asuser` for privilege-aware process launching
- **`launch_via_sudo()`** - Fallback method using `sudo -u` for user switching

## Usage Example

```rust
use your_crate::macos::{get_console_user, launch_as_user};

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    // Detect current console user
    if let Some(user) = get_console_user() {
        println!("Console user: {} (UID: {})", user.username, user.uid);
        
        // Launch an application as the console user
        let args = vec!["--version".to_string()];
        let mut child = launch_as_user("/usr/bin/whoami", &args, &user).await?;
        
        let status = child.wait().await?;
        println!("Process exited with: {:?}", status);
    } else {
        println!("No console user found");
    }
    
    Ok(())
}
```

The module implements a robust fallback strategy where `launch_via_launchctl()` is attempted first (preferred on macOS), falling back to `launch_via_sudo()` if needed. This ensures compatibility across different macOS configurations and security contexts.
