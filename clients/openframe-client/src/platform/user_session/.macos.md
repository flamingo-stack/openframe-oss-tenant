Provides macOS-specific utilities for identifying console users and launching processes under their context, with fallback mechanisms between `launchctl` and `sudo`.

## Key Components

- **`ConsoleUser`** - Struct containing username and UID of the current console user
- **`get_console_user()`** - Identifies the active console user by checking `/dev/console` ownership
- **`launch_as_user()`** - Launches executables as a specific user with automatic fallback between methods
- **`launch_via_launchctl()`** - Primary launch method using macOS `launchctl asuser`
- **`launch_via_sudo()`** - Fallback launch method using `sudo -u`

## Usage Example

```rust
use anyhow::Result;

#[tokio::main]
async fn main() -> Result<()> {
    // Get the current console user
    if let Some(user) = get_console_user() {
        println!("Console user: {} (UID: {})", user.username, user.uid);
        
        // Launch an application as that user
        let args = vec!["--version".to_string()];
        let mut child = launch_as_user("/usr/bin/whoami", &args, &user).await?;
        
        // Wait for the process to complete
        let status = child.wait().await?;
        println!("Process exited with: {}", status);
    } else {
        println!("No regular user found at console");
    }
    
    Ok(())
}
```

The module automatically handles executable validation and provides robust error handling with detailed logging for process spawning operations.
