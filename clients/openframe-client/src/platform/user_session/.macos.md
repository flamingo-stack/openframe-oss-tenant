This module provides macOS-specific functionality for detecting the current console user and launching processes under their credentials, essential for GUI applications that need to run in the user's session context.

## Key Components

- **`ConsoleUser`** - Struct containing username and UID of the console user
- **`get_console_user()`** - Detects the current console user by checking `/dev/console` ownership
- **`launch_as_user()`** - Launches processes as a specific user with fallback mechanisms
- **`launch_via_launchctl()`** - Primary launch method using macOS `launchctl asuser`
- **`launch_via_sudo()`** - Fallback launch method using `sudo -u`

## Usage Example

```rust
use anyhow::Result;
use tracing::info;

#[tokio::main]
async fn main() -> Result<()> {
    // Get the current console user
    if let Some(user) = get_console_user() {
        info!("Found console user: {} (UID: {})", user.username, user.uid);
        
        // Launch a GUI application as the console user
        let args = vec!["--help".to_string()];
        let child = launch_as_user("/usr/bin/open", &args, &user).await?;
        
        // Wait for the process to complete
        let output = child.wait_with_output().await?;
        info!("Process completed with status: {}", output.status);
    } else {
        warn!("No console user detected");
    }
    
    Ok(())
}
```

The module handles the complexities of macOS user session management, automatically falling back from `launchctl asuser` to `sudo -u` if the preferred method fails, ensuring reliable process launching in GUI contexts.
