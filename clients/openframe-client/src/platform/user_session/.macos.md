This module provides macOS-specific functionality for identifying the current console user and launching processes under their account. It handles privilege escalation scenarios common in macOS system administration and automation tools.

## Key Components

- **`ConsoleUser`** - Struct containing username and UID of the console user
- **`get_console_user()`** - Identifies the current console user by checking `/dev/console` ownership
- **`launch_as_user()`** - Launches executables under a specific user account with fallback mechanisms
- **`launch_via_launchctl()`** - Primary launch method using macOS `launchctl asuser` command
- **`launch_via_sudo()`** - Fallback launch method using `sudo -u` when launchctl fails

## Usage Example

```rust
use macos::{get_console_user, launch_as_user};

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    // Get the current console user
    if let Some(user) = get_console_user() {
        println!("Console user: {} (UID: {})", user.username, user.uid);
        
        // Launch an application as that user
        let args = vec!["--help".to_string()];
        let child = launch_as_user("/usr/bin/open", &args, &user).await?;
        
        // Wait for the process to complete
        let output = child.wait_with_output().await?;
        println!("Exit status: {}", output.status);
    } else {
        println!("No console user found");
    }
    
    Ok(())
}
```

The module automatically falls back from `launchctl` to `sudo` if the preferred method fails, making it robust for different macOS environments and permission scenarios.
