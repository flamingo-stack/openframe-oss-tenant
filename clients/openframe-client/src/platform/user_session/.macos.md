macOS-specific utilities for identifying and executing processes as the console user, providing seamless user privilege escalation for GUI applications.

## Key Components

- **`ConsoleUser`** - Struct containing username and UID of the current console user
- **`get_console_user()`** - Identifies the active console user by checking `/dev/console` ownership
- **`launch_as_user()`** - Launches executables as the console user with fallback mechanisms
- **`launch_via_launchctl()`** - Primary launch method using macOS `launchctl asuser`
- **`launch_via_sudo()`** - Fallback launch method using `sudo -u`

## Usage Example

```rust
use anyhow::Result;

#[tokio::main]
async fn main() -> Result<()> {
    // Get the current console user
    if let Some(user) = get_console_user() {
        println!("Console user: {} (UID: {})", user.username, user.uid);
        
        // Launch an application as the console user
        let args = vec!["--version".to_string()];
        let child = launch_as_user("/usr/bin/open", &args, &user).await?;
        
        // Wait for completion
        let output = child.wait_with_output().await?;
        println!("Exit status: {}", output.status);
    }
    
    Ok(())
}
```

This module is essential for MSP automation tools that need to launch GUI applications or user-specific processes on macOS systems while maintaining proper user context and permissions.
