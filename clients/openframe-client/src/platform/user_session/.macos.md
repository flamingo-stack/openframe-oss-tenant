macOS-specific utilities for managing user processes and console access in privileged applications.

## Key Components

- **`ConsoleUser`** - Struct representing a console user with username and UID
- **`get_console_user()`** - Identifies the current console user by examining `/dev/console` ownership
- **`launch_as_user()`** - Launches executables as a specific user with fallback mechanisms
- **`launch_via_launchctl()`** - Primary launch method using macOS `launchctl asuser`
- **`launch_via_sudo()`** - Fallback launch method using `sudo -u`

## Usage Example

```rust
use anyhow::Result;

#[tokio::main]
async fn main() -> Result<()> {
    // Get the current console user
    let user = get_console_user()
        .ok_or_else(|| anyhow::anyhow!("No console user found"))?;
    
    println!("Console user: {} (UID: {})", user.username, user.uid);
    
    // Launch an application as the console user
    let args = vec!["--help".to_string()];
    let child = launch_as_user("/usr/bin/open", &args, &user).await?;
    
    // Wait for the process to complete
    let output = child.wait_with_output().await?;
    println!("Exit status: {}", output.status);
    
    Ok(())
}
```

This module is particularly useful for system daemons or privileged processes that need to launch GUI applications or user-space processes with proper user context on macOS.
