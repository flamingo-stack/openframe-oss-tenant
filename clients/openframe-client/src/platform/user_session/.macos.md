macOS-specific utilities for user detection and process launching with proper permissions and user context switching.

## Key Components

- **`ConsoleUser`** - Struct containing username and UID of the currently logged-in console user
- **`get_console_user()`** - Detects the active console user by examining `/dev/console` ownership
- **`launch_as_user()`** - Launches processes as a specific user with fallback mechanisms
- **`launch_via_launchctl()`** - Primary launch method using macOS `launchctl asuser` command
- **`launch_via_sudo()`** - Fallback launch method using `sudo -u` when launchctl fails

## Usage Example

```rust
use anyhow::Result;

#[tokio::main]
async fn main() -> Result<()> {
    // Get the current console user
    if let Some(user) = get_console_user() {
        println!("Console user: {} (UID: {})", user.username, user.uid);
        
        // Launch an application as that user
        let args = vec!["--version".to_string()];
        let child = launch_as_user("/usr/bin/whoami", &args, &user).await?;
        
        // Wait for process completion
        let output = child.wait_with_output().await?;
        println!("Output: {}", String::from_utf8_lossy(&output.stdout));
    }
    
    Ok(())
}
```

This module provides essential functionality for MSP tools that need to run processes in the proper user context on macOS, with intelligent fallback between `launchctl` and `sudo` based on system capabilities.
