Provides macOS-specific utilities for managing console users and launching processes as different users. This module handles user detection and process execution with appropriate privileges for macOS systems.

## Key Components

- **`ConsoleUser`** - Struct containing username and UID of the current console user
- **`get_console_user()`** - Detects the active console user by examining `/dev/console` ownership
- **`launch_as_user()`** - Launches executables as a specific user with fallback mechanisms
- **`launch_via_launchctl()`** - Primary method using macOS `launchctl asuser` command
- **`launch_via_sudo()`** - Fallback method using `sudo -u` for process execution

## Usage Example

```rust
use anyhow::Result;

#[tokio::main]
async fn main() -> Result<()> {
    // Get the current console user
    if let Some(user) = get_console_user() {
        println!("Console user: {} (UID: {})", user.username, user.uid);
        
        // Launch an application as the console user
        let args = vec!["--version".to_string()];
        let child = launch_as_user("/usr/bin/whoami", &args, &user).await?;
        
        // Process will run with user privileges
        let output = child.wait_with_output().await?;
        println!("Output: {}", String::from_utf8_lossy(&output.stdout));
    }
    
    Ok(())
}
```

The module automatically tries `launchctl asuser` first (preferred on macOS) and falls back to `sudo -u` if that fails, ensuring reliable process launching across different macOS configurations.
