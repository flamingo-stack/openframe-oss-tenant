This module provides macOS-specific functionality for user management and process launching, enabling applications to identify console users and execute processes with their privileges.

## Key Components

### Types
- **`ConsoleUser`** - Struct containing username and UID of the current console user

### Functions
- **`get_console_user()`** - Identifies the current console user by checking `/dev/console` ownership
- **`launch_as_user()`** - Launches processes as a specific user with fallback mechanisms
- **`launch_via_launchctl()`** - Uses macOS `launchctl asuser` for process launching
- **`launch_via_sudo()`** - Fallback method using `sudo -u` for process launching

## Usage Example

```rust
use anyhow::Result;

#[tokio::main]
async fn main() -> Result<()> {
    // Get the current console user
    if let Some(user) = get_console_user() {
        println!("Console user: {} (UID: {})", user.username, user.uid);
        
        // Launch an application as that user
        let args = vec!["--version".to_string()];
        let mut child = launch_as_user("/usr/bin/whoami", &args, &user).await?;
        
        // Wait for completion
        let status = child.wait().await?;
        println!("Process exited with: {:?}", status);
    } else {
        println!("No console user found");
    }
    
    Ok(())
}
```

The module prioritizes `launchctl asuser` (the preferred macOS method) and falls back to `sudo -u` if needed, providing robust cross-privilege process execution capabilities.
