Provides macOS-specific functionality for launching processes as the console user, with fallback mechanisms for privilege escalation. Essential for running GUI applications from system daemons with proper user context.

## Key Components

### Structs
- **`ConsoleUser`** - Contains username and UID of the current console user

### Functions
- **`get_console_user()`** - Detects the currently logged-in user by checking `/dev/console` ownership
- **`launch_as_user()`** - Launches executables as a specific user with automatic fallback strategy
- **`launch_via_launchctl()`** - Uses macOS `launchctl asuser` for launching (preferred method)
- **`launch_via_sudo()`** - Fallback method using `sudo -u` when launchctl fails

## Usage Example

```rust
use anyhow::Result;

#[tokio::main]
async fn main() -> Result<()> {
    // Get the current console user
    let user = get_console_user()
        .ok_or_else(|| anyhow::anyhow!("No console user found"))?;
    
    println!("Console user: {} (UID: {})", user.username, user.uid);
    
    // Launch an application as the console user
    let args = vec!["/Applications/Calculator.app".to_string()];
    let child = launch_as_user("/usr/bin/open", &args, &user).await?;
    
    println!("Launched process with PID: {:?}", child.id());
    Ok(())
}
```

The module automatically tries `launchctl asuser` first (which preserves the GUI session context better), then falls back to `sudo -u` if needed. This ensures compatibility across different macOS configurations and security settings.
