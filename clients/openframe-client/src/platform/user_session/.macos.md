MacOS-specific utility functions for identifying console users and launching processes with user privileges. Provides console user detection and process spawning capabilities using macOS system commands.

## Key Components

- **`ConsoleUser`** - Struct containing username and UID of the current console user
- **`get_console_user()`** - Detects the active console user by examining `/dev/console` ownership
- **`launch_as_user()`** - Spawns processes as a specific user with fallback mechanisms
- **`launch_via_launchctl()`** - Primary method using macOS `launchctl asuser` command
- **`launch_via_sudo()`** - Fallback method using `sudo -u` when launchctl fails

## Usage Example

```rust
use anyhow::Result;

#[tokio::main]
async fn main() -> Result<()> {
    // Get the current console user
    if let Some(user) = get_console_user() {
        println!("Console user: {} (UID: {})", user.username, user.uid);
        
        // Launch an application as the console user
        let args = vec!["--version".to_string()];
        let child = launch_as_user("/usr/bin/whoami", &args, &user).await?;
        
        // Wait for the process to complete
        let output = child.wait_with_output().await?;
        println!("Output: {}", String::from_utf8_lossy(&output.stdout));
    } else {
        println!("No console user detected");
    }
    
    Ok(())
}
```

The module automatically handles privilege escalation using the most appropriate method for the macOS environment, falling back from `launchctl` to `sudo` if necessary.
