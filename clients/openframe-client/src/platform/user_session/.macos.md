Provides macOS-specific utilities for identifying the current console user and launching processes under their context, essential for GUI applications that need to run with proper user permissions.

## Key Components

- **`ConsoleUser`** - Struct containing username and UID of the console user
- **`get_console_user()`** - Identifies the current logged-in user by checking `/dev/console` ownership
- **`launch_as_user()`** - Launches executables as a specific user with fallback strategies
- **`launch_via_launchctl()`** - Primary launch method using macOS `launchctl asuser`
- **`launch_via_sudo()`** - Fallback launch method using `sudo -u`

## Usage Example

```rust
use anyhow::Result;

#[tokio::main]
async fn main() -> Result<()> {
    // Get the current console user
    let user = get_console_user()
        .ok_or_else(|| anyhow::anyhow!("No console user found"))?;
    
    println!("Console user: {} (UID: {})", user.username, user.uid);
    
    // Launch a GUI application as the console user
    let args = vec!["--version".to_string()];
    let mut child = launch_as_user("/Applications/TextEdit.app/Contents/MacOS/TextEdit", &args, &user).await?;
    
    // Wait for the process to complete
    let status = child.wait().await?;
    println!("Process exited with status: {}", status);
    
    Ok(())
}
```

This module handles the complexity of launching GUI applications on macOS with proper user context, automatically falling back from `launchctl` to `sudo` if needed. It's particularly useful for system services that need to spawn user-facing applications.
