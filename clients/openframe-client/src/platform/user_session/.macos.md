Provides macOS-specific utilities for identifying the active console user and launching processes under their account, with fallback mechanisms for different privilege escalation methods.

## Key Components

- **`ConsoleUser`** - Struct containing username and UID of the current console user
- **`get_console_user()`** - Detects the active console user by examining `/dev/console` ownership
- **`launch_as_user()`** - Launches executables as the console user with automatic fallback between methods
- **`launch_via_launchctl()`** - Primary launch method using macOS `launchctl asuser` command
- **`launch_via_sudo()`** - Fallback launch method using `sudo -u` when launchctl fails

## Usage Example

```rust
use anyhow::Result;

#[tokio::main]
async fn main() -> Result<()> {
    // Get the current console user
    if let Some(user) = get_console_user() {
        println!("Console user: {} (UID: {})", user.username, user.uid);
        
        // Launch an application as the console user
        let args = vec!["--version".to_string()];
        let mut child = launch_as_user("/usr/bin/whoami", &args, &user).await?;
        
        // Wait for the process to complete
        let status = child.wait().await?;
        println!("Process exited with: {:?}", status);
    } else {
        println!("No console user found");
    }
    
    Ok(())
}
```

The module automatically tries `launchctl asuser` first (preferred macOS method) and falls back to `sudo -u` if needed, providing robust cross-privilege execution capabilities.
