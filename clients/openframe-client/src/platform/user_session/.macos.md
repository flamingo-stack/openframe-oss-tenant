macOS-specific utilities for managing processes and user sessions, including console user detection and launching applications with proper user privileges.

## Key Components

- **`ConsoleUser`** - Struct containing username and UID of the current console user
- **`get_console_user()`** - Detects the active console user by checking `/dev/console` ownership and retrieving their UID
- **`launch_as_user()`** - Launches an executable as a specific user with fallback strategy (launchctl → sudo)
- **`launch_via_launchctl()`** - Uses macOS `launchctl asuser` for launching processes in user context
- **`launch_via_sudo()`** - Fallback method using `sudo -u` for process launching

## Usage Example

```rust
use crate::macos::{get_console_user, launch_as_user};

// Get the current console user
if let Some(user) = get_console_user() {
    println!("Console user: {} (UID: {})", user.username, user.uid);
    
    // Launch an application as that user
    let args = vec!["--version".to_string()];
    match launch_as_user("/usr/bin/whoami", &args, &user).await {
        Ok(mut child) => {
            let output = child.wait_with_output().await?;
            println!("Output: {}", String::from_utf8_lossy(&output.stdout));
        }
        Err(e) => eprintln!("Failed to launch: {}", e),
    }
}
```

The module prioritizes `launchctl asuser` for proper macOS session handling, falling back to `sudo` if needed. It includes validation to ensure executables exist and filters out root users from console detection.
