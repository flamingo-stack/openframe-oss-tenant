Cross-platform uninstall logic for the OpenFrame client service, handling service teardown, directory removal with retry/force fallback, and integrated tool cleanup across macOS, Windows, and Linux.

## Key Components

- **`spawn_detached_uninstall(install_path)`** — Spawns a detached `openframe-client uninstall` process that survives the parent service being stopped by the OS service manager. macOS uses `setsid()` for session isolation; Windows uses `DETACHED_PROCESS` creation flags. Linux is unsupported and returns an error.
- **`remove_directory_with_retry(path, max_retries)`** — Async directory removal with exponential backoff (capped at 8s), a pre-final-attempt file unlock pass, and a system-command force-removal fallback (`rd /S /Q` on Windows, `rm -rf` on Unix).
- **`unlock_directory_files(path)`** — Clears locked/read-only file attributes before removal (`attrib -R -S -H` on Windows, `chmod -R 777` on Unix).
- **`force_remove_directory(path)`** — Last-resort system-command removal with post-command existence verification and a timing-delay recheck.
- **`uninstall_integrated_tools(dir_manager)`** — Wires up the `InstalledToolsService`, `ToolCommandParamsResolver`, `ToolKillService`, and `ToolUninstallService`, then calls `uninstall_all()` to remove all registered tools.
- **`orbit_dir()`** — Returns the platform-specific Orbit installation path (`/opt/orbit` on macOS/Linux, `%ProgramFiles%\Orbit` on Windows).

## Usage Example

```rust
use std::path::Path;

// Spawn a detached self-uninstall process from within the running service
let binary_path = Path::new("/usr/local/bin/openframe-client");
spawn_detached_uninstall(binary_path)?;

// Remove a directory with up to 5 retry attempts
let target = Path::new("/opt/orbit/data");
remove_directory_with_retry(target, 5).await?;

// Uninstall all registered integrated tools
uninstall_integrated_tools(&dir_manager).await?;
```
