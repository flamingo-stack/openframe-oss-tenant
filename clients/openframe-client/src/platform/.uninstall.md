Handles the complete uninstallation lifecycle for the OpenFrame client service, including service removal, integrated tool teardown, and cross-platform directory cleanup with retry logic.

## Key Components

- **`orbit_dir()`** — Returns the Windows `Program Files\Orbit` installation path
- **`remove_directory_with_retry(path, max_retries)`** — Async directory removal with exponential backoff (max 8s), file unlocking, and forced OS-level deletion as a last resort
- **`unlock_directory_files(path)`** — Platform-specific attribute clearing (`attrib` on Windows, `chmod 777` on Unix) to release locked files
- **`force_remove_directory(path)`** — Last-resort removal using `rd /S /Q` (Windows) or `rm -rf` (Unix) with post-removal verification
- **`uninstall_integrated_tools(dir_manager)`** — Orchestrates graceful teardown of all managed tools via `ToolUninstallService`
- **`uninstall_windows(dir_manager, install_path)`** — Full Windows uninstall sequence: stop service → uninstall tools → clean directories → launch binary self-cleanup script

## Usage Example

```rust
use crate::uninstall::{uninstall_windows, remove_directory_with_retry};
use std::path::Path;

// Full Windows uninstall flow
let dir_manager = DirectoryManager::new()?;
let install_path = std::env::current_exe()?;
uninstall_windows(&dir_manager, &install_path).await?;

// Standalone directory removal with 5 retries
let target = Path::new("C:\\Program Files\\Orbit\\data");
remove_directory_with_retry(target, 5).await?;
```

## Notes

- All steps are non-fatal by design — failures emit `warn!` and continue cleanup
- Retry backoff: attempts 1→8s ceiling (`2^(attempt-1)`, capped at 8s)
- Binary self-deletion is deferred via a cleanup script launched after process exit (Windows only)
