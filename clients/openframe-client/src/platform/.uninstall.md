Handles the complete uninstallation lifecycle for the OpenFrame client agent, including service removal, integrated tool cleanup, and cross-platform directory deletion with retry/force-removal logic.

## Key Components

- **`orbit_dir()`** — Returns the Windows `%ProgramFiles%\Orbit` path used as a cleanup target.
- **`remove_directory_with_retry(path, max_retries)`** — Async directory removal with exponential backoff (max 8s), pre-removal file unlocking, and a final force-delete fallback.
- **`unlock_directory_files(path)`** — Platform-specific file unlocking: `attrib -R -S -H /S /D` on Windows, `chmod -R 777` on Unix.
- **`force_remove_directory(path)`** — Last-resort deletion using `cmd /C rd /S /Q` (Windows) or `rm -rf` (Unix), with post-command existence verification.
- **`uninstall_integrated_tools(dir_manager)`** — Composes `InstalledToolsService`, `ToolCommandParamsResolver`, `ToolKillService`, and `ToolUninstallService` to gracefully remove all managed tools.
- **`uninstall_windows(dir_manager, install_path)`** — Orchestrates the full Windows uninstall sequence: stop/remove service → uninstall tools → clean directories → launch deferred binary cleanup script.

## Usage Example

```rust
use crate::uninstall::{uninstall_windows, remove_directory_with_retry};
use std::path::Path;

// Full uninstall on Windows
let install_path = Path::new("C:\\Program Files\\OpenFrame\\openframe.exe");
uninstall_windows(&dir_manager, install_path).await?;

// Standalone retry-based directory removal
let path = Path::new("C:\\ProgramData\\OpenFrame\\cache");
remove_directory_with_retry(path, 5).await?;
```

> **Note:** Non-fatal errors (service not installed, tool cleanup partial failures) emit `warn!` logs and allow the uninstall sequence to continue rather than aborting.
