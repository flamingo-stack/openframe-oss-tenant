Handles stopping and killing tool processes across Windows, macOS, and Linux, supporting graceful termination with fallback to force kill, retries, and process verification.

## Key Components

- **`ToolKillService`** — Stateless, cloneable service struct that orchestrates all process termination logic
- **`stop_tool(tool_id)`** — Stops processes matching a tool's agent command pattern
- **`stop_asset(asset_id, tool_id)`** — Stops processes matching a specific asset/tool path pattern
- **`stop_installed_tool(tool)`** — Dispatches stop logic based on `Installation` variant (`GuiApp`, `Standard`, `Service`)
- **`stop_service(service_name)`** — Delegates to platform-specific service managers (`sc stop` on Windows, `launchctl`/`systemctl` on macOS/Linux)
- **`stop_processes_by_pattern()`** — Core process scanner using `sysinfo`; matches against both cmdline and executable path
- **`stop_process_with_retry()`** — Orchestrates graceful → force kill with up to `MAX_KILL_RETRIES` (3) attempts
- **`wait_for_process_exit()`** — Polls process table at 500ms intervals until exit or timeout

**Termination constants:**

| Constant | Value |
|---|---|
| `GRACEFUL_SHUTDOWN_TIMEOUT_SECS` | 5s |
| `FORCE_KILL_TIMEOUT_SECS` | 3s |
| `MAX_KILL_RETRIES` | 3 |
| `PROCESS_CHECK_INTERVAL_MS` | 500ms |

## Usage Example

```rust
let killer = ToolKillService::new();

// Stop all processes for a tool agent
killer.stop_tool("zabbix").await?;

// Stop processes for a specific monitored asset
killer.stop_asset("asset-123", "zabbix").await?;

// Stop using installation metadata
killer.stop_installed_tool(&installed_tool).await?;

// Stop a system service directly
killer.stop_service("ZabbixAgent2").await?;
```
