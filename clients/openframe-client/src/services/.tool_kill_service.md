Manages process termination for installed tools and services, providing graceful shutdown with force-kill fallback across Windows, macOS, and Linux.

## Key Components

- **`ToolKillService`** — Stateless service struct handling all process termination logic
- **`stop_tool(tool_id)`** — Stops processes matching a tool's agent command pattern
- **`stop_asset(asset_id, tool_id)`** — Stops processes matching a specific asset's command pattern
- **`stop_installed_tool(tool)`** — Dispatches stop logic based on `Installation` variant (`GuiApp`, `Standard`, `Service`)
- **`stop_service(service_name)`** — Platform-aware system service stopper (`sc stop` on Windows, launchctl/systemctl on macOS/Linux)
- **`stop_process_with_retry(pid)`** — Orchestrates graceful → force-kill with up to 3 retries
- **`wait_for_process_exit(pid, timeout_secs)`** — Polls process table every 500ms until exit or timeout

### Termination Constants

| Constant | Value |
|---|---|
| `GRACEFUL_SHUTDOWN_TIMEOUT_SECS` | 5s |
| `FORCE_KILL_TIMEOUT_SECS` | 3s |
| `MAX_KILL_RETRIES` | 3 |
| `PROCESS_CHECK_INTERVAL_MS` | 500ms |

## Usage Example

```rust
let kill_service = ToolKillService::new();

// Stop all processes for a tool
kill_service.stop_tool("prometheus").await?;

// Stop a specific asset's process
kill_service.stop_asset("client-123", "prometheus").await?;

// Stop by installation type (GuiApp, Standard, or Service)
kill_service.stop_installed_tool(&installed_tool).await?;

// Stop a system service directly
kill_service.stop_service("my-daemon").await?;
```

Process discovery matches against both the full command line and executable path, ensuring child or renamed processes are also caught.
