Manages the "last known good" (LKG) rollback mechanism for the OpenFrame agent updater, tracking a verified working binary version and its reserve copy to enable safe self-updates.

## Key Components

### `LastKnownGoodService`

The primary service struct managing rollback state across several file system artifacts:

| Field | Purpose |
|---|---|
| `anchor_file_path` | JSON file recording the last promoted version (`last_known_good.json`) |
| `boot_marker_path` | File written at boot to detect incomplete update cycles (`boot.marker`) |
| `reserve_path` | A `.lkg` copy of the last known good binary |
| `current_exe` | Path to the currently running executable |
| `logs_dir` | Directory for per-update transcript logs |

### Key Methods

| Method | Description |
|---|---|
| `new(directory_manager)` | Constructs the service, resolves all paths, ensures directories exist |
| `load()` | Reads and deserializes the anchor file, returning the stored version string |
| `promote(version)` | Atomically copies the running binary to reserve and updates the anchor JSON |
| `seed_if_missing()` | Bootstraps or repairs LKG state on startup; handles version mismatch degradation |
| `write_boot_marker()` | Atomically writes the current version as a boot marker |
| `new_transcript_path(version)` | Generates a timestamped log path for an update run |
| `prune_transcripts(keep)` | Removes old updater logs, retaining only the `keep` most recent |

All file writes use a write-then-rename pattern for atomicity.

## Usage Example

```rust
use crate::platform::directories::DirectoryManager;
use crate::updater::last_known_good_service::LastKnownGoodService;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let dir_manager = DirectoryManager::new()?;
    let lkg = LastKnownGoodService::new(dir_manager)?;

    // On startup: seed if no LKG exists yet
    lkg.seed_if_missing().await?;

    // Write a boot marker so crash recovery can detect incomplete updates
    lkg.write_boot_marker().await?;

    // After a successful update, promote the new version
    lkg.promote("1.4.2").await?;

    // Clean up old transcript logs, keeping the 5 most recent
    lkg.prune_transcripts(5).await;

    Ok(())
}
```
