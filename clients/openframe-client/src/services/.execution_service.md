Thin service layer that accepts an `ExecutionRequest`, delegates to the platform executor, measures wall-clock time, and maps the raw executor result into an `RmmResult`.

## Key Components

| Item | Description |
|------|-------------|
| `ExecutionService` | Stateless, cloneable service struct — acts as the public entry point for script execution |
| `execute(&self, req, machine_id)` | Async method that runs the script, enforces a default 900 s timeout when `timeout_secs == 0`, maps `PrivilegeLevel` to internal `Privilege`, and captures elapsed time |
| Exit-code 85 mapping | Treats return code `85` (spawn/unsupported-shell failure) as a hard error and copies `stderr` into the `RmmResult::error` field |
| Unsupported-platform fallback | On non-Unix/non-Windows targets the method compiles to a no-op that returns exit code `85` with a descriptive error message |

## Usage Example

```rust
use execution_service::ExecutionService;
use crate::models::{ExecutionRequest, PrivilegeLevel, ScriptShell};

let service = ExecutionService::new();

let req = ExecutionRequest {
    execution_id: "exec-42",
    code: "#!/bin/sh\necho hello\n",
    shell: ScriptShell::Bash,
    privilege: PrivilegeLevel::Admin,
    args: &[],
    timeout_secs: 60,   // 0 → defaults to 900 s
    env_vars: vec![],
    script_id: Some("script-7"),
    schedule_id: None,
};

let result = service.execute(&req, "machine-abc").await;

assert_eq!(result.exit_code, 0);
println!("stdout: {}", result.stdout);
println!("elapsed: {} ms", result.execution_time_ms);
```

## Platform Behaviour

| Platform | Behaviour |
|----------|-----------|
| Unix / Windows | Delegates to `execute_script` from `crate::executor` |
| Other | Returns `exit_code: 85`, `timed_out: false`, and `error: Some("unsupported platform")` |

## Notes

- `timeout_secs` is clamped to `u32::MAX` before being passed to the executor; a value of `0` is silently promoted to `900`.
- The struct derives `Default`, so `ExecutionService::default()` and `ExecutionService::new()` are equivalent.
