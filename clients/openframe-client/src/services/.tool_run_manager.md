This Rust file provides a comprehensive tool runtime manager for executing applications in Windows user sessions, with special handling for service environments.

## Key Components

**Core Structure:**
- `ToolRunManager` - Main service for launching and managing tool processes
- `get_active_user_session()` - Windows-specific function to detect active user sessions
- `launch_process_in_user_session()` - Launches processes with proper user context
- `launch_process_in_console_session()` - Alternative launch method for console sessions

**Key Services Integration:**
- `InstalledToolsService` - Manages available tools
- `ToolCommandParamsResolver` - Resolves command parameters
- `ToolKillService` - Handles process termination

**Windows API Functions:**
- Session enumeration via Windows Terminal Services
- User token management and duplication
- Process creation with user privileges

## Usage Example

```rust
use crate::services::tool_run_manager::ToolRunManager;

// Initialize the tool run manager
let tool_manager = ToolRunManager::new(
    installed_tools_service,
    command_resolver,
    kill_service
);

// Launch a tool in user session
let result = tool_manager.launch_tool_in_user_session(
    "notepad.exe",
    &["document.txt".to_string()]
).await?;

// The manager handles:
// - Finding active user sessions
// - Obtaining proper user tokens
// - Launching with correct desktop context
// - Process isolation and management
```

The manager is particularly valuable for Windows services that need to launch GUI applications in user desktop sessions, handling the complex Windows security model and session management automatically.
