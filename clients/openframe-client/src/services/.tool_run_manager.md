This file manages the execution of tools within the OpenFrame platform, providing cross-platform process management with specialized Windows session handling for GUI applications.

## Key Components

- **`ToolRunManager`** - Main service for managing tool process lifecycle
- **Windows Session Management** - Functions for detecting and launching processes in active user sessions:
  - `get_active_user_session()` - Detects active Windows Terminal Services sessions
  - `launch_process_in_user_session()` - Launches GUI tools in user context
  - `launch_process_in_console_session()` - Launches console applications
- **Process Monitoring** - Async process execution with output capture and retry logic
- **Service Dependencies**:
  - `InstalledToolsService` - Tool discovery and validation
  - `ToolCommandParamsResolver` - Command line argument resolution
  - `ToolKillService` - Process termination handling

## Usage Example

```rust
use crate::services::tool_run_manager::ToolRunManager;

// Initialize the tool run manager
let run_manager = ToolRunManager::new(
    installed_tools_service,
    params_resolver,
    kill_service,
);

// Execute a tool (cross-platform)
let result = run_manager.run_tool(
    "my-tool",
    &["--config", "production"],
    false, // not detached
).await?;

// On Windows, automatically handles:
// - Session detection (service vs user context)
// - Token duplication for user processes
// - GUI application desktop assignment
```

The manager automatically detects Windows service context and launches tools in the appropriate user session with proper desktop access, while providing standard process execution on other platforms.
