Manages the execution of tools in different user contexts, particularly on Windows systems, with support for running processes in active user sessions and console environments.

## Key Components

### Core Functions
- **`get_active_user_session()`** - Detects and returns the active Windows user session ID by enumerating terminal services sessions
- **`launch_process_in_console_session()`** - Launches processes in the physical console session using WTS APIs  
- **`launch_process_in_user_session()`** - Launches processes in active user sessions with proper token duplication
- **Helper functions** - `to_wide()` for UTF-16 conversion, `wcslen()` for string length calculation

### Windows-Specific Features
- Terminal Services session enumeration and selection
- User token querying and duplication for cross-session process creation
- Process creation with proper desktop assignment (`winsta0\default`)
- Session filtering logic to prefer RDP sessions over console sessions

### Dependencies
- Uses Windows APIs extensively (`WTSEnumerateSessionsW`, `CreateProcessAsUserW`, etc.)
- Integrates with `InstalledToolsService`, `ToolCommandParamsResolver`, and `ToolKillService`
- Built on tokio async runtime with tracing for comprehensive logging

## Usage Example

```rust
// Get the active user session (Windows only)
#[cfg(windows)]
if let Some(session_id) = get_active_user_session() {
    println!("Active session found: {}", session_id);
}

// Launch a process in user session
#[cfg(windows)]  
let command_path = r"C:\Program Files\MyApp\app.exe";
let args = vec!["--verbose".to_string(), "--config=default".to_string()];

match launch_process_in_user_session(command_path, &args) {
    Ok((pid, handle)) => {
        println!("Process launched with PID: {}", pid);
        // Process handle can be used for monitoring
    }
    Err(e) => {
        eprintln!("Failed to launch process: {}", e);
    }
}
```

The service provides robust session detection with fallback strategies, comprehensive logging for debugging session issues, and proper Windows security token handling for cross-session process execution.
