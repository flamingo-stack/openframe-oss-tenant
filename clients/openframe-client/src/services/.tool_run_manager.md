Manages the execution and lifecycle of tools in different system contexts, particularly handling Windows user session management and process launching.

## Key Components

- **`ToolRunManager`** - Main struct for managing tool execution with retry logic and process tracking
- **Session Management Functions** (Windows):
  - `get_active_user_session()` - Detects and returns the active user session ID
  - `launch_process_in_user_session()` - Launches processes in the active user's session
  - `launch_process_in_console_session()` - Launches processes in the console session
- **Process Management** - Handles tool process spawning, monitoring, and cleanup
- **Retry Logic** - Implements automatic retry mechanisms with configurable delays

## Usage Example

```rust
use tool_run_manager::ToolRunManager;
use crate::models::installed_tool::InstalledTool;

// Create a tool run manager
let manager = ToolRunManager::new(
    installed_tools_service,
    tool_kill_service,
    params_resolver
);

// Run a tool with automatic session management
let tool = InstalledTool {
    name: "my-tool".to_string(),
    path: "/path/to/tool".to_string(),
    // ... other fields
};

// The manager will automatically:
// 1. Detect the appropriate user session
// 2. Launch the tool in that session
// 3. Handle retries on failure
// 4. Track the running process
manager.run_tool(&tool, &["arg1", "arg2"]).await?;
```

The module provides robust cross-platform tool execution with special handling for Windows user session management, making it suitable for service-based applications that need to launch GUI tools in user contexts.
