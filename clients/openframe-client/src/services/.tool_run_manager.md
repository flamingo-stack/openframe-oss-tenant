This file manages the execution of tools in user sessions across different operating systems, with specialized Windows session handling for proper GUI application launches.

## Key Components

**Main Functions:**
- `get_active_user_session()` - Detects active Windows user sessions for proper process spawning
- `launch_process_in_console_session()` - Launches processes in the physical console session  
- `launch_process_in_user_session()` - Launches processes in active user sessions with full GUI support
- `launch_process_in_console_session()` - Fallback method for console-based process launching

**Key Features:**
- Cross-platform process execution (Windows-specific optimizations)
- Session enumeration and selection logic
- Token duplication for secure process creation
- Command-line argument handling with proper quoting
- Comprehensive logging for debugging session issues

**Dependencies:**
- Windows API integration for session management
- Tokio async process handling
- Tool services integration (InstalledToolsService, ToolKillService)

## Usage Example

```rust
use crate::tool_run_manager::*;

// Launch a tool in the active user session (Windows)
#[cfg(windows)]
async fn launch_gui_tool() -> Result<()> {
    let command_path = "C:\\Program Files\\MyTool\\tool.exe";
    let args = vec!["--config".to_string(), "config.json".to_string()];
    
    match launch_process_in_user_session(command_path, &args) {
        Ok((pid, handle)) => {
            info!("Successfully launched tool with PID: {}", pid);
            // Process handle can be used for monitoring
            Ok(())
        }
        Err(e) => {
            error!("Failed to launch tool: {}", e);
            Err(e)
        }
    }
}

// Session detection
#[cfg(windows)]
fn check_active_session() {
    if let Some(session_id) = get_active_user_session() {
        println!("Active user session found: {}", session_id);
    } else {
        println!("No active user session available");
    }
}
```

The tool run manager handles complex Windows session management, ensuring GUI applications launch properly in the user's desktop environment rather than the service session.
