Manages the execution of external tools and applications within user sessions, with cross-platform support for Windows and Unix-like systems. Handles process launching, session management, and Windows-specific user session detection for running tools in the active user context.

## Key Components

### Core Structure
- **ToolRunManager** - Main service for managing tool execution
- **Session Detection** - Windows-specific functions for finding active user sessions
- **Process Launching** - Cross-platform process creation with user session support

### Key Functions
- `get_active_user_session()` - Detects active Windows user sessions (RDP/Console)
- `launch_process_in_user_session()` - Launches processes in Windows user context
- `launch_process_in_console_session()` - Launches in physical console session
- Process management with retry logic and proper cleanup

### Dependencies
- `InstalledToolsService` - Tool metadata and configuration
- `ToolCommandParamsResolver` - Command parameter resolution
- `ToolKillService` - Process termination management

## Usage Example

```rust
use crate::services::tool_run_manager::ToolRunManager;
use crate::models::installed_tool::InstalledTool;

// Initialize the tool run manager
let tool_manager = ToolRunManager::new(
    installed_tools_service,
    params_resolver,
    kill_service
);

// Execute a tool in user session (Windows)
#[cfg(windows)]
let (pid, handle) = launch_process_in_user_session(
    "C:\\Program Files\\MyTool\\tool.exe",
    &vec!["--config".to_string(), "config.json".to_string()]
)?;

// The manager handles session detection, token duplication,
// and proper process creation in the active user context
```

## Platform-Specific Features

- **Windows**: Advanced session management with RDP/Console detection, user token handling, and proper desktop assignment
- **Cross-platform**: Unified interface with tokio process management and async I/O handling
