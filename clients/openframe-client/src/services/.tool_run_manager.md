Manages the execution and lifecycle of tool processes within Windows user sessions, handling process launching, session detection, and command execution.

## Key Components

- **`get_active_user_session()`** - Detects and returns the active Windows Terminal Services session ID
- **`launch_process_in_console_session()`** - Launches processes in the physical console session
- **`launch_process_in_user_session()`** - Launches processes in the active user session with proper token handling
- **`ToolRunManager`** - Main service for managing tool execution and process lifecycle
- **Session Management** - Windows-specific code for handling user sessions and process tokens
- **Command Execution** - Handles building command lines with proper argument quoting

## Usage Example

```rust
use tool_run_manager::ToolRunManager;
use crate::models::installed_tool::InstalledTool;

// Initialize the tool run manager
let manager = ToolRunManager::new(
    installed_tools_service,
    params_resolver,
    kill_service
);

// Launch a tool in the active user session
let tool = InstalledTool {
    name: "notepad".to_string(),
    command_path: "C:\\Windows\\System32\\notepad.exe".to_string(),
    // ... other fields
};

let args = vec!["document.txt".to_string()];
let (pid, handle) = manager.launch_tool_in_user_session(&tool, &args)?;

println!("Tool launched with PID: {}", pid);
```

**Platform Support**: Includes Windows-specific session management using Windows API for user token handling and process creation in user sessions. Uses tokio for async process management and includes retry mechanisms for robust tool execution.
