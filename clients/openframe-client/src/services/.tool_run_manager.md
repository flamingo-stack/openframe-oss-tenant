Manages the execution of installed tools as separate processes with cross-platform support and Windows-specific session handling for proper user context execution.

## Key Components

- **`get_active_user_session()`** - Windows-specific function to detect active user sessions for proper GUI application launching
- **`launch_process_in_console_session()`** - Launches processes in the physical console session on Windows
- **`launch_process_in_user_session()`** - Launches processes in the active user session with proper token handling
- **Session enumeration** - Enumerates Windows Terminal Services sessions to find active users
- **Process management** - Handles process creation with appropriate flags and security contexts

## Key Features

- **Cross-platform support** - Conditional compilation for Windows-specific functionality
- **User session detection** - Automatically finds active user sessions for GUI applications
- **Token management** - Proper Windows security token handling for user impersonation
- **Command line building** - Automatic quoting and argument handling for process execution
- **Process isolation** - Uses appropriate creation flags for proper process separation

## Usage Example

```rust
use anyhow::Result;

// Windows-specific session management
#[cfg(windows)]
fn launch_tool_in_user_context(tool_path: &str, args: &[String]) -> Result<(u32, HANDLE)> {
    // Detect active user session
    if let Some(session_id) = get_active_user_session() {
        println!("Found active session: {}", session_id);
        
        // Launch process in user session with proper token
        launch_process_in_user_session(tool_path, args)
    } else {
        // Fallback to console session
        launch_process_in_console_session(tool_path, args)
    }
}

// Cross-platform process execution
async fn run_installed_tool(tool: &InstalledTool, params: Vec<String>) -> Result<()> {
    let command_path = &tool.executable_path;
    
    #[cfg(windows)]
    {
        // Use Windows-specific session-aware launching
        let (_pid, _handle) = launch_process_in_user_session(command_path, &params)?;
    }
    
    #[cfg(not(windows))]
    {
        // Use standard tokio process for other platforms
        let mut cmd = Command::new(command_path);
        cmd.args(&params);
        let _child = cmd.spawn()?;
    }
    
    Ok(())
}
```

The tool run manager provides sophisticated Windows session management for running GUI applications in the proper user context, with fallback support for console applications and cross-platform compatibility.
