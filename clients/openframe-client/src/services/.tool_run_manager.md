This file manages the execution of tools in different user sessions, particularly handling Windows user session switching for GUI applications.

## Key Components

- **Session Management Functions**: `get_active_user_session()`, `launch_process_in_console_session()`, `launch_process_in_user_session()` - Handle Windows user session detection and process launching
- **Wide String Utilities**: `to_wide()`, `wcslen()` - Convert strings to Windows-compatible wide character format
- **Process Launching**: Functions to create processes in specific user sessions using Windows APIs
- **Service Integrations**: Uses `InstalledToolsService`, `ToolCommandParamsResolver`, and `ToolKillService`

## Usage Example

```rust
// Launch a tool in the active user session (Windows)
#[cfg(windows)]
let (pid, handle) = launch_process_in_user_session(
    "C:\\Program Files\\MyTool\\tool.exe",
    &["--config", "config.json", "--verbose"]
)?;

info!("Tool launched with PID: {}", pid);

// The system automatically:
// 1. Detects the active user session
// 2. Gets the user token for that session
// 3. Creates the process in the user's desktop environment
```

The manager handles the complexity of Windows session management, ensuring tools launch in the correct user context rather than the service session. It includes comprehensive logging and error handling for session detection, token management, and process creation. The system supports both console and RDP sessions, with intelligent session selection based on activity and type.
