Manages the execution and lifecycle of tools in both console and user sessions across Windows and Unix platforms.

## Key Components

- **get_active_user_session()** - Detects active Windows user sessions for service-to-user process launching
- **launch_process_in_console_session()** - Launches processes in Windows console sessions with proper token handling
- **launch_process_in_user_session()** - Launches processes in active user sessions with GUI desktop access
- **ToolRunManager** - Core service for executing tools with retry logic and process monitoring
- **Windows-specific token handling** - Manages user tokens and session duplication for cross-session process creation

## Usage Example

```rust
use crate::tool_run_manager::ToolRunManager;

// Create manager with dependencies
let manager = ToolRunManager::new(
    Arc::new(installed_tools_service),
    Arc::new(params_resolver),
    Arc::new(kill_service),
    Arc::new(RwLock::new(HashSet::new()))
);

// Launch a tool in user session
let tool = InstalledTool {
    name: "notepad".to_string(),
    executable_path: "C:\\Windows\\System32\\notepad.exe".to_string(),
    // ... other fields
};

let result = manager.run_tool(tool, vec!["document.txt".to_string()]).await?;
```

The manager handles platform-specific process launching, particularly complex Windows session management for services that need to launch GUI applications in user contexts. It includes comprehensive session enumeration, token duplication, and proper desktop assignment for Windows Terminal Services environments.
