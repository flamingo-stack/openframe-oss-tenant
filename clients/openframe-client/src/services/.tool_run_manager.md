Manages the execution of tools within user sessions on Windows systems, providing secure process launching and session management capabilities.

## Key Components

- **get_active_user_session()** - Detects and returns the ID of the active Windows user session
- **launch_process_in_console_session()** - Launches processes in the physical console session
- **launch_process_in_user_session()** - Launches processes in the active user session with proper token handling
- **to_wide()** - Converts strings to wide character format for Windows APIs
- **wcslen()** - Calculates the length of wide character strings

## Windows Session Management

This module provides comprehensive Windows Terminal Services integration for launching tools in the correct user context. It handles session enumeration, user token management, and process creation with proper desktop assignment.

## Usage Example

```rust
#[cfg(windows)]
use crate::tool_run_manager::{launch_process_in_user_session, get_active_user_session};

// Launch a tool in the active user session
let command_path = "C:\\Program Files\\MyTool\\tool.exe";
let args = vec!["--config".to_string(), "settings.json".to_string()];

match launch_process_in_user_session(command_path, &args) {
    Ok((pid, handle)) => {
        println!("Tool launched with PID: {}", pid);
        // Process handle can be used for monitoring
    }
    Err(e) => {
        eprintln!("Failed to launch tool: {}", e);
    }
}

// Check for active user session
if let Some(session_id) = get_active_user_session() {
    println!("Active session found: {}", session_id);
}
```

The module includes robust error handling, logging, and supports both RDP and console sessions with intelligent session selection based on session type and activity status.
