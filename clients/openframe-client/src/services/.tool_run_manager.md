This module manages the execution and lifecycle of tools as separate processes with specialized handling for Windows user session management.

## Key Components

**Core Types:**
- `ToolRunManager` - Main service for launching and managing tool processes
- Windows session management functions for proper user context execution
- Cross-platform process spawning with session awareness

**Key Functions:**
- `get_active_user_session()` - Detects active Windows user sessions (RDP/Console)
- `launch_process_in_user_session()` - Launches processes in proper user context
- `launch_process_in_console_session()` - Alternative console-based process launching
- Session enumeration and selection logic for multi-user environments

**Dependencies:**
- `InstalledTool` - Tool configuration model
- `InstalledToolsService` - Tool registry management
- `ToolCommandParamsResolver` - Command parameter resolution
- `ToolKillService` - Process termination handling

## Usage Example

```rust
use crate::services::tool_run_manager::ToolRunManager;
use crate::models::installed_tool::InstalledTool;

// Initialize the tool run manager
let run_manager = ToolRunManager::new(
    installed_tools_service,
    params_resolver,
    kill_service
);

// Launch a tool in the active user session (Windows)
#[cfg(windows)]
let (pid, handle) = launch_process_in_user_session(
    "C:\\Program Files\\MyTool\\tool.exe",
    &["--config".to_string(), "production".to_string()]
)?;

// The manager handles:
// - User session detection and selection
// - Process isolation and proper desktop assignment
// - Token duplication for security context
// - Cross-platform compatibility
```

The manager provides robust Windows session management, automatically detecting active RDP or console sessions and launching tools with proper user privileges and desktop access.
