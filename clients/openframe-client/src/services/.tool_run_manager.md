This Rust file implements a sophisticated tool execution manager that handles launching external tools and processes, with special support for Windows session management and user impersonation.

## Key Components

- **`ToolRunManager`** - Main service for executing and managing tool processes
- **Windows Session Management** - Functions for detecting active user sessions and launching processes in user context
- **Process Execution** - Cross-platform process launching with proper session handling
- **Retry Logic** - Built-in retry mechanism for failed tool executions

## Usage Example

```rust
use tool_run_manager::ToolRunManager;
use std::sync::Arc;
use tokio::sync::RwLock;

// Initialize the tool run manager
let running_tools = Arc::new(RwLock::new(HashSet::new()));
let tool_manager = ToolRunManager::new(
    installed_tools_service,
    params_resolver,
    kill_service,
    running_tools
);

// Execute a tool with retry logic
let result = tool_manager.run_tool_with_retry(
    "my-tool",
    vec!["--config", "production"],
    3 // max retries
).await?;

// Launch process in Windows user session (Windows only)
#[cfg(windows)]
let (pid, handle) = launch_process_in_user_session(
    "C:\\Program Files\\MyApp\\app.exe",
    &["--start".to_string()]
)?;
```

The manager provides robust cross-platform tool execution with Windows-specific features for running GUI applications in the correct user session, making it ideal for MSP automation tools that need to interact with user desktops.
