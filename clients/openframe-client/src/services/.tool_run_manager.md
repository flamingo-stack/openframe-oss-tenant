Manages tool execution with Windows session integration and proper process lifecycle handling. Provides platform-specific process launching capabilities with session detection, user token management, and process monitoring.

## Key Components

- **`get_active_user_session()`** - Detects active Windows user session for proper GUI app launching
- **`launch_process_in_user_session()`** - Launches processes in the user's desktop session with proper token duplication
- **`launch_process_in_console_session()`** - Alternative launch method using console session
- **Session enumeration utilities** - Windows Terminal Services integration for session management
- **Token management** - Handles user token querying and duplication for process creation
- **Command line building** - Constructs properly quoted command strings with arguments

## Usage Example

```rust
use crate::tool_run_manager::{get_active_user_session, launch_process_in_user_session};

// Detect active user session
if let Some(session_id) = get_active_user_session() {
    info!("Found active session: {}", session_id);
    
    // Launch a GUI application in user session
    let command_path = r"C:\Program Files\MyApp\app.exe";
    let args = vec!["--param1".to_string(), "value with spaces".to_string()];
    
    match launch_process_in_user_session(command_path, &args) {
        Ok((pid, handle)) => {
            info!("Process launched successfully with PID: {}", pid);
            // Process handle can be used for monitoring
        }
        Err(e) => {
            error!("Failed to launch process: {}", e);
        }
    }
}
```

The manager handles complex Windows session management, including service-to-user session bridging, proper token elevation, and desktop assignment for GUI applications. It includes comprehensive logging and error handling for troubleshooting process launch issues.
