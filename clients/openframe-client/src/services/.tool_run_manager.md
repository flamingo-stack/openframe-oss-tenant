Manages the execution of tools across different operating system environments, handling process launching, session management, and Windows-specific user session detection. Provides cross-platform tool execution capabilities with automatic retry mechanisms and process monitoring.

## Key Components

- **`ToolRunManager`** - Main struct for managing tool execution with retry logic and process state tracking
- **`get_active_user_session()`** - Windows-specific function to detect and select the best active user session for GUI applications
- **`launch_process_in_user_session()`** - Windows function to launch processes in active user sessions using proper token duplication
- **`launch_process_in_console_session()`** - Alternative Windows launcher for console session execution
- **Process state tracking** - Uses `Arc<RwLock<HashSet<u32>>>` for concurrent process ID management
- **Session enumeration** - Comprehensive Windows Terminal Services session detection with priority-based selection

## Usage Example

```rust
use crate::tool_run_manager::ToolRunManager;
use crate::services::installed_tools_service::InstalledToolsService;

// Initialize the tool run manager
let tools_service = InstalledToolsService::new();
let mut manager = ToolRunManager::new(tools_service);

// Run a tool with automatic retry and session management
let tool_id = "my-tool-id".to_string();
let result = manager.run_tool(&tool_id).await;

match result {
    Ok(output) => println!("Tool executed successfully: {}", output),
    Err(e) => eprintln!("Tool execution failed: {}", e),
}

// The manager automatically handles:
// - Windows user session detection and selection
// - Process launching with proper tokens
// - Cross-platform compatibility
// - Retry mechanisms with configurable delays
```

**Platform Support**: Full cross-platform support with enhanced Windows session management for GUI applications, including RDP and console session handling.
