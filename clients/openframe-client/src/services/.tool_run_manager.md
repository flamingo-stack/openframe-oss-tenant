Manages the execution and lifecycle of tools within the OpenFrame MSP platform, handling process creation, session management, and tool lifecycle operations across different operating systems.

## Key Components

- **`ToolRunManager`** - Main service for managing tool execution with retry logic and process monitoring
- **Windows Session Management** - Functions for detecting and launching processes in active Windows user sessions:
  - `get_active_user_session()` - Detects active Windows Terminal Services sessions
  - `launch_process_in_user_session()` - Launches processes with proper user context
  - `launch_process_in_console_session()` - Alternative console-based process launching
- **Cross-platform Process Management** - Handles tool execution across Windows and Unix-like systems
- **Integration Services** - Works with `InstalledToolsService`, `ToolCommandParamsResolver`, and `ToolKillService`

## Usage Example

```rust
// Initialize the tool run manager with required services
let tools_service = Arc::new(InstalledToolsService::new());
let params_resolver = Arc::new(ToolCommandParamsResolver::new());
let kill_service = Arc::new(ToolKillService::new());

let run_manager = ToolRunManager::new(
    tools_service,
    params_resolver, 
    kill_service
);

// Execute a tool with parameters
let tool = InstalledTool::new("my-tool", "/path/to/tool");
let params = vec!["--config", "production"];

match run_manager.execute_tool(&tool, &params).await {
    Ok(process_id) => info!("Tool started with PID: {}", process_id),
    Err(e) => error!("Failed to start tool: {}", e),
}
```

The manager automatically handles Windows session detection for GUI tools, implements retry logic with configurable delays, and provides comprehensive logging for debugging tool execution issues.
