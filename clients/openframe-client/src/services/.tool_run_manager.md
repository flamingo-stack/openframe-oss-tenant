Manages the execution of installed tools within user sessions on Windows and Unix systems, handling process launching, session detection, and lifecycle management.

## Key Components

### Core Functions
- `get_active_user_session()` - Detects active Windows user sessions by enumerating Terminal Services sessions
- `launch_process_in_user_session()` - Launches tools in the active user's desktop session using Windows API
- `launch_process_in_console_session()` - Alternative launcher for console-based tool execution
- `ToolRunManager` - Main service for coordinating tool execution and management

### Windows Session Management
- **Session Detection**: Enumerates Windows Terminal Services to find active user sessions
- **Token Management**: Handles user token duplication and security contexts
- **Process Creation**: Uses `CreateProcessAsUserW` for launching tools in user space

### Dependencies
- `InstalledToolsService` - Manages available tools
- `ToolCommandParamsResolver` - Resolves runtime parameters
- `ToolKillService` - Handles process termination

## Usage Example

```rust
use crate::services::tool_run_manager::ToolRunManager;
use crate::models::installed_tool::InstalledTool;

// Initialize the tool run manager
let run_manager = ToolRunManager::new(
    installed_tools_service,
    params_resolver,
    kill_service
);

// Launch a tool in user session
let tool = InstalledTool {
    name: "notepad".to_string(),
    path: "C:\\Windows\\System32\\notepad.exe".to_string(),
    // ... other fields
};

let result = run_manager.launch_tool(&tool, &["document.txt"]).await?;
```

The manager automatically detects active user sessions and launches tools with appropriate security contexts, ensuring GUI applications appear on the user's desktop rather than running as invisible services.
