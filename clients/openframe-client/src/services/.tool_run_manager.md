Manages the execution of external tools as processes with special handling for different platforms and user sessions.

## Key Components

- **`get_active_user_session()`** - Windows-specific function to detect the active user session for proper GUI application launching
- **`launch_process_in_console_session()`** - Launches processes in the Windows console session
- **`launch_process_in_user_session()`** - Launches processes in the active user session with proper token handling
- **Session management utilities** - Helper functions for Windows session enumeration and token duplication
- **Cross-platform process execution** - Handles tool execution across different operating systems

## Usage Example

```rust
use crate::tool_run_manager::*;
use tokio::process::Command;

// Basic async process execution
let mut cmd = Command::new("tool-executable");
cmd.args(&["--config", "config.json"]);
cmd.stdout(Stdio::piped());
cmd.stderr(Stdio::piped());

let child = cmd.spawn()
    .context("Failed to spawn tool process")?;

// Windows-specific user session launch
#[cfg(windows)]
{
    let (pid, handle) = launch_process_in_user_session(
        "C:\\Tools\\MyTool.exe",
        &["--gui".to_string(), "--session".to_string()]
    )?;
    
    info!("Tool launched with PID: {}", pid);
}

// Monitor process output
let reader = BufReader::new(child.stdout.take().unwrap());
let mut lines = reader.lines();
while let Some(line) = lines.next_line().await? {
    debug!("Tool output: {}", line);
}
```

The module provides robust process management with Windows session handling for GUI applications, automatic retries, and comprehensive logging for debugging process launch issues.
