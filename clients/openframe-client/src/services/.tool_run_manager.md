Manages the execution and lifecycle of external tool processes within user sessions, handling Windows-specific session management for proper UI application launching.

## Key Components

- **`get_active_user_session()`** - Detects active Windows Terminal Services sessions, prioritizing RDP over console sessions
- **`launch_process_in_console_session()`** - Launches processes in the physical console session using `WTSGetActiveConsoleSessionId`
- **`launch_process_in_user_session()`** - Launches processes in active user sessions with proper token duplication and desktop assignment
- **Session enumeration logic** - Enumerates and filters Windows sessions to find the most appropriate active user session
- **Token management** - Handles Windows security tokens for process creation in user context

## Usage Example

```rust
use crate::tool_run_manager::*;

// Launch a tool in the active user session (Windows)
#[cfg(windows)]
async fn run_gui_tool() -> Result<()> {
    let command_path = r"C:\Program Files\MyTool\tool.exe";
    let args = vec!["--config".to_string(), "config.json".to_string()];
    
    match launch_process_in_user_session(command_path, &args) {
        Ok((pid, handle)) => {
            info!("Tool launched successfully with PID: {}", pid);
            // Process handle can be used for monitoring
            Ok(())
        }
        Err(e) => {
            error!("Failed to launch tool: {}", e);
            Err(e)
        }
    }
}

// Get the active session ID
#[cfg(windows)]
fn check_active_session() -> Option<u32> {
    if let Some(session_id) = get_active_user_session() {
        info!("Active session found: {}", session_id);
        Some(session_id)
    } else {
        warn!("No active user session available");
        None
    }
}
```

The module provides comprehensive Windows session management for launching GUI applications in the correct user context, essential for MSP tools that need to interact with user desktops. It includes retry logic, extensive logging, and handles edge cases like service contexts and multiple active sessions.
