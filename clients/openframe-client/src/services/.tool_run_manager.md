This rust file manages the execution of external tools as separate processes, with special handling for Windows user session management and cross-platform process launching.

## Key Components

- **`ToolRunManager`** - Core service for launching and monitoring external tool processes
- **Windows Session Management** - Functions for detecting active user sessions (`get_active_user_session`, `launch_process_in_user_session`)
- **Process Launching** - Cross-platform process creation with proper user context
- **Retry Logic** - Built-in retry mechanism with configurable delays
- **Process Monitoring** - Async process lifecycle management with logging

## Usage Example

```rust
use crate::services::tool_run_manager::ToolRunManager;

// Create tool run manager instance
let tool_manager = ToolRunManager::new(
    installed_tools_service,
    params_resolver,
    kill_service
);

// Launch a tool with retry logic
let result = tool_manager
    .launch_tool_with_retry("my-tool", &args, 3)
    .await?;

// Monitor process output
if let Some(process) = result.process {
    let output = process.wait_with_output().await?;
    println!("Tool output: {}", String::from_utf8_lossy(&output.stdout));
}
```

The manager handles Windows-specific challenges like running processes in the correct user session when operating as a service, with fallback mechanisms for console applications. It integrates with the broader tool management system through dependency injection of related services.
