Manages the execution of external tools within Flamingo's OpenFrame platform, providing cross-platform process management with Windows session handling for proper user context execution.

## Key Components

- **`ToolRunManager`** - Main service for launching and managing external tool processes
- **Windows Session Management** - Functions for detecting active user sessions and launching processes in correct session context
- **Process Lifecycle** - Handles tool execution, monitoring, and cleanup with retry mechanisms
- **Cross-platform Support** - Unified interface with platform-specific optimizations for Windows and Unix systems

## Usage Example

```rust
use crate::tool_run_manager::ToolRunManager;
use crate::models::installed_tool::InstalledTool;

// Create a tool run manager instance
let tool_manager = ToolRunManager::new(
    installed_tools_service,
    tool_command_resolver,
    tool_kill_service
);

// Launch a tool with parameters
let tool = InstalledTool {
    name: "nmap".to_string(),
    command_path: "/usr/bin/nmap".to_string(),
    // ... other tool properties
};

// Execute tool with retry logic
match tool_manager.run_tool(&tool, &["--version"]).await {
    Ok(output) => println!("Tool executed: {}", output),
    Err(e) => eprintln!("Tool execution failed: {}", e),
}
```

## Windows-Specific Features

The manager includes sophisticated Windows session detection for proper tool execution in user contexts:

```rust
// Automatically detects active user sessions
let session_id = get_active_user_session();

// Launches tools in the correct user session for GUI applications
let (pid, handle) = launch_process_in_user_session(&command_path, &args)?;
```

## Architecture Integration

This component is essential for Flamingo's AI-driven MSP operations, enabling Mingo AI to execute diagnostic tools and automation scripts across different platforms while maintaining proper security contexts and user session management.
