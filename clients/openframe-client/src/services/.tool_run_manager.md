This module manages the execution of external tools in different user sessions, with specialized Windows support for launching processes in active user sessions.

## Key Components

**Core Structures:**
- `ToolRunManager` - Main service for executing and managing tool processes
- Windows-specific functions for session management and process creation
- Cross-platform process execution with retry logic

**Main Functions:**
- `get_active_user_session()` - Detects active Windows user sessions (RDP/Console)
- `launch_process_in_user_session()` - Launches processes in specific user sessions
- `launch_process_in_console_session()` - Alternative console session launcher
- Helper functions for Windows API integration (`to_wide`, `wcslen`)

**Dependencies:**
- `InstalledTool`, `InstalledToolsService` - Tool management
- `ToolCommandParamsResolver` - Command parameter resolution  
- `ToolKillService` - Process termination handling

## Usage Example

```rust
use crate::tool_run_manager::ToolRunManager;
use crate::models::installed_tool::InstalledTool;

// Launch a tool in the active user session
let tool = InstalledTool::new("notepad.exe", "/path/to/notepad");
let args = vec!["document.txt".to_string()];

#[cfg(windows)]
{
    // Launch in user session with GUI support
    let (pid, handle) = launch_process_in_user_session(
        &tool.executable_path,
        &args
    )?;
    
    println!("Tool launched with PID: {}", pid);
}

// The manager handles session detection, token duplication,
// and proper process creation for both service and user contexts
```

The module provides robust Windows session handling, automatically detecting active RDP or console sessions and launching tools with appropriate user privileges and desktop access.
