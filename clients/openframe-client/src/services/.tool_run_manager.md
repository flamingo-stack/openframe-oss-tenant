A Windows-focused process management system that handles launching and monitoring tools in user sessions, particularly for service-based applications that need to run processes in active desktop environments.

## Key Components

- **Session Management**: `get_active_user_session()` - Detects active Windows user sessions, prioritizing RDP over console sessions
- **Process Launching**: `launch_process_in_user_session()` and `launch_process_in_console_session()` - Creates processes with proper user tokens
- **Token Management**: Handles Windows security tokens for process creation in different user contexts
- **Helper Functions**: `to_wide()` for UTF-16 conversion, `wcslen()` for wide string length calculation
- **Cross-platform Support**: Windows-specific implementations with `#[cfg(windows)]` conditional compilation

## Usage Example

```rust
use crate::tool_run_manager::ToolRunManager;

// Launch a tool in the active user session (Windows)
#[cfg(windows)]
async fn launch_user_tool() -> Result<()> {
    let command_path = r"C:\Program Files\MyApp\tool.exe";
    let args = vec!["--config".to_string(), "production".to_string()];
    
    // This will find the active user session and launch the process there
    let (pid, handle) = launch_process_in_user_session(command_path, &args)?;
    
    info!("Tool launched with PID: {}", pid);
    Ok(())
}

// Get the active console session ID
#[cfg(windows)]
fn check_console_session() -> Option<u32> {
    get_active_user_session()
}
```

The manager is specifically designed for Windows service applications that need to launch GUI tools or processes in the user's desktop environment, handling the complex Windows session and security token management required for cross-session process creation.
