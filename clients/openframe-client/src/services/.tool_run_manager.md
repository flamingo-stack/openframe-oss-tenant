A Windows service component that manages launching and monitoring tool processes within active user sessions, with support for both console and RDP sessions.

## Key Components

- **`ToolRunManager`** - Main struct for managing tool execution and monitoring
- **`get_active_user_session()`** - Detects active Windows user sessions (console/RDP)
- **`launch_process_in_user_session()`** - Launches processes in detected user sessions
- **`launch_process_in_console_session()`** - Launches processes in physical console sessions
- **Session detection logic** - Enumerates Windows Terminal Services sessions
- **Process monitoring** - Tracks running tools and handles failures

## Usage Example

```rust
use crate::tool_run_manager::ToolRunManager;
use crate::services::installed_tools_service::InstalledToolsService;

// Initialize the tool run manager
let tools_service = Arc::new(InstalledToolsService::new());
let manager = ToolRunManager::new(tools_service);

// Run a tool (automatically detects active user session)
let tool = InstalledTool {
    name: "my-tool".to_string(),
    command: "notepad.exe".to_string(),
    // ... other fields
};

manager.run_tool(&tool).await?;
```

The manager handles Windows session management complexities, automatically finding active user sessions (preferring RDP over console), duplicating security tokens, and launching processes with proper desktop access. It includes comprehensive logging and error handling for debugging session-related issues.
