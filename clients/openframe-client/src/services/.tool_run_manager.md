A service for managing external tool execution within user sessions on Windows and Unix systems, handling process spawning, session detection, and lifecycle management.

## Key Components

- **Session Management**: Windows-specific functions for detecting active user sessions (`get_active_user_session`, `WTSEnumerateSessionsW`)
- **Process Launching**: Platform-specific process creation in user context (`launch_process_in_user_session`, `launch_process_in_console_session`)
- **Tool Execution**: Main orchestration through `ToolRunManager` with retry logic and process monitoring
- **Integration Services**: Uses `InstalledToolsService`, `ToolCommandParamsResolver`, and `ToolKillService` for complete tool lifecycle management

## Key Features

- **Cross-Platform Support**: Handles Windows user session management and Unix process spawning
- **Session Detection**: Intelligent Windows session enumeration with preference for RDP over console sessions
- **Process Isolation**: Creates processes with appropriate security context and desktop assignment
- **Error Handling**: Comprehensive error reporting and retry mechanisms with configurable delays
- **Async Operations**: Built on Tokio for non-blocking process management and I/O operations

## Usage Example

```rust
use crate::services::tool_run_manager::ToolRunManager;
use crate::models::installed_tool::InstalledTool;

// Initialize the tool run manager with required services
let tool_manager = ToolRunManager::new(
    installed_tools_service,
    params_resolver,
    kill_service
);

// Execute a tool with automatic session detection and process management
let tool = InstalledTool {
    name: "my-tool".to_string(),
    path: "/path/to/tool".to_string(),
    // ... other fields
};

// The manager handles session detection, process spawning, and monitoring
let result = tool_manager.run_tool(&tool, &args).await?;
```

The service automatically detects the appropriate user session on Windows (preferring RDP sessions), duplicates user tokens for proper security context, and launches processes with the correct desktop assignment for GUI applications.
