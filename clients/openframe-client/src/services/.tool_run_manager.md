This module manages the execution of tools and processes across different user sessions, with specialized Windows session handling for running processes in the appropriate user context.

## Key Components

- **Session Detection Functions**:
  - `get_active_user_session()` - Finds active Windows user sessions
  - `to_wide()` - Converts strings to Windows wide character format
  - `wcslen()` - Calculates wide string length

- **Process Launching Functions**:
  - `launch_process_in_console_session()` - Launches processes in the physical console session
  - `launch_process_in_user_session()` - Launches processes in active user sessions with proper token duplication

## Usage Example

```rust
use tool_run_manager::*;

#[cfg(windows)]
fn launch_tool_for_user() -> Result<(u32, HANDLE)> {
    let command_path = "C:\\Program Files\\MyTool\\tool.exe";
    let args = vec!["--config".to_string(), "production".to_string()];
    
    // Launch in active user session
    let (pid, handle) = launch_process_in_user_session(command_path, &args)?;
    println!("Tool launched with PID: {}", pid);
    
    Ok((pid, handle))
}

// Cross-platform tool execution with retry logic
async fn run_tool_with_retry() {
    for attempt in 1..=3 {
        match execute_tool().await {
            Ok(_) => break,
            Err(e) => {
                warn!("Tool execution failed (attempt {}): {}", attempt, e);
                sleep(Duration::from_secs(RETRY_DELAY_SECONDS)).await;
            }
        }
    }
}
```

The module provides comprehensive Windows session management with detailed logging, token duplication for proper security context, and robust error handling for cross-platform tool execution scenarios.
