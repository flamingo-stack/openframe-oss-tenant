This service manages the execution of installed tools within the Flamingo MSP platform, handling cross-platform process launching with special Windows session management for running tools in active user sessions.

## Key Components

- **`ToolRunManager`** - Main service class for managing tool execution
- **Windows Session Management** - Functions for detecting and launching processes in active Windows user sessions:
  - `get_active_user_session()` - Detects active Windows Terminal Services sessions
  - `launch_process_in_user_session()` - Launches processes in user sessions with proper token handling
  - `launch_process_in_console_session()` - Alternative console session launcher
- **Cross-platform Support** - Conditional compilation for Windows-specific functionality
- **Integration Services** - Uses `InstalledToolsService`, `ToolCommandParamsResolver`, and `ToolKillService`

## Usage Example

```rust
use crate::services::tool_run_manager::ToolRunManager;

// Windows-specific session detection
#[cfg(windows)]
let session_id = get_active_user_session().unwrap_or_else(|| {
    warn!("No active user session found");
    0
});

// Launch a tool in user session (Windows)
#[cfg(windows)]
let (pid, handle) = launch_process_in_user_session(
    "C:\\Program Files\\MyTool\\tool.exe",
    &["--config", "production", "--verbose"]
)?;

// The manager handles tool execution with proper session management,
// ensuring GUI tools appear on the user's desktop rather than running
// as invisible service processes
```

The service is particularly important for MSP environments where tools need to run with proper user context and visibility, handling Windows service-to-user session bridging automatically.
