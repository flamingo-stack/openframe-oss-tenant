Manages the execution of tools in user sessions with platform-specific process launching capabilities. Handles tool lifecycle, retry logic, and provides Windows-specific session management for running GUI applications in the correct user context.

## Key Components

- **ToolRunManager**: Main service for managing tool execution with retry logic and process tracking
- **Windows Session Management**: Functions for detecting active user sessions and launching processes in user context
  - `get_active_user_session()` - Detects active Windows Terminal Services sessions
  - `launch_process_in_user_session()` - Launches GUI applications in user desktop
  - `launch_process_in_console_session()` - Launches processes in console session
- **Tool Execution**: Handles command resolution, parameter injection, and process monitoring
- **Retry Logic**: Automatic retry with configurable delays for failed tool launches

## Usage Example

```rust
use crate::services::tool_run_manager::ToolRunManager;

// Initialize the tool run manager
let installed_tools_service = Arc::new(InstalledToolsService::new());
let params_resolver = Arc::new(ToolCommandParamsResolver::new());
let kill_service = Arc::new(ToolKillService::new());

let manager = ToolRunManager::new(
    installed_tools_service,
    params_resolver,
    kill_service,
);

// Run a tool with retry logic
let tool_id = "some-tool-id";
let result = manager.run_tool_with_retry(tool_id, 3).await;

match result {
    Ok(pid) => println!("Tool launched successfully with PID: {}", pid),
    Err(e) => eprintln!("Failed to launch tool: {}", e),
}

// Check if tool is currently running
if manager.is_tool_running("tool-id").await {
    println!("Tool is currently active");
}
```

The service integrates with `InstalledToolsService` for tool metadata, `ToolCommandParamsResolver` for parameter injection, and `ToolKillService` for process termination. On Windows, it automatically detects the best active user session (preferring RDP over console) and launches GUI applications with proper desktop integration.
