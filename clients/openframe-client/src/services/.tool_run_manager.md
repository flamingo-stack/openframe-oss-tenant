This file provides a comprehensive tool execution manager for running external processes in Windows environments, with special handling for user sessions and service contexts.

## Key Components

**Core Functions:**
- `get_active_user_session()` - Detects active Windows user sessions with sophisticated enumeration
- `launch_process_in_console_session()` - Launches processes in physical console session
- `launch_process_in_user_session()` - Launches processes in active user session with proper token handling

**Helper Functions:**
- `to_wide()` - Converts strings to UTF-16 for Windows APIs
- `wcslen()` - Calculates length of null-terminated wide strings

**Configuration:**
- `RETRY_DELAY_SECONDS` - Constant for retry timing (5 seconds)

## Usage Example

```rust
use crate::tool_run_manager::{get_active_user_session, launch_process_in_user_session};

// Detect active user session
if let Some(session_id) = get_active_user_session() {
    println!("Found active session: {}", session_id);
}

// Launch a process in user context
let args = vec!["--config".to_string(), "app.json".to_string()];
match launch_process_in_user_session("C:\\Program Files\\MyApp\\app.exe", &args) {
    Ok((pid, handle)) => {
        println!("Process launched with PID: {}", pid);
        // Handle process lifecycle
    }
    Err(e) => {
        eprintln!("Failed to launch process: {}", e);
    }
}
```

The module excels at handling complex Windows session management scenarios, making it ideal for MSP tools that need to run processes in user contexts from service environments. It includes comprehensive logging and error handling for troubleshooting session-related issues.
