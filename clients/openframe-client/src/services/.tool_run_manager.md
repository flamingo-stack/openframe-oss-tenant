A service for managing tool process execution in user sessions, handling platform-specific process launching and cross-session communication. Provides Windows-specific functionality for launching processes in active user sessions and Unix-like process management.

## Key Components

- **ToolRunManager** - Main service for launching and managing tool processes
- **get_active_user_session()** (Windows) - Detects active user sessions via WTS enumeration
- **launch_process_in_user_session()** (Windows) - Creates processes in user sessions with proper tokens
- **launch_process_in_console_session()** (Windows) - Alternative console session launcher
- **Process tracking** - Manages running processes with retry logic and monitoring

## Usage Example

```rust
use crate::services::tool_run_manager::ToolRunManager;

// Create tool run manager instance
let tool_manager = ToolRunManager::new(
    installed_tools_service,
    params_resolver,
    kill_service
);

// Launch a tool in user session (Windows)
let result = tool_manager.launch_tool_in_user_session(
    "notepad.exe",
    &["document.txt".to_string()]
).await?;

// Monitor process execution with retry logic
let process_handle = tool_manager.run_with_retry(
    tool_config,
    max_retries
).await?;
```

The service handles Windows session management through Terminal Services APIs, automatically detecting active user sessions and launching processes with appropriate security contexts. It includes comprehensive logging for debugging session detection and process creation issues.
