Resolves placeholder variables in tool command arguments before execution, substituting runtime values like server URL, machine ID, token paths, and dynamic asset paths.

## Key Components

### `ToolCommandParamsResolver`

A cloneable struct that holds references to three services used during placeholder resolution:

| Field | Purpose |
|---|---|
| `directory_manager` | Resolves filesystem paths for assets and secured directories |
| `initial_configuration_service` | Provides the server URL |
| `agent_configuration_service` | Provides the machine ID |

### Supported Placeholders

| Placeholder | Resolved Value |
|---|---|
| `${client.serverUrl}` | HTTPS-prefixed server URL from configuration |
| `${client.openframeSecret}` | Hardcoded secret value |
| `${client.openframeTokenPath}` | Path to `shared_token.enc` in secured directory |
| `${client.machineId}` | Machine identifier from agent configuration |
| `${client.assetPath.<name>}` | Dynamic per-tool asset path (executable flag set) |

### Key Methods

- **`new()`** — Constructs the resolver with required service dependencies
- **`process(tool_agent_id, command_args)`** — Iterates over all command arguments, applying both static and dynamic placeholder substitution
- **`build_token_path()`** — Constructs the full path to the shared encrypted token file
- **`process_assets_placeholders()`** — Applies regex-based substitution for `${client.assetPath.*}` patterns using a `LazyLock` compiled regex

## Usage Example

```rust
let resolver = ToolCommandParamsResolver::new(
    directory_manager,
    initial_configuration_service,
    agent_configuration_service,
);

let raw_args = vec![
    "--server=${client.serverUrl}".to_string(),
    "--binary=${client.assetPath.osquery}".to_string(),
    "--machine=${client.machineId}".to_string(),
];

let resolved = resolver.process("osquery-agent", raw_args)?;
// resolved[0] => "--server=https://example.flamingo.run"
// resolved[1] => "--binary=/opt/openframe/assets/osquery-agent/osquery"
// resolved[2] => "--machine=abc-123-def"
```

> **Note:** The `${client.openframeSecret}` placeholder currently resolves to a hardcoded value. See the source at [`tool_command_params_resolver.rs`](https://github.com/flamingo-stack/openframe-oss-tenant/blob/main/tool_command_params_resolver.rs) for full context.
