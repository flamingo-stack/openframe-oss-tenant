Manages tool connection processing by executing commands to discover agent tool IDs and publishing connection messages to establish communication between tools and the MSP platform.

## Key Components

- **`ToolConnectionProcessingManager`** - Main service that orchestrates tool connection establishment
- **`run()`** - Processes connections for all installed tools
- **`run_new_tool()`** - Handles connection setup for a single newly installed tool
- **`process_tool()`** - Executes agent ID discovery commands and publishes connection messages
- **`running_tools`** - Thread-safe tracking of tools currently being processed to prevent duplicates

## Usage Example

```rust
use crate::services::tool_connection_processing_manager::ToolConnectionProcessingManager;
use crate::models::installed_tool::InstalledTool;

// Initialize the manager with required services
let manager = ToolConnectionProcessingManager::new(
    installed_tools_service,
    params_processor,
    tool_connection_publisher,
    config_service,
    tool_connection_service,
);

// Process all installed tools
manager.run().await?;

// Process a specific newly installed tool
let new_tool = InstalledTool {
    tool_id: "monitoring-agent".to_string(),
    tool_agent_id: "agent-123".to_string(),
    tool_agent_id_command_args: vec!["--get-id".to_string()],
    executable_path: Some("./bin/agent".to_string()),
    tool_type: "monitoring".to_string(),
};

manager.run_new_tool(new_tool).await?;
```

The manager executes commands to discover agent tool IDs, publishes connection messages via the message publisher, and maintains persistent connection records. It includes retry logic with exponential backoff and prevents concurrent processing of the same tool through thread-safe tracking.
