Persistent result store for RMM script execution outcomes, using an embedded [redb](https://github.com/cberner/redb) database to provide durable journal and outbox semantics across agent restarts.

## Key Components

### `ResultPublisher` trait
Async trait for publishing serialized result bytes to a named subject (e.g., a NATS subject). Implementors handle the actual transport layer.

### `JournalRecord`
Tracks in-flight script executions. Records whether execution has `started` (used to distinguish interrupted vs. never-started jobs during recovery).

### `ResultStore`
Core struct wrapping an optional `Arc<Database>`. Degrades gracefully — if the database file is corrupt, it is quarantined (renamed to `.redb.corrupt`) and a fresh DB is opened. If that also fails, the store runs in a disabled/non-durable mode.

**Key methods:**

| Method | Description |
|---|---|
| `open_or_degrade` | Opens or creates the redb database with automatic corruption recovery |
| `journal_batch` | Atomically inserts a batch of `JournalRecord` entries if the execution ID is new |
| `journal_mark_started` | Marks a journal entry as started before script execution begins |
| `complete` | Moves a result from journal → outbox (meta + payload tables), then prunes if over capacity |
| `recover` | On startup, converts any unfinished journal entries into error results in the outbox |
| `encode_result` | Serializes an `RmmResult` to JSON, truncating `stdout`/`stderr` to fit `OUTBOX_MAX_PAYLOAD_BYTES` |
| `pending_keys` | Lists outbox entries awaiting publication |
| `load_payload` / `remove` | Fetch and acknowledge delivered outbox payloads |
| `prune_oldest` | Drops the oldest entries when outbox exceeds `OUTBOX_MAX_ENTRIES` |

### Helper functions
- `entry_key(execution_id, script_id)` — Constructs a composite key for multi-script batches.
- `now_secs()` — Returns current Unix timestamp in seconds.

## Usage Example

```rust
use std::path::PathBuf;

let store = ResultStore::open_or_degrade(PathBuf::from("/var/lib/agent/results.redb"));

// On startup: recover interrupted executions into the outbox
let recovered = store.recover().await?;

// Before executing a script: write a journal entry
let key = entry_key(&execution_id, Some(&script_id));
store.journal_batch(execution_id.clone(), vec![(key.clone(), record)]).await?;
store.journal_mark_started(key.clone()).await?;

// After execution: move result to outbox
let bytes = ResultStore::encode_result(&rmm_result);
store.complete(key, "results.machine-1".to_string(), bytes).await?;

// Drain outbox via publisher
for (key, subject) in store.pending_keys().await? {
    if let Some(payload) = store.load_payload(key.clone()).await? {
        publisher.publish_raw(&subject, &payload).await?;
        store.remove(key).await?;
    }
}
```
