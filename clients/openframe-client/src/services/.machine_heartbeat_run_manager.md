Manages the lifecycle of periodic machine heartbeat publishing, spawning an async background task that emits heartbeats at a fixed interval with timeout protection.

## Key Components

**Constants**
- `HEARTBEAT_INTERVAL` — 60-second tick interval between heartbeat publishes
- `HEARTBEAT_TIMEOUT` — 30-second timeout per individual publish attempt

**`MachineHeartbeatRunManager`**
- `new(publisher)` — Constructs the manager with a `MachineHeartbeatPublisher` instance
- `start()` — Spawns a Tokio background task that loops indefinitely, ticking every 60 seconds and calling `publisher.publish_heartbeat()` wrapped in a timeout; logs errors on failure or timeout (e.g. NATS disconnection) without crashing the task

## Usage Example

```rust
let publisher = MachineHeartbeatPublisher::new(nats_client);
let manager = MachineHeartbeatRunManager::new(publisher);

// Spawns background heartbeat loop — call once at startup
manager.start();
```

## Behavior Notes

- The background loop **never exits** on error; failures are logged and the next tick proceeds normally
- A timeout error specifically indicates a potential NATS connectivity issue
- `start()` is non-blocking — it returns immediately after spawning the task
- `MachineHeartbeatRunManager` is `Clone`, making it safe to share across service boundaries before calling `start()`
