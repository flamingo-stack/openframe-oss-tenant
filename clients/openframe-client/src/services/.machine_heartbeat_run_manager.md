Manages the lifecycle of periodic machine heartbeat publishing, spawning an async background task that emits heartbeats every 60 seconds with a 30-second timeout per attempt.

## Key Components

- **`MachineHeartbeatRunManager`** — Wraps a `MachineHeartbeatPublisher` and drives the heartbeat loop
- **`new(publisher)`** — Constructs the manager with a given publisher instance
- **`start()`** — Spawns a Tokio task that ticks on a 60s interval, invoking `publish_heartbeat()` with a 30s timeout; logs errors on failure or timeout without halting the loop
- **`HEARTBEAT_INTERVAL`** — 60 seconds between heartbeat attempts
- **`HEARTBEAT_TIMEOUT`** — 30 seconds before a single publish attempt is considered timed out

## Usage Example

```rust
let publisher = MachineHeartbeatPublisher::new(nats_client);
let manager = MachineHeartbeatRunManager::new(publisher);

// Spawns a background task; non-blocking
manager.start();
```

> **Note:** `start()` is fire-and-forget — it returns immediately after spawning the background loop. Timeout errors log a warning about potential NATS disconnection but do not terminate the loop, ensuring the agent continues attempting heartbeats on reconnect.
