Manages the lifecycle of periodic machine heartbeat publishing, spawning an async loop that emits heartbeat signals every 60 seconds with a 30-second timeout per attempt.

## Key Components

| Item | Description |
|------|-------------|
| `MachineHeartbeatRunManager` | Main struct holding a `MachineHeartbeatPublisher` instance |
| `HEARTBEAT_INTERVAL` | Tick rate constant — 60 seconds between heartbeats |
| `HEARTBEAT_TIMEOUT` | Max wait per publish attempt — 30 seconds before timeout error |
| `new()` | Constructor accepting a `MachineHeartbeatPublisher` |
| `start()` | Spawns a detached Tokio task running the heartbeat loop |

## Usage Example

```rust
use crate::services::machine_heartbeat_publisher::MachineHeartbeatPublisher;
use crate::run_managers::machine_heartbeat_run_manager::MachineHeartbeatRunManager;

let publisher = MachineHeartbeatPublisher::new(nats_client);
let manager = MachineHeartbeatRunManager::new(publisher);

// Spawns background task — non-blocking
manager.start();
```

## Behavior Notes

- `start()` is **fire-and-forget** — it spawns a background Tokio task and returns immediately
- On successful publish: silent (no log noise)
- On publish error: logs `"Failed to send heartbeat: <err>"`
- On timeout: logs `"Heartbeat timed out - NATS may be disconnected"` — useful signal for NATS connectivity issues
- The struct is `Clone`, making it safe to share across async contexts before calling `start()`
