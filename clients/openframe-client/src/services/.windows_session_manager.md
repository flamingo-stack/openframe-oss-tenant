Manages Windows Terminal Services (WTS) session lifecycle for registered tools, ensuring each tool process runs in every active user session — launching, monitoring, and restarting as needed.

## Key Components

### `WindowsSessionManager` (struct)
The primary manager holding shared state across async tasks:
- `registered_tools` — map of `tool_id → ToolRunInfo` (command path + args)
- `active_sessions` — set of currently active WTS session IDs
- `waiters` — set of `(tool_id, session_id)` pairs with live monitor tasks

### `SessionEvent` (enum)
Translated SCM session-change events: `Logon`, `Logoff`, `ConsoleConnect`, `ConsoleDisconnect`, `RemoteConnect`, `RemoteDisconnect`.

### Key Methods
- `WindowsSessionManager::new(session_rx)` — seeds active sessions via WTS enumeration, spawns the event dispatch loop
- `register_tool(tool_id, command_path, launch_args, new_tool)` — registers a tool and spawns per-session monitor tasks; if `new_tool` is `false`, waits `SESSION_STARTUP_DELAY_SECONDS` (5 min) to allow AutoRun to start the process first
- `ensure_waiter(...)` — deduplicates and spawns `waiter_task` per `(tool_id, session_id)` pair

### `waiter_task` (async fn)
Per-`(tool_id, session_id)` loop that:
1. Checks session/tool still active
2. Attaches to an existing process (via `find_pid_in_target_session`) or launches one
3. Blocks on `WaitForSingleObject` via `spawn_blocking`
4. Restarts after `RETRY_DELAY_SECONDS` on exit

### Helper Functions
- `enumerate_active_user_sessions()` — WTS enumeration filtering out session 0 and listener stations
- `find_pid_in_target_session(exe_path, session_id)` — matches a running process by full path or filename within a target session

## Usage Example

```rust
let (tx, rx) = tokio::sync::mpsc::unbounded_channel::<SessionEvent>();
let manager = WindowsSessionManager::new(rx);

manager.register_tool(
    "my_agent".to_string(),
    r"C:\Tools\agent.exe".to_string(),
    vec!["--mode".to_string(), "service".to_string()],
    true, // new install, no AutoRun delay
).await;

// Dispatch session events from the SCM handler
tx.send(SessionEvent::Logon { session_id: 3 }).unwrap();
```
