Manages Windows Terminal Services (WTS) session lifecycle for per-session tool process supervision — tracking active sessions, registering tools, and ensuring each registered tool runs (or restarts) in every active user session.

## Key Components

- **`SessionEvent`** — Enum translating SCM `ServiceControl::SessionChange` events (Logon, Logoff, ConsoleConnect/Disconnect, RemoteConnect/Disconnect)
- **`WindowsSessionManager`** — Core struct holding:
  - `registered_tools` — map of tool ID → command path + args
  - `active_sessions` — set of currently active WTS session IDs
  - `waiters` — set of active `(tool_id, session_id)` supervisor tasks
- **`WindowsSessionManager::new()`** — Seeds active sessions via WTS enumeration and spawns the SCM event dispatch loop
- **`WindowsSessionManager::register_tool()`** — Registers a tool for per-session lifecycle management; spawns waiters for all current sessions
- **`waiter_task()`** — Per-`(tool_id, session_id)` async task: attaches to an existing process or launches a new one, waits for exit, then restarts after `RETRY_DELAY_SECONDS`
- **`enumerate_active_user_sessions()`** — Calls `WTSEnumerateSessionsW`, filters for `WTSActive` non-zero non-listener sessions
- **`find_pid_in_target_session()`** — Calls `WTSEnumerateProcessesW` to locate a running process by exe path within a specific session

## Usage Example

```rust
// Create a channel for SCM session events
let (session_tx, session_rx) = mpsc::unbounded_channel::<SessionEvent>();

// Build the manager (seeds active sessions, spawns event loop)
let manager = WindowsSessionManager::new(session_rx);

// Register a tool — will launch/supervise in all active sessions
manager.register_tool(
    "my_agent".to_string(),
    r"C:\Program Files\MyTool\agent.exe".to_string(),
    vec!["--headless".to_string()],
    true, // new_tool: skip AutoRun startup delay
).await;

// Forward SCM session change events into the manager
session_tx.send(SessionEvent::Logon { session_id: 3 }).ok();
```

> **Constants:** `RETRY_DELAY_SECONDS = 5` · `SESSION_STARTUP_DELAY_SECONDS = 300` (AutoRun startup grace period)
