Handles agent registration with the Flamingo platform by collecting device metadata, submitting a registration request, and persisting the resulting credentials.

## Key Components

**`AgentRegistrationService`** — Primary service struct with four dependencies:
- `registration_client` — HTTP client for the registration API endpoint
- `device_data_fetcher` — Collects local device metadata (hostname, OS type, agent version)
- `config_service` — Persists registration credentials post-registration
- `initial_configuration_service` — Provides the initial key, org ID, and tags

**`register_agent()`** — Async entry point that orchestrates the full registration flow: fetches the initial key, builds the request, calls the API, and saves the returned `machine_id`, `client_id`, and `client_secret`.

**`build_registration_request()`** — Private helper that assembles an `AgentRegistrationRequest` from device and configuration data, gracefully defaulting missing fields to empty strings.

## Usage Example

```rust
let service = AgentRegistrationService::new(
    registration_client,
    device_data_fetcher,
    config_service,
    initial_configuration_service,
);

match service.register_agent().await {
    Ok(response) => {
        println!("Registered with machine_id: {}", response.machine_id);
    }
    Err(e) => {
        eprintln!("Registration failed: {e:#}");
    }
}
```

> **Note:** Registration is typically a one-time operation at agent startup. The service saves credentials via `AgentConfigurationService` so subsequent runs can authenticate without re-registering.
