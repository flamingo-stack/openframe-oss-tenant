Handles agent registration with the Flamingo platform by collecting device data, submitting a registration request, and persisting the resulting credentials.

## Key Components

**`AgentRegistrationService`** — Core service struct (clonable) with four dependencies:
- `RegistrationClient` — HTTP client for the registration API
- `DeviceDataFetcher` — Collects local device metadata (hostname, OS, agent version)
- `AgentConfigurationService` — Persists registration credentials after a successful response
- `InitialConfigurationService` — Reads the initial provisioning key, org ID, and tags

**`register_agent()`** — Async entry point that orchestrates the full registration flow: fetch initial key → build request → call API → save credentials.

**`build_registration_request()`** — Assembles an `AgentRegistrationRequest` from local device data and initial configuration, falling back to empty/default values on any fetch failure.

## Usage Example

```rust
let service = AgentRegistrationService::new(
    registration_client,
    device_data_fetcher,
    config_service,
    initial_configuration_service,
);

match service.register_agent().await {
    Ok(response) => {
        println!("Registered as machine: {}", response.machine_id);
    }
    Err(e) => {
        eprintln!("Registration failed: {}", e);
    }
}
```

> **Note:** `register_agent()` is idempotent in intent but not in implementation — calling it multiple times will attempt re-registration and overwrite saved credentials. Guard the call site with a prior check for existing registration state.
