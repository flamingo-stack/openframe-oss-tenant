This service manages the complete OpenFrame client update process, handling version validation, binary downloads, and platform-specific update execution with race condition protection.

## Key Components

- **`OpenFrameClientUpdateService`** - Main service struct with update lock protection
- **`process_update()`** - Public entry point with race condition prevention
- **`process_update_internal()`** - Core update logic with validation and error handling
- **`execute_update()`** - Performs the actual download, extraction, and updater launch
- **`create_temp_archive()`** - Platform-specific binary preparation (ZIP on Windows, direct file on Unix)
- **`parse_version()`** / **`is_valid_version()`** - Version validation utilities

## Usage Example

```rust
use openframe_client_update_service::*;

// Create service with dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process update message
let message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* configs */],
};

match update_service.process_update(message).await {
    Ok(()) => println!("Update launched successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service follows a robust update workflow: version validation → status tracking → binary download/extraction → updater launch, with comprehensive error handling and cleanup on failure. It prevents concurrent updates using async mutexes and handles platform differences for binary preparation.
