Service that orchestrates OpenFrame client software updates through a multi-phase process with race condition protection, version validation, and platform-specific binary deployment.

## Key Components

- **OpenFrameClientUpdateService**: Main service coordinating update operations
- **update_in_progress**: Mutex preventing concurrent updates
- **process_update()**: Public interface for handling update requests
- **execute_update()**: Core update execution with download, extraction, and updater launch
- **create_temp_archive()**: Platform-specific binary preparation (ZIP on Windows, direct file on Unix)
- **parse_version()** / **is_valid_version()**: Semantic versioning validation utilities

## Usage Example

```rust
use openframe_client_update_service::OpenFrameClientUpdateService;
use openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize service with dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* platform configs */],
};

// This will validate version, download binary, and launch platform updater
match update_service.process_update(message).await {
    Ok(_) => println!("Update process initiated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service manages the complete update lifecycle from validation through binary deployment, with automatic cleanup on failures and proper state tracking throughout the process.
