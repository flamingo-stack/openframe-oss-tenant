A service that orchestrates the complete OpenFrame client update process, handling version validation, binary downloads, and platform-specific update execution with race condition protection and comprehensive error handling.

## Key Components

- **OpenFrameClientUpdateService** - Main update orchestration service with concurrent update prevention
- **process_update()** - Public entry point that validates update requests and manages update locks
- **process_update_internal()** - Core update logic with version validation and status tracking
- **execute_update()** - Handles the actual download, extraction, and updater launch sequence
- **create_temp_archive()** - Platform-specific binary preparation (ZIP for Windows, direct file for Unix)
- **parse_version()** / **is_valid_version()** - Version validation utilities using semantic versioning

## Usage Example

```rust
use openframe_client_update_service::OpenFrameClientUpdateService;
use openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize the service with required dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* platform configs */],
};

// Execute update (handles race conditions automatically)
match update_service.process_update(message).await {
    Ok(()) => println!("Update process initiated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service ensures only one update can run at a time, validates version formats using semver, tracks update progress through multiple phases, and handles platform-specific binary preparation before launching the external updater process.
