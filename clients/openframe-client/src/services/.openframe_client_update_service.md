This service orchestrates OpenFrame client updates by downloading, extracting, and launching update processes while maintaining state tracking and preventing concurrent updates.

## Key Components

- **`OpenFrameClientUpdateService`** - Main service struct with mutex-protected update coordination
- **`process_update()`** - Public entry point that handles update requests with race condition protection
- **`process_update_internal()`** - Internal update logic with version validation and state management
- **`execute_update()`** - Core update execution including download, extraction, and updater launch
- **`create_temp_archive()`** - Platform-specific binary preparation (ZIP for Windows, direct file for Unix)
- **Version utilities** - `parse_version()` and `is_valid_version()` for semver validation

## Usage Example

```rust
use openframe_client_update_service::OpenFrameClientUpdateService;
use openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize the service with dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* download configs */],
};

match update_service.process_update(message).await {
    Ok(()) => println!("Update process initiated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service includes comprehensive error handling, state persistence, and platform-specific update mechanisms. It prevents concurrent updates using async mutexes and maintains detailed logging throughout the update lifecycle.
