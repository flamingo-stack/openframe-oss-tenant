A service for handling OpenFrame client updates with download, extraction, and platform-specific update launching capabilities. Provides thread-safe update processing with version validation and comprehensive error handling.

## Key Components

- **OpenFrameClientUpdateService** - Main service struct that orchestrates the update process
- **process_update()** - Public entry point with concurrency protection and version validation
- **process_update_internal()** - Core update logic with status tracking
- **execute_update()** - Handles download, extraction, and updater launching
- **create_temp_archive()** - Platform-specific binary preparation (ZIP on Windows, direct write on Unix)
- **parse_version()** / **is_valid_version()** - Version validation utilities using semver

## Usage Example

```rust
use openframe_client_update_service::OpenFrameClientUpdateService;
use openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize the service with required dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* download configs */],
};

match update_service.process_update(message).await {
    Ok(_) => println!("Update process initiated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service uses a mutex to prevent concurrent updates and provides comprehensive state tracking throughout the update lifecycle, from download through platform-specific updater script execution.
