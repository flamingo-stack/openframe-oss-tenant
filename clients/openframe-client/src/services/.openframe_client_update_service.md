Service that orchestrates OpenFrame client updates by downloading, validating, and launching platform-specific update processes with comprehensive error handling and race condition protection.

## Key Components

- **OpenFrameClientUpdateService** - Main service coordinating the update workflow
- **update_in_progress** - Mutex-protected flag preventing concurrent updates
- **process_update()** - Public entry point that validates requests and manages update locks
- **execute_update()** - Internal method handling download, extraction, and updater launch
- **create_temp_archive()** - Platform-specific archive creation (ZIP on Windows, direct binary on Unix)
- **parse_version()** - Semver validation with support for various version formats

## Usage Example

```rust
use openframe_client_update_service::OpenFrameClientUpdateService;
use crate::models::openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize the service with dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* platform configs */],
};

// The service handles version validation, download, and updater launch
match update_service.process_update(message).await {
    Ok(_) => println!("Update process initiated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service automatically prevents race conditions, validates semver formats, tracks update state through multiple phases (downloading, extracting, launching), and provides platform-specific handling for Windows (ZIP archives) and Unix (direct binaries).
