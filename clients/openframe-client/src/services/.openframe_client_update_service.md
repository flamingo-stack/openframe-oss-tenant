Handles OpenFrame client software updates with thread-safe download, validation, and installation processes. This service coordinates the complete update lifecycle from version validation through binary installation.

## Key Components

- **OpenFrameClientUpdateService** - Main service struct coordinating the update process
- **process_update()** - Entry point with race condition protection using mutex
- **execute_update()** - Core update logic handling download, extraction, and installation
- **create_temp_archive()** - Platform-specific binary preparation (ZIP for Windows, direct file for Unix)
- **parse_version()** / **is_valid_version()** - Version validation using semantic versioning

## Usage Example

```rust
use openframe_client_update_service::OpenFrameClientUpdateService;
use crate::models::openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize service with dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process update request
let update_message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* platform configs */],
};

match update_service.process_update(update_message).await {
    Ok(_) => println!("Update process launched successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service ensures only one update runs at a time, validates versions using semver, downloads binaries from GitHub, and launches platform-specific updater scripts that handle the final installation and service restart.
