A service that manages OpenFrame client updates, handling version validation, binary downloads, and coordinated update execution with proper state management and race condition protection.

## Key Components

- **`OpenFrameClientUpdateService`** - Main service struct with dependency injection for client info, download, and state management services
- **`process_update()`** - Public entry point that validates update requests and prevents concurrent updates using mutex locking
- **`process_update_internal()`** - Core update logic with version validation, state tracking, and error handling
- **`execute_update()`** - Handles the actual update workflow: download → extract → prepare → launch updater
- **`create_temp_archive()`** - Platform-specific archive creation (ZIP on Windows, direct binary on Unix)
- **`parse_version()` / `is_valid_version()`** - Version validation utilities supporting semver formats

## Usage Example

```rust
use crate::services::openframe_client_update_service::OpenFrameClientUpdateService;
use crate::models::openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize service with dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![download_config],
};

match update_service.process_update(message).await {
    Ok(_) => println!("Update process initiated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service ensures safe updates through mutex locking, comprehensive error handling, and proper state cleanup on failures. It supports cross-platform binary deployment and integrates with the OpenFrame client lifecycle management system.
