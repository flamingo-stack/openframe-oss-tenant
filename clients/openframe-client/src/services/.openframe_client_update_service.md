Service that manages OpenFrame client updates through a robust, async update process with comprehensive safety checks and error handling.

## Key Components

- **OpenFrameClientUpdateService** - Main service orchestrating the complete update workflow
- **process_update()** - Public entry point with race condition protection via mutex
- **process_update_internal()** - Core update logic with version validation and status tracking
- **execute_update()** - Handles download, extraction, and updater launch phases
- **create_temp_archive()** - Platform-specific archive creation (ZIP on Windows, direct binary on Unix)
- **parse_version()/is_valid_version()** - Semver version validation utilities

## Usage Example

```rust
// Initialize the service
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* configs */],
};

match update_service.process_update(message).await {
    Ok(()) => println!("Update launched successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}

// Version validation
assert!(OpenFrameClientUpdateService::is_valid_version("1.2.3"));
assert!(OpenFrameClientUpdateService::is_valid_version("v2.0.0-beta"));
```

The service implements a state machine progressing through phases: Downloading → Extracting → PreparingUpdater → UpdaterLaunched, with automatic cleanup on failures and comprehensive logging throughout the process.
