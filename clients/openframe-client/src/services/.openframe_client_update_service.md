A service that manages OpenFrame client application updates through a secure, multi-phase process with race condition protection and comprehensive error handling.

## Key Components

- **OpenFrameClientUpdateService** - Main service coordinating the complete update workflow
- **process_update()** - Entry point with race condition protection using mutex locks
- **execute_update()** - Core update logic handling download, extraction, and updater launch
- **create_temp_archive()** - Platform-specific binary preparation (ZIP for Windows, direct file for Unix)
- **parse_version()** - Semver-compliant version parsing with 'v' prefix support
- **is_valid_version()** - Basic version format validation

## Usage Example

```rust
use crate::services::openframe_client_update_service::OpenFrameClientUpdateService;
use crate::models::openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize service with dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process update request
let message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* platform configs */],
};

match update_service.process_update(message).await {
    Ok(()) => println!("Update process initiated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service implements a robust update pipeline with phase tracking (Downloading → Extracting → PreparingUpdater → UpdaterLaunched), automatic cleanup on failures, and platform-specific binary handling to ensure safe application updates.
