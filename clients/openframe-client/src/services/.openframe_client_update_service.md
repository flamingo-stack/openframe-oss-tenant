Manages the automated update process for the OpenFrame client with comprehensive safety checks, version validation, and platform-specific binary deployment. Coordinates downloading, validation, and installation of new client versions through external updater processes.

## Key Components

- **OpenFrameClientUpdateService** - Main service struct that orchestrates client update operations
- **process_update()** - Entry point that handles race condition protection and update workflow
- **execute_update()** - Core update logic including download, extraction, and updater launch
- **create_temp_archive()** - Platform-specific binary packaging (ZIP on Windows, direct binary on Unix)
- **parse_version()** / **is_valid_version()** - Version validation and semantic versioning support
- **UpdateState tracking** - Progress monitoring through different update phases

## Usage Example

```rust
// Initialize the update service with required dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update message from NATS
let message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* platform configs */],
};

// Execute the update (returns after launching updater)
update_service.process_update(message).await?;
```

The service provides atomic update operations with proper error handling, cleanup on failure, and prevents concurrent updates through mutex locking. The update process transitions through phases (Downloading → Extracting → PreparingUpdater → UpdaterLaunched) with persistent state tracking for recovery scenarios.
