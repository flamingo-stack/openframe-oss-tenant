An asynchronous service that handles OpenFrame client software updates by downloading, extracting, and launching platform-specific updater processes with comprehensive error handling and state management.

## Key Components

- **OpenFrameClientUpdateService**: Main service managing the complete update lifecycle with race condition protection
- **process_update()**: Public entry point with mutex-based concurrency control to prevent duplicate updates
- **process_update_internal()**: Core update logic with version validation and safety checks
- **execute_update()**: Handles download, extraction, and updater launching phases
- **create_temp_archive()**: Platform-specific archive creation (ZIP for Windows, direct binary for Unix)
- **parse_version()** & **is_valid_version()**: Semantic version validation utilities

## Usage Example

```rust
use openframe_client_update_service::OpenFrameClientUpdateService;
use crate::models::openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize service with dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* platform configs */],
};

// This will handle the complete update process:
// 1. Version validation
// 2. Download from GitHub
// 3. Platform-specific archive creation
// 4. Launch updater script
match update_service.process_update(message).await {
    Ok(()) => println!("Update process initiated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service ensures only one update can run at a time, tracks progress through multiple phases (downloading, extracting, preparing updater, launched), and handles cleanup on failures. After launching the updater, the current service process will be terminated and restarted with the new version.
