Manages the OpenFrame client update process, handling version validation, binary downloads, and coordinating with platform-specific updater scripts. Provides race condition protection and comprehensive error handling for safe automated updates.

## Key Components

- **OpenFrameClientUpdateService**: Main service struct that orchestrates the update workflow
- **process_update()**: Public entry point with concurrency protection using mutex locks
- **process_update_internal()**: Core update logic with version validation and status tracking
- **execute_update()**: Handles download, extraction, and updater script launching
- **create_temp_archive()**: Platform-specific binary preparation (ZIP for Windows, direct binary for Unix)
- **parse_version()** / **is_valid_version()**: Semver validation utilities

## Usage Example

```rust
use openframe_client_update_service::OpenFrameClientUpdateService;
use crate::models::openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize the service with dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* platform configs */],
};

match update_service.process_update(message).await {
    Ok(()) => println!("Update initiated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service ensures only one update can run at a time, validates semver versions, tracks update progress through different phases, and handles platform-specific binary preparation before launching the updater script that will restart the service.
