Orchestrates secure client update operations for OpenFrame, handling version validation, binary downloads, and platform-specific update launcher coordination with comprehensive error handling and race condition protection.

## Key Components

- **OpenFrameClientUpdateService** - Main service managing the update workflow
- **process_update** - Entry point with mutex-protected update processing
- **execute_update** - Core update logic handling download, extraction, and launcher
- **create_temp_archive** - Platform-specific binary preparation (ZIP for Windows, direct file for Unix)
- **parse_version/is_valid_version** - Semantic version validation helpers

## Usage Example

```rust
use openframe_client_update_service::OpenFrameClientUpdateService;
use crate::models::openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize with required dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process update request with version validation
let update_message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* platform configs */],
};

match update_service.process_update(update_message).await {
    Ok(()) => info!("Update process initiated successfully"),
    Err(e) => error!("Update failed: {:#}", e),
}
```

The service ensures single-threaded updates via mutex protection, validates semantic versions, downloads platform-appropriate binaries, and coordinates with platform-specific updater scripts while maintaining comprehensive state tracking throughout the update process.
