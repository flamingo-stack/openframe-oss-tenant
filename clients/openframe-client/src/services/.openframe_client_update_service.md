Service responsible for orchestrating OpenFrame client updates including version validation, binary downloads, and update process execution with comprehensive error handling and concurrency protection.

## Key Components

- **OpenFrameClientUpdateService** - Main service struct with mutex-protected update state
- **process_update()** - Entry point for processing update requests with race condition protection
- **execute_update()** - Core update logic handling download, extraction, and updater launch
- **create_temp_archive()** - Platform-specific temporary file creation (ZIP on Windows, direct binary on Unix)
- **parse_version()** / **is_valid_version()** - Version validation utilities using semver

## Usage Example

```rust
// Initialize the update service
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let update_message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* download configs */],
};

// This will handle the entire update process
match update_service.process_update(update_message).await {
    Ok(()) => println!("Update process initiated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service manages the complete update lifecycle from version validation through binary download and updater launch, with robust error handling and state tracking at each phase. It prevents concurrent updates using a mutex and provides platform-specific handling for Windows (ZIP archives) and Unix systems (direct binaries).
