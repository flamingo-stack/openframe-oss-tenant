This service handles automated client updates for the OpenFrame platform, coordinating version downloads, validation, and the update execution process with proper safety checks and error handling.

## Key Components

- **OpenFrameClientUpdateService** - Main service struct with dependency injection for client info, GitHub downloads, and update state management
- **process_update()** - Entry point that validates update requests and prevents concurrent updates using mutex locking
- **execute_update()** - Core update logic that downloads, extracts, and launches the updater process
- **create_temp_archive()** - Platform-specific methods (Windows ZIP vs Unix binary) for preparing update files
- **Version validation** - Semver parsing and format validation for update safety

## Usage Example

```rust
use openframe_client_update_service::OpenFrameClientUpdateService;
use openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize the service with required dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let update_message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* platform configs */],
};

// Execute update with race condition protection
match update_service.process_update(update_message).await {
    Ok(_) => println!("Update process initiated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service ensures safe updates through version validation, concurrent update prevention, proper error handling with status rollback, and platform-specific binary preparation. Update state is tracked throughout the process for recovery purposes.
