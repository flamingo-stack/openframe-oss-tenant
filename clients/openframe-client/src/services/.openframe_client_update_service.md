This service orchestrates the self-update process for OpenFrame clients, handling version validation, binary downloads, and platform-specific update execution with comprehensive error handling and state tracking.

## Key Components

**OpenFrameClientUpdateService**: Main service struct with dependencies and update concurrency protection
- `client_info_service`: Manages client information and update status
- `github_download_service`: Handles binary downloads from GitHub releases
- `update_state_service`: Tracks update progress and state persistence
- `update_in_progress`: Mutex preventing concurrent updates

**Core Methods**:
- `process_update()`: Entry point with concurrency control and error handling
- `execute_update()`: Orchestrates the complete update workflow
- `create_temp_archive()`: Platform-specific archive creation (ZIP for Windows, direct binary for Unix)
- Version validation utilities (`parse_version`, `is_valid_version`)

## Usage Example

```rust
use openframe_client_update_service::OpenFrameClientUpdateService;
use crate::models::openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize the service with dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let update_message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* download configs */],
};

match update_service.process_update(update_message).await {
    Ok(_) => println!("Update process initiated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service ensures safe updates through version validation, atomic state management, and proper cleanup on failures. It supports both Windows (ZIP archives) and Unix (direct binary) platforms with appropriate updater script launching.
