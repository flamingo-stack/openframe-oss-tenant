A comprehensive service for handling OpenFrame client updates with version validation, download management, and platform-specific update execution. This service orchestrates the entire update process from version verification through binary deployment.

## Key Components

- **OpenFrameClientUpdateService** - Main service struct with race condition protection via mutex
- **process_update()** - Primary entry point that validates versions and coordinates the update process
- **execute_update()** - Core update logic handling download, extraction, and updater launch
- **create_temp_archive()** - Platform-specific binary packaging (ZIP on Windows, direct binary on Unix)
- **parse_version()** / **is_valid_version()** - Version validation utilities using semver

## Usage Example

```rust
use crate::services::openframe_client_update_service::OpenFrameClientUpdateService;
use crate::models::openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize the service with dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let update_message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* platform configs */],
};

match update_service.process_update(update_message).await {
    Ok(()) => println!("Update initiated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service includes comprehensive error handling, state tracking, and automatic cleanup on failures. It prevents concurrent updates through mutex protection and supports both semantic versioning formats with or without the 'v' prefix.
