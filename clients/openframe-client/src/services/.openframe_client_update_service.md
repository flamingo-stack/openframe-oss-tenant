Manages OpenFrame client self-update operations by downloading new versions from GitHub and launching platform-specific update processes with comprehensive state tracking and race condition protection.

## Key Components

- **OpenFrameClientUpdateService** - Main service struct that orchestrates the update process
- **process_update()** - Entry point that validates versions and prevents concurrent updates using mutex
- **execute_update()** - Core update logic that downloads, extracts, and launches the updater
- **create_temp_archive()** - Platform-specific archive creation (ZIP on Windows, direct binary on Unix)
- **parse_version()** / **is_valid_version()** - Version validation using semantic versioning

## Usage Example

```rust
use openframe_client_update_service::OpenFrameClientUpdateService;
use openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize the service with dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let update_message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* platform configs */],
};

// This will download, prepare, and launch the updater
match update_service.process_update(update_message).await {
    Ok(()) => println!("Update process initiated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service handles the complete update lifecycle including version validation, binary download from GitHub releases, temporary file management, and launching platform-specific update scripts that will restart the service with the new version.
