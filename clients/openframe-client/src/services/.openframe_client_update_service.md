Manages OpenFrame client updates with race condition protection and comprehensive state tracking through multiple update phases.

## Key Components

- **OpenFrameClientUpdateService** - Main service orchestrating client updates with mutex-protected concurrent update prevention
- **process_update()** - Entry point that validates update requests and manages update locks
- **execute_update()** - Core update logic handling download, extraction, and updater process launch
- **create_temp_archive()** - Platform-specific archive creation (ZIP for Windows, direct binary for Unix)
- **parse_version()** - Semantic version parsing with 'v' prefix support
- **is_valid_version()** - Basic version format validation

## Usage Example

```rust
use openframe_client_update_service::OpenFrameClientUpdateService;
use crate::models::openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize the service with dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* platform configs */],
};

match update_service.process_update(message).await {
    Ok(()) => println!("Update initiated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service handles the complete update lifecycle: version validation, OS-specific download configuration selection, binary download/extraction, temporary archive creation, and updater process launch. It maintains update state throughout the process and prevents race conditions through mutex locking.
