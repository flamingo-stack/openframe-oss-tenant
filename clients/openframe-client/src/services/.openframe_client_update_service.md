A service that manages OpenFrame client updates by downloading new versions, validating them, and launching platform-specific update processes with state tracking and race condition protection.

## Key Components

- **`OpenFrameClientUpdateService`** - Main service for processing client updates with concurrent update prevention
- **`process_update`** - Public method that handles update requests with mutex-based locking
- **`process_update_internal`** - Internal update processing with version validation and safety checks
- **`execute_update`** - Core update execution including download, extraction, and updater launch
- **`create_temp_archive`** - Platform-specific binary preparation (ZIP on Windows, direct file on Unix)
- **Version validation methods** - `parse_version` and `is_valid_version` for semver compliance

## Usage Example

```rust
use openframe_client_update_service::OpenFrameClientUpdateService;
use openframe_client_update_message::OpenFrameClientUpdateMessage;

// Create service with dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* download configs */],
};

match update_service.process_update(message).await {
    Ok(_) => println!("Update process started successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service ensures only one update runs at a time using an async mutex, validates version formats using semver, tracks update progress through different phases, and handles platform-specific binary packaging before launching the updater process.
