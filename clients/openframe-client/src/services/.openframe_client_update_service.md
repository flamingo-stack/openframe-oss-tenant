OpenFrame client update service that manages the complete update lifecycle for OpenFrame client binaries, handling version validation, download, extraction, and update process execution with concurrency protection.

## Key Components

### Core Structure
- **OpenFrameClientUpdateService** - Main service managing client updates with race condition protection
- **update_in_progress** - Mutex preventing concurrent update operations

### Primary Methods
- **process_update()** - Entry point for update requests with validation and lock management
- **execute_update()** - Downloads binary, creates archive, and launches platform-specific updater
- **create_temp_archive()** - Platform-specific binary packaging (ZIP on Windows, direct binary on Unix)

### Validation Functions
- **parse_version()** - Semantic version parsing with 'v' prefix support
- **is_valid_version()** - Basic version format validation

## Usage Example

```rust
// Initialize the service
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* config data */],
};

match update_service.process_update(message).await {
    Ok(()) => println!("Update process initiated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service maintains update state throughout the process (downloading, extracting, preparing updater) and handles cleanup on failures. After launching the updater, the service expects to be stopped and restarted with the new version.
