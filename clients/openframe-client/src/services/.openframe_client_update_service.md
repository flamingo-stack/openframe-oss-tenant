The OpenFrame Client Update Service manages automated updates for the OpenFrame client application, handling download, extraction, and installation of new versions with comprehensive error handling and concurrency protection.

## Key Components

- **OpenFrameClientUpdateService**: Main service struct that orchestrates the entire update process
- **process_update()**: Entry point that validates update requests and prevents concurrent updates using mutex locking
- **execute_update()**: Core update logic that downloads, extracts, and launches the updater process
- **create_temp_archive()**: Platform-specific methods for preparing update files (ZIP for Windows, direct binary for Unix)
- **parse_version()/is_valid_version()**: Version validation utilities supporting semver format

## Usage Example

```rust
use openframe_client_update_service::OpenFrameClientUpdateService;
use openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize the service with required dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* platform configs */],
};

// Execute update (with automatic concurrency protection)
match update_service.process_update(message).await {
    Ok(_) => println!("Update initiated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service ensures only one update runs at a time, validates version formats, tracks update progress through different phases (downloading, extracting, launching updater), and handles platform-specific binary packaging before launching the system updater.
