This service manages OpenFrame client updates through NATS messaging, handling version validation, binary downloads, and platform-specific update processes with comprehensive error handling and state tracking.

## Key Components

- **OpenFrameClientUpdateService** - Main service class coordinating the update process
- **process_update()** - Entry point with race condition protection using mutex locks
- **execute_update()** - Core update logic handling download, extraction, and updater launch
- **create_temp_archive()** - Platform-specific binary preparation (ZIP for Windows, direct binary for Unix)
- **parse_version()** - Semantic version validation and parsing
- **is_valid_version()** - Basic version format validation

## Usage Example

```rust
use openframe_client_update_service::OpenFrameClientUpdateService;
use openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize the service with dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* platform configs */],
};

match update_service.process_update(message).await {
    Ok(_) => println!("Update process initiated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service ensures only one update runs at a time, validates semantic versions, downloads platform-appropriate binaries from GitHub releases, and launches platform-specific updater scripts while maintaining comprehensive state tracking throughout the process.
