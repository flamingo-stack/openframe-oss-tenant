Orchestrates OpenFrame client updates by downloading, extracting, and launching platform-specific update processes while preventing race conditions and providing comprehensive error handling.

## Key Components

- **OpenFrameClientUpdateService** - Main service struct handling the complete update lifecycle
- **process_update()** - Entry point that prevents concurrent updates using mutex protection
- **process_update_internal()** - Core update logic with version validation and state management
- **execute_update()** - Downloads binary, creates temporary archives, and launches platform-specific updaters
- **create_temp_archive()** - Platform-specific archive creation (ZIP for Windows, direct binary for Unix)
- **parse_version()** / **is_valid_version()** - Semantic version validation utilities

## Usage Example

```rust
// Initialize the update service with dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let update_message = OpenFrameClientUpdateMessage {
    version: "1.2.3".to_string(),
    download_configurations: vec![/* platform configs */],
};

match update_service.process_update(update_message).await {
    Ok(_) => info!("Update process initiated successfully"),
    Err(e) => error!("Update failed: {}", e),
}
```

The service includes race condition protection through mutex locking, comprehensive error handling with state cleanup, and platform-specific binary preparation for Windows (ZIP archives) and Unix systems (direct binaries).
