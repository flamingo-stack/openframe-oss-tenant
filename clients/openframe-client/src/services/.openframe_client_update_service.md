This service manages client software updates for the OpenFrame platform, handling the complete update lifecycle from version validation to launching the update process.

## Key Components

- **OpenFrameClientUpdateService** - Main service struct that orchestrates the update process
- **process_update()** - Public entry point with race condition protection using mutex locks
- **process_update_internal()** - Internal update logic with version validation and safety checks
- **execute_update()** - Handles downloading, extracting, and launching the actual update
- **create_temp_archive()** - Platform-specific methods for preparing update files (ZIP on Windows, direct binary on Unix)
- **parse_version()/is_valid_version()** - Version validation utilities supporting semver format

The service integrates with multiple components: client info tracking, GitHub downloads, update state management, and platform-specific updater launchers.

## Usage Example

```rust
use openframe_client_update_service::OpenFrameClientUpdateService;
use crate::models::openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize the service with required dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* download configs */],
};

// Execute the update (with built-in race condition protection)
match update_service.process_update(message).await {
    Ok(_) => println!("Update process started successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service provides comprehensive error handling, state tracking through multiple phases (downloading, extracting, preparing updater, launching), and automatic cleanup on failures.
