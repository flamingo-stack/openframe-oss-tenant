A service that orchestrates the OpenFrame client update process, managing the complete lifecycle from version validation to updater script execution with comprehensive error handling and race condition protection.

## Key Components

**OpenFrameClientUpdateService**
- Main service struct handling client updates with mutex-protected concurrency control
- Coordinates between client info, GitHub download, and update state services
- Implements platform-specific binary archive creation for updater compatibility

**Core Methods:**
- `process_update()` - Public entry point with race condition protection via mutex locking
- `process_update_internal()` - Version validation and update orchestration with rollback support
- `execute_update()` - Downloads, extracts, and launches the updater with comprehensive error cleanup
- `create_temp_archive()` - Platform-specific archive creation (ZIP for Windows, direct binary for Unix)
- `parse_version()` - Semver-compliant version parsing with 'v' prefix support
- `is_valid_version()` - Basic version format validation

**Update Flow:**
1. Acquire update lock to prevent concurrent operations
2. Validate requested version format using semver
3. Update client status and create tracking state
4. Download and extract binary from GitHub
5. Create platform-appropriate temporary archive
6. Launch updater script which stops the service

## Usage Example

```rust
use openframe_client_update_service::OpenFrameClientUpdateService;
use openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize service with dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process update request
let message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* platform configs */],
};

match update_service.process_update(message).await {
    Ok(_) => println!("Update process initiated successfully"),
    Err(e) => eprintln!("Update failed: {:#}", e),
}
```
