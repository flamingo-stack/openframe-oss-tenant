Service that manages OpenFrame client software updates with concurrent safety, version validation, and platform-specific binary handling. Coordinates download, extraction, and launcher processes while maintaining update state tracking.

## Key Components

- **`OpenFrameClientUpdateService`** - Main service struct with race condition protection via mutex
- **`process_update`** - Public entry point with concurrent update prevention
- **`process_update_internal`** - Core update logic with version validation and safety checks
- **`execute_update`** - Handles download, extraction, and updater launcher coordination
- **`create_temp_archive`** - Platform-specific binary preparation (ZIP on Windows, direct file on Unix)
- **Version utilities** - `parse_version` and `is_valid_version` for semver validation

## Usage Example

```rust
use openframe_client_update_service::OpenFrameClientUpdateService;

// Initialize service with dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process update request with version validation
let message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* platform configs */],
};

match update_service.process_update(message).await {
    Ok(_) => println!("Update launched successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}

// Concurrent requests are automatically rejected
let concurrent_result = update_service.process_update(another_message).await;
// Returns: Err("Update already in progress")
```

The service ensures only one update runs at a time, validates semver format, downloads platform-appropriate binaries from GitHub, and launches platform-specific updaters that replace the running executable.
