A comprehensive service for managing OpenFrame client updates with concurrent update protection and platform-specific binary handling. This service orchestrates the entire update process from version validation through binary deployment using external updater scripts.

## Key Components

- **OpenFrameClientUpdateService**: Main service struct with concurrent update protection via `Arc<Mutex<bool>>`
- **process_update**: Public entry point that handles update message processing with race condition prevention
- **execute_update**: Core update orchestration including download, extraction, and updater launching
- **create_temp_archive**: Platform-specific methods for preparing binary files (ZIP on Windows, direct binary on Unix)
- **Version validation utilities**: `parse_version` and `is_valid_version` for semver compliance checking

## Usage Example

```rust
use openframe_client_update_service::OpenFrameClientUpdateService;
use crate::models::openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize the service with required dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let update_message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* download configs */],
};

// This will validate the version, download the binary, and launch the updater
match update_service.process_update(update_message).await {
    Ok(()) => println!("Update process initiated successfully"),
    Err(e) => println!("Update failed: {}", e),
}
```

The service maintains update state throughout the process and automatically handles cleanup on failures. It supports concurrent request protection to prevent multiple simultaneous updates and provides platform-specific binary preparation for Windows (ZIP archives) and Unix systems (direct binaries).
