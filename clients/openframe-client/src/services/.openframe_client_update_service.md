Orchestrates OpenFrame client updates by managing the complete update lifecycle from version validation through binary deployment using GitHub downloads and platform-specific updaters.

## Key Components

- **`OpenFrameClientUpdateService`** - Main service struct that coordinates the entire update process
- **`process_update()`** - Public entry point that handles race condition protection and delegates to internal processing
- **`process_update_internal()`** - Core update logic with version validation and status tracking
- **`execute_update()`** - Executes the actual download, extraction, and updater launch sequence
- **`create_temp_archive()`** - Platform-specific binary preparation (ZIP on Windows, direct file on Unix)
- **Version utilities** - `parse_version()` and `is_valid_version()` for semver validation

## Usage Example

```rust
use openframe_client_update_service::OpenFrameClientUpdateService;
use crate::models::openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize the service with dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let update_message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* download configs */],
};

// This will handle the complete update lifecycle
match update_service.process_update(update_message).await {
    Ok(_) => println!("Update process initiated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service provides race condition protection through mutex locking, comprehensive error handling with status rollback, and platform-specific binary preparation for seamless client updates.
