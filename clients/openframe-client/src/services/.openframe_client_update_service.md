This service manages client updates for the OpenFrame platform, handling version validation, binary downloads, and coordinating the update process with proper race condition protection.

## Key Components

- **OpenFrameClientUpdateService** - Main service struct with dependency injection for client info, GitHub downloads, and update state management
- **update_in_progress** - Mutex-protected flag preventing concurrent updates
- **process_update()** - Public entry point that validates versions and manages update locks
- **execute_update()** - Core update logic handling download, extraction, and updater launch
- **create_temp_archive()** - Platform-specific binary packaging (ZIP on Windows, direct binary on Unix)
- **parse_version() / is_valid_version()** - Semver validation utilities

## Usage Example

```rust
// Initialize the service with dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* configs */],
};

match update_service.process_update(message).await {
    Ok(()) => println!("Update process initiated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service follows a multi-phase update process: version validation → downloading → extracting → preparing updater → launching platform-specific update script. It includes comprehensive error handling and cleanup, with update state tracking throughout the process. The updater ultimately stops the service to complete the installation.
