A comprehensive service for handling OpenFrame client updates with robust error handling, race condition protection, and platform-specific update procedures. It orchestrates the entire update process from version validation to binary deployment.

## Key Components

- **OpenFrameClientUpdateService** - Main service struct that coordinates client updates
- **process_update()** - Public entry point with mutex-based race condition protection
- **process_update_internal()** - Internal update logic with version validation and status tracking
- **execute_update()** - Core update execution including download, extraction, and updater launching
- **create_temp_archive()** - Platform-specific methods for preparing update archives (ZIP for Windows, direct binary for Unix)
- **parse_version()** / **is_valid_version()** - Version validation utilities supporting semver format

## Usage Example

```rust
use openframe_client_update_service::OpenFrameClientUpdateService;
use crate::models::openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize the service with dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let update_message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* configs */],
};

match update_service.process_update(update_message).await {
    Ok(()) => println!("Update initiated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service ensures only one update runs at a time, validates version formats, tracks update progress through multiple phases, and handles platform-specific binary deployment. On successful updater launch, the service will be stopped and restarted with the new version.
