A comprehensive service that handles OpenFrame client update operations with safety mechanisms including race condition protection, version validation, and complete rollback capabilities.

## Key Components

- **OpenFrameClientUpdateService**: Main service struct with dependency injection for client info, GitHub downloads, and update state management
- **process_update()**: Public entry point that validates requests and prevents concurrent updates using a mutex lock
- **execute_update()**: Internal method that orchestrates the complete update workflow
- **create_temp_archive()**: Platform-specific binary preparation (ZIP for Windows, direct binary for Unix)
- **Version validation utilities**: `parse_version()` and `is_valid_version()` for semver compliance

## Usage Example

```rust
use crate::services::openframe_client_update_service::OpenFrameClientUpdateService;
use crate::models::openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize service with dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* platform configs */],
};

// Service automatically handles version validation, download, extraction, 
// and updater launch with complete error recovery
match update_service.process_update(message).await {
    Ok(()) => println!("Update process initiated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service implements a robust update pipeline: validates version format → downloads platform-specific binary → creates temporary archive → launches platform updater → handles cleanup on failure. Race condition protection ensures only one update can run at a time.
