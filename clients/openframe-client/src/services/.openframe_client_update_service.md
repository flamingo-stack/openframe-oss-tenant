Orchestrates OpenFrame client updates by coordinating downloads, version validation, and platform-specific update execution with comprehensive error handling and race condition protection.

## Key Components

- **OpenFrameClientUpdateService**: Main service struct managing update workflow
- **process_update()**: Public entry point with mutex-based race condition protection
- **process_update_internal()**: Core update logic with version validation
- **execute_update()**: Handles download, extraction, and updater launching
- **create_temp_archive()**: Platform-specific binary preparation (Windows ZIP vs Unix direct)
- **parse_version()** / **is_valid_version()**: Semver-compliant version validation utilities

## Usage Example

```rust
use openframe_client_update_service::OpenFrameClientUpdateService;
use openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize service with dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let update_message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* platform configs */],
};

// Process update (mutex prevents concurrent updates)
match update_service.process_update(update_message).await {
    Ok(()) => println!("Update launched successfully"),
    Err(e) => println!("Update failed: {}", e),
}
```

The service maintains update state throughout the process, handles platform-specific binary packaging, and ensures only one update can run at a time through async mutex protection.
