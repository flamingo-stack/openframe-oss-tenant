Orchestrates client application updates for the OpenFrame platform by downloading, validating, and launching update processes through a series of managed phases.

## Key Components

- **OpenFrameClientUpdateService** - Main service that coordinates the entire update process
- **process_update()** - Entry point that handles update requests with race condition protection
- **execute_update()** - Core update logic including download, extraction, and updater launch
- **create_temp_archive()** - Platform-specific archive creation (ZIP on Windows, direct binary on Unix)
- **parse_version()** / **is_valid_version()** - Version validation and parsing utilities

## Usage Example

```rust
use crate::services::openframe_client_update_service::OpenFrameClientUpdateService;
use crate::models::openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize the service
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let update_message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* config data */],
};

// This will download, validate, and launch the updater
update_service.process_update(update_message).await?;
```

The service manages update state transitions (Downloading → Extracting → PreparingUpdater → UpdaterLaunched), prevents concurrent updates with mutex locking, and handles platform-specific differences in binary packaging. After launching the updater, the current service instance will be stopped and replaced with the new version.
