This service orchestrates self-updating functionality for the OpenFrame client, handling version validation, binary downloads, and platform-specific update execution with comprehensive safety checks and race condition protection.

## Key Components

- **OpenFrameClientUpdateService** - Main service class with thread-safe update coordination
- **process_update()** - Public entry point with mutex-based concurrency control
- **process_update_internal()** - Core update logic with version validation
- **execute_update()** - Handles download, extraction, and updater launch phases
- **create_temp_archive()** - Platform-specific binary preparation (ZIP for Windows, direct binary for Unix)
- **parse_version()/is_valid_version()** - Semver validation utilities

## Usage Example

```rust
use openframe_client_update_service::OpenFrameClientUpdateService;
use openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize service with dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process update request
let message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* platform configs */],
};

match update_service.process_update(message).await {
    Ok(_) => println!("Update launched successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service ensures only one update runs at a time, validates semver formats, tracks update phases through state management, and handles platform-specific binary preparation before launching external updater scripts that replace the running executable.
