Orchestrates the OpenFrame client update process with race condition protection and platform-specific update handling. Manages the complete update lifecycle from version validation through download, extraction, and updater launch.

## Key Components

- **`OpenFrameClientUpdateService`** - Main service struct with mutex-protected update process
- **`process_update()`** - Public entry point with race condition protection using async mutex
- **`process_update_internal()`** - Core update logic with version validation and status tracking
- **`execute_update()`** - Handles download, extraction, and updater launch phases
- **`create_temp_archive()`** - Platform-specific binary preparation (ZIP for Windows, direct file for Unix)
- **Version validation utilities** - `parse_version()` and `is_valid_version()` for semver compliance

## Usage Example

```rust
use openframe_client_update_service::OpenFrameClientUpdateService;
use openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize service with dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process update request
let update_message = OpenFrameClientUpdateMessage {
    version: "1.2.3".to_string(),
    download_configurations: vec![/* download configs */],
};

match update_service.process_update(update_message).await {
    Ok(()) => println!("Update process launched successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service ensures only one update can run at a time, validates version formats using semver, tracks update progress through multiple phases (downloading, extracting, preparing updater), and handles platform-specific binary packaging before launching the external updater process.
