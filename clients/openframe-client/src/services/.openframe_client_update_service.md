A service that manages the OpenFrame client update process, handling version validation, binary downloads, and safe update execution with race condition protection.

## Key Components

- **OpenFrameClientUpdateService** - Main update orchestration service
- **process_update()** - Entry point with concurrent update protection
- **process_update_internal()** - Core update logic with validation
- **execute_update()** - Handles download, extraction, and updater launch
- **create_temp_archive()** - Platform-specific binary preparation (ZIP on Windows, direct binary on Unix)
- **parse_version()** - Semantic version parsing with 'v' prefix support
- **is_valid_version()** - Basic version format validation

## Usage Example

```rust
use crate::services::openframe_client_update_service::OpenFrameClientUpdateService;
use crate::models::openframe_client_update_message::OpenFrameClientUpdateMessage;

// Create the update service
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let update_message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![download_config],
};

// This will validate version, download binary, and launch updater
match update_service.process_update(update_message).await {
    Ok(_) => println!("Update process initiated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service includes comprehensive error handling, state tracking through update phases (Downloading, Extracting, PreparingUpdater, UpdaterLaunched), and automatic cleanup on failures. It uses a mutex to prevent concurrent updates and supports both semantic versioning with optional 'v' prefixes.
