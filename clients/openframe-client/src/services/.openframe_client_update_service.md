A comprehensive service for managing OpenFrame client updates with version validation, download orchestration, and platform-specific binary installation. This service handles the complete update lifecycle from version verification to launching platform-specific updater scripts.

## Key Components

- **OpenFrameClientUpdateService**: Main service struct that orchestrates the update process
- **process_update()**: Entry point that validates requests and prevents concurrent updates
- **execute_update()**: Core update logic handling download, extraction, and updater launch
- **create_temp_archive()**: Platform-specific methods for preparing update binaries
- **Version utilities**: Functions for validating and parsing semantic versions

## Usage Example

```rust
use crate::services::{
    OpenFrameClientUpdateService,
    OpenFrameClientInfoService,
    GithubDownloadService,
    UpdateStateService
};
use crate::models::openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize the update service
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* download configs */],
};

match update_service.process_update(message).await {
    Ok(()) => println!("Update launched successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service includes robust error handling, concurrent update prevention via mutex locks, and platform-specific binary preparation for Windows (ZIP archives) and Unix systems (direct binary files).
