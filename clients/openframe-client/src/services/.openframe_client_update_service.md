This service manages OpenFrame client software updates by downloading new versions from GitHub, validating them, and orchestrating the update process across different operating systems.

## Key Components

- **OpenFrameClientUpdateService** - Main service that coordinates the entire update workflow
- **process_update()** - Entry point that validates update requests and prevents concurrent updates
- **execute_update()** - Core logic for downloading, extracting, and launching the updater
- **create_temp_archive()** - Platform-specific methods for preparing update binaries (ZIP on Windows, direct file on Unix)
- **Version validation** - Semantic version parsing and format validation with support for prefixes like "v1.2.3"

## Usage Example

```rust
use openframe_client_update_service::OpenFrameClientUpdateService;
use openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize the service with required dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* OS-specific configs */],
};

match update_service.process_update(message).await {
    Ok(_) => println!("Update process started successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service includes comprehensive error handling, race condition protection via mutex locks, and proper cleanup of temporary files. It tracks update progress through different phases and integrates with platform-specific updater launchers to complete the installation process.
