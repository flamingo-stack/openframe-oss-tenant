A service that handles client updates for the OpenFrame platform, orchestrating the complete update workflow from version validation to updater script execution.

## Key Components

- **OpenFrameClientUpdateService**: Main service struct with concurrency protection via mutex
- **process_update()**: Public entry point that validates requests and prevents concurrent updates
- **execute_update()**: Core update orchestration including download, extraction, and updater launch
- **create_temp_archive()**: Platform-specific binary preparation (ZIP on Windows, direct file on Unix)
- **parse_version()/is_valid_version()**: Semantic version validation utilities

## Dependencies

Integrates with multiple services:
- `OpenFrameClientInfoService`: Client status management
- `GithubDownloadService`: Binary download and extraction
- `UpdateStateService`: Update progress tracking
- `updater_launcher`: Platform-specific update execution

## Usage Example

```rust
use openframe_client_update_service::OpenFrameClientUpdateService;

// Initialize service with dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process update message from NATS
let message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* ... */],
};

// Execute update with race condition protection
match update_service.process_update(message).await {
    Ok(_) => println!("Update process initiated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service provides robust error handling, state tracking through all update phases, and automatic cleanup on failures. Updates are protected against concurrent execution and include comprehensive logging for debugging purposes.
