This service orchestrates OpenFrame client updates by downloading, validating, and launching update processes with comprehensive error handling and state tracking.

## Key Components

- **`OpenFrameClientUpdateService`** - Main service struct that coordinates the update process
- **`process_update()`** - Entry point that handles update requests with race condition protection
- **`execute_update()`** - Core update logic that downloads, extracts, and launches the updater
- **`create_temp_archive()`** - Platform-specific archive creation (ZIP for Windows, binary for Unix)
- **Version validation methods** - `parse_version()` and `is_valid_version()` for semver compliance

## Usage Example

```rust
use openframe_client_update_service::OpenFrameClientUpdateService;
use crate::models::openframe_client_update_message::OpenFrameClientUpdateMessage;

// Initialize the service with required dependencies
let update_service = OpenFrameClientUpdateService::new(
    client_info_service,
    github_download_service,
    update_state_service,
);

// Process an update request
let update_message = OpenFrameClientUpdateMessage {
    version: "v1.2.3".to_string(),
    download_configurations: vec![/* platform configs */],
};

// This will validate version, download binary, and launch updater
match update_service.process_update(update_message).await {
    Ok(()) => println!("Update process started successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service uses mutex-based locking to prevent concurrent updates, validates semver versions, tracks update state through different phases (downloading, extracting, preparing), and handles platform-specific binary packaging before launching the system updater.
