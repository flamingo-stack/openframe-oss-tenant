Thin wrapper around `NatsConnectionManager` that serializes a typed payload to JSON and publishes it to a NATS subject.

## Key Components

- **`NatsMessagePublisher`** — Cloneable struct holding a reference to the shared `NatsConnectionManager`.
- **`new(nats_connection_manager)`** — Constructor that injects the connection manager dependency.
- **`publish<T: Serialize>(subject, payload)`** — Async method that serializes `payload` to JSON, retrieves the NATS client, publishes to `subject`, and flushes the connection to guarantee delivery.

## Usage Example

```rust
let manager = NatsConnectionManager::new(nats_url).await?;
let publisher = NatsMessagePublisher::new(manager);

#[derive(Serialize)]
struct AlertEvent {
    device_id: String,
    message: String,
}

publisher.publish("alerts.critical", AlertEvent {
    device_id: "device-42".to_string(),
    message: "Disk usage above 90%".to_string(),
}).await?;
```

## Notes

- The `flush()` call after `publish()` ensures the message is fully written to the NATS server before returning — important for fire-and-forget scenarios where the caller does not hold the connection open.
- Errors from serialization, publishing, and flushing are all propagated via `anyhow::Result` with descriptive context strings for easy debugging.
