A thin publishing wrapper around `NatsConnectionManager` that serializes and dispatches messages to NATS subjects, with support for both typed (JSON) and raw byte payloads.

## Key Components

| Item | Description |
|------|-------------|
| `NatsMessagePublisher` | Cloneable struct holding a `NatsConnectionManager` reference |
| `publish<T: Serialize>` | Serializes a typed payload to JSON, then publishes to a NATS subject |
| `publish_raw` | Publishes a raw `&[u8]` payload directly to a NATS subject |
| `ResultPublisher` impl | Implements the `result_store::ResultPublisher` trait, bridging the async raw-publish method for trait consumers |

Both publish methods call `flush()` after each send to ensure delivery before returning.

## Usage Example

```rust
// Inject via constructor
let publisher = NatsMessagePublisher::new(nats_connection_manager);

// Publish a typed, serializable struct
#[derive(Serialize)]
struct JobResult { id: String, status: String }

publisher
    .publish("jobs.results", JobResult {
        id: "abc-123".into(),
        status: "completed".into(),
    })
    .await?;

// Publish raw bytes (e.g. pre-encoded protobuf or forwarded payload)
let raw: &[u8] = b"raw-payload-bytes";
publisher.publish_raw("jobs.raw", raw).await?;
```

## Notes

- Errors are wrapped with contextual messages via `anyhow::Context`, making failure points easy to trace (`"Failed to serialize payload"`, `"Failed to publish message to NATS"`, `"Failed to flush NATS publish"`).
- The `ResultPublisher` trait impl returns an `impl Future + Send`, making it compatible with multi-threaded async runtimes such as Tokio.
