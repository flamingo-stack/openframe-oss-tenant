Thin wrapper around a NATS client that serializes a typed payload to JSON and publishes it to a given subject.

## Key Components

- **`NatsMessagePublisher`** — Cloneable struct that holds a `NatsConnectionManager` and exposes a single async publish method.
- **`new(nats_connection_manager)`** — Constructor that injects the connection manager dependency.
- **`publish<T: Serialize>(subject, payload)`** — Serializes `payload` to JSON, acquires a NATS client from the connection manager, publishes to `subject`, and flushes the connection to guarantee delivery.

## Usage Example

```rust
let manager = NatsConnectionManager::new(/* config */).await?;
let publisher = NatsMessagePublisher::new(manager);

#[derive(Serialize)]
struct AlertEvent {
    device_id: String,
    message: String,
}

publisher.publish("alerts.devices", AlertEvent {
    device_id: "dev-42".into(),
    message: "Disk usage above 90%".into(),
}).await?;
```

## Notes

- The flush call after `publish` ensures the message is fully transmitted before returning — important in short-lived tasks or shutdown paths.
- Errors from serialization, connection acquisition, publish, and flush are all propagated via `anyhow::Result` with descriptive context strings.
- `NatsMessagePublisher` is `Clone`, making it cheap to share across services or task spawns that each need publishing capability.
