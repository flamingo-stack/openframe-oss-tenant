Wraps a `NatsConnectionManager` to provide a simple, typed interface for serializing and publishing messages to NATS subjects.

## Key Components

- **`NatsMessagePublisher`** — Cloneable struct that holds a `NatsConnectionManager` instance and exposes a single publish method.
- **`new(nats_connection_manager)`** — Constructor that injects the connection manager dependency.
- **`publish<T: Serialize>(subject, payload)`** — Generic async method that serializes any `Serialize`-compatible payload to JSON and publishes it to the given NATS subject, flushing the connection afterward.

## Usage Example

```rust
use crate::services::nats_connection_manager::NatsConnectionManager;
use crate::services::nats_message_publisher::NatsMessagePublisher;
use serde::Serialize;

#[derive(Serialize)]
struct AlertEvent {
    device_id: String,
    message: String,
}

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let manager = NatsConnectionManager::new("nats://localhost:4222").await?;
    let publisher = NatsMessagePublisher::new(manager);

    let event = AlertEvent {
        device_id: "srv-01".to_string(),
        message: "Disk usage above 90%".to_string(),
    };

    publisher.publish("alerts.devices", event).await?;
    Ok(())
}
```

> **Note:** `publish` acquires a NATS client via the connection manager on each call and calls `flush()` to ensure delivery before returning. Errors from serialization, connection retrieval, publishing, or flushing are all surfaced as `anyhow::Error` with descriptive context messages.
