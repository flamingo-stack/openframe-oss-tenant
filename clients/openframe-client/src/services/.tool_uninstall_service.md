Handles the complete lifecycle of uninstalling managed tools, including process termination, command execution, file cleanup, and registry record removal.

## Key Components

### `UninstallOutcome` (enum)
Return value indicating whether a tool was `Removed` or `NotInstalled`.

### `ToolUninstallService` (struct)
Core service orchestrating the uninstall pipeline. Composes:
- `InstalledToolsService` — reads/deletes registry records
- `ToolCommandParamsResolver` — resolves placeholder variables in uninstall command args
- `ToolKillService` — stops running processes before removal
- `DirectoryManager` — resolves tool executable and data paths

### Public Methods
| Method | Description |
|---|---|
| `uninstall_by_tool_agent_id` | Uninstalls a single tool by ID; removes its directory and registry entry |
| `uninstall_all` | Iterates all registered tools and uninstalls each, logging failures without aborting |

### Private Helpers
- `uninstall_tool` — core uninstall pipeline: stop process → run uninstall command → cleanup
- `stop_tool_process` — delegates to `ToolKillService`
- `cleanup_tool_processes` — kills residual detached processes by executable path
- `cleanup_gui_app_bundle` — macOS-only: removes `.app` bundles via `remove_app_bundle`
- `cleanup_gui_app_autorun` — Windows-only: removes autorun registry entries

## Usage Example

```rust
let svc = ToolUninstallService::new(
    installed_tools_service,
    command_params_resolver,
    tool_kill_service,
    directory_manager,
);

// Uninstall a specific tool
match svc.uninstall_by_tool_agent_id("fleet-agent").await? {
    UninstallOutcome::Removed     => println!("Tool removed"),
    UninstallOutcome::NotInstalled => println!("Tool was not installed"),
}

// Uninstall everything (e.g., on tenant offboarding)
svc.uninstall_all().await?;
```

> **Platform notes:** Fleet tools trigger an additional `osqueryd` kill step. GUI app cleanup is gated at compile time — `.app` bundle removal runs on macOS only; autorun deregistration runs on Windows only.
