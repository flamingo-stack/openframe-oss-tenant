Handles the complete uninstallation lifecycle for managed tools, including process termination, command execution, and platform-specific cleanup of GUI app bundles and autorun entries.

## Key Components

### `ToolUninstallService`

Primary struct owning four injected dependencies:

| Field | Purpose |
|---|---|
| `installed_tools_service` | Retrieves the list of currently installed tools |
| `command_params_resolver` | Resolves placeholder tokens in uninstall command args |
| `tool_kill_service` | Stops running tool processes by ID or executable path |
| `directory_manager` | Resolves absolute paths to tool executables |

### Public Methods

- **`new(...)`** — Constructor accepting all four service dependencies
- **`uninstall_all()`** — Iterates all installed tools and calls `uninstall_tool` for each; logs and continues on per-tool failures

### Private Methods

| Method | Behaviour |
|---|---|
| `uninstall_tool` | Full uninstall sequence: stop → run command → cleanup; fails fast on any error |
| `stop_tool_process` | Delegates to `ToolKillService::stop_installed_tool` |
| `cleanup_tool_processes` | Kills any remaining processes by executable path after uninstall |
| `cleanup_gui_app_bundle` | macOS-only: removes `.app` bundles via `remove_app_bundle` |
| `cleanup_gui_app_autorun` | Windows-only: removes autorun registry entries via `unregister_autorun` |

## Usage Example

```rust
let service = ToolUninstallService::new(
    installed_tools_service,
    command_params_resolver,
    tool_kill_service,
    directory_manager,
);

// Uninstall all registered tools
service.uninstall_all().await?;

// Or uninstall a single tool directly (private — called internally)
// service.uninstall_tool(&tool).await?;
```

> **Note:** Fleet-managed tools receive special handling — `osqueryd` is explicitly stopped before the main uninstall command runs, working around the lack of a Fleet-side stop mechanism.
