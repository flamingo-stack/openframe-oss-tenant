Handles the complete lifecycle of tool uninstallation — stopping processes, executing uninstall commands, and cleaning up platform-specific artifacts (app bundles, autorun entries).

## Key Components

**`ToolUninstallService`** — Main service struct with four dependencies:
- `InstalledToolsService` — retrieves the list of installed tools
- `ToolCommandParamsResolver` — resolves/replaces placeholders in uninstall command args
- `ToolKillService` — stops running tool processes before removal
- `DirectoryManager` — resolves tool executable paths on disk

**Public Methods**
- `new(...)` — Constructor injecting all required services
- `uninstall_all()` — Iterates all installed tools and uninstalls each; logs warnings on per-tool failures without aborting the loop

**Private Methods**
- `uninstall_tool(tool)` — Orchestrates the full uninstall sequence for one tool: stop → kill osqueryd (Fleet-specific) → resolve args → execute uninstall command → cleanup
- `stop_tool_process(tool)` — Delegates to `ToolKillService`
- `cleanup_tool_processes(tool)` — Kills any detached processes lingering after the uninstall command
- `cleanup_gui_app_bundle(tool)` — macOS-only: removes `.app` bundle via `remove_app_bundle`
- `cleanup_gui_app_autorun(tool)` — Windows-only: removes tool from autorun registry via `unregister_autorun`

## Usage Example

```rust
let uninstall_service = ToolUninstallService::new(
    installed_tools_service,
    command_params_resolver,
    tool_kill_service,
    directory_manager,
);

// Uninstall all tools (e.g., during agent teardown)
uninstall_service.uninstall_all().await?;
```

> **Note:** `uninstall_tool` fails fast — if stopping the process or executing the uninstall command returns a non-zero exit code, the error propagates immediately. `uninstall_all` is more lenient: it logs a warning and continues to the next tool on failure.
