Provides device metadata resolution for the OpenFrame agent, including hostname discovery, OS type detection, and agent version retrieval.

## Key Components

### `DeviceDataFetcher` (struct)

A cloneable, stateless struct exposing methods to collect device-level metadata.

| Method | Returns | Description |
|---|---|---|
| `new()` | `Self` | Constructs a new instance |
| `get_hostname()` | `Option<String>` | Resolves the device hostname with fallback chain |
| `get_agent_version()` | `Option<String>` | Returns the compile-time `OPENFRAME_VERSION` env value |
| `get_os_type()` | `String` | Returns `"WINDOWS"` or `"MAC_OS"` based on compile target |

### Hostname Resolution Strategy

`get_hostname()` follows a prioritized fallback chain:

1. **Kernel hostname** via the `hostname` crate
2. *(macOS only)* **`scutil --get LocalHostName`** — appends `.local` suffix
3. *(macOS only)* **`scutil --get ComputerName`**
4. Returns `None` if all sources fail

Each candidate is validated by `is_valid_hostname()`, which rejects empty strings, raw IP addresses, and generic names (`localhost`, `localhost.localdomain`).

## Usage Example

```rust
use device_data_fetcher::DeviceDataFetcher;

let fetcher = DeviceDataFetcher::new();

if let Some(hostname) = fetcher.get_hostname() {
    println!("Device hostname: {}", hostname);
}

if let Some(version) = fetcher.get_agent_version() {
    println!("Agent version: {}", version);
}

println!("OS type: {}", fetcher.get_os_type());
```

> **Note:** `get_agent_version()` reads the `OPENFRAME_VERSION` environment variable at **compile time** via `env!()`. Ensure this variable is set in your build environment or `build.rs`.
