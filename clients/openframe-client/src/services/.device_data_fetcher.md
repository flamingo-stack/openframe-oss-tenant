Provides utilities for fetching basic device metadata used by the OpenFrame agent during device registration and health reporting.

## Key Components

**`DeviceDataFetcher`** — A cloneable, stateless struct with the following methods:

| Method | Returns | Description |
|--------|---------|-------------|
| `new()` | `Self` | Constructs a new instance |
| `get_hostname()` | `Option<String>` | Resolves the system hostname via the `hostname` crate |
| `get_agent_version()` | `Option<String>` | Reads the agent version from the `OPENFRAME_VERSION` env var at compile time |
| `get_os_type()` | `String` | Returns `"WINDOWS"` or `"MAC_OS"` based on compile-time target OS |

## Usage Example

```rust
use crate::device_data_fetcher::DeviceDataFetcher;

let fetcher = DeviceDataFetcher::new();

if let Some(hostname) = fetcher.get_hostname() {
    println!("Device hostname: {}", hostname);
}

if let Some(version) = fetcher.get_agent_version() {
    println!("Agent version: {}", version);
}

let os = fetcher.get_os_type();
println!("OS type: {}", os); // "WINDOWS" or "MAC_OS"
```

## Notes

- `get_hostname()` returns `None` and emits a `warn!` log on failure — callers should handle the missing case gracefully.
- `get_agent_version()` depends on `OPENFRAME_VERSION` being set at build time; a missing env var will cause a **compile-time** panic.
- OS detection is compile-time only — Linux targets fall through to `"MAC_OS"`, which may need updating if Linux support is added.
