Provides utilities for fetching basic device metadata used during agent registration and telemetry reporting.

## Key Components

- **`DeviceDataFetcher`** — A cloneable, stateless struct exposing methods to retrieve local device information.

| Method | Return | Description |
|---|---|---|
| `new()` | `Self` | Constructs a new instance |
| `get_hostname()` | `Option<String>` | Resolves the machine's hostname via the `hostname` crate |
| `get_agent_version()` | `Option<String>` | Returns the agent version from the `OPENFRAME_VERSION` compile-time env var |
| `get_os_type()` | `String` | Returns `"WINDOWS"` or `"MAC_OS"` based on compile target |

## Usage Example

```rust
let fetcher = DeviceDataFetcher::new();

if let Some(hostname) = fetcher.get_hostname() {
    println!("Host: {}", hostname);
}

if let Some(version) = fetcher.get_agent_version() {
    println!("Agent version: {}", version);
}

let os = fetcher.get_os_type();
println!("OS type: {}", os); // "WINDOWS" or "MAC_OS"
```

## Notes

- `get_hostname()` logs a warning and returns `None` if resolution fails.
- `get_agent_version()` reads `OPENFRAME_VERSION` at **compile time** — the variable must be set during the build.
- OS detection is compile-time only; Linux targets currently fall through to `"MAC_OS"`.
- The unused `TcpStream` import suggests network-based device probing may be planned but is not yet implemented.
