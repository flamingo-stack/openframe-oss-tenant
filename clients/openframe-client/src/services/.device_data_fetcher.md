Provides system-level device metadata for the OpenFrame agent, including hostname resolution, agent version retrieval, and OS type detection.

## Key Components

- **`DeviceDataFetcher`** — A cloneable, stateless struct that exposes device introspection methods.

| Method | Return | Description |
|---|---|---|
| `new()` | `Self` | Constructs a new `DeviceDataFetcher` instance |
| `get_hostname()` | `Option<String>` | Resolves the machine's hostname via the `hostname` crate |
| `get_agent_version()` | `Option<String>` | Returns the agent version from the `OPENFRAME_VERSION` env var, baked in at compile time |
| `get_os_type()` | `String` | Returns `"WINDOWS"` or `"MAC_OS"` based on compile-time target OS |

## Usage Example

```rust
let fetcher = DeviceDataFetcher::new();

if let Some(hostname) = fetcher.get_hostname() {
    println!("Device hostname: {}", hostname);
}

if let Some(version) = fetcher.get_agent_version() {
    println!("Running agent version: {}", version);
}

let os = fetcher.get_os_type();
println!("OS type: {}", os); // "WINDOWS" or "MAC_OS"
```

## Notes

- `get_os_type()` uses `cfg!` macros, meaning the OS branch is resolved at **compile time**, not runtime.
- `OPENFRAME_VERSION` must be set in the build environment; absence will cause a **compile-time panic** via `env!`.
- `get_hostname()` returns `None` on failure and emits a `warn!` log rather than propagating the error.
