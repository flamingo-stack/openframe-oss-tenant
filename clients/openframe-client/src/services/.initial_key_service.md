Handles background fetching and persistence of the initial registration key for legacy agent upgrades where the key is absent from local configuration.

## Key Components

### `InitialKeyService`

The primary struct managing key retrieval. Holds references to an HTTP client, gateway base URL, configuration services, and a shared deactivation handle.

| Field | Type | Purpose |
|---|---|---|
| `http_client` | `Client` | Executes HTTP requests to the gateway |
| `base_url` | `String` | Gateway root URL |
| `initial_config_service` | `InitialConfigurationService` | Reads/writes local config for the initial key |
| `agent_config_service` | `AgentConfigurationService` | Provides the Bearer token for authenticated requests |
| `deactivation` | `Arc<DeactivationService>` | Guards against hammering the gateway when the tenant is suspended |

### Key Methods

- **`new(...) -> Self`** — Constructor; wires all dependencies.
- **`ensure_initial_key(self: Arc<Self>)`** — Entry point. No-ops if the key is already present; otherwise spawns a background retry loop that polls every 60 seconds (`RETRY_INTERVAL_SECS`).
- **`is_key_missing(&self) -> bool`** — Delegates to `InitialConfigurationService` to check key presence.
- **`fetch_registration_secret(&self) -> Result<String>`** — Authenticated GET to `/clients/agent/registration-secret/active`; deserializes the `key` field from the JSON response.

## Usage Example

```rust
let svc = Arc::new(InitialKeyService::new(
    http_client,
    "https://gateway.example.com".to_string(),
    initial_config_service,
    agent_config_service,
    Arc::clone(&deactivation_service),
));

// Call at agent startup; exits immediately if key exists,
// otherwise spawns a background fetch loop.
svc.ensure_initial_key().await;
```

> **Retry behavior:** The background loop sleeps 60 s between attempts and skips fetch calls entirely while `DeactivationService::is_suspended()` returns `true`, deferring recovery to the backoff probe.
