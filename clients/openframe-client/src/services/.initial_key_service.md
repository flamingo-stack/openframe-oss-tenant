Handles background fetching and persistence of the initial registration key for legacy agent upgrades where the key is absent from local configuration.

## Key Components

- **`InitialKeyService`** — Main service struct holding an HTTP client, base URL, and references to `InitialConfigurationService` and `AgentConfigurationService`
- **`ensure_initial_key`** — Public async entry point; no-ops if the key already exists, otherwise spawns a background retry loop
- **`fetch_registration_secret`** — Authenticates via bearer token and calls `GET /clients/agent/registration-secret/active` to retrieve the key
- **`is_key_missing`** — Delegates to `InitialConfigurationService` to check whether the key needs to be fetched
- **`RegistrationSecretResponse`** — Internal deserialization struct for the API response payload
- **`RETRY_INTERVAL_SECS`** — Constant (60s) controlling the delay between failed fetch attempts

## Usage Example

```rust
use std::sync::Arc;

let service = Arc::new(InitialKeyService::new(
    http_client,
    "https://api.flamingo.run".to_string(),
    initial_config_service,
    agent_config_service,
));

// Call once at agent startup; exits immediately if key exists,
// otherwise retries in the background every 60s until successful.
service.ensure_initial_key().await;
```

> **Note:** `ensure_initial_key` must be called with an `Arc<Self>` because it moves the reference into a `tokio::spawn` background task.
