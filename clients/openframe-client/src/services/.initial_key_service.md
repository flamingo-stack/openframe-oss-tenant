Handles background fetching and persistent storage of the agent's initial registration key, supporting legacy upgrade scenarios where the key may be absent from local configuration.

## Key Components

- **`InitialKeyService`** — Main struct managing the key retrieval lifecycle; holds an HTTP client, base URL, and references to both config services.
- **`ensure_initial_key(self: Arc<Self>)`** — Entry point that no-ops if the key already exists; otherwise spawns a background task that retries indefinitely until the key is successfully fetched and persisted.
- **`fetch_registration_secret()`** — Authenticated GET request to `/clients/agent/registration-secret/active`, returning the active registration key string.
- **`is_key_missing()`** — Delegates to `InitialConfigurationService` to check for a missing key, defaulting to `false` on error.
- **`RegistrationSecretResponse`** — Private deserializer struct for the API response payload.
- **`RETRY_INTERVAL_SECS`** — Constant (60s) controlling the backoff delay between failed fetch attempts.

## Usage Example

```rust
let service = Arc::new(InitialKeyService::new(
    reqwest::Client::new(),
    "https://api.example.com".to_string(),
    initial_config_service,
    agent_config_service,
));

// Call at startup; no-ops if key already present,
// otherwise spawns a retry loop in the background.
service.ensure_initial_key().await;
```

## Notes

- The retry loop runs forever until success — callers should invoke this once at agent startup and let it self-terminate.
- Errors during save are logged but do **not** re-trigger a retry; the loop exits after any successful fetch regardless of persistence outcome.
