This service handles downloading and extracting GitHub releases with robust error handling and platform-specific archive support. It provides retry logic with CDN fallback for rate-limited GitHub requests and supports both ZIP and tar.gz extraction.

## Key Components

- **`GithubDownloadService`** - Main service struct with HTTP client for GitHub downloads
- **`download_and_extract()`** - Core method that downloads archives and extracts target binaries
- **`download_with_retry()`** - Implements retry logic with jsDelivr CDN fallback on rate limits
- **`extract_from_zip()`** - Windows-specific ZIP archive extraction
- **`extract_from_tar_gz()`** - Unix-specific tar.gz archive extraction
- **`github_to_cdn_url()`** - Converts GitHub URLs to jsDelivr CDN URLs
- **`find_config_for_current_os()`** - Selects appropriate download config for current platform

## Usage Example

```rust
use reqwest::Client;
use crate::models::download_configuration::DownloadConfiguration;

// Create service with HTTP client
let client = Client::new();
let service = GithubDownloadService::new(client);

// Download and extract binary from GitHub release
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/app.tar.gz".to_string(),
    file_name: "app.tar.gz".to_string(),
    target_file_name: "app".to_string(),
    os: "linux".to_string(),
    arch: "x86_64".to_string(),
};

// Extract binary bytes
let binary_bytes = service.download_and_extract(&config).await?;

// Or download and save directly to filesystem
let tool_path = Path::new("/usr/local/bin");
let default_path = Path::new("/usr/local/bin/app");
service.download_and_save(&config, tool_path, default_path).await?;
```

The service automatically handles rate limiting by falling back to jsDelivr CDN, validates file sizes, and sets proper executable permissions on Unix systems.
