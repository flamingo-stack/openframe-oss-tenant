This service handles downloading and extracting agent binaries from GitHub releases with built-in retry logic and CDN fallback. It supports both ZIP and tar.gz archives with platform-specific extraction capabilities.

## Key Components

- **`GithubDownloadService`** - Main service for downloading and extracting binaries
- **`download_and_extract()`** - Downloads archive and extracts target binary
- **`download_with_retry()`** - Implements retry logic with jsDelivr CDN fallback on rate limits
- **`extract_from_zip()`** - Windows-specific ZIP extraction
- **`extract_from_tar_gz()`** - Unix-specific tar.gz extraction
- **`github_to_cdn_url()`** - Converts GitHub URLs to jsDelivr CDN URLs
- **`find_config_for_current_os()`** - Selects appropriate download configuration for the current platform

## Usage Example

```rust
use reqwest::Client;
use crate::models::download_configuration::DownloadConfiguration;

let http_client = Client::new();
let service = GithubDownloadService::new(http_client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/tool.zip".to_string(),
    file_name: "tool.zip".to_string(),
    target_file_name: "tool.exe".to_string(),
    // ... other config fields
};

let binary_bytes = service.download_and_extract(&config).await?;

// Or find config for current OS and download
let configs = vec![/* multiple platform configs */];
let current_config = service.find_config_for_current_os(&configs)?;
let executable_path = service.download_and_save(
    current_config,
    &tool_folder,
    &default_path
).await?;
```

The service automatically handles platform differences, rate limiting, timeouts, and file validation to ensure reliable binary downloads across different operating systems.
