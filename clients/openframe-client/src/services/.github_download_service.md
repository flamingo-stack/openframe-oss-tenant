A service for downloading and extracting GitHub release binaries with retry logic, CDN fallback, and cross-platform archive support.

## Key Components

- **GithubDownloadService**: Main service class with HTTP client for downloading GitHub releases
- **download_and_extract()**: Downloads and extracts binary from ZIP or tar.gz archives
- **download_with_retry()**: Implements retry logic with exponential backoff and jsDelivr CDN fallback for rate limits
- **extract_from_zip()**: Windows-specific ZIP archive extraction
- **extract_from_tar_gz()**: Unix-specific tar.gz archive extraction
- **github_to_cdn_url()**: Converts GitHub URLs to jsDelivr CDN URLs for rate limit workarounds
- **find_config_for_current_os()**: Selects appropriate download configuration for current platform
- **download_and_save()**: Complete download and save workflow with executable permissions

## Usage Example

```rust
use reqwest::Client;
use crate::github_download_service::GithubDownloadService;
use crate::models::download_configuration::DownloadConfiguration;

// Initialize service
let client = Client::new();
let service = GithubDownloadService::new(client);

// Find config for current OS
let configs = vec![/* download configurations */];
let config = service.find_config_for_current_os(&configs)?;

// Download and extract binary
let binary_bytes = service.download_and_extract(&config).await?;

// Or download and save directly
let tool_path = Path::new("/usr/local/bin");
let agent_path = Path::new("/usr/local/bin/agent");
let executable_name = service.download_and_save(&config, &tool_path, &agent_path).await?;
```

The service handles platform-specific archive formats (ZIP for Windows, tar.gz for Unix) and includes robust error handling with automatic CDN fallback when GitHub rate limits are encountered.
