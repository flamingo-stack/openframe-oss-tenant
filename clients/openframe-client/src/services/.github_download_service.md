A service that downloads and extracts GitHub release binaries with retry logic, fallback to jsDelivr CDN, and cross-platform archive support. It handles ZIP (Windows) and tar.gz (Unix) formats with proper validation and executable permissions.

## Key Components

- **`GithubDownloadService`** - Main service struct with HTTP client for downloading files
- **`download_and_extract`** - Downloads archives and extracts target binaries with size validation
- **`download_with_retry`** - Implements retry logic with automatic fallback to jsDelivr CDN on rate limits
- **`extract_from_zip`** / **`extract_from_tar_gz`** - Platform-specific archive extraction methods
- **`find_config_for_current_os`** - Selects appropriate download configuration for current platform
- **`download_and_save`** - High-level method that downloads and saves binaries to disk

## Usage Example

```rust
use reqwest::Client;
use crate::models::download_configuration::DownloadConfiguration;

// Create service with HTTP client
let client = Client::new();
let service = GithubDownloadService::new(client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/binary.tar.gz".to_string(),
    file_name: "binary.tar.gz".to_string(),
    target_file_name: "binary".to_string(),
    // ... other fields
};

let binary_bytes = service.download_and_extract(&config).await?;

// Or download and save to disk
let tool_path = Path::new("/usr/local/bin");
let agent_path = Path::new("/usr/local/bin/agent");
let executable_name = service.download_and_save(&config, tool_path, agent_path).await?;
```

The service automatically handles GitHub rate limiting by falling back to jsDelivr CDN, validates binary sizes, and sets proper executable permissions on Unix systems.
