A service that downloads and extracts binary files from GitHub releases with automatic retry logic and CDN fallback support. It handles both ZIP and tar.gz archives with platform-specific extraction methods.

## Key Components

- **`GithubDownloadService`** - Main service struct for downloading GitHub releases
- **`download_and_extract`** - Downloads archive and extracts target binary
- **`download_with_retry`** - Implements retry logic with timeout and rate limit handling
- **`github_to_cdn_url`** - Converts GitHub URLs to jsDelivr CDN fallback URLs
- **`extract_from_zip`** - Platform-specific ZIP extraction (Windows only)
- **`extract_from_tar_gz`** - Platform-specific tar.gz extraction (Unix/Linux only)
- **`find_config_for_current_os`** - Selects appropriate download configuration for current platform

## Usage Example

```rust
use reqwest::Client;
use crate::github_download_service::GithubDownloadService;
use crate::models::download_configuration::DownloadConfiguration;

// Create service instance
let client = Client::new();
let service = GithubDownloadService::new(client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/app.tar.gz".to_string(),
    file_name: "app.tar.gz".to_string(),
    target_file_name: "app".to_string(),
    // ... other fields
};

let binary_bytes = service.download_and_extract(&config).await?;

// Find OS-specific configuration
let configs = vec![/* download configurations */];
let os_config = service.find_config_for_current_os(&configs)?;
```

The service automatically handles GitHub rate limits by falling back to jsDelivr CDN, implements exponential backoff for retries, and validates binary sizes to ensure successful downloads.
