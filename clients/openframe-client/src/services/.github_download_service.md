A service for downloading and extracting GitHub release binaries with automatic retry logic, CDN fallback, and cross-platform archive support.

## Key Components

- **GithubDownloadService** - Main service struct with HTTP client
- **download_and_extract()** - Downloads and extracts binaries from ZIP/tar.gz archives
- **download_with_retry()** - Implements retry logic with jsDelivr CDN fallback on rate limits
- **extract_from_zip()** - Windows-specific ZIP extraction
- **extract_from_tar_gz()** - Unix-specific tar.gz extraction
- **find_config_for_current_os()** - OS-specific configuration selection
- **download_and_save()** - Complete download and save workflow

## Usage Example

```rust
use reqwest::Client;
use crate::github_download_service::GithubDownloadService;
use crate::models::download_configuration::DownloadConfiguration;

async fn download_agent() -> Result<()> {
    let client = Client::new();
    let service = GithubDownloadService::new(client);
    
    let configs = vec![
        DownloadConfiguration {
            link: "https://github.com/owner/repo/releases/download/v1.0/app.zip".to_string(),
            file_name: "app.zip".to_string(),
            target_file_name: "app.exe".to_string(),
            // ... other fields
        }
    ];
    
    let config = service.find_config_for_current_os(&configs)?;
    let binary_bytes = service.download_and_extract(config).await?;
    
    Ok(())
}
```

The service automatically handles GitHub API rate limits by falling back to jsDelivr CDN, validates minimum binary sizes, and sets appropriate executable permissions on Unix systems.
