A service for downloading and extracting agent binaries from GitHub releases with fallback support to jsDelivr CDN, handling ZIP and tar.gz archives based on the target platform.

## Key Components

- **GithubDownloadService**: Main service struct with HTTP client for downloading
- **download_and_extract()**: Downloads archive and extracts target binary with size validation
- **download_with_retry()**: Implements retry logic with CDN fallback for rate limits
- **extract_from_zip()**: Platform-specific ZIP extraction (Windows only)
- **extract_from_tar_gz()**: Platform-specific tar.gz extraction (Unix/Linux only)
- **github_to_cdn_url()**: Converts GitHub URLs to jsDelivr CDN URLs
- **find_config_for_current_os()**: Selects appropriate download config for current platform
- **download_and_save()**: High-level method for downloading and saving tools

## Usage Example

```rust
use reqwest::Client;
use crate::github_download_service::GithubDownloadService;
use crate::models::download_configuration::DownloadConfiguration;

// Create service with HTTP client
let client = Client::new();
let service = GithubDownloadService::new(client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/tool.tar.gz".to_string(),
    file_name: "tool.tar.gz".to_string(),
    target_file_name: "tool".to_string(),
    // ... other fields
};

// Extract binary bytes
let binary_bytes = service.download_and_extract(&config).await?;

// Or download and save directly to filesystem
let tool_path = std::path::Path::new("/opt/tools");
let default_path = std::path::Path::new("/opt/tools/default");
let executable_path = service.download_and_save(&config, tool_path, default_path).await?;
```

The service automatically handles platform-specific archive formats, implements exponential backoff retry logic, and provides CDN fallback for GitHub rate limiting scenarios.
