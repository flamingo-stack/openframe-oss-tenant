A service for downloading and extracting GitHub release binaries with retry logic, CDN fallback, and cross-platform archive support.

## Key Components

### Main Struct
- **`GithubDownloadService`** - Core service with HTTP client for downloading GitHub releases

### Primary Methods
- **`download_and_extract()`** - Downloads and extracts binary from archive with validation
- **`download_with_retry()`** - Implements retry logic with jsDelivr CDN fallback on rate limits
- **`download_and_save()`** - Downloads and saves tool agents to specified paths
- **`find_config_for_current_os()`** - Selects appropriate download configuration for current OS

### Archive Extraction
- **`extract_from_zip()`** - Windows ZIP extraction (conditional compilation)
- **`extract_from_tar_gz()`** - Unix tar.gz extraction (conditional compilation)

### Utility Methods
- **`github_to_cdn_url()`** - Converts GitHub URLs to jsDelivr CDN URLs for fallback
- **`set_executable_permissions()`** - Sets Unix executable permissions

## Usage Example

```rust
use reqwest::Client;
use crate::models::download_configuration::DownloadConfiguration;

// Create service
let client = Client::new();
let service = GithubDownloadService::new(client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/app.tar.gz".to_string(),
    file_name: "app.tar.gz".to_string(),
    target_file_name: "app".to_string(),
    // ... other fields
};

let binary_bytes = service.download_and_extract(&config).await?;

// Or download and save directly
let tool_path = Path::new("/usr/local/bin");
let agent_path = Path::new("/usr/local/bin/app");
let executable_name = service.download_and_save(&config, tool_path, agent_path).await?;
```

The service includes intelligent retry mechanisms with exponential backoff, automatic CDN fallback for GitHub rate limits, file size validation, and platform-specific archive handling (ZIP for Windows, tar.gz for Unix systems).
