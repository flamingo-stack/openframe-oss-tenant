A service for downloading and extracting binary files from GitHub releases with automatic fallback to jsDelivr CDN when GitHub rate limits are encountered. It handles both ZIP and tar.gz archives with platform-specific extraction support.

## Key Components

- **`GithubDownloadService`** - Main service struct with HTTP client for downloading files
- **`download_and_extract()`** - Downloads archive and extracts target binary with validation
- **`download_with_retry()`** - Implements retry logic with CDN fallback on rate limits (HTTP 429)
- **`github_to_cdn_url()`** - Converts GitHub release URLs to jsDelivr CDN URLs
- **`extract_from_zip()`** - ZIP extraction (Windows only)
- **`extract_from_tar_gz()`** - tar.gz extraction (Unix/Linux only)
- **`find_config_for_current_os()`** - Selects appropriate download config for current platform
- **`download_and_save()`** - Complete download and save workflow with file permissions

## Usage Example

```rust
use reqwest::Client;
use crate::github_download_service::GithubDownloadService;
use crate::models::download_configuration::DownloadConfiguration;

// Initialize service
let client = Client::new();
let service = GithubDownloadService::new(client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/tool.zip".to_string(),
    file_name: "tool.zip".to_string(),
    target_file_name: "tool.exe".to_string(),
    // ... other fields
};

let binary_bytes = service.download_and_extract(&config).await?;

// Or download and save directly
let tool_path = Path::new("./tools");
let agent_path = tool_path.join("tool.exe");
let exe_path = service.download_and_save(&config, &tool_path, &agent_path).await?;
```

The service automatically handles platform differences, retry logic with exponential backoff, CDN fallback for rate limits, and sets appropriate file permissions on Unix systems.
