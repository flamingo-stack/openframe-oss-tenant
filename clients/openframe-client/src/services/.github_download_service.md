A service for downloading GitHub releases and extracting agent binaries with built-in retry logic, CDN fallback, and cross-platform archive support.

## Key Components

- **`GithubDownloadService`** - Main service struct wrapping HTTP client
- **`download_and_extract()`** - Downloads and extracts binary from archive configuration
- **`download_with_retry()`** - Handles retries with jsDelivr CDN fallback on rate limits
- **`extract_from_zip()`** - ZIP archive extraction (Windows only)
- **`extract_from_tar_gz()`** - Tar.gz archive extraction (Unix/Linux only)
- **`github_to_cdn_url()`** - Converts GitHub URLs to jsDelivr CDN URLs
- **`find_config_for_current_os()`** - Selects appropriate download configuration
- **`download_and_save()`** - Downloads and saves binary to disk with proper permissions

## Usage Example

```rust
use reqwest::Client;
use crate::github_download_service::GithubDownloadService;
use crate::models::download_configuration::DownloadConfiguration;

// Create service instance
let client = Client::new();
let service = GithubDownloadService::new(client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/tool.tar.gz".to_string(),
    file_name: "tool.tar.gz".to_string(),
    target_file_name: "tool".to_string(),
    // ... other fields
};

let binary_bytes = service.download_and_extract(&config).await?;

// Save to disk with executable permissions
let tool_path = Path::new("/usr/local/bin/tool");
service.download_and_save(&config, &tool_path.parent().unwrap(), &tool_path).await?;
```

The service automatically handles GitHub rate limiting by falling back to jsDelivr CDN, validates binary sizes, and sets appropriate file permissions on Unix systems.
