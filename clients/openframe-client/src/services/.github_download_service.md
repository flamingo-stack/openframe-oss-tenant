A service for downloading and extracting GitHub release binaries with retry logic, CDN fallback, and platform-specific archive handling.

## Key Components

- **`GithubDownloadService`** - Main service struct with HTTP client
- **`download_and_extract()`** - Downloads and extracts binary from ZIP/tar.gz archives
- **`download_with_retry()`** - Handles download retries with jsDelivr CDN fallback on rate limits
- **`extract_from_zip()`** - Windows-specific ZIP extraction
- **`extract_from_tar_gz()`** - Unix-specific tar.gz extraction
- **`github_to_cdn_url()`** - Converts GitHub URLs to jsDelivr CDN URLs
- **`find_config_for_current_os()`** - Selects appropriate download configuration for current OS

## Usage Example

```rust
use reqwest::Client;
use crate::github_download_service::GithubDownloadService;
use crate::models::download_configuration::DownloadConfiguration;

// Initialize the service
let client = Client::new();
let service = GithubDownloadService::new(client);

// Download and extract a binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/binary.tar.gz".to_string(),
    file_name: "binary.tar.gz".to_string(),
    target_file_name: "binary".to_string(),
    // ... other fields
};

let binary_bytes = service.download_and_extract(&config).await?;

// Find configuration for current OS
let configs = vec![config];
let current_config = service.find_config_for_current_os(&configs)?;
```

The service includes intelligent retry logic that falls back to jsDelivr CDN when GitHub rate limits (429 errors) are encountered, and validates binary sizes to ensure successful downloads.
