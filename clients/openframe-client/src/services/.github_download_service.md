Handles downloading, extracting, and saving GitHub release binaries with intelligent retry logic and CDN fallback for MSP tool updates.

## Key Components

- **`GithubDownloadService`** - Main service for downloading GitHub releases
- **`download_and_extract()`** - Downloads archives and extracts target binaries with validation
- **`download_with_retry()`** - Implements retry logic with jsDelivr CDN fallback for rate limits
- **`extract_from_zip()`** - Platform-specific ZIP extraction (Windows only)
- **`extract_from_tar_gz()`** - Platform-specific tar.gz extraction (Unix/Linux only)
- **`github_to_cdn_url()`** - Converts GitHub URLs to jsDelivr CDN URLs for fallback
- **`find_config_for_current_os()`** - Selects appropriate download configuration for current platform

## Usage Example

```rust
use github_download_service::GithubDownloadService;
use reqwest::Client;

// Initialize service
let client = Client::new();
let service = GithubDownloadService::new(client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/tool.zip".to_string(),
    file_name: "tool.zip".to_string(),
    target_file_name: "tool.exe".to_string(),
    // ... other fields
};

let binary_bytes = service.download_and_extract(&config).await?;

// Find config for current OS
let configs = vec![/* platform-specific configs */];
let current_config = service.find_config_for_current_os(&configs)?;
```

The service automatically handles platform-specific archive formats (ZIP on Windows, tar.gz on Unix), implements exponential backoff retry logic, and provides jsDelivr CDN fallback when GitHub rate limits are encountered.
