A specialized service for downloading and extracting GitHub release binaries with retry logic, rate limiting fallback, and cross-platform archive support.

## Key Components

- **`GithubDownloadService`** - Main service struct with HTTP client for downloading releases
- **`download_and_extract()`** - Downloads archives and extracts target binaries with validation
- **`download_with_retry()`** - Implements retry logic with exponential backoff and jsDelivr CDN fallback
- **`extract_from_zip()` / `extract_from_tar_gz()`** - Platform-specific archive extraction methods
- **`github_to_cdn_url()`** - Converts GitHub URLs to jsDelivr CDN URLs for rate limit fallback
- **`find_config_for_current_os()`** - Selects appropriate download configuration for current platform

## Usage Example

```rust
use reqwest::Client;
use crate::models::download_configuration::DownloadConfiguration;
use crate::github_download_service::GithubDownloadService;

async fn download_tool() -> Result<(), Box<dyn std::error::Error>> {
    let client = Client::new();
    let service = GithubDownloadService::new(client);
    
    let config = DownloadConfiguration {
        link: "https://github.com/owner/repo/releases/download/v1.0/tool.tar.gz".to_string(),
        file_name: "tool.tar.gz".to_string(),
        target_file_name: "tool".to_string(),
        // ... other fields
    };
    
    // Download and extract binary
    let binary_bytes = service.download_and_extract(&config).await?;
    println!("Downloaded {} bytes", binary_bytes.len());
    
    Ok(())
}
```

The service automatically handles GitHub rate limits by falling back to jsDelivr CDN, validates binary sizes, and provides platform-specific archive extraction (ZIP on Windows, tar.gz on Unix systems).
