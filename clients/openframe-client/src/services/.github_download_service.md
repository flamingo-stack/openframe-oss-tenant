Handles downloading, extracting, and saving agent binaries from GitHub releases, with retry logic and automatic fallback to jsDelivr CDN on rate limiting.

## Key Components

- **`GithubDownloadService`** — Main service struct holding an HTTP client and platform-specific DMG extractor
- **`download_and_extract()`** — Downloads an archive from a `DownloadConfiguration` URL, detects format (`.zip` or `.tar.gz`), extracts the target binary, and validates minimum size
- **`download_with_retry()`** — Wraps downloads with configurable retry attempts, per-attempt timeouts, exponential backoff, and HTTP 429 CDN fallback
- **`github_to_cdn_url()`** — Converts GitHub release URLs to jsDelivr CDN equivalents (e.g., `github.com/owner/repo/releases/download/v1.0/file.zip` → `cdn.jsdelivr.net/gh/owner/repo@v1.0/file.zip`)
- **`extract_from_zip()`** — Windows-only ZIP extraction using the `zip` crate
- **`extract_from_tar_gz()`** — Non-Windows tar.gz extraction using `flate2` + `tar` crates
- **`find_config_for_current_os()`** — Selects the matching `DownloadConfiguration` for the current platform
- **`download_and_save()`** — High-level entry point: extracts and writes binary to disk, sets executable permissions, handles both single-binary and folder-extraction modes

## Usage Example

```rust
let service = GithubDownloadService::new(
    reqwest::Client::new(),
    DmgExtractor::default(),
);

// Find the OS-appropriate config from a list
let config = service.find_config_for_current_os(&download_configs)?;

// Download, extract, and write to disk
let exec_name = service
    .download_and_save(&config, &tool_folder_path, &default_agent_path)
    .await?;
```
