Service for downloading and extracting agent binaries from GitHub releases with automatic fallback to jsDelivr CDN and platform-specific archive handling.

## Key Components

- **`GithubDownloadService`** - Main service struct with HTTP client
- **`download_and_extract`** - Downloads and extracts binaries from archives (ZIP/tar.gz)
- **`download_with_retry`** - Implements retry logic with CDN fallback on rate limits
- **`extract_from_zip`** - Windows-specific ZIP extraction (conditional compilation)
- **`extract_from_tar_gz`** - Unix-specific tar.gz extraction (conditional compilation)
- **`find_config_for_current_os`** - Matches download configs to current platform
- **`download_and_save`** - Complete download and save workflow with permissions

## Usage Example

```rust
use reqwest::Client;
use crate::github_download_service::GithubDownloadService;
use crate::models::download_configuration::DownloadConfiguration;

// Create service with HTTP client
let client = Client::new();
let service = GithubDownloadService::new(client);

// Find configuration for current OS
let configs = vec![/* download configurations */];
let config = service.find_config_for_current_os(&configs)?;

// Download and extract binary
let binary_bytes = service.download_and_extract(&config).await?;

// Or download and save directly to disk
let tool_path = Path::new("/path/to/tool");
let agent_path = Path::new("/path/to/agent");
let executable_name = service.download_and_save(&config, &tool_path, &agent_path).await?;
```

The service handles GitHub rate limiting by automatically falling back to jsDelivr CDN, validates file sizes, and sets appropriate executable permissions on Unix systems.
