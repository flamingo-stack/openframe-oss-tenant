A service for downloading and extracting agent binaries from GitHub releases with automatic retry logic, CDN fallback, and cross-platform archive format support.

## Key Components

- **`GithubDownloadService`**: Main service struct with HTTP client for downloading binaries
- **`download_and_extract()`**: Downloads and extracts binaries from ZIP or tar.gz archives
- **`download_with_retry()`**: Implements retry logic with jsDelivr CDN fallback for rate limits
- **`extract_from_zip()`**: Windows-specific ZIP extraction (conditional compilation)
- **`extract_from_tar_gz()`**: Unix-specific tar.gz extraction (conditional compilation)
- **`find_config_for_current_os()`**: Selects appropriate download configuration for current platform
- **`github_to_cdn_url()`**: Converts GitHub URLs to jsDelivr CDN URLs for fallback

## Usage Example

```rust
use reqwest::Client;
use crate::models::download_configuration::DownloadConfiguration;

let client = Client::new();
let service = GithubDownloadService::new(client);

// Find configuration for current OS
let configs = vec![/* download configurations */];
let config = service.find_config_for_current_os(&configs)?;

// Download and extract binary
let binary_bytes = service.download_and_extract(config).await?;

// Or download and save to filesystem
let tool_path = std::path::Path::new("/opt/tools");
let agent_path = std::path::Path::new("/opt/agent");
let executable_name = service.download_and_save(config, tool_path, agent_path).await?;
```

The service handles platform-specific archive formats (ZIP on Windows, tar.gz on Unix) and includes intelligent retry mechanisms with CDN fallback for GitHub rate limiting scenarios.
