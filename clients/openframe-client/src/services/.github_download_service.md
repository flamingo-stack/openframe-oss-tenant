A service for downloading and extracting GitHub release binaries with automatic retry logic, CDN fallback, and cross-platform archive support. Handles ZIP archives on Windows and tar.gz archives on Unix-like systems.

## Key Components

- **`GithubDownloadService`** - Main service struct with HTTP client for downloading releases
- **`download_and_extract()`** - Downloads and extracts binary from archive based on configuration
- **`download_with_retry()`** - Implements retry logic with exponential backoff and jsDelivr CDN fallback
- **`extract_from_zip()`** - Extracts files from ZIP archives (Windows only)
- **`extract_from_tar_gz()`** - Extracts files from tar.gz archives (Unix only)
- **`github_to_cdn_url()`** - Converts GitHub URLs to jsDelivr CDN URLs for rate limit fallback
- **`find_config_for_current_os()`** - Finds appropriate download configuration for current platform

## Usage Example

```rust
use reqwest::Client;
use crate::models::download_configuration::DownloadConfiguration;

// Create service with HTTP client
let client = Client::new();
let service = GithubDownloadService::new(client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/tool.zip".to_string(),
    file_name: "tool.zip".to_string(),
    target_file_name: "tool.exe".to_string(),
    // ... other fields
};

let binary_bytes = service.download_and_extract(&config).await?;

// Or download and save to filesystem
let tool_path = Path::new("/usr/local/bin");
let default_path = Path::new("/usr/local/bin/tool");
let executable_name = service.download_and_save(&config, tool_path, default_path).await?;
```
