Service for downloading and extracting agent binaries from GitHub releases with fallback to jsDelivr CDN, supporting both ZIP and tar.gz archives with platform-specific extraction methods.

## Key Components

- **`GithubDownloadService`** - Main service struct with HTTP client for downloading
- **`download_and_extract()`** - Downloads and extracts binary from archive based on configuration
- **`download_with_retry()`** - Implements retry logic with rate limit fallback to jsDelivr CDN
- **`extract_from_zip()`** - Platform-specific ZIP extraction (Windows only)
- **`extract_from_tar_gz()`** - Platform-specific tar.gz extraction (Unix-like systems)
- **`find_config_for_current_os()`** - Selects appropriate download config for current OS
- **`download_and_save()`** - Downloads and saves tool agent to filesystem

## Usage Example

```rust
use reqwest::Client;
use github_download_service::GithubDownloadService;

// Create service with HTTP client
let client = Client::new();
let download_service = GithubDownloadService::new(client);

// Find configuration for current OS
let config = download_service
    .find_config_for_current_os(&download_configs)?;

// Download and extract binary
let binary_bytes = download_service
    .download_and_extract(config)
    .await?;

// Or download and save directly to filesystem
let executable_path = download_service
    .download_and_save(config, &tool_folder, &default_path)
    .await?;
```

The service automatically handles rate limiting by falling back to jsDelivr CDN when GitHub returns 429 errors, validates file sizes, and sets executable permissions on Unix systems.
