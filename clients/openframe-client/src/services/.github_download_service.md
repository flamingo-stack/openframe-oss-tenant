Handles downloading, extracting, and saving agent binaries from GitHub releases, with retry logic, jsDelivr CDN fallback on rate limiting, and platform-specific archive extraction (ZIP for Windows, tar.gz for Unix/macOS).

## Key Components

- **`GithubDownloadService`** — Main struct holding an HTTP client and platform-specific DMG extractor
- **`download_and_extract(config)`** — Downloads an archive and extracts the target binary, validating size thresholds
- **`download_with_retry(url)`** — Retries downloads up to `MAX_DOWNLOAD_RETRIES` with exponential backoff; falls back to jsDelivr CDN on HTTP 429
- **`github_to_cdn_url(url)`** — Converts a GitHub release URL to a jsDelivr CDN mirror URL
- **`extract_from_zip()`** — Windows-only ZIP extraction using the `zip` crate
- **`extract_from_tar_gz()`** — Unix/macOS tar.gz extraction using `flate2` + `tar` crates
- **`find_config_for_current_os(configs)`** — Selects the matching `DownloadConfiguration` for the running OS
- **`download_and_save(config, tool_folder_path, default_agent_path)`** — High-level entry point that downloads, extracts, sets permissions, and saves the binary

## Usage Example

```rust
let client = reqwest::Client::new();
let extractor = DmgExtractor::new();
let service = GithubDownloadService::new(client, extractor);

// Find the right config for the current OS
let config = service.find_config_for_current_os(&download_configs)?;

// Download and save binary to disk
let executable_name = service
    .download_and_save(&config, &tool_folder_path, &default_agent_path)
    .await?;

println!("Saved agent binary: {:?}", executable_name);
```
