This service handles downloading and extracting binary files from GitHub releases with robust error handling and platform-specific archive support.

## Key Components

- **`GithubDownloadService`** - Main service for downloading and extracting GitHub release binaries
- **`download_and_extract()`** - Downloads archives and extracts target binaries with size validation
- **`download_with_retry()`** - Implements retry logic with exponential backoff and jsDelivr CDN fallback for rate limits
- **`extract_from_zip()`** - ZIP archive extraction (Windows only)
- **`extract_from_tar_gz()`** - Tar.gz archive extraction (Unix/Linux only)
- **`github_to_cdn_url()`** - Converts GitHub URLs to jsDelivr CDN URLs for rate limit fallback
- **`find_config_for_current_os()`** - Selects appropriate download configuration for current platform

## Usage Example

```rust
use reqwest::Client;
use crate::github_download_service::GithubDownloadService;

// Initialize the service
let http_client = Client::new();
let download_service = GithubDownloadService::new(http_client);

// Download and extract binary
let config = download_service.find_config_for_current_os(&configs)?;
let binary_bytes = download_service.download_and_extract(config).await?;

// Save to file
let tool_path = Path::new("/path/to/tool");
let agent_path = Path::new("/path/to/agent");
let executable_name = download_service
    .download_and_save(config, tool_path, agent_path)
    .await?;
```

The service provides automatic platform detection, retry mechanisms for failed downloads, and fallback to CDN mirrors when GitHub rate limits are encountered.
