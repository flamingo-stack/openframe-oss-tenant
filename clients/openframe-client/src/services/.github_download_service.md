This service handles downloading and extracting binary tools from GitHub releases with platform-specific support and automatic CDN fallback.

## Key Components

- **`GithubDownloadService`** - Main service struct with HTTP client for downloading releases
- **`download_and_extract()`** - Downloads archives and extracts specific binaries with size validation
- **`download_with_retry()`** - Implements retry logic with automatic jsDelivr CDN fallback on rate limits
- **`extract_from_zip()` / `extract_from_tar_gz()`** - Platform-specific archive extraction (ZIP for Windows, tar.gz for Unix)
- **`github_to_cdn_url()`** - Converts GitHub release URLs to jsDelivr CDN URLs for fallback
- **`find_config_for_current_os()`** - Selects appropriate download configuration for current platform

## Usage Example

```rust
use reqwest::Client;
use crate::models::download_configuration::DownloadConfiguration;

// Initialize the service
let http_client = Client::new();
let service = GithubDownloadService::new(http_client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/tool.tar.gz".to_string(),
    file_name: "tool.tar.gz".to_string(),
    target_file_name: "tool".to_string(),
    // ... other fields
};

let binary_bytes = service.download_and_extract(&config).await?;

// Find OS-specific configuration
let configs = vec![/* multiple platform configs */];
let os_config = service.find_config_for_current_os(&configs)?;
```

The service automatically handles rate limiting by falling back to jsDelivr CDN and includes comprehensive error handling with configurable retry attempts.
