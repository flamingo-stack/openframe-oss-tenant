This service handles downloading and extracting GitHub release binaries with retry logic and CDN fallback capabilities.

## Key Components

- **`GithubDownloadService`** - Main service struct with HTTP client
- **`download_and_extract()`** - Downloads archives and extracts target binaries
- **`download_with_retry()`** - Implements retry logic with jsDelivr CDN fallback for rate limits
- **`extract_from_zip()`** - ZIP extraction (Windows only)
- **`extract_from_tar_gz()`** - Tar.gz extraction (Unix/Linux only)
- **`github_to_cdn_url()`** - Converts GitHub URLs to jsDelivr CDN URLs
- **`find_config_for_current_os()`** - Selects appropriate download configuration
- **`download_and_save()`** - Downloads and saves binaries with proper permissions

## Usage Example

```rust
use reqwest::Client;
use github_download_service::GithubDownloadService;
use crate::models::download_configuration::DownloadConfiguration;

// Initialize service
let client = Client::new();
let service = GithubDownloadService::new(client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/tool.tar.gz".to_string(),
    file_name: "tool.tar.gz".to_string(),
    target_file_name: "tool".to_string(),
    // ... other fields
};

let binary_bytes = service.download_and_extract(&config).await?;

// Or download and save directly to filesystem
let tool_path = Path::new("/usr/local/bin");
let agent_path = Path::new("/usr/local/bin/tool");
service.download_and_save(&config, tool_path, agent_path).await?;
```

The service automatically handles GitHub rate limits by falling back to jsDelivr CDN, supports platform-specific archive formats (ZIP on Windows, tar.gz on Unix), and includes comprehensive error handling with retry mechanisms.
