A service for downloading and extracting agent binaries from GitHub releases with platform-specific support and fallback mechanisms. Handles ZIP archives on Windows and tar.gz archives on Unix systems, with jsDelivr CDN fallback for rate limiting.

## Key Components

- **`GithubDownloadService`** - Main service struct containing HTTP client
- **`download_and_extract`** - Downloads and extracts binary from archive based on configuration
- **`download_with_retry`** - Implements retry logic with timeout and CDN fallback for rate limits
- **`extract_from_zip`** - Windows-specific ZIP extraction (conditional compilation)
- **`extract_from_tar_gz`** - Unix-specific tar.gz extraction (conditional compilation)
- **`github_to_cdn_url`** - Converts GitHub release URLs to jsDelivr CDN URLs
- **`find_config_for_current_os`** - Selects appropriate download configuration for current platform
- **`download_and_save`** - High-level method to download and save binaries with proper permissions

## Usage Example

```rust
use reqwest::Client;
use crate::github_download_service::GithubDownloadService;
use crate::models::download_configuration::DownloadConfiguration;

// Create service with HTTP client
let http_client = Client::new();
let service = GithubDownloadService::new(http_client);

// Find configuration for current OS
let configs = vec![/* download configurations */];
let config = service.find_config_for_current_os(&configs)?;

// Download and extract binary
let binary_bytes = service.download_and_extract(config).await?;

// Or download and save directly to filesystem
let tool_path = Path::new("/path/to/tool");
let agent_path = Path::new("/path/to/agent");
let executable_name = service.download_and_save(config, tool_path, agent_path).await?;
```

The service automatically handles platform differences, implements retry logic with exponential backoff, validates file sizes, and sets proper executable permissions on Unix systems.
