Handles downloading, extracting, and saving agent binaries from GitHub releases, with automatic retry logic and jsDelivr CDN fallback on rate limiting.

## Key Components

### `GithubDownloadService`
Main service struct holding an `http_client` (reqwest) and `dmg_extractor` for platform-specific extraction.

| Method | Description |
|---|---|
| `download_and_extract` | Downloads archive from a `DownloadConfiguration` URL, validates size, and extracts the target binary (`.zip` or `.tar.gz`) |
| `download_with_retry` | Retries downloads up to `MAX_DOWNLOAD_RETRIES` with exponential backoff; falls back to jsDelivr CDN on HTTP 429 |
| `github_to_cdn_url` | Converts a GitHub release URL to its jsDelivr CDN equivalent |
| `find_config_for_current_os` | Selects the matching `DownloadConfiguration` for the current OS from a slice |
| `download_and_save` | High-level method that downloads, extracts, writes to disk, and sets executable permissions |
| `extract_from_zip` | Windows-only ZIP extraction using the `zip` crate |
| `extract_from_tar_gz` | Non-Windows tar.gz extraction using `flate2` + `tar` crates |

## Usage Example

```rust
use reqwest::Client;
use crate::services::github_download_service::GithubDownloadService;
use crate::platform::DmgExtractor;

let http_client = Client::new();
let dmg_extractor = DmgExtractor::new();
let service = GithubDownloadService::new(http_client, dmg_extractor);

// Find the right config for the current OS
let config = service.find_config_for_current_os(&download_configs)?;

// Download and save to disk
let executable_name = service
    .download_and_save(&config, &tool_folder_path, &default_agent_path)
    .await?;
```

> **CDN Fallback:** On GitHub HTTP 429 rate-limit responses, the service automatically retries against `cdn.jsdelivr.net/gh/` before surfacing an error.
