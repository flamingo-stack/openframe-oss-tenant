A service for downloading and extracting GitHub release binaries with automatic retry logic, CDN fallback, and cross-platform archive support (ZIP/tar.gz).

## Key Components

- **`GithubDownloadService`** - Main service struct with HTTP client
- **`download_and_extract()`** - Downloads and extracts binary from archive based on configuration
- **`download_with_retry()`** - Implements retry logic with exponential backoff and jsDelivr CDN fallback for rate limits
- **`extract_from_zip()`** - Extracts files from ZIP archives (Windows)
- **`extract_from_tar_gz()`** - Extracts files from tar.gz archives (Unix/Linux)
- **`github_to_cdn_url()`** - Converts GitHub release URLs to jsDelivr CDN URLs
- **`find_config_for_current_os()`** - Selects appropriate download configuration for the current OS

## Usage Example

```rust
use reqwest::Client;
use github_download_service::GithubDownloadService;
use models::download_configuration::DownloadConfiguration;

// Create service instance
let client = Client::new();
let service = GithubDownloadService::new(client);

// Configure download
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/tool.tar.gz".to_string(),
    file_name: "tool.tar.gz".to_string(),
    target_file_name: "tool".to_string(),
    // ... other fields
};

// Download and extract binary
let binary_bytes = service.download_and_extract(&config).await?;

// Find OS-specific configuration
let configs = vec![config];
let os_config = service.find_config_for_current_os(&configs)?;
```

The service handles platform-specific archive formats, implements robust error handling with CDN fallbacks for GitHub rate limits, and includes binary size validation to ensure successful downloads.
