A service for downloading and extracting GitHub releases with automatic retry logic and CDN fallback support. Handles both ZIP and tar.gz archives with platform-specific extraction methods.

## Key Components

- **`GithubDownloadService`** - Main service struct with HTTP client
- **`download_and_extract()`** - Downloads and extracts binary from archive
- **`download_with_retry()`** - Implements retry logic with rate limit handling
- **`github_to_cdn_url()`** - Converts GitHub URLs to jsDelivr CDN URLs
- **`extract_from_zip()`** - ZIP extraction (Windows only)
- **`extract_from_tar_gz()`** - tar.gz extraction (non-Windows)
- **`find_config_for_current_os()`** - OS-specific configuration selection
- **`download_and_save()`** - Complete download and save workflow

## Usage Example

```rust
use reqwest::Client;
use crate::github_download_service::GithubDownloadService;
use crate::models::download_configuration::DownloadConfiguration;

// Create service instance
let http_client = Client::new();
let service = GithubDownloadService::new(http_client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/app.tar.gz".to_string(),
    file_name: "app.tar.gz".to_string(),
    target_file_name: "app".to_string(),
    // ... other fields
};

let binary_bytes = service.download_and_extract(&config).await?;

// Or download and save directly to disk
let tool_path = Path::new("/path/to/tool");
let agent_path = Path::new("/path/to/agent");
let executable_name = service.download_and_save(&config, tool_path, agent_path).await?;
```

The service automatically handles GitHub rate limits by falling back to jsDelivr CDN, validates file sizes, and sets appropriate executable permissions on Unix systems.
