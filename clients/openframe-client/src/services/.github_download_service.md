A service for downloading and extracting GitHub release binaries with retry logic and CDN fallback support. Handles both ZIP and tar.gz archives with platform-specific extraction methods.

## Key Components

- **GithubDownloadService** - Main service struct with HTTP client
- **download_and_extract()** - Downloads and extracts binaries from archives
- **download_with_retry()** - Implements retry logic with jsDelivr CDN fallback for rate limits
- **extract_from_zip()** - Extracts files from ZIP archives (Windows)
- **extract_from_tar_gz()** - Extracts files from tar.gz archives (Unix)
- **github_to_cdn_url()** - Converts GitHub URLs to jsDelivr CDN URLs
- **find_config_for_current_os()** - Selects appropriate download configuration
- **download_and_save()** - Complete download and save workflow

## Usage Example

```rust
use reqwest::Client;

// Create service with HTTP client
let http_client = Client::new();
let service = GithubDownloadService::new(http_client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/binary.tar.gz".to_string(),
    file_name: "binary.tar.gz".to_string(),
    target_file_name: "binary".to_string(),
    // ... other fields
};

let binary_bytes = service.download_and_extract(&config).await?;

// Or download and save to disk
let executable_path = service.download_and_save(
    &config,
    &tool_folder_path,
    &default_agent_path
).await?;
```

The service automatically handles GitHub rate limiting by falling back to jsDelivr CDN, validates file sizes, and sets appropriate permissions on Unix systems.
