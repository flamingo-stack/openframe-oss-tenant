A service that downloads and extracts agent binaries from GitHub releases with fallback to jsDelivr CDN, supporting ZIP and tar.gz archives across different platforms.

## Key Components

- **`GithubDownloadService`** - Main service struct with HTTP client
- **`download_and_extract()`** - Downloads and extracts binary from archive
- **`download_with_retry()`** - Retry logic with rate limit fallback to CDN
- **`github_to_cdn_url()`** - Converts GitHub URLs to jsDelivr CDN URLs
- **`extract_from_zip()`** - ZIP extraction (Windows only)
- **`extract_from_tar_gz()`** - tar.gz extraction (Unix only)
- **`find_config_for_current_os()`** - OS-specific configuration selection
- **`download_and_save()`** - Downloads and saves to filesystem with permissions

## Usage Example

```rust
use reqwest::Client;
use crate::github_download_service::GithubDownloadService;
use crate::models::download_configuration::DownloadConfiguration;

// Initialize service
let client = Client::new();
let service = GithubDownloadService::new(client);

// Configure download
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/tool.tar.gz".to_string(),
    file_name: "tool.tar.gz".to_string(),
    target_file_name: "tool".to_string(),
    // ... other fields
};

// Download and extract binary
let binary_bytes = service.download_and_extract(&config).await?;

// Or download and save to filesystem
let executable_path = service.download_and_save(
    &config,
    &tool_folder_path,
    &default_agent_path
).await?;
```

The service automatically handles GitHub rate limiting by falling back to jsDelivr CDN, validates file sizes, and sets appropriate executable permissions on Unix systems.
