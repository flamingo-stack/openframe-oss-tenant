A service for downloading and extracting agent binaries from GitHub releases with automatic CDN fallback and platform-specific archive handling. Handles ZIP extraction on Windows and tar.gz on Unix systems.

## Key Components

- **GithubDownloadService** - Main service struct with HTTP client for downloading releases
- **download_and_extract()** - Downloads archive and extracts target binary with validation
- **download_with_retry()** - Retry logic with jsDelivr CDN fallback on rate limits
- **extract_from_zip()** - ZIP extraction for Windows platforms  
- **extract_from_tar_gz()** - tar.gz extraction for Unix platforms
- **find_config_for_current_os()** - Selects appropriate download config for current OS
- **download_and_save()** - Complete download and save workflow with executable permissions

## Usage Example

```rust
use reqwest::Client;
use crate::models::download_configuration::DownloadConfiguration;

// Create service with HTTP client
let client = Client::new();
let service = GithubDownloadService::new(client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/tool.tar.gz".to_string(),
    file_name: "tool.tar.gz".to_string(),
    target_file_name: "tool".to_string(),
    // ... other fields
};

let binary_bytes = service.download_and_extract(&config).await?;

// Or download and save directly
let tool_path = Path::new("/tools");
let agent_path = Path::new("/tools/agent");
let executable_name = service.download_and_save(&config, tool_path, agent_path).await?;
```

The service automatically handles GitHub API rate limits by falling back to jsDelivr CDN, validates file sizes, and sets proper executable permissions on Unix systems.
