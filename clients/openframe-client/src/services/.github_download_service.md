A service for downloading and extracting GitHub releases, with intelligent retry logic, CDN fallback support, and cross-platform archive handling.

## Key Components

**Main Service:**
- `GithubDownloadService` - Core service with HTTP client for downloading GitHub releases

**Key Methods:**
- `download_and_extract()` - Downloads and extracts binary from archives (ZIP/tar.gz)
- `download_with_retry()` - Implements retry logic with jsDelivr CDN fallback on rate limits
- `find_config_for_current_os()` - Selects appropriate download configuration for current platform
- `download_and_save()` - Complete workflow for downloading and saving tools

**Platform-Specific Extraction:**
- `extract_from_zip()` - Windows ZIP archive extraction
- `extract_from_tar_gz()` - Unix/Linux tar.gz archive extraction

## Usage Example

```rust
use reqwest::Client;
use crate::github_download_service::GithubDownloadService;
use crate::models::download_configuration::DownloadConfiguration;

// Initialize the service
let client = Client::new();
let service = GithubDownloadService::new(client);

// Find configuration for current OS
let configs = vec![/* your download configurations */];
let config = service.find_config_for_current_os(&configs)?;

// Download and extract binary
let binary_bytes = service.download_and_extract(config).await?;

// Or download and save directly to disk
let tool_path = Path::new("/path/to/tools");
let agent_path = Path::new("/path/to/agent");
let executable_name = service.download_and_save(config, tool_path, agent_path).await?;
```

**Key Features:**
- Automatic retry with exponential backoff (2, 4, 6 seconds)
- Rate limit detection and jsDelivr CDN fallback
- Binary size validation and cross-platform executable permissions
- Support for both ZIP (Windows) and tar.gz (Unix) archives
