This service handles downloading and extracting agent binaries from GitHub releases with fallback to CDN and platform-specific archive support. It provides robust error handling with retry logic and automatic format detection for ZIP and tar.gz archives.

## Key Components

- **`GithubDownloadService`** - Main service struct with HTTP client
- **`download_and_extract()`** - Downloads archive and extracts target binary
- **`download_with_retry()`** - Implements retry logic with jsDelivr CDN fallback on rate limits
- **`extract_from_zip()`** - ZIP extraction (Windows-specific)
- **`extract_from_tar_gz()`** - Tar.gz extraction (Unix-specific)
- **`find_config_for_current_os()`** - Selects appropriate download configuration
- **`download_and_save()`** - Complete download and save workflow

## Usage Example

```rust
use reqwest::Client;
use crate::models::download_configuration::DownloadConfiguration;

// Create service with HTTP client
let client = Client::new();
let service = GithubDownloadService::new(client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/binary.tar.gz".to_string(),
    file_name: "binary.tar.gz".to_string(),
    target_file_name: "agent".to_string(),
    // ... other fields
};

let binary_bytes = service.download_and_extract(&config).await?;

// Or download and save to filesystem
let tool_path = Path::new("/opt/tools");
let agent_path = Path::new("/opt/agent");
let exe_path = service.download_and_save(&config, tool_path, agent_path).await?;
```

The service automatically handles:
- GitHub rate limit fallback to jsDelivr CDN
- Platform-specific archive formats (ZIP on Windows, tar.gz on Unix)
- Binary size validation and executable permissions
- Configurable retries with exponential backoff
