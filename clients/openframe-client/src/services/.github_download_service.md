Handles downloading, extracting, and saving agent binaries from GitHub releases, with retry logic and jsDelivr CDN fallback on rate limiting.

## Key Components

- **`GithubDownloadService`** — Main service struct wrapping an HTTP client and a platform-specific `DmgExtractor`
- **`download_and_extract`** — Downloads an archive and extracts the target binary; supports `.zip` (Windows) and `.tar.gz` (non-Windows)
- **`download_with_retry`** — Retry loop with configurable attempts, exponential backoff, and automatic fallback to jsDelivr CDN on HTTP 429
- **`github_to_cdn_url`** — Converts a GitHub release URL to its jsDelivr CDN equivalent
- **`find_config_for_current_os`** — Selects the matching `DownloadConfiguration` for the current platform
- **`download_and_save`** — Orchestrates full download-extract-persist flow; handles both single-binary and folder-extraction modes

## Usage Example

```rust
use reqwest::Client;
use crate::platform::DmgExtractor;
use crate::services::github_download_service::GithubDownloadService;

let client = Client::new();
let extractor = DmgExtractor::new();
let service = GithubDownloadService::new(client, extractor);

// Find the right config for the current OS
let config = service.find_config_for_current_os(&download_configs)?;

// Download, extract, and write to disk
let exec_path = service
    .download_and_save(&config, &tool_folder_path, &default_agent_path)
    .await?;
```
