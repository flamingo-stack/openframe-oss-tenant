A service for downloading and extracting GitHub release assets with automatic retry logic, CDN fallback for rate limits, and cross-platform archive support.

## Key Components

- **GithubDownloadService** - Main service struct with HTTP client for downloading GitHub releases
- **download_and_extract()** - Downloads archives and extracts target binaries with validation
- **download_with_retry()** - Implements retry logic with exponential backoff and jsDelivr CDN fallback
- **extract_from_zip()** - ZIP archive extraction (Windows platforms)
- **extract_from_tar_gz()** - Tar.gz archive extraction (Unix platforms)
- **find_config_for_current_os()** - Selects appropriate download configuration for current platform

## Usage Example

```rust
use reqwest::Client;
use crate::models::download_configuration::DownloadConfiguration;

// Create service with HTTP client
let client = Client::new();
let service = GithubDownloadService::new(client);

// Find configuration for current OS
let configs = vec![/* your download configurations */];
let config = service.find_config_for_current_os(&configs)?;

// Download and extract binary
let binary_bytes = service.download_and_extract(config).await?;

// Or download and save to disk
let executable_path = service.download_and_save(
    config,
    &tool_folder_path,
    &default_agent_path
).await?;
```

The service automatically handles GitHub rate limits by falling back to jsDelivr CDN, validates file sizes, and sets appropriate executable permissions on Unix systems. It supports both ZIP (Windows) and tar.gz (Unix) archive formats with platform-specific extraction logic.
