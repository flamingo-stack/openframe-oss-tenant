A service for downloading and extracting GitHub release assets with automatic retry logic, CDN fallback, and cross-platform archive support.

## Key Components

- **`GithubDownloadService`** - Main service struct with HTTP client for downloading GitHub releases
- **`download_and_extract()`** - Downloads archive and extracts target binary with validation
- **`download_with_retry()`** - Implements retry logic with jsDelivr CDN fallback for rate limits
- **`extract_from_zip()`** - Extracts files from ZIP archives (Windows)
- **`extract_from_tar_gz()`** - Extracts files from tar.gz archives (Unix/Linux)
- **`find_config_for_current_os()`** - Selects appropriate download configuration for current platform
- **`download_and_save()`** - Downloads and saves tool agents with proper permissions

## Usage Example

```rust
use reqwest::Client;
use crate::github_download_service::GithubDownloadService;
use crate::models::download_configuration::DownloadConfiguration;

// Create service with HTTP client
let http_client = Client::new();
let download_service = GithubDownloadService::new(http_client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/app.tar.gz".to_string(),
    file_name: "app.tar.gz".to_string(),
    target_file_name: "app".to_string(),
    // ... other fields
};

let binary_bytes = download_service.download_and_extract(&config).await?;

// Or find config for current OS and download
let configs = vec![/* multiple platform configs */];
let current_config = download_service.find_config_for_current_os(&configs)?;
let executable_path = download_service.download_and_save(
    current_config,
    &tool_folder_path,
    &default_agent_path
).await?;
```

## Key Features

- **Automatic retry with exponential backoff** - Retries failed downloads up to configured limit
- **CDN fallback for rate limits** - Automatically switches to jsDelivr CDN when GitHub returns 429
- **Cross-platform archive support** - ZIP extraction on Windows, tar.gz on Unix/Linux
- **Binary validation** - Checks minimum file size for downloaded and extracted binaries
- **Proper file permissions** - Sets executable permissions on Unix systems
- **Timeout handling** - Configurable download timeouts with proper error handling
