A service for downloading and extracting GitHub release artifacts with fallback CDN support and platform-specific archive handling. Provides robust retry mechanisms and automatic executable permission setting for Unix systems.

## Key Components

- **`GithubDownloadService`** - Main service struct with HTTP client for downloading GitHub releases
- **`download_and_extract()`** - Downloads archives and extracts target binaries with validation
- **`download_with_retry()`** - Implements retry logic with jsDelivr CDN fallback on rate limits
- **`extract_from_zip()`** / **`extract_from_tar_gz()`** - Platform-specific archive extraction methods
- **`find_config_for_current_os()`** - Selects appropriate download configuration for current platform
- **`download_and_save()`** - Complete download workflow with file saving and permission handling

## Usage Example

```rust
use reqwest::Client;
use crate::github_download_service::GithubDownloadService;
use crate::models::download_configuration::DownloadConfiguration;

// Create service instance
let client = Client::new();
let service = GithubDownloadService::new(client);

// Configure download for specific release
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/app.tar.gz".to_string(),
    file_name: "app.tar.gz".to_string(),
    target_file_name: "app".to_string(),
    // ... other fields
};

// Download and extract binary
let binary_bytes = service.download_and_extract(&config).await?;

// Or download and save directly to filesystem
let executable_path = service.download_and_save(
    &config,
    &tool_folder_path,
    &default_agent_path
).await?;
```

The service automatically handles GitHub rate limiting by falling back to jsDelivr CDN, supports both ZIP (Windows) and tar.gz (Unix) archives, and includes comprehensive error handling with configurable retry attempts.
