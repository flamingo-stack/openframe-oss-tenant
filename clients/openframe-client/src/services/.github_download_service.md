Provides GitHub release download functionality with archive extraction and CDN fallback capabilities for cross-platform agent deployment. Handles ZIP and tar.gz archives with automatic retry logic and jsDelivr CDN fallback when GitHub rate limits are encountered.

## Key Components

- **GithubDownloadService** - Main service for downloading and extracting GitHub release assets
- **download_and_extract()** - Downloads and extracts binary from archive based on file extension
- **download_with_retry()** - Implements retry logic with timeout and CDN fallback for rate limits
- **extract_from_zip()** - ZIP extraction (Windows only)
- **extract_from_tar_gz()** - tar.gz extraction (non-Windows platforms)
- **github_to_cdn_url()** - Converts GitHub URLs to jsDelivr CDN URLs
- **find_config_for_current_os()** - Selects appropriate download config for current platform

## Usage Example

```rust
use reqwest::Client;
use crate::models::download_configuration::DownloadConfiguration;

// Create service with HTTP client
let client = Client::new();
let service = GithubDownloadService::new(client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/app.zip".to_string(),
    file_name: "app.zip".to_string(),
    target_file_name: "app.exe".to_string(),
    // ... other fields
};

let binary_bytes = service.download_and_extract(&config).await?;

// Find config for current OS
let configs = vec![/* your configurations */];
let current_config = service.find_config_for_current_os(&configs)?;
```

The service automatically handles GitHub rate limits by falling back to jsDelivr CDN, validates file sizes, and provides platform-specific archive extraction support.
