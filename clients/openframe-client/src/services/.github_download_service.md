A service for downloading and extracting GitHub release binaries with retry logic, rate limit fallback to jsDelivr CDN, and cross-platform archive support.

## Key Components

- **`GithubDownloadService`** - Main service struct with HTTP client
- **`download_and_extract()`** - Downloads and extracts binary from ZIP/tar.gz archives
- **`download_with_retry()`** - Implements retry logic with automatic CDN fallback on rate limits
- **`extract_from_zip()`** - ZIP extraction (Windows only)
- **`extract_from_tar_gz()`** - tar.gz extraction (Unix-like systems only)
- **`github_to_cdn_url()`** - Converts GitHub URLs to jsDelivr CDN URLs
- **`find_config_for_current_os()`** - Selects appropriate download configuration for current OS
- **`download_and_save()`** - Complete download and save workflow

## Usage Example

```rust
use reqwest::Client;
use crate::github_download_service::GithubDownloadService;
use crate::models::download_configuration::DownloadConfiguration;

// Create service
let http_client = Client::new();
let service = GithubDownloadService::new(http_client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/binary.zip".to_string(),
    file_name: "binary.zip".to_string(),
    target_file_name: "binary".to_string(),
    // ... other fields
};

let binary_bytes = service.download_and_extract(&config).await?;

// Or download and save to disk
let executable_path = service.download_and_save(
    &config,
    &tool_folder_path,
    &default_agent_path
).await?;
```

The service handles platform-specific archive formats (ZIP for Windows, tar.gz for Unix), implements exponential backoff retry logic, and automatically falls back to jsDelivr CDN when GitHub returns 429 rate limit errors.
