A service that downloads and extracts GitHub release binaries with automatic retry logic, rate limit fallback to jsDelivr CDN, and cross-platform archive support.

## Key Components

- **GithubDownloadService** - Main service struct with HTTP client for downloading GitHub releases
- **download_and_extract()** - Downloads archives and extracts target binaries with size validation
- **download_with_retry()** - Implements retry logic with exponential backoff and CDN fallback
- **extract_from_zip()** - ZIP archive extraction (Windows-specific)
- **extract_from_tar_gz()** - Tar.gz archive extraction (Unix-specific)
- **github_to_cdn_url()** - Converts GitHub URLs to jsDelivr CDN URLs for rate limit workarounds
- **find_config_for_current_os()** - Selects appropriate download configuration based on OS
- **download_and_save()** - High-level method for downloading and saving binaries to disk

## Usage Example

```rust
use reqwest::Client;
use crate::github_download_service::GithubDownloadService;
use crate::models::download_configuration::DownloadConfiguration;

// Initialize service
let http_client = Client::new();
let service = GithubDownloadService::new(http_client);

// Create download configuration
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/binary.tar.gz".to_string(),
    file_name: "binary.tar.gz".to_string(),
    target_file_name: "binary".to_string(),
    // ... other fields
};

// Download and extract binary
let binary_bytes = service.download_and_extract(&config).await?;

// Or download and save to disk
let executable_path = service.download_and_save(
    &config,
    &tool_folder_path,
    &default_agent_path
).await?;
```

The service handles GitHub rate limits automatically by falling back to jsDelivr CDN and supports both ZIP (Windows) and tar.gz (Unix) archive formats with proper executable permissions.
