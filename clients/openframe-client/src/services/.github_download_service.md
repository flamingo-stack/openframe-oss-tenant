A robust service for downloading, extracting, and installing agent binaries from GitHub releases with cross-platform support, retry logic, and CDN fallback for rate-limited scenarios.

## Key Components

- **`GithubDownloadService`** - Main service handling GitHub release downloads
- **`download_and_extract`** - Downloads and extracts binaries from ZIP/tar.gz archives
- **`download_with_retry`** - Implements retry logic with jsDelivr CDN fallback for rate limits
- **`extract_from_zip`** - Windows-specific ZIP extraction
- **`extract_from_tar_gz`** - Unix-specific tar.gz extraction  
- **`github_to_cdn_url`** - Converts GitHub URLs to jsDelivr CDN URLs
- **`find_config_for_current_os`** - Selects appropriate download config for current platform
- **`download_and_save`** - Complete download and file system installation

## Key Features

- **Cross-platform support** - ZIP extraction on Windows, tar.gz on Unix systems
- **Smart retry logic** - Exponential backoff with configurable attempts
- **Rate limit handling** - Automatic fallback to jsDelivr CDN when GitHub returns 429
- **Archive format detection** - Supports both ZIP and tar.gz based on file extension
- **Binary validation** - Enforces minimum file size requirements
- **Executable permissions** - Automatically sets execute permissions on Unix systems

## Usage Example

```rust
use reqwest::Client;
use crate::models::download_configuration::DownloadConfiguration;

// Initialize service
let client = Client::new();
let service = GithubDownloadService::new(client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/agent.tar.gz".to_string(),
    file_name: "agent.tar.gz".to_string(),
    target_file_name: "agent".to_string(),
    // ... other fields
};

let binary_bytes = service.download_and_extract(&config).await?;

// Or download and save directly to filesystem
let tool_path = Path::new("/usr/local/bin");
let agent_path = Path::new("/usr/local/bin/agent");
service.download_and_save(&config, tool_path, agent_path).await?;
```
