A service for downloading and extracting GitHub release binaries with retry logic and CDN fallback. Handles platform-specific archive formats (ZIP for Windows, tar.gz for Unix) and includes automatic rate limit detection with jsDelivr CDN failover.

## Key Components

- `GithubDownloadService` - Main service for downloading and extracting binary files
- `download_and_extract()` - Downloads archives and extracts target binaries
- `download_with_retry()` - Implements retry logic with timeout and CDN fallback
- `github_to_cdn_url()` - Converts GitHub URLs to jsDelivr CDN URLs for rate limit bypass
- `extract_from_zip()` / `extract_from_tar_gz()` - Platform-specific archive extraction
- `find_config_for_current_os()` - OS detection for download configuration selection

## Usage Example

```rust
use reqwest::Client;
use crate::models::download_configuration::DownloadConfiguration;

// Initialize service
let http_client = Client::new();
let service = GithubDownloadService::new(http_client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/binary.tar.gz".to_string(),
    file_name: "binary.tar.gz".to_string(),
    target_file_name: "binary".to_string(),
    // ... other fields
};

let binary_bytes = service.download_and_extract(&config).await?;

// Or find config for current OS and download
let configs = vec![/* ... configurations ... */];
let os_config = service.find_config_for_current_os(&configs)?;
let executable_path = service.download_and_save(
    os_config,
    &tool_folder,
    &default_path
).await?;
```

The service automatically handles GitHub API rate limits by falling back to jsDelivr CDN, validates file sizes, and sets appropriate executable permissions on Unix systems.
