A service for downloading, extracting, and managing GitHub releases with automatic fallback to CDN and platform-specific archive handling. Provides robust retry logic and supports both ZIP and tar.gz archives based on the target platform.

## Key Components

- **GithubDownloadService** - Main service struct with HTTP client for downloading GitHub releases
- **download_and_extract()** - Downloads and extracts binaries from archives with validation
- **download_with_retry()** - Implements retry logic with jsDelivr CDN fallback for rate limits
- **extract_from_zip()** - ZIP extraction (Windows platform)
- **extract_from_tar_gz()** - tar.gz extraction (Unix platforms)
- **find_config_for_current_os()** - OS-specific configuration selection
- **download_and_save()** - Complete download and save workflow

## Usage Example

```rust
use reqwest::Client;
use crate::github_download_service::GithubDownloadService;
use crate::models::download_configuration::DownloadConfiguration;

// Initialize service
let client = Client::new();
let service = GithubDownloadService::new(client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/tool.tar.gz".to_string(),
    file_name: "tool.tar.gz".to_string(),
    target_file_name: "tool".to_string(),
    os: "linux".to_string(),
    arch: "x86_64".to_string(),
};

let binary_bytes = service.download_and_extract(&config).await?;

// Save to disk with proper permissions
let tool_path = Path::new("/usr/local/bin");
service.download_and_save(&config, &tool_path, &tool_path.join("tool")).await?;
```

The service automatically handles GitHub rate limits by falling back to jsDelivr CDN, validates file sizes, and sets proper executable permissions on Unix systems.
