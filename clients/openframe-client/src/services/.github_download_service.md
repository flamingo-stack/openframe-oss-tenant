A service for downloading and extracting agent binaries from GitHub releases with retry logic and CDN fallback support. Handles both ZIP and tar.gz archives across different operating systems.

## Key Components

- **`GithubDownloadService`** - Main service struct with HTTP client for downloading files
- **`download_and_extract()`** - Downloads and extracts binary from archive based on configuration
- **`download_with_retry()`** - Implements retry logic with timeout and jsDelivr CDN fallback on rate limits
- **`extract_from_zip()`** - Platform-specific ZIP extraction (Windows only)
- **`extract_from_tar_gz()`** - Platform-specific tar.gz extraction (non-Windows)
- **`github_to_cdn_url()`** - Converts GitHub release URLs to jsDelivr CDN URLs
- **`find_config_for_current_os()`** - Selects appropriate download configuration for current OS

## Usage Example

```rust
use reqwest::Client;
use crate::github_download_service::GithubDownloadService;

// Create service with HTTP client
let client = Client::new();
let service = GithubDownloadService::new(client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/app.zip".to_string(),
    file_name: "app.zip".to_string(),
    target_file_name: "app.exe".to_string(),
    // ... other fields
};

let binary_bytes = service.download_and_extract(&config).await?;

// Find config for current OS
let configs = vec![/* your configurations */];
let os_config = service.find_config_for_current_os(&configs)?;
```

The service provides robust downloading with automatic retries, rate limit handling, and cross-platform archive extraction capabilities.
