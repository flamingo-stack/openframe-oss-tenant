A Rust service for downloading and extracting GitHub release binaries with retry logic, CDN fallback, and cross-platform archive support for MSP tool deployment.

## Key Components

- **`GithubDownloadService`** - Main service struct with HTTP client for downloading GitHub releases
- **`download_and_extract()`** - Downloads archives and extracts target binaries with size validation
- **`download_with_retry()`** - Implements retry logic with jsDelivr CDN fallback for rate limiting
- **`extract_from_zip()`** - Windows-specific ZIP archive extraction
- **`extract_from_tar_gz()`** - Unix/Linux tar.gz archive extraction
- **`find_config_for_current_os()`** - OS-specific configuration matching
- **`download_and_save()`** - Complete download workflow with file permissions

## Usage Example

```rust
use reqwest::Client;

// Initialize the service
let http_client = Client::new();
let service = GithubDownloadService::new(http_client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/app.tar.gz".to_string(),
    file_name: "app.tar.gz".to_string(),
    target_file_name: "app".to_string(),
    os_type: "linux".to_string(),
    arch: "x64".to_string(),
};

let binary_bytes = service.download_and_extract(&config).await?;

// Or save directly to filesystem
service.download_and_save(&config, &tool_folder, &default_path).await?;
```

The service automatically handles GitHub rate limiting by falling back to jsDelivr CDN, validates binary sizes, and sets proper executable permissions on Unix systems.
