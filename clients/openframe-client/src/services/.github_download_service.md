A service for downloading and extracting GitHub release binaries with retry logic, rate limiting fallbacks, and cross-platform archive support.

## Key Components

- **`GithubDownloadService`** - Main service struct with HTTP client for downloading binaries
- **`download_and_extract()`** - Downloads archives and extracts target binaries with validation
- **`download_with_retry()`** - Implements retry logic with jsDelivr CDN fallback for rate limits
- **`extract_from_zip()`** - ZIP extraction (Windows only)
- **`extract_from_tar_gz()`** - Tar.gz extraction (Unix/Linux only)
- **`github_to_cdn_url()`** - Converts GitHub URLs to jsDelivr CDN URLs
- **`find_config_for_current_os()`** - Selects appropriate download config for current platform
- **`download_and_save()`** - Downloads and saves binaries with proper permissions

## Usage Example

```rust
use reqwest::Client;
use crate::models::download_configuration::DownloadConfiguration;

// Create service
let client = Client::new();
let service = GithubDownloadService::new(client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/binary.tar.gz".to_string(),
    file_name: "binary.tar.gz".to_string(),
    target_file_name: "binary".to_string(),
    // ... other fields
};

let binary_bytes = service.download_and_extract(&config).await?;

// Or download and save directly
let tool_path = Path::new("/usr/local/bin");
let agent_path = Path::new("/usr/local/bin/agent");
service.download_and_save(&config, tool_path, agent_path).await?;
```

The service handles GitHub rate limiting by automatically falling back to jsDelivr CDN, validates file sizes, and sets proper executable permissions on Unix systems.
