A service for downloading and extracting GitHub release binaries with retry logic and CDN fallback support. Handles both ZIP and tar.gz archives across different platforms with automatic format detection.

## Key Components

- **GithubDownloadService**: Main service struct with HTTP client for downloads
- **download_and_extract()**: Downloads archive and extracts target binary with validation
- **download_with_retry()**: Retry mechanism with jsDelivr CDN fallback for rate limits
- **extract_from_zip()**: ZIP extraction (Windows-specific implementation)
- **extract_from_tar_gz()**: Tar.gz extraction (Unix-specific implementation)
- **find_config_for_current_os()**: OS-specific configuration selection
- **download_and_save()**: Complete download and file system persistence workflow

## Usage Example

```rust
use reqwest::Client;
use crate::models::download_configuration::DownloadConfiguration;

// Create service instance
let client = Client::new();
let service = GithubDownloadService::new(client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/binary.tar.gz".to_string(),
    file_name: "binary.tar.gz".to_string(),
    target_file_name: "binary".to_string(),
    // ... other fields
};

let binary_bytes = service.download_and_extract(&config).await?;

// Or download and save to filesystem
let tool_path = Path::new("/usr/local/bin");
let agent_path = Path::new("/usr/local/bin/agent");
let executable_name = service.download_and_save(&config, tool_path, agent_path).await?;
```

The service automatically handles platform-specific archive formats (ZIP for Windows, tar.gz for Unix) and includes robust error handling with configurable retry attempts and timeout settings.
