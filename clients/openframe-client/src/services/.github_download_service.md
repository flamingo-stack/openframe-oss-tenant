A service for downloading and extracting agent binaries from GitHub releases with automatic fallback to CDN and platform-specific archive handling.

## Key Components

- **GithubDownloadService** - Main service struct with HTTP client for downloading GitHub release assets
- **download_and_extract()** - Downloads and extracts binary from archive based on configuration
- **download_with_retry()** - Implements retry logic with jsDelivr CDN fallback for rate limits
- **extract_from_zip()** - Platform-specific ZIP extraction (Windows only)
- **extract_from_tar_gz()** - Platform-specific tar.gz extraction (Unix/Linux only)
- **find_config_for_current_os()** - Selects appropriate download configuration for current platform
- **download_and_save()** - Complete download and save workflow with executable permissions

## Usage Example

```rust
use reqwest::Client;
use crate::github_download_service::GithubDownloadService;
use crate::models::download_configuration::DownloadConfiguration;

// Initialize service
let client = Client::new();
let service = GithubDownloadService::new(client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/binary.zip".to_string(),
    file_name: "binary.zip".to_string(),
    target_file_name: "binary.exe".to_string(),
    // ... other fields
};

let binary_bytes = service.download_and_extract(&config).await?;

// Or find config for current OS and download
let configs = vec![/* download configurations */];
let config = service.find_config_for_current_os(&configs)?;
let executable_path = service.download_and_save(
    config, 
    &tool_folder_path, 
    &default_agent_path
).await?;
```

The service handles GitHub rate limits by automatically falling back to jsDelivr CDN, validates file sizes, and sets appropriate executable permissions on Unix systems.
