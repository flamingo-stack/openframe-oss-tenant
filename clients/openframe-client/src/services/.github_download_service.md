A Rust service that handles downloading and extracting GitHub release binaries with automatic fallback to jsDelivr CDN for rate-limited requests. It supports both ZIP and tar.gz archives with platform-specific extraction logic.

## Key Components

- **`GithubDownloadService`** - Main service struct that manages HTTP client and download operations
- **`download_and_extract()`** - Downloads and extracts binary from archive based on configuration
- **`download_with_retry()`** - Implements retry logic with exponential backoff and CDN fallback for rate limits
- **`extract_from_zip()` / `extract_from_tar_gz()`** - Platform-specific archive extraction methods
- **`github_to_cdn_url()`** - Converts GitHub release URLs to jsDelivr CDN URLs
- **`find_config_for_current_os()`** - Selects appropriate download configuration for the current platform
- **`download_and_save()`** - Complete download and save workflow with executable permissions

## Usage Example

```rust
use reqwest::Client;
use crate::models::download_configuration::DownloadConfiguration;

// Initialize the service
let http_client = Client::new();
let download_service = GithubDownloadService::new(http_client);

// Find configuration for current OS
let configs = vec![/* download configurations */];
let config = download_service.find_config_for_current_os(&configs)?;

// Download and extract binary
let binary_bytes = download_service.download_and_extract(config).await?;

// Or download and save to disk
let tool_path = Path::new("/usr/local/bin");
let agent_path = Path::new("/usr/local/bin/agent");
let executable_name = download_service
    .download_and_save(config, tool_path, agent_path)
    .await?;
```

The service automatically handles GitHub API rate limits by falling back to jsDelivr CDN and supports both single binary and folder extraction modes with proper executable permissions on Unix systems.
