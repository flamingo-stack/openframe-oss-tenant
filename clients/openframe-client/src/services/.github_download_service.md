Downloads and extracts agent binaries from GitHub releases with automatic fallback to jsDelivr CDN for rate limiting scenarios. Supports both ZIP and tar.gz archives with platform-specific extraction capabilities.

## Key Components

- **`GithubDownloadService`** - Main service for downloading and extracting binaries
- **`download_and_extract()`** - Downloads archive and extracts target binary
- **`download_with_retry()`** - Implements retry logic with timeout and CDN fallback
- **`github_to_cdn_url()`** - Converts GitHub URLs to jsDelivr CDN URLs
- **`extract_from_zip()`** - Windows-specific ZIP extraction
- **`extract_from_tar_gz()`** - Unix-specific tar.gz extraction
- **`find_config_for_current_os()`** - Selects appropriate download config for current platform

## Usage Example

```rust
use reqwest::Client;

// Initialize the service
let http_client = Client::new();
let service = GithubDownloadService::new(http_client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/tool.tar.gz".to_string(),
    file_name: "tool.tar.gz".to_string(),
    target_file_name: "tool".to_string(),
    // ... other fields
};

let binary_bytes = service.download_and_extract(&config).await?;

// Or download and save directly to disk
let tool_path = Path::new("/usr/local/bin");
let default_path = Path::new("/usr/local/bin/tool");
let executable_name = service.download_and_save(&config, tool_path, default_path).await?;
```

The service automatically handles GitHub rate limiting by falling back to jsDelivr CDN, validates file sizes, and sets proper executable permissions on Unix systems.
