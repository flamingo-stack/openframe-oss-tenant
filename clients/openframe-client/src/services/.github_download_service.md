Handles downloading and extracting GitHub release binaries with cross-platform support, retry logic, and CDN fallback for rate limiting.

## Key Components

- **`GithubDownloadService`** - Main service for downloading and extracting binaries from GitHub releases
- **`download_and_extract`** - Downloads archives and extracts target binaries with size validation
- **`download_with_retry`** - Implements retry logic with exponential backoff and jsDelivr CDN fallback for rate limits
- **`extract_from_zip`** - Platform-specific ZIP extraction (Windows)
- **`extract_from_tar_gz`** - Platform-specific tar.gz extraction (Unix/Linux)
- **`github_to_cdn_url`** - Converts GitHub release URLs to jsDelivr CDN URLs
- **`find_config_for_current_os`** - Finds appropriate download configuration for the current operating system

## Usage Example

```rust
use reqwest::Client;
use crate::models::download_configuration::DownloadConfiguration;
use crate::services::github_download_service::GithubDownloadService;

// Initialize the service
let client = Client::new();
let download_service = GithubDownloadService::new(client);

// Create download configuration
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0.0/binary.tar.gz".to_string(),
    file_name: "binary.tar.gz".to_string(),
    target_file_name: "binary".to_string(),
    // ... other fields
};

// Download and extract binary
match download_service.download_and_extract(&config).await {
    Ok(binary_bytes) => {
        println!("Downloaded {} bytes", binary_bytes.len());
        // Write to disk or process binary
    }
    Err(e) => eprintln!("Download failed: {}", e),
}

// Find OS-specific configuration
let configs = vec![config];
if let Ok(os_config) = download_service.find_config_for_current_os(&configs) {
    println!("Using config for current OS: {}", os_config.file_name);
}
```

The service automatically handles GitHub rate limiting by falling back to jsDelivr CDN, validates binary sizes, and provides platform-specific archive extraction with appropriate error handling and logging.
