A service for downloading and extracting GitHub release binaries with retry logic, rate limit fallback to jsDelivr CDN, and cross-platform archive support (ZIP for Windows, tar.gz for Unix-like systems).

## Key Components

- **GithubDownloadService** - Main service struct wrapping HTTP client
- **download_and_extract()** - Downloads archive and extracts target binary
- **download_with_retry()** - Retry mechanism with CDN fallback for rate limits
- **extract_from_zip()** - ZIP extraction (Windows only)
- **extract_from_tar_gz()** - Tar.gz extraction (Unix-like systems only)
- **github_to_cdn_url()** - Converts GitHub URLs to jsDelivr CDN URLs
- **find_config_for_current_os()** - Selects appropriate download configuration
- **download_and_save()** - Complete download and save workflow

## Usage Example

```rust
use reqwest::Client;
use crate::github_download_service::GithubDownloadService;
use crate::models::download_configuration::DownloadConfiguration;

// Create service with HTTP client
let client = Client::new();
let service = GithubDownloadService::new(client);

// Download and extract binary
let config = DownloadConfiguration::new(
    "https://github.com/owner/repo/releases/download/v1.0/app.tar.gz".to_string(),
    "app.tar.gz".to_string(),
    "app".to_string(),
);

let binary_bytes = service.download_and_extract(&config).await?;

// Or find config for current OS and download
let configs = vec![/* platform-specific configs */];
let current_config = service.find_config_for_current_os(&configs)?;
let executable_path = service.download_and_save(
    current_config,
    &tool_folder_path,
    &default_agent_path,
).await?;
```

The service automatically handles GitHub rate limits by falling back to jsDelivr CDN, validates binary sizes, and sets appropriate file permissions on Unix systems.
