A service for downloading and extracting GitHub release binaries with fallback mechanisms and cross-platform archive support. Handles ZIP and tar.gz archives, implements retry logic with rate limit detection, and includes jsDelivr CDN fallback for GitHub rate limiting.

## Key Components

- **`GithubDownloadService`** - Main service struct with HTTP client
- **`download_and_extract()`** - Downloads and extracts binary from archives
- **`download_with_retry()`** - Implements retry logic with timeout and CDN fallback
- **`github_to_cdn_url()`** - Converts GitHub URLs to jsDelivr CDN URLs
- **`extract_from_zip()`** - ZIP extraction (Windows only)
- **`extract_from_tar_gz()`** - tar.gz extraction (Unix/Linux only)
- **`find_config_for_current_os()`** - Selects appropriate download config for current OS
- **`download_and_save()`** - Downloads and saves binaries to filesystem with proper permissions

## Usage Example

```rust
use reqwest::Client;

let client = Client::new();
let service = GithubDownloadService::new(client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/binary.tar.gz".to_string(),
    file_name: "binary.tar.gz".to_string(),
    target_file_name: "binary".to_string(),
    // ... other fields
};

let binary_bytes = service.download_and_extract(&config).await?;

// Or download and save directly
let tool_path = Path::new("/usr/local/bin");
let agent_path = Path::new("/usr/local/bin/agent");
let executable_name = service.download_and_save(&config, tool_path, agent_path).await?;
```

The service automatically handles platform-specific archive formats, implements exponential backoff retry logic, and falls back to jsDelivr CDN when GitHub rate limits are encountered.
