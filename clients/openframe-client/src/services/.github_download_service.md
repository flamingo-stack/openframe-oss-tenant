A service for downloading and extracting GitHub release assets with automatic retry logic, CDN fallback for rate limits, and cross-platform archive extraction support.

## Key Components

- **GithubDownloadService**: Main service struct with HTTP client for downloading GitHub releases
- **download_and_extract()**: Downloads archives and extracts target binaries with size validation
- **download_with_retry()**: Implements retry logic with exponential backoff and jsDelivr CDN fallback for rate limits
- **extract_from_zip()**: ZIP archive extraction (Windows only)
- **extract_from_tar_gz()**: Tar.gz archive extraction (Unix/Linux only)
- **github_to_cdn_url()**: Converts GitHub release URLs to jsDelivr CDN URLs
- **find_config_for_current_os()**: Selects appropriate download configuration for current platform

## Usage Example

```rust
use reqwest::Client;
use crate::github_download_service::GithubDownloadService;

// Create service with HTTP client
let client = Client::new();
let service = GithubDownloadService::new(client);

// Download and extract binary from GitHub release
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/app.tar.gz".to_string(),
    file_name: "app.tar.gz".to_string(),
    target_file_name: "app".to_string(),
    // ... other fields
};

// Extract binary bytes
let binary_bytes = service.download_and_extract(&config).await?;

// Or download and save to disk
let executable_path = service.download_and_save(
    &config,
    &tool_folder_path,
    &default_agent_path
).await?;
```

The service automatically handles platform-specific archive formats, implements intelligent retry with CDN fallback for GitHub rate limits, and validates file sizes to ensure successful downloads.
