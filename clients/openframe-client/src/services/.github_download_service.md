A service for downloading and extracting agent binaries from GitHub releases with automatic retry logic and CDN fallback support.

## Key Components

- **`GithubDownloadService`** - Main service struct for handling GitHub downloads
- **`download_and_extract()`** - Downloads and extracts binaries from ZIP or tar.gz archives
- **`download_with_retry()`** - Implements retry logic with timeout and jsDelivr CDN fallback
- **`extract_from_zip()`** - Platform-specific ZIP extraction (Windows only)
- **`extract_from_tar_gz()`** - Platform-specific tar.gz extraction (Unix-like systems)
- **`github_to_cdn_url()`** - Converts GitHub URLs to jsDelivr CDN URLs for rate limit fallback
- **`find_config_for_current_os()`** - Selects appropriate download configuration for current OS
- **`download_and_save()`** - Complete download and save workflow with permission handling

## Usage Example

```rust
use reqwest::Client;
use crate::models::download_configuration::DownloadConfiguration;

// Initialize the service
let http_client = Client::new();
let service = GithubDownloadService::new(http_client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/app.zip".to_string(),
    file_name: "app.zip".to_string(),
    target_file_name: "app".to_string(),
    // ... other fields
};

let binary_bytes = service.download_and_extract(&config).await?;

// Or find config for current OS and download
let configs = vec![/* platform configs */];
let config = service.find_config_for_current_os(&configs)?;
let result = service.download_and_save(config, &tool_path, &agent_path).await?;
```

The service provides robust error handling, automatic retries with exponential backoff, and platform-specific archive extraction. It automatically falls back to jsDelivr CDN when GitHub API rate limits are encountered.
