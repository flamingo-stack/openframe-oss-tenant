Service for downloading and extracting tool binaries from GitHub releases with platform-specific handling, retry logic, and fallback to CDN when rate-limited.

## Key Components

- **`GithubDownloadService`** - Main service struct wrapping HTTP client
- **`download_and_extract()`** - Downloads archives and extracts specific binaries
- **`download_with_retry()`** - Implements retry logic with CDN fallback for rate limits
- **`extract_from_zip()`** - Platform-conditional ZIP extraction (Windows only)
- **`extract_from_tar_gz()`** - Platform-conditional tar.gz extraction (Unix only)
- **`github_to_cdn_url()`** - Converts GitHub URLs to jsDelivr CDN URLs
- **`find_config_for_current_os()`** - Selects appropriate download configuration
- **`download_and_save()`** - Complete download and save workflow

## Usage Example

```rust
use reqwest::Client;
use crate::github_download_service::GithubDownloadService;
use crate::models::download_configuration::DownloadConfiguration;

// Create service with HTTP client
let client = Client::new();
let service = GithubDownloadService::new(client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/tool.zip".to_string(),
    file_name: "tool.zip".to_string(),
    agent_file_name: "tool.exe".to_string(),
    // ... other fields
};

let binary_bytes = service.download_and_extract(&config).await?;

// Save to file system
let tool_path = Path::new("/path/to/tool");
service.download_and_save(&config, tool_path, &default_path).await?;
```

The service automatically handles platform differences (ZIP on Windows, tar.gz on Unix), implements exponential backoff retry logic, and falls back to jsDelivr CDN when GitHub API rate limits are hit.
