This service handles downloading and extracting tool binaries from GitHub releases with intelligent fallback mechanisms and cross-platform support.

## Key Components

- **`GithubDownloadService`** - Main service for downloading and extracting agent binaries from GitHub
- **`download_and_extract()`** - Downloads archive and extracts target binary with validation
- **`download_with_retry()`** - Implements retry logic with jsDelivr CDN fallback for rate limiting
- **`extract_from_zip()` / `extract_from_tar_gz()`** - Platform-specific archive extraction methods
- **`github_to_cdn_url()`** - Converts GitHub URLs to jsDelivr CDN URLs for fallback
- **`find_config_for_current_os()`** - Selects appropriate download configuration for current platform

## Usage Example

```rust
use reqwest::Client;
use crate::github_download_service::GithubDownloadService;
use crate::models::download_configuration::DownloadConfiguration;

// Create service with HTTP client
let client = Client::new();
let service = GithubDownloadService::new(client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/tool.zip".to_string(),
    file_name: "tool.zip".to_string(),
    target_file_name: "tool.exe".to_string(),
    // ... other config fields
};

let binary_bytes = service.download_and_extract(&config).await?;

// Or download and save to disk
let tool_path = service.download_and_save(
    &config,
    &tool_folder_path,
    &default_agent_path
).await?;
```

The service automatically handles GitHub rate limiting by falling back to jsDelivr CDN, validates file sizes, and provides platform-specific archive extraction (ZIP for Windows, tar.gz for Unix).
