A service for downloading and extracting agent binaries from GitHub releases with retry logic, rate limiting fallback to jsDelivr CDN, and platform-specific archive handling.

## Key Components

- **`GithubDownloadService`** - Main service struct with HTTP client for GitHub downloads
- **`download_and_extract()`** - Downloads archives and extracts target binaries with size validation
- **`download_with_retry()`** - Implements retry logic with exponential backoff and CDN fallback on rate limits
- **`extract_from_zip()`** - Windows-specific ZIP archive extraction (conditional compilation)  
- **`extract_from_tar_gz()`** - Unix-specific tar.gz archive extraction (conditional compilation)
- **`github_to_cdn_url()`** - Converts GitHub release URLs to jsDelivr CDN URLs for fallback
- **`find_config_for_current_os()`** - Selects appropriate download configuration for current platform
- **`download_and_save()`** - Complete download workflow with file system persistence

## Usage Example

```rust
use reqwest::Client;
use crate::github_download_service::GithubDownloadService;
use crate::models::download_configuration::DownloadConfiguration;

// Create service with HTTP client
let client = Client::new();
let service = GithubDownloadService::new(client);

// Download and extract binary
let config = DownloadConfiguration {
    link: "https://github.com/owner/repo/releases/download/v1.0/archive.tar.gz".to_string(),
    file_name: "archive.tar.gz".to_string(),
    target_file_name: "binary".to_string(),
    // ... other fields
};

let binary_bytes = service.download_and_extract(&config).await?;

// Or download and save to filesystem
let executable_path = service.download_and_save(
    &config, 
    &tool_folder_path, 
    &default_agent_path
).await?;
```
