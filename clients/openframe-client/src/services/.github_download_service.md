A service for downloading and extracting agent binaries from GitHub releases with retry logic, CDN fallback, and cross-platform archive support.

## Key Components

- **`GithubDownloadService`** - Main service struct with HTTP client
- **`download_and_extract()`** - Downloads and extracts binary from archive with validation
- **`download_with_retry()`** - Implements retry logic with jsDelivr CDN fallback on rate limits
- **`extract_from_zip()`** - Windows-specific ZIP extraction (conditional compilation)
- **`extract_from_tar_gz()`** - Unix-specific tar.gz extraction (conditional compilation)
- **`find_config_for_current_os()`** - OS-specific configuration selection
- **`download_and_save()`** - High-level download and save operation

## Usage Example

```rust
use reqwest::Client;
use crate::github_download_service::GithubDownloadService;
use crate::models::download_configuration::DownloadConfiguration;

// Create service with HTTP client
let client = Client::new();
let service = GithubDownloadService::new(client);

// Find configuration for current OS
let configs = vec![/* your download configurations */];
let config = service.find_config_for_current_os(&configs)?;

// Download and extract binary
let binary_bytes = service.download_and_extract(config).await?;

// Or download and save to filesystem
let tool_path = Path::new("/path/to/tool");
let agent_path = Path::new("/path/to/agent");
let executable_name = service.download_and_save(config, tool_path, agent_path).await?;
```

The service handles platform-specific archive formats (ZIP for Windows, tar.gz for Unix), implements automatic retry with exponential backoff, and falls back to jsDelivr CDN when GitHub rate limits are hit. Binary size validation ensures downloaded files meet minimum requirements.
