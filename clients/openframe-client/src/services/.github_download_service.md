This service handles downloading and extracting agent binaries from GitHub releases with robust error handling and platform-specific archive support. It provides automatic retry logic, rate limit fallbacks via jsDelivr CDN, and cross-platform file extraction capabilities.

## Key Components

- **`GithubDownloadService`** - Main service struct wrapping an HTTP client
- **`download_and_extract`** - Primary method that downloads archives and extracts target binaries
- **`download_with_retry`** - Implements retry logic with timeout and rate limit fallback to jsDelivr CDN
- **`extract_from_zip`** - Windows-specific ZIP archive extraction (conditional compilation)
- **`extract_from_tar_gz`** - Unix-specific tar.gz archive extraction (conditional compilation)
- **`find_config_for_current_os`** - Selects appropriate download configuration for current platform
- **`download_and_save`** - High-level method for downloading and saving binaries to disk

## Usage Example

```rust
use reqwest::Client;
use crate::models::download_configuration::DownloadConfiguration;

// Initialize the service
let client = Client::new();
let service = GithubDownloadService::new(client);

// Find configuration for current OS
let configs = vec![/* your download configurations */];
let config = service.find_config_for_current_os(&configs)?;

// Download and extract binary
let binary_bytes = service.download_and_extract(config).await?;

// Or download and save directly to disk
let tool_folder = Path::new("/path/to/tools");
let agent_path = Path::new("/path/to/agent");
let executable_name = service.download_and_save(config, tool_folder, agent_path).await?;
```

The service automatically handles platform differences (ZIP on Windows, tar.gz on Unix) and includes comprehensive error handling with size validation and permission setting for extracted executables.
