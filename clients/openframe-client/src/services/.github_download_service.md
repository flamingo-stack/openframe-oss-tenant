This service handles downloading, extracting, and installing binary agents from GitHub releases with platform-specific archive support, automatic retry logic, and CDN fallback capabilities.

## Key Components

- **`GithubDownloadService`** - Main service struct with HTTP client for downloading releases
- **`download_and_extract()`** - Downloads archives and extracts target binaries with size validation
- **`download_with_retry()`** - Implements retry logic with exponential backoff and jsDelivr CDN fallback on rate limits
- **`extract_from_zip()`** - Platform-conditional ZIP extraction (Windows only)
- **`extract_from_tar_gz()`** - Platform-conditional tar.gz extraction (Unix/Linux only)
- **`github_to_cdn_url()`** - Converts GitHub release URLs to jsDelivr CDN URLs for fallback
- **`find_config_for_current_os()`** - Selects appropriate download configuration for current platform

## Usage Example

```rust
use reqwest::Client;
use crate::github_download_service::GithubDownloadService;
use crate::models::download_configuration::DownloadConfiguration;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let client = Client::new();
    let service = GithubDownloadService::new(client);
    
    let configs = vec![/* download configurations */];
    let config = service.find_config_for_current_os(&configs)?;
    
    // Download and extract binary
    let binary_bytes = service.download_and_extract(config).await?;
    println!("Downloaded {} bytes", binary_bytes.len());
    
    // Or download and save directly to filesystem
    let tool_path = std::path::Path::new("./tools");
    let agent_path = std::path::Path::new("./agent");
    let executable_name = service.download_and_save(config, tool_path, agent_path).await?;
    
    Ok(())
}
```

The service automatically handles GitHub API rate limits by falling back to jsDelivr CDN, supports both ZIP (Windows) and tar.gz (Unix) archives, and includes comprehensive error handling with configurable timeouts and retries.
