This service handles the complete installation lifecycle of tools for the Flamingo AI-powered MSP platform, managing downloads from multiple sources, asset management, and process coordination.

## Key Components

- **`ToolInstallationService`** - Main service that orchestrates tool installation, asset downloads, and dependency management
- **`install()`** - Core installation method that handles tool downloads, version management, and executable setup
- **Asset Management** - Handles assets from three sources: Artifactory, Tool API, and GitHub repositories
- **Process Coordination** - Integrates with tool run managers, connection services, and kill services for complete lifecycle management
- **Cross-platform Support** - Handles OS-specific configurations and executable permissions for Windows and Unix systems

## Usage Example

```rust
use crate::services::tool_installation_service::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Create service with all dependencies
let installation_service = ToolInstallationService::new(
    github_service,
    file_client,
    api_client,
    command_resolver,
    url_resolver,
    tools_service,
    directory_manager,
    run_manager,
    connection_manager,
    config_service,
    publisher,
    connection_service,
);

// Install a tool with reinstall option
let install_message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: true,
    // ... other fields
};

installation_service.install(install_message).await?;
```

The service supports three asset sources: Artifactory for internal tools, Tool API for dynamic assets with URL parameter resolution, and GitHub for open-source tools with OS-specific download configurations.
