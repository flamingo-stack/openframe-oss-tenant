A service that orchestrates the complete tool installation lifecycle, including downloading assets, managing dependencies, and handling tool registration across multiple sources.

## Key Components

- **ToolInstallationService**: Main service struct with dependencies for GitHub downloads, file management, and tool lifecycle operations
- **install()**: Primary installation method that handles tool download, asset management, and registration
- **download_from_artifactory()**: Downloads tools from the internal artifactory service
- **set_executable_permissions()**: Sets appropriate file permissions for executable assets (Unix-specific)

## Usage Example

```rust
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a tool from an installation message
let tool_message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    assets: Some(vec![asset_config]),
    download_configurations: Some(download_configs),
    // ... other fields
};

installation_service.install(tool_message).await?;
```

The service supports multiple asset sources (GitHub, Artifactory, Tool API), handles reinstallation by cleaning up existing installations, manages file permissions appropriately per platform, and publishes installation events for tracking. It creates tool-specific directories and ensures proper cleanup during reinstalls by stopping running processes before removal.
