Orchestrates the complete tool installation process for Flamingo's AI-powered MSP platform. Handles downloading, extracting, and configuring tools from multiple sources including GitHub, Artifactory, and Tool API with support for cross-platform deployment.

## Key Components

### Main Service
- **`ToolInstallationService`** - Core service managing tool installation lifecycle with dependency injection of multiple specialized services

### Key Methods
- **`new()`** - Constructor initializing all service dependencies and ensuring directory structure
- **`install()`** - Main installation method handling download, extraction, permission setting, and configuration
- **`download_from_artifactory()`** - Downloads tool binaries from internal Artifactory repository
- **`set_executable_permissions()`** - Sets proper file permissions for executable assets (Unix-specific)

### Asset Management
- **Multi-source downloads** - GitHub releases, Artifactory, and Tool API endpoints
- **Cross-platform configuration** - OS-specific download configurations and file paths
- **Asset versioning** - Version tracking and reinstallation support
- **Permission handling** - Automatic executable permission setting for Unix systems

## Usage Example

```rust
use tool_installation_service::ToolInstallationService;
use models::ToolInstallationMessage;

// Initialize service with all dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a tool from installation message
let install_msg = ToolInstallationMessage {
    tool_agent_id: "monitoring-agent".to_string(),
    version: "1.2.3".to_string(),
    reinstall: false,
    // ... other configuration
};

installation_service.install(install_msg).await?;
```

The service handles the complete installation workflow including pre-installation cleanup for reinstalls, multi-source asset downloading with parameter resolution, cross-platform executable permission management, and integration with the broader tool management ecosystem through service notifications and tracking.
