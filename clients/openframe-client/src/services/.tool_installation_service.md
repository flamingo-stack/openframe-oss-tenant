A service that orchestrates the complete installation lifecycle of tools in the OpenFrame platform, handling downloads from multiple sources, dependency management, and runtime configuration.

## Key Components

- **ToolInstallationService**: Main service coordinating tool installation, uninstallation, and lifecycle management
- **install()**: Core method that handles the full installation process including version checks, asset downloads, and configuration
- **Multiple download sources**: Supports GitHub releases, Artifactory, and Tool API endpoints
- **Asset management**: Downloads and configures executable and non-executable assets with proper permissions
- **Reinstallation support**: Handles tool updates by cleanly removing existing installations

## Usage Example

```rust
use crate::services::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Initialize the service with required dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a tool with configuration
let tool_message = ToolInstallationMessage {
    tool_agent_id: "example-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other configuration fields
};

installation_service.install(tool_message).await?;
```

The service manages platform-specific installations, handles executable permissions on Unix systems, and integrates with the broader OpenFrame tool ecosystem for tracking and lifecycle management.
