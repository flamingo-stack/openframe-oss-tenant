This service orchestrates the complete tool installation process for the Flamingo MSP platform, handling downloads from multiple sources (GitHub, Artifactory, Tool API), managing file permissions, and coordinating with various other services to ensure tools are properly installed and configured.

## Key Components

- **`ToolInstallationService`** - Main service struct that coordinates tool installation workflow
- **`install()`** - Primary method that handles the complete installation process including:
  - Checking for existing installations and handling reinstalls
  - Creating tool directories
  - Downloading executables and assets from multiple sources
  - Setting file permissions
  - Managing tool lifecycle (stopping/starting processes)

## Usage Example

```rust
use crate::services::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Create service with all required dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a tool
let install_message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other fields
};

installation_service.install(install_message).await?;
```

The service supports downloading from GitHub releases, Artifactory, and Tool API sources, with automatic OS detection and executable permission handling. It integrates with the broader Flamingo ecosystem for tool lifecycle management and agent communication.
