This service orchestrates the complete tool installation process, handling downloads from multiple sources (GitHub, Artifactory, Tool API), managing dependencies, and coordinating with other services for tool lifecycle management.

## Key Components

**Main Service**: `ToolInstallationService` - Core installation orchestrator with dependency injection of 12+ specialized services
**Primary Method**: `install()` - Handles complete installation workflow including validation, download, asset management, and service coordination
**Asset Sources**: Support for GitHub releases, Artifactory, and Tool API downloads with OS-specific configurations
**File Management**: Executable permission setting, directory creation, and cross-platform file operations
**Integration Points**: Coordinates with tool run managers, connection services, and installation tracking

## Usage Example

```rust
use crate::services::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Service is typically injected with all dependencies
let installation_service = ToolInstallationService::new(
    github_service,
    file_client,
    api_client,
    /* ... other dependencies ... */
);

// Install a tool with version and configuration
let install_msg = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    download_configurations: Some(configs),
    assets: Some(assets),
    // ... other fields
};

// Execute installation
installation_service.install(install_msg).await?;
```

The service handles complex scenarios like reinstallation (stopping running processes, cleanup), multi-source asset downloads, OS-specific configurations, and maintains consistency across the tool management ecosystem through coordinated service interactions.
