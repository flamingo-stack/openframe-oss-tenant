Tool installation service that orchestrates the complete lifecycle of tool deployment including download, installation, and management of tool assets and dependencies.

## Key Components

- **ToolInstallationService**: Main service struct that coordinates tool installation operations
- **install()**: Primary method that handles the complete installation workflow
- **download_from_artifactory()**: Downloads tools from the internal artifactory
- **set_executable_permissions()**: Sets proper file permissions on Unix systems
- **Tool management dependencies**: Integrates with multiple services for download, tracking, and execution management

## Usage Example

```rust
use crate::services::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Initialize the service with required dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a tool
let install_message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other fields
};

installation_service.install(install_message).await?;
```

The service supports multiple asset sources (Artifactory, Tool API, GitHub), handles reinstallation scenarios by stopping existing processes, and manages cross-platform file permissions. It integrates with the broader tool ecosystem for process management, configuration, and messaging.
