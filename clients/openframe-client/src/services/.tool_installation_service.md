Orchestrates the full lifecycle of tool installation within the OpenFrame agent, handling new installs, reinstalls, and pre-install cleanup of existing tool processes and directories.

## Key Components

### `ToolInstallationService` (struct)
The primary service struct that coordinates all installation operations. It holds references to:
- `GithubDownloadService` — fetches release assets from GitHub
- `ToolAgentFileClient` / `ToolApiClient` — agent file and API communication
- `ToolCommandParamsResolver` / `ToolUrlParamsResolver` — resolve dynamic parameters for commands and URLs
- `InstalledToolsService` — reads/writes the local tool registry
- `DirectoryManager` — manages tool-specific filesystem paths
- `ToolRunManager` — tracks per-tool update/run state and provides per-tool mutexes
- `ToolConnectionProcessingManager` / `ToolConnectionService` — manages active tool connections
- `ToolKillService` — terminates running tool processes before reinstall
- `InstalledAgentMessagePublisher` — publishes post-install state changes
- `AgentConfigurationService` — reads agent-level configuration

### `install()` (public async method)
Entry point for handling a `ToolInstallationMessage`. Acquires a per-tool async lock and sets/clears an `updating` marker around the inner install logic, preventing concurrent operations on the same tool.

### `install_inner()` (private async method)
Core installation logic. Handles three paths:
1. **Reinstall** — stops the running process, optionally runs an uninstall command (with a `300s` timeout via `TOOL_COMMAND_TIMEOUT_SECS`), kills directory-locking processes, removes the tool directory, and clears connection state
2. **Repair** — detects a registry record with a missing binary and proceeds with re-download
3. **Skip** — returns early if the tool is already installed and the binary is present

### `TOOL_COMMAND_TIMEOUT_SECS`
Hard 300-second cap on external install/uninstall commands to prevent a hung installer from indefinitely blocking client self-updates.

## Usage Example

```rust
let svc = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

let msg = ToolInstallationMessage {
    tool_agent_id: "osquery".to_string(),
    version: "5.12.1".to_string(),
    reinstall: false,
    ..Default::default()
};

svc.install(msg).await?;
```
