This service handles the complete lifecycle of tool installation and management within the Flamingo platform. It coordinates downloading tools from multiple sources (GitHub, Artifactory, Tool API), manages local file systems, and integrates with various dependent services for tool execution and monitoring.

## Key Components

**Core Service**
- `ToolInstallationService` - Main orchestrator for tool installation, uninstallation, and asset management

**Primary Methods**
- `install()` - Downloads and installs tools with version control and reinstall support
- `new()` - Constructor that initializes all dependent services and ensures directory structure

**Asset Management**
- Downloads from multiple sources (GitHub releases, Artifactory, Tool API)
- Handles executable permissions on Unix systems
- Manages tool-specific directories and file paths
- Processes URL parameter resolution for dynamic asset paths

**Integration Points**
- Coordinates with `ToolRunManager`, `ToolKillService`, and connection services
- Publishes installation events via `InstalledAgentMessagePublisher`
- Uses `GithubDownloadService` for GitHub-hosted tools

## Usage Example

```rust
use crate::services::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Initialize the service with all dependencies
let installation_service = ToolInstallationService::new(
    github_service,
    file_client,
    api_client,
    command_resolver,
    url_resolver,
    installed_tools_service,
    directory_manager,
    run_manager,
    connection_manager,
    config_service,
    publisher,
    connection_service,
);

// Install a tool with version control
let install_msg = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other fields
};

installation_service.install(install_msg).await?;
```

The service automatically handles reinstallation scenarios by stopping existing processes, cleaning up directories, and downloading fresh assets while maintaining proper file permissions across platforms.
