This service orchestrates the complete tool installation lifecycle within the Flamingo/OpenFrame platform, handling downloads from multiple sources (GitHub, Artifactory, Tool API), managing tool lifecycle, and coordinating with various platform services.

## Key Components

### Core Structure
- **ToolInstallationService**: Main service with 12+ injected dependencies for comprehensive tool management
- **install()**: Primary installation method handling downloads, asset management, and service coordination
- **Platform-specific handling**: Cross-platform support with OS-specific configurations and permissions

### Key Dependencies
- **GithubDownloadService**: GitHub asset downloads and extraction
- **ToolAgentFileClient & ToolApiClient**: Multi-source asset retrieval
- **InstalledToolsService**: Tool state persistence and tracking
- **ToolRunManager & ToolConnectionProcessingManager**: Process lifecycle management
- **DirectoryManager**: Cross-platform file system operations

## Usage Example

```rust
// Service initialization with dependency injection
let installation_service = ToolInstallationService::new(
    github_service,
    file_client,
    api_client,
    command_resolver,
    url_resolver,
    installed_tools_service,
    directory_manager,
    run_manager,
    connection_manager,
    config_service,
    publisher,
    connection_service,
);

// Install tool with comprehensive configuration
let tool_message = ToolInstallationMessage {
    tool_agent_id: "monitoring-tool".to_string(),
    version: "1.2.0".to_string(),
    reinstall: false,
    download_configurations: Some(github_configs),
    assets: Some(tool_assets),
    run_command_args: Some(args),
    tool_id: "tool-123".to_string(),
};

// Execute installation with automatic cleanup and error handling
installation_service.install(tool_message).await?;
```

The service handles reinstallation scenarios by stopping existing processes, cleaning directories, and coordinating with tracking services to ensure clean state transitions.
