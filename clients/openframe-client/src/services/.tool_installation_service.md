A service that manages the complete lifecycle of tool installation, including downloading, dependency resolution, and deployment within the Flamingo MSP platform.

## Key Components

- **ToolInstallationService**: Main service orchestrating tool installation from multiple sources
- **install()**: Primary method handling tool installation with version management and reinstall capabilities
- **Asset Management**: Downloads and manages tool assets from GitHub, Artifactory, or Tool API sources
- **Directory Management**: Creates and manages tool-specific directories and file permissions
- **Dependency Resolution**: Resolves URL and command parameters for proper tool configuration

## Usage Example

```rust
use tool_installation_service::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Initialize the service with required dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a tool with configuration message
let tool_message = ToolInstallationMessage {
    tool_agent_id: "monitoring-agent".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other configuration
};

installation_service.install(tool_message).await?;
```

The service handles cross-platform compatibility, manages tool processes during reinstallation, sets appropriate file permissions, and integrates with the broader Flamingo tool ecosystem for MSP automation.
