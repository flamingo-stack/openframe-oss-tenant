Orchestrates the full lifecycle of tool installation for the Flamingo agent, handling download, configuration, process management, and registration of tools on the host system.

## Key Components

- **`ToolInstallationService`** — Main service struct holding all dependencies needed for tool lifecycle management, including download, process control, connection tracking, and configuration services.

- **`new()`** — Constructor that wires together all dependencies and ensures required directories exist on the filesystem before returning the service instance.

- **`install()`** — Primary async entry point. Handles the complete installation flow:
  - Checks if the tool is already installed (skips or reinstalls based on the `reinstall` flag)
  - Stops and removes existing installations before reinstalling
  - Handles special-case cleanup for Fleet/Orbit tooling
  - Resolves the correct OS-specific download configuration
  - Stops any leftover processes before downloading
  - Routes to either `install_from_download_config()` or `download_from_artifactory()`
  - Resolves the final executable path and builds the `Installation` variant (`Service`, `GuiApp`, or `Standard`)
  - Downloads and saves associated asset files

## Usage Example

```rust
let service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

let message = ToolInstallationMessage { /* ... */ };
service.install(message).await?;
```

> **Platform notes:** Unix targets apply executable permissions via `PermissionsExt`; Windows targets include file-lock diagnostics via `log_file_lock_info`.
