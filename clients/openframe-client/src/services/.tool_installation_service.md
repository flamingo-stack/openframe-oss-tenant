A service that manages the complete lifecycle of tool installations in the Flamingo platform, handling downloads from multiple sources (GitHub, Artifactory, Tool API), asset management, and executable permissions with cross-platform support.

## Key Components

- **ToolInstallationService**: Main service struct with dependencies for download clients, file management, and tool lifecycle operations
- **install()**: Primary method that orchestrates tool installation including version checks, directory setup, asset downloads, and permission handling
- **Asset Management**: Downloads and manages tool assets from multiple sources (GitHub, Artifactory, Tool API) with platform-specific configurations
- **Reinstallation Logic**: Handles tool uninstallation, process termination, and cleanup before fresh installation
- **Cross-platform Support**: Platform-specific file permissions and path handling for Unix and Windows systems

## Usage Example

```rust
use crate::services::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Create service with all required dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a new tool
let installation_message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other fields
};

installation_service.install(installation_message).await?;
```

The service automatically handles directory creation, asset downloads, executable permissions, and integrates with the broader tool management ecosystem including process monitoring and connection services.
