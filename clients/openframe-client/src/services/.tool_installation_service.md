This service orchestrates the complete tool installation process for the Flamingo AI-powered MSP platform, handling downloads from multiple sources (GitHub, Artifactory, Tool API), managing tool lifecycles, and coordinating with various dependent services.

## Key Components

### Main Service
- **`ToolInstallationService`** - Core installation orchestrator with dependency injection for all required services
- **`install()`** - Primary method that handles the complete installation workflow including reinstallation logic

### Installation Features
- **Multi-source downloads** - Supports GitHub releases, Artifactory, and Tool API asset downloads
- **Cross-platform executable handling** - Automatically sets executable permissions on Unix systems
- **Directory management** - Creates and manages tool-specific directories in app support folder
- **Asset processing** - Downloads and configures tool assets with proper permissions
- **Reinstallation support** - Handles tool updates by stopping processes, cleaning directories, and reinstalling

### Integration Points
- **Process management** - Integrates with `ToolKillService` and `ToolRunManager` for lifecycle control
- **Connection tracking** - Coordinates with `ToolConnectionService` and processing managers
- **Configuration resolution** - Uses parameter resolvers for command args and URL templating

## Usage Example

```rust
use crate::services::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Service is typically dependency-injected with all required clients
let installation_service = ToolInstallationService::new(
    github_service,
    file_client,
    api_client,
    // ... other dependencies
);

// Install a new tool
let install_message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other configuration
};

installation_service.install(install_message).await?;
```

The service handles platform-specific concerns like file permissions and provides comprehensive error handling with detailed context for troubleshooting installation failures.
