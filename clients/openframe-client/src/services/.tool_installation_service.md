A service responsible for managing the complete lifecycle of tool installation, including downloading, extracting, permissions, and dependency management. It orchestrates the installation process by coordinating with multiple services and handles both fresh installations and reinstallations.

## Key Components

- **ToolInstallationService** - Main service struct that coordinates tool installation across multiple subsystems
- **install()** - Primary method that handles the complete installation workflow
- **download_from_artifactory()** - Downloads tools from the artifactory repository
- **set_executable_permissions()** - Sets proper file permissions for executable files on Unix systems
- **publish_installed_tool()** - Publishes installation status messages to tracking services

## Dependencies

The service integrates with numerous other services:
- GitHub download service for repository-based tools
- Tool API client for runtime tool management
- Directory manager for file system operations
- Installation tracking and agent configuration services
- Tool runtime management (start, stop, kill operations)

## Usage Example

```rust
// Initialize the installation service with all dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a tool from a message
let tool_message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other fields
};

installation_service.install(tool_message).await?;
```

## Installation Process

1. **Pre-installation checks** - Validates existing installations and handles reinstallation logic
2. **Directory setup** - Creates tool-specific directories in the app support folder
3. **Asset downloading** - Downloads executables and assets from various sources (GitHub, Artifactory, Tool API)
4. **Permission management** - Sets executable permissions on Unix systems
5. **Service registration** - Updates installed tools registry and publishes status messages
