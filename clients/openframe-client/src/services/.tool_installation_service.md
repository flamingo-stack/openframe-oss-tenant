A service responsible for managing tool installations, including downloading, configuring, and setting up tools from various sources like GitHub, Artifactory, and Tool API. It handles the complete lifecycle of tool installation including directory management, asset downloads, and executable permissions.

## Key Components

**Main Service:**
- `ToolInstallationService` - Core installation orchestrator with dependency injection for all required services

**Primary Methods:**
- `new()` - Constructor that initializes the service and ensures required directories exist
- `install()` - Main installation method that processes `ToolInstallationMessage` requests

**Key Features:**
- Multi-source asset downloading (GitHub, Artifactory, Tool API)
- Tool reinstallation with process cleanup
- Cross-platform executable permissions handling
- Directory and file management
- Installation status tracking and publishing

## Usage Example

```rust
// Initialize the service with required dependencies
let installation_service = ToolInstallationService::new(
    github_service,
    file_client,
    api_client,
    command_resolver,
    url_resolver,
    installed_tools_service,
    directory_manager,
    run_manager,
    connection_manager,
    config_service,
    message_publisher,
    connection_service,
);

// Install a tool from a message
let install_message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other fields
};

installation_service.install(install_message).await?;
```

The service automatically handles:
- Creating tool-specific directories
- Downloading executables and assets from configured sources  
- Setting appropriate file permissions
- Managing reinstallations by cleaning up existing processes
- Publishing installation status messages
