Orchestrates the full lifecycle of tool installation for the Flamingo agent, handling download, configuration, filesystem setup, process management, and registration of installed tools.

## Key Components

- **`ToolInstallationService`** — Main service struct holding references to all dependent services (download, kill, connection, configuration, etc.)
- **`new()`** — Constructor that initializes the service and ensures required directories exist via `DirectoryManager`
- **`install()`** — Primary async entry point that drives the full installation flow:
  - Checks for existing installations and handles reinstall logic (stop → clean → delete)
  - Resolves OS-specific `DownloadConfiguration` from GitHub or Artifactory
  - Stops any leftover processes before downloading
  - Installs via `install_from_download_config()` or `download_from_artifactory()`
  - Resolves executable path and builds the `Installation` variant (`Service`, `GuiApp`, or `Standard`)
  - Downloads and saves associated assets

## Usage Example

```rust
let service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

let message = ToolInstallationMessage {
    tool_agent_id: "fleet-agent".to_string(),
    version: "1.2.3".to_string(),
    reinstall: false,
    ..Default::default()
};

service.install(message).await?;
```

## Notes

- On reinstall, the service stops the running process, removes the tool directory, clears connection/run tracking, and handles Fleet/Orbit-specific cleanup
- Installation type (`Service`, `GuiApp`, `Standard`) is derived from `DownloadConfiguration` and determines how stop/start is handled
- Windows file lock diagnostics and Unix permission setting are conditionally compiled via `#[cfg]` attributes
