This service orchestrates the complete tool installation process for Flamingo's MSP platform. It handles downloading, extracting, configuring, and managing the lifecycle of MSP tools from various sources including GitHub, Artifactory, and Tool APIs.

## Key Components

- **ToolInstallationService** - Main service coordinating tool installation and management
- **install()** - Primary method handling the complete installation workflow
- **download_from_artifactory()** - Downloads tools from Flamingo's artifact repository
- **set_executable_permissions()** - Sets proper file permissions on Unix systems
- Multiple service dependencies for GitHub downloads, file operations, and tool management

## Usage Example

```rust
use crate::services::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Create service with all required dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a tool
let install_message = ToolInstallationMessage {
    tool_agent_id: "monitoring-agent".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other configuration
};

installation_service.install(install_message).await?;
```

The service supports multiple asset sources (GitHub, Artifactory, Tool API), handles reinstallation by stopping existing processes, manages file permissions, and integrates with Flamingo's broader tool management ecosystem. It ensures proper cleanup during reinstallation and publishes status messages for installed tools.
