This service orchestrates the complete installation lifecycle of tools within the Flamingo AI platform, handling downloads from multiple sources (GitHub, Artifactory, Tool API), asset management, and process coordination.

## Key Components

- **ToolInstallationService**: Main service struct managing tool installation workflow
- **install()**: Core method handling tool installation, reinstallation, and asset management
- **Multiple service dependencies**: Integrates with 12+ specialized services for different aspects of installation
- **Cross-platform support**: Handles OS-specific configurations and file permissions
- **Asset management**: Downloads and manages executable and non-executable assets from various sources

## Usage Example

```rust
use crate::services::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Create service with all required dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    // ... other dependencies
);

// Install a tool
let tool_message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other fields
};

installation_service.install(tool_message).await?;
```

The service handles complex scenarios like reinstallation (stopping processes, cleaning directories), asset downloading from multiple sources, setting executable permissions, and coordinating with other platform services to maintain tool state consistency.
