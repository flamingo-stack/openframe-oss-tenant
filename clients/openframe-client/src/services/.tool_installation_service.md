Service responsible for installing and managing tools from various sources (GitHub, Artifactory, Tool API) including asset download, executable permissions, and tool lifecycle management.

## Key Components

- **ToolInstallationService**: Main service struct that orchestrates tool installation
- **install()**: Core method that handles complete tool installation workflow
- **download_from_artifactory()**: Downloads tools from Artifactory source
- **set_executable_permissions()**: Sets proper file permissions for executables
- Multiple injected services for GitHub downloads, file management, tool tracking, and configuration

## Usage Example

```rust
// Create the service with all dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a tool
let installation_message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other fields
};

installation_service.install(installation_message).await?;
```

The service handles complex installation scenarios including:
- Checking for existing installations and managing reinstalls
- Downloading from multiple sources (GitHub releases, Artifactory, Tool API)
- Asset management with proper executable permissions
- Cross-platform directory and file handling
- Tool process lifecycle management during reinstallation
- Integration with tracking services for installed tools
