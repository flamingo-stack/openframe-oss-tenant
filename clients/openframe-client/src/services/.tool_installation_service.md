Core orchestration service responsible for installing, managing, and configuring MSP tools within the Flamingo/OpenFrame platform. It handles downloads from multiple sources (GitHub, Artifactory, Tool API), manages file permissions, and coordinates with other services for complete tool lifecycle management.

## Key Components

- **ToolInstallationService**: Main service with dependency injection for all required clients and services
- **install()**: Primary method that orchestrates the complete tool installation process
- **download_from_artifactory()**: Downloads tool binaries from internal Artifactory
- **set_executable_permissions()**: Platform-specific permission setting for executable files
- Multiple client integrations: GitHub downloads, file clients, API clients, and tool management services

## Usage Example

```rust
// Initialize the service with all dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a tool from a message
let installation_message = ToolInstallationMessage {
    tool_agent_id: "network-scanner".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other fields
};

installation_service.install(installation_message).await?;
```

The service supports multiple asset sources (GitHub releases, Artifactory, Tool API), handles reinstallation scenarios by stopping existing processes and cleaning up directories, and manages cross-platform executable permissions. It integrates with the broader tool management ecosystem to track installations and coordinate with running tool instances.
