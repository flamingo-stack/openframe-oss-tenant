This service manages the complete lifecycle of tool installation, including downloading, asset management, and process control for the OpenFrame AI platform.

## Key Components

- **ToolInstallationService**: Main orchestrator for tool installation operations
- **install()**: Core installation method handling download, configuration, and asset management
- **Dependencies**: Integrates with 11+ services including GitHub downloads, tool API client, and process management
- **Asset Management**: Downloads and configures executable assets from multiple sources (Artifactory, Tool API, GitHub)
- **Reinstallation Support**: Handles tool updates by stopping processes and cleaning directories

## Usage Example

```rust
use tool_installation_service::ToolInstallationService;
use models::ToolInstallationMessage;

// Initialize service with all dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a tool
let installation_message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other configuration
};

installation_service.install(installation_message).await?;
```

The service handles cross-platform executable permissions, manages tool directories, and coordinates with multiple backend services to ensure reliable tool deployment across the OpenFrame ecosystem.
