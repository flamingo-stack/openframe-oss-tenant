This service manages the complete lifecycle of tool installation in the Flamingo MSP platform, handling downloads from multiple sources (GitHub, Artifactory, Tool API), asset management, and reinstallation workflows.

## Key Components

- **ToolInstallationService** - Main service orchestrating tool installation processes
- **install()** - Primary method handling tool installation with support for reinstallation
- **download_from_artifactory()** - Downloads tool agents from Artifactory source
- **set_executable_permissions()** - Sets proper file permissions for executable assets (Unix-only)
- Multiple service dependencies for GitHub downloads, file management, tool lifecycle, and configuration

## Usage Example

```rust
use tool_installation_service::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Create service with all required dependencies
let installation_service = ToolInstallationService::new(
    github_service,
    file_client,
    api_client,
    command_resolver,
    url_resolver,
    installed_tools_service,
    directory_manager,
    run_manager,
    connection_manager,
    config_service,
    publisher,
    connection_service,
);

// Install a tool
let message = ToolInstallationMessage {
    tool_agent_id: "sample-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other fields
};

installation_service.install(message).await?;
```

The service supports multi-platform installations, handles asset dependencies, manages tool directories, and integrates with the broader Flamingo tool ecosystem for automated MSP operations.
