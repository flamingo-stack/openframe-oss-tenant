This service orchestrates the complete installation lifecycle for MSP tools, handling downloads from multiple sources (GitHub, Artifactory, Tool API), managing executable permissions, and coordinating with other system services for process management.

## Key Components

- **install()** - Main installation method that handles tool downloads, asset management, and service coordination
- **download_from_artifactory()** - Downloads tool binaries from internal Artifactory repository
- **set_executable_permissions()** - Sets proper file permissions for executable assets (Unix/Windows compatible)
- **Multiple service dependencies** - Integrates with GitHub downloads, tool management, process control, and messaging services

## Usage Example

```rust
use crate::services::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Create service with all required dependencies
let installation_service = ToolInstallationService::new(
    github_service,
    file_client,
    api_client,
    command_resolver,
    url_resolver,
    installed_tools_service,
    directory_manager,
    run_manager,
    connection_manager,
    config_service,
    publisher,
    connection_service,
);

// Install or reinstall a tool
let install_message = ToolInstallationMessage {
    tool_agent_id: "monitoring-agent".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other fields
};

installation_service.install(install_message).await?;
```

The service handles cross-platform installations, manages tool lifecycles including reinstallation scenarios, and ensures proper cleanup of existing processes and directories during updates.
