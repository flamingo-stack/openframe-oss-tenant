Orchestrates the full lifecycle of tool installation for the Flamingo agent platform, handling downloading, configuring, and registering tools from multiple asset sources (Artifactory, GitHub, Tool API) with support for reinstallation and cross-platform execution.

## Key Components

### `ToolInstallationService`

The primary struct managing all tool installation operations. Depends on a rich set of injected services:

| Field | Responsibility |
|---|---|
| `GithubDownloadService` | Fetches release binaries from GitHub |
| `ToolAgentFileClient` | Downloads files from Artifactory |
| `ToolApiClient` | Fetches assets from the Tool API |
| `InstalledToolsService` | Tracks installed tool registry |
| `ToolRunManager` | Manages running tool processes |
| `ToolKillService` | Stops running tool processes on reinstall |
| `DirectoryManager` | Resolves and creates tool-specific paths |
| `AgentConfigurationService` | Provides agent configuration context |

### Key Methods

- **`new()`** — Constructs the service and ensures required directories exist at startup.
- **`install()`** — Primary entrypoint. Accepts a `ToolInstallationMessage` and orchestrates the full install flow:
  - Skips if already installed (unless `reinstall: true`)
  - On reinstall: kills process, removes directory, clears registry entries
  - Resolves OS-specific download config and version overrides
  - Falls back to Artifactory if no `download_configurations` present
  - Downloads and saves asset files per-source (`Artifactory`, `ToolApi`, `Github`)
  - Builds final `Installation` record and registers the tool

## Usage Example

```rust
let service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

let message = ToolInstallationMessage {
    tool_agent_id: "my-tool".into(),
    version: "1.2.3".into(),
    reinstall: false,
    ..Default::default()
};

service.install(message).await?;
```

> **Note:** On Unix targets, executable permissions are set automatically post-download. On Windows, file lock diagnostics are logged during reinstall.
