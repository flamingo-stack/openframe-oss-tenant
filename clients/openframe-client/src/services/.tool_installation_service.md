A comprehensive service for managing tool installation lifecycle including download, deployment, and configuration in the Flamingo MSP platform.

## Key Components

- **ToolInstallationService** - Main service orchestrating tool installation from multiple sources (GitHub, Artifactory, Tool API)
- **install()** - Core installation method handling version management, reinstalls, and asset deployment
- **Platform Integration** - Cross-platform executable permissions and directory management
- **Asset Management** - Downloads and configures tool assets with proper permissions
- **Service Dependencies** - Integrates with 12+ specialized services for complete tool lifecycle management

## Usage Example

```rust
use crate::services::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Create service with all dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a tool with version management
let install_message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other configuration
};

installation_service.install(install_message).await?;
```

The service handles complex installation scenarios including:
- **Reinstall Logic** - Safely stops running processes and cleans up before reinstalling
- **Multi-Source Downloads** - GitHub releases, Artifactory, and Tool API assets
- **Cross-Platform Support** - Automatic OS detection and executable permissions
- **Asset Management** - Downloads and configures tool dependencies with proper file permissions
- **Service Coordination** - Integrates with connection managers, kill services, and publishers for complete tool lifecycle management
