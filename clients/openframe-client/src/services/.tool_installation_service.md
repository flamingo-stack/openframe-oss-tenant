A service responsible for handling the complete lifecycle of tool installation, including downloading from multiple sources, managing assets, and coordinating with other system services.

## Key Components

**Main Service Structure:**
- `ToolInstallationService` - Core service with dependency injection for file clients, downloaders, and managers
- `install()` - Primary method handling tool installation workflow with reinstall support
- Multi-source asset downloading (Artifactory, Tool API, GitHub)
- Cross-platform executable permission management

**Key Dependencies:**
- `GithubDownloadService`, `ToolAgentFileClient`, `ToolApiClient` - Download sources
- `InstalledToolsService`, `ToolRunManager` - Tool lifecycle management  
- `DirectoryManager` - File system organization
- `ToolKillService` - Process termination during reinstalls

## Usage Example

```rust
let installation_service = ToolInstallationService::new(
    github_service,
    file_client,
    api_client,
    command_resolver,
    url_resolver,
    installed_service,
    directory_manager,
    run_manager,
    processing_manager,
    config_service,
    publisher,
    connection_service,
);

// Install or reinstall a tool
let message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: true,
    download_configurations: Some(configs),
    assets: Some(assets),
    // ... other fields
};

installation_service.install(message).await?;
```

The service handles complex installation scenarios including stopping running processes during reinstalls, downloading from multiple asset sources (GitHub releases, Artifactory, Tool API), setting proper file permissions cross-platform, and coordinating with tool managers to prevent conflicts.
