A service that handles comprehensive tool installation, management, and lifecycle operations within the Flamingo MSP platform. It orchestrates tool downloads from multiple sources, manages directories, and coordinates with various platform services to ensure proper tool deployment.

## Key Components

- **ToolInstallationService** - Main service struct with dependency injection for all required services
- **install()** - Core installation method handling tool download, setup, and asset management
- **download_from_artifactory()** - Downloads tools from the artifactory client
- **set_executable_permissions()** - Platform-specific permission setting for executable files
- **Service Dependencies** - Integrates with GitHub downloads, tool APIs, directory management, and process management

## Usage Example

```rust
use tool_installation_service::ToolInstallationService;
use models::ToolInstallationMessage;

// Initialize service with dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a tool with configuration
let tool_message = ToolInstallationMessage {
    tool_agent_id: "sample-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other fields
};

// Execute installation
installation_service.install(tool_message).await?;
```

The service supports tool reinstallation, asset management from multiple sources (Artifactory, Tool API, GitHub), and handles platform-specific executable permissions. It integrates with the broader Flamingo ecosystem for process management and tool lifecycle tracking.
