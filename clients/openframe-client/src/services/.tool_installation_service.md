This service orchestrates the complete tool installation lifecycle for the Flamingo MSP platform. It handles downloading tools from multiple sources (GitHub, Artifactory, Tool API), managing assets, setting permissions, and coordinating with various platform services.

## Key Components

- **`ToolInstallationService`** - Main service struct that coordinates tool installation across multiple sources and manages the complete installation workflow
- **`install()`** - Primary method that handles the full installation process including reinstallation, asset management, and service coordination
- **Asset Management** - Downloads and manages tool assets with proper permissions and OS-specific configurations
- **Multi-source Downloads** - Supports GitHub releases, Artifactory, and Tool API as download sources
- **Service Integration** - Coordinates with tool management services for tracking, execution, and connection handling

## Usage Example

```rust
use crate::services::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Create installation service with dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a tool
let install_message = ToolInstallationMessage {
    tool_agent_id: "example-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other fields
};

installation_service.install(install_message).await?;
```

The service handles complex scenarios like reinstallation (stopping processes, cleaning directories), cross-platform compatibility, and asset management with proper executable permissions on Unix systems.
