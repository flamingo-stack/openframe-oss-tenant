This service orchestrates the complete installation, management, and lifecycle of tools within the Flamingo/OpenFrame platform. It handles downloading tool executables and assets from multiple sources (GitHub, Artifactory, Tool API), managing installed tool state, and coordinating with other services for tool execution and connection management.

## Key Components

- **ToolInstallationService**: Main service orchestrating tool installation and management
- **install()**: Core method handling tool installation, including reinstallation logic
- **download_from_artifactory()**: Downloads tool executables from Artifactory
- **set_executable_permissions()**: Sets proper file permissions for executable assets
- **Multiple client integrations**: Works with GitHub, Artifactory, and Tool API clients
- **Asset management**: Downloads and manages tool assets with proper permissions
- **Service coordination**: Integrates with tool run manager, connection services, and kill service

## Usage Example

```rust
use crate::services::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Create service with all dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a tool
let tool_message = ToolInstallationMessage {
    tool_agent_id: "example-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other fields
};

installation_service.install(tool_message).await?;
```

The service handles complex scenarios like reinstallation (stopping running processes, cleaning directories), asset management from multiple sources, and cross-platform executable permissions. It maintains tool state consistency across the entire OpenFrame platform ecosystem.
