This service manages the complete lifecycle of tool installation and management within the Flamingo platform. It handles downloading, extracting, setting up permissions, and managing the installation state of tools from various sources including GitHub, Artifactory, and Tool API endpoints.

## Key Components

- **ToolInstallationService**: Main service orchestrating tool installation operations
- **install()**: Primary method handling tool installation with support for reinstallation
- **download_from_artifactory()**: Downloads tools from Artifactory when no GitHub config exists
- **set_executable_permissions()**: Platform-specific permission handling for executable files
- **Asset Management**: Downloads and configures tool assets from multiple sources (GitHub, Artifactory, Tool API)
- **Directory Management**: Creates and manages tool-specific directory structures
- **Process Management**: Handles stopping existing tool processes during reinstallation

## Usage Example

```rust
use crate::services::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Initialize the service with required dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a tool with configuration
let tool_message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other configuration
};

installation_service.install(tool_message).await?;
```

The service supports cross-platform installation with automatic OS detection, handles concurrent installations safely, and provides comprehensive error handling with detailed context for troubleshooting installation issues.
