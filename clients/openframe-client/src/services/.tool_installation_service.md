Orchestrates the complete tool installation lifecycle for Flamingo's MSP platform. This service handles downloading, installing, and managing tools from multiple sources including GitHub, Artifactory, and Tool API endpoints.

## Key Components

- **`ToolInstallationService`** - Main service coordinating tool installation operations
- **`install()`** - Primary method handling complete tool installation workflow
- **Asset management** - Downloads and configures tool assets with proper permissions
- **Reinstallation logic** - Handles tool updates and reinstalls with proper cleanup
- **Cross-platform support** - Manages OS-specific configurations and file permissions

## Usage Example

```rust
use crate::services::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Create installation service with all dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a tool from installation message
let installation_message = ToolInstallationMessage {
    tool_agent_id: "monitoring-agent".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other fields
};

installation_service.install(installation_message).await?;
```

The service automatically handles directory creation, asset downloading from multiple sources, executable permission setting, and integration with Flamingo's tool management ecosystem. It supports reinstallation workflows that properly clean up existing installations before deploying new versions.
