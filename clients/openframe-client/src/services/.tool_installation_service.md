This service orchestrates the complete tool installation lifecycle for Flamingo's MSP platform, handling downloads from multiple sources (GitHub, Artifactory, Tool API), asset management, and process lifecycle coordination.

## Key Components

- **ToolInstallationService**: Main service coordinating tool installation operations
- **install()**: Core installation method handling tool download, asset management, and process coordination
- **Asset Management**: Supports GitHub releases, Artifactory, and Tool API asset sources
- **Process Lifecycle**: Integrates with kill service, run manager, and connection processing
- **Cross-Platform Support**: Handles executable permissions on Unix systems and directory management

## Dependencies

The service integrates with multiple specialized services:
- `GithubDownloadService` for GitHub release downloads
- `InstalledToolsService` for tool state tracking
- `ToolKillService` for process termination
- `DirectoryManager` for secure file system operations
- Various resolvers for command and URL parameter processing

## Usage Example

```rust
let service = ToolInstallationService::new(
    github_service,
    file_client,
    api_client,
    command_resolver,
    url_resolver,
    installed_tools_service,
    directory_manager,
    run_manager,
    connection_manager,
    config_service,
    publisher,
    connection_service,
);

// Install a tool with assets
let install_msg = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    assets: Some(vec![/* asset definitions */]),
    // ... other fields
};

service.install(install_msg).await?;
```

The service handles reinstallation by stopping existing processes, cleaning up directories, and performing fresh installations while maintaining proper process coordination across the platform.
