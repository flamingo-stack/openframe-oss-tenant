This service orchestrates the complete tool installation lifecycle for the Flamingo MSP platform, handling downloads, file management, process control, and dependency resolution. It integrates with multiple backend services to provide automated tool deployment and management capabilities.

## Key Components

- **ToolInstallationService** - Main orchestrator with 12 injected service dependencies
- **install()** - Core installation method handling tool lifecycle management
- **download_from_artifactory()** - Artifactory-based tool retrieval 
- **set_executable_permissions()** - Cross-platform file permission management
- **Asset management** - Handles multiple asset sources (GitHub, Artifactory, Tool API)
- **Process control** - Integrates with kill and connection services for tool lifecycle

## Usage Example

```rust
use tool_installation_service::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Initialize with all required dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install or reinstall a tool
let tool_message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other fields
};

installation_service.install(tool_message).await?;
```

The service handles complex scenarios including reinstallation (process termination, cleanup, restart), multi-source asset downloads with OS-specific configurations, and cross-platform executable permissions. It integrates deeply with the Flamingo ecosystem's tool management infrastructure.
