This service manages the complete lifecycle of tool installation for the Flamingo MSP platform agent system, including downloading, asset management, and process coordination.

## Key Components

**Main Service:**
- `ToolInstallationService` - Core service orchestrating tool installation workflow
- `install()` - Primary method handling tool installation, reinstallation, and asset management

**Key Dependencies:**
- `GithubDownloadService` - Downloads tools from GitHub releases
- `ToolAgentFileClient` - Downloads from internal artifactory
- `ToolApiClient` - Downloads from tool-specific APIs
- `InstalledToolsService` - Manages installed tool registry
- `ToolRunManager` & `ToolKillService` - Process lifecycle management
- `DirectoryManager` - Handles file system paths and directory structure

**Asset Management:**
- Multi-source asset downloading (GitHub, Artifactory, Tool API)
- Platform-specific executable permission handling
- URL parameter resolution for dynamic asset paths

## Usage Example

```rust
use crate::services::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Initialize service with all dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a new tool
let message = ToolInstallationMessage {
    tool_agent_id: "example_tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    assets: Some(vec![/* asset configurations */]),
    download_configurations: Some(vec![/* download configs */]),
    // ... other fields
};

installation_service.install(message).await?;
```

The service handles reinstallation by stopping existing processes, cleaning up directories, and performing fresh installation with asset management across multiple platforms.
