Manages the installation, configuration, and lifecycle of tools within the Flamingo platform. This service coordinates downloading tool binaries and assets from various sources, handling platform-specific configurations, and managing tool processes.

## Key Components

### Primary Service
- **`ToolInstallationService`** - Main orchestrator for tool installation operations

### Core Methods
- **`new()`** - Creates a new instance with all required dependencies
- **`install()`** - Handles complete tool installation process including download, asset management, and process control

### Dependencies
- **GitHub Download Service** - Downloads tools from GitHub releases
- **Tool Agent File Client** - Fetches tools from Artifactory
- **Tool API Client** - Downloads tools from Tool API endpoints
- **Installed Tools Service** - Manages installed tool records
- **Tool Run Manager** - Controls tool process execution
- **Tool Kill Service** - Handles tool process termination

## Usage Example

```rust
// Create installation service with dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a tool with configuration
let tool_message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other configuration
};

installation_service.install(tool_message).await?;
```

The service supports multiple download sources (GitHub, Artifactory, Tool API), handles platform-specific binaries, manages executable permissions, and provides clean reinstallation by properly terminating existing processes.
