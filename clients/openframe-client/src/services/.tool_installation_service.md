This service orchestrates the complete tool installation workflow for the Flamingo MSP platform, handling downloads from multiple sources, file management, process control, and system integration for AI-powered IT automation tools.

## Key Components

**Main Service:**
- `ToolInstallationService` - Core installation orchestrator with dependency injection for all required services

**Primary Methods:**
- `install()` - Complete tool installation workflow with reinstallation support
- `new()` - Constructor that initializes all dependencies and ensures directory structure

**Installation Features:**
- Multi-source asset downloading (GitHub, Artifactory, Tool API)
- Cross-platform executable permission handling
- Process management (stop/restart during reinstall)
- Directory structure management
- Version tracking and conflict resolution

**Dependency Services:**
- File management (`ToolAgentFileClient`, `DirectoryManager`)
- Download services (`GithubDownloadService`, `ToolApiClient`)
- Process control (`ToolRunManager`, `ToolKillService`)
- Configuration resolution (`ToolCommandParamsResolver`, `ToolUrlParamsResolver`)

## Usage Example

```rust
use crate::services::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Initialize service with all dependencies
let installation_service = ToolInstallationService::new(
    github_service,
    file_client,
    api_client,
    command_resolver,
    url_resolver,
    installed_tools,
    directory_manager,
    run_manager,
    processing_manager,
    config_service,
    publisher,
    connection_service,
);

// Install or reinstall a tool
let install_message = ToolInstallationMessage {
    tool_agent_id: "monitoring-agent".to_string(),
    version: "1.2.0".to_string(),
    reinstall: false,
    // ... other configuration
};

installation_service.install(install_message).await?;
```

The service handles complex scenarios like reinstallation (stopping processes, cleaning directories), multi-platform asset management, and integration with the broader Flamingo ecosystem through message publishing and service coordination.
