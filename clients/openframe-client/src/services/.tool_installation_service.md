A service that manages the installation, configuration, and lifecycle of tools in the Flamingo MSP platform. It handles downloading tool binaries from various sources (GitHub, Artifactory, Tool API), managing executable permissions, and coordinating with other services for tool deployment.

## Key Components

### Core Struct
- **ToolInstallationService** - Main service struct containing all dependencies for tool installation operations

### Key Methods
- **new()** - Constructor that initializes the service and ensures required directories exist
- **install()** - Primary installation method that handles the complete tool installation workflow
- **download_from_artifactory()** - Downloads tool binaries from the Artifactory repository
- **set_executable_permissions()** - Sets appropriate file permissions for executable files (Unix systems)

### Dependencies
- **GithubDownloadService** - Handles GitHub-based asset downloads
- **ToolAgentFileClient** - Manages Artifactory file operations
- **ToolApiClient** - Communicates with the Tool API
- **InstalledToolsService** - Tracks installed tool state
- **DirectoryManager** - Manages file system paths and directories

## Usage Example

```rust
use crate::services::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Create service instance with all dependencies
let installation_service = ToolInstallationService::new(
    github_service,
    file_client,
    api_client,
    command_resolver,
    url_resolver,
    tools_service,
    directory_manager,
    run_manager,
    processing_manager,
    config_service,
    publisher,
    connection_service,
);

// Install a tool from installation message
let message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other fields
};

installation_service.install(message).await?;
```

The service supports reinstallation workflows, handles multiple asset sources, manages cross-platform executable permissions, and coordinates with tool lifecycle management services.
