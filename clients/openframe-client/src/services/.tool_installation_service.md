This service handles the complete lifecycle of tool installation for the Flamingo AI-powered MSP platform. It manages downloading, extracting, configuring, and setting up tools with their assets from multiple sources including GitHub releases, Artifactory, and Tool API endpoints.

## Key Components

- **`ToolInstallationService`** - Main service orchestrating tool installations
- **`install()`** - Primary method handling complete tool installation workflow
- **Asset Management** - Downloads and configures executable assets from multiple sources
- **Reinstallation Support** - Handles clean removal and fresh installation of existing tools
- **Multi-Platform Support** - OS-specific configurations and permissions handling
- **Directory Management** - Creates and manages tool-specific directory structures

## Usage Example

```rust
// Initialize the service with required dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a tool with configuration message
let installation_message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other configuration
};

installation_service.install(installation_message).await?;
```

The service supports multiple asset sources (GitHub, Artifactory, Tool API), handles executable permissions on Unix systems, manages tool versioning, and provides comprehensive error handling with detailed context messages. It integrates with the broader Flamingo ecosystem through various client services and publishers.
