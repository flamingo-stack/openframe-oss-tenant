This service manages the complete lifecycle of tool installation for the Flamingo platform, handling downloads from multiple sources (GitHub, Artifactory, Tool API), asset management, and executable permissions across different operating systems.

## Key Components

### Core Structure
- **ToolInstallationService** - Main service coordinating tool installation operations
- **install()** - Primary installation method handling full tool lifecycle
- **download_from_artifactory()** - Downloads tools from internal Artifactory
- **set_executable_permissions()** - Sets proper file permissions for executables

### Dependencies
- Multiple service clients for different download sources
- Directory management for organized tool storage
- Tool lifecycle managers (run, connection, kill services)
- Configuration and messaging services

### Asset Management
- Support for multiple asset sources (GitHub, Artifactory, Tool API)
- OS-specific download configurations
- Executable permission handling
- URL parameter resolution for dynamic paths

## Usage Example

```rust
// Create the installation service with all dependencies
let installation_service = ToolInstallationService::new(
    github_service,
    file_client,
    api_client,
    command_resolver,
    url_resolver,
    tools_service,
    directory_manager,
    run_manager,
    connection_manager,
    config_service,
    publisher,
    connection_service,
);

// Install a tool
let message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other fields
};

installation_service.install(message).await?;
```

The service handles reinstallation scenarios by stopping existing processes, cleaning up directories, and performing fresh installations while maintaining proper state management across all dependent services.
