A comprehensive service that handles tool installation, updates, and asset management for the Flamingo platform. This service orchestrates downloads from multiple sources (GitHub, Artifactory, Tool API), manages executable permissions, and coordinates with other services for tool lifecycle management.

## Key Components

- **Installation Management**: Downloads and installs tools from GitHub releases, Artifactory, or Tool API endpoints
- **Asset Handling**: Downloads and manages tool assets with proper executable permissions and OS-specific configurations
- **Reinstallation Support**: Handles tool reinstalls by stopping processes, cleaning directories, and clearing tracking data
- **Multi-Source Downloads**: Supports GitHub releases, Artifactory files, and Tool API assets with URL parameter resolution
- **Cross-Platform Support**: Handles OS-specific download configurations and file permissions (Unix executable bits)
- **Process Coordination**: Integrates with tool run managers, connection services, and kill services for complete lifecycle management

## Usage Example

```rust
// Create installation service with all dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a new tool
let install_message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    assets: Some(vec![/* asset configurations */]),
    download_configurations: Some(vec![/* platform configs */]),
    // ... other fields
};

installation_service.install(install_message).await?;

// Reinstall existing tool
let reinstall_message = ToolInstallationMessage {
    reinstall: true,
    // ... same configuration
};

installation_service.install(reinstall_message).await?;
```
