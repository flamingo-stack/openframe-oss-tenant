This service orchestrates the complete tool installation process for the Flamingo MSP platform, handling downloads from multiple sources, asset management, and tool lifecycle operations.

## Key Components

- **ToolInstallationService**: Main service that coordinates tool installation, reinstallation, and asset management
- **install()**: Core method that processes `ToolInstallationMessage` to download and configure tools
- **download_from_artifactory()**: Downloads tool binaries from the Flamingo artifactory
- **set_executable_permissions()**: Sets appropriate file permissions for executable assets on Unix systems

## Usage Example

```rust
use crate::services::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Create service with all required dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a tool from installation message
let tool_message = ToolInstallationMessage {
    tool_agent_id: "example-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other fields
};

installation_service.install(tool_message).await?;
```

The service handles three asset sources (Artifactory, Tool API, GitHub), manages tool directories, handles reinstallation by stopping existing processes, and publishes installation status messages. It ensures proper file permissions and validates OS compatibility for all downloaded assets.
