This service handles the complete lifecycle of tool installation and management within the Flamingo platform, including downloading from multiple sources, managing assets, and coordinating with various other services for tool execution and lifecycle management.

## Key Components

- **ToolInstallationService**: Main service class that orchestrates tool installation, uninstallation, and asset management
- **install()**: Core method that handles the complete installation process including version checking, downloading, and setup
- **Multiple download sources**: Support for GitHub, Artifactory, and Tool API asset sources
- **Cross-platform support**: Handles OS-specific configurations and executable permissions
- **Reinstallation logic**: Manages tool updates and reinstalls with proper cleanup

## Usage Example

```rust
use crate::services::tool_installation_service::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Create the service with all dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a tool
let install_message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other fields
};

installation_service.install(install_message).await?;
```

The service automatically handles directory creation, asset downloads from multiple sources, executable permissions on Unix systems, and publishes installation events to other system components.
