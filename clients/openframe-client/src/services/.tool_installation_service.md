Orchestrates the complete installation lifecycle of tools for the OpenFrame AI-powered MSP platform. Handles downloading, extracting, permission setting, and service integration for tools from multiple sources including GitHub, Artifactory, and Tool API.

## Key Components

**Core Service:**
- `ToolInstallationService` - Main service managing tool installation workflows with dependency injection

**Key Methods:**
- `install()` - Performs complete tool installation including download, extraction, and service registration
- `download_from_artifactory()` - Downloads tool binaries from internal Artifactory
- `set_executable_permissions()` - Sets platform-specific executable permissions
- `create_installed_tool()` - Creates database records for successfully installed tools

**Dependencies:**
- `GithubDownloadService` - Handles GitHub releases and asset downloads
- `InstalledToolsService` - Manages tool installation database records
- `DirectoryManager` - Manages tool-specific directory structures
- `ToolRunManager` - Coordinates tool process execution
- Various parameter resolvers and configuration services

## Usage Example

```rust
use crate::services::tool_installation_service::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Initialize service with all dependencies
let installation_service = ToolInstallationService::new(
    github_service,
    file_client,
    api_client,
    command_resolver,
    url_resolver,
    installed_tools_service,
    directory_manager,
    run_manager,
    connection_manager,
    config_service,
    publisher,
    connection_service,
);

// Install a tool from installation message
let install_message = ToolInstallationMessage {
    tool_agent_id: "network-monitor".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other fields
};

installation_service.install(install_message).await?;
```

The service supports reinstallation by stopping existing processes, cleaning directories, and managing tool lifecycle across multiple asset sources with proper error handling and logging.
