A service that handles the complete lifecycle of tool installation, including downloading, asset management, and process control for MSP platform tools.

## Key Components

- **ToolInstallationService** - Main service orchestrating tool installation workflow
- **install()** - Primary method handling tool download, asset extraction, and dependency setup
- **Dependency injection** - Integrates with GitHub downloads, file clients, API clients, and process managers
- **Multi-source asset support** - Downloads from Artifactory, Tool API, and GitHub repositories
- **Process management** - Handles tool stopping, directory cleanup, and executable permissions
- **Reinstallation logic** - Manages clean uninstall/reinstall workflows when requested

## Usage Example

```rust
use crate::services::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Create service with all required dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a new tool
let install_message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other configuration
};

installation_service.install(install_message).await?;
```

The service automatically handles directory creation, asset downloading from multiple sources, executable permission setting, and integration with the broader tool management ecosystem. It supports both fresh installations and reinstallation scenarios with proper cleanup of existing processes and files.
