A service responsible for managing the complete lifecycle of tool installation, including downloading, asset management, and process control. It handles installation, reinstallation, and uninstallation of tools from various sources (GitHub, Artifactory, Tool API).

## Key Components

- **`ToolInstallationService`** - Main service struct with dependencies for file operations, API clients, and process management
- **`install()`** - Core installation method that handles tool lifecycle, downloads, asset management, and executable permissions
- **Multi-source downloads** - Supports GitHub releases, Artifactory, and Tool API asset sources
- **Asset management** - Downloads and configures tool-specific assets with proper executable permissions
- **Process control** - Integrates with kill service and run manager for tool process lifecycle
- **Directory management** - Creates tool-specific directories and manages file organization

## Usage Example

```rust
use crate::services::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Initialize service with required dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a tool
let install_message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other fields
};

installation_service.install(install_message).await?;
```

The service handles complex scenarios like reinstallation (stopping existing processes, cleaning directories), asset downloading from multiple sources, setting executable permissions, and publishing installation events to notify other system components.
