A comprehensive service that manages the complete lifecycle of tool installation, including downloading from multiple sources, setting up directories, handling dependencies, and managing tool processes.

## Key Components

- **`ToolInstallationService`** - Main service struct that orchestrates tool installation
- **`new()`** - Constructor that initializes the service with all required dependencies
- **`install()`** - Primary method that handles complete tool installation workflow
- **Asset Management** - Downloads and configures tool assets from multiple sources (GitHub, Artifactory, Tool API)
- **Directory Management** - Creates and manages tool-specific directories and file permissions
- **Reinstallation Logic** - Handles tool updates by stopping processes and cleaning up existing installations

## Usage Example

```rust
use crate::services::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Initialize the service with all required dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a new tool
let installation_message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other fields
};

installation_service.install(installation_message).await?;
```

The service handles complex installation scenarios including OS-specific downloads, executable permissions, asset management, and graceful reinstallation with process cleanup. It integrates with multiple external services to provide a unified tool installation experience across different platforms.
