Service that manages tool installation, downloading, and lifecycle operations for agent tools. It orchestrates downloading from multiple sources (GitHub, Artifactory, Tool API), handles file permissions, and manages tool lifecycle including reinstallation and uninstallation.

## Key Components

- **Installation Management**: Core `install()` method that handles tool download, extraction, and setup
- **Multi-Source Downloads**: Support for GitHub releases, Artifactory, and Tool API asset downloads
- **Asset Management**: Downloads and configures tool assets with proper file permissions
- **Lifecycle Operations**: Handles tool reinstallation, uninstallation, and process management
- **Directory Management**: Creates and manages tool-specific directories and file paths
- **Service Integration**: Coordinates with multiple services for tool tracking, process management, and notifications

## Usage Example

```rust
use crate::services::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Create installation service with required dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a new tool
let install_message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other configuration
};

installation_service.install(install_message).await?;
```

The service handles complex installation workflows including checking for existing installations, downloading from appropriate sources based on the current OS, setting executable permissions on Unix systems, and coordinating with other services to track tool status and manage running processes.
