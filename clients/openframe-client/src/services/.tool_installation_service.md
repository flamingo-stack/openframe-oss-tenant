A comprehensive service for managing tool installation operations within the OpenFrame platform, handling downloads, asset management, permissions, and lifecycle orchestration.

## Key Components

- **ToolInstallationService** - Main service orchestrating tool installation workflow
- **install()** - Primary installation method handling tool downloads, assets, and configuration
- **download_from_artifactory()** - Downloads tools from Artifactory repository
- **set_executable_permissions()** - Platform-specific permission management for executables
- **Multiple service dependencies** - Integrates with GitHub, API clients, tool management, and configuration services

## Usage Example

```rust
use crate::services::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Create service with all required dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a tool
let message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other fields
};

installation_service.install(message).await?;
```

The service handles complex installation scenarios including reinstallation, asset management from multiple sources (GitHub, Artifactory, Tool API), permission management across platforms, and integration with the broader tool lifecycle management system.
