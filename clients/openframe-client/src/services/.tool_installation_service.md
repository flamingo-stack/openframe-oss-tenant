This service orchestrates the complete installation lifecycle of tools within the Flamingo MSP platform, handling downloads from multiple sources (GitHub, Artifactory, Tool API), asset management, and process coordination.

## Key Components

- **`ToolInstallationService`** - Main service struct with comprehensive dependency injection for all installation operations
- **`install()`** - Core installation method that processes `ToolInstallationMessage` and coordinates the entire installation workflow
- **Asset Management** - Handles downloading and setting permissions for tool assets from multiple sources (GitHub, Artifactory, Tool API)
- **Reinstallation Logic** - Manages clean uninstallation of existing tools before reinstalling new versions
- **Cross-platform Support** - Handles OS-specific configurations and executable permissions

## Usage Example

```rust
use crate::services::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Initialize service with all dependencies
let installation_service = ToolInstallationService::new(
    github_service,
    file_client,
    api_client,
    command_resolver,
    url_resolver,
    installed_tools_service,
    directory_manager,
    run_manager,
    connection_manager,
    config_service,
    publisher,
    connection_service,
);

// Install a tool
let install_message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other fields
};

installation_service.install(install_message).await?;
```

The service ensures proper directory structure, handles existing installations, downloads and configures assets with appropriate permissions, and coordinates with other services to maintain tool state consistency across the platform.
