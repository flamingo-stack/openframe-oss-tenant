Service responsible for installing, managing, and configuring tools within the Flamingo agent system. Handles downloading from multiple sources, asset management, and tool lifecycle operations.

## Key Components

- **`ToolInstallationService`** - Main service struct that orchestrates tool installation process
- **`install()`** - Primary method that handles complete tool installation workflow
- **`download_from_artifactory()`** - Downloads tools from internal artifactory
- **`set_executable_permissions()`** - Sets proper file permissions for executable assets
- **Multiple client dependencies** - GitHub, Tool API, and File clients for different download sources

## Usage Example

```rust
use crate::services::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Create service with required dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    // ... other dependencies
);

// Install a tool
let installation_message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other fields
};

installation_service.install(installation_message).await?;
```

The service handles reinstallation by stopping existing processes, cleaning up directories, and downloading fresh assets. It supports multiple asset sources (GitHub, Artifactory, Tool API) and manages platform-specific configurations and permissions.
