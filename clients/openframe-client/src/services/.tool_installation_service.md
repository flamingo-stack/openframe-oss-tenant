This service orchestrates the complete installation process for tools in the Flamingo platform, managing downloads from multiple sources (GitHub, Artifactory, Tool API), handling dependencies and assets, and configuring runtime environments.

## Key Components

- **`ToolInstallationService`** - Main service handling tool installation, uninstallation, and asset management
- **`install()`** - Primary method for installing tools from various sources with version control
- **Asset Management** - Downloads and configures tool assets with proper permissions
- **Multi-source Downloads** - Supports GitHub releases, Artifactory, and Tool API endpoints
- **Process Management** - Integrates with kill service and connection managers for clean installations

## Usage Example

```rust
// Initialize the installation service
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a tool with version and assets
let installation_message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    download_configurations: Some(download_configs),
    assets: Some(vec![asset_config]),
    // ... other fields
};

installation_service.install(installation_message).await?;
```

The service handles cross-platform executable permissions, supports reinstallation workflows, and publishes installation events to notify other system components of tool availability.
