This service orchestrates the complete tool installation lifecycle for the Flamingo MSP platform. It handles downloading tools from multiple sources (GitHub, Artifactory, Tool API), managing file permissions, and coordinating with other services for tool lifecycle management.

## Key Components

- **ToolInstallationService**: Main service struct coordinating all installation operations
- **install()**: Primary method handling the complete installation workflow
- **download_from_artifactory()**: Downloads tools from Artifactory source
- **set_executable_permissions()**: Platform-specific permission management for executable files

## Usage Example

```rust
use crate::services::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Create installation service with all dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a tool
let tool_message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other fields
};

installation_service.install(tool_message).await?;
```

The service supports multiple asset sources (GitHub releases, Artifactory, Tool API), handles reinstallation by cleaning up existing processes and files, manages platform-specific executable permissions, and publishes installation status messages. It integrates with directory management, process control, and connection services for complete tool lifecycle management.
