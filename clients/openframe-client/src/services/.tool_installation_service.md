This service manages the complete lifecycle of tool installation and management within the OpenFrame platform, handling downloads from multiple sources (GitHub, Artifactory, Tool API), asset management, and tool process lifecycle.

## Key Components

- **ToolInstallationService** - Main service orchestrating tool installation, uninstallation, and asset management
- **install()** - Core installation method supporting GitHub, Artifactory, and Tool API downloads
- **download_from_artifactory()** - Downloads tool binaries from internal Artifactory
- **set_executable_permissions()** - Sets proper file permissions on Unix systems
- **Asset Management** - Handles downloading and storing tool assets with proper permissions

## Usage Example

```rust
use tool_installation_service::ToolInstallationService;
use models::ToolInstallationMessage;

// Create service with all dependencies
let service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a tool from installation message
let installation_msg = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other fields
};

service.install(installation_msg).await?;
```

The service automatically handles reinstallation by stopping running processes, cleaning up directories, and managing tool state across multiple tracking services. It supports cross-platform asset downloads with proper executable permissions and integrates with the broader tool management ecosystem.
