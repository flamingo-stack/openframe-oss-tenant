An orchestrator service that manages the complete lifecycle of tool installation, including downloading, asset management, and process coordination within the Flamingo/OpenFrame platform.

## Key Components

- **ToolInstallationService** - Main service handling tool installation, updates, and lifecycle management
- **install()** - Core installation method that handles downloads, asset management, and process coordination
- **Dependency services** - Integrates with GitHub downloads, API clients, file management, and process control services
- **Platform-specific handling** - Cross-platform executable permissions and directory management
- **Asset management** - Downloads and configures tool assets from multiple sources (Artifactory, Tool API, GitHub)

## Usage Example

```rust
use crate::services::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Initialize the service with required dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a tool with configuration
let tool_message = ToolInstallationMessage {
    tool_agent_id: "example-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other configuration
};

// Execute installation
installation_service.install(tool_message).await?;
```

The service handles complex installation workflows including reinstallation, asset downloading from multiple sources, executable permissions, and integration with the broader tool management ecosystem.
