A comprehensive service that orchestrates the complete tool installation process including downloading, extracting, configuring, and managing tool lifecycles within the Flamingo MSP platform.

## Key Components

### Main Service
- **`ToolInstallationService`** - Core service that coordinates tool installation operations
- **`install()`** - Primary method that handles the complete installation workflow

### Dependency Services
- **`GithubDownloadService`** - Downloads tools from GitHub repositories
- **`ToolAgentFileClient`** - Downloads assets from Artifactory
- **`ToolApiClient`** - Downloads assets from the Tool API
- **`InstalledToolsService`** - Manages installed tool records
- **`ToolKillService`** - Handles stopping running tool processes
- **`DirectoryManager`** - Manages tool directory structure

### Asset Sources
- **`AssetSource::Artifactory`** - Downloads from internal artifact repository
- **`AssetSource::ToolApi`** - Downloads from tool-specific APIs with URL parameter resolution
- **`AssetSource::Github`** - Downloads from GitHub releases

## Usage Example

```rust
// Initialize the service with all dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a new tool
let tool_message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other fields
};

installation_service.install(tool_message).await?;
```

The service handles reinstallation by stopping existing processes, cleaning up directories, and performing a fresh installation. It supports cross-platform executable permissions and tracks installation status throughout the process.
