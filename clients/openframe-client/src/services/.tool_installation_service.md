A service for managing tool installation operations including downloading, extracting, and configuring tools with their assets from various sources (GitHub, Artifactory, Tool API).

## Key Components

- **ToolInstallationService**: Main service orchestrating tool installation workflows
- **install()**: Core method handling complete tool installation process including:
  - Reinstallation logic with process termination
  - Directory management and cleanup  
  - Asset downloading from multiple sources
  - Permission setting for executables
  - Installation tracking and messaging

## Usage Example

```rust
use crate::services::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Create service with all required dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a tool
let installation_message = ToolInstallationMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    // ... other fields
};

installation_service.install(installation_message).await?;
```

The service handles complex installation scenarios including reinstallation with proper cleanup, multi-source asset downloads (GitHub releases, Artifactory, Tool API), executable permission management, and integration with the broader tool management ecosystem through various injected services.
