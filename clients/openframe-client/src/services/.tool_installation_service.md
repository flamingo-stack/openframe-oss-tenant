This service orchestrates the complete tool installation lifecycle for the Flamingo/OpenFrame MSP platform, handling downloads from multiple sources (GitHub, Artifactory, Tool API), asset management, and tool process lifecycle.

## Key Components

- **ToolInstallationService**: Main service managing tool installation, uninstallation, and configuration
- **install()**: Primary method handling tool download, extraction, and setup with support for reinstallation
- **download_from_artifactory()**: Downloads tool agents from Artifactory storage
- **set_executable_permissions()**: Sets proper file permissions on Unix-like systems
- **Asset Management**: Handles downloading and configuring tool assets from various sources
- **Process Management**: Integrates with tool kill, run, and connection services

## Usage Example

```rust
use crate::services::ToolInstallationService;
use crate::models::ToolInstallationMessage;

// Initialize the service with all required dependencies
let installation_service = ToolInstallationService::new(
    github_download_service,
    tool_agent_file_client,
    tool_api_client,
    command_params_resolver,
    url_params_resolver,
    installed_tools_service,
    directory_manager,
    tool_run_manager,
    tool_connection_processing_manager,
    config_service,
    installed_agent_publisher,
    tool_connection_service,
);

// Install a tool with automatic source detection
let install_message = ToolInstallationMessage {
    tool_agent_id: "monitoring-agent".to_string(),
    version: "1.0.0".to_string(),
    reinstall: false,
    download_configurations: Some(github_configs),
    assets: Some(tool_assets),
    // ... other fields
};

installation_service.install(install_message).await?;
```

The service automatically handles directory creation, permission setting, asset management, and integrates with the broader tool ecosystem for process management and configuration.
