A service that handles updating tool agents to new versions with backup and rollback capabilities, integrating with GitHub downloads and legacy Artifactory systems.

## Key Components

- **ToolAgentUpdateService**: Main service that orchestrates the update process for tool agents
- **process_update()**: Public method that validates and initiates tool agent updates
- **do_update()**: Internal method that performs the actual update workflow including backup, download, and installation
- **Dependencies**: Integrates with GitHub download service, file client, installed tools service, kill service, and message publisher

## Usage Example

```rust
use tool_agent_update_service::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize the service with required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.2.0".to_string(),
    download_configurations: vec![],
};

update_service.process_update(update_message).await?;
```

The service automatically handles stopping running tools, creating backups, downloading new binaries from GitHub or Artifactory, setting executable permissions, and publishing completion messages.
