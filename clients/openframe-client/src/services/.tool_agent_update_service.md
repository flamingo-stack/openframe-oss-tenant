A service responsible for orchestrating tool agent updates in the Flamingo MSP platform, handling the complete update lifecycle from download to deployment with rollback capabilities.

## Key Components

- **ToolAgentUpdateService** - Main service struct that coordinates tool agent updates
- **process_update()** - Primary entry point that validates and processes update messages
- **do_update()** - Internal method handling the actual update workflow including backup, download, and deployment

## Usage Example

```rust
use tool_agent_update_service::ToolAgentUpdateService;
use models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize the service with required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "monitoring-tool".to_string(),
    version: "1.2.3".to_string(),
    download_configurations: vec![/* download configs */],
};

update_service.process_update(update_message).await?;
```

The service ensures safe updates by stopping running processes, creating backups, downloading new binaries, setting proper permissions, and updating installation records. It supports both modern GitHub-based downloads and legacy Artifactory methods.
