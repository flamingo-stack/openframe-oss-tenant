Service responsible for orchestrating tool agent updates within the Flamingo AI platform, handling secure binary downloads, process management, and rollback capabilities.

## Key Components

**Main Struct:**
- `ToolAgentUpdateService` - Core service managing agent updates with dependency injection of file clients, GitHub services, and system managers

**Key Methods:**
- `new()` - Initializes service with all required dependencies and ensures directory structure
- `process_update()` - Main entry point processing `ToolAgentUpdateMessage` with version checks
- `do_update()` - Internal implementation handling the complete update workflow

**Dependencies:**
- `GithubDownloadService` - Modern download method using GitHub configurations
- `ToolAgentFileClient` - Legacy Artifactory-based download fallback
- `ToolKillService` - Process management for stopping running agents
- `DirectoryManager` - Platform-specific file system operations
- `InstalledToolsService` - Database operations for tool metadata

## Usage Example

```rust
use flamingo::services::ToolAgentUpdateService;
use flamingo::models::ToolAgentUpdateMessage;

// Initialize service with dependencies
let update_service = ToolAgentUpdateService::new(
    github_service,
    file_client,
    tools_service,
    kill_service,
    run_manager,
    directory_manager,
    config_service,
    publisher,
);

// Process an update message
let update_msg = ToolAgentUpdateMessage {
    tool_agent_id: "monitoring-agent".to_string(),
    version: "1.2.3".to_string(),
    download_configurations: vec![/* platform configs */],
};

match update_service.process_update(update_msg).await {
    Ok(_) => println!("Update completed successfully"),
    Err(e) => eprintln!("Update failed: {:#}", e),
}
```

The service implements a robust update workflow: stops running processes, creates backups, downloads new binaries (preferring GitHub over legacy Artifactory), sets executable permissions on Unix systems, updates metadata, and publishes completion notifications. It includes comprehensive error handling with automatic cleanup of backup files on success.
