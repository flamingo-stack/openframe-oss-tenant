This service manages the complete lifecycle of updating tool agents within the Flamingo platform, handling version checking, binary replacement, and state management during updates.

## Key Components

- **`ToolAgentUpdateService`** - Main service orchestrating tool agent updates with dependency injection for all required services
- **`process_update()`** - Entry point that validates update necessity and manages the update state
- **`do_update()`** - Core update logic handling process stopping, backup creation, binary download, and version tracking
- **Platform-specific permissions** - Unix-specific executable permission setting for downloaded binaries

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize the service with all dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.2.0".to_string(),
    download_configurations: vec![],
};

match update_service.process_update(update_message).await {
    Ok(()) => println!("Tool updated successfully"),
    Err(e) => eprintln!("Update failed: {:#}", e),
}
```

The service supports both modern GitHub-based downloads with platform-specific configurations and legacy Artifactory-based downloads, automatically creating backups and rolling back on failure.
