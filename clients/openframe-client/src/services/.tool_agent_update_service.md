A service that manages updating tool agents to newer versions, handling the complete update lifecycle from download to deployment with rollback capabilities.

## Key Components

- **ToolAgentUpdateService** - Main service struct that orchestrates tool agent updates
- **process_update()** - Public method that validates and initiates the update process
- **do_update()** - Private method that performs the actual update operations
- **Dependencies** - Integrates with GitHub downloads, file management, tool lifecycle, and messaging services

The service handles version checking, process stopping, binary backup/restore, download from multiple sources (GitHub or legacy Artifactory), file permissions, and post-update notifications.

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize the service with all required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.2.0".to_string(),
    download_configurations: vec![], // Or GitHub download configs
};

match update_service.process_update(update_message).await {
    Ok(()) => println!("Tool updated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service automatically handles stopping running processes, creating backups, downloading new binaries, setting proper permissions, and cleaning up temporary files.
