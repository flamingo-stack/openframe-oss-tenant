Service for updating tool agents to new versions, handling download, backup, and installation with process management.

## Key Components

- **ToolAgentUpdateService** - Main service coordinating the update process
- **process_update()** - Entry point for processing update messages, validates installation and version
- **do_update()** - Core update logic handling stop/backup/download/install/restart sequence
- Dependencies: GitHub download service, file client, tool management services, and directory manager

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize the update service with required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "2.0.0".to_string(),
    download_configurations: vec![],
};

update_service.process_update(update_message).await?;
```

The service ensures safe updates by stopping the tool process, creating backups, downloading new binaries (either via GitHub or legacy Artifactory), setting proper permissions, and publishing completion notifications. It includes rollback capabilities through backup files and comprehensive error handling throughout the update pipeline.
