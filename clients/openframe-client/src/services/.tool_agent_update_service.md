Service responsible for orchestrating tool agent updates by managing the complete update lifecycle including process termination, binary replacement, and service restart coordination.

## Key Components

- **ToolAgentUpdateService** - Main service struct coordinating updates across multiple dependencies
- **process_update()** - Entry point that validates prerequisites and orchestrates the update flow
- **do_update()** - Core update logic handling backup, download, installation, and cleanup
- **Dependencies** - Integrates with GitHub downloads, file management, process control, and messaging services

## Usage Example

```rust
// Initialize the service with required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "monitoring-agent".to_string(),
    version: "1.2.3".to_string(),
    download_configurations: vec![/* configs */],
};

update_service.process_update(update_message).await?;
```

The service handles version validation, process lifecycle management, binary backup/restore, and cross-platform executable permissions. It supports both modern GitHub-based downloads and legacy Artifactory fallback methods.
