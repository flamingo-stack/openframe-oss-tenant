This service handles updating tool agents by downloading new versions and managing the installation process, including backup/restore functionality and cross-platform compatibility.

## Key Components

- **ToolAgentUpdateService**: Main service struct that orchestrates the tool agent update process
- **process_update**: Entry point that validates the update request and delegates to the actual update logic
- **do_update**: Core update implementation that handles backup, download, installation, and cleanup
- **Dependencies**: Integrates with GitHub downloads, file management, tool lifecycle, and messaging services

## Usage Example

```rust
// Create the update service with required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.2.0".to_string(),
    download_configurations: vec![/* configs */],
};

update_service.process_update(update_message).await?;
```

The service ensures safe updates by stopping running processes, backing up existing binaries, downloading new versions (via GitHub or legacy Artifactory), setting proper permissions on Unix systems, and publishing completion messages to notify other components.
