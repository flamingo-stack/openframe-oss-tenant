A service that handles secure updates of tool agents by downloading new versions, backing up existing binaries, and managing the complete update lifecycle with rollback capabilities.

## Key Components

- **ToolAgentUpdateService**: Main service struct coordinating updates across multiple dependencies
- **process_update()**: Entry point that validates update requirements and orchestrates the update process
- **do_update()**: Core update implementation handling binary replacement, backup management, and permissions
- **Integration Services**: Uses GitHub downloads, file management, process control, and messaging services

## Usage Example

```rust
use tool_agent_update_service::ToolAgentUpdateService;

// Initialize service with required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.2.0".to_string(),
    download_configurations: vec![],
};

match update_service.process_update(update_message).await {
    Ok(()) => println!("Update completed successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service ensures atomic updates by stopping processes, creating backups, downloading new binaries, setting proper permissions, and publishing completion messages. It supports both GitHub releases and legacy Artifactory downloads with automatic OS-specific configuration selection.
