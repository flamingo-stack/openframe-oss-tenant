A service that handles updating tool agents by downloading new versions, replacing binaries, and managing the update lifecycle with proper backup and rollback capabilities.

## Key Components

- **ToolAgentUpdateService**: Main service struct that orchestrates tool agent updates with dependency injection for various services (GitHub downloads, file management, process control, etc.)
- **process_update()**: Public entry point that validates installed tools, checks version differences, and coordinates the update process
- **do_update()**: Internal implementation that handles the complete update workflow including process stopping, file backup, binary replacement, and cleanup

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize the service with all required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.2.0".to_string(),
    download_configurations: vec![],
};

if let Err(e) = update_service.process_update(update_message).await {
    eprintln!("Update failed: {}", e);
}
```

The service supports both modern GitHub-based downloads (using download configurations) and legacy Artifactory-based updates, with automatic OS-specific binary selection and executable permissions handling.
