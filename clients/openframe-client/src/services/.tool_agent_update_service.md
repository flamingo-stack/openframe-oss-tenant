A service that handles updating installed tool agents by downloading new versions, performing safe binary replacement with backup/restore functionality, and coordinating with other system services.

## Key Components

- **ToolAgentUpdateService** - Main service orchestrating tool agent updates
- **process_update()** - Primary entry point that validates installation status and version differences
- **do_update()** - Core update implementation handling process management, file operations, and rollback capabilities
- **Dependency Services** - Integrates with GitHub downloads, file management, process control, and messaging services

## Usage Example

```rust
use tool_agent_update_service::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize the service with all required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.2.0".to_string(),
    download_configurations: vec![],
};

update_service.process_update(update_message).await?;
```

The service supports both modern GitHub-based downloads with platform-specific configurations and legacy Artifactory-based downloads. It ensures atomic updates by creating backups, stopping running processes, and handling Unix executable permissions appropriately.
