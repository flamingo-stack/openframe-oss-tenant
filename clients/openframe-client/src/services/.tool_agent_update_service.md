Service responsible for updating installed tool agents to new versions with backup and rollback capabilities.

## Key Components

- **ToolAgentUpdateService** - Main service struct managing tool agent updates
- **process_update()** - Processes update requests from ToolAgentUpdateMessage
- **do_update()** - Performs the actual update operation with backup/restore logic
- Dependency services: GithubDownloadService, ToolKillService, InstalledToolsService, etc.

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Create the service with all required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "v2.0.0".to_string(),
    download_configurations: vec![],
};

match update_service.process_update(update_message).await {
    Ok(()) => println!("Tool updated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service handles the complete update workflow: stopping running processes, backing up current binaries, downloading new versions (via GitHub or legacy Artifactory), setting permissions, and notifying other services of the update completion.
