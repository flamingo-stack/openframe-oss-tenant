A service for updating tool agents to new versions, handling the complete update lifecycle from download to binary replacement with rollback capabilities.

## Key Components

- **ToolAgentUpdateService** - Main service struct that orchestrates tool agent updates
- **process_update()** - Entry point that validates and initiates the update process
- **do_update()** - Core update logic that handles binary replacement and version management

## Dependencies

The service integrates with multiple components:
- **GithubDownloadService** - Downloads new binaries from GitHub releases
- **ToolAgentFileClient** - Legacy Artifactory download client
- **InstalledToolsService** - Manages tool installation records
- **ToolKillService** - Stops running tool processes
- **ToolRunManager** - Tracks tool update states
- **DirectoryManager** - Manages file system paths
- **AgentConfigurationService** - Provides machine configuration
- **InstalledAgentMessagePublisher** - Publishes update notifications

## Usage Example

```rust
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "2.0.0".to_string(),
    download_configurations: vec![/* configs */],
};

update_service.process_update(update_message).await?;
```

The service ensures safe updates by stopping processes, creating backups, downloading new binaries, setting executable permissions (Unix), and publishing completion notifications. It supports both GitHub releases and legacy Artifactory downloads.
