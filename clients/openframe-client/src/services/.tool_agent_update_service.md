This service orchestrates the complete update process for tool agents, handling version checking, binary downloads, process management, and rollback capabilities.

## Key Components

- **`ToolAgentUpdateService`** - Main service struct that coordinates all update operations
- **`new()`** - Constructor that initializes the service with all required dependencies and ensures directories exist
- **`process_update()`** - Public entry point that validates update requirements and manages the update flow
- **`do_update()`** - Internal method that performs the actual binary update with backup/rollback support

The service integrates with multiple dependencies including GitHub downloads, file management, process control, and configuration services to provide a robust update mechanism.

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize the service with all dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.2.0".to_string(),
    download_configurations: vec![],
};

update_service.process_update(update_message).await?;
```

The service automatically handles version comparison, process stopping, binary backup, download (via GitHub or legacy Artifactory), file permissions, and cleanup operations.
