This service manages the update process for tool agents in the Flamingo OpenFrame platform, handling version checking, binary downloads, and safe replacement of existing tools.

## Key Components

- **ToolAgentUpdateService**: Main service orchestrating tool updates with dependency injection for file operations, GitHub downloads, process management, and configuration
- **process_update()**: Entry point that validates tool installation and version requirements before initiating updates
- **do_update()**: Core update logic handling process termination, binary backup, download, replacement, and cleanup
- **Dependency Services**: Integrates with GitHub downloads, file operations, process management, and messaging systems

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::ToolAgentUpdateMessage;

// Initialize the service with required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.2.0".to_string(),
    download_configurations: vec![],
};

match update_service.process_update(update_message).await {
    Ok(()) => println!("Tool updated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service ensures safe updates by stopping processes, creating backups, downloading new binaries (via GitHub or legacy Artifactory), setting proper permissions on Unix systems, and publishing completion notifications to the messaging system.
