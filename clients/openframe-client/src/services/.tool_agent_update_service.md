Service for updating tool agent binaries to new versions with safe rollback capabilities.

## Key Components

- **ToolAgentUpdateService** - Main service struct that orchestrates tool agent updates
- **process_update()** - Public method that processes update messages and validates before updating
- **do_update()** - Private method that handles the actual update process with backup/restore logic
- **Dependencies** - Integrates with GitHub download service, file client, tool management, and messaging services

## Usage Example

```rust
use crate::services::tool_agent_update_service::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Create service with required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.2.0".to_string(),
    download_configurations: vec![],
};

update_service.process_update(update_message).await?;
```

The service handles the complete update lifecycle: validating installed tools, stopping processes, backing up binaries, downloading new versions (via GitHub or legacy Artifactory), setting permissions, updating records, and publishing completion messages. It includes robust error handling and automatic cleanup of backup files.
