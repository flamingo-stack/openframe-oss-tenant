A service that handles updating tool agent binaries to new versions, managing the complete update lifecycle from download to version tracking.

## Key Components

- **ToolAgentUpdateService** - Main service struct that coordinates tool agent updates
- **process_update()** - Entry point that validates update requirements and orchestrates the update process
- **do_update()** - Core update logic that handles binary replacement, backup management, and version tracking

## Key Dependencies

The service integrates with multiple components:
- `GithubDownloadService` - Downloads new binaries from GitHub releases
- `ToolKillService` - Stops running tool processes before update
- `InstalledToolsService` - Manages tool installation records
- `ToolRunManager` - Tracks tool update states
- `DirectoryManager` - Handles file system paths and directory creation

## Usage Example

```rust
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "2.0.0".to_string(),
    download_configurations: vec![/* configs */],
};

update_service.process_update(update_message).await?;
```

The service performs atomic updates with backup/restore capabilities, supports both modern GitHub releases and legacy Artifactory downloads, sets proper executable permissions on Unix systems, and publishes completion notifications to maintain system consistency.
