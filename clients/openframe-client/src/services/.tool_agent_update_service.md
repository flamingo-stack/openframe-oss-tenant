A service responsible for updating tool agents to new versions, handling the complete update lifecycle including process management, file operations, and version tracking.

## Key Components

- **ToolAgentUpdateService**: Main service struct that orchestrates tool agent updates
- **process_update()**: Entry point that processes update messages and validates prerequisites
- **do_update()**: Core update logic handling binary replacement, backup/restore, and permissions
- **Dependencies**: Integrates with GitHub downloads, file management, process control, and configuration services

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize the service with required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.2.0".to_string(),
    download_configurations: vec![],
};

update_service.process_update(update_message).await?;
```

The service follows a safe update pattern: stop the running process, backup the current binary, download and install the new version, update records, and clean up. It supports both GitHub-based downloads with platform-specific configurations and legacy Artifactory downloads. On Unix systems, it automatically sets executable permissions on the updated binary.
