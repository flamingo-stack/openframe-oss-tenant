Service that manages tool agent binary updates with atomic deployment and rollback capabilities.

## Key Components

- **ToolAgentUpdateService** - Main service orchestrating tool agent updates
- **process_update()** - Processes update messages and validates version requirements
- **do_update()** - Performs atomic update with backup/rollback mechanism
- **Dependency Services** - GitHub download, file management, tool lifecycle, and messaging

## Usage Example

```rust
use tool_agent_update_service::ToolAgentUpdateService;
use models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize update service with required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process tool agent update
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "tool-123".to_string(),
    version: "2.1.0".to_string(),
    download_configurations: vec![/* configs */],
};

update_service.process_update(update_message).await?;
```

The service implements a safe update process: validates installed tools, stops running processes, creates backups, downloads new binaries (via GitHub or legacy Artifactory), sets proper permissions, updates records, and publishes completion messages. It supports rollback on failure and cross-platform deployment with OS-specific download configurations.
