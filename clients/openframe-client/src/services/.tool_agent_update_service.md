A service that orchestrates the complete update process for tool agents, handling version checking, binary replacement, and process management with atomic updates and rollback capabilities.

## Key Components

**Main Service:**
- `ToolAgentUpdateService` - Core service managing tool agent updates with dependency injection

**Key Methods:**
- `new()` - Constructor that initializes all dependencies and ensures directory structure
- `process_update()` - Main entry point that validates update requirements and coordinates the process
- `do_update()` - Internal method handling the atomic update workflow

**Dependencies:**
- `GithubDownloadService` - Downloads binaries from GitHub releases
- `ToolAgentFileClient` - Legacy Artifactory-based binary retrieval
- `InstalledToolsService` - Manages tool installation records
- `ToolKillService` - Handles process termination
- `ToolRunManager` - Tracks tool update states
- `DirectoryManager` - Manages file system paths
- `AgentConfigurationService` - Provides machine configuration
- `InstalledAgentMessagePublisher` - Publishes update notifications

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize service with dependencies
let update_service = ToolAgentUpdateService::new(
    github_service,
    file_client,
    tools_service,
    kill_service,
    run_manager,
    directory_manager,
    config_service,
    publisher,
);

// Process an update message
let message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.2.0".to_string(),
    download_configurations: vec![/* configs */],
};

// Performs atomic update with backup/rollback
update_service.process_update(message).await?;
```

The service implements a robust update workflow: validates version requirements, stops running processes, creates backups, downloads new binaries (GitHub or Artifactory), applies executable permissions, updates records, and publishes notifications. Failed updates can be rolled back using the backup system.
