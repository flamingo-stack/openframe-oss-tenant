Manages the complete update lifecycle for tool agents, handling version checks, binary downloads, backup/restore operations, and process management during updates.

## Key Components

- **ToolAgentUpdateService** - Main service struct that orchestrates tool agent updates
- **process_update()** - Public method that validates update requirements and coordinates the update process
- **do_update()** - Internal method that performs the actual update operations including process stopping, file operations, and rollback handling
- **Constructor dependencies** - Integrates with GitHub downloads, file management, process control, and messaging services

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Create the service with all required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process a tool update
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.2.0".to_string(),
    download_configurations: vec![/* configs */],
};

match update_service.process_update(update_message).await {
    Ok(()) => println!("Tool updated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service automatically handles version validation, process management, binary backup/restore, file permissions, and publishes completion messages. It supports both modern GitHub-based downloads and legacy Artifactory methods for maximum compatibility.
