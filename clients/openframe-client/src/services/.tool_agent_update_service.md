Manages automated updates for tool agents in the Flamingo platform, handling version checks, binary downloads, and safe rollback mechanisms.

## Key Components

- **ToolAgentUpdateService**: Main service that orchestrates the tool agent update process
- **process_update()**: Public method that processes update messages and coordinates the update workflow
- **do_update()**: Internal method that performs the actual update operations including backup, download, and installation
- Service dependencies for GitHub downloads, file operations, tool management, and configuration

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize the update service with all required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.2.0".to_string(),
    download_configurations: vec![],
};

update_service.process_update(update_message).await?;
```

The service automatically handles version comparison, creates backups, stops running processes during updates, sets proper file permissions on Unix systems, and publishes update notifications to the platform.
