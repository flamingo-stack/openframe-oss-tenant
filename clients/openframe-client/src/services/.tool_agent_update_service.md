Manages the complete lifecycle of tool agent updates, handling download, installation, and process management for AI-powered tools in the Flamingo MSP platform. This service ensures safe atomic updates with backup and rollback capabilities.

## Key Components

- **ToolAgentUpdateService** - Main service orchestrating tool agent updates
- **process_update()** - Entry point for processing update requests, validates installation state
- **do_update()** - Core update logic handling binary replacement and process management
- **Service Dependencies** - Integrates with GitHub downloads, file management, process control, and messaging
- **Platform Support** - Cross-platform with Unix-specific executable permissions handling

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize the update service with all dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "mingo-ai".to_string(),
    version: "2.1.0".to_string(),
    download_configurations: vec![/* platform configs */],
};

// Execute the update (handles stop, backup, download, replace, permissions)
update_service.process_update(update_message).await?;
```

The service automatically handles process termination, binary backup, atomic file replacement, executable permissions, database updates, and notification publishing for seamless tool agent updates.
