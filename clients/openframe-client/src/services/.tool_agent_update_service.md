This service handles updating tool agents in the Flamingo/OpenFrame MSP platform by downloading new versions, managing the update process, and ensuring proper rollback capabilities.

## Key Components

- **ToolAgentUpdateService**: Main service orchestrating tool agent updates
- **process_update()**: Entry point for processing update messages, validates installation and version requirements
- **do_update()**: Core update logic handling file backup, download, replacement, and cleanup
- **Dependencies**: Integrates with GitHub download service, file clients, tool management, and messaging services

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize the service with required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "monitoring-agent".to_string(),
    version: "v2.1.0".to_string(),
    download_configurations: vec![...],
};

match update_service.process_update(update_message).await {
    Ok(()) => println!("Tool agent updated successfully"),
    Err(e) => eprintln!("Update failed: {:#}", e),
}
```

The service ensures safe updates by stopping the running tool process, creating backups, downloading new binaries (from GitHub or legacy sources), setting proper permissions, and updating installation records. It includes comprehensive error handling and logging throughout the update lifecycle.
