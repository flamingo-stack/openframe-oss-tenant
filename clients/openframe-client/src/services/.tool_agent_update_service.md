Orchestrates tool agent updates by handling version management, binary replacement, and safe rollback for the Flamingo MSP platform's automated tool management system.

## Key Components

- **`ToolAgentUpdateService`** - Main service that coordinates tool agent updates across multiple subsystems
- **`process_update()`** - Primary entry point that validates update requirements and orchestrates the update process
- **`do_update()`** - Core update logic handling binary backup, download, replacement, and rollback
- **Dependencies** - Integrates with GitHub downloads, file management, process control, and configuration services

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize the service with required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process a tool update
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "network-monitor".to_string(),
    version: "2.1.0".to_string(),
    download_configurations: vec![/* download configs */],
};

match update_service.process_update(update_message).await {
    Ok(_) => println!("Tool updated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service ensures safe updates by stopping running processes, creating backups, downloading new binaries with proper permissions, and publishing completion notifications. It supports both GitHub-based downloads and legacy Artifactory methods.
