Orchestrates tool agent updates by downloading new versions, performing safe binary replacements, and managing the update lifecycle.

## Key Components

- **ToolAgentUpdateService**: Main service that coordinates tool agent updates
- **process_update()**: Processes incoming update messages and orchestrates the update flow
- **do_update()**: Performs the actual update by stopping processes, backing up binaries, downloading new versions, and updating records

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize the update service with dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my_tool".to_string(),
    version: "1.2.0".to_string(),
    download_configurations: vec![],
};

update_service.process_update(update_message).await?;
```

The service handles version checking, process management, binary backup/restore, and publishes completion notifications. It supports both modern GitHub-based downloads and legacy Artifactory methods, with automatic OS-specific binary selection and proper file permissions on Unix systems.
