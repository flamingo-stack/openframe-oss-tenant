This service manages the update process for tool agents in the Flamingo MSP platform, handling version checks, binary downloads, and safe deployment with rollback capabilities.

## Key Components

- **ToolAgentUpdateService** - Main orchestrator for tool agent updates
- **process_update()** - Entry point that validates update requirements and coordinates the process
- **do_update()** - Core update logic with backup/restore functionality
- **Service Dependencies** - Integrates with GitHub downloads, file management, tool lifecycle, and messaging services

The service supports both modern GitHub-based downloads and legacy Artifactory methods, with cross-platform compatibility including Unix permission handling.

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize the update service with dependencies
let update_service = ToolAgentUpdateService::new(
    github_service,
    file_client,
    tools_service,
    kill_service,
    run_manager,
    directory_manager,
    config_service,
    publisher,
);

// Process a tool update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "monitoring-agent".to_string(),
    version: "2.1.0".to_string(),
    download_configurations: vec![/* configs */],
};

// Execute the update with automatic version checking and rollback safety
update_service.process_update(update_message).await?;
```

The service automatically handles version validation, process stopping, binary backup, download/installation, and status publishing for seamless tool agent updates.
