Service responsible for updating installed tool agents to new versions, handling the complete update lifecycle including process management, file operations, and rollback capabilities.

## Key Components

- **ToolAgentUpdateService** - Main service struct that orchestrates tool agent updates
- **process_update()** - Entry point that validates update requirements and manages the update process
- **do_update()** - Core update logic handling binary replacement, backup creation, and cleanup
- **Service Dependencies** - Integrates with GitHub downloads, file management, process control, and messaging services

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Create update service with required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.2.0".to_string(),
    download_configurations: vec![],
};

update_service.process_update(update_message).await?;
```

The service performs atomic updates by:
1. Stopping the running tool process
2. Creating a backup of the current binary
3. Downloading and installing the new version
4. Setting proper file permissions (Unix systems)
5. Updating the installed tool registry
6. Publishing update notifications
7. Cleaning up backup files on success
