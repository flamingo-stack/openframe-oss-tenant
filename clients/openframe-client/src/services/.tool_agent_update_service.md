Service that manages tool agent updates by downloading new versions and safely replacing existing binaries with backup and rollback capabilities.

## Key Components

- **ToolAgentUpdateService**: Main service struct that orchestrates the update process
- **process_update()**: Entry point that validates and processes update messages
- **do_update()**: Core update logic that handles backup, download, and installation
- Dependencies on multiple services: GitHub downloads, file operations, tool management, and configuration

## Usage Example

```rust
use tool_agent_update_service::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Create service with all required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "monitoring-agent".to_string(),
    version: "2.1.0".to_string(),
    download_configurations: vec![/* configs */],
};

update_service.process_update(update_message).await?;
```

The service follows a safe update pattern: stops the running tool, backs up the current binary, downloads the new version, installs it with proper permissions, updates the database record, and publishes notification messages. It supports both modern GitHub-based downloads and legacy Artifactory methods.
