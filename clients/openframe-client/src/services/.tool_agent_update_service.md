Manages tool agent updates by orchestrating the download, installation, and configuration of new agent versions in the Flamingo platform.

## Key Components

- **`ToolAgentUpdateService`** - Main service struct that coordinates tool agent updates
- **`new()`** - Constructor that initializes the service with required dependencies
- **`process_update()`** - Public method that handles incoming update requests
- **`do_update()`** - Internal method that performs the actual update process

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize the service with required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "example-tool".to_string(),
    version: "1.2.0".to_string(),
    download_configurations: vec![],
};

update_service.process_update(update_message).await?;
```

The service handles version checking, binary backup/restore, process management, and post-update notifications. It supports both modern GitHub-based downloads and legacy Artifactory methods, with automatic OS-specific binary selection and executable permission handling on Unix systems.
