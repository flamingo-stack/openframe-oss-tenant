A service that manages automated updates for tool agents in the Flamingo platform, handling version checks, binary downloads, backups, and atomic replacements with rollback capabilities.

## Key Components

- **ToolAgentUpdateService**: Main service struct managing tool agent updates
- **process_update()**: Primary method that orchestrates the update process for a given tool agent
- **do_update()**: Internal method handling the actual update workflow including backup, download, and replacement
- **Dependencies**: Integrates with GitHub download service, file client, installed tools service, and kill service

The service supports both modern GitHub-based downloads and legacy Artifactory methods, with automatic OS detection and configuration selection.

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize the service with all required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let message = ToolAgentUpdateMessage {
    tool_agent_id: "monitoring-agent".to_string(),
    version: "v2.1.0".to_string(),
    download_configurations: vec![/* download configs */],
};

match update_service.process_update(message).await {
    Ok(()) => println!("Update completed successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service ensures atomic updates with backup/restore functionality, proper Unix permissions, and publishes completion notifications to maintain system consistency across the Flamingo infrastructure.
