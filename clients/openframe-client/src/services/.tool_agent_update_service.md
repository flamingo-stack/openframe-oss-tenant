Manages the update process for installed tool agents, handling version checks, binary replacement, and notification publishing.

## Key Components

- **ToolAgentUpdateService**: Main service coordinating tool agent updates through multiple dependencies
- **process_update()**: Entry point that validates update requirements and orchestrates the update flow
- **do_update()**: Internal method handling the actual update process including backup, download, and replacement
- Dependencies: GitHub download service, file client, installed tools service, tool management, and messaging

## Usage Example

```rust
// Initialize the update service with required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.2.0".to_string(),
    download_configurations: vec![],
};

update_service.process_update(update_message).await?;
```

The service performs a complete update workflow: validates the tool is installed and needs updating, stops the running process, backs up the current binary, downloads the new version (via GitHub or legacy Artifactory), replaces the binary with proper permissions, updates the database record, cleans up backup files, and publishes completion notifications.
