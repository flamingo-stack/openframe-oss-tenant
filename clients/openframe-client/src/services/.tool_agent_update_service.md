Orchestrates tool agent updates including binary replacement, asset versioning, installation type migration, and legacy Artifactory-based fallback updates for managed tools.

## Key Components

### `ToolAgentUpdateService` (struct)
The main service struct, holding references to all update-related dependencies:
- `github_download_service` — fetches binaries from GitHub releases
- `tool_agent_file_client` — legacy Artifactory file fetcher
- `installed_tools_service` — persists/retrieves tool metadata
- `tool_kill_service` — gracefully stops running tools before updates
- `tool_run_manager` — tracks updating state and restarts tools post-update
- `directory_manager` — resolves file paths for agents/assets
- `config_service` — reads agent configuration
- `installed_agent_publisher` — broadcasts post-update status messages
- `command_params_resolver` — resolves tool launch parameters

### Key Methods

| Method | Description |
|--------|-------------|
| `new(...)` | Constructor; ensures required directories exist on startup |
| `process_update(message)` | Entry point; checks installed version, determines what needs updating, sets update lock |
| `do_updates(...)` | Coordinates tool and asset update sequence; stops tool once before asset updates |
| `do_tool_update(...)` | Handles GitHub-based updates; detects/runs installation type migrations |
| `do_legacy_update(...)` | Fallback path using Artifactory; backs up binary, downloads, sets Unix permissions |
| `do_asset_update(...)` | Per-asset version check and binary replacement |

## Usage Example

```rust
let service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
    command_params_resolver,
);

let message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "2.1.0".to_string(),
    assets: Some(vec![...]),
    download_configurations: vec![...],
};

service.process_update(message).await?;
```
