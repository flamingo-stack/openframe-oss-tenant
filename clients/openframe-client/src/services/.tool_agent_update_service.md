A service that handles updating tool agents to new versions by downloading, backing up, and replacing agent binaries while managing the tool lifecycle.

## Key Components

- **`ToolAgentUpdateService`** - Main service struct that orchestrates tool agent updates
- **`new()`** - Constructor that initializes the service with required dependencies and ensures directories exist
- **`process_update()`** - Public method that processes update messages, validates requirements, and manages the update workflow
- **`do_update()`** - Internal method that performs the actual update process including file operations and version tracking

The service integrates with multiple dependencies including GitHub download service, file clients, tool management services, and configuration services to provide a complete update solution.

## Usage Example

```rust
use tool_agent_update_service::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize the service with required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.2.0".to_string(),
    download_configurations: vec![],
};

match update_service.process_update(update_message).await {
    Ok(_) => println!("Tool updated successfully"),
    Err(e) => eprintln!("Update failed: {:#}", e),
}
```

The service handles the complete update lifecycle: stopping running processes, backing up current binaries, downloading new versions (via GitHub or legacy methods), setting proper permissions, updating version records, and publishing completion notifications.
