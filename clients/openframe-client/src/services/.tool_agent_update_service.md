A service responsible for updating installed tool agents to new versions with atomic rollback capabilities. It handles the complete update lifecycle including process stopping, binary replacement, and state management.

## Key Components

- **ToolAgentUpdateService** - Main service struct managing tool agent updates
- **process_update()** - Processes update messages and orchestrates the update flow
- **do_update()** - Core update logic with backup/restore functionality
- **new()** - Constructor that initializes all dependencies and ensures directories exist

The service integrates with multiple components:
- GitHub download service for fetching new binaries
- Tool kill service for stopping running processes
- Installed tools service for state persistence
- Directory manager for file system operations
- Tool run manager for update status tracking

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize the service with all dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "v1.2.3".to_string(),
    download_configurations: vec![],
};

update_service.process_update(update_message).await?;
```

The service provides atomic updates with automatic backup creation, ensuring safe rollback if the update fails. It supports both modern GitHub-based downloads and legacy Artifactory methods.
