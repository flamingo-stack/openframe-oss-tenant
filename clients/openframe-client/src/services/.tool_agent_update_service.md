Orchestrates the full lifecycle of tool agent updates, handling version checks, binary downloads, installation type migrations, and asset updates for managed tool agents.

## Key Components

### `ToolAgentUpdateService`

The primary struct managing update operations, composed of:

| Dependency | Role |
|---|---|
| `GithubDownloadService` | Downloads tool binaries from GitHub releases |
| `ToolAgentFileClient` | Fetches binaries from Artifactory (legacy path) |
| `InstalledToolsService` | Persists and retrieves installed tool metadata |
| `ToolKillService` | Stops running tool processes before updates |
| `ToolRunManager` | Manages the updating state flag and process restarts |
| `DirectoryManager` | Resolves filesystem paths for agent binaries |
| `AgentConfigurationService` | Provides agent-level configuration |
| `InstalledAgentMessagePublisher` | Publishes post-update status messages |
| `ToolCommandParamsResolver` | Resolves launch parameters for tools |

### Key Methods

- **`process_update`** — Entry point; checks installed version, determines what needs updating (tool binary, assets, or both), sets the updating flag, and delegates work.
- **`do_updates`** — Coordinates sequencing: stops the tool once, runs the tool binary update, then iterates asset updates.
- **`do_tool_update`** — Handles modern GitHub-based updates with OS-specific download configs; detects and executes installation type migrations when needed.
- **`do_legacy_update`** — Fallback path for Artifactory-hosted binaries; backs up the existing binary before replacing it (Standard installation only).
- **`do_asset_update`** — Downloads and writes individual asset files, preserving the executable permission flag from the original install.

## Usage Example

```rust
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
    command_params_resolver,
);

let message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "2.1.0".to_string(),
    assets: Some(vec![/* AssetUpdate entries */]),
    download_configurations: vec![/* OS-specific configs */],
};

update_service.process_update(message).await?;
```

> **Note:** If `download_configurations` is empty, the service automatically falls back to the legacy Artifactory download path. Migration between installation types (e.g., Standard → Package) is detected and handled automatically before applying the update.
