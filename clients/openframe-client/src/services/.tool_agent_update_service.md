A service that orchestrates the updating of tool agents to new versions, handling the complete lifecycle from download to installation with backup and recovery capabilities.

## Key Components

- **ToolAgentUpdateService** - Main service struct managing tool agent updates with dependency injection for all required services
- **process_update()** - Public method that validates update requirements and coordinates the update process
- **do_update()** - Private method handling the actual update workflow including backup, download, and installation
- **Dependencies** - Integrates with GitHub downloads, file management, tool lifecycle, and messaging services

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize the service with all dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "2.0.0".to_string(),
    download_configurations: vec![],
};

match update_service.process_update(update_message).await {
    Ok(()) => println!("Tool updated successfully"),
    Err(e) => eprintln!("Update failed: {:#}", e),
}
```

The service handles version checking, process termination, binary backup, download from multiple sources (GitHub or legacy Artifactory), file permissions, and cleanup operations while maintaining system integrity throughout the update process.
