Service responsible for orchestrating tool agent updates by downloading new binaries, safely replacing existing installations, and managing the complete update lifecycle.

## Key Components

- **ToolAgentUpdateService** - Main service struct that coordinates tool agent updates
- **process_update()** - Primary method that processes tool agent update messages
- **do_update()** - Internal method that handles the actual update process
- **new()** - Constructor that initializes service dependencies and ensures directories exist

## Usage Example

```rust
use tool_agent_update_service::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize the service with required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "example-tool".to_string(),
    version: "1.2.0".to_string(),
    download_configurations: vec![],
};

update_service.process_update(update_message).await?;
```

The service handles version checking, safe binary replacement with backup creation, executable permissions on Unix systems, and publishes completion notifications through the installed agent publisher.
