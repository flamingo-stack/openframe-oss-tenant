Manages automatic updates for tool agents in the Flamingo platform, handling version checks, binary downloads, and safe installation processes.

## Key Components

- **`ToolAgentUpdateService`** - Main service that orchestrates the entire update process
- **`new()`** - Constructor that initializes all required dependencies and ensures directory structure
- **`process_update()`** - Public method that processes update messages and manages the update workflow
- **`do_update()`** - Internal method that performs the actual update operations including backup, download, and installation

## Dependencies

The service integrates with multiple components:
- `GithubDownloadService` - Downloads binaries from GitHub releases
- `ToolAgentFileClient` - Legacy Artifactory-based downloads
- `InstalledToolsService` - Manages tool installation records
- `ToolKillService` - Safely stops running tool processes
- `ToolRunManager` - Tracks tool update states
- `DirectoryManager` - Handles file system paths and directories

## Usage Example

```rust
// Initialize the service
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.2.0".to_string(),
    download_configurations: vec![/* download configs */],
};

update_service.process_update(update_message).await?;
```

The service handles version checking, creates backups, stops running processes, downloads new binaries, sets permissions, and publishes completion messages with comprehensive error handling and logging.
