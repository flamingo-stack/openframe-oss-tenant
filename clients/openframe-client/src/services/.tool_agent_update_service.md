A service that handles updating tool agents to new versions, including backup creation, process management, and binary replacement with rollback capabilities.

## Key Components

- **ToolAgentUpdateService** - Main service struct that orchestrates tool agent updates
- **process_update()** - Public method that validates and initiates update process
- **do_update()** - Internal method that performs the actual update workflow
- Dependencies include file client, GitHub download service, installed tools service, kill service, and configuration management

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Create service with dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.2.0".to_string(),
    download_configurations: vec![],
};

match update_service.process_update(update_message).await {
    Ok(()) => println!("Update completed successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service automatically handles process stopping, binary backup, download from GitHub or Artifactory, file permissions, version tracking, and cleanup operations during tool agent updates.
