Handles automated updates for tool agents by downloading new versions, managing backups, and coordinating service restarts to ensure seamless tool version management.

## Key Components

- **ToolAgentUpdateService** - Main service orchestrating tool agent updates with dependency injection for file operations, download services, and tool management
- **process_update()** - Entry point that validates update requirements and delegates to the update process
- **do_update()** - Core update logic handling backup creation, binary replacement, and rollback capabilities
- **new()** - Constructor ensuring required directories exist and initializing all service dependencies

Key dependencies include GitHub download service for fetching binaries, tool kill service for process management, and installed tools service for version tracking.

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize the service with required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "security-scanner".to_string(),
    version: "1.2.3".to_string(),
    download_configurations: vec![/* download configs */],
};

// Execute the update process
update_service.process_update(update_message).await?;
```

The service automatically handles version checking, process stopping, binary backup/replacement, permission setting (Unix), and publishes completion notifications to maintain system consistency during updates.
