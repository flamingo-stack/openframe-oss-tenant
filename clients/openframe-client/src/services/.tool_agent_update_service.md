Manages automated updates for tool agents installed on the system, handling version checking, binary replacement, and process management during updates.

## Key Components

- **`ToolAgentUpdateService`** - Main service for processing tool agent updates with dependency injection for file operations, GitHub downloads, and process management
- **`process_update()`** - Orchestrates the complete update workflow including version validation and process state management
- **`do_update()`** - Internal method handling the actual binary replacement, backup creation, and post-update cleanup

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Create update service with required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.2.0".to_string(),
    download_configurations: vec![],
};

update_service.process_update(update_message).await?;
```

The service handles both modern GitHub-based downloads and legacy Artifactory methods, automatically creates backups, manages process lifecycle during updates, and publishes completion notifications to maintain system state consistency.
