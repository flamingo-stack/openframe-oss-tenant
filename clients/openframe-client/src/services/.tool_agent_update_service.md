Manages tool agent updates by handling binary downloads, backups, and version management with rollback capabilities.

## Key Components

- **ToolAgentUpdateService** - Main service that orchestrates tool agent updates
- **process_update()** - Processes update messages and validates version changes
- **do_update()** - Handles the complete update workflow including backup, download, and installation
- **Dependencies** - Integrates with multiple services: GitHub downloads, file management, process control, and messaging

## Usage Example

```rust
use tool_agent_update_service::ToolAgentUpdateService;
use models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize the service with required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "2.0.0".to_string(),
    download_configurations: vec![],
};

update_service.process_update(update_message).await?;
```

The service implements a robust update workflow with automatic backup creation, process stopping, binary replacement, and rollback capabilities. It supports both modern GitHub-based downloads and legacy Artifactory methods, ensuring executable permissions are set correctly on Unix systems.
