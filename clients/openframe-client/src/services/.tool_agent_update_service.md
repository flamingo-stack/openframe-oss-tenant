Manages automatic updates for tool agents in the Flamingo platform, handling version checking, binary replacement, and service orchestration during the update process.

## Key Components

- **ToolAgentUpdateService** - Main service that coordinates the complete update workflow
- **process_update()** - Entry point that validates update requirements and manages the update lifecycle
- **do_update()** - Internal method that performs the actual binary replacement with backup/rollback support
- **Service Dependencies** - Integrates with GitHub downloads, file management, process control, and messaging services

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize the service with all required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "monitoring-agent".to_string(),
    version: "2.1.0".to_string(),
    download_configurations: vec![/* download configs */],
};

// Execute the update
match update_service.process_update(update_message).await {
    Ok(()) => println!("Update completed successfully"),
    Err(e) => eprintln!("Update failed: {:#}", e),
}
```

The service automatically handles process stopping, binary backup, download/extraction, permission setting, and database updates, with comprehensive error handling and logging throughout the process.
