Service for updating installed tool agents to newer versions with safe backup and rollback capabilities.

## Key Components

- **`ToolAgentUpdateService`** - Main service struct that orchestrates the update process for tool agents
- **`new()`** - Constructor that initializes the service with required dependencies and ensures directory structure exists
- **`process_update()`** - Public method that processes update messages, validates version differences, and coordinates the update flow
- **`do_update()`** - Private method that handles the actual update logic including backup, download, installation, and cleanup

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize the service with dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.2.0".to_string(),
    download_configurations: vec![],
};

match update_service.process_update(update_message).await {
    Ok(_) => println!("Tool updated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service handles the complete update lifecycle: stops running processes, creates backups, downloads new binaries (via GitHub or legacy Artifactory), installs with proper permissions, updates records, and publishes completion messages.
