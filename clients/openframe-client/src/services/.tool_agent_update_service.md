Manages tool agent updates by orchestrating the download, installation, and version tracking of agent binaries in the Flamingo MSP platform.

## Key Components

- **`ToolAgentUpdateService`** - Main service that coordinates tool agent updates
- **`process_update()`** - Processes update messages and handles version checks
- **`do_update()`** - Performs the actual update workflow with backup and rollback capabilities

## Usage Example

```rust
use tool_agent_update_service::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize the update service
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.2.0".to_string(),
    download_configurations: vec![],
};

update_service.process_update(update_message).await?;
```

The service handles the complete update lifecycle including stopping running processes, creating backups, downloading new binaries, setting permissions, and publishing update notifications. It supports both modern GitHub-based downloads and legacy Artifactory methods for backward compatibility.
