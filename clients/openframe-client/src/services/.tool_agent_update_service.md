A service that handles updating tool agents to new versions with safe backup and rollback mechanisms.

## Key Components

- **ToolAgentUpdateService**: Main service struct that orchestrates the tool agent update process
- **process_update()**: Public method that validates and initiates tool agent updates
- **do_update()**: Internal method that performs the actual update with backup and restoration
- **Dependencies**: Integrates with GitHub download service, file management, tool lifecycle management, and configuration services

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Create the service with all required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.2.3".to_string(),
    download_configurations: vec![],
};

// Execute the update
update_service.process_update(update_message).await?;
```

The service ensures safe updates by stopping the tool process, creating backups, downloading new binaries (from GitHub or legacy Artifactory), setting proper permissions, and publishing completion notifications. It includes validation to skip unnecessary updates and proper error handling with context.
