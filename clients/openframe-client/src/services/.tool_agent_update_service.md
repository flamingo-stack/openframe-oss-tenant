A service responsible for managing tool agent updates within the Flamingo Stack ecosystem. It orchestrates the complete update lifecycle including version checking, process management, binary replacement, and notification publishing.

## Key Components

- **`ToolAgentUpdateService`** - Main service struct that coordinates tool agent updates
- **`process_update`** - Public method that handles incoming update messages and validates update requirements
- **`do_update`** - Private method that performs the actual update process including backup, download, and installation
- **Dependencies** - Integrates with GitHub download service, file clients, tool management services, and configuration services

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize the service with required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.2.0".to_string(),
    download_configurations: vec![],
};

match update_service.process_update(update_message).await {
    Ok(_) => println!("Tool updated successfully"),
    Err(e) => eprintln!("Update failed: {}", e),
}
```

The service automatically handles version comparison, process stopping, binary backup/restoration, executable permissions (on Unix systems), and publishes completion notifications to keep the system synchronized.
