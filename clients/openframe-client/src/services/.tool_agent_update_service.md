Service responsible for updating tool agents to new versions, handling the complete update lifecycle including process termination, binary replacement, and rollback capabilities.

## Key Components

- **ToolAgentUpdateService**: Main service struct that orchestrates tool agent updates
- **process_update()**: Entry point that validates update requirements and delegates to internal update logic
- **do_update()**: Core update implementation that handles the binary replacement process
- **Dependencies**: Integrates with multiple services including GitHub downloads, file management, process control, and messaging

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize the service with required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "2.0.0".to_string(),
    download_configurations: vec![],
};

update_service.process_update(update_message).await?;
```

The service supports both modern GitHub-based downloads and legacy Artifactory methods, automatically handles process lifecycle management, creates backups for rollback safety, and publishes completion notifications to the messaging system.
