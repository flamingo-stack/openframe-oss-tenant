This service handles updating tool agents to new versions, managing the complete update lifecycle including process termination, file backup, binary download, and installation.

## Key Components

- **ToolAgentUpdateService**: Main service orchestrating tool agent updates
- **process_update()**: Entry point that validates update requirements and delegates to update logic
- **do_update()**: Core update implementation handling file operations and process management
- **Dependencies**: Integrates with GitHub download, file management, tool lifecycle, and messaging services

The service supports both modern GitHub-based downloads with platform-specific configurations and legacy Artifactory-based downloads as fallback.

## Usage Example

```rust
use tool_agent_update_service::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize service with required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "1.2.3".to_string(),
    download_configurations: vec![/* platform configs */],
};

update_service.process_update(update_message).await?;
```

The service automatically handles version checking, process stopping, file backup/restore on failure, binary download, permission setting (Unix), and status publishing throughout the update process.
