A service that manages the complete lifecycle of updating tool agents in the Flamingo platform, handling version checking, binary replacement, and process management with robust error handling and rollback capabilities.

## Key Components

- **ToolAgentUpdateService**: Main service struct that orchestrates tool agent updates
- **process_update()**: Primary entry point that validates and coordinates the update process
- **do_update()**: Core update implementation handling binary replacement and permissions
- **Service Dependencies**: Integrates with GitHub downloads, file management, process control, and configuration services

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize the service with all dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "2.0.0".to_string(),
    download_configurations: vec![],
};

match update_service.process_update(update_message).await {
    Ok(()) => println!("Tool updated successfully"),
    Err(e) => eprintln!("Update failed: {:#}", e),
}
```

The service provides atomic updates with automatic backup/restore, cross-platform binary permission handling, and comprehensive logging throughout the update process.
