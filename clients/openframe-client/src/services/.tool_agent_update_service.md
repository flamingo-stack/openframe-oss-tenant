Manages the update process for tool agents in the Flamingo OpenFrame platform, handling version checks, binary downloads, and safe rollback mechanisms.

## Key Components

- **ToolAgentUpdateService** - Main service orchestrating tool agent updates
- **process_update()** - Entry point for processing update messages with version validation
- **do_update()** - Core update logic handling download, backup, and binary replacement
- **Dependency services** - GitHub downloads, file management, process control, and messaging

## Usage Example

```rust
use crate::services::ToolAgentUpdateService;
use crate::models::tool_agent_update_message::ToolAgentUpdateMessage;

// Initialize the service with all required dependencies
let update_service = ToolAgentUpdateService::new(
    github_download_service,
    tool_agent_file_client,
    installed_tools_service,
    tool_kill_service,
    tool_run_manager,
    directory_manager,
    config_service,
    installed_agent_publisher,
);

// Process an update message
let update_message = ToolAgentUpdateMessage {
    tool_agent_id: "my-tool".to_string(),
    version: "v1.2.0".to_string(),
    download_configurations: vec![/* download configs */],
};

match update_service.process_update(update_message).await {
    Ok(()) => println!("Update completed successfully"),
    Err(e) => eprintln!("Update failed: {:#}", e),
}
```

The service ensures safe updates by stopping processes, creating backups, validating versions, and setting proper file permissions. It supports both modern GitHub-based downloads and legacy Artifactory methods for maximum compatibility.
