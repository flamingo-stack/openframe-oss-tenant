Manages the persistence of a shared authentication token by encrypting it and writing it atomically to a secured directory.

## Key Components

### `SharedTokenService`

A cloneable service struct that combines directory management and encryption to safely store shared tokens on disk.

**Fields:**
- `dir_manager: DirectoryManager` — Resolves the secured storage directory path
- `encryption_service: EncryptionService` — Handles token encryption before write

**Methods:**

| Method | Description |
|--------|-------------|
| `new(dir_manager, encryption_service) -> Self` | Constructs a new `SharedTokenService` instance |
| `update(token: String) -> Result<()>` | Encrypts the token and atomically writes it to `secured_dir/shared_token.enc` |

## Usage Example

```rust
use crate::services::shared_token_service::SharedTokenService;
use crate::platform::directories::DirectoryManager;
use crate::services::EncryptionService;

let dir_manager = DirectoryManager::new(/* ... */);
let encryption_service = EncryptionService::new(/* ... */);

let token_service = SharedTokenService::new(dir_manager, encryption_service);

// Persist an updated shared token securely
token_service.update("my-new-auth-token".to_string())?;
```

## Notes

- The token is written to `shared_token.enc` inside the platform's secured directory, ensuring it is never stored in plaintext.
- `atomic_write` prevents partial writes or corruption if the process is interrupted mid-operation.
- See related source at [`shared_token_service.rs`](https://github.com/flamingo-stack/openframe-oss-tenant/blob/main/src/services/shared_token_service.rs)
