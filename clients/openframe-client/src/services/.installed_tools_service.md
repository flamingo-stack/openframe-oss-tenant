Manages persistent storage of installed tools, reading and writing a JSON file in the secured directory with atomic write operations and async-safe concurrent access.

## Key Components

- **`InstalledToolsService`** — Cloneable service struct holding the JSON file path and a shared async mutex to serialize write operations.
- **`new(directory_manager)`** — Constructs the service, resolving the path to `secured_dir/installed_tools.json` and ensuring the directory exists.
- **`save(tool)`** — Upserts an `InstalledTool` by `tool_agent_id`; updates in place if found, appends if not.
- **`set_state(tool_agent_id, state)`** — Updates only the `state` field of a matching tool; returns `false` if not found.
- **`get_by_tool_agent_id(tool_id)`** — Returns a single tool by ID, or `None`.
- **`get_all()`** — Reads and deserializes all tools from disk; returns an empty `Vec` if the file does not yet exist.
- **`delete_by_tool_agent_id(tool_agent_id)`** — Removes a tool by ID; returns `true` if deleted, `false` if not found.
- **`persist(tools)`** *(private)* — Atomically writes the full tool list to disk using a `.json.tmp` temp file, `fsync`, and rename.

## Usage Example

```rust
use crate::platform::directories::DirectoryManager;
use crate::services::InstalledToolsService;
use crate::models::{InstalledTool, ToolRecordState};

let dir_manager = DirectoryManager::new()?;
let service = InstalledToolsService::new(dir_manager)?;

// Upsert a tool
service.save(InstalledTool { tool_agent_id: "agent-123".into(), ..Default::default() }).await?;

// Update its state
let updated = service.set_state("agent-123", ToolRecordState::Active).await?;

// Retrieve it
let tool = service.get_by_tool_agent_id("agent-123").await?;

// Remove it
let removed = service.delete_by_tool_agent_id("agent-123").await?;
```

> **Thread safety:** all mutations acquire the `Arc<Mutex<()>>` writer lock before reading and writing, preventing concurrent file corruption.
