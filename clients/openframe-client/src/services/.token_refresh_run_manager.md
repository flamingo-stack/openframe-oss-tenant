Proactively refreshes the agent's access token before expiry, keeping `shared_token.enc` valid without requiring a NATS reconnect.

## Key Components

**`TokenRefreshRunManager`** — Main struct that owns the refresh loop. Holds references to `AgentAuthService`, `AgentConfigurationService`, and `DeactivationService`.

**`start()`** — Spawns a background Tokio task containing two nested loops:
- **Outer loop**: Checks for tenant-gone suspension. If suspended, delegates to `DeactivationService` for exponential backoff probing; otherwise computes the next refresh delay and waits.
- **Inner retry loop**: Calls `reauthenticate()` with a 30-second timeout, retrying every 60 seconds on failure until success or tenant suspension is detected.

**`next_refresh_delay()`** (private) — Reads the current access token, decodes its `exp` claim via `jwt::token_exp_unix`, and returns a `Duration` until the token should be refreshed. Falls back to 30 minutes if the token is unreadable or has no decodable expiry.

### Timing Constants

| Constant | Value | Purpose |
|---|---|---|
| `REFRESH_MARGIN` | 5 min | Refresh this far before expiry under normal TTLs |
| `MIN_LEAD` | 15 s | Lead time for short-lived tokens to avoid per-loop refresh |
| `FALLBACK_INTERVAL` | 30 min | Used when `exp` cannot be decoded |
| `RETRY_INTERVAL` | 60 s | Delay between failed refresh attempts |
| `REAUTH_TIMEOUT` | 30 s | Hard cap on a single `reauthenticate()` call |

## Usage Example

```rust
let manager = TokenRefreshRunManager::new(
    auth_service.clone(),
    config_service.clone(),
    Arc::clone(&deactivation_service),
);

// Spawns a background task; call once at agent startup
manager.start();
```
