Handles the agent registration flow with retry logic, ensuring agents are properly registered with the Flamingo platform before operation.

## Key Components

- **RegistrationProcessor** - Main processor that orchestrates agent registration
- **process()** - Primary method that checks for existing registration or initiates registration loop
- **attempt_registration()** - Internal method that performs a single registration attempt
- **Dependencies**: 
  - `AgentRegistrationService` - Handles actual registration API calls
  - `AgentConfigurationService` - Manages agent configuration and machine ID storage

## Usage Example

```rust
use crate::registration_processor::RegistrationProcessor;
use crate::services::{AgentRegistrationService, AgentConfigurationService};

// Initialize the processor with required services
let registration_service = AgentRegistrationService::new(api_client);
let config_service = AgentConfigurationService::new(config_path);
let processor = RegistrationProcessor::new(registration_service, config_service);

// Start the registration process
processor.process().await?;
```

The processor implements intelligent registration logic - it first checks if the agent is already registered (via machine_id), and if not, enters a retry loop with 60-second intervals until registration succeeds. This ensures agents can recover from temporary network issues or service unavailability during startup.
