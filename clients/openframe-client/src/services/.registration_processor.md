Manages the agent registration workflow with automatic retry logic and machine ID validation.

## Key Components

- **`RegistrationProcessor`** - Main processor that coordinates agent registration
- **`new()`** - Constructor accepting registration and configuration services
- **`process()`** - Public method that handles the complete registration flow with retry logic
- **`attempt_registration()`** - Private helper that performs a single registration attempt

## Usage Example

```rust
use crate::services::{AgentRegistrationService, AgentConfigurationService};
use crate::processors::RegistrationProcessor;

#[tokio::main]
async fn main() -> Result<()> {
    let registration_service = AgentRegistrationService::new();
    let config_service = AgentConfigurationService::new();
    
    let processor = RegistrationProcessor::new(
        registration_service,
        config_service,
    );
    
    // Start registration process
    processor.process().await?;
    
    Ok(())
}
```

The processor first checks for an existing machine ID to avoid duplicate registrations. If no ID exists, it enters a retry loop with 60-second intervals between failed attempts. Registration succeeds when the agent receives a valid machine ID from the registration service.
