A registration processor that handles agent registration with automatic retry logic and machine ID validation for the Flamingo AI-powered MSP platform.

## Key Components

- **RegistrationProcessor** - Main struct that orchestrates agent registration workflow
- **process()** - Public method that checks for existing registration and initiates registration loop if needed
- **attempt_registration()** - Private method that performs a single registration attempt
- **Services Integration** - Uses `AgentRegistrationService` for API calls and `AgentConfigurationService` for machine ID management

## Usage Example

```rust
use crate::registration_processor::RegistrationProcessor;
use crate::services::{AgentRegistrationService, AgentConfigurationService};

#[tokio::main]
async fn main() -> Result<()> {
    // Initialize services
    let registration_service = AgentRegistrationService::new(api_client);
    let config_service = AgentConfigurationService::new();
    
    // Create processor and start registration
    let processor = RegistrationProcessor::new(registration_service, config_service);
    
    // Process registration (will skip if already registered)
    processor.process().await?;
    
    println!("Agent registration completed successfully");
    Ok(())
}
```

The processor implements intelligent retry logic with 60-second intervals and skips registration if a machine ID already exists, making it safe to run multiple times during agent initialization.
