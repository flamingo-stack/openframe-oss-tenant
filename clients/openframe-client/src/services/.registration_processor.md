Handles agent registration with automatic retry logic, checking for existing machine IDs and managing the registration lifecycle until successful completion.

## Key Components

- **`RegistrationProcessor`** - Main processor struct that orchestrates agent registration
- **`new()`** - Constructor that takes registration and configuration services
- **`process()`** - Primary entry point that handles the complete registration flow
- **`attempt_registration()`** - Internal method that performs a single registration attempt

## Usage Example

```rust
use crate::services::{AgentRegistrationService, AgentConfigurationService};
use crate::processors::RegistrationProcessor;

// Initialize services
let registration_service = AgentRegistrationService::new(client);
let config_service = AgentConfigurationService::new();

// Create processor
let processor = RegistrationProcessor::new(registration_service, config_service);

// Start registration process
match processor.process().await {
    Ok(_) => println!("Agent registered successfully"),
    Err(e) => eprintln!("Registration failed: {}", e),
}
```

The processor implements intelligent registration logic - it first checks if a machine ID already exists to avoid duplicate registrations, then enters a retry loop with 60-second intervals until registration succeeds. The design separates concerns by delegating actual registration calls to the `AgentRegistrationService` while handling the orchestration logic internally.
