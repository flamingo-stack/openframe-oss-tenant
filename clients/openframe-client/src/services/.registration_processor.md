Handles the agent registration workflow with automatic retry logic, ensuring agents are properly registered with the Flamingo platform before becoming operational.

## Key Components

- **`RegistrationProcessor`** - Main processor that orchestrates agent registration
- **`new()`** - Constructor taking registration and configuration services
- **`process()`** - Main entry point that checks existing registration and initiates registration loop
- **`attempt_registration()`** - Internal method that performs a single registration attempt

## Usage Example

```rust
use crate::services::{AgentRegistrationService, AgentConfigurationService};
use crate::processors::RegistrationProcessor;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let registration_service = AgentRegistrationService::new();
    let config_service = AgentConfigurationService::new();
    
    let processor = RegistrationProcessor::new(
        registration_service,
        config_service,
    );
    
    // Process registration - will retry until successful
    processor.process().await?;
    
    println!("Agent successfully registered!");
    Ok(())
}
```

The processor implements a simple retry mechanism with 60-second intervals between failed attempts. It skips registration if a machine ID already exists, making it safe to run multiple times. The registration continues indefinitely until successful, with a TODO note indicating plans for exponential backoff in future iterations.
