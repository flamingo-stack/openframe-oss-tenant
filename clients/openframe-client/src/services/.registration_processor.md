Handles agent registration processing with retry logic and machine ID validation for the Flamingo AI-powered MSP platform. Orchestrates registration attempts and configuration management to ensure agents are properly registered with the OpenFrame system.

## Key Components

- **`RegistrationProcessor`** - Main processor that coordinates agent registration workflow
- **`new()`** - Constructor accepting registration and configuration services
- **`process()`** - Public method that handles the complete registration flow with retry logic
- **`attempt_registration()`** - Private method that performs a single registration attempt

## Usage Example

```rust
use crate::services::{AgentRegistrationService, AgentConfigurationService};
use crate::processors::RegistrationProcessor;

// Initialize services
let registration_service = AgentRegistrationService::new(api_client);
let config_service = AgentConfigurationService::new(config_path);

// Create and run registration processor
let processor = RegistrationProcessor::new(registration_service, config_service);

// Process registration (will retry on failure)
if let Err(e) = processor.process().await {
    eprintln!("Registration failed: {}", e);
}
```

The processor automatically skips registration if a machine ID already exists, implements a 60-second retry loop on failures, and provides comprehensive logging for monitoring registration status.
