Handles the agent registration workflow with retry logic and machine ID validation for the Flamingo MSP platform.

## Key Components

### RegistrationProcessor
Main processor struct that coordinates agent registration:
- **`registration_service`** - Service for handling agent registration API calls
- **`config_service`** - Service for managing agent configuration and machine ID

### Core Methods
- **`new()`** - Creates a new processor instance with required services
- **`process()`** - Main entry point that checks for existing registration and handles retry loop
- **`attempt_registration()`** - Private method that performs a single registration attempt

## Usage Example

```rust
use crate::registration_processor::RegistrationProcessor;
use crate::services::{AgentRegistrationService, AgentConfigurationService};

#[tokio::main]
async fn main() -> Result<()> {
    let registration_service = AgentRegistrationService::new(api_client);
    let config_service = AgentConfigurationService::new(config_path);
    
    let processor = RegistrationProcessor::new(
        registration_service,
        config_service,
    );
    
    // Start registration process - will skip if already registered
    processor.process().await?;
    
    Ok(())
}
```

The processor implements intelligent retry logic with a 60-second delay between attempts. It automatically skips registration if a machine ID already exists, making it safe to run multiple times. Failed registration attempts are logged with full error context for debugging.
