Handles agent registration processing with retry logic and machine ID validation for the Flamingo MSP platform.

## Key Components

- **`RegistrationProcessor`** - Main processor struct that orchestrates agent registration
- **`new()`** - Constructor accepting registration and configuration services
- **`process()`** - Primary entry point that checks for existing machine ID and handles registration loop
- **`attempt_registration()`** - Internal method that performs a single registration attempt

## Usage Example

```rust
use crate::registration_processor::RegistrationProcessor;
use crate::services::{AgentRegistrationService, AgentConfigurationService};

#[tokio::main]
async fn main() -> Result<()> {
    let registration_service = AgentRegistrationService::new();
    let config_service = AgentConfigurationService::new();
    
    let processor = RegistrationProcessor::new(
        registration_service,
        config_service
    );
    
    // Process registration - will skip if machine_id exists
    processor.process().await?;
    
    Ok(())
}
```

The processor implements a robust registration flow that:
- Checks for existing machine ID to avoid duplicate registrations
- Retries failed registration attempts every 60 seconds
- Uses structured logging for monitoring registration status
- Leverages dependency injection for testability and modularity
