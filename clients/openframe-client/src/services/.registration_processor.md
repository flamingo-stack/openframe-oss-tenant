Handles agent registration with the Flamingo platform by orchestrating machine ID checks and retry logic for registration attempts.

## Key Components

- **RegistrationProcessor** - Main struct that orchestrates the registration workflow
- **new()** - Constructor accepting registration and configuration services  
- **process()** - Primary method that checks for existing machine ID and handles registration loop
- **attempt_registration()** - Internal method that performs a single registration attempt

## Usage Example

```rust
use crate::services::{AgentRegistrationService, AgentConfigurationService};
use crate::registration_processor::RegistrationProcessor;

#[tokio::main]
async fn main() -> Result<()> {
    let registration_service = AgentRegistrationService::new();
    let config_service = AgentConfigurationService::new();
    
    let processor = RegistrationProcessor::new(
        registration_service,
        config_service
    );
    
    // Start the registration process
    processor.process().await?;
    
    Ok(())
}
```

The processor implements smart registration logic - it first checks if the agent is already registered by looking for an existing machine ID. If no ID is found, it enters a retry loop with 60-second intervals between failed attempts. The registration continues until successful or the application is terminated. This ensures robust agent onboarding even in unstable network conditions.
