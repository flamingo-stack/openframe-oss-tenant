Handles the automated registration process for agents with retry logic and persistence checking.

## Key Components

- **RegistrationProcessor** - Main processor that orchestrates agent registration workflow
- **process()** - Primary entry point that checks for existing registration and handles retry loop
- **attempt_registration()** - Internal method that performs actual registration attempt via service
- **new()** - Constructor that accepts registration and configuration services

## Usage Example

```rust
use crate::registration_processor::RegistrationProcessor;
use crate::services::{AgentRegistrationService, AgentConfigurationService};

// Initialize the processor with required services
let registration_service = AgentRegistrationService::new(client);
let config_service = AgentConfigurationService::new();

let processor = RegistrationProcessor::new(
    registration_service,
    config_service,
);

// Start the registration process
match processor.process().await {
    Ok(_) => println!("Agent registered successfully"),
    Err(e) => eprintln!("Registration failed: {}", e),
}
```

The processor implements a retry loop with 60-second intervals when registration fails, and skips registration entirely if a machine ID already exists. It uses structured logging to track registration attempts and outcomes, making it suitable for production deployments where network issues or service unavailability might cause temporary failures.
