A processor that handles agent registration workflow, checking for existing machine IDs and managing retry logic for failed registration attempts.

## Key Components

- **RegistrationProcessor** - Main struct that orchestrates the registration process
  - `registration_service` - Service for handling agent registration API calls
  - `config_service` - Service for managing agent configuration and machine IDs
- **new()** - Constructor that initializes the processor with required services
- **process()** - Main entry point that checks for existing registration and manages the registration loop
- **attempt_registration()** - Internal method that performs a single registration attempt

## Usage Example

```rust
use crate::registration_processor::RegistrationProcessor;
use crate::services::{AgentRegistrationService, AgentConfigurationService};

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let registration_service = AgentRegistrationService::new(api_client);
    let config_service = AgentConfigurationService::new(config_path);
    
    let processor = RegistrationProcessor::new(
        registration_service,
        config_service,
    );
    
    // Start the registration process
    processor.process().await?;
    
    println!("Agent successfully registered!");
    Ok(())
}
```

The processor implements a retry loop with 60-second intervals for failed registration attempts and skips registration if a machine ID already exists, making it safe to run multiple times.
