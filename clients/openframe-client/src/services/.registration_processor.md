Handles the agent registration process with automatic retry logic and machine ID validation for the Flamingo MSP platform.

## Key Components

- **`RegistrationProcessor`** - Main processor struct that manages agent registration workflow
- **`new()`** - Constructor that takes registration and configuration services as dependencies
- **`process()`** - Entry point that checks for existing machine ID and starts registration loop if needed
- **`attempt_registration()`** - Internal method that attempts a single registration request

## Usage Example

```rust
use crate::services::{AgentRegistrationService, AgentConfigurationService};
use crate::processors::RegistrationProcessor;

#[tokio::main]
async fn main() -> Result<()> {
    let registration_service = AgentRegistrationService::new(api_client);
    let config_service = AgentConfigurationService::new(config_path);
    
    let processor = RegistrationProcessor::new(
        registration_service,
        config_service,
    );
    
    // Start registration process
    processor.process().await?;
    
    Ok(())
}
```

The processor implements a retry-on-failure pattern with 60-second intervals when registration attempts fail. It automatically skips registration if a machine ID already exists, preventing duplicate registrations. The current implementation uses fixed retry intervals but includes a TODO for exponential backoff improvements.
