Handles agent registration lifecycle with automatic retry logic for MSP platform agents.

## Key Components

- **`RegistrationProcessor`** - Main processor that orchestrates agent registration with retry mechanisms
- **`new()`** - Constructor accepting registration and configuration services as dependencies
- **`process()`** - Primary entry point that checks for existing registration and initiates registration loop if needed
- **`attempt_registration()`** - Internal method that performs a single registration attempt with error handling

## Usage Example

```rust
use crate::services::{AgentRegistrationService, AgentConfigurationService};
use crate::processors::RegistrationProcessor;

// Initialize services
let registration_service = AgentRegistrationService::new(api_client);
let config_service = AgentConfigurationService::new();

// Create processor
let processor = RegistrationProcessor::new(registration_service, config_service);

// Start registration process
processor.process().await?;
```

The processor implements a smart registration flow that:
- Checks for existing machine IDs to avoid duplicate registrations
- Retries failed registration attempts every 60 seconds with detailed error logging
- Uses async/await for non-blocking operation in the MSP agent runtime
- Leverages dependency injection for testable, modular architecture
