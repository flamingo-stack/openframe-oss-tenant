Handles agent registration workflow with retry logic and machine ID detection for the Flamingo MSP platform.

## Key Components

- **`RegistrationProcessor`** - Main processor struct that coordinates agent registration
- **`new()`** - Constructor accepting registration and configuration services
- **`process()`** - Primary entry point that checks for existing machine ID and handles registration loop
- **`attempt_registration()`** - Internal method that performs a single registration attempt

## Usage Example

```rust
use crate::services::{AgentRegistrationService, AgentConfigurationService};
use crate::registration_processor::RegistrationProcessor;

// Initialize services
let registration_service = AgentRegistrationService::new();
let config_service = AgentConfigurationService::new();

// Create processor
let processor = RegistrationProcessor::new(registration_service, config_service);

// Start registration process
processor.process().await?;
```

The processor first checks if a machine ID already exists to avoid duplicate registrations. If no machine ID is found, it enters a retry loop with 60-second intervals between failed attempts. The implementation uses structured logging and error context for debugging. A TODO comment indicates plans for exponential backoff to improve retry behavior.
