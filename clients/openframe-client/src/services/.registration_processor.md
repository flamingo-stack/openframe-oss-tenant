A processor that manages agent registration lifecycle, continuously attempting to register agents with the Flamingo platform until successful.

## Key Components

- **`RegistrationProcessor`** - Main struct orchestrating agent registration with built-in retry logic
- **`new()`** - Constructor accepting registration and configuration services
- **`process()`** - Primary entry point that handles the complete registration flow
- **`attempt_registration()`** - Internal method for single registration attempts with error context

## Usage Example

```rust
use crate::services::{AgentRegistrationService, AgentConfigurationService};
use crate::registration_processor::RegistrationProcessor;

// Initialize services
let registration_service = AgentRegistrationService::new();
let config_service = AgentConfigurationService::new();

// Create processor and start registration
let processor = RegistrationProcessor::new(registration_service, config_service);
processor.process().await?;
```

The processor implements a smart registration strategy: it first checks for an existing machine ID to avoid unnecessary re-registration, then enters a retry loop with 60-second intervals if registration fails. This ensures reliable agent onboarding in distributed MSP environments where network conditions may be unstable.
