Handles the agent registration process with retry logic, checking for existing machine IDs and coordinating between registration and configuration services.

## Key Components

- **`RegistrationProcessor`** - Main struct that orchestrates agent registration workflow
- **`new()`** - Constructor accepting registration and configuration services
- **`process()`** - Primary method that handles the complete registration flow with retry logic
- **`attempt_registration()`** - Private helper method for single registration attempts

## Usage Example

```rust
use crate::services::{AgentRegistrationService, AgentConfigurationService};
use crate::registration_processor::RegistrationProcessor;

// Initialize services
let registration_service = AgentRegistrationService::new();
let config_service = AgentConfigurationService::new();

// Create processor
let processor = RegistrationProcessor::new(registration_service, config_service);

// Process registration (will retry on failure)
match processor.process().await {
    Ok(_) => println!("Agent registered successfully"),
    Err(e) => eprintln!("Registration failed: {}", e),
}
```

The processor implements a retry loop with 60-second intervals when registration fails, and skips registration entirely if a machine ID already exists. It uses structured logging to track registration attempts and outcomes.
