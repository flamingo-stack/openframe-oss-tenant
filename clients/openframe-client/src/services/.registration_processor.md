Processes agent registration with the Flamingo platform, handling initial registration checks and retry logic for unregistered agents.

## Key Components

- **`RegistrationProcessor`** - Main processor struct that orchestrates agent registration workflow
- **`new()`** - Constructor taking registration and configuration services as dependencies
- **`process()`** - Primary entry point that checks for existing registration and initiates registration loop if needed
- **`attempt_registration()`** - Internal method that performs a single registration attempt with error context

## Usage Example

```rust
use crate::services::{AgentRegistrationService, AgentConfigurationService};
use crate::processors::RegistrationProcessor;

// Initialize services
let registration_service = AgentRegistrationService::new();
let config_service = AgentConfigurationService::new();

// Create processor
let processor = RegistrationProcessor::new(registration_service, config_service);

// Process registration
match processor.process().await {
    Ok(_) => println!("Agent registered successfully"),
    Err(e) => eprintln!("Registration failed: {}", e),
}
```

The processor implements a simple retry mechanism with 60-second intervals when registration fails. It skips registration entirely if a machine ID already exists, preventing duplicate registrations. Error handling uses `anyhow` for rich error context propagation.
