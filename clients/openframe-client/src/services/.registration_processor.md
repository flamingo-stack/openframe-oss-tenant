Handles agent registration processing with automatic retry logic for unregistered agents in the Flamingo MSP platform. The processor checks for existing machine IDs and initiates registration loops for new agents.

## Key Components

- **`RegistrationProcessor`** - Main struct that orchestrates agent registration with built-in retry mechanisms
- **`new()`** - Constructor that takes registration and configuration services as dependencies
- **`process()`** - Primary entry point that checks for existing registration and starts registration loop if needed
- **`attempt_registration()`** - Internal method that performs a single registration attempt with the upstream service

## Usage Example

```rust
use crate::registration_processor::RegistrationProcessor;
use crate::services::{AgentRegistrationService, AgentConfigurationService};

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let registration_service = AgentRegistrationService::new(/* config */);
    let config_service = AgentConfigurationService::new(/* config */);
    
    let processor = RegistrationProcessor::new(
        registration_service,
        config_service,
    );
    
    // Start registration process (will skip if already registered)
    processor.process().await?;
    
    println!("Agent registration complete");
    Ok(())
}
```

The processor implements a simple retry loop with 60-second delays on failure, logging all registration attempts and outcomes for debugging purposes.
