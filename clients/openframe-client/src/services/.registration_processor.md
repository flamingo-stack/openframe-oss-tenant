A background processor that handles agent registration with retry logic, ensuring agents are properly registered with the system before they begin operation.

## Key Components

- **RegistrationProcessor** - Main processor that orchestrates agent registration
- **process()** - Public method that starts the registration workflow with retry logic
- **attempt_registration()** - Internal method that handles individual registration attempts

## Usage Example

```rust
use crate::registration_processor::RegistrationProcessor;
use crate::services::{AgentRegistrationService, AgentConfigurationService};

// Initialize services
let registration_service = AgentRegistrationService::new();
let config_service = AgentConfigurationService::new();

// Create processor
let processor = RegistrationProcessor::new(
    registration_service,
    config_service,
);

// Start registration process
match processor.process().await {
    Ok(_) => println!("Agent successfully registered"),
    Err(e) => eprintln!("Registration failed: {}", e),
}
```

The processor implements a simple retry loop with 60-second intervals when registration fails. It skips registration if an existing `machine_id` is detected, preventing duplicate registrations. Future improvements include exponential backoff for retry timing.
