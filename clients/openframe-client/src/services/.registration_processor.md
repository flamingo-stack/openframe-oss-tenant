Handles the agent registration workflow by coordinating between registration and configuration services to ensure agents are properly registered with unique machine IDs.

## Key Components

- **RegistrationProcessor**: Main struct that orchestrates the agent registration process
- **process()**: Primary method that checks for existing registration and initiates registration loop if needed
- **attempt_registration()**: Internal method that attempts a single registration request
- **Dependencies**: Uses `AgentRegistrationService` for API calls and `AgentConfigurationService` for machine ID management

## Usage Example

```rust
use crate::registration_processor::RegistrationProcessor;
use crate::services::{AgentRegistrationService, AgentConfigurationService};

async fn setup_registration() -> Result<()> {
    let registration_service = AgentRegistrationService::new(api_client);
    let config_service = AgentConfigurationService::new();
    
    let processor = RegistrationProcessor::new(
        registration_service,
        config_service,
    );
    
    // Start the registration process
    processor.process().await?;
    
    Ok(())
}
```

The processor implements a retry loop with 60-second intervals for failed registration attempts, automatically skipping registration if a machine ID already exists. This ensures resilient agent onboarding while preventing duplicate registrations.
