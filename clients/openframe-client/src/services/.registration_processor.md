Handles automated agent registration with retry logic and machine ID management for the Flamingo AI platform.

## Key Components

- **RegistrationProcessor** - Main processor struct that orchestrates agent registration
- **process()** - Entry point that checks for existing machine ID and handles registration loop
- **attempt_registration()** - Internal method that calls the registration service
- **new()** - Constructor accepting registration and configuration services

## Usage Example

```rust
use crate::registration_processor::RegistrationProcessor;
use crate::services::{AgentRegistrationService, AgentConfigurationService};

// Initialize services
let registration_service = AgentRegistrationService::new(api_client);
let config_service = AgentConfigurationService::new(config_path);

// Create processor
let processor = RegistrationProcessor::new(registration_service, config_service);

// Start registration process
match processor.process().await {
    Ok(_) => println!("Agent registered successfully"),
    Err(e) => eprintln!("Registration failed: {}", e),
}
```

The processor implements a retry loop with 60-second intervals when registration fails, and automatically skips registration if a machine ID already exists. It uses structured logging to track registration attempts and outcomes.
