Orchestrates agent registration workflow by coordinating between registration and configuration services to ensure proper agent setup.

## Key Components

- **RegistrationProcessor**: Main processor struct that manages the registration workflow
- **new()**: Constructor that takes registration and configuration services as dependencies
- **process()**: Public method that handles the complete registration flow with retry logic
- **attempt_registration()**: Private method that performs a single registration attempt

## Usage Example

```rust
use crate::services::{AgentRegistrationService, AgentConfigurationService};
use crate::processors::RegistrationProcessor;

// Initialize services
let registration_service = AgentRegistrationService::new(config.clone());
let config_service = AgentConfigurationService::new();

// Create and run processor
let processor = RegistrationProcessor::new(registration_service, config_service);

// Process registration (will skip if machine_id already exists)
processor.process().await?;
```

The processor implements intelligent registration logic that:
- Checks for existing machine_id to avoid duplicate registrations
- Retries failed registrations with 60-second intervals
- Logs registration progress and errors for monitoring
- Uses async/await for non-blocking operations
