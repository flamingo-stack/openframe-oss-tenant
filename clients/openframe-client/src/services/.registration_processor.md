Handles automated agent registration with retry logic and machine ID persistence for the Flamingo MSP platform.

## Key Components

- **`RegistrationProcessor`** - Main orchestrator that manages agent registration workflow
- **`new()`** - Constructor accepting registration and configuration services
- **`process()`** - Primary entry point that checks for existing registration and handles retry loop
- **`attempt_registration()`** - Private method that performs single registration attempt

## Usage Example

```rust
use crate::services::{AgentRegistrationService, AgentConfigurationService};

// Initialize services
let registration_service = AgentRegistrationService::new(api_client);
let config_service = AgentConfigurationService::new(config_path);

// Create processor and start registration
let processor = RegistrationProcessor::new(registration_service, config_service);
processor.process().await?;
```

The processor implements intelligent registration behavior:
- Skips registration if a machine ID already exists
- Continuously retries failed registration attempts with 60-second intervals
- Uses structured logging for monitoring registration status
- Returns early on successful registration or existing machine ID detection

This component is essential for agent initialization in the OpenFrame platform, ensuring agents are properly registered with the central management system before beginning operations.
