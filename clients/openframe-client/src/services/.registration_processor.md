Handles automatic agent registration with the Flamingo platform, managing the registration lifecycle with retry logic and machine ID persistence.

## Key Components

- **`RegistrationProcessor`** - Main processor struct that coordinates agent registration attempts
- **`new()`** - Constructor that accepts registration and configuration services
- **`process()`** - Entry point that checks for existing machine ID and handles registration loop
- **`attempt_registration()`** - Internal method that performs a single registration attempt

## Usage Example

```rust
use crate::registration_processor::RegistrationProcessor;
use crate::services::{AgentRegistrationService, AgentConfigurationService};

// Initialize services
let registration_service = AgentRegistrationService::new(api_client);
let config_service = AgentConfigurationService::new(config_path);

// Create and run registration processor
let processor = RegistrationProcessor::new(registration_service, config_service);

// Process registration (will skip if machine_id exists)
processor.process().await?;
```

The processor implements a retry loop with 60-second intervals when registration fails, automatically skipping registration if a machine ID already exists. It uses structured logging to track registration attempts and includes error context for debugging failed registrations.
