Handles agent registration flow with retry logic and machine ID detection for the Flamingo/OpenFrame platform.

## Key Components

- **`RegistrationProcessor`** - Main orchestrator for agent registration process
- **`new()`** - Constructor accepting registration and configuration services
- **`process()`** - Primary entry point that checks for existing registration and initiates registration loop
- **`attempt_registration()`** - Internal method that wraps the registration service call with error context

## Usage Example

```rust
use crate::services::{AgentRegistrationService, AgentConfigurationService};
use crate::registration_processor::RegistrationProcessor;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let registration_service = AgentRegistrationService::new(api_client);
    let config_service = AgentConfigurationService::new(config_path);
    
    let processor = RegistrationProcessor::new(registration_service, config_service);
    
    // Start registration process - will skip if machine_id exists
    processor.process().await?;
    
    println!("Agent registration completed successfully");
    Ok(())
}
```

The processor implements a smart registration flow that:
- Checks for existing `machine_id` to avoid duplicate registrations
- Retries failed registration attempts every 60 seconds with detailed error logging
- Uses structured logging for monitoring registration status
- Leverages dependency injection for testability with service abstractions
