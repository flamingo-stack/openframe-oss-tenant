Handles agent registration logic with retry mechanisms and machine ID validation for the Flamingo MSP platform.

## Key Components

- **RegistrationProcessor** - Main processor that orchestrates agent registration flow
- **process()** - Entry point that checks for existing machine ID and initiates registration loop if needed
- **attempt_registration()** - Internal method that makes a single registration attempt via the registration service

The processor integrates with `AgentRegistrationService` for API calls and `AgentConfigurationService` for local machine ID management.

## Usage Example

```rust
use crate::registration_processor::RegistrationProcessor;
use crate::services::{AgentRegistrationService, AgentConfigurationService};

// Initialize services
let registration_service = AgentRegistrationService::new(api_client);
let config_service = AgentConfigurationService::new();

// Create and run processor
let processor = RegistrationProcessor::new(registration_service, config_service);

// Process registration (will skip if machine_id exists)
processor.process().await?;
```

The processor implements automatic retry logic with 60-second intervals when registration fails, and skips registration entirely if a machine ID already exists locally. This ensures agents don't re-register unnecessarily while providing resilience against temporary network issues during initial setup.
