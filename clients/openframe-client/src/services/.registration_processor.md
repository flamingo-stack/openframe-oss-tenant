A service processor that handles agent registration with retry logic, ensuring agents are properly registered with the Flamingo platform before beginning operations.

## Key Components

- **`RegistrationProcessor`** - Main processor struct that orchestrates agent registration
- **`new()`** - Constructor accepting registration and configuration services
- **`process()`** - Primary entry point that handles registration flow with machine ID checking
- **`attempt_registration()`** - Internal method that performs single registration attempts

## Usage Example

```rust
use crate::services::{AgentRegistrationService, AgentConfigurationService};
use crate::processors::RegistrationProcessor;

// Initialize services
let registration_service = AgentRegistrationService::new(api_client);
let config_service = AgentConfigurationService::new(config_path);

// Create and run registration processor
let processor = RegistrationProcessor::new(registration_service, config_service);

// Process registration (will retry on failure)
processor.process().await?;
```

The processor implements a robust registration flow: it first checks for an existing machine ID to avoid duplicate registrations, then enters a retry loop with 60-second intervals if no ID is found. The registration continues until successful or manually interrupted, making it suitable for automated agent deployment scenarios.
