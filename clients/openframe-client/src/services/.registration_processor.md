Handles agent registration processing with retry logic, coordinating between registration and configuration services to ensure agents are properly registered with the system.

## Key Components

- **RegistrationProcessor** - Main struct that orchestrates the registration process
- **new()** - Constructor that takes registration and configuration services as dependencies
- **process()** - Public entry point that checks for existing registration and handles the registration loop
- **attempt_registration()** - Private method that performs a single registration attempt

## Usage Example

```rust
use crate::registration_processor::RegistrationProcessor;
use crate::services::{AgentRegistrationService, AgentConfigurationService};

#[tokio::main]
async fn main() -> Result<()> {
    let registration_service = AgentRegistrationService::new().await?;
    let config_service = AgentConfigurationService::new().await?;
    
    let processor = RegistrationProcessor::new(
        registration_service,
        config_service,
    );
    
    // Start the registration process
    processor.process().await?;
    
    Ok(())
}
```

The processor implements a retry loop with 60-second intervals when registration fails, and skips registration entirely if a machine ID already exists. It uses structured logging to track registration progress and failures, making it suitable for long-running agent processes that need reliable registration with the Flamingo platform.
