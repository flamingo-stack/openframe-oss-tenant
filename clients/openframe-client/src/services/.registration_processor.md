Orchestrates agent registration with retry logic, handling machine ID persistence and automated registration attempts until successful.

## Key Components

- **`RegistrationProcessor`** - Main processor struct that manages agent registration workflow
- **`new()`** - Constructor accepting registration and configuration services
- **`process()`** - Primary method that checks for existing machine ID and handles registration loop
- **`attempt_registration()`** - Internal method that wraps the registration service call with error context

## Usage Example

```rust
use crate::registration_processor::RegistrationProcessor;
use crate::services::{AgentRegistrationService, AgentConfigurationService};

// Initialize services
let registration_service = AgentRegistrationService::new(api_client);
let config_service = AgentConfigurationService::new(config_path);

// Create processor
let processor = RegistrationProcessor::new(registration_service, config_service);

// Start registration process
match processor.process().await {
    Ok(_) => println!("Agent registered successfully"),
    Err(e) => eprintln!("Registration failed: {}", e),
}
```

The processor implements a robust registration workflow that skips registration if a machine ID already exists, otherwise continuously retries failed registration attempts with a 60-second delay until successful. This ensures reliable agent onboarding even in unstable network conditions.
