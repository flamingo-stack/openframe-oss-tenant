Handles agent registration with automatic retry logic, checking for existing registration before attempting new registration with the Flamingo platform.

## Key Components

- **RegistrationProcessor** - Main processor that manages agent registration lifecycle
- **process()** - Public method that checks for existing registration and initiates registration loop if needed
- **attempt_registration()** - Internal method that makes a single registration attempt via the registration service

The processor integrates with `AgentRegistrationService` for API communication and `AgentConfigurationService` for local machine ID management.

## Usage Example

```rust
use crate::registration_processor::RegistrationProcessor;
use crate::services::{AgentRegistrationService, AgentConfigurationService};

// Initialize services
let registration_service = AgentRegistrationService::new(api_client);
let config_service = AgentConfigurationService::new();

// Create and run registration processor
let processor = RegistrationProcessor::new(registration_service, config_service);

// Start registration process (will retry on failure)
processor.process().await?;
```

The processor implements a simple retry mechanism with 60-second intervals on registration failures. It automatically skips registration if a machine ID already exists, making it safe to run multiple times. The retry loop continues until registration succeeds or the process is terminated.
