Handles agent registration with automatic retry logic, ensuring agents are properly registered with the Flamingo platform before beginning operations.

## Key Components

**RegistrationProcessor**
- Main processor struct that orchestrates agent registration flow
- Contains `AgentRegistrationService` for API communication and `AgentConfigurationService` for local state management
- Implements retry logic with fixed 60-second intervals between failed attempts

**Methods:**
- `new()` - Constructor accepting registration and configuration services
- `process()` - Main entry point that checks existing registration and starts registration loop if needed
- `attempt_registration()` - Internal method that performs single registration attempt with error context

## Usage Example

```rust
use crate::services::{AgentRegistrationService, AgentConfigurationService};
use crate::processors::RegistrationProcessor;

// Initialize services
let registration_service = AgentRegistrationService::new(api_client);
let config_service = AgentConfigurationService::new();

// Create processor and start registration
let processor = RegistrationProcessor::new(registration_service, config_service);

// This will skip registration if machine_id exists, 
// otherwise retry until successful
processor.process().await?;
```

The processor implements a simple but robust registration strategy: check for existing registration first, then retry indefinitely on failure with logging. The TODO comment indicates plans for exponential backoff to improve retry behavior.
