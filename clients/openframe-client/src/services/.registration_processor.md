Handles the automated agent registration process with retry logic and machine ID validation for the Flamingo AI-powered MSP platform.

## Key Components

### RegistrationProcessor
- **`new(registration_service, config_service)`** - Creates a new processor with required service dependencies
- **`process()`** - Main entry point that checks for existing machine ID and handles the registration loop
- **`attempt_registration()`** - Private method that performs a single registration attempt

### Dependencies
- **AgentRegistrationService** - Service for communicating with the registration API
- **AgentConfigurationService** - Service for managing local agent configuration and machine ID storage
- **AgentRegistrationResponse** - Response model from successful registration

## Usage Example

```rust
use crate::registration_processor::RegistrationProcessor;
use crate::services::{AgentRegistrationService, AgentConfigurationService};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let registration_service = AgentRegistrationService::new(api_client);
    let config_service = AgentConfigurationService::new(config_path);
    
    let processor = RegistrationProcessor::new(
        registration_service,
        config_service,
    );
    
    // Start the registration process
    processor.process().await?;
    
    Ok(())
}
```

The processor implements a simple retry mechanism with 60-second intervals on failure, skipping registration if a machine ID already exists. Future improvements include exponential backoff for more sophisticated retry handling.
