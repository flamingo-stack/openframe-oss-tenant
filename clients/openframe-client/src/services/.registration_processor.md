Handles agent registration lifecycle with retry logic and configuration integration for automated agent enrollment.

## Key Components

### `RegistrationProcessor`
- **`new()`** - Creates a new processor with registration and configuration services
- **`process()`** - Main entry point that checks for existing machine ID and handles registration loop
- **`attempt_registration()`** - Private method that performs a single registration attempt

The processor integrates with `AgentRegistrationService` for actual registration calls and `AgentConfigurationService` for machine ID persistence.

## Usage Example

```rust
use crate::services::{AgentRegistrationService, AgentConfigurationService};
use crate::registration::RegistrationProcessor;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let registration_service = AgentRegistrationService::new(api_client);
    let config_service = AgentConfigurationService::new(config_path);
    
    let processor = RegistrationProcessor::new(
        registration_service,
        config_service,
    );
    
    // Start registration process - will skip if already registered
    processor.process().await?;
    
    Ok(())
}
```

The processor implements intelligent registration behavior: it skips registration if a machine ID already exists, otherwise enters a retry loop with 60-second intervals until successful. Failed attempts are logged with full error context while successful registration terminates the loop.
