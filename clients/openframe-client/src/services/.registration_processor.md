Handles agent registration with the Flamingo platform, managing the registration lifecycle with retry logic and machine ID persistence.

## Key Components

- **`RegistrationProcessor`** - Main processor struct that orchestrates agent registration
- **`new()`** - Constructor accepting registration and configuration services
- **`process()`** - Primary entry point that checks for existing registration or initiates registration loop
- **`attempt_registration()`** - Internal method that performs a single registration attempt

## Usage Example

```rust
use crate::services::{AgentRegistrationService, AgentConfigurationService};

// Initialize the registration processor
let registration_service = AgentRegistrationService::new();
let config_service = AgentConfigurationService::new();

let processor = RegistrationProcessor::new(
    registration_service,
    config_service,
);

// Process registration (will skip if machine_id exists)
processor.process().await?;
```

The processor implements smart registration logic - it first checks for an existing `machine_id` to avoid duplicate registrations. If no ID exists, it enters a retry loop with 60-second intervals until registration succeeds. The design uses dependency injection for testability and includes comprehensive error handling with structured logging.
