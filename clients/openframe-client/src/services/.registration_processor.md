Handles agent registration processing with automatic retry logic for unregistered agents in the Flamingo MSP platform.

## Key Components

- **`RegistrationProcessor`** - Main processor that manages agent registration workflow
- **`new()`** - Constructor accepting registration and configuration services
- **`process()`** - Primary method that checks existing registration and handles new registrations
- **`attempt_registration()`** - Internal method that performs a single registration attempt

## Usage Example

```rust
use crate::services::{AgentRegistrationService, AgentConfigurationService};
use crate::processors::RegistrationProcessor;

// Initialize services
let registration_service = AgentRegistrationService::new();
let config_service = AgentConfigurationService::new();

// Create processor
let processor = RegistrationProcessor::new(registration_service, config_service);

// Process registration
match processor.process().await {
    Ok(_) => println!("Agent registration completed successfully"),
    Err(e) => eprintln!("Registration failed: {}", e),
}
```

The processor first checks for an existing `machine_id` to avoid duplicate registrations. If no ID exists, it enters a retry loop with 60-second intervals until registration succeeds. This ensures robust agent onboarding even with temporary network issues or service unavailability.
