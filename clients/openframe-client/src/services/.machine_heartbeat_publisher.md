Publishes periodic heartbeat messages for a machine over NATS, with rate-limited logging to avoid log noise.

## Key Components

- **`MachineHeartbeatPublisher`** — Cloneable struct that wraps a NATS publisher and agent configuration service, tracking heartbeat count via a shared atomic counter.
- **`publish_heartbeat()`** — Async method that resolves the machine ID, builds a `MachineHeartbeatMessage`, serializes it to JSON, and publishes to the `machine.<id>.heartbeat` NATS topic.
- **`log_heartbeat()`** — Internal method that throttles log output: emits a `debug` log on every heartbeat, but only promotes to an `info` log every `60` heartbeats (resetting the counter each time).
- **`HEARTBEAT_LOG_INTERVAL`** — Constant (`60`) controlling how frequently a summary `info` log is emitted.

## Usage Example

```rust
let publisher = MachineHeartbeatPublisher::new(
    nats_publisher,
    config_service,
);

// Call on a recurring interval (e.g. via tokio::time::interval)
publisher.publish_heartbeat().await?;
```

> **Note:** The atomic counter (`Arc<AtomicU64>`) uses `Relaxed` ordering, making it safe and cheap across cloned instances sharing the same `Arc`. A summary `info` log fires every 60 heartbeats; individual sends log at `debug` level only.
