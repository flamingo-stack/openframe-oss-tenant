Publishes periodic machine heartbeat messages over NATS, with rate-limited logging to reduce noise in long-running agent processes.

## Key Components

- **`MachineHeartbeatPublisher`** — Main struct holding a NATS publisher, configuration service, and an atomic counter for tracking heartbeat frequency.
- **`publish_heartbeat()`** — Resolves the machine ID, constructs a `MachineHeartbeatMessage`, serializes it to JSON, and publishes it to the `machine.<machine_id>.heartbeat` NATS topic.
- **`log_heartbeat()`** — Internal method that throttles log output: emits a `debug` log on every heartbeat, but only promotes to `info` every `60` sends (resetting the counter each time).
- **`HEARTBEAT_LOG_INTERVAL`** — Constant (`60`) controlling how often a full `info`-level health summary is logged.

## Usage Example

```rust
let publisher = MachineHeartbeatPublisher::new(
    nats_publisher,
    config_service,
);

// Called on a recurring interval (e.g., inside a tokio::time::interval loop)
publisher.publish_heartbeat().await?;
```

The publisher is `Clone`-safe — the internal heartbeat counter is wrapped in `Arc<AtomicU64>`, so cloned instances share the same count across tasks without locking overhead.
