Publishes periodic machine heartbeat messages to NATS, tracking counts to throttle log verbosity.

## Key Components

- **`MachineHeartbeatPublisher`** — Main struct holding a NATS publisher, agent config service, and an atomic heartbeat counter shared across clones.
- **`publish_heartbeat()`** — Async method that resolves the machine ID, builds a `MachineHeartbeatMessage`, serializes it to JSON, and publishes to the topic `machine.<machine_id>.heartbeat`.
- **`log_heartbeat()`** — Internal method that increments the atomic counter and emits a `debug` log on every heartbeat, upgrading to `info` every `HEARTBEAT_LOG_INTERVAL` (60) heartbeats then resetting the counter.
- **`HEARTBEAT_LOG_INTERVAL`** — Constant controlling how frequently a full `info`-level log is emitted (every 60 heartbeats).

## Usage Example

```rust
let publisher = MachineHeartbeatPublisher::new(
    nats_publisher,
    config_service,
);

// Called on a timer loop (e.g., every 30 seconds)
loop {
    if let Err(e) = publisher.publish_heartbeat().await {
        error!("Heartbeat failed: {}", e);
    }
    tokio::time::sleep(Duration::from_secs(30)).await;
}
```

> The struct derives `Clone` and wraps the counter in `Arc<AtomicU64>`, so it can be safely shared across async tasks without locks on the counter itself.
