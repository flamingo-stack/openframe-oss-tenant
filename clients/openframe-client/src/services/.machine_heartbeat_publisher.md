Publishes periodic machine heartbeat messages to NATS, confirming agent liveness for a given machine ID.

## Key Components

- **`MachineHeartbeatPublisher`** — Cloneable struct wrapping a NATS publisher, agent config service, and an atomic heartbeat counter.
- **`publish_heartbeat()`** — Resolves the machine ID, serializes a `MachineHeartbeatMessage` to JSON, and publishes it to the NATS topic `machine.<machine_id>.heartbeat`.
- **`log_heartbeat()`** — Tracks cumulative heartbeat count using a lock-free `AtomicU64`. Emits an `info!` log every 60 heartbeats and a `debug!` log otherwise, then resets the counter.
- **`HEARTBEAT_LOG_INTERVAL`** — Constant (`60`) controlling how frequently a full `info`-level health log is emitted.

## Usage Example

```rust
use crate::services::machine_heartbeat_publisher::MachineHeartbeatPublisher;

let publisher = MachineHeartbeatPublisher::new(nats_publisher, config_service);

// Call on a recurring interval (e.g., inside a tokio::time::interval loop)
if let Err(e) = publisher.publish_heartbeat().await {
    error!("Heartbeat failed: {}", e);
}
```

> **NATS topic format:** `machine.<machine_id>.heartbeat`
>
> Heartbeats are logged at `DEBUG` level each tick and promoted to `INFO` every 60 ticks to keep log volume low during normal operation.

## Notes

- The struct is `Clone`-safe; the heartbeat counter is shared across clones via `Arc<AtomicU64>`.
- Machine ID is resolved at publish time via `AgentConfigurationService`, so config changes are reflected without restarting the publisher.
