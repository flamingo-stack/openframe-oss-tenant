Manages a background task that periodically flushes pending outbox entries from a durable result store by publishing them to a message broker, implementing a reliable outbox pattern for result delivery.

## Key Components

### `ResultOutboxRunManager<P: ResultPublisher>`
The primary struct holding shared references to:
- `store` — `Arc<ResultStore>`: durable store of pending result payloads
- `publisher` — `Arc<P>`: message publisher implementing `ResultPublisher`
- `notify` — `Arc<Notify>`: allows external callers to trigger an immediate flush

### `new(store, publisher, notify) -> Self`
Constructor that takes shared ownership of each dependency.

### `start(&self)`
Spawns a Tokio background task that:
1. **No-ops** if the store is not durable (`store.enabled()` returns false)
2. **Wakes** on either a periodic interval (`OUTBOX_FLUSH_INTERVAL_SECS`) or an explicit `Notify` signal
3. **Iterates** over pending `(key, subject)` pairs from the store
4. **Skips** entries exceeding `OUTBOX_MAX_PAYLOAD_BYTES` to prevent blocking healthy results
5. **Publishes** each payload with a `FLUSH_PUBLISH_TIMEOUT_SECS` deadline, removing the entry on success
6. **Breaks** the inner loop and retries on the next tick if any publish or load error occurs

## Usage Example

```rust
let manager = ResultOutboxRunManager::new(
    Arc::clone(&result_store),
    Arc::clone(&nats_publisher),
    Arc::clone(&notify),
);

// Starts the background flush loop; call notify.notify_one()
// elsewhere to trigger an immediate flush without waiting for
// the next interval tick.
manager.start();
```

## Configuration

All tuning constants are sourced from `update_config`:

| Constant | Purpose |
|---|---|
| `OUTBOX_FLUSH_INTERVAL_SECS` | Polling interval between flush attempts |
| `FLUSH_PUBLISH_TIMEOUT_SECS` | Per-message publish deadline |
| `OUTBOX_MAX_PAYLOAD_BYTES` | Maximum allowed payload size per entry |
