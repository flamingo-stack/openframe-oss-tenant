Handles the initial authentication flow for the Flamingo agent, checking for an existing access token and retrying authentication in a loop if none is found.

## Key Components

- **`InitialAuthenticationProcessor`** — Main struct holding references to `AgentAuthService` and `AgentConfigurationService`.
- **`new()`** — Constructor accepting both service dependencies.
- **`process()`** — Async entry point; skips authentication if a token already exists, otherwise enters a retry loop with a 60-second delay between attempts.
- **`attempt_authentication()`** — Private async method that delegates to `AgentAuthService::authenticate_initial()`.

## Usage Example

```rust
let processor = InitialAuthenticationProcessor::new(
    auth_service,
    config_service,
);

processor.process().await?;
```

## Notes

- If an `access_token` is already stored via `AgentConfigurationService`, the processor exits early without making any authentication requests.
- On failure, the retry loop waits **60 seconds** before reattempting. Exponential backoff is marked as a `TODO`.
- Errors from the auth service are wrapped with context via `anyhow` for improved diagnostics.
