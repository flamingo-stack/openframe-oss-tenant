Handles the initial authentication flow for an agent by checking for an existing access token and, if absent, entering a retry loop until authentication succeeds.

## Key Components

### `InitialAuthenticationProcessor`
A cloneable struct orchestrating startup authentication using two injected services:

| Field | Type | Role |
|---|---|---|
| `auth_service` | `AgentAuthService` | Executes the actual authentication request |
| `config_service` | `AgentConfigurationService` | Reads the stored access token |

### Methods

- **`new(auth_service, config_service)`** — Constructor; initializes the processor with required service dependencies.
- **`process()`** — Entry point. Skips authentication if a token already exists; otherwise, loops indefinitely retrying every 60 seconds until success.
- **`attempt_authentication()`** *(private)* — Delegates to `auth_service.authenticate_initial()`, wrapping errors with context.

## Usage Example

```rust
let processor = InitialAuthenticationProcessor::new(
    auth_service,
    config_service,
);

// Called once at agent startup; blocks until authenticated
processor.process().await?;
```

## Notes

- If an `access_token` is already stored in config, the processor exits immediately — no network call is made.
- Failed attempts log a `warn`-level message and wait a fixed **60-second** delay before retrying.
