Handles the initial authentication flow for the agent, checking for an existing access token and retrying authentication in a loop until successful.

## Key Components

- **`InitialAuthenticationProcessor`** — Main struct holding references to `AgentAuthService` and `AgentConfigurationService`
- **`new()`** — Constructor accepting both service dependencies
- **`process()`** — Async entry point; skips auth if a token already exists, otherwise enters a retry loop
- **`attempt_authentication()`** — Private method that delegates to `AgentAuthService::authenticate_initial()`

## Usage Example

```rust
let processor = InitialAuthenticationProcessor::new(
    auth_service,
    config_service,
);

processor.process().await?;
```

## Behavior Notes

- If a non-empty access token is already stored via `AgentConfigurationService`, authentication is skipped entirely
- On failure, retries every **60 seconds** indefinitely until authentication succeeds
