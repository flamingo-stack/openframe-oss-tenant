Handles the initial authentication flow for the agent, checking for an existing access token and retrying authentication in a loop until it succeeds.

## Key Components

### `InitialAuthenticationProcessor`

A cloneable processor struct that orchestrates startup authentication.

| Member | Type | Description |
|---|---|---|
| `auth_service` | `AgentAuthService` | Performs the actual authentication handshake |
| `config_service` | `AgentConfigurationService` | Reads persisted token state |

### Methods

- **`new(auth_service, config_service)`** — Constructor; wires the two service dependencies.
- **`process()`** — Public async entry point. Skips auth if a token already exists; otherwise enters a retry loop with a 60-second fixed delay between attempts.
- **`attempt_authentication()`** — Private; delegates to `auth_service.authenticate_initial()` with error context wrapping.

## Usage Example

```rust
let processor = InitialAuthenticationProcessor::new(
    auth_service,
    config_service,
);

processor.process().await?;
```

## Notes

- If `get_access_token()` returns a non-empty string, the processor exits immediately — safe for restarts without re-authenticating.
- The retry loop runs indefinitely until authentication succeeds; a `TODO` in the source flags a planned upgrade to exponential backoff.
- Errors from `authenticate_initial()` are surfaced with [`anyhow::Context`](https://docs.rs/anyhow) for enriched diagnostics.
