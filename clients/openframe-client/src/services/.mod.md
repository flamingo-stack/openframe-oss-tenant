Services module root for the OpenFrame OSS tenant agent, declaring and re-exporting all service components that handle authentication, configuration, tool lifecycle, NATS messaging, device management, and update orchestration.

## Key Components

### Authentication & Configuration
| Export | Description |
|--------|-------------|
| `AgentAuthService` | Handles agent authentication flows |
| `AgentConfigurationService` | Manages agent runtime configuration |
| `InitialConfigurationService` | Bootstraps first-run configuration |
| `AgentRegistrationService` | Registers the agent with the platform |
| `LocalTlsConfigProvider` | Provides local TLS certificate configuration |
| `EncryptionService` | Handles cryptographic operations |
| `SharedTokenService` | Manages shared authentication tokens |
| `InitialKeyService` | Handles initial key provisioning |

### Tool Lifecycle Management
| Export | Description |
|--------|-------------|
| `ToolInstallationService` | Installs managed tools |
| `ToolUninstallService` / `UninstallOutcome` | Uninstalls tools with outcome reporting |
| `ToolRestartService` / `RestartOutcome` | Restarts tools with outcome reporting |
| `ToolKillService` | Forcibly terminates tool processes |
| `ToolRunManager` | Manages tool execution lifecycle |
| `ToolConnectionService` | Manages tool connections |
| `ToolConnectionProcessingManager` | Processes incoming tool connection events |
| `InstalledToolsService` | Queries and tracks installed tools |

### NATS Messaging
| Export | Description |
|--------|-------------|
| `NatsConnectionManager` | Manages NATS broker connections |
| `NatsMessagePublisher` | Publishes messages to NATS subjects |
| `ToolConnectionMessagePublisher` | Publishes tool connection state messages |
| `InstalledAgentMessagePublisher` | Publishes installed agent status messages |

### Update & Heartbeat
| Export | Description |
|--------|-------------|
| `OpenFrameClientUpdateService` | Updates the OpenFrame client binary |
| `ToolAgentUpdateService` | Updates tool agent binaries |
| `GithubDownloadService` | Downloads releases from GitHub |
| `UpdateStateService` | Tracks update state transitions |
| `LastKnownGoodService` | Manages rollback to last known good state |
| `UpdateCleanupService` | Cleans up after update operations |
| `UpdateHandlerService` | Orchestrates the full update flow |
| `MachineHeartbeatPublisher` | Publishes device heartbeat signals |
| `MachineHeartbeatRunManager` | Runs the heartbeat loop |
| `TokenRefreshRunManager` | Manages periodic token refresh |
| `DeactivationService` | Handles agent deactivation |

## Usage Example

```rust
use crate::services::{
    AgentAuthService,
    NatsConnectionManager,
    NatsMessagePublisher,
    ToolInstallationService,
    ToolUninstallService,
    UninstallOutcome,
    MachineHeartbeatRunManager,
};

// Services are imported directly from the `services` module
// without needing to reference individual submodule paths.
let auth = AgentAuthService::new(/* ... */);
let nats = NatsConnectionManager::new(/* ... */);

match tool_uninstall.run().await {
    UninstallOutcome::Success => println!("Tool removed"),
    UninstallOutcome::NotFound => println!("Tool was not installed"),
}
```
