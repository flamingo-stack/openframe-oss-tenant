The services module root for the OpenFrame agent, aggregating and re-exporting all service implementations as a flat public API.

## Key Components

| Category | Exports |
|----------|---------|
| **Auth & Config** | `AgentAuthService`, `AgentConfigurationService`, `InitialConfigurationService`, `EncryptionService`, `SharedTokenService`, `InitialKeyService` |
| **Registration** | `AgentRegistrationService`, `LocalTlsConfigProvider` |
| **Tool Lifecycle** | `ToolInstallationService`, `ToolUninstallService`, `ToolKillService`, `ToolRunManager`, `InstalledToolsService` |
| **Tool Connectivity** | `ToolConnectionService`, `ToolConnectionProcessingManager`, `ToolConnectionMessagePublisher`, `ToolCommandParamsResolver`, `ToolUrlParamsResolver` |
| **NATS Messaging** | `NatsConnectionManager`, `NatsMessagePublisher`, `InstalledAgentMessagePublisher` |
| **Heartbeat** | `MachineHeartbeatPublisher`, `MachineHeartbeatRunManager` |
| **Updates** | `OpenFrameClientUpdateService`, `ToolAgentUpdateService`, `UpdateStateService`, `UpdateCleanupService`, `UpdateHandlerService`, `GithubDownloadService`, `OpenFrameClientInfoService` |
| **Device & Auth Flow** | `DeviceDataFetcher` (module only), `InitialAuthenticationProcessor`, `RegistrationProcessor` |

## Usage Example

```rust
use crate::services::{
    AgentAuthService,
    NatsConnectionManager,
    ToolInstallationService,
    MachineHeartbeatPublisher,
    UpdateHandlerService,
};

// Consume services directly from the flat re-export surface
// without referencing individual submodule paths
let auth = AgentAuthService::new(/* ... */);
let nats = NatsConnectionManager::new(/* ... */);
let heartbeat = MachineHeartbeatPublisher::new(/* ... */);
```

> All submodules are declared `pub mod`, preserving direct path access (e.g. `crate::services::nats_connection_manager::NatsConnectionManager`) while the `pub use` re-exports provide ergonomic top-level imports.
