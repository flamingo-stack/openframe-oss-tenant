Manages reading, writing, and mutating the tenant's initial configuration stored as a JSON file in a secured directory on disk.

## Key Components

### `InitialConfigurationService`
A cloneable service struct that wraps a file path to `initial_config.json` and provides typed accessors and mutators over the [`InitialConfiguration`](https://github.com/flamingo-stack/openframe-oss-tenant/blob/main/src/models.rs) model.

| Method | Description |
|---|---|
| `new(directory_manager)` | Constructs the service and ensures the secured directory exists |
| `get_initial_key()` | Returns the stored initial authentication key |
| `get_server_url()` | Returns the configured server host URL |
| `is_local_mode()` | Returns whether the agent is running in local mode |
| `get_org_id()` | Returns the tenant's organization ID |
| `get_local_ca_cert_path()` | Returns the path to a local CA certificate |
| `get_tags()` | Returns the list of `DeviceTag` entries |
| `clear_initial_key()` | Zeroes out the initial key and persists the change |
| `is_initial_key_missing()` | Returns `true` if the initial key is an empty string |
| `update_initial_key(key)` | Replaces the initial key and persists the change |
| `save(config)` | Serializes and writes the full config struct to disk |

The private `get()` method handles deserialization and returns an error if the file does not yet exist.

## Usage Example

```rust
use crate::platform::directories::DirectoryManager;
use crate::services::InitialConfigurationService;

let dir_manager = DirectoryManager::new("/etc/openframe")?;
let svc = InitialConfigurationService::new(dir_manager)?;

// Read values
let key = svc.get_initial_key()?;
let server = svc.get_server_url()?;
let tags = svc.get_tags()?;

// Rotate the initial key after first registration
svc.clear_initial_key()?;

// Or update it with a new value
svc.update_initial_key("new-key-abc123".to_string())?;
```
