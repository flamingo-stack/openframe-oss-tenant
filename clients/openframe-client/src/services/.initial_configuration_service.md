Manages reading and writing the device's initial configuration from a secured JSON file (`initial_config.json`), providing typed accessors for each configuration field.

## Key Components

**`InitialConfigurationService`** — Primary service struct with a single field:
- `config_file_path: PathBuf` — resolved path to `initial_config.json` inside the secured directory

**Constructor**
- `new(directory_manager: DirectoryManager)` — Resolves the config file path and ensures the secured directory exists before returning the service instance

**Read Methods**
- `get_initial_key()` — Returns the provisioning/registration key
- `get_server_url()` — Returns the configured server host URL
- `is_local_mode()` — Returns whether the device operates in local mode
- `get_org_id()` — Returns the organization identifier
- `get_local_ca_cert_path()` — Returns the path to a custom CA certificate
- `get_tags()` — Returns the list of `DeviceTag` entries associated with the device

**Write Methods**
- `save(config)` — Serializes and writes the full `InitialConfiguration` to disk (pretty-printed JSON)
- `update_initial_key(key)` — Loads, mutates, and saves the initial key
- `clear_initial_key()` — Resets the initial key to an empty string
- `is_initial_key_missing()` — Checks whether the initial key has been cleared or was never set

**Private**
- `get()` — Core loader; reads and deserializes the JSON file, returning an error if the file is absent

## Usage Example

```rust
use crate::platform::directories::DirectoryManager;
use crate::services::InitialConfigurationService;

let dir_manager = DirectoryManager::new("/etc/flamingo");
let svc = InitialConfigurationService::new(dir_manager)?;

// Read provisioning key
let key = svc.get_initial_key()?;

// Mark key as consumed after registration
svc.clear_initial_key()?;

// Check registration state
if svc.is_initial_key_missing()? {
    println!("Device already provisioned");
}

// Access server config
let server = svc.get_server_url()?;
let org    = svc.get_org_id()?;
```
