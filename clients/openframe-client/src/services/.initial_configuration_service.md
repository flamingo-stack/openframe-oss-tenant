Manages reading, writing, and updating the agent's initial configuration stored as a JSON file in a secured directory.

## Key Components

- **`InitialConfigurationService`** — Cloneable service struct that holds the path to `initial_config.json` inside the secured directory.
- **`new(directory_manager)`** — Constructor that resolves the config file path and ensures the secured directory exists.
- **`get()`** *(private)* — Core reader that deserializes `initial_config.json` into an `InitialConfiguration` model.
- **`save(config)`** — Serializes and writes an `InitialConfiguration` back to disk as pretty-printed JSON.
- **Accessor methods** — `get_initial_key`, `get_server_url`, `is_local_mode`, `get_org_id`, `get_local_ca_cert_path`, `get_tags` each call `get()` and return individual fields.
- **Key management** — `update_initial_key`, `clear_initial_key`, and `is_initial_key_missing` provide controlled mutation of the enrollment key.

## Usage Example

```rust
use crate::platform::directories::DirectoryManager;
use crate::services::InitialConfigurationService;

fn main() -> anyhow::Result<()> {
    let dir_manager = DirectoryManager::new("/etc/flamingo-agent")?;
    let config_svc = InitialConfigurationService::new(dir_manager)?;

    // Read individual fields
    let server_url = config_svc.get_server_url()?;
    let org_id = config_svc.get_org_id()?;
    println!("Connecting to {} for org {}", server_url, org_id);

    // Consume and clear the initial enrollment key after registration
    let initial_key = config_svc.get_initial_key()?;
    register_device(&initial_key)?;
    config_svc.clear_initial_key()?;

    // Check local mode and custom CA
    if config_svc.is_local_mode()? {
        let ca_path = config_svc.get_local_ca_cert_path()?;
        println!("Using local CA cert at: {}", ca_path);
    }

    Ok(())
}
```

> **Note:** The service reads from disk on every call to `get()`. There is no in-memory cache, so updates made externally to `initial_config.json` are always reflected immediately.
