Manages reading, writing, and updating the `initial_config.json` file stored in the secured directory, providing typed accessors for all configuration fields.

## Key Components

**`InitialConfigurationService`** — Core service struct exposing the following public methods:

| Method | Description |
|--------|-------------|
| `new(directory_manager)` | Constructs the service, resolving the config file path and ensuring the secured directory exists |
| `get_initial_key()` | Returns the device registration/initial key |
| `get_server_url()` | Returns the configured server host URL |
| `is_local_mode()` | Returns whether the agent is running in local mode |
| `get_org_id()` | Returns the organization ID |
| `get_local_ca_cert_path()` | Returns the path to a local CA certificate |
| `get_tags()` | Returns the list of `DeviceTag` entries |
| `clear_initial_key()` | Clears the initial key by setting it to an empty string and persisting |
| `is_initial_key_missing()` | Returns `true` if the initial key is empty |
| `update_initial_key(key)` | Updates and persists the initial key |
| `save(config)` | Serializes and writes the full `InitialConfiguration` to disk |

The private `get()` method handles all deserialization, returning an error if the file does not exist.

## Usage Example

```rust
let dir_manager = DirectoryManager::new()?;
let config_service = InitialConfigurationService::new(dir_manager)?;

// Read configuration values
let server_url = config_service.get_server_url()?;
let org_id = config_service.get_org_id()?;
let tags = config_service.get_tags()?;

// Rotate the initial key after first use
if !config_service.is_initial_key_missing()? {
    let key = config_service.get_initial_key()?;
    // use key for registration...
    config_service.clear_initial_key()?;
}

// Update with a new key
config_service.update_initial_key("new-registration-key".to_string())?;
```
