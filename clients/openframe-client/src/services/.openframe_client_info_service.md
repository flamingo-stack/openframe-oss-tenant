Manages persistence of OpenFrame client metadata (version, update status, binary path) by reading and writing a JSON file in the secured application directory.

## Key Components

| Item | Description |
|------|-------------|
| `OpenFrameClientInfoService` | Cloneable service struct holding the path to `openframe_client_info.json` |
| `new()` | Constructs the service, resolves the secured directory via `DirectoryManager`, and ensures it exists |
| `get()` | Reads and deserializes client info from disk; returns `Default` if the file does not exist |
| `save()` | Serializes and writes client info to disk as pretty-printed JSON |
| `update_version()` | Sets `current_version` and stamps `last_updated` with the current UTC timestamp |
| `reconcile_version()` | Syncs the stored version to the running binary version if they diverge |
| `set_update_status()` | Updates `status`, `target_version`, and `last_update_check` fields |
| `set_binary_path()` | Persists the resolved path of the running binary |

## Usage Example

```rust
use anyhow::Result;
use crate::platform::directories::DirectoryManager;
use crate::services::openframe_client_info_service::OpenFrameClientInfoService;
use crate::models::openframe_client_info::ClientUpdateStatus;

#[tokio::main]
async fn main() -> Result<()> {
    let dir_manager = DirectoryManager::new()?;
    let service = OpenFrameClientInfoService::new(dir_manager)?;

    // Reconcile stored version with the running binary on startup
    service.reconcile_version("1.4.2").await?;

    // Mark an update as available
    service.set_update_status(
        ClientUpdateStatus::UpdateAvailable,
        Some("1.5.0".to_string()),
    ).await?;

    // Persist the resolved binary path
    service.set_binary_path("/usr/local/bin/openframe".to_string()).await?;

    // Read current state
    let info = service.get().await?;
    println!("Running: {} -> Target: {:?}", info.current_version, info.target_version);

    Ok(())
}
```

## Notes

- All async methods delegate synchronous file I/O via `std::fs`; consider `tokio::fs` if blocking is a concern in high-throughput contexts.
- The file is stored under the platform-specific **secured directory** provided by [`DirectoryManager`](https://github.com/flamingo-stack/openframe-oss-tenant/blob/main/src/platform/directories.rs).
- Missing file on `get()` is treated as a non-error, returning `OpenFrameClientInfo::default()`.
