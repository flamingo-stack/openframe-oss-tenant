Manages NATS server connections for the Flamingo agent, handling initial connection setup, TLS configuration, authentication, and automatic reauthentication via token refresh callbacks.

## Key Components

### `NatsConnectionManager` (struct)

A cloneable connection manager wrapping an `Arc<RwLock<Option<Arc<Client>>>>` for safe concurrent access to the underlying NATS client.

| Field | Description |
|-------|-------------|
| `client` | Thread-safe, lazily initialized NATS client |
| `nats_server_url` | Base WebSocket URL for the NATS server |
| `config_service` | Reads machine ID and access tokens |
| `tls_config_provider` | Supplies TLS config in local/dev mode |
| `initial_configuration_service` | Detects local vs. production mode |
| `auth_service` | Handles token reauthentication |

### Key Methods

| Method | Description |
|--------|-------------|
| `new(...)` | Constructs the manager with all required service dependencies |
| `connect()` | Establishes the NATS connection with auth, ping, and reconnect callbacks |
| `get_client()` | Returns the active `Arc<Client>`, errors if `connect()` was not called |
| `perform_reauthentication_and_build_url(...)` | Private; invoked by the `auth_url_callback` to refresh tokens and rebuild the connection URL |
| `build_nats_connection_url()` | Private; appends the current access token as a query parameter |

## Usage Example

```rust
let manager = NatsConnectionManager::new(
    "wss://nats.example.com".to_string(),
    config_service,
    initial_configuration_service,
    auth_service,
    tls_config_provider,
);

// Establish connection (retries on failure, configures TLS in local mode)
manager.connect().await?;

// Retrieve the active client for publishing/subscribing
let client: Arc<Client> = manager.get_client().await?;
client.publish("agent.events", "payload".into()).await?;
```

> **Note:** The connection URL uses the WebSocket path `/ws/nats?authorization=<token>`. Token refresh is handled automatically via `auth_url_callback` — no manual intervention is needed on token expiry.
