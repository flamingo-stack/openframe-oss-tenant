Manages NATS messaging client connections with authentication, TLS support, and automatic reconnection for OpenFrame's agent communication system.

## Key Components

- **NatsConnectionManager**: Main struct that handles NATS client lifecycle and connection management
- **connect()**: Establishes NATS connection with authentication, retry logic, and optional TLS
- **get_client()**: Returns the active NATS client for message publishing/subscribing
- **build_nats_connection_url()**: Constructs WebSocket URL with authentication token
- **perform_reauthentication_and_build_url()**: Handles automatic token refresh during reconnection

## Usage Example

```rust
use crate::nats_connection_manager::NatsConnectionManager;

// Initialize the connection manager
let nats_manager = NatsConnectionManager::new(
    "wss://nats.flamingo.run".to_string(),
    config_service,
    initial_config_service,
    auth_service,
    tls_provider,
);

// Establish connection
nats_manager.connect().await?;

// Get client for messaging operations
let client = nats_manager.get_client().await?;
client.publish("agent.status", "online".into()).await?;
```

The manager automatically handles:
- Token-based authentication with machine credentials
- TLS configuration in local development mode
- Connection retries with exponential backoff
- Automatic reauthentication when tokens expire
- WebSocket transport for firewall compatibility
