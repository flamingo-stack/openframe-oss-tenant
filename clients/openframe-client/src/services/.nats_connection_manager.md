Manages the lifecycle of a NATS WebSocket connection for the Flamingo agent, including initial connection setup, TLS configuration, and automatic token-based reauthentication on reconnect.

## Key Components

### `NatsConnectionManager` (struct)
Cloneable connection manager wrapping the NATS client behind an `Arc<RwLock<Option<Arc<Client>>>>` to allow shared, async-safe access across tasks.

| Field | Description |
|---|---|
| `client` | Shared, lock-protected optional NATS client instance |
| `nats_server_url` | Base WebSocket URL for the NATS server |
| `config_service` | Reads machine ID and access tokens from agent config |
| `tls_config_provider` | Supplies TLS config for local/dev mode connections |
| `initial_configuration_service` | Determines if the agent is running in local mode |
| `auth_service` | Handles token reauthentication on auth expiry |

### Methods

- **`new()`** — Constructs the manager with all dependencies; client starts as `None`.
- **`connect()`** — Builds the authenticated WebSocket URL, configures reconnect/ping/auth callbacks, conditionally applies TLS (local mode only), and stores the connected client.
- **`get_client()`** — Returns the active `Arc<Client>`, or an error if `connect()` has not been called.
- **`perform_reauthentication_and_build_url()`** *(private)* — Called by the `auth_url_callback`; re-fetches a fresh JWT/token and rebuilds the connection URL.
- **`build_nats_connection_url()`** *(private)* — Constructs the initial `wss://.../ws/nats?authorization=<token>` URL.

## Usage Example

```rust
let manager = NatsConnectionManager::new(
    "wss://nats.example.com".to_string(),
    config_service,
    initial_config_service,
    auth_service,
    tls_config_provider,
);

// Establish connection (retries on failure)
manager.connect().await?;

// Retrieve client for publishing/subscribing
let client: Arc<Client> = manager.get_client().await?;
client.publish("agent.heartbeat", "ping".into()).await?;
```

> **Note:** TLS client config is only applied when `InitialConfigurationService::is_local_mode()` returns `true`. In production, TLS is expected to be handled at the transport/infrastructure level.
