Manages the lifecycle of a NATS WebSocket connection for the OpenFrame agent, including initial connection, token-based authentication, automatic reconnection with backoff, and tenant suspension handling.

## Key Components

### `NatsConnectionManager` (struct)
The primary connection manager, cloneable and thread-safe via `Arc<RwLock<_>>` internals.

| Field | Purpose |
|---|---|
| `client` | Thread-safe holder for the active `async_nats::Client` |
| `reconnect_tx` | Broadcast channel that notifies subscribers on reconnection |
| `nats_server_url` | Base WebSocket URL for the NATS gateway |
| `auth_service` / `config_service` | Token retrieval and agent configuration |
| `tls_config_provider` | Local dev TLS config (only applied in local mode) |
| `deactivation` | Detects tenant suspension to suppress reconnect storms |

### Key Methods

| Method | Description |
|---|---|
| `connect()` | Establishes the NATS connection with auth URL callback, ping interval, reconnect delay callback, and optional dev TLS |
| `get_client()` | Returns a clone of the active `Arc<Client>`, erroring if not yet connected |
| `subscribe_reconnect()` | Returns a `broadcast::Receiver<()>` that fires on each successful reconnection after the first |
| `perform_reauthentication_and_build_url()` | Refreshes the JWT/token and rebuilds the WebSocket URL; skips if tenant is suspended; 10s timeout enforced |

### `SUSPENDED_RECONNECT_DELAY`
A 5-minute constant applied via `reconnect_delay_callback` when the tenant is suspended, reducing gateway pressure ~60× compared to the default 5-second interval.

## Usage Example

```rust
let manager = NatsConnectionManager::new(
    "wss://gateway.example.com".to_string(),
    config_service,
    initial_configuration_service,
    auth_service,
    tls_config_provider,
    Arc::new(deactivation_service),
);

// Subscribe to reconnect events before connecting
let mut reconnect_rx = manager.subscribe_reconnect();

// Establish the connection
manager.connect().await?;

// Retrieve the active client for publishing/subscribing
let client = manager.get_client().await?;

// React to reconnections (e.g., re-subscribe to subjects)
tokio::spawn(async move {
    while reconnect_rx.recv().await.is_ok() {
        // Re-establish subscriptions after reconnect
    }
});
```

> **Local mode:** TLS configuration from `LocalTlsConfigProvider` is only applied when `InitialConfigurationService::is_local_mode()` returns `true`, keeping production paths clean.
