Manages NATS WebSocket connections with automatic authentication, TLS configuration, and reconnection handling for agent communication.

## Key Components

- **`NatsConnectionManager`** - Main connection manager with authentication and TLS support
- **`connect()`** - Establishes NATS connection with authentication callbacks and reconnection logic
- **`get_client()`** - Returns the active NATS client for publishing/subscribing
- **`build_nats_connection_url()`** - Constructs WebSocket URL with authorization token
- **`perform_reauthentication_and_build_url()`** - Handles automatic token refresh during reconnection

## Usage Example

```rust
use nats_connection_manager::NatsConnectionManager;

// Create manager with required services
let manager = NatsConnectionManager::new(
    "wss://nats.flamingo.run".to_string(),
    config_service,
    initial_config_service,
    auth_service,
    tls_provider
);

// Connect to NATS server
manager.connect().await?;

// Get client for messaging
let client = manager.get_client().await?;
client.publish("subject", "message").await?;
```

The manager automatically handles authentication token refresh through the `auth_url_callback`, maintains persistent connections with ping intervals, and provides TLS configuration for local development environments. It uses machine credentials for device authentication and WebSocket transport for firewall compatibility.
