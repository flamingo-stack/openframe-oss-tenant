Manages the lifecycle of a NATS client connection for the Flamingo agent, including initial connection setup, TLS configuration, token-based authentication, and automatic reauthentication on token expiry.

## Key Components

- **`NatsConnectionManager`** — Cloneable struct holding a shared `Arc<RwLock<Option<Arc<Client>>>>` alongside URL, config, TLS, and auth service dependencies.
- **`connect()`** — Establishes the WebSocket NATS connection with credentials, reconnect callbacks, ping keepalives, and optional local-mode TLS config.
- **`perform_reauthentication_and_build_url()`** — Static async helper invoked by the `auth_url_callback`; reauthenticates the agent and returns a fresh JWT-bearing connection URL.
- **`build_nats_connection_url()`** — Constructs the initial `wss://<host>/ws/nats?authorization=<token>` URL from the current access token.
- **`get_client()`** — Returns the active `Arc<Client>`, returning an error if `connect()` has not yet been called.

## Usage Example

```rust
let manager = NatsConnectionManager::new(
    "wss://nats.example.com".to_string(),
    config_service,
    initial_configuration_service,
    auth_service,
    tls_config_provider,
);

// Establish connection (retries on failure)
manager.connect().await?;

// Retrieve client for publishing / subscribing
let client = manager.get_client().await?;
client.publish("agent.heartbeat", "ping".into()).await?;
```

## Notes

- The connection URL embeds the access token as a query parameter (`?authorization=`).
- Reconnect delay is fixed at **5 seconds** per attempt; all reconnect events are logged via `tracing`.
- TLS (`LocalTlsConfigProvider`) is applied **only** when `is_local_mode()` returns `true`, keeping production paths unaffected.
- `NATS_DEVICE_USER` is hardcoded to `"machine"` with an empty password; primary auth is token-based via the URL callback.
