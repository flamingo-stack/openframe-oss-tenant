This file implements a NATS connection manager that handles secure WebSocket connections to a NATS messaging server with automatic authentication and reconnection capabilities.

## Key Components

- **NatsConnectionManager**: Main struct managing NATS client connections with authentication and TLS support
- **connect()**: Establishes connection with retry logic, event handling, and reauthentication callbacks
- **get_client()**: Returns the initialized NATS client for message operations
- **build_nats_connection_url()**: Constructs WebSocket connection URL with authorization token
- **perform_reauthentication_and_build_url()**: Handles token refresh during connection issues

The manager integrates with multiple services including configuration management, authentication, and TLS providers to maintain secure, persistent connections.

## Usage Example

```rust
use nats_connection_manager::NatsConnectionManager;

// Create manager with required services
let manager = NatsConnectionManager::new(
    "wss://nats.example.com".to_string(),
    config_service,
    initial_config_service,
    auth_service,
    tls_provider,
);

// Establish connection
manager.connect().await?;

// Get client for messaging
let client = manager.get_client().await?;
client.publish("subject", "message".into()).await?;
```

The connection automatically handles authentication failures, reconnection attempts, and maintains machine identity through custom headers. In local development mode, it configures TLS for secure connections.
