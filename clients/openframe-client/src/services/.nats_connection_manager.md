Manages NATS connections for the Flamingo agent, handling authentication, TLS configuration, and connection lifecycle with automatic reauthentication capabilities.

## Key Components

- **`NatsConnectionManager`** - Main connection manager with thread-safe client storage
- **Connection Methods**:
  - `connect()` - Establishes NATS connection with auth and TLS config
  - `get_client()` - Returns the active NATS client instance
- **Authentication Features**:
  - Automatic reauthentication callback for token refresh
  - Machine-based authentication with custom headers
  - Token-based authorization URL building
- **Configuration Support**:
  - Local development mode with TLS configuration
  - Connection retry and reconnection logic
  - Ping intervals and event callbacks

## Usage Example

```rust
use crate::services::nats_connection_manager::NatsConnectionManager;

// Initialize the connection manager
let manager = NatsConnectionManager::new(
    "nats://localhost:4222".to_string(),
    config_service,
    initial_config_service,
    auth_service,
    tls_provider,
);

// Connect to NATS server
manager.connect().await?;

// Get the client for publishing/subscribing
let client = manager.get_client().await?;
client.publish("subject", "message").await?;
```

The manager handles complex authentication flows, including automatic token refresh and reauthentication when the connection drops, making it suitable for long-running agent processes that need persistent NATS connectivity.
