Provides a single public utility function for crash-safe, atomic file writes using a temp-file-then-rename strategy.

## Key Components

### `atomic_write(path, contents) -> Result<()>`

Writes arbitrary byte content to a file path atomically by:

1. Creating a `NamedTempFile` in the same directory as the target (ensuring same-filesystem rename)
2. Writing all content to the temp file
3. On Unix, correcting permissions from `NamedTempFile`'s default `0o600` to `0o644`
4. Calling `persist()` to atomically replace the destination via `rename(2)` (Unix) or `MoveFileEx` (Windows)

Parent directories are created automatically via `create_dir_all`. Concurrent readers never observe a partially-written file.

## Usage Example

```rust
use std::path::Path;
use your_crate::fs::atomic_write;

fn save_token(token: &[u8]) -> anyhow::Result<()> {
    let path = Path::new("/var/lib/myapp/token.enc");
    atomic_write(path, token)?;
    Ok(())
}
```

## Behavior Notes

| Scenario | Behavior |
|---|---|
| Parent dir missing | Created automatically |
| Existing file at target | Atomically replaced |
| Pre-existing restrictive permissions (`0o600`) | Overwritten with `0o644` on next write |
| Windows | Uses `MoveFileEx` for atomic replace; permission fixup skipped |
| Write failure mid-way | Temp file is dropped/cleaned up; target untouched |
