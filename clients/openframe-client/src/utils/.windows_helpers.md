Windows-specific utility helpers for Win32 API interop and Windows Registry autorun management, used to register or unregister a program for automatic launch at user logon via `HKLM\Software\Microsoft\Windows\CurrentVersion\Run`.

## Key Components

- **`to_wide(s: &str) -> Vec<u16>`** — Converts a Rust `&str` to a null-terminated UTF-16 buffer for use with Win32 wide-character APIs.
- **`wcslen(ptr: *const u16) -> usize`** — Computes the length of a null-terminated UTF-16 string from a raw pointer (unsafe).
- **`build_command_line(command_path, args) -> String`** — Constructs a properly escaped Windows command-line string following `CommandLineToArgvW` conventions, including quoting for spaces, tabs, embedded quotes, and backslash sequences.
- **`register_autorun(value_name, command_path, args) -> Result<()>`** — Writes an autorun entry to the 64-bit HKLM Run key (`KEY_WOW64_64KEY`) and removes any stale duplicate from the WOW6432Node (32-bit) mirror to prevent double-launch.
- **`unregister_autorun(value_name)`** — Removes the autorun entry from both the 64-bit Run key and the WOW6432Node mirror.

## Usage Example

```rust
use crate::windows_helpers::{register_autorun, unregister_autorun, build_command_line};

// Register an agent to start at logon
let args = vec!["--service".to_string(), "--config".to_string(), "C:\\agent\\config.toml".to_string()];
register_autorun("FlamingoAgent", "C:\\Program Files\\Flamingo\\agent.exe", &args)?;

// Build a command line string manually
let cmdline = build_command_line("C:\\tools\\my app.exe", &["--flag".to_string(), "value with spaces".to_string()]);
// -> "C:\tools\my app.exe" --flag "value with spaces"

// Remove the autorun entry during uninstall
unregister_autorun("FlamingoAgent");
```

> **Note:** `register_autorun` only writes to the registry if the existing value differs from the computed command line, avoiding unnecessary writes on repeated calls.
