Windows-specific utility helpers for Win32 interop, command-line construction, and Windows Registry autorun management (HKLM Run key).

## Key Components

| Function | Description |
|---|---|
| `to_wide(s: &str) -> Vec<u16>` | Converts a Rust `&str` to a null-terminated UTF-16 buffer for Win32 wide-char APIs |
| `wcslen(ptr: *const u16) -> usize` | Unsafe C-style wide-string length counter, equivalent to `wcslen` in the CRT |
| `build_command_line(command_path, args) -> String` | Constructs a properly escaped Win32 command-line string following `CommandLineToArgvW` quoting rules |
| `register_autorun(value_name, command_path, args) -> Result<()>` | Writes a startup entry to the 64-bit `HKLM\...\Run` registry key; cleans up any stale WOW6432Node mirror entry |
| `unregister_autorun(value_name)` | Removes a startup entry from both the 64-bit Run key and the WOW6432Node mirror |

## Usage Example

```rust
use windows_helpers::{register_autorun, unregister_autorun, build_command_line};

// Register an agent to launch at Windows logon
register_autorun(
    "FlamingoAgent",
    r"C:\Program Files\Flamingo\agent.exe",
    &["--config".to_string(), r"C:\ProgramData\Flamingo\config.toml".to_string()],
)?;

// Build a quoted command line manually
let cmdline = build_command_line(
    r"C:\path\with spaces\app.exe",
    &["--flag".to_string(), "value with spaces".to_string()],
);
// -> `"C:\path\with spaces\app.exe" --flag "value with spaces"`

// Remove the autorun entry on uninstall
unregister_autorun("FlamingoAgent");
```

## Notes

- `register_autorun` always targets the **64-bit** registry view (`KEY_WOW64_64KEY`) to prevent double-launch on 64-bit Windows. The WOW6432Node mirror is only touched for cleanup.
- `build_command_line` correctly handles backslash-before-quote escaping per the MSVC `CommandLineToArgvW` specification — arguments containing spaces, tabs, or quotes are automatically quoted.
