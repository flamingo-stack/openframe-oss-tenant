Windows-specific registry helpers for managing autorun entries and persistent app configuration under `HKLM`, used by the OpenFrame agent to register tools for per-user autostart at Windows logon.

## Key Components

| Function | Description |
|---|---|
| `to_wide(s)` | Converts a `&str` to a null-terminated UTF-16 `Vec<u16>` for Win32 wide APIs |
| `wcslen(ptr)` | Unsafe C-style wide string length counter for raw `*const u16` pointers |
| `build_command_line(command_path, args)` | Builds a properly escaped Win32 command-line string with `CommandLineToArgvW`-compatible quoting |
| `register_autorun(value_name, command_path, args)` | Writes a launch entry to the 64-bit `HKLM\...\Run` key and removes any stale WOW64 mirror entry |
| `write_app_config(value_name, args)` | Persists parsed `--key value` / `--flag` CLI args as registry values under `HKLM\SOFTWARE\OpenFrame\<name>` |
| `unregister_autorun(value_name)` | Removes a named entry from both the 64-bit Run key and the WOW6432Node mirror |

## Registry Paths

```text
HKLM\Software\Microsoft\Windows\CurrentVersion\Run          (64-bit, autorun write target)
HKLM\Software\WOW6432Node\Microsoft\Windows\CurrentVersion\Run  (32-bit mirror, stale-entry cleanup only)
HKLM\SOFTWARE\OpenFrame\<value_name>                        (per-tool config fallback store)
```

## Usage Example

```rust
use windows_helpers::{register_autorun, write_app_config, unregister_autorun};

let args = vec![
    "--serverUrl".to_string(),
    "https://openframe.example.com".to_string(),
    "--devMode".to_string(),
];

// Register the tool for autostart at logon
register_autorun("OpenFrameTool", r"C:\Program Files\OpenFrame\tool.exe", &args)?;

// Persist config so the tool can recover args when relaunched without CLI flags
write_app_config("OpenFrameTool", &args)?;

// Remove the autorun entry on uninstall
unregister_autorun("OpenFrameTool");
```

> **Note:** All registry writes use `KEY_WOW64_64KEY` to ensure the 64-bit hive is targeted regardless of process bitness. `write_app_config` maps `--key value` pairs to string values and bare `--flag` args to `"1"`.
