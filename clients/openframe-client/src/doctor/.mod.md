Diagnostic runner module for OpenFrame's "doctor" command, providing pre-install validation and post-install health checks with structured, categorized check results.

## Key Components

### Enums
- **`CheckCategory`** — Classifies checks into `Command`, `Admin`, `Disk`, or `Network` domains
- **`CheckStatus`** — Result severity: `Pass`, `Fail`, `Warn`, or `Info`

### Structs
- **`CheckResult`** — A single diagnostic result with category, status, name, and optional hint message. Constructors: `pass`, `fail`, `warn`, `info`
- **`DoctorReport`** — Aggregates a `Vec<CheckResult>` with helpers: `has_failures()`, `failure_count()`, `warn_count()`, and `print()` for console output

### Public Functions
- **`run_preinstall(params)`** — Async pre-install diagnostics: validates CLI args → admin privileges → disk writability → disk space → network reachability. Fails fast on critical errors
- **`run_healthcheck()`** — Async post-install health check: validates admin → reads `initial_config.json` → runs network checks against the configured `server_host`

### Private Function
- **`run_network_checks(results, server_url)`** — Shared network pipeline: DNS resolution → TCP connection → TLS handshake → WebSocket upgrade → proxy env detection

## Usage Example

```rust
// Pre-install check before running setup
let params = InstallConfigParams { server_url: Some("https://openframe.example.com".into()), ..Default::default() };
let report = run_preinstall(&params).await;
report.print();
if report.has_failures() {
    eprintln!("{} check(s) failed — aborting install", report.failure_count());
    std::process::exit(1);
}

// Post-install health check
let report = run_healthcheck().await;
report.print();
```
