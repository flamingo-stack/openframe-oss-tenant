Orchestrates the OpenFrame agent's diagnostic system, providing pre-install validation and post-install health checks with structured result reporting.

## Key Components

**Enums**
- `CheckCategory` — classifies checks as `Command`, `Admin`, `Disk`, or `Network`
- `CheckStatus` — outcome states: `Pass`, `Fail`, `Warn`, `Info`

**Structs**
- `CheckResult` — single diagnostic outcome with category, status, name, and optional hint; constructors: `pass()`, `fail()`, `warn()`, `info()`
- `DoctorReport` — aggregates results with `has_failures()`, `failure_count()`, `warn_count()`, and `print()` for terminal output

**Public Functions**
- `run_preinstall(params)` — validates CLI args → admin privileges → disk writability (bin, app support, secured, logs) → disk space (200 MB) → network connectivity
- `run_healthcheck()` — verifies admin privileges → loads `initial_config.json` → runs network checks against stored `server_host`

**Private Helper**
- `run_network_checks()` — sequential pipeline: DNS resolve → TCP connect → TLS handshake → WebSocket upgrade → optional proxy env check; short-circuits on DNS failure

## Usage Example

```rust
use crate::doctor::{run_preinstall, run_healthcheck};

// Pre-install check before deploying the agent
let report = run_preinstall(&install_params).await;
report.print();
if report.has_failures() {
    eprintln!("{} failure(s) detected", report.failure_count());
    std::process::exit(1);
}

// Post-install health check
let health = run_healthcheck().await;
health.print();
```

> **Note:** Both functions short-circuit early on critical failures (missing args, no admin privileges, missing config) to avoid cascading misleading results downstream.
