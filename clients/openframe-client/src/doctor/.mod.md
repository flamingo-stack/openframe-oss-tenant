Diagnostics engine for the OpenFrame agent's `doctor` command, providing pre-install validation and post-install health checks across four categories: CLI arguments, admin privileges, disk access, and network connectivity.

## Key Components

### Enums
- **`CheckCategory`** — classifies a check as `Command`, `Admin`, `Disk`, or `Network`
- **`CheckStatus`** — result outcome: `Pass`, `Fail`, `Warn`, or `Info`

### Structs
- **`CheckResult`** — single check outcome with category, status, name, and optional hint message; constructed via `pass()`, `fail()`, `warn()`, `info()` convenience methods
- **`DoctorReport`** — collection of `CheckResult`s with helpers: `has_failures()`, `failure_count()`, `warn_count()`, and `print()` for terminal output

### Public Functions
- **`run_preinstall(params)`** — async; validates install args, admin rights, directory writability, disk space (200 MB minimum), service config, and network reachability before installation
- **`run_healthcheck()`** — async; post-install check that loads `initial_config.json` from the secured directory, verifies `server_host`, then runs network checks

### Private Helper
- **`run_network_checks(results, server_url)`** — chains DNS resolution → TCP connect → TLS handshake → WebSocket upgrade, short-circuiting on DNS failure; also appends proxy environment info if detected

## Usage Example

```rust
// Pre-install doctor run
let report = run_preinstall(&install_params).await;
report.print();
if report.has_failures() {
    eprintln!("{} check(s) failed", report.failure_count());
    std::process::exit(1);
}

// Post-install health check
let report = run_healthcheck().await;
report.print();
if report.has_failures() {
    eprintln!("Agent health check failed");
}
```
