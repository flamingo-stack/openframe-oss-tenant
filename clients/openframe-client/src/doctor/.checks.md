Pre-flight validation checks for the OpenFrame client installer, covering argument validation, system permissions, disk access, and network connectivity.

## Key Components

| Function | Category | Description |
|---|---|---|
| `check_required_args` | `Command` | Validates that `--serverUrl`, `--initialKey`, and `--orgId` are present in install params |
| `check_admin_privileges` | `Admin` | Verifies the process is running with elevated permissions (sudo/Administrator) |
| `check_dir_writable` | `Disk` | Probes a path (or its nearest existing ancestor) for write access using a temporary file |
| `check_disk_space` | `Disk` | Uses `sysinfo` to find the disk mount covering a given path and checks available MB |
| `check_service_config_writable` | `Disk` | Convenience wrapper that checks writability of the OS-specific service config directory |
| `check_dns_resolve` | `Network` | Resolves the server hostname via the system DNS resolver |
| `check_tcp_connect` | `Network` | Attempts a 5-second TCP connection to the server on port 443 (or an explicit port) |
| `check_tls_handshake` | `Network` | Performs an HTTPS GET to verify the TLS certificate chain is trusted |
| `check_websocket_upgrade` | `Network` | Sends a WebSocket upgrade request to `/ws/nats`; any HTTP response (including 401/403) counts as reachable |
| `check_proxy_env` | `Network` | Returns an informational result if any `HTTP_PROXY`/`HTTPS_PROXY` env vars are set |

## Usage Example

```rust
use crate::checks::{
    check_required_args, check_admin_privileges,
    check_disk_space, check_tcp_connect, check_tls_handshake,
};
use std::path::Path;

// Validate CLI arguments
let result = check_required_args(&params);
if !result.passed { eprintln!("{}", result.hint); }

// Confirm elevated privileges
let result = check_admin_privileges();

// Ensure at least 500 MB free under the install directory
let result = check_disk_space(Path::new("/opt/openframe"), 500);

// Network reachability (sync)
let result = check_tcp_connect("api.openframe.example.com");

// TLS + WebSocket (async)
let tls = check_tls_handshake("api.openframe.example.com").await;
let ws  = check_websocket_upgrade("api.openframe.example.com").await;
```

> **Platform note:** `check_service_config_writable` resolves to `/Library/LaunchDaemons` on macOS, `/etc/systemd/system` on Linux, and `%ProgramFiles%\OpenFrame\bin` on Windows.
