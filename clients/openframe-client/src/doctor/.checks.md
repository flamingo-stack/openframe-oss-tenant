Pre-flight installation checks for the OpenFrame client, validating system requirements across command arguments, permissions, disk, and network connectivity before installation proceeds.

## Key Components

| Function | Category | Description |
|---|---|---|
| `check_required_args` | `Command` | Validates `--serverUrl`, `--initialKey`, and `--orgId` are present in install params |
| `check_admin_privileges` | `Admin` | Verifies the process is running with elevated permissions (Administrator/sudo) |
| `check_dir_writable` | `Disk` | Probes write access to a path by creating a temporary `.openframe_write_test` file |
| `check_disk_space` | `Disk` | Uses `sysinfo` to confirm available disk space meets a minimum MB threshold |
| `check_service_config_writable` | `Disk` | Wraps `check_dir_writable` for the platform-specific service config directory |
| `check_dns_resolve` | `Network` | Resolves the server hostname via DNS |
| `check_tcp_connect` | `Network` | Attempts a 5-second TCP connection to the server (default port 443) |
| `check_tls_handshake` | `Network` | Async HTTPS GET via `reqwest` to verify TLS certificate acceptance |
| `check_websocket_upgrade` | `Network` | Sends a WebSocket upgrade request to `/ws/nats`; any HTTP response (including 401/403) is treated as reachable |
| `check_proxy_env` | `Network` | Detects `HTTP_PROXY`/`HTTPS_PROXY` environment variables; returns `None` if absent |

## Usage Example

```rust
use crate::preflight::checks::{
    check_required_args, check_admin_privileges,
    check_disk_space, check_tcp_connect, check_tls_handshake,
};
use std::path::Path;

// Validate CLI arguments
let result = check_required_args(&params);
if result.failed() { result.print_and_exit(); }

// Require elevated permissions
let result = check_admin_privileges();
if result.failed() { result.print_and_exit(); }

// Ensure 500 MB free on the install path
let result = check_disk_space(Path::new("/opt/openframe"), 500);

// Network reachability (async context)
let result = check_tls_handshake("https://my.openframe.server").await;
```

> **Platform note:** `check_service_config_writable` resolves to `/Library/LaunchDaemons` on macOS, `/etc/systemd/system` on Linux, and `%ProgramFiles%\OpenFrame\bin` on Windows.
