Pre-installation environment validation checks for the OpenFrame client installer, verifying that all required conditions are met before installation proceeds.

## Key Components

| Function | Category | Description |
|----------|----------|-------------|
| `check_required_args` | `Command` | Validates that `--serverUrl`, `--initialKey`, and `--orgId` are all provided and non-empty |
| `check_admin_privileges` | `Admin` | Confirms the process is running with elevated permissions (Administrator on Windows, root/sudo on Unix) |
| `check_dir_writable` | `Disk` | Probes a path (or its nearest existing ancestor) for write access using a temporary file |
| `check_disk_space` | `Disk` | Uses `sysinfo` to find the mounted disk covering the target path and enforces a minimum free-space threshold in MB |
| `check_service_config_writable` | `Disk` | Convenience wrapper — resolves the OS-specific service config directory (`/Library/LaunchDaemons`, `/etc/systemd/system`, or `%ProgramFiles%\OpenFrame\bin`) and delegates to `check_dir_writable` |
| `check_dns_resolve` | `Network` | Resolves the server hostname via the system resolver; defaults to port 443 if no port is specified |
| `check_tcp_connect` | `Network` | Attempts a TCP connection with a 5-second timeout; emits a warning (not a hard failure) on unreachable hosts |
| `check_tls_handshake` | `Network` | Async — performs an HTTPS GET to validate TLS certificate and proxy compatibility |
| `check_websocket_upgrade` | `Network` | Async — sends a WebSocket upgrade request to `/ws/nats`; accepts any HTTP response as "reachable" (including 401/403) |
| `check_proxy_env` | `Network` | Detects `HTTP_PROXY` / `HTTPS_PROXY` environment variables and returns an informational result if found |

## Usage Example

```rust
use crate::preflight::checks;

// Synchronous checks
let args_ok   = checks::check_required_args(&params);
let admin_ok  = checks::check_admin_privileges();
let disk_ok   = checks::check_disk_space(Path::new("/opt/openframe"), 512);
let write_ok  = checks::check_dir_writable(Path::new("/opt/openframe"), "install dir");
let dns_ok    = checks::check_dns_resolve("https://my.openframe.server");
let tcp_ok    = checks::check_tcp_connect("my.openframe.server:443");

// Async network checks
let tls_ok = checks::check_tls_handshake("my.openframe.server").await;
let ws_ok  = checks::check_websocket_upgrade("my.openframe.server").await;

// Optional proxy info
if let Some(proxy_info) = checks::check_proxy_env() {
    println!("Proxy detected: {:?}", proxy_info);
}
```
