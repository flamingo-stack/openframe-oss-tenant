Cross-platform system service lifecycle manager for the OpenFrame client, handling installation, uninstallation, and OS-native service registration on Windows, macOS, and Linux.

## Key Components

- **`Service`** — Main service struct with static methods for install/uninstall lifecycle management
- **`windows_service_main`** *(Windows only)* — SCM entry point that registers control handlers, manages shutdown signals, and forwards session change events to `WindowsSessionManager`
- **`set_service_status`** *(Windows only)* — Helper to report `ServiceState` transitions back to the Windows Service Control Manager
- **`FULL_SERVICE_NAME`** — Public constant (`"com.openframe.client"`) used as the canonical service identifier across all platforms
- **Recovery constants** — Tiered restart delays (10s → 60s → 300s) and a 1-day reset period for the Windows SCM failure recovery policy

## Usage Example

```rust
use crate::service::Service;
use crate::installation_initial_config_service::InstallConfigParams;

// Check if already installed before attempting install
if Service::is_installed() {
    println!("Service is already registered");
}

// Install with initial configuration params
let params = InstallConfigParams { /* ... */ };
Service::install(params).await?;

// Check install target path
let path = Service::get_install_location();
println!("Binary will be placed at: {}", path.display());
```

## Platform Detection

| Platform | Install Check | Service File Location |
|---|---|---|
| Windows | `sc query com.openframe.client` | SCM registry |
| macOS | plist existence | `/Library/LaunchDaemons/com.openframe.client.plist` |
| Linux | unit file existence | `/etc/systemd/system/com.openframe.client.service` |

> **Note:** On fresh installs where a previous version is detected, the installer automatically invokes the existing binary with `uninstall` before proceeding, with a 3-second cleanup grace period.
