Manages the OpenFrame client service lifecycle across Windows, macOS, and Linux, handling installation, uninstallation, and OS-level service registration with platform-specific SCM/launchd/systemd integration.

## Key Components

### Constants
| Constant | Value | Purpose |
|---|---|---|
| `FULL_SERVICE_NAME` | `"com.openframe.client"` | Cross-platform service identifier |
| `SERVICE_NAME` | `"client"` | Short service name |
| `DISPLAY_NAME` | `"OpenFrame Client Service"` | Human-readable name (Windows SCM) |
| Recovery timeouts | 10s / 60s / 300s | Progressive Windows SCM restart delays |

### `Service` struct
- **`Service::new()`** — Constructs a new `Service` instance.
- **`Service::is_installed() -> bool`** — Checks for an existing installation by probing the platform-native path (Windows registry, `/Library/LaunchDaemons/` plist, or `/etc/systemd/system/` unit file).
- **`Service::install(params: InstallConfigParams) -> Result<()>`** — Full installation flow: detects and removes prior installations, validates directories, persists initial config, copies the binary to the install location, and sets Unix executable permissions.

### Windows-only entry points (`#[cfg(windows)]`)
- **`windows_service_main`** — Called by Windows SCM; wires up a shutdown channel, registers the control handler, reports `Running` status, then blocks on a Tokio runtime running `Service::run()`.
- **`set_service_status`** — Helper to report `ServiceState` transitions back to the Windows SCM.

## Usage Example

```rust
// Check existing installation before installing
if Service::is_installed() {
    println!("Already installed");
}

// Install with configuration parameters
let params = InstallConfigParams { /* ... */ };
Service::install(params).await?;

// Windows: dispatch to SCM (called at process entry)
#[cfg(windows)]
service_dispatcher::start(FULL_SERVICE_NAME, ffi_service_main)?;
```

## Notes

- Binary copy includes a retry-with-rename fallback for in-use executables on Windows (`.exe.old` side-file strategy).
- Recovery policy constants define progressive restart delays for the Windows SCM failure action configuration.
- See [`InstallationInitialConfigService`](https://github.com/flamingo-stack/openframe-oss-tenant/blob/main/src/installation_initial_config_service.rs) for config persistence details.
