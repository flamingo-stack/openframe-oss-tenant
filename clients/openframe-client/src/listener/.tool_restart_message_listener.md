NATS JetStream push consumer that listens for tool restart messages on a per-machine subject and delegates restart execution to `ToolRestartService`.

## Key Components

### `ToolRestartMessageListener`

The primary struct holding injected service dependencies:

| Field | Purpose |
|---|---|
| `nats_connection_manager` | Manages NATS client lifecycle and reconnection signals |
| `tool_restart_service` | Executes guarded restart logic |
| `config_service` | Retrieves the local machine ID for subject routing |
| `tool_run_manager` | Coordinates concurrent tool operations via `park_or_dispatch` |

### Key Methods

- **`start()`** — Spawns a `tokio` task that runs `listen()` in an infinite loop, reconnecting after `RECONNECTION_DELAY_MS` on any exit or error.
- **`listen()`** — Creates a JetStream consumer and drives the `tokio::select!` loop, handling stream messages and NATS reconnection events.
- **`handle_message()`** — Deserializes `ToolRestartMessage`, then calls `park_or_dispatch` to serialize execution per `tool_agent_id`.
- **`dispatch()`** — Calls `restart_guarded`, ACKs on `Restarted`/`NotInstalled`, leaves unacked on error (triggers redelivery), and returns early on `Busy`.
- **`create_consumer()`** — Retries consumer creation with exponential backoff per cycle; recovers gracefully if the durable consumer already exists (error code `10013`).

### NATS Subject Conventions

```text
Filter subject:  machine.<machine_id>.tool-restart
Deliver subject: machine.<machine_id>.tool-restart.inbox
Durable name:    machine_<machine_id>_tool-restart_consumer
Stream:          TOOL_INSTALLATION
```

## Usage Example

```rust
let listener = ToolRestartMessageListener::new(
    nats_connection_manager,
    tool_restart_service,
    config_service,
    tool_run_manager,
);

// Spawns a self-healing background task
let handle = listener.start().await?;
handle.await?;
```

> Consumer retry behavior is governed by `CONSUMER_RETRY_ATTEMPTS_PER_CYCLE`, `INITIAL_RETRY_DELAY_MS`, `MAX_RETRY_DELAY_MS`, and `CONSUMER_CYCLE_PAUSE_MS` from `update_config`.
