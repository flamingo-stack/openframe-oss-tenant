Implements a NATS JetStream push consumer that listens for OpenFrame client update messages on the `CLIENT_UPDATE` stream, with automatic reconnection and retry logic.

## Key Components

- **`OpenFrameClientUpdateListener`** — Main struct holding a NATS connection manager, update service, and agent config service.
- **`start()`** — Spawns a background Tokio task that runs the listener loop indefinitely, reconnecting after failures using `RECONNECTION_DELAY_MS`.
- **`listen()`** — Establishes a JetStream context, resolves the machine ID, creates a durable push consumer, and streams incoming messages.
- **`handle_message()`** — Deserializes each `OpenFrameClientUpdateMessage`, delegates to `OpenFrameClientUpdateService::process_update`, and ACKs on success or leaves unacked for redelivery on failure.
- **`create_consumer()`** — Retry loop with exponential backoff across multiple cycles; gracefully handles `consumer name already in use` by fetching the existing durable consumer.
- **`build_consumer_configuration()`** — Constructs a `push::Config` scoped to `machine.all.client-update` with durable name, ACK wait, and `DeliverPolicy::New`.

## Usage Example

```rust
let listener = OpenFrameClientUpdateListener::new(
    nats_connection_manager,
    openframe_client_update_service,
    config_service,
);

// Spawns a self-healing background task
let handle = listener.start().await?;
handle.await?;
```

**Subject routing per machine:**

```text
Filter subject : machine.all.client-update
Deliver subject: machine.<machine_id>.client-update.inbox
Durable name   : machine_<machine_id>_client-update_consumer_v2
```
