Persistent NATS JetStream push consumer that listens for OpenFrame client update messages and delegates processing to `OpenFrameClientUpdateService`.

## Key Components

**`OpenFrameClientUpdateListener`** — Main struct holding references to:
- `NatsConnectionManager` — provides authenticated NATS client connections
- `OpenFrameClientUpdateService` — processes deserialized update messages
- `AgentConfigurationService` — retrieves the machine ID used for consumer scoping

**Methods:**

| Method | Description |
|--------|-------------|
| `start()` | Spawns a background `tokio` task with an infinite reconnection loop |
| `listen()` | Establishes JetStream context, creates the consumer, and drives the message stream |
| `handle_message()` | Deserializes `OpenFrameClientUpdateMessage`, delegates to the update service, and acks/nacks accordingly |
| `create_consumer()` | Retries consumer creation with exponential backoff across configurable cycles; recovers existing durable consumers on name conflict |
| `build_consumer_configuration()` | Constructs push consumer config with per-machine filter/deliver subjects and durable name |

**NATS Subject Patterns:**

```text
Filter subject:   machine.all.client-update
Deliver subject:  machine.<machine_id>.client-update.inbox
Durable name:     machine_<machine_id>_client-update_consumer_v2
Stream:           CLIENT_UPDATE
```

## Usage Example

```rust
let listener = OpenFrameClientUpdateListener::new(
    nats_connection_manager,
    openframe_client_update_service,
    config_service,
);

// Spawns a self-healing background task; hold the handle to track completion
let handle = listener.start().await?;
handle.await?;
```

**Retry behaviour:** failed consumer creation uses exponential backoff from `INITIAL_RETRY_DELAY_MS` up to `MAX_RETRY_DELAY_MS`, repeated for `CONSUMER_RETRY_ATTEMPTS_PER_CYCLE` attempts before pausing `CONSUMER_CYCLE_PAUSE_MS` between cycles. Unprocessable messages are left unacked for JetStream redelivery up to `CONSUMER_MAX_DELIVER` times.
