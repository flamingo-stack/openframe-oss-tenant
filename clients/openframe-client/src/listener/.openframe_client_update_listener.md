Subscribes to the NATS JetStream `CLIENT_UPDATE` stream and dispatches incoming OpenFrame client update messages to `OpenFrameClientUpdateService` for processing, with automatic reconnection and durable consumer management.

## Key Components

- **`OpenFrameClientUpdateListener`** — Core struct holding references to the NATS connection manager, update service, and agent config service.
- **`start()`** — Spawns a background Tokio task that runs the listen loop indefinitely, reconnecting after failures using `RECONNECTION_DELAY_MS`.
- **`listen()`** — Establishes a JetStream context, resolves the machine ID, creates/retrieves a push consumer, and processes the message stream.
- **`handle_message()`** — Deserializes the raw NATS payload into `OpenFrameClientUpdateMessage`, delegates to the update service, and acks on success or leaves unacked for redelivery on failure.
- **`create_consumer()`** — Attempts consumer creation with exponential backoff retry cycles; falls back to retrieving an existing durable consumer on name-conflict errors (`10013`).
- **`build_consumer_configuration()`** — Constructs a `push::Config` scoped to `machine.all.client-update`, with a machine-specific inbox and durable name (`v2`).

## Usage Example

```rust
let listener = OpenFrameClientUpdateListener::new(
    nats_connection_manager,
    openframe_client_update_service,
    config_service,
);

// Spawns background task; handle can be awaited or dropped
let _handle = listener.start().await?;
```

> **Consumer subjects** — The filter subject is broadcast (`machine.all.client-update`) while the deliver subject and durable name are machine-scoped, ensuring each agent receives its own isolated message inbox with at-least-once delivery guarantees.
