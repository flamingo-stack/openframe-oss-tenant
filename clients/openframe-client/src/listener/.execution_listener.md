Subscribes to NATS subjects for a specific machine and executes incoming script/command requests, enforcing concurrency limits and optionally persisting results to a durable journal before publishing back over NATS.

## Key Components

### `ExecutionListener<M>`

Generic struct parameterized over `M: ExecutionMessage`. Wires together NATS connectivity, execution, result storage, and concurrency control.

| Field | Purpose |
|---|---|
| `nats_connection_manager` | Provides the active NATS client |
| `nats_message_publisher` | Publishes `RmmResult` back to the broker |
| `execution_service` | Runs the actual script/command |
| `config_service` | Resolves the local machine ID |
| `semaphore` | Caps parallel executions |
| `result_store` | Durable journal for at-least-once delivery |
| `flush_notify` | Signals the flush background task |

### Key Methods

- **`start()`** — Spawns a self-restarting `tokio` loop; reconnects after `RECONNECTION_DELAY_MS` on any error.
- **`listen()`** — Subscribes to `machine.<id>.<KIND>` and drives `run_bounded`.
- **`handle_message()`** — Parses the NATS payload, branches into durable or best-effort execution.
- **`handle_durable()`** — Journals the batch, marks scripts started, persists results, triggers flush; falls back to direct publish on storage failure.
- **`publish_directly()`** — Best-effort fire-and-forget execution path.

### `run_bounded`

Free async function that drives a `futures::Stream`, acquiring a semaphore permit per item and spawning each handler in its own `tokio` task — permit held until the task completes.

## Usage Example

```rust
let listener = ExecutionListener::<MyMessage>::new(
    nats_connection_manager,
    nats_message_publisher,
    execution_service,
    config_service,
    Arc::new(Semaphore::new(4)), // max 4 concurrent executions
    result_store,
    flush_notify,
);

// Spawn the self-restarting listener loop
let _handle = listener.start().await?;
```
