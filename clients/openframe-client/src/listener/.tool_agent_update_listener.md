A NATS JetStream push consumer that listens for tool agent update messages on the `TOOL_UPDATE` stream, processes them via `ToolAgentUpdateService`, and handles reconnection with exponential backoff retry logic.

## Key Components

- **`ToolAgentUpdateListener`** — Main struct holding the NATS connection manager, update service, and agent config service
- **`start()`** — Spawns a background `tokio` task with an infinite reconnection loop
- **`listen()`** — Establishes a JetStream consumer and streams incoming messages
- **`handle_message()`** — Deserializes `ToolAgentUpdateMessage` payloads, delegates to `ToolAgentUpdateService`, and ACKs on success (leaves unacked for redelivery on failure)
- **`create_consumer()`** — Creates or retrieves a durable push consumer with cycle-based retry and exponential backoff (capped at `MAX_RETRY_DELAY_MS`)
- **`build_consumer_configuration()`** — Constructs the `push::Config` with filter subject `machine.all.tool.*.update`, per-machine deliver subject, and durable name

## Subject Routing

```text
Filter : machine.all.tool.*.update
Deliver: machine.{machine_id}.tool.update.inbox
Durable: machine_{machine_id}_tool_update_consumer
```

## Usage Example

```rust
let listener = ToolAgentUpdateListener::new(
    nats_connection_manager,
    tool_agent_update_service,
    config_service,
);

// Spawns a self-healing background task
let handle = listener.start().await?;

// Await if you need to join (typically fire-and-forget)
handle.await?;
```

## Retry Behavior

```text
Per cycle : CONSUMER_RETRY_ATTEMPTS_PER_CYCLE attempts
Backoff   : INITIAL_RETRY_DELAY_MS → doubles each attempt → capped at MAX_RETRY_DELAY_MS
Between cycles : CONSUMER_CYCLE_PAUSE_MS pause
On disconnect  : RECONNECTION_DELAY_MS before re-entering listen()
```
