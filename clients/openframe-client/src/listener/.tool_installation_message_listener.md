NATS JetStream push consumer that listens for tool installation messages targeting a specific machine and delegates installation processing to `ToolInstallationService`.

## Key Components

**`ToolInstallationMessageListener`** — Main struct holding references to the NATS connection manager, installation service, and agent configuration service.

### Methods

| Method | Description |
|--------|-------------|
| `start()` | Spawns a background Tokio task with an infinite reconnection loop |
| `listen()` | Establishes NATS JetStream context, creates the consumer, and polls the message stream |
| `handle_message()` | Deserializes payload into `ToolInstallationMessage`, delegates to `ToolInstallationService::install()`, and ACKs/NACKs accordingly |
| `create_consumer()` | Retry loop with exponential backoff; handles the `consumer name already in use` conflict by fetching the existing durable consumer |
| `build_consumer_configuration()` | Constructs a `push::Config` with machine-scoped filter/deliver subjects, ack wait, and max deliver limits |

### Subject Conventions

```text
Filter subject : machine.<machine_id>.tool-installation
Deliver subject: machine.<machine_id>.tool-installation.inbox
Durable name   : machine_<machine_id>_tool-installation_consumer
Stream name    : TOOL_INSTALLATION
```

## Usage Example

```rust
let listener = ToolInstallationMessageListener::new(
    nats_connection_manager,
    tool_installation_service,
    config_service,
);

// Spawns a self-healing background task that reconnects on failure
let _handle = listener.start().await?;
```

**Message handling behavior:**
- **Malformed JSON** → immediately ACKed to prevent infinite redelivery
- **Install success** → ACKed after successful processing
- **Install failure** → left unACKed, allowing JetStream to redeliver up to `CONSUMER_MAX_DELIVER` times
