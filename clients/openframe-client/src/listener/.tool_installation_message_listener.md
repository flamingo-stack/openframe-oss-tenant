Listens for NATS JetStream messages on the `TOOL_INSTALLATION` stream and delegates tool installation requests to `ToolInstallationService`, with automatic reconnection and retry logic.

## Key Components

**`ToolInstallationMessageListener`** — Main struct holding:
- `nats_connection_manager` — Manages NATS client connections
- `tool_installation_service` — Executes tool installations
- `config_service` — Retrieves the machine ID for subject routing

**Key Methods:**
- `start()` — Spawns a background `tokio` task with an infinite reconnection loop
- `listen()` — Connects to NATS JetStream and consumes messages from the stream
- `handle_message()` — Parses `ToolInstallationMessage` JSON, calls `install()`, and ACKs on success; leaves unACKed for redelivery on failure; ACKs malformed messages immediately to prevent infinite redelivery
- `create_consumer()` — Creates or retrieves a durable push consumer with exponential backoff retry cycles; handles the `consumer name already in use` (error `10013`) edge case
- `build_consumer_configuration()` — Constructs push consumer config with machine-scoped filter/deliver subjects and durable name

**NATS Subject Pattern:**
```text
Filter:  machine.<machine_id>.tool-installation
Deliver: machine.<machine_id>.tool-installation.inbox
Durable: machine_<machine_id>_tool-installation_consumer
```

## Usage Example

```rust
let listener = ToolInstallationMessageListener::new(
    nats_connection_manager,
    tool_installation_service,
    config_service,
);

// Spawns background task; auto-reconnects on failure
let handle = listener.start().await?;
handle.await?;
```
