Listens for tool uninstall commands delivered via NATS JetStream and orchestrates safe, concurrent uninstallation of tools on the local machine.

## Key Components

### `ToolUninstallMessageListener` (struct)

The primary listener struct, holding references to:

- `NatsConnectionManager` — manages NATS client connectivity and reconnect signals
- `ToolRunManager` — coordinates tool locks, supervision state, and update flags
- `ToolUninstallService` — performs the actual uninstall logic
- `AgentConfigurationService` — provides the machine identity for subject routing

### Key Methods

| Method | Description |
|---|---|
| `new(...)` | Constructs the listener with required service dependencies |
| `start()` | Spawns a supervised Tokio task that loops indefinitely, restarting `listen()` on failure |
| `listen()` | Creates a durable JetStream push consumer and drives the `select!` message/reconnect loop |
| `handle_message()` | Deserializes the `ToolUninstallMessage` payload and delegates to `park_or_dispatch` for concurrency gating |
| `dispatch()` | Acquires the per-tool lock, runs uninstall under panic protection, and ACKs or leaves the message for redelivery |
| `create_consumer()` | Creates (or recovers) a durable push consumer with exponential-backoff retry cycles |
| `build_consumer_configuration()` | Builds the `push::Config` with machine-scoped filter/deliver subjects and configured ACK wait |

### NATS Subject Pattern

```text
machine.<machine_id>.tool-uninstall          ← filter subject
machine.<machine_id>.tool-uninstall.inbox    ← deliver subject
machine_<machine_id>_tool-uninstall_consumer ← durable consumer name
```

## Usage Example

```rust
let listener = ToolUninstallMessageListener::new(
    nats_connection_manager,
    tool_run_manager,
    tool_uninstall_service,
    config_service,
);

let handle = listener.start().await?;
handle.await?;
```

The listener self-recovers from stream errors and NATS reconnections. Uninstall operations that fail or panic leave their message unacknowledged for automatic redelivery up to `UNINSTALL_CONSUMER_MAX_DELIVER` times.
