This is the minimal entry point binary for the OpenFrame client agent. It delegates all application logic to the shared `openframe-agent-lib` library (crate name `openframe`), sourced from the [flamingo-stack/openframe-oss-lib](https://github.com/flamingo-stack/openframe-oss-lib) repository, keeping the executable crate as a thin wrapper.

## Key Components

- **`main()`** - The binary's entry point. Returns `anyhow::Result<()>` for unified error handling and propagation, and immediately calls `openframe::run()` to hand off execution to the shared library.

## Usage Example

Building the binary requires the `OPENFRAME_VERSION` environment variable, which is consumed by the library's build script to embed version metadata:

```bash
OPENFRAME_VERSION=0.0.0-dev cargo build --release
```

Running the compiled binary simply invokes the library's runtime:

```bash
OPENFRAME_VERSION=0.0.0-dev cargo run --release
```

The `main.rs` file itself contains no business logic:

```rust
fn main() -> anyhow::Result<()> {
    openframe::run()
}
```

Any errors returned by `openframe::run()` propagate naturally through `anyhow::Result`, producing a non-zero exit code and a formatted error message if the agent fails to start or encounters a fatal error during execution. All functional behavior—configuration loading, service initialization, command handling, etc.—is implemented and documented within the `openframe-agent-lib` crate itself.
