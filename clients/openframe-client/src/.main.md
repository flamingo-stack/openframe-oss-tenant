Entry point for the OpenFrame agent binary, providing a CLI interface to install, uninstall, and run the OpenFrame client as a system service or directly.

## Key Components

- **`ensure_admin_privileges()`** — Platform-specific (Unix/Windows) guard that exits immediately if the process lacks root/administrator privileges.
- **`Cli` / `Commands`** — `clap`-derived structs defining the CLI surface:
  - `install` — Installs the agent as a system service with optional server URL, initial key, org ID, local mode, and tags.
  - `uninstall` — Removes the system service.
  - `run` — Runs the agent directly (no service wrapper), useful for debugging.
  - `run-as-service` *(hidden)* — Invoked by the OS service manager.
  - `check-permissions` *(hidden)* — Diagnostic command that prints capability status and exits `0`/`1` accordingly.
- **`check_capabilities_and_warn()`** — Logs warnings for any missing `PermissionUtils` capabilities without hard-failing the process.

## Usage Example

```bash
# Install as a system service
sudo openframe install \
  --serverUrl https://openframe.example.com \
  --initialKey abc123 \
  --orgId my-org \
  --tag production \
  --tag us-east

# Uninstall the service
sudo openframe uninstall

# Run directly (foreground, no service wrapper)
sudo openframe run

# Diagnostic: check current process permissions
sudo openframe check-permissions
```

```rust
// Default behaviour when no subcommand is provided (legacy mode):
// equivalent to `Service::run().await`
```

> **Note:** All subcommands require root/administrator privileges. The process exits with code `1` immediately if run without elevated permissions, before any subcommand logic executes.
