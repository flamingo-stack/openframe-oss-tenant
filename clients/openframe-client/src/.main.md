Entry point for the OpenFrame OSS tenant agent CLI. Parses subcommands to install, uninstall, run, or diagnose the OpenFrame client service, delegating to the `openframe` crate for all core logic.

## Key Components

### `Cli` / `Commands`
Clap-powered CLI parser with the following subcommands:

| Command | Description |
|---|---|
| `install` | Install the agent as a system service (runs pre-install health checks first) |
| `uninstall` | Remove the installed system service |
| `run` | Run the client directly, without a service wrapper |
| `run-as-service` | (hidden) Called by the OS service manager |
| `check-permissions` | (hidden) Print admin status and individual `Capability` flags |
| `doctor` | Run environment health checks against the installed agent config |
| *(none)* | Legacy mode — equivalent to `run-as-service` |

### `InstallArgs` / `InstallConfigParams`
Captures CLI flags (`--serverUrl`, `--initialKey`, `--localMode`, `--orgId`, `--tag`) and converts them to `InstallConfigParams` via `to_params()`.

### `init_logging()`
Helper that initialises file + console logging via `openframe::logging::init`, exiting on failure.

## Usage Example

```bash
# Install the agent
openframe-tenant install \
  --serverUrl https://openframe.example.com \
  --initialKey <KEY> \
  --orgId <ORG_ID> \
  --tag env=prod

# Run a post-install health check
openframe-tenant doctor

# Run directly (foreground, requires admin)
openframe-tenant run

# Inspect permission capabilities
openframe-tenant check-permissions

# Uninstall
openframe-tenant uninstall
```

## Notes

- Admin privileges are enforced via `PermissionUtils::require_admin()` before any mutating operation.
- The `install` command runs `openframe::doctor::run_preinstall` and aborts on failures before touching the system.
- All async work runs on a single `tokio::runtime::Runtime` created at startup.
