Entry point for the OpenFrame agent CLI binary. Parses subcommands and dispatches to install, uninstall, run, service, and diagnostic workflows using a Tokio async runtime.

## Key Components

| Item | Description |
|------|-------------|
| `Cli` | Root clap parser struct with optional subcommand dispatch |
| `InstallArgs` | CLI arguments for the `install` subcommand (`--serverUrl`, `--initialKey`, `--localMode`, `--orgId`, `--tag`) |
| `InstallArgs::to_params()` | Converts CLI args into `InstallConfigParams` for the service layer |
| `Commands` | Enum of available subcommands: `Install`, `Uninstall`, `Run`, `RunAsService` (hidden), `CheckPermissions` (hidden), `Doctor` |
| `main()` | Matches on parsed command and drives the async runtime via `rt.block_on(...)` |
| `init_logging()` | Helper that initializes the OpenFrame logging subsystem, exiting on failure |

## Command Behavior

| Command | Admin Required | Description |
|---------|---------------|-------------|
| `install` | No | Runs pre-install health checks, then installs the agent as a system service |
| `uninstall` | Yes | Removes the system service registration |
| `run` | Yes | Runs the client directly, bypassing the service wrapper |
| `run-as-service` | Yes | Invoked by the OS service manager; calls `Service::run_as_service()` |
| `check-permissions` | No | Prints admin status and each `Capability` flag, exits `1` if not admin |
| `doctor` | No | Runs environment health checks against the installed agent config |
| *(none)* | Yes | Legacy fallback — calls `Service::run(None)` directly |

## Usage Example

```bash
# Install with a remote server
openframe install --serverUrl https://msp.example.com --initialKey abc123 --orgId org_01

# Install in local mode with tags
openframe install --localMode --tag production --tag us-east

# Run health check diagnostics
openframe doctor

# Uninstall the service
openframe uninstall

# Run directly (foreground, no service wrapper)
openframe run

# Inspect permission capabilities
openframe check-permissions
```

```rust
// InstallArgs → InstallConfigParams conversion
let args = InstallArgs {
    server_url: Some("https://msp.example.com".into()),
    initial_key: Some("abc123".into()),
    org_id: Some("org_01".into()),
    local_mode: false,
    tags: vec!["production".into()],
};
let params = args.to_params();
Service::install(params).await?;
```

> Pre-install checks run via `openframe::doctor::run_preinstall()` before any installation proceeds. A failed check (not just a warning) will abort with `exit(1)`.
