Entry point for the OpenFrame client CLI binary, handling service lifecycle commands (install, uninstall, run) and diagnostics via a `clap`-based argument parser.

## Key Components

| Component | Description |
|-----------|-------------|
| `Cli` / `Commands` | `clap` structs defining the CLI surface: `install`, `uninstall`, `run`, `run-as-service`, `check-permissions`, `doctor` |
| `InstallArgs` | CLI arguments for the `install` subcommand, mapping to `InstallConfigParams` |
| `main()` | Dispatches each subcommand, enforcing admin checks, initializing logging, and driving the Tokio runtime |
| `init_logging()` | Initializes the full logging stack via `openframe::logging::init`, exiting on failure |

## Commands

| Command | Visibility | Description |
|---------|-----------|-------------|
| `install` | Public | Runs pre-install health checks, then installs the agent as a system service |
| `uninstall` | Public | Removes the installed system service |
| `run` | Public | Runs the client directly, bypassing the service wrapper |
| `run-as-service` | Hidden | Invoked by the OS service manager |
| `check-permissions` | Hidden | Prints admin status and capability flags |
| `doctor` | Public | Reads installed agent config and runs environment health checks |

## Usage Example

```bash
# Install with server URL and org
openframe install --serverUrl https://api.flamingo.run --initialKey abc123 --orgId my-org

# Run health diagnostics on an installed agent
openframe doctor

# Run directly (foreground, requires admin)
openframe run

# Inspect capabilities
openframe check-permissions
```

```rust
// Core dispatch pattern — each arm enforces permissions, initializes logging, then delegates
Some(Commands::Run) => {
    PermissionUtils::require_admin();
    init_logging();
    let client = Client::new(None)?;
    rt.block_on(client.start())?;
}
```

> **Note:** When invoked with no subcommand, the binary defaults to `Service::run(None)` (legacy service mode), preserving backwards compatibility with OS-managed service entries.
