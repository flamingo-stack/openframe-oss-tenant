Provides RAII-based cleanup for temporary script files, ensuring they are deleted when they go out of scope.

## Key Components

- **`TempFileGuard`** — A guard struct that wraps a `PathBuf`. Implements `Drop` to automatically remove the file at the stored path when the guard is dropped. Logs a warning via `tracing` if deletion fails.
- **`temp_script_name(ext)`** — Generates a unique, collision-resistant temporary filename in the format `ofcmd_<uuid>.<ext>` using a UUID v4 with simple (non-hyphenated) formatting.

## Usage Example

```rust
use std::fs;

// Generate a unique temp filename and write a script
let name = temp_script_name("sh");
let path = std::env::temp_dir().join(&name);
fs::write(&path, b"#!/bin/bash\necho hello").unwrap();

// Guard ensures the file is deleted when this block exits
let _guard = TempFileGuard { path };

// ... execute the script ...

// File is removed here when `_guard` drops
```

## Notes

- The `ofcmd_` prefix namespaces temp files to OpenFrame commands, making them identifiable in the filesystem.
- Deletion failures are non-fatal — the guard logs a warning rather than panicking, keeping cleanup best-effort.
- Both `TempFileGuard` and `temp_script_name` are `pub(crate)`, scoping them to internal use within the crate.
