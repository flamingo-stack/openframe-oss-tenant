Cross-platform script execution module that provides a unified interface for running scripts with configurable privileges, shell selection, environment variables, and timeout handling.

## Key Components

### Enums

- **`Privilege`** — Execution privilege level: `Agent` (service-level) or `User` (interactive user context)

### Structs

- **`ScriptParams<'a>`** — Input parameters for script execution:
  - `code` — Script source code to execute
  - `shell` — Shell interpreter path/name
  - `args` — Additional arguments passed to the script
  - `timeout_secs` — Maximum execution time in seconds
  - `privilege` — Execution privilege level
  - `env_vars` — Environment variable overrides

- **`ExecResult`** — Output from a completed script execution:
  - `stdout` / `stderr` — Captured output streams
  - `retcode` — Process exit code
  - `timed_out` — Whether execution was halted by the timeout

### Platform-Specific Exports

- **`execute_script`** — The primary entry point, re-exported from either `unix` or `windows` submodule depending on the compile target

### Internal Submodules

| Module | Purpose |
|---|---|
| `env` | Environment variable handling |
| `output` | Output capture utilities |
| `tempfile` | Temporary script file management |
| `unix` / `windows` | Platform-specific execution logic |

## Usage Example

```rust
use script::{execute_script, ExecResult, Privilege, ScriptParams};

let params = ScriptParams {
    code: "echo hello",
    shell: "/bin/bash",
    args: &[],
    timeout_secs: 30,
    privilege: Privilege::Agent,
    env_vars: &["MY_VAR=value".to_string()],
};

let result: ExecResult = execute_script(params)?;
println!("stdout: {}", result.stdout);
println!("exit code: {}", result.retcode);

if result.timed_out {
    eprintln!("Script exceeded timeout");
}
```
