Unix shell script executor that writes a temporary script file, optionally changes its ownership for run-as-user support, and executes it with a configurable timeout.

## Key Components

| Item | Description |
|------|-------------|
| `execute_script(params)` | Primary async entry point — resolves user privilege, creates a temp script, builds the command, and delegates to the timeout executor |
| `create_temp_script(code, run_as)` | Writes script bytes adjacent to the agent executable, sets `0o700` permissions, and `chown`s to the target user when running as a non-agent identity |
| `build_script_command(path, args)` | Constructs a `tokio::process::Command` from the temp file path and any caller-supplied arguments |
| `normalize_line_endings(code)` | Strips Windows-style `\r\n` line endings before writing to disk |
| `spawn_error(e)` | Converts a setup-phase `anyhow::Error` into an `ExecResult` with retcode `85` |
| `process` (submodule) | Contains `execute_with_timeout` — runs the command and enforces the deadline |
| `run_as_user` (submodule) | Provides `resolve_run_as` and `configure_preexec` for privilege resolution and `setuid`/`setgid` before `exec` |

## Usage Example

```rust
use crate::executor::{Privilege, ScriptParams};
use crate::executor::shell::execute_script;

let result = execute_script(ScriptParams {
    code: "#!/bin/sh\necho hello\n",
    shell: "/bin/sh",
    args: &[],
    timeout_secs: 30,
    privilege: Privilege::Agent,
    env_vars: &["MY_VAR=value".to_string()],
}).await;

assert_eq!(result.retcode, 0);
assert_eq!(result.stdout, "hello\n");
```

> **Error handling:** Any failure before `exec` (privilege resolution, temp-file write, `chown`, `preexec` setup) short-circuits with retcode `85` and the error message in `stderr`. The temp file is always removed via `TempFileGuard` regardless of outcome.
