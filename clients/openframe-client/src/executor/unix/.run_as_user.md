Resolves and applies OS-level user identity switching for child processes, mapping executor privilege levels to Unix UID/GID credentials before `exec`.

## Key Components

### Types

- **`RunAs`** — Enum representing execution identity: `Current` (inherit agent's user) or `User(UserInfo)` (switch to a specific user)
- **`UserInfo`** — Struct holding resolved POSIX user data: `username`, `uid`, `gid`, and `home_dir`

### Functions

- **`resolve_run_as(privilege)`** — Async entry point; maps `Privilege::Agent` → `RunAs::Current` and `Privilege::User` → `RunAs::User` with a fully resolved `UserInfo`
- **`lookup_user(username)`** — Performs `/etc/passwd`-style lookup via `nix::unistd::User::from_name`
- **`resolve_active_user()`** — Platform-specific detection of the active interactive user:
  - **macOS**: reads `/dev/console` owner via `stat -f %Su`
  - **Linux**: queries `loginctl list-sessions` for a seat-attached session, falls back to `who`
- **`configure_preexec(cmd, run_as)`** — Installs a `pre_exec` hook on a `tokio::process::Command` that calls `setpgid`, `initgroups`, `setgid`, and `setuid` in the child process before exec; also sets `HOME`, `USER`, `LOGNAME` env vars and `current_dir`

## Usage Example

```rust
use crate::executor::Privilege;

let privilege = Privilege::User;
let run_as = resolve_run_as(privilege).await?;

let mut cmd = Command::new("/bin/sh");
cmd.arg("-c").arg("id -u");

configure_preexec(&mut cmd, &run_as)?;
let output = cmd.output().await?;
```

> **Note:** Switching to another user requires the agent process to be running as `root`. If `uid != 0` and the target differs from the current user, `configure_preexec` returns an error immediately rather than spawning a process that would fail at `setuid`.
