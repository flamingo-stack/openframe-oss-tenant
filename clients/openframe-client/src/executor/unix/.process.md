Async subprocess executor that runs a command with a configurable timeout, captures stdout/stderr, and ensures the full process tree is cleaned up on exit or timeout.

## Key Components

### `execute_with_timeout(cmd, timeout_secs) -> ExecResult`
The primary entry point. Spawns a command with piped stdio, waits up to `timeout_secs` for completion, and returns an `ExecResult` with captured output and a return code. On timeout, kills the process group and returns retcode `98`. On signal termination, maps the signal to `128 + signum` (e.g., SIGKILL → `137`).

### `spawn_with_retry(cmd, max_retries)`
Retries process spawning up to `max_retries` times (500 ms apart) when the OS returns `ETXTBSY` (text file busy — common when a script file is still being written). All other errors fail immediately.

### `join_reads(stdout_task, stderr_task, pid)`
Awaits both stdio reader tasks with a 5-second grace period (`READ_GRACE`). If streams remain open after the grace period (e.g., a backgrounded child inherited the pipe), the process group is killed and reads are retried once more.

### `kill_process_tree(pid)`
Sends `SIGKILL` to the entire process group (`-pid`) via `libc::kill`. Refuses to target PID 0 to prevent accidentally killing the agent process itself.

## Usage Example

```rust
use tokio::process::Command;
use crate::executor::process::execute_with_timeout;

let mut cmd = Command::new("/bin/sh");
cmd.arg("-c").arg("echo hello");

let result = execute_with_timeout(cmd, 30).await;

assert_eq!(result.retcode, 0);
assert_eq!(result.stdout.trim(), "hello");
assert!(!result.timed_out);
```

## Return Codes

| Condition | `retcode` |
|---|---|
| Normal exit | Process exit code |
| Signal termination | `128 + signal` |
| Timeout | `98` |
| Spawn failure | `85` |
