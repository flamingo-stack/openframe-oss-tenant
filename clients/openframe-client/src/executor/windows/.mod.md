Windows script executor entry point for the OpenFrame agent. Handles interpreter resolution, temporary script file creation, and dispatch to either normal or user-impersonation execution paths for PowerShell and CMD shells.

## Key Components

| Item | Description |
|------|-------------|
| `Interpreter` | Holds the resolved executable path, CLI flags, and file extension for a supported shell |
| `execute_script` | Main async entry point — resolves interpreter, writes a temp script, waits for file readability, then dispatches to `run_as_user` or `process` |
| `resolve_interpreter` | Maps shell name (`"powershell"` / `"cmd"`) to an `Interpreter`; returns `None` for unsupported shells |
| `resolve_exe` | Resolves the absolute `System32` path for an executable via `WINDIR` / `SystemRoot`, falling back to bare name |
| `wait_until_readable` | Retries file-open up to 3 times with 200 ms delays to handle antivirus scan locks (OS error 32/33/5) |
| `create_temp_script` | Writes script code to `%PROGRAMDATA%\OpenFrame\<random>.<ext>` |
| `win_tmp_dir` | Returns (and creates) the `OpenFrame` temp directory under `PROGRAMDATA` |
| `spawn_error` | Constructs a failed `ExecResult` with retcode `85` for setup errors |

Submodules: `job` (Windows Job Objects for process-tree cleanup), `process` (normal execution), `run_as_user` (interactive-user impersonation).

## Usage Example

```rust
use crate::executor::{Privilege, ScriptParams};
use crate::executor::windows::execute_script;

let result = execute_script(ScriptParams {
    code: "Write-Output 'hello'",
    shell: "powershell",
    args: &[],
    timeout_secs: 30,
    privilege: Privilege::Agent,
    env_vars: &["MY_VAR=value".to_string()],
}).await;

assert_eq!(result.retcode, 0);
println!("{}", result.stdout); // "hello"
```

Unsupported shells return retcode `85` immediately without spawning any process. `Privilege::User` routes through `run_as_user::run_as_interactive`, which requires the agent to be running as `SYSTEM` with an active desktop session.
