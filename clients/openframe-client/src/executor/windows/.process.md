Async process execution handler for running interpreter-based scripts as child processes with timeout enforcement and output capture.

## Key Components

- **`run_normal`** — Primary async function that spawns a child process for a given interpreter and script file, captures stdout/stderr concurrently, enforces a configurable timeout, and returns a structured `ExecResult`.
- **`CREATE_NO_WINDOW`** — Windows creation flag (`0x0800_0000`) that suppresses console window creation for spawned processes.
- **`JobHandle::for_pid`** — Associates the child process with a job handle for reliable process group termination on timeout.

## Behavior & Exit Codes

| Scenario | `retcode` | `timed_out` |
|---|---|---|
| Spawn failure | `85` | `false` |
| Normal exit | Process exit code | `false` |
| Wait error | `1` | `false` |
| Timeout | `98` | `true` |

On timeout, the function calls both `job.terminate()` and `child.start_kill()` to ensure the process tree is cleaned up before collecting any buffered output.

## Usage Example

```rust
let result = run_normal(
    &interpreter,   // e.g. PowerShell or Python interpreter
    &tmp_script,    // path to the temp script file
    &ScriptParams {
        args: &["--flag"],
        env_vars: &[("KEY", "value")],
        timeout_secs: 30,
    },
)
.await;

println!("exit: {}, stdout: {}", result.retcode, result.stdout);
if result.timed_out {
    eprintln!("Script exceeded timeout");
}
```

## Notes

- stdout and stderr are read concurrently via `tokio::spawn` using capped readers to prevent unbounded memory growth.
- Output is sanitized through `clean_string` before being returned in `ExecResult`.
- See [`flamingo-stack/openframe-oss-tenant`](https://github.com/flamingo-stack/openframe-oss-tenant) for the full executor module context.
