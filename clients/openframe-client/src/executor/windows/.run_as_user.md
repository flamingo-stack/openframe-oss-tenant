Executes scripts as the currently logged-in interactive Windows user by acquiring a WTS session token and spawning a child process via `CreateProcessAsUserW`.

## Key Components

### Public Function

- **`run_as_interactive`** — Async entry point. Builds the command line, creates temp stdout/stderr files, and offloads execution to a blocking task via `tokio::task::spawn_blocking`.

### Private Functions

| Function | Description |
|---|---|
| `build_command_line` | Assembles the interpreter executable, flags, script path, and extra args into a single quoted command string |
| `quote` | Windows-style argument quoting (handles backslashes and embedded double-quotes) |
| `run_as_blocking` | Core blocking logic: acquires a token, creates the process, waits for completion, and collects output |
| `make_inheritable` | Sets `HANDLE_FLAG_INHERIT` so stdio handles are visible to the child process |
| `build_env_block` | Merges the user's environment block with caller-supplied overrides into a `NUL`-terminated UTF-16 block |
| `user_environment` | Calls `CreateEnvironmentBlock` with the user token to get the user's real environment |
| `read_capped_file` | Reads a temp output file up to `MAX_OUTPUT_SIZE` and sanitises the bytes |

### Types

- **`InteractiveToken`** — RAII wrapper around a Windows `HANDLE`. Acquires a primary token for the active console session (via `WTSQueryUserToken` + `DuplicateTokenEx`) and closes it on drop.

## Usage Example

```rust
let result = run_as_interactive(
    &interpreter,
    Path::new("C:\\Temp\\script_abc123.ps1"),
    &ScriptParams {
        args: &[],
        timeout_secs: 30,
        env_vars: &["MY_VAR=hello".to_string()],
    },
)
.await;
```

> **Platform note:** This module is Windows-only. It relies on WTS APIs (`wtsapi32`) and `CreateProcessAsUserW` and will not compile on other targets.
