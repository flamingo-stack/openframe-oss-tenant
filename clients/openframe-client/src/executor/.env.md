Utility module for parsing and applying environment variable strings to async process commands.

## Key Components

- **`split_env(var: &str) -> Option<(&str, &str)>`** — Splits a `KEY=VALUE` string on the first `=`, returning a `(key, value)` tuple. Returns `None` if no `=` is present. Values containing additional `=` characters are preserved intact.

- **`apply_env_vars(cmd: &mut Command, env_vars: &[String])`** — Iterates a slice of `KEY=VALUE` strings and sets each as an environment variable on a `tokio::process::Command`. Skips and logs a warning for any entry missing `=` or with an empty key name.

## Usage Example

```rust
use tokio::process::Command;
use crate::env::apply_env_vars;

let mut cmd = Command::new("my-binary");
let vars = vec![
    "DATABASE_URL=postgres://localhost/db".to_string(),
    "LOG_LEVEL=debug".to_string(),
    "ENCODED=base64==".to_string(), // values with '=' are handled correctly
];

apply_env_vars(&mut cmd, &vars);
cmd.spawn().expect("failed to spawn process");
```

## Notes

- Only the **first** `=` is used as the delimiter, so values like `TOKEN=abc=def` are split correctly into `("TOKEN", "abc=def")`.
- Malformed entries (no `=`, or empty key) are silently skipped at runtime but emit a `tracing::warn!` log — useful for debugging misconfigured deployments without crashing the process.
