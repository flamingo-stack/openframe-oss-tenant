Build script that forwards required environment variables into the compiled binary as compile-time constants, enabling version information to be embedded at build time.

## Key Components

- **`main()`** — Entry point that registers version env vars based on enabled Cargo features
- **`forward_required(var)`** — Helper that reads a required env var and re-emits it as a `cargo:rustc-env` directive, making it accessible via `env!()` at compile time. Panics if the variable is not set

## Feature Flags

| Feature | Environment Variable |
|---|---|
| *(always required)* | `OPENFRAME_VERSION` |
| `openframe-chat-version` | `OPENFRAME_CHAT_VERSION` |
| `meshcentral-agent-version` | `MESHCENTRAL_AGENT_VERSION` |
| `fleetmdm-agent-version` | `FLEETMDM_AGENT_VERSION` |
| `tacticalrmm-agent-version` | `TACTICALRMM_AGENT_VERSION` |
| `osquery-version` | `OSQUERY_VERSION` |

## Usage Example

Set the required variables before building:

```bash
export OPENFRAME_VERSION="1.2.3"
export OPENFRAME_CHAT_VERSION="0.9.1"  # if feature enabled
cargo build --features openframe-chat-version
```

Access the embedded values at runtime via `env!()`:

```rust
const VERSION: &str = env!("OPENFRAME_VERSION");
println!("Running OpenFrame v{VERSION}");
```

The `cargo:rerun-if-env-changed` directive ensures incremental builds are invalidated whenever any of these variables change, preventing stale version strings in compiled artifacts.
