Cargo build script that forwards required environment variables into the compiled binary at build time, ensuring version information for OpenFrame and optional components is embedded during compilation.

## Key Components

### `main()`
Entry point that registers version variables based on enabled Cargo features:
- `OPENFRAME_VERSION` — always required
- `OPENFRAME_CHAT_VERSION` — required when feature `openframe-chat-version` is enabled
- `MESHCENTRAL_AGENT_VERSION` — required when feature `meshcentral-agent-version` is enabled
- `FLEETMDM_AGENT_VERSION` — required when feature `fleetmdm-agent-version` is enabled
- `OSQUERY_VERSION` — required when feature `osquery-version` is enabled

### `forward_required(var: &str)`
Reads an environment variable and:
1. Emits `cargo:rerun-if-env-changed` so Cargo re-runs the build script when the variable changes
2. Emits `cargo:rustc-env` to make the variable accessible via `env!()` in source code
3. Panics with a descriptive message if the variable is not set

## Usage Example

```bash
# Set required variables before building
export OPENFRAME_VERSION="1.2.3"
export OPENFRAME_CHAT_VERSION="0.9.1"

cargo build --features openframe-chat-version
```

```rust
// Access embedded versions at runtime in application code
const VERSION: &str = env!("OPENFRAME_VERSION");
const CHAT_VERSION: &str = env!("OPENFRAME_CHAT_VERSION");
```

If `OPENFRAME_VERSION` is not set, the build fails immediately:

```text
error: OPENFRAME_VERSION environment variable must be set at build time
```

## Notes

- All version variables are **hard required** — there are no defaults or fallbacks
- Only feature-gated variables relevant to the build are validated, avoiding unnecessary build failures for unused components
