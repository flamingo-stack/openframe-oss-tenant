Kafka consumer for the `logs.events` topic that routes incoming Debezium CDC messages to `GenericJsonMessageProcessor` based on the `message-type` header.

## Key Components

| Element | Description |
|---|---|
| `LogsEventListener` | Spring `@Component` activated only when `openframe.oss-tenant.kafka.topics.inbound.logs-events.name` is set |
| `listenLogsEvents()` | `@KafkaListener` method consuming from the configured topic; extracts `MessageType` from the Kafka header and delegates to `GenericJsonMessageProcessor` |
| `GenericJsonMessageProcessor` | Injected processor that handles routing/transformation for all event types on the shared topic |

## Configuration

| Property | Purpose |
|---|---|
| `openframe.oss-tenant.kafka.topics.inbound.logs-events.name` | Topic name; also gates bean creation via `@ConditionalOnProperty` |
| `openframe-oss-logs-events-group` | Hardcoded consumer group ID |
| `ossTenantKafkaListenerContainerFactory` | Named container factory for listener configuration |

## Usage Example

```java
// application.yml
openframe:
  oss-tenant:
    kafka:
      topics:
        inbound:
          logs-events:
            name: logs.events
```

```java
// The listener activates automatically when the property is present.
// Incoming messages are dispatched based on the Kafka header:
//   KafkaHeader.MESSAGE_TYPE_HEADER -> MessageType enum value
//
// LogsEventListener -> GenericJsonMessageProcessor.process(message, messageType)
```

> **Error handling:** Exceptions are caught and logged at `ERROR` level without re-throwing, preventing consumer offset commit failures from halting the listener.
