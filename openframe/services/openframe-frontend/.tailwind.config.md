Tailwind CSS configuration for the application, extending the OpenFrame core design system preset with animation support.

## Key Components

- **`openframeCorePreset`** — Imported from `@flamingo-stack/openframe-frontend-core`, provides the full OpenFrame Design System (ODS) color palette and base styles
- **`tailwindcssAnimate`** — Plugin enabling CSS animation utilities
- **`content`** — Scans local `./src` files and the core package's `dist` for class usage
- **`presets`** — Inherits all ODS tokens, colors, and theme configuration from the core package

## Usage Example

No direct usage required — Tailwind picks up this config automatically. To extend or override:

```typescript
import openframeCorePreset from '@flamingo-stack/openframe-frontend-core/tailwind.config.ts';
import type { Config } from 'tailwindcss';
import tailwindcssAnimate from 'tailwindcss-animate';

const config: Config = {
  content: [
    './src/**/*.{js,ts,jsx,tsx,mdx}',
    './node_modules/@flamingo-stack/openframe-frontend-core/dist/**/*.{js,mjs,cjs}',
  ],
  plugins: [tailwindcssAnimate],
  presets: [openframeCorePreset],
  // Add local theme extensions here
  theme: {
    extend: {
      colors: {
        'custom-brand': '#FF5733',
      },
    },
  },
};

export default config;
```

> Any custom `theme.extend` values are merged on top of the ODS preset, so core design tokens remain intact while allowing local overrides.
