Tailwind CSS configuration for the application, extending the OpenFrame core design system preset with animation support.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `config` | `Config` | Default Tailwind configuration object |
| `openframeCorePreset` | Preset | ODS color tokens and base styles from `@flamingo-stack/openframe-frontend-core` |
| `tailwindcssAnimate` | Plugin | Animation utility classes via `tailwindcss-animate` |

## Configuration Details

- **Content paths** — Scans `./src/**/*.{js,ts,jsx,tsx,mdx}` and the compiled core package in `node_modules` to ensure utility classes from the OpenFrame UI kit are never purged.
- **Preset** — Inherits all ODS (OpenFrame Design System) color tokens, typography, and base theme values from the core package.
- **Plugin** — Adds `tailwindcss-animate` for transition/animation utilities used by UI components.

## Usage Example

```typescript
// tailwind.config.ts
import openframeCorePreset from '@flamingo-stack/openframe-frontend-core/tailwind.config.ts';
import type { Config } from 'tailwindcss';
import tailwindcssAnimate from 'tailwindcss-animate';

const config: Config = {
  content: [
    './src/**/*.{js,ts,jsx,tsx,mdx}',
    './node_modules/@flamingo-stack/openframe-frontend-core/dist/**/*.{js,mjs,cjs}',
  ],
  plugins: [tailwindcssAnimate],
  presets: [openframeCorePreset], // Inherits all ODS tokens
};

export default config;
```

> Extending the preset rather than merging manually ensures your app always inherits the latest ODS token updates when the core package is upgraded.
