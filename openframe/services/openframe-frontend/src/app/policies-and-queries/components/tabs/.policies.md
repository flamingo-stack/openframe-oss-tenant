A React component that renders the main policies list page with search, filtering, and table display functionality. Uses the ListPageLayout to provide a consistent UI structure with header actions and search capabilities.

## Key Components

- **Policies Component**: Main page component managing policy list state and user interactions
- **Search & Filtering**: Debounced search with 300ms delay and column-based filtering
- **Table Display**: Uses `Table` component with dynamic columns and row actions
- **Navigation**: Router integration for policy creation and detail views
- **Data Management**: Leverages `usePolicies` hook for data fetching and operations

## Usage Example

```typescript
import { Policies } from './policies'

// Used as a page component in Next.js app router
export default function PoliciesPage() {
  return <Policies />
}

// Or imported in routing configuration
const routes = [
  {
    path: '/policies-and-queries/policies',
    component: Policies
  }
]
```

The component integrates with the OpenFrame design system, using consistent styling classes and UI components. The table supports both search functionality and column filtering, with actions for viewing policy details and creating new policies.
