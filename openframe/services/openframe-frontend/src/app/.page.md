Root page component that handles initial authentication-based routing, redirecting users to the appropriate default path based on their authentication state.

## Key Components

- **`Home`** — Default export; client-side page component that evaluates auth state and redirects accordingly
- **`useAuthStore`** — Zustand store hook providing the `isAuthenticated` boolean/null state
- **`getDefaultRedirectPath`** — Utility that resolves the correct redirect target based on auth status and app mode
- **`AppShellSkeleton`** — Loading placeholder rendered while auth state is being determined (`isAuthenticated === null`)

## Usage Example

```typescript
// This component is automatically rendered at the "/" route.
// No manual usage required — Next.js handles mounting.

// Auth flow:
// 1. isAuthenticated === null  → renders AppShellSkeleton (loading)
// 2. isAuthenticated === true  → router.replace(authenticatedPath)
// 3. isAuthenticated === false → router.replace(unauthenticatedPath)
```

## Behavior Notes

- `force-dynamic` export ensures the page is never statically cached, guaranteeing fresh auth evaluation on every request
- Uses `router.replace` (not `push`) so the root `/` path is not retained in browser history after redirect
- The `useEffect` guard (`isAuthenticated !== null`) prevents premature redirects before the auth store has hydrated
