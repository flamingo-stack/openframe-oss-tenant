Configuration module that provides unified device action button definitions for remote control, shell access, and file management across different UI contexts.

## Key Components

- **`DeviceActionButtonConfig`** - Interface defining button properties including icons, labels, URLs, and disabled states
- **`ShellSubmenuItem`** - Configuration for shell type submenu items (CMD, PowerShell, Bash)
- **`getDeviceActionButtons()`** - Main factory function that returns all action button configurations based on device type
- **`getWindowsShellSubmenu()`** - Creates Windows-specific shell options with CMD and PowerShell
- **`toActionsMenuItem()`** - Converts button config to dropdown menu item format
- **`getShellHref()`** - Generates shell access URLs with appropriate shell type parameters

## Usage Example

```typescript
import { getDeviceActionButtons } from './device-action-config'

// Get all action buttons for a device
const actionButtons = getDeviceActionButtons(device, deviceId, isWindows)

// Access specific button configs
const remoteControlBtn = actionButtons.remoteControl
const remoteShellBtn = actionButtons.remoteShell
const manageFilesBtn = actionButtons.manageFiles

// Convert to dropdown menu format
const menuItem = toActionsMenuItem(
  actionButtons.remoteShell,
  deviceId,
  {
    onShellSelect: (shellType) => navigateToShell(shellType)
  }
)
```

This centralized configuration ensures consistent behavior and styling for device actions across table dropdowns and device detail pages.
