Unified configuration system for device action buttons (Remote Control, Remote Shell, Manage Files) that provides consistent behavior and availability across device table dropdowns and detail pages.

## Key Components

- **DeviceActionButtonConfig** - Interface defining button properties (label, icon, disabled state, href, type)
- **ShellSubmenuItem** - Configuration for shell type options (CMD, PowerShell, Bash)
- **DeviceActionButtons** - Complete set of action buttons with availability status
- **getDeviceActionButtons()** - Main factory function that creates all action configurations
- **getWindowsShellSubmenu()** - Returns Windows-specific shell options (CMD, PowerShell)
- **toActionsMenuItem()** - Converts button configs to ActionsMenu format for dropdowns

## Usage Example

```typescript
import { getDeviceActionButtons } from './device-action-config'

// Get all action buttons for a device
const actionButtons = getDeviceActionButtons(device, deviceId, isWindows)

// Access individual buttons
const { remoteControl, remoteShell, manageFiles } = actionButtons

// Check availability
if (actionButtons.availability.remoteControlEnabled) {
  // Render remote control button
}

// Convert for dropdown menu usage
const menuItem = toActionsMenuItem(
  actionButtons.remoteShell, 
  deviceId,
  {
    onShellSelect: (shellType) => console.log(`Selected ${shellType}`)
  }
)
```

The configuration handles platform-specific differences (Windows gets shell submenu with CMD/PowerShell, Linux gets direct Bash access) and integrates with device availability checks to enable/disable actions appropriately.
