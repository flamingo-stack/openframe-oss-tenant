This file provides unified configuration for device action buttons (Remote Control, Remote Shell, Manage Files) used consistently across table dropdowns and device detail pages in the OpenFrame platform.

## Key Components

**Core Types:**
- `ShellSubmenuItem` - Configuration for shell type submenu items (CMD, PowerShell, Bash)
- `DeviceActionButtonConfig` - Individual action button configuration with icon, label, and routing
- `DeviceActionButtons` - Complete set of all device action configurations

**Primary Functions:**
- `getDeviceActionButtons()` - Main function that returns all action button configurations based on device and OS
- `getWindowsShellSubmenu()` - Returns Windows-specific shell options (CMD, PowerShell)
- `getShellHref()` - Generates shell URLs with appropriate shell type parameters
- `toActionsMenuItem()` - Converts button configs to dropdown menu item format

## Usage Example

```typescript
import { getDeviceActionButtons } from './device-action-config'

// Get all action button configurations for a device
const actionButtons = getDeviceActionButtons(device, deviceId, isWindows)

// Access individual button configs
const remoteControlButton = actionButtons.remoteControl
const shellButton = actionButtons.remoteShell // Has submenu for Windows
const filesButton = actionButtons.manageFiles

// Convert to dropdown menu format
const menuItem = toActionsMenuItem(
  actionButtons.remoteShell,
  deviceId,
  {
    onShellSelect: (shellType) => navigateToShell(shellType)
  }
)
```

The configuration automatically handles OS-specific differences - Windows devices get a submenu with CMD/PowerShell options, while Unix systems default to bash.
