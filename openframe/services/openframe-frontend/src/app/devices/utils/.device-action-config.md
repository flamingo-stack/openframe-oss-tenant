Provides unified configuration for device action buttons (Remote Control, Remote Shell, Manage Files) used across device tables and detail pages, with platform-specific shell options for Windows vs Linux devices.

## Key Components

- **`DeviceActionButtonConfig`** - Interface defining button properties (label, icon, disabled state, href, type)
- **`ShellSubmenuItem`** - Configuration for shell type options (CMD, PowerShell, Bash)
- **`getDeviceActionButtons()`** - Main function returning all action button configurations for a device
- **`getWindowsShellSubmenu()`** - Returns Windows-specific shell options (CMD, PowerShell)
- **`toActionsMenuItem()`** - Converts button config to ActionsMenu format for dropdown usage
- **`getShellHref()`** - Generates shell URLs with proper shell type parameters

## Usage Example

```typescript
import { getDeviceActionButtons } from './device-action-config'

// Get all action buttons for a device
const actionButtons = getDeviceActionButtons(device, deviceId, isWindows)

// Access individual buttons
const remoteControlButton = actionButtons.remoteControl
const remoteShellButton = actionButtons.remoteShell // Has submenu for Windows
const manageFilesButton = actionButtons.manageFiles

// Convert for dropdown menu usage
const menuItem = toActionsMenuItem(
  remoteShellButton,
  deviceId,
  {
    onShellSelect: (shellType) => navigate(`/devices/details/${deviceId}/remote-shell?shellType=${shellType}`)
  }
)

// Check availability
if (actionButtons.availability.remoteControlEnabled) {
  // Show remote control option
}
```
