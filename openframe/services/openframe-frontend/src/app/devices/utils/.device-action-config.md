A centralized configuration system for device action buttons (Remote Control, Remote Shell, Manage Files) that provides consistent button definitions across both table dropdowns and device detail pages.

## Key Components

- **`DeviceActionButtonConfig`** - Interface defining button properties (label, icon, href, disabled state)
- **`ShellSubmenuItem`** - Configuration for shell type options (cmd, powershell, bash)
- **`getDeviceActionButtons()`** - Main function returning all device action configurations based on device type
- **`getWindowsShellSubmenu()`** - Returns Windows-specific shell options with CMD and PowerShell
- **`toActionsMenuItem()`** - Converts button configs to ActionsMenu format for dropdowns
- **`getShellHref()`** - Generates shell URLs with proper shell type parameters

## Usage Example

```typescript
import { getDeviceActionButtons } from './device-action-config'

function DeviceActions({ device, deviceId }: Props) {
  const isWindows = device.platform === 'windows'
  const actionButtons = getDeviceActionButtons(device, deviceId, isWindows)

  // Use buttons in detail page
  const { remoteControl, remoteShell, manageFiles } = actionButtons

  // Or convert for dropdown menu
  const menuItems = [
    toActionsMenuItem(remoteControl, deviceId),
    toActionsMenuItem(remoteShell, deviceId, {
      onShellSelect: (type) => navigate(`/devices/details/${deviceId}/remote-shell?shellType=${type}`)
    })
  ]

  return (
    <div>
      {/* Render buttons or menu items */}
    </div>
  )
}
```
