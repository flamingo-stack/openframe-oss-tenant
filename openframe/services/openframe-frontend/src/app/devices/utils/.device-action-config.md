Configuration module that provides a unified source of truth for device action buttons (Remote Control, Remote Shell, Manage Files) used across device tables and detail pages. It handles platform-specific behavior like Windows shell submenus and provides consistent button states based on device availability.

## Key Components

- **`DeviceActionButtonConfig`** - Interface defining button properties (label, icon, disabled state, href, etc.)
- **`getDeviceActionButtons()`** - Main function that generates all action button configurations for a device
- **`getWindowsShellSubmenu()`** - Creates CMD/PowerShell submenu items for Windows devices
- **`toActionsMenuItem()`** - Converts button configs to ActionsMenu format for dropdown components
- **`getShellHref()`** - Generates shell URLs with appropriate shell type parameters

## Usage Example

```typescript
import { getDeviceActionButtons } from './device-action-config'

// Get all action buttons for a device
const actionButtons = getDeviceActionButtons(device, deviceId, isWindows)

// Use in dropdown menu
const dropdownItems = [
  toActionsMenuItem(actionButtons.remoteControl, deviceId),
  toActionsMenuItem(actionButtons.remoteShell, deviceId, {
    onShellSelect: (shellType) => navigate(`/devices/details/${deviceId}/remote-shell?shellType=${shellType}`)
  }),
  toActionsMenuItem(actionButtons.manageFiles, deviceId)
]

// Use individual buttons
const { remoteControl, remoteShell, manageFiles, availability } = actionButtons
```

The configuration automatically handles Windows vs non-Windows shell behavior - Windows devices get a submenu with CMD/PowerShell options, while other platforms get direct bash access.
