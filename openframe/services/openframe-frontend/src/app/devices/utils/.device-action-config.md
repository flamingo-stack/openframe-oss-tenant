Configuration system that provides unified device action button definitions for remote control, shell access, and file management across different UI contexts.

## Key Components

- **DeviceActionButtonConfig** - Interface defining action button properties (label, icon, href, disabled state)
- **ShellSubmenuItem** - Configuration for Windows shell type options (CMD, PowerShell, Bash)
- **getDeviceActionButtons()** - Main factory function that generates complete action button configurations
- **getWindowsShellSubmenu()** - Helper that returns Windows-specific shell options
- **toActionsMenuItem()** - Converter function that transforms configs into dropdown menu items

## Usage Example

```typescript
import { getDeviceActionButtons, toActionsMenuItem } from './device-action-config'

// Get unified action configurations for a device
const device: Device = { /* device data */ }
const deviceId = 'device-123'
const isWindows = device.os?.includes('Windows') || false

const actionButtons = getDeviceActionButtons(device, deviceId, isWindows)

// Use in detail page
const remoteControlButton = actionButtons.remoteControl
console.log(remoteControlButton.href) // "/devices/details/device-123/remote-desktop"

// Convert for dropdown menu usage
const menuItem = toActionsMenuItem(
  actionButtons.remoteShell,
  deviceId,
  {
    onShellSelect: (type) => console.log(`Selected shell: ${type}`)
  }
)
```

The configuration automatically handles Windows vs non-Windows devices, showing appropriate shell options and managing availability states based on device capabilities.
