This file provides a unified configuration system for device action buttons used throughout the OpenFrame device management interface. It ensures consistent button behavior and appearance across both table dropdowns and device detail pages.

## Key Components

- **`ShellSubmenuItem`** - Interface for shell command options (CMD, PowerShell, Bash)
- **`DeviceActionButtonConfig`** - Main configuration interface for action buttons
- **`DeviceActionButtons`** - Complete collection of all device actions
- **`getDeviceActionButtons()`** - Primary function that generates action configurations
- **`getWindowsShellSubmenu()`** - Creates Windows-specific shell options
- **`toActionsMenuItem()`** - Converts config to dropdown menu format

## Usage Example

```typescript
import { getDeviceActionButtons } from './device-action-config'
import type { Device } from '../types/device.types'

// Get unified action button configurations
function DeviceActions({ device }: { device: Device }) {
  const isWindows = device.operatingSystem === 'Windows'
  const actions = getDeviceActionButtons(device, device.id, isWindows)
  
  // Use in dropdown menu
  const menuItems = [
    toActionsMenuItem(actions.remoteControl, device.id),
    toActionsMenuItem(actions.remoteShell, device.id, {
      onShellSelect: (type) => console.log(`Opening ${type} shell`)
    }),
    toActionsMenuItem(actions.manageFiles, device.id)
  ]
  
  return <ActionsDropdown items={menuItems} />
}
```

The configuration automatically handles platform differences (Windows shows shell submenu with CMD/PowerShell options, Linux/Mac shows direct Bash access) and manages button availability based on device status.
