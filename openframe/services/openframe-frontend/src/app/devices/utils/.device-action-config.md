Provides unified configuration for device action buttons (Remote Control, Remote Shell, Manage Files) used across device table dropdowns and detail pages in the Flamingo OpenFrame MSP platform.

## Key Components

- **`DeviceActionButtonConfig`** - Interface defining button properties (label, icon, href, disabled state)
- **`DeviceActionButtons`** - Complete set of all available device actions with availability status
- **`ShellSubmenuItem`** - Configuration for shell type submenu items (CMD, PowerShell, Bash)
- **`getDeviceActionButtons()`** - Main factory function that generates all action buttons based on device type
- **`getWindowsShellSubmenu()`** - Returns Windows-specific shell options (CMD, PowerShell)
- **`getShellHref()`** - Generates shell URLs with proper shell type parameters
- **`toActionsMenuItem()`** - Converts button configs to ActionsMenu component format

## Usage Example

```typescript
import { getDeviceActionButtons } from './device-action-config'

// Get all action buttons for a device
const actionButtons = getDeviceActionButtons(device, deviceId, isWindows)

// Access individual actions
const remoteControlButton = actionButtons.remoteControl
const shellButton = actionButtons.remoteShell
const filesButton = actionButtons.manageFiles

// Check availability
if (actionButtons.availability.remoteControlEnabled) {
  // Show remote control option
}

// Convert for dropdown menu usage
const menuItem = toActionsMenuItem(shellButton, deviceId, {
  onShellSelect: (shellType) => navigateToShell(shellType)
})
```

The configuration automatically handles platform differences - Windows devices get a shell submenu with CMD/PowerShell options, while other platforms get direct Bash access.
