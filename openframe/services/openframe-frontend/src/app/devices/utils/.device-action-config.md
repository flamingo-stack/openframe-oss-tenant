Device action button configuration module that provides a unified configuration system for device action buttons used across both table dropdown menus and device detail pages in the OpenFrame platform.

## Key Components

- **`DeviceActionButtonConfig`** - Interface defining action button properties including ID, label, icon, disabled state, and navigation href
- **`ShellSubmenuItem`** - Configuration for shell type submenu items (CMD, PowerShell, Bash)
- **`DeviceActionButtons`** - Complete set of device actions including remote control, shell, and file management
- **`getDeviceActionButtons()`** - Main function that generates action configurations based on device type and availability
- **`getWindowsShellSubmenu()`** - Returns Windows-specific shell options (CMD and PowerShell)
- **`toActionsMenuItem()`** - Converter function that transforms configurations for dropdown menu usage

## Usage Example

```typescript
import { getDeviceActionButtons } from './device-action-config'

// Get action configurations for a device
const device = { /* device object */ }
const deviceId = "device-123"
const isWindows = device.os === 'windows'

const actionButtons = getDeviceActionButtons(device, deviceId, isWindows)

// Use individual actions
const remoteControlButton = actionButtons.remoteControl
const shellButton = actionButtons.remoteShell // Has submenu for Windows

// Convert for dropdown usage
const menuItem = toActionsMenuItem(shellButton, deviceId, {
  onShellSelect: (type) => console.log(`Selected ${type} shell`)
})
```
