This file provides a unified configuration system for device action buttons (Remote Control, Remote Shell, Manage Files) used consistently across both table dropdowns and device detail pages in the Flamingo platform.

## Key Components

- **`ShellSubmenuItem`** - Interface defining shell type options (CMD, PowerShell, Bash)
- **`DeviceActionButtonConfig`** - Main configuration interface for action buttons with support for both simple buttons and submenu types
- **`DeviceActionButtons`** - Complete set of all device action configurations plus availability status
- **`getDeviceActionButtons()`** - Primary function that generates platform-specific button configurations based on device OS
- **`getWindowsShellSubmenu()`** - Returns Windows-specific shell options (CMD, PowerShell)
- **`getShellHref()`** - Generates shell URLs with appropriate shell type parameters
- **`toActionsMenuItem()`** - Converter function that transforms configurations into ActionsMenu-compatible format

## Usage Example

```typescript
import { getDeviceActionButtons, toActionsMenuItem } from './device-action-config'

// Get all action configurations for a device
const device = { /* Device object */ }
const deviceId = "device-123"
const isWindows = device.operatingSystem === 'Windows'

const actionButtons = getDeviceActionButtons(device, deviceId, isWindows)

// Use in a dropdown menu
const menuItems = [
  toActionsMenuItem(actionButtons.remoteControl, deviceId),
  toActionsMenuItem(actionButtons.remoteShell, deviceId, {
    onShellSelect: (type) => console.log(`Selected ${type} shell`)
  }),
  toActionsMenuItem(actionButtons.manageFiles, deviceId)
]

// Access individual configurations
const { remoteControl, remoteShell, manageFiles } = actionButtons
console.log('Remote control enabled:', !remoteControl.disabled)
```

The configuration automatically handles Windows submenu generation, availability checks, and provides consistent routing across the application.
