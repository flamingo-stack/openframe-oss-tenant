Provides unified configuration and utilities for device action buttons used across table dropdowns and detail pages, ensuring consistent behavior for remote control, shell access, and file management features.

## Key Components

- **`DeviceActionButtonConfig`** - Interface defining button properties (id, label, icon, disabled state, href, type)
- **`ShellSubmenuItem`** - Configuration for Windows shell submenu items (CMD, PowerShell, Bash)
- **`getDeviceActionButtons()`** - Main function returning complete button configurations based on device and OS
- **`getWindowsShellSubmenu()`** - Returns Windows-specific shell options with appropriate icons
- **`toActionsMenuItem()`** - Converts button config to ActionsMenu format for dropdown components
- **`getShellHref()`** - Generates shell URLs with proper shell type parameters

## Usage Example

```typescript
import { getDeviceActionButtons, toActionsMenuItem } from './device-action-config'

// Get all action buttons for a device
const actionButtons = getDeviceActionButtons(device, deviceId, isWindows)

// Use in detail page
const remoteControlButton = actionButtons.remoteControl

// Convert for dropdown menu
const menuItem = toActionsMenuItem(
  actionButtons.remoteShell,
  deviceId,
  {
    onShellSelect: (shellType) => {
      // Handle shell selection
      navigate(`/devices/details/${deviceId}/remote-shell?shellType=${shellType}`)
    }
  }
)

// Check availability
if (actionButtons.availability.remoteControlEnabled) {
  // Show remote control option
}
```
