Unified configuration system for device action buttons used across OpenFrame's device management interface, providing consistent behavior between table dropdowns and detail pages.

## Key Components

- **`DeviceActionButtonConfig`** - Interface defining button properties (label, icon, href, disabled state)
- **`ShellSubmenuItem`** - Interface for shell type submenu items (CMD, PowerShell, Bash)
- **`getDeviceActionButtons()`** - Main function returning configured buttons for a device
- **`getWindowsShellSubmenu()`** - Returns Windows-specific shell options (CMD, PowerShell)
- **`getShellHref()`** - Generates shell URLs with shell type parameters
- **`toActionsMenuItem()`** - Converts button configs to ActionsMenu format for dropdowns

## Usage Example

```typescript
import { getDeviceActionButtons } from './device-action-config'

function DeviceActionsComponent({ device }: { device: Device }) {
  const isWindows = device.os?.toLowerCase().includes('windows')
  const actions = getDeviceActionButtons(device, device.id, isWindows)
  
  return (
    <div>
      <a 
        href={actions.remoteControl.href}
        className={actions.remoteControl.disabled ? 'disabled' : ''}
      >
        {actions.remoteControl.icon}
        {actions.remoteControl.label}
      </a>
      
      {/* Windows shows submenu, Linux shows direct bash link */}
      {actions.remoteShell.type === 'submenu' ? (
        <SubmenuComponent items={actions.remoteShell.submenu} />
      ) : (
        <a href={actions.remoteShell.href}>Shell Access</a>
      )}
    </div>
  )
}
```
