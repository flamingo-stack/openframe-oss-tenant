Configuration module that provides a unified interface for device action buttons (remote control, shell, file management) used across the OpenFrame MSP platform's device management interface.

## Key Components

- **DeviceActionButtonConfig**: Interface defining button properties including icons, URLs, and disabled states
- **ShellSubmenuItem**: Configuration for Windows shell type selection (CMD, PowerShell, Bash)
- **getDeviceActionButtons()**: Main function returning standardized button configurations based on device type
- **getWindowsShellSubmenu()**: Helper for Windows-specific shell options
- **toActionsMenuItem()**: Converter function for dropdown menu integration
- **getShellHref()**: URL generator for shell session routing

## Usage Example

```typescript
import { getDeviceActionButtons } from './device-action-config'

// Get action buttons for a Windows device
const device = { id: '123', platform: 'windows' }
const isWindows = device.platform === 'windows'
const actionButtons = getDeviceActionButtons(device, '123', isWindows)

// Access individual buttons
const { remoteControl, remoteShell, manageFiles, availability } = actionButtons

// Use remote control button
if (!remoteControl.disabled) {
  // Navigate to: /devices/details/123/remote-desktop
  window.location.href = remoteControl.href
}

// Windows devices get shell submenu with CMD/PowerShell options
if (remoteShell.type === 'submenu' && remoteShell.submenu) {
  remoteShell.submenu.forEach(shell => {
    console.log(`${shell.label}: ${getShellHref('123', shell.id)}`)
  })
}
```

This configuration ensures consistent device actions across table dropdowns and detail pages while handling platform-specific differences like Windows shell type selection.
