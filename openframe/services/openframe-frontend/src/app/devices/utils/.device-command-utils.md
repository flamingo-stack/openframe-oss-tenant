Provides unified utilities for generating OpenFrame device installation and uninstallation commands across different operating systems, with automatic binary URL resolution and platform-specific command formatting.

## Key Components

- **Binary URL Builders**: `buildBinaryUrl()`, `getMacBinaryUrl()`, `getWindowsBinaryUrl()` - Generate GitHub release download URLs for different platforms
- **Command Builders**: `buildInstallCommand()`, `buildUninstallCommand()` - Generate platform-specific installation/uninstallation commands
- **Platform Normalization**: `normalizeDevicePlatform()` - Convert various OS string formats to standardized platform IDs
- **Configuration Interfaces**: `InstallCommandOptions`, `UninstallCommandOptions` - Type-safe command configuration

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Generate installation command for Windows
const installOptions = {
  platform: 'windows' as OSPlatformId,
  serverUrl: 'https://api.openframe.ai',
  initialKey: 'key_abc123',
  orgId: 'org_xyz789',
  releaseVersion: 'v1.2.3',
  additionalArgs: ['--verbose']
}

const windowsCommand = buildInstallCommand(installOptions)
// Returns PowerShell command that downloads and installs OpenFrame client

// Normalize platform from device info
const platform = normalizeDevicePlatform('Win32', 'windows', 'Windows 11')
// Returns 'windows'

// Generate macOS uninstall command
const uninstallCommand = buildUninstallCommand({
  platform: 'darwin',
  releaseVersion: 'latest'
})
// Returns bash command for macOS uninstallation
```

The utility handles platform-specific differences like PowerShell vs bash syntax, binary naming conventions, and admin privilege requirements automatically.
