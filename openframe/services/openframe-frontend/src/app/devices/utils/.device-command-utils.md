Unified utilities for generating cross-platform device installation and uninstallation commands for the OpenFrame client. Handles binary URL construction, platform-specific command generation, and OS type normalization.

## Key Components

- **Binary URL Functions**: `buildBinaryUrl()`, `getMacBinaryUrl()`, `getWindowsBinaryUrl()` - Generate GitHub release download URLs
- **Command Builders**: `buildInstallCommand()`, `buildUninstallCommand()` - Create platform-specific shell commands
- **Platform Utilities**: `normalizeDevicePlatform()` - Normalize OS identifiers to standardized platform IDs
- **Configuration Constants**: Release base URL and binary asset names for macOS and Windows

## Usage Example

```typescript
import { 
  buildInstallCommand, 
  buildUninstallCommand, 
  normalizeDevicePlatform 
} from './device-command-utils'

// Generate installation command
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.openframe.ai',
  initialKey: 'abc123',
  orgId: 'org-456',
  releaseVersion: 'v1.2.3',
  additionalArgs: ['--debug', '--auto-start']
})

// Generate uninstallation command
const uninstallCmd = buildUninstallCommand({
  platform: 'darwin',
  releaseVersion: 'v1.2.3'
})

// Normalize platform identifier
const platform = normalizeDevicePlatform('macOS') // Returns 'darwin'
```

The utilities automatically handle platform-specific differences like PowerShell vs bash syntax, file extensions, and execution permissions. Commands include binary download, extraction, and execution with proper error handling and cleanup.
