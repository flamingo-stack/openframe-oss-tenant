Utilities for generating cross-platform device installation and uninstallation commands for the OpenFrame client binary.

## Key Components

- **Binary URL Builders**: `buildBinaryUrl()`, `getMacBinaryUrl()`, `getWindowsBinaryUrl()` - Generate download URLs for OpenFrame client binaries
- **Command Builders**: `buildInstallCommand()`, `buildUninstallCommand()` - Create platform-specific shell commands for device management
- **Platform Normalizer**: `normalizeDevicePlatform()` - Standardizes OS identifiers to consistent platform IDs
- **Type Definitions**: `InstallCommandOptions`, `UninstallCommandOptions` - Configuration interfaces for command generation

## Usage Example

```typescript
import { 
  buildInstallCommand, 
  buildUninstallCommand, 
  normalizeDevicePlatform 
} from './device-command-utils'

// Generate installation command
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.example.com',
  initialKey: 'abc123',
  orgId: 'org_456',
  releaseVersion: 'v1.2.3',
  additionalArgs: ['--debug']
})

// Generate uninstallation command
const uninstallCmd = buildUninstallCommand({
  platform: 'darwin',
  releaseVersion: 'v1.2.3'
})

// Normalize platform identifier
const platform = normalizeDevicePlatform('macOS') // Returns 'darwin'
```

The utility automatically handles platform-specific binary downloads, command syntax differences (PowerShell vs bash), and provides fallback behavior for unknown platforms (defaults to macOS/darwin).
