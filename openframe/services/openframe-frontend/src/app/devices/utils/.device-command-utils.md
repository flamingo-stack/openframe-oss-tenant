Utility functions for generating cross-platform device management commands in the OpenFrame ecosystem, providing unified logic for installing and uninstalling the OpenFrame client on Windows and macOS systems.

## Key Components

- **Binary URL Builders**: `buildBinaryUrl()`, `getMacBinaryUrl()`, `getWindowsBinaryUrl()` - Generate download URLs for OpenFrame client binaries
- **Command Generators**: `buildInstallCommand()`, `buildUninstallCommand()` - Create platform-specific shell commands for device management
- **Platform Normalizer**: `normalizeDevicePlatform()` - Standardizes various OS string formats to consistent platform IDs
- **Configuration Interfaces**: `InstallCommandOptions`, `UninstallCommandOptions` - Type-safe options for command generation

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Generate installation command for Windows
const installCommand = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.flamingo.run',
  initialKey: 'abc123',
  orgId: 'org_456',
  releaseVersion: 'v1.2.3',
  additionalArgs: ['--debug', '--force']
})

// Normalize device platform from various formats
const platform = normalizeDevicePlatform('Win32') // Returns 'windows'
const macPlatform = normalizeDevicePlatform('Darwin') // Returns 'darwin'

// Generate uninstall command
const uninstallCommand = buildUninstallCommand({
  platform: 'darwin',
  releaseVersion: 'latest'
})
```

The utilities handle platform-specific command construction, including PowerShell for Windows and bash for macOS, with proper binary downloads from GitHub releases.
