Utility functions for generating platform-specific OpenFrame client installation and uninstallation commands across macOS and Windows platforms.

## Key Components

- **`buildBinaryUrl()`** - Constructs download URLs for OpenFrame client binaries
- **`getMacBinaryUrl()` / `getWindowsBinaryUrl()`** - Platform-specific binary URL generators
- **`buildInstallCommand()`** - Creates installation commands with server configuration
- **`buildUninstallCommand()`** - Generates uninstallation commands for client removal
- **`normalizeDevicePlatform()`** - Standardizes OS detection from various device fields

## Usage Example

```typescript
import { 
  buildInstallCommand, 
  buildUninstallCommand, 
  normalizeDevicePlatform 
} from './device-command-utils'

// Generate installation command
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.example.com',
  initialKey: 'abc123',
  orgId: 'org456',
  releaseVersion: 'v1.0.0',
  additionalArgs: ['--debug']
})

// Generate uninstallation command
const uninstallCmd = buildUninstallCommand({
  platform: 'darwin',
  releaseVersion: 'v1.0.0'
})

// Normalize OS detection
const platform = normalizeDevicePlatform('Win32') // Returns 'windows'
```

The utility handles PowerShell commands for Windows and bash commands for macOS, automatically downloading and executing the appropriate OpenFrame client binary with proper permissions and error handling.
