This utility module provides cross-platform command generation for installing and uninstalling the OpenFrame client on managed devices. It handles binary downloads from GitHub releases and constructs platform-specific shell commands for Windows PowerShell and macOS/Linux bash environments.

## Key Components

- **buildBinaryUrl()** - Constructs GitHub release download URLs for client binaries
- **getMacBinaryUrl() / getWindowsBinaryUrl()** - Platform-specific binary URL builders
- **buildInstallCommand()** - Generates installation commands with server connection parameters
- **buildUninstallCommand()** - Creates uninstallation commands for client removal
- **normalizeDevicePlatform()** - Standardizes OS detection from various device fields

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Generate installation command for a Windows device
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.flamingo.run',
  initialKey: 'ak_1234567890abcdef',
  orgId: 'org_flamingo_msp',
  releaseVersion: 'v1.2.3',
  additionalArgs: ['--debug']
})

// Normalize platform from device info
const platform = normalizeDevicePlatform('Win32', undefined, 'Windows 11')
// Returns: 'windows'

// Get binary URL
const binaryUrl = getMacBinaryUrl('v1.2.3')
// Returns: 'https://github.com/flamingo-stack/openframe-oss-tenant/releases/download/v1.2.3/openframe-client_macos.tar.gz'
```

The generated commands handle binary download, extraction, and execution with elevated privileges as required by each platform.
