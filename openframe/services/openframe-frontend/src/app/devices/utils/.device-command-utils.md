This utility module provides unified logic for building device installation and uninstallation commands for the OpenFrame client across different operating systems. It handles binary URL construction, platform-specific command generation, and OS type normalization.

## Key Components

- **Binary URL builders**: `buildBinaryUrl()`, `getMacBinaryUrl()`, `getWindowsBinaryUrl()` - Generate download URLs for OpenFrame client binaries
- **Command builders**: `buildInstallCommand()`, `buildUninstallCommand()` - Create platform-specific shell commands for client installation/removal  
- **Platform normalizer**: `normalizeDevicePlatform()` - Standardizes various OS identifiers to consistent platform IDs
- **Configuration interfaces**: `InstallCommandOptions`, `UninstallCommandOptions` - Type-safe options for command generation

## Usage Example

```typescript
import { 
  buildInstallCommand, 
  buildUninstallCommand, 
  normalizeDevicePlatform 
} from './device-command-utils'

// Generate installation command for Windows
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.openframe.ai',
  initialKey: 'key_abc123',
  orgId: 'org_xyz789',
  releaseVersion: 'v1.2.3',
  additionalArgs: ['--debug', '--verbose']
})

// Generate uninstall command for macOS
const uninstallCmd = buildUninstallCommand({
  platform: 'darwin',
  releaseVersion: 'latest'
})

// Normalize OS identifier
const platform = normalizeDevicePlatform('macOS') // Returns 'darwin'
```

The utility automatically handles platform differences, with Windows commands using PowerShell syntax and macOS/Linux using bash commands. Binary downloads are fetched from the OpenFrame OSS tenant GitHub releases.
