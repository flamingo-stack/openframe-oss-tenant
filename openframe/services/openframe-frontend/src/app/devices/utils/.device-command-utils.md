Provides unified utilities for building cross-platform device installation and uninstallation commands for the OpenFrame client, with platform-specific binary downloads and command generation.

## Key Components

**Binary URL Functions:**
- `buildBinaryUrl()` - Constructs GitHub release download URLs
- `getMacBinaryUrl()` - Gets macOS binary download URL  
- `getWindowsBinaryUrl()` - Gets Windows binary download URL

**Command Builders:**
- `buildInstallCommand()` - Generates platform-specific installation commands
- `buildUninstallCommand()` - Generates platform-specific uninstallation commands
- `normalizeDevicePlatform()` - Normalizes OS identifiers to standard platform IDs

**Types:**
- `InstallCommandOptions` - Configuration for installation commands
- `UninstallCommandOptions` - Configuration for uninstallation commands

## Usage Example

```typescript
import { 
  buildInstallCommand, 
  buildUninstallCommand, 
  normalizeDevicePlatform 
} from './device-command-utils'

// Generate installation command for Windows
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.example.com',
  initialKey: 'key_123',
  orgId: 'org_456', 
  releaseVersion: 'v1.0.0',
  additionalArgs: ['--silent']
})

// Generate uninstall command for macOS
const uninstallCmd = buildUninstallCommand({
  platform: 'darwin',
  releaseVersion: 'v1.0.0'
})

// Normalize platform identifier
const platform = normalizeDevicePlatform('macOS') // Returns 'darwin'
```

The utility handles platform-specific differences like PowerShell commands for Windows and bash commands for macOS/Linux, automatically downloading the appropriate binary and executing installation/uninstallation with proper permissions.
