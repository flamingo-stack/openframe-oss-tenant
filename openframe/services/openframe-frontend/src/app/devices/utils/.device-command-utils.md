Utility functions for generating OpenFrame device client installation and uninstallation commands across different operating systems. This module handles binary URL construction and platform-specific command generation for macOS and Windows.

## Key Components

- **`buildBinaryUrl()`** - Constructs GitHub release download URLs for OpenFrame client binaries
- **`getMacBinaryUrl()` / `getWindowsBinaryUrl()`** - Platform-specific binary URL helpers
- **`buildInstallCommand()`** - Generates complete installation commands with server configuration
- **`buildUninstallCommand()`** - Generates uninstallation commands for removing the client
- **`normalizeDevicePlatform()`** - Normalizes various OS identifiers to standardized platform IDs

## Usage Example

```typescript
import { 
  buildInstallCommand, 
  buildUninstallCommand, 
  normalizeDevicePlatform 
} from './device-command-utils'

// Generate macOS installation command
const installCmd = buildInstallCommand({
  platform: 'darwin',
  serverUrl: 'https://api.openframe.ai',
  initialKey: 'key_123',
  orgId: 'org_456',
  releaseVersion: 'v1.2.3',
  additionalArgs: ['--debug']
})

// Generate Windows uninstall command
const uninstallCmd = buildUninstallCommand({
  platform: 'windows',
  releaseVersion: 'v1.2.3'
})

// Normalize platform from device data
const platform = normalizeDevicePlatform('macOS Ventura')
// Returns: 'darwin'
```

The generated commands handle binary downloading, extraction, and execution with proper permissions and error handling for each platform.
