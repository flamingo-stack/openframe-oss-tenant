Utility functions for generating platform-specific OpenFrame client installation and uninstallation commands. This module handles binary URL construction, command generation, and OS platform normalization for device management operations.

## Key Components

### URL Builders
- `buildBinaryUrl()` - Constructs GitHub release download URLs
- `getMacBinaryUrl()` - macOS binary download URL
- `getWindowsBinaryUrl()` - Windows binary download URL

### Command Generators
- `buildInstallCommand()` - Generates installation commands with server configuration
- `buildUninstallCommand()` - Generates uninstallation commands for cleanup
- `normalizeDevicePlatform()` - Standardizes OS platform identification

### Type Definitions
- `InstallCommandOptions` - Configuration for installation commands
- `UninstallCommandOptions` - Configuration for uninstallation commands

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Generate installation command
const installCmd = buildInstallCommand({
  platform: 'darwin',
  serverUrl: 'https://api.openframe.ai',
  initialKey: 'abc123',
  orgId: 'org-456',
  releaseVersion: 'v1.2.3',
  additionalArgs: ['--silent']
})

// Normalize platform from device info
const platform = normalizeDevicePlatform('macOS')
// Returns: 'darwin'

// The generated commands handle binary download, extraction, and execution
// with proper permissions and error handling for each platform
```

The utility automatically generates PowerShell commands for Windows and bash commands for macOS/Linux, handling binary downloads from GitHub releases and proper sudo/admin execution.
