Utility functions for generating cross-platform device installation and uninstallation commands for the OpenFrame client binary.

## Key Components

### Binary URL Functions
- `buildBinaryUrl(version, assetName)` - Constructs GitHub release download URLs
- `getMacBinaryUrl(version)` - Returns macOS binary download URL
- `getWindowsBinaryUrl(version)` - Returns Windows binary download URL

### Command Builders
- `buildInstallCommand(options)` - Generates platform-specific installation commands
- `buildUninstallCommand(options)` - Generates platform-specific uninstallation commands
- `normalizeDevicePlatform(platform, osType, operatingSystem)` - Standardizes OS identifiers

### Interfaces
- `InstallCommandOptions` - Configuration for device installation
- `UninstallCommandOptions` - Configuration for device uninstallation

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Generate installation command
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.example.com',
  initialKey: 'abc123',
  orgId: 'org-456',
  releaseVersion: 'v1.2.3',
  additionalArgs: ['--debug']
})

// Normalize platform from device info
const platform = normalizeDevicePlatform('Windows 10', undefined, undefined)
// Returns: 'windows'
```

The utility handles platform-specific differences in command syntax, with Windows using PowerShell commands and macOS/Linux using bash commands. All commands download the appropriate binary, extract it, and execute with the required parameters.
