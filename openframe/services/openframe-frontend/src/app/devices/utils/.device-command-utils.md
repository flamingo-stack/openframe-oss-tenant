This utility module provides cross-platform command generation for OpenFrame client installation and uninstallation on macOS and Windows devices.

## Key Components

**Core Functions:**
- `buildBinaryUrl()` - Constructs GitHub release URLs for binary downloads
- `getMacBinaryUrl()` / `getWindowsBinaryUrl()` - Platform-specific binary URL generators
- `buildInstallCommand()` - Generates complete installation commands with cleanup and authentication
- `buildUninstallCommand()` - Creates uninstallation commands for device cleanup
- `normalizeDevicePlatform()` - Standardizes OS detection across different platform field formats

**Interfaces:**
- `InstallCommandOptions` - Configuration for installation commands
- `UninstallCommandOptions` - Configuration for uninstallation commands

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Generate installation command
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.flamingo.run',
  initialKey: 'ak_1a2b3c4d5e6f7890.sk_live_abcdefghijklmnopqrstuvwxyz123456',
  orgId: 'org_12345',
  releaseVersion: 'v1.2.3',
  additionalArgs: ['--verbose']
})

// Normalize device platform from various sources
const platform = normalizeDevicePlatform('Win32') // Returns 'windows'
const macPlatform = normalizeDevicePlatform(undefined, 'Darwin') // Returns 'darwin'
```

The module handles platform-specific binary downloads from GitHub releases and generates PowerShell commands for Windows and bash commands for macOS, including proper cleanup of temporary files and elevated permissions handling.
