Utility module for generating platform-specific OpenFrame device installation and uninstallation commands. Provides unified logic for building binary URLs and shell commands across Windows and macOS platforms.

## Key Components

- **Binary URL builders**: `buildBinaryUrl()`, `getMacBinaryUrl()`, `getWindowsBinaryUrl()` - Generate GitHub release download URLs
- **Command generators**: `buildInstallCommand()`, `buildUninstallCommand()` - Create platform-specific shell commands for device management
- **Platform normalization**: `normalizeDevicePlatform()` - Standardize OS identifiers to consistent platform IDs
- **Configuration interfaces**: `InstallCommandOptions`, `UninstallCommandOptions` - Type-safe command options

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Generate installation command
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.flamingo.run',
  initialKey: 'key123',
  orgId: 'org456',
  releaseVersion: 'v1.0.0',
  additionalArgs: ['--debug']
})

// Normalize device platform
const platform = normalizeDevicePlatform('Win32') // Returns 'windows'

// Get binary URL
const macUrl = getMacBinaryUrl('v1.0.0')
// Returns: https://github.com/flamingo-stack/openframe-oss-tenant/releases/download/v1.0.0/openframe-client_macos.tar.gz
```

The utility handles cross-platform differences in command syntax, binary extraction, and privilege escalation requirements for seamless OpenFrame client deployment.
