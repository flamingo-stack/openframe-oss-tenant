Utilities for building cross-platform OpenFrame client installation and uninstallation commands, with support for macOS and Windows binary distribution.

## Key Components

- **`buildBinaryUrl(version, assetName)`** - Constructs download URLs for release binaries
- **`getMacBinaryUrl(version)` / `getWindowsBinaryUrl(version)`** - Platform-specific binary URL builders
- **`buildInstallCommand(options)`** - Generates platform-specific installation commands with server configuration
- **`buildUninstallCommand(options)`** - Creates platform-specific uninstallation commands
- **`normalizeDevicePlatform(platform, osType, operatingSystem)`** - Standardizes OS detection from various device fields

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Build installation command for a Windows device
const installOptions = {
  platform: 'windows' as const,
  serverUrl: 'https://api.example.com',
  initialKey: 'ak_1234567890',
  orgId: 'org_abc123',
  releaseVersion: 'v1.2.3',
  additionalArgs: ['--verbose', '--daemon']
}

const windowsCommand = buildInstallCommand(installOptions)
// Returns PowerShell command with download, extract, and install steps

// Normalize platform detection
const detectedPlatform = normalizeDevicePlatform('Win32', 'Windows 11', undefined)
// Returns: 'windows'
```

The utility handles cross-platform binary distribution from GitHub releases, generating complete shell/PowerShell commands that download, extract, and execute the OpenFrame client with proper permissions and arguments.
