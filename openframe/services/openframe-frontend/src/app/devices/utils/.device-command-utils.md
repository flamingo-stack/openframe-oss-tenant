Provides unified utilities for generating platform-specific device installation and uninstallation commands for the OpenFrame client across macOS and Windows systems.

## Key Components

- **Binary URL Builders**: `buildBinaryUrl()`, `getMacBinaryUrl()`, `getWindowsBinaryUrl()` - Generate download URLs for OpenFrame client binaries
- **Command Builders**: `buildInstallCommand()`, `buildUninstallCommand()` - Create platform-specific shell commands for device management
- **Platform Normalization**: `normalizeDevicePlatform()` - Standardizes various OS identifiers to consistent platform IDs
- **Configuration Interfaces**: `InstallCommandOptions`, `UninstallCommandOptions` - Type-safe option structures for command generation

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Generate installation command for Windows device
const installOptions = {
  platform: 'windows' as const,
  serverUrl: 'https://api.openframe.ai',
  initialKey: 'abc123',
  orgId: 'org-456',
  releaseVersion: 'v1.2.3',
  additionalArgs: ['--debug']
}

const windowsCommand = buildInstallCommand(installOptions)
// Returns PowerShell script for downloading and installing OpenFrame client

// Normalize device platform from various sources
const platform = normalizeDevicePlatform(undefined, 'Win32', undefined)
// Returns: 'windows'

// Generate uninstall command
const uninstallCommand = buildUninstallCommand({
  platform: 'darwin',
  releaseVersion: 'latest'
})
// Returns bash script for macOS uninstallation
```

The utilities handle cross-platform differences in command syntax, file handling, and privilege escalation (sudo/RunAs) automatically based on the target operating system.
