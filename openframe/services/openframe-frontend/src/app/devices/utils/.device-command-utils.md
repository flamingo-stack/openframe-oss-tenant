Utility functions for generating cross-platform device installation and uninstallation commands for the OpenFrame client. Provides unified command building logic for macOS and Windows platforms with automatic binary download and execution.

## Key Components

- **buildBinaryUrl()** - Constructs GitHub release URLs for OpenFrame client binaries
- **getMacBinaryUrl() / getWindowsBinaryUrl()** - Platform-specific binary URL generators
- **buildInstallCommand()** - Creates complete installation command strings with server configuration
- **buildUninstallCommand()** - Generates uninstallation command strings
- **normalizeDevicePlatform()** - Converts various OS identifiers to standardized platform IDs

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Generate installation command for Windows
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.openframe.ai',
  initialKey: 'ak_1234567890',
  orgId: 'org_abcdef',
  releaseVersion: 'v1.0.0',
  additionalArgs: ['--debug']
})

// Normalize device platform from various sources
const platform = normalizeDevicePlatform('Win32') // Returns 'windows'

// Get binary download URL
const macUrl = getMacBinaryUrl('v1.0.0')
// Returns: https://github.com/flamingo-stack/openframe-oss-tenant/releases/download/v1.0.0/openframe-client_macos.tar.gz
```

The utility handles platform-specific command generation, including PowerShell commands for Windows with elevated privileges and shell commands for macOS with sudo access.
