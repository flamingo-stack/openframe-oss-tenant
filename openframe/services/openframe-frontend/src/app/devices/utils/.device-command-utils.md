Utility functions for generating cross-platform device installation and uninstallation commands for the OpenFrame client. Provides standardized command generation for macOS and Windows deployment scenarios.

## Key Components

- **Binary URL Builders**: `buildBinaryUrl()`, `getMacBinaryUrl()`, `getWindowsBinaryUrl()` - Generate download URLs for client binaries from GitHub releases
- **Command Generators**: `buildInstallCommand()`, `buildUninstallCommand()` - Create platform-specific shell commands for client deployment
- **Platform Normalization**: `normalizeDevicePlatform()` - Standardize OS detection from various device field formats
- **Configuration Interfaces**: `InstallCommandOptions`, `UninstallCommandOptions` - Type-safe options for command generation

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Generate installation command
const installCmd = buildInstallCommand({
  platform: 'darwin',
  serverUrl: 'https://api.openframe.ai',
  initialKey: 'key_abc123',
  orgId: 'org_456',
  releaseVersion: 'v1.2.3',
  additionalArgs: ['--debug', '--timeout=30']
})

// Normalize platform detection
const platform = normalizeDevicePlatform('macOS 14.0') // Returns 'darwin'

// Generate uninstall command
const uninstallCmd = buildUninstallCommand({
  platform: 'windows',
  releaseVersion: 'latest'
})
```

The utility handles platform-specific command formatting, binary downloads from GitHub releases, and provides consistent OS platform identification across different device data sources.
