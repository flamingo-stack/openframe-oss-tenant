Utility functions for generating cross-platform device installation and uninstallation commands for the OpenFrame client, with support for macOS and Windows binary distribution.

## Key Components

- **buildBinaryUrl()** - Constructs download URLs for OpenFrame client binaries
- **getMacBinaryUrl()** / **getWindowsBinaryUrl()** - Platform-specific binary URL helpers
- **buildInstallCommand()** - Generates complete installation commands with parameters
- **buildUninstallCommand()** - Creates uninstallation commands for device cleanup
- **normalizeDevicePlatform()** - Standardizes OS detection from various device fields

## Usage Example

```typescript
import { 
  buildInstallCommand, 
  buildUninstallCommand, 
  normalizeDevicePlatform 
} from './device-command-utils'

// Generate installation command
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.flamingo.run',
  initialKey: 'key_123456789',
  orgId: 'org_abc123',
  releaseVersion: 'v1.2.3',
  additionalArgs: ['--verbose']
})

// Generate uninstallation command
const uninstallCmd = buildUninstallCommand({
  platform: 'darwin',
  releaseVersion: 'latest'
})

// Normalize platform detection
const platform = normalizeDevicePlatform('macOS') // Returns 'darwin'
```

The utility automatically handles platform-specific command syntax, binary downloads from GitHub releases, and parameter formatting for the OpenFrame client installer.
