Utility functions for building cross-platform device installation and uninstallation commands for the OpenFrame client. Handles binary downloads, command generation, and platform normalization for macOS and Windows systems.

## Key Components

- **Binary URL Builders**: `buildBinaryUrl()`, `getMacBinaryUrl()`, `getWindowsBinaryUrl()` - Generate download URLs for OpenFrame client binaries
- **Command Builders**: `buildInstallCommand()`, `buildUninstallCommand()` - Generate platform-specific shell commands for client management
- **Platform Utilities**: `normalizeDevicePlatform()` - Normalize various OS identifiers to standard platform IDs
- **Type Interfaces**: `InstallCommandOptions`, `UninstallCommandOptions` - Configuration options for command generation

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Build installation command for Windows
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.openframe.ai',
  initialKey: 'abc123',
  orgId: 'org_456',
  releaseVersion: 'v1.2.0',
  additionalArgs: ['--debug', '--force']
})

// Normalize device platform from various sources
const platform = normalizeDevicePlatform('Win64') // returns 'windows'
const macPlatform = normalizeDevicePlatform('darwin') // returns 'darwin'

// Get binary download URL
import { getMacBinaryUrl } from './device-command-utils'
const downloadUrl = getMacBinaryUrl('v1.2.0')
// Returns: https://github.com/flamingo-stack/openframe-oss-tenant/releases/download/v1.2.0/openframe-client_macos.tar.gz
```
