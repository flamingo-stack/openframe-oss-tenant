Utility functions for generating platform-specific OpenFrame device client installation and uninstallation commands, with support for macOS and Windows binary downloads.

## Key Components

- **buildBinaryUrl()** - Constructs download URLs for release assets from GitHub releases
- **getMacBinaryUrl() / getWindowsBinaryUrl()** - Platform-specific binary URL generators
- **buildInstallCommand()** - Creates complete installation commands with server configuration
- **buildUninstallCommand()** - Generates platform-specific uninstallation commands
- **normalizeDevicePlatform()** - Converts various OS identifiers to standardized platform types

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Generate installation command for Windows
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.example.com',
  initialKey: 'key_123',
  orgId: 'org_456',
  releaseVersion: 'v1.2.3',
  additionalArgs: ['--verbose', '--force']
})

// Normalize device platform from various sources
const platform = normalizeDevicePlatform('Win32') // Returns 'windows'

// Get direct binary URLs
const macUrl = getMacBinaryUrl('v1.2.3')
// Returns: https://github.com/flamingo-stack/openframe-oss-tenant/releases/download/v1.2.3/openframe-client_macos.tar.gz
```

The utility handles cross-platform binary downloads, PowerShell commands for Windows, and bash commands for macOS/Linux with proper error handling and cleanup.
