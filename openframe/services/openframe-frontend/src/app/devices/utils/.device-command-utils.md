Utility functions for generating cross-platform device installation and uninstallation commands for the OpenFrame client binary. Provides platform-specific command generation with automatic binary download URLs and proper execution parameters.

## Key Components

- **buildBinaryUrl()** - Constructs GitHub release download URLs for OpenFrame client binaries
- **getMacBinaryUrl()** / **getWindowsBinaryUrl()** - Platform-specific binary URL helpers
- **buildInstallCommand()** - Generates complete installation commands with server connection parameters
- **buildUninstallCommand()** - Creates platform-appropriate uninstallation commands
- **normalizeDevicePlatform()** - Standardizes various OS identifiers to consistent platform IDs

## Usage Example

```typescript
import { buildInstallCommand, buildUninstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Generate installation command
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.flamingo.run',
  initialKey: 'device-key-123',
  orgId: 'org-456',
  releaseVersion: 'v1.0.0',
  additionalArgs: ['--verbose']
})

// Generate uninstallation command
const uninstallCmd = buildUninstallCommand({
  platform: 'darwin',
  releaseVersion: 'v1.0.0'
})

// Normalize platform from device info
const platform = normalizeDevicePlatform('Win32') // Returns 'windows'
```

The utility automatically handles PowerShell commands for Windows and bash commands for macOS/Linux, including proper binary download, extraction, and execution with elevated privileges.
