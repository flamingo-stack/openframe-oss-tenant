Provides unified utilities for generating platform-specific device installation and uninstallation commands for OpenFrame client binaries. Handles URL construction, command building, and OS platform normalization across Windows and macOS.

## Key Components

- **Binary URL Functions**: `buildBinaryUrl()`, `getMacBinaryUrl()`, `getWindowsBinaryUrl()` - Generate download URLs for OpenFrame client binaries
- **Command Builders**: `buildInstallCommand()`, `buildUninstallCommand()` - Create platform-specific shell commands for device management
- **Platform Utilities**: `normalizeDevicePlatform()` - Standardize OS detection from various device fields
- **Type Definitions**: `InstallCommandOptions`, `UninstallCommandOptions` - Configuration interfaces for command generation

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Generate installation command for Windows device
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.openframe.ai',
  initialKey: 'ak_abc123',
  orgId: 'org_456',
  releaseVersion: 'v1.2.3',
  additionalArgs: ['--verbose']
})

// Normalize platform from device data
const platform = normalizeDevicePlatform('Win10', undefined, 'Windows')
// Returns: 'windows'

// Build uninstall command
const uninstallCmd = buildUninstallCommand({
  platform: 'darwin',
  releaseVersion: 'latest'
})
```

The utility automatically handles binary downloads, extraction, and execution with appropriate permissions for each platform, generating PowerShell commands for Windows and bash commands for macOS.
