Utility functions for generating cross-platform OpenFrame client installation and uninstallation commands with automatic binary URL resolution.

## Key Components

### Binary URL Functions
- `buildBinaryUrl()` - Constructs download URLs for GitHub releases
- `getMacBinaryUrl()` / `getWindowsBinaryUrl()` - Platform-specific binary URL generators

### Command Builders
- `buildInstallCommand()` - Generates platform-specific installation commands with server configuration
- `buildUninstallCommand()` - Creates uninstallation commands for client removal
- `normalizeDevicePlatform()` - Standardizes OS platform identification from various device fields

### Interfaces
- `InstallCommandOptions` - Configuration for installation commands (server URL, keys, org ID)
- `UninstallCommandOptions` - Options for uninstallation commands

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Generate installation command for a Windows device
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.example.com',
  initialKey: 'key123',
  orgId: 'org456',
  releaseVersion: 'v1.2.3',
  additionalArgs: ['--verbose', '--timeout=30']
})

// Normalize platform from device data
const platform = normalizeDevicePlatform('Win32', 'windows', 'Windows 10')
// Returns: 'windows'

// Build macOS uninstall command
const uninstallCmd = buildUninstallCommand({
  platform: 'darwin',
  releaseVersion: 'latest'
})
```

The utility handles cross-platform differences in command syntax, binary extraction, and privilege escalation requirements.
