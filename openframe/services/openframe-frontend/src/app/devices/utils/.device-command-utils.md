Unified utility functions for generating cross-platform device installation and uninstallation commands for the OpenFrame client binary.

## Key Components

- **URL Builders**: `buildBinaryUrl()`, `getMacBinaryUrl()`, `getWindowsBinaryUrl()` - Generate download URLs for platform-specific binaries
- **Command Builders**: `buildInstallCommand()`, `buildUninstallCommand()` - Generate shell/PowerShell commands for device management
- **Platform Normalization**: `normalizeDevicePlatform()` - Standardize OS platform identification
- **Type Definitions**: `InstallCommandOptions`, `UninstallCommandOptions` - Configuration interfaces for command generation

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Generate installation command for Windows device
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.flamingo.run',
  initialKey: 'device-key-123',
  orgId: 'org-456',
  releaseVersion: 'v1.0.0',
  additionalArgs: ['--silent', '--auto-start']
})

// Normalize platform from device data
const platform = normalizeDevicePlatform('Windows 11', undefined, 'win64')
// Returns: 'windows'

// Generate uninstall command for macOS
const uninstallCmd = buildUninstallCommand({
  platform: 'darwin',
  releaseVersion: 'latest'
})
```

The utility handles platform-specific command generation, downloading binaries from GitHub releases, and executing installation/uninstallation with proper permissions (sudo for macOS, RunAs for Windows).
