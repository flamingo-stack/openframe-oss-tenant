Utilities for building OpenFrame client installation and uninstallation commands across different operating system platforms. This module provides cross-platform command generation for device management operations.

## Key Components

### Binary URL Builders
- `buildBinaryUrl()` - Constructs GitHub release download URLs
- `getMacBinaryUrl()` - Returns macOS binary download URL
- `getWindowsBinaryUrl()` - Returns Windows binary download URL

### Command Builders
- `buildInstallCommand()` - Generates OS-specific installation commands
- `buildUninstallCommand()` - Generates OS-specific uninstallation commands
- `normalizeDevicePlatform()` - Normalizes OS identifiers to standard platform IDs

### Types
- `InstallCommandOptions` - Configuration for installation commands
- `UninstallCommandOptions` - Configuration for uninstallation commands

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Build installation command for Windows
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.example.com',
  initialKey: 'ak_1234567890',
  orgId: 'org_abcdef',
  releaseVersion: 'v1.0.0',
  additionalArgs: ['--debug']
})

// Normalize platform from device info
const platform = normalizeDevicePlatform('Darwin 23.1.0', 'macOS', 'macOS')
// Returns: 'darwin'

// Build uninstall command
const uninstallCmd = buildUninstallCommand({
  platform: 'darwin',
  releaseVersion: 'v1.0.0'
})
```

The utility handles platform-specific differences like PowerShell commands for Windows and bash commands for macOS/Linux, automatically downloading the appropriate binary and executing installation/uninstallation with proper permissions.
