Utility functions for generating cross-platform device installation and uninstallation commands for the OpenFrame client. Handles binary download URLs, command construction, and platform normalization for macOS and Windows deployments.

## Key Components

- **Binary URL builders**: `buildBinaryUrl()`, `getMacBinaryUrl()`, `getWindowsBinaryUrl()` - Generate GitHub release download URLs
- **Command builders**: `buildInstallCommand()`, `buildUninstallCommand()` - Create platform-specific shell commands for device management
- **Platform utilities**: `normalizeDevicePlatform()` - Standardize OS platform detection from various input formats
- **Type definitions**: `InstallCommandOptions`, `UninstallCommandOptions` - Configuration interfaces for command generation

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Generate installation command for Windows device
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.openframe.ai',
  initialKey: 'ak_1234567890',
  orgId: 'org_abcdef123',
  releaseVersion: 'v1.2.3',
  additionalArgs: ['--debug', '--timeout=30']
})

// Normalize platform from device data
const platform = normalizeDevicePlatform('Win64') // Returns 'windows'

// Get binary download URL
const macUrl = getMacBinaryUrl('v1.2.3')
// Returns: https://github.com/flamingo-stack/openframe-oss-tenant/releases/download/v1.2.3/openframe-client_macos.tar.gz
```

The generated commands handle downloading the appropriate binary, extracting it, setting permissions, and executing the installation/uninstallation process with elevated privileges where required.
