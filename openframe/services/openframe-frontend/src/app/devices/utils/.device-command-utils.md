Utility functions for generating OpenFrame client installation and uninstallation commands across different operating systems, with support for dynamic binary downloads and platform detection.

## Key Components

### Binary URL Functions
- `buildBinaryUrl()` - Constructs download URLs for release binaries
- `getMacBinaryUrl()` - Returns macOS binary download URL
- `getWindowsBinaryUrl()` - Returns Windows binary download URL

### Command Builders
- `buildInstallCommand()` - Generates platform-specific installation commands
- `buildUninstallCommand()` - Generates platform-specific uninstallation commands
- `normalizeDevicePlatform()` - Normalizes various OS identifiers to standard platform IDs

### Interfaces
- `InstallCommandOptions` - Configuration for installation commands
- `UninstallCommandOptions` - Configuration for uninstallation commands

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Build installation command for Windows
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.openframe.ai',
  initialKey: 'key_abc123',
  orgId: 'org_456',
  releaseVersion: 'v1.0.0',
  additionalArgs: ['--debug']
})

// Normalize platform from device info
const platform = normalizeDevicePlatform('Win32') // Returns 'windows'

// Get binary URL for latest version
const macUrl = getMacBinaryUrl('') // Latest version
const winUrl = getWindowsBinaryUrl('v1.2.0') // Specific version
```

The utility generates complete one-liner commands that download, extract, and execute the OpenFrame client with proper permissions and error handling for each platform.
