Unified utility functions for generating cross-platform device installation and uninstallation commands for the OpenFrame client binary.

## Key Components

**Binary URL Builders:**
- `buildBinaryUrl()` - Constructs GitHub release download URLs
- `getMacBinaryUrl()` / `getWindowsBinaryUrl()` - Platform-specific binary URLs

**Command Builders:**
- `buildInstallCommand()` - Generates installation commands with server configuration
- `buildUninstallCommand()` - Generates uninstallation commands
- `normalizeDevicePlatform()` - Normalizes OS identifiers to standard platform IDs

**Interfaces:**
- `InstallCommandOptions` - Configuration for installation commands
- `UninstallCommandOptions` - Configuration for uninstallation commands

## Usage Example

```typescript
import { 
  buildInstallCommand, 
  buildUninstallCommand, 
  normalizeDevicePlatform 
} from './device-command-utils'

// Generate installation command
const installCmd = buildInstallCommand({
  platform: 'darwin',
  serverUrl: 'https://api.openframe.ai',
  initialKey: 'abc123',
  orgId: 'org_456',
  releaseVersion: 'v1.2.3',
  additionalArgs: ['--verbose']
})

// Generate uninstallation command
const uninstallCmd = buildUninstallCommand({
  platform: 'windows',
  releaseVersion: 'v1.2.3'
})

// Normalize platform from device info
const platform = normalizeDevicePlatform('Windows 10', 'win64')
// Returns: 'windows'
```

The utility automatically handles platform-specific command syntax (PowerShell for Windows, bash for macOS/Linux) and downloads the appropriate binary from GitHub releases.
