Provides utility functions for generating cross-platform device installation and uninstallation commands for the OpenFrame client binary. Handles platform-specific command generation for Windows PowerShell and macOS/Linux bash environments.

## Key Components

- `buildBinaryUrl()` - Constructs GitHub release download URLs for OpenFrame client binaries
- `getMacBinaryUrl()` / `getWindowsBinaryUrl()` - Platform-specific binary URL builders
- `buildInstallCommand()` - Generates complete installation commands with server configuration
- `buildUninstallCommand()` - Creates uninstallation commands for client removal
- `normalizeDevicePlatform()` - Standardizes OS detection from various device information sources

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Generate installation command
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.example.com',
  initialKey: 'abc123',
  orgId: 'org-456',
  releaseVersion: 'v1.2.3',
  additionalArgs: ['--debug', '--timeout=30']
})

// Normalize platform detection
const platform = normalizeDevicePlatform('Win32') // Returns 'windows'

// Get binary URLs
const macUrl = getMacBinaryUrl('v1.2.3')
// Returns: https://github.com/flamingo-stack/openframe-oss-tenant/releases/download/v1.2.3/openframe-client_macos.tar.gz
```

The utility automatically handles platform differences, generating PowerShell commands for Windows and bash commands for macOS/Linux systems.
