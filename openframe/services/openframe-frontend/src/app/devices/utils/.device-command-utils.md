Provides utilities for generating platform-specific installation and uninstallation commands for OpenFrame client devices, with support for Windows and macOS binary downloads.

## Key Components

- **buildBinaryUrl()** - Constructs GitHub release download URLs for client binaries
- **getMacBinaryUrl() / getWindowsBinaryUrl()** - Platform-specific binary URL generators
- **buildInstallCommand()** - Generates complete installation commands with server configuration
- **buildUninstallCommand()** - Creates platform-appropriate uninstallation commands
- **normalizeDevicePlatform()** - Normalizes various OS identifiers to standardized platform IDs

## Usage Example

```typescript
import { 
  buildInstallCommand, 
  buildUninstallCommand, 
  normalizeDevicePlatform 
} from './device-command-utils'

// Generate installation command for Windows
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.flamingo.run',
  initialKey: 'abc123',
  orgId: 'org_456',
  releaseVersion: 'v1.2.3',
  additionalArgs: ['--debug']
})

// Generate uninstall command for macOS
const uninstallCmd = buildUninstallCommand({
  platform: 'darwin',
  releaseVersion: 'v1.2.3'
})

// Normalize platform from device info
const platform = normalizeDevicePlatform(device.osType) // 'windows' | 'darwin' | 'linux'
```

The utility handles platform-specific command formatting, including PowerShell commands for Windows and bash commands for macOS, automatically downloading the appropriate binary from GitHub releases.
