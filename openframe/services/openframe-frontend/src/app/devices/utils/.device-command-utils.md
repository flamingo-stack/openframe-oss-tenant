Utility functions for generating cross-platform OpenFrame client installation and uninstallation commands across macOS and Windows systems.

## Key Components

- **Binary URL Generation**
  - `buildBinaryUrl()` - Constructs download URLs for release binaries
  - `getMacBinaryUrl()` / `getWindowsBinaryUrl()` - Platform-specific binary URL helpers

- **Command Generation**
  - `buildInstallCommand()` - Creates complete installation command strings with download, extract, and install steps
  - `buildUninstallCommand()` - Generates uninstallation command strings
  - `InstallCommandOptions` / `UninstallCommandOptions` - Configuration interfaces

- **Platform Utilities**
  - `normalizeDevicePlatform()` - Standardizes various OS identifiers to `OSPlatformId`

## Usage Example

```typescript
import { 
  buildInstallCommand, 
  buildUninstallCommand,
  normalizeDevicePlatform 
} from './device-command-utils'

// Generate installation command
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.openframe.ai',
  initialKey: 'ak_1234567890abcdef',
  orgId: 'org_abc123',
  releaseVersion: 'v1.2.3',
  additionalArgs: ['--debug', '--timeout=30']
})

// Generate uninstallation command
const uninstallCmd = buildUninstallCommand({
  platform: 'darwin',
  releaseVersion: 'v1.2.3'
})

// Normalize platform identifier
const platform = normalizeDevicePlatform('macOS') // Returns 'darwin'
```

The utilities handle platform-specific command syntax (PowerShell for Windows, bash for macOS) and automatically construct the appropriate GitHub release download URLs.
