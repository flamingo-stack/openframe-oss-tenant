Utility functions for generating cross-platform OpenFrame client installation and uninstallation commands with automatic binary downloads from GitHub releases.

## Key Components

- **Binary URL Builders**: `buildBinaryUrl()`, `getMacBinaryUrl()`, `getWindowsBinaryUrl()` - Generate download URLs for platform-specific binaries
- **Command Generators**: `buildInstallCommand()`, `buildUninstallCommand()` - Create shell/PowerShell commands for device management
- **Platform Normalization**: `normalizeDevicePlatform()` - Converts various OS identifiers to standardized platform IDs
- **Configuration Interfaces**: `InstallCommandOptions`, `UninstallCommandOptions` - Type-safe option objects for command building

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Generate installation command for a Windows device
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.openframe.ai',
  initialKey: 'abc123',
  orgId: 'org_456',
  releaseVersion: 'v1.2.3',
  additionalArgs: ['--debug', '--timeout=30']
})

// Normalize platform from device info
const platform = normalizeDevicePlatform('win32') // Returns 'windows'

// Generate uninstall command
const uninstallCmd = buildUninstallCommand({
  platform: 'darwin',
  releaseVersion: 'latest'
})
```

The utility automatically handles platform-specific differences like PowerShell vs Bash syntax, binary names, and execution permissions. Commands include automatic cleanup, binary download, extraction, and execution with elevated privileges where required.
