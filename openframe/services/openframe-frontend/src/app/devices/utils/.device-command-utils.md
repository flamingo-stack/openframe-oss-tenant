Provides utilities for generating cross-platform device installation and uninstallation commands for the OpenFrame client, including binary URL construction and platform-specific command generation.

## Key Components

### Binary URL Functions
- **`buildBinaryUrl(version, assetName)`** - Constructs download URLs for release binaries
- **`getMacBinaryUrl(version)`** - Gets macOS binary download URL
- **`getWindowsBinaryUrl(version)`** - Gets Windows binary download URL

### Command Builders
- **`buildInstallCommand(options)`** - Generates platform-specific installation commands with server configuration
- **`buildUninstallCommand(options)`** - Generates platform-specific uninstallation commands
- **`normalizeDevicePlatform(platform, osType, operatingSystem)`** - Normalizes various OS identifiers to standard platform IDs

### Interfaces
- **`InstallCommandOptions`** - Configuration for installation commands (platform, server URL, keys, etc.)
- **`UninstallCommandOptions`** - Configuration for uninstallation commands

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Build installation command for Windows
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.flamingo.run',
  initialKey: 'ak_123...abc',
  orgId: 'org_456',
  releaseVersion: 'v1.2.3',
  additionalArgs: ['--silent']
})

// Normalize platform from device info
const platform = normalizeDevicePlatform('Win32', 'windows', 'Windows 11')
// Returns: 'windows'

// Get binary URL for latest release
const macUrl = getMacBinaryUrl('') // Uses latest
// Returns: 'https://github.com/flamingo-stack/openframe-oss-tenant/releases/latest/download/openframe-client_macos.tar.gz'
```
