Provides utility functions for generating OpenFrame device installation and uninstallation commands across different operating systems, with platform-specific binary download URLs and command formatting.

## Key Components

- **Binary URL Builders**: `buildBinaryUrl()`, `getMacBinaryUrl()`, `getWindowsBinaryUrl()` - Generate GitHub release download URLs
- **Command Builders**: `buildInstallCommand()`, `buildUninstallCommand()` - Create platform-specific shell commands for device management
- **Platform Normalization**: `normalizeDevicePlatform()` - Convert various OS identifiers to standardized platform IDs
- **Configuration Interfaces**: `InstallCommandOptions`, `UninstallCommandOptions` - Type-safe option objects for command generation

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Generate installation command for Windows
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.openframe.ai',
  initialKey: 'ak_1a2b3c4d5e6f7890',
  orgId: 'org_123',
  releaseVersion: 'v1.2.3',
  additionalArgs: ['--verbose']
})

// Normalize device platform from various inputs
const platform = normalizeDevicePlatform('Win64') // Returns 'windows'
const macPlatform = normalizeDevicePlatform('Darwin') // Returns 'darwin'

// Generate uninstall command
const uninstallCmd = buildUninstallCommand({
  platform: 'darwin',
  releaseVersion: 'latest'
})
```

The utility automatically handles platform differences - Windows commands use PowerShell with elevated privileges, while macOS/Linux use bash with sudo permissions.
