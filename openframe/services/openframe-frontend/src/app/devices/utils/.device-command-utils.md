Utilities for generating cross-platform device installation and uninstallation commands for OpenFrame client deployment.

## Key Components

- **buildBinaryUrl()** - Constructs GitHub release download URLs for OpenFrame client binaries
- **getMacBinaryUrl()** / **getWindowsBinaryUrl()** - Platform-specific binary URL generators
- **buildInstallCommand()** - Creates installation commands with proper PowerShell/bash syntax
- **buildUninstallCommand()** - Generates uninstallation commands for device cleanup
- **normalizeDevicePlatform()** - Standardizes OS detection from various device metadata fields

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Generate installation command
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.openframe.ai',
  initialKey: 'of_key_abc123',
  orgId: 'org_xyz789',
  releaseVersion: 'v1.2.3',
  additionalArgs: ['--silent', '--auto-start']
})

// Normalize device OS detection
const platform = normalizeDevicePlatform('Win32', undefined, 'Windows 11')
// Returns: 'windows'

// Get binary download URL
const macUrl = getMacBinaryUrl('v1.2.3')
// Returns: 'https://github.com/flamingo-stack/openframe-oss-tenant/releases/download/v1.2.3/openframe-client_macos.tar.gz'
```

The utilities handle platform-specific installation flows - PowerShell commands for Windows with proper archive extraction, and bash commands for macOS with sudo elevation. All commands include cleanup of previous installations and proper error handling.
