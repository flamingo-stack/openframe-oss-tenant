Device Command Utilities module provides centralized logic for generating cross-platform OpenFrame client installation and uninstallation commands. It handles binary URL construction and platform-specific command generation for macOS and Windows deployment workflows.

## Key Components

- **buildBinaryUrl()** - Constructs GitHub release URLs for client binaries with version support
- **getMacBinaryUrl() / getWindowsBinaryUrl()** - Platform-specific binary URL generators  
- **buildInstallCommand()** - Creates complete installation commands with server configuration
- **buildUninstallCommand()** - Generates platform-appropriate uninstall commands
- **normalizeDevicePlatform()** - Converts various OS identifiers to standardized platform types
- **InstallCommandOptions / UninstallCommandOptions** - Type definitions for command parameters

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Generate installation command for Windows
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.openframe.ai',
  initialKey: 'key_123abc',
  orgId: 'org_456def',
  releaseVersion: 'v1.2.0',
  additionalArgs: ['--verbose']
})

// Normalize device platform from various sources
const platform = normalizeDevicePlatform('Win32') // Returns 'windows'

// Build binary URL for specific version
const macUrl = getMacBinaryUrl('v1.2.0')
// Returns: https://github.com/flamingo-stack/openframe-oss-tenant/releases/download/v1.2.0/openframe-client_macos.tar.gz
```

The utility generates PowerShell commands for Windows (with UAC elevation) and bash commands for macOS (with sudo privileges), handling binary downloads, extraction, and execution automatically.
