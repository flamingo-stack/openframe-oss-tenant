Provides unified utilities for building OpenFrame device installation and uninstallation commands across different operating systems. This module handles binary URL generation, command construction for Windows and macOS platforms, and platform normalization.

## Key Components

- **Binary URL Builders**: `buildBinaryUrl()`, `getMacBinaryUrl()`, `getWindowsBinaryUrl()` - Generate download URLs for OpenFrame client binaries
- **Command Builders**: `buildInstallCommand()`, `buildUninstallCommand()` - Create platform-specific installation/uninstallation commands
- **Platform Utilities**: `normalizeDevicePlatform()` - Standardize OS identifiers to consistent platform IDs
- **Configuration Constants**: Release URLs and binary names for different platforms

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform, getMacBinaryUrl } from './device-command-utils'

// Build installation command for a Windows device
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.openframe.ai',
  initialKey: 'ak_1234567890',
  orgId: 'org_abcdefgh',
  releaseVersion: 'v1.0.0',
  additionalArgs: ['--debug']
})

// Normalize platform from device info
const platform = normalizeDevicePlatform('Windows 10', undefined, 'win32')
// Returns: 'windows'

// Get macOS binary download URL
const macUrl = getMacBinaryUrl('v1.2.3')
// Returns: 'https://github.com/flamingo-stack/openframe-oss-tenant/releases/download/v1.2.3/openframe-client_macos.tar.gz'
```
