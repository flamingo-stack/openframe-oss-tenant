Unified command generation utilities for OpenFrame device installation and uninstallation across macOS and Windows platforms.

## Key Components

### Binary URL Functions
- `buildBinaryUrl(version: string, assetName: string)` - Constructs GitHub release download URLs
- `getMacBinaryUrl(version: string)` - Returns macOS binary download URL
- `getWindowsBinaryUrl(version: string)` - Returns Windows binary download URL

### Command Builders
- `buildInstallCommand(options: InstallCommandOptions)` - Generates platform-specific installation commands
- `buildUninstallCommand(options: UninstallCommandOptions)` - Generates platform-specific uninstallation commands
- `normalizeDevicePlatform()` - Normalizes various OS identifiers to standard platform IDs

### Types
- `InstallCommandOptions` - Configuration for installation commands
- `UninstallCommandOptions` - Configuration for uninstallation commands

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Generate installation command for Windows
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.openframe.ai',
  initialKey: 'abc123',
  orgId: 'org-456',
  releaseVersion: 'v1.0.0',
  additionalArgs: ['--verbose']
})

// Normalize OS platform
const platform = normalizeDevicePlatform('Windows 11') // Returns 'windows'

// Get binary URL
const macUrl = getMacBinaryUrl('v1.0.0')
// Returns: https://github.com/flamingo-stack/openframe-oss-tenant/releases/download/v1.0.0/openframe-client_macos.tar.gz
```

The utilities handle downloading, extracting, and executing the OpenFrame client with appropriate permissions and arguments for each platform.
