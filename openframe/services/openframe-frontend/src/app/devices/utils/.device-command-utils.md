Utilities for generating platform-specific OpenFrame client installation and uninstallation commands for Windows and macOS devices.

## Key Components

- **URL Builders**: `buildBinaryUrl()`, `getMacBinaryUrl()`, `getWindowsBinaryUrl()` - Generate download URLs for client binaries
- **Command Generators**: `buildInstallCommand()`, `buildUninstallCommand()` - Create platform-specific shell commands
- **Platform Utilities**: `normalizeDevicePlatform()` - Normalize OS identifiers to standard platform IDs
- **Types**: `InstallCommandOptions`, `UninstallCommandOptions` - Configuration interfaces for command generation

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Generate installation command for Windows device
const installCommand = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://app.flamingo.run',
  initialKey: 'abc123',
  orgId: 'org_456',
  releaseVersion: 'v1.2.3',
  additionalArgs: ['--debug']
})

// Normalize platform from device info
const platform = normalizeDevicePlatform('Win32', 'Windows', 'Windows 11')
// Returns: 'windows'

// Get binary download URL
import { getMacBinaryUrl } from './device-command-utils'
const macUrl = getMacBinaryUrl('v1.2.3')
// Returns: 'https://github.com/flamingo-stack/openframe-oss-tenant/releases/download/v1.2.3/openframe-client_macos.tar.gz'
```

The utilities handle cross-platform differences in command syntax, file handling, and privilege escalation, generating complete one-liner commands that can be executed directly in PowerShell (Windows) or bash (macOS).
