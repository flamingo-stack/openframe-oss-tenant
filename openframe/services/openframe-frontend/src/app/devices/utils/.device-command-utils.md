Utility functions for generating cross-platform device installation and uninstallation commands for OpenFrame client binaries. Provides command builders for Windows (PowerShell) and macOS/Linux (bash) environments.

## Key Components

### Binary URL Functions
- `buildBinaryUrl()` - Constructs GitHub release download URLs
- `getMacBinaryUrl()` - Returns macOS binary download URL
- `getWindowsBinaryUrl()` - Returns Windows binary download URL

### Command Builders
- `buildInstallCommand()` - Generates platform-specific installation commands
- `buildUninstallCommand()` - Generates platform-specific uninstallation commands
- `normalizeDevicePlatform()` - Normalizes OS strings to standard platform IDs

### Types
- `InstallCommandOptions` - Configuration for installation commands
- `UninstallCommandOptions` - Configuration for uninstallation commands

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Generate installation command
const installCmd = buildInstallCommand({
  platform: 'darwin',
  serverUrl: 'https://api.openframe.ai',
  initialKey: 'key_abc123',
  orgId: 'org_xyz789',
  releaseVersion: 'v1.2.3',
  additionalArgs: ['--verbose']
})

// Normalize platform from device data
const platform = normalizeDevicePlatform('macOS', 'Darwin', undefined)
// Returns: 'darwin'

// Generate uninstall command
const uninstallCmd = buildUninstallCommand({
  platform: 'windows',
  releaseVersion: 'v1.2.3'
})
```

The utility handles platform-specific command syntax, binary downloads, and argument formatting for seamless device management across different operating systems.
