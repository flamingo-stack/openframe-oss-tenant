Provides unified utilities for generating OpenFrame client installation and uninstallation commands across different operating systems (macOS and Windows). This module handles binary URL construction, command generation with proper arguments, and platform normalization.

## Key Components

**Binary URL Functions:**
- `buildBinaryUrl()` - Constructs GitHub release download URLs
- `getMacBinaryUrl()` - Gets macOS binary URL for specific version
- `getWindowsBinaryUrl()` - Gets Windows binary URL for specific version

**Command Builders:**
- `buildInstallCommand()` - Generates platform-specific installation commands
- `buildUninstallCommand()` - Generates platform-specific uninstallation commands
- `normalizeDevicePlatform()` - Normalizes various OS identifiers to standard platform IDs

**Types:**
- `InstallCommandOptions` - Configuration for installation commands
- `UninstallCommandOptions` - Configuration for uninstallation commands

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Generate installation command
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.example.com',
  initialKey: 'key_abc123',
  orgId: 'org_456',
  releaseVersion: 'v1.2.3',
  additionalArgs: ['--verbose', '--debug']
})

// Normalize platform from device info
const platform = normalizeDevicePlatform('Win64', 'windows', 'Windows 11')
// Returns: 'windows'

// Generate uninstall command
const uninstallCmd = buildUninstallCommand({
  platform: 'darwin',
  releaseVersion: 'latest'
})
```

The utility automatically handles platform differences, with PowerShell commands for Windows and bash commands for macOS, including proper binary download, extraction, and execution with elevated privileges.
