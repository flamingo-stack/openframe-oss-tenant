Provides unified utilities for building OpenFrame device installation and uninstallation commands across different operating systems, handling binary downloads and command generation.

## Key Components

- **buildBinaryUrl()** - Constructs GitHub release URLs for binary downloads
- **getMacBinaryUrl() / getWindowsBinaryUrl()** - Platform-specific binary URL builders
- **buildInstallCommand()** - Generates complete installation commands for macOS/Windows
- **buildUninstallCommand()** - Creates uninstallation commands with binary cleanup
- **normalizeDevicePlatform()** - Standardizes OS detection from various device fields
- **InstallCommandOptions / UninstallCommandOptions** - Type definitions for command parameters

## Usage Example

```typescript
import { 
  buildInstallCommand, 
  buildUninstallCommand, 
  normalizeDevicePlatform 
} from './device-command-utils'

// Generate installation command
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.example.com',
  initialKey: 'abc123',
  orgId: 'org_456',
  releaseVersion: 'v1.0.0',
  additionalArgs: ['--verbose']
})

// Generate uninstallation command
const uninstallCmd = buildUninstallCommand({
  platform: 'darwin',
  releaseVersion: 'v1.0.0'
})

// Normalize platform detection
const platform = normalizeDevicePlatform('macOS Ventura') // Returns 'darwin'
```

The utilities handle cross-platform differences in PowerShell vs bash syntax and automatically download/extract the appropriate OpenFrame client binary for each OS.
