Utilities for generating cross-platform device installation and uninstallation commands for OpenFrame clients. Provides unified logic for building shell commands that download, extract, and execute the OpenFrame client binary on Windows and macOS systems.

## Key Components

### Binary URL Functions
- `buildBinaryUrl()` - Constructs download URLs for GitHub releases
- `getMacBinaryUrl()` - Gets macOS binary download URL
- `getWindowsBinaryUrl()` - Gets Windows binary download URL

### Command Builders
- `buildInstallCommand()` - Generates platform-specific installation commands
- `buildUninstallCommand()` - Generates platform-specific uninstallation commands
- `normalizeDevicePlatform()` - Normalizes OS strings to standardized platform IDs

### Types
- `InstallCommandOptions` - Configuration for installation commands
- `UninstallCommandOptions` - Configuration for uninstallation commands

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Build installation command for Windows
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.openframe.ai',
  initialKey: 'abc123',
  orgId: 'org_456',
  releaseVersion: 'v1.0.0',
  additionalArgs: ['--debug']
})

// Normalize platform from device info
const platform = normalizeDevicePlatform('Win32') // Returns 'windows'

// The generated commands handle downloading, extracting, and executing
// the OpenFrame client with proper permissions and error handling
```
