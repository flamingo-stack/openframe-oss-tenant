Utility functions for generating cross-platform device installation and uninstallation commands for OpenFrame clients. Handles binary URL construction and platform-specific command generation for Windows and macOS deployments.

## Key Components

### Binary URL Functions
- `buildBinaryUrl()` - Constructs download URLs for OpenFrame client binaries
- `getMacBinaryUrl()` - Gets macOS-specific binary download URL
- `getWindowsBinaryUrl()` - Gets Windows-specific binary download URL

### Command Builders
- `buildInstallCommand()` - Generates platform-specific installation commands with server configuration
- `buildUninstallCommand()` - Creates platform-specific uninstallation commands
- `normalizeDevicePlatform()` - Converts various OS identifiers to standardized platform IDs

### Types
- `InstallCommandOptions` - Configuration for installation commands
- `UninstallCommandOptions` - Configuration for uninstallation commands

## Usage Example

```typescript
import { buildInstallCommand, normalizeDevicePlatform } from './device-command-utils'

// Generate installation command
const installCmd = buildInstallCommand({
  platform: 'windows',
  serverUrl: 'https://api.openframe.ai',
  initialKey: 'key123',
  orgId: 'org456',
  releaseVersion: 'v1.0.0',
  additionalArgs: ['--debug']
})

// Normalize platform from device info
const platform = normalizeDevicePlatform('Windows 10', 'win32', 'windows')
// Returns: 'windows'

// Generate uninstall command
const uninstallCmd = buildUninstallCommand({
  platform: 'darwin',
  releaseVersion: 'latest'
})
```

The utility automatically handles platform differences - Windows commands use PowerShell with elevated privileges, while macOS commands use bash with sudo permissions.
