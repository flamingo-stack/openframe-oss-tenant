A Next.js client-side page component for adding new OpenFrame devices to an organization, providing platform-specific installation commands and automated script generation.

## Key Components

- **NewDevicePage**: Main page component with device registration workflow
- **Platform Selection**: OS-specific binary downloads (macOS, Windows, Linux coming soon)
- **Organization Selector**: Dropdown to choose target organization for device registration
- **Command Generator**: Dynamic installer command based on platform and organization
- **Script Download**: Automated script generation for local installation
- **Antivirus Path Display**: Shows exclusion paths for security software

## Usage Example

```typescript
// This page is accessed via routing in the devices section
// URL: /devices/new

// Key features:
// 1. Auto-detects user's OS and validates platform selection
// 2. Generates platform-specific installation commands
// 3. Downloads executable scripts for local installation
// 4. Provides antivirus exclusion paths

// Example generated command for macOS:
const macCommand = `cd ~ && rm -f openframe-client_macos.tar.gz openframe-client 2>/dev/null; curl -L -o openframe-client_macos.tar.gz 'https://github.com/flamingo-stack/openframe-oss-tenant/releases/latest/download/openframe-client_macos.tar.gz' && tar -xzf openframe-client_macos.tar.gz && sudo chmod +x ./openframe-client && sudo ./openframe-client install --serverUrl hostname --initialKey abc123 --orgId org-456`

// The page handles:
// - Dynamic binary URL construction based on release version
// - Browser-based OS detection for validation
// - Script file generation and download
// - Clipboard operations for command copying
// - Toast notifications for user feedback
```

The component integrates with OpenFrame's core components and hooks to provide a streamlined device onboarding experience with platform-specific installation guidance.
