A Next.js page component for adding new devices to the OpenFrame platform, providing installation commands and scripts for different operating systems.

## Key Components

- **NewDevicePage** - Main page component handling device registration and installation
- **Platform Selection** - OS platform selector (Windows, macOS, Linux)
- **Organization Selection** - Dropdown for selecting target organization
- **Command Generation** - Dynamic installer command building based on platform and configuration
- **Script Download** - Generates downloadable installation scripts for end users
- **Antivirus Path Display** - Shows required folder exclusions for security software

## Usage Example

This page is typically accessed at `/devices/new` and provides a complete device onboarding workflow:

```typescript
// The page automatically:
// 1. Loads organizations and selects default
// 2. Detects user's OS platform
// 3. Generates platform-specific installation commands
// 4. Provides copy-to-clipboard functionality
// 5. Downloads executable scripts for users

// Example generated command for macOS:
const macCommand = `cd ~ && rm -f openframe-client_macos.tar.gz openframe-client 2>/dev/null; curl -L -o openframe-client_macos.tar.gz 'https://github.com/flamingo-stack/openframe-oss-tenant/releases/latest/download/openframe-client_macos.tar.gz' && tar -xzf openframe-client_macos.tar.gz && sudo chmod +x ./openframe-client && sudo ./openframe-client install --serverUrl localhost --initialKey abc123 --orgId org-456`

// Platform detection and validation
const detectUserOS = () => {
  const userAgent = navigator.userAgent.toLowerCase()
  return {
    isMac: userAgent.includes('mac'),
    isWindows: userAgent.includes('win'),
    isLinux: userAgent.includes('linux')
  }
}
```

The component handles cross-platform installation by generating appropriate PowerShell scripts for Windows and shell scripts for macOS/Linux, with automatic binary URL resolution and antivirus exclusion path guidance.
