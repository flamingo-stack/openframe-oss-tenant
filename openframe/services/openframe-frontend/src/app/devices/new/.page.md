A Next.js page component that provides an interactive interface for adding new devices to the OpenFrame platform with platform-specific installation commands.

## Key Components

- **NewDevicePage**: Main page component with device registration workflow
- **Platform Selection**: OS platform selector (Windows/macOS/Linux) 
- **Organization Selection**: Dropdown for choosing target organization
- **Command Generation**: Dynamic installer command building based on selections
- **Binary Management**: Handles GitHub release URLs for platform binaries
- **Installation Methods**: Copy-to-clipboard and script download options

## Usage Example

```typescript
// This is a Next.js page component - accessed via routing
// URL: /devices/new

// Key features:
// - Auto-detects organization and platform defaults
// - Generates platform-specific installation commands
// - Downloads executable scripts for local installation
// - Provides antivirus exclusion paths

// Command structure example:
const command = `cd ~ && curl -L -o openframe-client_macos.tar.gz 'https://github.com/flamingo-stack/openframe-oss-tenant/releases/latest/download/openframe-client_macos.tar.gz' && tar -xzf openframe-client_macos.tar.gz && sudo chmod +x ./openframe-client && sudo ./openframe-client install --serverUrl localhost --initialKey abc123 --orgId org-456`
```

## Core Functionality

- **Dynamic Binary URLs**: Constructs GitHub release download links based on version
- **Cross-Platform Support**: Windows PowerShell and macOS/Linux bash commands
- **Organization Integration**: Fetches and auto-selects organizations
- **Security Features**: Uses registration secrets and validates platform compatibility
- **User Experience**: Toast notifications, clipboard operations, and script generation

The page integrates with OpenFrame's device management system to streamline the process of onboarding new devices across different operating systems.
