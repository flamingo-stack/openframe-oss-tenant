A Next.js page component for adding new devices to the OpenFrame platform, providing platform-specific installation commands and organization management.

## Key Components

- **NewDevicePage** - Main page component for device registration
- **Platform Selection** - OS platform selector (Windows, macOS, Linux)
- **Organization Management** - Organization selector with auto-selection
- **Command Generation** - Dynamic installer command building
- **Binary URL Construction** - GitHub release URL generation
- **Script Download** - Platform-specific installation script creation
