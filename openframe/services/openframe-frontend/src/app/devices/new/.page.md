A client-side React page component for adding new devices to the OpenFrame platform with automated installation script generation.

## Key Components

- **Device Registration UI**: Organization selector, platform selector (Windows/macOS), and command generation
- **Installation Command Builder**: Dynamically constructs platform-specific installation commands with proper arguments
- **Script Download**: Generates and downloads executable installation scripts (.ps1 for Windows, .sh for macOS)
- **Antivirus Path Management**: Displays required antivirus exclusion paths for each platform
- **Command Copy Functionality**: One-click copying of installation commands to clipboard

## Usage Example

```typescript
// The page automatically handles device registration workflow
export default function NewDevicePage() {
  // Builds installation commands like:
  // Windows: PowerShell script with Invoke-WebRequest and binary execution
  // macOS: Bash script with curl download and sudo execution
  
  const command = useMemo(() => {
    const baseArgs = `install --serverUrl ${serverUrl} --initialKey ${initialKey} --orgId ${orgIdArg}`
    
    if (platform === 'windows') {
      return `Set-Location ~; Remove-Item -Path 'openframe-client.zip' -Force; Invoke-WebRequest -Uri '${windowsBinaryUrl}' -OutFile 'openframe-client.zip'; Expand-Archive -Path 'openframe-client.zip' -DestinationPath '.' -Force; Start-Process -FilePath '.\\openframe-client.exe' -ArgumentList '${baseArgs}' -Verb RunAs -Wait`
    }
    
    return `cd ~ && rm -f openframe-client_macos.tar.gz openframe-client; curl -L -o openframe-client_macos.tar.gz '${macBinaryUrl}' && tar -xzf openframe-client_macos.tar.gz && sudo chmod +x ./openframe-client && sudo ./openframe-client ${baseArgs}`
  }, [initialKey, args, platform, selectedOrgId, serverUrl])
}
```

The component provides a complete device onboarding experience, automatically detecting the user's platform and generating appropriate installation scripts that can be downloaded and executed locally.
