A Next.js page component for device registration that generates platform-specific installation commands for the OpenFrame client. This page allows users to select an organization and platform, then provides installation scripts and antivirus exclusion paths.

## Key Components

- **Platform Selection**: OS platform selector (Windows, macOS, Linux)
- **Organization Selection**: Dropdown for choosing target organization
- **Command Generation**: Creates platform-specific installation commands
- **Script Download**: Generates downloadable installation scripts
- **Antivirus Paths**: Displays required antivirus exclusion paths
- **Command Copying**: Copy installation commands to clipboard

## Usage Example

```typescript
// This is a Next.js page component that would be accessed via routing
// Located at /devices/new or similar route

// Key functionality includes:
const buildBinaryUrl = (version: string, assetName: string) => {
  if (!version) {
    return `${RELEASES_BASE_URL}/latest/download/${assetName}`
  }
  return `${RELEASES_BASE_URL}/download/${version}/${assetName}`
}

// Auto-detects server URL based on environment
const serverUrl = useMemo(() => {
  if (typeof window === 'undefined') return 'localhost'
  const { protocol, hostname } = window.location
  if (hostname === 'localhost' || hostname === '127.0.0.1') {
    return 'localhost --localMode'
  }
  return hostname
}, [])

// Generates platform-specific commands
const command = useMemo(() => {
  if (platform === 'windows') {
    return `Set-Location ~; Remove-Item -Path 'openframe-client.zip'...`
  }
  return `cd ~ && rm -f openframe-client_macos.tar.gz...`
}, [initialKey, args, platform, selectedOrgId, serverUrl])
```

The component integrates with OpenFrame's device management system, providing a streamlined onboarding experience with automatic organization selection, platform detection, and downloadable installation scripts for different operating systems.
