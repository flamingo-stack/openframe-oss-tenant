A Next.js page component that provides a device registration interface for the OpenFrame MSP platform, allowing users to generate and execute platform-specific installation commands for new devices.

## Key Components

- **NewDevicePage**: Main page component with dynamic rendering enabled
- **Platform Selection**: OS platform selector (Windows, macOS, Linux coming soon)
- **Organization Management**: Organization selector with auto-selection of default organization
- **Command Generation**: Dynamic installer command generation based on platform and parameters
- **Script Download**: Generates downloadable installation scripts for local execution
- **Antivirus Exclusions**: Displays required antivirus exclusion paths for each platform

## Usage Example

The page integrates with OpenFrame's core components for organization management, platform detection, and provides both copy-to-clipboard and downloadable script options for device registration across Windows and macOS platforms.
