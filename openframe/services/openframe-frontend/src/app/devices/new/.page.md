A Next.js page component for registering new devices to the OpenFrame platform. This page generates platform-specific installation commands and provides options to download installer scripts or copy commands to clipboard.

## Key Components

- **NewDevicePage**: Main page component that handles device registration workflow
- **Platform Selection**: OS platform selector (Windows, macOS, Linux)
- **Organization Selection**: Dropdown to choose target organization
- **Command Generation**: Dynamic installer command builder based on platform and settings
- **Script Download**: Generates and downloads executable installation scripts
- **Antivirus Exclusions**: Shows required folder paths for antivirus whitelist
