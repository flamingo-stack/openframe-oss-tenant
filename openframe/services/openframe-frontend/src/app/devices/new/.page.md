A React component that provides a guided device installation interface for the OpenFrame platform. It generates platform-specific commands and scripts to help users add new devices to their organizations.

## Key Components

- **OrganizationSelector**: Allows users to select which organization to register the device to
- **OSPlatformSelector**: Provides platform selection (Windows, macOS, Linux)
- **CommandBox**: Displays the generated installation command
- **Dynamic command generation**: Creates platform-specific installation commands with proper URLs and arguments
- **Script download functionality**: Generates downloadable installation scripts for direct execution
- **Antivirus exclusion paths**: Shows recommended folder exclusions for security software
