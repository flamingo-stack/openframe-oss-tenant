The main page component for adding new devices to the OpenFrame platform. It provides an installer command generator that creates platform-specific commands for downloading and running the OpenFrame client.

## Key Components

- **Platform Selection**: `OSPlatformSelector` for choosing Windows, macOS, or Linux
- **Organization Selection**: `OrganizationSelector` for selecting target organization
- **Command Generation**: Dynamic installer command creation based on platform and configuration
- **Command Execution**: Copy-to-clipboard and script download functionality
- **Binary URLs**: GitHub releases integration for downloading platform-specific binaries
- **Antivirus Exclusions**: Platform-specific path recommendations for AV software
