A Next.js page component that provides an interactive interface for adding new devices to the OpenFrame platform with OS-specific installation commands.

## Key Components

- **Device Installation Interface**: Form with organization selector and platform picker (Windows/macOS/Linux)
- **Dynamic Command Generation**: Creates OS-specific installation commands with registration keys
- **Binary Download URLs**: Constructs GitHub release URLs for platform-specific binaries
- **Script Generation**: Downloads executable installation scripts for users
- **Antivirus Path Display**: Shows filesystem paths that need antivirus exclusions
- **Command Box Integration**: Uses reusable CommandBox component for command display and copying
