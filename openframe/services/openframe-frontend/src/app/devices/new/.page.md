A Next.js page component that provides a device registration interface for the OpenFrame platform, allowing users to generate and execute installation commands for different operating systems.

## Key Components

- **NewDevicePage**: Main page component with platform selection, organization selection, and command generation
- **Dynamic rendering**: Forced for client-side features like `useSearchParams`
- **Binary URL builders**: Functions to construct download URLs for macOS and Windows binaries
- **Platform detection**: Browser-based OS detection for validation
- **Script generation**: Creates downloadable installation scripts for different platforms
