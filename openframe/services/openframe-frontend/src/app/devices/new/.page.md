A React component page for adding new devices to the OpenFrame platform with automated installation command generation and organization management.

## Key Components

- **NewDevicePage** - Main page component handling device registration workflow
- **AppLayout** - Layout wrapper providing consistent page structure
- **DetailPageContainer** - Container for page content with navigation
- **OrganizationSelector** - Dropdown for selecting target organization
- **OSPlatformSelector** - Platform selection (Windows, macOS, Linux)
- **CommandBox** - Display and interaction area for installation commands
- **PathsDisplay** - Shows antivirus exclusion paths for the selected platform

## Usage Example

```typescript
// The page automatically generates installation commands based on:
// - Selected organization
// - Target platform (Windows/macOS)
// - Registration secret
// - Server URL detection

// Example generated command for macOS:
const macCommand = `cd ~ && rm -f openframe-client_macos.tar.gz openframe-client 2>/dev/null; curl -L -o openframe-client_macos.tar.gz 'https://github.com/flamingo-stack/openframe-oss-tenant/releases/latest/download/openframe-client_macos.tar.gz' && tar -xzf openframe-client_macos.tar.gz && sudo chmod +x ./openframe-client && sudo ./openframe-client install --serverUrl hostname --initialKey secret123 --orgId org456`

// Platform-specific binary downloads
const binaryUrls = {
  macOS: buildBinaryUrl(version, 'openframe-client_macos.tar.gz'),
  windows: buildBinaryUrl(version, 'openframe-client_windows.zip')
}
```

The page provides two installation methods: copying commands to clipboard or downloading executable scripts. It automatically detects the server environment (localhost vs production) and manages organization selection with default fallbacks. The component also displays required antivirus exclusion paths for Windows and macOS platforms.
