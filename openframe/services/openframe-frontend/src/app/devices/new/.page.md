A client-side React page for onboarding new devices to the OpenFrame platform, providing installation scripts and commands for different operating systems.

## Key Components

- **Platform Selection**: OS platform selector (Windows, macOS, Linux) with dynamic script generation
- **Organization Management**: Organization selector with auto-selection of default organization
- **Command Generation**: Dynamic installer command building based on platform and configuration
- **Script Download**: Generates and downloads executable installation scripts for the selected platform
- **Antivirus Path Display**: Shows required antivirus exclusion paths for proper operation
- **Registration Secret Integration**: Uses registration secrets for secure device enrollment
