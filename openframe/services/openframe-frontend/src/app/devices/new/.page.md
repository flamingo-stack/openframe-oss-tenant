A React client component for the OpenFrame device registration page that generates platform-specific installation commands and provides device management functionality.

## Key Components

**Main Component:**
- `NewDevicePage` - Main page component with device registration workflow
- Platform selector for Windows/macOS/Linux
- Organization selector with auto-selection
- Command generation and execution utilities

**Key Features:**
- `buildBinaryUrl()` - Constructs GitHub release URLs for platform-specific binaries
- `copyCommand()` - Copies installation command to clipboard
- `runOnCurrentMachine()` - Downloads executable installation script
- Dynamic command building based on platform and organization selection

**State Management:**
- Platform selection (Windows, macOS, Linux)
- Organization selection with auto-detection of default org
- Registration secret and release version fetching
- Custom arguments handling (currently hidden)

## Usage Example

```typescript
// Component renders a complete device registration interface

  // Auto-detects user's platform and organization
  // Generates platform-specific installation commands
  // Handles command copying and script download
  
  return (
    <AppLayout>
      <DetailPageContainer title="New Device">
        {/* Organization selector */}
        <OrganizationSelector />
        
        {/* Platform selector */}
        <OSPlatformSelector />
        
        {/* Generated command display */}
        <CommandBox 
          command={command}
          primaryAction={{ onClick: copyCommand }}

      </DetailPageContainer>
    </AppLayout>
  )
}
```

The component integrates with OpenFrame's device management system, providing a streamlined onboarding experience for new devices across different operating systems.
