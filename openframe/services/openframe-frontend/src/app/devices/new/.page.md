A React component that provides a comprehensive device installation interface for the OpenFrame platform, allowing users to generate and execute platform-specific installation commands for new devices.

## Key Components

- **Platform Selection**: OS platform selector (Windows, macOS, Linux) with appropriate binary handling
- **Organization Management**: Organization selector with automatic default selection
- **Command Generation**: Dynamic installer command generation based on platform and configuration
- **Installation Methods**: Both copy-to-clipboard and direct script download functionality
- **Antivirus Configuration**: Platform-specific exclusion paths for security software
- **Registration Handling**: Integration with registration secrets and release version management

## Usage Example

```typescript
// This is a page component that handles device installation
export default function NewDevicePage() {
  // The component automatically:
  // 1. Loads available organizations and selects default
  // 2. Generates platform-specific installation commands
  // 3. Provides copy and download functionality
  // 4. Shows antivirus exclusion paths when needed
  
  return (
    <AppLayout>
      <DetailPageContainer title="New Device">
        {/* Platform selection, command generation, and installation options */}
      </DetailPageContainer>
    </AppLayout>
  )
}

// Key features:
// - Dynamic command generation: `buildBinaryUrl(version, assetName)`
// - Cross-platform support: Windows PowerShell and macOS/Linux bash scripts
// - One-click installation: `runOnCurrentMachine()` downloads executable scripts
// - Organization management: Auto-selects default org from available list
```

The component dynamically builds installation commands that download the appropriate OpenFrame client binary, extract it, and execute the installation with proper server URL, registration key, and organization ID parameters. It includes platform detection, error handling, and user-friendly toast notifications throughout the installation process.
