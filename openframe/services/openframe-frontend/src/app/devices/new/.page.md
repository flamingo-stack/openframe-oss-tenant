A Next.js page component for adding new devices to OpenFrame, providing platform-specific installer commands and automated setup.

## Key Components

- **NewDevicePage**: Main page component with device registration workflow
- **Platform Selection**: OS platform selector (Windows, macOS, Linux)
- **Organization Selector**: Dropdown for choosing target organization
- **Command Generation**: Dynamic installer command creation based on platform
- **Binary URL Building**: GitHub releases integration for downloading binaries
- **Script Generation**: Automated installer script creation and download

## Usage Example

```typescript
// This is a Next.js page component - accessed via routing
// URL: /devices/new

// Key functionality:
const command = useMemo(() => {
  const baseArgs = `install --serverUrl ${serverUrl} --initialKey ${initialKey} --orgId ${orgId}`
  
  if (platform === 'windows') {
    return `Set-Location ~; Invoke-WebRequest -Uri '${windowsBinaryUrl}' -OutFile 'openframe-client.zip'...`
  }
  
  return `cd ~ && curl -L -o openframe-client_macos.tar.gz '${macBinaryUrl}' && tar -xzf...`
}, [initialKey, platform, selectedOrgId, serverUrl])

// Copy command to clipboard
const copyCommand = useCallback(async () => {
  await navigator.clipboard.writeText(command)
  toast({ title: 'Command copied' })
}, [command])
```

The page integrates with OpenFrame's core components for organization management, platform detection, and provides both manual command copying and automated script download options for device registration across Windows and macOS platforms.
