A React page component for setting up new OpenFrame devices with platform-specific installation commands and organizational configuration.

## Key Components

- **NewDevicePage**: Main page component for device registration and setup
- **Dynamic URL building**: Constructs GitHub release URLs for platform-specific binaries
- **Command generation**: Creates platform-specific installation commands (PowerShell for Windows, bash for macOS/Linux)
- **Organization selection**: Dropdown for choosing target organization
- **Platform detection**: OS platform selector with auto-detection capabilities
- **Script download**: Generates downloadable installation scripts for end users

## Usage Example

This page is typically accessed via the `/devices/new` route and provides a guided setup experience:

```typescript
// The component automatically:
// 1. Loads available organizations
// 2. Detects user's platform
// 3. Generates installation commands
// 4. Provides copy/download functionality

// Key features include:
const features = {
  platformSupport: ['windows', 'darwin', 'linux'], // Linux coming soon
  binaryDownloads: {
    macOS: 'openframe-client_macos.tar.gz',
    windows: 'openframe-client_windows.zip'
  },
  commandGeneration: {
    windows: 'PowerShell script with Admin privileges',
    macOS: 'Bash script with sudo requirements'
  }
}
```

The page integrates with the OpenFrame stack to provide seamless device onboarding, automatically configuring server URLs, registration secrets, and organization assignments. It includes antivirus exclusion path guidance and platform validation to ensure successful installations.
