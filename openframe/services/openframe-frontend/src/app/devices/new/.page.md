A Next.js page component for adding new devices to the OpenFrame platform through an automated installer command generation interface.

## Key Components

**Main Exports:**
- `NewDevicePage` - Main page component with device registration workflow
- `dynamic = 'force-dynamic'` - Forces dynamic rendering for search params

**State Management:**
- Platform selection (Windows, macOS, Linux)
- Organization selection with auto-detection
- Registration secret and release version fetching
- Custom installation arguments (currently hidden)

**Core Functionality:**
- Binary URL generation for different platforms
- Command generation for automated device installation
- Script file download for local execution
- Clipboard operations for command copying
- Antivirus exclusion path display

## Usage Example

```typescript
// This is a page component - used by Next.js routing
// Access via: /devices/new

// Key hooks used internally:
const { initialKey } = useRegistrationSecret()
const { releaseVersion } = useReleaseVersion()
const { items: orgs } = useOrganizationsMin(100)

// Platform-specific command generation:
const command = useMemo(() => {
  if (platform === 'windows') {
    return `Set-Location ~; Remove-Item -Path 'openframe-client.zip'...`
  }
  return `cd ~ && rm -f openframe-client_macos.tar.gz...`
}, [platform, initialKey, selectedOrgId])

// Copy command to clipboard:
await navigator.clipboard.writeText(command)

// Download installation script:
const blob = new Blob([scriptContent], { type: mimeType })
const link = document.createElement('a')
link.download = platform === 'windows' ? 'install-openframe.ps1' : 'install-openframe.sh'
```

The page provides a user-friendly interface for generating platform-specific installation commands that automatically download, extract, and run the OpenFrame client binary with proper organization and authentication configuration.
