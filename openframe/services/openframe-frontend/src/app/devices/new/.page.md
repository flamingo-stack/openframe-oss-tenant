A Next.js page component for registering new devices in the OpenFrame platform, providing platform-specific installation commands and managing device onboarding.

## Key Components

- **NewDevicePage**: Main page component that handles device registration flow
- **Platform Selection**: OS platform selector (Windows, macOS, Linux) with appropriate binary URLs
- **Organization Management**: Dropdown for selecting target organization with auto-selection
- **Command Generation**: Dynamic installer command creation based on platform and configuration
- **Installation Methods**: Copy command or download executable script options
- **Antivirus Path Display**: Shows required folder exclusions for security software

## Usage Example

```typescript
// This is a complete page component - usage in app router:
// app/devices/new/page.tsx

export default function NewDevicePage() {
  // Component automatically:
  // 1. Loads available organizations
  // 2. Generates platform-specific commands
  // 3. Handles binary downloads and script generation
  // 4. Provides clipboard operations for easy deployment
  
  return (
    <AppLayout>
      <DetailPageContainer title="New Device">
        {/* Organization selector, platform picker, command display */}
      </DetailPageContainer>
    </AppLayout>
  )
}

// Key features:
// - Force dynamic rendering for search params compatibility
// - Auto-detects user's OS for platform validation
// - Generates PowerShell scripts for Windows, bash for macOS/Linux
// - Includes antivirus exclusion paths from OPENFRAME_PATHS constants
```

The component integrates with the OpenFrame core frontend library to provide a streamlined device onboarding experience with platform-aware installation commands and organizational management.
