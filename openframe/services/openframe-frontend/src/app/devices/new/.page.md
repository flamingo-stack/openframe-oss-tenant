A Next.js page component for device registration in the OpenFrame platform that generates platform-specific installation commands for new devices.

## Key Components

- **Platform Selection**: OS platform selector (Windows/macOS/Linux) with command generation
- **Organization Management**: Organization selector with auto-selection of default organization
- **Command Generation**: Dynamic installer command creation based on platform and configuration
- **Binary URL Building**: Release version-aware binary download URL construction
- **Script Generation**: Platform-specific installation script download functionality
- **Antivirus Paths**: Display of required antivirus exclusion paths for smooth operation

## Usage Example

```typescript
// Component renders a form-based interface for device registration
// Users select organization and platform, then get installation commands

// Key hooks used:
const { initialKey } = useRegistrationSecret()
const { releaseVersion } = useReleaseVersion()
const { items: orgs } = useOrganizationsMin(100)

// Dynamic command generation:

  const baseArgs = `install --serverUrl ${serverUrl} --initialKey ${initialKey} --orgId ${orgIdArg}`
  
  if (platform === 'windows') {
    return `Set-Location ~; Remove-Item -Path 'openframe-client.zip'...`
  }
  
  return `cd ~ && rm -f openframe-client_macos.tar.gz...`
}, [initialKey, args, platform, selectedOrgId])

// Copy command to clipboard
const copyCommand = useCallback(async () => {
  await navigator.clipboard.writeText(command)
  toast({ title: 'Command copied' })
}, [command])
```

The page provides both copy-to-clipboard functionality and downloadable installation scripts, with platform detection and validation to ensure users get the correct installer for their operating system.
