A Next.js page component for adding new devices to the OpenFrame platform. Provides organization selection, platform-specific installation commands, and automated script generation for device registration.

## Key Components

- **Platform Selection**: OSPlatformSelector for choosing Windows, macOS, or Linux
- **Organization Management**: OrganizationSelector with auto-selection of default organization
- **Command Generation**: Dynamic installation commands based on platform and configuration
- **Script Download**: Automated generation of platform-specific installation scripts
- **Antivirus Exclusions**: PathsDisplay component showing required folder exclusions
- **Registration Handling**: Integration with registration secrets and release versions
