A Next.js page component for device registration that provides an interactive installer command generator for the OpenFrame client across different operating systems.

## Key Components

- **Device Registration Flow**: Generates platform-specific installation commands with organization and authentication context
- **Platform Selection**: OSPlatformSelector for choosing between Windows, macOS, and Linux (coming soon)
- **Organization Management**: OrganizationSelector with auto-selection of default organization
- **Command Generation**: Dynamic command building based on platform, server URL, and registration secrets
- **Installation Methods**: Copy-to-clipboard and downloadable script generation for local execution
- **Antivirus Path Display**: Shows required exclusion paths for security software compatibility

## Usage Example

```typescript
// The page automatically handles device registration workflow
export default function NewDevicePage() {
  // Auto-detects server environment and generates appropriate commands
  const serverUrl = useMemo(() => {
    if (hostname === 'localhost') {
      return 'localhost --localMode'
    }
    return hostname
  }, [])

  // Platform-specific command generation
  const command = useMemo(() => {
    const baseArgs = `install --serverUrl ${serverUrl} --initialKey ${initialKey} --orgId ${orgId}`
    
    if (platform === 'windows') {
      return `Set-Location ~; Invoke-WebRequest -Uri '${windowsBinaryUrl}' -OutFile 'openframe-client.zip'...`
    }
    
    return `cd ~ && curl -L -o openframe-client_macos.tar.gz '${macBinaryUrl}'...`
  }, [platform, initialKey, serverUrl])
}
```

The component provides a complete device onboarding experience with automatic organization selection, platform detection, command generation, and antivirus configuration guidance through the PathsDisplay component.
