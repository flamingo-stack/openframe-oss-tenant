A Next.js page component for registering new OpenFrame devices with automated installation script generation and platform-specific binary distribution. This client-side page provides a complete device onboarding experience with organization selection, platform detection, and installation command generation.

## Key Components

- **Device Registration Form** - Organization selector and platform chooser (Windows, macOS, Linux)
- **Installation Command Generator** - Creates platform-specific installation commands with proper binary URLs
- **Script Download Feature** - Generates downloadable installation scripts (.ps1 for Windows, .sh for macOS)
- **Antivirus Path Display** - Shows required folder exclusions using `OPENFRAME_PATHS` constants
- **Real-time Configuration** - Dynamic server URL detection and registration secret management

## Usage Example

```typescript
// Component renders automatically with proper routing
// Force dynamic rendering for search params compatibility
export const dynamic = 'force-dynamic'

// Access via Next.js routing - typically /devices/new
<AppLayout>
  <DetailPageContainer title="New Device">
    {/* Organization selection, platform choice, command generation */}
  </DetailPageContainer>
</AppLayout>
```

The page integrates with OpenFrame's device management system, automatically detecting the user's environment and generating appropriate installation commands. It handles binary distribution from GitHub releases, provides clipboard integration for commands, and includes platform-specific validation to ensure users download the correct installer for their operating system.

Key features include automatic organization selection (prioritizing "Default" org), browser-based OS detection for validation, and comprehensive error handling with toast notifications for user feedback.
