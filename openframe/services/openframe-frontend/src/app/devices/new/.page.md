A Next.js page component that provides device registration functionality for the OpenFrame platform. It generates platform-specific installation commands and handles device onboarding with organization selection and configuration options.

## Key Components

### Main Component
- **NewDevicePage** - Main page component for device registration with dynamic rendering enabled

### State Management
- **Platform selection** - Windows, macOS, and Linux platform support
- **Organization selector** - Auto-selects default organization or first available
- **Command generation** - Creates platform-specific installation commands
- **Registration secret** - Fetches and manages device registration keys

### Core Features
- **Binary URL building** - Constructs GitHub release download URLs
- **Command copying** - Clipboard integration for installation commands
- **Script generation** - Downloads executable scripts for local installation
- **Antivirus path management** - Provides exclusion paths for security software
