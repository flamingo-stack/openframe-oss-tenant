A Next.js page component for device registration in the OpenFrame MSP platform, providing cross-platform client installation commands and antivirus exclusion paths.

## Key Components

- **Platform Selection**: OS platform selector (Windows, macOS, Linux) with platform-specific installation commands
- **Organization Management**: Organization selector with auto-selection of default organization
- **Command Generation**: Dynamic command building based on platform, server URL, and registration secrets
- **Installation Methods**: Copy-to-clipboard and downloadable script generation for local execution
- **Antivirus Integration**: Platform-specific folder path display for antivirus exclusions
- **Custom Hooks**: Integration with registration secrets, release versions, and organization data

## Usage Example

```typescript
// The component automatically detects server environment and generates commands
// Users select their organization and platform to get customized installation commands

// For Windows PowerShell:
Set-Location ~; Remove-Item -Path 'openframe-client.zip','openframe-client.exe' -Force -ErrorAction SilentlyContinue; Invoke-WebRequest -Uri 'https://github.com/flamingo-stack/openframe-oss-tenant/releases/latest/download/openframe-client_windows.zip' -OutFile 'openframe-client.zip'; Expand-Archive -Path 'openframe-client.zip' -DestinationPath '.' -Force; Start-Process -FilePath '.\\openframe-client.exe' -ArgumentList 'install --serverUrl hostname --initialKey secret --orgId orgId' -Verb RunAs -Wait

// For macOS/Linux bash:
cd ~ && rm -f openframe-client_macos.tar.gz openframe-client 2>/dev/null; curl -L -o openframe-client_macos.tar.gz 'https://github.com/flamingo-stack/openframe-oss-tenant/releases/latest/download/openframe-client_macos.tar.gz' && tar -xzf openframe-client_macos.tar.gz && sudo chmod +x ./openframe-client && sudo ./openframe-client install --serverUrl hostname --initialKey secret --orgId orgId
```

The page uses force-dynamic rendering due to server-side URL detection and provides both command copying and script file downloads for seamless client installation across different operating systems.
