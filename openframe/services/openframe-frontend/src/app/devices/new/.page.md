This React page component provides a user interface for registering new devices in the OpenFrame platform by generating and executing installation commands.

## Key Components

- **Device Registration Form**: Organization selector and OS platform selector for configuring device installation
- **Command Generation**: Creates platform-specific installation commands with authentication secrets
- **Binary Download URLs**: Builds GitHub release URLs for macOS and Windows OpenFrame client binaries  
- **Script Generation**: Downloads executable scripts for local installation
- **Antivirus Path Display**: Shows folder paths that need antivirus exclusions
- **Command Box UI**: Interactive command display with copy and execute functionality

## Usage Example

```typescript
// The page automatically generates installation commands like:
// macOS/Linux:
const macCommand = `cd ~ && rm -f openframe-client_macos.tar.gz openframe-client 2>/dev/null; curl -L -o openframe-client_macos.tar.gz 'https://github.com/flamingo-stack/openframe-oss-tenant/releases/latest/download/openframe-client_macos.tar.gz' && tar -xzf openframe-client_macos.tar.gz && sudo chmod +x ./openframe-client && sudo ./openframe-client install --serverUrl hostname --initialKey abc123 --orgId org-456`

// Windows PowerShell:
const windowsCommand = `Set-Location ~; Remove-Item -Path 'openframe-client.zip','openframe-client.exe' -Force -ErrorAction SilentlyContinue; Invoke-WebRequest -Uri 'https://github.com/flamingo-stack/openframe-oss-tenant/releases/latest/download/openframe-client_windows.zip' -OutFile 'openframe-client.zip'; Expand-Archive -Path 'openframe-client.zip' -DestinationPath '.' -Force; Start-Process -FilePath '.\\openframe-client.exe' -ArgumentList 'install --serverUrl hostname --initialKey abc123 --orgId org-456' -Verb RunAs -Wait`

// Component handles organization selection, platform detection, and script downloading
```

The component automatically detects the server URL from the browser location, fetches available organizations, and provides both copy-to-clipboard and download-script functionality for seamless device onboarding across different operating systems.
