A Next.js client-side page component that provides a streamlined interface for adding new devices to OpenFrame with automated installation command generation and platform-specific binary distribution.

## Key Components

**Main Exports:**
- `NewDevicePage` - React component for device registration workflow
- `dynamic = 'force-dynamic'` - Next.js configuration for dynamic rendering

**Core Features:**
- **Platform Selection** - macOS/Windows/Linux support with OS-specific installation commands
- **Organization Management** - Multi-tenant organization selection with auto-selection of default org
- **Binary Distribution** - Automated GitHub releases integration for platform-specific binaries
- **Command Generation** - Dynamic PowerShell/Bash script creation based on platform
- **Installation Automation** - One-click script download and clipboard integration

**Key Hooks & Dependencies:**
- `useRegistrationSecret()` - Fetches device registration tokens
- `useReleaseVersion()` - Gets latest OpenFrame client version
- `useOrganizationsMin()` - Loads available organizations
- Platform detection and command generation utilities

## Usage Example

```typescript
import { NewDevicePage } from './page'

// Renders device registration page with:
// - Organization selector (auto-selects default)
// - Platform picker (Windows/macOS/Linux)
// - Generated installation commands
// - Copy-to-clipboard functionality
// - Script download for local execution

export default function DevicesNewPage() {
  return <NewDevicePage />
}
```

The component automatically generates platform-specific installation commands that download binaries from GitHub releases, handle authentication with registration secrets, and configure the device for the selected organization. It includes antivirus exclusion path guidance and provides both manual copy-paste and automated script download workflows.
