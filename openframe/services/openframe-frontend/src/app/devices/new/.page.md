A Next.js page component that provides a device registration interface for the OpenFrame client, allowing users to generate and execute installation commands for different operating systems.

## Key Components

- **NewDevicePage**: Main page component with platform selection and command generation
- **Platform Selection**: OS platform selector (Windows, macOS, Linux)
- **Organization Selection**: Dropdown to choose target organization
- **Command Generation**: Dynamically builds installation commands based on platform
- **Installation Methods**: Copy command or download executable script
- **Antivirus Path Display**: Shows required security exclusions

## Usage Example

```typescript
// This is a Next.js page component - accessed via routing
// URL: /devices/new

// Key state management:
const [platform, setPlatform] = useState<Platform>(DEFAULT_OS_PLATFORM)
const [selectedOrgId, setSelectedOrgId] = useState<string>('')
const { initialKey } = useRegistrationSecret()

// Generated command example (macOS):
const command = `cd ~ && rm -f openframe-client_macos.tar.gz openframe-client 2>/dev/null; curl -L -o openframe-client_macos.tar.gz 'https://github.com/flamingo-stack/openframe-oss-tenant/releases/latest/download/openframe-client_macos.tar.gz' && tar -xzf openframe-client_macos.tar.gz && sudo chmod +x ./openframe-client && sudo ./openframe-client install --serverUrl localhost --initialKey ABC123 --orgId org-456`

// Copy command to clipboard:
const copyCommand = async () => {
  await navigator.clipboard.writeText(command)
  toast({ title: 'Command copied' })
}
```

The page automatically detects the server URL, fetches available organizations, and generates platform-specific installation commands. It includes safety features like platform validation and provides both manual command copying and automated script generation for easier deployment.
