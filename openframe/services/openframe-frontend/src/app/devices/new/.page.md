A React page component for registering new OpenFrame client devices by generating and providing platform-specific installation commands.

## Key Components

- **NewDevicePage**: Main page component for device registration
- **Platform Selection**: OS platform selector (Windows, macOS, Linux)
- **Organization Selection**: Dropdown for choosing target organization
- **Command Generation**: Dynamic installer command based on platform and settings
- **Installation Options**: Copy command or download executable script
- **Antivirus Exclusions**: Platform-specific path display for AV configuration

## Usage Example

```typescript
// Component automatically handles:
// 1. Loading organizations and auto-selecting default
// 2. Generating platform-specific commands
// 3. Providing copy/download functionality

export default function NewDevicePage() {
  const [platform, setPlatform] = useState<Platform>(DEFAULT_OS_PLATFORM)
  const [selectedOrgId, setSelectedOrgId] = useState<string>('')
  
  // Generated command example for macOS:
  const command = `cd ~ && rm -f openframe-client_macos.tar.gz openframe-client 2>/dev/null; 
    curl -L -o openframe-client_macos.tar.gz 'https://github.com/flamingo-stack/openframe-oss-tenant/releases/latest/download/openframe-client_macos.tar.gz' && 
    tar -xzf openframe-client_macos.tar.gz && 
    sudo chmod +x ./openframe-client && 
    sudo ./openframe-client install --serverUrl example.com --initialKey abc123 --orgId org-456`
}
```

The page dynamically builds installation commands that download the appropriate OpenFrame client binary, extract it, and execute the registration with the selected organization's credentials. It supports both manual command copying and automated script generation for direct execution.
