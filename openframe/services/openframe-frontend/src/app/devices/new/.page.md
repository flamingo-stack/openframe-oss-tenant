A Next.js page component for registering new devices in the OpenFrame MSP platform. This page provides OS-specific installation commands and automatic antivirus exclusion paths for seamless device onboarding.

## Key Components

- **`NewDevicePage`** - Main page component that generates platform-specific installation commands
- **Platform Selection** - OS platform selector (Windows, macOS, Linux coming soon)
- **Organization Selection** - Dropdown to choose which organization to register the device under
- **Command Generation** - Dynamic command builder based on platform and configuration
- **Installation Methods** - Copy command or download executable script
- **Antivirus Exclusions** - Automatic display of required antivirus exclusion paths

## Usage Example

```typescript
// The page automatically generates installation commands like:

// For macOS/Linux:
cd ~ && rm -f openframe-client_macos.tar.gz openframe-client 2>/dev/null; 
curl -L -o openframe-client_macos.tar.gz 'https://github.com/flamingo-stack/openframe-oss-tenant/releases/latest/download/openframe-client_macos.tar.gz' && 
tar -xzf openframe-client_macos.tar.gz && 
sudo chmod +x ./openframe-client && 
sudo ./openframe-client install --serverUrl hostname --initialKey secret --orgId orgId

// For Windows (PowerShell):
Set-Location ~; Remove-Item -Path 'openframe-client.zip','openframe-client.exe' -Force -ErrorAction SilentlyContinue; 
Invoke-WebRequest -Uri 'https://github.com/flamingo-stack/openframe-oss-tenant/releases/latest/download/openframe-client_windows.zip' -OutFile 'openframe-client.zip'; 
Expand-Archive -Path 'openframe-client.zip' -DestinationPath '.' -Force; 
Start-Process -FilePath '.\openframe-client.exe' -ArgumentList 'install --serverUrl hostname --initialKey secret --orgId orgId' -Verb RunAs -Wait
```

The component handles registration secrets, release version detection, OS platform validation, and provides both copy-to-clipboard and downloadable script options for device installation.
