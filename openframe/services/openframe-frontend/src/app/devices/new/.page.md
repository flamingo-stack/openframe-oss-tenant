A Next.js page component for adding new devices to the OpenFrame system with platform-specific installation commands.

## Key Components

- **NewDevicePage** - Main page component with platform selection and command generation
- **Platform Selection** - OS platform selector (Windows, macOS, Linux)
- **Organization Selector** - Dropdown to choose target organization
- **Command Generation** - Dynamic installer command builder based on platform
- **Script Download** - Automated script file generation for local execution
- **Antivirus Exclusions** - Platform-specific folder paths display

## Usage Example

```typescript
// This is a Next.js page component used as:
// /devices/new/page.tsx

export default function NewDevicePage() {
  // Component handles:
  // 1. Platform detection (Windows/macOS/Linux)
  // 2. Organization selection from available orgs
  // 3. Registration secret management
  // 4. Command generation for device installation
  // 5. Script download for local execution
  
  return (
    <AppLayout>
      <DetailPageContainer title="New Device">
        {/* Platform selector, organization picker, command display */}
      </DetailPageContainer>
    </AppLayout>
  )
}
```

The page dynamically generates platform-specific installation commands that download and execute the OpenFrame client binary with proper authentication tokens and organization settings. It includes features for copying commands to clipboard, downloading executable scripts, and displaying antivirus exclusion paths.
