A React page component for registering new devices in the OpenFrame platform, providing platform-specific installation commands and automated script generation.

## Key Components

- **Platform Selection**: OS platform selector (Windows, macOS, Linux) with dynamic command generation
- **Organization Selection**: Dropdown to choose target organization with auto-selection of default org
- **Command Generation**: Creates platform-specific installation commands with registration secrets
- **Script Download**: Generates and downloads executable installation scripts for the selected platform
- **Antivirus Path Display**: Shows required antivirus exclusion paths for each platform
- **Registration Secret Integration**: Uses hooks to fetch and include registration keys in commands

## Usage Example

```typescript
// This is a Next.js page component - no direct instantiation
// Route: /devices/new

// Key features accessed through UI:
const component = () => {
  // Auto-detects server URL based on environment
  const serverUrl = useMemo(() => {
    if (hostname === 'localhost') return 'localhost --localMode'
    return hostname
  }, [])

  // Generates platform-specific commands
  const command = useMemo(() => {
    if (platform === 'windows') {
      return `Set-Location ~; Invoke-WebRequest -Uri '${binaryUrl}' -OutFile 'client.zip'...`
    }
    return `cd ~ && curl -L -o client.tar.gz '${binaryUrl}' && tar -xzf...`
  }, [platform, serverUrl, initialKey])

  return <NewDevicePage />
}
```

The page integrates with the OpenFrame client installation workflow, handling binary downloads from GitHub releases and providing cross-platform installation automation with proper error handling and user feedback.
