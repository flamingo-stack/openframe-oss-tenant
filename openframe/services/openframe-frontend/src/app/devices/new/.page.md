A Next.js page component for adding new devices to OpenFrame, providing platform-specific installation commands and scripts.

## Key Components

- **NewDevicePage** - Main page component with device installation wizard
- **Platform Selection** - OS platform selector (Windows, macOS, Linux)
- **Organization Selection** - Dropdown for choosing target organization
- **Command Generation** - Dynamic installer command based on platform and settings
- **Script Download** - Generates and downloads platform-specific installation scripts
- **Antivirus Paths** - Displays required antivirus exclusion paths

## Features

- **Cross-Platform Support** - Generates PowerShell scripts for Windows and shell scripts for macOS
- **Auto-Organization Selection** - Automatically selects default or first available organization
- **Binary URL Generation** - Constructs download URLs for latest or specific release versions
- **Clipboard Integration** - Copy commands and file paths to clipboard
- **Platform Validation** - Warns users if selected platform doesn't match their OS
- **Dynamic Server Detection** - Automatically detects localhost vs production server URLs
