A React page component for adding new devices to the OpenFrame platform, providing platform-specific installation commands and scripts.

## Key Components

- **NewDevicePage**: Main page component handling device registration workflow
- **Platform Selection**: OS platform selector (Windows, macOS, Linux)
- **Organization Selection**: Dropdown for selecting target organization
- **Command Generation**: Dynamic installer command creation based on platform
- **Script Download**: Automatic generation and download of installation scripts
- **Registration Secret**: Integration with device registration authentication

## Usage Example

```typescript
// This is a Next.js page component that renders automatically
// when navigating to the /devices/new route

// Key functionality includes:
const command = useMemo(() => {
  const baseArgs = `install --serverUrl ${serverUrl} --initialKey ${initialKey} --orgId ${orgIdArg}`
  
  if (platform === 'windows') {
    return `Set-Location ~; Remove-Item -Path 'openframe-client.zip' -Force; 
            Invoke-WebRequest -Uri '${windowsBinaryUrl}' -OutFile 'openframe-client.zip';
            Expand-Archive -Path 'openframe-client.zip' -DestinationPath '.' -Force;
            Start-Process -FilePath '.\\openframe-client.exe' -ArgumentList '${baseArgs}' -Verb RunAs`
  }
  
  return `cd ~ && curl -L -o openframe-client_macos.tar.gz '${macBinaryUrl}' && 
          tar -xzf openframe-client_macos.tar.gz && 
          sudo chmod +x ./openframe-client && 
          sudo ./openframe-client ${baseArgs}`
}, [platform, initialKey, selectedOrgId])

// Copy to clipboard functionality
const copyCommand = useCallback(async () => {
  await navigator.clipboard.writeText(command)
  toast({ title: 'Command copied', variant: 'default' })
}, [command])
```

The page automatically detects the user's OS, generates appropriate installation commands, and provides downloadable scripts for easy device onboarding across Windows and macOS platforms.
