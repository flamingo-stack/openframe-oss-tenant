This Next.js page component provides device registration functionality for the OpenFrame platform, allowing users to install client software on new devices.

## Key Components

- **NewDevicePage**: Main page component for device registration
- **Platform Selection**: OS platform selector (Windows, macOS, Linux)
- **Organization Selection**: Dropdown to choose target organization
- **Command Generation**: Dynamic installer command creation
- **Script Download**: Automated script file generation for installation
- **Antivirus Path Display**: Shows required exclusion paths

**Key Features:**
- Auto-detects server URL (localhost vs production)
- Generates platform-specific installation commands
- Downloads executable scripts for user convenience
- Validates platform compatibility before execution
- Shows antivirus exclusion paths via `PathsDisplay` component
- Handles registration secrets and organization management
