A React page component for setting up new OpenFrame client devices with platform-specific installation commands and automated deployment scripts.

## Key Components

- **Platform Selection**: OS platform selector (Windows, macOS, Linux) with conditional command generation
- **Organization Selector**: Dropdown to choose target organization for device registration
- **Command Generation**: Dynamic installer command building based on platform and configuration
- **Binary URL Building**: Constructs download URLs for platform-specific client binaries
- **Script Generation**: Creates downloadable installation scripts for automated deployment
- **Antivirus Path Display**: Shows required antivirus exclusion paths for each platform
