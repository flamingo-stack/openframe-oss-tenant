A Next.js page component for device registration that generates platform-specific installation commands for the OpenFrame client. This page provides an interactive interface to configure and install the OpenFrame agent on new devices.

## Key Components

- **Platform Selection**: OS platform selector (Windows, macOS, Linux)
- **Organization Selection**: Dropdown to select target organization
- **Command Generation**: Dynamic command building based on platform and configuration
- **Installation Methods**: Copy command or download executable script
- **Security Paths**: Display of antivirus exclusion paths for the selected platform

## Usage Example

```typescript
// This is a Next.js page component - accessed via routing
// URL: /devices/new

// Key features used:
const [platform, setPlatform] = useState<Platform>(DEFAULT_OS_PLATFORM)
const { initialKey } = useRegistrationSecret()
const { releaseVersion } = useReleaseVersion()

// Dynamic command generation
const command = useMemo(() => {
  const baseArgs = `install --serverUrl ${serverUrl} --initialKey ${initialKey} --orgId ${orgId}`
  
  if (platform === 'windows') {
    return `Set-Location ~; Invoke-WebRequest -Uri '${windowsBinaryUrl}' -OutFile 'openframe-client.zip'...`
  }
  
  return `cd ~ && curl -L -o openframe-client_macos.tar.gz '${macBinaryUrl}' && tar -xzf...`
}, [initialKey, platform, selectedOrgId, serverUrl])

// Copy to clipboard functionality
const copyCommand = useCallback(async () => {
  await navigator.clipboard.writeText(command)
  toast({ title: 'Command copied' })
}, [command])
```

The page automatically detects the server URL, manages binary download URLs from GitHub releases, and provides antivirus exclusion paths through the `OPENFRAME_PATHS` constants. It includes validation to ensure platform selection matches the user's actual operating system when using the "Run on Current Machine" feature.
