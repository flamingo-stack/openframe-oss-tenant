A React page component that provides an interactive device installation interface for OpenFrame client setup across different operating systems.

## Key Components

- **Device Installation Interface** - Form for selecting organization and OS platform
- **Command Generation** - Dynamically builds platform-specific installation commands
- **Binary Download URLs** - Constructs GitHub release URLs for macOS and Windows binaries
- **Script Generation** - Creates downloadable installation scripts for direct execution
- **Antivirus Path Display** - Shows folder paths that need antivirus exclusions
- **Organization Selection** - Dropdown with auto-selection of default organization

## Usage Example

This page component is used as a Next.js route for device onboarding:

```typescript
// Used in Next.js app router as /devices/new/page.tsx
export default function NewDevicePage() {
  // Component handles:
  // - OS platform detection and selection
  // - Organization selection with auto-default
  // - Dynamic command generation based on server URL
  // - Script download for easier installation
  // - Clipboard operations for command copying
}

// Key features:
// - Forces dynamic rendering for client-side functionality
// - Auto-detects localhost vs production server URLs
// - Provides platform-specific installation commands
// - Generates downloadable .ps1 (Windows) or .sh (macOS) scripts
```

The component integrates with OpenFrame's core components and hooks to provide a streamlined device registration workflow, automatically handling platform differences and providing clear installation instructions with antivirus exclusion guidance.
