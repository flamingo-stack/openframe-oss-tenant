A Next.js page component for adding new devices to the OpenFrame platform, providing platform-specific installation commands and scripts.

## Key Components

- **NewDevicePage**: Main page component with platform selection, organization selection, and installation command generation
- **Dynamic exports**: Forces dynamic rendering for client-side functionality
- **Platform detection**: Browser-based OS detection for validation
- **Installation scripts**: Generates downloadable PowerShell/Bash scripts
- **Binary URL builders**: Constructs GitHub release URLs for different platforms
