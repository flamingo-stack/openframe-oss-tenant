A React client-side page component for adding new devices to the OpenFrame platform through automated client installation.

## Key Components

- **NewDevicePage**: Main page component handling device registration workflow
- **Platform Selection**: OS platform selector (Windows, macOS, Linux coming soon)  
- **Organization Selector**: Dropdown for choosing target organization
- **Command Generation**: Dynamic installer command builder based on platform and settings
- **Installation Methods**: Copy command or download executable script options
- **Antivirus Path Display**: Shows required antivirus exclusion paths for proper operation

## Usage Example

```typescript
// This is a Next.js page component - no direct imports needed
// Accessed via route: /devices/new

// Key functionality:
const command = useMemo(() => {
  const baseArgs = `install --serverUrl ${serverUrl} --initialKey ${initialKey} --orgId ${orgId}`
  
  if (platform === 'windows') {
    return `Set-Location ~; Invoke-WebRequest -Uri '${binaryUrl}' -OutFile 'client.zip'; ...`
  }
  
  return `cd ~ && curl -L -o client.tar.gz '${binaryUrl}' && tar -xzf client.tar.gz && ...`
}, [platform, serverUrl, initialKey, orgId])

// Copy to clipboard
await navigator.clipboard.writeText(command)

// Or download as executable script
const blob = new Blob([scriptContent], { type: mimeType })

```

The page automatically detects the user's environment, generates platform-specific installation commands, and provides multiple installation methods including command copying and script download. It also displays required antivirus exclusion paths to ensure proper client operation.
