A client-side Next.js page component for registering new OpenFrame devices with organization selection, platform detection, and automated installer script generation.

## Key Components

- **NewDevicePage**: Main page component with dynamic rendering enabled
- **Platform Selection**: OS platform selector with Windows/macOS/Linux options
- **Organization Management**: Multi-organization device registration support
- **Command Generation**: Dynamic installer command building based on selected platform
- **Script Download**: Automated PowerShell/Bash script generation for local installation
- **Binary URL Building**: Dynamic GitHub release URL construction
- **Antivirus Path Display**: Platform-specific folder exclusion recommendations
