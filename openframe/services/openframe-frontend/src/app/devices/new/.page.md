This is a Next.js page component for registering new devices in the OpenFrame platform, providing platform-specific installation commands and automated script generation.

## Key Components

- **Platform Selection**: OS platform selector (Windows, macOS, Linux) with corresponding binary URLs
- **Organization Management**: Dropdown selector for choosing target organization with auto-selection logic
- **Command Generation**: Dynamic installer command building based on platform, server URL, and registration keys
- **Script Download**: Automated generation and download of platform-specific installation scripts
- **Antivirus Integration**: Path exclusion recommendations for Windows/macOS security software
- **Clipboard Operations**: Copy functionality for commands and file paths

## Usage Example

```typescript
// The component automatically handles:
// 1. Loading organizations and selecting default
// 2. Detecting server environment (localhost vs production)
// 3. Building platform-specific commands

// Example generated command for macOS:
const macCommand = `cd ~ && rm -f openframe-client_macos.tar.gz openframe-client 2>/dev/null; curl -L -o openframe-client_macos.tar.gz 'https://github.com/flamingo-stack/openframe-oss-tenant/releases/latest/download/openframe-client_macos.tar.gz' && tar -xzf openframe-client_macos.tar.gz && sudo chmod +x ./openframe-client && sudo ./openframe-client install --serverUrl localhost --localMode --initialKey abc123 --orgId org-456`

// Example Windows PowerShell command:
const winCommand = `Set-Location ~; Remove-Item -Path 'openframe-client.zip','openframe-client.exe' -Force -ErrorAction SilentlyContinue; Invoke-WebRequest -Uri 'https://github.com/flamingo-stack/openframe-oss-tenant/releases/latest/download/openframe-client_windows.zip' -OutFile 'openframe-client.zip'; Expand-Archive -Path 'openframe-client.zip' -DestinationPath '.' -Force; Start-Process -FilePath '.\\openframe-client.exe' -ArgumentList 'install --serverUrl example.com --initialKey abc123 --orgId org-456' -Verb RunAs -Wait`
```

The page features dynamic server URL detection, automatic organization selection, platform validation, and generates downloadable installation scripts for end users.
