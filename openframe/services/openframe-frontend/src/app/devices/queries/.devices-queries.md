This file provides GraphQL query definitions for device management operations in the Flamingo MSP platform.

## Key Components

The file exports four main GraphQL queries:

- **`GET_DEVICE_FILTERS_QUERY`** - Retrieves available filter options (statuses, device types, OS types, organizations, tags) with counts for the device listing interface
- **`GET_DEVICES_QUERY`** - Fetches paginated device listings with comprehensive device information including organization details, tool connections, and tags
- **`GET_DEVICE_QUERY`** - Retrieves detailed information for a single device by machineId, including installed agents
- **`GET_DEVICES_OVERVIEW_QUERY`** - Provides a lightweight view of devices for overview/dashboard purposes, returning only status information

## Usage Example

```typescript
import { 
  GET_DEVICES_QUERY, 
  GET_DEVICE_QUERY, 
  GET_DEVICE_FILTERS_QUERY 
} from './devices-queries'

// Fetch devices with pagination and filters
const devicesResult = await graphqlClient.query({
  query: GET_DEVICES_QUERY,
  variables: {
    filter: { status: 'ONLINE' },
    pagination: { first: 20 },
    search: 'server',
    sort: { field: 'lastSeen', direction: 'DESC' }
  }
})

// Get single device details
const deviceResult = await graphqlClient.query({
  query: GET_DEVICE_QUERY,
  variables: { machineId: 'device-123' }
})

// Fetch filter options for UI
const filtersResult = await graphqlClient.query({
  query: GET_DEVICE_FILTERS_QUERY,
  variables: { filter: {} }
})
```

These queries support the core device management functionality in OpenFrame, enabling MSPs to monitor, filter, and manage their client devices efficiently.
