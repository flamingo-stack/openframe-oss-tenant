A React modal component for configuring remote desktop control settings with quality, scaling, frame rate, and input preferences.

## Key Components

- **RemoteSettingsModal** - Main modal component that manages remote desktop configuration settings
- **RemoteSettingsConfig** - Configuration interface for quality, scaling, frame rate, and input options
- **RemoteDesktopSettings** - Settings manager class for applying configurations and bandwidth estimation
- **MeshDesktop/MeshTunnel** - MeshCentral integration refs for desktop control and WebSocket communication

## Usage Example

```typescript
import { RemoteSettingsModal } from './remote-settings-modal'
import { RemoteSettingsConfig } from '@lib/meshcentral/remote-settings'

const [settingsOpen, setSettingsOpen] = useState(false)
const [currentSettings, setCurrentSettings] = useState<RemoteSettingsConfig>({
  quality: 60,
  scaling: 100,
  frameRate: '1000',
  swapMouseButtons: false,
  useRemoteKeyboardMap: false,
  invertScrollDirection: false
})

<RemoteSettingsModal
  open={settingsOpen}
  onOpenChange={setSettingsOpen}
  currentSettings={currentSettings}
  desktopRef={desktopRef}
  tunnelRef={tunnelRef}
  connectionState={connectionState}
  onSettingsChange={setCurrentSettings}
/>
```

The component validates connection state before applying settings, provides real-time bandwidth estimation, and syncs changes with the MeshCentral desktop instance. Settings include video quality (1-100), display scaling (50-200%), frame rate options, and input behavior toggles for mouse and keyboard handling.
