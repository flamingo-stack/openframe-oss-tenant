A React container component that provides a complete file management interface for remote devices via MeshCentral integration. It handles file operations, navigation, search, and modal workflows for a device management platform.

## Key Components

- **FileManagerContainer**: Main container component with props for `deviceId`, `meshcentralAgentId`, and optional `hostname`
- **useMeshFileManager**: Custom hook providing file operations and state management
- **Modal Components**: `NewFolderModal`, `RenameItemModal`, `DeleteConfirmationModal` for file operations
- **Progress Indicators**: Real-time upload/download progress overlays
- **Keyboard Shortcuts**: Copy (Ctrl+C), cut (Ctrl+X), paste (Ctrl+V), delete, and escape handlers

## Usage Example

```typescript
import { FileManagerContainer } from './file-manager-container'

function DeviceFilePage() {
  return (
    <FileManagerContainer
      deviceId="device-123"
      meshcentralAgentId="agent-456"
      hostname="server-01.example.com"
      organizationName="Acme Corp"
    />
  )
}
```

The component provides a full-featured file manager with breadcrumb navigation, file selection, search functionality, drag-and-drop operations, and real-time connection status. It includes skeleton loading states and handles both local and search-based file operations seamlessly.
