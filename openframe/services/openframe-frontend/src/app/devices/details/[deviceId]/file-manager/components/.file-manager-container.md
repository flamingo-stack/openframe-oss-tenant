A React container component that provides a complete file management interface for remote devices via MeshCentral agents. It wraps the core FileManager component with additional modals, progress indicators, and keyboard shortcuts for comprehensive file operations.

## Key Components

- **FileManagerContainer** - Main container component managing file operations state
- **useMeshFileManager** - Custom hook for MeshCentral file management operations
- **Modal Components** - NewFolderModal, RenameItemModal, DeleteConfirmationModal for user interactions
- **Progress Indicators** - Upload/download progress overlays with cancellation support
- **Keyboard Shortcuts** - Ctrl+C/X/V for copy/cut/paste, Delete key, Escape for clearing selection

## Usage Example

```typescript
import { FileManagerContainer } from './file-manager-container'

function DeviceFilePage() {
  return (
    <FileManagerContainer
      deviceId="device-123"
      meshcentralAgentId="agent-456"
      hostname="server-01.example.com"
      organizationName="Acme Corp"
    />
  )
}
```

The component handles navigation, file operations (upload, download, rename, delete), clipboard operations, search functionality, and provides visual feedback through progress indicators. It includes comprehensive keyboard shortcuts and modal-based confirmations for destructive operations.
