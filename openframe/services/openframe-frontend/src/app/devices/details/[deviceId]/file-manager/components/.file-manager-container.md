A React container component that provides a complete file management interface for remote devices through MeshCentral agents, featuring upload/download capabilities, file operations, search functionality, and modal dialogs for user interactions.

## Key Components

- **FileManagerContainer** - Main container component with device connection and file operations
- **useMeshFileManager** - Hook providing file management state and operations for MeshCentral devices
- **Modal Components** - NewFolderModal, RenameItemModal, DeleteConfirmationModal for file operations
- **Progress Indicators** - Upload and download progress overlays with cancellation support
- **Keyboard Shortcuts** - Copy (Ctrl+C), cut (Ctrl+X), paste (Ctrl+V), delete, and escape handling

## Props Interface

```typescript
interface FileManagerContainerProps {
  deviceId: string           // Device identifier for navigation
  meshcentralAgentId: string // MeshCentral agent ID for connection
  hostname?: string          // Optional display name for device
  organizationName?: string  // Optional organization context
}
```

## Usage Example

```typescript
import { FileManagerContainer } from './file-manager-container'

export default function DeviceFilePage({ params }: { params: { deviceId: string } }) {
  return (
    <FileManagerContainer
      deviceId={params.deviceId}
      meshcentralAgentId="agent-12345"
      hostname="Production Server"
      organizationName="Acme Corp"
    />
  )
}
```

## Key Features

- **Remote File Management** - Browse, upload, download files through MeshCentral
- **Search & Navigation** - File search with breadcrumb navigation
- **File Operations** - Create folders, rename, delete, copy/cut/paste with clipboard
- **Progress Tracking** - Real-time upload/download progress with cancellation
- **Keyboard Shortcuts** - Standard file manager shortcuts (Ctrl+C/X/V, Delete, Escape)
- **Connection Handling** - Skeleton loader during connection establishment
- **Modal Workflows** - User-friendly dialogs for folder creation, renaming, and deletion confirmation
