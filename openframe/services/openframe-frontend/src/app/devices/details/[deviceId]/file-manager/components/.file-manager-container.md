A comprehensive file manager container component that provides a complete remote file system interface for device management through MeshCentral agents. It integrates file operations, search functionality, and modal dialogs with keyboard shortcuts and progress tracking.

## Key Components

- **FileManagerContainer**: Main container component handling all file management operations
- **useMeshFileManager**: Custom hook managing MeshCentral file system interactions
- **Modal Components**: NewFolderModal, RenameItemModal, DeleteConfirmationModal for file operations
- **Progress Indicators**: Upload/download progress overlays with cancel functionality
- **Keyboard Shortcuts**: Copy (Ctrl+C), cut (Ctrl+X), paste (Ctrl+V), delete (Del), escape handling

## Usage Example

```typescript
import { FileManagerContainer } from './file-manager-container'

export default function DeviceFileManagerPage({ params }: { params: { deviceId: string } }) {
  return (
    <FileManagerContainer
      deviceId={params.deviceId}
      meshcentralAgentId="agent_12345"
      hostname="production-server"
      organizationName="Acme Corp"
    />
  )
}
```

The component provides a full-featured file manager interface with:
- File/folder navigation and breadcrumb navigation
- Multi-file selection with checkboxes
- Upload/download with progress tracking
- Search functionality across the file system
- Context-aware actions (rename, delete, create folder)
- Clipboard operations (copy/cut/paste)
- Connection state management with loading skeletons
- Keyboard shortcuts for common operations

Progress overlays appear in the bottom-right corner during file transfers, and all modals prevent accidental closure during operations.
