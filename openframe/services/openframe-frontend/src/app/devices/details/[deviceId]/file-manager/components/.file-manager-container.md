A React client-side container component that provides a full-featured file manager interface for remote device file operations using MeshCentral agents. This component orchestrates file operations, handles user interactions, and manages modal dialogs for folder creation, file renaming, and deletion confirmation.

## Key Components

- **FileManagerContainer** - Main container component with device-specific file management
- **Modal Components** - NewFolderModal, RenameItemModal, DeleteConfirmationModal for user interactions
- **Progress Displays** - Fixed-position upload/download progress indicators with cancel functionality
- **Keyboard Shortcuts** - Support for Ctrl+C/X/V clipboard operations, Delete key, and Escape key
- **Navigation** - Breadcrumb navigation with back-to-device functionality

## Usage Example

```typescript
import { FileManagerContainer } from './file-manager-container'

export function DeviceFilesPage({ params }: { params: { deviceId: string } }) {
  return (
    <FileManagerContainer
      deviceId={params.deviceId}
      meshcentralAgentId="agent-123"
      hostname="server-01.example.com"
      organizationName="Acme Corp"
    />
  )
}
```

The component integrates with the `useMeshFileManager` hook to provide real-time file operations including upload, download, search, clipboard operations, and folder navigation. It automatically handles connection states and displays appropriate loading skeletons while establishing remote connections.
