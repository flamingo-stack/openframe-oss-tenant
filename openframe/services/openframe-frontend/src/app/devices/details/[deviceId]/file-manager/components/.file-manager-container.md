A container component that provides a complete file management interface for remote device file systems through MeshCentral. Integrates with the mesh file manager hook and handles all file operations including navigation, upload/download, and file actions.

## Key Components

- **FileManagerContainer**: Main container component that orchestrates file operations
- **useMeshFileManager**: Custom hook for file system operations and state management
- **Progress components**: Display upload/download progress with cancellation
- **Modal components**: Handle new folder creation, renaming, and delete confirmations
- **Keyboard shortcuts**: Support for copy/cut/paste/delete operations
- **File operations**: Upload, download, rename, delete, search functionality

## Usage Example

```typescript
import { FileManagerContainer } from './file-manager-container'

function DeviceFilePage() {
  return (
    <FileManagerContainer
      deviceId="device-123"
      meshcentralAgentId="agent-456" 
      hostname="My Device"
      organizationName="Acme Corp"
    />
  )
}
```

The component provides a full-featured file manager with:
- Breadcrumb navigation and search functionality
- File selection with checkboxes and keyboard shortcuts
- Upload/download with progress tracking and cancellation
- Context menus for file operations (rename, delete, copy/cut/paste)
- Modal dialogs for destructive operations and user input
- Responsive skeleton loading states during connection
- Integration with MeshCentral for remote file system access
