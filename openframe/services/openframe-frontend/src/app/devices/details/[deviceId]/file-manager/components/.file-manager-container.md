A React container component that provides a complete file management interface for remote devices using MeshCentral connections. It integrates with the Flamingo Stack OpenFrame UI system to deliver file operations, search functionality, and progress tracking for device file management.

## Key Components

- **FileManagerContainer** - Main container component that wraps the core FileManager with device-specific functionality
- **useMeshFileManager** - Custom hook for managing MeshCentral file operations and connection state
- **Modal Components** - NewFolderModal, RenameItemModal, DeleteConfirmationModal for file operations
- **Progress Tracking** - Upload and download progress indicators with cancellation support
- **Keyboard Shortcuts** - Full keyboard support for copy/paste, delete, and selection operations

## Usage Example

```typescript
import { FileManagerContainer } from './file-manager-container'

export function DeviceFileManager() {
  return (
    <FileManagerContainer
      deviceId="device-123"
      meshcentralAgentId="agent-456"
      hostname="production-server"
      organizationName="Acme Corp"
    />
  )
}
```

The component handles all file operations including navigation, search, upload/download with progress tracking, clipboard operations (copy/cut/paste), and modal-based file management actions. It automatically manages connection states and provides fallback UI (skeleton loading) during disconnected states.
