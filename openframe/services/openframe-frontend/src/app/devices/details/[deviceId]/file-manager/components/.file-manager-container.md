A React component that provides a complete file management interface for remote devices in the OpenFrame MSP platform, integrating with MeshCentral for secure file operations.

## Key Components

- **FileManagerContainer** - Main container component that orchestrates file operations
- **useMeshFileManager** - Custom hook for MeshCentral file operations
- **Modal Components** - NewFolderModal, RenameItemModal, DeleteConfirmationModal for user interactions
- **Progress Components** - Upload/download progress indicators with cancellation
- **Keyboard Shortcuts** - Full clipboard operations (Ctrl+C/X/V) and file management (Delete, Escape)

## Usage Example

```typescript
import { FileManagerContainer } from './file-manager-container'

export function DeviceFileManager() {
  return (
    <FileManagerContainer
      deviceId="device-123"
      meshcentralAgentId="agent-456"
      hostname="server-01.example.com"
      organizationName="Acme Corp"
    />
  )
}
```

## Features

- **Remote File Operations** - Browse, upload, download, create folders, rename, delete files
- **Search Functionality** - Search files with real-time filtering and results count
- **Multi-Selection** - Checkbox-based selection with select all/none capabilities
- **Clipboard Operations** - Copy, cut, paste files with visual feedback
- **Progress Tracking** - Real-time upload/download progress with cancellation
- **Navigation** - Breadcrumb navigation and back-to-device routing
- **Connection States** - Handles connecting, connected, and disconnected states with appropriate UI
- **Keyboard Shortcuts** - Standard file manager shortcuts (Ctrl+C/X/V, Delete, Escape)

The component provides a desktop-like file management experience for remote device administration through the OpenFrame platform.
