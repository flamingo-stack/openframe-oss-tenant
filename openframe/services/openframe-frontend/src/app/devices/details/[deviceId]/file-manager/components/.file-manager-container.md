A React container component that provides a complete file management interface for remote devices, integrating with MeshCentral agents to enable file operations, uploads, downloads, and navigation with keyboard shortcuts and progress indicators.

## Key Components

- **FileManagerContainer** - Main container component that orchestrates file management functionality
- **useMeshFileManager** - Custom hook for handling remote file operations via MeshCentral
- **Modal Components** - NewFolderModal, RenameItemModal, DeleteConfirmationModal for user interactions
- **Progress Overlays** - Fixed-position progress indicators for upload/download operations
- **Keyboard Shortcuts** - Ctrl+C/X/V for copy/cut/paste, Delete key, and Escape handling

## Usage Example

```typescript
import { FileManagerContainer } from './file-manager-container'

function DevicePage() {
  return (
    <FileManagerContainer
      deviceId="device-123"
      meshcentralAgentId="agent-456" 
      hostname="Production Server"
      organizationName="Acme Corp"
    />
  )
}
```

The component handles all file management operations including:
- Remote file browsing and navigation
- File upload/download with progress tracking  
- Search functionality across the remote filesystem
- File/folder creation, deletion, and renaming
- Clipboard operations (copy/cut/paste)
- Multi-file selection with keyboard shortcuts
- Connection state management and loading states
