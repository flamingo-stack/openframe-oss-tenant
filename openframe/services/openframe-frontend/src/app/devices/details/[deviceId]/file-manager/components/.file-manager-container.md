A React container component that provides a complete file manager interface for remote device file system access through MeshCentral agents. It handles file operations, keyboard shortcuts, and modal dialogs for file management tasks.

## Key Components

- **FileManagerContainer** - Main container component that orchestrates the file manager interface
- **useMeshFileManager** - Custom hook for MeshCentral file operations
- **Modal Components** - NewFolderModal, RenameItemModal, DeleteConfirmationModal for file operations
- **Progress Components** - Upload/download progress overlays with cancel functionality
- **Keyboard Shortcuts** - Ctrl+C/X/V for clipboard operations, Delete key, Escape key handling

## Usage Example

```typescript
import { FileManagerContainer } from './file-manager-container'

function DeviceFilesPage() {
  return (
    <FileManagerContainer
      deviceId="device-123"
      meshcentralAgentId="agent-456"
      hostname="Server-01"
      organizationName="Acme Corp"
    />
  )
}
```

The component provides a full-featured file manager with:
- File navigation and breadcrumbs
- Search functionality across the file system
- File upload/download with progress tracking
- Create folders, rename files/folders, delete operations
- Multi-file selection with checkboxes
- Clipboard operations (copy/cut/paste)
- Keyboard shortcuts for common operations
- Connection state handling and loading skeletons

The interface integrates with the MeshCentral system for remote file access and includes proper error handling and user feedback through modal dialogs and progress indicators.
