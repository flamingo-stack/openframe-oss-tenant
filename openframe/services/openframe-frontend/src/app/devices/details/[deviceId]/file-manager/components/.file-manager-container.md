A React container component that provides a complete file management interface for remote devices, handling file operations, navigation, and modal interactions.

## Key Components

- **FileManagerContainer**: Main container component that orchestrates file management functionality
- **Modal Components**: NewFolderModal, RenameItemModal, DeleteConfirmationModal for user interactions
- **Progress Overlays**: Upload and download progress indicators with cancellation options
- **Keyboard Shortcuts**: Ctrl+C/X/V for copy/cut/paste, Delete key, and Escape handling
- **Search Integration**: File search with query state management
- **Connection State Handling**: Shows skeleton loader during connection establishment

## Usage Example

```typescript
import { FileManagerContainer } from './file-manager-container'

function DeviceFileManager() {
  return (
    <FileManagerContainer
      deviceId="device-123"
      meshcentralAgentId="agent-456"
      hostname="workstation-01"
      organizationName="Acme Corp"
    />
  )
}

// The component automatically handles:
// - File upload/download with progress tracking
// - Folder creation and navigation
// - File/folder rename and deletion
// - Search functionality across the file system
// - Keyboard shortcuts for common operations
// - Connection state management and loading states
```

The component integrates with the `useMeshFileManager` hook to provide comprehensive remote file system access, including clipboard operations, batch file selection, and real-time progress feedback for file transfers.
