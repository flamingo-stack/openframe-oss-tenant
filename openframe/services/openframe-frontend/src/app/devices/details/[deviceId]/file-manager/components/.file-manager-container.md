A React container component that provides remote file management capabilities through MeshCentral integration. It wraps the core FileManager component with device-specific state management, modal dialogs, and file operations handling.

## Key Components

**Main Export:**
- `FileManagerContainer` - Main container component with device connection and file operations

**Modal Components:**
- `NewFolderModal` - Dialog for creating new folders
- `RenameItemModal` - Dialog for renaming files/folders  
- `DeleteConfirmationModal` - Confirmation dialog for deletions

**Key Features:**
- Remote file system navigation via MeshCentral
- File upload/download with progress indicators
- Search functionality across directories
- Keyboard shortcuts (Ctrl+C, Ctrl+V, Delete, Escape)
- Clipboard operations (copy/cut/paste)
- Multi-file selection and batch operations

## Usage Example

```typescript
import { FileManagerContainer } from './file-manager-container'

function DeviceFileManager() {
  return (
    <FileManagerContainer
      deviceId="device-123"
      meshcentralAgentId="agent-456"
      hostname="server.example.com"
      organizationName="My Organization"
    />
  )
}

// The component handles all file operations internally:
// - Navigate: Click folders or use breadcrumbs
// - Upload: Click upload button or drag files
// - Download: Right-click file → Download
// - Create folder: Click "New Folder" button
// - Rename: Right-click → Rename
// - Delete: Select files → Press Delete key or right-click → Delete
// - Search: Use search bar (searches current directory and subdirectories)
// - Clipboard: Ctrl+C to copy, Ctrl+X to cut, Ctrl+V to paste
```

The component integrates with the `useMeshFileManager` hook to provide real-time file system access through MeshCentral's remote desktop protocol, displaying connection status and handling network interruptions gracefully.
