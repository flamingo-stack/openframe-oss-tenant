A React container component that provides a complete file management interface for remote devices using MeshCentral integration. It wraps the core FileManager component with device-specific functionality, modals, and progress tracking for file operations.

## Key Components

**Main Export:**
- `FileManagerContainer` - Primary container component with full file management capabilities

**Props Interface:**
- `FileManagerContainerProps` - Defines required device connection parameters

**Key Features:**
- Remote file system navigation and operations
- File upload/download with progress tracking
- Search functionality with real-time results
- Keyboard shortcuts for common operations (Ctrl+C, Ctrl+V, Delete, Escape)
- Modal dialogs for folder creation, renaming, and deletion confirmation
- Connection state management with skeleton loading

**Modal Components:**
- `NewFolderModal` - Folder creation dialog
- `RenameItemModal` - File/folder renaming dialog  
- `DeleteConfirmationModal` - Deletion confirmation dialog

## Usage Example

```typescript
import { FileManagerContainer } from './file-manager-container'

export function DeviceFileManager() {
  return (
    <FileManagerContainer
      deviceId="device-123"
      meshcentralAgentId="agent-456"
      hostname="workstation-01"
      organizationName="ACME Corp"
    />
  )
}

// Navigate to file manager from device details
const router = useRouter()
router.push(`/devices/file-manager/${deviceId}`)
```

The component integrates with the `useMeshFileManager` hook to provide seamless remote file system access, automatically handles connection states, and provides a consistent UI experience with progress indicators and keyboard navigation support.
