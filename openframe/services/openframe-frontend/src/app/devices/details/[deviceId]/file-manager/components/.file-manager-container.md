A React container component that provides a complete file management interface for remote MeshCentral devices. It orchestrates file operations, keyboard shortcuts, and modal interactions while handling connection states and progress tracking.

## Key Components

- **FileManagerContainer**: Main container component that wraps the FileManager UI
- **useMeshFileManager**: Custom hook providing file operations and state management
- **Modal Components**: NewFolderModal, RenameItemModal, DeleteConfirmationModal for user interactions
- **Progress Tracking**: Real-time upload/download progress displays with cancellation
- **Keyboard Shortcuts**: Copy (Ctrl+C), Cut (Ctrl+X), Paste (Ctrl+V), Delete, and Escape handling

## Usage Example

```typescript
import { FileManagerContainer } from './file-manager-container'

// Basic usage for device file management
<FileManagerContainer
  deviceId="device-123"
  meshcentralAgentId="agent-456"
  hostname="my-device"
  organizationName="My Org"
/>
```

The component handles all file operations including navigation, search, upload/download with progress tracking, and provides keyboard shortcuts for common actions. It automatically shows loading states and connection status while managing modal dialogs for folder creation, renaming, and deletion confirmation.
