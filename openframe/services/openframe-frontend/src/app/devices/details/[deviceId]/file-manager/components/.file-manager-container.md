A React client-side container component that provides a complete file management interface for remote devices using MeshCentral integration. It orchestrates file operations, modals, progress tracking, and keyboard shortcuts through the `useMeshFileManager` hook.

## Key Components

- **FileManagerContainer**: Main container component that renders the file manager interface
- **Modal Management**: Handles new folder creation, file renaming, and delete confirmation modals
- **Progress Tracking**: Displays upload/download progress with cancellation options
- **Keyboard Shortcuts**: Supports Ctrl+C/X/V for copy/cut/paste, Delete key, and Escape
- **File Operations**: Upload, download, rename, delete, create folder, and clipboard operations
- **Search Functionality**: Real-time file search with query management
- **Navigation**: Breadcrumb navigation and path management

## Usage Example

```typescript
import { FileManagerContainer } from './file-manager-container'

// Basic usage in a device details page
function DevicePage({ deviceId }: { deviceId: string }) {
  return (
    <FileManagerContainer
      deviceId="device-123"
      meshcentralAgentId="agent-456"
      hostname="prod-server-01"
      organizationName="Acme Corp"
    />
  )
}
```

The component automatically handles connection states, shows loading skeletons during connection, and provides a complete file management experience with drag-and-drop support, multi-file selection, and real-time progress feedback.
