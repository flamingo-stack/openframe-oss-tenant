A Next.js page component that provides remote shell access to devices through MeshCentral, featuring an xterm.js terminal with support for both Command Prompt and PowerShell on Windows systems.

## Key Components

- **RemoteShellPage** - Main page component handling device shell connections
- **MeshControlClient** - Client for MeshCentral authentication and session management
- **MeshTunnel** - WebSocket tunnel for terminal data transmission
- **Terminal Integration** - xterm.js terminal with fit addon for responsive sizing
- **Device Management** - Device details fetching and validation
- **Shell Type Support** - Configurable CMD or PowerShell execution

## Usage Example

```typescript
// Navigate to remote shell page
router.push(`/devices/shell/${deviceId}?shellType=powershell`)

// Component automatically:
// 1. Fetches device details and MeshCentral agent ID
// 2. Initializes xterm.js terminal with fit addon
// 3. Establishes MeshCentral tunnel connection
// 4. Handles terminal resize and data transmission
// 5. Auto-launches PowerShell if specified

// Terminal states
const states = {
  0: 'Idle',
  1: 'Connecting', 
  2: 'Open',
  3: 'Connected'
}
```

## Features

- **Responsive Terminal** - Auto-resizing terminal with proper font rendering
- **Connection Management** - Real-time connection status and error handling  
- **Shell Selection** - Support for Windows CMD and PowerShell environments
- **Loading States** - Skeleton UI during device loading and connection establishment
- **Error Handling** - Graceful fallbacks for missing agents or connection failures
- **Navigation** - Breadcrumb navigation back to device details

The component uses React hooks for state management, integrates with the app's toast system for notifications, and provides a full-featured terminal experience within the OpenFrame platform.
