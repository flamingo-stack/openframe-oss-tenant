A Next.js page component that provides a web-based remote shell interface for connecting to devices through MeshCentral, supporting both Command Prompt and PowerShell sessions.

## Key Components

- **RemoteShellPage**: Main React component that renders the terminal interface
- **MeshTunnel**: Handles WebSocket communication with MeshCentral agent
- **MeshControlClient**: Manages authentication and session control
- **Terminal Integration**: Uses xterm.js for terminal emulation with fit addon
- **Device Management**: Fetches device details and validates MeshCentral connectivity
- **State Management**: Tracks connection status, shell type, and data flow

## Usage Example

```typescript
// URL structure for accessing remote shell
// /devices/remote-shell/[deviceId]?shellType=powershell

// Component handles automatic PowerShell initialization
const WINDOWS_POWERSHELL_CMD = 'powershell -NoLogo -NoProfile 2>nul || ...'

// Terminal lifecycle management
useEffect(() => {
  const term = new Terminal({
    fontFamily: 'monospace',
    theme: { background: '#000000' },
    cursorBlink: true
  })
  
  const fit = new FitAddon()
  term.loadAddon(fit)
  term.open(containerRef.current)
  
  return () => term.dispose()
}, [])

// MeshCentral tunnel connection
const tunnel = new MeshTunnel({
  authCookie,
  nodeId: meshcentralAgentId,
  protocol: 1,
  onData: (data) => term.write(data),
  onStateChange: (state) => setState(state)
})
```

The component provides loading states, error handling for missing MeshCentral agents, connection status indicators, and automatic cleanup on navigation.
