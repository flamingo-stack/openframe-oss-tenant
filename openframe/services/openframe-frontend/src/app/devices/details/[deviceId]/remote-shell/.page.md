A Next.js page component that provides a web-based remote shell interface for devices managed through MeshCentral. It supports both Windows Command Prompt and PowerShell terminal sessions with real-time bidirectional communication.

## Key Components

**Main Component**: `RemoteShellPage` - The primary page component handling remote terminal sessions
**Dependencies**: 
- `MeshControlClient` - Manages MeshCentral authentication and control messages
- `MeshTunnel` - Handles WebSocket tunneling for terminal data
- `Terminal` (xterm.js) - Provides the terminal interface
- `useDeviceDetails` - Hook for fetching device information

**Key Features**:
- Real-time terminal with xterm.js
- Auto-switching between CMD and PowerShell
- WebSocket-based data tunneling
- Responsive terminal sizing
- Connection state management

## Usage Example

```typescript
// URL structure for accessing the remote shell
// /devices/shell/[deviceId]?shellType=powershell
// /devices/shell/[deviceId]?shellType=cmd

// Component handles device resolution and MeshCentral connection
export default function RemoteShellPage({ params }: RemoteShellPageProps) {
  const resolvedParams = use(params)
  const deviceId = resolvedParams.deviceId
  
  // Automatically detects shell type from URL parameters
  const shellType = useMemo<'cmd' | 'powershell'>(() => {
    return shellTypeParam === 'powershell' ? 'powershell' : 'cmd'
  }, [shellTypeParam])
}

// Terminal initialization with proper cleanup
useEffect(() => {
  const term = new Terminal({
    fontFamily: 'monospace',
    theme: { background: '#000000' },
    cursorBlink: true
  })
  
  // Handles bidirectional data flow
  term.onData((data: string) => 
    tunnelRef.current?.sendBinary(new TextEncoder().encode(data))
  )
}, [isPageReady])
```

The component includes comprehensive error handling, loading states, and automatic PowerShell command injection for Windows systems. It maintains secure WebSocket connections through MeshCentral's authentication system.
