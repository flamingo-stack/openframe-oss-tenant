This Next.js page component provides a remote shell interface for connecting to devices through MeshCentral, enabling terminal access with support for both CMD and PowerShell on Windows systems.

## Key Components

- **RemoteShellPage**: Main page component that manages the remote shell connection
- **MeshControlClient**: Handles MeshCentral authentication and session management
- **MeshTunnel**: Manages the WebSocket tunnel for terminal communication
- **Terminal Integration**: Uses xterm.js with FitAddon for terminal rendering
- **Device Management**: Integrates with device details and organization context

## Usage Example

```typescript
// URL structure for accessing remote shell
// /devices/remote-shell/[deviceId]?shellType=powershell

// The component automatically:
// 1. Fetches device details by ID
// 2. Establishes MeshCentral connection
// 3. Creates terminal tunnel
// 4. Handles shell type (cmd/powershell)

// Key features:
// - Auto-detects MeshCentral agent ID from device tool connections
// - Supports both CMD and PowerShell shells
// - Real-time terminal interaction with resize support
// - Connection state management and error handling
// - Loading states and error boundaries
```

The component handles the complete lifecycle of a remote shell session, from device validation and MeshCentral authentication to terminal rendering and bidirectional communication. It includes comprehensive error handling for missing agents, connection failures, and provides visual feedback for connection states.
