A Next.js page component that provides remote shell access to devices through MeshCentral, supporting both CMD and PowerShell terminal sessions with real-time WebSocket communication.

## Key Components

- **RemoteShellPage**: Main page component with terminal interface and device connection management
- **MeshControlClient**: Handles MeshCentral authentication and session management
- **MeshTunnel**: Manages WebSocket tunnel for terminal data transmission
- **Terminal Integration**: Uses xterm.js for terminal rendering with fit addon for responsive sizing
- **Device Details Hook**: Fetches device information and MeshCentral agent details

## Usage Example

```typescript
// URL parameters and search params
// /devices/remote-shell/[deviceId]?shellType=powershell

// The component automatically:
// 1. Fetches device details by ID
// 2. Establishes MeshCentral connection
// 3. Creates terminal session
// 4. Handles shell type selection (cmd/powershell)

// Terminal states managed through TunnelState enum:
// 0: Idle, 1: Connecting, 2: Open, 3: Connected

// PowerShell auto-launch command constant
const WINDOWS_POWERSHELL_CMD = 'powershell -NoLogo -NoProfile 2>nul || ...'
```

The page includes loading states, error handling for missing MeshCentral agents, and responsive terminal sizing. It automatically launches PowerShell when the shell type parameter is set to 'powershell' and provides disconnect functionality with navigation back to device details.
