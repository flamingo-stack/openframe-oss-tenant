A Next.js page component that provides a web-based remote shell interface for devices using MeshCentral tunneling. The component establishes secure terminal connections to remote devices and supports both Command Prompt and PowerShell sessions.

## Key Components

- **RemoteShellPage** - Main page component handling device shell connections
- **MeshTunnel** - WebSocket tunnel for terminal communication
- **MeshControlClient** - MeshCentral authentication and session management
- **Terminal Integration** - xterm.js terminal with fit addon for responsive display
- **Device Management** - Device details fetching and validation
- **State Management** - Connection state tracking and error handling

## Usage Example

```typescript
// URL structure for accessing remote shell
// /devices/shell/[deviceId]?shellType=powershell

// Component automatically:
// 1. Fetches device details and validates MeshCentral agent
// 2. Initializes xterm.js terminal with proper sizing
// 3. Establishes secure tunnel connection
// 4. Handles PowerShell initialization if specified
// 5. Manages real-time terminal data exchange

// Shell type configuration
const shellCommands = {
  cmd: 'cmd.exe',
  powershell: 'powershell -NoLogo -NoProfile'
}

// Connection states
enum TunnelState {
  Idle = 0,
  Connecting = 1, 
  Open = 2,
  Connected = 3
}
```

The component includes comprehensive error handling for missing MeshCentral agents, connection failures, and device loading states. It features a responsive terminal interface with proper cleanup on unmount and supports both Windows Command Prompt and PowerShell environments.
