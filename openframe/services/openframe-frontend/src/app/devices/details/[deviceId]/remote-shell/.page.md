A Next.js page component that provides a web-based remote shell interface for devices using MeshCentral tunneling. It renders an xterm.js terminal with real-time communication to remote devices through WebSocket tunnels.

## Key Components

- **RemoteShellPage**: Main component handling terminal initialization and device connection
- **MeshTunnel**: WebSocket tunnel for bidirectional terminal communication
- **MeshControlClient**: Authentication and session management for MeshCentral
- **Terminal Integration**: xterm.js terminal with fit addon for responsive sizing
- **Device Management**: Fetches device details and validates MeshCentral agent availability

## Usage Example

```typescript
// Route: /devices/remote-shell/[deviceId]?shellType=powershell
// Component automatically handles:
// - Device validation and MeshCentral agent detection
// - Terminal initialization with proper theming
// - PowerShell vs CMD shell type selection
// - Real-time bidirectional terminal communication

// Key features:
// - Auto-resizing terminal that syncs with remote session
// - PowerShell command injection for Windows devices
// - Connection state management and error handling
// - Loading states and skeleton UI during initialization
```

The component manages complex state including terminal lifecycle, tunnel connections, and PowerShell command injection. It provides comprehensive error handling for missing agents, connection failures, and device loading states. The terminal supports full keyboard interaction and automatically handles window resizing events.
