A Next.js page component that provides a remote shell interface for devices through MeshCentral tunneling. It renders an interactive terminal using xterm.js and handles real-time communication with remote devices.

## Key Components

- **RemoteShellPage** - Main page component that manages the remote shell interface
- **MeshControlClient** - Handles MeshCentral authentication and session management
- **MeshTunnel** - Manages the WebSocket tunnel for terminal communication
- **Terminal Integration** - Uses xterm.js with FitAddon for the terminal UI
- **Device Details Hook** - Fetches and manages device information
- **Shell Type Support** - Supports both CMD and PowerShell terminals on Windows

## Usage Example

```typescript
// The page is accessed via Next.js routing
// URL: /devices/[deviceId]/shell?shellType=powershell

// Key props and state management
const { deviceDetails, isLoading, error, fetchDeviceById } = useDeviceDetails()
const shellType = useMemo<'cmd' | 'powershell'>(() => {
  return shellTypeParam === 'powershell' ? 'powershell' : 'cmd'
}, [shellTypeParam])

// Terminal initialization with xterm.js
const term = new Terminal({
  fontFamily: 'monospace',
  theme: { background: '#000000' },
  cursorBlink: true
})

// MeshCentral tunnel setup
const tunnel = new MeshTunnel({
  authCookie,
  nodeId: meshcentralAgentId,
  protocol: 1,
  options: { cols: term.cols, rows: term.rows },
  onData: (data) => term.write(data),
  onStateChange: (state) => setState(state)
})
```

The component handles loading states, error conditions, and provides a full-screen terminal interface with connection status indicators and device information display.
