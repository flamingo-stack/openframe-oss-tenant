A Next.js client component that provides a web-based remote shell interface for devices through MeshCentral, supporting both Command Prompt and PowerShell connections with real-time terminal emulation.

## Key Components

- **RemoteShellPage**: Main React component handling terminal connection and UI
- **MeshControlClient**: WebSocket client for MeshCentral authentication and session management
- **MeshTunnel**: Tunnel handler for bidirectional terminal data communication
- **Terminal Integration**: xterm.js terminal with fit addon for responsive display
- **Device Management**: Integration with device details hook for hostname and organization info

## Usage Example

```typescript
// URL routing for different shell types
/devices/shell/[deviceId]?shellType=cmd        // Command Prompt
/devices/shell/[deviceId]?shellType=powershell // PowerShell

// Component handles automatic PowerShell initialization
const WINDOWS_POWERSHELL_CMD = 'powershell -NoLogo -NoProfile 2>nul || ...'

// Terminal setup with xterm.js
const term = new Terminal({
  fontFamily: 'monospace',
  theme: { background: '#000000' },
  cursorBlink: true
})
const fit = new FitAddon()
term.loadAddon(fit)
```

The component manages the complete terminal lifecycle including connection establishment, data streaming, window resizing, and cleanup. It provides loading states, error handling, and requires MeshCentral agent connectivity for device access.
