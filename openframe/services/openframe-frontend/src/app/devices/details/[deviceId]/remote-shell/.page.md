A Next.js page component that provides a web-based remote shell interface for devices through MeshCentral tunneling. It renders an xterm.js terminal with real-time command execution capabilities and supports both PowerShell and Command Prompt shells.

## Key Components

- **RemoteShellPage** - Main page component handling device shell connections
- **MeshControlClient** - Client for MeshCentral authentication and session management
- **MeshTunnel** - WebSocket tunnel for real-time terminal communication
- **Terminal Integration** - xterm.js terminal with fit addon for responsive sizing
- **Device Management** - Device details fetching and validation
- **State Management** - Connection states, loading states, and error handling

## Usage Example

```typescript
// URL structure for accessing remote shell
// /devices/remote-shell/[deviceId]?shellType=powershell
// /devices/remote-shell/[deviceId]?shellType=cmd

// Component handles device validation automatically
const device = await fetchDeviceById(deviceId)

// MeshCentral tunnel configuration
const tunnel = new MeshTunnel({
  authCookie,
  nodeId: meshcentralAgentId,
  protocol: 1,
  options: { cols: term.cols, rows: term.rows },
  onData: (data) => term.write(data),
  onStateChange: (state) => setState(state)
})

// Terminal setup with xterm.js
const terminal = new Terminal({
  fontFamily: 'monospace',
  theme: { background: '#000000' },
  cursorBlink: true
})
```

The component automatically establishes MeshCentral connections, initializes the terminal interface, handles PowerShell command injection for Windows systems, and provides real-time bidirectional communication between the web interface and remote device shells.
