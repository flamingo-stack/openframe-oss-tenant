A Next.js page component that provides a web-based remote shell interface for devices through MeshCentral tunneling, supporting both Command Prompt and PowerShell connections with real-time terminal emulation.

## Key Components

- **RemoteShellPage** - Main page component handling device shell connections
- **MeshControlClient** - Client for MeshCentral authentication and session management
- **MeshTunnel** - WebSocket tunnel for bidirectional shell communication
- **Terminal Integration** - xterm.js terminal with fit addon for responsive display
- **Device Management** - Integration with device details and organization context

## Usage Example

```typescript
// URL-based shell type selection
// /devices/[deviceId]/shell?shellType=powershell - Opens PowerShell
// /devices/[deviceId]/shell?shellType=cmd - Opens Command Prompt (default)

// Component renders automatically based on route parameters
export default function RemoteShellPage({ 
  params: Promise<{ deviceId: string }> 
}) {
  // Handles device lookup, MeshCentral connection, and terminal setup
}
```

The component features comprehensive error handling for missing MeshCentral agents, device loading states, and connection failures. It automatically switches to PowerShell when specified via URL parameters and provides visual feedback for connection status. The terminal supports full keyboard interaction, proper resizing, and real-time data streaming through secure WebSocket tunnels.

Key features include loading skeletons, connection status indicators, automatic PowerShell command execution, and graceful cleanup of resources when navigating away from the page.
