This file implements a remote terminal interface for connecting to devices through MeshCentral, providing both Command Prompt and PowerShell access with real-time terminal interaction.

## Key Components

- **RemoteShellPage**: Main React component that manages the terminal interface and connection state
- **MeshCentral Integration**: Uses `MeshControlClient` and `MeshTunnel` for establishing secure device connections
- **XTerm Terminal**: Implements a full-featured terminal using xterm.js with fit addon for responsive sizing
- **State Management**: Handles connection states, shell types (cmd/powershell), and terminal lifecycle
- **Device Integration**: Fetches device details and validates MeshCentral agent availability

## Usage Example

```typescript
// Route: /devices/[deviceId]/shell?shellType=powershell
// The component automatically:
// 1. Loads device details and validates MeshCentral agent
// 2. Initializes xterm.js terminal with proper theming
// 3. Establishes secure tunnel connection
// 4. Handles PowerShell initialization if specified
// 5. Manages real-time bidirectional data flow

// Key features:
// - Responsive terminal sizing
// - Connection state indicators
// - Automatic PowerShell command execution
// - Error handling and loading states
// - Clean disconnect and cleanup
```

The component provides a complete remote shell experience with proper error handling, loading states, and automatic cleanup when navigating away or disconnecting from the remote session.
