A Next.js page component that provides a remote shell interface for devices using MeshCentral tunneling and xterm.js terminal emulation. This component enables real-time command execution on remote devices through a web-based terminal interface.

## Key Components

- **RemoteShellPage**: Main page component that renders the terminal interface
- **MeshControlClient**: Client for establishing MeshCentral authentication and control
- **MeshTunnel**: WebSocket tunnel for bi-directional terminal communication
- **Terminal Integration**: xterm.js terminal with FitAddon for responsive sizing
- **Device State Management**: Handles device loading, error states, and connection status

## Usage Example

The page is accessed via dynamic routing with device ID and optional shell type:

```typescript
// URL structure
/devices/[deviceId]/remote-shell?shellType=powershell

// Component handles both cmd and powershell shells
const shellType = useMemo<'cmd' | 'powershell'>(() => {
  return shellTypeParam === 'powershell' ? 'powershell' : 'cmd'
}, [shellTypeParam])

// Terminal initialization with MeshCentral tunnel
const tunnel = new MeshTunnel({
  authCookie,
  nodeId: meshcentralAgentId,
  protocol: 1,
  options: { cols: term.cols, rows: term.rows },
  onData: (data) => {
    if (typeof data === 'string') term.write(data)
    else term.write(new TextDecoder().decode(data))
  }
})
```

The component automatically detects PowerShell availability on Windows systems and provides real-time terminal interaction with proper cleanup on component unmount.
