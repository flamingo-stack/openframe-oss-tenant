A Next.js page component that provides a web-based remote shell terminal interface for devices through MeshCentral connections. It supports both Command Prompt and PowerShell sessions with real-time terminal interaction.

## Key Components

- **RemoteShellPage** - Main page component handling device shell connections
- **MeshControlClient** - Client for MeshCentral authentication and control
- **MeshTunnel** - WebSocket tunnel for terminal data transmission
- **Terminal Integration** - xterm.js terminal with fit addon for responsive display
- **Device Management** - Hook integration for device details and validation

## Usage Example

```typescript
// Page is automatically routed via Next.js file-based routing
// URL: /devices/remote-shell/[deviceId]?shellType=powershell

// The component handles:
// - Device authentication via MeshCentral
// - Terminal initialization and rendering
// - Real-time data streaming
// - Shell type selection (cmd/powershell)

// Key features:
const features = {
  shellTypes: ['cmd', 'powershell'], // Supported shell types
  terminalFeatures: ['resize', 'copy-paste', 'color-support'],
  connectionStates: ['Idle', 'Connecting', 'Open', 'Connected']
}

// Usage in routing:
// Navigate to: `/devices/remote-shell/${deviceId}?shellType=powershell`
```

The component provides comprehensive error handling for missing MeshCentral agents, device loading failures, and connection issues. It includes a responsive terminal interface with automatic PowerShell command injection for Windows systems and proper cleanup on component unmount.
