A Next.js page component that provides remote desktop functionality for managing devices through MeshCentral integration, featuring real-time connection management, input controls, and device power actions.

## Key Components

- **RemoteDesktopPage**: Main page component handling device connection and remote desktop display
- **MeshCentral Integration**: Uses `MeshControlClient`, `MeshTunnel`, and `MeshDesktop` for remote connectivity
- **Device Management**: Supports both legacy device data and modern device fetching via `useDeviceDetails`
- **Settings Modal**: Remote desktop configuration through `RemoteSettingsModal`
- **Actions Menu**: Power controls and keyboard shortcuts via `ActionsMenu`
- **Display Management**: Multi-monitor support with display switching capabilities

## Usage Example

```typescript
// The component is used as a Next.js page route
// URL pattern: /devices/remote-desktop/[deviceId]

// With legacy device data (backward compatibility)
const legacyUrl = "/devices/remote-desktop/device123?deviceData=" + 
  encodeURIComponent(JSON.stringify({
    id: "device123",
    meshcentralAgentId: "agent456",
    hostname: "workstation01"
  }))

// Modern usage (fetches device data internally)
const modernUrl = "/devices/remote-desktop/device123"

// Key features:
// - Real-time remote desktop connection via WebSocket tunnel
// - Power management (wake, sleep, reset, poweroff)
// - Keyboard shortcuts (Ctrl+Alt+Del, Win+R, etc.)
// - Multi-display support with switching
// - Connection state monitoring and auto-reconnection
// - Settings configuration for display quality and input modes
```

The component manages connection lifecycle, handles reconnection attempts, and provides comprehensive remote desktop controls with toast notifications for user feedback.
