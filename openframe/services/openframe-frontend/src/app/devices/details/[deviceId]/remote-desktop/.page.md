This Next.js page component provides a comprehensive remote desktop interface for device management using MeshCentral integration. It handles device connection, screen sharing, input control, and various remote management features with backward compatibility support.

## Key Components

- **Remote Desktop Connection**: Manages MeshCentral tunnel and desktop streaming via `MeshTunnel` and `MeshDesktop`
- **Device Data Management**: Supports both legacy query parameters and modern device API fetching
- **Real-time Controls**: Keyboard input, mouse control, display switching, and power management
- **Connection State Management**: Handles connecting, reconnecting, and error states with user feedback
- **Settings Integration**: Remote desktop configuration via `RemoteSettingsModal`
- **Actions Menu**: Power controls, keyboard shortcuts, and display management

## Usage Example

```typescript
// Render the remote desktop page
<RemoteDesktopPage 
  params={Promise.resolve({ deviceId: "device-123" })} 
/>

// The component automatically handles:
// - Device data fetching or legacy parameter parsing
// - MeshCentral tunnel establishment
// - Desktop streaming to HTML5 canvas
// - User input forwarding
// - Connection state management

// Key user interactions:
// - Canvas displays remote screen
// - Mouse/keyboard input forwarded when enabled
// - Power actions via actions menu
// - Display switching for multi-monitor setups
// - Settings modal for configuration
```

The component uses refs for managing WebRTC connections and canvas rendering, while useState handles UI state like connection status, settings modals, and display selection. It includes comprehensive error handling, reconnection logic, and toast notifications for user feedback.
