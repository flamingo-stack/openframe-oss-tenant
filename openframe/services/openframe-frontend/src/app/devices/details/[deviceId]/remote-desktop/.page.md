This React component provides a remote desktop viewer interface using MeshCentral for device control through WebRTC tunneling.

## Key Components

- **RemoteDesktopPage**: Main component that handles remote desktop connection and control
- **MeshControlClient**: Client for MeshCentral authentication and control operations
- **MeshTunnel**: WebRTC tunnel for real-time desktop streaming
- **MeshDesktop**: Canvas-based desktop rendering and input handling
- **RemoteSettingsModal**: Configuration modal for display and input settings
- **ActionsMenu**: Dropdown menu with power actions and keyboard shortcuts

## Core Features

- **Real-time Desktop Streaming**: Canvas-based remote desktop with WebRTC
- **Input Control**: Keyboard/mouse input forwarding with view-only mode
- **Multi-display Support**: Switch between multiple displays on remote device
- **Power Management**: Wake, sleep, reset, and shutdown commands
- **Keyboard Shortcuts**: Ctrl+Alt+Del, Windows key combinations
- **Connection Management**: Auto-reconnection with status indicators
- **Legacy Compatibility**: Backward compatibility with URL-based device data

## Usage Example

```typescript
// Navigate to remote desktop
router.push(`/devices/remote-desktop/${deviceId}`)

// With legacy device data (backward compatibility)
const deviceData = { 
  id: 'device123', 
  meshcentralAgentId: 'agent456',
  hostname: 'workstation-01' 
}
router.push(`/devices/remote-desktop/${deviceId}?deviceData=${encodeURIComponent(JSON.stringify(deviceData))}`)

// Component handles both modern device API and legacy URL params
<RemoteDesktopPage params={Promise.resolve({ deviceId: "device123" })} />
```

The component manages complex state for tunnel connections, display switching, and real-time video streaming while providing a responsive interface for remote device control.
