A React component page that implements a remote desktop client interface using MeshCentral for device remote access functionality.

## Key Components

**Main Component:**
- `RemoteDesktopPage` - Primary page component handling remote desktop connections

**State Management:**
- Connection state tracking (`TunnelState`, reconnection handling)
- Remote desktop settings configuration
- Display management (multi-monitor support)
- Input control and canvas rendering

**Core Classes:**
- `MeshControlClient` - Handles MeshCentral authentication and control commands
- `MeshTunnel` - WebSocket tunnel for binary data transmission
- `MeshDesktop` - Canvas-based desktop rendering and interaction

**UI Components:**
- Canvas for desktop display
- Settings modal for configuration
- Actions menu for power and keyboard shortcuts
- Connection status indicators
