A Next.js page component that provides a complete remote desktop interface for connecting to devices through MeshCentral, featuring real-time screen sharing, input controls, and device management capabilities.

## Key Components

- **RemoteDesktopPage** - Main page component handling device connection and remote desktop functionality
- **MeshControlClient** - Client for MeshCentral API operations and power actions
- **MeshTunnel** - WebSocket tunnel for real-time desktop data transmission
- **MeshDesktop** - Canvas-based desktop rendering and input handling
- **RemoteSettingsModal** - Configuration interface for display and connection settings
- **State Management** - Connection status, reconnection logic, and display switching
- **Input Controls** - Mouse, keyboard, and special key combination handling

## Usage Example

```typescript
// Page route: /devices/[deviceId]/remote-desktop
// Access via: /devices/123/remote-desktop

// Legacy compatibility with query params
const url = '/devices/123/remote-desktop?deviceData=' + encodeURIComponent(JSON.stringify({
  id: '123',
  meshcentralAgentId: 'agent-id',
  hostname: 'workstation-01'
}))

// Modern usage (fetches device data internally)
router.push(`/devices/${deviceId}/remote-desktop`)

// Key interactions
const sendPowerAction = async () => {
  await sendPower('reset') // 'wake', 'sleep', 'reset', 'poweroff'
}

const sendSpecialKeys = () => {
  sendCtrlAltDel() // Windows security screen
  sendKeyCombo([0x5B, 0x4C]) // Win+L (lock screen)
}

const switchDisplay = () => {
  handleDisplayChange(1) // Switch to display ID 1
}
```

The component provides comprehensive remote desktop functionality including connection management, input forwarding, display switching, power controls, and real-time status monitoring with automatic reconnection capabilities.
