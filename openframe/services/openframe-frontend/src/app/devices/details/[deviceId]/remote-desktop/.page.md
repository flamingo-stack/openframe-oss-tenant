A Next.js page component that implements a remote desktop interface using MeshCentral, providing full desktop access and control capabilities for remote devices.

## Key Components

- **RemoteDesktopPage**: Main page component handling device connection and remote desktop session
- **Device Data Management**: Supports both legacy URL parameters and internal device fetching
- **MeshCentral Integration**: Uses `MeshControlClient`, `MeshTunnel`, and `MeshDesktop` for remote access
- **Connection State Management**: Handles tunnel states, reconnection attempts, and error handling
- **Desktop Control Features**: Power actions, key combinations, display switching, and input management
- **Settings Modal**: Configurable remote desktop settings via `RemoteSettingsModal`
- **Actions Menu**: Contextual actions for desktop control and device management

## Usage Example

```typescript
// Page is accessed via Next.js routing
// URL: /devices/[deviceId]/remote-desktop

// Legacy backward compatibility with deviceData query param
const legacyUrl = `/devices/123/remote-desktop?deviceData=${encodeURIComponent(JSON.stringify({
  id: '123',
  meshcentralAgentId: 'agent-123',
  hostname: 'device-hostname',
  organization: 'Acme Corp'
}))}`

// Modern usage - fetches device data internally
const modernUrl = `/devices/123/remote-desktop`

// Key functionality includes:
// - Real-time desktop streaming via HTML5 canvas
// - Mouse and keyboard input forwarding
// - Multiple display support
// - Power management (wake, sleep, reset, poweroff)
// - Configurable connection settings
// - Automatic reconnection handling
```

The component provides a complete remote desktop solution with robust error handling, connection management, and user-friendly controls for IT support scenarios.
