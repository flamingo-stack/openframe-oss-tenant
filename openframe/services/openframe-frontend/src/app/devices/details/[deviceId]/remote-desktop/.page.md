This file implements a remote desktop client page that connects to devices through MeshCentral for remote access and control. It provides a full-featured remote desktop interface with power management, display switching, and customizable settings.

## Key Components

### Core Classes
- **MeshControlClient** - Handles authentication and control commands
- **MeshTunnel** - Manages WebSocket connection for remote desktop data
- **MeshDesktop** - Renders remote desktop frames on HTML canvas
- **RemoteDesktopSettings** - Manages connection quality and display settings

### State Management
- **Connection States** - Tracks tunnel connection status (Idle/Connecting/Open/Connected)
- **Device Resolution** - Supports both legacy URL params and modern device API
- **Display Management** - Handles multiple monitor setups with switching capability
- **Reconnection Logic** - Automatic reconnection with user feedback

### Key Features
- **Power Management** - Wake, sleep, reset, and shutdown commands
- **Keyboard Input** - Key combinations and Ctrl+Alt+Del support
- **Settings Modal** - Configurable quality, compression, and display options
- **Multi-Display** - Support for multiple monitors with switching
