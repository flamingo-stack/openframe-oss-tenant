This is a Next.js page component that provides remote desktop functionality through MeshCentral integration. It manages WebRTC connections, input handling, display switching, and power controls for remote device access.

## Key Components

- **RemoteDesktopPageProps**: Interface defining page parameters with device ID
- **State Management**: Multiple useState hooks for connection state, settings, displays, and UI state
- **Core References**: useRef hooks for canvas element, desktop client, tunnel, and control instances
- **Device Data**: Legacy device data parsing and modern device details fetching with backward compatibility
- **Connection Management**: Automatic connection establishment, reconnection logic, and error handling

## Usage Example

```typescript
// Route: /devices/remote-desktop/[deviceId]
// Supports legacy deviceData query parameter for backward compatibility

// Example URL with legacy data:
// /devices/remote-desktop/device123?deviceData={"meshcentralAgentId":"node123","hostname":"workstation"}

// Modern usage (fetches device data internally):
// /devices/remote-desktop/device123

// Component handles:
// - MeshCentral tunnel establishment
// - Canvas-based desktop rendering
// - Input capture and forwarding
// - Display switching for multi-monitor setups
// - Power actions (wake, sleep, reset, poweroff)
// - Keyboard shortcuts (Ctrl+Alt+Del, Win+M, etc.)
// - Connection status monitoring and reconnection
```

## Key Features

- **Multi-Display Support**: Automatically detects and allows switching between multiple displays
- **Power Management**: Send wake, sleep, reset, and poweroff commands to remote devices
- **Keyboard Shortcuts**: Pre-mapped key combinations with fallback for unmapped sequences
- **Connection Recovery**: Automatic reconnection with user feedback and attempt counting
- **Settings Configuration**: Modal-based remote desktop settings management
- **Input Toggle**: View-only mode support for observation without interaction
