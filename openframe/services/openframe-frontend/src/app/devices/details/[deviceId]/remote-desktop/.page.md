A Next.js React component that provides a complete remote desktop interface for accessing and controlling devices through MeshCentral, featuring tunnel management, display switching, and remote control capabilities.

## Key Components

### Main Component
- **RemoteDesktopPage**: Main page component handling device remote desktop connections
- **Props**: `params` containing device ID from URL parameters

### Core State Management
- **Device Data**: Handles both legacy query params and internal device fetching
- **Connection State**: Manages tunnel state, connection status, and reconnection logic
- **Remote Desktop**: Controls canvas rendering, input handling, and display management
- **Settings**: Manages remote desktop configuration and preferences modal

### MeshCentral Integration
- **MeshControlClient**: Handles authentication and control commands
- **MeshTunnel**: Manages WebSocket tunnel for desktop data transfer
- **MeshDesktop**: Renders remote desktop frames and handles user interactions

### Key Features
- Multi-display support with display switching
- Power management (wake, sleep, reset, power off)
- Keyboard shortcuts and key combinations
- Real-time connection status and auto-reconnection
- Settings modal for desktop configuration
- Input toggle (view-only mode)

## Usage Example

```typescript
// Route: /devices/remote-desktop/[deviceId]
// Legacy support with deviceData query param
const legacyUrl = '/devices/remote-desktop/abc123?deviceData=' + encodeURIComponent(JSON.stringify({
  id: 'abc123',
  meshcentralAgentId: 'node//agent123',
  hostname: 'laptop-01',
  organization: 'Acme Corp'
}))

// Modern usage (fetches device data internally)
const modernUrl = '/devices/remote-desktop/abc123'

// Component handles both patterns automatically
// Establishes tunnel connection and renders desktop canvas
// Provides power controls, display switching, and settings
```

The component automatically handles device data resolution, establishes secure MeshCentral tunnels, renders the remote desktop canvas, and provides comprehensive remote control functionality including keyboard shortcuts, power management, and multi-display support.
