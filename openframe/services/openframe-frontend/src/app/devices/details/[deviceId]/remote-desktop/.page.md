This Next.js page component provides a full-featured remote desktop client interface using MeshCentral for device control. It handles the complete remote desktop session lifecycle including connection management, settings configuration, and user interactions.

## Key Components

- **RemoteDesktopPage**: Main component that manages the remote desktop session
- **MeshControlClient**: Handles authentication and control operations
- **MeshTunnel**: Manages the WebSocket connection for desktop data
- **MeshDesktop**: Renders the remote desktop canvas and handles display operations
- **RemoteSettingsModal**: Configuration modal for display and input settings
- **Device Data Management**: Supports both legacy query params and modern device fetching
- **Connection State Management**: Tracks tunnel states, reconnection attempts, and first frame rendering

## Usage Example

```typescript
// Component is used as a dynamic route page
// URL: /devices/remote-desktop/[deviceId]

// With legacy device data (backward compatibility)
const urlWithLegacy = `/devices/remote-desktop/123?deviceData=${encodeURIComponent(
  JSON.stringify({
    id: '123',
    meshcentralAgentId: 'agent123',
    hostname: 'workstation-01',
    organization: 'Acme Corp'
  })
)}`

// Modern usage (fetches device data internally)
const modernUrl = '/devices/remote-desktop/123'

// Key interactions handled:
// - Canvas rendering for remote desktop display
// - Power actions (wake, sleep, reset, poweroff)
// - Keyboard shortcuts (Ctrl+Alt+Del, Win+L, etc.)
// - Multi-display support with display switching
// - Real-time connection status and reconnection handling
```

The component provides comprehensive remote desktop functionality with robust error handling, reconnection logic, and support for multiple displays and input methods.
