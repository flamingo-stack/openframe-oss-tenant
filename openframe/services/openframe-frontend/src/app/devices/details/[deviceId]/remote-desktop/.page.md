React component for a remote desktop connection page that enables users to connect to and control devices through MeshCentral. The component handles device authentication, WebSocket tunneling, and real-time desktop streaming with input controls.

## Key Components

- **MeshControlClient** - Manages authentication and control commands for the remote device
- **MeshTunnel** - Handles WebSocket connection and binary data streaming
- **MeshDesktop** - Renders the remote desktop canvas and manages display settings
- **RemoteSettingsModal** - Configuration dialog for connection and display settings
- **Device State Management** - Handles both legacy query parameters and modern device API integration
- **Connection Management** - Automatic reconnection logic with retry attempts and status notifications

## Usage Example

```typescript
// Page component is automatically mounted when navigating to /devices/remote/[deviceId]
// Supports backward compatibility with legacy deviceData query parameter:
router.push(`/devices/remote/${deviceId}?deviceData=${encodeURIComponent(JSON.stringify(deviceData))}`)

// Modern usage with internal device API:
router.push(`/devices/remote/${deviceId}`)

// Key functionality includes:
// - Real-time desktop streaming via HTML5 canvas
// - Input control (mouse/keyboard) with view-only mode option
// - Multi-display support with automatic primary display selection
// - Power management (wake, sleep, reset, shutdown)
// - Special key combinations (Ctrl+Alt+Del, Windows shortcuts)
// - Connection status monitoring with automatic reconnection
// - Configurable display settings (quality, encoding, scaling)
```

The component integrates with the Flamingo Stack's device management system and provides a complete remote desktop solution with professional-grade features like multi-monitor support, power management, and robust connection handling.
