A Next.js page component that provides a remote desktop interface for accessing devices through MeshCentral. This component handles WebSocket connections, remote display management, input control, and power actions for remote device management.

## Key Components

- **RemoteDesktopPage** - Main page component that manages remote desktop connection state
- **MeshDesktop** - Canvas-based remote desktop renderer with input handling
- **MeshTunnel** - WebSocket tunnel for remote desktop data transmission
- **MeshControlClient** - Client for MeshCentral API operations and power management
- **RemoteSettingsModal** - Modal for configuring remote desktop display settings
- **useDeviceDetails** - Hook for fetching device information and connection details

## Usage Example

```typescript
// This page is accessed via Next.js routing
// URL: /devices/remote/[deviceId]
// Example: /devices/remote/abc123

// Legacy backward compatibility with deviceData query param
const legacyUrl = '/devices/remote/abc123?deviceData=' + 
  encodeURIComponent(JSON.stringify({
    id: 'abc123',
    meshcentralAgentId: 'node123',
    hostname: 'workstation-01'
  }))

// Modern usage (fetches device data internally)
const modernUrl = '/devices/remote/abc123'

// Key features available:
// - Live remote desktop display on HTML5 canvas
// - Input control toggle (view-only mode)
// - Multi-display support with display switching
// - Power actions (wake, sleep, reset, poweroff)
// - Keyboard shortcuts (Ctrl+Alt+Del, Win+M, etc.)
// - Connection state management with auto-reconnect
// - Real-time status updates and toast notifications
```

The component supports both legacy device data via URL params and modern device fetching, handles connection failures gracefully with reconnection attempts, and provides comprehensive remote desktop functionality including display management and power control.
