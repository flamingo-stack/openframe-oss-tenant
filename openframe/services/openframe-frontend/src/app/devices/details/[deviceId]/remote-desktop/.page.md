This Next.js client-side component provides a complete remote desktop interface for connecting to devices via MeshCentral. It handles real-time desktop streaming, input control, power management, and settings configuration with automatic reconnection capabilities.

## Key Components

- **Remote Desktop Connection**: Establishes WebSocket tunnel through MeshCentral for desktop streaming
- **Device Data Management**: Handles both legacy query parameters and internal device fetching for backward compatibility
- **Canvas-based Display**: Renders remote desktop frames with multi-display support
- **Input Controls**: Processes keyboard/mouse input and special key combinations (Ctrl+Alt+Del, Win+M, etc.)
- **Settings Modal**: Configurable remote desktop settings (resolution, quality, etc.)
- **Power Management**: Wake, sleep, reset, and shutdown commands
- **Connection State**: Real-time connection status with automatic reconnection logic
- **Actions Menu**: Dropdown menu for power actions and remote control functions

## Usage Example

```typescript
// Access remote desktop page
// URL: /devices/remote-desktop/[deviceId]
// Optional legacy support: ?deviceData={"id":"123","meshcentralAgentId":"abc"}

// Key state management
const [state, setState] = useState<TunnelState>(0) // 0=Idle, 1=Connecting, 2=Open, 3=Connected
const [enableInput, setEnableInput] = useState(true)
const [displays, setDisplays] = useState<DisplayInfo[]>([])

// Power actions
const sendPower = async (action: 'wake' | 'sleep' | 'reset' | 'poweroff') => {
  const client = controlRef.current || new MeshControlClient()
  await client.powerAction(meshcentralAgentId, action)
}

// Special key combinations
const sendCtrlAltDel = () => {
  const buffer = new ArrayBuffer(4)
  const view = new DataView(buffer)
  view.setUint16(0, 0x000A, false) // MNG_CTRLALTDEL command
  tunnelRef.current.sendBinary(new Uint8Array(buffer))
}
```

The component integrates with the Flamingo Stack's device management system and provides a seamless remote desktop experience with enterprise-grade features like multi-display support and robust error handling.
