A React component for establishing and managing remote desktop connections to devices through MeshCentral. This component provides full remote desktop functionality with keyboard/mouse input, display management, power controls, and connection handling.

## Key Components

**Main Exports:**
- `RemoteDesktopPage` - Primary component that renders the remote desktop interface

**Key Hooks & State:**
- `useDeviceDetails` - Fetches device information and connection details
- `useState` for connection state, settings, and display management
- `useRef` for canvas, desktop, tunnel, and control client instances

**Core Classes:**
- `MeshControlClient` - Handles authentication and control commands
- `MeshTunnel` - Manages WebSocket connection for desktop data
- `MeshDesktop` - Renders desktop frames and handles input

**UI Components:**
- `RemoteSettingsModal` - Configuration dialog for desktop settings
- `ActionsMenu` - Dropdown with power controls and shortcuts
- `AppLayout` - Application shell wrapper
