This React component provides a full-featured remote desktop interface that connects to devices via MeshCentral, supporting real-time desktop streaming, input control, and device management capabilities.

## Key Components

**Main Exports:**
- `RemoteDesktopPage` - Main component handling remote desktop connections and UI

**Core Dependencies:**
- `MeshControlClient` - Handles MeshCentral API communication and authentication
- `MeshTunnel` - Manages WebSocket tunneling for desktop data
- `MeshDesktop` - Renders desktop frames and handles display management
- `RemoteSettingsModal` - Configuration UI for connection settings
- `useDeviceDetails` - Hook for fetching device information

**Key State Management:**
- Connection state tracking (idle, connecting, open, connected)
- Display management with multi-monitor support
- Input control and settings configuration
- Reconnection handling with automatic retry logic

## Usage Example

```typescript
// Route usage in Next.js app router
// /devices/[deviceId]/remote-desktop/page.tsx

export default function RemoteDesktopPage({ params }: RemoteDesktopPageProps) {
  // Component handles:
  // 1. Device data fetching (legacy param support + internal fetching)
  // 2. MeshCentral tunnel establishment
  // 3. Desktop streaming and input forwarding  
  // 4. Power management and keyboard shortcuts
  // 5. Multi-display switching

  // Legacy compatibility via URL params:
  // ?deviceData={"id":"123","meshcentralAgentId":"abc","hostname":"device1"}

  // Modern usage fetches device details internally by deviceId
}
```

The component supports both legacy URL parameter-based device data and modern internal device fetching, provides comprehensive remote desktop functionality including power actions, keyboard shortcuts (Ctrl+Alt+Del), multi-display support, and automatic reconnection handling.
