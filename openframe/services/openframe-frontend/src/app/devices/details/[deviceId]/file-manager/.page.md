A Next.js page component that renders a file manager interface for managing files on a specific device through MeshCentral integration.

## Key Components

- **FileManagerPage** - Main page component that handles device file management with loading states, error handling, and MeshCentral agent validation
- **FileManagerPageSkeleton** - Loading skeleton component that displays while device details are being fetched
- **useDeviceDetails** - Custom hook for fetching device information and managing loading states
- **FileManagerContainer** - Core file management interface component
- **getMeshCentralAgentId** - Utility function to extract MeshCentral agent ID from device details

## Usage Example

This page is accessed via the Next.js App Router with dynamic routing:

```typescript
// Route: /devices/details/[deviceId]/file-manager
// The page automatically receives deviceId as a parameter

// Navigation example from device details page
const router = useRouter()
router.push(`/devices/details/${deviceId}/file-manager`)

// The component handles:
// 1. Loading device details by ID
// 2. Validating MeshCentral agent availability
// 3. Rendering file manager interface
// 4. Error states and fallback navigation
```

The page requires a valid MeshCentral agent ID to function and provides comprehensive error handling for missing data or connection issues. Users can navigate back to the device details page if file manager functionality is unavailable.
