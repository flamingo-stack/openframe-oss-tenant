A Next.js page component that provides a file management interface for remote devices through MeshCentral integration. This page handles device identification, loading states, and error scenarios while rendering the main file manager functionality.

## Key Components

- **FileManagerPage** - Main page component that manages device data fetching and renders the file manager interface
- **FileManagerPageSkeleton** - Loading skeleton component displayed while device details are being fetched
- **useDeviceDetails** - Custom hook for fetching and managing device information
- **FileManagerContainer** - Core file manager component that handles file operations for the specified device

## Usage Example

```typescript
// This page is accessed via Next.js routing at:
// /devices/details/[deviceId]/file-manager

// Example URL: /devices/details/device-123/file-manager
// The deviceId parameter is extracted from the URL and used to:
// 1. Fetch device details using useDeviceDetails hook
// 2. Extract MeshCentral Agent ID for file operations
// 3. Pass configuration to FileManagerContainer

// Error handling scenarios:
// - Loading state: Shows FileManagerPageSkeleton
// - Fetch error: Displays error message with return navigation
// - Missing MeshCentral ID: Shows specific error about agent requirement

// Navigation integration:
// - Back button returns to device details page
// - Error states provide return navigation options
```

The page requires a valid `deviceId` parameter and MeshCentral agent integration for file management functionality. It provides comprehensive error handling and loading states to ensure a smooth user experience during device file operations.
