A Next.js page component that renders a file manager interface for specific devices, integrating with MeshCentral for remote file management capabilities.

## Key Components

- **FileManagerPage** - Main page component that handles device file management
- **FileManagerPageSkeleton** - Loading state component with navigation and skeleton UI
- **useDeviceDetails** - Custom hook for fetching device information
- **FileManagerContainer** - Core file management interface component
- **AppLayout** - Application layout wrapper component

## Usage Example

```typescript
// The component is automatically rendered by Next.js routing
// URL: /devices/details/[deviceId]/file-manager

// Props are provided by Next.js dynamic routing
const pageProps: FileManagerPageProps = {
  params: Promise.resolve({
    deviceId: "device-123"
  })
}

// Error handling for missing MeshCentral Agent ID
if (!meshcentralAgentId) {
  // Shows error message and return navigation
}

// Loading state with skeleton UI
if (isLoading) {
  return <FileManagerPageSkeleton onBack={handleBack} />
}
```

The component automatically fetches device details on mount, validates MeshCentral connectivity, and provides comprehensive error handling with navigation fallbacks. It uses React's `use()` hook for handling promise-based params and includes proper loading states throughout the user experience.
