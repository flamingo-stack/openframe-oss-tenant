A React page component that provides file management functionality for specific devices through the MeshCentral agent integration. It handles device parameter resolution, state management, and renders appropriate UI states including loading, error, and success scenarios.

## Key Components

- **FileManagerPage** - Main page component that manages device file access
- **FileManagerPageSkeleton** - Loading state component with navigation and content placeholders
- **useDeviceDetails** - Custom hook for fetching device information
- **FileManagerContainer** - Core file management interface component
- **AppLayout** - Application-wide layout wrapper

## Usage Example

```typescript
// This page is accessed via Next.js routing
// URL: /devices/details/[deviceId]/file-manager

// The component automatically:
// 1. Extracts deviceId from URL parameters
// 2. Fetches device details using the deviceId
// 3. Validates MeshCentral agent availability
// 4. Renders the file manager interface

// Example routing setup in Next.js app directory:
// app/devices/details/[deviceId]/file-manager/page.tsx

// Navigation example:
const navigateToFileManager = (deviceId: string) => {
  router.push(`/devices/details/${deviceId}/file-manager`)
}

// Error handling states:
// - Loading: Shows skeleton with back navigation
// - Missing agent ID: Shows error with return link
// - General errors: Displays error message with navigation
```

The component integrates with the OpenFrame device management system, requiring a valid MeshCentral agent ID to enable file operations on remote devices.
