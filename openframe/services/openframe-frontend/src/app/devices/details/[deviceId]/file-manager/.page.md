A Next.js client-side page component that provides file management functionality for remote devices through MeshCentral integration. It handles device data loading, error states, and renders a file manager interface with proper navigation.

## Key Components

- **FileManagerPage**: Main page component that fetches device details and renders the file manager
- **FileManagerPageSkeleton**: Loading state component with navigation back button and skeleton UI
- **useDeviceDetails**: Custom hook for managing device data fetching and state
- **FileManagerContainer**: Core file management interface component
- **getMeshCentralAgentId**: Utility function to extract MeshCentral agent ID from device details

## Usage Example

```typescript
// This page is automatically rendered by Next.js routing
// Route: /devices/details/[deviceId]/file-manager

// The page expects URL params in the format:
interface RouteParams {
  deviceId: string // UUID or device identifier
}

// Example navigation to this page:
const navigateToFileManager = (deviceId: string) => {
  router.push(`/devices/details/${deviceId}/file-manager`)
}

// The component handles three main states:
// 1. Loading: Shows FileManagerPageSkeleton
// 2. Error: Shows error message with back navigation
// 3. Success: Renders FileManagerContainer with device data
```

The component validates that a MeshCentral Agent ID is available before rendering the file manager, ensuring the remote file system can be properly accessed. It includes comprehensive error handling and loading states for a smooth user experience.
