A Next.js client-side page component that provides a file management interface for individual devices within the Flamingo MSP platform, integrating with MeshCentral for remote file operations.

## Key Components

- **FileManagerPage** - Main page component that renders the device file manager with loading and error states
- **FileManagerPageSkeleton** - Loading skeleton component that displays while device details are being fetched
- **useDeviceDetails** - Custom hook for fetching and managing device information
- **FileManagerContainer** - Core file management interface component
- **getMeshCentralAgentId** - Utility function to extract MeshCentral agent ID from device details

## Usage Example

This page is automatically rendered when navigating to the file manager route:

```typescript
// Route: /devices/details/[deviceId]/file-manager
// Example URL: /devices/details/abc123/file-manager

// The component automatically:
// 1. Extracts deviceId from URL params
// 2. Fetches device details using the custom hook  
// 3. Validates MeshCentral agent availability
// 4. Renders the file manager interface or appropriate error states

// Error handling includes:
// - Loading skeleton during data fetch
// - Error message for fetch failures
// - Validation error if MeshCentral agent ID is missing
// - Back navigation to device details page
```

The component ensures proper error boundaries and loading states while providing seamless integration between device management and remote file operations through the MeshCentral platform.
