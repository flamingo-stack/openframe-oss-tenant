This Next.js page component renders a file manager interface for remote device access within the Flamingo/OpenFrame MSP platform. It provides file system navigation and management capabilities for devices connected through MeshCentral agents.

## Key Components

- **FileManagerPage** - Main page component that handles device validation and renders the file manager
- **FileManagerPageSkeleton** - Loading state component with navigation and skeleton UI
- **useDeviceDetails** - Custom hook for fetching device information
- **FileManagerContainer** - Core file management interface component
- **getMeshCentralAgentId** - Utility function to extract MeshCentral agent ID from device details

## Usage Example

```typescript
// This page is accessed via Next.js routing at:
// /devices/details/[deviceId]/file-manager

// Example URL: /devices/details/abc123/file-manager
// The deviceId parameter is automatically extracted from the route

// The component handles three main states:
// 1. Loading - Shows FileManagerPageSkeleton
// 2. Error - Shows error message with back navigation
// 3. Success - Renders FileManagerContainer with device details
```

The page includes comprehensive error handling for missing MeshCentral agent IDs (required for remote file access) and provides consistent navigation back to device details. The skeleton loading state maintains the same layout structure as the full interface for smooth user experience during data fetching.
