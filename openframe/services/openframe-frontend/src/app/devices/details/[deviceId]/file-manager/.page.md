A Next.js page component that provides a file manager interface for remotely accessing files on managed devices through MeshCentral agent integration.

## Key Components

- **FileManagerPage** - Main page component that handles device file management
- **FileManagerPageSkeleton** - Loading state component with navigation and skeleton UI
- **FileManagerContainer** - Core file management interface component
- **useDeviceDetails** - Custom hook for fetching device information
- **getMeshCentralAgentId** - Utility function to extract MeshCentral agent ID

## Usage Example

```typescript
// Route: /devices/details/[deviceId]/file-manager
// The page automatically handles:
// - Device ID parameter extraction
// - Device details fetching
// - MeshCentral agent validation
// - Error states and loading states

// Navigation to file manager
router.push(`/devices/details/${deviceId}/file-manager`)

// Error handling scenarios:
// 1. Device loading fails - shows error with return link
// 2. No MeshCentral agent ID - shows requirement error
// 3. Loading state - shows skeleton with back navigation
```

The component uses React 18's `use()` hook for handling async params, validates MeshCentral connectivity requirements, and provides comprehensive error handling with fallback navigation back to device details.
