A Next.js page component that provides a file manager interface for device management, handling loading states, error conditions, and MeshCentral agent integration.

## Key Components

- **FileManagerPage** - Main page component that renders the file manager for a specific device
- **FileManagerPageSkeleton** - Loading state component with navigation and content skeletons
- **useDeviceDetails** - Custom hook for fetching and managing device data
- **FileManagerContainer** - Core file management functionality container
- **AppLayout** - Consistent application layout wrapper

## Usage Example

This page is accessed via the Next.js app router at `/devices/details/[deviceId]/file-manager`:

```typescript
// URL: /devices/details/abc123/file-manager
// Renders file manager for device with ID "abc123"

// Component flow:
// 1. Extract deviceId from URL params
// 2. Fetch device details using useDeviceDetails hook
// 3. Extract MeshCentral agent ID for file operations
// 4. Render FileManagerContainer with device context

// Error handling includes:
// - Loading skeleton during data fetch
// - Error message for failed device lookup
// - Missing MeshCentral agent ID validation
// - Navigation back to device details page
```

The component implements proper error boundaries, loading states, and requires a valid MeshCentral agent ID to enable file management functionality. It integrates with the OpenFrame frontend core components for consistent UI patterns.
