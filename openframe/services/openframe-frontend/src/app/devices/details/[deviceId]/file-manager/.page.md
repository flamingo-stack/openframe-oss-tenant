A Next.js page component that renders a file management interface for remote device access, featuring loading states, error handling, and MeshCentral agent integration for secure file operations.

## Key Components

- **FileManagerPage** - Main page component that handles device-specific file management routing
- **FileManagerPageSkeleton** - Loading state component with back navigation and skeleton UI
- **useDeviceDetails** - Custom hook for fetching device information and MeshCentral agent data
- **FileManagerContainer** - Core file management interface component
- **getMeshCentralAgentId** - Utility function to extract MeshCentral agent identifier from device details

## Usage Example

```typescript
// This page is accessed via Next.js dynamic routing
// URL: /devices/details/[deviceId]/file-manager

// The component automatically:
// 1. Extracts deviceId from route params
// 2. Fetches device details using the custom hook
// 3. Validates MeshCentral agent availability
// 4. Renders the file manager or appropriate error states

// Example navigation to this page:
router.push(`/devices/details/${deviceId}/file-manager`)
```

The component implements comprehensive error handling for missing device details, unavailable MeshCentral agents, and loading states. It uses the AppLayout wrapper for consistent UI styling and provides a back navigation button to return to the device details page. The file manager requires a valid MeshCentral agent ID to function, enabling secure remote file system access through the OpenFrame platform.
