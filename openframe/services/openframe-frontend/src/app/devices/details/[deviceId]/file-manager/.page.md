Next.js page component that renders a file manager interface for managing files on remote devices through MeshCentral integration. Handles device parameter resolution, device details fetching, and displays appropriate loading/error states.

## Key Components

- **FileManagerPage**: Main page component that manages device file operations
- **FileManagerPageSkeleton**: Loading state component with navigation and content skeletons
- **useDeviceDetails**: Hook for fetching and managing device information
- **FileManagerContainer**: Core file management interface component
- **getMeshCentralAgentId**: Utility for extracting MeshCentral agent identifier

## Usage Example

```typescript
// Route: /devices/details/[deviceId]/file-manager
// This component automatically handles:
// - Device ID extraction from URL parameters
// - Device details fetching and validation
// - MeshCentral agent ID resolution
// - Error handling for missing or invalid devices

// Navigation to file manager
router.push(`/devices/details/${deviceId}/file-manager`)

// Component renders with loading state first, then:
// - File manager interface if device and agent ID are valid
// - Error message with return navigation if device/agent unavailable
// - Loading skeleton during data fetching
```

The component implements comprehensive error handling for missing MeshCentral agent IDs and provides consistent navigation patterns back to device details. It uses the AppLayout wrapper for consistent page structure and integrates with the OpenFrame design system.
