A Next.js client-side page component that provides file management functionality for devices through MeshCentral integration. The component handles device data fetching, validation, and renders the appropriate UI states including loading, error, and success scenarios.

## Key Components

- **FileManagerPage** - Main page component that manages device file operations
- **FileManagerPageSkeleton** - Loading state component with navigation and placeholder content
- **useDeviceDetails** - Custom hook for fetching device information
- **FileManagerContainer** - Core file management interface component
- **getMeshCentralAgentId** - Utility function to extract MeshCentral agent ID from device data

## Usage Example

```typescript
// This is a Next.js page component - accessed via routing
// URL: /devices/details/[deviceId]/file-manager

// The component automatically receives params from Next.js routing
interface PageProps {
  params: Promise<{ deviceId: string }>
}

// Navigation flow:
// 1. User navigates to file manager for specific device
// 2. Component fetches device details using deviceId
// 3. Validates MeshCentral agent availability
// 4. Renders FileManagerContainer or appropriate error state

// Error handling includes:
// - Loading skeleton during data fetch
// - Error message for failed requests
// - Validation error for missing MeshCentral agent
// - Back navigation to device details page
```

The component follows a defensive programming approach, gracefully handling missing data and providing clear user feedback for various error states while maintaining consistent navigation patterns throughout the device management workflow.
