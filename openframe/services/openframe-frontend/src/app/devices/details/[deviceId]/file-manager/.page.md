This Next.js page component provides a file management interface for accessing device file systems through MeshCentral agent integration. It handles device parameter resolution, loading states, error scenarios, and displays the file manager when a valid MeshCentral agent ID is available.

## Key Components

- **FileManagerPage**: Main page component that manages device file access
- **FileManagerPageSkeleton**: Loading state component with navigation and skeleton UI
- **useDeviceDetails**: Custom hook for fetching device information
- **FileManagerContainer**: Core file management functionality component
- **getMeshCentralAgentId**: Utility function to extract MeshCentral agent identifier

## Usage Example

```typescript
// Route: /devices/details/[deviceId]/file-manager
// Accessed via device details page with valid deviceId parameter

// Component handles these scenarios:
// 1. Loading state - shows skeleton UI
// 2. Error state - displays error with back navigation
// 3. Missing agent ID - shows error for devices without MeshCentral
// 4. Success state - renders full file manager interface

// Example navigation to file manager:
router.push(`/devices/details/${deviceId}/file-manager`)
```

The page requires a valid `deviceId` parameter and ensures the device has MeshCentral integration before allowing file system access. It provides consistent error handling and loading states while maintaining navigation context back to the device details page.
