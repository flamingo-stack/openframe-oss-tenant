A Next.js page component that provides a file manager interface for managing files on remote devices through MeshCentral integration. The page handles device validation, loading states, and error conditions while providing navigation back to device details.

## Key Components

- **FileManagerPage**: Main page component that fetches device details and renders the file manager
- **FileManagerPageSkeleton**: Loading skeleton component with navigation and placeholder content
- **useDeviceDetails**: Custom hook for fetching device information
- **FileManagerContainer**: Container component that handles the actual file management functionality
- **getMeshCentralAgentId**: Utility function to extract MeshCentral agent ID from device details

## Usage Example

```typescript
// This page is automatically routed by Next.js at:
// /devices/details/[deviceId]/file-manager

// Example URL: /devices/details/device-123/file-manager
// The deviceId parameter is automatically passed to the component

// Key features:
// - Validates MeshCentral agent ID exists
// - Shows loading skeleton during data fetch
// - Displays error messages for missing data
// - Provides back navigation to device details
// - Renders file manager interface when ready

// Error handling examples:
if (error) {
  // Shows error message with return link
}

if (!meshcentralAgentId) {
  // Shows specific error for missing MeshCentral integration
}
```

The component follows a standard Next.js pattern with proper error handling, loading states, and integration with the device management system through the OpenFrame platform.
