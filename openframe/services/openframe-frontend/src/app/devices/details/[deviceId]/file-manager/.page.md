A Next.js page component that renders a file manager interface for managing files on remote devices through MeshCentral integration. It handles device data fetching, loading states, error scenarios, and validates MeshCentral agent connectivity before displaying the file manager.

## Key Components

- **FileManagerPage** - Main page component that manages device details fetching and renders the file manager interface
- **FileManagerPageSkeleton** - Loading skeleton component displayed while device data is being fetched
- **FileManagerContainer** - Core file manager functionality component (imported)
- **useDeviceDetails** - Custom hook for fetching and managing device information
- **getMeshCentralAgentId** - Utility function to extract MeshCentral agent ID from device details

## Usage Example

This page is typically accessed via Next.js routing at `/devices/details/[deviceId]/file-manager`:

```typescript
// Example route: /devices/details/abc123/file-manager
// The component automatically:
// 1. Extracts deviceId from URL params
// 2. Fetches device details using the custom hook
// 3. Validates MeshCentral agent connectivity
// 4. Renders appropriate UI based on state

// Key state handling:
if (isLoading) {
  // Shows FileManagerSkeleton
}

if (error || !meshcentralAgentId) {
  // Shows error state with navigation back to device details
}

// Success state renders FileManagerContainer with:
// - deviceId: string
// - meshcentralAgentId: string  
// - hostname: string (device name for display)
```

The component requires a valid MeshCentral agent connection to function and provides clear error messaging when prerequisites aren't met.
