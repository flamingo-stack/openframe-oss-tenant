Device status constants and type definitions for filtering and displaying devices in the Flamingo platform. Provides predefined status groups for different UI contexts while excluding archived/deleted devices from default views.

## Key Components

- **`DEVICE_STATUS`** - Enumeration of all possible device statuses (ONLINE, OFFLINE, ACTIVE, INACTIVE, MAINTENANCE, DECOMMISSIONED, PENDING, ARCHIVED, DELETED)
- **`DEFAULT_VISIBLE_STATUSES`** - Array of statuses shown in standard device lists (excludes ARCHIVED and DELETED)
- **`DEFAULT_DASHBOARD_STATUSES`** - Minimal status set for dashboard views (ONLINE, OFFLINE only)
- **`HIDDEN_DEVICE_STATUSES`** - Statuses excluded from default queries (ARCHIVED, DELETED)
- **Type Definitions** - `DeviceStatus`, `DefaultVisibleStatus`, `HiddenDeviceStatus` for type safety

## Usage Example

```typescript
import { 
  DEVICE_STATUS, 
  DEFAULT_VISIBLE_STATUSES, 
  type DeviceStatus 
} from './device-statuses'

// Filter devices for main listing
const getActiveDevices = (devices: Device[]) => {
  return devices.filter(device => 
    DEFAULT_VISIBLE_STATUSES.includes(device.status as DeviceStatus)
  )
}

// Check specific status
const isOnline = (status: DeviceStatus) => {
  return status === DEVICE_STATUS.ONLINE
}

// Dashboard query with minimal statuses
const dashboardFilter = {
  status: { $in: DEFAULT_DASHBOARD_STATUSES }
}
```
