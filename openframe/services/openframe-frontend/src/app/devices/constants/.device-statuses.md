Device status constants and type definitions for the Flamingo platform's device management system. This module defines all possible device states and provides filtered status sets for different UI contexts.

## Key Components

- **`DEVICE_STATUS`** - Enumeration object containing all device status constants (ONLINE, OFFLINE, ACTIVE, etc.)
- **`DeviceStatus`** - TypeScript type representing any valid device status
- **`DEFAULT_VISIBLE_STATUSES`** - Array of statuses shown in standard device views (excludes ARCHIVED/DELETED)
- **`DEFAULT_DASHBOARD_STATUSES`** - Minimal status set for dashboard displays (ONLINE/OFFLINE only)
- **`HIDDEN_DEVICE_STATUSES`** - Statuses excluded from default views (ARCHIVED, DELETED)
- **Type definitions** - `DefaultVisibleStatus` and `HiddenDeviceStatus` for type safety

## Usage Example

```typescript
import { 
  DEVICE_STATUS, 
  DEFAULT_VISIBLE_STATUSES, 
  type DeviceStatus 
} from './device-statuses'

// Filter devices by visible statuses
const getActiveDevices = (devices: Device[]) => {
  return devices.filter(device => 
    DEFAULT_VISIBLE_STATUSES.includes(device.status as DeviceStatus)
  )
}

// Check specific status
const isOnline = (device: Device) => {
  return device.status === DEVICE_STATUS.ONLINE
}

// API query with default visible statuses
const fetchDevices = async () => {
  const params = {
    statuses: DEFAULT_VISIBLE_STATUSES.join(',')
  }
  return api.get('/devices', { params })
}
```
