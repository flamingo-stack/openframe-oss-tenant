This file defines constants and types for managing device statuses throughout the application, providing standardized status values and filtering presets for different views.

## Key Components

- **`DEVICE_STATUS`** - Constant object containing all available device status values (ONLINE, OFFLINE, ACTIVE, etc.)
- **`DeviceStatus`** - TypeScript type representing any valid device status value
- **`DEFAULT_VISIBLE_STATUSES`** - Array of statuses shown in standard device queries (excludes ARCHIVED and DELETED)
- **`DEFAULT_DASHBOARD_STATUSES`** - Subset of statuses for dashboard views (ONLINE and OFFLINE only)
- **`HIDDEN_DEVICE_STATUSES`** - Array of statuses that are hidden by default (ARCHIVED, DELETED)
- **Type definitions** - `DefaultVisibleStatus` and `HiddenDeviceStatus` for type safety

## Usage Example

```typescript
import { DEVICE_STATUS, DEFAULT_VISIBLE_STATUSES, DeviceStatus } from './device-statuses'

// Filter devices for standard views
const activeDevices = devices.filter(device => 
  DEFAULT_VISIBLE_STATUSES.includes(device.status as DefaultVisibleStatus)
)

// Check specific status
if (device.status === DEVICE_STATUS.MAINTENANCE) {
  showMaintenanceAlert()
}

// Type-safe status assignment
const newStatus: DeviceStatus = DEVICE_STATUS.ONLINE

// Query devices excluding hidden statuses
const visibleDeviceQuery = {
  status: { $nin: HIDDEN_DEVICE_STATUSES }
}
```

The file uses TypeScript's `as const` assertions and `satisfies` operator to ensure type safety while maintaining the constant nature of the status arrays.
