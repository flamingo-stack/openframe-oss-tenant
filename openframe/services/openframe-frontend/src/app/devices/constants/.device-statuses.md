Defines device status constants and filtered arrays for the Flamingo MSP platform's device management system. Provides type-safe status definitions with configurable visibility for different UI contexts.

## Key Components

- **`DEVICE_STATUS`** - Complete enumeration of all possible device states including operational, maintenance, and archived statuses
- **`DeviceStatus`** - Type union of all available device status values
- **`DEFAULT_VISIBLE_STATUSES`** - Array of statuses shown in standard device queries (excludes archived/deleted)
- **`DEFAULT_DASHBOARD_STATUSES`** - Simplified status list for dashboard views (online/offline only)
- **`HIDDEN_DEVICE_STATUSES`** - Statuses excluded from default views for data retention purposes
- **Type definitions** - `DefaultVisibleStatus` and `HiddenDeviceStatus` for type safety

## Usage Example

```typescript
import { 
  DEVICE_STATUS, 
  DEFAULT_VISIBLE_STATUSES, 
  type DeviceStatus 
} from './device-statuses'

// Filter devices for main dashboard
const dashboardDevices = devices.filter(device => 
  DEFAULT_VISIBLE_STATUSES.includes(device.status as DeviceStatus)
)

// Check specific status
if (device.status === DEVICE_STATUS.MAINTENANCE) {
  showMaintenanceAlert()
}

// Type-safe status assignment
const newDevice: { status: DeviceStatus } = {
  status: DEVICE_STATUS.PENDING
}
```

The constant arrays use `as const satisfies string[]` to maintain both immutability and type compatibility, ensuring status values remain consistent across the application while preventing accidental modifications.
