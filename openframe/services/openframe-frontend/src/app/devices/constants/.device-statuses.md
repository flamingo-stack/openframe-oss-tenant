A TypeScript constants file that defines device status enums and filtered status arrays for OpenFrame's device management system, providing type-safe status filtering for different UI contexts.

## Key Components

- **`DEVICE_STATUS`** - Const assertion object containing all possible device status values
- **`DeviceStatus`** - Type union of all device status string literals
- **`DEFAULT_VISIBLE_STATUSES`** - Array of statuses shown in standard device queries (excludes ARCHIVED/DELETED)
- **`DEFAULT_DASHBOARD_STATUSES`** - Minimal status set for dashboard views (ONLINE/OFFLINE only)
- **`HIDDEN_DEVICE_STATUSES`** - Array of statuses excluded from default views
- **Type exports** - `DefaultVisibleStatus` and `HiddenDeviceStatus` for specific use cases

## Usage Example

```typescript
import { 
  DEVICE_STATUS, 
  DEFAULT_VISIBLE_STATUSES,
  DEFAULT_DASHBOARD_STATUSES,
  type DeviceStatus 
} from './device-statuses'

// Filter devices for main listing
const activeDevices = devices.filter(device => 
  DEFAULT_VISIBLE_STATUSES.includes(device.status as DeviceStatus)
)

// Dashboard widget showing only online/offline
const dashboardDevices = devices.filter(device =>
  DEFAULT_DASHBOARD_STATUSES.includes(device.status as DeviceStatus)
)

// Check specific status
if (device.status === DEVICE_STATUS.MAINTENANCE) {
  showMaintenanceWarning()
}

// API query with visible statuses
const query = {
  status: { $in: DEFAULT_VISIBLE_STATUSES }
}
```
