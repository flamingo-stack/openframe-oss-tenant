Defines device status constants and type-safe status collections for filtering and displaying devices in different contexts throughout the OpenFrame platform.

## Key Components

- **`DEVICE_STATUS`** - Enum-like constant object containing all possible device statuses
- **`DeviceStatus`** - Type representing any valid device status value
- **`DEFAULT_VISIBLE_STATUSES`** - Array of statuses shown in standard device lists (excludes ARCHIVED/DELETED)
- **`DEFAULT_DASHBOARD_STATUSES`** - Minimal status set for dashboard views (ONLINE/OFFLINE only)
- **`HIDDEN_DEVICE_STATUSES`** - Statuses excluded from default views
- **`DefaultVisibleStatus`** and **`HiddenDeviceStatus`** - Refined types for specific status categories

## Usage Example

```typescript
import { 
  DEVICE_STATUS, 
  DEFAULT_VISIBLE_STATUSES, 
  type DeviceStatus 
} from './device-statuses'

// Filter devices for main listing
const visibleDevices = devices.filter(device => 
  DEFAULT_VISIBLE_STATUSES.includes(device.status as any)
)

// Check specific status
if (device.status === DEVICE_STATUS.MAINTENANCE) {
  showMaintenanceAlert()
}

// Type-safe status handling
function handleDeviceStatus(status: DeviceStatus) {
  switch (status) {
    case DEVICE_STATUS.ONLINE:
      return 'green'
    case DEVICE_STATUS.OFFLINE:
      return 'red'
    default:
      return 'gray'
  }
}
```

The file provides a centralized, type-safe way to manage device statuses across the platform, ensuring consistency between frontend filtering and backend status definitions.
