This file defines standardized device status constants and type-safe collections for filtering devices in the Flamingo MSP platform. It provides predefined status groups for different views while maintaining type safety.

## Key Components

- **`DEVICE_STATUS`** - Enum-like object containing all possible device statuses (ONLINE, OFFLINE, ACTIVE, etc.)
- **`DeviceStatus`** - Type representing any valid device status value
- **`DEFAULT_VISIBLE_STATUSES`** - Array of statuses shown in standard device lists (excludes ARCHIVED/DELETED)
- **`DEFAULT_DASHBOARD_STATUSES`** - Subset for dashboard views (ONLINE/OFFLINE only)
- **`HIDDEN_DEVICE_STATUSES`** - Statuses excluded from default views
- **`DefaultVisibleStatus`** and **`HiddenDeviceStatus`** - Derived types for specific status groups

## Usage Example

```typescript
import { 
  DEVICE_STATUS, 
  DEFAULT_VISIBLE_STATUSES, 
  type DeviceStatus 
} from './device-statuses'

// Filter devices for main dashboard
const dashboardDevices = devices.filter(device => 
  DEFAULT_VISIBLE_STATUSES.includes(device.status as DeviceStatus)
)

// Check specific status
if (device.status === DEVICE_STATUS.MAINTENANCE) {
  showMaintenanceAlert(device)
}

// Type-safe status assignment
const updateDeviceStatus = (status: DeviceStatus) => {
  // TypeScript ensures only valid statuses can be passed
  device.status = status
}
```

The file ensures consistency across the application when handling device statuses and provides clear separation between visible and hidden device states.
