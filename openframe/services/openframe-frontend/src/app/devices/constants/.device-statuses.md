Provides centralized device status constants and type definitions for the Flamingo OpenFrame platform's device management system. This module defines the complete status lifecycle for managed devices and their visibility rules across different views.

## Key Components

- **DEVICE_STATUS**: Complete enum-like object containing all possible device states
- **DeviceStatus**: Type union of all available status values
- **DEFAULT_VISIBLE_STATUSES**: Array of statuses shown in standard device views (excludes ARCHIVED/DELETED)
- **DEFAULT_DASHBOARD_STATUSES**: Minimal status set for dashboard displays (ONLINE/OFFLINE only)
- **HIDDEN_DEVICE_STATUSES**: Statuses excluded from default queries
- **DefaultVisibleStatus** and **HiddenDeviceStatus**: Type-safe subsets for specific use cases

## Usage Example

```typescript
import { 
  DEVICE_STATUS, 
  DEFAULT_VISIBLE_STATUSES, 
  type DeviceStatus 
} from './device-statuses'

// Filter devices by status
function getActiveDevices(devices: Device[]) {
  return devices.filter(device => 
    DEFAULT_VISIBLE_STATUSES.includes(device.status as any)
  )
}

// Type-safe status checking
function isDeviceOnline(status: DeviceStatus): boolean {
  return status === DEVICE_STATUS.ONLINE
}

// Query builder for device APIs
const deviceQuery = {
  status: { in: DEFAULT_VISIBLE_STATUSES },
  // Automatically excludes ARCHIVED and DELETED devices
}
```

The module ensures consistent device status handling across the platform while maintaining type safety and clear separation between visible and hidden device states.
