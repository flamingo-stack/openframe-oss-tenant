Defines device status constants and filtering utilities for managing device visibility across the Flamingo MSP platform. This module provides type-safe status enums and predefined status groups to ensure consistent device filtering behavior.

## Key Components

- **`DEVICE_STATUS`** - Enum-like constant containing all available device statuses (ONLINE, OFFLINE, ACTIVE, etc.)
- **`DeviceStatus`** - Type derived from all possible device status values
- **`DEFAULT_VISIBLE_STATUSES`** - Array of statuses shown in standard device views (excludes ARCHIVED/DELETED)
- **`DEFAULT_DASHBOARD_STATUSES`** - Minimal status set for dashboard displays (ONLINE/OFFLINE only)
- **`HIDDEN_DEVICE_STATUSES`** - Statuses excluded from default views (ARCHIVED, DELETED)
- **Type definitions** - `DefaultVisibleStatus` and `HiddenDeviceStatus` for type safety

## Usage Example

```typescript
import { 
  DEVICE_STATUS, 
  DEFAULT_VISIBLE_STATUSES, 
  type DeviceStatus 
} from './device-statuses'

// Filter devices for standard views
const visibleDevices = devices.filter(device => 
  DEFAULT_VISIBLE_STATUSES.includes(device.status as DefaultVisibleStatus)
)

// Check specific status
if (device.status === DEVICE_STATUS.MAINTENANCE) {
  showMaintenanceAlert()
}

// Type-safe status handling
function updateDeviceStatus(deviceId: string, status: DeviceStatus) {
  // status is constrained to valid values
  api.updateDevice(deviceId, { status })
}
```
