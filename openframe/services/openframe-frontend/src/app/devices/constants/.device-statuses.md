This TypeScript module defines device status constants and filtered status arrays for managing device visibility across the OpenFrame MSP platform. It provides a centralized source of truth for device state management with clear separation between visible and hidden statuses.

## Key Components

- **`DEVICE_STATUS`** - Constant object containing all possible device status values (ONLINE, OFFLINE, ACTIVE, etc.)
- **`DeviceStatus`** - Type union of all device status values
- **`DEFAULT_VISIBLE_STATUSES`** - Array of statuses shown in standard device views (excludes ARCHIVED/DELETED)
- **`DEFAULT_DASHBOARD_STATUSES`** - Simplified status array for dashboard views (ONLINE/OFFLINE only)
- **`HIDDEN_DEVICE_STATUSES`** - Array of statuses hidden by default (ARCHIVED, DELETED)
- **Type definitions** - `DefaultVisibleStatus` and `HiddenDeviceStatus` for type safety

## Usage Example

```typescript
import { 
  DEVICE_STATUS, 
  DEFAULT_VISIBLE_STATUSES, 
  DeviceStatus 
} from './device-statuses'

// Filter devices by visible statuses
const getActiveDevices = (devices: Device[]) => {
  return devices.filter(device => 
    DEFAULT_VISIBLE_STATUSES.includes(device.status as DefaultVisibleStatus)
  )
}

// Check specific status
const isDeviceOnline = (status: DeviceStatus) => {
  return status === DEVICE_STATUS.ONLINE
}

// API query with default visible statuses
const fetchDevices = async () => {
  return api.getDevices({
    statuses: DEFAULT_VISIBLE_STATUSES
  })
}
```
