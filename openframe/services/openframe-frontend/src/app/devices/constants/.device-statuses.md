This file defines device status constants and configurations for the Flamingo MSP platform, providing standardized status types and filtered collections for different UI contexts.

## Key Components

- **`DEVICE_STATUS`** - Enumeration of all possible device statuses including ONLINE, OFFLINE, MAINTENANCE, ARCHIVED, etc.
- **`DeviceStatus`** - TypeScript type derived from all status values
- **`DEFAULT_VISIBLE_STATUSES`** - Array of statuses shown in standard device queries (excludes ARCHIVED/DELETED)
- **`DEFAULT_DASHBOARD_STATUSES`** - Minimal status set for dashboard views (ONLINE/OFFLINE only)
- **`HIDDEN_DEVICE_STATUSES`** - Statuses excluded from default views
- **Type definitions** - `DefaultVisibleStatus` and `HiddenDeviceStatus` for type safety

## Usage Example

```typescript
import { 
  DEVICE_STATUS, 
  DEFAULT_VISIBLE_STATUSES, 
  DeviceStatus,
  DefaultVisibleStatus 
} from './device-statuses'

// Filter devices by visible statuses
const activeDevices = devices.filter(device => 
  DEFAULT_VISIBLE_STATUSES.includes(device.status as DefaultVisibleStatus)
)

// Check specific status
if (device.status === DEVICE_STATUS.MAINTENANCE) {
  showMaintenanceAlert()
}

// Type-safe status assignment
const deviceStatus: DeviceStatus = DEVICE_STATUS.ONLINE
```

The file ensures consistent device status handling across the OpenFrame platform, with clear separation between active and archived states for better UX and data management.
