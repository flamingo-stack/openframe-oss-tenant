This TypeScript file defines device status constants and filtering configurations for the Flamingo MSP platform's device management system. It provides type-safe status definitions and predefined collections for different UI contexts.

## Key Components

- **`DEVICE_STATUS`** - Complete enum-like object containing all possible device statuses
- **`DeviceStatus`** - Type union of all valid device status values
- **`DEFAULT_VISIBLE_STATUSES`** - Array of statuses shown in standard device views (excludes archived/deleted)
- **`DEFAULT_DASHBOARD_STATUSES`** - Minimal status set for dashboard displays (online/offline only)
- **`HIDDEN_DEVICE_STATUSES`** - Statuses excluded from default views (archived, deleted)
- **`DefaultVisibleStatus`** and **`HiddenDeviceStatus`** - Type unions for respective status groups

## Usage Example

```typescript
import { 
  DEVICE_STATUS, 
  DEFAULT_VISIBLE_STATUSES, 
  DeviceStatus 
} from './device-statuses'

// Filter devices for main device list
const activeDevices = devices.filter(device => 
  DEFAULT_VISIBLE_STATUSES.includes(device.status as DeviceStatus)
)

// Check specific status
if (device.status === DEVICE_STATUS.MAINTENANCE) {
  showMaintenanceAlert(device)
}

// Type-safe status assignment
const newDeviceStatus: DeviceStatus = DEVICE_STATUS.PENDING
```

The file uses TypeScript's `as const` assertions and `satisfies` operator to ensure type safety while maintaining the ability to iterate over status arrays at runtime. When adding new statuses to the backend, they must be added to `DEVICE_STATUS` and the appropriate visibility arrays.
