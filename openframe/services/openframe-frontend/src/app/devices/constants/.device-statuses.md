Defines device status constants and filtered status arrays for managing device visibility across the Flamingo MSP platform. This file provides type-safe device status management with predefined visibility rules for different UI contexts.

## Key Components

- **DEVICE_STATUS** - Const object containing all available device status values (ONLINE, OFFLINE, ACTIVE, etc.)
- **DeviceStatus** - Type union of all possible device status values
- **DEFAULT_VISIBLE_STATUSES** - Array of statuses shown in standard device views (excludes ARCHIVED/DELETED)
- **DEFAULT_DASHBOARD_STATUSES** - Minimal status set for dashboard views (ONLINE/OFFLINE only)
- **HIDDEN_DEVICE_STATUSES** - Array of statuses hidden by default (ARCHIVED, DELETED)
- **DefaultVisibleStatus** & **HiddenDeviceStatus** - Type unions for filtered status categories

## Usage Example

```typescript
import { 
  DEVICE_STATUS, 
  DEFAULT_VISIBLE_STATUSES, 
  type DeviceStatus 
} from './device-statuses'

// Filter devices by visible statuses
const getActiveDevices = (devices: Device[]) => {
  return devices.filter(device => 
    DEFAULT_VISIBLE_STATUSES.includes(device.status as DeviceStatus)
  )
}

// Check specific status
if (device.status === DEVICE_STATUS.MAINTENANCE) {
  showMaintenanceAlert()
}

// Type-safe status assignment
const updateDeviceStatus = (status: DeviceStatus) => {
  // TypeScript ensures only valid statuses can be passed
  device.status = status
}
```
