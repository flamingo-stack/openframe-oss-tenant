This TypeScript file defines device status constants and filtered status arrays for the Flamingo MSP platform's device management system, providing type-safe status handling across the application.

## Key Components

- **`DEVICE_STATUS`** - Const object containing all possible device status values as string literals
- **`DeviceStatus`** - Type union of all device status values
- **`DEFAULT_VISIBLE_STATUSES`** - Array of statuses shown in standard device views (excludes ARCHIVED/DELETED)
- **`DEFAULT_DASHBOARD_STATUSES`** - Simplified status array for dashboard displays (ONLINE/OFFLINE only)
- **`HIDDEN_DEVICE_STATUSES`** - Array of statuses excluded from default views
- **`DefaultVisibleStatus`** and **`HiddenDeviceStatus`** - Type unions for filtered status arrays

## Usage Example

```typescript
import { 
  DEVICE_STATUS, 
  DEFAULT_VISIBLE_STATUSES, 
  DeviceStatus 
} from './device-statuses'

// Type-safe status assignment
const deviceStatus: DeviceStatus = DEVICE_STATUS.ONLINE

// Filter devices by visible statuses
const getActiveDevices = (devices: Device[]) => {
  return devices.filter(device => 
    DEFAULT_VISIBLE_STATUSES.includes(device.status as any)
  )
}

// Check if status is hidden
const isHidden = (status: DeviceStatus) => {
  return status === DEVICE_STATUS.ARCHIVED || 
         status === DEVICE_STATUS.DELETED
}
```

The file uses TypeScript's `const` assertions and `satisfies` operator to ensure type safety while maintaining the exact string literal values needed for API communication.
