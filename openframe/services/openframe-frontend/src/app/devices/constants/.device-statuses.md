Centralized device status constants and type definitions for the Flamingo MSP platform, providing standardized status filtering across device management views.

## Key Components

- **`DEVICE_STATUS`** - Complete enumeration of all possible device statuses
- **`DeviceStatus`** - Union type for all device status values
- **`DEFAULT_VISIBLE_STATUSES`** - Array of statuses shown in standard device views (excludes archived/deleted)
- **`DEFAULT_DASHBOARD_STATUSES`** - Subset of statuses displayed on main dashboard
- **`HIDDEN_DEVICE_STATUSES`** - Statuses excluded from default views
- **Type definitions** - `DefaultVisibleStatus` and `HiddenDeviceStatus` for type safety

  DEVICE_STATUS,
