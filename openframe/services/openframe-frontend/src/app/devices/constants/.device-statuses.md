This file defines device status constants and collections for the OpenFrame platform's device management system, providing type-safe status filtering for different views.

## Key Components

- **`DEVICE_STATUS`** - Comprehensive enum of all possible device states (ONLINE, OFFLINE, ACTIVE, etc.)
- **`DeviceStatus`** - Type derived from all possible status values
- **`DEFAULT_VISIBLE_STATUSES`** - Collection of statuses shown in standard device lists (excludes ARCHIVED/DELETED)
- **`DEFAULT_DASHBOARD_STATUSES`** - Subset for dashboard views (ONLINE/OFFLINE only)
- **`HIDDEN_DEVICE_STATUSES`** - Statuses excluded from default queries
- **`DefaultVisibleStatus`** and **`HiddenDeviceStatus`** - Type unions for specific status collections

## Usage Example

```typescript
import { 
  DEVICE_STATUS, 
  DEFAULT_VISIBLE_STATUSES, 
  type DeviceStatus 
} from './device-statuses'

// Filter devices for main listing
const visibleDevices = devices.filter(device => 
  DEFAULT_VISIBLE_STATUSES.includes(device.status as DeviceStatus)
)

// Check specific status
if (device.status === DEVICE_STATUS.MAINTENANCE) {
  showMaintenanceAlert()
}

// Type-safe status assignment
const newStatus: DeviceStatus = DEVICE_STATUS.ONLINE
```

The constants ensure consistent status handling across the platform while providing clear separation between active and archived devices. When new statuses are added to the backend, they must be included in the appropriate collections to appear in UI components.
