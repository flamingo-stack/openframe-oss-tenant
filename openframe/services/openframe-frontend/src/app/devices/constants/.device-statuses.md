Device status constants and type definitions for filtering and displaying devices across different contexts in the OpenFrame platform. Provides predefined status groups for default views, dashboard displays, and hidden statuses.

## Key Components

- **`DEVICE_STATUS`** - Enumeration of all possible device statuses (ONLINE, OFFLINE, ACTIVE, etc.)
- **`DeviceStatus`** - TypeScript type derived from the status constants
- **`DEFAULT_VISIBLE_STATUSES`** - Array of statuses shown in standard device lists (excludes ARCHIVED/DELETED)
- **`DEFAULT_DASHBOARD_STATUSES`** - Subset of statuses displayed on dashboards (ONLINE/OFFLINE only)
- **`HIDDEN_DEVICE_STATUSES`** - Statuses excluded from default views (ARCHIVED, DELETED)

## Usage Example

```typescript
import { 
  DEVICE_STATUS, 
  DEFAULT_VISIBLE_STATUSES, 
  type DeviceStatus 
} from './device-statuses'

// Filter devices by visible statuses
const getActiveDevices = (devices: Device[]) => {
  return devices.filter(device => 
    DEFAULT_VISIBLE_STATUSES.includes(device.status as DeviceStatus)
  )
}

// Check if device is online
const isDeviceOnline = (status: DeviceStatus) => {
  return status === DEVICE_STATUS.ONLINE
}

// Dashboard query with limited statuses
const dashboardQuery = {
  status: { $in: DEFAULT_DASHBOARD_STATUSES }
}
```

The constants ensure consistent device filtering across the application while maintaining type safety and clear separation between visible and hidden device states.
