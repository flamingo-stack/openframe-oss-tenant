Provides comprehensive device status constants and type definitions for the Flamingo MSP platform's device management system. This module centralizes all device statuses and defines which ones should be visible by default in different contexts.

## Key Components

- **`DEVICE_STATUS`** - Enum-like constant object defining all possible device statuses
- **`DeviceStatus`** - Type union of all possible status values
- **`DEFAULT_VISIBLE_STATUSES`** - Array of statuses shown in standard device queries (excludes ARCHIVED/DELETED)
- **`DEFAULT_DASHBOARD_STATUSES`** - Limited status set for dashboard displays (ONLINE/OFFLINE only)
- **`HIDDEN_DEVICE_STATUSES`** - Statuses excluded from default views
- **`DefaultVisibleStatus`** and **`HiddenDeviceStatus`** - Specific type unions for different status categories

## Usage Example

```typescript
import { 
  DEVICE_STATUS, 
  DEFAULT_VISIBLE_STATUSES, 
  DeviceStatus 
} from './device-statuses'

// Filter devices for standard views
const getActiveDevices = async () => {
  return await deviceQuery({
    status: { $in: DEFAULT_VISIBLE_STATUSES }
  })
}

// Check specific status
const isDeviceOnline = (status: DeviceStatus) => {
  return status === DEVICE_STATUS.ONLINE
}

// Type-safe status handling
const handleStatusChange = (newStatus: DeviceStatus) => {
  if (DEFAULT_VISIBLE_STATUSES.includes(newStatus as any)) {
    // Show in UI
  } else {
    // Hide from default views
  }
}
```

This module ensures consistent device status handling across the platform and provides clear separation between visible and hidden device states for UI filtering.
