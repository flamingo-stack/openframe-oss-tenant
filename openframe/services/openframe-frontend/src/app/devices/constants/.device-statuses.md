A TypeScript constants file that defines device status enums and filtered status arrays for managing device visibility across different UI contexts in the OpenFrame platform.

## Key Components

- **`DEVICE_STATUS`** - Const assertion object containing all possible device status values
- **`DeviceStatus`** - Type derived from all DEVICE_STATUS keys for type safety
- **`DEFAULT_VISIBLE_STATUSES`** - Array of statuses shown in standard device views (excludes ARCHIVED/DELETED)
- **`DEFAULT_DASHBOARD_STATUSES`** - Subset of statuses displayed on dashboard views (ONLINE/OFFLINE only)
- **`HIDDEN_DEVICE_STATUSES`** - Array of statuses excluded from default views
- **`DefaultVisibleStatus`** and **`HiddenDeviceStatus`** - Specific types for filtered status arrays

## Usage Example

```typescript
import { 
  DEVICE_STATUS, 
  DEFAULT_VISIBLE_STATUSES, 
  type DeviceStatus 
} from './device-statuses'

// Type-safe status checking
function isDeviceOnline(status: DeviceStatus): boolean {
  return status === DEVICE_STATUS.ONLINE
}

// Filter devices for default views
const visibleDevices = devices.filter(device => 
  DEFAULT_VISIBLE_STATUSES.includes(device.status as any)
)

// API query with visible statuses
const queryParams = {
  statuses: DEFAULT_VISIBLE_STATUSES,
  // Excludes ARCHIVED and DELETED automatically
}
```

The file serves as a single source of truth for device status management, ensuring consistent filtering across the application while providing type safety and clear separation between visible and hidden device states.
