Defines device status constants and filtering arrays for the Flamingo MSP platform's device management system. Provides type-safe status definitions and pre-configured status groups for different UI contexts.

## Key Components

- **`DEVICE_STATUS`** - Constant object defining all possible device status values (ONLINE, OFFLINE, ACTIVE, etc.)
- **`DeviceStatus`** - TypeScript type derived from the status constant keys
- **`DEFAULT_VISIBLE_STATUSES`** - Array of statuses shown in standard device views (excludes ARCHIVED/DELETED)
- **`DEFAULT_DASHBOARD_STATUSES`** - Simplified status list for dashboard displays (ONLINE/OFFLINE only)
- **`HIDDEN_DEVICE_STATUSES`** - Statuses excluded from default views
- **Type definitions** - `DefaultVisibleStatus` and `HiddenDeviceStatus` for type safety

## Usage Example

```typescript
import { 
  DEVICE_STATUS, 
  DEFAULT_VISIBLE_STATUSES,
  type DeviceStatus 
} from './device-statuses'

// Filter devices by visible statuses
const visibleDevices = allDevices.filter(device => 
  DEFAULT_VISIBLE_STATUSES.includes(device.status)
)

// Check specific status
if (device.status === DEVICE_STATUS.MAINTENANCE) {
  showMaintenanceAlert()
}

// Type-safe status assignment
const updateStatus = (status: DeviceStatus) => {
  // TypeScript ensures only valid statuses are passed
  device.status = status
}
```

The file serves as a single source of truth for device status management, ensuring consistency across the application and providing clear separation between active and archived devices.
