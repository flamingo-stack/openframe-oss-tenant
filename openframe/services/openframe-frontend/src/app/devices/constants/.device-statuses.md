Provides constants and type definitions for managing device status states in the Flamingo MSP platform, including default filtering configurations for different views.

## Key Components

- **`DEVICE_STATUS`** - Enum-like object containing all possible device status values (ONLINE, OFFLINE, ACTIVE, etc.)
- **`DeviceStatus`** - Type union of all possible device statuses
- **`DEFAULT_VISIBLE_STATUSES`** - Array of statuses shown in standard device queries (excludes ARCHIVED/DELETED)
- **`DEFAULT_DASHBOARD_STATUSES`** - Limited set of statuses for dashboard displays (ONLINE/OFFLINE only)
- **`HIDDEN_DEVICE_STATUSES`** - Statuses excluded from default views (ARCHIVED, DELETED)
- **`DefaultVisibleStatus`** and **`HiddenDeviceStatus`** - Type-safe unions for filtered status sets

## Usage Example

```typescript
import { 
  DEVICE_STATUS, 
  DEFAULT_VISIBLE_STATUSES, 
  type DeviceStatus 
} from './device-statuses'

// Filter devices by active statuses only
const activeDevices = devices.filter(device => 
  DEFAULT_VISIBLE_STATUSES.includes(device.status as DeviceStatus)
)

// Check specific status
if (device.status === DEVICE_STATUS.MAINTENANCE) {
  showMaintenanceWarning(device)
}

// Type-safe status assignment
const updateDeviceStatus = (status: DeviceStatus) => {
  // TypeScript will enforce valid status values
  device.status = status
}
```

The constants ensure consistent device filtering across the application while maintaining type safety and clear separation between visible and hidden device states.
