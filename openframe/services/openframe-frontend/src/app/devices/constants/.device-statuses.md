Defines device status constants and visibility configurations for filtering device displays across the application.

## Key Components

- **`DEVICE_STATUS`** - Complete enum-like object containing all possible device status values
- **`DeviceStatus`** - Type representing any valid device status
- **`DEFAULT_VISIBLE_STATUSES`** - Array of statuses shown in standard device listings (excludes ARCHIVED/DELETED)
- **`DEFAULT_DASHBOARD_STATUSES`** - Subset of statuses displayed on dashboard views (ONLINE/OFFLINE only)
- **`HIDDEN_DEVICE_STATUSES`** - Statuses excluded from default views
- **`DefaultVisibleStatus`** / **`HiddenDeviceStatus`** - Utility types for type-safe status filtering

## Usage Example

```typescript
import { 
  DEVICE_STATUS, 
  DEFAULT_VISIBLE_STATUSES, 
  type DeviceStatus 
} from './device-statuses'

// Filter devices for main listing
const getActiveDevices = (devices: Device[]) => {
  return devices.filter(device => 
    DEFAULT_VISIBLE_STATUSES.includes(device.status as DefaultVisibleStatus)
  )
}

// Check specific status
const isOnline = (status: DeviceStatus) => {
  return status === DEVICE_STATUS.ONLINE
}

// API query with visible statuses
const fetchDevices = () => {
  return api.get('/devices', {
    params: { statuses: DEFAULT_VISIBLE_STATUSES.join(',') }
  })
}
```

This configuration ensures consistent device filtering across the application while maintaining type safety and providing clear documentation about which statuses are visible by default.
