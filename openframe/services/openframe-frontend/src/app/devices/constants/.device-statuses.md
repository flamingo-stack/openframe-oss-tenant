This TypeScript constants file defines device status types and filtering presets for the Flamingo MSP platform's device management system. It provides type-safe status enums and pre-configured status arrays for different UI contexts.

## Key Components

- **`DEVICE_STATUS`** - Const object defining all possible device status values as string literals
- **`DeviceStatus`** - Type union of all available device statuses
- **`DEFAULT_VISIBLE_STATUSES`** - Array of statuses shown in standard device lists (excludes ARCHIVED/DELETED)
- **`DEFAULT_DASHBOARD_STATUSES`** - Minimal status set for dashboard views (ONLINE/OFFLINE only)
- **`HIDDEN_DEVICE_STATUSES`** - Statuses excluded from default queries (ARCHIVED/DELETED)
- **`DefaultVisibleStatus`** and **`HiddenDeviceStatus`** - Derived types for the filtered status arrays

## Usage Example

```typescript
import { DEVICE_STATUS, DEFAULT_VISIBLE_STATUSES, type DeviceStatus } from './device-statuses'

// Type-safe status checking
function isDeviceActive(status: DeviceStatus): boolean {
  return status === DEVICE_STATUS.ONLINE || status === DEVICE_STATUS.ACTIVE
}

// Filter devices for standard views
const visibleDevices = allDevices.filter(device => 
  DEFAULT_VISIBLE_STATUSES.includes(device.status as any)
)

// API query with default statuses
const queryParams = {
  statuses: DEFAULT_VISIBLE_STATUSES,
  limit: 100
}
```

The constants ensure consistent device filtering across the application while maintaining type safety and providing clear documentation of which statuses are visible in different contexts.
