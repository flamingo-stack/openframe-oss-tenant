A comprehensive TypeScript constants file that defines device status types and filtering arrays for the Flamingo MSP platform's device management system.

## Key Components

- **`DEVICE_STATUS`** - Enum-like constant object defining all possible device states (ONLINE, OFFLINE, ACTIVE, etc.)
- **`DeviceStatus`** - Type alias for all possible device status values
- **`DEFAULT_VISIBLE_STATUSES`** - Array of statuses shown in standard device views (excludes ARCHIVED/DELETED)
- **`DEFAULT_DASHBOARD_STATUSES`** - Minimal status set for dashboard displays (ONLINE/OFFLINE only)
- **`HIDDEN_DEVICE_STATUSES`** - Statuses excluded from default views
- **Type aliases** - `DefaultVisibleStatus` and `HiddenDeviceStatus` for type safety

## Usage Example

```typescript
import { 
  DEVICE_STATUS, 
  DEFAULT_VISIBLE_STATUSES, 
  type DeviceStatus 
} from './device-statuses'

// Filter devices for main view (excludes archived/deleted)
const visibleDevices = devices.filter(device => 
  DEFAULT_VISIBLE_STATUSES.includes(device.status as DeviceStatus)
)

// Check specific status
if (device.status === DEVICE_STATUS.MAINTENANCE) {
  showMaintenanceAlert()
}

// Type-safe status handling
function updateDeviceStatus(deviceId: string, status: DeviceStatus) {
  // TypeScript ensures only valid statuses can be passed
  api.updateDevice(deviceId, { status })
}
```

The file provides a centralized location for device status management with built-in filtering logic for different UI contexts, ensuring consistent device visibility across the OpenFrame platform.
