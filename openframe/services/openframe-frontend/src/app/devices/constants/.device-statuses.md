This file defines device status constants and filtered status collections for OpenFrame's device management system, ensuring consistent status handling across the platform.

## Key Components

- **DEVICE_STATUS** - Complete enum-like object containing all possible device statuses
- **DeviceStatus** - Type representing any valid device status
- **DEFAULT_VISIBLE_STATUSES** - Array of statuses shown in standard device views (excludes archived/deleted)
- **DEFAULT_DASHBOARD_STATUSES** - Subset of statuses displayed on dashboard views
- **HIDDEN_DEVICE_STATUSES** - Statuses that are filtered out by default
- **DefaultVisibleStatus** & **HiddenDeviceStatus** - Helper types for filtered status arrays

## Usage Example

```typescript
import { 
  DEVICE_STATUS, 
  DEFAULT_VISIBLE_STATUSES, 
  type DeviceStatus 
} from './device-statuses'

// Check if device is in maintenance
const isInMaintenance = (status: DeviceStatus) => 
  status === DEVICE_STATUS.MAINTENANCE

// Filter devices for standard views
const getActiveDevices = (devices: Device[]) =>
  devices.filter(device => 
    DEFAULT_VISIBLE_STATUSES.includes(device.status as any)
  )

  }
}
```

The file ensures type safety while providing clear separation between visible and hidden device statuses for different UI contexts.
