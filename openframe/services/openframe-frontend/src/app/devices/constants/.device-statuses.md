A TypeScript constants file that defines device status enumerations and filtering presets for managing device visibility across the Flamingo MSP platform.

## Key Components

- **`DEVICE_STATUS`** - Immutable enum-like object containing all possible device statuses
- **`DeviceStatus`** - Type union derived from DEVICE_STATUS values
- **`DEFAULT_VISIBLE_STATUSES`** - Array of statuses shown in standard device lists (excludes ARCHIVED/DELETED)
- **`DEFAULT_DASHBOARD_STATUSES`** - Minimal status set for dashboard views (ONLINE/OFFLINE only)
- **`HIDDEN_DEVICE_STATUSES`** - Statuses excluded from default views for documentation reference
- **Type definitions** - `DefaultVisibleStatus` and `HiddenDeviceStatus` for type safety

## Usage Example

```typescript
import { 
  DEVICE_STATUS, 
  DEFAULT_VISIBLE_STATUSES, 
  type DeviceStatus 
} from './device-statuses'

// Filter devices for standard list view
const getActiveDevices = (devices: Device[]) => {
  return devices.filter(device => 
    DEFAULT_VISIBLE_STATUSES.includes(device.status as DeviceStatus)
  )
}

// Check specific status
const isOnline = (status: DeviceStatus) => 
  status === DEVICE_STATUS.ONLINE

// Dashboard query with minimal statuses
const dashboardQuery = {
  statuses: DEFAULT_DASHBOARD_STATUSES,
  limit: 50
}
```

This centralized approach ensures consistent device filtering across components while maintaining type safety and providing clear documentation about which statuses are visible by default.
