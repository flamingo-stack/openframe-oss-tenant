Defines device status constants and collections for filtering devices in OpenFrame MSP platform queries. This module provides type-safe status management with predefined status groups for different UI contexts.

## Key Components

### Constants
- **`DEVICE_STATUS`** - Enum-like object containing all possible device statuses (ONLINE, OFFLINE, ACTIVE, etc.)
- **`DEFAULT_VISIBLE_STATUSES`** - Array of statuses shown in standard device queries (excludes ARCHIVED/DELETED)
- **`DEFAULT_DASHBOARD_STATUSES`** - Subset for dashboard views (ONLINE/OFFLINE only)
- **`HIDDEN_DEVICE_STATUSES`** - Statuses excluded from default views (ARCHIVED/DELETED)

### Types
- **`DeviceStatus`** - Union type of all valid device statuses
- **`DefaultVisibleStatus`** - Type for statuses included in default queries
- **`HiddenDeviceStatus`** - Type for archived/deleted statuses

## Usage Example

```typescript
import { DEVICE_STATUS, DEFAULT_VISIBLE_STATUSES, DeviceStatus } from './device-statuses'

// Filter devices for main dashboard
const activeDevices = devices.filter(device => 
  DEFAULT_VISIBLE_STATUSES.includes(device.status as DeviceStatus)
)

// Check specific status
if (device.status === DEVICE_STATUS.MAINTENANCE) {
  showMaintenanceAlert(device)
}

// Type-safe status assignment
const deviceStatus: DeviceStatus = DEVICE_STATUS.ONLINE
```

The module ensures consistent device filtering across the platform and provides type safety for status-related operations.
