Defines device status constants and type-safe filters for managing device visibility across the OpenFrame platform. This module provides standardized status enums and pre-configured visibility groups for different UI contexts.

## Key Components

### Constants
- **`DEVICE_STATUS`** - Enum-like object containing all possible device status values
- **`DEFAULT_VISIBLE_STATUSES`** - Array of statuses shown in standard device views (excludes archived/deleted)
- **`DEFAULT_DASHBOARD_STATUSES`** - Subset of statuses for dashboard displays (online/offline only)
- **`HIDDEN_DEVICE_STATUSES`** - Statuses excluded from default views (archived/deleted)

### Types
- **`DeviceStatus`** - Union type of all possible device status values
- **`DefaultVisibleStatus`** - Type for statuses included in default views
- **`HiddenDeviceStatus`** - Type for statuses excluded from default views

## Usage Example

```typescript
import { 
  DEVICE_STATUS, 
  DEFAULT_VISIBLE_STATUSES, 
  type DeviceStatus 
} from './device-statuses'

// Filter devices for main listing
const activeDevices = devices.filter(device => 
  DEFAULT_VISIBLE_STATUSES.includes(device.status as DeviceStatus)
)

// Check specific status
if (device.status === DEVICE_STATUS.MAINTENANCE) {
  showMaintenanceAlert(device)
}

// Type-safe status validation
function updateDeviceStatus(deviceId: string, status: DeviceStatus) {
  // TypeScript ensures only valid statuses can be passed
  return api.updateDevice(deviceId, { status })
}
```

The module ensures consistent device filtering across the application while maintaining type safety and making it easy to adjust visibility rules centrally.
