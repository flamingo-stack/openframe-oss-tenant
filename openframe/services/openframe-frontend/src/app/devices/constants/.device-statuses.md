This TypeScript file defines device status constants and filtered status arrays for the OpenFrame MSP platform's device management system.

## Key Components

- **`DEVICE_STATUS`** - Enumeration of all possible device status values including ONLINE, OFFLINE, MAINTENANCE, ARCHIVED, etc.
- **`DeviceStatus`** - Type union derived from all DEVICE_STATUS values
- **`DEFAULT_VISIBLE_STATUSES`** - Array of statuses shown in standard device queries (excludes ARCHIVED/DELETED)
- **`DEFAULT_DASHBOARD_STATUSES`** - Minimal status set for dashboard views (ONLINE/OFFLINE only)
- **`HIDDEN_DEVICE_STATUSES`** - Array of statuses hidden from default views (ARCHIVED/DELETED)
- **Type definitions** - `DefaultVisibleStatus` and `HiddenDeviceStatus` for type safety

## Usage Example

```typescript
import { 
  DEVICE_STATUS, 
  DEFAULT_VISIBLE_STATUSES, 
  DeviceStatus 
} from './device-statuses'

// Filter devices for main dashboard
const dashboardDevices = devices.filter(device => 
  DEFAULT_VISIBLE_STATUSES.includes(device.status as DeviceStatus)
)

// Check specific status
if (device.status === DEVICE_STATUS.MAINTENANCE) {
  // Handle maintenance mode
}

// Query with visible statuses only
const activeDevices = await getDevices({
  statuses: DEFAULT_VISIBLE_STATUSES
})
```

This constant-based approach ensures consistent device status handling across the OpenFrame platform while maintaining type safety and clear separation between active and archived devices.
