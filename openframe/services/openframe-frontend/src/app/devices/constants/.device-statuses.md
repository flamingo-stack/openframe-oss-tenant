Defines device status constants and filtered status arrays for the OpenFrame MSP platform's device management system. This module provides type-safe status definitions and pre-configured status groups for different UI contexts.

## Key Components

- **`DEVICE_STATUS`** - Complete enumeration of all possible device statuses (ONLINE, OFFLINE, ACTIVE, INACTIVE, MAINTENANCE, DECOMMISSIONED, PENDING, ARCHIVED, DELETED)
- **`DEFAULT_VISIBLE_STATUSES`** - Array of statuses shown in standard device views (excludes ARCHIVED and DELETED)
- **`DEFAULT_DASHBOARD_STATUSES`** - Simplified status array for dashboard displays (ONLINE, OFFLINE only)
- **`HIDDEN_DEVICE_STATUSES`** - Statuses filtered out of default views (ARCHIVED, DELETED)
- **Type definitions** - `DeviceStatus`, `DefaultVisibleStatus`, and `HiddenDeviceStatus` for type safety

## Usage Example

```typescript
import { 
  DEVICE_STATUS, 
  DEFAULT_VISIBLE_STATUSES, 
  type DeviceStatus 
} from './device-statuses'

// Check if device is in a visible state
function isDeviceVisible(status: DeviceStatus): boolean {
  return DEFAULT_VISIBLE_STATUSES.includes(status as any)
}

// Filter devices by status
const activeDevices = devices.filter(device => 
  device.status === DEVICE_STATUS.ONLINE || 
  device.status === DEVICE_STATUS.ACTIVE
)

// Use in API queries for standard device listings
const query = {
  where: {
    status: { in: DEFAULT_VISIBLE_STATUSES }
  }
}
```

The module uses `as const` assertions and `satisfies` for strict type checking, ensuring status consistency across the application while maintaining compile-time safety.
