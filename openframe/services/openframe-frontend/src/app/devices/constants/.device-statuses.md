Defines device status constants and filters for the Flamingo MSP platform, providing type-safe status management with predefined visibility rules for different UI contexts.

## Key Components

- **`DEVICE_STATUS`** - Comprehensive enum-like object containing all possible device statuses (ONLINE, OFFLINE, ACTIVE, INACTIVE, MAINTENANCE, DECOMMISSIONED, PENDING, ARCHIVED, DELETED)
- **`DEFAULT_VISIBLE_STATUSES`** - Array of statuses shown in standard device queries (excludes ARCHIVED and DELETED)
- **`DEFAULT_DASHBOARD_STATUSES`** - Minimal status set for dashboard views (ONLINE and OFFLINE only)
- **`HIDDEN_DEVICE_STATUSES`** - Statuses excluded from default views (ARCHIVED, DELETED)
- **Type definitions** - `DeviceStatus`, `DefaultVisibleStatus`, and `HiddenDeviceStatus` for type safety

## Usage Example

```typescript
import { 
  DEVICE_STATUS, 
  DEFAULT_VISIBLE_STATUSES,
  DEFAULT_DASHBOARD_STATUSES,
  type DeviceStatus 
} from './device-statuses'

// Filter devices for standard views
const visibleDevices = devices.filter(device => 
  DEFAULT_VISIBLE_STATUSES.includes(device.status as DefaultVisibleStatus)
)

// Dashboard-specific filtering
const dashboardDevices = devices.filter(device =>
  DEFAULT_DASHBOARD_STATUSES.includes(device.status as any)
)

// Type-safe status checking
function isDeviceOnline(status: DeviceStatus): boolean {
  return status === DEVICE_STATUS.ONLINE
}

// Query with default visible statuses
const query = {
  status: { $in: DEFAULT_VISIBLE_STATUSES }
}
```

The file serves as a single source of truth for device status management across the OpenFrame platform, ensuring consistent filtering and display logic.
