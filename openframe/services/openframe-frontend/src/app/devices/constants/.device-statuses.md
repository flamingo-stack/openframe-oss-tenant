Constants and types for device status management in the Flamingo platform. This file provides a centralized definition of all possible device states and filtered sets for different UI contexts.

## Key Components

- **`DEVICE_STATUS`** - Complete enum-like object defining all available device statuses (ONLINE, OFFLINE, ACTIVE, etc.)
- **`DeviceStatus`** - TypeScript type derived from all status values
- **`DEFAULT_VISIBLE_STATUSES`** - Array of statuses shown in standard device views (excludes ARCHIVED/DELETED)
- **`DEFAULT_DASHBOARD_STATUSES`** - Minimal status set for dashboard displays (ONLINE/OFFLINE only)
- **`HIDDEN_DEVICE_STATUSES`** - Statuses excluded from default views
- **Type definitions** - `DefaultVisibleStatus` and `HiddenDeviceStatus` for type safety

## Usage Example

```typescript
import { 
  DEVICE_STATUS, 
  DEFAULT_VISIBLE_STATUSES, 
  type DeviceStatus 
} from './device-statuses'

// Filter devices by visible statuses
const activeDevices = devices.filter(device => 
  DEFAULT_VISIBLE_STATUSES.includes(device.status as DeviceStatus)
)

// Check specific status
if (device.status === DEVICE_STATUS.MAINTENANCE) {
  showMaintenanceAlert()
}

// Type-safe status handling
function handleDeviceStatus(status: DeviceStatus) {
  switch (status) {
    case DEVICE_STATUS.ONLINE:
      return 'green'
    case DEVICE_STATUS.OFFLINE:
      return 'red'
    default:
      return 'gray'
  }
}
```

The constants ensure consistent device filtering across the platform and provide type safety for status-related operations.
