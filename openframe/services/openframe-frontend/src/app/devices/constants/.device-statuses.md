Device status constants and type definitions for filtering and displaying devices in the Flamingo MSP platform. This module provides predefined status categories to ensure consistent device visibility across different views.

## Key Components

- **`DEVICE_STATUS`** - Enumeration of all possible device statuses including ONLINE, OFFLINE, ACTIVE, INACTIVE, MAINTENANCE, DECOMMISSIONED, PENDING, ARCHIVED, and DELETED
- **`DEFAULT_VISIBLE_STATUSES`** - Array of statuses shown in standard device queries (excludes ARCHIVED and DELETED)
- **`DEFAULT_DASHBOARD_STATUSES`** - Minimal status set for dashboard views (ONLINE and OFFLINE only)
- **`HIDDEN_DEVICE_STATUSES`** - Statuses that are filtered out by default (ARCHIVED and DELETED)
- **Type definitions** - `DeviceStatus`, `DefaultVisibleStatus`, and `HiddenDeviceStatus` for type safety

## Usage Example

```typescript
import { 
  DEVICE_STATUS, 
  DEFAULT_VISIBLE_STATUSES, 
  DEFAULT_DASHBOARD_STATUSES,
  type DeviceStatus 
} from './device-statuses'

// Filter devices for main inventory view
const visibleDevices = devices.filter(device => 
  DEFAULT_VISIBLE_STATUSES.includes(device.status as DeviceStatus)
)

// Dashboard query with minimal statuses
const dashboardQuery = {
  statuses: DEFAULT_DASHBOARD_STATUSES,
  limit: 100
}

// Check if device should be shown
const isVisible = device.status !== DEVICE_STATUS.ARCHIVED && 
                 device.status !== DEVICE_STATUS.DELETED

// Type-safe status comparison
const isOnline: boolean = device.status === DEVICE_STATUS.ONLINE
```

This module centralizes device status management and ensures that new backend statuses must be explicitly added to visibility arrays to appear in frontend views.
