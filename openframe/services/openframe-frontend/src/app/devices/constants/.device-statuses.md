A TypeScript constants file that defines device status enums and filtered status arrays for the Flamingo MSP platform's device management system.

## Key Components

- **`DEVICE_STATUS`** - Const assertion object containing all possible device status values
- **`DeviceStatus`** - Type union of all device status string literals
- **`DEFAULT_VISIBLE_STATUSES`** - Array of statuses shown in standard device queries (excludes ARCHIVED/DELETED)
- **`DEFAULT_DASHBOARD_STATUSES`** - Subset of statuses displayed on dashboard views (ONLINE/OFFLINE only)
- **`HIDDEN_DEVICE_STATUSES`** - Statuses excluded from default views for cleanup/archival purposes
- **`DefaultVisibleStatus`** and **`HiddenDeviceStatus`** - Derived types from the respective status arrays

## Usage Example

```typescript
import { 
  DEVICE_STATUS, 
  DEFAULT_VISIBLE_STATUSES, 
  type DeviceStatus 
} from './device-statuses'

// Filter devices by visible statuses
const activeDevices = devices.filter(device => 
  DEFAULT_VISIBLE_STATUSES.includes(device.status as DeviceStatus)
)

// Check specific status
if (device.status === DEVICE_STATUS.MAINTENANCE) {
  showMaintenanceAlert(device)
}

// Type-safe status assignment
const updateDeviceStatus = (status: DeviceStatus) => {
  // TypeScript ensures only valid statuses can be passed
  return api.updateDevice({ status })
}
```

The constants provide a single source of truth for device status management across the OpenFrame platform, ensuring consistent filtering and type safety when working with device states.
