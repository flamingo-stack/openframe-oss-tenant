This file defines the tab navigation configuration for device detail views in the OpenFrame platform, providing a centralized registry of all available device management tabs with their associated icons and components.

## Key Components

- **DEVICE_TABS**: Array of `TabItem` objects defining the complete tab configuration for device views
- **getDeviceTab()**: Helper function to retrieve a specific tab configuration by ID
- **getTabComponent()**: Utility to extract the React component for a given tab ID

The file exports 9 device management tabs covering hardware monitoring, network configuration, security settings, compliance tracking, agent management, user access, software inventory, vulnerability assessment, and system logs.

## Usage Example

```typescript
import { DEVICE_TABS, getDeviceTab, getTabComponent } from './device-tabs'

// Render all tabs in navigation
const DeviceNavigation = () => (
  <nav>
    {DEVICE_TABS.map(tab => (
      <TabButton
        key={tab.id}
        icon={tab.icon}
        label={tab.label}
        onClick={() => setActiveTab(tab.id)}
      />
    ))}
  </nav>
)

// Get specific tab configuration
const securityTab = getDeviceTab('security')
console.log(securityTab?.label) // 'Security'

// Dynamically render tab component
const TabContent = ({ activeTabId, device }) => {
  const Component = getTabComponent(activeTabId)
  return Component ? <Component device={device} /> : null
}
```
