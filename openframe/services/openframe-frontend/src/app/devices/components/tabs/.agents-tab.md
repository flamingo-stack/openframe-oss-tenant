React component that displays device management agents in a grid layout, showing installed agents and their connection status to various management platforms.

## Key Components

- **AgentsTab**: Main component that renders a grid of agent cards
- **agentTypeToToolType**: Mapping object that converts agent types to standardized tool type identifiers
- **Agent Card Layout**: Individual cards showing agent badges, connection info, and tooltips
- **Combined Agent Logic**: Merges installed agents with tool connections for comprehensive display

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'

// Device object with agents and connections
const device = {
  id: 'device-123',
  installedAgents: [
    {
      agentType: 'tacticalrmm-agent',
      version: '1.7.0'
    }
  ],
  toolConnections: [
    {
      toolType: 'TACTICAL_RMM',
      agentToolId: 'agent-456'
    }
  ]
}

// Render the agents tab
<AgentsTab device={device} />
```

The component automatically maps agent types to their corresponding tool types, displays connection status with badges and tooltips, and sorts agents to prioritize those with active connections. When no agents are found, it shows an informative placeholder card.
