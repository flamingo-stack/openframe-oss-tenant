A React component that displays information about management agents installed on a device, combining data from installed agents and tool connections to provide a comprehensive view of remote management capabilities.

## Key Components

- **AgentsTab**: Main component that renders agent information in a grid layout
- **agentTypeToToolType**: Mapping object that converts agent types to standardized tool types
- **connectionMap**: Map structure for efficiently looking up tool connections by type
- **combinedAgents**: Merged data structure combining installed agents with their corresponding tool connections

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

const deviceData: Device = {
  id: 'device-123',
  installedAgents: [
    {
      agentType: 'tacticalrmm-agent',
      version: '2.1.0'
    }
  ],
  toolConnections: [
    {
      toolType: 'TACTICAL_RMM',
      agentToolId: 'agent-456'
    }
  ]
}

function DevicePage() {
  return (
    <div>
      <h2>Device Management</h2>
      <AgentsTab device={deviceData} />
    </div>
  )
}
```

The component automatically merges agent installation data with tool connection information, displays agents in cards with tool badges and tooltips, and handles cases where agents are installed but not connected or vice versa. Cards are sorted to prioritize agents with active connections.
