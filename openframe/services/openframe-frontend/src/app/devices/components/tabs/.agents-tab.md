React component for displaying and managing device agents in the OpenFrame platform. Combines installed agents with tool connections to show a unified view of device management capabilities.

## Key Components

- **AgentsTab** - Main component that renders agent information in a responsive grid layout
- **agentTypeToToolType** - Mapping object that converts agent types to standardized tool types
- **combinedAgents** - Merged data structure combining installed agents with tool connections
- **InfoCard** - Display component for showing agent details with copyable IDs and versions
- **ToolBadge** - Visual indicator showing the agent/tool type with proper branding

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

// Example device with agents and tool connections
const device: Device = {
  id: 'device-123',
  toolConnections: [
    { toolType: 'TACTICAL_RMM', agentToolId: 'trm-456' }
  ],
  installedAgents: [
    { agentType: 'tacticalrmm-agent', version: '1.2.3' }
  ]
}

// Render agents tab in device details
function DeviceDetails() {
  return (
    <div>
      <AgentsTab device={device} />
    </div>
  )
}
```

The component automatically merges installed agent data with tool connections, sorts agents by connection status, and displays them in responsive cards with tooltips for additional context. When no agents are found, it shows an informative empty state.
