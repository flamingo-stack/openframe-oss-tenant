A React component that displays and manages device management agents in a grid layout, combining installed agents with tool connections to show comprehensive agent status information.

## Key Components

- **AgentsTab**: Main component that renders agent information in cards
- **agentTypeToToolType**: Mapping object converting agent types to standardized tool types
- **combinedAgents**: Merged data structure combining installed agents with tool connections
- **InfoCard**: Display component for individual agent information
- **ToolBadge**: Visual indicator for different agent/tool types
- **Tooltip system**: Contextual help for agent status and information

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

const device: Device = {
  id: 'device-123',
  installedAgents: [
    {
      agentType: 'tactical-rmm-agent',
      version: '1.2.3'
    }
  ],
  toolConnections: [
    {
      toolType: 'TACTICAL_RMM',
      agentToolId: 'agent-456'
    }
  ]
}

export function DevicePage() {
  return <AgentsTab device={device} />
}
```

The component intelligently merges installed agents with tool connections, prioritizes agents with connection IDs, and provides helpful tooltips explaining agent status. It handles empty states gracefully and uses responsive grid layouts for optimal display across devices.
