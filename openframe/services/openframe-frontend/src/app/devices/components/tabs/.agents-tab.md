This React component displays management agents installed on a device in a grid layout with connection status and version information.

## Key Components

- **AgentsTab**: Main component that renders a grid of agent cards
- **agentTypeToToolType**: Mapping object that converts agent types to standardized tool types
- **combinedAgents**: Merged data structure combining installed agents with tool connections
- **InfoCard/ToolBadge**: UI components for displaying agent information with visual badges

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

const device: Device = {
  id: 'device-123',
  installedAgents: [
    { agentType: 'tacticalrmm-agent', version: '1.2.3' }
  ],
  toolConnections: [
    { toolType: 'TACTICAL_RMM', agentToolId: 'agent-456' }
  ]
}

function DeviceManagement() {
  return (
    <div>
      <h2>Device Agents</h2>
      <AgentsTab device={device} />
    </div>
  )
}
```

The component intelligently merges installed agents with their corresponding tool connections, prioritizes agents with connection IDs, and provides helpful tooltips explaining each agent's purpose. When no agents are found, it displays an informative empty state.
