A React component that displays management agents installed on a device, showing both connected agents from external tools and locally installed agents with their versions and connection status.

## Key Components

- **AgentsTab** - Main component that renders a grid of agent cards
- **agentTypeToToolType** - Mapping object that converts agent types to standardized tool types
- **combinedAgents** - Merged data structure combining installed agents with tool connections
- **InfoCard & ToolBadge** - UI components for displaying agent information with visual indicators

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from './types/device.types'

function DeviceManagement() {
  const device: Device = {
    id: 'device-123',
    name: 'Workstation-01',
    installedAgents: [
      { 
        agentType: 'tacticalrmm-agent', 
        version: '2.4.0' 
      }
    ],
    toolConnections: [
      { 
        toolType: 'TACTICAL_RMM', 
        agentToolId: 'agent-456' 
      }
    ]
  }

  return (
    <div>
      <h2>Device Agents</h2>
      <AgentsTab device={device} />
    </div>
  )
}
```

The component intelligently merges local agent data with external tool connections, prioritizes agents with tool IDs, and provides helpful tooltips explaining each agent's purpose and connection status.
