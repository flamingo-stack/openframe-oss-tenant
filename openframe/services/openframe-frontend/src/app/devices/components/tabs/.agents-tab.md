A React component that displays a grid of management agent cards for a device, showing both installed agents and connected tool integrations.

## Key Components

- **AgentsTab**: Main component that renders a responsive grid of agent information cards
- **agentTypeToToolType**: Mapping object that converts agent types to standardized tool types
- **combinedAgents**: Merged array of installed agents and tool connections with connection status
- **InfoCard**: Displays agent details including ID, version, and connection status
- **ToolBadge**: Shows visual badge for each tool type
- **Tooltip**: Provides contextual help information for each agent

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../types/device.types'

function DevicePage({ device }: { device: Device }) {
  return (
    <div>
      <h2>Device Management</h2>
      <AgentsTab device={device} />
    </div>
  )
}

// Example device data structure
const exampleDevice: Device = {
  id: 'device-123',
  toolConnections: [
    {
      toolType: 'TACTICAL_RMM',
      agentToolId: 'trm-agent-456'
    }
  ],
  installedAgents: [
    {
      agentType: 'tacticalrmm-agent',
      version: '2.1.0'
    }
  ]
}
```

The component handles empty states, sorts agents by connection priority, and provides tooltips explaining agent functionality. It merges installed agent data with tool connections to show a comprehensive view of device management capabilities.
