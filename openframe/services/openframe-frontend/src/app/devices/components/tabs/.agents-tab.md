A React component that displays device management agents in a tabbed interface, combining installed agent data with tool connection information to show comprehensive agent status and details.

## Key Components

- **AgentsTab**: Main component that renders agent information in a responsive grid layout
- **agentTypeToToolType**: Mapping object that converts agent type strings to standardized tool types
- **combinedAgents**: Merged data structure combining installed agents with their connection status
- **InfoCard**: Displays individual agent details with badges and tooltips
- **ToolBadge**: Visual indicator showing the agent/tool type

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

const deviceData: Device = {
  id: 'device-123',
  installedAgents: [
    {
      agentType: 'tacticalrmm-agent',
      version: '1.2.3'
    }
  ],
  toolConnections: [
    {
      toolType: 'TACTICAL_RMM',
      agentToolId: 'agent-456'
    }
  ]
}

function DeviceView({ device }: { device: Device }) {
  return (
    <div>
      <AgentsTab device={device} />
    </div>
  )
}
```

The component intelligently merges installed agents with tool connections, displays agents with connection IDs first, and provides helpful tooltips explaining each agent's purpose. It gracefully handles empty states when no agents are found on the device.
