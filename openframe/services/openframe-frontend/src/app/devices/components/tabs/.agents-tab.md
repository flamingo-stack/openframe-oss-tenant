A React component that displays information about management agents installed on devices, showing their connection status, versions, and tool associations in an organized grid layout.

## Key Components

**AgentsTab** - Main component that renders a grid of InfoCards displaying agent information
- `agentTypeToToolType` - Mapping object that converts agent types to standardized tool types
- `combinedAgents` - Merged data structure combining installed agents with tool connections
- Grid layout with responsive columns (1/2/3 columns based on screen size)
- Tooltip integration for contextual help information

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

const device: Device = {
  id: 'device-123',
  installedAgents: [
    { agentType: 'tacticalrmm-agent', version: '1.2.3' },
    { agentType: 'osqueryd', version: '4.5.6' }
  ],
  toolConnections: [
    { toolType: 'TACTICAL_RMM', agentToolId: 'agent-456' }
  ]
}

export function DevicePage() {
  return (
    <div>
      <AgentsTab device={device} />
    </div>
  )
}
```

The component intelligently merges installed agents with tool connections, prioritizes agents with IDs, and provides helpful tooltips explaining each agent's purpose. When no agents are found, it displays an informative empty state.
