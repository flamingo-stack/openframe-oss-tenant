A React component that displays management agents installed on a device, combining data from installed agents and tool connections to show comprehensive agent status information.

## Key Components

- **AgentsTab** - Main component that renders agent information in a responsive grid layout
- **agentTypeToToolType** - Mapping object that converts agent types to standardized tool types
- **combinedAgents** - Logic that merges installed agents with tool connections for complete view
- **InfoCard** with **ToolBadge** - UI components for displaying agent details with visual indicators

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../types/device.types'

// Device with installed agents and tool connections
const device: Device = {
  id: 'device-123',
  installedAgents: [
    { agentType: 'tacticalrmm-agent', version: '2.1.0' }
  ],
  toolConnections: [
    { toolType: 'TACTICAL_RMM', agentToolId: 'agent-456' }
  ]
}

function DeviceDetails({ device }: { device: Device }) {
  return (
    <div>
      <h2>Device Management</h2>
      <AgentsTab device={device} />
    </div>
  )
}
```

The component intelligently combines installed agent data with tool connections, sorts agents by connection status, and provides tooltips explaining agent functionality. When no agents are found, it displays an informative empty state.
