A React component that displays management agents installed on a device in a grid layout, showing agent information and connection status for various MSP tools.

## Key Components

**Main Export:**
- `AgentsTab` - Primary component that renders installed agents with tool badges and connection details

**Key Features:**
- `agentTypeToToolType` - Maps agent types to standardized tool types (Fleet MDM, Tactical RMM, MeshCentral, etc.)
- Agent-connection correlation logic that combines installed agents with tool connections
- Responsive grid layout with InfoCard components for each agent
- Tooltip integration for contextual help information

**Props Interface:**
- `AgentsTabProps` - Expects a `device` object containing `toolConnections` and `installedAgents` arrays

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'

// Device with agents and connections
const deviceData = {
  toolConnections: [
    { toolType: 'TACTICAL_RMM', agentToolId: 'agent-123' }
  ],
  installedAgents: [
    { agentType: 'tacticalrmm-agent', version: '2.1.0' }
  ]
}

// Render agents tab
function DevicePage() {
  return (
    <div>
      <AgentsTab device={deviceData} />
    </div>
  )
}
```

The component automatically correlates installed agents with their corresponding tool connections, displays agent versions and IDs, and shows appropriate messaging when no agents are found. Each agent card includes a tool badge and info tooltip for user guidance.
