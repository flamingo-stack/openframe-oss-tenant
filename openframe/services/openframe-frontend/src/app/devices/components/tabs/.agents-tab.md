A React component that displays and manages agent information for devices in the OpenFrame device management interface. It combines installed agent data with tool connection information to provide a comprehensive view of device management capabilities.

## Key Components

- **AgentsTab** - Main component that renders agent information in a grid layout
- **agentTypeToToolType** - Mapping object that converts agent types to standardized tool types
- **combinedAgents** - Merged data structure combining installed agents with tool connections
- **InfoCard** - UI component for displaying agent details with badges and tooltips
- **ToolBadge** - Visual indicator for different tool types

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../types/device.types'

function DeviceDetailsPage({ device }: { device: Device }) {
  return (
    <div className="device-tabs">
      <AgentsTab device={device} />
    </div>
  )
}

// Example device data structure
const exampleDevice: Device = {
  id: 'device-123',
  installedAgents: [
    { agentType: 'tactical-rmm-agent', version: '2.1.0' }
  ],
  toolConnections: [
    { toolType: 'TACTICAL_RMM', agentToolId: 'agent-456' }
  ]
}
```

The component intelligently merges agent installation data with tool connection information, sorts agents by connection status, and displays them in responsive cards with appropriate badges and tooltips. It handles cases where agents are installed but not connected, or vice versa.
