A React component that displays management agents installed on a device, showing their connection status, versions, and associated tool information in a responsive card grid layout.

## Key Components

- **AgentsTab**: Main component that renders agent information cards
- **agentTypeToToolType**: Mapping object that converts agent types to standardized tool types
- **combinedAgents**: Merged data structure combining installed agents with tool connections
- **InfoCard**: Card component displaying agent details with badges and tooltips
- **ToolBadge**: Visual indicator for different agent/tool types

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../types/device.types'

function DeviceDetailsPage({ device }: { device: Device }) {
  return (
    <div>
      <h1>Device: {device.name}</h1>
      <AgentsTab device={device} />
    </div>
  )
}

// Example device data structure
const sampleDevice: Device = {
  id: 'device-123',
  name: 'Office Desktop',
  installedAgents: [
    {
      agentType: 'tacticalrmm-agent',
      version: '2.4.1'
    }
  ],
  toolConnections: [
    {
      toolType: 'TACTICAL_RMM',
      agentToolId: 'agent-456'
    }
  ]
}
```

The component automatically combines installed agent data with tool connection information, sorts agents by connection status, and displays them in a responsive grid. Each agent card shows its tool badge, version, connection ID, and includes helpful tooltips explaining the agent's purpose.
