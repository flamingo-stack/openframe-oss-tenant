A React component that displays device agents and their tool connections in a grid layout with interactive tooltips and status badges.

## Key Components

- **AgentsTab**: Main component that renders installed agents and tool connections for a device
- **agentTypeToToolType**: Mapping object that converts agent types to standardized tool types
- **combinedAgents**: Merged data structure combining installed agents with tool connections
- **InfoCard**: Display component for agent details with copyable IDs and version information
- **ToolBadge**: Visual indicator showing the type of management tool
- **Tooltip components**: Interactive help information for each agent

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../types/device.types'

// Example device with agents and tool connections
const device: Device = {
  id: 'device-123',
  installedAgents: [
    { agentType: 'tacticalrmm-agent', version: '1.2.3' }
  ],
  toolConnections: [
    { toolType: 'TACTICAL_RMM', agentToolId: 'agent-456' }
  ]
}

function DeviceDetailsPage() {
  return (
    <div className="device-details">
      <AgentsTab device={device} />
    </div>
  )
}
```

The component automatically merges installed agents with their corresponding tool connections, displays them in a responsive grid, and shows tooltips explaining each agent's purpose. Agents with tool IDs are prioritized in the display order.
