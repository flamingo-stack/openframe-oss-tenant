A React component that displays installed management agents and tool connections for a specific device in a responsive grid layout with tooltips and status information.

## Key Components

- **`AgentsTab`** - Main component that renders device agents and connections
- **`agentTypeToToolType`** - Mapping object that converts agent types to standardized tool types
- **Agent merging logic** - Combines installed agents with tool connections to show complete status
- **Responsive grid layout** - Uses CSS Grid with breakpoints for different screen sizes
- **Status indicators** - Shows connection status, agent IDs, and version information

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

function DeviceDetailsPage({ device }: { device: Device }) {
  return (
    <div className="container">
      <h1>Device: {device.name}</h1>
      
      {/* Display agents tab for the device */}
      <AgentsTab device={device} />
    </div>
  )
}

// Example device data structure
const exampleDevice: Device = {
  id: '123',
  name: 'Workstation-01',
  installedAgents: [
    { agentType: 'tactical-rmm-agent', version: '1.2.3' }
  ],
  toolConnections: [
    { toolType: 'TACTICAL_RMM', agentToolId: 'agent-456' }
  ]
}
```

The component handles edge cases like missing agents, combines installation status with connection data, and provides helpful tooltips explaining each agent's purpose and status.
