A React component that displays installed management agents and tool connections for a specific device in a grid layout with interactive cards and tooltips.

## Key Components

- **AgentsTab**: Main component that renders agent information in a responsive grid
- **agentTypeToToolType**: Mapping object that converts agent types to standardized tool types
- **combinedAgents**: Processed array combining installed agents with tool connections
- **InfoCard/ToolBadge**: UI components for displaying agent details and tool type indicators
- **Tooltip system**: Provides contextual help information for agents and empty states

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

const device: Device = {
  toolConnections: [
    { toolType: 'TACTICAL_RMM', agentToolId: 'trm-123' }
  ],
  installedAgents: [
    { agentType: 'tacticalrmm-agent', version: '1.2.3' }
  ]
}

function DeviceDetails() {
  return (
    <div>
      <AgentsTab device={device} />
    </div>
  )
}
```

The component intelligently merges installed agent data with tool connections, prioritizes agents with IDs, and handles edge cases like missing agents or connections. It displays each agent as a card with tool badge, version info, and agent ID when available, providing tooltips for additional context about agent functionality and status.
