A React component that displays a device's installed management agents and their connection status in a responsive card grid layout.

## Key Components

- **AgentsTab**: Main component that renders agent information cards
- **agentTypeToToolType**: Mapping object that converts agent types to standardized tool types
- **combinedAgents**: Merged data structure combining installed agents with tool connections
- Responsive grid layout with agent cards showing ID, version, and connection status

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

function DeviceDetails({ device }: { device: Device }) {
  return (
    <div>
      <h2>Device Management</h2>
      <AgentsTab device={device} />
    </div>
  )
}

// Example device data structure
const deviceWithAgents: Device = {
  id: "device-123",
  toolConnections: [
    {
      toolType: "TACTICAL_RMM",
      agentToolId: "agent-456"
    }
  ],
  installedAgents: [
    {
      agentType: "tacticalrmm-agent",
      version: "2.1.0"
    }
  ]
}
```

The component automatically handles cases where agents are installed but not connected, or where connections exist without local agent installations. It provides tooltips for additional context and sorts agents to prioritize those with active connections.
