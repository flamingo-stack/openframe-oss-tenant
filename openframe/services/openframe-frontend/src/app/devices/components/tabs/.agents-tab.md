A React component that displays device management agents in a responsive grid layout with connection status and version information.

## Key Components

- **AgentsTab** - Main component that renders agent cards with tool badges and connection details
- **agentTypeToToolType** - Mapping object that converts agent types to standardized tool types
- **combinedAgents** - Merged data structure combining installed agents with tool connections
- **InfoCard** - Card component for displaying agent information with tooltips

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

const device: Device = {
  id: 'device-123',
  installedAgents: [
    {
      agentType: 'tacticalrmm-agent',
      version: '1.0.0'
    }
  ],
  toolConnections: [
    {
      toolType: 'TACTICAL_RMM',
      agentToolId: 'agent-456'
    }
  ]
}

function DeviceDetails() {
  return (
    <div>
      <AgentsTab device={device} />
    </div>
  )
}
```

The component automatically merges installed agent data with tool connections, displays agents with connection IDs first, and shows helpful tooltips explaining agent status. When no agents are found, it displays an informational message with guidance about agent installation.
