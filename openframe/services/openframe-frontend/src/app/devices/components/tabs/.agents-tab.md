A React component that displays management agents installed on a device, combining data from tool connections and installed agents to show comprehensive agent information.

## Key Components

- **AgentsTab**: Main component that renders a grid of agent cards with tool badges, version info, and connection status
- **agentTypeToToolType**: Mapping object that converts agent types to standardized tool types for consistent display
- **combinedAgents**: Merged data structure combining installed agents with their corresponding tool connections

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

const device: Device = {
  id: "device-123",
  toolConnections: [
    {
      toolType: "TACTICAL_RMM",
      agentToolId: "agent-456"
    }
  ],
  installedAgents: [
    {
      agentType: "tacticalrmm-agent",
      version: "1.2.3"
    }
  ]
}

function DeviceDetails() {
  return (
    <div>
      <h2>Device Management</h2>
      <AgentsTab device={device} />
    </div>
  )
}
```

The component automatically merges agent installation data with tool connection information, displays appropriate tool badges, and shows helpful tooltips explaining each agent's purpose. When no agents are found, it displays an informative empty state with guidance about agent functionality.
