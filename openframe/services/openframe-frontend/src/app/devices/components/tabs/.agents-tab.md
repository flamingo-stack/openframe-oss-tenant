A React component that displays management agents installed on devices in a responsive grid layout with detailed connection information.

## Key Components

- **AgentsTab**: Main component that renders device agents in an organized card layout
- **agentTypeToToolType**: Mapping object that converts agent types to standardized tool types
- **InfoCard**: Displays agent information including ID, version, and connection status
- **ToolBadge**: Shows visual badges for different tool types
- **Tooltip**: Provides contextual information about agents and their statuses

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

// Example device with mixed agent data
const device: Device = {
  id: 'device-123',
  toolConnections: [
    { toolType: 'TACTICAL_RMM', agentToolId: 'agent-456' }
  ],
  installedAgents: [
    { agentType: 'tacticalrmm-agent', version: '2.1.0' }
  ]
}

// Render agents tab
function DeviceDetails() {
  return (
    <div>
      <h2>Device Management</h2>
      <AgentsTab device={device} />
    </div>
  )
}
```

The component intelligently combines installed agents with tool connections, prioritizes agents with connection IDs, and handles edge cases where agents exist without connections or vice versa. When no agents are found, it displays a helpful empty state with explanatory tooltips.
