React component that displays installed management agents and tool connections for a device in a grid layout with detailed information cards.

## Key Components

- **AgentsTab**: Main component that renders a grid of agent cards showing version info, connection status, and tool IDs
- **agentTypeToToolType**: Mapping object that converts agent types to standardized tool types
- **combinedAgents**: Merged data structure combining installed agents with tool connections
- **connectionMap**: Map for efficient lookup of tool connections by type

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

const device: Device = {
  id: 'device-123',
  toolConnections: [
    {
      toolType: 'TACTICAL_RMM',
      agentToolId: 'agent-456'
    }
  ],
  installedAgents: [
    {
      agentType: 'tacticalrmm-agent',
      version: '2.1.0'
    }
  ]
}

function DevicePage() {
  return (
    <div>
      <AgentsTab device={device} />
    </div>
  )
}
```

The component creates information cards for each agent, displaying tool badges, tooltips with context, and agent details like version and ID. It handles cases where agents are installed but not connected, or connected but not detected as installed, providing a comprehensive view of device management capabilities.
