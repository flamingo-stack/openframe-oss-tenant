A React component that displays device management agents in a tabbed interface, combining installed agents with tool connections to show comprehensive agent status and information.

## Key Components

- **`AgentsTab`** - Main component that renders agent information in a responsive grid layout
- **`agentTypeToToolType`** - Mapping object that converts agent types to standardized tool types
- **Agent combination logic** - Merges installed agents with tool connections to provide complete agent status
- **Responsive grid** - Displays agents as InfoCards with ToolBadges and tooltips

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

// Device data with agents and tool connections
const device: Device = {
  id: 'device-123',
  installedAgents: [
    { agentType: 'tactical-rmm', version: '1.2.3' }
  ],
  toolConnections: [
    { toolType: 'TACTICAL_RMM', agentToolId: 'agent-456' }
  ]
}

function DeviceDetails() {
  return (
    <div>
      <AgentsTab device={device} />
    </div>
  )
}
```

The component handles various states including devices with no agents, agents without connections, and connections without installed agents. It sorts agents to prioritize those with agent tool IDs and provides informative tooltips for each agent card.
