A React component that displays management agents and tool connections for a device in a grid layout, combining installed agent information with connection data from various management platforms.

## Key Components

- **AgentsTab**: Main component that renders device agents in a responsive grid
- **agentTypeToToolType**: Mapping object that converts agent types to standardized tool types
- **combinedAgents**: Merged data structure combining installed agents with tool connections
- **TooltipProvider/Tooltip**: Provides contextual information about each agent
- **InfoCard**: Displays agent details in a card format
- **ToolBadge**: Shows visual indicators for different tool types

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

const deviceData: Device = {
  id: 'device-123',
  installedAgents: [
    { agentType: 'tacticalrmm-agent', version: '1.2.3' }
  ],
  toolConnections: [
    { toolType: 'TACTICAL_RMM', agentToolId: 'agent-456' }
  ]
}

function DeviceDetails() {
  return (
    <div>
      <AgentsTab device={deviceData} />
    </div>
  )
}
```

The component automatically merges installed agent data with tool connections, displays agents with connections first, and provides helpful tooltips explaining each agent's purpose and status.
