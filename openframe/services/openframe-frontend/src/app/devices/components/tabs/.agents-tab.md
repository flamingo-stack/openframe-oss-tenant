A React component that displays device management agents in a grid layout, showing installed agents and their tool connections with tooltips and visual indicators.

## Key Components

- **AgentsTab** - Main component that renders device agents in an organized grid
- **agentTypeToToolType** - Mapping object that converts agent types to standardized tool types
- **combinedAgents** - Merged data structure combining installed agents with tool connections
- **ToolBadge** - Visual indicator for each agent type
- **InfoCard** - Card component displaying agent details (ID, version)
- **Tooltip system** - Contextual help for each agent card

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

// Use in a device detail view
function DeviceDetails({ device }: { device: Device }) {
  return (
    <div className="device-tabs">
      <AgentsTab device={device} />
    </div>
  )
}

// Example device data structure
const exampleDevice: Device = {
  id: 'device-123',
  installedAgents: [
    { agentType: 'tacticalrmm-agent', version: '1.2.3' }
  ],
  toolConnections: [
    { toolType: 'TACTICAL_RMM', agentToolId: 'agent-456' }
  ]
}
```

The component intelligently merges installed agents with tool connections, sorts them by connection status, and provides responsive grid layouts with helpful tooltips explaining each agent's purpose and connection state.
