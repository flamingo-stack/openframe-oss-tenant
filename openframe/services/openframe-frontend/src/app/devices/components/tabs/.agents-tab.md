A React component that displays management agents and tool connections for a specific device in a responsive grid layout with detailed tooltips and status information.

## Key Components

- **AgentsTab** - Main component that renders device agents and tool connections
- **agentTypeToToolType** - Mapping object for converting agent types to standardized tool types
- **combinedAgents** - Processed array merging installed agents with tool connections
- **Tooltip integration** - Provides contextual help for each agent card

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

const device: Device = {
  id: 'device-123',
  installedAgents: [
    { agentType: 'tacticalrmm-agent', version: '1.2.3' }
  ],
  toolConnections: [
    { toolType: 'TACTICAL_RMM', agentToolId: 'agent-456' }
  ]
}

function DevicePage() {
  return (
    <div>
      <AgentsTab device={device} />
    </div>
  )
}
```

The component creates InfoCards for each agent, displaying ToolBadges, version information, and agent IDs when available. It handles both installed agents and tool connections, merging and sorting them to prioritize connected agents. When no agents are found, it shows a helpful empty state with guidance about management capabilities.
