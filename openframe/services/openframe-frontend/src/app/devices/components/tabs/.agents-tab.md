A React component that displays management agents installed on a device, showing their versions, IDs, and connection status in a responsive grid layout.

## Key Components

- **AgentsTab** - Main component that renders device agents in InfoCard grid
- **agentTypeToToolType** - Mapping object for converting agent types to tool types
- **combinedAgents** - Merged data from installed agents and tool connections
- **ToolBadge** - Visual indicator for agent type
- **InfoCard** - Container displaying agent information with copyable IDs

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'

// Device with installed agents and tool connections
const device = {
  installedAgents: [
    { agentType: 'tacticalrmm-agent', version: '1.4.15' },
    { agentType: 'meshcentral-agent', version: '0.9.95' }
  ],
  toolConnections: [
    { toolType: 'TACTICAL_RMM', agentToolId: 'agent-123' },
    { toolType: 'MESHCENTRAL', agentToolId: 'node-456' }
  ]
}

// Render agents tab
<AgentsTab device={device} />
```

The component intelligently merges installed agent data with tool connection information, displays agents with IDs first, and shows helpful tooltips explaining each agent's purpose. When no agents are found, it displays an informative placeholder message.
