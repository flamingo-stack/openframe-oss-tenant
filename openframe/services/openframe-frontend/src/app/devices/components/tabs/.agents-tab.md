A React component that displays management agents installed on devices, combining both installed agent data and tool connections into a unified view with status information.

## Key Components

- **AgentsTab** - Main component that renders a grid of agent cards
- **agentTypeToToolType** - Mapping object that converts agent types to standardized tool types
- **combinedAgents** - Merged data structure combining installed agents with their corresponding tool connections
- **InfoCard** - Used to display agent details with copyable IDs and version information
- **ToolBadge** - Visual indicator showing the agent/tool type
- **Tooltip** - Provides contextual help information for each agent

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'

// Example device with agents and tool connections
const device = {
  id: 'device-123',
  installedAgents: [
    { agentType: 'tacticalrmm-agent', version: '1.0.0' }
  ],
  toolConnections: [
    { toolType: 'TACTICAL_RMM', agentToolId: 'agent-456' }
  ]
}

function DeviceView() {
  return (
    <div>
      <AgentsTab device={device} />
    </div>
  )
}
```

The component handles merging installed agent data with tool connections, displays appropriate badges and tooltips, and gracefully handles cases where no agents are found. Each agent card shows its ID (if available), version, and connection status.
