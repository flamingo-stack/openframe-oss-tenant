A React component that displays management agents installed on a device in a grid layout with tool badges and connection status information.

## Key Components

- **AgentsTab**: Main functional component that renders agent information cards
- **agentTypeToToolType**: Mapping object that converts agent type strings to standardized tool types
- **combinedAgents**: Merged data structure combining installed agents with their tool connections
- **connectionMap**: Map for efficient lookup of tool connections by type

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

function DeviceDetailsPage({ device }: { device: Device }) {
  return (
    <div>
      <h2>Device Management</h2>
      <AgentsTab device={device} />
    </div>
  )
}
```

The component processes device data to:
- Map installed agents to their corresponding tool connections
- Display agent IDs, versions, and connection status
- Show tool badges for visual identification (Fleet MDM, Tactical RMM, MeshCentral, etc.)
- Provide tooltips explaining agent functionality
- Handle empty states when no agents are found
- Sort agents to prioritize those with active tool connections

Each agent is displayed as an InfoCard with a ToolBadge overlay and contextual tooltip information about the management platform.
