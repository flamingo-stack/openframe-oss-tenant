A React component that displays management agents installed on a device in a responsive grid layout with tooltips and connection status indicators.

## Key Components

- **AgentsTab** - Main component that renders agent information cards
- **agentTypeToToolType** - Mapping object that converts agent types to standardized tool types
- **combinedAgents** - Merged data structure combining installed agents with tool connections
- **connectionMap** - Map for efficient lookup of tool connections by type

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

function DeviceManagement() {
  const device: Device = {
    id: 'device-123',
    installedAgents: [
      { agentType: 'tacticalrmm-agent', version: '2.1.0' }
    ],
    toolConnections: [
      { toolType: 'TACTICAL_RMM', agentToolId: 'agent-456' }
    ]
  }

  return (
    <div>
      <h2>Device Agents</h2>
      <AgentsTab device={device} />
    </div>
  )
}
```

The component intelligently merges installed agent data with tool connection information, displaying agents in responsive cards with badges, tooltips, and connection status. Agents with active connections are prioritized in the display order, and the component gracefully handles cases where no agents are installed.
