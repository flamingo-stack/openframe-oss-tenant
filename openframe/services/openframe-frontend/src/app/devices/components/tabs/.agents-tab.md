A React component that displays management agents installed on a device in a tabbed interface, combining data from tool connections and installed agent information.

## Key Components

- **AgentsTab** - Main component that renders agent information in a grid layout
- **agentTypeToToolType** - Mapping object that converts agent types to standardized tool types
- **combinedAgents** - Merged data structure combining installed agents with tool connections
- **InfoCard components** - Display individual agent details with badges and tooltips
- **TooltipProvider/Tooltip** - Contextual help information for each agent

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

const device: Device = {
  id: "device-123",
  toolConnections: [
    { toolType: "TACTICAL_RMM", agentToolId: "agent-456" }
  ],
  installedAgents: [
    { agentType: "tacticalrmm-agent", version: "2.1.0" }
  ]
}

function DeviceDetailsPage() {
  return (
    <div>
      <AgentsTab device={device} />
    </div>
  )
}
```

The component handles empty states gracefully and sorts agents to prioritize those with active tool connections. Each agent card displays version information, unique IDs, and connection status with appropriate visual indicators through tool badges and informative tooltips.
