React component that renders a tab interface displaying management agents and tool connections for a specific device, combining installed agent data with connection status information.

## Key Components

- **AgentsTab**: Main component that accepts a `Device` prop and renders agent information
- **agentTypeToToolType**: Mapping object that converts agent types to standardized tool types
- **combinedAgents**: Merged data structure combining installed agents with tool connections
- **InfoCard**: Display component for agent details with tool badges and tooltips

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

const device: Device = {
  id: 'device-123',
  toolConnections: [
    { toolType: 'TACTICAL_RMM', agentToolId: 'agent-456' }
  ],
  installedAgents: [
    { agentType: 'tacticalrmm-agent', version: '1.2.3' }
  ]
}

function DeviceDetails() {
  return (
    <div>
      <AgentsTab device={device} />
    </div>
  )
}
```

The component intelligently merges installed agent data with tool connection information, displays agents with connection IDs first, and provides helpful tooltips explaining agent status. It gracefully handles cases where no agents are found by showing an informative empty state.
