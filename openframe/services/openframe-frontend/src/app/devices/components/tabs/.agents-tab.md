A React component that displays and manages installed agents and tool connections for a specific device, combining data from both local agent installations and remote tool connections.

## Key Components

- **AgentsTab**: Main component that renders agent information in a grid layout
- **agentTypeToToolType**: Mapping object that converts agent types to standardized tool types
- **combinedAgents**: Merged data structure combining installed agents with tool connections
- **InfoCard**: Display component for agent details with badges and tooltips
- **ToolBadge**: Visual indicator showing the agent/tool type

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'

// Device data with agents and connections
const deviceData = {
  installedAgents: [
    {
      agentType: 'tacticalrmm-agent',
      version: '2.4.0'
    }
  ],
  toolConnections: [
    {
      toolType: 'TACTICAL_RMM',
      agentToolId: 'agent-123'
    }
  ]
}

// Render the agents tab
<AgentsTab device={deviceData} />
```

The component intelligently merges installed agent data with tool connection information, displays agents in a responsive grid, and provides helpful tooltips explaining each agent's purpose. Agents with connection IDs are prioritized in the display order, and the component gracefully handles cases where no agents are present.
