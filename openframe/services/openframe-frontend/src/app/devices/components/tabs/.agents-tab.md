A React component that displays installed management agents and their tool connections for a specific device in a responsive grid layout with detailed tooltips.

## Key Components

- **AgentsTab** - Main component that renders device agents and tool connections
- **agentTypeToToolType** - Mapping object that converts agent types to standardized tool types
- **combinedAgents** - Processed array merging installed agents with tool connections
- **TooltipProvider/Tooltip** - UI components providing contextual help information
- **InfoCard/ToolBadge** - Display components for agent details and visual identification

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

const deviceData: Device = {
  id: 'device-123',
  toolConnections: [
    { toolType: 'TACTICAL_RMM', agentToolId: 'trm-456' }
  ],
  installedAgents: [
    { agentType: 'tacticalrmm-agent', version: '1.2.3' }
  ]
}

function DevicePage() {
  return (
    <div>
      <AgentsTab device={deviceData} />
    </div>
  )
}
```

The component intelligently merges installed agent data with tool connections, prioritizes agents with IDs, and provides helpful tooltips explaining each agent's purpose. It handles empty states gracefully and displays agents in a responsive grid with tool badges for easy identification.
