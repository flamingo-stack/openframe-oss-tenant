A React component that displays a grid of management agents installed on devices, showing their connection status, versions, and tool types with visual badges and tooltips.

## Key Components

- **AgentsTab**: Main component that renders a grid of device management agents
- **agentTypeToToolType**: Mapping object that converts agent types to standardized tool types
- **combinedAgents**: Merged array of installed agents and tool connections with unified data structure
- **InfoCard**: UI component displaying agent information in card format
- **ToolBadge**: Visual badge component showing the tool type
- **Tooltip components**: Interactive help tooltips explaining agent functionality

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

const device: Device = {
  id: 'device-123',
  installedAgents: [
    {
      agentType: 'tacticalrmm-agent',
      version: '2.1.0'
    }
  ],
  toolConnections: [
    {
      toolType: 'TACTICAL_RMM',
      agentToolId: 'agent-456'
    }
  ]
}

function DeviceDetails() {
  return (
    <div>
      <h2>Device Agents</h2>
      <AgentsTab device={device} />
    </div>
  )
}
```

The component intelligently combines installed agent data with tool connection information, prioritizes agents with connection IDs, and provides comprehensive tooltips explaining each agent's purpose and status.
