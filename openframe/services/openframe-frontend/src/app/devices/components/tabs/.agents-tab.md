A React component that displays management agents and tool connections for a specific device in a grid layout with tooltips and connection status.

## Key Components

- **AgentsTab**: Main component that combines installed agents with tool connections
- **agentTypeToToolType**: Mapping object that translates agent types to standardized tool types
- **InfoCard**: Displays agent information including ID and version
- **ToolBadge**: Shows visual badge for each tool type
- **Tooltip system**: Provides contextual help information

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

const device: Device = {
  id: 'device-123',
  installedAgents: [
    {
      agentType: 'tacticalrmm-agent',
      version: '1.2.3'
    }
  ],
  toolConnections: [
    {
      toolType: 'TACTICAL_RMM',
      agentToolId: 'agent-456'
    }
  ]
}

function DeviceManagement() {
  return (
    <div>
      <AgentsTab device={device} />
    </div>
  )
}
```

The component merges installed agents with their corresponding tool connections, displaying them in a responsive grid. Agents with active connections are prioritized in the display order, and each card shows relevant metadata like agent ID and version with helpful tooltips explaining the connection status.
