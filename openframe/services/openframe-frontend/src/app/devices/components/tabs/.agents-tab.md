A React component that displays management agents installed on a device, showing their connection status, versions, and tool associations in a responsive grid layout.

## Key Components

- **AgentsTab** - Main component that renders agent information cards
- **agentTypeToToolType** - Mapping object that converts agent types to standardized tool types
- **combinedAgents** - Merged data structure combining installed agents with tool connections
- **InfoCard** - Individual agent display cards with tool badges and tooltips

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

const deviceData: Device = {
  id: 'device-123',
  installedAgents: [
    { agentType: 'tactical-rmm-agent', version: '1.2.3' }
  ],
  toolConnections: [
    { toolType: 'TACTICAL_RMM', agentToolId: 'agent-456' }
  ]
}

function DevicePage() {
  return (
    <div>
      <AgentsTab device={deviceData} />
    </div>
  )
}
```

The component intelligently merges installed agent data with tool connection information, prioritizing agents with active connections. It handles missing data gracefully and provides helpful tooltips explaining each agent's purpose and status. The responsive grid layout adapts from single column on mobile to three columns on larger screens.
