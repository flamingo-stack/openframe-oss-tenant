This React component renders a tabbed interface displaying installed management agents and their connection status for a specific device in the OpenFrame platform.

## Key Components

- **AgentsTab**: Main component that displays device agents in a responsive grid layout
- **agentTypeToToolType**: Mapping object that converts agent types to standardized tool types
- **combinedAgents**: Merged data structure combining installed agents with tool connections
- **InfoCard**: UI component for displaying agent information with badges and tooltips

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import { Device } from '../../types/device.types'

const device: Device = {
  id: 'device-123',
  installedAgents: [
    { agentType: 'fleetmdm-agent', version: '1.2.3' }
  ],
  toolConnections: [
    { toolType: 'FLEET_MDM', agentToolId: 'fleet-123' }
  ]
}

function DevicePage() {
  return <AgentsTab device={device} />
}
```

The component combines installed agents with tool connections, prioritizes agents with connection IDs, and displays them in responsive grid cards with tooltips. Each card shows the agent's tool badge, version information, and connection status. When no agents are found, it displays a helpful message explaining the purpose of management agents.
