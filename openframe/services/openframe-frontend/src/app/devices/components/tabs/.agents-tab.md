A React component that displays installed management agents and their tool connections for a device in a responsive grid layout with tooltips.

## Key Components

**AgentsTab** - Main component that:
- Takes a `device` prop containing agent and tool connection data
- Maps agent types to normalized tool types using `agentTypeToToolType` mapping
- Combines installed agents with tool connections to show complete agent status
- Renders agents as `InfoCard` components with `ToolBadge` indicators
- Shows helpful tooltips explaining each agent's purpose and status

**Key Features:**
- Safe array handling with fallbacks for missing data
- Agent type normalization (e.g., 'fleetmdm-agent' → 'FLEET_MDM')
- Connection status tracking between installed agents and tool connections
- Responsive grid layout (1/2/3 columns based on screen size)
- Copyable agent IDs when available

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'

const device = {
  installedAgents: [
    { agentType: 'fleetmdm-agent', version: '1.0.0' },
    { agentType: 'tacticalrmm-agent', version: '2.1.0' }
  ],
  toolConnections: [
    { toolType: 'FLEET_MDM', agentToolId: 'fleet-123' },
    { toolType: 'TACTICAL_RMM', agentToolId: 'tactical-456' }
  ]
}

// Displays agents with their versions, IDs, and connection status
<AgentsTab device={device} />
```

The component handles cases where agents are installed but not connected, connected but not installed locally, or completely missing agents with appropriate messaging and tooltips.
