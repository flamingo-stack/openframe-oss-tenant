A React component that displays management agents installed on a device, showing their connection status, versions, and tool identifiers in a grid layout.

## Key Components

- **AgentsTab**: Main component that renders device agents with their connection status
- **agentTypeToToolType**: Mapping object that converts agent types to standardized tool types
- **combinedAgents**: Merged data structure combining installed agents with tool connections
- **InfoCard**: Display component for agent information with badges and tooltips

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

// Example device with agents
const device: Device = {
  id: 'device-123',
  toolConnections: [
    { 
      toolType: 'TACTICAL_RMM', 
      agentToolId: 'agent-456' 
    }
  ],
  installedAgents: [
    { 
      agentType: 'tacticalrmm-agent', 
      version: '1.2.3' 
    }
  ]
}

function DeviceDetails() {
  return (
    <div>
      <AgentsTab device={device} />
    </div>
  )
}
```

The component intelligently merges installed agents with their corresponding tool connections, displays agents with active connections first, and provides informative tooltips explaining each agent's purpose. When no agents are found, it shows a helpful empty state message.
