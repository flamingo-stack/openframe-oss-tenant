A React component that displays management agents installed on devices in a grid layout with connection status and tooltips.

## Key Components

- **AgentsTab** - Main component that renders installed agents and tool connections
- **agentTypeToToolType** - Mapping object that converts agent types to standardized tool types
- **combinedAgents** - Merged data structure combining installed agents with their tool connections
- **InfoCard** - UI component for displaying agent information in cards
- **ToolBadge** - Visual indicator showing the agent/tool type
- **Tooltip** - Contextual help information for each agent

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from './types/device.types'

const device: Device = {
  id: 'device-123',
  name: 'Workstation-01',
  installedAgents: [
    {
      agentType: 'tacticalrmm-agent',
      version: '2.1.0'
    }
  ],
  toolConnections: [
    {
      toolType: 'TACTICAL_RMM',
      agentToolId: 'agent-456'
    }
  ]
}

export function DeviceDetails() {
  return (
    <div>
      <AgentsTab device={device} />
    </div>
  )
}
```

The component handles mapping between agent types and tool types, displays connection status, and provides helpful tooltips explaining each agent's purpose. It gracefully handles empty states when no agents are found.
