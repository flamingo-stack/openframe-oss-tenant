A React component that displays device management agents in a responsive grid layout, showing installed agents and tool connections with their metadata.

## Key Components

- **AgentsTab**: Main component that renders agent information cards
- **agentTypeToToolType**: Mapping object that converts agent types to standardized tool types
- **combinedAgents**: Merged data structure combining installed agents with tool connections
- **InfoCard**: Display component for agent details with badges and tooltips
- **ToolBadge**: Visual indicator for different tool types

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

// Example device with agents and tool connections
const device: Device = {
  id: 'device-123',
  toolConnections: [
    { toolType: 'TACTICAL_RMM', agentToolId: 'agent-456' }
  ],
  installedAgents: [
    { agentType: 'tacticalrmm-agent', version: '1.2.3' }
  ]
}

function DeviceDetails() {
  return (
    <div>
      <h2>Device Agents</h2>
      <AgentsTab device={device} />
    </div>
  )
}
```

The component automatically merges installed agent data with tool connection information, displays appropriate badges and tooltips, and handles cases where no agents are found. Each agent card shows relevant metadata like version numbers and unique identifiers when available.
