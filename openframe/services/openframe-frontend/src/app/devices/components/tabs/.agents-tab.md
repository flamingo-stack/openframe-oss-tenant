A React component that displays installed management agents and tool connections for a device in a grid layout with interactive tooltips.

## Key Components

- **AgentsTab** - Main component that renders device agents in a responsive grid
- **agentTypeToToolType** - Mapping object that converts agent types to standardized tool types
- **combinedAgents** - Merged data structure combining installed agents with tool connections
- **connectionMap** - Map for efficient lookup of tool connections by type

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

function DeviceDetails() {
  const device: Device = {
    id: 'device-123',
    toolConnections: [
      { toolType: 'TACTICAL_RMM', agentToolId: 'agent-456' }
    ],
    installedAgents: [
      { agentType: 'tacticalrmm-agent', version: '1.2.3' }
    ]
  }

  return <AgentsTab device={device} />
}
```

The component combines installed agents with tool connections, displays them as info cards with tool badges, and provides tooltips with contextual information. Agents with tool IDs are prioritized in the display order, and a fallback message appears when no agents are detected.
