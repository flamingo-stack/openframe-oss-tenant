This component displays installed management agents and their connections for a specific device in a grid layout with detailed tooltips.

## Key Components

- **AgentsTab**: Main React component that renders agent information cards
- **agentTypeToToolType**: Mapping object that converts agent types to standardized tool types
- **connectionMap**: Map structure for efficiently linking tool connections to installed agents
- **combinedAgents**: Merged data structure combining installed agents with their connection status

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

const device: Device = {
  id: 'device-123',
  installedAgents: [
    {
      agentType: 'tacticalrmm-agent',
      version: '1.2.3'
    }
  ],
  toolConnections: [
    {
      toolType: 'TACTICAL_RMM',
      agentToolId: 'agent-456'
    }
  ]
}

function DeviceDetails() {
  return (
    <div>
      <AgentsTab device={device} />
    </div>
  )
}
```

The component handles three scenarios: devices with both installed agents and connections, devices with only connections (cloud-managed), and devices with no agents. It displays agent badges, versions, IDs, and contextual tooltips explaining each agent's purpose and connection status.
