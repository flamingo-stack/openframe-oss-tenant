A React component that displays management agents installed on a device, combining installed agents with tool connections to show comprehensive agent status and information.

## Key Components

- **AgentsTab** - Main component that renders a grid of agent cards with status information
- **agentTypeToToolType** - Mapping object that converts agent types to standardized tool types
- **combinedAgents** - Merged data structure combining installed agents with tool connections
- **InfoCard** integration with ToolBadge and Tooltip components for rich display

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

function DeviceDetailsPage({ deviceData }: { deviceData: Device }) {
  return (
    <div className="device-tabs">
      <AgentsTab device={deviceData} />
    </div>
  )
}

// Example device data structure
const exampleDevice: Device = {
  toolConnections: [
    { toolType: 'TACTICAL_RMM', agentToolId: 'agent-123' }
  ],
  installedAgents: [
    { agentType: 'tacticalrmm-agent', version: '2.1.0' }
  ]
}
```

The component automatically merges installed agent data with tool connection information, displays agent badges with tooltips, and handles cases where no agents are present. Each agent card shows the tool type badge, connection status, agent ID (if available), and version information in a responsive grid layout.
