A React component that displays installed management agents and their tool connections for a specific device in a responsive grid layout.

## Key Components

- **AgentsTab**: Main component that renders device agent information
- **agentTypeToToolType**: Mapping object converting agent types to standardized tool types
- **combinedAgents**: Merged data structure combining installed agents with tool connections
- **InfoCard**: UI component displaying agent details with badges and tooltips
- **ToolBadge**: Visual indicator for different tool types

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

const device: Device = {
  id: 'device-123',
  installedAgents: [
    { agentType: 'fleetmdm-agent', version: '1.2.3' },
    { agentType: 'tacticalrmm-agent', version: '2.1.0' }
  ],
  toolConnections: [
    { toolType: 'FLEET_MDM', agentToolId: 'fleet-123' },
    { toolType: 'TACTICAL_RMM', agentToolId: 'tactical-456' }
  ]
}

// Render agents tab for device
<AgentsTab device={device} />
```

The component automatically merges installed agents with their corresponding tool connections, displays them in cards with tool badges, and shows appropriate tooltips. When no agents are found, it displays a helpful message explaining the purpose of management agents.
