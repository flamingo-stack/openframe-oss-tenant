A React component that displays management agents installed on a device in a responsive grid layout, showing connection status, versions, and tool integrations.

## Key Components

- **AgentsTab** - Main component that renders agent information in card format
- **agentTypeToToolType** - Mapping object that converts agent types to standardized tool types
- **combinedAgents** - Merged data structure combining installed agents with tool connections
- **TooltipProvider/Tooltip** - Provides contextual help information for each agent card
- **InfoCard** - Displays agent details like ID and version in a structured format
- **ToolBadge** - Visual indicator showing the tool type for each agent

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from './types/device.types'

function DeviceView() {
  const device: Device = {
    id: 'device-123',
    toolConnections: [
      { toolType: 'TACTICAL_RMM', agentToolId: 'agent-456' }
    ],
    installedAgents: [
      { agentType: 'tacticalrmm-agent', version: '1.2.3' }
    ]
  }

  return (
    <div>
      <AgentsTab device={device} />
    </div>
  )
}
```

The component handles empty states gracefully, sorts agents with IDs first, and provides tooltips explaining each agent's purpose and connection status. It supports various agent types including Fleet MDM, Tactical RMM, MeshCentral, and OpenFrame components.
