React component that displays installed management agents on a device, combining agent installation data with tool connection information to show comprehensive agent status.

## Key Components

- **AgentsTab**: Main component that renders agent cards in a responsive grid
- **agentTypeToToolType**: Mapping object that converts agent types to standardized tool types
- **combinedAgents**: Merged data structure combining installed agents with their tool connections
- **ToolBadge**: Visual indicator showing the agent/tool type
- **InfoCard**: Container displaying agent details like ID and version

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

function DeviceDetails({ device }: { device: Device }) {
  return (
    <div>
      <h2>Device Agents</h2>
      <AgentsTab device={device} />
    </div>
  )
}

// Example device data structure
const exampleDevice: Device = {
  toolConnections: [
    { toolType: 'TACTICAL_RMM', agentToolId: 'agent-123' }
  ],
  installedAgents: [
    { agentType: 'tacticalrmm-agent', version: '1.2.3' }
  ]
}
```

The component intelligently merges agent installation data with tool connection information, prioritizes connected agents, and provides helpful tooltips explaining each agent's purpose and status.
