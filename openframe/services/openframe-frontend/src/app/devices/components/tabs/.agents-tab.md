A React component that displays management agents installed on a device with their connection status and metadata in a responsive card grid layout.

## Key Components

- **AgentsTab** - Main component that renders agent information cards
- **agentTypeToToolType** - Mapping object that converts agent types to standardized tool types
- **combinedAgents** - Merged data structure combining installed agents with tool connections
- **InfoCard** - Card component displaying agent details with copyable IDs and version info
- **ToolBadge** - Visual indicator showing the agent/tool type
- **Tooltip** - Contextual help information for each agent card

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

const device: Device = {
  id: 'device-123',
  installedAgents: [
    {
      agentType: 'tacticalrmm-agent',
      version: '1.2.3'
    }
  ],
  toolConnections: [
    {
      toolType: 'TACTICAL_RMM',
      agentToolId: 'agent-456'
    }
  ]
}

function DeviceDetails() {
  return (
    <div>
      <AgentsTab device={device} />
    </div>
  )
}
```

The component handles various scenarios including agents with/without connections, missing data arrays, and provides informative tooltips explaining each agent's purpose and status.
