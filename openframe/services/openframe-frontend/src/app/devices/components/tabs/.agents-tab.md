A React component that displays device management agents in a tabbed interface, combining installed agent data with tool connections to show comprehensive agent status and information.

## Key Components

- **AgentsTab**: Main component that renders agent cards in a responsive grid layout
- **agentTypeToToolType**: Mapping object that converts agent types to standardized tool types
- **combinedAgents**: Merged data structure combining installed agents with tool connections
- **InfoCard**: Displays individual agent information with badges and tooltips
- **ToolBadge**: Shows visual indicators for different agent/tool types

## Usage Example

```typescript
import { AgentsTab } from './components/agents-tab'
import type { Device } from './types/device.types'

function DeviceDetails({ device }: { device: Device }) {
  return (
    <div className="device-tabs">
      <AgentsTab device={device} />
    </div>
  )
}

// Example device data structure
const deviceData: Device = {
  id: "device-123",
  toolConnections: [
    {
      toolType: "TACTICAL_RMM",
      agentToolId: "agent-456"
    }
  ],
  installedAgents: [
    {
      agentType: "tacticalrmm-agent",
      version: "2.4.1"
    }
  ]
}
```

The component automatically merges installed agent data with tool connections, displays agent badges and tooltips, and sorts agents with IDs first for better organization.
