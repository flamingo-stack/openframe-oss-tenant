A React component that displays management agents installed on devices in a responsive grid layout with tool badges and connection status information.

## Key Components

- **AgentsTab** - Main component that renders device agents with their connection status and metadata
- **agentTypeToToolType** - Mapping object that converts agent types to standardized tool types
- **Agent combination logic** - Merges installed agents with tool connections to show complete agent status
- **Responsive grid** - Displays agents as cards in a 1-3 column grid based on screen size

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

// Device with multiple agents
const device: Device = {
  id: 'device-123',
  installedAgents: [
    {
      agentType: 'tacticalrmm-agent',
      version: '1.2.3'
    }
  ],
  toolConnections: [
    {
      toolType: 'TACTICAL_RMM',
      agentToolId: 'agent-456'
    }
  ]
}

// Render agents tab
<AgentsTab device={device} />
```

The component automatically handles:
- Combining installed agents with their connection data
- Displaying appropriate tool badges and tooltips
- Sorting agents with IDs first
- Showing empty state when no agents are found
- Responsive layout across different screen sizes
