A React component that displays management agents and their connection status for a specific device in an organized grid layout.

## Key Components

- **AgentsTab**: Main component that renders installed agents and tool connections
- **agentTypeToToolType**: Mapping object that converts agent types to standardized tool types
- **InfoCard**: Displays agent information with ID, version, and connection status
- **ToolBadge**: Shows visual indicator for the agent/tool type
- **Tooltip**: Provides contextual information about agents and connections

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from '../../types/device.types'

const deviceData: Device = {
  id: 'device-123',
  toolConnections: [
    { toolType: 'TACTICAL_RMM', agentToolId: 'agent-456' }
  ],
  installedAgents: [
    { agentType: 'tacticalrmm-agent', version: '2.1.0' }
  ]
}

export function DeviceDetails() {
  return (
    <div>
      <AgentsTab device={deviceData} />
    </div>
  )
}
```

The component combines installed agents with tool connections, displays them in a responsive grid, and sorts agents with connection IDs first. When no agents are found, it shows an informative empty state with helpful tooltips explaining the purpose of management agents.
