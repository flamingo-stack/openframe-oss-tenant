A React component that displays management agents installed on a device in a responsive grid layout with connection status and version information.

## Key Components

- **AgentsTab**: Main component that renders device agents with tool connections
- **agentTypeToToolType**: Mapping object that converts agent types to standardized tool types
- **combinedAgents**: Merged data structure combining installed agents with tool connections
- **InfoCard/ToolBadge**: UI components for displaying agent information with badges and tooltips

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'

const device = {
  installedAgents: [
    { agentType: 'tactical-rmm-agent', version: '2.1.0' },
    { agentType: 'osqueryd', version: '5.8.2' }
  ],
  toolConnections: [
    { toolType: 'TACTICAL_RMM', agentToolId: 'trm-12345' },
    { toolType: 'OSQUERY', agentToolId: 'osq-67890' }
  ]
}

function DeviceDetails() {
  return (
    <div className="device-tabs">
      <AgentsTab device={device} />
    </div>
  )
}
```

The component automatically merges installed agents with their corresponding tool connections, displays them in a responsive grid, and shows connection status with unique agent IDs. Agents with connections are prioritized in the display order, and a fallback message appears when no agents are found.
