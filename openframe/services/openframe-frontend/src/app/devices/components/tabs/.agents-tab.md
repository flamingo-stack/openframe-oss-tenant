A React component that renders device management agents in a responsive card grid layout, combining installed agents with tool connections to display comprehensive agent status information.

## Key Components

- **AgentsTab** - Main component that displays device agents in a grid layout
- **agentTypeToToolType** - Mapping object that converts agent types to standardized tool types
- **combinedAgents** - Merged data structure combining installed agents with tool connections
- **InfoCard** - Card component displaying agent details with ID and version information
- **ToolBadge** - Badge component showing the tool type with appropriate styling
- **Tooltip integration** - Provides contextual help information for each agent

## Usage Example

```typescript
import { AgentsTab } from './agents-tab'
import type { Device } from './types/device.types'

const device: Device = {
  id: 'device-123',
  toolConnections: [
    { toolType: 'TACTICAL_RMM', agentToolId: 'agent-456' }
  ],
  installedAgents: [
    { agentType: 'tacticalrmm-agent', version: '1.2.3' }
  ]
}

function DeviceView() {
  return (
    <div>
      <AgentsTab device={device} />
    </div>
  )
}
```

The component handles both scenarios: devices with installed agents showing version info and connection status, and devices without agents displaying a helpful empty state with tooltips explaining the purpose of management agents.
