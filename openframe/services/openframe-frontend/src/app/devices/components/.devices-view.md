A React component that provides a comprehensive device management interface with dual view modes (table and grid), advanced filtering, cursor-based pagination, and real-time device operations.

## Key Components

- **DevicesView** - Main component orchestrating device display logic
- **ViewToggle** - Switches between table and grid display modes
- **Table** - Tabular view with sortable columns, filters, and row actions
- **DevicesGrid** - Grid layout for visual device browsing
- **useDevices** - Custom hook managing device data and operations
- **useCursorPaginationState** - Hook handling URL-synced pagination state
- **useApiParams** - Hook managing URL parameter state for filters and view mode

## Usage Example

```typescript
import { DevicesView } from './devices-view'

// Basic usage in a devices page
export default function DevicesPage() {
  return (
    <div className="min-h-screen">
      <DevicesView />
    </div>
  )
}

// The component automatically handles:
// - URL state management for filters, search, and pagination
// - View mode toggling (table/grid)
// - Device filtering by status, OS type, and organization
// - Navigation to device details on row/card click
// - Add new device functionality
```

The component features comprehensive state management with URL synchronization, allowing users to bookmark and share filtered device views. It supports real-time device operations like archiving and deletion with automatic list refresh, and provides responsive design with mobile-optimized filtering interfaces.
