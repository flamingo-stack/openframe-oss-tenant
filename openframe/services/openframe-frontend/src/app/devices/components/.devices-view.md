A comprehensive device management interface that provides both table and grid views for browsing, searching, and filtering devices with cursor-based pagination and real-time state management.

## Key Components

- **DevicesView** - Main component orchestrating device listing with dual view modes
- **ViewToggle** - Switches between table and grid display modes
- **Table/DevicesGrid** - Conditional rendering based on selected view mode
- **ListPageLayout** - Standardized layout with search, filters, and pagination
- **useDevices** - Custom hook managing device data fetching and filtering
- **useCursorPaginationState** - Handles pagination state and URL synchronization
- **useApiParams** - Manages URL parameters for filters and view preferences

## Usage Example

```typescript
import { DevicesView } from './devices-view'

// Render the complete devices management interface
function DevicesPage() {
  return (
    <div className="container">
      <DevicesView />
    </div>
  )
}

// The component automatically handles:
// - URL parameter synchronization (search, filters, pagination)
// - View mode switching (table/grid)
// - Device filtering by status, OS type, and organization
// - Cursor-based pagination with server-side data fetching
// - Navigation to device details on row/item selection
```

The component integrates multiple OpenFrame UI components and hooks to create a full-featured device management interface with responsive design, advanced filtering capabilities, and seamless navigation between different view modes while maintaining state consistency through URL parameters.
