A React component that provides a comprehensive devices management interface with both table and grid view modes, supporting advanced filtering, search, and pagination capabilities.

## Key Components

- **DevicesView** - Main component orchestrating the devices listing interface
- **ViewToggle** - Switch between table and grid display modes
- **Table/DevicesGrid** - Conditional rendering of data views
- **ListPageLayout** - Consistent page layout with header actions and search
- **Filter Management** - Multi-dimensional filtering by status, OS type, and organization
- **Cursor Pagination** - Server-side pagination with navigation controls

## Usage Example

```typescript
// Basic usage in a Next.js page
import { DevicesView } from './devices-view'

export default function DevicesPage() {
  return <DevicesView />
}

// The component handles all state management internally:
// - URL parameter synchronization for filters and view mode
// - Search functionality with debouncing
// - Pagination state management
// - Device data fetching and caching
```

The component integrates multiple OpenFrame UI components and hooks to create a full-featured device management interface. It manages complex state including search parameters, filter states, pagination cursors, and view modes while keeping everything synchronized with URL parameters for bookmarkable states. The interface supports both desktop table view with column filtering and mobile-optimized grid view with filter panels.
