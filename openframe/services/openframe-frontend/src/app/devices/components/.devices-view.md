A React component that provides a dual-view interface (table and grid) for managing devices with advanced filtering, search, and cursor-based pagination capabilities.

## Key Components

- **DevicesView** - Main component handling device list display with table/grid toggle
- **useDevices** - Custom hook for device data fetching and filtering
- **useCursorPaginationState** - Pagination state management with URL synchronization
- **useApiParams** - URL parameter management for filters and view mode
- **ViewToggle** - Component for switching between table and grid views
- **Table/DevicesGrid** - Conditional rendering based on selected view mode

## Usage Example

```typescript
import { DevicesView } from './components/devices-view'

// Used as a page component
export default function DevicesPage() {
  return <DevicesView />
}

// The component automatically handles:
// - URL params: /devices?viewMode=grid&statuses=ONLINE,OFFLINE
// - Search: /devices?search=laptop&cursor=abc123
// - Filters: /devices?osTypes=WINDOWS&organizationIds=org1,org2
```

## Features

- **Dual View Modes**: Toggle between table and grid layouts
- **Advanced Filtering**: Status, OS type, and organization filters with URL persistence
- **Cursor Pagination**: Efficient server-side pagination with navigation state
- **Search Integration**: Real-time device search with debouncing
- **Row Actions**: Archive/delete operations with refresh callbacks
- **Mobile Support**: Responsive design with mobile-specific filter UI
- **Navigation**: Click-to-navigate to device details pages

The component integrates multiple OpenFrame UI components and hooks to provide a comprehensive device management interface with persistent state management through URL parameters.
