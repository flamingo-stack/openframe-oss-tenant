A React component that provides a comprehensive device management interface with both table and grid view modes, supporting advanced filtering, search, and cursor-based pagination.

## Key Components

- **DevicesView**: Main component managing device listing with dual view modes
- **ViewToggle**: Switches between table and grid display modes
- **Table/DevicesGrid**: Conditional rendering based on view mode selection
- **useDevices**: Custom hook for device data management and API calls
- **useCursorPaginationState**: Handles pagination state and URL synchronization
- **useApiParams**: Manages URL parameters for filters and view preferences

## Usage Example

```typescript
import { DevicesView } from './devices-view'

// Basic usage - renders complete device management interface
function DevicesPage() {
  return <DevicesView />
}

// The component automatically handles:
// - URL parameter management (?viewMode=table&statuses[]=ONLINE)
// - Search functionality with debouncing
// - Filter state synchronization
// - Cursor-based pagination
// - Navigation to device details on row click
```

## Key Features

- **Dual View Modes**: Toggle between table and grid layouts
- **Advanced Filtering**: Filter by device status, OS type, and organization
- **Smart Pagination**: Cursor-based pagination with URL state persistence
- **Search Integration**: Real-time search with URL parameter synchronization
- **Mobile Responsive**: Dedicated mobile filter handling
- **Row Actions**: Support for device management actions (archive, delete)
- **Navigation**: Click-through to device detail pages

The component integrates with the OpenFrame design system and follows established patterns for list page layouts with comprehensive state management.
