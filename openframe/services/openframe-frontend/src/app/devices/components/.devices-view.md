A React component that provides a comprehensive devices management interface with table and grid view modes, search functionality, filtering, and cursor-based pagination.

## Key Components

- **DevicesView**: Main component rendering devices in either table or grid view
- **ViewToggle**: Switches between table and grid display modes
- **Table/DevicesGrid**: Conditional rendering based on selected view mode
- **Search & Filters**: Real-time search with status, OS type, and organization filtering
- **Cursor Pagination**: Server-side pagination with next/reset functionality
- **Row Actions**: Archive/delete operations with automatic refresh

## Usage Example

```typescript
import { DevicesView } from './devices-view'

// Use in a devices page
export default function DevicesPage() {
  return <DevicesView />
}

// The component handles all state management internally:
// - URL parameter synchronization (search, filters, view mode, cursor)
// - Device data fetching with filters
// - Pagination state management
// - View mode switching (table/grid)
// - Navigation to device details on row click
```

The component integrates with the OpenFrame frontend architecture, using custom hooks for API parameters, cursor pagination, and device data management. It provides a complete devices listing experience with filtering, search, and multiple view options while maintaining URL state synchronization.
