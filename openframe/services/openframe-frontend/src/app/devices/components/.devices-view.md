A React component that renders a comprehensive devices management interface with switchable table/grid views, advanced filtering, cursor-based pagination, and full CRUD operations for device management.

## Key Components

- **DevicesView** - Main component providing dual-view device management interface
- **ViewToggle** - Allows switching between table and grid display modes
- **Table/DevicesGrid** - Renders devices in either tabular or grid format
- **ListPageLayout** - Provides consistent layout with search, filters, and actions
- **Cursor Pagination** - Handles server-side pagination with cursor-based navigation
- **Advanced Filtering** - Multi-dimensional filtering by status, OS type, and organization

## Usage Example

```typescript
import { DevicesView } from './devices-view'

// Use in a page component
export default function DevicesPage() {
  return (
    <div className="container">
      <DevicesView />
    </div>
  )
}
```

The component automatically handles:
- URL state management for view mode, filters, and pagination
- Device fetching with real-time search and filtering
- Row actions (archive/delete) with automatic refresh
- Navigation to device details on row click
- Responsive mobile filtering interface
- Loading states and error handling

Key features include dual viewing modes (table/grid), advanced multi-column filtering, cursor-based server pagination, and seamless integration with the OpenFrame design system for consistent styling and behavior patterns.
