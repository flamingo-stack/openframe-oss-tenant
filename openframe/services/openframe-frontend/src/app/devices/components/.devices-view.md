A React component that provides a dual-view (table/grid) interface for managing and displaying devices with advanced filtering, search, and pagination capabilities.

## Key Components

- **DevicesView** - Main component orchestrating device display logic
- **useDevices** - Custom hook for device data management and API interactions
- **useCursorPaginationState** - Hook for managing cursor-based pagination state
- **useTablePagination** - Hook for table pagination controls
- **useApiParams** - Hook for URL parameter management and synchronization
- **getDeviceTableColumns/getDeviceTableRowActions** - Helper functions for table configuration

## Usage Example

```typescript
import { DevicesView } from './devices-view'

// Used as a page component
export default function DevicesPage() {
  return (
    <div className="container mx-auto p-4">
      <DevicesView />
    </div>
  )
}
```

The component supports:
- **View Modes**: Toggle between table and grid layouts
- **Advanced Filtering**: Filter by device status, OS type, and organization
- **Search & Pagination**: Real-time search with cursor-based pagination
- **Row Actions**: Archive/delete operations with automatic refresh
- **URL State Management**: All filters and search persist in URL parameters
- **Navigation**: Click-to-navigate to device detail pages

The component integrates with OpenFrame's design system and follows established patterns for list views with filtering and pagination.
