React component that provides a comprehensive devices management view with both table and grid display modes. Integrates device data fetching, filtering, search, and pagination functionality while maintaining URL state synchronization.

## Key Components

- **DevicesView**: Main component providing device listing with dual view modes
- **ViewToggle**: Switches between table and grid layouts
- **Table/DevicesGrid**: Conditional rendering based on view mode
- **useCursorPaginationState**: Manages pagination state and URL synchronization
- **useDevices**: Custom hook for device data fetching and filtering
- **useApiParams**: Handles URL parameter management for filters and view mode
- **getDeviceTableColumns/getDeviceTableRowActions**: Table configuration helpers

## Usage Example

```typescript
// Basic usage in a devices page
import { DevicesView } from './components/devices-view'

export default function DevicesPage() {
  return <DevicesView />
}

// The component automatically handles:
// - URL state: /devices?viewMode=table&statuses[]=ACTIVE&search=laptop
// - Filtering by status, OS type, and organization
// - Cursor-based pagination with search
// - View mode switching between table and grid
// - Device navigation to details page
```

The component manages complex state including search queries, multi-level filtering, pagination cursors, and view preferences while keeping everything synchronized with URL parameters for bookmarkable states and browser navigation support.
