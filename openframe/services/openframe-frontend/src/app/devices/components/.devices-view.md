A React component that provides a comprehensive devices management interface with table and grid view modes, supporting filtering, search, and pagination functionality.

## Key Components

- **DevicesView**: Main component that orchestrates the entire devices list interface
- **ViewToggle**: Switches between table and grid display modes
- **Table/DevicesGrid**: Conditional rendering based on view mode
- **ListPageLayout**: Provides consistent layout with search and filtering capabilities
- **useDevices**: Custom hook for device data management
- **useCursorPaginationState**: Manages pagination state and URL synchronization
- **useTablePagination**: Handles table-specific pagination logic

## Usage Example

```typescript
import { DevicesView } from './devices-view'

// Use in a Next.js page or layout
export default function DevicesPage() {
  return <DevicesView />
}

// The component automatically handles:
// - URL-based filtering (statuses, osTypes, organizationIds)
// - Search functionality with cursor pagination
// - View mode persistence (table/grid)
// - Device navigation on row click
```

## Key Features

**Dual View Modes**: Toggle between table and grid layouts for device browsing

**Advanced Filtering**: Multi-dimensional filtering by status, OS type, and organization with URL persistence

**Cursor Pagination**: Server-side pagination with navigation state management

**Search Integration**: Real-time search with automatic result fetching

**Mobile Optimization**: Responsive design with mobile-specific filter handling

**Navigation**: Click-through to device details using machineId or fallback ID
