React component that provides a dual-view interface (table/grid) for managing and displaying devices with advanced filtering, search, and pagination capabilities.

## Key Components

- **DevicesView**: Main component managing device display modes and data flow
- **ViewToggle**: Switches between table and grid view modes
- **Table/DevicesGrid**: Conditional rendering based on selected view mode
- **ListPageLayout**: Wrapper providing consistent layout with header and search
- **useDevices**: Custom hook for device data management and API calls
- **useCursorPaginationState**: Hook managing pagination state and URL synchronization
- **useApiParams**: Hook for URL parameter management (filters, view mode)

## Usage Example

```typescript
import { DevicesView } from './devices-view'

// Use in a page component
export default function DevicesPage() {
  return <DevicesView />
}

// The component automatically handles:
// - URL state management (?viewMode=table&statuses=ACTIVE,ONLINE)
// - Search functionality with debounced API calls
// - Filter management (status, OS type, organization)
// - Cursor-based pagination for large datasets
// - Row actions (archive, delete) with refresh callbacks
// - Navigation to device details on row click
```

The component uses cursor pagination for efficient handling of large device datasets and maintains all filter/search state in URL parameters for shareable links and browser navigation support.
