A comprehensive device management view component that provides both table and grid display modes for devices with advanced filtering, search, and pagination capabilities.

## Key Components

- **DevicesView**: Main component that orchestrates device display with dual view modes
- **ViewToggle**: Switches between table and grid layouts
- **Table/DevicesGrid**: Conditional rendering based on selected view mode
- **ListPageLayout**: Provides consistent page structure with header and search
- **useDevices**: Custom hook for device data management and API calls
- **useCursorPaginationState**: Manages pagination state and URL synchronization
- **useTablePagination**: Handles server-side pagination logic

## Usage Example

```typescript
import { DevicesView } from './components/devices-view'

export default function DevicesPage() {
  return <DevicesView />
}
```

The component supports URL-based filtering and pagination:
- `/devices?viewMode=grid&statuses=ONLINE,OFFLINE`
- `/devices?search=laptop&cursor=abc123`

Filter options include device status, OS type, and organization, with automatic URL synchronization for bookmarkable states.
