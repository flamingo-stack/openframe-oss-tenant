A React component that provides a comprehensive devices management interface with dual view modes (table and grid), advanced filtering, search functionality, and cursor-based pagination for the OpenFrame platform.

## Key Components

- **DevicesView** - Main component managing device listing with table/grid toggle
- **useDevices** - Hook for device data fetching and state management
- **useCursorPaginationState** - Hook for pagination state and URL parameter management
- **useApiParams** - Hook for managing URL-based filter parameters
- **DevicesGrid** - Grid view component for devices display
- **getDeviceTableColumns/getDeviceTableRowActions** - Table configuration utilities

## Usage Example

```typescript
import { DevicesView } from './devices-view'

// Basic usage in a page component
export default function DevicesPage() {
  return <DevicesView />
}

// The component automatically handles:
// - URL parameters for filters (statuses, osTypes, organizationIds)
// - View mode switching (table/grid)
// - Search and pagination state
// - Device filtering and refresh operations
```

## Key Features

- **Dual View Modes**: Toggle between table and grid layouts
- **Advanced Filtering**: Filter by device status, OS type, and organization
- **Cursor Pagination**: Server-side pagination with URL state persistence
- **Search Integration**: Real-time device search with debouncing
- **Row Actions**: Device management actions (archive, delete) with refresh
- **Mobile Responsive**: Adaptive filtering interface for mobile devices
- **Navigation**: Click-through to device details pages
- **URL State**: All filters, search, and pagination state persisted in URL

The component integrates with the OpenFrame design system and follows established patterns for data management, providing a consistent user experience across the platform.
