A React component that provides a comprehensive devices management interface with dual view modes (table and grid), advanced filtering, search functionality, and cursor-based pagination for optimal performance.

## Key Components

- **DevicesView** - Main container component managing device listing with table/grid views
- **View Management** - Toggle between table and grid display modes
- **Filtering System** - Multi-dimensional filtering by status, OS type, and organization
- **Pagination** - Cursor-based pagination for efficient data loading
- **Navigation** - Device detail routing and add device functionality

## Usage Example

```typescript
import { DevicesView } from './devices-view'

// Use in a devices listing page
export default function DevicesPage() {
  return (
    <div className="container">
      <DevicesView />
    </div>
  )
}

// The component automatically handles:
// - URL state management for filters and view mode
// - Cursor pagination with /devices?cursor=xyz&search=term
// - Filter persistence across navigation
// - Responsive mobile filtering interface
```

The component integrates with the OpenFrame frontend core system, utilizing hooks for API parameter management, cursor pagination, and table functionality. It supports real-time search, bulk filtering operations, and provides action menus for device management operations. The dual view system allows users to switch between detailed tabular data and visual grid layouts based on their workflow preferences.
