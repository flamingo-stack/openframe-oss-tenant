A React client component that provides a comprehensive device management interface with both table and grid view modes, advanced filtering, and cursor-based pagination.

## Key Components

- **DevicesView** - Main component managing device display with dual view modes
- **View Management** - Toggle between table and grid layouts via `ViewToggle`
- **Advanced Filtering** - Multi-criteria filtering by status, OS type, and organization
- **Cursor Pagination** - Server-side pagination with first/next page navigation
- **Search Integration** - Real-time device search with URL param persistence
- **Row Actions** - Device-specific actions with refresh callbacks
- **Navigation** - Click-to-navigate device details routing

## Usage Example

```typescript
import { DevicesView } from './devices-view'

// Basic usage in a page component
export default function DevicesPage() {
  return (
    <div className="min-h-screen">
      <DevicesView />
    </div>
  )
}

// The component handles its own state and URL params:
// - /devices?viewMode=table&statuses=ACTIVE,INACTIVE
// - /devices?search=server&cursor=abc123&osTypes=LINUX
```

The component integrates with OpenFrame's design system and provides a complete device management experience with persistent URL state, responsive design, and efficient data loading patterns. It automatically excludes archived/deleted devices by default and supports real-time filtering updates.
