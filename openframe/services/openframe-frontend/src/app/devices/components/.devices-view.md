Main devices list view component that provides both table and grid display modes for managing devices with filtering, pagination, and search capabilities.

## Key Components

- **DevicesView**: Main component that renders the devices list interface
- **ViewToggle**: Switches between table and grid display modes
- **Table/DevicesGrid**: Conditional rendering based on selected view mode
- **ListPageLayout**: Wrapper providing search, filters, and mobile responsiveness
- **Cursor Pagination**: Server-side pagination with next/reset functionality
- **Dynamic Filtering**: Status, OS type, and organization filters with URL state management

## Usage Example

```typescript
import { DevicesView } from './devices-view'

// Used as a page component
export default function DevicesPage() {
  return <DevicesView />
}

// The component automatically handles:
// - URL state management for filters and view mode
// - Search functionality with debouncing
// - Pagination with cursor-based navigation
// - Filter synchronization between table and mobile views
```

The component integrates with the devices API through the `useDevices` hook and manages complex state including search parameters, pagination cursors, and filter selections. It supports responsive design with mobile-optimized filtering and provides actions for adding new devices and navigating to device details.
