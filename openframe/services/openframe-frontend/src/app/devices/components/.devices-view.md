A React component that provides a comprehensive view for managing and displaying devices in both table and grid formats with advanced filtering, search, and pagination capabilities.

## Key Components

- **DevicesView**: Main component managing device display with table/grid toggle
- **ViewToggle**: Switches between table and grid view modes
- **Table/DevicesGrid**: Conditional rendering based on selected view mode
- **ListPageLayout**: Provides consistent layout with header actions and search
- **Cursor Pagination**: Server-side pagination with navigation controls
- **Advanced Filtering**: Multi-dimensional filtering by status, OS type, and organization
- **Row Actions**: Device-specific actions (archive/delete) with refresh callbacks

## Usage Example

```typescript
import { DevicesView } from './devices-view'

// Basic usage in a Next.js page
export default function DevicesPage() {
  return <DevicesView />
}

// The component automatically handles:
// - URL parameter management for filters and view mode
// - Device data fetching with pagination
// - Search functionality with debounced API calls
// - Filter state synchronization between table and mobile views
```

The component integrates with the devices API hook to provide real-time data management, supports both desktop table filtering and mobile-optimized filter panels, and maintains URL state for bookmarkable filtered views. Device rows are clickable and navigate to individual device detail pages using either `machineId` or `id` as the routing parameter.
