A React component that provides a comprehensive device management interface with dual viewing modes (table and grid), advanced filtering, cursor-based pagination, and real-time search capabilities.

## Key Components

- **DevicesView** - Main component that orchestrates device listing with table/grid views
- **ViewToggle** - Switches between table and grid display modes
- **Table/DevicesGrid** - Conditional rendering based on selected view mode
- **useDevices** - Custom hook for device data fetching and state management
- **useCursorPaginationState** - Manages pagination state and URL synchronization
- **useTablePagination** - Handles server-side pagination controls

## Usage Example

```typescript
import { DevicesView } from './devices-view'

// Use in a Next.js page component
export default function DevicesPage() {
  return <DevicesView />
}

// The component automatically handles:
// - URL state synchronization for filters and pagination
// - Search functionality with debouncing
// - Filter state management (statuses, OS types, organizations)
// - Navigation to device details on row click
```

## Key Features

- **Dual View Modes**: Toggle between table and responsive grid layouts
- **Advanced Filtering**: Multi-select filters for device status, OS type, and organization
- **Cursor Pagination**: Server-side pagination with efficient data loading
- **Real-time Search**: Instant device search with URL state persistence
- **Responsive Design**: Mobile-optimized with collapsible filters
- **Row Actions**: Context menu for device operations (archive, delete)
- **Deep Linking**: All state (search, filters, pagination) synced with URL

The component integrates with the OpenFrame design system and follows modern React patterns with comprehensive error handling and loading states.
