A React component that provides a comprehensive devices management interface with table/grid view toggle, filtering, search, and pagination capabilities.

## Key Components

- **DevicesView** - Main component export that renders the complete devices list interface
- **View Toggle** - Switches between table and grid display modes
- **Search & Filtering** - URL-synchronized search with status, OS type, and organization filters
- **Cursor Pagination** - Server-side pagination with next/reset navigation
- **Table Actions** - Row-level actions for device management with refresh callbacks
- **Navigation** - Click-to-navigate to device details pages

## Usage Example

```typescript
import { DevicesView } from './devices-view'

// Basic usage - renders complete devices management interface
function DevicesPage() {
  return <DevicesView />
}

// The component handles all state management internally:
// - URL params for filters and view mode
// - Search functionality with debouncing
// - Pagination with cursor-based loading
// - Device data fetching and caching
```

The component integrates with the OpenFrame frontend core for UI components and hooks, managing complex state synchronization between URL parameters, API calls, and UI interactions. It supports both table and grid views with consistent filtering and search across both modes.
