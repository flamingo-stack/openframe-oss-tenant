A React component that provides a comprehensive device management interface with table/grid view toggle, filtering, search, and cursor-based pagination functionality.

## Key Components

- **DevicesView** - Main component managing device display, filtering, and pagination
- **View Management** - Toggle between table and grid layouts with persistent URL state
- **Filter System** - Multi-faceted filtering by device status, OS type, and organization
- **Cursor Pagination** - Server-side pagination with URL state synchronization
- **Search Integration** - Real-time device search with debounced input
- **Device Actions** - Row-level actions for device management operations

## Usage Example

```typescript
import { DevicesView } from './devices-view'

// Basic usage in a devices page
export default function DevicesPage() {
  return (
    <div className="devices-page">
      <DevicesView />
    </div>
  )
}

// The component automatically handles:
// - URL params: ?viewMode=table&statuses[]=active&cursor=xyz
// - Filter persistence across navigation
// - Search state management
// - Pagination with cursor-based loading
```

The component integrates with the `useDevices` hook for data fetching, manages complex filter states through URL parameters, and provides both table and grid viewing modes. It includes mobile-responsive filtering, device creation navigation, and row-level actions for device management. The cursor pagination system enables efficient loading of large device datasets with proper loading states and error handling.
