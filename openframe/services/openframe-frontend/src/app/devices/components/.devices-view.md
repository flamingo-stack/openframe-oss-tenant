A React component that provides a comprehensive devices management interface with table and grid view modes, advanced filtering, search, and cursor-based pagination functionality.

## Key Components

- **DevicesView**: Main component that orchestrates the device management interface
- **useDevices**: Custom hook for device data fetching and management
- **useCursorPaginationState**: Hook for cursor-based pagination state management
- **useTablePagination**: Hook for table pagination configuration
- **ViewToggle**: Component for switching between table and grid views
- **DevicesGrid**: Grid layout component for device cards
- **getDeviceTableColumns/getDeviceTableRowActions**: Table configuration utilities

## Usage Example

```typescript
import { DevicesView } from './devices-view'

// Use as a page component
export default function DevicesPage() {
  return <DevicesView />
}

// The component handles all device management functionality:
// - Search and filtering by status, OS type, organization
// - Table/grid view toggle
// - Cursor-based pagination
// - Device creation navigation
// - Row actions (archive/delete with refresh)
// - Mobile-responsive filtering
```

The component integrates URL state management for filters and view mode, supports both table and grid layouts, and provides a responsive interface with mobile-optimized filtering. It includes comprehensive pagination with cursor-based navigation and maintains filter state across view mode changes.
