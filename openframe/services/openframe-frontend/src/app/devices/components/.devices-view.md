A React component that renders a comprehensive devices management interface with switchable table/grid views, advanced filtering, cursor pagination, and full CRUD operations.

## Key Components

**Main Exports:**
- `DevicesView` - Primary component providing complete device management interface

**Core Features:**
- **Dual View Modes** - Toggleable table and grid layouts via `ViewToggle`
- **Advanced Filtering** - Multi-dimensional filtering by device status, OS type, and organization
- **Cursor Pagination** - Server-side pagination with infinite scroll capabilities
- **Search Functionality** - Real-time device search with URL state persistence
- **Row Actions** - Contextual actions for device operations (archive, delete, etc.)

**Key Hooks:**
- `useDevices()` - Custom hook for device data fetching and management
- `useCursorPaginationState()` - Handles pagination state and URL synchronization
- `useApiParams()` - Manages URL parameters for filters and view mode
- `useTablePagination()` - Configures table pagination controls

## Usage Example

```typescript
import { DevicesView } from './devices-view'

// Basic usage - renders full device management interface
export default function DevicesPage() {
  return <DevicesView />
}

// Component handles all state management internally:
// - URL params: ?viewMode=table&statuses=active,pending&search=laptop
// - Filter state: Persisted across page refreshes
// - Pagination: Cursor-based with next/reset functionality
// - Navigation: Click rows to go to device details
```

The component automatically excludes archived/deleted devices by default and provides mobile-responsive filtering through `ListPageLayout`. Navigation to device creation (`/devices/new`) and details (`/devices/details/:id`) is handled internally.
