A comprehensive device management view component that provides both table and grid display modes for device listings with advanced filtering, search, and pagination capabilities.

## Key Components

- **DevicesView**: Main component handling device listing with dual view modes
- **ViewToggle**: Switches between table and grid display formats
- **Table/DevicesGrid**: Renders devices in tabular or grid layout
- **ListPageLayout**: Provides consistent page structure with header actions
- **useDevices**: Custom hook for device data fetching and management
- **useCursorPaginationState**: Manages cursor-based pagination state
- **useTablePagination**: Handles table pagination UI logic

## Usage Example

```typescript
import { DevicesView } from './components/devices-view'

// Basic usage in a page component
export default function DevicesPage() {
  return <DevicesView />
}

// The component automatically handles:
// - URL parameter synchronization (viewMode, filters, pagination)
// - Device filtering by status, OS type, and organization
// - Search functionality with debounced input
// - Cursor-based pagination for large datasets
// - Navigation to device detail pages on row click
```

The component integrates multiple OpenFrame UI components and hooks to create a full-featured device management interface. It supports real-time filtering, maintains URL state for bookmarkable views, and provides responsive design with mobile-optimized filter controls. The dual view mode allows users to switch between detailed table view and visual grid layout based on their preference.
