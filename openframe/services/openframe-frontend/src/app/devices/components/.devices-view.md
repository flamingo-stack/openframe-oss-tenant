React component that renders a comprehensive device management interface with dual view modes (table and grid), filtering, search, and pagination capabilities.

## Key Components

- **DevicesView**: Main component managing device display state and user interactions
- **ViewToggle**: Switches between table and grid display modes
- **Table**: Data table with sorting, filtering, and cursor pagination
- **DevicesGrid**: Alternative grid layout for device cards
- **ListPageLayout**: Wrapper providing consistent page structure and mobile-responsive filtering

## Usage Example

```typescript
import { DevicesView } from './components/devices-view'

// Render the complete devices management interface
export default function DevicesPage() {
  return <DevicesView />
}
```

The component integrates multiple hooks for state management:
- `useApiParams` for URL parameter synchronization
- `useCursorPaginationState` for pagination state
- `useDevices` for data fetching and filtering
- `useTablePagination` for table-specific pagination controls

Features include real-time search, multi-column filtering (status, OS type, organization), row actions for device management, and responsive design with mobile-optimized filters. Navigation to device details occurs on row/card clicks, with support for both machine ID and fallback ID routing.
