Client-side React component that provides a unified view for managing devices with both table and grid display modes, featuring filtering, search, and pagination capabilities.

## Key Components

- **DevicesView**: Main component handling device list display with dual view modes
- **useDevices**: Custom hook for device data fetching and management
- **useCursorPaginationState**: Hook managing cursor-based pagination state
- **useTablePagination**: Hook providing table pagination controls
- **useApiParams**: Hook managing URL parameters for filters and view mode

## Usage Example

```typescript
import { DevicesView } from './devices-view'

function DevicesPage() {
  return (
    <div>
      <DevicesView />
    </div>
  )
}
```

The component automatically handles:
- **Dual View Modes**: Toggle between table and grid layouts
- **Advanced Filtering**: Status, OS type, and organization filtering
- **Search & Pagination**: Real-time search with cursor-based pagination
- **URL State Management**: All filters and search state synced to URL
- **Row Actions**: Device management actions (archive, delete) with refresh
- **Navigation**: Click-to-view device details functionality

Integrates with the OpenFrame UI system and provides a complete device management interface with responsive design and mobile filter support.
