This is a React component that provides a comprehensive device management interface with dual viewing modes (table and grid), advanced filtering, and cursor-based pagination for an MSP platform.

## Key Components

- **DevicesView**: Main component managing device list display with table/grid view toggle
- **ViewToggle**: Switch between table and grid display modes
- **Table/DevicesGrid**: Conditional rendering based on selected view mode
- **Filtering System**: Multi-column filtering for device status, OS type, and organization
- **Cursor Pagination**: Server-side pagination with navigation controls
- **Search Functionality**: Real-time device search with debouncing
- **Row Actions**: Device-specific actions (archive, delete, etc.)

## Usage Example

```typescript
import { DevicesView } from './devices-view'

// Basic usage in a page component
export default function DevicesPage() {
  return (
    <div className="container mx-auto">
      <DevicesView />
    </div>
  )
}

// The component handles all URL params automatically:
// /devices?viewMode=grid&statuses=ONLINE,OFFLINE&search=server
```

The component integrates with OpenFrame's design system and provides a complete device management experience with filtering by status (excluding ARCHIVED/DELETED by default), OS types, organizations, plus real-time search and responsive pagination. Navigation to device details occurs on row clicks, while the header includes an "Add Device" button for creating new entries.
