A comprehensive React component that provides a dual-view interface (table and grid) for displaying and managing devices with advanced filtering, search, and pagination capabilities.

## Key Components

- **DevicesView** - Main component managing device list display with table/grid view toggle
- **useDevices** - Custom hook for device data fetching and management
- **useCursorPaginationState** - Hook for handling cursor-based pagination
- **useApiParams** - Hook for managing URL parameters and filters
- **DevicesGrid** - Grid view component for device display
- **getDeviceTableColumns/getDeviceTableRowActions** - Table configuration utilities

## Key Features

- **Dual View Modes**: Toggle between table and grid layouts
- **Advanced Filtering**: Multi-column filters for status, OS type, and organization
- **Cursor Pagination**: Server-side pagination with navigation controls
- **Search Functionality**: Real-time device search
- **URL State Management**: Filter and pagination state persisted in URL
- **Row Actions**: Device management actions (archive, delete, etc.)
- **Mobile Support**: Responsive design with mobile-specific filter handling

## Usage Example

```typescript
import { DevicesView } from './devices-view'

// Basic usage - renders complete device management interface
function DevicesPage() {
  return <DevicesView />
}

// The component handles all internal state and provides:
// - Search bar for device filtering
// - View toggle (table/grid)
// - Add device button
// - Pagination controls
// - Filter dropdowns
// - Row click navigation to device details
```

The component integrates with the OpenFrame UI system and provides a complete device management experience with enterprise-grade features like advanced filtering, pagination, and responsive design.
