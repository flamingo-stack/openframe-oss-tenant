React component that provides a comprehensive devices management interface with dual table/grid views, advanced filtering, search, and cursor-based pagination. Built using OpenFrame frontend components and hooks for seamless device browsing and management.

## Key Components

- **DevicesView**: Main component orchestrating the devices interface
- **ViewToggle**: Switches between table and grid display modes  
- **Table/DevicesGrid**: Conditional rendering based on view mode
- **useDevices**: Custom hook managing device data and API calls
- **useCursorPaginationState**: Handles search and pagination state
- **useApiParams**: Manages URL parameters for filters and view mode

## Usage Example

```typescript
import { DevicesView } from './devices-view'

// Use as a page component
export default function DevicesPage() {
  return <DevicesView />
}

// The component automatically handles:
// - URL parameter synchronization (?viewMode=grid&statuses=ONLINE)
// - Search with debouncing
// - Filter management (status, OS type, organization)
// - Cursor-based pagination
// - Navigation to device details on row click
```

The component integrates with OpenFrame's design system and provides a complete devices management experience with filtering by status, OS type, and organization, plus the ability to add new devices through the header action button.
