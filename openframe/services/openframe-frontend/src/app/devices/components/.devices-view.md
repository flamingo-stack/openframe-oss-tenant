A React component that provides a comprehensive view for managing devices with both table and grid display modes, including pagination, filtering, and search functionality.

## Key Components

- **DevicesView** - Main component rendering device management interface
- **ViewToggle** - Switch between table and grid display modes
- **Table/DevicesGrid** - Conditional rendering of device data in different layouts
- **ListPageLayout** - Wrapper providing common page structure with search and filters
- **Cursor Pagination** - Server-side pagination with next/reset controls
- **Dynamic Filtering** - Multi-column filtering for status, OS type, and organization

## Usage Example

```typescript
import { DevicesView } from './devices-view'

// Render the complete devices management interface
export default function DevicesPage() {
  return <DevicesView />
}

// The component handles URL state management automatically:
// - /devices?viewMode=table&statuses=ONLINE,OFFLINE
// - /devices?search=laptop&cursor=abc123
// - /devices?osTypes=Windows,MacOS&organizationIds=org1,org2
```

The component integrates with the devices API through the `useDevices` hook, manages URL parameters for persistent state, and provides navigation to device details pages. It supports both table view with sortable columns and grid view for visual device browsing, with real-time search and filtering capabilities.
