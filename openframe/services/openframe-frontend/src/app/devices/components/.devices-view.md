A React component that provides a comprehensive device management interface with dual view modes (table/grid), filtering, search, and pagination capabilities.

## Key Components

- **DevicesView**: Main component managing device listing with table/grid views
- **ViewToggle**: Switches between table and grid display modes
- **Table/DevicesGrid**: Conditional rendering based on selected view mode
- **ListPageLayout**: Provides consistent page layout with search and filters
- **Cursor Pagination**: Server-side pagination with next/reset functionality
- **Dynamic Filters**: Status, OS type, and organization filtering
- **Row Actions**: Device-specific actions (archive, delete, etc.)

## Usage Example

```typescript
import { DevicesView } from './devices-view'

// Basic usage - renders complete device management interface
function DevicesPage() {
  return <DevicesView />
}

// The component automatically handles:
// - URL parameter synchronization (search, filters, pagination)
// - View mode toggling (table vs grid)
// - Device filtering by status, OS, organization
// - Navigation to device details on row click
// - Add device functionality via header button
```

The component integrates with the OpenFrame design system and provides a complete device management experience with responsive design, loading states, error handling, and mobile-optimized filtering.
