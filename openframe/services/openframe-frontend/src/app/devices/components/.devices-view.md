A comprehensive React component that provides both table and grid view modes for displaying and managing devices with filtering, pagination, and search capabilities.

## Key Components

- **DevicesView**: Main component that renders device list with toggleable table/grid views
- **useDevices**: Custom hook for device data management and API operations
- **useCursorPaginationState**: Hook for handling cursor-based pagination with URL state
- **useTablePagination**: Hook for table pagination controls
- **useApiParams**: Hook for managing URL parameters and filters
- **DevicesGrid**: Grid view component for device cards
- **getDeviceTableColumns/getDeviceTableRowActions**: Table configuration functions

## Key Features

- **Dual View Modes**: Switch between table and grid layouts
- **Advanced Filtering**: Filter by status, OS type, and organization
- **Cursor Pagination**: Server-side pagination with URL state persistence
- **Search Functionality**: Real-time device search
- **Row Actions**: Device-specific actions (archive, delete, etc.)
- **Mobile Responsive**: Dedicated mobile filter interface
- **Navigation**: Click-to-navigate to device details

## Usage Example

```typescript
import { DevicesView } from './devices-view'

// Use in a page component
export default function DevicesPage() {
  return (
    <div className="container mx-auto">
      <DevicesView />
    </div>
  )
}

// The component automatically handles:
// - URL params: ?search=query&cursor=abc&viewMode=grid&statuses=ACTIVE
// - Filter state management
// - Pagination state
// - Search debouncing
// - Navigation to /devices/details/:id on row click
// - Navigation to /devices/new for creating devices
```

The component integrates with the OpenFrame UI system and provides a complete device management interface with persistent URL state for filters, search, and pagination.
