A React component that provides a dual-view interface for displaying and managing devices, offering both table and grid layouts with filtering, search, and pagination capabilities.

## Key Components

- **DevicesView** - Main component managing device display with switchable table/grid views
- **ViewToggle** - Toggle between table and grid display modes
- **Table/DevicesGrid** - Conditional rendering of device data in different formats
- **ListPageLayout** - Layout wrapper providing search, filters, and header actions
- **useDevices** - Custom hook for device data fetching and management
- **useCursorPaginationState** - Hook managing pagination state and URL synchronization
- **useApiParams** - Hook for URL parameter management (view mode, filters)

## Usage Example

```typescript
import { DevicesView } from './devices-view'

function DevicesPage() {
  return <DevicesView />
}
```

The component automatically handles:
- URL-based filter persistence (`statuses`, `osTypes`, `organizationIds`, `viewMode`)
- Cursor-based pagination with server-side data fetching
- Search functionality with debounced queries
- Row actions (archive/delete) with automatic refresh
- Navigation to device details on row/card click
- Responsive mobile filtering interface

Default behavior excludes archived and deleted devices unless explicitly filtered. The view mode defaults to 'table' and can be toggled to 'grid' view for different data presentation styles.
