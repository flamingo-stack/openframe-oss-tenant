A React component that provides a comprehensive device management interface with dual view modes (table/grid), advanced filtering, search functionality, and cursor-based pagination for the OpenFrame platform.

## Key Components

- **DevicesView**: Main component rendering the complete device management interface
- **ViewToggle**: Switches between table and grid display modes
- **Table**: Displays devices in a tabular format with sorting, filtering, and pagination
- **DevicesGrid**: Alternative grid view for device visualization
- **ListPageLayout**: Provides consistent layout structure with search and filter capabilities

## Usage Example

```typescript
import { DevicesView } from './devices-view'

// Basic usage - renders complete device management interface
function DevicesPage() {
  return <DevicesView />
}

// The component automatically handles:
// - URL state management for filters and pagination
// - Device data fetching and caching
// - Search functionality with debounced queries
// - Filter management (status, OS type, organization)
// - Navigation to device details on row/card click
```

The component integrates multiple hooks (`useDevices`, `useCursorPaginationState`, `useTablePagination`) to manage complex state synchronization between URL parameters, API calls, and UI interactions. It supports filtering by device status, OS type, and organization while maintaining pagination state across view mode changes.
