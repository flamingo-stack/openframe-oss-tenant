A React component that provides a comprehensive devices management interface with dual view modes (table/grid), advanced filtering, search functionality, and cursor-based pagination for displaying and managing IT devices in an MSP platform.

## Key Components

- **DevicesView**: Main component that orchestrates the entire devices listing experience
- **ViewToggle**: Switches between table and grid display modes
- **Table/DevicesGrid**: Conditional rendering of device data in different formats
- **useCursorPaginationState**: Hook for managing cursor-based pagination state
- **useDevices**: Custom hook for fetching and managing device data
- **ListPageLayout**: Wrapper providing consistent page structure and mobile-responsive design

## Usage Example

```typescript
import { DevicesView } from './devices-view'

// Basic usage in a route component
export default function DevicesPage() {
  return <DevicesView />
}

// The component automatically handles:
// - URL parameter synchronization for filters and view mode
// - Cursor pagination with search
// - Mobile-responsive filtering
// - Navigation to device details on row/card click
```

## Key Features

- **Dual View Modes**: Toggle between table and grid layouts via URL parameters
- **Advanced Filtering**: Filter by device status, OS type, and organization with URL persistence
- **Cursor Pagination**: Efficient pagination for large datasets with next/reset navigation
- **Mobile Responsive**: Adaptive filtering interface for mobile devices
- **Search Integration**: Real-time search with debounced API calls
- **Row Actions**: Context-sensitive actions like archive/delete with automatic refresh
- **Deep Linking**: All state (filters, pagination, view mode) persisted in URL for bookmarking

The component integrates with the OpenFrame frontend core components and follows the platform's design system with proper error handling and loading states.
