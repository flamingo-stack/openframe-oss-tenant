A React component that provides a unified devices view with both table and grid display modes, featuring advanced filtering, search, and cursor pagination capabilities.

## Key Components

- **DevicesView** - Main component that orchestrates the devices listing interface
- **View Toggle** - Switch between table and grid display modes
- **Filter Management** - Multi-dimensional filtering by status, OS type, and organization
- **Cursor Pagination** - Server-side pagination with next/reset navigation
- **Search Integration** - Real-time device search functionality
- **Row Actions** - Context-sensitive actions for device management

## Usage Example

```typescript
import { DevicesView } from './devices-view'

// Use in a devices listing page
function DevicesPage() {
  return (
    <div>
      <DevicesView />
    </div>
  )
}

// The component handles all state management internally:
// - URL-based filter persistence
// - Pagination state
// - Search functionality
// - View mode switching
```

The component integrates with the OpenFrame design system and uses custom hooks for device data fetching (`useDevices`), API parameter management (`useApiParams`), and pagination state (`useCursorPaginationState`). It automatically excludes archived and deleted devices by default and provides navigation to device detail pages on row selection.
