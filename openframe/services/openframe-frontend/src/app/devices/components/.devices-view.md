A React component that provides a complete devices management interface with dual view modes (table/grid), filtering, search, and pagination capabilities.

## Key Components

**Main Exports:**
- `DevicesView` - Primary component rendering the devices management interface

**Core Features:**
- **Dual View Modes**: Table and grid layouts with toggle functionality
- **Advanced Filtering**: Status, OS types, and organization-based filters
- **Cursor Pagination**: Server-side pagination with navigation controls
- **Search Functionality**: Real-time device search with debounced queries
- **Row Actions**: Device management actions (archive, delete) with refresh callbacks
- **Navigation**: Click-to-navigate device details routing

**State Management:**
- URL-based parameter management for filters and view preferences
- Cursor pagination state with first-page tracking
- Filter synchronization between mobile and desktop interfaces

## Usage Example

```typescript
import { DevicesView } from './devices-view'

// Basic usage in a devices page
function DevicesPage() {
  return (
    <div className="devices-page">
      <DevicesView />
    </div>
  )
}

// The component handles all internal state and URL synchronization
// URL params automatically managed:
// - /devices?viewMode=grid&statuses=ONLINE,OFFLINE
// - /devices?search=laptop&cursor=abc123&osTypes=WINDOWS
```

The component integrates with the OpenFrame UI system and manages complex state interactions between search, filtering, pagination, and view switching while maintaining URL synchronization for bookmarkable states.
