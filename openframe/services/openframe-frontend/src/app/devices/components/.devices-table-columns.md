Defines table column configuration for device management tables in the OpenFrame platform. Provides reusable column definitions and custom cell renderers for displaying device data in tabular format.

## Key Components

### **getDeviceTableColumns**
- Main function that returns an array of `TableColumn<Device>` configurations
- Includes columns for device info, status, OS type, and organization
- Supports responsive design with breakpoint-based column hiding
- Configures filterable columns with dynamic filter options

### **getDeviceTableRowActions**
- Returns a render function for device action dropdowns in table rows
- Provides three-dots menu with device-specific actions
- Accepts optional refresh callback for post-action updates

### **OrganizationCell**
- Custom cell component for organization column
- Conditionally renders organization icons based on feature flags
- Displays organization name with proper text styling

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'

// Configure table columns with filters
const columns = getDeviceTableColumns(deviceFilters)

// Add row actions with refresh callback
const rowActions = getDeviceTableRowActions(() => {
  // Handle table refresh after action
  refetchDevices()
})

// Use in data table component
<DataTable
  columns={columns}
  data={devices}
  rowActions={rowActions}
/>
```

The columns automatically handle responsive design, filtering, and proper rendering of device status, OS badges, and organization information with appropriate styling and icons.
