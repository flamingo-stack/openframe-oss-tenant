Column configuration for device table components with filtering, rendering, and responsive behavior.

## Key Components

- **`getDeviceTableColumns()`** - Main function that returns an array of table column configurations for device data
- **`getDeviceTableRowActions()`** - Returns a render function for the device actions dropdown menu in table rows
- **`OrganizationCell`** - React component that renders organization information with optional icon display

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'

// Configure table columns with filters
const columns = getDeviceTableColumns(deviceFilters)

// Set up row actions with refresh callback
const rowActions = getDeviceTableRowActions(() => {
  console.log('Device action completed, refreshing...')
})

// Use with table component
<DataTable
  columns={columns}
  data={devices}
  rowActions={rowActions}
/>
```

The column configuration includes:
- **Device**: Shows device icon and display name/hostname
- **Status**: Displays status tags with last seen timestamp and filtering options
- **OS**: Shows OS type badges with filtering capability
- **Organization**: Renders organization name with optional icon (feature flag controlled)

Each column supports responsive design with configurable widths and hide breakpoints for mobile optimization.
