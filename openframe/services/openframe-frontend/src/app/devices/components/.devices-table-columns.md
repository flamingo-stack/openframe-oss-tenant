This file defines table column configurations for displaying device data in a table format, including custom cell renderers and filtering options.

## Key Components

- `getDeviceTableRowActions()` - Creates action dropdown renderer for table rows
- `getDeviceTableColumns()` - Defines the main table column structure with 4 columns:
  - **Device**: Shows device icon and name
  - **Status**: Displays status badge and last seen timestamp
  - **OS**: Shows operating system badge
  - **Organization**: Displays organization icon and name (hidden on mobile)
- `OrganizationCell` - Custom cell component for organization display
- Filter configurations for status, OS type, and organization columns

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'

// Configure table with columns and row actions
const Table = () => {
  const handleRefresh = () => { /* refresh logic */ }
  
  const columns = getDeviceTableColumns(deviceFilters)
  const rowActions = getDeviceTableRowActions(handleRefresh)
  
  return (
    <DataTable 
      columns={columns}
      data={devices}
      renderRowActions={rowActions}
    />
  )
}
```

The columns are responsive (some hidden on mobile) and include filterable options for status, OS type, and organization. Status filtering excludes ARCHIVED and DELETED entries by default, with ARCHIVED shown separately below a divider.
