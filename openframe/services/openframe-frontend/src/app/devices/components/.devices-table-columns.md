Provides column configuration and rendering logic for device tables in the OpenFrame platform, defining how device data is displayed, filtered, and interacted with in tabular views.

## Key Components

- **`getDeviceTableRowActions()`** - Returns a render function for device action menus (three dots dropdown)
- **`OrganizationCell`** - React component for rendering organization information with optional logo
- **`getDeviceTableColumns()`** - Main function that returns complete column configuration array
- **Column definitions** - Device name, status, OS type, and organization columns with filtering support

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'
import { DataTable } from '@flamingo-stack/openframe-frontend-core/components/ui'

// Configure table columns with filters
const columns = getDeviceTableColumns(deviceFilters)

// Set up row actions
const rowActions = getDeviceTableRowActions(() => {
  // Refresh callback after actions
  refetchDevices()
})

// Use in DataTable component
<DataTable
  columns={columns}
  data={devices}
  rowActions={rowActions}
  // ... other props
/>
```

The columns include responsive design (hiding certain columns on mobile), filtering capabilities for status/OS/organization, and custom cell renderers that display device icons, status badges, last seen timestamps, and organization branding. Status filtering excludes deleted devices and separates archived devices below a divider.
