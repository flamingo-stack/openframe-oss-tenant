Configures table columns for device management with filtering, status display, and organization details.

## Key Components

- **`getDeviceTableRowActions`** - Returns render function for device action dropdown menus
- **`getDeviceTableColumns`** - Creates column configuration array with device info, status, OS, and organization
- **`OrganizationCell`** - Custom cell component displaying organization icon and name
- **Device Column** - Shows device icon and display name/hostname
- **Status Column** - Displays status tag with last seen timestamp and filterable status options
- **OS Column** - Shows OS type badge with filtering capability
- **Organization Column** - Shows organization icon/name with filtering support

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'

// Configure table columns with filters
const deviceFilters = {
  statuses: [
    { value: 'ONLINE', label: 'Online' },
    { value: 'OFFLINE', label: 'Offline' }
  ],
  osTypes: [
    { value: 'Windows', label: 'Windows' },
    { value: 'macOS', label: 'macOS' }
  ],
  organizationIds: [
    { value: 'org1', label: 'Company A' }
  ]
}

const columns = getDeviceTableColumns(deviceFilters)
const rowActions = getDeviceTableRowActions(() => {
  // Refresh callback after actions
  console.log('Table refreshed')
})

// Use with table component
<DataTable
  columns={columns}

  rowActions={rowActions}
/>
```

The configuration includes responsive column widths, filterable status/OS/organization options, and custom cell renderers with proper status handling that excludes archived/deleted devices from normal filters.
