Column configuration and row components for device data tables in OpenFrame, providing customizable table structures with filtering, status display, and organization branding.

## Key Components

- **`getDeviceTableRowActions()`** - Returns a render function for the device actions dropdown menu in table rows
- **`OrganizationCell`** - React component displaying organization name with optional branded icon
- **`getDeviceTableColumns()`** - Main function returning complete column configuration array for device tables
- **Column definitions** - Device name, status, OS type, and organization columns with filtering and responsive behavior

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'

// Configure table columns with filtering data
const columns = getDeviceTableColumns(deviceFilters)

// Set up row actions with refresh callback
const rowActions = getDeviceTableRowActions(() => {
  // Refresh table data after actions
  refetchDevices()
})

// Use in table component
<DataTable
  columns={columns}
  data={devices}
  rowActions={rowActions}
/>
```

The columns support responsive design (hiding at different breakpoints), filtering by status/OS/organization, and feature flag controls for organization images. Status column includes last seen timestamps, while the device column shows device type icons and display names.
