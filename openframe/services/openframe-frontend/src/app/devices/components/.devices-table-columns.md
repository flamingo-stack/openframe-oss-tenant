This file defines the column configuration and rendering logic for the devices table in the OpenFrame dashboard, providing customizable table columns with filtering capabilities.

## Key Components

- **`getDeviceTableRowActions`** - Returns a render function for the three-dots actions dropdown menu in table rows
- **`OrganizationCell`** - React component that renders organization information with optional logo and name
- **`getDeviceTableColumns`** - Main function that returns an array of table column configurations with filtering options
- **Column definitions** for device name, status, OS type, and organization with responsive breakpoints

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'

// Configure table columns with filtering data
const columns = getDeviceTableColumns(deviceFilters)

// Set up row actions with refresh callback
const rowActions = getDeviceTableRowActions(() => {
  // Refresh table data after actions
  refetchDevices()
})

// Use in table component
<DataTable 
  columns={columns}
  data={devices}
  rowActions={rowActions}
/>
```

The columns are responsive (hiding at different breakpoints), include status filtering with special handling for archived devices, and integrate with the OpenFrame UI component system for consistent styling and functionality.
