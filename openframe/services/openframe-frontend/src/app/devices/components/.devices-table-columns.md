A React component that defines the table structure and column configurations for device management tables in the OpenFrame platform.

## Key Components

- **getDeviceTableRowActions()** - Returns a render function for device action dropdown menus in table rows
- **getDeviceTableColumns()** - Main function that returns column definitions for device tables
- **OrganizationCell** - React component for rendering organization information with optional icons
- **Column Definitions** - Four main columns: Device, Status, OS, and Organization with filtering capabilities

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'

// Basic table setup
const columns = getDeviceTableColumns(deviceFilters)

// With row actions
const handleRefresh = () => { /* refresh logic */ }
const rowActions = getDeviceTableRowActions(handleRefresh)

// Use in a table component
<DataTable 
  columns={columns}
  data={devices}
  rowActions={rowActions}
/>

// Column features include:
// - Device column: Shows device icon, display name/hostname
// - Status column: Status badge with last seen timestamp
// - OS column: OS type badge (hidden on small screens)  
// - Organization column: Organization icon and name (hidden on large screens)
```

The component supports responsive design with columns that hide at different breakpoints, filterable columns for status/OS/organization, and integrates with the feature flag system for conditional rendering of organization images.
