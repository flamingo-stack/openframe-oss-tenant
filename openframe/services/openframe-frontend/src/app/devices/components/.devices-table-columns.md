Creates table column configurations for device data display, defining structure, filtering, and rendering for device information tables.

## Key Components

- **`getDeviceTableRowActions`** - Returns a render function for device action dropdown menus in table rows
- **`OrganizationCell`** - React component that renders organization information with optional icon and name
- **`getDeviceTableColumns`** - Main function that returns complete table column configuration array for device tables

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'

// Get column configuration with filtering options
const columns = getDeviceTableColumns(deviceFilters)

// Get row actions renderer with refresh callback
const rowActions = getDeviceTableRowActions(() => {
  console.log('Refreshing device data...')
})

// Use in table component
<DataTable 
  columns={columns}
  data={devices}
  rowActions={rowActions}
/>
```

The columns include device info with icons, status tags with timestamps, OS type badges, and organization details. Each column supports responsive design with breakpoint-specific visibility and filtering capabilities for status, OS type, and organization.
