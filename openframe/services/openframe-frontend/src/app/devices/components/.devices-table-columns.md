Table column configuration for the device management interface, defining how device data is displayed and filtered in the devices table.

## Key Components

- **`getDeviceTableRowActions`** - Factory function that returns a row actions renderer for the dropdown menu
- **`OrganizationCell`** - Renders organization information with optional logo/icon
- **`getDeviceTableColumns`** - Main function that returns the complete table column configuration with filtering options

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'

// Get table columns with filtering options
const columns = getDeviceTableColumns(deviceFilters)

// Get row actions with refresh callback
const rowActions = getDeviceTableRowActions(() => {
  // Refresh the table data
  refetchDevices()
})

// Use with table component
<DataTable
  columns={columns}
  data={devices}
  rowActions={rowActions}
/>
```

The column configuration includes:
- **Device**: Shows device icon and display name/hostname
- **Status**: Displays status badge with last seen timestamp, filterable with special handling for archived devices
- **OS**: Shows OS type badge, hidden on small screens, filterable by OS type
- **Organization**: Displays organization name with optional logo, hidden on large screens, filterable with deduplication

Each column supports responsive sizing, conditional visibility, and filtering capabilities through the OpenFrame table system.
