Defines table column configuration for the devices data table with custom rendering components and filtering capabilities.

## Key Components

- **`getDeviceTableRowActions()`** - Returns a render function for device action dropdown menus in table rows
- **`getDeviceTableColumns()`** - Main function that generates the complete table column configuration
- **`OrganizationCell`** - Custom cell component for rendering organization information with optional images
- **Column Definitions** - Four main columns: Device, Status, OS, and Organization with responsive behavior

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'

// Configure table columns with filtering
const tableColumns = getDeviceTableColumns(deviceFilters)

// Set up row actions with refresh callback
const rowActions = getDeviceTableRowActions(() => {
  // Refresh table data after actions
  refetchDevices()
})

// Use with a data table component
<DataTable
  columns={tableColumns}
  data={devices}
  rowActions={rowActions}
/>
```

The configuration includes responsive column widths, custom cell renderers for device icons and status badges, filterable columns with dropdown options, and integration with feature flags for conditional display elements. Status filtering excludes deleted devices and separates archived devices, while organization filtering supports deduplication of options.
