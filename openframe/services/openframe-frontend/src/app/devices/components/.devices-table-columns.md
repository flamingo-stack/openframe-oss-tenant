A React component that defines table column configurations for the device management interface in OpenFrame, handling device display, status, OS type, and organization information with filtering capabilities.

## Key Components

- **`getDeviceTableColumns()`** - Main function that returns an array of `TableColumn<Device>` configurations for the devices table
- **`getDeviceTableRowActions()`** - Factory function that creates a row actions renderer for the three-dots menu
- **`OrganizationCell`** - React component for rendering organization information with optional icons
- **Column Configurations** - Defines four main columns: Device, Status, OS, and Organization with their respective rendering and filtering logic

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'

// Basic usage with device table
const DeviceTable = ({ devices, deviceFilters, onRefresh }) => {
  const columns = getDeviceTableColumns(deviceFilters)
  const rowActions = getDeviceTableRowActions(onRefresh)

  return (
    <Table
      data={devices}
      columns={columns}
      rowActions={rowActions}
    />
  )
}

// Column configuration includes:
// - Device: Shows device icon and display name/hostname
// - Status: Status badge with last seen timestamp
// - OS: Operating system type badge
// - Organization: Organization name with optional logo
```

The columns support responsive design with different visibility breakpoints, filterable options for status/OS/organization, and integrate with feature flags for conditional rendering of organization images.
