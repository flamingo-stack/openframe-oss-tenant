Table column configuration factory for device management interfaces. Generates standardized column definitions with custom cell renderers, filtering options, and responsive display logic for device tables in the OpenFrame platform.

## Key Components

### Functions
- **`getDeviceTableRowActions(onRefresh?)`** - Creates device action dropdown renderer for table rows
- **`getDeviceTableColumns(deviceFilters?)`** - Generates complete table column configuration array

### Components
- **`OrganizationCell`** - Custom cell renderer for organization display with optional image icons
- **`DeviceRowActions`** - Action dropdown component wrapper for table context

### Column Definitions
- **Device column** - Shows device icon, display name/hostname with responsive layout
- **Status column** - Status badge with last seen timestamp and filterable options
- **OS column** - Operating system badge with filtering capabilities
- **Organization column** - Organization name with optional icon, responsive hidden on mobile

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'
import { DataTable } from '@flamingo-stack/openframe-frontend-core/components/ui'

function DeviceManagementTable({ devices, deviceFilters, onRefresh }) {
  const columns = getDeviceTableColumns(deviceFilters)
  const rowActions = getDeviceTableRowActions(onRefresh)
  
  return (
    <DataTable
      data={devices}
      columns={columns}
      rowActions={rowActions}
      filterable
      responsive
    />
  )
}
```

The column configuration includes filtering logic that separates normal statuses from archived items and completely hides deleted devices. Each column supports responsive behavior with breakpoint-based visibility controls.
