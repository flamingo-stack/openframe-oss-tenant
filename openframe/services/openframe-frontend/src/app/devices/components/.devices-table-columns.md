Defines table column configurations for the devices data table with custom cell renderers and filtering capabilities.

## Key Components

- **`getDeviceTableRowActions`** - Returns a render function for device action dropdown menus in table rows
- **`OrganizationCell`** - React component that renders organization information with optional icon
- **`getDeviceTableColumns`** - Main export that returns array of table column configurations with filtering and responsive behavior

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'

// Configure table columns with filters
const columns = getDeviceTableColumns(deviceFilters)

// Add row actions for device operations
const rowActions = getDeviceTableRowActions(() => {
  // Refresh callback after actions
  refetchDevices()
})

// Use with table component
<DataTable
  columns={columns}
  data={devices}
  rowActions={rowActions}
/>
```

The column definitions include:
- **Device**: Shows device icon and name with responsive layout
- **Status**: Displays status badge and last seen timestamp with filterable options
- **OS**: OS type badge with filtering (hidden on small screens)
- **Organization**: Organization name with icon support (hidden on large screens)

Each column supports filtering based on available device data and includes responsive visibility controls for different screen sizes.
