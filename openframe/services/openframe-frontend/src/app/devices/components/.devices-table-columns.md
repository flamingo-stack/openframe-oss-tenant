Configuration module for device table column definitions with React components and filtering capabilities.

## Key Components

- **`getDeviceTableRowActions()`** - Returns a render function for the device actions dropdown in table rows
- **`getDeviceTableColumns()`** - Main export that returns complete table column configuration array
- **`OrganizationCell`** - Internal React component for rendering organization information with optional logos
- **Column definitions** - Device name/type, status with timestamps, OS badges, and organization details

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'

// Basic usage with column definitions
const columns = getDeviceTableColumns(deviceFilters)

// With row actions for refresh functionality
const rowActions = getDeviceTableRowActions(() => {
  // Refresh callback logic
  refetchDevices()
})

// Using in a table component
<DataTable
  columns={columns}
  data={devices}
  rowActions={rowActions}
  filterable={true}
/>
```

The module provides responsive column configurations with built-in filtering, status visualization, and device type icons. Each column includes width specifications, visibility breakpoints, and custom render functions for complex data display including organization images, OS type badges, and formatted timestamps.
