Defines the table column configuration for the devices table in OpenFrame, providing standardized column definitions, cell renderers, and filtering options for device data display.

## Key Components

- `getDeviceTableColumns()` - Main function that returns an array of table column configurations
- `getDeviceTableRowActions()` - Factory function for device action dropdown components
- `OrganizationCell` - React component for rendering organization information with optional images
- Column definitions for device name, status, OS, and organization with responsive design

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'

// Configure table columns with optional filters
const columns = getDeviceTableColumns(deviceFilters)

// Set up row actions with refresh callback
const rowActions = getDeviceTableRowActions(() => {
  console.log('Device action completed, refreshing...')
})

// Use in table component
<Table
  columns={columns}
  data={devices}
  rowActions={rowActions}
/>
```

The configuration includes filterable columns for status (with special handling for archived devices), OS types, and organizations. Each column has responsive width settings and custom cell renderers for rich data display including device icons, status badges, and organization branding.
