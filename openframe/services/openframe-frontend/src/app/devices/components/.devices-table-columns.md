Table column definitions for device management interface. Provides column configurations, cell renderers, and filtering options for displaying device data in a tabular format.

## Key Components

- **`getDeviceTableRowActions()`** - Returns render function for device action dropdown menus in table rows
- **`OrganizationCell`** - React component that renders organization information with optional icon
- **`getDeviceTableColumns()`** - Main function that returns complete table column configuration array
- **Column definitions** - Device name, status, OS type, and organization columns with responsive layouts

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'
import { DataTable } from '@flamingo-stack/openframe-frontend-core/components/ui'

// Configure table with device data
const DevicesTable = ({ devices, deviceFilters, onRefresh }) => {
  const columns = getDeviceTableColumns(deviceFilters)
  const rowActions = getDeviceTableRowActions(onRefresh)

  return (
    <DataTable
      data={devices}
      columns={columns}
      rowActions={rowActions}
    />
  )
}
```

The configuration includes responsive column widths, filterable columns with dropdown options, custom cell renderers for device icons and status badges, and integration with feature flags for conditional display elements. Each column handles specific device properties like status colors, OS badges, and organization branding.
