This file defines the table column configuration and rendering logic for the device management table in the OpenFrame dashboard. It configures how device data is displayed, filtered, and what actions are available.

## Key Components

- **`getDeviceTableRowActions`** - Returns a render function for the device actions dropdown (three dots menu)
- **`OrganizationCell`** - Component that renders organization information with optional logo/icon
- **`getDeviceTableColumns`** - Main function that returns the complete column configuration for the devices table

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'

// Get table columns with filter options
const columns = getDeviceTableColumns(deviceFilters)

// Get row actions renderer with refresh callback
const rowActions = getDeviceTableRowActions(() => {
  console.log('Refreshing devices...')
})

// Use in table component
<DataTable 
  columns={columns}
  data={devices}
  rowActions={rowActions}
/>
```

The table includes four main columns: Device (with icon and name), Status (with last seen timestamp), OS (with badge), and Organization (with optional logo). Each column supports filtering based on available device data, with the status column showing a special separator for archived devices while completely hiding deleted ones.
