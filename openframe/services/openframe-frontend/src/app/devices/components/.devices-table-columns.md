A TypeScript module that defines the table column configuration for the device management interface, providing reusable column definitions with custom renderers, filters, and responsive behavior.

## Key Components

- **`getDeviceTableColumns`** - Main function returning an array of `TableColumn<Device>` configurations with filterable columns for device, status, OS, and organization
- **`getDeviceTableRowActions`** - Returns a render function for the device actions dropdown menu in table rows
- **`OrganizationCell`** - React component for rendering organization information with optional logo display
- **Column definitions** include device info with type icons, status badges with timestamps, OS type badges, and organization details with responsive visibility

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'

// Configure table columns with filter data
const columns = getDeviceTableColumns({
  statuses: [
    { value: 'ONLINE', label: 'Online' },
    { value: 'OFFLINE', label: 'Offline' }
  ],
  osTypes: [
    { value: 'Windows', label: 'Windows' },
    { value: 'macOS', label: 'macOS' }
  ],
  organizationIds: [
    { value: 'org1', label: 'Acme Corp' }
  ]
})

// Get row actions renderer
const rowActions = getDeviceTableRowActions(() => {
  console.log('Refreshing table after action')
})

// Use in DataTable component
<DataTable 
  columns={columns}
  rowActions={rowActions}
  data={devices}
/>
```

The module integrates with the OpenFrame design system and includes responsive breakpoints, feature flag support for organization images, and proper status filtering that hides deleted devices while separating archived ones.
