A table column configuration module for device management interfaces that defines the structure and rendering logic for device data tables with filtering capabilities.

## Key Components

- **`getDeviceTableRowActions`** - Factory function that returns a row actions renderer with device dropdown menu
- **`OrganizationCell`** - Custom cell component for displaying organization information with optional icons
- **`getDeviceTableColumns`** - Main function that returns the complete table column configuration array
- **Column definitions** - Device, Status, OS, and Organization columns with custom rendering and filtering

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'

// Configure table columns with device filters
const columns = getDeviceTableColumns({
  statuses: [
    { value: 'ONLINE', label: 'Online' },
    { value: 'OFFLINE', label: 'Offline' }
  ],
  osTypes: [
    { value: 'Windows', label: 'Windows' },
    { value: 'macOS', label: 'macOS' }
  ],
  organizationIds: [
    { value: 'org1', label: 'Acme Corp' }
  ]
})

// Get row actions handler
const rowActions = getDeviceTableRowActions(() => {
  console.log('Refreshing table...')
})

// Use with table component
<DataTable 
  columns={columns}
  data={devices}
  rowActions={rowActions}
/>
```

The module handles responsive design, status filtering (excluding ARCHIVED/DELETED by default), and integrates with OpenFrame's component system for consistent UI styling.
