Defines the table column configuration and cell renderers for device data display in the OpenFrame MSP platform.

## Key Components

**Functions:**
- `getDeviceTableRowActions(onRefresh?)` - Returns React component for device row action dropdown menu
- `getDeviceTableColumns(deviceFilters?)` - Main function that returns table column definitions for device listing

**Components:**
- `OrganizationCell` - Custom cell renderer for organization information with optional logo display

**Column Definitions:**
- **Device** - Shows device icon, display name/hostname with responsive layout
- **Status** - Displays status tag with last seen timestamp, includes filtering with archived status separation
- **OS** - Operating system badge with filterable options, hidden on small screens
- **Organization** - Organization name with optional icon, hidden on large screens, filterable by organization

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'

// Basic usage with table component
const columns = getDeviceTableColumns()
const rowActions = getDeviceTableRowActions(() => refetchDevices())

<DataTable
  columns={columns}
  data={devices}
  renderRowActions={rowActions}
/>

// With filter options
const columns = getDeviceTableColumns({
  statuses: [
    { value: 'ONLINE', label: 'Online' },
    { value: 'OFFLINE', label: 'Offline' }
  ],
  osTypes: [
    { value: 'Windows', label: 'Windows' },
    { value: 'macOS', label: 'macOS' }
  ],
  organizationIds: [
    { value: 'org1', label: 'Acme Corp' }
  ]
})
```

The configuration handles responsive design with `hideAt` breakpoints, filter options for status/OS/organization, and integrates with OpenFrame's design system components like `StatusTag` and `OSTypeBadge`.
