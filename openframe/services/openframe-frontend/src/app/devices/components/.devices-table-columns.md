Configuration module that defines table column structure and rendering for device management tables in the Flamingo Stack OpenFrame platform. It provides column definitions, custom cell renderers, and filter options for displaying device inventory data.

## Key Components

- **`getDeviceTableColumns()`** - Main function that returns an array of table column configurations with filtering and rendering logic
- **`getDeviceTableRowActions()`** - Factory function that creates a row actions renderer with dropdown menu functionality
- **`OrganizationCell`** - React component for rendering organization information with optional icons

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'
import { DataTable } from '@flamingo-stack/openframe-frontend-core/components/ui'

function DevicesPage({ devices, deviceFilters, onRefresh }: DevicesPageProps) {
  const columns = getDeviceTableColumns(deviceFilters)
  const rowActions = getDeviceTableRowActions(onRefresh)

  return (
    <DataTable
      data={devices}
      columns={columns}
      rowActions={rowActions}
      filterable
      searchable
    />
  )
}
```

The module includes four main columns: device info with icons, status with timestamps, OS type badges, and organization details. Status filtering excludes archived/deleted items by default, while the organization column conditionally displays icons based on feature flags.
