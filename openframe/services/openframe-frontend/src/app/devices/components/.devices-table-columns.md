Defines table column configuration for device management tables in the OpenFrame platform, including filtering, rendering, and responsive behavior for device data display.

## Key Components

- **`getDeviceTableRowActions`** - Returns a render function for device action dropdown menus in table rows
- **`OrganizationCell`** - Component that renders organization information with optional logo display
- **`getDeviceTableColumns`** - Main function that returns complete column configuration for device tables
- **Column Definitions** - Four main columns: Device, Status, OS, and Organization with different widths and responsive breakpoints

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'
import { type Device } from '../types/device.types'

// Set up table columns with filtering data
const columns = getDeviceTableColumns(deviceFilters)

// Configure row actions with refresh callback
const rowActions = getDeviceTableRowActions(() => {
  // Refresh table data after actions
  refetchDevices()
})

// Use in a table component
<DataTable<Device>
  columns={columns}
  data={devices}
  renderRowActions={rowActions}
  filterable
  responsive
/>
```

The columns support filtering (status, OS, organization), responsive hiding at different breakpoints, and custom cell rendering with device icons, status badges, and organization logos. Status filtering includes special handling for archived devices shown below a separator.
