Defines column configurations and rendering logic for the devices data table, providing structured layouts for device information, status indicators, and filterable organization data.

## Key Components

- **`getDeviceTableRowActions()`** - Returns a render function for device row action dropdowns with refresh callback support
- **`OrganizationCell`** - React component that renders organization information with optional images and proper text styling
- **`getDeviceTableColumns()`** - Main function that returns an array of table column configurations with filtering, responsive behavior, and custom cell renderers

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'

// Configure table columns with device filters
const columns = getDeviceTableColumns(deviceFilters)

// Set up row actions with refresh callback
const rowActions = getDeviceTableRowActions(() => {
  // Refresh table data after actions
  refetchDevices()
})

// Use in table component
<DataTable
  columns={columns}
  data={devices}
  rowActions={rowActions}
/>
```

The columns include responsive widths, status filtering with separated archived items, OS type badges, and organization cells with conditional image display based on feature flags.
