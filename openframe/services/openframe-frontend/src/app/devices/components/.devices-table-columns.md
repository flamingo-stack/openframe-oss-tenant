Configuration module for device table column definitions in the OpenFrame platform, handling device display, status management, and filtering capabilities.

## Key Components

- **`getDeviceTableRowActions`** - Factory function that returns a render function for device action dropdowns in table rows
- **`getDeviceTableColumns`** - Main function that returns complete table column definitions for device tables
- **`OrganizationCell`** - React component for rendering organization information with optional icons
- **Column Configuration** - Defines device, status, OS type, and organization columns with filtering and responsive behavior

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'

// Configure table columns with filtering options
const columns = getDeviceTableColumns({
  statuses: [
    { value: 'ONLINE', label: 'Online' },
    { value: 'OFFLINE', label: 'Offline' }
  ],
  osTypes: [
    { value: 'Windows', label: 'Windows' },
    { value: 'Linux', label: 'Linux' }
  ],
  organizationIds: [
    { value: 'org1', label: 'Company A' }
  ]
})

// Create action renderer for table rows
const rowActions = getDeviceTableRowActions(() => {
  console.log('Device action completed, refreshing...')
})

// Use with table component
<DataTable
  columns={columns}
  data={devices}
  rowActions={rowActions}
/>
```

The module provides responsive column definitions with built-in filtering, status visualization, and device type icons. Status filtering automatically separates archived devices and hides deleted ones. Organization columns conditionally display icons based on feature flags.
