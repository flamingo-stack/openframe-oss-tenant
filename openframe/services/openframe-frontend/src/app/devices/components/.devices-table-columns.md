Defines the column configuration and cell renderers for the devices data table, providing structured display of device information with filtering capabilities.

## Key Components

- **`getDeviceTableRowActions`** - Returns a render function for the device actions dropdown in table rows
- **`getDeviceTableColumns`** - Main function that returns an array of column configurations for the devices table
- **`OrganizationCell`** - Component that renders organization information with optional logo display
- **Column configurations** - Device, Status, OS, and Organization columns with custom rendering and filtering

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'

// Configure table columns with filtering options
const columns = getDeviceTableColumns({
  statuses: [
    { value: 'ONLINE', label: 'Online' },
    { value: 'OFFLINE', label: 'Offline' }
  ],
  osTypes: [
    { value: 'Windows', label: 'Windows' },
    { value: 'macOS', label: 'macOS' }
  ],
  organizationIds: [
    { value: 'org1', label: 'Acme Corp' }
  ]
})

// Get row actions renderer
const rowActions = getDeviceTableRowActions(() => {
  // Refresh callback after action completion
  refetchDevices()
})

// Use in table component
<Table 
  columns={columns}
  data={devices}
  rowActions={rowActions}
/>
```

The columns include device information with icons, status tags with timestamps, OS badges, and organization details. Status filtering excludes archived/deleted devices by default, while organization filtering includes deduplication logic.
