Defines column configurations and renderers for a device management table with advanced filtering and custom cell components.

## Key Components

- **`getDeviceTableRowActions`** - Returns a render function for device action dropdown menus
- **`OrganizationCell`** - Custom cell component displaying organization info with optional image
- **`getDeviceTableColumns`** - Main function that returns complete table column configuration array
- **Column renderers** - Custom cell renderers for device info, status, OS type, and organization

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'

// Get table columns with filter options
const columns = getDeviceTableColumns(deviceFilters)

// Get row actions renderer with refresh callback
const rowActions = getDeviceTableRowActions(() => {
  // Refresh table data
  refetchDevices()
})

// Use with table component
<DataTable
  columns={columns}
  data={devices}
  rowActions={rowActions}
/>
```

The column configuration includes:
- **Device column** - Shows device icon and name
- **Status column** - Filterable status tags with last seen timestamp  
- **OS column** - OS type badges with filtering
- **Organization column** - Organization info with images (feature-flagged)

Each column supports responsive width classes, filtering options, and custom cell renderers for rich data display.
