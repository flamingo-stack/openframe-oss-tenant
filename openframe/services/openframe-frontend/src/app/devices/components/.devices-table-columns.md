Defines table column configurations and rendering functions for the devices table component in OpenFrame. This module provides structured column definitions including device information, status, operating system, and organization details with filtering capabilities.

## Key Components

- **`getDeviceTableRowActions`** - Returns a render function for device action dropdowns in table rows
- **`getDeviceTableColumns`** - Main function that returns an array of table column configurations with filtering and rendering logic
- **`OrganizationCell`** - React component for rendering organization information with optional images

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'

// Configure table columns with filtering
const columns = getDeviceTableColumns(deviceFilters)

// Set up row actions with refresh callback
const rowActions = getDeviceTableRowActions(() => {
  console.log('Device action completed, refreshing table...')
})

// Use in table component
const tableConfig = {
  columns,
  rowActions,
  data: devices
}
```

The columns support responsive design with `hideAt` breakpoints, filterable options for status/OS/organization, and custom cell renderers that display device icons, status badges, and organization information with proper styling according to OpenFrame design system.
