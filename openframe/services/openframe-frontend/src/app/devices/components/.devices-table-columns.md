Column configuration factory for device data tables with filtering and responsive display capabilities.

## Key Components

- **`getDeviceTableColumns()`** - Main factory function that returns column configuration array for device tables
- **`getDeviceTableRowActions()`** - Returns render function for device action dropdown menu
- **`OrganizationCell`** - Custom cell component for organization column with optional image display
- **Column definitions** - Device name, status, OS, and organization columns with filtering support

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'

// Basic usage with device filters
const columns = getDeviceTableColumns(deviceFilters)

// With row actions for refresh functionality
const rowActions = getDeviceTableRowActions(() => {
  // Refresh callback
  refetchDevices()
})

// Use in table component
<DataTable
  columns={columns}
  data={devices}
  rowActions={rowActions}
/>
```

The columns provide responsive breakpoints, filtering capabilities, and status-aware rendering. The status column includes special handling for archived devices and excludes deleted ones from filter options. Organization column conditionally displays images based on feature flags.
