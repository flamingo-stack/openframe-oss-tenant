Configuration module that defines the table structure and column definitions for device data display in the OpenFrame platform.

## Key Components

- **`getDeviceTableColumns(deviceFilters?)`** - Main export that returns an array of table column configurations including device info, status, OS, and organization columns
- **`getDeviceTableRowActions(onRefresh?)`** - Returns a render function for device row actions (dropdown menu)
- **`OrganizationCell`** - React component that renders organization information with optional icon and name

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'

// Configure table columns with filter options
const columns = getDeviceTableColumns({
  statuses: [
    { value: 'ONLINE', label: 'Online' },
    { value: 'OFFLINE', label: 'Offline' }
  ],
  osTypes: [
    { value: 'Windows', label: 'Windows' },
    { value: 'macOS', label: 'macOS' }
  ],
  organizationIds: [
    { value: 'org1', label: 'Acme Corp' }
  ]
})

// Set up row actions with refresh callback
const rowActions = getDeviceTableRowActions(() => {
  // Refresh table data after action
  refetchDevices()
})

// Use in table component
<Table 
  columns={columns}
  rowActions={rowActions}
  data={devices}
/>
```

The module handles responsive design with `hideAt` breakpoints, filterable columns with custom options, and integrates with OpenFrame's design system components for consistent styling.
