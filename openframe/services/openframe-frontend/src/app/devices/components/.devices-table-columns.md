Configuration module that defines table column structure and rendering logic for device management interfaces in the OpenFrame platform.

## Key Components

- **`getDeviceTableColumns()`** - Main function that returns table column configuration array with device, status, OS, and organization columns
- **`getDeviceTableRowActions()`** - Returns a render function for device action dropdown menus in table rows
- **`OrganizationCell`** - React component for rendering organization information with optional image icons
- **Column definitions** - Structured configuration for device table display including filtering, responsive behavior, and custom cell renderers

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'
import { Device } from '../types/device.types'

// Configure table columns with filtering options
const columns = getDeviceTableColumns(deviceFilters)

// Set up row actions with refresh callback
const rowActions = getDeviceTableRowActions(() => {
  console.log('Refreshing device data...')
})

// Use in a table component
const DeviceTable = ({ devices }: { devices: Device[] }) => (
  <Table
    data={devices}
    columns={columns}
    rowActions={rowActions}
  />
)
```

The module provides responsive column definitions with built-in filtering capabilities, status badges, OS type indicators, and organization branding. Each column includes proper width constraints and mobile-responsive hiding behavior for optimal display across different screen sizes.
