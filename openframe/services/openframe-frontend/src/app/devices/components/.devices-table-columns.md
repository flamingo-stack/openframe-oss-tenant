Defines table column configurations and rendering logic for device data tables in the OpenFrame platform, handling device display, status, OS, and organization information with filtering capabilities.

## Key Components

- **`getDeviceTableRowActions()`** - Returns a render function for device action dropdown menus in table rows
- **`getDeviceTableColumns()`** - Main function that returns an array of table column configurations with filtering and responsive behavior
- **`OrganizationCell`** - Internal component for rendering organization information with optional icons
- **Column definitions** for device name, status, OS type, and organization with custom rendering logic

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'

// Configure table columns with filtering
const columns = getDeviceTableColumns(deviceFilters)

// Set up row actions with refresh callback
const rowActions = getDeviceTableRowActions(() => {
  console.log('Device action completed, refreshing table')
})

// Use in a table component
<DataTable
  columns={columns}
  data={devices}
  rowActions={rowActions}
/>
```

The columns include responsive width classes, filterable options based on device data, and custom cell renderers that display device icons, status badges, OS badges, and organization information. Status filtering excludes deleted devices and separates archived devices with a divider.
