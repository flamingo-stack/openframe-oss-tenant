Configures table columns and rendering logic for device data display in OpenFrame's device management interface.

## Key Components

- **`getDeviceTableRowActions()`** - Returns a render function for device action dropdown menus
- **`OrganizationCell`** - React component that renders organization info with optional icons
- **`getDeviceTableColumns()`** - Main function that defines table column configuration with filtering and responsive behavior

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'

// Configure table columns with filter data
const columns = getDeviceTableColumns(deviceFilters)

// Set up row actions with refresh callback
const rowActions = getDeviceTableRowActions(() => {
  // Refresh table data
  refetchDevices()
})

// Use in table component
<DataTable
  columns={columns}
  data={devices}
  rowActions={rowActions}
/>
```

The configuration includes:
- **Device column**: Shows device type icon and name/hostname
- **Status column**: Displays status tags with last seen timestamps, includes special handling for archived devices
- **OS column**: Shows OS type badges with filtering support
- **Organization column**: Displays organization name with optional icons

All columns support responsive design with configurable visibility breakpoints and filtering capabilities based on the provided `deviceFilters` data.
