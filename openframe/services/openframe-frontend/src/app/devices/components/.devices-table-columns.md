Table column configuration and cell renderers for the devices data table interface.

## Key Components

- `getDeviceTableColumns()` - Main function that returns table column definitions with filters and custom renderers
- `getDeviceTableRowActions()` - Returns a dropdown actions component for table rows
- `OrganizationCell` - React component that renders organization information with optional image icon
- Column definitions for device name, status, OS type, and organization with responsive layouts

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'
import { type Device } from '../types/device.types'

// Configure table columns with optional filters
const columns = getDeviceTableColumns(deviceFilters)

// Set up row actions with refresh callback
const rowActions = getDeviceTableRowActions(() => {
  // Refresh table data after action
  refetchDevices()
})

// Use with table component
<Table<Device>
  columns={columns}
  data={devices}
  renderRowActions={rowActions}
/>
```

The module provides a responsive table configuration with filterable columns, custom cell renderers for device icons and status badges, and integrated action dropdowns. Status filtering includes special handling for archived devices and excludes deleted items from the normal filter list.
