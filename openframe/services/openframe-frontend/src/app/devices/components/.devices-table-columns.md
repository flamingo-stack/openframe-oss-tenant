Defines table column configurations for device data tables with custom cell renderers and filtering options.

## Key Components

**Main Exports:**
- `getDeviceTableColumns()` - Returns array of TableColumn configurations for device tables
- `getDeviceTableRowActions()` - Creates render function for device row action dropdown menus

**Helper Components:**
- `OrganizationCell` - Renders organization name with optional logo/icon display

## Column Definitions

The table includes these filterable columns:

- **Device** - Shows device icon and display name/hostname
- **Status** - Device status with last seen timestamp, includes special handling for archived devices
- **OS** - Operating system type with badge display (hidden on small screens)
- **Organization** - Organization info with logo (hidden on large screens)

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'

// Basic table setup
const columns = getDeviceTableColumns(deviceFilters)

// With row actions for device management
const rowActions = getDeviceTableRowActions(handleRefresh)

// Use in data table component
<DataTable
  columns={columns}
  data={devices}
  rowActions={rowActions}
/>
```

The columns automatically handle responsive visibility, filtering options, and custom cell rendering for device-specific data like status badges and organization icons.
