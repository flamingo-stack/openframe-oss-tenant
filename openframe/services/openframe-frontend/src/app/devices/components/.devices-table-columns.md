Configuration functions for defining table columns and row actions in the devices data table, including filtering, sorting, and custom cell renderers.

## Key Components

- **`getDeviceTableColumns()`** - Returns array of table column definitions with filtering and custom renderers
- **`getDeviceTableRowActions()`** - Creates the actions dropdown component for table rows  
- **`OrganizationCell`** - Custom cell component for displaying organization info with optional icons

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'
import { Device } from '../types/device.types'

// Configure table columns with filtering options
const columns = getDeviceTableColumns({
  statuses: [
    { value: 'ONLINE', label: 'Online' },
    { value: 'OFFLINE', label: 'Offline' }
  ],
  osTypes: [
    { value: 'Windows', label: 'Windows' },
    { value: 'macOS', label: 'macOS' }
  ],
  organizationIds: [
    { value: 'org1', label: 'Acme Corp' }
  ]
})

// Set up row actions with refresh callback
const rowActions = getDeviceTableRowActions(() => {
  console.log('Device action completed, refreshing...')
})

// Use in table component
const tableProps = {
  columns,
  data: devices,
  rowActions
}
```

The module defines four main columns: device info with icon, status with last seen timestamp, OS type badge, and organization details. Status filtering excludes archived/deleted devices by default, while organization filtering uses deduplication for clean options.
