Table column configuration for device management interfaces with filtering capabilities and responsive design. Provides column definitions for displaying device information including device details, status, OS, and organization with corresponding render functions and filter options.

## Key Components

- **`getDeviceTableColumns`** - Main function that returns column configuration array for device tables
- **`getDeviceTableRowActions`** - Factory function that returns a render component for device action dropdowns
- **`OrganizationCell`** - React component for rendering organization information with optional icons
- **Column definitions** - Device, status, OS, and organization columns with filtering and responsive behavior

## Usage Example

```typescript
import { getDeviceTableColumns, getDeviceTableRowActions } from './devices-table-columns'

// Configure table columns with filters
const columns = getDeviceTableColumns(deviceFilters)

// Add row actions
const rowActions = getDeviceTableRowActions(() => {
  // Refresh callback
  refetchDevices()
})

// Use in table component
<DataTable
  columns={columns}
  data={devices}
  rowActions={rowActions}
/>
```

The columns support responsive breakpoints (`hideAt` property), filtering with custom options, and status-based rendering with specialized components like `OSTypeBadge` and `StatusTag`. Status filtering includes special handling for archived devices with separators.
