A React dropdown component that provides device management actions with context-aware menu items and confirmation dialogs for destructive operations.

## Key Components

- **DeviceActionsDropdown**: Main component that renders a dropdown menu with device actions
- **ActionAvailability**: Computed availability of actions based on device state and capabilities
- **MenuGroups**: Dynamic menu structure that adapts to table vs detail page context
- **ConfirmationDialogs**: Modal dialogs for archive, delete, and uninstall operations
- **ActionHandlers**: Methods for remote control, shell access, script execution, and device management

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'

function DeviceTable() {
  return (
    <DeviceActionsDropdown
      device={device}
      context="table"
      onActionComplete={() => refetchDevices()}
      onRemoteControl={() => openRemoteControlModal()}
      onRunScript={() => openScriptModal()}
      onRemoteShell={(type) => openShellModal(type)}
    />
  )
}

// Detail page usage
function DeviceDetailPage() {
  return (
    <DeviceActionsDropdown
      device={device}
      context="detail"
      onActionComplete={() => router.push('/devices')}
    />
  )
}
```

The component automatically determines available actions based on device capabilities (MeshCentral agent, online status) and renders different menu items depending on the context. Table context includes remote actions in the dropdown, while detail context assumes these are separate buttons.
