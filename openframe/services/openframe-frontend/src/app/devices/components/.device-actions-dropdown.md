A React component that provides a dropdown menu with device management actions like remote control, script execution, archiving, and deletion.

## Key Components

- **DeviceActionsDropdown** - Main dropdown component with context-aware action buttons
- **Action Handlers** - Methods for remote control, shell access, script execution, and device management
- **Confirmation Dialogs** - Archive and delete confirmation modals with proper styling
- **Uninstall Dialog** - Modal showing platform-specific uninstall commands
- **Menu Groups** - Dynamically generated action groups based on device capabilities and context

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'
import type { Device } from '../types/device.types'

function DeviceTable() {
  const device: Device = {
    id: 'device-123',
    machineId: 'machine-456',
    displayName: 'Office Computer',
    platform: 'Windows',
    status: 'online'
  }

  return (
    <DeviceActionsDropdown
      device={device}
      context="table"
      onActionComplete={() => {
        // Refresh device list after action
        refetchDevices()
      }}
      onRemoteControl={() => {
        // Custom remote control handler
        openRemoteDesktop(device.id)
      }}
      onRunScript={() => {
        // Custom script execution handler
        setScriptModalOpen(true)
      }}
      onRemoteShell={(type) => {
        // Custom shell handler
        openShell(device.id, type)
      }}
    />
  )
}
```

The component adapts its menu items based on the `context` prop - showing all actions in table view, while excluding remote actions that have dedicated buttons in detail view. It handles device archiving, deletion, and uninstallation with appropriate confirmation dialogs and integrates with the OpenFrame navigation system.
