A React dropdown component that provides contextual device actions in OpenFrame's device management interface.

## Key Components

**Main Export:**
- `DeviceActionsDropdown` - Dropdown menu component with device-specific actions

**Key Features:**
- Context-aware actions (table vs detail view)
- Remote control integration (MeshCentral)
- Script execution capabilities
- Device lifecycle management (archive/delete)
- Uninstall command generation
- Platform-specific shell options

**Props Interface:**
- `device` - Device object with platform/OS information
- `context` - Display context ('table' | 'detail')
- `onActionComplete` - Callback for action completion
- Optional action handlers for custom integration

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'
import type { Device } from '../types/device.types'

function DeviceTable() {
  const handleActionComplete = () => {
    // Refresh device list
    refetchDevices()
  }

  return (
    <table>
      {devices.map((device: Device) => (
        <tr key={device.id}>
          <td>{device.displayName}</td>
          <td>
            <DeviceActionsDropdown
              device={device}
              context="table"
              onActionComplete={handleActionComplete}
            />
          </td>
        </tr>
      ))}
    </table>
  )
}

// Custom handlers for integration
function DeviceDetail({ device }: { device: Device }) {
  const handleRemoteShell = (type: 'cmd' | 'powershell' | 'bash') => {
    openRemoteShellModal(device, type)
  }

  return (
    <DeviceActionsDropdown
      device={device}
      context="detail"
      onRemoteShell={handleRemoteShell}
      onRemoteControl={() => openRemoteDesktop(device)}
    />
  )
}
```

The component dynamically shows available actions based on device capabilities, platform detection, and MeshCentral agent availability. Actions include remote control, shell access, script execution, file management, and device lifecycle operations with proper confirmation dialogs.
