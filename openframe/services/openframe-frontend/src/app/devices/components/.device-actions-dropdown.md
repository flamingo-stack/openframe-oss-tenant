A React dropdown component that provides device management actions like remote control, shell access, file management, and device lifecycle operations (archive/delete/uninstall).

## Key Components

- **DeviceActionsDropdown** - Main component with context-aware action menu
- **Action Handlers** - Methods for remote control, shell access, file management, and device operations
- **Modal Dialogs** - Confirmation dialogs for destructive actions (archive, delete, uninstall)
- **Dynamic Menu Groups** - Context-sensitive menu items based on device capabilities and view context
- **Command Generation** - Platform-specific uninstall command generation with clipboard copy

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'

// In a device table row
<DeviceActionsDropdown
  device={device}
  context="table"
  onActionComplete={() => refreshDeviceList()}
/>

// In device detail view
<DeviceActionsDropdown
  device={device}
  context="detail"
  onRunScript={() => setShowScriptModal(true)}
  onActionComplete={() => router.push('/devices')}
/>
```

The component adapts its available actions based on device capabilities (MeshCentral agent availability, device status) and context (table vs detail view). It handles navigation routing, provides user feedback via toasts, and includes confirmation dialogs for destructive operations.
