A React component that provides a dropdown menu with device management actions like remote control, shell access, and device lifecycle operations.

## Key Components

- **DeviceActionsDropdown**: Main dropdown component with context-aware action menus
- **Action Handlers**: Functions for remote control, shell access, file management, and device lifecycle
- **Confirmation Dialogs**: Modal dialogs for destructive actions (archive, delete, uninstall)
- **Command Generation**: Builds platform-specific uninstall commands with clipboard copy functionality
- **Context Awareness**: Different action sets for table vs detail page contexts

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'
import type { Device } from '../types/device.types'

function DeviceTable({ devices }: { devices: Device[] }) {
  return (
    <div>
      {devices.map(device => (
        <div key={device.id} className="device-row">
          <span>{device.hostname}</span>
          
          <DeviceActionsDropdown
            device={device}
            context="table"
            onActionComplete={() => refetchDevices()}
            onRunScript={() => openScriptModal(device.id)}
          />
        </div>
      ))}
    </div>
  )
}

// On device detail page
function DeviceDetails({ device }: { device: Device }) {
  return (
    <div>
      <h1>{device.hostname}</h1>
      
      <DeviceActionsDropdown
        device={device}
        context="detail"
        onActionComplete={() => router.push('/devices')}
      />
    </div>
  )
}
```

The component automatically determines available actions based on device capabilities (MeshCentral agent, platform type) and shows different menu items depending on whether it's used in a table row or device detail page context.
