A React dropdown component that provides device management actions like remote control, archiving, and deletion with context-aware menu items based on device capabilities and current page context.

## Key Components

- **DeviceActionsDropdown** - Main component with dropdown menu containing device-specific actions
- **Action Handlers** - Functions for remote control, script execution, file management, and device lifecycle operations
- **Confirmation Dialogs** - Alert dialogs for destructive actions (archive/delete) with proper styling
- **Uninstall Modal** - Command display modal with copy-to-clipboard functionality for device uninstallation
- **Context-Aware Rendering** - Different menu items and behaviors for table vs detail page contexts

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'
import type { Device } from '../types/device.types'

// In a device table row
<DeviceActionsDropdown
  device={device}
  context="table"
  onActionComplete={() => refetchDevices()}
/>

// In device detail page with custom handlers
<DeviceActionsDropdown
  device={device}
  context="detail"
  onRemoteControl={() => openRemoteControlModal()}
  onRunScript={() => openScriptModal()}
  onRemoteShell={(type) => openShellModal(type)}
  onActionComplete={() => router.push('/devices')}
/>
```

The component integrates with device action utilities to determine available actions based on device capabilities, handles loading states for async operations, and provides appropriate navigation behavior depending on the context where it's used.
