This React component provides a dropdown menu for device actions in the OpenFrame platform, allowing users to perform various operations on managed devices.

## Key Components

- **DeviceActionsDropdown**: Main component that renders a dropdown menu with device-specific actions
- **Context-aware rendering**: Different action sets for table vs detail views
- **Action availability logic**: Determines which actions are enabled based on device state
- **Confirmation dialogs**: Modal confirmations for destructive actions (archive/delete)
- **Remote operations**: Handlers for remote control, shell access, and script execution
- **Uninstall command generation**: Platform-specific uninstall commands with clipboard copy

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'

// In a device table
<DeviceActionsDropdown
  device={deviceData}
  context="table"
  onActionComplete={() => refreshDeviceList()}
/>

// In device detail view with custom handlers
<DeviceActionsDropdown
  device={deviceData}
  context="detail"
  onRemoteControl={() => openRemoteDesktop()}
  onRunScript={() => openScriptModal()}
  onRemoteShell={(type) => openShellSession(type)}
/>
```

The component automatically adapts its available actions based on device capabilities (online status, MeshCentral agent availability) and provides appropriate navigation or callback execution for each action.
