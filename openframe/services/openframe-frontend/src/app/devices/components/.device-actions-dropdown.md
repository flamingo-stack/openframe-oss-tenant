A React component that provides a context-aware dropdown menu for device management actions, including remote control, scripting, and device lifecycle operations. The component adapts its interface based on whether it's displayed in a table row or device detail page context.

## Key Components

- **DeviceActionsDropdown**: Main component that renders a dropdown menu with device-specific actions
- **Action Handlers**: Methods for remote control, shell access, file management, and device lifecycle operations
- **Confirmation Dialogs**: AlertDialog components for destructive actions (archive/delete)
- **Uninstall Modal**: CommandBox integration for displaying platform-specific uninstall commands
- **Context-Aware Rendering**: Different menu items and triggers based on table vs detail context

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'
import type { Device } from '../types/device.types'

function DeviceTable() {
  const device: Device = {
    id: 'device-123',
    machineId: 'machine-456',
    displayName: 'Office Computer',
    platform: 'windows',
    status: 'online'
  }

  return (
    <DeviceActionsDropdown
      device={device}
      context="table"
      onActionComplete={() => {
        // Refresh device list after action
        refetchDevices()
      }}
      onRunScript={() => {
        // Handle script execution
        setShowScriptModal(true)
      }}
    />
  )
}

// In device detail page
function DeviceDetailPage() {
  return (
    <DeviceActionsDropdown
      device={device}
      context="detail"
      // Navigation handled internally for detail context
    />
  )
}
```

The component integrates with OpenFrame's device management system, providing unified access to remote desktop, shell sessions, file management, and device lifecycle operations with proper permission checking and platform-specific command generation.
