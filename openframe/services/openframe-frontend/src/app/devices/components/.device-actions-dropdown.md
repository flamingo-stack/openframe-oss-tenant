A React dropdown component providing contextual device management actions with support for remote control, script execution, and device lifecycle operations.

## Key Components

- **DeviceActionsDropdown**: Main component rendering a dropdown menu with device-specific actions
- **Action Handlers**: Functions for remote control, shell access, file management, archiving, and deletion
- **Confirmation Dialogs**: Archive and delete confirmation modals with proper UX patterns
- **Uninstall Command Generator**: Dynamic command generation based on device platform
- **Context-Aware Rendering**: Different action sets for table vs detail page contexts

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'

// In a device table
<DeviceActionsDropdown
  device={device}
  context="table"
  onActionComplete={() => refetchDevices()}
/>

// In a device detail page
<DeviceActionsDropdown
  device={device}
  context="detail"
  onRunScript={() => setShowScriptModal(true)}
  onActionComplete={() => router.push('/devices')}
/>
```

The component automatically determines available actions based on device capabilities (MeshCentral agent status, OS type) and renders appropriate confirmation dialogs for destructive operations. Actions include remote desktop, shell access, file management, script execution, uninstallation, archiving, and deletion.
