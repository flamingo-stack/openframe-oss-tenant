A React dropdown component that provides contextual device management actions with confirmation dialogs and shell command generation.

## Key Components

- **DeviceActionsDropdown**: Main component that renders a dropdown menu with device-specific actions
- **Action Handlers**: Functions for remote control, shell access, file management, archiving, and deletion
- **Confirmation Dialogs**: Modal dialogs for destructive actions (archive/delete) with custom styling
- **Uninstall Command Generation**: Dynamic command building based on device platform and release version
- **Context-Aware Menu**: Different action sets for table vs detail view contexts

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'

// In a device table row
<DeviceActionsDropdown
  device={deviceData}
  context="table"
  onActionComplete={() => refetchDevices()}
/>

// In device detail view
<DeviceActionsDropdown
  device={deviceData}
  context="detail"
  onRunScript={() => setShowScriptModal(true)}
  onActionComplete={() => router.push('/devices')}
/>
```

The component automatically determines available actions based on device capabilities (MeshCentral agent status, platform type) and provides appropriate visual feedback through loading states and toast notifications. Actions include remote desktop, shell access, file management, script execution, device archiving, and uninstallation with platform-specific commands.
