A React dropdown component that provides device-specific actions like remote control, scripting, and device management for the OpenFrame MSP platform.

## Key Components

- **DeviceActionsDropdown** - Main dropdown component with context-aware menu items
- **Action Handlers** - Functions for remote control, shell access, file management, and device lifecycle operations
- **Confirmation Dialogs** - AlertDialog components for archive/delete confirmations
- **Uninstall Command Generator** - Dynamic command generation with clipboard copy functionality
- **Context-Aware Rendering** - Different menu items for table vs detail view contexts

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'

// In a device table row
<DeviceActionsDropdown
  device={device}
  context="table"
  onActionComplete={() => refreshDeviceList()}
/>

// In device detail page
<DeviceActionsDropdown
  device={device}
  context="detail"
  onRunScript={() => setShowScriptModal(true)}
  onActionComplete={() => router.push('/devices')}
/>
```

The component automatically:
- Determines available actions based on device capabilities (MeshCentral agent, OS type)
- Handles navigation to remote desktop, shell, and file manager pages
- Provides archive/delete operations with confirmation dialogs
- Generates platform-specific uninstall commands
- Adapts menu items based on context (table row vs detail page)
