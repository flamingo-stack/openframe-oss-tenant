A React component that renders a contextual dropdown menu for device actions like remote control, file management, and device lifecycle operations.

## Key Components

- **DeviceActionsDropdown**: Main dropdown component with different layouts for table vs detail contexts
- **Action Handlers**: Methods for remote control, shell access, script execution, and file management
- **Device Actions**: Archive, delete, and uninstall device operations with confirmation dialogs
- **Platform Detection**: Windows-specific shell type selection (CMD/PowerShell vs Bash)
- **Command Generation**: Builds platform-specific uninstall commands with clipboard copying

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'
import type { Device } from '../types/device.types'

function DeviceTable({ devices }: { devices: Device[] }) {
  return (
    <table>
      {devices.map(device => (
        <tr key={device.id}>
          <td>{device.displayName}</td>
          <td>
            <DeviceActionsDropdown 
              device={device}
              context="table"
              onActionComplete={() => refetchDevices()}
              onRemoteControl={() => openRemoteDesktop(device)}
              onRunScript={() => openScriptModal(device)}
              onRemoteShell={(type) => openShell(device, type)}
            />
          </td>
        </tr>
      ))}
    </table>
  )
}

// In device detail page
function DeviceDetailPage({ device }: { device: Device }) {
  return (
    <div>
      <h1>{device.displayName}</h1>
      <DeviceActionsDropdown 
        device={device}
        context="detail"
      />
    </div>
  )
}
```

The component adapts its available actions based on device capabilities, platform type, and connection status. It integrates with MeshCentral for remote operations and provides unified device management across the OpenFrame platform.
