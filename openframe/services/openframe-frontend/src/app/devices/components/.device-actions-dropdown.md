A React dropdown component that provides contextual device actions (remote control, scripting, file management, archive/delete) for both table and detail views in the OpenFrame device management system.

## Key Components

### Main Export
- **`DeviceActionsDropdown`** - Primary component that renders a dropdown menu with device-specific actions

### Core Features
- **Context-aware rendering** - Different action sets for table vs detail views
- **Device capability detection** - Actions enabled/disabled based on device state and connectivity
- **Platform-specific commands** - OS-aware shell types and uninstall commands
- **Confirmation dialogs** - Archive and delete actions with user confirmation
- **Command generation** - Dynamic uninstall command building with version detection

### Action Categories
- **Remote Actions** - Shell access, remote desktop, file management
- **Script Management** - Run custom scripts on devices  
- **Device Lifecycle** - Archive, delete, and uninstall operations

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'
import type { Device } from '../types/device.types'

function DeviceTableRow({ device }: { device: Device }) {
  const handleActionComplete = () => {
    // Refresh device list after action
    refetchDevices()
  }

  return (
    <tr>
      <td>{device.hostname}</td>
      <td>
        <DeviceActionsDropdown 
          device={device}
          context="table"
          onActionComplete={handleActionComplete}
        />
      </td>
    </tr>
  )
}

// For device detail pages
function DeviceDetailActions({ device }: { device: Device }) {
  return (
    <DeviceActionsDropdown 
      device={device}
      context="detail"
      onRunScript={() => setShowScriptModal(true)}
    />
  )
}
```

The component automatically handles navigation, state management, and provides appropriate visual feedback for all device operations.
