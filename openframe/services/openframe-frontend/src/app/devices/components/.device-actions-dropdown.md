This React component provides a comprehensive dropdown menu for device management actions in the Flamingo MSP platform, offering different action sets based on context (table view vs detail view) and device capabilities.

## Key Components

**Main Component:**
- `DeviceActionsDropdown` - Dropdown menu with device-specific actions

**Key Features:**
- Context-aware action rendering (table vs detail views)
- Device capability detection for action availability
- Confirmation dialogs for destructive operations
- Shell type selection for Windows/Unix devices
- Command generation for device uninstallation

**Action Categories:**
- Remote actions (Remote Control, Remote Shell, File Manager)
- Script execution capabilities
- Device lifecycle management (Archive, Delete, Uninstall)

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'
import type { Device } from '../types/device.types'

function DeviceTable() {
  const handleActionComplete = () => {
    // Refresh device list
    refetchDevices()
  }

  return (
    <div>
      {devices.map(device => (
        <div key={device.id} className="device-row">
          <span>{device.displayName}</span>
          <DeviceActionsDropdown
            device={device}
            context="table"
            onActionComplete={handleActionComplete}
          />
        </div>
      ))}
    </div>
  )
}

// Detail page usage with custom handlers
function DeviceDetailPage({ device }: { device: Device }) {
  const [showScriptModal, setShowScriptModal] = useState(false)

  return (
    <div>
      <DeviceActionsDropdown
        device={device}
        context="detail"
        onRunScript={() => setShowScriptModal(true)}
        onRemoteShell={(type) => openRemoteShell(type)}
      />
    </div>
  )
}
```

The component automatically adapts its available actions based on device capabilities (MeshCentral agent status, platform type) and provides appropriate UI feedback for loading states and confirmations.
