A dropdown menu component that provides contextual actions for device management, including remote access, script execution, archiving, and deletion with appropriate confirmation dialogs.

## Key Components

- **DeviceActionsDropdown**: Main component that renders a dropdown menu with device-specific actions
- **Action Availability**: Determines which actions are enabled based on device capabilities and state
- **Context-Aware Rendering**: Different action sets for table vs detail page contexts
- **Confirmation Dialogs**: Archive, delete, and uninstall confirmation modals with appropriate styling
- **Platform-Specific Logic**: Windows/Unix shell type detection and command generation
- **Navigation Integration**: Handles routing to remote desktop, shell, and file management pages

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'

// In a device table row
<DeviceActionsDropdown
  device={device}
  context="table"
  onActionComplete={() => refetchDevices()}
/>

// In device details page
<DeviceActionsDropdown
  device={device}
  context="detail"
  onRunScript={() => setShowScriptModal(true)}
  onActionComplete={() => router.push('/devices')}
/>
```

The component automatically determines available actions based on device capabilities (MeshCentral agent presence, device state, etc.) and renders different menu items for table versus detail contexts. It includes proper loading states, error handling, and toast notifications for user feedback.
