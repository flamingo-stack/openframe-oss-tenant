A React component that provides a contextual dropdown menu for device management actions, supporting both table row and detail page contexts with actions like remote control, shell access, and device lifecycle management.

## Key Components

- **DeviceActionsDropdown** - Main dropdown component with configurable actions based on device capabilities
- **Action Handlers** - Methods for remote control, shell access, script execution, and device management
- **Confirmation Dialogs** - Archive and delete confirmation modals with loading states
- **Uninstall Command Modal** - Shows platform-specific uninstall commands with copy functionality
- **Context-Aware Rendering** - Different action sets for table vs detail page contexts

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'

// In a device table
<DeviceActionsDropdown
  device={device}
  context="table"
  onActionComplete={() => refetchDevices()}
/>

// On device detail page with custom handlers
<DeviceActionsDropdown
  device={device}
  context="detail"
  onRemoteControl={() => openRemoteDesktop()}
  onRunScript={() => setShowScriptModal(true)}
  onRemoteShell={(type) => openShell(type)}
  onActionComplete={() => router.push('/devices')}
/>
```

The component automatically determines available actions based on device capabilities (online status, platform, agent availability) and provides appropriate confirmation dialogs for destructive operations. Actions include remote desktop access, shell connections, script execution, file management, and device lifecycle operations (archive/delete/uninstall).
