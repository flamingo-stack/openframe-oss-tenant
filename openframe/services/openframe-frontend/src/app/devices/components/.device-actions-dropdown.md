A React component that provides a context-aware dropdown menu for device management actions including remote control, file management, archival, and deletion with confirmation dialogs.

## Key Components

- **DeviceActionsDropdown** - Main component that renders action menu based on context (table/detail view)
- **Action handlers** - Methods for remote control, shell access, script execution, and device lifecycle management
- **Confirmation dialogs** - AlertDialog components for destructive actions (archive/delete)
- **Uninstall modal** - CommandBox display for device uninstall commands
- **Platform detection** - Logic to determine appropriate shell types and commands based on device OS

## Usage Example

```typescript
// In device table row
<DeviceActionsDropdown
  device={device}
  context="table"
  onActionComplete={() => refreshDeviceList()}
/>

// In device detail page with custom handlers
<DeviceActionsDropdown
  device={device}
  context="detail"
  onRemoteControl={() => openRemoteDesktop()}
  onRunScript={() => setShowScriptModal(true)}
  onRemoteShell={(type) => openShellModal(type)}
/>

// Minimal usage
<DeviceActionsDropdown
  device={device}
  context="table"
/>
```

The component automatically determines available actions based on device capabilities (MeshCentral agent status, platform type) and renders appropriate menu items. Different contexts show different actions - table context includes all actions while detail context excludes items that have dedicated buttons elsewhere on the page.
