A dropdown menu component that provides device-specific actions like remote control, shell access, script execution, archiving, and deletion with contextual availability based on device capabilities.

## Key Components

- **DeviceActionsDropdown** - Main component with context-aware action menu
- **Device Actions** - Remote control, shell access, script execution, file management
- **Management Actions** - Archive, delete, and uninstall device operations
- **Confirmation Dialogs** - Archive and delete confirmation modals
- **Uninstall Command** - Platform-specific uninstall command generation and copying

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'

// In a device table row
<DeviceActionsDropdown
  device={device}
  context="table"
  onActionComplete={() => refetchDevices()}
/>

// In device detail page with custom handlers
<DeviceActionsDropdown
  device={device}
  context="detail"
  onRemoteControl={() => openRemoteControlModal()}
  onRunScript={() => openScriptModal()}
  onRemoteShell={(type) => openShellModal(type)}
/>
```

The component automatically determines action availability based on device capabilities (online status, MeshCentral agent, platform support) and renders appropriate menu items. Different contexts show different action sets - table context includes all actions while detail context excludes actions that have dedicated buttons elsewhere.
