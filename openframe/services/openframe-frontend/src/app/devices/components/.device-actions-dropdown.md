A React dropdown component that provides device-specific actions (remote control, shell, scripts, archive, delete) with context-aware menu items and confirmation dialogs.

## Key Components

- **DeviceActionsDropdown** - Main dropdown component with device actions menu
- **Action Handlers** - Methods for remote control, shell access, script execution, and device management
- **Confirmation Dialogs** - Modal dialogs for destructive actions (archive/delete)
- **Uninstall Command Generator** - Dynamic command building for device agent removal
- **Context-Aware Rendering** - Different menu items based on table vs detail view context

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'
import type { Device } from '../types/device.types'

// In a device table or detail view
function DeviceTable() {
  const handleActionComplete = () => {
    // Refresh device list after action
    refetchDevices()
  }

  return (
    <DeviceActionsDropdown
      device={device}
      context="table"
      onActionComplete={handleActionComplete}
      onRunScript={() => setShowScriptModal(true)}
    />
  )
}

// In device detail view
function DeviceDetail() {
  return (
    <DeviceActionsDropdown
      device={device}
      context="detail"
      onActionComplete={() => router.push('/devices')}
    />
  )
}
```

The component dynamically enables/disables actions based on device capabilities (MeshCentral agent status, device state) and provides different menu layouts depending on the display context.
