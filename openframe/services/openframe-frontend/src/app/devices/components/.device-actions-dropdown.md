A React dropdown component that provides contextual actions for device management in the OpenFrame platform, including remote control, file management, scripts, and device lifecycle operations.

## Key Components

- **DeviceActionsDropdown**: Main component that renders a dropdown menu with device-specific actions
- **Action Handlers**: Functions for remote control, shell access, script execution, file management, archiving, and deletion
- **Confirmation Dialogs**: AlertDialog components for destructive actions (archive/delete)
- **Uninstall Modal**: Modal showing platform-specific uninstall commands with clipboard copy functionality
- **Context-Aware Rendering**: Different menu items based on 'table' vs 'detail' context
- **Device Action Availability**: Dynamic enabling/disabling of actions based on device capabilities

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'

// In a device table row
<DeviceActionsDropdown
  device={device}
  context="table"
  onActionComplete={() => refetch()}
/>

// In device detail page with custom handlers
<DeviceActionsDropdown
  device={device}
  context="detail"
  onRemoteControl={() => openRemoteDesktop()}
  onRunScript={() => setScriptModalOpen(true)}
  onRemoteShell={(type) => openShell(type)}
  onActionComplete={() => router.push('/devices')}
/>
```

The component integrates with OpenFrame's device management system, providing unified access to remote operations, MeshCentral agent capabilities, and device lifecycle management through a responsive dropdown interface.
