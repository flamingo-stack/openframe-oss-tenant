A React component that provides a dropdown menu for device-related actions in the OpenFrame device management interface. Supports context-aware rendering for both table rows and device detail pages.

## Key Components

- **DeviceActionsDropdown**: Main component that renders a dropdown menu with device actions
- **Device Action Handlers**: Methods for remote control, shell access, script execution, and file management
- **Confirmation Dialogs**: Alert dialogs for destructive actions (archive/delete)
- **Uninstall Modal**: Shows platform-specific uninstall commands with copy functionality
- **Context-Aware Menu**: Different action sets for table vs detail page contexts

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'
import type { Device } from '../types/device.types'

function DeviceTable() {
  const device: Device = {
    id: 'device-123',
    machineId: 'machine-456',
    displayName: 'Server-01',
    platform: 'windows',
    // ... other device properties
  }

  return (
    <table>
      <tbody>
        <tr>
          <td>{device.displayName}</td>
          <td>
            <DeviceActionsDropdown
              device={device}
              context="table"
              onActionComplete={() => refreshDevices()}
              onRemoteControl={() => openRemoteModal()}
              onRunScript={() => openScriptModal()}
              onRemoteShell={(type) => openShellModal(type)}
            />
          </td>
        </tr>
      </tbody>
    </table>
  )
}

// Usage in device detail page
function DeviceDetailPage() {
  return (
    <div>
      <DeviceActionsDropdown
        device={device}
        context="detail"
        onActionComplete={() => router.push('/devices')}
      />
    </div>
  )
}
```

The component automatically handles device action availability based on agent status and provides appropriate navigation for different contexts.
