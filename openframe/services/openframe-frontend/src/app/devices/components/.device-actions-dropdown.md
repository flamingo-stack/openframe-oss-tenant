A React dropdown component that provides contextual device management actions with proper state handling and navigation.

## Key Components

- **DeviceActionsDropdown**: Main dropdown component with device-specific actions
- **Action handlers**: Methods for remote control, shell access, file management, and device lifecycle operations
- **Confirmation dialogs**: Modal dialogs for destructive operations (archive, delete, uninstall)
- **Dynamic menu generation**: Context-aware menu items based on device capabilities and current view

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'

// In a device table row
<DeviceActionsDropdown 
  device={device}
  context="table"
  onActionComplete={() => refetch()}
/>

// In a device detail page
<DeviceActionsDropdown 
  device={device}
  context="detail"
  onActionComplete={() => router.push('/devices')}
  onRunScript={() => setShowScriptModal(true)}
/>
```

The component automatically adapts its menu items based on the context (table vs detail view) and device capabilities. It handles routing for remote control features, displays appropriate confirmation dialogs for destructive actions, and provides proper loading states during operations.
