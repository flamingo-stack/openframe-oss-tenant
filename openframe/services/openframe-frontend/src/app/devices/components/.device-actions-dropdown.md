A React component providing a dropdown menu with device-specific actions like remote control, file management, and device lifecycle operations. It adapts its interface based on context (table row vs detail page) and device capabilities.

## Key Components

- **DeviceActionsDropdown** - Main dropdown component with action menu
- **Action Handlers** - Methods for remote control, script execution, shell access
- **Confirmation Dialogs** - AlertDialogs for destructive actions (archive/delete)
- **Uninstall Modal** - CommandBox showing platform-specific uninstall commands
- **Dynamic Menu Groups** - Context-aware action groupings based on device capabilities

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'

// In a table row context
<DeviceActionsDropdown
  device={device}
  context="table"
  onActionComplete={() => refetchDevices()}
/>

// In device detail page with custom handlers
<DeviceActionsDropdown
  device={device}
  context="detail"
  onRemoteControl={() => openRemoteControlModal()}
  onRunScript={() => setShowScriptModal(true)}
  onRemoteShell={(type) => openShellSession(type)}
/>
```

The component automatically determines available actions based on device capabilities (online status, OS type, agent availability) and provides appropriate confirmation dialogs for destructive operations. It uses the unified device action configuration system to ensure consistency across the platform.
