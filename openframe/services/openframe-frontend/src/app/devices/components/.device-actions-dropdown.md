React component that provides a comprehensive dropdown menu for device management actions in OpenFrame's device interface. Renders different action menus based on context (table vs detail view) with confirmation dialogs for destructive operations.

## Key Components

- **DeviceActionsDropdown**: Main component providing device actions dropdown
- **Action Types**: Remote control, shell access, script execution, file management, archive/delete
- **Confirmation Dialogs**: Archive and delete device confirmation modals
- **Uninstall Dialog**: Shows device-specific uninstall commands with copy functionality
- **Context-Aware Menu**: Different actions available in table vs detail view contexts
- **Platform Detection**: Windows-specific shell options (cmd/PowerShell vs bash)

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'

// In device table
<DeviceActionsDropdown
  device={device}
  context="table"
  onActionComplete={() => refetchDevices()}
/>

// In device detail page with custom handlers
<DeviceActionsDropdown
  device={device}
  context="detail"
  onRemoteControl={() => openRemoteDesktop()}
  onRunScript={() => setShowScriptModal(true)}
  onRemoteShell={(type) => openShell(type)}
/>

// Device object structure
const device = {
  id: 'device-123',
  machineId: 'machine-456',
  displayName: 'Production Server',
  hostname: 'srv-prod-01',
  platform: 'windows',
  osType: 'WINDOWS',
  operating_system: 'Windows 11'
}
```

The component automatically handles platform detection, action availability based on device state, and provides appropriate confirmation dialogs for destructive actions. It integrates with OpenFrame's routing system for navigation and includes loading states for async operations.
