A reusable React dropdown component that provides device-specific actions and management options with context-aware menu items and confirmation dialogs.

## Key Components

- **DeviceActionsDropdown**: Main component that renders a dropdown menu with device actions
- **Menu Groups**: Dynamic groups for remote actions (Remote Shell, Remote Control, File Manager) and destructive actions (Archive, Delete, Uninstall)
- **Confirmation Dialogs**: Archive and delete confirmation modals with proper styling
- **Uninstall Dialog**: Modal showing platform-specific uninstall commands with copy functionality
- **Context Awareness**: Different menu items shown based on table vs detail page context

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'

// In a device table
<DeviceActionsDropdown
  device={device}
  context="table"
  onActionComplete={() => refetchDevices()}
/>

// In device detail page
<DeviceActionsDropdown
  device={device}
  context="detail"
  onRunScript={() => setShowScriptModal(true)}
  onActionComplete={() => router.refresh()}
/>
```

The component automatically:
- Checks device capabilities and enables/disables actions accordingly
- Handles navigation to remote control, shell, and file manager pages
- Shows platform-appropriate uninstall commands (Windows/Linux/macOS)
- Provides confirmation dialogs for destructive actions
- Stops event propagation to prevent conflicts with table row clicks
- Uses the device's `machineId` for consistent URL routing
