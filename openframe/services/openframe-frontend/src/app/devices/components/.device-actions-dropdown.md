A React dropdown component providing various device management actions like remote control, shell access, file management, archiving, and deletion.

## Key Components

- **DeviceActionsDropdown** - Main dropdown component with contextual actions
- **Action Handlers** - Methods for remote control, shell access, script execution, and device management
- **Confirmation Dialogs** - AlertDialogs for archive/delete confirmations  
- **Uninstall Modal** - Modal showing platform-specific uninstall commands
- **Dynamic Menu Groups** - Context-aware menu items based on device capabilities and view context

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'
import type { Device } from '../types/device.types'

// In a device table
<DeviceActionsDropdown
  device={device}
  context="table"
  onActionComplete={() => refetchDevices()}
/>

// In device detail view with custom handlers
<DeviceActionsDropdown
  device={device}
  context="detail"
  onRemoteControl={() => openRemoteControlModal()}
  onRunScript={() => openScriptModal()}
  onRemoteShell={(type) => openShellModal(type)}
  onActionComplete={() => router.push('/devices')}
/>
```

The component automatically determines available actions based on device capabilities (online status, agent presence, etc.) and adjusts the menu items accordingly. It handles navigation differently based on context - table actions refresh the list while detail actions may navigate away from the page.
