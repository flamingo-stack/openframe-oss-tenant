A React dropdown component that provides contextual action menus for device management, supporting different layouts and actions based on the context (table or detail view).

## Key Components

- **DeviceActionsDropdown** - Main dropdown component with conditional rendering based on context
- **Action Handlers** - Methods for remote control, shell access, file management, and device lifecycle operations
- **Confirmation Dialogs** - Archive and delete confirmation modals with proper styling
- **Uninstall Dialog** - Modal showing platform-specific uninstall commands with copy functionality
- **Menu Configuration** - Dynamic menu groups based on device capabilities and context

## Usage Example

```typescript
// In a device table row
<DeviceActionsDropdown
  device={device}
  context="table"
  onActionComplete={() => refetchDevices()}
/>

// In device detail view
<DeviceActionsDropdown
  device={device}
  context="detail"
  onRunScript={() => setShowScriptModal(true)}
  onActionComplete={() => router.push('/devices')}
/>
```

The component dynamically shows/hides actions based on device capabilities (MeshCentral agent status, platform type) and provides different menu layouts for table versus detail contexts. Remote actions like shell access and file management are available when the device has an active MeshCentral agent, while destructive actions like archive/delete require appropriate permissions.
