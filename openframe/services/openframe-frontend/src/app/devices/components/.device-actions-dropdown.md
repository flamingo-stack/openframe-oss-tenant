A comprehensive dropdown component that provides contextual device management actions with confirmation dialogs and integration hooks for remote operations.

## Key Components

- **DeviceActionsDropdown** - Main dropdown component with dynamic action menus
- **Device Actions** - Remote control, shell access, script execution, file management
- **Device Lifecycle** - Archive, delete, and uninstall operations
- **Confirmation Dialogs** - AlertDialog components for destructive actions
- **Context Awareness** - Different action sets for table vs detail views

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'
import type { Device } from '../types/device.types'

function DeviceTable({ devices }: { devices: Device[] }) {
  return (
    <table>
      {devices.map(device => (
        <tr key={device.id}>
          <td>{device.hostname}</td>
          <td>
            <DeviceActionsDropdown
              device={device}
              context="table"
              onActionComplete={() => refetchDevices()}
              onRemoteControl={() => openRemoteDesktop(device)}
              onRunScript={() => openScriptModal(device)}
              onRemoteShell={(type) => openShell(device, type)}
            />
          </td>
        </tr>
      ))}
    </table>
  )
}

// Usage in device detail view
function DeviceDetail({ device }: { device: Device }) {
  return (
    <div>
      <h1>{device.hostname}</h1>
      <DeviceActionsDropdown
        device={device}
        context="detail"
        onActionComplete={() => router.push('/devices')}
      />
    </div>
  )
}
```

The component automatically determines action availability based on device state, handles platform-specific operations (Windows vs Linux shell types), and provides unified action buttons through the device action configuration system.
