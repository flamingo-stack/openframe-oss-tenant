A React component that renders a dropdown menu with device-specific actions like remote control, shell access, file management, and device lifecycle operations (archive/delete/uninstall).

## Key Components

- **DeviceActionsDropdown**: Main component that renders a context-aware dropdown menu
- **Action Availability**: Uses `getDeviceActionAvailability` to determine which actions are enabled based on device state
- **Platform Detection**: Dynamically shows platform-specific shell options (CMD/PowerShell for Windows, Bash for Linux/Mac)
- **Modal Dialogs**: Confirmation dialogs for destructive actions (archive, delete) and uninstall command display
- **Navigation Integration**: Handles routing to device detail pages and action-specific views

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'
import type { Device } from '../types/device.types'

// Basic usage in a device table
<DeviceActionsDropdown 
  device={device} 
  context="table"
  onActionComplete={() => refetch()} 
/>

// Usage in device detail page with custom handlers
<DeviceActionsDropdown 
  device={device} 
  context="detail"
  onRemoteControl={() => setShowRemoteDesktop(true)}
  onRunScript={() => setShowScriptModal(true)}
  onRemoteShell={(type) => openShellSession(type)}
/>

// Device object structure
const device: Device = {
  id: 'device-123',
  machineId: 'machine-abc',
  displayName: 'Production Server',
  hostname: 'prod-web-01',
  platform: 'linux',
  osType: 'ubuntu',
  status: 'online'
}
```

The component adapts its available actions based on device capabilities (online status, agent availability) and context (table row vs detail page), providing appropriate confirmation dialogs for destructive operations and platform-specific command generation for uninstalls.
