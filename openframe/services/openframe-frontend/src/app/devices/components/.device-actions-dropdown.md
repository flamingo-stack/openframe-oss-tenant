A React component that provides a dropdown menu with contextual device management actions like remote control, scripts, archiving, and deletion.

## Key Components

- **DeviceActionsDropdown**: Main component rendering a dropdown with device-specific actions
- **Action Categories**: Remote control (shell, desktop, files), scripts, and destructive actions (uninstall, archive, delete)
- **Context Awareness**: Different menu items based on 'table' vs 'detail' view context
- **Confirmation Dialogs**: Alert dialogs for destructive actions with proper user confirmation
- **Platform Detection**: OS-specific action availability and shell type selection

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'

// In a device table row
<DeviceActionsDropdown
  device={deviceData}
  context="table"
  onActionComplete={() => refetch()}
/>

// In a device detail page
<DeviceActionsDropdown
  device={deviceData}
  context="detail"
  onRunScript={() => setShowScriptModal(true)}
  onActionComplete={() => router.refresh()}
/>
```

The component automatically handles:
- Action availability based on device capabilities (MeshCentral agent status)
- Platform-specific features (Windows PowerShell vs Unix bash)
- Navigation routing for remote access features
- Uninstall command generation with clipboard copy functionality
- Proper event propagation handling in table contexts
