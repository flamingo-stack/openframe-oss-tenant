A React component that provides a dropdown menu with device management actions (remote control, scripts, archive, delete) with context-aware behavior for table and detail views.

## Key Components

- **DeviceActionsDropdown** - Main dropdown component with action menu
- **Action Handlers** - Functions for remote control, script execution, shell access, and file management
- **Confirmation Dialogs** - Archive and delete confirmation modals
- **Uninstall Command Dialog** - Modal showing platform-specific uninstall commands
- **Context-Aware Rendering** - Different menu items based on table vs detail context

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'

// In a device table row
<DeviceActionsDropdown
  device={device}
  context="table"
  onActionComplete={() => refetchDevices()}
/>

// In device detail view with custom handlers
<DeviceActionsDropdown
  device={device}
  context="detail"
  onRemoteControl={() => openRemoteControlModal()}
  onRunScript={() => openScriptModal()}
  onRemoteShell={(type) => openShellModal(type)}
  onActionComplete={() => router.push('/devices')}
/>
```

The component integrates with the device management system to provide unified access to remote operations, maintenance tasks, and device lifecycle management. It automatically determines action availability based on device capabilities and shows appropriate confirmation dialogs for destructive operations.
