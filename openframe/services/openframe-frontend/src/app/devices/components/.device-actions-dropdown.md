A React dropdown component providing contextual device management actions with remote control, file management, and device lifecycle operations.

## Key Components

- **DeviceActionsDropdown** - Main component that renders context-appropriate action menus
- **Action handlers** - Functions for remote control, shell access, file management, archive, and delete operations
- **Confirmation dialogs** - Archive and delete confirmation modals with proper styling
- **Uninstall modal** - Shows platform-specific uninstall commands with clipboard copy functionality
- **Context-aware rendering** - Different action sets for table vs detail page contexts

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'
import type { Device } from '../types/device.types'

function DeviceTable({ devices }: { devices: Device[] }) {
  return (
    <div>
      {devices.map(device => (
        <div key={device.id} className="device-row">
          <span>{device.displayName}</span>
          <DeviceActionsDropdown
            device={device}
            context="table"
            onActionComplete={() => {
              // Refresh device list after archive/delete
              refetchDevices()
            }}
          />
        </div>
      ))}
    </div>
  )
}

// In device detail page
function DeviceDetails({ device }: { device: Device }) {
  return (
    <div>
      <DeviceActionsDropdown
        device={device}
        context="detail"
        onRemoteControl={() => openRemoteDesktop()}
        onRunScript={() => openScriptModal()}
        onRemoteShell={(type) => openShellModal(type)}
      />
    </div>
  )
}
```

The component automatically determines available actions based on device capabilities (MeshCentral agent, platform type) and handles navigation or callback execution depending on the integration context.
