A React dropdown component that provides device management actions including remote control, shell access, archival, and deletion capabilities within the OpenFrame platform.

## Key Components

- **DeviceActionsDropdown** - Main component rendering a dropdown menu with context-sensitive device actions
- **Action handlers** - Methods for remote control, shell access, script execution, archival, and deletion
- **Confirmation dialogs** - Alert dialogs for destructive actions (archive/delete)
- **Uninstall command modal** - Shows platform-specific uninstall commands with copy functionality
- **Menu configuration** - Dynamic menu groups based on device capabilities and context

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'

// In a device table
<DeviceActionsDropdown
  device={device}
  context="table"
  onActionComplete={() => refreshDeviceList()}
/>

// In device details with custom handlers
<DeviceActionsDropdown
  device={device}
  context="detail"
  onRemoteControl={() => openRemoteDesktop()}
  onRunScript={() => openScriptModal()}
  onRemoteShell={(type) => openShell(type)}
/>
```

The component adapts its menu items based on device capabilities (MeshCentral agent status, OS type) and context (table vs detail view), with different actions available in each context to avoid duplication with dedicated action buttons.
