A React dropdown component that provides device management actions with context-aware menu items, confirmation dialogs, and platform-specific remote access options.

## Key Components

- **DeviceActionsDropdown**: Main component that renders a dropdown menu with device actions
- **Action Handlers**: Functions for remote control, shell access, file management, archiving, and deletion
- **Confirmation Dialogs**: Modal dialogs for destructive actions (archive/delete/uninstall)
- **Context-Aware Rendering**: Different menu items based on table vs detail page context
- **Platform Detection**: Windows/Unix shell type selection for remote access

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'

function DeviceTable() {
  return (
    <DeviceActionsDropdown
      device={deviceData}
      context="table"
      onActionComplete={() => refetchDevices()}
      onRunScript={() => setShowScriptModal(true)}
    />
  )
}

// In device detail page
function DeviceDetailPage() {
  return (
    <DeviceActionsDropdown
      device={deviceData}
      context="detail"
      onActionComplete={() => router.push('/devices')}
    />
  )
}
```

The component automatically handles:
- Remote desktop/shell navigation using device machine IDs
- Platform-specific uninstall command generation
- Action availability based on device capabilities (MeshCentral agent status)
- Toast notifications for user feedback
- Navigation differences between table and detail contexts
