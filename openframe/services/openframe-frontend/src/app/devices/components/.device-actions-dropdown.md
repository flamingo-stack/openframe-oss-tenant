A React client component that provides a dropdown menu with device-specific actions like remote control, file management, archiving, and deletion. The component adapts its interface based on context (table row vs detail page) and device capabilities.

## Key Components

- **DeviceActionsDropdown**: Main component rendering a dropdown menu with contextual device actions
- **Action handlers**: Functions for remote control, script execution, shell access, file management, archiving, and deletion
- **Confirmation dialogs**: AlertDialog components for destructive actions (archive/delete)
- **Uninstall dialog**: Modal showing platform-specific uninstall commands with copy functionality
- **Dynamic menu generation**: Context-aware menu items based on device capabilities and availability

## Usage Example

```typescript
// In a device table row
<DeviceActionsDropdown
  device={device}
  context="table"
  onActionComplete={() => refetchDevices()}
/>

// In device detail page with custom handlers
<DeviceActionsDropdown
  device={device}
  context="detail"
  onRemoteControl={() => setShowRemoteModal(true)}
  onRunScript={() => setShowScriptModal(true)}
  onRemoteShell={(type) => openShellSession(type)}
  onActionComplete={() => router.push('/devices')}
/>

// Device type example
const device: Device = {
  id: 'device-123',
  machineId: 'machine-456',
  displayName: 'Office Desktop',
  hostname: 'office-pc',
  platform: 'windows',
  osType: 'WINDOWS',
  operating_system: 'Windows 11'
}
```

The component integrates with OpenFrame's device management system, providing unified action availability checking, platform-specific command generation, and seamless navigation between device views.
