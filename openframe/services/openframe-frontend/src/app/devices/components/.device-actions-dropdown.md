A React component that provides a dropdown menu with various device management actions like remote control, shell access, archiving, and deletion.

## Key Components

- **DeviceActionsDropdown** - Main dropdown component with action menu
- **Action availability logic** - Determines which actions are enabled based on device state
- **Confirmation dialogs** - Archive and delete confirmation modals
- **Command generation** - Builds uninstall commands for different platforms
- **Context-aware rendering** - Different button styles for table vs detail views

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'
import { Device } from '../types/device.types'

const device: Device = {
  id: 'device-123',
  machineId: 'machine-456',
  displayName: 'Server-01',
  platform: 'Windows',
  status: 'online'
}

function DeviceTable() {
  return (
    <DeviceActionsDropdown
      device={device}
      context="table"
      onActionComplete={() => {
        // Refresh device list
        refetchDevices()
      }}
      onRemoteControl={() => {
        // Handle remote control action
        openRemoteDesktop()
      }}
      onRunScript={() => {
        // Open script execution modal
        setShowScriptModal(true)
      }}
      onRemoteShell={(type) => {
        // Open remote shell with specific type
        openShell(type)
      }}
    />
  )
}
```

The component automatically handles device action availability based on device status, platform compatibility, and agent connectivity. It provides different menu configurations for table and detail page contexts, with appropriate navigation and confirmation flows for destructive actions.
