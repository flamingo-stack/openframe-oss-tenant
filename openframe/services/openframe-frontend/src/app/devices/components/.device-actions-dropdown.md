React component that provides a dropdown menu with device-specific actions for OpenFrame devices. It supports different contexts (table vs detail view) and integrates with various device management operations.

## Key Components

- **DeviceActionsDropdown**: Main component that renders a dropdown menu with contextual device actions
- **Action handlers**: Methods for remote control, shell access, script execution, file management, archiving, and deletion
- **Confirmation dialogs**: AlertDialog components for destructive actions (archive/delete)
- **Uninstall modal**: Modal with command instructions for device uninstallation
- **Context-aware rendering**: Different menu items based on table vs detail view context

## Usage Example

```typescript
import { DeviceActionsDropdown } from './device-actions-dropdown'
import type { Device } from '../types/device.types'

// In a device table row
<DeviceActionsDropdown
  device={deviceData}
  context="table"
  onActionComplete={() => refetchDevices()}
/>

// In device detail view with custom handlers
<DeviceActionsDropdown
  device={deviceData}
  context="detail"
  onRemoteControl={() => openRemoteDesktop()}
  onRunScript={() => setScriptModalOpen(true)}
  onRemoteShell={(type) => openShellModal(type)}
  onActionComplete={() => router.push('/devices')}
/>
```

The component automatically determines available actions based on device capabilities and renders appropriate UI elements for each context. It handles navigation, state management, and integrates with the OpenFrame device management system.
