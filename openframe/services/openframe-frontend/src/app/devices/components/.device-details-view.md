This React component renders a detailed device view page with comprehensive device management capabilities in the OpenFrame MSP platform.

## Key Components

- **DeviceDetailsView**: Main component that displays device information, status, and management actions
- **Device Actions**: Remote control, shell access, and file management buttons with OS-specific functionality
- **Tab Navigation**: Hardware, logs, and other device-related tabs using the OpenFrame tab system
- **Modals**: Scripts execution modal for device automation
- **Status Display**: Real-time device status with color-coded indicators
- **Navigation**: URL-based action handling and tab synchronization

## Usage Example

```typescript
// Used in device routing
<DeviceDetailsView deviceId="device-123" />

// The component automatically:
// - Fetches device data using useDeviceDetails hook
// - Shows loading states with CardLoader
// - Handles action parameters from URL (e.g., ?action=runScript)
// - Provides OS-specific shell options (CMD/PowerShell for Windows, Bash for Linux)
// - Updates relative timestamps every second
// - Manages tab navigation with URL sync
```

The component integrates with the device management system to provide technicians with comprehensive remote device control, including shell access, file management, script execution, and detailed hardware/software information through a tabbed interface.
