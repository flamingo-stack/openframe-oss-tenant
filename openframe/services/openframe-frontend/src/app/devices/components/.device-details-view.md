Device details view component that provides a comprehensive interface for managing and interacting with individual devices in the Flamingo MSP platform.

## Key Components

- **DeviceDetailsView** - Main component rendering device information and management interface
- **Device Actions** - Remote control, shell access, file management, and script execution
- **Tab Navigation** - Hardware, software, logs, and other device-specific views
- **Modal Integration** - Scripts execution and remote shell interfaces
- **Status Management** - Real-time device status updates and availability checks

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

// Render device details page
function DeviceDetailsPage({ params }: { params: { deviceId: string } }) {
  return <DeviceDetailsView deviceId={params.deviceId} />
}

// With URL parameters for automated actions
const deviceUrl = `/devices/details/123?action=runScript`
const shellUrl = `/devices/details/123?action=remoteShell&shellType=powershell`
```

The component automatically handles URL-based action triggers, supports both Windows (CMD/PowerShell) and Linux (bash) shell types, and provides real-time status updates. It integrates with the broader OpenFrame platform for remote management capabilities including file management, script execution, and remote desktop access.
