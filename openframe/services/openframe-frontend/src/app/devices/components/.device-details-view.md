A React component that provides a comprehensive device details page with remote management capabilities, tabbed navigation, and action buttons for IT operations.

## Key Components

- **DeviceDetailsView** - Main component that renders device information and management interface
- **Device Actions** - Remote control, shell access, file management, and script execution buttons
- **Shell Type Selection** - Conditional dropdown for Windows devices (CMD/PowerShell) vs direct bash for non-Windows
- **Tab Navigation** - Hardware, logs, and other device information sections
- **URL Action Handling** - Processes URL parameters to trigger specific actions like script execution
- **Real-time Updates** - Auto-refreshes relative timestamps every second

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

// In a Next.js page component
export default function DeviceDetailsPage({ params }: { params: { id: string } }) {
  return (
    <div className="min-h-screen bg-background">
      <DeviceDetailsView deviceId={params.id} />
    </div>
  )
}

// URL-triggered actions
// Navigate to: /devices/details/123?action=runScript
// This will automatically open the scripts modal
```

The component integrates with the OpenFrame device management system, providing IT technicians with remote access tools, device monitoring, and automation capabilities through a unified interface.
