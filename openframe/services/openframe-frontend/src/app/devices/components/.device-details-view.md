A React component that displays comprehensive device details with remote management capabilities and tabbed content sections.

## Key Components

- **DeviceDetailsView**: Main component rendering device information, status, and management actions
- **Header Actions**: Remote control, shell access, and file management buttons with OS-specific shell selection
- **Device Info Section**: Displays core device information and current status
- **Tab Navigation**: Provides tabbed interface for different device detail views (hardware, software, logs, etc.)
- **Scripts Modal**: Allows running scripts on the selected device
- **URL Parameter Handling**: Supports deep-linking to specific actions and tabs

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

function DevicePage() {
  return (
    <DeviceDetailsView deviceId="device-123" />
  )
}

// URL-based navigation examples:
// /devices/details/device-123?action=runScript - Opens scripts modal
// /devices/details/device-123?tab=logs - Opens logs tab
```

The component automatically fetches device data, provides platform-specific remote access options (Windows shows CMD/PowerShell dropdown, others show bash), and includes real-time status updates. It integrates with the OpenFrame design system for consistent UI patterns and responsive behavior.
