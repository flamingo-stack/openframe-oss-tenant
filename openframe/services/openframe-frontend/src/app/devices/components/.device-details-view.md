A React component that renders a comprehensive device details page with remote management capabilities, device information, and tabbed content sections.

## Key Components

- **Device Information Display** - Shows device status, name, hostname and last updated timestamp
- **Action Buttons** - Remote Control, Remote Shell (with Windows CMD/PowerShell dropdown), and File Management
- **Modal Management** - Handles scripts execution and remote shell modals with URL parameter integration
- **Tab Navigation** - Displays device details in organized tabs (hardware, logs, etc.)
- **Device Actions Dropdown** - Additional device management options
- **Loading & Error States** - Comprehensive error handling with loaders and not found states

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

// Used in device details page route
export default function DeviceDetailsPage({ 
  params 
}: { 
  params: { deviceId: string } 
}) {
  return <DeviceDetailsView deviceId={params.deviceId} />
}

// Supports URL actions for deep linking
// /devices/details/123?action=runScript
// /devices/details/123?action=remoteShell&shellType=powershell
```

The component automatically handles URL parameters for triggering actions, manages shell type selection based on OS, and provides a responsive interface that hides content when remote shell modal is active. It integrates with the device management system to fetch real-time device data and enable remote operations.
