A comprehensive device details page component that provides device management capabilities including remote access, script execution, and tabbed information display.

## Key Components

**Main Component:**
- `DeviceDetailsView` - Primary device details page with remote control actions
- Handles URL parameters for action navigation from device tables
- Manages multiple modals for device operations

**Key Features:**
- Device information display with status indicators and last updated timestamps
- Remote control and shell access (CMD/PowerShell for Windows, bash for Linux)
- File manager navigation and script execution capabilities
- Tabbed interface for detailed device information
- Responsive action buttons with availability checking

**State Management:**
- Device loading and error handling
- Modal state management for scripts and remote shell
- Shell type selection for Windows devices
- URL parameter synchronization for deep linking

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

// Basic usage - typically in a page route
export default function DeviceDetailsPage({ 
  params 
}: { 
  params: { deviceId: string } 
}) {
  return <DeviceDetailsView deviceId={params.deviceId} />
}

// The component handles URL actions automatically:
// /devices/details/abc123?action=runScript
// /devices/details/abc123?action=remoteShell&shellType=powershell
```

The component integrates with the OpenFrame device management system, providing a unified interface for IT professionals to manage and interact with remote devices through various protocols and tools.
