A React component that renders a comprehensive device details page with device information, action buttons, and tabbed content for IT device management.

## Key Components

- **DeviceDetailsView** - Main component displaying device details with navigation, status, and actions
- **Device Info Section** - Shows device hardware and system information
- **Action Buttons** - Remote control, shell access, and file management capabilities
- **Tab Navigation** - Organized content tabs for hardware, software, logs, etc.
- **Modal Components** - Scripts execution and remote shell interfaces
- **URL State Management** - Handles routing and action parameters from navigation

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

// Render device details page
function DevicePage({ params }: { params: { deviceId: string } }) {
  return <DeviceDetailsView deviceId={params.deviceId} />
}

// Navigate with action parameters
router.push(`/devices/details/${deviceId}?action=remoteShell&shellType=powershell`)

// Handle device actions programmatically
const handleDeviceAction = (deviceId: string, action: string) => {
  router.push(`/devices/details/${deviceId}?action=${action}`)
}
```

The component integrates with the OpenFrame MSP platform to provide comprehensive device management capabilities including remote access, script execution, and detailed hardware monitoring through a tabbed interface.
