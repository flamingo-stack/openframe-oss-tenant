A React component that displays comprehensive device details with remote management capabilities and tabbed interface for device information.

## Key Components

- **Main View**: Device details page with back navigation and action buttons
- **Device Actions**: Remote control, shell access (with Windows CMD/PowerShell options), and file management
- **Info Section**: Device hardware and system information display
- **Tab Navigation**: Tabbed interface for different device data views (hardware, logs, etc.)
- **Scripts Modal**: Interface for running scripts on the device
- **Action Dropdown**: Additional device management actions
- **Status Display**: Real-time device status with relative timestamps

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

// Display device details page
function DevicePage({ params }: { params: { id: string } }) {
  return (
    <DeviceDetailsView deviceId={params.id} />
  )
}

// Component handles:
// - Loading device data via useDeviceDetails hook
// - URL parameter processing for actions (?action=runScript)
// - Real-time status updates every second
// - Platform-specific shell options (Windows vs Unix)
// - Navigation between tabs with URL synchronization
```

The component provides a complete device management interface with remote access capabilities, file management, script execution, and detailed system information organized in tabs. It automatically handles different operating systems and enables appropriate remote management tools based on device platform.
