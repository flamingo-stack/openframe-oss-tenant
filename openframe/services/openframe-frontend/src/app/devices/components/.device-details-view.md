This React component provides a comprehensive device details page with remote management capabilities and tabbed interface for device information.

## Key Components

- **DeviceDetailsView**: Main component rendering device details with action buttons and modals
- **Header Actions**: Remote control, shell access, and file management buttons with OS-specific shell options
- **Modals**: Scripts execution and remote shell access modals
- **Tabs**: Hardware, logs, and other device information tabs
- **URL Handling**: Deep linking support for actions via URL parameters

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

// Render device details page
function DevicePage({ params }: { params: { deviceId: string } }) {
  return <DeviceDetailsView deviceId={params.deviceId} />
}

// URL action handling examples:
// /devices/details/123?action=runScript - Opens scripts modal
// /devices/details/123?action=remoteShell&shellType=powershell - Opens PowerShell
```

The component automatically fetches device data, handles loading/error states, provides OS-aware remote access options (CMD/PowerShell for Windows, bash for others), and supports URL-based action triggering. It includes real-time status updates and integrates with the broader OpenFrame device management system.
