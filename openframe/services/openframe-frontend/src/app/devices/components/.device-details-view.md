A React component that provides a comprehensive device details page with remote management capabilities, tabbed navigation, and modal interfaces for device operations.

## Key Components

- **DeviceDetailsView**: Main component that fetches and displays device information
- **Header Actions**: Remote control, shell access, and file management buttons
- **DeviceInfoSection**: Basic device information display
- **TabNavigation**: Tabbed interface for different device views (hardware, logs, etc.)
- **ScriptsModal**: Interface for running scripts on the device
- **RemoteShellModal**: Terminal access modal with shell type selection
- **DeviceActionsDropdown**: Additional device management actions

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

function DevicePage({ params }: { params: { id: string } }) {
  return <DeviceDetailsView deviceId={params.id} />
}

// URL parameter handling for actions
// ?action=runScript - Opens scripts modal
// ?action=remoteShell&shellType=powershell - Opens shell with specific type
```

The component automatically handles device data fetching, URL parameter-based actions, OS-specific shell options (CMD/PowerShell for Windows, bash for others), and real-time status updates. It integrates with the OpenFrame frontend core for consistent UI patterns and device management workflows.
