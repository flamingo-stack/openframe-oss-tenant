A React component that renders a detailed view for individual devices in the OpenFrame MSP platform, providing device information, action buttons, and tabbed navigation for device management.

## Key Components

- **DeviceDetailsView** - Main component that displays comprehensive device details with action buttons and tabbed interface
- **Device Actions** - Remote control, shell access, file management, and script execution buttons
- **Shell Type Selection** - Dropdown for Windows devices to choose between CMD and PowerShell
- **Tab Navigation** - Hardware, logs, and other device-specific information tabs
- **Scripts Modal** - Interface for running scripts on the selected device
- **URL Parameter Handling** - Processes action parameters from navigation (e.g., runScript trigger)

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

function DevicePage({ params }: { params: { deviceId: string } }) {
  return (
    <DeviceDetailsView deviceId={params.deviceId} />
  )
}

// URL handling for actions
// Navigate with action: /devices/details/device-123?action=runScript
// Component automatically opens scripts modal and cleans URL
```

The component integrates with the device management system to provide IT technicians with comprehensive device control capabilities, including remote access, file management, and script execution through the OpenFrame platform.
