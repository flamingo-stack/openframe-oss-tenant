A React component that displays detailed information about a specific device with comprehensive management actions and tabbed content sections.

## Key Components

- **DeviceDetailsView** - Main component handling device detail display and actions
- **DeviceInfoSection** - Shows basic device information and status
- **TabNavigation/TabContent** - Provides tabbed interface for different device data views
- **RemoteShellModal** - Enables remote shell access with CMD/PowerShell support
- **ScriptsModal** - Allows running scripts on the device
- **DeviceActionsDropdown** - Dropdown menu with additional device actions

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

// Display device details page
function DeviceDetailsPage({ params }: { params: { id: string } }) {
  return <DeviceDetailsView deviceId={params.id} />
}

// Navigation with action parameters
const navigateToDeviceWithScript = (deviceId: string) => {
  router.push(`/devices/details/${deviceId}?action=runScript`)
}

// Remote shell with specific type
const openRemoteShell = (deviceId: string, shellType: 'cmd' | 'powershell') => {
  router.push(`/devices/details/${deviceId}?action=remoteShell&shellType=${shellType}`)
}
```

The component supports URL-based action triggering, real-time status updates, OS-specific shell options (CMD/PowerShell for Windows, Bash for others), and comprehensive device management through modals and navigation links. It integrates with the device management system to provide remote control, file management, and script execution capabilities.
