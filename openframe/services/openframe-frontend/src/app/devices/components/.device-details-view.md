A comprehensive device details page component that displays device information, status, and provides remote management actions for MSP operations.

## Key Components

**Main Exports:**
- `DeviceDetailsView` - Primary component for displaying device details with tabs and actions

**Key Features:**
- Device information display with real-time status updates
- Remote control, shell, and file management actions
- Cross-platform shell support (CMD/PowerShell for Windows, Bash for others)
- Tabbed interface for hardware, logs, and other device data
- URL parameter handling for direct action navigation
- Scripts execution modal integration

**UI Components:**
- Status indicators with relative time updates
- Action buttons with availability checking
- Platform-specific shell dropdown for Windows
- Back navigation to devices list
- Loading states and error handling

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

export default function DeviceDetailPage({ params }: { params: { id: string } }) {
  return <DeviceDetailsView deviceId={params.id} />
}

// URL navigation with actions
// /devices/details/device-123?action=runScript - opens scripts modal
// /devices/details/device-123?tab=logs&refresh=123456 - shows logs tab
```

The component automatically fetches device data, handles platform detection for appropriate shell options, and provides a complete device management interface with real-time status updates every second.
