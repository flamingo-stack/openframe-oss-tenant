A React component that provides a comprehensive device details view with remote management capabilities. This component displays device information, status, and provides access to remote control, shell access, file management, and script execution features.

## Key Components

- **DeviceDetailsView** - Main component that orchestrates the device details display and actions
- **DeviceInfoSection** - Shows basic device information and status
- **TabNavigation/TabContent** - Provides tabbed interface for different device data views
- **RemoteShellModal** - Modal for remote shell access (CMD, PowerShell, or Bash)
- **ScriptsModal** - Modal for running scripts on the device
- **DeviceActionsDropdown** - Additional device management actions

## Key Features

- URL parameter handling for deep-linking to specific actions
- Real-time status updates with relative timestamps
- Platform-aware shell options (Windows shows CMD/PowerShell dropdown)
- Conditional action availability based on device capabilities
- Responsive layout with proper loading and error states

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

// Basic usage - device ID from URL params
function DevicePage({ params }: { params: { id: string } }) {
  return <DeviceDetailsView deviceId={params.id} />
}

// With action parameters (e.g., from device table)
// URL: /devices/details/123?action=remoteShell&shellType=powershell
// Component automatically opens PowerShell modal on load
```

The component integrates with the OpenFrame device management system, providing a unified interface for IT administrators to monitor and control managed devices remotely.
