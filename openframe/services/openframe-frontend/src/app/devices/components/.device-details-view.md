A React component that renders a detailed device view with remote management capabilities, status information, and tabbed content sections.

## Key Components

- **DeviceDetailsView** - Main component displaying comprehensive device information with action buttons
- **headerActions** - Action bar with Remote Control, Remote Shell (Windows shell selector), and File Manager buttons
- **DeviceInfoSection** - Device summary information display
- **TabNavigation/TabContent** - Tabbed interface for different device data views
- **ScriptsModal** - Modal for running scripts on the device
- **DeviceActionsDropdown** - Additional device actions in a dropdown menu

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

function DevicePage({ params }: { params: { id: string } }) {
  return (
    <div className="min-h-screen">
      <DeviceDetailsView deviceId={params.id} />
    </div>
  )
}
```

The component handles URL parameters for actions (like `?action=runScript`), provides OS-specific shell options for Windows devices, and includes real-time status updates with relative timestamps. It integrates with the device management system to provide remote control, shell access, file management, and script execution capabilities based on device availability and platform type.
