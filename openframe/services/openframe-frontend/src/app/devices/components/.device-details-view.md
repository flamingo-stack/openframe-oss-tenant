A React component that renders a comprehensive device details page with remote management capabilities, action buttons, and tabbed navigation for detailed device information.

## Key Components

- **Device Details Management**: Fetches and displays device information using `useDeviceDetails` hook
- **Remote Access Tools**: Provides buttons for remote control, shell access, and file management
- **Action Modals**: Includes `RemoteShellModal` and `ScriptsModal` for device interactions
- **Tabbed Interface**: Uses `TabNavigation` to organize device information sections
- **URL Parameter Handling**: Supports deep linking to specific actions (runScript, remoteShell)
- **Status Display**: Shows device status with color-coded tags and last updated timestamps

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

function DevicePage({ params }: { params: { id: string } }) {
  return <DeviceDetailsView deviceId={params.id} />
}

// URL navigation examples:
// /devices/details/123 - Basic device view
// /devices/details/123?action=runScript - Opens scripts modal
// /devices/details/123?action=remoteShell&shellType=powershell - Opens PowerShell
// /devices/details/123?tab=logs&refresh=1234567890 - Opens logs tab
```

The component handles Windows vs non-Windows devices differently, providing CMD/PowerShell options for Windows and bash for other platforms. It includes loading states, error handling, and responsive design with mobile-optimized layouts.
