A React component that displays comprehensive device details including status, system information, and remote management capabilities with tabbed navigation and action modals.

## Key Components

- **DeviceDetailsView** - Main component for device detail pages
- **Device Info Display** - Shows device status, last updated time, and basic information
- **Action Buttons** - Remote Control, Remote Shell (with Windows CMD/PowerShell options), and File Management
- **Tab Navigation** - Hardware, logs, and other device-specific tabs
- **Modal Integration** - Scripts execution and remote shell terminals
- **URL Parameter Handling** - Supports direct action triggers via URL parameters

## Usage Example

```typescript
// Route: /devices/details/[deviceId]
import { DeviceDetailsView } from './device-details-view'

export default function DeviceDetailPage({ params }: { params: { deviceId: string } }) {
  return <DeviceDetailsView deviceId={params.deviceId} />
}

// Direct action navigation
router.push('/devices/details/device-123?action=remoteShell&shellType=powershell')
```

The component automatically fetches device data, handles OS-specific shell options (CMD/PowerShell for Windows, bash for others), and provides a responsive interface with proper loading states and error handling. It integrates with the OpenFrame core components for consistent UI patterns and includes real-time relative timestamps that update every second.
