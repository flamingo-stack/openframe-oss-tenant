A React component that renders a comprehensive device details view with remote management capabilities, device information, and tabbed content sections.

## Key Components

- **DeviceDetailsView** - Main component displaying device details with header actions
- **DeviceInfoSection** - Device information display section
- **TabNavigation/TabContent** - Tabbed interface for device details sections
- **DeviceActionsDropdown** - Dropdown menu for device management actions
- **ScriptsModal** - Modal for running scripts on the device

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

function DevicePage({ params }: { params: { deviceId: string } }) {
  return (
    <div className="h-full">
      <DeviceDetailsView deviceId={params.deviceId} />
    </div>
  )
}

// Usage in Next.js app router
export default function Page({ params }: { params: { deviceId: string } }) {
  return <DeviceDetailsView deviceId={params.deviceId} />
}
```

The component provides remote control, shell access (with Windows CMD/PowerShell selection), file management, and script execution capabilities. It includes URL parameter handling for deep linking to specific actions and automatically refreshes relative timestamps. The interface adapts based on device OS type and action availability.
