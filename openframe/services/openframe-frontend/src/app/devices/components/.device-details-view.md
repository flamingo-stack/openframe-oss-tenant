A React component that displays comprehensive device details with tabbed navigation and device management actions.

## Key Components

- **DeviceDetailsView** - Main container component managing device state and UI interactions
- **DeviceInfoSection** - Displays device overview information
- **TabNavigation** - Provides tabbed interface for device data sections
- **DeviceActionsDropdown** - Dropdown menu for device management actions
- **ScriptsModal** - Modal for running scripts on the device
- **RemoteShellModal** - Modal for remote shell access with CMD/PowerShell support

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

export default function DevicePage({ params }: { params: { id: string } }) {
  return (
    <div className="container mx-auto">
      <DeviceDetailsView deviceId={params.id} />
    </div>
  )
}

// URL parameter handling for actions
// Navigate to: /devices/details/123?action=runScript
// Navigate to: /devices/details/123?action=remoteShell&shellType=powershell
```

The component features responsive device management with OS-specific shell options (CMD/PowerShell for Windows, bash for others), real-time status updates, and URL-based action handling for deep linking to specific device operations.
