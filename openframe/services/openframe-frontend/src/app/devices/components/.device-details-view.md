A React component that displays detailed device information with remote management capabilities, including tabs for different device data views and modal dialogs for remote operations.

## Key Components

- **DeviceDetailsView**: Main component that renders a detailed device view with back navigation, status information, and action buttons
- **Header Actions**: Remote Control, Remote Shell (with Windows CMD/PowerShell options), and Manage Files buttons
- **Device Info Section**: Displays basic device information and status
- **Tab Navigation**: Organizes device data into different tabbed views (hardware, logs, etc.)
- **Modal Components**: Scripts modal for running commands and remote shell modal for terminal access
- **URL Parameter Handling**: Supports deep-linking to specific actions via URL parameters

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

function DevicePage({ params }: { params: { deviceId: string } }) {
  return (
    <DeviceDetailsView deviceId={params.deviceId} />
  )
}
```

The component automatically fetches device data, handles loading states, and provides comprehensive device management capabilities through an intuitive interface. It supports both Windows and Unix-like systems with appropriate shell options and manages modal visibility states for seamless user experience.
