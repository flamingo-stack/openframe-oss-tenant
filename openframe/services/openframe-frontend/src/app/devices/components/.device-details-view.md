A React component that renders a comprehensive device details page with tabs, action buttons, and remote management capabilities.

## Key Components

- **DeviceDetailsView**: Main component that displays detailed device information with tabbed interface
- **Header Actions**: Remote control, shell access, file management buttons with OS-specific shell dropdown
- **Device Info Section**: Shows device status, last updated time, and basic information
- **Tab Navigation**: Hardware, logs, and other device-related tabs
- **Scripts Modal**: Interface for running scripts on the device
- **Action Availability**: Determines which actions are enabled based on device capabilities

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

function DeviceDetailsPage() {
  return (
    <DeviceDetailsView deviceId="device-123" />
  )
}

// URL handling for action triggers
// Example: /devices/details/device-123?action=runScript
```

The component automatically handles URL parameters for action triggers, provides OS-specific shell options (CMD/PowerShell for Windows, Bash for others), and includes real-time updates for relative timestamps. It integrates with the OpenFrame frontend core for consistent UI components and device management utilities.
