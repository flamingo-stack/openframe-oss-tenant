A React component that displays comprehensive device details in a tabbed interface with remote management capabilities and action handling.

## Key Components

- **Device Information Display**: Shows device status, name, and last updated timestamp with real-time updates
- **Action Buttons**: Provides Remote Control, Remote Shell (with Windows CMD/PowerShell options), and File Management
- **Tab Navigation**: Organizes device information using configurable tabs (hardware, logs, etc.)
- **Modal Management**: Handles Scripts and Remote Shell modals with URL parameter-based navigation
- **Error Handling**: Displays loading states, error messages, and not found scenarios

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

// Display device details page
function DevicePage({ params }: { params: { deviceId: string } }) {
  return <DeviceDetailsView deviceId={params.deviceId} />
}

// With URL action handling (opens scripts modal)
// URL: /devices/details/device-123?action=runScript

// With shell action (opens remote shell)
// URL: /devices/details/device-123?action=remoteShell&shellType=powershell
```

The component automatically handles URL parameters for deep-linking to specific actions, provides real-time status updates, and adapts the shell interface based on the device's operating system (Windows shows CMD/PowerShell options, others show bash).
