A comprehensive device details view component that displays device information, manages remote actions, and provides tabbed navigation for device management features.

## Key Components

- **Main View Container**: Uses `DetailPageContainer` with back navigation and header actions
- **Device Information**: Displays device status, last updated time, and detailed info section
- **Action Buttons**: Remote Control, Remote Shell (with Windows CMD/PowerShell dropdown), and File Manager
- **Modal Management**: Handles Scripts Modal and Remote Shell Modal states
- **Tab Navigation**: Implements tabbed interface for different device views (hardware, logs, etc.)
- **URL Parameter Handling**: Processes action parameters from URL for deep linking
- **Loading States**: Implements proper loading, error, and not found states

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

// Basic usage with device ID
function DevicePage({ params }: { params: { id: string } }) {
  return <DeviceDetailsView deviceId={params.id} />
}

// URL parameters supported for actions:
// /devices/details/123?action=runScript
// /devices/details/123?action=remoteShell&shellType=powershell
```

The component automatically fetches device data, handles OS-specific shell options (CMD/PowerShell for Windows, bash for others), and provides real-time updates with automatic refresh intervals. It integrates with the device action system to enable/disable actions based on agent availability.
