A React component that renders a comprehensive device details view with remote management actions, device information, and tabbed navigation for device monitoring and administration.

## Key Components

- **DeviceDetailsView**: Main component displaying device details with full-screen layout
- **Device Actions**: Remote control, shell access, and file management buttons with OS-specific shell selection
- **Device Info Section**: Displays comprehensive device information and specifications
- **Tab Navigation**: Provides tabbed interface for hardware, logs, and other device-related views
- **Scripts Modal**: Integrated script execution interface with device log access
- **URL Parameter Handling**: Supports direct navigation to specific actions via URL parameters

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

// Basic usage with device ID
function DevicePage({ params }: { params: { id: string } }) {
  return <DeviceDetailsView deviceId={params.id} />
}

// URL-triggered script execution
// Navigate to: /devices/details/device-123?action=runScript
// This will automatically open the scripts modal

// Programmatic navigation to specific tabs
function navigateToDeviceLogs(deviceId: string) {
  router.push(`/devices/details/${deviceId}?tab=logs&refresh=${Date.now()}`)
}
```

The component provides a complete device management interface with real-time status updates, OS-aware shell access (CMD/PowerShell for Windows, Bash for Unix), and integrated remote management tools. It handles loading states, error conditions, and URL-based action triggers for seamless navigation from device lists.
