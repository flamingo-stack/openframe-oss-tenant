A React component that displays comprehensive device details with remote management capabilities and tabbed navigation for device information.

## Key Components

- **Device Header**: Shows device name, status, and last updated time with back navigation
- **Action Buttons**: Remote Control, Remote Shell (with Windows CMD/PowerShell options), and File Manager
- **Device Info Section**: Displays basic device information and specifications  
- **Tab Navigation**: Provides tabbed interface for different device data views (hardware, logs, etc.)
- **Scripts Modal**: Allows running scripts on the device with logging capabilities
- **Actions Dropdown**: Additional device management actions in a dropdown menu

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

// Render device details page
function DevicePage({ params }: { params: { id: string } }) {
  return (
    <div className="container">
      <DeviceDetailsView deviceId={params.id} />
    </div>
  )
}

// Navigate with action parameter to trigger script modal
router.push(`/devices/details/${deviceId}?action=runScript`)
```

The component handles URL parameters for triggering actions, auto-refreshes relative timestamps, and provides different shell options based on the device's operating system (Windows vs. Unix-like systems).
