A React component that renders a comprehensive device details view with action buttons, tabbed content, and modal dialogs for device management tasks.

## Key Components

- **DeviceDetailsView** - Main component that displays device information, status, and management actions
- **Device Actions** - Remote control, remote shell (CMD/PowerShell for Windows), file manager, and scripts
- **Tab Navigation** - Hardware, logs, and other device-specific tabs
- **Modal Integrations** - Remote shell terminal and scripts execution modals
- **URL Parameter Handling** - Supports deep linking to specific actions (e.g., `?action=remoteShell&shellType=cmd`)
- **Real-time Updates** - Auto-refreshes relative timestamps every second

## Usage Example

```typescript
// Basic usage in a Next.js page
import { DeviceDetailsView } from './device-details-view'

export default function DeviceDetailsPage({ params }: { params: { id: string } }) {
  return <DeviceDetailsView deviceId={params.id} />
}

// With action parameter for direct script execution
const deviceUrl = `/devices/details/${deviceId}?action=runScript`

// With shell type parameter for direct remote access
const remoteShellUrl = `/devices/details/${deviceId}?action=remoteShell&shellType=powershell`
```

The component automatically detects the device OS type to show appropriate shell options (CMD/PowerShell for Windows, bash for Linux/macOS) and handles action availability based on installed agents (TacticalRMM for scripts, MeshCentral for remote access).
