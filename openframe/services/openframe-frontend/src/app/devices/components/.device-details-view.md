A React component that renders a comprehensive device details page with tabs, modals, and device management actions for the OpenFrame MSP platform.

## Key Components

- **DeviceDetailsView** - Main component displaying device information and management interface
- **URL-based action handling** - Processes query parameters to trigger modals (scripts, remote shell)
- **Dynamic shell type selection** - Windows devices show CMD/PowerShell dropdown, others use bash
- **TabNavigation integration** - Renders device tabs for hardware, logs, etc.
- **Modal management** - Controls ScriptsModal and RemoteShellModal state
- **Action availability system** - Determines which device actions are enabled based on agent availability

## Usage Example

```typescript
// Route handler usage
export default function DeviceDetailsPage({ params }: { params: { deviceId: string } }) {
  return <DeviceDetailsView deviceId={params.deviceId} />
}

// Navigation with actions
router.push(`/devices/details/${deviceId}?action=runScript`)
router.push(`/devices/details/${deviceId}?action=remoteShell&shellType=powershell`)

// Component renders with:
// - Device status and last updated timestamp
// - Action buttons (Remote Control, Remote Shell, Manage Files)
// - Tabbed interface for device details
// - Modal overlays for scripts and remote shell
```

The component integrates with the device management system to provide real-time status updates, cross-platform shell access, and comprehensive device action capabilities through a responsive interface.
