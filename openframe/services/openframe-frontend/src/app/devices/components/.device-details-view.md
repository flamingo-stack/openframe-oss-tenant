React component that renders a detailed device management view with remote control capabilities, action buttons, and tabbed content sections.

## Key Components

- **Main View**: Complete device details page with navigation and action buttons
- **Action Buttons**: Remote Control, Remote Shell (with Windows CMD/PowerShell dropdown), and Manage Files
- **Device Info Section**: Displays device status, last updated time, and basic information
- **Tab Navigation**: Hardware, logs, and other device-specific content tabs
- **Modal Integration**: Scripts modal and remote shell modal for device interactions
- **URL Action Handling**: Processes action parameters from URL for direct feature access

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

function DevicePage({ params }: { params: { id: string } }) {
  return (
    <div className="device-page">
      <DeviceDetailsView deviceId={params.id} />
    </div>
  )
}

// URL with action parameters
// /devices/details/123?action=runScript
// /devices/details/123?action=remoteShell&shellType=powershell
```

The component automatically handles device loading, error states, and provides a complete interface for device management including remote access, file management, and script execution capabilities.
