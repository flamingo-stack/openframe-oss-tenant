A comprehensive device details view component that displays device information with tabbed navigation, action buttons, and remote access capabilities for IT management.

## Key Components

- **DeviceDetailsView**: Main component that renders a detailed view of a single device with status, actions, and tabbed content
- **Device Actions**: Remote control, shell access (platform-specific), file management, and script execution
- **Tab System**: Hardware, software, logs, and other device-specific information tabs
- **Action Modals**: Scripts modal for running automation tasks on the device
- **Status Display**: Real-time device status with relative time updates

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

function DevicePage({ params }: { params: { id: string } }) {
  return (
    <div className="h-full">
      <DeviceDetailsView deviceId={params.id} />
    </div>
  )
}

// Supports URL navigation with actions
// Example: /devices/details/123?action=runScript
// Will automatically open the scripts modal
```

The component handles device loading states, error handling, and provides platform-aware shell options (CMD/PowerShell for Windows, Bash for Unix-like systems). It integrates with the OpenFrame frontend core for consistent UI components and device management workflows.
