React component that displays detailed information and management actions for a specific device in an IT management system. Provides comprehensive device control including remote access, shell commands, file management, and script execution.

## Key Components

- **DeviceDetailsView**: Main component handling device detail display and actions
- **Device Actions**: Remote control, shell access (CMD/PowerShell on Windows), file management buttons
- **Tab Navigation**: Tabbed interface for different device information views (hardware, logs, etc.)
- **Scripts Modal**: Interface for executing scripts on the device
- **Device Info Section**: Core device information display
- **Status Management**: Real-time device status updates with relative time formatting

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

// Render device details page
function DevicePage({ params }: { params: { deviceId: string } }) {
  return (
    <div className="container">
      <DeviceDetailsView deviceId={params.deviceId} />
    </div>
  )
}

// The component handles:
// - Loading device data by ID
// - URL parameter actions (e.g., ?action=runScript)
// - Platform-specific shell options (Windows: CMD/PowerShell, Linux: Bash)
// - Real-time status updates every second
// - Navigation between tabs and back to device list
```

The component integrates with the OpenFrame frontend core for consistent UI patterns and handles both Windows and Unix-like systems with appropriate shell interfaces. It supports URL-driven actions and maintains real-time updates for device status information.
