A React component that renders a comprehensive device details view with remote control capabilities, file management, and tabbed information display.

## Key Components

- **DeviceDetailsView**: Main component handling device detail display with action buttons and modals
- **Device Actions**: Remote control, shell access (CMD/PowerShell on Windows, bash on others), and file management buttons
- **Tab System**: Hardware, logs, and other device information tabs with URL synchronization
- **Scripts Modal**: Interface for running scripts on the selected device
- **Status Display**: Real-time device status with relative time updates

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

// Render device details page
function DevicePage({ params }: { params: { id: string } }) {
  return (
    <DeviceDetailsView deviceId={params.id} />
  )
}

// Handle URL action parameters (e.g., from table navigation)
// URL: /devices/details/123?action=runScript
// Will automatically open the scripts modal
```

The component supports URL-based actions, automatically refreshes relative timestamps, and provides platform-specific shell options. It integrates with the device management system to enable remote operations and script execution across different operating systems.
