A React component that renders a comprehensive device details view with remote management capabilities, tabs for different device information sections, and various device actions.

## Key Components

- **DeviceDetailsView** - Main component displaying device information and management options
- **Remote Actions** - Remote control, shell access, and file management buttons
- **Tab Navigation** - Hardware, software, logs, and other device information tabs
- **Action Modals** - Scripts execution and remote shell modals
- **Device Actions Dropdown** - Additional device management options

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

function DevicePage({ params }: { params: { id: string } }) {
  return (
    <div className="container">
      <DeviceDetailsView deviceId={params.id} />
    </div>
  )
}

// URL-based action triggering
// Navigate to: /devices/details/123?action=runScript
// Navigate to: /devices/details/123?action=remoteShell&shellType=powershell
```

The component supports URL parameter-based action triggering, automatically detects Windows devices for shell type selection (CMD/PowerShell), and provides real-time status updates with relative time formatting. It integrates with the OpenFrame platform's device management system and includes proper error handling for loading states and missing devices.
