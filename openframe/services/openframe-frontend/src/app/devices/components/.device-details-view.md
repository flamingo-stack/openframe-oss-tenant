A comprehensive React component that renders a detailed device management interface with remote access capabilities, device information display, and tabbed content organization.

## Key Components

- **DeviceDetailsView** - Main component managing device detail page state and navigation
- **Device Information Display** - Shows device status, last updated time, and core device details
- **Header Actions** - Remote control, shell access, file management, and actions dropdown
- **Modal Management** - Handles scripts execution and remote shell modals
- **Tab Navigation** - Organizes device data into structured tabs (hardware, logs, etc.)
- **URL Parameter Handling** - Supports deep linking to specific actions and tabs

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

// Render device details page
function DeviceDetailPage({ params }: { params: { id: string } }) {
  return <DeviceDetailsView deviceId={params.id} />
}

// Navigation with actions
router.push('/devices/details/device-123?action=runScript')
router.push('/devices/details/device-123?action=remoteShell&shellType=powershell')
```

The component integrates with OpenFrame's device management system, providing administrators with comprehensive device control including remote desktop, shell access, file management, and script execution capabilities. It automatically detects the operating system to provide appropriate shell options (CMD/PowerShell for Windows, bash for others) and maintains real-time status updates through periodic refresh intervals.
