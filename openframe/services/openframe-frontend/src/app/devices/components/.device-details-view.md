A React component that renders a detailed view page for a specific device, providing device information, action buttons, and tabbed content for hardware, software, and logs.

## Key Components

- **DeviceDetailsView** - Main component that orchestrates device detail display
- **useDeviceDetails** - Custom hook for fetching and managing device data
- **DeviceInfoSection** - Displays basic device information
- **TabNavigation/TabContent** - Handles tabbed interface for device details
- **RemoteShellModal** - Modal for remote shell access
- **ScriptsModal** - Modal for running scripts on the device
- **DeviceActionsDropdown** - Dropdown menu for additional device actions

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

function DevicePage({ params }: { params: { id: string } }) {
  return (
    <div>
      <DeviceDetailsView deviceId={params.id} />
    </div>
  )
}
```

The component automatically handles:
- Device data fetching and loading states
- URL parameter-based action triggering (scripts, remote shell)
- Cross-platform shell type selection (CMD/PowerShell for Windows, Bash for others)
- Tab-based navigation with URL synchronization
- Real-time relative timestamp updates
- Action availability based on agent connectivity

Key features include remote control access, file management, script execution, and remote shell capabilities with platform-specific shell type selection.
