A React component that renders a comprehensive device details view with remote management capabilities, tab navigation, and action controls for OpenFrame's device management system.

## Key Components

- **DeviceDetailsView** - Main component displaying device information, status, and management actions
- **Header Actions** - Remote control, shell access, file management, and dropdown menu for additional actions
- **Device Info Section** - Displays device details and current status with real-time updates
- **Tab Navigation** - Tabbed interface for different device information views (hardware, logs, etc.)
- **Scripts Modal** - Modal for running scripts on the selected device
- **Action Availability** - Dynamic enabling/disabling of actions based on device capabilities

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

function DevicePage({ params }: { params: { deviceId: string } }) {
  return (
    <DeviceDetailsView deviceId={params.deviceId} />
  )
}

// Handle URL action parameters for deep linking
// Example: /devices/details/123?action=runScript
// This will automatically open the scripts modal
```

The component automatically handles URL-based actions, real-time status updates, OS-specific shell options (CMD/PowerShell for Windows, Bash for others), and provides a comprehensive device management interface with back navigation to the devices list.
