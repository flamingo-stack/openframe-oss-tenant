A comprehensive React component that renders a detailed device view page with tabs, action buttons, and modal interfaces for device management operations.

## Key Components

- **DeviceDetailsView**: Main component that displays device information, status, and management controls
- **DeviceInfoSection**: Shows basic device information and status
- **TabNavigation/TabContent**: Provides tabbed interface for different device views (hardware, software, etc.)
- **ScriptsModal**: Modal for running scripts on the device
- **RemoteShellModal**: Modal for remote shell access (CMD/PowerShell for Windows, bash for others)
- **DeviceActionsDropdown**: Dropdown menu with additional device actions
- **Action buttons**: Remote Control, Remote Shell, and Manage Files with conditional availability

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

function DeviceDetailsPage({ params }: { params: { id: string } }) {
  return (
    <div className="min-h-screen">
      <DeviceDetailsView deviceId={params.id} />
    </div>
  )
}

// Handle URL actions (e.g., from device table)
// URL: /devices/details/123?action=runScript
// URL: /devices/details/123?action=remoteShell&shellType=powershell
```

The component automatically handles URL parameters for triggering actions, provides OS-specific shell options for Windows devices, and manages modal states for various device operations. It uses the device details hook for data fetching and includes real-time relative timestamp updates.
