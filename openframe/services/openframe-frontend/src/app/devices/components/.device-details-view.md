A React component that displays comprehensive device details with interactive actions and tabbed navigation for device management in the Flamingo Stack MSP platform.

## Key Components

- **DeviceDetailsView** - Main component for displaying device information with actions
- **Device action buttons** - Remote Control, Remote Shell, File Manager with conditional OS-specific options
- **Modal integrations** - RemoteShellModal and ScriptsModal for device interactions
- **Tab navigation** - Hardware, logs, and other device-specific tabs
- **URL parameter handling** - Supports deep linking to specific actions and tabs
- **Real-time updates** - Auto-refreshing relative timestamps and device status

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

// In a Next.js page component
export default function DeviceDetailsPage({ params }: { params: { id: string } }) {
  return <DeviceDetailsView deviceId={params.id} />
}

// URL navigation examples:
// /devices/details/device-123 - Basic device view
// /devices/details/device-123?action=runScript - Opens scripts modal
// /devices/details/device-123?action=remoteShell&shellType=powershell - Opens PowerShell
// /devices/details/device-123?tab=logs&refresh=1234567890 - Shows logs tab
```

The component handles OS detection for Windows-specific shell options (CMD/PowerShell vs bash), manages device action availability based on agent connectivity, and provides a responsive interface that hides content when shell modals are active.
