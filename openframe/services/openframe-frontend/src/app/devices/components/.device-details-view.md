React component that renders a comprehensive device details page with remote management capabilities and tabbed content organization.

## Key Components

- **Device Details View**: Main component displaying device information, status, and management actions
- **Action Buttons**: Remote control, shell access (CMD/PowerShell for Windows, bash for Linux), and file management
- **Modal Management**: Handles scripts execution and remote shell access modals
- **Tab Navigation**: Organizes device information into tabbed sections (hardware, logs, etc.)
- **URL Parameter Handling**: Processes action parameters for deep linking and navigation
- **Real-time Updates**: Auto-refreshes relative timestamps every second

## Usage Example

```typescript
import { DeviceDetailsView } from './device-details-view'

// Render device details page
function DevicePage({ params }: { params: { id: string } }) {
  return <DeviceDetailsView deviceId={params.id} />
}

// URL examples that trigger actions:
// /devices/details/123?action=runScript - Opens scripts modal
// /devices/details/123?action=remoteShell&shellType=powershell - Opens PowerShell
```

The component automatically detects the device OS type to show appropriate shell options (CMD/PowerShell for Windows, bash for Linux) and manages action availability based on agent connectivity status. It integrates with the tab system for organizing detailed device information and provides a consistent interface for device management operations.
