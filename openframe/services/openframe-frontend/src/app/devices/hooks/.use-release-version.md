A React Query hook for fetching and managing the current release version from the Flamingo API with built-in error handling and caching.

## Key Components

- **`useReleaseVersion`** - Main hook that fetches release version data with configurable options
- **`fetchReleaseVersion`** - Async function that calls the `/api/release-version` endpoint 
- **`releaseVersionQueryKeys`** - Query key factory for consistent cache management
- **`UseReleaseVersionOptions`** - Interface for hook configuration options
- **`ReleaseVersionResponse`** - Type definition for API response structure

## Usage Example

```typescript
import { useReleaseVersion } from './use-release-version'

function VersionDisplay() {
  const { releaseVersion, isLoading, error, refetch } = useReleaseVersion()

  if (isLoading) return <div>Loading version...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <span>Current Version: {releaseVersion}</span>
      <button onClick={() => refetch()}>Refresh</button>
    </div>
  )
}

// Disable automatic fetching
function ConditionalVersion() {
  const { releaseVersion, refetch } = useReleaseVersion({ 
    enabled: false 
  })
  
  return (
    <button onClick={() => refetch()}>
      Load Version ({releaseVersion})
    </button>
  )
}
```

The hook includes automatic error toast notifications, 5-minute cache staleness, and returns both the release version data and query state for flexible UI handling.
