A React hook that fetches and manages the current release version from the API with automatic error handling and caching.

## Key Components

- **`useReleaseVersion`** - Main hook that returns release version data and loading states
- **`fetchReleaseVersion`** - API client function that retrieves the release version from `/api/release-version`
- **`releaseVersionQueryKeys`** - Query key factory for React Query cache management
- **`UseReleaseVersionOptions`** - Configuration interface with optional `enabled` flag

## Usage Example

```typescript
import { useReleaseVersion } from './use-release-version'

function VersionDisplay() {
  const { releaseVersion, isLoading, error, refetch } = useReleaseVersion({
    enabled: true // Optional: control when query runs
  })

  if (isLoading) return <div>Loading version...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <span>Current Version: {releaseVersion}</span>
      <button onClick={() => refetch()}>Refresh</button>
    </div>
  )
}

// Disable query initially
function ConditionalVersion() {
  const { releaseVersion, refetch } = useReleaseVersion({ 
    enabled: false 
  })
  
  return (
    <button onClick={() => refetch()}>
      Load Version: {releaseVersion}
    </button>
  )
}
```

The hook automatically displays error toasts on failures, caches data for 5 minutes, and falls back to 'latest' when no version is available.
