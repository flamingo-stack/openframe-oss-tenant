A React Query hook for fetching and managing the current release version from the OpenFrame API, with automatic error handling and toast notifications.

## Key Components

- **`useReleaseVersion`** - Main hook that fetches the current release version with caching and error handling
- **`releaseVersionQueryKeys`** - Query key factory following React Query best practices for cache management
- **`fetchReleaseVersion`** - Internal API client function that retrieves release version data
- **`UseReleaseVersionOptions`** - Configuration interface for controlling query behavior
- **`ReleaseVersionResponse`** - Type definition for the API response structure

## Usage Example

```typescript
import { useReleaseVersion } from './use-release-version'

function VersionDisplay() {
  // Basic usage with default options
  const { releaseVersion, isLoading, error } = useReleaseVersion()
  
  if (isLoading) return <div>Loading version...</div>
  if (error) return <div>Error: {error}</div>
  
  return <div>Current Version: {releaseVersion}</div>
}

function ConditionalVersionFetch() {
  // Disable query until user action
  const [shouldFetch, setShouldFetch] = useState(false)
  const { releaseVersion, refetch } = useReleaseVersion({ 
    enabled: shouldFetch 
  })
  
  return (
    <div>
      <button onClick={() => setShouldFetch(true)}>
        Check Version
      </button>
      <span>Version: {releaseVersion}</span>
    </div>
  )
}
```

The hook automatically caches results for 5 minutes, retries failed requests twice, and displays error toasts when enabled. It returns 'latest' as a fallback when the API call fails or returns empty data.
