A React hook that fetches and manages the current release version using TanStack Query with error handling and toast notifications.

## Key Components

- **`useReleaseVersion`** - Main hook that fetches and returns release version data
- **`releaseVersionQueryKeys`** - Query key factory for consistent cache management
- **`fetchReleaseVersion`** - API function that retrieves release version from `/api/release-version`
- **`ReleaseVersionResponse`** - Type definition for the API response structure
- **`UseReleaseVersionOptions`** - Configuration interface with `enabled` flag

## Usage Example

```typescript
import { useReleaseVersion } from '@/hooks/use-release-version'

function AppVersionDisplay() {
  const { 
    releaseVersion, 
    isLoading, 
    error,
    refetch 
  } = useReleaseVersion()

  if (isLoading) return <div>Loading version...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <span>Version: {releaseVersion}</span>
      <button onClick={() => refetch()}>
        Refresh Version
      </button>
    </div>
  )
}

// With options
function ConditionalVersionCheck() {
  const [shouldFetch, setShouldFetch] = useState(false)
  
  const { releaseVersion } = useReleaseVersion({ 
    enabled: shouldFetch 
  })

  return (
    <button onClick={() => setShouldFetch(true)}>
      Load Version: {releaseVersion}
    </button>
  )
}
```

The hook includes automatic caching (5-minute stale time), retry logic, and error toast notifications. It defaults to "latest" if no version is returned from the API.
