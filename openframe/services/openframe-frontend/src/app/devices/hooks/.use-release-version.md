A React Query hook for fetching and managing the current release version from the API, providing automatic error handling and toast notifications.

## Key Components

- **`releaseVersionQueryKeys`** - Query key factory for consistent caching across components
- **`fetchReleaseVersion()`** - Async function that retrieves release version from `/api/release-version` endpoint
- **`useReleaseVersion()`** - Main hook that wraps React Query with error handling and toast notifications
- **`UseReleaseVersionOptions`** - Configuration interface for enabling/disabling the query

## Usage Example

```typescript
import { useReleaseVersion } from './hooks/use-release-version'

function AppHeader() {
  const { 
    releaseVersion, 
    isLoading, 
    error,
    refetch 
  } = useReleaseVersion()

  if (isLoading) return <div>Loading version...</div>
  
  return (
    <div>
      <span>Version: {releaseVersion}</span>
      {error && (
        <button onClick={() => refetch()}>
          Retry
        </button>
      )}
    </div>
  )
}

// Conditionally enabled query
function ConditionalVersionCheck({ shouldCheck }: { shouldCheck: boolean }) {
  const { releaseVersion } = useReleaseVersion({ 
    enabled: shouldCheck 
  })
  
  return <span>{releaseVersion}</span>
}
```

The hook includes automatic caching (5-minute stale time), retry logic (2 attempts), and displays error toasts when the API call fails. It gracefully falls back to `'latest'` when no version is available.
