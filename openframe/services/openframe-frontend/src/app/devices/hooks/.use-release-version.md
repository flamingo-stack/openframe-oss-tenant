A React hook that fetches and manages the current release version from the API, providing automatic error handling and toast notifications.

## Key Components

- **`useReleaseVersion`** - Main hook that fetches release version with React Query
- **`releaseVersionQueryKeys`** - Query key factory for consistent cache management
- **`fetchReleaseVersion`** - Async function that retrieves version from `/api/release-version`
- **`UseReleaseVersionOptions`** - Configuration interface for enabling/disabling the query
- **`ReleaseVersionResponse`** - Type definition for the API response structure

## Usage Example

```typescript
import { useReleaseVersion } from './use-release-version'

function VersionDisplay() {
  const { 
    releaseVersion, 
    isLoading, 
    error, 
    refetch 
  } = useReleaseVersion()

  if (isLoading) return <div>Loading version...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <span>Version: {releaseVersion}</span>
      <button onClick={() => refetch()}>
        Refresh Version
      </button>
    </div>
  )
}

// Conditionally enabled query
function ConditionalVersion({ shouldFetch }: { shouldFetch: boolean }) {
  const { releaseVersion } = useReleaseVersion({ 
    enabled: shouldFetch 
  })
  
  return <span>{releaseVersion}</span>
}
```

The hook automatically caches results for 5 minutes, implements retry logic, and displays error toasts when requests fail. It returns "latest" as a fallback when no version is available.
