A React hook for fetching and managing the current application release version using TanStack Query, with error handling and toast notifications.

## Key Components

- **`useReleaseVersion`** - Main hook that fetches and returns the current release version
- **`releaseVersionQueryKeys`** - Query key factory for cache management and invalidation
- **`fetchReleaseVersion`** - Internal API function that retrieves version data from `/api/release-version`
- **`UseReleaseVersionOptions`** - Configuration interface for enabling/disabling the query
- **`ReleaseVersionResponse`** - Type definition for the API response structure

## Usage Example

```typescript
import { useReleaseVersion } from './use-release-version'

function AppHeader() {
  // Basic usage - automatically fetches on mount
  const { releaseVersion, isLoading, error } = useReleaseVersion()

  // Conditional fetching
  const { releaseVersion: conditionalVersion } = useReleaseVersion({
    enabled: someCondition
  })

  if (isLoading) return <div>Loading version...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <header>
      <h1>App v{releaseVersion}</h1>
    </header>
  )
}

// Manual refetch example
function VersionChecker() {
  const { releaseVersion, refetch, isFetching } = useReleaseVersion()

  return (
    <div>
      <p>Current: {releaseVersion}</p>
      <button onClick={() => refetch()} disabled={isFetching}>
        Check for Updates
      </button>
    </div>
  )
}
```

The hook provides comprehensive query state management with automatic error toasts, caching (5min stale time), and fallback to 'latest' when version data is unavailable.
