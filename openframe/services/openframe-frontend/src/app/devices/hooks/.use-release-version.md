A React hook that fetches and manages the current release version from the API with automatic error handling and caching.

## Key Components

- **`useReleaseVersion`** - Main hook that returns release version data with loading states
- **`fetchReleaseVersion`** - Async function that fetches version from `/api/release-version` endpoint
- **`releaseVersionQueryKeys`** - Query key factory for React Query caching
- **`ReleaseVersionResponse`** - Type definition for API response structure
- **`UseReleaseVersionOptions`** - Configuration options interface with optional `enabled` flag

## Usage Example

```typescript
import { useReleaseVersion } from './use-release-version'

function ReleaseInfo() {
  const { 
    releaseVersion, 
    isLoading, 
    error,
    refetch 
  } = useReleaseVersion()
  
  if (isLoading) return <div>Loading version...</div>
  if (error) return <div>Error: {error}</div>
  
  return (
    <div>
      <p>Current Version: {releaseVersion}</p>
      <button onClick={() => refetch()}>Refresh</button>
    </div>
  )
}

// Conditionally enabled query
function ConditionalVersion({ shouldFetch }: { shouldFetch: boolean }) {
  const { releaseVersion } = useReleaseVersion({ 
    enabled: shouldFetch 
  })
  
  return <span>Version: {releaseVersion}</span>
}
```

The hook includes built-in error toasts, 5-minute cache staleness, automatic retries, and fallback to 'latest' when no version is returned.
