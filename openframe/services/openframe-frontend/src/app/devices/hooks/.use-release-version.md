A React hook for fetching and managing the current release version from the API, with automatic error handling and caching capabilities.

## Key Components

- **`useReleaseVersion`** - Main hook that returns release version data with loading states
- **`releaseVersionQueryKeys`** - Query key factory for consistent cache management  
- **`fetchReleaseVersion`** - Internal API function that retrieves version from `/api/release-version`
- **`ReleaseVersionResponse`** - Type definition for the API response structure
- **`UseReleaseVersionOptions`** - Configuration interface with enabled/disabled control

## Usage Example

```typescript
import { useReleaseVersion } from './use-release-version'

function AppVersionDisplay() {
  const { 
    releaseVersion, 
    isLoading, 
    error, 
    refetch 
  } = useReleaseVersion()

  if (isLoading) return <div>Loading version...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <span>Version: {releaseVersion}</span>
      <button onClick={() => refetch()}>Refresh</button>
    </div>
  )
}

// Conditionally enabled query
function ConditionalVersion({ shouldFetch }: { shouldFetch: boolean }) {
  const { releaseVersion } = useReleaseVersion({ 
    enabled: shouldFetch 
  })
  
  return <span>{releaseVersion}</span>
}
```

The hook includes built-in error toasting, 5-minute cache staleness, and fallback to 'latest' when the API is unavailable.
