A React Query hook that fetches and manages the current application release version from the `/api/release-version` endpoint, with automatic error handling and toast notifications.

## Key Components

- **`useReleaseVersion`** - Main hook that fetches and returns the release version data
- **`releaseVersionQueryKeys`** - Query key factory for React Query cache management
- **`fetchReleaseVersion`** - Async function that makes the API call to retrieve release version
- **`UseReleaseVersionOptions`** - Interface for hook configuration options
- **`ReleaseVersionResponse`** - Type definition for the API response structure

## Usage Example

```typescript
import { useReleaseVersion } from './use-release-version'

function AppVersionDisplay() {
  const { 
    releaseVersion, 
    isLoading, 
    error,
    refetch 
  } = useReleaseVersion()

  if (isLoading) return <div>Loading version...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <span>Version: {releaseVersion}</span>
      <button onClick={() => refetch()}>Refresh</button>
    </div>
  )
}

// Disable automatic fetching
function ConditionalVersionCheck() {
  const { releaseVersion, refetch } = useReleaseVersion({ 
    enabled: false 
  })

  return (
    <button onClick={() => refetch()}>
      Check Version ({releaseVersion})
    </button>
  )
}
```

The hook includes automatic retry logic, caching with 5-minute stale time, and displays error toasts when version fetching fails. Returns `'latest'` as fallback when no version is available.
