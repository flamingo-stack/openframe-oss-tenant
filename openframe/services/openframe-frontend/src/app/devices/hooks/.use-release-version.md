A React Query hook for fetching and managing the current release version from the API, with built-in caching, error handling, and toast notifications.

## Key Components

- **`releaseVersionQueryKeys`** - Query key factory for React Query cache management
- **`fetchReleaseVersion()`** - Async function that fetches release version from `/api/release-version` endpoint
- **`useReleaseVersion()`** - Main hook that provides release version data with caching and error handling
- **`UseReleaseVersionOptions`** - Interface for hook configuration options
- **`ReleaseVersionResponse`** - Type definition for API response structure

## Usage Example

```typescript
import { useReleaseVersion } from '@/hooks/use-release-version'

function AppHeader() {
  const { releaseVersion, isLoading, error } = useReleaseVersion()
  
  // Conditionally enable the query
  const { releaseVersion: onDemandVersion } = useReleaseVersion({ 
    enabled: false 
  })
  
  if (isLoading) {
    return <div>Loading version...</div>
  }
  
  return (
    <header>
      <h1>App v{releaseVersion}</h1>
      {error && <span className="error">Failed to load version</span>}
    </header>
  )
}
```

The hook automatically caches data for 5 minutes, retries failed requests twice, and shows error toasts when enabled. It returns 'latest' as a fallback when the API response is empty or invalid.
