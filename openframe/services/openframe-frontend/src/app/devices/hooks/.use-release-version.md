A React Query hook for fetching the current release version from the API with error handling and caching.

## Key Components

- **`useReleaseVersion`** - Main hook that fetches and manages release version state
- **`fetchReleaseVersion`** - Async function that makes the API request to `/api/release-version`
- **`releaseVersionQueryKeys`** - Query key factory for consistent cache management
- **`UseReleaseVersionOptions`** - Configuration interface with `enabled` option
- **`ReleaseVersionResponse`** - Type definition for API response structure

## Usage Example

```typescript
import { useReleaseVersion } from './use-release-version'

function VersionDisplay() {
  const { releaseVersion, isLoading, error, refetch } = useReleaseVersion()

  if (isLoading) return <div>Loading version...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      Current Version: {releaseVersion}
      <button onClick={() => refetch()}>Refresh</button>
    </div>
  )
}

// Conditionally enabled query
function ConditionalVersion({ shouldFetch }: { shouldFetch: boolean }) {
  const { releaseVersion } = useReleaseVersion({ 
    enabled: shouldFetch 
  })
  
  return <span>Version: {releaseVersion}</span>
}
```

The hook includes built-in error toasts, 5-minute stale time, automatic retries, and falls back to `'latest'` when the version is unavailable. It exposes both simplified state (`releaseVersion`, `isLoading`, `error`) and the full React Query object for advanced use cases.
