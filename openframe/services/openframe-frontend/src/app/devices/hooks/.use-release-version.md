A React hook that fetches and manages the current release version of the application using TanStack Query with error handling and toast notifications.

## Key Components

- **`useReleaseVersion`** - Main hook for fetching release version data with caching and error handling
- **`releaseVersionQueryKeys`** - Query key factory for cache management and invalidation
- **`fetchReleaseVersion`** - Async function that retrieves release version from the API endpoint
- **`ReleaseVersionResponse`** - Type definition for the API response structure
- **`UseReleaseVersionOptions`** - Configuration interface for controlling query behavior

## Usage Example

```typescript
import { useReleaseVersion } from './use-release-version'

function AppVersion() {
  // Basic usage with default options
  const { releaseVersion, isLoading, error } = useReleaseVersion()

  // Conditional fetching
  const { releaseVersion: version, refetch } = useReleaseVersion({
    enabled: false // Disable automatic fetching
  })

  if (isLoading) {
    return <div>Loading version...</div>
  }

  if (error) {
    return <div>Error: {error}</div>
  }

  return (
    <div>
      <p>Current Version: {releaseVersion}</p>
      <button onClick={() => refetch()}>Refresh Version</button>
    </div>
  )
}
```

The hook automatically handles caching (5-minute stale time), retries failed requests, and displays error notifications through the toast system. It returns 'latest' as a fallback when the version cannot be determined.
