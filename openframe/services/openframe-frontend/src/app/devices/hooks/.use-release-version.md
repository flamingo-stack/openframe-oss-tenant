A React Query hook for fetching the current release version from the OpenFrame API, with built-in error handling and toast notifications.

## Key Components

- **`releaseVersionQueryKeys`** - Query key factory for consistent cache management
- **`fetchReleaseVersion()`** - API function that retrieves release version from `/api/release-version` endpoint
- **`useReleaseVersion()`** - Main hook that manages release version state with React Query
- **`UseReleaseVersionOptions`** - Configuration interface for enabling/disabling the query

## Usage Example

```typescript
import { useReleaseVersion } from './use-release-version'

function VersionDisplay() {
  // Basic usage - fetches immediately
  const { releaseVersion, isLoading, error } = useReleaseVersion()

  // Conditional fetching
  const { releaseVersion: conditionalVersion } = useReleaseVersion({
    enabled: userIsAuthenticated
  })

  if (isLoading) return <div>Loading version...</div>
  if (error) return <div>Error: {error}</div>

  return <div>Current Version: {releaseVersion}</div>
}

// Manual refetch
function RefreshButton() {
  const { refetch } = useReleaseVersion()
  
  return (
    <button onClick={() => refetch()}>
      Refresh Version
    </button>
  )
}
```

The hook automatically displays error toasts when requests fail, caches data for 5 minutes, and falls back to 'latest' if no version is returned.
