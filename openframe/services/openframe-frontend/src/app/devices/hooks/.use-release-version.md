Custom React hook for fetching and managing application release version data using React Query with automatic error handling and toast notifications.

## Key Components

- **`useReleaseVersion(options?)`** - Main hook that fetches release version data with configurable options
- **`releaseVersionQueryKeys`** - Query key factory for React Query cache management
- **`fetchReleaseVersion()`** - API function that retrieves release version from `/api/release-version` endpoint
- **`UseReleaseVersionOptions`** - Interface for hook configuration with optional `enabled` flag
- **`ReleaseVersionResponse`** - Type definition for API response structure

## Usage Example

```typescript
import { useReleaseVersion } from './use-release-version'

function AppHeader() {
  // Basic usage - auto-fetches on mount
  const { releaseVersion, isLoading, error } = useReleaseVersion()
  
  // Conditional fetching
  const { releaseVersion: conditionalVersion } = useReleaseVersion({ 
    enabled: false // Disable auto-fetch
  })

  if (isLoading) return <div>Loading version...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <header>
      <h1>OpenFrame v{releaseVersion}</h1>
    </header>
  )
}

// Access full query object for advanced use cases
function AdvancedVersionCheck() {
  const { query, refetch } = useReleaseVersion()
  
  return (
    <div>
      <span>Version: {query.data || 'latest'}</span>
      <button onClick={() => refetch()}>Refresh</button>
    </div>
  )
}
```

The hook automatically handles error states with toast notifications, implements caching with 5-minute stale time, and provides both simple data access and full React Query functionality.
