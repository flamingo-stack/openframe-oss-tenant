A React Query hook for fetching and managing the current release version from the API, with automatic error handling and caching.

## Key Components

- **`useReleaseVersion`** - Main hook that fetches release version data with React Query
- **`releaseVersionQueryKeys`** - Query key factory for cache management and invalidation
- **`fetchReleaseVersion`** - Async function that handles the API call to retrieve version information
- **`UseReleaseVersionOptions`** - Configuration interface for enabling/disabling the query
- **`ReleaseVersionResponse`** - Type definition for the API response structure

## Usage Example

```typescript
import { useReleaseVersion } from '@/hooks/use-release-version'

function VersionDisplay() {
  const { releaseVersion, isLoading, error, refetch } = useReleaseVersion()

  if (isLoading) {
    return <div>Loading version...</div>
  }

  if (error) {
    return <div>Error: {error}</div>
  }

  return (
    <div>
      <p>Current Version: {releaseVersion}</p>
      <button onClick={() => refetch()}>Refresh</button>
    </div>
  )
}

// Conditionally fetch version
function ConditionalVersionCheck() {
  const { releaseVersion } = useReleaseVersion({ 
    enabled: someCondition 
  })

  return <span>Version: {releaseVersion}</span>
}
```

The hook provides automatic caching (5-minute stale time), error handling with toast notifications, and returns a fallback "latest" value when no version is available.
