A React hook that fetches and manages the current release version from the API, providing caching and error handling for version-dependent features.

## Key Components

- **`useReleaseVersion`** - Main hook that fetches release version with React Query caching
- **`releaseVersionQueryKeys`** - Query key factory for consistent cache management
- **`fetchReleaseVersion`** - API function that retrieves version from `/api/release-version` endpoint
- **`UseReleaseVersionOptions`** - Configuration interface with `enabled` flag for conditional queries
- **`ReleaseVersionResponse`** - Type definition for API response structure

## Usage Example

```typescript
import { useReleaseVersion } from './use-release-version'

// Basic usage - always fetch version
function VersionBanner() {
  const { releaseVersion, isLoading } = useReleaseVersion()
  
  if (isLoading) return <div>Loading version...</div>
  
  return <div>Current Version: {releaseVersion}</div>
}

// Conditional fetching based on user permissions
function AdminPanel({ userCanViewVersion }: { userCanViewVersion: boolean }) {
  const { releaseVersion, error, refetch } = useReleaseVersion({
    enabled: userCanViewVersion
  })
  
  if (error) {
    return (
      <div>
        Version unavailable 
        <button onClick={() => refetch()}>Retry</button>
      </div>
    )
  }
  
  return userCanViewVersion ? (
    <span>v{releaseVersion}</span>
  ) : null
}
```

The hook automatically handles caching (5-minute stale time), retries failed requests, and displays toast notifications for errors. Returns 'latest' as fallback when version data is unavailable.
