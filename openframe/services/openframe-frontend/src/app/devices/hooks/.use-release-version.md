A React hook that fetches and manages the current application release version using TanStack Query with built-in error handling and toast notifications.

## Key Components

- **`useReleaseVersion`** - Main hook for fetching release version data with caching and error handling
- **`releaseVersionQueryKeys`** - Query key factory for consistent cache management
- **`fetchReleaseVersion`** - API function that retrieves the release version from `/api/release-version`
- **`UseReleaseVersionOptions`** - Configuration interface with optional `enabled` flag

## Usage Example

```typescript
import { useReleaseVersion } from './use-release-version'

function AppVersionDisplay() {
  const { releaseVersion, isLoading, error } = useReleaseVersion()
  
  if (isLoading) return <div>Loading version...</div>
  if (error) return <div>Version unavailable</div>
  
  return <div>Version: {releaseVersion}</div>
}

// With conditional fetching
function ConditionalVersionCheck() {
  const [shouldCheck, setShouldCheck] = useState(false)
  
  const { releaseVersion, refetch } = useReleaseVersion({ 
    enabled: shouldCheck 
  })
  
  return (
    <div>
      <button onClick={() => setShouldCheck(true)}>
        Check Version
      </button>
      <span>Current: {releaseVersion}</span>
    </div>
  )
}
```

The hook includes automatic caching (5-minute stale time), retry logic, and error toast notifications for improved user experience.
