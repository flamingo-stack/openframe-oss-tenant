React Query hook for fetching and managing the application's release version with error handling and toast notifications.

## Key Components

- **`useReleaseVersion`** - Main hook that fetches release version data with React Query
- **`fetchReleaseVersion`** - Async function that calls the release version API endpoint
- **`releaseVersionQueryKeys`** - Query key factory for consistent cache management
- **`UseReleaseVersionOptions`** - Interface for hook configuration options
- **`ReleaseVersionResponse`** - Type definition for the API response structure

## Usage Example

```typescript
import { useReleaseVersion } from './use-release-version'

function AppVersionDisplay() {
  // Basic usage with default options
  const { releaseVersion, isLoading, error } = useReleaseVersion()

  // Disabled query that can be enabled later
  const versionQuery = useReleaseVersion({ enabled: false })

  if (isLoading) return <div>Loading version...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <p>Current Version: {releaseVersion}</p>
      <button onClick={() => versionQuery.refetch()}>
        Refresh Version
      </button>
    </div>
  )
}
```

The hook automatically displays error toasts when requests fail, caches data for 5 minutes, and falls back to 'latest' when no version is returned. It includes comprehensive loading states and manual refetch capabilities for dynamic version checking.
