React hook for fetching and managing the current application release version from the API. Provides automatic error handling with toast notifications and caching via React Query.

## Key Components

- **`useReleaseVersion`** - Main hook that fetches release version data with configurable options
- **`releaseVersionQueryKeys`** - Query key factory for React Query cache management
- **`fetchReleaseVersion`** - Async function that retrieves release version from `/api/release-version`
- **`UseReleaseVersionOptions`** - Interface for hook configuration options
- **`ReleaseVersionResponse`** - Type definition for API response structure

## Usage Example

```typescript
import { useReleaseVersion } from './use-release-version'

function AppHeader() {
  // Basic usage - automatically fetches on mount
  const { releaseVersion, isLoading, error } = useReleaseVersion()

  // With options - disabled until manually enabled
  const { 
    releaseVersion: version, 
    refetch, 
    isSuccess 
  } = useReleaseVersion({ enabled: false })

  if (isLoading) return <div>Loading version...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <span>Version: {releaseVersion}</span>
      <button onClick={() => refetch()}>
        Refresh Version
      </button>
    </div>
  )
}
```

The hook automatically displays error toasts, caches results for 5 minutes, and falls back to `'latest'` if no version is returned. Uses React Query for efficient data fetching with retry logic and garbage collection.
