A React Query hook that fetches and manages the current release version from the Flamingo API with error handling and toast notifications.

## Key Components

- **`useReleaseVersion`** - Main hook for fetching release version data
- **`fetchReleaseVersion`** - Async function that calls the `/api/release-version` endpoint
- **`releaseVersionQueryKeys`** - Standardized query key factory for React Query caching
- **`UseReleaseVersionOptions`** - Configuration interface for enabling/disabling the query
- **`ReleaseVersionResponse`** - Type definition for the API response structure

## Usage Example

```typescript
import { useReleaseVersion } from './use-release-version'

function AppHeader() {
  const { 
    releaseVersion, 
    isLoading, 
    error,
    refetch 
  } = useReleaseVersion()

  if (isLoading) {
    return <div>Loading version...</div>
  }

  return (
    <header>
      <h1>Flamingo v{releaseVersion}</h1>
      {error && (
        <button onClick={() => refetch()}>
          Retry loading version
        </button>
      )}
    </header>
  )
}

// Disable automatic fetching
function ConditionalVersion({ shouldLoad }: { shouldLoad: boolean }) {
  const { releaseVersion } = useReleaseVersion({ enabled: shouldLoad })
  
  return <span>Version: {releaseVersion}</span>
}
```

The hook automatically handles caching (5-minute stale time), retries failed requests twice, and displays error toasts when version fetching fails. It returns 'latest' as a fallback when no version is available.
