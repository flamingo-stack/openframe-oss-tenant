A React hook that fetches and manages the current release version from the API using TanStack Query, with built-in error handling and toast notifications.

## Key Components

**Main Export:**
- `useReleaseVersion()` - Hook that fetches the release version with configurable options

**Supporting Exports:**
- `releaseVersionQueryKeys` - Typed query key factory for cache management
- `fetchReleaseVersion()` - Async function that handles the API request

**Types:**
- `ReleaseVersionResponse` - API response shape
- `UseReleaseVersionOptions` - Hook configuration options

## Usage Example

```typescript
import { useReleaseVersion } from './use-release-version'

function AppHeader() {
  const { 
    releaseVersion, 
    isLoading, 
    error,
    refetch 
  } = useReleaseVersion()

  if (isLoading) {
    return <div>Loading version...</div>
  }

  return (
    <div>
      <h1>OpenFrame v{releaseVersion}</h1>
      {error && (
        <button onClick={() => refetch()}>
          Retry loading version
        </button>
      )}
    </div>
  )
}

// Disable automatic fetching
function ConditionalVersion() {
  const { releaseVersion } = useReleaseVersion({ 
    enabled: false 
  })
  
  return <span>{releaseVersion}</span> // Shows 'latest' by default
}
```

The hook includes automatic retry logic, 5-minute cache duration, and fallback to 'latest' when the API is unavailable.
