A React hook that fetches and manages the current release version from the OpenFrame API with built-in error handling and caching.

## Key Components

### Functions
- **`fetchReleaseVersion()`** - Async function that fetches release version from `/api/release-version` endpoint
- **`useReleaseVersion(options)`** - Main hook that manages release version state with React Query

### Types
- **`ReleaseVersionResponse`** - API response type containing optional `releaseVersion` string
- **`UseReleaseVersionOptions`** - Configuration options with `enabled` flag for conditional fetching

### Constants
- **`releaseVersionQueryKeys`** - TanStack Query key factory for consistent cache management

## Usage Example

```typescript
import { useReleaseVersion } from './use-release-version'

function VersionDisplay() {
  const { releaseVersion, isLoading, error, refetch } = useReleaseVersion()

  if (isLoading) return <div>Loading version...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <p>Current Release: {releaseVersion}</p>
      <button onClick={() => refetch()}>Refresh Version</button>
    </div>
  )
}

// Conditional fetching
function ConditionalVersion({ shouldFetch }: { shouldFetch: boolean }) {
  const { releaseVersion } = useReleaseVersion({ enabled: shouldFetch })
  
  return <span>{releaseVersion}</span>
}
```

The hook includes automatic error toasts, 5-minute stale time, and falls back to 'latest' when the API returns no version data.
