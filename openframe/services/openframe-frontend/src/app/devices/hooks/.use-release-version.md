A React Query hook for fetching and managing the current release version of the application, with built-in error handling and caching.

## Key Components

- **`useReleaseVersion`** - Main hook that fetches the current release version
- **`releaseVersionQueryKeys`** - Query key factory for consistent caching
- **`fetchReleaseVersion`** - API function to retrieve release version from `/api/release-version`
- **`UseReleaseVersionOptions`** - Configuration interface for enabling/disabling the query
- **`ReleaseVersionResponse`** - Type definition for the API response

## Usage Example

```typescript
import { useReleaseVersion } from './use-release-version'

function AppHeader() {
  const { 
    releaseVersion, 
    isLoading, 
    error, 
    refetch 
  } = useReleaseVersion()

  // Conditionally enabled query
  const { releaseVersion: conditionalVersion } = useReleaseVersion({ 
    enabled: false 
  })

  if (isLoading) return <div>Loading version...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <header>
      <h1>OpenFrame v{releaseVersion}</h1>
      <button onClick={() => refetch()}>
        Refresh Version
      </button>
    </header>
  )
}
```

The hook automatically caches data for 5 minutes, shows toast notifications on errors, and falls back to 'latest' if no version is returned. It provides comprehensive query state including loading, error, and success indicators for flexible UI integration.
