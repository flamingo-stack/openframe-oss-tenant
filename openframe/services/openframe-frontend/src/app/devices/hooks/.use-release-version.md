A React Query hook for fetching and managing the current application release version with automatic error handling and toast notifications.

## Key Components

- **`useReleaseVersion`** - Main hook that fetches and returns release version data with loading states
- **`releaseVersionQueryKeys`** - Query key factory for consistent cache management
- **`fetchReleaseVersion`** - Async function that retrieves release version from the API endpoint
- **`UseReleaseVersionOptions`** - Configuration interface for enabling/disabling the query
- **`ReleaseVersionResponse`** - Type definition for the API response structure

## Usage Example

```typescript
import { useReleaseVersion } from './use-release-version'

function AppVersionDisplay() {
  const { releaseVersion, isLoading, error, refetch } = useReleaseVersion()
  
  if (isLoading) return <div>Loading version...</div>
  if (error) return <div>Error: {error}</div>
  
  return (
    <div>
      <span>Version: {releaseVersion}</span>
      <button onClick={() => refetch()}>Refresh</button>
    </div>
  )
}

// Conditionally fetch version
function ConditionalVersionCheck({ shouldFetch }: { shouldFetch: boolean }) {
  const { releaseVersion } = useReleaseVersion({ enabled: shouldFetch })
  
  return <span>{releaseVersion}</span>
}
```

The hook includes built-in caching (5-minute stale time), error retry logic, and automatic toast notifications for failed requests. It defaults to returning 'latest' when no version is available.
