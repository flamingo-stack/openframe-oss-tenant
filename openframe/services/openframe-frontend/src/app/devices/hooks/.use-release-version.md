A React hook that fetches and manages the current application release version using TanStack Query, providing automatic error handling and caching.

## Key Components

- **`useReleaseVersion`** - Main hook that fetches release version with configurable options
- **`releaseVersionQueryKeys`** - Query key factory for consistent cache management
- **`fetchReleaseVersion`** - Async function that retrieves version from `/api/release-version` endpoint
- **`UseReleaseVersionOptions`** - Interface for hook configuration options
- **`ReleaseVersionResponse`** - Type definition for API response structure

## Usage Example

```typescript
import { useReleaseVersion } from '@/hooks/use-release-version'

function AppHeader() {
  // Basic usage - auto-enabled with default caching
  const { releaseVersion, isLoading, error } = useReleaseVersion()

  // Conditional fetching
  const { releaseVersion: conditionalVersion } = useReleaseVersion({
    enabled: false // Disable automatic fetching
  })

  if (isLoading) return <div>Loading version...</div>
  if (error) return <div>Version unavailable</div>

  return (
    <header>
      <h1>OpenFrame v{releaseVersion}</h1>
    </header>
  )
}

// Access all query states
function VersionStatus() {
  const { 
    releaseVersion, 
    isLoading, 
    isSuccess, 
    isFetching, 
    refetch 
  } = useReleaseVersion()

  return (
    <div>
      <span>Version: {releaseVersion}</span>
      <button onClick={() => refetch()}>Refresh</button>
    </div>
  )
}
```

The hook includes built-in error handling with toast notifications, 5-minute stale time, and automatic retries for robust version management.
