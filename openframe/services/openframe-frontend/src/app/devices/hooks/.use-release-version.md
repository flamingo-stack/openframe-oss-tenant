A React Hook that fetches and manages the current release version from the OpenFrame API with caching and error handling capabilities.

## Key Components

- **`releaseVersionQueryKeys`** - Query key factory for TanStack Query cache management
- **`fetchReleaseVersion`** - Async function that calls the `/api/release-version` endpoint
- **`useReleaseVersion`** - Main hook that provides release version data with query state
- **`UseReleaseVersionOptions`** - Interface for configuring the hook behavior

## Usage Example

```typescript
import { useReleaseVersion } from './use-release-version'

function AppVersionDisplay() {
  const { 
    releaseVersion, 
    isLoading, 
    error, 
    refetch 
  } = useReleaseVersion()

  if (isLoading) return <div>Loading version...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <span>Current Version: {releaseVersion}</span>
      <button onClick={() => refetch()}>
        Refresh Version
      </button>
    </div>
  )
}

// Conditional fetching
function ConditionalVersion({ shouldFetch }: { shouldFetch: boolean }) {
  const { releaseVersion } = useReleaseVersion({ 
    enabled: shouldFetch 
  })

  return <span>Version: {releaseVersion}</span>
}
```

The hook automatically handles API errors with toast notifications, implements query caching with a 5-minute stale time, and falls back to `'latest'` when no version is available. It provides comprehensive query state including loading, success, and fetching indicators for flexible UI handling.
