A React Query hook that fetches and manages the current OpenFrame release version from the API, with automatic error handling and toast notifications.

## Key Components

- **`releaseVersionQueryKeys`** - Query key factory for consistent caching and invalidation
- **`fetchReleaseVersion()`** - API function that retrieves release version from `/api/release-version` endpoint
- **`useReleaseVersion()`** - Main hook that provides release version data with loading states and error handling
- **`UseReleaseVersionOptions`** - Configuration interface for enabling/disabling the query

## Usage Example

```typescript
import { useReleaseVersion } from './use-release-version'

function VersionDisplay() {
  const { 
    releaseVersion, 
    isLoading, 
    error,
    refetch 
  } = useReleaseVersion()

  if (isLoading) return <div>Loading version...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <p>Current version: {releaseVersion}</p>
      <button onClick={() => refetch()}>Refresh Version</button>
    </div>
  )
}

// Conditionally enable the query
function ConditionalVersion({ shouldFetch }: { shouldFetch: boolean }) {
  const { releaseVersion } = useReleaseVersion({ 
    enabled: shouldFetch 
  })
  
  return <span>Version: {releaseVersion}</span>
}
```

The hook includes automatic retry logic, caching with 5-minute stale time, and displays error toasts when version fetching fails. It defaults to "latest" if no version is returned from the API.
