A React hook that manages fetching and caching of the current release version from the API, providing automatic error handling and fallback to 'latest' when unavailable.

## Key Components

- **`useReleaseVersion`** - Main hook that fetches release version data with React Query
- **`fetchReleaseVersion`** - API client function that retrieves release version from `/api/release-version`
- **`releaseVersionQueryKeys`** - Query key factory for consistent cache management
- **`UseReleaseVersionOptions`** - Interface for hook configuration options
- **`ReleaseVersionResponse`** - Type definition for API response structure

## Usage Example

```typescript
import { useReleaseVersion } from '@/hooks/use-release-version'

function DeploymentInfo() {
  const { releaseVersion, isLoading, error, refetch } = useReleaseVersion()

  if (isLoading) return <div>Loading version...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <p>Current Release: {releaseVersion}</p>
      <button onClick={() => refetch()}>Refresh Version</button>
    </div>
  )
}

// Disable automatic fetching
function ConditionalVersion() {
  const { releaseVersion } = useReleaseVersion({ enabled: false })
  
  return <span>Version: {releaseVersion}</span>
}
```

The hook includes built-in caching (5 minutes stale time), automatic retry logic, and toast notifications for errors. It always returns a fallback value of 'latest' when the API is unavailable.
