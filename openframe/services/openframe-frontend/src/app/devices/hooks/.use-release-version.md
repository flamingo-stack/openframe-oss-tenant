A React Query hook for fetching and managing the application's release version from the API with error handling and caching.

## Key Components

- **`useReleaseVersion`** - Main hook that fetches the current release version with configurable options
- **`releaseVersionQueryKeys`** - Query key factory for consistent cache management
- **`fetchReleaseVersion`** - Async function that retrieves release version from `/api/release-version` endpoint
- **`UseReleaseVersionOptions`** - Interface for hook configuration options
- **`ReleaseVersionResponse`** - Type definition for API response structure

## Usage Example

```typescript
import { useReleaseVersion } from './use-release-version'

function AppVersionDisplay() {
  const { releaseVersion, isLoading, error, refetch } = useReleaseVersion()

  if (isLoading) return <div>Loading version...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <span>Version: {releaseVersion}</span>
      <button onClick={() => refetch()}>Refresh</button>
    </div>
  )
}

// With options
function ConditionalVersionCheck() {
  const [shouldFetch, setShouldFetch] = useState(false)
  
  const { releaseVersion } = useReleaseVersion({ 
    enabled: shouldFetch 
  })

  return (
    <div>
      <button onClick={() => setShouldFetch(true)}>
        Check Version
      </button>
      {shouldFetch && <span>Current: {releaseVersion}</span>}
    </div>
  )
}
```

The hook includes automatic error toast notifications, 5-minute cache time, and returns 'latest' as fallback when the version cannot be determined.
