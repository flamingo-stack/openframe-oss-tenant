A React hook that fetches and manages the current release version of the OpenFrame application using React Query for caching and error handling.

## Key Components

- **`useReleaseVersion`** - Main hook that fetches release version data with configurable options
- **`releaseVersionQueryKeys`** - Query key factory for React Query cache management
- **`fetchReleaseVersion`** - Async function that fetches release version from the API endpoint
- **`ReleaseVersionResponse`** - Type definition for the API response structure
- **`UseReleaseVersionOptions`** - Interface for hook configuration options

## Usage Example

```typescript
import { useReleaseVersion } from './use-release-version'

function AppVersion() {
  // Basic usage - automatically fetches on mount
  const { releaseVersion, isLoading, error } = useReleaseVersion()

  // With options - disabled until manually enabled
  const { 
    releaseVersion, 
    isLoading, 
    refetch 
  } = useReleaseVersion({ enabled: false })

  if (isLoading) return <div>Loading version...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <span>Version: {releaseVersion}</span>
      <button onClick={() => refetch()}>Refresh</button>
    </div>
  )
}
```

The hook provides automatic error handling with toast notifications, implements a 5-minute stale time with 10-minute garbage collection, and includes retry logic with exponential backoff. It returns 'latest' as a fallback when no version is available.
