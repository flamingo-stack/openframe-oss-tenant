A React Query hook for fetching and managing application release version information with error handling and toast notifications.

## Key Components

- **`releaseVersionQueryKeys`** - Query key factory for consistent caching and invalidation
- **`fetchReleaseVersion()`** - API function that retrieves release version from `/api/release-version` endpoint
- **`useReleaseVersion()`** - Main hook that manages release version state with React Query
- **`UseReleaseVersionOptions`** - Configuration interface for controlling query behavior
- **`ReleaseVersionResponse`** - Type definition for API response structure

## Usage Example

```typescript
import { useReleaseVersion } from './use-release-version'

function AppVersionDisplay() {
  // Basic usage - automatically fetches on mount
  const { releaseVersion, isLoading, error } = useReleaseVersion()

  // With options - disabled until manually triggered
  const versionQuery = useReleaseVersion({ enabled: false })

  if (isLoading) return <div>Loading version...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <p>Current Release: {releaseVersion}</p>
      <button onClick={() => versionQuery.refetch()}>
        Refresh Version
      </button>
    </div>
  )
}
```

The hook includes built-in caching (5-minute stale time), automatic retries, and error toast notifications. It returns 'latest' as a fallback when the API is unavailable or returns empty data.
