A React Query hook for fetching and managing the current application release version from the API, with automatic error handling and toast notifications.

## Key Components

- **`releaseVersionQueryKeys`** - Query key factory for consistent cache management
- **`fetchReleaseVersion()`** - Async function that fetches release version from `/api/release-version` endpoint
- **`useReleaseVersion()`** - Main hook that provides release version data with loading states and error handling
- **`UseReleaseVersionOptions`** - Configuration interface for enabling/disabling the query
- **`ReleaseVersionResponse`** - Type definition for API response structure

## Usage Example

```typescript
import { useReleaseVersion } from './use-release-version'

function AppVersionDisplay() {
  const { 
    releaseVersion, 
    isLoading, 
    error,
    refetch 
  } = useReleaseVersion()

  if (isLoading) {
    return <div>Loading version...</div>
  }

  if (error) {
    return (
      <div>
        Error loading version: {error}
        <button onClick={() => refetch()}>Retry</button>
      </div>
    )
  }

  return <div>Version: {releaseVersion}</div>
}

// Conditionally enabled query
function ConditionalVersionCheck({ shouldCheck }: { shouldCheck: boolean }) {
  const { releaseVersion } = useReleaseVersion({ 
    enabled: shouldCheck 
  })
  
  return <span>{releaseVersion}</span>
}
```

The hook includes built-in caching (5 minutes stale time, 10 minutes garbage collection), retry logic, and automatic toast error notifications. It returns 'latest' as fallback when the API response is empty or undefined.
