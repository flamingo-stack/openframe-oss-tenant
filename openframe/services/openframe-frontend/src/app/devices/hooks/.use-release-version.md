React hook for fetching and managing the application's release version with automatic error handling and toast notifications.

## Key Components

- **`useReleaseVersion`** - Main hook that fetches release version data with React Query
- **`releaseVersionQueryKeys`** - Query key factory for consistent caching
- **`fetchReleaseVersion`** - API function that retrieves version from `/api/release-version` endpoint
- **`UseReleaseVersionOptions`** - Configuration interface with `enabled` toggle
- **`ReleaseVersionResponse`** - Type definition for API response structure

## Usage Example

```typescript
import { useReleaseVersion } from './use-release-version'

function VersionDisplay() {
  const { releaseVersion, isLoading, error } = useReleaseVersion()
  
  if (isLoading) return <div>Loading version...</div>
  if (error) return <div>Error: {error}</div>
  
  return <div>Current version: {releaseVersion}</div>
}

// Conditionally fetch version
function ConditionalVersion({ shouldFetch }: { shouldFetch: boolean }) {
  const { releaseVersion, refetch } = useReleaseVersion({ 
    enabled: shouldFetch 
  })
  
  return (
    <div>
      Version: {releaseVersion}
      <button onClick={() => refetch()}>Refresh</button>
    </div>
  )
}
```

The hook provides automatic error handling with toast notifications, returns 'latest' as fallback, and includes React Query optimization with 5-minute stale time and 2 retry attempts.
