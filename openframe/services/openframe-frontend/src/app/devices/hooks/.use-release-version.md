A React Query hook for fetching and managing the current application release version from the OpenFrame API.

## Key Components

- **`useReleaseVersion`** - Primary hook that fetches and returns the current release version
- **`fetchReleaseVersion`** - Async function that handles the API request to `/api/release-version`
- **`releaseVersionQueryKeys`** - Query key factory for consistent cache management
- **`UseReleaseVersionOptions`** - Interface for hook configuration options
- **`ReleaseVersionResponse`** - Type definition for the API response structure

## Usage Example

```typescript
import { useReleaseVersion } from '@/hooks/use-release-version'

function VersionDisplay() {
  const { releaseVersion, isLoading, error } = useReleaseVersion()

  if (isLoading) return <div>Loading version...</div>
  if (error) return <div>Error: {error}</div>

  return <div>Current Version: {releaseVersion}</div>
}

// With options
function ConditionalVersionCheck() {
  const [shouldCheck, setShouldCheck] = useState(false)
  
  const { releaseVersion, refetch } = useReleaseVersion({
    enabled: shouldCheck
  })

  return (
    <div>
      <button onClick={() => setShouldCheck(true)}>
        Check Version
      </button>
      <button onClick={() => refetch()}>
        Refresh
      </button>
      <p>Version: {releaseVersion}</p>
    </div>
  )
}
```

The hook includes automatic error handling with toast notifications, caching with a 5-minute stale time, and fallback to 'latest' if no version is returned.
