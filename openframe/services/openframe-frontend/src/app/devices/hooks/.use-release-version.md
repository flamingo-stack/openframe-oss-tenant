A React hook for fetching and managing the current release version from the OpenFrame API, with built-in error handling and toast notifications.

## Key Components

- **`useReleaseVersion`** - Main hook that fetches release version data with caching and error handling
- **`releaseVersionQueryKeys`** - Query key factory for React Query cache management
- **`fetchReleaseVersion`** - API client function that retrieves release version from `/api/release-version`
- **`ReleaseVersionResponse`** - Type definition for the API response structure
- **`UseReleaseVersionOptions`** - Configuration options interface for the hook

## Usage Example

```typescript
import { useReleaseVersion } from '@/hooks/use-release-version'

function AppVersion() {
  const { releaseVersion, isLoading, error, refetch } = useReleaseVersion({
    enabled: true // Optional: disable auto-fetching
  })

  if (isLoading) return <div>Loading version...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <p>Current Version: {releaseVersion}</p>
      <button onClick={() => refetch()}>Refresh</button>
    </div>
  )
}

// Conditionally fetch version
function ConditionalVersion({ shouldFetch }: { shouldFetch: boolean }) {
  const { releaseVersion } = useReleaseVersion({ enabled: shouldFetch })
  
  return <span>v{releaseVersion}</span>
}
```

The hook automatically displays error toasts, caches results for 5 minutes, and falls back to 'latest' if the API request fails or returns empty data.
