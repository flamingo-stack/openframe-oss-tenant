A React hook that manages device data fetching, filtering, and pagination for the device management system. It provides comprehensive device list operations with search, filtering, and infinite scrolling capabilities.

## Key Components

- **`useDevices`** - Main hook that encapsulates all device management logic
- **State Management** - Handles devices list, filters, loading states, pagination info, and error states
- **Fetch Operations** - `fetchDevices`, `fetchDeviceFilters`, `searchDevices`, and `refreshDevices` functions
- **Pagination Control** - `fetchNextPage`, `fetchFirstPage`, and pagination state tracking
- **Filter Management** - Stable filter memoization to prevent infinite re-renders
- **Initial Load Control** - Allows parent components to control first data fetch with URL cursor support
