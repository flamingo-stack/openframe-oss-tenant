Utility functions for managing and transforming platform identifiers across different contexts in the application, including filtering, mapping, and display formatting.

## Key Components

- **HIDDEN_PLATFORMS** - Array of platform IDs that are hidden from the UI (currently `linux`)
- **DISABLED_PLATFORMS** - Array of platform IDs that are disabled (currently `darwin`) 
- **AVAILABLE_PLATFORMS** - Filtered list of platforms excluding hidden ones
- **mapPlatformsToOsTypes()** - Maps script platform names to device filter OS type values
- **mapPlatformsForDisplay()** - Maps platform identifiers to user-friendly display names

## Usage Example

```typescript
import { 
  AVAILABLE_PLATFORMS, 
  DISABLED_PLATFORMS,
  mapPlatformsToOsTypes, 
  mapPlatformsForDisplay 
} from './script-utils'

// Get platforms available in UI
console.log(AVAILABLE_PLATFORMS) // Excludes 'linux'

// Check if platform is disabled
const isDarwinDisabled = DISABLED_PLATFORMS.includes('darwin') // true

// Convert script platforms to device filter format
const scriptPlatforms = ['windows', 'darwin', 'linux']
const osTypes = mapPlatformsToOsTypes(scriptPlatforms)
console.log(osTypes) // ['WINDOWS', 'MAC_OS']

// Convert to display names
const displayNames = mapPlatformsForDisplay(scriptPlatforms)
console.log(displayNames) // ['Windows', 'macOS', 'Linux']
```

The utility handles the mapping between different platform naming conventions used throughout the application - from script identifiers (`windows`, `darwin`, `linux`) to device filter types (`WINDOWS`, `MAC_OS`) and user-friendly display names (`Windows`, `macOS`, `Linux`).
