A Next.js client-side page component that renders the scripts management interface with dynamic rendering enabled.

## Key Components

- **Scripts** (default export) - Main page component that combines the app layout with the scripts view
- **dynamic** - Next.js export configuration set to `'force-dynamic'` to ensure server-side rendering on every request
- **AppLayout** - Wrapper component providing consistent page structure
- **ScriptsView** - Core component handling the scripts interface functionality

## Usage Example

This page component is automatically routed by Next.js App Router based on its file location:

```typescript
// Accessed via /scripts route in the application
// The component structure follows this pattern:

export default function Scripts() {
  return (
    <AppLayout>
      <ScriptsView />
    </AppLayout>
  )
}

// Force dynamic rendering prevents static optimization
export const dynamic = 'force-dynamic'
```

The component uses the `'use client'` directive to enable client-side rendering and interactivity, while the `force-dynamic` export ensures the page is rendered dynamically on each request rather than being statically generated at build time.
