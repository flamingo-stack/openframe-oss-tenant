Comprehensive TypeScript definitions for the script scheduling system in OpenFrame's MSP platform. This module provides complete type safety for creating, managing, and executing scheduled script tasks across different platforms and intervals.

## Key Components

**API Response Types:**
- `ScriptScheduleListItem` - Schedule overview for list views
- `ScriptScheduleDetail` - Complete schedule configuration with actions and agents
- `ScriptScheduleAction` - Script execution configuration with timeout and arguments
- `ScriptScheduleAgent` - Target agent information for script deployment
- `ScriptScheduleHistoryEntry` - Execution history with status and output

**Request Types:**
- `CreateScriptSchedulePayload` - Payload for creating new schedules
- `UpdateScriptSchedulePayload` - Partial update payload
- `ScriptScheduleTaskType` - Schedule frequency types (runonce, daily, weekly, monthly)

**Form Types:**
- `CreateScheduleFormData` - Zod-validated form schema
- `ScheduleActionFormData` - Individual script action configuration
- Platform constants and utility functions for date handling

## Usage Example

```typescript
import { 
  CreateScheduleFormData, 
  buildCreatePayload, 
  toZuluDateString,
  PLATFORM_LABELS 
} from './script-schedule.types'

// Create a daily backup schedule

  name: "Daily Backup",
  scheduledDate: new Date(),
  repeatEnabled: true,
  repeatInterval: 1,
  repeatPeriod: "day",
  weekdays: 0,
  supportedPlatforms: ["windows", "linux"],
  enabled: true,
  actions: [{
    script: 123,
    name: "Backup Script",
    timeout: 3600,
    script_args: [{ id: "1", key: "path", value: "/backup" }],
    env_vars: [{ id: "2", key: "LOG_LEVEL", value: "INFO" }]
  }]
}
```
