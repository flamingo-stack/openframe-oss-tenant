A Next.js client-side page component that renders the schedule script management interface for a specific script, extracting the script ID from URL parameters.

## Key Components

- **ScheduleScriptPage** - Main page component that serves as a route handler for `/schedule/[id]` paths
- **AppLayout** - Wrapper component providing consistent application layout and navigation
- **ScheduleScriptView** - Core view component for managing and displaying script scheduling functionality
- **useParams** - Next.js hook for extracting dynamic route parameters

## Usage Example

```typescript
// This page is automatically rendered when navigating to routes like:
// /schedule/abc123
// /schedule/my-script-id

// The component extracts the script ID and passes it to the view:
const params = useParams<{ id?: string }>()
const id = typeof params?.id === 'string' ? params.id : ''

// Renders the complete page structure:
<AppLayout>
  <ScheduleScriptView scriptId="abc123" />
</AppLayout>
```

The page handles both valid script IDs and edge cases where the ID parameter might be missing or invalid, defaulting to an empty string for graceful error handling in the child component.
