A Next.js page component that renders the script scheduling interface, with feature flag protection to ensure the functionality is only available when enabled.

## Key Components

- **ScheduleScriptPage** - Default exported React component that serves as the main page
- **AppLayout** - Wrapper component providing consistent application layout
- **ScheduleScriptView** - Core view component for script scheduling functionality
- **NotFoundError** - Error component displayed when feature is disabled
- **Feature Flag Check** - Uses `featureFlags.scriptSchedule.enabled()` to control access

## Usage Example

```typescript
// This page is automatically rendered by Next.js routing
// Access via: /scripts/[id]/schedule

// The component extracts the script ID from URL parameters
// and passes it to the ScheduleScriptView component

// Example URL: /scripts/abc123/schedule
// Results in: <ScheduleScriptView scriptId="abc123" />

// If feature flag is disabled, shows error:
// "Script scheduling is not available. This feature is currently disabled."
// with a button to navigate back to /scripts
```

The page implements proper error handling for disabled features and extracts the script ID from URL parameters to pass to the scheduling view component.
