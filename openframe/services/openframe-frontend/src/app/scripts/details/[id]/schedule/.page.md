A React page component that renders the schedule script management interface for OpenFrame's automation system, displaying script details and scheduling options for a specific script ID.

## Key Components

- **ScheduleScriptPage** - Main page component that extracts script ID from URL parameters and renders the schedule view
- **AppLayout** - Wrapper component providing consistent application layout and navigation
- **ScheduleScriptView** - Core component handling script scheduling interface and functionality

## Usage Example

This page is automatically rendered when navigating to a script scheduling route:

```typescript
// URL: /schedule-script/[id]
// Example: /schedule-script/backup-automation-123

// The component automatically extracts the ID and passes it to the view
function ScheduleScriptPage() {
  const params = useParams<{ id?: string }>()
  const id = typeof params?.id === 'string' ? params.id : ''
  
  return (
    <AppLayout>
      <ScheduleScriptView scriptId={id} />
    </AppLayout>
  )
}
```

The page integrates with Next.js routing to provide a clean interface for managing automation script schedules within the OpenFrame platform. The script ID parameter is safely extracted and validated before being passed to the scheduling view component.
