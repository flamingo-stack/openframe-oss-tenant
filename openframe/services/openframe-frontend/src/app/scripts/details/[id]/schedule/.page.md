A Next.js page component that renders the schedule script management interface for a specific script identified by URL parameter.

## Key Components

- **ScheduleScriptPage** - Default exported page component that extracts script ID from URL params and renders the schedule script view
- **AppLayout** - Wrapper component providing consistent application layout structure
- **ScheduleScriptView** - Main component handling schedule script functionality, receives scriptId as prop
- **useParams** - Next.js hook for accessing dynamic route parameters

## Usage Example

This page is accessed via dynamic routing where the script ID is passed as a URL parameter:

```typescript
// Route: /schedule/script/[id]
// URL: /schedule/script/abc123
// The component extracts 'abc123' as the scriptId

function ScheduleScriptPage() {
  const params = useParams<{ id?: string }>()
  const id = typeof params?.id === 'string' ? params.id : ''
  
  return (
    <AppLayout>
      <ScheduleScriptView scriptId={id} />
    </AppLayout>
  )
}
```

The component safely handles undefined or non-string ID parameters by defaulting to an empty string, ensuring type safety for the ScheduleScriptView component.
