A Next.js page component that renders the script scheduling interface, with feature flag protection and error handling for disabled functionality.

## Key Components

- **ScheduleScriptPage**: Main page component that conditionally renders script scheduling UI
- **Feature Flag Check**: Validates if script scheduling is enabled before rendering
- **Route Parameters**: Extracts script ID from URL parameters
- **Error Handling**: Shows NotFoundError when feature is disabled

## Usage Example

This page is accessed via Next.js routing when users navigate to schedule a script:

```typescript
// URL pattern: /scripts/[id]/schedule
// Example: /scripts/abc123/schedule

// The component automatically:
// 1. Extracts the script ID from URL params
// 2. Checks if script scheduling feature is enabled
// 3. Renders ScheduleScriptView with the script ID
// 4. Shows error page if feature is disabled

// Feature flag configuration example:
const featureFlags = {
  scriptSchedule: {
    enabled: () => process.env.NEXT_PUBLIC_SCRIPT_SCHEDULE === 'true'
  }
}
```

The component uses the `AppLayout` wrapper and redirects users to `/scripts` when the feature is unavailable, ensuring a consistent user experience even when functionality is disabled.
