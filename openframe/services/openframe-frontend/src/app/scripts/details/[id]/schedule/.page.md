A Next.js client-side page component that displays the script scheduling interface, with feature flag protection to ensure the scheduling functionality is available before rendering.

## Key Components

- **ScheduleScriptPage**: Main page component that handles script scheduling display
- **Feature Flag Validation**: Checks if script scheduling is enabled via `featureFlags.scriptSchedule`
- **Route Parameter Extraction**: Extracts script ID from URL parameters
- **Error Handling**: Shows NotFoundError when feature is disabled

## Usage Example

```typescript
// This page is automatically rendered when navigating to:
// /scripts/[id]/schedule

// URL examples:
// /scripts/abc123/schedule -> scriptId = "abc123" 
// /scripts/xyz789/schedule -> scriptId = "xyz789"

// The component structure:
<AppLayout>
  {featureFlags.scriptSchedule.enabled() ? (
    <ScheduleScriptView scriptId={extractedId} />
  ) : (
    <NotFoundError message="Feature disabled" />
  )}
</AppLayout>
```

The page automatically redirects users to `/scripts` if the scheduling feature is disabled, ensuring a consistent user experience when features are toggled off.
