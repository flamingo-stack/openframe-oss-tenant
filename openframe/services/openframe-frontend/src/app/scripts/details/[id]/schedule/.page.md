A Next.js page component that displays the schedule script interface for a specific script, extracting the script ID from the URL parameters.

## Key Components

- **ScheduleScriptPage** - Main page component that renders the schedule script view
- **useParams** - Next.js hook for extracting route parameters
- **AppLayout** - Wrapper component providing consistent application layout
- **ScheduleScriptView** - Child component handling the actual schedule script functionality

## Usage Example

This page is accessed via dynamic routing where the script ID is passed as a URL parameter:

```typescript
// URL: /schedule-script/[id]
// Example: /schedule-script/abc123

export default function ScheduleScriptPage() {
  const params = useParams<{ id?: string }>()
  const id = typeof params?.id === 'string' ? params.id : ''
  
  return (
    <AppLayout>
      <ScheduleScriptView scriptId={id} />
    </AppLayout>
  )
}
```

The component safely extracts the `id` parameter from the URL, ensuring it's a string before passing it to the `ScheduleScriptView` component. If no ID is provided or it's not a string, an empty string is used as a fallback.
