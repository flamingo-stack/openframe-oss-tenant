A Next.js client-side page component that renders a schedule script management interface with dynamic routing for individual script instances.

## Key Components

- **ScheduleScriptPage**: Main page component that handles URL parameters and renders the schedule script view
- **AppLayout**: Wrapper component providing consistent application layout
- **ScheduleScriptView**: Core component for displaying and managing schedule script functionality
- **useParams**: Next.js hook for extracting dynamic route parameters

## Usage Example

```typescript
// Route structure: /schedule/script/[id]/page.tsx
// URL: /schedule/script/abc123
// The component automatically extracts 'abc123' as the script ID

// Example routing setup in Next.js app router:
// app/
//   schedule/
//     script/
//       [id]/
//         page.tsx  // This component

// Component usage (automatically handled by Next.js routing):
// When user navigates to /schedule/script/my-script-id
// The page renders with scriptId="my-script-id"
```

The component uses Next.js 13+ app router conventions with dynamic routing (`[id]`) to capture script identifiers from the URL. It safely handles undefined parameters by defaulting to an empty string, ensuring the `ScheduleScriptView` component always receives a valid string value for the `scriptId` prop.
