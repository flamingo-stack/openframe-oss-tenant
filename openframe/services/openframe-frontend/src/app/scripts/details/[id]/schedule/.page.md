A Next.js page component that renders the schedule script management interface for a specific script, extracting the script ID from the URL parameters.

## Key Components

- **ScheduleScriptPage**: Default exported page component that handles script scheduling functionality
- **AppLayout**: Wrapper component providing consistent application layout structure
- **ScheduleScriptView**: Main view component for managing script scheduling with script-specific functionality
- **useParams**: Next.js hook for extracting dynamic route parameters

## Usage Example

```typescript
// This page is automatically rendered when navigating to:
// /schedule/script/[id] routes

// Example URL: /schedule/script/abc123
// The component will extract 'abc123' as the scriptId

// The page structure follows this pattern:
<AppLayout>
  <ScheduleScriptView scriptId="abc123" />
</AppLayout>

// Type-safe parameter extraction:
const params = useParams<{ id?: string }>()
const scriptId = typeof params?.id === 'string' ? params.id : ''
```

The component uses Next.js 13+ app router conventions with client-side rendering, safely extracting the script ID from URL parameters and passing it to the schedule script view for script-specific scheduling operations.
