A Next.js page component that renders the schedule script view with the script ID from the URL parameters.

## Key Components

- **ScheduleScriptPage** - Default export page component that extracts script ID from URL params and renders the schedule script interface
- **AppLayout** - Wrapper component providing consistent application layout structure
- **ScheduleScriptView** - Main view component for displaying and managing scheduled scripts
- **useParams** - Next.js hook for accessing dynamic route parameters

## Usage Example

```typescript
// URL: /schedule/scripts/abc123
// The page will automatically extract "abc123" as the script ID

// Component renders as:
<AppLayout>
  <ScheduleScriptView scriptId="abc123" />
</AppLayout>

// Type-safe parameter extraction
const params = useParams<{ id?: string }>()
const id = typeof params?.id === 'string' ? params.id : ''
```

The component follows Next.js 13+ app router conventions with client-side rendering, safely extracting the dynamic `id` parameter from the URL and passing it to the `ScheduleScriptView` component for script-specific functionality.
