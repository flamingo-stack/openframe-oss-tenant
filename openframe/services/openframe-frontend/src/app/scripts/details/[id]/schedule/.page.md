A Next.js page component that renders a schedule script view within the application layout, extracting the script ID from URL parameters.

## Key Components

- **ScheduleScriptPage** - Default export page component that handles script viewing
- **useParams** - Next.js hook for accessing dynamic route parameters
- **AppLayout** - Wrapper component providing consistent application structure
- **ScheduleScriptView** - Main content component for displaying script details

## Usage Example

This page is accessed via dynamic routing in Next.js:

```typescript
// URL: /schedule/script/[id]
// Example: /schedule/script/abc123

// The component automatically extracts the ID and renders:
<AppLayout>
  <ScheduleScriptView scriptId="abc123" />
</AppLayout>
```

## Route Structure

```typescript
// File location suggests this route structure:
// app/schedule/script/[id]/page.tsx
// Matches URLs like: /schedule/script/12345
```

The component uses Next.js 13+ App Router conventions with client-side rendering (`'use client'`) to access browser APIs like `useParams`. The extracted ID parameter is safely type-checked and passed to the `ScheduleScriptView` component for rendering script-specific content.
