A Next.js page component that displays a detailed view for a specific scheduled script using dynamic routing.

## Key Components

- **ScheduleScriptPage**: Main page component that extracts script ID from URL parameters and renders the script view
- **useParams**: Hook to access dynamic route parameters (`id`)
- **AppLayout**: Wrapper component providing consistent application layout
- **ScheduleScriptView**: Child component that handles the actual script display logic

## Usage Example

```typescript
// This page is accessed via routes like:
// /schedule/scripts/[id] where [id] is the script identifier

// Example URLs:
// /schedule/scripts/abc123
// /schedule/scripts/script-backup-daily

// The component extracts the ID and passes it to ScheduleScriptView
function ExampleUsage() {
  // URL: /schedule/scripts/abc123
  // params.id = "abc123"
  // scriptId prop = "abc123"
  
  return (
    <AppLayout>
      <ScheduleScriptView scriptId="abc123" />
    </AppLayout>
  )
}
```

The page uses client-side rendering (`'use client'`) to access URL parameters and provides a clean separation of concerns by delegating the actual script viewing logic to the `ScheduleScriptView` component while handling route parameter extraction at the page level.
