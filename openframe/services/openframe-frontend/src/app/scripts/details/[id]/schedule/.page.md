A Next.js page component that renders the schedule script interface for editing or viewing automation scripts in the OpenFrame platform.

## Key Components

- **ScheduleScriptPage** - Main page component that extracts script ID from URL parameters and renders the schedule script view
- **AppLayout** - Wrapper component providing consistent layout structure
- **ScheduleScriptView** - Core component for managing scheduled automation scripts
- **useParams** - Next.js hook for accessing dynamic route parameters

## Usage Example

This page is accessed through dynamic routing where the script ID is passed as a URL parameter:

```typescript
// Route: /schedule-script/[id]/page.tsx
// URL: /schedule-script/abc123

// The component automatically extracts 'abc123' as the scriptId
// and passes it to ScheduleScriptView for script management

// Typical usage in route navigation:
router.push(`/schedule-script/${scriptId}`)
```

The page follows Next.js 13+ app directory conventions with client-side rendering enabled via the `'use client'` directive. It safely handles cases where the ID parameter might be undefined by defaulting to an empty string, ensuring the ScheduleScriptView component receives a valid string value for the scriptId prop.
