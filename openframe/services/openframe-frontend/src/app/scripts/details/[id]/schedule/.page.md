A Next.js page component that renders the script scheduling interface, with feature flag protection and error handling for disabled functionality.

## Key Components

- **ScheduleScriptPage** - Main page component that handles script scheduling UI
- **Feature Flag Guard** - Checks if script scheduling is enabled via `featureFlags.scriptSchedule`
- **Route Parameter Extraction** - Extracts script ID from URL parameters
- **Error Boundary** - Shows user-friendly error when feature is disabled

## Usage Example

```typescript
// This page is automatically rendered when navigating to:
// /scripts/schedule/[id] - where [id] is the script ID

// The component extracts the script ID and passes it to ScheduleScriptView:
<ScheduleScriptView scriptId="script-123" />

// If feature is disabled, users see:
<NotFoundError 
  message="Script scheduling is not available..." 
  onHome={() => router.push('/scripts')}
/>
```

The page integrates with the app's layout system and provides graceful degradation when the script scheduling feature is disabled through feature flags. Users are redirected back to the scripts listing when the feature is unavailable.
