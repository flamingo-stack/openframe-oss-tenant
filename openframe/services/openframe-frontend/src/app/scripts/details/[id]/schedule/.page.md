A Next.js page component that renders a schedule script view within the application layout, extracting the script ID from URL parameters.

## Key Components

- **ScheduleScriptPage** - Main page component that handles script ID routing
- **AppLayout** - Wrapper component providing consistent application layout
- **ScheduleScriptView** - Core component for displaying/managing schedule scripts
- **useParams** - Next.js hook for accessing dynamic route parameters

## Usage Example

This page is accessed via dynamic routing where the script ID is passed as a URL parameter:

```typescript
// Route: /schedule/script/[id]
// Example URL: /schedule/script/abc123

// The component automatically extracts 'abc123' as the script ID
// and passes it to ScheduleScriptView for rendering

// File structure:
// app/schedule/script/[id]/page.tsx
```

The component follows Next.js 13+ app router conventions with client-side rendering enabled via the `'use client'` directive. It safely handles the dynamic `id` parameter by ensuring it's a string before passing it to the child component, defaulting to an empty string if undefined.
