A Next.js client-side page component for scheduling scripts, with feature flag protection to control access to the script scheduling functionality.

## Key Components

- **ScheduleScriptPage**: Main page component that handles script scheduling routing
- **AppLayout**: Wrapper component providing consistent application layout
- **ScheduleScriptView**: Child component that renders the actual scheduling interface
- **NotFoundError**: Error component displayed when the feature is disabled
- **Feature Flag Integration**: Uses `featureFlags.scriptSchedule` to control feature availability

## Usage Example

This page is automatically rendered by Next.js App Router when users navigate to `/scripts/[id]/schedule`:

```typescript
// URL: /scripts/abc123/schedule
// The component extracts 'abc123' as the script ID parameter

// Feature flag check prevents access when disabled
if (!featureFlags.scriptSchedule.enabled()) {
  // Shows error message with redirect to /scripts
  return <NotFoundError />
}

// When enabled, renders the scheduling interface
return (
  <AppLayout>
    <ScheduleScriptView scriptId="abc123" />
  </AppLayout>
)
```

The component uses Next.js navigation hooks to extract the script ID from the URL and provides a fallback redirect to `/scripts` when the scheduling feature is disabled through feature flags.
