A Next.js page component that renders the schedule script interface for viewing and managing individual scheduled scripts within the Flamingo MSP platform.

## Key Components

- **ScheduleScriptPage**: Main page component that extracts script ID from URL parameters and renders the schedule script view
- **AppLayout**: Wrapper component providing consistent application layout and navigation
- **ScheduleScriptView**: Core component for displaying and managing scheduled script details
- **useParams**: Next.js hook for accessing dynamic route parameters

## Usage Example

This page is accessed via dynamic routing in the Flamingo application:

```typescript
// URL: /schedule-scripts/[id]
// Example: /schedule-scripts/script-123

// The component automatically extracts the script ID and passes it to ScheduleScriptView
function ScheduleScriptPage() {
  const params = useParams<{ id?: string }>()
  const id = typeof params?.id === 'string' ? params.id : ''
  
  return (
    <AppLayout>
      <ScheduleScriptView scriptId={id} />
    </AppLayout>
  )
}
```

The component handles type-safe parameter extraction, ensuring the script ID is properly validated as a string before passing it to the child component. It integrates with the broader Flamingo MSP automation system for managing scheduled IT operations.
