A Next.js client-side page component that renders the schedule script interface with ID-based routing. This page extracts the script ID from URL parameters and passes it to the schedule script view component within the application layout.

## Key Components

- **ScheduleScriptPage** - Main page component that handles ID-based routing for schedule scripts
- **AppLayout** - Application wrapper component providing consistent layout structure
- **ScheduleScriptView** - Core component for displaying and managing schedule script functionality
- **useParams** - Next.js hook for extracting dynamic route parameters

## Usage Example

```typescript
// URL routing examples:
// /schedule-script/123 -> scriptId = "123"
// /schedule-script/abc-def -> scriptId = "abc-def"
// /schedule-script -> scriptId = "" (empty string)

// The component automatically extracts the ID from the URL
// and passes it to ScheduleScriptView for script-specific operations
<ScheduleScriptView scriptId="extracted-id-from-url" />
```

The page uses type-safe parameter extraction, ensuring the ID is always a string (defaulting to empty string if not provided). The client-side nature enables dynamic interactions within the schedule script interface while maintaining proper routing behavior.
