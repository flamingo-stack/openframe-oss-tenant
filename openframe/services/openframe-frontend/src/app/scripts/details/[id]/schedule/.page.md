A Next.js page component that displays a scheduled script detail view within the application layout, extracting the script ID from URL parameters.

## Key Components

- **ScheduleScriptPage**: Default exported page component that renders a scheduled script view
- **AppLayout**: Wrapper component providing consistent application layout structure
- **ScheduleScriptView**: Child component that displays script scheduling interface and details
- **useParams**: Next.js hook for extracting dynamic route parameters

## Usage Example

This page is typically accessed via a dynamic route structure:

```typescript
// Route: /schedule/scripts/[id]/page.tsx
// URL example: /schedule/scripts/abc123

// The component automatically extracts the script ID from the URL
// and passes it to ScheduleScriptView for rendering the specific script
```

The component follows Next.js 13+ app router conventions with client-side rendering enabled via the `'use client'` directive. It safely handles cases where the `id` parameter might be undefined by providing an empty string fallback, ensuring type safety when passing the `scriptId` prop to the child component.
