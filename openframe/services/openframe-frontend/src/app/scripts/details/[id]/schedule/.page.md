A Next.js page component that renders the schedule script view interface, extracting the script ID from URL parameters and displaying it within the application layout.

## Key Components

- **ScheduleScriptPage**: Default export component that serves as the main page wrapper
- **AppLayout**: Application-wide layout component providing consistent UI structure
- **ScheduleScriptView**: Core view component for managing scheduled scripts
- **useParams**: Next.js hook for accessing dynamic route parameters

## Usage Example

This page component is automatically rendered when users navigate to a schedule script route:

```typescript
// Route: /schedule/[id]/page.tsx
// URL: /schedule/abc123
// The component receives 'abc123' as the id parameter

export default function ScheduleScriptPage() {
  const params = useParams<{ id?: string }>()
  const id = typeof params?.id === 'string' ? params.id : ''
  
  return (
    <AppLayout>
      <ScheduleScriptView scriptId={id} />
    </AppLayout>
  )
}
```

The component safely handles cases where the `id` parameter might be undefined or an array, defaulting to an empty string. The extracted ID is passed to `ScheduleScriptView` which handles the actual script management functionality within the consistent `AppLayout` wrapper.
