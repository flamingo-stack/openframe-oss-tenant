A Next.js page component that renders the script scheduling interface for a specific script, with feature flag protection and error handling for disabled functionality.

## Key Components

- **ScheduleScriptPage**: Main page component that handles script scheduling functionality
- **Feature Flag Check**: Validates if script scheduling is enabled before rendering
- **Route Parameter Extraction**: Extracts script ID from URL parameters
- **Error Handling**: Shows appropriate error message when feature is disabled

## Usage Example

```typescript
// This page is automatically rendered when navigating to:
// /schedule/script/[id] route

// Example URL: /schedule/script/abc123
// The component extracts 'abc123' as the script ID

// Feature flag configuration
const featureFlags = {
  scriptSchedule: {
    enabled: () => process.env.SCRIPT_SCHEDULE_ENABLED === 'true'
  }
}

// Error handling when feature is disabled
<NotFoundError
  message="Script scheduling is not available. This feature is currently disabled."
  onHome={() => router.push('/scripts')}
/>
```

The component uses Next.js client-side routing with `useParams` to extract the script ID from the URL, wraps content in the standard `AppLayout`, and gracefully handles cases where the script scheduling feature is disabled through feature flags. When disabled, users see a helpful error message with navigation back to the scripts list.
