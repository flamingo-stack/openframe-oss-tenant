A Next.js page component that renders the script scheduling interface, with feature flag protection and error handling for disabled functionality.

## Key Components

- **ScheduleScriptPage** - Main page component that handles script scheduling display
- **Feature Flag Protection** - Checks if script scheduling is enabled before rendering
- **Route Parameter Extraction** - Extracts script ID from URL parameters
- **Error Handling** - Shows appropriate error message when feature is disabled

## Usage Example

```typescript
// This page is accessed via Next.js routing at /scripts/[id]/schedule
// Example URL: /scripts/abc123/schedule

// The component automatically:
// 1. Extracts the script ID from the URL
// 2. Checks if the scriptSchedule feature flag is enabled
// 3. Either shows the ScheduleScriptView or a NotFoundError

// Feature flag configuration example:
const featureFlags = {
  scriptSchedule: {
    enabled: () => process.env.NEXT_PUBLIC_SCRIPT_SCHEDULE_ENABLED === 'true'
  }
}

// When feature is disabled, users see:
// "Script scheduling is not available. This feature is currently disabled."
// with a button to navigate back to /scripts
```

The component uses Next.js 13+ app router conventions with client-side rendering and integrates with the OpenFrame frontend core for consistent error handling across the application.
