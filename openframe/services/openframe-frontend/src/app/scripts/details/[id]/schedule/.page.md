A Next.js client-side page component that renders the schedule script management interface for a specific script identified by URL parameter.

## Key Components

- **ScheduleScriptPage** - Main page component that extracts script ID from URL parameters and renders the schedule view
- **AppLayout** - Wrapper component providing consistent application layout
- **ScheduleScriptView** - Core component for managing script scheduling functionality
- **useParams** - Next.js hook for accessing dynamic route parameters

## Usage Example

```typescript
// This component is automatically rendered when navigating to:
// /schedule-script/[id] where [id] is the script identifier

// Example URL: /schedule-script/abc123
// Results in: ScheduleScriptView receiving scriptId="abc123"

// The component structure:
<AppLayout>
  <ScheduleScriptView scriptId="abc123" />
</AppLayout>
```

The page safely extracts the `id` parameter from the URL, ensuring it's a string before passing it to the `ScheduleScriptView` component. If no valid ID is found, an empty string is passed as a fallback. This pattern follows Next.js 13+ app router conventions for dynamic routing with client-side rendering.
