A Next.js page component that renders the script scheduling interface, handling feature flag validation and error states.

## Key Components

- **ScheduleScriptPage**: Main page component that displays the script scheduling view
- **Feature Flag Guard**: Checks if script scheduling is enabled before rendering
- **Route Parameter Extraction**: Extracts script ID from URL parameters
- **Error Handling**: Shows NotFoundError when feature is disabled

## Usage Example

```typescript
// This page is automatically rendered when navigating to:
// /scripts/[id]/schedule

// The component will:
// 1. Extract the script ID from the URL
// 2. Check if scriptSchedule feature flag is enabled
// 3. Either show the ScheduleScriptView or NotFoundError

// Example URL that would render this page:
// /scripts/abc123/schedule
// - params.id would be "abc123"
// - ScheduleScriptView receives scriptId="abc123"
```

The page uses Next.js 13+ app router with client-side rendering, wrapping the main content in the AppLayout component. When the script scheduling feature is disabled, users are redirected to the scripts listing page with an appropriate error message.
