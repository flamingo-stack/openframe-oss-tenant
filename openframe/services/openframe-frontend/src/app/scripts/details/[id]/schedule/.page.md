A Next.js page component that renders the schedule script management interface for a specific script identified by URL parameters.

## Key Components

- **ScheduleScriptPage**: Default exported React component that serves as the main page wrapper
- **AppLayout**: Wrapper component providing consistent application layout structure
- **ScheduleScriptView**: Core view component for displaying and managing schedule script details
- **useParams**: Next.js hook for extracting URL parameters

## Usage Example

This page is accessed via dynamic routing where the script ID is passed as a URL parameter:

```typescript
// URL: /schedule-scripts/abc123
// The component will extract 'abc123' as the script ID

export default function ScheduleScriptPage() {
  const params = useParams<{ id?: string }>()
  const id = typeof params?.id === 'string' ? params.id : ''
  
  return (
    <AppLayout>
      <ScheduleScriptView scriptId={id} />
    </AppLayout>
  )
}
```

The component safely extracts the `id` parameter from the URL, validates it as a string, and passes it to the `ScheduleScriptView` component. If no valid ID is found, an empty string is passed as a fallback. The entire interface is wrapped in the `AppLayout` component for consistent styling and navigation.
