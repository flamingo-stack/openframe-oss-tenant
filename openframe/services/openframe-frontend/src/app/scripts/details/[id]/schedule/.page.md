A Next.js page component that renders the schedule script view within the application layout, extracting the script ID from URL parameters.

## Key Components

- **ScheduleScriptPage**: Default exported React component that serves as the main page
- **AppLayout**: Wrapper component providing consistent application layout
- **ScheduleScriptView**: Core component for displaying/managing scheduled scripts
- **useParams**: Next.js hook for extracting dynamic route parameters

## Usage Example

This page is designed to handle dynamic routes for individual scripts:

```typescript
// URL: /schedule-script/abc123
// The component will extract 'abc123' as the script ID

function ScheduleScriptPage() {
  const params = useParams<{ id?: string }>()
  const id = typeof params?.id === 'string' ? params.id : ''
  
  return (
    <AppLayout>
      <ScheduleScriptView scriptId={id} />
    </AppLayout>
  )
}
```

The component safely handles cases where the `id` parameter might be undefined or an array by providing an empty string fallback. This ensures the `ScheduleScriptView` always receives a valid string ID parameter, even for routes without an ID segment.
