A Next.js client-side page component that renders the schedule script management interface for a specific script identified by its ID parameter.

## Key Components

- **ScheduleScriptPage**: Default exported React component that serves as the main page wrapper
- **AppLayout**: Wrapper component providing consistent application layout and navigation
- **ScheduleScriptView**: Core component handling script scheduling functionality
- **useParams**: Next.js hook for extracting route parameters

## Usage Example

This page is typically accessed via a dynamic route structure:

```typescript
// Route: /schedule/script/[id]/page.tsx
// URL example: /schedule/script/abc123

// The component automatically extracts the script ID from the URL
// and passes it to ScheduleScriptView for script-specific operations

function ExampleUsage() {
  // When user navigates to /schedule/script/abc123
  // - useParams() returns { id: 'abc123' }
  // - Component renders ScheduleScriptView with scriptId="abc123"
  return (
    <AppLayout>
      <ScheduleScriptView scriptId="abc123" />
    </AppLayout>
  )
}
```

The component handles type safety by ensuring the `id` parameter is always a string, defaulting to an empty string if undefined or invalid.
