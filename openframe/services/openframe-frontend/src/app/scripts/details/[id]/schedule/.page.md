A Next.js page component that renders the schedule script management interface, extracting the script ID from URL parameters and passing it to the schedule script view.

## Key Components

- **ScheduleScriptPage**: Main page component that handles routing for individual script scheduling
- **AppLayout**: Wrapper component providing consistent application layout
- **ScheduleScriptView**: Core view component for managing script scheduling operations
- **useParams**: Next.js hook for extracting dynamic route parameters

## Usage Example

This page is accessed via dynamic routing where the script ID is part of the URL path:

```typescript
// URL: /schedule-script/abc123
// The component will extract 'abc123' as the script ID

function ScheduleScriptPage() {
  const params = useParams<{ id?: string }>()
  const id = typeof params?.id === 'string' ? params.id : ''
  
  return (
    <AppLayout>
      <ScheduleScriptView scriptId={id} />
    </AppLayout>
  )
}
```

The component safely extracts the `id` parameter from the URL, ensures it's a string type, and passes it to `ScheduleScriptView` for rendering the script scheduling interface. If no valid ID is found, an empty string is passed as a fallback.
