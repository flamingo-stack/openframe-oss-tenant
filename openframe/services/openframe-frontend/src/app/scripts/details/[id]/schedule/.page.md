A Next.js page component that renders the schedule script interface for a specific script identified by its ID parameter from the URL route.

## Key Components

- **ScheduleScriptPage** - Default export page component that extracts script ID from URL parameters
- **AppLayout** - Wrapper component providing consistent application layout structure
- **ScheduleScriptView** - Main view component for displaying and managing script scheduling functionality
- **useParams** - Next.js hook for accessing dynamic route parameters

## Usage Example

This page is automatically rendered when navigating to a route like `/schedule/[id]` where `[id]` is the script identifier:

```typescript
// URL: /schedule/script-123
// The component will receive:
// params.id = "script-123"

// Component renders:
<AppLayout>
  <ScheduleScriptView scriptId="script-123" />
</AppLayout>
```

The page handles parameter validation by ensuring the ID is extracted as a string, defaulting to an empty string if the parameter is missing or invalid. This follows Next.js 13+ app router conventions with the `'use client'` directive for client-side rendering capabilities.
