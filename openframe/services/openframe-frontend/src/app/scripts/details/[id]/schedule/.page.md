A Next.js page component that handles script scheduling functionality with feature flag protection and error handling for disabled features.

## Key Components

- **ScheduleScriptPage**: Main page component that renders the script scheduling interface
- **AppLayout**: Wrapper component providing consistent application layout
- **ScheduleScriptView**: Core component handling the script scheduling UI logic
- **NotFoundError**: Error component displayed when the feature is disabled
- **Feature Flag Check**: Uses `featureFlags.scriptSchedule.enabled()` to control feature availability

## Usage Example

```typescript
// This page is automatically routed by Next.js at /schedule-script/[id]
// The component extracts the script ID from URL parameters and passes it to the view

// Example URL: /schedule-script/abc123
// Results in: scriptId="abc123" being passed to ScheduleScriptView

// When feature is disabled, users see:
// "Script scheduling is not available. This feature is currently disabled."
// with a button to navigate back to /scripts

// The page structure follows this pattern:
<AppLayout>
  {featureEnabled ? (
    <ScheduleScriptView scriptId="abc123" />
  ) : (
    <NotFoundError message="..." onHome={() => router.push('/scripts')} />
  )}
</AppLayout>
```

The component demonstrates proper Next.js 13+ app router patterns with client-side rendering, parameter extraction, and feature flag-based conditional rendering for graceful feature rollouts.
