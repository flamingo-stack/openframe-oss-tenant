A Next.js page component that renders the script scheduling interface, with feature flag protection to ensure the functionality is only available when enabled.

## Key Components

- **ScheduleScriptPage** - Main page component that handles script scheduling UI
- **Feature Flag Check** - Validates if script scheduling is enabled via `featureFlags.scriptSchedule.enabled()`
- **Route Parameter Extraction** - Extracts script ID from URL parameters
- **Error Handling** - Shows NotFoundError when feature is disabled

## Usage Example

This page is accessed via the Next.js router at a route like `/scripts/[id]/schedule`:

```typescript
// URL: /scripts/abc123/schedule
// The component will:
// 1. Extract 'abc123' as the script ID
// 2. Check if script scheduling feature is enabled
// 3. Either show ScheduleScriptView or NotFoundError

// Feature flag configuration example
const featureFlags = {
  scriptSchedule: {
    enabled: () => process.env.NEXT_PUBLIC_ENABLE_SCRIPT_SCHEDULE === 'true'
  }
}
```

The component uses client-side rendering (`'use client'`) and integrates with the app's layout system, providing a consistent user experience while gracefully handling disabled features through the feature flag system.
