A Next.js page component that renders the script scheduling interface with feature flag protection and route parameter handling.

## Key Components

- **ScheduleScriptPage** - Main page component that handles script scheduling functionality
- **Feature Flag Check** - Validates if script scheduling is enabled via `featureFlags.scriptSchedule.enabled()`
- **Route Parameters** - Extracts script ID from URL parameters using Next.js `useParams` hook
- **Error Handling** - Shows `NotFoundError` when feature is disabled with navigation back to scripts list

## Usage Example

```typescript
// This page is automatically rendered when navigating to:
// /scripts/schedule/[id] route

// Example URL: /scripts/schedule/abc123
// The component will extract 'abc123' as the script ID

// If feature flag is disabled, user sees:
// "Script scheduling is not available. This feature is currently disabled."
// with option to return to /scripts page

// If feature is enabled, renders:
// <ScheduleScriptView scriptId="abc123" />
```

The component uses the `AppLayout` wrapper for consistent UI structure and integrates with the OpenFrame frontend core for standardized error handling. The feature flag system allows this functionality to be toggled without code deployment.
