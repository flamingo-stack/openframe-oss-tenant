A Next.js client-side page component that renders the schedule script management interface for a specific script identified by URL parameters.

## Key Components

- **ScheduleScriptPage** - Main page component that extracts script ID from URL parameters and renders the schedule script view within the application layout
- **AppLayout** - Wrapper component providing consistent application layout structure
- **ScheduleScriptView** - Core component for managing scheduled scripts, receiving the script ID as a prop

## Usage Example

This page is automatically rendered when navigating to routes like `/schedule-script/[id]`:

```typescript
// URL: /schedule-script/abc123
// The component extracts 'abc123' as the script ID

function ScheduleScriptPage() {
  const params = useParams<{ id?: string }>()
  const id = typeof params?.id === 'string' ? params.id : ''
  
  return (
    <AppLayout>
      <ScheduleScriptView scriptId={id} />
    </AppLayout>
  )
}
```

The component safely handles cases where the ID parameter might be undefined or an array, defaulting to an empty string. This follows Next.js dynamic routing conventions where `[id]` in the file path creates a route parameter that can be accessed via `useParams()`.
