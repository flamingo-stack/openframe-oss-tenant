A Next.js page component that renders the schedule script view for a specific script ID, extracting the ID from URL parameters.

## Key Components

- **ScheduleScriptPage**: Main page component that serves as a route handler
- **useParams**: Next.js hook to extract the script ID from URL parameters
- **AppLayout**: Layout wrapper component providing consistent page structure
- **ScheduleScriptView**: Core component that handles script scheduling functionality

## Usage Example

This page is accessed via dynamic routing where the script ID is passed as a URL parameter:

```typescript
// URL: /schedule/scripts/abc123
// The component will extract 'abc123' as the script ID

export default function ScheduleScriptPage() {
  const params = useParams<{ id?: string }>()
  const id = typeof params?.id === 'string' ? params.id : ''
  
  return (
    <AppLayout>
      <ScheduleScriptView scriptId={id} />
    </AppLayout>
  )
}
```

The component safely handles cases where no ID is provided by defaulting to an empty string, ensuring the page doesn't crash if accessed without proper parameters. This follows Next.js App Router conventions for dynamic route segments.
