A Next.js page component that renders the schedule script management interface for editing or viewing scheduled automation scripts.

## Key Components

- **ScheduleScriptPage**: Main page component that extracts the script ID from URL parameters and renders the schedule script view
- **AppLayout**: Wrapper component providing the application's layout structure
- **ScheduleScriptView**: Core component for managing scheduled scripts, receiving the script ID as a prop
- **useParams**: Next.js hook for accessing dynamic route parameters

## Usage Example

This page is accessed via dynamic routing where the script ID is passed as a URL parameter:

```typescript
// URL structure: /schedule-scripts/[id]
// Example: /schedule-scripts/abc123

// The component automatically extracts the ID and passes it to ScheduleScriptView
// which handles the script management functionality

// In your routing structure:
// app/
//   schedule-scripts/
//     [id]/
//       page.tsx  <- This component
```

The page ensures type safety by validating that the `id` parameter is a string before passing it to the `ScheduleScriptView` component. If no ID is provided or it's not a string, an empty string is used as the default value.
