A Next.js page component that renders the schedule script editing interface, extracting the script ID from the URL parameters and passing it to the ScheduleScriptView component.

## Key Components

- **ScheduleScriptPage**: Main page component that handles routing for individual script scheduling
- **useParams**: Next.js hook to extract the `id` parameter from the dynamic route
- **AppLayout**: Shared application layout wrapper
- **ScheduleScriptView**: Core component for script scheduling functionality

## Usage Example

```typescript
// This page is accessed via routes like:
// /schedule/script/[id] -> /schedule/script/abc123

// The component automatically extracts the script ID and renders:
function ScheduleScriptPage() {
  const params = useParams<{ id?: string }>()
  const id = typeof params?.id === 'string' ? params.id : ''
  
  return (
    <AppLayout>
      <ScheduleScriptView scriptId={id} />
    </AppLayout>
  )
}
```

This is a client-side rendered page (`'use client'`) that serves as a route handler for `/schedule/script/[id]` paths. It safely extracts the script ID from URL parameters with type checking and passes it to the ScheduleScriptView component for rendering the script scheduling interface within the standard app layout.
