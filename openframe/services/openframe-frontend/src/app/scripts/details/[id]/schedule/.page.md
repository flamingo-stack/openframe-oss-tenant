A Next.js page component that renders the script scheduling interface, with feature flag protection to ensure the functionality is only accessible when enabled.

## Key Components

- **ScheduleScriptPage** - Main page component that handles script scheduling UI
- **Feature flag validation** - Checks if script scheduling is enabled before rendering
- **Route parameter extraction** - Gets script ID from URL parameters
- **Error handling** - Shows NotFoundError when feature is disabled

## Usage Example

```typescript
// This page is accessed via Next.js routing at /scripts/[id]/schedule
// Example URL: /scripts/abc123/schedule

// The component automatically:
// 1. Extracts the script ID from the URL
// 2. Checks if script scheduling feature is enabled
// 3. Either shows the scheduling interface or a not found error

// Feature flag configuration example:
const featureFlags = {
  scriptSchedule: {
    enabled: () => process.env.SCRIPT_SCHEDULE_ENABLED === 'true'
  }
}
```

The page integrates with the Flamingo Stack's feature flag system to conditionally render content, and uses the OpenFrame frontend core for consistent error handling. When the script scheduling feature is disabled, users are redirected back to the main scripts page with an informative error message.
