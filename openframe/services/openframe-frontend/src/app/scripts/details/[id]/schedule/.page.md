A Next.js page component that displays the script scheduling interface, with feature flag protection and error handling for when the feature is disabled.

## Key Components

- **ScheduleScriptPage**: Main page component that renders the script scheduling view
- **Feature Flag Check**: Validates if script scheduling is enabled before rendering
- **Route Parameter Handling**: Extracts script ID from URL parameters
- **Error Boundary**: Shows NotFoundError when feature is disabled

## Usage Example

```typescript
// This page is automatically rendered when navigating to:
// /schedule-script/[id] route

// Example URL patterns:
// /schedule-script/abc123 - Shows scheduling for script ID "abc123"
// /schedule-script/ - Shows scheduling with empty ID

// Feature flag configuration:
import { featureFlags } from '@lib/feature-flags'

// Enable/disable the script scheduling feature
featureFlags.scriptSchedule.enabled() // Returns boolean

// Error handling when feature is disabled
<NotFoundError
  message="Script scheduling is not available..."
  onHome={() => router.push('/scripts')}
/>
```

The component uses Next.js App Router patterns with `useParams` to extract the script ID from the URL, wraps content in the standard `AppLayout`, and gracefully handles feature availability through feature flags. When the script scheduling feature is disabled, users see a helpful error message with navigation back to the scripts list.
