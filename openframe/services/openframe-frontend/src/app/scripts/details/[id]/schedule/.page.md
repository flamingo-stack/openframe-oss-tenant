A Next.js page component that renders the schedule script view for a specific script, extracting the script ID from URL parameters.

## Key Components

- **ScheduleScriptPage** - Main page component that wraps the schedule script view in the application layout
- **useParams** - Next.js hook to extract route parameters from the URL
- **AppLayout** - Shared layout wrapper component
- **ScheduleScriptView** - Core view component for displaying and managing script schedules

## Usage Example

This page is typically accessed via a dynamic route like `/schedule/[id]` where the ID parameter corresponds to a specific script:

```typescript
// URL: /schedule/abc123
// The component will extract 'abc123' as the scriptId

// Route structure in app directory:
// app/
//   schedule/
//     [id]/
//       page.tsx  // This file

// The extracted ID is passed to ScheduleScriptView
<ScheduleScriptView scriptId="abc123" />
```

The component safely handles cases where the ID parameter might be missing or invalid by defaulting to an empty string, ensuring the application remains stable even with malformed URLs.
