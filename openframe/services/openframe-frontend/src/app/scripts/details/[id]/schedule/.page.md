A Next.js client-side page component that renders the script scheduling interface when the feature is enabled, otherwise displays a not found error.

## Key Components

- **ScheduleScriptPage** - Main page component that conditionally renders the scheduling view
- **Feature Flag Check** - Uses `featureFlags.scriptSchedule.enabled()` to control access
- **Route Parameter Extraction** - Extracts script ID from URL parameters
- **Error Handling** - Shows `NotFoundError` when feature is disabled

## Usage Example

```typescript
// This page is accessed via routing at /scripts/[id]/schedule
// Example URL: /scripts/abc123/schedule

// The component automatically:
// 1. Extracts the script ID from the URL
// 2. Checks if script scheduling feature is enabled
// 3. Either shows the scheduling interface or an error page

// Feature flag configuration example:
const featureFlags = {
  scriptSchedule: {
    enabled: () => process.env.ENABLE_SCRIPT_SCHEDULING === 'true'
  }
}
```

The page wraps content in `AppLayout` and handles navigation back to the scripts list when the feature is unavailable. The script ID parameter is passed to `ScheduleScriptView` for rendering the actual scheduling interface.
