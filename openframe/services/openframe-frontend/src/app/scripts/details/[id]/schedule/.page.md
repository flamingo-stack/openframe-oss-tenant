A Next.js page component that renders the schedule script interface with dynamic routing support for viewing and managing specific scripts.

## Key Components

- **ScheduleScriptPage** - Default export page component that handles dynamic script routing
- **AppLayout** - Wrapper component providing consistent application layout
- **ScheduleScriptView** - Core view component for displaying schedule script details
- **useParams** - Next.js hook for accessing dynamic route parameters

## Usage Example

This page is automatically routed by Next.js based on the file structure. The component extracts the script ID from the URL parameters and passes it to the schedule script view:

```typescript
// URL: /schedule-scripts/abc123
// The component will receive params.id = "abc123"

export default function ScheduleScriptPage() {
  const params = useParams<{ id?: string }>()
  const id = typeof params?.id === 'string' ? params.id : ''
  
  return (
    <AppLayout>
      <ScheduleScriptView scriptId={id} />
    </AppLayout>
  )
}
```

The page uses client-side rendering (`'use client'`) to enable dynamic parameter access and provides a fallback empty string when no ID is present in the route. This allows the same component to handle both new script creation and existing script viewing/editing scenarios.
