A Next.js page component that renders the schedule script view interface within the main application layout, handling dynamic routing for individual script management.

## Key Components

- **ScheduleScriptPage**: Main page component that extracts script ID from URL parameters and renders the schedule script interface
- **AppLayout**: Wrapper component providing consistent application layout structure
- **ScheduleScriptView**: Core component for displaying and managing scheduled script details
- **useParams**: Next.js hook for accessing dynamic route parameters

## Usage Example

```typescript
// This page is automatically rendered when navigating to routes like:
// /schedule/scripts/[id] where [id] is a dynamic script identifier

// The component extracts the script ID and passes it to the view:
const params = useParams<{ id?: string }>()
const scriptId = typeof params?.id === 'string' ? params.id : ''

// Example URL: /schedule/scripts/script-123
// Results in: scriptId = "script-123"

// The page renders within the app layout:
<AppLayout>
  <ScheduleScriptView scriptId="script-123" />
</AppLayout>
```

This page serves as a route handler in the OpenFrame platform's scheduling system, providing a clean interface for users to view and manage individual scheduled scripts with proper layout consistency and URL-based navigation.
