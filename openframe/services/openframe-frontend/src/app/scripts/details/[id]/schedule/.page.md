A Next.js client-side page component that renders the script scheduling interface for a specific script, with feature flag protection to ensure the functionality is only available when enabled.

## Key Components

- **ScheduleScriptPage** - Main page component that handles script scheduling UI
- **AppLayout** - Wrapper component providing consistent page layout
- **ScheduleScriptView** - Core view component for script scheduling functionality
- **NotFoundError** - Error component displayed when feature is disabled
- **featureFlags.scriptSchedule** - Feature flag controlling script scheduling availability

## Usage Example

```typescript
// This page is automatically rendered by Next.js routing
// Access via: /scripts/[id]/schedule

// Example route: /scripts/abc123/schedule
// The component will:
// 1. Extract script ID from URL params
// 2. Check if script scheduling feature is enabled
// 3. Either show scheduling UI or feature disabled error

// Feature flag check
if (!featureFlags.scriptSchedule.enabled()) {
  // Shows "Script scheduling is not available" message
  // with button to return to /scripts
}

// When enabled, renders:
<AppLayout>
  <ScheduleScriptView scriptId="abc123" />
</AppLayout>
```

The component uses Next.js `useParams` to extract the script ID from the URL and implements graceful degradation when the script scheduling feature is disabled via feature flags.
