A Next.js client-side page component that renders the schedule device assignment interface, extracting the schedule ID from URL parameters and passing it to the assignment view.

## Key Components

- **ScheduleAssignDevicesPage** - Default exported page component that handles route parameters and renders the device assignment UI
- **Dynamic rendering configuration** - Forces dynamic rendering with `export const dynamic = 'force-dynamic'`
- **Route parameter extraction** - Uses `useParams` to get schedule ID from URL segments

## Usage Example

```typescript
// This page is automatically rendered when navigating to:
// /schedules/[id]/assign-devices

// Example URL: /schedules/abc123/assign-devices
// The component will extract "abc123" as the schedule ID

// Route structure in app directory:
// app/schedules/[id]/assign-devices/page.tsx

// The extracted ID gets passed to ScheduleAssignDevicesView:
<ScheduleAssignDevicesView scheduleId="abc123" />
```

The component follows Next.js 13+ app directory conventions with client-side rendering enabled via the `'use client'` directive. It wraps the assignment view in the standard `AppLayout` component and ensures the schedule ID parameter is properly typed and validated before passing to the child component.
