A Next.js client-side page component that renders a detailed view of a specific schedule item using dynamic routing.

## Key Components

- **ScheduleDetailPage** - Default exported React component that serves as the page entry point
- **Dynamic routing** - Extracts schedule ID from URL parameters using Next.js `useParams` hook
- **AppLayout wrapper** - Provides consistent application layout structure
- **ScheduleDetailView** - Child component that handles the actual schedule detail rendering

## Usage Example

This page component is automatically rendered by Next.js when users navigate to schedule detail routes:

```typescript
// Route: /schedules/[id]/page.tsx
// URL: /schedules/abc123 → renders schedule with ID "abc123"

// The component extracts the ID and passes it down:
<AppLayout>
  <ScheduleDetailView scheduleId="abc123" />
</AppLayout>
```

The `dynamic = 'force-dynamic'` export ensures this page is server-side rendered on each request rather than being statically generated, which is appropriate for dynamic schedule content that may change frequently. The component includes basic error handling by defaulting to an empty string if the ID parameter is not a valid string.
