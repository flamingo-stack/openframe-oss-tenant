A Next.js client-side page component that renders the schedule editing interface, extracting the schedule ID from URL parameters and passing it to the create/edit view component.

## Key Components

- **EditSchedulePage**: Default exported React component that serves as the page entry point
- **dynamic export**: Force dynamic rendering to ensure client-side execution
- **useParams hook**: Extracts route parameters, specifically the schedule ID from the URL
- **AppLayout**: Wrapper component providing consistent application layout structure
- **ScheduleCreateView**: Main view component handling schedule creation/editing logic

## Usage Example

```typescript
// This page is automatically rendered by Next.js routing
// URL: /schedules/edit/[id] where [id] is the schedule ID

// Example URL patterns:
// /schedules/edit/123 → scheduleId = "123"
// /schedules/edit/ → scheduleId = ""

// The component structure:
<AppLayout>
  <ScheduleCreateView scheduleId="extracted-id-from-url" />
</AppLayout>
```

The page uses Next.js App Router conventions with the `'use client'` directive for client-side rendering and `force-dynamic` export to prevent static optimization, ensuring the component can access URL parameters dynamically.
