A Next.js client-side page component that renders the schedule creation interface within the main application layout.

## Key Components

- **CreateSchedulePage** - Default exported React component that serves as the page entry point
- **dynamic export** - Next.js configuration forcing dynamic rendering
- **AppLayout** - Wrapper component providing consistent app structure
- **ScheduleCreateView** - Main view component handling schedule creation functionality

## Usage Example

This page is automatically routed by Next.js based on its file location. The component structure follows a typical layout pattern:

```typescript
// Rendered structure
<AppLayout>
  <ScheduleCreateView />
</AppLayout>
```

The `'use client'` directive ensures this runs on the client side, while `dynamic = 'force-dynamic'` prevents static generation, making it suitable for dynamic content that requires real-time data or user interaction.
