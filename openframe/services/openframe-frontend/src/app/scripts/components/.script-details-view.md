A detailed view component that displays comprehensive information about a script, including its content, metadata, and scheduled runs. The component provides inline code syntax highlighting with synchronized line numbers and includes action buttons for running, editing, and scheduling scripts.

## Key Components

- **ScriptDetailsView**: Main component that renders the complete script details page
- **Script Info Display**: Shows metadata using ScriptInfoSection and InfoCard components
- **Code Syntax Viewer**: Custom implementation with line numbers and synchronized scrolling
- **Action Controls**: Primary buttons for running scripts and dropdown menu for additional actions
- **Conditional Sections**: Environment variables, arguments, and scheduled runs based on data availability
- **Feature Flag Integration**: Conditional rendering of scheduling features based on feature flags

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

// Display script details page
function ScriptPage({ params }: { params: { scriptId: string } }) {
  return <ScriptDetailsView scriptId={params.scriptId} />
}

// The component handles:
// - Loading states with CardLoader
// - Error states with LoadError/NotFoundError
// - Navigation to edit, run, and schedule pages
// - Synchronized scrolling between line numbers and code content
```

The component uses the `useScriptDetails` hook to fetch script data and provides a rich user experience with features like syntax highlighting, responsive layout, and contextual actions based on feature availability.
