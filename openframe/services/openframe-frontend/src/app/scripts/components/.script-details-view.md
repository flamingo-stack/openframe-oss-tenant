A React component that renders a detailed view page for script management, displaying script information, code syntax, arguments, environment variables, and scheduled runs with navigation and action buttons.

## Key Components

- **ScriptDetailsView**: Main component that displays comprehensive script details with loading states and error handling
- **useScriptDetails**: Custom hook for fetching script data by ID
- **ScriptInfoSection**: Component displaying basic script metadata and information
- **ScheduledRunsSection**: Component showing scheduled script executions
- **handleCodeScroll**: Callback for synchronizing scroll between line numbers and code content

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

function ScriptPage({ params }: { params: { id: string } }) {
  return (
    <div className="container mx-auto">
      <ScriptDetailsView scriptId={params.id} />
    </div>
  )
}

// Usage in a Next.js app router
export default function Page({ params }: { params: { scriptId: string } }) {
  return <ScriptDetailsView scriptId={params.scriptId} />
}
```

The component provides a complete interface for viewing script details including:
- Header with navigation back to scripts list
- Action buttons for running, editing, and scheduling scripts  
- Display of script arguments and environment variables in organized cards
- Syntax highlighting with synchronized scrollable line numbers
- Integration with routing for seamless navigation between script management pages
