A comprehensive script details view component that displays script information, code syntax with line numbers, and execution controls for the MSP automation platform.

## Key Components

- **ScriptDetailsView**: Main component that renders the complete script details page with navigation, actions, and content sections
- **useScriptDetails**: Hook for fetching script data and handling loading/error states
- **DetailPageContainer**: Layout wrapper with back navigation and header actions
- **ScriptInfoSection**: Displays basic script metadata and properties
- **ScheduledRunsSection**: Shows scheduled execution history for the script
- **InfoCard**: Displays script arguments and environment variables in organized cards
- **Code Viewer**: Custom syntax highlighter with synchronized line numbers and scrolling

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

// In a Next.js page component
export default function ScriptPage({ params }: { params: { id: string } }) {
  return <ScriptDetailsView scriptId={params.id} />
}

// Route: /scripts/details/[id]
// Shows complete script details with:
// - Script metadata and info
// - Arguments and environment variables
// - Syntax highlighting with line numbers  
// - Run/Edit/Schedule action buttons
// - Scheduled runs history
```

The component handles loading states, error scenarios, and provides a complete script management interface with syntax highlighting, execution controls, and scheduled runs management for MSP automation workflows.
