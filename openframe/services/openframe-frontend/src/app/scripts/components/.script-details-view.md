A React component that renders a detailed view of a script with syntax highlighting, metadata display, and action controls. Part of the OpenFrame script management system.

## Key Components

- **ScriptDetailsView**: Main component that displays comprehensive script information including metadata, arguments, environment variables, and syntax-highlighted code
- **Script Actions**: Run, edit, and schedule script functionality with navigation routing
- **Code Display**: Synchronized scrolling code viewer with line numbers and syntax highlighting
- **Info Cards**: Structured display of script arguments and environment variables
- **Scheduled Runs**: Integration with scheduling system through `ScheduledRunsSection`

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

function ScriptPage({ params }: { params: { id: string } }) {
  return (
    <div className="container mx-auto">
      <ScriptDetailsView scriptId={params.id} />
    </div>
  )
}

// Navigation integration
const router = useRouter()

// View specific script
router.push('/scripts/details/script-123')

// Edit mode
router.push('/scripts/edit/script-123')

// Run script
router.push('/scripts/details/script-123/run')
```

The component handles loading states, error conditions, and provides a comprehensive interface for script management with proper navigation flow between view, edit, run, and schedule modes.
