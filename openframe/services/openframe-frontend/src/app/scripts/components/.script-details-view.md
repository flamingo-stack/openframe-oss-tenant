A React component that displays detailed information about a specific script, including its metadata, arguments, environment variables, syntax highlighting, and scheduled runs with interactive controls for editing and execution.

## Key Components

- **ScriptDetailsView**: Main component that renders a comprehensive script details page
- **useScriptDetails**: Custom hook for fetching script data
- **handleCodeScroll**: Synchronized scrolling between line numbers and code content
- **Navigation handlers**: Functions for routing to edit, run, and schedule views
- **ScriptInfoSection**: Displays basic script metadata
- **ScheduledRunsSection**: Shows scheduled script executions
- **Code syntax display**: Syntax-highlighted script body with line numbers

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

// Display script details page
function ScriptPage() {
  return (
    <ScriptDetailsView scriptId="script-123" />
  )
}

// The component handles loading states and errors automatically
// Provides actions for:
// - Running the script immediately
// - Editing the script
// - Scheduling the script
// - Viewing script arguments and environment variables
```

The component features a responsive layout with synchronized scrolling between line numbers and code content, comprehensive error handling, and integration with the Flamingo navigation system for seamless script management workflows.
