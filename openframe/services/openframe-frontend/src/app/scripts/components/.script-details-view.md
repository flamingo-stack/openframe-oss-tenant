A React component that displays comprehensive details for a specific script, including metadata, arguments, environment variables, and syntax highlighting with an integrated code viewer.

## Key Components

- **Script Information Display**: Shows script metadata through `ScriptInfoSection` component
- **Arguments & Environment Variables**: Renders script arguments and environment variables in `InfoCard` components when available
- **Syntax Viewer**: Custom code display with synchronized line numbers and scrolling for the script body
- **Action Buttons**: Primary "Run Script" button and more actions menu for edit/schedule operations
- **Scheduled Runs**: Conditional display of scheduled runs section based on feature flags
- **Error Handling**: Comprehensive loading, error, and not found states

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

function ScriptPage({ params }: { params: { id: string } }) {
  return (
    <div className="container mx-auto">
      <ScriptDetailsView scriptId={params.id} />
    </div>
  )
}

// Navigation handlers
const handleRunScript = () => {
  router.push(`/scripts/details/${scriptId}/run`)
}

const handleEditScript = () => {
  router.push(`/scripts/edit/${scriptId}`)
}
```

The component integrates with the `useScriptDetails` hook for data fetching and provides a full-featured script management interface with conditional scheduling features controlled by feature flags.
