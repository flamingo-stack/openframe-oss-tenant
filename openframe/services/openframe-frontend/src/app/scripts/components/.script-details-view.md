A React component that displays detailed information about a script, including metadata, arguments, environment variables, and source code with syntax highlighting.

## Key Components

- **ScriptDetailsView** - Main component that renders a comprehensive script details page
- **useScriptDetails** - Custom hook for fetching script data by ID
- **DetailPageContainer** - Layout wrapper with back button and action buttons
- **ScriptInfoSection** - Displays script metadata (description, shell type, platforms, category)
- **ScriptArgumentsCard** - Shows script arguments and environment variables in card format
- **ScriptEditor** - Read-only code editor with syntax highlighting for the script body

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

// In a Next.js page or component
function ScriptDetailsPage({ params }: { params: { id: string } }) {
  return <ScriptDetailsView scriptId={params.id} />
}

// The component handles:
// - Loading states with CardLoader
// - Error states with LoadError/NotFoundError
// - Navigation to edit page: /scripts/edit/{id}
// - Navigation to run page: /scripts/details/{id}/run
// - Back navigation to /scripts list
```

The component provides a complete script management interface with edit and run actions, responsive layout for arguments/environment variables, and syntax-highlighted code viewing. It gracefully handles loading, error, and not-found states while maintaining consistent navigation patterns throughout the application.
