A React component that displays comprehensive details for a script, including metadata, syntax highlighting, and scheduled runs management.

## Key Components

- **ScriptDetailsView**: Main component that renders the complete script details page
- **Script Information Display**: Shows basic script metadata using `ScriptInfoSection`
- **Code Viewer**: Custom syntax-highlighted code display with synchronized line numbers
- **Action Controls**: Header buttons for running, editing, and scheduling scripts
- **Arguments & Environment Variables**: Grid layout showing script configuration
- **Scheduled Runs Management**: Integrated section for managing script schedules

## Usage Example

```typescript
// In a Next.js page or parent component
import { ScriptDetailsView } from './script-details-view'

export default function ScriptPage({ params }: { params: { id: string } }) {
  return <ScriptDetailsView scriptId={params.id} />
}

// The component handles:
// - Loading states with CardLoader
// - Error states with LoadError/NotFoundError
// - Navigation to edit, run, and schedule pages
// - Synchronized scrolling between line numbers and code content
```

The component uses the `useScriptDetails` hook to fetch script data and provides a complete detail view with navigation actions, code syntax highlighting with line numbers, and sections for script arguments, environment variables, and scheduled runs. It includes responsive design with grid layouts and proper error handling for various loading states.
