A React component that displays detailed information about a script, including its properties, source code, and scheduled runs in a comprehensive detail view.

## Key Components

- **ScriptDetailsView**: Main component that renders the script detail page with navigation, actions, and content sections
- **Script Information Display**: Shows script metadata, arguments, and environment variables using InfoCard components
- **Code Viewer**: Custom syntax-highlighted code display with synchronized line numbers and scrolling
- **Action Buttons**: Primary "Run Script" button and more actions menu for editing and scheduling
- **Conditional Features**: Schedule-related functionality controlled by feature flags

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

// Display script details page
function ScriptPage({ params }: { params: { id: string } }) {
  return (
    <ScriptDetailsView scriptId={params.id} />
  )
}

// The component handles:
// - Loading states with CardLoader
// - Error states with LoadError/NotFoundError  
// - Navigation to edit, run, and schedule pages
// - Synchronized scrolling between line numbers and code
```

The component integrates with the OpenFrame frontend core for consistent UI patterns and includes comprehensive error handling, loading states, and responsive layout for script management workflows.
