A React component that renders a detailed view for individual scripts, providing comprehensive information display and action management.

## Key Components

- **ScriptDetailsView**: Main component that displays script details with navigation, actions, and content sections
- **useScriptDetails**: Custom hook for fetching script data and managing loading states
- **handleCodeScroll**: Callback function that synchronizes scrolling between line numbers and code content
- **Navigation handlers**: Functions for routing to edit, run, and schedule script pages
- **Action menu**: Dropdown menu with edit and schedule options, plus primary run button

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

// Display script details page
function ScriptPage({ params }: { params: { id: string } }) {
  return (
    <div className="h-screen">
      <ScriptDetailsView scriptId={params.id} />
    </div>
  )
}

// Usage in Next.js app router
export default function Page({ params }: { params: { scriptId: string } }) {
  return <ScriptDetailsView scriptId={params.scriptId} />
}
```

The component features a responsive layout with script metadata, arguments, environment variables, and syntax highlighting with synchronized line numbers. It includes loading states, error handling, and comprehensive navigation actions for script management workflows.
