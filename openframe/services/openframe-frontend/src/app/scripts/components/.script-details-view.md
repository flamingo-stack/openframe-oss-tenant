A React component that displays detailed information about a specific script in an MSP automation platform, including its configuration, syntax, and scheduled runs.

## Key Components

- **ScriptDetailsView** - Main component that renders script details with editing, running, and scheduling capabilities
- **useScriptDetails** - Custom hook for fetching script data
- **ScriptInfoSection** - Displays basic script information
- **ScheduledRunsSection** - Shows scheduled script executions
- **Code Viewer** - Syntax-highlighted script body with synchronized line numbers

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

function ScriptPage({ params }: { params: { id: string } }) {
  return (
    <div className="container mx-auto">
      <ScriptDetailsView scriptId={params.id} />
    </div>
  )
}

// Navigation handlers
const handleRunScript = () => {
  router.push(`/scripts/details/${scriptId}/run`)
}

const handleEditScript = () => {
  router.push(`/scripts/edit/${scriptId}`)
}
```

The component features a responsive layout with action buttons for running and scheduling scripts, displays script arguments and environment variables in cards, and includes a code viewer with synchronized scrolling between line numbers and content. It handles loading states, errors, and missing scripts with appropriate fallback components.
