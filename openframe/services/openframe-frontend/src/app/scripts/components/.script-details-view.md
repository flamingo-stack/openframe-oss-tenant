A React component that renders a detailed view page for displaying script information, code, and execution options in the OpenFrame script management interface.

## Key Components

- **ScriptDetailsView** - Main component that displays comprehensive script details including metadata, arguments, environment variables, and code syntax
- **Script Information Display** - Uses `ScriptInfoSection` to show basic script details
- **Code Viewer** - Custom syntax-highlighted code display with synchronized line numbers and scrolling
- **Action Buttons** - Run script, edit script, and conditional schedule script functionality
- **Scheduled Runs** - Conditionally rendered section for viewing scheduled executions
- **Error Handling** - Loading states, error messages, and not found scenarios

## Usage Example

```typescript
// Used in a Next.js page to display script details
import { ScriptDetailsView } from './script-details-view'

export default function ScriptDetailsPage({ params }: { params: { id: string } }) {
  return <ScriptDetailsView scriptId={params.id} />
}

// The component handles all internal state and navigation
// Provides actions for:
// - Editing the script (/scripts/edit/{id})
// - Running the script (/scripts/details/{id}/run) 
// - Scheduling the script (/scripts/details/{id}/schedule) - if enabled
// - Navigating back to scripts list (/scripts)
```

The component integrates with the script management system through the `useScriptDetails` hook and provides a comprehensive interface for viewing and managing individual scripts with proper error handling and responsive design.
