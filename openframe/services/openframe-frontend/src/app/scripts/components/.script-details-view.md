A React component that renders a detailed view of a script with syntax highlighting, arguments, environment variables, and action buttons for editing, running, and scheduling.

## Key Components

- **ScriptDetailsView** - Main component that displays comprehensive script details with code viewer
- **handleCodeScroll** - Callback for synchronizing line numbers with code content scroll
- **headerActions** - JSX element containing action buttons (Run, Edit, Schedule) with conditional scheduling
- **moreActionsItems** - Array of additional actions in dropdown menu, conditionally includes scheduling
- **Code viewer** - Custom implementation with synchronized line numbers and syntax highlighting

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

export default function ScriptPage({ params }: { params: { id: string } }) {
  return (
    <div className="min-h-screen">
      <ScriptDetailsView scriptId={params.id} />
    </div>
  )
}

// The component handles all loading states and navigation:
// - Shows CardLoader while fetching script data
// - Displays LoadError if script fetch fails  
// - Shows NotFoundError if script doesn't exist
// - Renders full script details with syntax-highlighted code viewer
```

The component uses the `useScriptDetails` hook to fetch script data and provides a comprehensive interface with synchronized scrolling between line numbers and code content, conditional feature flag support for scheduling, and integrated navigation actions.
