A React component that provides a comprehensive view for displaying script details, including metadata, code syntax, and scheduled runs with navigation and action controls.

## Key Components

- **ScriptDetailsView**: Main component that renders the script details page
- **useScriptDetails**: Custom hook for fetching script data
- **ScriptInfoSection**: Displays basic script information
- **ScheduledRunsSection**: Shows scheduled execution history
- **DetailPageContainer**: Layout wrapper with header actions
- **InfoCard**: Component for displaying key-value data

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

export default function ScriptPage({ params }: { params: { id: string } }) {
  return <ScriptDetailsView scriptId={params.id} />
}
```

The component handles loading states, error scenarios, and provides navigation to edit, run, and schedule scripts. It features a synchronized scrollable code viewer with line numbers, dynamic argument/environment variable display, and responsive layout with mobile optimization. The interface includes a "Run Script" primary action button and additional actions menu for editing and scheduling operations.
