A React component that displays detailed information about a script, including its content, arguments, environment variables, and scheduled runs, with options to run, edit, or schedule the script.

## Key Components

- **ScriptDetailsView**: Main component that renders the complete script details page
- **useScriptDetails**: Custom hook for fetching script data
- **handleCodeScroll**: Synchronized scrolling between line numbers and code content
- **Navigation handlers**: Functions for routing to edit, run, and schedule pages
- **Conditional rendering**: Shows different sections based on available data and feature flags

## Usage Example

```typescript
import { ScriptDetailsView } from './components/script-details-view'

// Basic usage in a page component
export default function ScriptPage({ params }: { params: { id: string } }) {
  return (
    <div className="container mx-auto">
      <ScriptDetailsView scriptId={params.id} />
    </div>
  )
}

// The component handles all states internally:
// - Loading state with CardLoader
// - Error state with LoadError 
// - Not found state with NotFoundError
// - Success state with full script details
```

The component features a responsive layout with synchronized code viewer, conditional action buttons based on feature flags, and comprehensive error handling. It integrates with the routing system to enable script management workflows.
