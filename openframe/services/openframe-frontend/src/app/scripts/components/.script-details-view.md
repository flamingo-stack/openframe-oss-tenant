A React component that displays detailed information about a script, including its metadata, code syntax, and scheduled runs with actions for editing, running, and scheduling.

## Key Components

- **ScriptDetailsView** - Main component that renders script details page
- **useScriptDetails** - Custom hook for fetching script data
- **DetailPageContainer** - Layout wrapper with header and navigation
- **ScriptInfoSection** - Component displaying basic script information
- **ScheduledRunsSection** - Component showing scheduled executions
- **InfoCard** - Displays script arguments and environment variables
- **MoreActionsMenu** - Dropdown menu for additional script actions

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

function ScriptPage({ params }: { params: { id: string } }) {
  return <ScriptDetailsView scriptId={params.id} />
}

// The component handles:
// - Loading states with CardLoader
// - Error states with LoadError/NotFoundError  
// - Navigation to edit, run, and schedule pages
// - Synchronized scrolling for code syntax viewer
// - Responsive layout for script metadata cards
```

The component features a code syntax viewer with line numbers, synchronized scrolling, and displays script arguments and environment variables in organized cards. It includes action buttons for running scripts immediately or scheduling them for later execution.
