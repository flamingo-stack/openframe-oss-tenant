A React component that displays detailed information about a script including its metadata, source code, and scheduled runs. It provides a comprehensive view with actions for editing, running, and scheduling scripts.

## Key Components

- **ScriptDetailsView**: Main component that renders the complete script details page
- **useScriptDetails**: Custom hook for fetching script data
- **ScriptInfoSection**: Child component displaying script metadata
- **ScheduledRunsSection**: Child component showing scheduled executions (feature-flagged)
- **InfoCard**: Displays script arguments and environment variables in a structured format
- **Code Viewer**: Custom syntax-highlighted code display with synchronized line numbers

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

export default function ScriptPage({ params }: { params: { id: string } }) {
  return <ScriptDetailsView scriptId={params.id} />
}

// The component handles all states internally:
// - Loading state with CardLoader
// - Error state with LoadError
// - Not found state with NotFoundError
// - Success state with full script details
```

## Features

- **Navigation**: Back to scripts list and edit/run/schedule actions
- **Code Display**: Syntax-highlighted script body with line numbers and synchronized scrolling
- **Conditional Rendering**: Shows arguments and environment variables only when present
- **Feature Flags**: Schedule functionality is controlled by feature flags
- **Responsive Layout**: Adapts to different screen sizes with grid layouts
