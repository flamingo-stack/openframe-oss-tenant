A React component that displays detailed information about a script, including its metadata, arguments, environment variables, and syntax with a code viewer.

## Key Components

- **ScriptDetailsView** - Main component that renders the script details page with navigation, actions, and multiple information sections
- **useScriptDetails** - Custom hook for fetching script data
- **ScriptInfoSection** - Component displaying basic script information
- **ScheduledRunsSection** - Component showing scheduled script executions
- **Code Viewer** - Custom implementation with synchronized line numbers and scroll

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

// Display script details page
function ScriptPage({ params }: { params: { id: string } }) {
  return <ScriptDetailsView scriptId={params.id} />
}

// The component handles:
// - Loading states with CardLoader
// - Error states with LoadError/NotFoundError
// - Navigation to edit, run, and schedule pages
// - Displaying script syntax with line numbers
// - Showing script arguments and environment variables
```

The component provides a comprehensive view of script details with actions for editing, running, and scheduling scripts. It includes a synchronized code viewer that displays the script body with line numbers, and conditionally renders sections for arguments and environment variables based on data availability.
