A React component that renders a detailed view of a script with code preview, metadata, and navigation actions. The component displays script information, arguments, environment variables, syntax highlighting, and scheduled runs in a structured layout.

## Key Components

- **ScriptDetailsView** - Main component that fetches and displays script details with loading states
- **Navigation Actions** - Edit, schedule, and run script buttons with routing integration
- **Script Information Display** - Arguments, environment variables, and metadata cards
- **Code Preview** - Syntax-highlighted script body with synchronized line numbers
- **Scheduled Runs Integration** - Embedded section showing script scheduling information

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

// Display script details page
function ScriptPage({ params }: { params: { id: string } }) {
  return (
    <div className="container">
      <ScriptDetailsView scriptId={params.id} />
    </div>
  )
}

// Usage with error boundaries
function ScriptDetailsPage() {
  const scriptId = "script-123"
  
  return (
    <Suspense fallback={<CardLoader items={4} />}>
      <ScriptDetailsView scriptId={scriptId} />
    </Suspense>
  )
}
```

The component handles loading states, error conditions, and provides a comprehensive interface for viewing and managing script details within the Flamingo platform.
