A React component that displays comprehensive details for a single script, including metadata, arguments, environment variables, and the script's source code with syntax highlighting.

## Key Components

- **ScriptDetailsView**: Main component that renders a detailed view of a script
- **useScriptDetails**: Custom hook for fetching script data
- **handleCodeScroll**: Synchronized scrolling between line numbers and code content
- **Navigation handlers**: Functions for routing to edit, run, and schedule operations
- **Conditional rendering**: Feature flag-based display of scheduling functionality

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

function ScriptPage({ params }: { params: { id: string } }) {
  return (
    <div className="container mx-auto">
      <ScriptDetailsView scriptId={params.id} />
    </div>
  )
}

// The component automatically handles:
// - Loading states with CardLoader
// - Error states with LoadError/NotFoundError
// - Script execution via Run Script button
// - Navigation to edit/schedule pages
// - Synchronized scrolling in code viewer

export default ScriptPage
```

The component provides a comprehensive script management interface with actions for running, editing, and scheduling scripts. It features a custom code viewer with line numbers and synchronized scrolling, displays script arguments and environment variables in organized cards, and integrates with feature flags to conditionally show scheduling functionality.
