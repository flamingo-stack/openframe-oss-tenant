A React component that displays detailed information about a specific script, including its metadata, syntax, and scheduled runs with actions to edit, run, and schedule the script.

## Key Components

- **ScriptDetailsView**: Main component that renders script details with navigation and actions
- **Custom hooks**: Uses `useScriptDetails` for data fetching
- **UI sections**: Renders `ScriptInfoSection` and `ScheduledRunsSection` for organized content
- **Code viewer**: Custom syntax-highlighted code display with synchronized line numbers
- **Feature flags**: Conditionally shows schedule-related features based on `featureFlags.scriptSchedule`

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

// Render script details page
function ScriptPage({ params }: { params: { id: string } }) {
  return (
    <ScriptDetailsView scriptId={params.id} />
  )
}

// The component handles:
// - Loading states with CardLoader
// - Error states with LoadError/NotFoundError  
// - Navigation back to scripts list
// - Script actions (edit, run, schedule)
// - Displaying script arguments and environment variables
// - Syntax highlighting with line numbers
```

The component provides a comprehensive view of script details with intuitive navigation, action buttons, and conditionally rendered sections based on available data and feature flags. It includes proper error handling and loading states for a smooth user experience.
