A React component that renders a detailed view of a script with information, actions, and execution options. It provides a comprehensive interface for viewing script details, source code, and managing script operations.

## Key Components

- **ScriptDetailsView** - Main component that displays script information and controls
- **useScriptDetails** - Custom hook for fetching script data
- **ScriptInfoSection** - Displays basic script metadata and information
- **ScheduledRunsSection** - Shows scheduled execution history and management
- **InfoCard** - Renders script arguments and environment variables in organized cards
- **Code Editor** - Syntax-highlighted code viewer with line numbers and synchronized scrolling

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

// Display script details page
function ScriptPage({ params }: { params: { id: string } }) {
  return (
    <ScriptDetailsView scriptId={params.id} />
  )
}

// Navigate to script details
router.push(`/scripts/details/${scriptId}`)
```

The component handles loading states, error conditions, and provides navigation actions like editing, running, and scheduling scripts. It features a responsive layout with code syntax highlighting and synchronized scroll between line numbers and code content.
