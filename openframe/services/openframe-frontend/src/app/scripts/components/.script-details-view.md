A React component that displays detailed information about a script, including metadata, syntax highlighting, and action buttons for running, editing, and scheduling scripts.

## Key Components

- **ScriptDetailsView**: Main component that fetches and displays comprehensive script information
- **useScriptDetails**: Custom hook for loading script data and handling loading states
- **DetailPageContainer**: Layout wrapper with header, back button, and action buttons
- **ScriptInfoSection**: Displays script metadata and basic information
- **ScheduledRunsSection**: Shows scheduled runs when scheduling feature is enabled
- **InfoCard**: Displays script arguments and environment variables in structured format
- **Syntax viewer**: Custom code display with line numbers and synchronized scrolling

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

// Display script details page
function ScriptPage({ params }: { params: { id: string } }) {
  return <ScriptDetailsView scriptId={params.id} />
}

// The component handles:
// - Loading states with CardLoader
// - Error states with LoadError/NotFoundError  
// - Navigation to edit, run, and schedule pages
// - Feature flag checks for scheduling functionality
// - Synchronized scrolling between line numbers and code content
```

The component provides a complete script management interface with conditional features based on feature flags and responsive layout for arguments and environment variables display.
