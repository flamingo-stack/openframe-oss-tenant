A comprehensive React component that displays detailed information about a script, including its metadata, arguments, environment variables, and syntax with line numbers.

## Key Components

- **ScriptDetailsView**: Main component that renders the complete script details view
- **Custom hooks**: Uses `useScriptDetails` for data fetching
- **Navigation handlers**: Functions for routing to edit, run, and schedule operations
- **Scroll synchronization**: Synchronized scrolling between line numbers and code content
- **Feature flag integration**: Conditional rendering based on `scriptSchedule` feature flag
- **Error handling**: Comprehensive error states with loading, not found, and error components

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

// Basic usage with script ID
function ScriptPage({ params }: { params: { id: string } }) {
  return <ScriptDetailsView scriptId={params.id} />
}

// The component automatically handles:
// - Loading states with CardLoader
// - Error states with LoadError
// - Not found states with NotFoundError
// - Conditional rendering based on feature flags
```

The component provides a complete script management interface with actions for running, editing, and scheduling scripts, along with detailed syntax highlighting and metadata display.
