A React component that displays detailed information about a specific script, including metadata, code syntax, and scheduled runs with navigation and action capabilities.

## Key Components

- **ScriptDetailsView** - Main component that renders the complete script details page
- **useScriptDetails** - Custom hook for fetching script data
- **handleCodeScroll** - Synchronized scrolling between line numbers and code content
- **Navigation handlers** - Functions for routing to edit, run, and schedule operations
- **ScriptInfoSection** - Sub-component displaying script metadata
- **ScheduledRunsSection** - Sub-component showing scheduled execution history

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

function ScriptPage({ params }: { params: { id: string } }) {
  return (
    <ScriptDetailsView scriptId={params.id} />
  )
}

// The component automatically handles:
// - Loading states with CardLoader
// - Error states with LoadError/NotFoundError  
// - Script arguments and environment variables display
// - Syntax highlighting with line numbers
// - Action buttons for run/edit/schedule operations
```

The component provides a comprehensive view with synchronized code scrolling, responsive layout for arguments/environment variables, and integrated navigation to related script operations. It uses the DetailPageContainer layout with header actions and handles all loading/error states gracefully.
