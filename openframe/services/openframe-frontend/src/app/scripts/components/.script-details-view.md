A React component that displays detailed information about a specific script, including its metadata, arguments, environment variables, syntax highlighting, and scheduled runs.

## Key Components

- **ScriptDetailsView** - Main component that renders a comprehensive script detail page with navigation, actions, and content sections
- **useScriptDetails** - Custom hook for fetching script data
- **ScriptInfoSection** - Component displaying basic script information
- **ScheduledRunsSection** - Component showing scheduled script executions
- **Code viewer** - Custom implementation with synchronized line numbers and scroll

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

// Render script details page
function ScriptPage({ params }: { params: { id: string } }) {
  return <ScriptDetailsView scriptId={params.id} />
}

// Component handles all loading states and navigation
<ScriptDetailsView scriptId="script-123" />
```

## Features

- **Loading States**: Shows card loader during data fetch and handles errors appropriately
- **Navigation**: Provides back button and action buttons for editing, scheduling, and running scripts
- **Code Display**: Features a custom code viewer with line numbers and synchronized scrolling
- **Responsive Layout**: Uses grid system for arguments and environment variables on larger screens
- **Action Menu**: Includes dropdown menu for additional script actions

The component automatically handles routing to related pages (edit, run, schedule) and displays script arguments, environment variables, and syntax-highlighted code body when available.
