A React component that renders a detailed view page for viewing and managing individual scripts in the OpenFrame platform.

## Key Components

- **ScriptDetailsView** - Main component that displays script details with loading, error, and not-found states
- **useScriptDetails** - Custom hook for fetching script data
- **ScriptInfoSection** - Component displaying basic script information
- **ScheduledRunsSection** - Component showing scheduled script executions (when scheduling is enabled)
- **Code viewer** - Custom implementation with synchronized line numbers and scrollable content
- **Action handlers** - Methods for running, editing, and scheduling scripts

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

export default function ScriptPage({ params }: { params: { id: string } }) {
  return <ScriptDetailsView scriptId={params.id} />
}
```

The component provides a comprehensive script management interface with:

- **Header actions** - Run script button and more actions menu (edit, schedule)
- **Script information** - Basic details and metadata
- **Arguments and environment variables** - Displayed in grid layout when present
- **Syntax highlighting** - Code viewer with line numbers and bash syntax highlighting
- **Scheduled runs** - Integration with scheduling feature when enabled
- **Navigation** - Back to scripts list and routing to edit/run/schedule pages

The component handles all loading states, errors, and feature flag-based conditional rendering for the scheduling functionality.
