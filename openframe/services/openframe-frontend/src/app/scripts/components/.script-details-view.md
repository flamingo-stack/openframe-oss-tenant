A React component that renders a detailed view page for displaying individual script information, including code syntax highlighting, arguments, environment variables, and execution controls.

## Key Components

- **ScriptDetailsView** - Main component that displays comprehensive script details with run/edit/schedule actions
- **useScriptDetails** - Custom hook for fetching script data
- **DetailPageContainer** - Layout wrapper with header actions and navigation
- **ScriptInfoSection** - Component displaying basic script information
- **ScheduledRunsSection** - Section showing scheduled executions (feature-flagged)
- **InfoCard** - Reusable component for displaying key-value pairs
- **MoreActionsMenu** - Dropdown menu for additional script actions

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

// Display script details page
function ScriptPage({ params }: { params: { id: string } }) {
  return <ScriptDetailsView scriptId={params.id} />
}

// The component handles:
// - Loading states with CardLoader
// - Error states with LoadError/NotFoundError
// - Navigation to edit/run/schedule pages
// - Synchronized scrolling between line numbers and code
// - Feature flag checks for scheduling functionality
```

The component includes a code viewer with synchronized line numbers, displays script arguments and environment variables in organized cards, and provides action buttons for running, editing, and scheduling scripts based on feature flag settings.
