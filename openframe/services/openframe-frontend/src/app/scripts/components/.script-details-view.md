A React component that displays detailed information about a specific script, including metadata, code syntax, and scheduled runs with integrated navigation and action controls.

## Key Components

- **ScriptDetailsView**: Main component that renders the complete script details page
- **useScriptDetails**: Custom hook for fetching script data
- **Navigation handlers**: Functions for routing to edit, run, and schedule pages
- **Synchronized scroll**: Custom implementation for line numbers and code content
- **Action menu**: Edit and schedule options with icons
- **Content sections**: Script info, arguments, environment variables, and syntax display

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

// Display script details page
function ScriptPage({ params }: { params: { id: string } }) {
  return (
    <ScriptDetailsView scriptId={params.id} />
  )
}

// The component handles loading states, errors, and renders:
// - Script metadata and information
// - Arguments and environment variables in grid layout
// - Syntax highlighting with line numbers
// - Scheduled runs section
// - Action buttons (Run, Edit, Schedule)
```

The component provides a comprehensive script management interface with synchronized scrolling between line numbers and code content, responsive grid layouts for script parameters, and integrated navigation to related script operations.
