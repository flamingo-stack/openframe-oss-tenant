A React component that renders a detailed view of a script with comprehensive information display and action controls for the OpenFrame script management system.

## Key Components

- **ScriptDetailsView** - Main component that displays script details including metadata, arguments, environment variables, and source code
- **useScriptDetails** - Hook for fetching script data
- **Navigation handlers** - Functions for routing to edit, run, and schedule operations
- **Code display** - Syntax-highlighted code viewer with synchronized line numbers
- **Action controls** - Header buttons and menu for script operations

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

// Display script details page
function ScriptPage({ params }: { params: { id: string } }) {
  return (
    <div className="container">
      <ScriptDetailsView scriptId={params.id} />
    </div>
  )
}

// The component handles:
// - Loading states with CardLoader
// - Error states with LoadError/NotFoundError
// - Navigation to /scripts/edit/{id}, /scripts/details/{id}/run, etc.
// - Displaying script arguments and environment variables in InfoCards
// - Code syntax highlighting with line numbers
```

The component provides a complete script management interface with actions for editing, running, and scheduling scripts, plus detailed information display including arguments, environment variables, and syntax-highlighted source code.
