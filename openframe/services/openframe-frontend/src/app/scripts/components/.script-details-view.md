A comprehensive script details view component that displays script information, code syntax, and scheduled runs with interactive actions for running, editing, and scheduling scripts.

## Key Components

- **ScriptDetailsView**: Main component that renders script details with navigation and action buttons
- **useScriptDetails**: Custom hook for fetching script data
- **ScriptInfoSection**: Displays basic script information
- **ScheduledRunsSection**: Shows scheduled script executions
- **Code viewer**: Syntax-highlighted script body with synchronized line numbers

## Usage Example

```typescript
// Display script details page
<ScriptDetailsView scriptId="script-123" />

// The component handles:
// - Loading states with CardLoader
// - Error states with LoadError/NotFoundError
// - Navigation to edit, run, and schedule pages
// - Displaying script arguments and environment variables
// - Code syntax highlighting with line numbers
```

## Features

- **Interactive Actions**: Run, edit, and schedule script functionality
- **Code Display**: Syntax-highlighted script body with scrollable line numbers
- **Responsive Layout**: Adaptive grid layout for script arguments and environment variables
- **Navigation**: Back button and programmatic routing to related pages
- **Error Handling**: Comprehensive loading and error state management

The component provides a complete script management interface within the OpenFrame MSP platform, allowing technicians to view, execute, and manage automation scripts effectively.
