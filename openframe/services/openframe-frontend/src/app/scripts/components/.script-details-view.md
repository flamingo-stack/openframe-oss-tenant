A React component that renders a detailed view page for individual script management, including script information, code display, and scheduled runs.

## Key Components

- **ScriptDetailsView** - Main component that displays comprehensive script details with navigation and action controls
- **useScriptDetails** - Custom hook for fetching script data and managing loading states
- **handleCodeScroll** - Callback function that synchronizes scrolling between line numbers and code content
- **Navigation handlers** - Functions for routing to edit, run, and schedule script pages
- **ScriptInfoSection** - Child component displaying basic script metadata
- **ScheduledRunsSection** - Child component showing script scheduling information

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

// Render script details page
function ScriptPage({ params }: { params: { id: string } }) {
  return (
    <div className="h-full">
      <ScriptDetailsView scriptId={params.id} />
    </div>
  )
}

// Use with Next.js dynamic routing
export default function Page({ params }: { params: { scriptId: string } }) {
  return <ScriptDetailsView scriptId={params.scriptId} />
}
```

The component features a synchronized code viewer with line numbers, action buttons for script management (run, edit, schedule), and displays script arguments and environment variables in organized cards. It handles loading states, errors, and provides a complete interface for script inspection and management within the Flamingo platform.
