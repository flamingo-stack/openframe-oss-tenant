A React component that provides a detailed view interface for script management, displaying comprehensive script information, code syntax highlighting, and execution controls.

## Key Components

- **ScriptDetailsView**: Main component that renders the complete script details page with loading states and error handling
- **useScriptDetails**: Custom hook for fetching and managing script data
- **ScriptInfoSection**: Component displaying basic script metadata and information
- **ScheduledRunsSection**: Component showing scheduled script executions and their status
- **Code Viewer**: Custom syntax-highlighted code display with synchronized line numbers and scrolling

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

function ScriptPage({ params }: { params: { scriptId: string } }) {
  return (
    <div className="container">
      <ScriptDetailsView scriptId={params.scriptId} />
    </div>
  )
}

// Navigation usage
const handleViewScript = (scriptId: string) => {
  router.push(`/scripts/details/${scriptId}`)
}
```

The component provides a comprehensive interface for viewing script details including metadata, arguments, environment variables, syntax highlighting with line numbers, and quick actions for editing, running, and scheduling scripts. It handles loading states and error conditions gracefully while maintaining a responsive layout across different screen sizes.
