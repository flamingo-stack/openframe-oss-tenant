A comprehensive React component that renders a detailed view page for individual scripts with code syntax highlighting, execution controls, and scheduling management.

## Key Components

- **ScriptDetailsView**: Main component that displays script details including metadata, arguments, environment variables, and syntax
- **useScriptDetails**: Custom hook for fetching script data with loading and error states
- **Code Display**: Synchronized scrollable code viewer with line numbers for script syntax
- **Action Controls**: Primary actions (Run Script) and secondary menu options (Edit, Schedule)
- **Information Sections**: Displays script arguments and environment variables in structured cards
- **ScheduledRunsSection**: Embedded component showing scheduled executions for the script

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

// Display detailed view for a specific script
function ScriptPage({ params }: { params: { id: string } }) {
  return <ScriptDetailsView scriptId={params.id} />
}

// The component handles:
// - Loading states with CardLoader
// - Error handling with LoadError/NotFoundError  
// - Navigation to edit, run, and schedule pages
// - Parsing and displaying script arguments/env vars
// - Synchronized scrolling between line numbers and code content
```

The component provides a complete script management interface with execution capabilities, detailed metadata display, and integrated scheduling functionality within the OpenFrame platform.
