A React component that renders a detailed view of a script with code display, actions, and scheduling information. It provides a comprehensive interface for viewing script details, running scripts, and managing scheduled executions.

## Key Components

- **ScriptDetailsView** - Main component that displays complete script information
- **useScriptDetails** - Custom hook for fetching script data
- **ScriptInfoSection** - Component displaying basic script metadata
- **ScheduledRunsSection** - Component showing scheduled script executions
- **Code Viewer** - Synchronized scrolling code display with line numbers
- **Navigation Actions** - Edit, run, and schedule script functionality

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

function ScriptPage({ params }: { params: { id: string } }) {
  return (
    <div className="min-h-screen">
      <ScriptDetailsView scriptId={params.id} />
    </div>
  )
}

// Route: /scripts/details/[id]
export default function Page({ params }: { params: { id: string } }) {
  return <ScriptDetailsView scriptId={params.id} />
}
```

The component handles loading states, error conditions, and provides a rich interface with:
- Script code display with syntax highlighting and line numbers
- Action buttons for running and scheduling scripts
- Environment variables and arguments visualization
- Navigation back to scripts list
- Responsive layout with grid-based sections
