A React component that provides a detailed view for individual scripts in the Flamingo platform, displaying script information, code syntax, and scheduled runs with navigation and action controls.

## Key Components

- **ScriptDetailsView** - Main component that renders the complete script details page
- **useScriptDetails** - Custom hook for fetching script data
- **DetailPageContainer** - Layout wrapper with header actions and navigation
- **ScriptInfoSection** - Displays basic script metadata
- **ScheduledRunsSection** - Shows upcoming and past scheduled executions
- **InfoCard** - Renders script arguments and environment variables
- **Code viewer** - Synchronized scrollable code display with line numbers

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

// Render script details page
function ScriptPage({ params }: { params: { id: string } }) {
  return <ScriptDetailsView scriptId={params.id} />
}

// The component handles:
// - Loading states with CardLoader
// - Error handling with LoadError/NotFoundError  
// - Navigation to edit, run, and schedule pages
// - Synchronized scrolling between line numbers and code
// - Dynamic grid layout for arguments and environment variables
```

The component provides a comprehensive script management interface with syntax highlighting, action buttons for running/editing/scheduling scripts, and organized display of script metadata and configuration details.
