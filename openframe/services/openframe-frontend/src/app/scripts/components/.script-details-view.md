A React component that renders a detailed view of a PowerShell script within the OpenFrame platform, providing script information, syntax highlighting with line numbers, and execution controls.

## Key Components

- **ScriptDetailsView**: Main component that displays script details, syntax, arguments, and scheduled runs
- **useScriptDetails**: Custom hook for fetching script data
- **ScriptInfoSection**: Renders basic script information 
- **ScheduledRunsSection**: Displays scheduled script executions
- **InfoCard components**: Show script arguments and environment variables
- **Syntax viewer**: Code display with synchronized line numbers and scrolling

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

function ScriptPage({ params }: { params: { scriptId: string } }) {
  return (
    <ScriptDetailsView scriptId={params.scriptId} />
  )
}

// Usage in Next.js dynamic route: /scripts/details/[scriptId]
export default ScriptPage
```

The component provides a comprehensive interface for viewing script details with actions for editing, running, and scheduling scripts. It includes error handling for loading states and missing scripts, plus a responsive layout that adapts the arguments/environment variables grid on different screen sizes.
