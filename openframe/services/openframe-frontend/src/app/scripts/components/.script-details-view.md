A React component that renders a detailed view for a script with execution, editing, and scheduling capabilities.

## Key Components

- **ScriptDetailsView**: Main component that displays script details with action buttons for running, editing, and scheduling
- **ScriptInfoSection**: Displays basic script information and metadata
- **ScheduledRunsSection**: Shows scheduled runs associated with the script
- **Code viewer**: Syntax-highlighted script body with synchronized line numbers and scrolling
- **InfoCard sections**: Display script arguments and environment variables in organized cards

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

// Display script details page
function ScriptPage({ params }: { params: { id: string } }) {
  return (
    <ScriptDetailsView scriptId={params.id} />
  )
}

// The component handles all loading states and provides:
// - Navigation back to scripts list
// - Edit script functionality
// - Run script execution
// - Schedule script jobs
// - View script source code with line numbers
// - Display script arguments and environment variables
```

The component uses the `useScriptDetails` hook to fetch script data and provides comprehensive error handling with loading states, error messages, and not-found scenarios. The code viewer features synchronized scrolling between line numbers and content for an enhanced development experience.
