A React component that displays comprehensive details for a script, including metadata, source code, and scheduled runs with interactive controls for editing, running, and scheduling.

## Key Components

- **ScriptDetailsView** - Main component that renders a detailed view of a script with navigation, actions, and content sections
- **useScriptDetails** - Custom hook for fetching script data and managing loading/error states  
- **ScriptInfoSection** - Child component displaying script metadata and information
- **ScheduledRunsSection** - Child component showing scheduled executions for the script
- **Code viewer** - Synchronized scrolling code display with line numbers and syntax highlighting

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

// Display details for a specific script
function ScriptPage({ params }: { params: { id: string } }) {
  return (
    <div className="container mx-auto">
      <ScriptDetailsView scriptId={params.id} />
    </div>
  )
}

// Navigation from script listing
function handleViewScript(scriptId: string) {
  router.push(`/scripts/details/${scriptId}`)
}
```

The component provides a complete script management interface with actions for running, editing, and scheduling scripts. It handles loading states, error conditions, and renders script arguments, environment variables, and source code with proper formatting. The code viewer features synchronized scrolling between line numbers and content for enhanced readability.
