A detailed view component that displays comprehensive information about a script, including its metadata, content, and execution options within the Flamingo Stack automation platform.

## Key Components

- **ScriptDetailsView**: Main component that renders a complete script details page with syntax highlighting, line numbers, and action buttons
- **useScriptDetails**: Custom hook for fetching script data and managing loading/error states
- **ScriptInfoSection**: Displays basic script metadata and information
- **ScheduledRunsSection**: Shows scheduled execution information for the script
- **Synchronized scrolling**: Line numbers and code content scroll together for better code readability

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

function ScriptPage({ params }: { params: { id: string } }) {
  return (
    <div className="min-h-screen">
      <ScriptDetailsView scriptId={params.id} />
    </div>
  )
}

// Navigation usage
const navigateToScript = (scriptId: string) => {
  router.push(`/scripts/details/${scriptId}`)
}
```

The component provides a comprehensive interface for viewing script details with actions for editing, running, and scheduling scripts. It includes error handling for loading states and missing scripts, plus a code viewer with syntax highlighting and synchronized line numbers for script content review.
