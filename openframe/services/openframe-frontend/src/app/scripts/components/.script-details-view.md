A detailed view component for displaying script information, code syntax, and management actions in the OpenFrame script management system.

## Key Components

- **ScriptDetailsView**: Main component that renders a comprehensive script details page with navigation, actions, and content sections
- **useScriptDetails**: Custom hook for fetching script data with loading and error states
- **Navigation handlers**: Functions for routing to edit, run, and schedule script pages
- **Scroll synchronization**: Logic to sync scrolling between line numbers and code content
- **Conditional rendering**: Feature flag-based display of scheduling functionality

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

// Display script details page
function ScriptPage({ params }: { params: { id: string } }) {
  return (
    <div className="min-h-screen">
      <ScriptDetailsView scriptId={params.id} />
    </div>
  )
}

// Usage in Next.js app router
export default function Page({ params }: { params: { scriptId: string } }) {
  return <ScriptDetailsView scriptId={params.scriptId} />
}
```

The component provides a full-featured script management interface with syntax highlighting, argument/environment variable display, scheduled runs (when enabled), and action buttons for editing, running, and scheduling scripts. It handles loading states, errors, and responsive layout for optimal user experience.
