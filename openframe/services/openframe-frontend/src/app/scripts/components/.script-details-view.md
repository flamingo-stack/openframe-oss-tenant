React component that displays comprehensive details for a specific script including metadata, code syntax with line numbers, and scheduled runs in a structured layout.

## Key Components

- **ScriptDetailsView** - Main component for displaying script details with navigation and actions
- **Custom scroll synchronization** - Syncs line numbers with code content scrolling
- **Navigation handlers** - Methods for routing to edit, run, and schedule operations
- **Conditional rendering** - Shows script arguments and environment variables only when present
- **Error handling** - Displays appropriate loading, error, and not found states

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

// Display script details page
function ScriptPage() {
  return (
    <ScriptDetailsView scriptId="script-123" />
  )
}

// Navigation to script details
router.push(`/scripts/details/${scriptId}`)
```

The component fetches script data using the `useScriptDetails` hook and renders a detailed view with:
- Header actions (Run Script button and More Actions menu)
- Script information section
- Optional arguments and environment variables cards
- Syntax viewer with synchronized scrolling line numbers
- Scheduled runs section

The layout is responsive with grid columns that adapt to screen size, and includes comprehensive error states for loading failures and missing scripts.
