A React component that displays detailed information about a specific automation script, including metadata, source code, and scheduled runs. This is a client-side view component that provides a comprehensive overview of script details with navigation and action capabilities.

## Key Components

- **ScriptDetailsView**: Main component that renders the complete script details page
- **useScriptDetails**: Custom hook for fetching script data
- **ScriptInfoSection**: Component displaying basic script metadata
- **ScheduledRunsSection**: Component showing scheduled script runs
- **Navigation handlers**: Functions for routing to edit, run, and schedule views
- **Code viewer**: Syntax-highlighted display with synchronized line numbers

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

export default function ScriptPage({ params }: { params: { id: string } }) {
  return (
    <div className="min-h-screen">
      <ScriptDetailsView scriptId={params.id} />
    </div>
  )
}

// Component handles:
// - Loading states with CardLoader
// - Error states with LoadError/NotFoundError  
// - Navigation to /scripts/edit/{id}, /scripts/details/{id}/run, etc.
// - Interactive code viewer with line numbers
// - Script arguments and environment variables display
// - More actions menu for additional operations
```

The component provides a complete script management interface with run, edit, and scheduling capabilities, along with a detailed code viewer that maintains synchronized scrolling between line numbers and content.
