A React component that displays detailed information about a script, including its metadata, code content, and execution options within a comprehensive detail page layout.

## Key Components

- **ScriptDetailsView**: Main component that renders the complete script details page
- **useScriptDetails**: Custom hook for fetching script data
- **ScriptInfoSection**: Displays basic script information
- **ScheduledRunsSection**: Shows scheduled runs (feature-flagged)
- **DetailPageContainer**: Wrapper providing consistent detail page layout
- **InfoCard**: Displays script arguments and environment variables in card format

## Usage Example

```typescript
import { ScriptDetailsView } from './script-details-view'

// Render script details page
function ScriptPage({ params }: { params: { id: string } }) {
  return <ScriptDetailsView scriptId={params.id} />
}

// The component handles all states internally:
// - Loading: Shows CardLoader with 4 skeleton items
// - Error: Displays LoadError with error message
// - Not Found: Shows NotFoundError message
// - Success: Renders full script details with actions
```

The component features synchronized scrolling between line numbers and code content, conditional rendering based on feature flags, and comprehensive navigation options including edit, run, and schedule actions. It automatically handles different data states and provides a responsive layout that adapts from single-column on mobile to multi-column on larger screens.
