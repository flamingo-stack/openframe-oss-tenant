A React component that renders the detailed view for a script schedule, displaying schedule information and providing tabbed navigation for scripts, devices, and execution history.

## Key Components

- **ScheduleDetailView** - Main component that renders the complete schedule detail page
- **SCHEDULE_TABS** - Configuration array defining the three main tabs:
  - Scheduled Scripts (`ScheduleScriptsTab`)
  - Assigned Devices (`ScheduleDevicesTab`) 
  - Execution History (`ScheduleHistoryTab`)
- **useScriptSchedule** - Custom hook for fetching schedule data
- **Navigation handlers** - Functions for routing to edit pages and back navigation

## Usage Example

```typescript
import { ScheduleDetailView } from './schedule-detail-view'

function SchedulePage({ params }: { params: { id: string } }) {
  return <ScheduleDetailView scheduleId={params.id} />
}

// The component automatically handles:
// - Loading states with ScheduleDetailLoader
// - Error states with LoadError/NotFoundError  
// - Tab navigation with URL synchronization
// - Action buttons for editing schedule and devices
```

The component uses the `DetailPageContainer` layout with tab navigation, includes an info bar showing schedule details, and provides edit actions. It handles loading, error, and not-found states gracefully while maintaining URL synchronization for the active tab.
