A React component that displays the execution history of script schedules in a tabular format with a detailed side panel for viewing individual log entries.

## Key Components

- **`ScheduleHistoryTab`** - Main component that renders a paginated table of script schedule execution history
- **`ScheduleHistoryDrawer`** - Side panel drawer that displays detailed information about a selected history entry
- **`InfoField`** - Utility component for displaying labeled information fields
- **Helper Functions**:
  - `getStatusVariant()` - Maps status strings to UI variant types
  - `getStatusLabel()` - Formats status labels for display
  - `formatDateTime()` - Formats ISO dates for display

## Usage Example

```typescript
import { ScheduleHistoryTab } from './schedule-history-tab'

function ScriptSchedulePage() {
  const schedule = {
    id: 'schedule-123',
    name: 'Daily Backup',
    // ... other schedule properties
  }

  return (
    <div>
      <ScheduleHistoryTab 
        schedule={schedule}
        scheduleId="schedule-123"
      />
    </div>
  )
}
```

The component automatically handles:
- Fetching paginated history data using the `useScriptScheduleHistory` hook
- Displaying execution status with color-coded status tags
- Opening a detailed view when clicking on table rows
- Pagination controls for large datasets
- Error states and loading indicators
- Responsive design with mobile-friendly column hiding
