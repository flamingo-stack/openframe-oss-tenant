A React component for creating and editing automation scripts in the OpenFrame MSP platform. This page provides a comprehensive form interface for configuring script details, platform support, arguments, environment variables, and the script body itself.

## Key Components

- **ScriptData Interface**: Defines the complete script configuration structure including metadata, execution settings, and content
- **EditScriptPage**: Main component handling both creation and editing modes with form state management
- **Platform Selection**: Multi-select interface for choosing supported operating systems (Windows, macOS, Linux)
- **Script Arguments & Environment Variables**: Dynamic lists for configuring script parameters
- **Code Editor**: Textarea with line numbers for writing the actual script content
- **Form Validation**: Ensures required fields are completed before saving

## Usage Example

```typescript
// Create new script
<EditScriptPage scriptId={null} />

// Edit existing script
<EditScriptPage scriptId="script-123" />

// Script data structure
const scriptData: ScriptData = {
  name: "System Health Check",
  shell: "powershell",
  default_timeout: 90,
  args: [{ name: "verbose", value: "true" }],
  script_body: "Get-ComputerInfo | Select-Object WindowsVersion",
  run_as_user: false,
  env_vars: [{ name: "LOG_LEVEL", value: "INFO" }],
  description: "Checks system health and reports status",
  supported_platforms: ["windows"],
  category: "System Maintenance"
}
```

The component integrates with the Tactical RMM API for script management and provides real-time validation, error handling, and success notifications through the toast system.
