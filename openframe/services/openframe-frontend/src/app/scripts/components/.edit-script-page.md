React component for creating and editing automation scripts with support for multiple platforms and shell types.

## Key Components

- **EditScriptPage** - Main component that renders the script editor form
- **ScriptData interface** - Defines the structure for script configuration data
- **Platform selection** - Multi-platform support with OS-specific options
- **Script editor** - Code textarea with syntax highlighting and line numbers
- **Dynamic fields** - Add/remove script arguments and environment variables
- **API integration** - Creates/updates scripts via Tactical RMM API

## Usage Example

```typescript
import { EditScriptPage } from './edit-script-page'

// Create new script
<EditScriptPage scriptId={null} />

// Edit existing script
<EditScriptPage scriptId="123" />

// Example script data structure
const scriptData = {
  name: "System Health Check",
  shell: "powershell",
  default_timeout: 90,
  args: [{ name: "verbose", value: "" }],
  script_body: "Get-SystemInfo",
  run_as_user: false,
  env_vars: [{ name: "DEBUG", value: "true" }],
  description: "Checks system health",
  supported_platforms: ["windows", "linux"],
  category: "Monitoring"
}
```

The component features a responsive form layout with platform selection buttons, shell type dropdown, script body editor with line numbers, and dynamic argument/environment variable management. It handles both creation and editing modes based on whether a `scriptId` is provided.
