A React component for creating and editing automation scripts in the OpenFrame platform with support for multiple operating systems, shell types, and script configurations.

## Key Components

- **EditScriptPage**: Main component handling script creation and editing functionality
- **ScriptData Interface**: Type definition for script configuration including shell type, timeout, arguments, environment variables, and platform support
- **Platform Selection**: Multi-select interface for choosing supported operating systems (Windows, macOS, Linux)
- **Script Editor**: Code editor with line numbers and syntax highlighting for script content
- **Dynamic Form Fields**: Configurable arguments and environment variables with add/remove functionality
- **API Integration**: Handles script creation and updates via tacticalApiClient

## Usage Example

```typescript
// Create new script
<EditScriptPage scriptId={null} />

// Edit existing script
<EditScriptPage scriptId="script-123" />

// Script data structure
const scriptData: ScriptData = {
  name: "System Cleanup",
  shell: "powershell",
  default_timeout: 90,
  args: [{ name: "path", value: "" }],
  script_body: "Get-ChildItem -Path $args[0] | Remove-Item",
  run_as_user: false,
  env_vars: [{ name: "LOG_LEVEL", value: "INFO" }],
  description: "Cleans up temporary files",
  supported_platforms: ["windows"],
  category: "System Maintenance"
}
```

The component provides a comprehensive interface for script management with form validation, platform compatibility settings, and real-time editing capabilities. It integrates with the OpenFrame design system and provides toast notifications for user feedback.
