A React component for creating and editing automation scripts in the Flamingo platform, providing a comprehensive form interface for script configuration including platform support, arguments, environment variables, and shell types.

## Key Components

- **EditScriptPage**: Main component handling script creation/editing with form state management
- **ScriptData Interface**: Type definition for script configuration including name, shell type, timeout, arguments, environment variables, and platform support
- **Platform Selection**: Multi-select interface for choosing supported operating systems (Windows, macOS, Linux)
- **Dynamic Form Fields**: Expandable sections for script arguments and environment variables
- **Code Editor**: Textarea with line numbers for script body editing
- **Shell Type Selection**: Dropdown for choosing execution shell (PowerShell, Bash, CMD, etc.)

## Usage Example

```typescript
// Creating a new script
<EditScriptPage scriptId={null} />

// Editing existing script
<EditScriptPage scriptId="script-123" />

// Component handles both modes automatically
const isEditMode = !!scriptId
```

The component integrates with Tactical RMM API for script persistence and includes validation, error handling, toast notifications, and responsive form layout. It supports cross-platform script deployment with OS-specific configuration options and provides a professional code editing experience with syntax highlighting capabilities.
