A React page component for creating and editing Tactical RMM automation scripts within the OpenFrame platform. Handles both create and edit modes with comprehensive script configuration options.

## Key Components

- **EditScriptPage** - Main component handling script creation/editing with form state management
- **ScriptData** - Interface defining the script configuration structure
- **Platform Selection** - Multi-select OS platform targeting (Windows, macOS, Linux)
- **Script Editor** - Code textarea with synchronized line numbers for script body editing
- **Dynamic Fields** - Add/remove functionality for script arguments and environment variables

## Usage Example

```typescript
import { EditScriptPage } from './edit-script-page'

// Create new script
function NewScriptPage() {
  return <EditScriptPage scriptId={null} />
}

// Edit existing script
function EditExistingScript() {
  const scriptId = "script-123"
  return <EditScriptPage scriptId={scriptId} />
}

// Script data structure
const scriptData: ScriptData = {
  name: "System Cleanup",
  shell: "powershell",
  default_timeout: 90,
  args: [{ name: "verbose", value: "" }],
  script_body: "Get-ChildItem -Path C:\\temp | Remove-Item",
  run_as_user: false,
  env_vars: [{ name: "DEBUG", value: "true" }],
  description: "Cleans temporary files",
  supported_platforms: ["windows"],
  category: "System Maintenance"
}
```

The component integrates with Tactical RMM API for script CRUD operations and provides a comprehensive form interface with platform selection, shell type configuration, argument/environment variable management, and a code editor with line numbers for script development.
