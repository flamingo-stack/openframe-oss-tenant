A React component for creating and editing automation scripts in the Flamingo/OpenFrame platform, providing a comprehensive form interface for script configuration including platform selection, shell type, arguments, environment variables, and script body editing.

## Key Components

- **EditScriptPage**: Main form component handling script creation and editing
- **ScriptData interface**: Type definition for script configuration data
- **Platform Selection**: Multi-select interface for Windows/Linux/macOS compatibility
- **Script Editor**: Code editor with line numbers for script body
- **Dynamic Forms**: Add/remove script arguments and environment variables
- **API Integration**: Tactical RMM API client for CRUD operations

## Usage Example

```typescript
import { EditScriptPage } from './edit-script-page'

// Create new script
<EditScriptPage scriptId={null} />

// Edit existing script
<EditScriptPage scriptId="script-123" />
```

The component automatically detects edit vs create mode based on the `scriptId` prop. It provides form validation, loading states, error handling, and toast notifications for user feedback. The script editor includes syntax highlighting and supports multiple shell types (PowerShell, Bash, etc.) with platform-specific configurations.
