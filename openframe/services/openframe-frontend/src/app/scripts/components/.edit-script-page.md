A React component that provides a comprehensive interface for creating and editing PowerShell scripts with integrated testing capabilities and form validation.

## Key Components

- **EditScriptPage** - Main component handling both create and edit modes for scripts
- **Form Management** - Integrates with `useEditScriptForm` hook for form state and validation
- **Test Integration** - Supports live script testing with device selection via `TestScriptModal`
- **Error Handling** - Displays loading states and error messages with fallback UI
- **Navigation** - Dynamic back button behavior based on edit vs. create mode

## Usage Example

```typescript
// Create new script
<EditScriptPage scriptId={null} />

// Edit existing script
<EditScriptPage scriptId="script-123" />

// Component handles all state management internally:
// - Form validation and submission
// - Test run execution and monitoring
// - Loading and error states
// - Navigation between script views
```

The component uses `FormPageContainer` for consistent layout, displays active test runs with real-time output via `TestRunCard`, and provides a modal interface for selecting test devices. Form validation ensures the script name is required before saving, and the component automatically adapts its UI based on whether it's in create or edit mode.
