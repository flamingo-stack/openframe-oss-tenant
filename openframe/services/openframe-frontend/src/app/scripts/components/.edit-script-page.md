A React form page component for creating and editing PowerShell/automation scripts with multi-platform support, argument configuration, and environment variable management.

## Key Components

- **EditScriptPage**: Main component with form state management for script creation/editing
- **ScriptData interface**: TypeScript interface defining script properties (name, shell, timeout, args, env vars, etc.)
- **Platform Selection**: Multi-platform support using PushButtonSelector with OS type icons
- **Dynamic Forms**: Add/remove script arguments and environment variables
- **Script Editor**: Code textarea with line numbers and syntax highlighting
- **Form Validation**: Input validation and error handling with toast notifications

## Usage Example

```typescript
import { EditScriptPage } from './edit-script-page'

// Create new script
function NewScriptPage() {
  return <EditScriptPage scriptId={null} />
}

// Edit existing script
function EditExistingScript() {
  const scriptId = "12345"
  return <EditScriptPage scriptId={scriptId} />
}

// Script data structure
const scriptData: ScriptData = {
  name: "System Cleanup",
  shell: "powershell", 
  default_timeout: 90,
  args: [{ name: "path", value: "" }],
  script_body: "Get-ChildItem -Path $path",
  run_as_user: false,
  env_vars: [{ name: "LOG_LEVEL", value: "INFO" }],
  description: "Cleans system temporary files",
  supported_platforms: ["windows", "linux"],
  category: "System Maintenance"
}
```

The component integrates with the Tactical RMM API client for CRUD operations and provides a comprehensive interface for managing automation scripts across different operating systems and shell environments.
