A React component page for creating and editing automation scripts in the Flamingo OpenFrame platform, providing a comprehensive form interface for script management.

## Key Components

- **EditScriptPage**: Main component handling script creation/editing with form validation and API integration
- **ScriptData Interface**: TypeScript interface defining script structure with metadata, execution settings, and platform support
- **Platform Selection**: OS-specific targeting using PushButtonSelector for Windows, macOS, and Linux
- **Script Editor**: Code textarea with synchronized line numbers and scroll handling
- **Dynamic Fields**: Add/remove functionality for script arguments and environment variables
- **API Integration**: CRUD operations through tacticalApiClient for script persistence

## Usage Example

```typescript
// Create new script
<EditScriptPage scriptId={null} />

// Edit existing script
<EditScriptPage scriptId="script-123" />

// Script data structure
const scriptData: ScriptData = {
  name: "System Cleanup",
  shell: "powershell",
  default_timeout: 90,
  args: [{ name: "path", value: "/tmp" }],
  script_body: "Get-ChildItem $path | Remove-Item",
  run_as_user: false,
  env_vars: [{ name: "LOG_LEVEL", value: "INFO" }],
  description: "Cleans temporary files",
  supported_platforms: ["windows"],
  category: "System Maintenance"
}
```

The component provides a full-featured script editor with platform-specific execution settings, argument management, and integrated testing capabilities for MSP automation workflows.
