A React component for creating and editing automation scripts within the Flamingo OpenFrame platform, supporting multiple shell types, platforms, and script configurations.

## Key Components

- **EditScriptPage** - Main component handling script creation/editing with form validation
- **ScriptData interface** - TypeScript interface defining script structure with arguments, environment variables, and platform support
- **Platform selection** - Multi-select interface for Windows/Linux/macOS compatibility using OS_TYPES
- **Dynamic form fields** - Add/remove script arguments and environment variables
- **Code editor** - Textarea with line numbers for script body editing
- **Shell type selection** - Dropdown for PowerShell, Bash, Python, etc.

## Usage Example

```typescript
import { EditScriptPage } from './edit-script-page'

// Create new script
<EditScriptPage scriptId={null} />

// Edit existing script
<EditScriptPage scriptId="123" />

// Component handles both create and edit modes
// Form data includes:
const scriptData = {
  name: "System Health Check",
  shell: "powershell",
  default_timeout: 90,
  args: [{ name: "verbose", value: "" }],
  script_body: "Get-SystemInfo",
  run_as_user: false,
  env_vars: [{ name: "LOG_LEVEL", value: "INFO" }],
  description: "Checks system health metrics",
  supported_platforms: ["windows", "linux"],
  category: "System Maintenance"
}
```

The component integrates with the Tactical RMM API for script management and provides real-time form validation with toast notifications for user feedback.
