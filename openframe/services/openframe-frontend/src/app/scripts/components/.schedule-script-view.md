A React component for scheduling script execution on selected devices with date/time scheduling and configuration options.

## Key Components

- **ScheduleScriptView** - Main component that renders the script scheduling interface
- **scheduleFormSchema** - Zod validation schema for form data including timeout, arguments, environment variables, and scheduling details
- **parseKeyValues/serializeKeyValues** - Utility functions for handling script arguments and environment variables
- **Device Selection Logic** - Multi-select device interface with search and organization filtering
- **Form Management** - React Hook Form integration with validation and error handling

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

// Render script scheduling interface
function ScriptSchedulePage({ params }: { params: { scriptId: string } }) {
  return <ScheduleScriptView scriptId={params.scriptId} />
}

// The component handles:
// - Loading script details and available devices
// - Form validation for scheduling parameters
// - Device selection with search/filter capabilities
// - Submission to Tactical RMM API for task creation
```

The component provides a comprehensive interface for scheduling script execution across multiple devices, with support for custom arguments, environment variables, timeout configuration, and flexible scheduling options. It includes robust error handling, device filtering by organization, and real-time validation feedback.
