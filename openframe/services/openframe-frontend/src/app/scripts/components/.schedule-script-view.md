A React component view for scheduling script execution on selected devices with support for arguments, environment variables, and scheduling options.

## Key Components

- **ScheduleScriptView**: Main component handling script scheduling workflow
- **scheduleFormSchema**: Zod validation schema for schedule form data
- **parseKeyValues/serializeKeyValues**: Utilities for handling script arguments and environment variables
- **Form Controls**: Timeout, script arguments, environment variables, scheduling date, and device selection
- **Device Filtering**: Search and organization-based filtering for device selection
- **API Integration**: Creates scheduled tasks via Tactical RMM API

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

// Basic usage in a page component
function ScheduleScriptPage({ params }: { params: { scriptId: string } }) {
  return (
    <ScheduleScriptView scriptId={params.scriptId} />
  )
}

// The component handles:
// - Loading script details and available devices
// - Form validation and submission
// - Device selection with search/filtering
// - Creating scheduled tasks for selected agents
export default ScheduleScriptPage
```

The component provides a comprehensive interface for scheduling script execution, including device selection with search/filter capabilities, configurable timeout and arguments, and integration with the Tactical RMM API for task creation. It supports both one-time and recurring schedules with proper error handling and user feedback.
