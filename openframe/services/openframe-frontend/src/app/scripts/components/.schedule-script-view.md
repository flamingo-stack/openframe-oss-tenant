A React component for scheduling script execution across multiple devices with form validation and organization filtering.

## Key Components

- **ScheduleScriptView**: Main component that renders the script scheduling interface
- **scheduleFormSchema**: Zod validation schema for timeout, arguments, environment variables, and scheduling options
- **parseKeyValues/serializeKeyValues**: Utility functions for handling key-value pairs in script arguments
- **Device filtering**: Client-side search and organization-based filtering of target devices
- **Form handling**: React Hook Form integration with validation and submission logic

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

// In a Next.js page or component
function ScheduleScriptPage({ params }: { params: { scriptId: string } }) {
  return <ScheduleScriptView scriptId={params.scriptId} />
}

// The component handles:
// - Loading script details and available devices
// - Form validation for scheduling parameters
// - Device selection with search and organization filtering
// - Creating scheduled tasks via Tactical RMM API
// - Error handling and user feedback via toast notifications
```

The component provides a comprehensive interface for IT administrators to schedule script execution, including timeout configuration, argument management, device selection with filtering capabilities, and scheduling options with optional repeat functionality. It integrates with the Tactical RMM backend to create scheduled tasks across selected devices.
