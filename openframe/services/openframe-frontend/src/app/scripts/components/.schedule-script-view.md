This React component provides a comprehensive interface for scheduling script execution across multiple devices in the Flamingo Stack MSP platform.

## Key Components

- **ScheduleScriptView**: Main component that renders the script scheduling interface
- **Form Schema**: Zod validation schema (`scheduleFormSchema`) for timeout, arguments, environment variables, scheduling date, and repeat settings
- **Device Management**: Client-side device filtering by search term and organization selection
- **Script Execution**: Integration with Tactical RMM API for creating scheduled tasks across selected agents

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

// Use in a Next.js page or route
export default function SchedulePage({ params }: { params: { scriptId: string } }) {
  return <ScheduleScriptView scriptId={params.scriptId} />
}
```

The component handles the complete scheduling workflow:
1. **Script Loading**: Fetches script details and available devices using `useRunScriptData`
2. **Device Selection**: Provides searchable device list with organization filtering
3. **Form Validation**: Uses React Hook Form with Zod schema for timeout, arguments, and scheduling parameters
4. **Task Creation**: Submits scheduled tasks to Tactical RMM API for each selected device
5. **Error Handling**: Comprehensive error states and toast notifications for user feedback

Key features include device compatibility checking (Windows/Linux/macOS), batch scheduling across multiple agents, and support for both one-time and recurring script execution.
