A React component for scheduling script execution across multiple devices with form validation and device filtering capabilities.

## Key Components

- **ScheduleScriptView**: Main component that handles script scheduling workflow
- **Form Schema**: Zod validation schema for timeout, arguments, environment variables, scheduling date, and repeat settings
- **Device Management**: Device selection with search, organization filtering, and bulk selection operations
- **Form Utilities**: Helper functions for parsing and serializing key-value pairs for script arguments
- **API Integration**: Integration with Tactical RMM for creating scheduled tasks

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

// Render the schedule script interface
function SchedulePage({ params }: { params: { scriptId: string } }) {
  return <ScheduleScriptView scriptId={params.scriptId} />
}

// The component handles:
// - Loading script details and available devices
// - Form validation with timeout limits (1-86400 seconds)
// - Device filtering by search term and organization
// - Batch scheduling across multiple agents
// - Error handling and user feedback via toasts
```

The component provides a comprehensive interface for scheduling scripts with device selection, argument configuration, timeout settings, and scheduling options. It includes client-side device filtering, form validation, and handles both one-time and recurring task scheduling through the Tactical RMM API.
