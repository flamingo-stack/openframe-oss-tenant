A React component that provides a comprehensive interface for scheduling script execution on remote devices with advanced filtering and configuration options.

## Key Components

- **`ScheduleScriptView`** - Main component for scheduling script execution
- **`scheduleFormSchema`** - Zod validation schema for form data
- **`parseKeyValues`/`serializeKeyValues`** - Utility functions for handling script arguments and environment variables
- **Device Management** - Client-side search and filtering with organization-based grouping
- **Form Validation** - React Hook Form integration with comprehensive error handling

## Usage Example

```typescript
// Basic usage in a Next.js page
export default function ScheduleScriptPage({ params }: { params: { id: string } }) {
  return <ScheduleScriptView scriptId={params.id} />
}

// The component handles:
// - Loading script details and device data
// - Form validation for scheduling parameters
// - Device selection with multi-organizational filtering
// - Tactical RMM API integration for task creation
```

The component integrates with the Tactical RMM backend to create scheduled tasks across selected devices, supporting both one-time and recurring schedules. It includes comprehensive error handling, toast notifications, and responsive design patterns. The form supports configurable timeouts, script arguments, environment variables, and device filtering by organization and search terms.
