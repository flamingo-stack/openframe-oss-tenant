A React component for scheduling script execution on selected devices with form validation and device filtering capabilities.

## Key Components

- **ScheduleScriptView**: Main component that renders the scheduling interface
- **scheduleFormSchema**: Zod validation schema for form data including timeout, script arguments, environment variables, and scheduling options
- **parseKeyValues/serializeKeyValues**: Utility functions for handling key-value pairs in script arguments and environment variables
- **Device Selection Logic**: Handles device filtering by search term and organization, with multi-select functionality
- **Form Handling**: Uses React Hook Form with Zod resolver for validation and submission

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

// Render the scheduling interface for a specific script
function SchedulePage() {
  return (
    <ScheduleScriptView scriptId="script-123" />
  )
}
```

The component integrates with the Tactical RMM API to create scheduled tasks, supports device filtering by organization and search terms, validates form inputs including timeout limits and required fields, and provides toast notifications for success/error feedback. It automatically populates default values from script metadata and handles cross-platform device compatibility checking.
