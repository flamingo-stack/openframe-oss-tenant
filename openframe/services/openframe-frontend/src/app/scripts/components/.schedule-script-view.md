A React component for scheduling script execution on selected devices with form validation and organization filtering.

## Key Components

- **ScheduleScriptView** - Main component for scheduling scripts on devices with date/time selection
- **scheduleFormSchema** - Zod validation schema for form data including timeout, arguments, environment variables, and scheduling options
- **parseKeyValues/serializeKeyValues** - Utility functions for converting between string arrays and key-value pairs
- **Device selection logic** - Client-side filtering and multi-selection of target devices
- **Organization filtering** - Filter devices by organization membership
- **Form submission** - Creates scheduled tasks via Tactical RMM API for selected agents

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

// Render the schedule script interface
function SchedulePage({ params }: { params: { scriptId: string } }) {
  return <ScheduleScriptView scriptId={params.scriptId} />
}

// The component handles:
// - Loading script details and available devices
// - Form validation with Zod schema
// - Device search and organization filtering
// - Multi-device selection with batch operations
// - Scheduled task creation with error handling
```

The component provides a comprehensive interface for scheduling script execution across multiple devices, with features like device filtering, form validation, batch operations, and detailed error handling. It integrates with Tactical RMM for actual task scheduling and includes responsive design for mobile and desktop usage.
