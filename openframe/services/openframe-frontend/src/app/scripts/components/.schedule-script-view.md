A React component that provides a comprehensive interface for scheduling script execution across multiple devices with form validation, device selection, and organization filtering.

## Key Components

- **ScheduleScriptView** - Main component handling script scheduling workflow
- **scheduleFormSchema** - Zod validation schema for form data including timeout, arguments, environment variables, and scheduling options
- **parseKeyValues/serializeKeyValues** - Utility functions for converting between string arrays and key-value pairs
- **Device selection logic** - Multi-device selection with search and organization filtering
- **Form submission** - Creates scheduled tasks via Tactical RMM API for selected devices

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

// Use in a Next.js page or component
export default function SchedulePage({ params }: { params: { scriptId: string } }) {
  return <ScheduleScriptView scriptId={params.scriptId} />
}

// The component handles:
// - Loading script details and available devices
// - Form validation with timeout (1-86400 seconds)
// - Device search and organization filtering
// - Multi-device selection with bulk operations
// - Scheduling execution with script arguments and environment variables
// - Creating scheduled tasks via Tactical RMM API
```

The component integrates with the OpenFrame frontend core for UI components, device management, and API communication. It supports both one-time and recurring task scheduling with comprehensive error handling and user feedback through toast notifications.
