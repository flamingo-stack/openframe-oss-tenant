A React component that provides an interface for scheduling script execution across selected devices with comprehensive form validation and device filtering capabilities.

## Key Components

### Main Component
- **`ScheduleScriptView`** - Main component that renders the complete scheduling interface with form controls, device selection, and submission handling

### Helper Functions  
- **`parseKeyValues`** - Converts string array to ScriptArgument objects for form initialization
- **`serializeKeyValues`** - Converts ScriptArgument pairs back to string array format for API submission

### Form Schema
- **`scheduleFormSchema`** - Zod validation schema for schedule form data including timeout, arguments, environment variables, and scheduling options
- **`scriptArgumentSchema`** - Schema for individual script argument validation

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

// Render the scheduling interface for a specific script
function ScriptSchedulePage() {
  const scriptId = "script-123"
  
  return (
    <ScheduleScriptView scriptId={scriptId} />
  )
}

// The component handles:
// - Loading script details and devices
// - Form validation with Zod schemas  
// - Device selection and filtering
// - Organization-based filtering
// - Scheduled task creation via Tactical RMM API
```

The component integrates with Tactical RMM for task scheduling, supports device filtering by organization and search terms, and provides comprehensive error handling and user feedback through toast notifications. It automatically handles platform detection and creates appropriate scheduled tasks based on device operating systems.
