A React component for scheduling script execution across multiple devices with form validation and device selection capabilities.

## Key Components

- **ScheduleScriptView** - Main component that handles script scheduling workflow
- **scheduleFormSchema** - Zod validation schema for form data including timeout, arguments, and scheduling options
- **parseKeyValues/serializeKeyValues** - Utility functions for converting key-value pairs between display and API formats
- **Device Selection Logic** - Multi-select functionality with search and organization filtering
- **Form Management** - React Hook Form integration with validation and submission handling

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

// Basic usage - schedule a script by ID
export default function SchedulePage({ params }: { params: { id: string } }) {
  return <ScheduleScriptView scriptId={params.id} />
}

// The component handles the complete scheduling workflow:
// 1. Loads script details and available devices
// 2. Provides form for timeout, arguments, and schedule date
// 3. Allows multi-device selection with search/filtering
// 4. Validates form data and creates scheduled tasks
// 5. Shows success/error feedback and navigates back
```

The component integrates with the Tactical RMM API to create scheduled tasks, supports both one-time and recurring schedules, and provides comprehensive error handling with user feedback through toast notifications. It automatically determines compatible platforms based on selected devices and handles partial success scenarios when scheduling across multiple agents.
