A React component that provides a comprehensive interface for scheduling script execution on selected devices with customizable parameters and timing.

## Key Components

- **ScheduleScriptView**: Main component handling script scheduling workflow
- **scheduleFormSchema**: Zod validation schema for form data including timeout, arguments, environment variables, and scheduling options
- **parseKeyValues/serializeKeyValues**: Utility functions for converting between key-value pairs and string arrays
- **Device filtering and selection**: Client-side search and organization-based filtering with multi-select capabilities
- **Form controllers**: React Hook Form integration for managing script arguments, environment variables, and scheduling parameters

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

function ScriptSchedulePage({ params }: { params: { scriptId: string } }) {
  return (
    <div className="container mx-auto">
      <ScheduleScriptView scriptId={params.scriptId} />
    </div>
  )
}

// The component handles:
// - Loading script details and available devices
// - Form validation with timeout limits (1s - 24h)
// - Device selection with search and organization filtering
// - Creating scheduled tasks via Tactical RMM API
// - Error handling and success notifications
```

The component integrates with the Tactical RMM API to create scheduled tasks, supports both one-time and recurring schedules, and provides real-time feedback on task creation success/failure across multiple selected devices.
