A React component for scheduling script execution across multiple devices with form validation, device selection, and organization filtering.

## Key Components

- **ScheduleScriptView**: Main component handling script scheduling with form validation
- **scheduleFormSchema**: Zod validation schema for schedule form fields
- **parseKeyValues/serializeKeyValues**: Utility functions for script argument conversion
- **Device Management**: Client-side search, selection, and organization filtering
- **tacticalApiClient Integration**: Creates scheduled tasks via Tactical RMM API

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

// Basic usage - schedule a script for execution
function ScriptSchedulePage({ params }: { params: { scriptId: string } }) {
  return (
    <ScheduleScriptView scriptId={params.scriptId} />
  )
}

// The component handles:
// - Loading script details and available devices
// - Form validation for timeout, arguments, and schedule date
// - Device selection with search and organization filtering
// - Creating scheduled tasks across multiple agents
```

The component provides a complete scheduling interface with real-time device filtering, form validation using react-hook-form and Zod, and batch task creation with detailed success/error reporting. It automatically parses script arguments and environment variables from the script definition and allows customization before scheduling.
