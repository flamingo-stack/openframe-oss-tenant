A React component for scheduling script execution on selected devices with form validation and API integration.

## Key Components

- **ScheduleScriptView** - Main component that renders the script scheduling interface
- **scheduleFormSchema** - Zod validation schema for form data including timeout, arguments, environment variables, and scheduling options
- **parseKeyValues/serializeKeyValues** - Utility functions for converting between array and key-value pair formats
- **Device selection logic** - Handles multi-device selection with organization filtering and search
- **Form submission handler** - Creates scheduled tasks via Tactical RMM API for selected agents

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

// Render script scheduling interface
function ScriptSchedulePage({ params }: { params: { scriptId: string } }) {
  return (
    <div>
      <ScheduleScriptView scriptId={params.scriptId} />
    </div>
  )
}

// The component handles:
// - Loading script details and devices
// - Form validation with timeout, arguments, and scheduling options
// - Device selection with search and organization filtering
// - API calls to create scheduled tasks on selected agents
// - Success/error notifications and navigation
```

The component provides a comprehensive interface for scheduling script execution across multiple devices, with support for script arguments, environment variables, timeout configuration, and scheduling options including one-time or recurring execution.
