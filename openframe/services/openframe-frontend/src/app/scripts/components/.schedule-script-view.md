This React component provides a comprehensive interface for scheduling PowerShell scripts to run on selected devices at specified times. It integrates form validation, device selection, and API communication to create scheduled tasks through the Tactical RMM system.

## Key Components

- **ScheduleScriptView**: Main component that handles script scheduling workflow
- **Form validation**: Uses Zod schema with react-hook-form for input validation
- **Device selection**: Multi-select interface with search and organization filtering
- **Script configuration**: Timeout, arguments, environment variables, and scheduling options
- **API integration**: Creates scheduled tasks via `tacticalApiClient`

## Usage Example

```typescript
// Basic usage in a Next.js page
export default function ScheduleScriptPage({ params }: { params: { scriptId: string } }) {
  return <ScheduleScriptView scriptId={params.scriptId} />
}

// The component handles the complete scheduling workflow:
// 1. Loads script details and available devices
// 2. Provides form for timeout, arguments, scheduling date
// 3. Allows device selection with search/filtering
// 4. Submits scheduled tasks to Tactical RMM API
// 5. Shows success/error feedback and navigates back
```

The component features responsive design, comprehensive error handling, and integrates with the OpenFrame design system. It supports both one-time and recurring scheduled tasks, with automatic OS detection and platform compatibility validation.
