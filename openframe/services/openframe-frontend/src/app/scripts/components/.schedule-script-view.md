A React component for scheduling script execution on selected devices with form validation, device filtering, and Tactical RMM integration. This view handles script configuration, device selection, scheduling parameters, and creates scheduled tasks through the Tactical API.

## Key Components

- **ScheduleScriptView**: Main component that renders the script scheduling interface
- **ScheduleFormData**: TypeScript type defining the form structure with validation
- **Device Management**: Client-side device filtering by search term and organization
- **Form Validation**: Zod schema validation for timeout, script arguments, environment variables, and scheduling
- **Script Arguments/Env Vars**: Dynamic key-value pair management with serialization utilities
- **Task Creation**: Integration with Tactical RMM API for creating scheduled tasks

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

function ScriptSchedulePage({ params }: { params: { scriptId: string } }) {
  return <ScheduleScriptView scriptId={params.scriptId} />
}

// The component handles:
// - Loading script details and devices
// - Form validation with timeout limits (1-86400 seconds)
// - Device selection with organization filtering
// - Schedule creation with success/error handling
// - Navigation back to script details

// Form includes:
// - Timeout configuration
// - Script arguments and environment variables
// - Scheduling date/time selection
// - Repeat schedule option
// - Device selection with search and organization filters
```

The component provides a comprehensive interface for scheduling script execution, with robust error handling, form validation, and seamless integration with the Tactical RMM backend for automated task creation across selected devices.
