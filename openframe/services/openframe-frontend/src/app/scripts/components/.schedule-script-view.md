A React component that provides a comprehensive interface for scheduling scripts to run on selected devices at specific times with customizable parameters.

## Key Components

- **ScheduleScriptView** - Main component handling script scheduling workflow
- **Form Management** - Uses React Hook Form with Zod validation for timeout, arguments, environment variables, and scheduling options
- **Device Selection** - Multi-device selection with search and organization filtering capabilities
- **Script Configuration** - Dynamic script arguments and environment variables management
- **Scheduling Options** - Date/time picker with repeat functionality support

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

export default function ScheduleScriptPage({ params }: { params: { scriptId: string } }) {
  return (
    <ScheduleScriptView scriptId={params.scriptId} />
  )
}
```

The component fetches script details and available devices, provides a form for configuring execution parameters (timeout, arguments, environment variables), allows users to select target devices with search/filter capabilities, and schedules the script execution through the Tactical RMM API. It includes comprehensive error handling, loading states, and success/failure notifications for the scheduling process.
