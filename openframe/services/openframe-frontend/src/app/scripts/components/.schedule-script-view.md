A Next.js component for scheduling script execution across multiple devices with form validation and device filtering capabilities.

## Key Components

- **ScheduleScriptView**: Main React component that handles script scheduling workflow
- **scheduleFormSchema**: Zod validation schema for form data including timeout, arguments, and scheduling options
- **parseKeyValues/serializeKeyValues**: Utility functions for handling key-value pair arguments
- **Device Management**: Device selection, filtering by organization and search terms
- **Form Controls**: Date picker, timeout input, script arguments, and environment variables
- **API Integration**: Tactical RMM API client for creating scheduled tasks

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

// Use in a page component
export default function ScheduleScriptPage() {
  return (
    <ScheduleScriptView scriptId="script-123" />
  )
}

// The component handles:
// - Loading script details and compatible devices
// - Form validation with Zod schema
// - Device filtering and selection
// - Scheduling tasks via Tactical RMM API
```

The component integrates with the OpenFrame frontend core library and provides a complete interface for scheduling script execution with device targeting, argument configuration, and scheduling options. It handles form validation, device compatibility checking, and API communication with proper error handling and user feedback through toast notifications.
