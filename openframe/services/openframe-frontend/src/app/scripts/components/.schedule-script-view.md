A React component for scheduling script execution across multiple devices with advanced filtering and form validation capabilities.

## Key Components

**Main Component:**
- `ScheduleScriptView` - Primary component handling script scheduling workflow

**Form Schema:**
- `scheduleFormSchema` - Zod validation schema for schedule form data
- `scriptArgumentSchema` - Schema for script arguments and environment variables

**Key Hooks:**
- `useRunScriptData` - Fetches script details and device data
- `useOrganizationsMin` - Loads organization data for filtering
- `useForm` - React Hook Form integration with Zod resolver

**Utility Functions:**
- `parseKeyValues` - Converts string arrays to key-value pairs
- `serializeKeyValues` - Serializes form data back to API format

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

function ScriptSchedulePage({ params }: { params: { scriptId: string } }) {
  return (
    <div className="container">
      <ScheduleScriptView scriptId={params.scriptId} />
    </div>
  )
}
```

The component provides:
- **Device Selection**: Multi-select with search and organization filtering
- **Schedule Configuration**: Date/time picker with repeat options
- **Script Customization**: Dynamic argument and environment variable inputs
- **Batch Operations**: Schedule scripts across multiple devices simultaneously
- **Error Handling**: Comprehensive validation and user feedback
- **Responsive Design**: Optimized layouts for desktop and mobile devices

Integration with Tactical RMM API handles the actual task scheduling, with support for different operating systems and platform-specific configurations.
