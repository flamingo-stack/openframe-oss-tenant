A React component for scheduling script execution on selected devices with form validation and device filtering capabilities.

## Key Components

**Main Component:**
- `ScheduleScriptView` - Core scheduling interface with form handling and device selection

**Form Schema:**
- `scheduleFormSchema` - Zod validation schema for timeout, arguments, environment variables, schedule date, and repeat settings
- `scriptArgumentSchema` - Validation for key-value script argument pairs

**Utility Functions:**
- `parseKeyValues()` - Converts string array to structured key-value pairs
- `serializeKeyValues()` - Converts key-value pairs back to string array format

**Key Features:**
- Device filtering by search term and organization
- Real-time form validation with react-hook-form
- Multi-device selection with batch operations
- Platform-aware script scheduling via Tactical RMM API

## Usage Example

```typescript
// Basic component usage
<ScheduleScriptView scriptId="script-123" />

// The component handles:
// - Loading script details and available devices
// - Form validation for scheduling parameters
// - Device selection and filtering
// - API calls to create scheduled tasks

// Form data structure:
const scheduleData: ScheduleFormData = {
  timeout: 90,
  scriptArgs: [{ id: 'arg-1', key: 'param1', value: 'value1' }],
  envVars: [{ id: 'env-1', key: 'NODE_ENV', value: 'production' }],
  note: 'Daily maintenance script',
  scheduledDate: new Date('2024-12-01T09:00:00Z'),
  repeatEnabled: true
}
```

The component integrates with the Tactical RMM API to create scheduled tasks across multiple agents, with proper error handling and user feedback through toast notifications.
