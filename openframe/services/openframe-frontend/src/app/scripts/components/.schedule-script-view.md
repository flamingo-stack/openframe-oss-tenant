A React component for scheduling script execution on selected devices with configurable parameters and timing options.

## Key Components

- **ScheduleScriptView** - Main component that provides a comprehensive interface for scheduling script execution
- **scheduleFormSchema** - Zod validation schema for form data including timeout, arguments, environment variables, and scheduling options
- **parseKeyValues/serializeKeyValues** - Utility functions for handling key-value pairs in script arguments and environment variables
- **Device selection logic** - Multi-device selection with search and organization filtering capabilities
- **Form submission handler** - Processes the schedule creation with error handling and toast notifications

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

function SchedulePage({ params }: { params: { id: string } }) {
  return (
    <div>
      <ScheduleScriptView scriptId={params.id} />
    </div>
  )
}

// The component handles:
// - Loading script details and available devices
// - Form validation with Zod schema
// - Device filtering by search term and organization
// - Creating scheduled tasks via Tactical RMM API
// - Navigation and error handling

export default SchedulePage
```

The component integrates with the Tactical RMM API to create scheduled tasks, supports device filtering by organization and search terms, and provides comprehensive form validation for scheduling parameters including timeout settings, script arguments, environment variables, and execution timing options.
