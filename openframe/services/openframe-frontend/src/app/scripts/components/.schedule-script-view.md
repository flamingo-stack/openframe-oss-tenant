A React component view for scheduling script execution on selected devices with form validation and batch operations.

## Key Components

- **`ScheduleScriptView`** - Main component for scheduling script execution with device selection
- **Form Management** - Uses `react-hook-form` with Zod validation for script parameters
- **Device Selection** - Multi-device selection with search and organization filtering
- **Script Configuration** - Timeout, arguments, environment variables, and scheduling options
- **API Integration** - Tactical RMM API client for creating scheduled tasks

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

// Schedule a script for execution
function ScriptSchedulePage({ params }: { params: { scriptId: string } }) {
  return (
    <ScheduleScriptView scriptId={params.scriptId} />
  )
}

// Form schema for validation
const scheduleFormSchema = z.object({
  timeout: z.number().min(1).max(86400),
  scriptArgs: z.array(scriptArgumentSchema),
  envVars: z.array(scriptArgumentSchema),
  scheduledDate: z.date(),
  repeatEnabled: z.boolean(),
})
```

The component provides a comprehensive interface for scheduling scripts with device filtering, argument configuration, and batch execution across multiple agents with proper error handling and user feedback.
