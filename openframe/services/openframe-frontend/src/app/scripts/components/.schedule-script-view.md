A React component that provides a comprehensive interface for scheduling script execution across selected devices in the OpenFrame MSP platform.

## Key Components

- **ScheduleScriptView** - Main component that handles script scheduling with device selection, form validation, and scheduling options
- **scheduleFormSchema** - Zod validation schema for timeout, arguments, environment variables, scheduling date, and repeat settings
- **parseKeyValues/serializeKeyValues** - Utility functions for converting between string arrays and key-value pairs
- **Device filtering** - Client-side search and organization-based filtering with selectable device cards
- **Form handling** - React Hook Form integration with comprehensive error handling and toast notifications

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

// Render the scheduling interface for a specific script
function SchedulePage() {
  return (
    <ScheduleScriptView scriptId="script-123" />
  )
}

// The component handles:
// - Loading script details and compatible devices
// - Device selection with search/filter capabilities
// - Form validation for scheduling parameters
// - Creating scheduled tasks via Tactical RMM API
// - Error handling and success notifications
```

The component integrates with Tactical RMM for task scheduling, supports both one-time and recurring schedules, and provides a responsive interface for device selection with organization-based filtering. It includes comprehensive validation, loading states, and error handling throughout the scheduling workflow.
