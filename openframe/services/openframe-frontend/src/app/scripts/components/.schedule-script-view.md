A React component for scheduling scripts to run on selected devices at specific times, providing form controls for script configuration and device selection.

## Key Components

- **ScheduleScriptView**: Main component handling script scheduling workflow
- **scheduleFormSchema**: Zod validation schema for form data including timeout, arguments, environment variables, and schedule settings
- **parseKeyValues/serializeKeyValues**: Utility functions for converting between key-value pairs and string arrays
- **Device filtering**: Client-side search and organization-based filtering of available devices
- **Form handling**: React Hook Form integration with comprehensive validation

## Usage Example

```typescript
// Use in a Next.js page or component
import { ScheduleScriptView } from './schedule-script-view'

export default function ScheduleScriptPage({ 
  params 
}: { 
  params: { scriptId: string } 
}) {
  return <ScheduleScriptView scriptId={params.scriptId} />
}

// The component provides:
// - Script information display
// - Timeout configuration
// - Script arguments and environment variables management
// - Device selection with search and filtering
// - Date/time scheduling with optional repeat functionality
// - Bulk device operations (select all, clear selection)
```

The component integrates with Tactical RMM API to create scheduled tasks across selected devices, handles form validation, provides user feedback through toast notifications, and supports both one-time and recurring schedule types with comprehensive error handling for partial failures.
