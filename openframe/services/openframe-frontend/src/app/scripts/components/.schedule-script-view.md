A React component for scheduling script execution across multiple devices with form validation, device selection, and organization filtering.

## Key Components

- **ScheduleScriptView** - Main component that renders the script scheduling interface
- **Form validation** - Uses Zod schema with react-hook-form for timeout, arguments, environment variables, and scheduling options
- **Device management** - Handles device selection, search filtering, and organization-based filtering
- **Script execution** - Integrates with Tactical RMM API to create scheduled tasks across selected devices

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

function SchedulePage() {
  return <ScheduleScriptView scriptId="script-123" />
}

// Form validation schema
const scheduleFormSchema = z.object({
  timeout: z.number().min(1).max(86400),
  scriptArgs: z.array(scriptArgumentSchema),
  envVars: z.array(scriptArgumentSchema),
  scheduledDate: z.date({ message: 'Please select a schedule date' }),
  repeatEnabled: z.boolean(),
})

// Device selection with organization filtering
const devices = useMemo(() => {
  let filtered = allDevices
  if (searchTerm) {
    filtered = filtered.filter(d => 
      d.displayName?.toLowerCase().includes(searchTerm.toLowerCase())
    )
  }
  if (selectedOrgIds.length > 0) {
    filtered = filtered.filter(d => 
      d.organizationId && selectedOrgIds.includes(d.organizationId)
    )
  }
  return filtered
}, [allDevices, searchTerm, selectedOrgIds])
```

The component provides a complete interface for scheduling script execution with device selection, argument configuration, and platform compatibility validation. It handles both one-time and recurring schedules through the Tactical RMM API integration.
