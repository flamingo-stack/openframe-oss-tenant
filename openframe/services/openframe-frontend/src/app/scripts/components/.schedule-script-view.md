This component provides a comprehensive interface for scheduling scripts to run on selected devices at specified times, with support for form validation, device filtering, and multi-agent deployment.

## Key Components

**Main Component:**
- `ScheduleScriptView` - Primary form component for scheduling script execution

**Form Schema & Validation:**
- `scheduleFormSchema` - Zod schema validating timeout, arguments, environment variables, schedule date, and repeat settings
- `ScheduleFormData` - TypeScript type for form data structure

**Utility Functions:**
- `parseKeyValues()` - Converts string arrays to key-value pair objects for script arguments
- `serializeKeyValues()` - Converts key-value pairs back to string format for API submission

**Key Features:**
- Device selection with search and organization filtering
- Script argument and environment variable configuration
- Date/time scheduling with optional repeat functionality
- Real-time form validation and error handling
- Bulk device operations (select all, clear selection)

## Usage Example

```typescript
// Basic usage in a Next.js page
import { ScheduleScriptView } from './schedule-script-view'

export default function ScheduleScriptPage({ 
  params 
}: { 
  params: { scriptId: string } 
}) {
  return <ScheduleScriptView scriptId={params.scriptId} />
}

// Form data structure example
const formData: ScheduleFormData = {
  timeout: 300,
  scriptArgs: [
    { id: 'arg-1', key: 'mode', value: 'production' },
    { id: 'arg-2', key: 'verbose', value: '' } // flag argument
  ],
  envVars: [
    { id: 'env-1', key: 'API_KEY', value: 'secret123' }
  ],
  note: 'Weekly maintenance script',
  scheduledDate: new Date('2024-01-15T10:00:00Z'),
  repeatEnabled: true
}
```

The component integrates with Tactical RMM API for creating scheduled tasks across multiple agents, handles cross-platform script execution (Windows, macOS, Linux), and provides comprehensive error handling with toast notifications.
