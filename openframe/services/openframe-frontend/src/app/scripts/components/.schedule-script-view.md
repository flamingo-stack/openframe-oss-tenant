A React component that provides an interface for scheduling script execution on selected devices with customizable parameters and timing options.

## Key Components

- **ScheduleScriptView** - Main component for scheduling script execution
- **Form Schema** - Zod validation schemas for `scriptArgumentSchema` and `scheduleFormSchema`
- **Form Controls** - Timeout, script arguments, environment variables, scheduling date, and repeat options
- **Device Selection** - Multi-device selection with search and organization filtering
- **Utility Functions** - `parseKeyValues()` and `serializeKeyValues()` for argument parsing

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

// Use in a scheduling page or modal
function ScheduleScriptPage({ params }: { params: { scriptId: string } }) {
  return (
    <div className="h-full">
      <ScheduleScriptView scriptId={params.scriptId} />
    </div>
  )
}

// Form validation schema structure
const scheduleFormSchema = z.object({
  timeout: z.number().min(1).max(86400),
  scriptArgs: z.array(scriptArgumentSchema),
  envVars: z.array(scriptArgumentSchema),
  note: z.string().optional(),
  scheduledDate: z.date(),
  repeatEnabled: z.boolean(),
})
```

The component integrates with React Hook Form for validation, supports device filtering by organization and search terms, and creates scheduled tasks through the Tactical API client. It provides comprehensive error handling and toast notifications for user feedback during the scheduling process.
