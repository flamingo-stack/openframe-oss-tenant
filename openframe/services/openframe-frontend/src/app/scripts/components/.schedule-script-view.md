A React component that provides an interface for scheduling script execution on selected devices with form validation and device filtering.

## Key Components

- **ScheduleScriptView**: Main component handling script scheduling workflow
- **Form Management**: Uses React Hook Form with Zod validation for timeout, arguments, environment variables, schedule date, and repeat settings
- **Device Selection**: Multi-device selection with search and organization filtering
- **Schedule Creation**: Creates scheduled tasks via Tactical API client for selected devices
- **Error Handling**: Comprehensive error states and toast notifications

## Usage Example

```tsx
import { ScheduleScriptView } from './schedule-script-view'

function ScriptSchedulePage() {
  return <ScheduleScriptView scriptId="12345" />
}

// The component provides:
// - Script information display
// - Device search and filtering
// - Form fields for timeout, arguments, environment variables
// - Date picker for scheduling
// - Bulk device selection controls
// - Validation and error handling
```

The component integrates with the Tactical RMM API to create scheduled tasks across multiple devices, supporting different operating systems (Windows, macOS, Linux) and providing real-time feedback on success/failure rates.
