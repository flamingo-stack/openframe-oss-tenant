This React component provides a comprehensive interface for scheduling script execution on selected devices with full form validation and error handling.

## Key Components

- **ScheduleScriptView** - Main component that renders the script scheduling interface
- **Form Management** - Uses React Hook Form with Zod validation for structured form handling
- **Device Selection** - Multi-device selection with search and organization filtering
- **Script Configuration** - Timeout, arguments, and environment variables setup
- **Schedule Options** - Date selection and repeat functionality

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

// Render the schedule interface for a specific script
function SchedulePage({ params }: { params: { scriptId: string } }) {
  return (
    <ScheduleScriptView scriptId={params.scriptId} />
  )
}

// The component handles:
// - Loading script details and available devices
// - Form validation with Zod schema
// - Device filtering by search term and organization
// - Submission to Tactical RMM API for scheduling
export default SchedulePage
```

The component integrates with the Tactical RMM backend to create scheduled tasks, supports both one-time and recurring schedules, and provides comprehensive error handling with toast notifications. It automatically populates form defaults from script metadata and validates all inputs before submission.
