A React component for scheduling script execution on devices with form validation and device selection functionality.

## Key Components

- **ScheduleScriptView**: Main component that renders the scheduling interface with form controls, device selection, and submission handling
- **scheduleFormSchema**: Zod validation schema for form fields including timeout, script arguments, environment variables, and scheduling options
- **parseKeyValues/serializeKeyValues**: Utility functions for converting between key-value string arrays and structured objects
- **Device filtering logic**: Client-side search and organization-based filtering of available devices
- **Form submission handler**: Creates scheduled tasks via Tactical RMM API for selected devices

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

// Render the schedule view for a specific script
function ScriptSchedulePage({ params }: { params: { scriptId: string } }) {
  return (
    <ScheduleScriptView scriptId={params.scriptId} />
  )
}

// The component handles:
// - Loading script details and available devices
// - Form validation with timeout, arguments, and scheduling options
// - Device selection with search and organization filtering
// - Submission to create scheduled tasks on selected agents
```

The component integrates with the Tactical RMM API to create scheduled tasks, supports both one-time and recurring schedules, and provides comprehensive error handling and user feedback through toast notifications.
