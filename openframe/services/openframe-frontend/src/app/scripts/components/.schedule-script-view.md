A React component for scheduling script execution across multiple devices with form validation, device selection, and Tactical RMM integration.

## Key Components

- **ScheduleScriptView** - Main component handling script scheduling with form validation using Zod schema
- **scheduleFormSchema** - Zod validation schema for timeout, arguments, environment variables, and scheduling options
- **parseKeyValues/serializeKeyValues** - Utility functions for converting between string arrays and key-value pairs
- **Device filtering** - Client-side search and organization-based filtering of target devices
- **Form integration** - React Hook Form with controlled inputs for script parameters and scheduling

## Usage Example

```typescript
// Use in a Next.js page or component
export default function ScheduleScriptPage({ params }: { params: { scriptId: string } }) {
  return <ScheduleScriptView scriptId={params.scriptId} />
}

// The component handles:
// - Loading script details and available devices
// - Form validation for scheduling parameters
// - Device selection with search and filtering
// - Tactical RMM API integration for task creation
```

The component provides a comprehensive interface for scheduling scripts with timeout configuration, argument passing, device selection, and scheduling options. It integrates with Tactical RMM for actual task execution and includes proper error handling and user feedback through toast notifications.
