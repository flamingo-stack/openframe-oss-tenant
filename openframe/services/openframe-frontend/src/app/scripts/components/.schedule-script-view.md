Component for scheduling script execution across multiple devices with form validation and device selection capabilities.

## Key Components

- **ScheduleScriptView** - Main component that handles script scheduling workflow
- **Form Schema** - Zod validation schemas for `scriptArgumentSchema` and `scheduleFormSchema`
- **Helper Functions**:
  - `parseKeyValues()` - Converts string arrays to key-value argument objects
  - `serializeKeyValues()` - Converts argument objects back to string format
- **Form Data Type** - `ScheduleFormData` interface derived from Zod schema
- **Device Management** - Selection, filtering, and organization-based grouping
- **API Integration** - Creates scheduled tasks via Tactical RMM API

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

// Basic usage - schedule a script by ID
function ScriptSchedulePage({ params }: { params: { scriptId: string } }) {
  return <ScheduleScriptView scriptId={params.scriptId} />
}

// The component handles:
// - Loading script details and available devices
// - Form validation with timeout, arguments, and scheduling
// - Device selection with search and organization filtering
// - Creating scheduled tasks across multiple agents
```

The component provides a comprehensive interface for scheduling script execution with features like device filtering by organization, search functionality, argument configuration, and batch scheduling across multiple devices with proper error handling and user feedback.
