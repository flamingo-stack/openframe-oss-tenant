A React component for scheduling script execution on selected devices with form validation and organization filtering.

## Key Components

- **ScheduleScriptView** - Main component for scheduling script execution with device selection
- **scheduleFormSchema** - Zod validation schema for form data including timeout, arguments, and scheduling options
- **parseKeyValues/serializeKeyValues** - Utility functions for converting between string arrays and key-value pairs
- **Device selection logic** - Multi-device selection with search and organization filtering
- **Form handling** - React Hook Form integration with validation and submission

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

// Render the schedule view for a specific script
function SchedulePage() {
  return (
    <ScheduleScriptView 
      scriptId="script-123" 
    />
  )
}

// The component handles:
// - Loading script details and available devices
// - Form validation for scheduling parameters
// - Device selection with search and filtering
// - Creating scheduled tasks via Tactical RMM API
export default SchedulePage
```

The component provides a comprehensive interface for scheduling script execution across multiple devices, with features including timeout configuration, script arguments management, environment variables, device filtering by organization, and scheduled/recurring task creation. It integrates with the Tactical RMM API for task scheduling and includes proper error handling and user feedback through toast notifications.
