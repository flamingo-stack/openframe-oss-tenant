This React component provides a comprehensive interface for scheduling script execution across multiple devices with advanced filtering and form validation capabilities.

## Key Components

- **ScheduleScriptView** - Main component that renders the script scheduling interface
- **ScheduleFormData** - TypeScript type derived from Zod schema for form validation
- **Device Management** - Handles device selection, filtering, and organization-based grouping
- **Form Controllers** - React Hook Form integration with Zod validation for timeout, arguments, environment variables, and scheduling options
- **API Integration** - Uses Tactical RMM API client for creating scheduled tasks across selected agents

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

// Use in a Next.js page or component
export default function ScheduleScriptPage({ params }: { params: { scriptId: string } }) {
  return <ScheduleScriptView scriptId={params.scriptId} />
}
```

The component features device filtering by search term and organization, real-time form validation, batch device selection, and comprehensive error handling. It integrates with the Tactical RMM backend to create scheduled tasks and provides user feedback through toast notifications. The form supports script arguments, environment variables, timeout configuration, and both one-time and recurring schedule options.
