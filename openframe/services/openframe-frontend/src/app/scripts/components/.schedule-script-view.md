This React component provides a comprehensive interface for scheduling script execution on selected devices within the Flamingo OpenFrame platform.

## Key Components

- **ScheduleScriptView**: Main component that orchestrates script scheduling workflow
- **Form Management**: Uses React Hook Form with Zod validation for robust form handling
- **Device Selection**: Multi-device selection with search and organization filtering capabilities
- **Script Configuration**: Configurable timeout, arguments, environment variables, and scheduling options
- **API Integration**: Interfaces with Tactical RMM API for creating scheduled tasks

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

function ScriptSchedulePage({ params }: { params: { id: string } }) {
  return <ScheduleScriptView scriptId={params.id} />
}

// The component handles:
// - Loading script details and available devices
// - Form validation with proper error handling
// - Device filtering by search term and organization
// - Bulk scheduling across multiple agents
// - Success/failure feedback with toast notifications
```

The component features a sophisticated device selection system with client-side filtering, organization-based grouping, and bulk operations. It validates form inputs including timeout constraints, handles script arguments and environment variables as key-value pairs, and provides comprehensive error handling with user-friendly feedback. The scheduling system supports both one-time and recurring tasks, with platform-aware execution based on device operating systems.
