A React component that provides a user interface for scheduling script execution across multiple devices with customizable parameters and timing options.

## Key Components

- **ScheduleScriptView**: Main component that renders the complete scheduling interface
- **ScheduleFormData**: TypeScript type defining the form structure with validation
- **parseKeyValues/serializeKeyValues**: Utility functions for handling script arguments and environment variables
- **Device selection logic**: Handles multi-device selection with search and organization filtering
- **Form validation**: Uses Zod schema for robust input validation

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

// Render the schedule interface for a specific script
function ScriptSchedulePage({ params }: { params: { scriptId: string } }) {
  return <ScheduleScriptView scriptId={params.scriptId} />
}

// The component handles:
// - Loading script details and available devices
// - Form validation with timeout, arguments, and schedule date
// - Device selection with search and organization filtering
// - Submitting scheduled tasks to the Tactical RMM API
```

The component integrates with the Tactical RMM API to create scheduled tasks, supports both one-time and recurring executions, and provides comprehensive error handling with toast notifications. It uses React Hook Form for state management and includes responsive design with mobile-optimized layouts.
