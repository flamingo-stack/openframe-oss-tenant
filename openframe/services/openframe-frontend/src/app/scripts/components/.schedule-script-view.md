This React component provides a comprehensive interface for scheduling script execution on selected devices within the OpenFrame platform.

## Key Components

**Main Component:**
- `ScheduleScriptView` - Primary component handling script scheduling workflow

**Form Management:**
- `scheduleFormSchema` (Zod) - Validates timeout, arguments, environment variables, and scheduling parameters
- React Hook Form integration with `zodResolver` for form validation

**Key Features:**
- Device selection with search and organization filtering
- Script argument and environment variable configuration
- Date/time scheduling with optional repeat functionality
- Batch task creation across multiple devices via Tactical RMM API

**Utility Functions:**
- `parseKeyValues` - Converts string arrays to key-value pairs
- `serializeKeyValues` - Converts key-value pairs back to strings
- Device filtering by search term and organization

## Usage Example

```typescript
// Basic usage in a page component
export default function ScheduleScriptPage({ params }: { params: { scriptId: string } }) {
  return (
    <ScheduleScriptView scriptId={params.scriptId} />
  )
}

// The component handles:
// 1. Loading script details and available devices
// 2. Form validation for scheduling parameters
// 3. Device selection with filtering capabilities
// 4. API calls to create scheduled tasks on selected agents
```

The component integrates with the Tactical RMM backend to create scheduled tasks, supports cross-platform script execution, and provides comprehensive error handling with toast notifications for user feedback.
