A React component that provides an interface for scheduling script execution on selected devices with form validation and multi-device management capabilities.

## Key Components

- **ScheduleScriptView** - Main component for scheduling script execution across multiple devices
- **Form Management** - Uses react-hook-form with Zod validation for schedule configuration
- **Device Selection** - Multi-select interface with search and organization filtering
- **Script Configuration** - Timeout, arguments, environment variables, and scheduling options
- **API Integration** - Creates scheduled tasks via Tactical RMM API

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

function ScriptSchedulePage() {
  return (
    <ScheduleScriptView 
      scriptId="script-123" 
    />
  )
}

// Form schema validation
const scheduleFormSchema = z.object({
  timeout: z.number().min(1).max(86400),
  scriptArgs: z.array(scriptArgumentSchema),
  envVars: z.array(scriptArgumentSchema),
  note: z.string().optional(),
  scheduledDate: z.date({ message: 'Please select a schedule date' }),
  repeatEnabled: z.boolean(),
})

// Device selection with multi-platform support
const normalizeOs = (os?: string): string | null => {
  const o = (os || '').toLowerCase()
  if (o.includes('win')) return 'windows'
  if (o.includes('mac')) return 'darwin'
  if (o.includes('linux')) return 'linux'
  return null
}
```

The component handles device filtering by search terms and organizations, validates form inputs, and creates scheduled tasks across multiple selected devices with comprehensive error handling and user feedback.
