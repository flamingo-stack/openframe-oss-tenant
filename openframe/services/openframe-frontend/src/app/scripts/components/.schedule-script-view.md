A React component that provides a comprehensive interface for scheduling script execution on multiple devices with form validation and organization filtering.

## Key Components

- **ScheduleScriptView**: Main component that renders the script scheduling interface
- **Form Management**: Uses React Hook Form with Zod validation for timeout, arguments, environment variables, and scheduling options
- **Device Selection**: Multi-device selection with search and organization filtering capabilities
- **Script Configuration**: Dynamic argument and environment variable input fields
- **API Integration**: Handles tactical API calls for creating scheduled tasks across selected agents

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

// Use in a page component
export default function ScheduleScriptPage({ params }: { params: { scriptId: string } }) {
  return <ScheduleScriptView scriptId={params.scriptId} />
}

// The component handles:
// - Loading script details and available devices
// - Form validation with timeout limits and required fields
// - Device filtering by search term and organization
// - Batch scheduling across multiple tactical agents
```

The component features comprehensive error handling, loading states, and toast notifications for user feedback. It supports both one-time and recurring scheduled tasks with platform-specific execution based on device operating systems.
