Provides a comprehensive interface for scheduling script execution across multiple devices with configurable parameters, timing, and device selection.

## Key Components

- **ScheduleScriptView** - Main React component for scheduling script execution
- **ScheduleFormData** - TypeScript interface defining form structure with validation
- **scheduleFormSchema** - Zod validation schema for form inputs
- **parseKeyValues/serializeKeyValues** - Utility functions for handling key-value pairs
- **Device selection logic** - Multi-select interface with search and organization filtering
- **Form submission handler** - Manages API calls to create scheduled tasks across selected devices

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

// Render the schedule interface for a specific script
function ScriptSchedulePage({ params }: { params: { id: string } }) {
  return (
    <div className="container mx-auto">
      <ScheduleScriptView scriptId={params.id} />
    </div>
  )
}

// Form data structure
const formData: ScheduleFormData = {
  timeout: 90,
  scriptArgs: [{ id: 'arg-1', key: 'debug', value: 'true' }],
  envVars: [{ id: 'env-1', key: 'ENV_VAR', value: 'production' }],
  note: 'Weekly maintenance script',
  scheduledDate: new Date('2024-01-15T10:00:00'),
  repeatEnabled: true
}
```

The component integrates with Tactical RMM for script execution, supports device filtering by organization, and provides real-time validation with toast notifications for success/error states. It handles both one-time and recurring scheduled tasks with comprehensive error handling for partial failures across multiple devices.
