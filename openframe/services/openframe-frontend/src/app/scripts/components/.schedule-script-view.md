This React component provides a comprehensive form interface for scheduling script execution on multiple devices with advanced filtering and validation capabilities.

## Key Components

- **`ScheduleScriptView`** - Main component that renders the script scheduling interface
- **Form Schema** - Zod validation schemas (`scheduleFormSchema`, `scriptArgumentSchema`) for form data validation
- **Device Management** - Device selection with search, organization filtering, and bulk operations
- **Script Configuration** - Dynamic script arguments, environment variables, and execution parameters
- **Scheduling Logic** - Date/time selection with optional repeat functionality

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

// Render the scheduling interface for a specific script
function ScriptSchedulePage({ params }: { params: { id: string } }) {
  return <ScheduleScriptView scriptId={params.id} />
}
```

The component handles the complete workflow from loading script details and devices, through form configuration and validation, to submitting scheduled tasks via the Tactical RMM API. It includes comprehensive error handling, loading states, and user feedback through toasts. The interface supports device filtering by organization and search terms, bulk device selection, and validates all form inputs before submission.

Key features include timeout configuration, dynamic script arguments/environment variables, scheduled date selection with optional daily repeats, and parallel task creation across selected devices with detailed success/failure reporting.
