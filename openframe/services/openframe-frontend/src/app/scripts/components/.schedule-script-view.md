A React component view for scheduling script execution on selected devices with advanced filtering and validation.

## Key Components

**Main Component:**
- `ScheduleScriptView` - Primary component handling script scheduling interface

**Form Schema & Validation:**
- `scheduleFormSchema` - Zod validation schema for schedule form data
- `scriptArgumentSchema` - Validation for script arguments and environment variables

**Helper Functions:**
- `parseKeyValues()` - Converts string arrays to structured key-value pairs
- `serializeKeyValues()` - Converts key-value pairs back to string format

**Key Features:**
- Device selection with search and organization filtering
- Script argument and environment variable management
- Date/time scheduling with optional repeat functionality
- Form validation using React Hook Form and Zod
- Integration with Tactical RMM API for task creation

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

// Use in a page component
export default function ScheduleScriptPage({ params }: { params: { scriptId: string } }) {
  return <ScheduleScriptView scriptId={params.scriptId} />
}

// The component handles:
// - Loading script details and compatible devices
// - Form validation for scheduling parameters
// - Device filtering by search term and organization
// - Creating scheduled tasks via Tactical API
// - Error handling and user feedback via toast notifications
```

The component provides a comprehensive interface for scheduling script execution across multiple devices with proper validation, error handling, and user feedback through the OpenFrame ecosystem.
