This React component provides a comprehensive interface for scheduling PowerShell/Bash scripts to run on multiple devices at specified times within an MSP management platform.

## Key Components

**Main Exports:**
- `ScheduleScriptView` - Primary component for scheduling script execution
- `ScheduleScriptViewProps` - TypeScript interface for component props
- Form validation schemas using Zod (`scheduleFormSchema`, `scriptArgumentSchema`)

**Core Features:**
- Multi-device selection with organization filtering
- Script argument and environment variable management
- Date/time scheduling with optional repeat functionality
- Timeout configuration and execution notes
- Integration with Tactical RMM for agent deployment

**Helper Functions:**
- `parseKeyValues()` - Converts string arrays to key-value pairs for form display
- `serializeKeyValues()` - Transforms form data back to API format

## Usage Example

```typescript
import { ScheduleScriptView } from './schedule-script-view'

// Schedule a script for execution
function ScriptSchedulePage() {
  return (
    <div>
      <ScheduleScriptView scriptId="script-123" />
    </div>
  )
}

// The component handles:
// - Loading script details and compatible devices
// - Form validation for timeout, arguments, and schedule date
// - Device filtering by search term and organization
// - Submitting scheduled tasks to Tactical RMM agents
```

The component uses React Hook Form with Zod validation, supports responsive design, and provides comprehensive error handling for failed scheduling operations across multiple devices.
