A React component that provides a tabbed interface for managing automation scripts and their schedules in the OpenFrame platform.

## Key Components

- **ScriptsView**: Main component that renders a tabbed interface with navigation and content areas
- **SCRIPTS_TABS**: Configuration array defining available tabs:
  - `list`: Scripts management table with BracketCurlyIcon
  - `schedules`: Script schedules table with CalendarIcon
- **Tab Components**:
  - `ScriptsTable`: Component for displaying and managing scripts
  - `ScriptSchedulesTable`: Component for managing script execution schedules

## Usage Example

```typescript
import { ScriptsView } from './scripts-view'

// Render the complete scripts management interface
function ScriptsPage() {
  return (
    <div className="container mx-auto p-4">
      <h1>Automation Scripts</h1>
      <ScriptsView />
    </div>
  )
}
```

The component uses URL-based tab state management, automatically syncing the active tab with the `tab` query parameter. It leverages OpenFrame's core navigation system with `TabNavigation` and `getTabComponent` utilities for consistent tab behavior across the platform. The interface provides a clean separation between script management and scheduling functionality, with a minimum height container to prevent layout shifts during tab transitions.
