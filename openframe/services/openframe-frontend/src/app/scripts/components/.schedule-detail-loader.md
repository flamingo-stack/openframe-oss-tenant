A loading skeleton component that displays placeholder UI while schedule detail data is being fetched, matching the exact layout structure of the actual schedule detail page.

## Key Components

- **`ScheduleDetailLoader`** - Main export that renders the complete schedule detail page skeleton
- **`InfoBarSkeleton`** - 4-column grid skeleton for date, time, repeat, and platform information
- **`TabsSkeleton`** - Navigation skeleton for Scripts, Devices, and History tabs
- **`TableRowSkeleton`** - Individual table row skeleton for tab content

## Usage Example

```typescript
import { ScheduleDetailLoader } from './schedule-detail-loader'

function ScheduleDetailPage({ params }: { params: { id: string } }) {
  const { data: schedule, isLoading } = useSchedule(params.id)
  
  if (isLoading) {
    return <ScheduleDetailLoader />
  }
  
  return <ScheduleDetailView schedule={schedule} />
}
```

The component provides a comprehensive loading state that mirrors the final page structure, including responsive design patterns (2-column grid on mobile, 4-column on desktop) and proper spacing that matches the OpenFrame design system using ODS classes.
