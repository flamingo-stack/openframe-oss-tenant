A responsive form card component for configuring scheduled script actions with platform filtering, timeout settings, and dynamic argument management.

## Key Components

- **ScheduleActionFormCard** - Main form card component that renders script selection, timeout configuration, and argument inputs
- **ScriptPlatformIcons** - Helper component that displays platform compatibility icons for scripts
- **Props Interface** - `ScheduleActionFormCardProps` defining the component's required properties

## Usage Example

```typescript
import { ScheduleActionFormCard } from './schedule-action-form-card'
import { FormProvider, useForm } from 'react-hook-form'

function ScheduleForm() {
  const form = useForm<CreateScheduleFormData>()
  const scripts = [
    { id: 1, name: 'Deploy Script', supported_platforms: ['linux', 'windows'], default_timeout: 300 }
  ]

  return (
    <FormProvider {...form}>
      <ScheduleActionFormCard
        index={0}
        scripts={scripts}
        supportedPlatforms={['linux', 'windows']}
        onRemove={() => console.log('Remove action')}
      />
    </FormProvider>
  )
}
```

The component features responsive layouts (mobile-first design), integrates with React Hook Form for state management, filters scripts based on platform compatibility, and provides dynamic script argument and environment variable configuration. It automatically updates form fields when a script is selected and includes visual platform indicators for better user experience.
