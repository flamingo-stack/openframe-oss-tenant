A React component that displays scheduled task runs for a specific script in a formatted table with date/time, repeat patterns, and device counts.

## Key Components

- **`ScheduledRunsSection`** - Main component that renders the scheduled runs table
- **`formatDate`** - Utility function to format ISO date strings into readable date/time format
- **`getRepeatLabel`** - Utility function to convert task types into human-readable repeat intervals
- **`ScheduledTaskRow`** - Interface defining the table row data structure
- **Custom table columns** - Configured with proper styling and cell renderers for each data field

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

function ScriptDetailPage() {
  return (
    <div>
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId="script-123" />
    </div>
  )
}

// The component will display a table with columns:
// - Note (task name)
// - Date & Time (formatted as MM/DD/YYYY and HH:MM AM/PM)
// - Repeat (Daily, Weekly, Monthly, or None)
// - Devices (currently hardcoded to 1)
```

The component fetches scheduled tasks using the `useScheduledTasks` hook and transforms the data for table display. It handles loading states, errors, and provides an empty state message when no scheduled runs exist. The table uses the OpenFrame UI Table component with custom column renderers for consistent styling.
