A React component that displays scheduled tasks for a script in a formatted table interface, showing scheduling details like date, time, and repeat patterns.

## Key Components

- **ScheduledRunsSection** - Main component that renders the scheduled runs table
- **ScheduledTaskRow** - Interface defining the table row data structure
- **formatDate()** - Utility function to format dates into separate date/time strings
- **getRepeatLabel()** - Function to convert task types into human-readable repeat labels
- **useScheduledTasks** - Custom hook for fetching scheduled task data
- **Table** - OpenFrame UI component for displaying tabular data

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

export function ScriptDetailsPage() {
  const scriptId = "script-123"
  
  return (
    <div className="container">
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId={scriptId} />
    </div>
  )
}
```

The component automatically handles loading states, error states, and empty states. It transforms raw scheduled task data into a user-friendly table format with columns for task name (labeled as "Note"), formatted date/time, repeat interval, and device count. The table supports skeleton loading and displays appropriate messages when no scheduled runs exist for the specified script.
