A React component that displays scheduled task runs for a specific script in a tabular format, transforming raw scheduled task data into a user-friendly table with formatted dates, repeat intervals, and device counts.

## Key Components

- **ScheduledRunsSection** - Main component that renders scheduled tasks table
- **formatDate()** - Utility function that converts ISO date strings to localized date/time format
- **getRepeatLabel()** - Utility function that converts task types to human-readable repeat intervals
- **ScheduledTaskRow** - Interface defining the table row data structure
- **useScheduledTasks** - Custom hook for fetching scheduled tasks data
- **Table** - UI component from OpenFrame core for rendering data tables

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

function ScriptDetailPage({ scriptId }: { scriptId: string }) {
  return (
    <div>
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId={scriptId} />
    </div>
  )
}

// The component transforms scheduled task data like:
// { id: 1, name: "Daily backup", task_type: "daily", daily_interval: 2, run_time_date: "2024-01-15T09:00:00Z" }
// Into table rows displaying: "Daily backup | 01/15/2024 9:00 AM | 2 Days | 1"
```

The component handles loading states, error states, and empty data scenarios while providing a clean tabular view of when scripts are scheduled to run and how frequently they repeat.
