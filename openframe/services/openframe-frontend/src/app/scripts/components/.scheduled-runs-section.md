React component that displays a table of scheduled script runs with formatted date/time and repeat intervals.

## Key Components

- **ScheduledRunsSection** - Main component that renders scheduled tasks in a table format
- **formatDate** - Utility function that converts ISO date strings to localized date and time format
- **getRepeatLabel** - Helper function that converts task types into human-readable repeat labels
- **ScheduledTaskRow** - Interface defining the table row structure with formatted data

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

export function ScriptDetails() {
  return (
    <div>
      <h1>Script Management</h1>
      <ScheduledRunsSection scriptId="script-123" />
    </div>
  )
}
```

The component fetches scheduled tasks using the `useScheduledTasks` hook, transforms the data for display (splitting dates/times, converting repeat types), and renders it in a styled table. It handles loading states, errors, and empty data scenarios. The table displays task name, formatted date/time, repeat interval, and device count with consistent typography and spacing using ODS design tokens.
