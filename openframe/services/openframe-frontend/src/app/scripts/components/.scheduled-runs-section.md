A React component that displays scheduled script runs in a table format, showing task details like timing, repeat patterns, and device counts.

## Key Components

- **ScheduledRunsSection** - Main component that fetches and displays scheduled tasks for a specific script
- **formatDate** - Utility function that formats ISO date strings into separate date and time display values
- **getRepeatLabel** - Helper function that converts task types into human-readable repeat intervals
- **ScheduledTaskRow** - Interface defining the table row data structure
- **Table columns configuration** - Defines how each column renders task data (Note, Date & Time, Repeat, Devices)

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

function ScriptDetailsPage({ scriptId }: { scriptId: string }) {
  return (
    <div>
      <h1>Script Details</h1>
      {/* Display scheduled runs for this script */}
      <ScheduledRunsSection scriptId={scriptId} />
    </div>
  )
}
```

The component uses the `useScheduledTasks` hook to fetch data and automatically handles loading states, errors, and empty states. It transforms the raw task data into a table-friendly format with proper date/time formatting and repeat pattern labels (Daily, Weekly, Monthly, or None for run-once tasks).
