A React component that displays scheduled task runs for a specific script in a table format with formatted dates, times, and repeat intervals.

## Key Components

- **ScheduledRunsSection**: Main component that renders scheduled tasks in a table
- **formatDate**: Utility function that formats ISO date strings into separate date and time display values
- **getRepeatLabel**: Helper that converts task types into human-readable repeat labels
- **ScheduledTaskRow**: Interface defining the structure for table row data
- **useScheduledTasks**: Custom hook for fetching scheduled task data
- **Table**: OpenFrame UI component for displaying tabular data

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

export function ScriptDetailsPage() {
  const scriptId = "script-123"
  
  return (
    <div className="container">
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId={scriptId} />
    </div>
  )
}
```

The component automatically handles loading states, error scenarios, and transforms raw scheduled task data into a formatted table with columns for task name, date & time, repeat frequency, and device count. It uses the OpenFrame design system for consistent styling and includes proper error boundaries for failed data fetching.
