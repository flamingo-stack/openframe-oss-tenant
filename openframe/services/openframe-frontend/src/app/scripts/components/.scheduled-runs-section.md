A React component that displays scheduled script runs in a table format, allowing users to view and manage their automated script executions with details like timing, repeat patterns, and device counts.

## Key Components

- **ScheduledRunsSection** - Main component that renders the scheduled runs table
- **formatDate** - Utility function that formats ISO date strings into separate date and time display values
- **getRepeatLabel** - Helper that converts task types into human-readable repeat frequency labels
- **ScheduledTaskRow** - Interface defining the table row data structure

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

function ScriptDetailsPage({ scriptId }: { scriptId: string }) {
  return (
    <div>
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId="script-123" />
    </div>
  )
}
```

The component integrates with the `useScheduledTasks` hook to fetch data and displays it using the OpenFrame Table component. It handles loading states, error conditions, and formats scheduling information into a user-friendly interface. Each row shows the task name, formatted date/time, repeat frequency (daily, weekly, monthly, or run-once), and associated device count. The table supports empty states and skeleton loading for better user experience.
