A React component that displays scheduled task runs in a tabular format, showing details like schedule timing, repeat intervals, and device assignments for a specific script.

## Key Components

- **ScheduledRunsSection**: Main component that renders scheduled tasks table
- **ScheduledTaskRow**: Interface defining the table row data structure
- **formatDate**: Utility function that formats ISO date strings into separate date and time displays
- **getRepeatLabel**: Helper function that converts task types into user-friendly repeat interval labels
- **Table columns configuration**: Defines how each column (Note, Date & Time, Repeat, Devices) is rendered

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

function ScriptDetailsPage({ scriptId }: { scriptId: string }) {
  return (
    <div className="container">
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId={scriptId} />
    </div>
  )
}
```

The component automatically fetches scheduled tasks using the `useScheduledTasks` hook and transforms the data for display. It handles loading states, error conditions, and empty states gracefully. The table shows task names as "Note", formatted dates and times, repeat intervals (Daily, Weekly, Monthly, or None), and currently hardcoded device count of 1. Each scheduled task type (daily, weekly, monthly, runonce) is converted to a human-readable repeat label with proper interval formatting.
