A React component that displays scheduled script runs in a table format, showing task details like name, date/time, repeat frequency, and device count.

## Key Components

- **ScheduledRunsSection**: Main component that renders the scheduled tasks table
- **formatDate**: Utility function to format ISO date strings into readable date and time
- **getRepeatLabel**: Converts task type into human-readable repeat frequency labels
- **ScheduledTaskRow**: Interface defining the table row data structure

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

export function ScriptDetailPage() {
  return (
    <div className="container">
      <ScheduledRunsSection scriptId="script-123" />
    </div>
  )
}
```

The component fetches scheduled tasks using the `useScheduledTasks` hook, transforms the data for table display, and handles loading/error states. It uses the OpenFrame UI Table component with custom column renderers for formatting date/time information and repeat frequencies. The table displays task names, execution dates/times, repeat patterns (daily, weekly, monthly, or one-time), and device counts in a clean, organized layout.
