A React component that displays scheduled tasks for a specific script in a formatted table, showing task details including timing, repetition patterns, and device counts.

## Key Components

- **ScheduledRunsSection** - Main component that renders the scheduled runs table
- **formatDate** - Utility function that converts ISO date strings to localized date and time format
- **getRepeatLabel** - Utility function that converts task types into human-readable repeat labels
- **ScheduledTaskRow** - Interface defining the table row data structure
- **useScheduledTasks** - Custom hook for fetching scheduled task data

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

function ScriptDetailsPage() {
  return (
    <div className="p-6">
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId="script-123" />
    </div>
  )
}
```

The component automatically handles loading states, error states, and empty states. It transforms raw scheduled task data into a user-friendly table format with columns for task name, date/time, repeat frequency, and device count. The table uses the OpenFrame UI Table component with custom cell renderers for proper formatting and styling.
