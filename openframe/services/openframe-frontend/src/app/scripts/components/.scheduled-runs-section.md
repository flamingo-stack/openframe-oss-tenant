A React component that displays scheduled task runs for a specific script in a table format, allowing users to view and manage script automation schedules.

## Key Components

- **`ScheduledRunsSection`** - Main component that renders the scheduled runs table
- **`formatDate`** - Utility function that formats ISO date strings into separate date and time display values
- **`getRepeatLabel`** - Utility function that converts task type and interval data into human-readable repeat labels
- **`handleEditTask`** - Navigation handler for editing scheduled tasks
- **Column definitions** - Table configuration for displaying task name, date/time, repeat pattern, and device count

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

function ScriptDetailsPage({ scriptId }: { scriptId: string }) {
  return (
    <div>
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId={scriptId} />
    </div>
  )
}

// The component automatically fetches and displays scheduled tasks
// Users can click on rows to navigate to edit forms at:
// /scripts/details/{scriptId}/schedule/{taskId}
```

The component uses the `useScheduledTasks` hook to fetch data and renders it in an OpenFrame Table component with loading states, error handling, and empty state messaging. Each row displays task details with formatted dates/times and human-readable repeat intervals (e.g., "2 Days", "Weekly", "Monthly", "None").
