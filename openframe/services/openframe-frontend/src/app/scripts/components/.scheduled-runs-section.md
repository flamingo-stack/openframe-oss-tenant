A React component that displays scheduled script runs in a table format, showing task details like date/time, repeat frequency, and target devices.

## Key Components

- **ScheduledRunsSection**: Main component that renders the scheduled runs table
- **formatDate**: Utility function to format ISO date strings into US locale date/time display
- **getRepeatLabel**: Utility function to convert task types into human-readable repeat labels
- **ScheduledTaskRow**: Interface for table row data structure
- **Table Integration**: Uses OpenFrame's Table component with custom column definitions

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

function ScriptDetailPage() {
  const scriptId = "script-123"
  
  return (
    <div>
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId={scriptId} />
    </div>
  )
}
```

The component fetches scheduled tasks using the `useScheduledTasks` hook, transforms the data into table-friendly format, and renders it with custom styling. It handles loading states, error states, and empty states automatically through the Table component. The table displays task name, formatted date/time, repeat frequency (daily/weekly/monthly/none), and device count with responsive styling using OpenFrame design system classes.
