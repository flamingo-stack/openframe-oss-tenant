A React component that displays scheduled script runs in a tabular format with date/time, repeat intervals, and device counts for a specific script.

## Key Components

- **ScheduledRunsSection**: Main component that renders a table of scheduled tasks
- **formatDate**: Utility function that formats ISO date strings into separate date and time components
- **getRepeatLabel**: Helper function that converts task types into human-readable repeat intervals
- **ScheduledTaskRow**: Interface defining the table row structure with formatted data
- **useScheduledTasks**: Custom hook for fetching scheduled tasks data
- **Table**: UI component from OpenFrame core for rendering data tables

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

export function ScriptDetailsPage({ scriptId }: { scriptId: string }) {
  return (
    <div>
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId={scriptId} />
    </div>
  )
}
```

The component automatically handles loading states, error states, and empty data scenarios. It transforms raw scheduled task data into a formatted table showing task names, formatted dates/times, repeat patterns (daily/weekly/monthly/none), and device counts. The table includes proper styling with OpenFrame design system classes and responsive text overflow handling.
