A React component that displays scheduled task runs in a table format for a specific script, with formatting for dates, times, and repeat intervals.

## Key Components

- **ScheduledRunsSection**: Main component that renders the scheduled tasks table
- **formatDate**: Utility function that converts ISO date strings to formatted date/time pairs
- **getRepeatLabel**: Helper function that converts task types into human-readable repeat intervals
- **ScheduledTaskRow**: Interface defining the table row data structure
- **useScheduledTasks**: Custom hook for fetching scheduled task data
- **Table**: UI component from OpenFrame for displaying tabular data

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

export function ScriptDetailPage() {
  const scriptId = "script-123"
  
  return (
    <div>
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId={scriptId} />
    </div>
  )
}
```

The component automatically handles loading states, error display, and transforms raw scheduled task data into a user-friendly table with columns for task name, date/time, repeat frequency, and device count. It uses the OpenFrame design system for consistent styling and supports empty states when no scheduled runs exist.
