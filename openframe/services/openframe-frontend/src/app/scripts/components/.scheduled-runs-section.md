A React component that displays scheduled task runs in a table format for a specific script, with support for different scheduling types and date/time formatting.

## Key Components

- **ScheduledRunsSection** - Main component that renders a table of scheduled tasks
- **formatDate()** - Utility function to format ISO date strings into localized date and time
- **getRepeatLabel()** - Utility function to convert task types into human-readable repeat labels
- **ScheduledTaskRow** - Interface for table row data structure

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

function ScriptDetails() {
  return (
    <div>
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId="script-123" />
    </div>
  )
}
```

The component fetches scheduled tasks using the `useScheduledTasks` hook and displays them in a responsive table with columns for task name, date/time, repeat interval, and device count. It handles loading states, error conditions, and empty states gracefully. The table supports different task types (daily, weekly, monthly, run-once) and formats dates according to US locale conventions.
