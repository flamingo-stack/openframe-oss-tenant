A React component that displays scheduled runs for a specific script in a tabular format with date/time formatting and repeat patterns.

## Key Components

- **ScheduledRunsSection** - Main component that renders the scheduled runs table
- **ScheduledTaskRow** - Interface defining the table row structure
- **formatDate()** - Utility function that converts ISO date strings to formatted date and time
- **getRepeatLabel()** - Helper function that converts task types to human-readable repeat labels
- **useScheduledTasks()** - Custom hook for fetching scheduled task data
- **Table** - UI component from OpenFrame frontend core for data display

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

function ScriptDetailsPage() {
  const scriptId = "script_123"

  return (
    <div>
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId={scriptId} />
    </div>
  )
}
```

The component transforms scheduled task data into a formatted table with columns for task name (Note), formatted date/time, repeat frequency, and device count. It handles loading states, error states, and empty data scenarios. The table displays tasks with proper date formatting (MM/DD/YYYY and 12-hour time) and converts task types like 'daily', 'weekly', 'monthly', and 'runonce' into user-friendly repeat labels.
