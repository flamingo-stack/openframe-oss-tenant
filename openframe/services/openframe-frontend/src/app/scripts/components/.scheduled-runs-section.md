A React component that displays scheduled task runs for a specific script in a table format with date/time, repeat patterns, and device information.

## Key Components

- **ScheduledRunsSection** - Main component that renders a table of scheduled tasks
- **formatDate** - Utility function that splits datetime strings into separate date and time values
- **getRepeatLabel** - Converts task type enums into human-readable repeat patterns
- **ScheduledTaskRow** - Interface defining the table row data structure
- **useScheduledTasks** - Custom hook for fetching scheduled task data

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

export function ScriptDetailsPage() {
  const scriptId = "script-123"
  
  return (
    <div>
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId={scriptId} />
    </div>
  )
}
```

The component automatically handles loading states, error scenarios, and empty data cases. It formats scheduled tasks into a readable table showing task names, execution dates/times, repeat intervals (daily, weekly, monthly, or one-time), and device counts. The table uses the OpenFrame UI Table component with custom column renderers for consistent styling.
