A React component that displays scheduled task runs for a specific script in a table format with date/time information, repeat intervals, and device counts.

## Key Components

- **ScheduledRunsSection** - Main component that renders scheduled runs table
- **ScheduledTaskRow** - Interface defining table row structure
- **formatDate** - Utility function for formatting date/time display
- **getRepeatLabel** - Utility function for formatting task repeat intervals
- **useScheduledTasks** - Custom hook for fetching scheduled task data

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

export function ScriptDetails() {
  return (
    <div>
      {/* Other script details */}
      <ScheduledRunsSection scriptId="123" />
    </div>
  )
}
```

The component transforms scheduled task data into a table format with columns for task name (Note), formatted date/time, repeat interval, and device count. It handles loading states, error states, and empty states through the OpenFrame Table component. Date formatting follows US locale standards with 12-hour time format, and repeat labels are generated based on task type (daily, weekly, monthly, or run-once).
