A React component that displays scheduled tasks for a specific script in a table format, featuring formatted date/time display and repeat interval labels.

## Key Components

- **ScheduledRunsSection** - Main component that renders the scheduled tasks table
- **formatDate()** - Utility function that formats ISO date strings into separate date and time values
- **getRepeatLabel()** - Helper function that converts task types (daily, weekly, monthly, runonce) into user-friendly repeat labels
- **ScheduledTaskRow** - Interface defining the structure of table row data
- **useScheduledTasks** - Custom hook for fetching scheduled task data

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

function ScriptDetailsPage({ params }: { params: { scriptId: string } }) {
  return (
    <div>
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId={params.scriptId} />
    </div>
  )
}

export default ScriptDetailsPage
```

The component automatically handles loading states, error display, and transforms raw scheduled task data into a formatted table showing task names, formatted dates/times, repeat intervals, and device counts. It uses the OpenFrame UI Table component with custom column renderers for proper styling and layout.
