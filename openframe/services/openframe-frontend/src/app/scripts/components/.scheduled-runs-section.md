React component that displays scheduled task runs for a specific script in a tabular format with formatted date/time information and repeat patterns.

## Key Components

- **ScheduledRunsSection**: Main component that renders a table of scheduled tasks for a given script
- **formatDate**: Utility function that converts ISO date strings to localized date and time formats
- **getRepeatLabel**: Helper function that generates human-readable repeat frequency labels based on task type
- **ScheduledTaskRow**: Interface defining the table row data structure
- **Table columns configuration**: Defines rendering for task name, date/time, repeat pattern, and device count

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

function ScriptDetailsPage({ params }: { params: { id: string } }) {
  return (
    <div>
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId={params.id} />
    </div>
  )
}
```

The component fetches scheduled tasks using the `useScheduledTasks` hook, transforms the data for table display, and handles loading/error states. It supports various repeat patterns (daily, weekly, monthly, run-once) and formats dates in US locale with 12-hour time format. The table displays task names, scheduled date/time, repeat frequency, and device count with custom cell renderers for proper styling.
