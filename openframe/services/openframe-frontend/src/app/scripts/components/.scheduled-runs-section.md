A React component that displays scheduled tasks for a script in a tabular format, with formatted date/time display and navigation to task editing pages.

## Key Components

- **`ScheduledRunsSection`** - Main component that renders scheduled tasks table
- **`formatDate`** - Utility function to format ISO date strings into separate date and time display
- **`getRepeatLabel`** - Utility function to convert task types into human-readable repeat labels
- **`ScheduledTaskRow`** - Interface defining the table row data structure
- **Table integration** - Uses OpenFrame's Table component with custom column definitions

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

function ScriptDetailsPage({ params }: { params: { id: string } }) {
  return (
    <div>
      {/* Other script details */}
      <ScheduledRunsSection scriptId={params.id} />
    </div>
  )
}
```

The component fetches scheduled tasks using the `useScheduledTasks` hook, formats the data for display, and provides click navigation to edit individual scheduled tasks. It handles loading states, errors, and empty states through the Table component's built-in features. The repeat labels are intelligently generated based on task frequency (daily, weekly, monthly, or run-once).
