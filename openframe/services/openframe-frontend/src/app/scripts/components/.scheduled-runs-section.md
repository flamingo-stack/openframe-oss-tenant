React component that displays a table of scheduled runs for a PowerShell script, showing when scripts are scheduled to execute with their recurrence patterns.

## Key Components

- **ScheduledRunsSection**: Main component that renders scheduled tasks in a table format
- **formatDate**: Utility function that splits datetime into separate date and time strings
- **getRepeatLabel**: Converts task type into human-readable repeat intervals
- **useScheduledTasks**: Custom hook for fetching scheduled task data
- **Table**: UI component from OpenFrame core for displaying tabular data

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

function ScriptDetailsPage({ scriptId }: { scriptId: string }) {
  return (
    <div>
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId={scriptId} />
    </div>
  )
}

// The component will display a table with columns:
// - Note (task name)
// - Date & Time (formatted as MM/DD/YYYY and HH:MM AM/PM)
// - Repeat (Daily, Weekly, Monthly, or None)
// - Devices (currently hardcoded to 1)
```

The component handles loading states, error states, and empty states automatically through the Table component. It transforms scheduled task data into a user-friendly format with proper date/time formatting and readable repeat intervals.
