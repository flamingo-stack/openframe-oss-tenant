A React component that displays scheduled script runs in a table format, showing task details like date/time, repeat intervals, and device counts for a specific script.

## Key Components

- **ScheduledRunsSection**: Main component that renders a table of scheduled tasks
- **formatDate**: Utility function that converts date strings to formatted date and time display
- **getRepeatLabel**: Helper function that converts task types into human-readable repeat intervals
- **ScheduledTaskRow**: Interface defining the table row structure
- **useScheduledTasks**: Custom hook for fetching scheduled task data

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

// Display scheduled runs for a specific script
function ScriptDetailsPage() {
  return (
    <div>
      <ScheduledRunsSection scriptId="script-123" />
    </div>
  )
}
```

The component transforms raw scheduled task data into a user-friendly table with columns for task name (labeled as "Note"), formatted date/time, repeat frequency, and device count. It handles loading states, error scenarios, and empty data gracefully. The table displays tasks with proper formatting - dates in MM/DD/YYYY format, times in 12-hour format, and repeat intervals converted from task types (daily, weekly, monthly, runonce) into readable labels.
