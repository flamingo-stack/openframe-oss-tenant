A React component that displays scheduled script runs in a table format, showing execution schedules with details like date, time, repeat patterns, and target devices.

## Key Components

- **ScheduledRunsSection**: Main component that renders scheduled tasks for a specific script
- **ScheduledTaskRow**: Interface defining the table row structure
- **formatDate**: Utility function to format ISO dates into user-friendly date/time strings
- **getRepeatLabel**: Helper function to convert task types into human-readable repeat intervals
- **Table columns configuration**: Defines how each column renders (Note, Date & Time, Repeat, Devices)

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

// Display scheduled runs for a specific script
function ScriptDetailsPage({ scriptId }: { scriptId: string }) {
  return (
    <div>
      <h1>Script Management</h1>
      <ScheduledRunsSection scriptId={scriptId} />
    </div>
  )
}

// Example of scheduled task data structure
const exampleTask: ScheduledTask = {
  id: 1,
  name: "Weekly maintenance check",
  task_type: "weekly",
  weekly_interval: 2,
  run_time_date: "2024-01-15T14:30:00Z"
}
```

The component handles loading states, error handling, and formats scheduling information (daily/weekly/monthly intervals) into a clean table interface. It uses the OpenFrame UI Table component with custom column renderers for consistent styling and responsive display.
