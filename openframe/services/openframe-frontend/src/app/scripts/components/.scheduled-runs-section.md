A React component that displays scheduled tasks for a specific script in a table format with date, time, repeat interval, and device information.

## Key Components

- **ScheduledRunsSection**: Main component that fetches and displays scheduled tasks in a table
- **formatDate**: Utility function to format ISO date strings into separate date and time strings
- **getRepeatLabel**: Helper function to generate human-readable repeat interval labels based on task type
- **ScheduledTaskRow**: Interface defining the structure of table row data
- **Table columns**: Configuration for displaying task name, date/time, repeat pattern, and device count

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

function ScriptDetailPage({ params }: { params: { id: string } }) {
  return (
    <div className="container mx-auto p-6">
      <h1>Script Details</h1>
      
      {/* Display scheduled runs for the script */}
      <ScheduledRunsSection scriptId={params.id} />
    </div>
  )
}

// The component automatically handles:
// - Loading states with skeleton rows
// - Error states with fallback UI
// - Empty states when no scheduled tasks exist
// - Date/time formatting in US locale
// - Repeat interval labeling (Daily, Weekly, Monthly, None)
```

The component uses the `useScheduledTasks` hook to fetch data and renders it using OpenFrame's Table component with custom column configurations for optimal display of scheduling information.
