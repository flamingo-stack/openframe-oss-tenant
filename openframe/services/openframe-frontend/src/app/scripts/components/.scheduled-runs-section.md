A React component that displays scheduled automation tasks for scripts in a tabular format, allowing users to view scheduled execution details including timing, repeat patterns, and target devices.

## Key Components

- **ScheduledRunsSection**: Main component that renders a table of scheduled tasks for a specific script
- **formatDate**: Utility function that converts ISO date strings to formatted date and time strings
- **getRepeatLabel**: Utility function that converts task types into human-readable repeat frequency labels
- **ScheduledTaskRow**: Interface defining the structure of table row data
- **useScheduledTasks**: Custom hook for fetching scheduled task data
- **Table**: UI component from OpenFrame core for rendering data tables

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

function ScriptDetailsPage({ scriptId }: { scriptId: string }) {
  return (
    <div>
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId="script-123" />
    </div>
  )
}
```

The component automatically handles loading states, error scenarios, and empty data cases. It transforms raw scheduled task data into a user-friendly table format with columns for task name, scheduled date/time, repeat frequency, and device count. Each row can be clicked to navigate to the task editing interface.
