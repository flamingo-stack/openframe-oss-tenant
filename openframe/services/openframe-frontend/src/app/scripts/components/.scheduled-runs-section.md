A React component that displays scheduled task runs for a specific script in a tabular format with date/time formatting and repeat interval labels.

## Key Components

- **ScheduledRunsSection**: Main component that renders a table of scheduled tasks for a given script
- **formatDate**: Utility function that converts ISO date strings to formatted date and time strings
- **getRepeatLabel**: Function that converts task types into human-readable repeat interval labels
- **ScheduledTaskRow**: Interface defining the table row structure with formatted data

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

function ScriptDetailsPage({ scriptId }: { scriptId: string }) {
  return (
    <div>
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId="script-123" />
    </div>
  )
}
```

The component fetches scheduled tasks using the `useScheduledTasks` hook, transforms the raw data into a table-friendly format, and displays it using OpenFrame's Table component. It handles loading states, error states, and formats dates/times for better readability. The table shows task names, scheduled date/time, repeat intervals (daily, weekly, monthly, or run-once), and device counts.
