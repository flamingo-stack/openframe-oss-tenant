A React component that displays scheduled tasks for a specific script in a formatted table with date/time, repeat intervals, and device counts.

## Key Components

- **`ScheduledRunsSection`** - Main component that renders a table of scheduled tasks for a given script
- **`formatDate`** - Utility function that converts ISO date strings to formatted date and time display
- **`getRepeatLabel`** - Helper function that transforms task types into human-readable repeat intervals
- **`ScheduledTaskRow`** - Interface defining the structure of table row data
- **Table Integration** - Uses OpenFrame's Table component with custom column definitions and cell renderers

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

function ScriptDetailsPage({ scriptId }: { scriptId: string }) {
  return (
    <div>
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId="script-123" />
    </div>
  )
}

// The component will display a table showing:
// - Task names in the "Note" column
// - Formatted dates and times in separate rows
// - Human-readable repeat intervals (e.g., "1 Day", "2 Weeks", "Monthly")
// - Device count (currently hardcoded to 1)
```

The component handles loading states, error states, and empty states automatically through the Table component. It fetches scheduled tasks using the `useScheduledTasks` hook and transforms the data into a user-friendly tabular format with proper date formatting and repeat interval labels.
