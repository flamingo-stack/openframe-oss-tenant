A React component that displays scheduled script executions in a formatted table with date/time formatting and repeat interval labeling.

## Key Components

- **ScheduledRunsSection** - Main component that renders a table of scheduled script runs
- **formatDate** - Utility function that converts ISO date strings to formatted date and time display
- **getRepeatLabel** - Helper function that converts task types to human-readable repeat intervals
- **ScheduledTaskRow** - Interface defining the table row structure with formatted data

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

function ScriptDetailsPage({ scriptId }: { scriptId: string }) {
  return (
    <div>
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId={scriptId} />
    </div>
  )
}
```

The component automatically fetches scheduled tasks using the `useScheduledTasks` hook and transforms the raw task data into a table-friendly format. It handles different task types (daily, weekly, monthly, run-once) and formats dates for consistent display. The table includes columns for task name, scheduled date/time, repeat interval, and device count, with proper loading and error states.
