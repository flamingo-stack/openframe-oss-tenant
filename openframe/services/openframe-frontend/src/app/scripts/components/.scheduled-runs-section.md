A React component that displays a table of scheduled script runs with details about timing, repetition patterns, and assigned devices.

## Key Components

- **ScheduledRunsSection**: Main component that renders a data table of scheduled tasks for a specific script
- **formatDate**: Utility function that converts ISO date strings to formatted date and time display
- **getRepeatLabel**: Helper function that converts task type into human-readable repeat intervals
- **ScheduledTaskRow**: Interface defining the structure for table row data
- **useScheduledTasks**: Custom hook for fetching scheduled tasks data

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

export function ScriptDetailsPage({ scriptId }: { scriptId: string }) {
  return (
    <div>
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId={scriptId} />
    </div>
  )
}
```

The component automatically handles loading states, error conditions, and empty data scenarios. It transforms raw scheduled task data into a user-friendly table format with columns for task name, date/time, repeat frequency, and device count. The table supports skeleton loading during data fetch and displays appropriate messages for error or empty states.
