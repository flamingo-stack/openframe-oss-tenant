A React component that displays scheduled task runs for a specific script in a tabular format with formatted date/time information and repeat intervals.

## Key Components

- **`ScheduledRunsSection`** - Main component that renders the scheduled runs table
- **`formatDate`** - Utility function that formats ISO date strings into separate date and time strings
- **`getRepeatLabel`** - Helper function that converts task type to human-readable repeat labels
- **`ScheduledTaskRow`** - Interface defining the table row structure
- **Table columns** - Configured columns for Note, Date & Time, Repeat, and Devices

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

function ScriptDetailPage({ scriptId }: { scriptId: string }) {
  return (
    <div>
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId={scriptId} />
    </div>
  )
}

// The component automatically handles:
// - Loading states with skeleton rows
// - Error states with fallback UI
// - Empty states with appropriate messaging
// - Date/time formatting (MM/DD/YYYY and 12-hour format)
// - Repeat interval labels (daily, weekly, monthly, run-once)
```

The component uses the `useScheduledTasks` hook to fetch scheduled tasks for the provided script ID and transforms the data into a user-friendly table format. It handles loading, error, and empty states gracefully while providing consistent styling using the OpenFrame design system.
