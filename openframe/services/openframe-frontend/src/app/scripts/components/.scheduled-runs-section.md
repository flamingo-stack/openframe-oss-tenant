React component that displays scheduled script execution tasks in a table format, with date/time formatting and repeat interval labels.

## Key Components

- **ScheduledRunsSection** - Main component that renders a table of scheduled tasks for a specific script
- **formatDate** - Utility function that formats ISO date strings into separate date and time display values
- **getRepeatLabel** - Helper that converts task type and interval data into human-readable repeat labels
- **ScheduledTaskRow** - Interface defining the structure of table row data
- **Table columns configuration** - Defines how each column (Note, Date & Time, Repeat, Devices) is rendered

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

function ScriptDetailsPage() {
  return (
    <div>
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId="script-123" />
    </div>
  )
}
```

The component automatically fetches scheduled tasks using the `useScheduledTasks` hook, transforms the data for table display, and handles loading/error states. It displays task names, formatted execution dates/times, repeat intervals (daily, weekly, monthly, or none), and device counts in a clean tabular interface.
