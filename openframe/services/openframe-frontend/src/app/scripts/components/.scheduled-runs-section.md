A React component that displays scheduled automation script runs in a tabular format with date/time formatting and repeat interval labels.

## Key Components

- **ScheduledRunsSection**: Main component that renders scheduled tasks for a specific script
- **formatDate**: Utility function to format ISO date strings into localized date and time
- **getRepeatLabel**: Utility function to convert task type into human-readable repeat intervals
- **ScheduledTaskRow**: Interface defining the table row data structure
- **useScheduledTasks**: Custom hook for fetching scheduled task data
- **Table**: Reusable table component from the UI library

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

function ScriptDetailsPage() {
  return (
    <div>
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId="script-123" />
    </div>
  )
}
```

The component automatically handles loading states, error states, and empty data scenarios. It formats scheduled tasks into a readable table showing task names, scheduled date/time, repeat intervals (Daily, Weekly, Monthly, or None), and device count. The table supports skeleton loading placeholders and displays appropriate error messages when data fetching fails.
