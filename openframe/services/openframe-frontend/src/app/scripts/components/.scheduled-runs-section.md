A React component that displays scheduled task runs for a specific script in a table format, showing execution dates, times, repeat intervals, and associated devices.

## Key Components

- **ScheduledRunsSection**: Main component that renders the scheduled runs table
- **ScheduledRunsSectionProps**: Interface defining the required `scriptId` prop
- **ScheduledTaskRow**: Interface for table row data structure
- **formatDate()**: Utility function to format dates into separate date/time strings
- **getRepeatLabel()**: Utility function to convert task types into human-readable repeat labels
- **Table columns configuration**: Defines the structure for Note, Date & Time, Repeat, and Devices columns

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

// Display scheduled runs for a specific script
function ScriptDetailPage({ scriptId }: { scriptId: string }) {
  return (
    <div>
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId={scriptId} />
    </div>
  )
}

// The component will automatically fetch and display:
// - Task names as "Note" column
// - Formatted dates and times
// - Repeat intervals (daily, weekly, monthly, or none)
// - Device count (currently hardcoded to 1)
```

The component uses the `useScheduledTasks` hook to fetch data and handles loading states, errors, and empty results. It formats task data into a consistent table structure with proper date/time formatting and repeat interval labels.
