React component that displays scheduled script runs in a table format, showing scheduling details and repeat patterns for automated script execution.

## Key Components

- **ScheduledRunsSection** - Main component that renders a table of scheduled tasks for a specific script
- **ScheduledTaskRow** - Interface defining the table row data structure with task details
- **formatDate()** - Utility function that formats ISO date strings into separate date and time components
- **getRepeatLabel()** - Utility function that converts task type into human-readable repeat frequency labels

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

function ScriptDetailsPage({ scriptId }: { scriptId: string }) {
  return (
    <div>
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId={scriptId} />
    </div>
  )
}
```

The component fetches scheduled tasks using the `useScheduledTasks` hook, transforms the data for table display, and handles loading/error states. It displays task names, formatted dates/times, repeat patterns (Daily, Weekly, Monthly, or None), and device counts in a styled table with proper typography and spacing following the OpenFrame design system.
