A React component that displays scheduled tasks for a specific script in a tabular format with date/time, repeat intervals, and device counts.

## Key Components

- **ScheduledRunsSection** - Main component that renders a table of scheduled script runs
- **ScheduledTaskRow** - Interface defining the table row data structure
- **formatDate** - Utility function that formats ISO date strings to separate date and time
- **getRepeatLabel** - Utility function that converts task types to human-readable repeat labels

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

function ScriptDetailsPage({ scriptId }: { scriptId: string }) {
  return (
    <div>
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId={scriptId} />
    </div>
  )
}
```

The component automatically fetches scheduled tasks using the `useScheduledTasks` hook, transforms the data for display, and handles loading/error states. Each row shows the task name, formatted date/time, repeat frequency (Daily, Weekly, Monthly, or None), and device count. The table supports empty states and loading skeletons for better UX.
