A React component that displays scheduled task runs in a table format for a specific script, showing task details like name, date/time, repeat intervals, and target devices.

## Key Components

- **ScheduledRunsSection** - Main component that renders scheduled tasks table
- **formatDate** - Utility function to format ISO date strings into readable date/time
- **getRepeatLabel** - Utility function to convert task type into human-readable repeat frequency
- **ScheduledTaskRow** - Interface defining table row structure
- **useScheduledTasks** - Custom hook for fetching scheduled task data
- **Table** - UI component from OpenFrame frontend core for data display

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

// Display scheduled runs for a specific script
function ScriptDetailsPage({ params }: { params: { id: string } }) {
  return (
    <div>
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId={params.id} />
    </div>
  )
}
```

The component automatically handles loading states, error scenarios, and transforms raw scheduled task data into a user-friendly table format. It supports different task types (daily, weekly, monthly, run-once) and displays appropriate repeat frequency labels. The table includes columns for task name, scheduled date/time, repeat pattern, and device count.
