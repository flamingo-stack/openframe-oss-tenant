A React component that displays scheduled task runs for a specific script in a formatted table with date/time information and repeat patterns.

## Key Components

- **`ScheduledRunsSection`** - Main component that renders the scheduled runs table
- **`formatDate`** - Utility function that converts ISO date strings to localized date and time format
- **`getRepeatLabel`** - Helper function that transforms task types into human-readable repeat labels
- **`ScheduledTaskRow`** - Interface defining the table row structure with formatted data
- **Table columns configuration** - Defines rendering for Note, Date & Time, Repeat, and Devices columns

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

function ScriptDetailsPage({ scriptId }: { scriptId: string }) {
  return (
    <div>
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId="script-123" />
    </div>
  )
}
```

The component fetches scheduled tasks using the `useScheduledTasks` hook, transforms the data for display, and renders it in a table format. It handles loading states, error conditions, and provides an empty state message when no scheduled runs exist. The table displays task names, formatted dates/times, repeat patterns (Daily, Weekly, Monthly, or None), and device counts.
