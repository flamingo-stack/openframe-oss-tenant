A React component that displays scheduled script runs in a tabular format, fetching data via custom hooks and presenting task details including dates, repeat patterns, and device counts.

## Key Components

- **ScheduledRunsSection**: Main component that renders a table of scheduled tasks for a specific script
- **formatDate**: Utility function that splits datetime strings into separate date and time displays
- **getRepeatLabel**: Helper function that converts task type data into user-friendly repeat interval labels
- **ScheduledTaskRow**: Interface defining the table row data structure
- **Table integration**: Uses OpenFrame's Table component with custom column renderers

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

// Display scheduled runs for a specific script
function ScriptDetailsPage({ scriptId }: { scriptId: string }) {
  return (
    <div>
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId={scriptId} />
    </div>
  )
}

// The component automatically handles:
// - Loading states with skeleton rows
// - Error states with fallback UI
// - Data transformation from ScheduledTask to table format
// - Responsive date/time display formatting
```

The component provides a clean interface for viewing scheduled automation tasks, with proper error handling and loading states built into the OpenFrame Table component.
