A React component that displays scheduled task runs for a specific script in a tabular format, fetching data from the scheduled tasks API and formatting it for user-friendly display.

## Key Components

- **ScheduledRunsSection** - Main component that renders a table of scheduled tasks
- **formatDate()** - Utility function to format ISO date strings into separate date and time display values
- **getRepeatLabel()** - Helper function to convert task type enums into human-readable repeat frequency labels
- **ScheduledTaskRow** - Interface defining the table row data structure
- **useScheduledTasks** - Custom hook for fetching scheduled task data
- **Table** - UI component from OpenFrame core for rendering data tables

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

function ScriptDetailsPage({ scriptId }: { scriptId: string }) {
  return (
    <div>
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId={scriptId} />
    </div>
  )
}
```

The component transforms raw scheduled task data into a user-friendly table format, displaying task names, formatted dates/times, repeat frequencies (Daily, Weekly, Monthly, or None), and device counts. It handles loading states, error states, and empty data scenarios with appropriate UI feedback.
