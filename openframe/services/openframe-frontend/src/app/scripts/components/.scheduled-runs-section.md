Displays a data table showing scheduled task runs for a specific script, including scheduling details like date/time, repeat intervals, and device counts.

## Key Components

- **ScheduledRunsSection**: Main component that renders scheduled tasks in a table format
- **formatDate**: Utility function that converts ISO date strings to localized date and time format
- **getRepeatLabel**: Utility function that converts task type to human-readable repeat labels
- **ScheduledTaskRow**: Interface defining the table row structure with formatted data

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

function ScriptDetailsPage() {
  return (
    <div>
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId="script-123" />
    </div>
  )
}
```

The component fetches scheduled tasks using the `useScheduledTasks` hook, transforms the data into a table-friendly format with separate date/time columns, and displays it using the OpenFrame Table component. It handles loading states, error states, and empty data scenarios. The table shows task names (as "Note"), formatted date/time, repeat intervals (Daily/Weekly/Monthly/None), and device count (currently hardcoded to 1).
