A React component that displays a table of scheduled runs for a specific script, showing task details like date/time, repeat intervals, and device counts in a formatted table view.

## Key Components

- **`ScheduledRunsSection`**: Main component that renders the scheduled tasks table
- **`formatDate`**: Utility function that formats ISO date strings into separate date and time components
- **`getRepeatLabel`**: Utility function that converts task type and intervals into human-readable repeat labels
- **`ScheduledTaskRow`**: Interface defining the structure of table row data
- **`useScheduledTasks`**: Custom hook for fetching scheduled task data
- **OpenFrame UI Table**: Reusable table component with loading states and empty message handling

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

export function ScriptDetailsPage() {
  const scriptId = "script-123"
  
  return (
    <div>
      <h1>Script Details</h1>
      <ScheduledRunsSection scriptId={scriptId} />
    </div>
  )
}
```

The component automatically handles loading states, error states, and empty data scenarios. It formats dates in MM/DD/YYYY format and times in 12-hour format, converts task types into readable labels (e.g., "daily" becomes "1 Day" or "2 Days"), and provides a responsive table layout with custom cell rendering for each column.
