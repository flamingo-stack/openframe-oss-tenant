A React component that displays scheduled script executions in a tabular format, allowing users to view when and how often their automation scripts are scheduled to run.

## Key Components

- **ScheduledRunsSection** - Main component that renders a table of scheduled tasks for a specific script
- **formatDate** - Utility function that splits ISO date strings into separate date and time display values
- **getRepeatLabel** - Helper function that converts task types into user-friendly repeat interval labels
- **ScheduledTaskRow** - Interface defining the table row structure with formatted display data

## Usage Example

```typescript
import { ScheduledRunsSection } from './scheduled-runs-section'

function ScriptDetailsPage({ scriptId }: { scriptId: string }) {
  return (
    <div>
      <h1>Script Details</h1>
      {/* Other script information */}
      <ScheduledRunsSection scriptId={scriptId} />
    </div>
  )
}
```

The component automatically fetches scheduled tasks using the `useScheduledTasks` hook and displays them in a responsive table with columns for task name, date/time, repeat interval, and device count. It handles loading states and error scenarios gracefully, showing appropriate messages when tasks fail to load or when no scheduled runs exist.
