A React component for creating and editing script schedules with form validation, platform selection, and recurring schedule configuration.

## Key Components

- **ScheduleCreateView** - Main component handling schedule creation/editing
- **Form Management** - Uses react-hook-form with zod validation for robust form handling
- **Platform Selection** - Multi-platform support with SelectButton components
- **Action Management** - Dynamic form fields for script actions using useFieldArray
- **Date/Time Scheduling** - Date picker with repeat interval configuration
- **Mutation Hooks** - Integration with create/update schedule API endpoints

## Usage Example

```typescript
// Create new schedule
<ScheduleCreateView />

// Edit existing schedule
<ScheduleCreateView scheduleId="schedule-123" />

// The component handles both modes automatically based on scheduleId presence
function SchedulePage({ params }: { params: { id?: string } }) {
  return <ScheduleCreateView scheduleId={params.id} />
}
```

## Key Features

- **Dual Mode Operation** - Supports both create and edit workflows
- **Platform Validation** - Validates script compatibility with selected platforms
- **Recurring Schedules** - Configurable repeat intervals (daily, weekly, monthly)
- **Dynamic Actions** - Add/remove multiple script actions within a schedule
- **Form Persistence** - Auto-populates form data when editing existing schedules
- **Responsive Design** - Adapts layout for mobile and desktop viewports
- **Error Handling** - Comprehensive validation with user-friendly error messages
