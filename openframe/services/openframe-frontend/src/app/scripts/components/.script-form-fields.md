A React component that renders form fields for script editing and creation in the Flamingo OpenFrame platform, providing comprehensive configuration options for script properties, platform support, and content editing.

## Key Components

- **`ScriptFormFields`** - Main form component that renders all script configuration fields
- **Platform Selection** - Multi-select interface for supported platforms with disabled state handling
- **Form Field Controllers** - React Hook Form controlled inputs for name, shell type, category, and timeout
- **Script Arguments/Environment Variables** - Dynamic key-value pair management sections
- **Script Editor Integration** - Embedded code editor with syntax highlighting based on selected shell type

## Usage Example

```typescript
import { useForm } from 'react-hook-form'
import { ScriptFormFields } from './script-form-fields'
import type { EditScriptFormData } from '../types/edit-script.types'

function ScriptEditForm() {
  const form = useForm<EditScriptFormData>({
    defaultValues: {
      name: '',
      shell: 'bash',
      category: '',
      supported_platforms: [],
      run_as_user: false,
      default_timeout: 90,
      description: '',
      args: [],
      env_vars: [],
      script_body: ''
    }
  })

  return (
    <form onSubmit={form.handleSubmit(onSubmit)}>
      <ScriptFormFields form={form} />
    </form>
  )
}
```

The component uses React Hook Form's `Controller` components for form state management and includes responsive design with different layouts for mobile and desktop viewports. Platform selection includes visual indicators for disabled platforms with "Coming Soon" tags.
