A client-side loading skeleton component that provides visual placeholders during the schedule creation page loading state. This component mirrors the exact layout and structure of the actual schedule form to ensure a smooth loading experience.

## Key Components

**Main Export:**
- `ScheduleCreateLoader` - Complete page skeleton matching the schedule creation form layout

**Internal Components:**
- `NameFieldSkeleton` - Skeleton for the schedule name input field with label
- `DateRepeatSkeleton` - Skeleton for date picker and repeat checkbox controls  
- `PlatformsSkeleton` - Skeleton for the platform selection buttons (3 platform options)
- `ActionCardSkeleton` - Skeleton for individual script action cards with dropdown and inputs

## Usage Example

```typescript
import { ScheduleCreateLoader } from './schedule-create-loader'

function SchedulePage() {
  const { data, loading } = useScheduleData()
  
  if (loading) {
    return <ScheduleCreateLoader />
  }
  
  return <ScheduleCreateView data={data} />
}

// Or with Suspense
function App() {
  return (
    <Suspense fallback={<ScheduleCreateLoader />}>
      <ScheduleCreatePage />
    </Suspense>
  )
}
```

The skeleton uses consistent spacing, rounded corners, and responsive design patterns that match the actual form components. Each skeleton section corresponds to a specific part of the schedule creation interface, from the header navigation to individual script action cards.
