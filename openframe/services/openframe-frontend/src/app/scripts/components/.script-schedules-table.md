A React component that displays script schedules in a paginated, searchable table with platform badges and edit actions.

## Key Components

- **ScriptSchedulesTable** - Main component rendering the script schedules list
- **getRepeatLabelFromTaskType()** - Utility function converting task types to human-readable repeat labels
- **Table Configuration** - Columns for script name, date/time, repeat frequency, supported platforms, and device count
- **Search & Pagination** - Debounced search with client-side pagination (10 items per page)
- **Row Actions** - Edit button for each schedule row with navigation

## Usage Example

```typescript
import { ScriptSchedulesTable } from './script-schedules-table'

// Display in a scripts management page
export default function ScriptsPage() {
  return (
    <div className="container">
      <ScriptSchedulesTable />
    </div>
  )
}

// The component handles:
// - Loading schedules via useScriptSchedules hook
// - Search filtering by script name
// - Client-side pagination with URL state
// - Navigation to schedule details/edit pages
// - Platform badge display with OS type icons
```

The component uses OpenFrame UI components and hooks for consistent styling and behavior. It automatically formats schedule dates, handles responsive column hiding, and provides smooth navigation between schedule views.
