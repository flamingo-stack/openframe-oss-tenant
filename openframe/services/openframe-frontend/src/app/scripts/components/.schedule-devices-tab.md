Renders a tab component displaying devices (agents) assigned to a specific script schedule in a table format with device information and OS type badges.

## Key Components

- **ScheduleDevicesTab**: Main component that displays assigned agents in a table
- **columns**: Table configuration defining device display format and details column
- **useScriptScheduleAgents**: Custom hook for fetching agent data for the schedule
- **Table**: Reusable table component with loading states and empty message handling

## Usage Example

```typescript
import { ScheduleDevicesTab } from './schedule-devices-tab'
import type { ScriptScheduleDetail } from '../types/script-schedule.types'

function ScheduleDetailsPage() {
  const schedule: ScriptScheduleDetail = {
    id: 'schedule-123',
    name: 'Weekly System Check',
    // ... other schedule properties
  }

  return (
    <div className="schedule-tabs">
      <ScheduleDevicesTab 
        schedule={schedule}
        scheduleId="schedule-123"
      />
    </div>
  )
}
```

The component automatically handles loading states, error conditions, and displays agent count. The table shows device hostnames and OS type badges, with the details column hidden on medium screens and smaller. Empty states are handled with a descriptive message when no devices are assigned to the schedule.
