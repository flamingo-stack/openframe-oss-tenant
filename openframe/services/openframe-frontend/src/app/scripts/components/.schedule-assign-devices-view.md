A React component for managing device assignment to script schedules in OpenFrame. It provides a tabbed interface to view available and selected devices, with search functionality and batch operations for efficient schedule management.

## Key Components

- **ScheduleAssignDevicesView**: Main component that handles device assignment to schedules
- **DeviceTabContent**: Sub-component for rendering device tables with different modes (available/selected)
- **fetchDevicesByPlatforms**: Async function to fetch devices filtered by supported platforms
- Custom hooks for schedule data management and mutations

## Usage Example

```typescript
import { ScheduleAssignDevicesView } from './schedule-assign-devices-view'

// Used in a route page to assign devices to a schedule
function AssignDevicesPage({ params }: { params: { scheduleId: string } }) {
  return <ScheduleAssignDevicesView scheduleId={params.scheduleId} />
}

// The component handles:
// - Fetching schedule details and current device assignments
// - Displaying available devices in a searchable table
// - Managing device selection state with add/remove actions
// - Saving device assignments back to the schedule
```

The component features a two-tab interface (Available/Selected devices), real-time search filtering, batch operations for adding/removing all devices, and integrates with the schedule management system for persistent device assignments.
