A loading skeleton component that displays placeholder content while the Schedule Assign Devices page loads, providing visual feedback during data fetching operations.

## Key Components

- **InfoBarSkeleton** - Mimics the schedule information bar with name/note and date/time/repeat/platform sections
- **SelectionModeSkeleton** - Shows skeleton for device selection mode radio options (manual vs automatic)
- **DeviceRowSkeleton** - Placeholder for individual device table rows with device info and action buttons
- **ScheduleAssignDevicesLoader** - Main loader that combines all skeleton components to match the full page layout

## Usage Example

```typescript
import { ScheduleAssignDevicesLoader } from './schedule-assign-devices-loader'

// Show loading skeleton while data is being fetched
function ScheduleAssignDevicesPage() {
  const { data, isLoading } = useScheduleDevices(scheduleId)
  
  if (isLoading) {
    return <ScheduleAssignDevicesLoader />
  }
  
  return <ScheduleAssignDevicesView data={data} />
}
```

The component provides a comprehensive loading state that matches the exact layout structure of the actual Schedule Assign Devices page, including the back navigation, title/save button, info bar, selection modes, tabs, search input, and device table rows. It uses the OpenFrame UI Skeleton component with consistent spacing and responsive design patterns.
