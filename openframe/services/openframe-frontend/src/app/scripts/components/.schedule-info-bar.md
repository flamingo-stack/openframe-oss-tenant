A responsive UI component that displays script schedule information in a structured grid layout with date, time, repeat frequency, and supported platforms.

## Key Components

- **`ScheduleInfoBar`** - Main component that displays schedule details from a `ScriptScheduleDetail` object
- **`ScheduleInfoBarFromData`** - Alternative component that accepts raw data props instead of a schedule object
- **`ScheduleInfoBarProps`** - Interface defining props for the main component
- **`ScheduleInfoBarFromDataProps`** - Interface for the data-driven variant

## Usage Example

```typescript
import { ScheduleInfoBar, ScheduleInfoBarFromData } from './schedule-info-bar'
import type { ScriptScheduleDetail } from '../types/script-schedule.types'

// Using with schedule object
const schedule: ScriptScheduleDetail = {
  run_time_date: '2024-01-15T10:30:00Z',
  task_supported_platforms: ['windows', 'linux'],
  repeat_type: 'daily'
}

function ScheduleDisplay() {
  return <ScheduleInfoBar schedule={schedule} />
}

// Using with raw data
function CustomScheduleDisplay() {
  return (
    <ScheduleInfoBarFromData
      name="Daily System Check"
      note="Automated health monitoring"
      date="Jan 15, 2024"
      time="10:30 AM"
      repeat="Daily"
      platforms={['windows', 'linux']}
    />
  )
}
```

The component features a responsive grid layout that adapts from 2 columns on mobile to 4 columns on desktop, with consistent styling using the OpenFrame design system classes.
