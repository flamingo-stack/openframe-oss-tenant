A comprehensive loading skeleton component for the Schedule Script page that matches the exact layout and responsive behavior of the actual ScheduleScriptView component.

## Key Components

- **`ScheduleScriptLoader`** - Main loader component providing complete page skeleton
- **`ScriptInfoSectionSkeleton`** - Skeleton for script metadata section with responsive grid layout
- **`ScriptArgumentsSkeleton`** - Skeleton for script arguments/environment variables sections
- **`DeviceCardSkeleton`** - Individual device selection card skeleton

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

// In your page component while loading script data
function ScheduleScriptPage() {
  const { data: scriptData, isLoading } = useScriptQuery(scriptId)
  
  if (isLoading) {
    return <ScheduleScriptLoader />
  }
  
  return <ScheduleScriptView script={scriptData} />
}
```

The loader provides skeletons for all major sections including the header with back button, script info card, timeout configuration, arguments/environment variables in a two-column grid, scheduling options (note, date/time, repeat), device/organization filtering with filter chips, and a responsive device selection grid. The component uses responsive design patterns matching mobile-first layouts with desktop optimizations, ensuring consistent visual hierarchy during loading states.
