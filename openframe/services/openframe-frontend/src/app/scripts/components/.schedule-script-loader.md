A client-side loading skeleton component that displays placeholder UI while the Schedule Script page is loading, matching the exact layout and structure of the actual ScheduleScriptView component.

## Key Components

- **ScheduleScriptLoader** - Main export providing complete page skeleton
- **ScriptInfoSectionSkeleton** - Skeleton for script details card (headline, description, metadata)
- **ScriptArgumentsSkeleton** - Skeleton for script arguments/environment variables sections
- **DeviceCardSkeleton** - Skeleton for individual device selection cards

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage() {
  const { isLoading, data } = useScheduleScript()
  
  if (isLoading) {
    return <ScheduleScriptLoader />
  }
  
  return <ScheduleScriptView data={data} />
}
```

The skeleton uses responsive design matching the actual component:
- Mobile-first grid layouts that expand on larger screens
- Proper spacing and sizing using Tailwind classes
- OpenFrame design system colors (`ods-card`, `ods-border`)
- Skeleton components from the core UI library for consistent loading states

Each skeleton section precisely mirrors its corresponding real component's structure, including the device grid (1→2→3→4 columns), two-column argument sections, and responsive form layouts.
