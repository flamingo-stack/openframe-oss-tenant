A loading skeleton component that displays placeholder elements while the Schedule Script page content is loading.

## Key Components

- **`ScheduleScriptLoader`** - Main skeleton loader that mirrors the complete Schedule Script page layout
- **`ScriptInfoSectionSkeleton`** - Skeleton for script information display with headline, description, and metadata
- **`ScriptArgumentsSkeleton`** - Skeleton for script arguments input section with key/value pairs
- **`DeviceCardSkeleton`** - Skeleton for individual device selection cards

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage() {
  const [isLoading, setIsLoading] = useState(true)

  if (isLoading) {
    return <ScheduleScriptLoader />
  }

  return (
    <div>
      {/* Actual schedule script content */}
    </div>
  )
}
```

The component provides responsive skeleton placeholders that match the exact layout structure of the Schedule Script view, including header navigation, script information cards, argument inputs, device selection grid, and form controls. It uses the OpenFrame design system's Skeleton component and follows the same responsive breakpoints as the actual page content.
