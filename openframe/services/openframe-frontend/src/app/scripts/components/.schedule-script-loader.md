A loading skeleton component that provides placeholder content while the Schedule Script page loads, maintaining the exact layout structure of the actual page.

## Key Components

**Main Export:**
- `ScheduleScriptLoader` - Complete page skeleton matching ScheduleScriptView layout

**Supporting Skeleton Components:**
- `ScriptInfoSectionSkeleton` - Mimics script details card with metadata
- `ScriptArgumentsSkeleton` - Shows placeholder for script arguments and environment variables
- `DeviceCardSkeleton` - Individual device selection card placeholder

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage() {
  const { data: scriptData, isLoading } = useScript(scriptId)
  
  if (isLoading) {
    return <ScheduleScriptLoader />
  }
  
  return <ScheduleScriptView script={scriptData} />
}

// Can also be used directly in Suspense boundaries
function App() {
  return (
    <Suspense fallback={<ScheduleScriptLoader />}>
      <ScheduleScriptPage />
    </Suspense>
  )
}
```

The component provides responsive skeleton layouts that match the desktop/mobile breakpoints of the actual page, including a two-column grid for script arguments, device selection cards, and all form controls with proper spacing and styling consistency using the OpenFrame design system.
