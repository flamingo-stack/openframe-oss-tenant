A comprehensive loading skeleton component that mirrors the exact layout of the Schedule Script page, providing smooth placeholder states during data fetching.

## Key Components

- **`ScheduleScriptLoader`** - Main export that renders the complete page skeleton
- **`ScriptInfoSectionSkeleton`** - Loading state for script details card (headline, description, metadata)
- **`ScriptArgumentsSkeleton`** - Skeleton for script arguments/environment variables sections  
- **`DeviceCardSkeleton`** - Individual device card placeholder with checkbox, icon, and device info

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage() {
  const { data, isLoading } = useScriptData()
  
  if (isLoading) {
    return <ScheduleScriptLoader />
  }
  
  return <ScheduleScriptView data={data} />
}

// Or as a fallback in Suspense boundaries
<Suspense fallback={<ScheduleScriptLoader />}>
  <ScheduleScriptView />
</Suspense>
```

The skeleton maintains responsive design patterns matching the actual component - mobile-first grid layouts, flexible form controls, and device cards that adapt from single column on mobile to 4 columns on desktop. All skeleton elements use consistent border radius (6px) and spacing to match the Flamingo design system.
