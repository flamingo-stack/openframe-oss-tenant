A client-side loading skeleton component that provides placeholder UI during script scheduling operations. It mirrors the exact layout and structure of the actual ScheduleScriptView component to maintain visual consistency during loading states.

## Key Components

- **`ScriptInfoSectionSkeleton`** - Skeleton for script metadata display (headline, description, shell type, platforms, category, author)
- **`ScriptArgumentsSkeleton`** - Skeleton for script parameters and environment variables sections
- **`DeviceCardSkeleton`** - Skeleton for individual device selection cards
- **`ScheduleScriptLoader`** - Main export that combines all skeleton components into a complete page loader

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage({ isLoading }: { isLoading: boolean }) {
  if (isLoading) {
    return <ScheduleScriptLoader />
  }

  return <ScheduleScriptView scriptId={scriptId} />
}

// Can also use individual skeleton components
function ScriptInfo({ script }: { script?: ScriptData }) {
  if (!script) {
    return <ScriptInfoSectionSkeleton />
  }

  return <ScriptInfoSection script={script} />
}
```

The loader implements responsive design patterns with mobile-first layouts that adapt to larger screens, matching the exact grid systems and spacing used in the actual component for seamless loading transitions.
