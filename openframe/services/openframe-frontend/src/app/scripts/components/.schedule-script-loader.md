A comprehensive loading skeleton component for the Schedule Script page that provides visual feedback while script scheduling data loads.

## Key Components

- **ScheduleScriptLoader** - Main skeleton component that renders the complete page layout
- **ScriptInfoSectionSkeleton** - Skeleton for script metadata (headline, description, shell type, platforms)
- **ScriptArgumentsSkeleton** - Skeleton for script arguments/environment variables sections
- **DeviceCardSkeleton** - Individual device selection card skeleton

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

// In your page component
export default function ScheduleScriptPage() {
  const { data, isLoading } = useScriptData()

  if (isLoading) {
    return <ScheduleScriptLoader />
  }

  return <ScheduleScriptView data={data} />
}
```

The component matches the exact layout structure of the actual ScheduleScriptView, including responsive grid layouts for device cards (1-4 columns), two-column sections for arguments/environment variables, and proper spacing for mobile and desktop viewports. It uses the OpenFrame design system's skeleton component with consistent border radius (6px) and proper semantic spacing throughout the loading interface.
