A React client-side component that provides loading skeleton states for the schedule script page, matching the exact layout and structure of the actual ScheduleScriptView.

## Key Components

- **ScheduleScriptLoader**: Main export that renders the complete skeleton layout
- **ScriptInfoSectionSkeleton**: Skeleton for script information card with metadata
- **ScriptArgumentsSkeleton**: Skeleton for script arguments and environment variables sections
- **DeviceCardSkeleton**: Individual device card skeleton with checkbox, icon, and details

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage() {
  const [isLoading, setIsLoading] = useState(true)
  
  if (isLoading) {
    return <ScheduleScriptLoader />
  }
  
  return <ScheduleScriptView />
}
```

The component creates a comprehensive loading state that mirrors the schedule script interface, including responsive layouts for mobile/desktop breakpoints. It uses skeleton placeholders for form fields, device grids, filter chips, and metadata sections to maintain visual consistency during data loading.
