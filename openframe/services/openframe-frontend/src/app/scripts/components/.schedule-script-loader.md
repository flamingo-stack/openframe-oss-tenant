A skeleton loading component that provides placeholder UI while the schedule script form data is being loaded, matching the exact layout structure of the ScheduleScriptView page.

## Key Components

- **ScheduleScriptLoader** - Main export that renders the complete skeleton layout
- **ScriptInfoSectionSkeleton** - Skeleton for script metadata card (headline, description, shell type, platforms, etc.)
- **ScriptArgumentsSkeleton** - Skeleton for script arguments and environment variables sections  
- **DeviceCardSkeleton** - Skeleton for individual device selection cards

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

export function ScheduleScriptPage() {
  const { data, isLoading } = useScheduleScriptData()
  
  if (isLoading) {
    return <ScheduleScriptLoader />
  }
  
  return <ScheduleScriptView data={data} />
}
```

The component uses responsive grid layouts and the OpenFrame Design System's Skeleton component to create placeholder elements that mirror the actual form structure, including the header section, script info card, arguments/environment variables in two columns, scheduling options, device search/filters, and a responsive device selection grid.
