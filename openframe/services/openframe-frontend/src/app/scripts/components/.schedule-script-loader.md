A React loading skeleton component that displays placeholder elements while the Schedule Script page data is being fetched, maintaining the exact visual layout of the actual page.

## Key Components

- **`ScheduleScriptLoader`** - Main skeleton component that replicates the complete Schedule Script page layout
- **`ScriptInfoSectionSkeleton`** - Skeleton for script metadata card (name, description, shell type, platforms, category, author)
- **`ScriptArgumentsSkeleton`** - Skeleton for script arguments and environment variables sections with input rows
- **`DeviceCardSkeleton`** - Skeleton for individual device selection cards with checkbox, icon, and device info

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage() {
  const { data: script, isLoading } = useScriptQuery(scriptId)
  
  if (isLoading) {
    return <ScheduleScriptLoader />
  }
  
  return <ScheduleScriptView script={script} />
}
```

The skeleton uses responsive grid layouts and matches the spacing, sizing, and visual hierarchy of the actual Schedule Script page. It includes placeholders for all major sections: header with back button and title, script info card, timeout settings, argument forms, scheduling options, device search filters, and the device selection grid. The component ensures a smooth loading experience by maintaining consistent layout dimensions across mobile and desktop breakpoints.
