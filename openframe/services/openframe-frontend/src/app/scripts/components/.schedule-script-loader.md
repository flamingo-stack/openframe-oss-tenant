A client-side React component that provides skeleton loading states for the Schedule Script page, mimicking the exact layout and structure of the actual ScheduleScriptView while content loads.

## Key Components

- **ScheduleScriptLoader** - Main export that renders the complete skeleton layout for the schedule script page
- **ScriptInfoSectionSkeleton** - Skeleton for script metadata display including headline, description, and shell/platform info
- **ScriptArgumentsSkeleton** - Loading state for script arguments and environment variables sections
- **DeviceCardSkeleton** - Individual device card placeholder with checkbox, icon, and device details

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage({ scriptId }: { scriptId: string }) {
  const { data: script, isLoading } = useScript(scriptId)
  
  if (isLoading) {
    return <ScheduleScriptLoader />
  }
  
  return <ScheduleScriptView script={script} />
}

// Individual skeleton components can also be used separately
function ScriptForm() {
  const { isLoading } = useScriptData()
  
  return (
    <div>
      {isLoading ? (
        <ScriptInfoSectionSkeleton />
      ) : (
        <ScriptInfoSection />
      )}
    </div>
  )
}
```

The skeleton components use responsive design patterns matching the actual UI, with mobile-first grid layouts that adapt to larger screens. Each skeleton maintains proper spacing and proportions to prevent layout shifts when real content loads.
