Loading screen component that provides skeleton placeholders while the script scheduling interface loads, matching the exact layout and responsive behavior of the actual Schedule Script page.

## Key Components

**Main Components:**
- `ScheduleScriptLoader` - Complete page skeleton that mirrors the full Schedule Script interface
- `ScriptInfoSectionSkeleton` - Card skeleton for script details (headline, description, metadata)
- `ScriptArgumentsSkeleton` - Form skeleton for script parameters with key/value pairs
- `DeviceCardSkeleton` - Individual device selection card placeholder

**Layout Features:**
- Responsive grid layouts (mobile-first design)
- Skeleton placeholders for search filters, date pickers, and action buttons
- Device grid with 1-4 columns based on screen size
- Two-column layouts for arguments/environment variables and search sections

## Usage Example

```typescript
'use client'

import { ScheduleScriptLoader } from './schedule-script-loader'
import { Suspense } from 'react'

function ScheduleScriptPage() {
  return (
    <Suspense fallback={<ScheduleScriptLoader />}>
      <ScheduleScriptView />
    </Suspense>
  )
}

// The loader automatically handles responsive breakpoints
// Mobile: Single column layout with stacked components
// Desktop: Multi-column grids for better space utilization
```

The component uses the OpenFrame design system's Skeleton component and CSS classes, providing smooth loading transitions that maintain the exact visual structure of the destination page across all device sizes.
