A React skeleton loader component that provides loading states for the script scheduling interface, mimicking the exact layout and structure of the actual ScheduleScriptView page.

## Key Components

- **ScheduleScriptLoader**: Main exported component that renders the complete skeleton layout
- **ScriptInfoSectionSkeleton**: Skeleton for script information card with metadata
- **ScriptArgumentsSkeleton**: Skeleton for script arguments and environment variables sections  
- **DeviceCardSkeleton**: Skeleton for individual device selection cards

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

// Use as loading state while fetching script scheduling data
function ScheduleScriptPage() {
  const [isLoading, setIsLoading] = useState(true)
  
  if (isLoading) {
    return <ScheduleScriptLoader />
  }
  
  return <ScheduleScriptView {...props} />
}

// Or with Suspense boundary
<Suspense fallback={<ScheduleScriptLoader />}>
  <ScheduleScriptView />
</Suspense>
```

The component provides responsive skeleton layouts that match the desktop/mobile breakpoints of the actual UI, including proper grid layouts, button placements, and form field arrangements. Each skeleton section uses the OpenFrame design system's Skeleton component with appropriate sizing and spacing to create a seamless loading experience.
