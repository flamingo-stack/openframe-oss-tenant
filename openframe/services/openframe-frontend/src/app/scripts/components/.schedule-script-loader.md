A React loading skeleton component that provides placeholder UI for the schedule script creation/editing interface while data loads.

## Key Components

- **`ScheduleScriptLoader`**: Main skeleton component matching the complete schedule script view layout
- **`ScriptInfoSectionSkeleton`**: Skeleton for script metadata display (title, description, shell type, platforms, category)
- **`ScriptArgumentsSkeleton`**: Skeleton for script arguments and environment variables sections
- **`DeviceCardSkeleton`**: Skeleton for individual device selection cards in the grid

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage() {
  const [isLoading, setIsLoading] = useState(true)
  
  if (isLoading) {
    return <ScheduleScriptLoader />
  }
  
  return <ScheduleScriptView />
}
```

The component provides a comprehensive loading state that mirrors the actual schedule script interface, including responsive layouts for mobile/desktop views, script configuration sections, device filtering, and a device selection grid. All skeletons use the OpenFrame design system's `Skeleton` component and follow the same styling patterns as the production interface.
