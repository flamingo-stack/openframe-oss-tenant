A React component that provides loading skeleton placeholders for the Schedule Script page, matching the exact layout and structure of the actual ScheduleScriptView component.

## Key Components

- **`ScheduleScriptLoader`** - Main export that renders the complete page skeleton
- **`ScriptInfoSectionSkeleton`** - Skeleton for script details card (headline, description, metadata)
- **`ScriptArgumentsSkeleton`** - Skeleton for script arguments and environment variables sections
- **`DeviceCardSkeleton`** - Skeleton for individual device selection cards

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

export default function ScheduleScriptPage() {
  const { data: script, isLoading } = useScript(id)
  
  if (isLoading) {
    return <ScheduleScriptLoader />
  }
  
  return <ScheduleScriptView script={script} />
}
```

The component uses responsive design patterns with mobile-first grid layouts that adapt from single columns on mobile to multi-column layouts on desktop. All skeleton elements use the `Skeleton` component from the OpenFrame UI library and follow the design system's spacing, colors, and border radius conventions.
