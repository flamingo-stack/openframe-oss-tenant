A React loading skeleton component that provides a placeholder UI matching the exact layout of the Schedule Script page while data loads.

## Key Components

- **ScheduleScriptLoader** - Main export that renders the complete page skeleton with responsive layout
- **ScriptInfoSectionSkeleton** - Skeleton for script metadata display (headline, description, shell type, platforms, category)
- **ScriptArgumentsSkeleton** - Skeleton for script arguments and environment variables sections with input rows
- **DeviceCardSkeleton** - Individual device selection card skeleton with checkbox, icon, and device info

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage() {
  const { isLoading, scriptData } = useScriptData()

  if (isLoading) {
    return <ScheduleScriptLoader />
  }

  return <ScheduleScriptView data={scriptData} />
}

// The skeleton matches the responsive layout patterns:
// - Mobile: stacked sections, 2x2 grids
// - Desktop: flex rows, multi-column layouts
// - Device grid: 1-4 columns based on screen size
```

The component uses the Skeleton component from the design system and maintains responsive breakpoints that mirror the actual ScheduleScriptView component, ensuring a smooth transition when real data loads.
