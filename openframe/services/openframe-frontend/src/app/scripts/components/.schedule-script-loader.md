A React component that provides a comprehensive loading skeleton for the Schedule Script page, matching the exact layout and structure of the actual ScheduleScriptView component.

## Key Components

- **`ScheduleScriptLoader`** - Main export that renders the complete page skeleton with all sections
- **`ScriptInfoSectionSkeleton`** - Skeleton for script information card with headline, description, and metadata row
- **`ScriptArgumentsSkeleton`** - Skeleton for script arguments section with input rows and add button
- **`DeviceCardSkeleton`** - Individual device card skeleton with checkbox, icon, and device details

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage() {
  const { isLoading, data } = useScheduleScript()
  
  if (isLoading) {
    return <ScheduleScriptLoader />
  }
  
  return <ScheduleScriptView data={data} />
}
```

The component provides responsive skeleton layouts that adapt from mobile (stacked) to desktop (multi-column) layouts, including sections for script info, timeout settings, arguments/environment variables, scheduling options, device filtering, and a device selection grid. Each skeleton element uses the OpenFrame design system's Skeleton component with proper spacing and sizing to match the real component's dimensions.
