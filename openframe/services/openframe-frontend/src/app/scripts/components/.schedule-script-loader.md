A skeleton loading component that displays placeholder content while the Schedule Script page is loading, providing users with visual feedback during data fetching.

## Key Components

- **`ScheduleScriptLoader`** - Main skeleton component that renders placeholder content for the entire Schedule Script page layout
- **`ScriptInfoSectionSkeleton`** - Skeleton for the script information card including headline, description, and metadata
- **`ScriptArgumentsSkeleton`** - Skeleton for the script arguments and environment variables sections
- **`DeviceCardSkeleton`** - Individual device card skeleton with checkbox, icon, and device details placeholders

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage() {
  const { data, isLoading } = useScheduleScriptData()
  
  if (isLoading) {
    return <ScheduleScriptLoader />
  }
  
  return <ScheduleScriptView data={data} />
}

// Or with Suspense
function App() {
  return (
    <Suspense fallback={<ScheduleScriptLoader />}>
      <ScheduleScriptPage />
    </Suspense>
  )
}
```

The component matches the exact layout structure of the actual Schedule Script page, including responsive breakpoints for mobile/desktop views, ensuring a seamless loading experience that maintains visual consistency with the final rendered content.
