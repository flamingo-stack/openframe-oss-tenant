A React component that provides skeleton loading states for the Schedule Script page, matching the exact layout and structure of the actual ScheduleScriptView component.

## Key Components

- **ScheduleScriptLoader**: Main export that renders the complete skeleton layout for the schedule script page
- **ScriptInfoSectionSkeleton**: Skeleton for the script information card (headline, description, metadata)
- **ScriptArgumentsSkeleton**: Skeleton for script arguments and environment variables sections
- **DeviceCardSkeleton**: Skeleton for individual device selection cards

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage() {
  const { data, isLoading } = useScheduleScript(scriptId)
  
  if (isLoading) {
    return <ScheduleScriptLoader />
  }
  
  return <ScheduleScriptView data={data} />
}

// Individual skeleton components can also be used separately
function ScriptInfoSection() {
  const { data, isLoading } = useScriptInfo()
  
  if (isLoading) {
    return <ScriptInfoSectionSkeleton />
  }
  
  return <ScriptInfoDisplay data={data} />
}
```

The component uses responsive design patterns with mobile-first layouts that adapt to larger screens, ensuring consistent loading states across all device sizes. Each skeleton section mirrors the spacing, sizing, and grid layouts of the actual components they represent.
