A client-side loading skeleton component that mirrors the exact layout of the Schedule Script page while content is being fetched.

## Key Components

- **`ScheduleScriptLoader`** - Main skeleton component that replicates the complete Schedule Script page layout
- **`ScriptInfoSectionSkeleton`** - Skeleton for the script information card with metadata display
- **`ScriptArgumentsSkeleton`** - Skeleton for script arguments and environment variables sections
- **`DeviceCardSkeleton`** - Individual device selection card skeleton with checkbox and device info

The component uses responsive design patterns matching the actual page, transitioning from mobile-friendly layouts to desktop multi-column grids. All skeletons use the OpenFrame design system's skeleton component and styling classes.

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage() {
  const { data: script, isLoading } = useScript(scriptId)
  
  if (isLoading) {
    return <ScheduleScriptLoader />
  }
  
  return <ScheduleScriptView script={script} />
}
```

The loader provides visual feedback during data fetching, maintaining the expected page structure while preventing layout shifts when real content loads.
