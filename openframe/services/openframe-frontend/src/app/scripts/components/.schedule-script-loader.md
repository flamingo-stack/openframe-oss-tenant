A React component that provides skeleton loading states for the Schedule Script page, including script information, arguments, device selection, and form fields.

## Key Components

- **`ScheduleScriptLoader`** - Main skeleton component matching the complete Schedule Script page layout
- **`ScriptInfoSectionSkeleton`** - Skeleton for script details card with metadata and author info
- **`ScriptArgumentsSkeleton`** - Skeleton for script parameters and environment variables sections
- **`DeviceCardSkeleton`** - Skeleton for individual device selection cards

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage() {
  const { isLoading, data } = useScriptData()
  
  if (isLoading) {
    return <ScheduleScriptLoader />
  }
  
  return <ScheduleScriptView data={data} />
}
```

The component provides responsive skeleton layouts that match the actual page structure, including:
- Header with back navigation and action button
- Script information card with shell type, platforms, and category
- Timeout configuration field
- Two-column layout for arguments and environment variables
- Device search and filtering interface
- Device grid with checkbox selection cards

All skeletons use the OpenFrame design system classes and maintain proper spacing and responsive behavior across mobile, tablet, and desktop viewports.
