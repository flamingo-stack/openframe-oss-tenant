A React component that provides skeleton loading states for the Schedule Script page, perfectly mirroring the layout and structure of the actual ScheduleScriptView component.

## Key Components

- **ScheduleScriptLoader** - Main export that renders the complete skeleton layout
- **ScriptInfoSectionSkeleton** - Skeleton for script metadata (headline, description, shell type, platforms, category, author)
- **ScriptArgumentsSkeleton** - Skeleton for script arguments and environment variables sections
- **DeviceCardSkeleton** - Skeleton for individual device selection cards

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage() {
  const { isLoading, data } = useScheduleScriptData()

  if (isLoading) {
    return <ScheduleScriptLoader />
  }

  return <ScheduleScriptView data={data} />
}
```

The component uses responsive design patterns with mobile-first approach, matching the exact grid layouts and spacing of the real component. It includes skeleton elements for the header navigation, script information card, form inputs (timeout, arguments, environment variables), scheduling options (note, date/time, repeat), device search and filtering, and the device selection grid that adapts from 1 column on mobile to 4 columns on extra-large screens.
