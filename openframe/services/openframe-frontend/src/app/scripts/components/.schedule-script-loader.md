A React component that provides skeleton loading states for the Schedule Script page, mirroring the exact layout and structure of the actual ScheduleScriptView component.

## Key Components

- **`ScheduleScriptLoader`** - Main skeleton loader component matching the complete Schedule Script page layout
- **`ScriptInfoSectionSkeleton`** - Skeleton for the script information card with headline, description, and metadata
- **`ScriptArgumentsSkeleton`** - Loading state for script arguments and environment variables sections
- **`DeviceCardSkeleton`** - Individual device card skeleton with checkbox, icon, and device details

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage() {
  const { data: scriptData, isLoading } = useScriptQuery()

  if (isLoading) {
    return <ScheduleScriptLoader />
  }

  return <ScheduleScriptView data={scriptData} />
}

// The skeleton provides responsive layouts matching the actual component:
// - Mobile: stacked layout with 2x2 grids for metadata
// - Desktop: flex row layout with proper spacing
// - Device grid adapts from 1 column (mobile) to 4 columns (xl screens)
```

The component uses OpenFrame's design system tokens (ods-card, ods-border) and includes responsive breakpoints that exactly match the production layout, ensuring a seamless loading experience.
