A React component that provides skeleton loading states for the Schedule Script page, displaying placeholder content while the actual script scheduling interface loads.

## Key Components

- **`ScheduleScriptLoader`** - Main skeleton component that mirrors the complete Schedule Script page layout
- **`ScriptInfoSectionSkeleton`** - Skeleton for script metadata display (title, description, shell type, platforms, category, author)
- **`ScriptArgumentsSkeleton`** - Skeleton for script arguments and environment variables sections with input rows
- **`DeviceCardSkeleton`** - Skeleton for individual device selection cards in the grid

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

export function ScheduleScriptPage({ isLoading }: { isLoading: boolean }) {
  if (isLoading) {
    return <ScheduleScriptLoader />
  }
  
  return (
    <div>
      {/* Actual schedule script content */}
    </div>
  )
}

// Or use with Suspense boundary
export function ScheduleScriptView() {
  return (
    <Suspense fallback={<ScheduleScriptLoader />}>
      <ScheduleScriptContent />
    </Suspense>
  )
}
```

The component uses responsive design patterns with mobile-first layouts (2x2 grids on mobile, flex rows on desktop) and includes all major sections: header with back button, script info card, timeout settings, argument/environment variable inputs, scheduling options, device filtering, and device selection grid.
