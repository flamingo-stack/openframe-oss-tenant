A React component that provides skeleton loading states for the Schedule Script page, matching the exact layout and structure of the actual ScheduleScriptView component.

## Key Components

- **`ScheduleScriptLoader`** - Main skeleton component that mirrors the complete Schedule Script page layout
- **`ScriptInfoSectionSkeleton`** - Skeleton for script information card with metadata (shell type, platforms, category, author)
- **`ScriptArgumentsSkeleton`** - Skeleton for script arguments and environment variables sections with key/value pairs
- **`DeviceCardSkeleton`** - Skeleton for individual device selection cards with checkbox, icon, and device details

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage() {
  const { data: script, isLoading } = useScript(scriptId)

  if (isLoading) {
    return <ScheduleScriptLoader />
  }

  return <ScheduleScriptView script={script} />
}
```

The component creates a comprehensive skeleton that includes:
- Header with back button and action button
- Script info card with metadata placeholders
- Timeout configuration field
- Two-column layout for arguments and environment variables
- Date/time and repeat configuration fields
- Device and organization search with filter chips
- Responsive device grid (1-4 columns based on screen size)

All skeleton elements use the `Skeleton` component from the OpenFrame UI library and maintain responsive behavior with Tailwind CSS classes to match the actual page layout exactly.
