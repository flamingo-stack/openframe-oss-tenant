A comprehensive loading skeleton component for the script scheduling interface that provides visual feedback while data is loading.

## Key Components

- **`ScheduleScriptLoader`** - Main loading skeleton that mirrors the complete schedule script page layout
- **`ScriptInfoSectionSkeleton`** - Skeleton for script metadata display (headline, description, shell type, platforms, category, and author)
- **`ScriptArgumentsSkeleton`** - Skeleton for script arguments and environment variables sections with input rows
- **`DeviceCardSkeleton`** - Individual device card skeleton with checkbox, icon, and device details

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage() {
  const { data: script, isLoading } = useScript(scriptId)
  
  if (isLoading) {
    return <ScheduleScriptLoader />
  }
  
  return <ScheduleScriptView script={script} />
}
```

The component creates a pixel-perfect loading state that matches the actual ScheduleScriptView layout, including responsive grid layouts for devices (1-4 columns), two-column argument sections, and mobile-optimized filter chip arrangements. All skeleton elements use consistent spacing and the OpenFrame design system styling with proper border radius and card backgrounds.
