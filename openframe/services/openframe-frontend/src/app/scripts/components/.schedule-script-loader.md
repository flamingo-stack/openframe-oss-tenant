A skeleton loading component that provides visual placeholders for the Schedule Script page while data is being fetched, ensuring smooth user experience during loading states.

## Key Components

- **`ScheduleScriptLoader`** - Main export that renders the complete page skeleton matching `ScheduleScriptView` layout
- **`ScriptInfoSectionSkeleton`** - Skeleton for script metadata display (headline, description, shell type, platforms, category, author)
- **`ScriptArgumentsSkeleton`** - Skeleton for script arguments and environment variables sections with input rows
- **`DeviceCardSkeleton`** - Individual device card placeholder with checkbox, icon, and device details

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage() {
  const { data: script, isLoading } = useScript(scriptId)
  
  if (isLoading) {
    return <ScheduleScriptLoader />
  }
  
  return <ScheduleScriptView script={script} />
}
```

The skeleton uses OpenFrame's design system (`ods-` classes) and matches the exact responsive layout of the actual Schedule Script page, including mobile-first grid layouts, proper spacing, and interactive elements like device selection cards. Each skeleton section mirrors the structure and visual hierarchy of its corresponding component for seamless loading transitions.
