A comprehensive loading skeleton component that mirrors the exact layout and structure of a script scheduling interface, providing visual feedback during data fetching.

## Key Components

- **ScheduleScriptLoader** - Main skeleton component that replicates the complete schedule script view layout
- **ScriptInfoSectionSkeleton** - Skeleton for script metadata display (headline, description, shell type, platforms, category, author)
- **ScriptArgumentsSkeleton** - Skeleton for script parameters and environment variables sections
- **DeviceCardSkeleton** - Skeleton for individual device selection cards in the grid

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage() {
  const { data: scriptData, isLoading } = useScriptData()
  
  if (isLoading) {
    return <ScheduleScriptLoader />
  }
  
  return <ScheduleScriptView data={scriptData} />
}

// Can also be used with Suspense boundaries
function App() {
  return (
    <Suspense fallback={<ScheduleScriptLoader />}>
      <ScheduleScriptPage />
    </Suspense>
  )
}
```

The component uses responsive design patterns with mobile-first layouts (grid transforms to flex on larger screens) and matches the exact spacing, dimensions, and visual hierarchy of the actual script scheduling interface for seamless loading states.
