A client-side React component that provides skeleton loading states for the Schedule Script interface, displaying placeholder content while the actual page loads.

## Key Components

- **`ScheduleScriptLoader`** - Main skeleton component that matches the complete layout of the Schedule Script view
- **`ScriptInfoSectionSkeleton`** - Skeleton for script information card (headline, description, metadata with avatar)
- **`ScriptArgumentsSkeleton`** - Skeleton for script arguments/environment variables sections with add functionality
- **`DeviceCardSkeleton`** - Individual device selection card skeleton with checkbox, icon, and device details

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage() {
  const { data: script, isLoading } = useScriptQuery(scriptId)
  
  if (isLoading) {
    return <ScheduleScriptLoader />
  }
  
  return <ScheduleScriptView script={script} />
}
```

The skeleton loader provides a responsive layout that adapts from single-column on mobile to multi-column grids on larger screens, including search filters, device cards, form fields, and metadata sections that mirror the actual Schedule Script interface structure.
