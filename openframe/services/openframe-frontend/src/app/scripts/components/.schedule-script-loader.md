A comprehensive skeleton loader component for the Schedule Script page that mirrors the exact layout and structure of the actual ScheduleScriptView component.

## Key Components

- **ScriptInfoSectionSkeleton** - Skeleton for script metadata display with headline, description, and property rows
- **ScriptArgumentsSkeleton** - Skeleton for script arguments/environment variables sections with key-value input pairs
- **DeviceCardSkeleton** - Skeleton for individual device selection cards with checkbox, icon, and device info
- **ScheduleScriptLoader** - Main exported component that combines all skeleton sections into the complete page layout

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage() {
  const [isLoading, setIsLoading] = useState(true)
  
  if (isLoading) {
    return <ScheduleScriptLoader />
  }
  
  return <ScheduleScriptView />
}

// Can also be used in loading states
function AsyncScheduleScript() {
  return (
    <Suspense fallback={<ScheduleScriptLoader />}>
      <ScheduleScriptView />
    </Suspense>
  )
}
```

The component provides responsive skeleton layouts matching the mobile-first design patterns, with appropriate grid layouts and spacing that automatically adapt from mobile (single column) to desktop (multi-column) layouts. Each skeleton section uses consistent OpenFrame design system classes for borders, spacing, and colors.
