A client-side React component that provides skeleton loading states for the Schedule Script page, matching the exact layout and structure of the actual ScheduleScriptView component.

## Key Components

- **`ScheduleScriptLoader`** - Main skeleton component that renders the complete loading state for the Schedule Script page
- **`ScriptInfoSectionSkeleton`** - Skeleton for the script information card with headline, description, and metadata row
- **`ScriptArgumentsSkeleton`** - Skeleton for script arguments and environment variables sections with key/value input rows
- **`DeviceCardSkeleton`** - Skeleton for individual device selection cards with checkbox, icon, and device details

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage() {
  const { isLoading } = useScheduleScriptData()
  
  if (isLoading) {
    return <ScheduleScriptLoader />
  }
  
  return <ScheduleScriptView />
}
```

The component provides comprehensive loading skeletons for all page sections including the header with back button, script information card, timeout settings, arguments/environment variables in a 2-column layout, scheduling options, device search with filter chips, and a responsive device grid. The skeletons use responsive design matching mobile-first breakpoints and maintain the same spacing and layout structure as the actual components.
