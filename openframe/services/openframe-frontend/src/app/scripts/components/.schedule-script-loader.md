A React loading skeleton component that displays placeholder content while the Schedule Script page is loading, matching the exact layout and structure of the actual ScheduleScriptView component.

## Key Components

- **`ScheduleScriptLoader`** - Main export that renders the complete skeleton layout for the schedule script page
- **`ScriptInfoSectionSkeleton`** - Skeleton for script information card with headline, description, and metadata
- **`ScriptArgumentsSkeleton`** - Skeleton for script arguments/environment variables sections with input rows
- **`DeviceCardSkeleton`** - Skeleton for individual device selection cards

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

// Show while loading schedule script data
function ScheduleScriptPage() {
  const { data, isLoading } = useScheduleScriptData()
  
  if (isLoading) {
    return <ScheduleScriptLoader />
  }
  
  return <ScheduleScriptView data={data} />
}
```

The component uses responsive design patterns with mobile-first grid layouts that adapt from single columns on mobile to multi-column layouts on larger screens. It includes skeletons for all major sections: header navigation, script info card, timeout settings, argument inputs, scheduling controls, device filtering, and the device selection grid.
