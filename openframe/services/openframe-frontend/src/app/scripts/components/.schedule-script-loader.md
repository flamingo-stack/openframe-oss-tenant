A comprehensive loading skeleton component that provides visual placeholders while the Schedule Script page loads, maintaining the exact layout structure of the actual page.

## Key Components

- **`ScheduleScriptLoader`** - Main skeleton component that mirrors the complete Schedule Script page layout
- **`ScriptInfoSectionSkeleton`** - Skeleton for script information card with metadata fields
- **`ScriptArgumentsSkeleton`** - Skeleton for script arguments/environment variables sections
- **`DeviceCardSkeleton`** - Individual device selection card skeleton

## Features

- **Responsive Design**: Adapts skeleton layout from mobile (single column) to desktop (multi-column grids)
- **Accurate Structure**: Matches exact spacing, sizing, and grid layouts of the actual components
- **Progressive Enhancement**: Shows filter chips, search fields, and device grids in appropriate screen sizes
- **Consistent Styling**: Uses OpenFrame design system with proper border radius and spacing

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage() {
  const { data, loading } = useScript()
  
  if (loading) {
    return <ScheduleScriptLoader />
  }
  
  return <ScheduleScriptView data={data} />
}
```

The skeleton includes placeholders for all major sections: header with back button, script info card, timeout settings, argument/environment variable forms, scheduling controls, device search with filters, and the device selection grid.
