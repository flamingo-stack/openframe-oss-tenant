A React loading skeleton component for the Schedule Script page that mirrors the actual layout with placeholder elements during data fetching.

## Key Components

- **`ScheduleScriptLoader`** - Main skeleton component matching the complete Schedule Script view layout
- **`ScriptInfoSectionSkeleton`** - Skeleton for script information card with headline, description, and metadata
- **`ScriptArgumentsSkeleton`** - Skeleton for script arguments/environment variables sections with input rows
- **`DeviceCardSkeleton`** - Skeleton for individual device selection cards

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage() {
  const { data, isLoading } = useScriptData()

  if (isLoading) {
    return <ScheduleScriptLoader />
  }

  return <ScheduleScriptView data={data} />
}
```

The loader provides a comprehensive skeleton that matches the Schedule Script page structure including:
- Header with back button and title
- Script info card with responsive metadata layout
- Timeout configuration
- Two-column script arguments and environment variables
- Date/time and repeat settings
- Device search with filter chips
- Responsive device selection grid (1-4 columns based on screen size)

Each skeleton element uses the Skeleton component from the UI library and maintains the same responsive breakpoints and spacing as the actual page components.
