A React skeleton component that provides loading states for the Schedule Script page, matching the exact layout and responsive behavior of the actual ScheduleScriptView component.

## Key Components

- **`ScheduleScriptLoader`** - Main skeleton component that renders loading placeholders for the entire schedule script form
- **`ScriptInfoSectionSkeleton`** - Skeleton for script metadata (name, description, platforms, category, author)
- **`ScriptArgumentsSkeleton`** - Skeleton for script arguments and environment variables sections
- **`DeviceCardSkeleton`** - Skeleton for individual device selection cards

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

export default function ScheduleScriptPage() {
  const { data: script, isLoading } = useQuery(['script', scriptId])
  
  if (isLoading) {
    return <ScheduleScriptLoader />
  }
  
  return <ScheduleScriptView script={script} />
}
```

The component uses responsive design patterns, transitioning from mobile-first layouts (stacked forms, single columns) to desktop layouts (flex rows, multi-column grids). Each skeleton element is carefully sized to match the expected content dimensions, providing smooth loading transitions that maintain layout stability.
