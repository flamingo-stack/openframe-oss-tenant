Client-side skeleton loader component that mirrors the layout structure of the Schedule Script page while data is loading.

## Key Components

- **`ScheduleScriptLoader`** - Main loader component matching the complete Schedule Script page layout
- **`ScriptInfoSectionSkeleton`** - Skeleton for script information card (title, description, metadata)
- **`ScriptArgumentsSkeleton`** - Skeleton for script arguments/environment variables sections
- **`DeviceCardSkeleton`** - Individual device selection card skeleton

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage() {
  const { data: script, isLoading } = useScript(scriptId)
  
  if (isLoading) {
    return <ScheduleScriptLoader />
  }
  
  return <ScheduleScriptView script={script} />
}

// Used in loading states or Suspense fallbacks
<Suspense fallback={<ScheduleScriptLoader />}>
  <ScheduleScriptContent />
</Suspense>
```

The loader provides responsive skeleton elements that match the exact layout structure of the actual Schedule Script page, including header actions, script info cards, form fields, device grids, and filter sections. Each skeleton component uses the OpenFrame design system's Skeleton component with proper spacing and responsive behavior.
