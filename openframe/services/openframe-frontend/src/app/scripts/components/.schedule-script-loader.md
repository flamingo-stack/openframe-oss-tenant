A comprehensive loading skeleton component for the Schedule Script page that mirrors the exact layout and structure of the actual Schedule Script interface during data loading.

## Key Components

- **`ScheduleScriptLoader`** - Main exported component providing the complete page skeleton
- **`ScriptInfoSectionSkeleton`** - Skeleton for script metadata section (title, description, shell type, platforms, category, author)
- **`ScriptArgumentsSkeleton`** - Skeleton for script arguments and environment variables input sections
- **`DeviceCardSkeleton`** - Individual device card skeleton with checkbox, icon, and device info

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage() {
  const { script, isLoading } = useScript(scriptId)
  
  if (isLoading) {
    return <ScheduleScriptLoader />
  }
  
  return <ScheduleScriptView script={script} />
}
```

The component provides pixel-perfect loading states with responsive grid layouts (1-4 columns based on screen size), matching form field dimensions, and proper spacing that seamlessly transitions to the actual content. It includes skeletons for all major sections: header navigation, script info card, timeout settings, argument inputs, scheduling controls, device/organization filters, and the device selection grid.
