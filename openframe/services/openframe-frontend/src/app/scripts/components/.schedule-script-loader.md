A comprehensive loading skeleton component that mirrors the complete layout and structure of the Schedule Script page, providing smooth visual feedback during data fetching.

## Key Components

**Main Export:**
- `ScheduleScriptLoader` - Full page skeleton matching ScheduleScriptView layout

**Internal Skeletons:**
- `ScriptInfoSectionSkeleton` - Script details card with metadata grid
- `ScriptArgumentsSkeleton` - Arguments/environment variables section with input rows
- `DeviceCardSkeleton` - Individual device selection card

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage() {
  const { data: script, isLoading } = useScriptQuery(scriptId)
  
  if (isLoading) {
    return <ScheduleScriptLoader />
  }
  
  return <ScheduleScriptView script={script} />
}

// The skeleton matches this exact layout structure:
// - Header with back button and title
// - Script info card with shell/platforms/category metadata
// - Timeout input field  
// - Arguments and environment variables in 2-column grid
// - Note, date/time, and repeat options
// - Device search with filter chips
// - Responsive device grid (1-4 columns based on screen size)
```

The component uses responsive design patterns with mobile-first grid layouts, transitioning from single column on mobile to multi-column grids on larger screens. All skeleton elements use consistent border radius and spacing to match the actual UI components.
