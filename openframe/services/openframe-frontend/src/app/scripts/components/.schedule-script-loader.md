This component provides a comprehensive loading skeleton for the Schedule Script page, maintaining pixel-perfect alignment with the actual UI during async data fetching.

## Key Components

- **ScheduleScriptLoader** - Main export that renders the complete page skeleton
- **ScriptInfoSectionSkeleton** - Skeleton for script details card with responsive metadata grid
- **ScriptArgumentsSkeleton** - Skeleton for argument input rows with add button
- **DeviceCardSkeleton** - Individual device selection card skeleton

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage() {
  const { data: script, isLoading } = useScript(scriptId)
  
  if (isLoading) {
    return <ScheduleScriptLoader />
  }
  
  return <ScheduleScriptView script={script} />
}
```

The loader matches the exact layout structure with responsive breakpoints, including the header with back button, script info card, timeout controls, argument/environment variable columns, scheduling controls, device search/filters, and device selection grid. Each skeleton element uses appropriate widths and spacing to maintain visual consistency during loading states.
