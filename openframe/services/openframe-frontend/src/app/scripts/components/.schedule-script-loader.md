A comprehensive skeleton loader component that mimics the exact layout and structure of the Schedule Script page while content is loading.

## Key Components

- **`ScheduleScriptLoader`** - Main skeleton component that replicates the full Schedule Script page layout
- **`ScriptInfoSectionSkeleton`** - Skeleton for script details card (headline, description, metadata row with avatar)
- **`ScriptArgumentsSkeleton`** - Skeleton for script arguments and environment variables sections with key/value input rows
- **`DeviceCardSkeleton`** - Skeleton for individual device selection cards with checkbox, icon and device details

## Usage Example

```typescript
import { ScheduleScriptLoader } from './schedule-script-loader'

function ScheduleScriptPage() {
  const { isLoading, script } = useScript(scriptId)

  if (isLoading) {
    return <ScheduleScriptLoader />
  }

  return <ScheduleScriptView script={script} />
}
```

The loader provides a pixel-perfect skeleton that matches the responsive layout patterns of the actual page, including:
- Mobile-first responsive grid layouts (2-column to 4-column device grid)
- Flexible form sections that adapt from single to multi-column layouts
- Proper spacing and visual hierarchy that matches the real components
- OpenFrame design system styling with `ods-card` and `ods-border` classes
