A React component that renders a data table for managing and viewing scripts with comprehensive filtering, search, and pagination capabilities.

## Key Components

- **ScriptsTable**: Main component managing script data display and interactions
- **UIScriptEntry**: Interface defining the structure of script entries in the UI
- **URL State Management**: Persistent search, filters, and pagination via `useApiParams`
- **Data Transformation**: Converts backend script data to UI-friendly format
- **Filter Options**: Dynamic generation of unique values for shell types, categories, platforms, and sources
- **Row Actions**: Edit, view details, and run script functionality

## Usage Example

```typescript
// Basic usage in a page component
import { ScriptsTable } from './scripts-table'

export default function ScriptsPage() {
  return (
    <div>
      <ScriptsTable />
    </div>
  )
}

// The table automatically handles:
// - URL-persisted search: /scripts?search=powershell
// - Multiple filters: /scripts?shellType=powershell&category=network
// - Pagination: /scripts?page=2
// - Navigation to script details/edit pages
```

The component integrates with the OpenFrame design system and provides a complete CRUD interface for script management, including debounced search, responsive column hiding, and contextual actions for each script entry.
