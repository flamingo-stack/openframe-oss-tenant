A React component that displays IT automation scripts in a filterable, paginated table with search and navigation capabilities for the OpenFrame platform.

## Key Components

- **ScriptsTable**: Main component providing comprehensive script management interface
- **UIScriptEntry**: Interface defining script data structure with platform, shell type, and metadata
- **Table Configuration**: Column definitions with responsive breakpoints and filtering options
- **URL State Management**: Search, filters, and pagination persisted in URL parameters
- **Filter Options**: Shell type, platform, category, and source filtering with dynamic option generation

## Usage Example

```typescript
import { ScriptsTable } from './scripts-table'

// Basic usage in a scripts management page
export default function ScriptsPage() {
  return (
    <div className="container mx-auto">
      <ScriptsTable />
    </div>
  )
}

// The component automatically handles:
// - URL-persisted search: /scripts?search=backup&page=2
// - Multi-filter states: /scripts?shellType=bash,powershell&category=system
// - Responsive column visibility based on screen size
// - Row actions for edit, details, and script execution
```

The component integrates with the OpenFrame design system, provides debounced search, responsive filtering, and navigation to script details, editing, and execution interfaces. All state is synchronized with URL parameters for shareable links and browser navigation support.
