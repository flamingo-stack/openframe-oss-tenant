A React component that displays automation scripts in a paginated, filterable data table with URL-based state management. It supports searching, filtering by shell type, platform, category, and provides actions for creating, editing, and running scripts.

## Key Components

- **ScriptsTable**: Main component that renders a comprehensive scripts management interface
- **UIScriptEntry**: TypeScript interface defining the structure of script entries in the table
- **useScripts**: Custom hook for fetching and managing script data
- **useApiParams**: Hook for URL-based state management of search and filters
- **Table**: Reusable table component with filtering and pagination capabilities
- **ListPageLayout**: Layout wrapper providing consistent page structure and mobile filters

## Usage Example

```typescript
import { ScriptsTable } from './scripts-table'

// Basic usage - renders complete scripts management interface
export default function ScriptsPage() {
  return (
    <div className="container mx-auto">
      <ScriptsTable />
    </div>
  )
}

// The component automatically handles:
// - URL state persistence (?search=term&shellType=bash&page=2)
// - Real-time search with 300ms debouncing
// - Multi-select filtering by shell type, platform, category
// - Pagination with 10 items per page
// - Row actions (edit, view details, run script)
```

The component provides a complete scripts management interface with client-side filtering, server-side data fetching, responsive design with mobile-optimized filters, and seamless navigation to script creation, editing, and execution workflows.
