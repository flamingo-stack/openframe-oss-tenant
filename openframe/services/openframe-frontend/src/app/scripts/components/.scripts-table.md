A React table component that displays and manages IT automation scripts with advanced filtering, search, and pagination capabilities. Built for the Flamingo MSP platform, this component provides a comprehensive interface for viewing, running, and managing scripts across different platforms and shell types.

## Key Components

- **ScriptsTable** - Main component handling script display with URL-persisted state
- **UIScriptEntry** - Interface defining the script data structure for the table
- **useScripts** - Custom hook for fetching and managing script data
- **useApiParams** - Hook for URL state management with filters and pagination
- **Table** - Reusable table component with filtering and responsive design
- **ListPageLayout** - Layout wrapper with search, actions, and mobile filtering

## Usage Example

```typescript
import { ScriptsTable } from './scripts-table'

// Basic usage - renders complete scripts management interface
function ScriptsPage() {
  return (
    <div className="container">
      <ScriptsTable />
    </div>
  )
}

// The component handles all state management internally:
// - URL-persisted search, filters, and pagination
// - Debounced search input for performance
// - Responsive column hiding based on screen size
// - Row actions for edit, view details, and run script
```

The component automatically transforms backend script data into a UI-friendly format, manages complex filtering by shell type, platform, category, and source, and provides seamless navigation to script editing and execution interfaces.
