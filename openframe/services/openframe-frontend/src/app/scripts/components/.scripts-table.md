A comprehensive table component for managing and displaying automation scripts with advanced filtering, search, and pagination capabilities.

## Key Components

- **ScriptsTable**: Main component providing script management interface
- **UIScriptEntry**: Interface defining script data structure with properties like name, shell type, supported platforms, and category
- **URL State Management**: Persistent search, filtering, and pagination parameters in URL
- **Data Transformation**: Converts backend script data to UI-friendly format
- **Advanced Filtering**: Multi-dimensional filtering by shell type, platform, category, and source
- **Responsive Design**: Adaptive column visibility and mobile-optimized filtering

## Usage Example

```typescript
import { ScriptsTable } from './scripts-table'

// Basic usage - renders complete scripts management interface
function ScriptsPage() {
  return (
    <div>
      <ScriptsTable />
    </div>
  )
}

// The component automatically handles:
// - URL-based state persistence (/scripts?search=powershell&shellType=powershell&page=2)
// - Real-time search with debouncing
// - Multi-select filtering by shell type, OS, category, and source
// - Pagination with client-side data slicing
// - Row actions (edit, view details, run script)
// - Responsive column hiding on smaller screens
```

The component integrates with the OpenFrame core design system and provides a complete script management experience with search, filtering, sorting, and navigation capabilities. It maintains all state in URL parameters for bookmarkable and shareable filtered views.
