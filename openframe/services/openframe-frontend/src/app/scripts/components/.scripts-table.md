A React component that displays a paginated, filterable table of scripts with search functionality and URL-based state management.

## Key Components

- **ScriptsTable**: Main component that renders a table of automation scripts with filtering, search, pagination, and actions
- **UIScriptEntry**: TypeScript interface defining the structure of script data displayed in the table
- **URL State Management**: Uses `useApiParams` to persist search, filters, and pagination in the URL
- **Custom Hooks**: Integrates `useScripts`, `useDebounce`, and `useTablePagination` for data management
- **Filter System**: Multi-column filtering for shell type, platform, category, and added-by fields
- **Row Actions**: Edit, view details, and run script actions for each table row

## Usage Example

```typescript
import { ScriptsTable } from './scripts-table'

// Basic usage - renders a full-featured scripts management interface
function ScriptsPage() {
  return (
    <div>
      <ScriptsTable />
    </div>
  )
}

// The component automatically handles:
// - URL params: /scripts?search=bash&shellType=bash&page=2
// - Filtering by shell type, OS, category, etc.
// - Pagination with 10 items per page
// - Debounced search (300ms delay)
// - Navigation to script details/edit/run pages
```

The component provides a complete scripts management interface with responsive design, supporting search across name/description fields, multi-select filtering, and seamless navigation to script-related pages. All state is synchronized with URL parameters for bookmarkable and shareable page states.
