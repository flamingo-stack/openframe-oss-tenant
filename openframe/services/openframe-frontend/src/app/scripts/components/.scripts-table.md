A React table component that displays and manages scripts with search, filtering, and pagination capabilities.

## Key Components

- **ScriptsTable**: Main table component with URL-based state management
- **useScripts hook**: Custom hook for fetching and managing script data
- **UIScriptEntry interface**: TypeScript interface defining script table row structure
- **Table component**: Reusable table with columns, filters, and actions
- **ListPageLayout**: Layout wrapper providing search, actions, and mobile filtering

## Usage Example

```typescript
import { ScriptsTable } from './scripts-table'

// Basic usage in a page component
export default function ScriptsPage() {
  return (
    <div>
      <ScriptsTable />
    </div>
  )
}

// The table automatically handles:
// - URL-based search parameters (?search=term)
// - Filter parameters (?shellType[]=powershell&category[]=security)
// - Pagination (?page=2)
// - Navigation to script details and editing
```

**Key Features:**
- **URL State Persistence**: All search, filter, and pagination state syncs to URL parameters
- **Debounced Search**: 300ms delay prevents excessive API calls during typing
- **Responsive Design**: Columns hide on smaller screens with mobile-optimized filtering
- **Multi-column Filtering**: Filter by shell type, platform, category, and source
- **Row Actions**: Quick access to edit, view details, and run scripts
- **Client-side Pagination**: Efficient handling of large script datasets

The component uses OpenFrame's UI system and integrates with the broader Flamingo platform's script management workflow.
