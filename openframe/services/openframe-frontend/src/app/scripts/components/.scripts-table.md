A React table component that provides a comprehensive interface for managing and viewing scripts with advanced filtering, search, and pagination capabilities.

## Key Components

- **ScriptsTable**: Main component that renders a paginated table of scripts with filtering and search
- **UIScriptEntry**: TypeScript interface defining the script data structure
- **Table Columns**: Configurable column definitions with responsive display and filtering
- **URL State Management**: Persistent search, filter, and pagination state via URL parameters
- **Row Actions**: Script-specific actions (edit, view details, run) with dropdown menu

## Usage Example

```typescript
import { ScriptsTable } from './scripts-table'

// Basic usage - renders full-featured scripts table
function ScriptsPage() {
  return (
    <div className="container">
      <ScriptsTable />
    </div>
  )
}

// The table automatically handles:
// - Search with debounced input
// - Multi-column filtering (shell type, OS, category, etc.)
// - Client-side pagination
// - Responsive column hiding
// - Row actions (edit, details, run)
// - URL state persistence
```

The component integrates with the OpenFrame UI system and uses custom hooks for API data fetching (`useScripts`) and URL parameter management (`useApiParams`). It provides a complete CRUD interface for script management with enterprise-grade features like advanced filtering, responsive design, and persistent state.
