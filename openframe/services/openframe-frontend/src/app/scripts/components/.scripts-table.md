A React component that displays a paginated, filterable table of scripts with search functionality and navigation actions.

## Key Components

- **ScriptsTable**: Main component providing script listing with URL-persisted search, filtering, and pagination
- **UIScriptEntry**: TypeScript interface defining the script data structure displayed in the table
- **Table columns**: Configurable columns for name, shell type, supported platforms, category, and description
- **URL state management**: Persists search terms, filters, and pagination state in URL parameters
- **Row actions**: Edit, view details, and run script functionality via dropdown menu and play button

## Usage Example

```typescript
import { ScriptsTable } from './scripts-table'

export function ScriptsPage() {
  return (
    <div className="container">
      <ScriptsTable />
    </div>
  )
}

// The component automatically handles:
// - URL state: /scripts?search=term&shellType=powershell&page=2
// - Filtering by shell type, category, platforms, etc.
// - Debounced search with 300ms delay
// - Client-side pagination with 10 items per page
// - Row actions for editing, viewing, and running scripts
```

The component integrates with a `useScripts` hook for data fetching and provides responsive design with mobile-friendly filtering. Search and filter state persists in the URL, allowing users to bookmark and share filtered views.
