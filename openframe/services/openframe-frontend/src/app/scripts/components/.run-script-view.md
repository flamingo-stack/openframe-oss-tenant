React component that provides an interface for running scripts on selected devices in the OpenFrame MSP platform. It allows users to search for devices, select multiple targets, and execute scripts across their infrastructure.

## Key Components

- **RunScriptView**: Main component that renders the script execution interface
- **useRunScriptData**: Custom hook for fetching script details and device data
- **Device Selection**: Grid-based device selector with search and multi-select capabilities
- **Script Execution**: Handles bulk script execution via Tactical RMM API
- **OS Normalization**: Maps device operating systems to compatible script shells

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

// Render script execution interface for a specific script
function ScriptExecutePage({ params }: { params: { id: string } }) {
  return <RunScriptView scriptId={params.id} />
}

// The component provides:
// - Script information display via ScriptInfoSection
// - Device search and filtering
// - Multi-device selection with "Select All" functionality
// - OS-aware script execution (Windows/Linux/macOS)
// - Real-time feedback via toast notifications
```

The component integrates with the Tactical RMM API to execute scripts on selected agents, automatically determining the appropriate shell (PowerShell/CMD for Windows, Bash for Unix-like systems) based on device operating systems. It includes comprehensive error handling and loading states throughout the script execution workflow.
