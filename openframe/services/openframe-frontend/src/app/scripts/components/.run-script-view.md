A React component that provides an interface for running scripts on multiple selected devices in the OpenFrame MSP platform.

## Key Components

- **RunScriptView** - Main component that renders the script execution interface
- **useRunScriptData** - Hook for fetching script details and available devices
- **Device Selection Logic** - Handles multi-device selection with search and filtering
- **Script Execution** - Manages bulk script deployment to selected agents via Tactical RMM
- **OS Detection** - Normalizes operating system types for cross-platform compatibility

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

// Used in a route to execute scripts on devices
function RunScriptPage({ params }: { params: { id: string } }) {
  return <RunScriptView scriptId={params.id} />
}

// Component handles:
// - Loading script details and device list
// - Device search and selection
// - OS-specific shell detection
// - Bulk script execution via Tactical RMM API
```

The component features debounced device search, multi-select functionality, OS-aware script execution, and comprehensive error handling. It integrates with the Tactical RMM backend to execute scripts across selected agents while providing real-time feedback through toast notifications.
