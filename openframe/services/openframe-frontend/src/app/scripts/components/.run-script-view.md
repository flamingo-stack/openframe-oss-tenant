A React component that provides an interface for running scripts on selected devices within the OpenFrame MSP platform. It combines script details display with device selection and execution capabilities.

## Key Components

- **RunScriptView** - Main component that orchestrates script execution workflow
- **useRunScriptData** - Custom hook for fetching script details and searchable devices
- **ScriptInfoSection** - Displays script metadata and configuration
- **SelectableDeviceCard** - Individual device selection interface
- **Device Selection Logic** - Handles multi-device selection with search and filtering
- **Script Execution Handler** - Processes bulk script deployment via Tactical RMM integration

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

// Used in script management pages
function ScriptExecutionPage({ params }: { params: { id: string } }) {
  return <RunScriptView scriptId={params.id} />
}

// The component handles:
// - Loading script details and compatible devices
// - Device search with 300ms debounced input
// - Multi-device selection with bulk operations
// - OS-specific shell determination (Windows/Linux/macOS)
// - Tactical RMM agent integration for script deployment
```

The component features responsive device grid layout, real-time search, selection management (select all/clear), and comprehensive error handling for both script loading and execution phases. It automatically determines appropriate shell environments based on device operating systems and validates agent compatibility before execution.
