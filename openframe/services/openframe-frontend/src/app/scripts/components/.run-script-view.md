A React component that provides a UI for running scripts on selected devices with search, filtering, and bulk execution capabilities.

## Key Components

- **RunScriptView**: Main component that renders the script execution interface
- **useRunScriptData**: Custom hook for fetching script details and device data
- **Device Selection Logic**: Manages multi-device selection with search and filtering
- **Script Execution**: Handles bulk script execution via Tactical RMM API
- **OS Normalization**: Converts various OS formats to standardized types (windows, linux, darwin)

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

// Use within a page component
function ScriptExecutionPage({ params }: { params: { scriptId: string } }) {
  return <RunScriptView scriptId={params.scriptId} />
}

// The component provides:
// - Script information display
// - Device search and selection
// - Bulk script execution on selected devices
// - Error handling and loading states
```

The component integrates with the Tactical RMM API for script execution, supports debounced search for device filtering, and provides a responsive grid layout for device cards. It includes comprehensive error handling, loading states, and toast notifications for user feedback during script execution operations.
