A client-side React component that provides an interface for running scripts on selected devices through the Tactical RMM system within the OpenFrame MSP platform.

## Key Components

- **RunScriptView**: Main component that orchestrates script execution workflow
- **useRunScriptData**: Custom hook for fetching script details and device data
- **ScriptInfoSection**: Displays script metadata and configuration
- **SelectableDeviceCard**: Device selection interface with multi-select capability
- **tacticalApiClient**: API client for executing bulk script actions

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

// Render the script execution interface for a specific script
function ScriptsPage() {
  return (
    <RunScriptView scriptId="123" />
  )
}

// The component handles:
// - Loading script details and compatible devices
// - Device search and filtering with 300ms debounce
// - Multi-device selection with bulk operations
// - OS-specific shell selection (PowerShell/CMD for Windows, bash for Unix)
// - Tactical RMM agent validation and script execution
```

The component features a responsive design with device grid layout, real-time search functionality, and comprehensive error handling. It automatically determines the appropriate shell environment based on selected device operating systems and validates that devices have compatible Tactical RMM agents before script execution.
