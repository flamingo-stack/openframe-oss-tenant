React component for running scripts on selected devices within the OpenFrame MSP platform. Provides device search, selection interface, and script execution capabilities with OS-aware shell handling.

## Key Components

**RunScriptView** - Main component that renders the script execution interface
- `scriptId` prop for identifying the target script
- Device search and filtering functionality
- Multi-device selection with batch operations
- Script execution with OS-specific shell configuration

**Key Features:**
- Debounced device search (300ms delay)
- Device selection state management with Set-based tracking
- OS normalization for cross-platform script execution
- Tactical RMM integration for remote script execution
- Toast notifications for user feedback

**Custom Hooks:**
- `useRunScriptData` - Manages script details and device data
- `useDebounce` - Optimizes search performance
- `useToast` - User notification system

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

// Render script execution interface for a specific script
function ScriptExecutionPage({ params }: { params: { scriptId: string } }) {
  return <RunScriptView scriptId={params.scriptId} />
}

// The component handles:
// - Loading script details and compatible devices
// - Device search and selection
// - OS-aware script execution via Tactical RMM
// - Navigation back to script details
```

The component integrates with the Tactical RMM API for remote script execution, automatically handles OS detection (Windows, macOS, Linux), and provides a responsive device selection grid with search capabilities.
