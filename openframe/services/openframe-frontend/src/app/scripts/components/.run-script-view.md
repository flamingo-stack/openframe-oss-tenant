React component for executing scripts across multiple devices with device selection interface and Tactical RMM integration.

## Key Components

- **`RunScriptView`** - Main component for script execution interface
- **Device Search & Selection** - Search bar with debounced filtering and multi-select functionality
- **Script Execution Logic** - Handles bulk script execution via Tactical RMM API
- **Device Cards Grid** - Responsive layout for device selection with type and OS display
- **OS Normalization** - Converts various OS strings to standardized format for shell selection
