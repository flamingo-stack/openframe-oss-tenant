A React component that provides a comprehensive interface for running scripts on selected devices through the Tactical RMM integration, featuring device search, multi-selection, and bulk script execution capabilities.

## Key Components

- **RunScriptView**: Main component that orchestrates script execution workflow
- **useRunScriptData**: Custom hook for fetching script details and device data
- **Device Selection Logic**: Multi-select functionality with search and filtering
- **Script Execution**: Handles bulk script submission to Tactical RMM agents
- **OS Normalization**: Maps various OS formats to standardized types (windows/linux/darwin)

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

// Used in script execution page
function ScriptExecutionPage({ params }: { params: { scriptId: string } }) {
  return <RunScriptView scriptId={params.scriptId} />
}

// Component handles:
// - Loading script details and compatible devices
// - Device search with debounced input (300ms)
// - Multi-device selection with visual feedback
// - OS-aware script execution via Tactical RMM API
// - Error handling and success notifications
```

The component integrates with the OpenFrame ecosystem, using shared UI components, hooks, and the Tactical API client for seamless script deployment across managed devices. It includes comprehensive error handling, loading states, and accessibility features through the DetailPageContainer layout.
