React component that provides an interface for running scripts on selected devices within the Flamingo MSP platform. It handles script execution across multiple devices with proper error handling and user feedback.

## Key Components

- **RunScriptView** - Main component that renders the script execution interface
- **useRunScriptData** - Custom hook for fetching script details and devices
- **Device Selection Logic** - Handles multi-device selection with search and filtering
- **Script Execution Handler** - Processes bulk script execution via Tactical RMM API
- **OS Normalization** - Converts device operating systems to standardized formats

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

function ScriptExecutionPage({ params }: { params: { scriptId: string } }) {
  return (
    <div>
      <RunScriptView scriptId={params.scriptId} />
    </div>
  )
}

// The component handles:
// - Loading script details and available devices
// - Searching and filtering devices with debounced input
// - Multi-select device functionality
// - Validating agent compatibility before execution
// - Submitting bulk script actions to Tactical RMM
// - Providing user feedback via toast notifications
```

The component integrates with the OpenFrame frontend core components and uses the Tactical API client for script execution, providing a complete workflow from device selection to script deployment across the MSP infrastructure.
