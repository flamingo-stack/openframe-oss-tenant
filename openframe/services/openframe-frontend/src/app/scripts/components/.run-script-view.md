A React component that provides an interface for running scripts on selected devices, featuring device search, selection management, and script execution through the Tactical RMM integration.

## Key Components

- **RunScriptView**: Main component that orchestrates script execution workflow
- **useRunScriptData**: Custom hook for fetching script details and device data
- **Device Selection Logic**: Multi-select functionality with search and filtering
- **Script Execution**: Handles bulk script deployment via Tactical RMM API
- **OS Detection**: Automatically determines appropriate shell based on device OS

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

// Used in a Next.js page or route
export default function RunScriptPage({ params }: { params: { scriptId: string } }) {
  return <RunScriptView scriptId={params.scriptId} />
}

// The component handles:
// - Loading script details and available devices
// - Device search and multi-selection
// - OS-specific shell selection (Windows: cmd/powershell, Unix: bash)
// - Bulk script execution via Tactical RMM API
```

The component provides a complete workflow from script selection through device targeting to execution, with proper error handling, loading states, and user feedback through toast notifications. It integrates with the OpenFrame design system and supports responsive layouts across different screen sizes.
