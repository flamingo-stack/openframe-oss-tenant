Client-side React component that provides a user interface for running scripts on selected devices through the Tactical RMM integration.

## Key Components

- **RunScriptView** - Main component that manages script execution workflow
- **useRunScriptData** - Custom hook for fetching script details and device data
- **Device Selection** - Multi-select interface with search functionality for target devices
- **Script Execution** - Handles bulk action submission to Tactical RMM API

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

// Used in a Next.js page component
export default function RunScriptPage({ params }: { params: { scriptId: string } }) {
  return <RunScriptView scriptId={params.scriptId} />
}
```

The component provides a complete workflow for:
- Displaying script information and parameters
- Searching and filtering available devices
- Multi-selecting target devices with visual feedback
- Executing scripts via Tactical RMM bulk actions
- Handling OS-specific shell selection (PowerShell, CMD, Bash)
- Toast notifications for success/error states

Features device compatibility validation, debounced search, and responsive grid layouts for device cards.
