A React component that provides a user interface for running scripts on selected devices within the Flamingo/OpenFrame platform. The component allows users to search for devices, select multiple targets, and execute scripts with appropriate platform-specific configurations.

## Key Components

- **RunScriptView**: Main component that renders the script execution interface
- **useRunScriptData**: Custom hook for fetching script details and device data
- **Device Selection Logic**: Handles multi-device selection with search functionality
- **Script Execution Handler**: Manages the API call to run scripts on selected devices with OS-specific shell configuration
- **UI Components**: Utilizes SelectableDeviceCard, SearchBar, and DetailPageContainer for the interface

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

// Render the script execution interface
function ScriptExecutionPage({ params }: { params: { id: string } }) {
  return <RunScriptView scriptId={params.id} />
}

// The component handles:
// - Loading script details and available devices
// - Device search with debounced input
// - Multi-device selection with toggle functionality
// - OS-specific script execution (Windows/Linux/macOS)
// - Error handling and user feedback via toast notifications

export default ScriptExecutionPage
```

The component integrates with the Tactical RMM API to execute scripts across multiple devices, automatically determining the appropriate shell (PowerShell/CMD for Windows, bash for Unix-like systems) and handling bulk operations with proper error handling and user feedback.
