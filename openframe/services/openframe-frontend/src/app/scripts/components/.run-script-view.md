A React component that provides an interface for executing scripts on selected devices through the Tactical RMM integration. It displays script information and allows users to search, select, and run scripts across multiple managed devices.

## Key Components

- **RunScriptView** - Main component that orchestrates the script execution workflow
- **useRunScriptData** - Custom hook for fetching script details and device data
- **ScriptInfoSection** - Displays script metadata and configuration
- **SelectableDeviceCard** - Renders selectable device cards with OS information
- **handleRunScript** - Core function that submits script execution to selected devices via Tactical RMM API

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

export default function RunScriptPage({ params }: { params: { scriptId: string } }) {
  return <RunScriptView scriptId={params.scriptId} />
}
```

The component handles device filtering with debounced search, batch device selection, OS-specific shell detection (Windows/Linux/macOS), and provides real-time feedback through toast notifications. It integrates with the Tactical RMM API to execute scripts across selected agents and validates device compatibility before submission.
