A React component for running automation scripts on selected devices within the OpenFrame MSP platform, providing device search, selection, and script execution capabilities.

## Key Components

- **`RunScriptView`** - Main component for script execution interface
- **Device Search & Selection** - Debounced search with multi-device selection
- **Script Execution Handler** - Tactical RMM API integration for bulk script deployment
- **OS Compatibility Logic** - Automatic shell detection based on device operating systems

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

// Render the script execution interface
function ScriptExecutionPage({ params }: { params: { scriptId: string } }) {
  return <RunScriptView scriptId={params.scriptId} />
}

// The component handles:
// - Loading script details and compatible devices
// - Device search with 300ms debounce
// - Multi-device selection with toggle/select-all functionality
// - Script execution via Tactical RMM bulk actions
// - OS-specific shell selection (PowerShell/CMD for Windows, bash for Linux/macOS)
```

The component integrates with the Tactical RMM API to execute scripts across multiple devices, automatically handling OS compatibility and providing real-time feedback through toast notifications. Device selection is managed through a grid layout with search and filtering capabilities.
