A React component that provides an interface for running scripts on selected devices within the OpenFrame MSP platform. It allows users to search for devices, select targets, and execute scripts with proper error handling and user feedback.

## Key Components

- **RunScriptView**: Main component that orchestrates the script execution workflow
- **useRunScriptData**: Custom hook for fetching script details and device data
- **Device Selection Logic**: Handles multi-device selection with search functionality
- **Script Execution**: Manages the bulk script execution via Tactical RMM API
- **OS Normalization**: Automatically detects and normalizes operating system types for cross-platform script execution

## Usage Example

```typescript
// Render the script execution interface
<RunScriptView scriptId="12345" />

// The component handles:
// - Loading script details and compatible devices
// - Device search and selection
// - OS-specific shell determination
// - Bulk script execution via tacticalApiClient
// - User feedback through toast notifications

// Key interactions:
// - Search devices with debounced input
// - Select/deselect individual devices or all displayed
// - Execute script on selected devices with proper payload formatting
// - Navigate back to script details page
```

The component integrates with the Tactical RMM API to execute scripts across multiple agents, automatically handling OS-specific shell selection (PowerShell/CMD for Windows, Bash for Unix-like systems) and providing comprehensive error handling throughout the execution pipeline.
