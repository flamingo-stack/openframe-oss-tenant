A React component that provides an interface for running scripts on selected devices within the OpenFrame platform. This view allows users to search for devices, select multiple targets, and execute scripts with appropriate configuration based on device operating systems.

## Key Components

- **RunScriptView** - Main component that renders the script execution interface
- **useRunScriptData** - Custom hook for fetching script details and device data
- **Device Selection Logic** - Handles multi-device selection with search functionality
- **OS Detection** - Automatically determines shell type based on device operating system
- **Script Execution** - Submits bulk actions to Tactical RMM agents

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

// Render script execution interface
function ScriptExecutionPage({ params }: { params: { scriptId: string } }) {
  return <RunScriptView scriptId={params.scriptId} />
}

// Component handles the complete workflow:
// 1. Loads script details and available devices
// 2. Provides search and selection interface
// 3. Configures execution parameters based on target OS
// 4. Submits script to selected agents via Tactical API
```

The component includes comprehensive error handling, loading states, and toast notifications for user feedback. It automatically adapts shell configuration (PowerShell/CMD for Windows, Bash for Linux/macOS) and validates agent compatibility before execution.
