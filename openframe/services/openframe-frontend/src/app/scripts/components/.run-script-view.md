A React component that provides a user interface for running scripts against multiple selected devices with search and device management capabilities.

## Key Components

- **RunScriptView**: Main component that renders the script execution interface
- **useRunScriptData**: Custom hook for fetching script details and device data
- **Device Selection**: Multi-select interface with search functionality for targeting devices
- **Script Execution**: Handles bulk script execution via Tactical RMM API
- **ScriptInfoSection**: Displays script metadata and configuration

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

function ScriptExecutionPage({ params }: { params: { id: string } }) {
  return <RunScriptView scriptId={params.id} />
}

// The component handles:
// - Loading script details and available devices
// - Device search with debounced input
// - Multi-device selection with bulk operations
// - Script execution with proper OS-specific shell selection
// - Error handling and user feedback via toast notifications
```

The component integrates with the Tactical RMM API to execute scripts across selected devices, automatically determining the appropriate shell type (PowerShell, CMD, or Bash) based on device operating systems. It provides a responsive grid layout for device selection and includes loading states, error handling, and success feedback.
