A React component that provides an interface for selecting devices and running scripts against them in the OpenFrame MSP platform.

## Key Components

- **RunScriptView** - Main component that renders the script execution interface with device selection
- **Device Selection Logic** - Handles multi-select functionality with search, filtering, and bulk operations
- **Script Execution** - Manages the API calls to run scripts on selected Tactical RMM agents
- **OS Compatibility** - Normalizes operating systems and selects appropriate shell environments

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

// Render script execution page for a specific script
function ScriptRunPage({ params }: { params: { scriptId: string } }) {
  return <RunScriptView scriptId={params.scriptId} />
}

// The component handles:
// - Loading script details and available devices
// - Device search and selection with debounced input
// - OS-aware script execution (Windows/Linux/macOS)
// - Bulk script submission to Tactical RMM agents
```

The component integrates with the Tactical RMM API to execute scripts across selected devices, automatically handling OS-specific shell selection and agent ID mapping. It provides a comprehensive UI for script management including search, multi-select, and execution feedback through toast notifications.
