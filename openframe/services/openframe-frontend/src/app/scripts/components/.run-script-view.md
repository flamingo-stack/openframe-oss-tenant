A React component that provides a user interface for running scripts on selected devices within the Tactical RMM system. It combines script details display with device selection and bulk script execution capabilities.

## Key Components

- **RunScriptView** - Main component that manages the script execution workflow
- **ScriptInfoSection** - Displays script details and configuration
- **SelectableDeviceCard** - Renders individual devices with selection capability
- **Search and filtering** - Device search with debounced input
- **Bulk actions** - Multi-device script execution with OS-specific shell detection

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

function ScriptRunPage({ params }: { params: { scriptId: string } }) {
  return (
    <RunScriptView scriptId={params.scriptId} />
  )
}

// The component handles:
// - Loading script details via useRunScriptData hook
// - Device search and selection state management
// - OS detection and shell selection (Windows/PowerShell/CMD vs Linux/Darwin/Bash)
// - Bulk script execution via tacticalApiClient.runBulkAction()
// - Error handling and user feedback via toast notifications
```

The component provides a complete workflow from script selection to execution, with real-time device filtering, multi-selection capabilities, and appropriate error handling for production use.
