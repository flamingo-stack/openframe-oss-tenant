A React component that provides an interface for running scripts on selected devices in the Flamingo OpenFrame platform. It allows users to search, select multiple devices, and execute scripts with proper error handling and progress feedback.

## Key Components

- **RunScriptView**: Main component that orchestrates the script execution workflow
- **useRunScriptData**: Custom hook for fetching script details and device data
- **Device Selection Logic**: Multi-select functionality with search and filtering
- **Script Execution Handler**: Processes bulk script execution via Tactical RMM API
- **OS Normalization**: Maps various OS formats to standard types (windows, linux, darwin)

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

// Used in script execution pages
function ScriptExecutionPage({ params }: { params: { scriptId: string } }) {
  return <RunScriptView scriptId={params.scriptId} />
}

// The component handles the full workflow:
// 1. Loads script details and available devices
// 2. Provides search functionality for device filtering  
// 3. Allows multi-select of target devices
// 4. Executes script on selected devices via Tactical API
// 5. Shows success/error feedback via toast notifications

export default ScriptExecutionPage
```

The component integrates with the Tactical RMM backend to execute scripts across multiple devices, with proper OS detection and shell selection based on the target platform. It includes comprehensive error handling and user feedback mechanisms.
