A React component that provides an interface for running scripts on multiple selected devices through the Tactical RMM API.

## Key Components

- **RunScriptView** - Main component that renders the script execution interface
- **useRunScriptData** - Custom hook for fetching script details and device data
- **Device Selection System** - Multi-select functionality with search and filtering
- **Script Execution Logic** - Handles bulk script submission to Tactical RMM agents

## Usage Example

```typescript
// Used in Next.js pages to run scripts on devices
import { RunScriptView } from './run-script-view'

export default function RunScriptPage({ params }: { params: { scriptId: string } }) {
  return <RunScriptView scriptId={params.scriptId} />
}

// The component provides:
// - Script information display
// - Device search and selection
// - Bulk script execution with proper OS detection
// - Toast notifications for success/error states
```

The component features a two-column layout with script details and device selection, supports cross-platform script execution (Windows/Linux/macOS), and includes proper error handling for failed script submissions. It integrates with the Tactical RMM API to execute scripts on selected agents and provides real-time feedback through toast notifications.
