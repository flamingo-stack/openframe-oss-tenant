A React component that provides an interface for running scripts on selected devices in the OpenFrame platform. It combines script information display with device selection and management capabilities for bulk script execution.

## Key Components

- **RunScriptView**: Main component that renders the script execution interface
- **useRunScriptData**: Custom hook for managing script and device data
- **Device Selection Logic**: Handles multi-device selection with search and filtering
- **Script Execution Handler**: Processes bulk script runs via Tactical RMM API
- **OS Normalization**: Converts various OS formats to standardized types (windows, linux, darwin)

## Usage Example

```typescript
// Used in script detail pages for execution
<RunScriptView scriptId="script-123" />

// The component handles:
// - Loading script details and available devices
// - Providing search/filter functionality for devices
// - Managing device selection state
// - Executing scripts on selected devices via API
// - Showing success/error feedback to users
```

The component integrates with the Tactical RMM API to execute scripts across multiple devices, automatically determining the appropriate shell type based on the target operating systems. It includes comprehensive error handling and user feedback through toast notifications.
