A React component that provides an interface for running scripts on selected devices, combining script details with device selection and execution capabilities.

## Key Components

- **RunScriptView** - Main component that renders the script execution interface
- **useRunScriptData** - Custom hook for managing script and device data
- **Device Selection Logic** - Handles multi-device selection with search functionality
- **Script Execution** - Manages bulk script execution via Tactical RMM API
- **OS Normalization** - Converts various OS formats to standardized types for script compatibility

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

// Used in a Next.js page to run a script on multiple devices
export default function RunScriptPage({ params }: { params: { scriptId: string } }) {
  return <RunScriptView scriptId={params.scriptId} />
}

// The component provides:
// - Script information display
// - Device search and filtering
// - Multi-device selection
// - Bulk script execution with OS-specific shell handling
```

The component integrates with the Tactical RMM API to execute scripts across multiple agents, automatically handling OS detection and shell selection (PowerShell/CMD for Windows, bash for Linux/macOS). It provides real-time feedback through toast notifications and maintains selection state throughout the user interaction.
