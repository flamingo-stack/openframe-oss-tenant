A React client component that provides an interface for running scripts on selected devices within the OpenFrame platform. It combines script information display with device selection and bulk script execution capabilities.

## Key Components

- **RunScriptView** - Main component that renders the script execution interface
- **useRunScriptData** - Custom hook for managing script and device data fetching
- **Device Selection Logic** - Multi-select functionality with search and filtering
- **Script Execution Handler** - Bulk action API integration for running scripts on multiple agents
- **OS Normalization** - Cross-platform operating system detection and shell selection

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

// Render the script execution interface
function ScriptRunPage({ params }: { params: { scriptId: string } }) {
  return <RunScriptView scriptId={params.scriptId} />
}

// The component handles:
// - Loading script details and compatible devices
// - Device search with debounced input
// - Multi-device selection with toggle/select all/clear
// - Cross-platform script execution via Tactical RMM API
```

The component automatically handles OS detection to select appropriate shells (PowerShell/CMD for Windows, bash for Unix-like systems) and validates device compatibility before script submission. It provides real-time feedback through toast notifications and includes comprehensive error handling for both data loading and script execution failures.
