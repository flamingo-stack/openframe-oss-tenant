React component for managing script execution across multiple devices through a user-friendly interface with device selection and search capabilities.

## Key Components

- **RunScriptView**: Main component that renders the script execution interface
- **useRunScriptData**: Custom hook for fetching script details and device data
- **Device Selection**: Interactive device cards with multi-select functionality
- **Script Execution**: Handles running scripts on selected devices via Tactical RMM API
- **Search & Filtering**: Real-time device search with debounced input

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

// Used in a route page component
export default function RunScriptPage({ 
  params 
}: { 
  params: { scriptId: string } 
}) {
  return <RunScriptView scriptId={params.scriptId} />
}

// The component handles:
// - Loading script details and compatible devices
// - Multi-device selection with search/filter
// - OS-specific script execution via Tactical RMM
// - Error handling and loading states
```

The component integrates with the Tactical RMM API to execute scripts across selected devices, automatically handling OS-specific shell requirements and providing real-time feedback through toast notifications. It includes comprehensive error handling for network failures and validation of device compatibility.
