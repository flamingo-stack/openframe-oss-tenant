A React component that provides an interface for running scripts on selected devices within the OpenFrame MSP platform, featuring device search, selection, and batch script execution capabilities.

## Key Components

- **RunScriptView** - Main component that manages script execution workflow
- **useRunScriptData** - Custom hook for fetching script details and device data
- **Device Selection System** - Multi-select interface with search and filtering
- **Script Execution Logic** - Handles OS detection and Tactical RMM integration
- **SelectableDeviceCard** - Individual device selection cards with OS information

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

// Used in a page component to run scripts on devices
function ScriptRunPage({ params }: { params: { id: string } }) {
  return <RunScriptView scriptId={params.id} />
}

// The component handles:
// - Loading script details and compatible devices
// - Device search with debounced input
// - Multi-device selection with toggle functionality
// - OS-specific script execution via Tactical RMM API
// - Error handling and user feedback via toast notifications
```

The component integrates with the Tactical RMM backend to execute scripts across multiple devices simultaneously, with intelligent OS detection to ensure proper shell selection (PowerShell/CMD for Windows, bash for Linux/macOS). It provides a comprehensive device selection interface with search capabilities and real-time feedback on script execution status.
