A React component for executing scripts across multiple devices in the OpenFrame platform. It provides device selection, search functionality, and bulk script execution capabilities with real-time feedback.

## Key Components

- **RunScriptView**: Main component that orchestrates script execution flow
- **useRunScriptData**: Custom hook for fetching script details and devices
- **Device Selection Logic**: Handles multi-device selection with search and filtering
- **Script Execution**: Manages bulk script deployment to Tactical RMM agents
- **OS Normalization**: Converts various OS formats to standardized types

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

function ScriptRunPage({ params }: { params: { scriptId: string } }) {
  return (
    <div className="container">
      <RunScriptView scriptId={params.scriptId} />
    </div>
  )
}

// The component handles:
// - Loading script details and available devices
// - Debounced search across device inventory  
// - Multi-select device management with visual feedback
// - OS-aware script execution (Windows/Linux/macOS)
// - Error handling and success notifications
```

The component integrates with the Tactical RMM API to execute scripts on selected agents, automatically determining appropriate shell environments based on device operating systems. It includes comprehensive error handling and user feedback through toast notifications.
