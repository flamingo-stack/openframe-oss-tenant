A React component for running scripts on multiple selected devices through the OpenFrame MSP platform interface.

## Key Components

- **RunScriptView**: Main component that provides device selection and script execution functionality
- **Script Info Display**: Shows script details and configuration before execution
- **Device Selection**: Search and multi-select interface for target devices
- **Bulk Action Execution**: Submits scripts to selected devices via Tactical RMM integration

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

// Render the script execution interface
function ScriptPage({ params }: { params: { scriptId: string } }) {
  return <RunScriptView scriptId={params.scriptId} />
}

// The component handles:
// - Loading script details and available devices
// - Device search with debounced input
// - Multi-device selection with toggle/select all
// - Script execution with proper OS detection and payload formatting
// - Toast notifications for success/error states
```

The component integrates with the Tactical RMM API to execute scripts across multiple devices, handling OS-specific shell selection (PowerShell/CMD for Windows, bash for Linux/macOS) and providing a responsive interface for device management. It includes comprehensive error handling, loading states, and user feedback through toast notifications.
