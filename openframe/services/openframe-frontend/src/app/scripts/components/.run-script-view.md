A React component for running scripts on selected devices, providing device search, selection, and bulk script execution capabilities.

## Key Components

**Main Component:**
- `RunScriptView` - Main component that handles script execution workflow with device selection

**Core Features:**
- Device search with debounced input (300ms delay)
- Multi-device selection with select all/clear functionality
- Script execution via Tactical RMM API integration
- OS-aware shell selection (PowerShell/CMD for Windows, Bash for Linux/macOS)
- Loading states and error handling throughout

**Key Hooks:**
- `useRunScriptData` - Custom hook for fetching script details and devices
- `useDebounce` - Debounces search input to prevent excessive API calls
- `useToast` - Provides user feedback for success/error states

## Usage Example

```typescript
// Used in Next.js page or component
import { RunScriptView } from './run-script-view'

function ScriptRunPage({ params }: { params: { scriptId: string } }) {
  return <RunScriptView scriptId={params.scriptId} />
}

// The component handles:
// 1. Loading script details and available devices
// 2. Providing search functionality for device filtering
// 3. Managing device selection state
// 4. Executing scripts on selected devices via Tactical RMM
// 5. Showing appropriate feedback and error states
```

The component integrates with the OpenFrame frontend core library and uses Tactical RMM for remote script execution across multiple devices simultaneously.
