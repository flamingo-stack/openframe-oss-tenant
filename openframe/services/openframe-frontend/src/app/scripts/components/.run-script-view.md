React component for executing scripts across multiple devices in the Flamingo OpenFrame platform. Provides device selection, search functionality, and batch script execution capabilities.

## Key Components

- **RunScriptView** - Main component handling script execution workflow
- **useRunScriptData** - Custom hook for fetching script details and devices
- **ScriptInfoSection** - Displays script metadata and configuration
- **SelectableDeviceCard** - Individual device selection component
- **Device Selection Logic** - Handles multi-device selection with search/filter
- **Script Execution** - Manages bulk script deployment via Tactical RMM

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

// Basic usage - displays script execution interface
function ScriptExecutionPage() {
  return (
    <RunScriptView scriptId="script-123" />
  )
}

// The component automatically handles:
// - Loading script details and compatible devices
// - Device search and selection
// - OS compatibility checking
// - Bulk script execution via Tactical RMM API
```

The component features device search, multi-selection capabilities, OS-specific script handling (Windows/Linux/macOS), and integrates with the Tactical RMM API for remote script execution. It includes comprehensive error handling and user feedback through toast notifications.
