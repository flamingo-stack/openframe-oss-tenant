A React component that provides a complete interface for running scripts on selected devices in the OpenFrame platform. This component handles script execution workflows by allowing users to search, select multiple devices, and execute scripts across them with proper error handling and user feedback.

## Key Components

- **RunScriptView** - Main component that orchestrates the script execution workflow
- **useRunScriptData** - Custom hook for fetching script details and device data
- **ScriptInfoSection** - Component displaying script metadata and configuration
- **SelectableDeviceCard** - Device selection cards with multi-select functionality
- **Bulk Action API** - Integration with Tactical RMM for script execution

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

// Used in a Next.js page for script execution
export default function RunScriptPage({ params }: { params: { id: string } }) {
  return <RunScriptView scriptId={params.id} />
}
```

The component features debounced device search, multi-device selection with "select all" functionality, OS-specific shell determination, and comprehensive error handling. It integrates with the Tactical RMM API to execute scripts on selected agents and provides toast notifications for execution status. The interface includes proper loading states and fallback UI for various error conditions.
