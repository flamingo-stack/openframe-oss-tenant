A React component that provides an interface for executing scripts on selected devices within the OpenFrame platform, featuring device search, selection, and bulk script execution capabilities.

## Key Components

- **RunScriptView** - Main component that renders the script execution interface
- **useRunScriptData** - Custom hook for managing script details and device data
- **ScriptInfoSection** - Displays script metadata and configuration
- **SelectableDeviceCard** - Individual device selection cards with OS information
- **tacticalApiClient** - API client for executing bulk actions on devices

## Features

- **Device Search & Selection**: Debounced search with multi-select device cards
- **OS Compatibility**: Automatically determines shell type based on device OS (Windows/Linux/macOS)
- **Bulk Execution**: Submits scripts to multiple selected devices via Tactical RMM integration
- **Error Handling**: Comprehensive error states for script loading and device operations
- **Selection Management**: Select all, clear selection, and individual device toggling

## Usage Example

```typescript
// Use within a Next.js page or component
import { RunScriptView } from './run-script-view'

export default function RunScriptPage({ params }: { params: { id: string } }) {
  return <RunScriptView scriptId={params.id} />
}

// The component handles all script execution logic internally
// including device filtering, OS detection, and API communication
```

The component integrates with the tactical API to execute scripts across selected devices, automatically handling OS-specific shell configuration and providing real-time feedback through toast notifications.
