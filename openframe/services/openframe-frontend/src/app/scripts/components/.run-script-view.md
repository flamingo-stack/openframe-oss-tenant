React component for executing scripts on selected devices within the OpenFrame platform. It provides a comprehensive interface for script deployment with device filtering, multi-selection capabilities, and batch execution functionality.

## Key Components

- **RunScriptView**: Main component that orchestrates script execution workflow
- **Device Selection Logic**: Multi-device selection with search and filtering capabilities
- **Script Execution Handler**: Processes bulk script deployment to selected agents
- **OS Compatibility**: Handles cross-platform script execution (Windows/Linux/macOS)
- **UI Components**: Integrated search, device cards, and action buttons

## Usage Example

```typescript
import { RunScriptView } from './components/run-script-view'

// Render script execution interface
function ScriptExecutionPage({ params }: { params: { id: string } }) {
  return (
    <div className="min-h-screen">
      <RunScriptView scriptId={params.id} />
    </div>
  )
}

// Component handles the complete script execution workflow:
// 1. Loads script details and available devices
// 2. Provides search and filtering for device selection
// 3. Validates OS compatibility for cross-platform scripts
// 4. Executes bulk actions via Tactical RMM API
// 5. Shows execution status and results to user
```

The component integrates with the Tactical RMM backend to execute scripts across multiple devices simultaneously, with proper error handling and user feedback through toast notifications.
