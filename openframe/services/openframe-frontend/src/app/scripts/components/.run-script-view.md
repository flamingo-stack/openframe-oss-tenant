A React component that provides an interface for running scripts on selected devices within the OpenFrame platform, combining script details display with device selection and bulk execution capabilities.

## Key Components

- **RunScriptView** - Main component that renders the script execution interface
- **useRunScriptData** - Custom hook for fetching script details and device data
- **Device Selection Logic** - Multi-device selection with search and filtering
- **Script Execution Handler** - Manages bulk script execution via Tactical RMM API
- **OS Type Normalization** - Handles different operating system formats and shell selection

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

// Render script execution interface
function ScriptExecutionPage({ params }: { params: { scriptId: string } }) {
  return <RunScriptView scriptId={params.scriptId} />
}

// Component handles:
// - Loading script details and compatible devices
// - Device search and selection with debounced input
// - OS-specific shell selection (PowerShell/CMD for Windows, bash for Unix)
// - Bulk script execution with error handling and toast notifications
// - Navigation back to script details page
```

The component features responsive design with device cards, real-time search functionality, and comprehensive error handling for script execution failures. It integrates with the Tactical RMM API for remote script execution across multiple selected devices.
