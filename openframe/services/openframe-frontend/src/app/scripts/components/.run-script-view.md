A React component that provides an interface for running scripts on selected devices, including device search, selection, and bulk script execution capabilities.

## Key Components

- **RunScriptView**: Main component that renders the script execution interface with device selection
- **useRunScriptData**: Custom hook for fetching script details and device data
- **Device Selection Logic**: Handles multi-device selection with search and filtering
- **Script Execution**: Manages bulk script execution via Tactical RMM API
- **UI Components**: Integrates SearchBar, SelectableDeviceCard, and DetailPageContainer

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

// Render script execution interface
function ScriptPage({ params }: { params: { scriptId: string } }) {
  return <RunScriptView scriptId={params.scriptId} />
}

// The component handles:
// - Loading script details and compatible devices
// - Device search with debounced input
// - Multi-device selection with toggle functionality  
// - OS-specific script execution via Tactical RMM
// - Success/error feedback through toast notifications
```

The component features a responsive grid layout for device cards, handles different device types and operating systems, and provides bulk actions for script deployment across multiple agents simultaneously.
