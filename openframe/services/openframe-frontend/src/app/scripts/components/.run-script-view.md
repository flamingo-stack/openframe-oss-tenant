A React component that provides an interface for executing scripts on multiple selected devices within the OpenFrame platform. It combines script information display with device selection and management capabilities for bulk script execution operations.

## Key Components

- **RunScriptView** - Main component that orchestrates the script execution workflow
- **ScriptInfoSection** - Displays script metadata and configuration details
- **SelectableDeviceCard** - Renders individual devices with selection capabilities
- **SearchBar** - Provides device filtering functionality
- **Device Selection Logic** - Manages multi-device selection state and operations

## Key Features

- **Script Information Display** - Shows script details, timeout settings, and execution parameters
- **Device Search & Filter** - Real-time device search with debounced input
- **Bulk Device Selection** - Multi-select with "Select All" and "Clear Selection" options
- **Cross-Platform Support** - Handles Windows, Linux, and macOS devices with appropriate shell selection
- **Tactical RMM Integration** - Maps devices to Tactical RMM agent IDs for script execution
- **Error Handling** - Comprehensive error states for script loading and device operations

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

// Used in script execution workflow
function ScriptExecutionPage({ params }: { params: { scriptId: string } }) {
  return (
    <RunScriptView scriptId={params.scriptId} />
  )
}

// The component handles:
// - Loading script details and available devices
// - Device search and selection management  
// - Script execution with proper OS-specific shell selection
// - Success/error feedback via toast notifications
```

The component integrates with the Tactical RMM API for script execution and uses OpenFrame's device management system for target selection, providing a streamlined interface for IT administrators to deploy scripts across their managed infrastructure.
