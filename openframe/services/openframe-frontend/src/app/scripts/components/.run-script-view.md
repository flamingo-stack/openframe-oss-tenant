A React component view that enables users to run scripts on selected devices through the Tactical RMM platform with device search, selection, and execution capabilities.

## Key Components

- **RunScriptView**: Main component that renders script execution interface with device selection
- **useRunScriptData**: Custom hook for fetching script details and devices
- **ScriptInfoSection**: Displays script metadata and configuration
- **SelectableDeviceCard**: Device cards with selection checkboxes
- **Bulk Action Execution**: Submits scripts to multiple selected devices via Tactical RMM API

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

// Render script execution interface
function ScriptRunPage({ params }: { params: { scriptId: string } }) {
  return <RunScriptView scriptId={params.scriptId} />
}

// Component handles:
// - Loading script details and available devices
// - Device search with debounced input
// - Multi-device selection with select all/clear options
// - Script execution with proper shell detection and payload formatting
// - Success/error notifications via toast system
```

The component automatically detects device operating systems, maps them to appropriate shell environments (PowerShell/CMD for Windows, bash for Unix-like systems), and submits bulk execution requests to the Tactical RMM API with proper error handling and user feedback.
