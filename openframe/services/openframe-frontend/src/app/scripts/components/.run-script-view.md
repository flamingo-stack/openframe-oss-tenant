A React component that provides a user interface for running scripts on selected devices within the OpenFrame platform, featuring device search, selection, and bulk script execution capabilities.

## Key Components

- **RunScriptView**: Main component that orchestrates the script execution workflow
- **useRunScriptData**: Custom hook for managing script details and device data
- **Device Selection Logic**: Handles multi-device selection with search and filtering
- **Script Execution Handler**: Processes bulk script execution via Tactical RMM API
- **OS Normalization**: Converts various OS formats to standardized types (windows/linux/darwin)

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

// Display the script execution interface
function ScriptExecutionPage({ params }: { params: { scriptId: string } }) {
  return <RunScriptView scriptId={params.scriptId} />
}

// The component handles:
// - Loading script details and compatible devices
// - Device search with debounced input
// - Multi-device selection with toggle functionality
// - OS-aware script execution via Tactical RMM
// - Success/error feedback via toast notifications
```

The component integrates with the Tactical RMM API to execute scripts across multiple devices, automatically determining the appropriate shell type based on device operating systems. It provides a responsive grid layout for device selection and includes comprehensive error handling for both data loading and script execution operations.
