A React component for running automation scripts across multiple devices in the OpenFrame platform. It provides device selection, script execution, and real-time feedback for MSP operations.

## Key Components

**Main Component:**
- `RunScriptView` - Primary container component for script execution interface

**Core Features:**
- Device search and filtering with 300ms debounce
- Multi-device selection with bulk operations
- Cross-platform script execution (Windows/Linux/macOS)
- Real-time toast notifications for operation feedback

**Key Hooks:**
- `useRunScriptData` - Manages script details and device data fetching
- `useDebounce` - Optimizes search performance
- `useToast` - Provides user feedback

**UI Components:**
- `DetailPageContainer` - Main layout wrapper
- `ScriptInfoSection` - Displays script metadata
- `SelectableDeviceCard` - Individual device selection cards
- `SearchBar` - Device filtering interface

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

// Used in script management pages
function ScriptExecutionPage({ params }: { params: { scriptId: string } }) {
  return (
    <RunScriptView scriptId={params.scriptId} />
  )
}

// The component handles:
// - Loading script details and compatible devices
// - Device search and selection
// - OS-specific shell selection (PowerShell/CMD/Bash)
// - Bulk script execution via Tactical RMM API
// - Error handling and user notifications
```

The component automatically determines the appropriate shell environment based on device OS and executes scripts across selected agents with proper timeout and environment variable handling.
