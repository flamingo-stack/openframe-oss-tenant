A React component that provides an interface for running scripts on multiple devices through a searchable device selection interface with bulk execution capabilities.

## Key Components

- **RunScriptView**: Main component that manages script execution workflow
- **useRunScriptData**: Custom hook for fetching script details and devices
- **Device Selection**: Multi-select interface with search functionality
- **Script Execution**: Bulk action handler for running scripts on selected devices
- **OS Detection**: Automatic shell selection based on device operating systems

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

export default function RunScriptPage({ params }: { params: { scriptId: string } }) {
  return <RunScriptView scriptId={params.scriptId} />
}
```

The component fetches script details and available devices, allows users to search and select multiple devices, then executes the script via the Tactical RMM API. It handles OS-specific shell selection (PowerShell/CMD for Windows, Bash for Unix-like systems) and provides real-time feedback through toast notifications. The interface includes device cards with selection state, bulk selection controls, and error handling for both script loading and execution failures.
