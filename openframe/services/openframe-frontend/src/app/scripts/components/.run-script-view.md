React component for running scripts on selected devices with search, filtering, and bulk execution capabilities.

## Key Components

- **RunScriptView**: Main component that provides an interface for selecting devices and executing scripts across them
- **Device Selection**: Interactive device cards with multi-select functionality and search capabilities
- **Script Execution**: Handles OS-specific script execution with proper shell selection and parameter passing
- **Search & Filtering**: Debounced device search with real-time filtering
- **Bulk Operations**: Select all/clear functionality for managing multiple device selections

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

function ScriptExecutionPage() {
  return (
    <RunScriptView 
      scriptId="script-123" 
    />
  )
}

// The component automatically:
// - Loads script details and available devices
// - Provides search functionality with 300ms debounce
// - Handles OS detection (Windows/Linux/macOS) for proper shell selection
// - Executes scripts via Tactical RMM API on selected devices
// - Shows success/error notifications via toast system
```

The component integrates with the Tactical RMM API for script execution, automatically detects device operating systems to select appropriate shells (PowerShell/CMD for Windows, bash for Unix-like systems), and provides comprehensive error handling with user feedback through toast notifications.
