A React component for executing scripts across multiple devices in the OpenFrame platform, providing device selection, search functionality, and batch script execution capabilities.

## Key Components

- **RunScriptView**: Main component that manages script execution workflow
- **useRunScriptData**: Custom hook for fetching script details and device data
- **Device Selection**: Multi-select interface with search and filtering
- **Script Execution**: Bulk action submission to Tactical RMM agents
- **OS Normalization**: Cross-platform operating system detection and shell selection

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

// Use in a Next.js page or component
function ScriptExecutionPage({ params }: { params: { scriptId: string } }) {
  return (
    <div>
      <RunScriptView scriptId={params.scriptId} />
    </div>
  )
}

// The component handles:
// - Loading script details and compatible devices
// - Device search with debounced input
// - Multi-device selection with batch operations
// - OS-aware shell selection (PowerShell/CMD for Windows, bash for Unix)
// - Tactical RMM agent integration for script execution
```

The component integrates with the Tactical RMM API to execute scripts on selected devices, automatically determining the appropriate shell based on device operating systems and providing real-time feedback through toast notifications.
