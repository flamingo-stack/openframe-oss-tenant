A React component that provides a comprehensive interface for executing scripts across multiple selected devices within the Tactical RMM integration.

## Key Components

- **RunScriptView**: Main component that orchestrates script execution workflow
- **useRunScriptData**: Custom hook for fetching script details and device data
- **ScriptInfoSection**: Displays script metadata and configuration
- **SelectableDeviceCard**: Individual device selection interface
- **Device Selection Logic**: Handles multi-device selection with search and filtering

## Usage Example

```typescript
import { RunScriptView } from './run-script-view'

// Display script execution interface for a specific script
function ScriptExecutionPage({ params }: { params: { scriptId: string } }) {
  return <RunScriptView scriptId={params.scriptId} />
}

// The component handles:
// - Loading script details and compatible devices
// - Device search and selection
// - OS-specific shell configuration
// - Bulk script execution via Tactical RMM API
```

The component features debounced device search, multi-device selection with "select all" functionality, and intelligent OS detection for proper shell selection. It integrates with the Tactical RMM API to execute scripts across selected agents, providing real-time feedback through toast notifications and comprehensive error handling for loading states and API failures.
