A React component that displays scheduled scripts in an expandable card format, showing script details, arguments, and environment variables with responsive design.

## Key Components

- **ScheduleScriptsTab**: Main container component that renders a list of script schedule actions
- **ScheduleScriptCard**: Individual expandable card component for each scheduled script action
- **Props interfaces**: `ScheduleScriptsTabProps` and `ScheduleScriptCardProps` for type safety

## Usage Example

```typescript
import { ScheduleScriptsTab } from './schedule-scripts-tab'
import type { ScriptScheduleDetail } from '../types/script-schedule.types'

const schedule: ScriptScheduleDetail = {
  actions: [
    {
      script: 123,
      name: "Database Backup",
      timeout: 300,
      script_args: ["--database=prod", "--compress=true"],
      env_vars: ["BACKUP_PATH=/var/backups", "LOG_LEVEL=info"]
    }
  ]
}

function SchedulePage() {
  return (
    <div className="container">
      <ScheduleScriptsTab schedule={schedule} />
    </div>
  )
}
```

The component features responsive design with mobile-specific button placement, smooth animations for expand/collapse functionality, and proper argument/environment variable parsing for display in InfoCard components.
