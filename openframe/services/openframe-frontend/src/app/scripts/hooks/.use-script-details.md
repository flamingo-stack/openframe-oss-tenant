A React hook for fetching and managing script details from the Tactical API, providing type-safe access to script metadata, configuration, and execution parameters.

## Key Components

- **`ScriptDetails` interface**: Comprehensive type definition for script metadata including execution settings, platform support, and security configurations
- **`scriptDetailsQueryKeys`**: Standardized query key factory for React Query caching and invalidation
- **`fetchScriptDetails`**: API function that retrieves script details via the tactical API client
- **`useScriptDetails`**: Main React hook that provides script data, loading states, and refetch capabilities

## Usage Example

```typescript
import { useScriptDetails } from './use-script-details'

function ScriptDetailsComponent({ scriptId }: { scriptId: string }) {
  const { scriptDetails, isLoading, error, refetch } = useScriptDetails(scriptId)

  if (isLoading) return <div>Loading script details...</div>
  if (error) return <div>Error: {error}</div>
  if (!scriptDetails) return <div>Script not found</div>

  return (
    <div>
      <h2>{scriptDetails.name}</h2>
      <p>{scriptDetails.description}</p>
      <div>
        <strong>Shell:</strong> {scriptDetails.shell}
        <strong>Category:</strong> {scriptDetails.category}
        <strong>Timeout:</strong> {scriptDetails.default_timeout}s
        <strong>Platforms:</strong> {scriptDetails.supported_platforms.join(', ')}
      </div>
      <button onClick={() => refetch()}>Refresh</button>
    </div>
  )
}
```

The hook automatically handles caching, error states, and provides a clean interface for accessing script metadata throughout the application.
