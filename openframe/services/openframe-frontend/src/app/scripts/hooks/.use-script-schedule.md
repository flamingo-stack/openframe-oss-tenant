A React Query-based custom hook library for managing script schedule data from the Tactical RMM API, providing centralized query management for schedules, agents, and execution history.

## Key Components

- **Query Keys**: Hierarchical query key factory (`scriptScheduleQueryKeys`) for consistent caching and invalidation
- **API Functions**: Async functions that wrap Tactical API client calls with error handling
- **Custom Hooks**:
  - `useScriptSchedules()` - Fetches all script schedules
  - `useScriptSchedule(id)` - Fetches single schedule details
  - `useScriptScheduleAgents(id)` - Fetches agents assigned to a schedule
  - `useScriptScheduleHistory(id, options)` - Fetches paginated execution history

## Usage Example

```typescript
import { 
  useScriptSchedules, 
  useScriptSchedule, 
  useScriptScheduleHistory 
} from './hooks/use-script-schedule'

function ScheduleManager() {
  // List all schedules
  const { schedules, isLoading, error } = useScriptSchedules()
  
  // Get specific schedule details
  const { schedule } = useScriptSchedule('schedule-123')
  
  // Get paginated execution history
  const { history, total } = useScriptScheduleHistory('schedule-123', {
    limit: 25,
    offset: 0
  })

  if (isLoading) return <div>Loading...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      {schedules.map(schedule => (
        <div key={schedule.id}>{schedule.name}</div>
      ))}
    </div>
  )
}
```
