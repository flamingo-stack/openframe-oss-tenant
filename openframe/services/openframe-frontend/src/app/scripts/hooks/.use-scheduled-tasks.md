A React Query hook for managing scheduled tasks associated with scripts, providing data fetching, caching, and deletion capabilities through the Tactical RMM API.

## Key Components

### Types
- **`ScheduledTask`** - Complete scheduled task interface with timing, actions, and configuration
- **`ScheduledTaskAction`** - Task action definition (currently supports script execution)

### Query Functions
- **`fetchScheduledTasksByScript()`** - Fetches and filters scheduled tasks by script ID
- **`deleteScheduledTaskApi()`** - Deletes a scheduled task via API

### Hook Export
- **`useScheduledTasks()`** - Main hook providing scheduled task operations for a specific script

## Usage Example

```typescript
import { useScheduledTasks } from './use-scheduled-tasks'

function ScriptScheduledTasks({ scriptId }: { scriptId: string }) {
  const {
    scheduledTasks,
    isLoading,
    error,
    deleteTask,
    isDeleting,
    refetch
  } = useScheduledTasks(scriptId)

  const handleDeleteTask = (taskId: string) => {
    deleteTask(taskId, {
      onSuccess: () => console.log('Task deleted successfully'),
      onError: (error) => console.error('Delete failed:', error)
    })
  }

  if (isLoading) return <div>Loading scheduled tasks...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      {scheduledTasks.map(task => (
        <div key={task.id}>
          <h3>{task.name}</h3>
          <p>Type: {task.task_type}</p>
          <button 
            onClick={() => handleDeleteTask(task.id.toString())}
            disabled={isDeleting}
          >
            Delete Task
          </button>
        </div>
      ))}
    </div>
  )
}
```

The hook automatically filters all scheduled tasks to only return those containing actions that reference the specified script ID, with built-in error handling and optimistic cache updates.
