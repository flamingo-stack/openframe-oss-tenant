React hook for managing scheduled tasks in TacticalRMM. Provides functionality to fetch scheduled tasks filtered by script ID and delete tasks with optimistic cache updates.

## Key Components

- **`ScheduledTask`**: TypeScript interface defining the complete structure of a scheduled task including timing, actions, and configuration
- **`ScheduledTaskAction`**: Interface for script-based actions within scheduled tasks
- **`useScheduledTasks`**: Main hook that provides query and mutation operations for scheduled tasks
- **`scheduledTasksQueryKeys`**: Query key factory for consistent cache management
- **API Functions**: `fetchScheduledTasksByScript` and `deleteScheduledTaskApi` for backend communication

## Usage Example

```typescript
import { useScheduledTasks } from '@/hooks/use-scheduled-tasks'

function ScheduledTasksList({ scriptId }: { scriptId: string }) {
  const {
    scheduledTasks,
    isLoading,
    error,
    deleteTask,
    isDeleting,
    refetch
  } = useScheduledTasks(scriptId)

  const handleDelete = (taskId: string) => {
    deleteTask(taskId, {
      onSuccess: () => console.log('Task deleted successfully'),
      onError: (error) => console.error('Delete failed:', error)
    })
  }

  if (isLoading) return <div>Loading scheduled tasks...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      {scheduledTasks.map(task => (
        <div key={task.id}>
          <h3>{task.name}</h3>
          <p>Type: {task.task_type}</p>
          <button 
            onClick={() => handleDelete(task.id.toString())}
            disabled={isDeleting}
          >
            Delete Task
          </button>
        </div>
      ))}
    </div>
  )
}
```
