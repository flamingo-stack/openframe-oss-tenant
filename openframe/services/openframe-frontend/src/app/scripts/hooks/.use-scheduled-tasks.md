React Query hook for managing scheduled tasks in the Tactical RMM platform, providing functionality to fetch and delete tasks filtered by script ID.

## Key Components

- **ScheduledTask Interface** - Type definition for scheduled task objects with timing, actions, and configuration
- **ScheduledTaskAction Interface** - Type for script-based actions within scheduled tasks
- **scheduledTasksQueryKeys** - Query key factory for React Query caching strategies
- **useScheduledTasks Hook** - Main hook providing scheduled tasks data and operations
- **fetchScheduledTasksByScript** - API function to retrieve tasks filtered by script ID
- **deleteScheduledTaskApi** - API function to remove scheduled tasks

## Usage Example

```typescript
import { useScheduledTasks } from './use-scheduled-tasks'

function ScheduledTasksList({ scriptId }: { scriptId: string }) {
  const {
    scheduledTasks,
    isLoading,
    error,
    deleteTask,
    isDeleting,
    refetch
  } = useScheduledTasks(scriptId)

  const handleDeleteTask = (taskId: string) => {
    deleteTask(taskId, {
      onSuccess: () => console.log('Task deleted successfully'),
      onError: (error) => console.error('Delete failed:', error)
    })
  }

  if (isLoading) return <div>Loading scheduled tasks...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      {scheduledTasks.map(task => (
        <div key={task.id}>
          <h3>{task.name}</h3>
          <p>Type: {task.task_type}</p>
          <button 
            onClick={() => handleDeleteTask(task.id.toString())}
            disabled={isDeleting}
          >
            Delete Task
          </button>
        </div>
      ))}
    </div>
  )
}
```

The hook automatically filters tasks to show only those containing script actions matching the provided script ID, with built-in caching and error handling through React Query.
