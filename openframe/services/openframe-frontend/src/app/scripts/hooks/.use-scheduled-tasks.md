A React Query-powered hook for managing scheduled tasks filtered by script ID, providing querying and deletion functionality with optimistic updates.

## Key Components

- **Types**: `ScheduledTask` and `ScheduledTaskAction` interfaces defining the task data structure
- **Query Keys**: Standardized cache keys for React Query with script-based filtering
- **API Functions**: `fetchScheduledTasksByScript()` and `deleteScheduledTaskApi()` for backend communication
- **Main Hook**: `useScheduledTasks()` providing data fetching, loading states, and task deletion

## Usage Example

```typescript
import { useScheduledTasks } from '@/hooks/use-scheduled-tasks'

function ScriptScheduledTasks({ scriptId }: { scriptId: string }) {
  const {
    scheduledTasks,
    isLoading,
    error,
    deleteTask,
    isDeleting,
    refetch
  } = useScheduledTasks(scriptId)

  const handleDelete = (taskId: string) => {
    deleteTask(taskId, {
      onSuccess: () => console.log('Task deleted successfully'),
      onError: (error) => console.error('Delete failed:', error)
    })
  }

  if (isLoading) return <div>Loading scheduled tasks...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <button onClick={() => refetch()}>Refresh</button>
      {scheduledTasks.map(task => (
        <div key={task.id}>
          <h3>{task.name}</h3>
          <p>Type: {task.task_type}</p>
          <button 
            onClick={() => handleDelete(task.id.toString())}
            disabled={isDeleting}
          >
            Delete Task
          </button>
        </div>
      ))}
    </div>
  )
}
```

The hook automatically filters all scheduled tasks to only return those containing actions that reference the specified script ID, making it ideal for script-specific task management interfaces.
