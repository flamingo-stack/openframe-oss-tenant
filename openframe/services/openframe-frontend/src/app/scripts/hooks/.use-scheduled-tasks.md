A React hook for managing scheduled tasks in the TacticalRMM system, providing query and mutation capabilities for tasks filtered by script ID.

## Key Components

- **`ScheduledTask` interface**: Defines the complete structure of a scheduled task including timing, actions, and execution settings
- **`ScheduledTaskAction` interface**: Represents script-based actions within scheduled tasks
- **`scheduledTasksQueryKeys`**: Query key factory for cache management and invalidation
- **`useScheduledTasks` hook**: Main hook providing filtered scheduled tasks data and deletion functionality
- **API functions**: `fetchScheduledTasksByScript` and `deleteScheduledTaskApi` for backend communication

## Usage Example

```typescript
import { useScheduledTasks } from './use-scheduled-tasks'

function ScriptScheduledTasks({ scriptId }: { scriptId: string }) {
  const {
    scheduledTasks,
    isLoading,
    error,
    deleteTask,
    isDeleting,
    refetch
  } = useScheduledTasks(scriptId)

  const handleDeleteTask = (taskId: string) => {
    deleteTask(taskId, {
      onSuccess: () => console.log('Task deleted successfully'),
      onError: (error) => console.error('Delete failed:', error)
    })
  }

  if (isLoading) return <div>Loading tasks...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      {scheduledTasks.map(task => (
        <div key={task.id}>
          <h3>{task.name}</h3>
          <p>Type: {task.task_type}</p>
          <button 
            onClick={() => handleDeleteTask(task.id.toString())}
            disabled={isDeleting}
          >
            Delete Task
          </button>
        </div>
      ))}
    </div>
  )
}
```

The hook automatically filters all scheduled tasks to show only those containing actions that reference the specified script ID, making it ideal for script management interfaces.
