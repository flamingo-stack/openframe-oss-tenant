A React Query hook for managing scheduled tasks, providing functionality to fetch tasks by script ID and delete tasks with optimistic updates.

## Key Components

- **`ScheduledTask` interface** - Complete type definition for scheduled tasks with timing configurations, actions, and metadata
- **`ScheduledTaskAction` interface** - Type for task actions that can execute scripts with parameters
- **`scheduledTasksQueryKeys`** - Query key factory for consistent caching and invalidation
- **`useScheduledTasks` hook** - Main hook providing scheduled task operations for a specific script
- **API functions** - `fetchScheduledTasksByScript` and `deleteScheduledTaskApi` for backend communication

## Usage Example

```typescript
import { useScheduledTasks } from './use-scheduled-tasks'

function ScheduledTasksManager({ scriptId }: { scriptId: string }) {
  const {
    scheduledTasks,
    isLoading,
    error,
    deleteTask,
    isDeleting,
    refetch
  } = useScheduledTasks(scriptId)

  const handleDeleteTask = (taskId: string) => {
    deleteTask(taskId, {
      onSuccess: () => console.log('Task deleted successfully'),
      onError: (error) => console.error('Delete failed:', error)
    })
  }

  if (isLoading) return <div>Loading tasks...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      {scheduledTasks.map(task => (
        <div key={task.id}>
          <h3>{task.name}</h3>
          <p>Type: {task.task_type}</p>
          <p>Enabled: {task.enabled ? 'Yes' : 'No'}</p>
          <button 
            onClick={() => handleDeleteTask(task.id.toString())}
            disabled={isDeleting}
          >
            Delete Task
          </button>
        </div>
      ))}
    </div>
  )
}
```

The hook automatically filters scheduled tasks to only return those that reference the specified script ID, and provides mutation functions with automatic cache invalidation.
