A React Query hook for managing scheduled tasks, providing CRUD operations and filtered queries for script-specific task management.

## Key Components

- **Types**: `ScheduledTask` and `ScheduledTaskAction` interfaces defining task structure with scheduling options (daily/weekly/monthly/runonce)
- **Query Keys**: `scheduledTasksQueryKeys` factory for consistent cache key management
- **API Functions**: `fetchScheduledTasksByScript()` and `deleteScheduledTaskApi()` for backend communication
- **Main Hook**: `useScheduledTasks()` providing reactive state management with loading states and mutations

## Usage Example

```typescript
import { useScheduledTasks } from './use-scheduled-tasks'

function ScriptTasksPanel({ scriptId }: { scriptId: string }) {
  const { 
    scheduledTasks, 
    isLoading, 
    error, 
    deleteTask,
    isDeleting 
  } = useScheduledTasks(scriptId)

  const handleDeleteTask = (taskId: string) => {
    deleteTask(taskId, {
      onSuccess: () => console.log('Task deleted successfully'),
      onError: (error) => console.error('Delete failed:', error)
    })
  }

  if (isLoading) return <div>Loading tasks...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      {scheduledTasks.map(task => (
        <div key={task.id}>
          <h3>{task.name}</h3>
          <p>Type: {task.task_type}</p>
          <button 
            onClick={() => handleDeleteTask(task.id.toString())}
            disabled={isDeleting}
          >
            Delete
          </button>
        </div>
      ))}
    </div>
  )
}
```

The hook automatically filters tasks by script ID and provides optimistic cache invalidation on mutations.
