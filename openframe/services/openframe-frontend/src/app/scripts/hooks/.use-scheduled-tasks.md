A React hook for managing scheduled tasks in the Flamingo platform, providing query and mutation functionality for script-based task scheduling operations.

## Key Components

- **Types**: `ScheduledTask` and `ScheduledTaskAction` interfaces defining task structure and script actions
- **useScheduledTasks**: Main hook for fetching, filtering, and deleting scheduled tasks by script ID
- **API Functions**: `fetchScheduledTasksByScript` and `deleteScheduledTaskApi` for backend communication
- **Query Keys**: Structured cache keys for React Query optimization

## Usage Example

```typescript
import { useScheduledTasks } from './use-scheduled-tasks'

function ScriptScheduledTasks({ scriptId }: { scriptId: string }) {
  const {
    scheduledTasks,
    isLoading,
    error,
    deleteTask,
    isDeleting
  } = useScheduledTasks(scriptId)

  const handleDeleteTask = (taskId: string) => {
    deleteTask(taskId, {
      onSuccess: () => console.log('Task deleted successfully'),
      onError: (error) => console.error('Delete failed:', error)
    })
  }

  if (isLoading) return <div>Loading scheduled tasks...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      {scheduledTasks.map(task => (
        <div key={task.id}>
          <h3>{task.name}</h3>
          <p>Type: {task.task_type}</p>
          <p>Enabled: {task.enabled ? 'Yes' : 'No'}</p>
          <button 
            onClick={() => handleDeleteTask(task.id.toString())}
            disabled={isDeleting}
          >
            Delete Task
          </button>
        </div>
      ))}
    </div>
  )
}
```

The hook automatically filters tasks to only include those with script actions matching the provided script ID, and provides optimistic updates through React Query cache invalidation.
