A React hook for managing scheduled tasks in the Tactical RMM system, providing functionality to fetch tasks by script ID and delete them with proper cache invalidation.

## Key Components

- **Types**: `ScheduledTask` and `ScheduledTaskAction` interfaces defining the task structure
- **Query Keys**: Centralized query key factory for consistent cache management
- **API Functions**: `fetchScheduledTasksByScript()` and `deleteScheduledTaskApi()` for data operations
- **Main Hook**: `useScheduledTasks()` - the primary hook exposing all functionality

## Usage Example

```typescript
import { useScheduledTasks } from './use-scheduled-tasks'

function ScriptTasksComponent({ scriptId }: { scriptId: string }) {
  const {
    scheduledTasks,
    isLoading,
    error,
    deleteTask,
    isDeleting,
    refetch
  } = useScheduledTasks(scriptId)

  const handleDeleteTask = (taskId: string) => {
    deleteTask(taskId, {
      onSuccess: () => console.log('Task deleted successfully'),
      onError: (error) => console.error('Failed to delete:', error.message)
    })
  }

  if (isLoading) return <div>Loading tasks...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      {scheduledTasks.map(task => (
        <div key={task.id}>
          <span>{task.name}</span>
          <button 
            onClick={() => handleDeleteTask(task.id.toString())}
            disabled={isDeleting}
          >
            Delete
          </button>
        </div>
      ))}
    </div>
  )
}
```

The hook automatically filters tasks to only return those that reference the specified script ID, making it ideal for script-specific task management interfaces.
