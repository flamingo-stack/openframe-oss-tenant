A React Query hook for managing scheduled tasks in the Tactical RMM system, providing CRUD operations with optimistic updates and error handling.

## Key Components

- **`ScheduledTask` Interface**: Complete type definition for scheduled tasks with timing, actions, and configuration
- **`ScheduledTaskAction` Interface**: Type for task actions (currently script-based)
- **`scheduledTasksQueryKeys`**: Centralized query key factory for React Query caching
- **`useScheduledTasks` Hook**: Main hook providing scheduled task operations for a specific script
- **API Functions**: `fetchScheduledTasksByScript()` and `deleteScheduledTaskApi()` for backend communication

## Usage Example

```typescript
import { useScheduledTasks } from '@/hooks/use-scheduled-tasks'

function ScriptScheduledTasks({ scriptId }: { scriptId: string }) {
  const {
    scheduledTasks,
    isLoading,
    error,
    deleteTask,
    isDeleting,
    refetch
  } = useScheduledTasks(scriptId)

  const handleDeleteTask = (taskId: string) => {
    deleteTask(taskId, {
      onSuccess: () => console.log('Task deleted successfully'),
      onError: (error) => console.error('Delete failed:', error.message)
    })
  }

  if (isLoading) return <div>Loading scheduled tasks...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      {scheduledTasks.map(task => (
        <div key={task.id}>
          <h3>{task.name}</h3>
          <button 
            onClick={() => handleDeleteTask(task.id.toString())}
            disabled={isDeleting}
          >
            Delete Task
          </button>
        </div>
      ))}
    </div>
  )
}
```

The hook automatically filters tasks by script ID and provides optimistic updates with automatic cache invalidation on successful mutations.
