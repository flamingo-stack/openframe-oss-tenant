A React Query hook for managing scheduled tasks in the Flamingo platform, providing CRUD operations for tasks that execute scripts on agents.

## Key Components

- **`ScheduledTask` Interface**: Complete type definition for scheduled tasks with timing configuration, actions, and execution settings
- **`ScheduledTaskAction` Interface**: Defines script execution actions with parameters, environment variables, and user permissions
- **`useScheduledTasks` Hook**: Main hook providing query and mutation operations for scheduled tasks
- **`scheduledTasksQueryKeys`**: Query key factory for React Query caching and invalidation
- **API Functions**: `fetchScheduledTasksByScript()` and `deleteScheduledTaskApi()` for server communication

## Usage Example

```typescript
import { useScheduledTasks } from './use-scheduled-tasks'

function ScriptScheduledTasks({ scriptId }: { scriptId: string }) {
  const {
    scheduledTasks,
    isLoading,
    error,
    deleteTask,
    isDeleting,
    refetch
  } = useScheduledTasks(scriptId)

  const handleDeleteTask = (taskId: string) => {
    deleteTask(taskId, {
      onSuccess: () => console.log('Task deleted successfully'),
      onError: (error) => console.error('Delete failed:', error.message)
    })
  }

  if (isLoading) return <div>Loading scheduled tasks...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <h3>Scheduled Tasks ({scheduledTasks.length})</h3>
      {scheduledTasks.map(task => (
        <div key={task.id}>
          <span>{task.name} - {task.task_type}</span>
          <button 
            onClick={() => handleDeleteTask(task.id.toString())}
            disabled={isDeleting}
          >
            Delete
          </button>
        </div>
      ))}
    </div>
  )
}
```

The hook automatically filters tasks to show only those containing actions that reference the specified script ID, providing a focused view for script management interfaces.
