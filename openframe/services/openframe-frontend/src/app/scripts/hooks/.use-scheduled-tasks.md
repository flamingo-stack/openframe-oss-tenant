A React Query hook for managing scheduled tasks associated with scripts, providing CRUD operations and filtering capabilities.

## Key Components

- **ScheduledTask Interface**: Defines the structure of scheduled tasks with timing configuration, actions, and execution settings
- **ScheduledTaskAction Interface**: Represents script actions that can be executed as part of scheduled tasks
- **useScheduledTasks Hook**: Main hook for querying, filtering, and deleting scheduled tasks by script ID
- **Query Keys Factory**: Structured keys for React Query caching and invalidation
- **API Functions**: Async functions for fetching and deleting scheduled tasks via the Tactical API

## Usage Example

```typescript
import { useScheduledTasks } from './use-scheduled-tasks'

function ScriptScheduledTasks({ scriptId }: { scriptId: string }) {
  const {
    scheduledTasks,
    isLoading,
    error,
    deleteTask,
    isDeleting,
    refetch
  } = useScheduledTasks(scriptId)

  const handleDeleteTask = (taskId: string) => {
    deleteTask(taskId, {
      onSuccess: () => console.log('Task deleted successfully'),
      onError: (error) => console.error('Delete failed:', error.message)
    })
  }

  if (isLoading) return <div>Loading scheduled tasks...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <h3>Scheduled Tasks ({scheduledTasks.length})</h3>
      {scheduledTasks.map((task) => (
        <div key={task.id}>
          <span>{task.name} - {task.task_type}</span>
          <button 
            onClick={() => handleDeleteTask(task.id.toString())}
            disabled={isDeleting}
          >
            Delete
          </button>
        </div>
      ))}
    </div>
  )
}
```

The hook automatically filters all scheduled tasks to only return those containing script actions that reference the specified script ID, making it ideal for script management interfaces.
