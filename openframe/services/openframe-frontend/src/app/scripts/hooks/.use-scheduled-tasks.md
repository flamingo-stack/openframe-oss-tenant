A React Query hook for managing scheduled tasks in the Tactical RMM system, providing CRUD operations and real-time state management.

## Key Components

- **`ScheduledTask` Interface** - Complete type definition for scheduled tasks with timing, actions, and configuration
- **`ScheduledTaskAction` Interface** - Type for task actions, currently supporting script execution
- **`useScheduledTasks` Hook** - Main hook providing query and mutation operations for scheduled tasks
- **`scheduledTasksQueryKeys`** - Query key factory for consistent cache management
- **API Functions** - `fetchScheduledTasksByScript` and `deleteScheduledTaskApi` for server communication

## Usage Example

```typescript
import { useScheduledTasks } from './use-scheduled-tasks'

function ScriptScheduledTasksPage({ scriptId }: { scriptId: string }) {
  const {
    scheduledTasks,
    isLoading,
    error,
    deleteTask,
    isDeleting,
    refetch
  } = useScheduledTasks(scriptId)

  const handleDeleteTask = (taskId: string) => {
    deleteTask(taskId, {
      onSuccess: () => console.log('Task deleted successfully'),
      onError: (error) => console.error('Delete failed:', error.message)
    })
  }

  if (isLoading) return <div>Loading tasks...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <button onClick={() => refetch()}>Refresh Tasks</button>
      {scheduledTasks.map(task => (
        <div key={task.id}>
          <h3>{task.name}</h3>
          <p>Type: {task.task_type}</p>
          <p>Enabled: {task.enabled ? 'Yes' : 'No'}</p>
          <button 
            onClick={() => handleDeleteTask(task.id.toString())}
            disabled={isDeleting}
          >
            Delete Task
          </button>
        </div>
      ))}
    </div>
  )
}
```
