A React hook for managing scheduled tasks with filtering by script ID, using React Query for efficient caching and state management.

## Key Components

- **`ScheduledTask`** - Complete task interface with timing configuration, actions, and metadata
- **`ScheduledTaskAction`** - Task action definition for script execution with arguments and environment
- **`useScheduledTasks`** - Main hook providing CRUD operations and query state management
- **`scheduledTasksQueryKeys`** - Query key factory for React Query cache organization

## Usage Example

```typescript
import { useScheduledTasks } from './use-scheduled-tasks'

function ScheduledTasksList({ scriptId }: { scriptId: string }) {
  const {
    scheduledTasks,
    isLoading,
    error,
    deleteTask,
    isDeleting
  } = useScheduledTasks(scriptId)

  const handleDelete = (taskId: string) => {
    deleteTask(taskId, {
      onSuccess: () => console.log('Task deleted successfully'),
      onError: (error) => console.error('Delete failed:', error.message)
    })
  }

  if (isLoading) return <div>Loading tasks...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      {scheduledTasks.map(task => (
        <div key={task.id}>
          <h3>{task.name}</h3>
          <p>Type: {task.task_type}</p>
          <p>Actions: {task.actions.length}</p>
          <button 
            onClick={() => handleDelete(task.id.toString())}
            disabled={isDeleting}
          >
            Delete Task
          </button>
        </div>
      ))}
    </div>
  )
}
```

The hook automatically filters tasks to show only those containing actions that reference the specified script ID, with built-in caching and optimistic updates.
