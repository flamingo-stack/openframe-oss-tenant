A React Query hook for managing scheduled tasks in the Tactical RMM platform, providing functionality to fetch, filter, and delete automated task schedules.

## Key Components

- **`ScheduledTask` Interface**: Comprehensive type definition for scheduled tasks with various timing options (daily, weekly, monthly, runonce)
- **`ScheduledTaskAction` Interface**: Defines task actions, currently supporting script execution with timeout and environment configurations
- **`useScheduledTasks` Hook**: Main hook providing scheduled task operations with optimistic updates and error handling
- **`scheduledTasksQueryKeys`**: Query key factory for consistent caching and invalidation
- **API Functions**: Async functions for fetching and deleting scheduled tasks via the Tactical API client

## Usage Example

```typescript
import { useScheduledTasks } from '@/hooks/use-scheduled-tasks'

function ScriptScheduledTasks({ scriptId }: { scriptId: string }) {
  const {
    scheduledTasks,
    isLoading,
    error,
    deleteTask,
    isDeleting,
    refetch
  } = useScheduledTasks(scriptId)

  const handleDeleteTask = (taskId: string) => {
    deleteTask(taskId, {
      onSuccess: () => {
        console.log('Task deleted successfully')
      },
      onError: (error) => {
        console.error('Failed to delete task:', error.message)
      }
    })
  }

  if (isLoading) return <div>Loading scheduled tasks...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      {scheduledTasks.map(task => (
        <div key={task.id}>
          <h3>{task.name}</h3>
          <p>Type: {task.task_type}</p>
          <button 
            onClick={() => handleDeleteTask(task.id.toString())}
            disabled={isDeleting}
          >
            Delete
          </button>
        </div>
      ))}
    </div>
  )
}
```

The hook automatically filters tasks to show only those containing actions that reference the specified script ID, making it ideal for script management interfaces.
