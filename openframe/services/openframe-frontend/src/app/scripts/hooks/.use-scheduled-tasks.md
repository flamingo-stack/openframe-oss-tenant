A React hook for managing scheduled tasks in the Tactical RMM platform, providing querying and deletion functionality with React Query integration.

## Key Components

**Types:**
- `ScheduledTaskAction` - Defines task actions with script execution parameters
- `ScheduledTask` - Complete scheduled task model with timing, actions, and configuration

**Hook:**
- `useScheduledTasks` - Main hook for fetching and managing scheduled tasks filtered by script ID

**Query Keys:**
- `scheduledTasksQueryKeys` - Centralized query key factory for cache management

## Usage Example

```typescript
import { useScheduledTasks } from './use-scheduled-tasks'

function ScheduledTasksManager({ scriptId }: { scriptId: string }) {
  const {
    scheduledTasks,
    isLoading,
    error,
    deleteTask,
    isDeleting,
    refetch
  } = useScheduledTasks(scriptId)

  const handleDeleteTask = (taskId: string) => {
    deleteTask(taskId, {
      onSuccess: () => console.log('Task deleted successfully'),
      onError: (error) => console.error('Delete failed:', error)
    })
  }

  if (isLoading) return <div>Loading tasks...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      {scheduledTasks.map(task => (
        <div key={task.id}>
          <h3>{task.name}</h3>
          <p>Type: {task.task_type}</p>
          <p>Actions: {task.actions.length}</p>
          <button 
            onClick={() => handleDeleteTask(task.id.toString())}
            disabled={isDeleting}
          >
            Delete
          </button>
        </div>
      ))}
    </div>
  )
}
```

The hook automatically filters tasks to show only those containing actions that reference the specified script ID, making it ideal for script-specific task management interfaces.
