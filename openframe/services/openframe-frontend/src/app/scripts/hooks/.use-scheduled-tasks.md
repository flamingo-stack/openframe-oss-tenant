A React hook for managing scheduled tasks with query and mutation operations, providing functionality to fetch tasks by script ID and delete tasks with optimistic updates.

## Key Components

**Types:**
- `ScheduledTaskAction` - Defines script-based task actions with execution parameters
- `ScheduledTask` - Complete task configuration including scheduling, actions, and metadata

**Query Management:**
- `scheduledTasksQueryKeys` - Centralized query key factory for cache management
- `fetchScheduledTasksByScript()` - Fetches and filters tasks by script ID
- `deleteScheduledTaskApi()` - Handles task deletion via API

**Main Hook:**
- `useScheduledTasks()` - Primary hook exposing task data, loading states, and operations

## Usage Example

```typescript
import { useScheduledTasks } from './use-scheduled-tasks'

function ScriptTasksView({ scriptId }: { scriptId: string }) {
  const {
    scheduledTasks,
    isLoading,
    error,
    deleteTask,
    isDeleting,
    refetch
  } = useScheduledTasks(scriptId)

  const handleDeleteTask = (taskId: string) => {
    deleteTask(taskId, {
      onSuccess: () => console.log('Task deleted successfully'),
      onError: (error) => console.error('Failed to delete:', error.message)
    })
  }

  if (isLoading) return <div>Loading tasks...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      {scheduledTasks.map(task => (
        <div key={task.id}>
          <h3>{task.name}</h3>
          <p>Type: {task.task_type}</p>
          <button 
            onClick={() => handleDeleteTask(task.id.toString())}
            disabled={isDeleting}
          >
            Delete Task
          </button>
        </div>
      ))}
    </div>
  )
}
```
