A custom React hook for managing scheduled tasks in TacticalRMM, providing query and mutation capabilities for tasks associated with specific scripts.

## Key Components

**Types:**
- `ScheduledTaskAction` - Defines script execution actions with timeout, arguments, and environment variables
- `ScheduledTask` - Complete task definition with scheduling options (daily/weekly/monthly/runonce), dates, and execution settings

**Hook Export:**
- `useScheduledTasks(scriptId)` - Main hook for fetching and managing scheduled tasks for a specific script

**Query Keys:**
- `scheduledTasksQueryKeys` - Centralized query key factory for React Query cache management

## Usage Example

```typescript
import { useScheduledTasks } from './use-scheduled-tasks'

function ScriptScheduledTasks({ scriptId }: { scriptId: string }) {
  const {
    scheduledTasks,
    isLoading,
    error,
    deleteTask,
    isDeleting,
    refetch
  } = useScheduledTasks(scriptId)

  if (isLoading) return <div>Loading scheduled tasks...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <h3>Scheduled Tasks ({scheduledTasks.length})</h3>
      {scheduledTasks.map(task => (
        <div key={task.id}>
          <span>{task.name} - {task.task_type}</span>
          <button 
            onClick={() => deleteTask(task.id.toString(), {
              onSuccess: () => console.log('Task deleted'),
              onError: (error) => console.error('Delete failed:', error)
            })}
            disabled={isDeleting}
          >
            Delete
          </button>
        </div>
      ))}
    </div>
  )
}
```
