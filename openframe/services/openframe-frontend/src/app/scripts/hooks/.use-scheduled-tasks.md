A React hook for managing scheduled tasks related to specific scripts in the Tactical RMM system, providing querying and deletion capabilities with React Query integration.

## Key Components

**Types:**
- `ScheduledTaskAction` - Defines script execution actions with parameters
- `ScheduledTask` - Complete task configuration with scheduling rules and metadata

**Query Keys:**
- `scheduledTasksQueryKeys` - Centralized query key factory for cache management

**Hook:**
- `useScheduledTasks` - Main hook providing scheduled task operations for a script

**API Functions:**
- `fetchScheduledTasksByScript` - Retrieves tasks filtered by script ID
- `deleteScheduledTaskApi` - Removes a scheduled task

## Usage Example

```typescript
import { useScheduledTasks } from './use-scheduled-tasks'

function ScriptScheduledTasks({ scriptId }: { scriptId: string }) {
  const {
    scheduledTasks,
    isLoading,
    error,
    deleteTask,
    isDeleting,
    refetch
  } = useScheduledTasks(scriptId)

  const handleDeleteTask = (taskId: string) => {
    deleteTask(taskId, {
      onSuccess: () => console.log('Task deleted successfully'),
      onError: (error) => console.error('Delete failed:', error.message)
    })
  }

  if (isLoading) return <div>Loading scheduled tasks...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      {scheduledTasks.map(task => (
        <div key={task.id}>
          <h3>{task.name}</h3>
          <p>Type: {task.task_type}</p>
          <p>Enabled: {task.enabled ? 'Yes' : 'No'}</p>
          <button 
            onClick={() => handleDeleteTask(task.id.toString())}
            disabled={isDeleting}
          >
            Delete Task
          </button>
        </div>
      ))}
    </div>
  )
}
```

The hook automatically filters tasks to show only those containing actions that reference the specified script ID, and provides optimistic cache updates when tasks are deleted.
