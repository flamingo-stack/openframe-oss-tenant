A React Hook for managing scheduled tasks filtered by script ID, providing query and mutation operations for task management in the Tactical RMM system.

## Key Components

- **Types**: `ScheduledTask`, `ScheduledTaskAction` - TypeScript interfaces defining the structure of scheduled tasks and their actions
- **Query Keys**: `scheduledTasksQueryKeys` - Structured query key factory for React Query caching
- **API Functions**: `fetchScheduledTasksByScript()`, `deleteScheduledTaskApi()` - Core API operations for retrieving and deleting tasks
- **Main Hook**: `useScheduledTasks()` - Primary hook that combines query and mutation logic with loading states

## Usage Example

```typescript
import { useScheduledTasks } from './use-scheduled-tasks'

function ScriptTasksPanel({ scriptId }: { scriptId: string }) {
  const {
    scheduledTasks,
    isLoading,
    error,
    deleteTask,
    isDeleting,
    refetch
  } = useScheduledTasks(scriptId)

  const handleDeleteTask = (taskId: string) => {
    deleteTask(taskId, {
      onSuccess: () => {
        console.log('Task deleted successfully')
      },
      onError: (error) => {
        console.error('Failed to delete task:', error.message)
      }
    })
  }

  if (isLoading) return <div>Loading tasks...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      {scheduledTasks.map(task => (
        <div key={task.id}>
          <h3>{task.name}</h3>
          <button 
            onClick={() => handleDeleteTask(task.id.toString())}
            disabled={isDeleting}
          >
            Delete Task
          </button>
        </div>
      ))}
    </div>
  )
}
```

The hook automatically filters tasks to only include those with script actions matching the provided `scriptId`, and provides optimistic UI updates through React Query's caching system.
