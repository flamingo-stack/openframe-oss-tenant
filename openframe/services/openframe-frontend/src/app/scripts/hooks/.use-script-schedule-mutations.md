Custom React hooks for managing script schedule mutations in the Flamingo platform. This module provides TanStack Query-powered mutations for CRUD operations on script schedules and agent assignments.

## Key Components

**Mutation Hooks:**
- `useCreateScriptSchedule()` - Creates new script schedules
- `useUpdateScriptSchedule()` - Updates existing schedule configuration
- `useDeleteScriptSchedule()` - Removes script schedules
- `useReplaceScheduleAgents()` - Replaces all agents assigned to a schedule
- `useAddScheduleAgents()` - Adds agents to an existing schedule
- `useRemoveScheduleAgents()` - Removes specific agents from a schedule

**API Functions:**
- `createScriptScheduleApi()` - Creates schedule via tactical API
- `updateScriptScheduleApi()` - Updates schedule details
- `deleteScriptScheduleApi()` - Deletes schedule by ID
- `replaceScheduleAgentsApi()` - Manages complete agent replacement
- `addScheduleAgentsApi()` - Adds agents to schedule
- `removeScheduleAgentsApi()` - Removes agents from schedule

## Usage Example

```typescript
import {
  useCreateScriptSchedule,
  useUpdateScriptSchedule,
  useReplaceScheduleAgents
} from './use-script-schedule-mutations'

function ScheduleManager() {
  const createSchedule = useCreateScriptSchedule()
  const updateSchedule = useUpdateScriptSchedule()
  const replaceAgents = useReplaceScheduleAgents()

  const handleCreate = () => {
    createSchedule.mutate({
      name: 'Daily Backup',
      script: 'backup-script.ps1',
      schedule_type: 'daily',
      run_time: '02:00'
    })
  }

  const handleUpdateAgents = (scheduleId: string) => {
    replaceAgents.mutate({
      id: scheduleId,
      agents: ['agent-1', 'agent-2', 'agent-3']
    })
  }
}
```

Each mutation automatically invalidates relevant query cache entries to keep the UI synchronized with server state.
