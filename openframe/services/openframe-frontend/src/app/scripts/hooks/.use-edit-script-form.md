A custom React hook that manages form state and submission logic for creating and editing scripts in the Tactical RMM system. It handles form validation, API mutations, and provides a unified interface for both create and edit operations.

## Key Components

- **useEditScriptForm** - Main hook that orchestrates form management and script operations
- **createScriptApi/updateScriptApi** - API wrapper functions for script CRUD operations
- **ScriptPayload** - Type definition for the API payload structure
- **Form state management** - Handles form initialization, validation, and reset logic
- **Mutation handlers** - React Query mutations for optimistic updates and error handling

## Usage Example

```typescript
import { useEditScriptForm } from './use-edit-script-form'

function EditScriptDialog({ scriptId, scriptDetails, isEditMode }) {
  const { form, isSubmitting, handleSave } = useEditScriptForm({
    scriptId,
    scriptDetails,
    isEditMode
  })

  const {
    register,
    formState: { errors },
    watch
  } = form

  return (
    <form>
      <input
        {...register('name')}
        placeholder="Script name"
        disabled={isSubmitting}
      />
      
      <textarea
        {...register('script_body')}
        placeholder="Script content"
        disabled={isSubmitting}
      />

      <button 
        onClick={handleSave}
        disabled={isSubmitting}
      >
        {isEditMode ? 'Update' : 'Create'} Script
      </button>
    </form>
  )
}
```

The hook automatically handles form population in edit mode, validates data using Zod schemas, manages loading states, displays toast notifications for success/error feedback, and invalidates relevant queries after successful operations.
