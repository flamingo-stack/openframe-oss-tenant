A React Query hook for managing script data fetching and caching in the Flamingo platform, providing scripts list management with automatic error handling and cache invalidation.

## Key Components

- **scriptsQueryKeys**: Query key factory for consistent cache key management
- **fetchAllScripts()**: API function that retrieves all scripts from the Tactical RMM API
- **useScripts()**: Main React hook that provides scripts data, loading states, error handling, and cache control methods

## Usage Example

```typescript
import { useScripts } from './hooks/use-scripts'

function ScriptsManager() {
  const { scripts, isLoading, error, refetch, invalidate } = useScripts()

  if (isLoading) return <div>Loading scripts...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <button onClick={() => refetch()}>Refresh Scripts</button>
      <button onClick={() => invalidate()}>Clear Cache</button>
      
      {scripts.map(script => (
        <div key={script.id}>{script.name}</div>
      ))}
    </div>
  )
}
```

The hook automatically manages loading states, error handling, and provides both immediate refetch and cache invalidation capabilities for optimal data synchronization.
