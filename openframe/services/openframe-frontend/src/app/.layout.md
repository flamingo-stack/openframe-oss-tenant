Next.js root layout component that sets up the complete app shell for OpenFrame, including metadata, providers, and conditional authentication components.

## Key Components

- **Metadata Configuration**: Complete SEO setup with OpenGraph, Twitter cards, favicons, and manifest
- **Font Integration**: Azeret Mono and DM Sans variable fonts from the design system
- **Provider Stack**: Query client, route guards, and authentication components
- **Conditional Features**: Dev ticket observer and GraphQL introspection only when auth is enabled
- **Skeleton Loading**: App shell skeleton for loading states

## Usage Example

This layout automatically wraps all pages in the OpenFrame application:

```typescript
// Used automatically by Next.js App Router
// Pages are rendered as children within this layout

// The layout provides:
// - SEO metadata and social sharing
// - Font variables for CSS custom properties
// - React Query provider for data fetching
// - Route protection and authentication
// - Global toaster for notifications
// - Loading states and error boundaries
```

The component uses `force-dynamic` rendering to prevent SSG issues with search parameters and ensures proper hydration with `suppressHydrationWarning` for dark mode and font loading.
