This is the root layout component for the OpenFrame application, providing global structure, metadata, and core providers for the entire Next.js application.

## Key Components

- **Metadata Configuration** - Complete SEO setup with OpenGraph, Twitter cards, and structured metadata for MSP-focused branding
- **Font Integration** - Custom Azeret Mono and DM Sans fonts with CSS variable support
- **Core Providers** - Query client, route guard, and authentication components
- **Performance Optimizations** - Dynamic rendering, suspense boundaries, and skeleton loading states
- **Analytics Integration** - Google Tag Manager for tracking and deployment initialization
- **Dark Theme** - Default dark mode with OpenFrame design system integration

## Usage Example

```typescript
// This layout automatically wraps all pages in the Next.js app
// Pages are rendered within the children prop:

export default function HomePage() {
  return (
    <div>
      {/* Content automatically gets the layout structure */}
      <h1>Welcome to OpenFrame</h1>
    </div>
  )
}

// The layout provides:
// - SEO metadata for all pages
// - Authentication context
// - Query client for data fetching
// - Global styling and fonts
// - Error boundaries and loading states
```

## Configuration Features

The layout includes comprehensive metadata configuration targeting MSP (Managed Service Provider) audiences, with OpenGraph images, Twitter cards, and favicon sets. It conditionally renders authentication-related components based on app mode and uses Suspense boundaries to prevent layout shifts during hydration.
