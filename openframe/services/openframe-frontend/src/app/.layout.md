The root layout component for the OpenFrame application that configures SEO metadata, initializes providers, and sets up the base HTML structure with conditional authentication features.

## Key Components

- **Metadata Configuration** - Complete SEO setup with Open Graph, Twitter cards, and favicon definitions for OpenFrame branding
- **Font Integration** - Custom font setup using Azeret Mono and DM Sans via CSS variables
- **Provider Stack** - QueryClient, RouteGuard, and conditional authentication providers
- **Initialization Components** - DeploymentInitializer, GraphQLIntrospectionInitializer, and DevTicketObserver for app setup
- **Analytics Integration** - Google Tag Manager and environment variable injection via PublicEnvScript
- **Responsive Layout** - Base flex layout with Suspense boundaries and skeleton loading states

## Usage Example

```typescript
// This is the root layout - automatically used by Next.js App Router
// Wraps all pages with providers and metadata

// The layout provides:
export const metadata = {
  title: 'OpenFrame - AI-Driven Open-Source OS for MSPs',
  description: 'Swap bloated vendor tools for open ones...',
  // Complete SEO and social media optimization
}

// Conditional authentication rendering
{isAuthEnabled() && (
  <Suspense fallback={null}>
    <DevTicketObserver />
    <GraphQLIntrospectionInitializer />
  </Suspense>
)}

// Provider hierarchy for state management
<QueryClientProvider>
  <RouteGuard>
    <div className="relative flex min-h-screen flex-col">
      <Suspense fallback={<AppShellSkeleton />}>
        {children}
      </Suspense>
    </div>
  </RouteGuard>
</QueryClientProvider>
```

The layout forces dynamic rendering to prevent SSG issues and includes comprehensive branding assets, theme configuration, and conditional feature loading based on authentication settings.
