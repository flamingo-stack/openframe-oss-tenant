Root layout component that configures the base HTML structure and global providers for the OpenFrame AI-powered MSP platform. Sets up SEO metadata, authentication guards, analytics tracking, and essential UI providers with dark theme styling.

## Key Components

**Layout Configuration:**
- `dynamic: 'force-dynamic'` - Forces dynamic rendering to prevent SSG issues with search params
- `metadata` - Comprehensive SEO configuration with OpenGraph and Twitter cards
- Font setup with Azeret Mono and DM Sans custom fonts

**Core Providers:**
- `QueryClientProvider` - React Query client for data fetching
- `RouteGuard` - Authentication and route protection
- `Toaster` - Global toast notification system

**Conditional Components:**
- `DevTicketObserver` - Development ticket monitoring (auth-enabled only)
- `GraphQLIntrospectionInitializer` - GraphQL schema introspection (auth-enabled only)
- `GoogleTagManager` - Analytics tracking
- `DeploymentInitializer` - Deployment configuration

## Usage Example

```typescript
// This is the root layout - automatically wraps all pages
// Used by Next.js App Router as the base layout

// Example page that inherits this layout:
export default function DashboardPage() {
  return (
    <div className="p-6">
      <h1>MSP Dashboard</h1>
      {/* Content automatically wrapped with providers */}
    </div>
  )
}

// SEO metadata is automatically applied to all routes
// Custom metadata can override in individual pages:
export const metadata = {
  title: 'Custom Page Title' // Will become "Custom Page Title | OpenFrame"
}
```

The layout provides a dark-themed, responsive foundation with comprehensive SEO optimization for the OpenFrame MSP platform, automatically handling authentication state and global UI components.
