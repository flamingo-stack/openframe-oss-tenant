This is the root layout component for the OpenFrame Next.js application that defines the overall HTML structure, metadata, and global providers for the entire application.

## Key Components

- **Metadata Configuration**: Comprehensive SEO metadata including Open Graph and Twitter card support
- **Font Integration**: Custom fonts (`azeretMono`, `dmSans`) with CSS variable support
- **Global Providers**: QueryClient for data fetching and RouteGuard for authentication
- **Conditional Features**: Authentication-dependent components loaded only when auth is enabled
- **Analytics & Monitoring**: Google Tag Manager integration and deployment initialization
- **Theme Support**: Dark mode theming with OpenFrame branding

## Usage Example

```typescript
// This layout wraps all pages in the application
// Pages automatically inherit this structure:

export default function HomePage() {
  return (
    <div>
      {/* Content automatically wrapped by RootLayout */}
      <h1>Welcome to OpenFrame</h1>
      {/* Has access to QueryClient, RouteGuard, Toaster, etc. */}
    </div>
  )
}

// Font variables are available throughout the app:
<div className="font-body"> {/* Uses dmSans */}
<div className="font-mono"> {/* Uses azeretMono */}
```

The layout enforces dynamic rendering to prevent SSG issues with client-side routing and includes comprehensive meta tags optimized for MSP (Managed Service Provider) audiences. All global styles, fonts, and essential providers are initialized here to ensure consistent functionality across the application.
