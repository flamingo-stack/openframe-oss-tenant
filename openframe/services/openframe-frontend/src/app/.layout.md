Root layout component for Next.js application that provides the HTML structure, metadata, and global providers for the OpenFrame MSP platform.

## Key Components

- **Metadata Configuration**: SEO-optimized metadata including Open Graph and Twitter cards
- **Font Loading**: Custom fonts (Azeret Mono, DM Sans) with variable declarations
- **Global Providers**: 
  - `QueryClientProvider` - React Query state management
  - `RouteGuard` - Authentication and route protection
  - `DeploymentInitializer` - Environment setup
  - `GraphQLIntrospectionInitializer` - GraphQL schema initialization
- **Development Tools**: `DevTicketObserver` for dev environment ticket tracking
- **Analytics**: Google Tag Manager integration
- **UI Components**: Toast notifications and loading skeleton

## Usage Example

```typescript
// This layout wraps all pages automatically in Next.js App Router
// Pages inherit the providers and styling:

export default function HomePage() {
  return (
    <div>
      {/* Page content automatically has access to: */}
      {/* - React Query client */}
      {/* - Authentication context */}
      {/* - Global CSS and fonts */}
      {/* - Toast notifications */}
    </div>
  )
}
```

The layout forces dynamic rendering to prevent SSG issues with client-side features and conditionally enables authentication components based on the app mode configuration.
