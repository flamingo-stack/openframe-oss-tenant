This is the root layout component for the OpenFrame MSP platform, defining the application shell with SEO metadata, authentication handling, and core UI providers.

## Key Components

- **Metadata Configuration**: Complete SEO setup with Open Graph, Twitter cards, and favicon support
- **Font Integration**: Custom fonts (Azeret Mono, DM Sans) with CSS variables
- **Authentication System**: Conditional auth components (`DevTicketObserver`, `RouteGuard`) when auth is enabled
- **Provider Hierarchy**: Query client, route guard, and toast notification providers
- **Development Tools**: Google Tag Manager and deployment initialization for analytics
- **UI Shell**: Responsive layout with loading skeleton fallback

## Usage Example

```typescript
// This layout automatically wraps all pages in the application
// Pages are rendered inside the {children} prop with full provider context

// Example page component that benefits from this layout:
export default function DashboardPage() {
  return (
    <div>
      <h1>MSP Dashboard</h1>
      {/* Has access to query client, auth context, and toast notifications */}
    </div>
  )
}

// Metadata is automatically applied to all pages unless overridden:
export const metadata = {
  title: 'Custom Page Title' // Will become "Custom Page Title | OpenFrame"
}
```

The layout enforces dynamic rendering, applies dark theme by default, and provides a complete application shell with proper SEO metadata for the OpenFrame MSP platform.
