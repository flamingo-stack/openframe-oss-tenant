This is the root layout component for the OpenFrame application, defining the base HTML structure, metadata, and global providers for all pages in the Next.js application.

## Key Components

- **Metadata Configuration**: Complete SEO setup including OpenGraph, Twitter cards, and favicons for OpenFrame branding
- **Font Loading**: Custom fonts (Azeret Mono and DM Sans) loaded via CSS variables
- **Authentication System**: Conditional rendering of auth-related components when authentication is enabled
- **Global Providers**: Query client provider for data fetching and route guard for navigation protection
- **Performance Optimization**: Forces dynamic rendering and includes suspense boundaries for loading states

## Usage Example

```typescript
// This layout automatically wraps all pages in your Next.js app
// Pages inherit the metadata and global providers:

// app/dashboard/page.tsx
export default function DashboardPage() {
  // This page automatically has access to:
  // - QueryClient for data fetching
  // - Route protection via RouteGuard
  // - Global fonts and styling
  // - OpenFrame metadata
  return <div>Dashboard content</div>
}

// Custom page metadata can override defaults:
export const metadata = {
  title: 'Dashboard', // Becomes "Dashboard | OpenFrame"
  description: 'Custom page description'
}
```

The layout includes essential OpenFrame branding, sets up dark theme by default, and provides a complete foundation for MSP-focused functionality with proper SEO optimization and performance considerations.
