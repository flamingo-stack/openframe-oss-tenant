Next.js root layout component that provides the foundational structure and configuration for the OpenFrame MSP platform application.

## Key Components

- **Metadata Configuration**: SEO-optimized metadata for OpenFrame with Open Graph and Twitter card support
- **Font Integration**: Azeret Mono and DM Sans font loading with CSS variable exports
- **Conditional Authentication**: Auth-related components only render when authentication is enabled
- **Layout Structure**: Responsive flex layout with skeleton loading states
- **Provider Hierarchy**: Query client, route guards, and environment script providers

## Usage Example

```typescript
// This layout automatically wraps all pages in the app
// Pages inherit the layout structure and providers

// Example page component receives the layout context:
export default function DashboardPage() {
  return (
    <div>
      <h1>MSP Dashboard</h1>
      {/* Page content here inherits fonts, providers, and layout */}
    </div>
  )
}

// The layout provides:
// - OpenFrame branding and SEO
// - Authentication guards (when enabled)
// - Query client for data fetching
// - Toast notifications
// - Google Analytics integration
```

**Key Features:**
- Forces dynamic rendering to prevent SSG issues with search parameters
- Conditional rendering based on authentication mode
- Comprehensive favicon and manifest configuration
- Skeleton loading states for better perceived performance
- Environment-aware base URL configuration for metadata
