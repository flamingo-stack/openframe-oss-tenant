Main Next.js layout component that configures the root HTML structure, metadata, and provider context for the OpenFrame application. It handles authentication, styling, analytics, and runtime environment setup with proper SEO optimization.

## Key Components

- **Metadata Configuration**: Comprehensive SEO metadata including OpenGraph, Twitter cards, and favicon setup
- **Provider Wrappers**: QueryClient for data fetching, RouteGuard for authentication, and runtime environment scripts
- **Authentication Components**: DevTicketObserver and GraphQLIntrospectionInitializer for auth-enabled deployments
- **Analytics Integration**: GoogleTagManager for tracking and DeploymentInitializer for app setup
- **UI Framework**: Custom fonts (Azeret Mono, DM Sans), dark mode styling, and Toaster notifications

## Usage Example

```typescript
// This layout wraps all pages in the Next.js app
// Applied automatically to all routes in the application

// The layout provides:
// 1. SEO metadata for MSP-focused content
// 2. Authentication context when enabled
// 3. Global UI providers and styling
// 4. Runtime environment configuration

// Environment variables used:
const appUrl = process.env.NEXT_PUBLIC_APP_URL || 'https://openframe.ai'

// Key features:
// - Force dynamic rendering to prevent SSG issues
// - Conditional auth components based on app mode
// - Suspense boundaries for loading states
// - OpenFrame-specific branding and theming
```

The layout enforces OpenFrame branding with MSP-specific messaging ("Swap bloated vendor tools for open ones") and provides the foundational infrastructure for the AI-driven platform's user interface and functionality.
