Next.js 14 app router root layout that provides the foundational structure and providers for the OpenFrame MSP platform application.

## Key Components

- **Metadata Configuration**: Comprehensive SEO metadata including OpenGraph, Twitter cards, and OpenFrame-specific branding
- **Font Integration**: Custom fonts (`azeretMono`, `dmSans`) from the design system
- **Authentication Provider**: Conditional `DevTicketObserver` and auth guards when authentication is enabled
- **Global Providers**: Query client, route guards, and deployment initialization
- **Analytics Integration**: Google Tag Manager for tracking and analytics
- **App Shell**: Suspense-wrapped layout with skeleton loading state

## Usage Example

```typescript
// This layout automatically wraps all app routes
// Children components receive the full provider context

// Example page component that benefits from this layout:
export default function Dashboard() {
  // Has access to:
  // - QueryClient for data fetching
  // - Authentication context
  // - Route protection
  // - Global styling and fonts
  
  return (
    <div>
      <h1>OpenFrame Dashboard</h1>
      {/* Content automatically inherits styling and providers */}
    </div>
  )
}

// The layout forces dynamic rendering to prevent SSG issues
// with useSearchParams and other dynamic features
```

The layout ensures all pages have consistent branding, authentication flow, error handling, and performance optimizations while maintaining OpenFrame's AI-driven MSP platform identity.
