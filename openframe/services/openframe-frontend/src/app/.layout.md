This is the Next.js 14 root layout component for OpenFrame, serving as the foundational wrapper for the entire application with comprehensive SEO metadata, authentication handling, and provider setup.

## Key Components

- **Metadata Configuration**: Complete SEO setup with OpenGraph, Twitter cards, and favicon management
- **Font Integration**: Custom fonts (`azeretMono`, `dmSans`) from the design system
- **Provider Wrappers**: QueryClient for data fetching and RouteGuard for authentication
- **Conditional Components**: Auth-enabled features like DevTicketObserver and GraphQL introspection
- **Analytics Integration**: Google Tag Manager and deployment tracking
- **Suspense Boundaries**: Loading states with AppShellSkeleton fallback

## Usage Example

```typescript
// This layout automatically wraps all pages in the app
// Pages inherit the metadata and provider context:

// app/dashboard/page.tsx
export default function DashboardPage() {
  // Has access to QueryClient, authentication state, and routing guards
  return (
    <div>
      <h1>Dashboard</h1>
      {/* Content automatically gets proper layout structure */}
    </div>
  )
}

// Metadata can be overridden in individual pages:
export const metadata: Metadata = {
  title: 'Dashboard', // Becomes "Dashboard | OpenFrame"
  description: 'Custom page description'
}
```

The layout enforces dynamic rendering, sets up dark mode by default, and provides a responsive foundation with proper accessibility attributes and viewport configuration for the OpenFrame MSP platform.
