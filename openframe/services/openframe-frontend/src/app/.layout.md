This is the root layout component for OpenFrame's Next.js application, defining the HTML structure, metadata, and global providers for the entire MSP platform.

## Key Components

- **Metadata Configuration**: Complete SEO setup with OpenGraph, Twitter cards, and favicon definitions optimized for MSP industry keywords
- **Font Loading**: Custom fonts (`azeretMono`, `dmSans`) with CSS variable integration
- **Global Providers**: Query client, route guards, and authentication components wrapped around the application
- **Conditional Auth**: Authentication components only load when auth is enabled via `isAuthEnabled()`
- **Development Tools**: Dev ticket observer and GraphQL introspection for development environments
- **Analytics**: Google Tag Manager integration for tracking and insights

## Usage Example

```typescript
// This layout automatically wraps all pages in the OpenFrame app
// Pages are rendered within the children prop:

// app/dashboard/page.tsx
export default function DashboardPage() {
  return (
    <div>
      {/* This content is automatically wrapped by RootLayout */}
      <h1>MSP Dashboard</h1>
    </div>
  )
}

// The layout provides:
// - SEO metadata for MSP-focused content
// - Authentication guards and observers
// - Global toast notifications via Toaster
// - Responsive font loading and dark theme
// - Query client for GraphQL/REST operations
```

The layout forces dynamic rendering to prevent SSG issues with search parameters and includes comprehensive metadata targeting the managed service provider market with OpenFrame branding.
