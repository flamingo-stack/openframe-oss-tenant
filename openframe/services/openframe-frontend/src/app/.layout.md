A Next.js 14 root layout component that provides the foundational HTML structure and global configuration for the OpenFrame application, including metadata, authentication, and provider setup.

## Key Components

- **Metadata Configuration**: Comprehensive SEO setup with OpenGraph, Twitter cards, and favicon configurations
- **Global Providers**: QueryClient, RouteGuard, and authentication components
- **Font Setup**: Custom font variables (Azeret Mono, DM Sans) with dark theme defaults
- **Conditional Authentication**: Auth-enabled features load only when authentication is active
- **Performance Optimizations**: Dynamic rendering, Suspense boundaries, and skeleton loading states

## Usage Example

```typescript
// This layout wraps all pages in the app
// Pages automatically inherit:
export default function MyPage() {
  return (
    <div>
      {/* Already wrapped with QueryClientProvider, RouteGuard, etc. */}
      <h1>My Page Content</h1>
    </div>
  )
}

// Metadata is automatically applied to all routes
// Can be overridden in individual page components:
export const metadata = {
  title: 'Custom Page Title', // Becomes "Custom Page Title | OpenFrame"
  description: 'Custom description for this page'
}
```

The layout enforces dynamic rendering across all routes and provides a consistent foundation with proper error boundaries, loading states, and global UI components like the Toaster for notifications.
