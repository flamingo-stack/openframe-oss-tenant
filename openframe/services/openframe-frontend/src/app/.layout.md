Root layout component that configures the global HTML structure and application-wide providers for the OpenFrame MSP platform. It sets up SEO metadata, authentication guards, analytics, and core UI components.

## Key Components

- **Metadata Configuration**: SEO-optimized meta tags with OpenGraph and Twitter card support
- **Font Setup**: Custom fonts (Azeret Mono, DM Sans) with CSS variable integration
- **Provider Hierarchy**: Query client, route guard, and authentication providers
- **Analytics Integration**: Google Tag Manager and deployment tracking
- **Global Styles**: Core UI styles and theme configuration with dark mode support
- **Authentication**: Conditional auth components based on app mode

## Usage Example

```typescript
// This is the root layout that wraps all pages
// All pages automatically inherit:
// - SEO metadata
// - Authentication state
// - Global styling
// - Provider context

// Example page that uses this layout:
export default function DashboardPage() {
  return (
    <div>
      {/* This content is wrapped by RootLayout */}
      <h1>MSP Dashboard</h1>
      {/* Has access to QueryClient, auth state, etc. */}
    </div>
  )
}

// Font classes are available via CSS variables:
// className="font-mono" (Azeret Mono)
// className="font-body" (DM Sans)
```

The layout enforces dynamic rendering to prevent SSG issues and provides comprehensive MSP platform branding with proper favicon sets and manifest configuration.
