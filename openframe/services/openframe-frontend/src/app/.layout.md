This is the root layout component for the OpenFrame MSP platform, providing the foundational structure and metadata for all pages in the Next.js application.

## Key Components

- **Metadata Configuration**: Comprehensive SEO metadata including OpenGraph, Twitter cards, and favicon definitions for the OpenFrame brand
- **Font Integration**: Custom font loading using Azeret Mono and DM Sans typefaces
- **Authentication Guards**: Conditional rendering of auth-related components (`DevTicketObserver`, `RouteGuard`) based on app mode
- **Global Providers**: Query client provider for data fetching and state management
- **Analytics Integration**: Google Tag Manager setup for tracking and analytics
- **Dynamic Rendering**: Forced dynamic rendering to prevent SSG issues with search parameters

## Usage Example

```typescript
// This layout wraps all pages automatically in Next.js app directory
// Pages inherit the structure and providers:

export default function HomePage() {
  // Page content has access to:
  // - QueryClient for data fetching
  // - Route protection via RouteGuard
  // - Global toast notifications via Toaster
  // - Proper SEO metadata inheritance
  
  return (
    <div>
      <h1>Welcome to OpenFrame</h1>
      {/* Page content */}
    </div>
  )
}
```

The layout ensures consistent theming, authentication flows, and performance optimizations across the entire OpenFrame application while maintaining proper SEO metadata for MSP-focused content.
