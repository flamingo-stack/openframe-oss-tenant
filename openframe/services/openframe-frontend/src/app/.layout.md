This Next.js root layout component establishes the foundational structure and configuration for the OpenFrame MSP platform application. It configures SEO metadata, initializes core services, and sets up the component hierarchy with authentication and routing guards.

## Key Components

- **Metadata Configuration**: Comprehensive SEO setup with OpenGraph, Twitter cards, favicons, and manifest files
- **Font Integration**: Custom fonts (Azeret Mono, DM Sans) with CSS variables
- **Service Initializers**: Google Tag Manager, deployment setup, and GraphQL introspection
- **Authentication Components**: Dev ticket observer and conditional auth-enabled features
- **Layout Structure**: Query client provider, route guard, and suspense boundaries with skeleton loading

## Usage Example

```typescript
// This layout automatically wraps all pages in the application
// Pages are rendered within the children prop structure:

export default function HomePage() {
  return (
    <div>
      <h1>Welcome to OpenFrame</h1>
      {/* Content is automatically wrapped with authentication, 
          routing guards, and error boundaries */}
    </div>
  )
}

// The layout provides these automatic features:
// - SEO metadata with OpenFrame branding
// - Dark theme with custom fonts
// - Authentication state management
// - Query client for GraphQL/REST operations
// - Toast notifications via Toaster component
// - Responsive viewport configuration
```

The layout forces dynamic rendering to prevent SSG issues with `useSearchParams` and conditionally loads authentication-related components based on the app mode configuration.
