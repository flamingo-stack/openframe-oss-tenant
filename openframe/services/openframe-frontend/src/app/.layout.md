Root layout component for the OpenFrame MSP platform that configures the application's HTML structure, metadata, and global providers with authentication-aware initialization.

## Key Components

- **Metadata Configuration**: Complete SEO setup with OpenGraph, Twitter cards, and favicons for the OpenFrame MSP platform
- **Font System**: Integrates Azeret Mono and DM Sans custom fonts with CSS variables
- **Provider Stack**: Wraps the app with QueryClient for data fetching and RouteGuard for authentication
- **Conditional Authentication**: Loads dev tools and GraphQL introspection only when auth is enabled
- **Global Initialization**: Sets up deployment tracking, Google Tag Manager, and runtime environment variables

## Usage Example

This layout is automatically used by Next.js for all pages:

```typescript
// The layout wraps all page components
export default function HomePage() {
  return (
    <div>
      <h1>Welcome to OpenFrame</h1>
      {/* This content will be wrapped by the RootLayout */}
    </div>
  )
}

// Custom metadata can override the defaults
export const metadata: Metadata = {
  title: 'Custom Page Title', // Becomes "Custom Page Title | OpenFrame"
  description: 'Page-specific description'
}
```

The layout enforces dynamic rendering, applies dark theme by default, and provides a responsive foundation with proper viewport configuration and hydration handling for the OpenFrame MSP platform.
