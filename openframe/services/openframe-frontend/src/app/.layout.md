Next.js 14 root layout component that provides the foundational structure, metadata, and provider setup for the OpenFrame MSP platform application.

## Key Components

- **Metadata Configuration**: Complete SEO setup with Open Graph, Twitter cards, and favicon management
- **Font Integration**: Custom fonts (Azeret Mono, DM Sans) with CSS variable support
- **Provider Stack**: QueryClient, RouteGuard, and authentication providers
- **Development Tools**: Dev ticket observer and GraphQL introspection for development environments
- **Analytics Integration**: Google Tag Manager and deployment tracking
- **Responsive Design**: Viewport optimization and dark theme configuration

## Usage Example

```typescript
// This layout wraps all pages in the application
// Children are automatically injected by Next.js routing

// Example of how metadata is inherited:
// Page: /dashboard -> Title: "Dashboard | OpenFrame"
// Page: /settings -> Title: "Settings | OpenFrame"

// The layout provides these features to all pages:
// - Authentication routing via RouteGuard
// - GraphQL query client access
// - Toast notifications via Toaster
// - Consistent theming and fonts
// - SEO optimization for MSP-focused content
```

The layout enforces dynamic rendering to prevent SSG issues with search parameters and conditionally loads authentication components based on the app mode configuration. All pages inherit the OpenFrame branding, MSP-focused SEO metadata, and the complete provider ecosystem for state management and routing.
