This file defines the root layout component for the OpenFrame application, providing essential metadata, global styles, and core providers for the entire MSP platform.

## Key Components

- **Metadata Configuration**: Comprehensive SEO metadata including Open Graph, Twitter cards, and favicon setup
- **Global Providers**: QueryClientProvider for API state management and RouteGuard for authentication
- **Development Tools**: DevTicketObserver and GraphQLIntrospectionInitializer for development workflow
- **Analytics & Tracking**: Google Tag Manager integration and deployment initialization
- **UI Foundation**: Global CSS imports, custom fonts (Azeret Mono, DM Sans), and toast notifications

## Usage Example

```typescript
// This layout automatically wraps all pages in the application
// Pages are rendered within the children prop with proper providers

// Example page that benefits from the layout:
export default function DashboardPage() {
  return (
    <div className="p-6">
      <h1 className="font-mono text-2xl">MSP Dashboard</h1>
      {/* Automatically has access to QueryClient, auth state, etc. */}
    </div>
  )
}

// The layout provides:
// - SEO metadata for MSP-focused content
// - Authentication routing protection
// - Global error/success toast notifications
// - Consistent dark theme styling
```

The layout enforces dynamic rendering to prevent SSG issues and conditionally loads authentication components based on the app mode configuration.
