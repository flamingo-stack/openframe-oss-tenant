Root layout component for the OpenFrame application that provides the foundational HTML structure, metadata configuration, and global providers for authentication, data fetching, and UI components.

## Key Components

- **Metadata Configuration** - Complete SEO setup including Open Graph, Twitter Cards, and favicon management
- **Font Integration** - Custom Azeret Mono and DM Sans font loading with CSS variables
- **Provider Stack** - QueryClient for data fetching, RouteGuard for authentication, and environment script injection
- **Conditional Rendering** - Auth-dependent components loaded only when authentication is enabled
- **Global Styling** - Dark theme enforcement and OpenFrame design system integration

## Usage Example

```typescript
// This layout automatically wraps all pages in the app
// Pages are rendered as children within the RouteGuard
function HomePage() {
  return (
    <div>
      <h1>Welcome to OpenFrame</h1>
      {/* Page content here */}
    </div>
  )
}

// Layout provides:
// - SEO metadata for OpenFrame branding
// - Authentication flow via RouteGuard
// - Global toast notifications via Toaster
// - Dark theme with custom fonts
// - Analytics tracking via GoogleTagManager
```

The layout enforces dynamic rendering to prevent SSG issues with search parameters and includes comprehensive metadata for MSP-focused SEO optimization. All global providers and initializers are properly suspended for optimal loading performance.
