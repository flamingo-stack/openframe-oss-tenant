OpenFrame's root layout component that configures the application shell with metadata, fonts, authentication, and global providers for the MSP platform.

## Key Components

- **Metadata Configuration**: SEO-optimized metadata including OpenGraph and Twitter cards for MSP-focused branding
- **Font Loading**: Custom fonts (Azeret Mono, DM Sans) for consistent typography
- **Authentication System**: Conditional dev ticket observer and GraphQL introspection for auth-enabled environments
- **Global Providers**: Query client provider for API state management and route guarding
- **Analytics Integration**: Google Tag Manager for tracking and deployment initialization
- **Responsive Layout**: Mobile-optimized viewport with dark theme and proper hydration handling

## Usage Example

This layout automatically wraps all pages in the OpenFrame application:

```typescript
// All pages inherit this layout structure
export default function HomePage() {
  return (
    <div>
      <h1>Welcome to OpenFrame</h1>
      {/* Content is automatically wrapped with providers and guards */}
    </div>
  )
}

// The layout provides these global features:
// - SEO metadata for MSP-focused search visibility
// - Authentication guards and session management
// - Global UI components like toast notifications
// - Responsive design with proper font loading
```

The layout ensures consistent branding, proper authentication handling, and optimal performance with dynamic rendering to support client-side features like search parameters.
