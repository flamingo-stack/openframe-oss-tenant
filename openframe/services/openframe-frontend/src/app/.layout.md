This is the root layout component for the OpenFrame application, providing the foundational HTML structure, metadata configuration, and provider setup for the entire Next.js application.

## Key Components

- **Metadata Configuration**: Complete SEO setup with OpenGraph, Twitter cards, and favicons for the OpenFrame MSP platform
- **Provider Setup**: QueryClient, RouteGuard, and conditional auth components wrapped around the application
- **Font Configuration**: Custom fonts (Azeret Mono, DM Sans) applied via CSS variables
- **Development Tools**: Google Tag Manager, deployment initializer, and dev ticket observer for development workflow
- **Dynamic Rendering**: Forces dynamic rendering to prevent SSG issues with search parameters

## Usage Example

```typescript
// This layout automatically wraps all pages in the application
// Children are rendered within the RouteGuard and Suspense boundaries

// Example page structure:
export default function HomePage() {
  return (
    <div>
      <h1>Welcome to OpenFrame</h1>
      {/* This content is automatically wrapped by RootLayout */}
    </div>
  )
}

// The layout provides:
// - SEO metadata for MSP-focused content
// - Authentication guard when auth is enabled
// - Global state management via QueryClient
// - Consistent theming with dark mode and custom fonts
```

The layout ensures all pages have proper SEO metadata, authentication handling, and consistent styling while providing development tools and error boundaries through suspense fallbacks.
