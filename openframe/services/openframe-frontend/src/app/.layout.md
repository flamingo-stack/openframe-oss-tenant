A Next.js root layout component that provides the foundational structure and metadata for the OpenFrame application, including authentication guards, analytics tracking, and responsive skeleton loading.

## Key Components

- **Metadata Configuration** - Complete SEO setup with OpenGraph, Twitter cards, and favicons for OpenFrame branding
- **Font Integration** - Custom fonts (`azeretMono`, `dmSans`) from the design system
- **Authentication System** - Conditional rendering of `DevTicketObserver` and auth-protected components
- **Query Management** - React Query provider for GraphQL and API state management
- **Route Protection** - `RouteGuard` wrapper for authentication-based navigation control
- **Analytics Integration** - Google Tag Manager for tracking and deployment initialization
- **Loading States** - Suspense boundaries with `AppShellSkeleton` for smooth UX

## Usage Example

This layout automatically wraps all pages in the Next.js application:

```typescript
// Any page component automatically receives this layout
export default function HomePage() {
  return (
    <div>
      <h1>Welcome to OpenFrame</h1>
      {/* Content rendered within the layout structure */}
    </div>
  )
}

// The layout provides:
// - SEO metadata for MSP-focused branding
// - Dark theme with custom fonts
// - Authentication state management
// - GraphQL client setup
// - Analytics tracking
```

The layout forces dynamic rendering (`export const dynamic = 'force-dynamic'`) to prevent SSG issues with client-side routing and search parameters, ensuring consistent behavior across the OpenFrame platform.
