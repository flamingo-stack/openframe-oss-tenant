Root layout component for OpenFrame that provides the foundational HTML structure, metadata, and application-wide providers for the AI-driven MSP platform.

## Key Components

- **Metadata Configuration**: SEO-optimized metadata with OpenGraph and Twitter cards for MSP positioning
- **Font Integration**: Custom typography using Azeret Mono and DM Sans fonts
- **Provider Stack**: QueryClient, RouteGuard, and authentication components
- **Conditional Features**: Auth-enabled features like DevTicketObserver and GraphQL introspection
- **Global Styling**: CSS imports for OpenFrame core styles and Tailwind classes
- **Analytics Integration**: Google Tag Manager and deployment tracking

## Usage Example

```typescript
// This layout automatically wraps all pages in the Next.js app
// Children components receive the full provider context

export default function HomePage() {
  return (
    <div className="p-6">
      <h1>Welcome to OpenFrame</h1>
      {/* Component has access to QueryClient, routing, and auth context */}
    </div>
  )
}

// Metadata is automatically applied to all routes
// Custom metadata can override defaults using Next.js metadata API
export const metadata = {
  title: 'Custom Page Title' // Will render as "Custom Page Title | OpenFrame"
}
```

The layout enforces dynamic rendering to prevent SSG issues with authentication and provides a responsive foundation with proper SEO metadata for the OpenFrame MSP platform.
