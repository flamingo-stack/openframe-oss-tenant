Root layout component for the OpenFrame Next.js application that provides the foundational HTML structure, SEO metadata, and essential providers for authentication, routing, and data fetching.

## Key Components

- **Metadata Configuration**: Complete SEO setup with OpenGraph, Twitter cards, and favicons
- **Font Integration**: Custom fonts (Azeret Mono, DM Sans) with CSS variables
- **Provider Hierarchy**: Query client, route guard, and authentication components
- **Environment Setup**: Runtime environment variables and deployment initialization
- **Analytics**: Google Tag Manager integration for tracking
- **Responsive Design**: Mobile-optimized viewport settings and dark theme

## Usage Example

This layout wraps all pages in the Next.js app router:

```typescript
// Automatically applied to all routes in app directory
// Provides these features to child components:

// Access to fonts via CSS variables
<div className="font-mono"> {/* Uses Azeret Mono */}
<div className="font-body">  {/* Uses DM Sans */}

// Query client for data fetching
const { data } = useQuery({ queryKey: ['example'] })

// Route protection (when auth enabled)
// Automatically redirects unauthenticated users

// Toast notifications
import { toast } from '@lib/openframe-core-ui'
toast.success('Action completed')
```

The layout forces dynamic rendering to prevent SSG issues with search parameters and includes comprehensive OpenFrame branding with the tagline "Swap bloated vendor tools for open ones. Automate the boring crap. Take your margin back."
