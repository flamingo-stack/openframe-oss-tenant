This is the root layout component for the OpenFrame Next.js application, serving as the foundation for all pages with SEO metadata, authentication, and core application setup.

## Key Components

- **Metadata Configuration**: Comprehensive SEO setup with Open Graph, Twitter cards, and favicon definitions for the OpenFrame MSP platform
- **Layout Structure**: HTML shell with dark theme, custom fonts (Azeret Mono, DM Sans), and responsive viewport configuration
- **Authentication System**: Conditional rendering of auth-enabled components including `DevTicketObserver` and `GraphQLIntrospectionInitializer`
- **Core Providers**: 
  - `QueryClientProvider` for data fetching
  - `RouteGuard` for access control
  - `DeploymentInitializer` for app setup
- **Development Tools**: Google Tag Manager integration and runtime environment script injection
- **UI Components**: Global toaster notifications and app shell skeleton for loading states

## Usage Example

```typescript
// This layout automatically wraps all pages in the app
// Pages receive the full context and styling setup

// Example page that inherits from this layout
export default function DashboardPage() {
  return (
    <div className="p-6">
      <h1>MSP Dashboard</h1>
      {/* Content inherits font-body class and dark theme */}
    </div>
  )
}
```

The layout forces dynamic rendering (`export const dynamic = 'force-dynamic'`) to prevent SSG issues with `useSearchParams` and ensures proper hydration with `suppressHydrationWarning` attributes.
