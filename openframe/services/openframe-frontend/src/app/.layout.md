This is the root layout component for the OpenFrame application, serving as the foundation for all pages with comprehensive SEO metadata, authentication handling, and essential app initialization.

## Key Components

**Configuration & Metadata:**
- `dynamic = 'force-dynamic'` - Forces dynamic rendering to prevent SSG issues
- `metadata` - Complete SEO configuration with OpenGraph, Twitter cards, and favicons
- Font loading via `azeretMono` and `dmSans` variables

**Core Providers & Initializers:**
- `QueryClientProvider` - React Query setup for data fetching
- `RouteGuard` - Authentication and route protection
- `DeploymentInitializer` - App deployment configuration
- `GoogleTagManager` - Analytics tracking
- `GraphQLIntrospectionInitializer` - GraphQL schema initialization (auth-gated)
- `DevTicketObserver` - Development ticket monitoring (auth-gated)

**UI Components:**
- `Toaster` - Global toast notifications
- `AppShellSkeleton` - Loading state for the main application shell

## Usage Example

```typescript
// This layout wraps all pages automatically in Next.js App Router
// Pages inherit all providers and configurations:

// pages/dashboard/page.tsx
export default function DashboardPage() {
  // Already wrapped with QueryClientProvider, RouteGuard, etc.
  return <div>Dashboard content</div>
}

// The layout provides:
// - SEO metadata for MSP-focused branding
// - Authentication state management
// - Global UI components (toasts, loading states)
// - GraphQL and React Query setup
// - Analytics tracking
```

The layout uses conditional rendering based on `isAuthEnabled()` to load authentication-specific components only when needed, optimizing performance for deployments without authentication requirements.
