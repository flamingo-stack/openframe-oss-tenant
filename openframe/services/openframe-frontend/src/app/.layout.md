Main layout component for the OpenFrame application that configures the Next.js App Router layout, metadata, fonts, and essential providers for the AI-driven MSP platform.

## Key Components

- **RootLayout**: Main layout wrapper with HTML structure and providers
- **Metadata Configuration**: SEO metadata for OpenFrame including OpenGraph and Twitter cards
- **Font Integration**: Custom fonts (Azeret Mono, DM Sans) from the typography system
- **Provider Stack**: Query client, authentication, routing, and analytics providers
- **Dynamic Rendering**: Forces dynamic rendering to prevent SSG issues with search parameters

## Usage Example

```typescript
// This layout automatically wraps all pages in the Next.js app
// The component structure provides:

// 1. SEO-optimized metadata
export const metadata: Metadata = {
  title: 'OpenFrame - AI-Driven Open-Source OS for MSPs',
  description: 'Swap bloated vendor tools for open ones...'
}

// 2. Provider hierarchy
<QueryClientProvider>
  <RouteGuard>
    <Suspense fallback={<AppShellSkeleton />}>
      {children} {/* Your page content */}
    </Suspense>
  </RouteGuard>
</QueryClientProvider>

// 3. Conditional auth components
{isAuthEnabled() && (
  <Suspense>
    <DevTicketObserver />
    <GraphQLIntrospectionInitializer />
  </Suspense>
)}
```

The layout includes Google Tag Manager integration, deployment initialization, toast notifications, and proper favicon configuration for the OpenFrame brand identity.
