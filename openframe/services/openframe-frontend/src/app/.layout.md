Next.js root layout component that provides the foundational structure and metadata for the OpenFrame MSP platform, configuring global styles, authentication guards, and essential providers.

## Key Components

- **Metadata Configuration**: Complete SEO setup including OpenGraph, Twitter cards, favicons, and manifest
- **Font Integration**: Custom fonts (Azeret Mono, DM Sans) from shared library
- **Provider Hierarchy**: QueryClient, RouteGuard, and Suspense boundaries for data fetching and navigation
- **Conditional Auth Components**: DevTicketObserver and GraphQLIntrospectionInitializer when authentication is enabled
- **Global Initializers**: DeploymentInitializer, GoogleTagManager, and runtime environment script
- **App Shell Structure**: Responsive layout with skeleton loading states

## Usage Example

```typescript
// This layout automatically wraps all pages in your Next.js app
// No direct imports needed - Next.js uses it automatically

// The layout provides:
// - SEO metadata for OpenFrame branding
// - Dark mode styling with custom fonts
// - Authentication guards and state management
// - Global toast notifications
// - Responsive mobile viewport settings

// Pages render within this structure:
export default function HomePage() {
  return (
    <div>
      <h1>Welcome to OpenFrame</h1>
      {/* Content automatically wrapped by layout */}
    </div>
  )
}

// Environment variables used:
// - NEXT_PUBLIC_APP_URL: Base URL for metadata
// - Auth configuration determines conditional components
```

The layout enforces dynamic rendering to prevent static generation issues and provides comprehensive OpenFrame branding with proper MSP-focused metadata and social sharing optimization.
