Next.js 13+ root layout component that provides the foundation structure and metadata for the OpenFrame MSP platform application.

## Key Components

- **Metadata Configuration**: SEO-optimized meta tags, Open Graph, Twitter cards, and favicon setup for OpenFrame branding
- **Font Integration**: Custom font loading with `azeretMono` and `dmSans` variables
- **Authentication System**: Conditional auth components (`DevTicketObserver`, `GraphQLIntrospectionInitializer`) based on auth mode
- **Core Providers**: Query client provider for data fetching and route guard for access control
- **Analytics & Monitoring**: Google Tag Manager integration and deployment initialization
- **Layout Structure**: Dark theme HTML wrapper with responsive design and loading states

## Usage Example

This layout automatically wraps all pages in the Next.js application:

```typescript
// Any page component will be rendered within this layout
export default function HomePage() {
  return (
    <div>
      <h1>Welcome to OpenFrame</h1>
      {/* This content appears inside the layout's children prop */}
    </div>
  )
}

// The final rendered structure includes:
// - HTML with dark theme classes and custom fonts
// - Meta tags for SEO and social sharing
// - Authentication observers (if auth enabled)
// - Query client and route protection
// - Suspense boundaries with skeleton loading
// - Toast notifications system
```

The layout forces dynamic rendering (`export const dynamic = 'force-dynamic'`) to prevent static generation issues with search parameters and ensures proper hydration with auth-dependent components.
