Root Next.js layout component that bootstraps the OpenFrame application shell, configuring global metadata, provider hierarchy, and rendering infrastructure for all routes.

## Key Components

### `metadata` (exported constant)
Next.js `Metadata` object defining SEO, Open Graph, Twitter card, favicon set, and PWA manifest for the OpenFrame platform.

### `RootLayout` (default export)
The root `<html>` / `<body>` shell rendered for every route. Responsibilities:

| Layer | Component | Purpose |
|---|---|---|
| Analytics | `GoogleTagManager` | GTM injection |
| Runtime | `PublicEnvScript` | Exposes public env vars client-side |
| Embed | `EmbedShimRegistration` | Registers iframe/embed shims |
| Deployment | `DeploymentInitializer` | Boot-time deployment config |
| Data | `RelayProvider` + `QueryClientProvider` | GraphQL (Relay) + REST query state |
| Auth | `DevTicketObserver`, `GraphQlIntrospectionInitializer` | Auth-gated dev tooling and schema init |
| Realtime | `NatsAppProvider` | NATS messaging context |
| Features | `FeatureFlagsGate` | Feature flag evaluation |
| Notifications | `NotificationsDataProvider` | Global notification state |
| Routing | `RouteGuard` | Auth/access protection |
| Shell | `AppShellSkeleton` | Suspense fallback during hydration |
| Toasts | `Toaster` | Global toast notification outlet |

## Usage Example

```typescript
// This file is the Next.js App Router root layout.
// It is automatically applied to every route under `app/`.
// No manual import or instantiation is required.

// To extend metadata for a child route, export metadata from that route's page:
export const metadata: Metadata = {
  title: 'Tickets', // renders as "Tickets | OpenFrame" via the template
};
```

## Notes

- `dynamic = 'force-dynamic'` disables static generation globally to avoid `useSearchParams` SSG errors.
- Fonts (`azeretMono`, `dmSans`) are injected as CSS variables on `<html>` and consumed via Tailwind's `font-body` utility.
- `suppressHydrationWarning` on both `<html>` and `<body>` suppresses dark-mode class mismatch warnings during SSR hydration.
- Auth-dependent providers (`DevTicketObserver`, `GraphQlIntrospectionInitializer`) are conditionally rendered only when `isAuthEnabled()` returns `true`.
