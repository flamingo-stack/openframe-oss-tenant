Root layout component for the OpenFrame application that configures the HTML structure, metadata, and core providers for the MSP platform.

## Key Components

- **Metadata Configuration**: Complete SEO setup with OpenGraph, Twitter cards, and favicon configuration for OpenFrame branding
- **Font Setup**: Integrates Azeret Mono and DM Sans font families using Next.js font optimization
- **Core Providers**: 
  - `QueryClientProvider` for data fetching and caching
  - `RouteGuard` for authentication and route protection
  - `Toaster` for notification system
- **Conditional Components**: Auth-enabled features like `DevTicketObserver` and `GraphQLIntrospectionInitializer`
- **Analytics & Deployment**: Google Tag Manager integration and deployment initialization

## Usage Example

```typescript
// This layout automatically wraps all pages in the application
// Example page component that will be rendered within this layout
export default function HomePage() {
  return (
    <main className="container mx-auto px-4">
      <h1>Welcome to OpenFrame</h1>
      {/* Page content automatically gets Toaster, QueryClient, etc. */}
    </main>
  )
}

// The layout provides these features to all child components:
import { useToast } from '@lib/openframe-core-ui'
import { useQuery } from '@tanstack/react-query'

export function MyComponent() {
  const { toast } = useToast() // Available via Toaster in layout
  const { data } = useQuery(...) // Available via QueryClientProvider
  
  return <div>Component with layout features</div>
}
```

The layout enforces dynamic rendering with `force-dynamic` to prevent SSG issues and includes comprehensive metadata for MSP-focused SEO optimization.
