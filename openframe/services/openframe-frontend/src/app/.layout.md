Root layout component for OpenFrame's Next.js application that provides the foundational HTML structure, metadata configuration, and core application providers.

## Key Components

**Metadata Configuration:**
- SEO-optimized metadata with OpenGraph and Twitter card support
- Dynamic title template system with MSP-focused messaging
- Comprehensive favicon and icon configuration
- Responsive viewport settings with zoom controls

**Core Providers:**
- `QueryClientProvider` - React Query integration for data fetching
- `RouteGuard` - Authentication and route protection
- `DeploymentInitializer` - Application deployment setup
- `GoogleTagManager` - Analytics tracking integration

**Conditional Features:**
- `DevTicketObserver` - Development environment authentication handling
- `GraphQLIntrospectionInitializer` - GraphQL schema initialization (auth-enabled only)
- `AppShellSkeleton` - Loading state for application shell

## Usage Example

```typescript
// This layout wraps all pages in the Next.js application
// Pages automatically inherit the providers and metadata

// Example page component that benefits from the layout:
export default function DashboardPage() {
  return (
    <div className="p-6">
      <h1>MSP Dashboard</h1>
      {/* QueryClient and RouteGuard are available here */}
    </div>
  )
}

// The layout provides:
// - Authentication state management
// - GraphQL client setup
// - Consistent theming (dark mode, fonts)
// - SEO metadata for MSP-focused content
```

The layout enforces dynamic rendering (`force-dynamic`) to prevent SSG issues with client-side routing and search parameters, ensuring proper handling of authentication flows and dynamic content.
