Next.js 14 root layout component that sets up the foundational structure for OpenFrame, the AI-driven MSP platform. It configures SEO metadata, authentication, and global providers for the application.

## Key Components

- **Metadata Configuration** - Comprehensive SEO setup including OpenGraph, Twitter cards, and favicon management
- **Font Integration** - Custom fonts (Azeret Mono, DM Sans) loaded from the fonts library
- **Authentication System** - Conditional auth components (`DevTicketObserver`, `GraphQLIntrospectionInitializer`) based on auth mode
- **Core Providers** - Query client, route guards, and global state management
- **Performance Optimizations** - Dynamic rendering, suspense boundaries, and skeleton loading states

## Usage Example

```typescript
// This layout wraps all pages in the OpenFrame application
export default function Page() {
  return (
    <div>
      <h1>OpenFrame Dashboard</h1>
      {/* All pages inherit the layout's providers and styling */}
    </div>
  )
}

// The layout provides these global features:
// - Dark theme with custom fonts
// - Authentication handling
// - Query client for API calls
// - Toast notifications
// - Google Analytics tracking
```

The layout enforces dynamic rendering to prevent SSG issues with client-side routing and search parameters. All pages automatically receive the configured providers, authentication logic, and OpenFrame branding.
