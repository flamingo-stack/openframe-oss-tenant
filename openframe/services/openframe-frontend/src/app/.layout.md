Next.js root layout component that provides the foundational structure and global configuration for the OpenFrame MSP platform application. This layout sets up SEO metadata, font configuration, authentication guards, and essential app initialization components.

## Key Components

- **Metadata Configuration**: Comprehensive SEO setup with OpenGraph, Twitter cards, and favicons optimized for MSP audience
- **Font System**: Custom font loading with Azeret Mono and DM Sans via CSS variables
- **Authentication Integration**: Conditional auth components (DevTicketObserver, RouteGuard) based on app mode
- **Global Providers**: QueryClient for React Query and app-wide state management
- **Initialization Components**: Deployment setup, GraphQL introspection, and Google Tag Manager integration
- **Responsive Layout**: Mobile-optimized viewport and skeleton loading states

## Usage Example

This layout automatically wraps all pages in the Next.js app:

```typescript
// Automatically applied to all routes
// /app/dashboard/page.tsx
export default function DashboardPage() {
  return (
    <div>
      {/* Content inherits all layout providers and styling */}
      <h1>MSP Dashboard</h1>
    </div>
  )
}

// Custom fonts available via CSS variables
// Component styling
<div className="font-mono"> {/* Uses Azeret Mono */}
  <span className="font-body"> {/* Uses DM Sans */}
    OpenFrame Content
  </span>
</div>
```

The layout enforces dynamic rendering (`force-dynamic`) to prevent static generation issues with authentication and ensures proper hydration with React 18's concurrent features through strategic `suppressHydrationWarning` usage.
