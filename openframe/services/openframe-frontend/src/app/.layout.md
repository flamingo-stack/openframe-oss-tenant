A Next.js root layout component that defines the foundational structure, metadata, and providers for the OpenFrame MSP platform application. It handles authentication state, development tooling, and provides essential UI scaffolding with proper SEO optimization.

## Key Components

- **Metadata Configuration**: Complete SEO setup with OpenGraph, Twitter cards, and favicon definitions for OpenFrame branding
- **Authentication Integration**: Conditionally renders auth-related components (`DevTicketObserver`, `GraphQLIntrospectionInitializer`) based on app mode
- **Provider Hierarchy**: Wraps the application with `QueryClientProvider` and `RouteGuard` for data fetching and navigation protection
- **Development Tools**: Includes `DeploymentInitializer` and Google Tag Manager for monitoring and analytics
- **App Shell**: Provides loading skeleton and toast notifications through `Toaster` component

## Usage Example

```typescript
// This layout wraps all pages in the application
// Children are rendered within the RouteGuard and Suspense boundaries

export default function HomePage() {
  return (
    <div>
      <h1>Welcome to OpenFrame</h1>
      {/* Page content automatically inherits layout structure */}
    </div>
  )
}
```

The layout enforces dynamic rendering (`export const dynamic = 'force-dynamic'`) to prevent SSG issues with URL search parameters and ensures proper hydration with dark theme and custom fonts (`azeretMono`, `dmSans`).
