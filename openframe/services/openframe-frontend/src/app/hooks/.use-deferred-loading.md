A React hook that prevents loading state flicker by delaying the appearance of loaders and enforcing a minimum visible duration.

## Key Components

**`useDeferredLoading(isLoading, options?)`** — Main export. Wraps a boolean `isLoading` signal and returns a derived `showLoading` boolean governed by two timing constraints.

**`UseDeferredLoadingOptions`**
| Option | Default | Description |
|---|---|---|
| `delayMs` | `150ms` | Suppress loader if loading finishes before this threshold |
| `minDurationMs` | `300ms` | Once visible, keep loader shown for at least this long |

**Behavior — three cases:**
1. Load completes before `delayMs` → loader never shown (cache hit / instant response)
2. Load completes between `delayMs` and `delayMs + minDurationMs` → loader stays until minimum elapses
3. Load completes after `delayMs + minDurationMs` → loader hides immediately when loading ends

## Usage Example

```typescript
import { useDeferredLoading } from './use-deferred-loading';

function DataTable() {
  const { data, isLoading } = useQuery(fetchData);

  // Won't flicker for fast responses; won't flash-disappear for slow ones
  const showLoader = useDeferredLoading(isLoading);

  if (showLoader) return <Spinner />;
  return <Table data={data} />;
}

// Custom timing
const showLoader = useDeferredLoading(isLoading, {
  delayMs: 200,       // wait 200ms before showing
  minDurationMs: 500, // keep visible at least 500ms once shown
});
```

## Notes

- All timers are cleared on unmount to prevent state updates on unmounted components
- Re-entrant safe: a new load cycle while the loader is already visible cancels any pending hide without re-triggering the show delay
