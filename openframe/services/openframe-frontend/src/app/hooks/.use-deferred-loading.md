Prevents loading state flicker by deferring the appearance of loaders and enforcing a minimum visible duration, avoiding flash on fast responses or brief loading states.

## Key Components

### `useDeferredLoading(isLoading, options?): boolean`

Main hook export. Accepts a boolean `isLoading` flag and optional configuration, returns a derived `showLoading` boolean that should drive UI visibility.

**Options:**

| Parameter | Default | Description |
|-----------|---------|-------------|
| `delayMs` | `150` | Suppress loader if loading completes before this threshold |
| `minDurationMs` | `300` | Minimum time loader stays visible once shown |

**Behavior cases:**

| Scenario | Result |
|----------|--------|
| Finishes before `delayMs` | Loader never shown |
| Finishes between `delayMs` and `delayMs + minDurationMs` | Loader held visible until minimum elapses |
| Finishes after `delayMs + minDurationMs` | Loader hides immediately when loading ends |

## Usage Example

```typescript
import { useDeferredLoading } from './use-deferred-loading';

function DataTable({ query }: { query: string }) {
  const { data, isLoading } = useFetchData(query);

  // Suppress flash on cache hits; hold loader for at least 300ms if shown
  const showLoader = useDeferredLoading(isLoading, {
    delayMs: 150,
    minDurationMs: 300,
  });

  return (
    <div>
      {showLoader && <Spinner />}
      {data && <Table rows={data} />}
    </div>
  );
}
```

> Timers are cleaned up automatically on unmount, preventing state updates on unmounted components.
