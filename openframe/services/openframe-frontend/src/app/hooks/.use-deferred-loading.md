A React hook that prevents loading state flicker by delaying loader appearance and enforcing a minimum visible duration.

## Key Components

### `useDeferredLoading(isLoading, options?): boolean`

Main export. Wraps a boolean `isLoading` signal and returns a debounced `showLoading` boolean with three behavioral cases:

1. **Fast response** (`< delayMs`) — loader never shown (cache hits, instant responses)
2. **Medium response** (`delayMs` to `delayMs + minDurationMs`) — loader shown until minimum duration elapses
3. **Slow response** (`> delayMs + minDurationMs`) — loader hides immediately when loading ends

### `UseDeferredLoadingOptions`

| Option | Default | Description |
|--------|---------|-------------|
| `delayMs` | `150ms` | Delay before showing loader |
| `minDurationMs` | `300ms` | Minimum time loader stays visible once shown |

## Usage Example

```typescript
import { useDeferredLoading } from './use-deferred-loading';

function DataTable({ query }: { query: string }) {
  const { data, isLoading } = useFetchData(query);

  // Won't flash on fast responses; won't flicker on medium-speed responses
  const showLoader = useDeferredLoading(isLoading);

  // Custom thresholds
  const showLoaderCustom = useDeferredLoading(isLoading, {
    delayMs: 200,
    minDurationMs: 500,
  });

  return showLoader ? <Spinner /> : <Table data={data} />;
}
```

## Internal State

| Ref | Purpose |
|-----|---------|
| `showTimerRef` | Tracks the pending "show" timer |
| `hideTimerRef` | Tracks the pending "hide" timer |
| `shownAtRef` | Records when the loader became visible |
| `isShownRef` | Tracks current visibility without triggering re-renders |

Timers are cleared on unmount to prevent state updates on unmounted components.
