Fetches and caches the active AI model configuration from the backend, exposing it via two React Query hooks for use in client components.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `AiModel` | Interface | Minimal model shape: `provider` and `displayName` |
| `useAiModel` | Hook | Returns the active `AiModel` or `null`; no loading state |
| `useAiModelStatus` | Hook | Returns `{ aiModel, isLoading }` — use when a skeleton is needed during fetch |

Both hooks share the same React Query cache key (`ai-configuration-model`), so only **one network request** is ever made regardless of how many components call either hook.

> Cache is considered fresh for **5 minutes** and will not refetch on window focus.

## Usage Example

```typescript
// Simple read — no loading state needed
function ModelBadge() {
  const aiModel = useAiModel();
  if (!aiModel) return null;
  return <span>{aiModel.displayName}</span>;
}

// With loading state — prevents layout shift
function ModelBadgeWithSkeleton() {
  const { aiModel, isLoading } = useAiModelStatus();

  if (isLoading) return <Skeleton className="h-4 w-24" />;
  if (!aiModel) return null;

  return <span>{aiModel.displayName}</span>;
}
```

Use `useAiModel` for lightweight reads where layout shift is acceptable; prefer `useAiModelStatus` in header/toolbar components where a skeleton placeholder matches the final element size.
