Fetches and caches the active AI model configuration from the chat API, exposing two hooks for consuming provider/display name data in client components.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `AiModel` | Interface | Shape returned to consumers — `provider` and `displayName` strings |
| `useAiModel` | Hook | Returns the active `AiModel` or `null`; minimal API for components that only need the value |
| `useAiModelStatus` | Hook | Same shared cache as `useAiModel`, additionally exposes `isLoading` for skeleton/loading-state rendering |

> `AI_MODEL_QUERY_OPTIONS` uses a 5-minute `staleTime` and disables `refetchOnWindowFocus`, so both hooks share a single cached request with no redundant network calls.

## Usage Example

```typescript
// Simple read — no loading state needed
function ModelBadge() {
  const aiModel = useAiModel();
  if (!aiModel) return null;

  return <span>{aiModel.displayName}</span>;
}

// Loading-aware — render a skeleton while config is in flight
function ModelHeader() {
  const { aiModel, isLoading } = useAiModelStatus();

  if (isLoading) return <Skeleton className="h-5 w-32" />;
  if (!aiModel) return null;

  return <h2>{aiModel.displayName} ({aiModel.provider})</h2>;
}
```
