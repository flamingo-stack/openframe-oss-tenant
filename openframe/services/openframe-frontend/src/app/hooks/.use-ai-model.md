Fetches and caches the active AI model configuration from the server, exposing it via two React Query hooks for use across client components.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `AiModel` | Interface | Shape returned to consumers: `provider` and `displayName` |
| `useAiModel` | Hook | Returns the active `AiModel` (or `null`); minimal API |
| `useAiModelStatus` | Hook | Same cached query as `useAiModel`, but also exposes `isLoading` for skeleton rendering |

Both hooks share the `'ai-configuration-model'` query key — a single network request is made regardless of how many components call either hook.

**Cache settings:** 5-minute `staleTime`, `refetchOnWindowFocus` disabled.

## Usage Example

```typescript
// Simple read — just need the model name
function ModelBadge() {
  const aiModel = useAiModel();
  if (!aiModel) return null;
  return <span>{aiModel.displayName}</span>;
}

// Loading-aware — prevent layout shift while config is in flight
function ModelBadgeWithSkeleton() {
  const { aiModel, isLoading } = useAiModelStatus();

  if (isLoading) return <Skeleton className="h-4 w-24" />;
  if (!aiModel) return null;

  return <span>{aiModel.displayName}</span>;
}
```

> Use `useAiModel` when the component renders fine without the value. Use `useAiModelStatus` when you need to show a placeholder during the initial fetch to avoid layout shift.
