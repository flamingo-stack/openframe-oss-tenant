Provides safe browser back-navigation utilities for Next.js apps, using the Navigation API (`window.navigation.canGoBack`) to decide between `router.back()` and a deterministic fallback route.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `navCanGoBack` | `function` | Probes `window.navigation.canGoBack` defensively; returns `false` for SSR, unsupported browsers, or when no safe back entry exists |
| `useSafeBack` | React hook | Returns a callback that calls `router.back()` when safe, otherwise `router.push(fallback)` |
| `safeBackOrReplace` | `function` | Post-submit helper that calls `router.back()` when safe, otherwise `router.replace(fallback)` to keep the form out of history |

## Usage Example

```typescript
// Hook usage — general back button
function BackButton() {
  const goBack = useSafeBack('/dashboard');
  return <button onClick={goBack}>Back</button>;
}

// After a form save — pop form from history when possible
async function handleSubmit(router: AppRouter) {
  await saveRecord();
  safeBackOrReplace(router, '/records');
}

// Direct probe — conditionally render back button
function ConditionalBack() {
  if (!navCanGoBack()) return null;
  return <button onClick={() => router.back()}>Back</button>;
}
```

## Behavior Matrix

| Scenario | `navCanGoBack()` | Result |
|----------|-----------------|--------|
| Normal in-app navigation | `true` | `router.back()` |
| Fresh tab / direct URL paste | `false` | Navigates to `fallback` |
| Unsupported browser | `false` | Navigates to `fallback` |
| SSR / `window` undefined | `false` | Navigates to `fallback` |

> **Browser support:** `window.navigation.canGoBack` requires Chrome 102+, Edge 102+, or Safari 16.4+. Older browsers silently fall back to the deterministic route.
