React hook for copying text to the clipboard with toast notifications and a temporary `copied` state indicator.

## Key Components

- **`useCopyToClipboard(options?)`** — Main hook export
- **`UseCopyToClipboardOptions`** — Configuration interface with fields:
  - `successTitle` / `successDescription` — Toast content on success (defaults: `"Copied"` / `"Copied to clipboard"`)
  - `errorTitle` / `errorDescription` — Toast content on failure (defaults: `"Copy failed"` / `"Could not copy to clipboard"`)
  - `resetDelay` — Milliseconds before `copied` resets to `false` (default: `2000`)
- **Returns** `{ copy, copied }`:
  - `copy(text: string)` — Async function that writes to the clipboard
  - `copied` — Boolean state, `true` for `resetDelay`ms after a successful copy

## Usage Example

```typescript
import { useCopyToClipboard } from './use-copy-to-clipboard';

function CopyButton({ value }: { value: string }) {
  const { copy, copied } = useCopyToClipboard({
    successTitle: 'Done!',
    successDescription: 'Token copied to clipboard',
    resetDelay: 3000,
  });

  return (
    <button onClick={() => copy(value)}>
      {copied ? 'Copied!' : 'Copy'}
    </button>
  );
}
```

> **Note:** Relies on `navigator.clipboard` (requires HTTPS or `localhost`) and the `useToast` hook from `@flamingo-stack/openframe-frontend-core`.
