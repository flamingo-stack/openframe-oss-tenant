React hook that copies text to the clipboard, shows a toast notification on success or failure, and resets its `copied` state after a configurable delay.

## Key Components

- **`useCopyToClipboard(options?)`** — Main hook export. Accepts `UseCopyToClipboardOptions` for customizing toast messages and reset timing.
- **`UseCopyToClipboardOptions`** — Interface with optional fields: `successTitle`, `successDescription`, `errorTitle`, `errorDescription`, `resetDelay` (default: `2000`ms).
- **`copy(text)`** — Async callback that writes to the clipboard via `navigator.clipboard.writeText`.
- **`copied`** — Boolean state indicating whether a copy operation just succeeded.

## Usage Example

```typescript
import { useCopyToClipboard } from './use-copy-to-clipboard';

function ApiKeyDisplay({ apiKey }: { apiKey: string }) {
  const { copy, copied } = useCopyToClipboard({
    successTitle: 'API Key Copied',
    successDescription: 'Your API key is in the clipboard.',
    resetDelay: 3000,
  });

  return (
    <button onClick={() => copy(apiKey)}>
      {copied ? 'Copied!' : 'Copy API Key'}
    </button>
  );
}
```

> **Note:** This hook requires a browser environment with `navigator.clipboard` support and must be used within a `'use client'` component in Next.js App Router.
