React hook and Zustand store for detecting and caching the current deployment environment (cloud, self-hosted, or development) across the application.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `useDeployment` | Hook | Primary hook returning deployment state, loading status, and convenience booleans |
| `getDeployment` | Helper | Static accessor for `DeploymentInfo` outside React components |
| `isCloudDeployment` | Helper | Static boolean check for cloud environment |
| `isSelfHostedDeployment` | Helper | Static boolean check for self-hosted environment |
| `isDevelopmentDeployment` | Helper | Static boolean check for development environment |
| `getDeploymentType` | Helper | Static accessor returning the `DeploymentType` string |
| `useDeploymentStore` | Store | Internal Zustand store (not exported); initialized once, DevTools-enabled |

## Usage Example

**In a React component:**

```typescript
import { useDeployment } from '@/hooks/use-deployment';

function FeatureFlag() {
  const { isCloud, isSelfHosted, isDevelopment, isLoading, hostname } = useDeployment();

  if (isLoading) return null;

  return (
    <span>
      {isCloud && `Cloud (${hostname})`}
      {isSelfHosted && 'Self-Hosted'}
      {isDevelopment && 'Development'}
    </span>
  );
}
```

**Outside React (e.g., API utilities):**

```typescript
import { isCloudDeployment, getDeploymentType } from '@/hooks/use-deployment';

function buildApiUrl(path: string) {
  if (isCloudDeployment()) {
    return `https://api.flamingo.run${path}`;
  }
  return `http://localhost:3000${path}`;
}
```

## Notes

- Detection runs **once** via a `setTimeout(0)` to guarantee browser context; subsequent calls return the cached Zustand state.
- `reset()` is exposed for testing or forced re-detection scenarios.
- Static helpers may return `null` / default values if called before the hook has initialized.
