Detects and caches the current deployment environment (cloud, self-hosted, or development) using a Zustand store, exposing both a React hook and static helper functions.

## Key Components

**`useDeploymentStore`** — Internal Zustand store (with Redux DevTools support) that runs `detectDeployment()` once and caches the result globally. Prevents redundant detection via an `isInitialized` guard.

**`useDeployment()`** *(hook)* — Primary React hook. Triggers initialization on first mount (deferred via `setTimeout` to guarantee browser context), tracks a loading state, and returns convenience boolean flags alongside the full `DeploymentInfo` object.

**Static Helpers** — Utility functions for non-component contexts (middleware, utilities, server actions):

| Function | Returns |
|---|---|
| `getDeployment()` | `DeploymentInfo \| null` |
| `getDeploymentType()` | `DeploymentType` |
| `isCloudDeployment()` | `boolean` |
| `isSelfHostedDeployment()` | `boolean` |
| `isDevelopmentDeployment()` | `boolean` |

> **Note:** Static helpers may return `null` / fallback defaults if called before the hook has initialized.

## Usage Example

```typescript
// Inside a React component
import { useDeployment } from '@/hooks/use-deployment';

function FeatureFlag() {
  const { isCloud, isSelfHosted, isDevelopment, isLoading, hostname } = useDeployment();

  if (isLoading) return null;

  return (
    <span>
      {isCloud && `Cloud (${hostname})`}
      {isSelfHosted && 'Self-Hosted'}
      {isDevelopment && 'Development'}
    </span>
  );
}

// Outside a component (e.g. in an API utility)
import { isCloudDeployment, getDeploymentType } from '@/hooks/use-deployment';

if (isCloudDeployment()) {
  console.log('Running on cloud, type:', getDeploymentType());
}
```
