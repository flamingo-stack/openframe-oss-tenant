Detects and caches the current deployment environment (cloud, self-hosted, or development) using a Zustand store, exposing both a React hook and static helpers for use across the application.

## Key Components

**`useDeploymentStore`** *(internal Zustand store)*
Global store holding `DeploymentInfo`, initialization status, and actions (`initialize`, `reset`). Integrates with Redux DevTools via the `devtools` middleware. Detection runs once and is cached.

**`useDeployment()`** *(primary hook)*
React hook that triggers deployment detection on first mount (deferred via `setTimeout` to guarantee browser context) and returns the full detection result plus convenience booleans.

**Static helpers** *(non-component use)*

| Function | Returns |
|---|---|
| `getDeployment()` | `DeploymentInfo \| null` |
| `getDeploymentType()` | `DeploymentType` |
| `isCloudDeployment()` | `boolean` |
| `isSelfHostedDeployment()` | `boolean` |
| `isDevelopmentDeployment()` | `boolean` |

## Usage Example

```typescript
// Inside a React component
import { useDeployment } from '@/hooks/use-deployment';

export function FeatureFlag() {
  const { isCloud, isSelfHosted, isDevelopment, isLoading, hostname } = useDeployment();

  if (isLoading) return <Spinner />;

  return (
    <div>
      {isCloud && <CloudBadge host={hostname} />}
      {isSelfHosted && <SelfHostedBadge />}
      {isDevelopment && <DevWarningBanner />}
    </div>
  );
}

// Outside a component (e.g. in a utility or server action)
import { isCloudDeployment, getDeploymentType } from '@/hooks/use-deployment';

if (isCloudDeployment()) {
  // Apply cloud-specific logic
}

const type = getDeploymentType(); // 'cloud' | 'self-hosted' | 'development'
```

> **Note:** Static helpers may return `null` or default values (`'development'`) if called before the hook has initialized. Prefer `useDeployment()` inside components where possible.
