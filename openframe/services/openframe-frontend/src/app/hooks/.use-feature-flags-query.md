Fetches frontend feature flags via GraphQL and syncs the results into the global `useFeatureFlagsStore` Zustand store, with graceful fallback to defaults on error.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `featureFlagsQueryKey` | `const` | Stable TanStack Query cache key `['featureFlags']` |
| `useFeatureFlagsQuery` | `hook` | Fetches and hydrates feature flags; accepts `{ enabled: boolean }` to conditionally run |

## Usage Example

```typescript
// Conditionally fetch flags once the user session is ready
function AppBootstrap({ isAuthenticated }: { isAuthenticated: boolean }) {
  const { isLoading } = useFeatureFlagsQuery({ enabled: isAuthenticated });

  if (isLoading) return <Spinner />;
  return <App />;
}

// Read flags anywhere via the store
const isNewDashboardEnabled = useFeatureFlagsStore(
  s => s.flags['new-dashboard']?.enabled ?? false
);
```

## Behavior Notes

- **Cache:** Results are considered fresh for **30 minutes** (`staleTime`) and will not re-fetch on window focus.
- **Retry:** Retries once on failure before falling back.
- **Error fallback:** On query failure, `setLoaded()` is called so the app proceeds with default flag values rather than blocking.
- **Store sync:** On successful fetch, `setFlags(data)` pushes all flags into the Zustand store, making them available globally without prop drilling.
