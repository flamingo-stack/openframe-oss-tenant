Fetches and synchronizes feature flags from the GraphQL API into the global feature flags store using React Query.

## Key Components

- **`featureFlagsQueryKey`** — Stable query key constant `['featureFlags']` for cache management and invalidation
- **`useFeatureFlagsQuery()`** — Primary hook that fetches feature flags via GraphQL and syncs results to `useFeatureFlagsStore`
- **`FE_FEATURE_FLAGS_QUERY`** — GraphQL query fetching `name` + `enabled` pairs filtered by `FEATURE_FLAG_NAMES`

## Behavior

- Fetches only the flags listed in `FEATURE_FLAG_NAMES` (compile-time constant list)
- Detects trial expiration from GraphQL error extensions via `detectTrialExpiredFromGraphqlErrors`
- On successful fetch, calls `setFlags()` to hydrate the store
- On error, logs a warning and calls `setLoaded()` so consumers fall back to defaults rather than blocking indefinitely
- Caches results for **30 minutes** (`staleTime`), no refetch on window focus, 1 retry on failure

## Usage Example

```typescript
// Typically called once at the app/auth boundary
function AppShell({ isAuthenticated }: { isAuthenticated: boolean }) {
  const { isLoading } = useFeatureFlagsQuery({ enabled: isAuthenticated });

  if (isLoading) return <Spinner />;
  return <App />;
}

// Consuming flags downstream (no direct dependency on this hook)
import { useFeatureFlagsStore } from '@/stores/feature-flags-store';

function MyFeature() {
  const flags = useFeatureFlagsStore(s => s.flags);
  return flags['my-feature']?.enabled ? <NewUI /> : <OldUI />;
}
```

> The `enabled` parameter gates execution — pass `false` until the user is authenticated to avoid unauthenticated GraphQL calls.
