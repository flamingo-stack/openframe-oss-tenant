Fetches and synchronizes feature flags from the GraphQL API into the global feature flags store using TanStack Query.

## Key Components

- **`featureFlagsQueryKey`** — Stable query key constant `['featureFlags']` for cache management and invalidation
- **`useFeatureFlagsQuery()`** — Hook that fetches feature flags via `feFeatureFlags` GraphQL query and syncs results into `useFeatureFlagsStore`
- **`FE_FEATURE_FLAGS_QUERY`** — GraphQL query document requesting `name` and `enabled` fields for all flags listed in `FEATURE_FLAG_NAMES`

## Behavior

- Calls `setFlags()` on successful fetch to populate the store
- Calls `setLoaded()` on error so the app can proceed with defaults instead of blocking
- Runs `detectTrialExpiredFromGraphqlErrors()` to intercept subscription lock signals embedded in GraphQL errors
- Retries once on failure; caches results for 30 minutes; does not refetch on window focus

## Usage Example

```typescript
function AppBootstrap({ isAuthenticated }: { isAuthenticated: boolean }) {
  const { isLoading } = useFeatureFlagsQuery({ enabled: isAuthenticated });

  if (isLoading) return <Spinner />;
  return <App />;
}
```
