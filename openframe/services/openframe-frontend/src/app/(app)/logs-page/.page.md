A Next.js page component that renders the Logs view, wrapping the `LogsTable` component in a responsive padded container.

## Key Components

- **`Logs`** — Default export; the top-level page component for the logs route
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time (required for live log data)
- **`LogsTable`** — Imported child component that handles log data fetching and display

## Usage Example

```typescript
// Rendered automatically by Next.js App Router at the /logs route.
// No manual instantiation needed.

// To extend the page with a header or filters:
export default function Logs() {
  return (
    <div className="p-4 md:p-6 space-y-6">
      <h1>System Logs</h1>
      <LogsTable />
    </div>
  );
}
```

## Notes

- Uses `'use client'` directive — runs in the browser despite `force-dynamic`, which affects the route segment's caching behavior
- Responsive padding via Tailwind: `p-4` on mobile, `p-6` on `md+` breakpoints
- Vertical spacing between child elements managed by `space-y-6`
