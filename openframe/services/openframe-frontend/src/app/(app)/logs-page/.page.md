A Next.js client-side page component that renders the application logs view.

## Key Components

- **`Logs`** — Default export page component that wraps the `LogsTable` component in a padded container
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time (useful for live log data)

## Usage Example

```typescript
// Automatically rendered by Next.js App Router at the /logs route
// No manual instantiation needed — just navigate to /logs

// The page renders:
<div className="p-4 md:p-6 space-y-6">
  <LogsTable />
</div>
```

> This page opts out of static caching via `force-dynamic`, ensuring log data is always fresh on each request.
