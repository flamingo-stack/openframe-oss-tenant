Client-side page component that renders the logs viewer interface within a responsive padded layout.

## Key Components

- **`Logs`** — Default export. Page component that wraps the `LogsTable` component in a responsive container.
- **`dynamic = 'force-dynamic'`** — Next.js export that disables static generation, ensuring the page is always server-rendered on each request (no caching).

## Usage Example

```typescript
// Rendered automatically by Next.js App Router
// Route: /logs (or wherever this page.tsx is nested)

import Logs from './page';

// Used internally by Next.js — no manual instantiation needed
<Logs />
```
