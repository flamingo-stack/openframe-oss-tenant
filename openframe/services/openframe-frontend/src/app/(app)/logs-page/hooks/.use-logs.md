React Query hooks for fetching paginated log entries and log filter options via GraphQL, with built-in error toasting and cursor-based infinite scroll support.

## Key Components

- **`useLogs(filters, search)`** — Infinite query hook that fetches paginated log entries (20 per page) using cursor-based pagination. Flattens all pages into a single `logs` array and exposes `fetchNextPage`, `hasNextPage`, and `resetToFirstPage`.
- **`useLogFilters(filter)`** — Standard query hook that fetches available filter options (severity, tool type, organizations) with a 60s stale time.
- **`logsQueryKeys`** — Structured cache key factory for consistent React Query cache invalidation/lookup.
- **`transformLogEntry(logEntry)`** — Internal transformer that maps flat backend fields (`hostname`, `organizationName`, `organizationId`) into a nested `device` object structure.

## Usage Example

```typescript
import { useLogs, useLogFilters } from './use-logs';

function LogsPage() {
  const { logs, isLoading, hasNextPage, fetchNextPage, resetToFirstPage } = useLogs(
    { severity: 'ERROR', organizationId: 'org_123' },
    'timeout'
  );

  const { logFilters } = useLogFilters({ organizationId: 'org_123' });

  return (
    <>
      {/* Render logs and filter dropdowns from logFilters.severities, etc. */}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>Load More</button>
      )}
      <button onClick={resetToFirstPage}>Refresh</button>
    </>
  );
}
```

> **Note:** Both hooks automatically display a destructive toast notification on fetch failure — no additional error handling is required in the consuming component.
