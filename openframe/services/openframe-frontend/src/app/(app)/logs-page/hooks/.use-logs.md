React Query hooks for fetching paginated log entries and log filter options via GraphQL, with automatic toast notifications on error.

## Key Components

### `logsQueryKeys`
Cache key factory for React Query — scopes keys by list filters/search and filter dropdowns.

### `useLogs(filters, search)`
Infinite-scroll hook that fetches paginated log entries (20 per page) from the GraphQL API.

**Returns:**
| Field | Type | Description |
|---|---|---|
| `logs` | `LogEntry[]` | Flattened entries across all loaded pages |
| `isLoading` | `boolean` | Initial fetch in progress |
| `isFetchingNextPage` | `boolean` | Next page fetch in progress |
| `hasNextPage` | `boolean` | More pages available |
| `fetchNextPage` | `function` | Load next page |
| `error` | `string \| null` | Error message if fetch failed |
| `resetToFirstPage` | `function` | Invalidate & reset cursor to page 1 |

### `useLogFilters(filter)`
Single-query hook that retrieves available filter options (severity, tool type, organizations).

### `transformLogEntry` *(internal)*
Maps flat backend fields (`hostname`, `organizationName`, `organizationId`) onto a nested `device` object expected by the UI.

## Usage Example

```typescript
import { useLogs, useLogFilters } from './use-logs';

function LogsPage() {
  const { logFilters } = useLogFilters({ organizationId: 'org-123' });

  const { logs, isLoading, hasNextPage, fetchNextPage } = useLogs(
    { severity: 'error', organizationId: 'org-123' },
    'timeout'
  );

  if (isLoading) return <Spinner />;

  return (
    <>
      {logs.map(log => <LogRow key={log.id} log={log} />)}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>Load more</button>
      )}
    </>
  );
}
```

> **Cache behaviour:** Log list entries are considered fresh for **30 seconds**; filter options for **60 seconds**. Errors surface automatically as destructive toasts — no additional error handling required at the call site.
