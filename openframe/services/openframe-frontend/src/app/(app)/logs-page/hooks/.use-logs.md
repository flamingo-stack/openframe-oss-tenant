React hooks for fetching paginated log entries and log filter options via GraphQL, with built-in error toasting and query cache management.

## Key Components

**`logsQueryKeys`** — Structured query key factory for TanStack Query cache management across log list and filter queries.

**`transformLogEntry()`** — Internal utility that normalizes flat backend fields (`hostname`, `organizationName`, `organizationId`) into a nested `device` object on each `LogEntry`.

**`useLogs(filters, search)`** — Infinite-scroll hook that fetches paginated log entries (20 per page) using `useInfiniteQuery`. Returns flattened logs, pagination controls, loading state, and a `resetToFirstPage` helper.

**`useLogFilters(filter)`** — Fetches available filter options (severity levels, tool types, organizations) using `useQuery` with a 60s stale time.

## Usage Example

```typescript
import { useLogs, useLogFilters } from './use-logs';

function LogsView() {
  const { logs, isLoading, hasNextPage, fetchNextPage } = useLogs(
    { severity: 'error', organizationId: 'org_123' },
    'timeout'
  );

  const { logFilters } = useLogFilters({ organizationId: 'org_123' });

  if (isLoading) return <Spinner />;

  return (
    <>
      <FilterBar options={logFilters} />
      <LogList entries={logs} />
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>Load more</button>
      )}
    </>
  );
}
```

> Both hooks automatically display a destructive toast notification on fetch failure via `useToast`. Cache entries remain fresh for 30s (`useLogs`) and 60s (`useLogFilters`) before background refetching.
