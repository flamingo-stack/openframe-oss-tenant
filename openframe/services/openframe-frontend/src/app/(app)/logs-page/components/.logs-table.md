Renders a paginated, filterable data table for system logs using Relay for GraphQL data fetching, supporting per-device and per-organization scoping with an inline drawer for quick log inspection.

## Key Components

- **`LogsTable`** — Public-facing component (with `forwardRef`) that wires backend filters, search debouncing, and exposes a `refresh()` handle via `LogsTableRef`
- **`LogsTableContent`** — Inner Relay-powered component (must live inside `<Suspense>`) that executes `logsTableRelayQuery` and `logsTableRelayFragment` for paginated log fetching
- **`LogsTableRef`** — Ref interface exposing a single `refresh()` method for parent-initiated reloads
- **`UiLogEntry`** — Normalized log shape used by the table columns (id, timestamp, status, source, device, description)
- **`columns`** — `ColumnDef<UiLogEntry>[]` defining Log ID, Status, Tool, Source, Log Details, and a quick-view actions column
- **`LogDrawer`** — Side drawer rendered when a row is selected, showing full log details
- **`ToolBadge`** — Displays the originating tool icon per log row

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from '@/app/components/logs-table';
import { useRef } from 'react';

function DeviceLogs({ deviceId }: { deviceId: string }) {
  const tableRef = useRef<LogsTableRef>(null);

  return (
    <>
      <button onClick={() => tableRef.current?.refresh()}>
        Refresh
      </button>
      <LogsTable
        ref={tableRef}
        deviceId={deviceId}
        organizationId="org-123" // hides org filter column
      />
    </>
  );
}
```

## Notes

- Pagination loads 20 records per page (`LOGS_PAGE_SIZE = 20`) using Relay's `loadNext`
- Search input is debounced before being passed to the GraphQL query
- Setting `organizationId` locks the table to a single org and hides the organization column filter
- Severity variants map `ERROR → error`, `WARNING → warning`, `CRITICAL → critical`, `INFO → grey`
