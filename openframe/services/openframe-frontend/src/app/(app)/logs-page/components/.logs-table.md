Renders a paginated, filterable data table for log entries using Relay for data fetching. Supports per-device or per-organization scoping, inline log drawer preview, and external navigation to full log details.

## Key Components

- **`LogsTable`** — Public-facing component (with `forwardRef`) that manages search, filter state, and debouncing. Wraps `LogsTableContent` in a `Suspense` boundary and exposes a `refresh()` handle via `LogsTableRef`.
- **`LogsTableContent`** — Inner Relay-powered component. Executes `logsTableRelayQuery` via `useLazyLoadQuery`, handles cursor-based pagination via `usePaginationFragment`, and builds the column definitions.
- **`LogsTableRef`** — Imperative handle interface exposing a `refresh()` method for parent components to trigger a network refetch.
- **`UiLogEntry`** — Normalized row shape derived from raw GraphQL nodes, used as the `ColumnDef<UiLogEntry>` generic.
- **GraphQL Fragments** — `logsTableRelayQuery` (entry query) and `logsTableRelayFragment` (refetchable pagination fragment with `@connection`).

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table';
import { useRef } from 'react';

function DeviceLogsPage({ deviceId }: { deviceId: string }) {
  const tableRef = useRef<LogsTableRef>(null);

  return (
    <>
      <button onClick={() => tableRef.current?.refresh()}>
        Reload Logs
      </button>
      <LogsTable
        ref={tableRef}
        deviceId={deviceId}
        organizationId="org_abc123"
      />
    </>
  );
}
```

## Column Structure

| Column | Filter Source | Notes |
|--------|--------------|-------|
| Log ID / Timestamp | — | Combined cell |
| Status | `severities` | Severity-mapped `Tag` variant |
| Tool | `toolTypes` | `ToolBadge` icon |
| Source / Device | `organizations` | Hidden when `organizationId` is locked |
| Log Details | — | 3-line truncated summary |
| Quick View | — | Opens `LogDrawer` or new tab |
