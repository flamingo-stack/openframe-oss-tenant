React component that renders a paginated, filterable data table for system/tool logs using Relay for data fetching, with support for log detail drawer and external navigation.

## Key Components

### Exports
- **`LogsTable`** (default, `forwardRef`) — Main table component with optional `deviceId` and `organizationId` props
- **`LogsTableRef`** — Interface exposing a `refresh()` imperative handle

### Internal Components
- **`LogsTableContent`** — Inner Relay-powered component (must live inside `<Suspense>`); handles query, pagination, filtering, and column definitions

### GraphQL
- **`logsTableRelayQuery`** — Root query fetching logs + available filter options (`toolTypes`, `eventTypes`, `severities`, `organizations`)
- **`logsTableRelayFragment`** — Refetchable, paginated fragment on `Query` keyed to `logsTableRelay_logs`

### Key Behaviors
- **Pagination** — Cursor-based via `loadNext`, page size of 20
- **Filters** — Server-side (`backendFilters`) + client-side multi-select (`tableFilters`) for severity, tool type, and organization
- **Search** — Debounced search string passed to backend
- **Severity mapping** — `ERROR → error`, `WARNING → warning`, `INFO → grey`, `CRITICAL → critical`
- **Organization lock** — When `organizationId` is provided, the organization column filter is hidden

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table';
import { useRef } from 'react';

function LogsPage() {
  const tableRef = useRef<LogsTableRef>(null);

  return (
    <>
      <button onClick={() => tableRef.current?.refresh()}>
        Refresh
      </button>
      {/* All logs, multi-org */}
      <LogsTable ref={tableRef} />

      {/* Scoped to a single device */}
      <LogsTable ref={tableRef} deviceId="device-abc-123" />

      {/* Locked to one organization (hides org filter) */}
      <LogsTable ref={tableRef} organizationId="org-xyz-456" />
    </>
  );
}
```
