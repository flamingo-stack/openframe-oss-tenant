Defines TypeScript interfaces for the log management system, covering log entries, edges, and filter structures used across the logging pipeline.

## Key Components

| Interface | Description |
|-----------|-------------|
| `LogEntry` | Core log record with severity levels, device context, and optional metadata |
| `LogEdge` | GraphQL-style edge wrapper containing a `LogEntry` node |
| `LogFilters` | Available filter options for the log viewer UI |
| `LogFilterInput` | Input parameters for querying/filtering log entries |

### Severity Levels

`LogEntry.severity` accepts: `DEBUG` · `INFO` · `WARNING` · `ERROR` · `CRITICAL`

## Usage Example

```typescript
import type { LogEntry, LogFilterInput, LogFilters } from './log.types';

// Constructing a log entry
const entry: LogEntry = {
  toolEventId: 'evt_abc123',
  eventType: 'AGENT_TASK',
  ingestDay: '2024-01-15',
  toolType: 'rmm',
  severity: 'ERROR',
  summary: 'Disk usage exceeded 90%',
  timestamp: '2024-01-15T10:30:00Z',
  hostname: 'workstation-42',
  organizationId: 'org_xyz',
  organizationName: 'Acme Corp',
  device: { id: 'dev_001', name: 'workstation-42' },
  metadata: { diskUsage: 92, threshold: 90 },
};

// Building a filter query
const filters: LogFilterInput = {
  severities: ['ERROR', 'CRITICAL'],
  toolTypes: ['rmm', 'psa'],
  organizationIds: ['org_xyz'],
};

// Populating filter UI options
const availableFilters: LogFilters = {
  toolTypes: ['rmm', 'psa', 'backup'],
  eventTypes: ['AGENT_TASK', 'ALERT', 'AUDIT'],
  severities: ['DEBUG', 'INFO', 'WARNING', 'ERROR', 'CRITICAL'],
  organizations: [{ id: 'org_xyz', name: 'Acme Corp' }],
};
```

> `device` is typed as `Partial<Device>` to accommodate partially hydrated records returned from the backend before full device resolution.
