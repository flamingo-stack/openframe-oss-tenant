Defines TypeScript interfaces for the log management system, covering log entries, edges, and filter structures used across the logging pipeline.

## Key Components

- **`LogEntry`** — Core interface representing a single log record with fields for event classification (`eventType`, `toolType`), severity levels, optional device/user associations, and a transformed `device` object following the `Device` type pattern
- **`LogEdge`** — GraphQL-style edge wrapper containing a `LogEntry` node, used for cursor-based pagination
- **`LogFilters`** — Describes available filter options (tool types, event types, severities, organizations) typically used to populate UI filter dropdowns
- **`LogFilterInput`** — Input interface for querying/filtering logs by severity, tool type, organization, device, or user

## Usage Example

```typescript
import type { LogEntry, LogFilterInput, LogFilters } from './log.types';

const entry: LogEntry = {
  toolEventId: 'evt_001',
  eventType: 'agent.action',
  ingestDay: '2024-01-15',
  toolType: 'ZABBIX',
  severity: 'WARNING',
  summary: 'High CPU usage detected',
  timestamp: '2024-01-15T10:30:00Z',
  hostname: 'server-01',
  organizationName: 'Acme Corp',
};

const filterInput: LogFilterInput = {
  severities: ['WARNING', 'ERROR', 'CRITICAL'],
  toolTypes: ['ZABBIX'],
  organizationIds: ['org_123'],
};
```

## Severity Levels

| Level | Use Case |
|-------|----------|
| `DEBUG` | Verbose diagnostic output |
| `INFO` | General operational events |
| `WARNING` | Non-critical anomalies |
| `ERROR` | Recoverable failures |
| `CRITICAL` | System-impacting failures |
