GraphQL query definitions for fetching log data, including filter metadata, paginated log lists, and detailed log entries.

## Key Components

| Export | Description |
|--------|-------------|
| `GET_LOG_FILTERS_QUERY` | Fetches available filter options (tool types, event types, severities, organizations) |
| `GET_LOGS_QUERY` | Fetches a paginated, searchable list of log entries with cursor-based pagination |
| `GET_LOG_DETAILS_QUERY` | Fetches full details of a single log entry by composite key |

## Usage Example

```typescript
import {
  GET_LOG_FILTERS_QUERY,
  GET_LOGS_QUERY,
  GET_LOG_DETAILS_QUERY,
} from './logs-queries';

// Fetch available filter options
const filters = await client.query(GET_LOG_FILTERS_QUERY, {
  filter: { organizationId: 'org_123' },
});

// Fetch paginated logs
const logs = await client.query(GET_LOGS_QUERY, {
  filter: { severity: 'ERROR', toolType: 'ENDPOINT' },
  first: 25,
  after: 'cursor_abc',
  search: 'disk usage',
});

// Fetch full log details
const detail = await client.query(GET_LOG_DETAILS_QUERY, {
  logId: 'evt_456',
  ingestDay: '2024-01-15',
  toolType: 'ENDPOINT',
  eventType: 'ALERT',
  timestamp: '2024-01-15T10:30:00Z',
});
```

> **Note:** `GET_LOG_DETAILS_QUERY` requires a composite key (`toolEventId`, `ingestDay`, `toolType`, `eventType`, `timestamp`) to uniquely identify a log entry. The `details` field returns the raw structured payload from the originating tool.
