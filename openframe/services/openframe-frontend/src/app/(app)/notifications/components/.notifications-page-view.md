Page-level view component for the Notifications feature, managing two paginated, searchable notification lists (unread and history) with debounced search, Relay query loading, and bulk mutation actions.

## Key Components

- **`NotificationsPageView`** — Main exported component that orchestrates the full notifications UI
- **Search state management** — Separate debounced search inputs for "New" and "History" sections using `useDebounce` (300ms) and `useApiParams` for URL-persisted state
- **Relay query loaders** — Two independent `useQueryLoader` instances for unread and read notification feeds, each reloaded on search change with `fetchPolicy: 'network-only'`
- **`useNotificationMutations`** — Hook wiring `markRead`, `markAllRead`, `removeNotification`, and `removeAllRead` mutations with filter pairs for optimistic connection updates
- **`NotificationsSection`** — Reused section component rendered twice (unread/history) with distinct row variants and bulk action buttons

## Usage Example

```typescript
// Used as a route-level page component (Next.js App Router)
// app/notifications/page.tsx

import { NotificationsPageView } from './notifications-page-view';

export default function NotificationsPage() {
  return <NotificationsPageView />;
}
```
