Defines and exports a column configuration factory for a notifications data table, supporting both unread and read notification states.

## Key Components

### `NotificationRow`
Interface representing a single notification record with fields: `id`, `title`, `description`, `createdAt` (Unix timestamp), and `read`.

### `buildNotificationColumns(args)`
Factory function that returns a `ColumnDef<NotificationRow>[]` array for use with a TanStack Table-based UI component. Accepts:

| Argument | Type | Description |
|---|---|---|
| `rowVariant` | `'unread' \| 'read'` | Controls the action icon rendered per row |
| `onMarkRead` | `(id: string) => void` | Callback fired when marking a notification read |
| `onDelete` | `(id: string) => void` | Callback fired when deleting a notification |

**Columns produced:**

| ID | Width | Description |
|---|---|---|
| `notification` | `flex-1` | Title + optional description |
| `time` | `160px` | Formatted time (`hh:mm a`) and date (`dd/MM/yyyy`) |
| `action` | `224px` | Reserved slot, renders `null` |
| `rowIcon` | `w-12` | `CheckCircleIcon` (unread) or `TrashIcon` (read) |

## Usage Example

```typescript
import { buildNotificationColumns } from './notifications-columns';

const columns = buildNotificationColumns({
  rowVariant: 'unread',
  onMarkRead: (id) => markAsRead(id),
  onDelete: (id) => deleteNotification(id),
});

// Pass `columns` to your DataTable component
<DataTable columns={columns} data={notifications} />
```

> The `rowIcon` cell uses `data-no-row-click` to prevent the row click handler from firing when the action button is pressed.
