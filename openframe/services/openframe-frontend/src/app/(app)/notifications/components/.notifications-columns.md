Defines the column configuration for the notifications data table, supporting both unread and read notification views with contextual action buttons.

## Key Components

### `NotificationRow`
Interface representing a single notification table row with fields: `id`, `title`, `description` (optional), `createdAt` (Unix timestamp), and `read` status.

### `buildNotificationColumns(args)`
Factory function that returns a `ColumnDef<NotificationRow>[]` array for use with a TanStack Table-compatible component. Accepts:

| Argument | Type | Description |
|---|---|---|
| `rowVariant` | `'unread' \| 'read'` | Controls which action button renders per row |
| `onMarkRead` | `(id: string) => void` | Callback fired when marking a notification as read |
| `onDelete` | `(id: string) => void` | Callback fired when deleting a notification |

**Columns produced:**

| Column ID | Width | Description |
|---|---|---|
| `notification` | `flex-1` | Title + optional description (truncated) |
| `time` | `160px` | Formatted time (`hh:mm a`) and date (`dd/MM/yyyy`) |
| `action` | `224px` | Reserved slot (renders `null`) |
| `rowIcon` | `48px` | Mark-read (✓) or Delete (🗑) button based on `rowVariant` |

## Usage Example

```typescript
const columns = buildNotificationColumns({
  rowVariant: 'unread',
  onMarkRead: (id) => markNotificationRead(id),
  onDelete: (id) => deleteNotification(id),
});

// Pass to your data table component
<DataTable columns={columns} data={notifications} />
```

> The `rowIcon` cell uses `data-no-row-click` to prevent the row click handler from firing when the action button is pressed.
