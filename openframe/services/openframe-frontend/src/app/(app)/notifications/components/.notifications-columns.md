Defines and exports a column configuration factory for notification data tables, returning TanStack-compatible `ColumnDef` arrays for use in unread and read notification views.

## Key Components

**`NotificationRow`** — Interface describing a single notification record with `id`, `title`, `description`, `createdAt` (Unix timestamp), and `read` status.

**`buildNotificationColumns(args)`** — Factory function returning four column definitions:

| Column | Description |
|--------|-------------|
| `notification` | Renders title and optional description with truncation |
| `time` | Formats `createdAt` timestamp into `hh:mm a` / `dd/MM/yyyy` |
| `action` | Reserved placeholder column (renders `null`) |
| `rowIcon` | Renders a **Mark as done** button for unread rows or a **Delete** button for read rows |

The `rowIcon` column uses `data-no-row-click` to prevent the row click handler from firing when the action button is clicked.

## Usage Example

```typescript
import { buildNotificationColumns } from './notifications-columns';

const columns = buildNotificationColumns({
  rowVariant: 'unread',
  onMarkRead: (id) => markNotificationRead(id),
  onDelete: (id) => deleteNotification(id),
});

// Pass to your data table component
<DataTable columns={columns} data={notifications} />
```

> Toggle `rowVariant` between `'unread'` and `'read'` to switch the action icon from **CheckCircle** (mark done) to **Trash** (delete), sharing a single column definition across both notification tabs.
