Renders a notifications panel section with search, a data table, and empty/loading states for either unread or read notification lists.

## Key Components

- **`NotificationsSection`** — Public section component that composes the section header, search input, and a `Suspense`-wrapped table. Accepts a Relay `PreloadedQuery` ref and delegates rendering to `SectionTable` or `SectionTableSkeleton`.
- **`SectionTable`** — Internal component that resolves the preloaded query via `usePreloadedQuery`, maps edges to `NotificationRow` objects, builds columns via `buildNotificationColumns`, and renders a `DataTable` with row-level mark-read and delete callbacks.
- **`SectionTableSkeleton`** — Renders an empty `DataTable` with `skeletonRows={4}` as a loading placeholder, used both during Suspense fallback and when `queryRef` is `null`.

## Usage Example

```typescript
import { NotificationsSection } from './notifications-section';
import { useQueryLoader } from 'react-relay';
import { notificationsListQuery } from '@/graphql/notifications/notifications-list-query';

function UnreadNotificationsPanel() {
  const [queryRef, loadQuery] = useQueryLoader(notificationsListQuery);
  const [search, setSearch] = useState('');

  return (
    <NotificationsSection
      title="Unread"
      queryRef={queryRef}
      searchValue={search}
      onSearchChange={setSearch}
      rowVariant="unread"
      onMarkRead={(id) => console.log('mark read', id)}
      onDelete={(id) => console.log('delete', id)}
      rightAction={<MarkAllReadButton />}
    />
  );
}
```

## Notes

- `rowVariant` controls both column configuration and empty-state messaging/icons (`BellOffIcon` for unread, `ClockHistoryIcon` for read history).
- Search filtering is handled externally via `searchValue`/`onSearchChange` props with `debounceMs={0}`.
- `EMPTY_ROWS` is a stable constant reference to prevent unnecessary re-renders in the skeleton state.
