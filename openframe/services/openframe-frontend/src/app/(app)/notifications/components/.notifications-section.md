Renders a paginated, searchable notifications list section with Relay-powered data fetching, supporting both unread and read notification variants.

## Key Components

- **`NotificationsSection`** — Top-level section component rendering a title, search input, optional action slot, and a Relay-backed data table wrapped in `Suspense`
- **`SectionTable`** — Inner component consuming a Relay preloaded query and pagination fragment to render notification rows with infinite scroll load-more support
- **`SectionTableSkeleton`** — Loading skeleton placeholder rendered during Suspense fallback or when `queryRef` is absent
- **`NOTIFICATIONS_SECTION_PAGE_SIZE`** — Exported constant (`50`) controlling pagination batch size

## Props — `NotificationsSectionProps`

| Prop | Type | Description |
|---|---|---|
| `title` | `string` | Section heading |
| `queryRef` | `PreloadedQuery \| null` | Relay preloaded query reference |
| `searchValue` | `string` | Controlled search input value |
| `onSearchChange` | `(value: string) => void` | Search change handler |
| `rightAction` | `ReactNode` | Optional slot rendered beside the title |
| `rowVariant` | `'unread' \| 'read'` | Controls column config and empty state messaging |
| `onMarkRead` | `(id: string) => void` | Callback to mark a notification read |
| `onDelete` | `(id: string) => void` | Callback to delete a notification |

## Usage Example

```typescript
import { NotificationsSection, NOTIFICATIONS_SECTION_PAGE_SIZE } from './notifications-section';

function NotificationsPage() {
  const [search, setSearch] = useState('');
  const queryRef = useQueryLoader(notificationsSectionRelayQuery, {
    first: NOTIFICATIONS_SECTION_PAGE_SIZE,
    search,
  });

  return (
    <NotificationsSection
      title="Unread"
      queryRef={queryRef}
      searchValue={search}
      onSearchChange={setSearch}
      rowVariant="unread"
      onMarkRead={(id) => markNotificationRead(id)}
      onDelete={(id) => deleteNotification(id)}
    />
  );
}
```
