Renders a paginated, searchable notifications section supporting both unread and read notification views, built with Relay for data fetching and a virtualized data table for display.

## Key Components

- **`NotificationsSection`** — Public-facing section wrapper that composes the search input, title, optional right-side action slot, and a Suspense-wrapped table
- **`SectionTable`** — Internal component that consumes a Relay preloaded query, handles pagination via `usePaginationFragment`, and maps GraphQL edges to `NotificationRow` objects
- **`SectionTableSkeleton`** — Loading skeleton rendered during Suspense fallback or when `queryRef` is null, using an empty data table with skeleton rows
- **`NOTIFICATIONS_SECTION_PAGE_SIZE`** — Exported constant (`50`) controlling pagination batch size

## Usage Example

```typescript
import { NotificationsSection, NOTIFICATIONS_SECTION_PAGE_SIZE } from './notifications-section';
import { useQueryLoader } from 'react-relay';
import { notificationsSectionRelayQuery } from '@/graphql/notifications/notifications-section-relay';

function UnreadNotificationsPage() {
  const [queryRef, loadQuery] = useQueryLoader(notificationsSectionRelayQuery);
  const [search, setSearch] = useState('');

  useEffect(() => {
    loadQuery({ first: NOTIFICATIONS_SECTION_PAGE_SIZE, search });
  }, [search]);

  return (
    <NotificationsSection
      title="Unread"
      queryRef={queryRef}
      searchValue={search}
      onSearchChange={setSearch}
      rowVariant="unread"
      onMarkRead={(id) => handleMarkRead(id)}
      onDelete={(id) => handleDelete(id)}
      rightAction={<MarkAllReadButton />}
    />
  );
}
```

## Props — `NotificationsSectionProps`

| Prop | Type | Description |
|------|------|-------------|
| `title` | `string` | Section heading |
| `queryRef` | `PreloadedQuery \| null` | Relay preloaded query reference |
| `searchValue` | `string` | Controlled search input value |
| `onSearchChange` | `(value: string) => void` | Search change handler |
| `rowVariant` | `'unread' \| 'read'` | Controls empty-state icon/message and column behavior |
| `rightAction` | `ReactNode` | Optional slot rendered beside the section title |
| `onMarkRead` | `(id: string) => void` | Callback when a notification is marked read |
| `onDelete` | `(id: string) => void` | Callback when a notification is deleted |
