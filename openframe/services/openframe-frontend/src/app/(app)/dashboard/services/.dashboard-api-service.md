Singleton service that fetches and normalizes device and ticket statistics for the dashboard, using GraphQL queries via `apiClient`.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `DashboardDeviceStats` | Interface | Normalized device counts with active/inactive totals and percentages |
| `DashboardTicketStats` | Interface | Normalized ticket counts with resolution time, Fae rating, and percentages |
| `dashboardApiService` | Singleton | Pre-instantiated `DashboardApiService` instance for app-wide use |
| `fetchDeviceStats()` | Method | Queries `GET_DEVICE_FILTERS_QUERY` and returns online/offline device breakdown |
| `fetchTicketStats()` | Method | Queries `GET_TICKET_STATISTICS_QUERY` and returns active/resolved ticket breakdown |

## Usage Example

```typescript
import { dashboardApiService } from './dashboard-api-service';

// Fetch device stats
const deviceStats = await dashboardApiService.fetchDeviceStats();
console.log(deviceStats.total);           // e.g. 120
console.log(deviceStats.activePercentage); // e.g. 85

// Fetch ticket stats
const ticketStats = await dashboardApiService.fetchTicketStats();
console.log(ticketStats.avgResolveTime);  // e.g. "2h 15m"
console.log(ticketStats.avgFaeRate);      // e.g. 4.7
```

> Both methods throw a descriptive `Error` on failure — wrap calls in `try/catch` or handle via your data-fetching layer (e.g. React Query, SWR).
