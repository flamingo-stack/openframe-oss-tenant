Centralized query key factory for dashboard React Query hooks, providing consistent and type-safe cache key generation for all dashboard-related queries.

## Key Components

**`dashboardQueryKeys`** — A `const` object implementing the query key factory pattern with the following keys:

| Key | Parameters | Description |
|-----|-----------|-------------|
| `all` | — | Root key `['dashboard']` shared by all dashboard queries |
| `deviceStats()` | — | Device statistics cache key |
| `ticketStats()` | — | Ticket statistics key (SaaS mode only) |
| `orgStats(limit)` | `limit: number` | Organization statistics, scoped by pagination limit |
| `ssoProviders()` | — | SSO provider count for onboarding flows |
| `userStats()` | — | User statistics for onboarding flows |
| `invalidateAll()` | — | Returns root key to bulk-invalidate all dashboard queries |

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query';
import { dashboardQueryKeys } from './query-keys';

// Fetch device stats
const { data } = useQuery({
  queryKey: dashboardQueryKeys.deviceStats(),
  queryFn: fetchDeviceStats,
});

// Fetch org stats with a limit
const { data: orgs } = useQuery({
  queryKey: dashboardQueryKeys.orgStats(10),
  queryFn: () => fetchOrgStats(10),
});

// Invalidate all dashboard queries at once
const queryClient = useQueryClient();
queryClient.invalidateQueries({
  queryKey: dashboardQueryKeys.invalidateAll(),
});
```

> All keys use hierarchical nesting under `['dashboard']`, so invalidating `dashboardQueryKeys.invalidateAll()` cascades to every dashboard sub-query automatically.
