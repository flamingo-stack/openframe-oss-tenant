Centralized query key factory for dashboard React Query hooks, providing consistent and type-safe cache key generation for all dashboard-related data fetching.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `dashboardQueryKeys.all` | `const` | Root cache key `['dashboard']` — parent for all dashboard queries |
| `dashboardQueryKeys.deviceStats()` | `function` | Cache key for device statistics data |
| `dashboardQueryKeys.ticketStats()` | `function` | Cache key for ticket statistics (SaaS mode only) |
| `dashboardQueryKeys.orgStats(limit)` | `function` | Cache key for organization statistics, scoped by `limit` parameter |
| `dashboardQueryKeys.ssoProviders()` | `function` | Cache key for SSO provider count (onboarding flow) |
| `dashboardQueryKeys.userStats()` | `function` | Cache key for user statistics (onboarding flow) |
| `dashboardQueryKeys.invalidateAll()` | `function` | Returns root key to invalidate all dashboard queries at once |

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query';
import { dashboardQueryKeys } from './query-keys';

// Fetch device stats
const { data } = useQuery({
  queryKey: dashboardQueryKeys.deviceStats(),
  queryFn: fetchDeviceStats,
});

// Fetch org stats with a limit
const { data: orgData } = useQuery({
  queryKey: dashboardQueryKeys.orgStats(10),
  queryFn: () => fetchOrgStats(10),
});

// Invalidate all dashboard queries (e.g. after a mutation)
const queryClient = useQueryClient();
queryClient.invalidateQueries({ queryKey: dashboardQueryKeys.invalidateAll() });
```

> Using a factory pattern ensures cache keys remain consistent across hooks and prevents silent cache misses caused by mismatched key strings.
