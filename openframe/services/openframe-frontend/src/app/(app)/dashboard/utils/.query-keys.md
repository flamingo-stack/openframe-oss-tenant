Centralized query key factory for dashboard React Query hooks, providing a structured and type-safe way to manage cache keys across all dashboard-related queries.

## Key Components

- **`dashboardQueryKeys`** — A `const` object containing key factory functions:
  - `all` — Root key `['dashboard']` used as the base for all dashboard queries
  - `deviceStats()` — Key for device statistics queries
  - `ticketStats()` — Key for ticket statistics (SaaS mode only)
  - `orgStats(limit)` — Key for organization statistics, scoped by a `limit` parameter
  - `ssoProviders()` — Key for SSO provider count (used in onboarding flows)
  - `userStats()` — Key for user statistics (used in onboarding flows)
  - `invalidateAll()` — Returns the root key to bulk-invalidate all dashboard queries

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query';
import { dashboardQueryKeys } from './query-keys';

// Fetch device stats
const { data } = useQuery({
  queryKey: dashboardQueryKeys.deviceStats(),
  queryFn: fetchDeviceStats,
});

// Fetch org stats with a limit
const { data: orgs } = useQuery({
  queryKey: dashboardQueryKeys.orgStats(10),
  queryFn: () => fetchOrgStats(10),
});

// Invalidate all dashboard queries at once
const queryClient = useQueryClient();
queryClient.invalidateQueries({ queryKey: dashboardQueryKeys.invalidateAll() });
```

> **Pattern:** All keys extend the root `['dashboard']` array, enabling targeted or bulk cache invalidation with a single `invalidateQueries` call.
