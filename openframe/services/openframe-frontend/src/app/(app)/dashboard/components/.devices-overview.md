Dashboard section component that displays an overview of device statuses (online/offline) with loading skeleton support.

## Key Components

- **`DevicesOverviewSection`** — Main exported React component that renders device status cards with totals, percentages, and progress indicators
- **`useDevicesOverview`** — Hook providing device stats (`total`, `active`, `inactive`, `activePercentage`, `inactivePercentage`, `isLoading`)
- **`DashboardInfoCard`** — Reusable card from `openframe-frontend-core` displaying a metric with optional progress bar and navigation link
- **`Skeleton`** — Loading placeholder component from `openframe-frontend-core`

## Usage Example

```typescript
import { DevicesOverviewSection } from './devices-overview';

export default function DashboardPage() {
  return (
    <main>
      <DevicesOverviewSection />
    </main>
  );
}
```

## Behavior

- **Loading state** — Renders skeleton placeholders while data is being fetched
- **Loaded state** — Displays total device count in the subtitle, then two info cards:
  - **Online** — links to `/devices?statuses=ONLINE`
  - **Offline** — links to `/devices?statuses=OFFLINE`
- Cards use a responsive grid: 1 column on mobile, 2 on `md`, 3 on `lg`
