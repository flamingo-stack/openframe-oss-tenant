Renders a dashboard section displaying a summary of device connectivity status, showing online/offline counts and percentages with progress indicators.

## Key Components

- **`DevicesOverviewSection`** — Main exported component that renders the devices overview dashboard section
- **`useDevicesOverview`** — Hook (from `use-dashboard-stats`) that fetches and returns device stats including `total`, `active`, `inactive`, `activePercentage`, and `inactivePercentage`
- **`DashboardInfoCard`** — Displays individual stat cards for Online/Offline device counts with progress bars and navigation links
- **`Skeleton`** — Loading placeholder rendered while device data is being fetched

## Usage Example

```typescript
import { DevicesOverviewSection } from './devices-overview';

export function DashboardPage() {
  return (
    <main>
      <DevicesOverviewSection />
    </main>
  );
}
```

## Behavior

| State | Output |
|-------|--------|
| Loading | Skeleton placeholders for heading and cards |
| Loaded | Total device count + Online/Offline stat cards |

- **Online card** links to `/devices?statuses=ONLINE`
- **Offline card** links to `/devices?statuses=OFFLINE`
- Responsive grid: 1 col (mobile) → 2 col (md) → 3 col (lg)
