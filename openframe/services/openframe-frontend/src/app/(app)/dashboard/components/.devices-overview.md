Dashboard section component that displays a summary of device statuses (online/offline) with progress indicators, loading skeleton states, and navigation links to filtered device views.

## Key Components

- **`DevicesOverviewSection`** — Main exported React component that renders the devices overview dashboard panel
- **`useDevicesOverview`** — Custom hook (from `use-dashboard-stats`) that fetches and returns device statistics including `total`, `active`, `inactive`, `activePercentage`, and `inactivePercentage`
- **`DashboardInfoCard`** — Reusable card from `@flamingo-stack/openframe-frontend-core` that displays a metric title, value, percentage, and progress bar with an optional navigation link
- **`Skeleton`** — Loading placeholder component rendered while device data is being fetched

## Usage Example

```typescript
import { DevicesOverviewSection } from './devices-overview';

export default function DashboardPage() {
  return (
    <main>
      <DevicesOverviewSection />
    </main>
  );
}
```

## Behavior Notes

- **Loading state**: Renders two skeleton cards and a skeleton subtitle while data loads
- **Loaded state**: Shows total device count in the subtitle and two `DashboardInfoCard` components — one for `ONLINE` devices and one for `OFFLINE` devices
- Both cards link to `/devices` pre-filtered by their respective status (`?statuses=ONLINE` / `?statuses=OFFLINE`)
- Responsive grid: 1 column on mobile → 2 on `md` → 3 on `lg` (currently renders 2 cards)
