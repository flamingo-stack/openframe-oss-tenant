Renders the main dashboard layout by composing all dashboard sections into a single scrollable view, conditionally including the tickets section based on SaaS tenant mode.

## Key Components

- **`DashboardContent`** — Default export. Orchestrates the four dashboard sections in order: onboarding, devices, tickets (SaaS only), and customers/organizations.
- **`isSaasTenantMode()`** — Runtime check that controls whether `TicketsOverviewSection` is rendered.

## Usage Example

```typescript
// Typically consumed via dynamic import to support a loading skeleton
import dynamic from 'next/dynamic';

const DashboardContent = dynamic(() => import('./dashboard-content'), {
  loading: () => <DashboardSkeleton />,
});

export default function DashboardPage() {
  return <DashboardContent />;
}
```

## Section Render Order

| Section | Condition |
|---|---|
| `OnboardingSection` | Always |
| `DevicesOverviewSection` | Always |
| `TicketsOverviewSection` | SaaS tenant mode only |
| `CustomersOverviewSection` | Always |
