Renders the main dashboard layout by composing overview sections, extracted as a separate component to enable dynamic import with a loading skeleton.

## Key Components

- **`DashboardContent`** (default export) — Assembles all dashboard sections in a vertical stack, conditionally rendering `TicketsOverviewSection` only in SaaS tenant mode.

| Section | Always Shown | SaaS Only |
|---|---|---|
| `OnboardingSection` | ✅ | |
| `DevicesOverviewSection` | ✅ | |
| `TicketsOverviewSection` | | ✅ |
| `CustomersOverviewSection` | ✅ | |

## Usage Example

Intended for dynamic import at the page level to enable streaming/skeleton loading:

```typescript
import dynamic from 'next/dynamic';
import { DashboardSkeleton } from './dashboard-skeleton';

const DashboardContent = dynamic(
  () => import('./dashboard-content'),
  { loading: () => <DashboardSkeleton /> }
);

export default function DashboardPage() {
  return <DashboardContent />;
}
```

> **SaaS Mode:** The `TicketsOverviewSection` is gated behind `isSaasTenantMode()`, which checks the current deployment context — it is hidden in self-hosted/MSP-managed tenant configurations.
