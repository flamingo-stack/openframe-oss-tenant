Lazy-loadable container component that composes the main dashboard layout by rendering all dashboard sections in order, conditionally showing the tickets overview based on SaaS tenant mode.

## Key Components

- **`DashboardContent`** — Default export. Renders the full dashboard layout including:
  - `OnboardingSection` — Always visible onboarding prompts
  - `DevicesOverviewSection` — Device monitoring summary
  - `TicketsOverviewSection` — Ticket metrics *(SaaS tenant mode only)*
  - `CustomersOverviewSection` — Customer/organization overview

## Usage Example

```typescript
import dynamic from 'next/dynamic';
import { DashboardSkeleton } from './dashboard-skeleton';

// Extracted for dynamic import to enable loading skeleton
const DashboardContent = dynamic(() => import('./dashboard-content'), {
  loading: () => <DashboardSkeleton />,
});

export default function DashboardPage() {
  return <DashboardContent />;
}
```

## Notes

- Marked `'use client'` — runs exclusively on the client side.
- Uses `isSaasTenantMode()` to gate `TicketsOverviewSection`; in non-SaaS (MSP) deployments, tickets are hidden.
- Intentionally extracted from the parent page to support `next/dynamic` with a skeleton fallback, avoiding layout shift during initial load.
