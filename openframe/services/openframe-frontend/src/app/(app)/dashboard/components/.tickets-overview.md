Renders the **Tickets Overview** section of the MSP dashboard, displaying key ticket metrics (active, resolved, average resolve time, and Fae satisfaction rate) with loading skeleton states.

## Key Components

- **`TicketsOverviewSection`** — Main exported React component that consumes `useTicketsOverview` and renders four `DashboardInfoCard` instances with ticket stats
- **`useTicketsOverview`** — Hook providing ticket metrics including totals, active/resolved counts with percentages, average resolve time, and average Fae rating
- **`DashboardInfoCard`** — Card component from `@flamingo-stack/openframe-frontend-core` used to display each metric tile
- **`Skeleton`** — Loading placeholder rendered in a matching 4-column grid while data fetches

## Usage Example

```typescript
import { TicketsOverviewSection } from './tickets-overview';

export function DashboardPage() {
  return (
    <main>
      <TicketsOverviewSection />
    </main>
  );
}
```

## Metric Cards

| Card | Description | Links To |
|------|-------------|----------|
| Active Tickets | Count + progress % | `/tickets?status=ACTIVE&status=TECH_REQUIRED&status=ON_HOLD` |
| Resolved Tickets | Count + progress % | `/tickets?status=RESOLVED` |
| Avg. Resolve Time | Mean resolution duration | — |
| Avg. Fae Rate | Client satisfaction score `/5` | — |
