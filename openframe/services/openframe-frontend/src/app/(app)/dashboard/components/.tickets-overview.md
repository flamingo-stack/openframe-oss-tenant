Renders a responsive dashboard section displaying key ticket metrics — active tickets, resolved tickets, average resolve time, and average Fae satisfaction rate — with loading skeleton states.

## Key Components

- **`TicketsOverviewSection`** — Main exported component that conditionally renders a skeleton loader or a 4-card metrics grid based on data fetch state
- **`useTicketsOverview`** — Hook (from `use-dashboard-stats`) providing ticket stats: `total`, `active`, `resolved`, `activePercentage`, `resolvedPercentage`, `avgResolveTime`, `avgFaeRate`, and `isLoading`
- **`DashboardInfoCard`** — Reusable card from `@flamingo-stack/openframe-frontend-core` supporting optional progress bars and deep-link `href` routing
- **`Skeleton`** — Loading placeholder component rendering 4 shimmer cards during data fetch

## Usage Example

```typescript
import { TicketsOverviewSection } from './tickets-overview';

export default function DashboardPage() {
  return (
    <main>
      <TicketsOverviewSection />
    </main>
  );
}
```

## Card Routing

| Card | Links To |
|------|----------|
| Active Tickets | `/tickets?status=ACTIVE&status=TECH_REQUIRED&status=ON_HOLD` |
| Resolved Tickets | `/tickets?status=RESOLVED` |
| Avg. Resolve Time | *(no link)* |
| Avg. Fae Rate | *(no link)* |

> **Note:** `Avg. Fae Rate` displays the AI client satisfaction score from Flamingo's Fae assistant, formatted as `X/5`.
