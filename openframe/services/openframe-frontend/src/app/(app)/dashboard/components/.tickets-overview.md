Renders the Tickets Overview dashboard section, displaying key ticket metrics in a responsive card grid with loading skeleton support.

## Key Components

- **`TicketsOverviewSection`** — Main exported component that fetches and displays ticket stats via `useTicketsOverview`
- **`useTicketsOverview`** — Hook providing ticket metrics: `total`, `active`, `resolved`, `activePercentage`, `resolvedPercentage`, `avgResolveTime`, `avgFaeRate`, and `isLoading`
- **`DashboardInfoCard`** — Renders individual metric cards with optional progress bars and navigation links
- **`Skeleton`** — Placeholder UI shown during data loading

## Metric Cards

| Card | Description | Link |
|------|-------------|------|
| Active Tickets | Count + percentage with progress bar | `/tickets?status=ACTIVE&...` |
| Resolved Tickets | Count + percentage with progress bar | `/tickets?status=RESOLVED` |
| Avg. Resolve Time | Mean time to resolution | — |
| Avg. Fae Rate | Client satisfaction score out of 5 | — |

## Usage Example

```typescript
import { TicketsOverviewSection } from './tickets-overview';

export default function DashboardPage() {
  return (
    <main>
      <TicketsOverviewSection />
    </main>
  );
}
```

> **Note:** This is a `'use client'` component. Ensure it is rendered within a client-capable React tree (Next.js App Router). Data fetching is handled internally via `useTicketsOverview` — no props required.
