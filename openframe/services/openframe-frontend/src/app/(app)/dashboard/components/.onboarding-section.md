Renders the dashboard onboarding walkthrough by composing guided setup steps with completion tracking and navigation routing.

## Key Components

**`OnboardingSection`** — Client component that wires together `useOnboardingCompletion` hook data with the `OnboardingWalkthrough` UI primitive. Defines five sequential onboarding steps, each mapping to a route or external URL.

| Step ID | Action | Destination |
|---|---|---|
| `organizations-setup` | Add Customer | `/customers/edit/new` |
| `device-management` | Add Device | `/devices/new` |
| `company-and-team` | Invite Users | `/settings/employees` |
| `sso-configuration` | Add SSO IdP | `/settings/sso` |
| `knowledge-base` | Knowledge Base | `flamingo.run/knowledge-base` (external) |

**`useOnboardingCompletion`** — Provides `completionStatus` and `isLoading` to avoid duplicate API calls already made by parent dashboard hooks.

**`trackDashboardActivity`** — Called on device add, SSO IdP add, and onboarding dismiss to emit analytics events.

## Usage Example

```typescript
// Drop into any dashboard layout — no props required
import { OnboardingSection } from './onboarding-section';

export default function DashboardPage() {
  return (
    <main>
      <OnboardingSection />
    </main>
  );
}
```

## Notes

- The `knowledge-base` step has no `checkComplete` — it auto-completes on click rather than verifying a backend state.
- Dismiss fires `EVENT_SUBTYPE.SKIP_ONBOARDING` for funnel tracking.
- `storageKey` (`"openframe-dashboard-onboarding"`) persists dismissal state in local storage via `OnboardingWalkthrough`.
