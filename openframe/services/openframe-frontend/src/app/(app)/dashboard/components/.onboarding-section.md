Renders the dashboard onboarding walkthrough by composing guided setup steps with completion-state detection, routing actions, and analytics tracking.

## Key Components

**`OnboardingSection`** — Client component that builds the five-step onboarding configuration and delegates rendering to `OnboardingWalkthrough`.

**Step definitions (`onboardingSteps`):**

| ID | Title | Destination |
|----|-------|-------------|
| `organizations-setup` | Customers Setup | `/customers/edit/new` |
| `device-management` | Device Management | `/devices/new` |
| `company-and-team` | Company & Team | `/settings/employees` |
| `sso-configuration` | SSO Configuration | `/settings/sso` |
| `knowledge-base` | Knowledge Base | External docs URL |

**`useOnboardingCompletion`** — Custom hook that supplies `completionStatus` and `isLoading`, preventing duplicate API calls already made by other dashboard hooks.

**Analytics** — `trackDashboardActivity` fires `ADD_DEVICE` and `ADD_SSO_IDP` events on the respective actions, and `SKIP_ONBOARDING` when the walkthrough is dismissed.

## Usage Example

```typescript
// Drop inside any dashboard layout — no props required
import { OnboardingSection } from './onboarding-section';

export default function DashboardPage() {
  return (
    <main>
      <OnboardingSection />
      {/* other dashboard widgets */}
    </main>
  );
}
```

> The `knowledge-base` step intentionally omits a `checkComplete` handler — it auto-completes on click rather than verifying server-side state. All other steps rely on `completionStatus` returned by `useOnboardingCompletion` to reflect real data.
