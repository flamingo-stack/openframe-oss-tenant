Renders the dashboard onboarding walkthrough by composing five guided setup steps and delegating completion-state tracking to the `useOnboardingCompletion` hook, avoiding redundant API calls.

## Key Components

**`OnboardingSection`** — Client component that configures and renders an `OnboardingWalkthrough` with the following steps:

| Step ID | Title | Route / Action |
|---|---|---|
| `organizations-setup` | Customers Setup | `/customers/edit/new` |
| `device-management` | Device Management | `/devices/new` |
| `company-and-team` | Company & Team | `/settings/employees` |
| `sso-configuration` | SSO Configuration | `/settings/sso` |
| `knowledge-base` | Knowledge Base | Opens `flamingo.run/knowledge-base` |

**`useOnboardingCompletion`** — Provides `completionStatus` and `isLoading` to avoid duplicate API calls from the parent dashboard.

**Analytics** — Tracks `ADD_DEVICE`, `ADD_SSO_IDP`, and `SKIP_ONBOARDING` events via `trackDashboardActivity`.

## Usage Example

```typescript
// Drop into any dashboard layout — no props required
import { OnboardingSection } from './onboarding-section';

export default function DashboardPage() {
  return (
    <main>
      <OnboardingSection />
    </main>
  );
}
```

> **Note:** The `knowledge-base` step has no `checkComplete` callback — it auto-completes on first click. All other steps rely on `completionStatus` returned by `useOnboardingCompletion` to determine their checked state. Dismissing the walkthrough fires the `SKIP_ONBOARDING` analytics event and persists state under the `"openframe-dashboard-onboarding"` storage key.
