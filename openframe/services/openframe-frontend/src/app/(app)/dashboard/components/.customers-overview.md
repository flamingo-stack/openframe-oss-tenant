Renders a dashboard section displaying an overview of customer organizations with their online/offline device statistics.

## Key Components

- **`CustomersOverviewSection`** — Primary exported component. Fetches and displays up to 10 customer organizations, each row showing an organization card alongside online and offline device count cards with progress indicators.
- **`CustomersSkeleton`** — Internal loading placeholder rendering 3 rows of shimmer skeletons matching the final layout structure.

## Usage Example

```typescript
import { CustomersOverviewSection } from './customers-overview';

// Drop into any dashboard page — data fetching is handled internally
export default function DashboardPage() {
  return (
    <main>
      <CustomersOverviewSection />
    </main>
  );
}
```

## Key Behaviors

- Uses `useCustomersOverview(10)` hook to fetch up to 10 organizations with aggregated device stats.
- Each organization row renders three cards in a responsive grid (`1 → 2 → 3` columns):
  - **`OrganizationCard`** — links to `/customers/details/:organizationId`
  - **`DashboardInfoCard` (Online)** — links to filtered `/devices` view with `statuses=ONLINE` when count > 0
  - **`DashboardInfoCard` (Offline)** — links to filtered `/devices` view with `statuses=OFFLINE` when count > 0
- Shows `CustomersSkeleton` during initial load, an error message on failure, and a total customer count subtitle once resolved.
- `organizationRows` is memoized via `useMemo` to avoid unnecessary re-renders on unrelated state changes.
