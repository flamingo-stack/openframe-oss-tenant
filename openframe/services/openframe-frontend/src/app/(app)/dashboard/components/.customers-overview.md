Renders the Customers Overview dashboard section, displaying a grid of organization cards with online/offline device statistics for up to 10 customers.

## Key Components

- **`CustomersSkeleton`** — Internal loading skeleton that renders 3 placeholder rows mimicking the card grid layout
- **`CustomersOverviewSection`** — Primary exported component that fetches and renders per-organization device health cards

### Data Flow

Uses `useCustomersOverview(10)` hook to fetch organization rows, then maps each into a 3-column responsive grid:

| Column | Component | Purpose |
|---|---|---|
| 1 | `OrganizationCard` | Org name, logo, total device count |
| 2 | `DashboardInfoCard` | Online devices count + progress bar |
| 3 | `DashboardInfoCard` | Offline devices count + progress bar |

## Usage Example

```typescript
import { CustomersOverviewSection } from './customers-overview';

// Drop into any dashboard page — fetches and renders automatically
export default function DashboardPage() {
  return (
    <main>
      <CustomersOverviewSection />
    </main>
  );
}
```

## Behavior Notes

- **Loading state**: Shows `CustomersSkeleton` only when loading with no cached rows
- **Error state**: Renders an inline error message styled with `text-ods-error`
- **Device links**: `href` targets filter the `/devices` route by `organizationId` and `statuses=ONLINE` / `statuses=OFFLINE`; falls back to unfiltered list when count is `0`
- **Images**: Resolved via `getFullImageUrl()` before passing to `OrganizationCard`
