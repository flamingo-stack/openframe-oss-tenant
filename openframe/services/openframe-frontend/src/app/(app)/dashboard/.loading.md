Next.js route-level loading skeleton for `/dashboard` that mirrors the exact layout and structure of the dashboard's live components, providing a visually accurate loading state while data fetches.

## Key Components

| Component | Description |
|-----------|-------------|
| `DashboardLoading` | Default export — root skeleton wrapper; conditionally renders `TicketsSkeleton` based on SaaS tenant mode |
| `OnboardingSkeleton` | Matches `OnboardingWalkthrough` — header row + 5 vertical `OnboardingStepCardSkeleton` cards |
| `OnboardingStepCardSkeleton` | Matches `OnboardingStepCard` — title, description, and two action button placeholders |
| `DevicesSkeleton` | Matches `DevicesOverviewSection` — title, subtitle, 2-card info grid |
| `TicketsSkeleton` | Matches `TicketsOverviewSection` — title, subtitle, 4-card info grid (SaaS tenant only) |
| `CustomersSkeleton` | Matches `CustomersOverviewSection` — title, subtitle, 3 rows of `[OrgCard, InfoCard, InfoCard]` |
| `InfoCardSkeleton` | Reusable card skeleton with value, percentage, and circular progress placeholders |
| `CustomerCardSkeleton` | Matches `OrganizationCard` — org name, details, and device count badge |

## Usage Example

This file is automatically used by Next.js as the route-level loading UI. No manual imports are needed — place it at `app/dashboard/loading.tsx`:

```typescript
// Next.js automatically renders this while dashboard/page.tsx suspends.
// Conditional sections mirror runtime logic from the live page:

export default function DashboardLoading() {
  const showTickets = isSaasTenantMode(); // hides tickets on non-SaaS tenants

  return (
    <div className="space-y-10 pt-6" role="status" aria-label="Loading dashboard">
      <OnboardingSkeleton />
      <DevicesSkeleton />
      {showTickets && <TicketsSkeleton />}
      <CustomersSkeleton />
    </div>
  );
}
```

> **Note:** Each skeleton component is intentionally sized to match its real counterpart's Tailwind classes (height, width, grid layout) to prevent layout shift when the live content loads.
