Minimal Next.js layout component for the OpenFrame Dashboard route segment, providing metadata and a passthrough wrapper for child routes.

## Key Components

- **`metadata`** — Next.js route metadata export setting the page title and description for the dashboard section
- **`DashboardLayout`** — Transparent layout wrapper that renders children without additional DOM structure

## Usage Example

```typescript
// app/dashboard/layout.tsx is automatically applied to all routes under /dashboard
// Child pages receive no extra wrapping elements

export default function DashboardPage() {
  return <div>My Dashboard Content</div>;
}
```

> This layout intentionally uses a React fragment (`<>`) to avoid adding wrapper elements, keeping the DOM clean for child layouts or pages that define their own structure.
