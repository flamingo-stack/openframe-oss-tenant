Minimal Next.js layout component for the OpenFrame Dashboard route segment, providing metadata and a passthrough wrapper for child routes.

## Key Components

- **`metadata`** — Next.js route metadata export setting the page title and description for the dashboard section
- **`DashboardLayout`** — Passthrough layout component that renders children without additional DOM wrapping

## Usage Example

```typescript
// app/dashboard/layout.tsx - automatically applied by Next.js
// to all routes under /dashboard

// Child pages receive the layout automatically:
export default function DashboardPage() {
  return <div>Dashboard Content</div>;
}
```

> This layout acts as a transparent wrapper — it contributes SEO metadata while adding zero visual structure, leaving full rendering control to child route segments.
