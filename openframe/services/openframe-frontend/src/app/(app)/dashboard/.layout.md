Root layout component for the OpenFrame Dashboard section, defining page metadata and rendering child routes.

## Key Components

- **`metadata`** — Next.js metadata export setting the page `title` and `description` for the dashboard section
- **`DashboardLayout`** — Passthrough layout wrapper that renders child route segments without additional markup

## Usage Example

```typescript
// Automatically applied by Next.js to all routes under /dashboard
export default function Page() {
  return <div>Dashboard Content</div>;
}
```

> This layout acts as a transparent wrapper — it injects SEO metadata for all dashboard routes while passing `children` through unchanged. Extend it to add shared UI (sidebars, nav) across all dashboard pages.
