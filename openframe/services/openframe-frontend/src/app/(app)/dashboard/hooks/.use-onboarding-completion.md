Aggregates data from multiple sources to determine the completion status of onboarding steps, checking SSO configuration, organization setup, device management, and team setup.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `useOnboardingCompletion` | Hook (public) | Returns a `completionStatus` map and `isLoading` flag for all onboarding steps |
| `useActiveSsoProviderCount` | Hook (internal) | Queries `api/sso/providers/available` and counts enabled SSO providers |
| `useUsersCount` | Hook (internal) | Fetches total user count via GraphQL |

### Completion Status Keys

| Key | Condition |
|-----|-----------|
| `sso-configuration` | At least 1 enabled SSO provider |
| `organizations-setup` | More than 1 organization |
| `device-management` | At least 1 device |
| `company-and-team` | More than 1 user |

## Usage Example

```typescript
import { useOnboardingCompletion } from './use-onboarding-completion';

function OnboardingChecklist() {
  const { completionStatus, isLoading } = useOnboardingCompletion();

  if (isLoading) return <Spinner />;

  return (
    <ul>
      {Object.entries(completionStatus).map(([step, done]) => (
        <li key={step}>
          {step}: {done ? '✅' : '⬜'}
        </li>
      ))}
    </ul>
  );
}
```

> Requires `QueryClientProvider` (TanStack Query) and an authenticated session via `useAuthStore`. All sub-queries are gated on `isAuthenticated` and use independent stale/gc time settings to minimize redundant network requests.
