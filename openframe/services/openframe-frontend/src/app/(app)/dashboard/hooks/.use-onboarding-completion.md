Tracks onboarding step completion by aggregating data from multiple API sources to determine whether key platform setup tasks have been completed.

## Key Components

- **`useOnboardingCompletion`** *(exported)* — Main hook that composes four data sources and returns a `completionStatus` map alongside a unified `isLoading` flag.
- **`useActiveSsoProviderCount`** *(internal)* — Fetches available SSO providers and counts how many are enabled via `api/sso/providers/available`.
- **`useUsersCount`** *(internal)* — Queries total user count via GraphQL (`/api/graphql`).

### Completion Status Keys

| Key | Condition |
|---|---|
| `sso-configuration` | At least 1 SSO provider enabled |
| `organizations-setup` | More than 1 organization exists |
| `device-management` | At least 1 device registered |
| `company-and-team` | More than 1 user account exists |

## Usage Example

```typescript
import { useOnboardingCompletion } from './use-onboarding-completion';

function OnboardingChecklist() {
  const { completionStatus, isLoading } = useOnboardingCompletion();

  if (isLoading) return <Spinner />;

  return (
    <ul>
      {Object.entries(completionStatus).map(([step, done]) => (
        <li key={step}>
          {step}: {done ? '✅' : '⬜'}
        </li>
      ))}
    </ul>
  );
}
```

> All internal queries are gated on `isAuthenticated` from `useAuthStore` and use `@tanstack/react-query` with conservative `staleTime`/`gcTime` settings to minimize redundant network calls.
