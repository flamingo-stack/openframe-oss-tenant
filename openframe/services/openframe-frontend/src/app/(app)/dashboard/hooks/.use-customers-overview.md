Fetches and aggregates per-organization device status metrics for the dashboard customers overview table, combining organization data with online/offline device counts via parallel GraphQL queries.

## Key Components

### `OrganizationOverviewRow` (interface)
Represents a single row in the customers overview table, including organization metadata and computed device health metrics (`total`, `active`, `inactive`, `activePct`, `inactivePct`).

### `fetchCustomersOverview(limit)` (async function)
Internal data fetcher that:
1. Loads up to 100 organizations via `GetOrganizations`
2. Fetches total device counts per org via `GetDeviceFilters`
3. Fetches online and offline counts in parallel
4. Computes percentages and sorts rows by total devices (descending)

### `useCustomersOverview(limit?)` (hook)
Primary export. Wraps `fetchCustomersOverview` in a React Query `useQuery`, gated on authentication state. Stale time is 3 minutes; cache is kept for 10 minutes.

## Usage Example

```typescript
import { useCustomersOverview } from './use-customers-overview';

function CustomersTable() {
  const {
    rows,
    loading,
    error,
    totalOrganizations,
    refresh,
    isFetching,
  } = useCustomersOverview(10);

  if (loading) return <Spinner />;
  if (error) return <ErrorBanner message={error} />;

  return (
    <>
      <p>Total organizations: {totalOrganizations}</p>
      {rows.map(row => (
        <div key={row.id}>
          {row.name} — {row.active}/{row.total} active ({row.activePct}%)
        </div>
      ))}
      <button onClick={refresh} disabled={isFetching}>Refresh</button>
    </>
  );
}
```

## Query Behavior

| Option | Value |
|--------|-------|
| `staleTime` | 3 minutes |
| `gcTime` | 10 minutes |
| `retry` | 1 attempt |
| `enabled` | Only when authenticated |
| `refetchOnWindowFocus` | Disabled |
