Fetches and aggregates a per-organization device health overview for the dashboard, combining organization metadata with online/offline device counts into sortable summary rows.

## Key Components

### `OrganizationOverviewRow` (interface)
Exported row shape consumed by dashboard UI components, containing org identity fields plus computed device health metrics (`total`, `active`, `inactive`, `activePct`, `inactivePct`).

### `fetchCustomersOverview` (async function)
Internal data-fetching function that executes three sequential/parallel GraphQL calls:
1. Fetches all organizations (up to 100)
2. Fetches total device counts per org (online + offline combined)
3. Fetches online and offline counts in parallel via `Promise.all`

Results are merged into `OrganizationOverviewRow[]`, sorted descending by total device count.

### `useCustomersOverview` (hook)
Public React Query hook wrapping `fetchCustomersOverview`. Caches results for 3 minutes (`staleTime`) with a 10-minute GC window. Only runs when the user is authenticated.

## Usage Example

```typescript
import { useCustomersOverview } from './use-customers-overview';

function CustomersDashboard() {
  const {
    rows,
    loading,
    error,
    totalOrganizations,
    refresh,
  } = useCustomersOverview(10);

  if (loading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;

  return (
    <table>
      {rows.map(row => (
        <tr key={row.id}>
          <td>{row.name}</td>
          <td>{row.total} devices</td>
          <td>{row.activePct}% online</td>
        </tr>
      ))}
    </table>
  );
}
```

## Query Behavior

| Option | Value |
|---|---|
| `staleTime` | 3 minutes |
| `gcTime` | 10 minutes |
| `retry` | 1 attempt |
| `enabled` | Requires authentication |
| `refetchOnWindowFocus` | Disabled |
