Fetches and aggregates per-organization device statistics for the dashboard customers overview, combining organization data with online/offline device counts into a sorted summary table.

## Key Components

### `OrganizationOverviewRow` (interface)
Exported row shape consumed by dashboard UI components:

| Field | Description |
|-------|-------------|
| `total` | Total device count (online + offline) |
| `active` / `inactive` | Online / offline device counts |
| `activePct` / `inactivePct` | Rounded percentage values |
| `imageUrl` | Nullable org logo URL |

### `fetchCustomersOverview(limit)` (async function)
Executes three parallel/sequential GraphQL calls:
1. `GetOrganizations` — fetches up to 100 org records
2. `GetDeviceFilters` (combined) — total devices per org
3. `GetDeviceFilters` (online + offline in parallel) — per-status counts

Returns rows sorted descending by total device count. Fails gracefully with `{ rows: [], totalOrganizations: 0 }` on any error.

### `useCustomersOverview(limit?)` (hook)
React Query wrapper with a 3-minute stale time, guarded by auth state.

## Usage Example

```typescript
import { useCustomersOverview } from './use-customers-overview';

function CustomersSummaryTable() {
  const {
    rows,
    loading,
    totalOrganizations,
    isFetching,
    refresh,
  } = useCustomersOverview(10);

  if (loading) return <Spinner />;

  return (
    <>
      <p>Total organizations: {totalOrganizations}</p>
      {rows.map(row => (
        <div key={row.id}>
          {row.name} — {row.active}/{row.total} online ({row.activePct}%)
        </div>
      ))}
      <button onClick={() => refresh()}>Refresh</button>
    </>
  );
}
```

## Query Behaviour

| Option | Value |
|--------|-------|
| `staleTime` | 3 minutes |
| `gcTime` | 10 minutes |
| `retry` | 1 attempt, 1 s delay |
| `enabled` | Only when authenticated |
| `refetchOnWindowFocus` | Disabled |
