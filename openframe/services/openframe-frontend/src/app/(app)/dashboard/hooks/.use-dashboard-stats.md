React Query hooks for fetching and exposing dashboard statistics — device overviews and ticket overviews — with authentication-gating and SaaS mode awareness.

## Key Components

| Export | Description |
|--------|-------------|
| `useDevicesOverview` | Fetches device stats (total, active, inactive, percentages). Enabled when authenticated. |
| `useTicketsOverview` | Fetches ticket stats (total, active, resolved, avg resolve time, Fae rate). Enabled only in SaaS tenant mode **and** when authenticated. |
| `useSharedDashboardData` | Composes both hooks into a unified object with a combined loading state and `refetchAll` helper. |

## Cache Configuration

| Hook | `staleTime` | `gcTime` | Retries |
|------|-------------|----------|---------|
| `useDevicesOverview` | 1 min | 5 min | 2 |
| `useTicketsOverview` | 3 min | 5 min | 2 |

## Usage Example

```typescript
// Using hooks individually
function DeviceStatsCard() {
  const { total, active, activePercentage, isLoading, error } = useDevicesOverview();

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;

  return <div>{active} / {total} active ({activePercentage}%)</div>;
}

// Using the combined hook
function DashboardPage() {
  const { devices, tickets, isAnyLoading, refetchAll } = useSharedDashboardData();

  if (isAnyLoading) return <FullPageSpinner />;

  return (
    <>
      <DeviceStats data={devices.data} />
      <TicketStats data={tickets.data} />
      <button onClick={refetchAll}>Refresh</button>
    </>
  );
}
```

## Notes

- `useTicketsOverview` is a no-op (query disabled) in non-SaaS/self-hosted deployments — `isSaasTenantMode()` gates the fetch.
- All numeric fields default to `0` and string fields to `'—'` when data is unavailable, making these hooks safe to destructure without null checks in JSX.
