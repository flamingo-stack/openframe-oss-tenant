React Query hooks for fetching and exposing dashboard statistics — device overview and ticket overview — with auth-gated, cached data fetching for the Flamingo dashboard.

## Key Components

| Export | Description |
|--------|-------------|
| `useDevicesOverview` | Fetches device stats (total, active, inactive, percentages); enabled when authenticated |
| `useTicketsOverview` | Fetches ticket stats (total, active, resolved, avg resolve time, Fae rate); enabled only in SaaS tenant mode + authenticated |
| `useSharedDashboardData` | Composes both hooks into a unified dashboard data object with a combined loading state and `refetchAll` helper |

## Cache Configuration

| Hook | `staleTime` | `gcTime` | Retries |
|------|------------|----------|---------|
| `useDevicesOverview` | 1 min | 5 min | 2 |
| `useTicketsOverview` | 3 min | 5 min | 2 |

## Usage Example

```typescript
// Use individual stat hooks
function DeviceWidget() {
  const { total, active, activePercentage, isLoading, error } = useDevicesOverview();

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;

  return <p>{active} / {total} active ({activePercentage}%)</p>;
}

// Or use the shared composer for full dashboard pages
function DashboardPage() {
  const { devices, tickets, isAnyLoading, refetchAll } = useSharedDashboardData();

  return (
    <>
      <DeviceCard data={devices.data} loading={devices.isLoading} />
      <TicketCard data={tickets.data} loading={tickets.isLoading} />
      <button onClick={refetchAll} disabled={isAnyLoading}>Refresh</button>
    </>
  );
}
```

> **Note:** `useTicketsOverview` is conditionally disabled outside SaaS tenant mode (`isSaasTenantMode()`), returning zeroed defaults — safe to render in all environments without guard checks.
