React Query hooks for fetching and exposing dashboard statistics — device overviews and ticket overviews — with auth-gating and SaaS mode awareness.

## Key Components

| Export | Description |
|--------|-------------|
| `useDevicesOverview` | Fetches device stats (total, active, inactive, percentages). Enabled when authenticated. |
| `useTicketsOverview` | Fetches ticket stats (total, active, resolved, avg resolve time, Fae rate). Enabled only in SaaS tenant mode **and** when authenticated. |
| `useSharedDashboardData` | Composes both hooks into a unified object with a combined loading state and `refetchAll` helper. |

## Cache Configuration

| Hook | `staleTime` | `gcTime` | Retries |
|------|-------------|----------|---------|
| `useDevicesOverview` | 1 min | 5 min | 2 |
| `useTicketsOverview` | 3 min | 5 min | 2 |

## Usage Example

```typescript
// Using the composed hook for dashboard widgets
function DashboardPage() {
  const { devices, tickets, isAnyLoading, refetchAll } = useSharedDashboardData();

  if (isAnyLoading) return <Spinner />;

  return (
    <>
      <DeviceWidget
        total={devices.data.total}
        activePercentage={devices.data.activePercentage}
      />
      <TicketWidget
        total={tickets.data.total}
        avgResolveTime={tickets.data.avgResolveTime}
        avgFaeRate={tickets.data.avgFaeRate}
      />
      <button onClick={refetchAll}>Refresh</button>
    </>
  );
}

// Using individual hooks
function DevicesCard() {
  const { total, active, inactive, isLoading, error } = useDevicesOverview();

  if (error) return <ErrorBanner message={error} />;
  return <StatsCard total={total} active={active} inactive={inactive} />;
}
```

> **Note:** `useTicketsOverview` returns zeroed-out defaults and skips the API call entirely when running outside SaaS tenant mode (`isSaasTenantMode()` returns `false`).
