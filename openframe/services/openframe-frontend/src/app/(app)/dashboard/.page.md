Client-side Next.js page component that renders the main dashboard view by delegating to the `DashboardContent` component.

## Key Components

- **`Dashboard`** — Default export; a client component that mounts `DashboardContent`
- **`dynamic`** — Named export set to `'force-dynamic'`, disabling static generation and ensuring the page is always server-rendered at request time

## Usage Example

```typescript
// Automatically resolved by Next.js App Router at the /dashboard route.
// No manual imports needed — Next.js picks up the default export.

// To reference the dynamic export in tests or config:
import { dynamic } from '@/app/dashboard/page';
console.log(dynamic); // 'force-dynamic'
```

> **Note:** The `force-dynamic` flag is useful when the dashboard relies on per-request data (e.g., session tokens, real-time metrics) that must not be cached or statically pre-rendered.
