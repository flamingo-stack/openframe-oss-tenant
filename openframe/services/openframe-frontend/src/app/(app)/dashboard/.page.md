Client-side dashboard page entry point that renders the main dashboard UI and opts out of static generation by forcing dynamic rendering on every request.

## Key Components

- **`Dashboard`** — Default export; a thin wrapper component that delegates all rendering to `DashboardContent`
- **`dynamic`** — Next.js route segment config export set to `'force-dynamic'`, disabling static/ISR caching for this route

## Usage Example

```typescript
// Automatically used by Next.js App Router at the /dashboard route.
// No direct instantiation needed — the framework renders this page component.

// To extend, pass props into DashboardContent or add layout wrappers:
export default function Dashboard() {
  return (
    <SomeProvider>
      <DashboardContent />
    </SomeProvider>
  );
}
```

> **Note:** The `'use client'` directive marks this as a Client Component, enabling React hooks and browser APIs within the component tree. Combined with `force-dynamic`, the dashboard will always fetch fresh data on each request rather than serving a cached static shell.
