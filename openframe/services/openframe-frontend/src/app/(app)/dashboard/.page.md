Client-side dashboard entry point that renders the main dashboard view. Forces dynamic rendering to ensure fresh data on every request.

## Key Components

- **`Dashboard`** — Default export; thin wrapper component that delegates rendering to `DashboardContent`
- **`dynamic`** — Next.js route segment config set to `'force-dynamic'`, disabling static generation for this route

## Usage Example

```typescript
// Automatically rendered by Next.js App Router at the /dashboard route.
// No direct instantiation needed — DashboardContent handles all UI logic.
import Dashboard from '@/app/dashboard/page';
```

> This page intentionally contains no logic — all dashboard UI and data-fetching concerns live in `DashboardContent`, keeping the route entry point clean and testable.
