Renders the checkout cancellation confirmation page, displayed when a user cancels a payment flow before completion.

## Key Components

- **`CheckoutCancelPage`** — Default export; a Next.js page component that renders a cancellation result card with error styling, informing the user no charges were made.
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time.

## Usage Example

```typescript
// Rendered automatically by Next.js when navigating to:
// /checkout/cancel (or equivalent route based on file location)

// The page renders a CheckoutResultCard with:
// - XCircle icon with error color styling
// - Title: "Payment Cancelled"
// - Description: "No charges were made..."
// - Primary CTA → /settings/billing-usage/subscription
// - Secondary CTA → /dashboard
```

> **Note:** This page is typically the `cancel_url` destination passed to a payment provider (e.g., Stripe). No user interaction is required — it simply confirms cancellation and provides navigation back to billing or the dashboard.
