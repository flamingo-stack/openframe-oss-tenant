Renders the checkout cancellation page, displayed when a user cancels a payment flow before completion.

## Key Components

- **`CheckoutCancelPage`** — Default export. A Next.js client page that renders a `CheckoutResultCard` with an error state indicating no charges were made, along with CTAs to return to the billing plans or navigate to the dashboard.
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time.

## Usage Example

```typescript
// Automatically rendered by Next.js when navigating to:
// /checkout/cancel

// The page renders a CheckoutResultCard with:
// - XCircle icon styled with error colors
// - "Payment Cancelled" title
// - CTA: "Back to Plans" → /settings/billing-usage/subscription
// - CTA: "Go to Dashboard" → /dashboard
```
