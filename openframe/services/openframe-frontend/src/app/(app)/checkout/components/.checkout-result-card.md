A reusable presentational card component for displaying checkout outcome screens (success, failure, etc.) with an icon, title, description, and one or two CTA buttons.

## Key Components

### `CheckoutResultCardProps`
| Prop | Type | Description |
|------|------|-------------|
| `icon` | `ComponentType<{ className?: string }>` | Icon component rendered inside a styled wrapper |
| `iconWrapperClassName` | `string` | Tailwind classes controlling icon background/color |
| `title` | `string` | Primary heading displayed on the card |
| `description` | `ReactNode` | Supporting text or rich content below the title |
| `primaryCta` | `{ label: string; href: string }` | Required accent-styled action button |
| `secondaryCta` | `{ label: string; href: string }` | Optional outline-styled secondary action |

### `CheckoutResultCard`
Client component that renders a centered card layout. Uses `useRouter` from Next.js for client-side navigation on button clicks.

## Usage Example

```typescript
import { CheckoutResultCard } from './checkout-result-card';
import { CheckCircleIcon } from 'lucide-react';

export default function PaymentSuccessPage() {
  return (
    <CheckoutResultCard
      icon={CheckCircleIcon}
      iconWrapperClassName="bg-green-100 text-green-600"
      title="Payment Successful"
      description="Your subscription is now active. Welcome aboard!"
      primaryCta={{ label: 'Go to Dashboard', href: '/dashboard' }}
      secondaryCta={{ label: 'View Invoice', href: '/billing/invoices' }}
    />
  );
}
```

> **Note:** `iconWrapperClassName` controls the visual state of the icon (e.g. green for success, red for failure), making this component reusable across different checkout outcomes without code duplication.
