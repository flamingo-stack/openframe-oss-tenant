A reusable presentational card component for displaying checkout outcome screens (success, failure, etc.) with an icon, title, description, and one or two CTA buttons.

## Key Components

**`CheckoutResultCard`** — Default export function component accepting:

| Prop | Type | Description |
|------|------|-------------|
| `icon` | `ComponentType<{ className? }>` | Icon component rendered in the colored circle |
| `iconWrapperClassName` | `string` | Tailwind classes controlling the icon background color |
| `title` | `string` | Primary heading displayed on the card |
| `description` | `ReactNode` | Supporting text or JSX below the title |
| `primaryCta` | `{ label, href }` | Required accent-styled action button |
| `secondaryCta` | `{ label, href }` (optional) | Optional outline-styled secondary action |

Navigation is handled via Next.js `useRouter().push()`.

## Usage Example

```typescript
import { CheckoutResultCard } from './checkout-result-card';
import { CheckCircleIcon } from 'lucide-react';

export default function CheckoutSuccessPage() {
  return (
    <CheckoutResultCard
      icon={CheckCircleIcon}
      iconWrapperClassName="bg-green-100 text-green-600"
      title="Payment Successful"
      description="Your subscription is now active. Welcome aboard!"
      primaryCta={{ label: 'Go to Dashboard', href: '/dashboard' }}
      secondaryCta={{ label: 'View Invoice', href: '/billing/invoices' }}
    />
  );
}
```
