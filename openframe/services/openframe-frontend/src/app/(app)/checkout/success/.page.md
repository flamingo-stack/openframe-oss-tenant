Renders the post-checkout success page displayed after a successful payment, showing a confirmation message with navigation options to the dashboard or subscription settings.

## Key Components

- **`CheckoutSuccessPage`** — Default export; a client-side page component that composes `CheckoutResultCard` with success-specific props
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time

## Usage Example

```typescript
// Automatically rendered by Next.js at:
// /checkout/success

// Internally renders:
<CheckoutResultCard
  icon={CheckCircle2}
  iconWrapperClassName="bg-ods-success-secondary text-ods-success"
  title="Payment Successful"
  description="Thanks for subscribing..."
  primaryCta={{ label: 'Continue to Dashboard', href: '/dashboard' }}
  secondaryCta={{ label: 'View Subscription', href: '/settings/billing-usage/subscription' }}
/>
```

## Behavior

- Displays a `CheckCircle2` icon styled with success colors from the ODS design token system
- Provides two CTAs:
  - **Primary** → `/dashboard`
  - **Secondary** → `/settings/billing-usage/subscription`
- Marked `'use client'` for client-side rendering while `force-dynamic` prevents caching
