Renders the post-checkout success page displayed after a successful Stripe payment, showing a confirmation message and navigation options.

## Key Components

- **`CheckoutSuccessPage`** — Default export; a `force-dynamic` Next.js page component that renders a success state using `CheckoutResultCard`
- **`CheckoutResultCard`** — Shared presentational card component accepting icon, styling, title, description, and CTA props

## Usage Example

```typescript
// Rendered automatically by Next.js at /checkout/success
// Typically redirected to by Stripe after a successful payment session

<CheckoutResultCard
  icon={CheckCircle2}
  iconWrapperClassName="bg-ods-success-secondary text-ods-success"
  title="Payment Successful"
  description="Thanks for subscribing..."
  primaryCta={{ label: 'Continue to Dashboard', href: '/dashboard' }}
  secondaryCta={{ label: 'View Subscription', href: '/settings/billing-usage/subscription' }}
/>
```

## Notes

- `export const dynamic = 'force-dynamic'` disables static caching, ensuring the page is always server-rendered at request time (relevant for post-payment state freshness)
- Primary CTA routes to `/dashboard`; secondary CTA routes to `/settings/billing-usage/subscription`
- Success icon and colors use ODS (OpenFrame Design System) tokens: `ods-success` and `ods-success-secondary`
