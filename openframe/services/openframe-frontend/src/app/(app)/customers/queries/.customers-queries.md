GraphQL query definitions for fetching customer organization data, supporting full detail, minimal, and single-record lookups with pagination and filtering support.

## Key Components

| Export | Description |
|--------|-------------|
| `GET_ORGANIZATIONS_QUERY` | Paginated list of organizations with full fields, cursor-based pagination, filtering, and `filteredCount` |
| `GET_ORGANIZATIONS_MIN_QUERY` | Lightweight organization list returning only `id`, `organizationId`, `name`, `isDefault`, and `imageUrl` |
| `GET_ORGANIZATION_BY_ORGANIZATION_ID_QUERY` | Full organization detail fetched by business-level `organizationId` (string) |
| `GET_ORGANIZATION_BY_ID_QUERY` | Full organization detail fetched by internal `id` (GraphQL `ID`) |

## Usage Example

```typescript
import {
  GET_ORGANIZATIONS_QUERY,
  GET_ORGANIZATION_BY_ID_QUERY,
} from './customers-queries';

// Paginated list with search and filter
const { data } = await apolloClient.query({
  query: gql(GET_ORGANIZATIONS_QUERY),
  variables: {
    search: 'Acme',
    first: 20,
    after: null,
    filter: { status: 'ACTIVE' },
  },
});

// Fetch single organization by internal ID
const { data: orgData } = await apolloClient.query({
  query: gql(GET_ORGANIZATION_BY_ID_QUERY),
  variables: { id: 'org_abc123' },
});
```

## Field Coverage

- **List queries** — `id`, `name`, `category`, `contactInformation`, `numberOfEmployees`, `websiteUrl`, `monthlyRevenue`, `contractStartDate/EndDate`, `status`, `image`
- **Detail queries** — all list fields plus `notes`, full `physicalAddress`/`mailingAddress`, `mailingAddressSameAsPhysical`, contact `title`/`phone`, `isDefault`
- **Pagination** — `pageInfo` (`hasNextPage`, `hasPreviousPage`, `startCursor`, `endCursor`) and `filteredCount` on the full list query
