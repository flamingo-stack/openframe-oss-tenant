GraphQL query definitions for fetching organization (customer) data, supporting full detail, minimal, and single-record lookups with pagination and filtering.

## Key Components

| Export | Description |
|--------|-------------|
| `GET_ORGANIZATIONS_QUERY` | Paginated list of organizations with full fields, search, filtering, and cursor-based pagination |
| `GET_ORGANIZATIONS_MIN_QUERY` | Lightweight organization list returning only `id`, `organizationId`, `name`, `isDefault`, and `image` |
| `GET_ORGANIZATION_BY_ORGANIZATION_ID_QUERY` | Full organization detail fetched by `organizationId` (string) |
| `GET_ORGANIZATION_BY_ID_QUERY` | Full organization detail fetched by internal `id` (ID scalar) |

## Usage Example

```typescript
import {
  GET_ORGANIZATIONS_QUERY,
  GET_ORGANIZATIONS_MIN_QUERY,
  GET_ORGANIZATION_BY_ORGANIZATION_ID_QUERY,
  GET_ORGANIZATION_BY_ID_QUERY,
} from './customers-queries';

// Paginated list with search and filter
const { data } = await client.query({
  query: GET_ORGANIZATIONS_QUERY,
  variables: { search: 'Acme', first: 20, after: null, filter: { status: 'ACTIVE' } },
});

// Minimal list for dropdowns/selectors
const { data: minData } = await client.query({
  query: GET_ORGANIZATIONS_MIN_QUERY,
  variables: { first: 50 },
});

// Fetch by organizationId (human-readable slug/ID)
const { data: orgData } = await client.query({
  query: GET_ORGANIZATION_BY_ORGANIZATION_ID_QUERY,
  variables: { organizationId: 'org-123' },
});

// Fetch by internal GraphQL ID
const { data: orgById } = await client.query({
  query: GET_ORGANIZATION_BY_ID_QUERY,
  variables: { id: 'abc-xyz-456' },
});
```

> **Note:** Full detail queries include contact information, physical/mailing addresses, contract dates, revenue, and status. Use `GET_ORGANIZATIONS_MIN_QUERY` for performance-sensitive UIs like dropdowns or autocomplete fields.
