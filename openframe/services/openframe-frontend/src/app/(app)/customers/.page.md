Renders the Organizations/Customers page with tab-based navigation, dynamically resolving the active tab component based on URL query parameters.

## Key Components

- **`Organizations`** — Default export; root page component for the Customers section
- **`useApiParams`** — Hook that reads and sets URL query parameters (`tab`, defaulting to `'active'`)
- **`getTabComponent`** — Utility that resolves the correct tab component from `CUSTOMERS_TABS` based on the active tab key
- **`CustomersTabNavigation`** — Tab navigation bar that highlights the active tab and triggers `setParam` on change

## Usage Example

```typescript
// Rendered automatically by Next.js App Router at the /customers route.
// Tab state is driven by the `?tab=` query param:
// /customers         → defaults to "active" tab
// /customers?tab=all → renders the "all" tab component

// Tab switching is handled internally:
<CustomersTabNavigation
  activeTab={params.tab}
  onTabChange={tab => setParam('tab', tab)}
/>

// The resolved tab component renders below the navigation:
{TabComponent ? <TabComponent /> : null}
```

## Notes

- Marked as `'use client'` — runs entirely on the client side
- `dynamic = 'force-dynamic'` disables static caching, ensuring query params are always read at runtime
- Gracefully renders nothing if an unrecognized tab key is passed (no `TabComponent` match)
