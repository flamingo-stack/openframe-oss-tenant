Renders the Organizations/Customers page with dynamic tab navigation, resolving the active tab from URL query params and rendering the corresponding tab component.

## Key Components

- **`Organizations`** — Default export; the page component that orchestrates tab state and rendering
- **`useApiParams`** — Hook used to read/write the `tab` query parameter (default: `'active'`)
- **`getTabComponent`** — Utility that resolves the correct component for the active tab from `CUSTOMERS_TABS`
- **`CustomersTabNavigation`** — Tab bar UI component wired to the current active tab and tab change handler

## Usage Example

```typescript
// Rendered automatically by Next.js at the /customers (or /organizations) route.
// Tab state is driven by the `?tab=` query param:
//   ?tab=active   → renders the Active Customers tab
//   ?tab=inactive → renders the Inactive Customers tab

// The tab navigation updates the URL param on change:
<CustomersTabNavigation
  activeTab={params.tab}
  onTabChange={tab => setParam('tab', tab)}
/>

// The resolved tab component is rendered below the nav:
{TabComponent ? <TabComponent /> : null}
```

## Notes

- Marked as `'use client'` — runs entirely on the client side
- `dynamic = 'force-dynamic'` disables static generation, ensuring query params are always evaluated at runtime
- Falls back gracefully to `null` if the resolved `TabComponent` is undefined (e.g. unknown tab value)
