Renders the Organizations/Customers page, managing tab-based navigation between customer views using URL-synced query parameters.

## Key Components

- **`Organizations`** — Default export; the main page component that reads and updates the active `tab` query param, resolves the matching tab component, and renders the navigation alongside it.
- **`useApiParams`** — Hook that syncs `tab` state with URL search params, defaulting to `'active'`.
- **`getTabComponent`** — Utility that resolves the correct tab component from `CUSTOMERS_TABS` based on the current tab key.
- **`CustomersTabNavigation`** — Tab navigation bar driven by `CUSTOMERS_TABS` config; fires `onTabChange` to update the URL param on selection.

## Usage Example

```typescript
// Rendered automatically by Next.js App Router at the /customers route.
// Tab state is driven by the URL: /customers?tab=active

// To add a new tab, extend CUSTOMERS_TABS in customers-tabs.tsx:
export const CUSTOMERS_TABS = [
  { key: 'active', label: 'Active', component: ActiveCustomers },
  { key: 'archived', label: 'Archived', component: ArchivedCustomers },
  // Add new tab here
];
```

> `export const dynamic = 'force-dynamic'` disables static caching, ensuring the page always reflects the latest server state on each request.
