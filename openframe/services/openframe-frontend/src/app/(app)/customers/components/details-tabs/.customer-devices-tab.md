Renders a scoped devices panel for a specific customer/organization, filtering and locking device views to a single `organizationId`.

## Key Components

- **`CustomerDevicesTab`** — Main component that wraps `DevicesPanel` with organization-scoped configuration
- **`lockedFilters`** — Memoized filter object restricting the panel to devices belonging to the given `organizationId`
- **`CustomerDevicesTabProps`** — Interface requiring a single `organizationId: string` prop

## Usage Example

```typescript
<CustomerDevicesTab organizationId="org_abc123" />
```

The component automatically:
- Locks the device list to the specified organization
- Pre-fills the "Add Device" link with the correct `organizationId` query param
- Hides the `organization` column and filter (redundant in single-org context)
