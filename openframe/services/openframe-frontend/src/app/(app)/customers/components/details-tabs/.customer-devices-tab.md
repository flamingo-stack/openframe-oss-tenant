Renders the **Devices** tab within a customer detail view, scoping the shared `DevicesPanel` to a single organization.

## Key Components

- **`CustomerDevicesTab`** — Tab component that wraps `DevicesPanel` with organization-specific constraints
- **`lockedFilters`** — Memoized filter object that pins the panel to the given `organizationId`, preventing cross-org data leakage
- **`hideColumns / hideFilters`** — Suppresses the `organization` column and filter since context is already scoped to one org

## Props

| Prop | Type | Description |
|------|------|-------------|
| `organizationId` | `string` | The organization whose devices are displayed |

## Usage Example

```typescript
import { CustomerDevicesTab } from './customer-devices-tab';

// Inside a customer detail page or tab layout
<CustomerDevicesTab organizationId="org_abc123" />
```

> The `addDeviceHref` link pre-populates the new device form with the current `organizationId`, ensuring newly created devices are automatically associated with the correct customer.
