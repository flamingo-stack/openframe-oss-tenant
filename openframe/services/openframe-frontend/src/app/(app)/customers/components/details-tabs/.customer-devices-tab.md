Renders a filtered devices panel scoped to a specific customer organization, used as a tab within the customer detail view.

## Key Components

- **`CustomerDevicesTab`** — Client component that wraps `DevicesPanel` with organization-scoped filters and configuration
- **`lockedFilters`** — Memoized filter object that locks the panel to display only devices belonging to the given `organizationId`

## Props

| Prop | Type | Description |
|------|------|-------------|
| `organizationId` | `string` | The organization ID used to filter and scope the devices panel |

## Usage Example

```typescript
import { CustomerDevicesTab } from './customer-devices-tab';

<CustomerDevicesTab organizationId="org_123abc" />
```

## Behavior Notes

- Hides the `organization` column and filter since the context is already scoped to a single org
- Pre-fills the "Add Device" link with the `organizationId` query param for seamless device creation
- `defaultStatuses` is set to an empty array, showing devices of all statuses by default
