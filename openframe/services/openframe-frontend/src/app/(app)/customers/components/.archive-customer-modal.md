Modal component that handles customer archiving with two states: a blocking alert when the customer has active devices, and a confirmation dialog when archiving is permitted.

## Key Components

### `ArchiveCustomerModal`
Main exported component that conditionally renders one of two dialogs based on the `canArchive` flag.

**Props (`ArchiveCustomerModalProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `open` | `boolean` | Controls dialog visibility |
| `onOpenChange` | `(open: boolean) => void` | Callback for open state changes |
| `canArchive` | `boolean` | Whether archiving is allowed (no active devices) |
| `onConfirm` | `() => void` | Callback executed on archive confirmation |
| `isPending` | `boolean?` | Shows loading state during async operation |

**Rendering logic:**
- `canArchive: false` → `AlertDialog` informing the user that active devices must be removed first
- `canArchive: true` → `ConfirmDialog` with a destructive confirmation flow

## Usage Example

```typescript
import { ArchiveCustomerModal } from './archive-customer-modal';

function CustomerActions({ customer }) {
  const [open, setOpen] = useState(false);
  const [isPending, setIsPending] = useState(false);

  const handleConfirm = async () => {
    setIsPending(true);
    await archiveCustomer(customer.id);
    setIsPending(false);
    setOpen(false);
  };

  return (
    <>
      <button onClick={() => setOpen(true)}>Archive</button>
      <ArchiveCustomerModal
        open={open}
        onOpenChange={setOpen}
        canArchive={customer.activeDevices === 0}
        onConfirm={handleConfirm}
        isPending={isPending}
      />
    </>
  );
}
```
