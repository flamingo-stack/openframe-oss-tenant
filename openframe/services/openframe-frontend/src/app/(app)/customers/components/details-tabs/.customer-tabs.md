Defines and exports the tab configuration for the customer detail view, mapping each tab (Devices, Tickets, Logs, Details) to its icon, label, and stable wrapper component.

## Key Components

- **`CustomerTabProps`** — Shared prop interface requiring a `CustomerDetails` organization object, passed to all tab components
- **`CUSTOMER_TABS`** — Static array of `TabItem` configs defining the four customer tabs with their icons and components
- **`getCustomerTab(tabId)`** — Looks up a `TabItem` by ID from `CUSTOMER_TABS`
- **`getCustomerTabComponent(tabId)`** — Returns the typed `ComponentType<CustomerTabProps>` for a given tab ID, or `null` if not found
- **Stable wrapper components** (`DevicesTab`, `TicketsTab`, `LogsTab`, `DetailsTab`) — Module-level wrappers that maintain stable function identities to prevent unnecessary unmount/remount cycles when the parent re-renders

## Usage Example

```typescript
import { CUSTOMER_TABS, getCustomerTabComponent } from './customer-tabs';

// Render all tabs in a navigation bar
<TabNavigation tabs={CUSTOMER_TABS} props={{ organization }} />

// Dynamically resolve a tab component by route param
const TabComponent = getCustomerTabComponent('devices');
if (TabComponent) {
  return <TabComponent organization={customerDetails} />;
}
```

> **Note:** Tab components are defined at module level (not inline) to keep their references stable across renders. Defining them inline would cause `TabNavigation`'s internal effect to reset the active tab on every parent re-render.
