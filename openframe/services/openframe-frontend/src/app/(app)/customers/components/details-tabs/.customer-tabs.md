Defines the tab configuration for the customer detail view, exporting a static tab registry with stable wrapper components and lookup utilities.

## Key Components

- **`CustomerTabProps`** — Shared prop interface requiring a `CustomerDetails` `organization` object, used by all tab wrapper components.
- **`CUSTOMER_TABS`** — Static `TabItem[]` array defining the four customer tabs: `devices`, `tickets`, `logs`, and `details`, each with an icon and component reference.
- **`DevicesTab` / `TicketsTab` / `LogsTab` / `DetailsTab`** — Module-level wrapper components that extract `organizationId` (or the full object for `DetailsTab`) before delegating to their respective tab implementations. Declared at module scope to keep function identities stable across parent re-renders, preventing unnecessary unmount/mount cycles in `TabNavigation`.
- **`getCustomerTab(tabId)`** — Looks up a `TabItem` by ID from `CUSTOMER_TABS`.
- **`getCustomerTabComponent(tabId)`** — Returns the `ComponentType<CustomerTabProps>` for a given tab ID, or `null` if not found.

## Usage Example

```typescript
import {
  CUSTOMER_TABS,
  getCustomerTabComponent,
} from './customer-tabs';

// Render a specific tab by ID
const tabId = 'devices';
const TabComponent = getCustomerTabComponent(tabId);

if (TabComponent) {
  return <TabComponent organization={customerDetails} />;
}

// Pass full tab list to a navigation component
return <TabNavigation tabs={CUSTOMER_TABS} />;
```

> **Note:** Wrapper components are defined at module level (not inline) so that `TabNavigation`'s internal effect — which depends on the `tabs` array reference — does not briefly reset the active tab during navigation transitions.
