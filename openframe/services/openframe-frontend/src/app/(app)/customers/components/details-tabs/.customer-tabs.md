Defines and exports the tab configuration for the customer detail view, mapping tab IDs to their corresponding icons, labels, and stable wrapper components.

## Key Components

- **`CustomerTabProps`** — Shared prop interface requiring a `CustomerDetails` organization object, passed to all tab components
- **`CUSTOMER_TABS`** — Static array of `TabItem` configs defining four tabs: `devices`, `tickets`, `logs`, and `details`
- **`getCustomerTab(tabId)`** — Looks up a `TabItem` by its string ID from `CUSTOMER_TABS`
- **`getCustomerTabComponent(tabId)`** — Returns the typed `ComponentType<CustomerTabProps>` for a given tab ID, or `null` if not found
- **Stable wrapper components** (`DevicesTab`, `TicketsTab`, `LogsTab`, `DetailsTab`) — Module-level wrappers that maintain referential identity across renders, preventing `TabNavigation` from unmounting/remounting the active tab on parent re-renders

## Usage Example

```typescript
import { CUSTOMER_TABS, getCustomerTabComponent } from './customer-tabs';

// Render a specific tab by ID
const tabId = 'devices';
const TabComponent = getCustomerTabComponent(tabId);

if (TabComponent) {
  return <TabComponent organization={customerDetails} />;
}

// Pass full tab config to a navigation component
return <TabNavigation tabs={CUSTOMER_TABS} activeTab={tabId} />;
```

> **Note:** Wrapper components are intentionally declared at module scope (not inline) to preserve function identity. Defining them inside the `CUSTOMER_TABS` array or a parent component would cause React to unmount and remount the active tab on every render cycle.
