Defines the column configuration, data transformation utilities, and UI components for rendering the customers data table, including search input and the full table body with device count integration.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `UiCustomerEntry` | Interface | Flattened UI-ready customer data shape used as table row data |
| `CUSTOMERS_COLUMNS` | `ColumnDef<UiCustomerEntry>[]` | Column definitions for Name, Tier, Devices, Last Activity, and open-in-new-tab action |
| `CustomerNameCell` | Component | Renders customer avatar, name, and email in the Name column |
| `transformCustomerToEntry` | Function | Maps a raw `Customer` + device count into a `UiCustomerEntry` |
| `customerRowHref` | Function | Generates the row navigation URL `/customers/details/:organizationId` |
| `CustomersSearchInput` | Component | Controlled search input with a search icon adornment |
| `CustomersTableBody` | Component | Full table composition: fetches device counts, transforms rows, renders `DataTable` with header, body, and optional footer |

## Usage Example

```typescript
import {
  CustomersTableBody,
  CustomersSearchInput,
} from './customers-table-columns';

// Render the search input + table together
function CustomersPage({ customers, isLoading }) {
  const [search, setSearch] = useState('');

  return (
    <div>
      <CustomersSearchInput value={search} onChange={setSearch} />
      <CustomersTableBody
        customers={customers}
        isLoading={isLoading}
        emptyMessage="No customers found."
        skeletonRows={8}
        stickyHeaderOffset="64px"
      />
    </div>
  );
}
```

> `CustomersTableBody` internally calls `useCustomerDeviceCounts` to enrich each row with live device counts, so no manual device data wiring is required.
