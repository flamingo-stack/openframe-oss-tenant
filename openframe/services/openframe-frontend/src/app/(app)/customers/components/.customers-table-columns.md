Defines the column configuration, cell renderers, and table body component for the Customers data table, including data transformation utilities and a search input component.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `UiCustomerEntry` | Interface | Flat UI-ready data shape for a customer row |
| `CUSTOMERS_COLUMNS` | `ColumnDef[]` | Column definitions for Name, Tier, Devices, Last Activity, and open-in-new-tab action |
| `CustomerNameCell` | Component | Renders customer avatar, name, and email in the Name column |
| `CustomersSearchInput` | Component | Controlled search input with a leading search icon |
| `CustomersTableBody` | Component | Full table with header, skeleton loading, empty state, and optional footer slot |
| `transformCustomerToEntry` | Function | Maps a raw `Customer` API object to a `UiCustomerEntry` for table consumption |
| `customerRowHref` | Function | Generates the row navigation URL (`/customers/details/:organizationId`) |

## Usage Example

```typescript
import {
  CustomersTableBody,
  CustomersSearchInput,
} from './customers-table-columns';

function CustomersPage() {
  const [search, setSearch] = useState('');
  const { customers, isLoading } = useCustomers({ search });

  return (
    <>
      <CustomersSearchInput value={search} onChange={setSearch} />
      <CustomersTableBody
        customers={customers}
        isLoading={isLoading}
        emptyMessage="No customers found."
        skeletonRows={8}
        stickyHeaderOffset="64px"
      />
    </>
  );
}
```

> **Note:** `CustomersTableBody` internally fetches device counts via `useCustomerDeviceCounts`, so no additional data wiring is needed for the Devices column.
