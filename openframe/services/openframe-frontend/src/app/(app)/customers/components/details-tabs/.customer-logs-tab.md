A thin wrapper component that renders the shared `LogsTable` within a customer detail view, scoping all log entries to a specific organization.

## Key Components

- **`CustomerLogsTab`** — Client component that delegates entirely to `LogsTable`, passing `organizationId` to lock the SOURCE filter to the current organization.

## Props

| Prop | Type | Description |
|------|------|-------------|
| `organizationId` | `string` | Scopes the logs table to a specific organization |

## Usage Example

```typescript
import { CustomerLogsTab } from './customer-logs-tab';

export function CustomerDetailPage({ orgId }: { orgId: string }) {
  return (
    <CustomerLogsTab organizationId={orgId} />
  );
}
```

## Notes

- Marked as `'use client'` — runs in the browser.
- Contains no local state or logic; all rendering, search, refresh, and filtering behavior is owned by `LogsTable`.
- The `organizationId` prop maps directly to the SOURCE filter inside `LogsTable`, ensuring logs are isolated to the given organization.
