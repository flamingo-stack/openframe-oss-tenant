A client-side tab component that renders activity logs scoped to a specific customer organization within the customer detail view.

## Key Components

**`CustomerLogsTab`** — Thin wrapper that delegates entirely to the shared `LogsTable` component, passing `organizationId` to automatically lock the SOURCE filter to the current organization.

### Props

| Prop | Type | Description |
|------|------|-------------|
| `organizationId` | `string` | Organization ID used to scope log entries to this customer |

## Usage Example

```typescript
import { CustomerLogsTab } from './customer-logs-tab';

// Inside a customer detail page or tabbed layout
<CustomerLogsTab organizationId="org_abc123" />
```

## Notes

- Marked as `'use client'` — runs in the browser.
- Intentionally minimal; all layout logic (title, Refresh button, search, pagination) is owned by `LogsTable`.
- The `organizationId` prop acts as a pre-applied SOURCE filter, so users see only logs relevant to this customer without manual filtering.
