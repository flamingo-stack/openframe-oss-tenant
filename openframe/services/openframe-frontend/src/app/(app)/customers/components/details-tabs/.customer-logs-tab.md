A client-side tab component that renders the activity logs view scoped to a specific customer organization.

## Key Components

- **`CustomerLogsTab`** — Thin wrapper that delegates fully to the shared `LogsTable` component, passing `organizationId` to automatically lock the SOURCE filter to the current organization.

## Usage Example

```typescript
<CustomerLogsTab organizationId="org_abc123" />
```

## Notes

- Marked as `'use client'` — renders on the client side.
- Contains no local state or layout logic; all rendering (title, Refresh button, search) is handled internally by `LogsTable`.
- The `organizationId` prop constrains log results to a single organization, preventing cross-tenant data exposure.
