Renders a tabbed navigation interface for switching between Active and Archived customer views, with optional URL query-string synchronization.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `CUSTOMERS_TABS` | `TabItem[]` | Static tab configuration array with `active` and `archived` tabs |
| `CustomersTabNavigation` | Component | Tab navigation wrapper with router-based tab switching |
| `ActiveCustomers` | Component (internal) | Renders `CustomersTable` filtered to `ACTIVE` status |
| `ArchivedCustomers` | Component (internal) | Renders `CustomersTable` filtered to `ARCHIVED` status |

### `CustomersTabNavigationProps`

| Prop | Type | Description |
|------|------|-------------|
| `activeTab` | `string?` | Currently selected tab ID; defaults to `'active'` |
| `onTabChange` | `(tab: string) => void` | Optional override for tab change handler; defaults to `router.replace` with `?tab=` query param |

## Usage Example

```typescript
// Basic usage — tab state driven by URL query param
<CustomersTabNavigation activeTab={searchParams.get('tab') ?? 'active'} />

// With custom tab change handler (e.g., controlled state)
<CustomersTabNavigation
  activeTab={currentTab}
  onTabChange={(tab) => setCurrentTab(tab)}
/>

// Using the static tab config directly (e.g., for testing or custom nav)
import { CUSTOMERS_TABS } from './customers-tabs';

const tabIds = CUSTOMERS_TABS.map(t => t.id); // ['active', 'archived']
```

> When `onTabChange` is not provided, tab changes update the URL via `router.replace` using the `?tab=` query parameter without adding a new browser history entry.
