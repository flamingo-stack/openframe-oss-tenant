Renders a tabbed navigation interface for switching between Active and Archived customer views, syncing the selected tab to the URL query string.

## Key Components

- **`CUSTOMERS_TABS`** — Static tab configuration array defining two tabs (`active`, `archived`) with icons and their respective table components
- **`ActiveCustomers`** — Internal component rendering `CustomersTable` filtered to `ACTIVE` status
- **`ArchivedCustomers`** — Internal component rendering `CustomersTable` filtered to `ARCHIVED` status
- **`CustomersTabNavigation`** — Main exported component wrapping `TabNavigation` with URL sync via `router.replace`

## Props

| Prop | Type | Description |
|---|---|---|
| `activeTab` | `string?` | Currently selected tab ID; defaults to `'active'` |
| `onTabChange` | `(tab: string) => void?` | Custom tab change handler; falls back to URL query sync |

## Usage Example

```typescript
// Basic usage — URL-driven tab state
<CustomersTabNavigation activeTab={searchParams.get('tab') ?? 'active'} />

// Custom tab change handler (e.g., controlled state)
<CustomersTabNavigation
  activeTab={currentTab}
  onTabChange={(tab) => setCurrentTab(tab)}
/>
```

> When no `onTabChange` is provided, switching tabs automatically appends `?tab=<id>` to the current pathname using `router.replace`, enabling shareable and back-navigable URLs without a full page reload.
