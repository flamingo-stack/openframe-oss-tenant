Renders a tabbed navigation interface for the Customers section, providing separate views for active and archived customers with URL-synced tab state.

## Key Components

- **`CUSTOMERS_TABS`** — Static array of `TabItem` config objects defining the two tabs: "Active Customers" (routes to `CustomersTable` with `status="ACTIVE"`) and "Archived Customers" (routes to `CustomersTable` with `status="ARCHIVED"`)
- **`ActiveCustomers`** / **`ArchivedCustomers`** — Private wrapper components that render `CustomersTable` with the appropriate `status` prop
- **`CustomersTabNavigation`** — Main exported component that wraps `TabNavigation` with router-based tab switching via query params (`?tab=<id>`)

## Props

| Prop | Type | Description |
|------|------|-------------|
| `activeTab` | `string?` | Currently active tab ID; defaults to `'active'` |
| `onTabChange` | `(tab: string) => void` | Optional override for tab change handler; defaults to `router.replace` with `?tab=` query param |

## Usage Example

```typescript
// Controlled usage with external tab state
<CustomersTabNavigation
  activeTab={searchParams.get('tab') ?? 'active'}
/>

// With custom tab change handler
<CustomersTabNavigation
  activeTab="archived"
  onTabChange={(tabId) => console.log('Tab changed to:', tabId)}
/>

// Using tab config directly in another TabNavigation context
import { CUSTOMERS_TABS } from './customers-tabs';
<TabNavigation tabs={CUSTOMERS_TABS} activeTab="active" />
```

> **Note:** By default, tab changes update the URL via `router.replace` using the current pathname and a `?tab=` query parameter, enabling shareable and browser-history-friendly navigation without a full page reload.
