Full-page view component for displaying customer details with tabbed navigation, archive/restore actions, and URL-synced tab state.

## Key Components

- **`CustomerDetailsView`** — Main export; renders the customer detail page within `PageLayout` using URL-driven tab state (`?tab=`) to avoid flicker bugs from internal tab sync effects
- **`TAB_IDS`** — Constant tuple defining valid tab slugs: `devices`, `tickets`, `logs`, `details`
- **`handleTabChange`** — Controlled tab handler that writes the active tab to the URL via `router.replace` without scroll
- **`actions`** — Memoized `PageActionButton[]` providing context-aware Archive/Restore and Edit buttons; disabled for default organizations
- **`handleArchiveClick`** — Pre-flight check via `checkCanArchive` before opening the archive modal
- **`handleArchiveConfirm` / `handleRestoreConfirm`** — Mutate organization status, invalidate relevant React Query caches, show toast feedback, and redirect

## Usage Example

```typescript
// app/customers/[id]/page.tsx
import { CustomerDetailsView } from '@/features/customers/components/customer-details-view';

interface PageProps {
  params: { id: string };
}

export default function CustomerPage({ params }: PageProps) {
  return <CustomerDetailsView id={params.id} />;
}
```

Navigate between tabs via URL:

```text
/customers/abc123?tab=devices
/customers/abc123?tab=tickets
/customers/abc123?tab=details
```

> **Note:** Tab state is derived exclusively from `searchParams` (not internal component state) to prevent a race condition where `TabNavigation`'s URL-sync effect could briefly reset the visible tab after an urgent state update.
