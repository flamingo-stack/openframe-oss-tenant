Main view component for displaying customer details, rendering a tabbed layout with actions for archiving, restoring, and editing a customer organization.

## Key Components

- **`CustomerDetailsView`** — Primary exported component accepting a customer `id` prop; orchestrates data fetching, tab navigation, and modal state
- **`TAB_IDS`** — Readonly tuple defining valid tab identifiers: `devices`, `tickets`, `logs`, `details`
- **`handleTabChange`** — URL-controlled tab switching via `router.replace` to avoid TabNavigation flicker in `urlSync` mode
- **`actions`** — Memoized `PageActionButton[]` array rendering Archive/Restore and Edit buttons based on organization status
- **`handleArchiveConfirm` / `handleRestoreConfirm`** — Async handlers that mutate organization status, invalidate React Query caches, show toasts, and redirect
- **`ArchiveCustomerModal` / `RestoreCustomerModal`** — Confirmation dialogs driven by local modal state

## Usage Example

```typescript
// Render the customer detail page for a given customer ID
import { CustomerDetailsView } from './customer-details-view';

export default function CustomerPage({ params }: { params: { id: string } }) {
  return <CustomerDetailsView id={params.id} />;
}
```

**Tab navigation via URL:**

```text
/customers/[id]?tab=devices   → Devices tab (default)
/customers/[id]?tab=tickets   → Tickets tab
/customers/[id]?tab=logs      → Logs tab
/customers/[id]?tab=details   → Details tab
```

> **Note:** Tab state is derived exclusively from the URL `?tab=` search parameter rather than internal component state, preventing a known flicker bug when `TabNavigation`'s `urlSync` mode lags behind React's urgent state updates.
