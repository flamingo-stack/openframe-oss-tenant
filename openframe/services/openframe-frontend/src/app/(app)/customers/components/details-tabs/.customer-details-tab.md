Renders a structured details card for a customer/organization, displaying website (with external link), physical address, and mailing address in a responsive grid layout.

## Key Components

- **`InfoCell`** — Reusable display cell showing a labeled value with optional icon and clickable `href`. Renders a plain `div` when empty or no `href` is provided; renders an `<a>` tag with `target="_blank"` when a valid link exists.
- **`CustomerDetailsTab`** — Main export. Accepts a `CustomerDetails` object and renders a two-row card: website row (with external link icon) and a responsive address row (physical + mailing).

## Usage Example

```typescript
import { CustomerDetailsTab } from './customer-details-tab';
import type { CustomerDetails } from '../../hooks/use-customer-details';

const org: CustomerDetails = {
  website: 'flamingo.run',
  physicalAddress: '123 Main St, Austin TX',
  mailingAddress: 'PO Box 456, Austin TX',
};

<CustomerDetailsTab organization={org} />
```

## Notes

- Empty or `"-"` values display as `—` (em dash) and suppress link rendering.
- Website URLs missing a protocol prefix are auto-prefixed with `https://`.
- Layout is single-column on mobile, two-column (`md:flex-row`) on wider screens.
- Styled with ODS design tokens (`ods-card`, `ods-border`, `ods-text-primary`, etc.) for dark-mode compatibility.
