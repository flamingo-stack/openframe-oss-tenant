Renders a structured details card for a customer/organization, displaying website, physical address, and mailing address in a responsive grid layout.

## Key Components

**`InfoCell`** — Internal display primitive that renders a labeled value with optional icon and external link support. Falls back to `—` for empty/missing values.

**`CustomerDetailsTab`** — Main exported component that composes `InfoCell` instances into a two-row card layout using `CustomerDetails` data.

## Props

| Prop | Type | Description |
|------|------|-------------|
| `organization` | `CustomerDetails` | Customer data object containing `website`, `physicalAddress`, and `mailingAddress` |

## Usage Example

```typescript
import { CustomerDetailsTab } from './customer-details-tab';

const org = {
  website: 'flamingo.run',
  physicalAddress: '123 Main St, Austin, TX',
  mailingAddress: 'PO Box 456, Austin, TX',
};

<CustomerDetailsTab organization={org} />
```

## Behaviors

- **Website normalization** — Prepends `https://` if the URL lacks a protocol prefix
- **External links** — Website renders as an `<a target="_blank">` only when a non-empty value is present
- **Empty state** — Any field that is empty or equals `"-"` renders `—` as a non-clickable placeholder
- **Responsive layout** — Address row stacks vertically on mobile, switches to horizontal (`md:flex-row`) on wider screens
