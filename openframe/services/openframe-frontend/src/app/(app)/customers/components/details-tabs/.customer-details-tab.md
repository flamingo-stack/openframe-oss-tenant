Renders a read-only details card for a customer/organization, displaying website (as a clickable external link) and physical/mailing addresses in a structured two-row layout.

## Key Components

**`InfoCell`** — Internal display cell that renders a labeled value with an optional icon. Automatically falls back to `—` for empty/missing values and conditionally wraps content in an `<a>` tag when an `href` is provided and the value is non-empty.

**`CustomerDetailsTab`** — Primary export. Accepts a `CustomerDetails` object and renders a bordered card with:
- Top row: website with external link icon (auto-prefixes `https://` if no protocol is present)
- Bottom row: physical and mailing addresses side-by-side on medium+ screens

## Usage Example

```typescript
import { CustomerDetailsTab } from './customer-details-tab';

const org: CustomerDetails = {
  website: 'flamingo.run',
  physicalAddress: '123 Main St, Austin, TX',
  mailingAddress: 'PO Box 456, Austin, TX',
};

<CustomerDetailsTab organization={org} />
```

## Props

| Prop | Type | Description |
|------|------|-------------|
| `organization` | `CustomerDetails` | Customer data object containing `website`, `physicalAddress`, and `mailingAddress` |
| `value` | `string` | *(InfoCell)* Display value; renders `—` if empty or `"-"` |
| `label` | `string` | *(InfoCell)* Field label shown below the value |
| `icon` | `ReactNode` | *(InfoCell)* Optional icon rendered inline with the value |
| `href` | `string` | *(InfoCell)* Makes the cell a clickable external link when value is non-empty |
