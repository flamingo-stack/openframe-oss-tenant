Renders a responsive subtitle row for organization detail tabs, combining a styled monospace heading with an optional slot for right-aligned action elements.

## Key Components

**`CustomerTabHeader`** — Client component that accepts:
- `title` *(string, required)* — Section heading rendered in monospace, semibold, responsive font size (`24px` → `28px`)
- `rightActions` *(ReactNode, optional)* — Arbitrary UI slotted into a flex row on the right (e.g. buttons, dropdowns)

## Usage Example

```typescript
import { CustomerTabHeader } from './customer-tab-header';
import { Button } from '@/components/ui/button';

// Title only
<CustomerTabHeader title="Devices" />

// With right-side actions
<CustomerTabHeader
  title="Active Tickets"
  rightActions={
    <Button size="sm" variant="outline">
      New Ticket
    </Button>
  }
/>
```

## Notes

- Wraps with `flex-wrap` so actions stack gracefully on narrow viewports
- `rightActions` is conditionally rendered — omitting it collapses the right slot entirely
- Typography follows the ODS design token `text-ods-text-primary` for consistent theming across organization detail tabs
