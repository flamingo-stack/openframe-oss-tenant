Renders a responsive header row for organization detail tabs, combining a styled title with an optional right-aligned action area.

## Key Components

**`CustomerTabHeader`** — Client component that displays a monospaced semibold heading alongside optional right-side actions in a flex row.

**`CustomerTabHeaderProps`**
| Prop | Type | Required | Description |
|---|---|---|---|
| `title` | `string` | ✅ | Section heading text |
| `rightActions` | `ReactNode` | ❌ | Buttons, badges, or controls rendered to the right |

## Usage Example

```typescript
import { CustomerTabHeader } from './customer-tab-header';

// Title only
<CustomerTabHeader title="Devices" />

// With right-side actions
<CustomerTabHeader
  title="Contacts"
  rightActions={
    <Button variant="outline" size="sm">
      + Add Contact
    </Button>
  }
/>
```

> The header wraps responsively via `flex-wrap`, so right actions drop below the title on narrow viewports rather than overflowing.
