Renders a subtitle row inside an organization detail tab, displaying a title alongside optional right-aligned action elements.

## Key Components

**`CustomerTabHeader`** — A layout component that renders a responsive flex row with a styled heading and an optional right-side actions slot.

| Prop | Type | Required | Description |
|------|------|----------|-------------|
| `title` | `string` | ✅ | Section heading text displayed in monospace font |
| `rightActions` | `ReactNode` | ❌ | Buttons, badges, or any React nodes rendered to the right |

## Usage Example

```typescript
import { CustomerTabHeader } from './customer-tab-header';

// Title only
<CustomerTabHeader title="Devices" />

// With right-side actions
<CustomerTabHeader
  title="Tickets"
  rightActions={
    <Button size="sm" variant="primary">
      New Ticket
    </Button>
  }
/>
```

> The header wraps gracefully on small screens via `flex-wrap`, keeping actions below the title on mobile viewports.
