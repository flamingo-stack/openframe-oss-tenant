A React tab component that displays and manages support tickets associated with a specific customer organization, featuring search, infinite scroll, and row-level navigation.

## Key Components

### `CustomerTicketsTab`
Main exported component that renders a searchable, paginated ticket table scoped to a given organization.

**Props:**
| Prop | Type | Description |
|------|------|-------------|
| `organizationId` | `string` | Filters tickets to those belonging to this organization |

### `ticketBelongsToOrganization`
Internal utility that checks ticket ownership — matches directly via `organizationId` or via a nested `machine.organizationId` on client-owned dialogs.

## Key Behaviors

- **Debounced search** — 300ms delay on search input before querying
- **Client-side filtering** — filters the full ticket list to only those matching the organization
- **Infinite scroll** — loads additional pages via `DataTable.InfiniteFooter`
- **New tab navigation** — the "open" column action opens the ticket in a new tab without blocking row-click navigation
- **Sticky search bar** — uses negative margin trick to extend background without adding layout space; table header docks at `top-[96px]`

## Usage Example

```typescript
import { CustomerTicketsTab } from './customer-tickets-tab';

// Inside a customer detail page or dialog
<CustomerTicketsTab organizationId="org_abc123" />
```

```typescript
// Ticket ownership resolution (internal)
ticketBelongsToOrganization(ticket, 'org_abc123');
// → true if ticket.organizationId matches OR
//   ticket.owner.machine.organizationId matches
```
