Renders a filterable, paginated ticket list scoped to a specific customer organization within the OpenFrame customer detail view.

## Key Components

- **`CustomerTicketsTab`** — Main exported component; accepts `organizationId` to filter tickets belonging to that org
- **`ticketBelongsToOrganization`** — Helper that checks ticket ownership by direct `organizationId` match or via a machine's `organizationId` on `ClientDialogOwner`
- **`useTicketsQuery`** — Fetches paginated, searchable tickets (unarchived)
- **`useDataTable`** — Configures the table instance with org-filtered rows and custom column definitions
- **`columns`** — Extends base ticket columns with an "open in new tab" action button per row

## Usage Example

```typescript
import { CustomerTicketsTab } from './customer-tickets-tab';

// Inside a customer detail page or tab layout
<CustomerTicketsTab organizationId="org_abc123" />
```

## Behavior Notes

- **Search** is debounced at 300ms and passed to `useTicketsQuery`; filtering by org is applied client-side via `useMemo`
- **Sticky search bar** uses negative margin (`-my`) to extend background without affecting layout height; the `DataTable` header sticks at `top-[96px]`
- **Infinite scroll** is handled by `DataTable.InfiniteFooter` using `fetchNextPage` from the query hook
- **New Ticket** button navigates to `/tickets/new` via `router.push`
- **Row clicks** navigate to `/tickets/dialog?id=<id>`; the open-in-new-tab button is wrapped in `data-no-row-click` to prevent row navigation from firing
