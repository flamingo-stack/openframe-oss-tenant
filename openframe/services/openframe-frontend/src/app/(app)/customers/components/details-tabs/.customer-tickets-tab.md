A React client component that renders a filterable, paginated ticket list for a specific customer organization within the OpenFrame MSP platform.

## Key Components

- **`CustomerTicketsTab`** — Main export; displays all tickets belonging to a given `organizationId` with search, infinite scroll, and row-level navigation
- **`ticketBelongsToOrganization`** — Helper that matches tickets to an org either by direct `organizationId` or via the ticket's associated machine owner
- **`useTicketsQuery`** — Fetches paginated, searchable ticket dialogs from the backend
- **`useDataTable`** — Wires column definitions and data into a table instance consumed by `DataTable`
- **Sticky search bar** — Positioned at `top-0 z-20` with bleed margins so the background extends seamlessly when pinned, while the table header docks at `top-[96px]`
- **Open-in-new-tab column** — Appends an icon button per row linking to `/tickets/dialog?id=<id>` without triggering the row click handler (`data-no-row-click`)

## Usage Example

```typescript
import { CustomerTicketsTab } from './customer-tickets-tab';

// Inside a customer detail page or tab panel:
<CustomerTicketsTab organizationId="org_abc123" />
```

The component accepts a single prop:

| Prop | Type | Description |
|---|---|---|
| `organizationId` | `string` | Filters the global ticket list to only tickets owned by (or machine-linked to) this organization |

> **Note:** Ticket filtering is performed client-side via `useMemo` after the full paginated result set is fetched. For large datasets, ensure the `search` debounce (300 ms) and server-side `search` parameter reduce the payload before client filtering runs.
