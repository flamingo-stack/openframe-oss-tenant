React page component for creating and editing customer (organization) records, handling form state, image uploads, and API submission for both new and existing customers.

## Key Components

### `NewCustomerPage`
Main exported component that renders a full-page form for customer creation or editing.

**Props:**
- `organizationId` — `string | null` — When provided, switches the form into edit mode and prefills data from the existing organization.

### Internal State
| State | Type | Purpose |
|-------|------|---------|
| `form` | `FormState` | Core editable fields (name, website, notes, addresses) |
| `preserved` | `PreservedFields` | Fields not directly edited here but round-tripped on save (contacts, revenue, contract dates) |
| `pendingFile` | `File \| null` | Holds logo file in memory for new orgs until after creation |
| `isSubmitting` | `boolean` | Guards against duplicate submissions |

### Key Behaviors
- **Edit mode prefill** — When `organizationId` is provided, fetches organization details via `useCustomerDetails` and hydrates form fields once (`didPrefill` guard prevents re-hydration on re-renders)
- **Mailing address sync** — Automatically mirrors physical address to mailing address when `mailingSameAsPhysical` is `true`
- **Deferred logo upload** — For new customers, the logo is held as a local `File` and uploaded after the organization is created
- **Blob URL cleanup** — `URL.revokeObjectURL` is called on unmount to prevent memory leaks

## Usage Example

```typescript
// Create mode
<NewCustomerPage organizationId={null} />

// Edit mode
<NewCustomerPage organizationId="org_abc123" />
```

The component navigates to `/customers` after creation or back to `/customers/details/:id` after an update, using `safeBackOrReplace` to handle browser history safely.
