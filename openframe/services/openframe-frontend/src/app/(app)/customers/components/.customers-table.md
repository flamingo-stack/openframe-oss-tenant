Renders the main customers list page with search, infinite scroll pagination, and an "Add Customer" action button.

## Key Components

- **`CustomersTable`** — Primary export; a `PageLayout`-wrapped table component that composes search input, data table body, and infinite scroll footer
- **`CustomersSearchInput`** — Search field with debounced URL param sync (500ms delay)
- **`CustomersTableBody`** — Renders the actual table rows with skeleton loading and empty states
- **`DataTable.InfiniteFooter`** — Appended when more pages are available, triggers `fetchNextPage` on scroll/click

## Key Behaviors

- Search state is kept locally (`localSearch`) and synced to URL params only after the 500ms debounce via `useApiParams`
- On filter/search change, the `<main>` scroll position resets to top (`instant` behavior, skipped on initial mount)
- The "Add Customer" button navigates to `/customers/edit/new`
- Error messages are rendered inline using the `ods-attention-red-error` token

## Usage Example

```typescript
// Render all customers (no status filter)
<CustomersTable />

// Render only active customers
<CustomersTable status="active" />
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `status` | `string` | `undefined` | Optional filter passed to `useCustomers` to scope results by customer status |
