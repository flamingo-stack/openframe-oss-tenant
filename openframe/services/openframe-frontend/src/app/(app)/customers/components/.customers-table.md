Renders the main customers list page with search, infinite scroll pagination, and an "Add Customer" action button.

## Key Components

- **`CustomersTable`** — Primary export; a page-level component that composes the full customers list UI
- **`CustomersSearchInput`** — Search field with debounced query synced to URL params via `useApiParams`
- **`CustomersTableBody`** — Renders the data rows, skeleton loading states, and empty messages
- **`DataTable.InfiniteFooter`** — Load-more footer triggered when `hasNextPage` is true
- **`PageLayout`** — Wraps the page with a title bar and action buttons

## Props

| Prop | Type | Description |
|------|------|-------------|
| `status` | `string` (optional) | Filters customers by status when passed |

## Usage Example

```typescript
// Render all customers
<CustomersTable />

// Render only active customers
<CustomersTable status="active" />
```

## Behavior Notes

- Search input is **debounced 500ms** before updating URL params and triggering API calls via `useCustomers`
- On search change, the page scrolls back to top (skipped on initial mount)
- "Add Customer" navigates to `/customers/edit/new`
- Infinite scroll is handled via `fetchNextPage` from the `useCustomers` hook, rendered as a `DataTable.InfiniteFooter` when more pages exist
- Errors from the API are displayed inline in red using the `ods-attention-red-error` token
