Renders the full-page customers list view with search, infinite scroll pagination, and an "Add Customer" action button.

## Key Components

- **`CustomersTable`** — Main export; a `PageLayout`-wrapped table component that composes search input, data table body, and infinite scroll footer
- **`CustomersTableProps`** — Interface accepting an optional `status` filter string
- **`useCustomers`** — Hook driving paginated customer data fetching, called with debounced search and status params
- **`useApiParams`** / `useDebounce` — Sync URL search params with a 500ms debounced local search state
- **`CustomersSearchInput`** / **`CustomersTableBody`** — Column-layer sub-components for input rendering and row rendering respectively

## Usage Example

```typescript
// Render all customers
<CustomersTable />

// Render only active customers
<CustomersTable status="active" />
```

## Behavior Notes

- Search input is debounced (500ms) before updating URL params and triggering a refetch
- On search change, the `main` scroll container resets to the top (skipped on initial mount)
- "Add Customer" button navigates to `/customers/edit/new`
- Infinite scroll is handled by `DataTable.InfiniteFooter` when `hasNextPage` is truthy
- Error state renders an inline message styled with `ods-attention-red-error`
