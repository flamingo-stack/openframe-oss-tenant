A confirmation modal component for restoring a previously archived/deleted customer back to the active workspace.

## Key Components

- **`RestoreCustomerModal`** — Thin wrapper around `ConfirmDialog` pre-configured with restore-specific copy and a `"default"` variant.
- **`RestoreCustomerModalProps`** — Interface defining the modal's control props.

| Prop | Type | Description |
|------|------|-------------|
| `open` | `boolean` | Controls modal visibility |
| `onOpenChange` | `(open: boolean) => void` | Callback to toggle open state |
| `onConfirm` | `() => void` | Triggered on confirmation |
| `isPending` | `boolean?` | Shows `"Restoring..."` label during async operation |

## Usage Example

```typescript
import { RestoreCustomerModal } from './restore-customer-modal';

function CustomerActions({ customerId }: { customerId: string }) {
  const [open, setOpen] = useState(false);
  const { mutate: restoreCustomer, isPending } = useRestoreCustomer();

  return (
    <>
      <button onClick={() => setOpen(true)}>Restore</button>
      <RestoreCustomerModal
        open={open}
        onOpenChange={setOpen}
        onConfirm={() => restoreCustomer(customerId)}
        isPending={isPending}
      />
    </>
  );
}
```

> The `isPending` prop disables interaction and swaps the confirm button label to `"Restoring..."` while the restore operation is in flight.
