A confirmation modal component for restoring a previously archived/deleted customer back to the active workspace.

## Key Components

### `RestoreCustomerModalProps`
| Prop | Type | Description |
|------|------|-------------|
| `open` | `boolean` | Controls modal visibility |
| `onOpenChange` | `(open: boolean) => void` | Callback when modal open state changes |
| `onConfirm` | `() => void` | Callback executed when restoration is confirmed |
| `isPending?` | `boolean` | Displays loading state during async restore operation |

### `RestoreCustomerModal`
A thin wrapper around the shared `ConfirmDialog` component, pre-configured with restore-specific labels and a `default` variant.

## Usage Example

```typescript
import { RestoreCustomerModal } from './restore-customer-modal';

function CustomerActions() {
  const [open, setOpen] = useState(false);
  const { mutate: restoreCustomer, isPending } = useRestoreCustomer();

  return (
    <>
      <Button onClick={() => setOpen(true)}>Restore</Button>
      <RestoreCustomerModal
        open={open}
        onOpenChange={setOpen}
        onConfirm={() => restoreCustomer(customerId)}
        isPending={isPending}
      />
    </>
  );
}
```
