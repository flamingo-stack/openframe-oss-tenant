A reusable confirmation modal for restoring an archived customer back to the active workspace.

## Key Components

- **`RestoreCustomerModal`** — Thin wrapper around `ConfirmDialog` pre-configured with restore-specific copy and a `default` variant.

### Props (`RestoreCustomerModalProps`)

| Prop | Type | Description |
|------|------|-------------|
| `open` | `boolean` | Controls modal visibility |
| `onOpenChange` | `(open: boolean) => void` | Callback to toggle open state |
| `onConfirm` | `() => void` | Handler executed on confirmation |
| `isPending` | `boolean?` | Shows loading state while restore is in progress |

## Usage Example

```typescript
import { RestoreCustomerModal } from './restore-customer-modal';

function CustomerActions({ customerId }: { customerId: string }) {
  const [open, setOpen] = useState(false);
  const { mutate: restoreCustomer, isPending } = useRestoreCustomer();

  return (
    <>
      <button onClick={() => setOpen(true)}>Restore</button>
      <RestoreCustomerModal
        open={open}
        onOpenChange={setOpen}
        onConfirm={() => restoreCustomer(customerId)}
        isPending={isPending}
      />
    </>
  );
}
```

> The component delegates all rendering to `ConfirmDialog`, keeping restore-specific UI concerns (title, description, button labels) co-located and the call site free of boilerplate.
