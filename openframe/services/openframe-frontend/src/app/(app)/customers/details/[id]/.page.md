Client-side Next.js page wrapper that extracts the `id` route parameter and passes it to the `CustomerDetailsView` component.

## Key Components

- **`CustomerDetailsPageWrapper`** — Default export; reads the dynamic `[id]` segment from the URL and renders the customer details view.

## Usage Example

```typescript
// Accessed via route: /customers/[id]
// e.g. /customers/abc123
// Automatically renders:
<CustomerDetailsView id="abc123" />
```

> Route param is safely coerced to an empty string if absent or non-string, preventing type errors downstream.
