Client-side Next.js page wrapper that extracts the `id` route parameter and passes it to the `CustomerDetailsView` component.

## Key Components

- **`CustomerDetailsPageWrapper`** — Default export; a `'use client'` page component that reads the dynamic `[id]` segment from the URL and delegates rendering to `CustomerDetailsView`.

## Usage Example

```typescript
// Rendered automatically by Next.js when navigating to:
// /customers/[id]  →  e.g. /customers/abc-123

// The wrapper safely coerces the param to a string before forwarding:
const id = typeof params?.id === 'string' ? params.id : '';
return <CustomerDetailsView id={id} />;
```

## Notes

- Uses `useParams<{ id?: string }>()` with a safe type guard to handle cases where the param may be `undefined` or an array, defaulting to an empty string.
- All rendering logic lives in `CustomerDetailsView`; this file is intentionally thin.
