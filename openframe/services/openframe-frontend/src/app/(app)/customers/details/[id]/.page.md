Client-side Next.js page component that extracts the `id` route parameter and passes it to the `CustomerDetailsView` component for rendering customer details.

## Key Components

- **`CustomerDetailsPageWrapper`** — Default export; reads the dynamic `[id]` segment from the URL and delegates rendering to `CustomerDetailsView`.

## Usage Example

```typescript
// Accessed via route: /customers/[id]
// e.g. /customers/abc-123
// The `id` param is safely extracted and passed down:
<CustomerDetailsView id="abc-123" />
```

> `params.id` is validated to be a `string` before use; falls back to `''` if undefined.
