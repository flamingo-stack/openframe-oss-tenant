A React hook providing archive management operations for customer organizations, including eligibility checks, archiving, and restoration.

## Key Components

- **`checkCanArchive(id)`** — Calls `GET /api/organizations/:id/can-archive` to verify if an organization is eligible for archiving. Returns a `boolean`.
- **`archiveOrganization(id)`** — Sends a `PATCH` to `/api/organizations/:id/status` with `{ status: 'ARCHIVED' }` to archive the organization.
- **`restoreOrganization(id)`** — Sends a `PATCH` to `/api/organizations/:id/status` with `{ status: 'ACTIVE' }` to restore a previously archived organization.

All three methods are memoized with `useCallback` and throw descriptive errors on failed API responses.

## Usage Example

```typescript
import { useCustomerArchive } from '@/hooks/use-customer-archive';

function CustomerActions({ customerId }: { customerId: string }) {
  const { checkCanArchive, archiveOrganization, restoreOrganization } = useCustomerArchive();

  const handleArchive = async () => {
    const canArchive = await checkCanArchive(customerId);
    if (!canArchive) {
      alert('This customer cannot be archived.');
      return;
    }
    await archiveOrganization(customerId);
  };

  const handleRestore = async () => {
    await restoreOrganization(customerId);
  };

  return (
    <>
      <button onClick={handleArchive}>Archive</button>
      <button onClick={handleRestore}>Restore</button>
    </>
  );
}
```
