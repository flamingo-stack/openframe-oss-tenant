React hook providing archive/restore operations for customer organizations, including eligibility checking before archiving.

## Key Components

- **`useCustomerArchive()`** — Custom hook returning three memoized async functions:
  - `checkCanArchive(id)` — Calls `GET /api/organizations/:id/can-archive` to verify archive eligibility
  - `archiveOrganization(id)` — Patches organization status to `ARCHIVED`
  - `restoreOrganization(id)` — Patches organization status back to `ACTIVE`

All functions throw on non-OK API responses.

## Usage Example

```typescript
import { useCustomerArchive } from '@/hooks/use-customer-archive';

function CustomerActions({ customerId }: { customerId: string }) {
  const { checkCanArchive, archiveOrganization, restoreOrganization } = useCustomerArchive();

  const handleArchive = async () => {
    const canArchive = await checkCanArchive(customerId);
    if (!canArchive) {
      alert('Customer cannot be archived (active tickets or dependencies exist).');
      return;
    }
    await archiveOrganization(customerId);
  };

  const handleRestore = async () => {
    await restoreOrganization(customerId);
  };

  return (
    <>
      <button onClick={handleArchive}>Archive</button>
      <button onClick={handleRestore}>Restore</button>
    </>
  );
}
```

> **Note:** Always call `checkCanArchive` before `archiveOrganization` to avoid archiving organizations with open dependencies (e.g., active tickets or linked assets).
