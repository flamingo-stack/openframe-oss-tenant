React Query hook that fetches and returns device counts per organization as a stable `Map<string, number>`, using a GraphQL query filtered by organization IDs.

## Key Components

- **`organizationDeviceCountsKeys`** — Query key factory for cache scoping; sorts organization IDs to ensure stable cache keys regardless of input order.
- **`useCustomerDeviceCounts(organizationIds)`** — Primary hook that queries the GraphQL endpoint and returns a map of organization ID → device count. Skips fetching when the ID list is empty and caches results for 30 seconds.

## Usage Example

```typescript
import { useCustomerDeviceCounts } from './use-customer-device-counts';

function CustomerList({ orgIds }: { orgIds: string[] }) {
  const { deviceCounts, isLoading } = useCustomerDeviceCounts(orgIds);

  if (isLoading) return <Spinner />;

  return (
    <>
      {orgIds.map((id) => (
        <div key={id}>
          Org {id}: {deviceCounts.get(id) ?? 0} devices
        </div>
      ))}
    </>
  );
}
```

## Return Value

| Field | Type | Description |
|-------|------|-------------|
| `deviceCounts` | `ReadonlyMap<string, number>` | Organization ID to device count mapping; empty map when no data |
| `isLoading` | `boolean` | `true` while the initial fetch is in progress |

## Notes

- Input IDs are sorted via `useMemo` before use, preventing unnecessary re-fetches when the array reference changes but contents are the same.
- Falls back to a shared `EMPTY_DEVICE_COUNTS` constant (not a new `Map`) to avoid referential instability in consumers.
