A React Query hook that fetches and maps device counts per organization from a GraphQL endpoint, returning a stable `Map<string, number>` keyed by organization ID.

## Key Components

- **`organizationDeviceCountsKeys`** — Query key factory for cache management and invalidation
- **`useCustomerDeviceCounts(organizationIds)`** — Primary hook that accepts an array of organization IDs and returns device counts with loading state
- **`EMPTY_DEVICE_COUNTS`** — Immutable empty map used as a safe default before data loads
- **`GET_DEVICE_COUNTS_QUERY`** — GraphQL query fetching `organizationIds` aggregation from `deviceFilters`

## Behavior Notes

- Organization IDs are **sorted and memoized** before use, ensuring a stable query key regardless of input array order
- Query is **disabled** when `organizationIds` is empty
- Data is considered **stale after 30 seconds** (`staleTime: 30_000`)
- Both GraphQL-level errors and HTTP-level errors are surfaced as thrown `Error` instances

## Usage Example

```typescript
import { useCustomerDeviceCounts } from '@/hooks/use-customer-device-counts';

function CustomerList({ orgIds }: { orgIds: string[] }) {
  const { deviceCounts, isLoading } = useCustomerDeviceCounts(orgIds);

  if (isLoading) return <Spinner />;

  return (
    <ul>
      {orgIds.map((id) => (
        <li key={id}>
          Org {id}: {deviceCounts.get(id) ?? 0} devices
        </li>
      ))}
    </ul>
  );
}
```
