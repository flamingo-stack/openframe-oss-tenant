React Query hook that fetches and maps device counts per organization ID using a GraphQL query, returning a stable `ReadonlyMap<string, number>` keyed by organization ID.

## Key Components

- **`organizationDeviceCountsKeys`** — Query key factory for cache management and invalidation
- **`useCustomerDeviceCounts(organizationIds)`** — Primary hook that accepts an array of organization IDs and returns device counts with loading state
- **`EMPTY_DEVICE_COUNTS`** — Shared empty map constant to avoid unnecessary re-renders when no data is available
- **`GET_DEVICE_COUNTS_QUERY`** — GraphQL query fetching `deviceFilters.organizationIds` aggregation

## Usage Example

```typescript
import { useCustomerDeviceCounts } from './use-customer-device-counts';

function CustomerList({ orgIds }: { orgIds: string[] }) {
  const { deviceCounts, isLoading } = useCustomerDeviceCounts(orgIds);

  if (isLoading) return <Spinner />;

  return (
    <ul>
      {orgIds.map((id) => (
        <li key={id}>
          Org {id}: {deviceCounts.get(id) ?? 0} devices
        </li>
      ))}
    </ul>
  );
}
```

## Notes

- Organization IDs are **sorted before use** (`useMemo`) to produce a stable query key regardless of input order, preventing duplicate cache entries
- Query is **disabled** when `organizationIds` is empty
- Results are cached for **30 seconds** (`staleTime: 30_000`)
- Both GraphQL-level and HTTP-level errors are surfaced as thrown `Error` instances
