A React hook that provides a memoized function for updating an existing customer/organization via the API.

## Key Components

- **`useUpdateCustomer`** — Custom hook returning `updateOrganization`, a `useCallback`-memoized async function
- **`updateOrganization(id, request)`** — Sends a `PUT` request to `/api/organizations/{id}` with the update payload; throws on failure

## Usage Example

```typescript
import { useUpdateCustomer } from './use-update-customer';
import type { CreateCustomerRequest } from './use-create-customer';

function EditCustomerForm({ customerId }: { customerId: string }) {
  const { updateOrganization } = useUpdateCustomer();

  const handleSubmit = async (data: CreateCustomerRequest) => {
    try {
      const updated = await updateOrganization(customerId, data);
      console.log('Updated:', updated);
    } catch (err) {
      console.error('Update failed:', err);
    }
  };
}
```

## Notes

- Reuses `CreateCustomerRequest` type from `use-create-customer` for the update payload shape
- Throws an `Error` using the API error message or a fallback status string if the response is not `ok`
- The callback is stable across renders (no dependencies), safe to pass as a prop or use in `useEffect`
