React hook for updating an existing customer/organization via a PUT request to the organizations API endpoint.

## Key Components

- **`useUpdateCustomer`** — Custom hook that exposes an `updateOrganization` function, memoized with `useCallback`
- **`updateOrganization(id, request)`** — Sends a `PUT` request to `/api/organizations/:id`; throws on non-OK responses

## Usage Example

```typescript
import { useUpdateCustomer } from './use-update-customer';

function EditCustomerForm({ customerId }: { customerId: string }) {
  const { updateOrganization } = useUpdateCustomer();

  const handleSubmit = async (data: CreateCustomerRequest) => {
    try {
      const updated = await updateOrganization(customerId, data);
      console.log('Updated:', updated);
    } catch (error) {
      console.error('Update failed:', error);
    }
  };
}
```

## Notes

- Reuses `CreateCustomerRequest` type from `use-create-customer` for the request payload shape
- Throws a descriptive `Error` on failure, using the API error message when available
