React hook for updating an existing customer/organization record via the API.

## Key Components

- **`useUpdateCustomer`** — Custom hook that returns an `updateOrganization` callback
- **`updateOrganization(id, request)`** — Sends a `PUT` request to `/api/organizations/:id` with the provided payload; throws on non-OK responses

## Usage Example

```typescript
import { useUpdateCustomer } from './use-update-customer';

function EditCustomerForm({ customerId }: { customerId: string }) {
  const { updateOrganization } = useUpdateCustomer();

  const handleSubmit = async (data: CreateCustomerRequest) => {
    try {
      const updated = await updateOrganization(customerId, data);
      console.log('Updated:', updated);
    } catch (err) {
      console.error('Update failed:', err);
    }
  };
}
```

## Notes

- Reuses `CreateCustomerRequest` type from `use-create-customer` for the request payload shape
- The callback is memoized with `useCallback` to prevent unnecessary re-renders
- Throws an `Error` using the API error message or a fallback status string on failure
