A React hook for fetching a minimal subset of organization/customer data via GraphQL, optimized for lightweight lookups such as search dropdowns and selectors.

## Key Components

### `OrganizationMin` Interface
Minimal organization shape returned by the hook:

| Field | Type | Description |
|-------|------|-------------|
| `id` | `string` | Internal node ID |
| `organizationId` | `string` | Business-level organization ID |
| `name` | `string` | Display name |
| `isDefault` | `boolean` | Whether this is the default organization |
| `imageUrl` | `string?` | Optional organization logo URL |

### `useCustomersMin(limit?)`
Client-side hook that queries `GET_ORGANIZATIONS_MIN_QUERY` via the GraphQL API endpoint. Accepts an optional `limit` (default: `10`) to cap results.

**Returns:**

| Field | Type | Description |
|-------|------|-------------|
| `items` | `OrganizationMin[]` | Fetched organization list |
| `isLoading` | `boolean` | Loading state |
| `error` | `string \| null` | Error message if request failed |
| `fetch` | `(search?: string) => Promise<OrganizationMin[]>` | Trigger function with optional search string |

## Usage Example

```typescript
import { useCustomersMin } from '@/features/customers/hooks/use-customers-min';

function CustomerSearchDropdown() {
  const { items, isLoading, error, fetch } = useCustomersMin(20);

  const handleSearch = async (query: string) => {
    await fetch(query);
  };

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;

  return (
    <Select
      options={items.map(org => ({ label: org.name, value: org.id }))}
      onInputChange={handleSearch}
    />
  );
}
```

> **Note:** `fetch` is memoized via `useCallback` and only recreates when `limit` changes, making it safe to use as a `useEffect` dependency.
