React hook for fetching a minimal subset of organization/customer data via GraphQL, optimized for lightweight search and dropdown use cases.

## Key Components

### `OrganizationMin` Interface
Lightweight organization shape containing only essential fields:
- `id` / `organizationId` — unique identifiers
- `name` — display name
- `isDefault` — default org flag
- `imageUrl` *(optional)* — logo/avatar URL

### `useCustomersMin(limit?)`
Client-side hook that queries `GET_ORGANIZATIONS_MIN_QUERY` against `/api/graphql`.

| Return | Type | Description |
|--------|------|-------------|
| `items` | `OrganizationMin[]` | Current fetched results |
| `isLoading` | `boolean` | Request in-flight state |
| `error` | `string \| null` | Last error message |
| `fetch` | `(search?: string) => Promise<OrganizationMin[]>` | Trigger search fetch |

The `fetch` callback is memoized via `useCallback` on `limit`, preventing unnecessary re-creation on parent re-renders.

## Usage Example

```typescript
import { useCustomersMin } from '@/features/customers/hooks/use-customers-min';

export function CustomerSearch() {
  const { items, isLoading, error, fetch } = useCustomersMin(20);

  const handleSearch = async (query: string) => {
    await fetch(query);
  };

  return (
    <div>
      <input onChange={(e) => handleSearch(e.target.value)} placeholder="Search customers..." />
      {isLoading && <Spinner />}
      {error && <p className="text-red-500">{error}</p>}
      {items.map((org) => (
        <div key={org.id}>{org.name}</div>
      ))}
    </div>
  );
}
```

> **Note:** `fetch` returns the mapped array directly, allowing callers to use results imperatively without relying solely on the `items` state — useful for one-shot lookups in form fields or comboboxes.
