A React hook for fetching a lightweight list of organizations/customers via GraphQL, optimized for search and selection UI components.

## Key Components

**`OrganizationMin`** — Minimal organization shape containing `id`, `organizationId`, `name`, `isDefault`, and optional `imageUrl`.

**`useCustomersMin(limit?)`** — Client-side hook that queries `GET_ORGANIZATIONS_MIN_QUERY` and returns:

| Return | Type | Description |
|--------|------|-------------|
| `items` | `OrganizationMin[]` | Fetched organization list |
| `isLoading` | `boolean` | Request in-flight state |
| `error` | `string \| null` | Error message if request failed |
| `fetch` | `(search?: string) => Promise<OrganizationMin[]>` | Trigger fetch with optional search string |

## Usage Example

```typescript
import { useCustomersMin } from '@/features/customers/hooks/use-customers-min';

function CustomerSearch() {
  const { items, isLoading, error, fetch } = useCustomersMin(20);

  const handleSearch = async (query: string) => {
    await fetch(query);
  };

  return (
    <select onChange={(e) => handleSearch(e.target.value)}>
      {isLoading && <option>Loading...</option>}
      {items.map((org) => (
        <option key={org.id} value={org.organizationId}>
          {org.name}
        </option>
      ))}
    </select>
  );
}
```

> **Note:** `fetch` is memoized via `useCallback` and only recreated when `limit` changes, making it safe to use as an effect dependency in search/autocomplete scenarios.
