React Query infinite scroll hook for fetching and paginating customer/organization data from a GraphQL API, with built-in error toasting and data normalization.

## Key Components

**Interfaces**
- `Customer` — normalized customer shape consumed by UI components
- `OrganizationNode` — raw GraphQL response shape for an organization
- `CustomersPage` — single page payload containing customers, pagination cursors, and total count

**Exports**
- `mapOrganizationNode(node)` — maps a raw `OrganizationNode` to a normalized `Customer`, applying safe fallbacks for nullable fields
- `customersQueryKeys` — React Query key factory (`all`, `list(search, status)`) for cache management and invalidation
- `useCustomers(search, status)` — primary hook; returns a flat customer list, pagination controls, loading states, error message, and `filteredCount`

## Usage Example

```typescript
import { useCustomers } from './use-customers';

function CustomerList() {
  const {
    customers,
    isLoading,
    isFetchingNextPage,
    hasNextPage,
    fetchNextPage,
    filteredCount,
  } = useCustomers('acme', 'active');

  if (isLoading) return <Spinner />;

  return (
    <>
      <p>{filteredCount} customers found</p>
      {customers.map(c => (
        <div key={c.id}>{c.name}</div>
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()} disabled={isFetchingNextPage}>
          Load more
        </button>
      )}
    </>
  );
}
```

**Notes**
- Page size is fixed at `20` records (`ORGANIZATIONS_PAGE_SIZE`)
- Cached data is considered fresh for `30s` (`staleTime: 30_000`)
- GraphQL errors and HTTP failures both surface as destructive toasts automatically
- Pass `search` and/or `status` to filter results; changing either resets pagination via the query key
