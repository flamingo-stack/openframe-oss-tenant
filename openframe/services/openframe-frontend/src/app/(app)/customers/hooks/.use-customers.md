React Query infinite scroll hook for fetching and managing paginated customer/organization data via GraphQL, with built-in error toasting and data normalization.

## Key Components

**Interfaces**
- `Customer` — normalized customer shape consumed by UI components
- `OrganizationNode` — raw GraphQL organization node shape
- `CustomersPage` — single page result containing customers, pagination info, and total count

**Exports**
- `mapOrganizationNode(node)` — transforms a raw `OrganizationNode` into a `Customer`, applying safe fallbacks for nullable fields
- `customersQueryKeys` — structured React Query cache key factory (`all`, `list`)
- `useCustomers(search, status)` — primary hook; returns flattened customer list, pagination controls, loading states, and error info

## Usage Example

```typescript
import { useCustomers } from './use-customers';

function CustomerList() {
  const {
    customers,
    isLoading,
    isFetchingNextPage,
    hasNextPage,
    fetchNextPage,
    filteredCount,
    refetch,
  } = useCustomers('acme', 'active');

  if (isLoading) return <Spinner />;

  return (
    <>
      <p>{filteredCount} customers found</p>
      {customers.map(c => (
        <CustomerRow key={c.id} customer={c} />
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()} disabled={isFetchingNextPage}>
          Load more
        </button>
      )}
    </>
  );
}
```

## Notes

- Page size is fixed at **20** via `ORGANIZATIONS_PAGE_SIZE`
- Cursor-based pagination uses `endCursor` from GraphQL `pageInfo`
- Cache entries stay fresh for **30 seconds** (`staleTime: 30_000`)
- Errors surface automatically via a destructive toast notification
- All pages are flattened into a single `customers` array via `useMemo`
