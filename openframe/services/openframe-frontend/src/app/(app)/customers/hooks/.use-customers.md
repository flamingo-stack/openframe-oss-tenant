Infinite-scroll React Query hook for fetching paginated customer/organization data via GraphQL, with error toasting and flattened page accumulation.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Customer` | Interface | Normalized customer shape used throughout the UI |
| `OrganizationNode` | Interface | Raw GraphQL organization node shape |
| `mapOrganizationNode` | Function | Transforms a raw `OrganizationNode` into a `Customer` |
| `customersQueryKeys` | Object | Typed React Query cache key factory for organization queries |
| `useCustomers` | Hook | Infinite-paginated query hook returning flattened customers + pagination controls |

## Usage Example

```typescript
import { useCustomers } from './use-customers';

function CustomerList() {
  const {
    customers,
    isLoading,
    isFetchingNextPage,
    hasNextPage,
    fetchNextPage,
    filteredCount,
  } = useCustomers('acme', 'active');

  if (isLoading) return <Spinner />;

  return (
    <>
      <p>{filteredCount} customers found</p>
      {customers.map(c => (
        <div key={c.id}>{c.name}</div>
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()} disabled={isFetchingNextPage}>
          Load more
        </button>
      )}
    </>
  );
}
```

## Behavior Notes

- **Page size** is fixed at `20` records per request via `ORGANIZATIONS_PAGE_SIZE`
- **Cursor-based pagination** — uses GraphQL `endCursor` / `hasNextPage` from `pageInfo`
- **Cache TTL** is `30s` (`staleTime: 30_000`); stale data is re-fetched automatically
- **Error handling** surfaces GraphQL-level and HTTP-level errors as a destructive toast notification
- All pages are **flattened** via `flatMap` so consumers receive a single `customers[]` array
