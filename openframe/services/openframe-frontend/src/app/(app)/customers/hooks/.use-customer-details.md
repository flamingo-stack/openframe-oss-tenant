Provides a React Query hook for fetching and normalizing detailed customer/organization data from a GraphQL API endpoint.

## Key Components

- **`CustomerDetails`** — Interface defining the full shape of a customer record, including contacts (primary, billing, technical), contract info, MRR, and addresses
- **`customerDetailsQueryKeys`** — Query key factory for scoping and invalidating TanStack Query cache entries
- **`formatAddress(addr)`** — Utility that joins address fields (`street1`, `city`, `state`, etc.) into a single display string
- **`mapOrganization(org)`** — Maps raw GraphQL organization response to the normalized `CustomerDetails` shape
- **`fetchCustomer(id)`** — Async function that POSTs to `/api/graphql` using `GET_ORGANIZATION_BY_ORGANIZATION_ID_QUERY`
- **`useCustomerDetails(id?)`** — Primary exported hook; returns `organization`, `isLoading`, `error`, and `refetch`

## Usage Example

```typescript
import { useCustomerDetails } from './use-customer-details';

function CustomerProfile({ organizationId }: { organizationId: string }) {
  const { organization, isLoading, error, refetch } = useCustomerDetails(organizationId);

  if (isLoading) return <p>Loading...</p>;
  if (error) return <p>Error: {error}</p>;

  return (
    <div>
      <h1>{organization?.name}</h1>
      <p>Industry: {organization?.industry}</p>
      <p>MRR: {organization?.mrrUsd ?? 'N/A'}</p>
      <p>Primary Contact: {organization?.primary.name}</p>
      <p>Address: {organization?.physicalAddress}</p>
    </div>
  );
}
```

> **Note:** The hook is disabled when `id` is `null` or `undefined`. Contacts are mapped positionally from the API response — index `0` → primary, `1` → billing, `2` → technical.
