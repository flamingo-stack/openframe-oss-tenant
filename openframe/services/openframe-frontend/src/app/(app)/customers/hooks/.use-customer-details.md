Provides a React Query hook for fetching and normalizing customer organization details from the GraphQL API, mapping raw API responses into a structured `CustomerDetails` shape.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `CustomerDetails` | Interface | Normalized customer data shape including contacts, addresses, contract info, and billing |
| `customerDetailsQueryKeys` | Object | React Query key factory for cache management (`all`, `detail(id)`) |
| `useCustomerDetails` | Hook | Primary hook — fetches a single customer by ID, returns `organization`, `isLoading`, `error`, `refetch` |
| `formatAddress` | Internal | Joins address fields (`street1`, `city`, `state`, etc.) into a single comma-separated string |
| `mapOrganization` | Internal | Transforms raw GraphQL organization response into a `CustomerDetails` object |

## Usage Example

```typescript
import { useCustomerDetails } from '@/features/customers/hooks/use-customer-details';

function CustomerProfile({ organizationId }: { organizationId: string }) {
  const { organization, isLoading, error, refetch } = useCustomerDetails(organizationId);

  if (isLoading) return <Spinner />;
  if (error) return <ErrorBanner message={error} />;

  return (
    <div>
      <h1>{organization?.name}</h1>
      <p>MRR: ${organization?.mrrUsd ?? 0}</p>
      <p>Primary Contact: {organization?.primary.name}</p>
      <p>Physical Address: {organization?.physicalAddress}</p>
    </div>
  );
}
```

## Notes

- The hook is **disabled** when `id` is falsy — safe to call with `null` or `undefined` during loading states.
- Contact roles (`primary`, `billing`, `technical`) are mapped positionally from the `contacts` array (index 0, 1, 2).
- Defaults `status` to `"ACTIVE"` and `isDefault` to `false` if not present in the API response.
