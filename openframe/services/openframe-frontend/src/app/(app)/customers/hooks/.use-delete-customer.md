React hook that provides a memoized function for deleting a customer organization via the REST API.

## Key Components

- **`useDeleteCustomer`** — Custom hook that returns a `deleteOrganization` callback, wrapped in `useCallback` for stable reference across renders.
- **`deleteOrganization(id: string)`** — Sends a `DELETE` request to `/api/organizations/:id`. Throws an `Error` if the response is not OK, using the API error message or HTTP status as the reason.

## Usage Example

```typescript
import { useDeleteCustomer } from '@/hooks/use-delete-customer';

function CustomerRow({ customer }) {
  const { deleteOrganization } = useDeleteCustomer();

  const handleDelete = async () => {
    try {
      await deleteOrganization(customer.id);
      console.log('Customer deleted successfully');
    } catch (error) {
      console.error('Failed to delete customer:', error.message);
    }
  };

  return <button onClick={handleDelete}>Delete</button>;
}
```

## Notes

- Marked `'use client'` — intended for use in Next.js Client Components only.
- The callback has no dependencies (`[]`), so it remains stable for the lifetime of the component.
- Error handling propagates to the caller; consumers should wrap calls in `try/catch` or handle via a state manager.
