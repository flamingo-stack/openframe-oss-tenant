A React hook that provides a memoized function for deleting a customer organization via the API.

## Key Components

- **`useDeleteCustomer`** — Custom hook returning a `deleteOrganization` function, wrapped in `useCallback` for referential stability.
- **`deleteOrganization(id: string)`** — Sends a `DELETE` request to `/api/organizations/:id`. Throws an error if the response is not successful; otherwise returns the response data.

## Usage Example

```typescript
import { useDeleteCustomer } from '@/hooks/use-delete-customer';

function CustomerActions({ customerId }: { customerId: string }) {
  const { deleteOrganization } = useDeleteCustomer();

  const handleDelete = async () => {
    try {
      await deleteOrganization(customerId);
      console.log('Customer deleted successfully');
    } catch (error) {
      console.error('Failed to delete customer:', error);
    }
  };

  return <button onClick={handleDelete}>Delete Customer</button>;
}
```
