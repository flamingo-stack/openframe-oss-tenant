A React hook for creating new customer organizations via the API, providing a memoized callback that posts customer data and handles error responses.

## Key Components

### Interfaces

| Interface | Description |
|-----------|-------------|
| `ContactPersonDto` | Contact person details: name, title, phone, email |
| `AddressDto` | Physical/mailing address fields |
| `ContactInformationDto` | Aggregates contacts, addresses, and mailing flag |
| `CreateCustomerRequest` | Full customer creation payload including company info, contract dates, and revenue |

### Hook

**`useCreateCustomer()`** — Returns `{ createOrganization }`, a memoized async function that `POST`s to `/api/organizations`.

## Usage Example

```typescript
import { useCreateCustomer } from '@/hooks/use-create-customer';

function NewCustomerForm() {
  const { createOrganization } = useCreateCustomer();

  const handleSubmit = async () => {
    try {
      const customer = await createOrganization({
        name: 'Acme Corp',
        numberOfEmployees: 150,
        websiteUrl: 'https://acme.com',
        contactInformation: {
          contacts: [{ contactName: 'Jane Doe', title: 'CTO', phone: '555-1234', email: 'jane@acme.com' }],
          physicalAddress: { street1: '123 Main St', city: 'Austin', state: 'TX' },
          mailingAddress: { street1: '123 Main St', city: 'Austin', state: 'TX' },
          mailingAddressSameAsPhysical: true,
        },
      });
      console.log('Created:', customer);
    } catch (err) {
      console.error('Failed to create customer:', err);
    }
  };
}
```

## Error Handling

Throws a descriptive `Error` when the API response is not `ok`, using the response's error message or falling back to the HTTP status code.
