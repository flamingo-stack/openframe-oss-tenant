Custom React hook for creating new customer organizations via the API.

## Key Components

**Interfaces**
- `ContactPersonDto` — Contact person details (name, title, phone, email)
- `AddressDto` — Physical/mailing address fields
- `ContactInformationDto` — Aggregates contacts and addresses, with a same-address flag
- `CreateCustomerRequest` — Full payload for creating a customer, including business details and contact info

**Hook**
- `useCreateCustomer()` — Returns `createOrganization`, a memoized async function that POSTs to `/api/organizations`

## Usage Example

```typescript
import { useCreateCustomer } from '@/hooks/use-create-customer';

function NewCustomerForm() {
  const { createOrganization } = useCreateCustomer();

  const handleSubmit = async () => {
    const customer = await createOrganization({
      name: 'Acme Corp',
      category: 'SMB',
      numberOfEmployees: 50,
      websiteUrl: 'https://acme.com',
      contactInformation: {
        contacts: [{ contactName: 'Jane Doe', title: 'CEO', phone: '555-1234', email: 'jane@acme.com' }],
        physicalAddress: { street1: '123 Main St', city: 'Austin', state: 'TX', postalCode: '78701', country: 'US' },
        mailingAddress: { street1: '123 Main St' },
        mailingAddressSameAsPhysical: true,
      },
    });
  };
}
```

> Throws an `Error` with the API's error message or HTTP status if the request fails.
