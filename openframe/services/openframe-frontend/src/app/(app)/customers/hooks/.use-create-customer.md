React hook for creating new customer organizations via the API.

## Key Components

**Interfaces**
- `ContactPersonDto` — Contact person details (name, title, phone, email)
- `AddressDto` — Physical/mailing address fields (street, city, state, postal code, country)
- `ContactInformationDto` — Aggregates contacts list, physical/mailing addresses, and same-address flag
- `CreateCustomerRequest` — Full payload for creating a customer, including org metadata, contract dates, and contact information

**Hook**
- `useCreateCustomer()` — Returns `{ createOrganization }`, a memoized async function that `POST`s to `/api/organizations` and throws on failure

## Usage Example

```typescript
import { useCreateCustomer, CreateCustomerRequest } from './use-create-customer';

function NewCustomerForm() {
  const { createOrganization } = useCreateCustomer();

  const handleSubmit = async () => {
    const payload: CreateCustomerRequest = {
      name: 'Acme Corp',
      numberOfEmployees: 50,
      websiteUrl: 'https://acme.com',
      monthlyRevenue: 5000,
      contractStartDate: '2024-01-01',
      contactInformation: {
        contacts: [{ contactName: 'Jane Doe', title: 'CTO', phone: '555-1234', email: 'jane@acme.com' }],
        physicalAddress: { street1: '123 Main St', city: 'Austin', state: 'TX', postalCode: '78701', country: 'US' },
        mailingAddress: { street1: '123 Main St' },
        mailingAddressSameAsPhysical: true,
      },
    };

    try {
      const result = await createOrganization(payload);
      console.log('Created:', result);
    } catch (err) {
      console.error('Failed to create customer:', err);
    }
  };
}
```

`createOrganization` is wrapped in `useCallback` with no dependencies, ensuring a stable reference across renders.
