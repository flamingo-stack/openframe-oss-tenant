Client-side route wrapper that resolves the `[id]` URL parameter and delegates to `NewCustomerPage`, treating the literal value `"new"` as a creation flow and any valid string ID as an edit flow.

## Key Components

- **`EditOrganizationPageWrapper`** — Default export; reads the `id` param from the URL, normalizes it to `null` (for new records) or a string ID (for edits), and renders `NewCustomerPage` accordingly.

## Usage Example

```typescript
// Route: /customers/new       → organizationId = null  (create)
// Route: /customers/abc-123   → organizationId = "abc-123" (edit)

<EditOrganizationPageWrapper />
```

The `NewCustomerPage` component receives `organizationId` as either a string or `null` to distinguish between create and edit modes.
