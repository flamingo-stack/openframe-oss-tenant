Client-side route wrapper that resolves the dynamic `[id]` URL parameter and renders the `NewCustomerPage` component in either create or edit mode.

## Key Components

- **`EditOrganizationPageWrapper`** — Default export. Reads the `id` param from the URL; maps the string `"new"` to `null` (create mode) or passes a valid string ID (edit mode) to `NewCustomerPage`.

## Usage Example

```typescript
// Accessed via routes:
// /customers/new          → organizationId = null  (create mode)
// /customers/abc-123      → organizationId = "abc-123" (edit mode)

<EditOrganizationPageWrapper />
// Internally renders:
<NewCustomerPage organizationId={null | "abc-123"} />
```

## Routing Logic

| URL Param | Resolved `organizationId` |
|-----------|--------------------------|
| `"new"` | `null` |
| `"abc-123"` | `"abc-123"` |
| `undefined` | `null` |
