Client-side page wrapper that handles routing logic for both creating new customers and editing existing ones, resolving the organization ID from URL parameters.

## Key Components

- **`EditOrganizationPageWrapper`** — Default export. Reads the `id` route param and passes `null` when the route is `/customers/new`, or the actual ID string for edit routes, delegating rendering to `NewCustomerPage`.

## Usage Example

```typescript
// Route: /customers/new → organizationId = null (create mode)
// Route: /customers/abc123 → organizationId = "abc123" (edit mode)

// Rendered automatically by Next.js via file-based routing:
// app/(app)/customers/[id]/page.tsx
<EditOrganizationPageWrapper />
```

## Routing Logic

```text
URL param "id"
  ├── "new"          → organizationId = null  (create flow)
  ├── "<string>"     → organizationId = id    (edit flow)
  └── undefined      → organizationId = null  (fallback)
```
