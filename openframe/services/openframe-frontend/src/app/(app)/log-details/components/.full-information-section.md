Renders a detailed information card for a log entry, displaying all available log fields (event ID, type, severity, tool type, timestamp, etc.) in a structured row layout with ODS styling.

## Key Components

- **`FullInformationSection`** — Main exported component that accepts an optional `logDetails` prop and renders a full-detail view or an empty state
- **`LogEntry`** — Interface defining the shape of a log entry (event ID, type, severity, tool type, timestamps, optional user/device IDs, etc.)
- **`FullInformationSectionProps`** — Props interface accepting a nullable `logDetails: LogEntry`
- **`formatTimestamp`** — Internal helper that normalizes a timestamp string to ISO 8601 format with graceful fallback

## Usage Example

```typescript
import { FullInformationSection } from './full-information-section';

const logEntry = {
  toolEventId: 'evt_abc123',
  eventType: 'alert',
  ingestDay: '2024-01-15',
  toolType: 'connectwise',
  severity: 'high',
  userId: 'usr_xyz',
  deviceId: 'dev_001',
  timestamp: '2024-01-15T10:30:00Z',
};

<FullInformationSection logDetails={logEntry} />

// Empty state
<FullInformationSection logDetails={null} />
```

## Notes

- `toolType` is rendered using `ToolBadge` with `normalizeToolTypeWithFallback` to handle unknown or non-standard tool type strings
- `userId` and `deviceId` rows are conditionally rendered only when present
- Displays a styled empty state card when `logDetails` is `null` or `undefined`
