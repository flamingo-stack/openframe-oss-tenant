Renders a detailed "Full Information" card for a single log entry, displaying all available log fields in a structured, divided layout with graceful empty-state handling.

## Key Components

- **`FullInformationSection`** — Main export; accepts an optional `LogEntry` and renders a labeled info card or an empty-state placeholder
- **`LogEntry`** — Interface defining the shape of a log entry (event ID, type, severity, timestamps, optional user/device IDs, etc.)
- **`formatTimestamp`** — Internal helper that normalizes a timestamp string to ISO 8601 format
- **`ToolBadge`** — Renders a visual badge for the normalized tool type
- **`InfoRow`** — Reusable labeled field row from the OpenFrame core library

## Usage Example

```typescript
import { FullInformationSection } from './full-information-section';

const logEntry = {
  toolEventId: 'evt_abc123',
  eventType: 'ALERT',
  ingestDay: '2025-01-15',
  toolType: 'zabbix',
  severity: 'HIGH',
  userId: 'usr_42',
  deviceId: 'dev_99',
  timestamp: '2025-01-15T10:30:00Z',
};

// With data
<FullInformationSection logDetails={logEntry} />

// Empty state — renders "No log details available"
<FullInformationSection logDetails={null} />
```

> **Note:** `userId` and `deviceId` rows are conditionally rendered — they only appear when present on the log entry. `toolType` uses `normalizeToolTypeWithFallback` before being passed to `ToolBadge` to handle unknown or legacy tool identifiers.
