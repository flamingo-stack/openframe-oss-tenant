Renders a detailed information card for a single log entry, displaying all available log fields in a structured, divided layout with graceful empty state handling.

## Key Components

- **`FullInformationSection`** — Main export; accepts an optional `logDetails` prop and renders a bordered card with labeled rows for each log field
- **`LogEntry`** — Interface defining the shape of a log record (`toolEventId`, `eventType`, `ingestDay`, `toolType`, `severity`, `userId`, `deviceId`, `message`, `timestamp`, `details`)
- **`formatTimestamp`** — Internal utility that normalizes a timestamp string to ISO 8601 format with a fallback to the raw value
- **`ToolBadge`** — Renders a visual badge for the tool type, normalized via `normalizeToolTypeWithFallback`
- **`InfoRow`** — Shared component used to render label/value pairs consistently across all fields

Optional fields (`userId`, `deviceId`) are conditionally rendered only when present on the log entry.

## Usage Example

```typescript
import { FullInformationSection } from './full-information-section';

const logEntry = {
  toolEventId: 'evt_abc123',
  eventType: 'ALERT',
  ingestDay: '2024-01-15',
  toolType: 'zabbix',
  severity: 'high',
  userId: 'usr_456',
  timestamp: '2024-01-15T10:30:00Z',
};

// With data
<FullInformationSection logDetails={logEntry} />

// Empty state — renders "No log details available"
<FullInformationSection logDetails={null} />
```
