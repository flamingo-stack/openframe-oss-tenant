Renders the full detail view for a single log entry, handling loading, error, and success states while providing copy-to-clipboard and navigation functionality.

## Key Components

- **`LogDetailsView`** — Main exported component that fetches and displays log details by ID
- **`getSeverityVariant`** — Helper that maps severity strings (`ERROR`, `WARNING`, `INFO`, `CRITICAL`, `DEBUG`) to Tag variant tokens
- **`LogDetailsViewProps`** — Interface requiring `logId`, `ingestDay`, `toolType`, `eventType`, and `timestamp`

## Usage Example

```typescript
import { LogDetailsView } from './log-details-view';

<LogDetailsView
  logId="evt_abc123"
  ingestDay="2024-01-15"
  toolType="connectwise"
  eventType="device.status.changed"
  timestamp="2024-01-15T14:32:00Z"
/>
```

## Behavior Notes

- **Auto-redirect** — If any required prop is missing, redirects to `/logs-page` via `router.replace`
- **Loading state** — Renders `LogDetailsSkeleton` while fetching
- **Error state** — Displays a "Log Not Found" message with a back button
- **Copy action** — Serializes key log fields into a plain-text string and copies to clipboard; icon swaps to a checkmark on success
- **Back navigation** — Uses `useSafeBack` to return to `/logs-page` with history fallback

## Rendered Sections (success state)

| Section | Component |
|---|---|
| Severity badge + timestamp | `Tag`, `formatDateTime` |
| Message + tool/event summary | `ToolBadge` |
| Device/user info | `DeviceInfoSection` |
| Structured log fields | `FullInformationSection` |
| Raw details payload | `DetailsSection` |
