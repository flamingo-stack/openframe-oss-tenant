Renders the full detail view for a single log entry, handling data fetching, loading/error states, and clipboard copy functionality.

## Key Components

- **`LogDetailsViewProps`** — Interface requiring `logId`, `ingestDay`, `toolType`, `eventType`, and `timestamp` to identify and fetch the log
- **`getSeverityVariant`** — Maps severity strings (`ERROR`, `WARNING`, `INFO`, `CRITICAL`, `DEBUG`) to UI tag color variants
- **`LogDetailsView`** — Main exported component orchestrating log fetching, display, and user interactions

### Internal Sections Rendered

| Section | Condition |
|---|---|
| `LogDetailsSkeleton` | While loading |
| Error/Not Found state | On fetch error or missing data |
| `Tag` + timestamp | Always (severity badge + formatted time) |
| Log Summary Card | Always (message, tool badge, event type) |
| `DeviceInfoSection` | Only when `deviceId` is present |
| `FullInformationSection` | Always |
| `DetailsSection` | Always |

## Usage Example

```typescript
// Typically rendered from a dynamic route page
<LogDetailsView
  logId="evt_abc123"
  ingestDay="2024-01-15"
  toolType="rmm"
  eventType="agent.status"
  timestamp="2024-01-15T10:30:00Z"
/>
```

### Behavior Notes

- Redirects to `/logs-page` if any required prop is missing
- **Copy to clipboard** formats key log fields into a plain-text summary with visual feedback (checkmark icon on success)
- Uses `useSafeBack` to navigate back, falling back to `/logs-page` if no history entry exists
