Renders the full detail view for a single log entry, handling data fetching, loading/error states, and user actions like copying log details to clipboard.

## Key Components

- **`LogDetailsView`** — Main export; a client component that fetches and displays a log's complete details using URL-derived props
- **`getSeverityVariant`** — Helper that maps severity strings (`ERROR`, `WARNING`, `INFO`, `CRITICAL`, `DEBUG`) to UI `Tag` variant tokens
- **`LogDetailsViewProps`** — Interface requiring `logId`, `ingestDay`, `toolType`, `eventType`, and `timestamp` to identify and fetch a log record

### Rendered Sub-sections

| Component | Purpose |
|---|---|
| `LogDetailsSkeleton` | Loading placeholder while fetching |
| `DeviceInfoSection` | Device/user info (rendered only if `deviceId` exists) |
| `FullInformationSection` | Expanded log payload display |
| `DetailsSection` | Structured key/value detail fields |

## Usage Example

```typescript
// Typically rendered by a Next.js page passing URL params
<LogDetailsView
  logId="evt_abc123"
  ingestDay="2025-01-15"
  toolType="rmm"
  eventType="agent.connected"
  timestamp="2025-01-15T10:30:00Z"
/>
```

## Behaviors

- **Auto-redirect**: If any required prop is missing, navigates to `/logs-page`
- **Copy to clipboard**: Serializes key log fields into a plain-text string and copies via `useCopyToClipboard`; button icon toggles to a checkmark on success
- **Safe back navigation**: Uses `useSafeBack` to return to `/logs-page` with browser history awareness
