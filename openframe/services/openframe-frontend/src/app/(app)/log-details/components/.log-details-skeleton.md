Loading state skeleton component for the Log Details page, rendering placeholder UI while log data is being fetched.

## Key Components

| Component | Description |
|-----------|-------------|
| `LogDetailsSkeleton` | Main exported component; wraps all skeleton sections in a `DetailPageContainer` |
| `StatusTimestampSkeleton` | Placeholder for the status badge and timestamp row |
| `LogSummaryCardSkeleton` | Placeholder for the log summary card with title and metadata |
| `DeviceInfoSkeleton` | Placeholder for the device info section using `DeviceInfoSectionSkeleton` |
| `FullInformationSkeleton` | Placeholder for the structured key/value info table (7 rows) |
| `DetailsSkeleton` | Placeholder for the raw log details block (17 lines of varying widths) |

## Usage Example

```typescript
import { LogDetailsSkeleton } from '@/app/components/log-details/log-details-skeleton';

function LogDetailsPage() {
  const router = useRouter();

  if (isLoading) {
    return <LogDetailsSkeleton onBack={() => router.back()} />;
  }

  return <LogDetails data={logData} onBack={() => router.back()} />;
}
```

## Props

| Prop | Type | Description |
|------|------|-------------|
| `onBack` | `() => void` | Callback passed to the `DetailPageContainer` back button |

## Notes

- Uses `'use client'` directive — renders on the client side only.
- Skeleton widths are defined as static constant arrays (`FULL_INFO_ROWS`, `DETAILS_LINE_WIDTHS`) to produce realistic, content-shaped placeholders.
- All styling uses ODS design tokens (`ods-card`, `ods-border`, `ods-text-secondary`) for dark-mode compatibility.
