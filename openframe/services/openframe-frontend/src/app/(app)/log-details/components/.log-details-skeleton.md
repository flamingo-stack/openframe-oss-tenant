Loading state skeleton component for the Log Details page, composing multiple sub-skeletons to match the full page layout during data fetching.

## Key Components

| Component | Description |
|---|---|
| `LogDetailsSkeleton` | Main exported component; wraps all sub-skeletons inside `DetailPageContainer` |
| `StatusTimestampSkeleton` | Placeholder for the status badge and timestamp row |
| `LogSummaryCardSkeleton` | Placeholder for the log summary card (title, type badge, metadata) |
| `DeviceInfoSkeleton` | Wraps `DeviceInfoSectionSkeleton` with a "Device Info" section label |
| `FullInformationSkeleton` | Renders a table-style list of label/value row skeletons using `FULL_INFO_ROWS` |
| `DetailsSkeleton` | Renders a code-block-style skeleton using `DETAILS_LINE_WIDTHS` with indentation |

## Usage Example

```typescript
import { LogDetailsSkeleton } from '@/app/components/log-details/log-details-skeleton';

function LogDetailsPage() {
  const { data, isLoading } = useLogDetails(logId);
  const router = useRouter();

  if (isLoading) {
    return <LogDetailsSkeleton onBack={() => router.back()} />;
  }

  return <LogDetails data={data} onBack={() => router.back()} />;
}
```

## Notes

- `FULL_INFO_ROWS` defines 7 label/value pairs with explicit Tailwind width classes to approximate real content proportions.
- `DETAILS_LINE_WIDTHS` defines 17 lines with varying widths and a 16px left margin on inner lines, mimicking indented log/code output.
- All sub-skeletons are internal to the file and not exported individually.
