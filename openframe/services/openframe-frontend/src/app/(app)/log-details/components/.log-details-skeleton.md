Loading state skeleton component for the log details page, rendering placeholder UI elements while log data is being fetched.

## Key Components

- **`LogDetailsSkeleton`** *(exported)* — Main skeleton wrapper using `DetailPageContainer` with a back button and header action placeholder
- **`StatusTimestampSkeleton`** — Placeholder for status badge and timestamp row
- **`LogSummaryCardSkeleton`** — Card placeholder with title and metadata (type badge + source)
- **`DeviceInfoSkeleton`** — Wraps `DeviceInfoSectionSkeleton` with a "Device Info" section label
- **`FullInformationSkeleton`** — Key-value row list skeleton driven by `FULL_INFO_ROWS` config (7 rows with varied widths)
- **`DetailsSkeleton`** — Multi-line code/text block skeleton using `DETAILS_LINE_WIDTHS` array (17 lines with indentation simulation)

## Usage Example

```typescript
import { LogDetailsSkeleton } from './log-details-skeleton';

function LogDetailsPage() {
  const router = useRouter();

  if (isLoading) {
    return <LogDetailsSkeleton onBack={() => router.back()} />;
  }

  return <LogDetailsContent data={logData} />;
}
```

## Props

| Prop | Type | Description |
|------|------|-------------|
| `onBack` | `() => void` | Callback fired when the back button is clicked |
