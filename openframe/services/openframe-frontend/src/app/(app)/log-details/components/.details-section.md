Renders a formatted JSON details panel for a log entry, parsing the `details` field if available or falling back to structured log metadata.

## Key Components

**`DetailsSection`** — React client component that accepts a `LogEntry` and displays its details as pretty-printed JSON inside a styled card.

**Parse Logic:**
- If `logDetails.details` is valid JSON → parses and displays it directly
- If `logDetails.details` is missing → builds a structured object from core `LogEntry` fields
- If `logDetails.details` is invalid JSON → builds the same structured object and appends `rawDetails` with the original string

## Usage Example

```typescript
import { DetailsSection } from './details-section';
import type { LogEntry } from '../../logs-page/types/log.types';

const log: LogEntry = {
  toolEventId: 'evt-123',
  eventType: 'alert',
  toolType: 'endpoint',
  severity: 'high',
  userId: 'user-456',
  deviceId: 'dev-789',
  timestamp: '2024-01-01T00:00:00Z',
  ingestDay: '2024-01-01',
  message: 'Disk usage critical',
  details: '{"threshold": 90, "current": 95}',
};

<DetailsSection logDetails={log} />
```

**Rendered output** — a labeled card titled "Details" containing:

```json
{
  "threshold": 90,
  "current": 95
}
```

The pre-formatted block uses `whitespace-pre-wrap` and `break-words` to remain readable across screen sizes, with responsive padding and font sizing via ODS design tokens.
