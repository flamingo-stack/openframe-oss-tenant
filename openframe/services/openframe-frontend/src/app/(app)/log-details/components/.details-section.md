Renders a styled JSON details panel for a log entry, parsing the `details` field if available or falling back to structured log metadata.

## Key Components

**`DetailsSection`** — Client component that accepts a `LogEntry` and displays its data as formatted JSON inside a card.

**Parse logic:**
- If `logDetails.details` is valid JSON → parse and display it
- If missing → build a structured object from core `LogEntry` fields
- If invalid JSON → fall back to structured object with `rawDetails` appended

## Usage Example

```typescript
import { DetailsSection } from './details-section';
import type { LogEntry } from '../../logs-page/types/log.types';

const entry: LogEntry = {
  toolEventId: 'evt-123',
  eventType: 'alert',
  toolType: 'zabbix',
  severity: 'high',
  userId: 'u-456',
  deviceId: 'd-789',
  timestamp: '2024-01-15T10:30:00Z',
  ingestDay: '2024-01-15',
  message: 'Disk usage exceeded 90%',
  details: '{"threshold": 90, "current": 93}',
};

<DetailsSection logDetails={entry} />
```

## Behavior Notes

- Wraps output in a `<pre>` tag with `whitespace-pre-wrap` and `break-words` for responsive display
- Horizontally scrollable on overflow via `overflow-x-auto`
- Styled with ODS design tokens (`ods-card`, `ods-border`, `ods-text-primary`, etc.)
- `DM Sans` monospace-style font at `14px` mobile / `16px` desktop
