Renders a formatted JSON view of a log entry's details, parsing the `details` field or falling back to structured log metadata when unavailable or invalid.

## Key Components

**`DetailsSection`** — React client component that accepts a `LogEntry` and displays its data as pretty-printed JSON inside a styled card.

**Props**

| Prop | Type | Description |
|------|------|-------------|
| `logDetails` | `LogEntry` | The log entry whose details are rendered |

**Parsing Logic**

- If `logDetails.details` exists and is valid JSON → parse and display it
- If `logDetails.details` is missing → build a structured object from core fields (`toolEventId`, `eventType`, `toolType`, `severity`, `userId`, `deviceId`, `timestamp`, `ingestDay`, `message`)
- If `logDetails.details` is invalid JSON → use the same structured object plus a `rawDetails` field containing the original string

## Usage Example

```typescript
import { DetailsSection } from './details-section';
import type { LogEntry } from '../../logs-page/types/log.types';

const entry: LogEntry = {
  toolEventId: 'evt-001',
  eventType: 'alert',
  toolType: 'monitoring',
  severity: 'high',
  userId: 'user-123',
  deviceId: 'device-456',
  timestamp: '2024-01-15T10:30:00Z',
  ingestDay: '2024-01-15',
  message: 'CPU threshold exceeded',
  details: '{"cpu": 95, "threshold": 80}',
};

<DetailsSection logDetails={entry} />
```
