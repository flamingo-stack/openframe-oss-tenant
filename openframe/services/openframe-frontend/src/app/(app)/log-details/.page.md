Async Next.js page component that validates required query parameters for viewing log details, redirecting to `/logs-page` if any are missing.

## Key Components

- **`LogDetailsPage`** — Async server component that resolves `searchParams` and guards against incomplete log detail queries
- **`LogDetailsView`** — Client component rendered with validated params (imported from `./components/log-details-view`)
- **`dynamic = 'force-dynamic'`** — Disables static rendering due to `useSearchParams` usage in the app layout

## Required Search Parameters

| Parameter | Description |
|-----------|-------------|
| `id` | Unique log entry identifier |
| `ingestDay` | Day the log was ingested |
| `toolType` | Source tool type |
| `eventType` | Category of the log event |
| `timestamp` | Log event timestamp |

## Usage Example

```typescript
// Navigate to this page with all required params:
const params = new URLSearchParams({
  id: 'log-abc123',
  ingestDay: '2024-01-15',
  toolType: 'connectwise',
  eventType: 'ticket.created',
  timestamp: '2024-01-15T10:30:00Z',
});

router.push(`/logs-page/details?${params.toString()}`);

// Missing any param → redirects to /logs-page
router.push('/logs-page/details?id=log-abc123'); // ← redirects
```
