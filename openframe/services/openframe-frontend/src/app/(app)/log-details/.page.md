Async Next.js page component that handles routing and parameter validation for the log details view, redirecting to `/logs-page` if any required query parameters are missing.

## Key Components

- **`LogDetailsPage`** — Async server component that resolves `searchParams`, validates required fields, and renders the `LogDetailsView`
- **`dynamic = 'force-dynamic'`** — Disables static rendering due to `useSearchParams` usage in the layout
- **`LogDetailsPageProps`** — Interface defining the expected async `searchParams` shape

## Required Query Parameters

| Parameter | Description |
|-----------|-------------|
| `id` | Log entry identifier |
| `ingestDay` | Day the log was ingested |
| `toolType` | Source tool type |
| `eventType` | Classification of the event |
| `timestamp` | Event timestamp |

## Usage Example

```typescript
// Navigate to this page with all required params:
const url = `/logs-page/details?id=abc123&ingestDay=2024-01-15&toolType=zabbix&eventType=alert&timestamp=1705312800`;

// Missing any param triggers redirect to /logs-page
const incompleteUrl = `/logs-page/details?id=abc123`;
// → redirects to /logs-page
```
