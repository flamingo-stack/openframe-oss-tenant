React hook for fetching and managing individual log entry details via GraphQL, with built-in loading state, error handling, and toast notifications.

## Key Components

- **`useLogDetails()`** — Primary hook export that encapsulates log detail fetching logic
- **`fetchLogDetailsById(logId, ingestDay, toolType, eventType, timestamp)`** — Async callback that queries the GraphQL endpoint for a specific log entry using composite key parameters
- **`clearLogDetails()`** — Resets `logDetails` and `error` state back to `null`
- **State** — `logDetails: LogEntry | null`, `isLoading: boolean`, `error: string | null`

## Usage Example

```typescript
import { useLogDetails } from './use-log-details';

function LogDetailPanel({ log }: { log: LogSummary }) {
  const { logDetails, isLoading, error, fetchLogDetailsById, clearLogDetails } = useLogDetails();

  useEffect(() => {
    fetchLogDetailsById(
      log.id,
      log.ingestDay,
      log.toolType,
      log.eventType,
      log.timestamp,
    );

    return () => clearLogDetails();
  }, [log.id]);

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;
  if (!logDetails) return null;

  return <LogDetailView entry={logDetails} />;
}
```

> **Note:** On fetch failure, the hook both sets the `error` state and surfaces a destructive toast notification — avoid double-handling errors in consuming components.
