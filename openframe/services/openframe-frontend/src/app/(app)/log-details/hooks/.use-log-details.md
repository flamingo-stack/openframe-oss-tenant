Provides a React hook for fetching and managing individual log entry details via GraphQL, with built-in loading state, error handling, and toast notifications.

## Key Components

- **`useLogDetails()`** — Main hook export that encapsulates log detail fetching logic
- **`fetchLogDetailsById(logId, ingestDay, toolType, eventType, timestamp)`** — Async callback that queries the GraphQL endpoint for a specific log entry using composite key parameters
- **`clearLogDetails()`** — Resets `logDetails` and `error` state back to `null`
- **State**:
  - `logDetails` — The fetched `LogEntry | null`
  - `isLoading` — Boolean fetch-in-progress indicator
  - `error` — Error message string or `null`

## Usage Example

```typescript
import { useLogDetails } from './use-log-details';

function LogDetailPanel({ log }) {
  const { logDetails, isLoading, error, fetchLogDetailsById, clearLogDetails } = useLogDetails();

  useEffect(() => {
    fetchLogDetailsById(
      log.id,
      log.ingestDay,
      log.toolType,
      log.eventType,
      log.timestamp
    );

    return () => clearLogDetails();
  }, [log.id]);

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;

  return <LogDetailView entry={logDetails} />;
}
```

> On GraphQL or HTTP errors, the hook automatically surfaces a destructive toast notification and re-throws the error for upstream handling.
