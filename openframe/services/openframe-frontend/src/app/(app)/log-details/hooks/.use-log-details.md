React hook for fetching and managing individual log entry details via GraphQL, with built-in loading state, error handling, and toast notifications.

## Key Components

- **`useLogDetails`** — Primary hook export that encapsulates log detail fetching state and actions
- **`fetchLogDetailsById`** — Async callback that queries `GET_LOG_DETAILS_QUERY` via `/api/graphql`, accepting `logId`, `ingestDay`, `toolType`, `eventType`, and `timestamp` as identifiers
- **`clearLogDetails`** — Resets `logDetails` and `error` state back to `null`
- **`LogDetailsResponse`** / **`GraphQlResponse<T>`** — Internal interfaces for typing the GraphQL API response shape

## Usage Example

```typescript
import { useLogDetails } from './use-log-details';

function LogDetailPanel({ log }: { log: LogEntry }) {
  const { logDetails, isLoading, error, fetchLogDetailsById, clearLogDetails } = useLogDetails();

  useEffect(() => {
    fetchLogDetailsById(
      log.id,
      log.ingestDay,
      log.toolType,
      log.eventType,
      log.timestamp,
    );

    return () => clearLogDetails();
  }, [log.id]);

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;
  if (!logDetails) return null;

  return <LogDetailView entry={logDetails} />;
}
```

## Return Values

| Property | Type | Description |
|---|---|---|
| `logDetails` | `LogEntry \| null` | Fetched log entry data |
| `isLoading` | `boolean` | Request in-flight indicator |
| `error` | `string \| null` | Last error message, if any |
| `fetchLogDetailsById` | `Function` | Triggers the GraphQL fetch |
| `clearLogDetails` | `Function` | Resets detail and error state |
