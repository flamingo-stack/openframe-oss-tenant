Brief description of the file's purpose: Defines TypeScript interfaces and types for the Dialog GraphQL API layer, covering response shapes, pagination, token usage, and hook configuration for the Mingo AI dialog system.

## Key Components

- **`DialogTokenUsage`** — Tracks AI token consumption metrics (input, output, total, context sizes) per chat interaction
- **`DialogStreamState`** — Union type representing streaming status: `'IDLE'` or `'STREAMING'`
- **`DialogNode`** — Core dialog entity with status, ownership, timestamps, rating, and token usage
- **`DialogEdge`** — Relay-style cursor wrapper around a `DialogNode`
- **`DialogConnection`** — Paginated collection of dialog edges with `pageInfo` for cursor-based pagination
- **`DialogsResponse`** — Top-level GraphQL response for a list query
- **`DialogResponse`** — Top-level GraphQL response for a single dialog query
- **`UseMingoDialogsOptions`** — Configuration options for the `useMingoDialogs` React hook

## Usage Example

```typescript
import type {
  DialogNode,
  DialogsResponse,
  UseMingoDialogsOptions,
} from './dialog.types';

// Consuming a paginated dialogs response
const response: DialogsResponse = await fetchDialogs();
const dialogs: DialogNode[] = response.data.dialogs.edges.map(
  (edge) => edge.node
);

// Checking stream state and token usage
dialogs.forEach((dialog) => {
  if (dialog.streamState === 'STREAMING') {
    console.log(`Dialog ${dialog.id} is actively streaming`);
  }
  dialog.tokenUsage?.forEach((usage) => {
    console.log(`${usage.chatType}: ${usage.totalTokensSize} tokens used`);
  });
});

// Hook options for filtered, paginated fetching
const options: UseMingoDialogsOptions = {
  enabled: true,
  search: 'network issue',
  limit: 20,
};
```
