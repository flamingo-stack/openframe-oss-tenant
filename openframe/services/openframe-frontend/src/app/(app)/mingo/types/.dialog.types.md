Brief description of the file's purpose: Defines TypeScript interfaces and types for dialog-related GraphQL responses and hook configurations used within the Mingo AI dialog system.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `DialogTokenUsage` | `interface` | Token consumption metrics per AI chat interaction |
| `DialogStreamState` | `type` | Union type representing streaming status — `'IDLE'` or `'STREAMING'` |
| `DialogNode` | `interface` | Core dialog entity with metadata, ownership, ratings, and token usage |
| `DialogEdge` | `interface` | Relay-style cursor wrapper around a `DialogNode` |
| `DialogConnection` | `interface` | Paginated collection of dialog edges with `pageInfo` |
| `DialogsResponse` | `interface` | Top-level GraphQL response shape for a list of dialogs |
| `DialogResponse` | `interface` | Top-level GraphQL response shape for a single dialog |
| `UseMingoDialogsOptions` | `interface` | Configuration options for the `useMingoDialogs` hook |

## Usage Example

```typescript
import type {
  DialogNode,
  DialogsResponse,
  UseMingoDialogsOptions,
} from './dialog.types';

// Consuming a paginated GraphQL response
const response: DialogsResponse = await fetchDialogs();
const dialogs: DialogNode[] = response.data.dialogs.edges.map(
  (edge) => edge.node
);

// Checking streaming state
dialogs.forEach((dialog) => {
  if (dialog.streamState === 'STREAMING') {
    console.log(`Dialog ${dialog.id} is currently streaming`);
  }
});

// Hook configuration
const options: UseMingoDialogsOptions = {
  enabled: true,
  search: 'printer issue',
  limit: 20,
};
```

> **Note:** `DialogNode` follows Relay cursor-based pagination conventions via `DialogEdge` and `DialogConnection`, making it compatible with GraphQL pagination utilities like `fetchMore`.
