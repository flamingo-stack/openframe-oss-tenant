Brief description: Defines TypeScript interfaces and types for the Dialog GraphQL response structures and hook options used in the Mingo AI dialog system.

## Key Components

- **`DialogTokenUsage`** — Token consumption metrics for a dialog session (input, output, total, context sizes)
- **`DialogStreamState`** — Union type representing streaming status: `'IDLE'` or `'STREAMING'`
- **`DialogNode`** — Core dialog entity with metadata including ownership, timestamps, ratings, and token usage
- **`DialogEdge`** — Cursor-based pagination wrapper around a `DialogNode`
- **`DialogConnection`** — Paginated collection of dialog edges with `pageInfo` for cursor navigation
- **`DialogsResponse`** — Top-level GraphQL response shape for a list of dialogs
- **`DialogResponse`** — Top-level GraphQL response shape for a single dialog
- **`UseMingoDialogsOptions`** — Configuration options for the `useMingoDialogs` hook

## Usage Example

```typescript
import type {
  DialogNode,
  DialogConnection,
  UseMingoDialogsOptions,
} from './dialog.types';

// Consuming a paginated dialogs response
function processDialogs(connection: DialogConnection): DialogNode[] {
  return connection.edges.map((edge) => edge.node);
}

// Configuring the hook
const options: UseMingoDialogsOptions = {
  enabled: true,
  search: 'printer offline',
  limit: 20,
};

// Checking stream state
function isStreaming(dialog: DialogNode): boolean {
  return dialog.streamState === 'STREAMING';
}
```
