Defines TypeScript interfaces and type guards for the chat message system, covering both GraphQL API responses and normalized core message structures used throughout the OpenFrame chat UI.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `GraphQlMessage` | Interface | Raw message shape returned from the GraphQL API, including dialog metadata, owner info, and untyped `messageData` |
| `CoreMessage` | Interface | Normalized message used in the UI layer with typed `content`, role (`user`/`assistant`/`error`), and optional display metadata |
| `Message` | Type alias | Convenience alias for `CoreMessage` |
| `MessageConnection` | Interface | Paginated GraphQL connection wrapper with `edges` and `pageInfo` |
| `MessagesResponse` | Interface | Top-level GraphQL response envelope for a messages query |
| `MessagePage` | Interface | Flattened page structure used after unwrapping a `MessageConnection` |
| `isGraphQlMessage` | Type guard | Returns `true` if the value has a `messageData` property (GraphQL shape) |
| `isCoreMessage` | Type guard | Returns `true` if the value has a `content` property (core UI shape) |

## Usage Example

```typescript
import {
  isGraphQlMessage,
  isCoreMessage,
  type GraphQlMessage,
  type CoreMessage,
} from './message.types';

function processMessage(message: GraphQlMessage | CoreMessage) {
  if (isGraphQlMessage(message)) {
    // Safe to access message.messageData, message.dialogId, etc.
    console.log('GraphQL message from dialog:', message.dialogId);
  } else if (isCoreMessage(message)) {
    // Safe to access message.content, message.role, etc.
    console.log('Core message role:', message.role);
  }
}
```
