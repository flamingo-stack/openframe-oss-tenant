Defines TypeScript interfaces and type guards for the messaging system, covering both GraphQL wire-format messages and normalized core message structures used throughout the chat UI.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `GraphQlMessage` | Interface | Raw message shape returned from the GraphQL API, including `dialogId`, `chatType`, `owner`, and untyped `messageData` |
| `CoreMessage` | Interface | Normalized message used in UI state; includes `role`, typed `content`, `authorType`, and `assistantType` |
| `Message` | Type alias | Convenience alias for `CoreMessage` |
| `MessageConnection` | Interface | Paginated GraphQL connection wrapper with `edges` and `pageInfo` |
| `MessagesResponse` | Interface | Top-level GraphQL response envelope containing a `MessageConnection` |
| `MessagePage` | Interface | Flattened page result after unwrapping the connection, used for internal pagination state |
| `isGraphQlMessage` | Type guard | Returns `true` if a value contains `messageData`, narrowing to `GraphQlMessage` |
| `isCoreMessage` | Type guard | Returns `true` if a value contains `content`, narrowing to `CoreMessage` |

## Usage Example

```typescript
import {
  isGraphQlMessage,
  isCoreMessage,
  type GraphQlMessage,
  type CoreMessage,
} from './message.types';

function processMessage(message: GraphQlMessage | CoreMessage) {
  if (isGraphQlMessage(message)) {
    // Safe to access message.messageData, message.dialogId, etc.
    console.log('GraphQL message owner:', message.owner.type);
  } else if (isCoreMessage(message)) {
    // Safe to access message.content, message.role, etc.
    console.log('Core message role:', message.role);
  }
}

// Handling a paginated GraphQL response
function extractPage(response: MessagesResponse): MessagePage {
  const { edges, pageInfo } = response.data.messages;
  return {
    messages: edges.map((e) => e.node),
    pageInfo,
  };
}
```
