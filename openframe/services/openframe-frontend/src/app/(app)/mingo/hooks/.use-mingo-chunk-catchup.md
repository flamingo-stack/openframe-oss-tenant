Mingo-specific wrapper around the core `useChunkCatchup` hook, scoped to `ADMIN` chat type and wired to the Flamingo API client for fetching dialog chunks.

## Key Components

- **`useMingoChunkCatchup`** — React hook that configures and delegates to `useChunkCatchupCore` with Mingo-specific defaults
- **`fetchChunks`** — Internal `useCallback` that fetches missed chunks from `/chat/api/v1/dialogs/{dialogId}/chunks` with optional `fromSequenceId` pagination
- **Re-exports** — `ChunkData`, `NatsMessageType`, `UseChunkCatchupReturn` forwarded from core for consumer convenience

## Usage Example

```typescript
import { useMingoChunkCatchup } from './use-mingo-chunk-catchup';

function MingoChat({ dialogId }: { dialogId: string }) {
  const { startCatchup, stopCatchup } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: (chunk, messageType) => {
      console.log('Received chunk:', chunk, 'type:', messageType);
    },
  });

  useEffect(() => {
    startCatchup();
    return () => stopCatchup();
  }, [startCatchup, stopCatchup]);
}
```

## Notes

- Chat type is hardcoded to `CHAT_TYPE.ADMIN` — use a different hook variant for other chat types (e.g. `FAE`)
- `fetchChunks` returns an empty array on both HTTP errors and thrown exceptions, avoiding unhandled rejections
- `fromSequenceId` is optional; omitting it fetches all available chunks for the dialog
