Mingo-specific wrapper around the core `useChunkCatchup` hook, scoped to `ADMIN` chat type and wired to the Flamingo API client for fetching missed NATS message chunks during dialog catchup.

## Key Components

- **`useMingoChunkCatchup`** — Primary hook that orchestrates chunk catchup for a given dialog, restricted to `CHAT_TYPE.ADMIN`
- **`fetchChunks`** — Internal callback that hits `/chat/api/v1/dialogs/{dialogId}/chunks` with optional `fromSequenceId` for incremental catchup
- **Re-exports** — `ChunkData`, `NatsMessageType`, `UseChunkCatchupReturn` forwarded for consumer convenience

## Usage Example

```typescript
import { useMingoChunkCatchup } from './use-mingo-chunk-catchup';
import type { ChunkData, NatsMessageType } from './use-mingo-chunk-catchup';

function DialogStream({ dialogId }: { dialogId: string }) {
  const { startCatchup, stopCatchup } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: (chunk: ChunkData, messageType: NatsMessageType) => {
      console.log('Received chunk:', chunk, messageType);
    },
  });

  useEffect(() => {
    startCatchup();
    return () => stopCatchup();
  }, [startCatchup, stopCatchup]);
}
```

## Notes

- `chatTypes` is hardcoded to `[CHAT_TYPE.ADMIN]` — use the core `useChunkCatchup` directly if other chat types are needed
- `fromSequenceId` is optional; omitting it fetches all available chunks for the dialog
- Errors are swallowed and return `[]` — callers should handle missing chunks gracefully via the `onChunkReceived` callback
