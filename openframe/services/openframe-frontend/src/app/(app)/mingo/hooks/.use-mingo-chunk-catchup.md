React hook that wraps the core `useChunkCatchup` logic with Mingo-specific configuration, fetching missed AI response chunks for a given dialog via the internal API client.

## Key Components

- **`useMingoChunkCatchup`** — Main hook that initializes chunk catch-up for `CHAT_TYPE.ADMIN` dialogs, wiring up the API fetch function and delegating to `useChunkCatchupCore`
- **`fetchChunks`** — Memoized async callback that calls `GET /chat/api/v1/dialogs/{dialogId}/chunks` with optional `fromSequenceId` pagination support
- **`UseMingoChunkCatchupOptions`** — Input interface requiring a `dialogId` and an `onChunkReceived` handler

## Usage Example

```typescript
import { useMingoChunkCatchup } from './use-mingo-chunk-catchup';

function ChatComponent({ dialogId }: { dialogId: string }) {
  const { startCatchup, stopCatchup } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: (chunk, messageType) => {
      console.log('Received chunk:', chunk, 'type:', messageType);
    },
  });

  useEffect(() => {
    startCatchup();
    return () => stopCatchup();
  }, [startCatchup, stopCatchup]);
}
```

> **Note:** `dialogId` accepts `null` to support conditional activation — the hook safely defers fetching until a valid dialog ID is provided. Only `CHAT_TYPE.ADMIN` chunks are fetched, scoping this hook exclusively to Mingo (technician-facing) chat sessions.
