Manages Mingo AI dialog selection, message fetching, and approval/rejection workflows within the Flamingo OpenFrame dashboard. It coordinates infinite pagination, realtime streaming deduplication, and optimistic UI updates for chat dialogs.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `useMingoDialogSelection` | Hook | Primary hook managing dialog selection, message loading, and approval state |
| `computeInitialStartSeq` | Helper | Computes the highest `lastChunkStreamSeq` across all fetched pages for realtime stream alignment |

### Internal Responsibilities

- **`dialogQuery`** — Fetches active dialog metadata via GraphQL; auto-refetches every 15s during `STREAMING` state
- **`messagesQuery`** — Infinite-scrolling paginated message loader (50 messages/page, descending `createdAt`)
- **`handleApprove` / `handleReject`** — Optimistically updates approval state before network calls to prevent streaming race conditions
- **`selectDialogMutation`** — Switches active dialog while preserving cached messages for fast tab switching
- **Streaming dedup logic** — Reconciles realtime synthetic messages against GraphQL-persisted history to prevent duplicate assistant turns

## Usage Example

```typescript
const {
  handleApprove,
  handleReject,
  selectDialogMutation,
  dialogQuery,
  messagesQuery,
  approvalStatuses,
} = useMingoDialogSelection();

// Switch to a dialog
selectDialogMutation.mutate('dialog-id-123');

// Approve a pending AI command
await handleApprove('request-id-456');

// Reject a pending AI command
await handleReject('request-id-456');
```

> **Note:** Approval state is flipped *optimistically* before the network round-trip to prevent the incoming streaming continuation from being absorbed into the still-pending approval bubble.
