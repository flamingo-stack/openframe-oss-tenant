Manages Mingo AI dialog selection, message loading, and approval/rejection workflows by coordinating infinite query pagination, real-time streaming state, and optimistic UI updates.

## Key Components

- **`useMingoDialogSelection()`** — Primary hook that orchestrates dialog selection, historical message fetching, and approval state management
- **`computeInitialStartSeq()`** — Utility that calculates the highest stream sequence number across loaded message pages for SSE deduplication
- **`handleApprove / handleReject`** — Optimistic mutation handlers that flip approval status before the network round-trip to prevent streaming bubble collisions
- **`dialogQuery`** — React Query `useQuery` fetching dialog metadata with auto-refetch during active streaming (`streamState === 'STREAMING'`)
- **`messagesQuery`** — `useInfiniteQuery` for paginated historical messages (50/page, DESC order, admin chat type only)
- **`selectDialogMutation`** — Mutation that resets pagination state and sets the active dialog ID
- **`foldPendingApprovalsEnvelope`** — Post-processes messages to group pending approvals into batch UI elements

## Usage Example

```typescript
function MingoDialogPanel() {
  const {
    activeDialogId,
    dialogQuery,
    messagesQuery,
    handleApprove,
    handleReject,
    selectDialogMutation,
    initialOptStartSeq,
  } = useMingoDialogSelection();

  // Select a dialog
  const openDialog = (id: string) => {
    selectDialogMutation.mutate(id);
  };

  // Approve a pending command
  const onApprove = (requestId: string) => {
    handleApprove(requestId);
  };

  return (
    <div>
      {dialogQuery.data?.streamState === 'STREAMING' && <StreamingIndicator />}
      {messagesQuery.data?.pages.map(page =>
        page.messages.map(msg => (
          <MessageBubble
            key={msg.id}
            message={msg}
            onApprove={onApprove}
            startSeq={initialOptStartSeq}
          />
        ))
      )}
    </div>
  );
}
```

> **Note:** Approval status is flipped optimistically before mutation to prevent the realtime SSE stream from re-adopting an in-progress approval bubble as a new streaming message.
