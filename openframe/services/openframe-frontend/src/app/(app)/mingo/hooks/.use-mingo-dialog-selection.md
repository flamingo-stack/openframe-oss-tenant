Manages the selection, loading, and state of Mingo AI chat dialogs — including historical message processing, real-time streaming deduplication, and approval/rejection workflows for AI-generated action requests.

## Key Components

| Export / Symbol | Description |
|----------------|-------------|
| `useMingoDialogSelection` | Primary hook orchestrating dialog selection, message fetching, approval handling, and streaming deduplication |
| `computeInitialStartSeq` | Utility to determine the highest `lastChunkStreamSeq` across loaded message pages, used to anchor real-time stream resume |
| `handleApprove` / `handleReject` | Optimistically updates approval state and calls the backend mutation, then tracks analytics |
| `dialogQuery` | `useQuery` fetching the active dialog's metadata with self-healing refetch while streaming |
| `messagesQuery` | `useInfiniteQuery` for paginated, descending historical messages filtered to `ADMIN` chat type |
| `selectDialogMutation` | `useMutation` that switches the active dialog and resets pagination/loading state |

## Usage Example

```typescript
import { useMingoDialogSelection } from './use-mingo-dialog-selection';

function MingoDialogPanel() {
  const {
    // Consumed indirectly via useMingoMessagesStore
    // and returned from this hook as side effects
  } = useMingoDialogSelection();

  // The hook wires dialog selection, infinite message loading,
  // approval mutations, and streaming dedup automatically.
  // Pair with useMingoMessagesStore to read derived state:
  // activeDialogId, messages, pagination, streamingMessage.
}
```

> **Note:** This hook depends on `useMingoMessagesStore` for shared state and performs optimistic approval updates **before** the network round-trip to prevent streaming chunks from overwriting the approval card UI.
