React hook that manages the full lifecycle of a Mingo AI chat session — creating dialogs, sending/receiving messages, handling approval workflows, and controlling generation state.

## Key Components

**`useMingoChat(dialogId)`** — Primary hook accepting an optional dialog ID and returning a `UseMingoChat` object with:

| Member | Type | Description |
|--------|------|-------------|
| `messages` | `ProcessedMessage[]` | Deduplicated, filtered messages ready for rendering |
| `approvals` | `MessageSegment[]` | Pending approval requests extracted from message segments |
| `createDialog` | `() => Promise<string \| null>` | Creates a new Mingo dialog, returns its ID |
| `sendMessage` | `(content, targetDialogId?) => Promise<boolean>` | Sends a message with optimistic UI update |
| `stopGeneration` | `() => Promise<void>` | Cancels the current streaming response |
| `isTyping` | `boolean` | Whether Mingo is currently generating a response |
| `isCompacting` | `boolean` | Whether context compaction is in progress |
| `isCreatingDialog` | `boolean` | Guards against duplicate dialog creation |

**Approval deduplication logic** — Filters `approval_request` segments with `status: 'pending'` from the rendered message list and surfaces them separately via `approvals`. When a user message interrupts a pending approval, the latest pending request is immediately flipped to `'rejected'` before the API call resolves.

## Usage Example

```typescript
function MingoChatPanel({ dialogId }: { dialogId: string | null }) {
  const {
    messages,
    approvals,
    isTyping,
    isCompacting,
    sendMessage,
    createDialog,
    stopGeneration,
  } = useMingoChat(dialogId);

  const handleSend = async (text: string) => {
    let id = dialogId;
    if (!id) {
      id = await createDialog();
      if (!id) return;
    }
    await sendMessage(text, id);
  };

  return (
    <ChatUI
      messages={messages}
      approvals={approvals}
      isTyping={isTyping}
      isCompacting={isCompacting}
      onSend={handleSend}
      onStop={stopGeneration}
    />
  );
}
```

> **Note:** `sendMessage` is a no-op while `isTyping` is `true`, preventing duplicate submissions during active generation.
