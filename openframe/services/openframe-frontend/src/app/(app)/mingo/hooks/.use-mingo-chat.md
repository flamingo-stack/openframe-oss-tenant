React hook managing Mingo AI chat state and interactions, including message processing, dialog lifecycle, approval handling, and generation control.

## Key Components

### `ProcessedMessage`
Normalized message shape returned to consumers — includes `id`, `content`, `role`, `authorType`, `assistantType`, and `timestamp`.

### `UseMingoChat`
Return type interface exposing:
- **Messages:** `messages`, `isLoading`
- **Actions:** `createDialog`, `sendMessage`, `stopGeneration`
- **Approval system:** `approvals`
- **State:** `isCreatingDialog`, `isTyping`, `isCompacting`, `assistantType`

### `useMingoChat(dialogId)`
Primary export. Accepts a nullable `dialogId` and returns the full chat interface.

**Key behaviors:**
- **Message deduplication** — filters duplicate `approval_request`/`approval_batch` segments by `requestId`; first occurrence wins
- **Pending approval filtering** — pending approval cards are stripped from rendered messages and surfaced separately via `approvals`
- **Optimistic user messages** — adds a local message immediately before the API call resolves
- **Interrupt handling** — when a message is sent while an approval is pending, immediately flips the latest pending approval to `rejected` to avoid layout jumps
- **Compaction detection** — `isCompacting` is `true` when the last assistant message ends with a `context_compaction` segment in `started` state

## Usage Example

```typescript
function MingoChatPanel({ dialogId }: { dialogId: string | null }) {
  const {
    messages,
    isTyping,
    isCompacting,
    approvals,
    sendMessage,
    createDialog,
    stopGeneration,
  } = useMingoChat(dialogId);

  const handleSend = async (text: string) => {
    let id = dialogId;
    if (!id) {
      id = await createDialog();
    }
    if (id) await sendMessage(text, id);
  };

  return (
    <ChatUI
      messages={messages}
      approvals={approvals}
      isTyping={isTyping}
      isCompacting={isCompacting}
      onSend={handleSend}
      onStop={stopGeneration}
    />
  );
}
```
