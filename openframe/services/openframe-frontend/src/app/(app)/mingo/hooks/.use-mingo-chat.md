React hook that manages Mingo AI chat state and interactions, handling message processing, dialog lifecycle, approval workflows, and streaming generation control for a specific dialog session.

## Key Components

### `ProcessedMessage` Interface
Normalized message shape returned to consumers — includes `id`, `content` (string or `MessageSegment[]`), `role`, `name`, `authorType`, `assistantType`, and `timestamp`.

### `UseMingoChat` Interface
Return contract of the hook, exposing:
- **`messages`** — deduplicated, filtered `ProcessedMessage[]`
- **`approvals`** — pending `MessageSegment[]` extracted across all messages
- **`isTyping`** / **`isCompacting`** / **`isCreatingDialog`** — reactive UI state flags
- **`createDialog`** / **`sendMessage`** / **`stopGeneration`** — async action handlers

### `useMingoChat(dialogId)`
Main exported hook. Key behaviors:

| Concern | Detail |
|---|---|
| **Approval deduplication** | Filters `pending` approval segments from rendered bubbles; deduplicates by `requestId` across message history |
| **Interrupt handling** | When a message is sent while an approval is pending, the latest pending approval is immediately flipped to `rejected` before the API call |
| **Optimistic updates** | User messages are added to the store instantly with a generated ID before the server confirms |
| **Compaction detection** | Checks if the last assistant message tail is a `context_compaction` segment with `started` status |

## Usage Example

```typescript
const {
  messages,
  approvals,
  isTyping,
  isCompacting,
  createDialog,
  sendMessage,
  stopGeneration,
} = useMingoChat(dialogId);

// Create a new dialog, then send an opening message
const handleStart = async () => {
  const newDialogId = await createDialog();
  if (newDialogId) {
    await sendMessage('Hello, Mingo!', newDialogId);
  }
};

// Stop an in-progress generation
const handleStop = () => stopGeneration();
```
