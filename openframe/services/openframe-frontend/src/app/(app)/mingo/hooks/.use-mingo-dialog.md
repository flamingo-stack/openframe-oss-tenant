React hook for managing Mingo AI admin chat dialogs — handles dialog creation, message sending, and state management for the ADMIN agent type via the chat API.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `useMingoDialog` | Hook | Core hook managing dialog lifecycle and message dispatch |
| `createDialog` | Function | Creates a new ADMIN dialog session via `POST /chat/api/v1/dialogs` |
| `sendMessage` | Function | Sends a message to an active dialog, auto-creating one if needed |
| `resetDialog` | Function | Clears all dialog state and resets both mutations |
| `getActiveDialogId` | Internal | Resolves the active dialog ID from state, ref, or override |

### Returned State

| Property | Type | Description |
|----------|------|-------------|
| `currentDialogId` | `string \| null` | Active dialog session ID |
| `isCreatingDialog` | `boolean` | Dialog creation in-flight |
| `isSendingMessage` | `boolean` | Message send in-flight |
| `hasDialog` | `boolean` | Whether a dialog is currently active |
| `error` | `Error \| null` | Latest error from either mutation |

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog';

function MingoChat() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    hasDialog,
    sendMessage,
    resetDialog,
  } = useMingoDialog();

  const handleSend = async (text: string) => {
    // Auto-creates a dialog if none exists
    const success = await sendMessage(text);
    if (!success) console.warn('Message failed to send');
  };

  const handleNewChat = () => resetDialog();

  return (
    <div>
      <button onClick={() => handleSend('Hello, Mingo!')} disabled={isSendingMessage}>
        Send
      </button>
      {hasDialog && (
        <button onClick={handleNewChat}>New Chat</button>
      )}
    </div>
  );
}
```

> **Note:** `sendMessage` will automatically call `createDialog` if no active dialog exists, making it safe to call without pre-initializing a session. Dialog ID is tracked in both React state and a `useRef` to remain accessible within async closures.
