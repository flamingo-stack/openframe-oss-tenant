React hook managing Mingo AI admin chat dialog lifecycle — creates dialogs, sends messages, and tracks dialog state for the ADMIN agent type.

## Key Components

- **`useMingoDialog`** — Main exported hook that orchestrates dialog creation and message sending via `@tanstack/react-query` mutations
- **`createDialog`** — Creates a new ADMIN dialog via `POST /chat/api/v1/dialogs`, stores the returned `id` in both state and a ref for synchronous access
- **`sendMessage`** — Validates content, auto-creates a dialog if none exists, then sends via `POST /chat/api/v1/messages`
- **`resetDialog`** — Clears dialog state and resets both mutations back to idle
- **`getActiveDialogId`** — Resolves the active dialog ID with priority: `preferredDialogId` → `currentDialogId` state → `dialogIdRef` (covers async timing gaps)

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog';

function MingoChat() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    hasDialog,
    sendMessage,
    resetDialog,
  } = useMingoDialog();

  const handleSend = async (text: string) => {
    // Auto-creates a dialog if none exists, then sends
    const success = await sendMessage(text);
    if (!success) console.warn('Message failed to send');
  };

  const handleNewChat = () => resetDialog();

  return (
    <div>
      <button onClick={() => handleSend('Hello, Mingo!')} disabled={isSendingMessage}>
        {isCreatingDialog ? 'Starting chat...' : 'Send'}
      </button>
      {hasDialog && (
        <button onClick={handleNewChat}>New Chat</button>
      )}
    </div>
  );
}
```

## Returned State

| Property | Type | Description |
|---|---|---|
| `currentDialogId` | `string \| null` | Active dialog ID |
| `isCreatingDialog` | `boolean` | Dialog creation in flight |
| `isSendingMessage` | `boolean` | Message send in flight |
| `hasDialog` | `boolean` | Whether a dialog is active |
| `error` | `Error \| null` | Last mutation error |
