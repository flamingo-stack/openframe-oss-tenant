React hook that manages Mingo AI admin chat dialog lifecycle — creating dialogs, sending messages, and tracking state for the admin agent type.

## Key Components

**`useMingoDialog()`** — Primary exported hook returning:

| Return | Type | Description |
|--------|------|-------------|
| `currentDialogId` | `string \| null` | Active dialog ID (state + ref for sync access) |
| `isCreatingDialog` | `boolean` | Pending state for dialog creation |
| `isSendingMessage` | `boolean` | Pending state for message sending |
| `hasDialog` | `boolean` | Convenience flag for active dialog existence |
| `createDialog` | `() => Promise<string \| null>` | Creates a new ADMIN agent dialog |
| `sendMessage` | `(content, dialogId?) => Promise<boolean>` | Sends message, auto-creating dialog if needed |
| `resetDialog` | `() => void` | Clears dialog state and mutation caches |
| `error` | `Error \| null` | Latest error from either mutation |

**Internal mutations** (via TanStack Query):
- `createDialogMutation` — `POST /chat/api/v1/dialogs` with `agentType: 'ADMIN'`
- `sendMessageMutation` — `POST /chat/api/v1/messages` with `chatType: CHAT_TYPE.ADMIN`

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog';

function MingoAdminChat() {
  const {
    hasDialog,
    isCreatingDialog,
    isSendingMessage,
    sendMessage,
    resetDialog,
  } = useMingoDialog();

  const handleSubmit = async (input: string) => {
    // Auto-creates a dialog if none exists
    const success = await sendMessage(input);
    if (!success) console.warn('Message failed to send');
  };

  return (
    <ChatUI
      isLoading={isCreatingDialog || isSendingMessage}
      hasSession={hasDialog}
      onSend={handleSubmit}
      onReset={resetDialog}
    />
  );
}
```

> **Note:** Dialog ID is tracked via both `useState` and `useRef` to ensure synchronous access during rapid successive calls (e.g., auto-create then send in the same flow).
