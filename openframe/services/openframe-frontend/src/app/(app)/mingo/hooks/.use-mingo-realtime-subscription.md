Manages real-time NATS/JetStream subscriptions for Mingo AI chat dialogs, handling streaming message chunks, approval workflows, tool execution updates, and connection state across multiple concurrent dialog sessions.

## Key Components

### `useMingoRealtimeSubscription`
Primary hook that manages subscription lifecycle for multiple dialog sessions simultaneously.

- Tracks `subscribedDialogs` (Set), per-dialog `DialogSubscriptionState`, and overall `connectionState`
- Auto-subscribes to `activeDialogId` when it changes
- Exposes `subscribeToDialog`, `unsubscribeFromDialog`, `getSubscriptionState`, and `onConnectionChange`

### `useDialogChunkProcessor`
Internal hook that wires incoming NATS chunk data into the Mingo messages store.

- Calls `useRealtimeChunkProcessor` from `@flamingo-stack/openframe-frontend-core`
- Handles stream lifecycle: `onStreamStart`, `onStreamEnd`, `onSegmentsUpdate`, `onError`
- Manages approval resolution (`onApprovalResolved`), tool execution updates (`onToolExecuted`), and token usage (`onTokenUsage`)
- Computes `incompleteState` via `extractIncompleteMessageState` to support catchup on reconnect
- Respects feature flags for `thinking` and `batchApproval`

### `isInProgress` (utility)
Determines if a message's segments indicate an ongoing operation (active tool execution, pending approval request, or unresolved approval batch).

### Constants
- `MINGO_JETSTREAM_TOPIC` — `'admin-message'`
- `CHAT_CHUNKS_STREAM` — `'CHAT_CHUNKS'`

## Usage Example

```typescript
const {
  subscribeToDialog,
  unsubscribeFromDialog,
  getSubscriptionState,
  subscribedDialogs,
  connectionState,
  onConnectionChange,
} = useMingoRealtimeSubscription(activeDialogId, {
  onChunkReceived: (dialogId, chunk, messageType) => {
    console.log('Chunk received for dialog', dialogId);
  },
});

// Subscribe to a specific dialog
subscribeToDialog('dialog-abc-123');

// Check connection state
const { isSubscribed, isConnected, hasCaughtUp } = getSubscriptionState('dialog-abc-123');

// Unsubscribe when done
unsubscribeFromDialog('dialog-abc-123');
```
