Manages real-time NATS/JetStream subscriptions for Mingo AI chat dialogs, processing streaming message chunks, tool executions, and approval workflows into the Mingo messages store.

## Key Components

### `useMingoRealtimeSubscription`
Primary hook managing subscription lifecycle for multiple dialogs simultaneously. Tracks connection state, subscribed dialog sets, and per-dialog subscription states (`isSubscribed`, `isConnected`, `hasCaughtUp`).

### `useDialogChunkProcessor`
Internal hook wiring `useRealtimeChunkProcessor` from `openframe-frontend-core` to the Mingo messages store. Handles stream lifecycle events: start/end, segment updates, token usage, approval resolution, tool execution, and errors.

### `isInProgress`
Helper that inspects `MessageSegment[]` to determine if an assistant message still has pending tool executions, approval requests, or unresolved approval batches.

### Constants
| Constant | Value |
|---|---|
| `MINGO_JETSTREAM_TOPIC` | `'admin-message'` |
| `CHAT_CHUNKS_STREAM` | `'CHAT_CHUNKS'` |

## Usage Example

```typescript
const {
  subscribeToDialog,
  unsubscribeFromDialog,
  getSubscriptionState,
  subscribedDialogs,
  connectionState,
  onConnectionChange,
} = useMingoRealtimeSubscription(activeDialogId, {
  onChunkReceived: (dialogId, chunk, messageType) => {
    console.log('Chunk received for dialog:', dialogId);
  },
});

// Subscribe to a specific dialog
subscribeToDialog('dialog-abc-123');

// Check per-dialog state
const { isSubscribed, isConnected, hasCaughtUp } =
  getSubscriptionState('dialog-abc-123');

// Unsubscribe when done
unsubscribeFromDialog('dialog-abc-123');
```

**Feature flags respected:** `featureFlags.thinking` and `featureFlags.batchApproval` gate thinking mode and batch approval rendering in the chunk processor.
