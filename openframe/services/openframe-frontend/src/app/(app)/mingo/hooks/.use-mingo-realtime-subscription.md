Manages real-time NATS/JetStream subscriptions for Mingo AI chat dialogs, handling streaming message chunks, approval workflows, tool execution updates, and connection state across multiple concurrent dialog sessions.

## Key Components

### `useMingoRealtimeSubscription(activeDialogId, options)`
Top-level hook managing subscription lifecycle for multiple dialogs simultaneously. Tracks per-dialog connection/subscription/catchup states and auto-subscribes to the `activeDialogId` on mount.

**Returns:**
- `subscribeToDialog(dialogId)` — registers a dialog for real-time updates
- `unsubscribeFromDialog(dialogId)` — cleans up dialog subscription and catchup refs
- `getSubscriptionState(dialogId)` — returns `{ isSubscribed, isConnected, hasCaughtUp }`
- `subscribedDialogs` — `Set<string>` of active dialog IDs
- `connectionState` — `'connected' | 'disconnected' | 'connecting'`
- `onConnectionChange(dialogId, connected)` — NATS connection callback

### `useDialogChunkProcessor(dialogId, options)`
Internal hook wiring `useRealtimeChunkProcessor` to the Mingo message store. Handles:
- Stream lifecycle (`onStreamStart`, `onStreamEnd`)
- Segment updates with compaction/append support
- Approval resolution and tool execution updates
- Error and token usage reporting

### `isInProgress(segments)`
Pure utility that returns `true` if any segment indicates an ongoing operation (executing tool, pending approval request, or incomplete approval batch).

### Constants
- `MINGO_JETSTREAM_TOPIC` — `'admin-message'`
- `CHAT_CHUNKS_STREAM` — `'CHAT_CHUNKS'`

## Usage Example

```typescript
const {
  subscribeToDialog,
  unsubscribeFromDialog,
  getSubscriptionState,
  connectionState,
  onConnectionChange,
} = useMingoRealtimeSubscription(activeDialogId, {
  onChunkReceived: (dialogId, chunk, messageType) => {
    console.log('Chunk received for', dialogId);
  },
});

// Subscribe to a specific dialog
subscribeToDialog('dialog-123');

// Check state
const { isConnected, hasCaughtUp } = getSubscriptionState('dialog-123');

// Cleanup
unsubscribeFromDialog('dialog-123');
```
