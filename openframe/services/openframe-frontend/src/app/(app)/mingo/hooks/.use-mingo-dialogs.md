Fetches and manages paginated Mingo AI dialog conversations with unread message counts, using infinite scroll and periodic background refresh.

## Key Components

- **`transformToDialogItem`** — Transforms a raw `DialogNode` into a `DialogItem` shape, merging in the unread message count from the messages store.
- **`useMingoDialogs`** — Primary hook that queries the `/chat/graphql` endpoint for ADMIN agent dialogs, supports cursor-based pagination, optional search filtering, and auto-refetch every 60 seconds.

### Options (`UseMingoDialogsOptions`)

| Option | Default | Description |
|--------|---------|-------------|
| `enabled` | `true` | Toggle query execution |
| `search` | `undefined` | Filter dialogs by search term |
| `limit` | `20` | Items per page |

### Return Values

| Field | Type | Description |
|-------|------|-------------|
| `dialogs` | `DialogItem[]` | Flat list of all loaded dialogs with unread counts |
| `isLoading` | `boolean` | Initial load state |
| `isError` | `boolean` | Error state flag |
| `error` | `string \| undefined` | Error message |
| `hasNextPage` | `boolean` | Whether more pages exist |
| `fetchNextPage` | `function` | Load next page |
| `isFetchingNextPage` | `boolean` | Pagination load state |

## Usage Example

```typescript
import { useMingoDialogs } from './use-mingo-dialogs';

function DialogList() {
  const {
    dialogs,
    isLoading,
    hasNextPage,
    fetchNextPage,
    isFetchingNextPage,
  } = useMingoDialogs({ search: 'network issue', limit: 15 });

  if (isLoading) return <Spinner />;

  return (
    <>
      {dialogs.map(dialog => (
        <DialogRow
          key={dialog.id}
          title={dialog.title}
          unread={dialog.unreadMessagesCount}
        />
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()} disabled={isFetchingNextPage}>
          Load more
        </button>
      )}
    </>
  );
}
```
