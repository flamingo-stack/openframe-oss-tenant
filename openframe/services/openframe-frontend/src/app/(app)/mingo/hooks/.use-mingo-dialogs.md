Fetches and manages paginated Mingo AI dialog list data, merging server-side dialog records with local unread message counts from the messages store.

## Key Components

- **`transformToDialogItem(dialog, unreadCount)`** — Maps a raw `DialogNode` to a `DialogItem` shape, defaulting the title to `'Untitled Dialog'` and attaching the current unread count.
- **`useMingoDialogs(options)`** — Primary hook; wraps `useInfiniteQuery` to paginate dialogs via the `/chat/graphql` endpoint, filtered to `ADMIN` agent type. Merges paginated results with unread counts from `useMingoMessagesStore`.

### Options (`UseMingoDialogsOptions`)

| Option | Default | Description |
|--------|---------|-------------|
| `enabled` | `true` | Conditionally enable the query |
| `search` | — | Filter dialogs by search string |
| `limit` | `20` | Number of dialogs per page |

### Return Value

| Field | Type | Description |
|-------|------|-------------|
| `dialogs` | `DialogItem[]` | Flat list of all loaded dialogs with unread counts |
| `isLoading` | `boolean` | Initial load state |
| `isError` | `boolean` | Error state |
| `error` | `string \| undefined` | Error message if any |
| `hasNextPage` | `boolean` | Whether more pages exist |
| `fetchNextPage` | `fn` | Load the next page |
| `isFetchingNextPage` | `boolean` | Pagination in-flight state |

## Usage Example

```typescript
import { useMingoDialogs } from './use-mingo-dialogs';

function DialogList() {
  const {
    dialogs,
    isLoading,
    hasNextPage,
    fetchNextPage,
    isFetchingNextPage,
  } = useMingoDialogs({ limit: 10, search: 'network issue' });

  if (isLoading) return <Spinner />;

  return (
    <>
      {dialogs.map(d => (
        <DialogRow key={d.id} dialog={d} />
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()} disabled={isFetchingNextPage}>
          Load more
        </button>
      )}
    </>
  );
}
```

> Data is considered fresh for **30 seconds** and automatically refetched every **60 seconds** to surface new dialogs without manual interaction.
