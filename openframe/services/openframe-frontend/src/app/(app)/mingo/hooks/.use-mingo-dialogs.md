Fetches and manages paginated Mingo AI dialog sessions, merging server-side dialog data with local unread message counts from the store.

## Key Components

- **`transformToDialogItem`** — Maps a raw `DialogNode` to a `DialogItem` shape, injecting unread count and normalizing the timestamp
- **`useMingoDialogs(options)`** — Main hook; wraps `useInfiniteQuery` for cursor-based pagination over the `/chat/graphql` endpoint, filtered to `ADMIN` agent type dialogs

### Options (`UseMingoDialogsOptions`)

| Option | Default | Description |
|--------|---------|-------------|
| `enabled` | `true` | Enables/disables the query |
| `search` | — | Optional search string to filter dialogs |
| `limit` | `20` | Number of dialogs per page |

### Return Value

| Field | Type | Description |
|-------|------|-------------|
| `dialogs` | `DialogItem[]` | Flat list of all loaded dialogs with unread counts |
| `isLoading` | `boolean` | Initial load state |
| `isError` | `boolean` | Error state flag |
| `error` | `string \| undefined` | Error message if any |
| `hasNextPage` | `boolean` | Whether more pages exist |
| `fetchNextPage` | `function` | Loads the next page |
| `isFetchingNextPage` | `boolean` | Pagination loading state |

## Usage Example

```typescript
import { useMingoDialogs } from './use-mingo-dialogs';

function DialogList() {
  const {
    dialogs,
    isLoading,
    hasNextPage,
    fetchNextPage,
    isFetchingNextPage,
  } = useMingoDialogs({ search: 'network issue', limit: 10 });

  if (isLoading) return <Spinner />;

  return (
    <>
      {dialogs.map(dialog => (
        <DialogRow key={dialog.id} dialog={dialog} />
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()} disabled={isFetchingNextPage}>
          Load more
        </button>
      )}
    </>
  );
}
```

> Data is cached for 30 seconds (`staleTime`) and automatically refetched every 60 seconds (`refetchInterval`) to keep dialog lists current.
