Zustand store managing all Mingo AI chat state, including messages, streaming, approvals, tool executions, and pagination across multiple dialog sessions.

## Key Components

### State Slices

| Slice | Type | Description |
|-------|------|-------------|
| `messagesByDialog` | `Map<string, Message[]>` | Per-dialog message arrays keyed by `dialogId` |
| `streamingMessages` | `Map<string, Message \| null>` | Active streaming message per dialog |
| `segmentAccumulators` | `Map<string, MessageSegmentAccumulator>` | Real-time segment accumulators for streaming |
| `typingStates` / `unreadCounts` | `Map<string, ...>` | Per-dialog typing indicators and unread counts |
| `highestStreamSeqByDialog` | `Map<string, number>` | Highest JetStream sequence observed, persists across remounts |
| `tokenUsageByDialog` | `Map<string, TokenUsageData>` | Token consumption tracking per dialog |

### Message Actions

- **`setMessages`** / **`addMessage`** / **`updateMessage`** / **`removeMessage`** — CRUD operations (add deduplicates by `id`)
- **`prependMessages`** — Prepends older messages for pagination
- **`prependWithBoundaryMerge`** — Prepends with optional boundary message patch (used on paginated load)
- **`updateApprovalStatusInMessages`** — Updates `approval_request` or `approval_batch` segment status; syncs streaming message state
- **`updateToolExecutionInMessages`** — Patches `tool_execution` or `approval_batch` segments with execution results

### Streaming & Segments

- **`updateStreamingMessageSegments`** — Replaces segments on the active streaming message
- **`appendSegmentsToLastAssistant`** — Appends segments to the last assistant message in history
- **`getOrCreateAccumulator`** / **`resetAccumulator`** — Lifecycle management for `MessageSegmentAccumulator` instances

## Usage Example

```typescript
const { setMessages, addMessage, setStreamingMessage, getOrCreateAccumulator } =
  useMingoMessagesStore.getState();

// Load history
setMessages(dialogId, fetchedMessages);

// Handle incoming stream segment
const accumulator = getOrCreateAccumulator(dialogId, {
  onApprove: (requestId) => approveAction(requestId),
  onReject: (requestId) => rejectAction(requestId),
});

// Commit streamed message
setStreamingMessage(dialogId, null);
addMessage(dialogId, completedMessage);
```
