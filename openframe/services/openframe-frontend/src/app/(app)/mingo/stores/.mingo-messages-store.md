Zustand store managing all real-time message and dialog state for the Mingo AI chat interface, including streaming, segment accumulation, approval flows, and pagination.

## Key Components

### `MingoMessagesStore` Interface
Defines the complete store shape with:
- **`messagesByDialog`** — `Map<string, Message[]>` keyed by `dialogId`
- **`streamingMessages`** — active streaming message per dialog
- **`segmentAccumulators`** — `MessageSegmentAccumulator` instances for real-time token assembly
- **`typingStates` / `unreadCounts`** — per-dialog real-time UI state
- **`highestStreamSeqByDialog`** — persists highest JetStream `streamSeq` across subscription remounts
- **`tokenUsageByDialog`** — token consumption tracking per dialog

### `useMingoMessagesStore`
Zustand store created with `devtools` middleware, exposing actions across four domains:

| Domain | Key Actions |
|--------|-------------|
| Message CRUD | `setMessages`, `addMessage`, `updateMessage`, `removeMessage` |
| Pagination | `prependMessages`, `prependWithBoundaryMerge`, `setPagination` |
| Streaming | `setStreamingMessage`, `updateStreamingMessageSegments`, `appendSegmentsToLastAssistant` |
| Approvals & Tools | `updateApprovalStatusInMessages`, `updateToolExecutionInMessages`, `updateAccumulatorApprovalStatus` |

## Usage Example

```typescript
const {
  getMessages,
  setStreamingMessage,
  updateApprovalStatusInMessages,
  getOrCreateAccumulator,
} = useMingoMessagesStore();

// Read messages for current dialog
const messages = getMessages(activeDialogId);

// Resolve an approval request
updateApprovalStatusInMessages(dialogId, requestId, 'approved');

// Create/retrieve a segment accumulator with approval handlers
const accumulator = getOrCreateAccumulator(dialogId, {
  onApprove: (requestId) => handleApprove(requestId),
  onReject:  (requestId) => handleReject(requestId),
});
```

> `prependWithBoundaryMerge` handles the common pagination edge case where the oldest loaded message needs partial updates (e.g. cursor markers) when prepending a new history page.
