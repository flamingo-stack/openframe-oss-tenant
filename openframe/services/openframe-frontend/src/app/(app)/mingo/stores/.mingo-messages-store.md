Zustand store for managing all Mingo AI chat state, including messages, dialogs, streaming, segment accumulators, token usage, and real-time indicators across multiple dialog sessions.

## Key Components

### State Shape
| Field | Type | Purpose |
|-------|------|---------|
| `messagesByDialog` | `Map<string, Message[]>` | Per-dialog message lists |
| `activeDialogId` | `string \| null` | Currently selected dialog |
| `streamingMessages` | `Map<string, Message \| null>` | In-progress AI responses |
| `segmentAccumulators` | `Map<string, MessageSegmentAccumulator>` | Streaming segment builders |
| `highestStreamSeqByDialog` | `Map<string, number>` | JetStream deduplication cursor |
| `typingStates` / `unreadCounts` | `Map<string, ...>` | Real-time UI indicators |

### Message Actions
- **`setMessages`** / **`addMessage`** / **`updateMessage`** / **`removeMessage`** — CRUD on per-dialog message lists; `addMessage` upserts by `id`
- **`prependMessages`** — Prepends older (paginated) messages
- **`prependWithBoundaryMerge`** — Prepends and optionally patches a boundary message in one atomic update
- **`updateApprovalStatusInMessages`** — Updates `approval_request` or `approval_batch` segments and syncs the streaming message
- **`updateToolExecutionInMessages`** — Patches a `tool_execution` or `approval_batch` segment with execution results

### Streaming / Segments
- **`setStreamingMessage`** / **`updateStreamingMessageSegments`** — Manage the live AI response bubble
- **`appendSegmentsToLastAssistant`** — Appends segments to the last persisted assistant message
- **`getOrCreateAccumulator`** / **`resetAccumulator`** / **`updateAccumulatorApprovalStatus`** — Lifecycle for `MessageSegmentAccumulator` instances

## Usage Example

```typescript
// Reading messages in a component
const messages = useMingoMessagesStore(s => s.getMessages(dialogId));
const streaming = useMingoMessagesStore(s => s.getStreamingMessage(dialogId));

// Handling an incoming stream event
const { appendSegmentsToLastAssistant, recordHighestStreamSeq } = useMingoMessagesStore.getState();
appendSegmentsToLastAssistant(dialogId, incomingSegments);
recordHighestStreamSeq(dialogId, streamSeq);

// Approving a tool call
useMingoMessagesStore.getState().updateApprovalStatusInMessages(dialogId, requestId, 'approved');
```

> **Note:** The store is backed by Zustand `devtools` middleware — all actions are inspectable in Redux DevTools under the `useMingoMessagesStore` slice.
