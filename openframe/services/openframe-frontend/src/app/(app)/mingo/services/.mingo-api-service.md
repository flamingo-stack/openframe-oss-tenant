React Query mutation hooks for Mingo AI chat operations, providing dialog creation, message sending, approval/rejection handling, and generation control via the centralized `apiClient`.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `useCreateDialogMutation` | Hook | Creates a new Mingo AI admin chat dialog |
| `useSendMessageMutation` | Hook | Sends a message to an existing dialog |
| `useApproveRequestMutation` | Hook | Approves a pending AI approval request |
| `useRejectRequestMutation` | Hook | Rejects a pending AI approval request |
| `useStopGenerationMutation` | Hook | Stops active AI response generation for a dialog |
| `CreateDialogResponse` | Interface | Shape of a newly created dialog |
| `SendMessageResponse` | Interface | Shape of a sent message response |
| `ApprovalResponse` | Interface | Shape of an approval/rejection response |

All hooks wrap `useMutation` from `@tanstack/react-query`. Approve/reject hooks include destructive toast notifications on error via `useToast`.

## Usage Example

```typescript
import {
  useCreateDialogMutation,
  useSendMessageMutation,
  useApproveRequestMutation,
  useStopGenerationMutation,
} from './mingo-api-service';

function MingoChat() {
  const createDialog = useCreateDialogMutation();
  const sendMessage = useSendMessageMutation();
  const approve = useApproveRequestMutation();
  const stopGeneration = useStopGenerationMutation();

  const handleStart = async () => {
    const dialog = await createDialog.mutateAsync();

    await sendMessage.mutateAsync({
      dialogId: dialog.id,
      content: 'List all offline devices',
    });
  };

  const handleApprove = (requestId: string) => {
    approve.mutate(requestId);
  };

  const handleStop = (dialogId: string) => {
    stopGeneration.mutate(dialogId);
  };
}
```

> All mutations throw on non-OK responses, making them compatible with `mutateAsync` try/catch patterns and React Query's `onError` callbacks.
