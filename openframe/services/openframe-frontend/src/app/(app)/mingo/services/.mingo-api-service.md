React Query mutation hooks for Mingo AI chat operations, providing a typed interface for dialog management, message sending, and approval workflows via the centralized `apiClient`.

## Key Components

### Interfaces
| Interface | Description |
|-----------|-------------|
| `CreateDialogResponse` | Dialog creation result including `id`, `agentType`, `status`, and timestamps |
| `SendMessageResponse` | Message send result containing `messageId` |
| `ApprovalResponse` | Approval/rejection result with `requestId`, `status`, and `timestamp` |
| `CreateDialogRequest` | Payload for dialog creation (`agentType: 'ADMIN'`) |
| `SendMessageRequest` | Payload for sending a message (`dialogId`, `content`, `chatType`) |

### Hooks
| Hook | Endpoint | Description |
|------|----------|-------------|
| `useCreateDialogMutation` | `POST /chat/api/v1/dialogs` | Creates a new ADMIN agent dialog |
| `useSendMessageMutation` | `POST /chat/api/v1/messages` | Sends a message to an existing dialog |
| `useApproveRequestMutation` | `POST /chat/api/v1/approval-requests/:id/approve` | Approves a pending request; shows destructive toast on error |
| `useRejectRequestMutation` | `POST /chat/api/v1/approval-requests/:id/approve` | Rejects a pending request (`approve: false`); shows destructive toast on error |
| `useStopGenerationMutation` | `POST /chat/api/v1/dialogs/:id/stop` | Stops active AI response generation for a dialog |

## Usage Example

```typescript
import {
  useCreateDialogMutation,
  useSendMessageMutation,
  useApproveRequestMutation,
} from './mingo-api-service';

function MingoChat() {
  const createDialog = useCreateDialogMutation();
  const sendMessage = useSendMessageMutation();
  const approveRequest = useApproveRequestMutation();

  const handleStart = async () => {
    const dialog = await createDialog.mutateAsync();
    await sendMessage.mutateAsync({
      dialogId: dialog.id,
      content: 'List all offline devices',
    });
  };

  const handleApprove = (requestId: string) => {
    approveRequest.mutate(requestId);
  };
}
```

> All hooks use `@tanstack/react-query` mutations. Approval/rejection hooks integrate `useToast` to surface errors automatically — no additional error handling needed at the call site.
