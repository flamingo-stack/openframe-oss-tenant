React Query mutation hooks for Mingo AI chat operations, providing a typed interface for dialog management, message sending, and approval workflows via the centralized `apiClient`.

## Key Components

### Interfaces

| Interface | Description |
|-----------|-------------|
| `CreateDialogRequest` / `CreateDialogResponse` | Payload and response shape for dialog creation |
| `SendMessageRequest` / `SendMessageResponse` | Payload and response shape for sending messages |
| `ApprovalResponse` | Response shape for approve/reject operations |

### Hooks

| Hook | Description |
|------|-------------|
| `useCreateDialogMutation` | Creates a new `ADMIN` agent dialog via `POST /chat/api/v1/dialogs` |
| `useSendMessageMutation` | Sends a message to an existing dialog via `POST /chat/api/v1/messages` |
| `useApproveRequestMutation` | Approves a pending request via `POST /chat/api/v1/approval-requests/:id/approve` — shows a destructive toast on error |
| `useRejectRequestMutation` | Rejects a pending request using the same endpoint with `approve: false` — shows a destructive toast on error |
| `useStopGenerationMutation` | Stops ongoing AI response generation for a dialog via `POST /chat/api/v1/dialogs/:id/stop` |

## Usage Example

```typescript
import {
  useCreateDialogMutation,
  useSendMessageMutation,
  useApproveRequestMutation,
} from './mingo-api-service';

function MingoChat() {
  const createDialog = useCreateDialogMutation();
  const sendMessage = useSendMessageMutation();
  const approveRequest = useApproveRequestMutation();

  const handleStart = async () => {
    const dialog = await createDialog.mutateAsync();

    await sendMessage.mutateAsync({
      dialogId: dialog.id,
      content: 'List all offline devices',
    });
  };

  const handleApprove = (requestId: string) => {
    approveRequest.mutate(requestId);
  };

  return (/* ... */);
}
```

> All hooks throw on non-OK API responses. Approval and rejection hooks additionally surface failures via the shared `useToast` notification system.
