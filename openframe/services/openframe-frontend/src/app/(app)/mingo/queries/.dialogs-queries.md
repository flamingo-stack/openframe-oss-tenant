GraphQL query definitions for the Mingo AI dialog system, providing list, detail, and message retrieval operations with cursor-based pagination support.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `GET_MINGO_DIALOGS_QUERY` | `string` | Fetches a paginated list of dialogs with filtering and search |
| `GET_MINGO_DIALOG_QUERY` | `string` | Fetches a single dialog's full detail including owner, ratings, and token usage |
| `getMingoDialogMessagesQuery()` | `function` | Returns a messages query string, optionally including AI thinking data |

## Query Variables

**`GET_MINGO_DIALOGS_QUERY`**
- `$filter: DialogFilterInput` — Filter dialogs by criteria
- `$pagination: CursorPaginationInput` — Cursor-based pagination
- `$search: String` — Full-text search

**`GET_MINGO_DIALOG_QUERY`**
- `$id: ID!` — Dialog identifier

**`getMingoDialogMessagesQuery()`**
- `$dialogId: ID!`, `$cursor`, `$limit`, `$sortField`, `$sortDirection`

## Usage Example

```typescript
import {
  GET_MINGO_DIALOGS_QUERY,
  GET_MINGO_DIALOG_QUERY,
  getMingoDialogMessagesQuery,
} from './dialogs-queries';

// Fetch paginated dialog list
const dialogs = await gqlClient.query(GET_MINGO_DIALOGS_QUERY, {
  filter: { status: 'OPEN' },
  pagination: { limit: 20 },
  search: 'network issue',
});

// Fetch single dialog detail
const dialog = await gqlClient.query(GET_MINGO_DIALOG_QUERY, {
  id: 'dialog_abc123',
});

// Fetch messages — include AI thinking steps for debug/advanced views
const messagesQuery = getMingoDialogMessagesQuery({ includeThinking: true });
const messages = await gqlClient.query(messagesQuery, {
  dialogId: 'dialog_abc123',
  limit: 50,
  sortDirection: 'ASC',
});
```

## Message Data Union Types

The messages query resolves `messageData` as a GraphQL union supporting: `TextData`, `ThinkingData` *(opt-in)*, `ExecutingToolData`, `ExecutedToolData`, `ApprovalRequestData`, `ApprovalResultData`, `ContextCompactionStartData`, `ContextCompactionEndData`, and `ErrorData`.
