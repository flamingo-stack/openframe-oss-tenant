A React hook that provides an article update mutation via Relay, with built-in toast error notifications and pending state tracking.

## Key Components

- **`updateArticleMutation`** — GraphQL mutation that updates an article's `name`, `parentId`, `content`, `summary`, and `updatedAt` fields, returning the updated record by `id`
- **`useUpdateArticle()`** — Custom hook exposing:
  - `updateArticle({ input, onCompleted? })` — Returns a `Promise<void>` that resolves on success or rejects with a destructive toast on error
  - `isPending` — Boolean reflecting Relay's in-flight mutation state

## Usage Example

```typescript
import { useUpdateArticle } from './use-update-article';

function ArticleEditor({ articleId }: { articleId: string }) {
  const { updateArticle, isPending } = useUpdateArticle();

  const handleSave = async (content: string) => {
    await updateArticle({
      input: { id: articleId, content },
      onCompleted: () => console.log('Article saved'),
    });
  };

  return (
    <button onClick={() => handleSave('Updated content')} disabled={isPending}>
      {isPending ? 'Saving...' : 'Save'}
    </button>
  );
}
```

## Notes

- Must be used in a **client component** (`'use client'`)
- Requires a Relay environment provider in the component tree
- Error messages surface directly from the `Error` object if available, otherwise falls back to `'Unable to update article'`
