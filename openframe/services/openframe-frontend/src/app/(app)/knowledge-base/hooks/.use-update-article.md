A React hook that wraps a Relay GraphQL mutation for updating knowledge base articles, with built-in error toasting and promise-based completion handling.

## Key Components

- **`updateArticleMutation`** — Relay `graphql` tagged mutation that calls `updateArticle`, returning updated fields: `id`, `name`, `parentId`, `content`, `summary`, `updatedAt`
- **`useUpdateArticle()`** — Primary exported hook returning:
  - `updateArticle(args)` — Async function that commits the mutation and returns a `Promise<void>`
  - `isPending` — Boolean reflecting Relay's in-flight mutation state

## Usage Example

```typescript
import { useUpdateArticle } from './use-update-article';

function ArticleEditor({ articleId }: { articleId: string }) {
  const { updateArticle, isPending } = useUpdateArticle();

  const handleSave = async (content: string) => {
    await updateArticle({
      input: { id: articleId, content },
      onCompleted: () => console.log('Article saved'),
    });
  };

  return (
    <button onClick={() => handleSave('Updated content')} disabled={isPending}>
      {isPending ? 'Saving...' : 'Save'}
    </button>
  );
}
```

## Behavior Notes

- On **success**: calls the optional `onCompleted` callback, then resolves the promise
- On **error**: displays a destructive toast via `useToast` with the error message, then rejects the promise
- The `updateArticle` function is memoized with `useCallback` — stable across re-renders unless `commit` or `toast` changes
