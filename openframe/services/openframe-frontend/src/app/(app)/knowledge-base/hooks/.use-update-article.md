Provides a React hook for executing the `updateArticle` GraphQL mutation with built-in loading state tracking and error toast notifications.

## Key Components

- **`updateArticleMutation`** — Relay GraphQL mutation that updates an article's `name`, `parentId`, `content`, `summary`, and `updatedAt` fields
- **`useUpdateArticle()`** — Primary hook export returning:
  - `updateArticle(args)` — Promise-based mutation executor accepting an `UpdateArticleInput` and optional `onCompleted` callback
  - `isPending` — Boolean reflecting in-flight mutation state

## Usage Example

```typescript
import { useUpdateArticle } from './use-update-article';

function ArticleEditor({ articleId }: { articleId: string }) {
  const { updateArticle, isPending } = useUpdateArticle();

  const handleSave = async (content: string) => {
    await updateArticle({
      input: { id: articleId, content },
      onCompleted: () => console.log('Article saved'),
    });
  };

  return (
    <button onClick={() => handleSave('New content')} disabled={isPending}>
      {isPending ? 'Saving...' : 'Save'}
    </button>
  );
}
```

## Behavior Notes

- Returns a `Promise<void>` — supports `async/await` and `.then()` chaining
- On error, automatically fires a destructive toast with the error message before rejecting the promise
- `onCompleted` callback fires before the promise resolves, allowing sequential side effects
