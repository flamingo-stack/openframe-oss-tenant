A React hook that handles folder renaming via a GraphQL mutation using Relay, with built-in error toast notifications.

## Key Components

- **`renameFolderMutation`** — Relay GraphQL mutation that calls `renameFolder(id, name)` and returns the updated `id`, `name`, and `updatedAt` fields
- **`RenameFolderArgs`** — Interface defining the hook's rename parameters: `id`, `name`, and an optional `onCompleted` callback
- **`useRenameFolder()`** — Primary exported hook returning `renameFolder` and `isPending`

## Usage Example

```typescript
import { useRenameFolder } from './use-rename-folder';

function FolderItem({ folder }) {
  const { renameFolder, isPending } = useRenameFolder();

  const handleRename = (newName: string) => {
    renameFolder({
      id: folder.id,
      name: newName,
      onCompleted: () => console.log('Folder renamed successfully'),
    });
  };

  return (
    <button onClick={() => handleRename('New Folder Name')} disabled={isPending}>
      Rename
    </button>
  );
}
```

## Return Values

| Value | Type | Description |
|-------|------|-------------|
| `renameFolder` | `(args: RenameFolderArgs) => void` | Triggers the rename mutation |
| `isPending` | `boolean` | `true` while the mutation is in-flight |

> On mutation failure, a destructive toast notification is automatically displayed with the error message, requiring no additional error handling at the call site.
