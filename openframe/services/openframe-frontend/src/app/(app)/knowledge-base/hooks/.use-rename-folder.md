A React hook that renames a folder via a GraphQL mutation using React Relay, with built-in error toast notifications.

## Key Components

- **`renameFolderMutation`** — Relay GraphQL mutation that calls `renameFolder(id, name)` and returns the updated `id`, `name`, and `updatedAt` fields
- **`RenameFolderArgs`** — Interface defining the hook's input: `id`, `name`, and an optional `onCompleted` callback
- **`useRenameFolder()`** — Main exported hook returning `renameFolder` and `isPending`

## Usage Example

```typescript
import { useRenameFolder } from './use-rename-folder';

function FolderRenameButton({ folderId }: { folderId: string }) {
  const { renameFolder, isPending } = useRenameFolder();

  const handleRename = () => {
    renameFolder({
      id: folderId,
      name: 'New Folder Name',
      onCompleted: () => console.log('Folder renamed successfully'),
    });
  };

  return (
    <button onClick={handleRename} disabled={isPending}>
      {isPending ? 'Renaming...' : 'Rename Folder'}
    </button>
  );
}
```

## Return Values

| Property | Type | Description |
|---|---|---|
| `renameFolder` | `(args: RenameFolderArgs) => void` | Triggers the rename mutation |
| `isPending` | `boolean` | `true` while the mutation is in-flight |

On error, a destructive toast is displayed automatically with the error message or a fallback `'Unable to rename folder'` string. The `onCompleted` callback is optional and fires only on success.
