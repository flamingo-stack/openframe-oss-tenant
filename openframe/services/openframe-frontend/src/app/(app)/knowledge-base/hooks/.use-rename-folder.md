A React hook that executes a GraphQL mutation to rename a folder, with built-in error toast notifications.

## Key Components

- **`renameFolderMutation`** — Relay GraphQL mutation that accepts `id` and `name` variables, returning the updated `id`, `name`, and `updatedAt` fields.
- **`RenameFolderArgs`** — Interface defining the hook's input: `id` (folder ID), `name` (new name), and an optional `onCompleted` callback.
- **`useRenameFolder`** — Primary exported hook returning `renameFolder` (the mutation trigger) and `isPending` (in-flight state).

## Usage Example

```typescript
import { useRenameFolder } from './use-rename-folder';

function FolderItem({ folder }) {
  const { renameFolder, isPending } = useRenameFolder();

  const handleRename = (newName: string) => {
    renameFolder({
      id: folder.id,
      name: newName,
      onCompleted: () => console.log('Folder renamed successfully'),
    });
  };

  return (
    <button onClick={() => handleRename('New Folder Name')} disabled={isPending}>
      Rename
    </button>
  );
}
```

## Behavior Notes

- On **success**, the optional `onCompleted` callback is invoked and Relay's store is automatically updated with the returned fields.
- On **error**, a destructive toast is displayed with the error message (or a generic fallback).
- `isPending` reflects the Relay `isInFlight` state, useful for disabling UI controls during the mutation.
