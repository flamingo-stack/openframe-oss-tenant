Fetches a pre-signed download URL for a knowledge base article attachment via GraphQL, then triggers a browser file download using a temporary object URL.

## Key Components

- **`downloadArticleAttachmentQuery`** — Relay GraphQL query that resolves `knowledgeBaseAttachmentDownloadUrl` for a given `attachmentId`.
- **`useDownloadArticleAttachment`** — Custom hook returning a `download` callback that orchestrates the full fetch-and-save flow.
- **`download(attachmentId, fileName)`** — Fetches the signed URL, retrieves the file as a blob, creates a temporary anchor element to trigger the browser download, then revokes the object URL. Displays a destructive toast on any failure.

## Usage Example

```typescript
import { useDownloadArticleAttachment } from './use-download-article-attachment';

function AttachmentItem({ id, name }: { id: string; name: string }) {
  const { download } = useDownloadArticleAttachment();

  return (
    <button onClick={() => download(id, name)}>
      Download {name}
    </button>
  );
}
```

## Behavior Notes

- Uses `fetchPolicy: 'network-only'` to ensure a fresh signed URL is always retrieved rather than served from the Relay store cache.
- The blob/object URL pattern avoids exposing the signed URL in the browser's download history.
- Errors from both the GraphQL query and the subsequent file fetch are caught and surfaced via the `useToast` notification system.
