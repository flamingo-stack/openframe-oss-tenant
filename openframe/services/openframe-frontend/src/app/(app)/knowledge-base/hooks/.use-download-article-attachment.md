A React hook that fetches a presigned download URL for a knowledge base article attachment via Relay and triggers a browser file download.

## Key Components

- **`downloadArticleAttachmentQuery`** — Relay GraphQL query that resolves `knowledgeBaseAttachmentDownloadUrl` for a given `attachmentId`
- **`useDownloadArticleAttachment`** — Main hook export; returns a `download` function
- **`download(attachmentId, fileName)`** — Async callback that fetches the signed URL, retrieves the file as a Blob, creates a temporary `<a>` element to trigger the download, then revokes the object URL to free memory
- **Error handling** — Surfaces failures (missing URL, failed fetch) via a destructive toast notification

## Usage Example

```typescript
import { useDownloadArticleAttachment } from './use-download-article-attachment';

function AttachmentItem({ attachment }) {
  const { download } = useDownloadArticleAttachment();

  return (
    <button onClick={() => download(attachment.id, attachment.fileName)}>
      Download {attachment.fileName}
    </button>
  );
}
```

## Notes

- Uses `fetchPolicy: 'network-only'` to always retrieve a fresh presigned URL, avoiding stale cached URLs
- The Relay environment is consumed via `useRelayEnvironment()`, so this hook must be used within a `RelayEnvironmentProvider`
- Object URLs are revoked immediately after the download click to prevent memory leaks
