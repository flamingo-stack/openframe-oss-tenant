Manages tag search and selection state for knowledge base filtering, providing debounced search input handling alongside multi-tag selection operations.

## Key Components

### `TagSearchState` (interface)
Describes the full state shape and actions returned by the hook:

| Property | Type | Description |
|---|---|---|
| `search` | `string` | Current raw search input value |
| `debouncedSearch` | `string` | Search value debounced by 300ms |
| `setSearch` | `(value: string) => void` | Updates the search input |
| `selectedTags` | `SelectedKnowledgeBaseTag[]` | Currently selected tag objects |
| `tagIds` | `string[]` | Derived array of selected tag IDs |
| `tagSearchOptions` | `TagSearchOption<string>[]` | Derived options formatted for UI select components |
| `addTag` | `(tag) => void` | Adds a tag (deduplicates by ID) |
| `removeTag` | `(id) => void` | Removes a tag by ID |
| `clearAll` | `() => void` | Resets search and clears all selected tags |

### `useTagSearchState` (hook)
Returns a `TagSearchState` object. Internally uses `useState` for search and selection, `useDebounce` (300ms) for the search string, and `useMemo`/`useCallback` to memoize derived values and stable action references.

## Usage Example

```typescript
import { useTagSearchState } from './use-tag-search-state';

function KnowledgeBaseFilter() {
  const {
    search,
    debouncedSearch,
    setSearch,
    selectedTags,
    tagSearchOptions,
    addTag,
    removeTag,
    clearAll,
  } = useTagSearchState();

  // debouncedSearch is safe to use in API calls
  useEffect(() => {
    fetchTags(debouncedSearch);
  }, [debouncedSearch]);

  return (
    <TagSearchInput
      value={search}
      onChange={setSearch}
      selectedOptions={tagSearchOptions}
      onAdd={addTag}
      onRemove={removeTag}
      onClear={clearAll}
    />
  );
}
```
