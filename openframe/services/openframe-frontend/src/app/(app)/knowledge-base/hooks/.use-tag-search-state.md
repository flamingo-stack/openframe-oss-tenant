Manages tag search and selection state for the Knowledge Base UI, combining debounced text search with a collection of selected tags.

## Key Components

**`TagSearchState` interface** — Shape of the returned state object:

| Property | Type | Description |
|---|---|---|
| `search` | `string` | Raw search input value |
| `debouncedSearch` | `string` | Search value debounced by 300ms |
| `setSearch` | `(value: string) => void` | Updates the search input |
| `selectedTags` | `SelectedKnowledgeBaseTag[]` | Currently selected tag objects |
| `tagIds` | `string[]` | Derived array of selected tag IDs |
| `tagSearchOptions` | `TagSearchOption<string>[]` | Tags mapped to `{ label, value }` for UI dropdowns |
| `addTag` | `(tag) => void` | Adds a tag (deduplicates by ID) |
| `removeTag` | `(id) => void` | Removes a tag by ID |
| `clearAll` | `() => void` | Resets search and selected tags |

**`useTagSearchState()`** — Main hook that encapsulates all state and memoized callbacks.

## Usage Example

```typescript
import { useTagSearchState } from './use-tag-search-state';

function KnowledgeBaseFilter() {
  const {
    search,
    debouncedSearch,
    setSearch,
    selectedTags,
    tagSearchOptions,
    addTag,
    removeTag,
    clearAll,
  } = useTagSearchState();

  // debouncedSearch is safe to use in API calls
  useEffect(() => {
    fetchTags(debouncedSearch);
  }, [debouncedSearch]);

  return (
    <TagSearchInput
      value={search}
      onChange={setSearch}
      selected={tagSearchOptions}
      onAdd={addTag}
      onRemove={removeTag}
      onClear={clearAll}
    />
  );
}
```
