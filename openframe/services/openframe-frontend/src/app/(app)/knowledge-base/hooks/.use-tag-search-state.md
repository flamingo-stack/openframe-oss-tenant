Manages tag-based search state for the knowledge base, combining debounced text search with multi-tag selection in a single reusable hook.

## Key Components

### `TagSearchState` Interface
Describes the full shape of the state and actions returned by the hook:

| Property | Type | Description |
|---|---|---|
| `search` | `string` | Raw search input value |
| `debouncedSearch` | `string` | Debounced (300ms) search value for API calls |
| `setSearch` | `(value: string) => void` | Updates the search input |
| `selectedTags` | `SelectedKnowledgeBaseTag[]` | Currently selected tags |
| `tagIds` | `string[]` | Derived array of selected tag IDs |
| `tagSearchOptions` | `TagSearchOption<string>[]` | Derived options formatted for the tag search UI component |
| `addTag` | `(tag) => void` | Adds a tag (deduplicates by ID) |
| `removeTag` | `(id) => void` | Removes a tag by ID |
| `clearAll` | `() => void` | Resets search and selected tags |

### `useTagSearchState()`
The hook itself. Internally uses `useState` for raw state, `useDebounce` (300ms) for the search string, and `useMemo`/`useCallback` for stable derived values and handlers.

## Usage Example

```typescript
import { useTagSearchState } from './use-tag-search-state';

function KnowledgeBaseSearch() {
  const {
    search,
    debouncedSearch,
    setSearch,
    selectedTags,
    tagSearchOptions,
    addTag,
    removeTag,
    clearAll,
  } = useTagSearchState();

  // Use debouncedSearch for API queries to avoid excessive calls
  useEffect(() => {
    fetchArticles({ query: debouncedSearch, tagIds });
  }, [debouncedSearch, tagIds]);

  return (
    <TagSearchInput
      value={search}
      onChange={setSearch}
      options={tagSearchOptions}
      onAddTag={addTag}
      onRemoveTag={removeTag}
      onClear={clearAll}
    />
  );
}
```
