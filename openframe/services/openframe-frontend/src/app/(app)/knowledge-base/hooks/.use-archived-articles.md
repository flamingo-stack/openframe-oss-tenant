Utility for managing Relay connection IDs for archived knowledge base articles, supporting filtered pagination by search term and tag IDs.

## Key Components

- **`ARCHIVED_ARTICLES_CONNECTION_KEY`** — Constant string key (`'knowledgeBaseTable_archivedArticles'`) used to identify the Relay connection.
- **`ArchivedArticlesConnectionFilter`** — Interface defining filter shape with optional `search` string and `tagIds` array.
- **`getArchivedArticlesConnectionId`** — Generates a stable Relay connection ID from the root client record, scoped by the provided search and tag filters.

## Usage Example

```typescript
import {
  getArchivedArticlesConnectionId,
  ArchivedArticlesConnectionFilter,
} from './use-archived-articles';

const filter: ArchivedArticlesConnectionFilter = {
  search: 'vpn setup',
  tagIds: ['tag-1', 'tag-2'],
};

const connectionId = getArchivedArticlesConnectionId(filter);
// Use connectionId to read/update the Relay store for this filtered connection
```
