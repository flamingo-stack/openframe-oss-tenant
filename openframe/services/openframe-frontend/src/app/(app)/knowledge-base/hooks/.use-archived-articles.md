Utility for managing the Relay connection ID for archived knowledge base articles, supporting filter-based connection lookups.

## Key Components

- **`ARCHIVED_ARTICLES_CONNECTION_KEY`** — Constant string key identifying the archived articles Relay connection (`knowledgeBaseTable_archivedArticles`).
- **`ArchivedArticlesConnectionFilter`** — Interface defining the filter shape: `search` (nullable string) and `tagIds` (nullable readonly string array).
- **`getArchivedArticlesConnectionId`** — Function that generates a deterministic Relay connection ID from the root client record, keyed by the provided search and tagIds filters.

## Usage Example

```typescript
import {
  getArchivedArticlesConnectionId,
  ArchivedArticlesConnectionFilter,
} from './use-archived-articles';

const filter: ArchivedArticlesConnectionFilter = {
  search: 'firewall setup',
  tagIds: ['tag-1', 'tag-2'],
};

const connectionId = getArchivedArticlesConnectionId(filter);
// Returns a stable Relay connection ID for use in store updates or optimistic responses
```

> **Note:** `null` is used as the default for both filter fields when values are not provided, ensuring consistent connection ID generation regardless of whether filters are explicitly set.
