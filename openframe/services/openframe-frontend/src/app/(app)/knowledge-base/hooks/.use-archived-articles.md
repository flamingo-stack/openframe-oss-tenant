Custom Relay hook that manages the client-side connection ID for archived knowledge base articles, enabling filtered pagination via Relay's `ConnectionHandler`.

## Key Components

- **`ARCHIVED_ARTICLES_CONNECTION_KEY`** — Constant string key identifying the archived articles Relay connection (`knowledgeBaseTable_archivedArticles`)
- **`ArchivedArticlesConnectionFilter`** — Interface defining filter parameters (`search`, `tagIds`) for the connection
- **`getArchivedArticlesConnectionId`** — Function that generates a stable Relay connection ID from the root client record and the provided filters

## Usage Example

```typescript
import {
  getArchivedArticlesConnectionId,
  ArchivedArticlesConnectionFilter,
} from './use-archived-articles';

const filter: ArchivedArticlesConnectionFilter = {
  search: 'network setup',
  tagIds: ['tag-1', 'tag-2'],
};

const connectionId = getArchivedArticlesConnectionId(filter);
// Returns a Relay connection ID scoped to 'client:root'
// with the given search/tagIds filters applied

// Use in a Relay mutation to append/delete edges
const updater = (store) => {
  const connection = store.get(connectionId);
  // manipulate edges...
};
```

> The returned connection ID is deterministic — passing the same filter values always produces the same ID, making it safe to use in Relay store updaters and optimistic responses.
