Fetches a single knowledge base item by ID using a Relay lazy-load query, returning full item details including author, tags, and attachments.

## Key Components

- **`knowledgeBaseItemQuery`** — GraphQL query fragment fetching all fields for a knowledge base item: metadata, content, author profile, tags, and attachments.
- **`KnowledgeBaseItemNode`** — Exported type representing the non-nullable shape of a single knowledge base item response.
- **`useKnowledgeBaseItem(id)`** — React hook that executes the query with a `store-and-network` fetch policy, ensuring cached data renders immediately while a fresh network request runs in the background.

## Usage Example

```typescript
import { useKnowledgeBaseItem } from './use-knowledge-base-item';

function KnowledgeBaseArticle({ id }: { id: string }) {
  const item = useKnowledgeBaseItem(id);

  if (!item) return null;

  return (
    <article>
      <h1>{item.name}</h1>
      <p>{item.summary}</p>
      <span>By {item.author?.firstName} {item.author?.lastName}</span>
    </article>
  );
}
```

> **Note:** This hook uses `useLazyLoadQuery`, which suspends rendering until data is available. Wrap consuming components in a `<Suspense>` boundary with an appropriate fallback.
