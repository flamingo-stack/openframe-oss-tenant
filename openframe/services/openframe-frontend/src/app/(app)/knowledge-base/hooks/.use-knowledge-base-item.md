Fetches a single knowledge base item by ID using a Relay lazy-load query, returning its full detail including metadata, author, tags, and attachments.

## Key Components

- **`knowledgeBaseItemQuery`** — GraphQL query fragment that retrieves a knowledge base item's full detail: content, summary, status, author profile, tags, and attachments
- **`KnowledgeBaseItemNode`** — Exported type alias derived from the generated query response, representing a non-nullable knowledge base item node
- **`useKnowledgeBaseItem(id)`** — React hook that executes the query with `store-and-network` fetch policy, ensuring cached data is shown immediately while a fresh network request runs in the background

## Usage Example

```typescript
import { useKnowledgeBaseItem } from './use-knowledge-base-item';

function KnowledgeBaseArticle({ id }: { id: string }) {
  const item = useKnowledgeBaseItem(id);

  if (!item) return null;

  return (
    <article>
      <h1>{item.name}</h1>
      <p>{item.summary}</p>
      <div dangerouslySetInnerHTML={{ __html: item.content ?? '' }} />
      <span>By {item.author?.firstName} {item.author?.lastName}</span>
    </article>
  );
}
```

> **Note:** This hook uses `useLazyLoadQuery`, so it must be rendered inside a Relay `<Suspense>` boundary. The `store-and-network` policy serves stale data instantly while revalidating in the background.
