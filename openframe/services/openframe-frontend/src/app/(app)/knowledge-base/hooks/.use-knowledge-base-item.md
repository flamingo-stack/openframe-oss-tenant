Fetches a single knowledge base item by ID using Relay's lazy-load query, returning full item details including metadata, author, tags, and attachments.

## Key Components

- **`knowledgeBaseItemQuery`** — GraphQL query that retrieves a knowledge base item by `id`, including fields: `type`, `name`, `parentId`, `slug`, `content`, `summary`, `status`, `publishedAt`, timestamps, `author` (with avatar), `tags`, and `attachments`
- **`KnowledgeBaseItemNode`** — Exported TypeScript type representing the non-nullable shape of the returned item, derived from the generated query response type
- **`useKnowledgeBaseItem(id)`** — React hook that executes the query with `store-and-network` fetch policy, serving cached data immediately while refreshing from the network in the background

## Usage Example

```typescript
import { useKnowledgeBaseItem } from './use-knowledge-base-item';

function ArticlePage({ id }: { id: string }) {
  const item = useKnowledgeBaseItem(id);

  if (!item) return null;

  return (
    <article>
      <h1>{item.name}</h1>
      <p>{item.summary}</p>
      <span>By {item.author?.firstName} {item.author?.lastName}</span>
    </article>
  );
}
```

## Notes

- Must be used within a Relay `<Suspense>` boundary, as `useLazyLoadQuery` suspends while fetching
- The `store-and-network` policy ensures fast renders from cache with background revalidation
- Returns `null` if no item matches the given `id`
