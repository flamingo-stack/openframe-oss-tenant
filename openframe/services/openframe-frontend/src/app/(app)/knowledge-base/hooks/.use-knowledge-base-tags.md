Provides React hooks for fetching and creating knowledge base article tags via GraphQL/Relay, with built-in toast notifications for error handling.

## Key Components

**`useKnowledgeBaseTags(options)`**
Fetches knowledge base tags using `useLazyLoadQuery` with `store-and-network` fetch policy.
- `folderId?: string | null` — filter tags by folder
- `archived?: boolean` — include archived tags

**`useCreateKnowledgeBaseTag()`**
Returns `{ createTag, isPending }` for creating a new tag scoped to `KNOWLEDGE_ARTICLE` entity type.
- `createTag(key, color?)` — returns a `Promise<{ id, key }>`, shows a destructive toast on failure
- `isPending` — reflects in-flight mutation state

**`KnowledgeBaseTag`** (exported type)
Single element type derived from the query response array.

**`knowledgeBaseTagsQuery`** (exported)
The raw Relay GraphQL query fragment, useful for cache invalidation or preloading.

## Usage Example

```typescript
// Fetch tags for a folder
function TagList({ folderId }: { folderId: string }) {
  const tags = useKnowledgeBaseTags({ folderId, archived: false });
  return tags.map(tag => <span key={tag.id}>{tag.key}</span>);
}

// Create a new tag
function CreateTagButton() {
  const { createTag, isPending } = useCreateKnowledgeBaseTag();

  const handleCreate = async () => {
    const { id, key } = await createTag('security', '#FF0000');
    console.log(`Created tag: ${key} (${id})`);
  };

  return (
    <button onClick={handleCreate} disabled={isPending}>
      Add Tag
    </button>
  );
}
```
