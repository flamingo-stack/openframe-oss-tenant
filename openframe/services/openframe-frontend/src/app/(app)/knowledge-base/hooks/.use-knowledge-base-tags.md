Provides React hooks for fetching and creating knowledge base tags via GraphQL (Relay), used within the Flamingo OpenFrame knowledge base module.

## Key Components

**`knowledgeBaseTagsQuery`** — GraphQL query that fetches tags filtered by optional `folderId` and `archived` status, returning `id`, `key`, `color`, and `description`.

**`KnowledgeBaseTag`** — Exported type representing a single tag entry derived from the query response.

**`useKnowledgeBaseTags(options?)`** — Hook that lazily loads knowledge base tags with `store-and-network` fetch policy.

| Option | Type | Description |
|--------|------|-------------|
| `folderId` | `string \| null` | Filter tags by folder |
| `archived` | `boolean` | Include archived tags |

**`useCreateKnowledgeBaseTag()`** — Hook that returns a `createTag` function and `isPending` flag. Commits a mutation to create a new `KNOWLEDGE_ARTICLE` tag and shows a destructive toast on failure.

## Usage Example

```typescript
// Fetching tags
function TagList({ folderId }: { folderId: string }) {
  const tags = useKnowledgeBaseTags({ folderId, archived: false });

  return (
    <ul>
      {tags.map(tag => (
        <li key={tag.id} style={{ color: tag.color ?? undefined }}>
          {tag.key}
        </li>
      ))}
    </ul>
  );
}

// Creating a tag
function CreateTagButton() {
  const { createTag, isPending } = useCreateKnowledgeBaseTag();

  const handleCreate = async () => {
    const { id, key } = await createTag('my-tag', '#FF5733');
    console.log('Created:', id, key);
  };

  return (
    <button onClick={handleCreate} disabled={isPending}>
      Create Tag
    </button>
  );
}
```
