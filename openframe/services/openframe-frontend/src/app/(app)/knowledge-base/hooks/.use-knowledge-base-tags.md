Provides React hooks for fetching and creating knowledge base tags via GraphQL/Relay in the Flamingo OpenFrame platform.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `knowledgeBaseTagsQuery` | GraphQL query | Fetches tags filtered by `folderId` and `archived` status |
| `KnowledgeBaseTag` | Type | Inferred type for a single knowledge base tag (`id`, `key`, `color`, `description`) |
| `useKnowledgeBaseTags` | Hook | Lazily loads knowledge base tags with `store-and-network` fetch policy |
| `useCreateKnowledgeBaseTag` | Hook | Returns a `createTag` function and `isPending` state for tag creation |

## Usage Example

```typescript
// Fetch tags for a specific folder
function TagList({ folderId }: { folderId: string }) {
  const tags = useKnowledgeBaseTags({ folderId, archived: false });

  return tags.map(tag => (
    <span key={tag.id} style={{ color: tag.color }}>{tag.key}</span>
  ));
}

// Create a new tag
function CreateTagForm() {
  const { createTag, isPending } = useCreateKnowledgeBaseTag();

  const handleSubmit = async () => {
    const { id, key } = await createTag('my-tag', '#ff5733');
    console.log('Created:', id, key);
  };

  return <button onClick={handleSubmit} disabled={isPending}>Create Tag</button>;
}
```

## Notes

- `useKnowledgeBaseTags` uses Relay's `useLazyLoadQuery` — must be rendered inside a Relay `<Suspense>` boundary.
- `useCreateKnowledgeBaseTag` automatically shows a destructive toast notification on mutation failure.
- Tags are scoped to `entityType: "KNOWLEDGE_ARTICLE"` on creation.
