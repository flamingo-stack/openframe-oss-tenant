Provides a React hook for unarchiving knowledge base articles via a GraphQL mutation, with Relay store connection management and toast error notifications.

## Key Components

- **`unarchiveArticleMutation`** — GraphQL mutation that calls `unarchiveArticle`, returning the updated article's `id`, `status`, `parentId`, and `updatedAt`
- **`UnarchiveArticleArgs`** — Interface defining mutation parameters including connection IDs for Relay store updates
- **`useUnarchiveArticle`** — Hook exposing `unarchiveArticle` (async function) and `isPending` (in-flight state)

### Relay Store Updater Logic

- Removes the article node from each connection in `removeFromConnections`
- Appends the unarchived article as a `KnowledgeBaseItemEdge` to each connection in `appendToConnections` (optional)

## Usage Example

```typescript
const { unarchiveArticle, isPending } = useUnarchiveArticle();

await unarchiveArticle({
  id: 'article-123',
  parentId: 'folder-456',
  removeFromConnections: [archivedConnectionId],
  appendToConnections: [activeConnectionId],
  onCompleted: () => console.log('Article restored'),
});
```

> On error, a destructive toast notification is displayed automatically. The returned promise rejects with the original error for additional handling upstream.
