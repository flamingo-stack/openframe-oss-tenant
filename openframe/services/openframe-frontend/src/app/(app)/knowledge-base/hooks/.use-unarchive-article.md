Provides a React hook for unarchiving knowledge base articles via a GraphQL mutation, with Relay store connection management and toast error notifications.

## Key Components

- **`unarchiveArticleMutation`** — GraphQL mutation that calls `unarchiveArticle`, returning the updated article's `id`, `status`, `parentId`, and `updatedAt`
- **`UnarchiveArticleArgs`** — Interface defining mutation arguments including connection arrays for Relay store updates
- **`useUnarchiveArticle()`** — Primary exported hook returning `unarchiveArticle` function and `isPending` state

## Usage Example

```typescript
const { unarchiveArticle, isPending } = useUnarchiveArticle();

await unarchiveArticle({
  id: 'article-123',
  parentId: 'folder-456',
  // Remove from archived articles connection
  removeFromConnections: [archivedConnectionId],
  // Append to active articles connection
  appendToConnections: [activeConnectionId],
  onCompleted: () => console.log('Article restored'),
});
```

## Relay Store Behavior

The hook's Relay `updater` performs two connection operations atomically:

1. **Removes** the article node from all `removeFromConnections` connection IDs
2. **Appends** the unarchived article as a `KnowledgeBaseItemEdge` to all `appendToConnections` connection IDs

On mutation error, a destructive toast notification is displayed via `useToast` and the returned `Promise` rejects with the error. On success, the optional `onCompleted` callback fires and the promise resolves.
