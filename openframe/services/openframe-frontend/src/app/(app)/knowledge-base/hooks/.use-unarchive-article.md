Provides a React hook for unarchiving knowledge base articles via a GraphQL mutation, with Relay connection management and toast error notifications.

## Key Components

- **`unarchiveArticleMutation`** — GraphQL mutation that calls `unarchiveArticle(id, parentId)` and returns the updated article's `id`, `status`, `parentId`, and `updatedAt`
- **`UnarchiveArticleArgs`** — Interface defining the hook's action parameters:
  - `id` / `parentId` — Article identifiers
  - `removeFromConnections` — Relay connection IDs to remove the article from (e.g. archived list)
  - `appendToConnections` — Optional Relay connection IDs to append the article to (e.g. active list)
  - `onCompleted` — Optional success callback
- **`useUnarchiveArticle()`** — Main exported hook returning `unarchiveArticle` (async action) and `isPending` (in-flight state)

## Usage Example

```typescript
const { unarchiveArticle, isPending } = useUnarchiveArticle();

await unarchiveArticle({
  id: article.id,
  parentId: article.parentId ?? null,
  removeFromConnections: [archivedConnectionId],
  appendToConnections: [activeConnectionId],
  onCompleted: () => console.log('Article restored'),
});
```

## Notes

- Returns a `Promise<void>`, making it safe to `await` in async handlers
- Relay store updates run optimistically: nodes are deleted from `removeFromConnections` and new `KnowledgeBaseItemEdge` edges are inserted into `appendToConnections`
- On error, displays a destructive toast via `useToast` and rejects the promise
