React hook for creating knowledge base folders via a GraphQL mutation, with optimistic Relay store updates and toast error notifications.

## Key Components

- **`createFolderMutation`** — GraphQL mutation that creates a folder and appends the new node to the connection using `@appendNode`
- **`CreateFolderArgs`** — Interface defining `name`, `parentId` (nullable), and `connections` (Relay connection IDs)
- **`useCreateFolder`** — Main hook export returning `createFolder` and `isPending`

## Usage Example

```typescript
import { useCreateFolder } from './use-create-folder';

function NewFolderButton({ connectionId }: { connectionId: string }) {
  const { createFolder, isPending } = useCreateFolder();

  const handleCreate = async () => {
    const { id } = await createFolder({
      name: 'My New Folder',
      parentId: null,       // null for root-level folder
      connections: [connectionId],
    });
    console.log('Created folder:', id);
  };

  return (
    <button onClick={handleCreate} disabled={isPending}>
      New Folder
    </button>
  );
}
```

## Behavior Notes

- Returns a `Promise<{ id: string }>` — resolves with the new folder's ID on success, rejects on error
- **Relay store updater** manually deduplicates the created folder against `KNOWLEDGE_BASE_FOLDER_TREE_FIELD` before appending, preventing duplicate entries alongside the `@appendNode` directive
- On mutation error, displays a destructive toast notification before rejecting the promise
- `isPending` reflects Relay's in-flight state, useful for disabling UI during submission
