React hook that creates a knowledge base folder via a GraphQL mutation, with optimistic Relay store updates and toast error notifications.

## Key Components

- **`createFolderMutation`** — GraphQL mutation using `@appendNode` to insert the new folder directly into the Relay connection
- **`CreateFolderArgs`** — Input interface with `name`, `parentId` (nullable), and `connections` (Relay connection IDs)
- **`useCreateFolder`** — Main hook exposing `createFolder` and `isPending`

## Usage Example

```typescript
import { useCreateFolder } from './use-create-folder';

function NewFolderButton({ connectionId }: { connectionId: string }) {
  const { createFolder, isPending } = useCreateFolder();

  const handleCreate = async () => {
    const { id } = await createFolder({
      name: 'My New Folder',
      parentId: null,        // null = root-level folder
      connections: [connectionId],
    });
    console.log('Created folder:', id);
  };

  return (
    <button onClick={handleCreate} disabled={isPending}>
      Create Folder
    </button>
  );
}
```

## Relay Store Updater

After mutation, the updater manually appends the new folder record to `KNOWLEDGE_BASE_FOLDER_TREE_FIELD` on the root store, guarding against duplicates by checking `getDataID()` before insertion. This keeps the folder tree in sync without a full refetch.

## Returns

| Property | Type | Description |
|---|---|---|
| `createFolder` | `(args: CreateFolderArgs) => Promise<{ id: string }>` | Executes the mutation |
| `isPending` | `boolean` | `true` while the mutation is in-flight |
