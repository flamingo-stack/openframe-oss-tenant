React hook that executes a GraphQL mutation to create a new folder in the Knowledge Base, handling Relay store updates and error notifications.

## Key Components

- **`createFolderMutation`** — GraphQL mutation using `@appendNode` to optimistically insert the new folder into the Relay connection
- **`useCreateFolder`** — Main exported hook returning `createFolder` and `isPending`
- **`createFolder(args)`** — Promise-based function that commits the mutation and manually deduplicates entries in the `KNOWLEDGE_BASE_FOLDER_TREE_FIELD` linked records
- **Relay `updater`** — Syncs the flat folder tree field alongside the connection-based append to keep both data shapes consistent

## Usage Example

```typescript
import { useCreateFolder } from './use-create-folder';

function NewFolderButton({ parentId, connectionId }: Props) {
  const { createFolder, isPending } = useCreateFolder();

  const handleCreate = async () => {
    try {
      const { id } = await createFolder({
        name: 'My New Folder',
        parentId,            // null for root-level folder
        connections: [connectionId],
      });
      console.log('Created folder with id:', id);
    } catch (err) {
      // toast notification is already shown by the hook on error
    }
  };

  return (
    <button onClick={handleCreate} disabled={isPending}>
      New Folder
    </button>
  );
}
```

## Notes

- `isPending` reflects Relay's `isInFlight` state — useful for disabling UI during the request
- On error, a destructive toast is automatically displayed via `useToast`; the promise also rejects, allowing callers to handle errors additionally if needed
- The `updater` guards against duplicate records by checking `getDataID()` before appending to `KNOWLEDGE_BASE_FOLDER_TREE_FIELD`
