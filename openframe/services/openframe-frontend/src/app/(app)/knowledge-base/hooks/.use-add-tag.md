A React hook that adds a tag to a knowledge base item via a GraphQL mutation, with built-in error toast notification.

## Key Components

- **`addTagMutation`** — GraphQL mutation that calls `addTagToKnowledgeBaseItem`, returning the updated item's `id` and `tags` (id, key, color)
- **`useAddTag()`** — Hook exposing:
  - `addTag(itemId, tagId)` — Returns a `Promise<void>` that resolves on success or rejects (with a destructive toast) on error
  - `isPending` — Boolean reflecting whether the mutation is in-flight

## Usage Example

```typescript
import { useAddTag } from './use-add-tag';

function TagSelector({ itemId }: { itemId: string }) {
  const { addTag, isPending } = useAddTag();

  const handleTagSelect = async (tagId: string) => {
    await addTag(itemId, tagId);
  };

  return (
    <button disabled={isPending} onClick={() => handleTagSelect('tag-123')}>
      {isPending ? 'Adding...' : 'Add Tag'}
    </button>
  );
}
```

## Notes

- Uses **Relay** (`useMutation`) for GraphQL transport
- Error handling surfaces user-friendly messages via `useToast` with a `destructive` variant
- `addTag` is memoized with `useCallback` to avoid unnecessary re-renders
