A React hook that adds a tag to a Knowledge Base item via a GraphQL mutation, with built-in error toast notification.

## Key Components

- **`addTagMutation`** — Relay GraphQL mutation that calls `addTagToKnowledgeBaseItem`, returning the updated item's `id` and `tags` (with `id`, `key`, `color`)
- **`useAddTag()`** — Custom hook exposing:
  - `addTag(itemId, tagId)` — Returns a `Promise<void>` that resolves on success or rejects (and shows a destructive toast) on error
  - `isPending` — Boolean reflecting the in-flight mutation state

## Usage Example

```typescript
import { useAddTag } from './use-add-tag';

function TagSelector({ itemId }: { itemId: string }) {
  const { addTag, isPending } = useAddTag();

  const handleAddTag = async (tagId: string) => {
    try {
      await addTag(itemId, tagId);
      console.log('Tag added successfully');
    } catch {
      // Toast notification is handled internally by the hook
    }
  };

  return (
    <button disabled={isPending} onClick={() => handleAddTag('tag-123')}>
      {isPending ? 'Adding...' : 'Add Tag'}
    </button>
  );
}
```
