React hook for deleting a knowledge base folder via a GraphQL mutation, with optimistic Relay store cleanup for both connection-based lists and the folder tree.

## Key Components

- **`deleteFolderMutation`** — GraphQL mutation accepting a `DeleteFolderInput` (id, childrenAction, optional moveTargetFolderId)
- **`FolderChildrenAction`** — Union type `'MOVE' | 'ARCHIVE'` controlling what happens to child items on deletion
- **`DeleteFolderArgs`** — Input interface with folder `id`, `childrenAction`, optional `moveTargetFolderId`, Relay `connections` array, and optional `onCompleted` callback
- **`useDeleteFolder()`** — Primary export; returns `deleteFolder` executor and `isPending` boolean

## Behavior

The Relay `updater` performs two store operations after mutation:
1. Removes the deleted node from each provided Relay connection ID using `ConnectionHandler.deleteNode`
2. Filters the deleted folder from the flat `KNOWLEDGE_BASE_FOLDER_TREE_FIELD` linked record list on the root

`moveTargetFolderId` is only forwarded to the mutation when `childrenAction === 'MOVE'`; otherwise it is sent as `null`.

On error, a destructive toast notification is shown with the error message.

## Usage Example

```typescript
import { useDeleteFolder } from './use-delete-folder';

function FolderActions({ folderId, connectionId }) {
  const { deleteFolder, isPending } = useDeleteFolder();

  const handleDelete = () => {
    deleteFolder({
      id: folderId,
      childrenAction: 'MOVE',
      moveTargetFolderId: 'folder-parent-id',
      connections: [connectionId],
      onCompleted: () => console.log('Folder deleted'),
    });
  };

  return (
    <button onClick={handleDelete} disabled={isPending}>
      Delete Folder
    </button>
  );
}
```
