React hook that executes a GraphQL mutation to delete a knowledge base folder, with optimistic Relay store updates and error toast notifications.

## Key Components

- **`deleteFolderMutation`** — GraphQL mutation accepting a `DeleteFolderInput` that calls `deleteFolder` on the server
- **`FolderChildrenAction`** — Union type `'MOVE' | 'ARCHIVE'` controlling how child items are handled before deletion
- **`DeleteFolderArgs`** — Interface defining the hook's delete parameters
- **`useDeleteFolder`** — Main hook returning `deleteFolder` callback and `isPending` loading state

### Relay Store Updater

After a successful mutation, the updater performs two cleanup operations:
1. Removes the deleted folder node from all provided Relay connection IDs
2. Filters the folder out of the `KNOWLEDGE_BASE_FOLDER_TREE_FIELD` linked records on the root store

## Usage Example

```typescript
import { useDeleteFolder } from './use-delete-folder';

function FolderDeleteButton({ folderId, connectionIds }) {
  const { deleteFolder, isPending } = useDeleteFolder();

  const handleDelete = () => {
    deleteFolder({
      id: folderId,
      childrenAction: 'MOVE',
      moveTargetFolderId: 'target-folder-id',
      connections: connectionIds,
      onCompleted: () => console.log('Folder deleted'),
    });
  };

  return (
    <button onClick={handleDelete} disabled={isPending}>
      {isPending ? 'Deleting...' : 'Delete Folder'}
    </button>
  );
}
```

> When `childrenAction` is `'ARCHIVE'`, `moveTargetFolderId` is automatically coerced to `null` regardless of the value passed in.
