A React hook that unpublishes a knowledge base article via a GraphQL mutation, with built-in loading state and error toast notifications.

## Key Components

- **`unpublishArticleMutation`** — Relay GraphQL mutation that calls `unpublishArticle(id)` and returns updated `id`, `status`, `publishedAt`, and `updatedAt` fields
- **`useUnpublishArticle()`** — Hook exposing:
  - `unpublishArticle(id)` — Returns a `Promise<void>` that resolves on success or rejects with the error after showing a destructive toast
  - `isPending` — Boolean indicating whether the mutation is in-flight

## Usage Example

```typescript
import { useUnpublishArticle } from './use-unpublish-article';

function ArticleActions({ articleId }: { articleId: string }) {
  const { unpublishArticle, isPending } = useUnpublishArticle();

  const handleUnpublish = async () => {
    try {
      await unpublishArticle(articleId);
      console.log('Article unpublished successfully');
    } catch (err) {
      // Toast is shown automatically; handle additional logic here if needed
    }
  };

  return (
    <button onClick={handleUnpublish} disabled={isPending}>
      {isPending ? 'Unpublishing...' : 'Unpublish'}
    </button>
  );
}
```

> On error, a destructive toast is automatically displayed with the message `'Unpublish failed'` and the underlying error description before the promise rejects.
