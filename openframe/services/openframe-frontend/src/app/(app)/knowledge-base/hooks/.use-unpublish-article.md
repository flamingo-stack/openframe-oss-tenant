A React hook that unpublishes a knowledge base article via a GraphQL mutation, returning a promise-based handler with toast error notifications.

## Key Components

- **`unpublishArticleMutation`** — Relay GraphQL mutation that calls `unpublishArticle(id)` and returns the updated `id`, `status`, `publishedAt`, and `updatedAt` fields
- **`useUnpublishArticle()`** — Custom hook exposing:
  - `unpublishArticle(id)` — Triggers the mutation, returns a `Promise<void>` that resolves on success or rejects on error
  - `isPending` — Boolean reflecting the in-flight mutation state

## Usage Example

```typescript
import { useUnpublishArticle } from './use-unpublish-article';

function ArticleActions({ articleId }: { articleId: string }) {
  const { unpublishArticle, isPending } = useUnpublishArticle();

  const handleUnpublish = async () => {
    try {
      await unpublishArticle(articleId);
      console.log('Article unpublished successfully');
    } catch (err) {
      // Error toast is shown automatically by the hook
    }
  };

  return (
    <button onClick={handleUnpublish} disabled={isPending}>
      {isPending ? 'Unpublishing...' : 'Unpublish'}
    </button>
  );
}
```

> On error, a destructive toast notification is automatically displayed with the error message — no additional error handling UI is required at the call site.
