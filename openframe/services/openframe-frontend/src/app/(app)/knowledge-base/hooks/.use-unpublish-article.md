A React hook that provides article unpublishing functionality via a Relay GraphQL mutation, with built-in error toast notifications.

## Key Components

- **`unpublishArticleMutation`** — GraphQL mutation that sets an article's status to unpublished and returns updated `id`, `status`, `publishedAt`, and `updatedAt` fields.
- **`useUnpublishArticle()`** — Custom hook exposing a `unpublishArticle(id)` function and an `isPending` loading state flag.

## Usage Example

```typescript
import { useUnpublishArticle } from './use-unpublish-article';

function ArticleActions({ articleId }: { articleId: string }) {
  const { unpublishArticle, isPending } = useUnpublishArticle();

  const handleUnpublish = async () => {
    try {
      await unpublishArticle(articleId);
      console.log('Article unpublished successfully');
    } catch (err) {
      // Error toast is shown automatically
    }
  };

  return (
    <button onClick={handleUnpublish} disabled={isPending}>
      {isPending ? 'Unpublishing...' : 'Unpublish'}
    </button>
  );
}
```

## Behaviour Notes

- Returns a `Promise<void>` — callers can `await` and chain logic on success.
- On error, automatically triggers a **destructive toast** with the error message; the promise also rejects so callers can handle it further if needed.
- `isPending` mirrors Relay's `isInFlight` flag, useful for disabling UI controls during the in-flight request.
