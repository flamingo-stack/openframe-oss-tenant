A React hook that links temporary file attachments to a knowledge base article via a GraphQL mutation.

## Key Components

- **`linkArticleAttachmentsMutation`** — GraphQL mutation (`linkKnowledgeBaseTempAttachmentsToArticle`) that promotes temp attachments to permanent article attachments, returning metadata (`id`, `fileName`, `fileSize`, `contentType`, `createdAt`)
- **`LinkInput`** — Input interface with `articleId` (target article) and `tempIds` (array of temporary attachment IDs to link)
- **`useLinkArticleAttachments()`** — Hook exposing a promise-based `linkAttachments` function and an `isPending` loading flag

## Usage Example

```typescript
import { useLinkArticleAttachments } from './use-link-article-attachments';

function ArticleEditor({ articleId }: { articleId: string }) {
  const { linkAttachments, isPending } = useLinkArticleAttachments();

  const handleSave = async (tempIds: string[]) => {
    try {
      await linkAttachments({ articleId, tempIds });
      console.log('Attachments linked successfully');
    } catch (error) {
      console.error('Failed to link attachments:', error);
    }
  };

  return (
    <button disabled={isPending} onClick={() => handleSave(['tmp-1', 'tmp-2'])}>
      {isPending ? 'Saving...' : 'Save Article'}
    </button>
  );
}
```

> **Note:** This hook follows a two-phase upload pattern — files are first uploaded as temporary attachments, then permanently linked to an article using this hook. The `isPending` flag reflects in-flight mutation state for UI feedback.
