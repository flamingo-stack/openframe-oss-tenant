A React hook that links temporary file attachments to a knowledge base article via a GraphQL mutation.

## Key Components

- **`linkArticleAttachmentsMutation`** — GraphQL mutation (`linkKnowledgeBaseTempAttachmentsToArticle`) that promotes temp attachments to a permanent article, returning metadata (`id`, `fileName`, `fileSize`, `contentType`, `createdAt`)
- **`LinkInput`** — Interface defining `articleId` (target article) and `tempIds` (array of temporary attachment IDs to link)
- **`useLinkArticleAttachments()`** — Main exported hook returning:
  - `linkAttachments(input)` — Promise-based function that commits the mutation and rejects on GraphQL or network errors
  - `isPending` — Boolean reflecting in-flight mutation state

## Usage Example

```typescript
import { useLinkArticleAttachments } from './use-link-article-attachments';

function ArticleEditor({ articleId }: { articleId: string }) {
  const { linkAttachments, isPending } = useLinkArticleAttachments();

  const handleSave = async (tempIds: string[]) => {
    try {
      await linkAttachments({ articleId, tempIds });
      console.log('Attachments linked successfully');
    } catch (error) {
      console.error('Failed to link attachments:', error);
    }
  };

  return (
    <button onClick={() => handleSave(['temp-1', 'temp-2'])} disabled={isPending}>
      {isPending ? 'Saving...' : 'Save Attachments'}
    </button>
  );
}
```

> **Note:** This hook follows a two-phase upload pattern — files are first uploaded as temporary attachments, then permanently associated with an article via this hook.
