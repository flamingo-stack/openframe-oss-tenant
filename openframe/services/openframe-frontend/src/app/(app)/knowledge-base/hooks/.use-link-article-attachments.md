React hook that links temporary file attachments to a knowledge base article via a GraphQL mutation.

## Key Components

- **`linkArticleAttachmentsMutation`** — GraphQL mutation (`linkKnowledgeBaseTempAttachmentsToArticle`) that promotes temp attachments to permanent article attachments, returning metadata (`id`, `fileName`, `fileSize`, `contentType`, `createdAt`)
- **`LinkInput`** — Input interface requiring `articleId` (target article) and `tempIds` (array of temporary attachment IDs to link)
- **`useLinkArticleAttachments()`** — Hook exposing `linkAttachments` (async function) and `isPending` (in-flight state boolean)

## Usage Example

```typescript
import { useLinkArticleAttachments } from './use-link-article-attachments';

function ArticleEditor({ articleId }: { articleId: string }) {
  const { linkAttachments, isPending } = useLinkArticleAttachments();

  const handleSave = async (tempIds: string[]) => {
    try {
      await linkAttachments({ articleId, tempIds });
      console.log('Attachments linked successfully');
    } catch (error) {
      console.error('Failed to link attachments:', error);
    }
  };

  return (
    <button disabled={isPending} onClick={() => handleSave(['temp-1', 'temp-2'])}>
      {isPending ? 'Saving...' : 'Save Attachments'}
    </button>
  );
}
```

## Notes

- Returns a `Promise<void>` — GraphQL-level errors are normalized into rejected promises for consistent `try/catch` handling
- Follows a **temp-to-permanent** attachment pattern: files are uploaded as temporary assets first, then linked to an article on save
