Provides a React hook for creating knowledge base articles via a GraphQL mutation, with built-in loading state and error toast notifications.

## Key Components

- **`createArticleMutation`** — Relay GraphQL mutation that appends the new article node to specified Relay connections using `@appendNode`
- **`useCreateArticle()`** — Custom hook returning `createArticle` and `isPending`
- **`createArticle(args)`** — Async function (returns a `Promise<{ id: string }>`) that commits the mutation
- **`isPending`** — Boolean reflecting the in-flight mutation state

## Usage Example

```typescript
import { useCreateArticle } from './use-create-article';

function CreateArticleButton({ connectionId }: { connectionId: string }) {
  const { createArticle, isPending } = useCreateArticle();

  const handleCreate = async () => {
    const { id } = await createArticle({
      input: {
        name: 'New Article',
        content: '## Hello World',
        status: 'DRAFT',
      },
      connections: [connectionId],
    });

    console.log('Created article:', id);
  };

  return (
    <button onClick={handleCreate} disabled={isPending}>
      {isPending ? 'Creating...' : 'Create Article'}
    </button>
  );
}
```

## Behavior Notes

- On **success**, resolves with `{ id }` of the newly created article
- On **error**, fires a destructive toast notification and rejects the promise
- The `connections` array tells Relay which paginated lists to automatically update with the new node — no manual cache invalidation needed
