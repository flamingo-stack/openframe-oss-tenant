React hook that executes a GraphQL mutation to create a new knowledge base article, with built-in loading state and error toast notifications.

## Key Components

- **`createArticleMutation`** — Relay GraphQL mutation that calls `createArticle`, appending the new node to a connection via `@appendNode` with edge type `KnowledgeBaseItemEdge`
- **`useCreateArticle()`** — Custom hook exposing a `createArticle` function and `isPending` state
- **`CreateArticleArgs`** — Input interface requiring a `CreateArticleInput` payload and `connections` array (Relay connection IDs for cache updates)

## Usage Example

```typescript
import { useCreateArticle } from './use-create-article';

function CreateArticleButton({ connectionId }: { connectionId: string }) {
  const { createArticle, isPending } = useCreateArticle();

  const handleCreate = async () => {
    const article = await createArticle({
      input: {
        name: 'New Article',
        content: 'Article body...',
        status: 'DRAFT',
      },
      connections: [connectionId],
    });

    console.log('Created article ID:', article.id);
  };

  return (
    <button onClick={handleCreate} disabled={isPending}>
      {isPending ? 'Creating...' : 'Create Article'}
    </button>
  );
}
```

## Behavior Notes

- Returns a `Promise<{ id: string }>` — resolves with the new article's ID on success, rejects on error
- On mutation error, automatically fires a destructive toast via `useToast` before rejecting
- Rejects with a generic `Error` if the mutation completes but returns no data
- `isPending` reflects Relay's in-flight state, useful for disabling UI during submission
