Wraps a Relay GraphQL mutation for creating knowledge base articles, exposing a promise-based `createArticle` function with built-in error toasting.

## Key Components

- **`createArticleMutation`** — GraphQL mutation that creates an article and appends it to a Relay connection via `@appendNode`, returning full article fields including author and tags.
- **`useCreateArticle()`** — Custom hook that returns:
  - `createArticle({ input, connections })` — Executes the mutation; resolves with `{ id }` on success or rejects on failure.
  - `isPending` — Boolean reflecting in-flight mutation state.

## Usage Example

```typescript
import { useCreateArticle } from './use-create-article';

function NewArticleButton({ connectionId }: { connectionId: string }) {
  const { createArticle, isPending } = useCreateArticle();

  const handleCreate = async () => {
    try {
      const { id } = await createArticle({
        input: {
          name: 'Getting Started',
          content: '...',
          status: 'DRAFT',
        },
        connections: [connectionId],
      });
      console.log('Created article:', id);
    } catch (err) {
      // Toast is shown automatically; handle navigation or cleanup here
    }
  };

  return (
    <button onClick={handleCreate} disabled={isPending}>
      {isPending ? 'Creating...' : 'New Article'}
    </button>
  );
}
```

> **Note:** `connections` must be valid Relay connection IDs. The mutation uses `@appendNode` with `edgeTypeName: "KnowledgeBaseItemEdge"` to update the store optimistically without a refetch.
