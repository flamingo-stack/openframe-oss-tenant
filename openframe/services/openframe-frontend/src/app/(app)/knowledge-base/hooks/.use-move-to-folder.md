Relay mutation hook that moves a knowledge base item to a different folder, managing optimistic Relay store updates for connection removal and insertion.

## Key Components

- **`moveToFolderMutation`** — GraphQL mutation updating `id`, `parentId`, and `updatedAt` on the moved item
- **`MoveToFolderArgs`** — Input interface controlling the move operation:
  - `id` — Item to move
  - `parentId` — Destination folder (`null` for root)
  - `removeFromConnections` — Relay connection IDs to remove the item from
  - `appendToConnections` — Optional Relay connection IDs to insert the item into
  - `onCompleted` — Optional success callback
- **`useMoveToFolder()`** — Returns `moveToFolder(args)` (Promise) and `isPending` (boolean)

## Usage Example

```typescript
const { moveToFolder, isPending } = useMoveToFolder();

await moveToFolder({
  id: 'item-123',
  parentId: 'folder-456',          // null to move to root
  removeFromConnections: [currentConnectionId],
  appendToConnections: [targetConnectionId],
  onCompleted: () => console.log('Moved successfully'),
});
```

## Notes

- Returns a `Promise<void>` — callers can `await` or chain `.then()/.catch()`
- On error, displays a destructive toast via `useToast` and rejects the promise
- Store updates use `ConnectionHandler.deleteNode` for removal and `ConnectionHandler.insertEdgeAfter` for insertion, creating edges typed as `KnowledgeBaseItemEdge`
