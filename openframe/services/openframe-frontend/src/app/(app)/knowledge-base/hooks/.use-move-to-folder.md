Provides a React hook for moving knowledge base items between folders via a GraphQL mutation, with optimistic Relay store updates and toast error handling.

## Key Components

- **`moveToFolderMutation`** — GraphQL mutation that accepts an item `id` and optional `parentId`, returning the updated item's `id`, `parentId`, and `updatedAt`
- **`MoveToFolderArgs`** — Interface defining the hook's move operation parameters:
  - `id` — ID of the item to move
  - `parentId` — Target folder ID, or `null` to move to root
  - `removeFromConnections` — Relay connection IDs from which the item should be removed
  - `appendToConnections` — Optional Relay connection IDs where the item should be appended after moving
  - `onCompleted` — Optional callback fired on success
- **`useMoveToFolder`** — Main exported hook returning `moveToFolder` (async function) and `isPending` (in-flight state)

## Usage Example

```typescript
const { moveToFolder, isPending } = useMoveToFolder();

await moveToFolder({
  id: 'item-123',
  parentId: 'folder-456',
  removeFromConnections: [sourceConnectionId],
  appendToConnections: [targetConnectionId],
  onCompleted: () => console.log('Moved successfully'),
});
```

The hook manually updates the Relay store via `ConnectionHandler` — deleting the node from source connections and inserting a new `KnowledgeBaseItemEdge` into target connections — ensuring the UI reflects the move immediately without a full refetch. Errors surface as a destructive toast notification and cause the returned `Promise` to reject.
