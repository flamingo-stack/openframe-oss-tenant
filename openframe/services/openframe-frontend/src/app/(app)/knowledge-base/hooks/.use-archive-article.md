A React hook that archives a knowledge base article via a GraphQL mutation, with Relay store updates to remove the article from specified connections and optionally prepend it to archive connections.

## Key Components

- **`archiveArticleMutation`** — GraphQL mutation returning the archived article's `id`, `status`, `parentId`, and `updatedAt`
- **`ArchiveArticleArgs`** — Interface defining the hook's arguments:
  - `id` — Article ID to archive
  - `removeFromConnections` — Relay connection IDs to remove the article from
  - `appendToConnections` — Optional connection IDs to prepend the archived article to (e.g. an "archived" list)
  - `onCompleted` — Optional callback fired on success
- **`archiveArticle`** — Memoized function returning a `Promise<void>`, commits the mutation and applies Relay store updates
- **`isPending`** — Boolean indicating the mutation is in-flight

## Usage Example

```typescript
import { useArchiveArticle } from './use-archive-article';

function ArticleActions({ articleId, activeConnectionId, archivedConnectionId }) {
  const { archiveArticle, isPending } = useArchiveArticle();

  const handleArchive = async () => {
    await archiveArticle({
      id: articleId,
      removeFromConnections: [activeConnectionId],
      appendToConnections: [archivedConnectionId],
      onCompleted: () => console.log('Article archived'),
    });
  };

  return (
    <button onClick={handleArchive} disabled={isPending}>
      {isPending ? 'Archiving...' : 'Archive'}
    </button>
  );
}
```

On error, a destructive toast notification is displayed automatically via `useToast`.
