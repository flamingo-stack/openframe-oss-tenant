A React hook that archives a knowledge base article via a GraphQL mutation, managing Relay store updates to remove the article from specified connections and optionally append it to archived connections.

## Key Components

- **`archiveArticleMutation`** — GraphQL mutation that sets an article's status to archived, returning `id`, `status`, `parentId`, and `updatedAt`
- **`ArchiveArticleArgs`** — Interface defining the hook's action parameters:
  - `id` — Article ID to archive
  - `removeFromConnections` — Relay connection IDs to remove the article from
  - `appendToConnections` — Optional Relay connection IDs to insert the archived article into
  - `onCompleted` — Optional callback fired on success
- **`useArchiveArticle()`** — Main exported hook returning `archiveArticle` (async action) and `isPending` (in-flight status)

## Usage Example

```typescript
const { archiveArticle, isPending } = useArchiveArticle();

await archiveArticle({
  id: articleId,
  removeFromConnections: [activeListConnectionId],
  appendToConnections: [archivedListConnectionId],
  onCompleted: () => {
    router.push('/knowledge-base');
  },
});
```

> On error, a destructive toast notification is automatically displayed with the failure message — no additional error handling is required at the call site.
