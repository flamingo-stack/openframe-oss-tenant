React hook that archives a knowledge base article via a GraphQL mutation, managing Relay store connection updates and error notifications.

## Key Components

- **`archiveArticleMutation`** — GraphQL mutation that archives an article by ID, returning its updated `status`, `parentId`, and `updatedAt` fields.
- **`ArchiveArticleArgs`** — Interface defining the hook's action arguments:
  - `id` — Article ID to archive.
  - `removeFromConnections` — Relay connection IDs from which the article node should be removed.
  - `appendToConnections` — *(optional)* Relay connection IDs where the archived article should be prepended.
  - `onCompleted` — *(optional)* Callback fired on successful mutation.
- **`useArchiveArticle`** — Primary export; returns `archiveArticle` (the action) and `isPending` (mutation in-flight state).

## Usage Example

```typescript
const { archiveArticle, isPending } = useArchiveArticle();

await archiveArticle({
  id: 'article-123',
  removeFromConnections: [activeListConnectionId],
  appendToConnections: [archivedListConnectionId],
  onCompleted: () => console.log('Article archived'),
});
```

## Relay Store Behavior

The `updater` function performs two connection operations atomically:

1. **Removes** the article node from each connection in `removeFromConnections`.
2. **Prepends** a new `KnowledgeBaseItemEdge` to each connection in `appendToConnections` using the returned `archiveArticle` root field.

On error, a destructive toast notification is displayed via `useToast` and the returned `Promise` rejects with the original error.
