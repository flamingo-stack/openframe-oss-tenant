Provides a React hook for removing a tag from a Knowledge Base item via a GraphQL mutation, with built-in error toast notifications.

## Key Components

- **`removeTagMutation`** — GraphQL mutation that calls `removeTagFromKnowledgeBaseItem`, returning the updated item's `id` and `tags` list
- **`useRemoveTag()`** — Custom hook exposing:
  - `removeTag(itemId, tagId)` — Returns a `Promise<void>` that commits the mutation and rejects with a destructive toast on failure
  - `isPending` — Boolean reflecting in-flight mutation state

## Usage Example

```typescript
import { useRemoveTag } from './use-remove-tag';

function TagBadge({ itemId, tagId }: { itemId: string; tagId: string }) {
  const { removeTag, isPending } = useRemoveTag();

  const handleRemove = async () => {
    await removeTag(itemId, tagId);
  };

  return (
    <button onClick={handleRemove} disabled={isPending}>
      Remove Tag
    </button>
  );
}
```
