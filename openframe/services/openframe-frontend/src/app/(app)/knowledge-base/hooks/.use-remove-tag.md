Provides a React hook for removing a tag from a Knowledge Base item via a GraphQL mutation, with built-in loading state and error toast notifications.

## Key Components

- **`removeTagMutation`** — GraphQL mutation that calls `removeTagFromKnowledgeBaseItem`, returning the updated item's `id` and `tags` array.
- **`useRemoveTag()`** — Custom hook exposing:
  - `removeTag(itemId, tagId)` — Returns a `Promise<void>` that resolves on success or rejects (and shows a destructive toast) on error.
  - `isPending` — Boolean reflecting the in-flight mutation state.

## Usage Example

```typescript
import { useRemoveTag } from './use-remove-tag';

function TagBadge({ itemId, tagId }: { itemId: string; tagId: string }) {
  const { removeTag, isPending } = useRemoveTag();

  const handleRemove = async () => {
    await removeTag(itemId, tagId);
  };

  return (
    <button onClick={handleRemove} disabled={isPending}>
      {isPending ? 'Removing...' : 'Remove Tag'}
    </button>
  );
}
```

## Notes

- Uses `react-relay` for mutation execution and optimistic in-flight tracking.
- On error, displays a toast via `useToast` from `@flamingo-stack/openframe-frontend-core` with the error message if available.
- The `removeTag` function is memoized with `useCallback` to avoid unnecessary re-renders.
