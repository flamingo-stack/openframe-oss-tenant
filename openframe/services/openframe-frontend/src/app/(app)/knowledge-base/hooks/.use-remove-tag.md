React hook for removing a tag from a knowledge base item via a GraphQL mutation, with built-in error toast notification.

## Key Components

- **`removeTagMutation`** — Relay GraphQL mutation that calls `removeTagFromKnowledgeBaseItem`, returning the updated item's `id` and `tags` array.
- **`useRemoveTag()`** — Custom hook exposing:
  - `removeTag(itemId, tagId)` — Returns a `Promise<void>` that commits the mutation and rejects with a destructive toast on failure.
  - `isPending` — Boolean reflecting the in-flight mutation state.

## Usage Example

```typescript
import { useRemoveTag } from './use-remove-tag';

function TagBadge({ itemId, tagId }: { itemId: string; tagId: string }) {
  const { removeTag, isPending } = useRemoveTag();

  const handleRemove = async () => {
    await removeTag(itemId, tagId);
  };

  return (
    <button onClick={handleRemove} disabled={isPending}>
      Remove Tag
    </button>
  );
}
```

> On error, a destructive toast is automatically displayed with the error message — no additional error handling required at the call site unless you need to act on the rejection.
