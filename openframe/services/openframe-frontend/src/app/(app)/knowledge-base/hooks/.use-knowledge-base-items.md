Relay-based hook and utilities for querying and managing knowledge base folder/article connections in the Flamingo platform.

## Key Components

### Connection Key Constants
- `KNOWLEDGE_BASE_FOLDERS_CONNECTION_KEY` — Relay connection key for folder listings
- `KNOWLEDGE_BASE_ARTICLES_CONNECTION_KEY` — Relay connection key for article listings
- `KNOWLEDGE_BASE_ARTICLES_SUBTREE_CONNECTION_KEY` — Relay connection key for full subtree article listings

### Connection ID Helpers
- `getKnowledgeBaseFoldersConnectionId(filter)` — Returns a stable Relay connection ID scoped to folders
- `getKnowledgeBaseArticlesConnectionId(filter)` — Returns a stable Relay connection ID scoped to articles
- `getKnowledgeBaseArticlesSubtreeConnectionId(filter)` — Returns a stable Relay connection ID for subtree traversal (type-agnostic)

### Hook
- `useKnowledgeBaseFolders()` — Relay lazy-load query hook returning a flat list of `FolderOption` nodes from `knowledgeBaseFolderTree`

### Tree Utilities
- `buildFolderTree(folders)` — Converts a flat `FolderOption[]` array into a nested `FolderTreeNode[]` tree, sorted alphabetically at each level

### Types
- `KnowledgeBaseItemsConnectionFilter` — Filter shape used for all connection ID generators (`parentId`, `search`, `tagIds`)
- `FolderOption` — Flat folder representation (`id`, `name`, `parentId`)
- `FolderTreeNode` — Recursive tree node extending `FolderOption` with `children`

## Usage Example

```typescript
import {
  useKnowledgeBaseFolders,
  buildFolderTree,
  getKnowledgeBaseFoldersConnectionId,
} from './use-knowledge-base-items';

// Fetch flat folder list and build a nested tree
function FolderTreeView() {
  const folders = useKnowledgeBaseFolders();
  const tree = buildFolderTree(folders);
  // tree is sorted alphabetically, nested by parentId
}

// Generate a stable Relay connection ID for cache operations
const connectionId = getKnowledgeBaseFoldersConnectionId({
  parentId: 'folder-123',
  search: 'onboarding',
  tagIds: ['tag-abc'],
});
```
