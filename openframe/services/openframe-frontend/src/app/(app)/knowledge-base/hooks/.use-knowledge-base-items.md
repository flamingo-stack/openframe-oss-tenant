Provides Relay-based utilities for fetching and managing knowledge base folder and article connections, including connection ID generators, a folder tree query hook, and a tree-building helper.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `KNOWLEDGE_BASE_FOLDERS_CONNECTION_KEY` | `string` | Relay connection key for folder pagination |
| `KNOWLEDGE_BASE_ARTICLES_CONNECTION_KEY` | `string` | Relay connection key for article pagination |
| `KNOWLEDGE_BASE_ARTICLES_SUBTREE_CONNECTION_KEY` | `string` | Relay connection key for subtree (mixed) pagination |
| `getKnowledgeBaseFoldersConnectionId` | `function` | Generates a Relay connection ID scoped to folders |
| `getKnowledgeBaseArticlesConnectionId` | `function` | Generates a Relay connection ID scoped to articles |
| `getKnowledgeBaseArticlesSubtreeConnectionId` | `function` | Generates a Relay connection ID for untyped subtree traversal |
| `useKnowledgeBaseFolders` | `hook` | Fetches the flat folder list via `useLazyLoadQuery` |
| `buildFolderTree` | `function` | Converts a flat `FolderOption[]` array into a nested `FolderTreeNode[]` tree, sorted alphabetically |
| `KnowledgeBaseItemsConnectionFilter` | `interface` | Filter shape used by all connection ID helpers |

## Usage Example

```typescript
import {
  useKnowledgeBaseFolders,
  buildFolderTree,
  getKnowledgeBaseFoldersConnectionId,
} from './use-knowledge-base-items';

// Fetch flat folder list and build a nested tree
function FolderTree() {
  const folders = useKnowledgeBaseFolders();
  const tree = buildFolderTree(folders);
  // tree is FolderTreeNode[] sorted alphabetically at every level
}

// Generate a stable Relay connection ID for cache operations
const connectionId = getKnowledgeBaseFoldersConnectionId({
  parentId: 'folder-123',
  search: 'onboarding',
  tagIds: ['tag-abc'],
});
```

> **Note:** `tagIds` is normalized — an empty array is treated as `null` to avoid cache key fragmentation across filtered and unfiltered queries.
