Provides Relay connection ID utilities, GraphQL queries, and tree-building helpers for managing knowledge base folders and articles.

## Key Components

**Constants**
- `KNOWLEDGE_BASE_FOLDERS_CONNECTION_KEY` — Relay connection key for folder listings
- `KNOWLEDGE_BASE_ARTICLES_CONNECTION_KEY` — Relay connection key for article listings
- `KNOWLEDGE_BASE_ARTICLES_SUBTREE_CONNECTION_KEY` — Relay connection key for full subtree article queries
- `KNOWLEDGE_BASE_ROOT_LABEL` — Display label for the root knowledge base node

**Connection ID Helpers**
- `getKnowledgeBaseFoldersConnectionId(filter)` — Computes Relay connection ID scoped to `type: FOLDER`
- `getKnowledgeBaseArticlesConnectionId(filter)` — Computes Relay connection ID scoped to `type: ARTICLE`
- `getKnowledgeBaseArticlesSubtreeConnectionId(filter)` — Computes Relay connection ID for all types (subtree traversal)

**Hook**
- `useKnowledgeBaseFolders()` — Lazy-loads the flat folder list via GraphQL (`store-or-network`)

**Utilities**
- `buildFolderTree(folders)` — Converts a flat `FolderOption[]` into a sorted nested `FolderTreeNode[]` hierarchy

## Usage Example

```typescript
import {
  useKnowledgeBaseFolders,
  buildFolderTree,
  getKnowledgeBaseArticlesConnectionId,
} from './use-knowledge-base-items';

// Fetch flat folder list and build a tree
function FolderTreeView() {
  const folders = useKnowledgeBaseFolders();
  const tree = buildFolderTree(folders);
  // tree is sorted, nested FolderTreeNode[]
}

// Compute a stable Relay connection ID for cache operations
const connectionId = getKnowledgeBaseArticlesConnectionId({
  parentId: 'folder-123',
  search: 'setup',
  tagIds: ['tag-abc'],
});
```
