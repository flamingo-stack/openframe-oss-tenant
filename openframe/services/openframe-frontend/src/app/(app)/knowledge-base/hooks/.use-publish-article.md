Custom React hook that publishes a knowledge base article via a GraphQL mutation, exposing a promise-based callback and loading state.

## Key Components

- **`publishArticleMutation`** — Relay GraphQL mutation that calls `publishArticle(id)` and returns the updated `id`, `status`, `publishedAt`, and `updatedAt` fields
- **`usePublishArticle()`** — Hook that wraps the mutation with toast error handling and returns a stable `publishArticle` callback plus an `isPending` flag

## Usage Example

```typescript
import { usePublishArticle } from './use-publish-article';

function ArticleActions({ articleId }: { articleId: string }) {
  const { publishArticle, isPending } = usePublishArticle();

  const handlePublish = async () => {
    try {
      await publishArticle(articleId);
      // Article is now published
    } catch (err) {
      // Error already surfaced via toast
    }
  };

  return (
    <button onClick={handlePublish} disabled={isPending}>
      {isPending ? 'Publishing...' : 'Publish'}
    </button>
  );
}
```

## Return Value

| Property | Type | Description |
|---|---|---|
| `publishArticle` | `(id: string) => Promise<void>` | Triggers the publish mutation for the given article ID |
| `isPending` | `boolean` | `true` while the mutation is in-flight |

## Notes

- On error, a destructive toast notification is automatically shown — callers only need to handle the rejected promise if additional side effects are required
- The `publishArticle` callback is memoized via `useCallback`, referencing `commit` and `toast` as dependencies
