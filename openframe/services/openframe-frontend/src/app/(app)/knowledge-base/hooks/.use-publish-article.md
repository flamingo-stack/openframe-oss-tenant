A React hook that triggers a GraphQL mutation to publish an article, handling loading state and error notifications.

## Key Components

- **`publishArticleMutation`** — Relay GraphQL mutation that calls `publishArticle(id)` and returns `id`, `status`, `publishedAt`, and `updatedAt`
- **`usePublishArticle()`** — Custom hook exposing a `publishArticle` function and an `isPending` flag

## Usage Example

```typescript
import { usePublishArticle } from './use-publish-article';

function ArticleActions({ articleId }: { articleId: string }) {
  const { publishArticle, isPending } = usePublishArticle();

  const handlePublish = async () => {
    try {
      await publishArticle(articleId);
      console.log('Article published successfully');
    } catch (err) {
      // Error toast is automatically shown by the hook
    }
  };

  return (
    <button onClick={handlePublish} disabled={isPending}>
      {isPending ? 'Publishing...' : 'Publish'}
    </button>
  );
}
```

## Behavior

| Scenario | Behavior |
|----------|----------|
| Mutation succeeds | Resolves the returned `Promise<void>` |
| Mutation fails | Shows a destructive toast and rejects the promise |
| In-flight | `isPending` is `true` |

## Returns

| Property | Type | Description |
|----------|------|-------------|
| `publishArticle` | `(id: string) => Promise<void>` | Triggers the publish mutation |
| `isPending` | `boolean` | `true` while the mutation is in flight |
