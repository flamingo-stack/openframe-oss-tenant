A React hook that handles publishing a knowledge base article via a GraphQL mutation, with built-in loading state and error toast notifications.

## Key Components

- **`publishArticleMutation`** — Relay GraphQL mutation that calls `publishArticle(id)`, returning the updated `id`, `status`, `publishedAt`, and `updatedAt` fields
- **`usePublishArticle()`** — Custom hook exposing:
  - `publishArticle(id)` — Returns a `Promise<void>` that resolves on success or rejects (with a destructive toast) on failure
  - `isPending` — Boolean indicating whether the mutation is in-flight

## Usage Example

```typescript
import { usePublishArticle } from './use-publish-article';

function ArticleActions({ articleId }: { articleId: string }) {
  const { publishArticle, isPending } = usePublishArticle();

  const handlePublish = async () => {
    try {
      await publishArticle(articleId);
      // Article is now published
    } catch {
      // Error already surfaced via toast
    }
  };

  return (
    <button onClick={handlePublish} disabled={isPending}>
      {isPending ? 'Publishing...' : 'Publish'}
    </button>
  );
}
```

> On error, a destructive toast is automatically shown with the error message — no additional error handling UI is required at the call site.
