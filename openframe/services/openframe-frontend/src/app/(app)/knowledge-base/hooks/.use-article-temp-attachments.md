Manages temporary file attachment state and lifecycle for knowledge base articles, handling upload, removal, and deletion of both new (temp) and existing attachments via GraphQL/Relay mutations.

## Key Components

### Types

- **`TempFileStatus`** — Union type: `'uploading' | 'uploaded' | 'error' | 'existing'`
- **`TempFileEntry`** — Shape of a tracked file entry including `id`, `fileName`, `fileSize`, `contentType`, `status`, and optional `error`

### Internal Helpers

- **`createTempAttachment(environment, file)`** — Creates a temp attachment record via GraphQL, then PUTs the file to the returned presigned URL
- **`deleteTempAttachment(environment, id)`** — Deletes a temp (unpublished) attachment record
- **`deleteKnowledgeBaseAttachment(environment, id)`** — Deletes a finalized knowledge base attachment

### Hook: `useArticleTempAttachments()`

| Return Value | Description |
|---|---|
| `files` | Current list of `TempFileEntry` objects |
| `uploadFile(file)` | Adds a placeholder entry, uploads, then updates status |
| `removeFile(id)` | Removes a file locally; defers deletion of `existing` entries |
| `initializeExisting(attachments)` | Seeds the list with already-saved attachments (deduped) |
| `getTempAttachmentIds()` | Returns IDs of successfully uploaded (non-pending) temp files |
| `deleteRemovedAttachments()` | Flushes pending deletes for removed `existing` attachments |
| `isUploading` | `true` if any file is in `uploading` state |
| `hasPendingDeletes` | `true` if any existing attachments are queued for deletion |
| `reset()` | Clears all file state |

## Usage Example

```typescript
const {
  files,
  uploadFile,
  removeFile,
  initializeExisting,
  isUploading,
  getTempAttachmentIds,
  deleteRemovedAttachments,
  reset,
} = useArticleTempAttachments();

// Seed with existing saved attachments (e.g., when editing an article)
initializeExisting(article.attachments);

// Upload a new file from an <input type="file"> change event
uploadFile(event.target.files[0]);

// Remove a file (temp or existing)
removeFile(fileId);

// On form submit: flush deferred deletes, then collect temp IDs for mutation
await deleteRemovedAttachments();
const tempIds = getTempAttachmentIds();
```
