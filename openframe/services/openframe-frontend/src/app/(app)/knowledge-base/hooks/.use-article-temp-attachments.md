Manages temporary file attachments for knowledge base articles, handling the full lifecycle of file uploads, deletions, and state tracking via Relay GraphQL mutations and direct S3-style PUT uploads.

## Key Components

### Types

- **`TempFileStatus`** — Union type: `'uploading' | 'uploaded' | 'error' | 'existing'`
- **`TempFileEntry`** — Shape of a tracked file entry including `id`, `fileName`, `fileSize`, `contentType`, `status`, and optional `error`

### GraphQL Mutations

| Mutation | Purpose |
|----------|---------|
| `createTempAttachmentMutation` | Creates a temp attachment record and returns a pre-signed upload URL |
| `deleteTempAttachmentMutation` | Deletes a temporary (not yet saved) attachment |
| `deleteAttachmentMutation` | Deletes a persisted knowledge base attachment |

### Hook: `useArticleTempAttachments`

Returns an object with the following members:

| Member | Type | Description |
|--------|------|-------------|
| `files` | `TempFileEntry[]` | Current list of tracked file entries |
| `uploadFile` | `(file: File) => void` | Initiates upload with optimistic placeholder entry |
| `removeFile` | `(id: string) => void` | Removes a file; defers deletion of `existing` entries |
| `initializeExisting` | `(attachments) => void` | Seeds state with already-persisted attachments |
| `getTempAttachmentIds` | `() => string[]` | Returns IDs of successfully uploaded temp files |
| `deleteRemovedAttachments` | `() => Promise<void>` | Flushes pending deletes for `existing` entries |
| `isUploading` | `boolean` | `true` if any file is in `uploading` state |
| `hasPendingDeletes` | `boolean` | `true` if existing attachments are queued for deletion |
| `reset` | `() => void` | Clears all file and delete state |

## Usage Example

```typescript
const {
  files,
  uploadFile,
  removeFile,
  initializeExisting,
  isUploading,
  getTempAttachmentIds,
  deleteRemovedAttachments,
  reset,
} = useArticleTempAttachments();

// Seed with existing saved attachments on edit
initializeExisting(article.attachments);

// Upload a new file from an input event
const handleFileChange = (e: React.ChangeEvent<HTMLInputElement>) => {
  const file = e.target.files?.[0];
  if (file) uploadFile(file);
};

// On form submit: delete removed attachments, then get temp IDs
const handleSubmit = async () => {
  await deleteRemovedAttachments();
  const tempIds = getTempAttachmentIds();
  // pass tempIds to article save mutation
};
```

> **Note:** Files marked `existing` are not immediately deleted on `removeFile`. Their deletion is deferred and executed in bulk via `deleteRemovedAttachments`, typically called on form submission.
