Manages temporary file attachment state for knowledge base articles, handling upload, removal, and lifecycle coordination via Relay GraphQL mutations and direct S3-style PUT uploads.

## Key Components

### Types
- **`TempFileStatus`** — Union type: `'uploading' | 'uploaded' | 'error' | 'existing'`
- **`TempFileEntry`** — Shape of a tracked file entry (id, fileName, fileSize, contentType, status, optional error)

### GraphQL Mutations
- **`createTempAttachmentMutation`** — Requests a presigned upload URL and creates a temp attachment record
- **`deleteTempAttachmentMutation`** — Removes a temporary (not-yet-committed) attachment
- **`deleteAttachmentMutation`** — Removes a persisted knowledge base attachment

### Hook: `useArticleTempAttachments()`

| Return Value | Description |
|---|---|
| `files` | Current list of `TempFileEntry` items |
| `uploadFile(file)` | Adds a placeholder, requests a presigned URL, then PUTs the file directly |
| `removeFile(id)` | Removes a file; defers deletion of `'existing'` attachments until `deleteRemovedAttachments()` |
| `initializeExisting(attachments)` | Seeds the list with already-saved attachments (deduped) |
| `getTempAttachmentIds()` | Returns IDs of successfully uploaded temp attachments |
| `deleteRemovedAttachments()` | Commits deferred deletions for `'existing'` attachments |
| `hasPendingDeletes` | `true` when deferred deletions are queued |
| `isUploading` | `true` while any file is in `'uploading'` state |
| `reset()` | Clears all state |

## Usage Example

```typescript
const {
  files,
  uploadFile,
  removeFile,
  initializeExisting,
  getTempAttachmentIds,
  deleteRemovedAttachments,
  isUploading,
  reset,
} = useArticleTempAttachments();

// Seed with existing saved attachments on edit
initializeExisting(article.attachments);

// Upload a new file from an input event
const handleFileChange = (e: React.ChangeEvent<HTMLInputElement>) => {
  const file = e.target.files?.[0];
  if (file) uploadFile(file);
};

// On form submit: commit deferred deletes, then pass temp IDs to mutation
const handleSubmit = async () => {
  await deleteRemovedAttachments();
  const tempIds = getTempAttachmentIds();
  await saveArticle({ tempAttachmentIds: tempIds });
  reset();
};
```
