A React hook that manages the create/edit form for knowledge base articles, handling validation, tag resolution, attachment management, assignment diffing, and publish/unpublish/archive state transitions.

## Key Components

- **`useEditArticleForm`** — Primary export; orchestrates the full article form lifecycle
- **`SaveStatus`** — Union type `'DRAFT' | 'PUBLISHED'` controlling target article state
- **`UseEditArticleFormOptions`** — Input options: `articleId`, `initialFolderId`, `initialArticle`
- **`handleSave`** — Submits the form, resolves/creates tags, applies assignment diffs, links attachments, and transitions publish state
- **`resolveTagIds`** — Resolves tag keys to IDs, creating new tags via the API if they don't exist
- **`tempAttachments`** — Manages staged file uploads and pending deletes before article persistence

## Usage Example

```typescript
const {
  form,
  isEditMode,
  isSubmitting,
  handleSave,
  tempAttachments,
} = useEditArticleForm({
  articleId: 'article-123',        // null for create mode
  initialFolderId: 'folder-456',
  initialArticle: existingArticle, // KnowledgeBaseItemNode or null
});

// Save as draft
handleSave('DRAFT', { availableTags: tagList });

// Publish directly
handleSave('PUBLISHED', { availableTags: tagList });
```

## Behavior Notes

- **Create mode**: `articleId = null` — creates article, links attachments, applies assignments, then redirects
- **Edit mode**: diffs tags (add/remove), applies assignment changes, deletes removed attachments, and handles `ARCHIVED → PUBLISHED/DRAFT` transitions
- Form validation errors are surfaced via toast with field-level messages
- After save, navigates back or replaces route with `/knowledge-base/details/:id`
