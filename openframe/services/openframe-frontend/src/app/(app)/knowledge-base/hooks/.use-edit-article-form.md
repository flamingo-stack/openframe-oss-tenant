Unified React hook for managing knowledge base article create/edit form state, handling validation, tag resolution, attachment management, assignment diffing, and publish/unpublish lifecycle.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `useEditArticleForm` | Hook | Main hook orchestrating the full article form lifecycle |
| `SaveStatus` | Type | `'DRAFT' \| 'PUBLISHED'` — target publish state on save |
| `UseEditArticleFormOptions` | Interface | Hook input: `articleId`, `initialFolderId`, `initialArticle` |

### Returned Values

| Property | Description |
|----------|-------------|
| `form` | `react-hook-form` instance with Zod validation via `articleFormSchema` |
| `isEditMode` | `true` when `articleId` is provided |
| `isSubmitting` | Submission in-progress flag |
| `handleSave` | Triggers validated save with a target `SaveStatus` |
| `tempAttachments` | Temporary attachment state manager |

## Usage Example

```typescript
const { form, isEditMode, isSubmitting, handleSave, tempAttachments } =
  useEditArticleForm({
    articleId: 'article-123',        // null for create mode
    initialFolderId: 'folder-456',
    initialArticle: existingArticle, // KnowledgeBaseItemNode | null
  });

// Save as draft
handleSave('DRAFT', { availableTags: tags });

// Publish
handleSave('PUBLISHED', { availableTags: tags });
```

## Behavior Notes

- **Create mode** (`articleId = null`): creates article, links attachments, applies assignments, then redirects to the new article's detail page.
- **Edit mode**: diffs tags (add/remove), diffs assignments, handles attachment deletes/links, and transitions article status (`DRAFT` → `PUBLISHED`, `ARCHIVED` → `PUBLISHED`, `PUBLISHED` → `DRAFT`) as needed.
- New tag keys not found in `availableTags` are created on-the-fly via `createTag` before save.
- Validation errors surface as a destructive toast listing all field messages.
