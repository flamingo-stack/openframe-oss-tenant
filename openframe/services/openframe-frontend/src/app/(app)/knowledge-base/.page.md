Entry point for the Knowledge Base page route, gating access behind a feature flag and rendering the root-level knowledge base view.

## Key Components

- **`KnowledgeBasePage`** — Default page component that checks the `knowledgeBase` feature flag; redirects to a 404 if disabled, otherwise renders `KnowledgeBaseView` at the root folder level (`folderId={null}`).
- **`featureFlags.knowledgeBase.enabled()`** — Runtime feature flag check controlling access to the Knowledge Base feature.
- **`KnowledgeBaseView`** — The primary view component receiving `folderId={null}` to represent the root folder context.
- **`dynamic = 'force-dynamic'`** — Disables Next.js static generation, ensuring the page is always server-rendered at request time.

## Usage Example

```typescript
// Automatically rendered by Next.js at the /knowledge-base route.
// No direct instantiation needed; the page is gated by the feature flag:

if (!featureFlags.knowledgeBase.enabled()) {
  notFound(); // Returns 404
}
// Otherwise renders:
<KnowledgeBaseView folderId={null} />
```

> **Note:** The `'use client'` directive marks this as a Client Component. Combined with `force-dynamic`, the page skips static caching and re-evaluates the feature flag on every render.
