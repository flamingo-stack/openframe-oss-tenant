Entry point for the Knowledge Base page route, gating access via a feature flag and rendering the root-level knowledge base view.

## Key Components

- **`KnowledgeBasePage`** — Default page component that checks the `knowledgeBase` feature flag; redirects to a 404 if disabled, otherwise renders `KnowledgeBaseView` at the root folder level (`folderId={null}`).
- **`featureFlags.knowledgeBase.enabled()`** — Runtime feature flag guard controlling visibility of the Knowledge Base feature.
- **`KnowledgeBaseView`** — The primary UI component for browsing knowledge base content, initialized with no specific folder context.
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered on each request.

## Usage Example

```typescript
// This page is automatically mounted at the /knowledge-base route.
// No direct instantiation needed — Next.js handles rendering.

// To enable the page, ensure the feature flag is active:
// featureFlags.knowledgeBase.enabled() === true

// The page renders the root folder view:
<KnowledgeBaseView folderId={null} />
```

> **Note:** Navigating to `/knowledge-base` while the `knowledgeBase` feature flag is disabled will result in a `404 Not Found` response.
