Renders the Knowledge Base **Archived Articles** page, providing tag-based and text search filtering over archived articles with a back-navigation button.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `ArchivePage` | `default` (React component) | Page component rendering the archived articles view |
| `dynamic` | `const` | Set to `'force-dynamic'` to disable static generation |

### Internal Dependencies

- **`useTagSearchState`** — Manages combined text search + tag filter state with debouncing
- **`ArchivedArticlesTable`** — Renders the filtered archived articles list
- **`KnowledgeBaseTagsRow`** — Tag selector row scoped to archived content (`archived` prop)
- **`useSafeBack`** — Navigates back, falling back to `/knowledge-base` if no history
- **`featureFlags.knowledgeBase.enabled()`** — Gates the page; returns `notFound()` if disabled

## Usage Example

```typescript
// Accessed via Next.js route, e.g. /knowledge-base/archive
// No props required — all state is managed internally

// Feature flag guard
if (!featureFlags.knowledgeBase.enabled()) {
  notFound(); // redirects to 404 if KB feature is off
}

// Filter state wired to both search input and tag row
const { search, debouncedSearch, tagIds, ...handlers } = useTagSearchState();

// debouncedSearch (not raw search) is passed to the table
// to avoid excessive re-fetches on every keystroke
<ArchivedArticlesTable
  search={debouncedSearch}
  tagIds={tagIds}
  emptyMessage={hasFilters ? 'No archived articles match your filters.' : 'No archived articles.'}
/>
```

> **Note:** The `dynamic = 'force-dynamic'` export ensures this page is always server-rendered at request time, which is required for feature flag evaluation and live data fetching.
