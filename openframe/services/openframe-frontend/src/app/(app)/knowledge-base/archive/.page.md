Renders the Knowledge Base Archive page, displaying a searchable, filterable table of archived articles with tag-based filtering support.

## Key Components

- **`ArchivePage`** — Default export; Next.js Client Component page for browsing archived knowledge base articles
- **`useSafeBack`** — Provides safe back-navigation fallback to `/knowledge-base`
- **`useTagSearchState`** — Manages combined text search and tag filter state with debouncing
- **`TagSearchInput`** — Search input with active tag chips and clear-all support
- **`KnowledgeBaseTagsRow`** — Horizontal tag selector row scoped to archived content (`archived` flag, `parentId={null}`)
- **`ArchivedArticlesTable`** — Table component consuming debounced search and tag filters
- **`featureFlags.knowledgeBase.enabled()`** — Guards the route; triggers `notFound()` if the feature is disabled

## Usage Example

```typescript
// Accessed via Next.js routing at /knowledge-base/archive
// No props required — all state is managed internally

// Feature flag guard
if (!featureFlags.knowledgeBase.enabled()) {
  notFound(); // Returns 404 if knowledge base feature is disabled
}

// Empty state message adapts based on active filters
const hasFilters = search.length > 0 || tagIds.length > 0;
const emptyMessage = hasFilters
  ? 'No archived articles match your filters.'
  : 'No archived articles.';
```

## Notes

- `dynamic = 'force-dynamic'` disables static generation, ensuring the page is always server-rendered at request time
- Tag filtering uses `parentId={null}` to load top-level tags only
- Search is debounced before being passed to the table to reduce unnecessary data fetches
