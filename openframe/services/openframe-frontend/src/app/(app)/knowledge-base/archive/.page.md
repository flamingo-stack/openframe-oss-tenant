Renders the Knowledge Base **Archived Articles** page, providing search, tag filtering, and a table of archived articles with feature-flag gating.

## Key Components

- **`ArchivePage`** — Default export; the Next.js page component for `/knowledge-base/archive`
- **`useTagSearchState`** — Manages search input, debounced search, and tag filter state
- **`useSafeBack`** — Provides safe back-navigation to `/knowledge-base`
- **`TagSearchInput`** — Controlled search input with tag chip display and clear support
- **`KnowledgeBaseTagsRow`** — Renders selectable tag filters scoped to archived articles
- **`ArchivedArticlesTable`** — Displays filtered archived articles; accepts `search`, `tagIds`, and `emptyMessage`
- **`featureFlags.knowledgeBase.enabled()`** — Guards the page; returns `notFound()` if the feature is disabled

## Usage Example

```typescript
// This is a Next.js App Router page — rendered automatically at:
// /knowledge-base/archive

// Feature flag must be enabled:
featureFlags.knowledgeBase.enabled(); // → true

// Active filters are derived from state:
const hasFilters = search.length > 0 || tagIds.length > 0;

// Empty state message adapts to filter context:
emptyMessage={hasFilters
  ? 'No archived articles match your filters.'
  : 'No archived articles.'
}
```

## Notes

- `dynamic = 'force-dynamic'` disables static caching, ensuring archived article data is always fresh
- Tag filtering uses `parentId={null}` to fetch top-level tags only
- Search is debounced before being passed to the table to reduce unnecessary fetches
