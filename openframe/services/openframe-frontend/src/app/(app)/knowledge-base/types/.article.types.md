Defines the Zod validation schema and TypeScript types for the article creation/editing form.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `articleFormSchema` | `z.ZodObject` | Zod schema with validation rules for article form fields |
| `ArticleFormData` | `type` | TypeScript type inferred from `articleFormSchema` |
| `ARTICLE_FORM_DEFAULTS` | `ArticleFormData` | Default values for initializing a blank article form |

## Schema Field Rules

| Field | Validation |
|-------|------------|
| `title` | Required string, 1–255 characters |
| `folderId` | Nullable string |
| `tags` | Array of strings, max 20 items |
| `body` | String, max 50,000 characters |
| `assignments` | Delegated to `assignmentsSchema` |

## Usage Example

```typescript
import { articleFormSchema, ARTICLE_FORM_DEFAULTS } from './article.types';

// Validate form data
const result = articleFormSchema.safeParse({
  title: 'Getting Started Guide',
  folderId: 'folder-123',
  tags: ['onboarding', 'setup'],
  body: 'Welcome to the platform...',
  assignments: ASSIGNMENTS_DEFAULT,
});

if (!result.success) {
  console.error(result.error.flatten());
}

// Initialize a form with defaults (e.g. react-hook-form)
const { register } = useForm<ArticleFormData>({
  defaultValues: ARTICLE_FORM_DEFAULTS,
});
```
