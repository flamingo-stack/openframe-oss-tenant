Defines the Zod validation schema and TypeScript types for the article creation/editing form.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `articleFormSchema` | `ZodObject` | Zod schema validating all article form fields |
| `ArticleFormData` | `type` | TypeScript type inferred from `articleFormSchema` |
| `ARTICLE_FORM_DEFAULTS` | `const` | Default values for initializing a blank article form |

## Schema Field Rules

| Field | Constraints |
|-------|-------------|
| `title` | Required, max 255 characters |
| `folderId` | Nullable string |
| `tags` | String array, max 20 items |
| `body` | Max 50,000 characters |
| `assignments` | Delegated to `assignmentsSchema` |

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';
import { articleFormSchema, ArticleFormData, ARTICLE_FORM_DEFAULTS } from './article.types';

const form = useForm<ArticleFormData>({
  resolver: zodResolver(articleFormSchema),
  defaultValues: ARTICLE_FORM_DEFAULTS,
});

// Validate raw data directly
const result = articleFormSchema.safeParse({
  title: 'My Article',
  folderId: 'folder-123',
  tags: ['networking', 'windows'],
  body: 'Article content here...',
  assignments: [],
});
```
