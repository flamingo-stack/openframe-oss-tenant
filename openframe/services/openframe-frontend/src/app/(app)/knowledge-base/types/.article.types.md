Defines the Zod validation schema and TypeScript types for the article creation/editing form.

## Key Components

- **`articleFormSchema`** — Zod schema validating article form fields: `title` (1–255 chars), `folderId` (nullable string), `tags` (max 20), `body` (max 50,000 chars), and `assignments` (delegated to `assignmentsSchema`)
- **`ArticleFormData`** — TypeScript type inferred from `articleFormSchema`
- **`ARTICLE_FORM_DEFAULTS`** — Default values for initializing an empty article form

## Usage Example

```typescript
import { articleFormSchema, ARTICLE_FORM_DEFAULTS, ArticleFormData } from './article.types';
import { useForm } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';

const { register, handleSubmit } = useForm<ArticleFormData>({
  resolver: zodResolver(articleFormSchema),
  defaultValues: ARTICLE_FORM_DEFAULTS,
});

// Validate data directly
const result = articleFormSchema.safeParse({
  title: 'My Article',
  folderId: 'folder-123',
  tags: ['networking', 'vpn'],
  body: 'Article content here...',
  assignments: { /* ... */ },
});
```
