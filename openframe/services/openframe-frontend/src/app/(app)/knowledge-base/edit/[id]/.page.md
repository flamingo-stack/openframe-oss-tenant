Client-side page component for editing an existing knowledge base article. Reads the article `id` from the URL params and renders the shared `ArticleFormPage` in edit mode, redirecting to 404 if the `knowledgeBase` feature flag is disabled.

## Key Components

- **`EditArticlePageWrapper`** — Default export; extracts `id` from route params, guards behind `featureFlags.knowledgeBase.enabled()`, and passes `articleId` to `ArticleFormPage`.
- **`featureFlags.knowledgeBase.enabled()`** — Feature flag guard; triggers `notFound()` if the knowledge base feature is inactive.
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time.

## Usage Example

This page is automatically rendered by Next.js when navigating to a route such as:

```text
/knowledge-base/articles/[id]/edit
```

No manual instantiation is needed. The `id` param is resolved from the URL:

```typescript
// Resolved internally within the component
const params = useParams<{ id?: string }>();
const id = typeof params?.id === 'string' ? params.id : null;

// Renders:
<ArticleFormPage articleId={id} />
```

If `featureFlags.knowledgeBase.enabled()` returns `false`, the component calls `notFound()` and the user is shown a 404 page instead.
