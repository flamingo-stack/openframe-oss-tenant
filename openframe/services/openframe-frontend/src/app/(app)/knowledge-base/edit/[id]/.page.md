Client-side page component that renders the knowledge base article editing interface, gated behind a feature flag.

## Key Components

- **`EditArticlePageWrapper`** — Default export; reads the `id` route parameter, checks the `knowledgeBase` feature flag, and renders `ArticleFormPage` with the resolved article ID (or `null` if unavailable)
- **`featureFlags.knowledgeBase.enabled()`** — Guards the route; triggers `notFound()` if the feature is disabled
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time

## Usage Example

```typescript
// Accessed via route: /knowledge-base/articles/[id]/edit
// e.g. /knowledge-base/articles/abc-123/edit

// If featureFlags.knowledgeBase.enabled() returns false → 404
// If params.id = "abc-123" → renders <ArticleFormPage articleId="abc-123" />
// If params.id is missing   → renders <ArticleFormPage articleId={null} />
```
