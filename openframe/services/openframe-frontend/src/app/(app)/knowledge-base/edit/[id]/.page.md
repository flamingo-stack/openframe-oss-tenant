Client-side page component for editing an existing knowledge base article, gated behind a feature flag.

## Key Components

- **`EditArticlePageWrapper`** — Default export; reads the `id` route param, checks if the knowledge base feature is enabled (redirects to 404 if not), then renders the shared `ArticleFormPage` in edit mode by passing the article ID.
- **`featureFlags.knowledgeBase.enabled()`** — Guards the route; returns `notFound()` if the feature is disabled.
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time.

## Usage Example

```typescript
// Rendered at route: /knowledge-base/articles/[id]/edit
// e.g. /knowledge-base/articles/abc123/edit

// If knowledgeBase feature flag is disabled → 404
// If enabled → renders <ArticleFormPage articleId="abc123" />
```

> **Note:** The `id` param is validated as a `string` before being passed down; if the param is missing or not a string, `null` is passed to `ArticleFormPage`, which should handle the fallback gracefully.
