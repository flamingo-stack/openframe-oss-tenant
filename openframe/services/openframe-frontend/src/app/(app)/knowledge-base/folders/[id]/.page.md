Renders a dynamic Knowledge Base folder page by extracting the folder ID from route params and delegating display to `KnowledgeBaseView`, with a feature flag guard that returns a 404 if the knowledge base feature is disabled.

## Key Components

- **`FolderPage`** — Default export page component that validates the feature flag and route param before rendering
- **`featureFlags.knowledgeBase.enabled()`** — Guards access; triggers `notFound()` if the feature is off
- **`KnowledgeBaseView`** — Delegate component that receives the resolved `folderId` prop
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring params are always read at request time

## Usage Example

This page is automatically mounted by Next.js at a route matching `[id]`, e.g. `/knowledge-base/[id]`:

```typescript
// Resolved route: /knowledge-base/abc123
// params = { id: 'abc123' }

// Feature flag disabled → notFound()
// params.id missing   → notFound()
// params.id valid     → <KnowledgeBaseView folderId="abc123" />
```

```typescript
// next.config equivalent — route is always server-rendered
export const dynamic = 'force-dynamic';
```
