A client-side Next.js page component that renders a specific Knowledge Base folder by its dynamic route ID.

## Key Components

- **`FolderPage`** — Default page export that reads the `id` route param, validates the `knowledgeBase` feature flag, and renders the folder view
- **`featureFlags.knowledgeBase.enabled()`** — Guards access; triggers a 404 if the feature is disabled
- **`KnowledgeBaseView`** — The UI component receiving the resolved `folderId` prop
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time

## Usage Example

```typescript
// Route: /knowledge-base/folders/[id]
// e.g. /knowledge-base/folders/abc-123

// With feature flag enabled and valid ID → renders KnowledgeBaseView
<KnowledgeBaseView folderId="abc-123" />

// With feature flag disabled → notFound() (404)
// With missing/invalid ID     → notFound() (404)
```

## Behavior

| Condition | Result |
|---|---|
| Feature flag disabled | 404 |
| `id` param missing or non-string | 404 |
| Valid `id` + flag enabled | Renders `KnowledgeBaseView` |
