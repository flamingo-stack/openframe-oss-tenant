Modal component for confirming folder deletion with an option to either archive or move child articles to another folder before deletion.

## Key Components

- **`DeleteFolderModal`** — Main export; renders a `ConfirmDialog` that handles folder deletion with a child-content disposition picker
- **`FolderPicker`** — Dropdown built with `ActionsMenuDropdown` that lists all available destination folders (excluding the folder being deleted) plus an archive option
- **`FolderPickerSkeleton`** — Pulse placeholder shown via `Suspense` while folder data loads
- **`DeleteSelection`** — Union type: `{ kind: 'archive' }` or `{ kind: 'move'; target: FolderMenuTarget }`

## Usage Example

```typescript
import { DeleteFolderModal, type DeleteFolderTarget } from './delete-folder-modal';

function KnowledgeBaseView() {
  const [target, setTarget] = useState<DeleteFolderTarget | null>(null);
  const [isOpen, setIsOpen] = useState(false);

  return (
    <DeleteFolderModal
      isOpen={isOpen}
      onClose={() => setIsOpen(false)}
      folder={target}               // { id: 'folder-123', name: 'Support Docs' }
      sourceConnectionId="conn-456"
      onDeleted={() => refetchFolders()}
    />
  );
}
```

## Behavior Notes

- Selection resets to `archive` each time the modal is closed (via `useEffect` on `isOpen`)
- When `folder` is `null`, the component returns `null` (safe to mount unconditionally)
- On confirm, dispatches `deleteFolder` with either `'ARCHIVE'` or `'MOVE'` as the `childrenAction`; on success shows a toast and calls `onDeleted?.()` then `onClose()`
- The folder picker excludes the folder being deleted from the destination list via `excludeFolderId`
