A modal dialog for deleting a knowledge base folder, with an option to either archive or move its child articles to another folder before deletion.

## Key Components

- **`DeleteFolderModal`** — Main exported component. Renders a `ConfirmDialog` with folder deletion logic, toast notifications, and a folder destination picker.
- **`FolderPicker`** — Dropdown selector built on `ActionsMenuDropdown` that lists available destination folders (excluding the folder being deleted) plus an archive option.
- **`FolderPickerSkeleton`** — Pulse-animated placeholder rendered via `Suspense` while folder data loads.
- **`DeleteSelection`** — Union type representing the user's chosen action: `{ kind: 'archive' }` or `{ kind: 'move'; target: FolderMenuTarget }`.
- **`DeleteFolderTarget`** — Exported interface describing the folder to be deleted (`id`, `name`).

## Usage Example

```typescript
import { DeleteFolderModal, type DeleteFolderTarget } from './delete-folder-modal';

const folder: DeleteFolderTarget = { id: 'folder-123', name: 'Support Docs' };

<DeleteFolderModal
  isOpen={isModalOpen}
  onClose={() => setModalOpen(false)}
  folder={folder}
  sourceConnectionId="conn-abc"
  onDeleted={() => refetchFolders()}
/>
```

## Behavior Notes

- Selection resets to `archive` (default) each time the modal closes via the `useEffect` on `isOpen`.
- The `FolderPicker` dropdown excludes the folder being deleted via `excludeFolderId` to prevent circular moves.
- On confirmation, delegates to `useDeleteFolder` hook with either `ARCHIVE` or `MOVE` as the `FolderChildrenAction`, then fires a success toast and calls `onDeleted` / `onClose`.
