Lazy-loads `SimpleMarkdownRenderer` and `MarkdownEditor` from `@flamingo-stack/openframe-frontend-core` using Next.js dynamic imports to prevent SSR and reduce initial bundle size.

## Key Components

- **`SimpleMarkdownRenderer`** — Dynamically imported markdown renderer, client-side only (`ssr: false`)
- **`MarkdownEditor`** — Dynamically imported rich markdown editor, client-side only (`ssr: false`)

## Usage Example

```typescript
import { SimpleMarkdownRenderer, MarkdownEditor } from './lazy-markdown';

// Render markdown content
<SimpleMarkdownRenderer content="## Hello World" />

// Full editor with markdown support
<MarkdownEditor value={content} onChange={setContent} />
```

> Both components render `null` during loading and are never server-rendered, making them safe for use in client-only contexts (e.g., browser-dependent editors or renderers).
