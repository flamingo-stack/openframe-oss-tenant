Builds hierarchical folder menu items for the Knowledge Base folder tree, converting `FolderTreeNode` structures into `ActionsMenuItem` arrays suitable for dropdown/context menus.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `FolderMenuTarget` | Interface | Represents a selected folder with `id` (nullable) and `name` |
| `FOLDER_ROOT_MENU_ID` | Constant | Sentinel ID (`__kb_root__`) for the root folder menu entry |
| `FOLDER_ROOT_TARGET` | Constant | Pre-built root target using `KNOWLEDGE_BASE_ROOT_LABEL` |
| `buildFolderMenuItems` | Function | Recursively builds menu items from a folder tree, with optional folder exclusion |
| `buildFolderMenuItemsWithRoot` | Function | Same as above but prepends a root-level entry at the top |

### Behavior Notes

- Nodes with children render as **submenus**, injecting a `__self` item (to select the parent folder itself) and a `separator` before nested children
- The `excludeFolderId` option omits a specific folder from the output — useful when moving a folder to prevent self-targeting
- Leaf nodes render as plain clickable items

## Usage Example

```typescript
const items = buildFolderMenuItemsWithRoot(
  folderTree,
  (target) => {
    console.log(`Moving to folder: ${target.name} (id: ${target.id})`);
  },
  { excludeFolderId: currentFolderId }, // prevent moving into itself
);

// Pass items to an ActionsMenu component
<ActionsMenu items={items} />
```
