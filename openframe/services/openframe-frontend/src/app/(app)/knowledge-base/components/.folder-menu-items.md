Utility functions for building nested folder navigation menu items from a `FolderTreeNode` tree, used in the Knowledge Base folder picker UI.

## Key Components

### Exports

| Export | Type | Description |
|--------|------|-------------|
| `FolderMenuTarget` | Interface | Represents a selected folder with `id` (nullable) and `name` |
| `FOLDER_ROOT_MENU_ID` | Constant | Sentinel ID (`__kb_root__`) for the root menu entry |
| `FOLDER_ROOT_TARGET` | Constant | Pre-built `FolderMenuTarget` representing the KB root folder |
| `buildFolderMenuItems` | Function | Recursively converts a `FolderTreeNode[]` into `ActionsMenuItem[]` |
| `buildFolderMenuItemsWithRoot` | Function | Same as above but prepends a root folder entry |

### `BuildFolderMenuItemsOptions`

| Option | Type | Description |
|--------|------|-------------|
| `excludeFolderId` | `string \| null` | Omits a specific folder node (e.g. the folder being moved) |

## Usage Example

```typescript
const menuItems = buildFolderMenuItemsWithRoot(
  folderTree,
  (target) => {
    console.log(`Moving to: ${target.name} (id: ${target.id})`);
  },
  { excludeFolderId: currentFolderId },
);
```

## Notes

- Nodes with children render as `submenu` type, with a self-select entry and a separator prepended before child items.
- Leaf nodes render as plain clickable `onClick` items.
- `id: null` on `FOLDER_ROOT_TARGET` signals the Knowledge Base root (no parent folder).
