Builds hierarchical folder dropdown menu items for the Knowledge Base folder tree, converting `FolderTreeNode` structures into `ActionsMenuItem` arrays with optional root entry and folder exclusion support.

## Key Components

- **`FolderMenuTarget`** — Interface representing a selected folder with its `id` (null for root) and `name`
- **`FOLDER_ROOT_MENU_ID`** — Sentinel ID (`'__kb_root__'`) used to identify the root menu entry
- **`FOLDER_ROOT_TARGET`** — Pre-built target object pointing to the Knowledge Base root
- **`buildFolderMenuItems()`** — Recursively maps `FolderTreeNode[]` into `ActionsMenuItem[]`; nodes with children render as submenus with a self-select entry and a separator before nested items; supports excluding a specific folder via `excludeFolderId`
- **`buildFolderMenuItemsWithRoot()`** — Wraps `buildFolderMenuItems()` and prepends a root-level "move to root" entry

## Usage Example

```typescript
// Render folder picker menu excluding the folder being moved
const menuItems = buildFolderMenuItemsWithRoot(
  folderTree,
  (target) => {
    console.log(`Moving to: ${target.name} (id: ${target.id})`);
    moveItem(target.id);
  },
  { excludeFolderId: currentFolderId },
);

// Without root option (nested only)
const nestedItems = buildFolderMenuItems(folderTree, onSelect);
```

Nodes with children produce a submenu structured as:
```text
FolderName
  ├── FolderName          ← self-select
  ├── ─────────────       ← separator
  ├── ChildFolder A
  └── ChildFolder B
```
