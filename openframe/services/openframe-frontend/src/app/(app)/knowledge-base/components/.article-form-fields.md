Renders the form field layout for creating or editing a knowledge base article, wiring together React Hook Form controllers for title, folder, tags, body, attachments, and assignments.

## Key Components

- **`ArticleFormFields`** — Main export. Accepts a `UseFormReturn<ArticleFormData>` instance, available tags, and a temp-attachments manager, then renders all form fields as controlled inputs.
- **`ArticleFormFieldsProps`** — Interface defining the three required props: `form`, `availableTags`, and `tempAttachments`.
- **Field sections rendered:**
  - `title` — Text `Input` with validation error display
  - `folderId` — `ActionsMenuDropdown` built from a folder tree via `buildFolderTree` / `buildFolderMenuItemsWithRoot`
  - `tags` — `ArticleTagsManager` component
  - `body` — `MarkdownEditor` with a live `SimpleMarkdownRenderer` preview
  - Attachments — `FileUpload` with multi-file support, mapped to upload/error/uploaded statuses
  - `assignments` — `AssignmentsField` component

## Usage Example

```typescript
import { ArticleFormFields } from './article-form-fields';
import { useForm } from 'react-hook-form';
import type { ArticleFormData } from '../types/article.types';
import { useArticleTempAttachments } from '../hooks/use-article-temp-attachments';

function ArticleFormExample() {
  const form = useForm<ArticleFormData>();
  const tempAttachments = useArticleTempAttachments();

  return (
    <form onSubmit={form.handleSubmit(console.log)}>
      <ArticleFormFields
        form={form}
        availableTags={[]}
        tempAttachments={tempAttachments}
      />
      <button type="submit">Save Article</button>
    </form>
  );
}
```

> **Note:** This component is marked `'use client'` and is intended for Next.js App Router client boundaries. The `MarkdownEditor` and `SimpleMarkdownRenderer` are lazy-loaded to avoid SSR issues.
