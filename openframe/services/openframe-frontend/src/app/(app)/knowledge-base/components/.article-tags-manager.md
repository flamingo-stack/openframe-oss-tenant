A tag management component for knowledge base articles that renders a multi-select autocomplete allowing users to search, select, and create tags inline.

## Key Components

### `ArticleTagsManager`

A React component that wraps the OpenFrame `Autocomplete` UI primitive with tag-specific behavior.

**Props (`ArticleTagsManagerProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `selected` | `string[]` | Currently selected tag keys |
| `onChange` | `(tags: string[]) => void` | Callback fired when the tag selection changes |
| `availableTags` | `ReadonlyArray<KnowledgeBaseTag>` | Tags fetched from the knowledge base |
| `disabled` | `boolean?` | Disables the input when `true` |

**Internal logic:**

- `options` — memoized list merging `availableTags` keys with any already-selected tags (handles stale/custom tags not present in the current fetch), deduplicated via `Set`.
- Passes `creatable` and `freeSolo` to `Autocomplete` so users can add new tags that don't yet exist in the knowledge base.

## Usage Example

```typescript
import { ArticleTagsManager } from './article-tags-manager';

function ArticleEditor() {
  const [tags, setTags] = useState<string[]>(['networking', 'vpn']);
  const { tags: availableTags } = useKnowledgeBaseTags();

  return (
    <ArticleTagsManager
      selected={tags}
      onChange={setTags}
      availableTags={availableTags}
    />
  );
}
```

> **Note:** The `options` memo always includes currently `selected` tags even if they are absent from `availableTags`, preventing selected values from disappearing when the available tag list is refreshed.
