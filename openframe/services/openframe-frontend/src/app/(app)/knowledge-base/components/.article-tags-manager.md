Renders a tag selection and creation UI for knowledge base articles, combining existing tags with user-defined ones via an autocomplete input.

## Key Components

- **`ArticleTagsManager`** — Main component that wraps the `Autocomplete` UI with multi-select, free-text entry, and tag creation support
- **`ArticleTagsManagerProps`** — Interface defining `selected` tags, `onChange` handler, `availableTags` source, and optional `disabled` state
- **`options` (memoized)** — Merges `availableTags` keys with any already-selected tags (including custom ones not in the available list) into a deduplicated option set

## Usage Example

```typescript
import { ArticleTagsManager } from './article-tags-manager';

const availableTags = [
  { key: 'networking' },
  { key: 'windows' },
];

<ArticleTagsManager
  selected={['networking', 'custom-tag']}
  availableTags={availableTags}
  onChange={(tags) => console.log('Updated tags:', tags)}
  disabled={false}
/>
```

## Notes

- Selected tags not present in `availableTags` (e.g. previously created custom tags) are still surfaced as valid options via the `useMemo` merge
- The `Autocomplete` is configured with `creatable` and `freeSolo` to allow new tags to be typed and added on the fly
- Placeholder adapts based on whether tags are already selected
