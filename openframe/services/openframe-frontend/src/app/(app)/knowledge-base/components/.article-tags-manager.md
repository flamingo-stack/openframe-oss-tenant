Renders a tag management UI for knowledge base articles, combining existing tags with user-created ones via a multi-select autocomplete input.

## Key Components

**`ArticleTagsManager`** — Named export component accepting:
- `selected` — currently applied tag keys (`string[]`)
- `onChange` — callback fired with updated tag array
- `availableTags` — readonly list of `KnowledgeBaseTag` from the knowledge base
- `disabled?` — optional flag to lock the control

**`options` (memoized)** — Merges `availableTags` keys with any `selected` tags not yet in the list (e.g. newly created ones), deduplicating via a `Set`, then maps to `{ label, value }` pairs for the `Autocomplete` component.

## Usage Example

```typescript
import { ArticleTagsManager } from './article-tags-manager';

function ArticleEditor() {
  const [tags, setTags] = useState<string[]>(['networking', 'vpn']);
  const { availableTags } = useKnowledgeBaseTags();

  return (
    <ArticleTagsManager
      selected={tags}
      onChange={setTags}
      availableTags={availableTags}
    />
  );
}
```

> Tags not present in `availableTags` but already on the article are preserved in the dropdown options, preventing them from disappearing when editing existing content.
