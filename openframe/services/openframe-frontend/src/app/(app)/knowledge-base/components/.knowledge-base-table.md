Renders the knowledge base items list and archived articles table using Relay pagination, handling row-level actions (edit, move, archive, unarchive) for both standard and archive view modes.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `KnowledgeBaseItemsListView` | Component | Unified list view supporting `standard` and `archive` modes with contextual row actions |
| `ArchivedArticlesTable` | Component | Suspense-wrapped archived articles table with Relay pagination and search/tag filtering |
| `KnowledgeBaseTableSkeleton` | Component | Pulse-animated loading skeleton (5 rows) |
| `readKnowledgeBaseItems` | Function | Reads inline Relay fragment data from connection edges into `ItemNode[]` |
| `ItemNode` | Type | Resolved shape of a `KnowledgeBaseItem` (id, type, name, status, tags, etc.) |
| `ListViewProps` | Type | Discriminated union — `StandardListViewProps` or `ArchiveListViewProps` |
| `KNOWLEDGE_BASE_PAGE_SIZE` | Constant | Default page size (`20`) for all paginated queries |

## Usage Example

```typescript
// Standard mode (folders + articles)
<KnowledgeBaseItemsListView
  mode="standard"
  items={items}
  filteredCount={100}
  hasNext={true}
  isLoadingNext={false}
  onLoadMore={loadMore}
  emptyMessage="No articles found."
  foldersConnectionId="client:root:folders"
  articlesConnectionId="client:root:articles"
/>

// Archive mode — wraps in Suspense automatically
<ArchivedArticlesTable
  search="vpn setup"
  tagIds={['tag-1']}
  emptyMessage="No archived articles."
/>

// Read Relay edges into plain ItemNode[]
const items = readKnowledgeBaseItems(data.articles.edges);
```

## Row Actions by Mode

| Mode | Item Type | Available Actions |
|------|-----------|-------------------|
| `standard` | Article | Edit, Move to folder, Archive |
| `standard` | Folder | Folder-specific actions via `useFolderRowActions` |
| `archive` | Article | Unarchive |
