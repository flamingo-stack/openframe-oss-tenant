Renders the knowledge base data table UI, handling both standard (active folders/articles) and archived article views with pagination, row actions, and modal workflows via Relay GraphQL.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `KnowledgeBaseItemsListView` | Component | Core list view supporting `standard` and `archive` modes with context-aware row actions |
| `ArchivedArticlesTable` | Component | Suspense-wrapped table for archived articles with Relay pagination |
| `KnowledgeBaseTableSkeleton` | Component | Animated pulse skeleton for loading states (5 rows) |
| `readKnowledgeBaseItems` | Function | Reads inline Relay fragment data from edge arrays into `ItemNode[]` |
| `ItemNode` | Type | Alias for `knowledgeBaseTableRow_node$data` — the normalized row shape |
| `ListViewProps` | Type | Discriminated union (`standard` | `archive`) for list view configuration |
| `KNOWLEDGE_BASE_PAGE_SIZE` | Constant | Default page size (`20`) for all paginated queries |

## Usage Example

```typescript
// Rendering active folders and articles (standard mode)
<KnowledgeBaseItemsListView
  mode="standard"
  items={items}
  filteredCount={100}
  hasNext={true}
  isLoadingNext={false}
  onLoadMore={handleLoadMore}
  emptyMessage="No articles found."
  foldersConnectionId="folder-conn-id"
  articlesConnectionId="articles-conn-id"
/>

// Rendering the archived articles table with search + tag filters
<ArchivedArticlesTable
  search="backup policy"
  tagIds={["tag-1", "tag-2"]}
  emptyMessage="No archived articles match your search."
/>

// Extracting items from Relay edges
const items = readKnowledgeBaseItems(data.archivedArticles.edges);
```

**Row actions by mode:**
- `standard` folders → folder-specific actions (via `useFolderRowActions`)
- `standard` articles → Edit, Move to folder, Archive
- `archive` → Unarchive only
