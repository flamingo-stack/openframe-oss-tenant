Renders the knowledge base items list with support for both standard (active) and archive modes, including row-level actions, pagination, and modal workflows for archiving, unarchiving, and moving articles.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `KnowledgeBaseItemsListView` | Component | Core list view rendering knowledge base rows with contextual action menus based on `mode` (`standard` or `archive`) |
| `ArchivedArticlesTable` | Component | Suspense-wrapped table for archived articles, fetching data via Relay pagination |
| `KnowledgeBaseTableSkeleton` | Component | Animated pulse placeholder shown during data loading |
| `readKnowledgeBaseItems` | Function | Utility to deserialize Relay inline fragment edges into `ItemNode[]` |
| `ItemNode` | Type | Shape of a knowledge base item row derived from the `knowledgeBaseTableRow_node` GraphQL fragment |
| `KNOWLEDGE_BASE_PAGE_SIZE` | Constant | Default page size (`20`) used across pagination queries |
| `ListViewProps` | Type | Discriminated union (`standard` | `archive`) defining props for `KnowledgeBaseItemsListView` |

## Usage Example

```typescript
// Render the archived articles table with search and tag filters
<ArchivedArticlesTable
  search="firewall setup"
  tagIds={['tag-1', 'tag-2']}
  emptyMessage="No archived articles found."
/>

// Render the standard list view (active articles and folders)
<KnowledgeBaseItemsListView
  mode="standard"
  items={items}
  filteredCount={42}
  hasNext={true}
  isLoadingNext={false}
  onLoadMore={handleLoadMore}
  emptyMessage="No articles yet."
  foldersConnectionId="connection-folders-123"
  articlesConnectionId="connection-articles-456"
/>
```

**Row actions by mode:**
- **`standard` / article:** Edit, Move to folder, Archive
- **`standard` / folder:** Delegated to `useFolderRowActions`
- **`archive`:** Unarchive only
