Renders the full detail view for a single Knowledge Base article, handling article status lifecycle (Draft → Published → Archived), contextual actions, metadata display, markdown content, attachments, and assigned items.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `ArticleDetailsPage` | Component | Root export; wraps content in `Suspense` with a skeleton fallback |
| `ArticleDetailsContent` | Component (internal) | Fetches and renders article data, actions, and modals |
| `ArticleDetailsFallback` | Component (internal) | Animated skeleton shown during Suspense resolution |
| `ArticleDetailsPageProps` | Type | `{ articleId: string }` |
| `ArticleStatus` | Type | `'DRAFT' \| 'PUBLISHED' \| 'ARCHIVED'` |

### Status → Tag Variant Map

```typescript
const STATUS_VARIANT = {
  PUBLISHED: 'success',
  DRAFT: 'warning',
  ARCHIVED: 'grey',
};
```

### Action Matrix by Status

| Status | Primary Actions | Menu Actions |
|--------|----------------|--------------|
| `DRAFT` | Edit, Publish | Archive, Move to Folder |
| `PUBLISHED` | Edit | Archive, Move to Folder, Move to Draft |
| `ARCHIVED` | Unarchive | *(none)* |

## Usage Example

```typescript
// app/knowledge-base/[articleId]/page.tsx
import { ArticleDetailsPage } from '@/features/knowledge-base/components/article-details-page';

export default function Page({ params }: { params: { articleId: string } }) {
  return <ArticleDetailsPage articleId={params.articleId} />;
}
```

## Key Behaviors

- Calls `notFound()` if the fetched item is missing or not of type `ARTICLE`
- Derives `sourceConnectionId` from article status to keep relay/cache connections consistent across archive and active lists
- Downloads attachments via `useDownloadArticleAttachment` with pre-formatted file sizes
- Modals (`ArchiveArticleModal`, `MoveToFolderModal`, `UnarchiveArticleModal`) receive `null` items when closed to avoid stale data flashes
