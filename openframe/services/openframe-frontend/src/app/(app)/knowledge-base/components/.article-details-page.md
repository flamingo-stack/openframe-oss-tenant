Renders the full detail view for a single knowledge base article, handling status-aware actions (publish, unpublish, archive, unarchive, move to folder) and displaying article metadata, content, attachments, and assignments.

## Key Components

- **`ArticleDetailsPage`** — Public exported component wrapping content in a `Suspense` boundary with a skeleton fallback
- **`ArticleDetailsContent`** — Core rendering logic; fetches article data via `useKnowledgeBaseItem` and orchestrates all actions
- **`ArticleDetailsFallback`** — Pulse-animated skeleton shown during data loading
- **`STATUS_VARIANT`** — Maps `DRAFT | PUBLISHED | ARCHIVED` to Tag color variants (`warning`, `success`, `grey`)

### Conditional Action Logic

| Status | Primary Actions | Menu Actions |
|---|---|---|
| `DRAFT` | Edit, Publish | Archive, Move to Folder |
| `PUBLISHED` | Edit | Archive, Move to Folder, Move to Draft |
| `ARCHIVED` | Unarchive | *(none)* |

## Usage Example

```typescript
// In a Next.js page (e.g. app/knowledge-base/[id]/page.tsx)
import { ArticleDetailsPage } from '@/features/knowledge-base/components/article-details-page';

interface PageProps {
  params: { id: string };
}

export default function ArticlePage({ params }: PageProps) {
  return <ArticleDetailsPage articleId={params.id} />;
}
```

> **Note:** Calls `notFound()` from `next/navigation` if the fetched item is missing or not of type `ARTICLE`, delegating to the nearest Next.js not-found boundary.
