Client-side page component that renders the full detail view for a single Knowledge Base article, including metadata, content, attachments, and status-driven actions.

## Key Components

- **`ArticleDetailsPage`** — Public export; wraps content in a `<Suspense>` boundary with an animated skeleton fallback
- **`ArticleDetailsContent`** — Core logic component; fetches article data and renders the full detail layout
- **`ArticleDetailsFallback`** — Pulse-animated skeleton shown while the article suspends
- **`STATUS_VARIANT`** — Maps `ArticleStatus` (`DRAFT` | `PUBLISHED` | `ARCHIVED`) to Tag color variants

### Status-driven behaviour

| Status | Primary Action | Menu Actions |
|--------|---------------|--------------|
| `DRAFT` | Edit + Publish | Archive, Move to Folder |
| `PUBLISHED` | Edit | Archive, Move to Folder, Move to Draft |
| `ARCHIVED` | Unarchive | _(none)_ |

### Modals managed

- `ArchiveArticleModal` — archive a live/draft article
- `UnarchiveArticleModal` — restore an archived article
- `MoveToFolderModal` — relocate article within the KB hierarchy

## Usage Example

```typescript
// app/knowledge-base/[articleId]/page.tsx
import { ArticleDetailsPage } from '@/features/knowledge-base/components/article-details-page';

interface PageProps {
  params: { articleId: string };
}

export default function Page({ params }: PageProps) {
  return <ArticleDetailsPage articleId={params.articleId} />;
}
```

> **Note:** The component calls `notFound()` from `next/navigation` if the resolved item is missing or is not of type `ARTICLE`, so no additional null-guard is needed at the route level.
