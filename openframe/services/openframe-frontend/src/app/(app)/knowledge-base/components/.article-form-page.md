Renders the knowledge base article creation and editing page, handling both new article and edit modes with loading states, form actions, and navigation.

## Key Components

- **`ArticleFormPage`** — Main exported component; switches between create and edit modes, wrapping content in a `Suspense` boundary with a skeleton fallback
- **`EditFormBody`** — Fetches the existing article by ID via `useKnowledgeBaseItem`, calls `notFound()` if the item is missing or not of type `ARTICLE`
- **`FormShell`** — Core form layout; wires up `useEditArticleForm`, `useKnowledgeBaseTags`, back navigation, and page actions (Save as Draft / Save and Publish)
- **`ArticleFormFallback`** — Skeleton loading UI with animated pulse placeholders shown during Suspense resolution

## Usage Example

```typescript
// Render for creating a new article inside a folder
<ArticleFormPage articleId={null} initialFolderId="folder-123" />

// Render for editing an existing article
<ArticleFormPage articleId="article-456" initialFolderId="folder-123" />
```

## Behavior Notes

- **Edit mode** is inferred from `articleId !== null`; the page title and back button destination update accordingly
- Back navigation returns to the article detail page in edit mode, or to `/knowledge-base` when creating
- `handleSave` is called with either `'DRAFT'` or `'PUBLISHED'` status and the resolved `availableTags`
- Tags are scoped to the folder via `useKnowledgeBaseTags({ folderId })`
