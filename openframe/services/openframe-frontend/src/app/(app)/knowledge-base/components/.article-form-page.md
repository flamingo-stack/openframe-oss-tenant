Renders the create/edit article form page for the Knowledge Base module, handling both new article creation and existing article editing with loading states and navigation actions.

## Key Components

- **`ArticleFormPage`** *(exported)* — Root component that determines edit vs. create mode and wraps rendering in a `Suspense` boundary
- **`FormShell`** — Core layout shell that composes `PageLayout` with back navigation, save actions (Draft/Publish), and `ArticleFormFields`
- **`EditFormBody`** — Fetches the existing article by ID via `useKnowledgeBaseItem`; calls `notFound()` if the item is missing or not of type `ARTICLE`
- **`ArticleFormFallback`** — Skeleton loading state shown during Suspense with animated pulse placeholders

## Usage Example

```typescript
// Render a "New Article" form inside a specific folder
<ArticleFormPage articleId={null} initialFolderId="folder-123" />

// Render an "Edit Article" form for an existing article
<ArticleFormPage articleId="article-456" initialFolderId="folder-123" />
```

## Behavior Notes

- **Edit mode** is determined by `articleId !== null`; back navigation returns to the article detail page
- **Create mode** skips data fetching and returns to `/knowledge-base` on back
- Save actions delegate to `handleSave('DRAFT' | 'PUBLISHED', { availableTags })` from `useEditArticleForm`
- Available tags are scoped to the `initialFolderId` via `useKnowledgeBaseTags`
- `actions` and `backButton` are memoized to avoid unnecessary re-renders
