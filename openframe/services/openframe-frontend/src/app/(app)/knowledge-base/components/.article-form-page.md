Renders the full-page form UI for creating or editing a Knowledge Base article, handling both create and edit modes with Suspense-based loading states.

## Key Components

- **`ArticleFormPage`** *(exported)* — Root component; determines create vs. edit mode based on `articleId` and wraps children in a `Suspense` boundary with a skeleton fallback.
- **`EditFormBody`** — Fetches the existing article via `useKnowledgeBaseItem`; calls `notFound()` if the item is missing or not of type `ARTICLE`.
- **`FormShell`** — Core form layout; wires up `useEditArticleForm`, `useKnowledgeBaseTags`, and `useSafeBack` to produce the page title, back button, and Save as Draft / Save and Publish actions.
- **`ArticleFormFallback`** — Pulse-animated skeleton matching the form layout, shown during Suspense suspension.

## Usage Example

```typescript
// Create mode — no articleId
<ArticleFormPage articleId={null} initialFolderId="folder-123" />

// Edit mode — existing article
<ArticleFormPage articleId="article-456" initialFolderId="folder-123" />
```

## Behavior Notes

- **Edit mode**: `articleId !== null` → fetches article, redirects to 404 if not found or wrong type.
- **Back navigation**: returns to the article detail page in edit mode, or to `/knowledge-base` in create mode.
- **Save actions**: both call `handleSave` with either `'DRAFT'` or `'PUBLISHED'` status, passing resolved `availableTags`; buttons are disabled while `isSubmitting` is `true`.
