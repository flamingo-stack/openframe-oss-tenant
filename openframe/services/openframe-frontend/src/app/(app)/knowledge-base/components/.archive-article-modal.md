A confirmation modal component for archiving knowledge base articles, using a destructive confirm dialog pattern with toast feedback on success.

## Key Components

- **`ArchiveArticleTarget`** — Interface defining the minimal article shape (`id`, `name`) required for the archive operation
- **`ArchiveArticleModalProps`** — Props interface accepting open state, close handler, target article, and the source connection to remove the article from
- **`ArchiveArticleModal`** — Main component rendering a `ConfirmDialog` that triggers the archive mutation and updates optimistic connection state
- **`ARCHIVED_ARTICLES_CONNECTION_KEY`** — Re-exported constant for use by parent modules managing connection cache keys

## Usage Example

```typescript
import { ArchiveArticleModal, ArchiveArticleTarget } from './archive-article-modal';

const article: ArchiveArticleTarget = { id: 'art_123', name: 'How to Reset VPN' };

<ArchiveArticleModal
  isOpen={isArchiveOpen}
  onClose={() => setIsArchiveOpen(false)}
  article={article}
  sourceConnectionId="articles:list:all"
/>
```

## Behavior Notes

- Calls `archiveArticle` with `removeFromConnections` (source list) and `appendToConnections` (archive list) to perform an optimistic connection swap
- Uses `getArchivedArticlesConnectionId` with `null` filters to target the default archived articles feed
- Displays a success toast with the article name on completion; silently swallows errors (no error toast — consider adding one)
- The `ConfirmDialog` uses `variant="destructive"` to render the confirm button in red, reinforcing the irreversible nature of archiving
