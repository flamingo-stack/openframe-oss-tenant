A confirmation modal component for archiving knowledge base articles, integrating with optimistic connection management to move articles from their source list to the archived articles collection.

## Key Components

**`ArchiveArticleTarget`** — Interface defining the minimal article shape (`id`, `name`) required for the archive operation.

**`ArchiveArticleModalProps`** — Props interface accepting open state, close handler, target article, and the source connection ID to remove the article from.

**`ArchiveArticleModal`** — Main component that renders a destructive `ConfirmDialog`, triggers the archive mutation on confirm, and displays a success toast on completion.

**`ARCHIVED_ARTICLES_CONNECTION_KEY`** — Re-exported constant for use by consumers needing to reference the archived articles cache key.

## Usage Example

```typescript
import { ArchiveArticleModal, ArchiveArticleTarget } from './archive-article-modal';

const article: ArchiveArticleTarget = { id: 'art_123', name: 'VPN Setup Guide' };

<ArchiveArticleModal
  isOpen={isModalOpen}
  onClose={() => setModalOpen(false)}
  article={article}
  sourceConnectionId="articles:active:list"
/>
```

## Behavior Notes

- Resolves the target archived connection ID (no search/tag filters) via `getArchivedArticlesConnectionId`
- Passes `removeFromConnections` and `appendToConnections` to the mutation, enabling optimistic list updates without a full refetch
- No-ops silently on mutation error (empty `catch` block) — consumers should handle error feedback upstream if needed
- Dialog's `onOpenChange` delegates close to `onClose`, keeping open state controlled by the parent
