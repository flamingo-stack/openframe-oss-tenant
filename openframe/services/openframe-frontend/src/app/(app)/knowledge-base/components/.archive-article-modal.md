A confirmation modal component for archiving knowledge base articles, integrating with the archive mutation hook and connection-based cache management.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `ArchiveArticleModal` | Component | Confirmation dialog that triggers the archive mutation |
| `ArchiveArticleTarget` | Interface | Shape of the article object required (`id`, `name`) |
| `ARCHIVED_ARTICLES_CONNECTION_KEY` | Re-export | Connection key constant forwarded from the archived articles hook |

## Props

| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls dialog visibility |
| `onClose` | `() => void` | Callback fired on cancel or successful archive |
| `article` | `ArchiveArticleTarget \| null` | Target article to archive |
| `sourceConnectionId` | `string` | The current list's connection ID, removed from on archive |

## Behavior

1. Resolves the destination connection ID via `getArchivedArticlesConnectionId` (no search/tag filters)
2. Calls `archiveArticle` with `removeFromConnections` and `appendToConnections` to move the article between cache connections
3. Shows a success toast on completion and calls `onClose`
4. Errors are silently swallowed — the parent is responsible for error boundaries
