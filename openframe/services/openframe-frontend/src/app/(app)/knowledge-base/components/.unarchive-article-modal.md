Modal component for restoring archived Knowledge Base articles to a selected folder destination.

## Key Components

- **`UnarchiveArticleModal`** — Main modal component that orchestrates the unarchive flow; handles folder selection state, confirmation, toast notifications, and connection ID management
- **`FolderPicker`** — Dropdown UI built with `ActionsMenuDropdown` + `InputTrigger` that renders the folder tree for destination selection
- **`FolderPickerSkeleton`** — Animated placeholder shown while folder data loads via `Suspense`
- **`UnarchiveArticleTarget`** — Interface defining the minimal article shape (`id`, `name`) required by the modal
- **`UnarchiveArticleModalProps`** — Props interface accepting `isOpen`, `onClose`, `article`, and `sourceConnectionId`

## Usage Example

```typescript
import { UnarchiveArticleModal } from './unarchive-article-modal';

function ArchivedArticlesList() {
  const [modalOpen, setModalOpen] = useState(false);
  const [target, setTarget] = useState<UnarchiveArticleTarget | null>(null);

  return (
    <>
      <button onClick={() => {
        setTarget({ id: 'article-123', name: 'Getting Started Guide' });
        setModalOpen(true);
      }}>
        Unarchive
      </button>

      <UnarchiveArticleModal
        isOpen={modalOpen}
        onClose={() => setModalOpen(false)}
        article={target}
        sourceConnectionId="archived-connection-id"
      />
    </>
  );
}
```

## Behavior Notes

- Selected folder resets to `null` whenever the modal closes (`isOpen` → `false`)
- When the root folder is selected (`selected.id === null`), `appendToConnections` is set to an empty array
- The confirm button is disabled until both `article` and `selected` are non-null, preventing partial submissions
- Errors from `unarchiveArticle` are silently swallowed; success triggers a `variant: 'success'` toast and calls `onClose()`
