Modal component for restoring archived Knowledge Base articles to a selected folder destination.

## Key Components

- **`UnarchiveArticleModal`** — Main modal that prompts the user to pick a destination folder before restoring an archived article. Calls `useUnarchiveArticle` to perform the mutation and shows a success toast on completion.
- **`FolderPicker`** — Dropdown that renders the full folder tree (including a root option) using `ActionsMenuDropdown` and `InputTrigger`. Built from `useKnowledgeBaseFolders` data.
- **`FolderPickerSkeleton`** — Pulse placeholder shown while folder data is loading via `Suspense`.
- **`UnarchiveArticleTarget`** — Interface describing the article being unarchived (`id`, `name`).

## Usage Example

```typescript
import { UnarchiveArticleModal } from './unarchive-article-modal';

function ArticleList() {
  const [target, setTarget] = useState<UnarchiveArticleTarget | null>(null);
  const [isOpen, setIsOpen] = useState(false);

  return (
    <>
      <button onClick={() => {
        setTarget({ id: 'article-123', name: 'My Article' });
        setIsOpen(true);
      }}>
        Unarchive
      </button>

      <UnarchiveArticleModal
        isOpen={isOpen}
        onClose={() => setIsOpen(false)}
        article={target}
        sourceConnectionId="archived-connection-id"
      />
    </>
  );
}
```

## Behavior Notes

- Resets the folder selection to `null` whenever the modal closes.
- Derives the `targetConnectionId` via `getKnowledgeBaseArticlesConnectionId` when a non-root folder is selected; root selection passes an empty `appendToConnections` array.
- The **Unarchive** button stays disabled until both `article` and a `selected` folder are present.
