Modal component for unarchiving knowledge base articles, allowing users to select a destination folder before restoring an archived article.

## Key Components

- **`UnarchiveArticleModal`** — Main modal component that orchestrates the unarchive flow, manages folder selection state, and triggers the unarchive mutation with connection ID updates
- **`FolderPicker`** — Dropdown component that renders the folder tree as a selectable menu using `ActionsMenuDropdown` with `InputTrigger`
- **`FolderPickerSkeleton`** — Loading placeholder rendered while folder data is suspended or the article target is null
- **`UnarchiveArticleTarget`** — Interface describing the minimal article shape (`id`, `name`) required by the modal

## Usage Example

```typescript
import { UnarchiveArticleModal } from './unarchive-article-modal';

function ArticleList() {
  const [modalOpen, setModalOpen] = useState(false);
  const [target, setTarget] = useState<UnarchiveArticleTarget | null>(null);

  return (
    <>
      <button
        onClick={() => {
          setTarget({ id: 'article-123', name: 'Getting Started Guide' });
          setModalOpen(true);
        }}
      >
        Unarchive
      </button>

      <UnarchiveArticleModal
        isOpen={modalOpen}
        onClose={() => setModalOpen(false)}
        article={target}
        sourceConnectionId="conn-archived-456"
      />
    </>
  );
}
```

## Behavior Notes

- Folder selection resets to `null` whenever the modal closes (`isOpen` → `false`)
- Selecting the root folder (id `null`) unarchives the article with no parent, omitting `appendToConnections`
- The **Unarchive** button is disabled until both `article` and `selected` are non-null, preventing partial submissions
- Uses `Suspense` to defer folder tree loading, showing `FolderPickerSkeleton` as fallback
