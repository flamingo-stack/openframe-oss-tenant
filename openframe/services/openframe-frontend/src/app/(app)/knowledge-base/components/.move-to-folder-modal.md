Modal component for moving knowledge base items (folders or articles) to a different folder, featuring a searchable folder picker dropdown with Suspense loading state.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `MoveToFolderModal` | Component | Main modal with confirm/cancel actions and pending state |
| `MoveToFolderItem` | Interface | Shape of the item being moved (`id`, `name`, `type`) |
| `MoveToFolderModalProps` | Interface | Props for the modal including `isOpen`, `onClose`, `item`, and `sourceConnectionId` |
| `FolderPicker` | Internal Component | Dropdown built from a folder tree, excludes the source folder when moving a folder |
| `FolderPickerSkeleton` | Internal Component | Pulse skeleton shown during Suspense fallback or when `item` is null |

## Usage Example

```typescript
import { MoveToFolderModal, type MoveToFolderItem } from './move-to-folder-modal';

const item: MoveToFolderItem = {
  id: 'article-123',
  name: 'Getting Started Guide',
  type: 'article',
};

<MoveToFolderModal
  isOpen={isModalOpen}
  onClose={() => setModalOpen(false)}
  item={item}
  sourceConnectionId={currentFolderConnectionId}
/>
```

## Behavior Notes

- Resets selected folder whenever the modal closes (`isOpen` → `false`)
- When moving a **folder**, excludes itself from the picker to prevent circular nesting
- On success, invalidates the source connection and appends to the target connection via `useMoveToFolder`, then shows a success toast
- Confirm button is disabled until a destination folder is selected or while the mutation is in flight
