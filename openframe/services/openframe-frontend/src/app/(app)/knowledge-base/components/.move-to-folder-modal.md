Modal component for moving knowledge base items (folders or articles) to a different folder, featuring a folder picker dropdown and optimistic connection management.

## Key Components

- **`MoveToFolderModal`** — Main modal component that orchestrates the move operation, manages selected folder state, and displays Cancel/Move action buttons
- **`FolderPicker`** — Internal dropdown component that renders the folder tree using `ActionsMenuDropdown` with an `InputTrigger`, excluding the item being moved (when it's a folder) to prevent circular nesting
- **`FolderPickerSkeleton`** — Loading placeholder rendered via `Suspense` while folder data is being fetched
- **`MoveToFolderItem`** — Interface describing the item to be moved (`id`, `name`, `type: 'folder' | 'article'`)

## Usage Example

```typescript
import { MoveToFolderModal } from './move-to-folder-modal';

function KnowledgeBaseItem() {
  const [isOpen, setIsOpen] = useState(false);

  const item: MoveToFolderItem = {
    id: 'article-123',
    name: 'Getting Started Guide',
    type: 'article',
  };

  return (
    <>
      <button onClick={() => setIsOpen(true)}>Move to Folder</button>
      <MoveToFolderModal
        isOpen={isOpen}
        onClose={() => setIsOpen(false)}
        item={item}
        sourceConnectionId="connection-abc"
      />
    </>
  );
}
```

## Behavior Notes

- Resets selected folder state when the modal closes (`useEffect` on `isOpen`)
- When moving a **folder**, excludes itself from the picker to prevent circular nesting
- On success, updates both `removeFromConnections` and `appendToConnections` to keep the normalized connection store in sync, then shows a success toast
