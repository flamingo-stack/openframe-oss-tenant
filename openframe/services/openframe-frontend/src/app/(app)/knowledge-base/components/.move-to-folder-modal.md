A modal dialog component for moving knowledge base items (folders or articles) to a different folder destination.

## Key Components

- **`MoveToFolderModal`** — Main exported modal component; handles state, confirmation logic, and toast notifications on success
- **`FolderPicker`** — Internal dropdown component that renders a hierarchical folder tree using `ActionsMenuDropdown`; excludes the item being moved if it's a folder
- **`FolderPickerSkeleton`** — Pulse-animated placeholder shown while folder data loads via `Suspense`
- **`MoveToFolderItem`** — Exported interface describing the item to be moved (`id`, `name`, `type`)

## Usage Example

```typescript
import { MoveToFolderModal, type MoveToFolderItem } from './move-to-folder-modal';

const item: MoveToFolderItem = {
  id: 'article-123',
  name: 'Getting Started Guide',
  type: 'article',
};

<MoveToFolderModal
  isOpen={isModalOpen}
  onClose={() => setIsModalOpen(false)}
  item={item}
  sourceConnectionId={currentConnectionId}
/>
```

## Behavior Notes

- Resets selected folder when the modal closes (`isOpen` → `false`)
- When moving a **folder**, its own ID is excluded from the destination picker to prevent circular nesting
- On confirm, computes the correct `targetConnectionId` based on item type (folder vs. article) using the `selected.id` as `parentId`
- Passes both `removeFromConnections` and `appendToConnections` to `useMoveToFolder` to keep relay/cache connections consistent
- Displays a success toast with item and destination names; errors are silently swallowed
