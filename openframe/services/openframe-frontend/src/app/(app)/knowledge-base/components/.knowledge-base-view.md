A thin client-side view wrapper that renders the knowledge base content for a given folder context.

## Key Components

- **`KnowledgeBaseView`** — Client component that accepts an optional `folderId` and delegates rendering to `KnowledgeBaseBody` via its `parentId` prop.

## Usage Example

```typescript
// Render the root knowledge base (no folder selected)
<KnowledgeBaseView folderId={null} />

// Render contents of a specific folder
<KnowledgeBaseView folderId="folder-abc-123" />
```

## Notes

- Marked `'use client'` — runs in the browser, suitable for use within Next.js App Router client trees.
- Acts purely as a prop-mapping passthrough; all business logic lives in `KnowledgeBaseBody`.
