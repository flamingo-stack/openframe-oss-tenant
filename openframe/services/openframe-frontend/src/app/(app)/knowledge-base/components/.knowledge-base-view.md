A thin client-side view component that wraps `KnowledgeBaseBody`, passing a folder ID to scope the knowledge base display.

## Key Components

- **`KnowledgeBaseView`** — Client component that accepts an optional `folderId` and delegates rendering to `KnowledgeBaseBody`
- **`KnowledgeBaseViewProps`** — Interface defining the `folderId` prop (`string | null`)

## Usage Example

```typescript
// Render knowledge base scoped to a specific folder
<KnowledgeBaseView folderId="folder-123" />

// Render top-level knowledge base (no folder)
<KnowledgeBaseView folderId={null} />
```
