A thin client-side wrapper component that renders the knowledge base content for a given folder context.

## Key Components

- **`KnowledgeBaseView`** — Presentational wrapper that accepts a nullable `folderId` and delegates rendering to `KnowledgeBaseBody`, passing it as `parentId`.

| Prop | Type | Description |
|------|------|-------------|
| `folderId` | `string \| null` | ID of the folder to display; `null` renders the root level |

## Usage Example

```typescript
import { KnowledgeBaseView } from './knowledge-base-view';

// Render root-level knowledge base
<KnowledgeBaseView folderId={null} />

// Render contents of a specific folder
<KnowledgeBaseView folderId="folder_abc123" />
```

> This component acts as an entry point/adapter between routing/page-level concerns and the `KnowledgeBaseBody` implementation, keeping prop naming consistent across layers.
