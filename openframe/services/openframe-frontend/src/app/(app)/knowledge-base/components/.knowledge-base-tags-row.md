Renders a horizontal row of selectable knowledge base tags filtered by folder context, excluding already-selected tags. Wraps async data fetching in `Suspense` with a skeleton fallback.

## Key Components

| Export | Description |
|--------|-------------|
| `KnowledgeBaseTagsRow` | Main component; wraps content in `Suspense` with a pulse skeleton fallback |
| `KnowledgeBaseTagsRowContent` | Fetches tags via `useKnowledgeBaseTags`, filters out selected ones, renders clickable `Tag` chips |
| `KnowledgeBaseTagsRowSkeleton` | Loading placeholder rendering 4 animated placeholder chips |
| `SelectedKnowledgeBaseTag` | Exported interface `{ id, key }` passed to the `onAdd` callback |

## Props

| Prop | Type | Description |
|------|------|-------------|
| `parentId` | `string \| null` | Folder ID used to scope tag retrieval |
| `selectedIds` | `ReadonlyArray<string>` | Tag IDs already selected; excluded from display |
| `onAdd` | `(tag: SelectedKnowledgeBaseTag) => void` | Callback fired when a tag chip is clicked |
| `archived` | `boolean?` | When `true`, fetches archived tags |

## Usage Example

```typescript
import { KnowledgeBaseTagsRow, SelectedKnowledgeBaseTag } from './knowledge-base-tags-row';

const [selectedIds, setSelectedIds] = useState<string[]>([]);

function handleAdd(tag: SelectedKnowledgeBaseTag) {
  setSelectedIds(prev => [...prev, tag.id]);
}

<KnowledgeBaseTagsRow
  parentId="folder-123"
  selectedIds={selectedIds}
  onAdd={handleAdd}
/>
```
