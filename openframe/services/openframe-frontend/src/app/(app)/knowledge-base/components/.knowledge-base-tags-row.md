A client-side component that renders a horizontal row of selectable knowledge base tags, filtered to exclude already-selected ones, with Suspense-based loading skeleton support.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `KnowledgeBaseTagsRow` | Component | Public entry point; wraps content in `Suspense` with a skeleton fallback |
| `KnowledgeBaseTagsRowContent` | Component (internal) | Fetches tags via `useKnowledgeBaseTags`, filters out already-selected IDs, and renders clickable `Tag` chips |
| `KnowledgeBaseTagsRowSkeleton` | Component (internal) | Renders 4 animated pulse placeholders while tags are loading |
| `SelectedKnowledgeBaseTag` | Interface | Shape of a tag selection event (`id`, `key`) |
| `KnowledgeBaseTagsRowProps` | Interface | Component props definition |

### Props

| Prop | Type | Description |
|------|------|-------------|
| `parentId` | `string \| null` | Folder ID used to scope tag fetching |
| `selectedIds` | `ReadonlyArray<string>` | IDs of already-selected tags to exclude from display |
| `onAdd` | `(tag: SelectedKnowledgeBaseTag) => void` | Callback fired when a tag chip is clicked |
| `archived` | `boolean?` | When `true`, fetches archived tags instead |

## Usage Example

```typescript
import { KnowledgeBaseTagsRow, SelectedKnowledgeBaseTag } from './knowledge-base-tags-row';

function ArticleTagPicker({ folderId }: { folderId: string }) {
  const [selected, setSelected] = useState<SelectedKnowledgeBaseTag[]>([]);

  const handleAdd = (tag: SelectedKnowledgeBaseTag) => {
    setSelected(prev => [...prev, tag]);
  };

  return (
    <KnowledgeBaseTagsRow
      parentId={folderId}
      selectedIds={selected.map(t => t.id)}
      onAdd={handleAdd}
    />
  );
}
```
