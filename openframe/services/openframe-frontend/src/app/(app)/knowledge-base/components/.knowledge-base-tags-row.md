Renders a horizontally-wrapped row of selectable knowledge base tags, filtered to exclude already-selected tags, with Suspense-based skeleton loading.

## Key Components

- **`KnowledgeBaseTagsRow`** — Public export; wraps content in `Suspense` with a skeleton fallback during tag data loading.
- **`KnowledgeBaseTagsRowContent`** — Fetches available tags via `useKnowledgeBaseTags`, filters out already-selected IDs, and renders clickable `Tag` components.
- **`KnowledgeBaseTagsRowSkeleton`** — Placeholder UI showing 4 animated pulse blocks while tags are loading.
- **`SelectedKnowledgeBaseTag`** — Exported interface representing a tag selection payload (`id`, `key`).

## Props

| Prop | Type | Description |
|---|---|---|
| `parentId` | `string \| null` | Folder ID used to scope tag fetching |
| `selectedIds` | `ReadonlyArray<string>` | IDs of already-selected tags to exclude from display |
| `onAdd` | `(tag: SelectedKnowledgeBaseTag) => void` | Callback fired when a tag is clicked |
| `archived` | `boolean?` | Whether to fetch archived tags |

## Usage Example

```typescript
import { KnowledgeBaseTagsRow } from './knowledge-base-tags-row';

function TagSelector() {
  const [selectedTags, setSelectedTags] = useState<SelectedKnowledgeBaseTag[]>([]);

  return (
    <KnowledgeBaseTagsRow
      parentId="folder-123"
      selectedIds={selectedTags.map(t => t.id)}
      onAdd={(tag) => setSelectedTags(prev => [...prev, tag])}
      archived={false}
    />
  );
}
```
