Defines column definitions and the table body component for rendering knowledge base items (articles and folders) in a data table, supporting both standard and archive display modes.

## Key Components

- **`KnowledgeBaseRow`** — Interface describing a knowledge base item with fields for `id`, `type`, `name`, `status`, `summary`, timestamps, and tags
- **`KnowledgeBaseTableMode`** — Union type `'standard' | 'archive'` controlling which columns and labels are displayed
- **`knowledgeBaseRowHref`** — Helper that resolves the navigation URL for a row based on its type (`ARTICLE` → `/knowledge-base/details/:id`, `FOLDER` → `/knowledge-base/folders/:id`)
- **`KNOWLEDGE_BASE_OPEN_COLUMN`** — Pre-built column definition that renders an "open in new tab" button, excluded from sorting
- **`getKnowledgeBaseColumns(mode)`** — Returns the base column set: a `name` column (with icon, status tag, and summary) and a date column (Created or Archived depending on mode)
- **`KnowledgeBaseTableBody`** — Fully composed table component that wires columns, loading states, empty messages, row navigation, and an optional actions column slot

## Usage Example

```typescript
import {
  KnowledgeBaseTableBody,
  type KnowledgeBaseRow,
} from './knowledge-base-table-columns';

const items: KnowledgeBaseRow[] = [
  {
    id: 'article-1',
    type: 'ARTICLE',
    name: 'Getting Started',
    status: 'PUBLISHED',
    summary: 'An introduction to the platform.',
    createdAt: '2024-06-01T10:00:00Z',
  },
  {
    id: 'folder-1',
    type: 'FOLDER',
    name: 'Onboarding',
  },
];

export function MyKnowledgeBasePage() {
  return (
    <KnowledgeBaseTableBody
      items={items}
      mode="standard"
      totalCount={42}
      emptyMessage="No knowledge base items found."
    />
  );
}
```
