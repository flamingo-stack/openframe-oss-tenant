Defines column configurations and the table body component for the Knowledge Base data table, supporting both standard and archive display modes.

## Key Components

### Types & Interfaces
- **`KnowledgeBaseRow`** — Row data shape with `id`, `type`, `name`, `status`, `summary`, timestamps, and tags
- **`KnowledgeBaseRowType`** — `'ARTICLE' | 'FOLDER' | string`
- **`KnowledgeBaseRowStatus`** — `'DRAFT' | 'PUBLISHED' | 'ARCHIVED' | string | null | undefined`
- **`KnowledgeBaseTableMode`** — `'standard' | 'archive'`
- **`KnowledgeBaseTableBodyProps`** — Props for the table body component

### Exports
- **`knowledgeBaseRowHref(item)`** — Derives the navigation href for a row (`/knowledge-base/details/:id` for articles, `/knowledge-base/folders/:id` for folders)
- **`KNOWLEDGE_BASE_OPEN_COLUMN`** — Pre-built "open in new tab" action column definition
- **`getKnowledgeBaseColumns(mode)`** — Returns the `name` and date columns, adapting labels/accessors based on `mode`
- **`KnowledgeBaseTableBody`** — Full table component with header, body, skeleton loading, empty state, and optional footer/actions column

## Usage Example

```typescript
import {
  KnowledgeBaseTableBody,
  type KnowledgeBaseRow,
} from './knowledge-base-table-columns';

const items: KnowledgeBaseRow[] = [
  { id: '1', type: 'ARTICLE', name: 'Getting Started', status: 'PUBLISHED', createdAt: '2024-01-15T10:00:00Z' },
  { id: '2', type: 'FOLDER', name: 'Guides' },
];

// Standard mode — shows "Created" date column
<KnowledgeBaseTableBody items={items} mode="standard" totalCount={2} />

// Archive mode — shows "Archived" date column, uses updatedAt
<KnowledgeBaseTableBody
  items={items}
  mode="archive"
  isLoading={false}
  emptyMessage="No archived articles."
  totalCount={2}
/>
```
