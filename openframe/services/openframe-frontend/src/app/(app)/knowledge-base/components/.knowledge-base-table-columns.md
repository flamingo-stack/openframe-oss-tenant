Defines column definitions and the table body component for rendering knowledge base items (articles and folders) in a sortable, mode-aware data table.

## Key Components

### Types & Interfaces
- **`KnowledgeBaseRow`** — Row data shape with `id`, `type`, `name`, `status`, timestamps, and tags
- **`KnowledgeBaseTableMode`** — `'standard'` (created date) or `'archive'` (updated date) display mode
- **`KnowledgeBaseRowType`** — `'ARTICLE' | 'FOLDER' | string`
- **`KnowledgeBaseRowStatus`** — `'DRAFT' | 'PUBLISHED' | 'ARCHIVED' | string | null | undefined`

### Exports
- **`knowledgeBaseRowHref(item)`** — Resolves navigation href: `/knowledge-base/details/:id` for articles, `/knowledge-base/folders/:id` for folders
- **`KNOWLEDGE_BASE_OPEN_COLUMN`** — Static column definition rendering an "open in new tab" icon button
- **`getKnowledgeBaseColumns(mode)`** — Returns `name` + date column definitions based on the current mode; shows `DRAFT`/`ARCHIVED` status tags inline with the name
- **`KnowledgeBaseTableBody`** — Full table component composing columns, `useDataTable`, and `DataTable` sub-components with sticky header, skeleton loading, empty state, and optional footer/actions slot

## Usage Example

```typescript
import {
  KnowledgeBaseTableBody,
  type KnowledgeBaseRow,
} from './knowledge-base-table-columns';

const items: KnowledgeBaseRow[] = [
  {
    id: '1',
    type: 'ARTICLE',
    name: 'Getting Started',
    status: 'PUBLISHED',
    summary: 'A quick start guide.',
    createdAt: '2024-01-15T10:00:00Z',
  },
  {
    id: '2',
    type: 'FOLDER',
    name: 'Guides',
  },
];

export function MyKnowledgeBase() {
  return (
    <KnowledgeBaseTableBody
      items={items}
      mode="standard"
      totalCount={42}
      emptyMessage="No articles yet."
      stickyHeaderOffset="64px"
    />
  );
}
```
