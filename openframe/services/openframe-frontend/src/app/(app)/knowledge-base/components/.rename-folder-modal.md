Modal component for renaming an existing folder, pre-populating the input with the current folder name and submitting via the `useRenameFolder` hook.

## Key Components

- **`RenameFolderModal`** — Main modal component rendering a labeled text input and Save/Cancel actions
- **`RenameFolderTarget`** — Exported interface representing the folder to rename (`id`, `name`)
- **`useRenameFolder`** — Hook handling the rename mutation and pending state
- **`canSubmit` guard** — Submission is blocked if the trimmed name is empty, unchanged from the original, or a request is in flight

## Usage Example

```typescript
import { RenameFolderModal } from './rename-folder-modal';

function FolderList() {
  const [target, setTarget] = useState<RenameFolderTarget | null>(null);

  return (
    <>
      <button onClick={() => setTarget({ id: 'folder-123', name: 'My Documents' })}>
        Rename
      </button>

      <RenameFolderModal
        isOpen={!!target}
        onClose={() => setTarget(null)}
        folder={target}
      />
    </>
  );
}
```

## Behaviour Notes

- Input is pre-filled with `folder.name` whenever the modal opens (`useEffect` on `isOpen`)
- Supports **Enter** key submission via `handleKeyDown`
- Displays a success toast with the new name on completion, then closes automatically
- Save button shows `"Saving…"` with a loading spinner while the request is pending
