Modal component for renaming an existing folder. Renders a labeled text input pre-filled with the current folder name and submits the new name via the `useRenameFolder` hook.

## Key Components

- **`RenameFolderModal`** — Main component. Accepts `isOpen`, `onClose`, and a `folder` target object, then manages local name state and submission logic.
- **`RenameFolderTarget`** — Exported interface describing the minimal folder shape (`id`, `name`) required by the modal.
- **`canSubmit`** — Derived boolean that gates submission: name must be non-empty, different from the original, and no request must be in flight.
- **`handleKeyDown`** — Allows submitting the form via `Enter` key.
- **`useRenameFolder`** — Hook encapsulating the rename mutation and its `isPending` state.

## Usage Example

```typescript
import { RenameFolderModal } from './rename-folder-modal';

const [open, setOpen] = useState(false);
const folder = { id: 'folder-123', name: 'My Documents' };

<RenameFolderModal
  isOpen={open}
  onClose={() => setOpen(false)}
  folder={folder}
/>
```

## Behavior Notes

- The input is pre-populated with `folder.name` each time the modal opens via a `useEffect` dependency on `isOpen` and `folder`.
- On successful rename, a success toast is shown and `onClose` is called automatically.
- Both Cancel and Save buttons are disabled while the rename request is pending; Save also shows a `"Saving..."` label during the operation.
