Modal component for renaming an existing folder, pre-populating the input with the current folder name and submitting via the `useRenameFolder` hook.

## Key Components

- **`RenameFolderModal`** — Main modal component rendering a labeled text input and Cancel/Save action buttons
- **`RenameFolderTarget`** — Exported interface defining the `id` and `name` of the folder to rename
- **`canSubmit`** — Derived boolean guard: submit is enabled only when the trimmed name is non-empty, differs from the original, and no request is pending
- **`handleKeyDown`** — Allows submitting via the `Enter` key when the input is focused

## Usage Example

```typescript
import { RenameFolderModal } from './rename-folder-modal';

function FolderActions() {
  const [isOpen, setIsOpen] = useState(false);
  const folder = { id: 'folder-123', name: 'My Documents' };

  return (
    <>
      <button onClick={() => setIsOpen(true)}>Rename</button>
      <RenameFolderModal
        isOpen={isOpen}
        onClose={() => setIsOpen(false)}
        folder={folder}
      />
    </>
  );
}
```

## Behaviour Notes

- Input is pre-filled with the current folder name whenever the modal opens (`useEffect` on `isOpen` + `folder`)
- Save button shows a loading state (`isPending`) and the label changes to `Saving…` during the mutation
- On success, a toast notification is displayed and `onClose` is called automatically
