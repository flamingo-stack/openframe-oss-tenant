A React hook that manages folder row action menus (rename, move, delete) and their associated modal dialogs for file/folder management UI.

## Key Components

### `FolderActionTarget`
Interface representing the minimal folder data needed for actions — `id` and `name`.

### `useFolderRowActions(args)`
Custom hook that encapsulates folder action state and modal rendering.

**Parameters:**
- `sourceConnectionId` — connection context for move/delete operations
- `onDeleted?` — optional callback fired after successful deletion

**Returns:** `FolderRowActions`
- `buildMenuGroups(folder)` — builds an `ActionsMenuGroup[]` with Rename, Move, and Delete actions for a given folder
- `modals` — a `ReactNode` containing all three modal dialogs, wired to internal state

## Usage Example

```typescript
import { useFolderRowActions } from './folder-row-actions';

function FolderList({ connectionId }: { connectionId: string }) {
  const { buildMenuGroups, modals } = useFolderRowActions({
    sourceConnectionId: connectionId,
    onDeleted: () => refetchFolders(),
  });

  return (
    <>
      {folders.map((folder) => (
        <FolderRow
          key={folder.id}
          folder={folder}
          menuGroups={buildMenuGroups(folder)}
        />
      ))}
      {modals}
    </>
  );
}
```

## Notes

- `buildMenuGroups` is memoized with `useCallback` to prevent unnecessary re-renders
- Modal visibility is controlled by nullable state — a `null` target means the modal is closed
- Modals (`RenameFolderModal`, `MoveToFolderModal`, `DeleteFolderModal`) are rendered once at the parent level rather than per-row, avoiding DOM bloat
