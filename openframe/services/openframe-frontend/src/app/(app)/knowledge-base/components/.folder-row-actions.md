A React hook that manages folder row action menus and their associated modals, providing rename, move, and delete operations for folders.

## Key Components

**`FolderActionTarget`** — Interface defining the minimal folder data (`id`, `name`) required to trigger actions.

**`useFolderRowActions(args)`** — Custom hook returning:
- `buildMenuGroups(folder)` — Builds an `ActionsMenuGroup[]` with Rename, Move, and Delete menu items for a given folder
- `modals` — A pre-rendered `ReactNode` containing the three controlled modals (`RenameFolderModal`, `MoveToFolderModal`, `DeleteFolderModal`)

Each action sets local state to target the selected folder, which drives modal visibility via the `isOpen` prop pattern.

## Usage Example

```typescript
function FolderRow({ folder, sourceConnectionId }) {
  const { buildMenuGroups, modals } = useFolderRowActions({
    sourceConnectionId,
    onDeleted: () => refetch(),
  });

  return (
    <>
      <ActionsMenu groups={buildMenuGroups(folder)} />
      {modals}
    </>
  );
}
```

> **Note:** `modals` should be rendered once per hook instance — typically adjacent to the trigger element. The `sourceConnectionId` prop is forwarded to `MoveToFolderModal` and `DeleteFolderModal` for scoping API operations to the correct connection. The `onDeleted` callback is optional and fires after a successful delete.
