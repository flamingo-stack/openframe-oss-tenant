A React hook that manages folder row action menus (rename, move, delete) and their associated modals for file/folder management UI.

## Key Components

- **`useFolderRowActions`** — Custom hook returning a menu group builder and pre-wired modal nodes
- **`FolderActionTarget`** — Interface describing the minimal folder data (`id`, `name`) needed to trigger actions
- **`buildMenuGroups`** — Memoized function that constructs the `ActionsMenuGroup[]` array for a given folder, wiring each item to open its corresponding modal
- **`modals`** — Pre-rendered `ReactNode` containing `RenameFolderModal`, `MoveToFolderModal`, and `DeleteFolderModal`, each driven by local state

## Usage Example

```typescript
import { useFolderRowActions } from './folder-row-actions';

function FolderTable({ folders, connectionId }) {
  const { buildMenuGroups, modals } = useFolderRowActions({
    sourceConnectionId: connectionId,
    onDeleted: () => refetch(),
  });

  return (
    <>
      {folders.map((folder) => (
        <FolderRow
          key={folder.id}
          folder={folder}
          menuGroups={buildMenuGroups(folder)}
        />
      ))}
      {/* Render all modals once at the parent level */}
      {modals}
    </>
  );
}
```

## Notes

- `buildMenuGroups` is memoized with `useCallback` (no dependencies) — safe to call per-row without re-renders
- Modal visibility is controlled via nullable state targets; passing `null` closes the modal
- `onDeleted` callback is forwarded only to `DeleteFolderModal`, allowing parent components to react post-deletion (e.g., cache invalidation or list refresh)
