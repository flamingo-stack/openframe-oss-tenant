Modal component for creating new folders within a file/document management system, supporting parent folder nesting and connection-scoped creation.

## Key Components

- **`NewFolderModalProps`** — Interface defining `isOpen`, `onClose`, `parentFolderId`, `parentConnectionId`, and optional `onCreated` callback
- **`NewFolderModal`** — Main export; a controlled modal wrapping `SimpleModal` with a labeled text input and Cancel/Create action buttons
- **`useCreateFolder`** — Custom hook handling the async folder creation API call and pending state
- **`handleSubmit`** — Async handler that trims the name, calls `createFolder`, shows a success toast, invokes `onCreated` with the new folder ID, and closes the modal
- **`handleKeyDown`** — Enables `Enter` key submission when input is valid
- Name state is reset to `''` whenever the modal closes via a `useEffect` on `isOpen`

## Usage Example

```typescript
import { NewFolderModal } from './new-folder-modal';

function FileExplorer() {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <>
      <Button onClick={() => setIsOpen(true)}>New Folder</Button>

      <NewFolderModal
        isOpen={isOpen}
        onClose={() => setIsOpen(false)}
        parentFolderId="folder-abc"
        parentConnectionId="conn-123"
        onCreated={(folderId) => {
          console.log('Created folder:', folderId);
          // e.g. navigate into the new folder
        }}
      />
    </>
  );
}
```
