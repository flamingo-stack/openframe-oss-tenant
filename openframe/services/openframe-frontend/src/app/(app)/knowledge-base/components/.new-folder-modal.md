Modal component for creating a new folder within a file/document management context. Renders a simple dialog with a name input field and handles folder creation via an async mutation hook.

## Key Components

- **`NewFolderModal`** — Primary exported component; wraps `SimpleModal` with a controlled input and submit logic
- **`NewFolderModalProps`** — Interface defining required connection context (`parentConnectionId`), optional parent folder (`parentFolderId`), open state, and callbacks
- **`useCreateFolder`** — Custom hook (external) providing `createFolder` mutation and `isPending` state
- **`handleSubmit`** — Async handler that trims the name, calls `createFolder`, shows a success toast, fires `onCreated` callback, and closes the modal
- **`handleKeyDown`** — Allows `Enter` key to trigger submission when the input is focused
- **Reset on close** — `useEffect` clears the name field whenever `isOpen` transitions to `false`

## Usage Example

```typescript
import { NewFolderModal } from './new-folder-modal';

function FileExplorer() {
  const [showModal, setShowModal] = useState(false);

  return (
    <>
      <Button onClick={() => setShowModal(true)}>New Folder</Button>

      <NewFolderModal
        isOpen={showModal}
        onClose={() => setShowModal(false)}
        parentConnectionId="conn_abc123"
        parentFolderId="folder_xyz"
        onCreated={(folderId) => {
          console.log('Created folder:', folderId);
        }}
      />
    </>
  );
}
```

**Submission guard:** The `canSubmit` flag requires a non-empty trimmed name and no in-flight request, preventing double-submits or empty folder names.
