Modal component for creating a new folder within a specified parent connection, handling name input, submission state, and success/error feedback.

## Key Components

- **`NewFolderModalProps`** — Interface defining modal configuration:
  - `isOpen` / `onClose` — visibility control
  - `parentFolderId` — optional parent folder (defaults to `null` for root)
  - `parentConnectionId` — required connection scope for the new folder
  - `onCreated` — optional callback receiving the newly created folder's ID

- **`NewFolderModal`** — Main exported component that:
  - Resets the name field on close via `useEffect`
  - Delegates creation to the `useCreateFolder` hook
  - Supports `Enter` key submission
  - Shows a success toast on folder creation
  - Disables controls and shows a loading state while `isPending`

## Usage Example

```typescript
import { NewFolderModal } from './new-folder-modal';

function FileExplorer() {
  const [showModal, setShowModal] = useState(false);

  return (
    <>
      <Button onClick={() => setShowModal(true)}>New Folder</Button>
      <NewFolderModal
        isOpen={showModal}
        onClose={() => setShowModal(false)}
        parentConnectionId="conn_abc123"
        parentFolderId="folder_xyz"
        onCreated={(folderId) => console.log('Created:', folderId)}
      />
    </>
  );
}
```
