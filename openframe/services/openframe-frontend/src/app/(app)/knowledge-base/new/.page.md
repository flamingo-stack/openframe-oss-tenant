Client-side page component for creating a new knowledge base article, gated behind a feature flag.

## Key Components

- **`NewArticlePageWrapper`** — Default export; reads optional `folderId` from the URL query string and renders the article creation form. Returns a 404 if the `knowledgeBase` feature flag is disabled.
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring query params are always read at request time.

## Usage Example

```typescript
// Navigate to this page with an optional pre-selected folder:
// /knowledge-base/articles/new?folderId=abc123

// The component resolves to:
<ArticleFormPage articleId={null} initialFolderId="abc123" />
```
