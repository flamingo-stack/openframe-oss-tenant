Client-side page component that renders the new knowledge base article creation form, gated behind a feature flag.

## Key Components

- **`NewArticlePageWrapper`** — Default export; checks if the knowledge base feature is enabled (returns 404 if not), reads an optional `folderId` query parameter, and renders `ArticleFormPage` in creation mode (`articleId={null}`)
- **`featureFlags.knowledgeBase.enabled()`** — Feature gate; redirects to 404 if the knowledge base module is disabled
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring query params are always read at request time

## Usage Example

```typescript
// Accessed via: /knowledge-base/articles/new?folderId=abc123
// Renders ArticleFormPage with no existing article and a pre-selected folder

<NewArticlePageWrapper />
// → <ArticleFormPage articleId={null} initialFolderId="abc123" />
```

## Notes

- `folderId` is optional; if omitted, `initialFolderId` is `null`
- The page is marked `'use client'` due to `useSearchParams()` usage
- Feature flag gating ensures the route is inaccessible when the knowledge base module is turned off
