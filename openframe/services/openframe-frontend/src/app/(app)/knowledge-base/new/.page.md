Client-side page component that renders the new article creation form within the Knowledge Base feature.

## Key Components

- **`NewArticlePageWrapper`** — Default export; reads the optional `folderId` query parameter and renders `ArticleFormPage` in "create" mode (`articleId={null}`). Returns a 404 if the `knowledgeBase` feature flag is disabled.
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring query parameters are always read at request time.

## Usage Example

```typescript
// Accessed via navigation:
// /knowledge-base/articles/new
// /knowledge-base/articles/new?folderId=abc123

// ArticleFormPage receives:
<ArticleFormPage articleId={null} initialFolderId="abc123" />
```

## Notes

- Guarded by `featureFlags.knowledgeBase.enabled()` — unauthenticated or flag-disabled requests receive a 404.
- `folderId` is optional; when present, pre-selects the target folder in the article form.
