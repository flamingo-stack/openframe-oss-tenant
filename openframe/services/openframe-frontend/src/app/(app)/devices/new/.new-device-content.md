A client-side React component that renders the "New Device" onboarding page, allowing technicians to generate, copy, and download platform-specific agent installation commands for a selected customer organization.

## Key Components

| Export/Hook | Description |
|---|---|
| `NewDeviceContent` | Main page component — form, command generation, and actions |
| `newDeviceContentQuery` | Relay GraphQL query fetching up to 100 organizations |
| `newDeviceSchema` | Zod schema validating `organizationId` and `platform` |
| `useInstallCommand` | Derives the install command string from org/platform/tags |
| `validateBeforeAction` | Guards copy/run actions — checks form, secret, tag validity, and tag uniqueness |

## Usage Example

```typescript
// Rendered automatically by the /devices/new route.
// Pre-select a customer via query param:
// /devices/new?organizationId=<organizationId>

import { NewDeviceContent } from './new-device-content';

// Inside a Suspense boundary (required by useLazyLoadQuery):
export default function NewDevicePage() {
  return (
    <Suspense fallback={<Spinner />}>
      <NewDeviceContent />
    </Suspense>
  );
}
```

## Behavior Notes

- **Org pre-selection priority:** `?organizationId` query param → default org → first org in list
- **Copy Command:** Validates form + tags, then copies the generated install command to clipboard
- **Run on Current Machine:** Validates platform matches the browser's OS, then downloads a ready-to-run `.ps1` (Windows) or `.sh` (macOS/Linux) script
- **Tags:** Deduplicates and strips invalid entries before embedding them in the install command; enforces alphanumeric/`_`/`-`/`.` characters only
