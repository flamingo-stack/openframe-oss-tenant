React client component that renders the "New Device" onboarding form, allowing technicians to generate, copy, or download a platform-specific agent installation command for a selected customer organization.

## Key Components

| Export / Hook | Purpose |
|---|---|
| `NewDeviceContent` | Main page component — form + install command UI |
| `newDeviceContentQuery` | Relay GraphQL query fetching up to 100 organizations |
| `newDeviceSchema` | Zod schema validating `organizationId` + `platform` |
| `useInstallCommand` | Derives the install command string from org/platform/tags |
| `validateBeforeAction` | Guards copy/run actions with form + tag validation |
| `copyCommand` | Copies generated command to clipboard |
| `runOnCurrentMachine` | Detects OS, generates a shell/PowerShell script, triggers download |

## Usage Example

```typescript
// Rendered by the /devices/new route.
// Optionally pre-selects an organization via query param:
// /devices/new?organizationId=<orgId>

import { NewDeviceContent } from './new-device-content';

export default function NewDevicePage() {
  return (
    <Suspense fallback={<Spinner />}>
      <NewDeviceContent />
    </Suspense>
  );
}
```

## Behavior Notes

- **Org pre-selection priority:** `?organizationId` query param → default org → first org in list
- **Tag validation:** Duplicate keys and invalid characters (only `[a-zA-Z0-9._-]` allowed) are rejected before any action
- **Platform mismatch guard:** `runOnCurrentMachine` cross-checks `navigator.userAgent` against the selected platform before downloading the script
- **Script output:**
  - `windows` → `install-openframe.ps1` (PowerShell)
  - `darwin`/`linux` → `install-openframe.sh` (Bash)
- **`AntivirusWarning`** is rendered conditionally based on the selected platform to alert technicians about AV false positives
