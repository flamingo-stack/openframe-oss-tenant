Client-side page component that renders the "New Device" form with a Suspense boundary to handle async loading states.

## Key Components

- **`dynamic`** — Exported constant set to `'force-dynamic'` to disable static rendering, required because child components use `useSearchParams` via `AppLayout`
- **`NewDevicePage`** — Default page export wrapping `NewDeviceContent` in a `Suspense` boundary with `NewDeviceSkeleton` as the fallback UI

## Usage Example

```typescript
// Rendered automatically by Next.js App Router at the /devices/new route.
// No direct invocation needed — Next.js uses the default export.

// Suspense boundary pattern used internally:
<Suspense fallback={<NewDeviceSkeleton />}>
  <NewDeviceContent />
</Suspense>
```

## Notes

- The `'use client'` directive marks this as a Client Component, enabling React hooks in the subtree
- `force-dynamic` prevents build-time static generation, ensuring `useSearchParams` is always evaluated at request time — omitting this would cause a Next.js runtime warning/error
