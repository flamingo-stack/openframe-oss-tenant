Client-side page component that renders the "New Device" form, wrapping the main content in a `Suspense` boundary to display a skeleton loader while the content loads.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `NewDevicePage` | Default export | Page component with `Suspense` + skeleton fallback |
| `dynamic` | Named export | Forces dynamic rendering to support `useSearchParams` in layout |

## Usage Example

```typescript
// Rendered automatically by Next.js App Router at the /new-device route.
// No manual usage required — Next.js resolves this as a page component.

// The Suspense boundary handles async loading states:
<Suspense fallback={<NewDeviceSkeleton />}>
  <NewDeviceContent />
</Suspense>
```

## Notes

- `'use client'` directive enables client-side rendering
- `dynamic = 'force-dynamic'` prevents static generation, required when `useSearchParams` is used in `AppLayout`
- `NewDeviceSkeleton` provides a placeholder UI during content load
