Loading state skeleton component for the "New Device" page, displaying placeholder UI while content is being fetched.

## Key Components

- **`NewDeviceSkeleton`** — A functional component that renders animated skeleton placeholders matching the layout of the new device form, including breadcrumb, organization/platform selectors, tag section, command box, and antivirus warning panel.

## Usage Example

```typescript
import { NewDeviceSkeleton } from './new-device-skeleton';

function NewDevicePage() {
  if (isLoading) return <NewDeviceSkeleton />;
  return <NewDeviceForm />;
}
```

## Layout Structure

| Section | Skeleton Shape |
|---|---|
| Breadcrumb | `h-5 w-40` text bar |
| Page title | `h-9 w-32` heading bar |
| Org + Platform selectors | Two full-width `h-12` input bars |
| Add Device Tag | Circle icon + text bar |
| Command box | Title, multiline textarea, two action buttons |
| Antivirus warning | Banner, description, 5 list items, footer note |
