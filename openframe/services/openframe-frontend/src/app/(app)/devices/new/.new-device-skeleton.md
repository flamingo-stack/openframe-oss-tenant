Loading state placeholder component for the "New Device" page, rendering a skeleton UI that mirrors the layout of the actual form while content is being fetched.

## Key Components

- **`NewDeviceSkeleton`** — A single exported functional component that renders shimmer placeholders matching the structural layout of the new device registration page.

## Layout Sections

| Section | Skeleton Elements |
|---|---|
| Breadcrumb / title | Narrow bar + heading block |
| Organization + Platform | Two full-width input-height blocks (2-col grid on `md+`) |
| Add Device Tag | Circle icon + label bar |
| Command box | Title, command textarea, two action buttons |
| Antivirus warning | Banner, description line, 5 list rows, footnote |

## Usage Example

```typescript
import { NewDeviceSkeleton } from './new-device-skeleton';

// Render while the new-device page data is loading
function NewDevicePage() {
  const { isLoading } = useNewDeviceData();

  if (isLoading) return <NewDeviceSkeleton />;

  return <NewDeviceForm />;
}
```

## Notes

- Uses `DetailPageContainer` with `padding="none"` and an ODS spacing variable override (`p-[var(--spacing-system-l)]`) for consistent page chrome.
- `Skeleton` components are sourced from the shared UI library — they inherit the platform's dark-mode ODS tokens automatically.
- The antivirus warning section renders **5 skeleton rows** via `Array.map` to match the expected list length without hardcoding repeated JSX.
