Loading state placeholder component that renders a skeleton screen for the "New Device" page, mimicking the layout of the actual form before content loads.

## Key Components

- **`NewDeviceSkeleton`** — Default exported functional component that renders animated skeleton placeholders matching the structure of the new device registration form, including:
  - Breadcrumb/title area
  - Organization + Platform selector fields (2-column grid)
  - Add Device Tag row
  - Command box section (title, command area, action buttons)
  - Antivirus warning section (banner, description, 5 list items, footer note)

## Usage Example

```typescript
import { NewDeviceSkeleton } from './new-device-skeleton';

// Render while device form data or dependencies are loading
function NewDevicePage() {
  const { isLoading } = useDeviceFormData();

  if (isLoading) return <NewDeviceSkeleton />;

  return <NewDeviceForm />;
}
```

> **Note:** Uses `DetailPageContainer` with `padding="none"` and a system-level spacing variable (`--spacing-system-l`) to maintain layout consistency with the real page. Skeleton shapes are sized to closely match their live counterparts, ensuring a stable layout shift-free loading experience.
