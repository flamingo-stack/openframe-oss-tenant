React hook providing archive and delete actions for devices, with loading state tracking and toast notifications for success/error feedback.

## Key Components

- **`useDeviceActions(options?)`** — Main hook accepting optional `onSuccess` callback
- **`archiveDevice(deviceId, deviceName?)`** — PATCHes device status to `ARCHIVED`, returns `Promise<boolean>`
- **`deleteDevice(deviceId, deviceName?)`** — PATCHes device status to `DELETED`, returns `Promise<boolean>`
- **`isArchiving`** / **`isDeleting`** — Individual loading states per action
- **`isProcessing`** — Combined loading flag (`isArchiving || isDeleting`)

## Usage Example

```typescript
import { useDeviceActions } from './use-device-actions';

function DeviceRow({ device }) {
  const { archiveDevice, deleteDevice, isProcessing } = useDeviceActions({
    onSuccess: () => refetchDevices(),
  });

  return (
    <>
      <button
        onClick={() => archiveDevice(device.id, device.name)}
        disabled={isProcessing}
      >
        Archive
      </button>
      <button
        onClick={() => deleteDevice(device.id, device.name)}
        disabled={isProcessing}
      >
        Delete
      </button>
    </>
  );
}
```

> Both actions display a destructive toast on failure and call `onSuccess` only on successful API response. The `deviceName` parameter is optional — `deviceId` is used as fallback in toast messages.
