React hook for managing device lifecycle actions (archive and delete) with built-in loading state tracking and toast notifications.

## Key Components

**`useDeviceActions(options?)`** — Main hook export that provides device mutation actions.

**Options**
- `onSuccess?: () => void` — Optional callback invoked after any successful action.

**Returns**

| Property | Type | Description |
|---|---|---|
| `archiveDevice` | `(deviceId, deviceName?) => Promise<boolean>` | Sets device status to `ARCHIVED` |
| `deleteDevice` | `(deviceId, deviceName?) => Promise<boolean>` | Sets device status to `DELETED` |
| `isArchiving` | `boolean` | Loading state for archive operation |
| `isDeleting` | `boolean` | Loading state for delete operation |
| `isProcessing` | `boolean` | `true` if either operation is in progress |

Both action functions return `true` on success and `false` on failure, and automatically display toast notifications for both outcomes.

## Usage Example

```typescript
import { useDeviceActions } from './use-device-actions';

function DeviceCard({ device, onRefresh }) {
  const { archiveDevice, deleteDevice, isProcessing } = useDeviceActions({
    onSuccess: onRefresh,
  });

  return (
    <div>
      <button
        disabled={isProcessing}
        onClick={() => archiveDevice(device.id, device.name)}
      >
        Archive
      </button>
      <button
        disabled={isProcessing}
        onClick={() => deleteDevice(device.id, device.name)}
      >
        Delete
      </button>
    </div>
  );
}
```

> Both `archiveDevice` and `deleteDevice` use `PATCH /api/devices/:id` with a `status` payload, relying on the shared `apiClient` for request handling.
