React hook managing MeshCentral file manager connections, state, and file operations (upload, download, navigation, clipboard) for remote/local device file systems.

## Key Components

- **`useMeshFileManager`** — Primary exported hook accepting `meshcentralAgentId`, `isRemote`, and `onError` options
- **`activeFileManagers`** — Module-level `Map` preventing duplicate connections in React Strict Mode
- **`MeshCentralFileManager`** — Underlying file manager class managing WebSocket-based file operations
- **`ClipboardItem`** — Internal interface tracking copy/cut operations with source path and file IDs
- **`getDirectoryFromFileIds`** — Helper extracting parent directory path from file ID strings

## Usage Example

```typescript
import { useMeshFileManager } from './use-mesh-file-manager';

function DeviceFileManager({ agentId }: { agentId: string }) {
  const {
    files,
    currentPath,
    connectionState,
    loading,
    uploadProgress,
    navigateToPath,
    navigateInto,
    navigateUp,
    uploadFile,
    downloadFile,
    createFolder,
    deleteItems,
    handleFileAction,
    copyToClipboard,
    pasteFiles,
  } = useMeshFileManager({
    meshcentralAgentId: agentId,
    isRemote: true,
    onError: (err) => console.error('File manager error:', err),
  });

  if (connectionState === 'connecting') return <div>Connecting...</div>;

  return (
    <FileManagerUI
      files={files}
      currentPath={currentPath}
      loading={loading}
      uploadProgress={uploadProgress}
      onNavigate={navigateToPath}
      onNavigateInto={navigateInto}
      onNavigateUp={navigateUp}
      onUpload={uploadFile}
      onDownload={downloadFile}
      onCreateFolder={createFolder}
      onDelete={deleteItems}
      onAction={handleFileAction}
    />
  );
}
```

## State Managed

| State | Type | Description |
|-------|------|-------------|
| `files` | `FileItem[]` | Current directory listing |
| `currentPath` | `string` | Active directory path |
| `connectionState` | `FileConnectionState` | `disconnected` / `connecting` / `connected_end_to_end` / `failed` |
| `uploadProgress` / `downloadProgress` | `FileTransferProgress \| null` | Active transfer progress |
| `clipboard` | `ClipboardItem \| null` | Pending copy/cut operation |
| `isSearching` | `boolean` | Search operation in progress |
