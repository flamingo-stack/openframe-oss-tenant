React hook that manages MeshCentral file manager connections, providing file system operations (navigate, upload, download, search, clipboard) for remote or local agent devices.

## Key Components

**`useMeshFileManager(options)`** — Primary hook export accepting:
- `meshcentralAgentId` — Target device agent ID
- `isRemote` — Whether connecting to a remote or server-side file system (default: `true`)
- `onError` — Optional error callback

**Returned State**
| Field | Type | Description |
|---|---|---|
| `files` | `FileItem[]` | Current directory listing |
| `currentPath` | `string` | Active directory path |
| `connectionState` | `FileConnectionState` | `'disconnected'` \| `'connecting'` \| `'connected_end_to_end'` \| `'failed'` |
| `uploadProgress` / `downloadProgress` | `FileTransferProgress \| null` | Active transfer state |
| `clipboard` | `ClipboardItem \| null` | Copy/cut clipboard state |

**Internal Protections**
- `activeFileManagers` — Module-level `Map` prevents duplicate connections under React Strict Mode double-invocation
- `initTokenRef` — Cancellation token aborts in-flight initialization on unmount

## Usage Example

```typescript
import { useMeshFileManager } from './use-mesh-file-manager';

function RemoteFileManager({ agentId }: { agentId: string }) {
  const {
    files,
    currentPath,
    connectionState,
    loading,
    navigateInto,
    navigateUp,
    uploadFile,
    downloadFile,
    copyToClipboard,
    pasteFiles,
    handleFileAction,
  } = useMeshFileManager({
    meshcentralAgentId: agentId,
    isRemote: true,
    onError: (err) => console.error('FM error:', err),
  });

  if (connectionState !== 'connected_end_to_end') {
    return <p>Status: {connectionState}</p>;
  }

  return (
    <FileManagerUI
      files={files}
      path={currentPath}
      loading={loading}
      onFolderOpen={navigateInto}
      onNavigateUp={navigateUp}
      onUpload={uploadFile}
      onDownload={downloadFile}
      onAction={handleFileAction}
    />
  );
}
```

> **Note:** The hook automatically disconnects and cleans up the `MeshCentralFileManager` and `MeshControlClient` instances on unmount, including cancelling any in-progress initialization.
