React hook that manages a MeshCentral remote file manager session, handling WebSocket connection lifecycle, directory navigation, file transfers, search, and clipboard operations for a target device.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `useMeshFileManager` | Hook | Primary hook that initializes and manages a `MeshCentralFileManager` instance |
| `UseMeshFileManagerOptions` | Interface | Input options: `meshcentralAgentId`, `isRemote`, `onError` |
| `UseMeshFileManagerReturn` | Interface | Full API surface returned by the hook |
| `ClipboardItem` | Interface | Internal clipboard state tracking copy/cut operations |
| `activeFileManagers` | `Map<string, boolean>` | Module-level guard preventing duplicate connections under React Strict Mode |

### Returned Actions

| Action | Description |
|--------|-------------|
| `navigateToPath` / `navigateUp` / `navigateInto` | Directory traversal |
| `createFolder` / `deleteItems` / `renameItem` | Filesystem mutations |
| `uploadFile` / `downloadFile` | File transfer with progress tracking |
| `searchFiles` / `cancelSearch` | Recursive file search |
| `copyToClipboard` / `cutFiles` / `pasteFiles` | Clipboard-based copy/move |
| `handleFileAction` | Unified dispatcher for UI-triggered `FileAction` events |

## Usage Example

```typescript
import { useMeshFileManager } from './use-mesh-file-manager';

function RemoteFileManager({ agentId }: { agentId: string }) {
  const {
    files,
    currentPath,
    connectionState,
    loading,
    uploadProgress,
    navigateToPath,
    navigateInto,
    navigateUp,
    uploadFile,
    downloadFile,
    handleFileAction,
  } = useMeshFileManager({
    meshcentralAgentId: agentId,
    isRemote: true,
    onError: (err) => console.error('File manager error:', err),
  });

  if (connectionState === 'connecting') return <Spinner />;

  return (
    <FileManagerUI
      files={files}
      currentPath={currentPath}
      loading={loading}
      uploadProgress={uploadProgress}
      onNavigate={navigateToPath}
      onNavigateUp={navigateUp}
      onFolderOpen={navigateInto}
      onUpload={uploadFile}
      onDownload={downloadFile}
      onAction={handleFileAction}
    />
  );
}
```

> **Note:** The module-level `activeFileManagers` map prevents duplicate connections when React Strict Mode double-invokes effects. The hook cancels in-flight initialization via a `token.cancelled` flag on unmount.
