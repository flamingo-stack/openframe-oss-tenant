Fetches and manages the active agent registration secret from the API, auto-loading on mount and exposing state for loading, error handling, and manual refetch.

## Key Components

- **`useRegistrationSecret`** — Custom React hook that retrieves the active registration secret via `GET /api/agent/registration-secret/active`, wiring together loading state, error handling, and toast notifications.

| Return Value | Type | Description |
|---|---|---|
| `initialKey` | `string` | The active registration secret key |
| `isLoading` | `boolean` | `true` while the request is in flight |
| `error` | `string \| null` | Error message if the fetch failed |
| `refetch` | `() => Promise<void>` | Manually re-triggers the fetch |

## Usage Example

```typescript
import { useRegistrationSecret } from '@/hooks/use-registration-secret';

export function RegistrationSecretPanel() {
  const { initialKey, isLoading, error, refetch } = useRegistrationSecret();

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error} onRetry={refetch} />;

  return (
    <div>
      <code>{initialKey}</code>
      <button onClick={refetch}>Refresh</button>
    </div>
  );
}
```

> The hook auto-fetches on mount — no manual call needed on initial render. Use `refetch` to re-validate the secret after rotation or on user demand. Errors are surfaced both via the `error` return value and a destructive toast notification.
