Fetches and manages the active agent registration secret via the `/api/agent/registration-secret/active` endpoint, exposing loading and error state for use in registration UI components.

## Key Components

- **`useRegistrationSecret`** — Custom React hook that auto-fetches the active registration secret on mount and exposes controls for manual refetching.

### Returned Values

| Property | Type | Description |
|----------|------|-------------|
| `initialKey` | `string` | The active registration secret key |
| `isLoading` | `boolean` | `true` while the fetch is in progress |
| `error` | `string \| null` | Error message if the fetch failed |
| `refetch` | `() => Promise<void>` | Manually re-trigger the secret fetch |

## Usage Example

```typescript
import { useRegistrationSecret } from './use-registration-secret';

export function AgentRegistrationForm() {
  const { initialKey, isLoading, error, refetch } = useRegistrationSecret();

  if (isLoading) return <Spinner />;
  if (error) return <ErrorBanner message={error} onRetry={refetch} />;

  return (
    <SecretKeyDisplay
      value={initialKey}
      onRotate={refetch}
    />
  );
}
```

> On mount, the hook automatically calls `/api/agent/registration-secret/active`. If the request fails, a destructive toast notification is displayed and the error is surfaced via the `error` property for in-component handling.
