Fetches and manages the active agent registration secret from the API, auto-loading on mount and exposing refetch capability.

## Key Components

- **`useRegistrationSecret`** — Custom React hook that retrieves the active registration secret via `GET /api/agent/registration-secret/active`, manages loading/error state, and displays a destructive toast on failure.

| Return Value | Type | Description |
|---|---|---|
| `initialKey` | `string` | The active registration secret key |
| `isLoading` | `boolean` | Fetch in-progress indicator |
| `error` | `string \| null` | Error message if fetch failed |
| `refetch` | `() => Promise<void>` | Manually re-trigger the fetch |

## Usage Example

```typescript
import { useRegistrationSecret } from './use-registration-secret';

function RegistrationSecretPanel() {
  const { initialKey, isLoading, error, refetch } = useRegistrationSecret();

  if (isLoading) return <Spinner />;
  if (error) return <button onClick={refetch}>Retry</button>;

  return (
    <div>
      <code>{initialKey}</code>
      <button onClick={refetch}>Refresh Secret</button>
    </div>
  );
}
```

> The hook auto-fetches on mount via `useEffect`, so no manual call is needed for initial load. Use `refetch` only when a manual refresh is required (e.g., after secret rotation).
