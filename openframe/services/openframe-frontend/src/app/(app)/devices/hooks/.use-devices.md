React Query infinite scroll hook for fetching paginated device data from a GraphQL endpoint, with built-in error toasting and flat device list transformation.

## Key Components

- **`devicesQueryKeys`** — Structured cache key factory for React Query; scoped to `['devices', 'list', filters, search]` to enable granular cache invalidation.
- **`useDevices(filters, search)`** — Primary hook wrapping `useInfiniteQuery` that handles pagination, error display, and data normalization.
- **`DEVICES_PAGE_SIZE`** — Constant (20) controlling the cursor-based pagination page size.
- **`DevicesPage`** — Internal interface describing a single page of results including `pageInfo` cursors and `filteredCount`.

## Usage Example

```typescript
import { useDevices } from './use-devices';

function DeviceList() {
  const {
    devices,
    isLoading,
    isFetchingNextPage,
    hasNextPage,
    fetchNextPage,
    filteredCount,
    refetch,
  } = useDevices({ status: 'online' }, 'workstation');

  if (isLoading) return <Spinner />;

  return (
    <>
      <p>{filteredCount} devices found</p>
      {devices.map(device => (
        <DeviceCard key={device.id} device={device} />
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()} disabled={isFetchingNextPage}>
          {isFetchingNextPage ? 'Loading...' : 'Load More'}
        </button>
      )}
    </>
  );
}
```

## Behavior Notes

- Pages are **flattened** via `flatMap` so consumers receive a single `Device[]` array.
- Results are sorted server-side by `status DESC` and cached for **30 seconds** (`staleTime`).
- Errors surface automatically as a destructive toast via `useToast`; the raw message is also returned as `error` for inline handling.
- `filteredCount` is sourced from the **first page only**, reflecting the total matched results regardless of pagination state.
