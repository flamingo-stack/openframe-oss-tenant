React Query infinite scroll hook for fetching paginated device data via GraphQL, with built-in error toasting and flat device list memoization.

## Key Components

- **`devicesQueryKeys`** — Structured query key factory for React Query cache management (`all` and `list` variants).
- **`useDevices(filters, search)`** — Main hook that wraps `useInfiniteQuery` to fetch devices in pages of 20, supporting filtering, search, and cursor-based pagination.
- **`DEVICES_PAGE_SIZE`** — Constant controlling page size (20 items per page).
- **`DevicesPage`** — Internal interface describing the shape of each paginated response page.

## Usage Example

```typescript
import { useDevices } from '@/features/devices/hooks/use-devices';

function DeviceList() {
  const {
    devices,
    isLoading,
    isFetchingNextPage,
    hasNextPage,
    fetchNextPage,
    filteredCount,
    refetch,
  } = useDevices(
    { status: 'online', siteId: 'site-123' },
    'workstation'
  );

  if (isLoading) return <Spinner />;

  return (
    <>
      <p>{filteredCount} devices found</p>
      {devices.map(device => (
        <DeviceCard key={device.id} device={device} />
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()} disabled={isFetchingNextPage}>
          {isFetchingNextPage ? 'Loading...' : 'Load More'}
        </button>
      )}
    </>
  );
}
```

## Behavior Notes

- **Pagination** uses cursor-based infinite scroll via `endCursor`; call `fetchNextPage()` to load the next 20 devices.
- **Cache** is considered fresh for **30 seconds** (`staleTime: 30_000`).
- **Errors** are surfaced via a destructive toast notification automatically.
- **`devices`** is a flat memoized array merged across all loaded pages, sorted server-side by `status DESC`.
