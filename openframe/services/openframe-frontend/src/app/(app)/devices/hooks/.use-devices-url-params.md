Manages URL query parameters for the devices list page, synchronizing search, filter, and tag state between the URL and API filter inputs with debounced search support.

## Key Components

### `useDevicesUrlParams(options?)`

Main hook that orchestrates URL param state for the devices list. Accepts an optional `UseDevicesUrlParamsOptions` object.

**Options**

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `defaultStatuses` | `string[]` | `DEFAULT_DEVICES_LIST_STATUSES` | Fallback statuses when none are selected. Pass `[]` to disable defaults (e.g. customer-scoped views). |

**Returns**

| Property | Type | Description |
|----------|------|-------------|
| `params` | `object` | Raw URL param values (`search`, `statuses`, `osTypes`, `organizationIds`, `tags`, `viewMode`) |
| `localSearch` / `setLocalSearch` | `string / setter` | Unthrottled local search input value |
| `debouncedSearch` | `string` | Search value debounced 500ms before URL sync |
| `filters` | `DeviceFilterInput` | Computed API filter object including effective statuses and tag values |
| `tableFilters` | `object` | Column filter shape expected by the table component |
| `tagOptions` | `TagSearchOption<string>[]` | Tag params shaped for the tag search UI |
| `handleFilterChange` | `fn` | Updates status/os/organization params and scrolls to top |
| `handleTagRemove` | `fn` | Removes a single tag from URL params |
| `handleTagSubmit` | `fn` | Adds a new tag and clears search input |
| `handleClearAll` | `fn` | Resets search and all tag params |

## Usage Example

```typescript
import { useDevicesUrlParams } from './use-devices-url-params';

function DevicesPage() {
  const {
    localSearch,
    setLocalSearch,
    filters,
    tableFilters,
    tagOptions,
    handleFilterChange,
    handleTagSubmit,
    handleTagRemove,
    handleClearAll,
  } = useDevicesUrlParams({
    // Pass [] to skip default status filtering in customer-scoped views
    defaultStatuses: [],
  });

  return (
    <DevicesTable
      search={localSearch}
      onSearchChange={setLocalSearch}
      filters={tableFilters}
      onFilterChange={handleFilterChange}
      tagOptions={tagOptions}
      onTagSubmit={handleTagSubmit}
      onTagRemove={handleTagRemove}
      onClearAll={handleClearAll}
      apiFilters={filters}
    />
  );
}
```

> **Note:** Tag params use `key:value` format in the URL. Only the `value` portion is forwarded to the API via `tagValues` — the `key` prefix is stripped during `filters` computation.
