Manages URL query parameters for the Devices page, synchronizing search, filter, and tag state between the URL and the API filter input with debounced search support.

## Key Components

### `useDevicesUrlParams(options?)`
Main hook that orchestrates URL-based filter state for device listings.

**Options:**
- `defaultStatuses?: string[]` — Statuses applied when none are selected. Defaults to `DEFAULT_VISIBLE_STATUSES` (ONLINE/OFFLINE/PENDING/ARCHIVED). Pass `[]` to return all statuses including DELETED.

**Returns:**

| Property | Type | Description |
|---|---|---|
| `params` | `object` | Raw URL param values (search, statuses, osTypes, organizationIds, tags, viewMode) |
| `filters` | `DeviceFilterInput` | Computed API filter object, applies `defaultStatuses` fallback |
| `tableFilters` | `object` | Column filter map keyed by `status`, `os`, `organization` |
| `tagOptions` | `TagSearchOption[]` | Tag params formatted for the tag search component |
| `localSearch` | `string` | Immediate (non-debounced) search input value |
| `debouncedSearch` | `string` | Search value debounced 500ms before URL sync |
| `handleFilterChange` | `fn` | Updates status/OS/org filters and scrolls table to top |
| `handleTagRemove` | `fn` | Removes a single tag from URL params |
| `handleTagSubmit` | `fn` | Adds a trimmed, unique tag and clears search |
| `handleClearAll` | `fn` | Resets search and all tags |

## Usage Example

```typescript
import { useDevicesUrlParams } from './use-devices-url-params';

function DevicesPage() {
  const {
    localSearch,
    setLocalSearch,
    filters,
    tableFilters,
    tagOptions,
    handleFilterChange,
    handleTagSubmit,
    handleTagRemove,
    handleClearAll,
  } = useDevicesUrlParams();

  // Pass `filters` to your API query
  const { data } = useDevicesQuery({ variables: { filter: filters } });

  return (
    <DevicesTable
      data={data}
      search={localSearch}
      onSearchChange={setLocalSearch}
      columnFilters={tableFilters}
      onFilterChange={handleFilterChange}
      tags={tagOptions}
      onTagSubmit={handleTagSubmit}
      onTagRemove={handleTagRemove}
      onClearAll={handleClearAll}
    />
  );
}
```

> Tags stored in URL params use a `key:value` format; only the value portion after `:` is forwarded to the API filter as `tagValues`.
