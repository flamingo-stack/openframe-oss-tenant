Manages URL query parameters for device list filtering, syncing search, status, OS type, organization, and tag filters between the URL state and the API filter input.

## Key Components

### `useDevicesUrlParams(options?)`

Main hook export. Accepts an optional `UseDevicesUrlParamsOptions` object.

**Options**

| Option | Type | Default | Description |
|---|---|---|---|
| `defaultStatuses` | `string[]` | `DEFAULT_VISIBLE_STATUSES` | Statuses applied when none are selected. Pass `[]` to return all statuses including `DELETED`. |

**Returns**

| Value | Type | Description |
|---|---|---|
| `params` | `object` | Raw URL params (search, statuses, osTypes, organizationIds, tags, viewMode) |
| `localSearch` / `setLocalSearch` | `string / setter` | Unthrottled local search input state |
| `debouncedSearch` | `string` | Search value debounced 500ms before writing to URL |
| `filters` | `DeviceFilterInput` | Composed API filter object, applies `defaultStatuses` fallback |
| `tableFilters` | `object` | Column-keyed filter map for table components |
| `tagOptions` | `TagSearchOption[]` | Tag params mapped to label/value pairs |
| `handleFilterChange` | `fn` | Updates status/OS/org filters and scrolls page to top |
| `handleTagRemove` | `fn` | Removes a single tag from URL params |
| `handleClearAll` | `fn` | Resets search and tag params |
| `handleTagSubmit` | `fn` | Appends a new unique tag and clears search |

> **Note:** Only `key:value` formatted tags have their value extracted and sent to the API. Bare tag strings are filtered out of `filters.tagValues`.

## Usage Example

```typescript
const {
  localSearch,
  setLocalSearch,
  filters,
  tableFilters,
  tagOptions,
  handleFilterChange,
  handleTagRemove,
  handleTagSubmit,
  handleClearAll,
} = useDevicesUrlParams({ defaultStatuses: [] }); // include all statuses
```
