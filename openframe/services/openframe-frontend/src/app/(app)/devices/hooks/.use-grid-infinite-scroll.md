Provides an `IntersectionObserver`-based infinite scroll hook for grid layouts, automatically triggering the next page fetch when a sentinel element enters the viewport.

## Key Components

- **`UseGridInfiniteScrollParams`** — Interface defining the hook's configuration:
  - `enabled` — Toggles infinite scroll behavior on/off
  - `hasNextPage` — Indicates whether more pages are available
  - `isFetchingNextPage` — Prevents duplicate fetch calls while loading
  - `fetchNextPage` — Callback invoked when the sentinel enters the viewport
- **`useGridInfiniteScroll`** — Hook that attaches an `IntersectionObserver` to a sentinel `div` ref, firing `fetchNextPage` with a `200px` root margin lookahead

## Usage Example

```typescript
import { useGridInfiniteScroll } from './use-grid-infinite-scroll';

function DeviceGrid({ query }) {
  const { data, hasNextPage, isFetchingNextPage, fetchNextPage } =
    useInfiniteQuery(query);

  const sentinelRef = useGridInfiniteScroll({
    enabled: true,
    hasNextPage,
    isFetchingNextPage,
    fetchNextPage,
  });

  return (
    <>
      <div className="grid grid-cols-3 gap-4">
        {data.pages.flat().map(device => (
          <DeviceCard key={device.id} device={device} />
        ))}
      </div>
      {/* Sentinel element — place at the bottom of the grid */}
      <div ref={sentinelRef} />
    </>
  );
}
```

> The observer disconnects automatically on cleanup, and no fetch is triggered while `isFetchingNextPage` is `true` or when `hasNextPage` is `false`, preventing redundant network calls.
