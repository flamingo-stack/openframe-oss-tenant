A React hook that enables infinite scroll behavior for grid layouts using the Intersection Observer API.

## Key Components

- **`useGridInfiniteScroll`** — Custom hook that observes a sentinel DOM element and triggers paginated data fetching when it enters the viewport
- **`UseGridInfiniteScrollParams`** — Interface defining the hook's configuration parameters:
  - `enabled` — Toggle to activate/deactivate the scroll listener
  - `hasNextPage` — Whether more pages are available to fetch
  - `isFetchingNextPage` — Prevents duplicate fetch calls while a request is in-flight
  - `fetchNextPage` — Callback invoked when the sentinel becomes visible
- **`sentinelRef`** — A `RefObject<HTMLDivElement>` returned by the hook, to be attached to a marker element at the bottom of the grid

## Usage Example

```typescript
import { useGridInfiniteScroll } from './use-grid-infinite-scroll';

function ItemGrid({ query }) {
  const { data, hasNextPage, isFetchingNextPage, fetchNextPage } =
    useInfiniteQuery(query);

  const sentinelRef = useGridInfiniteScroll({
    enabled: true,
    hasNextPage,
    isFetchingNextPage,
    fetchNextPage,
  });

  return (
    <div className="grid grid-cols-3 gap-4">
      {data.pages.flat().map(item => (
        <ItemCard key={item.id} item={item} />
      ))}
      {/* Sentinel element — triggers fetch when scrolled into view */}
      <div ref={sentinelRef} />
    </div>
  );
}
```

The observer uses a `rootMargin` of `200px`, so fetching begins slightly before the sentinel reaches the visible viewport, reducing perceived loading delays.
