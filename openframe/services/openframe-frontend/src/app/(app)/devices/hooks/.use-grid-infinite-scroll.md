A React hook that enables infinite scroll behavior for grid layouts using the IntersectionObserver API, automatically fetching the next page when a sentinel element enters the viewport.

## Key Components

- **`UseGridInfiniteScrollParams`** — Interface defining the hook's configuration:
  - `enabled` — Toggle to activate/deactivate the observer
  - `hasNextPage` — Whether more data is available to fetch
  - `isFetchingNextPage` — Guards against duplicate fetch calls
  - `fetchNextPage` — Callback triggered when the sentinel is visible
- **`sentinelRef`** — A `ref` attached to a bottom-of-grid `<div>` that acts as the scroll trigger, with a `200px` root margin for early prefetching

## Usage Example

```typescript
import { useGridInfiniteScroll } from './use-grid-infinite-scroll';

function ItemGrid({ query }) {
  const { data, hasNextPage, isFetchingNextPage, fetchNextPage } =
    useInfiniteQuery(query);

  const sentinelRef = useGridInfiniteScroll({
    enabled: true,
    hasNextPage,
    isFetchingNextPage,
    fetchNextPage,
  });

  return (
    <div className="grid grid-cols-3 gap-4">
      {data.pages.flat().map(item => (
        <ItemCard key={item.id} item={item} />
      ))}
      {/* Sentinel must be rendered at the bottom of the grid */}
      <div ref={sentinelRef} />
    </div>
  );
}
```

> **Note:** The sentinel `<div>` must always be rendered in the DOM for the observer to attach. The hook internally guards against triggering fetches when `enabled` is `false`, `hasNextPage` is `false`, or a fetch is already in progress.
