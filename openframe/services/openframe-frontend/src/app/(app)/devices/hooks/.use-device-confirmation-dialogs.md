Manages confirmation dialogs for device archive and delete actions, including generating and copying platform-specific uninstall commands for the delete flow.

## Key Components

- **`useDeviceConfirmationDialogs(device, options)`** — Main hook that returns dialog controls and rendered dialog nodes
- **`openArchive()`** — Triggers the archive confirmation dialog
- **`openDelete()`** — Triggers the delete confirmation dialog (also fetches the release version for uninstall command generation)
- **`dialogs`** — Pre-rendered `ReactNode` containing both `ConfirmDialog` instances, ready to be mounted in a parent component
- **`isArchiving` / `isDeleting`** — Pending state flags forwarded from `useDeviceActions`

## Usage Example

```typescript
import { useDeviceConfirmationDialogs } from './use-device-confirmation-dialogs';

function DeviceActions({ device }: { device: Device }) {
  const { openArchive, openDelete, dialogs, isArchiving, isDeleting } =
    useDeviceConfirmationDialogs(device, {
      onArchived: () => console.log('Device archived'),
      onDeleted: () => console.log('Device deleted'),
    });

  return (
    <>
      <button onClick={openArchive} disabled={isArchiving}>
        Archive
      </button>
      <button onClick={openDelete} disabled={isDeleting}>
        Delete
      </button>
      {/* Mount the pre-built dialogs */}
      {dialogs}
    </>
  );
}
```

## Notes

- The delete dialog includes a `CommandBox` with a platform-aware uninstall command (built via `buildUninstallCommand` + `normalizeDevicePlatform`), with a copy-to-clipboard action that shows a `CheckIcon` on success.
- The `releaseVersion` is only fetched when the delete dialog is open (`enabled: showDeleteConfirm`), avoiding unnecessary network requests.
- Callbacks `onArchived` and `onDeleted` are only invoked on successful action completion.
