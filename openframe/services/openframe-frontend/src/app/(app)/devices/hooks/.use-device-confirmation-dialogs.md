Manages confirmation dialogs for device archive and delete actions, providing pre-built dialog UI and handlers as a reusable hook.

## Key Components

**`useDeviceConfirmationDialogs(device, options)`**
Main hook that encapsulates the full dialog lifecycle for two destructive device operations.

- **`openArchive()`** — Opens the archive confirmation dialog
- **`openDelete()`** — Opens the delete confirmation dialog, which includes a platform-specific uninstall command with a copy-to-clipboard action
- **`dialogs`** — Pre-rendered `ReactNode` containing both `ConfirmDialog` instances; must be rendered in the component tree
- **`isArchiving`** / **`isDeleting`** — Pending state flags for each operation

**Options**
| Option | Description |
|---|---|
| `onArchived` | Callback fired after a successful archive |
| `onDeleted` | Callback fired after a successful delete |

**Internal dependencies**
- `useDeviceActions` — Executes archive/delete API calls
- `useReleaseVersion` — Fetches the current release version to build the uninstall command (lazy, only when delete dialog is open)
- `buildUninstallCommand` / `normalizeDevicePlatform` — Derive the correct CLI command per device OS

## Usage Example

```typescript
function DeviceActionsMenu({ device }: { device: Device }) {
  const { openArchive, openDelete, dialogs, isArchiving, isDeleting } =
    useDeviceConfirmationDialogs(device, {
      onArchived: () => router.push('/devices'),
      onDeleted:  () => router.push('/devices'),
    });

  return (
    <>
      <button onClick={openArchive} disabled={isArchiving}>Archive</button>
      <button onClick={openDelete}  disabled={isDeleting}>Delete</button>

      {/* Render both confirmation dialogs */}
      {dialogs}
    </>
  );
}
```

> **Note:** The delete dialog automatically fetches the platform-specific uninstall command only when opened, keeping the `useReleaseVersion` call lazy until needed.
