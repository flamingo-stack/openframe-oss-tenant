Builds the complete set of action menu items for a device, composing navigation, availability checks, and confirmation dialogs into a single reusable hook.

## Key Components

### `useDeviceActionsMenu(device, options)`
Primary hook that returns structured menu items, confirmation dialogs, and action availability state.

**Options:**
| Option | Type | Description |
|---|---|---|
| `onRunScript` | `() => void` | Custom handler for Run Script; falls back to route navigation |
| `onActionComplete` | `() => void` | Callback fired after any action completes |
| `deviceId` | `string` | Override for device ID when `device` is still loading |
| `iconSize` | `string` | Tailwind classes for icons (default: `'w-6 h-6'`) |
| `navigateOnDestructive` | `boolean` | Navigate to `/devices` after archive or delete |

### `DeviceActionsMenuItems`
Typed map of all menu entries: `deviceDetails`, `remoteShell`, `remoteControl`, `manageFiles`, `runScript`, `deviceLogs`, `archive`, `delete`. Destructive items (`archive`, `delete`) are `null` when unavailable for the current device state.

### `UseDeviceActionsMenuResult`
Return shape: `items`, `dialogs` (React nodes for confirmation modals), and `actionAvailability`.

## Usage Example

```typescript
const { items, dialogs, actionAvailability } = useDeviceActionsMenu(device, {
  navigateOnDestructive: true,
  onActionComplete: () => refetchDeviceList(),
});

return (
  <>
    <ActionsMenu items={Object.values(items).filter(Boolean)} />
    {dialogs}
  </>
);
```

> **Note:** `archive` and `delete` items are conditionally `null` — always filter before rendering the menu list.
