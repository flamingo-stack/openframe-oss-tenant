Builds a structured set of device action menu items (details, remote shell, remote control, manage files, run script, logs, archive, delete) along with associated confirmation dialogs for a given device.

## Key Components

**`useDeviceActionsMenu(device, options)`**
Main hook that composes menu items, action availability, and dialogs.

**`UseDeviceActionsMenuOptions`**
| Option | Type | Description |
|---|---|---|
| `onRunScript` | `() => void` | Custom handler for Run Script; falls back to router navigation |
| `onActionComplete` | `() => void` | Called after any action completes |
| `deviceId` | `string` | Override ID used for href building during device load |
| `iconSize` | `string` | Tailwind size classes for icons (default: `w-6 h-6`) |
| `navigateOnDestructive` | `boolean` | Navigate to `/devices` after archive or delete |

**`UseDeviceActionsMenuResult`**
- `items` — `DeviceActionsMenuItems`: all menu entries (`archive` and `delete` are `null` when unavailable)
- `dialogs` — `ReactNode`: confirmation dialog nodes to render alongside the menu
- `actionAvailability` — `DeviceActionAvailability | null`: computed availability flags for the device

## Usage Example

```typescript
import { useDeviceActionsMenu } from './use-device-actions-menu';

function DeviceActionsMenu({ device }: { device: Device }) {
  const { items, dialogs, actionAvailability } = useDeviceActionsMenu(device, {
    navigateOnDestructive: true,
    onActionComplete: () => refetchDeviceList(),
    iconSize: 'w-5 h-5',
  });

  return (
    <>
      <ActionsMenu items={Object.values(items).filter(Boolean)} />
      {dialogs}
    </>
  );
}
```

> `archive` and `delete` entries return `null` when the device state does not permit those actions — always filter before rendering.
