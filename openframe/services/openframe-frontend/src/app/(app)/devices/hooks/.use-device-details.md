Fetches and assembles a unified `Device` object by combining data from multiple backend sources (GraphQL, Tactical RMM, Fleet MDM, and MeshCentral) into a single normalized structure.

## Key Components

### `createDevice(node, tacticalData, fleetData, meshCentralStatus, meshCentralLastSeen)`

Internal factory function that maps raw API responses from all four data sources into a single `Device` object. Handles:

- **Software, Battery, User, MDM** — transforms Fleet-specific shapes into unified types
- **IP deduplication** — merges IPs from Fleet, Tactical, and GraphQL node using a `Set`, filters private ranges
- **Tool connection enrichment** — patches `TACTICAL_RMM`, `FLEET_MDM`, and `MESHCENTRAL` connection entries with live status and `lastSeen` timestamps
- **Field priority** — Fleet data takes precedence, falling back to GraphQL node, then Tactical RMM

### `useDeviceDetails(deviceId)`

*(implied hook, referenced via `GET_DEVICE_QUERY` and `deviceQueryKeys`)* — React Query hook that fetches device data and surfaces a toast notification on error.

## Usage Example

```typescript
import { useDeviceDetails } from '@/features/devices/hooks/use-device-details';

function DevicePanel({ deviceId }: { deviceId: string }) {
  const { data: device, isLoading, error } = useDeviceDetails(deviceId);

  if (isLoading) return <Spinner />;

  return (
    <div>
      <h1>{device?.displayName}</h1>
      <p>OS: {device?.os_version}</p>
      <p>IP: {device?.ip}</p>
      <p>Status: {device?.status}</p>
    </div>
  );
}
```

## Data Source Priority

| Field Category | Primary | Fallback 1 | Fallback 2 |
|---|---|---|---|
| Hostname | Fleet | GraphQL node | Tactical RMM |
| OS version | Fleet | GraphQL node | Tactical RMM |
| Serial number | Fleet | GraphQL node | Tactical RMM |
| Public IP | Fleet (filtered) | Tactical (filtered) | — |
| Status | GraphQL node | Fleet | Tactical RMM |
