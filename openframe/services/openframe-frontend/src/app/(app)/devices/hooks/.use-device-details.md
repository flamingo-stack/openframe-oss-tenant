Fetches and aggregates device details from multiple backend sources (GraphQL, Tactical RMM, Fleet MDM, and MeshCentral) into a single unified `Device` object, with automatic polling and toast notifications on error.

## Key Components

**`createDevice(node, tacticalData, fleetData, meshCentralStatus, meshCentralLastSeen)`**
Pure mapping function that merges data from all sources into a normalized `Device` object. Handles IP deduplication (private vs. public), software/battery/user transformation, MDM info, and tool connection status enrichment.

**`useDeviceDetails(deviceId: string)`** *(implied hook)*
React Query-powered hook that:
- Fetches the GraphQL `DeviceGraphQlNode` via `GET_DEVICE_QUERY`
- Enriches with Tactical RMM agent data via `tacticalApiClient`
- Enriches with Fleet MDM host data via `fleetApiClient`
- Enriches with MeshCentral online status via `getMeshCentralDeviceInfo`
- Shows a toast on fetch failure
- Returns a single merged `Device` object

## Usage Example

```typescript
import { useDeviceDetails } from '@/features/devices/hooks/use-device-details';

function DevicePanel({ deviceId }: { deviceId: string }) {
  const { data: device, isLoading, error } = useDeviceDetails(deviceId);

  if (isLoading) return <Spinner />;

  return (
    <div>
      <h2>{device?.displayName}</h2>
      <p>OS: {device?.os_version}</p>
      <p>IP: {device?.public_ip}</p>
      <p>Status: {device?.status}</p>
    </div>
  );
}
```

## Data Priority

| Field | Priority Order |
|-------|---------------|
| Hostname | Fleet → GraphQL node → Tactical |
| Public IP | Fleet (if public) → Tactical (if public) |
| OS Version | Fleet → GraphQL node → Tactical |
| Status | GraphQL node → Fleet → Tactical |
