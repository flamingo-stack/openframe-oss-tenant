React Query hook for fetching and merging device details from multiple backend sources (GraphQL, TacticalRMM, Fleet MDM, and MeshCentral) into a unified `Device` object.

## Key Components

### `createDevice(node, tacticalData, fleetData, meshCentralStatus, meshCentralLastSeen)`
Pure mapping function that merges data from all sources into a single normalized `Device` object. Handles:
- Software, battery, user, and MDM info transformation from Fleet
- IP deduplication and public/private IP classification
- Tool connection status enrichment per provider type (`TACTICAL_RMM`, `FLEET_MDM`, `MESHCENTRAL`)
- Legacy field aliases for backward compatibility

### `useDeviceDetails(deviceId)` *(implied hook — standard pattern)*
React Query hook that orchestrates parallel fetching from:
- **GraphQL** — core device node via `GET_DEVICE_QUERY`
- **TacticalRMM** — agent details via `tacticalApiClient`
- **Fleet MDM** — host details via `fleetApiClient`
- **MeshCentral** — online status + last seen via `getMeshCentralDeviceInfo`

Uses `deviceQueryKeys` for cache key management and `useToast` for error notifications.

## Usage Example

```typescript
import { useDeviceDetails } from '@/features/devices/hooks/use-device-details';

function DevicePanel({ deviceId }: { deviceId: string }) {
  const { data: device, isLoading, error } = useDeviceDetails(deviceId);

  if (isLoading) return <Spinner />;
  if (!device) return null;

  return (
    <div>
      <h1>{device.displayName}</h1>
      <p>OS: {device.os_version} ({device.platform})</p>
      <p>IP: {device.ip}</p>
      <p>Status: {device.status}</p>
      <p>Serial: {device.serial_number}</p>
    </div>
  );
}
```

> **Note:** `createDevice` performs direct field mapping with no intermediate normalization layer. Source priority is generally **Fleet → GraphQL node → TacticalRMM** for most fields, with MeshCentral used exclusively for online/last-seen status enrichment on `MESHCENTRAL` tool connections.
