React Query hook for fetching device filter options via GraphQL, used to populate filter dropdowns or faceted search UI for the device list.

## Key Components

### `deviceFiltersQueryKeys`

Cache key factory for React Query:

| Key | Description |
|-----|-------------|
| `all` | Base key for all device filter queries |
| `byFilter(filters)` | Scoped key per unique filter input combination |

### `useDeviceFilters(filters?)`

Primary hook that queries `/api/graphql` for available `DeviceFilters` using `GET_DEVICE_FILTERS_QUERY`.

**Behaviors:**
- Accepts an optional `DeviceFilterInput` (defaults to `{}`)
- Retains previous data while new results load (`keepPreviousData`)
- Caches results for **30 seconds** (`staleTime`)
- Throws on HTTP errors or GraphQL-level errors
- Returns `null` if the response contains no data payload

## Usage Example

```typescript
import { useDeviceFilters } from '@/features/devices/hooks/use-device-filters';

function DeviceFilterPanel() {
  const { data: filters, isLoading } = useDeviceFilters({ siteId: 'site_123' });

  if (isLoading) return <Spinner />;

  return (
    <Select
      options={filters?.operatingSystems ?? []}
      placeholder="Filter by OS"
    />
  );
}
```

> **Note:** Pass filter inputs that narrow the available filter options (e.g. by site or client). Omit arguments to fetch all available filter values globally.
