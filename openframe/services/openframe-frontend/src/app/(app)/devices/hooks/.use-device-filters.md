Fetches available device filter options via GraphQL, providing structured filter metadata for device list UI components.

## Key Components

**`deviceFiltersQueryKeys`**
Query key factory for React Query cache management:
- `all` — base key for all device filter queries
- `byFilter(filters)` — scoped key based on active `DeviceFilterInput`

**`useDeviceFilters(filters?)`**
React Query hook that POSTs a GraphQL request to `/api/graphql` using `GET_DEVICE_FILTERS_QUERY`. Returns available `DeviceFilters` options scoped to the provided filter input.

- Caches results for **30 seconds** (`staleTime`)
- Retains previous data during refetches (`keepPreviousData`)
- Returns `null` when no data is present in the GraphQL response
- Throws on HTTP errors or GraphQL-level errors

## Usage Example

```typescript
import { useDeviceFilters } from './use-device-filters';

function DeviceFilterPanel() {
  const { data: filters, isLoading } = useDeviceFilters({ siteId: 'site-123' });

  if (isLoading) return <Spinner />;

  return (
    <FilterDropdown
      statuses={filters?.statuses}
      platforms={filters?.platforms}
    />
  );
}
```

> **Note:** Pass an empty object `{}` or omit the argument to fetch unscoped filter options. The query key automatically updates when `filters` changes, triggering a fresh fetch.
