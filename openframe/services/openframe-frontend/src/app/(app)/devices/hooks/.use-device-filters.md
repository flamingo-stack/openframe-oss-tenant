Provides a React Query hook for fetching device filter options via GraphQL, enabling dynamic filtering of device lists with caching and stale-data handling.

## Key Components

- **`deviceFiltersQueryKeys`** — Query key factory with two helpers:
  - `all` — Base key for all device filter queries
  - `byFilter(filters)` — Scoped key based on the current `DeviceFilterInput`

- **`useDeviceFilters(filters?)`** — Primary hook that fetches available `DeviceFilters` from the GraphQL endpoint, accepting an optional `DeviceFilterInput` to scope results

## Usage Example

```typescript
import { useDeviceFilters } from './use-device-filters';

function DeviceFilterPanel() {
  const { data: filters, isLoading, error } = useDeviceFilters({
    siteId: 'site-123',
    status: 'active',
  });

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage error={error} />;

  return <FilterDropdowns options={filters} />;
}
```

## Behavior Notes

- **`placeholderData: keepPreviousData`** — Retains the last successful response while new filter parameters are being fetched, preventing UI flicker on filter changes
- **`staleTime: 30s`** — Suppresses redundant refetches for 30 seconds, suitable for filter metadata that changes infrequently
- GraphQL errors embedded in a `200 OK` response are surfaced as thrown `Error` instances
- Returns `null` when the GraphQL response contains no `data` payload
