Fetches and caches the current release version from the `/api/release-version` endpoint, exposing loading/error state and toast notifications on failure.

## Key Components

- **`releaseVersionQueryKeys`** — Structured React Query key factory for cache management and invalidation
- **`fetchReleaseVersion`** — Async fetcher that calls `/api/release-version` and falls back to `'latest'` on empty response
- **`useReleaseVersion(options)`** — Primary hook returning the resolved version string, query state flags, and a `refetch` handle; shows a destructive toast on error

## Usage Example

```typescript
import { useReleaseVersion } from '@/hooks/use-release-version';

function VersionBadge() {
  const { releaseVersion, isLoading, error, refetch } = useReleaseVersion();

  if (isLoading) return <span>Loading...</span>;
  if (error) return <button onClick={() => refetch()}>Retry</button>;

  return <span>v{releaseVersion}</span>;
}
```

```typescript
// Conditionally enable fetching
const { releaseVersion } = useReleaseVersion({ enabled: isAuthenticated });
```

## Cache Behaviour

| Option | Value |
|---|---|
| `staleTime` | 5 minutes |
| `gcTime` | 10 minutes |
| `retry` | 2 attempts |
| `retryDelay` | 1 second |
