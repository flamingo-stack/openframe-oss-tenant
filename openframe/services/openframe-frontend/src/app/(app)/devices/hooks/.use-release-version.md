Fetches and caches the current release version string from the `/api/release-version` endpoint, surfacing load errors via toast notifications.

## Key Components

**`releaseVersionQueryKeys`**
Query key factory for React Query cache management:
- `all` — base key `['releaseVersion']`
- `detail()` — scoped detail key for the version fetch

**`fetchReleaseVersion`** *(internal)*
Async function that calls `GET /api/release-version` and returns the trimmed version string, falling back to `'latest'` if the field is absent.

**`useReleaseVersion(options)`**
Primary hook. Wraps React Query with:
- 5-minute `staleTime` and 10-minute `gcTime` for efficient caching
- 2 retries with a 1-second delay
- Automatic destructive toast on fetch error (when `enabled`)
- `enabled` option to defer execution until explicitly activated

## Usage Example

```typescript
import { useReleaseVersion } from '@/hooks/use-release-version';

function VersionBadge() {
  const { releaseVersion, isLoading, error } = useReleaseVersion();

  if (isLoading) return <span>Loading...</span>;
  if (error) return <span>Error: {error}</span>;

  return <span>v{releaseVersion}</span>;
}

// Deferred fetch — only runs after user action
function LazyVersion() {
  const [enabled, setEnabled] = useState(false);
  const { releaseVersion, isFetching, refetch } = useReleaseVersion({ enabled });

  return (
    <button onClick={() => setEnabled(true)}>
      {isFetching ? 'Checking...' : releaseVersion}
    </button>
  );
}
```

## Return Values

| Property | Type | Description |
|---|---|---|
| `releaseVersion` | `string` | Version string or `'latest'` fallback |
| `isLoading` | `boolean` | True on first fetch |
| `isFetching` | `boolean` | True on any background refetch |
| `isSuccess` | `boolean` | True when data is available |
| `error` | `string \| null` | Error message if fetch failed |
| `refetch` | `function` | Manually trigger a re-fetch |
| `query` | `UseQueryResult` | Full React Query result object |
