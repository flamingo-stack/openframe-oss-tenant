React Query hook that fetches and caches the current release version from `/api/release-version`, with built-in error toasting and sensible cache defaults.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `releaseVersionQueryKeys` | `object` | Structured query key factory for cache management |
| `fetchReleaseVersion` | `async function` | Internal fetcher — calls `/api/release-version`, falls back to `'latest'` |
| `UseReleaseVersionOptions` | `interface` | Options: `enabled?: boolean` |
| `useReleaseVersion` | `hook` | Primary export — returns version state and query controls |

## Usage Example

```typescript
import { useReleaseVersion } from '@/hooks/use-release-version';

function VersionBadge() {
  const { releaseVersion, isLoading, error } = useReleaseVersion();

  if (isLoading) return <Spinner />;

  return <span>{releaseVersion}</span>;
}
```

**Conditionally enabled:**

```typescript
const { releaseVersion, refetch } = useReleaseVersion({ enabled: isAuthenticated });
```

## Cache Behavior

| Setting | Value | Description |
|---------|-------|-------------|
| `staleTime` | 5 min | Data considered fresh for 5 minutes |
| `gcTime` | 10 min | Cached entry kept for 10 minutes after unmount |
| `retry` | 2 | Retries failed requests twice |
| `retryDelay` | 1000ms | Fixed 1 second delay between retries |

## Return Shape

```typescript
{
  releaseVersion: string;   // Resolved version or 'latest'
  isLoading: boolean;
  isFetching: boolean;
  isSuccess: boolean;
  error: string | null;
  refetch: () => void;
  query: UseQueryResult;    // Raw TanStack Query result
}
```

> On fetch failure (when `enabled: true`), a destructive toast is automatically shown with the error message.
