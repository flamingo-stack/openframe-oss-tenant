Generates a platform-specific client installation command string for deploying the OpenFrame agent on macOS or Windows endpoints.

## Key Components

- **`useInstallCommand(options)`** — Main hook export. Assembles a full shell/PowerShell install command using the current server URL, registration secret, organization ID, release version, and optional tags.
- **`buildBinaryUrl(version, assetName)`** — Constructs a GitHub Releases download URL, falling back to `/latest/download/` when no version is specified.
- **`buildTagArgs(tags, platform)`** — Serializes `TagEntry[]` into CLI `--tag key=value` arguments, using platform-appropriate quoting (`"` for Windows, `'` for macOS).
- **`useRegistrationSecret`** / **`useReleaseVersion`** — Composed hooks that supply the `initialKey` and `releaseVersion` values.

## Usage Example

```typescript
import { useInstallCommand } from './use-install-command';

function InstallWidget({ orgId }: { orgId: string }) {
  const { command } = useInstallCommand({
    organizationId: orgId,
    platform: 'macos',
    tags: [{ key: 'env', values: ['production'] }],
  });

  return <pre>{command}</pre>;
}
```

## Notes

- On **Windows**, the command uses PowerShell (`Invoke-WebRequest`, `Expand-Archive`, `Start-Process -Verb RunAs`).
- On **macOS**, it uses a `curl` + `tar` + `sudo` shell pipeline.
- When running on `localhost` / `127.0.0.1`, the `--localMode` flag is automatically appended to `serverUrl`.
- Returns both `command` (the full install string) and `initialKey` (for display alongside the command).
