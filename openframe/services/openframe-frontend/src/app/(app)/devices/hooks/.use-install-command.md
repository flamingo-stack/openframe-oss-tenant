Generates platform-specific shell/PowerShell install commands for the OpenFrame client agent, resolving the binary download URL, registration secret, and optional tag arguments based on the target OS.

## Key Components

- **`useInstallCommand(options)`** — Main hook; returns `{ command, initialKey }` where `command` is a ready-to-paste terminal string for macOS or Windows.
- **`buildBinaryUrl(version, assetName)`** — Constructs the GitHub Releases download URL, falling back to `/latest/download/` when no version is available.
- **`buildTagArgs(tags, platform)`** — Serializes `TagEntry[]` into `--tag key=value` CLI arguments, using platform-appropriate quoting (`'` for macOS, `"` for Windows).
- **`useRegistrationSecret`** — Supplies the `initialKey` registration token.
- **`useReleaseVersion`** — Supplies the target release version string.

## Usage Example

```typescript
import { useInstallCommand } from './use-install-command';

function InstallStep({ orgId }: { orgId: string }) {
  const { command } = useInstallCommand({
    organizationId: orgId,
    platform: 'macos',
    tags: [{ key: 'env', values: ['production'] }],
  });

  return <pre>{command}</pre>;
}
```

## Notes

- When running on `localhost` / `127.0.0.1`, the server URL automatically appends `--localMode` to the generated command.
- The Windows command runs the installer via `Start-Process ... -Verb RunAs` (elevated), while the macOS command uses `sudo` inline.
- Both commands are fully self-contained: they download, extract, and execute the binary in a single copy-paste step.
