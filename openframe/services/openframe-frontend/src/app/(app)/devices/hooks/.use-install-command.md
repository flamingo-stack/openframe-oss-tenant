Generates a platform-specific OpenFrame client install command string for macOS and Windows, incorporating the server URL, registration secret, organization ID, release version, and optional tag arguments.

## Key Components

- **`useInstallCommand(options)`** – Main hook that returns the generated `command` string and `initialKey`
- **`buildBinaryUrl(version, assetName)`** – Constructs a GitHub release download URL; falls back to `latest` if no version is provided
- **`buildTagArgs(tags, platform)`** – Serializes `TagEntry[]` into `--tag key=value` CLI arguments with platform-appropriate quoting (`"` for Windows, `'` for macOS)
- **`UseInstallCommandOptions`** – Input interface requiring `organizationId`, `platform` (`OSPlatformId`), and optional `tags`

## Usage Example

```typescript
import { useInstallCommand } from './use-install-command';

function InstallInstructions({ orgId }: { orgId: string }) {
  const { command } = useInstallCommand({
    organizationId: orgId,
    platform: 'macos',
    tags: [{ key: 'env', values: ['production'] }],
  });

  return <pre>{command}</pre>;
}
```

## Notes

- **macOS** output: a `curl` + `tar` + `sudo` one-liner
- **Windows** output: a PowerShell one-liner using `Invoke-WebRequest` + `Expand-Archive` + `Start-Process -Verb RunAs`
- Server URL detection runs client-side only; `localhost` triggers `--localMode` automatically
- Depends on [`useRegistrationSecret`](./use-registration-secret) for `initialKey` and [`useReleaseVersion`](./use-release-version) for the binary version tag
