Builds and exports a factory function for device action menu items used across different views (device table dropdowns, ticket panels) in the OpenFrame platform.

## Key Components

### Interfaces

- **`DeviceMenuItemContext`** — Configuration object passed by each view, controlling `deviceId`, action availability, icon sizing, Windows shell behavior, and new-tab icon actions.
- **`DeviceMenuItems`** — Shape of the returned menu item set: `deviceDetails`, `remoteShell`, `remoteControl`, `manageFiles`, `deviceLogs`.

### Functions

- **`buildDeviceMenuItems(ctx)`** — Primary export. Constructs the full `DeviceMenuItems` object from a given context. Views destructure only the items they need.
- **`buildRemoteShellItem(ctx)`** *(internal)* — Handles the three Remote Shell variants: Windows submenu (CMD / PowerShell), bash link, or plain link without a `shellType` param.
- **`maybeNewTabAction(ctx, href, label, disabled?)`** *(internal)* — Conditionally appends an `iconAction` (arrow-up-right icon) when `ctx.withNewTabAction` is `true`.

> **Note:** `Run Script` is intentionally excluded — it requires a React-stateful `onClick` to open a modal and cannot be expressed as pure config.

## Usage Example

```typescript
// Device table dropdown (Windows machine, with new-tab actions)
const items = buildDeviceMenuItems({
  deviceId: 'abc-123',
  availability: getDeviceActionAvailability(device),
  iconSize: 'w-6 h-6',
  isWindows: true,
  withNewTabAction: true,
});

// Render only the items this view needs
const menuItems = [
  items.deviceDetails,
  items.remoteShell,   // renders as CMD / PowerShell submenu
  items.remoteControl,
  items.manageFiles,
];

// Ticket panel (smaller icons, no new-tab actions, OS unknown)
const ticketItems = buildDeviceMenuItems({
  deviceId: machineId,
  availability,        // null while device loads → remote actions disabled
});
```
