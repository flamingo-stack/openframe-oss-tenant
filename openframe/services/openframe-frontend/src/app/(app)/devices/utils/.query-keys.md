Centralized query key factory for device-related React Query cache entries, ensuring consistent and type-safe cache key generation across the application.

## Key Components

- **`deviceQueryKeys.all`** — Base key `['devices']` shared by all device queries
- **`deviceQueryKeys.lists()`** — Key for device list queries: `['devices', 'list']`
- **`deviceQueryKeys.detail(machineId)`** — Key for a specific device query: `['devices', 'detail', machineId]`

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query';
import { deviceQueryKeys } from './query-keys';

// Fetch all devices
useQuery({ queryKey: deviceQueryKeys.lists(), queryFn: fetchDevices });

// Fetch a specific device
useQuery({
  queryKey: deviceQueryKeys.detail('machine-123'),
  queryFn: () => fetchDevice('machine-123'),
});

// Invalidate all device queries
const queryClient = useQueryClient();
queryClient.invalidateQueries({ queryKey: deviceQueryKeys.all });
```

## Notes

- Keys are defined `as const` for full TypeScript inference and immutability
- Hierarchical structure allows targeted invalidation — invalidating `all` cascades to both `lists` and `detail` entries
