Defines centralized React Query cache key factories for device-related queries, ensuring consistent and type-safe cache key management across the application.

## Key Components

- **`deviceQueryKeys.all`** — Base key `['devices']` used as the root for all device queries
- **`deviceQueryKeys.lists()`** — Generates keys for device list queries: `['devices', 'list']`
- **`deviceQueryKeys.detail(machineId)`** — Generates keys for individual device queries: `['devices', 'detail', machineId]`

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query';
import { deviceQueryKeys } from './query-keys';

// Fetch all devices list
const { data } = useQuery({
  queryKey: deviceQueryKeys.lists(),
  queryFn: fetchDevices,
});

// Fetch a single device by machine ID
const { data: device } = useQuery({
  queryKey: deviceQueryKeys.detail('machine-abc-123'),
  queryFn: () => fetchDevice('machine-abc-123'),
});

// Invalidate all device-related cache entries
const queryClient = useQueryClient();
queryClient.invalidateQueries({ queryKey: deviceQueryKeys.all });
```

## Notes

- The hierarchical structure allows targeted or broad cache invalidation — invalidating `deviceQueryKeys.all` will also clear list and detail caches.
- All keys are `as const` for full TypeScript inference and type safety.
