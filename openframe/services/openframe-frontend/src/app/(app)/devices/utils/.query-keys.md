Centralized query key factory for device-related React Query cache entries, ensuring consistent and type-safe cache key management.

## Key Components

- **`deviceQueryKeys.all`** — Base key tuple `['devices']` used as the root for all device queries
- **`deviceQueryKeys.lists()`** — Generates keys for device list queries: `['devices', 'list']`
- **`deviceQueryKeys.detail(machineId)`** — Generates keys for individual device queries: `['devices', 'detail', machineId]`

## Usage Example

```typescript
import { deviceQueryKeys } from './query-keys';

// Fetch all devices list
const { data } = useQuery({
  queryKey: deviceQueryKeys.lists(),
  queryFn: fetchDevices,
});

// Fetch a specific device by machine ID
const { data } = useQuery({
  queryKey: deviceQueryKeys.detail('machine-abc-123'),
  queryFn: () => fetchDevice('machine-abc-123'),
});

// Invalidate all device-related cache entries
queryClient.invalidateQueries({ queryKey: deviceQueryKeys.all });
```

> **Tip:** Using the shared `all` root key lets you invalidate all device queries at once (lists + details) with a single `invalidateQueries` call — useful after mutations that affect multiple device records.
