Utility functions for converting MeshCentral `FileEntry` objects to UI-Kit `FileItem` format, along with helpers for path manipulation, file size formatting, and date formatting used in the OpenFrame file manager.

## Key Components

| Function | Description |
|---|---|
| `convertFileEntryToItem` | Converts a single MeshCentral `FileEntry` to a `FileItem`, resolving the full path from `currentPath` |
| `convertFileEntriesToItems` | Batch converts an array of `FileEntry` objects to `FileItem[]` |
| `formatFileSize` | Formats raw bytes into a human-readable string (e.g., `1.23 MB`) |
| `formatDate` | Converts a Unix timestamp to `MM/DD/YYYY HH:MM` format |
| `getFileExtension` | Extracts and lowercases the file extension from a filename |
| `isDownloadable` | Returns `true` if the MeshCentral file type is `3` (regular file) |
| `sanitizePath` | Strips path traversal sequences (`..`, `.`) and normalizes slashes; handles Windows drive letters |
| `getParentPath` | Returns the parent directory of a given path |
| `joinPath` | Joins path segments, normalizing duplicate slashes and ensuring a leading `/` |

## Usage Example

```typescript
import {
  convertFileEntriesToItems,
  sanitizePath,
  getParentPath,
  formatFileSize,
} from './file-manager-utils';

// Convert MeshCentral entries for the UI
const items = convertFileEntriesToItems(
  [{ n: 'documents', t: 1, d: 1700000000000 }],
  '/home/user'
);
// → [{ id: '/home/user/documents', name: 'documents', type: 'folder', ... }]

// Format bytes
formatFileSize(1048576); // → "1 MB"

// Prevent path traversal
sanitizePath('/home/user/../../etc/passwd'); // → '/home/user'

// Navigate up
getParentPath('/home/user/documents'); // → '/home/user'
```
