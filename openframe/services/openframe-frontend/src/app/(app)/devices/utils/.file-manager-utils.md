Utility functions for converting MeshCentral `FileEntry` objects into UI-Kit `FileItem` format, with helpers for path manipulation, formatting, and sanitization.

## Key Components

| Function | Description |
|---|---|
| `convertFileEntryToItem` | Converts a single `FileEntry` to `FileItem`, resolving the full path from current directory context |
| `convertFileEntriesToItems` | Batch converts an array of `FileEntry` objects |
| `formatFileSize` | Formats raw bytes into human-readable strings (B, KB, MB, GB, TB) |
| `formatDate` | Formats Unix timestamps to `MM/DD/YYYY HH:MM` |
| `getFileExtension` | Extracts the lowercased file extension from a filename |
| `isDownloadable` | Returns `true` only for type `3` (regular file) entries |
| `sanitizePath` | Strips path traversal sequences (`..`, `.`), with Windows drive letter support |
| `getParentPath` | Returns the parent directory of a given path |
| `joinPath` | Joins path segments, normalizing slashes and ensuring a leading `/` |

## Usage Example

```typescript
import {
  convertFileEntriesToItems,
  sanitizePath,
  getParentPath,
  formatFileSize,
} from './file-manager-utils';

// Convert MeshCentral entries for the file manager UI
const items = convertFileEntriesToItems(fileEntries, '/home/user/documents');

// Safely handle user-provided paths
const safe = sanitizePath('../../etc/passwd'); // returns '/'
const parent = getParentPath('/home/user/documents'); // returns '/home/user'

// Format raw byte values
const size = formatFileSize(1048576); // returns '1 MB'
```
