Utility functions for converting MeshCentral `FileEntry` objects to UI-Kit `FileItem` format, along with helpers for path manipulation, file size formatting, and date formatting used by the OpenFrame file manager.

## Key Components

| Function | Description |
|---|---|
| `convertFileEntryToItem` | Converts a single MeshCentral `FileEntry` to a `FileItem`, resolving absolute paths |
| `convertFileEntriesToItems` | Batch converts an array of `FileEntry` objects to `FileItem` array |
| `formatFileSize` | Formats raw byte count into human-readable string (e.g. `1.23 MB`) |
| `formatDate` | Formats a Unix timestamp to `MM/DD/YYYY HH:MM` string |
| `getFileExtension` | Extracts lowercase file extension from a filename |
| `isDownloadable` | Returns `true` only for MeshCentral type `3` (regular file) |
| `sanitizePath` | Strips path traversal sequences (`..`, `.`), supports Windows drive letters |
| `getParentPath` | Returns the parent directory path, bottoming out at `/` |
| `joinPath` | Joins path segments, normalizing slashes and ensuring a leading `/` |

## Usage Example

```typescript
import {
  convertFileEntriesToItems,
  sanitizePath,
  getParentPath,
  joinPath,
  formatFileSize,
} from './file-manager-utils';

// Convert MeshCentral entries to UI-Kit FileItems
const items = convertFileEntriesToItems(entries, '/home/user');

// Safely resolve a user-provided path
const safe = sanitizePath('../../etc/passwd'); // → '/'

// Navigate up one directory
const parent = getParentPath('/home/user/documents'); // → '/home/user'

// Build a new path from segments
const target = joinPath('/home/user', 'downloads', 'file.txt');
// → '/home/user/downloads/file.txt'

// Format raw bytes
const size = formatFileSize(1048576); // → '1 MB'
```

> **Note:** `sanitizePath` handles both Unix (`/`) and Windows (`C:\`) path formats, making it safe to use across platforms when communicating with MeshCentral agents on mixed OS environments.
