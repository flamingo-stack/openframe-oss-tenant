Utility module providing unified logic for generating platform-specific OpenFrame client installation and uninstallation shell commands, along with OS platform normalization helpers.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `buildBinaryUrl` | Function | Constructs a GitHub release download URL for a given version and asset name |
| `getMacBinaryUrl` | Function | Returns the macOS `.tar.gz` binary download URL |
| `getWindowsBinaryUrl` | Function | Returns the Windows `.zip` binary download URL |
| `buildInstallCommand` | Function | Generates a full install shell command for Windows (PowerShell) or macOS (bash) |
| `buildUninstallCommand` | Function | Generates a full uninstall shell command for Windows or macOS |
| `normalizeDevicePlatform` | Function | Normalizes raw OS strings (e.g. `win32`, `darwin`, `ubuntu`) into a typed `OSPlatformId` |
| `InstallCommandOptions` | Interface | Options for `buildInstallCommand`: platform, serverUrl, initialKey, orgId, releaseVersion, additionalArgs |
| `UninstallCommandOptions` | Interface | Options for `buildUninstallCommand`: platform and releaseVersion |

## Usage Example

```typescript
import {
  buildInstallCommand,
  buildUninstallCommand,
  normalizeDevicePlatform,
} from './device-command-utils';

// Normalize a raw OS string from a device record
const platform = normalizeDevicePlatform(undefined, 'win32'); // → 'windows'

// Build a Windows install command
const installCmd = buildInstallCommand({
  platform,
  serverUrl: 'https://my-tenant.openframe.ai',
  initialKey: 'abc123',
  orgId: 'org_456',
  releaseVersion: 'v1.2.0',
  additionalArgs: ['--silent'],
});

// Build an uninstall command for macOS
const uninstallCmd = buildUninstallCommand({
  platform: 'darwin',
  releaseVersion: 'v1.2.0',
});
```

### Platform Behavior

| Platform | Shell | Download Method | Executor |
|----------|-------|-----------------|----------|
| `windows` | PowerShell | `Invoke-WebRequest` | `Start-Process` with `RunAs` |
| `darwin` / macOS | bash | `curl` | `sudo` |

> When `releaseVersion` is empty, `buildBinaryUrl` falls back to the `/releases/latest/download/` URL automatically.
