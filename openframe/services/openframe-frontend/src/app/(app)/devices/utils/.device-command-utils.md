Utilities for generating platform-specific OpenFrame client installation and uninstallation shell commands, plus OS platform normalization from raw device strings.

## Key Components

### Functions

| Function | Description |
|---|---|
| `buildBinaryUrl(version, assetName)` | Constructs a GitHub release download URL; falls back to `latest` if version is empty |
| `getMacBinaryUrl(version)` | Returns the macOS `.tar.gz` binary download URL |
| `getWindowsBinaryUrl(version)` | Returns the Windows `.zip` binary download URL |
| `buildInstallCommand(options)` | Generates a full install shell command for macOS (`curl`/`tar`) or Windows (PowerShell) |
| `buildUninstallCommand(options)` | Generates a full uninstall shell command for macOS or Windows |
| `normalizeDevicePlatform(platform?, osType?, operatingSystem?)` | Normalizes raw OS strings to `OSPlatformId` (`windows`, `darwin`, `linux`); defaults to `darwin` |

### Interfaces

- **`InstallCommandOptions`** — `platform`, `serverUrl`, `initialKey`, `orgId`, `releaseVersion`, optional `additionalArgs`
- **`UninstallCommandOptions`** — `platform`, `releaseVersion`

## Usage Example

```typescript
import {
  buildInstallCommand,
  buildUninstallCommand,
  normalizeDevicePlatform
} from './device-command-utils';

// Generate a macOS install command
const installCmd = buildInstallCommand({
  platform: 'darwin',
  serverUrl: 'https://my-tenant.openframe.ai',
  initialKey: 'abc123',
  orgId: 'org_xyz',
  releaseVersion: 'v1.2.0',
});

// Generate a Windows uninstall command
const uninstallCmd = buildUninstallCommand({
  platform: 'windows',
  releaseVersion: 'v1.2.0',
});

// Normalize a raw OS string from a device record
const platform = normalizeDevicePlatform(undefined, 'Win32');
// → 'windows'
```
