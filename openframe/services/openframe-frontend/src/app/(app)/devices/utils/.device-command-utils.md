Utilities for generating platform-specific OpenFrame client installation and uninstallation shell commands, plus OS platform normalization across Windows, macOS, and Linux.

## Key Components

- **`buildBinaryUrl(version, assetName)`** — Constructs the GitHub release download URL; falls back to `/latest/download/` when no version is specified
- **`getMacBinaryUrl(version)`** / **`getWindowsBinaryUrl(version)`** — Platform-specific binary URL helpers
- **`buildInstallCommand(options)`** — Generates a full one-liner shell command (PowerShell for Windows, bash for macOS) that downloads, extracts, and runs the OpenFrame client installer
- **`buildUninstallCommand(options)`** — Same pattern as install but runs the `uninstall` subcommand
- **`normalizeDevicePlatform(platform?, osType?, operatingSystem?)`** — Resolves various OS strings (`win32`, `darwin`, `ubuntu`, etc.) to a canonical `OSPlatformId` (`windows` | `darwin` | `linux`)
- **`InstallCommandOptions`** — Interface with `platform`, `serverUrl`, `initialKey`, `orgId`, `releaseVersion`, and optional `additionalArgs`
- **`UninstallCommandOptions`** — Interface with `platform` and `releaseVersion`

## Usage Example

```typescript
import {
  buildInstallCommand,
  buildUninstallCommand,
  normalizeDevicePlatform,
} from './device-command-utils';

// Normalize an incoming device OS string
const platform = normalizeDevicePlatform(undefined, 'win32'); // → 'windows'

// Generate a Windows install command
const installCmd = buildInstallCommand({
  platform,
  serverUrl: 'https://openframe.example.com',
  initialKey: 'abc123',
  orgId: 'org_456',
  releaseVersion: 'v1.2.0',
  additionalArgs: ['--silent'],
});

// Generate a macOS uninstall command
const uninstallCmd = buildUninstallCommand({
  platform: 'darwin',
  releaseVersion: 'v1.2.0',
});
```

> When `releaseVersion` is an empty string, both `buildInstallCommand` and `buildUninstallCommand` automatically resolve to the latest GitHub release via `/releases/latest/download/`.
