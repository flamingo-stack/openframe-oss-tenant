Provides device status configuration utilities for consistent status mapping and OS type resolution across table and grid views in the OpenFrame device management UI.

## Key Components

**Types**
- `DeviceStatusVariant` — Union type for UI badge variants: `success`, `error`, `warning`, `grey`, `critical`
- `DeviceCardStatus` — Union type for card-level status: `active`, `inactive`, `offline`, `warning`, `error`
- `DeviceStatusConfig` — Interface combining `label`, `variant`, and `cardStatus` for a given device state

**Functions**
- `getDeviceStatusConfig(status)` — Maps raw device status strings to a `DeviceStatusConfig` object; case-insensitive; falls back to `grey`/`inactive` for unknown values
- `getDeviceOperatingSystem(osType?)` — Wraps `getOSPlatformId` from `openframe-frontend-core` to resolve an `OSPlatformId` (`darwin`, `windows`, `linux`)

## Status Mapping Reference

| Input Status | Label | Variant | Card Status |
|---|---|---|---|
| `ONLINE` | ONLINE | `success` | `active` |
| `PENDING`, `ACTIVE` | PENDING | `warning` | `warning` |
| `OFFLINE`, `DECOMMISSIONED`, `DELETED` | — | `error` | `offline` |
| `IDLE`, `INACTIVE`, `ARCHIVED` | — | `grey` | `inactive` |
| `MAINTENANCE` | MAINTENANCE | `warning` | `warning` |

## Usage Example

```typescript
import { getDeviceStatusConfig, getDeviceOperatingSystem } from './device-status';

// Resolve display config for a device row or card
const statusConfig = getDeviceStatusConfig('ONLINE');
// { label: 'ONLINE', variant: 'success', cardStatus: 'active' }

// Render a status badge
<Badge variant={statusConfig.variant}>{statusConfig.label}</Badge>

// Resolve OS platform icon
const os = getDeviceOperatingSystem('macOS Sonoma');
// 'darwin'

<DeviceCard osType={os} status={statusConfig.cardStatus} />
```
