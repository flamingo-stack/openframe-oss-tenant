Utility module that maps raw device status strings and OS types to normalized display configurations for consistent rendering across table and grid views.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `DeviceStatusVariant` | Badge/chip color variant: `success`, `error`, `warning`, `grey`, `critical` |
| `DeviceCardStatus` | Semantic card state: `active`, `inactive`, `offline`, `warning`, `error` |
| `DeviceStatusConfig` | Combined display config with `label`, `variant`, and `cardStatus` |

### Functions

**`getDeviceStatusConfig(status: string): DeviceStatusConfig`**
Normalizes raw device status strings (case-insensitive) into a display config. Handles `ONLINE`, `PENDING`, `ACTIVE`, `OFFLINE`, `IDLE`, `INACTIVE`, `MAINTENANCE`, `ARCHIVED`, `DECOMMISSIONED`, `DELETED`, and falls back gracefully for unknown values.

**`getDeviceOperatingSystem(osType?: string): OSPlatformId | undefined`**
Delegates to `getOSPlatformId` from `openframe-frontend-core` to resolve an OS string into a normalized platform ID (`darwin` | `windows` | `linux`).

## Usage Example

```typescript
import { getDeviceStatusConfig, getDeviceOperatingSystem } from './device-status';

// Status config for table/grid rendering
const config = getDeviceStatusConfig('ONLINE');
// { label: 'ONLINE', variant: 'success', cardStatus: 'active' }

const offlineConfig = getDeviceStatusConfig('DECOMMISSIONED');
// { label: 'DECOMMISSIONED', variant: 'error', cardStatus: 'offline' }

// OS platform resolution for DeviceCard
const os = getDeviceOperatingSystem('darwin');
// 'darwin'

const unknown = getDeviceOperatingSystem('unknown-os');
// undefined
```

## Status Mapping Reference

| Input Status | Label | Variant | Card Status |
|---|---|---|---|
| `ONLINE` | ONLINE | `success` | `active` |
| `PENDING` / `ACTIVE` | PENDING | `warning` | `warning` |
| `OFFLINE` / `DECOMMISSIONED` / `DELETED` | *(as-is)* | `error` | `offline` |
| `IDLE` / `INACTIVE` / `ARCHIVED` | *(normalized)* | `grey` | `inactive` |
| `MAINTENANCE` | MAINTENANCE | `warning` | `warning` |
| *(unknown)* | *(uppercased)* | `grey` | `inactive` |
