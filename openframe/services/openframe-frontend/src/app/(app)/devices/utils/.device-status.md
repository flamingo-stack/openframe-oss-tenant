Provides device status configuration utilities for consistent status mapping and OS type resolution across table and grid views in the OpenFrame device management UI.

## Key Components

**Types**
- `DeviceStatusVariant` — Badge/indicator style variants: `success`, `error`, `warning`, `grey`, `critical`
- `DeviceCardStatus` — Card-level status states: `active`, `inactive`, `offline`, `warning`, `error`
- `DeviceStatusConfig` — Aggregated config shape with `label`, `variant`, and `cardStatus`

**Functions**
- `getDeviceStatusConfig(status)` — Maps a raw device status string to a `DeviceStatusConfig` object for display in both table and grid views
- `getDeviceOperatingSystem(osType?)` — Resolves an OS type string to a normalized `OSPlatformId` (`darwin` | `windows` | `linux`) via the shared `@flamingo-stack/openframe-frontend-core` package

## Status Mapping Reference

| Input Status | Label | Variant | Card Status |
|---|---|---|---|
| `ONLINE` | ONLINE | `success` | `active` |
| `PENDING` / `ACTIVE` | PENDING | `warning` | `warning` |
| `OFFLINE` / `DECOMMISSIONED` / `DELETED` | — | `error` | `offline` |
| `IDLE` / `INACTIVE` / `ARCHIVED` | — | `grey` | `inactive` |
| `MAINTENANCE` | MAINTENANCE | `warning` | `warning` |
| _(unknown)_ | raw value | `grey` | `inactive` |

## Usage Example

```typescript
import { getDeviceStatusConfig, getDeviceOperatingSystem } from './device-status';

// Resolve display config for a device row
const config = getDeviceStatusConfig('ONLINE');
// → { label: 'ONLINE', variant: 'success', cardStatus: 'active' }

// Resolve OS platform for icon rendering
const os = getDeviceOperatingSystem('windows 11');
// → 'windows'
```
