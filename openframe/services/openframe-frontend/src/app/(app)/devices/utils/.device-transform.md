Transforms a GraphQL node (`DevicesGraphQlNode`) into a normalized `Device` object optimized for list view rendering, omitting fields that require external API calls.

## Key Components

**`createDeviceListItem(node: DevicesGraphQlNode): Device`**
Maps a raw GraphQL device node to a flat `Device` shape suitable for list/table views. Fields unavailable at the GraphQL layer (CPU details, memory, storage, MDM, software) are explicitly set to `undefined` to maintain type contract integrity.

Notable mapping behaviors:
- `hostname` falls back to `displayName` if not set (and vice versa)
- `local_ips` is coerced to a single-element array from `node.ip`, or `[]` if absent
- `tacticalAgentId` is resolved by scanning `toolConnections` for a `TACTICAL_RMM` entry
- `organizationImageUrl` defaults to `null` (not `undefined`) when missing

## Usage Example

```typescript
import { createDeviceListItem } from './device-transform';
import { DevicesGraphQlNode } from '../types/device.types';

const graphqlNode: DevicesGraphQlNode = {
  id: 'dev-123',
  hostname: 'workstation-01',
  ip: '192.168.1.50',
  status: 'online',
  osType: 'windows',
  osVersion: '11',
  toolConnections: [
    { toolType: 'TACTICAL_RMM', agentToolId: 'tac-456' }
  ],
  organization: { organizationId: 'org-1', name: 'Acme Corp', image: null },
  // ...other fields
};

const device = createDeviceListItem(graphqlNode);
console.log(device.tacticalAgentId); // 'tac-456'
console.log(device.cpu_brand);       // undefined (not fetched in list view)
```

> **Note:** Use this transform for list/table views only. Detail views requiring CPU, memory, storage, or MDM data should use a separate enriched transform that makes additional API calls.
