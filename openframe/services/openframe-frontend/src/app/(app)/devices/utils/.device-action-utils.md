Utility module providing a unified, single-source-of-truth for determining device action availability across MeshCentral, Tactical RMM, and Fleet MDM integrations.

## Key Components

**Status Helpers**
- `isDeviceOnline(status)` — Case-insensitive check for `ONLINE` status
- `canArchiveDevice(status)` — Returns `true` if device is not `ARCHIVED` or `DELETED`
- `canDeleteDevice(status)` — Returns `true` if device is not `DELETED`

**Tool Connection Helpers**
- `getToolConnection(toolConnections, toolType)` — Finds a connection by type (`MESHCENTRAL`, `TACTICAL_RMM`, `FLEET_MDM`)
- `getMeshCentralAgentId(device)` — Extracts the MeshCentral agent ID
- `getTacticalAgentId(device)` — Extracts the Tactical RMM agent ID
- `getFleetHostId(device)` — Extracts and coerces the Fleet MDM host ID to a number

**Action Availability**
- `DeviceActionAvailability` — Interface describing all enabled states and resolved tool IDs
- `getDeviceActionAvailability(device)` — Computes the full availability object for a device

## Usage Example

```typescript
import { getDeviceActionAvailability } from './device-action-utils';

const availability = getDeviceActionAvailability(device);

if (availability.remoteShellEnabled) {
  openShell(availability.meshcentralAgentId);
}

if (availability.runScriptEnabled) {
  runScript(availability.tacticalAgentId);
}

if (availability.archiveEnabled) {
  archiveDevice(device.id);
}
```

## Action Enablement Rules

| Action | Requirement |
|---|---|
| Remote Shell / Control / Files | MeshCentral agent present + device `ONLINE` + MeshCentral not `offline` |
| Run Script | Tactical RMM agent present + device `ONLINE` |
| Archive | Status is not `ARCHIVED` or `DELETED` |
| Delete | Status is not `DELETED` |
