Provides unified, centralized logic for determining which actions are available for a device based on its status and tool connections (MeshCentral, Tactical RMM, Fleet MDM).

## Key Components

### Interfaces
- **`DeviceActionAvailability`** — Result shape describing enabled/disabled states for all device actions, available tool IDs, and online status.

### Utility Functions

| Function | Description |
|---|---|
| `isDeviceOnline(status)` | Case-insensitive check if device status is `ONLINE` |
| `canArchiveDevice(status)` | Returns `true` if status is not `ARCHIVED` or `DELETED` |
| `canDeleteDevice(status)` | Returns `true` if status is not `DELETED` |
| `getToolConnection(toolConnections, toolType)` | Finds a connection by tool type (`MESHCENTRAL`, `TACTICAL_RMM`, `FLEET_MDM`) |
| `getMeshCentralAgentId(device)` | Extracts MeshCentral agent ID from tool connections |
| `getTacticalAgentId(device)` | Extracts Tactical RMM agent ID from tool connections |
| `getFleetHostId(device)` | Extracts Fleet MDM host ID as a numeric value |
| `getDeviceActionAvailability(device)` | **Primary entry point** — returns the full `DeviceActionAvailability` object |

## Usage Example

```typescript
import { getDeviceActionAvailability } from './device-action-utils';

const availability = getDeviceActionAvailability(device);

// Gate UI actions
if (availability.remoteShellEnabled) {
  openRemoteShell(availability.meshcentralAgentId);
}

if (availability.runScriptEnabled) {
  runScript(availability.tacticalAgentId);
}

if (availability.archiveEnabled) {
  archiveDevice(device.id);
}
```

> **Note:** `remoteShellEnabled`, `remoteControlEnabled`, and `manageFilesEnabled` all require a valid MeshCentral agent ID, an online device, and a non-offline MeshCentral connection. `runScriptEnabled` requires a Tactical RMM agent ID and an online device.
