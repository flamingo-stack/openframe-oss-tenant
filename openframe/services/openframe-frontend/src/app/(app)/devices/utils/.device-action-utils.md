Provides unified logic for determining device action availability across remote management tools (MeshCentral, Tactical RMM, Fleet MDM), serving as the single source of truth for enabling/disabling device actions in the Flamingo platform.

## Key Components

**Status Helpers**
- `isDeviceOnline(status)` — Case-insensitive check for `ONLINE` status
- `canArchiveDevice(status)` — Returns `true` if device is not `ARCHIVED` or `DELETED`
- `canDeleteDevice(status)` — Returns `true` if device is not `DELETED`

**Tool Connection Helpers**
- `getToolConnection(toolConnections, toolType)` — Finds a connection by tool type (`MESHCENTRAL`, `TACTICAL_RMM`, `FLEET_MDM`)
- `getMeshCentralAgentId(device)` — Extracts MeshCentral agent ID
- `getTacticalAgentId(device)` — Extracts Tactical RMM agent ID
- `getFleetHostId(device)` — Extracts Fleet MDM host ID as a `number`

**Core Export**
- `DeviceActionAvailability` — Interface describing all action enabled states and resolved tool IDs
- `getDeviceActionAvailability(device)` — Computes the full availability object for a device

## Usage Example

```typescript
import { getDeviceActionAvailability } from './device-action-utils';

const availability = getDeviceActionAvailability(device);

// Gate UI actions
if (availability.remoteShellEnabled) {
  openRemoteShell(availability.meshcentralAgentId);
}

if (availability.runScriptEnabled) {
  runScript(availability.tacticalAgentId);
}

if (availability.archiveEnabled) {
  archiveDevice(device.id);
}
```

## Action Enablement Rules

| Action | Requirements |
|--------|-------------|
| `remoteShellEnabled` | MeshCentral agent present + device online + agent not offline |
| `remoteControlEnabled` | Same as remote shell |
| `manageFilesEnabled` | Same as remote shell |
| `runScriptEnabled` | Tactical RMM agent present + device online |
| `archiveEnabled` | Status is not `ARCHIVED` or `DELETED` |
| `deleteEnabled` | Status is not `DELETED` |
