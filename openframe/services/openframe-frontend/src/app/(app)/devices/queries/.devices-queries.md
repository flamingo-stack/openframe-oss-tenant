GraphQL query definitions for device-related operations, providing queries to fetch device lists, individual device details, filter metadata, and lightweight overview data.

## Key Components

| Export | Operation | Description |
|--------|-----------|-------------|
| `GET_DEVICE_FILTERS_QUERY` | `GetDeviceFilters` | Retrieves available filter facets (statuses, device types, OS types, organizations, tags) with counts |
| `GET_DEVICES_QUERY` | `GetDevices` | Paginated device list with full field set, filtering, sorting, and cursor-based pagination |
| `GET_DEVICE_QUERY` | `GetDevice` | Single device lookup by `machineId`, includes `installedAgents` not present in list queries |
| `GET_DEVICES_OVERVIEW_QUERY` | `GetDevicesOverview` | Lightweight paginated query returning only `status` per device, used for summary/dashboard views |

## Usage Example

```typescript
import {
  GET_DEVICES_QUERY,
  GET_DEVICE_QUERY,
  GET_DEVICE_FILTERS_QUERY,
} from './devices-queries';

// Fetch paginated devices with filters and sorting
const devicesResult = await graphqlClient.request(GET_DEVICES_QUERY, {
  filter: { osType: 'WINDOWS', organizationIds: ['org_123'] },
  first: 25,
  after: null,
  search: 'workstation',
  sort: { field: 'lastSeen', direction: 'DESC' },
});

// Fetch a single device by machineId
const deviceResult = await graphqlClient.request(GET_DEVICE_QUERY, {
  machineId: 'machine-uuid-abc123',
});

// Fetch filter facets scoped to an organization
const filtersResult = await graphqlClient.request(GET_DEVICE_FILTERS_QUERY, {
  filter: { organizationIds: ['org_123'] },
});
```

> **Note:** `GET_DEVICE_QUERY` additionally returns `installedAgents` (agent type, version, timestamps), making it the preferred query when full device detail is required. Use `GET_DEVICES_OVERVIEW_QUERY` for high-frequency polling or summary dashboards where minimal payload is preferred.
