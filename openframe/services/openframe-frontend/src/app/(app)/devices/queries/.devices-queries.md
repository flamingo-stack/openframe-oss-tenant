GraphQL query definitions for device-related operations, providing queries for fetching device lists, individual device details, filter metadata, and lightweight overview data.

## Key Components

| Export | Description |
|--------|-------------|
| `GET_DEVICE_FILTERS_QUERY` | Fetches available filter facets (statuses, device types, OS types, organizations, tags) with counts for a given filter input |
| `GET_DEVICES_QUERY` | Paginated device list with full node details including hardware info, OS, organization, tool connections, and tags |
| `GET_DEVICE_QUERY` | Single device lookup by `machineId`, including installed agents not returned by the list query |
| `GET_DEVICES_OVERVIEW_QUERY` | Lightweight paginated query returning only device `status` — optimized for dashboard/summary views |

## Usage Example

```typescript
import {
  GET_DEVICES_QUERY,
  GET_DEVICE_QUERY,
  GET_DEVICE_FILTERS_QUERY,
} from './devices-queries';

// Fetch paginated devices with filtering and sorting
const devicesResult = await graphqlClient.query({
  query: GET_DEVICES_QUERY,
  variables: {
    filter: { osType: 'WINDOWS', status: 'ONLINE' },
    first: 25,
    after: null,
    search: 'workstation',
    sort: { field: 'lastSeen', direction: 'DESC' },
  },
});

// Fetch a single device by machineId
const deviceResult = await graphqlClient.query({
  query: GET_DEVICE_QUERY,
  variables: { machineId: 'abc-123-xyz' },
});

// Fetch filter facets for sidebar/filter UI
const filtersResult = await graphqlClient.query({
  query: GET_DEVICE_FILTERS_QUERY,
  variables: { filter: { organizationIds: ['org-1'] } },
});
```

> **Note:** `GET_DEVICE_QUERY` is the only query that returns `installedAgents`. Use `GET_DEVICES_OVERVIEW_QUERY` when only status counts are needed to minimize payload size.
