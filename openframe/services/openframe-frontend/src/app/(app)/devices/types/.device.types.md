Unified type definitions serving as the single source of truth for all device-related data structures across the Flamingo/OpenFrame platform.

## Key Components

| Export | Kind | Description |
|--------|------|-------------|
| `Device` | Interface | Primary unified device type — all fields flat at root level, no nesting |
| `Software` | Interface | Installed software entry with vulnerability and path info |
| `Vulnerability` | Interface | CVE vulnerability record linked to a software item |
| `Battery` | Interface | Battery health and cycle count |
| `User` | Interface | Local user account on a device |
| `MdmInfo` | Interface | MDM enrollment and fleet connection state |
| `DeviceTag` | Interface | Key/value tag with optional color and description |
| `ToolType` | Type alias | Union of supported RMM/MDM tool identifiers |
| `ToolConnection` | Interface | Per-tool agent connection record with sync timestamps |
| `InstalledAgent` | Interface | Agent installation record on a machine |
| `DeviceFilters` / `DeviceFilterInput` | Interfaces | Filter options and input shape for device list queries |
| `DevicesGraphQlNode` / `DeviceGraphQlNode` | Types | GraphQL response node shapes for list vs. detail queries |
| `GraphQlResponse<T>` | Generic Interface | Wrapper for GraphQL responses with typed `data` and `errors` |

## Usage Example

```typescript
import type {
  Device,
  Software,
  ToolConnection,
  DeviceFilterInput,
  GraphQlResponse,
  DevicesGraphQlNode,
} from './device.types';

// Typed device object
const device: Device = {
  id: 'abc-123',
  machineId: 'machine-456',
  hostname: 'mac-pro-01',
  displayName: 'Alice's MacBook',
  status: 'online',
  local_ips: ['192.168.1.10'],
};

// Filter devices by OS type and tag
const filters: DeviceFilterInput = {
  osTypes: ['macOS'],
  tagKeys: ['env'],
  tagValues: ['production'],
};

// Handle a GraphQL list response
function handleResponse(res: GraphQlResponse<{ devices: DevicesGraphQlNode[] }>) {
  if (res.errors?.length) {
    console.error(res.errors[0].message);
    return;
  }
  const nodes = res.data?.devices ?? [];
  nodes.forEach(node => console.log(node.hostname, node.status));
}
```

> **Note:** `Device` intentionally keeps all fields at the root level (no nested hardware/network sub-objects) to simplify cross-tool normalization between Fleet MDM, Tactical RMM, and MeshCentral data sources.
