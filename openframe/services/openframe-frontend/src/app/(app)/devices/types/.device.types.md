Single source of truth for all device-related TypeScript types used across the Flamingo/OpenFrame platform, defining unified flat structures for devices, software, hardware, and filtering.

## Key Components

| Export | Kind | Description |
|--------|------|-------------|
| `Device` | `interface` | Primary unified device model — all fields at root level, no nesting |
| `Software` | `interface` | Installed software with vulnerability tracking and multi-source support |
| `Vulnerability` | `interface` | CVE vulnerability record linked to a software entry |
| `Battery` | `interface` | Battery cycle count and health status |
| `User` | `interface` | Local device user account info |
| `MdmInfo` | `interface` | MDM enrollment and Fleet connection details |
| `DeviceTag` | `interface` | Tag key/value pairs with optional color and description |
| `ToolType` | `type` | Union of supported RMM/MDM tool identifiers (`MESHCENTRAL`, `TACTICAL_RMM`, `FLEET_MDM`) |
| `ToolConnection` | `interface` | Agent tool link with sync timestamps and status |
| `InstalledAgent` | `interface` | Installed agent record per device |
| `DeviceFilters` | `interface` | Aggregated filter options for device list views |
| `DeviceFilterInput` | `interface` | User-supplied filter parameters |
| `DevicesGraphQlNode` | `type` | GraphQL list query response shape |
| `DeviceGraphQlNode` | `type` | GraphQL single device query response shape |
| `GraphQlResponse<T>` | `interface` | Generic GraphQL response wrapper with typed data and errors |

## Usage Example

```typescript
import type {
  Device,
  Software,
  ToolType,
  DeviceFilterInput,
  GraphQlResponse,
  DevicesGraphQlNode
} from './device.types';

// Type-safe device access
const device: Device = getDeviceById('abc-123');
console.log(device.hostname, device.os_version, device.status);

// Check installed software vulnerabilities
const vulnerable: Software[] = (device.software ?? []).filter(
  (s) => s.vulnerabilities.length > 0
);

// Filter devices by OS and tag
const filters: DeviceFilterInput = {
  osTypes: ['windows'],
  tagKeys: ['env'],
  tagValues: ['production'],
};

// Handle GraphQL response
const response: GraphQlResponse<{ devices: DevicesGraphQlNode[] }> = await fetchDevices();
if (response.errors) {
  console.error(response.errors[0].message);
} else {
  const nodes = response.data?.devices ?? [];
}

// Narrow tool connection type
const toolType: ToolType = 'FLEET_MDM';
const fleetConn = device.toolConnections?.find((c) => c.toolType === toolType);
```
