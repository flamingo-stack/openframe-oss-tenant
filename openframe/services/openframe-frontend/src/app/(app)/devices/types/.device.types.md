Unified type definitions serving as the single source of truth for device-related data structures across the Flamingo/OpenFrame platform.

## Key Components

| Export | Kind | Description |
|--------|------|-------------|
| `Device` | `interface` | Primary unified device model — all fields flat at root level, no nesting |
| `Software` | `interface` | Installed software with vulnerability tracking and multi-source support |
| `Vulnerability` | `interface` | CVE entry linked to a software record |
| `Battery` | `interface` | Battery cycle count and health string |
| `User` | `interface` | Local/logged-in user account on a device |
| `MdmInfo` | `interface` | MDM enrollment state and Fleet/MDM connection details |
| `DeviceTag` | `interface` | Key/value tag with optional color and description |
| `ToolType` | `type` | Union of supported RMM/MDM tool identifiers: `MESHCENTRAL`, `TACTICAL_RMM`, `FLEET_MDM` |
| `ToolConnection` | `interface` | Active connection record between a device and an RMM/MDM tool |
| `InstalledAgent` | `interface` | Agent installation record on a device |
| `DeviceFilters` | `interface` | Aggregated filter options returned from the API (counts per value) |
| `DeviceFilterInput` | `interface` | Filter parameters sent in a device list query |
| `DevicesGraphQlNode` | `type` | Lightweight GraphQL list-view representation of a device |
| `DeviceGraphQlNode` | `type` | Full GraphQL detail-view representation of a device |
| `GraphQlResponse<T>` | `interface` | Generic GraphQL response wrapper with optional errors |

## Usage Example

```typescript
import type {
  Device,
  Software,
  ToolConnection,
  DeviceFilterInput,
  GraphQlResponse,
  DevicesGraphQlNode,
} from './device.types';

// Render a device summary
function getDeviceSummary(device: Device): string {
  return `${device.displayName} (${device.osType ?? 'Unknown OS'}) — ${device.status}`;
}

// Check if any installed software has known CVEs
function hasVulnerabilities(software: Software[]): boolean {
  return software.some((s) => s.vulnerabilities.length > 0);
}

// Build a filter query payload
const filters: DeviceFilterInput = {
  statuses: ['online'],
  osTypes: ['macOS', 'Windows'],
  organizationIds: ['org_abc123'],
};

// Type a GraphQL list response
type DeviceListResponse = GraphQlResponse<{
  devices: { nodes: DevicesGraphQlNode[] };
}>;

// Narrow a tool connection to Fleet MDM
function isFleetConnection(conn: ToolConnection): boolean {
  return conn.toolType === 'FLEET_MDM';
}
```
