Complete TypeScript type definitions for Fleet MDM API responses, modeling host inventory data including hardware, software, network, MDM enrollment, and security information.

## Key Components

| Interface | Description |
|-----------|-------------|
| `FleetHost` | Primary host record with ~50 fields covering hardware, OS, network, storage, and status |
| `FleetHostResponse` | Top-level API response wrapper containing a single `FleetHost` |
| `FleetSoftware` | Installed software entry with CVE vulnerability tracking and signature info |
| `FleetVulnerability` | CVE reference attached to a software record |
| `FleetSignatureInfo` | macOS code-signing metadata for installed apps |
| `FleetMdmInfo` | MDM enrollment state, DEP profile status, and device management details |
| `FleetLabel` | Fleet label/group membership with query and platform metadata |
| `FleetUser` | Local OS user account record |
| `FleetBattery` | Battery health and cycle count (primarily macOS) |
| `FleetIssues` | Aggregated policy failure and issue counts for a host |

## Usage Example

```typescript
import {
  FleetHostResponse,
  FleetHost,
  FleetSoftware,
} from './fleet.types';

// Parse a Fleet MDM API response
async function getHostDetails(hostId: number): Promise<FleetHost> {
  const response = await fetch(`/api/v1/fleet/hosts/${hostId}`);
  const data: FleetHostResponse = await response.json();
  return data.host;
}

// Filter vulnerable software on a host
function getVulnerableSoftware(host: FleetHost): FleetSoftware[] {
  return (host.software ?? []).filter(
    (pkg) => pkg.vulnerabilities && pkg.vulnerabilities.length > 0
  );
}

// Check MDM enrollment and encryption status
function isCompliant(host: FleetHost): boolean {
  return (
    host.mdm.enrollment_status === 'On (automatic)' &&
    host.disk_encryption_enabled &&
    host.issues.failing_policies_count === 0
  );
}
```
