Defines TypeScript interfaces for Fleet MDM API response data, providing complete type coverage for host inventory including hardware, software, network, MDM enrollment, and vulnerability information.

## Key Components

| Interface | Description |
|---|---|
| `FleetHost` | Primary interface representing a managed device with ~50+ typed fields across hardware, OS, network, storage, and status categories |
| `FleetHostResponse` | Wrapper interface for the Fleet API `/hosts/:id` endpoint response |
| `FleetSoftware` | Installed software entry with source type union, vulnerability list, and signature details |
| `FleetVulnerability` | CVE record linked to a Fleet details page |
| `FleetMdmInfo` | MDM enrollment state, DEP profile status, encryption key availability, and pending actions |
| `FleetLabel` | osquery-based host label with query, platform, and membership type metadata |
| `FleetIssues` | Aggregate counts for failing policies and total host issues |
| `FleetUser` | Local OS user account with UID, group, and shell |
| `FleetBattery` | Battery cycle count and health string |
| `FleetSignatureInfo` | macOS code-signing path and team identifier |

## Usage Example

```typescript
import { FleetHostResponse, FleetSoftware } from './fleet.types';

async function getHostDetails(hostId: number): Promise<FleetHost> {
  const response = await fetch(`/api/fleet/hosts/${hostId}`);
  const data: FleetHostResponse = await response.json();
  return data.host;
}

// Filter vulnerable software on a host
function getVulnerableSoftware(host: FleetHost): FleetSoftware[] {
  return (host.software ?? []).filter(
    (sw) => sw.vulnerabilities && sw.vulnerabilities.length > 0
  );
}

// Check MDM enrollment and encryption status
function isCompliant(host: FleetHost): boolean {
  return (
    host.mdm.enrollment_status === 'On (automatic)' &&
    host.disk_encryption_enabled &&
    host.issues.failing_policies_count === 0
  );
}
```
