Main page view component for the Devices section, rendering either a table or grid layout with search, filtering, and infinite scroll capabilities.

## Key Components

- **`DevicesView`** — Primary exported component that composes the full devices page, including URL-synced state, data fetching, and view toggling

### Internal Hooks Used
| Hook | Purpose |
|------|---------|
| `useDevicesUrlParams` | Manages URL search params, local search state, and tag/filter handlers |
| `useDevices` | Fetches paginated device data with infinite scroll support |
| `useDeviceFilters` | Fetches available filter options (status, OS, org) |
| `useTagFilterModal` | Controls the filter modal state and tag selection |
| `useGridInfiniteScroll` | Wires up intersection observer for grid auto-loading |

### View Modes
- **Table** — `DevicesTableBody` with column filters, row actions, and an infinite scroll footer
- **Grid** — `DevicesGrid` with sentinel-based auto-loading

## Usage Example

```typescript
// Rendered at the /devices route (Next.js App Router)
import { DevicesView } from './components/devices-view';

export default function DevicesPage() {
  return <DevicesView />;
}
```
