Renders a context-aware dropdown menu for device actions, adapting available options based on whether it appears in a table row or device detail view.

## Key Components

**`DeviceActionsDropdownProps`**
- `device` — The target `Device` object for all actions
- `context` — `'table'` or `'detail'`; controls which action items are included
- `onActionComplete?` — Optional callback fired after any action completes
- `onRunScript?` — Optional callback for the run script action

**`DeviceActionsDropdown`**
Main export. Builds two action groups via `useMemo`:
- **Primary group** — Remote Shell, Remote Control, and Manage Files (table context only) + Run Script; rendered with a separator
- **Destructive group** — Archive and/or Delete, if available

Renders `null` when no groups are populated (e.g., user lacks permissions for all actions). Wraps output in `data-no-row-click` to prevent table row click propagation.

## Usage Example

```typescript
// Inside a device table row
<DeviceActionsDropdown
  device={device}
  context="table"
  onActionComplete={() => refetch()}
/>

// Inside a device detail page
<DeviceActionsDropdown
  device={device}
  context="detail"
  onRunScript={() => setScriptPanelOpen(true)}
  onActionComplete={() => refetch()}
/>
```

> **Note:** In `detail` context, Remote Shell, Remote Control, and Manage Files are intentionally omitted from the dropdown — they are expected to be surfaced as dedicated buttons elsewhere on the detail page.
