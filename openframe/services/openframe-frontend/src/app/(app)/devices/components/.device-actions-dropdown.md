Renders a context-aware dropdown menu for device actions, adapting available options based on whether it appears in a table row or device detail view.

## Key Components

**`DeviceActionsDropdownProps`**
- `device` — The target `Device` object
- `context` — `'table'` or `'detail'`; controls which actions are visible
- `onActionComplete` — Optional callback fired after any action completes
- `onRunScript` — Optional callback to trigger the run script flow

**`DeviceActionsDropdown`**
Main export. Builds grouped menu items via `useDeviceActionsMenu`, then organizes them into two `ActionsMenuGroup` sections:
- **Actions group** — Remote Shell, Remote Control, Manage Files (table only), Run Script
- **Destructive group** — Archive and/or Delete (when available)

Returns `null` if no groups are populated. Wraps output in `data-no-row-click` to prevent table row click propagation.

## Usage Example

```typescript
// In a device table row
<DeviceActionsDropdown
  device={device}
  context="table"
  onActionComplete={() => refetch()}
  onRunScript={() => openScriptPanel()}
/>

// In a device detail page (remote actions rendered elsewhere)
<DeviceActionsDropdown
  device={device}
  context="detail"
  onActionComplete={() => router.push('/devices')}
/>
```

> In `detail` context, Remote Shell/Control/Files are intentionally omitted from the dropdown since they are surfaced as dedicated buttons elsewhere on the page. Destructive actions in `detail` context will also trigger navigation on completion.
