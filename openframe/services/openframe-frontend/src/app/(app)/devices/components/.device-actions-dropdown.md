Renders a context-aware dropdown menu of available actions for a device, adapting its menu items based on whether it's displayed in a table row or device detail view.

## Key Components

- **`DeviceActionsDropdownProps`** — Interface defining required `device` and `context` props, plus optional `onActionComplete` and `onRunScript` callbacks
- **`useDeviceActionsMenu`** — Hook that resolves available action items and associated dialog components for the given device
- **`menuGroups`** — Memoized array of `ActionsMenuGroup` objects, split into a primary group (remote actions + scripts) and a destructive group (archive/delete)
- **`ActionsMenuDropdown`** — Core UI component from `openframe-frontend-core` that renders the grouped menu

## Context Behavior

| Context | Remote Shell / Control / Files | Run Script | Archive / Delete |
|---------|-------------------------------|------------|-----------------|
| `table` | ✅ Included | ✅ Included | If permitted |
| `detail` | ❌ Excluded (shown elsewhere) | ✅ Included | If permitted |

> In `detail` context, `navigateOnDestructive` is enabled so the user is redirected after destructive actions like deletion.

## Usage Example

```typescript
// Inside a device table row
<DeviceActionsDropdown
  device={device}
  context="table"
  onActionComplete={() => refetchDevices()}
/>

// Inside a device detail page
<DeviceActionsDropdown
  device={device}
  context="detail"
  onRunScript={() => openScriptPanel()}
  onActionComplete={() => refetchDevice()}
/>
```

Returns `null` if no menu groups are resolved (e.g., the user lacks permissions for all actions).
