Modal component for selecting and executing scripts on a target device, with platform-compatible filtering, category browsing, search, and multi-select capabilities.

## Key Components

### `ScriptsModal`
Main exported component. Renders a modal dialog allowing users to search, filter, and select scripts to run on a specific device. Handles script execution via `tacticalApiClient`, shows toast notifications for success/partial/failure states, and redirects to device logs after submission.

### `filterScriptsByPlatform(scripts, devicePlatform)`
Filters the script list to only include scripts compatible with the device's OS platform. Uses `getOSPlatformId` and `OS_TYPES` from the OpenFrame core for normalized alias matching.

### `getCategoriesFromScripts(scripts)`
Extracts up to 3 unique, sorted category labels (uppercased) from the script list for use as filter chips.

### `CustomCheckbox`
Internal UI primitive rendering a styled checkbox with an amber accent when active and a bordered card style when inactive.

## Usage Example

```typescript
import { ScriptsModal } from './scripts-modal';

<ScriptsModal
  isOpen={showScripts}
  onClose={() => setShowScripts(false)}
  deviceId="device-abc-123"
  device={{ plat: 'windows' }}
  onRunScripts={(scriptIds) => console.log('Running:', scriptIds)}
  onDeviceLogs={() => router.push('/device/logs')}
/>
```

## Props

| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls modal visibility |
| `onClose` | `() => void` | Called on cancel or after redirect |
| `deviceId` | `string` | Target device identifier for API calls |
| `device` | `Partial<Device> \| null` | Used to filter scripts by `plat` platform field |
| `onRunScripts` | `(scriptIds: string[]) => void` | Callback with selected script IDs |
| `onDeviceLogs` | `() => void` *(optional)* | Called after 3s redirect to navigate to logs tab |
