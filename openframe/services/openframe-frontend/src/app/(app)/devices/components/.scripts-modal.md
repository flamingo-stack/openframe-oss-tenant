Modal component for selecting and executing scripts on a specific device. Provides search, category filtering, platform-compatible script listing, multi-select, and redirects to device logs after execution.

## Key Components

- **`ScriptsModal`** — Main exported modal component rendering the full script selection and execution UI
- **`CustomCheckbox`** — Internal styled checkbox with active/inactive states using ODS tokens
- **`filterScriptsByPlatform`** — Filters scripts by device OS using the centralized `OS_TYPES` / `getOSPlatformId` helpers
- **`getCategoriesFromScripts`** — Extracts and deduplicates up to 3 sorted category labels from a script list
- **`ScriptsModalProps`** — Interface defining `isOpen`, `onClose`, `deviceId`, `device`, `onRunScripts`, and optional `onDeviceLogs`

## Usage Example

```typescript
import { ScriptsModal } from './scripts-modal';

<ScriptsModal
  isOpen={showScripts}
  onClose={() => setShowScripts(false)}
  deviceId="agent-001"
  device={{ plat: 'windows' }}
  onRunScripts={(ids) => console.log('Running scripts:', ids)}
  onDeviceLogs={() => navigateTo('logs')}
/>
```

## Behavior Notes

- Scripts are filtered against the device's platform via `device.plat` before display
- Execution fires parallel `tacticalApiClient.runScript()` calls; partial failures surface via toast
- After submitting, a 3-second redirecting state (skeleton UI) precedes `onDeviceLogs()` + `onClose()`
- Category filter chips are derived from the **platform-filtered** list (max 3), not the full script store
- "Select All" targets the current **filtered** view (search + category), not the full list
