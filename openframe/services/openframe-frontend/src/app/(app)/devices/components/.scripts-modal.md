Modal component for selecting and executing scripts on a specific device, with platform-based filtering, category browsing, multi-select, and redirect-to-logs behavior after submission.

## Key Components

- **`ScriptsModal`** — Primary export. Renders a `SimpleModal` with search, category filters, script list, and run/cancel actions.
- **`filterScriptsByPlatform`** — Filters the script list to only show scripts compatible with the target device's OS, using `getOSPlatformId` and `OS_TYPES` from the UI kit.
- **`getCategoriesFromScripts`** — Extracts and deduplicates up to 3 sorted uppercase categories from a script list.
- **`CustomCheckbox`** — Internal checkbox component rendering an active (amber-filled + check icon) or inactive (bordered) state.

## Usage Example

```typescript
<ScriptsModal
  isOpen={isScriptsModalOpen}
  onClose={() => setScriptsModalOpen(false)}
  deviceId="abc123"
  device={{ plat: 'windows' }}
  onRunScripts={(scriptIds) => console.log('Running:', scriptIds)}
  onDeviceLogs={() => setActiveTab('logs')}
/>
```

## Behavior Notes

- Scripts are fetched via the `useScripts` hook and filtered by `device.plat` before display.
- Each script is executed independently via `tacticalApiClient.runScript`, with partial-success toasts.
- After triggering execution, a 3-second redirect state displays a skeleton loader before calling `onDeviceLogs()` and `onClose()`.
- Category filter chips show the top 3 categories; **Show All** clears the filter.
- **Select All** toggles selection across the currently filtered script list only.
