Renders the **Network** tab for a device detail view, displaying public IP, local IPv4, and local IPv6 addresses sourced from Fleet MDM — with the Fleet-designated primary IP pinned to the top of the IPv4 list.

## Key Components

- **`NetworkTab`** — Main exported component. Accepts a `device` prop and renders network address cards.
- **IP Sorting Logic** — Separates `local_ips` into IPv4/IPv6 arrays, pins `device.primary_ip` to the top of the IPv4 list, numerically sorts the remainder, and lexicographically sorts IPv6 addresses.
- **`InfoCard`** — Renders labeled address groups with copy support.
- **`Tooltip` / `TooltipProvider`** — Provides contextual help text on each card's info icon.

## Usage Example

```typescript
import { NetworkTab } from './network-tab';

const device = {
  public_ip: '203.0.113.42',
  primary_ip: '192.168.1.10',
  local_ips: ['192.168.1.20', '192.168.1.10', '10.0.0.5', 'fe80::1'],
};

<NetworkTab device={device} />
```

## IP Ordering Behavior

| Scenario | Result |
|---|---|
| `primary_ip` present in `local_ips` | Pinned first, rest sorted numerically |
| `primary_ip` not in `local_ips` | All IPs sorted numerically |
| No `primary_ip` | All IPs sorted numerically |
| IPv6 addresses | Shown in separate card, sorted lexicographically |

## Props

| Prop | Type | Description |
|---|---|---|
| `device` | `any` | Device object from Fleet MDM containing `public_ip`, `primary_ip`, and `local_ips` |
