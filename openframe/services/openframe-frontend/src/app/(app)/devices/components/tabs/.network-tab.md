Renders the Network tab for a device detail view, displaying public IP and local IPv4/IPv6 addresses sourced from Fleet MDM with sorting logic that pins the Fleet primary IP to the top of the IPv4 list.

## Key Components

- **`NetworkTab`** — Main exported component that accepts a `device` prop and renders network address information using `InfoCard` and `Tooltip` components from `@flamingo-stack/openframe-frontend-core`
- **IPv4 sorting logic** — Numerically sorts local IPv4 addresses while preserving the Fleet MDM `primary_ip` at the top of the list
- **IPv6 sorting** — Lexicographically sorts IPv6 addresses into a separate card
- **Conditional rendering** — IPv4 and IPv6 cards only render when addresses are present

## Usage Example

```typescript
import { NetworkTab } from './network-tab';

const device = {
  public_ip: '203.0.113.45',
  primary_ip: '192.168.1.10',
  local_ips: ['192.168.1.20', '192.168.1.10', '10.0.0.5', 'fe80::1'],
};

<NetworkTab device={device} />
```

## IP Sorting Behavior

| Scenario | Result |
|---|---|
| `primary_ip` found in `local_ips` | Pinned to top; remaining IPs sorted numerically |
| `primary_ip` not in `local_ips` | All IPs sorted numerically |
| No `primary_ip` | All IPs sorted numerically |
| IPv6 addresses | Separated and sorted lexicographically |
