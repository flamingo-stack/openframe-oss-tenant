Renders the Network tab for a device detail view, displaying public IP and local IPv4/IPv6 addresses sourced from Fleet MDM with sorted, copyable entries.

## Key Components

- **`NetworkTab`** — Main exported component that accepts a `device` prop and renders network address information using `InfoCard` tiles with tooltip descriptions.
- **IP Sorting Logic** — Separates `local_ips` into IPv4 and IPv6 arrays. IPv4 addresses are sorted numerically with the Fleet MDM `primary_ip` pinned to the top; IPv6 addresses are sorted lexicographically.
- **`InfoCard`** — Shared UI component from `@flamingo-stack/openframe-frontend-core` used to display each IP group with copyable values.
- **`TooltipProvider` / `Tooltip`** — Wraps each card's icon with contextual help text explaining the data source and usage.

## Usage Example

```typescript
import { NetworkTab } from './network-tab';

const device = {
  public_ip: '203.0.113.42',
  primary_ip: '192.168.1.10',
  local_ips: ['192.168.1.20', '192.168.1.10', 'fe80::1'],
};

<NetworkTab device={device} />
```

## Notes

- The `primary_ip` field is expected from Fleet MDM and is always rendered first in the IPv4 list regardless of its sort position.
- IPv4/IPv6 cards are conditionally rendered — they only appear when addresses of that type are present.
- All IP values are rendered with `copyable: true`, enabling one-click clipboard copy in the UI.
