Renders a sortable data table of installed software for a given device, displaying software name/vendor/version, installation source, vulnerability count, and last-opened timestamp.

## Key Components

- **`SoftwareTab`** — Main exported component accepting a `Device | null` prop and rendering the software inventory table
- **`columns`** — `ColumnDef<Software>[]` defining four sortable columns: `SOFTWARE`, `SOURCE`, `SECURITY`, and `LAST OPENED`
- **`table`** — `useDataTable` instance with client-side sorting and stable row IDs
- **Vulnerability badge** — Renders a `success` tag for clean software or an `error` tag with issue count

## Usage Example

```typescript
import { SoftwareTab } from './software-tab';
import type { Device } from '../../types/device.types';

export function DeviceDetailPage({ device }: { device: Device | null }) {
  return (
    <div>
      <SoftwareTab device={device} />
    </div>
  );
}
```

## Empty States

| Condition | Rendered output |
|---|---|
| `device` is `null` | "No device data available" |
| `device.software` is empty | "No software data available for this device" |

## Column Summary

| Column | Width | Sortable | Notes |
|---|---|---|---|
| `SOFTWARE` | 40% | ✅ | `SoftwareInfo` with name, vendor, version |
| `SOURCE` | 20% | ✅ | `SoftwareSourceBadge` |
| `SECURITY` | 15% | ✅ | Custom sort by `vulnerabilities.length` |
| `LAST OPENED` | 25% | ✅ | Formatted via `formatDateTime` |
