Renders a sortable data table of installed software for a given device, displaying software name/vendor/version, installation source, vulnerability count, and last-opened timestamp.

## Key Components

- **`SoftwareTab`** — Main exported component; accepts a `device` prop and renders a `DataTable` of installed software entries
- **`columns`** — Memoized `ColumnDef<Software>[]` defining four columns: `SOFTWARE`, `SOURCE`, `SECURITY`, and `LAST OPENED`
- **`SoftwareInfo`** — Renders name, vendor, and version together in a formatted cell
- **`SoftwareSourceBadge`** — Displays the software installation source (e.g., system, store, manual)
- **`Tag`** — Shows vulnerability status as `NO ISSUES` (success) or `N ISSUES` (error)
- **`useDataTable`** — Configures client-side sorting state for the table instance

## Usage Example

```typescript
import { SoftwareTab } from './software-tab';
import type { Device } from '../../types/device.types';

const device: Device = {
  id: 'device-123',
  software: [
    {
      id: 1,
      name: 'Google Chrome',
      vendor: 'Google',
      version: '124.0.0',
      source: 'brew',
      vulnerabilities: [],
      last_opened_at: '2024-05-01T10:00:00Z',
    },
  ],
};

export default function DevicePage() {
  return <SoftwareTab device={device} />;
}
```

## Behavior Notes

- Renders a centered `"No device data available"` message when `device` is `null`
- Renders `"No software data available for this device"` when the software array is empty
- Vulnerability sorting uses a custom `sortingFn` comparing array lengths directly
- Dates fall back to `"Never"` when `last_opened_at` is absent
