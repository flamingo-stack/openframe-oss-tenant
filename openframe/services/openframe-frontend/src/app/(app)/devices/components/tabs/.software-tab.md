Renders a sortable data table of installed software for a given device, displaying name, vendor, version, source, security vulnerability count, and last opened date.

## Key Components

- **`SoftwareTab`** — Main exported component accepting a `device` prop and rendering the software inventory table
- **`columns`** — Memoized `ColumnDef<Software>[]` defining four columns: `SOFTWARE`, `SOURCE`, `SECURITY`, and `LAST OPENED`
- **`useDataTable`** — Hook wiring up client-side sorting state to the `DataTable` component
- **`SoftwareInfo`** — Displays software name, vendor, and version as a composite cell
- **`SoftwareSourceBadge`** — Renders a badge indicating the software's installation source
- **`Tag`** — Shows `NO ISSUES` (success) or `N ISSUES` (error) based on vulnerability count

## Usage Example

```typescript
import { SoftwareTab } from './software-tab';
import type { Device } from '../../types/device.types';

const device: Device = {
  id: 'dev-001',
  software: [
    {
      id: 1,
      name: 'Visual Studio Code',
      vendor: 'Microsoft',
      version: '1.89.0',
      source: 'homebrew',
      vulnerabilities: [],
      last_opened_at: '2024-05-01T10:00:00Z',
    },
  ],
};

export default function DeviceDetails() {
  return <SoftwareTab device={device} />;
}
```

## Empty States

| Condition | Rendered Output |
|-----------|----------------|
| `device` is `null` | `"No device data available"` centered in a 64-unit height container |
| `device.software` is empty | `"No software data available for this device"` centered |
| Software present | Sortable `DataTable` with row count header slot |
