Renders a security-focused device detail tab displaying MDM status, encryption, user sessions, security agents, network interfaces, and alert configuration using grouped `InfoCard` components with contextual tooltips.

## Key Components

- **`SecurityTab`** — Main exported React component accepting a `device` prop and rendering five security sections as labeled card grids
- **`SecurityTabProps`** — Interface defining the `device` prop (typed as `any`)
- Sections rendered:
  - **Security Posture** — Encryption status, MDM enrollment, system security (reboot/maintenance)
  - **User Sessions** — Active user, last logged-in user, root user count, total users
  - **Security Agents** — OpenFrame agent, osquery, and Orbit agent versions/statuses
  - **Network Security** — Primary IP, public IP, MAC address (all copyable)
  - **Alert Configuration** — Alert settings card (truncated in source)

## Usage Example

```typescript
import { SecurityTab } from './security-tab';

const device = {
  disk_encryption_enabled: true,
  mdm: {
    enrollment_status: 'enrolled',
    device_status: 'locked',
    pending_action: 'None',
    connected_to_fleet: true,
    encryption_key_available: true,
  },
  users: [{ uid: 0 }, { uid: 1001 }],
  logged_in_username: 'jdoe',
  osquery_version: '5.10.2',
  orbit_version: '1.22.0',
  primary_ip: '192.168.1.50',
  last_seen: '2024-01-15T10:30:00Z',
};

<SecurityTab device={device} />
```

## Notes

- Renders a centered fallback message when `device` is `null` or `undefined`
- Root user count is derived by filtering `device.users` for entries where `uid === 0`
- Tooltip descriptions reference data sources (Fleet MDM, Tactical RMM) for each card
- Uses `formatDateTime` from `@/lib/format-date` for the agent's last-seen timestamp
