Renders a security overview tab for a device detail view, displaying security posture, user sessions, agent status, network interfaces, and alert configuration using grouped `InfoCard` components with tooltips.

## Key Components

- **`SecurityTab`** — Default export; accepts a `device` prop and renders five grouped sections:
  - **Security Posture** — Encryption status, MDM enrollment, and system security (reboot/maintenance)
  - **User Sessions** — Current/last logged-in user, root user count, total users
  - **Security Agents** — OpenFrame agent, osquery, and Orbit agent versions/status
  - **Network Security** — Primary IP, public IP, and MAC address (all copyable)
  - **Alert Configuration** — Alert settings card

Each section uses `InfoCard` from `@flamingo-stack/openframe-frontend-core` with an `InfoIcon` tooltip explaining the data source (Fleet MDM, Tactical RMM, etc.).

## Usage Example

```typescript
import { SecurityTab } from './security-tab';

// Inside a device detail page or tab panel
export default function DevicePage({ device }) {
  return (
    <SecurityTab device={device} />
  );
}

// Expected device shape (partial)
const device = {
  disk_encryption_enabled: true,
  needs_reboot: false,
  maintenance_mode: false,
  logged_in_username: 'jdoe',
  last_logged_in_user: 'jdoe',
  users: [{ uid: 0 }, { uid: 1001 }],
  mdm: {
    enrollment_status: 'On (automatic)',
    device_status: 'unlocked',
    pending_action: '',
    connected_to_fleet: true,
    encryption_key_available: true,
  },
  osquery_version: '5.10.2',
  orbit_version: '1.22.0',
  primary_ip: '192.168.1.42',
  public_ip: '203.0.113.5',
  primary_mac: 'aa:bb:cc:dd:ee:ff',
  last_seen: '2024-11-01T10:00:00Z',
};
```

> **Note:** The component renders a centered "No device data available" fallback when `device` is `null` or `undefined`. Root users are derived by filtering `device.users` for entries with `uid === 0`.
