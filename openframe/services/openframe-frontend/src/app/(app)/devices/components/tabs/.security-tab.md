Renders a security-focused tab panel for device detail views in OpenFrame, displaying MDM status, encryption, user sessions, agent versions, and network security information.

## Key Components

**`SecurityTab`** — Main exported React component that accepts a `device` prop and renders four grouped `InfoCard` sections:

| Section | Data Displayed |
|---------|---------------|
| Security Posture | Disk encryption, MDM enrollment/status, reboot & maintenance flags |
| User Sessions | Current/last logged-in user, root user count, total users |
| Security Agents | OpenFrame agent, osquery, and Orbit versions/status |
| Network Security | Primary IP, public IP, MAC address (all copyable) |

Each card includes an `InfoIcon` tooltip explaining the data source (Fleet MDM, Tactical RMM, etc.).

## Usage Example

```typescript
import { SecurityTab } from './security-tab';

export function DeviceDetails({ device }) {
  return (
    <Tabs>
      <TabsContent value="security">
        <SecurityTab device={device} />
      </TabsContent>
    </Tabs>
  );
}
```

**Props:**

| Prop | Type | Description |
|------|------|-------------|
| `device` | `any` | Device object from Fleet/Tactical RMM containing MDM, user, agent, and network fields |

**Graceful fallback:** Renders a centered "No device data available" message when `device` is `null` or `undefined`.

**Key logic:** Counts root users by filtering `device.users` for entries where `uid === 0`, surfacing privileged account exposure at a glance.
