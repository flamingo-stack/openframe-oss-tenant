Renders a responsive grid of device cards with loading skeletons, empty states, and infinite scroll support for the devices list view.

## Key Components

- **`DevicesGrid`** — Main export; a grid layout component that handles three states: initial loading (skeleton grid), empty results, and populated device cards
- **`DevicesGridProps`** — Interface defining `devices`, `isLoading`, `hasNextPage`, `isFetchingNextPage`, and `sentinelRef` for infinite scroll
- **`handleDeviceClick`** — Navigates to `/devices/details/[id]` using `machineId` with fallback to `id`

## Usage Example

```typescript
import { DevicesGrid } from './devices-grid';
import { useRef } from 'react';

function DevicesPage() {
  const sentinelRef = useRef<HTMLDivElement>(null);

  return (
    <DevicesGrid
      devices={devices}
      isLoading={isLoading}
      hasNextPage={hasNextPage}
      isFetchingNextPage={isFetchingNextPage}
      sentinelRef={sentinelRef}
    />
  );
}
```

## Behavior Notes

- Shows `DeviceCardSkeletonGrid` (12 cards) on initial load when `devices` is empty
- Appends 4 `DeviceCardSkeleton` cards at the bottom while fetching the next page
- Renders an invisible 1px sentinel `<div>` when `hasNextPage` is true — attach an `IntersectionObserver` to `sentinelRef` to trigger pagination
- Device display name resolves via priority: `displayName` → `hostname` → `description`
- Status badge variant and label are derived from `getDeviceStatusConfig(device.status)`
