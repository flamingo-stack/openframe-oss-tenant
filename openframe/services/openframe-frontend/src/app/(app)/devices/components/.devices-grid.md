Responsive grid component for displaying a list of devices as cards, with loading skeletons, empty state, and infinite scroll support.

## Key Components

- **`DevicesGrid`** — Main export; renders a responsive 1–3 column grid of `DeviceCard` components
- **`DevicesGridProps`** — Interface defining `devices`, `isLoading`, pagination flags (`hasNextPage`, `isFetchingNextPage`), and an optional `sentinelRef` for infinite scroll
- **`handleDeviceClick`** — Navigates to `/devices/details/[id]` using `machineId` or `id` as the route param
- **Skeleton states** — Shows `DeviceCardSkeletonGrid` (12 cards) on initial load and `DeviceCardSkeleton` rows while fetching the next page
- **Empty state** — Displays a centered message when no devices match the current search/filters
- **Infinite scroll sentinel** — A 1px `div` bound to `sentinelRef` triggers the next page fetch via an external intersection observer

## Usage Example

```typescript
import { DevicesGrid } from './devices-grid';
import { useRef } from 'react';

const sentinelRef = useRef<HTMLDivElement>(null);

<DevicesGrid
  devices={devices}
  isLoading={isLoading}
  hasNextPage={hasNextPage}
  isFetchingNextPage={isFetchingNextPage}
  sentinelRef={sentinelRef}
/>
```

> The component delegates OS detection and status badge configuration to `getDeviceOperatingSystem` and `getDeviceStatusConfig` utilities, keeping card rendering logic decoupled from device data normalization.
