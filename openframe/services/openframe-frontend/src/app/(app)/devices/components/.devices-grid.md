Renders a responsive grid of device cards with loading skeletons, empty state handling, and infinite scroll support via a sentinel ref.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `DevicesGrid` | Component | Main grid component that renders device cards or appropriate loading/empty states |
| `DevicesGridProps` | Interface | Props contract for the grid including pagination and scroll sentinel support |

## Usage Example

```typescript
import { DevicesGrid } from './devices-grid';

function DevicesPage() {
  const { data, isLoading, hasNextPage, isFetchingNextPage, ref } = useInfiniteDevices();

  return (
    <DevicesGrid
      devices={data}
      isLoading={isLoading}
      hasNextPage={hasNextPage}
      isFetchingNextPage={isFetchingNextPage}
      sentinelRef={ref}
    />
  );
}
```

## Behavior

- **Initial load** — renders a 12-card `DeviceCardSkeletonGrid` while `isLoading` is `true` and `devices` is empty
- **Empty state** — displays a centered message when no devices match the current search/filters
- **Populated state** — renders a responsive `1 → 2 → 3` column grid using `DeviceCard`, mapping each device's `status`, `osType`, and display name via `getDeviceStatusConfig` / `getDeviceOperatingSystem` utilities
- **Pagination** — appends 4 `DeviceCardSkeleton` placeholders during `isFetchingNextPage`; a 1px sentinel `<div>` triggers the next page load via `IntersectionObserver` (managed by the parent)
- **Navigation** — clicking a card routes to `/devices/details/[machineId || id]`
