A client-side navigation button component that links to a device's detail page, accepting either a `deviceId` or `machineId` as the target identifier.

## Key Components

**`DeviceDetailsButton`** — Named export React component

**`DeviceDetailsButtonProps`** interface:
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `deviceId` | `string` | — | Device identifier |
| `machineId` | `string` | — | Machine identifier (takes priority over `deviceId`) |
| `label` | `string` | `'Details'` | Button display text |
| `variant` | `'accent' \| 'outline'` | `'outline'` | Visual style variant |
| `className` | `string` | — | Additional CSS classes |
| `openInNewTab` | `boolean` | `false` | Open link in a new browser tab |

> **Note:** If neither `deviceId` nor `machineId` is provided, the component renders `null`.

## Usage Example

```typescript
// Basic usage with deviceId
<DeviceDetailsButton deviceId="abc-123" />

// Using machineId with accent variant, opens in new tab
<DeviceDetailsButton
  machineId="machine-456"
  label="View Device"
  variant="accent"
  openInNewTab={true}
  className="mt-2"
/>

// Renders null — no ID provided
<DeviceDetailsButton label="Details" />
```

Navigates to `/devices/details/{id}`, where `machineId` takes precedence over `deviceId` when both are supplied.
