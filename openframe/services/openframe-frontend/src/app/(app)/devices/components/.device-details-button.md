A client-side navigation button component that links to a device's detail page, supporting both `deviceId` and `machineId` identifiers.

## Key Components

- **`DeviceDetailsButton`** — Renders a `Button` that navigates to `/devices/details/:id`. Returns `null` if no valid ID is provided.
- **`DeviceDetailsButtonProps`** — Interface defining the component's props:

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `deviceId` | `string` | — | Primary device identifier |
| `machineId` | `string` | — | Alternate machine identifier (takes precedence) |
| `label` | `string` | `'Details'` | Button display text |
| `variant` | `'accent' \| 'outline'` | `'outline'` | Button visual style |
| `className` | `string` | — | Additional CSS classes |
| `openInNewTab` | `boolean` | `false` | Opens the link in a new browser tab |

> **ID resolution:** `machineId` takes precedence over `deviceId` when both are provided.

## Usage Example

```typescript
// Basic usage with deviceId
<DeviceDetailsButton deviceId="dev-abc123" />

// Using machineId with accent variant, opens in new tab
<DeviceDetailsButton
  machineId="mach-xyz789"
  label="View Device"
  variant="accent"
  openInNewTab={true}
  className="mt-2"
/>

// Returns null — no ID provided
<DeviceDetailsButton label="Details" />
```
