A reusable client-side button component that navigates to a device's detail page, accepting either a `deviceId` or `machineId` as the target identifier.

## Key Components

- **`DeviceDetailsButtonProps`** — Interface defining optional props:
  - `deviceId` / `machineId` — At least one must be provided; `machineId` takes precedence
  - `label` — Button text (default: `'Details'`)
  - `variant` — `'accent'` or `'outline'` (default: `'outline'`)
  - `className` — Additional CSS classes
  - `openInNewTab` — Opens link in new browser tab (default: `false`)

- **`DeviceDetailsButton`** — Named export; renders `null` if neither `deviceId` nor `machineId` is provided, otherwise renders a `Button` linking to `/devices/details/:id`

## Usage Example

```typescript
// Basic usage with deviceId
<DeviceDetailsButton deviceId="abc-123" />

// Using machineId with accent variant, opening in new tab
<DeviceDetailsButton
  machineId="machine-456"
  label="View Device"
  variant="accent"
  openInNewTab={true}
  className="mt-2"
/>

// Returns null — nothing renders
<DeviceDetailsButton />
```

> **Note:** `machineId` takes precedence over `deviceId` when both are supplied. If neither is provided, the component renders nothing, making it safe to use in lists where device IDs may be undefined.
