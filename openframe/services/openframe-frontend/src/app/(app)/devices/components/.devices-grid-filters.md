A sticky, horizontal filter bar rendered above the devices grid view, providing the same per-column dropdown filters available in the devices table layout.

## Key Components

### `DevicesGridFilters` (exported component)
Renders a row of `FiltersDropdown` buttons for each filterable column, plus an optional result count badge.

**Props (`DevicesGridFiltersProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `filterColumns` | `DeviceFilterColumn[]` | Column definitions; only columns with `filterable: true` and populated `filterOptions` are rendered |
| `currentFilters` | `Record<string, string[]>` | Active filter values keyed by column ID (mirrors URL/table state) |
| `onFilterChange` | `(filters: Record<string, string[]>) => void` | Callback fired on apply or reset; intended to write back to URL params |
| `totalCount` | `number` (optional) | Server-side result count displayed as a trailing "N results" label |

**Behaviour notes:**
- Returns `null` when no filterable columns exist and `totalCount` is undefined
- Active filters highlight the filter icon with `text-ods-accent`
- The bar is `sticky` at `top-[96px]` so it remains visible while scrolling the grid

## Usage Example

```typescript
<DevicesGridFilters
  filterColumns={tableColumns}
  currentFilters={parsedUrlFilters}
  onFilterChange={(next) => {
    const params = new URLSearchParams();
    Object.entries(next).forEach(([key, vals]) =>
      vals.forEach(v => params.append(key, v))
    );
    router.push(`?${params.toString()}`);
  }}
  totalCount={deviceCount}
/>
```
