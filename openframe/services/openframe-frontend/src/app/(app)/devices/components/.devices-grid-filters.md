A client-side React component that renders a sticky horizontal row of dropdown filters above the devices grid view, mirroring the column-header filters available in the table layout.

## Key Components

**`DevicesGridFilters`** — Main exported component that maps over filterable columns and renders a `FiltersDropdown` for each.

**`DevicesGridFiltersProps`**
| Prop | Type | Description |
|------|------|-------------|
| `filterColumns` | `DeviceFilterColumn[]` | Column definitions describing filterable fields and their options |
| `currentFilters` | `Record<string, string[]>` | Active filter values keyed by column id |
| `onFilterChange` | `(filters: Record<string, string[]>) => void` | Callback invoked on apply or reset; should persist to URL params |
| `totalCount` | `number` (optional) | Server-side result count rendered as a trailing "N results" label |

**Behavior**
- Filters out non-filterable columns and those with no options before rendering
- Returns `null` when no filterable columns exist and `totalCount` is undefined
- Highlights the filter icon in accent color when a filter has active selections
- Merges per-column changes into the full `currentFilters` record before calling `onFilterChange`

## Usage Example

```typescript
<DevicesGridFilters
  filterColumns={columns}
  currentFilters={activeFilters}
  onFilterChange={(next) => {
    setSearchParams(buildFilterParams(next));
  }}
  totalCount={devices.total}
/>
```

> **Note:** `onFilterChange` receives the full merged filters record (not just the changed column), making it safe to write directly to URL search params without losing other active filters.
