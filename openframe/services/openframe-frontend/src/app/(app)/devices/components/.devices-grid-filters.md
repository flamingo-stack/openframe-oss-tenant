A sticky horizontal filter bar rendered above the devices grid, providing the same column-based filtering available in the table view layout.

## Key Components

### `DevicesGridFilters` (exported component)

Renders a row of `FiltersDropdown` controls for each filterable `DeviceFilterColumn`. Highlights active filters via an accent-colored icon and optionally displays a server-side result count.

**Props (`DevicesGridFiltersProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `filterColumns` | `DeviceFilterColumn[]` | Column definitions including filter metadata |
| `currentFilters` | `Record<string, string[]>` | Active filter values keyed by column id |
| `onFilterChange` | `(filters: Record<string, string[]>) => void` | Callback on apply/reset — intended to write to URL params |
| `totalCount` | `number` (optional) | Server-side count displayed as "N results" |

Returns `null` when no filterable columns exist and `totalCount` is undefined.

## Usage Example

```typescript
import { DevicesGridFilters } from './devices-grid-filters';
import type { DeviceFilterColumn } from './devices-table-columns';

const columns: DeviceFilterColumn[] = [
  {
    key: 'status',
    label: 'Status',
    filterable: true,
    filterOptions: [
      { label: 'Online', value: 'online' },
      { label: 'Offline', value: 'offline' },
    ],
  },
];

<DevicesGridFilters
  filterColumns={columns}
  currentFilters={{ status: ['online'] }}
  onFilterChange={(filters) => {
    // Sync to URL search params
    setSearchParams(filters);
  }}
  totalCount={142}
/>
```
