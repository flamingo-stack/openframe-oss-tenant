Renders the **Users** tab within a device detail view, displaying the currently logged-in user and all system user accounts associated with a device.

## Key Components

- **`UsersTab`** — Default export component accepting a `Device | null` prop
- **Logged-in User Section** — Highlights the active session user with UID, group, and shell details sourced from Fleet MDM and Tactical RMM
- **All System Users Grid** — Responsive 3-column grid listing every user account when more than one user exists, with account type badges (`● Active`, `User Account`, `System User`)
- **`InfoCard`** — ODS component used to render each user entry with structured key/value metadata
- **`TooltipProvider` / `Tooltip`** — Wraps info icons to surface contextual help text about data sources

## Usage Example

```typescript
import { UsersTab } from './users-tab';
import { Device } from '../../types/device.types';

const device: Device = {
  users: [
    { username: 'jdoe', uid: 501, groupname: 'staff', shell: '/bin/zsh', isLoggedIn: true },
    { username: '_spotlight', uid: 89, type: 'service', isLoggedIn: false },
  ],
  logged_in_username: 'jdoe',
  // ...other device fields
};

<UsersTab device={device} />
```

## Data Resolution Logic

The active user is resolved in priority order:

1. First user in `device.users` where `isLoggedIn === true`
2. First entry in `device.users` array
3. `device.logged_in_username`
4. `device.logged_username`
5. Falls back to `'Unknown'`
