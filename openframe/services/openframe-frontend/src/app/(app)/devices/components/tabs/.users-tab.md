Renders the Users tab within a device detail view, displaying the currently logged-in user and all system user accounts associated with a device.

## Key Components

- **`UsersTab`** — Main exported component that accepts a `device` prop and renders user session data
- **`loggedInUser`** — Derives the active session user by checking `isLoggedIn` flag or falling back to `device.logged_in_username` / `device.logged_username`
- **`InfoCard`** — Displays structured user details (UID, group, shell, type) with tooltip context from `@flamingo-stack/openframe-frontend-core`
- **`TooltipProvider`** — Wraps the tab to provide hover tooltips explaining data sources (Fleet MDM, Tactical RMM)

## Behavior

- Shows an empty state message if `device` is `null`
- Always renders the **Currently Logged In** section for the active session user
- Conditionally renders the **All System Users** grid (3-column on large screens) only when more than one user exists
- User subtitles distinguish between active sessions (`● Active`), person accounts, and service/system users

## Usage Example

```typescript
import { UsersTab } from './tabs/users-tab';
import { Device } from '../types/device.types';

const device: Device = {
  users: [
    { username: 'jsmith', uid: 501, groupname: 'staff', shell: '/bin/zsh', isLoggedIn: true, type: 'person' },
    { username: '_spotlight', uid: 89, groupname: 'spotlight', shell: '/usr/bin/false', type: 'service' },
  ],
  logged_in_username: 'jsmith',
};

<UsersTab device={device} />
```
