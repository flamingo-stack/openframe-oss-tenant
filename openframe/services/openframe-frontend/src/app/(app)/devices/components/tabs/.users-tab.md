Renders the Users tab within a device detail view, displaying the currently logged-in user and all system user accounts associated with a device.

## Key Components

- **`UsersTab`** — Main exported component that accepts a `device` prop and renders user session and account information
- **Logged-in User Section** — Highlights the active session user with UID, group, and shell details sourced from Fleet MDM or Tactical RMM
- **All System Users Grid** — Responsive 3-column grid listing every user account on the device when more than one user exists, with active/inactive session indicators
- **Tooltip Info Icons** — Contextual `InfoIcon` tooltips on each `InfoCard` explaining data sources and field meanings

## Usage Example

```typescript
import { UsersTab } from './users-tab';
import { Device } from '../../types/device.types';

const device: Device = {
  id: 'device-123',
  logged_in_username: 'jsmith',
  users: [
    { username: 'jsmith', uid: 501, groupname: 'staff', shell: '/bin/zsh', isLoggedIn: true },
    { username: '_daemon', uid: 1, type: 'service', shell: '/usr/bin/false', isLoggedIn: false },
  ],
};

export default function DeviceDetail() {
  return <UsersTab device={device} />;
}
```

## Notes

- Gracefully handles a `null` device with a centered empty-state message
- Falls back through `users[0]`, `device.logged_in_username`, and `device.logged_username` when resolving the active user
- User subtitle distinguishes active sessions (`● Active`), person accounts, and system/service users based on `isLoggedIn` and `type` fields
