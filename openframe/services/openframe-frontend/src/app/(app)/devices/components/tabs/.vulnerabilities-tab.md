Renders a sortable data table of CVE vulnerabilities aggregated across all software installed on a device, with severity classification and per-severity counts displayed in a summary header.

## Key Components

- **`VulnerabilitiesTab`** — Main exported component; accepts a `Device | null` prop and renders the full vulnerability view
- **`VulnerabilityWithSoftware`** — Extended interface merging `Vulnerability` with parent software metadata (`name`, `version`, `vendor`, `source`, `unique_key`)
- **`getSeverity`** — Heuristic callback that classifies CVE severity (`critical` / `high` / `medium` / `low`) based on how many years ago the CVE was published
- **`columns`** — `ColumnDef` array defining five sortable columns: CVE ID, Software, Source, Severity, and Discovered date
- **`severityCounts`** — Memoized record tallying vulnerabilities per severity level, shown in the header bar

## Usage Example

```typescript
import { VulnerabilitiesTab } from './vulnerabilities-tab';
import type { Device } from '../../types/device.types';

const device: Device = {
  software: [
    {
      name: 'OpenSSL',
      version: '1.0.2',
      vendor: 'OpenSSL Foundation',
      source: 'system',
      vulnerabilities: [
        { cve: 'CVE-2024-0001', created_at: '2024-01-15T00:00:00Z' },
      ],
    },
  ],
  // ...other device fields
};

export default function DeviceDetail() {
  return <VulnerabilitiesTab device={device} />;
}
```

## Behaviour Notes

- Returns a **"No device data"** placeholder when `device` is `null`
- Returns a **green "No Vulnerabilities Found"** badge when all software is clean
- Severity ranking uses a year-gap heuristic; replace `getSeverity` with CVSS API data for production accuracy
- Row keys are composite (`cve-name-version-index`) to avoid collisions across software with duplicate CVEs
