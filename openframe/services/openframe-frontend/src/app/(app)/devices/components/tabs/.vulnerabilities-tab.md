Renders a sortable data table of CVE vulnerabilities aggregated across all software installed on a device, with severity badges and a summary count header.

## Key Components

| Export / Symbol | Description |
|---|---|
| `VulnerabilitiesTab` | Main React component; accepts a `Device` and renders the full vulnerability table |
| `VulnerabilityWithSoftware` | Internal interface extending `Vulnerability` with denormalized software context fields |
| `getSeverity` | Heuristic callback that maps a CVE's year delta to `critical` / `high` / `medium` / `low` |
| `severityCounts` | Memoized record summarising per-severity totals shown in the header row |
| `columns` | `ColumnDef` array defining CVE ID, software, source, severity, and discovered-date columns |

## Usage Example

```typescript
import { VulnerabilitiesTab } from './vulnerabilities-tab';
import type { Device } from '../../types/device.types';

export function DeviceDetailPage({ device }: { device: Device }) {
  return (
    <div>
      {/* other tabs ... */}
      <VulnerabilitiesTab device={device} />
    </div>
  );
}
```

## Behaviour Notes

- **Flattening**: iterates `device.software[].vulnerabilities[]` and merges each entry with its parent software metadata into a single flat list for the table.
- **Severity heuristic**: compares the CVE year against the current year; replace `getSeverity` with a real CVSS fetch in production.
- **Empty states**: renders a success badge when no vulnerabilities exist, and a plain message when `device` is `null`.
- **Sorting**: client-side via `useDataTable`; the severity column uses a numeric rank comparator rather than alphabetical sort.
