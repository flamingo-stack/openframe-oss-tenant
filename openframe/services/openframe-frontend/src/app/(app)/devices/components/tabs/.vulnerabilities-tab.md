Renders a sortable data table of CVE vulnerabilities detected across all software installed on a device, grouped with software context and severity classification.

## Key Components

**`VulnerabilitiesTab`** — Main exported component that accepts a `device` prop and renders a full vulnerability report with severity summary counts and a sortable table.

**`VulnerabilityWithSoftware`** — Extended interface merging `Vulnerability` with denormalized software metadata (`software_name`, `software_version`, `software_vendor`, `software_source`, `unique_key`) for flat table rendering.

**`getSeverity`** — Heuristic function that classifies CVE severity (`critical` | `high` | `medium` | `low`) based on the CVE year relative to the current year. Note: intended to be replaced with real CVSS score lookups.

**Table columns:** CVE ID (linked via `CveLink`), Software (name/vendor/version via `SoftwareInfo`), Source (`SoftwareSourceBadge`), Severity (`Tag` with color-coded variant), Discovered date.

## Usage Example

```typescript
import { VulnerabilitiesTab } from './vulnerabilities-tab';
import type { Device } from '../../types/device.types';

function DeviceDetail({ device }: { device: Device }) {
  return (
    <TabPanel value="vulnerabilities">
      <VulnerabilitiesTab device={device} />
    </TabPanel>
  );
}
```

## Behavior Notes

- Returns a "No device data" placeholder when `device` is `null`
- Returns a green "No Vulnerabilities Found" badge when the software list is clean
- Severity summary counts (CRITICAL / HIGH / MEDIUM / LOW) are displayed inline above the table and only shown when count > 0
- Sorting is client-side; severity sorting uses a numeric rank (4–1) rather than string comparison
- Row keys use a composite `${cve}-${name}-${version}-${softIdx}-${vulnIdx}` to handle duplicate CVEs across different packages
