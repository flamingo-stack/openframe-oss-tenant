Renders a hardware information tab for a device, displaying disk, RAM, and CPU details parsed from Fleet MDM data.

## Key Components

### `HardwareTab`
Main exported component that accepts a `device` prop and renders three hardware sections:

- **Disk Info** — processes raw partition + physical disk data into grouped, sorted disk cards with usage progress bars
- **RAM Info** — displays total system memory
- **CPU Info** — shows processor model, core counts, and type

### Helper Functions

| Function | Purpose |
|----------|---------|
| `parseCpuModel` | Maps CPU brand/model arrays into labeled items using `cpu_physical_cores`, `cpu_logical_cores`, and `cpu_type` |
| `processDiskData` | Merges partition stats with physical disk strings, groups by physical device, filters invalid entries, and sorts by capacity descending |

## Usage Example

```typescript
import { HardwareTab } from './tabs/hardware-tab';
import { Device } from '../types/device.types';

const device: Device = {
  cpu_brand: 'Apple M2',
  cpu_physical_cores: 8,
  cpu_logical_cores: 8,
  cpu_type: 'arm64',
  totalRam: '16 GB',
  disks: [
    { device: 'disk1s1', total: '500 GB', used: '200 GB', free: '300 GB', percent: 40, fstype: 'apfs' }
  ],
  physical_disks: ['disk1 500GB SSD'],
  batteries: [],
};

<HardwareTab device={device} />
```

> **Note:** Renders a centered "No device data available" fallback when `device` is `null`. Disk cards are suppressed if `total === '0 B'`, `device === 'map auto_home'`, or `percent === 0`.
