Renders the hardware details tab for a device, displaying disk, RAM, and CPU information using `InfoCard` components with tooltips.

## Key Components

### `HardwareTab({ device })`
Main exported component that accepts a `Device | null` prop and renders three sections:
- **Disk Info** — Usage percentage, used/free/total space per physical disk, with progress bar
- **RAM Info** — Total system memory
- **CPU** — CPU model, physical/logical cores, and CPU type (up to 4 CPUs displayed)

### `parseCpuModel(cpuArray, device?)`
Internal helper that maps raw CPU strings into structured `{ model, items[] }` objects. Pulls `cpu_physical_cores`, `cpu_logical_cores`, and `cpu_type` from the `Device` record.

### `processDiskData(disks, physicalDisks)`
Internal helper that cross-references logical partition data (from `device.disks`) with physical disk metadata (from `device.physical_disks`). Filters invalid entries, groups partitions by physical disk, infers disk type (SSD/HDD/Virtual), and sorts results by capacity descending.

## Usage Example

```typescript
import { HardwareTab } from './hardware-tab';
import { Device } from '../../types/device.types';

const device: Device = {
  cpu_brand: 'Apple M2',
  cpu_physical_cores: 8,
  cpu_logical_cores: 8,
  cpu_type: 'ARM',
  totalRam: '16 GB',
  disks: [{ free: '120 GB', used: '80 GB', total: '200 GB', device: 'disk1s1', fstype: 'apfs', percent: 40 }],
  physical_disks: ['disk1 200GB SSD'],
  batteries: [],
};

<HardwareTab device={device} />
```

> **Note:** When `device` is `null`, a centered "No device data available" placeholder is rendered instead.
