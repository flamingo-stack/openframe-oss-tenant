Renders the hardware information tab for a device detail view, displaying disk, RAM, and CPU specifications sourced from Fleet MDM data.

## Key Components

### `HardwareTab({ device })`
Main exported component that renders three hardware sections for a given `Device` object.

### `parseCpuModel(cpuArray, device?)`
Internal helper that maps CPU brand/model strings into structured objects containing physical cores, logical cores, and CPU type metadata.

### `processDiskData(disks, physicalDisks)`
Internal helper that merges partition-level disk data with physical disk inventory, groups by physical device, filters invalid entries, and sorts results by capacity (largest first). Handles macOS (`disk0`, `disk1`), Windows (`C:`, `D:`), and virtual disk formats.

## Rendered Sections

| Section | Layout | Data Source |
|---------|--------|-------------|
| **Disk Info** | 4-col grid | `device.disks` + `device.physical_disks` |
| **RAM Info** | 3-col grid | `device.totalRam` |
| **CPU** | 4-col grid (max 4) | `device.cpu_brand` or `device.cpu_model` |

Each card uses `InfoCard` from `@flamingo-stack/openframe-frontend-core` with an info tooltip sourced from Fleet MDM.

## Usage Example

```typescript
import { HardwareTab } from './hardware-tab';
import { Device } from '../../types/device.types';

const device: Device = {
  cpu_brand: 'Apple M2',
  cpu_physical_cores: 8,
  cpu_logical_cores: 8,
  cpu_type: 'ARM64',
  totalRam: '16 GB',
  disks: [{ device: 'disk1s1', free: '120 GB', used: '80 GB', total: '200 GB', fstype: 'apfs', percent: 40 }],
  physical_disks: ['disk1 200GB SSD'],
  batteries: [],
};

<HardwareTab device={device} />
```

> **Note:** Pass `device={null}` to render the empty state (`No device data available`).
