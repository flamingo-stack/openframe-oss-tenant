Defines column definitions, filter metadata, and the `DevicesTableBody` component for rendering the devices data table with support for filtering, custom actions, and responsive column visibility.

## Key Components

- **`getDeviceTableRowActions(onRefresh?)`** — Returns a row-level render function wrapping `DeviceActionsDropdown` for the three-dot context menu.
- **`deviceRowHref(device)`** — Generates the detail page URL using `machineId` or `id`.
- **`DEVICE_OPEN_COLUMN`** — Pre-built `ColumnDef` that renders an "open in new tab" button aligned to the right.
- **`DevicesTableBody`** — Full table component composing columns, `useDataTable`, and `DataTable` sub-components. Supports server-side pagination via `totalCount`, sticky headers, column hiding, and external column filter state.
- **`getDeviceFilterColumns(deviceFilters?)`** — Returns filter metadata for the external mobile filter modal (`status`, `os`, `organization`), excluding archived/deleted statuses.
- **`getDeviceTableColumns(deviceFilters?)`** — Returns the four base `ColumnDef` entries: `device`, `status`, `os`, `organization`, each with responsive width, optional filter options, and custom cell renderers.
- **`OrganizationCell`** — Internal component rendering the customer logo + name in the organization column.

## Usage Example

```typescript
// Render the full devices table with server-side filters and a custom actions column
import {
  DevicesTableBody,
  getDeviceTableRowActions,
} from './devices-table-columns';

const actionsColumn = {
  id: 'actions',
  cell: ({ row }) => getDeviceTableRowActions(refetch)(row.original),
  meta: { width: 'w-12' },
};

<DevicesTableBody
  devices={devices}
  isLoading={isLoading}
  deviceFilters={filters}
  totalCount={totalCount}
  hideColumns={['organization']}
  actionsColumn={actionsColumn}
  columnFilters={columnFilters}
  onColumnFiltersChange={setColumnFilters}
  stickyHeaderOffset="64px"
/>
```
