Defines the column structure, row actions, and table composition for the devices data table, including filter metadata for both inline column filters and the external mobile filter modal.

## Key Components

- **`getDeviceTableRowActions`** — Factory that returns a per-row actions renderer wrapping `DeviceActionsDropdown` in table context
- **`deviceRowHref`** — Derives the detail-page URL for a device row using `machineId` or `id`
- **`DEVICE_OPEN_COLUMN`** — Constant `ColumnDef` rendering an "open in new tab" icon button aligned to the right
- **`DevicesTableBody`** — Composable table component that assembles columns, wires up `useDataTable`, and renders a full `DataTable` with header, body, and optional footer
- **`getDeviceFilterColumns`** — Returns `DeviceFilterColumn[]` metadata consumed by the external tag-filter modal (status, OS, organization)
- **`getDeviceTableColumns`** — Returns the core `ColumnDef<Device>[]` array: device name/icon, status+last-seen, OS badge, and organization cell — each with responsive widths and optional filter options

## Usage Example

```typescript
// Rendering the table on a scoped (single-org) page with row actions
import {
  DevicesTableBody,
  getDeviceTableRowActions,
} from './devices-table-columns';

const actionsColumn = {
  id: 'actions',
  cell: ({ row }) => getDeviceTableRowActions(refetch)(row.original),
  enableSorting: false,
  meta: { width: 'w-12' },
};

<DevicesTableBody
  devices={devices}
  isLoading={isLoading}
  deviceFilters={filters}
  hideColumns={['organization']}
  actionsColumn={actionsColumn}
  totalCount={totalCount}
  onColumnFiltersChange={setColumnFilters}
  columnFilters={columnFilters}
/>
```
