Renders the full device details page, managing tab navigation, action menus, scripts modal, and device status/tag display within a `PageLayout` shell.

## Key Components

- **`DeviceDetailsView`** — Main export. Fetches device data via `useDeviceDetails`, handles URL-driven tab state, builds the actions menu, and dispatches URL-based action params (e.g., `?action=runScript`).
- **`DeviceStatusAndTags`** — Internal component rendering the device's status `Tag` alongside any key/value tags displayed as styled pills with `Tooltip` overlays.
- **`DEVICE_TAB_IDS`** — Const tuple of valid tab slugs (`hardware`, `network`, `security`, `compliance`, `agents`, `users`, `software`, `vulnerabilities`, `logs`).
- **`handleTabChange`** — Updates the `?tab=` search param via `router.replace` in controlled mode, using the URL as the single source of truth to avoid flicker.
- **`menuActions`** — Memoized `ActionsMenuGroup[]` built from `useDeviceActionsMenu`, splitting primary (run script, manage files) and destructive (archive, delete) items.

## Usage Example

```typescript
// Render the device details page for a given device ID
import { DeviceDetailsView } from './device-details-view';

export default function DevicePage({ params }: { params: { id: string } }) {
  return <DeviceDetailsView deviceId={params.id} />;
}

// URL tab navigation is automatic — navigate to a specific tab:
// /devices/details/abc123?tab=network

// Trigger scripts modal via URL action param:
// /devices/details/abc123?action=runScript
```

> **Note:** Tab state is fully URL-controlled. The `?tab=` param defaults to `hardware` for unknown or missing values, preventing invalid tab states.
