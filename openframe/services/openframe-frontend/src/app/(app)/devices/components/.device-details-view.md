Main view component for the device details page, rendering the full device profile including status tags, info section, tabbed content, action menus, and a scripts modal.

## Key Components

### `DeviceDetailsView`
Primary export. Orchestrates device data fetching, tab routing, action menu construction, and modal state for a given `deviceId`.

- Reads and writes the active tab via URL search params (`?tab=`) using controlled mode to prevent flicker during navigation
- Handles `?action=runScript` URL param to open the scripts modal (e.g., when navigating from a device table row dropdown)
- Forces a re-render every second to keep relative timestamps current
- Builds `menuActions` groups (primary + destructive) from `useDeviceActionsMenu` availability flags
- Renders `LoadError`, `NotFoundError`, or `DeviceDetailsSkeleton` for error/loading states

### `DeviceStatusAndTags`
Internal component. Displays the device's status `Tag` and flattened key/value tag list with tooltips showing the full `key:value` pair on hover.

## Usage Example

```typescript
// app/devices/details/[deviceId]/page.tsx
import { DeviceDetailsView } from '@/features/devices/components/device-details-view';

export default function DeviceDetailsPage({ params }: { params: { deviceId: string } }) {
  return <DeviceDetailsView deviceId={params.deviceId} />;
}
```

```typescript
// Navigating to a specific tab programmatically
router.push(`/devices/details/${deviceId}?tab=software`);

// Triggering the scripts modal via URL action param
router.push(`/devices/details/${deviceId}?action=runScript`);
```

## Tab IDs

| ID | Description |
|----|-------------|
| `hardware` | Default tab — hardware specs |
| `network` | Network interfaces |
| `security` | Security posture |
| `compliance` | Compliance status |
| `agents` | Installed agents |
| `users` | Logged-in/associated users |
| `software` | Installed software |
| `vulnerabilities` | CVEs and patches |
| `logs` | Device activity logs |
