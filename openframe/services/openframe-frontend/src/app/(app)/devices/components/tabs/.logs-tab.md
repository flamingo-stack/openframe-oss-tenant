Device logs tab component that renders a filtered `LogsTable` for a specific device, with support for URL-based refresh triggering via the `refresh` search parameter.

## Key Components

- **`LogsTab`** — Main exported component that accepts a `device` prop and displays its associated logs
- **`deviceId` resolution** — Prefers `device.machineId` over `device.id` as the primary identifier for log filtering
- **Refresh trigger** — Watches the `refresh` URL search param and calls `logsTableRef.current?.refresh()` with a 100ms debounce to ensure the tab is fully rendered
- **Empty state** — Renders a fallback card when no valid device ID can be resolved

## Usage Example

```typescript
// Basic usage inside a device detail page/tab panel
import { LogsTab } from './logs-tab';

export function DeviceDetailTabs({ device }) {
  return (
    <TabPanel value="logs">
      <LogsTab device={device} />
    </TabPanel>
  );
}

// Trigger a refresh by navigating with the refresh param
router.push(`/devices/${deviceId}?tab=logs&refresh=${Date.now()}`);
```

## Props

| Prop | Type | Description |
|------|------|-------------|
| `device` | `any` | Device object; uses `machineId` (preferred) or `id` to filter logs |
