A device-specific logs tab component that renders a filtered `LogsTable` for a given device, with support for URL-based refresh triggering.

## Key Components

- **`LogsTab`** — Main exported component that wraps `LogsTable` and scopes it to a specific device
- **`deviceId` resolution** — Prefers `device.machineId` over `device.id` as the primary identifier for log filtering
- **Refresh via `searchParams`** — Watches the `refresh` URL query parameter and calls `logsTableRef.current.refresh()` with a 100ms debounce to ensure the tab is fully mounted
- **`LogsTableRef`** — Forwarded ref used to imperatively trigger a data refresh on the underlying table

## Usage Example

```typescript
import { LogsTab } from './logs-tab';

// Inside a device detail page or tab panel
<LogsTab device={{ machineId: 'abc-123', name: 'Workstation-01' }} />

// Trigger a refresh by navigating with ?refresh=<timestamp>
// e.g. router.push(`/devices/${id}?tab=logs&refresh=${Date.now()}`)
```

## Notes

- Renders a fallback card if no `deviceId` can be resolved from the device object
- The 100ms `setTimeout` guards against the ref being unavailable during tab transition animations
- Relies on `'use client'` directive — not suitable for server-side rendering
