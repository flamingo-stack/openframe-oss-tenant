Renders a device-specific logs tab by wrapping the shared `LogsTable` component with device ID resolution and URL-param-driven refresh support.

## Key Components

- **`LogsTab`** — Main export; accepts a `device` object, resolves its identifier (`machineId` falling back to `id`), and renders `LogsTable` filtered to that device.
- **`refreshParam`** — Reads the `refresh` query parameter via `useSearchParams` to trigger a table refresh with a 100ms debounce.
- **`logsTableRef`** — `LogsTableRef` forwarded ref used to imperatively call `refresh()` on the underlying `LogsTable`.

## Usage Example

```typescript
import { LogsTab } from './logs-tab';

// Inside a device detail page/tab panel
<LogsTab device={{ machineId: 'abc-123', name: 'Workstation-01' }} />

// Trigger a refresh by navigating with ?refresh=<timestamp>
router.push(`?refresh=${Date.now()}`);
```

## Behavior Notes

- If neither `machineId` nor `id` is resolvable from the `device` prop, a fallback message is displayed instead of the table.
- The 100ms timeout on refresh guards against calling `refresh()` before the tab finishes mounting.
