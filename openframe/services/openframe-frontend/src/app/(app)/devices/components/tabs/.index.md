Barrel export file for the device detail tabs module, consolidating all tab components and utilities into a single importable entry point.

## Key Components

| Export | Source | Description |
|--------|--------|-------------|
| `AgentsTab` | `agents-tab` | Displays installed agent information for a device |
| `ComplianceTab` | `compliance-tab` | Shows compliance status and policy checks |
| `DeviceTabContent` | `device-tab-content` | Wrapper component for rendering active tab content |
| `DEVICE_TABS` | `device-tabs` | Constant array defining all available device tabs |
| `getDeviceTab` | `device-tabs` | Utility to retrieve a specific tab definition by key |
| `getTabComponent` | `device-tabs` | Resolves the component associated with a given tab |
| `HardwareTab` | `hardware-tab` | Lists hardware specs and inventory details |
| `LogsTab` | `logs-tab` | Displays device event and activity logs |
| `NetworkTab` | `network-tab` | Shows network interfaces, IPs, and connectivity info |
| `SecurityTab` | `security-tab` | Summarizes security posture and endpoint protection |
| `SoftwareTab` | `software-tab` | Lists installed software and application inventory |
| `UsersTab` | `users-tab` | Shows local and domain user accounts on the device |
| `VulnerabilitiesTab` | `vulnerabilities-tab` | Displays detected CVEs and vulnerability findings |

## Usage Example

```typescript
import {
  DeviceTabContent,
  DEVICE_TABS,
  getDeviceTab,
  getTabComponent,
  SoftwareTab,
  VulnerabilitiesTab,
} from '@/components/device/tabs';

// Resolve and render a tab dynamically
const tab = getDeviceTab('software');
const TabComponent = getTabComponent(tab.key);

// Or use a specific tab directly
<SoftwareTab deviceId={device.id} />
<VulnerabilitiesTab deviceId={device.id} />
```
