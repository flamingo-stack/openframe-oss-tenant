Barrel export file for device detail tab components, centralizing all tab-related exports for the device management interface.

## Key Components

| Export | Description |
|--------|-------------|
| `AgentsTab` | Displays installed monitoring/management agents on the device |
| `ComplianceTab` | Shows compliance status and policy adherence |
| `DeviceTabContent` | Wrapper component for rendering active tab content |
| `DEVICE_TABS` | Constant defining available tab configurations |
| `getDeviceTab` | Utility to retrieve a specific tab by identifier |
| `getTabComponent` | Utility to resolve the component for a given tab |
| `HardwareTab` | Displays hardware inventory and specs |
| `LogsTab` | Shows device event and activity logs |
| `NetworkTab` | Displays network interfaces and connectivity info |
| `SecurityTab` | Shows security posture and endpoint protection status |
| `SoftwareTab` | Lists installed software and applications |
| `UsersTab` | Displays user accounts and session data |
| `VulnerabilitiesTab` | Lists known CVEs and vulnerability findings |

## Usage Example

```typescript
import {
  DeviceTabContent,
  DEVICE_TABS,
  getDeviceTab,
  getTabComponent,
  HardwareTab,
  VulnerabilitiesTab,
} from '@/components/device/tabs';

const tab = getDeviceTab('hardware');
const TabComponent = getTabComponent(tab);

// Render within device detail view
<DeviceTabContent tabs={DEVICE_TABS} deviceId={device.id}>
  <TabComponent device={device} />
</DeviceTabContent>
```
