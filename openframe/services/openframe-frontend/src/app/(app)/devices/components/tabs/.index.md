Barrel export file for device detail tab components, consolidating all tab-related exports into a single entry point.

## Key Components

| Export | Description |
|--------|-------------|
| `AgentsTab` | Displays installed monitoring/management agents on the device |
| `ComplianceTab` | Shows device compliance status and policy adherence |
| `DeviceTabContent` | Root container component that renders the active tab |
| `DEVICE_TABS` | Constant defining available tab configuration |
| `getDeviceTab` | Utility to retrieve a specific tab definition by identifier |
| `getTabComponent` | Utility to resolve the component for a given tab |
| `HardwareTab` | Displays hardware inventory and specifications |
| `LogsTab` | Shows device event and system logs |
| `NetworkTab` | Displays network interfaces and connectivity info |
| `SecurityTab` | Shows security posture and endpoint protection status |
| `SoftwareTab` | Lists installed software and applications |
| `UsersTab` | Displays local and domain users on the device |
| `VulnerabilitiesTab` | Lists known CVEs and security vulnerabilities |

## Usage Example

```typescript
import {
  DeviceTabContent,
  DEVICE_TABS,
  getDeviceTab,
  getTabComponent,
} from '@/components/device/tabs';

// Resolve the component for a given tab key
const activeTab = getDeviceTab('software');
const TabComponent = getTabComponent(activeTab);

// Render the full tab layout
<DeviceTabContent deviceId={device.id} tabs={DEVICE_TABS} />
```
