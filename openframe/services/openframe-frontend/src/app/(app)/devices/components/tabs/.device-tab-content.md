Renders the content area for the active device tab by resolving the appropriate tab component and delegating rendering to the shared `TabContent` wrapper.

## Key Components

- **`DeviceTabContent`** — Client component that accepts the active tab identifier and device data, retrieves the matching tab component via `getTabComponent`, and passes it to `TabContent` with the device as a prop.

## Usage Example

```typescript
import { DeviceTabContent } from './device-tab-content';

<DeviceTabContent
  activeTab="overview"
  device={deviceData}
/>
```

## Notes

- Marked as `'use client'` — runs in the browser only.
- Tab component resolution is handled by `getTabComponent` from `./device-tabs`.
- The `device` prop is forwarded as `componentProps` to the resolved tab component, keeping tab components decoupled from the parent.
