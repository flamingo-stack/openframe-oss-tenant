Renders the active tab's content for a device detail view by resolving the appropriate tab component and passing device data as props.

## Key Components

- **`DeviceTabContent`** — Client component that maps the active tab identifier to its corresponding component and delegates rendering to `TabContent`
- **`getTabComponent`** — Imported utility that resolves a tab string key to its React component
- **`TabContent`** — Core layout wrapper from `@flamingo-stack/openframe-frontend-core` that handles tab content rendering

## Props

| Prop | Type | Description |
|------|------|-------------|
| `activeTab` | `string` | The currently selected tab identifier |
| `device` | `any` | Device data object passed down to the resolved tab component |

## Usage Example

```typescript
import { DeviceTabContent } from './device-tab-content';

export function DeviceDetailPage({ device }) {
  const [activeTab, setActiveTab] = useState('overview');

  return (
    <div>
      <DeviceTabContent activeTab={activeTab} device={device} />
    </div>
  );
}
```
