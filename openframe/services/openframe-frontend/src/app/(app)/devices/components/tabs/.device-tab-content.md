Renders the active tab's content for a device detail view by resolving the appropriate tab component and passing device data as props.

## Key Components

- **`DeviceTabContent`** — Client component that maps the active tab key to its corresponding component via `getTabComponent` and delegates rendering to `TabContent`

### Props

| Prop | Type | Description |
|------|------|-------------|
| `activeTab` | `string` | Key identifying the currently selected tab |
| `device` | `any` | Device data object passed as props to the resolved tab component |

## Usage Example

```typescript
import { DeviceTabContent } from './device-tab-content';

export function DeviceDetailPage({ device }) {
  const [activeTab, setActiveTab] = React.useState('overview');

  return (
    <div>
      {/* Tab navigation ... */}
      <DeviceTabContent activeTab={activeTab} device={device} />
    </div>
  );
}
```

## Notes

- Marked as a client component (`'use client'`) — tab switching and component resolution happen on the client side
- Tab component resolution is handled by `getTabComponent` from `./device-tabs`; add new tabs there rather than modifying this component
- The `device` prop is typed as `any` — consider narrowing to a shared `Device` interface for better type safety across tab components
