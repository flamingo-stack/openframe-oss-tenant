Renders a responsive, multi-breakpoint info card displaying key metadata for a single device, including hostname, type, OS, serial number, customer/organization link, timestamps, and a copyable UUID.

## Key Components

### `DeviceInfoSection`

Primary export. Accepts a nullable `Device` and renders a structured card with three distinct responsive layouts:

- **Mobile (`< md`)** — single-column rows, customer/assigned user stacked vertically
- **Tablet (`md–lg`)** — two-column rows, customer/assigned user share one horizontal row
- **Desktop (`lg+`)** — four-column rows with all cells visible per row

### `formatDateWithTime(iso?)`

Private helper that parses an ISO date string and returns a React node with the date and a secondary-colored time component. Returns `'Unknown'` for missing or invalid values.

### `DeviceInfoSectionProps`

```typescript
interface DeviceInfoSectionProps {
  device: Device | null;
}
```

## Key Behaviors

- **UUID copy** — Uses `useCopyToClipboard`; the copy icon toggles to a `CheckIcon` on success. Disabled when UUID is `'Unknown'`.
- **Customer link** — Renders a navigable `Link` to `/customers/details/:organizationId` when an `organizationId` is present, otherwise plain text.
- **Assigned user** — Block is intentionally hidden (`username: null`) pending backend support for user entity resolution.
- **Fallback** — Renders a minimal empty-state card when `device` is `null`.

## Usage Example

```typescript
import { DeviceInfoSection } from './device-info-section';
import type { Device } from '../types/device.types';

const device: Device = {
  hostname: 'workstation-01',
  type: 'desktop',
  osType: 'windows',
  manufacturer: 'Dell',
  model: 'OptiPlex 7090',
  serialNumber: 'ABC123XYZ',
  osUuid: 'xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx',
  organization: 'Acme Corp',
  organizationId: 'org_456',
  registeredAt: '2024-01-15T10:30:00Z',
  updatedAt: '2025-06-01T08:00:00Z',
};

export default function DevicePage() {
  return <DeviceInfoSection device={device} />;
}
```
