Displays a structured, responsive summary card for a single device, rendering key metadata (hostname, type, OS, serial number, customer, UUID, timestamps) across mobile, tablet, and desktop layouts.

## Key Components

**`DeviceInfoSection`**
Main exported component. Accepts a `device` prop (`Device | null`) and renders a multi-row info card. Falls back to an empty-state message when `device` is `null`.

**`formatDateWithTime(iso?)`**
Internal helper that formats an ISO date string into a date + secondary-styled time node using `splitDateAndTimeWithSeconds`. Returns `'Unknown'` for missing or invalid values.

**`DeviceInfoSectionProps`**
```typescript
interface DeviceInfoSectionProps {
  device: Device | null;
}
```

## Key Behaviors

- **Responsive layout:** 2 cells/row on mobile, 2–4 cells/row on tablet, 4 cells/row on desktop (`lg+`), implemented via Tailwind breakpoint classes.
- **UUID copy:** Integrates `useCopyToClipboard` — shows a `CheckIcon` confirmation after copying, disabled when UUID is `'Unknown'`.
- **Customer link:** Renders an anchor to `/customers/details/{organizationId}` when `organizationId` is present; falls back to plain text.
- **Assigned user:** Block is intentionally hidden pending backend user entity support.
- **Icon sizing:** Device type and OS icons scale from `w-4 h-4` (mobile) to `w-6 h-6` (tablet+).

## Usage Example

```typescript
import { DeviceInfoSection } from './device-info-section';
import type { Device } from '../types/device.types';

const device: Device = {
  hostname: 'workstation-01',
  type: 'Desktop',
  osType: 'windows',
  manufacturer: 'Dell',
  model: 'OptiPlex 7090',
  serialNumber: 'ABC123',
  osUuid: 'xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx',
  organization: 'Acme Corp',
  organizationId: 'org_42',
  registeredAt: '2024-01-15T10:30:00Z',
  updatedAt: '2024-06-01T08:00:00Z',
};

<DeviceInfoSection device={device} />
```
