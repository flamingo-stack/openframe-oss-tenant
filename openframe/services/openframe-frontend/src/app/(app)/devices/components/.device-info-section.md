Renders a responsive device information card displaying key metadata about a managed device, adapting its layout across mobile, tablet, and desktop breakpoints.

## Key Components

**`DeviceInfoSection`**
Main export. Accepts a `Device | null` prop and renders a structured card with the following info cells:
- **Hostname** — device network name
- **Type** — device category with icon
- **Device** — manufacturer/model with OS type icon
- **Serial Number** — hardware serial or fallback
- **Customer** — linked organization with avatar (navigates to `/customers/details/:id`)
- **Assigned User** — user avatar + name (hidden until backend returns user entity)
- **Registered / Updated** — ISO timestamps split into date + secondary-styled time
- **UUID** — copyable machine/OS UUID with clipboard feedback icon

**`formatDateWithTime(iso?)`**
Private helper that formats an ISO date string into a `ReactNode` with the date and a secondary-colored time segment.

## Usage Example

```typescript
import { DeviceInfoSection } from './device-info-section';
import type { Device } from '../types/device.types';

const device: Device = {
  hostname: 'workstation-01',
  type: 'Laptop',
  manufacturer: 'Dell',
  model: 'XPS 15',
  osType: 'windows',
  serialNumber: 'SN123456',
  osUuid: 'xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx',
  organization: 'Acme Corp',
  organizationId: 'org-42',
  registeredAt: '2024-01-15T10:30:00Z',
  updatedAt: '2024-06-01T08:00:00Z',
};

export default function DevicePage() {
  return <DeviceInfoSection device={device} />;
}
```

## Layout Behavior

| Breakpoint | Columns per row |
|---|---|
| Mobile (`< md`) | 2 cells; customer/assigned as full-width rows |
| Tablet (`md–lg`) | 2 cells; customer + assigned share one row |
| Desktop (`lg+`) | 4 cells per row |
