Displays an antivirus warning card for OpenFrame installations, alerting users that security software may falsely block the installer and providing platform-specific folder paths to add as exclusions.

## Key Components

- **`AntivirusWarning`** — Main component accepting an `OSPlatformId` prop (`'windows'` | `'darwin'`) and rendering a warning card with copyable exclusion paths
- **`OPENFRAME_PATHS`** — External constant providing OS-specific folder paths to whitelist
- **`PathsDisplay`** — Shared UI component rendering the list of paths with copy-to-clipboard buttons
- **`useCopyToClipboard`** — Hook handling clipboard operations with success/error toast notifications

## Usage Example

```typescript
import { AntivirusWarning } from './antivirus-warning';

// Inside an installation setup page
export function InstallPage() {
  const platform = 'windows'; // or 'darwin'

  return (
    <div>
      <h1>Install OpenFrame</h1>
      <AntivirusWarning platform={platform} />
    </div>
  );
}
```

## Behavior Notes

- Returns `null` silently when `platform` is unsupported (e.g., `'linux'`) or no paths are defined
- Paths are memoized via `useMemo` to avoid unnecessary recalculation on re-renders
- Each path entry is individually copyable via `onCopyPath`, delegated to the `useCopyToClipboard` hook
- Styled using ODS (OpenFrame Design System) CSS variables for consistent theming across light/dark modes
