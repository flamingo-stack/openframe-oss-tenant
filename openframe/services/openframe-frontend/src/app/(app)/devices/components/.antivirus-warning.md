Displays a platform-aware antivirus warning card during OpenFrame installation, listing OS-specific folder paths that users should add to their antivirus exclusions to prevent false-positive blocks.

## Key Components

- **`AntivirusWarning`** — Main exported component that renders a warning banner with exclusion paths and copy-to-clipboard functionality
- **`AntivirusWarningProps`** — Interface accepting a `platform` prop of type `OSPlatformId` (`'windows'` | `'darwin'`)
- **`OPENFRAME_PATHS`** — Platform-keyed path map imported from `openframe-frontend-core`, providing OS-specific exclusion folder paths
- **`PathsDisplay`** — Reusable component from core that renders the list of paths with individual copy buttons
- **`useCopyToClipboard`** — Custom hook handling clipboard operations with success/error toast notifications

## Usage Example

```typescript
import { AntivirusWarning } from './antivirus-warning';

// Inside an installation wizard step
export function InstallStep({ detectedPlatform }: { detectedPlatform: OSPlatformId }) {
  return (
    <div>
      <h2>Install OpenFrame</h2>
      <AntivirusWarning platform={detectedPlatform} />
    </div>
  );
}
```

## Behavior Notes

- Returns `null` when the platform has no defined paths (e.g., Linux), rendering nothing
- Paths are memoized via `useMemo` to avoid recomputation on re-renders
- The `copyPath` callback is stabilized with `useCallback` to prevent unnecessary re-renders of `PathsDisplay`
- Warning is styled using ODS (OpenFrame Design System) CSS variables for consistent theming
