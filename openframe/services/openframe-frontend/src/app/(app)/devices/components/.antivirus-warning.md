Displays a platform-aware antivirus warning card during OpenFrame installation, guiding users to add exclusion paths or temporarily disable antivirus protection when a false positive block occurs.

## Key Components

- **`AntivirusWarning`** — Main exported component that renders a warning banner with actionable exclusion paths based on the detected OS platform
- **`AntivirusWarningProps`** — Interface accepting a `platform` prop of type `OSPlatformId` (`'windows'` | `'darwin'`)
- **`OPENFRAME_PATHS`** — Platform-keyed path map sourced from `openframe-frontend-core`, used to resolve OS-specific antivirus exclusion directories
- **`PathsDisplay`** — Shared UI component rendering the exclusion paths list with per-path copy-to-clipboard actions
- **`useCopyToClipboard`** — Local hook wiring clipboard copy with toast-style success/error feedback

## Usage Example

```typescript
import { AntivirusWarning } from './antivirus-warning';

// Inside an installation step or setup wizard
export function InstallationPage() {
  const detectedPlatform = 'windows'; // resolved from OS detection logic

  return (
    <div>
      <h2>Install OpenFrame</h2>
      <AntivirusWarning platform={detectedPlatform} />
    </div>
  );
}
```

## Behavior Notes

- Returns `null` when `platform` is neither `'windows'` nor `'darwin'` (e.g. Linux), since no exclusion paths are defined for those platforms
- Path list is memoized via `useMemo` to avoid recomputation on unrelated re-renders
- Copy handler is stabilized with `useCallback` to prevent unnecessary child re-renders in `PathsDisplay`
