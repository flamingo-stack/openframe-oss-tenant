Renders loading skeleton placeholders for the device details page, mirroring the layout of every section and tab (Hardware, Network, Security, Compliance, Agents) to prevent layout shift during data fetching.

## Key Components

| Component | Description |
|-----------|-------------|
| `SectionHeadingSkeleton` | Reusable heading placeholder matching `h3.text-h5` styling |
| `InfoCardSkeleton` | Card placeholder with configurable item count, title, subtitle, and progress bar |
| `TableSkeleton` | Table placeholder with configurable column widths and row count |
| `InfoFieldSkeleton` | Field placeholder matching `DeviceInfoSection` label/value pair layout |
| `DeviceInfoSectionSkeleton` | Three-row grid of 4 fields each, matching the device info header block |
| `DeviceStatusAndTagsSkeleton` | Status tag and chip strip placeholder |
| `TabNavigationSkeleton` | Full-width tab bar with 9 icon+label tab placeholders |
| `HardwareTabSkeleton` | Disk (4 cards), RAM (2 cards), and CPU (1 card) section skeletons |
| `NetworkTabSkeleton` | Public IP card plus 2-column local address grid skeleton |
| `SecurityTabSkeleton` | Six security sections (posture, sessions, agents, network, alerts, boot) |
| `ComplianceTabSkeleton` | Patch management, policy compliance, and compliance checks sections |
| `AgentsTabSkeleton` | 3-column grid of 6 agent cards with absolute-positioned badge and icon overlays |

## Usage Example

```typescript
import {
  DeviceInfoSectionSkeleton,
  TabNavigationSkeleton,
  HardwareTabSkeleton,
} from './device-details-skeleton';

export default function DeviceDetailsPage({ isLoading }: { isLoading: boolean }) {
  if (isLoading) {
    return (
      <>
        <DeviceStatusAndTagsSkeleton />
        <DeviceInfoSectionSkeleton />
        <TabNavigationSkeleton />
        <HardwareTabSkeleton />
      </>
    );
  }

  return <ActualDeviceDetails />;
}
```

All components are `'use client'` and rely solely on the `Skeleton` primitive from `@flamingo-stack/openframe-frontend-core`. No props are required — each skeleton is self-contained and sized to match its real counterpart pixel-for-pixel.
