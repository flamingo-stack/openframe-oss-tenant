Skeleton loading state component for the device details page, providing pixel-accurate placeholder layouts that mirror the real UI components while data is being fetched.

## Key Components

| Component | Description |
|-----------|-------------|
| `SectionHeadingSkeleton` | Section heading placeholder matching `h3.text-h5` styles |
| `InfoCardSkeleton` | Configurable card skeleton with optional title, subtitle, items, and progress bar |
| `TableSkeleton` | Table skeleton with configurable columns and row count |
| `InfoFieldSkeleton` | Single field skeleton matching label/value pairs in device info sections |
| `DeviceInfoSectionSkeleton` | Three-row grid of 4 fields each, matching the device info header |
| `DeviceStatusAndTagsSkeleton` | Status tag and chip row placeholder |
| `TabNavigationSkeleton` | 9-tab navigation bar skeleton with icon + label slots |
| `HardwareTabSkeleton` | Disk, RAM, and CPU section skeletons |
| `NetworkTabSkeleton` | Public IP and local address card skeletons |
| `SecurityTabSkeleton` | Six security sections (posture, sessions, agents, network, alerts, boot) |
| `ComplianceTabSkeleton` | Patch management, policy compliance, and compliance checks sections |
| `AgentsTabSkeleton` | 6-card grid with absolute-positioned tool badge and info icon slots |

## Usage Example

```typescript
// Render the full device details skeleton while data loads
import { DeviceDetailsSkeleton } from './device-details-skeleton';

function DeviceDetailsPage({ deviceId }: { deviceId: string }) {
  const { data, isLoading } = useDeviceDetails(deviceId);

  if (isLoading) {
    return <DeviceDetailsSkeleton />;
  }

  return <DeviceDetails data={data} />;
}
```

## Notes

- All skeletons use ODS design tokens (`bg-ods-card`, `border-ods-border`) for consistent dark-mode rendering
- `InfoCardSkeleton` props control visibility of title (`showTitle`), subtitle (`showSubtitle`), and progress bar (`showProgress`), and item count (`itemCount`)
- Tab-specific skeletons are scoped to their respective data shapes and grid layouts
