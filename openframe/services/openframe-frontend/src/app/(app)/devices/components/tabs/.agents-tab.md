Renders the **Agents** tab for a device detail view, merging `installedAgents` and `toolConnections` data into a unified grid of agent cards with status, version, and ID details.

## Key Components

- **`AgentsTab`** — Main exported component accepting a `Device` prop
- **`agentTypeToToolType`** — Maps raw agent type strings (e.g. `'tacticalrmm-agent'`) to normalized tool type keys (e.g. `'TACTICAL_RMM'`)
- **`AGENT_TYPES_WITH_STATUS`** — Set of tool types that support live status display (`TACTICAL_RMM`, `FLEET_MDM`, `MESHCENTRAL`)
- **`getAgentDisplayStatus`** — Dispatches to per-tool status parsers, normalizing raw status strings to `'online' | 'offline'`
- **`combinedAgents`** — Merge logic that deduplicates installed agents and tool connections, sorting connected agents (those with `agentToolId`) first

## Behavior

- Installed agents without a matching tool connection are still rendered with version info
- Tool connections without a matching installed agent are appended as connection-only entries
- Each agent card shows a `ToolBadge`, an info `Tooltip`, and an `InfoCard` with conditional fields: **Status** tag, **Last seen**, **ID** (copyable), **Version**, **Last fetched**
- If no agents exist, a single empty-state `InfoCard` is shown

## Usage Example

```typescript
import { AgentsTab } from './agents-tab';
import type { Device } from '../../types/device.types';

const device: Device = {
  toolConnections: [
    { toolType: 'TACTICAL_RMM', agentToolId: 'abc-123', status: 'online', lastSeen: '2024-01-01T00:00:00Z', lastFetched: '2024-01-01T01:00:00Z' },
  ],
  installedAgents: [
    { agentType: 'tacticalrmm-agent', version: '0.17.3' },
  ],
};

<AgentsTab device={device} />;
```
