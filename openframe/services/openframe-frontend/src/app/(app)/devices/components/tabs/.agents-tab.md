Renders the **Agents** tab on a device detail page, combining `installedAgents` and `toolConnections` from a device record into a unified, sorted grid of agent cards.

## Key Components

- **`AgentsTab`** — Main exported component. Accepts a `Device` prop and renders one `InfoCard` per detected agent (or an empty-state card if none exist).
- **`agentTypeToToolType`** — Maps raw agent type strings (e.g. `'tacticalrmm-agent'`) to canonical tool type keys (e.g. `'TACTICAL_RMM'`).
- **`AGENT_TYPES_WITH_STATUS`** — Set of tool types that support live status display (`TACTICAL_RMM`, `FLEET_MDM`, `MESHCENTRAL`).
- **`getAgentDisplayStatus`** — Normalizes raw status strings per tool type into `'online' | 'offline'`.
- **`combinedAgents`** — Merged array deduplicating installed agents and tool connections; sorted to show agents with an `agentToolId` first.

## Usage Example

```typescript
import { AgentsTab } from './agents-tab';
import type { Device } from '../../types/device.types';

const device: Device = {
  installedAgents: [
    { agentType: 'tacticalrmm-agent', version: '0.17.0' },
  ],
  toolConnections: [
    {
      toolType: 'TACTICAL_RMM',
      agentToolId: 'abc-123',
      status: 'online',
      lastSeen: '2024-06-01T10:00:00Z',
      lastFetched: '2024-06-01T10:05:00Z',
    },
  ],
};

export default function DeviceDetail() {
  return <AgentsTab device={device} />;
}
```

Each agent card displays a `ToolBadge`, an info tooltip, and contextual fields — **Status** (as a `Tag`), **Last seen**, **ID** (copyable), **Version**, and **Last fetched** — depending on the agent type and available data.
