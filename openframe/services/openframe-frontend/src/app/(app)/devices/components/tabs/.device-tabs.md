Defines and exports the tab configuration for the device detail view, mapping tab IDs to their respective icons and components.

## Key Components

- **`DEVICE_TABS`** — Static array of `TabItem` objects defining all available device tabs: `hardware`, `network`, `security`, `compliance`, `agents`, `users`, `software`, `vulnerabilities`, and `logs`
- **`getDeviceTab(tabId)`** — Looks up a single `TabItem` by its string ID
- **`getTabComponent(tabId)`** — Returns the React component associated with a given tab ID, or `null` if not found

## Usage Example

```typescript
import { DEVICE_TABS, getDeviceTab, getTabComponent } from './device-tabs';

// Render all tab headers
DEVICE_TABS.forEach(tab => console.log(tab.id, tab.label));

// Retrieve a specific tab definition
const securityTab = getDeviceTab('security');
// → { id: 'security', label: 'Security', icon: ShieldIcon, component: SecurityTab }

// Dynamically render a tab's component
const TabComponent = getTabComponent('hardware');
if (TabComponent) {
  return <TabComponent device={device} />;
}
```
