Defines and exports the ordered tab configuration for the device detail view, mapping tab IDs to their icons and React components.

## Key Components

- **`DEVICE_TABS`** — Ordered array of `TabItem` objects defining all 9 device detail tabs: `hardware`, `network`, `security`, `compliance`, `agents`, `users`, `software`, `vulnerabilities`, and `logs`
- **`getDeviceTab(tabId)`** — Looks up a single `TabItem` by its string ID, returns `undefined` if not found
- **`getTabComponent(tabId)`** — Convenience helper that returns only the React component for a given tab ID, or `null` if not found

## Usage Example

```typescript
import { DEVICE_TABS, getDeviceTab, getTabComponent } from './device-tabs';

// Render all tabs in a tab bar
DEVICE_TABS.forEach(tab => console.log(tab.id, tab.label));

// Look up a specific tab
const securityTab = getDeviceTab('security');
// → { id: 'security', label: 'Security', icon: ShieldIcon, component: SecurityTab }

// Dynamically render a tab's content
const TabComponent = getTabComponent('hardware');
if (TabComponent) {
  return <TabComponent device={device} />;
}
```
