Defines and exports the ordered list of tab configurations for the device detail view, mapping each tab ID to its label, icon, and component.

## Key Components

- **`DEVICE_TABS`** — Ordered array of `TabItem` configs covering: `hardware`, `network`, `security`, `compliance`, `agents`, `users`, `software`, `vulnerabilities`, and `logs`
- **`getDeviceTab(tabId)`** — Looks up a single `TabItem` by its string ID; returns `undefined` if not found
- **`getTabComponent(tabId)`** — Returns the React component associated with a tab ID, or `null` if not found

## Usage Example

```typescript
import {
  DEVICE_TABS,
  getDeviceTab,
  getTabComponent,
} from './device-tabs';

// Render all tab labels in a nav bar
DEVICE_TABS.forEach(tab => console.log(tab.id, tab.label));

// Resolve a single tab by ID
const securityTab = getDeviceTab('security');
// → { id: 'security', label: 'Security', icon: ShieldIcon, component: SecurityTab }

// Dynamically render the active tab's component
const ActiveComponent = getTabComponent('hardware');
if (ActiveComponent) {
  return <ActiveComponent device={device} />;
}
```
