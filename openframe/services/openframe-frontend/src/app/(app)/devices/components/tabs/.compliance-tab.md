Renders the compliance tab for a device detail view, displaying patch management status, Windows update policies, policy compliance hierarchy, compliance check results, and Fleet MDM labels/issues.

## Key Components

- **`ComplianceTab`** — Main exported component accepting a `device` prop and rendering all compliance-related sections
- **`formatScheduleDays`** — Internal helper that converts numeric day arrays (0–6) to abbreviated day name strings (e.g., `Mon, Wed, Fri`)

## Sections Rendered

| Section | Description |
|---|---|
| Patch Management | Last install date, pending patches status |
| Windows Update Policy | Severity policies and update schedule (conditional) |
| Policy Compliance | Applied policy hierarchy + inheritance settings |
| Compliance Checks | Pass/fail/warning/info check counts |
| Fleet Policies | Failing policies and total issues (conditional) |
| Fleet Labels | MDM labels rendered as styled badges (conditional) |

## Usage Example

```typescript
import { ComplianceTab } from './compliance-tab';

// Inside a device detail page or tab panel
<ComplianceTab device={deviceData} />
```

Where `deviceData` is expected to include optional fields such as:

```typescript
{
  patches_last_installed: string;
  has_patches_pending: boolean;
  winupdatepolicy: Array<{ critical: string; run_time_days: number[]; ... }>;
  checks: { total: number; passing: number; failing: number; warning: number; info: number };
  applied_policies: { agent_policy: string; site_policy: string; ... };
  block_policy_inheritance: boolean;
  issues: { failing_policies_count: number; total_issues_count: number };
  labels: Array<{ name: string }>;
}
```

Renders an empty state with a centered message when `device` is `null` or `undefined`.
