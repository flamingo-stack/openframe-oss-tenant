Renders a device compliance dashboard tab displaying patch management status, Windows Update policies, policy hierarchy, automated compliance checks, Fleet MDM policies, and Fleet labels for a given device.

## Key Components

- **`ComplianceTab`** — Main exported React component that accepts a `device` prop and renders multiple compliance sections
- **`formatScheduleDays`** — Internal helper that converts numeric day arrays (0–6) to abbreviated weekday strings (e.g., `Mon, Wed, Fri`)
- **Section guards** — Conditional rendering for Windows Update Policy, Fleet Policies, and Fleet Labels sections (only shown when data exists)

## Usage Example

```typescript
import { ComplianceTab } from './compliance-tab';

const device = {
  patches_last_installed: '2024-01-15T10:00:00Z',
  has_patches_pending: false,
  winupdatepolicy: [{ critical: 'auto', important: 'auto', run_time_hour: 2, run_time_days: [1, 3, 5] }],
  applied_policies: { agent_policy: 'Default Agent', site_policy: 'None' },
  block_policy_inheritance: false,
  checks: { total: 12, passing: 10, failing: 1, warning: 1, info: 0 },
  issues: { failing_policies_count: 1, total_issues_count: 3 },
  labels: [{ name: 'PRODUCTION' }, { name: 'WINDOWS' }],
};

<ComplianceTab device={device} />
```

## Sections Rendered

| Section | Data Source | Conditional |
|---|---|---|
| Patch Management | `device.patches_last_installed`, `has_patches_pending` | Always shown |
| Windows Update Policy | `device.winupdatepolicy[0]` | Only if policy data exists |
| Policy Compliance | `device.applied_policies` | Always shown |
| Compliance Checks | `device.checks` | Always shown |
| Fleet Policies | `device.issues` | Only if issues exist |
| Fleet Labels | `device.labels` | Only if labels present |
