Renders the Compliance tab for a device detail view, displaying patch management status, Windows update policies, policy compliance hierarchy, compliance check results, Fleet MDM policies, and Fleet labels.

## Key Components

- **`ComplianceTab`** — Main exported component accepting a `device` prop and rendering all compliance-related sections
- **`formatScheduleDays`** — Internal helper that converts numeric day arrays (0–6) to abbreviated day name strings (e.g., `Mon, Wed, Fri`)
- **Conditional sections** — Windows Update Policy, Fleet Policies, and Fleet Labels sections only render when relevant data is present on the device object

## Data Sections Rendered

| Section | Source Field |
|---|---|
| Patch Management | `patches_last_installed`, `has_patches_pending` |
| Windows Update Policy | `winupdatepolicy[0]` |
| Policy Compliance | `applied_policies`, `block_policy_inheritance` |
| Compliance Checks | `checks` (total, passing, failing, warning, info) |
| Fleet Policies | `issues` |
| Fleet Labels | `labels` |

## Usage Example

```typescript
import { ComplianceTab } from './compliance-tab';

// Inside a device detail page or tab panel
<ComplianceTab device={deviceData} />

// deviceData shape (partial)
const deviceData = {
  patches_last_installed: '2024-01-15T10:30:00Z',
  has_patches_pending: false,
  winupdatepolicy: [{ critical: 'install', run_time_days: [1, 3, 5] }],
  applied_policies: { agent_policy: 'Default', site_policy: 'None' },
  checks: { total: 12, passing: 10, failing: 1, warning: 1 },
  issues: { failing_policies_count: 2, total_issues_count: 3 },
  labels: [{ name: 'WORKSTATION' }],
};
```

> Each card includes an `InfoIcon` tooltip with contextual help describing the data source (Tactical RMM or Fleet MDM).
