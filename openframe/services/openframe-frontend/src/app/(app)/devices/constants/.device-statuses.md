Defines device status constants and typed status groupings used across device queries and views throughout the platform.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `DEVICE_STATUS` | `const object` | Exhaustive map of all possible device status values |
| `DeviceStatus` | `type` | Union type of all valid status strings |
| `DEFAULT_VISIBLE_STATUSES` | `const array` | Statuses shown in default/general device views (`ONLINE`, `OFFLINE`, `PENDING`, `ARCHIVED`) |
| `DEFAULT_DASHBOARD_STATUSES` | `const array` | Statuses shown on the dashboard (`ONLINE`, `OFFLINE`) |
| `DEFAULT_DEVICES_LIST_STATUSES` | `const array` | Statuses shown in the devices list view (`ONLINE`, `OFFLINE`, `ARCHIVED`) |
| `HIDDEN_DEVICE_STATUSES` | `const array` | Statuses excluded from default views (`ARCHIVED`, `DELETED`) |
| `DefaultVisibleStatus` | `type` | Union type narrowed to `DEFAULT_VISIBLE_STATUSES` members |
| `HiddenDeviceStatus` | `type` | Union type narrowed to `HIDDEN_DEVICE_STATUSES` members |

## Usage Example

```typescript
import {
  DEVICE_STATUS,
  DeviceStatus,
  DEFAULT_DASHBOARD_STATUSES,
  DEFAULT_DEVICES_LIST_STATUSES,
} from './device-statuses';

// Type-safe status comparison
function isOnline(status: DeviceStatus): boolean {
  return status === DEVICE_STATUS.ONLINE;
}

// Use pre-defined groups for query filters
const dashboardDevices = await fetchDevices({
  statuses: DEFAULT_DASHBOARD_STATUSES, // ['ONLINE', 'OFFLINE']
});

const listDevices = await fetchDevices({
  statuses: DEFAULT_DEVICES_LIST_STATUSES, // ['ONLINE', 'OFFLINE', 'ARCHIVED']
});
```

> **Note:** When new statuses are added to the backend, update `DEFAULT_VISIBLE_STATUSES` and relevant groupings to include them in default views.
