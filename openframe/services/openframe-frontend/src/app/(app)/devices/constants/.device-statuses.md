Defines device status constants and typed status collections used across device queries, dashboards, and list views to ensure consistent filtering behavior.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `DEVICE_STATUS` | `const object` | Exhaustive map of all possible device status string literals |
| `DeviceStatus` | `type` | Union type derived from all `DEVICE_STATUS` values |
| `DEFAULT_VISIBLE_STATUSES` | `const array` | Default filter set for general device views (excludes `DELETED`) |
| `DEFAULT_DASHBOARD_STATUSES` | `const array` | Restricted set for dashboard widgets (`ONLINE`, `OFFLINE` only) |
| `DEFAULT_DEVICES_LIST_STATUSES` | `const array` | Status filter for the main devices list view |
| `HIDDEN_DEVICE_STATUSES` | `const array` | Statuses excluded from default queries (`ARCHIVED`, `DELETED`) |
| `DefaultVisibleStatus` | `type` | Union type scoped to `DEFAULT_VISIBLE_STATUSES` members |
| `HiddenDeviceStatus` | `type` | Union type scoped to `HIDDEN_DEVICE_STATUSES` members |

## Usage Example

```typescript
import {
  DEVICE_STATUS,
  DEFAULT_DASHBOARD_STATUSES,
  DEFAULT_DEVICES_LIST_STATUSES,
  type DeviceStatus,
} from './device-statuses';

// Type-safe status comparison
function isOnline(status: DeviceStatus): boolean {
  return status === DEVICE_STATUS.ONLINE;
}

// Use pre-defined filter sets in queries
const devices = await db.devices.findMany({
  where: {
    status: { in: [...DEFAULT_DEVICES_LIST_STATUSES] },
  },
});

// Dashboard — only active statuses
const dashboardDevices = await db.devices.findMany({
  where: {
    status: { in: [...DEFAULT_DASHBOARD_STATUSES] },
  },
});
```

> **Note:** When adding new statuses to the backend, update `DEFAULT_VISIBLE_STATUSES` and the relevant default arrays to ensure new statuses surface in the correct views.
