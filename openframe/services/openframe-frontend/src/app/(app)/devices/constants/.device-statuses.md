Defines and exports typed constants for device lifecycle statuses used across device queries, dashboards, and list views throughout the Flamingo platform.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `DEVICE_STATUS` | `const object` | Exhaustive map of all device status string literals |
| `DeviceStatus` | `type` | Union type of all valid status values |
| `DEFAULT_VISIBLE_STATUSES` | `readonly array` | Statuses shown in general views (`ONLINE`, `OFFLINE`, `PENDING`, `ARCHIVED`) |
| `DEFAULT_DASHBOARD_STATUSES` | `readonly array` | Statuses shown on dashboards (`ONLINE`, `OFFLINE` only) |
| `DEFAULT_DEVICES_LIST_STATUSES` | `readonly array` | Statuses shown in device list views (`ONLINE`, `OFFLINE`, `ARCHIVED`) |
| `DefaultVisibleStatus` | `type` | Union type derived from `DEFAULT_VISIBLE_STATUSES` |
| `HIDDEN_DEVICE_STATUSES` | `readonly array` | Statuses excluded from default views (`ARCHIVED`, `DELETED`) |
| `HiddenDeviceStatus` | `type` | Union type derived from `HIDDEN_DEVICE_STATUSES` |

## Usage Example

```typescript
import {
  DEVICE_STATUS,
  DEFAULT_DASHBOARD_STATUSES,
  DEFAULT_DEVICES_LIST_STATUSES,
  type DeviceStatus,
} from './device-statuses';

// Type-safe status comparison
function isOnline(status: DeviceStatus): boolean {
  return status === DEVICE_STATUS.ONLINE;
}

// Filter devices for dashboard query
const dashboardDevices = allDevices.filter(device =>
  (DEFAULT_DASHBOARD_STATUSES as readonly string[]).includes(device.status)
);

// Filter devices for list view (includes ARCHIVED)
const listDevices = allDevices.filter(device =>
  (DEFAULT_DEVICES_LIST_STATUSES as readonly string[]).includes(device.status)
);
```

> **Note:** When adding new statuses to the backend, update `DEFAULT_VISIBLE_STATUSES` to include them in default views. `ARCHIVED` and `DELETED` are intentionally excluded from most views via `HIDDEN_DEVICE_STATUSES`.
