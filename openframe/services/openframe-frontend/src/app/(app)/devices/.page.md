Devices page route component that renders the shared `DevicesPanel` with system-level spacing tokens applied.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Devices` | Default export | Next.js page component rendering the devices panel |
| `dynamic` | Named export | Forces dynamic rendering on every request (`'force-dynamic'`) |

## Usage Example

```typescript
// Rendered automatically by Next.js when navigating to the /devices route.
// The panel fills the layout with ODS-defined spacing:
<DevicesPanel className="px-[var(--spacing-system-l)] pb-[var(--spacing-system-l)]" />
```

## Notes

- Marked `'use client'` — runs in the browser, enabling client-side interactivity within `DevicesPanel`.
- `force-dynamic` disables static generation, ensuring device data is always fetched fresh on each request.
- Spacing is applied via CSS custom properties (`--spacing-system-l`) from the ODS token system rather than hardcoded Tailwind values.
