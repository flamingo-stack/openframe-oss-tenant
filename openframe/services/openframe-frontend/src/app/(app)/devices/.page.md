Devices page route component that renders the shared `DevicesPanel` with consistent system spacing.

## Key Components

- **`Devices`** — Default page export; wraps `DevicesPanel` with horizontal and bottom padding using CSS custom properties
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time

## Usage Example

```typescript
// Rendered automatically by Next.js at the /devices route.
// DevicesPanel receives layout-level spacing via CSS variables:
<DevicesPanel className="px-[var(--spacing-system-l)] pb-[var(--spacing-system-l)]" />
```
