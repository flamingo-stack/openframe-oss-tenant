Devices page route component that renders the shared `DevicesPanel` with system-level layout spacing.

## Key Components

- **`Devices`** (default export) — Client-side page component that wraps `DevicesPanel` with horizontal and bottom padding using CSS custom properties (`--spacing-system-l`)
- **`dynamic`** — Exported constant forcing Next.js dynamic (no static pre-rendering) for this route

## Usage Example

```typescript
// Rendered automatically by Next.js at the /devices route
// DevicesPanel receives layout-specific spacing via className
<Devices />
// Equivalent to:
<DevicesPanel className="px-[var(--spacing-system-l)] pb-[var(--spacing-system-l)]" />
```
