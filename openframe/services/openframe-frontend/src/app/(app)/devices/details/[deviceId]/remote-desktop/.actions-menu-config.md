Defines the actions menu configuration for remote desktop sessions, providing keyboard shortcuts, power controls, and session toggles via a structured menu group factory.

## Key Components

**`VK`** — Constants map of Windows Virtual-Key codes used to compose keyboard shortcut combos.

**`ActionHandlers`** — Interface defining all side-effect callbacks required by the menu, including `sendCtrlAltDel`, `sendKeyCombo`, `sendPower`, `setEnableInput`, `setClipboardEnabled`, and `toast`.

**`createActionsMenuGroups`** — Factory function that returns three `ActionsMenuGroup` arrays:
- **Shortcuts submenu** — Predefined key combos (Ctrl+Alt+Del, Win+M, Win+L, Win+R, Ctrl+W, etc.)
- **Power controls** — Wake, Sleep, Reboot, Shut Down actions
- **Session toggles** — Enable Input and Clipboard Sharing checkboxes

## Usage Example

```typescript
import { createActionsMenuGroups, ActionHandlers } from './actions-menu-config';

const handlers: ActionHandlers = {
  sendCtrlAltDel: () => remoteSession.ctrlAltDel(),
  sendKeyCombo: (keys) => remoteSession.sendKeys(keys),
  sendPower: (action) => remoteSession.power(action),
  setEnableInput: (enabled) => setInputState(enabled),
  setClipboardEnabled: (enabled) => setClipboardState(enabled),
  toast: ({ title, description, variant }) =>
    showToast({ title, description, variant }),
};

const menuGroups = createActionsMenuGroups(
  handlers,
  enableInput,       // boolean — current input toggle state
  clipboardEnabled,  // boolean — current clipboard toggle state
);
```
