Defines the configuration and menu structure for the remote desktop actions menu, including keyboard shortcuts, power controls, and session toggles.

## Key Components

### `VK` — Virtual Key Codes
A constant map of Windows Virtual-Key codes used to construct keyboard combos sent to the remote session.

### `ActionHandlers` — Interface
Defines the handler callbacks required by the menu:

| Handler | Description |
|---|---|
| `sendCtrlAltDel` | Sends the Ctrl+Alt+Del sequence |
| `sendKeyCombo` | Sends an arbitrary key combination by VK code array |
| `sendPower` | Triggers a power action (`wake`, `sleep`, `reset`, `poweroff`) |
| `setEnableInput` | Toggles keyboard/mouse input to the remote session |
| `setClipboardEnabled` | Toggles clipboard sharing |
| `toast` | Displays a toast notification with title, description, and variant |

### `createActionsMenuGroups` — Factory Function
Returns an `ActionsMenuGroup[]` structure consumed by `ActionsMenu` from `@flamingo-stack/openframe-frontend-core`. Accepts the handler map and current toggle states.

**Menu groups produced:**

1. **Shortcuts submenu** — Ctrl+Alt+Del and common Win/Ctrl key combos with toast feedback
2. **Power controls** — Wake, Sleep, Reboot, Shut Down actions with Lucide icons
3. **Session toggles** — Checkbox items for Enable Input and Clipboard Sharing

## Usage Example

```typescript
const menuGroups = createActionsMenuGroups(
  {
    sendCtrlAltDel: () => session.ctrlAltDel(),
    sendKeyCombo: (keys) => session.sendKeys(keys),
    sendPower: (action) => device.power(action),
    setEnableInput: (enabled) => setInputEnabled(enabled),
    setClipboardEnabled: (enabled) => setClipboard(enabled),
    toast: ({ title, description, variant }) =>
      showToast({ title, description, variant }),
  },
  inputEnabled,
  clipboardEnabled,
);

<ActionsMenu groups={menuGroups} />
```
