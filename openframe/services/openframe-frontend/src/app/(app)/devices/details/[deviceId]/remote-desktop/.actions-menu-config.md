Defines the configuration and menu structure for a remote desktop actions menu, including keyboard shortcuts, power controls, and input toggles.

## Key Components

**`VK`** — Windows Virtual-Key code constants (hex) for composing key combinations (e.g., `SHIFT`, `LWIN`, `CONTROL`).

**`ActionHandlers`** — Interface defining the callback contract required by the menu:
- `sendCtrlAltDel` — Sends the Ctrl+Alt+Del sequence
- `sendKeyCombo(keys)` — Sends an arbitrary key combination by VK codes
- `sendPower(action)` — Triggers a power action (`wake`, `sleep`, `reset`, `poweroff`)
- `setEnableInput` / `setClipboardEnabled` — Toggles input and clipboard state
- `toast` — Displays a notification after an action

**`createActionsMenuGroups(handlers, enableInput, clipboardEnabled)`** — Factory function returning three `ActionsMenuGroup` arrays:
1. **Shortcuts submenu** — 8 Windows key combos (Alt+Ctrl+Del, Win+M/L/R, Ctrl+W, etc.)
2. **Power controls** — Wake, Sleep, Reboot, Shut Down
3. **Toggles** — Enable Input and Clipboard Sharing checkboxes

## Usage Example

```typescript
import { createActionsMenuGroups, ActionHandlers } from './actions-menu-config';

const handlers: ActionHandlers = {
  sendCtrlAltDel: () => rdpSession.sendCtrlAltDel(),
  sendKeyCombo: (keys) => rdpSession.sendKeys(keys),
  sendPower: (action) => rdpSession.power(action),
  setEnableInput: (enabled) => setInputEnabled(enabled),
  setClipboardEnabled: (enabled) => setClipboard(enabled),
  toast: ({ title, description, variant }) =>
    showToast({ title, description, variant }),
};

const menuGroups = createActionsMenuGroups(handlers, inputEnabled, clipboardEnabled);

<ActionsMenu groups={menuGroups} />
```
