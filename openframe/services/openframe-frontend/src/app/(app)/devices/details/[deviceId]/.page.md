Renders the device details page for a specific device, resolving dynamic route params and delegating display logic to `DeviceDetailsView`.

## Key Components

- **`DeviceDetailsPage`** — Default page component that unwraps the async `params` Promise using React's `use()` hook and extracts `deviceId` from the route segment
- **`dynamic = 'force-dynamic'`** — Next.js export flag that disables static generation, required due to `useSearchParams` usage in `AppLayout`
- **`DeviceDetailsView`** — Imported component responsible for rendering the full device details UI

## Usage Example

```typescript
// Accessed via route: /devices/[deviceId]
// e.g. /devices/abc-123

// Next.js automatically passes route params as a Promise in App Router
<DeviceDetailsPage params={Promise.resolve({ deviceId: 'abc-123' })} />

// Internally resolves to:
<DeviceDetailsView deviceId="abc-123" />
```

## Notes

- Uses React 19's `use()` hook to unwrap the `params` Promise, required by Next.js App Router where route params are now async
- All business logic and UI rendering is delegated to `DeviceDetailsView`, keeping this page component minimal and focused on routing concerns
