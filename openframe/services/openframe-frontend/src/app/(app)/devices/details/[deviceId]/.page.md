Renders the device details page for a specific device, resolving dynamic route params and delegating display to `DeviceDetailsView`.

## Key Components

- **`DeviceDetailsPage`** — Default page component that unwraps the async `params` Promise using React's `use()` hook and extracts the `deviceId` route segment
- **`dynamic = 'force-dynamic'`** — Disables static rendering to support `useSearchParams` used in the parent `AppLayout`
- **`DeviceDetailsView`** — Delegate component that receives the resolved `deviceId` and handles all device detail rendering logic

## Usage Example

```typescript
// Route: /devices/[deviceId]/page.tsx
// Accessed via: /devices/abc-123

export default function DeviceDetailsPage({ params }: DeviceDetailsPageProps) {
  const resolvedParams = use(params); // unwrap Promise<{ deviceId: string }>
  const id = resolvedParams.deviceId; // e.g. "abc-123"
  return <DeviceDetailsView deviceId={id} />;
}
```

> **Note:** The `params` prop is typed as `Promise<{ deviceId: string }>` per Next.js 15+ async params API. Use React's `use()` hook (not `await`) since this is a client component.
