Renders the device details page by resolving dynamic route params and delegating display to `DeviceDetailsView`.

## Key Components

- **`DeviceDetailsPage`** — Default page component that unwraps the async `params` Promise using React's `use()` hook and passes the resolved `deviceId` to the view layer
- **`dynamic = 'force-dynamic'`** — Next.js segment config forcing dynamic rendering, required due to `useSearchParams` usage in `AppLayout`

## Usage Example

```typescript
// Route: /devices/[deviceId]/page.tsx
// Accessed via: /devices/abc-123

// Next.js automatically passes params as a Promise in App Router
<DeviceDetailsPage params={Promise.resolve({ deviceId: 'abc-123' })} />

// Internally resolves to:
<DeviceDetailsView deviceId="abc-123" />
```

## Notes

- Uses React 19's `use()` hook to unwrap the async `params` Promise inline within the component
- Thin route-layer component — all rendering logic lives in `DeviceDetailsView`
- `force-dynamic` prevents static generation at build time for this route segment
