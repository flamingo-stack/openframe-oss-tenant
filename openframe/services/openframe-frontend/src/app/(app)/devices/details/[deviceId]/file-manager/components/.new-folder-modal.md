Modal component for creating new folders, wrapping `SimpleModal` with a controlled text input and keyboard/button submission support.

## Key Components

- **`NewFolderModalProps`** — Interface defining the modal's controlled state and event handlers:
  - `isOpen` / `onClose` — visibility control
  - `folderName` / `onChange` — controlled input value
  - `submitting` — loading state to disable controls during async submission
  - `onSubmit` — submission callback

- **`NewFolderModal`** — Named export rendering a `SimpleModal` with:
  - Auto-focused `Input` for folder name entry
  - `Enter` key listener (via `useEffect`) that triggers `onSubmit` when input is non-empty and not already submitting
  - Cancel/Create footer buttons with disabled states tied to `submitting` and `folderName` validity

## Usage Example

```typescript
const [isOpen, setIsOpen] = useState(false);
const [folderName, setFolderName] = useState('');
const [submitting, setSubmitting] = useState(false);

const handleSubmit = async () => {
  setSubmitting(true);
  await createFolder(folderName);
  setSubmitting(false);
  setIsOpen(false);
  setFolderName('');
};

<NewFolderModal
  isOpen={isOpen}
  folderName={folderName}
  submitting={submitting}
  onChange={setFolderName}
  onSubmit={handleSubmit}
  onClose={() => setIsOpen(false)}
/>
```

> The `Enter` key listener is cleaned up automatically when the modal closes, preventing stale event handlers.
