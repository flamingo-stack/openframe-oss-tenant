Modal component for creating new folders, wrapping `SimpleModal` with a controlled text input and keyboard/button submission handling.

## Key Components

- **`NewFolderModal`** — Named export; renders a `SimpleModal` with a folder name `Input`, Cancel/Create `Button` actions, and an `Enter` key listener that triggers submission when the input is non-empty and not already submitting.

### Props (`NewFolderModalProps`)

| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls modal visibility |
| `folderName` | `string` | Controlled input value |
| `submitting` | `boolean` | Disables controls during async submission |
| `onChange` | `(value: string) => void` | Input change callback |
| `onSubmit` | `() => void` | Submission callback |
| `onClose` | `() => void` | Close/cancel callback |

## Usage Example

```typescript
const [isOpen, setIsOpen] = useState(false);
const [folderName, setFolderName] = useState('');
const [submitting, setSubmitting] = useState(false);

const handleSubmit = async () => {
  setSubmitting(true);
  await createFolder(folderName);
  setSubmitting(false);
  setIsOpen(false);
};

<NewFolderModal
  isOpen={isOpen}
  folderName={folderName}
  submitting={submitting}
  onChange={setFolderName}
  onSubmit={handleSubmit}
  onClose={() => setIsOpen(false)}
/>
```

## Behavior Notes

- The `Enter` key listener is registered only while the modal is open and cleaned up on close or unmount.
- The **Create** button and `Enter` shortcut are both gated on `folderName.trim()` being non-empty and `submitting` being `false`, preventing accidental double-submission.
