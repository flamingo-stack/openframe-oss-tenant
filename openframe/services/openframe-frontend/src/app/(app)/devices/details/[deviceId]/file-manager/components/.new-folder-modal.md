Modal component for creating a new folder, featuring keyboard support (Enter key submission) and controlled input with loading/disabled states during submission.

## Key Components

### `NewFolderModal`
A controlled modal component wrapping `SimpleModal` that renders a folder name input with Create/Cancel actions.

**Props (`NewFolderModalProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls modal visibility |
| `folderName` | `string` | Current value of the folder name input |
| `submitting` | `boolean` | Disables inputs and shows loading state during creation |
| `onChange` | `(value: string) => void` | Callback fired on input change |
| `onSubmit` | `() => void` | Callback fired on Create button click or Enter key |
| `onClose` | `() => void` | Callback fired on Cancel or modal dismiss |

**Behaviors:**
- Listens for `Enter` keydown globally while open, triggering `onSubmit` when the folder name is non-empty and not currently submitting
- Cleans up the keyboard listener on close or unmount
- Auto-focuses the input when the modal opens

## Usage Example

```typescript
const [isOpen, setIsOpen] = useState(false);
const [folderName, setFolderName] = useState('');
const [submitting, setSubmitting] = useState(false);

const handleSubmit = async () => {
  setSubmitting(true);
  await createFolder(folderName);
  setSubmitting(false);
  setIsOpen(false);
};

<NewFolderModal
  isOpen={isOpen}
  folderName={folderName}
  submitting={submitting}
  onChange={setFolderName}
  onSubmit={handleSubmit}
  onClose={() => setIsOpen(false)}
/>
```
