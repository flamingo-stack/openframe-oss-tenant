Orchestrates the remote file manager UI for a MeshCentral-connected device, wiring together file browsing, upload/download, clipboard operations, and CRUD modals into a single cohesive container component.

## Key Components

- **`FileManagerContainer`** — Main exported component that composes the full file management experience
- **`useMeshFileManager`** — Custom hook providing all file system operations over a MeshCentral WebSocket connection
- **`DeleteConfirmationModal`** — Modal for confirming file/folder deletion
- **`NewFolderModal`** — Modal for creating a new directory
- **`RenameItemModal`** — Modal for renaming a file or folder
- **`FileManagerSkeleton`** — Loading placeholder shown during connection setup

## Key Behaviors

| Feature | Details |
|---|---|
| Connection states | Shows skeleton on `disconnected` / `connecting` |
| Keyboard shortcuts | `Ctrl+C/X/V`, `Delete`, `Escape` |
| Upload/Download | Fixed bottom-right progress overlay with cancel button |
| Search | Clears on navigation; disabled at root path |
| Clipboard | Cut/copy/paste with visual status indicator |

## Usage Example

```typescript
import { FileManagerContainer } from './file-manager-container';

export default function DeviceFilesPage() {
  return (
    <FileManagerContainer
      deviceId="device-123"
      meshcentralAgentId="agent-abc"
      hostname="DESKTOP-XYZ"
      organizationName="Acme Corp"
    />
  );
}
```
