A React container component that manages the full file manager UI for a remote device, wiring together the `useMeshFileManager` hook with file operations (upload, download, rename, delete, copy/cut/paste, search, folder navigation) and modal dialogs.

## Key Components

- **`FileManagerContainer`** — Main exported component accepting device and agent identifiers, renders the `FileManager` or `FileManagerSkeleton` based on connection state
- **`useMeshFileManager`** — Hook providing all file system state and operations over a MeshCentral agent connection
- **`DeleteConfirmationModal`** — Modal for confirming single or bulk file/folder deletion
- **`NewFolderModal`** — Modal for creating a new folder in the current path
- **`RenameItemModal`** — Modal for renaming a selected file or folder
- **Upload/Download Progress Overlays** — Fixed bottom-right cards showing transfer progress with cancel support
- **Keyboard Shortcuts** — Global `keydown` listener supporting `Ctrl+C`, `Ctrl+X`, `Ctrl+V`, `Delete`, and `Escape`

## Usage Example

```typescript
import { FileManagerContainer } from './file-manager-container';

export default function DeviceFilesPage({ params }: { params: { deviceId: string } }) {
  return (
    <FileManagerContainer
      deviceId={params.deviceId}
      meshcentralAgentId="agent-abc123"
      hostname="DESKTOP-XYZ"
      organizationName="Acme Corp"
    />
  );
}
```

## Props

| Prop | Type | Description |
|------|------|-------------|
| `deviceId` | `string` | Internal device identifier, used for back-navigation |
| `meshcentralAgentId` | `string` | MeshCentral agent ID for the remote connection |
| `hostname` | `string?` | Display name shown in the page subtitle |
| `organizationName` | `string?` | Organization label (passed through, optional) |
| `className` | `string?` | Additional CSS classes for the outer container |
