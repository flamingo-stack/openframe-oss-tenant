A smart container component that wraps the `FileManager` UI with full remote file system functionality for MeshCentral-connected devices, managing navigation, uploads, downloads, search, clipboard operations, and CRUD modals.

## Key Components

**Props: `FileManagerContainerProps`**
- `deviceId` — local device identifier for back-navigation
- `meshcentralAgentId` — MeshCentral agent ID used to establish the remote connection
- `hostname` / `organizationName` — display metadata
- `className` — optional CSS override

**Internal State & Hooks**
- `useMeshFileManager` — core hook providing file list, connection state, and all remote FS operations
- `useSafeBack` — safe back-navigation to the device detail page
- `fileInputRef` — hidden `<input type="file">` triggered programmatically for uploads
- Three modal states: **New Folder**, **Rename**, **Delete Confirmation**

**Key Handlers**

| Handler | Responsibility |
|---|---|
| `handleFileAction` | Routes `FileAction` enum to the correct operation or modal |
| `handleSearch` | Debounces search; cancels active search on empty query |
| `handleFolderOpen` | Navigates into a directory via `navigateInto` |
| `handleFileClick` | Resolves a file's parent path and navigates there (used in search results) |
| `handleFileUpload` | Reads the hidden input and calls `uploadFile` |

**Keyboard Shortcuts** (registered globally via `useEffect`)
- <kbd>Ctrl/Cmd+C</kbd> — copy selected files
- <kbd>Ctrl/Cmd+X</kbd> — cut selected files
- <kbd>Ctrl/Cmd+V</kbd> — paste clipboard
- <kbd>Delete</kbd> — open delete confirmation
- <kbd>Escape</kbd> — deselect / clear clipboard

## Usage Example

```typescript
import { FileManagerContainer } from './file-manager-container';

export default function DeviceFilesPage({ params }) {
  return (
    <FileManagerContainer
      deviceId={params.deviceId}
      meshcentralAgentId={params.agentId}
      hostname="WORKSTATION-01"
      organizationName="Acme Corp"
      className="my-custom-class"
    />
  );
}
```

> **Note:** The component shows a `FileManagerSkeleton` while the MeshCentral WebSocket is in `disconnected` or early `connecting` state, and renders fixed-position progress toasts for active upload/download operations.
