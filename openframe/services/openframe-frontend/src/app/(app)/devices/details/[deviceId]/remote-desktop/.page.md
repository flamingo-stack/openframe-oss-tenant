Remote desktop session page component for MeshCentral-based device remote control, handling tunnel lifecycle, display management, clipboard sync, and fullscreen controls.

## Key Components

- **`RemoteDesktopPage`** — Default export; full-page remote desktop client rendering a canvas-backed MeshDesktop session
- **`MeshTunnel`** — WebSocket tunnel managing connection state, reconnection logic, and binary frame relay
- **`MeshDesktop`** — Canvas renderer receiving binary frames and handling keyboard/mouse input
- **`MeshControlClient`** — Control channel for auth cookies, clipboard sync, and pairing requests
- **`RemoteDesktopSettings`** — Applies quality/encoding settings once tunnel reaches connected state (`state === 3`)
- **`createActionsMenuGroups`** — Builds the actions dropdown (power, display switch, clipboard toggle, etc.)
- **`RemoteSettingsModal`** — Settings panel for encoding, quality, and input options

## Key State & Refs

| Name | Purpose |
|------|---------|
| `state` (`TunnelState`) | Current tunnel connection state (0=disconnected, 3=connected) |
| `firstFrameReceived` | Toggles loading overlay off after first video frame |
| `displays` | List of remote monitors; supports multi-display switching |
| `clipboardEnabled` | Toggles bidirectional clipboard sync via `navigator.clipboard` |
| `isFullscreen` | Tracks browser fullscreen API state |

## Usage Example

```typescript
// Route: /devices/[deviceId]/remote-desktop
// Legacy backward-compatible deep-link with encoded device data:
const url = `/devices/${deviceId}/remote-desktop?deviceData=${encodeURIComponent(
  JSON.stringify({
    id: deviceId,
    meshcentralAgentId: 'node//abc123',
    hostname: 'DESKTOP-01',
    organization: 'Acme Corp',
  })
)}`;

// Modern usage (no query param needed):
const url = `/devices/${deviceId}/remote-desktop`;
// Device data is fetched internally via useDeviceDetails
```

> **Note:** The page auto-reconnects on tunnel drop and shows toast notifications for connection state changes. Clipboard sync requires the page to be served over HTTPS due to `navigator.clipboard` permissions.
