A reusable modal component for confirming delete operations, supporting both single and bulk item deletion with keyboard shortcut support.

## Key Components

**`DeleteConfirmationModal`** — Named export wrapping `ConfirmDialog` with delete-specific copy and behavior.

**Props (`DeleteConfirmationModalProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls modal visibility |
| `itemCount` | `number` | Drives singular/plural title and description |
| `submitting` | `boolean` | Disables `Enter` shortcut and shows pending state |
| `onConfirm` | `() => void` | Called on confirm or `Enter` keypress |
| `onClose` | `() => void` | Called when dialog is dismissed |

**`useEffect` — Keyboard Handler:** Registers a `keydown` listener when the modal is open, triggering `onConfirm` on `Enter` (unless `submitting` is `true`). Cleans up on close.

## Usage Example

```typescript
import { DeleteConfirmationModal } from './delete-confirmation-modal';

function MyList() {
  const [isDeleting, setIsDeleting] = useState(false);
  const [showModal, setShowModal] = useState(false);
  const selectedIds = ['id-1', 'id-2'];

  const handleDelete = async () => {
    setIsDeleting(true);
    await deleteItems(selectedIds);
    setIsDeleting(false);
    setShowModal(false);
  };

  return (
    <DeleteConfirmationModal
      isOpen={showModal}
      itemCount={selectedIds.length}
      submitting={isDeleting}
      onConfirm={handleDelete}
      onClose={() => setShowModal(false)}
    />
  );
}
```

> **Note:** The `Enter` key shortcut is automatically disabled while `submitting` is `true` to prevent duplicate submissions.
