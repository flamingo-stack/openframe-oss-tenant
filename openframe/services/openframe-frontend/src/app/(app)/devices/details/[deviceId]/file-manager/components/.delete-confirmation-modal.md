A reusable modal component for confirming deletion of one or more items, wrapping `ConfirmDialog` with delete-specific messaging and `Enter` key support.

## Key Components

- **`DeleteConfirmationModal`** — Main exported component that renders a destructive confirmation dialog
- **`DeleteConfirmationModalProps`** — Interface defining the component's props:
  - `isOpen` — Controls modal visibility
  - `itemCount` — Number of items to delete (drives singular/plural messaging)
  - `submitting` — Optional loading state during deletion (default: `false`)
  - `onConfirm` — Callback fired on confirmation
  - `onClose` — Callback fired on dismissal
- **`useEffect` keyboard handler** — Binds `Enter` key to trigger `onConfirm` while the modal is open and not already submitting

## Usage Example

```typescript
import { DeleteConfirmationModal } from './delete-confirmation-modal';

function MyList() {
  const [isDeleting, setIsDeleting] = useState(false);
  const [showModal, setShowModal] = useState(false);
  const selectedIds = [1, 2, 3];

  const handleDelete = async () => {
    setIsDeleting(true);
    await deleteItems(selectedIds);
    setIsDeleting(false);
    setShowModal(false);
  };

  return (
    <>
      <button onClick={() => setShowModal(true)}>Delete Selected</button>
      <DeleteConfirmationModal
        isOpen={showModal}
        itemCount={selectedIds.length}
        submitting={isDeleting}
        onConfirm={handleDelete}
        onClose={() => setShowModal(false)}
      />
    </>
  );
}
```

> **Note:** The `Enter` key shortcut is disabled while `submitting` is `true` to prevent duplicate submissions.
