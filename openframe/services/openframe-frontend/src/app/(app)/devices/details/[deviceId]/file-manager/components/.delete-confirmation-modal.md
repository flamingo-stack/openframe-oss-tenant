A reusable modal component for confirming destructive delete actions, supporting both single and bulk item deletion with keyboard shortcut support.

## Key Components

### `DeleteConfirmationModal`
A client-side React component wrapping `ConfirmDialog` with delete-specific messaging and behavior.

**Props (`DeleteConfirmationModalProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls modal visibility |
| `itemCount` | `number` | Number of items to delete (adjusts copy) |
| `submitting` | `boolean?` | Disables confirm during async operation |
| `onConfirm` | `() => void` | Callback fired on confirmation |
| `onClose` | `() => void` | Callback fired on dismissal |

**Behaviors:**
- Dynamically generates singular/plural title and description based on `itemCount`
- Registers a `keydown` listener on `window` to trigger `onConfirm` via **Enter** key when the modal is open and not submitting
- Passes `variant="destructive"` and pending state to `ConfirmDialog` for appropriate styling

## Usage Example

```typescript
import { DeleteConfirmationModal } from './delete-confirmation-modal';

function ItemList() {
  const [isDeleting, setIsDeleting] = useState(false);
  const [showModal, setShowModal] = useState(false);
  const selectedIds = ['id-1', 'id-2'];

  const handleConfirmDelete = async () => {
    setIsDeleting(true);
    await deleteItems(selectedIds);
    setIsDeleting(false);
    setShowModal(false);
  };

  return (
    <DeleteConfirmationModal
      isOpen={showModal}
      itemCount={selectedIds.length}
      submitting={isDeleting}
      onConfirm={handleConfirmDelete}
      onClose={() => setShowModal(false)}
    />
  );
}
```
