A modal dialog component for renaming items, featuring a controlled text input with keyboard support (Enter to submit) and loading state management.

## Key Components

### `RenameItemModal`
The sole export — a controlled modal wrapping `SimpleModal` with rename-specific UX.

**Props (`RenameItemModalProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls modal visibility |
| `value` | `string` | Current input value (controlled) |
| `submitting` | `boolean` | Disables controls and shows loading state |
| `onChange` | `(value: string) => void` | Input change handler |
| `onSubmit` | `() => void` | Triggered on button click or Enter key |
| `onClose` | `() => void` | Closes the modal |

**Behaviors:**
- Listens for `Enter` keydown globally when open — submits if not already submitting and value is non-empty
- Submit button disabled when `value` is blank or `submitting` is true
- Input auto-focuses on open

## Usage Example

```typescript
const [isOpen, setIsOpen] = useState(false);
const [name, setName] = useState('');
const [submitting, setSubmitting] = useState(false);

const handleSubmit = async () => {
  setSubmitting(true);
  await renameItem(name);
  setSubmitting(false);
  setIsOpen(false);
};

<RenameItemModal
  isOpen={isOpen}
  value={name}
  submitting={submitting}
  onChange={setName}
  onSubmit={handleSubmit}
  onClose={() => setIsOpen(false)}
/>
```
