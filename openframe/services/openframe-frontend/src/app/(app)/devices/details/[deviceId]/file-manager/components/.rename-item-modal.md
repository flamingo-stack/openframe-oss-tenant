Modal component for renaming items, built on `SimpleModal`. Supports keyboard submission via **Enter** and disables controls while a rename operation is in progress.

## Key Components

### `RenameItemModal`
A controlled modal component that renders a text input and Cancel/Rename action buttons.

**Props (`RenameItemModalProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls modal visibility |
| `value` | `string` | Current input value (controlled) |
| `submitting` | `boolean` | Disables input and buttons during async submission |
| `onChange` | `(value: string) => void` | Called on input change |
| `onSubmit` | `() => void` | Called on Rename click or Enter keypress |
| `onClose` | `() => void` | Called on Cancel click or modal dismiss |

### `useEffect` — Keyboard Handler
Attaches a `keydown` listener when the modal is open. Triggers `onSubmit` on **Enter** if the input is non-empty and not currently submitting. Cleans up the listener on close or dependency change.

## Usage Example

```typescript
import { RenameItemModal } from './rename-item-modal';

function MyComponent() {
  const [isOpen, setIsOpen] = useState(false);
  const [name, setName] = useState('');
  const [submitting, setSubmitting] = useState(false);

  const handleSubmit = async () => {
    setSubmitting(true);
    await renameItem(name);
    setSubmitting(false);
    setIsOpen(false);
  };

  return (
    <RenameItemModal
      isOpen={isOpen}
      value={name}
      submitting={submitting}
      onChange={setName}
      onSubmit={handleSubmit}
      onClose={() => setIsOpen(false)}
    />
  );
}
```
