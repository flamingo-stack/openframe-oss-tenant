A React modal component for configuring remote desktop session settings, including display quality, scaling, frame rate, and input device preferences via MeshCentral.

## Key Components

### `RemoteSettingsModal`

The primary exported component that renders a `SimpleModal` with controls for:

- **Quality** — Select display quality level from predefined `QUALITY_OPTIONS`
- **Scaling** — Select display scaling percentage from `SCALING_OPTIONS`
- **Frame Rate** — Select update frequency from `FRAME_RATE_OPTIONS`
- **Invert Scroll Direction** — Checkbox to reverse mouse wheel behavior
- **Swap Mouse Buttons** — Checkbox to swap left/right mouse button functions
- **Use Remote Keyboard Map** — Checkbox to apply the remote device's keyboard layout

### Props (`RemoteSettingsModalProps`)

| Prop | Type | Description |
|------|------|-------------|
| `open` | `boolean` | Controls modal visibility |
| `onOpenChange` | `(open: boolean) => void` | Modal open/close handler |
| `currentSettings` | `RemoteSettingsConfig` | Current active settings |
| `desktopRef` | `MutableRefObject<MeshDesktop \| null>` | Ref to the MeshCentral desktop instance |
| `tunnelRef` | `MutableRefObject<MeshTunnel \| null>` | Ref to the MeshCentral tunnel instance |
| `connectionState` | `number` | Must equal `3` (connected) to save |
| `onSettingsChange` | `(settings: RemoteSettingsConfig) => void` | Optional callback after successful save |

## Usage Example

```typescript
import { RemoteSettingsModal } from '@/app/components/remote-settings-modal';

<RemoteSettingsModal
  open={isSettingsOpen}
  onOpenChange={setIsSettingsOpen}
  currentSettings={remoteSettings}
  desktopRef={desktopRef}
  tunnelRef={tunnelRef}
  connectionState={connectionState}
  onSettingsChange={(updated) => setRemoteSettings(updated)}
/>
```

> **Note:** Settings can only be saved when `connectionState === 3` (active connection). Attempting to save otherwise displays a destructive toast notification. On cancel, local state is reset to `currentSettings`.
