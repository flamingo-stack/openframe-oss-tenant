A modal dialog component for configuring remote desktop session settings, including display quality, frame rate, scaling, and input device preferences.

## Key Components

**`RemoteSettingsModal`** — Main exported component that renders a `SimpleModal` with controls for:
- **Quality** — Select dropdown using `QUALITY_OPTIONS`
- **Scaling** — Select dropdown using `SCALING_OPTIONS`
- **Frame Rate** — Select dropdown using `FRAME_RATE_OPTIONS`
- **Invert Scroll Direction** — Checkbox toggle
- **Swap Mouse Buttons** — Checkbox toggle
- **Use Remote Keyboard Map** — Checkbox toggle

**`RemoteSettingsModalProps`** — Interface defining required props:

| Prop | Type | Description |
|------|------|-------------|
| `open` | `boolean` | Controls modal visibility |
| `onOpenChange` | `(open: boolean) => void` | Visibility state callback |
| `currentSettings` | `RemoteSettingsConfig` | Active settings object |
| `desktopRef` | `MutableRefObject<MeshDesktop \| null>` | Reference to the desktop instance |
| `tunnelRef` | `MutableRefObject<MeshTunnel \| null>` | Reference to the tunnel instance |
| `connectionState` | `number` | Must be `3` (connected) to apply settings |
| `onSettingsChange` | `(settings: RemoteSettingsConfig) => void` | Optional callback on save |

**`handleSaveSettings`** — Validates an active connection (`connectionState === 3`), applies settings via `RemoteDesktopSettings`, updates the desktop ref directly for mouse/keyboard options, and shows a bandwidth estimate toast.

**`handleClose`** — Resets local state to `currentSettings` before closing, discarding unsaved changes.

## Usage Example

```typescript
import { RemoteSettingsModal } from './remote-settings-modal';

const desktopRef = useRef<MeshDesktop | null>(null);
const tunnelRef = useRef<MeshTunnel | null>(null);
const [settingsOpen, setSettingsOpen] = useState(false);
const [config, setConfig] = useState<RemoteSettingsConfig>(defaultSettings);

<RemoteSettingsModal
  open={settingsOpen}
  onOpenChange={setSettingsOpen}
  currentSettings={config}
  desktopRef={desktopRef}
  tunnelRef={tunnelRef}
  connectionState={connectionState}
  onSettingsChange={setConfig}
/>
```

> **Note:** Settings can only be saved when `connectionState === 3`. Attempting to save while disconnected shows a destructive toast and aborts the operation.
