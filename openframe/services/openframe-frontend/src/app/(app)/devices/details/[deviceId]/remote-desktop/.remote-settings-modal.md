Modal component for configuring remote desktop session settings, including quality, scaling, frame rate, and input device preferences. Integrates with MeshCentral's desktop and tunnel refs to apply settings live to an active connection.

## Key Components

- **`RemoteSettingsModal`** — Main exported component that renders a `SimpleModal` with form controls for adjusting remote session behavior
- **`RemoteSettingsModalProps`** — Interface defining required props: modal open state, current settings config, refs to `MeshDesktop`/`MeshTunnel` instances, connection state, and an optional change callback
- **`handleSaveSettings`** — Validates connection state (`=== 3`), instantiates `RemoteDesktopSettings`, applies settings via tunnel WebSocket, and patches the desktop ref for input options
- **`handleClose`** — Resets local state to `currentSettings` before closing, discarding unsaved changes

## Settings Controlled

| Setting | Type | Control |
|---|---|---|
| Quality | `number` | `Select` (QUALITY_OPTIONS) |
| Scaling | `number` | `Select` (SCALING_OPTIONS) |
| Frame Rate | `string` | `Select` (FRAME_RATE_OPTIONS) |
| Invert Scroll | `boolean` | `Checkbox` |
| Swap Mouse Buttons | `boolean` | `Checkbox` |
| Use Remote Keyboard Map | `boolean` | `Checkbox` |

## Usage Example

```typescript
<RemoteSettingsModal
  open={settingsOpen}
  onOpenChange={setSettingsOpen}
  currentSettings={remoteConfig}
  desktopRef={desktopRef}
  tunnelRef={tunnelRef}
  connectionState={connectionState}
  onSettingsChange={(updated) => setRemoteConfig(updated)}
/>
```

> Settings are applied immediately to the live session on save. If `connectionState !== 3`, a destructive toast is shown and no changes are applied. Closing without saving resets all fields to `currentSettings`.
