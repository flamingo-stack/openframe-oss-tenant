Renders the schedule assign-devices page by extracting the dynamic `id` route parameter and passing it to the `ScheduleAssignDevicesView` component.

## Key Components

- **`ScheduleAssignDevicesPage`** – Default page component that reads the `[id]` segment from the URL and delegates rendering to the view layer.
- **`dynamic = 'force-dynamic'`** – Disables static generation, ensuring the page is always server-rendered at request time.

## Usage Example

```typescript
// Accessed via: /schedules/[id]/assign-devices
// e.g. /schedules/abc-123/assign-devices

// The page extracts `id` from the route params and renders:
<ScheduleAssignDevicesView scheduleId="abc-123" />
```
