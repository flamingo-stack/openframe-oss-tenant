Client-side Next.js page that renders the device assignment view for a specific maintenance schedule, extracting the schedule ID from the route parameters.

## Key Components

- **`ScheduleAssignDevicesPage`** — Default page component that reads the `id` route param and passes it to the assignment view
- **`ScheduleAssignDevicesView`** — Imported view component responsible for rendering the device assignment UI
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time

## Usage Example

```typescript
// Accessed via route: /schedules/[id]/assign-devices
// Example: /schedules/abc-123/assign-devices

// The page resolves the dynamic segment and delegates rendering:
<ScheduleAssignDevicesView scheduleId="abc-123" />
```

## Notes

- Uses `useParams` from `next/navigation` for client-side param extraction
- Guards against non-string param values, falling back to an empty string if `id` is undefined or an array
