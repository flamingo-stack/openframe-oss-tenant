Renders the schedule assign-devices page by extracting the dynamic `id` route parameter and delegating rendering to `ScheduleAssignDevicesView`.

## Key Components

- **`ScheduleAssignDevicesPage`** – Default page component that reads the `[id]` route segment and passes it as `scheduleId` to the view component.
- **`dynamic = 'force-dynamic'`** – Disables static generation, ensuring the page is always server-rendered at request time.

## Usage Example

```typescript
// Rendered automatically by Next.js for routes matching:
// /schedule/[id]/assign-devices

// The page extracts `id` from the URL and renders:
<ScheduleAssignDevicesView scheduleId="abc-123" />
```
