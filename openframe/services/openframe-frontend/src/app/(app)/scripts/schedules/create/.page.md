A Next.js page component that renders the schedule creation interface.

## Key Components

- **`CreateSchedulePage`** – Default page export that renders the `ScheduleCreateView` component
- **`dynamic`** – Export flag set to `'force-dynamic'` to disable static generation and ensure the page is always server-rendered at request time

## Usage Example

```typescript
// Accessed via routing, e.g. /schedule/create
// No props required — layout and logic are handled inside ScheduleCreateView
<CreateSchedulePage />
```
