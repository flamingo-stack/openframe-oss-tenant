A Next.js page component that renders the schedule creation interface.

## Key Components

- **`CreateSchedulePage`** — Default page export that mounts the `ScheduleCreateView` component
- **`dynamic`** — Export set to `'force-dynamic'` to disable static generation and ensure fresh server-side rendering on every request

## Usage Example

```typescript
// Accessed via route: /schedule/create (or equivalent app router path)
// No props required — self-contained via ScheduleCreateView
import CreateSchedulePage from './page';

// Renders as:
<CreateSchedulePage />
```
