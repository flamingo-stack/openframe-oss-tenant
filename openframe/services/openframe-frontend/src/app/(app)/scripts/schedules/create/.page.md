A Next.js client-side page component that renders the schedule creation interface.

## Key Components

- **`CreateSchedulePage`** — Default page export that mounts the `ScheduleCreateView` component
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time

## Usage Example

```typescript
// Accessible at the /schedule/create route (or equivalent nested route)
// No props required — all logic is encapsulated in ScheduleCreateView

import CreateSchedulePage from './page';

// Used automatically by Next.js App Router
<CreateSchedulePage />
```
