Client-side Next.js page component for editing an existing schedule, extracting the schedule ID from the URL parameters and passing it to the shared `ScheduleCreateView` component.

## Key Components

- **`EditSchedulePage`** — Default export page component that reads the `id` route param and renders the schedule editor
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time
- **`ScheduleCreateView`** — Shared component used for both creating and editing schedules, driven by the presence of `scheduleId`

## Usage Example

```typescript
// Route: /schedules/[id]/edit
// e.g. /schedules/abc-123/edit

// The page automatically extracts the ID from params:
const params = useParams<{ id?: string }>();
const id = typeof params?.id === 'string' ? params.id : '';

// Passes it to the shared view — empty string signals "create mode"
<ScheduleCreateView scheduleId={id} />
```

## Behavior Notes

- If `params.id` is not a string (e.g. array or undefined), `id` safely falls back to `''`
- The `ScheduleCreateView` component handles both create and edit modes based on whether `scheduleId` is populated
