Renders the schedule edit page by extracting the schedule `id` from the URL parameters and passing it to the `ScheduleCreateView` component for editing an existing schedule.

## Key Components

- **`EditSchedulePage`** — Default page component that reads the dynamic route param `id` and delegates rendering to `ScheduleCreateView`
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time

## Usage Example

```typescript
// Accessed via route: /schedule/[id]/edit
// e.g. /schedule/abc123/edit

// The component resolves params and renders:
<ScheduleCreateView scheduleId="abc123" />
```
