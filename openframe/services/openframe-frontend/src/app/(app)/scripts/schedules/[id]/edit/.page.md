Renders the edit schedule page by extracting the `id` route parameter and passing it to the `ScheduleCreateView` component for editing an existing schedule.

## Key Components

- **`EditSchedulePage`** — Default page component that reads the dynamic `[id]` route segment and delegates rendering to `ScheduleCreateView`
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time

## Usage Example

```typescript
// Accessed via route: /schedule/[id]/edit
// e.g., /schedule/abc-123/edit

// The component resolves the `id` param and renders:
<ScheduleCreateView scheduleId="abc-123" />

// If no valid string id is found, falls back to empty string:
<ScheduleCreateView scheduleId="" />
```
