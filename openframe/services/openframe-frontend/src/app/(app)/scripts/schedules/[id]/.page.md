A Next.js dynamic route page component that renders the detail view for a specific schedule entry.

## Key Components

- **`ScheduleDetailPage`** — Default export page component that extracts the `id` route parameter and delegates rendering to `ScheduleDetailView`
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time
- **`useParams`** — Next.js hook used to safely extract the `id` segment from the URL

## Usage Example

```typescript
// Accessed via route: /schedule/[id]
// e.g., /schedule/abc-123

// The page extracts `id` from URL params and passes it down:
<ScheduleDetailView scheduleId="abc-123" />
```

The `id` falls back to an empty string if the param is missing or not a plain string, preventing type errors in the child component.
