Renders the schedule detail page by extracting the `id` route parameter and passing it to the `ScheduleDetailView` component.

## Key Components

- **`ScheduleDetailPage`** – Default export; Next.js dynamic route page component that reads the `id` param and delegates rendering to `ScheduleDetailView`
- **`dynamic = 'force-dynamic'`** – Disables static generation, ensuring the page is always server-rendered at request time

## Usage Example

```typescript
// Accessed via route: /schedules/[id]
// e.g. /schedules/abc-123 → renders <ScheduleDetailView scheduleId="abc-123" />

export default function ScheduleDetailPage() {
  const params = useParams<{ id?: string }>();
  const id = typeof params?.id === 'string' ? params.id : '';

  return <ScheduleDetailView scheduleId={id} />;
}
```

> The `id` param is narrowed with a type guard to ensure a plain string (never an array) is passed to `ScheduleDetailView`.
