A Next.js dynamic route page component that renders the schedule detail view for a specific schedule by ID.

## Key Components

- **`ScheduleDetailPage`** — Default export; client-side page component that extracts the `id` route parameter and passes it to the detail view
- **`ScheduleDetailView`** — Imported component responsible for rendering the full schedule detail UI
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time

## Usage Example

```typescript
// Accessed via route: /schedule/[id]
// e.g. /schedule/abc-123

// params.id is extracted safely with a string type guard
const id = typeof params?.id === 'string' ? params.id : '';

return <ScheduleDetailView scheduleId={id} />;
```

> The `id` parameter falls back to an empty string if the route param is missing or not a plain string, preventing type errors downstream in `ScheduleDetailView`.
