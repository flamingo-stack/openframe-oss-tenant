React Query mutation hooks for managing script schedule CRUD operations and agent assignments via the Tactical RMM API, with automatic cache invalidation on success.

## Key Components

### API Functions (internal)
| Function | Description |
|---|---|
| `createScriptScheduleApi` | POST a new script schedule |
| `updateScriptScheduleApi` | PATCH an existing schedule by ID |
| `deleteScriptScheduleApi` | DELETE a schedule by ID |
| `replaceScheduleAgentsApi` | Replace the full agent list on a schedule |
| `addScheduleAgentsApi` | Append agents to a schedule |
| `removeScheduleAgentsApi` | Remove specific agents from a schedule |

### Exported Hooks
| Hook | Invalidates |
|---|---|
| `useCreateScriptSchedule` | `all` |
| `useUpdateScriptSchedule` | `detail(id)`, `all` |
| `useDeleteScriptSchedule` | `all` |
| `useReplaceScheduleAgents` | `agents(id)`, `detail(id)`, `all` |
| `useAddScheduleAgents` | `agents(id)`, `detail(id)` |
| `useRemoveScheduleAgents` | `agents(id)`, `detail(id)` |

## Usage Example

```typescript
import {
  useCreateScriptSchedule,
  useUpdateScriptSchedule,
  useDeleteScriptSchedule,
  useAddScheduleAgents,
} from './use-script-schedule-mutations';

function ScheduleManager() {
  const createSchedule = useCreateScriptSchedule();
  const updateSchedule = useUpdateScriptSchedule();
  const deleteSchedule = useDeleteScriptSchedule();
  const addAgents = useAddScheduleAgents();

  // Create
  createSchedule.mutate({ name: 'Nightly Patch', scriptId: 42, cron: '0 2 * * *' });

  // Update
  updateSchedule.mutate({ id: '123', payload: { name: 'Updated Name' } });

  // Delete
  deleteSchedule.mutate('123');

  // Add agents to schedule
  addAgents.mutate({ id: '123', agents: ['agent-1', 'agent-2'] });
}
```

> All hooks throw descriptive errors on non-OK API responses, including the HTTP status code, making error handling straightforward via `mutation.error`.
