React Query mutation hooks for managing script schedule CRUD operations and agent assignments via the Tactical RMM API, with automatic cache invalidation on success.

## Key Components

### Mutation Hooks

| Hook | Description | Cache Invalidation |
|------|-------------|-------------------|
| `useCreateScriptSchedule` | Creates a new script schedule | All schedules |
| `useUpdateScriptSchedule` | Updates an existing schedule by ID | Schedule detail + all schedules |
| `useDeleteScriptSchedule` | Deletes a schedule by ID | All schedules |
| `useReplaceScheduleAgents` | Replaces the full agent list on a schedule | Agents + detail + all schedules |
| `useAddScheduleAgents` | Appends agents to a schedule | Agents + detail |
| `useRemoveScheduleAgents` | Removes specific agents from a schedule | Agents + detail |

### Internal API Functions
Private async helpers (`createScriptScheduleApi`, `updateScriptScheduleApi`, etc.) wrap `tacticalApiClient` calls and normalize errors with descriptive messages.

## Usage Example

```typescript
import {
  useCreateScriptSchedule,
  useUpdateScriptSchedule,
  useDeleteScriptSchedule,
  useAddScheduleAgents,
} from './use-script-schedule-mutations';

function ScheduleManager() {
  const createSchedule = useCreateScriptSchedule();
  const updateSchedule = useUpdateScriptSchedule();
  const deleteSchedule = useDeleteScriptSchedule();
  const addAgents = useAddScheduleAgents();

  // Create a new schedule
  createSchedule.mutate({ scriptId: 'script-1', cron: '0 * * * *' });

  // Update an existing schedule
  updateSchedule.mutate({ id: 'sched-42', payload: { cron: '0 9 * * 1' } });

  // Delete a schedule
  deleteSchedule.mutate('sched-42');

  // Add agents to a schedule
  addAgents.mutate({ id: 'sched-42', agents: ['agent-1', 'agent-2'] });
}
```

> All hooks use `scriptScheduleQueryKeys` from `use-script-schedule` to ensure consistent cache key targeting across query invalidations.
