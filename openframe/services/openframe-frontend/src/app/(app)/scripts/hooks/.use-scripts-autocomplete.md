Provides server-side script autocomplete functionality with debounced search, lazy query activation, and edit-mode pre-selection support for the TacticalRMM scripts API.

## Key Components

- **`fetchScriptsV2(search, platforms)`** — Fetches paginated scripts from `/v2/scripts/` with optional search and platform filters (page size: 25)
- **`fetchScriptById(id)`** — Fetches a single script by ID for pre-populating edit-mode selections
- **`useScriptsAutocomplete(supportedPlatforms, selectedScriptId?)`** — Main hook managing autocomplete state, deduplication, and lifecycle events

## Loading Strategy

- **Lazy activation** — Search query only fires while the dropdown is active (`isActive`), preventing redundant requests on mount
- **Refresh on open** — Query refetches on every focus (`staleTime: 0` default)
- **Reset on close** — Input is cleared on blur so re-opening always shows unfiltered results
- **Edit-mode hydration** — When `selectedScriptId` is provided, that script is fetched immediately on mount and prepended to the list (with `staleTime: Infinity`)

## Usage Example

```typescript
function ScriptSelector({ platforms, existingScriptId }: Props) {
  const {
    scripts,
    isLoading,
    inputValue,
    onInputChange,
    onOpen,
    onClose,
    onClear,
  } = useScriptsAutocomplete(platforms, existingScriptId);

  return (
    <Autocomplete
      options={scripts}
      loading={isLoading}
      inputValue={inputValue}
      onInputChange={(_, value) => onInputChange(value)}
      onOpen={onOpen}
      onClose={onClose}
      onClear={onClear}
      getOptionLabel={(s) => s.name}
    />
  );
}
```

## Return Values

| Property | Type | Description |
|---|---|---|
| `scripts` | `ScriptEntry[]` | Deduplicated, ordered options list |
| `isLoading` | `boolean` | True while a search request is in-flight |
| `inputValue` | `string` | Controlled input value |
| `onInputChange` | `(v: string) => void` | Updates input and triggers debounced search |
| `onOpen` | `() => void` | Activates the lazy query |
| `onClose` | `() => void` | Deactivates query and resets input |
| `onClear` | `() => void` | Immediately clears input, bypassing debounce |
