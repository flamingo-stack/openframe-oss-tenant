Provides server-side script autocomplete with debounced search, lazy query activation, and edit-mode pre-selection for the TacticalRMM scripts API.

## Key Components

**`useScriptsAutocomplete(supportedPlatforms, selectedScriptId?)`**
Main exported hook managing autocomplete state and data fetching.

**`fetchScriptsV2(search, platforms)`**
Fetches paginated scripts (25 per page) from `/v2/scripts/` with optional search and platform filters.

**`fetchScriptById(id)`**
Fetches a single script by ID, used to pre-populate the selected value in edit mode.

## Loading Strategy

- **Lazy activation** — search query only fires when the dropdown is open (`isActive`), avoiding redundant network requests when multiple cards are mounted simultaneously.
- **Refresh on open** — `staleTime` defaults to `0`, so re-focusing always refetches an up-to-date list.
- **Reset on close** — input is cleared on blur so the next open starts with an unfiltered list.
- **Edit-mode pre-selection** — when `selectedScriptId` is provided, that script is fetched immediately on mount (`staleTime: Infinity`) and prepended to the options list when no search is active.
- **Deduplication** — the merged options list uses a `Set<number>` to prevent the pre-selected item from appearing twice when it also appears in search results.

## Usage Example

```typescript
const {
  scripts,
  isLoading,
  inputValue,
  onInputChange,
  onOpen,
  onClose,
  onClear,
} = useScriptsAutocomplete(['windows', 'linux'], existingScriptId);

// Bind to your autocomplete/combobox component
<Combobox
  options={scripts}
  loading={isLoading}
  inputValue={inputValue}
  onInputChange={onInputChange}
  onOpen={onOpen}
  onClose={onClose}
  onClear={onClear}
/>
```
