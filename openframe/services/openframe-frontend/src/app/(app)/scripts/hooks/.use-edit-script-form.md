Manages the form state, validation, and API mutations for creating and editing scripts in the OpenFrame scripts module.

## Key Components

### `useEditScriptForm(options)`

Main hook accepting `UseEditScriptFormOptions`:

| Option | Type | Description |
|--------|------|-------------|
| `scriptId` | `string \| null` | ID of the script being edited |
| `scriptDetails` | `ScriptDetails \| null` | Existing script data to pre-populate the form |
| `isEditMode` | `boolean` | Toggles between create and update flows |

**Returns:**

| Property | Type | Description |
|----------|------|-------------|
| `form` | `UseFormReturn` | React Hook Form instance with Zod validation |
| `isSubmitting` | `boolean` | `true` while either mutation is pending |
| `handleSave` | `() => void` | Triggers form validation and submission |

### Internal API Functions

- **`createScriptApi`** — POSTs a new script via `tacticalApiClient.createScript`
- **`updateScriptApi`** — PATCHes an existing script via `tacticalApiClient.updateScript`

## Usage Example

```typescript
const { form, isSubmitting, handleSave } = useEditScriptForm({
  scriptId: 'script-123',
  scriptDetails: fetchedScript,
  isEditMode: true,
});

// Bind to a save button
<Button onClick={handleSave} disabled={isSubmitting}>
  {isSubmitting ? 'Saving...' : 'Save Script'}
</Button>
```

## Behavior Notes

- On **mount/edit mode**, the form is reset with mapped `scriptDetails` — args are parsed from `"key value"` strings and env vars from `"KEY=VALUE"` strings
- On **create success**, navigates to `/scripts/details/{newId}` and invalidates the scripts list query
- On **update success**, navigates back (or falls back to `/scripts/details/{scriptId}`) and invalidates both the list and detail queries
- Empty `args` and `env_vars` entries (blank `key`) are filtered out before submission
