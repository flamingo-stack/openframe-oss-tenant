Manages the React Hook Form state and submission logic for creating and editing scripts, handling both create and update mutations with validation, query cache invalidation, and toast notifications.

## Key Components

- **`useEditScriptForm`** — Primary hook accepting `scriptId`, `scriptDetails`, and `isEditMode`, returning `form`, `isSubmitting`, and `handleSave`
- **`createScriptApi`** — Calls `tacticalApiClient.createScript` and throws on non-OK responses
- **`updateScriptApi`** — Calls `tacticalApiClient.updateScript` with script ID and throws on non-OK responses
- **`ScriptPayload`** — Internal type describing the API request body shape
- **Form population** — `useEffect` pre-populates form fields when `isEditMode` is true, parsing `args` (space-delimited key/value) and `env_vars` (`KEY=VALUE`) into structured objects
- **Submission** — `onSubmit` serializes structured args/env_vars back to string format, then dispatches to the appropriate mutation based on `isEditMode`

## Usage Example

```typescript
const { form, isSubmitting, handleSave } = useEditScriptForm({
  scriptId: '42',
  scriptDetails: fetchedScript,   // null when creating
  isEditMode: true,               // false triggers createMutation
});

// Bind to a save button
<Button onClick={handleSave} disabled={isSubmitting}>
  {isSubmitting ? 'Saving...' : 'Save Script'}
</Button>

// Access form controls directly
const { control, formState: { errors } } = form;
```

> On success, create navigates to `/scripts/details/:id` and update uses `safeBackOrReplace` to return to the detail page. Both paths invalidate the scripts query cache.
