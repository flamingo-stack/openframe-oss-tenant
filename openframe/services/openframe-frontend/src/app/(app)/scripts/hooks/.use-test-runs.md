Manages the lifecycle of script test runs against a target device, including execution, real-time elapsed-time tracking, abort control, and output parsing.

## Key Components

### `useTestRuns(getFormValues)`

A React hook that accepts a `getFormValues` callback returning the current `EditScriptFormData` and exposes:

| Return Value | Type | Description |
|---|---|---|
| `testRun` | `TestRunData \| null` | Current test run state (output, status, elapsed time) |
| `handleRunTest` | `(device: SelectedTestDevice) => Promise<void>` | Initiates a test run against a device, aborting any in-progress run first |
| `handleStopRun` | `() => void` | Aborts the active run and appends an abort message to output |
| `clearTestRun` | `() => void` | Resets `testRun` state to `null` |

**Internal mechanisms:**
- `AbortController` — cancels the in-flight API request on stop or new run
- `setInterval` timer — increments `elapsedSeconds` each second while status is `running`
- Cleanup `useEffect` — aborts requests and clears timers on unmount

**Response parsing** handles `string`, `Array`, and `object` payloads (extracting `retcode`, `stdout`, `stderr`).

## Usage Example

```typescript
import { useTestRuns } from './use-test-runs';
import { useFormContext } from 'react-hook-form';

function ScriptTestPanel() {
  const { getValues } = useFormContext<EditScriptFormData>();
  const { testRun, handleRunTest, handleStopRun, clearTestRun } =
    useTestRuns(getValues);

  const device: SelectedTestDevice = {
    deviceName: 'workstation-01',
    agentToolId: 42,
  };

  return (
    <>
      <button onClick={() => handleRunTest(device)}>Run Test</button>
      {testRun?.status === 'running' && (
        <button onClick={handleStopRun}>Stop</button>
      )}
      {testRun && (
        <pre>{testRun.output.join('\n')}</pre>
      )}
    </>
  );
}
```
