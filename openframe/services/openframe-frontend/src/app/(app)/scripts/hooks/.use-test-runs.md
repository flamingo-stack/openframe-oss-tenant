Manages the lifecycle of script test runs against remote devices, including execution, elapsed-time tracking, abort control, and output parsing.

## Key Components

- **`useTestRuns(getFormValues)`** — Primary hook accepting a form-values getter and returning test run state and control handlers
- **`testRun`** — Current `TestRunData` state (`null` when idle), holding status, output lines, and elapsed time
- **`handleRunTest(device)`** — Fires a POST to `/scripts/:agentToolId/test/` with current form values, manages an `AbortController`, starts the elapsed timer, and normalises API response output (string, array, or object with `stdout`/`stderr`/`retcode`)
- **`handleStopRun()`** — Aborts the in-flight request and marks the run as `'aborted'`
- **`clearTestRun()`** — Resets state back to `null`
- **`startTimer` / `stopTimer`** — Internal helpers driving a 1-second interval that updates `elapsedSeconds` while status is `'running'`

## Usage Example

```typescript
const { testRun, handleRunTest, handleStopRun, clearTestRun } = useTestRuns(
  () => form.getValues()
);

// Start a test run against a selected device
await handleRunTest({ deviceName: 'DESKTOP-01', agentToolId: 42 });

// Abort mid-run
handleStopRun();

// Reset UI
clearTestRun();
```

## Notes

- A module-level `runIdCounter` prevents stale-state collisions when a new run starts before the previous one settles
- Abort signals are propagated directly to `tacticalApiClient.post` so in-flight HTTP requests are cancelled cleanly
- All timers and abort controllers are cleaned up on unmount via the `useEffect` teardown
