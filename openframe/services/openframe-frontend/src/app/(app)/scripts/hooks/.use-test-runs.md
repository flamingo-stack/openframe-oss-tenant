Manages the lifecycle of script test runs against remote devices, including execution, real-time elapsed-time tracking, abort control, and output parsing.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `useTestRuns` | Hook | Primary hook; accepts a `getFormValues` callback and returns test run state and control handlers |
| `testRun` | `TestRunData \| null` | Current test run state (status, output lines, elapsed time) |
| `handleRunTest` | `(device: SelectedTestDevice) => Promise<void>` | Initiates a new script test run against the given device, aborting any in-progress run first |
| `handleStopRun` | `() => void` | Aborts the active run and marks it as `aborted` |
| `clearTestRun` | `() => void` | Resets `testRun` state to `null` |

## Internals

- **`AbortController`** — cancels in-flight `tacticalApiClient` requests when a new run starts or the user stops execution.
- **`setInterval` timer** — updates `elapsedSeconds` every second while status is `running`; stopped and cleaned up on abort, completion, or unmount.
- **Output normalization** — handles string, array, and object (with `stdout`/`stderr`/`retcode`) response shapes from the tactical API.
- **`runIdCounter`** — module-level counter that produces stable, unique IDs per run to prevent stale-closure state updates.

## Usage Example

```typescript
import { useTestRuns } from './use-test-runs';
import { useForm } from 'react-hook-form';

function ScriptEditor() {
  const { getValues } = useForm<EditScriptFormData>();

  const { testRun, handleRunTest, handleStopRun, clearTestRun } =
    useTestRuns(getValues);

  return (
    <>
      <button onClick={() => handleRunTest({ deviceName: 'win-agent-01', agentToolId: 42 })}>
        Run Test
      </button>
      {testRun?.status === 'running' && (
        <button onClick={handleStopRun}>Stop ({testRun.elapsedSeconds}s)</button>
      )}
      {testRun && <pre>{testRun.output.join('\n')}</pre>}
      <button onClick={clearTestRun}>Clear</button>
    </>
  );
}
```
