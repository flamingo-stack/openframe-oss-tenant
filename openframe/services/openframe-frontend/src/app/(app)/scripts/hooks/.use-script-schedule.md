React Query hooks for fetching script schedule data from the Tactical RMM API, providing list, detail, agents, and execution history views.

## Key Components

**Query Keys**
- `scriptScheduleQueryKeys` — Structured cache key factory for all script schedule queries (`list`, `detail`, `agents`, `history`)

**Hooks**
- `useScriptSchedules()` — Fetches all script schedules as a flat list
- `useScriptSchedule(id)` — Fetches a single schedule's full detail; disabled when `id` is falsy
- `useScriptScheduleAgents(id)` — Fetches agents associated with a given schedule
- `useScriptScheduleHistory(id, options)` — Fetches paginated execution history for a schedule; defaults to `limit: 50, offset: 0`

## Usage Example

```typescript
import {
  useScriptSchedules,
  useScriptSchedule,
  useScriptScheduleAgents,
  useScriptScheduleHistory,
} from './use-script-schedule';

// List all schedules
function ScheduleList() {
  const { schedules, isLoading, error } = useScriptSchedules();
  if (isLoading) return <Spinner />;
  return schedules.map(s => <div key={s.id}>{s.name}</div>);
}

// Detail + agents + paginated history for one schedule
function ScheduleDetail({ id }: { id: string }) {
  const { schedule } = useScriptSchedule(id);
  const { agents } = useScriptScheduleAgents(id);
  const { history, total } = useScriptScheduleHistory(id, { limit: 25, offset: 0 });

  return (
    <>
      <h2>{schedule?.name}</h2>
      <p>Agents: {agents.length} — Runs: {total}</p>
    </>
  );
}
```

Each hook returns a stable empty array/null fallback (`EMPTY_SCHEDULES`, `EMPTY_AGENTS`, `EMPTY_HISTORY`) to prevent unnecessary re-renders when data is absent.
