React Query hooks for fetching and managing script schedule data from the Tactical RMM API, including list, detail, assigned agents, and execution history.

## Key Components

### Query Keys

| Key Factory | Description |
|---|---|
| `scriptScheduleQueryKeys.list()` | All schedules list |
| `scriptScheduleQueryKeys.detail(id)` | Single schedule detail |
| `scriptScheduleQueryKeys.agents(id)` | Agents assigned to a schedule |
| `scriptScheduleQueryKeys.history(id, limit, offset)` | Paginated execution history |

### Hooks

| Hook | Returns |
|---|---|
| `useScriptSchedules()` | `schedules`, `isLoading`, `error`, `refetch` |
| `useScriptSchedule(id)` | `schedule`, `isLoading`, `error`, `refetch` |
| `useScriptScheduleAgents(id)` | `agents`, `isLoading`, `error`, `refetch` |
| `useScriptScheduleHistory(id, options)` | `history`, `total`, `isLoading`, `error`, `refetch` |

## Usage Example

```typescript
// Fetch all schedules
const { schedules, isLoading, error } = useScriptSchedules();

// Fetch a single schedule by ID
const { schedule } = useScriptSchedule('schedule-123');

// Fetch agents assigned to a schedule
const { agents } = useScriptScheduleAgents('schedule-123');

// Fetch paginated execution history
const { history, total } = useScriptScheduleHistory('schedule-123', {
  limit: 25,
  offset: 0,
});
```

> All hooks are disabled when `id` is an empty string, preventing unnecessary API calls. History defaults to `limit: 50, offset: 0` if no options are provided.
