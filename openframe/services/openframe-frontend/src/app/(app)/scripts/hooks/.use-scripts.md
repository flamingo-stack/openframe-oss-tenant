React Query hook for fetching and managing the full list of scripts from the Tactical RMM API.

## Key Components

- **`scriptsQueryKeys`** — Centralized query key registry (`['scripts']`) for cache coordination across consumers
- **`fetchAllScripts()`** — Internal async function that calls `tacticalApiClient.getScripts()` and normalizes the response, throwing on error
- **`useScripts()`** — Primary exported hook that wraps `useQuery` and exposes a clean, stable API surface

## Usage Example

```typescript
import { useScripts } from '@/features/scripts/hooks/use-scripts';

function ScriptList() {
  const { scripts, isLoading, error, refetch, invalidate } = useScripts();

  if (isLoading) return <Spinner />;
  if (error) return <ErrorBanner message={error} />;

  return (
    <>
      <button onClick={() => invalidate()}>Refresh</button>
      {scripts.map(script => (
        <ScriptRow key={script.id} script={script} />
      ))}
    </>
  );
}
```

## Return Shape

| Field | Type | Description |
|-------|------|-------------|
| `scripts` | `ScriptEntry[]` | Fetched scripts array, defaults to stable `[]` |
| `isLoading` | `boolean` | `true` while any fetch (including background refetch) is in-flight |
| `error` | `string \| null` | Error message string or `null` |
| `refetch` | `function` | Manually trigger a fresh fetch |
| `invalidate` | `function` | Invalidates the query cache, triggering a background refetch for all subscribers |

> **Note:** `EMPTY_SCRIPTS` is a module-level constant to prevent unnecessary re-renders caused by a new `[]` reference on each render cycle.
