React Query hook for fetching and managing the full list of automation scripts from the Tactical RMM API.

## Key Components

- **`scriptsQueryKeys`** — Centralized query key registry (`['scripts']`) for cache management and invalidation
- **`fetchAllScripts`** — Async function that calls `tacticalApiClient.getScripts()` and returns a typed `ScriptEntry[]` array; throws on non-OK responses
- **`useScripts`** — Primary hook exposing scripts data, loading/error states, and cache control utilities

## Usage Example

```typescript
import { useScripts } from '@/features/scripts/hooks/use-scripts';

function ScriptList() {
  const { scripts, isLoading, error, refetch, invalidate } = useScripts();

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;

  return (
    <>
      <button onClick={() => invalidate()}>Refresh</button>
      {scripts.map(script => (
        <ScriptRow key={script.id} script={script} />
      ))}
    </>
  );
}
```

## Return Shape

| Field | Type | Description |
|-------|------|-------------|
| `scripts` | `ScriptEntry[]` | Fetched scripts; stable empty array as fallback |
| `isLoading` | `boolean` | `true` while any fetch is in-flight |
| `error` | `string \| null` | Error message string or `null` |
| `refetch` | `function` | Manually re-triggers the query |
| `invalidate` | `function` | Marks the cache stale and triggers background refetch |
