React Query hook for fetching and managing the full list of scripts from the Tactical RMM API.

## Key Components

- **`scriptsQueryKeys`** — Centralized query key registry (`['scripts']`) for cache consistency and invalidation
- **`fetchAllScripts()`** — Async function that calls `tacticalApiClient.getScripts()` and throws on error responses
- **`useScripts()`** — Primary hook exposing scripts data, loading/error state, and cache control methods

## Usage Example

```typescript
import { useScripts } from '@/features/scripts/hooks/use-scripts';

function ScriptsList() {
  const { scripts, isLoading, error, refetch, invalidate } = useScripts();

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;

  return (
    <>
      <button onClick={() => invalidate()}>Refresh</button>
      {scripts.map(script => (
        <ScriptRow key={script.id} script={script} />
      ))}
    </>
  );
}
```

## Returned Values

| Property | Type | Description |
|---|---|---|
| `scripts` | `ScriptEntry[]` | Fetched scripts, defaults to stable `[]` reference |
| `isLoading` | `boolean` | `true` while any fetch is in-flight |
| `error` | `string \| null` | Error message string or `null` |
| `refetch` | `function` | Manually re-triggers the query |
| `invalidate` | `function` | Marks cache stale and triggers background refetch |

> **Note:** `EMPTY_SCRIPTS` is defined as a module-level constant to ensure a stable array reference across renders, preventing unnecessary re-renders from `[] !== []` reference changes.
