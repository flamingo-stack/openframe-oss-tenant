React Query hook for fetching and managing scheduled tasks filtered by script ID, with support for deletion and cache invalidation.

## Key Components

**Types**
- `ScheduledTaskAction` — defines a script-based task action with timeout, args, and env vars
- `ScheduledTask` — full task entity including schedule type (`daily` | `weekly` | `monthly` | `runonce`), recurrence config, and associated actions

**Query Keys**
- `scheduledTasksQueryKeys.all` — root key for all scheduled tasks
- `scheduledTasksQueryKeys.byScript(scriptId)` — scoped key for tasks filtered by script

**Hook: `useScheduledTasks(scriptId)`**
- Fetches all scheduled tasks and filters client-side to those referencing the given script ID
- Exposes a `deleteTask` mutation with optional `onSuccess`/`onError` callbacks
- Invalidates both `byScript` and `scriptScheduleQueryKeys.all` caches on successful deletion

## Usage Example

```typescript
import { useScheduledTasks } from './use-scheduled-tasks';

function ScriptTaskList({ scriptId }: { scriptId: string }) {
  const {
    scheduledTasks,
    isLoading,
    error,
    deleteTask,
    isDeleting,
  } = useScheduledTasks(scriptId);

  if (isLoading) return <p>Loading...</p>;
  if (error) return <p>Error: {error}</p>;

  return (
    <ul>
      {scheduledTasks.map(task => (
        <li key={task.id}>
          {task.name}
          <button
            onClick={() =>
              deleteTask(String(task.id), {
                onSuccess: () => console.log('Deleted'),
                onError: (err) => console.error(err.message),
              })
            }
            disabled={isDeleting}
          >
            Delete
          </button>
        </li>
      ))}
    </ul>
  );
}
```

> **Note:** Filtering is done client-side after fetching all tasks. For large task sets, consider a server-side filter endpoint to reduce payload size.
