React Query hook for fetching and managing scheduled tasks filtered by script ID, with support for deletion and cache invalidation.

## Key Components

### Types

- **`ScheduledTaskAction`** — Describes a script-based action within a task (script ID, timeout, args, env vars)
- **`ScheduledTask`** — Full scheduled task shape including recurrence config (`daily`, `weekly`, `monthly`, `runonce`), actions, and agent assignment

### Query Keys

- **`scheduledTasksQueryKeys`** — Structured cache key factory; `byScript(scriptId)` scopes queries to a specific script

### API Functions

- **`fetchScheduledTasksByScript(scriptId)`** — Fetches all tasks, then filters to those containing at least one action referencing the given script ID
- **`deleteScheduledTaskApi(taskId)`** — Deletes a task by ID via the tactical API client

### Hook

- **`useScheduledTasks(scriptId)`** — Primary export; returns tasks filtered by script, loading/error state, a `deleteTask` handler with optional callbacks, and the raw query object

## Usage Example

```typescript
const {
  scheduledTasks,
  isLoading,
  error,
  deleteTask,
  isDeleting,
} = useScheduledTasks('42');

// Delete a task with success/error callbacks
deleteTask('99', {
  onSuccess: () => console.log('Task deleted'),
  onError: (err) => console.error(err.message),
});
```

On successful deletion, both the `byScript` query and `scriptScheduleQueryKeys.all` are invalidated to keep related caches in sync.
