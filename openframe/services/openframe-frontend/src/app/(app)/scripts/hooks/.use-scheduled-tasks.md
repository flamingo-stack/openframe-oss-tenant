React Query hook for fetching and managing scheduled tasks filtered by script ID, with support for deleting tasks and cache invalidation.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `ScheduledTask` | Full task object including recurrence config, actions, and agent assignment |
| `ScheduledTaskAction` | Action payload for a task — currently supports `'script'` type with args, env vars, and timeout |

### Query Keys

```typescript
scheduledTasksQueryKeys.all              // ['scheduled-tasks']
scheduledTasksQueryKeys.byScript(id)     // ['scheduled-tasks', 'by-script', scriptId]
```

### `useScheduledTasks(scriptId: string)`

Main hook — fetches all scheduled tasks and filters to those referencing the given script ID.

| Return | Type | Description |
|--------|------|-------------|
| `scheduledTasks` | `ScheduledTask[]` | Tasks filtered by script reference |
| `isLoading` | `boolean` | Fetch in-flight indicator |
| `error` | `string \| null` | Error message if fetch failed |
| `refetch` | `function` | Manual refetch trigger |
| `deleteTask` | `function` | Delete a task by ID with optional callbacks |
| `isDeleting` | `boolean` | Delete mutation in-flight indicator |
| `scheduledTasksQuery` | `UseQueryResult` | Raw query for advanced use |

## Usage Example

```typescript
const {
  scheduledTasks,
  isLoading,
  error,
  deleteTask,
  isDeleting,
} = useScheduledTasks('42');

// Delete a task with callbacks
deleteTask(taskId, {
  onSuccess: () => toast.success('Task deleted'),
  onError: (err) => toast.error(err.message),
});
```

On successful delete, both `scheduledTasksQueryKeys.byScript` and `scriptScheduleQueryKeys.all` caches are invalidated automatically.
