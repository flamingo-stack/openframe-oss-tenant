Provides device list filtering by search term and organization, combining local filter state with fetched organization data.

## Key Components

**`useDeviceFilter(options)`** — Custom React hook accepting:
- `devices` — full list of `Device` objects to filter
- `enabled` — optional flag (default `true`) to conditionally skip fetching organizations (e.g. when a modal is closed)

**Returns:**

| Property | Type | Description |
|---|---|---|
| `searchTerm` | `string` | Current text search value |
| `setSearchTerm` | `setter` | Updates the search term |
| `selectedOrgIds` | `string[]` | Active organization filter IDs |
| `setSelectedOrgIds` | `setter` | Updates selected org IDs |
| `organizationOptions` | `{label, value}[]` | Org list mapped for select inputs |
| `filteredDevices` | `Device[]` | Devices matching all active filters |

**Filtering logic:**
- Text search matches against `displayName`, `hostname`, `osType`, and `operating_system` (case-insensitive)
- Org filter restricts results to devices whose `organizationId` is in `selectedOrgIds`
- Both filters apply simultaneously

## Usage Example

```typescript
const {
  searchTerm,
  setSearchTerm,
  selectedOrgIds,
  setSelectedOrgIds,
  organizationOptions,
  filteredDevices,
} = useDeviceFilter({ devices: allDevices, enabled: isModalOpen });

// Bind to a search input
<input value={searchTerm} onChange={e => setSearchTerm(e.target.value)} />

// Bind to a multi-select for organizations
<MultiSelect
  options={organizationOptions}
  value={selectedOrgIds}
  onChange={setSelectedOrgIds}
/>

// Render filtered results
filteredDevices.map(device => <DeviceRow key={device.id} device={device} />);
```
