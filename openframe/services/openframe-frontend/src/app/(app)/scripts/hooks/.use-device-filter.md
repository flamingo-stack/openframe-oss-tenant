Provides client-side filtering logic for a device list, supporting search by name/OS and filtering by organization.

## Key Components

**`useDeviceFilter(options)`** — Custom React hook that accepts a `Device[]` array and an optional `enabled` flag, returning all state and derived data needed to drive a device filter UI.

| Return Value | Type | Description |
|---|---|---|
| `searchTerm` | `string` | Current text search input value |
| `setSearchTerm` | `setter` | Updates the search query |
| `selectedOrgIds` | `string[]` | Active organization filter IDs |
| `setSelectedOrgIds` | `setter` | Updates selected org filters |
| `organizationOptions` | `{ label, value }[]` | Org picker options from `useCustomersMin` |
| `filteredDevices` | `Device[]` | Memoized devices after all filters applied |

**Filtering logic:**
- **Search** — matches against `displayName`, `hostname`, `osType`, or `operating_system` (case-insensitive)
- **Org filter** — restricts results to devices whose `organizationId` is in `selectedOrgIds`
- Organizations are fetched lazily via `useCustomersMin`, skipped when `enabled = false` (e.g. modal is closed)

## Usage Example

```typescript
function DeviceListPanel({ devices }: { devices: Device[] }) {
  const [isOpen, setIsOpen] = useState(false);

  const {
    searchTerm,
    setSearchTerm,
    selectedOrgIds,
    setSelectedOrgIds,
    organizationOptions,
    filteredDevices,
  } = useDeviceFilter({ devices, enabled: isOpen });

  return (
    <>
      <input value={searchTerm} onChange={e => setSearchTerm(e.target.value)} />
      <OrgMultiSelect
        options={organizationOptions}
        value={selectedOrgIds}
        onChange={setSelectedOrgIds}
      />
      <DeviceTable devices={filteredDevices} />
    </>
  );
}
```
