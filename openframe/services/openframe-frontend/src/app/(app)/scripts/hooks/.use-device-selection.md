Manages multi-select state for a list of devices, tracking selected device IDs in a `Set` and exposing helpers to toggle, bulk-select, and clear selections.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `useDeviceSelection` | Hook | Returns selection state and control callbacks |
| `selectedIds` | `Set<string>` | Set of currently selected device primary IDs |
| `selectedCount` | `number` | Reactive count of selected devices |
| `toggleSelect` | `(id: string) => void` | Adds or removes a single device ID from the selection |
| `selectAllDisplayed` | `(devices: Device[]) => void` | Replaces the selection with all IDs from the provided device list |
| `clearSelection` | `() => void` | Resets the selection to an empty set |

## Usage Example

```typescript
import { useDeviceSelection } from './hooks/use-device-selection';

function DeviceTable({ devices }: { devices: Device[] }) {
  const {
    selectedIds,
    selectedCount,
    toggleSelect,
    selectAllDisplayed,
    clearSelection,
  } = useDeviceSelection();

  return (
    <>
      <button onClick={() => selectAllDisplayed(devices)}>
        Select All ({devices.length})
      </button>
      <button onClick={clearSelection} disabled={selectedCount === 0}>
        Clear ({selectedCount})
      </button>
      {devices.map(device => {
        const id = getDevicePrimaryId(device);
        return (
          <DeviceRow
            key={id}
            device={device}
            selected={selectedIds.has(id)}
            onToggle={() => toggleSelect(id)}
          />
        );
      })}
    </>
  );
}
```

> **Note:** `selectAllDisplayed` is intended to reflect the currently visible/filtered device list, not the full dataset — pass only the devices rendered in the current view.
