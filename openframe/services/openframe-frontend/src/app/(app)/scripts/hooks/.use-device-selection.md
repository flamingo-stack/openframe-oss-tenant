Manages multi-select state for a list of devices, providing toggle, select-all, and clear operations backed by a `Set` of string IDs.

## Key Components

- **`useDeviceSelection`** — Custom React hook that encapsulates device selection logic
- **`selectedIds`** — `Set<string>` of currently selected device IDs
- **`selectedCount`** — Reactive count of selected devices (`selectedIds.size`)
- **`toggleSelect(id)`** — Adds or removes a single device ID from the selection
- **`selectAllDisplayed(devices)`** — Replaces the selection with all IDs from the provided `Device[]` array, resolved via `getDevicePrimaryId`
- **`clearSelection()`** — Resets the selection to an empty set

## Usage Example

```typescript
import { useDeviceSelection } from './use-device-selection';

function DeviceTable({ devices }: { devices: Device[] }) {
  const {
    selectedIds,
    selectedCount,
    toggleSelect,
    selectAllDisplayed,
    clearSelection,
  } = useDeviceSelection();

  return (
    <>
      <button onClick={() => selectAllDisplayed(devices)}>
        Select All ({devices.length})
      </button>
      <button onClick={clearSelection} disabled={selectedCount === 0}>
        Clear ({selectedCount})
      </button>
      {devices.map(device => {
        const id = getDevicePrimaryId(device);
        return (
          <input
            key={id}
            type="checkbox"
            checked={selectedIds.has(id)}
            onChange={() => toggleSelect(id)}
          />
        );
      })}
    </>
  );
}
```

> All state mutations use immutable `Set` copies, ensuring React detects changes and re-renders correctly. Callbacks are memoized with `useCallback` to prevent unnecessary child re-renders.
