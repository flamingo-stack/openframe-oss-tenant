Manages multi-select state for a list of devices, providing toggle, select-all, and clear operations backed by a `Set` of device IDs.

## Key Components

- **`useDeviceSelection`** — Custom React hook that returns device selection state and action callbacks
- **`selectedIds`** — `Set<string>` of currently selected device primary IDs
- **`selectedCount`** — Derived count of selected devices (`selectedIds.size`)
- **`toggleSelect(id)`** — Adds or removes a single device ID from the selection
- **`selectAllDisplayed(devices)`** — Replaces the selection with all IDs from a given `Device[]` array, using `getDevicePrimaryId` to resolve each device's primary key
- **`clearSelection()`** — Resets the selection to an empty set

## Usage Example

```typescript
import { useDeviceSelection } from './use-device-selection';

function DeviceTable({ devices }: { devices: Device[] }) {
  const {
    selectedIds,
    selectedCount,
    toggleSelect,
    selectAllDisplayed,
    clearSelection,
  } = useDeviceSelection();

  return (
    <>
      <button onClick={() => selectAllDisplayed(devices)}>
        Select All ({devices.length})
      </button>
      <button onClick={clearSelection} disabled={selectedCount === 0}>
        Clear ({selectedCount})
      </button>
      {devices.map(device => {
        const id = getDevicePrimaryId(device);
        return (
          <DeviceRow
            key={id}
            device={device}
            selected={selectedIds.has(id)}
            onToggle={() => toggleSelect(id)}
          />
        );
      })}
    </>
  );
}
```

> All action callbacks are memoized with `useCallback`, making them safe to pass as props without triggering unnecessary re-renders.
