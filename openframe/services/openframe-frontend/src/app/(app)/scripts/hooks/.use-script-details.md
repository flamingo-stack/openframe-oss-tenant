Provides a React Query hook for fetching detailed information about a specific script from the Tactical RMM API.

## Key Components

**`ScriptDetails`** — Interface describing the full script object, including metadata (`id`, `name`, `category`), execution config (`shell`, `args`, `default_timeout`, `run_as_user`), and platform support (`supported_platforms`, `env_vars`).

**`scriptDetailsQueryKeys`** — Structured query key factory for cache management:
- `all` — base key for all script detail queries
- `detail(scriptId)` — scoped key for a specific script

**`useScriptDetails(scriptId)`** — Primary hook that fetches and caches script details. Skips the query if `scriptId` is empty.

## Usage Example

```typescript
import { useScriptDetails } from '@/hooks/use-script-details';

function ScriptViewer({ scriptId }: { scriptId: string }) {
  const { scriptDetails, isLoading, error, refetch } = useScriptDetails(scriptId);

  if (isLoading) return <Spinner />;
  if (error) return <p>Error: {error}</p>;
  if (!scriptDetails) return null;

  return (
    <div>
      <h2>{scriptDetails.name}</h2>
      <p>{scriptDetails.description}</p>
      <pre>{scriptDetails.script_body}</pre>
      <span>Timeout: {scriptDetails.default_timeout}s</span>
    </div>
  );
}
```

## Return Values

| Property | Type | Description |
|---|---|---|
| `scriptDetails` | `ScriptDetails \| null` | Fetched script data or `null` |
| `isLoading` | `boolean` | `true` while fetching |
| `error` | `string \| null` | Error message if the request failed |
| `refetch` | `function` | Manually re-trigger the query |
