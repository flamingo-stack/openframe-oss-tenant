Provides a React Query hook for fetching detailed information about a specific script from the Tactical RMM API.

## Key Components

- **`ScriptDetails`** — Interface defining the full schema of a script, including metadata (`id`, `name`, `shell`, `category`), execution config (`args`, `default_timeout`, `run_as_user`), and platform support fields.
- **`scriptDetailsQueryKeys`** — Query key factory with `all` (base key) and `detail(scriptId)` for targeted cache management.
- **`fetchScriptDetails`** — Internal async function that calls `tacticalApiClient.getScript()` and throws on failure.
- **`useScriptDetails`** — Primary exported hook that wraps React Query, enabling the query only when a valid `scriptId` is provided.

## Usage Example

```typescript
import { useScriptDetails } from './use-script-details';

function ScriptEditor({ scriptId }: { scriptId: string }) {
  const { scriptDetails, isLoading, error, refetch } = useScriptDetails(scriptId);

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;

  return (
    <pre>{scriptDetails?.script_body}</pre>
  );
}
```

## Notes

- The query is **disabled** when `scriptId` is an empty string, preventing unnecessary API calls.
- `isLoading` maps to `isFetching`, so it reflects both initial loads and background refetches.
- Returns `null` for `scriptDetails` and `error` instead of `undefined` for safer downstream consumption.
