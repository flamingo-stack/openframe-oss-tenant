Fetches and caches detailed metadata for a single script using TanStack Query, wrapping the Tactical RMM API client.

## Key Components

**`ScriptDetails`** — Interface describing the full shape of a script object, including body, hash, platform support, shell type, and execution options.

**`scriptDetailsQueryKeys`** — Structured query key factory for cache management:
- `all` — base key `['script-details']`
- `detail(scriptId)` — scoped key `['script-details', scriptId]`

**`useScriptDetails(scriptId)`** — Primary hook that fetches script details for a given ID. Skips the query when `scriptId` is falsy.

| Return Value | Type | Description |
|---|---|---|
| `scriptDetails` | `ScriptDetails \| null` | Fetched script data |
| `isLoading` | `boolean` | True while fetching |
| `error` | `string \| null` | Error message if fetch failed |
| `refetch` | `function` | Manually re-trigger the query |

## Usage Example

```typescript
import { useScriptDetails } from '@/hooks/use-script-details';

function ScriptDetailPanel({ scriptId }: { scriptId: string }) {
  const { scriptDetails, isLoading, error } = useScriptDetails(scriptId);

  if (isLoading) return <Spinner />;
  if (error) return <ErrorBanner message={error} />;

  return (
    <div>
      <h2>{scriptDetails?.name}</h2>
      <p>{scriptDetails?.description}</p>
      <pre>{scriptDetails?.script_body}</pre>
    </div>
  );
}
```
