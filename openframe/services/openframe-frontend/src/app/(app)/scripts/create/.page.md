A thin client-side page component that renders the script creation flow by wrapping `EditScriptPage` with a `null` `scriptId`, signaling a new (unsaved) script.

## Key Components

- **`CreateScriptPageWrapper`** — Default export; a `'use client'` Next.js page component that delegates rendering to `EditScriptPage` with `scriptId={null}` to indicate "create new" mode.

## Usage Example

```typescript
// Automatically rendered by Next.js when navigating to the /scripts/create route.
// No manual instantiation needed.

// Internally delegates to:
<EditScriptPage scriptId={null} />
```

> `EditScriptPage` uses `scriptId === null` to distinguish between **create** and **edit** modes — passing `null` here ensures the form starts blank with no pre-loaded script data.
