A thin Next.js route page component that renders the script creation flow by delegating to the shared `EditScriptPage` component with no existing script ID.

## Key Components

- **`CreateScriptPageWrapper`** — Default page export that mounts `EditScriptPage` in "create new" mode by passing `scriptId={null}`.

## Usage Example

```typescript
// Automatically rendered by Next.js at the /scripts/create route.
// No manual instantiation needed — the router handles this.

// To reuse the same pattern for editing an existing script:
<EditScriptPage scriptId="some-existing-id" />

// This page passes null to signal "create new":
<EditScriptPage scriptId={null} />
```

> The `'use client'` directive ensures this page renders on the client side, enabling interactive editing features within `EditScriptPage`.
