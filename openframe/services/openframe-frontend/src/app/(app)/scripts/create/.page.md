A thin Next.js page wrapper that renders the script creation flow by mounting the `EditScriptPage` component with no existing script ID.

## Key Components

- **`CreateScriptPageWrapper`** — Default page export that renders `EditScriptPage` in "create new" mode by passing `scriptId={null}`.

## Usage Example

```typescript
// Rendered automatically by Next.js when navigating to the create-script route.
// No props required — scriptId is hardcoded to null to signal a new script.
<CreateScriptPageWrapper />
```

> Passing `scriptId={null}` tells `EditScriptPage` to initialize an empty form rather than load an existing script for editing.
