Client-side page component that extracts a script `id` from the URL parameters and renders the script execution view.

## Key Components

- **`RunScriptPage`** — Default export; a Next.js client component that reads the `[id]` dynamic route segment and delegates rendering to `RunScriptView`.

## Usage Example

```typescript
// Accessed via route: /scripts/[id]/run
// e.g. /scripts/abc123/run → renders <RunScriptView scriptId="abc123" />
```

```typescript
// Internal wiring
const params = useParams<{ id?: string }>();
const id = typeof params?.id === 'string' ? params.id : '';
return <RunScriptView scriptId={id} />;
```

## Notes

- Marked `'use client'` — runs exclusively in the browser context.
- Guards against non-string `id` values (e.g. `undefined`, arrays) by falling back to an empty string `''`.
- All script execution UI logic lives in `RunScriptView`; this page is purely a routing adapter.
