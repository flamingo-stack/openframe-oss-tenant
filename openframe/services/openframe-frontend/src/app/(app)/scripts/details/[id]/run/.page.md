Client-side page component that extracts a script `id` from the URL params and renders the script execution view.

## Key Components

- **`RunScriptPage`** — Default export; a Next.js client page component that reads the dynamic `[id]` route segment and delegates rendering to `RunScriptView`.

## Usage Example

```typescript
// Accessed via route: /scripts/[id]/run
// e.g. /scripts/abc123/run → renders <RunScriptView scriptId="abc123" />
```

```typescript
// Internal wiring (handled automatically by Next.js routing)
const params = useParams<{ id?: string }>();
const id = typeof params?.id === 'string' ? params.id : '';
return <RunScriptView scriptId={id} />;
```

## Notes

- Uses `'use client'` directive — required because `useParams` is a client-side hook.
- Safely falls back to an empty string if `id` is missing or not a plain string, preventing runtime errors in `RunScriptView`.
