Client-side Next.js page component that extracts a script `id` from the URL parameters and renders the script execution view.

## Key Components

- **`RunScriptPage`** — Default export; reads the dynamic `[id]` route segment and passes it to the execution UI.
- **`RunScriptView`** — Imported component that handles the full script-running interface, receiving `scriptId` as a prop.

## Usage Example

```typescript
// Accessed via route: /scripts/[id]/run
// e.g. /scripts/abc123/run → scriptId = "abc123"

<RunScriptPage />
// Renders: <RunScriptView scriptId="abc123" />
```

## Notes

- Uses `'use client'` directive — required because `useParams` is a client-side hook.
- Safely handles missing/non-string `id` by defaulting to an empty string `''`.
