Next.js client-side page component that renders the details view for a single script, extracting the `id` route parameter and passing it to the display component.

## Key Components

- **`ScriptDetailsPage`** — Default export; reads the dynamic `[id]` route segment and delegates rendering to `ScriptDetailsView`

## Usage Example

```typescript
// Accessed via route: /scripts/[id]
// e.g. /scripts/abc-123

// The page automatically extracts the ID from the URL:
const params = useParams<{ id?: string }>();
const id = typeof params?.id === 'string' ? params.id : '';

// And passes it down:
<ScriptDetailsView scriptId={id} />
```

## Notes

- Marked `'use client'` — runs in the browser, enabling React hooks like `useParams`
- Safely coerces the `id` param to an empty string if absent or non-string, preventing runtime errors in `ScriptDetailsView`
