Next.js client-side page component that renders the script details view for a given script ID extracted from the route parameters.

## Key Components

- **`ScriptDetailsPage`** – Default export; a client component that reads the `id` route param and passes it to the details view.
- **`useParams`** – Next.js hook used to safely extract the dynamic `id` segment from the URL.
- **`ScriptDetailsView`** – The primary UI component responsible for rendering script details, receiving `scriptId` as a prop.

## Usage Example

```typescript
// Rendered automatically by Next.js when navigating to:
// /scripts/[id]  →  e.g., /scripts/abc123

// The page extracts `id` from the route and delegates rendering:
<ScriptDetailsView scriptId="abc123" />
```

> **Note:** The `id` param is safely coerced to an empty string (`''`) if it is absent or not a plain string (e.g., when it is an array segment), preventing downstream type errors in `ScriptDetailsView`.
