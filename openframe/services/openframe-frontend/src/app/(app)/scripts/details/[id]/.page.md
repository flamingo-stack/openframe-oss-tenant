Next.js client-side page component that extracts the `id` route parameter and passes it to the script details view.

## Key Components

- **`ScriptDetailsPage`** — Default export; client component that reads the dynamic `[id]` route segment and renders the detail view.

## Usage Example

```typescript
// Accessed via route: /scripts/[id]
// e.g. /scripts/abc-123 → renders ScriptDetailsView with scriptId="abc-123"

<ScriptDetailsPage />
// Internally resolves to:
<ScriptDetailsView scriptId="abc-123" />
```

## Notes

- Marked `'use client'` — runs in the browser, enabling `useParams` from `next/navigation`.
- Guards against non-string param values by falling back to an empty string (`''`).
- Rendering logic is fully delegated to `ScriptDetailsView`; this page acts purely as a routing adapter.
