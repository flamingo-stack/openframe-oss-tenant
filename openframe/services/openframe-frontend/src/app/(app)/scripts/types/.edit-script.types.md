Defines Zod validation schemas, TypeScript types, and default values for the Edit Script form used in script management workflows.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `scriptArgumentSchema` | Zod schema | Validates individual script arguments/env vars with `id`, `key`, and `value` fields |
| `editScriptSchema` | Zod schema | Full form validation schema with rules for all script fields |
| `EditScriptFormData` | TypeScript type | Inferred type from `editScriptSchema` |
| `CATEGORIES` | `string[]` | Predefined script category options |
| `EDIT_SCRIPT_DEFAULT_VALUES` | `EditScriptFormData` | Initial form state with sensible defaults |

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';
import {
  editScriptSchema,
  EditScriptFormData,
  EDIT_SCRIPT_DEFAULT_VALUES,
  CATEGORIES,
} from './edit-script.types';

const form = useForm<EditScriptFormData>({
  resolver: zodResolver(editScriptSchema),
  defaultValues: EDIT_SCRIPT_DEFAULT_VALUES,
});

// Access validated data on submit
const onSubmit = (data: EditScriptFormData) => {
  console.log(data.name, data.shell, data.default_timeout);
};
```

## Validation Rules

- `name` — required, non-empty string
- `shell` — required, non-empty string
- `default_timeout` — number between `1` and `86400` seconds (max 24 hours), defaults to `90`
- `supported_platforms` — at least one platform required, defaults to `["windows"]`
- `category` — required, one of the predefined `CATEGORIES`
- `args` / `env_vars` — arrays of `{ id, key, value }` objects
