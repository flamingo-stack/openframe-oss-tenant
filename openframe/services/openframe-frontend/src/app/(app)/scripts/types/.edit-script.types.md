Defines Zod validation schemas, TypeScript types, and default values for the script editing form used in the Flamingo platform's script management feature.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `scriptArgumentSchema` | Zod Schema | Validates individual script arguments/env vars with `id`, `key`, and `value` fields |
| `editScriptSchema` | Zod Schema | Full form validation schema for creating/editing a script |
| `EditScriptFormData` | TypeScript Type | Inferred type from `editScriptSchema` |
| `CATEGORIES` | `string[]` | Predefined script category options |
| `EDIT_SCRIPT_DEFAULT_VALUES` | `EditScriptFormData` | Default form state for new scripts |

## Usage Example

```typescript
import { editScriptSchema, EDIT_SCRIPT_DEFAULT_VALUES, CATEGORIES } from './edit-script.types';
import { useForm } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';

const { register, handleSubmit } = useForm({
  resolver: zodResolver(editScriptSchema),
  defaultValues: EDIT_SCRIPT_DEFAULT_VALUES,
});

// Validate a script payload directly
const result = editScriptSchema.safeParse({
  name: 'Disk Cleanup',
  shell: 'powershell',
  default_timeout: 300,
  args: [{ id: '1', key: '--drive', value: 'C:' }],
  script_body: 'Get-PSDrive',
  run_as_user: false,
  env_vars: [],
  description: 'Cleans up temp files',
  supported_platforms: ['windows'],
  category: 'System Maintenance',
});
```

## Validation Rules

- `default_timeout`: Must be between **1–86400 seconds** (max 24 hours)
- `supported_platforms`: Requires **at least one** platform selection
- `name`, `shell`, `category`: All required (non-empty strings)
