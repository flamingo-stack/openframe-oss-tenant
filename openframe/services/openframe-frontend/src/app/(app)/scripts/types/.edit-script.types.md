Defines Zod validation schemas, TypeScript types, and default values for the edit script form used in script management workflows.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `scriptArgumentSchema` | Zod Schema | Validates individual script arguments/env vars with `id`, `key`, and `value` string fields |
| `editScriptSchema` | Zod Schema | Full form validation schema for creating/editing scripts with constraints on timeout, platforms, and category |
| `EditScriptFormData` | Type | Inferred TypeScript type from `editScriptSchema` |
| `CATEGORIES` | `string[]` | Predefined script category options |
| `EDIT_SCRIPT_DEFAULT_VALUES` | `EditScriptFormData` | Default form state with `windows` platform pre-selected and 90s timeout |

## Usage Example

```typescript
import { editScriptSchema, EDIT_SCRIPT_DEFAULT_VALUES, EditScriptFormData } from './edit-script.types';
import { useForm } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';

const { register, handleSubmit, formState: { errors } } = useForm<EditScriptFormData>({
  resolver: zodResolver(editScriptSchema),
  defaultValues: EDIT_SCRIPT_DEFAULT_VALUES,
});

// Validate manually
const result = editScriptSchema.safeParse({
  name: 'Disk Cleanup',
  shell: 'powershell',
  default_timeout: 300,
  args: [{ id: '1', key: '--force', value: 'true' }],
  script_body: 'Get-Disk | ...',
  run_as_user: false,
  env_vars: [],
  description: 'Cleans up disk space',
  supported_platforms: ['windows'],
  category: 'System Maintenance',
});
```

**Timeout constraints:** minimum `1` second, maximum `86400` seconds (24 hours). At least one `supported_platforms` entry is required.
