Defines all TypeScript types, Zod validation schemas, constants, and utility functions for the script scheduling feature, covering API response shapes, form data structures, and payload builders.

## Key Components

### API Response Types
| Type | Description |
|------|-------------|
| `ScriptScheduleListItem` | Summary item returned in schedule list endpoints |
| `ScriptScheduleDetail` | Full schedule object including actions, agents, and last runs |
| `ScriptScheduleHistoryEntry` | Single execution history record with status and output |
| `ScriptScheduleAgent` | Agent assigned to a schedule |
| `AgentsModifyResponse` | Response after modifying agent assignments |

### Request Payload Types
| Type | Description |
|------|-------------|
| `ScriptScheduleTaskType` | Union of `'runonce' \| 'daily' \| 'weekly' \| 'monthly' \| 'monthlydow'` |
| `CreateScriptSchedulePayload` | POST body for schedule creation |
| `UpdateScriptSchedulePayload` | PATCH body (partial `CreateScriptSchedulePayload`) |

### Form / Zod Schemas
| Export | Description |
|--------|-------------|
| `createScheduleFormSchema` | Zod schema for the create/edit form |
| `CreateScheduleFormData` | Inferred form type from schema |
| `ScheduleActionFormData` | Inferred type for a single action row |

### Constants
- `WEEKDAYS` — bit-indexed weekday array (Mon=0 … Sun=6)
- `PLATFORMS` / `PLATFORM_LABELS` — `windows`, `linux`, `darwin`
- `REPEAT_PERIOD_OPTIONS` — dropdown options for `day`, `week`, `month`

### Utility Functions
| Function | Description |
|----------|-------------|
| `toZuluDateString(date)` | Formats a `Date` to `yyyy-MM-dd'T'HH:mm:ss'Z'` using local components as UTC |
| `parseZuluToLocalDate(iso)` | Parses a Zulu string into a local `Date` preserving UTC values |
| `formatScheduleDate(iso)` | Returns `{ date, time }` strings formatted in UTC |
| `getRepeatLabel(schedule)` | Human-readable repeat label (e.g. `"3 Days"`, `"Monthly"`) |
| `buildTaskTypeFromForm(...)` | Maps `repeatEnabled` + `RepeatPeriod` → `ScriptScheduleTaskType` |
| `scheduleDetailToFormData(...)` | Converts an API `ScriptScheduleDetail` into `CreateScheduleFormData` |
| `buildCreatePayload(formData)` | Converts form data into a `CreateScriptSchedulePayload` for the API |

## Usage Example

```typescript
import {
  buildCreatePayload,
  scheduleDetailToFormData,
  formatScheduleDate,
  getRepeatLabel,
} from './script-schedule.types';

// Convert API detail → form state (for edit flow)
const formData = scheduleDetailToFormData(scheduleDetail);

// Convert form state → API payload (on submit)
const payload = buildCreatePayload(formData);

// Display helpers
const { date, time } = formatScheduleDate(scheduleDetail.run_time_date);
// date: "06/15/2025"  time: "02:30 PM"

const repeatLabel = getRepeatLabel(scheduleDetail);
// "3 Days" | "1 Week" | "Monthly" | "Once"
```

> **Date handling note:** `toZuluDateString` and `parseZuluToLocalDate` treat the user's picked time as UTC — no timezone offset is applied. This ensures the stored value and the date picker always display the same time regardless of the user's local timezone.
