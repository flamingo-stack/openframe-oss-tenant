Defines all TypeScript types, Zod validation schemas, constants, and utility functions for the script scheduling feature, covering API response shapes, form data structures, and payload builders.

## Key Components

### API Response Types
| Type | Description |
|------|-------------|
| `ScriptScheduleListItem` | Summary item for schedule list views |
| `ScriptScheduleDetail` | Full schedule detail including actions and assigned agents |
| `ScriptScheduleHistoryEntry` | Single execution history record with status and output |
| `ScriptScheduleHistoryResponse` | Paginated wrapper for history entries |
| `ScriptScheduleAgent` | Agent metadata for schedule assignment |
| `AgentsModifyResponse` | Result of agent assignment operations |

### Form & Validation
| Export | Description |
|--------|-------------|
| `createScheduleFormSchema` | Zod schema for the create/edit schedule form |
| `CreateScheduleFormData` | Inferred form type from the Zod schema |
| `ScheduleActionFormData` | Inferred type for individual script action rows |

### Constants
- `WEEKDAYS` — Bit-indexed weekday definitions (Mon=0 … Sun=6)
- `PLATFORMS` — Supported OS platforms: `windows`, `linux`, `darwin`
- `PLATFORM_LABELS` — Human-readable platform display names
- `REPEAT_PERIOD_OPTIONS` — Dropdown options for repeat frequency

### Utility Functions
| Function | Description |
|----------|-------------|
| `toZuluDateString` | Formats a `Date` as a UTC ISO string without timezone shifting |
| `parseZuluToLocalDate` | Parses a UTC ISO string into a local `Date` matching UTC values |
| `scheduleDetailToFormData` | Maps an API `ScriptScheduleDetail` to `CreateScheduleFormData` |
| `buildCreatePayload` | Converts form data into a `CreateScriptSchedulePayload` for the API |
| `buildTaskTypeFromForm` | Derives `ScriptScheduleTaskType` from repeat settings |
| `getRepeatLabel` | Returns a human-readable repeat interval string |
| `formatScheduleDate` | Splits an ISO date string into separate `date` and `time` display strings |

## Usage Example

```typescript
import {
  scheduleDetailToFormData,
  buildCreatePayload,
  formatScheduleDate,
} from './script-schedule.types';

// Convert API detail to form-ready data
const formData = scheduleDetailToFormData(scheduleDetail);

// Build API payload from submitted form
const payload = buildCreatePayload(formData);

// Display schedule run time
const { date, time } = formatScheduleDate(scheduleDetail.run_time_date);
// date → "01/15/2025", time → "02:30 PM"
```
