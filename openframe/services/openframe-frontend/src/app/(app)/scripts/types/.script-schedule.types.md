Defines all TypeScript types, Zod validation schemas, constants, and utility functions for the Script Schedule feature, covering API response shapes, form data models, and payload transformation helpers.

## Key Components

### API Response Types
| Type | Description |
|------|-------------|
| `ScriptScheduleListItem` | Summary row for schedule list views |
| `ScriptScheduleDetail` | Full schedule detail including actions and assigned agents |
| `ScriptScheduleHistoryEntry` | Single execution history record with status and output |
| `ScriptScheduleAgent` | Agent metadata (hostname, platform, timezone, org) |
| `AgentsModifyResponse` | Result counts after modifying agent assignments |

### Request Payload Types
| Type | Description |
|------|-------------|
| `ScriptScheduleTaskType` | Union: `runonce` \| `daily` \| `weekly` \| `monthly` \| `monthlydow` |
| `CreateScriptSchedulePayload` | Full create request body |
| `UpdateScriptSchedulePayload` | Partial version of create payload for PATCH requests |

### Form Constants
- `REPEAT_PERIOD_OPTIONS` — UI options for day/week/month repeat cadence
- `WEEKDAYS` — bitmask-indexed weekday definitions (Mon=0 … Sun=6)
- `PLATFORMS` / `PLATFORM_LABELS` — supported OS platforms with display names

### Zod Schemas
- `createScheduleFormSchema` — full form validation including actions array
- `ScheduleActionFormData` / `CreateScheduleFormData` — inferred form types

### Utility Functions
| Function | Purpose |
|----------|---------|
| `toZuluDateString` | Formats a `Date` as `yyyy-MM-dd'T'HH:mm:ss'Z'` without timezone shift |
| `parseZuluToLocalDate` | Converts UTC ISO string to a local `Date` matching UTC components |
| `getRepeatLabel` | Returns human-readable repeat label (e.g. `"3 Days"`, `"Monthly"`) |
| `formatScheduleDate` | Splits ISO string into `{ date, time }` display strings |
| `buildTaskTypeFromForm` | Maps `repeatEnabled` + `RepeatPeriod` → `ScriptScheduleTaskType` |
| `scheduleDetailToFormData` | Transforms API `ScriptScheduleDetail` → `CreateScheduleFormData` |
| `buildCreatePayload` | Transforms form data → `CreateScriptSchedulePayload` for API submission |

## Usage Example

```typescript
import {
  scheduleDetailToFormData,
  buildCreatePayload,
  formatScheduleDate,
  getRepeatLabel,
} from './script-schedule.types';

// Convert API response to form state
const formData = scheduleDetailToFormData(scheduleDetail);

// Submit: convert form state back to API payload
const payload = buildCreatePayload(formData);

// Display helpers
const { date, time } = formatScheduleDate(scheduleDetail.run_time_date);
// date → "06/15/2025", time → "02:30 PM"

const label = getRepeatLabel(scheduleDetail);
// → "3 Days" | "1 Week" | "Monthly" | "Once"
```
