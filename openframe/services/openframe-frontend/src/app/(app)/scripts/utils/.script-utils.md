Utility functions for mapping script platform identifiers to device filter OS types and display-friendly labels.

## Key Components

- **`AVAILABLE_PLATFORMS` / `DISABLED_PLATFORMS`** — Re-exported constants from `@/lib/platforms` defining supported and disabled platform sets.
- **`mapPlatformsToOsTypes(platforms)`** — Converts script platform strings (`windows`, `darwin`) to device filter enum values (`WINDOWS`, `MAC_OS`). Note: `linux` is intentionally excluded from this mapping as it has no corresponding OS type filter value.
- **`mapPlatformsForDisplay(platforms)`** — Converts platform identifiers to human-readable labels (`windows` → `Windows`, `darwin` → `macOS`, `linux` → `Linux`).

## Usage Example

```typescript
import { mapPlatformsToOsTypes, mapPlatformsForDisplay } from './script-utils';

const scriptPlatforms = ['windows', 'darwin', 'linux'];

// For device filtering
const osTypeFilters = mapPlatformsToOsTypes(scriptPlatforms);
// → ['WINDOWS', 'MAC_OS']  (linux is excluded — no matching OS type)

// For UI display
const displayLabels = mapPlatformsForDisplay(scriptPlatforms);
// → ['Windows', 'macOS', 'Linux']
```

> **Note:** Both functions are case-insensitive (`p.toLowerCase()`) and silently drop unrecognized platform strings via the `.filter()` step, so unknown values never propagate downstream.
