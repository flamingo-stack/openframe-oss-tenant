Utility functions for mapping script platform identifiers to OS type filter values and display labels used across the Flamingo platform.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `AVAILABLE_PLATFORMS` | Re-export | List of supported platforms from `@/lib/platforms` |
| `DISABLED_PLATFORMS` | Re-export | List of disabled platforms from `@/lib/platforms` |
| `mapPlatformsToOsTypes` | Function | Maps script platform strings to device filter OS type values |
| `mapPlatformsForDisplay` | Function | Maps script platform strings to human-readable display labels |

## Platform Mappings

| Script Value | OS Type Filter | Display Label |
|-------------|----------------|---------------|
| `windows` | `WINDOWS` | `Windows` |
| `darwin` | `MAC_OS` | `macOS` |
| `linux` | *(filtered out)* | `Linux` |

> **Note:** `linux` is intentionally excluded from `mapPlatformsToOsTypes` as it has no corresponding device filter OS type value.

## Usage Example

```typescript
import { mapPlatformsToOsTypes, mapPlatformsForDisplay } from '@/lib/script-utils';

const scriptPlatforms = ['windows', 'darwin', 'linux'];

// For device filtering
const osTypeFilters = mapPlatformsToOsTypes(scriptPlatforms);
// → ['WINDOWS', 'MAC_OS']

// For UI display
const displayLabels = mapPlatformsForDisplay(scriptPlatforms);
// → ['Windows', 'macOS', 'Linux']
```

Both functions are case-insensitive and silently drop unrecognized platform values via `.filter()`.
