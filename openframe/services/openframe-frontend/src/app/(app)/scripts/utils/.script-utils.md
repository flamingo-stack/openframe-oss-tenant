Utility module for mapping script platform identifiers to their corresponding OS type values used in device filtering and display contexts.

## Key Components

- **`AVAILABLE_PLATFORMS`** / **`DISABLED_PLATFORMS`** — Re-exported constants from `@/lib/platforms` defining supported and disabled platform sets
- **`mapPlatformsToOsTypes(platforms)`** — Maps script platform strings (`windows`, `darwin`) to device filter OS type values (`WINDOWS`, `MAC_OS`). Note: `linux` is intentionally excluded from this mapping
- **`mapPlatformsForDisplay(platforms)`** — Maps platform strings to human-readable display labels (`Windows`, `macOS`, `Linux`)

## Usage Example

```typescript
import { mapPlatformsToOsTypes, mapPlatformsForDisplay } from './script-utils';

const scriptPlatforms = ['windows', 'darwin', 'linux'];

// For device filtering
const osTypeFilters = mapPlatformsToOsTypes(scriptPlatforms);
// → ['WINDOWS', 'MAC_OS']  (linux excluded — no osType mapping)

// For UI display
const displayLabels = mapPlatformsForDisplay(scriptPlatforms);
// → ['Windows', 'macOS', 'Linux']
```

> Both functions silently drop unrecognized or unmapped platform values via `.filter(Boolean)`, so callers receive only valid mapped entries without needing extra null checks.
