Utility helpers for resolving device identity, OS normalization, and shell execution context from `Device` objects.

## Key Components

| Export | Signature | Description |
|--------|-----------|-------------|
| `getDevicePrimaryId` | `(device: Device) => string` | Returns the best available identifier: `machineId` → `agent_id` → `id` |
| `normalizeOsOrNull` | `(os?: string) => 'windows' \| 'linux' \| 'darwin' \| null` | Maps an OS string to a platform ID, returns `null` for unrecognized values |
| `resolveOsTypeFromDevices` | `(devices: Device[]) => 'windows' \| 'linux' \| 'darwin' \| 'all'` | Derives a single platform from a device set, or `'all'` if mixed |
| `resolveShellForExecution` | `(resolvedOsType: string, scriptShell?: string) => string` | Picks `powershell`, `cmd`, or `/bin/bash` based on OS and shell preference |

## Usage Example

```typescript
import {
  getDevicePrimaryId,
  normalizeOsOrNull,
  resolveOsTypeFromDevices,
  resolveShellForExecution,
} from './device-helpers';

// Resolve stable device identifier
const id = getDevicePrimaryId(device); // e.g. "abc-123"

// Normalize an arbitrary OS string
normalizeOsOrNull('Ubuntu 22.04'); // 'linux'
normalizeOsOrNull('Unknown OS');   // null

// Determine shared OS across a selection
const osType = resolveOsTypeFromDevices(selectedDevices);
// 'windows' | 'linux' | 'darwin' | 'all' (mixed)

// Pick the correct shell for script execution
const shell = resolveShellForExecution(osType, 'powershell');
// 'powershell' on Windows, '/bin/bash' on Linux/macOS
```

## Notes

- `normalizeOsOrNull` intentionally differs from `normalizeDevicePlatform` — it returns `null` instead of defaulting to `'darwin'`, making mixed-platform detection explicit.
- `resolveOsTypeFromDevices` filters out `null` OS values before comparing, so devices with unknown OS do not skew the result toward `'all'`.
