Utility helpers for resolving device identity, OS platform normalization, and shell selection across multi-device operations.

## Key Components

| Function | Description |
|---|---|
| `getDevicePrimaryId` | Returns the best available identifier for a device (`machineId` → `agent_id` → `id`) |
| `normalizeOsOrNull` | Maps an OS string to a platform ID (`windows`, `linux`, `darwin`) or `null` for unrecognized values |
| `resolveOsTypeFromDevices` | Detects whether a device set shares a single OS platform, returning `'all'` for mixed environments |
| `resolveShellForExecution` | Selects the appropriate shell (`powershell`, `cmd`, `/bin/bash`) based on resolved OS type |

## Usage Example

```typescript
import {
  getDevicePrimaryId,
  normalizeOsOrNull,
  resolveOsTypeFromDevices,
  resolveShellForExecution,
} from './device-helpers';

// Resolve the best identifier for a device
const id = getDevicePrimaryId(device); // e.g. "abc-123"

// Normalize a raw OS string
normalizeOsOrNull('Ubuntu 22.04'); // 'linux'
normalizeOsOrNull('Unknown OS');   // null

// Detect shared OS across selected devices
const osType = resolveOsTypeFromDevices(selectedDevices);
// 'windows' | 'linux' | 'darwin' | 'all'

// Pick the right shell for script execution
const shell = resolveShellForExecution(osType, 'powershell');
// 'powershell' on Windows, '/bin/bash' on Linux/macOS
```

> `normalizeOsOrNull` differs from `normalizeDevicePlatform` by returning `null` instead of defaulting to `'darwin'`, making mixed-platform detection explicit in callers like `resolveOsTypeFromDevices`.
