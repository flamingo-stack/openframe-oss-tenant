Utility helpers for resolving device identity, OS normalization, and shell selection across a set of `Device` objects.

## Key Components

| Export | Signature | Description |
|--------|-----------|-------------|
| `getDevicePrimaryId` | `(device: Device) => string` | Returns the best available identifier: `machineId` → `agent_id` → `id` |
| `normalizeOsOrNull` | `(os?: string) => 'windows' \| 'linux' \| 'darwin' \| null` | Maps an OS string to a platform ID, returning `null` for unrecognized values instead of defaulting |
| `resolveOsTypeFromDevices` | `(devices: Device[]) => 'windows' \| 'linux' \| 'darwin' \| 'all'` | Returns the single shared platform across all devices, or `'all'` when mixed |
| `resolveShellForExecution` | `(resolvedOsType: string, scriptShell?: string) => string` | Picks the appropriate shell (`powershell`, `cmd`, or `/bin/bash`) for script execution |

## Usage Example

```typescript
import {
  getDevicePrimaryId,
  normalizeOsOrNull,
  resolveOsTypeFromDevices,
  resolveShellForExecution,
} from './device-helpers';

// Resolve the best available device ID
const id = getDevicePrimaryId(device);
// → device.machineId ?? device.agent_id ?? device.id

// Safely normalize an OS string without a default fallback
const platform = normalizeOsOrNull('Ubuntu 22.04');
// → 'linux'

const unknown = normalizeOsOrNull('ChromeOS');
// → null

// Determine shared OS across a selection of devices
const osType = resolveOsTypeFromDevices(selectedDevices);
// → 'windows' | 'linux' | 'darwin' | 'all'

// Pick the correct shell for execution
const shell = resolveShellForExecution(osType, 'powershell');
// → 'powershell' (Windows) or '/bin/bash' (Linux/macOS)
```

## Notes

- `normalizeOsOrNull` differs from `normalizeDevicePlatform` in that it returns `null` rather than defaulting to `'darwin'`, making mixed-platform detection explicit.
- `resolveOsTypeFromDevices` silently drops devices with unrecognized OS values (via the `null` filter) when computing the consensus platform.
