Utility functions for converting between flat `key=value` string arrays and structured `ScriptArgument` objects used in OpenFrame script configurations.

## Key Components

- **`parseKeyValues(arr, separator)`** — Parses an array of delimited strings (e.g. `["FOO=bar", "DEBUG=true"]`) into `ScriptArgument[]` objects with `id`, `key`, and `value` fields. Defaults to `=` as the separator. If no separator is found in an item, the entire string becomes the `key` with an empty `value`.

- **`serializeKeyValues(pairs, separator)`** — Converts `ScriptArgument[]` back into flat strings, filtering out entries with blank keys. Produces `key=value` when a value exists, or just `key` when the value is empty.

## Usage Example

```typescript
import { parseKeyValues, serializeKeyValues } from './script-key-values';

// Parse raw CLI-style args into structured objects
const args = parseKeyValues(['TIMEOUT=30', 'DEBUG=true', 'FLAG']);
// [
//   { id: 'arg-0', key: 'TIMEOUT', value: '30' },
//   { id: 'arg-1', key: 'DEBUG',   value: 'true' },
//   { id: 'arg-2', key: 'FLAG',    value: '' }
// ]

// Serialize back to strings (e.g. before saving or sending to API)
const raw = serializeKeyValues(args);
// ['TIMEOUT=30', 'DEBUG=true', 'FLAG']

// Use a custom separator
const envPairs = parseKeyValues(['HOST:localhost', 'PORT:8080'], ':');
```
