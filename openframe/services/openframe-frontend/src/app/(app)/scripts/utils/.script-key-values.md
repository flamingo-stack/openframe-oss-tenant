Utility functions for converting between flat string arrays and structured `ScriptArgument` key-value pairs used in script argument handling.

## Key Components

- **`parseKeyValues(arr, separator)`** — Parses an array of strings (e.g., `["FOO=bar", "DEBUG=true"]`) into `ScriptArgument[]` objects with `id`, `key`, and `value` fields. Defaults to `=` as the separator. Items without a separator are stored with an empty `value`.
- **`serializeKeyValues(pairs, separator)`** — Converts `ScriptArgument[]` back to a flat string array. Skips entries with blank keys. Omits the separator entirely for value-less arguments.

## Usage Example

```typescript
import { parseKeyValues, serializeKeyValues } from './script-key-values';

// Parse raw strings into structured arguments
const args = parseKeyValues(['FOO=bar', 'DEBUG=true', 'STANDALONE']);
// [
//   { id: 'arg-0', key: 'FOO',        value: 'bar'  },
//   { id: 'arg-1', key: 'DEBUG',      value: 'true' },
//   { id: 'arg-2', key: 'STANDALONE', value: ''     }
// ]

// Serialize back to flat strings
const raw = serializeKeyValues(args);
// ['FOO=bar', 'DEBUG=true', 'STANDALONE']

// Custom separator
const semicolonArgs = parseKeyValues(['HOST:localhost', 'PORT:8080'], ':');
// [{ id: 'arg-0', key: 'HOST', value: 'localhost' }, ...]
```

> Values containing the separator character are handled correctly — only the **first** occurrence is used as the split point, preserving values like `URL=http://example.com?a=1`.
