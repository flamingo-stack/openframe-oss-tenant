Utility functions for converting between flat `key=value` string arrays and structured `ScriptArgument` objects used in OpenFrame script argument handling.

## Key Components

| Export | Signature | Description |
|--------|-----------|-------------|
| `parseKeyValues` | `(arr, separator?) => ScriptArgument[]` | Parses a string array of `key=value` pairs into `ScriptArgument` objects |
| `serializeKeyValues` | `(pairs, separator?) => string[]` | Serializes `ScriptArgument` objects back into `key=value` strings |

## Usage Example

```typescript
import { parseKeyValues, serializeKeyValues } from './script-key-values';

// Parse raw CLI-style arguments into structured objects
const raw = ['timeout=30', 'verbose', 'host=192.168.1.1'];
const parsed = parseKeyValues(raw);
// [
//   { id: 'arg-0', key: 'timeout', value: '30' },
//   { id: 'arg-1', key: 'verbose', value: '' },
//   { id: 'arg-2', key: 'host', value: '192.168.1.1' }
// ]

// Serialize back to string array, skipping empty keys
const serialized = serializeKeyValues(parsed);
// ['timeout=30', 'verbose', 'host=192.168.1.1']

// Custom separator support
const envPairs = parseKeyValues(['NODE_ENV:production'], ':');
// [{ id: 'arg-0', key: 'NODE_ENV', value: 'production' }]
```

## Behavior Notes

- **Missing separator:** If no `=` is found in a string, the entire string becomes the `key` with an empty `value` (useful for boolean flags).
- **Empty key filtering:** `serializeKeyValues` silently drops any pair where `key` is blank or whitespace-only.
- **Value-only pairs:** If `value` is falsy, `serializeKeyValues` emits just the key with no separator appended.
- **Custom separators:** Both functions accept an optional `separator` parameter (default `=`), allowing alternate delimiters such as `:`.
