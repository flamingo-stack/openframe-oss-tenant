Zustand store managing the state for scripts/automation library, including script entries, search filtering, loading, and error states.

## Key Components

### Interfaces
- **`ScriptEntry`** — Represents a single script with metadata: `id`, `name`, `category`, `shell`, `syntax`, `supported_platforms`, `script_type`, `args`, `env_vars`, `favorite`, `hidden`, `default_timeout`, `run_as_user`, and more
- **`ScriptsState`** — Combined state + actions interface for the Zustand store

### Store
- **`useScriptsStore`** — Zustand store created with `immer` (immutable updates) and `devtools` middleware

### Actions
| Action | Description |
|---|---|
| `setScripts(scripts)` | Replaces the scripts list and clears any error |
| `setSearch(search)` | Updates the search filter string |
| `setLoading(loading)` | Sets the loading flag |
| `setError(error)` | Sets an error message and stops loading |
| `clearScripts()` | Empties the scripts list and clears errors |
| `reset()` | Restores full initial state |

### Selectors
Memoization-friendly selectors to minimize re-renders:
- `selectLogs` — returns `scripts` array
- `selectSearch` — returns current search string
- `selectIsLoading` — returns loading boolean
- `selectError` — returns error string or null

## Usage Example

```typescript
import { useScriptsStore, selectSearch, selectIsLoading } from './scripts-store';

function ScriptList() {
  const scripts = useScriptsStore(state => state.scripts);
  const search = useScriptsStore(selectSearch);
  const isLoading = useScriptsStore(selectIsLoading);
  const { setScripts, setLoading, setError } = useScriptsStore();

  useEffect(() => {
    setLoading(true);
    fetchScripts()
      .then(setScripts)
      .catch(err => setError(err.message));
  }, []);

  const filtered = scripts.filter(s =>
    s.name.toLowerCase().includes(search.toLowerCase())
  );

  if (isLoading) return <Spinner />;
  return <ScriptTable scripts={filtered} />;
}
```

> **Note:** `selectLogs` is misnamed — it returns the `scripts` array, not logs. Consider aliasing it as `selectScripts` when consuming it.
