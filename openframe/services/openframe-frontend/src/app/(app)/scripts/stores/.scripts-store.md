Zustand store managing the state for scripts/automation entries, including loading, search, and error handling with Immer immutability and Redux DevTools support.

## Key Components

### Interfaces

- **`ScriptEntry`** — Shape of a single script record, including metadata like `args`, `category`, `shell`, `supported_platforms`, `syntax`, and `favorite` flag
- **`ScriptsState`** — Combined state + action interface for the store

### Store

- **`useScriptsStore`** — Primary Zustand hook created with `immer` (immutable updates) and `devtools` (Redux DevTools integration)

### Actions

| Action | Description |
|---|---|
| `setScripts(scripts)` | Replaces the scripts list and clears any active error |
| `setSearch(search)` | Updates the search filter string |
| `setLoading(loading)` | Toggles the loading state |
| `setError(error)` | Sets an error message and stops loading |
| `clearScripts()` | Empties the scripts list and clears errors |
| `reset()` | Restores the store to its initial state |

### Selectors

Pre-built selectors for optimized re-renders: `selectLogs`, `selectSearch`, `selectIsLoading`, `selectError`

## Usage Example

```typescript
import {
  useScriptsStore,
  selectIsLoading,
  selectSearch,
  selectError,
} from './scripts-store';

function ScriptsList() {
  const scripts = useScriptsStore(state => state.scripts);
  const isLoading = useScriptsStore(selectIsLoading);
  const search = useScriptsStore(selectSearch);
  const { setScripts, setSearch, setLoading, setError } = useScriptsStore();

  useEffect(() => {
    setLoading(true);
    fetchScripts()
      .then(setScripts)
      .catch(err => setError(err.message));
  }, []);

  const filtered = scripts.filter(s =>
    s.name.toLowerCase().includes(search.toLowerCase())
  );

  if (isLoading) return <Spinner />;

  return (
    <>
      <input value={search} onChange={e => setSearch(e.target.value)} />
      {filtered.map(script => <ScriptRow key={script.id} script={script} />)}
    </>
  );
}
```
