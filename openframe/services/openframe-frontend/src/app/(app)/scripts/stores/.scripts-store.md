Zustand store managing the scripts list state, including loading, search, and error handling for script entries in the Flamingo platform.

## Key Components

### `ScriptEntry`
Interface representing a script with fields for metadata (`id`, `name`, `filename`, `category`), execution config (`shell`, `script_type`, `default_timeout`, `run_as_user`), and display properties (`hidden`, `favorite`, `supported_platforms`).

### `ScriptsState`
Full store interface combining state fields and action methods:

| State | Type | Description |
|-------|------|-------------|
| `scripts` | `ScriptEntry[]` | Loaded script entries |
| `search` | `string` | Current search query |
| `isLoading` | `boolean` | Loading indicator (defaults to `true`) |
| `error` | `string \| null` | Last error message |

### `useScriptsStore`
Primary Zustand store hook built with `immer` (immutable updates) and `devtools` (Redux DevTools support).

**Actions:**

| Action | Behavior |
|--------|----------|
| `setScripts` | Updates scripts list and clears error |
| `setSearch` | Updates search query |
| `setLoading` | Toggles loading state |
| `setError` | Sets error and sets `isLoading` to `false` |
| `clearScripts` | Empties scripts array and clears error |
| `reset` | Restores full initial state |

### Selectors
Pre-defined selectors (`selectLogs`, `selectSearch`, `selectIsLoading`, `selectError`) for optimized component re-renders.

## Usage Example

```typescript
import { useScriptsStore, selectSearch, selectIsLoading } from './scripts-store';

function ScriptsList() {
  const scripts = useScriptsStore(state => state.scripts);
  const search = useScriptsStore(selectSearch);
  const isLoading = useScriptsStore(selectIsLoading);
  const { setScripts, setSearch, setLoading, setError } = useScriptsStore();

  useEffect(() => {
    setLoading(true);
    fetchScripts()
      .then(setScripts)
      .catch(err => setError(err.message));
  }, []);

  return isLoading ? <Spinner /> : <ScriptGrid scripts={scripts} />;
}
```
