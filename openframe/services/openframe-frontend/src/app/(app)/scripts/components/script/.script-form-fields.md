Renders the complete set of form fields for creating or editing a script, wiring each field to a `react-hook-form` controller and delegating to shared UI components from the OpenFrame frontend core.

## Key Components

- **`ScriptFormFields`** — Primary export; a controlled form section that accepts a `UseFormReturn<EditScriptFormData>` instance and renders all script configuration fields.

**Rendered fields:**

| Field | Component | Notes |
|---|---|---|
| `supported_platforms` | `SelectButton` grid | Min 1 platform required; disabled platforms show "Coming Soon" tag |
| `run_as_user` | `CheckboxBlock` | Windows-only toggle |
| `name` | `Input` | Text input with validation error display |
| `shell` | `Select` | Populated from `SHELL_TYPES` constant |
| `category` | `Select` | Populated from `CATEGORIES` constant |
| `default_timeout` | `Input (number)` | Seconds adornment, coerces to `Number` |
| `description` | `Textarea` | 4-row free text |
| `args` | `ScriptArguments` | Key/value argument pairs |
| `env_vars` | `ScriptArguments` | Key/value environment variable pairs |
| `script_body` | `ScriptEditor` | Syntax-aware editor, 600px height, shell-aware |

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import { ScriptFormFields } from './components/script-form-fields';
import type { EditScriptFormData } from './types/edit-script.types';

export function EditScriptPage() {
  const form = useForm<EditScriptFormData>({
    defaultValues: {
      name: '',
      shell: 'powershell',
      category: 'Maintenance',
      supported_platforms: ['windows'],
      run_as_user: false,
      default_timeout: 90,
      description: '',
      args: [],
      env_vars: [],
      script_body: '',
    },
  });

  return (
    <form onSubmit={form.handleSubmit(onSubmit)}>
      <ScriptFormFields form={form} />
    </form>
  );
}
```
