Renders all form fields for the script editor form, managing platform selection, shell type, category, timeout, description, arguments, environment variables, and script body content using `react-hook-form` controllers.

## Key Components

- **`ScriptFormFields`** — Main export; a controlled form component that accepts a `UseFormReturn<EditScriptFormData>` instance and renders all script configuration fields
- **Platform Selection** — Grid of `SelectButton` toggles for supported OS platforms, with "Coming Soon" disabled states and a "Run as User" checkbox (Windows only)
- **Core Fields** — Name (`Input`), Shell Type (`Select` from `SHELL_TYPES`), Category (`Select` from `CATEGORIES`), and Timeout (`Input[number]`) in a responsive 2/4-column grid
- **Description** — Multi-row `Textarea` field
- **Arguments & Env Vars** — Side-by-side `ScriptArguments` panels for script arguments and environment variables
- **Script Body** — `ScriptEditor` code editor (600px height) bound to the `script_body` field, shell-type-aware

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import { ScriptFormFields } from './components/script-form-fields';
import type { EditScriptFormData } from './types/edit-script.types';

export function EditScriptForm() {
  const form = useForm<EditScriptFormData>({
    defaultValues: {
      name: '',
      shell: 'powershell',
      category: '',
      default_timeout: 90,
      supported_platforms: ['windows'],
      run_as_user: false,
      description: '',
      args: [],
      env_vars: [],
      script_body: '',
    },
  });

  return (
    <form onSubmit={form.handleSubmit(onSubmit)}>
      <ScriptFormFields form={form} />
    </form>
  );
}
```

> **Note:** At least one platform must remain selected — the toggle handler prevents deselecting the last active platform.
