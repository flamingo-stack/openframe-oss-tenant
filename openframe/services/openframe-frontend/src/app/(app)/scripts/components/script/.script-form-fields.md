Renders the complete set of form fields for creating or editing a script, wiring each field to a `react-hook-form` controller bound to the `EditScriptFormData` schema.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `ScriptFormFields` | Component | Root form fields component; receives a `UseFormReturn<EditScriptFormData>` and renders all sections |
| `ScriptFormFieldsProps` | Interface | Props interface — accepts a single `form` prop |

**Rendered sections (top → bottom):**

1. **Supported Platform** — `SelectButton` grid for available platforms with "Coming Soon" tags for disabled ones; `CheckboxBlock` for "Run as User" (Windows-only)
2. **Core fields grid** — Name (`Input`), Shell Type (`Select` from `SHELL_TYPES`), Category (`Select` from `CATEGORIES`), Timeout (`Input[number]` with "Seconds" adornment)
3. **Description** — multi-row `Textarea`
4. **Arguments & Env Vars** — two side-by-side `ScriptArguments` panels (`args` and `env_vars`)
5. **Syntax / Script Body** — `ScriptEditor` (Monaco-style) at 600px height, shell-aware

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import { ScriptFormFields } from './components/script-form-fields';
import type { EditScriptFormData } from './types/edit-script.types';

export function EditScriptPage() {
  const form = useForm<EditScriptFormData>({
    defaultValues: {
      name: '',
      shell: 'powershell',
      category: 'Maintenance',
      supported_platforms: ['windows'],
      run_as_user: false,
      default_timeout: 90,
      description: '',
      args: [],
      env_vars: [],
      script_body: '',
    },
  });

  return (
    <form onSubmit={form.handleSubmit(onSubmit)}>
      <ScriptFormFields form={form} />
      <button type="submit">Save Script</button>
    </form>
  );
}
```

> **Note:** Platform selection enforces a minimum of one platform — attempting to deselect the last active platform is silently blocked. The `ScriptEditor` automatically adjusts syntax highlighting based on the currently selected `shell` value.
