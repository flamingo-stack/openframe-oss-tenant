A read-only tab component that displays the list of devices assigned to a script schedule, adapting TacticalRMM agent data into the shared `Device` shape for rendering.

## Key Components

- **`ScheduleDevicesTab`** — Main exported component; fetches agents for a given `scheduleId` and renders them in a read-only `DeviceSelector` table
- **`agentToDevice`** — Utility adapter that maps a `ScriptScheduleAgent` (TacticalRMM shape) to the `Device` interface expected by `DeviceSelector`
- **`useScriptScheduleAgents`** — Hook (from `use-script-schedule`) that fetches the agent list, loading state, and error for a schedule

## Usage Example

```typescript
import { ScheduleDevicesTab } from './schedule-devices-tab';
import type { ScriptScheduleDetail } from '../../types/script-schedule.types';

// Rendered inside a tabbed schedule detail view
<ScheduleDevicesTab
  schedule={scheduleDetail}
  scheduleId="42"
/>
```

## Notes

- The `DeviceSelector` is rendered in `readOnly` mode with `organization`, `status`, and `actions` columns hidden — suitable for an informational view
- `agentToDevice` maps `agent_id` to both `id` and `machineId`, and `client_name` to `organization`
- Errors are surfaced via the shared `LoadError` component from `@flamingo-stack/openframe-frontend-core`
- The `schedule` prop is declared in the interface but not consumed in the current implementation, suggesting it may be reserved for future use
