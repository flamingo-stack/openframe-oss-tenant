Renders a read-only list of devices assigned to a script schedule by fetching agents via `useScriptScheduleAgents` and adapting them into the `Device` shape expected by `DeviceSelector`.

## Key Components

- **`ScheduleDevicesTab`** — Main exported component; accepts a `scheduleId` prop, fetches associated agents, and renders a read-only `DeviceSelector` table with `organization`, `status`, and `actions` columns hidden.
- **`agentToDevice`** — Internal adapter function that maps a `ScriptScheduleAgent` (TacticalRMM shape) to the `Device` interface consumed by `DeviceSelector`.

## Usage Example

```typescript
import { ScheduleDevicesTab } from './schedule-devices-tab';

// Inside a parent tab panel:
<ScheduleDevicesTab
  schedule={scheduleDetail}
  scheduleId="abc-123"
/>
```

> **Note:** The `schedule` prop is accepted by the interface but the component currently only uses `scheduleId`. The displayed table suppresses `organization`, `status`, and `actions` columns, showing only device identity and OS information.
