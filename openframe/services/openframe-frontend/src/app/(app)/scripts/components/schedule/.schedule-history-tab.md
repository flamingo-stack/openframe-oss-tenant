Renders a paginated execution history table for a script schedule, displaying run logs with status, device info, and output details. Clicking a row opens a `LogDrawer` with full execution metadata.

## Key Components

- **`ScheduleHistoryTab`** — Main exported component; accepts a `ScriptScheduleDetail` object and `scheduleId` string. Manages pagination state (`offset`/`limit = 50`) and selected drawer entry.
- **`getStatusVariant`** — Maps status strings (`'passing'`, `'failing'`) to Tag color variants (`'success'`, `'error'`, `'grey'`).
- **`getStatusLabel`** — Derives a display label from a history entry's `retcode` and `status` fields.
- **`useScriptScheduleHistory`** — Hook that fetches paginated history data for the given `scheduleId`.
- **`LogDrawer`** — Slide-out drawer showing full run metadata: status, return code, device, platform, execution time, agent ID, sync status, and stdout/stderr output.

### Table Columns

| Column | Description |
|--------|-------------|
| `LOG ID` | Zero-padded log ID + formatted timestamp |
| `STATUS` | Color-coded `Tag` component |
| `DEVICE` | Agent hostname (hidden at `md` breakpoint) |
| `LOG DETAILS` | Truncated stdout/stderr preview (hidden at `md`) |

## Usage Example

```typescript
import { ScheduleHistoryTab } from './schedule-history-tab';

<ScheduleHistoryTab
  scheduleId="sched_abc123"
  schedule={scheduleDetail}
/>
```

> Pagination controls render automatically when `total > 50`. Row clicks open the `LogDrawer` with full execution details including stdout, stderr, and agent metadata.
