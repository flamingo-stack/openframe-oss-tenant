Displays paginated execution history for a script schedule, rendering log entries in a data table with status tags and a detail drawer for individual run inspection.

## Key Components

- **`ScheduleHistoryTab`** — Main exported component; fetches and displays script schedule run history with pagination (50 entries per page)
- **`getStatusVariant`** — Maps status strings (`passing`, `failing`) to Tag color variants (`success`, `error`, `grey`)
- **`getStatusLabel`** — Derives a human-readable status label from a history entry, using return code `0` as `OK`
- **`LogDrawer`** — Slide-in detail panel showing full run metadata (device, platform, return code, stdout/stderr, execution time) for a selected entry
- **`useScriptScheduleHistory`** — Custom hook that fetches paginated history for a given `scheduleId`

## Column Structure

| Column | Key | Notes |
|--------|-----|-------|
| LOG ID | `id` | Zero-padded ID + formatted timestamp |
| STATUS | `status` | Rendered as a `Tag` component |
| DEVICE | `agent_hostname` | Hidden on `md` breakpoint |
| LOG DETAILS | `stdout`/`stderr` | Truncated preview; hidden on `md` |

## Usage Example

```typescript
import { ScheduleHistoryTab } from './schedule-history-tab';

<ScheduleHistoryTab
  schedule={scheduleDetail}
  scheduleId="sched-abc123"
/>
```

> **Note:** Pagination controls (Previous / Next) only render when `total > 50`. Row clicks open a `LogDrawer` with full execution metadata including stdout, stderr, agent platform, sync status, and execution time.
