Skeleton loading state component for the Schedule Detail page, providing placeholder UI that mirrors the layout of the fully-loaded `ScheduleDetailView`.

## Key Components

| Component | Description |
|-----------|-------------|
| `ScheduleDetailSkeleton` | *(exported)* Full-page skeleton wrapped in `DetailPageContainer` — renders header, info bar, tabs, and script card placeholders |
| `InfoBarSkeleton` | 4-column grid placeholder matching `ScheduleInfoBar` (Date, Time, Repeat, Platform) |
| `TabsSkeleton` | Three tab-shaped skeletons mimicking the Scripts / Devices / History tab navigation |
| `ScriptCardSkeleton` | Single card placeholder matching `ScheduleScriptCard` layout with name, timeout, and action buttons |

## Usage Example

```typescript
import { ScheduleDetailSkeleton } from './schedule-details-skeleton';

// Render while schedule data is loading
export default function ScheduleDetailPage() {
  const { data, isLoading } = useScheduleDetail(id);

  if (isLoading) return <ScheduleDetailSkeleton />;

  return <ScheduleDetailView data={data} />;
}
```

## Notes

- Marked `'use client'` — renders on the client only.
- Sub-components (`InfoBarSkeleton`, `TabsSkeleton`, `ScriptCardSkeleton`) are internal and not exported.
- Skeleton dimensions are sized to closely match real content, minimising layout shift when data loads.
