Loading state skeleton component for the Schedule Detail page, rendering placeholder UI while schedule data is being fetched.

## Key Components

| Component | Type | Description |
|-----------|------|-------------|
| `ScheduleDetailSkeleton` | Named Export | Root skeleton wrapping the full detail page layout |
| `InfoBarSkeleton` | Internal | 4-column bar placeholder (Date, Time, Repeat, Platform) |
| `TabsSkeleton` | Internal | 3-tab navigation placeholder (Scripts, Devices, History) |
| `ScriptCardSkeleton` | Internal | Single script card placeholder matching `ScheduleScriptCard` layout |

## Usage Example

```typescript
import { ScheduleDetailSkeleton } from './schedule-details-skeleton';

// Use as a Suspense fallback or conditional loading state
export default function ScheduleDetailPage() {
  const { data, isLoading } = useScheduleDetail(id);

  if (isLoading) return <ScheduleDetailSkeleton />;

  return <ScheduleDetailView data={data} />;
}
```

## Notes

- Marked `'use client'` — renders only on the client side
- Uses `DetailPageContainer` from `@flamingo-stack/openframe-frontend-core` to match the exact layout structure of the real page
- All skeleton dimensions are sized to closely mirror their real counterparts, preventing layout shift on data load
- `InfoBarSkeleton` uses responsive grid (`grid-cols-2` → `grid-cols-4`) matching the live component's breakpoints
