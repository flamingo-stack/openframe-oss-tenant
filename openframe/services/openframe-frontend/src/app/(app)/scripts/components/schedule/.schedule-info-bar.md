Displays a summary info bar for script schedule details, rendering date, time, repeat interval, and supported platforms in a responsive grid layout.

## Key Components

- **`ScheduleInfoBar`** — Accepts a `ScriptScheduleDetail` object and derives display values using `formatScheduleDate` and `getRepeatLabel` helpers before rendering the info grid.
- **`ScheduleInfoBarFromData`** — A data-driven variant that accepts pre-formatted primitive props (`name`, `note`, `date`, `time`, `repeat`, `platforms`), adding a top row for schedule name and optional note.
- **`OSTypeBadgeGroup`** — Imported from `openframe-frontend-core`, renders OS platform badges from the supported platforms list.

## Usage Example

```typescript
// From a ScriptScheduleDetail object
import { ScheduleInfoBar } from './schedule-info-bar';

<ScheduleInfoBar schedule={scheduleDetail} />

// From pre-formatted data (e.g. inside a form preview or confirmation step)
import { ScheduleInfoBarFromData } from './schedule-info-bar';

<ScheduleInfoBarFromData
  name="Weekly Patch Run"
  note="Targets production servers"
  date="Jun 15, 2025"
  time="02:00 AM"
  repeat="Weekly"
  platforms={['windows', 'linux']}
/>
```

## Props

| Component | Prop | Type | Description |
|---|---|---|---|
| `ScheduleInfoBar` | `schedule` | `ScriptScheduleDetail` | Full schedule object; date/time/repeat are derived internally |
| `ScheduleInfoBarFromData` | `name` | `string` | Display name of the schedule |
| | `note` | `string?` | Optional note; renders `—` if absent |
| | `date` / `time` / `repeat` | `string` | Pre-formatted display strings |
| | `platforms` | `string[]` | List of supported OS platform identifiers |
