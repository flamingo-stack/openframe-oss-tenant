Read-only info bar components that display schedule metadata (date, time, repeat interval, and supported platforms) in a responsive grid layout.

## Key Components

### `ScheduleInfoBar`
Accepts a `ScriptScheduleDetail` object and derives display values using `formatScheduleDate` and `getRepeatLabel` utilities. Renders a 4-column grid showing **Date**, **Time**, **Repeat**, and **Supported Platform**.

**Props:**
| Prop | Type | Description |
|------|------|-------------|
| `schedule` | `ScriptScheduleDetail` | Full schedule detail object |

---

### `ScheduleInfoBarFromData`
A data-driven variant that accepts pre-formatted primitive values directly. Extends the base layout with an additional header row showing **Schedule Name** and **Note**.

**Props:**
| Prop | Type | Description |
|------|------|-------------|
| `name` | `string` | Schedule display name |
| `note` | `string?` | Optional note; renders `—` if absent |
| `date` | `string` | Pre-formatted date string |
| `time` | `string` | Pre-formatted time string |
| `repeat` | `string` | Pre-formatted repeat label |
| `platforms` | `string[]` | OS platform identifiers |

---

## Usage Example

```typescript
// From a ScriptScheduleDetail object
<ScheduleInfoBar schedule={scheduleDetail} />

// From pre-formatted primitive data
<ScheduleInfoBarFromData
  name="Weekly Patch Run"
  note="Targets production servers"
  date="Jan 15, 2025"
  time="02:00 AM"
  repeat="Weekly"
  platforms={["windows", "linux"]}
/>
```

> Both components use `OSTypeBadgeGroup` to render platform icons for supported OS types. The layout collapses to a 2-column grid on smaller screens via responsive Tailwind breakpoints.
