Displays a summary info bar for script schedule details, rendering date, time, repeat interval, and supported platforms in a responsive grid layout.

## Key Components

### `ScheduleInfoBar`
Accepts a `ScriptScheduleDetail` object and derives display values using `formatScheduleDate` and `getRepeatLabel` helpers. Renders a 4-column info bar (Date, Time, Repeat, Supported Platform).

**Props:**
| Prop | Type | Description |
|------|------|-------------|
| `schedule` | `ScriptScheduleDetail` | Full schedule detail object |

---

### `ScheduleInfoBarFromData`
A data-driven variant that accepts pre-formatted strings directly, with an additional header row showing schedule name and optional note.

**Props:**
| Prop | Type | Description |
|------|------|-------------|
| `name` | `string` | Schedule name |
| `note` | `string?` | Optional note (falls back to `—`) |
| `date` | `string` | Pre-formatted date string |
| `time` | `string` | Pre-formatted time string |
| `repeat` | `string` | Pre-formatted repeat label |
| `platforms` | `string[]` | Supported OS platform identifiers |

---

## Usage Example

```typescript
// From a schedule detail object
<ScheduleInfoBar schedule={scheduleDetail} />

// From pre-formatted data (e.g. in a form preview)
<ScheduleInfoBarFromData
  name="Weekly Patch Run"
  note="Targets production endpoints"
  date="Jan 15, 2025"
  time="02:00 AM"
  repeat="Weekly"
  platforms={["windows", "linux"]}
/>
```

> **Note:** Use `ScheduleInfoBar` when working directly with `ScriptScheduleDetail` API data. Use `ScheduleInfoBarFromData` when rendering schedule summaries from form state or other pre-processed sources, as it also exposes the schedule name and note fields.
