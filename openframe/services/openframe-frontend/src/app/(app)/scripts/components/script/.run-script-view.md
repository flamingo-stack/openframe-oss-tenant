Renders the full "Run Script" page, allowing users to configure and execute a script against one or more selected devices via the Tactical RMM bulk-action API.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `RunScriptView` | Component | Main page component; accepts a `scriptId` prop and orchestrates the entire run-script workflow |
| `RunScriptViewProps` | Interface | `{ scriptId: string }` |
| `runFormSchema` | Zod schema | Validates `timeout` (1–86400 s), `scriptArgs`, and `envVars` before submission |

**Internal state & hooks used:**

- `useRunScriptData` — fetches script details and available devices
- `useForm` + `zodResolver` — form state and validation
- `DeviceSelector` — multi-device selection with per-device Tactical agent guard
- `ExecutionStartedModal` — post-submission confirmation with a "View Logs" shortcut
- `useSafeBack` — safe back-navigation fallback to `/scripts/details/:id`

## Usage Example

```typescript
// app/scripts/[scriptId]/run/page.tsx
import RunScriptView from '@/features/scripts/components/run-script-view';

export default function RunScriptPage({ params }: { params: { scriptId: string } }) {
  return <RunScriptView scriptId={params.scriptId} />;
}
```

**Form shape submitted to `tacticalApiClient.runBulkAction`:**

```typescript
{
  mode: 'script',
  target: 'agents',
  agents: string[],          // Tactical agent IDs resolved from selected devices
  script: number,            // scriptDetails.id
  timeout: number,           // 1–86400 seconds
  args: string,              // serialised key=value pairs (space-separated)
  env_vars: string,          // serialised key=value pairs
  shell: string,             // resolved from OS type + script shell preference
  run_as_user: boolean,
}
```

> **Validation guards:** Submission is blocked if no devices are selected, or if none of the selected devices carry a Tactical agent ID. Both cases surface a destructive toast notification.
