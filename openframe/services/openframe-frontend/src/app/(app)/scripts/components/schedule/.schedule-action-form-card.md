A responsive form card component for configuring a single scheduled script action, including script selection, timeout, script arguments, and environment variables.

## Key Components

### `ScheduleActionFormCard` (default export)
The main card component rendered for each action entry in a schedule form. Integrates with `react-hook-form` via `useFormContext` and handles:
- Script selection via autocomplete (filtered by supported platforms)
- Timeout field (numeric, in seconds, defaults to `90`)
- Script arguments and environment variable key-value pairs (rendered via `ScriptArguments`)
- Remove action button with disabled guard (`canRemove`)

### `ScriptPlatformIcons`
Internal helper component that renders small OS platform icons inline for each supported platform on a script option.

### Props — `ScheduleActionFormCardProps`

| Prop | Type | Description |
|------|------|-------------|
| `index` | `number` | Position in the `actions` field array |
| `supportedPlatforms` | `string[]` | Platform filter passed to scripts autocomplete |
| `onRemove` | `() => void` | Callback to remove this action card |
| `canRemove` | `boolean` | Disables remove button when `false` |

## Usage Example

```typescript
import { ScheduleActionFormCard } from './schedule-action-form-card';

// Inside a FormProvider with CreateScheduleFormData context
<ScheduleActionFormCard
  index={0}
  supportedPlatforms={['windows', 'linux']}
  onRemove={() => remove(0)}
  canRemove={fields.length > 1}
/>
```

> **Note:** This component must be rendered inside a `react-hook-form` `FormProvider` with a `CreateScheduleFormData` schema. Script selection auto-populates `name` and `timeout` from the selected script's defaults. The layout is responsive — mobile uses a stacked layout while tablet+ uses a single-row grid.
