A responsive form card component for configuring a single scheduled script action, including script selection, timeout, script arguments, and environment variables.

## Key Components

### `ScheduleActionFormCard`
The primary export. Renders a card with script autocomplete, timeout input, and optional argument/env var editors. Integrates with `react-hook-form` via `useFormContext<CreateScheduleFormData>` and adapts layout between mobile (stacked) and tablet+ (grid row) breakpoints.

**Props:**
| Prop | Type | Description |
|------|------|-------------|
| `index` | `number` | Action index within the `actions` array |
| `supportedPlatforms` | `string[]` | Filters scripts to matching OS platforms |
| `onRemove` | `() => void` | Callback to remove this action card |
| `canRemove` | `boolean` | Disables the remove button when `false` |

### `ScriptPlatformIcons`
Internal helper that renders small OS platform icons next to script names in autocomplete options, using `OS_PLATFORMS` from the core package.

## Key Behaviors

- **Script selection** auto-populates `name` and `timeout` from the selected script's metadata via `setValue`
- **Autocomplete blur** is handled carefully — `onClose` fires only when focus leaves the entire widget, not on internal focus transitions
- **Script arguments / env vars** panels are conditionally rendered only when a valid script is selected (`selectedScriptId > 0`)
- **Timeout** defaults to the script's `default_timeout` or `90` seconds as a fallback

## Usage Example

```typescript
// Inside a parent form wrapped with <FormProvider>
<ScheduleActionFormCard
  index={0}
  supportedPlatforms={['windows', 'linux']}
  onRemove={() => removeAction(0)}
  canRemove={fields.length > 1}
/>
```
