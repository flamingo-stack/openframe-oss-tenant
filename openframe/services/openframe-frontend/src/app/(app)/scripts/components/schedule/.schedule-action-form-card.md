A responsive form card component for configuring a single scheduled action, allowing users to select a script, set a timeout, and define script arguments and environment variables.

## Key Components

### `ScheduleActionFormCard`
Main exported component that renders a bordered card with responsive layouts (mobile/tablet+) for configuring one action entry within a schedule form.

**Props:**
| Prop | Type | Description |
|------|------|-------------|
| `index` | `number` | Position in the `actions` array within the parent form |
| `supportedPlatforms` | `string[]` | Filters available scripts by compatible OS platforms |
| `onRemove` | `() => void` | Callback to remove this action from the schedule |
| `canRemove` | `boolean` | Disables the remove button when only one action remains |

### `ScriptPlatformIcons`
Internal helper component that renders small OS platform icons next to script names in the autocomplete dropdown.

### Key Behaviors
- Uses `useFormContext<CreateScheduleFormData>` — must be rendered inside a React Hook Form `<FormProvider>`
- Auto-populates `name` and `timeout` fields when a script is selected via `handleScriptChange`
- Script arguments and environment variable editors are only shown when a valid script is selected (`selectedScriptId > 0`)
- Autocomplete open/close state is managed via focus/blur events to avoid closing on internal focus transitions

## Usage Example

```typescript
import { ScheduleActionFormCard } from './schedule-action-form-card';
import { useFieldArray, FormProvider, useForm } from 'react-hook-form';

function ScheduleForm() {
  const methods = useForm<CreateScheduleFormData>();
  const { fields, append, remove } = useFieldArray({
    control: methods.control,
    name: 'actions',
  });

  return (
    <FormProvider {...methods}>
      {fields.map((field, index) => (
        <ScheduleActionFormCard
          key={field.id}
          index={index}
          supportedPlatforms={['windows', 'linux']}
          onRemove={() => remove(index)}
          canRemove={fields.length > 1}
        />
      ))}
    </FormProvider>
  );
}
```
