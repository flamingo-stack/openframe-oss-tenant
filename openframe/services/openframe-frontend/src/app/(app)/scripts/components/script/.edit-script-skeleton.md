Loading state skeleton component for the Edit Script page, rendering placeholder UI that mirrors the layout of `EditScriptPage` while script data is being fetched.

## Key Components

| Component | Description |
|-----------|-------------|
| `EditScriptSkeleton` | *(exported)* Full-page skeleton matching the complete Edit Script layout |
| `PlatformSkeleton` | 3 platform card placeholders + "Run as User" checkbox block (responsive 3→4 col grid) |
| `FormFieldsSkeleton` | 4 form field placeholders (Name, Shell Type, Category, Timeout) in a 2→4 col grid |
| `DescriptionSkeleton` | Label + textarea placeholder |
| `ArgumentsSkeleton` | Script Arguments / Environment Variables section placeholder |
| `EditorSkeleton` | Code editor placeholder (300px mobile / 600px desktop) |

## Usage Example

```typescript
import { EditScriptSkeleton } from './edit-script-skeleton';

// Use with React Suspense or a loading state gate
export default function EditScriptPage({ params }: { params: { id: string } }) {
  const { data, isLoading } = useScript(params.id);

  if (isLoading) return <EditScriptSkeleton />;

  return <ScriptFormFields data={data} />;
}
```

## Layout Structure

```text
EditScriptSkeleton
├── Back link placeholder
├── Title row + action buttons (Save / Cancel)
├── PlatformSkeleton      ← platform cards grid
├── FormFieldsSkeleton    ← name / shell / category / timeout
├── DescriptionSkeleton   ← textarea
├── ArgumentsSkeleton × 2 ← args + env vars (side-by-side on lg)
└── EditorSkeleton        ← code editor
```

> All sub-components are **unexported** and composed solely within `EditScriptSkeleton`, keeping the skeleton self-contained as a single import.
