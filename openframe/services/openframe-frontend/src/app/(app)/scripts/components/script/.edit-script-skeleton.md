Skeleton loading component for the Edit Script page, rendering placeholder UI that mirrors the exact layout of `EditScriptPage` + `ScriptFormFields` while content is loading.

## Key Components

| Component | Description |
|-----------|-------------|
| `EditScriptSkeleton` | *(exported)* Full-page skeleton matching the Edit Script layout — header, title row, form sections, and code editor |
| `PlatformSkeleton` | 3 platform cards + "Run as User" checkbox in a responsive grid (3 cols / 4 cols on lg) |
| `FormFieldsSkeleton` | 4-field row (Name, Shell Type, Category, Timeout) — 2 cols on mobile, 4 cols on lg |
| `DescriptionSkeleton` | Label + textarea placeholder |
| `ArgumentsSkeleton` | Script Arguments / Environment Variables section with an add-button placeholder |
| `EditorSkeleton` | Code editor placeholder — `300px` tall on mobile, `600px` on lg |

## Usage Example

```typescript
import { EditScriptSkeleton } from './edit-script-skeleton';

// Use as a Suspense fallback or conditional loading state
export default function EditScriptPage({ isLoading, script }) {
  if (isLoading) return <EditScriptSkeleton />;

  return <ScriptFormFields script={script} />;
}
```

> **Note:** `EditScriptSkeleton` is the only exported member. The sub-skeletons (`PlatformSkeleton`, `FormFieldsSkeleton`, etc.) are internal and compose into the full layout — use only `EditScriptSkeleton` externally.
