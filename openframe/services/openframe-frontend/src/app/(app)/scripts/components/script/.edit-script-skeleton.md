Loading state skeleton component for the Edit Script page, rendering placeholder UI that mirrors the exact layout of `EditScriptPage` + `ScriptFormFields` while data is being fetched.

## Key Components

| Component | Description |
|-----------|-------------|
| `EditScriptSkeleton` | Main exported skeleton — full page layout with header, title row, and all form sections |
| `PlatformSkeleton` | 3 platform cards + "Run as User" checkbox in a responsive 3/4-col grid |
| `FormFieldsSkeleton` | 4-field row (Name, Shell Type, Category, Timeout) in a 2/4-col responsive grid |
| `DescriptionSkeleton` | Label + textarea placeholder |
| `ArgumentsSkeleton` | Script Arguments / Environment Variables section with add-button placeholder |
| `EditorSkeleton` | Code editor placeholder — 300px on mobile, 600px on `lg` |

## Usage Example

```typescript
import { EditScriptSkeleton } from './edit-script-skeleton';

// In a Next.js page or Suspense boundary
export default function EditScriptPage() {
  return (
    <Suspense fallback={<EditScriptSkeleton />}>
      <EditScriptContent />
    </Suspense>
  );
}
```

## Notes

- Uses the `Skeleton` primitive from `@flamingo-stack/openframe-frontend-core`
- All sub-components are private (not exported) — only `EditScriptSkeleton` is public
- Layout breakpoints match the real form: `md` for the title row flex direction, `lg` for multi-column grids and editor height
- Marked `'use client'` — renders on the client side within the Next.js App Router
