Detail view component for displaying a script schedule's full details, including tabbed navigation for scripts, devices, and execution history.

## Key Components

**`ScheduleDetailView`** — Main exported component that renders the schedule detail page.

**`SCHEDULE_TABS`** — Static tab configuration array defining three tabs:
- `schedule-scripts` — Scheduled Scripts (via `ScheduleScriptsTab`)
- `schedule-devices` — Assigned Devices (via `ScheduleDevicesTab`)
- `schedule-history` — Execution History (via `ScheduleHistoryTab`)

**URL-controlled tab state** — Active tab is derived from the `?tab=` search param, with `schedule-scripts` as the default. Tab changes use `router.replace` to keep the URL as the single source of truth, avoiding a flicker bug present in `urlSync` mode.

**Actions** — Two memoized action buttons: `Edit Devices` and `Edit Schedule`, linking to `/scripts/schedules/:id/devices` and `/scripts/schedules/:id/edit` respectively.

## Usage Example

```typescript
// Renders the full schedule detail page for a given schedule ID
<ScheduleDetailView scheduleId="sch_abc123" />

// URL-based tab navigation
// /scripts/schedules/sch_abc123?tab=schedule-history
// /scripts/schedules/sch_abc123?tab=schedule-devices
```

## Error States

| State | Component Rendered |
|---|---|
| Loading | `ScheduleDetailSkeleton` |
| Fetch error | `LoadError` with message |
| Schedule not found | `NotFoundError` |
