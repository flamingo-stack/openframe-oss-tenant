Detail view component for a script schedule, rendering tabbed navigation with scripts, devices, and execution history tabs alongside schedule metadata and edit actions.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `ScheduleDetailView` | Component | Main detail page for a single schedule |
| `SCHEDULE_TABS` | `TabItem[]` | Tab configuration for scripts, devices, and history |
| `DEFAULT_SCHEDULE_TAB` | `string` | Fallback tab (`schedule-scripts`) |

## Tabs

| Tab ID | Label | Component |
|--------|-------|-----------|
| `schedule-scripts` | Scheduled Scripts | `ScheduleScriptsTab` |
| `schedule-devices` | Assigned Devices | `ScheduleDevicesTab` |
| `schedule-history` | Execution History | `ScheduleHistoryTab` |

## Behavior Notes

- **URL-driven tab state** — active tab is read from `?tab=` search param; `router.replace` is used on change to avoid flicker caused by internal sync effects in `urlSync` mode
- **Safe back navigation** — falls back to `/scripts/?tab=schedules` if no history entry exists
- **Loading/error states** — renders `ScheduleDetailSkeleton`, `LoadError`, or `NotFoundError` based on fetch state from `useScriptSchedule`

## Usage Example

```typescript
// Rendered by a dynamic route, e.g. /scripts/schedules/[scheduleId]/page.tsx
import { ScheduleDetailView } from './schedule-details-view';

export default function ScheduleDetailPage({ params }: { params: { scheduleId: string } }) {
  return <ScheduleDetailView scheduleId={params.scheduleId} />;
}
```
