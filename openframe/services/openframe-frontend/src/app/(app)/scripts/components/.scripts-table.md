Renders a paginated, filterable data table for scripts, supporting URL-persisted search/filter state, row actions (run, edit, details), and responsive column visibility.

## Key Components

- **`ScriptsTable`** — Main exported component; renders the full scripts list page with search, multi-select filters, and a `DataTable`
- **`UiScriptEntry`** — Local interface defining the normalized shape of a script row (id, name, shellType, supportedPlatforms, category, etc.)
- **`useScripts`** — Custom hook that fetches raw script data from the API
- **`useApiParams`** — Persists `search`, `shellType`, `category`, and `supportedPlatforms` filters in the URL query string
- **`useDebounce`** — Debounces the search input (300 ms) before syncing to URL state
- **`renderRowActions`** — Builds the `ActionsMenuDropdown` with Run, Edit, and Details actions (each with an optional "open in new tab" icon)
- **`columns`** — Memoized `ColumnDef<UiScriptEntry>[]` array with responsive `hideAt` breakpoints and `multiSelectFilterFn` on filterable columns
- **`handleColumnFiltersChange`** — Stable callback that syncs `DataTable` column-filter state back to URL params

## Usage Example

```typescript
// Drop-in page usage — no props required; all state is managed internally
import { ScriptsTable } from '@/features/scripts/components/scripts-table';

export default function ScriptsPage() {
  return <ScriptsTable />;
}
```
