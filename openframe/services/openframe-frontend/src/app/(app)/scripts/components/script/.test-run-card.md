A React client component that displays a real-time test run status card for agent tool executions on a device, showing metadata, elapsed time, status, and a scrollable live log output.

## Key Components

### `TestRunData` (interface)
Represents the data model for a test run, including:
- `id`, `deviceName`, `agentToolId` — identifiers
- `status` — `'running' | 'completed' | 'error' | 'aborted'`
- `output` — array of log lines rendered in real time
- `elapsedSeconds` / `startedAt` / `startTime` — timing info

### `TestRunCard` (component)
Main exported component. Renders a responsive card with:
- **Header row** — device name, start time, duration, status, and action buttons
- **Log panel** — scrollable 240px output area with color-coded lines (error/success/neutral)
- **Auto-scroll** — `useRef` + `useEffect` keeps the log pinned to the latest output
- **Responsive layout** — duration and status row collapse/reorder between `md`/`lg` breakpoints

### Helper Functions
| Function | Purpose |
|---|---|
| `formatDuration(totalSeconds)` | Converts seconds to `HH:MM:SS` string |
| `getStatusLabel(status)` | Maps status enum to display string |
| `getStatusColor(status)` | Returns Tailwind class for status color |

## Usage Example

```typescript
<TestRunCard
  run={{
    id: 'run-001',
    deviceName: 'WORKSTATION-42',
    agentToolId: 'ping-check',
    startedAt: '2024-01-15 10:32:00',
    startTime: Date.now(),
    status: 'running',
    output: ['Starting ping test...', 'Sending packets to 8.8.8.8'],
    elapsedSeconds: 34,
  }}
  onStop={() => console.log('stop')}
  onTestAgain={() => console.log('retry')}
  onClose={() => console.log('close')}
/>
```
