A React client component that displays a real-time test run card for agent tool executions on a device, showing status, duration, and a scrollable live log output.

## Key Components

### `TestRunData` (interface)
Data model for a test run, including:
- `id`, `deviceName`, `agentToolId` — identifiers
- `status` — `'running' | 'completed' | 'error' | 'aborted'`
- `output` — array of log lines rendered in the card body
- `elapsedSeconds` — drives the live duration display

### `TestRunCardProps` (interface)
Props accepted by the card:
- `run: TestRunData` — current run state
- `onStop` — callback to abort a running test
- `onTestAgain` — callback to re-run the test after completion
- `onClose` — callback to dismiss the card

### `TestRunCard` (component)
Main export. Renders a two-section card:
- **Header** — device name, start time, duration, status label, and contextual action buttons (Stop / Test Again + Close)
- **Log pane** — auto-scrolling 240px output area with color-coded lines (error = red, success = green) and a pulsing "Waiting for response…" indicator while running

### Helper functions
| Function | Purpose |
|---|---|
| `formatDuration(seconds)` | Formats elapsed seconds as `HH:MM:SS` |
| `getStatusLabel(status)` | Maps status enum to display string |
| `getStatusColor(status)` | Returns Tailwind color class for the status |

## Usage Example

```typescript
import { TestRunCard, TestRunData } from './test-run-card';

const run: TestRunData = {
  id: 'run-001',
  deviceName: 'DESKTOP-ABC123',
  agentToolId: 'tool-ping',
  startedAt: '2024-01-15 10:30:00',
  startTime: Date.now(),
  status: 'running',
  output: ['Starting ping test...', 'Sent 4 packets'],
  elapsedSeconds: 12,
};

<TestRunCard
  run={run}
  onStop={() => handleStop(run.id)}
  onTestAgain={() => handleRerun(run.agentToolId)}
  onClose={() => setRuns(prev => prev.filter(r => r.id !== run.id))}
/>
```
