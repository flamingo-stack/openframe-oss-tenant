Renders a responsive card UI for a single agent tool test run, displaying device info, elapsed time, status, and a scrollable live log output with controls to stop, re-run, or dismiss the test.

## Key Components

- **`TestRunData`** — Interface defining the shape of a test run: id, device name, agent tool ID, start time, status, output lines, and elapsed seconds
- **`TestRunCardProps`** — Props interface accepting a `TestRunData` object and three callbacks: `onStop`, `onTestAgain`, `onClose`
- **`TestRunCard`** — Primary exported component rendering the card with responsive desktop/mobile layouts
- **`formatDuration(totalSeconds)`** — Formats elapsed seconds into `HH:MM:SS` string
- **`getStatusLabel(status)`** — Maps status enum to human-readable labels (`running` → `In Progress`, etc.)
- **`getStatusColor(status)`** — Maps status to ODS token color classes for visual feedback

## Usage Example

```typescript
import { TestRunCard, TestRunData } from './test-run-card';

const run: TestRunData = {
  id: 'run-001',
  deviceName: 'DESKTOP-ABC123',
  agentToolId: 'tool-ping',
  startedAt: '2:30 PM',
  startTime: Date.now(),
  status: 'running',
  output: ['Starting test...', 'Connecting to device...'],
  elapsedSeconds: 42,
};

<TestRunCard
  run={run}
  onStop={() => console.log('stop')}
  onTestAgain={() => console.log('retry')}
  onClose={() => console.log('close')}
/>
```

## Notes

- Log output auto-scrolls to the bottom on each new line via a `useRef` + `useEffect` on `run.output.length`
- Log lines are color-coded: error lines use `text-ods-error`, success/passed/completed lines use green, others use secondary text
- While `status === 'running'`, a pulsing "Waiting for response..." indicator is appended to the log
- Responsive layout: duration and status columns are conditionally shown/hidden across `md`/`lg` breakpoints
