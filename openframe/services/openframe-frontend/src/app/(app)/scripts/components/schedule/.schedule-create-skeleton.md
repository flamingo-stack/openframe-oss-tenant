Loading state skeleton component for the Schedule Create/Edit page, mirroring the exact layout of `ScheduleCreateView` inside `DetailPageContainer` during data fetch.

## Key Components

| Component | Description |
|-----------|-------------|
| `ScheduleCreateSkeleton` | **Primary export.** Full-page skeleton matching the Schedule Create/Edit layout |
| `NameFieldSkeleton` | Label + input field placeholder for the schedule name |
| `DateRepeatSkeleton` | Two-item row placeholder for the date picker and repeat checkbox |
| `PlatformsSkeleton` | Label + three platform button placeholders |
| `ActionCardSkeleton` | Card-shaped placeholder for `ScheduleActionFormCard` with header, input, and field row |

## Usage Example

```typescript
import { ScheduleCreateSkeleton } from './schedule-create-skeleton';

// Render while schedule data / form dependencies are loading
export default function ScheduleCreatePage() {
  const { data, isLoading } = useSchedule(id);

  if (isLoading) return <ScheduleCreateSkeleton />;

  return <ScheduleCreateView data={data} />;
}
```

> Only `ScheduleCreateSkeleton` is exported. The inner skeleton primitives (`NameFieldSkeleton`, `DateRepeatSkeleton`, `PlatformsSkeleton`, `ActionCardSkeleton`) are internal layout helpers and are not exposed for external use.
