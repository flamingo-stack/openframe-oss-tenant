Loading skeleton component for the Schedule Create/Edit page that mirrors the layout structure of `ScheduleCreateView`, preventing layout shift during data fetching.

## Key Components

| Component | Description |
|-----------|-------------|
| `ScheduleCreateSkeleton` | Main exported skeleton matching the full Schedule Create/Edit page layout |
| `NameFieldSkeleton` | Skeleton for the schedule name label + input field |
| `DateRepeatSkeleton` | Skeleton for the date picker and repeat checkbox row |
| `PlatformsSkeleton` | Skeleton for the supported platforms section (3 platform buttons) |
| `ActionCardSkeleton` | Skeleton for a single `ScheduleActionFormCard` with title, delete button, and fields |

## Usage Example

```typescript
import { ScheduleCreateSkeleton } from './schedule-create-skeleton';

// Render while schedule form data is loading
export default function ScheduleCreatePage() {
  const { data, isLoading } = useScheduleData();

  if (isLoading) {
    return <ScheduleCreateSkeleton />;
  }

  return <ScheduleCreateView data={data} />;
}
```

## Notes

- Marked as `'use client'` — renders on the client side only
- Uses `Skeleton` from `@flamingo-stack/openframe-frontend-core`
- Internal sub-components (`NameFieldSkeleton`, `DateRepeatSkeleton`, etc.) are not exported — composed exclusively inside `ScheduleCreateSkeleton`
- Skeleton dimensions are tuned to match the real form layout, reducing cumulative layout shift (CLS)
