A confirmation modal displayed when a script execution has been successfully submitted, informing the user and providing navigation to activity logs.

## Key Components

### `ExecutionStartedModal`
A client-side modal component wrapping `SimpleModal` with two footer actions.

**Props (`ExecutionStartedModalProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls modal visibility |
| `onClose` | `() => void` | Callback to dismiss the modal |
| `scriptName` | `string` | Name of the script submitted for execution |
| `onViewLogs` | `() => void` | Callback to navigate to activity logs |

## Usage Example

```typescript
import { ExecutionStartedModal } from './execution-started-modal';

function ScriptRunner() {
  const [showModal, setShowModal] = useState(false);

  const handleRun = async () => {
    await submitScript();
    setShowModal(true);
  };

  return (
    <>
      <button onClick={handleRun}>Run Script</button>
      <ExecutionStartedModal
        isOpen={showModal}
        onClose={() => setShowModal(false)}
        scriptName="backup-cleanup.ps1"
        onViewLogs={() => router.push('/activity-logs')}
      />
    </>
  );
}
```

> The modal presents a **Close** button to dismiss and a **View Logs** button to navigate directly to execution progress, reducing friction after script submission.
