A confirmation modal displayed when a script execution has been successfully submitted, notifying the user and providing navigation to the activity logs.

## Key Components

### `ExecutionStartedModal`

A client-side modal component built on `SimpleModal` that confirms script execution acceptance.

**Props (`ExecutionStartedModalProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls modal visibility |
| `onClose` | `() => void` | Callback fired when the modal is dismissed |
| `scriptName` | `string` | Name of the script submitted for execution |
| `onViewLogs` | `() => void` | Callback fired when the user navigates to activity logs |

## Usage Example

```typescript
import { ExecutionStartedModal } from './execution-started-modal';

function ScriptRunner() {
  const [modalOpen, setModalOpen] = useState(false);

  const handleRunScript = async () => {
    await submitScript();
    setModalOpen(true);
  };

  const handleViewLogs = () => {
    setModalOpen(false);
    router.push('/activity-logs');
  };

  return (
    <>
      <Button onClick={handleRunScript}>Run Script</Button>
      <ExecutionStartedModal
        isOpen={modalOpen}
        onClose={() => setModalOpen(false)}
        scriptName="backup-cleanup.ps1"
        onViewLogs={handleViewLogs}
      />
    </>
  );
}
```

The footer renders two actions: **Close** (outline variant) to dismiss the modal, and **View Logs** to redirect the user to execution progress tracking.
