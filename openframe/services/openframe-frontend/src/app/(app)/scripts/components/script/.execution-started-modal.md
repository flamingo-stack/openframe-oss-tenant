A confirmation modal displayed when a script execution has been successfully initiated, informing the user and providing navigation to activity logs.

## Key Components

### `ExecutionStartedModal`
A modal component built on `SimpleModal` that notifies users their script has been accepted for execution.

**Props (`ExecutionStartedModalProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls modal visibility |
| `onClose` | `() => void` | Handler for closing the modal |
| `scriptName` | `string` | Name of the script being executed |
| `onViewLogs` | `() => void` | Handler to navigate to activity logs |

## Usage Example

```typescript
import { ExecutionStartedModal } from './execution-started-modal';

function ScriptRunner() {
  const [showModal, setShowModal] = useState(false);

  const handleExecute = async () => {
    await triggerScriptExecution();
    setShowModal(true);
  };

  return (
    <>
      <Button onClick={handleExecute}>Run Script</Button>
      <ExecutionStartedModal
        isOpen={showModal}
        onClose={() => setShowModal(false)}
        scriptName="Deploy Production"
        onViewLogs={() => router.push('/activity-logs')}
      />
    </>
  );
}
```

The modal renders two footer actions: **Close** (outline variant) to dismiss, and **View Logs** (primary variant) to navigate to the activity logs section where execution progress and results can be tracked.
