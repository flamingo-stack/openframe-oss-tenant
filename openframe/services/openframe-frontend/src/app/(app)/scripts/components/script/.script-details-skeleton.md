Renders a loading skeleton placeholder for the script details page, mimicking the layout of the header, info section, and code editor while content is being fetched.

## Key Components

- **`InfoFieldSkeleton`** — Renders a two-line skeleton (value + label) with configurable value width via `valueWidth` prop
- **`ScriptInfoSectionSkeleton`** — Skeleton for the description row and 3-column info bar (Shell Type, Supported Platforms, Category)
- **`CodeEditorSkeleton`** — Renders 12 skeleton lines of varying widths inside a fixed-height (`400px`) code editor container
- **`ScriptDetailsSkeleton`** *(exported)* — Composes all sub-skeletons into the full page layout using `DetailPageContainer`, including header breadcrumb, title, action buttons, info section, and code editor

## Usage Example

```typescript
import { ScriptDetailsSkeleton } from './script-details-skeleton';

// Use as a Suspense fallback or loading state in the script details route
export default function ScriptDetailsPage() {
  if (isLoading) {
    return <ScriptDetailsSkeleton />;
  }
  return <ScriptDetails script={data} />;
}
```

> The skeleton uses `DetailPageContainer` with `padding="none"` and applies system spacing via a CSS variable (`--spacing-system-l`), keeping it visually consistent with the real page layout.
