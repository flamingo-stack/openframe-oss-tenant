Skeleton loading state component for the Script Details page, rendering animated placeholder elements that match the layout of the actual script detail view.

## Key Components

| Component | Description |
|-----------|-------------|
| `ScriptDetailsSkeleton` | Main exported skeleton — wraps the full page in `DetailPageContainer` with header, info section, and code editor placeholders |
| `ScriptInfoSectionSkeleton` | Mimics the script metadata card: description row + 3-column grid (Shell Type, Platforms, Category) |
| `CodeEditorSkeleton` | Renders 12 animated lines of varying widths inside a fixed-height container to simulate a code editor |
| `InfoFieldSkeleton` | Atomic skeleton for a single labeled field (value on top, label below); accepts `valueWidth` for customization |

## Usage Example

```typescript
import { ScriptDetailsSkeleton } from './script-details-skeleton';

// Render while script data is loading
export default function ScriptDetailsPage() {
  const { data, isLoading } = useScript(scriptId);

  if (isLoading) return <ScriptDetailsSkeleton />;

  return <ScriptDetails script={data} />;
}
```

## Notes

- Uses ODS design tokens (`bg-ods-card`, `border-ods-border`) for consistent dark-mode theming.
- `CodeEditorSkeleton` line widths use a deterministic formula `Math.max(20, 80 - i * 5 + ((i * 17) % 30))` to produce natural-looking staggered lengths without randomness (safe for SSR).
- `'use client'` directive is required since skeleton state is driven by client-side loading conditions.
