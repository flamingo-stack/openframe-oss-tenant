Skeleton loading placeholder for the script details page, rendering animated shimmer elements that mirror the layout of the actual script detail view during data fetching.

## Key Components

- **`InfoFieldSkeleton`** — Renders a two-line shimmer block (value + label), with a configurable `valueWidth` prop for varying widths
- **`ScriptInfoSectionSkeleton`** — Skeleton for the info card section, including a description row and a 3-column grid (Shell Type, Supported Platforms, Category)
- **`CodeEditorSkeleton`** — Mimics a code editor with 12 shimmer lines of staggered widths inside a fixed-height container
- **`ScriptDetailsSkeleton`** *(exported)* — Root skeleton component that composes all sub-skeletons inside a `DetailPageContainer`, including a page header with breadcrumb, title, and action button placeholders

## Usage Example

```typescript
import { ScriptDetailsSkeleton } from './script-details-skeleton';

// Use as a Suspense fallback or conditional loading state
function ScriptDetailsPage({ id }: { id: string }) {
  const { data, isLoading } = useScriptDetails(id);

  if (isLoading) return <ScriptDetailsSkeleton />;

  return <ScriptDetails data={data} />;
}
```

> The component is a pure presentational placeholder — no props are required. Sub-skeletons (`InfoFieldSkeleton`, `ScriptInfoSectionSkeleton`, `CodeEditorSkeleton`) are internal and not exported.
