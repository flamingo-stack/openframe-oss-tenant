Tabbed view component for the Scripts section, rendering either the Scripts List or Scripts Schedules table based on the active URL query parameter.

## Key Components

- **`SCRIPTS_TABS`** — Static tab configuration array defining two tabs: `list` (ScriptsTable) and `schedules` (ScriptSchedulesTable), each with an icon and associated component
- **`ScriptsView`** — Main exported component that manages tab state via URL query params (`?tab=`) and renders the active tab's content

## Usage Example

```typescript
// Rendered at a page level — no props required
import { ScriptsView } from './scripts-view';

export default function ScriptsPage() {
  return <ScriptsView />;
}

// URL-driven tab switching:
// ?tab=list      → renders <ScriptsTable />
// ?tab=schedules → renders <ScriptSchedulesTable />
```

## Behavior Notes

- **URL sync** is handled manually via `router.replace()` on tab change; `TabNavigation`'s built-in `urlSync` is disabled (`false`) to avoid conflicts
- **Active tab** defaults to `'list'` when no `?tab` param is present, resolved via `useApiParams`
- **Tab component** is resolved dynamically using `getTabComponent` — renders `null` if no matching tab is found
- The wrapper applies `-mt-4` to visually align the tab bar with the surrounding page layout
