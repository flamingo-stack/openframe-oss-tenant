Tabbed view component for the Scripts section, rendering either the Scripts List or Script Schedules table based on the active URL query parameter.

## Key Components

- **`SCRIPTS_TABS`** — Static tab configuration array defining two tabs: `list` (ScriptsTable) and `schedules` (ScriptSchedulesTable), each with an icon and label.
- **`ScriptsView`** — Main exported component that manages tab state via URL query params (`?tab=`), handles navigation, and renders the appropriate tab component.

## Usage Example

```typescript
// Basic usage - renders the full scripts tabbed interface
import { ScriptsView } from './scripts-view';

export default function ScriptsPage() {
  return <ScriptsView />;
}

// Tab navigation is URL-driven:
// /scripts?tab=list       → renders <ScriptsTable />
// /scripts?tab=schedules  → renders <ScriptSchedulesTable />
```

## Behavior Notes

- **URL sync** is handled manually via `router.replace()` on tab change, keeping `urlSync={false}` on `TabNavigation` to avoid double-sync conflicts.
- **Default tab** falls back to `'list'` when no `tab` query param is present.
- The `getTabComponent` utility resolves the active tab's component from the `SCRIPTS_TABS` array; renders nothing if the tab ID is unrecognized.
