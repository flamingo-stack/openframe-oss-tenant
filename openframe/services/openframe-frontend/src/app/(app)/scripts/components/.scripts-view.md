Renders the top-level Scripts section view with tab-based navigation between the scripts list and scheduled scripts tables.

## Key Components

- **`SCRIPTS_TABS`** — Static tab configuration array defining two tabs: `list` (ScriptsTable) and `schedules` (ScriptSchedulesTable), each with an associated icon and component
- **`ScriptsView`** — Main exported component that composes tab navigation with URL-synced tab state

## Behavior

- Reads the active `tab` query parameter via `useApiParams` (defaults to `'list'`)
- On tab change, updates the URL using `router.replace` to persist tab state across navigation
- Dynamically resolves the active tab's component via `getTabComponent` and renders it inside a minimum-height container

## Usage Example

```typescript
// Rendered as a page-level component — no props required
import { ScriptsView } from './scripts-view';

export default function ScriptsPage() {
  return <ScriptsView />;
}

// URL-driven tab selection:
// /scripts?tab=list      → renders <ScriptsTable />
// /scripts?tab=schedules → renders <ScriptSchedulesTable />
```
