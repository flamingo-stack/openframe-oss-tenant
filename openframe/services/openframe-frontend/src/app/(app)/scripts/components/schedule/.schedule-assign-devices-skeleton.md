Loading state skeleton component for the Schedule Assign Devices page, rendering placeholder UI that mirrors the layout of the full `ScheduleAssignDevicesView` during data fetching.

## Key Components

| Component | Description |
|-----------|-------------|
| `InfoBarSkeleton` | Mimics the schedule info bar with a 2-column top row (Name/Note) and a 4-column bottom row (Date/Time/Repeat/Platform) |
| `SelectionModeSkeleton` | Renders two radio-option cards for device selection mode, with the second card shown at reduced opacity |
| `DeviceRowSkeleton` | Single device table row placeholder with icon, name/detail stack, and action button slots |
| `ScheduleAssignDevicesSkeleton` *(exported)* | Root skeleton composing all sub-skeletons into the full page shell — back link, title bar, info bar, selection mode, sub-tabs, search input, and 8 device rows |

## Usage Example

```typescript
import { ScheduleAssignDevicesSkeleton } from './schedule-assign-devices-skeleton';

// Use as a Suspense fallback or conditional loading state
function ScheduleAssignDevicesPage() {
  const { data, isLoading } = useScheduleAssignDevices(scheduleId);

  if (isLoading) {
    return <ScheduleAssignDevicesSkeleton />;
  }

  return <ScheduleAssignDevicesView data={data} />;
}
```

Only `ScheduleAssignDevicesSkeleton` is exported; the three sub-skeletons are internal helpers composed within it.
