Skeleton loading UI for the Schedule Assign Devices page, rendering placeholder shimmer components that mirror the layout of the full `ScheduleAssignDevicesView` during data fetching.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `ScheduleAssignDevicesSkeleton` | Named export | Full-page skeleton matching the Assign Devices view layout |
| `InfoBarSkeleton` | Internal | Mimics the schedule name/note + date/time/repeat/platform info bar |
| `SelectionModeSkeleton` | Internal | Mimics the selection mode radio option cards |
| `DeviceRowSkeleton` | Internal | Mimics a single device table row with icon, name, metadata, and actions |

## Usage Example

```typescript
import { ScheduleAssignDevicesSkeleton } from './schedule-assign-devices-skeleton';

// Use as a Suspense fallback or loading state
export default function ScheduleAssignDevicesPage() {
  if (isLoading) {
    return <ScheduleAssignDevicesSkeleton />;
  }

  return <ScheduleAssignDevicesView />;
}
```

## Layout Structure

```text
ScheduleAssignDevicesSkeleton
├── Back link
├── Title + Save button
├── InfoBarSkeleton
│   ├── Top row: Name | Note  (2-col grid)
│   └── Bottom row: Date | Time | Repeat | Platform  (4-col grid)
├── SelectionModeSkeleton  (2 radio cards)
├── Sub-tabs  (Available / Selected)
├── Search input
└── DeviceRowSkeleton × 8
```
