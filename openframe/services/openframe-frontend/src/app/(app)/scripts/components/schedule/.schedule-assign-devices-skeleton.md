Loading state skeleton component for the Schedule Assign Devices page, rendering placeholder UI that matches the layout of the fully-loaded view.

## Key Components

| Component | Type | Description |
|-----------|------|-------------|
| `ScheduleAssignDevicesSkeleton` | Named export | Full-page skeleton matching `ScheduleAssignDevicesView` layout |
| `InfoBarSkeleton` | Internal | Placeholder for the schedule name/note and date/time/repeat/platform info bar |
| `SelectionModeSkeleton` | Internal | Placeholder for the two selection mode radio options |
| `DeviceRowSkeleton` | Internal | Placeholder for a single device table row with icon, name, and action buttons |

## Usage Example

```typescript
import { ScheduleAssignDevicesSkeleton } from './schedule-assign-devices-skeleton';

// Use as a Suspense fallback or during data loading
export default function ScheduleAssignDevicesPage() {
  if (isLoading) {
    return <ScheduleAssignDevicesSkeleton />;
  }

  return <ScheduleAssignDevicesView />;
}
```

## Layout Structure

The skeleton mirrors the following section order of the real page:

```text
Back link
Title + Save button
InfoBar (2-col name/note row + 4-col metadata row)
Selection mode (2 radio option cards)
Sub-tabs (Available / Selected)
Search input
Device rows × 8
```
