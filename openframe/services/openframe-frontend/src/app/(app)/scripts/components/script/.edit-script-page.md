Page component for creating and editing automation scripts, handling form state, test runs, and navigation within the OpenFrame scripts module.

## Key Components

- **`EditScriptPage`** — Main page component accepting an optional `scriptId` prop; when provided, operates in edit mode; when `null`, operates in create mode
- **`useEditScriptForm`** — Manages form state, validation, and save logic
- **`useScriptDetails`** — Fetches existing script data when editing
- **`useTestRuns`** — Controls script test execution, stop, and clear lifecycle
- **`ScriptFormFields`** — Renders form inputs bound to the react-hook-form instance
- **`TestScriptModal`** — Device selection modal before triggering a test run
- **`TestRunCard`** — Displays live/completed test run output with stop and retry actions

## Usage Example

```typescript
// Render in create mode
<EditScriptPage scriptId={null} />

// Render in edit mode (scriptId from route params)
<EditScriptPage scriptId="script_abc123" />
```

## Behavior Notes

- **Loading state** — Renders `EditScriptSkeleton` while fetching script details
- **Error state** — Displays a styled error card with a back button if the script fails to load in edit mode
- **Back navigation** — Uses `useSafeBack` to return to `/scripts` in create mode or `/scripts/details/:id` in edit mode
- **Actions bar** — Provides "Test Script" (outline) and "Save Script" (accent, with loading state) via `FormPageContainer`
- **Test run flow** — Opening `TestScriptModal` → selecting a device → triggers `handleRunTest` → result shown in `TestRunCard`
