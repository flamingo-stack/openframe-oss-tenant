Page component for creating and editing automation scripts, handling form state, test execution, and navigation within the Flamingo/OpenFrame scripts feature.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `EditScriptPage` | Component | Main page component for create/edit script workflows |
| `EditScriptPageProps` | Interface | Accepts `scriptId: string \| null` — `null` triggers create mode |

## Behavior

- **Create vs. Edit mode** — determined by whether `scriptId` is `null`; controls title, back navigation, and form pre-population
- **Back navigation** — routes to `/scripts` (create) or `/scripts/details/:id` (edit) using `useSafeBack`
- **Script testing** — opens `TestScriptModal` to select a device, then streams results into a `TestRunCard`; supports stop, retry, and dismiss
- **Error state** — renders an inline error card with a destructive back button if script loading fails in edit mode
- **Loading state** — renders `EditScriptSkeleton` while fetching script details

## Key Hooks

| Hook | Purpose |
|------|---------|
| `useScriptDetails` | Fetches existing script data by ID |
| `useEditScriptForm` | Manages form state, validation, and save handler |
| `useTestRuns` | Controls test execution lifecycle (run, stop, clear) |

## Usage Example

```typescript
// Create mode
<EditScriptPage scriptId={null} />

// Edit mode
<EditScriptPage scriptId="script-abc-123" />
```

> **Note:** `scriptId` is typically derived from route params. Pass `null` explicitly for new script creation to ensure correct form initialization and navigation behavior.
