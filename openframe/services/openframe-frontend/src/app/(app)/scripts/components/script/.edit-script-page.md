Page component for creating and editing automation scripts, handling form state, test execution, and navigation within the Scripts module.

## Key Components

- **`EditScriptPage`** — Main page component accepting an optional `scriptId` prop; renders in "new" or "edit" mode accordingly
- **`useScriptDetails`** — Fetches existing script data when in edit mode
- **`useEditScriptForm`** — Manages form state, validation, and save handler
- **`useTestRuns`** — Controls test execution lifecycle (run, stop, clear)
- **`ScriptFormFields`** — Renders the script form inputs
- **`TestScriptModal`** — Device selection modal for triggering a test run
- **`TestRunCard`** — Displays live test run output with stop/re-test/close controls
- **`EditScriptSkeleton`** — Loading placeholder shown while script data is fetching

## Usage Example

```typescript
// Render in "new script" mode
<EditScriptPage scriptId={null} />

// Render in "edit script" mode
<EditScriptPage scriptId="abc123" />
```

## Behavior Notes

- `scriptId === null` → **Create** mode: back button navigates to `/scripts`
- `scriptId` provided → **Edit** mode: back button navigates to `/scripts/details/:id`
- A loading skeleton is shown while script details are fetched
- On fetch error (edit mode only), an error card is rendered with a destructive back button
- The `TestScriptModal` receives `supported_platforms` from the watched form field, filtering available test devices by platform
- `actions` (Test Script / Save Script) are memoized to prevent unnecessary re-renders
