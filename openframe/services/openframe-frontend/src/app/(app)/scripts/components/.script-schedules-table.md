A client-side React component that renders a paginated, searchable table of script schedules with inline row actions, OS badges, and "load more" pagination.

## Key Components

- **`ScriptSchedulesTable`** — Main exported component. Renders a `ListPageLayout` wrapping a `DataTable` for browsing script schedules.
- **`getRepeatLabelFromTaskType`** — Helper that converts a `ScriptScheduleTaskType` enum value (`runonce`, `daily`, `weekly`, `monthly`, `monthlydow`) into a human-readable label.
- **Column definitions** — Six columns: Script name, OS badge group, Date & Time, Repeat frequency, Device count, and row-level Actions/Open buttons.
- **Search & pagination** — Debounced (300ms) client-side search with URL param sync via `useApiParams`. Visible rows are incrementally expanded via `visibleCount` (load-more pattern, page size of 10).
- **Row actions** — Dropdown menu per row with `Edit Schedule` and `Edit Devices` links, each supporting open-in-new-tab via `iconAction`.

## Usage Example

```typescript
// Drop into any Next.js page to render the schedules list
import { ScriptSchedulesTable } from './script-schedules-table';

export default function ScriptSchedulesPage() {
  return <ScriptSchedulesTable />;
}
```

The component is self-contained — it fetches its own data via `useScriptSchedules()`, manages search state, and handles navigation internally. No props are required. Row clicks navigate to `/scripts/schedules/[id]`; the Add Schedule button navigates to `/scripts/schedules/create`.
