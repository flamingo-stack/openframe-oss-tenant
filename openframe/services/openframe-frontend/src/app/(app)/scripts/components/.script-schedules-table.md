A client-side React table component that displays a paginated, searchable list of script schedules with inline actions for editing schedules and managing associated devices.

## Key Components

- **`ScriptSchedulesTable`** — Main exported component rendering the full list page layout with search, data table, and load-more pagination
- **`getRepeatLabelFromTaskType`** — Helper that maps `ScriptScheduleTaskType` enum values (`runonce`, `daily`, `weekly`, `monthly`, `monthlydow`) to human-readable repeat labels
- **Column definitions** — Six columns: Script name (truncated), OS badge group, Date & Time (formatted), Repeat frequency, Device count, and row actions (edit schedule/devices + open in new tab)
- **`renderRowActions`** — Builds an `ActionsMenuDropdown` with "Edit Schedule" and "Edit Devices" actions, each supporting in-tab and new-tab navigation
- **Client-side filtering** — Filters schedules by name using debounced search input (`useDebounce`, 300ms)
- **Incremental pagination** — Load-more pattern using `visibleCount` state (10 items per page) with reset on search change

## Usage Example

```typescript
// Render inside a schedules page
import { ScriptSchedulesTable } from './script-schedules-table';

export default function SchedulesPage() {
  return <ScriptSchedulesTable />;
}
```

The component internally manages:
- Search state synced to URL params via `useApiParams`
- Schedule data fetched via `useScriptSchedules` hook
- Row clicks navigate to `/scripts/schedules/:id`
- "Add Schedule" button routes to `/scripts/schedules/create`
