Renders a paginated, searchable table of script schedules with inline row actions for editing schedules and managing assigned devices.

## Key Components

- **`ScriptSchedulesTable`** — Main exported component that composes the full list page, including search, column definitions, row actions, and load-more pagination.
- **`getRepeatLabelFromTaskType`** — Helper that maps `ScriptScheduleTaskType` enum values (`runonce`, `daily`, `weekly`, `monthly`, `monthlydow`) to human-readable repeat labels.

### Columns

| Column | Description |
|--------|-------------|
| `Script` | Schedule name with text truncation |
| `OS` | Supported platform badges (hidden on small screens) |
| `Date & Time` | Formatted run date and time |
| `Repeat` | Human-readable frequency label (hidden on md) |
| `Devices` | Assigned agent count (hidden on lg) |
| `Actions` | Dropdown with Edit Schedule / Edit Devices links |
| `Open` | Opens schedule detail in a new tab |

### Behavior

- **Debounced search** (300ms) filters schedules by name via URL params.
- **Client-side pagination** with a load-more footer (increments by 10).
- Visible count resets when the search term changes.

## Usage Example

```typescript
// Drop in as a page-level component — no props required.
import { ScriptSchedulesTable } from './script-schedules-table';

export default function SchedulesPage() {
  return <ScriptSchedulesTable />;
}
```
