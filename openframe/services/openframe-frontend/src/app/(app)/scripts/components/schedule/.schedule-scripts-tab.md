Renders the Scripts tab within a schedule detail view, displaying each scheduled script action as an expandable card with argument and environment variable details.

## Key Components

- **`ScheduleScriptsTab`** — Container component that maps over `schedule.actions` and renders a `ScheduleScriptCard` for each entry
- **`ScheduleScriptCard`** — Expandable card showing a single script action's name, timeout, parsed arguments, and environment variables. Navigates to `/scripts/details/:id` on detail button click

## Usage Example

```typescript
import { ScheduleScriptsTab } from './schedule-scripts-tab';

<ScheduleScriptsTab
  schedule={{
    actions: [
      {
        name: 'Backup Script',
        script: 42,
        timeout: 120,
        script_args: ['--output /tmp/backup', '--compress'],
        env_vars: ['BACKUP_KEY=abc123', 'REGION=us-east-1'],
      },
    ],
  }}
/>
```

## Behavior Notes

- Script arguments are split on the first space into `label` / `value` pairs; args with no space are treated as flags
- Environment variables are split on `=`, joining remaining segments to preserve values containing `=`
- The expand/collapse animation uses a CSS `grid-template-rows` transition (`0fr` → `1fr`)
- The **Script Details** button is hidden on mobile inside the header but rendered again inside the expanded panel for small screens
