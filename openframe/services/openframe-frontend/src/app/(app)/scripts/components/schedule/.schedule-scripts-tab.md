Renders the Scripts tab within a schedule detail view, displaying each scheduled script action as an expandable card with arguments, environment variables, and navigation to script details.

## Key Components

### `ScheduleScriptsTab`
Top-level tab component that maps over `schedule.actions` and renders a `ScheduleScriptCard` for each action.

**Props:**
| Prop | Type | Description |
|------|------|-------------|
| `schedule` | `ScriptScheduleDetail` | Full schedule object containing the `actions` array |

### `ScheduleScriptCard` *(internal)*
Collapsible card displaying a single `ScriptScheduleAction`. Parses raw `script_args` (space-delimited) and `env_vars` (`=`-delimited) into label/value pairs for `InfoCard` display.

**Behaviors:**
- Expand/collapse toggle animates via CSS grid row transition
- **Desktop:** "Script Details" button visible inline in the header
- **Mobile:** "Show Script Details" button appears inside the expanded content area
- Navigates to `/scripts/details/:id` on script details click

## Usage Example

```typescript
import { ScheduleScriptsTab } from './schedule-scripts-tab';

// Inside a parent schedule detail page/component:
<ScheduleScriptsTab schedule={scheduleDetail} />
```

Where `scheduleDetail` satisfies `ScriptScheduleDetail`:

```typescript
const scheduleDetail: ScriptScheduleDetail = {
  actions: [
    {
      name: 'Patch Scanner',
      script: 42,
      timeout: 120,
      script_args: ['--verbose', '--target 192.168.1.1'],
      env_vars: ['API_KEY=abc123', 'DEBUG=true'],
    },
  ],
};
```
