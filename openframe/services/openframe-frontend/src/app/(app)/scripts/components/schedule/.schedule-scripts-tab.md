Renders the Scripts tab within a schedule detail view, displaying each scheduled script action as an expandable card with arguments, environment variables, and navigation to script details.

## Key Components

**`ScheduleScriptsTab`**
Top-level tab component that iterates over `schedule.actions` and renders a `ScheduleScriptCard` for each action.

**`ScheduleScriptCard`**
Internal card component for a single `ScriptScheduleAction`. Features:
- **Header row** — script name, timeout value, and a "Script Details" button (hidden on mobile)
- **Expand/collapse toggle** — animated via CSS `grid-template-rows` transition
- **Expandable section** — shows parsed script arguments and environment variables via `InfoCard`, with a mobile-only "Show Script Details" button

**Argument parsing**
- `script_args`: splits each entry at the first space into `label`/`value`; entries with no space are treated as flags
- `env_vars`: splits on `=`; handles values that themselves contain `=` via `rest.join('=')`

## Usage Example

```typescript
import { ScheduleScriptsTab } from './schedule-scripts-tab';
import type { ScriptScheduleDetail } from '../../types/script-schedule.types';

const schedule: ScriptScheduleDetail = {
  actions: [
    {
      name: 'Cleanup Logs',
      script: 42,
      timeout: 60,
      script_args: ['--verbose', '--output /var/log/result.txt'],
      env_vars: ['LOG_LEVEL=debug', 'MAX_SIZE=100'],
    },
  ],
};

export default function Page() {
  return <ScheduleScriptsTab schedule={schedule} />;
}
```
