A modal component for selecting a target device when testing a script, filtering available devices by supported platforms and requiring a Tactical RMM agent to be present.

## Key Components

- **`TestScriptModal`** — Main modal component wrapping `SimpleModal` with a `DeviceSelector` for single-device selection
- **`fetchDevicesForTest`** — Async function that queries online devices via GraphQL, filtered by OS type derived from supported platforms, and sorts results with Tactical-agent-enabled devices first
- **`SelectedTestDevice`** — Exported interface representing the confirmed selection (`agentToolId`, `deviceName`)
- **`TestScriptModalProps`** — Props interface for controlling open state, close/confirm callbacks, and platform filtering

## Usage Example

```typescript
import { TestScriptModal, SelectedTestDevice } from './test-script-modal';

function ScriptRunner() {
  const [modalOpen, setModalOpen] = useState(false);

  const handleDeviceSelected = (device: SelectedTestDevice) => {
    console.log(`Running test on ${device.deviceName} via agent ${device.agentToolId}`);
    setModalOpen(false);
  };

  return (
    <>
      <Button onClick={() => setModalOpen(true)}>Test Script</Button>
      <TestScriptModal
        isOpen={modalOpen}
        onClose={() => setModalOpen(false)}
        onDeviceSelected={handleDeviceSelected}
        supportedPlatforms={['windows', 'linux']}
      />
    </>
  );
}
```

## Behavior Notes

- Devices are fetched only when the modal is open **and** at least one platform is specified; a placeholder message is shown otherwise
- Devices without a Tactical RMM agent are listed but disabled with an inline tooltip (`"Tactical agent is\nnot installed"`)
- Selection state is reset on both confirm and cancel to prevent stale selections on re-open
