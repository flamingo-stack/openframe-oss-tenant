A modal component for selecting a target device when testing a script, filtering available devices by supported platforms and requiring a Tactical RMM agent to be present.

## Key Components

- **`TestScriptModal`** — Main modal component wrapping `SimpleModal` with a `DeviceSelector` for single-device selection
- **`fetchDevicesForTest`** — Async function that queries online devices filtered by OS type (derived from `supportedPlatforms`), sorting Tactical-agent-enabled devices first
- **`SelectedTestDevice`** — Exported interface describing the resolved device selection (`agentToolId`, `deviceName`)
- **`TestScriptModalProps`** — Props interface controlling open state, close/select callbacks, and platform filtering

## Usage Example

```typescript
import { TestScriptModal, SelectedTestDevice } from './test-script-modal';

function ScriptRunner() {
  const [modalOpen, setModalOpen] = useState(false);

  const handleDeviceSelected = (device: SelectedTestDevice) => {
    console.log('Running script on:', device.deviceName);
    console.log('Agent ID:', device.agentToolId);
    // dispatch script execution with device.agentToolId
  };

  return (
    <>
      <Button onClick={() => setModalOpen(true)}>Test Script</Button>
      <TestScriptModal
        isOpen={modalOpen}
        onClose={() => setModalOpen(false)}
        onDeviceSelected={handleDeviceSelected}
        supportedPlatforms={['windows', 'linux']}
      />
    </>
  );
}
```

## Behaviour Notes

- Device list is only fetched when the modal is open **and** at least one platform is specified; otherwise a prompt is shown
- Devices without a Tactical RMM agent are displayed but disabled with a tooltip
- Selection state resets on both confirm and cancel
