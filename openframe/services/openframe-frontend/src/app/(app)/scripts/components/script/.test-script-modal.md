A modal component for selecting a target device when testing a script, filtering available online devices by supported platform and requiring a Tactical RMM agent to be present.

## Key Components

- **`TestScriptModal`** – Main modal component rendering a `SimpleModal` with a `DeviceSelector` and confirm/cancel actions
- **`fetchDevicesForTest`** – Async function that queries online devices via GraphQL, filtered by OS type derived from `supportedPlatforms`, and sorts results with Tactical agent-equipped devices first
- **`SelectedTestDevice`** – Exported interface describing the confirmed device selection (`agentToolId`, `deviceName`)
- **`TestScriptModalProps`** – Props interface requiring open state, close/selection callbacks, and a `supportedPlatforms` string array

## Behavior Notes

- Devices are fetched only when the modal is open **and** at least one platform is specified (`enabled: isOpen && hasPlatforms`)
- If no device is selected or the selected device lacks a Tactical RMM agent, a destructive toast is shown
- Device list is sorted: Tactical-agent devices appear first
- Selection state resets on both confirm and cancel

## Usage Example

```typescript
import { TestScriptModal, SelectedTestDevice } from './test-script-modal';

function ScriptRunner() {
  const [isOpen, setIsOpen] = useState(false);

  const handleDeviceSelected = (device: SelectedTestDevice) => {
    console.log('Running test on:', device.deviceName);
    runScriptOnDevice(device.agentToolId);
  };

  return (
    <TestScriptModal
      isOpen={isOpen}
      onClose={() => setIsOpen(false)}
      onDeviceSelected={handleDeviceSelected}
      supportedPlatforms={['windows', 'linux']}
    />
  );
}
```
