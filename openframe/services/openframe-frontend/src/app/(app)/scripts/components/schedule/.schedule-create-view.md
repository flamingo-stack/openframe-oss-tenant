React form view component for creating and editing script schedules, supporting both create and edit modes with Zod validation via React Hook Form.

## Key Components

- **`ScheduleCreateView`** — Main exported component accepting an optional `scheduleId` prop; presence of this prop toggles between create and edit modes
- **Form fields** — Schedule name, scheduled date/time, repeat interval/period, supported platform toggles, and a dynamic list of script action cards
- **`useFieldArray`** — Manages dynamic addition/removal of script action entries
- **`useCreateScriptSchedule` / `useUpdateScriptSchedule`** — Mutation hooks for API persistence
- **`ScheduleActionFormCard`** — Child component rendering each script action row
- **`ScheduleCreateSkeleton`** — Loading placeholder shown while fetching an existing schedule in edit mode

## Usage Example

```typescript
// Create mode — no props needed
<ScheduleCreateView />

// Edit mode — pass an existing schedule ID
<ScheduleCreateView scheduleId="sched_abc123" />
```

## Behavior Notes

- In **edit mode**, fetches the existing schedule via `useScriptSchedule` and resets the form with `scheduleDetailToFormData`
- Platform toggles enforce a minimum of one selected platform
- Repeat fields (`repeatInterval`, `repeatPeriod`) are conditionally rendered only when `repeatEnabled` is checked
- On successful submit, redirects to the schedule detail page; on failure, surfaces a destructive toast
- The `Cancel` action button is mobile-only (`showOnlyMobile: true`); desktop navigation relies on the back button
