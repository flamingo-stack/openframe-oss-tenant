Renders the create/edit form for script schedules, handling both new schedule creation and existing schedule editing via a shared form view controlled by an optional `scheduleId` prop.

## Key Components

- **`ScheduleCreateView`** — Main exported component; accepts an optional `scheduleId` to toggle between create and edit modes
- **`useForm` / `FormProvider`** — React Hook Form setup with Zod schema validation (`createScheduleFormSchema`)
- **`useFieldArray`** — Manages the dynamic list of script actions (add/remove)
- **`useCreateScriptSchedule` / `useUpdateScriptSchedule`** — Mutation hooks for submitting to the API
- **`useScriptSchedule`** — Fetches existing schedule data when in edit mode
- **`ScheduleActionFormCard`** — Renders each individual script action entry in the form
- **`togglePlatform`** — Prevents deselecting the last active platform

## Form Fields

| Field | Type | Notes |
|---|---|---|
| `name` | Text input | Required |
| `scheduledDate` | Date + time picker | Required |
| `repeatEnabled` | Checkbox | Reveals interval/period fields |
| `repeatInterval` | Number | Visible when repeat is enabled |
| `repeatPeriod` | Select | `day`, `week`, etc. |
| `supportedPlatforms` | Toggle buttons | At least one required |
| `actions` | Dynamic array | Min. one `ScheduleActionFormCard` |

## Usage Example

```typescript
// Create mode
<ScheduleCreateView />

// Edit mode — loads existing schedule and prefills form
<ScheduleCreateView scheduleId="sched_abc123" />
```

> On successful submission, the user is redirected to the schedule detail page. Failures surface via the toast notification system.
