Form view component for creating and editing script schedules, handling form state, validation, and submission for both create and update operations.

## Key Components

- **`ScheduleCreateView`** — Main exported component accepting an optional `scheduleId` prop; when provided, switches to edit mode and pre-populates form data from the existing schedule
- **Form management** — Uses `react-hook-form` with `zodResolver` against `createScheduleFormSchema` for validation; `FormProvider` wraps child components for context access
- **`useFieldArray`** — Manages the dynamic list of script actions, supporting add/remove operations
- **`togglePlatform`** — Prevents deselecting the last active platform while toggling OS targets (Windows, macOS, Linux)
- **`onSubmit`** — Dispatches either `createMutation` or `updateMutation` based on mode, shows toast feedback, and redirects on success
- **`ScheduleActionFormCard`** — Child component rendering per-action script configuration fields
- **`ScheduleCreateSkeleton`** — Displayed while fetching existing schedule data in edit mode

## Usage Example

```typescript
// Create mode — no scheduleId
<ScheduleCreateView />

// Edit mode — pass existing schedule ID
<ScheduleCreateView scheduleId="sched_abc123" />
```

## Form Fields

| Field | Type | Description |
|---|---|---|
| `name` | `string` | Schedule display name |
| `scheduledDate` | `Date` | Initial run date/time |
| `repeatEnabled` | `boolean` | Toggles repeat interval controls |
| `repeatInterval` | `number` | Numeric repeat frequency |
| `repeatPeriod` | `string` | Unit (`day`, `week`, etc.) |
| `supportedPlatforms` | `Platform[]` | Target OS list |
| `actions` | `array` | One or more script action definitions |
