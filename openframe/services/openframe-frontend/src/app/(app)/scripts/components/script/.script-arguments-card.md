Renders a labeled info card displaying a list of script arguments parsed into key-value pairs using a configurable separator.

## Key Components

- **`ScriptArgumentsCard`** — Client component that parses and displays script arguments as structured label/value pairs
- **`ScriptArgumentsCardProps`** — Interface defining the component's props:
  - `title` — Label displayed above the card
  - `args` — Array of argument strings to parse and display
  - `separator` — Delimiter used to split each argument into key/value (defaults to `=`)

## Usage Example

```typescript
// Basic usage with default "=" separator
<ScriptArgumentsCard
  title="Script Parameters"
  args={['timeout=30', 'retries=3', 'verbose=true']}
/>

// Custom separator
<ScriptArgumentsCard
  title="Environment Variables"
  args={['HOST:localhost', 'PORT:8080']}
  separator=":"
/>

// Returns null when args is empty or undefined
<ScriptArgumentsCard title="No Params" args={[]} /> // renders nothing
```

**Parsing behavior:**
- `"key=value"` → `{ label: "key", value: "value" }`
- `"flag"` (no separator found) → `{ label: "flag", value: "" }`
- Only the first occurrence of the separator is used as the split point (`indexOf`)
