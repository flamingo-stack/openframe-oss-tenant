Renders a labeled info card displaying script arguments as key-value pairs, splitting each argument string on a configurable separator character.

## Key Components

- **`ScriptArgumentsCard`** — React component that accepts a list of raw argument strings and displays them in an `InfoCard` layout with parsed label/value pairs
- **`ScriptArgumentsCardProps`** — Interface defining:
  - `title` — section label rendered above the card
  - `args` — array of raw argument strings (e.g., `["key=value"]`)
  - `separator` *(optional)* — delimiter used to split each arg into label/value; defaults to `'='`

## Behavior

- Returns `null` if `args` is empty or undefined, preventing empty card renders
- Splits each argument string at the **first occurrence** of the separator using `indexOf`, ensuring values containing the separator character are preserved correctly

## Usage Example

```typescript
// Basic usage with default '=' separator
<ScriptArgumentsCard
  title="Script Parameters"
  args={["timeout=30", "retries=3", "verbose"]}
/>

// Custom separator
<ScriptArgumentsCard
  title="Environment Variables"
  args={["HOST:localhost", "PORT:8080"]}
  separator=":"
/>

// Returns null — nothing rendered
<ScriptArgumentsCard title="No Args" args={[]} />
```
