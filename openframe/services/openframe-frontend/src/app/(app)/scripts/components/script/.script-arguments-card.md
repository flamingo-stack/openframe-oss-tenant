Renders a labeled card displaying script arguments as key-value pairs, parsing each argument string using a configurable separator.

## Key Components

- **`ScriptArgumentsCard`** — Client component that accepts a list of argument strings, splits each on a separator, and renders them as label/value rows inside an `InfoCard`
- **`ScriptArgumentsCardProps`** — Interface defining:
  - `title` — Card heading text
  - `args` — Array of argument strings (e.g., `["key=value"]`)
  - `separator` — Delimiter used to split each arg into key/value (defaults to `"="`)

Returns `null` when `args` is empty or undefined.

## Usage Example

```typescript
// Basic usage with default '=' separator
<ScriptArgumentsCard
  title="Script Parameters"
  args={["timeout=30", "retries=3", "verbose=true"]}
/>

// Custom separator
<ScriptArgumentsCard
  title="Script Parameters"
  args={["timeout:30", "retries:3"]}
  separator=":"
/>

// Args without a separator render as label-only rows
<ScriptArgumentsCard
  title="Flags"
  args={["--dry-run", "--force"]}
/>
```
