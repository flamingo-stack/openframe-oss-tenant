A Monaco-based code editor component styled with the ODS dark theme, supporting multiple shell/scripting languages for script editing within the Flamingo platform.

## Key Components

- **`ScriptEditor`** — Main exported component wrapping Monaco Editor with ODS theming and shell language detection
- **`defineOdsTheme`** — Registers a custom `ods-dark` Monaco theme matching Flamingo's design tokens
- **`SHELL_TO_LANGUAGE`** — Maps shell type identifiers (`powershell`, `bash`, `python`, `deno`, `sql`, etc.) to Monaco language IDs
- **`ScriptEditorProps`** — Interface defining `value`, `onChange`, `shell`, `readOnly`, and `height` props

## Usage Example

```typescript
import { ScriptEditor } from './script-editor';

// Editable bash script
<ScriptEditor
  value="#!/bin/bash\necho 'Hello, World!'"
  onChange={(val) => console.log(val)}
  shell="bash"
  height="300px"
/>

// Read-only PowerShell viewer
<ScriptEditor
  value="Get-Process | Where-Object { $_.CPU -gt 10 }"
  shell="powershell"
  readOnly
/>

// Python script with custom height
<ScriptEditor
  value="import os\nprint(os.getcwd())"
  onChange={handleChange}
  shell="python"
  height="500px"
/>
```

## Supported Shell Types

| `shell` Prop | Monaco Language |
|---|---|
| `powershell` | `powershell` |
| `cmd` | `bat` |
| `bash` / `shell` / `nushell` | `shell` |
| `python` | `python` |
| `deno` | `typescript` |
| `sql` | `sql` |

> The editor is dynamically imported with `ssr: false` to prevent server-side rendering issues with Monaco. The minimap and quick suggestions are automatically disabled in `readOnly` mode.
