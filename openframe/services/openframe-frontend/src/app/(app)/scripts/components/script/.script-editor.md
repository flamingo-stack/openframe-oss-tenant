A Monaco-based code editor component with a custom Flamingo dark theme (`ods-dark`) and multi-shell language support, rendered client-side via Next.js dynamic import.

## Key Components

- **`ScriptEditor`** — Main exported React component wrapping the Monaco editor
- **`defineOdsTheme`** — Registers the `ods-dark` custom Monaco theme using Flamingo's amber/teal color palette
- **`SHELL_TO_LANGUAGE`** — Maps shell identifiers (`powershell`, `bash`, `python`, `deno`, etc.) to Monaco language IDs
- **`ScriptEditorProps`** — Interface defining `value`, `onChange`, `shell`, `readOnly`, and `height`

## Usage Example

```typescript
import { ScriptEditor } from '@/components/script-editor';

// Editable bash script
<ScriptEditor
  value={scriptContent}
  onChange={(val) => setScriptContent(val)}
  shell="bash"
  height="300px"
/>

// Read-only PowerShell viewer
<ScriptEditor
  value={psScript}
  shell="powershell"
  readOnly
/>

// Python with custom height
<ScriptEditor
  value={pythonCode}
  onChange={handleChange}
  shell="python"
  height="500px"
/>
```

## Supported Shells

| `shell` prop | Monaco Language |
|---|---|
| `bash` / `shell` / `nushell` | `shell` |
| `powershell` | `powershell` |
| `cmd` | `bat` |
| `python` | `python` |
| `deno` | `typescript` |
| `sql` | `sql` |

## Notes

- SSR is disabled via `next/dynamic` — safe for server components
- Minimap is hidden in `readOnly` mode; suggestions and context menu are also suppressed
- Theme colors align with Flamingo's design system: amber `#ffc008` cursors/selections, teal `#5efaf0` strings, `#161616` background
