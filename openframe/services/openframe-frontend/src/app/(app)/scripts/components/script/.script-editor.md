A Monaco-based code editor component with a custom dark theme (`ods-dark`) styled to match the Flamingo/OpenFrame design system, supporting multiple shell/scripting languages.

## Key Components

- **`ScriptEditor`** — Main exported component wrapping Monaco Editor with Flamingo's amber-accented dark theme
- **`defineOdsTheme`** — Registers the custom `ods-dark` Monaco theme with Flamingo brand colors (`#ffc008` amber, `#5efaf0` teal, `#161616` background)
- **`SHELL_TO_LANGUAGE`** — Maps shell identifiers (`powershell`, `bash`, `python`, `deno`, `sql`, etc.) to Monaco language IDs
- **`ScriptEditorProps`** — Interface for `value`, `onChange`, `shell`, `readOnly`, and `height`

## Usage Example

```typescript
import { ScriptEditor } from '@/components/script-editor';

// Editable PowerShell script
<ScriptEditor
  value={scriptContent}
  onChange={(val) => setScriptContent(val)}
  shell="powershell"
  height="300px"
/>

// Read-only Python snippet
<ScriptEditor
  value={pythonCode}
  shell="python"
  readOnly
  height="200px"
/>
```

## Supported Shell Values

| `shell` prop | Monaco Language |
|---|---|
| `bash` / `shell` / `nushell` | `shell` |
| `powershell` | `powershell` |
| `cmd` | `bat` |
| `python` | `python` |
| `deno` | `typescript` |
| `sql` | `sql` |

## Notes

- Dynamically imported (`ssr: false`) to avoid SSR issues with Monaco
- Minimap, context menu, and quick suggestions are automatically disabled in `readOnly` mode
- Font defaults to `--font-azeret-mono` with monospace fallbacks
