Read-only detail view component for displaying a script's full metadata, arguments, environment variables, and syntax.

## Key Components

- **`ScriptDetailsView`** — Main component accepting a `scriptId` prop; fetches and renders complete script details
- **`useScriptDetails`** — Hook that loads script data, exposes `scriptDetails`, `isLoading`, and `error`
- **`actions`** — Memoized array of page-level actions: `Edit Script` (outline) and `Run Script` (accent, only rendered when script ID resolves)
- **`ScriptInfoSection`** — Displays headline, shell type, supported platforms, and category metadata
- **`ScriptArgumentsCard`** — Renders argument and environment variable lists in a responsive two-column grid
- **`ScriptEditor`** — Read-only syntax-highlighted code editor for the script body (400px height)

## States Handled

| State | Rendered Output |
|-------|----------------|
| Loading | `ScriptDetailsSkeleton` |
| Fetch error | `LoadError` with message |
| Not found | `NotFoundError` |
| Success | Full detail layout |

## Usage Example

```typescript
// Route: /scripts/details/[scriptId]/page.tsx
import { ScriptDetailsView } from './components/script-details-view';

export default function ScriptDetailsPage({ params }: { params: { scriptId: string } }) {
  return <ScriptDetailsView scriptId={params.scriptId} />;
}
```

Navigation links are derived from `scriptId`:
- Edit → `/scripts/edit/{scriptId}`
- Run → `/scripts/details/{id}/run` (conditionally shown after script resolves)
- Back → `/scripts` via `useSafeBack`
