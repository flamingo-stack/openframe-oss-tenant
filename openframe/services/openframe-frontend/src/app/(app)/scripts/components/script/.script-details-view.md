Read-only detail view component for displaying comprehensive script information including metadata, arguments, environment variables, and syntax with Edit/Run action buttons.

## Key Components

- **`ScriptDetailsView`** — Main page component that fetches and renders a script's full details by `scriptId`
- **`useScriptDetails`** — Hook providing `scriptDetails`, `isLoading`, and `error` state
- **`actions`** — Memoized array of page-level actions: *Edit Script* (outline) and *Run Script* (accent, conditionally rendered when `scriptDetails.id` is available)
- **`ScriptArgumentsCard`** — Renders default script arguments and environment variables in a responsive 2-column grid
- **`ScriptEditor`** — Read-only syntax-highlighted code viewer for `script_body`
- **`ScriptInfoSection`** — Displays headline, description, shell type, supported platforms, and category

## Loading & Error States

| State | Component Rendered |
|---|---|
| Loading | `ScriptDetailsSkeleton` |
| Fetch error | `LoadError` with message |
| Not found | `NotFoundError` |

## Usage Example

```typescript
// In a Next.js page
export default function ScriptDetailsPage({ params }: { params: { id: string } }) {
  return <ScriptDetailsView scriptId={params.id} />;
}
```

The component conditionally shows the **Run Script** button only after `scriptDetails.id` resolves, preventing premature navigation. The back button uses `useSafeBack('/scripts')` to fall back to `/scripts` if no browser history is available.
