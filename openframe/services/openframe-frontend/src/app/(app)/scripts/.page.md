A Next.js client-side page component that renders the Scripts management interface within the OpenFrame platform.

## Key Components

- **`Scripts`** — Default export; top-level page component that wraps the scripts interface in a layout container
- **`ContentPageContainer`** — Layout wrapper from `@flamingo-stack/openframe-frontend-core` providing consistent page structure
- **`ScriptsView`** — The primary scripts UI component handling script listing, management, and interactions

## Usage Example

```typescript
// This is a Next.js App Router page — rendered automatically at its route.
// No direct import needed; Next.js resolves it via the filesystem.

// To compose ScriptsView elsewhere:
import { ScriptsView } from './components/scripts-view';

export default function CustomScriptsPage() {
  return (
    <ContentPageContainer padding="none" showHeader={false}>
      <ScriptsView />
    </ContentPageContainer>
  );
}
```

## Notes

- Marked as `'use client'` — runs exclusively in the browser
- `dynamic = 'force-dynamic'` disables static generation, ensuring the page is always server-rendered fresh (useful for live script data)
- Header is hidden (`showHeader={false}`) and padding is applied via CSS custom property `--spacing-system-l`
