Client-side Next.js page component that acts as a route wrapper for the script editing interface, extracting the `id` route parameter and passing it to the `EditScriptPage` component.

## Key Components

- **`EditScriptPageWrapper`** — Default export; reads the `id` param from the URL and renders `EditScriptPage` with a typed, nullable `scriptId` prop.

## Usage Example

```typescript
// Rendered automatically by Next.js when navigating to:
// /scripts/[id]/edit  →  EditScriptPageWrapper receives params.id

// Internally delegates to:
<EditScriptPage scriptId="abc-123" />  // id found in route
<EditScriptPage scriptId={null} />     // id missing or not a string
```

## Notes

- Marked `'use client'` — runs in the browser, enabling `useParams` from `next/navigation`.
- Guards against non-string param values by coercing to `null`, keeping `EditScriptPage` safely typed.
