Next.js client-side route wrapper that extracts the `id` route parameter and passes it to the `EditScriptPage` component for editing an existing script.

## Key Components

- **`EditScriptPageWrapper`** — Default export; reads the `id` param from the URL and renders `EditScriptPage` with the resolved script ID (or `null` if absent/invalid).

## Usage Example

```typescript
// Accessed via route: /scripts/[id]/edit
// e.g. /scripts/abc123/edit → scriptId = "abc123"
// e.g. /scripts/edit (no id) → scriptId = null

<EditScriptPageWrapper />
// Renders: <EditScriptPage scriptId="abc123" />
```
