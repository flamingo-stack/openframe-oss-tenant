Client-side Next.js page component that extracts the `id` route parameter and passes it to the `EditScriptPage` component for editing an existing script.

## Key Components

- **`EditScriptPageWrapper`** — Default export; reads the dynamic `[id]` route param via `useParams` and renders `EditScriptPage` with the resolved `scriptId`.

## Usage Example

```typescript
// Accessed via route: /scripts/[id]/edit
// e.g. /scripts/abc123/edit → scriptId = "abc123"
// e.g. /scripts/edit (no id) → scriptId = null

<EditScriptPageWrapper />
// Internally renders:
<EditScriptPage scriptId="abc123" />
```

## Notes

- Marked `'use client'` — required because `useParams` is a client-side hook.
- Safely coerces `params.id` to `null` if it is not a plain string (e.g. array or undefined), preventing type mismatches in `EditScriptPage`.
