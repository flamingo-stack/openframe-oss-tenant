Client-side Next.js page component that acts as a routing wrapper for the policy editor, resolving the URL parameter to either a new policy or an existing one by ID.

## Key Components

- **`EditPolicyPageWrapper`** — Default export; reads the `id` route param and passes `null` for new policies or the string ID for existing ones to `EditPolicyPage`

## Usage Example

```typescript
// Accessed via routes:
// /policies/new        → policyId: null  (create mode)
// /policies/abc-123    → policyId: "abc-123"  (edit mode)

<EditPolicyPageWrapper />
```

## Route Parameter Logic

| URL Param | Resolved `policyId` |
|-----------|---------------------|
| `"new"` | `null` |
| `"abc-123"` | `"abc-123"` |
| `undefined` | `null` |
