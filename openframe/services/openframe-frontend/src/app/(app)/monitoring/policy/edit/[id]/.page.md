Client-side Next.js route wrapper that resolves the `[id]` URL parameter and renders the `EditPolicyPage` component, normalizing the special `"new"` slug to `null` for policy creation flows.

## Key Components

- **`EditPolicyPageWrapper`** — Default export; reads the `id` route param, maps `"new"` → `null` (create mode) and any valid string → the policy ID (edit mode), then delegates to `EditPolicyPage`.

## Usage Example

```typescript
// Rendered automatically by Next.js at:
// /policies/new          → policyId = null  (create)
// /policies/abc-123      → policyId = "abc-123" (edit)

// EditPolicyPage receives:
<EditPolicyPage policyId={null} />       // create mode
<EditPolicyPage policyId="abc-123" />    // edit mode
```

## Route Behavior

| URL Param | Resolved `policyId` | Mode   |
|-----------|---------------------|--------|
| `new`     | `null`              | Create |
| `abc-123` | `"abc-123"`         | Edit   |
| *(missing)*| `null`             | Create |
