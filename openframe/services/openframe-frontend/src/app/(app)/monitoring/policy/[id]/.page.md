Client-side Next.js page component that handles routing for individual monitoring policy pages, redirecting `/monitoring/policy/new` to the edit route and rendering `PolicyDetailsView` for existing policies.

## Key Components

- **`PolicyPageWrapper`** — Default export page component that reads the `id` route param, performs a redirect for `new` policy creation, and renders the policy details view.

## Usage Example

```typescript
// Accessed via Next.js dynamic route: /monitoring/policy/[id]

// Navigating to a new policy → redirects to:
// /monitoring/policy/edit/new

// Navigating to an existing policy → renders:
<PolicyDetailsView policyId="policy-123" />
```

## Behavior

| Route | Behavior |
|---|---|
| `/monitoring/policy/new` | Redirects to `/monitoring/policy/edit/new` |
| `/monitoring/policy/[id]` | Renders `PolicyDetailsView` with the given `id` |
