Client-side Next.js page component that handles routing for individual monitoring policy pages, redirecting `new` policy requests to the edit route and rendering existing policies via `PolicyDetailsView`.

## Key Components

- **`PolicyPageWrapper`** — Default export page component that reads the `id` route parameter and conditionally renders or redirects

## Behavior

- If `id === 'new'`: redirects to `/monitoring/policy/edit/new` and returns `null` to prevent flash of content
- Otherwise: renders `<PolicyDetailsView>` with the resolved `policyId`

## Usage Example

```typescript
// Rendered automatically by Next.js for routes matching:
// /monitoring/policy/[id]

// Example: /monitoring/policy/abc-123
// → renders <PolicyDetailsView policyId="abc-123" />

// Example: /monitoring/policy/new
// → redirects to /monitoring/policy/edit/new
```
