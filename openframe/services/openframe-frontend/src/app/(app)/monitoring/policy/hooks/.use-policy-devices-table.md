Builds and returns a sorted table of policy-device compliance rows by combining paginated Fleet device data with passing/failing/pending host compliance statuses.

## Key Components

### `fetchDevicesPage(cursor)`
Fetches a single page of devices from the GraphQL API using `GET_DEVICES_QUERY`, filtering by default statuses and paginating via cursor.

### `fetchAllDevices()`
Iterates all pages from `fetchDevicesPage` until exhausted, returning the full flat array of `Device` objects.

### `usePolicyDevicesTable(policyId, assignedHostIds?)`
Main hook. Combines three data sources into a unified `PolicyDeviceRow[]` array:

- **Failing hosts** — sourced from `usePolicyResponseHosts(policyId, 'failing')`
- **Passing hosts** — sourced from `usePolicyResponseHosts(policyId, 'passing')`
- **All devices** — fetched via `useQuery` + `fetchAllDevices`, cached under `['policy-devices-table-devices']`

Compliance status priority: `non-compliant` → `pending` → `passing`. Rows are sorted by compliance status first, then alphabetically by `displayName`. Devices are deduplicated by Fleet host ID, keeping the most recently seen entry.

## Usage Example

```typescript
const { rows, isLoading, error } = usePolicyDevicesTable(
  policyId,
  assignedHostIds, // optional: [{ id: 42, hostname: 'workstation-01' }]
);

if (isLoading) return <Spinner />;
if (error) return <ErrorBanner message={error} />;

return (
  <Table
    rows={rows}
    columns={['displayName', 'osType', 'complianceStatus', 'organization']}
  />
);
```

## Return Value

| Field | Type | Description |
|-------|------|-------------|
| `rows` | `PolicyDeviceRow[]` | Sorted compliance rows ready for table rendering |
| `isLoading` | `boolean` | `true` while any data source is still loading |
| `error` | `string \| null` | Device fetch error message, if any |
