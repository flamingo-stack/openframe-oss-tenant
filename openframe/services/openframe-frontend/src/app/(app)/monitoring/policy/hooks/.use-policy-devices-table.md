Builds and returns a sorted table of policy-device compliance rows by fetching all Fleet-connected devices (via paginated GraphQL) and merging them with passing/failing/pending host status data for a given policy.

## Key Components

**`fetchDevicesPage(cursor)`**
Fetches a single paginated page of devices via GraphQL using `GET_DEVICES_QUERY`, returning the device list alongside pagination metadata.

**`fetchAllDevices()`**
Iterates through all pages using `fetchDevicesPage` until `hasNextPage` is `false`, returning the complete flat list of `Device` objects.

**`usePolicyDevicesTable(policyId, assignedHostIds?)`**
Primary hook. Combines:
- `usePolicyResponseHosts` (failing & passing compliance states)
- `useQuery` for full device list
- `useMemo` to merge and sort rows into `PolicyDeviceRow[]`

Compliance priority resolution per host:
1. `non-compliant` — from failing hosts
2. `passing` — from passing hosts (if not already marked)
3. `pending` — from `assignedHostIds` (if not already marked)

Rows are sorted by compliance status order (`non-compliant → pending → passing`), then alphabetically by `displayName`.

## Usage Example

```typescript
const { rows, isLoading, error } = usePolicyDevicesTable(
  42,
  [{ id: 101, hostname: 'macbook-pro.local' }]
);

if (isLoading) return <Spinner />;
if (error) return <ErrorMessage message={error} />;

return <DeviceTable rows={rows} />;
```

## Return Value

| Field | Type | Description |
|-------|------|-------------|
| `rows` | `PolicyDeviceRow[]` | Merged, sorted device compliance rows |
| `isLoading` | `boolean` | `true` while any data source is still loading |
| `error` | `string \| null` | Error message from the devices query, if any |
