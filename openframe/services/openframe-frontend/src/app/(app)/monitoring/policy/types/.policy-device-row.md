Defines the `ComplianceStatus` union type and `PolicyDeviceRow` interface used to represent a device row within a policy compliance view.

## Key Components

- **`ComplianceStatus`** — Union type representing a device's compliance state: `'non-compliant'`, `'passing'`, or `'pending'`
- **`PolicyDeviceRow`** — Interface describing a device entry in a policy table, including identity, organization, OS metadata, and compliance status fields

## Usage Example

```typescript
import { PolicyDeviceRow, ComplianceStatus } from './policy-device-row';

const status: ComplianceStatus = 'non-compliant';

const deviceRow: PolicyDeviceRow = {
  id: 'device-abc-123',
  hostname: 'workstation-01',
  displayName: 'Marketing Laptop',
  deviceType: 'laptop',
  organization: 'Acme Corp',
  organizationImageUrl: 'https://cdn.example.com/acme-logo.png',
  osType: 'macOS',
  complianceStatus: status,
  machineId: 'machine-xyz-456',
  fleetHostId: 42,
};
```
