Defines the `ComplianceStatus` union type and `PolicyDeviceRow` interface used to represent a device row in a policy compliance view.

## Key Components

- **`ComplianceStatus`** — Union type representing a device's compliance state: `'non-compliant'`, `'passing'`, or `'pending'`
- **`PolicyDeviceRow`** — Interface describing a flattened device record for display in policy/compliance tables, combining identity, organization, OS, and compliance metadata

## Usage Example

```typescript
import { PolicyDeviceRow, ComplianceStatus } from './policy-device-row';

const row: PolicyDeviceRow = {
  id: 'device-123',
  hostname: 'workstation-01',
  displayName: 'Marketing Laptop',
  deviceType: 'laptop',
  organization: 'Acme Corp',
  organizationImageUrl: 'https://cdn.example.com/acme.png',
  osType: 'windows',
  complianceStatus: 'passing',
  machineId: 'machine-abc',
  fleetHostId: 42,
};

function getBadgeColor(status: ComplianceStatus): string {
  switch (status) {
    case 'passing':      return 'green';
    case 'non-compliant': return 'red';
    case 'pending':      return 'yellow';
  }
}
```
