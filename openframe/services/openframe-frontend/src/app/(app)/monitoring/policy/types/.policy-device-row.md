Defines the data structure for representing a device row within a policy compliance view.

## Key Components

- **`ComplianceStatus`** — Union type indicating a device's compliance state: `'non-compliant'`, `'passing'`, or `'pending'`
- **`PolicyDeviceRow`** — Interface describing a flattened device record used in policy compliance tables, combining identity, organizational, and compliance metadata

## Usage Example

```typescript
import { PolicyDeviceRow, ComplianceStatus } from './policy-device-row';

const device: PolicyDeviceRow = {
  id: 'abc-123',
  hostname: 'workstation-01',
  displayName: 'Marketing Laptop',
  deviceType: 'laptop',
  organization: 'Acme Corp',
  organizationImageUrl: 'https://cdn.example.com/acme-logo.png',
  osType: 'windows',
  complianceStatus: 'non-compliant',
  machineId: 'machine-xyz',
  fleetHostId: 42,
};

function isCompliant(status: ComplianceStatus): boolean {
  return status === 'passing';
}
```
