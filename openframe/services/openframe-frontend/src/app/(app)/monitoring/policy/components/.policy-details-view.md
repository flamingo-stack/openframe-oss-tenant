Renders a full detail view for a single monitoring policy, including its metadata, SQL query, associated devices, and edit/delete actions.

## Key Components

- **`PolicyStatusTag`** — Internal helper component that resolves a policy's computed status and renders a styled `Tag` using `POLICY_STATUS_CONFIG`.
- **`PolicyDetailsView`** — Main exported component; accepts a `policyId` string, parses it to a numeric ID, and orchestrates data fetching, loading/error states, and action handlers.

## Key Behaviors

- Validates `policyId` is a parseable integer before fetching; renders `NotFoundError` if data is absent.
- Handles three async states: loading (`CardLoader`), error (`LoadError`), and not-found (`NotFoundError`).
- **Edit** navigates to `/monitoring/policy/edit/:policyId`.
- **Delete** triggers `deletePolicy` and redirects to `/monitoring?tab=policies` on success; guarded by a `ConfirmDeleteMonitoringModal`.
- Back navigation uses `useSafeBack` with a fallback to `/monitoring?tab=policies`.
- Renders the policy's SQL query (if present) in a read-only `ScriptEditor` with `shell="sql"`.

## Usage Example

```typescript
// app/monitoring/policy/[id]/page.tsx
import { PolicyDetailsView } from './policy-details-view';

export default function PolicyDetailPage({ params }: { params: { id: string } }) {
  return <PolicyDetailsView policyId={params.id} />;
}
```

## Props

| Prop | Type | Description |
|------|------|-------------|
| `policyId` | `string` | URL-sourced policy identifier; parsed internally to a number |
