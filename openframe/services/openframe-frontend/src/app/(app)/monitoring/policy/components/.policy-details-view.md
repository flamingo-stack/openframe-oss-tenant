Renders the full detail view for a single monitoring policy, displaying its metadata, SQL query, associated devices, and action controls (edit/delete).

## Key Components

- **`PolicyStatusTag`** — Internal helper component that maps a policy's computed status to a styled `Tag` using `POLICY_STATUS_CONFIG`.
- **`PolicyDetailsView`** — Main exported component. Accepts a `policyId` string, validates it as numeric, and orchestrates data fetching, loading/error states, and rendering.

## Key Behaviors

- Validates `policyId` before passing to `usePolicyDetails` (passes `null` for invalid IDs to prevent bad requests)
- Renders `CardLoader`, `LoadError`, or `NotFoundError` for respective loading/error/missing states
- Edit action navigates to `/monitoring/policy/edit/:id`
- Delete action uses `usePolicies().deletePolicy` with a post-success redirect to `/monitoring?tab=policies`
- Safe back navigation falls back to `/monitoring?tab=policies`

## Usage Example

```typescript
// app/monitoring/policy/[id]/page.tsx
import { PolicyDetailsView } from './components/policy-details-view';

export default function PolicyDetailPage({ params }: { params: { id: string } }) {
  return <PolicyDetailsView policyId={params.id} />;
}
```

## Props

| Prop | Type | Description |
|------|------|-------------|
| `policyId` | `string` | URL-sourced policy ID; parsed internally to a number before fetching |
