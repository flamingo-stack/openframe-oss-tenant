Fetches and caches the list of hosts that are passing or failing a specific Fleet policy, using React Query for data management.

## Key Components

- **`policyResponseHostsQueryKeys`** — Structured query key factory for cache scoping; keys are namespaced by `policyId` and `response` type (`'passing'` | `'failing'`).
- **`fetchPolicyResponseHosts`** *(internal)* — Calls `fleetApiClient.getHosts` with policy filters, fetching up to 100 hosts per page with `disable_failing_policies: true` to avoid recursive policy evaluation.
- **`usePolicyResponseHosts`** — Primary hook; accepts a nullable `policyId` (query is disabled when `null`) and a `policyResponse` filter, returning hosts, loading state, and error message.

## Usage Example

```typescript
import { usePolicyResponseHosts } from '@/hooks/use-policy-response-hosts';

function PolicyHostList({ policyId }: { policyId: number }) {
  const { hosts, isLoading, error } = usePolicyResponseHosts(policyId, 'failing');

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;

  return (
    <ul>
      {hosts.map((host) => (
        <li key={host.id}>{host.display_name}</li>
      ))}
    </ul>
  );
}
```

## Notes

- Passing `null` as `policyId` safely disables the query — useful when the policy ID is not yet resolved.
- Returns a stable `EMPTY_HOSTS` reference (module-level constant) when no data is available, preventing unnecessary re-renders from new array allocations.
- Error messages are normalized to `string | null` for consistent downstream handling.
