Provides a React Query hook for fetching Fleet hosts filtered by their compliance status (passing or failing) for a specific policy.

## Key Components

- **`policyResponseHostsQueryKeys`** — Structured query key factory for cache management, scoped by `policyId` and `response` type
- **`fetchPolicyResponseHosts`** — Async fetcher that calls `fleetApiClient.getHosts()` with policy filtering params (`policy_id`, `policy_response`, `per_page: 100`, `disable_failing_policies: true`)
- **`usePolicyResponseHosts`** — Primary exported hook; wraps the query and returns a normalized shape with `hosts`, `isLoading`, and `error`. Query is disabled when `policyId` is `null`

## Usage Example

```typescript
const { hosts, isLoading, error } = usePolicyResponseHosts(42, 'failing');

if (isLoading) return <Spinner />;
if (error) return <ErrorBanner message={error} />;

return (
  <HostList
    hosts={hosts}
    emptyMessage="No failing hosts for this policy"
  />
);
```

## Notes

- `policyId` accepts `null` to safely handle unselected/loading states — the query will not fire until a valid ID is provided
- Results are capped at **100 hosts per page** via the `per_page` param
- Returns a stable `EMPTY_HOSTS` constant (instead of a new `[]`) to prevent unnecessary re-renders when no data is available
- Error messages are normalized to `string | null` from the raw `Error` object
