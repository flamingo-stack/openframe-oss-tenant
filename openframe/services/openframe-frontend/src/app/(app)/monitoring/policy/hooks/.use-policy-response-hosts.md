Fetches and caches the list of hosts filtered by their response (passing or failing) to a specific Fleet policy, using React Query for data management.

## Key Components

- **`policyResponseHostsQueryKeys`** — Structured query key factory for cache scoping; keys are namespaced by `policyId` and `response` type.
- **`fetchPolicyResponseHosts`** — Async fetcher that calls `fleetApiClient.getHosts` with `policy_id`, `policy_response`, and a page limit of 100. Throws on non-OK responses.
- **`usePolicyResponseHosts`** — Primary hook; wraps the query and returns a stable `EMPTY_HOSTS` array reference when no data is available. Query is disabled when `policyId` is `null`.

## Usage Example

```typescript
import { usePolicyResponseHosts } from '@/hooks/use-policy-response-hosts';

function PolicyHostList({ policyId }: { policyId: number }) {
  const { hosts, isLoading, error } = usePolicyResponseHosts(policyId, 'failing');

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;

  return (
    <ul>
      {hosts.map(host => (
        <li key={host.id}>{host.hostname}</li>
      ))}
    </ul>
  );
}
```

## Notes

- Pass `null` as `policyId` to safely suspend fetching (e.g., before a policy is selected).
- Results are capped at **100 hosts per request**; pagination is not handled.
- `disable_failing_policies` is set to `true` on all requests to avoid recursive policy evaluation overhead.
