Fetches and normalizes the full device list for use in policy device selectors, handling pagination, deduplication, and Fleet/non-Fleet device separation.

## Key Components

- **`fetchAllDevices`** — Async function that paginates through the GraphQL devices endpoint (100 per page), collecting all `ONLINE` and `OFFLINE` devices into a single flat array.
- **`deduplicateByFleetId`** — Pure utility that deduplicates Fleet-managed devices by host ID, retaining the entry with the most recent `lastSeen` timestamp.
- **`usePolicyDevices`** — Primary exported hook that composes the above utilities via `useQuery`, then splits results into Fleet and non-Fleet buckets, deduplicates Fleet devices, and returns a merged list.

## Usage Example

```typescript
import { usePolicyDevices } from './use-policy-devices';

function PolicyDeviceSelector() {
  const { devices, isLoading } = usePolicyDevices();

  if (isLoading) return <Spinner />;

  return (
    <ul>
      {devices.map(device => (
        <li key={device.id}>{device.name}</li>
      ))}
    </ul>
  );
}
```

## Notes

- Pagination uses a cursor-based loop with a fixed page size of `100`.
- Fleet devices appearing across multiple records (e.g. from different MDM enrollments) are collapsed to the most recently seen entry before being merged with non-Fleet devices.
- Results are cached under the `'policy-device-selector-devices'` React Query key.
