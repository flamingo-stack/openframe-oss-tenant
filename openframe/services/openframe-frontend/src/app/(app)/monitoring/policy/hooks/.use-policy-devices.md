Fetches and normalizes the full device list for use in policy device selectors, handling GraphQL pagination and Fleet host ID deduplication.

## Key Components

- **`fetchAllDevices`** — Async function that paginates through all online/offline devices via GraphQL, collecting results across pages (100 per page)
- **`deduplicateByFleetId`** — Deduplicates Fleet-managed devices by host ID, retaining the most recently seen entry
- **`usePolicyDevices`** — Primary exported hook; returns a deduplicated, merged device list and a loading state

## Usage Example

```typescript
import { usePolicyDevices } from './use-policy-devices';

function PolicyDeviceSelector() {
  const { devices, isLoading } = usePolicyDevices();

  if (isLoading) return <Spinner />;

  return (
    <ul>
      {devices.map(device => (
        <li key={device.id}>{device.hostname}</li>
      ))}
    </ul>
  );
}
```

## Behavior Notes

- Fetches **all pages** of devices before returning — suitable for selectors that need the full list upfront
- Devices with a Fleet host ID are deduplicated; non-Fleet devices are appended as-is after deduplication
- Query is cached under the key `policy-device-selector-devices` via React Query
- Only `ONLINE` and `OFFLINE` statuses are included; devices in other states (e.g. `PENDING`) are excluded
