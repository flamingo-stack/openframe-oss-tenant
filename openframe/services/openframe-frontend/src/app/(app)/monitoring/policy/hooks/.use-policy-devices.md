Fetches and processes all devices for policy assignment, handling paginated GraphQL queries and deduplicating Fleet-managed devices by host ID.

## Key Components

- **`fetchAllDevices`** — Async function that paginates through the GraphQL devices API (100 per page), collecting all `ONLINE` and `OFFLINE` devices into a single flat array.
- **`deduplicateByFleetId`** — Deduplicates Fleet-managed devices by host ID, retaining the entry with the most recent `lastSeen` timestamp.
- **`usePolicyDevices`** — Primary hook that orchestrates fetching and memoized deduplication, returning a merged list of deduplicated Fleet devices followed by non-Fleet devices.

## Usage Example

```typescript
import { usePolicyDevices } from './use-policy-devices';

function PolicyDeviceSelector() {
  const { devices, isLoading } = usePolicyDevices();

  if (isLoading) return <Spinner />;

  return (
    <ul>
      {devices.map(device => (
        <li key={device.id}>{device.hostname}</li>
      ))}
    </ul>
  );
}
```

## Notes

- Query key `policy-device-selector-devices` is used for React Query caching; invalidate it when device state changes upstream.
- Fleet devices and non-Fleet devices are kept in separate buckets before merging, preserving ordering (Fleet-deduplicated first, non-Fleet appended).
- Throws an explicit error on failed API responses or missing GraphQL `data`, surfacing via `devicesQuery.error` in the consuming component.
