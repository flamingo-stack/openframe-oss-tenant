Renders a data table displaying devices assigned to a specific compliance policy, showing device identity, customer organization, OS type, and compliance status with navigation support.

## Key Components

- **`PolicyDevicesTable`** — Main exported component accepting `policyId` and optional `assignedHostIds` props
- **`usePolicyDevicesTable`** — Custom hook that fetches and shapes device rows for the given policy
- **Column Definitions** — Five columns: `device`, `organization`, `os`, `compliance`, and an `open` action
- **`policyDeviceRowHref`** — Row-level navigation callback routing to `/devices/details/:machineId`

## Column Breakdown

| Column | Content | Responsive Behavior |
|--------|---------|-------------------|
| `device` | Device type icon + display name | Always visible |
| `organization` | Entity image + org name | Hidden below `lg` |
| `os` | `OSTypeBadge` | Hidden below `md` |
| `compliance` | `Tag` with `pending` / `non-compliant` / `passing` variants | Always visible |
| `open` | External link button → `/devices/details/:machineId` | Always visible |

## Usage Example

```typescript
import { PolicyDevicesTable } from './policy-devices-table';

// Basic usage with only a policy ID
<PolicyDevicesTable policyId={42} />

// With pre-resolved host assignments
<PolicyDevicesTable
  policyId={42}
  assignedHostIds={[
    { id: 1, hostname: 'workstation-01' },
    { id: 2, hostname: 'server-prod' },
  ]}
/>
```

## Notes

- Row clicks navigate to the device detail page; the open-in-new-tab button uses `data-no-row-click` to prevent double navigation
- Sorting is disabled across all columns
- Displays 5 skeleton rows during loading and an empty state message when no devices are assigned
