Renders a data table of devices assigned to a compliance policy, displaying device info, customer organization, OS type, and compliance status with navigation to device detail pages.

## Key Components

- **`PolicyDevicesTable`** — Main exported component accepting `policyId` and optional `assignedHostIds` props
- **`usePolicyDevicesTable`** — Custom hook (external) that fetches and transforms device rows for the given policy
- **Column definitions** — Five columns: `device`, `organization`, `os`, `compliance`, and `open` (external link)
- **`PolicyDeviceRow`** — Row type driving column accessors (`displayName`, `hostname`, `osType`, `complianceStatus`, `machineId`, etc.)

## Usage Example

```typescript
import { PolicyDevicesTable } from './policy-devices-table';

// Basic usage with policy ID only
<PolicyDevicesTable policyId={42} />

// With pre-fetched assigned host IDs to filter results
<PolicyDevicesTable
  policyId={42}
  assignedHostIds={[
    { id: 1, hostname: 'workstation-01' },
    { id: 2, hostname: 'server-02' },
  ]}
/>
```

## Column Behaviour

| Column | Visibility | Notes |
|--------|-----------|-------|
| `device` | Always | Shows device type icon + display name or hostname |
| `organization` | Hidden `< lg` | Entity image + org name |
| `os` | Hidden `< md` | `OSTypeBadge` component |
| `compliance` | Always | `warning` / `error` / `success` `Tag` variant |
| `open` | Always | Opens `/devices/details/:machineId` in a new tab; hidden if no `machineId` |

Rows are clickable and navigate to `/devices/details/:machineId` when a `machineId` is present. Sorting is disabled across all columns.
