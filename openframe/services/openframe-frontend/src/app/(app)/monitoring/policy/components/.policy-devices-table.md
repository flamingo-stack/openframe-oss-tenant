Renders a data table displaying devices assigned to a compliance policy, showing device name, customer organization, OS type, and compliance status with navigation support.

## Key Components

- **`PolicyDevicesTable`** — Main exported component accepting `policyId` and optional `assignedHostIds` props
- **`usePolicyDevicesTable`** — Custom hook that fetches and formats device rows for the given policy
- **`columns`** — Memoized column definitions for: Device, Customer, OS, Compliance Status, and an external link action
- **`policyDeviceRowHref`** — Callback that resolves each row's navigation URL to `/devices/details/:machineId`

## Column Structure

| Column | Content |
|--------|---------|
| `DEVICE` | Device type icon + display name or hostname |
| `CUSTOMER` | Organization logo + name |
| `OS` | `OSTypeBadge` for the OS type |
| `STATUS` | `Tag` with `success`, `warning`, or `error` variant based on compliance |
| *(action)* | Button to open device details in a new tab |

## Usage Example

```typescript
import { PolicyDevicesTable } from './policy-devices-table';

// Render assigned devices for a policy
<PolicyDevicesTable
  policyId={42}
  assignedHostIds={[
    { id: 1, hostname: 'DESKTOP-ABC123' },
    { id: 2, hostname: 'LAPTOP-XYZ789' },
  ]}
/>

// Minimal usage — loads all devices for the policy
<PolicyDevicesTable policyId={42} />
```

Rows are clickable and navigate to `/devices/details/:machineId`. The open-in-new-tab button uses `data-no-row-click` to prevent triggering row navigation.
