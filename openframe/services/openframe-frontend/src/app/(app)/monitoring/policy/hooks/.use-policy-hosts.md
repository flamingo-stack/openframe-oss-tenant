React Query hooks for fetching and mutating the list of hosts assigned to a Fleet policy, with paginated data loading and cache invalidation.

## Key Components

**Query Keys**
- `policyHostsQueryKeys.all` — base key for all policy-host queries
- `policyHostsQueryKeys.list(policyId)` — scoped key for a specific policy's host list

**API Functions**
- `fetchAllPolicyHosts(policyId)` — paginates through all pages (`per_page: 100`) until `has_next_results` is false, returning a flat `PolicyHost[]`
- `replacePolicyHostsApi(params)` — calls the Fleet API to atomically replace the host list for a policy

**Hooks**
- `usePolicyHosts(policyId)` — queries all hosts for a given policy; returns `hosts`, `isLoading`, `error`, and `refetch`; disabled when `policyId` is `null`
- `useReplacePolicyHosts()` — mutation hook that replaces policy hosts, then invalidates both the policy-hosts list and the parent `policiesQueryKeys.all` cache; shows a toast on error

## Usage Example

```typescript
// Read policy hosts
const { hosts, isLoading, error } = usePolicyHosts(42);

// Replace policy hosts
const { mutate: replaceHosts } = useReplacePolicyHosts();

replaceHosts(
  { policyId: 42, hostIds: [1, 2, 3] },
  {
    onSuccess: () => console.log('Hosts updated'),
  }
);
```
