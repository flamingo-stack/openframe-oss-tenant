React Query hooks for fetching and replacing the list of hosts associated with a Fleet policy, with automatic pagination and cache invalidation.

## Key Components

**Query Keys**
- `policyHostsQueryKeys.all` — base key for all policy host queries
- `policyHostsQueryKeys.list(policyId)` — scoped key for a specific policy's host list

**API Functions** *(internal)*
- `fetchAllPolicyHosts(policyId)` — paginates through all hosts for a policy (`per_page: 100`) until `has_next_results` is false
- `replacePolicyHostsApi({ policyId, hostIds })` — replaces the full host assignment on a policy

**Hooks**
- `usePolicyHosts(policyId)` — queries hosts for a given policy; skips the request when `policyId` is `null`
- `useReplacePolicyHosts()` — mutation that replaces policy hosts, then invalidates both the policy host list and the parent policies query; surfaces errors via toast

## Usage Example

```typescript
// Read policy hosts
const { hosts, isLoading, error } = usePolicyHosts(42);

// Replace assigned hosts
const { mutate: replacePolicyHosts } = useReplacePolicyHosts();

replacePolicyHosts(
  { policyId: 42, hostIds: [1, 2, 3] },
  { onSuccess: () => console.log('Hosts updated') }
);
```

## Notes

- `policyId: null` disables the query entirely — safe to call before a policy is selected
- On a successful replacement, both `policyHostsQueryKeys.list(policyId)` and `policiesQueryKeys.all` are invalidated, keeping policy-level counters in sync
- Pagination is handled transparently; consumers always receive the full host array
