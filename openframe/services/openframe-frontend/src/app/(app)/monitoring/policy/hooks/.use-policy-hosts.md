Provides React Query hooks for fetching and replacing hosts assigned to a Fleet policy, with automatic pagination and cache invalidation.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `policyHostsQueryKeys` | Object | Structured React Query cache key factory for policy host queries |
| `usePolicyHosts` | Hook | Fetches all hosts for a given policy ID with automatic pagination |
| `useReplacePolicyHosts` | Hook | Mutation hook to replace the full host list for a policy |

## Usage Example

```typescript
// Fetch all hosts assigned to a policy
function PolicyHostList({ policyId }: { policyId: number }) {
  const { hosts, isLoading, error } = usePolicyHosts(policyId);

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;

  return <HostTable rows={hosts} />;
}

// Replace assigned hosts
function PolicyHostEditor({ policyId }: { policyId: number }) {
  const replaceMutation = useReplacePolicyHosts();

  const handleSave = (selectedHostIds: number[]) => {
    replaceMutation.mutate({ policyId, hostIds: selectedHostIds });
  };

  return <HostPicker onSave={handleSave} />;
}
```

## Notes

- `usePolicyHosts` accepts `null` as `policyId` and disables the query until a valid ID is provided.
- `fetchAllPolicyHosts` handles server-side pagination internally (100 hosts per page), resolving a flat array of all results.
- On successful replacement, both the specific policy host list and the parent `policiesQueryKeys.all` cache are invalidated to keep related queries in sync.
