React Query hook for fetching a single Fleet policy by ID, wrapping the `fleetApiClient.getPolicy` call with loading, error, and refetch state.

## Key Components

- **`fetchPolicy(id)`** — Internal async function that calls `fleetApiClient.getPolicy`, throws on non-OK responses or missing data.
- **`usePolicyDetails(policyId)`** — Primary exported hook; accepts a nullable policy ID and returns normalized query state. Query is disabled when `policyId` is `null`.

## Usage Example

```typescript
import { usePolicyDetails } from './use-policy-details';

function PolicyDetailPanel({ policyId }: { policyId: number | null }) {
  const { policyDetails, isLoading, error, refetch } = usePolicyDetails(policyId);

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error} onRetry={refetch} />;
  if (!policyDetails) return null;

  return <pre>{JSON.stringify(policyDetails, null, 2)}</pre>;
}
```

## Return Shape

| Field | Type | Description |
|---|---|---|
| `policyDetails` | `Policy \| null` | Fetched policy data, or `null` if not yet loaded |
| `isLoading` | `boolean` | `true` while the request is in-flight |
| `error` | `string \| null` | Error message string, or `null` on success |
| `refetch` | `function` | Manually re-triggers the query |

## Notes

- Uses `policiesQueryKeys.detail(policyId)` for cache key consistency with the broader policies query namespace.
- The query is conditionally enabled — passing `null` as `policyId` prevents any fetch from firing.
