React Query hook for fetching a single Fleet policy by ID, exposing a simplified interface with `policyDetails`, loading state, error message, and a refetch function.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `usePolicyDetails` | Hook | Fetches and returns a single policy by numeric ID |
| `fetchPolicy` | Internal async fn | Calls `fleetApiClient.getPolicy(id)` and normalizes errors |

## Usage Example

```typescript
import { usePolicyDetails } from './use-policy-details';

function PolicyDetailPanel({ policyId }: { policyId: number | null }) {
  const { policyDetails, isLoading, error, refetch } = usePolicyDetails(policyId);

  if (isLoading) return <Spinner />;
  if (error) return <ErrorBanner message={error} onRetry={refetch} />;
  if (!policyDetails) return null;

  return <pre>{JSON.stringify(policyDetails, null, 2)}</pre>;
}
```

## Behavior Notes

- **Disabled when `null`** — the query does not execute if `policyId` is `null`, making it safe to call unconditionally before an ID is selected.
- **Error normalization** — both API-level errors (`res.error`) and HTTP status failures are surfaced as a plain `string | null` rather than an `Error` object.
- **Cache key** — reuses `policiesQueryKeys.detail(id)` from the shared `use-policies` hook, so detail fetches share the same React Query cache namespace as the policies list.
