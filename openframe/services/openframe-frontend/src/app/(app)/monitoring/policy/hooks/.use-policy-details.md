React Query hook for fetching a single Fleet policy by ID, with conditional fetching when a policy ID is provided.

## Key Components

- **`fetchPolicy(id)`** — Internal async function that calls `fleetApiClient.getPolicy(id)` and throws on failed or empty responses
- **`usePolicyDetails(policyId)`** — Primary exported hook that wraps React Query's `useQuery`, disabled when `policyId` is `null`

## Usage Example

```typescript
import { usePolicyDetails } from './use-policy-details';

function PolicyDetailPanel({ policyId }: { policyId: number | null }) {
  const { policyDetails, isLoading, error, refetch } = usePolicyDetails(policyId);

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;
  if (!policyDetails) return null;

  return <PolicyView policy={policyDetails} onRefresh={refetch} />;
}
```

## Return Shape

| Field | Type | Description |
|---|---|---|
| `policyDetails` | `Policy \| null` | Fetched policy data, or `null` if unavailable |
| `isLoading` | `boolean` | `true` while the request is in flight |
| `error` | `string \| null` | Error message string, or `null` on success |
| `refetch` | `function` | Manually re-triggers the query |

> The query is **skipped entirely** when `policyId` is `null`, preventing unnecessary API calls when no policy is selected.
