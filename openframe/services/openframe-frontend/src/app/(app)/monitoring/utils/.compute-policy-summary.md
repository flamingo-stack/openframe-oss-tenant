Computes policy compliance statistics and determines individual policy statuses from a list of Fleet/MDM policies.

## Key Components

- **`PolicyStatus`** — Union type: `'compliant' | 'failing' | 'pending' | 'partial'`
- **`POLICY_STATUS_CONFIG`** — Display config map (label + badge variant) for each `PolicyStatus`
- **`getPolicyStatus(policy)`** — Derives a single policy's status based on passing/failing/missing host counts
- **`computePolicySummary(policies)`** — Aggregates a policy list into a `PolicySummaryStats` object with counts and percentages

## Status Logic

| Status | Condition |
|--------|-----------|
| `pending` | No hosts have responded yet (`responded === 0` and hosts are expected) |
| `partial` | Some hosts responded but others are missing |
| `failing` | All expected hosts responded, at least one is failing |
| `compliant` | All expected hosts responded and none are failing |

> **Note:** `pending` and `partial` policies are excluded from compliance percentage calculations — only `compliant` and `failing` policies count toward `resolvedPolicies`.

## Usage Example

```typescript
import { computePolicySummary, getPolicyStatus } from './compute-policy-summary';

const policies: Policy[] = await fetchPolicies();

// Single policy status
const status = getPolicyStatus(policies[0]);
// → 'compliant' | 'failing' | 'pending' | 'partial'

// Aggregate summary
const summary = computePolicySummary(policies);
// {
//   totalPolicies: 10,
//   failingPolicies: 2,
//   failingPoliciesPercentage: 25,
//   compliantPolicies: 6,
//   compliantPoliciesPercentage: 75,
//   lastUpdatedAt: '2024-01-15T10:30:00Z',
// }
```
