Computes policy compliance status and summary statistics from a list of Fleet/MDM policies, categorizing each as compliant, failing, pending, or partial based on host response counts.

## Key Components

- **`PolicyStatus`** — Union type: `'compliant' | 'failing' | 'pending' | 'partial'`
- **`POLICY_STATUS_CONFIG`** — Display config map (label + badge variant) for each status
- **`getPolicyStatus(policy)`** — Derives a single `PolicyStatus` for a policy based on passing/failing/missing host counts
- **`computePolicySummary(policies)`** — Aggregates a list of policies into a `PolicySummaryStats` object; only `compliant` and `failing` policies count toward percentages

## Status Logic

| Condition | Status |
|---|---|
| No hosts responded, some missing | `pending` |
| Some responded, some missing | `partial` |
| All responded, any failing | `failing` |
| All responded, none failing | `compliant` |

> **Note:** Percentages are calculated over *resolved* policies only (`compliant + failing`). `pending` and `partial` policies are excluded from compliance stats but still counted in `totalPolicies`.

## Usage Example

```typescript
import { computePolicySummary, getPolicyStatus } from './compute-policy-summary';

// Single policy status
const status = getPolicyStatus(policy);
// → 'compliant' | 'failing' | 'pending' | 'partial'

// Aggregate summary for a dashboard
const summary = computePolicySummary(policies);
// {
//   totalPolicies: 10,
//   failingPolicies: 2,
//   failingPoliciesPercentage: 25,
//   compliantPolicies: 6,
//   compliantPoliciesPercentage: 75,
//   lastUpdatedAt: '2024-01-15T10:30:00Z'
// }
```
