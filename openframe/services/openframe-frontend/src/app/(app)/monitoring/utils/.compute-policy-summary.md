Computes policy compliance status and summary statistics from a list of Fleet/MDM policies, determining whether each policy is compliant, failing, pending, or partial based on host response counts.

## Key Components

- **`PolicyStatus`** — Union type: `'compliant' | 'failing' | 'pending' | 'partial'`
- **`POLICY_STATUS_CONFIG`** — Display config map (label + badge variant) for each status
- **`getPolicyStatus(policy)`** — Derives a single `PolicyStatus` for a policy based on passing/failing/missing host counts
- **`computePolicySummary(policies)`** — Aggregates a list of policies into a `PolicySummaryStats` object; only `compliant` and `failing` policies count toward percentage calculations

## Status Logic

| Condition | Status |
|-----------|--------|
| No hosts responded, some missing | `pending` |
| Some responded, some missing | `partial` |
| All responded, some failing | `failing` |
| All responded, none failing | `compliant` |

> `pending` and `partial` policies are excluded from compliance percentages — only definitively resolved policies are used as the denominator.

## Usage Example

```typescript
import { getPolicyStatus, computePolicySummary } from './compute-policy-summary';

const status = getPolicyStatus(policy);
// → 'compliant' | 'failing' | 'pending' | 'partial'

const summary = computePolicySummary(policies);
// → {
//     totalPolicies: 10,
//     failingPolicies: 2,
//     failingPoliciesPercentage: 25,
//     compliantPolicies: 6,
//     compliantPoliciesPercentage: 75,
//     lastUpdatedAt: '2024-11-01T12:00:00Z'
//   }

// Use status config for UI rendering
const { label, variant } = POLICY_STATUS_CONFIG[status];
// → { label: 'Failing', variant: 'error' }
```
