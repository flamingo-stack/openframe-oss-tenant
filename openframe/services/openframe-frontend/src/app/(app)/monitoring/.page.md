Monitoring page entry point that renders the full-screen monitoring dashboard within a padded content container.

## Key Components

- **`Monitoring`** — Default export; top-level page component for the `/monitoring` route
- **`ContentPageContainer`** — Layout wrapper from `@flamingo-stack/openframe-frontend-core` that provides consistent page structure without a header
- **`MonitoringView`** — Primary monitoring dashboard component rendering the main content

## Usage Example

```typescript
// Rendered automatically by Next.js App Router at /monitoring
// No manual instantiation required

// ContentPageContainer configuration used:
<ContentPageContainer
  className="p-[var(--spacing-system-l)]"
  padding="none"
  showHeader={false}
>
  <MonitoringView />
</ContentPageContainer>
```

## Notes

- Marked as `'use client'` — runs exclusively on the client side
- `dynamic = 'force-dynamic'` disables static generation, ensuring the page is always server-rendered fresh on each request (useful for live monitoring data)
- Header is hidden (`showHeader={false}`) to maximize dashboard real estate
- Spacing uses the design system token `--spacing-system-l` for consistent padding
