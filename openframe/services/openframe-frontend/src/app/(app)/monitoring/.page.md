A Next.js client-side page component that renders the Monitoring section within the OpenFrame platform.

## Key Components

- **`Monitoring`** — Default page export that wraps the monitoring UI in a `ContentPageContainer` with system-level padding and no header.
- **`ContentPageContainer`** — Layout wrapper from `@flamingo-stack/openframe-frontend-core` providing consistent page structure.
- **`MonitoringView`** — The primary monitoring UI component rendered within the page.

## Usage Example

```typescript
// Rendered automatically by Next.js App Router at the /monitoring route.
// No manual instantiation required.

// ContentPageContainer props used:
// - className: applies CSS variable-based padding
// - padding="none": disables default padding
// - showHeader={false}: hides the page header
```

> `export const dynamic = 'force-dynamic'` disables static generation, ensuring the page is always server-rendered at request time — suitable for live monitoring data.
