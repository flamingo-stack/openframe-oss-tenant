React Query hook for managing Fleet device policies — handles listing, creating, updating, and deleting policies with built-in toast notifications and cache invalidation.

## Key Components

### `policiesQueryKeys`
Structured query key factory for consistent React Query cache management:
- `all` — base key for all policy queries
- `list(params?)` — scoped to filtered/team-specific lists
- `detail(id)` — scoped to a single policy by ID

### `usePolicies(params?)`
Primary hook exposing full CRUD operations for policies. Accepts optional `ListPoliciesParams` (`team_id`, `query`) to filter results.

**Returns:**

| Property | Type | Description |
|----------|------|-------------|
| `policies` | `Policy[]` | Fetched list, defaults to `[]` |
| `isLoading` | `boolean` | Query loading state |
| `error` | `string \| null` | Error message if fetch failed |
| `refetch` | `function` | Manually re-trigger the list query |
| `createPolicy` | `function` | Creates a policy with success/error callbacks |
| `isCreating` | `boolean` | Mutation pending state |
| `updatePolicy` | `function` | Updates a policy by ID |
| `isUpdating` | `boolean` | Mutation pending state |
| `deletePolicy` | `function` | Deletes a policy by ID |
| `isDeleting` | `boolean` | Mutation pending state |
| `policiesQuery` | `UseQueryResult` | Raw query object for advanced use |

## Usage Example

```typescript
import { usePolicies } from '@/features/policies/hooks/use-policies';

function PoliciesPanel({ teamId }: { teamId: number }) {
  const {
    policies,
    isLoading,
    createPolicy,
    isCreating,
    deletePolicy,
  } = usePolicies({ team_id: teamId });

  const handleCreate = () => {
    createPolicy(
      {
        name: 'Firewall Enabled',
        query: 'SELECT * FROM iptables WHERE ...',
        description: 'Ensure firewall is active',
        critical: true,
        team_id: teamId,
      },
      {
        onSuccess: (policy) => console.log('Created:', policy.id),
        onError: (err) => console.error(err.message),
      }
    );
  };

  if (isLoading) return <Spinner />;

  return (
    <>
      {policies.map(p => (
        <PolicyRow key={p.id} policy={p} onDelete={() => deletePolicy(p.id)} />
      ))}
      <button onClick={handleCreate} disabled={isCreating}>
        Add Policy
      </button>
    </>
  );
}
```

> All mutations automatically invalidate the `policies` cache on success and display toast notifications via `useToast`.
