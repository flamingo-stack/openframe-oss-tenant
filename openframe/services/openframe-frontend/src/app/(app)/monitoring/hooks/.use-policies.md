React Query hook for managing Fleet device policies — handles listing, creating, updating, and deleting policies with automatic cache invalidation and toast notifications.

## Key Components

**`policiesQueryKeys`** — Structured query key factory for consistent cache management across list and detail queries.

**`usePolicies(params?)`** — Primary hook that composes all policy operations into a single interface.

**Internal API functions** — `fetchPolicies`, `createPolicyApi`, `updatePolicyApi`, `deletePolicyApi` wrap `fleetApiClient` calls with normalized error handling.

### Hook Return Values

| Property | Type | Description |
|---|---|---|
| `policies` | `Policy[]` | Fetched policy list (defaults to `[]`) |
| `isLoading` | `boolean` | Query loading state |
| `error` | `string \| null` | Error message if query failed |
| `createPolicy` | `fn` | Create with success/error callbacks |
| `updatePolicy` | `fn` | Update by ID with partial data |
| `deletePolicy` | `fn` | Delete by ID |
| `isCreating/isUpdating/isDeleting` | `boolean` | Mutation pending states |
| `policiesQuery` | `UseQueryResult` | Raw query for advanced use cases |

## Usage Example

```typescript
import { usePolicies } from './use-policies';

function PoliciesPanel({ teamId }: { teamId: number }) {
  const {
    policies,
    isLoading,
    createPolicy,
    isCreating,
    deletePolicy,
  } = usePolicies({ team_id: teamId });

  const handleCreate = () => {
    createPolicy(
      {
        name: 'Disk Encryption Check',
        query: 'SELECT 1 FROM disk_encryption WHERE encrypted = 1;',
        description: 'Ensures disk encryption is enabled',
        platform: 'darwin',
        critical: true,
      },
      {
        onSuccess: (policy) => console.log('Created:', policy.id),
        onError: (err) => console.error(err),
      }
    );
  };

  if (isLoading) return <Spinner />;

  return (
    <ul>
      {policies.map(p => (
        <li key={p.id}>
          {p.name}
          <button onClick={() => deletePolicy(p.id)}>Remove</button>
        </li>
      ))}
      <button onClick={handleCreate} disabled={isCreating}>
        Add Policy
      </button>
    </ul>
  );
}
```

> All mutations automatically invalidate the `['policies']` cache key and display toast notifications on success or failure via `handleApiError`.
