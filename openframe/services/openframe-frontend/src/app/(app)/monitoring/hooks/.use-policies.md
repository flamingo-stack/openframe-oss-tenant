React Query hook for managing Fleet policies — handles listing, creating, updating, and deleting policies with automatic cache invalidation and toast notifications.

## Key Components

**`policiesQueryKeys`** — Structured query key factory for consistent cache management across list and detail queries.

**`usePolicies(params?)`** — Primary hook exposing:
- `policies` — fetched policy array (defaults to `[]`)
- `isLoading`, `error` — query state
- `refetch` — manual refetch trigger
- `createPolicy(data, options?)` — creates a policy with success/error callbacks
- `updatePolicy(id, data, options?)` — partial update by ID
- `deletePolicy(id, options?)` — removes a policy by ID
- `isCreating`, `isUpdating`, `isDeleting` — mutation pending states
- `policiesQuery` — raw TanStack Query object for advanced use

**Interfaces**
- `ListPoliciesParams` — optional `team_id` and `query` filters
- `CreatePolicyData` — full policy creation payload
- `UpdatePolicyData` — wraps `id` + partial `CreatePolicyData`

## Usage Example

```typescript
import { usePolicies } from './use-policies';

function PoliciesPanel() {
  const { policies, isLoading, createPolicy, deletePolicy } = usePolicies({
    team_id: 42,
  });

  const handleCreate = () => {
    createPolicy(
      { name: 'Disk Encryption', query: 'SELECT...', description: 'Ensure disk is encrypted' },
      {
        onSuccess: (policy) => console.log('Created:', policy.id),
        onError: (err) => console.error(err),
      },
    );
  };

  if (isLoading) return <Spinner />;

  return (
    <>
      {policies.map(p => (
        <PolicyRow key={p.id} policy={p} onDelete={() => deletePolicy(p.id)} />
      ))}
      <button onClick={handleCreate}>Add Policy</button>
    </>
  );
}
```

> All mutations automatically invalidate the `['policies']` cache and surface success/error feedback via toast notifications.
