React Query hook for managing fleet labels (categories), providing list, create, and delete operations with toast notifications and cache invalidation.

## Key Components

### `labelsQueryKeys`
Structured query key factory for TanStack Query cache management:
- `labelsQueryKeys.all` — root key `['labels']`
- `labelsQueryKeys.list()` — scoped key for the labels list query

### `useLabels()` Hook
Primary export. Combines data fetching and mutations into a single interface:

| Return Value | Type | Description |
|---|---|---|
| `labels` | `FleetLabel[]` | Fetched labels, defaults to `[]` |
| `isLoading` | `boolean` | Fetch in-progress state |
| `error` | `string \| null` | Fetch error message |
| `createLabel` | `function` | Creates a label by name |
| `isCreating` | `boolean` | Create mutation pending state |
| `deleteLabel` | `function` | Deletes a label by numeric ID |
| `isDeleting` | `boolean` | Delete mutation pending state |

## Usage Example

```typescript
import { useLabels } from '@/hooks/use-labels';

function LabelManager() {
  const {
    labels,
    isLoading,
    createLabel,
    isCreating,
    deleteLabel,
  } = useLabels();

  const handleCreate = () => {
    createLabel('Workstations', {
      onSuccess: (label) => console.log('Created:', label),
      onError: (err) => console.error(err),
    });
  };

  const handleDelete = (id: number) => {
    deleteLabel(id, {
      onSuccess: () => console.log('Deleted'),
    });
  };

  if (isLoading) return <span>Loading...</span>;

  return (
    <>
      {labels.map(l => (
        <div key={l.id}>
          {l.name}
          <button onClick={() => handleDelete(l.id)}>Remove</button>
        </div>
      ))}
      <button onClick={handleCreate} disabled={isCreating}>
        Add Label
      </button>
    </>
  );
}
```

Both `createLabel` and `deleteLabel` automatically invalidate the labels cache on success and surface toast notifications for success and error states via `handleApiError`.
