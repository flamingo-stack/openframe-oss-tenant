React hook for managing Fleet labels (categories) via TanStack Query, providing list, create, and delete operations with toast notifications and cache invalidation.

## Key Components

**`labelsQueryKeys`** — Structured query key factory for consistent cache management:
- `labelsQueryKeys.all` — root key for all label queries
- `labelsQueryKeys.list()` — scoped key for the label list query

**`useLabels()`** — Primary hook export returning:

| Return Value | Type | Description |
|---|---|---|
| `labels` | `FleetLabel[]` | Fetched labels, defaults to `[]` |
| `isLoading` | `boolean` | Fetch in-flight indicator |
| `error` | `string \| null` | Fetch error message |
| `createLabel` | `function` | Creates a label with optional callbacks |
| `isCreating` | `boolean` | Create mutation pending state |
| `deleteLabel` | `function` | Deletes a label by ID with optional callbacks |
| `isDeleting` | `boolean` | Delete mutation pending state |

## Usage Example

```typescript
import { useLabels } from '@/hooks/use-labels';

function LabelsManager() {
  const {
    labels,
    isLoading,
    error,
    createLabel,
    isCreating,
    deleteLabel,
    isDeleting,
  } = useLabels();

  const handleCreate = () => {
    createLabel('Workstations', {
      onSuccess: (label) => console.log('Created:', label),
      onError: (err) => console.error('Error:', err),
    });
  };

  const handleDelete = (id: number) => {
    deleteLabel(id, {
      onSuccess: () => console.log('Deleted'),
    });
  };

  if (isLoading) return <Spinner />;
  if (error) return <p>{error}</p>;

  return (
    <ul>
      {labels.map(label => (
        <li key={label.id}>
          {label.name}
          <button onClick={() => handleDelete(label.id)} disabled={isDeleting}>
            Remove
          </button>
        </li>
      ))}
      <button onClick={handleCreate} disabled={isCreating}>
        Add Label
      </button>
    </ul>
  );
}
```

> Both `createLabel` and `deleteLabel` automatically invalidate the labels cache on success and display toast notifications via `useToast`. Error handling is delegated to `handleApiError`.
