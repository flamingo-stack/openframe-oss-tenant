React Query hook for managing Fleet labels (categories), providing list, create, and delete operations with toast notifications and cache invalidation.

## Key Components

### `labelsQueryKeys`
Structured query key factory for TanStack Query cache management:
- `all` — base key `['labels']`
- `list()` — scoped key for the labels list query

### `useLabels()` Hook
Primary export. Composes label CRUD operations into a single interface.

**Returns:**

| Property | Type | Description |
|----------|------|-------------|
| `labels` | `FleetLabel[]` | Fetched labels list (defaults to `[]`) |
| `isLoading` | `boolean` | Fetch in-flight state |
| `error` | `string \| null` | Fetch error message |
| `createLabel` | `fn` | Creates a label by name with optional callbacks |
| `isCreating` | `boolean` | Create mutation pending state |
| `deleteLabel` | `fn` | Deletes a label by ID with optional callbacks |
| `isDeleting` | `boolean` | Delete mutation pending state |

## Usage Example

```typescript
import { useLabels } from '@/hooks/use-labels';

function LabelsManager() {
  const {
    labels,
    isLoading,
    createLabel,
    isCreating,
    deleteLabel,
    isDeleting,
  } = useLabels();

  const handleCreate = () => {
    createLabel('Workstations', {
      onSuccess: (label) => console.log('Created:', label),
      onError: (err) => console.error(err),
    });
  };

  const handleDelete = (id: number) => {
    deleteLabel(id, {
      onSuccess: () => console.log('Deleted'),
    });
  };

  if (isLoading) return <Spinner />;

  return (
    <ul>
      {labels.map(label => (
        <li key={label.id}>
          {label.name}
          <button
            onClick={() => handleDelete(label.id)}
            disabled={isDeleting}
          >
            Remove
          </button>
        </li>
      ))}
      <button onClick={handleCreate} disabled={isCreating}>
        Add Label
      </button>
    </ul>
  );
}
```

> Both `createLabel` and `deleteLabel` automatically show success/error toast notifications and invalidate the labels cache on completion.
