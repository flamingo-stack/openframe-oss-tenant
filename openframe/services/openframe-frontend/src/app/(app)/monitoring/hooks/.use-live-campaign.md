React hook that manages the full lifecycle of a Fleet live query campaign — creating the campaign via the Fleet API, establishing a SockJS-over-WebSocket connection, and streaming real-time query results, errors, and status updates back to the caller.

## Key Components

**Exported Types**
- `CampaignError` — per-host error with display name, osquery version, and error string
- `CampaignEmptyResult` — host that responded with zero rows
- `CampaignTotals` — aggregate counts (total, online, offline, missing in action)
- `UseLiveCampaignReturn` — full return shape of the hook

**Internal Utilities**
- `buildWsUrl(httpUrl)` — converts an HTTP(S) URL to a WS(S) URL for the SockJS transport
- `encodeSockJsMessage(msg)` — serializes an outbound SockJS frame
- `parseSockJsFrame(raw)` — parses inbound SockJS frames (`o`, `h`, `a`, `c`)
- `getAllHostsLabelId()` — fetches and caches the Fleet "All Hosts" dynamic label ID
- `fetchFleetApiToken()` — retrieves the Fleet MDM API token via a GraphQL query

**Hook: `useLiveCampaign()`**
- `startCampaign(sql, hostIds)` — creates a Fleet campaign and opens a WebSocket; targets selected hosts or falls back to all hosts
- `stopCampaign()` — tears down the WebSocket and timeout, marks campaign finished
- Internal message handler routes `totals`, `result`, `status`, and `error` frames, enforcing a hard limit of 250 000 rows and a 5-minute timeout

## Usage Example

```typescript
import { useLiveCampaign } from './use-live-campaign';

function LiveQueryPanel() {
  const {
    startCampaign,
    stopCampaign,
    isRunning,
    results,
    errors,
    totals,
    hostsResponded,
    hostsFailed,
    connectionState,
    campaignStatus,
  } = useLiveCampaign();

  const handleRun = () => {
    startCampaign('SELECT * FROM os_version;', []);
  };

  return (
    <div>
      <button onClick={handleRun} disabled={isRunning}>Run</button>
      <button onClick={stopCampaign} disabled={!isRunning}>Stop</button>
      <p>State: {connectionState} | Status: {campaignStatus}</p>
      <p>Responded: {hostsResponded} | Failed: {hostsFailed}</p>
      {totals && <p>Online hosts: {totals.online} / {totals.count}</p>}
      <pre>{JSON.stringify(results.slice(0, 5), null, 2)}</pre>
    </div>
  );
}
```
