Manages a live Fleet MDM osquery campaign over a SockJS-framed WebSocket connection, streaming real-time query results, errors, and host totals back to the caller.

## Key Components

### Types & Interfaces

- **`CampaignError`** — Per-host error detail including `host_id`, `host_display_name`, `osquery_version`, and `error` message
- **`CampaignEmptyResult`** — Host that responded with zero rows
- **`CampaignTotals`** — Aggregate counts: `count`, `online`, `offline`, `missing_in_action`
- **`UseLiveCampaignReturn`** — Full public surface of the hook

### Internal Helpers

- **`buildWsUrl(httpUrl)`** — Converts `http(s)://` to `ws(s)://` for the SockJS endpoint
- **`encodeSockJsMessage(msg)`** — Serializes outbound SockJS frames
- **`parseSockJsFrame(raw)`** — Decodes inbound SockJS frames (`o`, `h`, `a`, `c`)
- **`getAllHostsLabelId()`** — Cached lookup of the Fleet "All Hosts" dynamic label ID
- **`fetchFleetApiToken()`** — Retrieves the Fleet MDM API key via GraphQL

### Hook: `useLiveCampaign()`

Core hook that orchestrates campaign lifecycle:

- Creates a Fleet live-query campaign via REST, then opens a native `WebSocket` with SockJS framing
- Dispatches incoming messages (`totals`, `result`, `status`, `error`) into React state
- Enforces a **250,000 row cap** (`CAMPAIGN_LIMIT`) and a **5-minute timeout** (`CAMPAIGN_TIMEOUT_MS`)
- Exposes `startCampaign(sql, hostIds)` and `stopCampaign()` controls

## Usage Example

```typescript
import { useLiveCampaign } from './use-live-campaign';

function QueryRunner() {
  const {
    startCampaign,
    stopCampaign,
    isRunning,
    results,
    errors,
    totals,
    hostsResponded,
    campaignStatus,
    connectionState,
  } = useLiveCampaign();

  const handleRun = () => {
    startCampaign('SELECT * FROM os_version', [101, 202]);
  };

  return (
    <>
      <button onClick={handleRun} disabled={isRunning}>Run</button>
      <button onClick={stopCampaign} disabled={!isRunning}>Stop</button>
      <p>Status: {campaignStatus} | Connection: {connectionState}</p>
      <p>Hosts responded: {hostsResponded} | Rows: {results.length}</p>
      {totals && <p>Online: {totals.online} / {totals.count}</p>}
    </>
  );
}
```

> **Note:** When `hostIds` is an empty array, the campaign targets all hosts via the cached Fleet "All Hosts" label.
