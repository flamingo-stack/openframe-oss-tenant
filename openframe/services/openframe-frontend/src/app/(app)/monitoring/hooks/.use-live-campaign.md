React hook that manages the full lifecycle of a Fleet MDM live query campaign over a SockJS/WebSocket connection, including campaign creation, real-time result streaming, error handling, and cleanup.

## Key Components

### Exported Types

- **`CampaignError`** — Per-host error with display name, osquery version, and error message
- **`CampaignEmptyResult`** — Host that returned no rows
- **`CampaignTotals`** — Aggregate counts: total, online, offline, missing in action
- **`UseLiveCampaignReturn`** — Full return shape of the hook

### Helpers

- **`buildWsUrl(httpUrl)`** — Converts HTTP URL to WebSocket URL (`http` → `ws`)
- **`encodeSockJsMessage(msg)`** — Serializes a message into SockJS array-frame format
- **`parseSockJsFrame(raw)`** — Parses SockJS frames (`o`, `h`, `a`, `c`) into typed objects
- **`getAllHostsLabelId()`** — Fetches and caches the Fleet "All Hosts" dynamic label ID
- **`fetchFleetApiToken()`** — Retrieves the Fleet MDM API token via GraphQL

### Hook: `useLiveCampaign()`

Manages campaign state and WebSocket lifecycle:

| State | Description |
|---|---|
| `isRunning` | Whether a campaign is active |
| `results` | Accumulated `QueryResultRow[]` |
| `errors` / `emptyResults` | Per-host failures and no-row responses |
| `totals` | Live aggregate counts |
| `connectionState` | `disconnected` \| `connecting` \| `connected` |
| `campaignStatus` | `''` \| `'pending'` \| `'finished'` |

**Key behaviors:**
- Auto-stops after `250,000` results or `5` minutes
- Falls back to "All Hosts" label when no specific `hostIds` are provided
- Cleans up WebSocket and timers on unmount

## Usage Example

```typescript
const {
  startCampaign,
  stopCampaign,
  isRunning,
  results,
  errors,
  totals,
  connectionState,
} = useLiveCampaign();

// Run a live query against specific hosts
await startCampaign('SELECT * FROM os_version', [101, 202]);

// Or against all hosts
await startCampaign('SELECT * FROM uptime', []);
```
