React Query hook for managing Fleet osquery queries — handles listing, creating, updating, and deleting queries with toast notifications and automatic cache invalidation.

## Key Components

**`queriesQueryKeys`** — Structured query key factory for TanStack Query cache management:
- `all` — base key for all queries
- `list(params?)` — scoped to filtered/team-specific lists
- `detail(id)` — scoped to a single query by ID

**`useQueries(params?)`** — Primary hook exposing:
- `queries` — fetched list (defaults to stable empty array)
- `createQuery(data, options?)` — creates a query, shows success toast
- `updateQuery(id, data, options?)` — patches a query by ID, shows success toast
- `deleteQuery(id, options?)` — removes a query by ID, shows success toast
- Loading flags: `isLoading`, `isCreating`, `isUpdating`, `isDeleting`
- `refetch` and `queriesQuery` for advanced use cases

**Internal API functions** — `fetchQueries`, `createQueryApi`, `updateQueryApi`, `deleteQueryApi` wrap `fleetApiClient` calls with error normalization.

## Usage Example

```typescript
import { useQueries } from './use-queries';

function QueriesPanel({ teamId }: { teamId: number }) {
  const {
    queries,
    isLoading,
    createQuery,
    isCreating,
    deleteQuery,
  } = useQueries({ team_id: teamId });

  const handleCreate = () => {
    createQuery(
      { name: 'OS Version', query: 'SELECT * FROM os_version;', team_id: teamId },
      { onSuccess: (q) => console.log('Created:', q.id) },
    );
  };

  if (isLoading) return <Spinner />;

  return (
    <>
      {queries.map(q => (
        <QueryRow key={q.id} query={q} onDelete={() => deleteQuery(q.id)} />
      ))}
      <button onClick={handleCreate} disabled={isCreating}>Add Query</button>
    </>
  );
}
```

> All mutations automatically invalidate the `['queries']` cache key, keeping the list in sync without manual refetches.
