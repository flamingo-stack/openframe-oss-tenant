React Query hook for managing Fleet osquery queries — provides list, create, update, and delete operations with toast notifications and automatic cache invalidation.

## Key Components

**`queriesQueryKeys`** — Structured query key factory for TanStack Query cache management:
- `all` — base key for all queries
- `list(params?)` — scoped to filtered list results
- `detail(id)` — scoped to a single query by ID

**`useQueries(params?)`** — Primary hook exposing full CRUD interface for Fleet osquery queries.

**Interfaces:**
- `ListQueriesParams` — optional `team_id` and `query` filter fields
- `CreateQueryData` — full payload for creating a query (name, SQL, interval, platform, etc.)
- `UpdateQueryData` — wraps `id` + partial `CreateQueryData` for patch operations

## Usage Example

```typescript
import { useQueries } from './use-queries';

function QueriesManager() {
  const {
    queries,
    isLoading,
    error,
    createQuery,
    isCreating,
    updateQuery,
    deleteQuery,
    isDeleting,
  } = useQueries({ team_id: 1 });

  const handleCreate = () => {
    createQuery(
      {
        name: 'Running Processes',
        query: 'SELECT * FROM processes;',
        interval: 300,
        platform: 'linux',
      },
      {
        onSuccess: (query) => console.log('Created:', query.id),
        onError: (err) => console.error(err),
      },
    );
  };

  const handleDelete = (id: number) => {
    deleteQuery(id, { onSuccess: () => console.log('Deleted') });
  };

  if (isLoading) return <Spinner />;
  if (error) return <Error message={error} />;

  return (
    <QueryList
      queries={queries}
      onDelete={handleDelete}
      isDeleting={isDeleting}
    />
  );
}
```

## Notes

- All mutations automatically invalidate the full `queries` cache key on success.
- Toast notifications are fired for every successful or failed mutation via `useToast`.
- The Fleet API response envelope `{ query: Query }` is unwrapped internally — consumers receive the `Query` object directly.
- Returns `queriesQuery` raw for advanced TanStack Query use cases (e.g., `isFetching`, `status`).
