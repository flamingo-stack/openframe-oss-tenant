React Query hook for managing Fleet osquery queries — handles listing, creating, updating, and deleting queries with toast notifications and automatic cache invalidation.

## Key Components

**`queriesQueryKeys`** — Structured query key factory for TanStack Query cache management:
- `all` — base key for all queries
- `list(params?)` — scoped to filtered list results
- `detail(id)` — scoped to a single query by ID

**`useQueries(params?)`** — Primary hook that exposes:
- `queries` — fetched query list (defaults to stable empty array)
- `createQuery(data, options?)` — creates a new osquery query
- `updateQuery(id, data, options?)` — patches an existing query
- `deleteQuery(id, options?)` — removes a query by ID
- Loading/pending flags: `isLoading`, `isCreating`, `isUpdating`, `isDeleting`
- `error` — string error message or `null`
- `refetch` — manual refetch trigger
- `queriesQuery` — raw TanStack Query object for advanced use

## Usage Example

```typescript
import { useQueries } from './use-queries';

function QueriesPanel({ teamId }: { teamId: number }) {
  const {
    queries,
    isLoading,
    error,
    createQuery,
    isCreating,
    deleteQuery,
  } = useQueries({ team_id: teamId });

  const handleCreate = () => {
    createQuery(
      {
        name: 'Running Processes',
        query: 'SELECT * FROM processes;',
        interval: 3600,
        team_id: teamId,
      },
      {
        onSuccess: (query) => console.log('Created:', query.id),
        onError: (err) => console.error(err),
      }
    );
  };

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;

  return (
    <QueryList
      queries={queries}
      onDelete={(id) => deleteQuery(id)}
      onCreate={handleCreate}
      isCreating={isCreating}
    />
  );
}
```

> All mutations automatically invalidate the full queries cache on success and display toast notifications for both success and error states via `handleApiError`.
