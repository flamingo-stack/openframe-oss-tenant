Fetches and caches a single Fleet query's details by ID using React Query, wrapping the Fleet API's nested response structure.

## Key Components

- **`fetchQuery(id)`** — Async function that calls `fleetApiClient.getQuery(id)`, unwraps the `{ query: {...} }` envelope returned by the Fleet API, and throws on failure.
- **`useQueryDetails(queryId)`** — React hook that conditionally fetches query details; skips the request when `queryId` is `null`.

## Usage Example

```typescript
import { useQueryDetails } from './use-query-details';

function QueryInspector({ queryId }: { queryId: number | null }) {
  const { queryDetails, isLoading, error, refetch } = useQueryDetails(queryId);

  if (isLoading) return <Spinner />;
  if (error) return <ErrorBanner message={error} />;
  if (!queryDetails) return null;

  return (
    <div>
      <h2>{queryDetails.name}</h2>
      <pre>{queryDetails.query}</pre>
      <button onClick={() => refetch()}>Refresh</button>
    </div>
  );
}
```

## Return Shape

| Field | Type | Description |
|---|---|---|
| `queryDetails` | `Query \| null` | Fetched query object, or `null` if not yet loaded |
| `isLoading` | `boolean` | `true` while the request is in-flight |
| `error` | `string \| null` | Error message string, or `null` on success |
| `refetch` | `function` | Manually re-trigger the fetch |

> **Note:** The hook shares the same `queriesQueryKeys.detail` cache key used across the queries feature, so data fetched here integrates with any existing cache entries.
