Provides a React Query hook for fetching a single Fleet query's details by ID, wrapping the Fleet API client response and normalizing the nested `{ query: {...} }` response shape.

## Key Components

- **`fetchQuery(id)`** — Async function that calls `fleetApiClient.getQuery(id)`, validates the response, and unwraps the Fleet API's nested `{ query: Query }` envelope
- **`useQueryDetails(queryId)`** — Primary export; a React Query-powered hook that conditionally fetches query details when a non-null ID is provided

## Usage Example

```typescript
import { useQueryDetails } from './use-query-details';

function QueryInspector({ queryId }: { queryId: number | null }) {
  const { queryDetails, isLoading, error, refetch } = useQueryDetails(queryId);

  if (isLoading) return <Spinner />;
  if (error) return <ErrorBanner message={error} />;
  if (!queryDetails) return null;

  return (
    <div>
      <h2>{queryDetails.name}</h2>
      <pre>{queryDetails.query}</pre>
      <button onClick={() => refetch()}>Refresh</button>
    </div>
  );
}
```

## Notes

- The hook is **disabled** when `queryId` is `null`, preventing spurious fetches during initialization
- Query cache keys are shared with `queriesQueryKeys.detail()` from the parent `use-queries` hook, enabling cache reuse and invalidation
- The `as unknown as { query: Query }` cast handles a naming collision between the Fleet API envelope key `query` and the `Query.query` SQL field
