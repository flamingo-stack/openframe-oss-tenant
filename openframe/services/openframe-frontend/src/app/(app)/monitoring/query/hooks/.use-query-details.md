Fetches and caches a single Fleet query by ID using React Query, wrapping the Fleet API's nested `{ query: {...} }` response format.

## Key Components

- **`fetchQuery(id)`** — Async function that calls `fleetApiClient.getQuery(id)`, unwraps the nested Fleet API response, and throws on failure.
- **`useQueryDetails(queryId)`** — React Query hook that fetches a query's details. Skips the request when `queryId` is `null`.

## Usage Example

```typescript
const { queryDetails, isLoading, error, refetch } = useQueryDetails(queryId);

if (isLoading) return <Spinner />;
if (error) return <ErrorBanner message={error} />;
```

## Return Value

| Field | Type | Description |
|-------|------|-------------|
| `queryDetails` | `Query \| null` | The fetched query object, or `null` if not yet loaded |
| `isLoading` | `boolean` | `true` while the request is in-flight |
| `error` | `string \| null` | Error message string, or `null` on success |
| `refetch` | `function` | Manually re-triggers the query fetch |

## Notes

- The hook is disabled (`enabled: false`) when `queryId` is `null`, preventing unnecessary API calls.
- Cache keys are shared with the queries list via `queriesQueryKeys.detail()`, ensuring consistency across the app.
