Page component for creating and editing osquery monitoring queries, handling form state, device assignment, interval configuration, and live query testing.

## Key Components

### Utility Functions
- **`secondsToUnitValue(totalSeconds)`** — Converts raw seconds into a human-friendly `{ value, unit }` pair (minutes/hours/days)
- **`unitValueToSeconds(value, unit)`** — Converts a value + time unit back to total seconds

### Form Schema
Zod schema (`queryFormSchema`) validating:
- `name` — required string
- `description` — optional string
- `query` — SQL query string
- `interval` — minimum 300 seconds (5 minutes)

### `EditQueryPage` Component
Main form page supporting both **create** and **edit** modes, determined by `queryId` prop.

**Key behaviors:**
- Loads existing query details and assigned hosts when editing
- Manages device selection via `DeviceSelector` with Fleet host ID mapping
- Splits interval storage (seconds) from display (value + unit selector)
- Runs live query tests via `useLiveCampaign` + `LiveTestPanel`
- Saves query then replaces host assignments in sequence on submit

## Usage Example

```typescript
// Create mode
<EditQueryPage queryId={null} />

// Edit mode
<EditQueryPage queryId="42" />
```

## Dependencies

| Hook / Component | Purpose |
|---|---|
| `useQueryDetails` | Fetch existing query data |
| `useQueries` | Create / update mutation |
| `useQueryHosts` / `useReplaceQueryHosts` | Load and replace host assignments |
| `usePolicyDevices` | Available device list |
| `useLiveCampaign` | Manage live test execution |
| `LiveTestPanel` | Display live query results |
| `ScriptEditor` | SQL query input with syntax highlighting |
