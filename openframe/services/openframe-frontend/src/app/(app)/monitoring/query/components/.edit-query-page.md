Page component for creating and editing osquery monitoring queries, including form fields for name, description, SQL query, execution frequency, device targeting, and an inline live-test panel.

## Key Components

### Utility Functions
- **`secondsToUnitValue(totalSeconds)`** — Converts a raw seconds value into a `{ value, unit }` pair using the largest fitting time unit (minutes/hours/days)
- **`unitValueToSeconds(value, unit)`** — Converts a human-readable frequency back to seconds for storage

### Schema
- **`queryFormSchema`** — Zod schema validating `name`, `description`, `query`, and `interval` (minimum 300s / 5 minutes)

### `EditQueryPage` Component
Handles both **create** and **edit** modes based on the presence of a numeric `queryId` prop.

Key behaviors:
- Loads existing query details and currently assigned hosts when editing
- Syncs frequency state (numeric value + unit) bidirectionally with the `interval` form field
- Manages device selection via `DeviceSelector` and persists host assignments via `useReplaceQueryHosts`
- Triggers a live campaign test via `useLiveCampaign` and renders results in `LiveTestPanel`
- Shows `CardLoader`, `LoadError`, or `NotFoundError` states during loading or on failure

## Usage Example

```typescript
// Routed from /monitoring/query/[id]/edit or /monitoring/query/new
<EditQueryPage queryId="42" />   // edit mode
<EditQueryPage queryId={null} /> // create mode
```

Form actions available to the user:

```typescript
// "Test Query" — runs a live campaign against selected devices
// "Save Query" — validates via Zod, then calls createQuery or updateQuery,
//                then replaces host assignments via replaceQueryHostsMutation
actions = [
  { label: 'Test Query', variant: 'outline', disabled: !hasQuery },
  { label: 'Save Query', variant: 'accent',  disabled: isSaving || !hasName },
];
```
