React page component for creating and editing osquery monitoring queries, handling form state, device assignment, interval configuration, and live query testing.

## Key Components

### Utility Functions
- **`secondsToUnitValue(totalSeconds)`** — Converts a raw seconds value into a human-friendly `{ value, unit }` pair (minutes/hours/days)
- **`unitValueToSeconds(value, unit)`** — Inverse conversion back to seconds for form storage

### Schema
- **`queryFormSchema`** — Zod schema validating `name`, `description`, `query`, and `interval` (min 300s / 5 minutes)

### Main Export
- **`EditQueryPage({ queryId })`** — Full-page form component supporting both create (`queryId: null`) and update (`queryId: string`) modes

## Key Behaviors

| Feature | Detail |
|---------|--------|
| **Dual mode** | Create vs. edit detected via `numericId` presence |
| **Host assignment** | Loads current hosts on edit, syncs via `useReplaceQueryHosts` on save |
| **Interval UI** | Numeric input + unit selector (`minutes`/`hours`/`days`) mapped to/from raw seconds |
| **Live testing** | `useLiveCampaign` drives `LiveTestPanel`; test runs against selected device set |
| **Loading states** | `CardLoader`, `LoadError`, `NotFoundError` guard render before form mounts |

## Usage Example

```typescript
// In a Next.js App Router page
import { EditQueryPage } from './edit-query-page';

export default function Page({ params }: { params: { id?: string } }) {
  return <EditQueryPage queryId={params.id ?? null} />;
}
```

> **Create mode:** Pass `queryId={null}` — submits via `createQuery`, then redirects to `/monitoring?tab=queries`.
> **Edit mode:** Pass a numeric string ID — loads existing data, saves via `updateQuery` + host replacement, then navigates back to the query detail page.
