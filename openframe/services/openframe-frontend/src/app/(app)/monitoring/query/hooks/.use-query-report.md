Fetches and transforms a Fleet query report for a given query ID, returning flattened row data suitable for tabular display.

## Key Components

- **`fetchQueryReport(queryId)`** — Async function that calls the Fleet API client to retrieve a query report, throwing on failure
- **`flattenResults(results)`** — Transforms raw report results into flat `QueryResultRow[]` objects by merging `host_name`, formatted `last_fetched`, and dynamic `columns` into a single row per result
- **`useQueryReport(queryId)`** — Primary exported hook that composes TanStack Query with the above utilities, accepting a nullable query ID

## Usage Example

```typescript
const { rows, reportClipped, isLoading, error, refetch } = useQueryReport(42);

if (isLoading) return <Spinner />;
if (error) return <ErrorBanner message={error} />;

return (
  <>
    {reportClipped && <Banner>Results are clipped</Banner>}
    <DataTable rows={rows} />
  </>
);
```

## Return Value

| Field | Type | Description |
|---|---|---|
| `rows` | `QueryResultRow[]` | Flattened, memoized result rows |
| `reportClipped` | `boolean` | Whether the report was truncated by Fleet |
| `isLoading` | `boolean` | Query loading state |
| `error` | `string \| null` | Error message if the request failed |
| `refetch` | `function` | Manually re-trigger the query |

> The hook is disabled when `queryId` is `null`, preventing unnecessary API calls when no query is selected.
