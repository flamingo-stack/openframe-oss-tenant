Fetches and transforms query report data for a specific Fleet query, returning flattened result rows suitable for tabular display.

## Key Components

- **`fetchQueryReport(queryId)`** — Async function that calls `fleetApiClient.getQueryReport` and throws on failure
- **`flattenResults(results)`** — Merges `host_name`, formatted `last_fetched`, and dynamic `columns` into flat `QueryResultRow` objects
- **`useQueryReport(queryId)`** — Main exported hook; wraps TanStack Query with memoized row transformation

## Usage Example

```typescript
import { useQueryReport } from './use-query-report';

function QueryResultsTable({ queryId }: { queryId: number | null }) {
  const { rows, reportClipped, isLoading, error, refetch } = useQueryReport(queryId);

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;

  return (
    <>
      {reportClipped && <Banner>Results have been clipped</Banner>}
      <DataTable rows={rows} />
    </>
  );
}
```

## Return Shape

| Field | Type | Description |
|-------|------|-------------|
| `rows` | `QueryResultRow[]` | Flattened result rows with host metadata and dynamic columns |
| `reportClipped` | `boolean` | Whether Fleet truncated the result set |
| `isLoading` | `boolean` | Query loading state |
| `error` | `string \| null` | Error message if the fetch failed |
| `refetch` | `function` | Manually re-trigger the query |

The hook is disabled when `queryId` is `null`, preventing unnecessary requests before a query is selected.
