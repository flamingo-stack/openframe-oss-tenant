Provides React Query hooks for fetching and updating the list of hosts associated with a Fleet query, including paginated data fetching and cache invalidation.

## Key Components

- **`queryHostsQueryKeys`** — Structured query key factory for `query-hosts` list cache entries, scoped by `queryId`
- **`fetchAllQueryHosts`** — Internal async function that paginates through all host results (100 per page) for a given query ID
- **`replaceQueryHostsApi`** — Internal async function that replaces the full host assignment for a query via the Fleet API
- **`useQueryHosts`** — Read hook that returns the host list, loading state, error message, and a refetch function; disabled when `queryId` is `null`
- **`useReplaceQueryHosts`** — Mutation hook that replaces query host assignments, invalidates the host list and query detail caches on success, and shows a toast on error

## Usage Example

```typescript
import { useQueryHosts, useReplaceQueryHosts } from './use-query-hosts';

function QueryHostsPanel({ queryId }: { queryId: number }) {
  const { hosts, isLoading, error } = useQueryHosts(queryId);
  const replaceHosts = useReplaceQueryHosts();

  const handleSave = (selectedHostIds: number[]) => {
    replaceHosts.mutate({ queryId, hostIds: selectedHostIds });
  };

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;

  return <HostList hosts={hosts} onSave={handleSave} />;
}
```
