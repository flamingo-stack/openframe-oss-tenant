Provides React Query hooks for fetching and replacing hosts associated with a Fleet query, including paginated data loading and cache invalidation.

## Key Components

- **`queryHostsQueryKeys`** — Structured query key factory for cache scoping (`all`, `list(queryId)`)
- **`fetchAllQueryHosts(queryId)`** — Paginated API fetcher that auto-iterates all pages (100 hosts/page) until exhausted
- **`replaceQueryHostsApi(params)`** — API wrapper that replaces the full host assignment for a given query
- **`useQueryHosts(queryId)`** — Query hook returning `hosts`, `isLoading`, `error`, and `refetch`; skips fetch when `queryId` is `null`
- **`useReplaceQueryHosts()`** — Mutation hook that replaces hosts and invalidates both `queryHostsQueryKeys.list` and `queriesQueryKeys.detail` on success

## Usage Example

```typescript
// Fetch hosts assigned to a query
const { hosts, isLoading, error } = useQueryHosts(42);

// Replace assigned hosts
const replaceHosts = useReplaceQueryHosts();

replaceHosts.mutate({
  queryId: 42,
  hostIds: [1, 2, 3],
});
```

## Notes

- `useQueryHosts` is disabled when `queryId` is `null`, making it safe for conditional rendering
- Falls back to `EMPTY_QUERY_HOSTS` (`[]`) to avoid undefined checks on consumers
- `useReplaceQueryHosts` triggers toast error feedback via `handleApiError` on failure and dual cache invalidation on success to keep query detail and host list in sync
