Provides React Query hooks for fetching and updating the list of hosts associated with a Fleet query, including paginated data fetching and cache invalidation.

## Key Components

- **`queryHostsQueryKeys`** — Structured query key factory for scoping TanStack Query cache entries by query ID
- **`fetchAllQueryHosts(queryId)`** — Internal async function that paginates through all host results (100 per page) until exhausted
- **`useQueryHosts(queryId)`** — Read hook that returns the full host list, loading state, error message, and a refetch trigger; skips fetching when `queryId` is `null`
- **`useReplaceQueryHosts()`** — Mutation hook that replaces the assigned hosts for a query, then invalidates both the host list and parent query detail caches on success; surfaces errors via toast notification

## Usage Example

```typescript
// Fetch hosts assigned to a query
const { hosts, isLoading, error } = useQueryHosts(queryId);

// Replace assigned hosts
const replaceHosts = useReplaceQueryHosts();

replaceHosts.mutate({
  queryId: 42,
  hostIds: [1, 2, 3],
});
```
