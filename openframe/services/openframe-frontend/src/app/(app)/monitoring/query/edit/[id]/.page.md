Client-side Next.js page wrapper that resolves the dynamic route parameter `id` and renders the `EditQueryPage` component, treating the special value `"new"` as a null ID to signal query creation mode.

## Key Components

- **`EditQueryPageWrapper`** — Default export page component that reads the `id` route param, normalizes it (`"new"` → `null`, valid string → string, otherwise `null`), and passes it to `EditQueryPage` as `queryId`.

## Usage Example

```typescript
// Route: /queries/[id]/page.tsx
// Accessed via:
//   /queries/new         → queryId = null  (create mode)
//   /queries/abc-123     → queryId = "abc-123" (edit mode)
//   /queries/            → queryId = null  (fallback)

<EditQueryPageWrapper />
// Internally renders:
<EditQueryPage queryId={null} />        // create
<EditQueryPage queryId="abc-123" />     // edit
```

## Behavior

| Route Param | `queryId` Passed | Mode |
|---|---|---|
| `"new"` | `null` | Create |
| `"abc-123"` | `"abc-123"` | Edit |
| `undefined` | `null` | Fallback |
