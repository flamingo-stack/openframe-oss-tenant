Detail view component for displaying a monitoring query's full information, including metadata, SQL content, execution results, and actions (edit/delete).

## Key Components

**`formatInterval(seconds)`**
Utility that converts a numeric interval (in seconds) to a human-readable string (e.g., `"Every 5m"`, `"Every 2h"`, `"Manual"` for `0`).

**`QueryDetailsView({ queryId })`**
Main page component that orchestrates:
- `useQueryDetails` — fetches query metadata
- `useQueryReport` — fetches latest execution results
- `useQueries` — provides `deleteQuery` mutation
- `useSafeBack` — safe back-navigation fallback to `/monitoring?tab=queries`

## Usage Example

```typescript
// Typically rendered by a Next.js dynamic route: /monitoring/query/[id]
import { QueryDetailsView } from './query-details-view';

export default function QueryDetailPage({ params }: { params: { id: string } }) {
  return <QueryDetailsView queryId={params.id} />;
}
```

## Rendered Sections

| Section | Description |
|---|---|
| Header | Query name, back button, Edit button, Delete (via `MoreActionsMenu`) |
| Info card | Optional description + formatted run frequency |
| SQL editor | Read-only `ScriptEditor` with `shell="sql"`, 300px height |
| Results table | `QueryReportTable` with CSV export, ordered by `host_name` / `last_fetched` |
| Delete modal | `ConfirmDeleteMonitoringModal` — redirects to queries list on confirm |

## States

- **Loading** → `<CardLoader items={4} />`
- **Error** → `<LoadError />` with message
- **Not found / invalid ID** → `<NotFoundError />`
