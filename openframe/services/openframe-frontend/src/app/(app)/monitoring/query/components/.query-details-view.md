Detail view component for displaying a single monitoring query's full information, including its SQL content, execution frequency, report results, and edit/delete actions.

## Key Components

- **`QueryDetailsView`** — Main exported component that renders the full query detail page
- **`formatInterval(seconds)`** — Utility that converts a numeric interval (in seconds) to a human-readable string (e.g., `"Every 5m"`, `"Manual"`)
- **Hooks used:**
  - `useQueryDetails` — Fetches query metadata by ID
  - `useQueryReport` — Fetches report rows for the query
  - `useQueries` — Provides `deleteQuery` mutation
  - `useSafeBack` — Safe navigation fallback to `/monitoring?tab=queries`

## Usage Example

```typescript
// Renders the full detail page for a given query ID (typically from a route param)
import { QueryDetailsView } from './query-details-view';

export default function QueryDetailPage({ params }: { params: { id: string } }) {
  return <QueryDetailsView queryId={params.id} />;
}
```

## Behavior Notes

- Invalid or non-numeric `queryId` safely skips data fetching
- Renders `CardLoader` while loading, `LoadError` on failure, `NotFoundError` if query is missing
- **Edit** button navigates to `/monitoring/query/edit/:id`
- **Delete** opens a confirmation modal (`ConfirmDeleteMonitoringModal`), then redirects to `/monitoring?tab=queries` on success
- SQL content is displayed read-only via `ScriptEditor` with `shell="sql"`
- Report results are rendered in `QueryReportTable` with CSV export support, columns ordered as `host_name → last_fetched`
