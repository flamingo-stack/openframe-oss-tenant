Detail page view component for displaying a monitoring query's full information, including metadata, SQL script, and query results report.

## Key Components

- **`QueryDetailsView`** — Main page component rendered at `/monitoring/query/[id]`
- **`formatInterval(seconds)`** — Utility that converts a numeric interval to a human-readable string (e.g., `Every 5m`, `Manual`)
- **`QueryDetailsViewProps`** — Interface accepting a `queryId: string` prop

**Hooks used:**
- `useQueryDetails` — Fetches query metadata (name, description, interval, SQL)
- `useQueryReport` — Fetches tabular results for the query
- `useQueries` — Provides `deleteQuery` action with loading state
- `useSafeBack` — Handles back navigation with a fallback route

**UI states handled:**
- Loading → `CardLoader`
- Fetch error → `LoadError`
- Not found / invalid ID → `NotFoundError`

## Usage Example

```typescript
// Typically rendered by a Next.js dynamic route page
// app/monitoring/query/[id]/page.tsx

import { QueryDetailsView } from './query-details-view';

export default function QueryDetailPage({ params }: { params: { id: string } }) {
  return <QueryDetailsView queryId={params.id} />;
}
```

**Header actions available to the user:**
- **Edit** — navigates to `/monitoring/query/edit/[id]`
- **Delete** — opens `ConfirmDeleteMonitoringModal`, then redirects to `/monitoring?tab=queries` on success

**Query results table** uses `QueryReportTable` with column ordering (`host_name`, `last_fetched`) and CSV export support via `useToast` feedback.
