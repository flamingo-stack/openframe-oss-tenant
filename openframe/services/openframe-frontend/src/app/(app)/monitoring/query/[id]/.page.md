Client-side page wrapper for query detail routing. Handles the special `new` case by redirecting to the edit route, and renders the `QueryDetailsView` component for existing queries.

## Key Components

- **`QueryPageWrapper`** — Default export page component that reads the `id` route param, redirects `new` to `/monitoring/query/edit/new`, and renders `QueryDetailsView` for existing query IDs.

## Usage Example

```typescript
// Route: /monitoring/query/[id]
// Accessing /monitoring/query/new → redirects to /monitoring/query/edit/new
// Accessing /monitoring/query/abc123 → renders <QueryDetailsView queryId="abc123" />
```
