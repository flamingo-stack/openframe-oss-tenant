Client-side page component that handles routing for individual query detail views in the monitoring section, including a redirect for the `new` route.

## Key Components

- **`QueryPageWrapper`** — Default export page component that reads the `id` route param and conditionally renders the query details view or redirects to the edit page.

## Behavior

- If the `id` param is `"new"`, redirects to `/monitoring/query/edit/new` and renders nothing during the transition.
- For all other `id` values, renders `QueryDetailsView` with the resolved `queryId`.

## Usage Example

```typescript
// Accessed via route: /monitoring/query/[id]
// e.g. /monitoring/query/abc123 → renders QueryDetailsView
// e.g. /monitoring/query/new   → redirects to /monitoring/query/edit/new
```
