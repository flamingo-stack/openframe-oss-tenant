Defines TypeScript interfaces for Fleet/osquery query management, representing query configurations, execution reports, and report request parameters.

## Key Components

| Interface | Description |
|-----------|-------------|
| `Query` | Full query object including metadata, scheduling, and automation settings |
| `QueryReportResult` | Single host result row from a query report execution |
| `QueryReportResponse` | Paginated query report response with clipping indicator |
| `QueryReportParams` | Optional sorting parameters for fetching query reports |

## Usage Example

```typescript
import {
  Query,
  QueryReportResult,
  QueryReportResponse,
  QueryReportParams,
} from "./queries.types";

// Typed query object
const query: Query = {
  id: 42,
  name: "Get running processes",
  query: "SELECT * FROM processes;",
  description: "Lists all running processes",
  author_id: 1,
  author_name: "Admin",
  author_email: "admin@example.com",
  saved: true,
  observer_can_run: false,
  interval: 3600,
  automations_enabled: true,
  created_at: "2024-01-01T00:00:00Z",
  updated_at: "2024-06-01T00:00:00Z",
};

// Fetching a report with sort params
const params: QueryReportParams = {
  order_key: "host_name",
  order_direction: "asc",
};

// Handling the report response
const response: QueryReportResponse = {
  query_id: 42,
  report_clipped: false,
  results: [
    {
      host_id: 7,
      host_name: "macbook-pro-01",
      last_fetched: "2024-06-01T12:00:00Z",
      columns: { pid: "1234", name: "node" },
    },
  ],
};
```

> **Note:** `report_clipped` indicates the result set was truncated due to size limits — check `output_size` on the parent `Query` to understand configured thresholds.
