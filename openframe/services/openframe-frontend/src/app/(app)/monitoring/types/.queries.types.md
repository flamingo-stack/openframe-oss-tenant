Defines TypeScript interfaces for Fleet/osquery query entities, including query metadata, report results, and API request/response shapes.

## Key Components

| Interface | Description |
|---|---|
| `Query` | Full query object with metadata, scheduling, authorship, and configuration fields |
| `QueryReportResult` | Single host result entry from a query report, including column data |
| `QueryReportResponse` | API response wrapper for query reports with clipping indicator |
| `QueryReportParams` | Optional sort parameters for fetching query reports |

## Usage Example

```typescript
import {
  Query,
  QueryReportResult,
  QueryReportResponse,
  QueryReportParams,
} from "./queries.types";

// Working with a query object
const query: Query = {
  id: 42,
  name: "Active Users",
  query: "SELECT * FROM users WHERE active = 1;",
  description: "Lists all active users",
  author_id: 1,
  author_name: "Jane Doe",
  author_email: "jane@example.com",
  saved: true,
  observer_can_run: false,
  interval: 3600,
  automations_enabled: true,
  created_at: "2024-01-01T00:00:00Z",
  updated_at: "2024-06-01T00:00:00Z",
};

// Fetching a report with sort params
const params: QueryReportParams = {
  order_key: "host_name",
  order_direction: "asc",
};

// Handling the report response
const response: QueryReportResponse = {
  query_id: 42,
  report_clipped: false,
  results: [
    {
      host_id: 7,
      host_name: "workstation-01",
      last_fetched: "2024-06-01T12:00:00Z",
      columns: { username: "jdoe", uid: "1001" },
    },
  ],
};
```
