Defines the `PolicySummaryStats` interface representing aggregated compliance statistics for a set of policies.

## Key Components

**`PolicySummaryStats`** — Interface containing:
- `totalPolicies` — Total number of policies evaluated
- `failingPolicies` — Count of policies currently in a failing/non-compliant state
- `failingPoliciesPercentage` — Percentage of policies that are failing
- `compliantPolicies` — Count of policies currently passing/compliant
- `compliantPoliciesPercentage` — Percentage of policies that are compliant
- `lastUpdatedAt` — ISO timestamp of the last statistics refresh, or `null` if never updated

## Usage Example

```typescript
import { PolicySummaryStats } from './policy-summary.types';

const stats: PolicySummaryStats = {
  totalPolicies: 120,
  failingPolicies: 18,
  failingPoliciesPercentage: 15,
  compliantPolicies: 102,
  compliantPoliciesPercentage: 85,
  lastUpdatedAt: '2025-01-15T10:30:00Z',
};

if (stats.failingPoliciesPercentage > 20) {
  console.warn('High policy failure rate detected');
}
```
