Defines the TypeScript interface for aggregated policy compliance statistics used in summary dashboards and reporting views.

## Key Components

**`PolicySummaryStats`** — Interface representing rolled-up policy health metrics:

| Field | Type | Description |
|-------|------|-------------|
| `totalPolicies` | `number` | Total number of evaluated policies |
| `failingPolicies` | `number` | Count of policies currently in violation |
| `failingPoliciesPercentage` | `number` | Percentage of policies that are failing |
| `compliantPolicies` | `number` | Count of policies passing all checks |
| `compliantPoliciesPercentage` | `number` | Percentage of policies that are compliant |
| `lastUpdatedAt` | `string \| null` | ISO timestamp of the last stats refresh, or `null` if never computed |

## Usage Example

```typescript
import { PolicySummaryStats } from './policy-summary.types';

const stats: PolicySummaryStats = {
  totalPolicies: 120,
  failingPolicies: 18,
  failingPoliciesPercentage: 15,
  compliantPolicies: 102,
  compliantPoliciesPercentage: 85,
  lastUpdatedAt: '2025-01-15T10:30:00Z',
};

function isHealthy(stats: PolicySummaryStats): boolean {
  return stats.failingPoliciesPercentage < 10;
}
```

> **Note:** `failingPoliciesPercentage` and `compliantPoliciesPercentage` should always sum to `100`. Consumers should treat a `null` `lastUpdatedAt` as an indication that stats have not yet been computed for the current dataset.
