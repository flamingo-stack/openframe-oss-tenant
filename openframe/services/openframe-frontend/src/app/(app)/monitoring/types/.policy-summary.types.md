Defines the TypeScript interface for aggregated policy compliance statistics used in summary views and dashboards.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `PolicySummaryStats` | `interface` | Aggregated metrics representing the compliance state of all monitored policies |

### `PolicySummaryStats` Fields

| Field | Type | Description |
|-------|------|-------------|
| `totalPolicies` | `number` | Total count of all tracked policies |
| `failingPolicies` | `number` | Count of policies currently out of compliance |
| `failingPoliciesPercentage` | `number` | Percentage of policies that are failing |
| `compliantPolicies` | `number` | Count of policies currently in compliance |
| `compliantPoliciesPercentage` | `number` | Percentage of policies that are compliant |
| `lastUpdatedAt` | `string \| null` | ISO timestamp of the last stats refresh, or `null` if never updated |

## Usage Example

```typescript
import { PolicySummaryStats } from './policy-summary.types';

const stats: PolicySummaryStats = {
  totalPolicies: 42,
  failingPolicies: 5,
  failingPoliciesPercentage: 11.9,
  compliantPolicies: 37,
  compliantPoliciesPercentage: 88.1,
  lastUpdatedAt: '2025-01-15T10:30:00Z',
};

function isHealthy(stats: PolicySummaryStats): boolean {
  return stats.failingPoliciesPercentage === 0;
}
```
