Policies page component that displays a paginated, searchable list of monitoring policies with compliance summary statistics, status indicators, and CRUD actions.

## Key Components

- **`Policies`** — Main page component rendering the full policies dashboard with summary cards, search, and data table
- **`PolicyStatusCell`** — Internal cell component that renders a policy's compliance status tag with device counts for partial/failing states
- **`parsePlatforms`** — Utility that splits a comma-separated platform string into a string array

## Usage Example

```typescript
// Rendered as a Next.js page route (e.g. /monitoring/policies)
import { Policies } from './policies';

export default function PoliciesPage() {
  return <Policies />;
}
```

## Key Behaviors

- **Summary stats** — Displays four `DashboardInfoCard` tiles: total policies, compliance rate (with progress), failed policies, and last updated timestamp
- **Search** — Debounced (500ms) filter on policy name and description; resets visible count on each new search
- **Pagination** — Client-side load-more pattern in increments of `PAGE_SIZE` (20)
- **Row actions** — Each row exposes a `MoreActionsMenu` with "Policy Details" (router push) and "Delete Policy" (opens `ConfirmDeleteMonitoringModal`), plus an open-in-new-tab button
- **Column responsiveness** — Severity hidden at `md`, Platform hidden at `lg`, via column `meta.hideAt`
- **Delete flow** — Controlled via `policyToDelete` state; delegates to `deletePolicy` from `usePolicies`, clearing state on success
