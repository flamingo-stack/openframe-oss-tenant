Policies page component that renders a full-page list view of monitoring policies, including summary statistics, searchable/filterable data table, and delete confirmation flow.

## Key Components

- **`Policies`** — Main page component; fetches and displays all policies with stats, search, pagination, and row actions
- **`PolicyStatusCell`** — Table cell subcomponent that renders a status `Tag` with contextual device counts for `partial` and `failing` states
- **`parsePlatforms`** — Utility that splits a comma-separated platform string into a trimmed array

## Usage Example

```typescript
// Route: /monitoring/policies
// Render directly as a Next.js page component
import { Policies } from './policies';

export default function PoliciesPage() {
  return <Policies />;
}
```

## Key Behaviors

| Feature | Detail |
|---|---|
| Summary stats | Total, compliance rate, failed count, last updated |
| Search | Debounced (500ms), filters by name + description |
| Pagination | Client-side load-more, 20 rows per page |
| Row click | Navigates to `/monitoring/policy/:id` |
| Open in new tab | Per-row button using `openInNewTab` |
| Delete | Triggers `ConfirmDeleteMonitoringModal`, calls `deletePolicy` on confirm |
| Platform badges | Parses comma-separated platform string into `OSTypeBadgeGroup` |
| Severity | Displays `Critical` or `Low` based on `policy.critical` flag |
