Renders the Monitoring section's tabbed layout, using URL search params (`?tab=`) as the single source of truth for active tab state.

## Key Components

- **`MonitoringView`** — Main page component that manages tab navigation between `policies` and `queries` tabs
- **`TAB_IDS`** — Allowed tab identifiers (`'policies' | 'queries'`), used to validate the `?tab=` param
- **`DEFAULT_TAB`** — Fallback tab (`'policies'`) used when the URL param is absent or invalid
- **`handleTabChange`** — Callback that updates the URL via `router.replace` without a scroll jump, avoiding the flicker bug caused by `TabNavigation`'s internal `urlSync` mode

## Usage Example

```typescript
// Rendered by the monitoring page route (e.g., /monitoring?tab=queries)
import { MonitoringView } from './monitoring-view';

export default function MonitoringPage() {
  return <MonitoringView />;
}
```

Navigating between tabs updates the URL cleanly:

```text
/monitoring           → defaults to ?tab=policies
/monitoring?tab=queries  → activates the Queries tab
/monitoring?tab=invalid  → falls back to policies tab
```

> Tab components are resolved lazily via `getTabComponent` from `@flamingo-stack/openframe-frontend-core`, keeping each tab's bundle separate until it is first activated.
