Renders the Queries list page for the monitoring module, providing searchable, paginated display of monitoring queries with inline actions for navigation, deletion, and creation.

## Key Components

- **`Queries`** — Main page component that composes the full list view
- **`formatInterval(seconds)`** — Utility that converts interval seconds to human-readable strings (e.g., `Every 5m`, `Every 2h`, `Manual`)
- **`columns`** — `ColumnDef<Query>[]` defining Name/Description, Frequency, row actions menu, and open-in-new-tab button
- **`useQueries`** — Custom hook providing `queries`, `isLoading`, `error`, and `deleteQuery`
- **`ConfirmDeleteMonitoringModal`** — Confirmation dialog shown before destructive delete operations
- **`useDataTable`** — Wires table state (data, columns, row IDs, sorting) to `DataTable`

## Usage Example

```typescript
// Render within the monitoring route layout
import { Queries } from './queries';

export default function QueriesPage() {
  return <Queries />;
}
```

## Behavior Notes

| Feature | Detail |
|---|---|
| Search | Debounced 300ms, filters by `name` and `description`, resets pagination |
| Pagination | Client-side load-more, `PAGE_SIZE = 20` rows per batch |
| Row click | Navigates to `/monitoring/query/:id` |
| Open in new tab | Button per row using `openInNewTab` utility |
| Delete | Sets `queryToDelete` state → confirmation modal → `deleteQuery` on confirm |
| Add Query | Routes to `/monitoring/query/edit/new` |
