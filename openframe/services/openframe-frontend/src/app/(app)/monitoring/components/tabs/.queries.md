List page component for browsing, searching, and managing monitoring queries in the OpenFrame platform.

## Key Components

- **`Queries`** — Main page component rendering a searchable, paginated list of monitoring queries
- **`formatInterval`** — Utility that converts a seconds-based interval into a human-readable string (e.g., `Every 5m`, `Manual`)
- **`PAGE_SIZE`** — Constant controlling how many rows load per page (default: `20`)

## Key Behaviors

- **Debounced search** — Filters queries by `name` or `description` with a 300ms debounce, synced to URL params via `useApiParams`
- **Client-side pagination** — Incremental "load more" via `visibleCount` slice rather than API pagination
- **Row actions** — Each row exposes a `MoreActionsMenu` (Query Details, Delete Query) and an open-in-new-tab button
- **Delete flow** — Selecting "Delete Query" opens `ConfirmDeleteMonitoringModal`; confirmed deletion calls `deleteQuery` from `useQueries`

## Usage Example

```typescript
// Rendered as a route-level page component, no props required
import { Queries } from './queries';

export default function QueriesPage() {
  return <Queries />;
}
```

```typescript
// formatInterval examples
formatInterval(0);     // → 'Manual'
formatInterval(30);    // → 'Every 30s'
formatInterval(120);   // → 'Every 2m'
formatInterval(7200);  // → 'Every 2h'
formatInterval(86400); // → 'Every 1d'
```

## Dependencies

| Hook / Component | Purpose |
|---|---|
| `useQueries` | Fetches query list and exposes `deleteQuery` |
| `useApiParams` | Syncs search term to URL query params |
| `useDebounce` | Delays search filter updates |
| `ListPageLayout` | Consistent page shell with title, actions, and search bar |
| `DataTable` | Sortable/paginated table with sticky header support |
