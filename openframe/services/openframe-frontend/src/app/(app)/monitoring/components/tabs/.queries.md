Renders the monitoring Queries list page, providing search, pagination, and CRUD actions for scheduled query definitions.

## Key Components

- **`Queries`** — Main page component that displays a searchable, paginated table of monitoring queries
- **`formatInterval(seconds)`** — Utility that converts a numeric interval (in seconds) to a human-readable frequency string (e.g. `Every 5m`, `Manual`)
- **`columns`** — Table column definitions for query name/description, frequency, row actions menu, and open-in-new-tab button
- **`rowActions`** — Per-row context menu with "Query Details" (navigate) and "Delete Query" (open confirm modal) options
- **`ConfirmDeleteMonitoringModal`** — Confirmation dialog invoked before calling `deleteQuery`

## Usage Example

```typescript
// Rendered as a page component within the monitoring section
import { Queries } from './queries';

// In your Next.js page or layout:
export default function QueriesPage() {
  return <Queries />;
}
```

## Behavior Notes

- **Search** is debounced (300ms) and synced to URL params via `useApiParams`; resets visible count on new searches
- **Client-side filtering** on `name` and `description` fields; no server-side search request
- **Pagination** uses a "load more" pattern (`PAGE_SIZE = 20`), appending rows via `DataTable.InfiniteFooter`
- **Row click** navigates to `/monitoring/query/:id`; the open icon launches in a new tab
- **Delete flow** sets `queryToDelete` state → shows confirm modal → calls `deleteQuery` on confirmation
