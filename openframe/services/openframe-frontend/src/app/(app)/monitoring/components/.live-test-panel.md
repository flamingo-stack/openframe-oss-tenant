A real-time test results panel component that displays live campaign execution status, device response metrics, errors, and query/policy results in a collapsible card UI.

## Key Components

### `LiveTestPanel` (main export)
The primary panel component that renders campaign test output, including:
- **Start time & duration** — live elapsed timer updating every second via `useEffect`
- **Device counters** — responded/online ratio with failed host count
- **Action buttons** — "Test Again", "Stop" (while running), and "Close"
- **Error summary** — collapsible list of hosts that returned errors (capped at 10 + overflow count)
- **Empty results warning** — collapsible list of hosts returning no data
- **Results table** — `QueryReportTable` with skeleton loading state

### `CollapsibleSection`
Internal helper component rendering a togglable section with a colored chevron header and scrollable content area (`max-h-24`).

### `LiveTestPanelProps`
```typescript
interface LiveTestPanelProps {
  mode: 'query' | 'policy';
  isRunning: boolean;
  startedAt: Date | null;
  results: QueryResultRow[];
  errors: CampaignError[];
  emptyResults: CampaignEmptyResult[];
  totals: CampaignTotals | null;
  hostsResponded: number;
  hostsFailed: number;
  campaignStatus: '' | 'pending' | 'finished';
  onTestAgain: () => void;
  onStop: () => void;
  onClose: () => void;
}
```

## Usage Example

```typescript
import { LiveTestPanel } from './live-test-panel';

<LiveTestPanel
  mode="query"
  isRunning={isRunning}
  startedAt={startedAt}
  results={queryResults}
  errors={campaignErrors}
  emptyResults={emptyHosts}
  totals={campaignTotals}
  hostsResponded={42}
  hostsFailed={3}
  campaignStatus="finished"
  onTestAgain={handleRerun}
  onStop={handleStop}
  onClose={() => setShowPanel(false)}
/>
```

> **Note:** Error and empty-result sections are only rendered when `campaignStatus === 'finished'` and the respective arrays are non-empty. The duration timer auto-stops when `isRunning` becomes `false`.
