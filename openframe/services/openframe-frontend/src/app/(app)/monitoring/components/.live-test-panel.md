Real-time test execution panel component that displays live campaign results, timing stats, host response counts, errors, and empty-result warnings for query or policy test runs.

## Key Components

### `LiveTestPanel` (main export)
Full-featured panel that renders campaign test state including start time, elapsed duration, host response progress, error/empty-result summaries, and a scrollable results table.

**Props (`LiveTestPanelProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `mode` | `'query' \| 'policy'` | Sets panel label and export filename |
| `isRunning` | `boolean` | Controls timer, Stop/Test Again buttons |
| `startedAt` | `Date \| null` | Anchor for duration calculation |
| `results` | `QueryResultRow[]` | Rows fed into `QueryReportTable` |
| `errors` | `CampaignError[]` | Hosts that returned errors |
| `emptyResults` | `CampaignEmptyResult[]` | Hosts that returned no data |
| `totals` | `CampaignTotals \| null` | Online host totals |
| `campaignStatus` | `'' \| 'pending' \| 'finished'` | Gates error/empty-result sections |
| `onTestAgain` / `onStop` / `onClose` | `() => void` | Action callbacks |

### `CollapsibleSection`
Internal accordion used to show truncated error and empty-result lists (capped at 10 items with overflow count).

### Helper Functions
- `formatDuration(ms)` — converts milliseconds to `HH:MM:SS`
- `formatTime(date)` — formats a `Date` to locale time string
