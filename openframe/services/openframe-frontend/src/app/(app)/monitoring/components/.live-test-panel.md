Real-time test execution panel component that displays live campaign results, progress metrics, and error summaries for query or policy test runs.

## Key Components

**`LiveTestPanel`** — Main export. Renders a card-based panel showing test status, elapsed duration, device response progress, error/empty-result collapsible sections, and a results table.

**`CollapsibleSection`** — Internal toggle section used to show error summaries and hosts with no data, capped at 10 visible rows with overflow count.

**`formatDuration(ms)`** — Converts milliseconds to `HH:MM:SS` string for the live duration counter.

**`formatTime(date)`** — Formats a `Date` to locale-aware `HH:MM:SS` time string for the "Started" field.

## Props (`LiveTestPanelProps`)

| Prop | Type | Description |
|------|------|-------------|
| `mode` | `'query' \| 'policy'` | Controls panel label and export filename |
| `isRunning` | `boolean` | Drives duration timer and Stop/Test Again button visibility |
| `campaignStatus` | `'' \| 'pending' \| 'finished'` | Gates error/empty-result sections |
| `results` | `QueryResultRow[]` | Rows passed to `QueryReportTable` |
| `errors` | `CampaignError[]` | Hosts that returned errors |
| `emptyResults` | `CampaignEmptyResult[]` | Hosts that returned no data |
| `totals` | `CampaignTotals \| null` | Source for total online host count |
| `onTestAgain / onStop / onClose` | `() => void` | Action callbacks |

## Usage Example

```typescript
<LiveTestPanel
  mode="query"
  isRunning={isRunning}
  startedAt={startedAt}
  results={queryResults}
  errors={campaignErrors}
  emptyResults={emptyHosts}
  totals={campaignTotals}
  hostsResponded={42}
  hostsFailed={2}
  campaignStatus="finished"
  onTestAgain={handleTestAgain}
  onStop={handleStop}
  onClose={() => setShowPanel(false)}
/>
```
