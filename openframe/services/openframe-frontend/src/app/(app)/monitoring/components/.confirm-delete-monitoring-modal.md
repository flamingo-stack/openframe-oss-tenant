A reusable confirmation modal for deleting monitoring items (policies or queries), built on top of the shared `ConfirmDialog` component.

## Key Components

**`ConfirmDeleteMonitoringModal`** — Main export. Renders a destructive confirmation dialog with a dynamically generated description highlighting the item name in error styling.

**`ConfirmDeleteMonitoringModalProps`**
| Prop | Type | Description |
|------|------|-------------|
| `open` | `boolean` | Controls dialog visibility |
| `onOpenChange` | `(open: boolean) => void` | Callback for open state changes |
| `itemName` | `string` | Name of the item being deleted (highlighted in red) |
| `itemType` | `'policy' \| 'query'` | Type label used in the dialog description and confirm button |
| `onConfirm` | `() => void` | Callback invoked when the user confirms deletion |

## Usage Example

```typescript
import { ConfirmDeleteMonitoringModal } from './confirm-delete-monitoring-modal';

function MonitoringList() {
  const [open, setOpen] = useState(false);

  return (
    <>
      <button onClick={() => setOpen(true)}>Delete Policy</button>
      <ConfirmDeleteMonitoringModal
        open={open}
        onOpenChange={setOpen}
        itemName="CPU Usage Alert"
        itemType="policy"
        onConfirm={() => {
          deletePolicy('cpu-usage-alert');
          setOpen(false);
        }}
      />
    </>
  );
}
```

The confirm button label auto-capitalizes the `itemType` (e.g., `"policy"` → `"Delete Policy"`), and the `itemName` is rendered with `text-ods-error` styling to visually emphasize the destructive action.
