A reusable confirmation modal for deleting monitoring items (policies or queries), wrapping the shared `ConfirmDialog` component with deletion-specific messaging.

## Key Components

**`ConfirmDeleteMonitoringModal`** — Named export. Renders a destructive confirmation dialog with a dynamically generated description highlighting the item name in error color.

**`ConfirmDeleteMonitoringModalProps`**

| Prop | Type | Description |
|------|------|-------------|
| `open` | `boolean` | Controls dialog visibility |
| `onOpenChange` | `(open: boolean) => void` | Callback for open state changes |
| `itemName` | `string` | Name of the item being deleted (highlighted in red) |
| `itemType` | `'policy' \| 'query'` | Type label used in dialog copy |
| `onConfirm` | `() => void` | Callback executed on deletion confirmation |

## Usage Example

```typescript
import { ConfirmDeleteMonitoringModal } from './confirm-delete-monitoring-modal';

function MonitoringList() {
  const [open, setOpen] = useState(false);

  const handleDelete = () => {
    // perform delete logic
  };

  return (
    <ConfirmDeleteMonitoringModal
      open={open}
      onOpenChange={setOpen}
      itemName="CPU Usage Alert"
      itemType="policy"
      onConfirm={handleDelete}
    />
  );
}
```

> **Note:** The confirm button label is auto-capitalized from `itemType` (e.g., `"policy"` → `"Delete Policy"`). The item name renders with `text-ods-error` styling to visually reinforce the destructive nature of the action.
