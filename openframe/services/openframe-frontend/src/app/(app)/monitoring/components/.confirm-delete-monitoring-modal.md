A reusable confirmation modal for deleting monitoring items (policies or queries), built on top of the shared `ConfirmDialog` component.

## Key Components

- **`ConfirmDeleteMonitoringModal`** — Modal component that renders a destructive action confirmation dialog tailored for monitoring item deletion.
- **`ConfirmDeleteMonitoringModalProps`** — Interface defining the modal's props:
  - `open` / `onOpenChange` — controls visibility state
  - `itemName` — displayed in the description (highlighted in error color)
  - `itemType` — either `'policy'` or `'query'`, used to customize labels
  - `onConfirm` — callback triggered on confirmation

## Usage Example

```typescript
import { ConfirmDeleteMonitoringModal } from './confirm-delete-monitoring-modal';

function MonitoringList() {
  const [open, setOpen] = useState(false);

  const handleDelete = () => {
    // perform deletion logic
  };

  return (
    <>
      <button onClick={() => setOpen(true)}>Delete Policy</button>
      <ConfirmDeleteMonitoringModal
        open={open}
        onOpenChange={setOpen}
        itemName="CPU Threshold Alert"
        itemType="policy"
        onConfirm={handleDelete}
      />
    </>
  );
}
```

The confirm button label is automatically capitalized based on `itemType` (e.g., `"Delete Policy"` or `"Delete Query"`), and the item name is rendered in the error color (`text-ods-error`) to reinforce the destructive nature of the action.
