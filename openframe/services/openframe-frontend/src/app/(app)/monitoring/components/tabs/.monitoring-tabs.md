Defines and exports the tab configuration for the Monitoring section, providing tab metadata and lookup utilities for the Policies and Queries views.

## Key Components

- **`MONITORING_TABS`** — Static array of `TabItem` objects defining the two monitoring tabs: `policies` (with `FolderShieldIcon`) and `queries` (with `BracketCurlyEllipsisVrIcon`), each mapped to their respective components.
- **`getMonitoringTab(tabId)`** — Looks up a `TabItem` by its `id` string; returns `undefined` if not found.
- **`getTabComponent(tabId)`** — Convenience helper that resolves a tab's `React.ComponentType` by ID, returning `null` if the tab or component is absent.

## Usage Example

```typescript
import {
  MONITORING_TABS,
  getMonitoringTab,
  getTabComponent,
} from './monitoring-tabs';

// Render all tabs in a tab bar
MONITORING_TABS.forEach(tab => {
  console.log(tab.id, tab.label); // 'policies', 'queries'
});

// Resolve a tab by ID
const tab = getMonitoringTab('policies');
// → { id: 'policies', label: 'Policies', icon: FolderShieldIcon, component: Policies }

// Dynamically render the tab component
const TabComponent = getTabComponent('queries');
if (TabComponent) {
  return <TabComponent />;
}
```
