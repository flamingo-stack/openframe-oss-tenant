Defines and exports the tab configuration for the Monitoring section, providing tab metadata and utility functions for tab lookup and component resolution.

## Key Components

- **`MONITORING_TABS`** — Static array of `TabItem` objects defining two monitoring tabs:
  - `policies` — Renders the `Policies` component with a folder-shield icon
  - `queries` — Renders the `Queries` component with a curly-bracket icon
- **`getMonitoringTab(tabId)`** — Looks up a `TabItem` by its string ID; returns `undefined` if not found
- **`getTabComponent(tabId)`** — Resolves the React component associated with a tab ID; returns `null` if the tab does not exist

## Usage Example

```typescript
import {
  MONITORING_TABS,
  getMonitoringTab,
  getTabComponent,
} from './monitoring-tabs';

// Render all tabs in a tab bar
MONITORING_TABS.forEach(tab => {
  console.log(tab.id, tab.label); // 'policies', 'queries'
});

// Look up a specific tab by ID
const tab = getMonitoringTab('policies');
// { id: 'policies', label: 'Policies', icon: FolderShieldIcon, component: Policies }

// Dynamically resolve and render the tab's component
const TabComponent = getTabComponent('queries');
if (TabComponent) {
  return <TabComponent />;
}
```
