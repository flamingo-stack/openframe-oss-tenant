Defines and exports the tab configuration for the Monitoring section, mapping tab IDs to their icons and components.

## Key Components

- **`MONITORING_TABS`** — Static array of `TabItem` objects defining the two monitoring tabs: `policies` (Policies component) and `queries` (Queries component), each with an associated icon.
- **`getMonitoringTab(tabId)`** — Looks up a `TabItem` by its string ID, returning `undefined` if not found.
- **`getTabComponent(tabId)`** — Resolves a tab ID to its React component, returning `null` if the tab does not exist.

## Usage Example

```typescript
import {
  MONITORING_TABS,
  getMonitoringTab,
  getTabComponent,
} from './monitoring-tabs';

// Render all tab headers
MONITORING_TABS.forEach(tab => console.log(tab.id, tab.label));

// Resolve a tab by ID
const tab = getMonitoringTab('policies');
// → { id: 'policies', label: 'Policies', icon: FolderShieldIcon, component: Policies }

// Dynamically render a tab's component
const TabComponent = getTabComponent('queries');
if (TabComponent) {
  return <TabComponent />;
}
```
