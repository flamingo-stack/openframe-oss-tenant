A Next.js page component that renders the Architecture tab view within the Flamingo/OpenFrame platform.

## Key Components

- **`ArchitecturePage`** — Default export. A client-side page component that mounts the `ArchitectureTab` UI.
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time.

## Usage Example

```typescript
// Accessed via the /architecture route
// Internally renders:
import { ArchitectureTab } from '../components/tabs/architecture';

export default function ArchitecturePage() {
  return <ArchitectureTab />;
}
```

> This page acts as a thin route wrapper. All UI logic lives in `ArchitectureTab`.
