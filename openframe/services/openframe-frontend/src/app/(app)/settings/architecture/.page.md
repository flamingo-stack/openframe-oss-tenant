Thin page-level route component that renders the Architecture tab view within the application's routing structure.

## Key Components

- **`ArchitecturePage`** — Default export; a client-side page component that mounts the `ArchitectureTab` UI
- **`dynamic = 'force-dynamic'`** — Next.js route segment config that disables static generation, ensuring the page is always server-rendered at request time

## Usage Example

```typescript
// Accessed via its Next.js route (e.g., /architecture)
// No props required — renders ArchitectureTab directly

import ArchitecturePage from './page';

// Next.js resolves this automatically based on the file path
<ArchitecturePage />
```

## Notes

- Marked as `'use client'` to enable client-side interactivity within the `ArchitectureTab` component
- Acts purely as a routing shim; all substantive logic and UI lives in `ArchitectureTab`
