Renders the Architecture page by wrapping the `ArchitectureTab` component in a Next.js client-side route with forced dynamic rendering.

## Key Components

- **`ArchitecturePage`** — Default export; a Next.js page component that renders `ArchitectureTab`
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time

## Usage Example

```typescript
// Accessed via the Next.js router at the /architecture route
// No props required — renders ArchitectureTab directly

import ArchitecturePage from './page';

// Next.js renders this automatically when navigating to /architecture
<ArchitecturePage />
```
