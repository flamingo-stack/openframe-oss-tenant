Renders the AI Settings page by mounting the `AiSettingsTab` component as a full Next.js App Router client-side page with forced dynamic rendering.

## Key Components

- **`AiSettingsPage`** — Default page export that renders the `AiSettingsTab` component
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time

## Usage Example

```typescript
// Accessed via the AI Settings route in the Next.js App Router.
// No props required — rendering is handled entirely by AiSettingsTab.
import AiSettingsPage from './page';

// Renders as:
<AiSettingsPage />
```
