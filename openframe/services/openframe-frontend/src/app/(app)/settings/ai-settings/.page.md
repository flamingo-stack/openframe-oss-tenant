Renders the AI settings page by mounting the `AiSettingsTab` component as a Next.js client-side dynamic route.

## Key Components

- **`AiSettingsPage`** — Default export; page component that renders the `AiSettingsTab` UI
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time

## Usage Example

```typescript
// Accessed via its file-system route, e.g. /settings/ai
// No direct instantiation needed — Next.js App Router handles rendering

export default function AiSettingsPage() {
  return <AiSettingsTab />;
}
```

> This page delegates all UI and logic to `AiSettingsTab`. To modify the AI settings interface, update `../components/tabs/ai-settings` rather than this file.
