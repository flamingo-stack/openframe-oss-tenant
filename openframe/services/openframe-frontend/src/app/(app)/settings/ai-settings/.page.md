Renders the AI Settings page by delegating to the `AiSettingsTab` component within the Next.js App Router.

## Key Components

- **`AiSettingsPage`** — Default page export that renders the `AiSettingsTab` component
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time

## Usage Example

```typescript
// Accessed via its route (e.g., /settings/ai)
// No props required — renders AiSettingsTab directly
export default function AiSettingsPage() {
  return <AiSettingsTab />;
}
```
