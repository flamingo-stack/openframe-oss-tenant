Defines TypeScript types for managing AI settings state in the OpenFrame frontend, specifically for custom policy configuration and edit session snapshots.

## Key Components

### `CustomPolicyState`
Tracks the full state of a custom AI policy being created or modified:

| Field | Type | Description |
|-------|------|-------------|
| `enabled` | `boolean` | Whether the custom policy is active |
| `baseTemplateId` | `string \| null` | ID of the template this policy extends |
| `originalRules` | `Map<string, ApprovalLevel>` | Unmodified rules from the base template |
| `changes` | `Map<string, ApprovalLevel>` | Pending rule modifications |
| `existingOverrides` | `Record<string, ApprovalLevel>` | Previously saved rule overrides |
| `baseTemplateForDisplay` | `PolicyTemplateDetail \| null` | Resolved template data for UI rendering |

### `EditSnapshot`
Captures a point-in-time snapshot of the AI settings editor state for dirty-checking or undo support:

| Field | Type | Description |
|-------|------|-------------|
| `provider` | `string` | Selected AI provider |
| `model` | `string` | Selected AI model |
| `templateId` | `string \| null` | Active policy template |
| `policyGroups` | `Map<string, PermissionCategory[]>` | Permission groups keyed by category name |
| `customBaseTemplateId` | `string \| null` | Base template ID when using a custom policy |

## Usage Example

```typescript
import type { CustomPolicyState, EditSnapshot } from './ai-settings';

const policyState: CustomPolicyState = {
  enabled: true,
  baseTemplateId: 'template-strict',
  originalRules: new Map([['file.read', 'auto']]),
  changes: new Map([['file.write', 'require_approval']]),
  existingOverrides: { 'network.access': 'blocked' },
  baseTemplateForDisplay: null,
};

const snapshot: EditSnapshot = {
  provider: 'openai',
  model: 'gpt-4o',
  templateId: 'template-strict',
  policyGroups: new Map(),
  customBaseTemplateId: null,
};
```
