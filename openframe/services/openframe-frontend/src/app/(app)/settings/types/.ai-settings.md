Defines TypeScript types for managing AI settings state, specifically for custom policy configurations and edit session snapshots in the OpenFrame AI settings workflow.

## Key Components

### `CustomPolicyState`
Tracks the full lifecycle state of a custom AI policy:
- `enabled` — whether the custom policy is active
- `baseTemplateId` — the source template ID this policy derives from
- `originalRules` / `changes` — Maps tracking rule keys to their `ApprovalLevel`, separating original state from pending edits
- `existingOverrides` — persisted overrides keyed by rule identifier
- `baseTemplateForDisplay` — resolved `PolicyTemplateDetail` for UI rendering

### `EditSnapshot`
Captures a point-in-time snapshot of the AI settings editor state for diffing or undo support:
- `provider` / `model` — selected AI provider and model
- `templateId` — active policy template
- `policyGroups` — Map of group keys to arrays of `PermissionCategory`
- `customBaseTemplateId` — base template selected for a custom policy

## Usage Example

```typescript
import type { CustomPolicyState, EditSnapshot } from './ai-settings';

const policyState: CustomPolicyState = {
  enabled: true,
  baseTemplateId: 'template-standard',
  originalRules: new Map([['file.read', 'auto']]),
  changes: new Map([['file.read', 'require_approval']]),
  existingOverrides: { 'file.write': 'blocked' },
  baseTemplateForDisplay: null,
};

const snapshot: EditSnapshot = {
  provider: 'openai',
  model: 'gpt-4o',
  templateId: 'template-standard',
  policyGroups: new Map([['system', ['file', 'network']]]),
  customBaseTemplateId: null,
};
```
