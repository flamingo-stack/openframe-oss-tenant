Defines TypeScript types for managing AI settings state, specifically for custom policy configuration and edit snapshots within the OpenFrame AI settings workflow.

## Key Components

### `CustomPolicyState`
Tracks the full state of a custom AI policy being configured:
- `enabled` — whether the custom policy is active
- `baseTemplateId` — the template this policy is derived from
- `originalRules` / `changes` — Maps tracking per-permission `ApprovalLevel` changes (original vs. pending edits)
- `existingOverrides` — persisted overrides keyed by permission identifier
- `baseTemplateForDisplay` — resolved `PolicyTemplateDetail` for UI rendering

### `EditSnapshot`
Captures a point-in-time snapshot of the AI settings editor state for change tracking or undo support:
- `provider` / `model` — selected AI provider and model
- `templateId` — active policy template
- `policyGroups` — Map of group keys to `PermissionCategory[]` arrays
- `customBaseTemplateId` — base template used when a custom policy is selected

## Usage Example

```typescript
const snapshot: EditSnapshot = {
  provider: 'openai',
  model: 'gpt-4o',
  templateId: 'template-standard',
  policyGroups: new Map([['remote-support', ['read', 'execute']]]),
  customBaseTemplateId: null,
};

const customPolicy: CustomPolicyState = {
  enabled: true,
  baseTemplateId: 'template-standard',
  originalRules: new Map([['remote-support.execute', 'require_approval']]),
  changes: new Map([['remote-support.execute', 'auto_approve']]),
  existingOverrides: { 'remote-support.execute': 'require_approval' },
  baseTemplateForDisplay: null,
};
```
