Defines TypeScript interfaces and constants for the AI policy management system, describing the data structures used to configure, display, and override AI approval policies within OpenFrame.

## Key Components

- **`CUSTOM_CREATION_TEMPLATE_ID`** — Constant identifier (`'CUSTOM_CREATION'`) used to flag a policy as user-created rather than derived from a system template.
- **`PolicyTemplateSummary`** — Lightweight summary of a policy template for list/overview views, including active status and override count.
- **`PolicyRule`** — Granular rule definition mapping a tool/function to an `ApprovalLevel`, identified by a natural key and categorized by group, operation, and command pattern.
- **`PolicyTemplateDetail`** — Full policy template payload including all rules, custom overrides, and optional reference to a source template.
- **`CustomPolicyRequest`** — Request body for creating or updating a custom policy, pairing a `templateId` with a map of rule overrides keyed by natural key.

## Usage Example

```typescript
import type {
  PolicyTemplateSummary,
  PolicyTemplateDetail,
  CustomPolicyRequest,
} from './ai-policies';
import { CUSTOM_CREATION_TEMPLATE_ID } from './ai-policies';

// Build a custom policy creation request
const request: CustomPolicyRequest = {
  templateId: CUSTOM_CREATION_TEMPLATE_ID,
  overrides: {
    'reboot-server:execute': 'REQUIRE_APPROVAL',
    'delete-file:write':     'AUTO_APPROVE',
  },
};

// Type-check a fetched policy detail
const detail: PolicyTemplateDetail = await fetchPolicyDetail('policy-123');
const requiresApproval = detail.rules.filter(
  (rule) => rule.approvalLevel === 'REQUIRE_APPROVAL'
);
```
