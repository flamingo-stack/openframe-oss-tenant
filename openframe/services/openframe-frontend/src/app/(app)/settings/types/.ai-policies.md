Defines shared TypeScript types and constants for the AI policy management system, used to configure approval levels and rules for AI-driven automation across the Flamingo/OpenFrame platform.

## Key Components

- **`CUSTOM_CREATION_TEMPLATE_ID`** — Constant sentinel value (`'CUSTOM_CREATION'`) identifying a new custom policy creation request.
- **`PolicyTemplateSummary`** — Lightweight summary of a policy template for list/index views, including active state and override count.
- **`PolicyRule`** — Granular rule definition mapping a tool/function/operation to an `ApprovalLevel`, identified by a `naturalKey`.
- **`PolicyTemplateDetail`** — Full policy template with all rules, custom overrides, and optional source template reference.
- **`CustomPolicyRequest`** — Payload for applying custom approval-level overrides to an existing template.

## Usage Example

```typescript
import type {
  PolicyTemplateSummary,
  PolicyTemplateDetail,
  CustomPolicyRequest,
  PolicyRule,
} from './ai-policies';
import { CUSTOM_CREATION_TEMPLATE_ID } from './ai-policies';

// Check if user is creating a brand-new custom policy
const isNew = templateId === CUSTOM_CREATION_TEMPLATE_ID;

// Build an override request for a specific template
const request: CustomPolicyRequest = {
  templateId: 'template-abc-123',
  overrides: {
    'restart_service': 'REQUIRE_APPROVAL',
    'read_logs':       'AUTO_APPROVE',
  },
};

// Inspect a rule from a loaded template detail
const detail: PolicyTemplateDetail = await fetchPolicyTemplate('template-abc-123');
detail.rules.forEach((rule: PolicyRule) => {
  console.log(`${rule.tool}.${rule.function} → ${rule.approvalLevel}`);
});
```
