Returns a React icon component for a given SSO provider key, mapping provider names to their corresponding brand icon components.

## Key Components

**`getProviderIcon(providerKey, className?)`**
- `providerKey` — Case-insensitive provider identifier (`'microsoft'`, `'google'`, `'slack'`)
- `className` — Tailwind CSS classes for the icon (defaults to `'h-6 w-6 shrink-0'`)
- Returns the matching `React.ReactElement`, or `null` for unsupported providers

**Supported Providers**

| Key | Component |
|-----|-----------|
| `microsoft` | `MicrosoftIcon` |
| `google` | `GoogleLogo` |
| `slack` | `SlackIcon` |

## Usage Example

```typescript
import { getProviderIcon } from './get-provider-icon';

// Default size
const icon = getProviderIcon('microsoft');

// Custom size
const largeIcon = getProviderIcon('google', 'h-8 w-8 shrink-0');

// Handle unsupported provider
const unknown = getProviderIcon('github'); // returns null

// Typical usage in a component
function SSOButton({ providerKey, label }: { providerKey: string; label: string }) {
  const icon = getProviderIcon(providerKey);
  return (
    <button>
      {icon}
      <span>{label}</span>
    </button>
  );
}
```

> Provider key matching is case-insensitive — `'Microsoft'`, `'MICROSOFT'`, and `'microsoft'` all resolve to `MicrosoftIcon`.
