Returns the appropriate React icon component for a given SSO provider key, mapping provider strings to their corresponding brand icon components.

## Key Components

- **`getProviderIcon(providerKey, className?)`** — Main exported function that performs a case-insensitive lookup and returns the matching icon component, or `null` for unsupported providers.

**Supported providers:**

| Key | Icon Component |
|-----|---------------|
| `microsoft` | `MicrosoftIcon` |
| `google` | `GoogleLogo` |
| `slack` | `SlackIcon` |

## Usage Example

```typescript
import { getProviderIcon } from './get-provider-icon';

// Default size (h-6 w-6 shrink-0)
const icon = getProviderIcon('microsoft');

// Custom size
const largeIcon = getProviderIcon('google', 'h-8 w-8');

// Unsupported provider returns null
const unknown = getProviderIcon('github'); // null

// Typical usage in a component
function ProviderButton({ providerKey }: { providerKey: string }) {
  return (
    <button>
      {getProviderIcon(providerKey)}
      <span>Sign in with {providerKey}</span>
    </button>
  );
}
```

> **Note:** Provider key matching is case-insensitive — `'Microsoft'`, `'MICROSOFT'`, and `'microsoft'` all resolve to `MicrosoftIcon`.
