Returns the appropriate React icon component for a given SSO provider key, supporting Microsoft, Google, and Slack.

## Key Components

- **`getProviderIcon(providerKey, className?)`** — Maps a provider string to its corresponding icon component. Performs a case-insensitive match and returns `null` for unsupported providers.

## Supported Providers

| `providerKey` | Icon Component |
|---|---|
| `microsoft` | `MicrosoftIcon` |
| `google` | `GoogleLogo` |
| `slack` | `SlackIcon` |

## Usage Example

```typescript
import { getProviderIcon } from './get-provider-icon';

// Default size (h-6 w-6 shrink-0)
const icon = getProviderIcon('microsoft');

// Custom className
const smallIcon = getProviderIcon('google', 'h-4 w-4');

// Unsupported provider returns null
const unknown = getProviderIcon('github'); // null

// Typical usage inside JSX
function ProviderButton({ providerKey }: { providerKey: string }) {
  return (
    <button>
      {getProviderIcon(providerKey)}
      Sign in with {providerKey}
    </button>
  );
}
```
