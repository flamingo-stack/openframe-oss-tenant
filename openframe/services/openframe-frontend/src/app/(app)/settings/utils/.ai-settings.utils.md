Utility functions for transforming flat `PolicyRule` arrays into structured, UI-ready permission group hierarchies used by the AI settings interface.

## Key Components

- **`buildPolicyGroups(rules)`** — Transforms a flat array of `PolicyRule` entries into a nested `Map<string, PermissionCategory[]>`, grouping by `policyGroup` → `category`. Each category receives a `Shield` icon and sorted policies with normalized tool types and approval levels.
- **`clonePolicyGroups(groups)`** — Deep-clones the `Map<string, PermissionCategory[]>` structure (including nested policy objects) to prevent unintended mutation.
- **`mapToObject(entries)`** — Converts a `Map<string, T>` to a plain `Record<string, T>` object for serialization or prop passing.
- **`slugify(value)`** *(internal)* — Normalizes a string to a URL-safe slug used as stable category IDs.

## Usage Example

```typescript
import { buildPolicyGroups, clonePolicyGroups, mapToObject } from './ai-settings.utils';

// Build grouped policy structure from raw rules
const groups = buildPolicyGroups(policyRules);
// groups.get('Network') → PermissionCategory[]

// Clone before mutation (e.g. local state edits)
const draft = clonePolicyGroups(groups);

// Convert to plain object for API submission or state storage
const payload = mapToObject(groups);
// { Network: [...], General: [...] }
```

> **Note:** `buildPolicyGroups` falls back to `'General'` for rules missing a `policyGroup` and `'Other'` for those missing a `category`. Categories are sorted alphabetically within each group.
