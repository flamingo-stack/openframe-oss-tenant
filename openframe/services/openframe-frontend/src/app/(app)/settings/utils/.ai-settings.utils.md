Utility functions for transforming raw AI policy rules into structured, grouped permission categories for display and management in the OpenFrame AI settings UI.

## Key Components

### `buildPolicyGroups(rules: PolicyRule[])`
Transforms a flat array of `PolicyRule` objects into a nested `Map<string, PermissionCategory[]>`, grouping first by `policyGroup` (defaulting to `"General"`), then by `category` (defaulting to `"Other"`). Each category receives a `Shield` icon and a sorted list of resolved policies with normalized tool types and approval levels.

### `clonePolicyGroups(groups: Map<string, PermissionCategory[]>)`
Performs a deep clone of a policy groups `Map`, ensuring policies and categories are fully independent copies — safe for local state mutations without affecting the original.

### `mapToObject<T>(entries: Map<string, T>)`
Generic helper that converts any `Map<string, T>` to a plain `Record<string, T>` object, useful for serialization or prop passing.

### `slugify(value: string)` *(internal)*
Converts a string to a URL-safe slug used as a deterministic category ID (e.g., `"PSA:Tickets"` → `"psa-tickets"`).

## Usage Example

```typescript
import { buildPolicyGroups, clonePolicyGroups, mapToObject } from './ai-settings.utils';

// Build structured groups from flat policy rules
const policyGroups = buildPolicyGroups(rules);

// Clone before mutating local state
const localCopy = clonePolicyGroups(policyGroups);

// Serialize for API submission
const payload = mapToObject(localCopy);
```
