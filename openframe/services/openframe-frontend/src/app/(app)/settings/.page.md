Client-side settings page entry point that renders the main `SettingsHub` component with forced dynamic rendering.

## Key Components

- **`Settings`** — Default page component that mounts the `SettingsHub`
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time

## Usage Example

```typescript
// Accessed via Next.js routing at /settings
// No props required — renders SettingsHub directly
export default function Settings() {
  return <SettingsHub />;
}
```
