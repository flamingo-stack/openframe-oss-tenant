Client-side settings page entry point that renders the `SettingsHub` component with forced dynamic rendering (no static caching).

## Key Components

- **`Settings`** — Default page component that mounts the `SettingsHub`
- **`dynamic = 'force-dynamic'`** — Next.js config export disabling static generation for this route

## Usage Example

```typescript
// Automatically rendered by Next.js at the /settings route
// No direct invocation needed — imports SettingsHub internally
import Settings from './page';

// Or navigate to the route in your app
router.push('/settings');
```
