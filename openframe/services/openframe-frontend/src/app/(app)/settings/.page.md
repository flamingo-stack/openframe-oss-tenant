A Next.js client-side settings page that renders the `SettingsHub` component as its primary UI.

## Key Components

- **`Settings`** — Default page export that serves as the entry point for the settings route
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time
- **`SettingsHub`** — Imported component that contains the full settings interface logic and layout

## Usage Example

```typescript
// Accessed via the /settings route in Next.js App Router
// No props required — the page delegates all rendering to SettingsHub

import { SettingsHub } from './components/settings-hub';

export default function Settings() {
  return <SettingsHub />;
}
```

> This page acts as a thin shell — all settings logic lives inside `SettingsHub`. To extend or modify the settings UI, update `./components/settings-hub` rather than this file.
