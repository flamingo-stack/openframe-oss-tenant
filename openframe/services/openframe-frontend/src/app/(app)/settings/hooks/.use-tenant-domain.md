React hook for fetching and updating tenant domain configuration, including auto-provisioning settings via the global domain API.

## Key Components

**Types**
- `TenantDomainInfo` — Shape of the domain config response (`domain`, `generic`, `autoAllow`)
- `UpdateSharedAutoProvisionPayload` — Payload for toggling auto-provision (`autoAllow: boolean`)
- `UpdateSharedAutoProvisionResponse` — Union result with optional `success` or structured `error`

**Hook: `useTenantDomain()`**

Returns:
| Property | Type | Description |
|---|---|---|
| `fetchTenantDomain` | `() => Promise<TenantDomainInfo>` | GET tenant domain from `api/config/global/domain` |
| `updateSharedAutoProvision` | `(enabled: boolean) => Promise<UpdateSharedAutoProvisionResponse>` | POST auto-provision toggle to `api/config/global/domain` |
| `isLoading` | `boolean` | True while `fetchTenantDomain` is in-flight |
| `isUpdating` | `boolean` | True while `updateSharedAutoProvision` is in-flight |

## Usage Example

```typescript
import { useTenantDomain } from '@/hooks/use-tenant-domain';

export function DomainSettings() {
  const { fetchTenantDomain, updateSharedAutoProvision, isLoading, isUpdating } = useTenantDomain();

  useEffect(() => {
    fetchTenantDomain().then((info) => {
      console.log(info.domain, info.autoAllow);
    });
  }, [fetchTenantDomain]);

  const handleToggle = async (enabled: boolean) => {
    const result = await updateSharedAutoProvision(enabled);
    if (result.error) {
      console.error(result.error.message);
    }
  };

  return <Toggle disabled={isUpdating} onChange={handleToggle} />;
}
```

> **Note:** `autoAllow` defaults to `false` when absent from the API response. `updateSharedAutoProvision` surfaces structured `BAD_REQUEST` errors as return values rather than thrown exceptions, but re-throws unexpected errors for caller handling.
