React hook for managing tenant domain configuration, providing fetch and update operations for domain info and auto-provisioning settings via the API.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `TenantDomainInfo` | Domain details including `domain`, `generic` flag, and `autoAllow` setting |
| `UpdateSharedAutoProvisionPayload` | Payload for toggling auto-provision (`autoAllow: boolean`) |
| `UpdateSharedAutoProvisionResponse` | Response shape with optional `success` or structured `error` |

### Hook: `useTenantDomain`

| Return Value | Type | Description |
|-------------|------|-------------|
| `fetchTenantDomain` | `() => Promise<TenantDomainInfo>` | Fetches domain config from `api/config/global/domain` |
| `updateSharedAutoProvision` | `(enabled: boolean) => Promise<UpdateSharedAutoProvisionResponse>` | POSTs auto-provision toggle; handles both structured and generic error formats |
| `isLoading` | `boolean` | `true` while fetch is in flight |
| `isUpdating` | `boolean` | `true` while update is in flight |

## Usage Example

```typescript
import { useTenantDomain } from '@/hooks/use-tenant-domain';

function TenantDomainSettings() {
  const { fetchTenantDomain, updateSharedAutoProvision, isLoading, isUpdating } = useTenantDomain();

  const handleLoad = async () => {
    const domain = await fetchTenantDomain();
    console.log(domain.domain, domain.generic, domain.autoAllow);
  };

  const handleToggle = async (enabled: boolean) => {
    const result = await updateSharedAutoProvision(enabled);
    if (result.error) {
      console.error(`[${result.error.code}] ${result.error.message}`);
    }
  };

  return <button disabled={isLoading || isUpdating} onClick={() => handleToggle(true)} />;
}
```

> `autoAllow` defaults to `false` when absent from the API response, guarding against older API versions that may not return the property.
