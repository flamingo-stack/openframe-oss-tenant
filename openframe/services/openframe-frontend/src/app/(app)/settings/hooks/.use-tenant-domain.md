React hook for fetching and updating tenant domain configuration, including auto-provisioning settings via the global domain API.

## Key Components

### Types

- **`TenantDomainInfo`** — Shape of the domain config response (`domain`, `generic`, `autoAllow`)
- **`UpdateSharedAutoProvisionPayload`** — Payload for toggling auto-allow (`{ autoAllow: boolean }`)
- **`UpdateSharedAutoProvisionResponse`** — Response shape with optional `success` flag or structured `error`

### Hook: `useTenantDomain`

Returns the following:

| Property | Type | Description |
|---|---|---|
| `fetchTenantDomain` | `() => Promise<TenantDomainInfo>` | Fetches domain config from `api/config/global/domain` |
| `updateSharedAutoProvision` | `(enabled: boolean) => Promise<...>` | POSTs auto-provision toggle to the same endpoint |
| `isLoading` | `boolean` | True while fetching domain info |
| `isUpdating` | `boolean` | True while submitting an update |

> `autoAllow` defaults to `false` if the property is absent in the API response.

## Usage Example

```typescript
import { useTenantDomain } from '@/hooks/use-tenant-domain';

function DomainSettings() {
  const { fetchTenantDomain, updateSharedAutoProvision, isLoading, isUpdating } = useTenantDomain();

  const handleLoad = async () => {
    const domain = await fetchTenantDomain();
    console.log(domain.domain, domain.generic, domain.autoAllow);
  };

  const handleToggle = async (enabled: boolean) => {
    const result = await updateSharedAutoProvision(enabled);
    if (result.error) {
      console.error(`[${result.error.code}] ${result.error.message}`);
    }
  };

  return (
    <button disabled={isLoading || isUpdating} onClick={() => handleToggle(true)}>
      Enable Auto-Provision
    </button>
  );
}
```
