React hook for managing SSO (Single Sign-On) provider configuration via the Flamingo API, exposing async operations to fetch, update, and toggle identity providers.

## Key Components

**Types**
- `AvailableProvider` — Provider identifier and display name
- `ProviderConfig` — Full provider configuration including credentials, tenant ID, and provisioning settings
- `UpdateSsoPayload` — Payload shape for creating/updating a provider's OAuth credentials

**Hook: `useSsoConfig`**

| Function | Description |
|---|---|
| `fetchAvailableProviders()` | Lists all supported SSO providers from `GET api/sso/providers/available` |
| `fetchProviderConfig(provider)` | Retrieves current config for a given provider; returns `undefined` if not configured |
| `updateProviderConfig(provider, payload)` | Saves OAuth credentials and settings via `PUT api/sso/:provider` |
| `toggleProviderEnabled(provider, enabled)` | Enables or disables a provider via `PATCH api/sso/:provider/toggle` |

All functions are memoized with `useCallback`.

## Usage Example

```typescript
import { useSsoConfig } from '@/hooks/use-sso-config';

function SsoSettings() {
  const {
    fetchAvailableProviders,
    fetchProviderConfig,
    updateProviderConfig,
    toggleProviderEnabled,
  } = useSsoConfig();

  async function handleSave(provider: string) {
    await updateProviderConfig(provider, {
      clientId: 'my-client-id',
      clientSecret: 'my-secret',
      msTenantId: 'tenant-id',       // Microsoft only
      autoProvisionUsers: true,
      allowedDomains: ['example.com'],
    });

    await toggleProviderEnabled(provider, true);
  }
}
```
