A React hook for managing SSO (Single Sign-On) provider configuration, providing CRUD operations for fetching, updating, and toggling SSO providers via the API client.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `AvailableProvider` | Provider name and display label |
| `ProviderConfig` | Full provider configuration including credentials and domain restrictions |
| `UpdateSsoPayload` | Payload shape for creating/updating a provider config |

### Hook: `useSsoConfig`

Returns four memoized async functions:

| Function | Method | Description |
|----------|--------|-------------|
| `fetchAvailableProviders` | `GET api/sso/providers/available` | Lists all supported SSO providers |
| `fetchProviderConfig` | `GET api/sso/:provider` | Retrieves config for a specific provider; returns `undefined` if not found |
| `updateProviderConfig` | `PUT api/sso/:provider` | Creates or updates provider credentials and settings |
| `toggleProviderEnabled` | `PATCH api/sso/:provider/toggle` | Enables or disables a provider |

## Usage Example

```typescript
import { useSsoConfig } from '@/hooks/use-sso-config';

function SsoSettings() {
  const {
    fetchAvailableProviders,
    fetchProviderConfig,
    updateProviderConfig,
    toggleProviderEnabled,
  } = useSsoConfig();

  const handleSave = async () => {
    await updateProviderConfig('microsoft', {
      clientId: 'your-client-id',
      clientSecret: 'your-client-secret',
      msTenantId: 'your-tenant-id',
      autoProvisionUsers: true,
      allowedDomains: ['company.com'],
    });

    await toggleProviderEnabled('microsoft', true);
  };
}
```

> `fetchProviderConfig` returns `undefined` rather than throwing when no configuration exists, allowing callers to distinguish between "not configured" and an actual API error.
