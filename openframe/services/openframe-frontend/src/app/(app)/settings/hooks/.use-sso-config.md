A React hook providing API interaction methods for managing SSO (Single Sign-On) provider configurations, including fetching, updating, and toggling providers.

## Key Components

**Types**
- `AvailableProvider` — Provider identifier and display name
- `ProviderConfig` — Full SSO provider configuration including credentials, tenant ID, and domain allowlist
- `UpdateSsoPayload` — Payload shape for creating or updating a provider config

**Hook: `useSsoConfig`**

| Method | Description |
|--------|-------------|
| `fetchAvailableProviders()` | Retrieves all available SSO providers |
| `fetchProviderConfig(provider)` | Fetches config for a specific provider; returns `undefined` if not configured |
| `updateProviderConfig(provider, payload)` | Creates or updates credentials and settings for a provider |
| `toggleProviderEnabled(provider, enabled)` | Enables or disables a provider via PATCH |

## Usage Example

```typescript
import { useSsoConfig } from '@/hooks/use-sso-config';

function SsoSettings() {
  const {
    fetchAvailableProviders,
    fetchProviderConfig,
    updateProviderConfig,
    toggleProviderEnabled,
  } = useSsoConfig();

  const handleLoad = async () => {
    const providers = await fetchAvailableProviders();
    const config = await fetchProviderConfig('microsoft');
    console.log(providers, config);
  };

  const handleSave = async () => {
    await updateProviderConfig('microsoft', {
      clientId: 'your-client-id',
      clientSecret: 'your-secret',
      msTenantId: 'your-tenant-id',
      autoProvisionUsers: true,
      allowedDomains: ['example.com'],
    });
    await toggleProviderEnabled('microsoft', true);
  };
}
```

> All methods are memoized with `useCallback` and throw descriptive errors on failed API responses.
