Custom React hook managing AI policy templates — fetching, selecting, activating, and creating/updating custom policies via the OpenFrame API.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `useAiPolicies` | Hook | Primary hook exposing policy state and CRUD operations |
| `fetchTemplates` | `async () => void` | Loads all policy templates, sorts CUSTOM types to end, sets active selection |
| `fetchTemplate` | `async (policyId) => PolicyTemplateDetail` | Loads full detail for a single policy template |
| `activateTemplate` | `async (policyId) => void` | Activates a policy template as the live guardrail |
| `createOrUpdateCustomPolicy` | `async (baseTemplateId, overrides) => string` | Creates or updates a custom policy with `ApprovalLevel` overrides |
| `refetchSelectedTemplate` | `() => Promise` | Re-fetches the currently selected template (no-ops for custom creation mode) |
| `templateOptions` | `Array` | Memoized display list derived from raw `templates` state |

## Usage Example

```typescript
import { useAiPolicies } from './use-ai-policies';

function AIPoliciesPanel() {
  const {
    templateOptions,
    selectedTemplateId,
    setSelectedTemplateId,
    selectedTemplate,
    activeTemplateId,
    isLoading,
    isActivating,
    activateTemplate,
    createOrUpdateCustomPolicy,
  } = useAiPolicies();

  if (isLoading) return <Spinner />;

  const handleActivate = async () => {
    if (!selectedTemplateId) return;
    await activateTemplate(selectedTemplateId);
  };

  const handleCustomSave = async () => {
    await createOrUpdateCustomPolicy('base-template-id', {
      'delete-device': 'REQUIRE_APPROVAL',
      'run-script': 'AUTO_APPROVE',
    });
  };

  return (
    <PolicySelector
      options={templateOptions}
      selected={selectedTemplateId}
      active={activeTemplateId}
      template={selectedTemplate}
      onSelect={setSelectedTemplateId}
      onActivate={handleActivate}
      onSaveCustom={handleCustomSave}
      isActivating={isActivating}
    />
  );
}
```

> **Note:** The hook automatically fetches templates on mount and re-fetches the selected template whenever `selectedTemplateId` changes. The `CUSTOM_CREATION_TEMPLATE_ID` sentinel value bypasses template detail fetching for new custom policy creation flows.
