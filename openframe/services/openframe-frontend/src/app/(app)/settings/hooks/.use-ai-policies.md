React hook managing AI policy templates — fetching, selecting, activating, and creating/updating custom guardrail policies via the OpenFrame chat API.

## Key Components

**`useAiPolicies()`** — Primary hook returning:

| Return Value | Type | Description |
|---|---|---|
| `templates` | `PolicyTemplateSummary[]` | All available policy templates (custom sorted last) |
| `templateOptions` | `array` | Mapped options for UI selectors |
| `activeTemplateId` | `string \| null` | Currently active policy ID |
| `selectedTemplateId` / `setSelectedTemplateId` | `string \| null` | Currently viewed template in UI |
| `selectedTemplate` | `PolicyTemplateDetail \| null` | Full detail of the selected template |
| `isLoading` / `isLoadingTemplate` / `isActivating` | `boolean` | Loading states |
| `activateTemplate(policyId)` | `async fn` | Activates a policy and refreshes state |
| `createOrUpdateCustomPolicy(baseId, overrides)` | `async fn` | Creates/updates a custom policy with approval-level overrides |
| `refetchTemplates` / `refetchSelectedTemplate` | `async fn` | Manual refresh helpers |

**Internal helpers:**
- `fetchTemplates()` — loads all templates, sorts CUSTOM to end, resolves active/selected IDs
- `fetchTemplate(policyId)` — loads full detail for a single template
- `getErrorMessage()` — normalizes error objects to strings for toast messages

## Usage Example

```typescript
import { useAiPolicies } from './use-ai-policies';

function AiPoliciesPanel() {
  const {
    templateOptions,
    selectedTemplateId,
    setSelectedTemplateId,
    selectedTemplate,
    isLoading,
    isActivating,
    activateTemplate,
    createOrUpdateCustomPolicy,
  } = useAiPolicies();

  if (isLoading) return <Spinner />;

  const handleActivate = async () => {
    if (selectedTemplateId) {
      await activateTemplate(selectedTemplateId);
    }
  };

  const handleCustomSave = async () => {
    await createOrUpdateCustomPolicy('base-template-id', {
      'ticket-creation': 'AUTO',
      'remote-access': 'REQUIRE_APPROVAL',
    });
  };

  return (
    <PolicySelector
      options={templateOptions}
      selected={selectedTemplateId}
      onSelect={setSelectedTemplateId}
      detail={selectedTemplate}
      onActivate={handleActivate}
      activating={isActivating}
      onSaveCustom={handleCustomSave}
    />
  );
}
```

> **Note:** Selecting `CUSTOM_CREATION_TEMPLATE_ID` suppresses the auto-fetch of template details, allowing the UI to render a blank creation form instead.
