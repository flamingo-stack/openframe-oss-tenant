React hook managing AI policy templates — fetching, selecting, activating, and creating/updating custom guardrail policies via the OpenFrame API.

## Key Components

**`useAiPolicies()`** — Primary hook exposing:

| Returned Value | Type | Description |
|---|---|---|
| `templates` | `PolicyTemplateSummary[]` | Raw list of all policy templates |
| `templateOptions` | `{id, label, description, isActive, type}[]` | Memoized display-ready options |
| `activeTemplateId` | `string \| null` | Currently activated policy ID |
| `selectedTemplateId` | `string \| null` | Currently selected (viewed) policy ID |
| `selectedTemplate` | `PolicyTemplateDetail \| null` | Full detail of the selected policy |
| `isLoading` | `boolean` | Initial template list load state |
| `isLoadingTemplate` | `boolean` | Individual template fetch state |
| `isActivating` | `boolean` | Activation request in-flight state |
| `activateTemplate` | `(policyId: string) => Promise` | Activates a policy and refreshes state |
| `createOrUpdateCustomPolicy` | `(baseTemplateId, overrides) => Promise` | Creates or updates a custom policy |
| `refetchTemplates` | `() => Promise` | Manually re-fetches the template list |
| `refetchSelectedTemplate` | `() => Promise` | Re-fetches the currently selected template |

**Internal helpers:**
- `fetchTemplates` — Loads and sorts all templates (custom types sorted to end), resolves active/selected IDs
- `fetchTemplate(policyId)` — Loads full detail for a single policy
- `getErrorMessage` — Normalizes unknown errors to strings for toast messages

## Usage Example

```typescript
import { useAiPolicies } from './hooks/use-ai-policies';

function AiPoliciesPanel() {
  const {
    templateOptions,
    selectedTemplateId,
    setSelectedTemplateId,
    selectedTemplate,
    isLoading,
    isActivating,
    activateTemplate,
    createOrUpdateCustomPolicy,
  } = useAiPolicies();

  if (isLoading) return <Spinner />;

  return (
    <>
      <PolicySelector
        options={templateOptions}
        value={selectedTemplateId}
        onChange={setSelectedTemplateId}
      />
      <PolicyDetail template={selectedTemplate} />
      <button
        disabled={isActivating}
        onClick={() => activateTemplate(selectedTemplateId!)}
      >
        Activate Policy
      </button>
      <button
        onClick={() =>
          createOrUpdateCustomPolicy('base-template-id', {
            'ticket.delete': 'REQUIRE_APPROVAL',
          })
        }
      >
        Save Custom Policy
      </button>
    </>
  );
}
```

> **Note:** Selecting `CUSTOM_CREATION_TEMPLATE_ID` suppresses automatic detail fetching, allowing the UI to render a creation form without triggering an API call.
