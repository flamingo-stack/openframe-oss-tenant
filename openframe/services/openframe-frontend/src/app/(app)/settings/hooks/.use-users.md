React Query hook for fetching and managing paginated user data, with built-in delete mutation and toast error handling.

## Key Components

**Types**
- `UserStatus` — Enum with `Active` and `Deleted` states
- `UserRecord` — User entity shape (id, email, name, roles, status, timestamps)
- `PagedUsersResponse` — Paginated API response wrapper

**Query Keys**
- `usersQueryKeys` — Structured cache key factory for list queries (`['users', 'list', { page, size }]`)

**Hook: `useUsers(page?, size?)`**
- Fetches a paginated user list via `GET /api/users?page=&size=`
- Exposes `deleteUser(userId, options?)` — calls `DELETE /api/users/:id`, invalidates cache on success, shows toast on error
- Returns pagination metadata (`totalPages`, `hasNext`, `hasPrevious`, etc.)
- Exposes raw `usersQuery` and `deleteUserMutation` for advanced use cases

## Usage Example

```typescript
import { useUsers } from '@/hooks/use-users';

function UserList() {
  const {
    users,
    isLoading,
    error,
    totalPages,
    hasNext,
    deleteUser,
  } = useUsers(0, 20);

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;

  return (
    <>
      {users.map(user => (
        <UserRow
          key={user.id}
          user={user}
          onDelete={() =>
            deleteUser(user.id, {
              onSuccess: () => console.log('User deleted'),
            })
          }
        />
      ))}
      <Pagination hasNext={hasNext} totalPages={totalPages} />
    </>
  );
}
```

> **Note:** `page` defaults to `0` and `size` defaults to `20`. Pass custom values to control pagination from the parent component.
