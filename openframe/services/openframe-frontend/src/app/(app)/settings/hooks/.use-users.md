React Query hook for fetching and managing paginated user data, including user deletion with toast notifications and cache invalidation.

## Key Components

**Types**
- `UserStatus` — Enum with `Active` and `Deleted` states
- `UserRecord` — User entity shape (id, email, name, roles, status, timestamps)
- `PagedUsersResponse` — Paginated API response wrapper

**Query Keys**
- `usersQueryKeys` — Structured cache key factory for list queries

**Hook: `useUsers(page, size)`**
- Fetches paginated users via `GET /api/users?page=&size=`
- Exposes `deleteUser(userId, options?)` with automatic cache invalidation and error toasting
- Returns flat pagination metadata alongside user data

## Usage Example

```typescript
import { useUsers } from '@/hooks/use-users';

function UserTable() {
  const {
    users,
    isLoading,
    error,
    totalPages,
    hasNext,
    hasPrevious,
    deleteUser,
  } = useUsers(0, 20);

  if (isLoading) return <Spinner />;
  if (error) return <Error message={error} />;

  return (
    <>
      {users.map(user => (
        <UserRow
          key={user.id}
          user={user}
          onDelete={() =>
            deleteUser(user.id, {
              onSuccess: () => console.log('User deleted'),
            })
          }
        />
      ))}
      <Pagination totalPages={totalPages} hasNext={hasNext} hasPrevious={hasPrevious} />
    </>
  );
}
```

**Parameters**

| Param | Default | Description |
|-------|---------|-------------|
| `page` | `0` | Zero-based page index |
| `size` | `20` | Records per page |
