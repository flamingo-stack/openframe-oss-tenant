React Query hook for fetching and managing paginated user records, with support for deleting users and automatic cache invalidation.

## Key Components

### Types & Enums

- **`UserStatus`** — Enum with `Active` (`ACTIVE`) and `Deleted` (`DELETED`) values
- **`UserRecord`** — User shape including `id`, `email`, `roles`, `status`, and optional name/timestamp fields
- **`PagedUsersResponse`** — Paginated response wrapper with `items`, pagination metadata, and navigation flags

### Query Keys

- **`usersQueryKeys`** — Structured cache key factory: `all` for broad invalidation, `list(page, size)` for scoped queries

### Hook

- **`useUsers(page, size)`** — Primary hook; defaults to page `0`, size `20`. Returns user data, pagination info, loading/error states, `deleteUser` action, and the raw `usersQuery` for advanced use.

## Usage Example

```typescript
function UsersTable() {
  const [page, setPage] = useState(0);

  const {
    users,
    isLoading,
    error,
    totalPages,
    hasNext,
    hasPrevious,
    deleteUser,
    deleteUserMutation,
  } = useUsers(page, 20);

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;

  return (
    <>
      {users.map(user => (
        <UserRow
          key={user.id}
          user={user}
          onDelete={() =>
            deleteUser(user.id, {
              onSuccess: () => console.log('User deleted'),
            })
          }
          isDeleting={deleteUserMutation.isPending}
        />
      ))}
      <Pagination
        page={page}
        totalPages={totalPages}
        hasNext={hasNext}
        hasPrevious={hasPrevious}
        onChange={setPage}
      />
    </>
  );
}
```

> On successful deletion, the hook automatically invalidates all `users` queries via `usersQueryKeys.all`, keeping every paginated view in sync without a manual refetch.
