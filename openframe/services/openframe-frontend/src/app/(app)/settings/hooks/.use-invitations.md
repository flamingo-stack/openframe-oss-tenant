React Query hook for managing user invitations, providing paginated fetching, revocation, resending, and bulk invite operations with toast notifications.

## Key Components

**Types**
- `InvitationStatus` — enum with `Pending` and `Expired` states
- `InvitationRecord` — single invitation shape (id, email, roles, timestamps, status)
- `PagedInvitationsResponse` — paginated wrapper around `InvitationRecord[]`

**Query Keys**
- `invitationsQueryKeys` — structured cache key factory for list queries

**API Functions** *(internal)*
- `fetchInvitations(page, size)` — GET paginated invitations
- `revokeInvitationApi(id)` — DELETE a single invitation
- `resendInvitationApi(id)` — POST resend to invitation endpoint
- `inviteUsersApi(emails[])` — POST bulk invites, collecting per-email failures

**Hook**
- `useInvitations(page?, size?)` — main export; returns data, pagination metadata, loading/error states, and all mutation handlers

## Usage Example

```typescript
import { useInvitations } from '@/hooks/use-invitations';

function InvitationsTable() {
  const {
    invitations,
    isLoading,
    totalPages,
    hasNext,
    revokeInvitation,
    resendInvitation,
    inviteUsers,
    inviteUsersMutation,
  } = useInvitations(0, 20);

  const handleInvite = async () => {
    await inviteUsers(['alice@example.com', 'bob@example.com']);
  };

  const handleRevoke = (id: string) => {
    revokeInvitation(id, {
      onSuccess: () => console.log('Revoked'),
      onError: (err) => console.error(err),
    });
  };

  if (isLoading) return <Spinner />;

  return (
    <>
      {invitations.map(inv => (
        <InvitationRow
          key={inv.id}
          invitation={inv}
          onRevoke={() => handleRevoke(inv.id)}
          onResend={() => resendInvitation(inv.id)}
        />
      ))}
      <button onClick={handleInvite} disabled={inviteUsersMutation.isPending}>
        Invite Users
      </button>
    </>
  );
}
```

> **Note:** All mutation errors are surfaced via toast notifications automatically. Optional `onSuccess`/`onError` callbacks are supported on `revokeInvitation` and `resendInvitation` for additional side effects. Cache is invalidated across all invitation queries on any successful mutation.
