React Query hook for managing user invitations — fetching paginated invitation lists, sending new invites, revoking, and resending invitations with toast notifications on errors.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `useInvitations` | Hook | Main hook for invitation CRUD operations with pagination |
| `InvitationStatus` | Enum | `PENDING` \| `EXPIRED` invitation states |
| `InvitationRecord` | Type | Single invitation shape (id, email, roles, dates, status) |
| `PagedInvitationsResponse` | Type | Paginated API response wrapper |
| `invitationsQueryKeys` | Object | Structured React Query cache keys |

## Usage Example

```typescript
import { useInvitations } from '@/hooks/use-invitations';

function InvitationsPage() {
  const {
    invitations,
    isLoading,
    totalPages,
    hasNext,
    revokeInvitation,
    resendInvitation,
    inviteUsers,
    inviteUsersMutation,
  } = useInvitations(0, 20);

  const handleInvite = async () => {
    await inviteUsers(['alice@example.com', 'bob@example.com']);
  };

  const handleRevoke = (id: string) => {
    revokeInvitation(id, {
      onSuccess: () => console.log('Invitation revoked'),
    });
  };

  const handleResend = (id: string) => {
    resendInvitation(id, {
      onError: (err) => console.error(err.message),
    });
  };

  if (isLoading) return <Spinner />;

  return (
    <>
      {invitations.map(inv => (
        <InvitationRow
          key={inv.id}
          invitation={inv}
          onRevoke={() => handleRevoke(inv.id)}
          onResend={() => handleResend(inv.id)}
        />
      ))}
    </>
  );
}
```

## Notes

- `inviteUsers` accepts multiple emails and sends them concurrently via `Promise.all`, collecting per-address failures into a single thrown error.
- All mutations automatically invalidate the `invitations` query cache on success.
- Error handling delegates to `handleApiError` which surfaces messages via the shared toast system.
- Pagination metadata (`totalPages`, `hasNext`, `hasPrevious`) is forwarded directly from the API response.
