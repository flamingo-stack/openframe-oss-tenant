React Query hook for managing user invitations — fetching paginated records, sending new invites, revoking, and resending existing ones.

## Key Components

**Types**
- `InvitationStatus` — enum with `Pending` and `Expired` states
- `InvitationRecord` — single invitation shape (id, email, roles, timestamps, status)
- `PagedInvitationsResponse` — paginated wrapper around `InvitationRecord[]`

**Query Keys**
- `invitationsQueryKeys` — structured cache key factory for list queries

**Hook**
- `useInvitations(page, size)` — primary export; wraps all invitation operations with TanStack Query

## Usage Example

```typescript
import { useInvitations, InvitationStatus } from './use-invitations';

function InvitationsPanel() {
  const {
    invitations,
    isLoading,
    totalPages,
    hasNext,
    revokeInvitation,
    resendInvitation,
    inviteUsers,
    inviteUsersMutation,
  } = useInvitations(0, 20);

  const handleInvite = async () => {
    await inviteUsers(['alice@example.com', 'bob@example.com']);
  };

  const handleRevoke = (id: string) => {
    revokeInvitation(id, {
      onSuccess: () => console.log('Revoked'),
      onError: (err) => console.error(err),
    });
  };

  if (isLoading) return <Spinner />;

  return (
    <>
      {invitations.map(inv => (
        <div key={inv.id}>
          {inv.email} — {inv.status}
          <button onClick={() => handleRevoke(inv.id)}>Revoke</button>
          <button onClick={() => resendInvitation(inv.id)}>Resend</button>
        </div>
      ))}
      <button onClick={handleInvite} disabled={inviteUsersMutation.isPending}>
        Invite Users
      </button>
    </>
  );
}
```

## Returned Values

| Value | Type | Description |
|-------|------|-------------|
| `invitations` | `InvitationRecord[]` | Current page items (defaults to `[]`) |
| `isLoading` | `boolean` | Fetch in-progress state |
| `error` | `string \| null` | Error message if fetch failed |
| `totalPages`, `hasNext`, `hasPrevious` | `number / boolean` | Pagination metadata |
| `revokeInvitation` | `fn(id, options?)` | Deletes an invitation, invalidates cache |
| `resendInvitation` | `fn(id, options?)` | Re-sends invite email, invalidates cache |
| `inviteUsers` | `Promise<void>` | Sends bulk invitations by email array |
