React hook for managing API key CRUD operations, exposing state and async actions for listing, creating, updating, regenerating, and toggling API keys.

## Key Components

**`ApiKeyRecord`** — Type representing an API key with metadata fields including usage statistics (`totalRequests`, `successfulRequests`, `failedRequests`), lifecycle timestamps, and enabled state.

**`useApiKeys()`** — Custom hook returning:

| Member | Type | Description |
|---|---|---|
| `items` | `ApiKeyRecord[]` | Current list of API keys |
| `isLoading` | `boolean` | Loading state for `fetchApiKeys` |
| `error` | `string \| null` | Last fetch error message |
| `fetchApiKeys` | `() => Promise<ApiKeyRecord[]>` | Load all keys from `GET api/api-keys` |
| `createApiKey` | `(data) => Promise<{ apiKey, fullKey }>` | Create a new key; returns the full plaintext key |
| `updateApiKey` | `(id, data) => Promise<ApiKeyRecord>` | Update name/description/expiry |
| `regenerateApiKey` | `(id) => Promise<{ apiKey, fullKey }>` | Rotate a key secret; returns new plaintext key |
| `setApiKeyEnabled` | `(id, enabled) => Promise<ApiKeyRecord>` | Enable or disable a key |

> `createApiKey` and `regenerateApiKey` return `fullKey` — the only time the plaintext secret is available. Store it immediately.

## Usage Example

```typescript
import { useApiKeys } from '@/hooks/use-api-keys';

function ApiKeyManager() {
  const { items, isLoading, error, fetchApiKeys, createApiKey, setApiKeyEnabled } = useApiKeys();

  useEffect(() => { fetchApiKeys(); }, [fetchApiKeys]);

  const handleCreate = async () => {
    const { apiKey, fullKey } = await createApiKey({
      name: 'CI Pipeline',
      description: 'Used by GitHub Actions',
      expiresAt: '2026-01-01T00:00:00Z',
    });
    console.log('Save this key now:', fullKey); // only shown once
  };

  const handleToggle = (id: string, enabled: boolean) =>
    setApiKeyEnabled(id, !enabled);

  if (isLoading) return <Spinner />;
  if (error) return <p>{error}</p>;

  return items.map(key => (
    <div key={key.id}>
      <span>{key.name}</span>
      <button onClick={() => handleToggle(key.id, key.enabled)}>
        {key.enabled ? 'Disable' : 'Enable'}
      </button>
    </div>
  ));
}
```
