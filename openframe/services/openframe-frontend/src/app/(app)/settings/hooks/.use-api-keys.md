React hook for managing API key CRUD operations, exposing state and async actions for fetching, creating, updating, regenerating, and toggling API keys via `apiClient`.

## Key Components

**`ApiKeyRecord`** — Type definition for an API key record, including metadata (`id`, `name`, `description`, `enabled`), timestamps (`createdAt`, `updatedAt`, `lastUsed`, `expiresAt`), and usage statistics (`totalRequests`, `successfulRequests`, `failedRequests`).

**`useApiKeys()`** — React hook returning:

| Member | Type | Description |
|--------|------|-------------|
| `items` | `ApiKeyRecord[]` | Current list of API keys |
| `isLoading` | `boolean` | Fetch in-progress flag |
| `error` | `string \| null` | Last error message |
| `fetchApiKeys` | `() => Promise<ApiKeyRecord[]>` | Load all keys |
| `createApiKey` | `(data) => Promise<{ apiKey, fullKey }>` | Create and return new key + raw secret |
| `updateApiKey` | `(id, data) => Promise<ApiKeyRecord>` | Update name/description/expiry |
| `regenerateApiKey` | `(id) => Promise<{ apiKey, fullKey }>` | Rotate secret, returns new raw key |
| `setApiKeyEnabled` | `(id, enabled) => Promise<ApiKeyRecord>` | Enable or disable a key |

> `createApiKey` and `regenerateApiKey` return `fullKey` — the plaintext secret only available at creation/rotation time. Store it immediately; it will not be retrievable again.

## Usage Example

```typescript
import { useApiKeys } from '@/hooks/use-api-keys';

export function ApiKeysPanel() {
  const {
    items,
    isLoading,
    error,
    fetchApiKeys,
    createApiKey,
    setApiKeyEnabled,
  } = useApiKeys();

  useEffect(() => { fetchApiKeys(); }, [fetchApiKeys]);

  const handleCreate = async () => {
    const { apiKey, fullKey } = await createApiKey({
      name: 'CI Pipeline',
      description: 'Used by GitHub Actions',
      expiresAt: '2026-01-01T00:00:00Z',
    });
    console.log('Save this key now:', fullKey); // shown once
  };

  const handleToggle = (id: string, enabled: boolean) =>
    setApiKeyEnabled(id, !enabled);

  if (isLoading) return <p>Loading...</p>;
  if (error) return <p>Error: {error}</p>;

  return (
    <ul>
      {items.map(key => (
        <li key={key.id}>
          {key.name} — {key.enabled ? 'Active' : 'Disabled'}
          <button onClick={() => handleToggle(key.id, key.enabled)}>
            Toggle
          </button>
        </li>
      ))}
    </ul>
  );
}
```
