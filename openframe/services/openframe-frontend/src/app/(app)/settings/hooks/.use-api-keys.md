React hook for managing API key CRUD operations, providing state management and async methods to fetch, create, update, regenerate, and toggle API keys via `apiClient`.

## Key Components

**`ApiKeyRecord`** — Type representing an API key with fields for metadata (`id`, `name`, `description`, `enabled`), timestamps (`createdAt`, `updatedAt`, `lastUsed`, `expiresAt`), and usage statistics (`totalRequests`, `successfulRequests`, `failedRequests`).

**`useApiKeys()`** — Hook exposing:

| Return | Description |
|--------|-------------|
| `items` | Current list of `ApiKeyRecord[]` |
| `isLoading` | Loading state for `fetchApiKeys` |
| `error` | Error message string or `null` |
| `fetchApiKeys()` | Loads all API keys into `items` state |
| `createApiKey(data)` | Creates a new key, returns `{ apiKey, fullKey }` |
| `updateApiKey(id, data)` | Updates name/description/expiry of an existing key |
| `regenerateApiKey(id)` | Rotates the secret, returns `{ apiKey, fullKey }` |
| `setApiKeyEnabled(id, enabled)` | Enables or disables a key |

> **Note:** `fullKey` (the raw secret) is only returned on `createApiKey` and `regenerateApiKey` — store it immediately, as it cannot be retrieved later.

## Usage Example

```typescript
const {
  items,
  isLoading,
  error,
  fetchApiKeys,
  createApiKey,
  setApiKeyEnabled,
} = useApiKeys();

// Load all keys on mount
useEffect(() => { fetchApiKeys(); }, [fetchApiKeys]);

// Create a new key
const { apiKey, fullKey } = await createApiKey({
  name: 'My Integration',
  description: 'Used by Zapier',
  expiresAt: '2026-01-01T00:00:00Z',
});
// fullKey is only available here — save it now

// Toggle a key off
await setApiKeyEnabled(apiKey.id, false);
```
