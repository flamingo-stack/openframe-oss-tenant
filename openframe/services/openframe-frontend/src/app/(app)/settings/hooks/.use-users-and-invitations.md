Combines `useUsers` and `useInvitations` hooks into a single unified interface, normalizing both users and pending invitations into a common `UnifiedUserRecord` shape for consistent list rendering and management.

## Key Components

**`RecordType` (enum)**
Discriminator values: `User` and `Invitation` — used to identify the origin of each unified record.

**`UnifiedUserRecord` (type)**
Common shape merging `UserRecord` and `InvitationRecord` fields, including `type`, `expiresAt`, `originalUser`, and `originalInvitation` for access to the raw source record.

**`useUsersAndInvitations(page, size)` (hook)**
Main export. Fetches both users and invitations in parallel, merges them into a single `records` array, and exposes combined loading/error state, pagination metadata, all mutations, and raw sub-hooks.

## Usage Example

```typescript
import { useUsersAndInvitations, RecordType } from './use-users-and-invitations';

function UserManagementTable() {
  const {
    records,
    isLoading,
    error,
    combinedTotalElements,
    deleteUser,
    revokeInvitation,
    resendInvitation,
    inviteUsers,
    refetchAll,
  } = useUsersAndInvitations(0, 25);

  if (isLoading) return <Spinner />;
  if (error) return <ErrorBanner error={error} />;

  return records.map((record) => (
    <Row key={record.id}>
      <span>{record.email}</span>
      <span>{record.status}</span>
      {record.type === RecordType.User ? (
        <Button onClick={() => deleteUser(record.id)}>Remove</Button>
      ) : (
        <Button onClick={() => resendInvitation(record.id)}>Resend</Button>
      )}
    </Row>
  ));
}
```

> Access the original source record via `record.originalUser` or `record.originalInvitation` when you need fields not present on the unified type.
