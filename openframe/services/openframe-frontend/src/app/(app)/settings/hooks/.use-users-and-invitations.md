Combines `useUsers` and `useInvitations` hooks into a single unified interface, normalizing both users and pending invitations into a shared `UnifiedUserRecord` shape for consistent rendering in user management UIs.

## Key Components

**`RecordType`** — Enum distinguishing `'user'` from `'invitation'` records.

**`UnifiedUserRecord`** — Normalized type merging `UserRecord` and `InvitationRecord` fields, with a `type` discriminator and references to the original source object.

**`useUsersAndInvitations(page, size)`** — Primary hook that:
- Fetches users and invitations in parallel with independent pagination
- Merges both into a single `records` array via `useMemo`
- Aggregates loading/error states
- Exposes mutations from both sub-hooks (`deleteUser`, `revokeInvitation`, `resendInvitation`, `inviteUsers`)
- Provides combined and per-source pagination metadata

## Usage Example

```typescript
import { useUsersAndInvitations, RecordType } from './use-users-and-invitations';

function UserManagementTable() {
  const {
    records,
    isLoading,
    error,
    combinedTotalElements,
    deleteUser,
    revokeInvitation,
    refetchAll,
  } = useUsersAndInvitations(0, 20);

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage error={error} />;

  return records.map((record) => (
    <Row
      key={record.id}
      record={record}
      onDelete={
        record.type === RecordType.User
          ? () => deleteUser(record.id)
          : () => revokeInvitation(record.id)
      }
    />
  ));
}
```

> Raw sub-hooks are also accessible via `usersHook` and `invitationsHook` for advanced use cases requiring direct access to the underlying query state.
