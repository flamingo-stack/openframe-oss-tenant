Combines `useUsers` and `useInvitations` into a single unified hook, normalizing both into a common `UnifiedUserRecord` shape for consistent rendering and management of users and pending invitations.

## Key Components

- **`RecordType`** — Enum distinguishing `user` vs `invitation` records
- **`UnifiedUserRecord`** — Normalized record type merging fields from both `UserRecord` and `InvitationRecord`, with `type` and original-record references
- **`UnifiedUserStatus`** — Union type of `UserStatus | InvitationStatus`
- **`userToUnified` / `invitationToUnified`** — Private mappers converting raw records to `UnifiedUserRecord`
- **`useUsersAndInvitations`** — Primary hook combining both data sources with shared loading/error state, pagination info, and all mutations

## Usage Example

```typescript
import { useUsersAndInvitations, RecordType } from './use-users-and-invitations';

function UserManagementTable() {
  const {
    records,
    isLoading,
    error,
    combinedTotalElements,
    deleteUser,
    revokeInvitation,
    resendInvitation,
    inviteUsers,
    refetchAll,
  } = useUsersAndInvitations(0, 20);

  if (isLoading) return <Spinner />;
  if (error) return <Error message={error.message} />;

  return records.map((record) => (
    <Row
      key={record.id}
      record={record}
      onDelete={
        record.type === RecordType.User
          ? () => deleteUser(record.id)
          : () => revokeInvitation(record.id)
      }
    />
  ));
}
```

> The hook exposes `usersHook` and `invitationsHook` directly via the `rawHooks` pattern for advanced use cases that need access to the underlying paginated query state.
