React hook for fetching integrated tools from the OpenFrame GraphQL API, managing loading/error state and surfacing toast notifications on failure.

## Key Components

- **`GET_INTEGRATED_TOOLS_QUERY`** — GraphQL query that retrieves full tool metadata including credentials, URLs, health-check config, and layer properties.
- **`IntegratedTool`** — Core type representing a platform-integrated tool (PSA, RMM, monitoring, etc.) with fields for identity, connectivity, and UI presentation.
- **`ToolUrl` / `ApiKey` / `Credentials`** — Supporting types for tool connection and authentication data.
- **`useIntegratedTools()`** — The exported hook exposing `tools`, `isLoading`, `error`, and `fetchIntegratedTools`.

## Usage Example

```typescript
import { useIntegratedTools } from '@/hooks/use-integrated-tools';

export function ToolList() {
  const { tools, isLoading, error, fetchIntegratedTools } = useIntegratedTools();

  useEffect(() => {
    // Fetch only enabled monitoring tools
    fetchIntegratedTools({ enabled: true, category: 'monitoring' });
  }, [fetchIntegratedTools]);

  if (isLoading) return <Spinner />;
  if (error) return <p>Error: {error}</p>;

  return (
    <ul>
      {tools.map(tool => (
        <li key={tool.id}>{tool.name}</li>
      ))}
    </ul>
  );
}
```

## Behaviour Notes

- Defaults to `{ enabled: true, category: null }` filter when called without arguments.
- On GraphQL-level errors (HTTP 200 with `errors` array), throws and displays a destructive toast via `useToast`.
- Returns the fetched tool array directly from `fetchIntegratedTools` in addition to updating state, allowing one-shot use without subscribing to the `tools` state slice.
