React hook for fetching integrated tools from the OpenFrame GraphQL API, with loading state, error handling, and toast notifications.

## Key Components

- **`GET_INTEGRATED_TOOLS_QUERY`** — GraphQL query that retrieves integrated tools with full configuration details (URLs, credentials, health checks, layer metadata)
- **`IntegratedTool`** — Primary type representing a tool registered in the platform (id, name, toolUrls, credentials, layer info, etc.)
- **`useIntegratedTools()`** — Custom hook exposing tool state and fetch logic

### Hook Return Values

| Property | Type | Description |
|---|---|---|
| `tools` | `IntegratedTool[]` | List of fetched tools |
| `isLoading` | `boolean` | Fetch in-progress indicator |
| `error` | `string \| null` | Last error message |
| `fetchIntegratedTools` | `function` | Trigger fetch with optional filter/search |

## Usage Example

```typescript
import { useIntegratedTools } from '@/hooks/use-integrated-tools';

function ToolList() {
  const { tools, isLoading, error, fetchIntegratedTools } = useIntegratedTools();

  useEffect(() => {
    // Fetch only enabled tools in the 'monitoring' category
    fetchIntegratedTools({ enabled: true, category: 'monitoring' }, 'grafana');
  }, [fetchIntegratedTools]);

  if (isLoading) return <Spinner />;
  if (error) return <p>Error: {error}</p>;

  return (
    <ul>
      {tools.map((tool) => (
        <li key={tool.id}>{tool.name}</li>
      ))}
    </ul>
  );
}
```

> **Note:** `fetchIntegratedTools` defaults to `{ enabled: true, category: null }` if no filter is provided. GraphQL and HTTP errors are both handled — failed requests surface via toast notification and re-throw for caller handling.
