React hook for managing AI provider configuration state, including fetching the current configuration, listing supported models, and persisting updates via the OpenFrame chat API.

## Key Components

**Interfaces**
- `AiConfiguration` — Active AI provider config (provider, model, API key status, timestamps)
- `ModelInfo` — Metadata for a specific model (name, display name, provider, context window)
- `SupportedModels` — Grouped model lists keyed by provider (`openai`, `anthropic`, `google-gemini`)
- `UpdateAiConfigurationParams` — Input shape for saving a new configuration

**Hook: `useAiConfiguration()`**

| Return Value | Type | Description |
|---|---|---|
| `configuration` | `AiConfiguration \| null` | Currently active AI configuration |
| `supportedModels` | `SupportedModels` | Available models grouped by provider |
| `isLoading` | `boolean` | True while initial data is fetching |
| `isSaving` | `boolean` | True while an update is in progress |
| `fetchConfiguration` | `() => Promise` | Manually refresh current config |
| `fetchSupportedModels` | `() => Promise` | Manually refresh model list |
| `updateConfiguration` | `(params) => Promise` | Save new provider/model/API key |

## Usage Example

```typescript
import { useAiConfiguration } from './use-ai-configuration';

function AiSettingsPanel() {
  const {
    configuration,
    supportedModels,
    isLoading,
    isSaving,
    updateConfiguration,
  } = useAiConfiguration();

  if (isLoading) return <p>Loading...</p>;

  const handleSave = async () => {
    await updateConfiguration({
      provider: 'OPENAI',
      modelName: 'gpt-4o',
      apiKey: 'sk-...', // optional — omit to keep existing key
    });
  };

  return (
    <div>
      <p>Active provider: {configuration?.provider}</p>
      <p>Active model: {configuration?.modelName}</p>
      <button disabled={isSaving} onClick={handleSave}>
        {isSaving ? 'Saving...' : 'Save'}
      </button>
    </div>
  );
}
```

> **Note:** The `apiKey` field in `updateConfiguration` is optional. Omit it to update the provider/model without rotating the stored API key. Toast notifications are shown automatically on both success and error.
