React hook for managing AI provider configuration state, including fetching the active configuration, listing supported models, and saving provider/model/API key updates.

## Key Components

**Interfaces**
- `AiConfiguration` — active AI config record (provider, model, API key presence, timestamps)
- `ModelInfo` — metadata for a single model (display name, provider, context window size)
- `SupportedModels` — grouped model lists keyed by provider slug
- `UpdateAiConfigurationParams` — payload shape for saving a new configuration

**Hook: `useAiConfiguration`**

| Return Value | Type | Description |
|---|---|---|
| `configuration` | `AiConfiguration \| null` | Currently active AI configuration |
| `supportedModels` | `SupportedModels` | Available models grouped by provider |
| `isLoading` | `boolean` | True while initial data is fetching |
| `isSaving` | `boolean` | True while an update is in-flight |
| `fetchConfiguration` | `() => Promise` | Re-fetches active configuration |
| `fetchSupportedModels` | `() => Promise` | Re-fetches supported model list |
| `updateConfiguration` | `(params) => Promise` | POSTs new provider/model/key settings |

**API Endpoints Used**
- `GET /chat/api/v1/ai-configuration` — load active config
- `GET /chat/api/v1/ai-configuration/supported-models` — load model catalog
- `POST /chat/api/v1/ai-configuration` — save updated config

## Usage Example

```typescript
import { useAiConfiguration } from './use-ai-configuration';

function AiSettingsPanel() {
  const {
    configuration,
    supportedModels,
    isLoading,
    isSaving,
    updateConfiguration,
  } = useAiConfiguration();

  const handleSave = async () => {
    await updateConfiguration({
      provider: 'OPENAI',
      modelName: 'gpt-4o',
      apiKey: 'sk-...',
    });
  };

  if (isLoading) return <Spinner />;

  return (
    <div>
      <p>Active model: {configuration?.modelName}</p>
      <button onClick={handleSave} disabled={isSaving}>
        {isSaving ? 'Saving...' : 'Save'}
      </button>
    </div>
  );
}
```

> **Note:** `apiKey` is optional in `updateConfiguration` — omit it to keep the existing stored key. Toast notifications are automatically shown on both success and error.
