React hook for managing AI provider configuration state, including fetching the current setup, retrieving supported models, and persisting updates via the chat API.

## Key Components

### Interfaces

| Interface | Description |
|-----------|-------------|
| `AiConfiguration` | Active AI config record (provider, model, API key status) |
| `ModelInfo` | Metadata for a single model (name, display name, context window) |
| `SupportedModels` | Map of provider keys to their available `ModelInfo` arrays |
| `UpdateAiConfigurationParams` | Input shape for saving a new configuration |

### Hook: `useAiConfiguration`

| Return Value | Type | Description |
|---|---|---|
| `configuration` | `AiConfiguration \| null` | Currently active AI configuration |
| `supportedModels` | `SupportedModels` | Available models grouped by provider |
| `isLoading` | `boolean` | True while initial data is fetching |
| `isSaving` | `boolean` | True while an update is in progress |
| `fetchConfiguration` | `() => Promise` | Re-fetches the active configuration |
| `fetchSupportedModels` | `() => Promise` | Re-fetches available models |
| `updateConfiguration` | `(params) => Promise` | POSTs new provider/model/API key settings |

Both fetch calls are triggered automatically on mount. Toast notifications are shown on success and failure.

## Usage Example

```typescript
import { useAiConfiguration } from './use-ai-configuration';

function AiSettingsPanel() {
  const {
    configuration,
    supportedModels,
    isLoading,
    isSaving,
    updateConfiguration,
  } = useAiConfiguration();

  const handleSave = async () => {
    await updateConfiguration({
      provider: 'ANTHROPIC',
      modelName: 'claude-3-5-sonnet-20241022',
      apiKey: 'sk-ant-...',
    });
  };

  if (isLoading) return <Spinner />;

  return (
    <div>
      <p>Active model: {configuration?.modelName}</p>
      <button onClick={handleSave} disabled={isSaving}>
        {isSaving ? 'Saving...' : 'Save'}
      </button>
    </div>
  );
}
```
