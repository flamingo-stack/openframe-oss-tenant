Defines shared TypeScript types and re-exports for the subscription management feature, consolidating billing, product selection, and update action contracts used across checkout and subscription hooks.

## Key Components

| Export | Kind | Description |
|--------|------|-------------|
| `BillingPeriod` | Re-export | Billing cycle enum (`MONTHLY` / `ANNUAL`) from generated GraphQL fragment |
| `SubscriptionProductStatus` | Re-export | Product status enum from generated subscription GraphQL fragment |
| `OpenframeProduct` | Re-export | Product type from generated settings query |
| `UpdateAction` | Type | Union of `'ADD'` or `'CANCEL'` for subscription mutations |
| `ProductSelectionState` | Interface | UI state shape for a product card (billing period, package, quantity) |
| `ProductUpdates` | Interface | Resolved diff payload split between `updateSubscription` and `createCheckoutSession` calls |

## Usage Example

```typescript
import type {
  BillingPeriod,
  ProductSelectionState,
  ProductUpdates,
  UpdateAction,
} from './subscription.types';

// Track user selections on a product card
const selectionState: ProductSelectionState = {
  payAsYouGoEnabled: false,
  billingPeriod: 'MONTHLY',
  selectedPackageId: 'pkg_pro_50',
  customQuantity: null,
};

// Build the resolved update payload before calling hooks
const updates: ProductUpdates = {
  packageUpdates: [{ packageId: 'pkg_pro_50', action: 'ADD' as UpdateAction }],
  checkout: { productId: 'prod_openframe', packageId: 'pkg_pro_50' },
  valid: true,
};
```

> `valid` must be checked before dispatching either hook — it is `false` when the user selects **Custom Amount** but leaves the quantity empty or invalid.
