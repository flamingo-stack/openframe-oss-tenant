Defines shared TypeScript types and re-exports for the subscription management feature, centralizing billing state and update payload shapes used across checkout and subscription hooks.

## Key Components

| Export | Kind | Description |
|--------|------|-------------|
| `BillingPeriod` | Re-export | Billing cycle enum from generated GraphQL fragment |
| `SubscriptionProductStatus` | Re-export | Product status enum from generated GraphQL fragment |
| `OpenframeProduct` | Re-export | Product type from generated subscription settings query |
| `UpdateAction` | Type | Union `'ADD' \| 'CANCEL'` representing subscription change direction |
| `ProductSelectionState` | Interface | UI state for a product's current billing selections |
| `ProductUpdates` | Interface | Computed diff payload dispatched to checkout or update hooks |

## Usage Example

```typescript
import type {
  BillingPeriod,
  ProductSelectionState,
  ProductUpdates,
} from './subscription.types';

const selectionState: ProductSelectionState = {
  payAsYouGoEnabled: false,
  billingPeriod: 'MONTHLY',
  selectedPackageId: 'pkg_standard',
  customQuantity: null,
};

const updates: ProductUpdates = {
  packageUpdates: [{ packageId: 'pkg_standard', action: 'ADD' }],
  checkout: { productId: 'prod_abc', packageId: 'pkg_standard' },
  valid: true,
};
```

> `ProductUpdates.packageUpdates` targets active paid subscriptions via `updateSubscription`, while `ProductUpdates.checkout` targets non-active states (`TRIAL`, `TRIAL_EXPIRED`, `CANCELED`) via `createCheckoutSession`. Always check `valid` before dispatching either payload.
