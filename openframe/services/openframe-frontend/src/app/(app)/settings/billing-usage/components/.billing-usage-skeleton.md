Loading state skeleton for the Billing & Usage settings page, mirroring the layout of dashboard info cards and billing section blocks with animated placeholders.

## Key Components

| Component | Description |
|-----------|-------------|
| `BillingUsageSkeleton` | Main exported skeleton wrapping the full page layout with info cards and section blocks |
| `InfoCardSkeleton` | Mirrors a `DashboardInfoCard` (~94px) with text column and circular progress placeholder |
| `BillingRowSkeleton` | Mirrors a `BillingRow` with label, flex divider, and value placeholders |
| `SectionBlockSkeleton` | Mirrors a `SectionBlock` (~166px card) with a title and stacked billing rows |
| `CURRENT_PLAN_ROWS` | Static row config for the Current Plan section (4 rows) |
| `USAGE_OVERVIEW_ROWS` | Static row config for the Usage Overview section (2 rows) |

## Usage Example

```typescript
import { BillingUsageSkeleton } from './billing-usage-skeleton';

// Render while billing data is loading
export default function BillingPage() {
  const { data, isLoading } = useBillingData();

  if (isLoading) return <BillingUsageSkeleton />;

  return <BillingUsageContent data={data} />;
}
```

> **Layout structure:** Two `InfoCardSkeleton` components in a responsive 2-column grid at the top, followed by `SectionBlockSkeleton` instances for **Current Plan** and **Usage Overview** — each using varied `labelWidth`/`valueWidth` Tailwind classes to simulate realistic content widths.
