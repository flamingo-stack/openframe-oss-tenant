Loading skeleton component for the Billing & Usage settings page, providing visual placeholders that mirror the layout of `DashboardInfoCard` and billing section blocks during data fetch.

## Key Components

| Component | Description |
|---|---|
| `BillingUsageSkeleton` | Main exported skeleton wrapping the full page layout with info cards and section blocks |
| `InfoCardSkeleton` | Mirrors a `DashboardInfoCard` (~94px) with a text column and circular progress placeholder |
| `BillingRowSkeleton` | Mirrors a `BillingRow` with label, dotted divider, and value placeholders |
| `SectionBlockSkeleton` | Mirrors a `SectionBlock` (~166px card) with an uppercase title and stacked billing rows |

## Usage Example

```typescript
// Rendered automatically during data loading in the Billing & Usage page
import { BillingUsageSkeleton } from './billing-usage-skeleton';

function BillingUsagePage() {
  if (isLoading) return <BillingUsageSkeleton />;
  return <BillingUsageContent data={data} />;
}
```

## Notes

- `CURRENT_PLAN_ROWS` and `USAGE_OVERVIEW_ROWS` define varied placeholder widths to simulate realistic content density
- Uses `useSafeBack('/settings')` to ensure the back button falls back to `/settings` if no history is available
- Skeleton dimensions and spacing intentionally match the real layout to prevent layout shift on load
