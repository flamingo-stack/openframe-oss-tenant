Loading state skeleton component for the Billing & Usage settings page, mirroring the layout of real content cards during data fetch.

## Key Components

- **`InfoCardSkeleton`** — Mimics a `DashboardInfoCard` (~94px tall) with a text column (title + value) and a circular progress placeholder
- **`BillingRowSkeleton`** — Mimics a `BillingRow` with a label, dotted divider, and value aligned left/right; accepts `labelWidth` and `valueWidth` props for varied shimmer sizes
- **`SectionBlockSkeleton`** — Mimics a `SectionBlock` card (~166px) with an uppercase section title and a list of `BillingRowSkeleton` rows
- **`BillingUsageSkeleton`** *(exported)* — Composes the full page skeleton inside `PageLayout`, matching the two-column grid layout of the real Billing & Usage page

## Usage Example

```typescript
// Render during async data load in the Billing & Usage route
import { BillingUsageSkeleton } from './billing-usage-skeleton';

export default function BillingUsagePage() {
  const { data, isLoading } = useBillingData();

  if (isLoading) return <BillingUsageSkeleton />;

  return <BillingUsageContent data={data} />;
}
```

## Notes

- Row widths (`CURRENT_PLAN_ROWS`, `USAGE_OVERVIEW_ROWS`) are hardcoded Tailwind width classes to match the typical label/value proportions of the real content, preventing layout shift
- Uses `useSafeBack('/settings')` so the back button falls back to `/settings` if there is no navigation history
