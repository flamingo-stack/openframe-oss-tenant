A modal dialog component for confirming subscription cancellation, displaying data loss warnings, collecting a cancellation reason, and optionally gathering freeform feedback.

## Key Components

### `CancelSubscriptionModal` (primary export)
The main modal component. Renders a `SimpleModal` with:
- Subscription end date display
- Data loss statistics box (or skeleton loader)
- Reason selector dropdown (required)
- Freeform comment textarea (shown only when reason is `'OTHER'`)
- Keep/Continue action buttons

### `DataLossBox`
Conditionally renders a warning panel listing non-zero stats (active devices, tickets, KB articles, monitoring policies, saved queries). Rows with zero values are automatically hidden; the entire box is omitted if all stats are zero.

### `DataLossSkeleton`
A loading placeholder that mirrors the `DataLossBox` structure (header + 4 bulleted rows) to prevent layout shift during data fetch.

### Types

| Type | Description |
|------|-------------|
| `CancelReason` | Union of 5 cancellation reason string literals |
| `DataLossStats` | Shape of the stats object (`activeDevices`, `tickets`, `kbArticles`, `monitoringPolicies`, `savedQueries`) |
| `CancelSubscriptionModalProps` | Full props interface for `CancelSubscriptionModal` |

## Usage Example

```typescript
import {
  CancelSubscriptionModal,
  type CancelReason,
  type DataLossStats,
} from '@/app/components/billing/cancel-subscription-modal';

const stats: DataLossStats = {
  activeDevices: 42,
  tickets: 1500,
  kbArticles: 8,
  monitoringPolicies: 3,
  savedQueries: 0,
};

<CancelSubscriptionModal
  isOpen={isModalOpen}
  endDate="2025-12-31T23:59:59Z"
  stats={stats}
  isStatsLoading={false}
  isPending={isCancelling}
  onClose={() => setModalOpen(false)}
  onConfirm={(reason: CancelReason, comment: string) => {
    submitCancellation({ reason, comment });
  }}
/>
```

> **Note:** The `Continue` button is disabled until a cancellation reason is selected. State (reason and comment) is reset automatically when the modal closes.
