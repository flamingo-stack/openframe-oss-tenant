A modal dialog component that guides users through cancelling their subscription, collecting a cancellation reason and optional comment while displaying a warning summary of data that will become inaccessible after the subscription ends.

## Key Components

- **`CancelSubscriptionModal`** — Main exported modal component built on `SimpleModal`. Manages local state for `reason` and `comment`, resets on close, and gates the confirm action until a reason is selected.
- **`CancelReason`** — Union type of five cancellation reasons: `TOO_EXPENSIVE`, `NOT_USING_ENOUGH`, `MISSING_FEATURE`, `TECHNICAL_ISSUES`, `OTHER`.
- **`DataLossStats`** — Interface describing counts for active devices, tickets, KB articles, monitoring policies, and saved queries.
- **`DataLossBox`** — Renders a warning panel listing only non-zero stats. Combines `monitoringPolicies` and `savedQueries` into a single row. Returns `null` if all stats are zero.
- **`DataLossSkeleton`** — Loading placeholder that mirrors the `DataLossBox` layout to prevent layout shift during data fetch.
- **`formatCount`** — Formats large numbers as `1,000+` style strings (floors to nearest 100 for values ≥ 1000).

## Usage Example

```typescript
import { CancelSubscriptionModal, CancelReason, DataLossStats } from './cancel-subscription-modal';

const stats: DataLossStats = {
  activeDevices: 42,
  tickets: 1250,
  kbArticles: 18,
  monitoringPolicies: 5,
  savedQueries: 3,
};

<CancelSubscriptionModal
  isOpen={isOpen}
  endDate="2025-12-31T23:59:59Z"
  stats={stats}
  isStatsLoading={false}
  isPending={isCancelling}
  onClose={() => setIsOpen(false)}
  onConfirm={(reason: CancelReason, comment: string) => {
    handleCancelSubscription(reason, comment);
  }}
/>
```

> The `OTHER` reason reveals an additional free-text `Textarea` for additional feedback. The confirm button remains disabled until a reason is selected or while `isPending` is `true`.
