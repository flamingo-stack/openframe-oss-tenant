Computes and organizes all billing summary state for the OpenFrame subscription dashboard, deriving usage metrics, overage warnings, and UI presentation data from raw GraphQL subscription and billing plan data.

## Key Components

- **`WARNING_THRESHOLD` / `OVER_THRESHOLD`** — Constants (90% / 100%) defining usage alert thresholds
- **`UsageState`** — Union type (`'success' | 'warning' | 'over'`) representing a resource's usage health
- **`getUsageState(percentage)`** — Pure helper that maps a usage percentage to a `UsageState`
- **`useBillingSummary(subscription, billingPlan)`** — Primary hook returning a structured summary object covering device/AI usage, billing financials, UI flags, and overage warnings

## Usage Example

```typescript
import { useBillingSummary } from './use-billing-summary';

function BillingDashboard({ subscription, billingPlan }) {
  const summary = useBillingSummary(subscription, billingPlan);

  const {
    status,
    flags: { isTrial, isOverdue, isNearLimits },
    device: { used, allocation, pct, state, overage },
    ai: { used: aiUsed, isPayg: aiIsPayg },
    ui: { warnings, showOverageBlock },
    billing: { monthlyCost, nextBilling, estimatedOverageCost },
  } = summary;

  return (
    <div>
      <p>Devices: {used} / {allocation} ({pct}%) — {state}</p>
      {showOverageBlock && <p>Overage cost: ${estimatedOverageCost}</p>}
      {warnings.map(w => <Alert key={w.title} title={w.title} description={w.description} />)}
    </div>
  );
}
```

## Return Shape

| Key | Description |
|-----|-------------|
| `status` | Raw subscription status |
| `flags` | Boolean flags: `isTrial`, `isPendingCancellation`, `isOverdue`, `isNearLimits`, `hasAi`, `hasPendingPlan` |
| `device` | Device usage metrics, progress variant, PAYG flag, and overage count |
| `ai` | AI token usage metrics, progress variant, PAYG flag, and overage count |
| `ui` | Warning messages array, overage block visibility, and accent CSS classes |
| `billing` | Monthly cost, next billing date, estimated overage cost, pending invoice, trial expiration |
| `updatedPlan` | Scheduled downgrade details (quantities and start date for devices/AI) |
