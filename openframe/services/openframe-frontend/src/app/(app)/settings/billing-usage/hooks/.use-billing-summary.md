Computes and organizes all billing summary data from a subscription GraphQL response into a structured object consumed by billing UI components.

## Key Components

**`useBillingSummary(subscription)`** — Primary hook that derives billing state from raw subscription data, returning a normalized summary object.

**`getUsageState(percentage)`** — Pure helper that maps a usage percentage to a `UsageState` value using two thresholds:
- `>= 100%` → `'over'`
- `>= 90%` → `'warning'`
- `< 90%` → `'success'`

**`UsageState`** — Exported union type: `'success' | 'warning' | 'over'`

## Return Shape

| Key | Description |
|-----|-------------|
| `status` | Subscription status (active, trial, overdue, etc.) |
| `flags` | Boolean indicators: `isTrial`, `isPendingCancellation`, `isOverdue`, `isNearLimits`, `hasAi`, `hasPendingPlan` |
| `device` | Device usage metrics: `used`, `active`, `inactive`, `pct`, `state`, `isPayg`, `allocation`, `overage`, `progressVariant`, `showProgress` |
| `ai` | AI token usage metrics: `used`, `pct`, `state`, `isPayg`, `allocation`, `overage`, `progressVariant`, `showProgress` |
| `ui` | Derived UI state: `warnings[]`, `showOverageBlock`, `accentClass`, `accentBorderClass` |
| `billing` | Financial data: `monthlyCost`, `nextBilling`, `estimatedOverageCost`, `latestPendingInvoice`, `trialExpirationDate` |
| `updatedPlan` | Scheduled downgrade details for `PENDING_ACTIVATION` package options |

## Usage Example

```typescript
import { useBillingSummary } from './use-billing-summary';

function BillingDashboard({ subscription }) {
  const summary = useBillingSummary(subscription);

  const { device, ai, flags, ui, billing } = summary;

  return (
    <>
      {flags.isNearLimits && ui.warnings.map(w => (
        <Alert key={w.title} title={w.title} description={w.description} />
      ))}
      <ProgressBar
        value={device.pct}
        variant={device.progressVariant}
        label={`${device.used} / ${device.allocation} devices`}
      />
      {flags.hasAi && (
        <ProgressBar
          value={ai.pct}
          variant={ai.progressVariant}
          label={`${ai.used} / ${ai.allocation} tokens`}
        />
      )}
      <span>Monthly cost: ${billing.monthlyCost}</span>
    </>
  );
}
```

> `monthlyCost` is memoized via `useMemo` and only recalculates when `subscriptionProducts` changes. Pay-as-you-go products without an active package option are excluded from the total.
