Computes and aggregates all display-ready billing summary data for a subscription, combining usage metrics, product allocations, overage calculations, and UI state into a single structured result.

## Key Components

### Constants
- `WARNING_THRESHOLD` (`90`) — percentage at which usage enters `'warning'` state
- `OVER_THRESHOLD` (`100`) — percentage at which usage enters `'over'` state

### Types
- **`UsageState`** — `'success' | 'warning' | 'over'`; describes how close usage is to its limit

### Functions
- **`getUsageState(percentage)`** — maps a numeric percentage to a `UsageState`
- **`useBillingSummary(subscription, billingPlan)`** — primary hook; accepts raw GraphQL query data and returns a fully derived billing summary object

### Return Shape

| Key | Description |
|-----|-------------|
| `status` | Current subscription status |
| `flags` | Boolean indicators: `isTrial`, `isPendingCancellation`, `isOverdue`, `isNearLimits`, `hasAi`, `hasPendingPlan` |
| `updatedPlan` | Scheduled downgrade details (pending quantities and start date) |
| `device` | Managed devices usage: `used`, `active`, `inactive`, `pct`, `state`, `isPayg`, `allocation`, `overage`, `progressVariant`, `showProgress` |
| `ai` | AI token usage: same shape minus `active`/`inactive` |
| `ui` | `warnings[]`, `showOverageBlock`, `accentClass`, `accentBorderClass` |
| `billing` | `monthlyCost`, `nextBilling`, `estimatedOverageCost`, `latestPendingInvoice`, `trialExpirationDate` |

## Usage Example

```typescript
import { useBillingSummary } from './use-billing-summary';

function BillingOverview({ subscription, billingPlan }) {
  const summary = useBillingSummary(subscription, billingPlan);

  const { device, ai, flags, billing, ui } = summary;

  return (
    <>
      {ui.warnings.map(w => (
        <Alert key={w.title} title={w.title} description={w.description} />
      ))}
      <ProgressBar
        value={device.pct}
        variant={device.progressVariant}
        label={`${device.used} / ${device.allocation} devices`}
      />
      {flags.hasAi && (
        <ProgressBar
          value={ai.pct}
          variant={ai.progressVariant}
          label={`${ai.used} / ${ai.allocation} tokens`}
        />
      )}
      <p>Monthly cost: ${billing.monthlyCost}</p>
    </>
  );
}
```
