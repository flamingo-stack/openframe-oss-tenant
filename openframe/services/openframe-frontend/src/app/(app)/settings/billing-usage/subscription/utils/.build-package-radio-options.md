Builds the array of radio option objects used to render subscription package selection UI, combining pay-as-you-go, tiered pricing, and custom plan entries into a single unified list.

## Key Components

- **`buildPackageRadioOptions`** — Primary export. Accepts pricing tiers, billing period config, and PAYG settings; returns a flat array of radio option descriptors.
- **`BuildPackageRadioOptionsArgs`** — Input interface defining tiers, unit pricing, labels, period metadata, and PAYG visibility.
- **`PriceTier`** — Describes a single pricing tier with a `from` quantity threshold and `unitPrice`.
- **`PayAsYouGoOption`** — Optional PAYG metadata (`name`, `description`) passed to `formatPaygSubtitle`.

## Behavior

| Option Type | Condition | Value |
|---|---|---|
| Pay As You Go | `showPayg && payAsYouGoOption` | `PAYG_OPTION_ID` |
| Tier entries | One per `tiers[]` entry | `String(tier.from)` |
| Custom plan | Always appended | `CUSTOM_OPTION_ID` |

Tier options calculate total cost (`from × unitPrice × months`) and a discount percentage relative to `baselineUnitPrice`. If a discount exists, a `<Tag variant="success">` badge is attached as the `trailing` element.

## Usage Example

```typescript
const options = buildPackageRadioOptions({
  tiers: [
    { from: 50, unitPrice: 1.20 },
    { from: 100, unitPrice: 0.90 },
  ],
  baselineUnitPrice: 1.50,
  months: 12,
  periodSuffix: '/yr',
  packageUnitLabel: 'devices',
  customLabel: 'Custom plan',
  customSubtitle: 'Contact us for pricing',
  payAsYouGoOption: { name: 'PAYG', description: 'Billed monthly per use' },
  unitSize: 1,
  showPayg: true,
});
// Returns: [paygEntry, ...tierEntries, customEntry]
```
