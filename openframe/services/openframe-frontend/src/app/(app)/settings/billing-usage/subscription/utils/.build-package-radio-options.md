Builds the radio option list for subscription package selection, combining pay-as-you-go, tiered pricing, and custom options into a unified array for use in pricing UI forms.

## Key Components

- **`BuildPackageRadioOptionsArgs`** — Input interface defining tiers, pricing, labels, and display flags
- **`PriceTier`** — Represents a pricing tier with `from` (unit quantity) and `unitPrice`
- **`buildPackageRadioOptions()`** — Main export; constructs a sorted options array: `[PAYG?, ...tiers, Custom]`

Each option returns:

| Field | Description |
|---|---|
| `value` | Tier quantity, `PAYG_OPTION_ID`, or `CUSTOM_OPTION_ID` |
| `label` | Human-readable unit label (e.g. `"500 devices"`) |
| `description` | Formatted price string or PAYG subtitle |
| `trailing` | Discount badge (`Tag`) shown when savings > 0% |

## Usage Example

```typescript
const options = buildPackageRadioOptions({
  tiers: [
    { from: 100, unitPrice: 0.50 },
    { from: 500, unitPrice: 0.40 },
  ],
  baselineUnitPrice: 0.50,
  months: 12,
  periodSuffix: '/yr',
  packageUnitLabel: 'devices',
  customLabel: 'Custom',
  customSubtitle: 'Contact us for pricing',
  payAsYouGoOption: { name: 'PAYG', description: 'Billed monthly' },
  unitSize: 1,
  showPayg: true,
});
// → [{ value: 'payg', ... }, { value: '100', ... }, { value: '500', label: '500 devices', trailing: <Tag -20%/> }, { value: 'custom', ... }]
```

> **Note:** PAYG option is hidden on yearly billing tabs via `showPayg: false`. Discount badges only render when `baselineUnitPrice` is provided and the tier is below it.
