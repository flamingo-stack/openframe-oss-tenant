Builds an array of radio option objects for subscription package selection, combining pay-as-you-go, tiered pricing, and custom plan choices into a unified list for UI rendering.

## Key Components

- **`buildPackageRadioOptions`** — Main exported function that maps pricing tiers into labeled radio options with discount badges, PAYG entries, and a custom plan option
- **`PriceTier`** — Interface describing a pricing tier with a `from` quantity threshold and `unitPrice`
- **`PayAsYouGoOption`** — Interface for PAYG plan metadata (`name`, `description`)
- **`BuildPackageRadioOptionsArgs`** — Full input shape including tiers, billing period, unit labels, and display flags

## Usage Example

```typescript
import { buildPackageRadioOptions } from './build-package-radio-options';

const options = buildPackageRadioOptions({
  tiers: [
    { from: 10, unitPrice: 2.5 },
    { from: 50, unitPrice: 2.0 },
  ],
  baselineUnitPrice: 2.5,
  months: 12,
  periodSuffix: '/yr',
  packageUnitLabel: 'devices',
  customLabel: 'Custom Plan',
  customSubtitle: 'Contact us for pricing',
  payAsYouGoOption: { name: 'PAYG', description: 'Billed monthly per device' },
  unitSize: 1,
  showPayg: false, // Hide PAYG on yearly tab
});

// Returns: [tierOptions..., { value: 'custom', label: 'Custom Plan', ... }]
```

## Notes

- Discount badges (`-X%`) are rendered as `<Tag variant="success">` only when the tier price is below `baselineUnitPrice`
- PAYG option is suppressed when `showPayg` is `false` (e.g., on annual billing tabs)
- The custom option (`CUSTOM_OPTION_ID`) is always appended last
