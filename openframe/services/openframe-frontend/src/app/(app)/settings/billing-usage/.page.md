Billing Usage page component that renders the subscription usage dashboard, gating access behind a feature flag and streaming content with a skeleton fallback.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `BillingUsagePage` | `default` (Page Component) | Next.js page that renders billing usage content |
| `dynamic` | `const` | Forces dynamic (SSR) rendering on every request |

## Usage Example

```typescript
// Accessed via route: /billing/usage
// Automatically gated — returns 404 if subscription feature flag is disabled

// Feature flag check (lib/feature-flags.ts)
featureFlags.subscription.enabled() // must return true to render page

// Renders:
// <Suspense fallback={<BillingUsageSkeleton />}>
//   <BillingUsageView />
// </Suspense>
```

## Behavior

- **Feature Flag Gate** — Calls `featureFlags.subscription.enabled()`; redirects to `notFound()` if the subscription feature is disabled.
- **Streaming / Suspense** — Wraps `BillingUsageView` in `<Suspense>` with `BillingUsageSkeleton` as the loading fallback, enabling progressive rendering.
- **Force Dynamic** — `export const dynamic = 'force-dynamic'` ensures the page is never statically cached, keeping usage data fresh on every request.
