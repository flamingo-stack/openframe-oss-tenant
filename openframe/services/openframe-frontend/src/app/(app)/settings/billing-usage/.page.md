Billing usage page component that renders subscription usage data, gating access behind the `subscription` feature flag and redirecting to 404 if disabled.

## Key Components

- **`BillingUsagePage`** — Default export; checks the `subscription` feature flag via `featureFlags.subscription.enabled()`, calls `notFound()` if inactive, otherwise renders `BillingUsageView` wrapped in a `Suspense` boundary
- **`BillingUsageSkeleton`** — Loading fallback displayed while `BillingUsageView` suspends
- **`BillingUsageView`** — The primary content component presenting billing/usage details
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time

## Usage Example

```typescript
// Automatically rendered by Next.js App Router at:
// /billing/usage

// Feature flag guard (inside component):
if (!featureFlags.subscription.enabled()) {
  notFound(); // → 404
}

// With subscription enabled, renders:
<Suspense fallback={<BillingUsageSkeleton />}>
  <BillingUsageView />
</Suspense>
```

> **Note:** This page requires the `subscription` feature flag to be enabled. Deployments without an active subscription plan will serve a 404 for this route.
