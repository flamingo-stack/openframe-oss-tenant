Billing usage page component that conditionally renders based on the subscription feature flag, displaying usage data with a Suspense boundary for loading state.

## Key Components

- **`BillingUsagePage`** — Default export; checks `featureFlags.subscription.enabled()` and calls `notFound()` if the feature is disabled, otherwise renders the usage view
- **`BillingUsageView`** — Async content component wrapped in `<Suspense>`
- **`BillingUsageSkeleton`** — Fallback UI displayed during `BillingUsageView` data fetching
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time

## Usage Example

```typescript
// Accessed via the /billing/usage route.
// Rendered automatically by Next.js App Router.
// No props required.

// Feature flag guard pattern used:
if (!featureFlags.subscription.enabled()) {
  notFound(); // Returns 404 if subscription feature is off
}
```

> The page is protected by a feature flag — if `featureFlags.subscription.enabled()` returns `false`, Next.js will render the standard 404 page instead of the billing usage view.
