React hook that initiates a Stripe (or compatible) checkout session via a GraphQL mutation, handling redirect and error toast notifications.

## Key Components

- **`createCheckoutSessionMutation`** — Relay GraphQL mutation that calls `createCheckoutSession(input:)` and returns a `checkoutUrl`
- **`useCreateCheckoutSession()`** — Primary exported hook returning:
  - `mutate(input: CheckoutInput)` — triggers the mutation, redirects to `checkoutUrl` on success
  - `isPending: boolean` — reflects in-flight mutation state
- **Re-exported types** — `CheckoutInput`, `ProductCheckoutInput` from generated GraphQL types

## Usage Example

```typescript
import { useCreateCheckoutSession } from './use-create-checkout-session';

function CheckoutButton({ productId }: { productId: string }) {
  const { mutate, isPending } = useCreateCheckoutSession();

  const handleCheckout = () => {
    mutate({
      products: [{ productId, quantity: 1 }],
    });
  };

  return (
    <button onClick={handleCheckout} disabled={isPending}>
      {isPending ? 'Redirecting...' : 'Subscribe'}
    </button>
  );
}
```

## Behavior Notes

| Scenario | Behavior |
|---|---|
| Success with URL | Shows success toast → redirects via `window.location.href` |
| Success without URL | Shows destructive toast, no redirect |
| Mutation error | Shows destructive toast with error message |
