Custom React hook that initiates a Stripe (or compatible) checkout session via a GraphQL mutation, handles redirect on success, and displays toast notifications on failure.

## Key Components

- **`createCheckoutSessionMutation`** — Relay GraphQL mutation that calls `createCheckoutSession` and returns a `checkoutUrl`
- **`useCreateCheckoutSession()`** — Primary hook export; wraps the mutation with toast feedback and browser redirect logic
- **`mutate(input: CheckoutInput)`** — Triggers the checkout session creation with the provided input
- **`isPending`** — Boolean reflecting in-flight mutation state, useful for disabling UI controls
- **Re-exports** — `CheckoutInput` and `ProductCheckoutInput` types from generated GraphQL types

## Usage Example

```typescript
import { useCreateCheckoutSession } from './use-create-checkout-session';
import type { CheckoutInput } from './use-create-checkout-session';

function CheckoutButton({ priceId }: { priceId: string }) {
  const { mutate, isPending } = useCreateCheckoutSession();

  const handleCheckout = () => {
    const input: CheckoutInput = {
      products: [{ priceId, quantity: 1 }],
    };
    mutate(input);
  };

  return (
    <button onClick={handleCheckout} disabled={isPending}>
      {isPending ? 'Redirecting...' : 'Subscribe Now'}
    </button>
  );
}
```

## Behavior

| Scenario | Result |
|----------|--------|
| Mutation succeeds with URL | Success toast → `window.location.href` redirect |
| Mutation succeeds, no URL returned | Destructive toast, no redirect |
| Mutation throws error | Destructive toast with error message |
