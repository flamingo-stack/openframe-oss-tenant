React hook that initiates a Stripe (or similar) checkout session via a GraphQL mutation, handles redirect to the checkout URL, and surfaces toast notifications for success and error states.

## Key Components

- **`createCheckoutSessionMutation`** — Relay GraphQL mutation that calls `createCheckoutSession(input: CheckoutInput!)` and returns a `checkoutUrl`
- **`useCreateCheckoutSession()`** — Primary hook export; wraps the mutation with toast feedback and a `window.location.href` redirect on success
- **`CheckoutInput` / `ProductCheckoutInput`** — Re-exported generated GraphQL input types for consumer use

## Usage Example

```typescript
import { useCreateCheckoutSession } from './use-create-checkout-session';
import type { CheckoutInput } from './use-create-checkout-session';

function UpgradeButton() {
  const { mutate, isPending } = useCreateCheckoutSession();

  const handleCheckout = () => {
    const input: CheckoutInput = {
      products: [{ productId: 'plan_pro', quantity: 1 }],
    };
    mutate(input);
  };

  return (
    <button onClick={handleCheckout} disabled={isPending}>
      {isPending ? 'Loading...' : 'Upgrade to Pro'}
    </button>
  );
}
```

## Behavior

| Scenario | Outcome |
|----------|---------|
| Mutation succeeds with URL | Success toast → redirects to `checkoutUrl` |
| Mutation succeeds, no URL returned | Destructive toast, no redirect |
| Mutation throws an error | Destructive toast with error message |

- Returns `isPending` (mapped from Relay's `isInFlight`) to disable UI during the in-flight request
- The `mutate` function is memoized via `useCallback`, depending on `commit` and `toast`
