A retention-focused modal displayed during subscription cancellation that presents context-aware alternative offers based on the user's stated cancellation reason.

## Key Components

### `OFFER_PRESETS`

A record mapping each `CancelReason` to a tailored `OfferPreset` object. Handles five cancellation scenarios:

| Reason | Offer Strategy |
|---|---|
| `TOO_EXPENSIVE` | Downgrade plan → `/settings/billing-usage/subscription` |
| `NOT_USING_ENOUGH` | Downgrade plan → `/settings/billing-usage/subscription` |
| `MISSING_FEATURE` | View roadmap → `https://openframe.ai/roadmap` |
| `TECHNICAL_ISSUES` | Contact support → `mailto:support@openframe.ai` |
| `OTHER` | Contact support → `mailto:support@openframe.ai` |

### `CancelOfferModal`

The main exported component. Renders a `SimpleModal` with a dynamic CTA card and two footer actions: **Keep Subscription** and **Cancel Subscription**.

### `OfferPreset` Interface

Defines the shape of each preset: `title`, `description`, `ctaTitle`, `ctaDescription`, `ctaIcon`, and optional `ctaHref`.

## Usage Example

```typescript
import { CancelOfferModal } from './cancel-offer-modal';
import type { CancelReason } from './cancel-subscription-modal';

function BillingPage() {
  const [isOpen, setIsOpen] = useState(false);
  const [reason, setReason] = useState<CancelReason | null>('TOO_EXPENSIVE');

  return (
    <CancelOfferModal
      isOpen={isOpen}
      reason={reason}
      isPending={false}
      onClose={() => setIsOpen(false)}
      onConfirm={() => handleCancelSubscription()}
      onCtaClick={() => trackCtaClick(reason)}
    />
  );
}
```

> **Note:** The component returns `null` when `reason` is `null`, so it is safe to render unconditionally while managing open state externally. The `onCtaClick` prop overrides the default `window.open` behavior, useful for analytics tracking before navigation.
