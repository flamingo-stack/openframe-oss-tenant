A modal component that presents context-aware retention offers before confirming a subscription cancellation, mapping each `CancelReason` to a tailored message and CTA.

## Key Components

**`OFFER_PRESETS`** — A `Record<CancelReason, OfferPreset>` map that defines per-reason retention content:
- `TOO_EXPENSIVE` / `NOT_USING_ENOUGH` → Plan comparison CTA (`/settings/billing-usage/subscription`)
- `MISSING_FEATURE` → Roadmap link (`https://openframe.ai/roadmap`)
- `TECHNICAL_ISSUES` / `OTHER` → Support contact (`mailto:support@openframe.ai`)

**`CancelOfferModal`** — The exported component renders a `SimpleModal` with:
- A contextual description and icon-driven CTA button
- "Keep Subscription" (outline) and "Cancel Subscription" (destructive) footer actions
- A `handleCtaClick` that either calls `onCtaClick` or opens `preset.ctaHref` in a new tab

**`OfferPreset`** — Internal interface defining the shape of each retention offer (`title`, `description`, `ctaTitle`, `ctaDescription`, `ctaIcon`, `ctaHref`).

## Usage Example

```typescript
import { CancelOfferModal } from './cancel-offer-modal';

<CancelOfferModal
  isOpen={showOfferModal}
  reason="TOO_EXPENSIVE"
  isPending={isCancelling}
  onClose={() => setShowOfferModal(false)}
  onConfirm={handleConfirmCancel}
  onCtaClick={() => router.push('/settings/billing-usage/subscription')}
/>
```

> **Note:** `reason` accepts `CancelReason` values (`TOO_EXPENSIVE`, `NOT_USING_ENOUGH`, `MISSING_FEATURE`, `TECHNICAL_ISSUES`, `OTHER`). Passing `null` renders nothing — guard upstream before opening the modal.
