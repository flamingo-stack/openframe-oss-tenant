A retention-focused modal shown during subscription cancellation flow, presenting contextual offers and alternatives based on the user's stated cancellation reason before confirming cancellation.

## Key Components

### `OFFER_PRESETS`
A `Record<CancelReason, OfferPreset>` map that defines tailored retention messaging for each cancellation reason:

| Reason | Offer |
|---|---|
| `TOO_EXPENSIVE` / `NOT_USING_ENOUGH` | Downgrade plan link → `/settings/billing-usage/subscription` |
| `MISSING_FEATURE` | Roadmap link → `https://openframe.ai/roadmap` |
| `TECHNICAL_ISSUES` / `OTHER` | Support contact → `mailto:support@openframe.ai` |

### `CancelOfferModal`
Main exported component. Renders a `SimpleModal` with:
- Contextual description text from the matched preset
- A clickable CTA card (icon + title + description + chevron) linking to the retention resource
- Footer with **Keep Subscription** (outline) and **Cancel Subscription** (destructive) actions

### Interfaces
- **`OfferPreset`** — shape of each retention preset (title, description, CTA content, icon, href)
- **`CancelOfferModalProps`** — `isOpen`, `reason`, `isPending`, `onClose`, `onConfirm`, `onCtaClick`

## Usage Example

```typescript
import { CancelOfferModal } from './cancel-offer-modal';
import type { CancelReason } from './cancel-subscription-modal';

function BillingPage() {
  const [showOffer, setShowOffer] = useState(false);
  const [cancelReason, setCancelReason] = useState<CancelReason | null>(null);

  return (
    <CancelOfferModal
      isOpen={showOffer}
      reason={cancelReason}
      isPending={false}
      onClose={() => setShowOffer(false)}
      onConfirm={() => handleCancelSubscription()}
      onCtaClick={() => trackRetentionCtaClick(cancelReason)}
    />
  );
}
```

> The `onCtaClick` prop overrides the default `window.open` behavior, useful for analytics tracking before redirecting.
