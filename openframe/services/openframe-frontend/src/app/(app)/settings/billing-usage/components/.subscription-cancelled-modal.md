Modal component that notifies users their subscription has been cancelled, displaying the service end date and informing them of access limitations.

## Key Components

**`SubscriptionCancelledModal`** — Main exported component rendering a `SimpleModal` with cancellation details and a close button.

**`formatEndDate(iso)`** — Internal helper that safely formats an ISO date string using `formatDate`, falling back to the raw string or `—` if null/invalid.

**`SubscriptionCancelledModalProps`** — Interface defining:
- `isOpen: boolean` — Controls modal visibility
- `endDate: string | null` — ISO date string for subscription end date
- `onClose: () => void` — Callback to dismiss the modal

## Usage Example

```typescript
import { SubscriptionCancelledModal } from './subscription-cancelled-modal';

function BillingPage() {
  const [showModal, setShowModal] = useState(true);

  return (
    <SubscriptionCancelledModal
      isOpen={showModal}
      endDate="2025-03-31T23:59:59Z"
      onClose={() => setShowModal(false)}
    />
  );
}
```

## Behavior Notes

- **Null-safe date formatting**: If `endDate` is `null`, the end date renders as `—`
- **Pay-as-you-go disabled**: Informs users top-ups are deactivated; existing devices and tokens remain accessible until the displayed end date
- **Accent close button**: Uses the `accent` variant from the OpenFrame UI system, spanning full available width in the footer
