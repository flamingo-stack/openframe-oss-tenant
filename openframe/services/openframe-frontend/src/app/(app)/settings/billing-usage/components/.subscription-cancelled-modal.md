A modal component that notifies users their subscription has been cancelled, displaying the service end date and informing them of access limitations.

## Key Components

### `SubscriptionCancelledModal`
The primary exported component. Renders a `SimpleModal` with a cancellation notice and an accent "Close" button in the footer.

### `SubscriptionCancelledModalProps`
| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls modal visibility |
| `endDate` | `string \| null` | ISO date string for service end date |
| `onClose` | `() => void` | Callback fired when the modal is dismissed |

### `formatEndDate` (internal)
Safely formats a nullable ISO date string using `formatDate`. Falls back to the raw string on parse error, or `—` if null.

## Usage Example

```typescript
import { SubscriptionCancelledModal } from './subscription-cancelled-modal';

function BillingPage() {
  const [showModal, setShowModal] = useState(true);

  return (
    <SubscriptionCancelledModal
      isOpen={showModal}
      endDate="2025-09-01T00:00:00Z"
      onClose={() => setShowModal(false)}
    />
  );
}
```

The modal highlights the end date in `ods-warning` color and informs the user that pay-as-you-go top-ups are disabled while existing devices and tokens remain active until that date.
