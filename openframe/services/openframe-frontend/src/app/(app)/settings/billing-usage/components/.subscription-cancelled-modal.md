Modal component that notifies users their subscription has been cancelled, displaying the access end date and disabling pay-as-you-go top-ups.

## Key Components

- **`SubscriptionCancelledModal`** — Main export; renders a `SimpleModal` informing the user that pay-as-you-go top-ups are disabled and showing when existing devices/tokens expire
- **`formatEndDate`** — Internal helper that safely formats an ISO date string using `formatDate`, falling back to the raw string on parse errors or `—` if null

## Props

| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls modal visibility |
| `endDate` | `string \| null` | ISO date string for subscription end; displays `—` if null |
| `onClose` | `() => void` | Callback fired when the Close button is clicked |

## Usage Example

```typescript
import { SubscriptionCancelledModal } from '@/app/components/billing/subscription-cancelled-modal';

export function BillingPage() {
  const [showCancelled, setShowCancelled] = useState(false);

  return (
    <SubscriptionCancelledModal
      isOpen={showCancelled}
      endDate="2025-12-31T23:59:59Z"
      onClose={() => setShowCancelled(false)}
    />
  );
}
```
