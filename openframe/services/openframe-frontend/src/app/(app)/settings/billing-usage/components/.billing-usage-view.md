Renders the Billing & Usage settings page, displaying subscription status, device/AI usage metrics, plan details, and a multi-step subscription cancellation flow.

## Key Components

- **`BillingUsageView`** — Public entry point; wraps content in `<Suspense>` with `BillingUsageSkeleton` as fallback
- **`BillingUsageContent`** — Core rendering logic; fetches data via `billingUsageViewQuery` (Relay) and orchestrates the full page layout
- **`billingUsageViewQuery`** — GraphQL query fetching `subscription` (status, usage, invoices, products) and `billingPlan` (product definitions)
- **Cancel flow state machine** — Four steps: `idle → reason → offer → cancelled`, managed via `useState`

## Key Behaviors

- **Dynamic primary action** — Adapts CTA label/variant based on subscription state: pending cancellation → "Renew", overdue → "Pay Overage", trial → "Activate", otherwise → "Update Subscription"
- **Overage warnings block** — Conditionally renders device/AI overage counts and estimated costs when limits are exceeded
- **Pending plan section** — Shows upcoming plan changes (device/AI quantities + start date) when `flags.hasPendingPlan` is true
- **Cancellation impact** — Lazy-loads `useCancellationImpact` stats (tickets, KB articles, monitoring policies) only when the cancel modal is open

## Usage Example

```typescript
// Rendered as a Next.js page route
export default function BillingUsagePage() {
  return <BillingUsageView />;
}
```

```typescript
// Cancel flow state transitions
// idle → (click "Cancel Subscription") → reason
// reason → (confirm with reason) → offer
// offer → (confirm cancellation) → cancelled
// any step → (close modal) → idle
```
