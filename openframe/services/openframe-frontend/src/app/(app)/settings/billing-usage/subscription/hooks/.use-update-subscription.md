A React hook that executes the `updateSubscription` GraphQL mutation via Relay, handling success/error toasts and automatic redirect to Stripe-hosted invoice pages when payment is required.

## Key Components

- **`useUpdateSubscription()`** — Primary hook returning `mutate` and `isPending`
- **`mutate(input: UpdateSubscriptionInput)`** — Triggers the mutation; handles three outcome paths:
  - GraphQL-level errors → destructive toast
  - Pending invoices exist → success toast + redirect to `hostedInvoiceUrl` (most recent invoice)
  - Clean success → success toast
- **`isPending`** — Boolean reflecting Relay's in-flight mutation state
- **Re-exported types** — `PackageUpdateInput`, `UpdateSubscriptionInput` (from generated GraphQL types)

## Usage Example

```typescript
import { useUpdateSubscription } from './use-update-subscription';

function SubscriptionManager() {
  const { mutate, isPending } = useUpdateSubscription();

  const handleUpgrade = () => {
    mutate({
      subscriptionId: 'sub_123',
      packages: [{ packageId: 'pkg_pro', quantity: 1 }],
    });
  };

  return (
    <button onClick={handleUpgrade} disabled={isPending}>
      {isPending ? 'Updating...' : 'Upgrade Plan'}
    </button>
  );
}
```

> **Note:** When the mutation returns pending invoices, the hook automatically redirects the user to the Stripe-hosted payment page (`window.location.href`). Ensure this hook is only used in client components (`'use client'`).
