A React hook that wraps a Relay GraphQL mutation for updating a subscription, with built-in toast notifications and payment redirect handling.

## Key Components

- **`useUpdateSubscription()`** — Primary hook export that returns `mutate` and `isPending`
- **`updateSubscriptionMutation`** — GraphQL mutation fetching subscription status, dates, cancellation info, and pending invoices
- **`mutate(input)`** — Executes the mutation; handles errors, payment redirects, and success states via toast notifications
- **`isPending`** — Boolean reflecting the in-flight mutation state
- **Re-exported types:** `PackageUpdateInput`, `UpdateSubscriptionInput`

## Behavior

| Outcome | Action |
|---|---|
| GraphQL errors returned | Destructive toast with error messages |
| Pending invoice exists | Redirects to `hostedInvoiceUrl` for payment |
| Successful update | Success toast confirming changes applied |
| Network/runtime error | Destructive toast with error message |

## Usage Example

```typescript
import { useUpdateSubscription } from './use-update-subscription';

function SubscriptionManager() {
  const { mutate, isPending } = useUpdateSubscription();

  const handleUpgrade = () => {
    mutate({
      packages: [{ packageId: 'pkg_pro', quantity: 1 }],
    });
  };

  return (
    <button onClick={handleUpgrade} disabled={isPending}>
      {isPending ? 'Updating...' : 'Upgrade Plan'}
    </button>
  );
}
```
