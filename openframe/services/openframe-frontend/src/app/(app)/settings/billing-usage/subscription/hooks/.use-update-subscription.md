React hook that manages subscription update mutations via Relay GraphQL, handling success/error toasts and payment redirect flows for pending invoices.

## Key Components

- **`useUpdateSubscription`** — Primary hook that wraps a Relay mutation for updating a subscription, returning a `mutate` function and `isPending` loading state
- **`updateSubscriptionMutation`** — GraphQL mutation fetching updated subscription fields (`status`, `startDate`, `currentPeriodEnd`, `cancellationEffectiveAt`, `pendingInvoices`)
- **`PackageUpdateInput` / `UpdateSubscriptionInput`** — Re-exported input types from generated GraphQL types

## Behavior

| Scenario | Result |
|---|---|
| GraphQL errors returned | Destructive toast with error messages |
| Pending invoice exists | Success toast + redirect to `hostedInvoiceUrl` |
| No pending invoice | Success toast confirming changes applied |
| Network/runtime error | Destructive toast with error message |

## Usage Example

```typescript
import { useUpdateSubscription } from './use-update-subscription';

function SubscriptionManager() {
  const { mutate, isPending } = useUpdateSubscription();

  const handleUpgrade = () => {
    mutate({
      packageUpdates: [{ packageId: 'pkg_123', quantity: 5 }],
    });
  };

  return (
    <button onClick={handleUpgrade} disabled={isPending}>
      {isPending ? 'Updating...' : 'Upgrade Plan'}
    </button>
  );
}
```
