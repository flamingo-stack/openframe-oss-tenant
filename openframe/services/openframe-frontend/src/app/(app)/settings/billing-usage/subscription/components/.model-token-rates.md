Renders a table of AI model token exchange rates fetched via Relay, displaying provider icons and input/output token ratios in a styled card layout.

## Key Components

- **`ModelTokenRates`** *(exported)* — Public entry point; wraps content in a self-contained `Suspense` boundary to avoid triggering page-level skeleton flashes during lazy query fetching
- **`ModelTokenRatesContent`** — Fetches `aiModelRates` (model name, provider type, input/output token rates) via `useLazyLoadQuery` and renders each row with a provider icon and formatted rate ratio
- **`ModelTokenRatesSkeleton`** — Loading fallback rendering 10 placeholder rows with animated skeletons
- **`formatRate(value)`** — Converts a numeric rate to a human-readable ratio string (e.g., `2:1` or `1:4`); returns `—` for invalid/zero values
- **`PROVIDER_ICON`** — Maps provider type strings (`ANTHROPIC`, `OPENAI`, `GOOGLE_GEMINI`) to their respective logo icon components

## Usage Example

```typescript
import { ModelTokenRates } from './model-token-rates';

// Drop into any tooltip or panel — handles its own loading state
function AiCostTooltip() {
  return (
    <TooltipContent>
      <ModelTokenRates />
    </TooltipContent>
  );
}
```

> **Note:** The component uses `fetchPolicy: 'store-or-network'`, so repeated opens within the same session serve from the Relay store without a network round-trip. Designed for use inside tooltips or popovers that mount lazily — the internal `Suspense` boundary ensures only the card skeleton flashes, not the full page.
