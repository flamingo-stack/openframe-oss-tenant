Renders a table of AI model token exchange rates fetched via Relay, mapping provider icons to input/output rate ratios with a built-in Suspense skeleton fallback.

## Key Components

- **`ModelTokenRates`** — Public export; wraps content in a self-contained `Suspense` boundary to avoid triggering the page-level skeleton on lazy load
- **`ModelTokenRatesContent`** — Executes the `modelTokenRatesQuery` GraphQL query via `useLazyLoadQuery` and renders the rates table
- **`ModelTokenRatesSkeleton`** — Loading placeholder with 10 animated skeleton rows matching the table layout
- **`formatRate(value)`** — Utility that converts a numeric token rate into a human-readable ratio string (e.g. `2:1` or `1:4`); returns `—` for invalid/zero values
- **`PROVIDER_ICON`** — Map from provider type string (`ANTHROPIC`, `OPENAI`, `GOOGLE_GEMINI`) to their respective logo icon components

## Usage Example

```typescript
// Drop into any tooltip or panel — fetches lazily on mount,
// falls back to skeleton without affecting page-level Suspense
import { ModelTokenRates } from './model-token-rates';

export function TokenInfoTooltip() {
  return (
    <TooltipContent>
      <ModelTokenRates />
    </TooltipContent>
  );
}
```

> **Note:** Input and output rates are displayed as a single value when equal, or as `inputRate / outputRate` when they differ. The `fetchPolicy: 'store-or-network'` ensures cached data is used when available, avoiding redundant network requests on repeated tooltip opens.
