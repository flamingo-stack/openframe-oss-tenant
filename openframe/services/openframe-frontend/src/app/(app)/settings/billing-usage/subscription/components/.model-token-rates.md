Renders a table of AI model token exchange rates fetched via Relay, displaying provider icons and input/output token ratios in a tooltip-friendly card layout.

## Key Components

- **`ModelTokenRates`** — Public export; wraps content in a local `Suspense` boundary to avoid bubbling suspension to the page-level skeleton.
- **`ModelTokenRatesContent`** — Fetches `aiModelRates` (model name, provider, input/output token rates) via `useLazyLoadQuery` with `store-or-network` policy and renders the populated card.
- **`ModelTokenRatesSkeleton`** — Placeholder card with 10 animated skeleton rows shown while the query is in-flight.
- **`formatRate(value)`** — Converts a numeric rate to a human-readable ratio string (e.g., `2:1` or `1:4`); returns `—` for invalid/zero values.
- **`PROVIDER_ICON`** — Maps provider type strings (`ANTHROPIC`, `OPENAI`, `GOOGLE_GEMINI`) to their respective logo icon components.

## Usage Example

```typescript
// Drop into any tooltip, popover, or settings panel.
// The component self-manages its loading state — no external Suspense needed.
import { ModelTokenRates } from './model-token-rates';

function TokenRatesTooltip() {
  return (
    <Tooltip>
      <ModelTokenRates />
    </Tooltip>
  );
}
```

> **Note:** The query is triggered lazily on first render of the tooltip/popover, so placing `ModelTokenRates` inside a conditionally rendered container (e.g., a closed tooltip) defers the network request until the user opens it.
