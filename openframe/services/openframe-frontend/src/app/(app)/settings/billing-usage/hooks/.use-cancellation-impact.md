React Query hook that aggregates data loss metrics across three API transports (ai-agent GraphQL, main GraphQL, Fleet REST) for display in a subscription cancellation confirmation modal.

## Key Components

**`CancellationImpact`** — Exported interface describing the four resource counts surfaced to the user:
- `tickets` — Sum of all ticket status counts
- `kbArticles` — Total knowledge base articles
- `monitoringPolicies` — Fleet monitoring policies count
- `savedQueries` — Fleet saved queries count

**`fetchTicketsTotal()`** — Internal async function querying the ai-agent GraphQL endpoint (`/chat/graphql`) for aggregated ticket status counts.

**`fetchKbArticles()`** — Internal async function querying the main GraphQL endpoint (`/api/graphql`) for knowledge base article count.

**`useCancellationImpact({ enabled })`** — Primary exported hook; uses `Promise.allSettled` so a failure in any single source degrades gracefully to `0` rather than rejecting the entire query.

## Usage Example

```typescript
import { useCancellationImpact } from '@/hooks/use-cancellation-impact';

function CancellationModal({ isOpen }: { isOpen: boolean }) {
  const { impact, isLoading } = useCancellationImpact({ enabled: isOpen });

  if (isLoading) return <Spinner />;

  return (
    <div>
      <p>You will lose access to:</p>
      <ul>
        <li>{impact?.tickets} tickets</li>
        <li>{impact?.kbArticles} knowledge base articles</li>
        <li>{impact?.monitoringPolicies} monitoring policies</li>
        <li>{impact?.savedQueries} saved queries</li>
      </ul>
    </div>
  );
}
```

> **Design note:** The hook is lazily fetched (`enabled` prop) and cached for 60 seconds (`staleTime: 60_000`). Individual source failures silently fall back to `0` — no error toasts are shown, as this is read-only ancillary data.
