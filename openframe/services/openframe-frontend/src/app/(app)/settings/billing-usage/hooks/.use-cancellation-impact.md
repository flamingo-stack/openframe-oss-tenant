React Query hook that aggregates "what you'll lose" impact counts (tickets, KB articles, monitoring policies, saved queries) for display in a subscription cancellation confirmation modal.

## Key Components

### `CancellationImpact` (interface)
Exported shape returned by the hook:

| Field | Description |
|---|---|
| `tickets` | Total ticket count across all statuses |
| `kbArticles` | Knowledge base article count |
| `monitoringPolicies` | Fleet monitoring policy count |
| `savedQueries` | Fleet saved query count |

### `fetchTicketsTotal` (internal)
Posts to the ai-agent GraphQL endpoint (`/chat/graphql`) to sum ticket counts across all `statusCounts` entries.

### `fetchKbArticles` (internal)
Posts to the main GraphQL endpoint (`/api/graphql`) querying `knowledgeBaseItems` filtered to `ARTICLE` type.

### `useCancellationImpact` (exported hook)
Lazy React Query hook controlled by `enabled`. Runs all four data fetches in parallel via `Promise.allSettled` — individual failures silently degrade to `0` rather than rejecting the whole result.

## Usage Example

```typescript
const { impact, isLoading } = useCancellationImpact({ enabled: isModalOpen });

if (isLoading) return <Spinner />;

return (
  <p>You will lose {impact?.tickets} tickets and {impact?.kbArticles} KB articles.</p>
);
```

## Behavior Notes

- **Lazy fetching** — only executes while `enabled: true` (i.e. modal is open)
- **Fault-tolerant** — uses `Promise.allSettled`; any failing source returns `0` for that field, no toast or throw
- **Three transports** — ai-agent GraphQL, main GraphQL, and Fleet REST API are queried concurrently
- **Cache TTL** — results are stale after 60 seconds (`staleTime: 60_000`)
