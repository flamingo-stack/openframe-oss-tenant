Fetches and aggregates "what you'll lose" counts across multiple data sources (tickets, KB articles, monitoring policies, saved queries) to display in a cancellation confirmation modal.

## Key Components

### `CancellationImpact` (interface)
Aggregated impact data shape returned by the hook:

| Field | Description |
|-------|-------------|
| `tickets` | Total ticket count across all statuses |
| `kbArticles` | Total knowledge base article count |
| `monitoringPolicies` | Fleet monitoring policy count |
| `savedQueries` | Fleet saved query count |

### `useCancellationImpact({ enabled })`
Primary hook. Accepts an `enabled` flag for lazy fetching — only executes while the cancellation modal is open. Uses `Promise.allSettled` so a failing source degrades to `0` silently rather than blocking the full result.

**Data sources:**
- `fetchTicketsTotal()` — ai-agent GraphQL endpoint (`/chat/graphql`)
- `fetchKbArticles()` — main GraphQL endpoint (`/api/graphql`)
- `fleetApiClient.getPoliciesCount()` — Fleet REST API
- `fleetApiClient.getQueriesCount()` — Fleet REST API

## Usage Example

```typescript
import { useCancellationImpact } from './use-cancellation-impact';

function CancellationModal({ isOpen }: { isOpen: boolean }) {
  const { impact, isLoading } = useCancellationImpact({ enabled: isOpen });

  if (isLoading) return <Spinner />;

  return (
    <div>
      <p>Tickets: {impact?.tickets}</p>
      <p>KB Articles: {impact?.kbArticles}</p>
      <p>Monitoring Policies: {impact?.monitoringPolicies}</p>
      <p>Saved Queries: {impact?.savedQueries}</p>
    </div>
  );
}
```

> Results are cached for 60 seconds (`staleTime: 60_000`). Failed individual sources return `0` — no error toasts are shown since this is read-only ancillary data.
