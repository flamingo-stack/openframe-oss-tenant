Utility functions for formatting numbers, currency, and dates for display in the UI.

## Key Components

| Function | Description |
|----------|-------------|
| `formatCount` | Formats a number with locale-aware thousands separators (en-US) |
| `formatCurrency` | Formats a number as USD currency with 2 decimal places |
| `formatDateOrDash` | Formats an ISO date string using `formatDate`, returning `—` for null/undefined and falling back to the raw string on parse errors |

## Usage Example

```typescript
import { formatCount, formatCurrency, formatDateOrDash } from '@/lib/format';

formatCount(1234567);         // "1,234,567"
formatCurrency(9.5);          // "$9.50"
formatCurrency(1299.99);      // "$1,299.99"

formatDateOrDash(null);               // "—"
formatDateOrDash('2024-01-15T00:00:00Z'); // "Jan 15, 2024" (via formatDate)
formatDateOrDash('not-a-date');           // "not-a-date" (fallback)
```

> **Note:** `formatDateOrDash` silently catches errors from the underlying `formatDate` utility and returns the original string as a safe fallback, preventing UI crashes from malformed date inputs.
