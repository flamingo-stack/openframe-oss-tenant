Utility functions for formatting numbers, currency, and dates for display in the UI.

## Key Components

| Function | Description |
|----------|-------------|
| `formatCount` | Formats a number with locale-aware thousands separators (e.g. `1000` → `"1,000"`) |
| `formatCurrency` | Formats a number as USD currency with two decimal places (e.g. `9.5` → `"$9.50"`) |
| `formatDateOrDash` | Formats an ISO date string using the shared `formatDate` utility; returns `—` for null/undefined and falls back to the raw string on parse errors |

## Usage Example

```typescript
import { formatCount, formatCurrency, formatDateOrDash } from '@/lib/format';

// Number formatting
formatCount(1000000);         // "1,000,000"

// Currency formatting
formatCurrency(1234.5);       // "$1,234.50"
formatCurrency(0);            // "$0.00"

// Date formatting
formatDateOrDash('2024-01-15T10:30:00Z'); // "Jan 15, 2024" (via formatDate)
formatDateOrDash(null);                   // "—"
formatDateOrDash(undefined);              // "—"
formatDateOrDash('bad-date');             // "bad-date" (fallback)
```

> All number and currency formatting uses `en-US` locale. Currency values are always rendered as USD.
