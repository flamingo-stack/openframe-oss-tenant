Utility functions for formatting numbers, currency, and dates for display in the UI.

## Key Components

| Function | Signature | Description |
|----------|-----------|-------------|
| `formatCount` | `(value: number) => string` | Formats a number with US locale thousand separators (e.g. `1000` → `"1,000"`) |
| `formatCurrency` | `(value: number) => string` | Formats a number as USD currency with 2 decimal places (e.g. `9.5` → `"$9.50"`) |
| `formatDateOrDash` | `(iso: string \| null \| undefined) => string` | Parses an ISO date string via `formatDate`; returns `"—"` for falsy input and falls back to the raw string on parse error |

## Usage Example

```typescript
import { formatCount, formatCurrency, formatDateOrDash } from './format';

// Number formatting
formatCount(1500000);          // "1,500,000"

// Currency formatting
formatCurrency(1299.9);        // "$1,299.90"
formatCurrency(0);             // "$0.00"

// Date formatting
formatDateOrDash('2024-03-15T10:00:00Z');  // "Mar 15, 2024" (via formatDate)
formatDateOrDash(null);                     // "—"
formatDateOrDash(undefined);               // "—"
formatDateOrDash('not-a-date');            // "not-a-date" (fallback)
```

> **Note:** `formatDateOrDash` silently swallows parse errors and returns the original string as a safe fallback, making it safe to use with untrusted or partially-formed ISO strings.
