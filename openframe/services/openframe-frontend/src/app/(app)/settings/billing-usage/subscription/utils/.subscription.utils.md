Utility functions for subscription product selection, pricing calculations, and checkout/update payload construction within the billing UI.

## Key Components

### Constants
- `CUSTOM_OPTION_ID` — Sentinel ID (`'__custom__'`) for user-defined quantity selections
- `PAYG_OPTION_ID` — Sentinel ID (`'__payg__'`) for Pay-As-You-Go selections

### Formatting Helpers
- `formatMoney(value)` — Formats a number as a locale string with no decimal places
- `formatCompact(value)` — Formats large numbers compactly (e.g. `100000` → `"100K"`)
- `formatPaygSubtitle(option)` — Combines `description` and `name` into a display subtitle

### Selection & Pricing Logic
- `topmostSelectionId(product, period)` — Returns the default radio selection ID for a given billing period
- `calculateCustomQuantityPrice(quantity, allTiers, baselineUnitPrice, months)` — Computes total cost and discount percentage for a custom quantity against tiered pricing
- `buildInitialSelection(product, subscriptionProduct)` — Derives the initial `ProductSelectionState` from active subscription data
- `toDisplayQuantity(rawUnits, unitSize)` — Converts backend unit quantities to human-readable display values

### Mutation Payload Builders
- `diffPackageUpdates(product, currentSelection, subscriptionProduct)` — Produces `PackageUpdateInput[]` representing the minimal ADD/CANCEL diff between current and desired state
- `buildProductCancelUpdates(productName, subscriptionProduct)` — Builds CANCEL inputs for all active packages on a product (used when disabling AI Assistant)
- `buildCheckoutProduct(product, currentSelection)` — Builds a `ProductCheckoutInput` describing the target plan for new checkout sessions (trial/canceled flows)

## Usage Example

```typescript
import {
  buildInitialSelection,
  diffPackageUpdates,
  buildCheckoutProduct,
  calculateCustomQuantityPrice,
} from './subscription.utils';

// Derive UI state from active subscription
const selection = buildInitialSelection(product, subscriptionProduct);

// Compute diff for an update mutation
const updates = diffPackageUpdates(product, selection, subscriptionProduct);

// Build checkout payload for a new subscription
const checkoutInput = buildCheckoutProduct(product, selection);

// Price a custom quantity against tiered pricing
const pricing = calculateCustomQuantityPrice(500, priceTiers, 0.10, 12);
// → { total: 540, discountPercent: 10 }
```
