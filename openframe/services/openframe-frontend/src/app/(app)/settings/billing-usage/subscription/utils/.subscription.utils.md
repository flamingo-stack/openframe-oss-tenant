Utility functions for subscription product selection, pricing calculations, and checkout/update payload construction used by the billing UI.

## Key Components

### Constants
- `CUSTOM_OPTION_ID` — Sentinel ID (`"__custom__"`) for user-entered custom quantity selections
- `PAYG_OPTION_ID` — Sentinel ID (`"__payg__"`) for Pay-As-You-Go selections

### Formatting Helpers
- `formatMoney(value)` — Formats a number as a locale string with no decimal places
- `formatCompact(value)` — Formats a number with compact notation (e.g. `100000 → "100K"`)
- `formatPaygSubtitle(option)` — Combines PAYG option `description` and `name` into a display string

### Pricing Logic
- `topmostSelectionId(product, period)` — Returns the first selectable radio option ID for a billing period (PAYG → first tier → Custom)
- `calculateCustomQuantityPrice(quantity, allTiers, baselineUnitPrice, months)` — Finds the applicable price tier, computes total cost, and calculates discount percentage
- `toDisplayQuantity(rawUnits, unitSize)` — Converts backend unit quantities to human-readable counts (e.g. tokens ÷ 100,000)

### State Builders
- `buildInitialSelection(product, subscriptionProduct)` — Derives initial `ProductSelectionState` from active subscription data, falling back to sensible defaults
- `diffPackageUpdates(product, currentSelection, subscriptionProduct)` — Computes `PackageUpdateInput[]` diff (ADD/CANCEL) between current active package and desired selection
- `buildProductCancelUpdates(productName, subscriptionProduct)` — Generates CANCEL updates for all active packages on a product (used for AI Assistant opt-out)
- `buildCheckoutProduct(product, currentSelection)` — Builds a `ProductCheckoutInput` describing the full target plan for new checkout sessions

## Usage Example

```typescript
// Build initial UI state from active subscription
const selection = buildInitialSelection(productData, subscriptionProductData);

// Compute what mutations are needed on save
const updates = diffPackageUpdates(productData, selection, subscriptionProductData);
// → [{ productName: "AI Assistant", packageOptionId: "uuid", action: "ADD", quantity: 5 }]

// For new checkout (TRIAL / CANCELED state)
const checkoutProduct = buildCheckoutProduct(productData, selection);
```
