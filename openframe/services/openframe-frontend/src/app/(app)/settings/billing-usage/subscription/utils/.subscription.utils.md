Utility functions for subscription product selection, pricing calculations, and checkout/update payload construction used by the product subscription card UI.

## Key Components

| Export | Description |
|--------|-------------|
| `CUSTOM_OPTION_ID` | Sentinel ID (`__custom__`) for user-defined quantity selections |
| `PAYG_OPTION_ID` | Sentinel ID (`__payg__`) for pay-as-you-go selections |
| `formatMoney` | Formats a number as a locale-aware integer string (no decimals) |
| `formatCompact` | Compacts large numbers (e.g. `100000` → `"100K"`) |
| `topmostSelectionId` | Returns the default radio selection ID for a given billing period |
| `calculateCustomQuantityPrice` | Computes total price and discount % for a custom quantity against tiered pricing |
| `formatPaygSubtitle` | Builds display subtitle from a PAYG option's name/description |
| `buildInitialSelection` | Derives initial `ProductSelectionState` from catalog + active subscription data |
| `diffPackageUpdates` | Diffs current vs. desired selection into `PackageUpdateInput[]` (ADD/CANCEL actions) |
| `buildCheckoutProduct` | Builds a `ProductCheckoutInput` for new checkout sessions (trial/canceled accounts) |

## Usage Example

```typescript
import {
  buildInitialSelection,
  diffPackageUpdates,
  buildCheckoutProduct,
  calculateCustomQuantityPrice,
} from './subscription.utils';

// Derive initial UI state from catalog + active subscription
const selection = buildInitialSelection(productData, subscriptionProductData);

// Compute mutations needed to reach the new selection
const updates = diffPackageUpdates(productData, selection, subscriptionProductData);
// → [{ productName: 'AI Tokens', packageOptionId: 'uuid-...', action: 'ADD', quantity: 500 }]

// For new subscriptions (trial/canceled), build checkout payload instead
const checkoutProduct = buildCheckoutProduct(productData, selection);

// Price preview for a custom quantity input
const pricing = calculateCustomQuantityPrice(2500, priceTiers, baselineUnitPrice, 12);
// → { total: 30000, discountPercent: 20 }
```

> **Note:** `diffPackageUpdates` is a no-op (`[]`) when the desired state matches the active subscription, preventing redundant mutations.
