Reusable layout components for rendering structured billing information sections within the OpenFrame billing UI.

## Key Components

### `SectionBlock`
A container component that wraps billing content under a labeled section header. Renders a secondary uppercase title above a styled card panel.

**Props:**
| Prop | Type | Description |
|------|------|-------------|
| `title` | `string` | Section heading displayed in uppercase |
| `children` | `React.ReactNode` | Content rendered inside the card panel |

---

### `BillingRow`
A single labeled billing line item with a dotted separator and right-aligned value. Supports visual states for muted secondary info or warning highlights.

**Props:**
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `label` | `string` | — | Left-side label text |
| `value` | `React.ReactNode` | — | Right-side value (text, badge, icon, etc.) |
| `muted` | `boolean` | `false` | Renders value in secondary text color |
| `warning` | `boolean` | `false` | Renders value in warning color (takes priority over `muted`) |

## Usage Example

```typescript
import { SectionBlock, BillingRow } from './billing-section';

<SectionBlock title="Current Plan">
  <BillingRow label="Plan" value="Pro" />
  <BillingRow label="Seats" value="48 / 50" muted />
  <BillingRow label="Overdue Balance" value="$120.00" warning />
</SectionBlock>
```
