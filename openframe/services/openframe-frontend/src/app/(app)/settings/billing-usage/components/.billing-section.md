Reusable layout primitives for rendering structured billing information sections within the OpenFrame billing UI.

## Key Components

### `SectionBlock`
A titled container component that wraps billing content in a styled card with a secondary uppercase label header.

| Prop | Type | Description |
|------|------|-------------|
| `title` | `string` | Section heading displayed in uppercase secondary text |
| `children` | `React.ReactNode` | Content rendered inside the card container |

### `BillingRow`
A horizontal label-value row with a dotted separator line, used to display individual billing line items.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `label` | `string` | — | Left-side descriptor text |
| `value` | `React.ReactNode` | — | Right-side value (supports icons/badges) |
| `muted` | `boolean` | `false` | Renders value in secondary/dimmed text color |
| `warning` | `boolean` | `false` | Renders value in warning amber color |

## Usage Example

```typescript
import { SectionBlock, BillingRow } from './billing-section';

function BillingDetails() {
  return (
    <SectionBlock title="Current Period">
      <BillingRow label="Seats" value="12" />
      <BillingRow label="Overage" value="$24.00" warning />
      <BillingRow label="Next Renewal" value="Aug 1, 2025" muted />
    </SectionBlock>
  );
}
```
