Reusable layout primitives for billing UI sections, providing a labeled card container (`SectionBlock`) and a dotted-leader row (`BillingRow`) for displaying billing data.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `SectionBlock` | Component | Titled card wrapper with ODS-styled border, background, and padding |
| `BillingRow` | Component | Label/value row with a flexible divider line and optional text state variants |

### `SectionBlock` Props

| Prop | Type | Description |
|------|------|-------------|
| `title` | `string` | Uppercase section heading rendered above the card |
| `children` | `React.ReactNode` | Content rendered inside the card body |

### `BillingRow` Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `label` | `string` | — | Left-side label text |
| `value` | `React.ReactNode` | — | Right-side value (supports icons, badges, etc.) |
| `muted` | `boolean` | `false` | Renders value in `ods-text-secondary` |
| `warning` | `boolean` | `false` | Renders value in `ods-warning` (takes precedence over `muted`) |

## Usage Example

```typescript
import { SectionBlock, BillingRow } from './billing-section';

export function PlanSummary() {
  return (
    <SectionBlock title="Current Plan">
      <BillingRow label="Plan" value="Pro" />
      <BillingRow label="Seats Used" value="48 / 50" warning />
      <BillingRow label="Next Invoice" value="$299.00" muted />
    </SectionBlock>
  );
}
```

> **Note:** `warning` takes precedence over `muted` when both are set. The flexible `h-px` divider between label and value stretches to fill available space, keeping values right-aligned regardless of label length.
