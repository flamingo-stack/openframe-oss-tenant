Custom React hook that executes a GraphQL mutation to cancel a subscription, with built-in toast error handling and optional success/failure callbacks.

## Key Components

- **`cancelSubscriptionMutation`** — Relay GraphQL mutation targeting `cancelSubscription(input: CancelSubscriptionInput)`
- **`CancelSubscriptionOptions`** — Optional config interface accepting `reason`, `description`, and `onSuccess` callback
- **`useCancelSubscription`** — Primary exported hook returning `mutate` and `isPending`

## Usage Example

```typescript
import { useCancelSubscription } from './use-cancel-subscription';

function CancelButton() {
  const { mutate, isPending } = useCancelSubscription();

  const handleCancel = () => {
    mutate({
      reason: 'too_expensive',
      description: 'Looking for a cheaper alternative',
      onSuccess: () => console.log('Subscription cancelled'),
    });
  };

  return (
    <button onClick={handleCancel} disabled={isPending}>
      {isPending ? 'Cancelling...' : 'Cancel Subscription'}
    </button>
  );
}
```

## Behavior Notes

- If neither `reason` nor `description` is provided, the mutation is called with `input: null`
- On error, a destructive toast notification is automatically shown with the error message
- `isPending` reflects the Relay in-flight mutation state, useful for disabling UI during the request
