A React hook that handles subscription cancellation via a GraphQL mutation, with built-in loading state and error toast notifications.

## Key Components

- **`cancelSubscriptionMutation`** — Relay GraphQL mutation targeting `cancelSubscription` with an optional `CancelSubscriptionInput`
- **`CancelSubscriptionOptions`** — Interface for optional cancellation parameters: `reason`, `description`, and an `onSuccess` callback
- **`useCancelSubscription()`** — Primary hook export returning `mutate` and `isPending`

## Usage Example

```typescript
import { useCancelSubscription } from './use-cancel-subscription';

function CancelSubscriptionButton() {
  const { mutate, isPending } = useCancelSubscription();

  const handleCancel = () => {
    mutate({
      reason: 'Too expensive',
      description: 'Monthly cost exceeds budget',
      onSuccess: () => console.log('Subscription cancelled'),
    });
  };

  return (
    <button onClick={handleCancel} disabled={isPending}>
      {isPending ? 'Cancelling...' : 'Cancel Subscription'}
    </button>
  );
}
```

## Behavior Notes

- `input` is passed as `null` when neither `reason` nor `description` is provided
- On error, a destructive toast is shown with the error message or a fallback string
- `isPending` reflects Relay's `isInFlight` state for disabling UI during the request
