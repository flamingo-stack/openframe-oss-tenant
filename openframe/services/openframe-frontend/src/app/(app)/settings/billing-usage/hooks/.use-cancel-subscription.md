React hook that executes a GraphQL mutation to cancel a subscription, with built-in error toast notifications and loading state tracking.

## Key Components

- **`cancelSubscriptionMutation`** — Relay GraphQL mutation calling `cancelSubscription` with an optional `CancelSubscriptionInput`
- **`CancelSubscriptionOptions`** — Interface accepting optional `reason`, `description`, and `onSuccess` callback
- **`useCancelSubscription`** — Main hook returning `mutate` and `isPending`

## Usage Example

```typescript
import { useCancelSubscription } from './use-cancel-subscription';

function CancelSubscriptionButton() {
  const { mutate, isPending } = useCancelSubscription();

  const handleCancel = () => {
    mutate({
      reason: 'too_expensive',
      description: 'The pricing no longer fits our budget.',
      onSuccess: () => console.log('Subscription cancelled'),
    });
  };

  return (
    <button onClick={handleCancel} disabled={isPending}>
      {isPending ? 'Cancelling...' : 'Cancel Subscription'}
    </button>
  );
}
```

## Behavior Notes

- If neither `reason` nor `description` is provided, `input` is sent as `null`
- On error, a destructive toast is displayed with the error message or a fallback string
- `isPending` reflects Relay's `isInFlight` state, useful for disabling UI during mutation
