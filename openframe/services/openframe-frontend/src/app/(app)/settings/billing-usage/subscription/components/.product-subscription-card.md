A React client component that renders a product subscription selection card, allowing users to choose billing periods and package options (including custom quantities) for a given product within the Flamingo/OpenFrame MSP platform.

## Key Components

### Fragments
- **`productSubscriptionCardProductFragment`** — Relay fragment on `Product`, fetching id, name, unitSize, packageOptions (with price tiers), and payAsYouGoOption.
- **`productSubscriptionCardSubscriptionFragment`** — Relay fragment on `SubscriptionProductDetail`, fetching existing package/PAYG selections and status.

### Internal Components
- **`HelpTooltip`** — Renders a `QuestionCircleIcon` button that opens a tooltip. Supports both plain text and rich `ReactNode` content (adjusts styling accordingly).

### Main Export
- **`ProductSubscriptionCard`** — The primary card UI. Orchestrates billing period tab switching, package radio selection, and custom quantity input with live price calculation and divisibility validation.

## Key Props (`ProductSubscriptionCardProps`)

| Prop | Type | Description |
|------|------|-------------|
| `productRef` | Fragment key | Relay ref for product data |
| `subscriptionProductRef` | Fragment key \| null | Relay ref for existing subscription state |
| `packageUnitLabel` | `string` | Unit label shown in inputs (e.g. "seats") |
| `customLabel` | `string` | Label for the custom quantity radio option |
| `helpText` | `ReactNode` | Optional tooltip content |
| `disabled` | `boolean` | Grays out and disables the entire card |
| `onUpdatesChange` | `(updates: ProductUpdates) => void` | Callback fired on any selection change |

## Usage Example

```typescript
<ProductSubscriptionCard
  productRef={productFragmentKey}
  subscriptionProductRef={subscriptionFragmentKey}
  title="Microsoft 365"
  description="Cloud productivity suite"
  packageUnitLabel="licenses"
  customLabel="Custom"
  customSubtitle="Choose your own quantity"
  helpText="Contact us for volume pricing."
  onUpdatesChange={(updates) => handleSubscriptionUpdates(updates)}
/>
```
