A client-side React component that renders a product subscription selection card, allowing users to choose billing periods, package tiers, and custom quantities for a given product.

## Key Components

### Fragments
- **`productSubscriptionCardProductFragment`** — Relay fragment on `Product`, fetching id, name, unitSize, packageOptions (with price tiers), and payAsYouGoOption
- **`productSubscriptionCardSubscriptionFragment`** — Relay fragment on `SubscriptionProductDetail`, fetching existing package selections and PAYG option

### Components
- **`HelpTooltip`** — Internal tooltip component rendering a `QuestionCircleIcon` trigger; supports both plain text and rich `ReactNode` content with adaptive styling
- **`ProductSubscriptionCard`** — Main exported component handling billing period tab selection, package radio group, and animated custom quantity input with tiered price calculation

### Props (`ProductSubscriptionCardProps`)
| Prop | Type | Description |
|---|---|---|
| `productRef` | Fragment key | Relay product fragment reference |
| `subscriptionProductRef` | Fragment key \| `null` | Relay subscription fragment reference |
| `title` / `description` | `string` | Card header content |
| `packageUnitLabel` | `string` | Unit label (e.g. "users") |
| `customLabel` / `customSubtitle` | `string` | Labels for the custom quantity option |
| `helpText` | `ReactNode` | Optional tooltip content |
| `disabled` | `boolean` | Disables all interactions |
| `onUpdatesChange` | `(updates: ProductUpdates) => void` | Fires when selection changes |

## Usage Example

```typescript
<ProductSubscriptionCard
  productRef={productFragmentKey}
  subscriptionProductRef={subscriptionFragmentKey}
  title="Endpoint Protection"
  description="Per-device antivirus and threat monitoring"
  packageUnitLabel="devices"
  customLabel="Custom"
  customSubtitle="Enter a specific quantity"
  helpText="Billed monthly or annually depending on your selection."
  onUpdatesChange={(updates) => handleSubscriptionUpdates(updates)}
/>
```

> **Note:** Custom quantity input enforces whole multiples of `unitSize`; validation errors and tiered pricing previews render inline below the input field.
