A client-side React component that renders a product subscription selection card, allowing users to choose billing periods, package tiers, or enter custom quantities with real-time pricing calculations.

## Key Components

- **`ProductSubscriptionCard`** — Main export. Renders a full subscription card with billing period tabs, package radio options, and a collapsible custom quantity input with price feedback.
- **`HelpTooltip`** — Internal helper component that displays a `QuestionCircleIcon` trigger with contextual tooltip content (supports both plain text and rich `ReactNode`).
- **`productSubscriptionCardProductFragment`** — Relay GraphQL fragment on `Product`, pulling `id`, `name`, `unitSize`, `packageOptions`, and `payAsYouGoOption`.
- **`productSubscriptionCardSubscriptionFragment`** — Relay GraphQL fragment on `SubscriptionProductDetail`, pulling active package options and pay-as-you-go state.

## Key Behaviors

- Billing period tab selector renders only when multiple periods are available.
- Custom quantity input animates in/out via CSS grid row transitions when the custom package option is selected.
- Validates custom quantity is a whole multiple of `unitSize`; shows an error message otherwise.
- Displays calculated total price and discount percentage for valid custom quantities.
- Entire card can be disabled via the `disabled` prop (opacity + pointer-events).

## Usage Example

```typescript
import { ProductSubscriptionCard } from './product-subscription-card';

<ProductSubscriptionCard
  productRef={productFragmentKey}
  subscriptionProductRef={subscriptionFragmentKey}
  title="Endpoint Protection"
  description="Per-device antivirus and threat monitoring"
  packageUnitLabel="devices"
  customLabel="Custom"
  customSubtitle="Enter your own quantity"
  helpText="Billed per managed device per month."
  onUpdatesChange={(updates) => handleProductUpdates(updates)}
/>
```
