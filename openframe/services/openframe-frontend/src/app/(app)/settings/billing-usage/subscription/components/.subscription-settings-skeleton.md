Loading state skeleton component for the Subscription Settings page, providing a shimmer placeholder UI while billing/subscription data is being fetched.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `SubscriptionSettingsSkeleton` | Component | Root skeleton layout matching the full subscription settings page structure |
| `EnableCheckboxSkeleton` | Internal Component | Placeholder for the enable/disable subscription checkbox row |
| `ProductCardSkeleton` | Internal Component | Placeholder for each product card including title, description, tab selector, and package radio rows |

`RADIO_ROW_KEYS` — constant tuple defining the 5 pricing tier rows (`payg`, `tier-1`, `tier-2`, `tier-3`, `custom`) used to render the correct number of skeleton radio rows per card.

## Usage Example

```typescript
import { SubscriptionSettingsSkeleton } from './subscription-settings-skeleton';

// Use as a Suspense fallback or conditional loading state
export default function SubscriptionSettingsPage() {
  if (isLoading) return <SubscriptionSettingsSkeleton />;
  return <SubscriptionSettings />;
}
```

## Notes

- Uses `useSafeBack('/settings/billing-usage')` to wire the back button even during loading, preventing navigation deadlocks.
- `ProductCardSkeleton` renders two instances in a responsive grid (`1-col` → `2-col` at `lg`), mirroring the real page layout for zero layout shift.
- The price badge skeleton (`h-8 w-14`) only renders on middle rows (`idx > 0 && idx < length - 1`), matching the real UI where PAYG and custom tiers don't show a badge.
