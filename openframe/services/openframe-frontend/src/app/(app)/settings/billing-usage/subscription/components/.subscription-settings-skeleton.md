Loading state skeleton component for the Subscription Settings page, rendering placeholder UI while subscription data is being fetched.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `SubscriptionSettingsSkeleton` | Component | Root skeleton layout matching the full subscription settings page structure |
| `EnableCheckboxSkeleton` | Internal Component | Placeholder for the enable/disable subscription checkbox row |
| `ProductCardSkeleton` | Internal Component | Placeholder for each product card including title, description, tab selector, and package radio rows |

`RADIO_ROW_KEYS` defines the five package tier placeholders (`payg`, `tier-1`, `tier-2`, `tier-3`, `custom`) rendered inside each product card.

## Usage Example

```typescript
import { SubscriptionSettingsSkeleton } from './subscription-settings-skeleton';

// Render while subscription data is loading
export default function SubscriptionSettingsPage() {
  const { data, isLoading } = useSubscriptionSettings();

  if (isLoading) return <SubscriptionSettingsSkeleton />;

  return <SubscriptionSettings data={data} />;
}
```

## Notes

- Uses `useSafeBack` to navigate back to `/settings/billing-usage` if no browser history entry exists.
- Price badge skeletons (`h-8 w-14`) are conditionally rendered — omitted for the first (`payg`) and last (`custom`) radio rows, mirroring the real UI where only mid-tier packages display pricing badges.
- Responsive layout uses `lg:grid-cols-2` for the two product cards and `lg:flex-row` for the footer action row, consistent with the actual settings page.
