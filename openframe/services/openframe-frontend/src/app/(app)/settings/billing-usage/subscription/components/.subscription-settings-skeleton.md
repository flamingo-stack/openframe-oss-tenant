Loading state skeleton component for the Subscription Settings page, rendering placeholder UI while billing/subscription data is being fetched.

## Key Components

**`SubscriptionSettingsSkeleton`** *(exported)*
Main skeleton layout that mirrors the real Subscription Settings page structure — includes a checkbox toggle area, two product cards side-by-side, and a bottom action bar with a save button.

**`EnableCheckboxSkeleton`** *(internal)*
Placeholder for the enable/disable subscription checkbox row, with icon and two lines of label text.

**`ProductCardSkeleton`** *(internal)*
Placeholder for a billing product card, rendering skeletons for title, description, billing period tab selector, and a list of 5 radio-row pricing tiers (`payg`, `tier-1`, `tier-2`, `tier-3`, `custom`). Price badges are shown only on middle tiers (indices 1–3).

## Usage Example

```typescript
import { SubscriptionSettingsSkeleton } from './subscription-settings-skeleton';

// Use as a Suspense fallback or conditional loading state
export default function SubscriptionSettingsPage() {
  if (isLoading) {
    return <SubscriptionSettingsSkeleton />;
  }
  return <SubscriptionSettings />;
}
```

## Notes

- Uses `useSafeBack` to ensure the back button navigates to `/settings/billing-usage` without breaking navigation history.
- Skeleton dimensions are intentionally matched to the real content layout to minimize cumulative layout shift (CLS).
- Responsive grid collapses to single-column on mobile (`grid-cols-1 lg:grid-cols-2`).
