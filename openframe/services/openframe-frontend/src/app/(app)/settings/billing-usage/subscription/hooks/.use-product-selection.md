Manages product subscription selection state, handling billing period changes, package tier selection, custom quantity input, and real-time update diffing for subscription checkout flows.

## Key Components

### `useProductSelection(args)`

Primary hook that encapsulates all selection state and derived values for a subscription product card.

**Arguments:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `product` | `ProductData` | Relay fragment data for the product |
| `subscriptionProduct` | `SubscriptionProductData \| null` | Existing subscription state, if any |
| `onUpdatesChange` | `(updates: ProductUpdates) => void` | Callback fired whenever selection changes |

**Returns:**

| Field | Type | Description |
|-------|------|-------------|
| `selection` | `SelectionState` | Current selection state |
| `billingPeriodItems` | `{ id, label }[]` | Deduplicated billing period options |
| `allTiers` / `tiers` | arrays | Full and secondary price tier lists |
| `baselineUnitPrice` | `number \| null` | First tier or PAYG unit price |
| `unitSize` | `number` | Products per billable unit (e.g. `1` for devices, `100_000` for AI tokens) |
| `months` | `1 \| 12` | Multiplier based on billing period |
| `periodSuffix` | `string` | `/month` or `/year` display label |
| `setBillingPeriod` | `fn` | Updates period and resets package to topmost valid option |
| `setSelectedPackage` | `fn` | Selects a tier, PAYG, or custom package |
| `setCustomQuantity` | `fn` | Parses and validates a raw string input for custom quantity |

## Usage Example

```typescript
const {
  selection,
  billingPeriodItems,
  tiers,
  unitSize,
  setBillingPeriod,
  setSelectedPackage,
  setCustomQuantity,
} = useProductSelection({
  product,
  subscriptionProduct,
  onUpdatesChange: (updates) => {
    if (updates.valid) {
      applyCheckout(updates.checkout);
    }
  },
});
```

## Notes

- Selection resets automatically when `product` or `subscriptionProduct` props change via `useEffect`.
- `onUpdatesChange` is captured in a ref to avoid stale closure issues while still firing on every selection change.
- Custom quantity is validated as a positive integer that is a whole multiple of `unitSize`.
