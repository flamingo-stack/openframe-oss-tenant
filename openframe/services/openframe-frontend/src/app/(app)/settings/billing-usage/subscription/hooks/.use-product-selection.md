Manages product selection state for subscription cards, handling billing period changes, package tier selection, and custom quantity inputs while computing derived values and propagating validated updates to the parent.

## Key Components

**`useProductSelection(args)`**
Main hook that accepts:
- `product` — GraphQL fragment data describing available packages, tiers, and billing options
- `subscriptionProduct` — current active subscription state (or `null` for new subscriptions)
- `onUpdatesChange` — callback fired whenever selection changes, receiving `PackageUpdates`, checkout payload, and a validity flag

**Returned values & setters**

| Key | Description |
|---|---|
| `selection` | Current selection state (billing period, package ID, custom quantity) |
| `billingPeriodItems` | Deduplicated list of `{ id, label }` billing period options |
| `allTiers` / `tiers` | Full price tier list and tiers excluding the baseline |
| `baselineUnitPrice` | Unit price for tier 0 or PAYG fallback |
| `unitSize` | Products per billable unit (e.g. `1` for devices, `100000` for AI tokens) |
| `months` / `periodSuffix` | Display helpers derived from billing period |
| `setBillingPeriod` | Resets package selection to topmost available for the new period |
| `setSelectedPackage` | Toggles PAYG flag and clears/restores custom quantity |
| `setCustomQuantity` | Parses integer input, nullifies invalid values |

## Usage Example

```typescript
const {
  selection,
  billingPeriodItems,
  tiers,
  baselineUnitPrice,
  unitSize,
  periodSuffix,
  setBillingPeriod,
  setSelectedPackage,
  setCustomQuantity,
} = useProductSelection({
  product,
  subscriptionProduct,
  onUpdatesChange: (updates) => {
    if (updates.valid) applyUpdates(updates.packageUpdates);
  },
});
```

> **Validation note:** Custom quantity selections are only marked `valid` when the entered value is a positive integer that is an exact multiple of `unitSize`.
