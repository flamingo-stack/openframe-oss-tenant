Manages product selection state for subscription cards, handling billing period switching, package tier selection, custom quantities, and change diffing against the current subscription.

## Key Components

**`useProductSelection(args)`** — Main hook accepting:
- `product` — GraphQL product fragment data including package options, tiers, and unit size
- `subscriptionProduct` — Current active subscription data (or `null` for new subscriptions)
- `onUpdatesChange` — Callback fired whenever selection state produces a diff against the existing subscription

**Returns:**

| Field | Description |
|---|---|
| `selection` | Current selection state (billing period, package ID, custom quantity) |
| `billingPeriodItems` | Deduplicated list of available billing periods (`MONTHLY` / `YEARLY`) |
| `allTiers` / `tiers` | Full tier list and sliced tiers (excluding baseline) |
| `baselineUnitPrice` | Unit price of the first tier or PAYG fallback |
| `unitSize` | Products per billable unit (e.g. `1` for devices, `100_000` for AI tokens) |
| `months` / `periodSuffix` | Display helpers based on billing period |
| `setBillingPeriod` | Switches period and resets package to topmost available option |
| `setSelectedPackage` | Selects a tier package, PAYG, or custom option |
| `setCustomQuantity` | Parses and validates a freeform quantity string |

## Usage Example

```typescript
const {
  selection,
  billingPeriodItems,
  tiers,
  baselineUnitPrice,
  unitSize,
  periodSuffix,
  setBillingPeriod,
  setSelectedPackage,
  setCustomQuantity,
} = useProductSelection({
  product,
  subscriptionProduct,
  onUpdatesChange: (updates) => {
    if (updates.valid) {
      applyPendingChanges(updates.packageUpdates);
    }
  },
});
```

> **Note:** `customQuantity` must be a positive multiple of `unitSize`. The `valid` flag in `onUpdatesChange` is `false` when a custom quantity violates this constraint.
