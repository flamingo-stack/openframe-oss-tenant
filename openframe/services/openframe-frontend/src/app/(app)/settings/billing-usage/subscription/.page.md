Route-level page component for the Subscription Settings section, guarded by a feature flag and wrapped in a `Suspense` boundary.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `SubscriptionSettingsPage` | Default export | Page component that gates access and renders the subscription settings view |
| `dynamic` | Named export | Forces Next.js dynamic rendering (`'force-dynamic'`) |

## Usage Example

```typescript
// Automatically rendered by Next.js App Router
// Accessible at: /settings/subscription (or equivalent route)

// Feature flag check — returns 404 if disabled:
if (!featureFlags.subscription.enabled()) {
  notFound(); // Redirects to 404
}

// When enabled, renders:
<Suspense fallback={<SubscriptionSettingsSkeleton />}>
  <SubscriptionSettingsView />
</Suspense>
```

## Behavior

- **Feature flag guard** — calls `featureFlags.subscription.enabled()` on render; returns a 404 via `notFound()` if the subscription feature is disabled, preventing access to the route entirely.
- **Suspense boundary** — wraps `SubscriptionSettingsView` with `SubscriptionSettingsSkeleton` as the loading fallback, enabling async data fetching inside the view without blocking the page render.
- **Force dynamic** — the `dynamic = 'force-dynamic'` export opts this route out of static generation, ensuring server-side evaluation on every request (required for runtime feature flag checks).
