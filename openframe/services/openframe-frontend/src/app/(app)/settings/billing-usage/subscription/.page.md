Subscription settings page component that conditionally renders based on a feature flag, returning a 404 if subscriptions are disabled.

## Key Components

- **`SubscriptionSettingsPage`** — Default export; checks the `subscription` feature flag and either calls `notFound()` or renders the settings view wrapped in a `Suspense` boundary
- **`featureFlags.subscription.enabled()`** — Guards the route; prevents access when the subscription feature is toggled off
- **`SubscriptionSettingsSkeleton`** — Loading fallback rendered during async data resolution
- **`SubscriptionSettingsView`** — The actual settings UI rendered inside `Suspense`
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time

## Usage Example

```typescript
// Accessed via its Next.js route (e.g. /settings/subscription)
// No direct invocation needed — Next.js handles rendering automatically.

// To enable the page, ensure the feature flag is active:
// lib/feature-flags.ts
export const featureFlags = {
  subscription: {
    enabled: () => process.env.NEXT_PUBLIC_SUBSCRIPTION_ENABLED === 'true',
  },
};
```

> If `featureFlags.subscription.enabled()` returns `false`, the route resolves to a **404** — no settings UI is rendered or accessible.
