Subscription settings page component that renders the subscription management UI, gating access behind a feature flag and displaying a skeleton loader during async data fetching.

## Key Components

- **`SubscriptionSettingsPage`** — Default export; the main page component that checks the `subscription` feature flag and conditionally renders the settings view or triggers a 404
- **`featureFlags.subscription.enabled()`** — Guards the page; if the subscription feature is disabled, redirects to a not-found response
- **`SubscriptionSettingsView`** — The main content component loaded within a `Suspense` boundary
- **`SubscriptionSettingsSkeleton`** — Fallback UI shown while `SubscriptionSettingsView` resolves

## Usage Example

```typescript
// Accessed via Next.js routing (e.g. /settings/subscription)
// No manual instantiation needed — Next.js handles rendering

// Feature flag check (internal behavior):
if (!featureFlags.subscription.enabled()) {
  notFound(); // Returns HTTP 404 if subscription feature is off
}

// Renders with Suspense fallback while view loads:
<Suspense fallback={<SubscriptionSettingsSkeleton />}>
  <SubscriptionSettingsView />
</Suspense>
```

> **Note:** `dynamic = 'force-dynamic'` disables static generation for this page, ensuring it is always server-rendered at request time. This is required for accurate feature flag evaluation per request.
