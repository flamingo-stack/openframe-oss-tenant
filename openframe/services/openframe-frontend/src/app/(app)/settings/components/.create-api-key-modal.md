Modal component for creating or editing API keys, supporting both create and edit modes with name, description, and optional expiration date fields.

## Key Components

### `CreateApiKeyModalProps`
Interface defining modal configuration:
- `isOpen` / `onClose` — visibility control
- `create` — async function to create a new API key, returns `{ apiKey, fullKey }`
- `onCreated` — callback receiving `{ apiKeyId, fullKey }` after creation
- `mode` — `'create'` (default) or `'edit'`
- `initial` — pre-populated values for edit mode (`id`, `name`, `description`, `expiresAt`)
- `update` — async function to persist edits by key ID
- `onUpdated` — callback receiving `{ id }` after a successful update

### `CreateApiKeyModal`
Client component rendering a `SimpleModal` with three fields:
- **API Key Name** — required; submit is disabled until non-empty
- **Description** — optional textarea
- **Expiration Date** — optional `datetime-local` input, converted to ISO 8601 on submit

State resets on close; in edit mode, fields are pre-filled from `initial` on open.

## Usage Example

```typescript
// Create mode
<CreateApiKeyModal
  isOpen={isOpen}
  onClose={() => setIsOpen(false)}
  create={async (data) => apiClient.createApiKey(data)}
  onCreated={({ apiKeyId, fullKey }) => {
    setNewKey(fullKey); // show the key once
  }}
/>

// Edit mode
<CreateApiKeyModal
  isOpen={isOpen}
  onClose={() => setIsOpen(false)}
  mode="edit"
  initial={{ id: 'key_123', name: 'My Key', expiresAt: '2025-12-31T00:00:00Z' }}
  update={async (id, data) => apiClient.updateApiKey(id, data)}
  onUpdated={() => refetch()}
/>
```

> **Note:** The `fullKey` value is only available at creation time. Display it immediately via `onCreated` — it cannot be retrieved again.
