Modal component for creating and editing API keys, supporting both create and edit modes with name, description, and optional expiration date fields.

## Key Components

### `CreateApiKeyModal`
Main exported component that renders a `SimpleModal` with a controlled form.

**Props (`CreateApiKeyModalProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls modal visibility |
| `onClose` | `() => void` | Called when modal is dismissed |
| `mode` | `'create' \| 'edit'` | Defaults to `'create'` |
| `create` | `function` | Async handler for key creation |
| `onCreated` | `function` | Callback with `apiKeyId` and `fullKey` after creation |
| `initial` | `object` | Pre-populates fields in edit mode |
| `update` | `function` | Async handler for key update |
| `onUpdated` | `function` | Callback with `id` after update |

**Internal state:** `name`, `description`, `expiresAt`, `isSubmitting`

## Usage Example

```typescript
// Create mode
<CreateApiKeyModal
  isOpen={showModal}
  onClose={() => setShowModal(false)}
  create={async (data) => await apiClient.createKey(data)}
  onCreated={({ apiKeyId, fullKey }) => {
    // Show the full key to the user once
    setRevealedKey(fullKey);
  }}
/>

// Edit mode
<CreateApiKeyModal
  isOpen={showModal}
  onClose={() => setShowModal(false)}
  mode="edit"
  initial={{ id: key.id, name: key.name, description: key.description, expiresAt: key.expiresAt }}
  update={async (id, data) => await apiClient.updateKey(id, data)}
  onUpdated={({ id }) => refetch()}
/>
```

**Behavior notes:**
- Form resets on close; pre-fills from `initial` when opened in edit mode
- Submit is disabled until `name` has a non-empty value
- `expiresAt` is stored as ISO 8601 UTC; `datetime-local` input is normalized on submit
- Success and error states surface via `useToast`
