Modal component for creating or editing API keys, supporting both create and edit modes with name, description, and optional expiration date fields.

## Key Components

**`CreateApiKeyModal`** — Main exported component

**Props (`CreateApiKeyModalProps`):**
| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls modal visibility |
| `onClose` | `() => void` | Close handler |
| `mode` | `'create' \| 'edit'` | Defaults to `'create'` |
| `create` | `function` | Async function to create a new API key |
| `onCreated` | `function` | Callback fired after successful creation with `apiKeyId` and `fullKey` |
| `initial` | `object` | Pre-populated values for edit mode |
| `update` | `function` | Async function to update an existing API key |
| `onUpdated` | `function` | Callback fired after successful update |

**Internal state:** `name`, `description`, `expiresAt`, `isSubmitting`

## Usage Example

```typescript
// Create mode
<CreateApiKeyModal
  isOpen={isOpen}
  onClose={() => setIsOpen(false)}
  create={async (data) => await apiClient.createKey(data)}
  onCreated={({ apiKeyId, fullKey }) => {
    console.log('New key:', fullKey);
  }}
/>

// Edit mode
<CreateApiKeyModal
  isOpen={isOpen}
  onClose={() => setIsOpen(false)}
  mode="edit"
  initial={{ id: 'key_123', name: 'My Key', description: 'For CI', expiresAt: null }}
  update={async (id, data) => await apiClient.updateKey(id, data)}
  onUpdated={({ id }) => refetch()}
/>
```

**Behavior notes:**
- Form resets on close; pre-fills from `initial` when opened in edit mode
- Submit is disabled until `name` has a non-empty value
- Expiration date is stored as ISO 8601 UTC; `null` means no expiration
- Toast notifications are shown on both success and error
