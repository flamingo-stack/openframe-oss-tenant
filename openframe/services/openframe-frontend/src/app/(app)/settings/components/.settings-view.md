Renders the main Settings page view, managing URL-synchronized tab navigation across all settings sections.

## Key Components

- **`SettingsView`** — Root settings page component that reads/writes the active tab from the URL `?tab=` query parameter, enabling shareable links and browser back/forward navigation
- **`TabId`** — Union type defining valid tab identifiers: `ai-settings`, `architecture`, `company-and-users`, `api-keys`, `sso-configuration`, `profile`
- **`DEFAULT_TAB`** — Fallback tab (`ai-settings`) used when no valid `?tab=` param is present
- **`handleTabChange`** — Updates both local state and the URL via `router.replace` without adding a history entry

## Usage Example

```typescript
// Render within a Next.js App Router page
import { SettingsView } from './settings-view';

export default function SettingsPage() {
  return <SettingsView />;
}

// Navigate to a specific tab via URL:
// /settings?tab=api-keys
// /settings?tab=profile
```

## Behavior Notes

- **URL sync**: On mount, reads `?tab=` from `searchParams`; falls back to `DEFAULT_TAB` if the value is missing or invalid
- **Back/forward support**: A `useEffect` watches `searchParams` changes and updates `activeTab` state to match, keeping the UI in sync with browser navigation
- **Tab validation**: Uses a `Set` derived from `getSettingsTabs()` to guard against arbitrary query param values
