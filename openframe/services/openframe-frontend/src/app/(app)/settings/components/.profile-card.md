A read-only profile card component that displays the authenticated user's avatar, name, roles, email, and email verification status with edit and verify action callbacks.

## Key Components

- **`ProfileCard`** — Main exported component that renders the user profile summary card
- **`ProfileCardProps`** — Interface with two callbacks: `onEditProfile` and `onVerifyEmail`
- **Loading state** — Renders a `Skeleton` placeholder while profile data is being fetched
- **Error state** — Renders a `PageError` when no user data is available
- **Email verification warning** — Shows a clickable `AlertCircleIcon` badge when `user.emailVerified === false`
- **Role tags** — Iterates `user.roles` to render `Tag` components for each assigned role

## Notes

- Reads user state directly from `useAuthStore` — no props needed for user data
- `displayName` falls back to `user.email` if both `firstName` and `lastName` are absent
- Avatar URL is resolved via `getFullImageUrl` to support relative image paths
