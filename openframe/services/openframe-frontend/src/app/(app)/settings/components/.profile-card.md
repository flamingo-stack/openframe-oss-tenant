A read-only profile summary card that displays the authenticated user's avatar, name, roles, email, and email verification status with quick-action buttons.

## Key Components

- **`ProfileCard`** — Main exported component that renders the user profile card
- **`ProfileCardProps`** — Interface with two callbacks:
  - `onEditProfile` — Triggered when the "Edit Profile" button is clicked
  - `onVerifyEmail` — Triggered when the "Not verified" warning badge is clicked
- **Loading state** — Renders a `Skeleton` placeholder while profile data is being fetched
- **Error state** — Renders a `PageError` when no user data is available
- **Email verification warning** — Conditionally renders an `AlertCircleIcon` button when `user.emailVerified === false`

## Usage Example

```typescript
import { ProfileCard } from '@/components/profile-card';

function ProfilePage() {
  const handleEditProfile = () => {
    // open edit profile modal/drawer
  };

  const handleVerifyEmail = () => {
    // trigger resend verification email
  };

  return (
    <ProfileCard
      onEditProfile={handleEditProfile}
      onVerifyEmail={handleVerifyEmail}
    />
  );
}
```

## Notes

- Reads user state directly from `useAuthStore` — no props required for user data
- `displayName` falls back through `firstName + lastName` → `email` → `'—'`
- Avatar URL is resolved via `getFullImageUrl` to handle relative image paths
- User roles are rendered as `Tag` components inline with the display name
