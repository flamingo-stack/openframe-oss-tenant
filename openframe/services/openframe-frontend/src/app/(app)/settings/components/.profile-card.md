Displays the authenticated user's profile summary card, including avatar, display name, roles, email, and email verification status, with actions to edit the profile or trigger email verification.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `ProfileCard` | `React.FC` | Main profile card component rendered in profile/account pages |
| `ProfileCardProps` | `interface` | Props contract with `onEditProfile` and `onVerifyEmail` callbacks |

## Key Behaviors

- **Loading state** — renders a `Skeleton` placeholder while `isLoadingProfile` is `true` and no user data exists
- **Error state** — renders a `PageError` if user data is unavailable after loading
- **Display name** — derived from `firstName` + `lastName`; falls back to `email`, then `—`
- **Role tags** — maps `user.roles[]` to `Tag` components with `outline` variant
- **Unverified email** — shows a clickable warning badge when `emailVerified === false`, calling `onVerifyEmail` on click

  const handleEditProfile = () => {
    // open edit profile modal/drawer

## Dependencies

- **`useAuthStore`** — reads `user` and `isLoadingProfile` from global auth state
- **`getFullImageUrl`** — resolves relative image paths to absolute URLs for the avatar
- **`SquareAvatar`** — renders the user's profile image with a text fallback
