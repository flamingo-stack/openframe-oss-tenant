A modal component for bulk-inviting users by email with role assignment, built on top of `SimpleModal`.

## Key Components

- **`AddUsersModal`** — Main exported component that renders a multi-row invite form inside a modal dialog
- **`InviteRow`** — Internal type representing a single invite entry `{ email: string; role: string }`
- **`AddUsersModalProps`** — Interface defining `isOpen`, `onClose`, `onInvited`, and `invite` callback props

### Internal State & Logic

| Item | Purpose |
|---|---|
| `rows` | Dynamic list of email/role pairs |
| `canSubmit` | Validates at least one row has a valid email |
| `emailRegex` | RFC-style email validation pattern |
| `roleOptions` | Static `Admin` / `Viewer` options |
| `handleSubmit` | Filters valid rows, calls `invite()`, shows toast feedback |

## Usage Example

```typescript
import { AddUsersModal } from '@/app/components/add-users-modal';

function TeamPage() {
  const [open, setOpen] = useState(false);

  const handleInvite = async (rows: { email: string; role: string }[]) => {
    await api.users.invite(rows);
  };

  return (
    <AddUsersModal
      isOpen={open}
      onClose={() => setOpen(false)}
      onInvited={async () => await refetchUsers()}
      invite={handleInvite}
    />
  );
}
```

## Behavior Notes

- Resets to a single blank row on close via `useEffect`
- Invalid emails show inline `invalid` styling on the `Input`
- The trash icon only appears when more than one row exists
- Submit filters out any rows with invalid/empty emails before calling `invite()`
- Success and error states are communicated via the `useToast` hook
