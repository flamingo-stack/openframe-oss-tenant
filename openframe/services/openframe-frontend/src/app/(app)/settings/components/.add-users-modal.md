A modal dialog component for inviting multiple users to the system by email, supporting dynamic row management and role assignment.

## Key Components

**`AddUsersModal`** — Main exported component wrapping `SimpleModal` with the following props:

| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls modal visibility |
| `onClose` | `() => void` | Callback when modal is dismissed |
| `onInvited` | `() => Promise<void> \| void` | Optional callback after successful invite |
| `invite` | `(rows: InviteRow[]) => Promise<void>` | Async function to send invitations |

**`InviteRow`** — Internal type representing a single invite entry: `{ email: string; role: string }`.

**Key internal behaviors:**
- `rows` state — dynamic list of `InviteRow` entries, initialized with one `ADMIN` row
- `canSubmit` — memoized validation requiring at least one valid email
- `handleSubmit` — filters valid rows, calls `invite`, shows success/error toasts, then resets state
- Auto-resets form state when `isOpen` changes to `false`

## Usage Example

```typescript
import { AddUsersModal } from '@/app/components/add-users-modal';

function MyPage() {
  const [open, setOpen] = useState(false);

  const handleInvite = async (rows: { email: string; role: string }[]) => {
    await api.sendInvites(rows);
  };

  return (
    <AddUsersModal
      isOpen={open}
      onClose={() => setOpen(false)}
      onInvited={async () => await refetchUsers()}
      invite={handleInvite}
    />
  );
}
```

> **Note:** Currently only the `ADMIN` role is available in `roleOptions`. Extend the `roleOptions` array to support additional roles.
