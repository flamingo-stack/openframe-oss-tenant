A modal dialog component for inviting multiple users to the system by entering their email addresses and assigning roles, then dispatching bulk invite requests.

## Key Components

- **`AddUsersModal`** — Main exported component that renders a `SimpleModal` with a dynamic list of email/role input rows
- **`InviteRow`** — Internal type representing a single invite entry `{ email: string; role: string }`
- **`AddUsersModalProps`** — Interface defining `isOpen`, `onClose`, `onInvited` callback, and `invite` async handler

### State & Logic

| Hook/Variable | Purpose |
|---|---|
| `rows` | Array of `InviteRow` entries; starts with one empty Admin row |
| `canSubmit` | `true` when at least one row has a valid email |
| `emailRegex` | Memoized RFC-style email validation pattern |
| `roleOptions` | Currently only `ADMIN`; memoized for extensibility |

- Resets state on modal close via `useEffect`
- `handleSubmit` filters invalid rows before calling `invite()`, shows success/error toasts

## Usage Example

```typescript
import { AddUsersModal } from './add-users-modal';

function UsersPage() {
  const [open, setOpen] = useState(false);

  const handleInvite = async (rows: { email: string; role: string }[]) => {
    await fetch('/api/users/invite', {
      method: 'POST',
      body: JSON.stringify(rows),
    });
  };

  return (
    <AddUsersModal
      isOpen={open}
      onClose={() => setOpen(false)}
      onInvited={async () => refetchUsers()}
      invite={handleInvite}
    />
  );
}
```

> **Note:** The `invite` prop owns the API call logic — this component handles only UI state, validation, and user feedback via toasts.
