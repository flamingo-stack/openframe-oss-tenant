A reusable navigation card component for settings pages, rendering a styled link with an icon, title, description, and a chevron indicator.

## Key Components

### `SettingsNavCardProps`
| Prop | Type | Description |
|------|------|-------------|
| `href` | `string` | Navigation target URL |
| `icon` | `ReactNode` | Icon element displayed on the left |
| `title` | `string` | Primary card label |
| `description` | `string` | Secondary descriptive text |

### `SettingsNavCard`
A client-side Next.js `Link`-based card that renders a navigable settings entry using ODS design tokens for consistent theming.

## Usage Example

```typescript
import { SettingsNavCard } from '@/components/settings-nav-card';
import { Bell } from 'lucide-react';

export function SettingsMenu() {
  return (
    <SettingsNavCard
      href="/settings/notifications"
      icon={<Bell className="size-5" />}
      title="Notifications"
      description="Manage your alert preferences"
    />
  );
}
```

## Layout Structure

```text
[ Icon Box ] [ Title / Description ] [ ChevronRight ]
```

- **Icon box** — shrink-0, bordered, uses `--spacing-system-sf` padding
- **Text block** — flex-1, truncation-safe (`min-w-0`)
- **Chevron** — shrink-0, mirrored card styling, always right-aligned

> ODS tokens (`ods-card`, `ods-border`, `ods-text-primary/secondary`) ensure this component automatically adapts to Flamingo's dark-mode theme without additional styling.
