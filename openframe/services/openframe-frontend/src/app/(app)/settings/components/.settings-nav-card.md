A reusable navigation card component for settings pages that renders a styled, clickable link with an icon, title, description, and a chevron indicator.

## Key Components

### `SettingsNavCardProps`
| Prop | Type | Description |
|------|------|-------------|
| `href` | `string` | Navigation target URL |
| `icon` | `ReactNode` | Icon element displayed on the left |
| `title` | `string` | Primary card label |
| `description` | `string` | Secondary descriptive text |

### `SettingsNavCard`
A client component that wraps Next.js `Link` to render a card-style navigation item, following ODS (OpenFrame Design System) styling tokens for borders, spacing, and typography.

## Usage Example

```typescript
import { SettingsNavCard } from '@/components/settings-nav-card';
import { Shield } from 'lucide-react';

export function SettingsMenu() {
  return (
    <div className="flex flex-col gap-4">
      <SettingsNavCard
        href="/settings/security"
        icon={<Shield className="size-5" />}
        title="Security"
        description="Manage passwords, 2FA, and session settings"
      />
    </div>
  );
}
```

## Notes

- Marked as `'use client'` — must be rendered in a client boundary
- Uses ODS CSS custom properties (`--spacing-system-m`, `--spacing-system-s`, `--spacing-system-sf`) for consistent spacing
- Chevron arrow (`ChevronRight`) is always rendered and non-configurable
- Icon container uses `shrink-0` to prevent compression on long text content
