A clickable navigation card component for settings pages, rendering an icon, title, description, and a chevron arrow as a Next.js `Link`.

## Key Components

**`SettingsNavCard`** — Default export functional component

**`SettingsNavCardProps`** interface:
| Prop | Type | Description |
|------|------|-------------|
| `href` | `string` | Navigation target URL |
| `icon` | `ReactNode` | Icon element displayed on the left |
| `title` | `string` | Primary card label |
| `description` | `string` | Secondary descriptive text |

## Usage Example

```typescript
import { SettingsNavCard } from './settings-nav-card';
import { Bell } from 'lucide-react';

export function SettingsMenu() {
  return (
    <SettingsNavCard
      href="/settings/notifications"
      icon={<Bell className="size-5" />}
      title="Notifications"
      description="Manage your alert preferences"
    />
  );
}
```

## Notes

- Marked `'use client'` — requires a client-side rendering context (Next.js App Router)
- Uses ODS design tokens (`ods-card`, `ods-border`, `ods-text-primary`, etc.) and CSS spacing variables for consistent theming
- The chevron (`ChevronRight`) is always rendered on the trailing edge, indicating a drill-down navigation pattern
- Icon is rendered in a bordered square badge; text truncates via `min-w-0` + `flex-1` to prevent overflow
