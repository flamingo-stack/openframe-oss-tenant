A client-side modal component that prompts users to confirm regeneration of an API key, warning that the current key will be immediately invalidated.

## Key Components

- **`RegenerateApiKeyModal`** — Main export; wraps `ConfirmDialog` with regeneration-specific copy and async loading state management.
- **`RegenerateApiKeyModalProps`** — Interface defining:
  - `isOpen` — controls modal visibility
  - `onClose` — callback fired when the dialog is dismissed
  - `apiKeyName` — optional display name of the key being regenerated
  - `onConfirm` — async callback that performs the actual regeneration

## Usage Example

```typescript
import { RegenerateApiKeyModal } from './regenerate-api-key-modal';

function ApiKeySettings() {
  const [isOpen, setIsOpen] = useState(false);

  const handleRegenerate = async () => {
    await fetch('/api/keys/my-key/regenerate', { method: 'POST' });
  };

  return (
    <RegenerateApiKeyModal
      isOpen={isOpen}
      onClose={() => setIsOpen(false)}
      apiKeyName="Production Key"
      onConfirm={handleRegenerate}
    />
  );
}
```

## Behavior Notes

- Loading state (`isPending`) is set to `true` on confirm and reset once `onConfirm` resolves.
- Loading is also reset when the modal closes via the `useEffect` on `isOpen`, preventing stale state if the dialog is dismissed mid-request.
- Renders with a `warning` variant, highlighting the key name in `ods-warning` color to reinforce the destructive nature of the action.
