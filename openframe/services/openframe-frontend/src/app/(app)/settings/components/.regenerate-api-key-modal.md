A client-side modal component for confirming API key regeneration, wrapping the shared `ConfirmDialog` with regeneration-specific messaging and async loading state.

## Key Components

**`RegenerateApiKeyModal`** — Named export. Renders a warning-styled confirmation dialog that alerts the user the current key will be invalidated immediately upon confirmation.

**`RegenerateApiKeyModalProps`**

| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls dialog visibility |
| `onClose` | `() => void` | Called when dialog is dismissed |
| `apiKeyName` | `string?` | Optional display name for the key being regenerated |
| `onConfirm` | `() => Promise<void>` | Async handler executed on confirmation |

**Internal state:**
- `loading` — tracks async confirmation in-flight; resets automatically when `isOpen` becomes `false`

## Usage Example

```typescript
import { RegenerateApiKeyModal } from './regenerate-api-key-modal';

function ApiKeySettings() {
  const [modalOpen, setModalOpen] = useState(false);

  const handleRegenerate = async () => {
    await regenerateKey(keyId);
    setModalOpen(false);
  };

  return (
    <>
      <button onClick={() => setModalOpen(true)}>Regenerate</button>
      <RegenerateApiKeyModal
        isOpen={modalOpen}
        onClose={() => setModalOpen(false)}
        apiKeyName="Production API Key"
        onConfirm={handleRegenerate}
      />
    </>
  );
}
```

> **Note:** The `onConfirm` callback is responsible for closing the modal after a successful regeneration. The component only manages its own loading state.
