Main settings hub component that renders the settings landing page, including a user profile card, navigation grid to settings sub-sections, and modals for profile editing and email verification.

## Key Components

- **`SettingsHub`** — Primary exported component that orchestrates the settings page layout
- **`SETTINGS_NAV_ITEMS`** — Static config array defining navigation cards (Billing, AI Settings, Architecture, Employees, API Keys, SSO)
- **`updateProfile`** — Async handler that PUTs updated user name to `api/users/:id` and syncs auth store
- **`handleResendVerification`** — Sends a verification email via `authApiClient` and provides toast feedback

## Usage Example

```typescript
// Rendered as a route-level page component
import { SettingsHub } from './settings-hub';

export default function SettingsPage() {
  return <SettingsHub />;
}
```

## Behavior Notes

- On mount, calls `fetchFullProfile()` to ensure the auth store has the latest user data
- Billing & Usage nav item is conditionally rendered based on `featureFlags.subscription.enabled()`
- Profile updates optimistically sync `firstName`/`lastName` into the auth store via `updateUser`
- All API errors are routed through `handleApiError` for consistent toast messaging
- Modals (`EditProfileModal`, `EmailVerificationModal`) are only mounted when `user` is non-null
