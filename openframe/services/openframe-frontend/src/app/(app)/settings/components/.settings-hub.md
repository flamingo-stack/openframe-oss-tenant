Central settings page component that renders the user profile card, a grid of navigation cards linking to settings sub-sections, and modals for editing profile details and verifying email.

## Key Components

- **`SettingsHub`** — Main exported component. Orchestrates profile data fetching, profile update mutation, email verification resend, and conditional rendering of modals.
- **`SETTINGS_NAV_ITEMS`** — Static array defining the six settings navigation destinations: Billing & Usage, AI Settings & Guardrails, Architecture Overview, Employees & Permissions, API Keys Management, and SSO Configuration.
- **Feature flag gate** — Filters out the `/settings/billing-usage` card when `featureFlags.subscription.enabled()` returns `false`.

## Key Behaviors

| Behavior | Details |
|---|---|
| Profile update | `PUT api/users/:id` via `apiClient`, updates auth store on success |
| Email verification | Calls `authApiClient.resendVerificationEmail`, shows success toast |
| Profile hydration | Calls `fetchFullProfile()` on mount via `useEffect` |
| Modals | `EditProfileModal` and `EmailVerificationModal` only rendered when `user` is defined |

## Usage Example

```typescript
// Render as a Next.js page (app router)
import { SettingsHub } from '@/features/settings/settings-hub';

export default function SettingsPage() {
  return <SettingsHub />;
}
```

The component is self-contained — it reads auth state from `useAuthStore` and manages all async operations internally. No props are required.
