The main settings hub component that renders the user's settings dashboard, including a profile card, navigation grid to sub-settings pages, and modals for profile editing and email verification.

## Key Components

- **`SettingsHub`** — Primary exported component orchestrating the settings page layout
- **`SETTINGS_NAV_ITEMS`** — Static configuration array defining navigation cards (Billing & Usage, AI Settings, Architecture, Employees, API Keys, SSO), with Billing gated behind a feature flag
- **`updateProfile`** — Callback to `PUT api/users/:id` and sync auth store on success
- **`handleResendVerification`** — Sends a verification email via `authApiClient`

## Usage Example

```typescript
// Rendered as a route-level page component
import { SettingsHub } from './settings-hub';

export default function SettingsPage() {
  return <SettingsHub />;
}
```

## Behavior Notes

- On mount, calls `fetchFullProfile()` to hydrate the auth store with full user data
- The **Billing & Usage** nav card is conditionally rendered based on `featureFlags.subscription.enabled()`
- Profile updates patch first/last name only; avatar changes are handled separately via `onImageChange`
- All API errors are routed through `handleApiError` for consistent toast feedback
