Renders the API Keys management tab within the Settings section, providing a full CRUD interface for listing, creating, editing, regenerating, enabling/disabling, and viewing details of API keys.

## Key Components

- **`ApiKeysTab`** — Main page component that composes the data table and all modal dialogs for API key lifecycle management.
- **`columns`** — Memoized `ColumnDef<ApiKeyRecord>[]` defining table columns: Name/Description, Status (ACTIVE/INACTIVE tag), Key ID, Usage count, Created date, Expires date, and row Actions.
- **`useApiKeys`** — Hook providing `items`, `isLoading`, `error`, and CRUD operations (`createApiKey`, `updateApiKey`, `regenerateApiKey`, `setApiKeyEnabled`, `fetchApiKeys`).
- **Modal dialogs** — `CreateApiKeyModal` (shared for create/edit), `ApiKeyCreatedModal` (displays the full key once after creation/regeneration), `ApiKeyDetailsModal`, `RegenerateApiKeyModal`, `DisableApiKeyModal`.
- **`headerActions`** — Renders an "API Documentation" button (links to `/swagger-ui/index.html`) and a "Create API Key" button.

## Usage Example

```typescript
// Rendered as a tab inside the Settings page
import { ApiKeysTab } from './tabs/api-keys';

export function SettingsPage() {
  return (
    <Tabs>
      <Tab label="API Keys">
        <ApiKeysTab />
      </Tab>
    </Tabs>
  );
}
```

> **Note:** After key creation or regeneration, the full API key string is displayed once via `ApiKeyCreatedModal` and then discarded from state — it cannot be retrieved again.
