A reusable header component for settings sub-pages that renders a back-navigation arrow linking to `/settings` alongside a page title.

## Key Components

- **`SettingsSubPageHeader`** — Client component accepting a `title` prop, rendering a styled back button and `<h1>` heading.
- **`SettingsSubPageHeaderProps`** — Interface with a single required `title: string` field.

## Usage Example

```typescript
import { SettingsSubPageHeader } from '@/components/settings-sub-page-header';

export default function NotificationsSettingsPage() {
  return (
    <div>
      <SettingsSubPageHeader title="Notifications" />
      {/* page content */}
    </div>
  );
}
```

> The back button always navigates to `/settings`, so this component is intended for direct children of the settings root page only.
