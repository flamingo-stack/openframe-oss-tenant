A reusable header component for settings sub-pages that renders a back navigation button linking to `/settings` and a styled page title.

## Key Components

- **`SettingsSubPageHeader`** — Client component that accepts a `title` prop and renders a back arrow (`ArrowLeft`) linking to `/settings` alongside a monospace heading.

### Props

| Prop | Type | Description |
|------|------|-------------|
| `title` | `string` | The page title displayed as an `<h1>` heading |

## Usage Example

```typescript
import { SettingsSubPageHeader } from '@/components/settings-sub-page-header';

export default function BillingSettingsPage() {
  return (
    <div>
      <SettingsSubPageHeader title="Billing" />
      {/* page content */}
    </div>
  );
}
```

> **Note:** The back button always navigates to `/settings`. This component is marked `'use client'` due to its interactive link behavior within the Next.js App Router.
