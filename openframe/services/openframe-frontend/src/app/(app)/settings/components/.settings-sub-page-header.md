A reusable header component for settings sub-pages that renders a back navigation button linking to `/settings` and a styled page title.

## Key Components

- **`SettingsSubPageHeader`** — Named export; renders a back arrow (`ArrowLeft` from `lucide-react`) as a `Link` to `/settings` alongside a styled `<h1>` title.
- **`SettingsSubPageHeaderProps`** — Interface accepting a single `title: string` prop.

## Usage Example

```typescript
import { SettingsSubPageHeader } from '@/components/settings-sub-page-header';

export default function NotificationsSettingsPage() {
  return (
    <div>
      <SettingsSubPageHeader title="Notifications" />
      {/* page content */}
    </div>
  );
}
```
