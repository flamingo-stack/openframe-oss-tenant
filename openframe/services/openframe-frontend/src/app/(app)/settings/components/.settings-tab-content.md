Renders the content area for the Settings page by dynamically resolving and mounting the correct tab component based on the active tab selection.

## Key Components

- **`SettingsTabContent`** — Client component that accepts an `activeTab` string, resolves the matching component from `SETTINGS_TABS` via `getTabComponent`, and renders it. Displays a fallback "Tab Not Found" message if no matching tab is found.
- **`SettingsTabContentProps`** — Interface defining the `activeTab` prop (string identifier for the currently selected settings tab).

## Usage Example

```typescript
import { SettingsTabContent } from './settings-tab-content';

export function SettingsPage() {
  const [activeTab, setActiveTab] = useState('general');

  return (
    <div>
      {/* Tab navigation handled separately */}
      <SettingsTabContent activeTab={activeTab} />
    </div>
  );
}
```

## Behavior Notes

- Uses `getTabComponent` from `@flamingo-stack/openframe-frontend-core` to look up the tab component from the `SETTINGS_TABS` registry.
- All content is rendered inside a `min-h-[400px]` container to maintain consistent layout height.
- If `activeTab` does not match any registered tab key, a centered fallback UI is displayed rather than throwing an error.
