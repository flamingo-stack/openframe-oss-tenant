Renders the content area for the active settings tab by dynamically resolving and mounting the appropriate tab component.

## Key Components

- **`SettingsTabContent`** — Client component that accepts an `activeTab` string, looks up the matching component from `SETTINGS_TABS` via `getTabComponent`, and renders it inside a minimum-height container.
- **Fallback UI** — Displays a centered "Tab Not Found" message if the provided `activeTab` key does not match any registered tab.

## Usage Example

```typescript
import { SettingsTabContent } from './settings-tab-content';

// Render the content area for a given active tab key
<SettingsTabContent activeTab="general" />
```

## Behavior Notes

- Uses `getTabComponent` from `@flamingo-stack/openframe-frontend-core` to resolve tab components at runtime based on the `SETTINGS_TABS` registry.
- All tab content is wrapped in a `min-h-[400px]` container for layout consistency.
- The fallback state surfaces the unrecognized `activeTab` value in the error message to aid debugging.
