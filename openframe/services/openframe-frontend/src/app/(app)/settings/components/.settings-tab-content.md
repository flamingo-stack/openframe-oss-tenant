Renders the content area for the Settings page by dynamically resolving and displaying the active tab's component based on the provided tab key.

## Key Components

- **`SettingsTabContent`** — Main exported component that accepts an `activeTab` string and renders the corresponding settings tab component
- **`getTabComponent`** — Utility from `@flamingo-stack/openframe-frontend-core` used to resolve a tab component from the `SETTINGS_TABS` registry
- **`SETTINGS_TABS`** — Tab registry imported from local `./tabs` configuration
- **Fallback UI** — Displays a "Tab Not Found" message with the unrecognized tab key when no matching component is found

## Usage Example

```typescript
import { SettingsTabContent } from './settings-tab-content';

export default function SettingsPage() {
  const [activeTab, setActiveTab] = React.useState('general');

  return (
    <div>
      {/* Tab navigation handled separately */}
      <SettingsTabContent activeTab={activeTab} />
    </div>
  );
}
```

## Notes

- Requires a minimum height of `400px` in both the resolved tab and fallback states
- Relies on `SETTINGS_TABS` being properly populated with tab keys mapped to React components
- The fallback renders inline — no routing or redirects occur on an unrecognized `activeTab` value
