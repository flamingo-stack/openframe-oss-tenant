A modal dialog component that prompts users to resend an email verification link when their account email has not yet been verified.

## Key Components

**`EmailVerificationModal`** — A wrapper around `ConfirmDialog` that presents a confirmation prompt, highlighting the unverified email address and offering a resend action.

**`EmailVerificationModalProps`**

| Prop | Type | Description |
|------|------|-------------|
| `open` | `boolean` | Controls dialog visibility |
| `onOpenChange` | `(open: boolean) => void` | Callback to toggle open state |
| `userEmail` | `string` | The unverified email address to display |
| `onSubmit` | `() => Promise<void>` | Handler triggered on confirmation |
| `isSending` | `boolean` | Disables confirm button and shows pending label while sending |

## Usage Example

```typescript
const [open, setOpen] = useState(false);
const [isSending, setIsSending] = useState(false);

const handleResend = async () => {
  setIsSending(true);
  await resendVerificationEmail(user.email);
  setIsSending(false);
  setOpen(false);
};

<EmailVerificationModal
  open={open}
  onOpenChange={setOpen}
  userEmail={user.email}
  onSubmit={handleResend}
  isSending={isSending}
/>
```

> The unverified email address is rendered with the `text-ods-warning` token, ensuring it stands out visually in Flamingo's dark-mode ODS theme.
