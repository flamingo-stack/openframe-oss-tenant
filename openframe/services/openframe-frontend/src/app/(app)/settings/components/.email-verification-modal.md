A modal dialog component that prompts users to resend an email verification link when their account email has not yet been verified.

## Key Components

**`EmailVerificationModal`** — A wrapper around `ConfirmDialog` that presents a user-facing prompt to resend the verification email.

**`EmailVerificationModalProps`** — Interface defining the component's props:

| Prop | Type | Description |
|------|------|-------------|
| `open` | `boolean` | Controls dialog visibility |
| `onOpenChange` | `(open: boolean) => void` | Callback to toggle dialog state |
| `userEmail` | `string` | Displays the unverified email address |
| `onSubmit` | `() => Promise<void>` | Handler triggered on confirmation |
| `isSending` | `boolean` | Disables the confirm button during submission |

## Usage Example

```typescript
import { EmailVerificationModal } from './email-verification-modal';

function AccountSettings() {
  const [open, setOpen] = useState(false);
  const [isSending, setIsSending] = useState(false);

  const handleResend = async () => {
    setIsSending(true);
    await resendVerificationEmail();
    setIsSending(false);
    setOpen(false);
  };

  return (
    <EmailVerificationModal
      open={open}
      onOpenChange={setOpen}
      userEmail="user@example.com"
      onSubmit={handleResend}
      isSending={isSending}
    />
  );
}
```

> The unverified email address is highlighted using the `text-ods-warning` Tailwind class, drawing visual attention to the affected address before the user confirms the resend action.
