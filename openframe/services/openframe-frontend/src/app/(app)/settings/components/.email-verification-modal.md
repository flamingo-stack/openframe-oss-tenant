A modal dialog component that prompts users to resend an email verification link when their email address has not yet been verified.

## Key Components

**`EmailVerificationModal`** — Main exported component wrapping `ConfirmDialog` with email verification-specific content.

**`EmailVerificationModalProps`** — Interface defining the component's props:

| Prop | Type | Description |
|------|------|-------------|
| `open` | `boolean` | Controls modal visibility |
| `onOpenChange` | `(open: boolean) => void` | Callback for open state changes |
| `userEmail` | `string` | The unverified email address to display |
| `onSubmit` | `() => Promise<void>` | Handler to trigger the verification email resend |
| `isSending` | `boolean` | Disables confirm button and shows pending state during send |

## Usage Example

```typescript
import { EmailVerificationModal } from './email-verification-modal';

function AccountSettings() {
  const [open, setOpen] = useState(false);
  const [isSending, setIsSending] = useState(false);

  const handleResend = async () => {
    setIsSending(true);
    await resendVerificationEmail();
    setIsSending(false);
    setOpen(false);
  };

  return (
    <EmailVerificationModal
      open={open}
      onOpenChange={setOpen}
      userEmail="user@example.com"
      onSubmit={handleResend}
      isSending={isSending}
    />
  );
}
```

The component highlights the unverified email address in warning color (`text-ods-warning`) and renders two button states: **"Resend Verification"** (idle) and **"Sending..."** (pending).
