Renders the Settings section tab navigation bar, defining all available settings tabs and their associated icons and components.

## Key Components

- **`SETTINGS_TABS`** — Static array of `TabItem` configs defining the six settings tabs: AI Settings, Architecture, Company & Users, API Keys, SSO Configuration, and Profile
- **`getSettingsTabs()`** — Helper function returning the full `SETTINGS_TABS` array
- **`SettingsTabNavigation`** — Client component that renders a `TabNavigation` bar, wired to external `activeTab` state and `onTabChange` handler

## Usage Example

```typescript
import { SettingsTabNavigation, getSettingsTabs } from './navigation';

// Render the navigation bar
function SettingsPage() {
  const [activeTab, setActiveTab] = useState('profile');

  return (
    <SettingsTabNavigation
      activeTab={activeTab}
      onTabChange={setActiveTab}
    />
  );
}

// Retrieve tab definitions (e.g. for routing or dynamic rendering)
const tabs = getSettingsTabs();
const activeComponent = tabs.find(t => t.id === 'ai-settings')?.component;
```
