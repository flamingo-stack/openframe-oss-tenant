Renders the settings section tab navigation bar, defining all available settings tabs and their associated icons and components.

## Key Components

- **`SETTINGS_TABS`** — Static array of `TabItem` objects defining the six settings tabs: AI Settings, Architecture, Company & Users, API Keys, SSO Configuration, and Profile.
- **`getSettingsTabs()`** — Utility function that returns the `SETTINGS_TABS` array.
- **`SettingsTabNavigation`** — Client component that renders the `TabNavigation` bar, accepting `activeTab` and `onTabChange` props to control the active state.

## Usage Example

```typescript
import { SettingsTabNavigation, getSettingsTabs } from './navigation';

// Render the tab navigation bar
function SettingsPage() {
  const [activeTab, setActiveTab] = useState('ai-settings');

  return (
    <>
      <SettingsTabNavigation
        activeTab={activeTab}
        onTabChange={(tabId) => setActiveTab(tabId)}
      />
      {/* Render active tab content */}
    </>
  );
}

// Access tab definitions directly
const tabs = getSettingsTabs();
const aiSettingsTab = tabs.find(tab => tab.id === 'ai-settings');
```
