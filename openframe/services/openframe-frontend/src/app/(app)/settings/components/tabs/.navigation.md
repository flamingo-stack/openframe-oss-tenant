Renders the settings page tab navigation bar, defining all available settings sections and their associated icons and components.

## Key Components

- **`SETTINGS_TABS`** — Static array of `TabItem` configurations defining the six settings sections: AI Settings, Architecture, Company & Users, API Keys, SSO Configuration, and Profile
- **`getSettingsTabs()`** — Helper function returning the `SETTINGS_TABS` array
- **`SettingsTabNavigation`** — Client component that renders a `TabNavigation` bar with controlled `activeTab` state

## Props

| Prop | Type | Description |
|------|------|-------------|
| `activeTab` | `string` | ID of the currently selected tab |
| `onTabChange` | `(tabId: string) => void` | Callback fired when the user selects a different tab |

## Usage Example

```typescript
import { SettingsTabNavigation, SETTINGS_TABS } from './navigation';

function SettingsPage() {
  const [activeTab, setActiveTab] = useState(SETTINGS_TABS[0].id);

  return (
    <>
      <SettingsTabNavigation
        activeTab={activeTab}
        onTabChange={setActiveTab}
      />
      {/* Render active tab component */}
    </>
  );
}
```
