Modal component for editing SSO (OAuth2) provider configurations, supporting Client ID/Secret input, Microsoft-specific tenant settings, auto-provisioning with domain allowlists, and enable/disable actions.

## Key Components

**`SsoConfigModal` / `EditSsoConfigModal`** — Primary export (aliased for backwards compatibility)

**`SsoConfigModalProps`** — Interface defining:
- `providerKey` / `providerDisplayName` — Identifies the SSO provider (e.g. `"microsoft"`, `"google"`)
- `initialClientId`, `initialClientSecret`, `initialMsTenantId` — Pre-populated credential fields
- `initialAutoProvisionUsers`, `initialAllowedDomains` — Domain allowlist settings
- `onSubmit(data)` — Async callback receiving sanitized credentials
- `onDisable()` — Async callback to deactivate the provider

**Internal state:**
- `clientId`, `clientSecret` — OAuth credentials with masked secret toggle
- `isSingleTenant`, `msTenantId` — Microsoft-only tenant configuration
- `autoProvisionUsers`, `allowedDomains` — Auto-account-creation gating by domain
- `canSubmit` (memoized) — Validates required fields; enforces domain entry when auto-provisioning is enabled

**Key behaviors:**
- Redirect URL auto-generated from `runtimeEnv.sharedHostUrl()` + `providerKey`
- One-click copy of redirect URL via `useCopyToClipboard`
- Domain validation delegated to `validateEmailDomain` utility
- Resets all fields on modal open via `useEffect`

## Usage Example

```typescript
<SsoConfigModal
  isOpen={isOpen}
  onClose={() => setIsOpen(false)}
  providerKey="microsoft"
  providerDisplayName="Microsoft"
  isEnabled={true}
  initialClientId="abc123"
  initialClientSecret="secret"
  initialMsTenantId="tenant-id"
  initialAutoProvisionUsers={true}
  initialAllowedDomains={['openframe.com']}
  onSubmit={async (data) => {
    await saveSsoConfig(data);
  }}
  onDisable={async () => {
    await disableSsoProvider('microsoft');
  }}
/>
```
