Displays the Architecture Overview tab, rendering integrated/enabled tools grouped by layer with search filtering and credential details.

## Key Components

**`ArchitectureTab`** — Main exported component that:
- Fetches enabled integrated tools via `useIntegratedTools` on mount
- Provides real-time search filtering across tool name, description, category, layer, and URLs
- Groups filtered tools by `layer`, rendered in alphabetical order
- Shows skeleton loaders during fetch
- Renders each tool as a `ServiceCard` with URL rows (including port display), username, password, and API key credential rows

**Props**

| Prop | Type | Default |
|------|------|---------|
| `title` | `string` | `'Architecture Overview'` |

## Usage Example

```typescript
import { ArchitectureTab } from './architecture';

// Default usage inside a settings/architecture route
export default function ArchitecturePage() {
  return <ArchitectureTab />;
}

// With custom title
export default function ArchitecturePage() {
  return <ArchitectureTab title="My Stack Overview" />;
}
```

## Notes

- Credentials marked `isSecret` (password, API key) render with reveal/copy actions; URLs render with open/copy actions
- Port numbers are displayed both appended to the URL and as a dedicated **Port** row
- Back navigation defaults to `/settings` via `useSafeBack`
