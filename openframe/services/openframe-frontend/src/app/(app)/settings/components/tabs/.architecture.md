Renders the **Architecture Overview** tab in the OpenFrame settings UI, displaying all enabled integrated tools grouped by layer with search/filter capability and credential details.

## Key Components

**`ArchitectureTab`** — Main exported component accepting an optional `title` prop.

- **`useIntegratedTools`** — Fetches enabled integrated tools on mount (`enabled: true, category: null`).
- **`filteredTools`** — Memoized search across `name`, `description`, `category`, `layer`, and `toolUrls`.
- **`grouped`** — Reduces filtered tools into a `Record<layer, tools[]>` map, sorted alphabetically.
- **`ServiceCard`** — Renders each tool with URL rows (with optional port suffix), username, password, and API key credential rows. Secrets are masked with reveal/copy actions.
- **Loading state** — Shows a 4-card skeleton grid while tools are being fetched.

## Usage Example

```typescript
import { ArchitectureTab } from './architecture';

// Default title
<ArchitectureTab />

// Custom title
<ArchitectureTab title="Infrastructure Overview" />
```

## Row Construction Logic

Each `ServiceCard` receives dynamically built `rows` derived from a tool's data:

```typescript
// URL row (with optional port concatenation)
{ label: 'Web Url', value: 'https://tool.local:8080', href: '...', actions: { copy: true, open: true } }

// Separate port row (when port exists)
{ label: 'Port', value: '8080', actions: { copy: true } }

// Credential rows
{ label: 'User',    value: 'admin',       actions: { copy: true } }
{ label: 'Pass',    value: '••••••',      isSecret: true, actions: { reveal: true, copy: true } }
{ label: 'API Key', value: '••••••',      isSecret: true, actions: { reveal: true, copy: true } }
```
