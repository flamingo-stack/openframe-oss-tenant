Renders the SSO Configuration tab UI for managing OAuth provider settings, including a searchable data table of providers, shared SSO domain configuration, and an edit modal for per-provider OAuth credentials.

## Key Components

### `SsoConfigurationTab` (default export)
Main page component that orchestrates:
- **Provider table** — lists available SSO providers (Google, Microsoft, etc.) with status, allowed domains, and configuration state
- **Shared SSO card** — toggle for auto-provisioning accounts from the tenant's verified domain via shared Google & Microsoft SSO
- **Edit modal** — opens `SsoConfigModal` pre-filled with provider credentials for inline editing

### Internal Types

| Type | Description |
|------|-------------|
| `UiProviderRow` | Flattened row model for the `DataTable`, derived from `AvailableProvider` + `ProviderConfig` |

### Key Hooks Used

| Hook | Purpose |
|------|---------|
| `useSsoConfig` | Fetch/update per-provider OAuth config and enable/disable toggle |
| `useTenantDomain` | Fetch tenant domain info and update shared auto-provision setting |
| `useDataTable` | Wire filtered rows into the sortable/filterable `DataTable` |
| `useSafeBack` | Navigate back to `/settings` safely |

## Usage Example

```typescript
// Render inside a settings route that requires authentication
import { SsoConfigurationTab } from './sso-configuration';

export default function SsoSettingsPage() {
  return <SsoConfigurationTab />;
}
```

> **Note:** The shared SSO card only renders when `tenantDomain.generic` is `false` (i.e., the tenant has a verified non-generic domain). Generic domains (e.g. `gmail.com`) disable the auto-provision checkbox with an explanatory tooltip.
