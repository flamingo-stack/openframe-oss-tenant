Renders the SSO Configuration tab UI for managing Single Sign-On providers, including listing available OAuth providers, their configuration status, and a shared SSO auto-provisioning toggle for tenant domains.

## Key Components

- **`SsoConfigurationTab`** — Main exported component that orchestrates provider listing, search filtering, shared SSO domain settings, and modal-driven configuration editing
- **`UiProviderRow`** — Local type defining the shape of each table row (provider identity, status, domains, config state)
- **`useSsoConfig`** — Hook supplying provider fetch/update/toggle operations
- **`useTenantDomain`** — Hook supplying tenant domain info and shared auto-provision update
- **`SsoConfigModal`** — Modal component (imported) for editing individual provider credentials
- **`useDataTable`** / **`DataTable`** — Table primitives powering the sortable, filterable provider list

## Usage Example

```typescript
// Render inside a settings page or tab panel
import { SsoConfigurationTab } from './sso-configuration';

export default function SettingsPage() {
  return (
    <div>
      <SsoConfigurationTab />
    </div>
  );
}
```

## Behavior Notes

- On mount, fetches all available OAuth providers and their configs in parallel; per-provider configs are merged into `UiProviderRow` state
- Tenant domain is loaded separately; if the domain is non-generic, a **Shared SSO** card renders with a `CheckboxWithDescription` toggle for auto-provisioning accounts on first sign-in
- Clicking **Edit** on any row opens `SsoConfigModal` pre-populated with `clientId`, `clientSecret`, `msTenantId`, allowed domains, and enabled state
- Search filters by `displayName` or `provider` key (case-insensitive)
- Errors surface via `PageError`; intermediate loading states use `Skeleton` placeholders
