A client-side modal component that prompts the user to confirm revoking a pending invitation, displaying the invitee's email and a destructive confirmation action.

## Key Components

- **`ConfirmRevokeInvitationModal`** — Named export wrapping `ConfirmDialog` with revoke-specific copy and styling.
- **`ConfirmRevokeInvitationModalProps`** — Interface defining the component's props:
  - `open` — Controls modal visibility.
  - `onOpenChange` — Callback to toggle open state.
  - `userEmail` — Email of the invited user, highlighted in error color.
  - `onConfirm` — Async or sync handler executed on confirmation.

## Usage Example

```typescript
import { ConfirmRevokeInvitationModal } from './confirm-revoke-invitation-modal';

function InvitationList() {
  const [open, setOpen] = useState(false);

  const handleRevoke = async () => {
    await revokeInvitation(invitationId);
  };

  return (
    <>
      <button onClick={() => setOpen(true)}>Revoke</button>
      <ConfirmRevokeInvitationModal
        open={open}
        onOpenChange={setOpen}
        userEmail="jane@example.com"
        onConfirm={handleRevoke}
      />
    </>
  );
}
```

> The invitee's email is rendered with `text-ods-error` styling to visually reinforce the destructive nature of the action. Once confirmed, the invitation is permanently deleted and the user can no longer register via that invite link.
