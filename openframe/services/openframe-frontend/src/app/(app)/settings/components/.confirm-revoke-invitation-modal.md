A confirmation modal component for revoking pending user invitations, built on top of the shared `ConfirmDialog` component.

## Key Components

### `ConfirmRevokeInvitationModal`
A thin wrapper around `ConfirmDialog` that pre-configures the dialog for the invitation revocation flow, displaying the target user's email in an error-styled highlight.

### `ConfirmRevokeInvitationModalProps`
| Prop | Type | Description |
|------|------|-------------|
| `open` | `boolean` | Controls dialog visibility |
| `onOpenChange` | `(open: boolean) => void` | Callback to toggle open state |
| `userEmail` | `string` | Email address of the invited user to display in the warning message |
| `onConfirm` | `() => Promise<void> \| void` | Async or sync callback executed on confirmation |

## Usage Example

```typescript
const [revokeOpen, setRevokeOpen] = useState(false);

const handleRevoke = async () => {
  await revokeInvitation(invitationId);
};

<ConfirmRevokeInvitationModal
  open={revokeOpen}
  onOpenChange={setRevokeOpen}
  userEmail="technician@example.com"
  onConfirm={handleRevoke}
/>
```

> The user's email is rendered with the `text-ods-error` class, providing a clear visual warning before the destructive action is confirmed.
