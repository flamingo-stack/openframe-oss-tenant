A modal dialog component for confirming the revocation of a pending user invitation, built on top of the shared `ConfirmDialog` primitive.

## Key Components

- **`ConfirmRevokeInvitationModal`** — Default export. Renders a confirmation dialog that warns the user about permanently deleting an invitation for a specific email address.
- **`ConfirmRevokeInvitationModalProps`** — Interface defining the component's props:
  - `open` — Controls dialog visibility
  - `onOpenChange` — Callback to handle open/close state changes
  - `userEmail` — The invitee's email address, highlighted in error color
  - `onConfirm` — Async or sync callback executed upon confirmation

## Usage Example

```typescript
import { ConfirmRevokeInvitationModal } from './confirm-revoke-invitation-modal';

function InvitationsTable() {
  const [open, setOpen] = useState(false);

  const handleRevoke = async () => {
    await revokeInvitation(inviteId);
  };

  return (
    <>
      <button onClick={() => setOpen(true)}>Revoke</button>
      <ConfirmRevokeInvitationModal
        open={open}
        onOpenChange={setOpen}
        userEmail="john@example.com"
        onConfirm={handleRevoke}
      />
    </>
  );
}
```

> The target email is rendered with `text-ods-error` styling inside the dialog description, giving users a clear visual cue about the affected account before confirming the destructive action.
