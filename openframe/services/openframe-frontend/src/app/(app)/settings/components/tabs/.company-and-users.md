A client-side React component that renders the **Company & Users** settings tab, displaying a unified data table of active users and pending/expired invitations with contextual action menus.

## Key Components

- **`CompanyAndUsersTab`** — Main exported component; manages all modal state and mutation handlers for user/invitation lifecycle actions
- **`statusToLabel`** / **`statusToVariant`** — Lookup maps converting `UnifiedUserStatus` values to display strings and `Tag` color variants
- **`columns`** — Memoized `ColumnDef<UnifiedUserRecord>[]` defining USER, ROLE, STATUS, and actions columns; action menu items vary by record type and user permissions
- **`useUsersAndInvitations`** — Hook providing unified `records[]`, loading/error state, and mutation functions (`deleteUser`, `revokeInvitation`, `resendInvitation`, `inviteUsers`)
- **Modal set** — `ConfirmDeleteUserModal`, `ConfirmRevokeInvitationModal`, `ConfirmRemoveInvitationModal`, `ConfirmResendInvitationModal`, `AddUsersModal`

## Usage Example

```typescript
// Rendered as a tab inside the settings page
import { CompanyAndUsersTab } from './company-and-users';

export default function SettingsPage() {
  return (
    <Tabs>
      <TabPanel value="users">
        <CompanyAndUsersTab />
      </TabPanel>
    </Tabs>
  );
}
```

## Behavior Notes

- **Delete** is disabled for: the current user (`isSelf`), owners (`isOwner`), or already-deleted users
- **Expired invitations** show "Resend" + "Remove" actions; pending invitations show "Revoke" only
- Table loads up to **1,000 records** (pagination not yet implemented — noted as TODO)
- `isMutating` gates the table body loading state across all three active mutations
