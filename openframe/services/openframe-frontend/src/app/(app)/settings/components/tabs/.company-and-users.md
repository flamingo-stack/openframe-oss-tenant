A client-side React tab component that renders a data table of company users and invitations, with actions to add, delete, revoke, resend, and remove users/invitations.

## Key Components

- **`CompanyAndUsersTab`** — Main exported component; displays a unified list of users and pending/expired invitations with role and status columns
- **`statusToLabel`** — Maps `UserStatus` and `InvitationStatus` values to human-readable display strings
- **`statusToVariant`** — Maps statuses to `Tag` component variant styles (`success`, `grey`, `warning`, `error`)
- **Column definitions** — Defines `USER`, `ROLE`, `STATUS`, and `actions` columns; the actions column renders context-aware menus based on record type and user permissions
- **Action handlers** — `handleDeleteRequest`, `handleRevokeRequest`, `handleRemoveRequest`, `handleResendRequest` open their respective confirmation modals; each confirm handler calls the appropriate mutation and closes the modal on success

## Usage Example

```typescript
// Rendered as a tab inside a settings page
import { CompanyAndUsersTab } from './company-and-users';

export function SettingsPage() {
  return (
    <Tabs>
      <TabPanel value="users">
        <CompanyAndUsersTab />
      </TabPanel>
    </Tabs>
  );
}
```

## Notes

- Fetches up to 1,000 records via `useUsersAndInvitations(0, 1000)` — pagination is a planned future enhancement
- Delete action is disabled for owners, the currently authenticated user (`isSelf`), and already-deleted users
- Expired invitations expose **Resend** and **Remove** actions; pending invitations expose only **Revoke**
- All destructive actions route through confirmation modals (`ConfirmDeleteUserModal`, `ConfirmRevokeInvitationModal`, etc.) before executing mutations
