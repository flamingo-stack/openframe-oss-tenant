Renders the **Company & Users** settings tab, displaying a unified data table of active users and pending/expired invitations with contextual action menus for managing each record type.

## Key Components

- **`CompanyAndUsersTab`** — Main exported component; orchestrates user and invitation management UI
- **`statusToLabel`** — Maps `UnifiedUserStatus` values to display strings (e.g., `ACTIVE`, `INVITE SENT`)
- **`statusToVariant`** — Maps statuses to `Tag` color variants (`success`, `warning`, `error`, `grey`)
- **Column definitions** — Three data columns (`USER`, `ROLE`, `STATUS`) plus a context-aware `actions` column that renders different menus for users vs. invitations
- **Modal state management** — Controls five modals: Add Users, Confirm Delete, Revoke Invitation, Remove Invitation, Resend Invitation

## Usage Example

```typescript
// Rendered as a settings sub-route tab
import { CompanyAndUsersTab } from './company-and-users';

export default function SettingsPage() {
  return <CompanyAndUsersTab />;
}
```

## Action Logic Summary

| Record Type | Status | Available Actions |
|-------------|--------|-------------------|
| `User` | Active | Delete (disabled if owner or self) |
| `User` | Deleted | Delete (disabled) |
| `Invitation` | Pending | Revoke |
| `Invitation` | Expired | Resend, Remove |

**Key behaviors:**
- Delete is blocked for the current user (`isSelf`), owners (`isOwner`), or already-deleted users
- Uses `useUsersAndInvitations(0, 1000)` — full fetch with no pagination (pagination planned)
- Mutation loading states (`isPending`) are aggregated into a single `isMutating` flag passed to `DataTable.Body`
