Modal component for editing a user's profile, including first/last name fields and profile image upload/delete functionality.

## Key Components

**`EditProfileModal`** — Main exported component that renders a `SimpleModal` with:
- `HeroImageUploader` — Handles authenticated profile image upload and deletion via `/api/users/image`
- First/Last Name inputs — Editable text fields synced to the current user state
- Email & Role inputs — Read-only display fields
- Save/Cancel footer actions with loading state

**Props (`EditProfileModalProps`)**

| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls modal visibility |
| `onClose` | `() => void` | Callback to close the modal |
| `user` | `User \| null` | Current user data to pre-populate fields |
| `onSave` | `(data) => Promise<void>` | Async handler for name updates |
| `onImageChange` | `(image) => void` | Notifies parent of image changes |
| `isSaving` | `boolean` | Disables inputs and shows saving state |

**Internal handlers**
- `handleAuthenticatedUpload` — Uploads file via `uploadWithAuth`, updates local state, fires toast
- `handleAuthenticatedDelete` — Removes image via `deleteWithAuth`, clears state, fires toast
- `handleSave` — Calls `onSave` with current name values then closes modal

## Usage Example

```typescript
<EditProfileModal
  isOpen={isProfileModalOpen}
  onClose={() => setIsProfileModalOpen(false)}
  user={currentUser}
  onSave={async ({ firstName, lastName }) => {
    await updateUserProfile({ firstName, lastName });
  }}
  onImageChange={(image) => {
    setCurrentUser(prev => prev ? { ...prev, image } : prev);
  }}
  isSaving={isSaving}
/>
```
