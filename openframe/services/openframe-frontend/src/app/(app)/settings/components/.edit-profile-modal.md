Modal component for editing a user's profile, including name fields, profile image upload/delete, and read-only email/role display.

## Key Components

### `EditProfileModalProps`

| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls modal visibility |
| `onClose` | `() => void` | Callback to close the modal |
| `user` | `User \| null` | Current user data to pre-populate fields |
| `onSave` | `(data) => Promise<void>` | Async handler for saving name changes |
| `onImageChange` | `(image) => void` | Callback fired on profile image upload or delete |
| `isSaving` | `boolean` | Disables inputs and shows loading state on the save button |

### Internal Handlers

- **`handleAuthenticatedUpload`** — POSTs the selected file to `/api/users/image` via `uploadWithAuth`, updates local image state, and fires `onImageChange`.
- **`handleAuthenticatedDelete`** — DELETEs the current image from `/api/users/image` via `deleteWithAuth` and clears image state.
- **`handleSave`** — Calls `onSave` with current first/last name values, then closes the modal.

## Usage Example

```typescript
<EditProfileModal
  isOpen={isProfileModalOpen}
  onClose={() => setProfileModalOpen(false)}
  user={currentUser}
  onSave={async ({ firstName, lastName }) => {
    await updateUserProfile({ firstName, lastName });
  }}
  onImageChange={(image) => {
    setCurrentUser(prev => prev ? { ...prev, image } : prev);
  }}
  isSaving={isSaving}
/>
```

> **Note:** Email and Role fields are read-only. Only the first name, last name, and profile image are editable. The primary role displayed is derived from `user.roles[0]`, defaulting to `"User"`.
