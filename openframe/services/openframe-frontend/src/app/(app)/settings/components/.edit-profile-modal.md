A modal dialog component for editing a user's profile, including first/last name fields and profile image upload/delete functionality.

## Key Components

### `EditProfileModal`
The primary exported component. Renders a `SimpleModal` containing:
- **`HeroImageUploader`** — Handles authenticated profile image upload and deletion via `/api/users/image`
- **Name fields** — Editable `firstName` and `lastName` inputs
- **Read-only fields** — Disabled `email` and primary `role` inputs
- **Footer actions** — Cancel and Update Profile buttons with saving state

### `EditProfileModalProps`
| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls modal visibility |
| `onClose` | `() => void` | Called on cancel or after save |
| `user` | `User \| null` | Current user data to pre-populate fields |
| `onSave` | `(data) => Promise<void>` | Handles name persistence |
| `onImageChange` | `(image) => void` | Propagates image state changes to parent |
| `isSaving` | `boolean` | Disables inputs and shows loading state |

## Usage Example

```typescript
<EditProfileModal
  isOpen={isProfileModalOpen}
  onClose={() => setIsProfileModalOpen(false)}
  user={currentUser}
  isSaving={isSaving}
  onSave={async ({ firstName, lastName }) => {
    await updateUserProfile({ firstName, lastName });
  }}
  onImageChange={(image) => {
    setCurrentUser(prev => prev ? { ...prev, image } : prev);
  }}
/>
```

## Behavior Notes

- Fields are re-initialized from `user` prop each time the modal opens via `useEffect`
- Image uploads call `uploadWithAuth` and trigger a success toast on completion
- Image deletions call `deleteWithAuth` and clear the local image state
- `onClose` is called automatically after a successful save
