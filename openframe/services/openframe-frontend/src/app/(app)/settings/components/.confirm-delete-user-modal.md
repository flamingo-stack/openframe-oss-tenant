A client-side modal component that prompts the user to confirm deletion of a system user, wrapping the shared `ConfirmDialog` with deletion-specific messaging.

## Key Components

- **`ConfirmDeleteUserModal`** — React component that renders a confirmation dialog displaying the target username (highlighted in error color) and a "Delete User" confirm button.
- **`ConfirmDeleteUserModalProps`** — Interface defining the component's props:
  - `open` — Controls dialog visibility.
  - `onOpenChange` — Callback to toggle open state.
  - `userName` — Name of the user to be deleted, rendered in `ods-error` styling.
  - `onConfirm` — Async or sync callback executed on confirmation.

## Usage Example

```typescript
import { ConfirmDeleteUserModal } from './confirm-delete-user-modal';

function UserManagement() {
  const [isOpen, setIsOpen] = useState(false);

  const handleDelete = async () => {
    await deleteUser(userId);
    setIsOpen(false);
  };

  return (
    <ConfirmDeleteUserModal
      open={isOpen}
      onOpenChange={setIsOpen}
      userName="john.doe@example.com"
      onConfirm={handleDelete}
    />
  );
}
```
