A reusable modal component that prompts confirmation before permanently deleting a user, built on top of the shared `ConfirmDialog` component.

## Key Components

- **`ConfirmDeleteUserModal`** — Client component that renders a confirmation dialog for user deletion
- **`ConfirmDeleteUserModalProps`** — Interface defining the component's props:
  - `open` — Controls dialog visibility
  - `onOpenChange` — Callback to toggle open state
  - `userName` — Display name of the user being deleted (highlighted in error color)
  - `onConfirm` — Async or sync callback executed on confirmation

## Usage Example

```typescript
import { ConfirmDeleteUserModal } from './confirm-delete-user-modal';

function UserManagement() {
  const [isOpen, setIsOpen] = useState(false);

  const handleDeleteUser = async () => {
    await deleteUser(userId);
  };

  return (
    <ConfirmDeleteUserModal
      open={isOpen}
      onOpenChange={setIsOpen}
      userName="John Doe"
      onConfirm={handleDeleteUser}
    />
  );
}
```

> The user's name is rendered in `text-ods-error` (red) within the description to visually reinforce the destructive nature of the action.
