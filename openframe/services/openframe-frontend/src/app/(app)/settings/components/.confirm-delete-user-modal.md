A client-side modal component that prompts the user to confirm deletion of a system user, wrapping the shared `ConfirmDialog` with user-specific messaging.

## Key Components

- **`ConfirmDeleteUserModal`** — Named export; renders a confirmation dialog warning that the target user will lose system access.
- **`ConfirmDeleteUserModalProps`** — Interface defining the component's props:
  - `open` — Controls dialog visibility.
  - `onOpenChange` — Callback to toggle the dialog open state.
  - `userName` — Display name of the user being deleted (highlighted in error color).
  - `onConfirm` — Async or sync callback executed on confirmation.

## Usage Example

```typescript
import { ConfirmDeleteUserModal } from './confirm-delete-user-modal';

function UserManagement() {
  const [open, setOpen] = useState(false);

  const handleDelete = async () => {
    await deleteUser(userId);
    setOpen(false);
  };

  return (
    <>
      <button onClick={() => setOpen(true)}>Delete User</button>
      <ConfirmDeleteUserModal
        open={open}
        onOpenChange={setOpen}
        userName="john.doe@example.com"
        onConfirm={handleDelete}
      />
    </>
  );
}
```
