Barrel export file for the Settings module, re-exporting all tab components and navigation utilities from their respective sub-modules.

## Key Components

| Export | Source Module | Description |
|--------|--------------|-------------|
| `AiSettingsTab` | `./ai-settings` | AI configuration settings tab |
| `ApiKeysTab` | `./api-keys` | API key management tab |
| `ArchitectureTab` | `./architecture` | System architecture settings tab |
| `CompanyAndUsersTab` | `./company-and-users` | Company profile and user management tab |
| `getSettingsTabs` | `./navigation` | Helper function to retrieve available settings tabs |
| `SETTINGS_TABS` | `./navigation` | Constant defining all settings tab identifiers |
| `SettingsTabNavigation` | `./navigation` | Navigation component for settings tabs |
| `ProfileTab` | `./profile` | User profile settings tab |
| `SsoConfigurationTab` | `./sso-configuration` | SSO/identity provider configuration tab |

## Usage Example

```typescript
import {
  AiSettingsTab,
  ApiKeysTab,
  CompanyAndUsersTab,
  getSettingsTabs,
  SETTINGS_TABS,
  SettingsTabNavigation,
  ProfileTab,
  SsoConfigurationTab,
} from '@/modules/settings';

// Render navigation and conditionally display the active tab
const tabs = getSettingsTabs();

return (
  <>
    <SettingsTabNavigation tabs={tabs} />
    {activeTab === SETTINGS_TABS.PROFILE && <ProfileTab />}
    {activeTab === SETTINGS_TABS.API_KEYS && <ApiKeysTab />}
    {activeTab === SETTINGS_TABS.SSO && <SsoConfigurationTab />}
  </>
);
```
