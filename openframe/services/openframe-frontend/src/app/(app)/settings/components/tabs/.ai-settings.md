React client component that renders the AI settings tab, allowing users to configure AI provider/model selection and manage AI policy templates (including custom policy creation and editing).

## Key Components

**`AiSettingsTab`** — Main exported component that orchestrates:
- **AI Provider/Model Selection** — Dropdown controls for switching between Anthropic, OpenAI, and Google Gemini providers with their respective models
- **Policy Template Management** — Radio group for selecting predefined or custom policy templates
- **Custom Policy Editor** — Edit mode for creating/modifying custom permission rules per `PermissionCategory`
- **Edit/Save/Cancel Session** — Snapshot-based edit session (`editSnapshotRef`) that captures pre-edit state for safe cancellation

**Internal State**
| State | Purpose |
|---|---|
| `isEditMode` | Toggles read/edit UI |
| `policyGroups` | `Map<string, PermissionCategory[]>` built from template rules |
| `customPolicy` | Tracks custom policy base template, overrides, and pending changes |
| `editSnapshotRef` | Ref snapshot for cancel/rollback |

**Key Utilities Used**
- `buildPolicyGroups` — Converts flat policy rules into grouped categories
- `clonePolicyGroups` — Deep clones groups for snapshot
- `mapToObject` — Converts `Map<string, ApprovalLevel>` to plain object for API payload

## Usage Example

```typescript
// Rendered inside a settings page as a tab panel
import { AiSettingsTab } from './ai-settings';

export default function SettingsPage() {
  return (
    <TabsContent value="ai">
      <AiSettingsTab />
    </TabsContent>
  );
}
```

**Save Flow:**

```typescript
// handleSave batches AI config + policy changes into parallel promises
await Promise.all([
  updateConfiguration({ provider, modelName }),   // if provider/model changed
  createOrUpdateCustomPolicy(templateId, overrides), // if custom policy changed
]);
```
