Settings page component for configuring AI provider, model selection, and policy management within the Flamingo/OpenFrame platform.

## Key Components

### `AiSettingsTab` (default export)
The main settings tab component managing three interconnected concerns:

- **AI Provider & Model Selection** — Allows selecting from Anthropic (Claude), OpenAI, and Google Gemini providers with their available models via `useAiConfiguration`
- **Policy Template Management** — Radio-group based selection of predefined or custom permission policy templates via `useAiPolicies`
- **Custom Policy Editor** — Edit mode with snapshot-based undo/cancel, supporting creation and modification of custom `PolicyConfigurationPanel` overrides

### Supporting Constants
- `PROVIDER_CONFIG` — Maps provider keys to display labels, API key slugs, and icon components
- `API_KEY_TO_PROVIDER` — Reverse lookup from API key strings to typed `ProviderKey`
- `CUSTOM_CREATION_TEMPLATE_ID` — Sentinel ID for new (unsaved) custom policies

## Usage Example

```typescript
// Rendered as a tab inside the settings page
import { AiSettingsTab } from './ai-settings';

export default function SettingsPage() {
  return (
    <Tabs>
      <TabsContent value="ai">
        <AiSettingsTab />
      </TabsContent>
    </Tabs>
  );
}
```

## State Management Pattern

The component uses an `editSnapshotRef` to capture pre-edit state, enabling full cancel/rollback without a form library:

```typescript
// On edit begin: snapshot current values
editSnapshotRef.current = { provider, model, templateId, policyGroups, customBaseTemplateId };

// On cancel: restore from snapshot
setSelectedProvider(snapshot.provider);
setSelectedModel(snapshot.model);
setSelectedTemplateId(snapshot.templateId);
```

Save logic (`handleSave`) batches AI config and policy changes into parallel `Promise.all` calls, only persisting deltas detected against the snapshot.
