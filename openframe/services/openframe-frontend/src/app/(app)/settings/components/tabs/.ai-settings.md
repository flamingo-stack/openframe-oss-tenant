Client-side React component providing the AI configuration settings tab within the OpenFrame platform, allowing technicians to configure AI providers, models, and policy templates for Mingo AI behavior.

## Key Components

- **`AiSettingsTab`** — Main exported component managing the complete AI settings UI
- **`PROVIDER_CONFIG`** — Static map of supported AI providers (Anthropic/Claude, OpenAI, Google Gemini) with icons and labels
- **`API_KEY_TO_PROVIDER`** — Lookup map normalizing raw API key strings to typed provider keys
- **`CUSTOM_TEMPLATE_TYPE`** — Constant distinguishing custom policy templates from built-in ones

## Key State & Hooks

| Hook / State | Purpose |
|---|---|
| `useAiConfiguration` | Fetches and updates the active AI provider/model config |
| `useAiPolicies` | Manages policy templates: listing, selecting, activating, and creating/updating custom policies |
| `editSnapshotRef` | Stores a point-in-time snapshot before edit mode begins, enabling full cancel/rollback |
| `customPolicy` (`CustomPolicyState`) | Tracks pending rule overrides for custom policy creation or editing |
| `policyGroups` | Derived `Map` grouping policy rules by `PermissionCategory` for display |

## Key Handlers

- **`beginEditSession`** — Captures edit snapshot and enters edit mode
- **`handleSave`** — Batches AI config updates and policy create/activate calls; commits on success
- **`handleCancel`** — Rolls back all state to the pre-edit snapshot
- **`handleUseForCustomPolicy`** — Fetches a base template by ID and seeds the custom policy editor

## Usage Example

```typescript
// Rendered as a tab within the settings page
import { AiSettingsTab } from './tabs/ai-settings';

export default function SettingsPage() {
  return (
    <SettingsLayout>
      <AiSettingsTab />
    </SettingsLayout>
  );
}
```
