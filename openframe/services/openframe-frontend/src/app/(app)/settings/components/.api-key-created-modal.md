A one-time display modal that reveals a newly created API key, prompting the user to copy and securely store it before dismissing.

## Key Components

- **`ApiKeyCreatedModal`** — Main exported component that wraps `SimpleModal` to display the full API key
- **`ApiKeyCreatedModalProps`** — Interface defining `isOpen`, `fullKey`, and `onClose` props
- **`useCopyToClipboard`** — Hook providing `copy` and `copied` state with success/error toast feedback
- **Local key state** — Mirrors `fullKey` into `localKey` and clears it on modal close to prevent stale data exposure

## Behavior Notes

- Returns `null` if `localKey` is empty, preventing the modal from rendering without a valid key
- Displays a warning `Alert` informing the user this is the **only time** the full key will be shown
- The copy button icon toggles between `Copy02Icon` and `CheckIcon` after a successful copy

## Usage Example

```typescript
import { ApiKeyCreatedModal } from '@/app/components/api-keys/api-key-created-modal';

function ApiKeysPage() {
  const [createdKey, setCreatedKey] = useState<string | null>(null);

  const handleCreate = async () => {
    const { fullKey } = await createApiKey();
    setCreatedKey(fullKey);
  };

  return (
    <>
      <Button onClick={handleCreate}>Create API Key</Button>
      <ApiKeyCreatedModal
        isOpen={!!createdKey}
        fullKey={createdKey}
        onClose={() => setCreatedKey(null)}
      />
    </>
  );
}
```
