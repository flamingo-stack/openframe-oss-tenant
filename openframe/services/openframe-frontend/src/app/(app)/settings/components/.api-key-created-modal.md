A one-time display modal that reveals a newly created API key to the user, with copy-to-clipboard functionality and a security warning.

## Key Components

- **`ApiKeyCreatedModal`** — Main export; a `SimpleModal`-based component that displays the full API key exactly once after creation
- **`ApiKeyCreatedModalProps`** — Interface defining `isOpen`, `fullKey` (nullable string), and `onClose` callback
- **`localKey` state** — Caches the key while the modal is open; clears on close to prevent re-display
- **`useCopyToClipboard`** — Hook powering the copy button with success/error toast descriptions
- **Warning alert** — Prominent `AlertTriangleIcon` banner reminding users this is the only opportunity to save the key

## Usage Example

```typescript
import { ApiKeyCreatedModal } from '@/app/components/api-key-created-modal';

function ApiKeyManager() {
  const [newKey, setNewKey] = useState<string | null>(null);

  const handleCreate = async () => {
    const { fullKey } = await createApiKey();
    setNewKey(fullKey);
  };

  return (
    <>
      <Button onClick={handleCreate}>Create API Key</Button>
      <ApiKeyCreatedModal
        isOpen={!!newKey}
        fullKey={newKey}
        onClose={() => setNewKey(null)}
      />
    </>
  );
}
```

> **Security note:** The `localKey` state intentionally clears when `isOpen` becomes `false`, ensuring the plaintext key is never re-shown after the modal is dismissed.
