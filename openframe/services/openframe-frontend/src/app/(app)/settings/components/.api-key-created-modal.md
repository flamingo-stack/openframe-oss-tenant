Modal component displayed immediately after API key creation, allowing users to view and copy their full API key before it becomes permanently hidden.

## Key Components

**`ApiKeyCreatedModalProps`**
| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls modal visibility |
| `fullKey` | `string \| null` | The full plaintext API key to display |
| `onClose` | `() => void` | Callback fired when the user dismisses the modal |

**Internal State**
- `localKey` — Retains the key value while open; clears on close to prevent stale key display on re-render.
- `useCopyToClipboard` — Provides `copy` / `copied` state with toast feedback on success or failure.

**Rendering Logic**
- Returns `null` if `localKey` is empty (guards against flash of empty modal).
- Displays a warning `Alert` reminding users this is a one-time view.
- Renders the key inside a monospace `<code>` block with `break-all` to handle long key strings.
- Footer offers **Copy API Key** (with a `CheckIcon` confirmation on success) and **Continue** to dismiss.

## Usage Example

```typescript
const [modalOpen, setModalOpen] = useState(false);
const [createdKey, setCreatedKey] = useState<string | null>(null);

// After successful API key creation response:
const handleKeyCreated = (fullKey: string) => {
  setCreatedKey(fullKey);
  setModalOpen(true);
};

return (
  <ApiKeyCreatedModal
    isOpen={modalOpen}
    fullKey={createdKey}
    onClose={() => {
      setModalOpen(false);
      setCreatedKey(null); // Key is no longer accessible after close
    }}
  />
);
```

> **One-time visibility:** The full API key is only available at creation time. Once `onClose` is called, the key should be discarded from parent state — it cannot be retrieved again.
