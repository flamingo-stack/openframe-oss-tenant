A modal dialog component for confirming the removal of an expired user invitation, wrapping the shared `ConfirmDialog` with invitation-specific messaging.

## Key Components

- **`ConfirmRemoveInvitationModal`** — Client component that renders a destructive confirmation dialog
- **`ConfirmRemoveInvitationModalProps`** — Interface defining the component's props:
  - `open` — Controls dialog visibility
  - `onOpenChange` — Callback for open/close state changes
  - `userEmail` — Email address of the invitee, highlighted in error color
  - `onConfirm` — Async or sync callback executed on confirmation

## Usage Example

```typescript
import { ConfirmRemoveInvitationModal } from './confirm-remove-invitation-modal';

function InvitationList() {
  const [open, setOpen] = useState(false);

  const handleRemove = async () => {
    await removeInvitation(invitationId);
  };

  return (
    <ConfirmRemoveInvitationModal
      open={open}
      onOpenChange={setOpen}
      userEmail="jane@example.com"
      onConfirm={handleRemove}
    />
  );
}
```

## Notes

- Delegates all dialog rendering to the shared `ConfirmDialog` component
- The `userEmail` is styled with `text-ods-error` to visually emphasize the affected account
- Marked as `'use client'` — must be used within a React client boundary
