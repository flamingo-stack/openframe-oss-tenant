A modal dialog component that confirms the removal of an expired user invitation, wrapping the shared `ConfirmDialog` with invitation-specific messaging.

## Key Components

- **`ConfirmRemoveInvitationModal`** — Named export; renders a pre-configured `ConfirmDialog` for the invitation removal flow
- **`ConfirmRemoveInvitationModalProps`** — Interface defining the component's props:
  - `open` — Controls dialog visibility
  - `onOpenChange` — Callback to toggle open state
  - `userEmail` — Email address of the invitee, highlighted in error color within the description
  - `onConfirm` — Async or sync handler executed on confirmation

## Usage Example

```typescript
import { ConfirmRemoveInvitationModal } from './confirm-remove-invitation-modal';

function InvitationsList() {
  const [open, setOpen] = useState(false);

  const handleRemove = async () => {
    await removeInvitation('user@example.com');
  };

  return (
    <ConfirmRemoveInvitationModal
      open={open}
      onOpenChange={setOpen}
      userEmail="user@example.com"
      onConfirm={handleRemove}
    />
  );
}
```
