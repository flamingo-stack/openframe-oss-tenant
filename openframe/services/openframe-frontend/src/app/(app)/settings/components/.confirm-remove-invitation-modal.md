A confirmation modal component for removing expired user invitations, wrapping the shared `ConfirmDialog` with invitation-specific copy and styling.

## Key Components

**`ConfirmRemoveInvitationModal`** — A focused modal that prompts the user to confirm permanent deletion of an expired invitation, highlighting the target email in error color (`text-ods-error`).

### Props (`ConfirmRemoveInvitationModalProps`)

| Prop | Type | Description |
|------|------|-------------|
| `open` | `boolean` | Controls modal visibility |
| `onOpenChange` | `(open: boolean) => void` | Callback to toggle open state |
| `userEmail` | `string` | Email address of the invited user, displayed in error color |
| `onConfirm` | `() => Promise<void> \| void` | Handler called on confirmation, supports async |

## Usage Example

```typescript
import { ConfirmRemoveInvitationModal } from './confirm-remove-invitation-modal';

function InvitationList() {
  const [open, setOpen] = useState(false);

  const handleRemove = async () => {
    await deleteInvitation(invitationId);
    setOpen(false);
  };

  return (
    <ConfirmRemoveInvitationModal
      open={open}
      onOpenChange={setOpen}
      userEmail="jane@example.com"
      onConfirm={handleRemove}
    />
  );
}
```

> Delegates all dialog rendering to the shared `ConfirmDialog` component — only the title, description, and confirm label are customized here.
