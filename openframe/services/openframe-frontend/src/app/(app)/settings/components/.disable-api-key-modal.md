A confirmation modal component for disabling/deactivating an API key, wrapping the shared `ConfirmDialog` with destructive styling and disable-specific messaging.

## Key Components

- **`DisableApiKeyModal`** — Client component that renders a destructive confirmation dialog prompting the user to confirm deactivation of a named API key.
- **`DisableApiKeyModalProps`** — Interface defining `isOpen`, `onClose`, optional `apiKeyName`, and async `onConfirm` handler.

## Usage Example

```typescript
const [isModalOpen, setIsModalOpen] = useState(false);

async function handleDisable() {
  await disableApiKey(keyId);
  setIsModalOpen(false);
}

<DisableApiKeyModal
  isOpen={isModalOpen}
  onClose={() => setIsModalOpen(false)}
  apiKeyName="Production Key"
  onConfirm={handleDisable}
/>
```

## Notes

- Falls back to `"this API Key"` if `apiKeyName` is not provided.
- Uses `variant="destructive"` on `ConfirmDialog`, rendering the confirm button in error/danger styling (`text-ods-error`).
- The disabled key is **not deleted** — it can be reactivated, which is surfaced to the user in the dialog description.
