A confirmation modal component for disabling/deactivating an API key, built on top of the shared `ConfirmDialog` component.

## Key Components

**`DisableApiKeyModal`** — Modal dialog that prompts the user to confirm deactivation of a specific API key.

**`DisableApiKeyModalProps`**
| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls modal visibility |
| `onClose` | `() => void` | Callback fired when the modal is dismissed |
| `apiKeyName` | `string?` | Display name of the API key being disabled |
| `onConfirm` | `() => Promise<void>` | Async callback executed on confirmation |

## Usage Example

```typescript
import { DisableApiKeyModal } from './disable-api-key-modal';

function ApiKeySettings() {
  const [isOpen, setIsOpen] = useState(false);

  const handleDisable = async () => {
    await disableApiKey(keyId);
    setIsOpen(false);
  };

  return (
    <DisableApiKeyModal
      isOpen={isOpen}
      onClose={() => setIsOpen(false)}
      apiKeyName="Production Key"
      onConfirm={handleDisable}
    />
  );
}
```

## Notes

- Uses a `destructive` variant on `ConfirmDialog`, rendering the confirm button in a danger/error style.
- Falls back to `"this API Key"` if `apiKeyName` is not provided.
- The disabled key is deactivated (not deleted) and can be reactivated later.
