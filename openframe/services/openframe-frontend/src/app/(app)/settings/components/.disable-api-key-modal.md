A confirmation modal component for disabling/deactivating an API key, built on top of the shared `ConfirmDialog` component.

## Key Components

- **`DisableApiKeyModal`** — Modal dialog that prompts the user to confirm deactivation of a named API key before proceeding
- **`DisableApiKeyModalProps`** — Interface defining the component's props:
  - `isOpen` — Controls modal visibility
  - `onClose` — Callback fired when the modal is dismissed
  - `apiKeyName` — Optional display name of the API key being disabled (falls back to `"this API Key"`)
  - `onConfirm` — Async callback executed on confirmation

## Usage Example

```typescript
import { DisableApiKeyModal } from './disable-api-key-modal';

function ApiKeySettings() {
  const [isModalOpen, setIsModalOpen] = useState(false);

  const handleDisable = async () => {
    await fetch(`/api/keys/${keyId}/disable`, { method: 'PATCH' });
    setIsModalOpen(false);
  };

  return (
    <>
      <button onClick={() => setIsModalOpen(true)}>Disable Key</button>

      <DisableApiKeyModal
        isOpen={isModalOpen}
        onClose={() => setIsModalOpen(false)}
        apiKeyName="production-key-01"
        onConfirm={handleDisable}
      />
    </>
  );
}
```

> **Note:** This is a non-destructive operation — the key is deactivated but not deleted, and can be reactivated later. The modal uses the `destructive` variant of `ConfirmDialog` to visually signal the impact of the action.
