A confirmation modal dialog for resending user invitations, built on top of the shared `ConfirmDialog` component. Displays a warning that the previous invitation will be invalidated.

## Key Components

**`ConfirmResendInvitationModal`** — Named export wrapping `ConfirmDialog` with resend-invitation-specific content:
- Highlights the target `userEmail` in warning color
- Uses `variant="warning"` styling
- Accepts an async-compatible `onConfirm` callback

**`ConfirmResendInvitationModalProps`** — Interface defining:
| Prop | Type | Description |
|------|------|-------------|
| `open` | `boolean` | Controls modal visibility |
| `onOpenChange` | `(open: boolean) => void` | Visibility toggle handler |
| `userEmail` | `string` | Email address displayed in the warning message |
| `onConfirm` | `() => Promise<void> \| void` | Callback triggered on confirmation |

## Usage Example

```typescript
import { ConfirmResendInvitationModal } from './confirm-resend-invitation-modal';

function UserManagementTable() {
  const [modalOpen, setModalOpen] = useState(false);

  const handleResend = async () => {
    await resendInvitation(selectedUser.email);
    setModalOpen(false);
  };

  return (
    <>
      <button onClick={() => setModalOpen(true)}>Resend Invite</button>

      <ConfirmResendInvitationModal
        open={modalOpen}
        onOpenChange={setModalOpen}
        userEmail="jane@example.com"
        onConfirm={handleResend}
      />
    </>
  );
}
```
