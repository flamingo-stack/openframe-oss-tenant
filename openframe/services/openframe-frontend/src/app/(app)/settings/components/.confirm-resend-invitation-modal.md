A modal dialog component that prompts the user to confirm resending an invitation email, warning that the previous invitation will be invalidated.

## Key Components

**`ConfirmResendInvitationModal`** — Wrapper around `ConfirmDialog` pre-configured for the resend invitation flow.

**`ConfirmResendInvitationModalProps`**

| Prop | Type | Description |
|------|------|-------------|
| `open` | `boolean` | Controls dialog visibility |
| `onOpenChange` | `(open: boolean) => void` | Callback to update open state |
| `userEmail` | `string` | Target email address displayed in the warning message |
| `onConfirm` | `() => Promise<void> \| void` | Async or sync handler executed on confirmation |

## Usage Example

```typescript
import { ConfirmResendInvitationModal } from './confirm-resend-invitation-modal';

function UserManagement() {
  const [open, setOpen] = useState(false);

  const handleResend = async () => {
    await resendInvitation(userId);
  };

  return (
    <ConfirmResendInvitationModal
      open={open}
      onOpenChange={setOpen}
      userEmail="jane@example.com"
      onConfirm={handleResend}
    />
  );
}
```

> The dialog renders with a `warning` variant, highlighting the target email in `text-ods-warning` styling to emphasize that the previous invitation link will be invalidated upon confirmation.
