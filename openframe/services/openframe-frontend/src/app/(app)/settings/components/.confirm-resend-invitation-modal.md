A confirmation modal component for resending user invitations, built on top of the shared `ConfirmDialog` component. Displays a warning dialog informing the admin that resending will invalidate the previous invitation.

## Key Components

**`ConfirmResendInvitationModal`** — Named export; renders a warning-styled confirm dialog scoped to the resend invitation action.

**`ConfirmResendInvitationModalProps`** — Interface defining the component's props:

| Prop | Type | Description |
|------|------|-------------|
| `open` | `boolean` | Controls dialog visibility |
| `onOpenChange` | `(open: boolean) => void` | Callback to toggle open state |
| `userEmail` | `string` | Target email highlighted in warning color |
| `onConfirm` | `() => Promise<void> \| void` | Action executed on confirmation |

## Usage Example

```typescript
import { ConfirmResendInvitationModal } from './confirm-resend-invitation-modal';

function UserManagementTable() {
  const [open, setOpen] = useState(false);

  const handleResend = async () => {
    await resendInvitation(userId);
  };

  return (
    <>
      <button onClick={() => setOpen(true)}>Resend Invite</button>
      <ConfirmResendInvitationModal
        open={open}
        onOpenChange={setOpen}
        userEmail="jane@example.com"
        onConfirm={handleResend}
      />
    </>
  );
}
```

> **Note:** Confirming the action invalidates any previously sent invitation link. The user must use the newly generated link to complete registration.
