Read-only modal component that displays detailed information and usage statistics for a selected API key record.

## Key Components

- **`ApiKeyDetailsModal`** — Main exported component that renders a `SimpleModal` with API key metadata and request statistics
- **`ApiKeyDetailsModalProps`** — Interface defining `isOpen`, `onClose`, and `apiKey` (`ApiKeyRecord | null`) props
- **`fmt`** — Internal helper that formats nullable date strings via `formatDateTime`, falling back to `'—'`

## Layout Structure

- **Header** — Key name, optional description, and active/inactive `Tag` status badge
- **Two-column grid** — Key ID, Created, Expires, Total/Successful/Failed Requests (read-only `Input` fields)
- **Full-width row** — Last Used timestamp spanning both columns

## Usage Example

```typescript
import { ApiKeyDetailsModal } from './api-key-details-modal';
import { useState } from 'react';

export function ApiKeysPage() {
  const [selectedKey, setSelectedKey] = useState<ApiKeyRecord | null>(null);

  return (
    <>
      {/* ...key list */}
      <ApiKeyDetailsModal
        isOpen={!!selectedKey}
        onClose={() => setSelectedKey(null)}
        apiKey={selectedKey}
      />
    </>
  );
}
```

> **Note:** The component returns `null` early when `apiKey` is `null`, so it is safe to pass `null` while the modal is closed without conditional rendering at the call site.
