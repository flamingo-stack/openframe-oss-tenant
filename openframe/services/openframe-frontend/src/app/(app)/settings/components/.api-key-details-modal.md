Read-only modal component that displays detailed information and usage statistics for a selected API key record.

## Key Components

- **`ApiKeyDetailsModal`** — Main export; renders a `SimpleModal` with structured API key metadata and request statistics
- **`ApiKeyDetailsModalProps`** — Interface defining `isOpen`, `onClose`, and the nullable `ApiKeyRecord` to display
- **`fmt`** — Internal helper that formats nullable date strings using `formatDateTime`, falling back to `'—'`

## Layout Structure

| Section | Fields |
|---|---|
| Header row | Name, description, enabled status tag |
| Two-column grid | Key ID, Created, Expires, Total Requests, Successful Requests, Failed Requests |
| Full-width row | Last Used |

All fields render as disabled `Input` components, making the modal strictly read-only.

## Usage Example

```typescript
import { ApiKeyDetailsModal } from './api-key-details-modal';

function ApiKeysPage() {
  const [selectedKey, setSelectedKey] = useState<ApiKeyRecord | null>(null);

  return (
    <ApiKeyDetailsModal
      isOpen={selectedKey !== null}
      onClose={() => setSelectedKey(null)}
      apiKey={selectedKey}
    />
  );
}
```

> **Note:** The component returns `null` early when `apiKey` is `null`, so it is safe to pass a null record while the modal is closed without unmounting the component.
