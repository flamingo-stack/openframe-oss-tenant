Read-only modal component that displays detailed information and usage statistics for a single API key record.

## Key Components

- **`ApiKeyDetailsModal`** — Main export; a `SimpleModal`-based dialog accepting `isOpen`, `onClose`, and an `ApiKeyRecord | null` prop
- **`ApiKeyDetailsModalProps`** — Interface defining the component's props contract
- **`fmt`** — Internal helper that formats nullable date strings via `formatDateTime`, falling back to `'—'`

## Usage Example

```typescript
import { ApiKeyDetailsModal } from './api-key-details-modal';
import { useApiKeys } from '../hooks/use-api-keys';

function ApiKeysPage() {
  const [selectedKey, setSelectedKey] = useState<ApiKeyRecord | null>(null);

  return (
    <>
      <ApiKeyDetailsModal
        isOpen={!!selectedKey}
        onClose={() => setSelectedKey(null)}
        apiKey={selectedKey}
      />
    </>
  );
}
```

## Displayed Fields

| Field | Layout |
|---|---|
| Name, Description, Status badge | Full-width header row |
| Key ID, Created | 2-column |
| Expires, Total Requests | 2-column |
| Successful Requests, Failed Requests | 2-column |
| Last Used | Full-width (`col-span-2`) |

All fields render as **disabled `Input`** components — the modal is purely informational with no edit capability. The component renders `null` early when `apiKey` is `null`, making it safe to mount unconditionally.
