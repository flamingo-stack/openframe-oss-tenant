Renders the API Keys settings page by wrapping the `ApiKeysTab` component as a Next.js App Router page with forced dynamic rendering.

## Key Components

- **`ApiKeysPage`** — Default export; a client-side page component that renders the `ApiKeysTab` UI
- **`dynamic = 'force-dynamic'`** — Next.js route segment config that disables static generation, ensuring the page is always server-rendered per request

## Usage Example

```typescript
// Accessed via the /settings/api-keys route (or equivalent)
// No props required — rendered automatically by Next.js routing

import ApiKeysPage from './page';

// Next.js renders this automatically when the route is matched
<ApiKeysPage />
```
