A Next.js page component that renders the API Keys management interface.

## Key Components

- **`ApiKeysPage`** — Default page export that wraps the `ApiKeysTab` component, marked as a Client Component with forced dynamic rendering.

## Usage Example

```typescript
// Accessed via the /api-keys route (or equivalent segment in the app directory)
// No props required — renders ApiKeysTab directly

export default function ApiKeysPage() {
  return <ApiKeysTab />;
}
```

## Notes

- `'use client'` — designates this as a Client Component in the Next.js App Router.
- `dynamic = 'force-dynamic'` — disables static generation, ensuring the page is always server-rendered at request time (useful for auth-sensitive or real-time data pages).
- Delegates all rendering logic to `ApiKeysTab`, keeping the page layer thin.
