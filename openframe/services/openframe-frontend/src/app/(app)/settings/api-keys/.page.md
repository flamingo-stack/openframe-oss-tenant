A minimal Next.js page component that renders the API Keys management interface.

## Key Components

- **`ApiKeysPage`** — Default export; a client-side page component that delegates rendering to `ApiKeysTab`.
- **`dynamic`** — Exported constant forcing Next.js to disable static generation for this route, ensuring the page is always server-rendered on demand.

## Usage Example

```typescript
// Accessed via its Next.js file-system route (e.g., /settings/api-keys)
// No direct instantiation needed — Next.js handles routing automatically.

// The page simply mounts the ApiKeysTab component:
export default function ApiKeysPage() {
  return <ApiKeysTab />;
}
```

> This page uses `'use client'` with `force-dynamic` to ensure API key data is never cached or statically pre-rendered.
