Renders the Employees page by delegating entirely to the `CompanyAndUsersTab` component. Marked as a dynamic Next.js route to disable static rendering.

## Key Components

- **`EmployeesPage`** — Default page export that renders the company and users management interface
- **`dynamic = 'force-dynamic'`** — Next.js route config export that forces server-side rendering on every request

## Usage Example

```typescript
// Accessed via Next.js file-based routing
// e.g. /employees → renders <CompanyAndUsersTab />
import EmployeesPage from './page';

// Used automatically by Next.js App Router
<EmployeesPage />
```
