Renders the Employees page by delegating to the `CompanyAndUsersTab` component. Marked as a dynamic route to ensure server-side rendering on every request.

## Key Components

- **`EmployeesPage`** – Default page export that wraps `CompanyAndUsersTab` for the `/employees` route.
- **`dynamic = 'force-dynamic'`** – Disables static caching, ensuring fresh data on each request.

## Usage Example

```typescript
// Automatically rendered by Next.js when navigating to /employees
// No props required — data fetching is handled within CompanyAndUsersTab
import EmployeesPage from './page';
```
