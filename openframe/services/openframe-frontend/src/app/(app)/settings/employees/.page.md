Renders the Employees page by delegating entirely to the `CompanyAndUsersTab` component. Marked as a dynamic (non-cached) Next.js route.

## Key Components

- **`EmployeesPage`** — Default page export; thin wrapper that renders `CompanyAndUsersTab`
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered fresh

## Usage Example

```typescript
// Automatically rendered by Next.js when navigating to the /employees route
// No props or configuration required — layout is handled by CompanyAndUsersTab
import EmployeesPage from './page';

// Used internally by Next.js App Router:
<EmployeesPage />
```
