A Next.js page component that renders the SSO (Single Sign-On) configuration interface.

## Key Components

- **`SsoConfigurationPage`** — Default page export that renders the `SsoConfigurationTab` component
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time

## Usage Example

```typescript
// Accessed via the SSO configuration route
// Renders the full SSO configuration tab UI
<SsoConfigurationPage />
```
