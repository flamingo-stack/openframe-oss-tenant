A Next.js client-side page component that renders the SSO (Single Sign-On) configuration interface.

## Key Components

- **`SsoConfigurationPage`** — Default page export that wraps the `SsoConfigurationTab` component
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time

## Usage Example

```typescript
// Rendered automatically by Next.js when navigating to the SSO configuration route.
// No direct instantiation needed — Next.js handles page routing.

// The page delegates all rendering to:
import { SsoConfigurationTab } from '../components/tabs/sso-configuration';
```

> This page acts as a thin route wrapper. All SSO configuration UI logic lives in `SsoConfigurationTab`.
