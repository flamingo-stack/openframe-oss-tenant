A Next.js page component that renders the SSO (Single Sign-On) configuration interface.

## Key Components

- **`SsoConfigurationPage`** — Default page export that wraps the `SsoConfigurationTab` component
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time

## Usage Example

```typescript
// Rendered automatically by Next.js App Router
// Route: /settings/sso (or equivalent based on directory structure)

import SsoConfigurationPage from './page';

// Used internally by Next.js — no manual instantiation needed
<SsoConfigurationPage />
```

> This page delegates all rendering logic to `SsoConfigurationTab`, keeping the route entry point minimal and focused solely on routing concerns.
