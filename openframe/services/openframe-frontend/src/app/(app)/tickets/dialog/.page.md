Async Next.js page component that resolves search parameters and renders the ticket details view for a given ticket ID, redirecting to `/tickets` if no ID is provided.

## Key Components

- **`TicketDetailsPage`** — Async server component that awaits `searchParams`, extracts the `id` query parameter, and conditionally redirects or renders the detail view.
- **`dynamic = 'force-dynamic'`** — Disables static generation to support `useSearchParams` usage within `AppLayout`.
- **`TicketDetailsView`** — Client component receiving the resolved `ticketId` prop.

## Usage Example

```typescript
// Accessed via: /tickets/details?id=TICKET-123
// Renders: <TicketDetailsView ticketId="TICKET-123" />

// Missing ID → redirects to /tickets
// /tickets/details (no ?id=) → redirect('/tickets')
```

```typescript
interface TicketDetailsPageProps {
  searchParams: Promise<{
    id?: string;
  }>;
}
```

> `searchParams` is typed as a `Promise` following the Next.js 15 async params API — must be awaited before access.
