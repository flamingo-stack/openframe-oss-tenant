Server-side page component that handles routing for individual ticket detail views, resolving the ticket `id` from search params and redirecting to `/tickets` if none is provided.

## Key Components

- **`TicketDetailsPage`** — Async Next.js page component that extracts `id` from `searchParams` and renders `TicketDetailsView`
- **`dynamic = 'force-dynamic'`** — Disables static rendering to support `useSearchParams` in the layout
- **`redirect('/tickets')`** — Server-side guard that redirects unauthenticated or param-less requests back to the ticket list

## Usage Example

```typescript
// Accessed via URL: /tickets/details?id=TKT-1234
// Next.js resolves searchParams and renders:
<TicketDetailsView ticketId="TKT-1234" />

// If no `id` param is present:
// /tickets/details → redirects to /tickets
```
