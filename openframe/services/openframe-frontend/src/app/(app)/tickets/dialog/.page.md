Server-side page component that resolves a ticket ID from URL search parameters and renders the ticket details view, redirecting to `/tickets` if no ID is provided.

## Key Components

- **`TicketDetailsPage`** – Async server component that awaits `searchParams`, extracts the `id` query parameter, and delegates rendering to `TicketDetailsView`
- **`dynamic = 'force-dynamic'`** – Disables static generation to support runtime `useSearchParams` usage inside `AppLayout`
- **`redirect('/tickets')`** – Next.js server-side redirect triggered when the `id` param is missing

## Usage Example

```typescript
// Accessed via URL: /tickets/details?id=TICKET-123
// searchParams resolves to: { id: 'TICKET-123' }

export default async function TicketDetailsPage({ searchParams }: TicketDetailsPageProps) {
  const params = await searchParams;
  const { id } = params; // 'TICKET-123'

  if (!id) {
    redirect('/tickets'); // fallback if no ID present
  }

  return <TicketDetailsView ticketId={id} />;
}
```

> **Note:** `searchParams` is typed as a `Promise` to align with Next.js 15's async params API — always `await` before accessing values.
