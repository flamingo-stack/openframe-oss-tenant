Zustand store managing per-side (client/admin) chat state for a ticket details view, including messages, streaming, approvals, and tool executions.

## Key Components

### Types
- **`ChatSide`** — `'client' | 'admin'`, selects which chat context to operate on
- **`SideState`** — per-side slice holding `messages`, `streaming`, `accumulator`, `tokenUsage`, and `isTyping`
- **`ApprovalStatus`** / **`ApprovalStatusMap`** — `'approved' | 'rejected'` keyed by request ID

### Internal Helpers
- **`createSideState()`** — initializes a blank `SideState` with a fresh `MessageSegmentAccumulator`
- **`produceSide()`** — immutably updates one side (`client` or `admin`) while preserving the other

### Store Actions (`useTicketDetailsStore`)

| Action | Description |
|---|---|
| `clearChatState` | Resets both sides and approval statuses |
| `setMessages` / `addMessage` / `updateMessage` / `removeMessage` | CRUD on a side's message list |
| `prependMessages` | Prepends older messages (pagination) |
| `prependWithBoundaryMerge` | Prepends messages while optionally patching a boundary message |
| `setStreamingMessage` / `updateStreamingMessageSegments` | Manages live-streaming assistant message |
| `appendSegmentsToLastAssistant` | Appends segments to the most recent assistant message, with compaction handling |
| `updateApprovalStatusInMessages` | Patches `approval_request` / `approval_batch` segments and updates `approvalStatuses` map |
| `updateToolExecutionInMessages` | Updates `tool_execution` or `approval_batch` execution state by request ID |
| `setAccumulatorCallbacks` / `resetAccumulator` | Wires approve/reject callbacks into the segment accumulator |
| `setTokenUsage` / `getTokenUsage` | Tracks token consumption per side |
| `setTypingIndicator` | Controls typing indicator visibility |
| `clearSide` | Resets a single side without touching the other |

## Usage Example

```typescript
const store = useTicketDetailsStore.getState();

// Load history for admin chat
store.setMessages('admin', fetchedMessages);

// Stream an incoming assistant reply
store.setStreamingMessage('admin', newMessage);
store.updateStreamingMessageSegments('admin', incomingSegments);

// Commit streamed message and reset
store.addMessage('admin', finalMessage);
store.setStreamingMessage('admin', null);
store.resetAccumulator('admin');

// Handle tool approval
store.setApprovalStatus('req-abc-123', 'approved');
store.updateApprovalStatusInMessages('admin', 'req-abc-123', 'approved');

// Switch tickets — wipe all state
store.clearChatState();
```
