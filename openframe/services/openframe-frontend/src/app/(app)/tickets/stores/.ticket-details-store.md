Zustand store managing per-side (client/admin) chat state for a ticket details view, including messages, streaming, approvals, tool executions, and token usage.

## Key Components

### Types
- **`ChatSide`** — `'client' | 'admin'`; identifies which chat panel is being operated on
- **`SideState`** — Per-side state shape holding `messages`, `streaming`, `accumulator`, `tokenUsage`, and `isTyping`
- **`ApprovalStatus`** / **`ApprovalStatusMap`** — Approval state per request ID (`'approved'` | `'rejected'`)

### Core Utilities
- **`createSideState()`** — Factory that returns a fresh, empty `SideState`
- **`produceSide()`** — Immutable updater helper that applies a `SideState` transform to only the targeted side, returning updated `client`/`admin` slices

### Store: `useTicketDetailsStore`
Zustand store exposing actions grouped by concern:

| Group | Key Actions |
|---|---|
| **Messages** | `setMessages`, `addMessage`, `updateMessage`, `removeMessage`, `prependMessages`, `prependWithBoundaryMerge` |
| **Streaming** | `setStreamingMessage`, `updateStreamingMessageSegments`, `appendSegmentsToLastAssistant` |
| **Approvals** | `updateApprovalStatusInMessages`, `updateToolExecutionInMessages`, `setApprovalStatus`, `mergeApprovalStatuses` |
| **Accumulator** | `setAccumulatorCallbacks`, `resetAccumulator` |
| **Token Usage** | `setTokenUsage`, `getTokenUsage` |
| **Lifecycle** | `clearChatState`, `clearSide`, `setTypingIndicator` |

## Usage Example

```typescript
const { addMessage, setStreamingMessage, setTypingIndicator } = useTicketDetailsStore();

// Add a new message to the admin chat
addMessage('admin', {
  id: 'msg-001',
  role: 'assistant',
  content: 'How can I help?',
});

// Begin a streaming response on the client side
setStreamingMessage('client', {
  id: 'stream-001',
  role: 'assistant',
  content: [],
});

// Show typing indicator
setTypingIndicator('client', true);

// Update an approval request status within messages
updateApprovalStatusInMessages('admin', 'req-abc', 'approved');
```
