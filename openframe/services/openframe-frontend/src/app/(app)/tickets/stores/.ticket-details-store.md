Zustand store managing per-side (client/admin) chat state for a ticket details view, including messages, streaming, approvals, tool executions, and token usage.

## Key Components

### Types
- **`ChatSide`** — `'client' | 'admin'`, identifies which chat panel is being operated on
- **`SideState`** — Per-side state slice holding messages, streaming message, segment accumulator, token usage, and typing indicator
- **`ApprovalStatus`** / **`ApprovalStatusMap`** — Approval state (`'approved' | 'rejected'`) keyed by request ID

### Store: `useTicketDetailsStore`

Created via Zustand `create`, exposes two parallel `SideState` slices (`client`, `admin`) plus shared approval tracking.

**Message Actions**
| Method | Description |
|---|---|
| `setMessages` | Replace all messages for a side |
| `prependMessages` | Prepend a batch of messages |
| `prependWithBoundaryMerge` | Prepend messages and optionally patch a boundary message |
| `addMessage` | Append or replace a message by ID |
| `updateMessage` | Patch a message by ID |
| `removeMessage` | Remove a message by ID |

**Streaming**
| Method | Description |
|---|---|
| `setStreamingMessage` | Set or clear the active streaming message |
| `updateStreamingMessageSegments` | Replay segments into the streaming message via accumulator |
| `appendSegmentsToLastAssistant` | Append segments to the last assistant message, with context compaction handling |

**Approvals & Tool Execution**
| Method | Description |
|---|---|
| `updateApprovalStatusInMessages` | Update approval/batch segments in messages and accumulator |
| `updateToolExecutionInMessages` | Merge tool execution results into `tool_execution` or `approval_batch` segments |
| `setApprovalStatus` / `mergeApprovalStatuses` | Manage the shared approval status map |

**Utilities**
- `setTokenUsage` / `getTokenUsage` — Per-side token usage tracking
- `setTypingIndicator` — Per-side typing state
- `clearSide` — Reset one side's state
- `clearChatState` — Reset all state (e.g. on ticket navigation)

## Usage Example

```typescript
const { setMessages, addMessage, setStreamingMessage, updateApprovalStatusInMessages } =
  useTicketDetailsStore();

// Load history for the admin chat panel
setMessages('admin', fetchedMessages);

// Append a new incoming message
addMessage('client', { id: 'msg-42', role: 'user', content: 'Hello!' });

// Begin streaming an assistant response
setStreamingMessage('admin', { id: 'stream-1', role: 'assistant', content: [] });

// Approve a pending tool request
updateApprovalStatusInMessages('admin', 'req-abc', 'approved');
```
