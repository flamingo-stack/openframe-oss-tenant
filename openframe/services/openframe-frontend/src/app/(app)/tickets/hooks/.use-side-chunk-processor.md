Drives one chat side (`client` or `admin`) of a ticket dialog by wiring NATS real-time chunk processing to the ticket details store, managing message lifecycle, streaming state, approvals, and tool executions.

## Key Components

### `useSideChunkProcessor(side, options)`
Main exported hook. Connects a `ChatSide` to `useRealtimeChunkProcessor`, routing incoming chunks into the appropriate side of the ticket details store.

**Parameters:**
- `side` — `'client' | 'admin'` — which chat pane to drive
- `options.assistantName` / `assistantType` — identity of the AI assistant
- `options.userDisplayName` — display name override for end-user messages
- `options.onApprove` / `onReject` — approval action callbacks
- `options.onMetadata` — receives model/provider metadata on stream start

**Returns:** `processChunk` function to feed raw NATS chunks into the pipeline

### `isInProgress(segments)`
Internal helper. Returns `true` if any segment in an existing assistant message represents an unfinished operation (active tool execution, pending approval request, or incomplete approval batch), used to resume streaming into an existing message rather than creating a new one.

### `incompleteState` (memo)
Reconstructs prior incomplete assistant state from the trailing assistant messages in history. Passed as `initialState` to `useRealtimeChunkProcessor` so the accumulator correctly resumes mid-stream after a page reload.

## Usage Example

```typescript
const processChunk = useSideChunkProcessor('client', {
  assistantName: 'Mingo',
  assistantType: 'MINGO',
  userDisplayName: 'Jane Doe',
  onApprove: async (requestId) => {
    await approveToolCall(requestId);
  },
  onReject: async (requestId) => {
    await rejectToolCall(requestId);
  },
  onMetadata: ({ modelDisplayName }) => {
    console.log('Model in use:', modelDisplayName);
  },
});

// Feed a raw NATS chunk into the processor
processChunk(incomingChunk);
```

> Feature flags (`featureFlags.thinking`, `featureFlags.batchApproval`) gate thinking-mode and batch approval behaviors at runtime.
