Fetches and caches ticket status transition rules using React Query, exposing the full query result for components that need to determine valid ticket status transitions.

## Key Components

- **`useTicketStatusTransitionRules`** — Custom hook that queries `ticketService.fetchTicketStatusTransitionRules()` and returns a `TicketStatusTransitionRule[]` array. Data is cached for 1 hour (`staleTime` and `gcTime` both set to `3_600_000ms`).

## Usage Example

```typescript
import { useTicketStatusTransitionRules } from './use-ticket-status-transition-rules';

function TicketStatusSelector({ currentStatus }: { currentStatus: string }) {
  const { data: rules, isLoading, error } = useTicketStatusTransitionRules();

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage error={error} />;

  const allowedTransitions = rules?.filter(
    (rule) => rule.fromStatus === currentStatus
  );

  return (
    <Select>
      {allowedTransitions?.map((rule) => (
        <Option key={rule.toStatus} value={rule.toStatus}>
          {rule.toStatus}
        </Option>
      ))}
    </Select>
  );
}
```

> **Note:** Results are aggressively cached (1 hour) since transition rules are configuration data that rarely changes. Force a refresh by invalidating the `ticketsQueryKeys.statusTransitionRules()` query key when rules are updated.
