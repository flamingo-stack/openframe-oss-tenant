Fetches and caches ticket status transition rules using React Query, providing access to the allowed state transitions for tickets.

## Key Components

- **`useTicketStatusTransitionRules`** — Custom hook that queries `ticketService.fetchTicketStatusTransitionRules()` and returns the full React Query result object containing an array of `TicketStatusTransitionRule` items.
- **Cache config** — Both `staleTime` and `gcTime` are set to 1 hour (3,600,000 ms), since transition rules rarely change.

## Usage Example

```typescript
import { useTicketStatusTransitionRules } from './use-ticket-status-transition-rules';

function TicketStatusSelector() {
  const { data: rules, isLoading, isError } = useTicketStatusTransitionRules();

  if (isLoading) return <Spinner />;
  if (isError) return <ErrorMessage />;

  return (
    <ul>
      {rules?.map((rule) => (
        <li key={rule.id}>
          {rule.fromStatus} → {rule.toStatus}
        </li>
      ))}
    </ul>
  );
}
```
