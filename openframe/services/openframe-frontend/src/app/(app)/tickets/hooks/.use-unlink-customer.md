Provides a React mutation hook for unlinking a customer (organization) from a support ticket via GraphQL, with toast notifications and query cache invalidation on success or error.

## Key Components

- **`unlinkCustomerApi(ticketId)`** — Internal async function that sends the `UNLINK_ORGANIZATION_FROM_TICKET_MUTATION` GraphQL mutation, extracts the response, and throws on `userErrors`.
- **`useUnlinkCustomer(onSuccess?)`** — Exported React hook wrapping `useMutation` that handles the full unlink lifecycle: API call, cache invalidation for tickets and dialogs, success/error toasts, and an optional `onSuccess` callback.

## Usage Example

```typescript
import { useUnlinkCustomer } from './use-unlink-customer';

function TicketCustomerPanel({ ticketId }: { ticketId: string }) {
  const { mutate: unlinkCustomer, isPending } = useUnlinkCustomer(() => {
    console.log('Customer unlinked, closing panel...');
  });

  return (
    <button
      disabled={isPending}
      onClick={() => unlinkCustomer(ticketId)}
    >
      {isPending ? 'Unlinking...' : 'Unlink Customer'}
    </button>
  );
}
```

## Behavior Notes

- On **success**: invalidates `ticketsQueryKeys.all` and `dialogsQueryKeys.all` query caches, then fires a `success` toast and the optional callback.
- On **error**: displays a `destructive` toast with the server-returned `userErrors` message or a generic fallback.
