Provides a React mutation hook for unlinking a customer (organization) from a support ticket via GraphQL, with toast notifications and query cache invalidation on completion.

## Key Components

- **`unlinkCustomerApi(ticketId)`** — Internal async function that sends the `UNLINK_ORGANIZATION_FROM_TICKET_MUTATION` GraphQL mutation and throws on `userErrors`.
- **`useUnlinkCustomer(onSuccess?)`** — Exported hook wrapping `useMutation` that handles the full unlink lifecycle, including cache invalidation for tickets and dialogs queries and success/error toast feedback.

## Usage Example

```typescript
import { useUnlinkCustomer } from './use-unlink-customer';

function TicketCustomerPanel({ ticketId }: { ticketId: string }) {
  const { mutate: unlinkCustomer, isPending } = useUnlinkCustomer(() => {
    console.log('Customer unlinked, closing panel...');
  });

  return (
    <button
      disabled={isPending}
      onClick={() => unlinkCustomer(ticketId)}
    >
      {isPending ? 'Unlinking...' : 'Unlink Customer'}
    </button>
  );
}
```

## Behavior Notes

- On **success**: invalidates `ticketsQueryKeys.all` and `dialogsQueryKeys.all`, shows a `success` toast, then calls the optional `onSuccess` callback.
- On **error**: displays the GraphQL `userErrors` message or a generic fallback via a `destructive` toast.
