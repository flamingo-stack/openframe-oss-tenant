React Query mutation hook for unlinking a customer (organization) from a support ticket via GraphQL, with toast notifications and query cache invalidation on success or error.

## Key Components

- **`unlinkCustomerApi(ticketId)`** — Internal async function that posts the `UNLINK_ORGANIZATION_FROM_TICKET_MUTATION` GraphQL mutation, extracts the response, and throws on `userErrors`.
- **`useUnlinkCustomer(onSuccess?)`** — Exported hook wrapping `useMutation` that handles the full unlink lifecycle: API call, cache invalidation (`ticketsQueryKeys.all`, `dialogsQueryKeys.all`), success/error toast feedback, and an optional `onSuccess` callback.

## Usage Example

```typescript
import { useUnlinkCustomer } from './use-unlink-customer';

function TicketCustomerPanel({ ticketId }: { ticketId: string }) {
  const { mutate: unlinkCustomer, isPending } = useUnlinkCustomer(() => {
    console.log('Customer unlinked, closing panel...');
  });

  return (
    <button
      disabled={isPending}
      onClick={() => unlinkCustomer(ticketId)}
    >
      {isPending ? 'Unlinking...' : 'Unlink Customer'}
    </button>
  );
}
```

## Behavior Notes

| Event | Behavior |
|-------|----------|
| **Success** | Invalidates tickets + dialogs query cache, shows success toast, calls `onSuccess?.()` |
| **API `userErrors`** | Throws with the first error message before reaching `onSuccess` |
| **Network/unknown error** | Shows destructive toast with error message or fallback string |
