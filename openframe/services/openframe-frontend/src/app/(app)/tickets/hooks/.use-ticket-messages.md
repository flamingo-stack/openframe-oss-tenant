Provides infinite-scroll pagination for ticket dialog messages, fetching and normalizing chat history in reverse-chronological order using React Query.

## Key Components

### `useTicketMessages(dialogId, chatType)`

Custom hook that manages paginated message fetching for a ticket dialog.

**Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| `dialogId` | `string \| null` | The target dialog/ticket ID |
| `chatType` | `ChatType` | The chat channel type (e.g. internal, client) |

**Returns:**
| Field | Type | Description |
|-------|------|-------------|
| `messages` | `Message[]` | Flattened, chronologically ordered message list |
| `rawPages` | `MessagePage[] \| undefined` | Raw paginated response pages |
| `isLoading` | `boolean` | Initial load state |
| `isFetched` | `boolean` | Whether data has been fetched at least once |
| `hasNextPage` | `boolean` | Whether older messages are available |
| `isFetchingNextPage` | `boolean` | Background page fetch in progress |
| `fetchNextPage` | `function` | Triggers loading of the next (older) page |
| `error` | `string \| null` | Error message if fetch failed |

**Behavior notes:**
- Automatically invalidates the query cache when `dialogId` or `chatType` changes
- Pages are fetched in `DESC` order (newest first) then reversed for correct chat display
- Returns empty state immediately if `dialogId` is `null`
- Cached for 30 seconds (`staleTime`)
- Page size is fixed at 50 messages per request

## Usage Example

```typescript
const {
  messages,
  isLoading,
  hasNextPage,
  fetchNextPage,
  isFetchingNextPage,
} = useTicketMessages(ticketId, 'client');

if (isLoading) return <Spinner />;

return (
  <>
    {hasNextPage && (
      <button onClick={() => fetchNextPage()} disabled={isFetchingNextPage}>
        Load older messages
      </button>
    )}
    {messages.map(msg => (
      <MessageBubble key={msg.id} message={msg} />
    ))}
  </>
);
```
