Provides infinite-scroll pagination for ticket dialog messages using React Query, fetching messages in reverse-chronological order and flattening pages into a single sorted array.

## Key Components

**`useTicketMessages(dialogId, chatType)`**
Main hook that manages paginated message fetching for a given dialog.

| Parameter | Type | Description |
|-----------|------|-------------|
| `dialogId` | `string \| null` | The dialog/ticket ID to fetch messages for |
| `chatType` | `ChatType` | Chat context type (e.g., internal, client) |

**Return values:**

| Field | Type | Description |
|-------|------|-------------|
| `messages` | `Message[]` | Flattened, chronologically ordered messages |
| `rawPages` | `MessagePage[]` | Raw paginated response pages |
| `isLoading` | `boolean` | Initial load state |
| `isFetched` | `boolean` | Whether data has been fetched at least once |
| `hasNextPage` | `boolean` | Whether older messages are available |
| `isFetchingNextPage` | `boolean` | Pagination fetch in progress |
| `fetchNextPage` | `function` | Triggers loading the next page |
| `error` | `string \| null` | Error message if fetch failed |

**Behavior notes:**
- Queries are invalidated automatically when `dialogId` or `chatType` changes
- Fetches 50 messages per page, sorted `DESC` by `createdAt`
- Pages are reversed and flattened so the output array reads oldest → newest
- Query is disabled when `dialogId` is `null`
- Cache stays fresh for 30 seconds (`staleTime`)

## Usage Example

```typescript
function TicketChat({ ticketId }: { ticketId: string }) {
  const {
    messages,
    isLoading,
    hasNextPage,
    isFetchingNextPage,
    fetchNextPage,
  } = useTicketMessages(ticketId, 'client');

  if (isLoading) return <Spinner />;

  return (
    <>
      {hasNextPage && (
        <button onClick={() => fetchNextPage()} disabled={isFetchingNextPage}>
          Load older messages
        </button>
      )}
      {messages.map(msg => (
        <MessageBubble key={msg.id} message={msg} />
      ))}
    </>
  );
}
```
