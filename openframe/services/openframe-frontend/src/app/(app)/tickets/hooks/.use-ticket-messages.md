Provides paginated, cursor-based message fetching for a ticket dialog using React Query's infinite query pattern, with automatic cache invalidation when the dialog or chat type changes.

## Key Components

- **`useTicketMessages(dialogId, chatType)`** — Main hook that manages infinite-scroll message loading for a given dialog
- **Cache invalidation** — `useEffect` triggers `invalidateQueries` whenever `dialogId` or `chatType` changes, ensuring fresh data on context switches
- **`messagesQuery`** — `useInfiniteQuery` instance fetching 50 messages per page, sorted by `createdAt DESC`, with a 30-second stale time
- **`messages`** — Memoized flat array of `Message` objects with pages and per-page messages reversed to produce chronological order (oldest → newest)

## Usage Example

```typescript
import { useTicketMessages } from './use-ticket-messages';
import { ChatType } from '../constants';

function TicketChat({ dialogId }: { dialogId: string }) {
  const {
    messages,
    isLoading,
    hasNextPage,
    isFetchingNextPage,
    fetchNextPage,
    error,
  } = useTicketMessages(dialogId, ChatType.Support);

  if (isLoading) return <Spinner />;
  if (error) return <ErrorBanner message={error} />;

  return (
    <>
      {hasNextPage && (
        <button onClick={() => fetchNextPage()} disabled={isFetchingNextPage}>
          Load older messages
        </button>
      )}
      {messages.map(msg => (
        <MessageBubble key={msg.id} message={msg} />
      ))}
    </>
  );
}
```

## Return Values

| Property | Type | Description |
|---|---|---|
| `messages` | `Message[]` | Flat, chronologically ordered message list |
| `rawPages` | `MessagePage[]` | Raw paginated response pages |
| `isLoading` | `boolean` | Initial load state |
| `isFetched` | `boolean` | Whether query has completed at least once |
| `hasNextPage` | `boolean` | More pages available to fetch |
| `isFetchingNextPage` | `boolean` | Background page fetch in progress |
| `fetchNextPage` | `function` | Trigger next page load |
| `error` | `string \| null` | Error message if query failed |
