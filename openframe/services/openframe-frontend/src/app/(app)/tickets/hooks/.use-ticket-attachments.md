Provides a React hook for downloading ticket attachments via a GraphQL-powered presigned URL flow, with built-in error toast notifications.

## Key Components

- **`useDownloadTicketAttachment`** — Custom hook that exposes a `download(attachmentId, fileName)` function. Internally it:
  1. Fetches a presigned download URL via the `GET_TICKET_ATTACHMENT_DOWNLOAD_URL` GraphQL query
  2. Fetches the file blob from that URL
  3. Programmatically triggers a browser download using a temporary anchor element
  4. Revokes the object URL after use to prevent memory leaks
  5. Surfaces any failure via a destructive toast notification

## Usage Example

```typescript
import { useDownloadTicketAttachment } from './use-ticket-attachments';

function TicketAttachmentItem({ id, name }: { id: string; name: string }) {
  const { download } = useDownloadTicketAttachment();

  return (
    <button onClick={() => download(id, name)}>
      Download {name}
    </button>
  );
}
```

## Notes

- Requires `apiClient` to be configured and authenticated before calling `download`
- The GraphQL query (`GET_TICKET_ATTACHMENT_DOWNLOAD_URL`) is expected to return a short-lived presigned URL under `ticketAttachmentDownloadUrl`
- Toast feedback is handled automatically — no additional error handling is needed at the call site
