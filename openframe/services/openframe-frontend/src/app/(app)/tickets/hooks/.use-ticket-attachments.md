Provides a React hook for downloading ticket attachments via a GraphQL-backed presigned URL, triggering a browser file download.

## Key Components

- **`useDownloadTicketAttachment`** — Custom hook that returns a `download` function to fetch and save a ticket attachment to the user's device.
- **`download(attachmentId, fileName)`** — Async callback that:
  1. Queries `GET_TICKET_ATTACHMENT_DOWNLOAD_URL` via GraphQL to retrieve a presigned download URL
  2. Fetches the file as a `Blob`
  3. Creates a temporary `<a>` element to trigger the browser's native download
  4. Cleans up the object URL after download
  5. Displays a destructive toast notification on failure

## Usage Example

```typescript
import { useDownloadTicketAttachment } from './use-ticket-attachments';

function AttachmentItem({ id, name }: { id: string; name: string }) {
  const { download } = useDownloadTicketAttachment();

  return (
    <button onClick={() => download(id, name)}>
      Download {name}
    </button>
  );
}
```

## Error Handling

Errors are surfaced non-disruptively via a `destructive` toast — covering missing URLs, network failures, and unexpected exceptions — without throwing to the caller.
