Provides a React hook for downloading ticket attachments via a GraphQL-backed presigned URL, handling blob creation and browser-triggered file download.

## Key Components

- **`useDownloadTicketAttachment`** — Custom hook that returns a `download` function to fetch and trigger a browser file download for a given ticket attachment.
- **`download(attachmentId, fileName)`** — Resolves a presigned download URL via the `GET_TICKET_ATTACHMENT_DOWNLOAD_URL` GraphQL query, fetches the file as a blob, creates a temporary anchor element to trigger the download, then revokes the object URL to free memory.
- **Error handling** — Catches failures at both the URL resolution and file fetch stages, surfacing a destructive toast notification via `useToast`.

## Usage Example

```typescript
import { useDownloadTicketAttachment } from './use-ticket-attachments';

function AttachmentItem({ id, name }: { id: string; name: string }) {
  const { download } = useDownloadTicketAttachment();

  return (
    <button onClick={() => download(id, name)}>
      Download {name}
    </button>
  );
}
```

## Notes

- Requires the `apiClient` to be authenticated; unauthenticated requests will fail at the GraphQL layer before a URL is returned.
- The `download` callback is memoized with `useCallback` — safe to pass as a prop without causing unnecessary re-renders.
- Object URLs are always revoked after the download is triggered to prevent memory leaks.
