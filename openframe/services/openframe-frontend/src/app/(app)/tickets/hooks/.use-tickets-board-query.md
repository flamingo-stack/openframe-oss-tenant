Manages infinite-scroll paginated data fetching for a Kanban-style ticket board, providing per-column query state for each `BoardStatus` using TanStack Query.

## Key Components

- **`BOARD_PAGE_SIZE`** — Constant defining 20 tickets per page fetch
- **`BOARD_STATUSES`** — Readonly tuple of the four board columns: `ACTIVE`, `TECH_REQUIRED`, `ON_HOLD`, `RESOLVED`
- **`BoardColumnState`** — Shape of each column's state: tickets array, total count, cursor, pagination flags
- **`BoardColumnsState`** — Record mapping every `BoardStatus` to its `BoardColumnState`
- **`useBoardColumnQuery`** — Internal hook wrapping `useInfiniteQuery` per status; polls every 5s, stale after 60s, retries twice on error
- **`toColumnState`** — Utility that flattens paginated pages into a single `BoardColumnState` object
- **`useTicketsBoardQuery`** — Primary exported hook; composes all four column queries, exposes `loadMore`, `refetch`, unified `isLoading`, and surfaces the first error via a destructive toast

## Usage Example

```typescript
import { useTicketsBoardQuery } from './use-tickets-board-query';

function TicketsBoard() {
  const { columns, loadMore, refetch, isLoading, error } = useTicketsBoardQuery({
    search: 'network',
    organizationIds: ['org-123'],
    assigneeIds: ['user-456'],
  });

  if (isLoading) return <BoardSkeleton />;

  return (
    <>
      {BOARD_STATUSES.map(status => (
        <BoardColumn
          key={status}
          tickets={columns[status].tickets}
          total={columns[status].total}
          hasMore={columns[status].hasMore}
          isLoadingMore={columns[status].isLoadingMore}
          onLoadMore={() => loadMore(status)}
        />
      ))}
    </>
  );
}
```
