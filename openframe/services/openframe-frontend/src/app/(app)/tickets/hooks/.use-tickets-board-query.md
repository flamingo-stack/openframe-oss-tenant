Manages infinite-scroll paginated data fetching for the ticket board view, providing per-column query state for each `BoardStatus` using TanStack Query.

## Key Components

- **`BOARD_PAGE_SIZE`** — Page size constant (`20`) used for all board column queries
- **`BOARD_STATUSES`** — Readonly tuple of valid board statuses: `ACTIVE`, `TECH_REQUIRED`, `ON_HOLD`, `RESOLVED`
- **`BoardColumnState`** — Interface describing a single column's resolved state (tickets, pagination info, loading state)
- **`BoardColumnsState`** — Record mapping each `BoardStatus` to its `BoardColumnState`
- **`useBoardColumnQuery`** *(internal)* — Per-column infinite query with 15s refetch interval, 60s stale time, and cursor-based pagination
- **`toColumnState`** *(internal)* — Flattens paginated `InfiniteData` pages into a single `BoardColumnState` object
- **`useTicketsBoardQuery`** — Primary exported hook; composes all four column queries, exposes `loadMore`, `refetch`, error toasts, and unified loading state

## Usage Example

```typescript
import { useTicketsBoardQuery } from './use-tickets-board-query';

function TicketBoard() {
  const { columns, loadMore, refetch, isLoading, error } = useTicketsBoardQuery({
    search: 'network issue',
    organizationIds: ['org-123'],
    assigneeIds: ['user-456'],
  });

  const activeColumn = columns['ACTIVE'];
  // { tickets: Dialog[], total: number, hasMore: boolean, isLoadingMore: boolean }

  return (
    <BoardColumn
      tickets={activeColumn.tickets}
      onLoadMore={() => loadMore('ACTIVE')}
      hasMore={activeColumn.hasMore}
    />
  );
}
```

Each column polls independently every **15 seconds** and supports infinite scroll via `loadMore(columnId)`. Errors surface automatically as destructive toasts via the `useToast` hook.
