React Query hook for fetching and caching a single ticket's full dialog/detail data by ID.

## Key Components

- **`useTicketDetail(ticketId)`** — Custom hook wrapping `useQuery` to fetch a `Dialog` object from `ticketService.fetchDialog`, with a 30-second stale time. Query is disabled when `ticketId` is falsy.

## Usage Example

```typescript
const { ticket, isPending, error, refetch } = useTicketDetail(ticketId);

if (isPending) return <Spinner />;
if (error) return <ErrorMessage error={error} />;
if (!ticket) return null;

return <TicketDetailView ticket={ticket} onRefresh={refetch} />;
```

## Return Value

| Field | Type | Description |
|---|---|---|
| `ticket` | `Dialog \| null` | Fetched ticket detail, or `null` if unavailable |
| `isPending` | `boolean` | True while the request is in-flight |
| `error` | `Error \| null` | Query error, if any |
| `refetch` | `function` | Manually re-trigger the fetch |
