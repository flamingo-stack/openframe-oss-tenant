React Query hook for fetching a single ticket's full dialog details, with built-in null safety and a 30-second stale time.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `useTicketDetail` | Hook | Fetches a `Dialog` object for a given ticket ID |

**Return values:**

| Property | Type | Description |
|----------|------|-------------|
| `ticket` | `Dialog \| null` | The fetched ticket dialog, or `null` if unavailable |
| `isPending` | `boolean` | `true` while the request is in-flight |
| `error` | `Error \| null` | Any fetch error |
| `refetch` | `function` | Manually re-triggers the query |

## Usage Example

```typescript
import { useTicketDetail } from './use-ticket-detail';

function TicketPanel({ ticketId }: { ticketId: string | null }) {
  const { ticket, isPending, error, refetch } = useTicketDetail(ticketId);

  if (isPending) return <Spinner />;
  if (error) return <ErrorBanner onRetry={refetch} message={error.message} />;
  if (!ticket) return null;

  return <DialogView dialog={ticket} />;
}
```

## Behavior Notes

- **Disabled when no ID** — query does not fire if `ticketId` is `null` or `undefined`
- **Stable cache key** — uses `ticketsQueryKeys.detail(ticketId)` for consistency; falls back to a `__none__` sentinel to avoid key conflicts when ID is absent
- **Stale time** — cached data is considered fresh for 30 seconds, reducing redundant network calls
