React Query hook for fetching a single ticket's full dialog/detail data, with built-in caching and a 30-second stale window.

## Key Components

- **`useTicketDetail(ticketId)`** — Main exported hook that wraps `useQuery` to fetch a `Dialog` object for a given ticket ID
- **`ticketService.fetchDialog`** — Underlying service call used as the query function
- **`ticketsQueryKeys.detail`** — Generates a consistent cache key for the ticket detail query
- **`enabled: !!ticketId`** — Prevents fetching when `ticketId` is `null` or `undefined`
- **`staleTime: 30_000`** — Caches results for 30 seconds before treating them as stale

## Usage Example

```typescript
import { useTicketDetail } from '@/features/tickets/hooks/use-ticket-detail';

function TicketDetailPanel({ ticketId }: { ticketId: string | null }) {
  const { ticket, isPending, error, refetch } = useTicketDetail(ticketId);

  if (isPending) return <Spinner />;
  if (error) return <ErrorMessage message={error.message} onRetry={refetch} />;
  if (!ticket) return null;

  return <DialogView dialog={ticket} />;
}
```

## Return Value

| Field | Type | Description |
|-------|------|-------------|
| `ticket` | `Dialog \| null` | Fetched ticket dialog, or `null` if unavailable |
| `isPending` | `boolean` | `true` while the request is in-flight |
| `error` | `Error \| null` | Any fetch error, otherwise `null` |
| `refetch` | `function` | Manually re-triggers the query |
