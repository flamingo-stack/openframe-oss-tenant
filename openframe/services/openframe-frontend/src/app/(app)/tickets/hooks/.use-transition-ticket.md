React Query mutation hook for transitioning a ticket's status, handling cache invalidation and toast notifications on success or failure.

## Key Components

- **`TransitionTicketInput`** — Interface defining the mutation payload: `ticketId` (string) and `toStatusId` (string)
- **`useTransitionTicket`** — Custom hook that wraps `useMutation` to call `ticketService.transitionTicket`, invalidate relevant queries, and display feedback toasts

## Usage Example

```typescript
import { useTransitionTicket } from '../hooks/use-transition-ticket';

function TicketStatusButton({ ticketId, toStatusId }: TransitionTicketInput) {
  const { mutate, isPending } = useTransitionTicket();

  return (
    <button
      disabled={isPending}
      onClick={() => mutate({ ticketId, toStatusId })}
    >
      Update Status
    </button>
  );
}
```

## Behavior

| Event | Action |
|-------|--------|
| **Success** | Invalidates `ticketsQueryKeys.detail(ticketId)` + all dialogs, shows `"Status updated"` success toast |
| **Error** | Shows destructive toast with error message (5s duration), falls back to `"Failed to update status"` |
