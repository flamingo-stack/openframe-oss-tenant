React Query mutation hook for transitioning a ticket's status, with automatic cache invalidation and toast notifications on success or error.

## Key Components

- **`TransitionTicketInput`** — Input interface requiring `ticketId` (string) and `toStatusId` (string)
- **`useTransitionTicket`** — Custom hook wrapping `useMutation` that calls `ticketService.transitionTicket`, invalidates the ticket detail query and all dialog queries on success, and displays toast feedback

## Usage Example

```typescript
import { useTransitionTicket } from '../hooks/use-transition-ticket';

function TicketStatusButton({ ticketId, toStatusId }: TransitionTicketInput) {
  const { mutate: transitionTicket, isPending } = useTransitionTicket();

  return (
    <button
      disabled={isPending}
      onClick={() => transitionTicket({ ticketId, toStatusId })}
    >
      Move to Next Status
    </button>
  );
}
```

## Behavior

| Event | Action |
|-------|--------|
| Success | Invalidates `ticketsQueryKeys.detail(ticketId)` + all dialogs, shows `"Status updated"` success toast |
| Error | Shows `"Failed to update status"` destructive toast with the error message (5s duration) |
