React Query mutation hook that archives all resolved tickets via a GraphQL API call, with optimistic UI updates and toast notifications.

## Key Components

- **`useArchiveResolvedMutation`** — Primary export; wraps `useMutation` to handle the full archive lifecycle
- **`ArchiveResolvedPayload`** — Internal interface typing the GraphQL response shape (`count` + `userErrors`)
- **Optimistic update** (`onMutate`) — Cancels in-flight dialog list queries and immediately filters out `RESOLVED` dialogs from cached pages before the server responds
- **Rollback** (`onError`) — Restores all previously cached query data if the mutation fails, then shows a destructive toast
- **Success handler** (`onSuccess`) — Displays a pluralized success toast with the archived ticket count
- **Settlement handler** (`onSettled`) — Invalidates all dialog lists and ticket statistics queries regardless of outcome

## Usage Example

```typescript
import { useArchiveResolvedMutation } from './use-archive-resolved-mutation';

function ArchiveButton() {
  const { mutate: archiveResolved, isPending } = useArchiveResolvedMutation();

  return (
    <button
      onClick={() => archiveResolved()}
      disabled={isPending}
    >
      {isPending ? 'Archiving...' : 'Archive Resolved Tickets'}
    </button>
  );
}
```

> **Note:** This hook relies on `dialogsQueryKeys.lists()` for optimistic cache manipulation. Ensure all dialog list queries use consistent query keys so the rollback covers every affected cache entry.
