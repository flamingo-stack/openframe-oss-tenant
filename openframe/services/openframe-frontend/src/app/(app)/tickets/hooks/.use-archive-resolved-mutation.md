React Query mutation hook that archives all resolved tickets via GraphQL, with optimistic UI updates and toast notifications.

## Key Components

- **`useArchiveResolvedMutation`** — Primary export; wraps `useMutation` to handle the full archive-resolved-tickets lifecycle
- **`ArchiveResolvedPayload`** — Internal interface typing the GraphQL response shape (`count` + `userErrors`)
- **Optimistic update** (`onMutate`) — Cancels in-flight dialog list queries and immediately filters out `RESOLVED` dialogs from cached pages before the server responds
- **Rollback** (`onError`) — Restores all previously cached query snapshots if the mutation fails, then displays a destructive toast
- **Success handler** (`onSuccess`) — Shows a pluralized success toast reporting how many tickets were archived
- **Settlement handler** (`onSettled`) — Invalidates all dialog lists and ticket statistics queries to sync server state regardless of outcome

## Usage Example

```typescript
import { useArchiveResolvedMutation } from './use-archive-resolved-mutation';

function ArchiveButton() {
  const { mutate: archiveResolved, isPending } = useArchiveResolvedMutation();

  return (
    <button
      onClick={() => archiveResolved()}
      disabled={isPending}
    >
      {isPending ? 'Archiving...' : 'Archive All Resolved'}
    </button>
  );
}
```

> **Note:** This hook requires `QueryClientProvider` and `ToastProvider` in the component tree. The optimistic update assumes paginated dialog data shaped as `{ pages: [{ dialogs: Dialog[] }] }`.
