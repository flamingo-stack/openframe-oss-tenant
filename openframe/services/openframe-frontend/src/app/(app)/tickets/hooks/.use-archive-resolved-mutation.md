React Query mutation hook that archives all resolved tickets via a GraphQL API call, with optimistic UI updates and toast notifications.

## Key Components

- **`useArchiveResolvedMutation`** — Primary export; wraps `useMutation` to handle the full archive lifecycle
- **`ArchiveResolvedPayload`** — Internal interface describing the GraphQL response shape, including `count` and `userErrors`
- **Optimistic update** (`onMutate`) — Immediately filters out `RESOLVED` dialogs from all cached list queries before the server responds
- **Rollback** (`onError`) — Restores previous query cache state if the mutation fails, then shows a destructive toast
- **Success handler** (`onSuccess`) — Displays a pluralized success toast with the archived ticket count
- **Settled handler** (`onSettled`) — Invalidates all dialog queries and ticket statistics regardless of outcome, ensuring cache consistency

## Usage Example

```typescript
import { useArchiveResolvedMutation } from './use-archive-resolved-mutation';

function ArchiveButton() {
  const { mutate, isPending } = useArchiveResolvedMutation();

  return (
    <button
      onClick={() => mutate()}
      disabled={isPending}
    >
      {isPending ? 'Archiving...' : 'Archive Resolved Tickets'}
    </button>
  );
}
```

> **Note:** This hook requires `QueryClientProvider` and `ToastProvider` to be present in the component tree. The mutation takes no arguments — it archives **all** resolved tickets in a single operation.
