React Query mutation hook for assigning or unassigning a technician to a ticket via GraphQL, with automatic cache invalidation and toast notifications on success or failure.

## Key Components

- **`assignTicketApi`** — Internal async function that dispatches either `ASSIGN_TICKET_MUTATION` or `UNASSIGN_TICKET_MUTATION` based on whether `assigneeId` is `null`. Throws on GraphQL `userErrors`.
- **`useAssignTicket`** — Exported React Query `useMutation` hook that wraps `assignTicketApi`, invalidates `tickets` and `dialogs` query caches on success, and surfaces toast feedback.
- **`AssignTicketParams`** — Interface defining `ticketId: string` and `assigneeId: string | null` (null triggers unassign).

## Usage Example

```typescript
import { useAssignTicket } from './use-assign-ticket';

function TicketAssignButton({ ticketId, assigneeId }: { ticketId: string; assigneeId: string | null }) {
  const { mutate: assignTicket, isPending } = useAssignTicket();

  return (
    <button
      disabled={isPending}
      onClick={() => assignTicket({ ticketId, assigneeId })}
    >
      {assigneeId ? 'Assign Ticket' : 'Unassign Ticket'}
    </button>
  );
}
```

> Pass `assigneeId: null` to unassign the current technician from the ticket. The hook automatically invalidates both `ticketsQueryKeys.all` and `dialogsQueryKeys.all` after a successful mutation, keeping list and dialog views in sync.
