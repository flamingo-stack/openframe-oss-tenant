React Query mutation hook for assigning or unassigning a ticket to/from a technician via GraphQL, with toast notifications and automatic cache invalidation on success.

## Key Components

- **`assignTicketApi`** — Internal async function that dispatches either `ASSIGN_TICKET_MUTATION` or `UNASSIGN_TICKET_MUTATION` based on whether `assigneeId` is `null`. Handles `userErrors` from the GraphQL response.
- **`useAssignTicket`** — Exported hook wrapping `useMutation`. Invalidates `ticketsQueryKeys.all` and `dialogsQueryKeys.all` caches on success and surfaces toast feedback for both success and error states.
- **`AssignTicketParams`** — Interface defining `ticketId: string` and `assigneeId: string | null` (pass `null` to unassign).

## Usage Example

```typescript
import { useAssignTicket } from './use-assign-ticket';

function AssignButton({ ticketId, technicianId }: { ticketId: string; technicianId: string | null }) {
  const { mutate: assignTicket, isPending } = useAssignTicket();

  return (
    <button
      disabled={isPending}
      onClick={() => assignTicket({ ticketId, assigneeId: technicianId })}
    >
      {technicianId ? 'Assign Technician' : 'Unassign Technician'}
    </button>
  );
}
```

> Pass `assigneeId: null` to trigger the unassign mutation — the hook handles both operations through a single interface.
