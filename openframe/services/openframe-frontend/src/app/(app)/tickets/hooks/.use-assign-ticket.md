React Query mutation hook for assigning or unassigning a ticket to a technician via GraphQL, with automatic cache invalidation and toast notifications.

## Key Components

- **`assignTicketApi`** — Internal async function that dispatches either `ASSIGN_TICKET_MUTATION` or `UNASSIGN_TICKET_MUTATION` based on whether `assigneeId` is `null`. Handles GraphQL user errors by throwing.
- **`useAssignTicket`** — Exported hook wrapping `useMutation`. On success, invalidates `tickets` and `dialogs` query caches and shows a success toast. On error, surfaces the GraphQL error message or a fallback string.

## Usage Example

```typescript
import { useAssignTicket } from './use-assign-ticket';

function TicketAssignButton({ ticketId, assigneeId }: { ticketId: string; assigneeId: string | null }) {
  const { mutate: assignTicket, isPending } = useAssignTicket();

  return (
    <button
      disabled={isPending}
      onClick={() => assignTicket({ ticketId, assigneeId })}
    >
      {assigneeId ? 'Assign Ticket' : 'Unassign Ticket'}
    </button>
  );
}
```

> Pass `assigneeId: null` to trigger the unassign flow; any non-null string triggers the assign flow.
