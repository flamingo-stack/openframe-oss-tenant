Handles sending admin messages within a ticket's chat dialog, including lazy dialog creation if one doesn't yet exist and optimistic UI updates.

## Key Components

- **`useSendAdminMessage`** — Custom hook that returns a `sendAdminMessage` function and an `isSendingAdminMessage` loading flag.
- **Lazy dialog creation** — If `messageDialogId` is `null`, a new AI-mode dialog is created via `POST` to `API_ENDPOINTS.DIALOGS` before sending the message.
- **Optimistic update** — Immediately appends a local `ChatMessage` to the `admin` chat panel via `useTicketDetailsStore.addMessage` before the server confirms delivery.
- **`onBeforeDialogCreated`** — Optional callback invoked after a new dialog is created but before the query cache is invalidated; useful for UI state resets.
- **Error handling** — Displays a destructive toast notification on mutation failure.

## Usage Example

```typescript
const { sendAdminMessage, isSendingAdminMessage } = useSendAdminMessage({
  ticketId: 'ticket-123',
  messageDialogId: existingDialogId ?? null,
  onBeforeDialogCreated: () => setDialogJustCreated(true),
});

// Send a message
sendAdminMessage('Please review the latest logs.');

// Guard the send button
<button disabled={isSendingAdminMessage} onClick={() => sendAdminMessage(inputValue)}>
  Send
</button>
```

> Calls are no-ops when `message` is blank or a send is already in flight (`isPending`), preventing duplicate submissions.
