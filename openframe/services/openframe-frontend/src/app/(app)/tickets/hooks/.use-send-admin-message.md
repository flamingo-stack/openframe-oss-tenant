Sends an admin message within a ticket's dialog, handling dialog creation on-demand, optimistic UI updates, and error notifications.

## Key Components

- **`useSendAdminMessage`** — Custom hook that returns a `sendAdminMessage` function and `isSendingAdminMessage` pending state
- **`UseSendAdminMessageOptions`** — Options interface accepting `ticketId`, `messageDialogId`, and an optional `onBeforeDialogCreated` callback
- **Dialog auto-creation** — If no `messageDialogId` exists, creates an AI-mode `CLIENT` agent dialog before sending
- **Optimistic update** — Immediately appends the message to the `admin` chat via `useTicketDetailsStore` before the API confirms
- **Error handling** — Displays a destructive toast notification on mutation failure

## Usage Example

```typescript
const { sendAdminMessage, isSendingAdminMessage } = useSendAdminMessage({
  ticketId: 'ticket-123',
  messageDialogId: existingDialogId ?? null,
  onBeforeDialogCreated: () => {
    // e.g. close a modal or reset UI state before dialog is created
  },
});

// Send a message
sendAdminMessage('Hello, this is an admin note.');

// Disable send button while pending
<button disabled={isSendingAdminMessage}>Send</button>
```

> **Note:** Calls are no-ops when the message is empty or a send is already in progress (`isSendingAdminMessage === true`). The optimistic message uses the current authenticated user's display name, falling back to `'Admin'` if unavailable.
