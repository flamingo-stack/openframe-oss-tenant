Sends an admin message to a ticket's dialog, handling dialog creation if one doesn't exist yet and appending an optimistic message to the UI immediately.

## Key Components

- **`useSendAdminMessage(options)`** — Custom hook accepting `ticketId`, `messageDialogId`, and an optional `onBeforeDialogCreated` callback
- **Dialog auto-creation** — If `messageDialogId` is `null`, creates a new AI-mode dialog via `POST /dialogs` before sending
- **Optimistic update** — Immediately appends the message to the local store via `addMessage` before the server confirms delivery
- **`sendAdminMessage(message)`** — Stable callback that trims input and guards against concurrent sends (`isPending`)
- **`isSendingAdminMessage`** — Boolean reflecting the mutation's pending state for UI feedback

## Usage Example

```typescript
import { useSendAdminMessage } from './use-send-admin-message';

function AdminMessageBox({ ticketId, dialogId }) {
  const { sendAdminMessage, isSendingAdminMessage } = useSendAdminMessage({
    ticketId,
    messageDialogId: dialogId,
    onBeforeDialogCreated: () => console.log('New dialog created'),
  });

  return (
    <button
      disabled={isSendingAdminMessage}
      onClick={() => sendAdminMessage('Hello from admin')}
    >
      {isSendingAdminMessage ? 'Sending...' : 'Send'}
    </button>
  );
}
```

> **Note:** If no `messageDialogId` is provided, the hook automatically creates an `AI`-mode dialog with `agentType: 'CLIENT'` and invalidates the ticket detail query before sending the message.
