Thin wrapper around the core `useChunkCatchup` hook that wires ticket-service chunk fetching for both client and admin chat types within a specific dialog.

## Key Components

- **`useChunkCatchup`** — React hook that initializes chunk catch-up logic for a dialog, automatically covering `CHAT_TYPE.CLIENT` and `CHAT_TYPE.ADMIN` channels
- **`UseChunkCatchupOptions`** — Local options interface requiring a `dialogId` and an `onChunkReceived` callback
- **Re-exports** — `ChunkData`, `NatsMessageType`, and `UseChunkCatchupReturn` from the core package for consumer convenience

## Usage Example

```typescript
import { useChunkCatchup } from './use-chunk-catchup';

function DialogStream({ dialogId }: { dialogId: string }) {
  const { isLoading } = useChunkCatchup({
    dialogId,
    onChunkReceived: (chunk, messageType) => {
      console.log(`[${messageType}] Received chunk:`, chunk);
    },
  });

  return isLoading ? <Spinner /> : <MessageList />;
}
```

## Notes

- `fetchChunks` is memoized with `useCallback` (no deps) since `ticketService` is a singleton
- The `options` object is memoized with `useMemo` to prevent unnecessary re-runs of the core hook
- `dialogId` accepts `null` to allow conditional/deferred initialization
