React hook that wraps the core `useChunkCatchup` hook from `@flamingo-stack/openframe-frontend-core`, wiring it to the ticket service for fetching missed AI response chunks during reconnection or catchup scenarios.

## Key Components

- **`useChunkCatchup`** — Main hook that initializes chunk catchup logic for both `CLIENT` and `ADMIN` chat types, bound to a specific dialog.
- **`fetchChunks`** — Memoized callback delegating to `ticketService.fetchChunks` to retrieve chunks from a given sequence ID.
- **`options`** — Memoized config object passed to the core hook, combining `dialogId`, `onChunkReceived`, supported chat types, and the fetch function.

### Re-exported Types

| Type | Description |
|------|-------------|
| `ChunkData` | Shape of an individual AI response chunk |
| `NatsMessageType` | NATS message type identifier |
| `UseChunkCatchupReturn` | Return type of the hook |

## Usage Example

```typescript
import { useChunkCatchup } from './use-chunk-catchup';

function TicketDialog({ dialogId }: { dialogId: string }) {
  const { startCatchup, stopCatchup } = useChunkCatchup({
    dialogId,
    onChunkReceived: (chunk, messageType) => {
      console.log('Received chunk:', chunk, 'type:', messageType);
    },
  });

  useEffect(() => {
    startCatchup();
    return () => stopCatchup();
  }, [startCatchup, stopCatchup]);
}
```

> **Note:** Pass `dialogId: null` to disable catchup — the core hook will skip initialization when no dialog is active.
