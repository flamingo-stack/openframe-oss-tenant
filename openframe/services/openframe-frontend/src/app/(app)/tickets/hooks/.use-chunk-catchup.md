Thin wrapper around the core `useChunkCatchup` hook that wires ticket-service chunk fetching for both `CLIENT` and `ADMIN` chat types in the Flamingo frontend.

## Key Components

- **`useChunkCatchup`** — Main exported hook. Accepts a `dialogId` and an `onChunkReceived` callback, then delegates to `useChunkCatchupCore` with pre-configured chat types and a `ticketService`-backed fetch function.
- **`fetchChunks`** — Memoized callback that calls `ticketService.fetchChunks` to retrieve missed chunks by `dialogId`, `chatType`, and optional `fromSequenceId`.
- **Re-exports** — `ChunkData`, `NatsMessageType`, and `UseChunkCatchupReturn` are re-exported from core for consumer convenience.

## Usage Example

```typescript
import { useChunkCatchup, type ChunkData, type NatsMessageType } from './use-chunk-catchup';

function TicketDialog({ dialogId }: { dialogId: string }) {
  const { isLoading } = useChunkCatchup({
    dialogId,
    onChunkReceived: (chunk: ChunkData, messageType: NatsMessageType) => {
      console.log('Received chunk:', chunk, messageType);
    },
  });

  return <div>{isLoading ? 'Catching up...' : 'Live'}</div>;
}
```

> **Note:** Both `CHAT_TYPE.CLIENT` and `CHAT_TYPE.ADMIN` channels are watched automatically — no additional configuration needed at the call site.
