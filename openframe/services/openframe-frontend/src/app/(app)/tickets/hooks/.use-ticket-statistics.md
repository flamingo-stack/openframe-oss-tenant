React Query hook that fetches and derives ticket statistics via a GraphQL API, exposing the resolved ticket count and loading state.

## Key Components

- **`useTicketStatistics(options?)`** — Main exported hook accepting an optional `enabled` flag to conditionally run the query
- **`resolvedCount`** — Memoized value derived from raw statistics using `resolvedCountFromStatistics`
- **`isLoading`** — Query loading state passed through from React Query
- Caches results for 60 seconds (`staleTime: 60_000`) via `ticketsQueryKeys.statistics()` cache key

## Usage Example

```typescript
import { useTicketStatistics } from './use-ticket-statistics';

function TicketDashboard() {
  const { resolvedCount, isLoading } = useTicketStatistics();

  if (isLoading) return <Spinner />;

  return <p>Resolved tickets: {resolvedCount}</p>;
}

// Conditionally fetch (e.g., only when a panel is open)
function ConditionalPanel({ isOpen }: { isOpen: boolean }) {
  const { resolvedCount } = useTicketStatistics({ enabled: isOpen });

  return <span>{resolvedCount}</span>;
}
```
