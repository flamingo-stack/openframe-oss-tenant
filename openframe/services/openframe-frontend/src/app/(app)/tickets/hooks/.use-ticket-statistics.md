React Query hook that fetches ticket statistics via GraphQL and computes a resolved ticket count from the response data.

## Key Components

- **`useTicketStatistics`** — Custom hook that queries ticket statistics and returns derived metrics
- **`TicketStatisticsResponse`** — Internal interface typing the GraphQL response shape
- **`resolvedCount`** — Memoized value derived from raw statistics via `resolvedCountFromStatistics`

## Usage Example

```typescript
import { useTicketStatistics } from './use-ticket-statistics';

function TicketDashboard() {
  const { resolvedCount, isLoading } = useTicketStatistics();

  if (isLoading) return <Spinner />;

  return <p>Resolved tickets: {resolvedCount}</p>;
}

// Conditionally enable fetching
function ConditionalStats({ isAdmin }: { isAdmin: boolean }) {
  const { resolvedCount } = useTicketStatistics({ enabled: isAdmin });

  return <p>Resolved: {resolvedCount ?? '—'}</p>;
}
```

## Behavior Notes

- **Cache TTL:** `staleTime` is set to `60_000ms` (1 minute), limiting unnecessary refetches
- **Conditional fetching:** Pass `enabled: false` to defer the query (e.g., based on permissions or component readiness)
- **`resolvedCount`** is memoized and recalculates only when `ticketStatistics` data changes
