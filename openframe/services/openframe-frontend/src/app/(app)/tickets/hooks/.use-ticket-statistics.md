Fetches and computes ticket statistics via GraphQL, exposing the count of resolved tickets with React Query caching.

## Key Components

- **`useTicketStatistics`** — Custom hook that queries the GraphQL endpoint for ticket status counts and returns a derived `resolvedCount` value
- **`StatusCount`** — Interface representing a `{ status, count }` pair from the API response
- **`TicketStatisticsResponse`** — Interface typing the raw GraphQL response shape

## Behavior

- Uses `ticketsQueryKeys.statistics()` as the React Query cache key with a 60-second `staleTime`
- Accepts an optional `enabled` flag to conditionally suspend the query
- Derives `resolvedCount` via `useMemo` by filtering `statusCounts` for entries where `status === 'RESOLVED'`

## Usage Example

```typescript
import { useTicketStatistics } from './use-ticket-statistics';

function TicketDashboard() {
  const { resolvedCount, isLoading } = useTicketStatistics();

  if (isLoading) return <Spinner />;

  return <p>{resolvedCount} tickets resolved</p>;
}

// Conditionally disable fetching
function ConditionalWidget({ isVisible }: { isVisible: boolean }) {
  const { resolvedCount } = useTicketStatistics({ enabled: isVisible });

  return <span>{resolvedCount}</span>;
}
```

## Returns

| Field | Type | Description |
|-------|------|-------------|
| `resolvedCount` | `number` | Count of tickets with `RESOLVED` status; defaults to `0` |
| `isLoading` | `boolean` | `true` while the query is in-flight |
