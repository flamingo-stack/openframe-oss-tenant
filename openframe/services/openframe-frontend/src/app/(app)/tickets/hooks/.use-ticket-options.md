Provides React Query hooks for fetching autocomplete and avatar dropdown options used in ticket forms, covering organizations, devices, assignees, and labels.

## Key Components

### Interfaces
- **`AutocompleteOption`** — Base option shape with `label` and `value` strings
- **`AvatarOption`** — Extends `AutocompleteOption` with an optional `imageUrl` for avatar display

### Hooks
| Hook | Source | Returns |
|------|--------|---------|
| `useOrganizationOptions(search?)` | `/api/graphql` (organizations) | `AvatarOption[]` |
| `useDeviceOptions(organizationId?, search?)` | `/api/graphql` (devices) | `AutocompleteOption[]` |
| `useAssigneeOptions()` | `/api/users` (REST) | `AvatarOption[]` |
| `useTicketLabelOptions()` | `/chat/graphql` (ticket labels) | `AutocompleteOption[]` |

> **Note:** `useDeviceOptions` is disabled when no `organizationId` is provided — it will not fetch until an organization is selected.

## Usage Example

```typescript
import {
  useOrganizationOptions,
  useDeviceOptions,
  useTicketLabelOptions,
  useAssigneeOptions,
} from './use-ticket-options';

function TicketForm() {
  const [orgId, setOrgId] = useState<string>();
  const [search, setSearch] = useState('');

  const { options: orgOptions, isLoading: orgsLoading } =
    useOrganizationOptions(search);

  const { options: deviceOptions, isLoading: devicesLoading } =
    useDeviceOptions(orgId, search);

  const { options: assignees } = useAssigneeOptions();
  const { options: labels } = useTicketLabelOptions();

  // Pass options to your autocomplete/select components
}
```

All hooks return a stable empty array fallback (`[]`) while loading, preventing unnecessary re-renders in downstream components.
