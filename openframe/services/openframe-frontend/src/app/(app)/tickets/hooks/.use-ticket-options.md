Provides React Query hooks for fetching and formatting autocomplete/avatar option lists used in ticket form fields, covering organizations, devices, assignees, and labels.

## Key Components

### Interfaces
- **`AutocompleteOption`** — Base shape `{ label, value }` for dropdown options
- **`AvatarOption`** — Extends `AutocompleteOption` with an optional `imageUrl` field

### Hooks

| Hook | Data Source | Returns |
|------|-------------|---------|
| `useOrganizationOptions(search?)` | GraphQL `/api/graphql` | `AvatarOption[]` — org name + logo |
| `useDeviceOptions(organizationId?, search?)` | GraphQL `/api/graphql` | `AutocompleteOption[]` — scoped to org, disabled if no org ID |
| `useAssigneeOptions()` | REST `/api/users` | `AvatarOption[]` — full name or email + avatar |
| `useTicketLabelOptions()` | GraphQL `/chat/graphql` | `AutocompleteOption[]` — ticket label key/id pairs |

## Usage Example

```typescript
import {
  useOrganizationOptions,
  useDeviceOptions,
  useAssigneeOptions,
  useTicketLabelOptions,
} from './use-ticket-options';

function TicketForm() {
  const { options: orgs, isLoading: orgsLoading } = useOrganizationOptions('Acme');
  const { options: devices } = useDeviceOptions('org-123', '');
  const { options: assignees } = useAssigneeOptions();
  const { options: labels } = useTicketLabelOptions();

  return (
    <Autocomplete options={orgs} loading={orgsLoading} />
  );
}
```

## Notes

- `useDeviceOptions` is **disabled** until an `organizationId` is provided (`enabled: !!organizationId`)
- All hooks return stable empty arrays (`EMPTY_AUTOCOMPLETE_OPTIONS` / `EMPTY_AVATAR_OPTIONS`) to avoid unnecessary re-renders when data is absent
- Image URLs are normalized via `getFullImageUrl` for both org logos and user avatars
