Provides optimistic-update mutation hooks for moving tickets across board columns and tracking in-flight move operations.

## Key Components

- **`MoveTicketLifecycleParams`** — Interface defining the move operation: `ticketId`, `sourceStatusId`, `targetStatusId`, and optional `afterTicketId`/`beforeTicketId` anchors for ordered insertion.
- **`moveTicketRequest`** — Internal async function that routes the API call: uses `transitionTicket` for cross-column moves without anchors, or `reorderTicket` for all other cases (in-column reorders and cross-column moves with position anchors).
- **`useMoveTicketLifecycle`** — Primary mutation hook that applies optimistic board updates on `onMutate`, rolls back on error with a toast notification, and invalidates the ticket detail query on `onSettled`.
- **`useMovingTicketIdsLifecycle`** — Selector hook that returns a `Set<string>` of ticket IDs currently being moved, derived from pending mutations with the same mutation key.

## Usage Example

```typescript
// Trigger a move with optimistic UI
const { mutate: moveTicket } = useMoveTicketLifecycle();

moveTicket({
  ticketId: 'ticket-123',
  sourceStatusId: 'status-open',
  targetStatusId: 'status-in-progress',
  afterTicketId: 'ticket-100',
  beforeTicketId: null,
});

// Show a loading indicator on cards being dragged
const movingIds = useMovingTicketIdsLifecycle();

<TicketCard isMoving={movingIds.has(ticket.id)} />
```
