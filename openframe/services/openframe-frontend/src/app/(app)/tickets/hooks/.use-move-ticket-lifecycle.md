Handles optimistic UI updates for ticket drag-and-drop moves on the Kanban board, supporting both same-column reordering and cross-column status transitions with automatic rollback on failure.

## Key Components

- **`MoveTicketLifecycleParams`** — Input interface defining `ticketId`, `sourceStatusId`, `targetStatusId`, `afterTicketId`, and `beforeTicketId`
- **`moveTicketRequest`** — Internal async function that routes to either `transitionTicket` (cross-column, no anchor) or `reorderTicket` (reorder/combined move)
- **`useMoveTicketLifecycle`** — Primary mutation hook; applies optimistic board updates via `applyOptimisticMoveLifecycle`, rolls back via `rollbackOptimisticMove` on error, and invalidates the ticket detail query on settle
- **`useMovingTicketIdsLifecycle`** — Returns a `Set<string>` of ticket IDs currently being moved (pending mutations), useful for disabling/loading UI states

## Usage Example

```typescript
// Trigger a cross-column move with optimistic update
const { mutate: moveTicket } = useMoveTicketLifecycle();

moveTicket({
  ticketId: 'ticket-123',
  sourceStatusId: 'status-open',
  targetStatusId: 'status-in-progress',
  afterTicketId: 'ticket-456',
  beforeTicketId: null,
});

// Determine which tickets are currently being moved
const movingIds = useMovingTicketIdsLifecycle();
const isMoving = movingIds.has('ticket-123');
```

## Notes

- Uses `scope: { id: 'tickets-board-move-lifecycle' }` to serialize concurrent moves and prevent race conditions
- Board column queries are cancelled before each optimistic update to avoid stale overwrites
- Toast error messages surface the raw `Error.message` when available
