A React hook that provides ticket status management operations with loading state tracking, error handling via toast notifications, and automatic React Query cache invalidation.

## Key Components

### `useTicketStatus()`

Main hook export that wraps `ticketService.mutateStatus` with UX-friendly state management.

**Returns:**

| Property | Type | Description |
|----------|------|-------------|
| `updateTicketStatus` | `(ticketId, status) => Promise<DialogStatus \| null>` | Generic status updater |
| `putOnHold` | `(ticketId) => Promise<DialogStatus \| null>` | Sets status to `ON_HOLD` |
| `resolve` | `(ticketId) => Promise<DialogStatus \| null>` | Sets status to `RESOLVED` |
| `activate` | `(ticketId) => Promise<DialogStatus \| null>` | Sets status to `ACTIVE` |
| `archive` | `(ticketId) => Promise<DialogStatus \| null>` | Sets status to `ARCHIVED` |
| `isUpdating` | `boolean` | Concurrent update guard flag |

**Behavior notes:**
- Returns `null` and no-ops if an update is already in progress (`isUpdating` guard)
- Invalidates all dialog queries on success via `invalidateAllDialogs`
- Shows a destructive toast notification on failure

## Usage Example

```typescript
import { useTicketStatus } from './use-ticket-status';

function TicketActions({ ticketId }: { ticketId: string }) {
  const { resolve, putOnHold, archive, activate, isUpdating } = useTicketStatus();

  return (
    <div>
      <button onClick={() => resolve(ticketId)} disabled={isUpdating}>
        Resolve
      </button>
      <button onClick={() => putOnHold(ticketId)} disabled={isUpdating}>
        Hold
      </button>
      <button onClick={() => archive(ticketId)} disabled={isUpdating}>
        Archive
      </button>
      <button onClick={() => activate(ticketId)} disabled={isUpdating}>
        Activate
      </button>
    </div>
  );
}
```
