A React client-side hook for managing ticket status transitions in the OpenFrame platform, providing debounce-safe mutation helpers with toast error feedback and automatic query cache invalidation.

## Key Components

**`useTicketStatus()`** — Main hook export returning:

| Return Value | Type | Description |
|---|---|---|
| `updateTicketStatus` | `(ticketId, status) => Promise<DialogStatus \| null>` | Generic status mutator with guard against concurrent updates |
| `putOnHold` | `(ticketId) => Promise` | Transitions ticket to `ON_HOLD` |
| `resolve` | `(ticketId) => Promise` | Transitions ticket to `RESOLVED` |
| `activate` | `(ticketId) => Promise` | Transitions ticket to `ACTIVE` |
| `archive` | `(ticketId) => Promise` | Transitions ticket to `ARCHIVED` |
| `isUpdating` | `boolean` | Mutation in-flight state flag |

**Internal dependencies:**
- `ticketService.mutateStatus` — Performs the API call
- `invalidateAllDialogs` — Busts the React Query dialog cache on success
- `useToast` — Surfaces destructive error toasts on failure

## Usage Example

```typescript
import { useTicketStatus } from './use-ticket-status';

function TicketActions({ ticketId }: { ticketId: string }) {
  const { resolve, putOnHold, activate, archive, isUpdating } = useTicketStatus();

  return (
    <div>
      <button onClick={() => resolve(ticketId)} disabled={isUpdating}>
        Resolve
      </button>
      <button onClick={() => putOnHold(ticketId)} disabled={isUpdating}>
        Put on Hold
      </button>
      <button onClick={() => archive(ticketId)} disabled={isUpdating}>
        Archive
      </button>
    </div>
  );
}
```

> Concurrent calls are automatically dropped — if `isUpdating` is `true`, `updateTicketStatus` returns `null` immediately, preventing duplicate API requests.
