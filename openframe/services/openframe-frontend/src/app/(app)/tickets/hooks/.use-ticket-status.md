A React hook that manages ticket status transitions with optimistic query invalidation, loading state tracking, and error toast notifications.

## Key Components

**`useTicketStatus()`** — Main hook export that wraps `ticketService.mutateStatus` with UX handling.

**Returned values:**

| Name | Type | Description |
|------|------|-------------|
| `updateTicketStatus` | `(ticketId, status) => Promise<DialogStatus \| null>` | Generic status updater; prevents concurrent calls via `isUpdating` guard |
| `putOnHold` | `(ticketId) => Promise` | Sets status to `ON_HOLD` |
| `resolve` | `(ticketId) => Promise` | Sets status to `RESOLVED` |
| `activate` | `(ticketId) => Promise` | Sets status to `ACTIVE` |
| `archive` | `(ticketId) => Promise` | Sets status to `ARCHIVED` |
| `isUpdating` | `boolean` | `true` while a status mutation is in flight |

**Side effects:**
- Calls `invalidateAllDialogs(queryClient)` on success to refresh all related React Query caches
- Displays a destructive toast for 5 seconds on failure

## Usage Example

```typescript
import { useTicketStatus } from '../hooks/use-ticket-status';

function TicketActions({ ticketId }: { ticketId: string }) {
  const { resolve, putOnHold, activate, archive, isUpdating } = useTicketStatus();

  return (
    <div>
      <button onClick={() => resolve(ticketId)} disabled={isUpdating}>
        Resolve
      </button>
      <button onClick={() => putOnHold(ticketId)} disabled={isUpdating}>
        Put On Hold
      </button>
      <button onClick={() => archive(ticketId)} disabled={isUpdating}>
        Archive
      </button>
    </div>
  );
}
```

> The `isUpdating` flag is shared across all status actions — only one transition can be in progress at a time.
