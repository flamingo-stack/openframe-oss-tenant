Provides a React hook for moving tickets between board columns with optimistic UI updates, rollback support, and in-flight tracking.

## Key Components

- **`MoveTicketParams`** — Interface defining move parameters: `ticketId`, `sourceStatus`, `targetStatus`, and optional `afterTicketId`/`beforeTicketId` anchors for ordering
- **`moveTicketRequest`** — Internal async function that dispatches either a `mutateStatus` call (cross-column, no anchor) or a `reorderTicket` call (with positioning)
- **`useMoveTicket`** — Primary mutation hook with optimistic board updates, automatic rollback on error, and query invalidation on settle
- **`useMovingTicketIds`** — Derives a `Set<string>` of ticket IDs currently being moved, useful for disabling UI interactions during in-flight mutations

## Usage Example

```typescript
// Moving a ticket between columns
const { mutate: moveTicket } = useMoveTicket();

moveTicket({
  ticketId: 'ticket-123',
  sourceStatus: 'open',
  targetStatus: 'in_progress',
  afterTicketId: 'ticket-100',
  beforeTicketId: null,
});

// Disabling drag handles for in-flight tickets
const movingIds = useMovingTicketIds();

const isDragging = movingIds.has('ticket-123'); // true while mutation is pending
```

## Behavior Notes

- Uses **optimistic updates** via `applyOptimisticMove` — the board reflects the move instantly before the server responds
- On error, `rollbackOptimisticMove` restores the previous board snapshot and shows a destructive toast
- Mutations are **scoped** to `'tickets-board-move'` to serialize concurrent moves
- On settle, only the moved ticket's detail query is invalidated (not the full board), minimizing refetch overhead
