Provides a React hook for moving tickets across board columns with optimistic UI updates, rollback on failure, and real-time tracking of in-flight moves.

## Key Components

- **`MoveTicketParams`** — Interface defining move operation parameters: `ticketId`, `sourceStatus`, `targetStatus`, and optional anchor IDs (`afterTicketId`, `beforeTicketId`) for ordering
- **`moveTicketRequest`** — Internal async function that routes to either `mutateStatus` (cross-column, no anchor) or `reorderTicket` (ordered/cross-column moves)
- **`useMoveTicket`** — Primary mutation hook with optimistic board updates, automatic rollback on error, and toast notifications
- **`useMovingTicketIds`** — Derived hook that returns a `Set<string>` of ticket IDs currently being moved (pending mutations)

## Usage Example

```typescript
// Moving a ticket with optimistic UI
function TicketCard({ ticket }: { ticket: Ticket }) {
  const { mutate: moveTicket } = useMoveTicket();
  const movingIds = useMovingTicketIds();

  const isMoving = movingIds.has(ticket.id);

  const handleDrop = (targetStatus: BoardStatus, afterId: string | null) => {
    moveTicket({
      ticketId: ticket.id,
      sourceStatus: ticket.status,
      targetStatus,
      afterTicketId: afterId,
      beforeTicketId: null,
    });
  };

  return (
    <div style={{ opacity: isMoving ? 0.5 : 1 }}>
      {ticket.title}
    </div>
  );
}
```

## Behavior Notes

- Mutations are **scoped** to `tickets-board-move`, preventing concurrent conflicting moves
- Optimistic updates are applied immediately via `applyOptimisticMove` and rolled back via `rollbackOptimisticMove` on error
- On settlement, the moved ticket's detail query is **invalidated** to sync server state
