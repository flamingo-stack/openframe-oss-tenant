React Query mutation hook for creating tickets via GraphQL, handling cache invalidation, toast notifications, and post-creation navigation.

## Key Components

- **`createTicketApi`** — Async function that posts a `CREATE_TICKET_MUTATION` GraphQL request, extracts the response payload, and throws on `userErrors`
- **`useCreateTicket`** — Custom hook wrapping `useMutation` that orchestrates ticket creation with side effects

## Behavior on Success

1. Invalidates `ticketsQueryKeys.all` and `dialogsQueryKeys.all` query caches
2. Shows a success toast
3. Redirects to `/tickets/dialog?id=<ticket.id>` if an ID is returned, otherwise falls back to `/tickets`

## Behavior on Error

Displays a destructive toast with the error message from `userErrors[0].message` or a generic fallback.

## Usage Example

```typescript
import { useCreateTicket } from '@/modules/tickets/hooks/use-create-ticket';

function NewTicketForm() {
  const { mutate: createTicket, isPending } = useCreateTicket();

  const handleSubmit = (formData: CreateTicketInput) => {
    createTicket(formData);
  };

  return (
    <button onClick={() => handleSubmit({ title: 'New Issue', ... })} disabled={isPending}>
      {isPending ? 'Creating...' : 'Create Ticket'}
    </button>
  );
}
```

> **Note:** This hook must be used within a component tree that has `QueryClientProvider` and the Next.js `router` context available.
