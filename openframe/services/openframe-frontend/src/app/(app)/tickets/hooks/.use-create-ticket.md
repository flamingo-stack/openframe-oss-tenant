React Query mutation hook for creating tickets via GraphQL, handling success/error toasts, cache invalidation, and post-creation navigation.

## Key Components

- **`createTicketApi`** — Async function that sends a GraphQL `createTicket` mutation via `apiClient`, extracts the response payload, and throws on `userErrors`.
- **`useCreateTicket`** — Custom hook wrapping `useMutation` that orchestrates ticket creation with side effects.

## Usage Example

```typescript
import { useCreateTicket } from '@/features/tickets/hooks/use-create-ticket';

function CreateTicketForm() {
  const { mutate: createTicket, isPending } = useCreateTicket();

  const handleSubmit = (data: CreateTicketInput) => {
    createTicket(data);
  };

  return (
    <button onClick={() => handleSubmit({ title: 'New Issue', ... })} disabled={isPending}>
      {isPending ? 'Creating...' : 'Create Ticket'}
    </button>
  );
}
```

## Behavior

| Event | Action |
|-------|--------|
| **Success** | Invalidates `tickets` + `dialogs` query caches, shows success toast, navigates to `/tickets/dialog?id={id}` (or `/tickets` if no ID) |
| **GraphQL `userErrors`** | Throws with the first error message before `onSuccess` runs |
| **Network / unknown error** | Shows destructive toast with the error message or a fallback string |
