React Query mutation hook for creating a new support ticket via GraphQL, handling success/error toasts, cache invalidation, and post-creation navigation.

## Key Components

- **`createTicketApi(input)`** — Internal async function that posts the `CREATE_TICKET_MUTATION` GraphQL query, extracts the response data, and throws on `userErrors`.
- **`useCreateTicket()`** — Exported hook wrapping `useMutation` with:
  - Cache invalidation for `ticketsQueryKeys.all` and `dialogsQueryKeys.all` on success
  - Success toast + redirect to `/tickets/dialog?id=<id>` (or `/tickets` if no ID returned)
  - Error toast displaying the server or fallback error message

## Usage Example

```typescript
import { useCreateTicket } from '@/modules/tickets/hooks/use-create-ticket';

function NewTicketForm() {
  const { mutate: createTicket, isPending } = useCreateTicket();

  const handleSubmit = (formData: CreateTicketInput) => {
    createTicket(formData);
  };

  return (
    <button onClick={() => handleSubmit({ title: 'VPN Issue', priority: 'high' })} disabled={isPending}>
      {isPending ? 'Creating...' : 'Create Ticket'}
    </button>
  );
}
```

> **Note:** On success, the hook automatically navigates away from the current page. Avoid calling this inside components that unmount during the mutation to prevent state update warnings.
