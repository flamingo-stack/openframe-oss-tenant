Provides infinite-scroll pagination for fetching ticket dialogs, with support for filtering by status, organization, assignee, search term, and archived state.

## Key Components

- **`useTicketsQuery(params: DialogsQueryParams)`** — Main hook that wraps `useInfiniteQuery` to load paginated ticket dialogs
- **`TICKETS_PAGE_SIZE`** — Constant (`20`) controlling page size per fetch
- **Status resolution** — When the `ticketStatuses` feature flag is enabled and `archived` is `true`, resolves the `ARCHIVED` status ID from `useTicketStatusesQuery` before querying
- **Error handling** — Displays a destructive toast notification on query failure
- **`resetToFirstPage`** — Callback that resets the query cache to page 1 for the current filter set

## Usage Example

```typescript
const {
  dialogs,
  isLoading,
  isFetchingNextPage,
  hasNextPage,
  fetchNextPage,
  error,
  resetToFirstPage,
} = useTicketsQuery({
  archived: false,
  search: 'printer issue',
  statusFilters: ['ACTIVE', 'ON_HOLD'],
  organizationIds: ['org_123'],
  assigneeIds: ['user_456'],
});

// Render list, trigger next page on scroll
if (hasNextPage) fetchNextPage();
```

## Behavior Notes

- Query is **deferred** while waiting for status ID resolution (`waitingForStatusIds`)
- Default active statuses: `ACTIVE`, `TECH_REQUIRED`, `ON_HOLD`, `RESOLVED`
- Default archived status: `ARCHIVED` (or resolved status ID if lifecycle feature flag is on)
- Cache settings: `staleTime: 60s`, `gcTime: 5min`, `retry: 2` with `1000ms` delay
