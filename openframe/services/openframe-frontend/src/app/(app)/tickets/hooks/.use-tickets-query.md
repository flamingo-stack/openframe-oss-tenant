Infinite-scroll data fetching hook for paginated ticket/dialog lists, supporting filtering by status, search, organization, assignee, and archived state.

## Key Components

- **`useTicketsQuery(params: DialogsQueryParams)`** — Main exported hook
- **`TICKETS_PAGE_SIZE`** — Page size constant (20 items per page)
- **Status resolution logic** — When `archived` is enabled and the `ticketStatuses` feature flag is on, fetches the `ARCHIVED` status ID dynamically before querying
- **`dialogs`** — Flattened array of all loaded ticket pages
- **`resetToFirstPage`** — Resets the query cache back to the first page for the current filter set

## Parameters (`DialogsQueryParams`)

| Field | Description |
|---|---|
| `archived` | Toggle archived ticket view |
| `search` | Free-text search string |
| `statusFilters` | Explicit status filter overrides |
| `organizationIds` | Filter by organization |
| `assigneeIds` | Filter by assignee |

## Return Value

| Field | Description |
|---|---|
| `dialogs` | Flat list of all fetched tickets |
| `isLoading` | True while loading or waiting for status IDs |
| `isFetchingNextPage` | True during next-page fetch |
| `hasNextPage` | Whether more pages exist |
| `fetchNextPage` | Trigger next page load |
| `error` | Error message string or `null` |
| `resetToFirstPage` | Reset pagination to page 1 |

## Usage Example

```typescript
const {
  dialogs,
  isLoading,
  hasNextPage,
  fetchNextPage,
  resetToFirstPage,
} = useTicketsQuery({
  archived: false,
  search: 'printer',
  statusFilters: ['ACTIVE'],
  organizationIds: ['org-123'],
  assigneeIds: ['user-456'],
});

// Render tickets with infinite scroll
dialogs.forEach(ticket => console.log(ticket.id));

// Load next page on scroll
if (hasNextPage) fetchNextPage();

// Reset when filters change
resetToFirstPage();
```

> Errors are surfaced automatically via a destructive toast notification — no additional error handling required at the call site.
