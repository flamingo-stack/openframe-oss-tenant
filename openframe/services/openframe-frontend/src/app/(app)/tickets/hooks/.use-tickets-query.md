Infinite-scroll data fetching hook for paginated ticket/dialog lists, built on TanStack Query with cursor-based pagination and filter support.

## Key Components

- **`useTicketsQuery`** — Primary export. Accepts `DialogsQueryParams` (`archived`, `search`, `statusFilters`, `organizationIds`, `assigneeIds`) and returns a normalized query result.
- **Status resolution logic** — Derives the `statuses` array from filters: explicit `statusFilters` take priority, then `archived` maps to `['ARCHIVED']`, defaulting to `['ACTIVE', 'TECH_REQUIRED', 'ON_HOLD', 'RESOLVED']`.
- **`resetToFirstPage`** — Resets the query cache to the first page, useful after filter changes.
- **Error toasting** — Automatically surfaces fetch errors via `useToast` on failure.

| Constant | Value | Purpose |
|---|---|---|
| `TICKETS_PAGE_SIZE` | `20` | Items per page |
| `staleTime` | `60s` | Cache freshness window |
| `gcTime` | `5min` | Garbage collection delay |
| `retry` | `2` | Retry attempts on failure |

## Usage Example

```typescript
const {
  dialogs,
  isLoading,
  isFetchingNextPage,
  hasNextPage,
  fetchNextPage,
  resetToFirstPage,
} = useTicketsQuery({
  archived: false,
  search: 'network issue',
  statusFilters: ['ACTIVE', 'ON_HOLD'],
  organizationIds: ['org_123'],
  assigneeIds: ['user_456'],
});

// Load next page on scroll
if (hasNextPage && !isFetchingNextPage) {
  fetchNextPage();
}

// Reset after applying new filters
resetToFirstPage();
```
