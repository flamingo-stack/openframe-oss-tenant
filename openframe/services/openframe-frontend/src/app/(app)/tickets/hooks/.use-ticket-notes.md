React Query mutation hooks for managing ticket notes (add, update, delete) with optimistic cache updates and error rollback.

## Key Components

| Export | Description |
|--------|-------------|
| `useAddTicketNote(ticketId)` | Mutation hook to add a new note to a ticket |
| `useUpdateTicketNote(ticketId)` | Mutation hook to edit an existing note's content |
| `useDeleteTicketNote(ticketId)` | Mutation hook to remove a note from a ticket |
| `setNotesInCache` | Internal helper to update the notes array in React Query cache |
| `getNotesFromCache` | Internal helper to read the current notes array from cache |

All three hooks share the same pattern:
- **Optimistic updates** — the cache is updated immediately before the GraphQL mutation resolves
- **Rollback on error** — previous notes are restored if the mutation fails
- **Query invalidation on success** — forces a fresh fetch of the ticket detail after confirmation
- **Toast notifications** — surfaces error messages via `useToast`

`useAddTicketNote` also reads from `useAuthStore` to populate the optimistic note with the current user's name and avatar.

## Usage Example

```typescript
import { useAddTicketNote, useUpdateTicketNote, useDeleteTicketNote } from './use-ticket-notes';

function TicketNotes({ ticketId }: { ticketId: string }) {
  const addNote    = useAddTicketNote(ticketId);
  const updateNote = useUpdateTicketNote(ticketId);
  const deleteNote = useDeleteTicketNote(ticketId);

  const handleAdd = () =>
    addNote.mutate({ content: 'Initial investigation complete.' });

  const handleUpdate = (id: string) =>
    updateNote.mutate({ id, content: 'Updated findings.' });

  const handleDelete = (id: string) =>
    deleteNote.mutate(id);

  return (/* render notes UI */);
}
```
