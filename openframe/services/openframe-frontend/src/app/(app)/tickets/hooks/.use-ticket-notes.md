React Query mutation hooks for managing ticket notes (add, update, delete) with optimistic updates and automatic cache rollback on error.

## Key Components

- **`useAddTicketNote(ticketId)`** — Optimistically appends a new note to the cache using the current auth user's identity, then syncs with the server via `addTicketNote` GraphQL mutation
- **`useUpdateTicketNote(ticketId)`** — Optimistically patches note content in-cache by ID, confirmed via `updateTicketNote` mutation
- **`useDeleteTicketNote(ticketId)`** — Optimistically removes a note from cache by ID, confirmed via `deleteTicketNote` mutation
- **`setNotesInCache`** — Internal helper; applies a functional updater to the `Dialog.notes` array in the React Query cache for a given ticket
- **`getNotesFromCache`** — Internal helper; reads the current notes array from cache, defaulting to `[]`

All three hooks share the same error-handling pattern: roll back to `previousNotes` snapshot on failure and surface a destructive toast notification.

## Usage Example

```typescript
const { mutate: addNote } = useAddTicketNote(ticketId);
const { mutate: updateNote } = useUpdateTicketNote(ticketId);
const { mutate: deleteNote } = useDeleteTicketNote(ticketId);

// Add a note
addNote({ content: 'Checked the server logs — no anomalies found.' });

// Update an existing note
updateNote({ id: 'note-123', content: 'Updated: anomaly found in auth service.' });

// Delete a note
deleteNote('note-123');
```

> All mutations apply optimistic updates immediately and invalidate `ticketsQueryKeys.detail(ticketId)` on success to keep the cache fresh.
