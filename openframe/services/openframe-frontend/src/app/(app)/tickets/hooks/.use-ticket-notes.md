React Query mutation hooks for managing ticket notes (add, update, delete) with optimistic UI updates and automatic cache rollback on error.

## Key Components

| Export | Description |
|--------|-------------|
| `useAddTicketNote(ticketId)` | Mutation hook to add a new note; inserts an optimistic placeholder instantly |
| `useUpdateTicketNote(ticketId)` | Mutation hook to edit an existing note's content in-place |
| `useDeleteTicketNote(ticketId)` | Mutation hook to remove a note by ID |
| `setNotesInCache` *(internal)* | Helper to update the notes array inside the cached `Dialog` object |
| `getNotesFromCache` *(internal)* | Helper to read the current notes array from the React Query cache |

All three hooks share the same pattern:

1. **Optimistic update** — cache is modified immediately before the server responds
2. **GraphQL mutation** — sent via `apiClient` using the corresponding query constant
3. **`onSuccess`** — invalidates the ticket detail query to sync with the server
4. **`onError`** — rolls back to the previous notes snapshot and shows a destructive toast

## Usage Example

```typescript
import { useAddTicketNote, useUpdateTicketNote, useDeleteTicketNote } from './use-ticket-notes';

function TicketNotes({ ticketId }: { ticketId: string }) {
  const addNote    = useAddTicketNote(ticketId);
  const updateNote = useUpdateTicketNote(ticketId);
  const deleteNote = useDeleteTicketNote(ticketId);

  // Add
  const handleAdd = () => addNote.mutate({ content: 'New note text' });

  // Update
  const handleEdit = (id: string) =>
    updateNote.mutate({ id, content: 'Updated content' });

  // Delete
  const handleDelete = (id: string) => deleteNote.mutate(id);
}
```

> **Note:** The optimistic author info for `useAddTicketNote` is derived from `useAuthStore`, so the note displays the current user's name and avatar immediately without waiting for the server response.
