React hook for managing ticket approval request mutations, providing approve and reject actions with success/error callback support.

## Key Components

- **`ApprovalRequestAction`** — Type defining the mutation payload (`requestId`, `approve` flag)
- **`useApprovalRequests`** — Main hook wrapping a TanStack Query `useMutation` for approval state management
- **`handleApproveRequest`** — Approves a request by ID, calls `onSuccess` with `APPROVAL_STATUS.APPROVED` on completion
- **`handleRejectRequest`** — Rejects a request by ID, calls `onSuccess` with `APPROVAL_STATUS.REJECTED` on completion
- **`approvalMutation`** — Raw TanStack Query mutation instance for advanced use cases

## Usage Example

```typescript
function ApprovalCard({ requestId }: { requestId: string }) {
  const {
    handleApproveRequest,
    handleRejectRequest,
    isLoading,
    error,
  } = useApprovalRequests();

  const onApprove = () =>
    handleApproveRequest(requestId, {
      onSuccess: (status) => console.log('Approved:', status),
      onError: (err) => console.error('Failed:', err.message),
    });

  const onReject = () =>
    handleRejectRequest(requestId, {
      onSuccess: (status) => console.log('Rejected:', status),
      onError: (err) => console.error('Failed:', err.message),
    });

  return (
    <>
      <button onClick={onApprove} disabled={isLoading}>Approve</button>
      <button onClick={onReject} disabled={isLoading}>Reject</button>
      {error && <p>{error}</p>}
    </>
  );
}
```

## Notes

- Both handlers re-throw errors after invoking `onError`, allowing upstream `try/catch` handling
- `isLoading` reflects `isPending` from the underlying mutation — shared across both approve and reject actions
- `error` is normalized to `string | null` from the mutation's error message
