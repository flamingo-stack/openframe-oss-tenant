React hook for managing ticket approval request mutations, providing approve and reject actions with success/error callback support via TanStack Query.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `useApprovalRequests` | Hook | Main hook exposing approve/reject handlers and mutation state |
| `ApprovalRequestAction` | Type | Payload shape for the underlying mutation (`requestId`, `approve`) |
| `handleApproveRequest` | Function | Approves a request by ID, calls `onSuccess` with `APPROVED` status |
| `handleRejectRequest` | Function | Rejects a request by ID, calls `onSuccess` with `REJECTED` status |

## Usage Example

```typescript
import { useApprovalRequests } from './use-approval-requests';

function ApprovalActions({ requestId }: { requestId: string }) {
  const { handleApproveRequest, handleRejectRequest, isLoading, error } =
    useApprovalRequests();

  const onApprove = () =>
    handleApproveRequest(requestId, {
      onSuccess: (status) => console.log('Approved:', status),
      onError: (err) => console.error('Failed:', err.message),
    });

  const onReject = () =>
    handleRejectRequest(requestId, {
      onSuccess: (status) => console.log('Rejected:', status),
      onError: (err) => console.error('Failed:', err.message),
    });

  return (
    <>
      <button onClick={onApprove} disabled={isLoading}>Approve</button>
      <button onClick={onReject} disabled={isLoading}>Reject</button>
      {error && <span>{error}</span>}
    </>
  );
}
```

## Notes

- Both handlers re-throw errors after invoking `onError`, allowing upstream error boundaries to catch them.
- `isLoading` reflects `approvalMutation.isPending` — shared across both approve and reject operations.
- The raw `approvalMutation` object is exposed for advanced use cases requiring direct mutation control.
