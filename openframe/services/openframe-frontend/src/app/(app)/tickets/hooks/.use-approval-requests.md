A React hook that manages approval request mutations for tickets, providing approve/reject actions with loading and error state via TanStack Query.

## Key Components

- **`ApprovalRequestAction`** — Type defining the mutation payload (`requestId`, `approve` flag)
- **`useApprovalRequests`** — Main hook returning approval/rejection handlers and mutation state
- **`handleApproveRequest`** — Calls `ticketService.approveRequest` and invokes `onSuccess` with `APPROVED` status
- **`handleRejectRequest`** — Calls `ticketService.rejectRequest` and invokes `onSuccess` with `REJECTED` status
- **`approvalMutation`** — Underlying TanStack Query mutation instance for direct access if needed

## Usage Example

```typescript
import { useApprovalRequests } from './use-approval-requests';

function ApprovalActions({ requestId }: { requestId: string }) {
  const { handleApproveRequest, handleRejectRequest, isLoading, error } =
    useApprovalRequests();

  const onApprove = () =>
    handleApproveRequest(requestId, {
      onSuccess: (status) => console.log('Approved:', status),
      onError: (err) => console.error('Failed:', err.message),
    });

  const onReject = () =>
    handleRejectRequest(requestId, {
      onSuccess: (status) => console.log('Rejected:', status),
      onError: (err) => console.error('Failed:', err.message),
    });

  return (
    <>
      <button onClick={onApprove} disabled={isLoading}>Approve</button>
      <button onClick={onReject} disabled={isLoading}>Reject</button>
      {error && <p>{error}</p>}
    </>
  );
}
```

> Both handlers re-throw caught errors after invoking `onError`, allowing upstream error boundaries or callers to handle failures independently.
