Provides a React mutation hook for unlinking a device from a support ticket via GraphQL, with query invalidation and toast notifications on success or failure.

## Key Components

- **`unlinkDeviceApi(ticketId)`** — Internal async function that sends the `UNLINK_DEVICE_FROM_TICKET_MUTATION` GraphQL mutation, extracts the response payload, and throws on `userErrors`.
- **`useUnlinkDevice(onSuccess?)`** — Exported hook wrapping `useMutation` that handles the full unlink flow, including cache invalidation for `ticketsQueryKeys.all` and `dialogsQueryKeys.all`, and toast feedback.

## Usage Example

```typescript
import { useUnlinkDevice } from './use-unlink-device';

function TicketDevicePanel({ ticketId }: { ticketId: string }) {
  const { mutate: unlinkDevice, isPending } = useUnlinkDevice(() => {
    console.log('Device successfully unlinked, running follow-up logic');
  });

  return (
    <button
      disabled={isPending}
      onClick={() => unlinkDevice(ticketId)}
    >
      {isPending ? 'Unlinking...' : 'Unlink Device'}
    </button>
  );
}
```

The optional `onSuccess` callback fires after cache invalidation and the success toast, allowing callers to trigger additional side effects such as closing a dialog or resetting local state.
