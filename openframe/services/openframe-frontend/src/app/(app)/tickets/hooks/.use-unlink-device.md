React Query mutation hook for unlinking a device from a support ticket via GraphQL, with toast notifications and automatic cache invalidation.

## Key Components

- **`unlinkDeviceApi(ticketId)`** — Internal async function that calls the `UNLINK_DEVICE_FROM_TICKET_MUTATION` GraphQL mutation, extracts the response, and throws on `userErrors`.
- **`useUnlinkDevice(onSuccess?)`** — Exported hook wrapping `useMutation` that handles the full unlink lifecycle: API call, success/error toasts, and query invalidation for both tickets and dialogs caches.

## Usage Example

```typescript
import { useUnlinkDevice } from './use-unlink-device';

function TicketDevicePanel({ ticketId }: { ticketId: string }) {
  const { mutate: unlinkDevice, isPending } = useUnlinkDevice(() => {
    console.log('Device unlinked, closing panel...');
  });

  return (
    <button
      disabled={isPending}
      onClick={() => unlinkDevice(ticketId)}
    >
      {isPending ? 'Unlinking...' : 'Unlink Device'}
    </button>
  );
}
```

## Behavior

| Event | Action |
|-------|--------|
| Success | Invalidates `ticketsQueryKeys.all` + `dialogsQueryKeys.all`, shows success toast, calls `onSuccess?.()` |
| `userErrors` in response | Throws with first error message, triggers error toast |
| Network/unknown error | Shows destructive toast with error message or fallback text |
