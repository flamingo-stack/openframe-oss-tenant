React Query mutation hook for removing a device association from a ticket via GraphQL, with automatic cache invalidation and toast notifications.

## Key Components

- **`unlinkDeviceApi(ticketId)`** — Internal async function that sends the `UNLINK_DEVICE_FROM_TICKET_MUTATION` GraphQL request and throws on `userErrors`
- **`useUnlinkDevice(onSuccess?)`** — Exported hook wrapping `useMutation` that handles success/error feedback and query invalidation

## Usage Example

```typescript
import { useUnlinkDevice } from './use-unlink-device';

function TicketDevicePanel({ ticketId }: { ticketId: string }) {
  const { mutate: unlinkDevice, isPending } = useUnlinkDevice(() => {
    console.log('Device successfully unlinked');
  });

  return (
    <button
      disabled={isPending}
      onClick={() => unlinkDevice(ticketId)}
    >
      {isPending ? 'Unlinking...' : 'Unlink Device'}
    </button>
  );
}
```

## Behavior

| Event | Action |
|-------|--------|
| **Success** | Invalidates `ticketsQueryKeys.all` + `dialogsQueryKeys.all`, shows success toast, calls optional `onSuccess` callback |
| **Error** | Shows destructive toast with the GraphQL `userErrors` message or a generic fallback |
