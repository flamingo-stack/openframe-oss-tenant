Manages temporary file attachments for tickets, handling upload lifecycle (presigned URL generation → S3 PUT), removal of temp and existing attachments, and deferred deletion tracking.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `TempFileStatus` | Union: `'uploading' \| 'uploaded' \| 'error' \| 'existing'` |
| `TempFileEntry` | File metadata + status tracked in local state |

### Internal Helpers

| Function | Description |
|----------|-------------|
| `createTempAttachment` | Requests a presigned upload URL via GraphQL, then PUTs the file directly to storage |
| `deleteTempAttachment` | Removes a temp attachment via GraphQL mutation |
| `deleteTicketAttachment` | Removes a persisted ticket attachment via GraphQL mutation |

### `useTempAttachments()` Hook

Returns:

| Member | Type | Description |
|--------|------|-------------|
| `files` | `TempFileEntry[]` | Current attachment list with statuses |
| `uploadFile` | `(file: File) => void` | Adds a placeholder then uploads |
| `removeFile` | `(id: string) => void` | Removes temp/pending files immediately; defers deletion for `existing` entries |
| `initializeExisting` | `(attachments[]) => void` | Seeds state with already-saved attachments (deduped) |
| `getTempAttachmentIds` | `() => string[]` | Returns IDs of successfully uploaded (non-persisted) files |
| `deleteRemovedAttachments` | `() => Promise<void>` | Flushes deferred deletions for existing attachments |
| `hasPendingDeletes` | `boolean` | Whether any deferred deletions are queued |
| `isUploading` | `boolean` | Whether an upload mutation is in-flight |
| `reset` | `() => void` | Clears all state |

## Usage Example

```typescript
const {
  files,
  uploadFile,
  removeFile,
  initializeExisting,
  getTempAttachmentIds,
  deleteRemovedAttachments,
  hasPendingDeletes,
  isUploading,
  reset,
} = useTempAttachments();

// Seed with existing ticket attachments (e.g. when editing)
initializeExisting(ticket.attachments);

// Upload a new file from an <input> change event
const handleFileChange = (e: React.ChangeEvent<HTMLInputElement>) => {
  const file = e.target.files?.[0];
  if (file) uploadFile(file);
};

// On form submit: flush deferred deletes, then collect new IDs
const handleSubmit = async () => {
  if (hasPendingDeletes) await deleteRemovedAttachments();
  const tempIds = getTempAttachmentIds(); // pass to ticket mutation
};

// Remove a file by ID (handles all status variants)
removeFile(fileEntry.id);
```

> **Note:** `existing` attachment deletions are deferred — they are only sent to the server when `deleteRemovedAttachments()` is explicitly called (e.g. on form submit). Orphaned temp uploads are cleaned up by a backend job if the upload session is abandoned.
