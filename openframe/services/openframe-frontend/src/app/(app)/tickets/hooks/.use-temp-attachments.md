Manages temporary file attachment state for ticket forms, handling upload, removal, and lifecycle of both new and existing attachments via GraphQL and presigned S3 URLs.

## Key Components

**Types**
- `TempFileStatus` — Union type: `'uploading' | 'uploaded' | 'error' | 'existing'`
- `TempFileEntry` — Shape of a tracked file entry (id, fileName, fileSize, contentType, status, optional error)

**Internal Helpers**
- `createTempAttachment(file)` — Requests a presigned upload URL via GraphQL, then PUTs the file directly to S3
- `deleteTempAttachment(id)` — Deletes a temp attachment (not yet committed to a ticket)
- `deleteTicketAttachment(id)` — Deletes a persisted ticket attachment on form submit

**Hook: `useTempAttachments()`**

| Return | Description |
|---|---|
| `files` | Current list of `TempFileEntry` items |
| `uploadFile(file)` | Adds a placeholder entry then uploads; resolves to real ID on success |
| `removeFile(id)` | Handles `pending-*`, `existing`, and `uploaded` entries differently |
| `initializeExisting(attachments)` | Seeds the list with already-saved attachments (deduped) |
| `getTempAttachmentIds()` | Returns IDs of successfully uploaded (not yet committed) files |
| `deleteRemovedAttachments()` | Flushes deferred deletions of `existing` entries on save |
| `hasPendingDeletes` | `true` when removed `existing` attachments are awaiting deletion |
| `isUploading` | `true` while an upload mutation is in flight |
| `reset()` | Clears all state |

## Usage Example

```typescript
const {
  files,
  uploadFile,
  removeFile,
  initializeExisting,
  getTempAttachmentIds,
  deleteRemovedAttachments,
  isUploading,
  reset,
} = useTempAttachments();

// Seed with existing saved attachments (e.g. when editing a ticket)
initializeExisting(ticket.attachments);

// Upload a new file from an <input type="file"> event
const handleFileChange = (e: React.ChangeEvent<HTMLInputElement>) => {
  const file = e.target.files?.[0];
  if (file) uploadFile(file);
};

// On form submit
const handleSubmit = async () => {
  const tempIds = getTempAttachmentIds(); // pass to mutation variables
  await deleteRemovedAttachments();       // flush deferred deletions
  await saveTicket({ tempAttachmentIds: tempIds });
  reset();
};
```

> **Note:** Removing an `existing` attachment is deferred — the entry is removed from the UI immediately and the actual API call is batched into `deleteRemovedAttachments()` at submit time. Orphaned temp uploads are cleaned up by a backend job if the form is abandoned.
