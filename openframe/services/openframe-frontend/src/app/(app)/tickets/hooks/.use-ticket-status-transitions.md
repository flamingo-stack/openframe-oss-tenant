Fetches and caches the available ticket status transitions from the ticket service, exposing them via React Query.

## Key Components

- **`useTicketStatusTransitions`** — Custom hook that queries all valid `TicketStatusTransition` objects. Results are cached for 1 hour (`staleTime` and `gcTime` both set to `3600000ms`) to minimize redundant network requests, since status transitions are relatively static data.

## Usage Example

```typescript
import { useTicketStatusTransitions } from './use-ticket-status-transitions';

function TicketStatusSelector() {
  const { data: transitions, isLoading, error } = useTicketStatusTransitions();

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage message={error.message} />;

  return (
    <select>
      {transitions?.map((transition) => (
        <option key={transition.id} value={transition.toStatus}>
          {transition.label}
        </option>
      ))}
    </select>
  );
}
```
