Fetches and caches available ticket status transitions via React Query, with a 1-hour stale and garbage collection time.

## Key Components

- **`useTicketStatusTransitions`** — Custom hook that returns a React Query result containing an array of `TicketStatusTransition` objects, representing all valid status transitions for tickets.

## Usage Example

```typescript
import { useTicketStatusTransitions } from './use-ticket-status-transitions';

function TicketStatusSelector() {
  const { data: transitions, isLoading, error } = useTicketStatusTransitions();

  if (isLoading) return <p>Loading transitions...</p>;
  if (error) return <p>Failed to load transitions</p>;

  return (
    <ul>
      {transitions?.map((t) => (
        <li key={t.id}>{t.label}</li>
      ))}
    </ul>
  );
}
```

## Notes

- Data is cached for **1 hour** (`staleTime` and `gcTime` both set to `3,600,000ms`), making it suitable for relatively static configuration data.
- Query is keyed via `ticketsQueryKeys.statusTransitions()` for consistent cache management across the app.
