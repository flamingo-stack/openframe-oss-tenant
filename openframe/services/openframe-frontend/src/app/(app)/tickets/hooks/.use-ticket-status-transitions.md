Fetches and caches the list of available ticket status transitions using React Query, with a 1-hour stale and garbage collection time.

## Key Components

- **`useTicketStatusTransitions`** — Custom hook that returns a React Query result containing an array of `TicketStatusTransition` objects, representing all valid status transitions for tickets.

## Usage Example

```typescript
import { useTicketStatusTransitions } from './use-ticket-status-transitions';

function TicketStatusSelector() {
  const { data: transitions, isLoading, error } = useTicketStatusTransitions();

  if (isLoading) return <Spinner />;
  if (error) return <ErrorMessage error={error} />;

  return (
    <select>
      {transitions?.map((transition) => (
        <option key={transition.id} value={transition.toStatus}>
          {transition.label}
        </option>
      ))}
    </select>
  );
}
```

## Notes

- Data is cached for **1 hour** (`staleTime` and `gcTime` both set to `60 * 60 * 1000` ms), making it suitable for relatively static configuration data that rarely changes.
- Query is keyed via `ticketsQueryKeys.statusTransitions()` for consistent cache management across the app.
