React hook that manages the create/edit ticket form, handling form state, validation, data prefilling for edit mode, and submission logic for both creating and updating tickets.

## Key Components

- **`useCreateTicketForm(options)`** — Main hook accepting an optional `ticketId` to toggle between create and edit mode
- **`isEditMode`** — Derived boolean; `true` when a `ticketId` is provided
- **`form`** — `react-hook-form` instance with Zod schema validation via `createTicketSchema`
- **`handleSave`** — Validated submit handler that dispatches either `createTicket` or `updateTicket` mutations, applies assignment diffs, and manages temp attachment lifecycle
- **`tempAttachments`** — Manages temporary attachment state, including pending deletes and ID extraction
- **`isFaeForm`** — Flag indicating the ticket originated from a Fae client form (`CREATION_SOURCE.FAE_FORM`)

## Usage Example

```typescript
// Create mode
const { form, handleSave, isSubmitting, tempAttachments } = useCreateTicketForm();

// Edit mode — prefills form with existing ticket data
const {
  form,
  handleSave,
  isEditMode,
  isLoadingTicket,
  isSubmitting,
  tempAttachments,
  isFaeForm,
} = useCreateTicketForm({ ticketId: 'ticket-abc-123' });

return (
  <form onSubmit={handleSave}>
    <input {...form.register('title')} />
    <button type="submit" disabled={isSubmitting}>
      {isEditMode ? 'Update' : 'Create'} Ticket
    </button>
  </form>
);
```

## Form Fields

| Field | Type | Description |
|-------|------|-------------|
| `title` | `string` | Ticket title |
| `description` | `string` | Ticket body content |
| `organizationId` | `string?` | Associated organization |
| `deviceId` | `string?` | Associated device |
| `assignedTo` | `string?` | Assignee ID |
| `labelIds` | `string[]` | Applied label IDs |
| `assignments` | `object` | Knowledge base / resource assignments |
| `assignKnowledgeBase` | `boolean` | Whether to assign KB entries |
