Unified form hook for creating and editing tickets, handling schema validation, data prefill, attachment management, and assignment diffing in both create and edit modes.

## Key Components

**`useCreateTicketForm(options)`**
Main exported hook that accepts an optional `ticketId` to toggle between create and edit mode.

- **`form`** — `react-hook-form` instance bound to `createTicketSchema` via Zod resolver
- **`handleSave`** — Validated submit handler; branches on `isEditMode` to call either `useUpdateTicket` or `useCreateTicket`, then applies assignment diffs via `useApplyAssignmentsDiff`
- **`tempAttachments`** — Manages pending attachment uploads and deletions via `useTempAttachments`
- **`isEditMode`** — Derived boolean (`!!ticketId`) controlling data fetching and submit logic
- **`isFaeForm`** — Flags tickets created via the Fae client portal (`CREATION_SOURCE.FAE_FORM`)

**Side Effects**
- Fetches existing ticket data via GraphQL when `ticketId` is present
- Prefills form fields and initializes existing attachments once ticket data and assignment state are both ready (`assignedItems.isReady`)

## Usage Example

```typescript
// Create mode
const { form, handleSave, isSubmitting, tempAttachments } =
  useCreateTicketForm();

// Edit mode — pass a ticketId to prefill and update
const {
  form,
  handleSave,
  isSubmitting,
  isLoadingTicket,
  isFaeForm,
  tempAttachments,
} = useCreateTicketForm({ ticketId: 'ticket-abc-123' });

return (
  <form onSubmit={handleSave}>
    <input {...form.register('title')} />
    <button type="submit" disabled={isSubmitting}>
      {isEditMode ? 'Update' : 'Create'}
    </button>
  </form>
);
```
