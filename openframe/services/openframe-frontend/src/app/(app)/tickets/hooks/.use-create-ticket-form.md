Manages the unified form state for creating and editing tickets, supporting both creation and edit modes with prefill, attachments, and assignments diff logic.

## Key Components

- **`useCreateTicketForm(options)`** — Primary hook accepting an optional `ticketId` to toggle between create and edit mode
- **`isEditMode`** — Derived boolean; `true` when `ticketId` is provided
- **`form`** — `react-hook-form` instance validated via `createTicketSchema` (Zod)
- **`handleSave`** — Async submit handler that routes to `useCreateTicket` or `useUpdateTicket` based on mode, then applies assignments diff
- **`tempAttachments`** — Manages temporary attachment uploads, pending deletes, and existing attachment initialization
- **`isFaeForm`** — Flags tickets created via the Fae client portal (`creationSource === CREATION_SOURCE.FAE_FORM`)

## Usage Example

```typescript
import { useCreateTicketForm } from './use-create-ticket-form';

// Create mode
function CreateTicketDialog() {
  const { form, handleSave, isSubmitting, tempAttachments } = useCreateTicketForm();

  return <form onSubmit={handleSave}>...</form>;
}

// Edit mode — prefills form with fetched ticket data
function EditTicketDialog({ ticketId }: { ticketId: string }) {
  const {
    form,
    handleSave,
    isLoadingTicket,
    isSubmitting,
    isFaeForm,
    tempAttachments,
  } = useCreateTicketForm({ ticketId });

  if (isLoadingTicket) return <Spinner />;

  return <form onSubmit={handleSave}>...</form>;
}
```

## Returned Values

| Property | Type | Description |
|---|---|---|
| `form` | `UseFormReturn` | react-hook-form instance |
| `isEditMode` | `boolean` | Whether editing an existing ticket |
| `isLoadingTicket` | `boolean` | Ticket fetch in progress |
| `isSubmitting` | `boolean` | Create or update mutation pending |
| `handleSave` | `function` | Validated submit handler |
| `tempAttachments` | `object` | Attachment state and actions |
| `isFaeForm` | `boolean` | Created via Fae client portal |
