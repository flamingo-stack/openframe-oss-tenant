Provides ticket list page action buttons, dropdown menu items, and a confirmation dialog for bulk-archiving resolved tickets.

## Key Components

### `useTicketsActions(params)`

Custom hook that returns all interactive controls for the tickets list page.

**Parameters:**

| Name | Type | Description |
|------|------|-------------|
| `isLoading` | `boolean` | Disables destructive actions while data is loading |
| `enabled` | `boolean` | Gates all actions (default: `true`) |

**Returns:**

| Field | Type | Description |
|-------|------|-------------|
| `actions` | `PageActionButton[]` | Primary action buttons (e.g. "New Ticket") |
| `menuActions` | `ActionsMenuGroup[]` | Overflow menu items (archive, statuses) |
| `dialog` | `ReactNode` | Confirmation dialog for bulk archive |
| `canArchiveResolved` | `boolean` | Whether bulk archive action is currently available |
| `openArchiveResolvedConfirm` | `() => void` | Opens the archive confirmation dialog |

## Usage Example

```typescript
import { useTicketsActions } from './use-tickets-actions';

function TicketsPage() {
  const { actions, menuActions, dialog, canArchiveResolved } = useTicketsActions({
    isLoading: false,
    enabled: true,
  });

  return (
    <>
      <PageHeader actions={actions} menuActions={menuActions} />
      {/* page content */}
      {dialog}
    </>
  );
}
```

## Notes

- Menu items are conditionally rendered: `Edit Statuses` requires `featureFlags.ticketStatuses.enabled()`, and `Archive Resolved Tickets` only appears when `resolvedCount > 0`
- Archive confirmation dialog pluralises its description based on `resolvedCount`
- All actions return `[]` when `enabled` is `false`
