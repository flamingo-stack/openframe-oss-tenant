Provides page-level action buttons and menu items for the tickets list view, including navigation to create a new ticket and bulk-archiving of resolved tickets with a confirmation dialog.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `useTicketsActions` | Hook | Returns action buttons, dropdown menu groups, and a confirm dialog node for the tickets page |
| `UseTicketsActionsParams` | Interface | Input params: `isLoading` (disables archive action) and `enabled` (gates all actions) |

**Return shape:**

| Field | Type | Description |
|-------|------|-------------|
| `actions` | `PageActionButton[]` | Primary page buttons (e.g. "New Ticket") |
| `menuActions` | `ActionsMenuGroup[]` | Dropdown menu items (archive nav, bulk-archive resolved) |
| `dialog` | `ReactNode` | Confirmation dialog for the bulk-archive operation |

## Usage Example

```typescript
const { actions, menuActions, dialog } = useTicketsActions({
  isLoading: isFetching,
  enabled: hasPermission,
});

return (
  <>
    <PageHeader actions={actions} menuActions={menuActions} />
    {dialog}
  </>
);
```

## Behavior Notes

- All actions are suppressed when `enabled` is `false` (returns empty arrays)
- **Archive Resolved** menu item only appears when `resolvedCount > 0`
- The archive action is disabled while the mutation or a data fetch is in-flight (`isPending || isLoading`)
- Confirmation dialog dynamically adjusts its description based on singular vs. plural resolved ticket count
