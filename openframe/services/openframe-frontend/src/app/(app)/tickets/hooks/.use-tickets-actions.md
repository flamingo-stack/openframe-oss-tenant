Provides ticket list page actions including a "New Ticket" button, dropdown menu items (Edit Statuses, Tickets Archive, Archive Resolved), and a confirmation dialog for bulk-archiving resolved tickets.

## Key Components

- **`useTicketsActions`** — Primary hook that composes and returns all action-related state and UI for the tickets list page
- **`actions`** — `PageActionButton[]` array containing the "New Ticket" primary action button
- **`menuActions`** — `ActionsMenuGroup[]` array with contextual menu items (Edit Statuses, Tickets Archive, Archive Resolved Tickets)
- **`dialog`** — `ReactNode` rendering the `ConfirmDialog` for bulk archive confirmation
- **`canArchiveResolved`** — Boolean flag indicating whether the archive action is currently available
- **`openArchiveResolvedConfirm`** — Callback to programmatically open the archive confirmation dialog

## Usage Example

```typescript
import { useTicketsActions } from './use-tickets-actions';

function TicketsPageHeader({ isLoading }: { isLoading: boolean }) {
  const { actions, menuActions, dialog } = useTicketsActions({
    isLoading,
    enabled: true,
  });

  return (
    <>
      <PageHeader
        actions={actions}
        menuActions={menuActions}
      />
      {dialog}
    </>
  );
}
```

## Notes

- All actions are suppressed (empty arrays returned) when `enabled` is `false`
- The "Archive Resolved Tickets" menu item is conditionally rendered only when `resolvedCount > 0`
- "Edit Statuses" is gated behind `featureFlags.ticketStatuses.enabled()`
- Archive action is disabled while `archiveResolvedMutation.isPending` or `isLoading` is `true`
