Fetches all available ticket labels/tags via GraphQL, returning a cached query result using TanStack Query.

## Key Components

- **`useTicketLabels()`** — React hook that retrieves the full list of ticket labels (`Tag[]`) from the GraphQL API, keyed under `ticketsQueryKeys.labels()`

## Usage Example

```typescript
import { useTicketLabels } from '@/hooks/use-ticket-labels';

function TicketLabelPicker() {
  const { data: labels, isLoading, isError } = useTicketLabels();

  if (isLoading) return <Spinner />;
  if (isError) return <p>Failed to load labels</p>;

  return (
    <ul>
      {labels?.map((label) => (
        <li key={label.id}>{label.name}</li>
      ))}
    </ul>
  );
}
```

## Notes

- Uses `ticketsQueryKeys.labels()` for consistent cache key management across the tickets domain
- Returns an empty array (`[]`) as a safe fallback if `ticketLabels` is absent in the GraphQL response
- Query result is automatically cached and shared across all components consuming this hook
