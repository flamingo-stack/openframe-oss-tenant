Fetches and caches the list of available ticket labels via a GraphQL query, returning typed `Tag` objects for use in ticket labeling UI components.

## Key Components

- **`useTicketLabels()`** — Custom React Query hook that queries the `ticketLabels` GraphQL endpoint, using `ticketsQueryKeys.labels()` as the cache key and returning an array of `Tag` objects (defaults to `[]` on empty response).

## Usage Example

```typescript
import { useTicketLabels } from '@/hooks/use-ticket-labels';

function TicketLabelPicker() {
  const { data: labels, isLoading, isError } = useTicketLabels();

  if (isLoading) return <Spinner />;
  if (isError) return <ErrorMessage />;

  return (
    <ul>
      {labels?.map((label) => (
        <li key={label.id}>{label.name}</li>
      ))}
    </ul>
  );
}
```
