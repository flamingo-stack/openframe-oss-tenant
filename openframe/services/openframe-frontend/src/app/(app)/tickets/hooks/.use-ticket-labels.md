Fetches all available ticket labels via GraphQL, returning them as a cached query using TanStack Query.

## Key Components

- **`useTicketLabels`** — React hook that queries the GraphQL endpoint for all ticket label tags, using `ticketsQueryKeys.labels()` as the cache key.

## Usage Example

```typescript
import { useTicketLabels } from '@/hooks/use-ticket-labels';

function TicketLabelFilter() {
  const { data: labels, isLoading, isError } = useTicketLabels();

  if (isLoading) return <Spinner />;
  if (isError) return <p>Failed to load labels</p>;

  return (
    <ul>
      {labels?.map((label) => (
        <li key={label.id}>{label.name}</li>
      ))}
    </ul>
  );
}
```

## Notes

- Returns `Tag[]` — falls back to an empty array if `ticketLabels` is absent in the response.
- Leverages `extractGraphQlData` to unwrap the GraphQL response and surface errors early.
- Cache is keyed via `ticketsQueryKeys.labels()`, enabling shared state across components without duplicate requests.
