Manages direct chat functionality for tickets, handling dialog creation, mode switching, and client message sending via React Query mutations.

## Key Components

- **`useDirectChat(options)`** — Primary hook that orchestrates direct chat operations for a given ticket
- **`createDialogMutation`** — Creates a new dialog in `DIRECT` mode when no dialog exists
- **`switchModeMutation`** — Switches an existing dialog to `DIRECT` mode via `PATCH` request
- **`sendClientMessageMutation`** — Sends a client message to the active dialog, resolving `dialogId` from cache if not provided
- **`setMode`** — Optimistically updates the React Query cache with the new dialog mode and ID

## Usage Example

```typescript
import { useDirectChat } from './use-direct-chat';

function TicketChatPanel({ ticketId, dialogId, currentMode }) {
  const {
    isDirectMode,
    isStartingDirectChat,
    isSendingClientMessage,
    startDirectChat,
    sendClientMessage,
  } = useDirectChat({
    ticketId,
    dialogId,
    currentMode,
    onDialogCreated: () => console.log('Dialog ready'),
  });

  return (
    <>
      <button onClick={startDirectChat} disabled={isStartingDirectChat}>
        {isDirectMode ? 'Direct Mode Active' : 'Start Direct Chat'}
      </button>
      <button onClick={() => sendClientMessage('Hello!')} disabled={isSendingClientMessage}>
        Send
      </button>
    </>
  );
}
```

## Returned Values

| Property | Type | Description |
|---|---|---|
| `isDirectMode` | `boolean` | Whether the current mode is `DIRECT` |
| `isStartingDirectChat` | `boolean` | Pending state for create or switch mutations |
| `isSendingClientMessage` | `boolean` | Pending state for message send |
| `startDirectChat` | `() => void` | Creates a new dialog or switches mode depending on `dialogId` presence |
| `sendClientMessage` | `(msg: string) => void` | Sends a trimmed message, no-ops if empty or pending |
