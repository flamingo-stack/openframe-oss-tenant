Manages direct client chat functionality for a ticket dialog, handling dialog creation, mode switching, and message sending via React Query mutations.

## Key Components

- **`useDirectChat`** — Main hook accepting `ticketId`, `dialogId`, `currentMode`, and optional `onDialogCreated` callback
- **`createDialogMutation`** — Creates a new `CLIENT`/`DIRECT` mode dialog via `POST /dialogs` when no dialog exists
- **`switchModeMutation`** — Switches an existing dialog to `DIRECT` mode via `PATCH /dialogs/:id/mode`
- **`sendClientMessageMutation`** — Sends a client message to the active dialog, resolving `dialogId` from cache if not provided
- **`setMode`** — Optimistically updates the React Query cache for the ticket detail query

## Usage Example

```typescript
const {
  isDirectMode,
  isStartingDirectChat,
  isSendingClientMessage,
  startDirectChat,
  sendClientMessage,
} = useDirectChat({
  ticketId: 'ticket-123',
  dialogId: 'dialog-456',        // undefined if no dialog exists yet
  currentMode: 'AI',             // current dialog mode
  onDialogCreated: () => {
    console.log('New dialog created, open chat panel');
  },
});

// Start or switch to direct chat
<Button
  onClick={startDirectChat}
  disabled={isStartingDirectChat}
>
  {isDirectMode ? 'Direct Chat Active' : 'Start Direct Chat'}
</Button>

// Send a message
<ChatInput
  onSend={sendClientMessage}
  disabled={isSendingClientMessage}
/>
```

## Behavior Notes

- If `dialogId` is `undefined`, triggers dialog creation; otherwise switches the existing dialog's mode
- Guards against concurrent mutations — `startDirectChat` is a no-op while either mutation is pending
- Tracks analytics via `EVENT_SUBTYPE.START_DIRECT_CHAT` on successful mode activation
- All failures surface as destructive toast notifications
