Manages direct chat functionality for a ticket dialog, handling creation of new dialogs, switching existing dialogs to direct mode, and sending client messages.

## Key Components

### `useDirectChat(options: UseDirectChatOptions)`

Main hook accepting:

| Option | Type | Description |
|---|---|---|
| `ticketId` | `string` | Target ticket identifier |
| `dialogId` | `string \| undefined` | Existing dialog ID if available |
| `currentMode` | `string \| undefined` | Current dialog mode |
| `onDialogCreated` | `() => void` | Optional callback fired after dialog creation |

**Returns:**

| Property | Type | Description |
|---|---|---|
| `isDirectMode` | `boolean` | Whether dialog is currently in direct mode |
| `isStartingDirectChat` | `boolean` | Pending state for create/switch mutations |
| `isSendingClientMessage` | `boolean` | Pending state for message send |
| `startDirectChat` | `() => void` | Initiates direct chat (creates or switches mode) |
| `sendClientMessage` | `(message: string) => void` | Sends a trimmed client message |

**Internal mutations:**
- `createDialogMutation` — `POST` to `API_ENDPOINTS.DIALOGS` with `DIALOG_MODE.DIRECT`
- `switchModeMutation` — `PATCH` to `dialogs/:id/mode` when a dialog already exists
- `sendClientMessageMutation` — Delegates to `ticketService.sendMessage` using the active dialog ID

## Usage Example

```typescript
const {
  isDirectMode,
  isStartingDirectChat,
  isSendingClientMessage,
  startDirectChat,
  sendClientMessage,
} = useDirectChat({
  ticketId: 'ticket-123',
  dialogId: existingDialogId,
  currentMode: dialog?.currentMode,
  onDialogCreated: () => scrollToBottom(),
});

// Start or switch to direct mode
startDirectChat();

// Send a message to the client
sendClientMessage('How can I help you today?');
```

> Both `startDirectChat` and `sendClientMessage` are no-ops when their respective mutations are already pending, preventing duplicate requests.
