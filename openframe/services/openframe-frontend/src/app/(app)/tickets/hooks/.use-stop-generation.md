Sends a stop-generation request for an active AI dialog, clearing the typing indicator on success and surfacing errors via toast notification.

## Key Components

- **`useStopGeneration(messageDialogId)`** — Custom hook that accepts an active dialog ID and returns controls to halt ongoing AI response generation.
- **`stopGeneration`** — Callback that triggers the stop mutation; no-ops if a request is already in flight.
- **`isStopping`** — Boolean flag indicating a pending stop request, useful for disabling UI controls.

## Usage Example

```typescript
import { useStopGeneration } from './use-stop-generation';

function ChatToolbar({ dialogId }: { dialogId: string | null }) {
  const { stopGeneration, isStopping } = useStopGeneration(dialogId);

  return (
    <button onClick={stopGeneration} disabled={isStopping}>
      {isStopping ? 'Stopping…' : 'Stop Generation'}
    </button>
  );
}
```

## Behavior Notes

| Scenario | Outcome |
|----------|---------|
| `messageDialogId` is `null` | Throws `"No active dialog to stop"` |
| Request succeeds | Sets admin typing indicator to `false` |
| Request fails | Displays destructive toast with error message |
| Called while already pending | No-op (guarded by `mutation.isPending`) |
