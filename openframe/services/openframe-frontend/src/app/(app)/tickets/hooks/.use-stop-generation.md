Provides a React hook for stopping an in-progress AI response generation for a specific message dialog, sending a stop request to the API and updating the typing indicator state on success.

## Key Components

- **`useStopGeneration(messageDialogId)`** — Main hook that accepts an active dialog ID and returns controls to cancel ongoing AI generation
- **`stopGeneration`** — Memoized callback that triggers the stop mutation; no-ops if a stop request is already in flight
- **`isStopping`** — Boolean flag indicating whether a stop request is currently pending
- **`mutation`** — TanStack Query mutation handling the `POST /{dialogId}/stop` API call with `chatType: ADMIN`

## Usage Example

```typescript
import { useStopGeneration } from './use-stop-generation';

function ChatControls({ activeDialogId }: { activeDialogId: string | null }) {
  const { stopGeneration, isStopping } = useStopGeneration(activeDialogId);

  return (
    <button
      onClick={stopGeneration}
      disabled={isStopping || !activeDialogId}
    >
      {isStopping ? 'Stopping...' : 'Stop Generation'}
    </button>
  );
}
```

## Behavior Notes

- If `messageDialogId` is `null`, the mutation throws immediately without making a network request
- On success, clears the `admin` typing indicator via `useTicketDetailsStore`
- On failure, surfaces a destructive toast notification with the error message and a 5-second duration
- Prevents duplicate stop requests by checking `mutation.isPending` before calling `mutate()`
