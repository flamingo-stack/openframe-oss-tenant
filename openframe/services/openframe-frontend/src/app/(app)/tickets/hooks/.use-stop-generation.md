Sends a stop-generation request for an active AI message dialog, disabling the typing indicator on success.

## Key Components

- **`useStopGeneration(messageDialogId)`** — Custom hook that accepts an active dialog ID and returns controls to abort AI response generation
- **`stopGeneration`** — Callback that POST to `{DIALOGS}/{messageDialogId}/stop` with `chatType: ADMIN`; guards against concurrent calls via `isPending` check
- **`isStopping`** — Boolean reflecting whether the stop request is in-flight
- **`setTypingIndicator`** — Clears the `admin` typing indicator in `useTicketDetailsStore` on success
- Displays a destructive toast notification on failure

## Usage Example

```typescript
import { useStopGeneration } from './use-stop-generation';

function StopButton({ dialogId }: { dialogId: string | null }) {
  const { stopGeneration, isStopping } = useStopGeneration(dialogId);

  return (
    <button onClick={stopGeneration} disabled={isStopping}>
      {isStopping ? 'Stopping...' : 'Stop Generation'}
    </button>
  );
}
```
