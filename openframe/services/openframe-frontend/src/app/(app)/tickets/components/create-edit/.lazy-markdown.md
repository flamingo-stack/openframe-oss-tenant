Lazy-loads `SimpleMarkdownRenderer` and `MarkdownEditor` from `@flamingo-stack/openframe-frontend-core` using Next.js dynamic imports, disabling SSR for both components.

## Key Components

- **`SimpleMarkdownRenderer`** — Dynamically imported renderer for displaying markdown content; client-side only, renders `null` during load.
- **`MarkdownEditor`** — Dynamically imported rich markdown editor component; client-side only, renders `null` during load.

## Usage Example

```typescript
import { SimpleMarkdownRenderer, MarkdownEditor } from './lazy-markdown';

// Render markdown content
<SimpleMarkdownRenderer content="## Hello World" />

// Edit markdown content
<MarkdownEditor value={markdown} onChange={setMarkdown} />
```

> Both exports preserve full prop types from their source components via `ComponentProps`, ensuring type safety without eagerly loading the underlying modules.
