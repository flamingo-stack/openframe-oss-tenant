Defines the column structure and table body component for displaying support tickets in a data table, including title, source, assignee, and status columns with configurable filtering and navigation.

## Key Components

- **`getTicketTableColumns(options)`** — Returns an array of `ColumnDef<Dialog>` objects for the ticket table. Accepts `isArchived` flag to conditionally enable status filter options. Columns: `title` (with timestamp), `source` (device/org info), `assignee` (avatar + name), `status` (tag with optional multi-select filter).
- **`ticketRowHref(ticket)`** — Generates the navigation URL for a ticket row: `/tickets/dialog?id=<id>`.
- **`TICKET_OPEN_COLUMN`** — A static column definition rendering an "open in new tab" button, bypassing row-click navigation via `data-no-row-click`.
- **`TicketTableBody`** — The primary rendered component. Composes columns via `useMemo`, initialises a `useDataTable` instance, and renders a full `DataTable` with sticky header, loading skeletons, empty state, and an optional footer slot.

## Usage Example

```typescript
// Basic ticket table with archived mode and custom actions column
<TicketTableBody
  tickets={ticketList}
  isLoading={isFetching}
  isArchived={false}
  emptyMessage="No open tickets."
  skeletonRows={5}
  stickyHeaderOffset="64px"
  actionsColumn={myActionsColumnDef}
  columnFilters={filters}
  onColumnFiltersChange={setFilters}
  footerSlot={<Pagination />}
/>

// Standalone column definitions (e.g. for a custom table setup)
const columns = getTicketTableColumns({ isArchived: true });
```

## Notes

- Responsive visibility is controlled via `meta.hideAt`: `sourceColumn` hides at `md`, `middleColumn` at `lg`.
- Status filter options (`ACTIVE`, `TECH_REQUIRED`, `ON_HOLD`, `RESOLVED`) are only injected when `isArchived` is `false`.
- `formatTimestamp` safely falls back to the raw string if the date is invalid.
