Defines column configurations and the `TicketTableBody` component for rendering a filterable, navigable ticket data table using the OpenFrame UI system.

## Key Components

### `getTicketTableColumns(options)`
Returns an array of `ColumnDef<Dialog>` column definitions for the ticket table:
- **TITLE** — Displays ticket title and formatted creation timestamp.
- **SOURCE** — Shows device/machine hostname and organization via `DeviceCardCompact`.
- **ASSIGNEE** — Renders assignee avatar and name, hidden on smaller screens.
- **STATUS** — Renders a `TicketStatusTag`; includes multi-select filter options when `isArchived` is `false`.

### `ticketRowHref(ticket)`
Returns the navigation URL string for a given ticket row: `/tickets/dialog?id=<id>`.

### `TICKET_OPEN_COLUMN`
A static column definition that renders an "Open in new tab" icon button, bypassing row-click navigation via `data-no-row-click`.

### `TicketTableBody`
A self-contained table component that composes columns, wires up `useDataTable`, and renders the full `DataTable` layout including header, body, and optional footer slot.

## Usage Example

```typescript
import { TicketTableBody } from './ticket-table-columns';

<TicketTableBody
  tickets={dialogList}
  isLoading={isFetching}
  emptyMessage="No open tickets."
  stickyHeaderOffset="64px"
  isArchived={false}
  columnFilters={filters}
  onColumnFiltersChange={setFilters}
  footerSlot={<Pagination />}
/>
```

To use columns independently:

```typescript
import { getTicketTableColumns, TICKET_OPEN_COLUMN } from './ticket-table-columns';

const columns = [
  ...getTicketTableColumns({ isArchived: true }),
  TICKET_OPEN_COLUMN,
];
```
