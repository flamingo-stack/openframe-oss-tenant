Renders the unified Create/Edit Ticket page, dynamically switching between creation and edit modes based on the `edit` query parameter.

## Key Components

- **`CreateEditTicketPage`** — Main page component that composes the ticket form layout with context-aware navigation and actions
- **`useCreateTicketForm`** — Custom hook providing form state, submission handling, attachments, and edit-mode detection
- **`useSafeBack`** — Hook for safe back-navigation, routing to the ticket dialog or ticket list depending on mode
- **`TicketFormFields`** — Form UI component rendering all ticket input fields
- **`PageLayout`** — Shell component providing title, back button, and action bar

## Usage Example

```typescript
// Rendered automatically via Next.js routing
// Accessed as: /tickets/new          → Create mode
// Accessed as: /tickets/new?edit=123 → Edit mode for ticket ID 123

import { CreateEditTicketPage } from './create-edit-ticket-page';

export default function Page() {
  return <CreateEditTicketPage />;
}
```

## Behavior Notes

- If `?edit=<ticketId>` is present in the URL, the page enters **edit mode**: title becomes "Edit Ticket", save button reads "Save Changes", and back navigation returns to the ticket dialog
- Without the param, the page is in **create mode**: title is "New Ticket", back navigates to `/tickets`
- The save action is disabled while the ticket is loading or a submission is in progress
- Supports Fae form variant via `isFaeForm` flag passed down to `TicketFormFields`
