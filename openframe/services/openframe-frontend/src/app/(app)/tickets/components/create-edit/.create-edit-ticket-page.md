Renders the unified Create/Edit Ticket page, dynamically switching between "New Ticket" and "Edit Ticket" modes based on the presence of an `edit` query parameter.

## Key Components

- **`CreateEditTicketPage`** — Main page component; reads `?edit=<ticketId>` from the URL to determine create vs. edit mode
- **`useCreateTicketForm`** — Custom hook providing form state, submission logic, attachment handling, and loading flags
- **`useSafeBack`** — Hook that constructs safe back-navigation handlers (falls back to `/tickets` or the specific ticket dialog)
- **`TicketFormFields`** — Renders the actual form inputs, attachment previews, and Fae-specific fields
- **`PageLayout`** — Shell component providing the page title, back button, and action bar

## Usage Example

```typescript
// Rendered at /tickets/create or /tickets/create?edit=<ticketId>
// No props required — all state is derived from URL search params

import { CreateEditTicketPage } from './create-edit-ticket-page';

export default function Page() {
  return <CreateEditTicketPage />;
}
```

**Edit mode** is activated automatically when the URL contains `?edit=<ticketId>`:

```text
/tickets/create            → "New Ticket" form, saves back to /tickets
/tickets/create?edit=123   → "Edit Ticket" form, saves back to /tickets/dialog?id=123
```

The action button label and back-navigation destination both update reactively via `useMemo`, ensuring no stale closures across mode transitions.
