Renders the unified create/edit ticket page, determining mode based on the presence of an `edit` query parameter and wiring up form state, navigation, and action buttons.

## Key Components

- **`CreateEditTicketPage`** — Main page component that handles both ticket creation and editing flows
- **`useCreateTicketForm`** — Hook providing form state, submission logic, attachment handling, and edit/Fae form detection
- **`useSafeBack`** — Hook for safe back-navigation, routing to the ticket dialog (edit mode) or tickets list (create mode)
- **`TicketFormFields`** — Renders the actual form inputs, receiving form state, attachments, and mode flags
- **`PageLayout`** — Shell component providing title, back button, and action bar

## Usage Example

```typescript
// Rendered at /tickets/new or /tickets/new?edit=<ticketId>
// No props required — reads query params internally
<CreateEditTicketPage />
```

```typescript
// Edit mode is activated via the `edit` query param:
// /tickets/new?edit=abc123
// → title becomes "Edit Ticket"
// → save button label becomes "Save Changes"
// → back button navigates to /tickets/dialog?id=abc123
```

The `actions` array passed to `PageLayout` disables the save button while the ticket is loading or submitting, and shows a loading spinner during submission. Navigation context is resolved at render time via `useMemo` to avoid unnecessary re-computation on unrelated state changes.
