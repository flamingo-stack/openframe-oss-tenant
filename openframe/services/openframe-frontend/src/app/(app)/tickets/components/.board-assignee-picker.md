A compact assignee picker component for Kanban board tickets, rendering an `AssigneeDropdown` that allows users to assign or reassign a ticket directly from the board view.

## Key Components

- **`BoardAssigneePicker`** — Main exported component that wires board ticket data to the `AssigneeDropdown` UI element
- **`useAssigneeOptions`** — Hook providing the list of available assignee options with loading state
- **`useAssignTicket`** — Hook exposing the mutation function to assign a ticket to a user
- **`getFullImageUrl`** — Utility to resolve full avatar image URLs from relative paths

## Usage Example

```typescript
import { BoardAssigneePicker } from './board-assignee-picker';
import type { BoardTicket } from '@flamingo-stack/openframe-frontend-core/components/features';

const ticket: BoardTicket = {
  id: 'ticket-123',
  assignees: [
    {
      id: 'user-1',
      name: 'Jane Doe',
      initials: 'JD',
      avatarUrl: '/avatars/jane.png',
    },
  ],
  // ...other ticket fields
};

export function BoardCard() {
  return <BoardAssigneePicker ticket={ticket} />;
}
```

## Notes

- Only the **first assignee** (`ticket.assignees?.[0]`) is displayed; multi-assignee scenarios are not surfaced in this component
- The dropdown renders in `compact` variant, suited for space-constrained board cards
- Assignee name falls back to `initials` then `id` if `name` is unavailable
