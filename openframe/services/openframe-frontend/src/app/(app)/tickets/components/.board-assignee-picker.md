A compact React component that renders an assignee picker dropdown for a kanban board ticket, wiring together assignee options and the assign mutation.

## Key Components

- **`BoardAssigneePicker`** — Default export component that wraps `AssigneeDropdown` with board-specific data and mutation logic
- **`BoardAssigneePickerProps`** — Interface accepting a single `ticket: BoardTicket` prop
- **`useAssigneeOptions`** — Hook providing available assignee `options` and `isLoading` state
- **`useAssignTicket`** — Hook returning a mutation for assigning a ticket to a user
- **`getFullImageUrl`** — Utility resolving relative avatar URLs to absolute paths

## Usage Example

```typescript
import { BoardAssigneePicker } from './board-assignee-picker';

// Inside a board ticket card
function TicketCard({ ticket }: { ticket: BoardTicket }) {
  return (
    <div className="ticket-card">
      <span>{ticket.title}</span>
      <BoardAssigneePicker ticket={ticket} />
    </div>
  );
}
```

## Behavior Notes

- Displays the **first assignee** from `ticket.assignees` array (index `[0]`); tickets with multiple assignees only show one in this picker
- Assignee display name falls back through: `name → initials → id`
- Renders in **compact variant** — suited for space-constrained board card layouts
- Passes `isPending` from the mutation to the dropdown to handle in-flight UI states (e.g., loading spinner on the avatar)
