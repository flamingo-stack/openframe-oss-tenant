A compact assignee picker component for Kanban board tickets that renders an `AssigneeDropdown` in compact variant, loading available assignees and handling assignment mutations.

## Key Components

- **`BoardAssigneePicker`** — Main exported component that wraps `AssigneeDropdown` with board-specific data fetching and mutation logic
- **`useAssigneeOptions`** — Hook providing the list of available assignee options and loading state
- **`useAssignTicket`** — Hook exposing the assign mutation (`mutate`, `isPending`) for updating ticket assignees
- **`getFullImageUrl`** — Utility to resolve full avatar image URLs from relative paths

## Usage Example

```typescript
import { BoardAssigneePicker } from './board-assignee-picker';
import type { BoardTicket } from '@flamingo-stack/openframe-frontend-core/components/features';

const ticket: BoardTicket = {
  id: 'ticket-123',
  assignees: [
    {
      id: 'user-1',
      name: 'Jane Doe',
      initials: 'JD',
      avatarUrl: '/avatars/jane.png',
    },
  ],
  // ...other ticket fields
};

export function BoardCard() {
  return (
    <div className="board-card">
      <BoardAssigneePicker ticket={ticket} />
    </div>
  );
}
```

## Notes

- Only the **first assignee** (`ticket.assignees?.[0]`) is displayed; multi-assignee scenarios are not surfaced in the UI
- Falls back gracefully through `name → initials → id` for display label when name is absent
- Passes `isPending` to the dropdown to show loading state during an in-flight assignment mutation
