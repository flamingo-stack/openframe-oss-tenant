Kanban-style board view for managing tickets across lifecycle statuses, with support for drag-and-drop column transitions, real-time column updates, search, and filtering by organization and assignee.

## Key Components

**`TicketsBoardLifecycle`** — Main exported component that renders a full-page board layout with:
- Debounced search input
- Organization and assignee filters
- Draggable ticket columns mapped to ticket statuses
- Infinite scroll per column via `loadMore`
- Transition rule enforcement (allowed column moves)
- Archive action for resolved tickets

**`dialogToBoardTicket(dialog)`** — Maps internal `Dialog` type to the `BoardTicket` shape expected by the `Board` component, including assignee initials generation.

**`initialsOf(name)`** — Utility that derives 1–2 character initials from a display name string.

## Usage Example

```typescript
import { TicketsBoardLifecycle } from './tickets-board-lifecycle';

function TicketsPage() {
  const [search, setSearch] = useState('');
  const [orgIds, setOrgIds] = useState<string[]>([]);
  const [assigneeIds, setAssigneeIds] = useState<string[]>([]);

  return (
    <TicketsBoardLifecycle
      search={search}
      onSearchChange={setSearch}
      organizationIds={orgIds}
      onOrganizationIdsChange={setOrgIds}
      assigneeIds={assigneeIds}
      onAssigneeIdsChange={setAssigneeIds}
      selector={<ViewSelector />}
    />
  );
}
```

> **Note:** Each board column is independently subscribed via `BoardColumnSubscriber`, enabling paginated, per-status data fetching. Column transitions are validated against `useTicketStatusTransitionRules` before a move is committed via `useMoveTicketLifecycle`.
