Kanban-style board component for managing tickets across lifecycle statuses, with drag-and-drop column transitions, search, and filtering by organization and assignee.

## Key Components

**`TicketsBoardLifecycle`** — Main exported component that renders a full-page board layout with:
- Debounced search input
- Organization and assignee filters
- Status columns derived from `useTicketStatusesQuery`
- Drag-and-drop ticket movement via `useMoveTicketLifecycle`
- Transition rule enforcement via `useTicketStatusTransitionRules`
- Per-column lazy loading via `BoardColumnSubscriber`

**`dialogToBoardTicket(dialog)`** — Maps a `Dialog` entity to the `BoardTicket` shape expected by the `Board` component, including assignee initials and device hostnames.

**`initialsOf(name)`** — Utility that extracts up to two uppercase initials from a display name string.

## Usage Example

```typescript
import { TicketsBoardLifecycle } from './tickets-board-lifecycle';
import { useState } from 'react';

export function TicketsBoardPage() {
  const [search, setSearch] = useState('');
  const [orgIds, setOrgIds] = useState<string[]>([]);
  const [assigneeIds, setAssigneeIds] = useState<string[]>([]);

  return (
    <TicketsBoardLifecycle
      search={search}
      onSearchChange={setSearch}
      organizationIds={orgIds}
      onOrganizationIdsChange={setOrgIds}
      assigneeIds={assigneeIds}
      onAssigneeIdsChange={setAssigneeIds}
      selector={<MyViewSelector />}
    />
  );
}
```

> **Note:** `ARCHIVED` status columns are automatically excluded from the board. Columns with `RESOLVED` kind expose an archive action when `canArchiveResolved` is truthy, controlled by `useTicketsActions`.
