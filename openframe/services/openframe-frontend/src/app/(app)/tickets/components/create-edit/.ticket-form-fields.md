Renders the complete set of form fields for creating or editing a support ticket, wiring React Hook Form controllers to UI components for title, customer, device, assignee, tags, file uploads, description, and assignments.

## Key Components

- **`TicketFormFields`** — Main export; a controlled form field group accepting a `UseFormReturn<CreateTicketFormData>` instance and temp attachment state
- **`TicketFormFieldsProps`** — Interface accepting `form`, `tempAttachments`, `isFaeForm` (client-facing mode), and `isEditMode` flags
- **`managedFiles`** — Memoized mapping that normalizes `'existing'` attachment status to `'uploaded'` for the `FileUpload` component
- **`renderPreview`** — Memoized callback rendering a `SimpleMarkdownRenderer` inside the Markdown editor's preview pane

## Field Layout

| Field | Component | Notes |
|-------|-----------|-------|
| Title | `Input` | Text input with validation error display |
| Customer | `Autocomplete` | Debounced search; disabled in Fae/edit-with-device mode |
| Device | `Autocomplete` | Dependent on selected org; debounced search |
| Assigned | `Autocomplete` | Technician assignee with avatar rendering |
| Labels | `TicketTagsManager` | Tag multi-select |
| Files | `FileUpload` | Managed mode with temp attachment lifecycle |
| Description | `MarkdownEditor` | 500px height with live preview; disabled in Fae mode |
| Assignments | `AssignmentsField` | Supports `ORGANIZATION`, `DEVICE`, `KNOWLEDGE_ARTICLE` types |

## Usage Example

```typescript
import { TicketFormFields } from './ticket-form-fields';
import { useForm } from 'react-hook-form';
import { useTempAttachments } from '../../hooks/use-temp-attachments';

function CreateTicketForm() {
  const form = useForm<CreateTicketFormData>();
  const tempAttachments = useTempAttachments();

  return (
    <form onSubmit={form.handleSubmit(onSubmit)}>
      <TicketFormFields
        form={form}
        tempAttachments={tempAttachments}
        isFaeForm={false}
        isEditMode={false}
      />
    </form>
  );
}
```

> **Note:** When `isFaeForm={true}`, the Customer, Device, and Description fields are disabled — restricting client-submitted ticket edits. When `isEditMode={true}` and a device is already selected (`lockOrgAndDevice`), the Customer and Device dropdowns are locked to prevent reassignment.
