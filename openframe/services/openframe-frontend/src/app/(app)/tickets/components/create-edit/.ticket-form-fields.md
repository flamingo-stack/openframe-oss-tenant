Renders the controlled form fields for creating or editing a support ticket, wiring together React Hook Form controllers with UI components for title, customer, device, assignee, tags, file attachments, description, and assignments.

## Key Components

| Export / Symbol | Description |
|---|---|
| `TicketFormFields` | Main component rendering all ticket form fields via `react-hook-form` `Controller` wrappers |
| `TicketFormFieldsProps` | Interface accepting the RHF form instance, temp attachment state, and optional `isFaeForm` / `isEditMode` flags |
| `managedFiles` | Memoized mapping that normalises `'existing'` attachment status to `'uploaded'` for the `FileUpload` component |
| `renderPreview` | Memoized callback rendering a `SimpleMarkdownRenderer` inside the markdown editor preview pane |
| `handleFilesAdded` | Handler normalising single/array file input and delegating to `tempAttachments.uploadFile` |

## Usage Example

```typescript
import { TicketFormFields } from './ticket-form-fields';
import { useForm } from 'react-hook-form';
import { useTempAttachments } from '../../hooks/use-temp-attachments';
import type { CreateTicketFormData } from '../../types/create-ticket.types';

function CreateTicketForm() {
  const form = useForm<CreateTicketFormData>();
  const tempAttachments = useTempAttachments();

  return (
    <form onSubmit={form.handleSubmit(onSubmit)}>
      <TicketFormFields
        form={form}
        tempAttachments={tempAttachments}
        isFaeForm={false}
        isEditMode={false}
      />
    </form>
  );
}
```

## Notes

- **`isFaeForm`** disables the customer, device, and description fields when rendered in a client-facing (Fae) context.
- **`lockOrgAndDevice`** prevents changing the organisation or device in edit mode when a device is already attached.
- Organisation and device searches are debounced at **300 ms** to avoid excessive API calls.
- The `AssignmentsField` is scoped to `ORGANIZATION`, `DEVICE`, and `KNOWLEDGE_ARTICLE` assignment types.
