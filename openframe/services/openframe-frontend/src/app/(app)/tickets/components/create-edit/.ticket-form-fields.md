Renders the complete set of form fields for creating or editing a support ticket, wiring React Hook Form controllers to UI components for title, customer, device, assignee, tags, file attachments, description, and assignments.

## Key Components

- **`TicketFormFields`** — Main export; a controlled form section accepting a `UseFormReturn<CreateTicketFormData>` instance and temp attachment state
- **`tempAttachments`** — Managed file upload state via `useTempAttachments`; maps `existing` status to `uploaded` for the `FileUpload` component
- **`useOrganizationOptions` / `useDeviceOptions` / `useAssigneeOptions`** — Debounced async option loaders for autocomplete fields
- **`TicketTagsManager`** — Label/tag selector bound to `labelIds`
- **`MarkdownEditor`** — Lazy-loaded rich text editor for the description field with inline preview via `SimpleMarkdownRenderer`
- **`AssignmentsField`** — Multi-type assignment selector supporting `ORGANIZATION`, `DEVICE`, and `KNOWLEDGE_ARTICLE`

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `form` | `UseFormReturn<CreateTicketFormData>` | — | RHF form instance |
| `tempAttachments` | `ReturnType<typeof useTempAttachments>` | — | File upload state |
| `isFaeForm` | `boolean` | `false` | Disables org, device, and description fields for client-facing (Fae) forms |
| `isEditMode` | `boolean` | `false` | Locks org/device fields when a device is already selected |

## Usage Example

```typescript
import { useForm } from 'react-hook-form';
import { TicketFormFields } from './ticket-form-fields';
import { useTempAttachments } from '../../hooks/use-temp-attachments';
import type { CreateTicketFormData } from '../../types/create-ticket.types';

function CreateTicketForm() {
  const form = useForm<CreateTicketFormData>();
  const tempAttachments = useTempAttachments();

  return (
    <form onSubmit={form.handleSubmit(onSubmit)}>
      <TicketFormFields
        form={form}
        tempAttachments={tempAttachments}
        isFaeForm={false}
        isEditMode={false}
      />
    </form>
  );
}
```

> **Note:** Device selection is automatically cleared when the customer changes. In edit mode with an existing device, both the customer and device fields are locked to prevent reassignment.
