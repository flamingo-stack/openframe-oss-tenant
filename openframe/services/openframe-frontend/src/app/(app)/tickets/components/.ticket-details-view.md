Brief description of the main ticket details view component that renders the full ticket/dialog interface including dual chat channels (client Fae AI + admin Mingo AI), ticket info, notes, attachments, device actions, and approval workflows for the Flamingo MSP platform.

## Key Components

### Main Export
- **`TicketDetailsView`** — Primary React component rendering the complete ticket detail page with tabbed chat interface, ticket metadata, and action menus

### Helper Functions
- **`maxLastChunkStreamSeq`** — Calculates the highest stream sequence number across all message pages for chunk catchup synchronization
- **`withActivityTracking`** — HOC-style wrapper that decorates device menu items with analytics event tracking, recursively applying to submenu leaf nodes

### Key Hooks Used
| Hook | Purpose |
|------|---------|
| `useTicketDetail` | Fetches ticket/dialog metadata |
| `useTicketMessages` | Loads paginated message history per chat type |
| `useChunkCatchup` | Manages real-time streaming chunk synchronization |
| `useSideChunkProcessor` | Processes SSE chunks into typed chat messages per side (client/admin) |
| `useDirectChat` | Manages direct-mode client chat initiation |
| `useSendAdminMessage` | Sends admin (Mingo AI) messages |
| `useApprovalRequests` | Handles approval/rejection of pending AI actions |
| `useDeviceActionsMenu` | Builds context menu for device remote actions |
| `useTicketDetailsStore` | Zustand store for dual chat state accumulation |

### State Management
- Dual AI model tracking (`currentClientModel` / `currentAdminModel`) for Fae and Mingo display
- `activeChatTab` — toggles between client and admin chat panes
- `ticketInfoExpanded` — auto-expands for form/dashboard-created tickets
- `noteToDelete` — confirmation dialog state for note deletion

## Usage Example

```typescript
// Render the full ticket detail view for a given ticket ID
import { TicketDetailsView } from './ticket-details-view';

export default function TicketPage({ params }: { params: { id: string } }) {
  return <TicketDetailsView ticketId={params.id} />;
}
```

```typescript
// withActivityTracking wraps device menu items with analytics
const trackedItems = deviceMenuItems.map(item =>

```

> **Note:** This component depends on `TicketDialogSubscription` for NATS real-time message streaming and `useTicketDetailsStore` for cross-chunk state accumulation across client and admin chat channels.
