Multi-select autocomplete filter component for filtering tickets by assignee, with the current user's option automatically sorted to the top of the list.

## Key Components

- **`AssigneeFilter`** — Main exported component; renders a multi-select `Autocomplete` with avatar-rendered options and a filter icon adornment
- **`AssigneeFilterProps`** — Interface defining `value` (selected IDs), `onChange` handler, and optional `className`
- **`renderOption`** — Avatar renderer using round style, derived from `renderAvatarOption`
- **`sortedOptions`** — Memoized list that hoists the current user's entry to the first position

## Usage Example

```typescript
import { AssigneeFilter } from './assignee-filter';

function TicketFilters() {
  const [assignees, setAssignees] = useState<string[]>([]);

  return (
    <AssigneeFilter
      value={assignees}
      onChange={setAssignees}
      className="w-64"
    />
  );
}
```

## Behavior Notes

- Pulls assignee options from `useAssigneeOptions` hook
- Reads the authenticated user's ID via `useAuthStore` to prioritize their entry
- Displays `"Show All Employees"` as placeholder when no selection is made
- Passes `loading` state through to the `Autocomplete` during data fetch
