Multi-select autocomplete filter component for filtering tickets by assignee, with the current user automatically sorted to the top of the options list.

## Key Components

- **`AssigneeFilter`** — Main exported component that renders a multi-select autocomplete for assignee filtering
- **`AssigneeFilterProps`** — Interface defining `value` (selected assignee IDs), `onChange` callback, and optional `className`
- **`renderOption`** — Avatar renderer using `renderAvatarOption` with `'round'` variant for displaying user avatars in the dropdown

## Behavior

- Fetches assignee options via `useAssigneeOptions` hook
- Reads the current authenticated user's ID from `useAuthStore`
- Sorts options so the **current user always appears first** in the list (if present)
- Displays a filter icon as a start adornment
- Falls back to showing all employees when no selection is made (`placeholder="Show All Employees"`)

## Usage Example

```typescript
import { AssigneeFilter } from './assignee-filter';
import { useState } from 'react';

function TicketFilters() {
  const [assignees, setAssignees] = useState<string[]>([]);

  return (
    <AssigneeFilter
      value={assignees}
      onChange={setAssignees}
      className="w-64"
    />
  );
}
```
