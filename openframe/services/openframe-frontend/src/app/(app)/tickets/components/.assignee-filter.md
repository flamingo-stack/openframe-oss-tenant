Multi-select autocomplete filter component for filtering tickets by assignee, rendering employee options with circular avatar thumbnails.

## Key Components

- **`AssigneeFilter`** — Main exported component. Renders a multi-select `Autocomplete` with a filter icon adornment, wired to available assignee options.
- **`AssigneeFilterProps`** — Interface defining `value` (selected assignee IDs), `onChange` callback, and optional `className`.
- **`renderOption`** — Avatar renderer configured with `'round'` shape, delegated to `renderAvatarOption`.
- **`useAssigneeOptions`** — Hook providing the `options` array and `isLoading` state for available assignees.

## Usage Example

```typescript
import { AssigneeFilter } from './assignee-filter';

function TicketFilters() {
  const [selectedAssignees, setSelectedAssignees] = useState<string[]>([]);

  return (
    <AssigneeFilter
      value={selectedAssignees}
      onChange={setSelectedAssignees}
      className="w-64"
    />
  );
}
```

## Notes

- Defaults to `"Show All Employees"` placeholder when no selection is active.
- Loading state is handled automatically via `useAssigneeOptions` — the dropdown shows a loading indicator while options are being fetched.
- Avatar rendering is shared via `renderAvatarOption` to maintain consistency with other avatar-based filters in the same feature.
