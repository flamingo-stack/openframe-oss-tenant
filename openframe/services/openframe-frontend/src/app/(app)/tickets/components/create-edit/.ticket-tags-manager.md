Autocomplete-based component for managing tags on a ticket, supporting both selection of existing tags and optimistic creation of new ones.

## Key Components

- **`TicketTagsManager`** — Main component that renders a multi-select autocomplete for ticket tags
- **`useTicketLabels`** — Hook that fetches available ticket labels/tags
- **`useCreateTagMutation`** — Hook that handles tag creation API calls
- **`optimisticTags`** — Local state for immediately reflecting newly created tags before the server confirms them

## Behavior

- Merges server-fetched tags with locally created (optimistic) tags into a single options list
- On selection of a new (unknown) value, assigns a temporary `_optimistic_<uuid>` ID and calls `createTag` in the background
- Once the tag is persisted, replaces the temp ID with the real server ID and removes it from the optimistic list
- Supports `disabled` state and shows a loading indicator while a tag is being created

## Props

| Prop | Type | Description |
|------|------|-------------|
| `selectedIds` | `string[]` | Currently selected tag IDs |
| `onChange` | `(ids: string[]) => void` | Callback fired with updated tag ID list |
| `disabled` | `boolean?` | Disables the control when `true` |

## Usage Example

```typescript
import { TicketTagsManager } from './ticket-tags-manager';

function TicketForm() {
  const [tagIds, setTagIds] = useState<string[]>([]);

  return (
    <TicketTagsManager
      selectedIds={tagIds}
      onChange={setTagIds}
    />
  );
}
```
