Manages ticket tag selection with support for creating new tags inline via an autocomplete UI, using optimistic updates to provide immediate feedback while tag creation completes in the background.

## Key Components

### `TicketTagsManager`
Main exported component that renders a multi-select autocomplete for assigning tags to a ticket.

**Props (`TicketTagsManagerProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `selectedIds` | `string[]` | Currently selected tag IDs |
| `onChange` | `(ids: string[]) => void` | Callback fired when selection changes |
| `disabled` | `boolean?` | Disables the control when `true` |

**Internal behavior:**
- `optimisticTags` — temporary in-memory tags assigned a `_optimistic_` prefixed UUID while the real create mutation is in-flight
- `options` — merged list of persisted tags and optimistic tags passed to the `Autocomplete`
- `handleChange` — separates incoming values into existing IDs vs. new free-text keys, triggers `createTag` for each new key, then swaps the temp ID for the real ID once the mutation resolves

## Usage Example

```typescript
import { TicketTagsManager } from './ticket-tags-manager';

function TicketForm() {
  const [tagIds, setTagIds] = useState<string[]>([]);

  return (
    <TicketTagsManager
      selectedIds={tagIds}
      onChange={setTagIds}
    />
  );
}
```

> **Optimistic flow:** When a user types a new tag and confirms, a temporary ID (`_optimistic_<uuid>`) is added immediately so the UI reflects the change without waiting for the API. Once `createTag` resolves, the temp ID is replaced with the real persisted ID and `optimisticTags` state is cleared.
