Utility module providing avatar-enhanced rendering helpers for autocomplete components, supporting both round and square avatar variants with selection state indicators.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `AvatarVariant` | `type` | Union type: `'round' \| 'square'` |
| `renderAvatarOption` | `function` | Higher-order function returning a renderer for autocomplete dropdown options with avatar + label + check icon |
| `avatarStartAdornment` | `function` | Returns a standalone avatar node for use as an input start adornment |

## Usage Example

```typescript
import {
  renderAvatarOption,
  avatarStartAdornment,
} from './avatar-autocomplete';

// Render dropdown options with round avatars
const optionRenderer = renderAvatarOption('round');

<Autocomplete
  options={technicianOptions}
  renderOption={optionRenderer}
  startAdornment={avatarStartAdornment(selectedOption, 'round')}
/>

// Use square avatars for company/organization pickers
const squareOptionRenderer = renderAvatarOption('square');

<Autocomplete
  options={companyOptions}
  renderOption={squareOptionRenderer}
  startAdornment={avatarStartAdornment(selectedCompany, 'square')}
/>
```

## Notes

- `renderAvatarOption` is curried — call it with a `variant` to get a renderer compatible with the `AutocompleteOption` interface
- Selected options receive a teal `CheckIcon` (`text-ods-accent`) aligned to the right
- Image URLs are normalized via `getFullImageUrl` before being passed to `SquareAvatar`
- Both helpers consume `AvatarOption` (extends `AutocompleteOption` with an `imageUrl` field) from the ticket options hook
