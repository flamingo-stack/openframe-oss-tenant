Utility module providing avatar-enhanced rendering functions for autocomplete components, supporting both round and square avatar variants with selection indicators.

## Key Components

- **`renderAvatarOption(variant)`** — Higher-order function returning an autocomplete option renderer that displays a `SquareAvatar` alongside the label, with a checkmark icon (`CheckIcon`) when the option is selected
- **`avatarStartAdornment(option, variant)`** — Returns a `SquareAvatar` node to use as a start adornment (prefix icon) inside an autocomplete input field; returns `undefined` if no option is provided
- **`AvatarVariant`** — Union type `'round' | 'square'` controlling avatar shape

## Usage Example

```typescript
import {
  renderAvatarOption,
  avatarStartAdornment,
} from './avatar-autocomplete';

// Render each dropdown option with an avatar
<Autocomplete
  options={technicianOptions}
  renderOption={renderAvatarOption('round')}
  startAdornment={avatarStartAdornment(selectedOption, 'round')}
/>

// Square variant for company/organization pickers
<Autocomplete
  options={companyOptions}
  renderOption={renderAvatarOption('square')}
  startAdornment={avatarStartAdornment(selectedOption, 'square')}
/>
```
