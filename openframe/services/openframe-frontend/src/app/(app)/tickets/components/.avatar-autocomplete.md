Utility module providing avatar-enhanced autocomplete rendering helpers for ticket option fields.

## Key Components

- **`AvatarVariant`** — Union type (`'round' | 'square'`) controlling avatar shape
- **`renderAvatarOption(variant)`** — Higher-order function returning an autocomplete option renderer that displays a `SquareAvatar`, truncated label, and a checkmark when selected
- **`avatarStartAdornment(option, variant)`** — Returns a `SquareAvatar` node for use as a leading adornment inside an autocomplete input field

## Usage Example

```typescript
import {
  renderAvatarOption,
  avatarStartAdornment,
} from './avatar-autocomplete';

// Render each dropdown option with a round avatar
<Autocomplete
  options={agentOptions}
  renderOption={renderAvatarOption('round')}
  startAdornment={avatarStartAdornment(selectedAgent, 'round')}
/>

// Render each dropdown option with a square avatar
<Autocomplete
  options={companyOptions}
  renderOption={renderAvatarOption('square')}
  startAdornment={avatarStartAdornment(selectedCompany, 'square')}
/>
```

## Notes

- Relies on `getFullImageUrl` to resolve relative image paths before passing them to `SquareAvatar`
- Expects options to conform to the `AvatarOption` shape (extends `AutocompleteOption` with an `imageUrl` field)
- The selected-state checkmark uses the `text-ods-accent` theme token for consistent accent coloring
