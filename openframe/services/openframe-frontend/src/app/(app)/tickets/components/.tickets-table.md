A reusable tickets data table component that renders a paginated, filterable, and searchable list of support tickets with support for both active and archived views.

## Key Components

### `TicketsTable`
The core component accepting:
- **`isArchived`** — toggles between active and archived ticket views
- **`statusFilters`** / **`onStatusFilterChange`** — controlled status filter state
- **`search`** / **`onSearchChange`** — controlled search input state
- **`backButton`**, **`selector`** — optional layout customization slots

### `CurrentTickets`
Convenience wrapper rendering `TicketsTable` with `isArchived={false}`.

### `ArchivedTickets`
Convenience wrapper rendering `TicketsTable` with `isArchived={true}`.

## Key Behaviors

- **Debounced search** — delays query by 300ms via `useDebounce` to reduce API calls
- **Infinite scroll** — uses `DataTable.InfiniteFooter` with `fetchNextPage` for pagination
- **Column filters** — syncs `ColumnFiltersState` with external `statusFilters` prop; disabled in archived view
- **Mobile filter modal** — renders a `FilterModal` triggered by a filter icon button on small screens
- **Error boundary** — renders `PageError` when the tickets query fails

## Usage Example

```typescript
import { CurrentTickets, ArchivedTickets } from './tickets-table';

function TicketsPage() {
  const [search, setSearch] = useState('');
  const [statusFilters, setStatusFilters] = useState<string[]>([]);

  return (
    <CurrentTickets
      search={search}
      onSearchChange={setSearch}
      statusFilters={statusFilters}
      onStatusFilterChange={setStatusFilters}
      backButton={{ label: 'Back', onClick: () => router.back() }}
    />
  );
}

// For archived view
function ArchivedPage() {
  const [search, setSearch] = useState('');
  return <ArchivedTickets search={search} onSearchChange={setSearch} />;
}
```
