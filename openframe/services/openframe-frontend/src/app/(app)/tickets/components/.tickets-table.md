Reusable tickets data table component that renders a searchable, filterable list of support tickets with support for both active and archived views.

## Key Components

**`TicketsTable`** — Core component that composes search input, column/mobile filters, infinite scroll pagination, and ticket actions into a full-page layout.

**`CurrentTickets`** — Convenience wrapper rendering `TicketsTable` with `isArchived={false}`.

**`ArchivedTickets`** — Convenience wrapper rendering `TicketsTable` with `isArchived={true}`.

### Props (`TicketsTableProps`)

| Prop | Type | Description |
|---|---|---|
| `isArchived` | `boolean` | Toggles archived vs. active ticket view |
| `statusFilters` | `string[]` | Active status filter values |
| `onStatusFilterChange` | `(status: string[]) => void` | Callback when filters change |
| `backButton` | `{ label?: string; onClick: () => void }` | Optional back navigation button |
| `selector` | `ReactNode` | Optional slot for a selector/dropdown |
| `search` | `string` | Controlled search input value |
| `onSearchChange` | `(value: string) => void` | Callback on search input change |

## Usage Example

```typescript
import { CurrentTickets, ArchivedTickets } from './tickets-table';

// Active tickets with search and status filtering
function TicketsPage() {
  const [search, setSearch] = useState('');
  const [statusFilters, setStatusFilters] = useState<string[]>([]);

  return (
    <CurrentTickets
      search={search}
      onSearchChange={setSearch}
      statusFilters={statusFilters}
      onStatusFilterChange={setStatusFilters}
      backButton={{ label: 'Back', onClick: () => router.back() }}
    />
  );
}

// Archived tickets view (filters disabled)
function ArchivedPage() {
  const [search, setSearch] = useState('');
  return <ArchivedTickets search={search} onSearchChange={setSearch} />;
}
```

> **Note:** Search is debounced by 300ms via `useDebounce`. Status filter changes on mobile are handled via a `FilterModal` overlay. Filter actions are disabled when `isArchived={true}`.
