Renders a paginated, searchable, and filterable tickets data table with support for both active and archived ticket views.

## Key Components

### `TicketsTable`
The primary export. Accepts the following props:

| Prop | Type | Description |
|------|------|-------------|
| `isArchived` | `boolean` | Toggles between active and archived ticket views |
| `statusFilters` | `string[]` | Active status filter values |
| `onStatusFilterChange` | `(status: string[]) => void` | Callback when status filters change |
| `backButton` | `{ label?: string; onClick: () => void }` | Optional back navigation button |
| `selector` | `ReactNode` | Optional UI element injected into the page header |
| `search` | `string` | Controlled search input value |
| `onSearchChange` | `(value: string) => void` | Callback on search input change |

### `CurrentTickets`
Convenience wrapper for `TicketsTable` with `isArchived={false}`.

### `ArchivedTickets`
Convenience wrapper for `TicketsTable` with `isArchived={true}`.

## Usage Example

```typescript
import { CurrentTickets, ArchivedTickets } from './tickets-table';

function TicketsPage() {
  const [search, setSearch] = useState('');
  const [statusFilters, setStatusFilters] = useState<string[]>([]);

  return (
    <CurrentTickets
      search={search}
      onSearchChange={setSearch}
      statusFilters={statusFilters}
      onStatusFilterChange={setStatusFilters}
      backButton={{ label: 'Back', onClick: () => router.back() }}
    />
  );
}

// Archived variant
function ArchivedPage() {
  const [search, setSearch] = useState('');

  return <ArchivedTickets search={search} onSearchChange={setSearch} />;
}
```

> **Note:** Search input is debounced at 300ms via `useDebounce` before triggering queries. On mobile, column-based filters are surfaced via a `FilterModal` instead of inline column controls. Status filter changes automatically scroll the page to the top.
