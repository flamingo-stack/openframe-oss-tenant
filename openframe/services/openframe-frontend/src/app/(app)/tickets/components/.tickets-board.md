Kanban-style board component for managing and visualizing tickets across status columns, with support for drag-and-drop reordering, filtering, and inline assignee management.

## Key Components

- **`TicketsBoard`** — Main exported component rendering the full board UI with search, filters, and column-based ticket layout
- **`dialogToBoardTicket`** — Transforms internal `Dialog` data shape into the `BoardTicket` format expected by the core `Board` component
- **`initialsOf`** — Utility that derives avatar initials from a display name (up to two words)
- **`TicketsBoardProps`** — Interface defining optional filter controls (organization, assignee, search) and a custom selector slot

## Usage Example

```typescript
import { TicketsBoard } from './tickets-board';
import { useState } from 'react';

export function TicketsBoardPage() {
  const [search, setSearch] = useState('');
  const [orgIds, setOrgIds] = useState<string[]>([]);
  const [assigneeIds, setAssigneeIds] = useState<string[]>([]);

  return (
    <TicketsBoard
      search={search}
      onSearchChange={setSearch}
      organizationIds={orgIds}
      onOrganizationIdsChange={setOrgIds}
      assigneeIds={assigneeIds}
      onAssigneeIdsChange={setAssigneeIds}
    />
  );
}
```

## Notes

- Search input is debounced (300ms) via `useDebounce` before being passed to the board query
- Allowed column-to-column drag transitions are derived from `useTicketStatusTransitions`, ensuring only valid status moves are permitted
- Moving tickets in flight are tracked via `useMovingTicketIds`, reflected in the `aria-busy` attribute for accessibility
- Column collapse state is persisted to storage under the key `"tickets-board"`
