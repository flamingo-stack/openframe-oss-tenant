Multi-select autocomplete filter component for filtering tickets or views by organization/customer, with debounced search and avatar rendering.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `OrganizationFilter` | Component | Multi-select autocomplete for filtering by organization |
| `OrganizationFilterProps` | Interface | Props: `value` (selected IDs), `onChange` callback, optional `className` |

**Internal dependencies:**
- `useOrganizationOptions` — fetches organization options based on debounced search input
- `renderAvatarOption('square')` — renders each option with a square avatar
- `useDebounce` — delays search query by 300ms to reduce API calls

## Usage Example

```typescript
import { OrganizationFilter } from './organization-filter';

function TicketFilters() {
  const [selectedOrgs, setSelectedOrgs] = useState<string[]>([]);

  return (
    <OrganizationFilter
      value={selectedOrgs}
      onChange={setSelectedOrgs}
      className="w-64"
    />
  );
}
```

## Behavior Notes

- **Debounced search:** Input changes are debounced 300ms before triggering `useOrganizationOptions`
- **Client-side filtering disabled:** `disableClientFilter` delegates all filtering to the server/hook
- **Default placeholder:** Displays `"Show All Customers"` when no selection is made
- **Loading state:** Passes `isLoading` from the options hook directly to the `Autocomplete` component
- **Adornment:** Renders a `Filter02Icon` at the start of the input field
