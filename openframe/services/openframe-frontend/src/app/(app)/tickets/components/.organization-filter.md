Multi-select autocomplete filter component for filtering tickets or views by organization/customer, with debounced search and avatar-rendered options.

## Key Components

- **`OrganizationFilter`** – Main exported component that renders a searchable, multi-select autocomplete for customer/organization filtering
- **`OrganizationFilterProps`** – Interface defining `value` (selected org IDs), `onChange` callback, and optional `className`
- **`renderOption`** – Square avatar renderer reused from `renderAvatarOption` utility for consistent org option display

## Usage Example

```typescript
import { OrganizationFilter } from './organization-filter';

function TicketFilters() {
  const [selectedOrgs, setSelectedOrgs] = useState<string[]>([]);

  return (
    <OrganizationFilter
      value={selectedOrgs}
      onChange={setSelectedOrgs}
      className="w-64"
    />
  );
}
```

## Behavior Notes

- **Debounced search** – Input changes are debounced by 300ms before triggering `useOrganizationOptions` to reduce API calls
- **Server-side filtering** – `disableClientFilter` is set, meaning filtering is delegated entirely to the backend via `useOrganizationOptions`
- **Multi-select** – Supports selecting multiple organizations simultaneously
- **Default placeholder** – Shows `"Show All Customers"` when no selection is active, indicating an unfiltered state
