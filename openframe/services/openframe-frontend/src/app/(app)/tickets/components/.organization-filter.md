A multi-select autocomplete filter component for filtering tickets or lists by organization/customer, featuring debounced search and avatar-styled option rendering.

## Key Components

- **`OrganizationFilter`** — Main export; renders a multi-select `Autocomplete` with a filter icon adornment, debounced search input, and server-side option fetching
- **`OrganizationFilterProps`** — Interface defining `value` (selected IDs), `onChange` callback, and optional `className`
- **`renderOption`** — Square-variant avatar renderer via `renderAvatarOption`, applied to each dropdown option

## Usage Example

```typescript
import { OrganizationFilter } from './organization-filter';

function TicketListFilters() {
  const [selectedOrgs, setSelectedOrgs] = useState<string[]>([]);

  return (
    <OrganizationFilter
      value={selectedOrgs}
      onChange={setSelectedOrgs}
      className="w-64"
    />
  );
}
```

## Behavior Notes

- Search input is debounced by **300ms** before triggering `useOrganizationOptions`, reducing unnecessary API calls
- `disableClientFilter` delegates all filtering to the server/hook layer
- Defaults to `"Show All Customers"` placeholder when no selection is made
- Avatar options use the `'square'` variant, consistent with organization/company branding conventions
