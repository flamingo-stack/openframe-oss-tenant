Defines the Zod validation schema and inferred TypeScript type for the create ticket form, enforcing field constraints and structure across the ticket creation flow.

## Key Components

- **`createTicketSchema`** — Zod object schema validating all ticket creation fields, including title length limits, description cap, optional org/device/user assignments, label array constraints, and knowledge base assignment
- **`CreateTicketFormData`** — TypeScript type inferred from `createTicketSchema`, used to type form state and submission handlers
- **`assignmentsSchema`** — Imported from `@/components/assignments`, embedded as the `assignments` field for structured assignment validation

## Field Reference

| Field | Type | Constraints |
|-------|------|-------------|
| `title` | `string` | Required, 1–255 chars |
| `description` | `string` | Max 5000 chars |
| `organizationId` | `string` | Optional |
| `deviceId` | `string` | Optional |
| `assignedTo` | `string \| null` | Optional |
| `labelIds` | `string[]` | Max 20 items |
| `userId` | `string` | Optional *(pending Authentik)* |
| `type` | `string` | Required *(pending backend support)* |
| `assignKnowledgeBase` | `boolean` | Required |
| `assignments` | `assignmentsSchema` | Structured assignments |

> **Note:** `userId` and `type` are defined in the schema but not yet consumed by the backend — both are pending future integration work.

## Usage Example

```typescript
import { createTicketSchema, CreateTicketFormData } from './create-ticket.types';
import { useForm } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';

const form = useForm<CreateTicketFormData>({
  resolver: zodResolver(createTicketSchema),
  defaultValues: {
    title: '',
    description: '',
    labelIds: [],
    type: 'incident',
    assignKnowledgeBase: false,
    assignments: [],
  },
});
```
