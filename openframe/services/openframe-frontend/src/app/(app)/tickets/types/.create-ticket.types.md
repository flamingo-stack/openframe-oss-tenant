Defines the Zod validation schema and TypeScript types for the create ticket form, enforcing field constraints and structure for new ticket submissions.

## Key Components

- **`createTicketSchema`** — Zod schema validating all fields required to create a ticket, including title length limits, optional organization/device/user associations, label constraints, and assignment data
- **`CreateTicketFormData`** — TypeScript type inferred from `createTicketSchema`, used to type form state and submission payloads

## Usage Example

```typescript
import { createTicketSchema, CreateTicketFormData } from './create-ticket.types';

const formData: CreateTicketFormData = {
  title: 'Cannot connect to VPN',
  description: 'User reports VPN fails to connect since last update.',
  organizationId: 'org_123',
  deviceId: 'dev_456',
  assignedTo: 'tech_789',
  labelIds: ['label_abc'],
  type: 'incident',
  assignKnowledgeBase: true,
  assignments: { /* assignmentsSchema-valid data */ },
};

const result = createTicketSchema.safeParse(formData);
if (!result.success) {
  console.error(result.error.flatten());
}
```

> **Note:** Two fields have pending backend support: `userId` (reporter — planned with Authentik integration) and `type` (ticket categorization). Both are currently accepted by the schema but not yet processed by the backend.
