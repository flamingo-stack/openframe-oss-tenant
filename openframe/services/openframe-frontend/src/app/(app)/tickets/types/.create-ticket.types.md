Defines the Zod validation schema and inferred TypeScript type for the create ticket form, enforcing field constraints and structure used during ticket creation.

## Key Components

- **`createTicketSchema`** — Zod object schema validating all ticket creation fields, including character limits, optional fields, and array constraints
- **`CreateTicketFormData`** — TypeScript type inferred from `createTicketSchema`, used to type form state and submission payloads

## Schema Fields

| Field | Type | Notes |
|-------|------|-------|
| `title` | `string` | Required, 1–255 chars |
| `description` | `string` | Optional, max 5000 chars |
| `organizationId` | `string?` | Optional org association |
| `deviceId` | `string?` | Optional device link |
| `assignedTo` | `string \| null \| undefined` | Nullable assignee |
| `labelIds` | `string[]` | Max 20 labels |
| `userId` | `string?` | Pending Authentik integration |
| `type` | `string` | Pending backend support |
| `assignKnowledgeBase` | `boolean` | Knowledge base assignment flag |
| `assignments` | `assignmentsSchema` | Shared assignments schema |

## Usage Example

```typescript
import { createTicketSchema, CreateTicketFormData } from './create-ticket.types';

const formData: CreateTicketFormData = {
  title: 'Printer offline in Room 204',
  description: 'HP LaserJet not responding since this morning.',
  organizationId: 'org_abc123',
  deviceId: 'dev_xyz789',
  assignedTo: 'user_456',
  labelIds: ['label_hardware', 'label_urgent'],
  type: 'incident',
  assignKnowledgeBase: true,
  assignments: [],
};

const result = createTicketSchema.safeParse(formData);
if (!result.success) {
  console.error(result.error.flatten());
}
```
