Defines TypeScript types for the Flamingo/OpenFrame ticket system, mirroring the backend GraphQL schema from `openframe-saas-ai-agent`.

## Key Components

| Export | Kind | Description |
|--------|------|-------------|
| `TicketStatus` | Type | Union of ticket lifecycle states: `ACTIVE`, `TECH_REQUIRED`, `ON_HOLD`, `RESOLVED`, `ARCHIVED` |
| `Ticket` | Interface | Core ticket entity with full field set including owner, assignee, labels, attachments, and notes |
| `TicketOwner` | Interface | Identifies ticket ownership by `CLIENT` or `ADMIN` with optional machine/user reference |
| `TicketNote` | Interface | Inline note attached to a ticket with author info and timestamps |
| `TicketAttachment` | Interface | Persisted file attachment linked to a ticket |
| `TempAttachment` | Interface | Pre-upload temporary attachment with a signed `uploadUrl` |
| `KnowledgeBaseArticle` | Interface | Linked KB article in `DRAFT` or `PUBLISHED` state |
| `TicketPayload` / `TempAttachmentPayload` / `TicketAttachmentUploadPayload` / `DeletePayload` | Interfaces | GraphQL mutation response wrappers including `userErrors` |
| `CreateTicketInput` / `UpdateTicketInput` / `AssignTicketInput` / `TicketIdInput` | Interfaces | Typed mutation input shapes |

## Usage Example

```typescript
import type {
  Ticket,
  CreateTicketInput,
  TicketPayload,
  TicketStatus,
} from './ticket.types';

// Build a create mutation input
const input: CreateTicketInput = {
  title: 'Printer offline - Floor 2',
  description: 'HP LaserJet not responding since 09:00.',
  organizationId: 'org_abc123',
  assigneeId: 'usr_tech01',
  labelIds: ['lbl_hardware'],
};

// Narrow status in conditional logic
function isOpen(status: TicketStatus): boolean {
  return status === 'ACTIVE' || status === 'TECH_REQUIRED';
}

// Handle GraphQL mutation response
function handlePayload(payload: TicketPayload): Ticket {
  if (payload.userErrors.length > 0) {
    throw new Error(payload.userErrors.map(e => e.message).join(', '));
  }
  if (!payload.ticket) throw new Error('No ticket returned');
  return payload.ticket;
}
```
