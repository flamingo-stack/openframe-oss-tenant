Defines the complete TypeScript type system for the ticket module, mirroring the backend GraphQL schema from `openframe-saas-ai-agent`.

## Key Components

**Core Types**
- `TicketStatus` — Union type for ticket lifecycle states: `ACTIVE`, `TECH_REQUIRED`, `ON_HOLD`, `RESOLVED`, `ARCHIVED`
- `Ticket` — Primary ticket entity with full relational data (owner, assignee, labels, attachments, notes)
- `TicketOwner` — Discriminated ownership model supporting `CLIENT` or `ADMIN` with optional machine/user context

**Supporting Entities**
- `TicketNote` — Internal technician notes attached to a ticket
- `TicketAttachment` / `TempAttachment` — Permanent and pre-upload temporary file metadata
- `TicketImage` — Avatar/image references for users and organizations
- `KnowledgeBaseArticle` — Linked KB articles with `DRAFT` | `PUBLISHED` status
- `TicketUserInfo` — Lightweight user reference used across assignee, reporter, and author fields

**GraphQL Payload Types**
- `TicketPayload`, `TempAttachmentPayload`, `TicketAttachmentUploadPayload`, `DeletePayload` — Mutation response wrappers including `UserError` for field-level validation errors

**Mutation Input Types**
- `CreateTicketInput`, `UpdateTicketInput`, `AssignTicketInput`, `TicketIdInput` — Strongly typed inputs for all ticket mutation operations

## Usage Example

```typescript
import type {
  Ticket,
  CreateTicketInput,
  TicketPayload,
  TicketStatus
} from './ticket.types';

const input: CreateTicketInput = {
  title: 'VPN not connecting',
  description: 'User unable to connect since firmware update',
  organizationId: 'org_123',
  assigneeId: 'tech_456',
  labelIds: ['label_urgent'],
  tempAttachmentIds: ['tmp_789']
};

function handlePayload(payload: TicketPayload): Ticket {
  if (payload.userErrors.length > 0) {
    throw new Error(payload.userErrors[0].message);
  }
  return payload.ticket!;
}

const isResolved = (status: TicketStatus): boolean =>
  status === 'RESOLVED' || status === 'ARCHIVED';
```
