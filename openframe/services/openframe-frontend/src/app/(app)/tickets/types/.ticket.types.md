Defines the complete TypeScript type system for the ticket management module, mirroring the backend GraphQL schema used by the OpenFrame AI agent service.

## Key Components

| Type | Kind | Description |
|------|------|-------------|
| `TicketStatus` | Union | Ticket lifecycle states: `ACTIVE`, `TECH_REQUIRED`, `ON_HOLD`, `RESOLVED`, `ARCHIVED` |
| `Ticket` | Interface | Core ticket entity with full relational data (owner, assignee, labels, attachments, notes) |
| `TicketOwner` | Interface | Identifies ticket ownership by `CLIENT` or `ADMIN` type, optionally scoped to machine/user |
| `TicketAttachment` | Interface | Persisted file attachment linked to a ticket |
| `TempAttachment` | Interface | Staging attachment with upload URL before final association |
| `TicketNote` | Interface | Internal note authored by a user on a ticket |
| `KnowledgeBaseArticle` | Interface | Linked KB article in `DRAFT` or `PUBLISHED` status |
| `TicketPayload` / `TempAttachmentPayload` / `TicketAttachmentUploadPayload` / `DeletePayload` | Interfaces | GraphQL mutation response wrappers with `userErrors` |
| `CreateTicketInput` / `UpdateTicketInput` / `AssignTicketInput` / `TicketIdInput` | Interfaces | Mutation input shapes for ticket CRUD operations |

## Usage Example

```typescript
import type {
  Ticket,
  CreateTicketInput,
  TicketPayload,
  TicketStatus,
} from './ticket.types';

// Constructing a create mutation input
const input: CreateTicketInput = {
  title: 'VPN not connecting after Windows update',
  description: 'Client unable to connect since KB5034441 was applied.',
  organizationId: 'org_123',
  assigneeId: 'tech_456',
  labelIds: ['label_vpn', 'label_urgent'],
  tempAttachmentIds: ['tmp_789'],
};

// Handling a GraphQL mutation response
function handleTicketPayload(payload: TicketPayload): Ticket {
  if (payload.userErrors.length > 0) {
    throw new Error(payload.userErrors.map(e => e.message).join(', '));
  }
  if (!payload.ticket) {
    throw new Error('No ticket returned');
  }
  return payload.ticket;
}

// Narrowing ticket status
function isResolved(status: TicketStatus): boolean {
  return status === 'RESOLVED' || status === 'ARCHIVED';
}
```
