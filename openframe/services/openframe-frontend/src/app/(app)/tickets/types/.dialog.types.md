Defines the core TypeScript types and interfaces for the Dialog (ticket/conversation) system, covering dialog lifecycle, ownership, messaging, tool execution, and pagination.

## Key Components

**Dialog Types**
- `DialogStatus` — Union type for ticket states: `ACTIVE`, `TECH_REQUIRED`, `ON_HOLD`, `RESOLVED`, `ARCHIVED`
- `Dialog` — Primary interface representing a support ticket/conversation, including lifecycle fields, V2 ticket metadata, attachments, notes, and token usage
- `DialogConnection` / `DialogEdge` — Cursor-based paginated dialog list
- `DialogRating` — End-user satisfaction rating tied to a dialog
- `Machine` — Endpoint/device associated with a client dialog

**Message Types**
- `MessageDataType` — Union discriminating message payloads: `TEXT`, `ERROR`, `EXECUTING_TOOL`, `EXECUTED_TOOL`, `APPROVAL_REQUEST`, `APPROVAL_RESULT`, `SYSTEM`, context compaction markers
- `Message` — A single chat message with owner, chat type, mode, and polymorphic `messageData`
- `MessageConnection` / `MessageEdge` — Cursor-based paginated message list

**Owner Variants**
- `ClientDialogOwner`, `ClientOwner` — Machine-linked client
- `AssistantOwner` — AI model reference
- `AdminOwner` — Admin user with optional profile fields

**Tool Execution**
- `ExecutingToolData` / `ExecutedToolData` — Tracks AI tool invocations including approval state
- `ApprovalRequestData` / `ApprovalResultData` — Human-in-the-loop approval flow

## Usage Example

```typescript
import type {
  Dialog,
  Message,
  DialogStatus,
  ExecutingToolData,
  DialogConnection,
} from './dialog.types';

// Narrow dialog owner to client
function getMachineId(dialog: Dialog): string | undefined {
  const owner = dialog.owner as import('./dialog.types').ClientDialogOwner;
  return owner.machineId;
}

// Type-guard for tool execution messages
function isExecutingTool(msg: Message): msg is Message & { messageData: ExecutingToolData } {
  return msg.messageData.type === 'EXECUTING_TOOL';
}

// Paginate dialogs
function getNextCursor(connection: DialogConnection): string | null | undefined {
  return connection.pageInfo.hasNextPage
    ? connection.pageInfo.endCursor
    : null;
}
```
