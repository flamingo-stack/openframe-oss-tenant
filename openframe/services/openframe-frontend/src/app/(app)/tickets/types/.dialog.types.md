Defines all TypeScript types and interfaces for the Dialog and Message domain, covering dialog lifecycle states, ownership models, paginated connections, and the full message data type hierarchy used across the Flamingo/OpenFrame platform.

## Key Components

### Dialog Types
| Type/Interface | Description |
|---|---|
| `DialogStatus` | Lifecycle states: `ACTIVE`, `TECH_REQUIRED`, `ON_HOLD`, `RESOLVED`, `ARCHIVED` |
| `Dialog` | Core dialog/ticket entity with base fields plus V2 ticket-specific fields (assignments, labels, attachments, notes) |
| `DialogOwner` / `ClientDialogOwner` | Owner discriminated union — `CLIENT` or `ADMIN`, with machine reference for client owners |
| `DialogConnection` / `DialogEdge` | Cursor-based pagination wrappers for dialog lists |
| `ChatTypeTokenUsage` | AI token consumption tracking per chat type |

### Message Types
| Type/Interface | Description |
|---|---|
| `MessageDataType` | Union of all message payload kinds: `TEXT`, `ERROR`, `EXECUTING_TOOL`, `EXECUTED_TOOL`, `APPROVAL_REQUEST`, `APPROVAL_RESULT`, `SYSTEM`, and context compaction markers |
| `Message` | Core message entity linking to a dialog with typed owner and polymorphic `messageData` |
| `ClientOwner` / `AssistantOwner` / `AdminOwner` | Discriminated message owner types carrying context-specific fields (machine, model, user) |
| `ExecutingToolData` / `ExecutedToolData` | Tool invocation lifecycle — pre and post execution with approval status |
| `ApprovalRequestData` / `ApprovalResultData` | Human-in-the-loop approval flow payloads |
| `MessageConnection` / `MessageEdge` | Cursor-based pagination wrappers for message lists |

## Usage Example

```typescript
import type {
  Dialog,
  DialogStatus,
  Message,
  ExecutingToolData,
  DialogConnection,
} from './dialog.types';

// Narrow dialog status
function isResolved(dialog: Dialog): boolean {
  const terminal: DialogStatus[] = ['RESOLVED', 'ARCHIVED'];
  return terminal.includes(dialog.status);
}

// Narrow message data by type
function getToolName(message: Message): string | null {
  const data = message.messageData;
  if (data.type === 'EXECUTING_TOOL') {
    return (data as ExecutingToolData).toolFunction;
  }
  return null;
}

// Work with paginated dialogs
function getDialogIds(connection: DialogConnection): string[] {
  return connection.edges.map((edge) => edge.node.id);
}
```
