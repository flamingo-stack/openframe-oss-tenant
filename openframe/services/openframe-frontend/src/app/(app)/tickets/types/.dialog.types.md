Defines TypeScript types and interfaces for the Dialog and Message domain, covering ticket lifecycle states, ownership models, paginated connections, and chat message data variants used across the Flamingo support platform.

## Key Components

**Dialog Types**
- `DialogStatus` — union type for ticket states: `ACTIVE`, `TECH_REQUIRED`, `ON_HOLD`, `RESOLVED`, `ARCHIVED`
- `Dialog` — core ticket entity with lifecycle fields, V2 ticket metadata (assignee, labels, attachments, notes), and AI token usage
- `DialogOwner` / `ClientDialogOwner` — ownership model distinguishing `CLIENT` vs `ADMIN` origins
- `DialogConnection` / `DialogEdge` — cursor-based pagination wrapper for dialog lists
- `ChatTypeTokenUsage` — tracks AI token consumption per chat type

**Message Types**
- `MessageDataType` — discriminated union covering `TEXT`, `ERROR`, `EXECUTING_TOOL`, `EXECUTED_TOOL`, `APPROVAL_REQUEST`, `APPROVAL_RESULT`, `SYSTEM`, and context compaction markers
- `Message` — core chat message entity linking to a dialog with typed owner and polymorphic `messageData`
- `ExecutingToolData` / `ExecutedToolData` — tool invocation lifecycle with approval tracking
- `ApprovalRequestData` / `ApprovalResultData` — human-in-the-loop approval flow payloads
- `MessageConnection` / `MessageEdge` — cursor-based pagination for message lists
- `CursorPageInfo` — shared pagination metadata (`hasNextPage`, `hasPreviousPage`, cursors)

## Usage Example

```typescript
import type {
  Dialog,
  DialogStatus,
  Message,
  ExecutingToolData,
  DialogConnection,
} from './dialog.types';

// Type-guard for tool execution messages
function isExecutingTool(msg: Message): msg is Message & { messageData: ExecutingToolData } {
  return msg.messageData.type === 'EXECUTING_TOOL';
}

// Paginate through dialogs
function processPage(connection: DialogConnection): Dialog[] {
  return connection.edges.map(edge => edge.node);
}

// Check if a dialog needs technician attention
function needsTech(dialog: Dialog): boolean {
  return dialog.status === 'TECH_REQUIRED';
}
```
