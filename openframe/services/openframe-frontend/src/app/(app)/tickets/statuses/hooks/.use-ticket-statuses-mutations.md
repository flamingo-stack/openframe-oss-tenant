React Query mutation hooks for managing ticket status CRUD operations — create, update, reorder, and delete — against a GraphQL API with optimistic toast feedback.

## Key Components

### `useSaveTicketStatusesMutation()`
Wraps the `saveTicketStatuses` function in a TanStack `useMutation`. On success, invalidates the `ticketsQueryKeys.statuses()` query and shows a success toast. On error, displays a descriptive error toast.

### `useDeleteTicketStatusMutation()`
Mutation hook for deleting a single ticket status. Accepts a `DeleteTicketStatusInput` (status `id` + optional `replacementStatusId` for reassigning open tickets) and invalidates the statuses cache on success.

### `saveTicketStatuses(input)` *(internal)*
Diffs form state against a server snapshot and dispatches the minimal required GraphQL mutations in order:
1. **Creates** — new rows not present in the snapshot
2. **Updates** — persisted rows with changed `name` or `color`
3. **Reorders** — when insertion order changed or new rows were created

Returns the final custom status list with temporary IDs replaced by real server-assigned IDs.

### `precedingSystemId(snapshot)` *(internal)*
Resolves the system status anchor ID used when positioning the first custom status in the reorder sequence.

### `runStatusMutation<K>(query, key, variables)` *(internal)*
Generic GraphQL POST helper that extracts the typed result from the response by key.

## Usage Example

```typescript
// Save (create/update/reorder) ticket statuses from a form
const saveMutation = useSaveTicketStatusesMutation();

saveMutation.mutate({
  customStatuses: formState.customStatuses,
  snapshot: serverSnapshot,
});

// Delete a status, reassigning its tickets to another
const deleteMutation = useDeleteTicketStatusMutation();

deleteMutation.mutate({
  id: 'status-abc',
  replacementStatusId: 'status-xyz',
});
```
