Manages the form state, validation, and mutation lifecycle for the ticket statuses configuration screen, wiring together React Hook Form, Zod validation, server queries, and save/delete mutations.

## Key Components

- **`useTicketStatusesForm()`** — Primary hook returning form controls, field array helpers, mutation state, and derived data for the ticket statuses UI
- **`ReplacementOption`** — Interface describing a status that can replace a deleted one (`id`, `name`, `color`)
- **`replacementOptionsFor(statusId)`** — Filters valid replacement targets using the transition-rule matrix; only statuses the deleted status can legally transition to are returned
- **`collectErrorMessages(errors)`** — Recursively walks a `FieldErrors` tree to collect all human-readable validation messages for toast display
- **Dirty-state guard** — Uses a `useRef` to track `isDirty` so server data resets never clobber in-progress edits, and saves don't cause a visible flicker before refetch

## Usage Example

```typescript
const {
  form,
  fieldArray,
  saveMutation,
  deleteMutation,
  onValidSubmit,
  onInvalidSubmit,
  canDelete,
  systemStatuses,
  persistedCustomIds,
  replacementOptionsFor,
} = useTicketStatusesForm();

// Bind to your form element
<Form {...form}>
  <form onSubmit={form.handleSubmit(onValidSubmit, onInvalidSubmit)}>
    {fieldArray.fields.map((field, index) => (
      <StatusRow
        key={field._key}
        index={index}
        replacementOptions={replacementOptionsFor(field.id)}
        canDelete={canDelete}
      />
    ))}
  </form>
</Form>
```

> **Note:** Replacement options respect transition rules — only statuses reachable from the deleted status are offered, preventing invalid ticket state transitions during reassignment.
