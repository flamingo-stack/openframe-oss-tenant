Manages the form state, validation, and mutation logic for the ticket statuses configuration screen, coordinating server data synchronization, field array operations, and delete-replacement workflows.

## Key Components

- **`useTicketStatusesForm()`** — Primary hook returning form controls, mutation handles, and derived state for the ticket statuses UI
- **`ReplacementOption`** — Interface describing a status that can replace a deleted one (`id`, `name`, `color`)
- **`collectErrorMessages()`** — Internal utility that recursively walks `FieldErrors` and deduplicates human-readable messages for toast notifications

## Returned Values

| Property | Description |
|---|---|
| `form` | `react-hook-form` instance with Zod validation |
| `fieldArray` | Field array controls for `customStatuses` |
| `saveMutation` / `deleteMutation` | TanStack Query mutation handles |
| `onValidSubmit` / `onInvalidSubmit` | Form submission handlers |
| `canDelete` | `true` when more than one custom status exists |
| `systemStatuses` | Read-only system statuses from server |
| `persistedCustomIds` | Set of custom status IDs already saved to the server |
| `replacementOptionsFor(statusId)` | Returns transition-rule-filtered replacement targets for a given status |

## Usage Example

```typescript
function TicketStatusesForm() {
  const {
    form,
    fieldArray,
    saveMutation,
    onValidSubmit,
    onInvalidSubmit,
    canDelete,
    replacementOptionsFor,
  } = useTicketStatusesForm();

  return (
    <form onSubmit={form.handleSubmit(onValidSubmit, onInvalidSubmit)}>
      {fieldArray.fields.map((field) => (
        <StatusRow
          key={field._key}
          replacementOptions={replacementOptionsFor(field.id)}
          canDelete={canDelete}
        />
      ))}
      <button type="submit" disabled={saveMutation.isPending}>
        Save
      </button>
    </form>
  );
}
```

> **Note:** Server data is only adopted when the form is pristine (`isDirty === false`), preventing in-progress edits from being overwritten by background refetches.
