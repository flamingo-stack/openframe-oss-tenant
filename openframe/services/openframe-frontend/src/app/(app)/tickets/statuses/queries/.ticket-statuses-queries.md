GraphQL query and mutation definitions for managing ticket statuses in the OpenFrame platform, executed via the `openframe-saas-ai-agent` service at `/chat/graphql`.

## Key Components

**Shared Fragment**
- `STATUS_DEFINITION_FIELDS` — Reusable field fragment returning `id`, `name`, `color`, `position`, `kind`, `isSystem`, and `systemKey`

**Exported Queries**
- `GET_TICKET_STATUSES_QUERY` — Fetches all ticket statuses

**Exported Mutations**
- `CREATE_TICKET_STATUS_MUTATION` — Creates a new ticket status via `CreateTicketStatusInput`
- `UPDATE_TICKET_STATUS_MUTATION` — Updates an existing status via `UpdateTicketStatusInput`
- `DELETE_TICKET_STATUS_MUTATION` — Deletes a status via `DeleteTicketStatusInput` (returns scalar, no fields)
- `REORDER_TICKET_STATUS_MUTATION` — Changes a status's position via `ReorderTicketStatusInput`

## Usage Example

```typescript
import {
  GET_TICKET_STATUSES_QUERY,
  CREATE_TICKET_STATUS_MUTATION,
  DELETE_TICKET_STATUS_MUTATION,
} from './ticket-statuses-queries';

// Fetch all statuses
const { ticketStatuses } = await graphqlClient.request(GET_TICKET_STATUSES_QUERY);

// Create a new status
const { createTicketStatus } = await graphqlClient.request(
  CREATE_TICKET_STATUS_MUTATION,
  {
    input: {
      name: 'Awaiting Parts',
      color: '#FFC008',
      position: 3,
      kind: 'CUSTOM',
    },
  }
);

// Delete a status
await graphqlClient.request(DELETE_TICKET_STATUS_MUTATION, {
  input: { id: 'status-id-123' },
});
```

> **Note:** `DELETE_TICKET_STATUS_MUTATION` returns a scalar boolean rather than a status object — no field selection is needed in the mutation body.
