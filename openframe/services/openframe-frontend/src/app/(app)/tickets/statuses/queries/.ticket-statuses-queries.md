GraphQL query and mutation definitions for managing ticket statuses, used by the `openframe-saas-ai-agent` service via the `/chat/graphql` endpoint.

## Key Components

**Shared Fragment**
- `STATUS_DEFINITION_FIELDS` — Reusable field fragment returned by all status operations: `id`, `name`, `color`, `position`, `kind`, `isSystem`, `systemKey`

**Exported Queries**
- `GET_TICKET_STATUSES_QUERY` — Fetches all ticket statuses

**Exported Mutations**
- `CREATE_TICKET_STATUS_MUTATION` — Creates a new ticket status (`CreateTicketStatusInput`)
- `UPDATE_TICKET_STATUS_MUTATION` — Updates an existing ticket status (`UpdateTicketStatusInput`)
- `DELETE_TICKET_STATUS_MUTATION` — Deletes a ticket status (`DeleteTicketStatusInput`), returns scalar only
- `REORDER_TICKET_STATUS_MUTATION` — Reorders ticket statuses (`ReorderTicketStatusInput`)

## Usage Example

```typescript
import {
  GET_TICKET_STATUSES_QUERY,
  CREATE_TICKET_STATUS_MUTATION,
  REORDER_TICKET_STATUS_MUTATION,
} from './ticket-statuses-queries';

// Fetch all statuses
const { ticketStatuses } = await graphqlClient.request(GET_TICKET_STATUSES_QUERY);

// Create a new status
await graphqlClient.request(CREATE_TICKET_STATUS_MUTATION, {
  input: { name: 'In Review', color: '#FFC008', position: 3, kind: 'CUSTOM' },
});

// Reorder statuses
await graphqlClient.request(REORDER_TICKET_STATUS_MUTATION, {
  input: { id: 'status-id', newPosition: 1 },
});
```

> All queries/mutations target the `/chat/graphql` endpoint and are intended for use within the AI agent service layer — not the standard client API.
