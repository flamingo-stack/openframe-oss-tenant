Fetches and organizes ticket status definitions via GraphQL, separating them into system and custom statuses sorted by fractional-index position.

## Key Components

- **`TicketStatusesData`** — Return shape containing `systemStatuses`, `customStatuses`, and a raw `snapshot` array of all definitions
- **`byPosition`** — Comparator for bytewise sorting of fractional-index position strings
- **`useTicketStatusesQuery`** — React Query hook that POSTs the `GET_TICKET_STATUSES_QUERY` GraphQL query and maps results into typed status arrays

## Usage Example

```typescript
import { useTicketStatusesQuery } from './use-ticket-statuses-query';

function TicketStatusPicker() {
  const { data, isLoading } = useTicketStatusesQuery();

  if (isLoading) return <Spinner />;

  return (
    <>
      <StatusGroup label="System" statuses={data?.systemStatuses} />
      <StatusGroup label="Custom" statuses={data?.customStatuses} />
    </>
  );
}

// Conditionally fetch only when needed
const { data } = useTicketStatusesQuery({ enabled: isModalOpen });
```

## Notes

- Accepts an optional `enabled` flag (defaults to `true`) to defer fetching
- The `snapshot` array preserves the full `TicketStatusDefinition` objects in sorted order, useful when you need raw definitions rather than mapped system/custom types
- Cache key is managed via `ticketsQueryKeys.statuses()`
