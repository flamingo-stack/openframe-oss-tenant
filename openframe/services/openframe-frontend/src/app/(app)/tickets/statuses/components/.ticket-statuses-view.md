React view component for managing ticket status configurations, rendering system and custom statuses in a structured form with drag-reorder, add, and delete capabilities.

## Key Components

- **`TicketStatusesView`** — Main page component orchestrating the full ticket statuses settings UI
- **`createCustomStatus()`** — Factory function generating a new custom status with a UUID and default color
- **`renderSystemRow()`** — Helper rendering a read-only `TicketStatusConfigRow` for system statuses
- **`DeleteStatusDialog`** — Confirmation dialog shown when deleting a persisted custom status, requiring a replacement status selection
- **`TOP_KINDS`** — Set controlling layout order, separating `AI_ASSISTANCE` / `TECH_REQUIRED` statuses into a top section from resolved statuses at the bottom

## Usage Example

```typescript
// Rendered as a page route, e.g. /tickets/statuses
import { TicketStatusesView } from './ticket-statuses-view';

export default function TicketStatusesPage() {
  return <TicketStatusesView />;
}
```

## Behavior Notes

- **Save** button is disabled until the form is dirty or a save mutation is pending
- **Delete** on a persisted custom status opens `DeleteStatusDialog`; unpersisted statuses are removed immediately from the field array
- **Drag-to-reorder** is handled via `TicketStatusConfigList` with `fieldArray.move`
- **Minimum enforcement** — deletion is blocked (`canDelete`) when only one custom status remains, surfacing `DELETE_DISABLED_REASON` as a tooltip
- Form state and mutations are fully encapsulated in `useTicketStatusesForm`; navigation fallback uses `useSafeBack('/tickets')`
