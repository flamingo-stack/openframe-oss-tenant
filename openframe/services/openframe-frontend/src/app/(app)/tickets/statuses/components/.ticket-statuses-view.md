React view component that renders the Ticket Statuses configuration page, allowing users to manage both system-defined and custom ticket statuses with support for adding, editing, reordering, and deleting entries.

## Key Components

- **`TicketStatusesView`** — Main page component orchestrating the full ticket status management UI
- **`createCustomStatus()`** — Factory function that generates a new custom status with a UUID and default color
- **`renderSystemRow()`** — Helper that renders a read-only `TicketStatusConfigRow` for system statuses
- **`DeleteStatusDialog`** — Confirmation dialog triggered when deleting a persisted custom status, requiring a replacement status selection
- **`TicketStatusConfigList`** — Drag-and-drop sortable list for custom statuses
- **`useTicketStatusesForm`** — Form hook providing field array management, save/delete mutations, and validation handlers

## Layout Structure

The form renders three labeled sections:

1. **System statuses (top)** — `AI_ASSISTANCE` and `TECH_REQUIRED` kinds
2. **Custom statuses** — Editable, draggable rows with name/color controls and delete actions
3. **Resolved status (bottom)** — Remaining system statuses

## Usage Example

```typescript
// Rendered as a route-level page component — no props required
import { TicketStatusesView } from './components/ticket-statuses-view';

export default function TicketStatusesPage() {
  return <TicketStatusesView />;
}
```

## Key Behaviors

- **Add** — Appends a new custom status with a generated UUID and default color
- **Delete (unpersisted)** — Removes directly from the field array without a server call
- **Delete (persisted)** — Opens `DeleteStatusDialog` to select a replacement before calling `deleteMutation`
- **Save** — Disabled until the form is dirty or a save is in progress; uses `react-hook-form` submit validation
