Defines the TypeScript types, Zod validation schemas, and utility functions for managing ticket status configurations in the Flamingo MSP platform.

## Key Components

### Interfaces
- **`TicketStatusDefinition`** — Raw status shape returned from the backend (id, name, color, position, kind, isSystem flags)
- **`SystemTicketStatus`** — Enriched system status with tooltip and tag variant metadata for UI rendering
- **`CustomTicketStatus`** — User-defined status with a `'custom'` kind discriminant; supports both persisted (server id) and unsaved (temp `crypto.randomUUID()`) rows
- **`TicketStatusesPayload`** — API write payload shape containing an array of `CustomTicketStatus`

### Validation Schemas
- **`customTicketStatusSchema`** — Zod schema validating a single custom status (name 1–50 chars, 6-digit hex color)
- **`ticketStatusesSchema`** — Zod schema for the full payload; requires at least one custom status to remain

### Constants
- **`SYSTEM_KIND_META`** — Record mapping each non-custom `TicketStatusKind` (`AI_ASSISTANCE`, `TECH_REQUIRED`, `RESOLVED`, `ARCHIVED`) to its tooltip copy and tag variant

### Utility Functions
- **`derivePreset(color)`** — Matches a hex color against `TICKET_STATUS_COLOR_PRESETS` and returns the preset key if found
- **`mapDefinitionToCustom(def)`** — Converts a `TicketStatusDefinition` to a `CustomTicketStatus`
- **`mapDefinitionToSystem(def)`** — Converts a `TicketStatusDefinition` to a `SystemTicketStatus`, resolving canonical status key and injecting metadata

### Re-exports
`kindToCanonicalStatus`, `usesCanonicalStatusStyle`, `TicketStatusKind` — proxied from core so consumers have a single import surface.

## Usage Example

```typescript
import {
  mapDefinitionToCustom,
  mapDefinitionToSystem,
  ticketStatusesSchema,
  derivePreset,
} from './ticket-statuses.types';

// Map backend definitions for UI rendering
const custom = mapDefinitionToCustom(def);   // { kind: 'custom', id, name, color, preset? }
const system = mapDefinitionToSystem(def);   // { id, statusKey, tooltip, tagVariant, ... }

// Derive a preset key from a hex color
const preset = derivePreset('#FF5733');      // e.g. 'orange' or undefined

// Validate the save payload before submitting
const result = ticketStatusesSchema.safeParse({ customStatuses: [custom] });
if (!result.success) console.error(result.error.flatten());
```
