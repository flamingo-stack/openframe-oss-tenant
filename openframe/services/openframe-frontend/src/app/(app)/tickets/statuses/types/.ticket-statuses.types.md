Defines the TypeScript types, Zod validation schemas, constants, and utility functions for managing ticket status definitions within the Flamingo MSP platform's ticketing feature.

## Key Components

### Interfaces
- **`TicketStatusDefinition`** — Raw status shape returned from the backend, covering both system and custom statuses
- **`SystemTicketStatus`** — Enriched system status with UI metadata (`tooltip`, `tagVariant`)
- **`CustomTicketStatus`** — User-defined status with color preset support; uses `crypto.randomUUID()` for unsaved rows
- **`TicketStatusesPayload`** — API payload shape for saving custom statuses

### Schemas (Zod)
- **`customTicketStatusSchema`** — Validates a single custom status (name 1–50 chars, valid 6-digit hex color)
- **`ticketStatusesSchema`** — Validates the full payload; requires at least one custom status

### Constants
- **`SYSTEM_KIND_META`** — Maps each non-`CUSTOM` `TicketStatusKind` to its tooltip text and tag variant (`outline` | `primary`)

### Utility Functions
- **`derivePreset(color)`** — Resolves a color hex to its named preset key, if one exists
- **`mapDefinitionToCustom(def)`** — Converts a `TicketStatusDefinition` to `CustomTicketStatus`
- **`mapDefinitionToSystem(def)`** — Converts a `TicketStatusDefinition` to an enriched `SystemTicketStatus`

### Re-exports
- `kindToCanonicalStatus`, `usesCanonicalStatusStyle`, `TicketStatusKind` — forwarded from core to keep this module the **single import surface** for ticket status logic

## Usage Example

```typescript
import {
  mapDefinitionToCustom,
  mapDefinitionToSystem,
  ticketStatusesSchema,
  derivePreset,
} from './ticket-statuses.types';

// Map a backend definition to its UI representation
const custom = mapDefinitionToCustom({
  id: 'abc123',
  name: 'Waiting on Client',
  color: '#FFC008',
  position: '1',
  kind: 'CUSTOM',
  isSystem: false,
});
// → { kind: 'custom', id: 'abc123', name: 'Waiting on Client', color: '#FFC008', preset: 'amber' }

// Validate a payload before submission
const result = ticketStatusesSchema.safeParse({ customStatuses: [custom] });

// Resolve a preset from a hex color
const preset = derivePreset('#4ECDC4'); // → 'teal' (if registered)
```
