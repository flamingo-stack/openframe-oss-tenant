A confirmation dialog component for deleting a ticket status, requiring the user to select a replacement status before tickets are reassigned and the original status is removed.

## Key Components

**`DeleteStatusDialog`** — Modal dialog component that:
- Displays a warning message referencing the status being deleted
- Renders a `Select` dropdown populated with `ReplacementOption` items (id, name, color)
- Auto-selects the first available replacement on open via `useEffect`
- Disables the confirm button until a valid replacement is chosen or while the operation is pending
- Exposes Cancel and Delete (destructive) footer actions

**`DeleteStatusDialogProps`**

| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls modal visibility |
| `onClose` | `() => void` | Cancel / close handler |
| `statusName` | `string` | Name of the status being deleted |
| `options` | `ReplacementOption[]` | Available replacement statuses |
| `onConfirm` | `(replacementStatusId: string) => void` | Called with the selected replacement ID |
| `isPending` | `boolean` | Disables controls and shows loading state during deletion |

## Usage Example

```typescript
import { DeleteStatusDialog } from './delete-status-dialog';

<DeleteStatusDialog
  isOpen={isDeleteOpen}
  onClose={() => setIsDeleteOpen(false)}
  statusName="In Progress"
  options={[
    { id: 'open-1', name: 'Open', color: '#4ECDC4' },
    { id: 'done-2', name: 'Done', color: '#96CEB4' },
  ]}
```
