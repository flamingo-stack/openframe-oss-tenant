A confirmation dialog component for safely deleting a ticket status by requiring the user to select a replacement status before proceeding.

## Key Components

**`DeleteStatusDialog`** — Modal dialog component that prevents orphaned tickets by forcing selection of a replacement status prior to deletion.

**Props (`DeleteStatusDialogProps`):**
| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls dialog visibility |
| `onClose` | `() => void` | Callback when dialog is dismissed |
| `statusName` | `string` | Name of the status being deleted |
| `options` | `ReplacementOption[]` | Available statuses to reassign tickets to |
| `onConfirm` | `(replacementStatusId: string) => void` | Callback with selected replacement ID |
| `isPending` | `boolean` | Disables controls and shows loading state during async operation |

**Behavior:**
- Auto-selects the first available replacement option when the dialog opens
- Disables the **Delete** button until a valid replacement is selected
- Renders each replacement option with a colored dot indicator sourced from `opt.color`

## Usage Example

```typescript
<DeleteStatusDialog
  isOpen={isDeleteOpen}
  onClose={() => setIsDeleteOpen(false)}
  statusName="In Progress"
  options={[
    { id: 'status-1', name: 'Open', color: '#4ECDC4' },
    { id: 'status-2', name: 'Resolved', color: '#96CEB4' },
  ]}
  onConfirm={(replacementId) => handleDeleteStatus(targetStatusId, replacementId)}
```
