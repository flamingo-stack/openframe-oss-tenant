Client-side Next.js page component for the Tickets route. Restricts access to SaaS tenant mode only, redirecting non-SaaS users to the dashboard.

## Key Components

- **`Tickets`** — Default export page component that conditionally renders the tickets interface
- **`isSaasTenantMode()`** — Utility check that gates access; redirects to `/dashboard` if the app is not running in SaaS tenant mode
- **`TicketsView`** — The actual tickets UI rendered when access is permitted
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time

## Usage Example

```typescript
// Automatically rendered by Next.js App Router at /tickets
// No direct instantiation needed

// Access control behavior:
// - SaaS tenant mode → renders <TicketsView />
// - Any other mode   → redirects to /dashboard, renders null
```

> **Note:** This page is exclusively available in SaaS tenant mode. In self-hosted or other deployment modes, users are silently redirected to `/dashboard` both on initial render (returns `null`) and via the `useEffect` router redirect.
