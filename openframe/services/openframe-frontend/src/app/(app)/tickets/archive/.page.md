Archived tickets page component that renders a searchable list of archived tickets, restricted to SaaS tenant mode only.

## Key Components

- **`TicketsArchive`** — Default export page component that:
  - Redirects to `/dashboard` if not in SaaS tenant mode
  - Manages a `search` query param via `useApiParams`
  - Provides a back button that navigates to `/tickets`
  - Renders the `ArchivedTickets` table component

## Usage Example

```typescript
// Accessed via Next.js routing at /tickets/archive
// Automatically redirects non-SaaS tenants to /dashboard

<ArchivedTickets
  backButton={{ label: 'Back', onClick: handleBack }}
  search={params.search}
  onSearchChange={handleSearchChange}
/>
```

## Notes

- `export const dynamic = 'force-dynamic'` disables static caching for this route
- SaaS tenant guard runs both in `useEffect` (redirect) and render (null return) to prevent flash of content
- Search state is URL-param-driven via `useApiParams`, enabling shareable/bookmarkable filtered views
