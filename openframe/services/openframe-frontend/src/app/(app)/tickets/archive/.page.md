Renders the archived tickets page for SaaS tenant mode, redirecting non-SaaS users to the dashboard.

## Key Components

- **`TicketsArchive`** — Default export page component that guards access to the archive view based on tenant mode
- **`isSaasTenantMode`** — Guard check that redirects to `/dashboard` if the current context is not a SaaS tenant
- **`useApiParams`** — Manages URL-synced search parameter state
- **`useSafeBack`** — Provides safe back navigation, defaulting to `/tickets`
- **`ArchivedTickets`** — Renders the archived tickets table with search and back button support

## Usage Example

```typescript
// Accessed via route: /tickets/archive
// Only available in SaaS tenant mode — non-SaaS contexts are redirected to /dashboard

<ArchivedTickets
  backButton={{ label: 'Back', onClick: handleBack }}
  search={params.search}
  onSearchChange={handleSearchChange}
/>
```

## Behavior Notes

- `dynamic = 'force-dynamic'` disables static rendering to ensure fresh data on every request
- On mount, non-SaaS tenants are redirected via `router.replace('/dashboard')` and the component returns `null` to prevent a flash of content
- Search state is managed through URL params via `useApiParams`, enabling shareable/bookmarkable filtered archive URLs
