Archived tickets page component that displays a filterable list of archived tickets, restricted to SaaS tenant mode only.

## Key Components

- **`TicketsArchive`** — Default export page component that:
  - Redirects to `/dashboard` if not running in SaaS tenant mode
  - Provides a back button that navigates to `/tickets`
  - Manages a `search` query param via `useApiParams` for filtering archived tickets
  - Renders the `ArchivedTickets` table component with search and navigation props

## Usage Example

```typescript
// Rendered automatically by Next.js at /tickets/archive
// Accessible only in SaaS tenant mode; otherwise redirects to /dashboard

// The page manages search state via URL params:
// /tickets/archive?search=printer
// → filters archived tickets containing "printer"
```

## Behavior Notes

- `dynamic = 'force-dynamic'` disables static rendering to ensure fresh data on each request
- Uses `router.replace` (not `push`) for both back navigation and the SaaS redirect, preventing extra history entries
- Returns `null` during the redirect cycle to avoid flashing the `ArchivedTickets` component to non-SaaS users
