Implements the `TicketService` class, which bridges the ticket-based GraphQL API with the dialog-oriented frontend interface by fetching, normalizing, and mutating ticket data.

## Key Components

### `TicketService` (class)
Implements `TicketServiceInterface` with the following methods:

| Method | Description |
|--------|-------------|
| `fetchDialogs(params)` | Fetches a paginated, filtered list of tickets mapped as dialogs |
| `fetchTicketsBoard(params)` | Fetches tickets grouped by board status (ACTIVE, TECH_REQUIRED, ON_HOLD, RESOLVED) |
| `fetchDialog(id)` | Fetches a single ticket by ID as a `Dialog` |
| `fetchMessages(params)` | Fetches paginated chat messages for a dialog/ticket |
| `updateStatus(ticketId, status)` | Updates ticket status, returns boolean success |
| `mutateStatus(ticketId, status)` | Executes the appropriate GraphQL status mutation |
| `fetchTicketStatusTransitions()` | Returns allowed status transitions from the API |
| `reorderTicket(params)` | Reorders a ticket on the board with optional status change |

### `normalizeTicketToDialog(ticket)` (internal)
Maps a raw `TicketNode` from the GraphQL response into the frontend `Dialog` type, including owner, notes, attachments, and token usage normalization.

### Status Mappings
- `TICKET_TO_DIALOG_STATUS` / `DIALOG_TO_TICKET_STATUS` — bidirectional status string maps
- `STATUS_TO_MUTATION` — maps each target status to its corresponding GraphQL mutation and response key

## Usage Example

```typescript
const service = new TicketService();

// Fetch paginated tickets as dialogs
const page = await service.fetchDialogs({
  limit: 20,
  statuses: ['ACTIVE', 'TECH_REQUIRED'],
  organizationIds: ['org-123'],
});

// Transition a ticket to resolved
const newStatus = await service.mutateStatus('ticket-abc', 'RESOLVED');

// Fetch board view grouped by status
const board = await service.fetchTicketsBoard({
  limit: 10,
  search: 'printer',
});

// Reorder a ticket between two others
await service.reorderTicket({
  id: 'ticket-abc',
  afterTicketId: 'ticket-111',
  beforeTicketId: 'ticket-222',
  status: 'ACTIVE',
});
```
