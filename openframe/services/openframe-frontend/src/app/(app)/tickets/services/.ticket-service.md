Provides a GraphQL-backed service implementation for managing support tickets, handling CRUD operations, status transitions, board views, and message fetching by adapting the ticket domain model to the shared `Dialog` interface.

## Key Components

- **`TicketService`** — Main class implementing `TicketServiceInterface` with methods for ticket and message operations
- **`normalizeTicketToDialog()`** — Maps raw `TicketNode` GraphQL responses to the unified `Dialog` type
- **`mutateTicketStatus()`** — Private helper that executes status-change GraphQL mutations and returns the updated `DialogStatus`
- **`STATUS_TO_MUTATION`** — Lookup map routing target statuses (`ON_HOLD`, `RESOLVED`, `ARCHIVED`, `ACTIVE`) to their corresponding GraphQL mutations
- **`TICKET_TO_DIALOG_STATUS` / `DIALOG_TO_TICKET_STATUS`** — Bidirectional status mapping between ticket and dialog domains

## Key Methods

| Method | Description |
|---|---|
| `fetchDialogs(params)` | Paginated ticket list with filtering by status, org, assignee |
| `fetchTicketsBoard(params)` | Fetches all board columns (`ACTIVE`, `TECH_REQUIRED`, `ON_HOLD`, `RESOLVED`) in a single query |
| `fetchBoardColumnByStatusId(params)` | Fetches a single board column by custom status ID |
| `fetchDialog(id)` | Fetches a single ticket and normalizes it to `Dialog` |
| `fetchMessages(params)` | Fetches paginated chat messages, respecting the `thinking` feature flag |
| `mutateStatus(ticketId, status)` | Dispatches the correct GraphQL mutation for a status transition |

## Usage Example

```typescript
const service = new TicketService();

// Fetch paginated tickets filtered by status
const page = await service.fetchDialogs({
  limit: 20,
  statuses: ['ACTIVE', 'TECH_REQUIRED'],
  organizationIds: ['org-123'],
  assigneeIds: ['user-456'],
});

// Fetch the full Kanban board
const board = await service.fetchTicketsBoard({ limit: 10 });
console.log(board.ACTIVE.dialogs); // Dialog[]

// Transition a ticket to ON_HOLD
const newStatus = await service.mutateStatus('ticket-id', 'ON_HOLD');

// Fetch messages for a ticket's dialog
const messages = await service.fetchMessages({
  dialogId: 'dialog-id',
  chatType: 'TECH',
  limit: 50,
  sortDirection: 'DESC',
});
```
