Defines TypeScript interfaces and types for the ticket service layer, providing contracts for ticket/dialog CRUD operations, pagination, board management, and real-time messaging within the Flamingo OpenFrame platform.

## Key Components

### Interfaces

| Interface | Description |
|-----------|-------------|
| `TicketsPage` | Paginated response containing dialogs with cursor-based page info and filtered count |
| `MessagePage` | Paginated response for messages within a dialog |
| `FetchTicketsParams` | Query params for listing tickets — supports status filter, search, org/assignee filters, and pagination |
| `FetchTicketsBoardParams` | Query params for the Kanban-style board view (excludes status filter) |
| `ReorderTicketParams` | Params for drag-and-drop ticket reordering using before/after anchor IDs |
| `TicketStatusTransition` | Defines allowed status transitions from one `DialogStatus` to a set of targets |
| `FetchMessagesParams` | Query params for fetching messages with sort and pagination support |
| `TicketService` | Core service contract — all implementations must satisfy this interface |

### Types

| Type | Description |
|------|-------------|
| `BoardStatus` | Union type for Kanban board columns: `ACTIVE`, `TECH_REQUIRED`, `ON_HOLD`, `RESOLVED` |
| `TicketsBoardPage` | Record mapping each `BoardStatus` to a `TicketsPage` |
