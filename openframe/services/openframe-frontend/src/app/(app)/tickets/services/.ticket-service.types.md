Defines TypeScript interfaces and types for the ticket service layer, providing contracts for ticket/dialog operations including pagination, board management, message handling, and status transitions.

## Key Components

**Pagination Interfaces**
- `TicketsPage` — Paginated dialog results with filtered count
- `MessagePage` — Paginated message results

**Parameter Interfaces**
- `FetchTicketsParams` — Filters for list-view ticket queries (status, search, org, assignee, cursor)
- `FetchTicketsBoardParams` — Filters for Kanban board queries
- `FetchBoardColumnByStatusIdParams` — Filters for fetching a single board column by custom status ID
- `FetchMessagesParams` — Paginated message fetch with sort options and chat type
- `ReorderTicketParams` — Drag-and-drop ticket reordering with optional lifecycle `statusId`

**Status & Transition Types**
- `BoardStatus` — Union of four fixed Kanban columns: `ACTIVE | TECH_REQUIRED | ON_HOLD | RESOLVED`
- `TicketsBoardPage` — Map of `BoardStatus` → `TicketsPage`
- `TicketStatusTransition` — Typed transition using `DialogStatus`
- `TicketStatusTransitionRule` — Raw string-based transition rule

**Service Contract**
- `TicketService` — Main interface defining all ticket operations (fetch, update, reorder, message, approve/reject, archive, chunks)

## Usage Example

```typescript
import type { TicketService, FetchTicketsParams, BoardStatus } from './ticket-service.types';

const params: FetchTicketsParams = {
  statuses: ['ACTIVE'],
  search: 'VPN issue',
  organizationIds: ['org_123'],
  limit: 25,
  cursor: 'eyJpZCI6IjEwMCJ9',
};

// Inject and consume via the service contract
async function loadBoard(service: TicketService) {
  const board = await service.fetchTicketsBoard({ limit: 20 });

  const activeTickets = board['ACTIVE'];   // TicketsPage
  console.log(activeTickets.filteredCount);

  await service.reorderTicket({
    id: 'ticket_1',
    afterTicketId: 'ticket_0',
    beforeTicketId: null,
    status: 'ACTIVE' as BoardStatus,
  });
}
```
