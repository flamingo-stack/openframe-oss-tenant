Entry point for the ticket service module that instantiates a singleton `TicketService` and re-exports all related TypeScript types.

## Key Components

- **`ticketService`** — Singleton instance of `TicketService`, ready for import and use across the application.
- **Re-exported Types:**
  - `BoardStatus` — Status values for ticket boards
  - `FetchMessagesParams` — Parameters for fetching ticket messages
  - `FetchTicketsBoardParams` — Parameters for fetching board-level tickets
  - `FetchTicketsParams` — Parameters for fetching tickets
  - `MessagePage` — Paginated message response shape
  - `TicketsBoardPage` — Paginated board tickets response shape
  - `TicketsPage` — Paginated tickets response shape

## Usage Example

```typescript
import { ticketService } from './tickets';
import type { FetchTicketsParams, TicketsPage } from './tickets';

const params: FetchTicketsParams = {
  page: 1,
  pageSize: 25,
};

const tickets: TicketsPage = await ticketService.fetchTickets(params);
```
