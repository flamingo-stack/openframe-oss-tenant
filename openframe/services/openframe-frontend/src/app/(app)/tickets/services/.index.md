Initializes and exports a singleton instance of `TicketService` along with all related TypeScript types for ticket and message operations.

## Key Components

- **`ticketService`** — Singleton instance of `TicketService`, ready for use across the application without re-instantiation.
- **Exported Types:**
  - `BoardStatus` — Status values for ticket boards.
  - `FetchMessagesParams` — Parameters for fetching messages.
  - `FetchTicketsBoardParams` — Parameters for fetching board-view tickets.
  - `FetchTicketsParams` — Parameters for fetching tickets.
  - `MessagePage` — Paginated message result shape.
  - `TicketsBoardPage` — Paginated board ticket result shape.
  - `TicketsPage` — Paginated ticket list result shape.

## Usage Example

```typescript
import {
  ticketService,
  FetchTicketsParams,
  TicketsPage,
} from './tickets';

const params: FetchTicketsParams = {
  page: 1,
  pageSize: 25,
  status: 'open',
};

const result: TicketsPage = await ticketService.fetchTickets(params);
console.log(result.items);
```

> Import `ticketService` directly from this module to ensure a single shared instance is used across all consumers.
