Entry point for the ticket service module — instantiates and exports a singleton `TicketService` along with all related TypeScript types.

## Key Components

- **`ticketService`** — Singleton instance of `TicketService`, ready for import across the application
- **Re-exported Types:**
  - `BoardStatus` — Status values for ticket boards
  - `FetchMessagesParams` — Parameters for fetching ticket messages
  - `FetchTicketsBoardParams` — Parameters for board-based ticket queries
  - `FetchTicketsParams` — Parameters for general ticket queries
  - `MessagePage` — Paginated message response shape
  - `TicketsBoardPage` — Paginated board ticket response shape
  - `TicketsPage` — Paginated ticket list response shape

## Usage Example

```typescript
import { ticketService } from './tickets';
import type { FetchTicketsParams, TicketsPage } from './tickets';

const params: FetchTicketsParams = {
  page: 1,
  pageSize: 25,
  status: 'open',
};

const result: TicketsPage = await ticketService.fetchTickets(params);
```

> Import `ticketService` as a shared singleton rather than instantiating `TicketService` directly to avoid multiple instances across the codebase.
