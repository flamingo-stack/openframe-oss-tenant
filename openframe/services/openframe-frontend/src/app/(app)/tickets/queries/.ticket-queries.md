GraphQL query and mutation constants for the Flamingo ticket management system, targeting the `openframe-saas-ai-agent` service via `/chat/graphql`.

## Key Components

### Queries
| Export | Description |
|--------|-------------|
| `GET_TICKET_QUERY` | Fetch a single ticket by ID with full detail (notes, attachments, dialog, transitions) |
| `GET_TICKETS_QUERY` | Paginated, filterable, searchable ticket list |
| `GET_TICKETS_BOARD_QUERY` | Kanban board view with columns for `ACTIVE`, `TECH_REQUIRED`, `ON_HOLD`, `RESOLVED` |
| `GET_BOARD_COLUMN_TICKETS_QUERY` | Lifecycle board column tickets by custom `statusId` (requires `featureFlags.ticketStatuses`) |
| `GET_TICKET_LABELS_QUERY` | All available ticket labels |
| `GET_TICKET_ATTACHMENT_DOWNLOAD_URL` | Presigned download URL for a ticket attachment |
| `GET_TICKET_STATUS_TRANSITION_RULES_QUERY` | Valid status transition rules between custom statuses |

### Mutations
| Export | Description |
|--------|-------------|
| `CREATE_TICKET_MUTATION` | Create a new ticket |
| `UPDATE_TICKET_MUTATION` | Update ticket fields |
| `TRANSITION_TICKET_MUTATION` | Transition ticket to a new custom status |
| `PUT_TICKET_ON_HOLD_MUTATION` | Set ticket status to `ON_HOLD` |
| `RESOLVE_TICKET_MUTATION` | Mark ticket as resolved |
| `ADD_TICKET_NOTE_MUTATION` | Add an internal note to a ticket |
| `UPDATE_TICKET_NOTE_MUTATION` | Edit an existing note |
| `DELETE_TICKET_NOTE_MUTATION` | Delete a note |
| `CREATE_TEMP_ATTACHMENT_UPLOAD_URL` | Generate a presigned URL for staging a file upload |
| `DELETE_TEMP_ATTACHMENT` | Remove a staged (temporary) attachment |
| `DELETE_TICKET_ATTACHMENT` | Remove a confirmed ticket attachment |

### Internal Fragments
- `BOARD_CARD_TICKET_FRAGMENT` — Core ticket fields for standard board cards
- `BOARD_CARD_TICKET_LIFECYCLE_FRAGMENT` — Extended board card fields including `statusDefinition` for lifecycle/custom-status boards
- `BOARD_COLUMN_CONNECTION_FRAGMENT` — Cursor pagination wrapper for board columns

## Usage Example

```typescript
import {
  GET_TICKET_QUERY,
  CREATE_TICKET_MUTATION,
  GET_TICKETS_BOARD_QUERY,
} from './ticket-queries';

// Fetch a single ticket
const { data } = await graphqlClient.query({
  query: GET_TICKET_QUERY,
  variables: { id: 'ticket-uuid' },
});

// Create a new ticket
const { data } = await graphqlClient.mutate({
  mutation: CREATE_TICKET_MUTATION,
  variables: {
    input: {
      title: 'Printer offline',
      description: 'HP LaserJet not responding',
      organizationId: 'org-uuid',
    },
  },
});

// Load the Kanban board
const { data } = await graphqlClient.query({
  query: GET_TICKETS_BOARD_QUERY,
  variables: {
    limit: 20,
    search: '',
    organizationIds: ['org-uuid'],
    assigneeIds: [],
  },
});
```

> **Note:** The lifecycle board queries (`GET_BOARD_COLUMN_TICKETS_QUERY`, `GET_TICKET_STATUS_TRANSITION_RULES_QUERY`, `TRANSITION_TICKET_MUTATION`) are gated behind the `featureFlags.ticketStatuses` feature flag and support custom status definitions beyond the default four columns.
