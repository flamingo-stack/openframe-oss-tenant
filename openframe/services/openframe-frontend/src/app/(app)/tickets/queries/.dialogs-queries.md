Defines GraphQL query strings for fetching dialog-related data, including statistics and paginated message threads with optional AI thinking data.

## Key Components

- **`GET_DIALOG_STATISTICS_QUERY`** — Static query fetching aggregate dialog stats: total count, status breakdown, average resolution time, and average rating.
- **`getDialogMessagesQuery(options?)`** — Factory function returning a paginated `messages` query. Accepts `{ includeThinking: boolean }` to conditionally inline the `ThinkingData` fragment.
- **`THINKING_FRAGMENT`** — Internal GraphQL inline fragment for `ThinkingData`, conditionally injected into the messages query.

### Message Data Union Types Covered

| Fragment | Key Fields |
|---|---|
| `TextData` | `text` |
| `ThinkingData` | `text` (optional) |
| `SystemData` | `text` |
| `ExecutingToolData` | `toolFunction`, `requiresApproval`, `approvalStatus` |
| `ExecutedToolData` | `result`, `success`, `approvalStatus` |
| `ApprovalRequestData` | `approvalRequestId`, `toolCalls` |
| `ApprovalResultData` | `approved`, `approvalType` |
| `ContextCompactionStartData` / `ContextCompactionEndData` | `summary` |
| `ErrorData` | `error`, `details` |

## Usage Example

```typescript
import {
  GET_DIALOG_STATISTICS_QUERY,
  getDialogMessagesQuery,
} from './dialogs-queries';

// Fetch dialog statistics
const statsResult = await gqlClient.query({ query: GET_DIALOG_STATISTICS_QUERY });

// Fetch messages without AI thinking data (default)
const messagesQuery = getDialogMessagesQuery();

// Fetch messages including AI thinking steps (e.g. Mingo AI debug view)
const messagesWithThinking = getDialogMessagesQuery({ includeThinking: true });

const result = await gqlClient.query({
  query: messagesWithThinking,
  variables: {
    dialogId: 'dialog_123',
    limit: 50,
    sortField: 'createdAt',
    sortDirection: 'ASC',
  },
});
```
