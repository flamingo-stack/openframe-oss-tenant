Defines GraphQL query strings for fetching dialog/conversation data, including statistics and paginated message threads with support for various message types.

## Key Components

- **`GET_DIALOG_STATISTICS_QUERY`** — Static query that retrieves aggregate dialog stats: total count, status breakdowns, average resolution time, and average rating.
- **`getDialogMessagesQuery(options)`** — Factory function that returns a paginated `GetAllMessages` query. Accepts an `includeThinking` boolean option to conditionally include `ThinkingData` fragments.
- **`THINKING_FRAGMENT`** — Private inline fragment appended to the messages query only when `includeThinking` is `true`.

### Supported Message Data Types

The messages query handles the following union types via inline fragments:

| Type | Description |
|---|---|
| `TextData` | Standard text message |
| `ThinkingData` | AI reasoning output (optional) |
| `SystemData` | System-generated message |
| `ExecutingToolData` | Tool invocation in progress |
| `ExecutedToolData` | Completed tool result |
| `ApprovalRequestData` | Human-in-the-loop approval prompt |
| `ApprovalResultData` | Response to an approval request |
| `ContextCompactionStartData` | Context compression initiated |
| `ContextCompactionEndData` | Context compression summary |
| `ErrorData` | Error with details |

## Usage Example

```typescript
import { GET_DIALOG_STATISTICS_QUERY, getDialogMessagesQuery } from './dialogs-queries';

// Fetch dialog stats
const statsResult = await gqlClient.query({ query: GET_DIALOG_STATISTICS_QUERY });

// Fetch messages without thinking traces
const messagesQuery = getDialogMessagesQuery();

// Fetch messages including AI thinking traces (e.g., for debug/admin views)
const messagesWithThinking = getDialogMessagesQuery({ includeThinking: true });

const result = await gqlClient.query({
  query: messagesWithThinking,
  variables: {
    dialogId: 'dialog-123',
    limit: 50,
    sortField: 'createdAt',
    sortDirection: 'ASC',
  },
});
```
