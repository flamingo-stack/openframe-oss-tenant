GraphQL query definitions for dialog-related data fetching, including dialog statistics and paginated message retrieval with optional AI thinking data support.

## Key Components

### `GET_DIALOG_STATISTICS_QUERY`
Static GraphQL query string that fetches aggregate dialog metrics:
- `totalCount` — total number of dialogs
- `statusCounts` — breakdown of dialogs by status
- `averageResolutionTimeFormatted` — human-readable resolution time
- `averageRating` — average dialog rating score

### `getDialogMessagesQuery(options?)`
Factory function that returns a dynamic GraphQL query string for paginated message fetching. Supports cursor-based pagination, sorting, and chat type filtering.

**Parameters:**
| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `includeThinking` | `boolean` | `false` | Conditionally includes `ThinkingData` fragment for AI reasoning traces |

**Supported `messageData` union types:**
- `TextData` — standard text messages
- `ThinkingData` — AI internal reasoning (opt-in)
- `SystemData` — system-generated messages
- `ExecutingToolData` / `ExecutedToolData` — tool call lifecycle events
- `ApprovalRequestData` / `ApprovalResultData` — human-in-the-loop approval flows
- `ContextCompactionStartData` / `ContextCompactionEndData` — context window management events
- `ErrorData` — error details

## Usage Example

```typescript
import { GET_DIALOG_STATISTICS_QUERY, getDialogMessagesQuery } from './dialogs-queries';

// Fetch dialog statistics
const statsResult = await gqlClient.query({ query: GET_DIALOG_STATISTICS_QUERY });

// Fetch messages without thinking data (default)
const messagesQuery = getDialogMessagesQuery();

// Fetch messages including Mingo AI thinking traces
const messagesWithThinking = getDialogMessagesQuery({ includeThinking: true });

const result = await gqlClient.query({
  query: messagesWithThinking,
  variables: {
    dialogId: 'dialog_123',
    chatType: 'AGENT',
    limit: 50,
    sortField: 'createdAt',
    sortDirection: 'ASC',
  },
});
```
