Client-side page component that guards the new ticket creation route, redirecting non-SaaS tenant users to the tickets list and rendering the `CreateEditTicketPage` form only in SaaS tenant mode.

## Key Components

- **`NewTicketPage`** — Default export; a Next.js page component with a `force-dynamic` rendering directive.
- **`isSaasTenantMode()`** — Utility check that determines if the app is running in SaaS tenant mode; controls both the redirect and render guard.
- **`CreateEditTicketPage`** — The actual ticket creation/editing form rendered when the mode check passes.

## Usage Example

```typescript
// Automatically rendered by Next.js at route: /tickets/new
// No direct usage required — routing is handled by the framework.

// Access control logic summary:
// - SaaS tenant mode     → renders <CreateEditTicketPage />
// - Non-SaaS tenant mode → redirects to /tickets and returns null
```

## Behavior Notes

- Uses `useEffect` + `router.replace` for a client-side redirect on mount, preventing history stack pollution.
- The `if (!isSaasTenantMode()) return null` guard prevents a flash of content before the redirect completes.
- `export const dynamic = 'force-dynamic'` ensures the page is never statically cached, keeping mode checks evaluated at runtime.
