Client-side page component for creating new tickets, restricted to SaaS tenant mode only. Redirects non-SaaS users to `/tickets` and renders the `CreateEditTicketPage` form when access is permitted.

## Key Components

- **`NewTicketPage`** — Default export; route guard component that conditionally renders the ticket creation form
- **`isSaasTenantMode()`** — Utility check that determines if the current deployment is in SaaS tenant mode
- **`CreateEditTicketPage`** — Shared form component used for both creating and editing tickets
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time

## Usage Example

```typescript
// Rendered automatically by Next.js at route: /tickets/new
// Access is gated by isSaasTenantMode()

// If NOT in SaaS tenant mode:
// → router.replace('/tickets') is called
// → Component returns null (no flash of content)

// If IN SaaS tenant mode:
// → <CreateEditTicketPage /> is rendered
```

## Behavior Notes

- Uses `useEffect` + `router.replace` to perform a client-side redirect on mount if the mode check fails
- The early `return null` prevents any UI flash before the redirect completes
- `force-dynamic` export ensures deployment context is always evaluated fresh, avoiding stale static renders
