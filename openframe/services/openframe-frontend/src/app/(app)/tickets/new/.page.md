Client-side page component for creating new tickets, restricted to SaaS tenant mode. Redirects to `/tickets` if the app is not running in SaaS tenant mode.

## Key Components

- **`NewTicketPage`** — Default export; a Next.js page component that guards access based on deployment mode and renders the ticket creation form.
- **`isSaasTenantMode()`** — Utility imported from `@/lib/app-mode` used to check if the app is running in SaaS tenant mode.
- **`CreateEditTicketPage`** — Shared form component rendered when access is permitted.
- **`dynamic = 'force-dynamic'`** — Disables static generation, ensuring the page is always server-rendered at request time.

## Usage Example

```typescript
// Automatically rendered by Next.js at /tickets/new
// Redirects non-SaaS users to /tickets
export default function NewTicketPage() {
  const router = useRouter();

  useEffect(() => {
    if (!isSaasTenantMode()) {
      router.replace('/tickets');
    }
  }, [router]);

  if (!isSaasTenantMode()) {
    return null; // Prevents flash of content before redirect
  }

  return <CreateEditTicketPage />;
}
```

> The `null` return before the redirect resolves prevents a brief flash of the ticket form for non-SaaS users while the router redirect is processing.
