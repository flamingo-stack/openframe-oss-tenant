Defines all shared constants, enums, and derived TypeScript types used across the dialog/chat system, covering statuses, message types, API endpoints, and network configuration.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `DIALOG_STATUS` / `DialogStatus` | const + type | Lifecycle states for dialogs (`ON_HOLD`, `RESOLVED`, `ACTIVE`, `ARCHIVED`) |
| `TICKET_STATUS` / `TicketStatusValue` | const + type | Mirrors backend `TicketStatus` enum, adds `TECH_REQUIRED` |
| `DIALOG_MODE` / `DialogModeValue` | const + type | Conversation mode — `AI` or `DIRECT` |
| `CHAT_TYPE` / `ChatType` | const + type | Distinguishes client (`CLIENT_CHAT`) vs admin (`ADMIN_AI_CHAT`) chat surfaces |
| `MESSAGE_TYPE` / `MessageType` | const + type | Full message lifecycle events including tool execution and approval flow |
| `OWNER_TYPE` / `OwnerType` | const + type | Message/dialog ownership — `CLIENT`, `ADMIN`, or `ASSISTANT` |
| `APPROVAL_STATUS` / `ApprovalStatus` | const + type | Approval workflow states: `pending`, `approved`, `rejected` |
| `ASSISTANT_CONFIG` / `AssistantType` | const + type | Named config for `fae` (client-facing) and `mingo` (technician) AI assistants |
| `CREATION_SOURCE` / `CreationSource` | const + type | Origin of a ticket/dialog: form, dialog, or admin dashboard |
| `API_ENDPOINTS` | const | Chat service REST and GraphQL route paths |
| `NATS_TOPICS` / `NatsMessageType` | const + type | NATS pub/sub topic names for real-time messaging |
| `STORAGE_KEYS` | const | Browser storage key for the access token |
| `NETWORK_CONFIG` | const | Tuning values for connection timeouts, polling limits, and ping intervals |
