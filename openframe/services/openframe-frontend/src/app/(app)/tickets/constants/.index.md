Defines all shared constants and discriminated-union types for the dialog/chat system, covering statuses, modes, message types, assistant identities, API routes, and network configuration.

## Key Components

| Export | Description |
|--------|-------------|
| `DIALOG_STATUS` / `DialogStatus` | Lifecycle states for dialogs: `ON_HOLD`, `RESOLVED`, `ACTIVE`, `ARCHIVED` |
| `TICKET_STATUS` / `TicketStatusValue` | Mirrors the backend `TicketStatus` enum, adds `TECH_REQUIRED` |
| `DIALOG_MODE` / `DialogModeValue` | Conversation mode: `AI` or `DIRECT` |
| `CHAT_TYPE` / `ChatType` | Distinguishes `CLIENT_CHAT` from `ADMIN_AI_CHAT` |
| `MESSAGE_TYPE` / `MessageType` | Full message lifecycle: text, tool execution, approval flow, errors, system events |
| `OWNER_TYPE` / `OwnerType` | Message author: `CLIENT`, `ADMIN`, or `ASSISTANT` |
| `APPROVAL_STATUS` / `ApprovalStatus` | Tool-approval states: `pending`, `approved`, `rejected` |
| `ASSISTANT_CONFIG` / `AssistantType` | Named assistant registry — `fae` (Fae) and `mingo` (Mingo AI) |
| `CREATION_SOURCE` / `CreationSource` | Ticket origin: FAE form/dialog or admin dashboard |
| `API_ENDPOINTS` | Typed path map for all chat service HTTP routes |
| `NATS_TOPICS` / `NatsMessageType` | NATS subject names for real-time messaging |
| `STORAGE_KEYS` | Browser storage key constants (e.g. `of_access_token`) |
| `NETWORK_CONFIG` | Tuning values for connection timeouts, ping intervals, and message pagination |

## Usage Example

```typescript
import {
  DIALOG_STATUS,
  MESSAGE_TYPE,
  ASSISTANT_CONFIG,
  API_ENDPOINTS,
  NETWORK_CONFIG,
  type DialogStatus,
  type MessageType,
  type AssistantType,
} from './index';

// Type-safe status comparison
function isResolved(status: DialogStatus): boolean {
  return status === DIALOG_STATUS.RESOLVED;
}

// Route reference without magic strings
async function sendMessage(payload: unknown) {
  await fetch(API_ENDPOINTS.SEND_MESSAGE, {
    method: 'POST',
    body: JSON.stringify(payload),
  });
}

// Assistant identity lookup
const assistant = ASSISTANT_CONFIG.MINGO;
// assistant.type → 'mingo', assistant.name → 'Mingo'

// Network config for a NATS client
const client = await connect({
  timeout: NETWORK_CONFIG.CONNECT_TIMEOUT_MS,       // 10 000 ms
  reconnectTimeWait: NETWORK_CONFIG.RECONNECT_TIME_WAIT_MS, // 2 000 ms
  pingInterval: NETWORK_CONFIG.PING_INTERVAL_MS,    // 30 000 ms
  maxPingOut: NETWORK_CONFIG.MAX_PING_OUT,          // 3
});
```
