Utility for extracting resolved ticket counts from statistics data, with feature-flag-aware branching between legacy string-based status counts and structured status definition counts.

## Key Components

### Interfaces

- **`TicketStatusCount`** — Legacy status count shape: `{ status: string, count: number }`
- **`TicketStatusDefinitionCount`** — Structured status count shape: `{ status: { kind: string }, count: number }`
- **`TicketStatisticsCounts`** — Union container holding either or both count arrays

### Functions

- **`resolvedCountFromStatistics(stats)`** — Returns the resolved ticket count from a statistics object; returns `0` if stats are undefined. Branches on the `ticketStatuses` feature flag:
  - **Flag enabled:** searches `statusDefinitionCounts` by `status.kind`
  - **Flag disabled:** searches `statusCounts` by `status` string

## Usage Example

```typescript
import { resolvedCountFromStatistics } from './ticket-statistics';

const stats = {
  statusCounts: [
    { status: 'resolved', count: 42 },
    { status: 'open', count: 15 },
  ],
};

const resolvedCount = resolvedCountFromStatistics(stats);
// → 42 (when ticketStatuses feature flag is disabled)

const structuredStats = {
  statusDefinitionCounts: [
    { status: { kind: 'resolved' }, count: 7 },
  ],
};

const resolvedFromStructured = resolvedCountFromStatistics(structuredStats);
// → 7 (when ticketStatuses feature flag is enabled)

resolvedCountFromStatistics(undefined); // → 0
```
