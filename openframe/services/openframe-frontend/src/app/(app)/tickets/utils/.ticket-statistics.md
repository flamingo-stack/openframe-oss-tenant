Utility for extracting resolved ticket counts from statistics data, with support for both legacy status strings and feature-flagged status definition objects.

## Key Components

**Interfaces**
- `TicketStatusCount` — Simple status/count pair using a plain string status
- `TicketStatusDefinitionCount` — Status/count pair using a structured `{ kind: string }` status object
- `TicketStatisticsCounts` — Union container holding either (or both) count array formats

**Functions**
- `resolvedCountFromStatistics(stats)` — Returns the resolved ticket count from a statistics object, branching on the `ticketStatuses` feature flag to select the correct data format

## Usage Example

```typescript
import { resolvedCountFromStatistics } from './ticket-statistics';

const stats = {
  statusCounts: [
    { status: 'resolved', count: 42 },
    { status: 'open', count: 10 },
  ],
  statusDefinitionCounts: [
    { status: { kind: 'resolved' }, count: 42 },
  ],
};

const resolved = resolvedCountFromStatistics(stats);
// Returns 42 (source array selected based on feature flag)

const empty = resolvedCountFromStatistics(undefined);
// Returns 0 safely
```

## Notes

- Returns `0` gracefully when `stats` is `undefined` or the resolved status entry is missing
- The feature flag `ticketStatuses.enabled()` determines whether to read from `statusDefinitionCounts` (new) or `statusCounts` (legacy)
