Utility types and helper for safely unwrapping GraphQL API responses, throwing descriptive errors on HTTP failures, GraphQL-level errors, or missing data.

## Key Components

- **`GraphQlResponse<T>`** — Generic interface representing a standard GraphQL response envelope with optional `data` and `errors` fields.
- **`extractGraphQlData<T>`** — Function that unwraps a wrapped fetch response containing a `GraphQlResponse<T>`, throwing on any failure condition.

## Usage Example

```typescript
import { extractGraphQlData, GraphQlResponse } from './graphql';

interface UserQuery {
  user: { id: string; name: string };
}

const response = await apiFetch<GraphQlResponse<UserQuery>>('/graphql');

// Throws if HTTP failed, GraphQL returned errors, or data is missing
const data = extractGraphQlData<UserQuery>(response);

console.log(data.user.name);
```

## Error Handling

`extractGraphQlData` throws an `Error` in three distinct cases:

| Condition | Error Message |
|-----------|---------------|
| `response.ok` is `false` | `response.error` or `Request failed with status {status}` |
| `gql.errors` is non-empty | First error's `message` or `'GraphQL error occurred'` |
| `gql.data` is missing | `'No data received from server'` |
