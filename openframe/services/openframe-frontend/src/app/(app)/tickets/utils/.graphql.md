Utility types and helpers for handling GraphQL API responses, providing type-safe data extraction with built-in error handling for both HTTP-level and GraphQL-level errors.

## Key Components

- **`GraphQlResponse<T>`** — Generic interface representing a standard GraphQL response envelope with optional `data` and `errors` fields.
- **`extractGraphQlData<T>`** — Function that unwraps a GraphQL response, throwing descriptive errors for HTTP failures, GraphQL errors, or missing data.

## Usage Example

```typescript
import { extractGraphQlData, GraphQlResponse } from './graphql';

interface User {
  id: string;
  name: string;
}

interface UsersQuery {
  users: User[];
}

// Simulate a fetch wrapper response
const response = {
  ok: true,
  data: {
    data: { users: [{ id: '1', name: 'Alice' }] },
  } as GraphQlResponse<UsersQuery>,
  status: 200,
};

// Throws on HTTP error, GraphQL errors, or missing data
const result = extractGraphQlData<UsersQuery>(response);
console.log(result.users); // [{ id: '1', name: 'Alice' }]
```

## Error Handling

| Condition | Error Thrown |
|---|---|
| `response.ok === false` | HTTP error message or `Request failed with status {N}` |
| `gql.errors` non-empty | First GraphQL error message or `GraphQL error occurred` |
| `gql.data` is absent | `No data received from server` |
