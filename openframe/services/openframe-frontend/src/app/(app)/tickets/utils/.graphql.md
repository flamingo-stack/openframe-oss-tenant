Utility types and helpers for handling GraphQL HTTP responses in a type-safe manner, including error extraction and data unwrapping.

## Key Components

- **`GraphQlResponse<T>`** — Generic interface representing a standard GraphQL response envelope with optional `data` and `errors` fields.
- **`extractGraphQlData<T>`** — Function that unwraps a GraphQL HTTP response, throwing descriptive errors for HTTP failures, GraphQL-level errors, or missing data.

## Usage Example

```typescript
import { extractGraphQlData, GraphQlResponse } from './graphql';

interface User {
  id: string;
  name: string;
}

interface UsersQuery {
  users: User[];
}

const response = await fetch('/graphql', { method: 'POST', body: query });
const json: GraphQlResponse<UsersQuery> = await response.json();

const data = extractGraphQlData<UsersQuery>({
  ok: response.ok,
  data: json,
  status: response.status,
});

console.log(data.users); // User[]
```

## Error Handling

`extractGraphQlData` throws in three distinct scenarios:

| Scenario | Error Message |
|----------|---------------|
| HTTP request failed (`ok: false`) | Provided `error` string or `Request failed with status <code>` |
| GraphQL `errors` array present | First error's `message` or `GraphQL error occurred` |
| No `data` in response body | `No data received from server` |
