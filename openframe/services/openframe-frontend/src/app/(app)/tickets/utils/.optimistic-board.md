Provides optimistic UI updates for drag-and-drop ticket moves on the Kanban board, manipulating React Query's cache directly to reflect column changes before the server confirms them.

## Key Components

**Interfaces**
- `OptimisticMoveInput` — Parameters for a legacy-status board move (ticketId, source/target `BoardStatus`, neighbor ticket IDs for ordering)
- `OptimisticMoveLifecycleInput` — Same shape but uses string `statusId` for custom lifecycle statuses
- `OptimisticMoveSnapshot` — Captured cache state (all board column entries + optional detail query) used for rollback

**Exported Functions**
- `applyOptimisticMove` — Applies an optimistic card move across legacy-status board columns in the React Query cache; returns a snapshot
- `applyOptimisticMoveLifecycle` — Identical logic for custom-status (lifecycle) columns, keyed by `statusId` instead of the `BoardStatus` enum
- `rollbackOptimisticMove` — Restores all affected cache entries from a previously captured snapshot on mutation error

**Internal Helpers**
- `removeFromColumn` — Immutably removes a dialog from an `InfiniteData<TicketsPage>` structure
- `insertIntoColumn` — Immutably inserts a dialog at the correct position (after/before neighbor IDs, or prepends to the first page as fallback)
- `findDialogInCache` — Scans all paged cache entries to locate a dialog by ID

## Usage Example

```typescript
// Inside a useMutation onMutatehandler
const snapshot = applyOptimisticMove(queryClient, {
  ticketId: 'ticket-123',
  sourceStatus: 'open',
  targetStatus: 'in_progress',
  afterTicketId: 'ticket-100',
  beforeTicketId: null,
});

// On error, restore the previous cache state
rollbackOptimisticMove(queryClient, snapshot);

// For custom lifecycle statuses
const lifecycleSnapshot = applyOptimisticMoveLifecycle(queryClient, {
  ticketId: 'ticket-456',
  sourceStatusId: 'status-uuid-1',
  targetStatusId: 'status-uuid-2',
  afterTicketId: null,
  beforeTicketId: 'ticket-789',
});
```
