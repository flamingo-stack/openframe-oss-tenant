Provides optimistic UI update logic for drag-and-drop ticket moves on a Kanban board, allowing instant visual feedback before server confirmation with full rollback support.

## Key Components

- **`OptimisticMoveInput`** — Input descriptor for a board move, including ticket ID, source/target statuses, and neighboring ticket IDs for positional ordering.
- **`OptimisticMoveSnapshot`** — Captures pre-move cache state (board columns + ticket detail) to enable rollback.
- **`applyOptimisticMove`** — Mutates the React Query cache to reflect the move instantly: removes the dialog from the source column, inserts it into the target column at the correct position, and updates the detail query.
- **`rollbackOptimisticMove`** — Restores all affected query cache entries to their pre-move snapshot state on error.
- **`removeFromColumn`** *(internal)* — Immutably removes a dialog from a paginated `InfiniteData<TicketsPage>` structure.
- **`insertIntoColumn`** *(internal)* — Immutably inserts a dialog at the correct index using `afterTicketId`/`beforeTicketId` anchors, falling back to prepend on the first page.
- **`isBoardQueryKey`** *(internal)* — Type guard to validate a query key matches the board column shape `['dialogs', 'boardColumn', status, filters]`.

## Usage Example

```typescript
// In a drag-and-drop mutation handler
const mutation = useMutation({
  mutationFn: (input: OptimisticMoveInput) => moveTicketApi(input),

  onMutate: async (input) => {
    await queryClient.cancelQueries({ queryKey: dialogsQueryKeys.boardColumns() });
    const snapshot = applyOptimisticMove(queryClient, input);
    return { snapshot };
  },

  onError: (_err, _input, context) => {
    if (context?.snapshot) {
      rollbackOptimisticMove(queryClient, context.snapshot);
    }
  },

  onSettled: () => {
    queryClient.invalidateQueries({ queryKey: dialogsQueryKeys.boardColumns() });
  },
});
```

> **Note:** `afterTicketId` and `beforeTicketId` should reflect the drop position relative to adjacent tickets. Pass `null` for both to prepend to the first page.
