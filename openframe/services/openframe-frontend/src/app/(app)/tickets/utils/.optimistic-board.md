Provides optimistic UI updates for drag-and-drop ticket movements on a Kanban board, manipulating React Query cache directly to reflect card repositioning before server confirmation.

## Key Components

**Interfaces**
- `OptimisticMoveInput` — Parameters for a legacy-status board move (ticket ID, source/target status, neighbor ticket IDs for positioning)
- `OptimisticMoveLifecycleInput` — Same contract for custom-status (lifecycle) columns, using string `statusId` instead of the `BoardStatus` enum
- `OptimisticMoveSnapshot` — Captured cache state before mutation, used for rollback

**Exported Functions**
- `applyOptimisticMove` — Applies an optimistic card move across legacy `BoardStatus` columns in the React Query cache; returns a snapshot for rollback
- `applyOptimisticMoveLifecycle` — Lifecycle (custom-status) counterpart; columns are keyed by `statusId` string rather than the legacy enum
- `rollbackOptimisticMove` — Restores all affected cache entries from a previously captured snapshot

**Internal Helpers**
- `removeFromColumn` — Splices a ticket out of an `InfiniteData<TicketsPage>` structure
- `insertIntoColumn` — Inserts a ticket at a position determined by `afterTicketId` / `beforeTicketId` neighbors, falling back to the top of the first page
- `findDialogInCache` — Locates a `Dialog` by ID across all paginated board column entries

## Usage Example

```typescript
import {
  applyOptimisticMove,
  rollbackOptimisticMove,
} from './optimistic-board';

// Inside a useMutation onMutate handler:
const snapshot = applyOptimisticMove(queryClient, {
  ticketId: 'ticket-123',
  sourceStatus: 'open',
  targetStatus: 'in_progress',
  afterTicketId: 'ticket-099',
  beforeTicketId: null,
});

// On error, restore the previous cache state:
rollbackOptimisticMove(queryClient, snapshot);
```
