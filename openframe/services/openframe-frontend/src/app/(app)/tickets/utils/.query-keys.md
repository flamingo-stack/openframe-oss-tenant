Defines structured React Query cache key factories for dialogs (tickets/conversations) and tickets, ensuring consistent cache key hierarchies across all related hooks and enabling targeted or broad cache invalidation.

## Key Components

**`DialogsQueryParams`** — Interface describing filterable parameters for dialog list queries: `archived`, `search`, `statusFilters`, `statusIds`, `organizationIds`, `assigneeIds`.

**`dialogsQueryKeys`** — Key factory for dialog queries:
- `all` — Root key `['dialogs']`, used for broad invalidation
- `lists()` / `list(params)` — Paginated list queries with normalized filter params
- `boardColumns()` / `boardColumn(status, params)` — Standard (built-in status) kanban column queries
- `boardColumnsLifecycle()` / `boardColumnLifecycle(statusId, params)` — Lifecycle (custom-status) kanban columns; intentionally namespaced separately to prevent cache collisions between differing card shapes

**`invalidateAllDialogs(queryClient)`** — Utility that invalidates every dialogs cache entry via the root key.

**`ticketsQueryKeys`** — Key factory for ticket-level queries: `all`, `labels()`, `detail(id)`, `statistics()`, `statusTransitions()`, `statusTransitionRules()`, `statuses()`.

## Usage Example

```typescript
import { useQuery, useInfiniteQuery, useQueryClient } from '@tanstack/react-query';
import { dialogsQueryKeys, ticketsQueryKeys, invalidateAllDialogs } from './query-keys';

// Paginated dialog list
const { data } = useInfiniteQuery({
  queryKey: dialogsQueryKeys.list({
    archived: false,
    search: 'network',
    assigneeIds: ['user-1'],
  }),
  queryFn: fetchDialogs,
});

// Kanban board column (lifecycle/custom status)
const { data: column } = useInfiniteQuery({
  queryKey: dialogsQueryKeys.boardColumnLifecycle('status-42', {
    organizationIds: ['org-1'],
  }),
  queryFn: fetchLifecycleColumn,
});

// Ticket detail
const { data: ticket } = useQuery({
  queryKey: ticketsQueryKeys.detail('ticket-99'),
  queryFn: () => fetchTicket('ticket-99'),
});

// Invalidate all dialogs after a mutation
const queryClient = useQueryClient();
await invalidateAllDialogs(queryClient);
```
