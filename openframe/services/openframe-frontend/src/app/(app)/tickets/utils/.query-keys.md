Defines and exports structured React Query key factories for dialogs (tickets/boards) and tickets queries, ensuring consistent cache key shapes across all related hooks.

## Key Components

### `DialogsQueryParams`
Interface describing filter parameters used to scope dialog list and board column queries.

| Field | Type | Description |
|-------|------|-------------|
| `archived` | `boolean` | Required. Filters archived vs. active dialogs |
| `search` | `string?` | Optional text search |
| `statusFilters` | `string[]?` | Filter by status values |
| `organizationIds` | `string[]?` | Filter by organization |
| `assigneeIds` | `string[]?` | Filter by assignee |

### `dialogsQueryKeys`
Hierarchical key factory for all dialogs-related queries:

| Key | Description |
|-----|-------------|
| `.all` | Root key — `['dialogs']` |
| `.lists()` | All paginated list queries |
| `.list(params)` | Specific list query scoped to filters |
| `.boardColumns()` | Root key for all board column queries |
| `.boardColumn(status, params)` | Single board column keyed by status + filters |

### `invalidateAllDialogs(queryClient)`
Utility that invalidates every dialogs query by targeting the root `dialogsQueryKeys.all` key.

### `ticketsQueryKeys`
Key factory for ticket-specific queries:

| Key | Description |
|-----|-------------|
| `.all` | Root key — `['tickets']` |
| `.labels()` | Ticket label queries |
| `.detail(id)` | Single ticket detail by ID |
| `.statistics()` | Ticket statistics queries |
| `.statusTransitions()` | Available status transitions |

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query';
import { dialogsQueryKeys, ticketsQueryKeys, invalidateAllDialogs } from './query-keys';

// List query with filters
const { data } = useInfiniteQuery({
  queryKey: dialogsQueryKeys.list({
    archived: false,
    search: 'network',
    statusFilters: ['open'],
    organizationIds: ['org_123'],
  }),
  queryFn: fetchDialogs,
});

// Board column query per status
const { data: column } = useInfiniteQuery({
  queryKey: dialogsQueryKeys.boardColumn('open', { search: 'vpn' }),
  queryFn: fetchBoardColumn,
});

// Ticket detail
const { data: ticket } = useQuery({
  queryKey: ticketsQueryKeys.detail('ticket_abc'),
  queryFn: () => fetchTicket('ticket_abc'),
});

// Invalidate all dialogs after mutation
const queryClient = useQueryClient();
invalidateAllDialogs(queryClient);
```
