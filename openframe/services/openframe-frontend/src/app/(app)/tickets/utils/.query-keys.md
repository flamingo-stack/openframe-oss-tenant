Defines structured React Query cache key factories for dialogs (tickets) and board column queries, ensuring consistent cache invalidation and query namespacing across the application.

## Key Components

**`DialogsQueryParams`** — Interface describing filter parameters shared across list and board column queries (archived state, search, status/org/assignee filters).

**`dialogsQueryKeys`** — Hierarchical key factory for dialog queries:
- `all` — root key; used for broad cache invalidation
- `lists()` / `list(params)` — paginated list queries with normalized filter params
- `boardColumns()` / `boardColumn(status, params)` — per-status board columns (standard statuses)
- `boardColumnsLifecycle()` / `boardColumnLifecycle(statusId, params)` — parallel namespace for lifecycle/custom-status columns; intentionally isolated to prevent cache collisions between different card shapes

**`invalidateAllDialogs(queryClient)`** — Utility to bulk-invalidate every dialogs query via the root key.

**`ticketsQueryKeys`** — Key factory for ticket-specific queries: `labels`, `detail`, `statistics`, `statusTransitions`, `statusTransitionRules`, `statuses`.

## Usage Example

```typescript
import { useInfiniteQuery, useQueryClient } from '@tanstack/react-query';
import { dialogsQueryKeys, ticketsQueryKeys, invalidateAllDialogs } from './query-keys';

// Paginated dialog list
const { data } = useInfiniteQuery({
  queryKey: dialogsQueryKeys.list({ archived: false, assigneeIds: ['user-1'] }),
  queryFn: fetchDialogs,
});

// Board column for a lifecycle status
const { data: column } = useInfiniteQuery({
  queryKey: dialogsQueryKeys.boardColumnLifecycle('status-42', { search: 'vpn' }),
  queryFn: fetchColumnDialogs,
});

// Ticket detail
const key = ticketsQueryKeys.detail('ticket-99'); // ['tickets', 'detail', 'ticket-99']

// Invalidate everything
const queryClient = useQueryClient();
invalidateAllDialogs(queryClient);
```

> **Note:** `boardColumn` and `boardColumnLifecycle` are kept in separate namespaces so standard and lifecycle card shapes never share a cache entry, preventing stale cross-shape renders.
