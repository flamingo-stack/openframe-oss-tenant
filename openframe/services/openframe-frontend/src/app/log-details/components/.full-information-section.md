A React component that displays detailed log entry information in a structured card format with consistent styling and conditional rendering for optional fields.

## Key Components

- **FullInformationSection**: Main component that renders log details in a card layout
- **LogEntry**: TypeScript interface defining the structure of log data with fields like `toolEventId`, `eventType`, `severity`, etc.
- **formatTimestamp**: Utility function that safely converts timestamps to ISO string format
- Uses `InfoRow` and `ToolBadge` components from the OpenFrame frontend core library

## Usage Example

```typescript
import { FullInformationSection } from './full-information-section'

const logEntry = {
  toolEventId: "evt_123456",
  eventType: "error",
  ingestDay: "2024-01-15",
  toolType: "monitoring",
  severity: "high",
  userId: "user_789",
  timestamp: "2024-01-15T10:30:00Z",
  message: "System error occurred"
}

export function LogDetailsPage() {
  return (
    <div className="p-4">
      <FullInformationSection logDetails={logEntry} />
    </div>
  )
}
```

The component automatically handles empty states, conditionally renders optional fields like `userId` and `deviceId`, and applies consistent OpenFrame design system styling with proper responsive behavior.
