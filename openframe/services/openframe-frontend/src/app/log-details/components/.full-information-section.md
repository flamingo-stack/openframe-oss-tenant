A React component that displays comprehensive log entry details in a structured card format with labeled information rows for the OpenFrame platform.

## Key Components

- **FullInformationSection**: Main component that renders log details in a card-based UI
- **LogEntry**: TypeScript interface defining the structure of log data
- **formatTimestamp**: Utility function for converting timestamps to ISO format
- **InfoRow**: Imported component for displaying label-value pairs
- **ToolBadge**: Imported component for displaying normalized tool type badges

## Usage Example

```typescript
import { FullInformationSection } from './full-information-section'

const logEntry = {
  toolEventId: "event-123",
  eventType: "error",
  ingestDay: "2024-01-15",
  toolType: "monitoring",
  severity: "high",
  userId: "user-456",
  deviceId: "device-789",
  timestamp: "2024-01-15T10:30:00Z",
  message: "System error detected"
}

function LogDetailsPage() {
  return (
    <div className="p-4">
      <FullInformationSection logDetails={logEntry} />
    </div>
  )
}
```

The component renders essential log information including tool event ID, ingestion date, tool type with visual badge, event type, severity level, and optional user/device identifiers. It gracefully handles missing log details with a placeholder message and uses responsive design patterns for mobile compatibility.
