A React component that displays comprehensive log entry information in a structured card format with visual styling and tool type badges.

## Key Components

- **FullInformationSection** - Main component that renders log details in an organized information card
- **LogEntry** - TypeScript interface defining the structure of log data including tool events, timestamps, and metadata
- **FullInformationSectionProps** - Component props interface accepting optional log details

## Usage Example

```typescript
import { FullInformationSection } from './full-information-section'

// Example log entry data
const logEntry = {
  toolEventId: "evt_123456",
  eventType: "error",
  ingestDay: "2024-01-15",
  toolType: "monitoring",
  severity: "high",
  userId: "user_789",
  deviceId: "device_456",
  message: "Connection timeout",
  timestamp: "2024-01-15T10:30:00Z",
  details: "Network timeout after 30 seconds"
}

// Render the component
function LogViewer() {
  return (
    <div>
      <FullInformationSection logDetails={logEntry} />
    </div>
  )
}
```

The component features a responsive design with proper spacing, typography using the Azeret Mono and DM Sans fonts, and handles missing data gracefully with a fallback state. It includes special formatting for timestamps and integrates with the OpenFrame design system using ODS CSS variables for consistent theming.
