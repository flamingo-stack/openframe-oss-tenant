A React component that displays detailed log entry information in a structured card format within the OpenFrame platform.

## Key Components

- **`FullInformationSection`** - Main component that renders log details in an organized card layout
- **`LogEntry`** - Interface defining the structure of log data with fields like toolEventId, eventType, severity, etc.
- **`FullInformationSectionProps`** - Component props interface accepting optional log details
- **`formatTimestamp`** - Utility function that safely formats timestamp strings to ISO format
- **`InfoRow`** - Imported component for displaying label-value pairs
- **`ToolBadge`** - Imported component for displaying tool type badges

## Usage Example

```typescript
import { FullInformationSection } from './full-information-section'

const logEntry = {
  toolEventId: 'evt_123',
  eventType: 'error',
  ingestDay: '2024-01-15',
  toolType: 'monitoring',
  severity: 'high',
  userId: 'user_456',
  timestamp: '2024-01-15T10:30:00Z',
  message: 'System error occurred'
}

export function LogViewer() {
  return (
    <div>
      <FullInformationSection logDetails={logEntry} />
    </div>
  )
}
```

The component handles empty states gracefully and conditionally renders optional fields like userId and deviceId. It uses consistent OpenFrame styling with dividers between information rows and responsive padding.
