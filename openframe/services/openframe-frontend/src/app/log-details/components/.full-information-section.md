A React component that displays detailed log entry information in a structured card layout with conditional field rendering and tool type visualization.

## Key Components

- **FullInformationSection**: Main component that renders log details in a formatted information card
- **LogEntry Interface**: TypeScript interface defining the structure of log data with fields like toolEventId, eventType, severity, etc.
- **FullInformationSectionProps Interface**: Props interface accepting optional log details
- **formatTimestamp**: Utility function that safely converts timestamp strings to ISO format

## Usage Example

```typescript
import { FullInformationSection } from './full-information-section'

const logData = {
  toolEventId: "evt_123456",
  eventType: "ERROR",
  ingestDay: "2024-01-15",
  toolType: "monitoring",
  severity: "high",
  userId: "user_789",
  deviceId: "device_456",
  message: "System alert triggered",
  timestamp: "2024-01-15T10:30:00Z",
  details: "Additional context information"
}

function LogViewer() {
  return (
    <div>
      <FullInformationSection logDetails={logData} />
    </div>
  )
}
```

The component features responsive design, conditional field rendering (userId and deviceId only show if present), and uses the OpenFrame design system with custom styling. It displays a "No log details available" message when no data is provided and formats the tool type with a visual badge component.
