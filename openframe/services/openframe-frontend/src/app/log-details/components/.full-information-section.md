A React component that displays detailed log information in a structured card format for the OpenFrame MSP platform. The component renders comprehensive log entry details with proper formatting and visual organization.

## Key Components

- **FullInformationSection**: Main component that displays log details in a formatted card
- **LogEntry**: Interface defining the structure of log entry data with fields like toolEventId, eventType, severity, timestamps, and optional user/device information
- **formatTimestamp**: Helper function that converts timestamp strings to ISO format with error handling

## Usage Example

```typescript
import { FullInformationSection } from './full-information-section'

const logEntry = {
  toolEventId: "evt_123456",
  eventType: "ERROR",
  ingestDay: "2024-01-15",
  toolType: "MONITORING",
  severity: "HIGH",
  userId: "user_789",
  deviceId: "device_456",
  timestamp: "2024-01-15T10:30:00Z",
  message: "System alert triggered",
  details: "Additional context information"
}

export function LogDetailsPage() {
  return (
    <div className="p-4">
      <FullInformationSection logDetails={logEntry} />
    </div>
  )
}
```

The component features responsive design with proper spacing, conditional rendering for optional fields, and integration with OpenFrame's design system including ToolBadge components and InfoRow layouts.
