A React component that displays comprehensive log entry details in a structured card format for the OpenFrame platform's monitoring interface.

## Key Components

- **FullInformationSection** - Main component that renders log details in a formatted card
- **LogEntry** - TypeScript interface defining the structure of log data including tool events, severity, and metadata
- **FullInformationSectionProps** - Props interface accepting optional log details
- **formatTimestamp** - Utility function that safely converts timestamps to ISO format

## Usage Example

```typescript
import { FullInformationSection } from './full-information-section'

const logEntry = {
  toolEventId: "evt_123456",
  eventType: "error",
  ingestDay: "2024-01-15",
  toolType: "monitoring",
  severity: "high",
  userId: "user_789",
  deviceId: "device_456",
  message: "System alert triggered",
  timestamp: "2024-01-15T10:30:00Z",
  details: "Memory usage exceeded threshold"
}

function LogDetailsPanel() {
  return (
    <div className="p-4">
      <FullInformationSection logDetails={logEntry} />
    </div>
  )
}
```

The component features responsive design with proper spacing, displays tool types with visual badges, handles missing data gracefully with conditional rendering, and maintains consistent OpenFrame design system styling throughout the interface.
