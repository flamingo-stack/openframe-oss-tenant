A React component that displays detailed log entry information in a structured, card-based layout with proper formatting and conditional rendering for optional fields.

## Key Components

- **FullInformationSection**: Main component that renders log details in an organized information card
- **LogEntry**: TypeScript interface defining the structure of log data with fields like toolEventId, eventType, severity, etc.
- **FullInformationSectionProps**: Props interface accepting optional log details
- **formatTimestamp**: Utility function that converts timestamp strings to ISO format with error handling

## Usage Example

```typescript
import { FullInformationSection } from './full-information-section'

const logEntry = {
  toolEventId: "evt_123456789",
  eventType: "authentication",
  ingestDay: "2024-01-15",
  toolType: "active_directory",
  severity: "warning",
  userId: "user_abc123",
  deviceId: "device_xyz789",
  timestamp: "2024-01-15T10:30:00Z",
  message: "Login attempt detected"
}

function LogDetailsPage() {
  return (
    <div className="p-6">
      <FullInformationSection logDetails={logEntry} />
    </div>
  )
}
```

The component uses OpenFrame's design system components (`InfoRow`, `ToolBadge`) and handles empty states gracefully. It displays core log information like event ID, type, severity, and timestamp, while conditionally showing optional fields like userId and deviceId when available.
