A React component that displays comprehensive log entry details in a structured, card-based format with proper error handling for missing data.

## Key Components

- **FullInformationSection**: Main component that renders log entry details in an organized layout
- **LogEntry**: TypeScript interface defining the structure of log entry data
- **FullInformationSectionProps**: Props interface for the component
- **formatTimestamp**: Utility function that safely converts timestamps to ISO format

## Usage Example

```typescript
import { FullInformationSection } from './full-information-section'

// Example log entry data
const logEntry = {
  toolEventId: "evt_123456789",
  eventType: "error",
  ingestDay: "2024-01-15",
  toolType: "monitoring",
  severity: "high",
  userId: "user_123",
  deviceId: "device_456",
  message: "System error occurred",
  timestamp: "2024-01-15T10:30:00Z",
  details: "Additional error details"
}

// Render the component
function LogDetailsPage() {
  return (
    <div className="container mx-auto p-4">
      <FullInformationSection logDetails={logEntry} />
    </div>
  )
}
```

The component features a responsive design with proper spacing, dividers between rows, and conditional rendering for optional fields like `userId` and `deviceId`. It includes a fallback state for when no log details are available and uses the OpenFrame design system for consistent styling.
