A React component that renders a detailed view page for individual log entries with comprehensive information display and user interaction features.

## Key Components

- **LogDetailsView**: Main component that displays log details in a structured layout
- **getSeverityVariant**: Utility function that maps log severity levels to visual variants
- **Custom header content**: Includes navigation back button, title, and copy functionality
- **Responsive sections**: Log summary card, device information, full information, and details sections

## Usage Example

```typescript
import { LogDetailsView } from './log-details-view'

// Render log details page with required parameters
function LogPage() {
  return (
    <LogDetailsView
      logId="log-12345"
      ingestDay="2024-01-15"
      toolType="syslog"
      eventType="error"
      timestamp="2024-01-15T10:30:00Z"
    />
  )
}

// Use with Next.js dynamic routing
function DynamicLogPage({ params }: { params: { logId: string } }) {
  const searchParams = new URLSearchParams(window.location.search)
  
  return (
    <LogDetailsView
      logId={params.logId}
      ingestDay={searchParams.get('ingestDay') || ''}
      toolType={searchParams.get('toolType') || ''}
      eventType={searchParams.get('eventType') || ''}
      timestamp={searchParams.get('timestamp') || ''}
    />
  )
}
```

The component handles loading states, error scenarios, and provides a comprehensive view with copy-to-clipboard functionality for log details. It automatically redirects to the logs page if required parameters are missing and includes responsive design for mobile and desktop layouts.
