A React client component that displays comprehensive details for a single log entry with navigation, status visualization, and structured information sections.

## Key Components

- **LogDetailsView** - Main component that renders a detailed view of a log entry with back navigation and copy functionality
- **getSeverityVariant** - Helper function that maps log severity levels to appropriate visual variants
- **Custom header** - Includes back navigation button, page title, and copy log details action
- **Status and timestamp display** - Shows log severity as a status tag with formatted timestamp
- **Log summary card** - Displays the main log message with tool badge and event type
- **Conditional sections** - Device information, full information, and details sections based on available data

## Usage Example

```typescript
// Used in a log details page route
import { LogDetailsView } from './log-details-view'

export default function LogDetailsPage({ 
  params 
}: { 
  params: { 
    logId: string
    ingestDay: string 
    toolType: string
    eventType: string
    timestamp: string
  } 
}) {
  return (
    <LogDetailsView
      logId={params.logId}
      ingestDay={params.ingestDay}
      toolType={params.toolType}
      eventType={params.eventType}
      timestamp={params.timestamp}
    />
  )
}

// The component handles loading states, error handling, and automatic redirects
// if required parameters are missing. It fetches log details on mount and 
// provides clipboard functionality for sharing log information.
```

The component provides a comprehensive interface for viewing log details with responsive design, proper error handling, and intuitive navigation back to the logs list.
