A React component that displays detailed information for a specific log entry, providing a comprehensive view with navigation, copy functionality, and organized data sections.

## Key Components

- **LogDetailsView**: Main component that fetches and displays log details with routing parameters
- **getSeverityVariant**: Helper function mapping log severity levels to UI status variants
- **Custom Header**: Navigation back to logs list with copy functionality
- **Status Display**: Shows severity badge and timestamp
- **Log Summary Card**: Displays main message, tool badge, and event type
- **Device Info Section**: Shows associated device information when available
- **Data Sections**: Full information and details sections for comprehensive log data

## Usage Example

```typescript
// Route-based usage
<LogDetailsView 
  logId="log-123"
  ingestDay="2024-01-15"
  toolType="monitoring"
  eventType="error"
  timestamp="2024-01-15T10:30:00Z"
/>

// Severity mapping example
const variant = getSeverityVariant("ERROR") // returns 'error'
const defaultVariant = getSeverityVariant("UNKNOWN") // returns 'info'
```

The component handles loading states, error scenarios, and automatic redirection when required parameters are missing. It uses the `useLogDetails` hook for data fetching and provides a responsive layout that adapts between mobile and desktop views.
