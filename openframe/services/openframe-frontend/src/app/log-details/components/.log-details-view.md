A comprehensive view component for displaying detailed log information with device context, status indicators, and action buttons for log management.

## Key Components

- **LogDetailsView**: Main component that renders the complete log details interface
- **getSeverityVariant**: Helper function that maps log severity levels to appropriate visual variants
- **useLogDetails**: Custom hook for fetching and managing log detail state
- **DeviceInfoSection**: Displays associated device information when available
- **FullInformationSection**: Renders complete log metadata and properties
- **DetailsSection**: Shows detailed log content and additional information

## Usage Example

```typescript
import { LogDetailsView } from './log-details-view'

// Render log details page
function LogPage() {
  return (
    <LogDetailsView
      logId="evt_12345"
      ingestDay="2024-01-15"
      toolType="microsoft365"
      eventType="sign-in"
      timestamp="2024-01-15T10:30:00Z"
    />
  )
}

// Example with URL parameters from Next.js
function LogDetailsPage({ params }: { params: { id: string } }) {
  const searchParams = useSearchParams()
  
  return (
    <LogDetailsView
      logId={params.id}
      ingestDay={searchParams.get('ingestDay') || ''}
      toolType={searchParams.get('toolType') || ''}
      eventType={searchParams.get('eventType') || ''}
      timestamp={searchParams.get('timestamp') || ''}
    />
  )
}
```

The component provides comprehensive log viewing capabilities including copying log details to clipboard, navigation back to the logs list, and responsive design that adapts to different screen sizes.
