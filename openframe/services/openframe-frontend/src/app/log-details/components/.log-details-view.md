A React component that provides a detailed view for individual log entries, displaying comprehensive log information with device context and copy functionality.

## Key Components

- **LogDetailsView** - Main component that renders log details with back navigation, copy functionality, and organized sections
- **getSeverityVariant** - Helper function that maps log severity levels to appropriate status tag variants
- **Custom Header** - Responsive header with back navigation and copy action button
- **Status Display** - Shows severity badge and formatted timestamp
- **Log Summary Card** - Displays log message with tool badge and event type
- **Device Information** - Shows related device details when available
- **Full Information & Details Sections** - Expandable sections for complete log data

## Usage Example

```typescript
import { LogDetailsView } from './log-details-view'

// In a Next.js page or component
function LogDetailPage({ params }: { params: { id: string } }) {
  const searchParams = useSearchParams()
  
  return (
    <LogDetailsView
      logId={params.id}
      ingestDay={searchParams.get('ingestDay') || ''}
      toolType={searchParams.get('toolType') || ''}
      eventType={searchParams.get('eventType') || ''}
      timestamp={searchParams.get('timestamp') || ''}
    />
  )
}

// Error handling and loading states are built-in
// Automatically redirects to /logs-page if required params are missing
```

The component includes built-in error handling, loading states, and responsive design. It automatically fetches log details using the provided parameters and handles navigation back to the logs listing page.
