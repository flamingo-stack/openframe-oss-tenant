A detailed view component for displaying comprehensive log information with device context and interactive features.

## Key Components

### LogDetailsView
Main component that renders a detailed view of a specific log entry with:
- **Props**: `logId`, `ingestDay`, `toolType`, `eventType`, `timestamp` for log identification
- **Features**: Back navigation, copy functionality, responsive layout, error handling
- **Sections**: Status display, log summary, device information, and detailed breakdown

### getSeverityVariant
Utility function that maps log severity levels to appropriate visual variants:
- Maps severity strings to standardized status variants (`success`, `warning`, `error`, `info`, `critical`)
- Handles case-insensitive severity matching with fallback to `info`

## Usage Example

```typescript
import { LogDetailsView } from './log-details-view'

function LogPage() {
  return (
    <LogDetailsView
      logId="log_123456"
      ingestDay="2024-01-15"
      toolType="monitoring"
      eventType="alert"
      timestamp="2024-01-15T10:30:00Z"
    />
  )
}

// Custom severity mapping
const variant = getSeverityVariant("ERROR") // returns 'error'
const defaultVariant = getSeverityVariant("UNKNOWN") // returns 'info'
```

The component automatically fetches log details on mount, displays loading/error states, and provides a responsive interface with copy-to-clipboard functionality and breadcrumb navigation back to the logs listing page.
