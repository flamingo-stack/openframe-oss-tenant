A React component that displays detailed information about a specific log entry, providing a comprehensive view with device information, status indicators, and actionable controls.

## Key Components

- **LogDetailsView**: Main component rendering log details with navigation, status indicators, and copy functionality
- **getSeverityVariant**: Utility function mapping severity levels to visual variants (error, warning, info, critical)
- **Custom header**: Includes back navigation and copy action button
- **Log summary card**: Displays message, tool badge, and event type information
- **Conditional sections**: Device info, full information, and details sections based on available data

## Usage Example

```typescript
import { LogDetailsView } from './log-details-view'

// Used in log detail pages with URL parameters
function LogDetailPage({ params }: { params: { logId: string, ingestDay: string, toolType: string, eventType: string, timestamp: string } }) {
  return (
    <LogDetailsView
      logId={params.logId}
      ingestDay={params.ingestDay}
      toolType={params.toolType}
      eventType={params.eventType}
      timestamp={params.timestamp}
    />
  )
}

// Handles loading states, error states, and navigation
// Automatically fetches log details on component mount
// Provides clipboard functionality for log information
```

The component handles loading and error states, automatically fetches log data using the provided parameters, and redirects to the logs page if parameters are missing. It includes responsive design with mobile-optimized layouts and provides copy-to-clipboard functionality for sharing log details.
