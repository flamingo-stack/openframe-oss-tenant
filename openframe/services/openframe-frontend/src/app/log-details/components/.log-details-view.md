A React component for displaying detailed log information in a structured layout with navigation, copy functionality, and error handling.

## Key Components

- **LogDetailsView**: Main component that renders log details with back navigation and copy functionality
- **getSeverityVariant**: Utility function that maps log severity levels to appropriate UI variants
- **Custom header content**: Responsive header with back button and copy action
- **Status and metadata display**: Shows severity tags, timestamps, and tool information
- **Conditional sections**: Device info, full information, and details sections based on available data

## Usage Example

```typescript
import { LogDetailsView } from './log-details-view'

// Render log details page
function LogPage() {
  return (
    <LogDetailsView
      logId="log-123"
      ingestDay="2024-01-15"
      toolType="windows-defender"
      eventType="threat-detection"
      timestamp="2024-01-15T10:30:00Z"
    />
  )
}

// The component will:
// - Fetch log details using the provided parameters
// - Display loading state while fetching
// - Show error state if log is not found
// - Render structured log information with copy functionality
// - Provide navigation back to logs listing
```

The component handles loading states, error conditions, and provides a responsive layout that adapts to different screen sizes. It integrates with the OpenFrame design system and includes accessibility features like proper heading hierarchy and keyboard navigation.
