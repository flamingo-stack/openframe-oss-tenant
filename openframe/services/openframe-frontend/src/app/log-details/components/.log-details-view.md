A React component that displays detailed information about a specific log entry in the OpenFrame platform, including metadata, device information, and full log details with copy functionality.

## Key Components

- **LogDetailsView**: Main component that renders a comprehensive view of log details with navigation and action buttons
- **getSeverityVariant**: Helper function that maps log severity levels to appropriate UI variant types
- **Custom header content**: Includes back navigation, page title, and copy action button
- **Log summary card**: Displays key log information with tool badge and event type
- **Conditional sections**: Device info, full information, and details sections based on available data

## Usage Example

```typescript
import { LogDetailsView } from './log-details-view'

// Use in a page component with URL parameters
function LogDetailsPage({ params }: { params: { logId: string } }) {
  const searchParams = useSearchParams()
  
  return (
    <LogDetailsView
      logId={params.logId}
      ingestDay={searchParams.get('ingestDay') || ''}
      toolType={searchParams.get('toolType') || ''}
      eventType={searchParams.get('eventType') || ''}
      timestamp={searchParams.get('timestamp') || ''}
    />
  )
}
```

The component automatically fetches log details on mount, handles loading and error states, and provides a responsive layout with mobile-optimized navigation. It includes clipboard functionality to copy formatted log information and integrates with the OpenFrame design system components.
