Provides the `ChatRuntime` context required by `<EmbeddableChat>`, wiring Guide-mode SSE endpoints, auth token handling, and in-app navigation for the OpenFrame frontend.

## Key Components

| Export / Symbol | Description |
|---|---|
| `OpenframeChatRuntimeProvider` | React provider component that builds and supplies the `ChatRuntime` context to all child chat components |
| `CHAT_AUTH_ADAPTER` | Module-scoped `EmbedAuthAdapter` singleton that attaches Bearer tokens (dev-ticket mode only) and delegates cookie-based auth + token refresh for production |
| `CHAT_SOURCE` | Stable namespace string (`'openframe'`) used for localStorage history keying — must not change between deployments |
| `ACCESS_TOKEN_KEY` | localStorage key (`'of_access_token'`) shared with `api-client.ts` for bearer token consistency |
| `safeReadToken` | Sandboxed localStorage read that silently returns `null` on iframe/access errors |

## Usage Example

```typescript
// app/layout.tsx or a shell wrapper
import { OpenframeChatRuntimeProvider } from '@/providers/openframe-chat-runtime-provider';
import { EmbeddableChat } from '@flamingo-stack/openframe-frontend-core';

export default function Layout({ children }: { children: React.ReactNode }) {
  return (
    <OpenframeChatRuntimeProvider>
      <EmbeddableChat />
      {children}
    </OpenframeChatRuntimeProvider>
  );
}
```

## Behavioural Notes

- **Auth strategy**: In production, auth relies on `credentials: 'include'` (http-only cookies). The localStorage Bearer is only attached when `enableDevTicketObserver()` is true, preventing stale token leakage.
- **Adapter registration**: `setEmbedAuthAdapter` and `clearEmbedProxyAuth` run at **module load** (not in `useEffect`) to guarantee the adapter is present before child mount effects fire their first requests.
- **Guide endpoints**: All `/guide/*` paths resolve against `NEXT_PUBLIC_TENANT_HOST_URL`; the gateway reverse-proxies them to MPH, keeping the upstream URL opaque to the browser.
- **Navigation**: Uses `mode: 'host'` with `router.push` so in-app chip clicks preserve SPA state instead of triggering full-page navigations.
