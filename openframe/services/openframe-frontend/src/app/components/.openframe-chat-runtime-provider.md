Provides the `ChatRuntime` context required by `<EmbeddableChat>`, wiring Guide-mode (SSE/MPH) endpoints, authentication, and in-app navigation for the OpenFrame frontend's embedded chat panel.

## Key Components

- **`CHAT_AUTH_ADAPTER`** — Module-scope `EmbedAuthAdapter` singleton that attaches Bearer tokens (dev-ticket mode only) and `credentials: 'include'` to every embedded-chat request, with 401-triggered token refresh via `refreshAccessToken`.
- **`OpenframeChatRuntimeProvider`** — React provider component that constructs a `ChatRuntime` object with Guide-mode endpoint URLs, Next.js App Router navigation, and a stable `source` identifier, then exposes it via `ChatRuntimeContext`.
- **`safeReadToken()`** — Sandboxed `localStorage` reader that suppresses errors in restricted iframe contexts.
- **Module-level side effects** — `clearEmbedProxyAuth()` and `setEmbedAuthAdapter()` run once at load time (before any child mount effects) to avoid race conditions with the chat's identity/slash-command requests.

## Usage Example

```typescript
// app/layout.tsx or a panel wrapper
import { OpenframeChatRuntimeProvider } from '@/components/openframe-chat-runtime-provider';
import { EmbeddableChat } from '@flamingo-stack/openframe-frontend-core';

export default function Layout({ children }: { children: React.ReactNode }) {
  return (
    <OpenframeChatRuntimeProvider>
      <EmbeddableChat />
      {children}
    </OpenframeChatRuntimeProvider>
  );
}
```

> **Note:** The provider covers Guide mode only. Mingo mode calls `apiClient` against `/chat/*` directly and does not use this runtime. All Guide endpoints are proxied through `NEXT_PUBLIC_TENANT_HOST_URL/guide/*` so the upstream MPH origin is never exposed to the client.
