A full-page loading skeleton that mirrors the exact structure and dimensions of the `AppShell` layout, used as a Suspense fallback and during session/initialization loading states.

## Key Components

| Component | Description |
|---|---|
| `AppShellSkeleton` | **Exported.** Root skeleton matching the full app layout: sidebar (224px), header (56px), and content area (`p-6 pt-0`) |
| `OnboardingSkeleton` | Skeleton for the onboarding walkthrough section — header row + 5 step cards |
| `OnboardingStepCardSkeleton` | Individual onboarding step row with title, description, and two action buttons |
| `DevicesSkeleton` | Devices overview section — title, subtitle, and a 2-card responsive grid |
| `TicketsSkeleton` | Tickets overview section — title, subtitle, and a 4-card responsive grid |
| `CustomersSkeleton` | Organizations overview section — title, subtitle, and 3 rows of `[OrgCard, InfoCard, InfoCard]` |
| `CustomerCardSkeleton` | Single organization card with name, details, and device count badge |
| `InfoCardSkeleton` | Stat card with title, value, percentage, and circular progress indicator |

## Usage Example

```typescript
import { AppShellSkeleton } from './app-shell-skeleton';

// As a Next.js Suspense fallback in root layout
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html>
      <body>
        <Suspense fallback={<AppShellSkeleton />}>
          {children}
        </Suspense>
      </body>
    </html>
  );
}

// During session/initialization check
if (status === 'checking' || status === 'initializing') {
  return <AppShellSkeleton />;
}
```

> **Layout accuracy note:** Each sub-skeleton is intentionally sized to match its real counterpart exactly — `w-56`/`h-14` for the sidebar/header, `rounded-[6px]` for cards, `h-14` for buttons — preventing layout shift when content loads.
