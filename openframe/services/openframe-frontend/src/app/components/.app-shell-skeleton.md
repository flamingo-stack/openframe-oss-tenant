A full-page loading skeleton that mirrors the exact layout and dimensions of the application shell, used as a Suspense fallback and session-checking placeholder across root-level loading states.

## Key Components

| Component | Description |
|-----------|-------------|
| `AppShellSkeleton` | **Primary export.** Renders the full app shell skeleton including sidebar, header, and dashboard content area |
| `InfoCardSkeleton` | Matches `DashboardInfoCard` — card with title, value/percentage row, and circular progress placeholder |
| `OnboardingStepCardSkeleton` | Matches `OnboardingStepCard` — row with title, description, and two action button placeholders |
| `OnboardingSkeleton` | Matches `OnboardingWalkthrough` — header row + 5 stacked `OnboardingStepCardSkeleton` items |
| `DevicesSkeleton` | Matches `DevicesOverviewSection` — title, subtitle, 2-column `InfoCardSkeleton` grid |
| `TicketsSkeleton` | Matches `TicketsOverviewSection` — title, subtitle, 4-column `InfoCardSkeleton` grid |
| `CustomerCardSkeleton` | Matches `OrganizationCard` — card with name, details, and device count badge placeholders |
| `CustomersSkeleton` | Matches `CustomersOverviewSection` — title, subtitle, 3-row grid of `CustomerCardSkeleton` + `InfoCardSkeleton` |

## Usage Example

```typescript
import { AppShellSkeleton } from './app-shell-skeleton';

// Root layout Suspense fallback
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>
        <Suspense fallback={<AppShellSkeleton />}>
          {children}
        </Suspense>
      </body>
    </html>
  );
}
```

## Use Cases

- Root layout `<Suspense>` fallback
- Session validation / "Checking session" loading state
- App initialization / "Initializing" loading state
- Root page redirect loading state

> **Layout fidelity:** Skeleton dimensions are hard-coded to match the live shell exactly — sidebar `w-56` (224px), header `h-14` (56px), content `p-6 pt-0` — preventing layout shift on hydration.
