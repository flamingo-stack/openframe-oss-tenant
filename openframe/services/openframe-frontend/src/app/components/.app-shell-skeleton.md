Skeleton loading UI that replicates the full AppShell layout — including sidebar, header, and dashboard content sections — for use during session checks, initialization states, and Suspense fallbacks.

## Key Components

| Component | Description |
|-----------|-------------|
| `AppShellSkeleton` | **Primary export.** Full-page skeleton matching the AppShell structure: `w-56` sidebar, `h-14` header, and `p-6 pt-0` content area |
| `OnboardingSkeleton` | Matches `OnboardingWalkthrough` — header row + 5 `OnboardingStepCardSkeleton` items |
| `OnboardingStepCardSkeleton` | Matches `OnboardingStepCard` — responsive row with title, description, and two action buttons |
| `DevicesSkeleton` | Matches `DevicesOverviewSection` — title, subtitle, and a 2-card `InfoCardSkeleton` grid |
| `TicketsSkeleton` | Matches `TicketsOverviewSection` — title, subtitle, and a 4-card `InfoCardSkeleton` grid |
| `CustomersSkeleton` | Matches `CustomersOverviewSection` — title, subtitle, and 3 rows of `[CustomerCardSkeleton, InfoCardSkeleton, InfoCardSkeleton]` |
| `InfoCardSkeleton` | Matches `DashboardInfoCard` — label, value/percentage row, and circular progress indicator |
| `CustomerCardSkeleton` | Matches `OrganizationCard` — org name, details, and device count badge |

## Usage Example

```typescript
import { AppShellSkeleton } from './app-shell-skeleton';

// Root layout Suspense fallback
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>
        <Suspense fallback={<AppShellSkeleton />}>
          {children}
        </Suspense>
      </body>
    </html>
  );
}

// Session/initialization loading state
if (status === 'checking' || status === 'initializing') {
  return <AppShellSkeleton />;
}
```

> All skeleton sub-components are intentionally **non-exported** — only `AppShellSkeleton` is the public API. Each sub-component mirrors its real counterpart's exact dimensions and layout tokens (ODS card, border, and background classes) to prevent layout shift on hydration.
