A reusable confirmation dialog component built on `SimpleModal`, designed for destructive and reversible action prompts with support for pending states and multiple visual variants.

## Key Components

### `ConfirmDialog`
The primary export — a controlled modal dialog that wraps `SimpleModal` with confirm/cancel footer buttons and three visual variants.

### `ConfirmDialogProps`
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `open` | `boolean` | — | Controls dialog visibility (parent-owned) |
| `onOpenChange` | `(open: boolean) => void` | — | Called when dialog requests close |
| `title` | `string` | — | Dialog header text |
| `description` | `ReactNode` | — | Body content |
| `variant` | `'destructive' \| 'warning' \| 'default'` | `'destructive'` | Confirm button color scheme |
| `isPending` | `boolean` | `false` | Shows spinner and disables both buttons |
| `pendingLabel` | `string` | — | Confirm button label during pending state |
| `extraContent` | `ReactNode` | — | Optional slot between description and footer |
| `onConfirm` | `() => void \| Promise<void>` | — | Called when confirm button is clicked |

## Usage Example

```typescript
import { ConfirmDialog } from './confirm-dialog';

function DeleteUserButton({ userId }: { userId: string }) {
  const [open, setOpen] = useState(false);
  const [isPending, setIsPending] = useState(false);

  const handleConfirm = async () => {
    setIsPending(true);
    await deleteUser(userId);
    setIsPending(false);
    setOpen(false);
  };

  return (
    <>
      <button onClick={() => setOpen(true)}>Delete User</button>
      <ConfirmDialog
        open={open}
        onOpenChange={setOpen}
        title="Delete User"
        description="This action cannot be undone."
        variant="destructive"
        confirmLabel="Delete"
        pendingLabel="Deleting..."
        isPending={isPending}
        onConfirm={handleConfirm}
      />
    </>
  );
}
```

> **Note:** The dialog does **not** auto-close on confirm. The parent is responsible for setting `open` to `false` after the async operation settles, allowing the pending spinner to remain visible throughout the mutation.
