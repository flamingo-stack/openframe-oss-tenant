A reusable confirmation dialog component built on `SimpleModal`, designed for destructive and reversible actions with support for async pending states and three button color variants.

## Key Components

### `ConfirmDialog`
The sole export — a controlled modal component that delegates layout to `SimpleModal` and adds confirmation-specific behavior:

- **`variant`** — Controls confirm button color: `'destructive'` (red), `'warning'` (yellow), or `'default'` (accent). Defaults to `'destructive'`.
- **`isPending`** — Disables both buttons and shows a spinner on the confirm button while an async action is in flight.
- **`pendingLabel`** — Optional label swap on the confirm button during pending state (e.g. `"Deleting…"`).
- **`extraContent`** — Optional `ReactNode` slot rendered between the description and the footer (e.g. a command input or secondary CTA).
- **`onOpenChange`** — Parent owns open state; the dialog never auto-closes, allowing pending state to remain visible until the mutation settles.

## Usage Example

```typescript
import { ConfirmDialog } from './confirm-dialog';

function DeleteUserButton({ userId }: { userId: string }) {
  const [open, setOpen] = useState(false);
  const [isPending, setIsPending] = useState(false);

  const handleConfirm = async () => {
    setIsPending(true);
    await deleteUser(userId);
    setIsPending(false);
    setOpen(false);
  };

  return (
    <>
      <button onClick={() => setOpen(true)}>Delete User</button>
      <ConfirmDialog
        open={open}
        onOpenChange={setOpen}
        title="Delete User"
        description="This action cannot be undone. The user will be permanently removed."
        confirmLabel="Delete"
        pendingLabel="Deleting…"
        variant="destructive"
        isPending={isPending}
        onConfirm={handleConfirm}
      />
    </>
  );
}
```
