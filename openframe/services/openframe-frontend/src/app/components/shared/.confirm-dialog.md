A reusable confirmation dialog component built on top of `SimpleModal`, designed for destructive and reversible action confirmations with loading state support.

## Key Components

**`ConfirmDialog`** — Main exported component accepting these notable props:

| Prop | Type | Description |
|------|------|-------------|
| `open` / `onOpenChange` | `boolean` / `fn` | Parent-controlled open state |
| `variant` | `'destructive' \| 'warning' \| 'default'` | Confirm button color (red / yellow / accent) |
| `isPending` | `boolean` | Shows spinner and disables buttons during async ops |
| `pendingLabel` | `string` | Confirm button label override while pending |
| `onConfirm` | `() => void \| Promise<void>` | Confirm handler — dialog does **not** auto-close |
| `extraContent` | `ReactNode` | Optional slot between description and footer |

**Style constants:**
- `CANCEL_BUTTON` — neutral card-styled cancel button
- `CONFIRM_BUTTON_BASE` — shared confirm button base styles
- `CONFIRM_BUTTON_VARIANT` — variant-to-class map for destructive/warning/default

## Usage Example

```typescript
import { ConfirmDialog } from './confirm-dialog';

function DeleteUserButton({ userId }: { userId: string }) {
  const [open, setOpen] = useState(false);
  const [isPending, setIsPending] = useState(false);

  const handleConfirm = async () => {
    setIsPending(true);
    await deleteUser(userId);
    setIsPending(false);
    setOpen(false);
  };

  return (
    <>
      <button onClick={() => setOpen(true)}>Delete User</button>
      <ConfirmDialog
        open={open}
        onOpenChange={setOpen}
        title="Delete User"
        description="This action cannot be undone."
        variant="destructive"
        confirmLabel="Delete"
        isPending={isPending}
        pendingLabel="Deleting..."
        onConfirm={handleConfirm}
      />
    </>
  );
}
```

> **Note:** The dialog intentionally does not auto-close on confirm — the parent controls dismissal after the async operation settles, keeping the pending spinner visible throughout.
