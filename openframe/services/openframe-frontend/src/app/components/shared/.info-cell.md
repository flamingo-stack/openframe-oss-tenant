Reusable display cell that renders a primary value alongside a secondary label, optionally with a leading icon or an external link wrapper. Designed for detail/info card layouts using ODS typography tokens (`h4` for value, `h6` for label).

## Key Components

### `InfoCellProps`

| Prop | Type | Description |
|------|------|-------------|
| `value` | `React.ReactNode` | Primary content (string, element, or mixed JSX) |
| `label` | `string` | Secondary descriptive label rendered below the value |
| `icon` | `React.ReactNode` | Optional leading icon displayed inline with the value |
| `href` | `string` | When provided, wraps the entire cell in an external `<a>` tag |
| `className` | `string` | Additional CSS classes applied to the root container |

### `InfoCell`

Functional component that renders a stacked `value` / `label` pair. String values automatically receive a `title` attribute for truncation tooltips. When `href` is set, the cell becomes a block-level external link with a hover opacity transition.

## Usage Example

```typescript
// Basic hostname display
<InfoCell value="workstation-23.acme.local" label="Hostname" />

// With an icon
<InfoCell value="Laptop" label="Device Type" icon={<LaptopIcon />} />

// Mixed JSX value
<InfoCell
  value={<>{date} <span className="text-ods-text-secondary">{time}</span></>}
  label="Last Updated"
/>

// Clickable external link cell
<InfoCell
  value="example.com"
  label="Website"
  href="https://example.com"
/>
```
