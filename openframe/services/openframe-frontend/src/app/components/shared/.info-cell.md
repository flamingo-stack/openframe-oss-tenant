Reusable display cell that renders a primary value with a secondary label, used in detail and info card layouts. Supports optional icons and external link wrapping.

## Key Components

### `InfoCellProps`

| Prop | Type | Description |
|------|------|-------------|
| `value` | `React.ReactNode` | Primary display value (string or JSX) |
| `label` | `string` | Secondary descriptive label below the value |
| `icon` | `React.ReactNode` | Optional icon rendered before the value |
| `href` | `string` | When set, wraps the entire cell in an external `<a>` tag |
| `className` | `string` | Optional additional CSS classes |

### `InfoCell`

Functional component that renders value/label stacked vertically using ODS typography tokens (`text-h4` for value, `text-h6` for label). Long values are truncated with a native `title` tooltip when the value is a plain string.

## Usage Example

```typescript
// Basic usage
<InfoCell value="workstation-23.acme.local" label="Hostname" />

// With an icon
<InfoCell value="Laptop" label="Device Type" icon={<LaptopIcon />} />

// With mixed JSX value
<InfoCell
  value={<>{date} <span className="text-ods-text-secondary">{time}</span></>}
  label="Last Updated"
/>

// As an external link
<InfoCell
  value="example.com"
  label="Website"
  href="https://example.com"
/>
```

> When `href` is provided, the cell renders as an `<a>` tag with `target="_blank"` and `rel="noreferrer"`, and applies a hover opacity transition.
