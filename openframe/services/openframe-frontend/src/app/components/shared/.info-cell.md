Reusable display cell that renders a primary value with a secondary descriptive label, designed for detail/info card layouts using ODS typography tokens (`h4`/`h6`).

## Key Components

### `InfoCellProps`

| Prop | Type | Description |
|------|------|-------------|
| `value` | `React.ReactNode` | Primary content displayed prominently |
| `label` | `string` | Secondary descriptive label below the value |
| `icon` | `React.ReactNode` | Optional icon rendered inline before the value |
| `href` | `string` | Optional URL — wraps the entire cell in an external link |
| `className` | `string` | Optional additional CSS classes on the root element |

### `InfoCell`

Renders a flex column with a truncated primary value (`text-h4`) and a truncated secondary label (`text-h6`). When `href` is provided, the cell becomes an accessible external anchor tag with `target="_blank"`.

## Usage Example

```typescript
// Basic hostname display
<InfoCell value="workstation-23.acme.local" label="Hostname" />

// With an icon
<InfoCell
  value="Laptop"
  label="Device Type"
  icon={<LaptopIcon />}
/>

// With mixed JSX value
<InfoCell
  value={<>{date} <span className="text-muted">{time}</span></>}
  label="Last Updated"
/>

// As an external link
<InfoCell
  value="example.com"
  label="Website"
  href="https://example.com"
/>
```

> **Note:** When `value` is a plain `string`, it is passed as the native `title` tooltip attribute to expose truncated text on hover.
