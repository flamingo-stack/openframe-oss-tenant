Renders a loading skeleton placeholder that mirrors the layout of the `DeviceInfoSection` component's inline `DeviceCard`, providing a visual loading state while device data is being fetched.

## Key Components

- **`DeviceInfoSectionSkeleton`** — Default exported functional component that renders shimmer placeholders matching the two-row `DeviceCard` structure

## Layout Structure

The skeleton replicates the `DeviceCard` layout:

- **Row 1:** 32×32 icon box · OS icon + device name · organization name · "Details" button placeholder
- **Row 2:** Status tag badge · "Last Seen" text placeholder

## Usage Example

```typescript
import { DeviceInfoSectionSkeleton } from './device-info-section-skeleton';

// Use as a Suspense fallback or conditional loading state
function DevicePanel({ deviceId }: { deviceId: string }) {
  const { data, isLoading } = useDevice(deviceId);

  if (isLoading) return <DeviceInfoSectionSkeleton />;
  return <DeviceInfoSection device={data} />;
}
```

> **Note:** The skeleton is a `'use client'` component and depends on `Skeleton` from `@flamingo-stack/openframe-frontend-core`. Its dimensions (`min-h-[130px]`, `w-[88px]` button, `w-40` name) are tuned to prevent layout shift when the real `DeviceInfoSection` mounts.
