Renders a loading skeleton placeholder that mirrors the layout of `DeviceInfoSection`'s inline `DeviceCard`, providing visual continuity while device data is being fetched.

## Key Components

- **`DeviceInfoSectionSkeleton`** — Client component that outputs a two-row skeleton card matching the exact dimensions and layout of the live `DeviceCard`:
  - **Row 1:** Icon box placeholder, OS icon + device name + org name placeholders, Details button placeholder
  - **Row 2:** Status tag placeholder + "Last Seen" text placeholder

## Usage Example

```typescript
import { DeviceInfoSectionSkeleton } from './device-info-section-skeleton';

// Use as a Suspense fallback while device data loads
export default function DevicePanel() {
  return (
    <Suspense fallback={<DeviceInfoSectionSkeleton />}>
      <DeviceInfoSection deviceId={deviceId} />
    </Suspense>
  );
}
```

## Notes

- Marked as `'use client'` — renders on the client side only.
- Skeleton dimensions are intentionally matched to the live card (`min-h-[130px]`, `w-40` for name, `w-[88px]` for button) to prevent layout shift (CLS) during data loading.
- Uses `Skeleton` from `@flamingo-stack/openframe-frontend-core` for consistent shimmer styling across the platform.
