Renders a loading skeleton placeholder that mirrors the layout of `DeviceInfoSection`'s inline `DeviceCard`, used to prevent layout shift while device data is loading.

## Key Components

**`DeviceInfoSectionSkeleton`** — Client component that replicates the two-row structure of the device card:

- **Row 1:** Icon box, OS icon + device name + org name, and a "Details" button placeholder
- **Row 2:** Status tag and "Last Seen" text placeholders

## Usage Example

```typescript
import { DeviceInfoSectionSkeleton } from './device-info-section-skeleton';

// Typically used as a Suspense fallback or conditional loading state
function DevicePanel({ isLoading }: { isLoading: boolean }) {
  if (isLoading) return <DeviceInfoSectionSkeleton />;
  return <DeviceInfoSection />;
}

// Or as a Suspense boundary fallback
<Suspense fallback={<DeviceInfoSectionSkeleton />}>
  <DeviceInfoSection deviceId={deviceId} />
</Suspense>
```

## Layout Structure

```text
┌─────────────────────────────────────────┐
│ [icon] [OS icon] [Device Name]  [Button]│  ← Row 1
│        [Org]                            │
├─────────────────────────────────────────┤
│ [Status Tag] [Last Seen: ...]           │  ← Row 2
└─────────────────────────────────────────┘
```

Sized to `min-h-[130px]` to match the real card's minimum height, preventing content reflow on data load.
