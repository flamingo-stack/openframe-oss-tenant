A pure presentational toolbar component combining a tag-aware search input, a responsive "Device Tags" filter button, and a `FilterModal`. All state is externally owned by the parent.

## Key Components

- **`DevicesFilterToolbar`** — Main exported component rendering the search/filter row and modal
- **`DevicesFilterToolbarProps`** — Interface defining all required and optional props
- **`TagSearchInput`** — Search input with chip-style selected tag display
- **`FilterModal`** — Modal for browsing and selecting device tag filters
- **`sticky`** prop — Controls whether the toolbar bleeds over `PageLayout` padding using negative margins (default: `true`)

## Usage Example

```typescript
<DevicesFilterToolbar
  searchValue={search}
  onSearchChange={setSearch}
  tags={selectedTagChips}
  onTagRemove={handleTagRemove}
  onClearAll={handleClearAll}
  onSubmit={handleSubmit}
  isMdUp={isMdUp}
  onOpenFilterModal={() => setFilterModalOpen(true)}
  isFilterModalOpen={isFilterModalOpen}
  onCloseFilterModal={() => setFilterModalOpen(false)}
  filterGroups={filterGroups}
  onFilterChange={handleFilterChange}
  currentFilters={currentFilters}
  tagFilterKeys={tagFilterKeys}
  selectedTags={selectedTags}
  onTagsChange={handleTagsChange}
  sticky={true}
/>
```

## Notes

- **Responsive behavior** — At `md+` breakpoints (`isMdUp: true`), the filter button renders with a "Device Tags" label; below `md`, it renders as an icon-only button.
- **Sticky mode** — When `sticky={true}`, applies negative-margin bleed so the toolbar background covers `PageLayout` padding. Set `sticky={false}` when mounting inside a modal or contained layout.
- **Stateless** — No internal state; intended for reuse across `DevicesPanel` and `DeviceSelector`.
