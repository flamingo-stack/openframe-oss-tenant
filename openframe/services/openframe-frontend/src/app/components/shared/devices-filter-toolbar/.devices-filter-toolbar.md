Purely presentational toolbar component combining a tag-aware search input, a responsive "Device Tags" filter button, and a `FilterModal`. All state is owned by the parent — this component only renders and proxies callbacks.

## Key Components

- **`DevicesFilterToolbar`** — Default export; renders the search row and filter modal as a fragment
- **`DevicesFilterToolbarProps`** — Full interface defining all controlled props passed down from the parent
- **`TagSearchInput`** — Displays the current search value with removable tag chips
- **`FilterModal`** — Full filter panel; props are proxied directly from the parent without local state
- **`sticky` prop** — When `true` (default), applies negative-margin bleed and `position: sticky` so the toolbar covers `PageLayout` padding; set to `false` inside modals or constrained containers

## Usage Example

```typescript
import { DevicesFilterToolbar } from './devices-filter-toolbar';

function DevicesPanel() {
  const [search, setSearch] = useState('');
  const [isFilterOpen, setFilterOpen] = useState(false);

  return (
    <DevicesFilterToolbar
      searchValue={search}
      onSearchChange={setSearch}
      tags={[]}
      onTagRemove={() => {}}
      onClearAll={() => setSearch('')}
      onSubmit={setSearch}
      isMdUp={true}
      onOpenFilterModal={() => setFilterOpen(true)}
      isFilterModalOpen={isFilterOpen}
      onCloseFilterModal={() => setFilterOpen(false)}
      filterGroups={[]}
      onFilterChange={() => {}}
      tagFilterKeys={[]}
      selectedTags={[]}
      onTagsChange={() => {}}
      sticky={true}
    />
  );
}
```

> **Responsive behavior:** At `md+` breakpoints, the filter button renders with a "Device Tags" label; below `md`, it collapses to an icon-only button using the same `Filter02Icon`.
