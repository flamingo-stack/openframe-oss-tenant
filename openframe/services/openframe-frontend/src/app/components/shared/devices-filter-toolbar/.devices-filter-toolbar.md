A pure presentational toolbar component combining a tag-aware search input, a responsive "Device Tags" filter button, and a `FilterModal`. All state is owned by the parent — this component only renders UI and proxies events.

## Key Components

- **`DevicesFilterToolbar`** — Main export; renders the search/filter row and the `FilterModal` together as a single unit
- **`DevicesFilterToolbarProps`** — Interface defining all props, split into three logical groups: search, filter button, and modal state
- **`sticky` prop** — Controls whether the toolbar bleeds into `PageLayout` padding and pins to the top (default `true`); set to `false` when mounting inside a modal or container
- **`isMdUp` prop** — Drives responsive rendering: labeled button on `md+` viewports, icon-only button on smaller screens

## Usage Example

```typescript
import { DevicesFilterToolbar } from './devices-filter-toolbar';

function DevicesPanel() {
  const [search, setSearch] = useState('');
  const [isModalOpen, setIsModalOpen] = useState(false);

  return (
    <DevicesFilterToolbar
      searchValue={search}
      onSearchChange={setSearch}
      tags={[]}
      onTagRemove={(v) => console.log('remove', v)}
      onClearAll={() => setSearch('')}
      onSubmit={(v) => setSearch(v)}
      isMdUp={true}
      onOpenFilterModal={() => setIsModalOpen(true)}
      isFilterModalOpen={isModalOpen}
      onCloseFilterModal={() => setIsModalOpen(false)}
      filterGroups={[]}
      onFilterChange={() => {}}
      tagFilterKeys={[]}
      selectedTags={[]}
      onTagsChange={() => {}}
      sticky={true}
    />
  );
}
```

> **Note:** When reusing inside a modal or non-full-width container (e.g. `DeviceSelector`), pass `sticky={false}` to disable the negative-margin bleed behaviour.
