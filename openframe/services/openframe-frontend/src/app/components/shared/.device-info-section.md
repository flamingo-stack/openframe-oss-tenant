Renders a device information section displaying a `DeviceCard` with status, OS, and action controls. Accepts device data either directly via props or fetches it remotely using a device ID, with a skeleton loading state while fetching.

## Key Components

- **`DeviceInfoSection`** — Main export. Conditionally fetches device details via `useDeviceDetails` when no `device` prop is provided, then renders a `DeviceCard` with mapped fields.
- **`DeviceInfoSectionProps`** — Interface accepting optional `deviceId`, `userId`, and a partial `Device` object for pre-loaded data.
- **`DeviceInfoSectionSkeleton`** — Placeholder UI rendered during remote fetch loading state.

## Usage Example

```typescript
// With pre-loaded device data (no fetch triggered)
<DeviceInfoSection
  device={{
    id: 'dev-123',
    displayName: 'MacBook Pro',
    status: 'online',
    osType: 'darwin',
  }}
/>

// With device ID (triggers remote fetch)
<DeviceInfoSection deviceId="dev-123" />

// Renders nothing if neither deviceId nor device is provided
<DeviceInfoSection />
```

## Behavior Notes

- If both `deviceId` and `device` prop are provided, the `device` prop takes precedence and no fetch is initiated.
- Returns `null` silently when neither a `deviceId` nor `device` data is available.
- The `DeviceDetailsButton` is always rendered in the card actions; the "more" button is hidden by default.
