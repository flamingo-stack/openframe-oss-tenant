Renders a device information section displaying a `DeviceCard` with status, OS, and action controls. Supports both prop-injected device data (e.g., from a log or dialog) and on-demand fetching via device ID.

## Key Components

- **`DeviceInfoSection`** — Main export. Accepts optional `deviceId`, `userId`, and `device` (partial `Device`). Prioritizes prop-passed device data over fetched data to avoid redundant network calls.
- **`useDeviceDetails`** — Hook used to fetch device details when no prop data is available. Polling is disabled.
- **`DeviceCard`** — Renders device name, OS, last seen, and status tag.
- **`DeviceDetailsButton`** — Injected as the card's details action button.
- **`DeviceInfoSectionSkeleton`** — Shown during loading when no prop data is present.

## Usage Example

```typescript
// With a device ID (fetches data automatically)
<DeviceInfoSection deviceId="device-abc123" />

// With pre-loaded device data (no fetch triggered)
<DeviceInfoSection
  device={{
    id: 'device-abc123',
    displayName: 'Workstation-01',
    status: 'online',
    osType: 'windows',
  }}
/>

// Inside a log or dialog context
<DeviceInfoSection
  deviceId="device-abc123"
  device={logEntry.device}
/>
```

> If neither `deviceId` nor `device` is provided, the component renders `null`.
