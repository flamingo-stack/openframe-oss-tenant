Barrel export file for the `DeviceSelector` component, re-exporting the component and its TypeScript types from their respective modules.

## Key Components

- **`DeviceSelector`** — The main component class/function exported from `./device-selector`
- **`DeviceSelectorProps`** — TypeScript interface defining the component's props
- **`InfiniteScrollConfig`** — TypeScript interface for configuring infinite scroll behavior

## Usage Example

```typescript
import { DeviceSelector } from '@/components/device-selector';
import type { DeviceSelectorProps, InfiniteScrollConfig } from '@/components/device-selector';

const scrollConfig: InfiniteScrollConfig = {
  pageSize: 20,
  threshold: 0.8,
};

const props: DeviceSelectorProps = {
  onSelect: (device) => console.log(device),
  infiniteScroll: scrollConfig,
};
```
