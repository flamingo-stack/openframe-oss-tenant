Barrel export file that re-exports the `DeviceSelector` component and its associated TypeScript types from the device-selector module.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `DeviceSelector` | Component | Main device selector UI component |
| `DeviceSelectorProps` | Type | Props interface for the `DeviceSelector` component |
| `InfiniteScrollConfig` | Type | Configuration interface for infinite scroll behavior |

## Usage Example

```typescript
import {
  DeviceSelector,
  type DeviceSelectorProps,
  type InfiniteScrollConfig,
} from '@/components/device-selector';

const scrollConfig: InfiniteScrollConfig = {
  pageSize: 20,
  threshold: 0.8,
};

const props: DeviceSelectorProps = {
  infiniteScroll: scrollConfig,
  onSelect: (device) => console.log(device),
};
```
