Custom hook managing device filtering, search, and tab-switching state for a device selector UI component.

## Key Components

**`useDeviceSelector(params)`** — Main hook that accepts:
- `devices` — Full list of available `Device` objects
- `selectedIds` — `Set<string>` of currently selected device keys
- `getDeviceKey` — Resolver function mapping a `Device` to its unique key

**Returns:**
| Field | Type | Description |
|---|---|---|
| `searchTerm` | `string` | Current search input value |
| `setSearchTerm` | `setter` | Updates search filter |
| `activeSubTab` | `SubTab` | Active tab (`'available'` or `'selected'`) |
| `handleTabChange` | `fn` | Switches tab and resets search |
| `filteredDevices` | `Device[]` | Devices filtered by search term |
| `displayDevices` | `Device[]` | Final list after tab + search filtering |

**Internal logic:**
- `filteredDevices` — Matches against `displayName`, `hostname`, `osType`, or `operating_system` (case-insensitive)
- `displayDevices` — When on the `'selected'` tab, further filters to only devices whose key exists in `selectedIds`
- `handleTabChange` — Resets `searchTerm` to `''` on every tab switch

## Usage Example

```typescript
const {
  searchTerm,
  setSearchTerm,
  activeSubTab,
  handleTabChange,
  displayDevices,
} = useDeviceSelector({
  devices: allDevices,
  selectedIds: new Set(['device-1', 'device-2']),
  getDeviceKey: (device) => device.id,
});
```
