Custom React hook managing search filtering and tab-based view state for a device selection UI component.

## Key Components

**`useDeviceSelector(params)`** — Main hook accepting:
- `devices` — Full list of `Device` objects to display
- `selectedIds` — `Set<string>` of currently selected device keys
- `getDeviceKey` — Resolver function mapping a `Device` to its unique key

**Returns:**
| Field | Type | Description |
|---|---|---|
| `searchTerm` | `string` | Current search input value |
| `setSearchTerm` | `fn` | Updates search filter |
| `activeSubTab` | `SubTab` | Active tab (`'available'` or `'selected'`) |
| `handleTabChange` | `fn` | Switches tab and clears search |
| `filteredDevices` | `Device[]` | Devices matching the search term |
| `displayDevices` | `Device[]` | Final list after tab + search filtering |

**Filtering logic:**
- `filteredDevices` — matches against `displayName`, `hostname`, `osType`, or `operating_system` (case-insensitive)
- `displayDevices` — when `activeSubTab === 'selected'`, further restricts to devices whose key exists in `selectedIds`

## Usage Example

```typescript
const {
  searchTerm,
  setSearchTerm,
  activeSubTab,
  handleTabChange,
  displayDevices,
} = useDeviceSelector({
  devices: allDevices,
  selectedIds: new Set(['device-1', 'device-2']),
  getDeviceKey: (device) => device.id,
});

// Render only filtered/tab-relevant devices
displayDevices.map(device => <DeviceRow key={device.id} device={device} />);
```
