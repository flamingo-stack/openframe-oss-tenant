Defines TypeScript types and interfaces for the `DeviceSelector` component, including props for selection behavior, infinite scroll configuration, and display customization.

## Key Components

- **`SubTab`** — Union type for tab state: `'available'` or `'selected'`
- **`InfiniteScrollConfig`** — Configuration for paginated/infinite scroll on the available devices tab
- **`DeviceSelectorProps`** — Full props interface for the `DeviceSelector` component

## `DeviceSelectorProps` Overview

| Prop | Type | Description |
|------|------|-------------|
| `devices` | `Device[]` | Device list; consumer handles fetching and pre-filtering |
| `loading` | `boolean` | Loading state for the device list |
| `selectedIds` | `Set<string>` | Currently selected device keys |
| `onSelectionChange` | `(ids: Set<string>) => void` | Selection change handler |
| `getDeviceKey` | `(device: Device) => string \| undefined` | Key extractor; defaults to `machineId ?? id` |
| `readOnly` | `boolean` | Viewer mode — disables tabs, radio, and action buttons |
| `infiniteScroll` | `InfiniteScrollConfig` | Pagination config for the available tab |
| `singleSelect` | `boolean` | Restricts selection to a single device |
| `addAllBehavior` | `'replace' \| 'merge'` | Controls "Add All" behavior; defaults to `'merge'` |
| `isDeviceDisabled` | `(device: Device) => string \| undefined` | Returns tooltip string when a device should be disabled |
| `hideColumns` | `string[]` | Column IDs to hide (e.g. `['organization', 'status']`) |
| `headerContent` | `ReactNode` | Extra content above the radio/tabs (e.g. `ScheduleInfoBar`) |

## Usage Example

```typescript
import type { DeviceSelectorProps, InfiniteScrollConfig } from './device-selector.types';

const scrollConfig: InfiniteScrollConfig = {
  hasNextPage: true,
  isFetchingNextPage: false,
  onLoadMore: () => fetchNextPage(),
  skeletonRows: 5,
};

const props: DeviceSelectorProps = {
  devices,
  loading: isLoading,
  selectedIds: new Set(['machine-123']),
  onSelectionChange: (ids) => setSelected(ids),
  infiniteScroll: scrollConfig,
  addAllBehavior: 'merge',
  singleSelect: false,
  hideColumns: ['organization'],
  isDeviceDisabled: (d) => d.online ? undefined : 'Device is offline',
};
```
