Defines TypeScript types and interfaces for the `DeviceSelector` component, including configuration for infinite scroll behavior, selection modes, and rendering options.

## Key Components

- **`SubTab`** — Union type for tab states: `'available'` or `'selected'`
- **`InfiniteScrollConfig`** — Configuration object for paginated/infinite scroll on the available devices tab
- **`DeviceSelectorProps`** — Main props interface for the `DeviceSelector` component

## `DeviceSelectorProps` Notable Fields

| Prop | Type | Description |
|------|------|-------------|
| `devices` | `Device[]` | Consumer-controlled device list (pre-fetched/filtered) |
| `selectedIds` | `Set<string>` | Currently selected device keys |
| `onSelectionChange` | `(ids: Set<string>) => void` | Selection change callback |
| `readOnly` | `boolean` | Viewer mode — disables tabs, radio, and action buttons |
| `singleSelect` | `boolean` | Restricts selection to one device at a time |
| `addAllBehavior` | `'replace' \| 'merge'` | Controls "Add All" strategy |
| `isDeviceDisabled` | `(device: Device) => string \| undefined` | Returns tooltip if device should be disabled |
| `hideColumns` | `string[]` | Column IDs to remove from the table |
| `infiniteScroll` | `InfiniteScrollConfig` | Pagination config for available tab |
| `headerContent` | `ReactNode` | Extra content rendered above tabs/radio |

## Usage Example

```typescript
const config: DeviceSelectorProps = {
  devices: deviceList,
  loading: isFetching,
  selectedIds: new Set(['machine-001', 'machine-002']),
  onSelectionChange: (ids) => setSelected(ids),
  singleSelect: false,
  addAllBehavior: 'merge',
  hideColumns: ['organization'],
  isDeviceDisabled: (device) =>
    device.status === 'offline' ? 'Device is offline' : undefined,
  infiniteScroll: {
    hasNextPage: true,
    isFetchingNextPage: false,
    onLoadMore: fetchNextPage,
    skeletonRows: 5,
  },
};
```
