Types definition file for the `DeviceSelector` component, declaring prop interfaces and supporting types for device selection UI with infinite scroll, read-only, and single-select capabilities.

## Key Components

- **`SubTab`** — Union type for tab state: `'available'` or `'selected'`
- **`InfiniteScrollConfig`** — Configuration object for paginated device loading on the available tab
- **`DeviceSelectorProps`** — Primary props interface for the `DeviceSelector` component

## `DeviceSelectorProps` Reference

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `devices` | `Device[]` | — | Device list; consumer controls fetching/filtering |
| `loading` | `boolean` | — | Loading state for the device list |
| `selectedIds` | `Set<string>` | — | Currently selected device keys |
| `onSelectionChange` | `(ids: Set<string>) => void` | — | Fires on selection change |
| `getDeviceKey` | `(device: Device) => string \| undefined` | `d.machineId ?? d.id` | Extracts unique key per device |
| `readOnly` | `boolean` | `false` | Hides tabs, radio, and action buttons |
| `infiniteScroll` | `InfiniteScrollConfig` | — | Pagination config for available tab |
| `disabled` | `boolean` | — | Disables all interactions |
| `showSelectionModeRadio` | `boolean` | `true` | Toggles selection mode radio group |
| `headerContent` | `ReactNode` | — | Content rendered above tabs/radio |
| `rowKey` | `string` | `"id"` | Table row key |
| `addAllBehavior` | `'replace' \| 'merge'` | `'merge'` | Behavior when adding all devices |
| `singleSelect` | `boolean` | `false` | Restricts selection to one device |
| `isDeviceDisabled` | `(device: Device) => string \| undefined` | — | Returns tooltip string if device is disabled |
| `hideColumns` | `string[]` | — | Column IDs to remove from the table |

## Usage Example

```typescript
import type { DeviceSelectorProps, InfiniteScrollConfig } from './device-selector.types';

const scrollConfig: InfiniteScrollConfig = {
  hasNextPage: true,
  isFetchingNextPage: false,
  onLoadMore: () => fetchNextPage(),
  skeletonRows: 5,
};

const props: DeviceSelectorProps = {
  devices,
  loading: isLoading,
  selectedIds: new Set(['machine-001', 'machine-002']),
  onSelectionChange: (ids) => setSelected(ids),
  infiniteScroll: scrollConfig,
  hideColumns: ['organization'],
  isDeviceDisabled: (device) =>
    device.status === 'offline' ? 'Device is offline' : undefined,
};
```
