A reusable slide-over drawer component for displaying structured log entry details, including status, metadata fields, and an optional pinned device card.

## Key Components

### `LogDrawer` (main export)
The primary drawer component rendering log details in a right-side panel.

**Props:**
| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls drawer visibility |
| `onClose` | `() => void` | Callback on dismiss |
| `description` | `string` | Log event description shown in header |
| `statusTag` | `{ label, variant? }` | Optional status badge (`success`, `warning`, `error`, `grey`, `critical`) |
| `timestamp` | `string` | Optional formatted timestamp |
| `infoFields` | `LogDrawerInfoField[]` | Key/value metadata fields rendered in an info card |
| `deviceId` | `string` | If provided, pins a `DeviceCard` to the drawer bottom |
| `children` | `React.ReactNode` | Optional additional content |

### `LogDrawerInfoField` (exported interface)
```typescript
interface LogDrawerInfoField {
  label: string;
  value: string | React.ReactNode;
}
```

### `DrawerDeviceCard` (internal)
Fetches device details via `useDeviceDetails` and renders a `DeviceCard` with OS, status, and a details action button. Shows a skeleton while loading.

## Usage Example

```typescript
import { LogDrawer } from './log-drawer';

<LogDrawer
  isOpen={isDrawerOpen}
  onClose={() => setDrawerOpen(false)}
  description="Authentication failure detected"
  statusTag={{ label: 'Error', variant: 'error' }}
  timestamp="2024-01-15 14:32:01"
  deviceId="device-abc123"
  infoFields={[
    { label: 'Source IP', value: '192.168.1.100' },
    { label: 'User', value: 'john.doe@company.com' },
    { label: 'Event Code', value: 'AUTH_FAIL_4011' },
  ]}
/>
```

> **Note:** The device card is suppressed if `deviceId` is `undefined`, `"null"`, or an empty string, guarding against stringified null values from API responses.
