A reusable slide-over drawer component for displaying structured log entry details, including status tags, timestamps, key-value info fields, and an optional pinned device card.

## Key Components

- **`LogDrawer`** — Main exported drawer component that renders log details in a right-side panel
- **`DrawerDeviceCard`** — Internal component that fetches and renders a `DeviceCard` for an associated device, with loading skeleton support
- **`LogDrawerInfoField`** — Exported interface defining the shape of key-value info fields (`{ label, value }`)
- **`LogDrawerProps`** — Props interface supporting open state, description, status tag, timestamp, info fields, and optional device ID

## Usage Example

```typescript
import { LogDrawer, type LogDrawerInfoField } from './log-drawer';

const fields: LogDrawerInfoField[] = [
  { label: 'Event Type', value: 'Authentication' },
  { label: 'Source IP', value: '192.168.1.100' },
  { label: 'User', value: 'john.doe@example.com' },
];

<LogDrawer
  isOpen={isDrawerOpen}
  onClose={() => setDrawerOpen(false)}
  description="Failed login attempt detected"
  statusTag={{ label: 'Failed', variant: 'error' }}
  timestamp="2024-01-15 14:32:01"
  infoFields={fields}
  deviceId="device-abc123"
/>
```

## Behavior Notes

- Info fields render value on top, label below (value-first layout)
- `DeviceCard` is pinned to the drawer bottom and only renders when `deviceId` is a valid non-empty, non-`"null"` string
- Device data is fetched via `useDeviceDetails` with polling disabled
- Shows `DeviceInfoSectionSkeleton` while device data loads
