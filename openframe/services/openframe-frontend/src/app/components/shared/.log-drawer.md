A reusable slide-out drawer component for displaying detailed log entry information, including status tags, timestamps, structured info fields, and an optional pinned device card.

## Key Components

### `LogDrawer` (main export)
The primary drawer component rendered on the right side of the screen with the following sections:
- **Header** — title, description, optional status `Tag`, and timestamp
- **Body** — structured info fields rendered as value-over-label pairs
- **Pinned device card** — rendered at the bottom when a valid `deviceId` is provided

### `DrawerDeviceCard` (internal)
Fetches device details via `useDeviceDetails` and renders a `DeviceCard` with OS info, status tag, and a `DeviceDetailsButton`. Shows a skeleton loader while fetching.

### `LogDrawerInfoField` (exported interface)
```typescript
interface LogDrawerInfoField {
  label: string;
  value: string | React.ReactNode;
}
```

## Props

| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls drawer visibility |
| `onClose` | `() => void` | Called when drawer closes |
| `description` | `string` | Subtitle text in the header |
| `statusTag` | `{ label, variant? }` | Optional status badge |
| `timestamp` | `string` | Optional timestamp displayed next to the tag |
| `infoFields` | `LogDrawerInfoField[]` | Key-value pairs rendered in the info card |
| `deviceId` | `string` | If provided, pins a `DeviceCard` to the drawer bottom |

## Usage Example

```typescript
<LogDrawer
  isOpen={isDrawerOpen}
  onClose={() => setIsDrawerOpen(false)}
  description="Authentication failure detected"
  statusTag={{ label: 'Error', variant: 'error' }}
  timestamp="2025-01-15 14:32:00"
  infoFields={[
    { label: 'Source IP', value: '192.168.1.42' },
    { label: 'User', value: 'john.doe@example.com' },
  ]}
  deviceId="device-abc-123"
/>
```
