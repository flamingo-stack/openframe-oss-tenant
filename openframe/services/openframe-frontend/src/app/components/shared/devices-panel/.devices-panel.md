Reusable panel component that renders the full devices management UI, supporting both table and grid view modes with filtering, infinite scroll pagination, and an "Add Device" action.

## Key Components

- **`DevicesPanel`** — Main exported component that composes the complete devices page experience
- **`DevicesPanelProps`** — Interface for configuring the panel's behavior, including locked filters, hidden columns/filters, default statuses, and layout overrides
- **View Mode Toggle** — `TabSelector` switches between `table` and `grid` layouts (grid is desktop-only; auto-collapses to table on mobile)
- **Filter System** — Combines URL-driven filters, locked filters, a filter toolbar, and a tag filter modal
- **Infinite Scroll** — `useGridInfiniteScroll` handles auto-loading in grid mode; `DataTable.InfiniteFooter` handles table mode pagination

## Usage Example

```typescript
// Full-page devices list
<DevicesPanel title="All Devices" />

// Scoped to a single organization (e.g. inside a customer tab)
<DevicesPanel
  title="Customer Devices"
  addDeviceHref="/customers/123/devices/new"
  lockedFilters={{ organizationId: '123' }}
  hideColumns={['organization']}
  hideFilters={['organization']}
  defaultStatuses={[]}
  className=""
/>
```

## Behavior Notes

| Prop | Default | Notes |
|------|---------|-------|
| `title` | `"Devices"` | Shown in `PageLayout` header |
| `addDeviceHref` | `"/devices/new"` | Router push destination |
| `lockedFilters` | `undefined` | Merged over URL filters; user cannot override |
| `hideColumns` | `undefined` | Drops columns from the data table |
| `hideFilters` | `undefined` | Drops keys from the filter modal |
| `defaultStatuses` | `undefined` | Pass `[]` to return all statuses by default |
| `className` | `""` | Overrides `PageLayout` wrapper padding |
