Reusable panel component that renders the full device management UI — combining search, filters, table/grid view toggling, infinite scroll, and row actions — within a `PageLayout` wrapper.

## Key Components

| Export | Description |
|---|---|
| `DevicesPanel` | Main panel component orchestrating device list views |
| `DevicesPanelProps` | Interface defining all configuration props |

**Key props:**

| Prop | Type | Description |
|---|---|---|
| `title` | `string` | Page header title (default: `'Devices'`) |
| `addDeviceHref` | `string` | Route for the "Add Device" button (default: `'/devices/new'`) |
| `lockedFilters` | `Partial<DeviceFilterInput>` | Filters merged on top of URL-driven filters (e.g. scoping to one org) |
| `hideColumns` | `string[]` | Column IDs to remove from the table |
| `hideFilters` | `string[]` | Filter keys to remove from the filter modal |
| `defaultStatuses` | `string[]` | Default status filters when user hasn't selected any |
| `className` | `string` | Overrides the `PageLayout` wrapper className |

**Internal hooks used:**

- `useDevicesUrlParams` — URL-driven filter/search state
- `useDevices` — paginated device data fetching
- `useDeviceFilters` — available filter options
- `useTagFilterModal` — filter modal open/close state and tag management
- `useGridInfiniteScroll` — sentinel-based infinite scroll for grid view

## Usage Example

```typescript
// Basic usage on the global devices page
<DevicesPanel />

// Scoped to a single organization (e.g. inside a customer tab)
<DevicesPanel
  title="Customer Devices"
  addDeviceHref="/customers/123/devices/new"
  lockedFilters={{ organizationId: '123' }}
  hideColumns={['organization']}
  hideFilters={['organization']}
  defaultStatuses={[]}
  className=""
/>
```

> **Note:** Grid view is automatically collapsed to table view on mobile (`< md` breakpoint) to ensure usability at narrow widths.
