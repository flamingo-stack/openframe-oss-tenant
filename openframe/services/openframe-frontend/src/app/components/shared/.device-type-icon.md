Renders a device-type icon from the `icons-v2` set based on a string type identifier, replacing the deprecated `getDeviceTypeIcon` utility from the core library.

## Key Components

- **`renderDeviceTypeIcon(type?, className?)`** — Returns a `React.ReactNode` icon component matched to the given device type string. Returns `undefined` for unknown or missing types, allowing callers to conditionally skip rendering.

**Supported types** (case-insensitive):

| Type | Icon Component |
|------|---------------|
| `desktop` | `MonitorIcon` |
| `laptop` | `LaptopIcon` |
| `server` | `HardDrivesIcon` |
| `mobile` | `MobilePhoneIcon` |
| `tablet` | `TabletIcon` |

## Usage Example

```typescript
import { renderDeviceTypeIcon } from './device-type-icon';

// Default styling (w-6 h-6 text-ods-text-secondary)
const icon = renderDeviceTypeIcon('laptop');

// Custom class
const icon = renderDeviceTypeIcon('server', 'w-4 h-4 text-blue-500');

// Safe rendering — skips if type is unknown
const icon = renderDeviceTypeIcon(device.type);
return icon ? <span>{icon}</span> : null;
```

> **Note:** Several call sites still use the deprecated `getDeviceTypeIcon` from `@flamingo-stack/openframe-frontend-core` and should be migrated to this utility:
> - `monitoring/policy/components/policy-devices-table.tsx`
> - `devices/components/devices-table-columns.tsx`
> - `components/shared/device-selector/device-selector.tsx`
