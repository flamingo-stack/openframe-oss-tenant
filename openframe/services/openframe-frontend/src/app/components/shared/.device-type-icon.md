Renders a device-type-appropriate icon React node from the `icons-v2` set, replacing the deprecated `getDeviceTypeIcon` utility from core.

## Key Components

### `renderDeviceTypeIcon(type?, className?)`

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `type` | `string` (optional) | — | Device type string (`desktop`, `laptop`, `server`, `mobile`, `tablet`) |
| `className` | `string` (optional) | `w-6 h-6 text-ods-text-secondary` | Tailwind/ODS classes applied to the icon |

**Returns:** `React.ReactNode` — the matching icon component, or `undefined` for unknown/missing types.

Type matching is **case-insensitive** (`"Desktop"` → `MonitorIcon`).

## Usage Example

```typescript
import { renderDeviceTypeIcon } from './device-type-icon';

// Basic usage — uses default ODS sizing/color
const icon = renderDeviceTypeIcon('laptop');

// Custom className
const largeIcon = renderDeviceTypeIcon('server', 'w-8 h-8 text-ods-text-primary');

// Safe rendering — returns undefined for unknown types
const unknownIcon = renderDeviceTypeIcon('printer'); // → undefined

// In JSX
function DeviceRow({ device }) {
  return (
    <div className="flex items-center gap-2">
      {renderDeviceTypeIcon(device.type)}
      <span>{device.name}</span>
    </div>
  );
}
```

## Supported Device Types

| Input | Icon Component |
|-------|---------------|
| `desktop` | `MonitorIcon` |
| `laptop` | `LaptopIcon` |
| `server` | `HardDrivesIcon` |
| `mobile` | `MobilePhoneIcon` |
| `tablet` | `TabletIcon` |
| *(anything else)* | `undefined` |

> **Migration note:** Call sites in `policy-devices-table.tsx`, `devices-table-columns.tsx`, and `device-selector.tsx` still use the deprecated `getDeviceTypeIcon` from `@flamingo-stack/openframe-frontend-core` and should be migrated to this utility.
