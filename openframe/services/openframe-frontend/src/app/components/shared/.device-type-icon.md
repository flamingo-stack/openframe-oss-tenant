Renders a device-type-specific icon by mapping a device type string to the appropriate icon component from the `icons-v2` set.

## Key Components

**`renderDeviceTypeIcon(type?, className?)`**
- Accepts an optional device type string and an optional CSS class name
- Returns a `React.ReactNode` for supported types: `desktop`, `laptop`, `server`, `mobile`, `tablet`
- Case-insensitive matching via `.toLowerCase()`
- Returns `undefined` for unknown or missing types, allowing callers to conditionally skip rendering
- Defaults to `w-6 h-6 text-ods-text-secondary` if no `className` is provided

## Usage Example

```typescript
import { renderDeviceTypeIcon } from './device-type-icon';

// Basic usage with default styling
const icon = renderDeviceTypeIcon('laptop');

// Custom class name
const icon = renderDeviceTypeIcon('server', 'w-8 h-8 text-blue-500');

// Safe rendering — returns undefined for unknown types
const icon = renderDeviceTypeIcon(device.type);
if (icon) {
  return <span>{icon}</span>;
}
```

## Supported Device Types

| Type | Icon Component |
|------|---------------|
| `desktop` | `MonitorIcon` |
| `laptop` | `LaptopIcon` |
| `server` | `HardDrivesIcon` |
| `mobile` | `MobilePhoneIcon` |
| `tablet` | `TabletIcon` |
