Renders a small circular avatar for an organization, displaying either the org's image or a two-letter initials fallback when no image is available or the image fails to load.

## Key Components

- **`OrgAvatar`** — Client component that accepts an optional `imageUrl` and required `name`, automatically falling back to initials on image load errors
- **`getFullImageUrl`** — Utility used to resolve relative or partial image URLs into absolute URLs
- **`failedUrl` state** — Tracks failed image URLs to prevent infinite retry loops and trigger the initials fallback

## Usage Example

```typescript
import { OrgAvatar } from '@/components/org-avatar';

// With image
<OrgAvatar name="Flamingo Inc." imageUrl="/uploads/org-logo.png" />

// Initials fallback (no image or null)
<OrgAvatar name="Acme Corp" />

// Initials fallback (broken URL)
<OrgAvatar name="OpenFrame" imageUrl="https://broken.url/logo.png" />
```

## Behavior Notes

- Initials are derived from the first two characters of `name`, uppercased (e.g. `"Acme"` → `"AC"`)
- Falls back to `??` if `name` is empty
- Image dimensions are fixed at `20×20px` with `object-cover` to fill the circular container
- Error handling via `onError` sets `failedUrl` to match `fullUrl`, suppressing re-render attempts with the same broken URL
