A small React client component that renders an organization's avatar as either an image or a two-letter initials fallback.

## Key Components

- **`OrgAvatar`** — Default export component accepting `imageUrl` (optional) and `name` props
- **`OrgAvatarProps`** — Interface defining the component's props
- **Fallback logic** — Tracks failed image URLs via `useState` to gracefully degrade to initials when an image fails to load

## Usage Example

```typescript
import { OrgAvatar } from '@/components/org-avatar';

// With an image
<OrgAvatar
  imageUrl="https://cdn.example.com/org-logo.png"
  name="Acme Corp"
/>

// Initials fallback (no image or broken URL)
<OrgAvatar name="Flamingo MSP" />
```

## Behavior

| Scenario | Renders |
|----------|---------|
| Valid `imageUrl` | `next/image` covering the avatar circle |
| `imageUrl` is `null`/`undefined` | Two-letter initials (e.g. `AC`) |
| Image fails to load (`onError`) | Falls back to initials silently |
| `name` is empty | Displays `??` as initials |

The avatar is a fixed **20×20 px** circle (`size-5`) with `overflow-hidden`, a dark `#161616` background, and an ODS border token, ensuring a consistent appearance whether the image loads or not.
