A client-side React component that renders an organization's avatar, displaying either the org's image or a two-letter initials fallback when no image is available or when the image fails to load.

## Key Components

- **`OrgAvatar`** — Main exported component that accepts an optional `imageUrl` and a required `name` prop
- **Initials fallback** — Derives a two-character uppercase string from `name` (defaults to `??`)
- **Error handling** — Tracks failed image URLs via `failedUrl` state to prevent infinite reload loops
- **`getFullImageUrl`** — Utility used to resolve relative or partial image URLs to absolute paths

## Usage Example

```typescript
// With an image URL
<OrgAvatar
  imageUrl="/uploads/orgs/acme-logo.png"
  name="Acme Corp"
/>

// Fallback to initials when no image provided
<OrgAvatar
  name="Flamingo MSP"
/>
// Renders a circle with "FL"

// Fallback to initials when image fails to load
<OrgAvatar
  imageUrl="https://broken.url/logo.png"
  name="Broken Org"
/>
// Automatically falls back to "BR" initials after load error
```

## Notes

- Renders a 20×20px (`size-5`) circular container
- Uses Next.js `<Image>` for optimized image loading
- The `failedUrl` guard ensures a broken image doesn't trigger repeated retries — once a URL fails, it stays in fallback mode for the lifetime of the component instance
