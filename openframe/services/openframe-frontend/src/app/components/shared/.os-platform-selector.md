A client-side React component that renders an OS platform selection UI using a tab-based selector, mapping OS platform identifiers to labeled, icon-equipped tabs with optional badges and disabled states.

## Key Components

### Interfaces

- **`PlatformSelectorOption`** — Defines a selectable OS platform entry with optional `disabled` flag and `badge` configuration (text + color scheme).
- **`OsPlatformSelectorProps`** — Props for the `OsPlatformSelector` component, including controlled `value`, change handler, display options, and styling overrides.

### Component

- **`OsPlatformSelector`** — Renders a `TabSelector` populated with OS platform tabs. Resolves icons via `getOSIcon`, applies active icon coloring for the `primary` variant, and injects `StatusBadge` elements for options with badge config. Falls back to all `OS_TYPES` if no explicit `options` are provided.

## Usage Example

```typescript
import { OsPlatformSelector } from './os-platform-selector';
import type { OSPlatformId } from '@flamingo-stack/openframe-frontend-core/utils';

function ScriptTargetPicker() {
  const [platform, setPlatform] = useState<OSPlatformId>('windows');

  return (
    <OsPlatformSelector
      value={platform}
      onValueChange={setPlatform}
      label="Target OS"
      disabledPlatforms={['linux']}
      options={[
        { platformId: 'windows' },
        { platformId: 'macos', badge: { text: 'Beta', colorScheme: 'yellow' } },
        { platformId: 'linux', disabled: true },
      ]}
      variant="primary"
      iconSize="w-4 h-4"
    />
  );
}
```

## Notes

- Defaults to rendering all platforms from `OS_TYPES` when `options` is omitted.
- Active tab icons in the `primary` variant receive a hardcoded `#212121` color override.
- Unrecognized `platformId` values (not found in `OS_TYPES`) are silently filtered out.
