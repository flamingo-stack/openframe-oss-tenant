A client-side React component that renders an OS platform selector using a tab-based UI, allowing users to switch between different operating system platforms (Windows, macOS, Linux, etc.).

## Key Components

**Interfaces**
- `PlatformSelectorOption` — Defines a selectable platform entry with optional disabled state and status badge
- `OsPlatformSelectorProps` — Props for the `OsPlatformSelector` component

**Component**
- `OsPlatformSelector` — Renders a `TabSelector` pre-configured with OS platform icons, labels, and optional status badges

## Usage Example

```typescript
import { OsPlatformSelector } from './os-platform-selector';
import type { OSPlatformId } from '@flamingo-stack/openframe-frontend-core/utils';

// Basic usage — renders all available OS platforms
<OsPlatformSelector
  value="windows"
  onValueChange={(platform: OSPlatformId) => console.log(platform)}
/>

// Custom platforms with badges and disabled states
<OsPlatformSelector
  value="linux"
  onValueChange={setPlatform}
  label="Target OS"
  variant="secondary"
  iconSize="w-4 h-4"
  options={[
    { platformId: 'windows', badge: { text: 'Beta', colorScheme: 'yellow' } },
    { platformId: 'macos' },
    { platformId: 'linux', disabled: true },
  ]}
/>

// Using disabledPlatforms shorthand
<OsPlatformSelector
  value={selectedPlatform}
  onValueChange={setSelectedPlatform}
  disabledPlatforms={['linux']}
/>
```

> **Note:** When `options` is not provided, the component automatically generates tabs for all entries in `OS_TYPES`. The active tab icon fills with `#212121` in `primary` variant mode.
