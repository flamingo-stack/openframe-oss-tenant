A client-side React component that renders an OS platform tab selector, mapping OS types to interactive tabs with icons, optional badges, and disabled states.

## Key Components

### Interfaces

- **`PlatformSelectorOption`** — Defines a platform tab option with `platformId`, optional `disabled` flag, and optional `badge` config (text + color scheme).
- **`OsPlatformSelectorProps`** — Props for the selector including controlled `value`, `onValueChange` handler, display options, and styling variants.

### Component

- **`OsPlatformSelector`** — Wraps `TabSelector` with OS-aware logic: resolves platform icons via `getOSIcon`, applies active state coloring, and renders `StatusBadge` for flagged platforms.

## Usage Example

```typescript
import { OsPlatformSelector } from './os-platform-selector';
import type { OSPlatformId } from '@flamingo-stack/openframe-frontend-core/utils';

// Basic usage — auto-populates all OS types
<OsPlatformSelector
  value={selectedPlatform}
  onValueChange={(platform: OSPlatformId) => setSelectedPlatform(platform)}
/>

// Custom options with badge and disabled state
<OsPlatformSelector
  value={selectedPlatform}
  onValueChange={setSelectedPlatform}
  variant="secondary"
  iconSize="w-4 h-4"
  options={[
    { platformId: 'windows' },
    { platformId: 'macos', badge: { text: 'Beta', colorScheme: 'yellow' } },
    { platformId: 'linux', disabled: true },
  ]}
/>
```

## Notes

- If `options` is omitted, all platforms from `OS_TYPES` are rendered; `disabledPlatforms` can exclude specific ones.
- Active tab icons receive a dark fill (`#212121`) only in the `primary` variant.
- Platforms not found in `OS_TYPES` are silently filtered out.
