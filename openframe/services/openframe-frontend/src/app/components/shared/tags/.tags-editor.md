A client-side React component for managing a list of key-value tags, using Relay for fetching autocomplete suggestions and exposing CRUD operations per tag entry.

## Key Components

- **`TagsEditor`** — Main component rendering a dynamic list of `TagRow` entries with add/update/delete handlers
- **`tagsEditorRootQuery`** — Relay GraphQL root query fetching initial tag key suggestions (limit: 20)
- **`keySuggestionsFragment`** — Exported refetchable Relay fragment providing `tagKeySuggestions` (key + values) to child rows; consumed by `useTagKeySuggestions`
- **`TagsEditorProps`** — `tags: TagEntryWithId[]`, `onTagsChange` callback, optional `addLabel` string

## Usage Example

```typescript
import { TagsEditor } from './tags-editor';
import type { TagEntryWithId } from './types';

const [tags, setTags] = useState<TagEntryWithId[]>([]);

<TagsEditor
  tags={tags}
  onTagsChange={setTags}
  addLabel="Add Tag"
/>
```

> **Note:** `TagsEditor` must be rendered inside a Relay `Environment` provider and a React Suspense boundary, as it uses `useLazyLoadQuery` which suspends on fetch.

## Behavior Notes

- Each new tag is assigned a `crypto.randomUUID()` client-side ID
- `existingKeys` filters already-used keys to prevent duplicates in suggestions
- The `keySuggestionsFragment` ref is passed down to each `TagRow` to enable per-row refetchable key autocomplete
