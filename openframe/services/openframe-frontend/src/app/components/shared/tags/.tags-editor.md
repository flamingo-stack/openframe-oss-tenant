A React client component that renders an editable list of key-value tag entries, backed by a Relay GraphQL query for tag key autocomplete suggestions.

## Key Components

- **`TagsEditor`** — Main exported component. Renders a list of `TagRow` entries with add/update/delete callbacks, and fetches key suggestions via Relay's `useLazyLoadQuery`.
- **`keySuggestionsFragment`** — Exported refetchable GraphQL fragment (`tagsEditor_keySuggestions`) used by `useTagKeySuggestions` to drive autocomplete.
- **`tagsEditorRootQuery`** — Root GraphQL query that spreads the key suggestions fragment with a configurable `limit`.
- **`SUGGESTIONS_LIMIT`** — Constant (`20`) capping the number of tag key suggestions fetched on initial load.

## Usage Example

```typescript
import { TagsEditor } from './tags-editor';
import type { TagEntryWithId } from './types';

function MyForm() {
  const [tags, setTags] = useState<TagEntryWithId[]>([]);

  return (
    <TagsEditor
      tags={tags}
      onTagsChange={setTags}
      addLabel="Add Tag"
    />
  );
}
```

> **Note:** `TagsEditor` must be rendered inside a Relay `<Suspense>` boundary (and a `RelayEnvironmentProvider`) since it calls `useLazyLoadQuery` internally.

```typescript
<Suspense fallback={<Spinner />}>
  <TagsEditor tags={tags} onTagsChange={setTags} />
</Suspense>
```

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `tags` | `TagEntryWithId[]` | — | Controlled list of tag entries |
| `onTagsChange` | `(tags: TagEntryWithId[]) => void` | — | Called on add, update, or delete |
| `addLabel` | `string` | `'Add Tag'` | Label for the add button |
