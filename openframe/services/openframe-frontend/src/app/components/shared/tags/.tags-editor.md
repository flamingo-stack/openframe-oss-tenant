A React client component for managing a list of key-value tags, supporting add, update, and delete operations with GraphQL-powered key autocomplete suggestions.

## Key Components

- **`TagsEditor`** — Main exported component that renders a list of `TagRow` entries with controls to add, update, and delete tags.
- **`keySuggestionsFragment`** — Exported Relay GraphQL fragment (`tagsEditor_keySuggestions`) used by `useTagKeySuggestions` hook to query and refetch tag key suggestions.
- **`tagsEditorRootQuery`** — Relay GraphQL root query fetching tag key suggestions limited to `SUGGESTIONS_LIMIT` (20).
- **`TagsEditorProps`** — Interface defining `tags`, `onTagsChange`, and optional `addLabel` props.

## Usage Example

```typescript
import { TagsEditor } from './tags-editor';
import type { TagEntryWithId } from './types';
import { useState } from 'react';

function MyForm() {
  const [tags, setTags] = useState<TagEntryWithId[]>([]);

  return (
    <TagsEditor
      tags={tags}
      onTagsChange={setTags}
      addLabel="Add Tag"
    />
  );
}
```

## Notes

- Uses `useLazyLoadQuery` with `store-or-network` fetch policy to avoid redundant network requests.
- Each tag entry is assigned a `crypto.randomUUID()` client-side ID on creation for stable React keying.
- `existingKeys` is derived from current tags and passed to each `TagRow` to prevent duplicate key selection.
- Requires a Relay environment provider higher in the component tree.
