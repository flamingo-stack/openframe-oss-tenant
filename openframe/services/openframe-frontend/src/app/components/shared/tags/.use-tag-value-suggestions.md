Provides debounced, searchable autocomplete suggestions for tag values by fetching data via a refetchable Relay GraphQL fragment, with deferred loading state management.

## Key Components

- **`useTagValueSuggestions(tagKey)`** — Main hook that accepts a tag key string and returns autocomplete options, loading state, and input handlers
- **`valueSuggestionsRootQuery`** — Root GraphQL query bootstrapping the fragment with `tagKey` and `limit` arguments
- **`valueSuggestionsFragment`** — Refetchable fragment on `Query` supporting `search`, `tagKey`, and `limit` to power live filtering
- **`SUGGESTIONS_LIMIT`** — Caps results at 20 entries
- **`DEBOUNCE_MS`** — 300ms debounce delay before triggering a refetch on input change

## Usage Example

```typescript
import { useTagValueSuggestions } from './use-tag-value-suggestions';

function TagValueAutocomplete({ tagKey }: { tagKey: string }) {
  const { options, isRefetching, handleInputChange, resetInput } =
    useTagValueSuggestions(tagKey);

  return (
    <Autocomplete
      options={options}
      loading={isRefetching}
      onInputChange={handleInputChange}
      onClear={resetInput}
    />
  );
}
```

## Return Values

| Property | Type | Description |
|----------|------|-------------|
| `options` | `AutocompleteOption[]` | Mapped `{ label, value }` pairs from suggestions |
| `isRefetching` | `boolean` | Deferred loading indicator during refetch transitions |
| `handleInputChange` | `(value: string) => void` | Updates internal search input state |
| `resetInput` | `() => void` | Clears search input and resets suggestions |
