Provides debounced, searchable autocomplete suggestions for tag values by fetching and refetching data via Relay GraphQL with a 300ms input debounce and deferred loading state.

## Key Components

- **`useTagValueSuggestions(tagKey)`** — Main hook that accepts a tag key string and returns autocomplete options, loading state, and input handlers
- **`valueSuggestionsRootQuery`** — Relay root query fetching initial tag value suggestions
- **`valueSuggestionsFragment`** — Refetchable Relay fragment supporting `tagKey`, `search`, and `limit` arguments
- **`SUGGESTIONS_LIMIT`** — Maximum of 20 suggestions returned per query
- **`DEBOUNCE_MS`** — 300ms debounce delay applied to search input before triggering a refetch

## Return Values

| Property | Type | Description |
|----------|------|-------------|
| `options` | `AutocompleteOption[]` | Mapped `{ label, value }` pairs from suggestions |
| `isRefetching` | `boolean` | Deferred loading indicator during refetch transitions |
| `handleInputChange` | `(value: string) => void` | Updates internal search input state |
| `resetInput` | `() => void` | Clears search input back to empty string |

## Usage Example

```typescript
import { useTagValueSuggestions } from './use-tag-value-suggestions';

function TagValueAutocomplete({ tagKey }: { tagKey: string }) {
  const { options, isRefetching, handleInputChange, resetInput } =
    useTagValueSuggestions(tagKey);

  return (
    <Autocomplete
      options={options}
      loading={isRefetching}
      onInputChange={handleInputChange}
      onClose={resetInput}
    />
  );
}
```

> **Note:** This hook uses `useLazyLoadQuery` and requires a Relay environment provider in the component tree. Search refetches are wrapped in `useTransition` to avoid blocking the UI during network requests.
