Provides debounced, searchable autocomplete suggestions for tag values by fetching data via Relay GraphQL with refetchable fragments.

## Key Components

- **`useTagValueSuggestions(tagKey)`** — Main hook that returns autocomplete options and input handlers for a given tag key
- **`valueSuggestionsRootQuery`** — Relay root query fetching initial tag value suggestions (limit: 20)
- **`valueSuggestionsFragment`** — Refetchable Relay fragment supporting `search` and `limit` arguments for filtered suggestions
- **`SUGGESTIONS_LIMIT`** — Maximum number of suggestions returned (20)
- **`DEBOUNCE_MS`** — Input debounce delay (300ms) to throttle refetch calls

## Return Values

| Property | Type | Description |
|---|---|---|
| `options` | `AutocompleteOption[]` | Mapped `{ label, value }` pairs from suggestions |
| `isRefetching` | `boolean` | Deferred loading state during refetch transitions |
| `handleInputChange` | `(value: string) => void` | Updates search input, triggering debounced refetch |
| `resetInput` | `() => void` | Clears search input back to empty string |

## Usage Example

```typescript
import { useTagValueSuggestions } from './use-tag-value-suggestions';

function TagValueAutocomplete({ tagKey }: { tagKey: string }) {
  const { options, isRefetching, handleInputChange, resetInput } =
    useTagValueSuggestions(tagKey);

  return (
    <Autocomplete
      options={options}
      loading={isRefetching}
      onInputChange={handleInputChange}
      onClose={resetInput}
    />
  );
}
```

> **Note:** This hook uses `useLazyLoadQuery` with `store-or-network` fetch policy — wrap the consuming component in a Relay `Suspense` boundary to handle the initial load state.
