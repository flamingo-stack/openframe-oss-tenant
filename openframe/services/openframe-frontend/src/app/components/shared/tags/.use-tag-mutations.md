React hooks for tag CRUD operations via Relay GraphQL mutations, with integrated toast error notifications.

## Key Components

| Export | Description |
|--------|-------------|
| `useCreateTagMutation` | Creates a new tag with `key`, `entityType`, and optional `description`/`color` |
| `useUpdateTagMutation` | Updates an existing tag by `id` with optional field patches |
| `useDeleteTagMutation` | Deletes a tag by `id` |

Each hook returns a typed action function and an `isInFlight` boolean for loading state tracking.

## Usage Example

```typescript
import {
  useCreateTagMutation,
  useUpdateTagMutation,
  useDeleteTagMutation,
} from './use-tag-mutations';

function TagManager() {
  const { createTag, isInFlight: creating } = useCreateTagMutation();
  const { updateTag, isInFlight: updating } = useUpdateTagMutation();
  const { deleteTag, isInFlight: deleting } = useDeleteTagMutation();

  // Create a new tag
  createTag(
    { key: 'priority', entityType: 'ticket', color: '#FF0000' },
    (newId) => console.log('Created tag:', newId),
  );

  // Update an existing tag
  updateTag(
    { id: 'tag-123', description: 'High priority items' },
    () => console.log('Tag updated'),
  );

  // Delete a tag
  deleteTag('tag-123', () => console.log('Tag deleted'));
}
```

## Notes

- All hooks display a destructive toast notification automatically on mutation error — no manual error handling required.
- `onCompleted` callbacks are optional; pass them to trigger post-mutation side effects (e.g., cache refresh, navigation).
- `isInFlight` can be used to disable buttons or show loading spinners during pending mutations.
