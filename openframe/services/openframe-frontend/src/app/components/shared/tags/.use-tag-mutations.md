React hooks for tag CRUD operations using Relay mutations, with built-in toast notifications for error handling.

## Key Components

| Export | Description |
|--------|-------------|
| `useCreateTagMutation` | Hook to create a new tag with `key`, `entityType`, optional `description` and `color` |
| `useUpdateTagMutation` | Hook to update an existing tag by `id` |
| `useDeleteTagMutation` | Hook to delete a tag by `id` |

Each hook returns a memoized mutation function and an `isInFlight` boolean indicating pending state. Errors are automatically surfaced via destructive toast notifications.

## Usage Example

```typescript
import {
  useCreateTagMutation,
  useUpdateTagMutation,
  useDeleteTagMutation,
} from './use-tag-mutations';

function TagManager() {
  const { createTag, isInFlight: creating } = useCreateTagMutation();
  const { updateTag, isInFlight: updating } = useUpdateTagMutation();
  const { deleteTag, isInFlight: deleting } = useDeleteTagMutation();

  // Create a new tag
  createTag(
    { key: 'urgent', entityType: 'ticket', color: '#FF0000' },
    (id) => console.log('Created tag:', id),
  );

  // Update an existing tag
  updateTag(
    { id: 'tag-123', color: '#00FF00' },
    () => console.log('Tag updated'),
  );

  // Delete a tag
  deleteTag('tag-123', () => console.log('Tag deleted'));
}
```
