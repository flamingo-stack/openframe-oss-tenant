React hooks for creating, updating, and deleting tags via GraphQL mutations using React Relay, with built-in toast error notifications.

## Key Components

- **`useCreateTagMutation`** — Commits a `createTag` mutation; accepts `key`, `entityType`, and optional `description`/`color`; returns the new tag's `id` via `onCompleted` callback
- **`useUpdateTagMutation`** — Commits an `updateTag` mutation by `id`; all fields except `id` are optional
- **`useDeleteTagMutation`** — Commits a `deleteTag` mutation by `id`; returns a boolean result
- Each hook exposes an `isInFlight` boolean to track pending mutation state
- Errors are surfaced automatically via the `useToast` hook with a `destructive` variant

## Usage Example

```typescript
import {
  useCreateTagMutation,
  useUpdateTagMutation,
  useDeleteTagMutation,
} from './use-tag-mutations';

function TagManager() {
  const { createTag, isInFlight: isCreating } = useCreateTagMutation();
  const { updateTag, isInFlight: isUpdating } = useUpdateTagMutation();
  const { deleteTag, isInFlight: isDeleting } = useDeleteTagMutation();

  // Create a new tag
  createTag(
    { key: 'priority', entityType: 'ticket', color: '#FFC008' },
    (id) => console.log('Created tag:', id),
  );

  // Update an existing tag
  updateTag(
    { id: 'tag-123', description: 'High priority items' },
    () => console.log('Tag updated'),
  );

  // Delete a tag
  deleteTag('tag-123', () => console.log('Tag deleted'));
}
```
