A single-row component for editing a key/value tag entry, including validation logic and autocomplete suggestions for both tag keys and values.

## Key Components

**Exports**
- `TAG_REGEX` — Validation pattern: alphanumeric, underscores, hyphens; must start with a letter or digit
- `TAG_MAX_LENGTH` — Maximum allowed length (64 characters)
- `isValidTag(value)` — Returns `true` if the value passes regex and length checks
- `validateTagKey(key)` — Returns an error message string or `undefined`
- `validateTagValues(values)` — Validates an array of tag values, returns an error message or `undefined`
- `TagRow` — Main row component rendering key autocomplete, value autocomplete, and a delete button

**`TagRowProps`**
| Prop | Description |
|---|---|
| `tag` | Current `TagEntry` with a stable `id` |
| `onChange` | Called with updated `TagEntry` on key/value change |
| `onDelete` | Called when the trash icon is clicked |
| `existingKeys` | All keys in the editor, used to detect duplicates |
| `keySuggestionsRef` | Relay fragment ref for key autocomplete suggestions |
| `isFirst` | Shows column labels (`Tag Name` / `Tag Values`) when `true` |

## Usage Example

```typescript
<TagRow
  tag={{ id: '1', key: 'env', values: ['production'] }}
  onChange={(updated) => updateTag('1', updated)}
  onDelete={() => removeTag('1')}
  existingKeys={['env', 'region']}
  keySuggestionsRef={fragmentRef}
  isFirst
/>
```

**Validation behaviour:** Changing the tag key clears existing values. Duplicate keys and format/length violations surface inline errors on the respective field.
