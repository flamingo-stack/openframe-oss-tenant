A React component that renders a single editable tag key/value row within a tags editor, including validation, autocomplete suggestions, and a delete action.

## Key Components

### Exports

| Export | Type | Description |
|--------|------|-------------|
| `TagRow` | Component | Renders a tag key + values pair row with autocomplete and delete button |
| `TAG_REGEX` | Constant | Validation regex for tag keys/values (`/^[a-zA-Z0-9][a-zA-Z0-9_-]*$/`) |
| `TAG_MAX_LENGTH` | Constant | Maximum allowed length for tag keys/values (64 characters) |
| `isValidTag` | Function | Returns `true` if a string passes length and format rules |
| `validateTagKey` | Function | Returns an error message string or `undefined` for a tag key |
| `validateTagValues` | Function | Returns an error message string or `undefined` for an array of tag values |

### Props — `TagRow`

| Prop | Type | Description |
|------|------|-------------|
| `tag` | `TagEntry & { id: string }` | Current tag state |
| `onChange` | `(tag: TagEntry) => void` | Called when key or values change |
| `onDelete` | `() => void` | Called when the delete button is clicked |
| `existingKeys` | `string[]` | Used to detect duplicate keys |
| `keySuggestionsRef` | `KeySuggestionsFragmentKey` | Relay fragment ref for key suggestions |
| `isFirst` | `boolean?` | When `true`, renders column labels for the first row only |

## Usage Example

```typescript
import { TagRow } from './tag-row';

<TagRow
  tag={{ id: '1', key: 'environment', values: ['production'] }}
  onChange={(updated) => updateTag('1', updated)}
  onDelete={() => removeTag('1')}
  existingKeys={['environment', 'region']}
  keySuggestionsRef={keySuggestionsFragmentRef}
  isFirst
/>
```

> Key changes reset the values array to prevent stale value associations. The value `Autocomplete` is disabled until a valid key is entered, with lazy loading via `Suspense`.
