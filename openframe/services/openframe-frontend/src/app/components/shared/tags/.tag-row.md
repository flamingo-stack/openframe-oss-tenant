A single row component in the tags editor UI, rendering paired key/value autocomplete inputs with inline validation and a delete button.

## Key Components

**Exports**
- `TAG_REGEX` — Regex pattern enforcing alphanumeric, underscore, and hyphen characters starting with a letter or digit
- `TAG_MAX_LENGTH` — Maximum character length constant (`64`)
- `isValidTag(value)` — Returns `true` if a string passes both length and regex checks
- `validateTagKey(key)` — Returns an error message string or `undefined` for a tag key
- `validateTagValues(values)` — Returns an error message string or `undefined` for an array of tag values
- `TagRow` — Primary row component combining key autocomplete, value autocomplete, and delete action

**TagRow Props**

| Prop | Type | Description |
|------|------|-------------|
| `tag` | `TagEntry & { id: string }` | Current tag key/values with stable ID |
| `onChange` | `(tag: TagEntry) => void` | Called on key or value change |
| `onDelete` | `() => void` | Called when the delete button is pressed |
| `existingKeys` | `string[]` | All current keys, used for duplicate detection |
| `keySuggestionsRef` | `KeySuggestionsFragmentKey` | Relay fragment ref for key suggestions query |
| `isFirst` | `boolean` | Shows column labels only on the first row |

## Usage Example

```typescript
<TagRow
  tag={{ id: 'row-1', key: 'environment', values: ['production'] }}
  onChange={(updated) => updateTag('row-1', updated)}
  onDelete={() => removeTag('row-1')}
  existingKeys={['environment', 'region']}
  keySuggestionsRef={keySuggestionsFragmentRef}
  isFirst={true}
/>
```

**Validation behavior:**
- Changing the key clears existing values
- Duplicate keys surface an inline error on the key field
- Value autocomplete is disabled and shows a skeleton fallback (`Suspense`) until a key is entered
