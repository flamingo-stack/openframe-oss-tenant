Defines core TypeScript types and interfaces for the tag management system, supporting entity tagging across devices, tickets, and knowledge articles.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `TagEntityType` | Union type | Constrains taggable entities to `'DEVICE'`, `'TICKET'`, or `'KNOWLEDGE_ARTICLE'` |
| `TagEntry` | Interface | Base key-value pair structure for a tag |
| `TagEntryWithId` | Interface | Extends `TagEntry` with a unique `id` field |
| `Tag` | Interface | Full tag record including metadata like color, description, and creation timestamp |

## Usage Example

```typescript
import { Tag, TagEntry, TagEntryWithId, TagEntityType } from './types';

// Define which entity type a tag applies to
const entityType: TagEntityType = 'DEVICE';

// Basic tag key-value pair
const entry: TagEntry = {
  key: 'environment',
  values: ['production', 'us-east'],
};

// Tag entry with persisted ID
const entryWithId: TagEntryWithId = {
  id: 'entry-123',
  key: 'environment',
  values: ['production'],
};

// Full tag record from the API
const tag: Tag = {
  id: 'tag-abc',
  key: 'environment',
  description: 'Deployment environment label',
  color: '#FFC008',
  entityType: 'TICKET',
  createdAt: '2025-01-15T10:00:00Z',
};
```
