Defines core TypeScript types for the tagging system, supporting entities such as devices, tickets, and knowledge articles.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `TagEntityType` | Union type | Constrains tags to valid entity contexts: `'DEVICE'`, `'TICKET'`, or `'KNOWLEDGE_ARTICLE'` |
| `TagEntry` | Interface | Represents a tag key paired with multiple values |
| `TagEntryWithId` | Interface | Extends `TagEntry` with a unique identifier |
| `Tag` | Interface | Full tag record including metadata such as color, description, and entity scope |

## Usage Example

```typescript
import { Tag, TagEntry, TagEntryWithId, TagEntityType } from './types';

// Define a tag scoped to devices
const deviceTag: Tag = {
  id: 'tag-001',
  key: 'environment',
  description: 'Deployment environment label',
  color: '#FF5733',
  entityType: 'DEVICE',
  createdAt: '2024-01-15T10:00:00Z',
};

// Tag entry without persistence ID (pre-save)
const entry: TagEntry = {
  key: 'environment',
  values: ['production', 'staging'],
};

// Tag entry with ID (post-save)
const entryWithId: TagEntryWithId = {
  id: 'entry-001',
  key: 'environment',
  values: ['production'],
};

// Typed entity scope
const scope: TagEntityType = 'TICKET';
```
