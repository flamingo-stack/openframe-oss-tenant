Defines core TypeScript types and interfaces for the tagging system, supporting entities such as devices, tickets, and knowledge articles.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `TagEntityType` | Union type | Constrains taggable entities to `'DEVICE'`, `'TICKET'`, or `'KNOWLEDGE_ARTICLE'` |
| `TagEntry` | Interface | A key-value pair representing a tag entry with multiple values |
| `TagEntryWithId` | Interface | Extends `TagEntry` with a unique `id` field |
| `Tag` | Interface | Full tag record including metadata such as color, description, and entity scope |

## Usage Example

```typescript
import { Tag, TagEntry, TagEntryWithId, TagEntityType } from './types';

// Define a tag scoped to devices
const deviceTag: Tag = {
  id: 'tag-001',
  key: 'environment',
  description: 'Deployment environment',
  color: '#FFC008',
  entityType: 'DEVICE',
  createdAt: '2024-01-15T10:00:00Z',
};

// A tag entry without an ID (e.g., for creation payloads)
const entry: TagEntry = {
  key: 'environment',
  values: ['production', 'staging'],
};

// A tag entry with an ID (e.g., after persistence)
const entryWithId: TagEntryWithId = {
  id: 'entry-123',
  key: 'environment',
  values: ['production'],
};

// Using the entity type constraint
const entityType: TagEntityType = 'TICKET';
```
