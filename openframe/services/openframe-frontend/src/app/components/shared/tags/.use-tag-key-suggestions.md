Provides autocomplete suggestions for tag keys by debouncing user input and refetching a Relay fragment with filtered results.

## Key Components

- **`useTagKeySuggestions(currentKey, keySuggestionsRef)`** — Main hook that manages tag key autocomplete state and remote suggestions.
- **`keySuggestionsFragment`** — Relay refetchable fragment sourced from `tags-editor`, used to fetch paginated/filtered key suggestions.
- **`SUGGESTIONS_LIMIT`** — Caps returned suggestions at `20` items.
- **`DEBOUNCE_MS`** — Delays refetch by `300ms` after input changes to reduce network requests.

## Usage Example

```typescript
import { useTagKeySuggestions } from './use-tag-key-suggestions';

function TagKeyAutocomplete({ keySuggestionsRef, selectedKey }) {
  const {
    options,
    isRefetching,
    handleInputChange,
    resetInput,
  } = useTagKeySuggestions(selectedKey, keySuggestionsRef);

  return (
    <Autocomplete
      options={options}
      loading={isRefetching}
      onInputChange={handleInputChange}
      onSelect={resetInput}
    />
  );
}
```

## Behavior Notes

- **Current key injection** — If `currentKey` is set but not present in fetched suggestions (e.g. during first load), it is prepended to the options list to prevent a blank selection.
- **Deferred loading** — Uses `useDeferredLoading` to avoid flickering on fast refetches triggered by `useTransition`.
- **Relay fetch policy** — Uses `store-or-network` to serve cached data immediately while revalidating in the background.
