Provides debounced, refetchable autocomplete suggestions for tag keys using a Relay fragment and React transitions.

## Key Components

- **`useTagKeySuggestions(currentKey, keySuggestionsRef)`** — Main hook that manages tag key autocomplete state and data fetching
- **`SUGGESTIONS_LIMIT`** — Maximum number of suggestions returned per query (20)
- **`DEBOUNCE_MS`** — Input debounce delay to throttle refetch calls (300ms)

## Usage Example

```typescript
import { useTagKeySuggestions } from './use-tag-key-suggestions';

function TagKeyInput({ fragmentRef, currentKey }) {
  const { options, isRefetching, handleInputChange, resetInput } =
    useTagKeySuggestions(currentKey, fragmentRef);

  return (
    <Autocomplete
      options={options}
      loading={isRefetching}
      onInputChange={handleInputChange}
      onSelect={resetInput}
    />
  );
}
```

## Return Values

| Property | Type | Description |
|---|---|---|
| `options` | `AutocompleteOption[]` | Merged list of suggestions; prepends `currentKey` if not already present and no input is active |
| `isRefetching` | `boolean` | Deferred loading state to avoid flicker on fast refetches |
| `handleInputChange` | `(value: string) => void` | Updates internal input state, triggering debounced refetch |
| `resetInput` | `() => void` | Clears the input (e.g. after selection) |
