Provides debounced, refetchable autocomplete suggestions for tag keys using a Relay refetchable fragment.

## Key Components

- **`useTagKeySuggestions(currentKey, keySuggestionsRef)`** — Main hook that manages tag key autocomplete state and Relay data fetching
- **`SUGGESTIONS_LIMIT`** — Caps results at 20 suggestions per query
- **`DEBOUNCE_MS`** — 300ms debounce delay applied to user input before triggering a refetch

## Behavior

- Debounces the user's search input before firing a Relay refetch (`store-or-network`)
- Wraps refetch in `useTransition` for non-blocking UI updates; defers the loading indicator via `useDeferredLoading`
- Ensures the `currentKey` value always appears in the options list even when absent from fetched suggestions (e.g. when input is empty and the key isn't in the top 20)

## Usage Example

```typescript
import { useTagKeySuggestions } from './use-tag-key-suggestions';

function TagKeyAutocomplete({ currentKey, fragmentRef }) {
  const { options, isRefetching, handleInputChange, resetInput } =
    useTagKeySuggestions(currentKey, fragmentRef);

  return (
    <Autocomplete
      options={options}
      loading={isRefetching}
      onInputChange={handleInputChange}
      onClose={resetInput}
    />
  );
}
```

## Return Value

| Property | Type | Description |
|---|---|---|
| `options` | `AutocompleteOption[]` | Merged list of fetched + current key suggestions |
| `isRefetching` | `boolean` | Deferred loading state for the refetch |
| `handleInputChange` | `(value: string) => void` | Updates the search input |
| `resetInput` | `() => void` | Clears search input (e.g. on dropdown close) |
