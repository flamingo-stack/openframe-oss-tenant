A multi-value autocomplete input component for selecting or creating tag values, backed by server-side suggestions fetched via `useTagValueSuggestions`.

## Key Components

- **`TagValueAutocomplete`** — Main exported component that wraps the core `Autocomplete` UI with tag-value-specific behavior
- **`TagValueAutocompleteProps`** — Interface defining the component's props:
  - `tagKey` — The tag key used to fetch relevant value suggestions
  - `values` — Currently selected values (controlled)
  - `onChange` — Callback fired when the selected values change
  - `error` — Optional validation error message
  - `label` — Optional input label
  - `className` — Optional CSS class override
- **`useTagValueSuggestions`** — Hook (external) providing debounced/async options, loading state, input change handler, and reset function

## Usage Example

```typescript
import { TagValueAutocomplete } from './tag-value-autocomplete';

function TagFilter() {
  const [selectedValues, setSelectedValues] = useState<string[]>([]);

  return (
    <TagValueAutocomplete
      tagKey="environment"
      values={selectedValues}
      onChange={setSelectedValues}
      label="Environment"
      error={selectedValues.length === 0 ? 'Required' : undefined}
    />
  );
}
```

## Behavior Notes

- Supports **multiple selection** and **free-text entry** (`freeSolo` + `creatable`) — users can type arbitrary values not present in suggestions
- Client-side filtering is **disabled** (`disableClientFilter`) — filtering is handled server-side via the suggestions hook
- The input is **reset** after each selection via `resetInput()`, clearing the search query without affecting selected values
- Placeholder adapts contextually: `"Add More..."` when values exist, `"Enter value..."` when empty
