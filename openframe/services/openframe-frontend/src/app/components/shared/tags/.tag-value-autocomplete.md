A multi-value autocomplete input component for filtering or tagging workflows, allowing users to search and select tag values associated with a specific tag key.

## Key Components

**`TagValueAutocomplete`** — Main exported component wrapping the shared `Autocomplete` UI primitive with tag-value-specific logic.

**Props (`TagValueAutocompleteProps`):**

| Prop | Type | Description |
|---|---|---|
| `tagKey` | `string` | The tag key used to fetch relevant value suggestions |
| `values` | `string[]` | Currently selected values |
| `onChange` | `(values: string[]) => void` | Callback fired when selection changes |
| `error` | `string?` | Optional validation error message |
| `label` | `string?` | Optional field label |
| `className` | `string?` | Optional CSS class override |

**`useTagValueSuggestions`** — Custom hook (external) that drives async suggestion fetching based on the provided `tagKey`.

## Behavior Notes

- Supports **multiple selections** rendered as chips/tags
- **`freeSolo` + `creatable`**: users can enter arbitrary values not present in suggestions
- **`disableClientFilter`**: filtering is handled server-side via the suggestions hook
- Input is reset via `resetInput()` after each selection change to clear the search query

## Usage Example

```typescript
import { TagValueAutocomplete } from './tag-value-autocomplete';

function FilterPanel() {
  const [selectedValues, setSelectedValues] = useState<string[]>([]);

  return (
    <TagValueAutocomplete
      tagKey="environment"
      values={selectedValues}
      onChange={setSelectedValues}
      label="Environment"
      error={selectedValues.length === 0 ? 'Required' : undefined}
    />
  );
}
```
