A multi-value autocomplete input for filtering or tagging by a specific tag key, fetching suggestions dynamically via `useTagValueSuggestions`.

## Key Components

- **`TagValueAutocomplete`** — Main component that renders a multi-select autocomplete field for entering tag values associated with a given `tagKey`
- **`TagValueAutocompleteProps`** — Interface defining:
  - `tagKey` — the tag key used to fetch relevant value suggestions
  - `values` — current selected values array
  - `onChange` — callback fired with the updated values array
  - `error` / `label` / `className` — optional display/styling props
- **`useTagValueSuggestions`** — Hook providing dynamic options, loading state, and input handlers for suggestion fetching
- **`handleChange`** — Memoized callback that resets the input field and propagates value changes upstream

## Usage Example

```typescript
import { TagValueAutocomplete } from './tag-value-autocomplete';

function TagFilter() {
  const [selectedValues, setSelectedValues] = useState<string[]>([]);

  return (
    <TagValueAutocomplete
      tagKey="environment"
      values={selectedValues}
      onChange={setSelectedValues}
      label="Environment"
      error={undefined}
    />
  );
}
```

## Notes

- Supports free-form entry (`freeSolo` + `creatable`) — users can type arbitrary values not present in suggestions
- Client-side filtering is disabled (`disableClientFilter`) — all filtering is handled server-side via the suggestions hook
- Placeholder text adapts based on whether values are already selected
