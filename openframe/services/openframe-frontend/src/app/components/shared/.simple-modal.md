A slot-based modal wrapper over `ModalV2*` primitives that conditionally renders header, content, and footer sections based on provided props.

## Key Components

**`SimpleModal`** — Main export. Accepts the following props:

| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls modal visibility |
| `onClose` | `() => void` | Close handler passed to `ModalV2` |
| `title` | `ReactNode` | Convenience prop — wrapped in `ModalV2Header` + `ModalV2Title` |
| `header` | `ReactNode` | Fully custom header — overrides `title` when provided |
| `children` | `ReactNode` | Modal body content |
| `contentClassName` | `string` | When set, wraps `children` in `ModalV2Content` with scrollable overflow |
| `footer` | `ReactNode` | Rendered inside `ModalV2Footer` (e.g. Cancel + confirm buttons) |
| `className` | `string` | Passed to outer `ModalV2` (e.g. `md:max-w-[600px]`) |

> For confirm/destructive flows, prefer `<ConfirmDialog>` — it wraps `SimpleModal` with built-in variant button styling and pending state.

## Usage Example

```typescript
// Basic modal with title and footer
<SimpleModal
  isOpen={isOpen}
  onClose={() => setIsOpen(false)}
  title="Edit Record"
  contentClassName="p-4"
  footer={
    <>
      <button onClick={() => setIsOpen(false)}>Cancel</button>
      <button onClick={handleSave}>Save</button>
    </>
  }
>
  <MyForm />
</SimpleModal>

// Custom header, no scroll container (short modal)
<SimpleModal
  isOpen={isOpen}
  onClose={onClose}
  header={<CustomHeaderWithIcon />}
  className="md:max-w-[400px]"
>
  <p>Short confirmation message.</p>
</SimpleModal>
```
