A slot-based modal wrapper over `ModalV2*` primitives that conditionally renders header, content, and footer sections based on provided props.

## Key Components

**`SimpleModal`** — Main exported component wrapping `ModalV2`, `ModalV2Header`, `ModalV2Content`, and `ModalV2Footer`.

**`SimpleModalProps`**

| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls modal visibility |
| `onClose` | `() => void` | Close handler |
| `title` | `ReactNode` | Convenience prop — wrapped in `ModalV2Title` automatically |
| `header` | `ReactNode` | Fully custom header — overrides `title` if both provided |
| `children` | `ReactNode` | Modal body content |
| `contentClassName` | `string` | When provided, wraps children in `ModalV2Content` (enables scrolling for long content) |
| `footer` | `ReactNode` | Rendered inside `ModalV2Footer` (typically action buttons) |
| `className` | `string` | Passed to outer `ModalV2` (e.g. `md:max-w-[600px]`) |

## Usage Example

```typescript
// Simple titled modal
<SimpleModal
  isOpen={isOpen}
  onClose={() => setIsOpen(false)}
  title="Edit User"
  contentClassName="p-4"
  footer={
    <>
      <button onClick={() => setIsOpen(false)}>Cancel</button>
      <button onClick={handleSave}>Save</button>
    </>
  }
>
  <UserForm user={user} />
</SimpleModal>

// Custom header, no scroll wrapper needed
<SimpleModal
  isOpen={isOpen}
  onClose={onClose}
  header={<CustomHeader icon={<AlertIcon />} title="Warning" />}
  className="md:max-w-[400px]"
>
  <p>Short confirmation message.</p>
</SimpleModal>
```

> **Note:** For confirm/destructive flows, prefer `<ConfirmDialog>` — it wraps `SimpleModal` with built-in variant button styling and pending state management.
