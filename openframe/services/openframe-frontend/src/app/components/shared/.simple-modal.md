A slot-based modal wrapper over `ModalV2*` primitives that conditionally renders header, content, and footer sections based on provided props.

## Key Components

### `SimpleModal`

| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | `boolean` | Controls modal visibility |
| `onClose` | `() => void` | Callback fired when modal requests close |
| `title` | `ReactNode` | Convenience prop — wrapped automatically in `ModalV2Header` + `ModalV2Title` |
| `header` | `ReactNode` | Fully custom header node — overrides `title` when provided |
| `children` | `ReactNode` | Modal body content |
| `contentClassName` | `string` | When provided, wraps `children` in `ModalV2Content` with this className (enables scrollable overflow); omit for short modals |
| `footer` | `ReactNode` | Rendered inside `ModalV2Footer` — typically Cancel + primary action buttons |
| `className` | `string` | Passed to the outer `ModalV2` (e.g. `md:max-w-[600px]`) |

## Usage Example

```typescript
// Simple title + scrollable content + footer
<SimpleModal
  isOpen={isOpen}
  onClose={() => setIsOpen(false)}
  title="Edit User"
  contentClassName="flex flex-col gap-4"
  footer={
    <>
      <Button variant="ghost" onClick={() => setIsOpen(false)}>Cancel</Button>
      <Button onClick={handleSave}>Save</Button>
    </>
  }
>
  <UserForm />
</SimpleModal>

// Custom header override
<SimpleModal
  isOpen={isOpen}
  onClose={onClose}
  header={<div className="flex items-center gap-2"><Icon /><h2>Custom Header</h2></div>}
  className="md:max-w-[800px]"
>
  <LargeContentComponent />
</SimpleModal>
```

> For confirm/destructive flows, prefer `<ConfirmDialog>` — it wraps `SimpleModal` with built-in variant button styling and pending state management.
