Entry point component that mounts `EmbeddableChat` inside OpenFrame's `AppLayoutDrawer` with full dialog management wired to the OpenFrame REST/GraphQL backend and NATS WebSocket for Mingo AI, running shell-less so the host drawer controls open/close state.

## Key Components

### `OpenframeEmbeddableChatEntry`

The sole exported component. Accepts two props and delegates all rendering to `EmbeddableChat` from `@flamingo-stack/openframe-frontend-core`.

| Prop | Type | Description |
|------|------|-------------|
| `open` | `boolean` | Controlled open state shared with the host `AppLayoutDrawer` |
| `onOpenChange` | `(open: boolean) => void` | Close handler called by the chat's X button to collapse the drawer |

### Internal Callbacks (all `useCallback`)

| Callback | Description |
|----------|-------------|
| `fetchDialogs` | Paginates dialog list via GraphQL with agent-type filter |
| `fetchDialogMessages` | Loads messages DESC, reverses to chronological, hydrates token usage on first page only |
| `createDialog` | POSTs to `/chat/api/v1/dialogs` with `ADMIN` agent type |
| `publishUserMessage` | POSTs message with `ADMIN_AI_CHAT` chat type |
| `approveRequest` / `rejectRequest` | Approves or rejects approval-request items |
| `stopGeneration` | Cancels in-flight assistant generation for a dialog |

### Mode Configuration

- **`modes.guide`** — SSE/Guide mode; reads config from the ambient runtime provider, activated by passing `{}`
- **`modes.mingo`** — NATS/Mingo mode; wired via `useNatsAppConfig().getWsUrl` and all callbacks above

## Usage Example

```typescript
// Inside AppLayoutDrawer (host)
import { OpenframeEmbeddableChatEntry } from '@/components/openframe-embeddable-chat-entry';

function AppLayoutDrawer() {
  const [chatOpen, setChatOpen] = useState(false);

  return (
    <>
      <button onClick={() => setChatOpen(true)}>Ask AI</button>
      <Drawer open={chatOpen} onOpenChange={setChatOpen}>
        <OpenframeEmbeddableChatEntry
          open={chatOpen}
          onOpenChange={setChatOpen}
        />
      </Drawer>
    </>
  );
}
```

> **Migration note:** Coexists with the legacy `/mingo` page route during the chat architecture migration. The `dialogId: null` shim in `mingoModeConfig` is a compatibility stub for `@flamingo-stack/openframe-frontend-core` ≤ 0.0.215 and should be removed once the package is bumped.
