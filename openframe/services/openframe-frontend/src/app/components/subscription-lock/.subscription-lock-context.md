Provides a React context for managing subscription lock state, exposing the current subscription status, lock copy, and locked flag to child components.

## Key Components

- **`SubscriptionLockState`** — Interface holding `status`, `lockCopy`, and `isLocked` derived from the subscription status
- **`SubscriptionLockProvider`** — Context provider that computes lock state via `getLockCopy` and memoizes the value on `status` changes
- **`useSubscriptionLock`** — Hook to consume lock state; returns a safe default (`ACTIVE`, unlocked) when used outside the provider

## Usage Example

```typescript
// Wrap a feature area with the provider
function BillingPage({ subscriptionStatus }: { subscriptionStatus: SubscriptionStatus }) {
  return (
    <SubscriptionLockProvider status={subscriptionStatus}>
      <FeatureContent />
    </SubscriptionLockProvider>
  );
}

// Consume lock state in any child component
function FeatureContent() {
  const { isLocked, lockCopy } = useSubscriptionLock();

  if (isLocked) {
    return <LockScreen message={lockCopy?.heading} />;
  }

  return <ActiveFeature />;
}
```

> **Note:** `useSubscriptionLock` is safe to call outside a provider — it falls back to `{ status: 'ACTIVE', lockCopy: null, isLocked: false }` instead of throwing, making it suitable for shared components that may render in both locked and unlocked contexts.
