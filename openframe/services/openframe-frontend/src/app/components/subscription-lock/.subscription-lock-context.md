Provides a React context for managing subscription lock state, exposing the current subscription status, lock copy messaging, and whether the subscription is locked.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `SubscriptionLockProvider` | Component | Wraps children with subscription lock context, computing lock state from a given `SubscriptionStatus` |
| `useSubscriptionLock` | Hook | Consumes the lock context; returns a safe default (`ACTIVE`, unlocked) if used outside the provider |
| `SubscriptionLockState` | Interface | Internal shape: `{ status, lockCopy, isLocked }` |

## Usage Example

```typescript
// Wrap your feature tree with the provider
import { SubscriptionLockProvider } from './subscription-lock-context';

function App({ subscriptionStatus }) {
  return (
    <SubscriptionLockProvider status={subscriptionStatus}>
      <FeaturePage />
    </SubscriptionLockProvider>
  );
}

// Consume lock state anywhere in the tree
import { useSubscriptionLock } from './subscription-lock-context';

function FeaturePage() {
  const { isLocked, lockCopy } = useSubscriptionLock();

  if (isLocked) {
    return <LockedBanner message={lockCopy?.heading} />;
  }

  return <ActiveFeatureContent />;
}
```

## Behavior Notes

- `getLockCopy(status)` drives lock detection — if it returns `null`, `isLocked` is `false`.
- State is memoized on `status` to prevent unnecessary re-renders.
- `useSubscriptionLock` is safe to call without a provider; it defaults to `{ status: 'ACTIVE', lockCopy: null, isLocked: false }`.
