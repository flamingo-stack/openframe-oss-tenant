Provides a React context for managing subscription lock state, exposing the current subscription status, lock copy (UI strings), and whether the subscription is locked throughout the component tree.

## Key Components

- **`SubscriptionLockProvider`** — Wraps children with subscription lock context; derives `lockCopy` and `isLocked` from the provided `status` via `getLockCopy`, memoized on status changes.
- **`useSubscriptionLock`** — Hook to consume subscription lock state; returns a safe default (`ACTIVE`, unlocked) when used outside the provider.
- **`SubscriptionLockState`** — Internal interface containing `status`, `lockCopy`, and `isLocked`.

## Usage Example

```typescript
// Wrap your app or page with the provider
function AppLayout({ subscriptionStatus, children }) {
  return (
    <SubscriptionLockProvider status={subscriptionStatus}>
      {children}
    </SubscriptionLockProvider>
  );
}

// Consume lock state in any child component
function FeaturePanel() {
  const { isLocked, lockCopy } = useSubscriptionLock();

  if (isLocked) {
    return <p>{lockCopy?.message ?? 'Subscription required.'}</p>;
  }

  return <div>Feature content</div>;
}
```

> **Note:** `useSubscriptionLock` gracefully defaults to `{ status: 'ACTIVE', lockCopy: null, isLocked: false }` when called outside a `SubscriptionLockProvider`, so components remain functional in unguarded contexts.
