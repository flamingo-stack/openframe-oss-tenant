Re-exports the `SubscriptionStatus` enum and provides utilities for resolving subscription states and retrieving lock-screen copy for the OpenFrame billing/access-control flow.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `SubscriptionStatus` | Enum (re-export) | Backend-sourced enum with values: `ACTIVE`, `TRIAL`, `TRIAL_EXPIRED`, `CANCELED`, `PAST_DUE`, `SUSPENDED` |
| `SubscriptionLockCopy` | Interface | Shape for full-screen lock UI copy (`title`, `description`, `ctaLabel`) |
| `resolveSubscriptionStatus` | Function | Normalizes a raw string to a valid `SubscriptionStatus`, falling back to `ACTIVE` |
| `getLockCopy` | Function | Returns lock-screen copy for a given status, or `null` if the status does not lock the app |

## Status Behavior

| Status | Behavior |
|--------|----------|
| `ACTIVE`, `TRIAL` | Normal app access |
| `TRIAL_EXPIRED`, `CANCELED` | Full lock screen shown |
| `PAST_DUE`, `SUSPENDED` | Inline warning on billing page only; app remains accessible |

## Usage Example

```typescript
import { resolveSubscriptionStatus, getLockCopy } from '@/lib/subscription-status';

// Normalize a raw API value
const status = resolveSubscriptionStatus(org.subscriptionStatus);
// → SubscriptionStatus.TRIAL_EXPIRED (or ACTIVE if unrecognized)

// Get lock-screen copy
const copy = getLockCopy(status);
if (copy) {
  // Render full-screen gate
  showLockScreen(copy.title, copy.description, copy.ctaLabel);
}
```

> `TRIAL` and `TRIAL_EXPIRED` are first-class backend values — the frontend no longer derives trial state from dates.
