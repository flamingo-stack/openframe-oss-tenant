Re-exports the `SubscriptionStatus` enum and provides helpers for resolving raw status strings and retrieving lock-screen copy for paywalled subscription states in the OpenFrame frontend.

## Key Components

- **`SubscriptionStatus`** — Re-exported enum mirroring the backend GraphQL schema. Key values: `ACTIVE`, `TRIAL`, `TRIAL_EXPIRED`, `CANCELED`, `PAST_DUE`, `SUSPENDED`.
- **`SubscriptionLockCopy`** — Interface defining the `title`, `description`, and `ctaLabel` strings shown on the full-app lock screen.
- **`LOCK_COPY`** — Static copy map for lock-triggering statuses (`TRIAL_EXPIRED`, `CANCELED`). `PAST_DUE` and `SUSPENDED` are handled separately on the billing page (inline, no full lock).
- **`resolveSubscriptionStatus(rawStatus)`** — Safely coerces a raw string (e.g. from an API response) to a known `SubscriptionStatus`, falling back to `ACTIVE` for unknown/null values.
- **`getLockCopy(status)`** — Returns the `SubscriptionLockCopy` for lock-triggering statuses, or `null` if the status does not warrant a lock screen.

## Usage Example

```typescript
import { resolveSubscriptionStatus, getLockCopy } from '@/lib/subscription-status';

const status = resolveSubscriptionStatus(user.subscriptionStatus);

const lockCopy = getLockCopy(status);

if (lockCopy) {
  // Render full-app lock screen
  showLockScreen(lockCopy.title, lockCopy.description, lockCopy.ctaLabel);
} else {
  // User has access — render the app normally
  renderApp();
}
```

> `PAST_DUE` and `SUSPENDED` do **not** produce lock copy — they display an inline "Pay Overage" CTA on the billing page while preserving full app access.
