Re-exports and extends the `SubscriptionStatus` enum with helpers for resolving raw status strings and retrieving UI copy for subscription lock screens.

## Key Components

- **`SubscriptionStatus`** — Re-exported backend enum (`ACTIVE`, `TRIAL`, `TRIAL_EXPIRED`, `PAST_DUE`, `SUSPENDED`, `CANCELED`). Values are sourced from `schema.graphql` via `npm run generate-enums`.
- **`SubscriptionLockCopy`** — Interface defining `title`, `description`, and `ctaLabel` strings shown on full-screen subscription gates.
- **`LOCK_COPY`** — Static map of lock-screen UI copy for `TRIAL_EXPIRED` and `CANCELED` statuses (the two states that fully block app access).
- **`resolveSubscriptionStatus(rawStatus)`** — Safely coerces an unknown string into a valid `SubscriptionStatus`, falling back to `ACTIVE` for unrecognized or nullish values.
- **`getLockCopy(status)`** — Returns the `SubscriptionLockCopy` for a locking status, or `null` if the status does not trigger a lock screen.

## Usage Example

```typescript
import { resolveSubscriptionStatus, getLockCopy } from './subscription-status';

const status = resolveSubscriptionStatus(user.subscriptionStatus);
// e.g. 'TRIAL_EXPIRED' → SubscriptionStatus.TRIAL_EXPIRED
//      null            → SubscriptionStatus.ACTIVE

const copy = getLockCopy(status);
if (copy) {
  // Render full-screen gate
  renderLockScreen(copy.title, copy.description, copy.ctaLabel);
}
// PAST_DUE / SUSPENDED → getLockCopy returns null (inline billing CTA instead)
```

> **Lock behaviour:** `TRIAL_EXPIRED` and `CANCELED` trigger the full subscribe screen. `PAST_DUE` and `SUSPENDED` keep app access and show an inline "Pay Overage" CTA on the billing page.
