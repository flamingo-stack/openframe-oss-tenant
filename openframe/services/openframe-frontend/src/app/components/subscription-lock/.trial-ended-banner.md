A client-side banner component that displays a trial-ended message using subscription lock copy data.

## Key Components

- **`TrialEndedBanner`** — Renders a styled heading and description when a user's trial has expired, driven by externally provided copy.
- **`TrialEndedBannerProps`** — Interface accepting a `lockCopy` object of type `SubscriptionLockCopy` containing `title` and `description` strings.

## Usage Example

```typescript
import { TrialEndedBanner } from './trial-ended-banner';

const lockCopy = {
  title: 'Your trial has ended',
  description: 'Upgrade your plan to continue using Flamingo.',
};

<TrialEndedBanner lockCopy={lockCopy} />
```
