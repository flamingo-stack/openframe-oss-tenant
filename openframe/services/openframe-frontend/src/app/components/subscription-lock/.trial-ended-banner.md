Renders a banner UI component displayed when a user's trial subscription has ended, showing a title and description from provided lock copy.

## Key Components

- **`TrialEndedBanner`** — Client component that accepts `lockCopy` and renders a styled heading and description paragraph
- **`TrialEndedBannerProps`** — Interface requiring a `lockCopy` prop of type `SubscriptionLockCopy`

## Usage Example

```typescript
import { TrialEndedBanner } from './trial-ended-banner';

<TrialEndedBanner
  lockCopy={{
    title: 'Your trial has ended',
    description: 'Upgrade your plan to continue using all features.',
  }}
/>
```
