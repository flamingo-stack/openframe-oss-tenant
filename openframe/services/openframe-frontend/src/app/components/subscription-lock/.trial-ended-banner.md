Renders a banner UI component displayed when a user's trial subscription has ended, showing a title and description from the provided lock copy.

## Key Components

- **`TrialEndedBanner`** — Client component that accepts a `SubscriptionLockCopy` object and renders a styled heading and description paragraph.
- **`TrialEndedBannerProps`** — Interface requiring a `lockCopy` prop of type `SubscriptionLockCopy` (imported from `subscription-status`).

## Usage Example

```typescript
import { TrialEndedBanner } from './trial-ended-banner';

const lockCopy = {
  title: 'Your trial has ended',
  description: 'Upgrade your plan to continue using all features.',
};

<TrialEndedBanner lockCopy={lockCopy} />
```
