Renders the subscription management UI as a full-page overlay when a tenant is locked out of the application (e.g., trial expired, subscription canceled).

## Key Components

- **`SubscriptionLockContent`** — Client component that wraps `SubscriptionSettingsView` in a `Suspense` boundary, displaying `SubscriptionSettingsSkeleton` while data loads. The view adapts its appearance based on lock state via context, replacing the standard header with a "trial has ended" banner and updating the submit CTA.

## Usage Example

```typescript
// Rendered automatically by the lock-gate layer when tenant access is restricted
import { SubscriptionLockContent } from './subscription-lock-content';

export default function LockedPage() {
  return <SubscriptionLockContent />;
}
```

## Notes

- Reuses the full `SubscriptionSettingsView` rather than a separate locked-state component — no data duplication.
- Lock-aware UI changes (banner, CTA) are driven by context inside `SubscriptionSettingsView`, not by props passed here.
- The `Suspense` fallback ensures a consistent skeleton is shown during async data fetching.
