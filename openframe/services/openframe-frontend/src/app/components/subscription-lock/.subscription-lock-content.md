Renders the subscription management UI as a full-page overlay when a tenant is locked out of the application (e.g., trial expired, subscription canceled). Reuses `SubscriptionSettingsView` with a `Suspense` boundary, relying on context to adapt the view into a lock-state experience.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `SubscriptionLockContent` | React Component | Root component displayed during tenant lockout; wraps subscription settings in a `Suspense` boundary |
| `SubscriptionSettingsView` | (imported) | Shared subscription settings view that adapts its header/CTA when lock context is active |
| `SubscriptionSettingsSkeleton` | (imported) | Loading fallback shown while subscription data is fetching |

## Usage Example

```typescript
// Rendered at the app layout level when tenant lock state is detected
import { SubscriptionLockContent } from './subscription-lock-content';

export function AppShell({ isLocked }: { isLocked: boolean }) {
  if (isLocked) {
    return <SubscriptionLockContent />;
  }
  return <MainAppContent />;
}
```

## Behavior Notes

- **No new data fetching** — reuses the same `SubscriptionSettingsView` component as the billing settings page; lock-aware UI changes (banner swap, CTA label) are driven by subscription context, not props
- **Suspense boundary** — displays `SubscriptionSettingsSkeleton` while async subscription data resolves, preventing layout shift during load
- **Client component** — marked `'use client'` to support context consumption and interactive subscription management actions
