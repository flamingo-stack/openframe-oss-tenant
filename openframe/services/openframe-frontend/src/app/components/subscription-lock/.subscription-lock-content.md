Renders the subscription management UI as a full-page lock screen when a tenant's access is restricted (e.g., trial expired, subscription canceled), reusing `SubscriptionSettingsView` which adapts its presentation based on lock state via context.

## Key Components

- **`SubscriptionLockContent`** — Client component that wraps `SubscriptionSettingsView` in a `Suspense` boundary, displaying `SubscriptionSettingsSkeleton` during async data loading. The underlying view detects lock state via context to swap its header for a "trial has ended" banner and update the CTA.

## Usage Example

```typescript
// Rendered at the app layout level when tenant is locked out
import { SubscriptionLockContent } from './subscription-lock-content';

export default function LockedLayout() {
  return (
    <main>
      <SubscriptionLockContent />
    </main>
  );
}
```

## Notes

- Relies on `SubscriptionSettingsView` consuming a lock-state context — no additional props required.
- The skeleton fallback matches the full settings card layout, preventing layout shift during load.
