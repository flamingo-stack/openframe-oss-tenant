Bridges Relay's preloaded GraphQL query data with the OpenFrame notifications store by hydrating it on mount/update.

## Key Components

- **`NotificationsListHydrator`** — Public entry component; guards against null/undefined `queryRef` before rendering the inner hydrator.
- **`HydratorInner`** — Consumes the preloaded Relay query, maps raw GraphQL edges into normalized notification objects via `mapNotificationNode`, and syncs them into the global notifications store via `setNotifications`.
- **`NotificationsListHydratorProps`** — Interface accepting a nullable `PreloadedQuery<NotificationsListQueryType>` ref.

## Usage Example

```typescript
import { NotificationsListHydrator } from './notifications-list-hydrator';
import { useQueryLoader } from 'react-relay';
import { notificationsListQuery } from '@/graphql/notifications/notifications-list-query';

function NotificationsProvider() {
  const [queryRef, loadQuery] = useQueryLoader(notificationsListQuery);

  useEffect(() => {
    loadQuery({});
  }, [loadQuery]);

  return (
    <>
      {/* Renders nothing to the DOM — side-effect only */}
      <NotificationsListHydrator queryRef={queryRef} />
      <NotificationsBell />
    </>
  );
}
```

## Notes

- **Render-nothing pattern** — Both components return `null`; this is a pure data-sync component with no UI output.
- **Memoized mapping** — `useMemo` prevents re-mapping edges on unrelated re-renders; `useEffect` ensures the store is updated only when the derived list reference changes.
- The null guard on `queryRef` keeps the component safe during the initial load window before the query has been preloaded.
