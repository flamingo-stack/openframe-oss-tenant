Initializes deployment environment detection at app startup, setting HTML attributes for deployment context and logging deployment metadata once the app mounts.

## Key Components

- **`DeploymentInitializer`** — A side-effect-only React component (renders `null`) that consumes the `useDeployment` hook and runs initialization logic once deployment is detected.

## Behavior

- Reads `isInitialized` and `deployment` from `useDeployment()`
- On initialization, logs deployment metadata to the console
- Attaches `data-deployment` and `data-hostname` attributes to `document.documentElement` for CSS styling or debugging

## Usage Example

```typescript
// app/layout.tsx — Place at root layout level
import { DeploymentInitializer } from '@/components/deployment-initializer';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>
        <DeploymentInitializer />
        {children}
      </body>
    </html>
  );
}
```

After initialization, the `<html>` element will carry deployment context:

```html
<html data-deployment="cloud" data-hostname="app.flamingo.run">
```

These attributes can be used in CSS for environment-specific styling:

```css
[data-deployment="development"] .env-badge {
  display: block;
}
```

> **Note:** This component is marked `'use client'` and is safe to include in Next.js App Router layouts. It produces no DOM output and has no visible rendering impact.
