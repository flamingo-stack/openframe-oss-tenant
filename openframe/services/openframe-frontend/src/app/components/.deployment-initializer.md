Initializes deployment detection at application startup by consuming the `useDeployment` hook and attaching deployment metadata to the document root for debugging and conditional styling.

## Key Components

- **`DeploymentInitializer`** — Side-effect-only React component (renders `null`) that runs once on mount to detect and record the current deployment context.

## Behavior

- Consumes `useDeployment()` to access `isInitialized` and `deployment` state
- Once initialized, logs deployment info (`type`, `hostname`, `isCloud`, `isSelfHosted`, `isDevelopment`) to the console
- Sets `data-deployment` and `data-hostname` attributes on `<html>` for CSS targeting and runtime debugging
- Safe for SSR — guards `document` access with `typeof document !== 'undefined'`

## Usage Example

Place once at the application root (e.g., `layout.tsx`):

```typescript
import { DeploymentInitializer } from '@/components/deployment-initializer';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>
        <DeploymentInitializer />
        {children}
      </body>
    </html>
  );
}
```

After initialization, the `<html>` element will have attributes available for CSS:

```css
/* Target cloud deployments */
[data-deployment="cloud"] .cloud-only {
  display: block;
}

/* Target self-hosted instances */
[data-deployment="self-hosted"] .self-hosted-banner {
  display: flex;
}
```

> **Note:** This component must be used within a provider that exposes `useDeployment`. It is a client component (`'use client'`) and should only be rendered once at the root layout level.
