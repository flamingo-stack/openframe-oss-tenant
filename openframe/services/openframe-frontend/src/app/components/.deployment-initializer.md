Initializes deployment detection on application mount, setting HTML attributes for deployment context and logging environment details once the deployment state is resolved.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `DeploymentInitializer` | React Component | Headless component that bootstraps deployment detection at app root |

### Behavior

- Consumes `useDeployment` hook to access `isInitialized` and `deployment` state
- On initialization, sets `data-deployment` and `data-hostname` attributes on `<html>` for CSS targeting and debugging
- Logs deployment context (type, hostname, cloud/self-hosted/dev flags) to the console once on mount
- Renders `null` — no DOM output

## Usage Example

Place once at the application root (e.g. root layout):

```typescript
import { DeploymentInitializer } from '@/components/deployment-initializer';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>
        <DeploymentInitializer />
        {children}
      </body>
    </html>
  );
}
```

After initialization, the `<html>` element will carry:

```html
<html data-deployment="cloud" data-hostname="app.flamingo.run">
```

These attributes can be used in CSS for deployment-specific styling:

```css
[data-deployment="self-hosted"] .cloud-only {
  display: none;
}
```

> **Note:** This component is marked `'use client'` and should only be mounted once at the root level. It depends on the `useDeployment` hook resolving its state before attributes are applied.
