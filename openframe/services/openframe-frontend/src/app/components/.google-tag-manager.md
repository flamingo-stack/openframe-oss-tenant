Client-side React component that injects Google Tag Manager (GTM) scripts into a Next.js application, supporting both JavaScript and no-script environments.

## Key Components

- **`GoogleTagManager`** — React component that renders the GTM loader script and a `<noscript>` iframe fallback
- **`GoogleTagManagerProps`** — Interface accepting an optional `containerId` override; falls back to `runtimeEnv.gtmContainerId()` if not provided
- **`dataLayer` initialization** — Ensures `window.dataLayer` array exists via `useEffect` before GTM loads

## Usage Example

```typescript
// In your root layout (app/layout.tsx)
import { GoogleTagManager } from '@/components/google-tag-manager';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html>
      <body>
        {/* Uses GTM_CONTAINER_ID from runtime env by default */}
        <GoogleTagManager />

        {/* Or pass a container ID explicitly */}
        <GoogleTagManager containerId="GTM-XXXXXXX" />

        {children}
      </body>
    </html>
  );
}
```

## Behavior Notes

- Renders `null` silently if no container ID is found (safe for non-production or unconfigured environments)
- Script loads with `strategy="afterInteractive"` to avoid blocking page render
- Includes a `<noscript>` iframe fallback for browsers with JavaScript disabled
- Container ID is sourced at runtime via `runtimeEnv.gtmContainerId()`, supporting dynamic configuration without a rebuild
