Client-side React component that injects the Google Tag Manager (GTM) snippet into a Next.js application, supporting both JavaScript and `<noscript>` fallback loading.

## Key Components

- **`GoogleTagManagerProps`** — Interface accepting an optional `containerId` string to override the default GTM container ID.
- **`GoogleTagManager`** — Named export component that renders the GTM loader script and `<noscript>` iframe fallback. Falls back to `runtimeEnv.gtmContainerId()` when no `containerId` prop is provided. Returns `null` if no container ID is resolved.
- **`dataLayer` initialization** — `useEffect` ensures `window.dataLayer` is initialized as an array when a valid container ID is present.

## Usage Example

```typescript
// app/layout.tsx
import { GoogleTagManager } from '@/components/google-tag-manager';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <head>
        {/* Uses GTM_CONTAINER_ID from runtime environment */}
        <GoogleTagManager />

        {/* Or pass an explicit container ID */}
        <GoogleTagManager containerId="GTM-XXXXXXX" />
      </head>
      <body>{children}</body>
    </html>
  );
}
```

> The script loads with `strategy="afterInteractive"` (Next.js Script API), deferring execution until after the page becomes interactive to avoid blocking initial render. The `<noscript>` iframe ensures basic tag firing for users with JavaScript disabled.
