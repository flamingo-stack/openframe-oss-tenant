React component that injects Google Tag Manager (GTM) scripts into a Next.js application, supporting both JavaScript-enabled and no-script environments.

## Key Components

- **`GoogleTagManagerProps`** — Interface with an optional `containerId` string prop
- **`GoogleTagManager`** — Client component that renders the GTM loader script and a `<noscript>` iframe fallback
- **`runtimeEnv.gtmContainerId()`** — Runtime config fallback used when no `containerId` prop is provided
- **`window.dataLayer`** — Initialized via `useEffect` to ensure it exists before GTM events fire

## Behavior

- Returns `null` if no container ID is resolved (prop or runtime env), making it safe to include unconditionally in layouts
- Uses Next.js `<Script strategy="afterInteractive">` to defer GTM loading until after hydration
- Includes a `<noscript>` iframe fallback for environments with JavaScript disabled

## Usage Example

```typescript
// app/layout.tsx
import { GoogleTagManager } from '@/components/google-tag-manager';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html>
      <body>
        {/* Uses GTM_CONTAINER_ID from runtime env automatically */}
        <GoogleTagManager />

        {/* Or pass a container ID explicitly */}
        <GoogleTagManager containerId="GTM-XXXXXXX" />

        {children}
      </body>
    </html>
  );
}
```

> The container ID resolution order is: explicit `containerId` prop → `runtimeEnv.gtmContainerId()` → render nothing.
