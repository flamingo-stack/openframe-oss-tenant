Full-screen overlay component displayed when a user is unauthenticated, prompting them to sign in or retry authentication.

## Key Components

- **`UnauthorizedOverlay`** — Client-side React component that renders a centered sign-in prompt. Redirects to the configured auth login URL via `runtimeEnv.authLoginUrl()`, falling back to an optional `onRetry` callback if no URL is available.

### Props

| Prop | Type | Description |
|------|------|-------------|
| `onRetry` | `() => void` (optional) | Fallback handler invoked when no auth login URL is configured |

## Usage Example

```typescript
import { UnauthorizedOverlay } from './unauthorized-overlay';

// Basic usage — redirects to configured auth URL
<UnauthorizedOverlay />

// With retry fallback
<UnauthorizedOverlay onRetry={() => refetchSession()} />
```

> **Note:** The component reads the login URL from `runtimeEnv.authLoginUrl()`. If the runtime config returns a valid URL, clicking **Sign in** performs a hard redirect (`window.location.href`). Otherwise, `onRetry` is called as a fallback.
