Full-screen overlay component displayed when a user attempts to access a protected route without authentication. Redirects to the configured auth login URL or triggers an optional retry callback.

## Key Components

- **`UnauthorizedOverlay`** — Default export React component that renders a centered sign-in prompt
- **`UnauthorizedOverlayProps`** — Interface accepting an optional `onRetry` callback used as a fallback when no login URL is configured
- **`handleLogin`** — Redirects to `runtimeEnv.authLoginUrl()` if available; falls back to invoking `onRetry`

## Usage Example

```typescript
import { UnauthorizedOverlay } from './unauthorized-overlay';

// Basic usage — redirects to configured auth login URL
<UnauthorizedOverlay />

// With retry fallback (e.g., re-fetch session)
<UnauthorizedOverlay onRetry={() => refetchSession()} />
```

> The login URL is resolved at runtime via `runtimeEnv.authLoginUrl()`, keeping auth configuration environment-specific without requiring a build-time change.
