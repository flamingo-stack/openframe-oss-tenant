Full-screen overlay displayed when a user is unauthenticated, prompting them to sign in or retry access.

## Key Components

- **`UnauthorizedOverlay`** — Client-side React component that renders a centered sign-in prompt. Redirects to the configured auth login URL via `runtimeEnv.authLoginUrl()`, falling back to an optional `onRetry` callback if no URL is available.

### Props

| Prop | Type | Description |
|------|------|-------------|
| `onRetry` | `() => void` (optional) | Fallback callback invoked when no login URL is configured |

## Usage Example

```typescript
import { UnauthorizedOverlay } from './unauthorized-overlay';

// Basic usage — redirects to auth login URL
<UnauthorizedOverlay />

// With retry fallback
<UnauthorizedOverlay onRetry={() => refetchSession()} />
```

## Behavior

- Reads the login URL from `runtimeEnv.authLoginUrl()` at render time
- On button click, navigates to the login URL via `window.location.href`
- If no login URL is configured, calls `onRetry` instead (no-op if neither is provided)
