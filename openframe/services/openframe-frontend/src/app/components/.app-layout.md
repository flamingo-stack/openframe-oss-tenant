Root client layout component that wraps authenticated app pages with navigation shell, auth guards, subscription enforcement, and the Mingo AI chat drawer.

## Key Components

| Export / Component | Purpose |
|---|---|
| `AppLayout` | Public export — wraps `AppLayoutInner` in `<Suspense>` with an `AppShellSkeleton` fallback |
| `AppLayoutInner` | Auth state machine — handles loading, redirect, OSS/SaaS mode branching, and `SubscriptionGuard` |
| `AppShell` | Full UI shell — composes `CoreAppLayout` with sidebar, header, mobile burger menu, and Mingo AI drawer |
| `ContentLoading` | Inline `<CompactPageLoader />` used as the route-level loading fallback |

## Key Behaviors

- **Multi-mode auth routing** — detects `isOssTenantMode`, `isSaasTenantMode`, and `isAuthOnlyMode` to branch between redirect, overlay, or passthrough rendering
- **Subscription lock** — uses `useSubscriptionLock` to replace page content with `SubscriptionLockContent` when locked; checkout result pages are exempt
- **Mingo AI drawer** — gated by `featureFlags.mingoSidebar`; renders a resizable right-side `AppLayoutDrawer` hosting `OpenframeEmbeddableChatEntry`; suppressed when subscription is locked
- **Navigation** — `getNavigationItems(pathname)` drives the sidebar; memoized on route change

## Usage Example

```typescript
// app/(app)/layout.tsx
import { AppLayout } from '@/components/app-layout';

export default function Layout({ children }: { children: React.ReactNode }) {
  return (
    <AppLayout mainClassName="pb-20 md:pb-20">
      {children}
    </AppLayout>
  );
}
```

> `mainClassName` overrides the default bottom padding on the `<main>` element — useful for pages that render a sticky bottom bar or full-bleed content.
