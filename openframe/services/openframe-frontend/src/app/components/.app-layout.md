Root layout wrapper that handles authentication state, subscription gating, and the Mingo AI chat drawer for the OpenFrame application shell.

## Key Components

**`AppLayout`** *(exported)*
Top-level entry point. Wraps `AppLayoutInner` in a `Suspense` boundary with an `AppShellSkeleton` fallback.

**`AppLayoutInner`**
Handles authentication routing logic:
- Shows `AppShellSkeleton` while auth is loading
- In `auth-only` mode, renders children directly (no shell)
- In OSS mode, redirects unauthenticated users to `/auth`
- In SaaS mode, renders `UnauthorizedOverlay` for unauthenticated users
- Wraps authenticated users in `SubscriptionGuard` → `AppShell`

**`AppShell`**
The full interactive shell. Composes `CoreAppLayout` with:
- Sidebar navigation (path-aware via `getNavigationItems`)
- Header with user profile, logout, notifications, and Mingo AI launcher
- Resizable right-side `AppLayoutDrawer` hosting the `OpenframeEmbeddableChatEntry`
- `SubscriptionLockContent` overlay when subscription is locked (except on `/checkout` pages)

## Usage Example

```typescript
// app/layout.tsx or a nested route layout
import { AppLayout } from '@/components/app-layout';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <AppLayout mainClassName="pb-20 md:pb-20">
      {children}
    </AppLayout>
  );
}
```

## Props

| Prop | Type | Description |
|------|------|-------------|
| `children` | `React.ReactNode` | Page content to render inside the shell |
| `mainClassName` | `string?` | Optional override for the main content area CSS class |

## Feature Flags

| Flag | Effect |
|------|--------|
| `mingoSidebar` | Enables the Mingo AI chat launcher + drawer |
| `notifications` | Shows the notification bell in the header |
