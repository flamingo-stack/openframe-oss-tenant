Root layout wrapper that handles authentication state, app mode detection, and navigation shell rendering for the OpenFrame frontend.

## Key Components

- **`AppLayout`** *(exported)* — Top-level entry point wrapping children in `Suspense` with an `AppShellSkeleton` fallback.
- **`AppLayoutInner`** — Orchestrates auth state checks, mode-based routing (`OSS`, `SaaS`, `auth-only`), and subscription guard mounting.
- **`AppShell`** — Renders the `CoreAppLayout` with sidebar navigation, header, and mobile burger menu; conditionally shows `SubscriptionLockContent` when subscription is locked.
- **`ContentLoading`** — Minimal loading indicator used as the in-shell page transition fallback.

## Behavior by App Mode

| Mode | Unauthenticated | Authenticated |
|------|----------------|---------------|
| OSS Tenant | Redirect → `/auth` + skeleton | Full shell |
| SaaS Tenant | `UnauthorizedOverlay` | Full shell |
| Auth-only | Render children directly | Render children directly |

## Usage Example

```typescript
// app/layout.tsx
import { AppLayout } from '@/components/app-layout/app-layout';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <AppLayout mainClassName="custom-main-class">
      {children}
    </AppLayout>
  );
}
```

## Notes

- Reads user identity (`firstName`, `lastName`, `email`, `role`, `image`) from `useAuthStore`.
- Navigation items are recomputed on every `pathname` change via `getNavigationItems`.
- Feature flag `featureFlags.notifications.enabled()` controls notification bell visibility in the header.
- Subscription lock state is sourced from `useSubscriptionLock` context; when locked, sidebar is disabled and content is replaced with `SubscriptionLockContent`.
