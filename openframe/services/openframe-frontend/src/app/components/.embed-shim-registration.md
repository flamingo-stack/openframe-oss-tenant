Client-side component that triggers embed shim registration on mount by calling `registerEmbedShims()` from the shim registration library.

## Key Components

- **`EmbedShimRegistration`** — A render-less React component (`returns null`) whose sole purpose is to invoke `registerEmbedShims()` at the module level when the client bundle loads.
- **`registerEmbedShims()`** — Imported from `@/lib/register-embed-shims`; executes shim setup logic for embed handlers (YouTube, Reddit, Tweet, etc.).

## Usage Example

Mount once in a client boundary layout to ensure shims are registered globally before any embed rendering occurs:

```typescript
import { EmbedShimRegistration } from '@/components/embed-shim-registration';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html>
      <body>
        <EmbedShimRegistration />
        {children}
      </body>
    </html>
  );
}
```

> **Note:** The `registerEmbedShims()` call runs at module evaluation time (outside the component body), so shims are registered as soon as the chunk is loaded — not deferred to React's render cycle.
