Client-side component that triggers embed shim registration on mount by calling `registerEmbedShims()` from the shim registration library.

## Key Components

- **`EmbedShimRegistration`** — A render-nothing React component (`return null`) whose sole purpose is to invoke `registerEmbedShims()` at module load time on the client side.
- **`registerEmbedShims()`** — Imported from `@/lib/register-embed-shims`; handles the actual shim setup (e.g., registering custom embed handlers for YouTube, Reddit, Tweet, etc.).

## Usage Example

Mount this component once, high in the component tree (e.g., in a root layout), to ensure shims are registered before any embed rendering occurs:

```typescript
import { EmbedShimRegistration } from '@/components/embed-shim-registration';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html>
      <body>
        <EmbedShimRegistration />
        {children}
      </body>
    </html>
  );
}
```

> **Note:** The `'use client'` directive ensures this runs exclusively in the browser, preventing SSR execution of shim registration logic that may depend on browser APIs.
