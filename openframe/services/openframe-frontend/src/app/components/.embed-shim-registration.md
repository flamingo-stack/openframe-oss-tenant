Client-side component that triggers embed shim registration when rendered in the browser. Acts as a lightweight mount point to ensure `registerEmbedShims()` runs on the client side.

## Key Components

- **`registerEmbedShims()`** — Called at module load time to register all embed shims (YouTube, Reddit, Twitter, etc.) with the renderer.
- **`EmbedShimRegistration`** — A no-op React component (`returns null`) used to force client-side execution of the shim registration via the `'use client'` directive.

## Usage Example

```typescript
// In a layout or root component
import { EmbedShimRegistration } from '@/components/embed-shim-registration';

export default function RootLayout({ children }) {
  return (
    <html>
      <body>
        <EmbedShimRegistration />
        {children}
      </body>
    </html>
  );
}
```

> **Note:** The `'use client'` directive ensures shim registration only occurs in the browser environment, preventing SSR hydration mismatches for embed elements.
