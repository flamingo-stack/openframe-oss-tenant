Type definitions and constants for Flamingo's AI-powered chat system, providing standardized enums and configuration values for dialog states, message types, and network settings.

## Key Components

- **DIALOG_STATUS** - Dialog states (ON_HOLD, RESOLVED, ACTIVE)
- **CHAT_TYPE** - Chat channel types (CLIENT, ADMIN)
- **MESSAGE_TYPE** - Message classification including tool execution and approval workflows
- **OWNER_TYPE** - Message sender types (CLIENT, ADMIN, ASSISTANT)
- **APPROVAL_STATUS** - Approval workflow states (pending, approved, rejected)
- **ASSISTANT_CONFIG** - AI assistant configurations (Fae for clients, Mingo for technicians)
- **API_ENDPOINTS** - REST API route constants
- **NATS_TOPICS** - Message queue topic names
- **STORAGE_KEYS** - Local storage key constants
- **NETWORK_CONFIG** - Connection timeouts and limits

## Usage Example

```typescript
import { DIALOG_STATUS, MESSAGE_TYPE, ASSISTANT_CONFIG, type DialogStatus, type MessageType } from './index'

// Check dialog state
const isActive: boolean = dialog.status === DIALOG_STATUS.ACTIVE

// Handle different message types
switch (message.type as MessageType) {
  case MESSAGE_TYPE.EXECUTING_TOOL:
    showLoadingState()
    break
  case MESSAGE_TYPE.APPROVAL_REQUEST:
    showApprovalDialog()
    break
}

// Configure AI assistant
const assistant = ASSISTANT_CONFIG.FAE // Fae for client interactions
const mingoBehavior = ASSISTANT_CONFIG.MINGO // Mingo for technician support
```
