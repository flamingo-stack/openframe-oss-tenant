TypeScript module that centralizes all dialog-related constants and type definitions for the Flamingo chat system, providing type-safe enums and configuration values for message handling, user roles, and network settings.

## Key Components

- **Dialog Status Management**: `DIALOG_STATUS` enum for tracking conversation states (ON_HOLD, RESOLVED, ACTIVE)
- **Message Classification**: `MESSAGE_TYPE` enum defining message categories including tool execution and approval workflows  
- **User Role Types**: `OWNER_TYPE` and `CHAT_TYPE` enums for distinguishing between clients, admins, and AI assistants
- **Assistant Configuration**: `ASSISTANT_CONFIG` object defining Fae (client assistant) and Mingo (admin assistant) settings
- **API Integration**: `API_ENDPOINTS` and `NATS_TOPICS` constants for communication endpoints
- **Network Settings**: `NETWORK_CONFIG` object with timeout, reconnection, and polling parameters

## Usage Example

```typescript
import { DIALOG_STATUS, MESSAGE_TYPE, ASSISTANT_CONFIG, DialogStatus } from './index'

// Type-safe dialog status handling
function updateDialogStatus(status: DialogStatus) {
  if (status === DIALOG_STATUS.RESOLVED) {
    console.log('Dialog completed')
  }
}

// Message type checking
function handleMessage(type: keyof typeof MESSAGE_TYPE) {
  switch (type) {
    case 'EXECUTING_TOOL':
      showToolExecution()
      break
    case 'APPROVAL_REQUEST':
      showApprovalDialog()
      break
  }
}

// Assistant configuration
const clientAssistant = ASSISTANT_CONFIG.FAE.name // "Fae"
const adminAssistant = ASSISTANT_CONFIG.MINGO.name // "Mingo"
```
