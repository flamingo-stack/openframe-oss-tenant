Type definitions and constants for Flamingo's dialog and messaging system. This file centralizes all enums, configuration values, and type definitions used across the chat platform's frontend and backend components.

## Key Components

- **Dialog Status Enums**: `DIALOG_STATUS`, `DialogStatus` - Track conversation states (active, on hold, resolved)
- **Message Type System**: `MESSAGE_TYPE`, `MessageType` - Define different message types including tool execution and approval flows
- **Chat & Owner Types**: `CHAT_TYPE`, `OWNER_TYPE` - Distinguish between client/admin chats and message ownership
- **Assistant Configuration**: `ASSISTANT_CONFIG`, `AssistantType` - Configure Fae (client) and Mingo (admin) AI assistants
- **API & Network Config**: `API_ENDPOINTS`, `NATS_TOPICS`, `NETWORK_CONFIG` - Define service endpoints and connection parameters
- **Storage Keys**: `STORAGE_KEYS` - Standardize local storage key names

## Usage Example

```typescript
import { DIALOG_STATUS, MESSAGE_TYPE, ASSISTANT_CONFIG, type DialogStatus, type MessageType } from './index'

// Create a new dialog with specific status
const dialog = {
  id: 'dialog-123',
  status: DIALOG_STATUS.ACTIVE as DialogStatus,
  assistantType: ASSISTANT_CONFIG.FAE.type
}

// Handle different message types
function processMessage(type: MessageType, content: string) {
  switch (type) {
    case MESSAGE_TYPE.TEXT:
      return handleTextMessage(content)
    case MESSAGE_TYPE.EXECUTING_TOOL:
      return showToolExecution(content)
    case MESSAGE_TYPE.APPROVAL_REQUEST:
      return requestApproval(content)
    default:
      return handleUnknownMessage(content)
  }
}

// Use network configuration
const connection = {
  timeout: NETWORK_CONFIG.CONNECT_TIMEOUT_MS,
  pingInterval: NETWORK_CONFIG.PING_INTERVAL_MS
}
```
