Defines constants, enums, and type definitions for the OpenFrame chat dialog system, providing a centralized configuration for chat functionality, message types, and network settings.

## Key Components

- **DIALOG_STATUS** - Dialog state constants (ON_HOLD, RESOLVED, ACTIVE)
- **CHAT_TYPE** - Chat type definitions (CLIENT, ADMIN)
- **MESSAGE_TYPE** - Message type enums for different chat interactions
- **OWNER_TYPE** - User role definitions (CLIENT, ADMIN, ASSISTANT)
- **APPROVAL_STATUS** - Approval workflow states
- **ASSISTANT_CONFIG** - AI assistant configurations (Fae, Mingo)
- **API_ENDPOINTS** - Chat API route constants
- **NATS_TOPICS** - Message broker topic definitions
- **STORAGE_KEYS** - Local storage key constants
- **NETWORK_CONFIG** - Connection and polling configuration

## Usage Example

```typescript
import { 
  DIALOG_STATUS, 
  MESSAGE_TYPE, 
  ASSISTANT_CONFIG,
  DialogStatus,
  MessageType 
} from './index'

// Type-safe dialog status handling
const updateDialogStatus = (status: DialogStatus) => {
  if (status === DIALOG_STATUS.ACTIVE) {
    // Handle active dialog
  }
}

// Message type checking
const processMessage = (type: MessageType) => {
  switch (type) {
    case MESSAGE_TYPE.TEXT:
      return 'Regular text message'
    case MESSAGE_TYPE.EXECUTING_TOOL:
      return 'Tool execution in progress'
    default:
      return 'Unknown message type'
  }
}

// Assistant configuration
const currentAssistant = ASSISTANT_CONFIG.FAE
console.log(`Using ${currentAssistant.name} assistant`)
```
