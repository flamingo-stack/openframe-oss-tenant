Centralized constants and type definitions for the Flamingo chat dialog system, providing type-safe enums and configuration values for chat interactions, message handling, and API communication.

## Key Components

- **Dialog Management**: `DIALOG_STATUS` enum with ON_HOLD, RESOLVED, and ACTIVE states
- **Message System**: `MESSAGE_TYPE` enum covering text messages, tool execution, approvals, and errors
- **Chat Types**: `CHAT_TYPE` distinguishing between client and admin AI chats  
- **User Roles**: `OWNER_TYPE` and `APPROVAL_STATUS` for message ownership and approval workflows
- **Assistant Config**: `ASSISTANT_CONFIG` defining Fae (client) and Mingo (admin) assistants
- **API & Network**: `API_ENDPOINTS`, `NATS_TOPICS`, and `NETWORK_CONFIG` for communication settings

## Usage Example

```typescript
import { 
  DIALOG_STATUS, 
  MESSAGE_TYPE, 
  ASSISTANT_CONFIG,
  type DialogStatus,
  type MessageType 
} from './index'

// Type-safe dialog status checking
const isDialogActive = (status: DialogStatus) => 
  status === DIALOG_STATUS.ACTIVE

// Message type handling
const handleMessage = (type: MessageType) => {
  switch (type) {
    case MESSAGE_TYPE.TEXT:
      return processTextMessage()
    case MESSAGE_TYPE.EXECUTING_TOOL:
      return showToolExecution()
    default:
      return handleOtherMessage()
  }
}

// Assistant configuration
const clientAssistant = ASSISTANT_CONFIG.FAE
console.log(`Using ${clientAssistant.name} assistant`) // "Using Fae assistant"
```
