Central constants and type definitions for the Flamingo chat/dialog system, providing type-safe enums for chat statuses, message types, and configuration values used across the OpenFrame platform.

## Key Components

- **Dialog Management**: `DIALOG_STATUS` enum for tracking conversation states (ON_HOLD, RESOLVED, ACTIVE)
- **Chat Types**: `CHAT_TYPE` enum distinguishing between client and admin AI chats
- **Message Classification**: `MESSAGE_TYPE` enum for various message types including tool execution and approval workflows
- **User Roles**: `OWNER_TYPE` and assistant configuration for Fae (client AI) and Mingo (technician AI)
- **API Configuration**: Endpoint URLs, NATS messaging topics, and network timeout settings
- **Storage Keys**: LocalStorage keys for authentication tokens

## Usage Example

```typescript
import { DIALOG_STATUS, MESSAGE_TYPE, ASSISTANT_CONFIG } from './index'

// Check dialog state
if (dialog.status === DIALOG_STATUS.ACTIVE) {
  console.log('Dialog is currently active')
}

// Handle different message types
switch (message.type) {
  case MESSAGE_TYPE.TEXT:
    renderTextMessage(message)
    break
  case MESSAGE_TYPE.EXECUTING_TOOL:
    showToolExecutionIndicator()
    break
  case MESSAGE_TYPE.APPROVAL_REQUEST:
    showApprovalDialog(message)
    break
}

// Configure assistant
const assistant = ASSISTANT_CONFIG.FAE // { type: 'fae', name: 'Fae' }
```
