Defines constants, enums, and type definitions for the dialog and chat system in OpenFrame's AI-powered MSP platform. This file serves as a centralized configuration hub for chat functionality, message types, and network settings.

## Key Components

**Status and Type Enums:**
- `DIALOG_STATUS` - Dialog states (ON_HOLD, RESOLVED, ACTIVE)
- `CHAT_TYPE` - Chat categories (CLIENT, ADMIN)
- `MESSAGE_TYPE` - Message classifications (TEXT, TOOL_EXECUTION, APPROVAL_REQUEST, etc.)
- `OWNER_TYPE` - Message ownership (CLIENT, ADMIN, ASSISTANT)
- `APPROVAL_STATUS` - Approval workflow states (PENDING, APPROVED, REJECTED)

**Assistant Configuration:**
- `ASSISTANT_CONFIG` - Defines Fae (client AI) and Mingo (technician AI) assistants
- `AssistantType` - Type union for assistant identification

**API and Network Configuration:**
- `API_ENDPOINTS` - REST API routes for chat operations
- `NATS_TOPICS` - Message queue topic names
- `STORAGE_KEYS` - LocalStorage key constants
- `NETWORK_CONFIG` - Connection timeouts, retry intervals, and limits

    break
}
