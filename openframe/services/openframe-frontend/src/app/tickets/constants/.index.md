Defines type-safe constants and enums for the OpenFrame dialog and messaging system, providing standardized values for chat interactions, message types, and API configurations.

## Key Components

**Dialog & Chat Constants:**
- `DIALOG_STATUS` - Dialog states (ON_HOLD, RESOLVED, ACTIVE)
- `CHAT_TYPE` - Chat contexts (CLIENT_CHAT, ADMIN_AI_CHAT)
- `OWNER_TYPE` - Message ownership types (CLIENT, ADMIN, ASSISTANT)

**Message System:**
- `MESSAGE_TYPE` - Comprehensive message types including tool execution and approval workflows
- `APPROVAL_STATUS` - Approval workflow states (pending, approved, rejected)

**Assistant Configuration:**
- `ASSISTANT_CONFIG` - AI assistant definitions (Fae for clients, Mingo for technicians)

**API & Network:**
- `API_ENDPOINTS` - REST API routes for chat operations
- `NATS_TOPICS` - Message broker topic names
- `NETWORK_CONFIG` - Connection timeouts, retry intervals, and limits
- `STORAGE_KEYS` - Local storage key names

## Usage Example

```typescript
import { DIALOG_STATUS, MESSAGE_TYPE, ASSISTANT_CONFIG, type DialogStatus } from './index'

// Type-safe dialog status handling
function updateDialog(status: DialogStatus) {
  if (status === DIALOG_STATUS.RESOLVED) {
    // Handle resolved dialog
  }
}

// Message type checking
function processMessage(type: string) {
  switch (type) {
    case MESSAGE_TYPE.EXECUTING_TOOL:
      showSpinner()
      break
    case MESSAGE_TYPE.APPROVAL_REQUEST:
      showApprovalDialog()
      break
  }
}

// Assistant configuration
const faeConfig = ASSISTANT_CONFIG.FAE
console.log(`Using ${faeConfig.name} assistant (${faeConfig.type})`)
```
