Central constants and type definitions for the Flamingo chat dialog system, providing strongly-typed enums and configuration values for chat functionality, message handling, and network operations.

## Key Components

- **DIALOG_STATUS** - Dialog state constants (ON_HOLD, RESOLVED, ACTIVE)
- **CHAT_TYPE** - Chat channel types (CLIENT, ADMIN)
- **MESSAGE_TYPE** - Message classification (TEXT, EXECUTING_TOOL, APPROVAL_REQUEST, etc.)
- **OWNER_TYPE** - Message ownership (CLIENT, ADMIN, ASSISTANT)
- **APPROVAL_STATUS** - Approval workflow states (PENDING, APPROVED, REJECTED)
- **ASSISTANT_CONFIG** - AI assistant configurations (Fae for clients, Mingo for technicians)
- **API_ENDPOINTS** - Chat API route constants
- **NATS_TOPICS** - Message queue topic names
- **STORAGE_KEYS** - Local storage key constants
- **NETWORK_CONFIG** - Connection and performance settings

## Usage Example

```typescript
import { DIALOG_STATUS, MESSAGE_TYPE, ASSISTANT_CONFIG, DialogStatus } from './index'

// Type-safe dialog status handling
const updateDialogStatus = (status: DialogStatus) => {
  if (status === DIALOG_STATUS.ACTIVE) {
    console.log('Dialog is active')
  }
}

// Message type checking
const handleMessage = (type: string) => {
  switch (type) {
    case MESSAGE_TYPE.APPROVAL_REQUEST:
      return 'Handle approval request'
    case MESSAGE_TYPE.EXECUTING_TOOL:
      return 'Show tool execution status'
  }
}

// Assistant configuration
const faeConfig = ASSISTANT_CONFIG.FAE
console.log(`Using ${faeConfig.name} assistant`) // "Using Fae assistant"
```
