Central constants and type definitions for Flamingo's dialog and messaging system, providing type-safe enums and configuration values used throughout the chat interface.

## Key Components

- **Dialog Management**: `DIALOG_STATUS` enum for tracking conversation states (active, on hold, resolved)
- **Chat Types**: `CHAT_TYPE` constants distinguishing between client and admin AI chats
- **Message System**: `MESSAGE_TYPE` enum covering all message variants from text to tool execution and approvals
- **User Roles**: `OWNER_TYPE` and assistant configurations for Fae (client AI) and Mingo (technician AI)
- **API Configuration**: Predefined endpoints for chat operations and NATS messaging topics
- **Network Settings**: Connection timeouts, retry intervals, and message limits for real-time communication

## Usage Example

```typescript
import { DIALOG_STATUS, MESSAGE_TYPE, ASSISTANT_CONFIG } from './index'

// Type-safe status checking
const isActiveDialog = status === DIALOG_STATUS.ACTIVE

// Message type validation
if (message.type === MESSAGE_TYPE.APPROVAL_REQUEST) {
  handleApprovalRequest(message)
}

// Assistant configuration
const faeConfig = ASSISTANT_CONFIG.FAE
console.log(`Using ${faeConfig.name} assistant`) // "Using Fae assistant"

// API endpoint usage
fetch(API_ENDPOINTS.SEND_MESSAGE, {
  method: 'POST',
  body: JSON.stringify(messageData)
})
```
