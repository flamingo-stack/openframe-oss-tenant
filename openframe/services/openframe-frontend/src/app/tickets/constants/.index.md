Centralized constants and type definitions for Flamingo's dialog and chat system, providing type-safe enums and configuration values for the messaging infrastructure.

## Key Components

- **Dialog Status Types**: `DIALOG_STATUS` enum and `DialogStatus` type for managing conversation states (ON_HOLD, RESOLVED, ACTIVE)
- **Chat & Message Types**: `CHAT_TYPE`, `MESSAGE_TYPE` enums with corresponding TypeScript types for different conversation contexts and message formats
- **Owner & Approval Types**: `OWNER_TYPE` and `APPROVAL_STATUS` enums for message ownership and approval workflow states
- **Assistant Configuration**: `ASSISTANT_CONFIG` defining Fae (client assistant) and Mingo (technician assistant) with their types
- **API & Network Config**: `API_ENDPOINTS` for REST endpoints, `NATS_TOPICS` for pub/sub messaging, and `NETWORK_CONFIG` for connection settings
- **Storage Keys**: `STORAGE_KEYS` for consistent local storage key naming
