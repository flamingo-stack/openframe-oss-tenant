Centralized constants and type definitions for the Flamingo chat system, providing type-safe enumerations for dialog statuses, message types, and system configuration.

## Key Components

**Dialog & Chat Constants:**
- `DIALOG_STATUS` - Dialog states (ON_HOLD, RESOLVED, ACTIVE)
- `CHAT_TYPE` - Chat types (CLIENT, ADMIN) 
- `MESSAGE_TYPE` - Message types including tool execution and approval states
- `OWNER_TYPE` - Message ownership (CLIENT, ADMIN, ASSISTANT)

**System Configuration:**
- `ASSISTANT_CONFIG` - AI assistant definitions (Fae for clients, Mingo for technicians)
- `API_ENDPOINTS` - REST API routes for chat operations
- `NATS_TOPICS` - Message broker topic names
- `NETWORK_CONFIG` - Connection timeouts and polling limits
- `STORAGE_KEYS` - Local storage key names

**Type Exports:**
Each constant object has a corresponding TypeScript type for compile-time safety.

## Usage Example

```typescript
import { DIALOG_STATUS, MESSAGE_TYPE, type DialogStatus, type MessageType } from './index'

// Type-safe status checking
function handleDialog(status: DialogStatus) {
  if (status === DIALOG_STATUS.ACTIVE) {
    console.log('Dialog is active')
  }
}

// Message type validation
function processMessage(type: MessageType) {
  switch (type) {
    case MESSAGE_TYPE.EXECUTING_TOOL:
      return 'Tool is running...'
    case MESSAGE_TYPE.APPROVAL_REQUEST:
      return 'Awaiting approval'
    default:
      return 'Processing message'
  }
}

// Assistant configuration
const assistant = ASSISTANT_CONFIG.FAE
console.log(`Using ${assistant.name} assistant`) // "Using Fae assistant"
```
