Centralized constants and type definitions for the Flamingo dialog system, managing chat interactions, message types, and network configuration for AI assistants Fae and Mingo.

## Key Components

- **DIALOG_STATUS** - Dialog state constants (ON_HOLD, RESOLVED, ACTIVE)
- **CHAT_TYPE** - Chat context types (CLIENT, ADMIN)
- **MESSAGE_TYPE** - Message classification including tool execution and approval flows
- **OWNER_TYPE** - Message ownership (CLIENT, ADMIN, ASSISTANT)
- **APPROVAL_STATUS** - Approval workflow states (pending, approved, rejected)
- **ASSISTANT_CONFIG** - Configuration for Fae (client-facing) and Mingo (technician-facing) AI assistants
- **API_ENDPOINTS** - REST API routes for chat operations
- **NATS_TOPICS** - Pub/sub messaging topics
- **STORAGE_KEYS** - Local storage key constants
- **NETWORK_CONFIG** - Network timing and connection parameters

## Usage Example

```typescript
import { 
  DIALOG_STATUS, 
  MESSAGE_TYPE, 
  ASSISTANT_CONFIG, 
  type DialogStatus,
  type MessageType 
} from './index'

// Type-safe dialog management
const dialogStatus: DialogStatus = DIALOG_STATUS.ACTIVE

// Message classification
const messageType: MessageType = MESSAGE_TYPE.EXECUTING_TOOL

// Assistant configuration
const faeAssistant = ASSISTANT_CONFIG.FAE
console.log(`Using ${faeAssistant.name} assistant of type ${faeAssistant.type}`)

// API endpoint usage
fetch(API_ENDPOINTS.SEND_MESSAGE, {
  method: 'POST',
  body: JSON.stringify({ type: messageType })
})
```
