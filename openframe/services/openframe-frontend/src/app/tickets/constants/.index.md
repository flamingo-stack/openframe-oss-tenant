This file defines core constants, enums, and type definitions for a real-time chat dialog system in the Flamingo MSP platform, providing standardized values for message types, approval workflows, and network configuration.

## Key Components

- **Dialog Management**: `DIALOG_STATUS` enum (ON_HOLD, RESOLVED, ACTIVE) and `CHAT_TYPE` for client/admin conversations
- **Message System**: `MESSAGE_TYPE` enum covering text, tool execution, approvals, and message lifecycle events
- **User Types**: `OWNER_TYPE` and `APPROVAL_STATUS` enums for managing permissions and approval workflows
- **AI Assistants**: `ASSISTANT_CONFIG` defining Fae (client-facing) and Mingo (admin-facing) AI assistants
- **Network Configuration**: API endpoints, NATS messaging topics, storage keys, and connection settings
- **Type Definitions**: TypeScript types derived from const assertions for type safety
