Central constants and type definitions module for the OpenFrame dialog and messaging system, providing standardized values and types for chat functionality, API endpoints, and network configuration.

## Key Components

- **Dialog Status Constants** - `DIALOG_STATUS` enum for managing dialog states (ON_HOLD, RESOLVED, ACTIVE)
- **Chat & Message Types** - `CHAT_TYPE`, `MESSAGE_TYPE`, and `OWNER_TYPE` enums for categorizing communications
- **Approval System** - `APPROVAL_STATUS` enum for handling approval workflows
- **Assistant Configuration** - `ASSISTANT_CONFIG` defining Fae and Mingo AI assistants
- **API & Network Config** - `API_ENDPOINTS`, `NATS_TOPICS`, and `NETWORK_CONFIG` for system communication
- **Storage Keys** - `STORAGE_KEYS` for local storage management

## Usage Example

```typescript
import { 
  DIALOG_STATUS, 
  MESSAGE_TYPE, 
  ASSISTANT_CONFIG,
  DialogStatus 
} from './index'

// Type-safe dialog status checking
const isDialogActive = (status: DialogStatus): boolean => {
  return status === DIALOG_STATUS.ACTIVE
}

// Message type handling
const handleMessage = (type: MessageType) => {
  switch (type) {
    case MESSAGE_TYPE.TEXT:
      return processTextMessage()
    case MESSAGE_TYPE.EXECUTING_TOOL:
      return showToolExecution()
    default:
      return handleUnknownMessage()
  }
}

// Assistant configuration
const faeConfig = ASSISTANT_CONFIG.FAE
console.log(`${faeConfig.name} assistant type: ${faeConfig.type}`)
```

This module serves as the single source of truth for all constants used across the OpenFrame messaging system, ensuring type safety and consistency throughout the application.
