Defines comprehensive constants and type definitions for a dialog/chat system with AI assistants, approval workflows, and real-time messaging capabilities.

## Key Components

**Status & Type Enums:**
- `DIALOG_STATUS` - Dialog states (ON_HOLD, RESOLVED, ACTIVE)
- `CHAT_TYPE` - Chat categories (CLIENT, ADMIN)  
- `MESSAGE_TYPE` - Message classifications including tool execution and approval states
- `OWNER_TYPE` - Message ownership (CLIENT, ADMIN, ASSISTANT)
- `APPROVAL_STATUS` - Approval workflow states (PENDING, APPROVED, REJECTED)

**Configuration Objects:**
- `ASSISTANT_CONFIG` - AI assistant definitions (Fae for clients, Mingo for technicians)
- `API_ENDPOINTS` - REST API routes for chat operations
- `NATS_TOPICS` - Real-time messaging topics
- `STORAGE_KEYS` - Local storage identifiers
- `NETWORK_CONFIG` - Connection timeouts, limits, and intervals

**Type Exports:**
- All corresponding TypeScript types derived from the constants using `typeof` patterns

## Usage Example

```typescript
import { 
  DIALOG_STATUS, 
  MESSAGE_TYPE, 
  ASSISTANT_CONFIG, 
  type DialogStatus,
  type MessageType 
} from './index'

// Create a new dialog
const dialog = {
  status: DIALOG_STATUS.ACTIVE as DialogStatus,
  assistant: ASSISTANT_CONFIG.FAE.type
}

// Handle different message types
function processMessage(type: MessageType) {
  switch (type) {
    case MESSAGE_TYPE.EXECUTING_TOOL:
      return 'Processing...'
    case MESSAGE_TYPE.APPROVAL_REQUEST:
      return 'Awaiting approval'
    default:
      return 'Unknown message type'
  }
}
```
