A centralized constants file that defines all dialog and chat system enums, types, and configuration values used throughout the OpenFrame AI chat platform.

## Key Components

**Dialog Status Management**
- `DIALOG_STATUS` - Status states for chat dialogs (ON_HOLD, RESOLVED, ACTIVE)
- `CHAT_TYPE` - Chat context types (CLIENT, ADMIN)
- `MESSAGE_TYPE` - Message classification (TEXT, EXECUTING_TOOL, APPROVAL_REQUEST, etc.)
- `OWNER_TYPE` - Message ownership (CLIENT, ADMIN, ASSISTANT)

**AI Assistant Configuration**
- `ASSISTANT_CONFIG` - Configuration for Fae (client AI) and Mingo (technician AI)
- `APPROVAL_STATUS` - Tool execution approval states (pending, approved, rejected)

**System Infrastructure**
- `API_ENDPOINTS` - REST API routes for chat operations
- `NATS_TOPICS` - Message broker topic names
- `STORAGE_KEYS` - Browser storage identifiers
- `NETWORK_CONFIG` - Connection timeouts, retry intervals, and message limits

## Usage Example

```typescript
import { DIALOG_STATUS, MESSAGE_TYPE, ASSISTANT_CONFIG, type DialogStatus } from './index'

// Check dialog state
const isActive: boolean = dialog.status === DIALOG_STATUS.ACTIVE

// Create typed message
const message = {
  type: MESSAGE_TYPE.APPROVAL_REQUEST,
  owner: OWNER_TYPE.ASSISTANT,
  content: 'Request permission to restart service'
}

// Configure AI assistant
const assistant = ASSISTANT_CONFIG.FAE // { type: 'fae', name: 'Fae' }
```
