Core constants and type definitions for the OpenFrame chat dialog system, providing standardized values for dialog statuses, message types, API endpoints, and network configuration.

## Key Components

**Dialog Status Management:**
- `DIALOG_STATUS` - Dialog states: ON_HOLD, RESOLVED, ACTIVE
- `DialogStatus` - TypeScript type for dialog status values

**Message System:**
- `MESSAGE_TYPE` - Message categories including TEXT, EXECUTING_TOOL, APPROVAL_REQUEST, ERROR
- `MessageType` - Type-safe message type definitions
- `OWNER_TYPE` - Message ownership: CLIENT, ADMIN, ASSISTANT
- `CHAT_TYPE` - Chat context types: CLIENT_CHAT, ADMIN_AI_CHAT

**AI Assistants:**
- `ASSISTANT_CONFIG` - Configuration for Fae (client assistant) and Mingo (admin assistant)
- `AssistantType` - Type definitions for assistant types

**Infrastructure:**
- `API_ENDPOINTS` - REST API routes for chat operations
- `NATS_TOPICS` - Message broker topic names
- `STORAGE_KEYS` - Local storage key constants
- `NETWORK_CONFIG` - Connection timeouts, retry intervals, and message limits

## Usage Example

```typescript
import { DIALOG_STATUS, MESSAGE_TYPE, ASSISTANT_CONFIG, type DialogStatus } from './index'

// Type-safe dialog status handling
const updateDialogStatus = (status: DialogStatus) => {
  if (status === DIALOG_STATUS.RESOLVED) {
    // Handle resolved dialog
  }
}

// Message type checking
const processMessage = (type: string) => {
  switch (type) {
    case MESSAGE_TYPE.APPROVAL_REQUEST:
      return handleApprovalRequest()
    case MESSAGE_TYPE.EXECUTING_TOOL:
      return showExecutionIndicator()
  }
}

// Assistant configuration
const getAssistantName = () => ASSISTANT_CONFIG.FAE.name // "Fae"
```
