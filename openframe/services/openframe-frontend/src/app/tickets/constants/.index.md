Centralized constants and type definitions for the OpenFrame chat/dialog system, providing type-safe enums for message types, dialog states, API endpoints, and network configuration.

## Key Components

**Dialog & Message Types:**
- `DIALOG_STATUS` - Dialog states (ON_HOLD, RESOLVED, ACTIVE)
- `MESSAGE_TYPE` - Message types including tool execution and approval workflows
- `CHAT_TYPE` - Distinguishes between client and admin AI chats
- `OWNER_TYPE` - Message ownership (CLIENT, ADMIN, ASSISTANT)
- `APPROVAL_STATUS` - Approval workflow states

**System Configuration:**
- `ASSISTANT_CONFIG` - Defines Fae and Mingo AI assistants
- `API_ENDPOINTS` - REST API routes for chat operations
- `NATS_TOPICS` - Message broker topic names
- `STORAGE_KEYS` - Local storage key constants
- `NETWORK_CONFIG` - Connection timeouts, retry intervals, and limits

## Usage Example

```typescript
import { DIALOG_STATUS, MESSAGE_TYPE, ASSISTANT_CONFIG, DialogStatus } from './index'

// Type-safe dialog status checking
const updateDialog = (status: DialogStatus) => {
  if (status === DIALOG_STATUS.ACTIVE) {
    console.log('Dialog is currently active')
  }
}

// Message type validation
const processMessage = (type: string) => {
  switch (type) {
    case MESSAGE_TYPE.EXECUTING_TOOL:
      return 'Tool is running...'
    case MESSAGE_TYPE.APPROVAL_REQUEST:
      return 'Awaiting approval'
    default:
      return 'Unknown message type'
  }
}

// Assistant configuration
const currentAssistant = ASSISTANT_CONFIG.FAE.name // "Fae"
```
