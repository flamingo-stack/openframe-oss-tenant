Constants and type definitions for the Flamingo chat system, defining all the enums, configuration values, and API endpoints used throughout the dialog and messaging components.

## Key Components

- **Status Enums**: `DIALOG_STATUS`, `MESSAGE_TYPE`, `OWNER_TYPE`, `APPROVAL_STATUS` - Core state management constants
- **Chat Configuration**: `CHAT_TYPE`, `ASSISTANT_CONFIG` - Chat system and AI assistant definitions
- **API & Network**: `API_ENDPOINTS`, `NATS_TOPICS`, `NETWORK_CONFIG` - External service integration constants
- **Storage**: `STORAGE_KEYS` - Local storage key definitions
- **Type Exports**: TypeScript types derived from each constant object for type safety

## Usage Example

```typescript
import { 
  DIALOG_STATUS, 
  DialogStatus, 
  MESSAGE_TYPE, 
  ASSISTANT_CONFIG,
  API_ENDPOINTS 
} from './index'

// Using dialog status
const currentStatus: DialogStatus = DIALOG_STATUS.ACTIVE

// Checking message type
if (message.type === MESSAGE_TYPE.APPROVAL_REQUEST) {

}

// Assistant configuration
```

The constants use `as const` assertions to ensure literal type inference, providing both runtime values and compile-time type safety for the Flamingo chat system.
