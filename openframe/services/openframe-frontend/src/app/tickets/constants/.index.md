Defines constants, enums, and type definitions for the OpenFrame dialog and chat system, providing standardized values for message types, dialog states, API endpoints, and network configuration.

## Key Components

- **Dialog Status Types**: `DIALOG_STATUS` enum with ON_HOLD, RESOLVED, and ACTIVE states
- **Chat & Message Types**: `CHAT_TYPE` (CLIENT/ADMIN) and `MESSAGE_TYPE` (TEXT, TOOL execution, approvals, errors)
- **Owner Types**: `OWNER_TYPE` defining CLIENT, ADMIN, and ASSISTANT roles
- **Assistant Configuration**: `ASSISTANT_CONFIG` for Fae (client AI) and Mingo (technician AI)
- **API Endpoints**: `API_ENDPOINTS` with chat service URLs
- **Network Configuration**: `NETWORK_CONFIG` with timeouts, intervals, and connection settings
- **Storage Keys**: `STORAGE_KEYS` for browser storage
- **NATS Topics**: `NATS_TOPICS` for message broker communication

## Usage Example

```typescript
import { DIALOG_STATUS, MESSAGE_TYPE, ASSISTANT_CONFIG } from './index'

// Check dialog state
if (dialog.status === DIALOG_STATUS.ACTIVE) {
  console.log('Dialog is currently active')
}

// Handle message types
switch (message.type) {
  case MESSAGE_TYPE.TEXT:
    renderTextMessage(message)
    break
  case MESSAGE_TYPE.EXECUTING_TOOL:
    showToolExecution(message)
    break
}

// Configure assistant
const assistant = ASSISTANT_CONFIG.FAE
console.log(`Using ${assistant.name} assistant`) // "Using Fae assistant"

// API call
fetch(API_ENDPOINTS.SEND_MESSAGE, {
  method: 'POST',
  body: JSON.stringify(messageData)
})
```
