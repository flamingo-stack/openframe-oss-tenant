This file defines constants, enums, and types for a chat/dialog system that supports AI assistants (Fae and Mingo) with approval workflows and real-time messaging capabilities.

## Key Components

- **DIALOG_STATUS** - Dialog states: `ON_HOLD`, `RESOLVED`, `ACTIVE`
- **CHAT_TYPE** - Chat contexts: `CLIENT_CHAT`, `ADMIN_AI_CHAT`
- **MESSAGE_TYPE** - Message categories including tool execution and approval workflows
- **OWNER_TYPE** - Message ownership: `CLIENT`, `ADMIN`, `ASSISTANT`
- **APPROVAL_STATUS** - Approval workflow states: `pending`, `approved`, `rejected`
- **ASSISTANT_CONFIG** - AI assistant definitions (Fae for clients, Mingo for technicians)
- **API_ENDPOINTS** - Chat API routes for messages and approvals
- **NATS_TOPICS** - Real-time messaging topics
- **STORAGE_KEYS** - Local storage configuration
- **NETWORK_CONFIG** - Connection timeouts and polling settings

## Usage Example

```typescript
import { DIALOG_STATUS, MESSAGE_TYPE, ASSISTANT_CONFIG } from './index'

// Create a new dialog
const dialog = {
  status: DIALOG_STATUS.ACTIVE,
  chatType: CHAT_TYPE.CLIENT
}

// Send a message
const message = {
  type: MESSAGE_TYPE.TEXT,
  owner: OWNER_TYPE.CLIENT,
  content: "Help me troubleshoot my network"
}

// Configure AI assistant
const assistant = ASSISTANT_CONFIG.FAE // For client support
```
