Centralized constants and type definitions for the chat dialog system, providing type-safe enums and configuration values for chat operations, message handling, and network communications.

## Key Components

- **Status Enums**: `DIALOG_STATUS`, `MESSAGE_TYPE`, `OWNER_TYPE`, `APPROVAL_STATUS` - Core status tracking
- **Chat Configuration**: `CHAT_TYPE`, `ASSISTANT_CONFIG` - Chat type definitions and AI assistant configs  
- **API Constants**: `API_ENDPOINTS`, `NATS_TOPICS`, `STORAGE_KEYS` - External service endpoints and keys
- **Network Settings**: `NETWORK_CONFIG` - Connection timeouts, limits, and polling intervals
- **Type Exports**: Corresponding TypeScript types for all enums using `typeof` pattern

## Usage Example

```typescript
import { 
  DIALOG_STATUS, 
  MESSAGE_TYPE, 
  ASSISTANT_CONFIG,
  type DialogStatus,
  type MessageType 
} from './index'

// Type-safe status checking
const isActiveDialog = (status: DialogStatus) => 
  status === DIALOG_STATUS.ACTIVE

// Message type validation
const handleMessage = (type: MessageType) => {
  if (type === MESSAGE_TYPE.APPROVAL_REQUEST) {
    // Handle approval workflow
  }
}

// Assistant configuration
const faeConfig = ASSISTANT_CONFIG.FAE
console.log(`Using ${faeConfig.name} assistant`) // "Using Fae assistant"

// Network configuration
const timeout = NETWORK_CONFIG.CONNECT_TIMEOUT_MS // 10000
```
