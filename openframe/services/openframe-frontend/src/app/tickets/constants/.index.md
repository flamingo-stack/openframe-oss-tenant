Centralized constants and type definitions for the OpenFrame dialog/chat system, providing type-safe enums for message types, dialog states, and API configuration.

## Key Components

- **Dialog Management**: `DIALOG_STATUS` enum for tracking conversation states (ON_HOLD, RESOLVED, ACTIVE)
- **Chat Types**: `CHAT_TYPE` constants distinguishing client and admin chat contexts
- **Message System**: `MESSAGE_TYPE` enum covering text, tool execution, approvals, and system messages
- **User Roles**: `OWNER_TYPE` defining CLIENT, ADMIN, and ASSISTANT message ownership
- **Assistant Configuration**: `ASSISTANT_CONFIG` for Fae (client) and Mingo (admin) AI assistants
- **API & Network**: Endpoint URLs, NATS messaging topics, and connection timeout configurations
- **Storage**: Local storage keys for authentication tokens

## Usage Example

```typescript
import { DIALOG_STATUS, MESSAGE_TYPE, ASSISTANT_CONFIG, type MessageType } from './index'

// Create a new message
const message = {
  type: MESSAGE_TYPE.TEXT as MessageType,
  content: "Hello from Fae!",
  assistant: ASSISTANT_CONFIG.FAE.type
}

// Check dialog state
if (dialog.status === DIALOG_STATUS.ACTIVE) {
  // Handle active conversation
}

// Configure network timeouts
const connection = {
  timeout: NETWORK_CONFIG.CONNECT_TIMEOUT_MS,
  pingInterval: NETWORK_CONFIG.PING_INTERVAL_MS
}
```
