Constants and type definitions for the OpenFrame dialog and chat system, providing standardized enums for message types, dialog statuses, and configuration values.

## Key Components

- **Dialog Status Constants** - `DIALOG_STATUS` enum for tracking conversation states (ON_HOLD, RESOLVED, ACTIVE)
- **Message Type System** - `MESSAGE_TYPE` enum defining various message categories including tool execution and approval workflows
- **Chat Configuration** - `CHAT_TYPE` and `OWNER_TYPE` enums for distinguishing between client and admin interactions
- **Assistant Types** - `ASSISTANT_CONFIG` object defining Fae (client assistant) and Mingo (admin assistant) configurations
- **API Endpoints** - `API_ENDPOINTS` constants for chat service routes
- **Network Configuration** - `NETWORK_CONFIG` with timeout, reconnection, and polling settings
- **NATS Topics** - `NATS_TOPICS` for message broker communication channels

## Usage Example

```typescript
import { DIALOG_STATUS, MESSAGE_TYPE, ASSISTANT_CONFIG, type DialogStatus } from './index'

// Check dialog status
if (dialog.status === DIALOG_STATUS.ACTIVE) {
  // Handle active dialog
}

// Create a message with proper typing
const message = {
  type: MESSAGE_TYPE.TEXT,
  owner: OWNER_TYPE.CLIENT,
  content: "Hello"
}

// Configure assistant
const assistant = ASSISTANT_CONFIG.FAE
console.log(`Using ${assistant.name} (${assistant.type})`)

// Type-safe status handling
const status: DialogStatus = DIALOG_STATUS.RESOLVED
```
