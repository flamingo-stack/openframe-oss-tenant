Centralized constants and type definitions for the OpenFrame dialog/chat system, providing type-safe configuration values for message handling, user interactions, and network communication.

## Key Components

- **Dialog States**: `DIALOG_STATUS` enum for tracking conversation states (ON_HOLD, RESOLVED, ACTIVE)
- **Chat Types**: `CHAT_TYPE` enum distinguishing between client and admin AI chat sessions
- **Message Types**: `MESSAGE_TYPE` enum covering all message variants from text to tool execution and approvals
- **User Roles**: `OWNER_TYPE` and `ASSISTANT_CONFIG` for identifying message senders and AI assistants (Fae, Mingo)
- **API Configuration**: `API_ENDPOINTS`, `NATS_TOPICS`, and `STORAGE_KEYS` for service communication
- **Network Settings**: `NETWORK_CONFIG` with timeouts, retry delays, and connection parameters

## Usage Example

```typescript
import { DIALOG_STATUS, MESSAGE_TYPE, ASSISTANT_CONFIG, type DialogStatus, type MessageType } from './index'

// Type-safe dialog state management
const updateDialogStatus = (status: DialogStatus) => {
  if (status === DIALOG_STATUS.RESOLVED) {
    // Handle resolved dialog
  }
}

// Message type validation
const processMessage = (type: MessageType) => {
  switch (type) {
    case MESSAGE_TYPE.TEXT:
      return handleTextMessage()
    case MESSAGE_TYPE.EXECUTING_TOOL:
      return showToolExecution()
    case MESSAGE_TYPE.APPROVAL_REQUEST:
      return requestApproval()
  }
}

// Assistant configuration
const getAssistant = () => ASSISTANT_CONFIG.FAE.name // "Fae"
```
