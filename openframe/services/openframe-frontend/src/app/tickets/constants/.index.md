Central configuration file that defines constants, enums, and type definitions for the chat dialog system in the Flamingo MSP platform.

## Key Components

**Status & Type Enums:**
- `DIALOG_STATUS` - Dialog states (ON_HOLD, RESOLVED, ACTIVE)
- `CHAT_TYPE` - Chat categories (CLIENT, ADMIN)
- `MESSAGE_TYPE` - Message types including tool execution and approval flows
- `OWNER_TYPE` - Message ownership (CLIENT, ADMIN, ASSISTANT)
- `APPROVAL_STATUS` - Approval workflow states

**Assistant Configuration:**
- `ASSISTANT_CONFIG` - Defines Fae (client AI) and Mingo (technician AI) assistants
- `AssistantType` - Type-safe assistant identification

**API & Network Configuration:**
- `API_ENDPOINTS` - REST API routes for messages, dialogs, and approvals
- `NATS_TOPICS` - Message queue topic names
- `NETWORK_CONFIG` - Connection timeouts, retry delays, and limits
- `STORAGE_KEYS` - Local storage key constants

## Usage Example

```typescript
import { DIALOG_STATUS, MESSAGE_TYPE, ASSISTANT_CONFIG, type DialogStatus } from './index'

// Type-safe dialog status checking
const isActive = (status: DialogStatus) => status === DIALOG_STATUS.ACTIVE

// Assistant configuration
const assistantName = ASSISTANT_CONFIG.FAE.name // "Fae"

// API endpoint usage
const endpoint = `${API_ENDPOINTS.SEND_MESSAGE}/${dialogId}`

// Network configuration
const timeout = NETWORK_CONFIG.CONNECT_TIMEOUT_MS // 10000
```
