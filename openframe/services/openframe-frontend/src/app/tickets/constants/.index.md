Exports constants, enums, and type definitions for dialog management, chat operations, and network configuration in the Flamingo platform.

## Key Components

- **Dialog Status Management** - `DIALOG_STATUS`, `DialogStatus` - Track dialog states (ON_HOLD, RESOLVED, ACTIVE)
- **Chat System Types** - `CHAT_TYPE`, `ChatType` - Define client and admin chat channels
- **Message Types** - `MESSAGE_TYPE`, `MessageType` - Comprehensive message categorization including tool execution and approvals
- **Owner Classifications** - `OWNER_TYPE`, `OwnerType` - Identify message originators (CLIENT, ADMIN, ASSISTANT)
- **Approval Workflow** - `APPROVAL_STATUS`, `ApprovalStatus` - Manage approval request states
- **AI Assistants** - `ASSISTANT_CONFIG`, `AssistantType` - Configuration for Fae and Mingo AI assistants
- **API Configuration** - `API_ENDPOINTS` - REST API endpoint definitions
- **Messaging Infrastructure** - `NATS_TOPICS` - NATS message broker topic names
- **Storage Keys** - `STORAGE_KEYS` - Local storage key constants
- **Network Settings** - `NETWORK_CONFIG` - Connection timeouts, polling intervals, and retry configurations

## Usage Example

```typescript
import { 
  DIALOG_STATUS, 
  MESSAGE_TYPE, 
  ASSISTANT_CONFIG,
  NETWORK_CONFIG 
} from './index'

// Create a new dialog with active status
const dialog = {
  id: 'dialog-123',
  status: DIALOG_STATUS.ACTIVE,
  chatType: CHAT_TYPE.CLIENT
}

// Send a message with proper typing
const message = {
  type: MESSAGE_TYPE.TEXT,
  owner: OWNER_TYPE.CLIENT,
  content: 'Hello Fae!'
}

// Configure AI assistant
const assistant = ASSISTANT_CONFIG.FAE.type // 'fae'

// Use network configuration
const timeout = NETWORK_CONFIG.CONNECT_TIMEOUT_MS // 10000
```
