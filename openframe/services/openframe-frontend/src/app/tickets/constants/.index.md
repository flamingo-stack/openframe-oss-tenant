A comprehensive constants and type definitions file that centralizes all enums, API endpoints, and configuration values used throughout the OpenFrame dialog/chat system.

## Key Components

- **Status Enums**: `DIALOG_STATUS`, `MESSAGE_TYPE`, `OWNER_TYPE`, `APPROVAL_STATUS` - Core state management constants
- **Chat Configuration**: `CHAT_TYPE`, `ASSISTANT_CONFIG` - Defines client vs admin chats and AI assistants (Fae/Mingo)
- **API Integration**: `API_ENDPOINTS`, `NATS_TOPICS`, `STORAGE_KEYS` - External service configuration
- **Network Settings**: `NETWORK_CONFIG` - Connection timeouts, retry logic, and message limits
- **TypeScript Types**: Corresponding type definitions for all constants using `typeof` patterns

## Usage Example

```typescript
import { 
  DIALOG_STATUS, 
  MESSAGE_TYPE, 
  ASSISTANT_CONFIG,
  type DialogStatus,
  type MessageType 
} from './index'

// Type-safe status checking
const currentStatus: DialogStatus = DIALOG_STATUS.ACTIVE

// Message type validation
if (message.type === MESSAGE_TYPE.APPROVAL_REQUEST) {

// Assistant configuration
const assistantConfig = ASSISTANT_CONFIG.FAE
console.log(`Using ${assistantConfig.name} assistant`) // "Using Fae assistant"

// API endpoint usage
```
