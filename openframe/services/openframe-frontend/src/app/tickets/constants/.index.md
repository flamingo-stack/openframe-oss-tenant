Centralized constants and type definitions for the Flamingo dialog and messaging system, providing type-safe enums for chat operations, message handling, and network configuration.

## Key Components

- **DIALOG_STATUS** - Status constants for chat dialog states (ON_HOLD, RESOLVED, ACTIVE)
- **CHAT_TYPE** - Chat type identifiers for client and admin AI conversations
- **MESSAGE_TYPE** - Message classification types including tool execution, approvals, and errors
- **OWNER_TYPE** - Message ownership types (CLIENT, ADMIN, ASSISTANT)
- **APPROVAL_STATUS** - Status constants for approval workflows
- **ASSISTANT_CONFIG** - Configuration for AI assistants (Fae for clients, Mingo for technicians)
- **API_ENDPOINTS** - REST API endpoint paths for chat operations
- **NATS_TOPICS** - Message queue topic names for real-time communication
- **STORAGE_KEYS** - Local storage key constants
- **NETWORK_CONFIG** - Connection timeouts, polling limits, and network settings

## Usage Example

```typescript
import { DIALOG_STATUS, MESSAGE_TYPE, ASSISTANT_CONFIG, type DialogStatus, type MessageType } from './index'

// Type-safe dialog status checking
const handleDialogUpdate = (status: DialogStatus) => {
  if (status === DIALOG_STATUS.ACTIVE) {
    console.log('Dialog is active')
  }
}

// Message type validation
const processMessage = (type: MessageType) => {
  switch (type) {
    case MESSAGE_TYPE.EXECUTING_TOOL:
      return 'Tool is running...'
    case MESSAGE_TYPE.APPROVAL_REQUEST:
      return 'Awaiting approval'
    default:
      return 'Processing message'
  }
}

// Assistant configuration
const getFaeConfig = () => ASSISTANT_CONFIG.FAE
```
