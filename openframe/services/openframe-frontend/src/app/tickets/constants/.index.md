A comprehensive constants module that defines all the enums, types, and configuration values used throughout the Flamingo chat dialog system, providing type-safe constants for dialog management, messaging, and network operations.

## Key Components

**Dialog Management:**
- `DIALOG_STATUS` - Dialog states (ON_HOLD, RESOLVED, ACTIVE)
- `CHAT_TYPE` - Chat categories (CLIENT, ADMIN)
- `MESSAGE_TYPE` - Message categories including tool execution and approval workflows
- `OWNER_TYPE` - Message ownership (CLIENT, ADMIN, ASSISTANT)
- `APPROVAL_STATUS` - Approval workflow states

**AI Assistants:**
- `ASSISTANT_CONFIG` - Configuration for Fae (client assistant) and Mingo (technician assistant)
- `AssistantType` - Type-safe assistant identifiers

**API & Network:**
- `API_ENDPOINTS` - REST API routes for chat operations
- `NATS_TOPICS` - Message broker topic names
- `NETWORK_CONFIG` - Connection timeouts, limits, and polling intervals
- `STORAGE_KEYS` - Local storage key constants
