Constants and type definitions for the chat dialog system, including status types, message types, API endpoints, and network configuration.

## Key Components

- **Dialog Status Types**: `DIALOG_STATUS` enum with ON_HOLD, RESOLVED, and ACTIVE states
- **Chat Types**: `CHAT_TYPE` enum distinguishing between client and admin AI chats
- **Message Types**: `MESSAGE_TYPE` enum covering text, tool execution, approvals, and system messages
- **Owner Types**: `OWNER_TYPE` enum for CLIENT, ADMIN, and ASSISTANT message ownership
- **Assistant Configuration**: `ASSISTANT_CONFIG` with Fae and Mingo AI assistant definitions
- **API Endpoints**: `API_ENDPOINTS` constant mapping for approval requests, messages, and dialogs
- **Network Configuration**: `NETWORK_CONFIG` with timeouts, retry settings, and polling limits
- **NATS Topics**: `NATS_TOPICS` for message queue topic definitions
- **Storage Keys**: `STORAGE_KEYS` for local storage access token management

## Usage Example

```typescript
import { 
  DIALOG_STATUS, 
  MESSAGE_TYPE, 
  ASSISTANT_CONFIG,
  type DialogStatus,
  type MessageType 
} from './index'

// Create a dialog with active status
const dialog = {
  id: 'dialog-123',
  status: DIALOG_STATUS.ACTIVE as DialogStatus,
  assistant: ASSISTANT_CONFIG.FAE
}

// Handle different message types
function processMessage(type: MessageType) {
  switch (type) {
    case MESSAGE_TYPE.TEXT:
      return 'Processing text message'
    case MESSAGE_TYPE.EXECUTING_TOOL:
      return 'Tool execution in progress'
    case MESSAGE_TYPE.APPROVAL_REQUEST:
      return 'Awaiting approval'
  }
}
```
