This file exports centralized constants and type definitions for a chat/dialog system, providing standardized enums and configuration values used across the OpenFrame chat application.

## Key Components

- **Status Constants**: `DIALOG_STATUS`, `CHAT_TYPE`, `MESSAGE_TYPE`, `OWNER_TYPE`, `APPROVAL_STATUS` - Core enum-like objects for chat system states
- **Assistant Configuration**: `ASSISTANT_CONFIG` - Defines available AI assistants (Fae for clients, Mingo for admins)
- **API Endpoints**: `API_ENDPOINTS` - Centralized REST API route definitions
- **NATS Topics**: `NATS_TOPICS` - Message queue topic names for real-time communication
- **Network Configuration**: `NETWORK_CONFIG` - Connection timeouts, limits, and polling intervals
- **Storage Keys**: `STORAGE_KEYS` - Local storage key constants
- **Type Definitions**: Corresponding TypeScript types for all constants using `typeof` pattern

## Usage Example

```typescript
import { 
  DIALOG_STATUS, 
  DialogStatus, 
  MESSAGE_TYPE, 
  ASSISTANT_CONFIG,
  NETWORK_CONFIG 
} from './index'

// Type-safe status checking
const updateDialogStatus = (status: DialogStatus) => {
  if (status === DIALOG_STATUS.RESOLVED) {
    // Handle resolved dialog
  }
}

// Message type validation
const processMessage = (type: string) => {
  if (type === MESSAGE_TYPE.APPROVAL_REQUEST) {
    // Handle approval request
  }
}

// Assistant configuration
const getAssistant = () => ASSISTANT_CONFIG.FAE.name // "Fae"

// Network settings
const timeout = NETWORK_CONFIG.CONNECT_TIMEOUT_MS // 10000
```
