A centralized configuration file that exports constants and type definitions for chat dialog functionality in the Flamingo platform, providing type-safe enums for dialog states, message types, and network settings.

## Key Components

- **DIALOG_STATUS** - Dialog state constants (ON_HOLD, RESOLVED, ACTIVE)
- **CHAT_TYPE** - Chat channel types (CLIENT, ADMIN) 
- **MESSAGE_TYPE** - Message classification types including tool execution and approval flows
- **OWNER_TYPE** - Message sender types (CLIENT, ADMIN, ASSISTANT)
- **APPROVAL_STATUS** - Approval workflow states (PENDING, APPROVED, REJECTED)
- **ASSISTANT_CONFIG** - AI assistant configurations for Fae and Mingo
- **API_ENDPOINTS** - REST API endpoint paths for chat operations
- **NATS_TOPICS** - Messaging topic names for real-time communication
- **STORAGE_KEYS** - Local storage key constants
- **NETWORK_CONFIG** - Network timing and connection settings

## Usage Example

```typescript
import { DIALOG_STATUS, MessageType, ASSISTANT_CONFIG } from './index'

// Type-safe dialog status checking
const isActiveDialog = (status: string) => status === DIALOG_STATUS.ACTIVE

// Message type handling
const handleMessage = (type: MessageType) => {
  switch (type) {
    case MESSAGE_TYPE.TEXT:
      return processTextMessage()
    case MESSAGE_TYPE.EXECUTING_TOOL:
      return showToolExecution()
  }
}

// Assistant configuration
const assistantName = ASSISTANT_CONFIG.FAE.name // "Fae"
const assistantType = ASSISTANT_CONFIG.MINGO.type // "mingo"
```
