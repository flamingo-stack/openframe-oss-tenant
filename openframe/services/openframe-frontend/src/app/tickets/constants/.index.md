Centralized constants and type definitions for the Flamingo dialog and chat system, providing type-safe enums and configuration values for message handling, API endpoints, and network settings.

## Key Components

- **Status Enums**: `DIALOG_STATUS`, `MESSAGE_TYPE`, `APPROVAL_STATUS` for tracking conversation and message states
- **Entity Types**: `CHAT_TYPE`, `OWNER_TYPE`, `ASSISTANT_CONFIG` defining chat participants and AI assistants (Fae, Mingo)
- **API Configuration**: `API_ENDPOINTS`, `NATS_TOPICS` for service communication endpoints
- **Network Settings**: `NETWORK_CONFIG` with timeout, reconnection, and polling parameters
- **Storage Keys**: `STORAGE_KEYS` for consistent local storage access

## Usage Example

```typescript
import { DIALOG_STATUS, MESSAGE_TYPE, ASSISTANT_CONFIG, NETWORK_CONFIG } from './index'

// Type-safe status checking
function isDialogActive(status: string) {
  return status === DIALOG_STATUS.ACTIVE
}

// Message type validation
function handleMessage(type: MessageType) {
  switch (type) {
    case MESSAGE_TYPE.TEXT:
      return 'Regular message'
    case MESSAGE_TYPE.EXECUTING_TOOL:
      return 'Tool execution in progress'
    default:
      return 'Unknown message type'
  }
}

// Assistant configuration
const currentAssistant = ASSISTANT_CONFIG.FAE.name // "Fae"

// Network timeout configuration
const connectionTimeout = NETWORK_CONFIG.CONNECT_TIMEOUT_MS // 10000
```
