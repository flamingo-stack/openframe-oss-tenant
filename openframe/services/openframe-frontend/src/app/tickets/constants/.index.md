Central constants and type definitions for the dialog/chat system, providing type-safe enums and configuration values used throughout the Flamingo chat infrastructure.

## Key Components

- **Status Enums**: `DIALOG_STATUS`, `MESSAGE_TYPE`, `OWNER_TYPE`, `APPROVAL_STATUS` - Core state management constants
- **Chat Types**: `CHAT_TYPE` and `ASSISTANT_CONFIG` - Defines client vs admin chats and AI assistants (Fae/Mingo)
- **API Configuration**: `API_ENDPOINTS`, `NATS_TOPICS`, `STORAGE_KEYS` - Network and storage constants
- **Network Settings**: `NETWORK_CONFIG` - Connection timeouts, retry intervals, and message limits
- **Type Exports**: TypeScript types derived from constants for type safety

## Usage Example

```typescript
import { 
  DIALOG_STATUS, 
  MESSAGE_TYPE, 
  ASSISTANT_CONFIG,
  type DialogStatus,
  type MessageType 
} from './index'

// Type-safe status checking
const currentStatus: DialogStatus = DIALOG_STATUS.ACTIVE

// Message type validation
if (message.type === MESSAGE_TYPE.APPROVAL_REQUEST) {
  // Handle approval workflow
}

// Assistant configuration
const assistantName = ASSISTANT_CONFIG.FAE.name // "Fae"
const assistantType = ASSISTANT_CONFIG.MINGO.type // "mingo"

// Network configuration
const timeout = NETWORK_CONFIG.CONNECT_TIMEOUT_MS // 10000
```

The constants use `as const` assertions to ensure literal types, and companion TypeScript types are exported for strict type checking across the chat system.
