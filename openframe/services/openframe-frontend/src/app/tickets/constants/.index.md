A centralized constants file defining all enums, types, and configuration values used throughout the OpenFrame dialog and messaging system.

## Key Components

- **Status Enums**: `DIALOG_STATUS`, `MESSAGE_TYPE`, `APPROVAL_STATUS` - Define state management for conversations and messages
- **Identity Types**: `CHAT_TYPE`, `OWNER_TYPE`, `ASSISTANT_CONFIG` - Classify chat participants and assistant types (Fae for clients, Mingo for technicians)
- **API Configuration**: `API_ENDPOINTS`, `NATS_TOPICS`, `STORAGE_KEYS` - Define service endpoints and message broker topics
- **Network Settings**: `NETWORK_CONFIG` - Connection timeouts, retry intervals, and message limits
- **Type Definitions**: Corresponding TypeScript types for all constants using `typeof` pattern for type safety

## Usage Example

```typescript
import { 
  DIALOG_STATUS, 
  MESSAGE_TYPE, 
  ASSISTANT_CONFIG,
  type DialogStatus,
  type MessageType 
} from './index'

// Create a new dialog with active status
const dialog = {
  id: 'dialog-123',
  status: DIALOG_STATUS.ACTIVE as DialogStatus,
  chatType: CHAT_TYPE.CLIENT
}

// Handle different message types
function processMessage(type: MessageType) {
  switch (type) {
    case MESSAGE_TYPE.TEXT:
      return handleTextMessage()
    case MESSAGE_TYPE.APPROVAL_REQUEST:
      return handleApprovalRequest()
    case MESSAGE_TYPE.EXECUTING_TOOL:
      return showToolExecution()
  }
}

// Configure assistant
const assistant = ASSISTANT_CONFIG.FAE // For client-facing chat
const mingoAssistant = ASSISTANT_CONFIG.MINGO // For technician support
```
