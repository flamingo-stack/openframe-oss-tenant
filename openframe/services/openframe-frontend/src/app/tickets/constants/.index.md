Central constants and type definitions for the Flamingo chat and dialog system. This file provides all the enums, types, and configuration values used across the platform's AI chat interfaces.

## Key Components

- **Dialog Management**: `DIALOG_STATUS` enum for tracking conversation states (ON_HOLD, RESOLVED, ACTIVE)
- **Chat Types**: `CHAT_TYPE` distinguishing between client and admin AI chat interfaces
- **Message System**: `MESSAGE_TYPE` enum covering all message variants from text to tool execution and approvals
- **User Roles**: `OWNER_TYPE` defining message ownership (CLIENT, ADMIN, ASSISTANT)
- **AI Assistants**: `ASSISTANT_CONFIG` for Fae (client-facing) and Mingo (technician-facing) AI assistants
- **Network Configuration**: Connection timeouts, polling intervals, and NATS messaging topics
- **API Endpoints**: Standardized routes for chat operations and approval workflows

## Usage Example

```typescript
import { 
  DIALOG_STATUS, 
  MESSAGE_TYPE, 
  ASSISTANT_CONFIG,
  type DialogStatus,
  type MessageType 
} from './index'

// Create a new dialog with active status
const newDialog = {
  status: DIALOG_STATUS.ACTIVE,
  chatType: CHAT_TYPE.CLIENT
}

// Handle different message types
function processMessage(type: MessageType) {
  switch (type) {
    case MESSAGE_TYPE.TEXT:
      return handleTextMessage()
    case MESSAGE_TYPE.EXECUTING_TOOL:
      return showToolExecution()
    case MESSAGE_TYPE.APPROVAL_REQUEST:
      return promptUserApproval()
  }
}

// Configure AI assistant
const assistant = ASSISTANT_CONFIG.FAE // For client chat
```
