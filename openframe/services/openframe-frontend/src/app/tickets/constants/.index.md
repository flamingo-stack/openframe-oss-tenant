This file defines shared constants and type definitions for the Flamingo dialog/chat system, providing standardized enums and configuration values used across the application.

## Key Components

- **Dialog Status Constants**: `DIALOG_STATUS` - Tracks dialog states (ON_HOLD, RESOLVED, ACTIVE)
- **Chat Type Constants**: `CHAT_TYPE` - Distinguishes between client and admin chat types  
- **Message Type Constants**: `MESSAGE_TYPE` - Defines various message types including tool execution and approval workflows
- **Owner Type Constants**: `OWNER_TYPE` - Identifies message senders (CLIENT, ADMIN, ASSISTANT)
- **Approval Status Constants**: `APPROVAL_STATUS` - Manages approval workflow states
- **Assistant Configuration**: `ASSISTANT_CONFIG` - Defines Fae (client) and Mingo (admin) AI assistants
- **API Endpoints**: `API_ENDPOINTS` - Chat service API routes
- **NATS Topics**: `NATS_TOPICS` - Message bus topic definitions
- **Network Configuration**: `NETWORK_CONFIG` - Connection timeouts, retry intervals, and message limits

## Usage Example

```typescript
import { DIALOG_STATUS, MESSAGE_TYPE, ASSISTANT_CONFIG } from './index'

// Check dialog status
if (dialog.status === DIALOG_STATUS.ACTIVE) {
  // Handle active dialog
}

// Create a message with proper typing
const message = {
  type: MESSAGE_TYPE.TEXT,
  owner: OWNER_TYPE.CLIENT,
  content: "Hello"
}

// Use assistant configuration
const assistant = ASSISTANT_CONFIG.FAE
console.log(`Using ${assistant.name} assistant`) // "Using Fae assistant"
```
