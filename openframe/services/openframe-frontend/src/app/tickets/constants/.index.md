Central constants and type definitions for the Flamingo chat system, providing type-safe enums for dialog status, message types, API endpoints, and network configuration.

## Key Components

- **Dialog Management**: `DIALOG_STATUS`, `CHAT_TYPE` enums for tracking conversation states
- **Message System**: `MESSAGE_TYPE`, `OWNER_TYPE` enums for categorizing chat messages and participants
- **Approval Workflow**: `APPROVAL_STATUS` enum for managing admin approval requests
- **AI Assistants**: `ASSISTANT_CONFIG` defining Fae (client) and Mingo (admin) assistant types
- **API Configuration**: `API_ENDPOINTS` for chat service routes and `NATS_TOPICS` for real-time messaging
- **Network Settings**: `NETWORK_CONFIG` with connection timeouts, reconnection delays, and message limits
- **Storage**: `STORAGE_KEYS` for local storage management

## Usage Example

```typescript
import { DIALOG_STATUS, MESSAGE_TYPE, ASSISTANT_CONFIG, type DialogStatus, type MessageType } from './index'

// Type-safe dialog status handling
const updateDialogStatus = (status: DialogStatus) => {
  if (status === DIALOG_STATUS.RESOLVED) {
    console.log('Dialog completed')
  }
}

// Message type checking
const processMessage = (type: MessageType) => {
  switch (type) {
    case MESSAGE_TYPE.APPROVAL_REQUEST:
      return handleApprovalRequest()
    case MESSAGE_TYPE.EXECUTED_TOOL:
      return displayToolResult()
  }
}

// Assistant configuration
const assistantName = ASSISTANT_CONFIG.FAE.name // "Fae"
```
