Central constants and type definitions for the dialog system, providing enums for chat statuses, message types, ownership, and configuration values used throughout the chat interface.

## Key Components

- **Dialog Management**: `DIALOG_STATUS` enum for tracking conversation states (active, on hold, resolved)
- **Chat Types**: `CHAT_TYPE` distinguishing between client and admin AI chats  
- **Message System**: `MESSAGE_TYPE` enum covering text, tool execution, approvals, and system messages
- **Ownership**: `OWNER_TYPE` defining message senders (client, admin, assistant)
- **Assistants**: `ASSISTANT_CONFIG` for Fae (client assistant) and Mingo (admin assistant)
- **API Configuration**: `API_ENDPOINTS` for REST endpoints and `NATS_TOPICS` for real-time messaging
- **Network Settings**: `NETWORK_CONFIG` with timeouts, reconnection delays, and message limits

## Usage Example

```typescript
import { 
  DIALOG_STATUS, 
  MESSAGE_TYPE, 
  ASSISTANT_CONFIG,
  type DialogStatus,
  type MessageType 
} from './index'

// Check dialog state
const isActive = (status: DialogStatus) => status === DIALOG_STATUS.ACTIVE

// Handle different message types
const processMessage = (type: MessageType) => {
  switch (type) {
    case MESSAGE_TYPE.TEXT:
      return handleTextMessage()
    case MESSAGE_TYPE.EXECUTING_TOOL:
      return showToolExecution()
    case MESSAGE_TYPE.APPROVAL_REQUEST:
      return requestApproval()
  }
}

// Configure assistant
const mingoConfig = ASSISTANT_CONFIG.MINGO
console.log(`Using ${mingoConfig.name} assistant`) // "Using Mingo assistant"
```
