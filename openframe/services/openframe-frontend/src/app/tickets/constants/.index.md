Centralized constants and type definitions for the OpenFrame dialog and chat system, providing type-safe enums and configuration values used across the platform.

## Key Components

- **Status Enums**: `DIALOG_STATUS`, `MESSAGE_TYPE`, `APPROVAL_STATUS` - Define state management for conversations and approvals
- **Identity Types**: `CHAT_TYPE`, `OWNER_TYPE`, `AssistantType` - Classify chat participants and conversation types
- **Assistant Configuration**: `ASSISTANT_CONFIG` - Defines Fae (client AI) and Mingo (admin AI) assistant types
- **API & Network Config**: `API_ENDPOINTS`, `NATS_TOPICS`, `NETWORK_CONFIG` - Service endpoints and connection settings
- **Storage Keys**: `STORAGE_KEYS` - Consistent local storage key definitions

## Usage Example

```typescript
import { DIALOG_STATUS, MESSAGE_TYPE, ASSISTANT_CONFIG, type DialogStatus, type MessageType } from './index'

// Type-safe status checking
const isDialogActive = (status: DialogStatus) => status === DIALOG_STATUS.ACTIVE

// Message type validation
const handleMessage = (type: MessageType) => {
  switch (type) {
    case MESSAGE_TYPE.TEXT:
      return handleTextMessage()
    case MESSAGE_TYPE.APPROVAL_REQUEST:
      return handleApprovalRequest()
    default:
      return handleUnknownMessage()
  }
}

// Assistant configuration
const getFaeConfig = () => ASSISTANT_CONFIG.FAE
// Returns: { type: 'fae', name: 'Fae' }
```

This module ensures consistent typing and values across the OpenFrame chat system, preventing magic strings and providing compile-time safety for dialog states, message types, and system configuration.
