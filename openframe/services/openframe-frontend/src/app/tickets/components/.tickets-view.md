A client-side React component that renders the main tickets view with tabbed navigation and filtering capabilities. It manages URL parameters for tab selection and status filtering to provide a stateful, bookmarkable tickets interface.

## Key Components

- **`TicketsView`** - Main component that orchestrates the tickets interface with tab navigation and content display
- **`useApiParams`** - Hook for managing URL parameters with type safety and defaults
- **`TicketsTabNavigation`** - Child component handling tab switching UI
- **`TicketsTabContent`** - Child component rendering filtered ticket content based on active tab and status

## Usage Example

```typescript
// Basic usage in a page component
import { TicketsView } from './components/tickets-view'

export default function TicketsPage() {
  return (
    <div className="container mx-auto">
      <h1>Support Tickets</h1>
      <TicketsView />
    </div>
  )
}

// The component automatically manages URL state:
// /tickets?tab=current&status=open,pending
// /tickets?tab=closed&status=resolved
```

The component uses URL parameters to maintain state, allowing users to bookmark specific views and enabling proper browser back/forward navigation. The `tab` parameter defaults to 'current' and `status` accepts an array of filter values for multi-select filtering.
