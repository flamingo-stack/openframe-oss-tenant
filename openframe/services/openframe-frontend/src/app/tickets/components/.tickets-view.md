A React component that provides a tabbed interface for managing and viewing support tickets with URL parameter state management.

## Key Components

- **TicketsView** - Main component that coordinates the tabbed tickets interface
- **useApiParams** - Hook for managing URL parameters with type safety
- **TicketsTabNavigation** - Child component handling tab navigation UI
- **TicketsTabContent** - Child component rendering the content for each tab

## Usage Example

```typescript
import { TicketsView } from './tickets-view'

// Used in a tickets management page
function TicketsPage() {
  return (
    <div className="container mx-auto p-4">
      <h1>Support Tickets</h1>
      <TicketsView />
    </div>
  )
}
```

The component maintains URL synchronization for the active tab (defaulting to 'current') and status filters array. Tab changes and filter updates are handled through the `setParam` function, ensuring the UI state persists across page refreshes and can be bookmarked. The layout uses Flexbox with full width for responsive ticket management.
