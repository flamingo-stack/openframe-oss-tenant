A React client component that provides the main view for the tickets management interface, handling tab navigation and content display with URL parameter synchronization.

## Key Components

- **TicketsView** - Main component that orchestrates the tickets interface
- **useApiParams** - Custom hook for managing URL parameters with type safety
- **TicketsTabNavigation** - Child component for tab switching UI
- **TicketsTabContent** - Child component that renders content based on active tab and filters

## Usage Example

```typescript
import { TicketsView } from './tickets-view'

export default function TicketsPage() {
  return (
    <div className="container mx-auto">
      <h1>Support Tickets</h1>
      <TicketsView />
    </div>
  )
}
```

The component automatically manages URL state for the active tab (defaulting to 'current') and status filters, allowing users to bookmark or share specific filtered views of tickets. The layout uses Flexbox to stack the navigation tabs above the content area.
