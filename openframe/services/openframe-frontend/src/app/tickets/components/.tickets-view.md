Main container component for the tickets management interface, providing tabbed navigation and content with URL parameter synchronization.

## Key Components

- **TicketsView** - Root component that orchestrates the tickets interface layout and state management
- **useApiParams hook** - Manages URL parameters for tab selection and status filtering with default values
- **TicketsTabNavigation** - Tab navigation component for switching between ticket views
- **TicketsTabContent** - Main content area that displays tickets based on active tab and filters

## Usage Example

```typescript
import { TicketsView } from './tickets-view'

// Basic usage in a page component
export default function TicketsPage() {
  return (
    <div className="container mx-auto p-4">
      <h1 className="text-2xl font-bold mb-6">Support Tickets</h1>
      <TicketsView />
    </div>
  )
}

// URL parameters are automatically managed:
// - /tickets?tab=current (default)
// - /tickets?tab=archived&status=open,pending
```

The component automatically handles URL state synchronization, allowing users to bookmark specific ticket views and maintaining state across page refreshes. The tab parameter defaults to 'current' and status filters default to an empty array (showing all statuses).
