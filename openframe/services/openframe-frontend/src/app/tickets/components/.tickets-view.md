A React client-side component that provides the main view for the tickets interface, managing URL-synced parameters for tab navigation and status filtering.

## Key Components

- **TicketsView**: Main component that orchestrates the tickets interface
- **useApiParams**: Custom hook for managing URL-synchronized parameters with type safety
- **TicketsTabNavigation**: Child component for tab switching interface
- **TicketsTabContent**: Child component that displays filtered ticket content

## Usage Example

```typescript
import { TicketsView } from './tickets-view'

// In a page component
export default function TicketsPage() {
  return (
    <div className="container">
      <h1>Support Tickets</h1>
      <TicketsView />
    </div>
  )
}
```

The component automatically handles URL parameter synchronization, allowing users to bookmark specific tab/filter combinations. The `tab` parameter defaults to 'current' and the `status` parameter accepts an array of status filters. State changes are reflected in the URL for better user experience and navigation.
