Main view component for the tickets interface that manages tab navigation and content display with URL-synchronized state. Provides a clean separation between navigation controls and content rendering.

## Key Components

- **TicketsView** - Primary component that orchestrates the tickets interface
- **useApiParams** - Hook for managing URL-synchronized parameters
- **TicketsTabNavigation** - Child component for tab switching controls
- **TicketsTabContent** - Child component that renders content based on active tab

## Usage Example

```typescript
import { TicketsView } from './tickets-view'

export default function TicketsPage() {
  return (
    <div className="container mx-auto p-4">
      <h1>Support Tickets</h1>
      <TicketsView />
    </div>
  )
}
```

The component automatically handles URL parameters for `tab` (defaults to 'current') and `status` (array for filtering), ensuring the interface state persists across browser navigation and page refreshes.
