React component that provides the main view for managing and displaying tickets with tabbed navigation and filtering capabilities.

## Key Components

- **TicketsView** - Main component that orchestrates the tickets interface with state management
- **useApiParams** - Hook for managing URL-based parameters with type safety and defaults
- **TicketsTabNavigation** - Child component for tab switching functionality
- **TicketsTabContent** - Child component that renders ticket content based on active tab and filters

## Usage Example

```typescript
import { TicketsView } from './tickets-view'

export default function TicketsPage() {
  return (
    <div className="container mx-auto p-4">
      <h1 className="text-2xl font-bold mb-6">Support Tickets</h1>
      <TicketsView />
    </div>
  )
}
```

The component automatically manages URL parameters for `tab` (defaults to 'current') and `status` (defaults to empty array), allowing users to bookmark and share filtered ticket views. The state synchronization between navigation and content components is handled through the shared parameter management system.
