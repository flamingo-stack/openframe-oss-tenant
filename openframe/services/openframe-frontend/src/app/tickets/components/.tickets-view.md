A React client component that provides the main interface for viewing and managing support tickets with tab-based navigation and filtering capabilities.

## Key Components

- **TicketsView** - Main component that orchestrates the tickets interface
- **useApiParams** - Custom hook for managing URL parameters with type safety
- **TicketsTabNavigation** - Tab navigation component for switching between ticket views
- **TicketsTabContent** - Content area that displays tickets based on active tab and filters

## Usage Example

```typescript
import { TicketsView } from './tickets-view'

// Use in a page or layout component
export default function TicketsPage() {
  return (
    <div className="container mx-auto p-4">
      <h1 className="text-2xl font-bold mb-6">Support Tickets</h1>
      <TicketsView />
    </div>
  )
}
```

The component automatically manages URL state for the active tab (defaults to 'current') and status filters, allowing users to bookmark and share specific ticket views. The flexible parameter system supports both string values for tab selection and array values for multi-select status filtering.
