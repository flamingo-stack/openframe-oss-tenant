A React client component that provides the main view for the tickets management interface, handling tab navigation and URL parameter synchronization.

## Key Components

- **TicketsView**: Main component that orchestrates the tickets interface
- **useApiParams**: Hook for managing URL parameters with type safety
- **TicketsTabNavigation**: Child component for tab switching interface
- **TicketsTabContent**: Child component that renders tab-specific content

## Usage Example

```typescript
import { TicketsView } from './tickets-view'

// Basic usage in a page or layout
export default function TicketsPage() {
  return (
    <div className="container">
      <h1>Support Tickets</h1>
      <TicketsView />
    </div>
  )
}
```

The component automatically manages URL state for the active tab (defaulting to 'current') and status filters, ensuring bookmarkable URLs and proper browser navigation. The tab parameter accepts string values while status accepts an array of filter values, both synchronized with the browser's URL parameters for seamless user experience.
