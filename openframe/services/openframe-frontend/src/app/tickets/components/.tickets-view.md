A React component that provides the main view for the tickets management interface, handling tab navigation and content rendering with URL parameter synchronization.

## Key Components

- **TicketsView**: Main component that orchestrates the tickets interface
- **useApiParams**: Custom hook for managing URL parameters with type safety
- **TicketsTabNavigation**: Child component for tab switching UI
- **TicketsTabContent**: Child component that renders content based on active tab

## Usage Example

```typescript
import { TicketsView } from './tickets-view'

// Use in a page or layout component
export default function TicketsPage() {
  return (
    <div className="container mx-auto">
      <h1>Support Tickets</h1>
      <TicketsView />
    </div>
  )
}
```

The component automatically manages URL parameters for the current tab (`current` by default) and status filters (empty array by default), enabling shareable URLs and browser back/forward navigation. The layout uses flexbox for responsive design with full width container.
