Main React component that renders the tickets management interface with tabbed navigation and URL-based parameter management.

## Key Components

- **TicketsView**: Primary container component that orchestrates the tickets interface
- **useApiParams**: Custom hook for managing URL parameters with type safety
- **TicketsTabNavigation**: Child component handling tab switching UI
- **TicketsTabContent**: Child component rendering tab-specific content with filtering

## Usage Example

```typescript
import { TicketsView } from './tickets-view'

export default function TicketsPage() {
  return (
    <div className="container mx-auto">
      <h1>Support Tickets</h1>
      <TicketsView />
    </div>
  )
}
```

The component manages two URL parameters:
- `tab`: String parameter defaulting to 'current' for active tab selection
- `status`: Array parameter for ticket status filtering

Parameter changes automatically update the URL and trigger re-renders of child components, enabling bookmarkable filtered views and browser navigation support.
