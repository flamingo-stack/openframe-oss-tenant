A React component that provides the main view for the tickets interface, managing tab navigation and filtering state through URL parameters.

## Key Components

- **TicketsView**: Main container component that orchestrates the tickets interface
- **useApiParams**: Hook for managing URL-synchronized parameters (tab selection and status filters)
- **TicketsTabNavigation**: Child component for tab navigation controls
- **TicketsTabContent**: Child component that displays filtered ticket content

## Usage Example

```typescript
import { TicketsView } from './tickets-view'

export default function TicketsPage() {
  return (
    <div className="container mx-auto p-4">
      <h1>Support Tickets</h1>
      <TicketsView />
    </div>
  )
}
```

The component automatically syncs the active tab ('current' by default) and status filter array with URL parameters, enabling deep linking and browser navigation. Tab changes update the URL via `setParam('tab', tab)`, while status filter changes are handled through `setParam('status', status)`. The layout uses Flexbox to stack the navigation and content vertically with full width.
