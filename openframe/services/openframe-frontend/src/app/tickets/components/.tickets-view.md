Main view component for the tickets interface that manages tab navigation and URL-synchronized parameters. Provides a clean separation between navigation controls and content display with persistent state management.

## Key Components

- **`TicketsView`** - Primary container component that orchestrates the tickets interface
- **URL State Management** - Uses `useApiParams` to sync tab selection and status filters with URL parameters
- **`TicketsTabNavigation`** - Tab navigation component for switching between ticket views
- **`TicketsTabContent`** - Content area that displays tickets based on active tab and filters

## Usage Example

```typescript
import { TicketsView } from './tickets-view'

export default function TicketsPage() {
  return (
    <div className="container mx-auto p-4">
      <h1 className="text-2xl font-bold mb-6">Support Tickets</h1>
      <TicketsView />
    </div>
  )
}
```

The component automatically handles URL synchronization, so navigating to `/tickets?tab=closed&status=resolved,pending` will:
- Set the active tab to "closed"
- Apply status filters for "resolved" and "pending" tickets
- Maintain these parameters across browser navigation and page refreshes
