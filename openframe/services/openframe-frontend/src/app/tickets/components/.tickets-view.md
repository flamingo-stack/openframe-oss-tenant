Main view component that manages ticket display state and navigation, coordinating between tab navigation and content display with URL-persisted parameters.

## Key Components

- **TicketsView** - Main container component that orchestrates the tickets interface
- **useApiParams hook** - Manages URL-synchronized parameters for tab and status filtering
- **TicketsTabNavigation** - Tab navigation component for switching between ticket views
- **TicketsTabContent** - Content display component that renders tickets based on active tab and filters

## Usage Example

```typescript
import { TicketsView } from './tickets-view'

// Basic usage in a page component
export default function TicketsPage() {
  return (
    <div className="container mx-auto p-4">
      <h1>Support Tickets</h1>
      <TicketsView />
    </div>
  )
}

// The component automatically handles:
// - URL parameters: ?tab=current&status[]=open&status[]=pending
// - Tab switching between different ticket views
// - Status filtering with multiple selections
// - State persistence across page refreshes
```

The component uses a declarative approach where URL parameters define the current view state, making it easy to share filtered ticket views via URL and maintain state across browser navigation.
