A client-side React component that renders a complete tickets management interface with tabbed navigation and filtering capabilities, using URL-synchronized parameters for state management.

## Key Components

- **TicketsView** - Main container component that orchestrates the tickets interface
- **useApiParams** - Hook for managing URL-synchronized parameters with type definitions
- **TicketsTabNavigation** - Child component for tab switching functionality
- **TicketsTabContent** - Child component that displays ticket content based on active tab and filters

## Usage Example

```typescript
import { TicketsView } from './tickets-view'

// Use in a page or parent component
export default function TicketsPage() {
  return (
    <div className="container mx-auto">
      <h1>Support Tickets</h1>
      <TicketsView />
    </div>
  )
}

// URL parameters are automatically managed:
// /tickets?tab=closed&status[]=resolved&status[]=archived
```

The component automatically synchronizes the active tab (`current` by default) and status filters (empty array by default) with URL parameters, providing shareable URLs and browser history support. The layout uses Flexbox with full width to ensure proper responsive behavior within the parent container.
