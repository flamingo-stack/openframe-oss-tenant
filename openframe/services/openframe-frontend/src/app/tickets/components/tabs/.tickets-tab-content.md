A React component that dynamically renders tab content for the tickets interface, handling tab switching and status filtering functionality.

## Key Components

- **TicketsTabContent**: Main component that renders the appropriate tab content based on the active tab
- **TicketsTabContentProps**: Interface defining the component's props including active tab and status filters
- **getTabComponent**: Utility function from the OpenFrame core that retrieves the correct tab component
- **TICKETS_TABS**: Configuration object containing available ticket tabs

## Usage Example

```typescript
import { TicketsTabContent } from './tickets-tab-content'

function TicketsPage() {
  const [activeTab, setActiveTab] = useState('all')
  const [statusFilters, setStatusFilters] = useState<string[]>(['open', 'in-progress'])

  return (
    <div>
      <TicketsTabContent 
        activeTab={activeTab}
        statusFilters={statusFilters}
        onStatusFilterChange={setStatusFilters}
      />
    </div>
  )
}
```

The component provides error handling for invalid tabs by displaying a user-friendly "Tab Not Found" message. It maintains a minimum height of 400px and passes through status filtering props to the dynamically loaded tab components, enabling consistent filtering behavior across different ticket views.
