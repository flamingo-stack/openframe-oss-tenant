A React component that dynamically renders tab content for the tickets section based on the currently active tab.

## Key Components

- **TicketsTabContent** - Main component that resolves and renders the appropriate tab component
- **TicketsTabContentProps** - Interface defining component props including active tab and status filter handlers
- **getTabComponent** - Utility function from OpenFrame core that resolves tab components from configuration
- **TICKETS_TABS** - Configuration object defining available ticket tabs

## Usage Example

```typescript
import { TicketsTabContent } from './tickets-tab-content'

function TicketsPage() {
  const [activeTab, setActiveTab] = useState('open-tickets')
  const [statusFilters, setStatusFilters] = useState<string[]>([])

  return (
    <TicketsTabContent
      activeTab={activeTab}
      statusFilters={statusFilters}
      onStatusFilterChange={setStatusFilters}
    />
  )
}
```

The component provides error handling for invalid tabs, displaying a user-friendly message when a requested tab cannot be found. It maintains a minimum height of 400px and passes through status filtering props to the resolved tab component, making it a flexible container for various ticket management interfaces.
