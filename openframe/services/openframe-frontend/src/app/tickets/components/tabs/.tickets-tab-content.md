A React component that renders dynamic tab content for the tickets interface, providing a wrapper that handles tab component resolution and error states.

## Key Components

**TicketsTabContent**: Main component that dynamically renders tab content based on the active tab selection
- `activeTab`: Current tab identifier
- `statusFilters`: Optional array of status filter values
- `onStatusFilterChange`: Optional callback for status filter changes

**Key Dependencies**:
- `getTabComponent`: Utility function from OpenFrame core for tab component resolution
- `TICKETS_TABS`: Configuration object defining available ticket tabs

## Usage Example

```typescript
import { TicketsTabContent } from './tickets-tab-content'

function TicketsView() {
  const [activeTab, setActiveTab] = useState('open')
  const [statusFilters, setStatusFilters] = useState<string[]>(['new', 'in-progress'])

  return (
    <TicketsTabContent
      activeTab={activeTab}
      statusFilters={statusFilters}
      onStatusFilterChange={setStatusFilters}
    />
  )
}
```

The component provides graceful error handling by displaying a "Tab Not Found" message when an invalid tab is selected, while maintaining consistent minimum height styling across all states. It acts as a bridge between the tab navigation and the actual tab content components, passing through filter props to enable consistent filtering behavior across different ticket views.
