A client-side React component that dynamically renders ticket management tab content based on the active tab selection.

## Key Components

- **TicketsTabContent** - Main functional component that renders the appropriate tab content
- **TicketsTabContentProps** - TypeScript interface defining component props including active tab identifier and status filter handlers
- **getTabComponent** - Imported utility function from OpenFrame core that resolves tab configurations to renderable components
- **TICKETS_TABS** - Imported tab configuration object defining available ticket tabs

## Usage Example

```typescript
import { TicketsTabContent } from './tickets-tab-content'

function TicketsPage() {
  const [activeTab, setActiveTab] = useState('open-tickets')
  const [statusFilters, setStatusFilters] = useState<string[]>(['open', 'in-progress'])

  return (
    <TicketsTabContent
      activeTab={activeTab}
      statusFilters={statusFilters}
      onStatusFilterChange={setStatusFilters}
    />
  )
}
```

The component provides error handling for invalid tab selections, displaying a user-friendly "Tab Not Found" message when the requested tab doesn't exist in the `TICKETS_TABS` configuration. It maintains a consistent minimum height of 400px and passes through status filtering capabilities to the rendered tab components.
