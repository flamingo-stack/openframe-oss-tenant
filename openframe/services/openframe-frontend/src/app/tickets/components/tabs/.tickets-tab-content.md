A React component that dynamically renders tab content for the tickets interface based on the active tab selection.

## Key Components

- **TicketsTabContent**: Main component that renders the appropriate tab content based on `activeTab` prop
- **TicketsTabContentProps**: Interface defining the component's props including active tab, status filters, and filter change handler
- **getTabComponent**: Utility function from OpenFrame core that resolves the correct tab component
- **TICKETS_TABS**: Configuration object containing available ticket tabs

## Usage Example

```typescript
import { TicketsTabContent } from './tickets-tab-content'

function TicketsPage() {
  const [activeTab, setActiveTab] = useState('open')
  const [statusFilters, setStatusFilters] = useState<string[]>(['new', 'in-progress'])

  return (
    <TicketsTabContent
      activeTab={activeTab}
      statusFilters={statusFilters}
      onStatusFilterChange={setStatusFilters}
    />
  )
}
```

The component provides error handling by displaying a user-friendly message when an invalid tab is selected. It maintains a consistent minimum height of 400px and passes through status filtering functionality to the rendered tab components. This creates a flexible tab system where each tab can implement its own filtering logic while sharing common props.
