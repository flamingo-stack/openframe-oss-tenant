A React component that dynamically renders tab content for the tickets section based on the active tab selection.

## Key Components

- **`TicketsTabContent`** - Main component that renders the appropriate tab content
- **`TicketsTabContentProps`** - TypeScript interface defining component props
- **`getTabComponent`** - Utility function from OpenFrame core for dynamic tab component resolution
- **`TICKETS_TABS`** - Tab configuration imported from tickets-tabs module

## Usage Example

```typescript
import { TicketsTabContent } from './tickets-tab-content'

function TicketsPage() {
  const [activeTab, setActiveTab] = useState('all')
  const [statusFilters, setStatusFilters] = useState<string[]>([])

  return (
    <div>
      {/* Tab navigation would go here */}
      <TicketsTabContent 
        activeTab={activeTab}
        statusFilters={statusFilters}
        onStatusFilterChange={setStatusFilters}
      />
    </div>
  )
}
```

The component uses dynamic tab resolution to render the correct tab content based on the `activeTab` prop. If the specified tab isn't found in the `TICKETS_TABS` configuration, it displays a user-friendly error message. The component passes through status filtering props to the rendered tab component, enabling consistent filtering behavior across all ticket tabs.
