A React client component that dynamically renders the appropriate tab content based on the active tickets tab selection, handling status filtering and error states.

## Key Components

- **TicketsTabContent**: Main component that resolves and renders the active tab component
- **TicketsTabContentProps**: Interface defining the component props including active tab and status filtering
- **getTabComponent**: Utility function from the OpenFrame core library for tab component resolution
- **TICKETS_TABS**: Tab configuration import that defines available ticket tabs

## Usage Example

```typescript
import { TicketsTabContent } from './tickets-tab-content'

function TicketsPage() {
  const [activeTab, setActiveTab] = useState('open')
  const [statusFilters, setStatusFilters] = useState<string[]>(['pending', 'in-progress'])

  return (
    <div>
      <TicketsTabContent 
        activeTab={activeTab}
        statusFilters={statusFilters}
        onStatusFilterChange={setStatusFilters}
      />
    </div>
  )
}
```

The component provides a fallback error state when an invalid tab is selected, ensuring graceful handling of navigation errors. Status filtering is passed through to the resolved tab component, enabling consistent filtering behavior across all ticket views.
