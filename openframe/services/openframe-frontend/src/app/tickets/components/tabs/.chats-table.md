A React component that renders a searchable, filterable table of chat dialogs (tickets) with pagination support and archiving functionality. This component displays both current and archived chats based on the `isArchived` prop.

## Key Components

- **ChatsTable** - Main table component with search, filters, pagination, and archive functionality
- **CurrentChats** - Wrapper component that renders active chats with `isArchived={false}`
- **ArchivedChats** - Wrapper component that renders archived chats with `isArchived={true}`

The component integrates with organization lookup for displaying client organization names, supports status filtering for active chats, and provides bulk archiving of resolved tickets.

## Usage Example

```typescript
// Display current chats with status filtering
const [statusFilters, setStatusFilters] = useState<string[]>([])

<CurrentChats 
  statusFilters={statusFilters}
  onStatusFilterChange={setStatusFilters}
/>

// Display archived chats (read-only)
<ArchivedChats />

// Direct usage with custom archive state
<ChatsTable 
  isArchived={false}
  statusFilters={['OPEN', 'IN_PROGRESS']}
  onStatusFilterChange={(status) => setFilters(status)}
/>
```

The component automatically handles:
- Cursor-based pagination with server-side data fetching
- Organization name resolution for client-owned dialogs
- Row click navigation to individual ticket details
- Bulk archiving of resolved tickets (for current chats only)
- Mobile-responsive filtering interface
