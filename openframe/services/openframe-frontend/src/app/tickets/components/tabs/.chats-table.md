A React component that renders a paginated table of chat dialogs (tickets) with support for both current and archived states, search functionality, and status filtering.

## Key Components

- **ChatsTable** - Main table component with cursor-based pagination, search, and filtering capabilities
- **CurrentChats** - Wrapper component for displaying active/current chat dialogs
- **ArchivedChats** - Wrapper component for displaying archived chat dialogs
- **Organization Lookup Integration** - Lazy loads organization names for client-owned dialogs
- **Archive Resolved Action** - Allows bulk archiving of resolved dialogs in current view

## Usage Example

```typescript
import { ChatsTable, CurrentChats, ArchivedChats } from './chats-table'

// Main table with full control
function ChatsPage() {
  const [statusFilters, setStatusFilters] = useState<string[]>(['OPEN', 'IN_PROGRESS'])
  
  return (
    <ChatsTable 
      isArchived={false}
      statusFilters={statusFilters}
      onStatusFilterChange={setStatusFilters}
    />
  )
}

// Simplified wrapper components
function CurrentChatsTab() {
  return <CurrentChats statusFilters={['OPEN']} />
}

function ArchivedChatsTab() {
  return <ArchivedChats />
}
```

The component automatically handles organization name resolution for client-owned dialogs, provides row-click navigation to individual dialog details, and includes bulk actions like archiving resolved chats when viewing current dialogs.
