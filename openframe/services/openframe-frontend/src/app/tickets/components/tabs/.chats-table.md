A React component that provides a comprehensive table interface for displaying and managing chat dialogs in both current and archived states, with pagination, filtering, and archival capabilities.

## Key Components

- **`ChatsTable`** - Main table component with configurable archive state and status filtering
- **`CurrentChats`** - Wrapper component for active chat dialogs with filtering enabled
- **`ArchivedChats`** - Wrapper component for archived chat dialogs with read-only view
- **Organization Lookup Integration** - Lazy loads organization names for client-owned dialogs
- **Cursor Pagination** - Server-side pagination with search and filter state management
- **Archive Functionality** - Bulk archival of resolved chat dialogs

## Usage Example

```typescript
// Current chats with status filtering
function ChatDashboard() {
  const [statusFilters, setStatusFilters] = useState<string[]>(['OPEN', 'IN_PROGRESS'])
  
  return (
    <CurrentChats 
      statusFilters={statusFilters}
      onStatusFilterChange={setStatusFilters}
    />
  )
}

// Archived chats (read-only)
function ArchivedChatHistory() {
  return <ArchivedChats />
}

// Direct usage with custom archive state
function CustomChatTable() {
  return (
    <ChatsTable 
      isArchived={false}
      statusFilters={['RESOLVED']}
      onStatusFilterChange={(filters) => console.log('Filters changed:', filters)}
    />
  )
}
```

The component integrates with the Flamingo Stack's UI system, providing consistent styling, pagination controls, and responsive design. It automatically handles organization name resolution for client-owned dialogs and supports bulk operations for chat management workflows.
