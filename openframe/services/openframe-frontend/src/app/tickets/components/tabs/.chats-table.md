A client-side React component that renders a paginated table of chat dialogs with filtering, search, and archive functionality. It supports both current and archived chat views with organization name resolution.

## Key Components

- **ChatsTable**: Main table component with filtering, search, pagination, and archive actions
- **CurrentChats**: Wrapper component for non-archived chats with filtering enabled
- **ArchivedChats**: Wrapper component for archived chats with filtering disabled
- **useDialogsQuery**: Fetches chat dialog data with cursor-based pagination
- **useOrganizationLookup**: Lazy-loads organization names for client-owned dialogs
- **useArchiveResolvedMutation**: Handles archiving of resolved chat dialogs

## Usage Example

```typescript
import { CurrentChats, ArchivedChats } from './chats-table'

// Display current chats with status filtering
function ChatsDashboard() {
  const [statusFilters, setStatusFilters] = useState<string[]>(['ACTIVE'])
  
  return (
    <CurrentChats 
      statusFilters={statusFilters}
      onStatusFilterChange={setStatusFilters}
    />
  )
}

// Display archived chats (read-only)
function ArchivedChatsPage() {
  return <ArchivedChats />
}
```

The component features cursor-based pagination, real-time search, status filtering, row click navigation to dialog details, and bulk archiving of resolved dialogs. It automatically fetches organization names for client-owned dialogs and provides responsive mobile filtering capabilities.
