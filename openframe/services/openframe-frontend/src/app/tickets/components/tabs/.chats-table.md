A React component that renders a paginated table of chat dialogs with support for both current and archived states, featuring search, filtering, and organization lookup functionality.

## Key Components

- **ChatsTable** - Main component that renders dialog/chat data in a table format with pagination
- **CurrentChats** - Wrapper component for active chats (isArchived=false)  
- **ArchivedChats** - Wrapper component for archived chats (isArchived=true)
- **useDialogsQuery** - Hook for fetching dialog data with cursor-based pagination
- **useOrganizationLookup** - Hook for lazy loading organization names
- **useArchiveResolvedMutation** - Hook for archiving resolved dialogs

## Usage Example

```typescript
// Display current chats with status filtering
function ChatManagement() {
  const [statusFilters, setStatusFilters] = useState<string[]>([])

  return (
    <CurrentChats 
      statusFilters={statusFilters}
      onStatusFilterChange={setStatusFilters}
    />
  )
}

// Display archived chats (read-only)
function ArchivedChatView() {
  return <ArchivedChats />
}
```

The component provides a full-featured data table with:
- **Cursor-based pagination** for efficient loading of large datasets
- **Search functionality** across dialog content
- **Status filtering** for current chats (disabled for archived)
- **Organization lookup** for client-owned dialogs
- **Bulk actions** like archiving resolved dialogs
- **Navigation** to individual dialog detail pages
- **Responsive design** with mobile filter support

The table automatically fetches organization names for client dialogs and provides smooth navigation to detailed dialog views when rows are clicked.
