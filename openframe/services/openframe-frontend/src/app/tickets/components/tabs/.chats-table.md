A React table component for displaying chat dialogs in both current and archived states, with pagination, filtering, and organization lookup functionality.

## Key Components

- **`ChatsTable`** - Main component that renders a table of chat dialogs with search, filtering, and pagination
- **`CurrentChats`** - Wrapper component that renders the table for non-archived chats with filtering enabled
- **`ArchivedChats`** - Wrapper component that renders the table for archived chats with filtering disabled
- **Custom Hooks Integration** - Uses `useDialogsQuery` for data fetching, `useCursorPaginationState` for pagination state, and `useOrganizationLookup` for organization name resolution

## Usage Example

```typescript
import { CurrentChats, ArchivedChats } from './chats-table'

// For current chats with status filtering
function CurrentChatsPage() {
  const [statusFilters, setStatusFilters] = useState<string[]>(['OPEN', 'IN_PROGRESS'])
  
  return (
    <CurrentChats 
      statusFilters={statusFilters}
      onStatusFilterChange={setStatusFilters}
    />
  )
}

// For archived chats (no filtering)
function ArchivedChatsPage() {
  return <ArchivedChats />
}
```

The component features lazy organization lookup, cursor-based pagination, row click navigation to ticket details, and bulk archive functionality for resolved chats. It integrates with the OpenFrame UI component system and provides responsive mobile filtering.
