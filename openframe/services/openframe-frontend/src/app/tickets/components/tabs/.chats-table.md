A React component that provides a filterable, searchable table interface for displaying chat dialogs (tickets) with support for both current and archived views, including pagination and bulk operations.

## Key Components

- **ChatsTable** - Main table component with cursor-based pagination, search, and filtering capabilities
- **CurrentChats** - Wrapper for displaying active/current chat dialogs
- **ArchivedChats** - Wrapper for displaying archived chat dialogs
- **useDialogsQuery** - Hook for fetching dialog data with filtering and pagination
- **useOrganizationLookup** - Hook for lazy-loading organization names for client-owned dialogs
- **useArchiveResolvedMutation** - Hook for bulk archiving resolved dialogs

## Usage Example

```typescript
import { ChatsTable, CurrentChats, ArchivedChats } from './chats-table'

// Basic usage with status filtering
function ChatsDashboard() {
  const [statusFilters, setStatusFilters] = useState<string[]>([])

  return (
    <CurrentChats
      statusFilters={statusFilters}
      onStatusFilterChange={setStatusFilters}
    />
  )
}

// Tab-based navigation between current and archived
function ChatsView() {
  const [activeTab, setActiveTab] = useState('current')

  return (
    <div>
      {activeTab === 'current' && <CurrentChats />}
      {activeTab === 'archived' && <ArchivedChats />}
    </div>
  )
}
```

The component handles organization name resolution for client-owned dialogs, provides bulk actions for archiving resolved chats, and supports mobile-responsive filtering. It uses cursor-based pagination for efficient data loading and includes comprehensive error handling and loading states.
