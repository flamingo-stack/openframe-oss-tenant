A comprehensive React table component for displaying and managing chat dialogs in the Flamingo Stack ticketing system. The component provides filtered views for both active and archived conversations with cursor-based pagination, search functionality, and organization lookup capabilities.

## Key Components

- **ChatsTable** - Main table component that handles dialog display, filtering, and pagination
- **CurrentChats** - Wrapper component for displaying active chat dialogs
- **ArchivedChats** - Wrapper component for displaying archived chat dialogs
- **useDialogsQuery** - Custom hook for fetching dialog data with cursor pagination
- **useOrganizationLookup** - Hook for lazy-loading organization names for client dialogs
- **useArchiveResolvedMutation** - Hook for bulk archiving resolved dialogs

## Usage Example

```typescript
import { CurrentChats, ArchivedChats } from './chats-table'

// Display active chats with status filtering
function ActiveChatsPage() {
  const [statusFilters, setStatusFilters] = useState<string[]>([])
  
  return (
    <CurrentChats
      statusFilters={statusFilters}
      onStatusFilterChange={setStatusFilters}
    />
  )
}

// Display archived chats (read-only)
function ArchivedChatsPage() {
  return <ArchivedChats />
}

// Custom implementation with archived state
function CustomChatsTable() {
  const [isArchived, setIsArchived] = useState(false)
  
  return (
    <ChatsTable
      isArchived={isArchived}
      statusFilters={['OPEN', 'IN_PROGRESS']}
      onStatusFilterChange={(status) => console.log('Status changed:', status)}
    />
  )
}
```

The component features cursor-based pagination, real-time organization name resolution, bulk archive operations for resolved dialogs, and responsive design with mobile filter support. It integrates with Next.js routing for dialog navigation and provides comprehensive loading states and error handling.
