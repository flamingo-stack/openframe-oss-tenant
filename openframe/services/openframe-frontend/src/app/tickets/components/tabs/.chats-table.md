React component that displays chat dialogs in a paginated table format, supporting both current and archived chat views with filtering and search functionality.

## Key Components

- **ChatsTable** - Main table component with cursor-based pagination, search, and status filtering
- **CurrentChats** - Wrapper component for displaying active chats with filtering enabled
- **ArchivedChats** - Wrapper component for displaying archived chats with filtering disabled
- **useDialogsQuery** - Custom hook for fetching paginated dialog data
- **useOrganizationLookup** - Hook for lazy loading organization names for display
- **useArchiveResolvedMutation** - Mutation hook for bulk archiving resolved chats

## Usage Example

```typescript
import { CurrentChats, ArchivedChats } from './chats-table'

// Display current chats with status filtering
function ActiveChatsPage() {
  const [statusFilters, setStatusFilters] = useState<string[]>([])
  
  return (
    <CurrentChats 
      statusFilters={statusFilters}
      onStatusFilterChange={setStatusFilters}
    />
  )
}

// Display archived chats (read-only)
function ArchivedChatsPage() {
  return <ArchivedChats />
}

// Direct usage with custom archive state
function CustomChatsView() {
  return (
    <ChatsTable 
      isArchived={false}
      statusFilters={['OPEN', 'IN_PROGRESS']}
      onStatusFilterChange={(filters) => console.log(filters)}
    />
  )
}
```

The component features organization name resolution, row-level navigation to individual chat dialogs, bulk archiving of resolved chats, and responsive mobile filtering support.
