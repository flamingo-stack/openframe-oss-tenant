A comprehensive React table component for displaying and managing chat dialogs with support for both current and archived views, including search, filtering, pagination, and bulk operations.

## Key Components

- **ChatsTable** - Main component handling dialog display with cursor-based pagination and organization lookups
- **CurrentChats** - Wrapper for displaying active/unarchived dialogs with filtering capabilities
- **ArchivedChats** - Wrapper for displaying archived dialogs in read-only mode
- **useCursorPaginationState** - Custom hook managing pagination state and search parameters
- **useDialogsQuery** - Data fetching hook with filtering and pagination support
- **useOrganizationLookup** - Lazy loading hook for organization name resolution
- **useArchiveResolvedMutation** - Mutation hook for bulk archiving resolved dialogs

## Usage Example

```typescript
import { ChatsTable, CurrentChats, ArchivedChats } from './chats-table'
import { useState } from 'react'

// Direct usage with full control
function ChatPage() {
  const [statusFilters, setStatusFilters] = useState<string[]>(['OPEN', 'IN_PROGRESS'])
  
  return (
    <ChatsTable 
      isArchived={false}
      statusFilters={statusFilters}
      onStatusFilterChange={setStatusFilters}
    />
  )
}

// Using wrapper components for tab navigation
function ChatTabs() {
  const [filters, setFilters] = useState<string[]>([])
  
  return (
    <div>
      <CurrentChats 
        statusFilters={filters}
        onStatusFilterChange={setFilters}
      />
      <ArchivedChats />
    </div>
  )
}
```

The component automatically handles organization name fetching for client-owned dialogs, provides bulk archive functionality for resolved chats, and supports responsive mobile filtering with cursor-based pagination for optimal performance.
