A React component that renders a paginated, filterable table for displaying chat dialogs with support for both current and archived views.

## Key Components

- **`ChatsTable`** - Main component that handles chat dialog display with pagination, search, filtering, and archiving functionality
- **`CurrentChats`** - Wrapper component for non-archived chats with filtering capabilities
- **`ArchivedChats`** - Wrapper component for archived chats view

## Features

- **Cursor-based pagination** with server-side data loading
- **Real-time search** across chat dialogs
- **Status filtering** for current chats (disabled for archived view)
- **Organization lookup** for client-owned dialogs
- **Bulk archive resolved chats** functionality
- **Mobile-responsive filtering** with dedicated mobile filter interface
- **Row click navigation** to individual chat dialog pages

## Usage Example

```typescript
import { CurrentChats, ArchivedChats } from './chats-table'

function ChatsPage() {
  const [statusFilters, setStatusFilters] = useState<string[]>([])

  return (
    <div>
      {/* Current chats with filtering */}
      <CurrentChats 
        statusFilters={statusFilters}
        onStatusFilterChange={setStatusFilters}
      />
      
      {/* Archived chats (read-only) */}
      <ArchivedChats />
    </div>
  )
}
```

The component integrates with the OpenFrame UI system and uses custom hooks for data fetching, pagination state management, and organization lookups. It automatically loads organization names for client-owned dialogs and provides a bulk archive action for resolved chats.
