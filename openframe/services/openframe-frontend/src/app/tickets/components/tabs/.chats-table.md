A React component that displays chat dialogs in a paginated table format, supporting both current and archived views with search, filtering, and organization lookup capabilities.

## Key Components

- **`ChatsTable`** - Main table component with cursor-based pagination, search, and status filtering
- **`CurrentChats`** - Wrapper component for displaying active chats
- **`ArchivedChats`** - Wrapper component for displaying archived chats
- **Organization Lookup** - Lazy-loaded organization names for client-owned dialogs
- **Archive Functionality** - Bulk archive action for resolved chats

## Usage Example

```typescript
import { ChatsTable, CurrentChats, ArchivedChats } from './chats-table'

// Full control with ChatsTable
function ChatsPage() {
  const [statusFilters, setStatusFilters] = useState<string[]>([])
  
  return (
    <ChatsTable
      isArchived={false}
      statusFilters={statusFilters}
      onStatusFilterChange={setStatusFilters}
    />
  )
}

// Using wrapper components
function CurrentChatsTab() {
  return <CurrentChats statusFilters={['OPEN', 'IN_PROGRESS']} />
}

function ArchivedChatsTab() {
  return <ArchivedChats />
}
```

The component integrates with the OpenFrame UI system, providing cursor-based pagination, real-time search, column filtering, and row click navigation to individual dialog views. It automatically fetches organization names for client-owned dialogs and supports bulk archiving of resolved chats.
