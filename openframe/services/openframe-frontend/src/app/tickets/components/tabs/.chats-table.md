A React component that displays a table of chat dialogs with filtering, search, and pagination capabilities. The component supports both current and archived chats with status filtering and the ability to archive resolved chats.

## Key Components

**Main Exports:**
- `ChatsTable` - Primary table component that accepts `isArchived`, `statusFilters`, and `onStatusFilterChange` props
- `CurrentChats` - Wrapper component that sets `isArchived={false}`
- `ArchivedChats` - Wrapper component that sets `isArchived={true}`

**Key Features:**
- Cursor-based pagination with server-side data fetching
- Dynamic organization lookup for dialog owners
- Row-level click navigation to dialog details
- Bulk archive operation for resolved chats
- Real-time filtering by status
- Responsive search functionality

## Usage Example

```typescript
import { ChatsTable, CurrentChats, ArchivedChats } from './chats-table'

// Basic usage with wrapper components
function ChatTabs() {
  const [statusFilters, setStatusFilters] = useState<string[]>([])
  
  return (
    <div>
      <CurrentChats 
        statusFilters={statusFilters}
        onStatusFilterChange={setStatusFilters}
      />
      
      <ArchivedChats />
    </div>
  )
}

// Direct usage with custom configuration
function CustomChatTable() {
  return (
    <ChatsTable
      isArchived={false}
      statusFilters={['OPEN', 'IN_PROGRESS']}
      onStatusFilterChange={(filters) => console.log('Filters changed:', filters)}
    />
  )
}
```

The component integrates with the OpenFrame UI system, providing a consistent table experience with loading states, error handling, and responsive design patterns.
