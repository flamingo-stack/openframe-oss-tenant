A React table component for displaying and managing chat dialogs with support for both current and archived views, cursor-based pagination, filtering, and bulk operations.

## Key Components

- **ChatsTable** - Main table component with pagination, search, filtering, and archive functionality
- **CurrentChats** - Wrapper for displaying active/current chat dialogs 
- **ArchivedChats** - Wrapper for displaying archived chat dialogs
- **ChatsTableProps** - Interface defining component props including archive state and status filters

## Usage Example

```typescript
import { ChatsTable, CurrentChats, ArchivedChats } from './chats-table'

// Main component with full control
function ChatManagement() {
  const [statusFilters, setStatusFilters] = useState<string[]>(['OPEN', 'IN_PROGRESS'])
  
  return (
    <ChatsTable 
      isArchived={false}
      statusFilters={statusFilters}
      onStatusFilterChange={setStatusFilters}
    />
  )
}
```

The component integrates with organization lookup for displaying client information, provides cursor-based pagination for large datasets, and includes bulk archive operations for resolved tickets. It uses the ListPageLayout for consistent UI patterns and supports both desktop filtering and mobile filter sheets.
