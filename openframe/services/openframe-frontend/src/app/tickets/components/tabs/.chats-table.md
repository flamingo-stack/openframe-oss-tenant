A React table component that displays chat dialogs (tickets) with support for both current and archived views, featuring search, filtering, pagination, and bulk archive operations.

## Key Components

**Main Component:**
- `ChatsTable` - Core table component with configurable archived state and status filtering
- `CurrentChats` - Wrapper for displaying active chat dialogs
- `ArchivedChats` - Wrapper for displaying archived chat dialogs

**Key Features:**
- Cursor-based pagination with lazy loading
- Organization name lookup for client-owned dialogs
- Status-based filtering (disabled for archived view)
- Bulk archive operation for resolved dialogs
- Row-level navigation to individual dialog pages

**Props Interface:**
- `isArchived: boolean` - Determines table mode and available actions
- `statusFilters?: string[]` - Optional status filter array
- `onStatusFilterChange?: (status: string[]) => void` - Filter change callback

## Usage Example

```typescript
import { CurrentChats, ArchivedChats } from './chats-table'

// Current chats with status filtering
function ActiveChatsPage() {
  const [statusFilters, setStatusFilters] = useState<string[]>(['OPEN', 'IN_PROGRESS'])
  
  return (
    <CurrentChats 
      statusFilters={statusFilters}
      onStatusFilterChange={setStatusFilters}
    />
  )
}

// Archived chats (read-only)
function ArchivedChatsPage() {
  return <ArchivedChats />
}

// Custom implementation with different archive state
function CustomChatTable() {
  return (
    <ChatsTable 
      isArchived={false}
      statusFilters={['RESOLVED']}
      onStatusFilterChange={(filters) => console.log('Filters:', filters)}
    />
  )
}
```
