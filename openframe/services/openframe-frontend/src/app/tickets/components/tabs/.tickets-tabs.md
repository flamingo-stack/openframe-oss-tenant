A tab navigation component for managing current and archived chat tickets with clean URL state handling and customizable tab switching behavior.

## Key Components

- **`TICKETS_TABS`** - Static configuration array defining current and archived chat tabs with icons and components
- **`getTicketsTab()`** - Helper function to find a tab by ID
- **`getTabComponent()`** - Helper function to retrieve a tab's React component
- **`TicketsTabNavigation`** - Main component providing tab navigation with URL synchronization

## Usage Example

```typescript
import { TicketsTabNavigation, getTabComponent } from './tickets-tabs'

// Basic usage with default URL handling
function TicketsPage() {
  return (
    <div>
      <TicketsTabNavigation activeTab="current" />
    </div>
  )
}

// Custom tab change handling
function CustomTicketsPage() {
  const handleTabChange = (tabId: string) => {
    console.log('Switching to tab:', tabId)
    // Custom logic here
  }

  return (
    <TicketsTabNavigation 
      activeTab="archived" 
      onTabChange={handleTabChange} 
    />
  )
}

// Getting tab component dynamically
const TabComponent = getTabComponent('current') // Returns CurrentChats
```

The component uses Next.js router for URL management and clears tab-specific parameters when switching between tabs to ensure a clean state for each tab view.
