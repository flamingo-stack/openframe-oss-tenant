A React component for managing ticket system navigation between current and archived chat tabs with routing integration.

## Key Components

- **TICKETS_TABS**: Configuration array defining available tabs (current/archived chats) with icons and components
- **getTicketsTab()**: Utility function to find a specific tab configuration by ID
- **getTabComponent()**: Returns the React component associated with a given tab ID
- **TicketsTabNavigation**: Main navigation component with URL synchronization and tab switching logic

## Usage Example

```typescript
import { TicketsTabNavigation, getTabComponent } from './tickets-tabs'

// Basic tab navigation
function TicketsPage() {
  return (
    <div>
      <TicketsTabNavigation activeTab="current" />
      {/* Tab content renders based on active tab */}
    </div>
  )
}

// Custom tab change handling
function CustomTicketsPage() {
  const [activeTab, setActiveTab] = useState('current')
  
  const handleTabChange = (tabId: string) => {
    console.log(`Switching to ${tabId}`)
    setActiveTab(tabId)
  }

  const TabComponent = getTabComponent(activeTab)
  
  return (
    <div>
      <TicketsTabNavigation 
        activeTab={activeTab}
        onTabChange={handleTabChange}
      />
      {TabComponent && <TabComponent />}
    </div>
  )
}
```

The component automatically handles URL parameter updates and provides clean navigation between chat views while clearing tab-specific parameters on switches.
