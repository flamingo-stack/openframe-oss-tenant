A React component that provides tabbed navigation for ticket management, organizing current and archived chat conversations.

## Key Components

- **`TICKETS_TABS`** - Array of tab configuration objects defining current and archived chat tabs
- **`getTicketsTab()`** - Utility function to find a tab by ID
- **`getTabComponent()`** - Returns the React component associated with a specific tab
- **`TicketsTabNavigation`** - Main navigation component with URL synchronization and tab switching

## Usage Example

```typescript
import { TicketsTabNavigation, getTabComponent } from './tickets-tabs'

function TicketsPage({ searchParams }: { searchParams: { tab?: string } }) {
  const activeTab = searchParams.tab || 'current'
  const TabComponent = getTabComponent(activeTab)

  return (
    <div>
      <TicketsTabNavigation activeTab={activeTab} />
      {TabComponent && <TabComponent />}
    </div>
  )
}

// Custom tab change handler
function CustomTicketsNav() {
  const handleTabChange = (tabId: string) => {
    console.log('Switching to tab:', tabId)
    // Custom navigation logic
  }

  return (
    <TicketsTabNavigation 
      activeTab="current"
      onTabChange={handleTabChange}
    />
  )
}
```

The component automatically handles URL synchronization and provides a clean slate when switching between tabs by clearing tab-specific parameters.
