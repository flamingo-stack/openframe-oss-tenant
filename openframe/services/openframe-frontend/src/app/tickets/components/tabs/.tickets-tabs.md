A client-side React component that provides tabbed navigation for tickets/chat management with support for current and archived chat views.

## Key Components

- **TICKETS_TABS**: Configuration array defining available tabs (current chats, archived chats) with associated icons and components
- **getTicketsTab()**: Helper function to retrieve a specific tab configuration by ID
- **getTabComponent()**: Helper function to extract the React component for a given tab
- **TicketsTabNavigation**: Main navigation component that renders tabs and handles navigation state

## Usage Example

```typescript
import { TicketsTabNavigation, getTabComponent } from './tickets-tabs'

// Basic usage with default navigation
function TicketsPage() {
  return (
    <div>
      <TicketsTabNavigation />
      {/* Tab content will be handled by the component itself */}
    </div>
  )
}

// Advanced usage with custom tab change handling
function CustomTicketsPage() {
  const [currentTab, setCurrentTab] = useState('current')
  
  const handleTabChange = (tabId: string) => {
    setCurrentTab(tabId)
    // Custom logic for tab changes
  }

  const TabComponent = getTabComponent(currentTab)

  return (
    <div>
      <TicketsTabNavigation 
        activeTab={currentTab}
        onTabChange={handleTabChange} 
      />
      {TabComponent && <TabComponent />}
    </div>
  )
}
```

The component automatically manages URL synchronization and provides a clean navigation experience by clearing tab-specific parameters when switching between tabs.
