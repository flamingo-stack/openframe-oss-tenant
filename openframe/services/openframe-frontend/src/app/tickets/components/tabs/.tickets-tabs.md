A React component that manages tab navigation for the tickets/chats interface, providing current and archived chat views with URL synchronization.

## Key Components

- **TICKETS_TABS**: Static array defining available tab configurations (current and archived chats)
- **getTicketsTab()**: Utility function to retrieve a specific tab by ID
- **getTabComponent()**: Helper to extract the React component for a given tab
- **TicketsTabNavigation**: Main component that renders the tab navigation with URL routing integration

## Usage Example

```typescript
import { TicketsTabNavigation, getTabComponent } from './tickets-tabs'

// Basic usage with default URL handling
function TicketsPage() {
  return <TicketsTabNavigation />
}

// Custom tab change handling
function CustomTicketsPage() {
  const handleTabChange = (tabId: string) => {
    console.log('Switching to tab:', tabId)
    // Custom logic here
  }

  return (
    <TicketsTabNavigation 
      activeTab="archived"
      onTabChange={handleTabChange}
    />
  )
}

// Get component dynamically
const ChatComponent = getTabComponent('current') // Returns CurrentChats
```

The component automatically clears URL parameters when switching tabs to provide a clean state for each tab view. It integrates with Next.js routing using `useRouter` and `usePathname` hooks.
