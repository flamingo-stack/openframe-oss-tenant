A React component that manages tabbed navigation for ticket/chat management interfaces, providing tabs for current and archived chats with URL synchronization.

## Key Components

- **`TICKETS_TABS`** - Configuration array defining available tabs (Current Chats, Archived Chats)
- **`getTicketsTab()`** - Helper function to find a tab by ID
- **`getTabComponent()`** - Returns the React component associated with a tab ID
- **`TicketsTabNavigation`** - Main navigation component with tab switching logic

## Usage Example

```typescript
import { TicketsTabNavigation, getTabComponent } from './tickets-tabs'

function TicketsPage() {
  const [activeTab, setActiveTab] = useState('current')
  
  const TabComponent = getTabComponent(activeTab)

  return (
    <div>
      <TicketsTabNavigation 
        activeTab={activeTab}
        onTabChange={setActiveTab}
      />
      {TabComponent && <TabComponent />}
    </div>
  )
}

// Or with automatic URL sync (default behavior)
function SimpleTicketsPage() {
  return <TicketsTabNavigation />
}
```

The component automatically handles URL parameter updates when tabs are switched, clearing previous tab-specific parameters to provide a clean state for each tab. It integrates with Next.js routing and uses the OpenFrame UI component library for consistent styling.
