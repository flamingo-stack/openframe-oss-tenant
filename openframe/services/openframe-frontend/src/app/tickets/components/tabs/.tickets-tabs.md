A client-side React component that provides tab navigation for tickets/chat management, allowing users to switch between current and archived conversations with URL synchronization.

## Key Components

- `TICKETS_TABS` - Array defining available tab configurations (current and archived chats)
- `getTicketsTab()` - Helper function to find a tab by its ID
- `getTabComponent()` - Utility to extract the React component for a specific tab
- `TicketsTabNavigation` - Main navigation component with URL routing integration

## Usage Example

```typescript
import { TicketsTabNavigation, getTabComponent } from './tickets-tabs'

// Basic usage with default behavior
function TicketsPage() {
  return (
    <div>
      <TicketsTabNavigation />
    </div>
  )
}

// Custom tab change handler
function CustomTicketsPage() {
  const handleTabChange = (tabId: string) => {
    console.log('Switching to tab:', tabId)
    // Custom logic before tab change
  }

  return (
    <TicketsTabNavigation 
      activeTab="archived"
      onTabChange={handleTabChange}
    />
  )
}

// Get tab component dynamically
const TabComponent = getTabComponent('current') // Returns CurrentChats component
```

The component automatically clears URL parameters when switching tabs to provide a clean slate, and integrates with Next.js routing for proper navigation state management.
