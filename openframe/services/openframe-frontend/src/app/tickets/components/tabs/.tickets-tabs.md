A Next.js client-side component that manages tabbed navigation for tickets/chats interface with current and archived views.

## Key Components

- **TICKETS_TABS**: Configuration array defining available tabs (Current Chats, Archived Chats) with their icons and associated components
- **getTicketsTab()**: Utility function to find a tab by ID
- **getTabComponent()**: Helper to retrieve the React component for a specific tab
- **TicketsTabNavigation**: Main navigation component that handles tab switching with URL synchronization

## Usage Example

```typescript
import { TicketsTabNavigation, getTabComponent } from './tickets-tabs'

// Basic usage with default behavior
function TicketsPage() {
  return (
    <div>
      <TicketsTabNavigation />
      {/* Tab content will be handled by the navigation component */}
    </div>
  )
}

// Custom tab change handling
function CustomTicketsPage() {
  const [activeTab, setActiveTab] = useState('current')
  
  const handleTabChange = (tabId: string) => {
    setActiveTab(tabId)
    // Custom logic here
  }

  const TabComponent = getTabComponent(activeTab)

  return (
    <div>
      <TicketsTabNavigation 
        activeTab={activeTab}
        onTabChange={handleTabChange} 
      />
      {TabComponent && <TabComponent />}
    </div>
  )
}
```

The component automatically clears URL parameters when switching tabs to provide a clean slate for each tab view. It integrates with Next.js routing and uses the OpenFrame design system components.
