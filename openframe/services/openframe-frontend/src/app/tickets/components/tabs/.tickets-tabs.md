A React component that provides tab navigation for tickets/chats interface, managing both current and archived chat views with URL synchronization and clean parameter handling.

## Key Components

- **`TICKETS_TABS`** - Array of tab configuration objects defining current and archived chat tabs
- **`getTicketsTab()`** - Utility function to find a tab by its ID
- **`getTabComponent()`** - Returns the React component associated with a specific tab ID
- **`TicketsTabNavigation`** - Main component that renders the tab navigation interface

## Usage Example

```typescript
import { TicketsTabNavigation, getTabComponent } from './tickets-tabs'

// Basic usage with default navigation
function TicketsPage() {
  return (
    <div>
      <TicketsTabNavigation activeTab="current" />
    </div>
  )
}

// Custom tab change handling
function CustomTicketsPage() {
  const handleTabChange = (tabId: string) => {
    console.log('Tab changed to:', tabId)
    // Custom logic here
  }

  return (
    <TicketsTabNavigation 
      activeTab="archived" 
      onTabChange={handleTabChange} 
    />
  )
}

// Get specific tab component
const CurrentChatsComponent = getTabComponent('current')
```

The component automatically clears URL parameters when switching tabs to ensure a clean state, and integrates with Next.js routing for seamless navigation between current and archived chat views.
