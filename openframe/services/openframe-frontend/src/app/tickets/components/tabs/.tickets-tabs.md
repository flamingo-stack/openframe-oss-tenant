A React component that provides tabbed navigation for managing current and archived chat tickets in the OpenFrame platform.

## Key Components

- **`TICKETS_TABS`** - Configuration array defining available tabs (current/archived chats)
- **`getTicketsTab()`** - Helper function to find a tab by ID
- **`getTabComponent()`** - Helper function to get the React component for a specific tab
- **`TicketsTabNavigation`** - Main component that renders the tab navigation with URL synchronization

## Usage Example

```typescript
import { TicketsTabNavigation } from './tickets-tabs'

// Basic usage with default behavior
function TicketsPage() {
  return (
    <div>
      <TicketsTabNavigation />
    </div>
  )
}

// Custom tab change handler
function CustomTicketsPage() {
  const handleTabChange = (tabId: string) => {
    console.log('Switching to tab:', tabId)
    // Custom logic here
  }

  return (
    <TicketsTabNavigation 
      activeTab="current"
      onTabChange={handleTabChange}
    />
  )
}

// Get specific tab configuration
const currentTab = getTicketsTab('current')
const CurrentComponent = getTabComponent('current')
```

The component automatically clears URL parameters when switching tabs to provide a clean slate for each tab's state management. It integrates with Next.js routing for URL synchronization and uses icons from the OpenFrame core component library.
