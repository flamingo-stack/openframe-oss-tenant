A React component that provides tabbed navigation for managing current and archived chat tickets in the OpenFrame MSP platform.

## Key Components

- **`TICKETS_TABS`** - Configuration array defining the two main tabs (Current Chats and Archived Chats) with their icons and components
- **`getTicketsTab()`** - Helper function to retrieve a specific tab configuration by ID
- **`getTabComponent()`** - Utility to extract the React component for a given tab
- **`TicketsTabNavigation`** - Main navigation component that renders the tab interface with URL synchronization

## Usage Example

```typescript
import { TicketsTabNavigation, getTabComponent } from './tickets-tabs'

// Basic usage with default behavior
function TicketsPage() {
  return (
    <div>
      <TicketsTabNavigation />
      {/* Tab content will be handled by the navigation component */}
    </div>
  )
}

// Custom tab change handling
function CustomTicketsPage() {
  const [activeTab, setActiveTab] = useState('current')
  
  const handleTabChange = (tabId: string) => {
    setActiveTab(tabId)
    // Custom logic here
  }

  return (
    <div>
      <TicketsTabNavigation 
        activeTab={activeTab}
        onTabChange={handleTabChange}
      />
    </div>
  )
}

// Get specific tab component
const CurrentChatsComponent = getTabComponent('current')
```

The component automatically handles URL parameter management, clearing tab-specific parameters when switching between tabs to ensure a clean state for each view.
