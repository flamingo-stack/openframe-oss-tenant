A client-side React component that provides tabbed navigation for tickets/chat management in the OpenFrame platform, allowing users to switch between current and archived chats.

## Key Components

- **TICKETS_TABS**: Array of tab configuration objects defining current and archived chat tabs with their respective icons and components
- **getTicketsTab()**: Utility function to find a specific tab by its ID
- **getTabComponent()**: Helper function to extract the React component for a given tab ID
- **TicketsTabNavigation**: Main navigation component that renders tabs with URL synchronization and clean state management

## Usage Example

```typescript
import { TicketsTabNavigation, getTabComponent, TICKETS_TABS } from './tickets-tabs'

// Basic usage with default tab switching
function TicketsPage() {
  return (
    <div>
      <TicketsTabNavigation />
      {/* Tab content renders automatically based on URL */}
    </div>
  )
}

// Custom tab change handling
function CustomTicketsPage() {
  const [currentTab, setCurrentTab] = useState('current')
  
  const handleTabChange = (tabId: string) => {
    // Custom logic before tab change
    console.log(`Switching to ${tabId}`)
    setCurrentTab(tabId)
  }

  return (
    <TicketsTabNavigation 
      activeTab={currentTab}
      onTabChange={handleTabChange} 
    />
  )
}

// Get specific tab component
const CurrentChatsComponent = getTabComponent('current')
```

The component automatically clears URL parameters when switching tabs to ensure clean state transitions between current and archived chat views.
