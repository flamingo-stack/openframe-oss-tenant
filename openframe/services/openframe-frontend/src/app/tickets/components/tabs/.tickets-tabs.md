A React component that provides tabbed navigation for managing chat tickets, with current and archived views using the OpenFrame design system.

## Key Components

- `TICKETS_TABS` - Static array defining two tabs: "Current Chats" and "Archived Chats" with their respective icons and components
- `getTicketsTab()` - Helper function to find a tab by ID
- `getTabComponent()` - Helper function to retrieve the component associated with a tab
- `TicketsTabNavigation` - Main navigation component that handles tab switching with URL synchronization

## Usage Example

```typescript
import { TicketsTabNavigation, getTabComponent } from './tickets-tabs'

// Basic usage with default navigation
function TicketsPage() {
  return (
    <div>
      <TicketsTabNavigation />
      {/* Tab content will be handled by the navigation */}
    </div>
  )
}

// Custom tab handling
function CustomTicketsPage() {
  const [activeTab, setActiveTab] = useState('current')
  
  const handleTabChange = (tabId: string) => {
    setActiveTab(tabId)
    // Custom logic here
  }

  const TabComponent = getTabComponent(activeTab)

  return (
    <div>
      <TicketsTabNavigation 
        activeTab={activeTab}
        onTabChange={handleTabChange}
      />
      {TabComponent && <TabComponent />}
    </div>
  )
}
```

The component automatically clears URL parameters when switching tabs to ensure a clean state, and defaults to the "current" tab if no active tab is specified.
