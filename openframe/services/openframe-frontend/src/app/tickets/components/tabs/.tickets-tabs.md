A React client component that manages tab navigation for chat/ticket management in the OpenFrame MSP platform, providing organized access to current and archived support conversations.

## Key Components

- **TICKETS_TABS**: Predefined tab configuration array containing current and archived chat tabs with associated icons and components
- **getTicketsTab()**: Helper function to retrieve a specific tab by ID
- **getTabComponent()**: Utility to extract the React component associated with a tab ID
- **TicketsTabNavigation**: Main component that renders tab navigation with URL synchronization and clean state management

## Usage Example

```typescript
import { TicketsTabNavigation, TICKETS_TABS, getTabComponent } from './tickets-tabs'

// Basic usage with default tab switching
function TicketsPage() {
  return (
    <div>
      <TicketsTabNavigation />
    </div>
  )
}

// Custom tab change handling
function CustomTicketsPage() {
  const [currentTab, setCurrentTab] = useState('current')
  
  const handleTabChange = (tabId: string) => {
    // Custom logic before tab switch
    console.log(`Switching to ${tabId}`)
    setCurrentTab(tabId)
  }

  return (
    <TicketsTabNavigation 
      activeTab={currentTab}
      onTabChange={handleTabChange}
    />
  )
}

// Getting tab components dynamically
const CurrentComponent = getTabComponent('current') // Returns CurrentChats
```

The component implements clean URL management by clearing tab-specific parameters when switching between current and archived chat views, ensuring a fresh state for each tab.
