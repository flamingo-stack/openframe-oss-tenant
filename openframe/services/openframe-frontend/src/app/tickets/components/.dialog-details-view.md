A React component that displays a detailed view of a dialog/chat conversation with real-time messaging capabilities, status management, and approval workflows for the OpenFrame platform.

## Key Components

- **Dialog Management**: Handles loading dialog details, messages, and real-time updates through NATS subscriptions
- **Dual Chat Views**: Displays both client-facing chat (Fae) and admin chat (Mingo) with appropriate message processing
- **Status Controls**: Provides buttons to put dialogs on hold or mark as resolved
- **Approval System**: Manages approval requests within messages with approve/reject functionality
- **Real-time Processing**: Handles streaming messages, typing indicators, and chunk-based updates
- **Device Information**: Shows device details for client-owned dialogs

## Usage Example

```typescript
import { DialogDetailsView } from './dialog-details-view'

export function DialogPage({ params }: { params: { id: string } }) {
  return (
    <div className="h-full">
      <DialogDetailsView dialogId={params.id} />
    </div>
  )
}

// The component automatically handles:
// - Loading dialog and message data
// - Setting up NATS subscriptions for real-time updates
// - Processing historical messages with error handling
// - Managing approval request states
// - Providing admin message sending capabilities
```

The component integrates with multiple custom hooks for dialog status management, NATS messaging, chunk processing, and approval workflows, providing a comprehensive interface for managing customer support conversations within the Flamingo MSP platform.
