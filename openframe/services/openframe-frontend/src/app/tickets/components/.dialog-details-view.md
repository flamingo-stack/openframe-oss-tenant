A React component that displays detailed information and chat interfaces for a specific dialog in the OpenFrame platform, featuring real-time messaging, approval workflows, and dialog status management.

## Key Components

- **`DialogDetailsView`** - Main component handling dialog display with dual chat interfaces (client/admin)
- **Real-time Processing** - Integrates NATS subscription for live message updates and chunk processing
- **Message Processing** - Converts raw messages into UI-friendly format with approval handling
- **Status Management** - Controls dialog state transitions (hold, resolve) with optimistic updates
- **Chat Interfaces** - Renders separate client and admin chat views with typing indicators

## Usage Example

```typescript
import { DialogDetailsView } from './dialog-details-view'

function DialogPage({ params }: { params: { id: string } }) {
  return (
    <div className="min-h-screen">
      <DialogDetailsView dialogId={params.id} />
    </div>
  )
}

// Component handles:
// - Loading dialog data and messages on mount
// - Real-time message streaming via NATS
// - Approval request processing with status tracking
// - Dialog status updates (hold/resolve)
// - Admin message sending with error handling

export default DialogPage
```

The component automatically establishes real-time connections, processes historical messages with error handling, and provides interactive controls for dialog management and approval workflows.
