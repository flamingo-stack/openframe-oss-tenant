A React component that renders a detailed view of a customer support dialog with real-time chat functionality, approval management, and dialog status controls for MSP technicians.

## Key Components

- **DialogDetailsView**: Main component handling dialog display with dual chat interfaces (client and admin)
- **Real-time Updates**: NATS subscription system for live message streaming and typing indicators
- **Message Processing**: Converts historical messages to chat format with approval request handling
- **Status Management**: Dialog status controls (put on hold, resolve) with optimistic updates
- **Chunk Catchup**: Handles message synchronization when reconnecting to real-time streams

## Usage Example

```typescript
import { DialogDetailsView } from './dialog-details-view'

// Render dialog details page
function DialogPage({ params }: { params: { id: string } }) {
  return (
    <DialogDetailsView dialogId={params.id} />
  )
}

// Component handles all dialog state management internally
// - Loads dialog data and messages on mount
// - Subscribes to real-time updates via NATS
// - Processes approval requests and status changes
// - Provides admin chat interface for technician responses
```

The component integrates with Zustand stores for state management, custom hooks for real-time functionality, and the OpenFrame chat system for seamless client-technician communication. It automatically handles message synchronization, typing indicators, and approval workflow states within the MSP support interface.
