A React component that provides a detailed view interface for dialog management in the OpenFrame platform, featuring real-time messaging, approval workflows, and dialog status management.

## Key Components

- **DialogDetailsView** - Main component handling dialog display with dual chat interfaces
- **Real-time Processing** - NATS subscription for live message updates and streaming
- **Message Processing** - Historical message parsing with approval request extraction
- **Status Management** - Dialog state controls (put on hold, resolve)
- **Approval System** - Interactive approval/rejection handling for requests
- **Chat Interfaces** - Separate client and admin chat views with typing indicators

## Usage Example

```typescript
import { DialogDetailsView } from './dialog-details-view'

// Display dialog details page
function DialogPage({ params }: { params: { id: string } }) {
  return (
    <div className="min-h-screen">
      <DialogDetailsView dialogId={params.id} />
    </div>
  )
}

// Handle dialog status updates
const handleStatusChange = async (dialogId: string, status: string) => {
  const success = await putOnHold(dialogId)
  if (success) {
    updateDialogStatus(DIALOG_STATUS.ON_HOLD)
  }
}

// Process real-time message chunks

```

The component integrates multiple hooks for real-time communication, manages dual chat streams for client and admin interactions, and provides a comprehensive interface for dialog management with approval workflows and status controls.
