A React component that displays detailed view of a dialog/chat conversation with real-time messaging, approval handling, and admin capabilities. It manages both client and admin chat streams with NATS subscription for live updates.

## Key Components

- **DialogDetailsView** - Main component for viewing dialog details
- **Real-time messaging** - NATS-based live chat updates with typing indicators
- **Message processing** - Handles historical and streaming messages with error handling
- **Approval system** - Manages approval requests with approve/reject functionality
- **Status management** - Dialog status updates (on hold, resolved)
- **Dual chat streams** - Separate client and admin message processing
- **Chunk catchup** - Synchronizes missed messages when reconnecting

## Usage Example

```typescript
import { DialogDetailsView } from './dialog-details-view'

// Display dialog details page
function DialogPage({ params }: { params: { id: string } }) {
  return <DialogDetailsView dialogId={params.id} />
}

// Router integration
<Route path="/dialogs/:id" element={<DialogDetailsView />} />
```

The component integrates with multiple stores and hooks for state management, real-time updates via NATS messaging, and provides a comprehensive chat interface with device information display and approval workflow handling.
