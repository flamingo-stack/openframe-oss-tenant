A React component that renders the detailed view of a chat dialog in the OpenFrame platform, supporting both client and admin messaging with real-time updates and approval workflows.

## Key Components

- **Main Component**: `DialogDetailsView` - Primary component managing dialog details display
- **State Management**: Uses `useDialogDetailsStore` for dialog/message state
- **Real-time Processing**: `useDialogRealtimeProcessor` and `useNatsDialogSubscription` for live updates
- **Message Processing**: `processMessages` function converting raw messages to display format
- **Action Handlers**: Functions for dialog status changes (hold/resolve) and approval workflows
- **Chat Interface**: Integrated `ChatMessageList` and `ChatInput` components

## Usage Example

```typescript
import { DialogDetailsView } from './dialog-details-view'

// Basic usage in a page component
export default function DialogPage({ params }: { params: { id: string } }) {
  return <DialogDetailsView dialogId={params.id} />
}

// With routing context
function App() {
  return (
    <BrowserRouter>
      <Route path="/dialogs/:id" element={
        <DialogDetailsView dialogId={useParams().id} />
      } />
    </BrowserRouter>
  )
}
```

The component handles complex real-time messaging scenarios including typing indicators, chunk processing for streaming responses, approval request workflows, and maintains separate chat contexts for client and admin communications. It integrates with NATS messaging for real-time updates and provides a complete chat interface with device information display.
