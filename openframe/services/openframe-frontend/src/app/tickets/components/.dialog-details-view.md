A React component for displaying detailed dialog views with dual chat interfaces, real-time messaging, and approval workflow management in the Flamingo Stack OpenFrame platform.

## Key Components

- **DialogDetailsView**: Main component managing dialog state and real-time communication
- **useDialogDetailsStore**: Zustand store for dialog and message state management
- **useNatsDialogSubscription**: Real-time subscription hook for NATS messaging
- **useChunkCatchup**: Handles message chunk processing and catch-up logic
- **useApprovalRequests**: Manages approval workflow operations
- **processMessages**: Transforms raw messages into UI-ready format with approval segments

## Usage Example

```typescript
import { DialogDetailsView } from './dialog-details-view'

// Render dialog details page
function DialogPage({ params }: { params: { id: string } }) {
  return (
    <DialogDetailsView dialogId={params.id} />
  )
}

// The component automatically handles:
// - Loading dialog and message data
// - Real-time message updates via NATS
// - Approval request processing
// - Chat message sending (admin/client)
// - Dialog status updates (hold/resolve)
```

The component provides a comprehensive interface for managing customer support dialogs with features like device information display, dual chat tabs (client/admin), typing indicators, message approval workflows, and real-time synchronization. It integrates with the OpenFrame ecosystem for MSP operations and utilizes NATS for real-time communication.
