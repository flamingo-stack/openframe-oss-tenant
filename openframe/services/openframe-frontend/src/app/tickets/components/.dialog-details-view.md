A React component that renders a detailed view of a dialog session with real-time chat functionality, device information, and administrative controls for MSP technicians in the OpenFrame platform.

## Key Components

- **DialogDetailsView**: Main component handling dialog display and real-time updates
- **Chat Systems**: Dual chat interfaces for client (Fae AI) and admin (Mingo AI) conversations
- **Real-time Processing**: NATS subscription for live message streaming and chunk processing
- **Dialog Management**: Status controls (put on hold, resolve) and approval request handling
- **Message Processing**: Historical message processing with error handling and approval workflows

## Usage Example

```typescript
import { DialogDetailsView } from './dialog-details-view'

// In a dialog detail page
export default function DialogPage({ params }: { params: { id: string } }) {
  return (
    <div className="container mx-auto p-6">
      <DialogDetailsView dialogId={params.id} />
    </div>
  )
}

// Example of how the component handles real-time updates
const handleNatsEvent = useCallback(
  (payload: unknown, messageType: NatsMessageType) => {
    const processed = processChunk(payload as any, messageType as 'message' | 'admin-message')
    if (!processed) return
  },
  [processChunk]
)
```

The component integrates multiple custom hooks for real-time functionality (`useNatsDialogSubscription`, `useChunkCatchup`, `useDialogRealtimeProcessor`) and manages complex state for dual chat systems, approval workflows, and dialog status updates. It automatically handles message catchup, typing indicators, and approval request processing for seamless MSP operations.
