A React component that displays a detailed view of a dialog/chat conversation with real-time messaging capabilities, status management, and admin controls. It manages both client and admin chat streams with NATS real-time subscriptions.

## Key Components

- **DialogDetailsView** - Main component handling dialog display and interactions
- **Real-time Processing** - Uses `useDialogRealtimeProcessor` and `useChunkCatchup` for live message streaming
- **Status Management** - Handles dialog status changes (on hold, resolved) via `useDialogStatus`
- **Approval System** - Manages approval requests with `useApprovalRequests` hook
- **NATS Integration** - Real-time message subscription through `useNatsDialogSubscription`
- **Chat Interface** - Renders separate client and admin chat streams with typing indicators

## Usage Example

```typescript
// Used in a Next.js page or component to display dialog details
import { DialogDetailsView } from './dialog-details-view'

export default function DialogPage({ params }: { params: { id: string } }) {
  return <DialogDetailsView dialogId={params.id} />
}

// The component handles:
// - Loading dialog data and message history
// - Real-time message streaming via NATS
// - Admin actions (put on hold, resolve, send messages)
// - Approval request handling
// - Chat processing for both client (Fae) and admin (Mingo) assistants
```

The component integrates with the Flamingo OpenFrame ecosystem, providing a comprehensive chat interface with real-time capabilities, status management, and approval workflows for MSP support operations.
