A React component that displays detailed view of support dialogs with real-time messaging, status management, and approval workflows. It provides both client and admin chat interfaces with streaming message support.

## Key Components

- **DialogDetailsView** - Main component for dialog detail view with real-time chat functionality
- **Chat interfaces** - Separate client and admin chat channels with streaming support
- **Status management** - Dialog status controls (hold, resolve) with optimistic updates
- **Approval system** - Request approval/rejection handling with status tracking
- **Real-time processing** - NATS subscription for live message streaming and chunked data
- **Message processing** - Historical message processing with error handling and type safety

## Usage Example

```typescript
import { DialogDetailsView } from './dialog-details-view'

// Basic usage in a page component
export default function DialogPage({ params }: { params: { id: string } }) {
  return <DialogDetailsView dialogId={params.id} />
}

// With routing integration
function ChatRouter() {
  const router = useRouter()
  
  return (
    <Routes>
      <Route 
        path="/dialog/:dialogId" 
        element={<DialogDetailsView dialogId={params.dialogId} />} 
      />
    </Routes>
  )
}
```
