A React component that provides a comprehensive chat interface for viewing and managing individual dialog conversations in the OpenFrame platform.

## Key Components

- **DialogDetailsView**: Main component handling dialog display with real-time messaging
- **State Management**: Uses Zustand store (`useDialogDetailsStore`) for dialog and message state
- **Real-time Features**: NATS subscription for live message updates and typing indicators
- **Message Processing**: Handles both client and admin chat streams with approval workflows
- **Status Management**: Controls dialog lifecycle (active, on hold, resolved)
- **Approval System**: Interactive approval/rejection interface for pending requests

## Usage Example

```typescript
import { DialogDetailsView } from './dialog-details-view'

// Render dialog details page
function DialogPage({ params }: { params: { id: string } }) {
  return <DialogDetailsView dialogId={params.id} />
}

// Component handles:
// - Loading dialog data and messages
// - Real-time message streaming via NATS
// - Admin message sending
// - Dialog status updates (hold/resolve)
// - Approval request handling
// - Typing indicators for both client and admin chats
```

The component integrates multiple custom hooks for NATS subscriptions, chunk processing, approval management, and real-time message handling, providing a complete chat management interface with device information display and interactive controls.
