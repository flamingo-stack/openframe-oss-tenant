A comprehensive React component for viewing and managing dialog details with real-time messaging, approval workflows, and status management capabilities.

## Key Components

- **DialogDetailsView** - Main component for displaying dialog conversations with dual-chat interface (client/admin)
- **Real-time Processing** - Handles NATS subscriptions and chunk-based message streaming
- **Approval Management** - Processes approval requests with approve/reject functionality
- **Status Controls** - Provides dialog status management (hold, resolve)
- **Message Processing** - Converts historical messages to display format with error handling
- **Typing Indicators** - Shows real-time typing status for both chat types

## Usage Example

```typescript
import { DialogDetailsView } from './dialog-details-view'

// Basic usage in a page component
export default function DialogPage({ params }: { params: { id: string } }) {
  return (
    <div className="container">
      <DialogDetailsView dialogId={params.id} />
    </div>
  )
}

// With error boundary
export default function DialogPageWithErrorBoundary({ params }: { params: { id: string } }) {
  return (
    <ErrorBoundary fallback={<DialogErrorFallback />}>
      <DialogDetailsView dialogId={params.id} />
    </ErrorBoundary>
  )
}
```

The component automatically handles loading states, real-time message updates via NATS, approval request processing, and provides admin controls for dialog status management. It integrates with the OpenFrame frontend core components for consistent UI and messaging functionality.
