A React component that provides a comprehensive interface for viewing and managing dialog conversations in the OpenFrame platform, with real-time messaging, approval workflows, and status management capabilities.

## Key Components

**Main Component:**
- `DialogDetailsView` - Complete dialog viewing interface with dual-chat support

**Core Features:**
- Real-time message streaming with NATS subscription
- Client and admin chat separation with different AI assistants (Fae/Mingo)
- Approval request handling with status tracking
- Dialog status management (on hold, resolved)
- Message catchup mechanism for reconnection scenarios
- Auto-scroll functionality for new messages

**Key Hooks Integration:**
- `useDialogDetailsStore` - State management for dialog data
- `useDialogStatus` - Status update operations
- `useNatsDialogSubscription` - Real-time event subscription
- `useChunkCatchup` - Message synchronization after disconnection
- `useDialogRealtimeProcessor` - Real-time message processing

## Usage Example

```typescript
import { DialogDetailsView } from './dialog-details-view'

function DialogPage({ params }: { params: { id: string } }) {
  return (
    <div className="h-full">
      <DialogDetailsView dialogId={params.id} />
    </div>
  )
}

// The component automatically handles:
// - Loading dialog data and messages
// - Setting up real-time subscriptions
// - Processing approval requests
// - Managing typing indicators
// - Cleanup on unmount
```

The component renders a detail page container with device information, dual chat interfaces (client and admin), message lists with approval handling, and action buttons for dialog status management. It maintains real-time synchronization and provides a complete conversation management experience for support workflows.
