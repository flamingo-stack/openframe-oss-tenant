This is the main dialog details view component that displays a comprehensive real-time chat interface for IT support conversations between clients and admin AI assistants (Fae and Mingo) in the OpenFrame platform.

## Key Components

- **DialogDetailsView** - Main component managing dual-chat interface with real-time message processing
- **Real-time hooks integration** - NATS subscription, chunk catchup, and realtime processors
- **Message processing system** - Historical message processing with error handling and approval workflows
- **Dialog status management** - Put on hold, resolve, and status update functionality
- **Dual chat interface** - Separate client (Fae) and admin (Mingo) chat channels
- **Approval system** - Handle approval requests with approve/reject functionality

## Usage Example

```typescript
import { DialogDetailsView } from './dialog-details-view'

export default function DialogPage({ params }: { params: { id: string } }) {
  return (
    <div className="h-full">
      <DialogDetailsView dialogId={params.id} />
    </div>
  )
}

// The component automatically handles:
// - Real-time message streaming via NATS
// - Message history loading with pagination
// - Typing indicators for both chat channels
// - Approval request processing
// - Dialog status updates (hold/resolve)
// - Error handling and user feedback
```

The component provides a complete support ticket interface with real-time chat capabilities, approval workflows, device information display, and comprehensive error handling for the OpenFrame MSP platform.
