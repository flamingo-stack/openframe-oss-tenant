A React component that displays detailed dialog (chat conversation) view with real-time messaging, approval workflows, and status management capabilities for the OpenFrame MSP platform.

## Key Components

- **DialogDetailsView** - Main component that renders the complete dialog interface
- **Real-time hooks** - `useNatsDialogSubscription`, `useChunkCatchup`, `useDialogRealtimeProcessor` for live updates
- **Dialog management hooks** - `useDialogStatus`, `useApprovalRequests` for workflow operations
- **Message processing** - Handles historical and real-time messages with error handling
- **Status controls** - Put on hold, resolve, and approval request handling
- **Dual chat interface** - Separate client and admin chat channels

## Usage Example

```typescript
import { DialogDetailsView } from './dialog-details-view'

function DialogPage({ params }: { params: { id: string } }) {
  return (
    <div className="dialog-container">
      <DialogDetailsView dialogId={params.id} />
    </div>
  )
}

// The component automatically handles:
// - Real-time message streaming via NATS
// - Dialog status updates (on hold, resolved)
// - Approval request workflows
// - Message chunking and catch-up logic
// - Typing indicators for both client and admin chats
```

The component provides a complete MSP dialog management interface with real-time capabilities, supporting both client-facing (Fae AI) and admin-facing (Mingo AI) chat channels with approval workflows and status management.
