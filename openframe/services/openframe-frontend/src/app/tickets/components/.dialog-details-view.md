A React component that renders the detailed view for a chat dialog with real-time messaging, approval workflows, and admin controls. It manages both client and admin chat streams with NATS integration for real-time updates.

## Key Components

- **DialogDetailsView** - Main component that displays dialog details with dual chat interfaces
- **Real-time Integration** - NATS subscription handling with chunk processing and catchup mechanisms
- **Message Processing** - Converts historical messages to display format with approval request handling
- **Admin Controls** - Status management buttons (Put On Hold, Resolve) with loading states
- **Chat Interfaces** - Separate client and admin chat views with typing indicators
- **Approval System** - Interactive approval/rejection controls for pending requests

## Usage Example

```typescript
import { DialogDetailsView } from './dialog-details-view'

// Render dialog details page
function DialogPage({ params }: { params: { id: string } }) {
  return (
    <div className="h-full">
      <DialogDetailsView dialogId={params.id} />
    </div>
  )
}

// Example with routing
export default function DialogDetailsPage() {
  const params = useParams()
  const dialogId = params?.id as string
  
  if (!dialogId) {
    return <div>Dialog not found</div>
  }
  
  return <DialogDetailsView dialogId={dialogId} />
}
```

The component automatically handles data fetching, real-time subscriptions, and cleanup when the dialog ID changes or component unmounts.
