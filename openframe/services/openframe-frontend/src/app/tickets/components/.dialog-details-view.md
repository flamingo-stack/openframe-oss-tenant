A React component that renders a detailed view for dialog/conversation management in the OpenFrame MSP platform, featuring real-time chat functionality, approval workflows, and admin controls.

## Key Components

- **DialogDetailsView** - Main component for viewing and managing support dialogs
- **Real-time Communication** - NATS-based live chat updates with typing indicators
- **Dual Chat System** - Separate client (Fae) and admin (Mingo) chat interfaces  
- **Approval Workflow** - Handles approval requests with approve/reject functionality
- **Status Management** - Dialog status controls (Put On Hold, Resolve)
- **Message Processing** - Converts historical messages to UI-friendly format
- **Auto-scroll Logic** - Automatically scrolls to new messages
- **Device Information** - Shows client device details for context

## Usage Example

```typescript
import { DialogDetailsView } from './dialog-details-view'

// Render dialog details page
function DialogPage({ params }: { params: { id: string } }) {
  return (
    <DialogDetailsView dialogId={params.id} />
  )
}

// The component automatically handles:
// - Loading dialog data and message history
// - Setting up real-time subscriptions
// - Processing incoming messages and approvals
// - Managing typing indicators
// - Providing admin controls for dialog management
```

The component integrates multiple custom hooks for real-time functionality (`useNatsDialogSubscription`, `useChunkCatchup`, `useDialogRealtimeProcessor`) and maintains complex state for message synchronization, approval tracking, and UI responsiveness across both client and admin chat channels.
