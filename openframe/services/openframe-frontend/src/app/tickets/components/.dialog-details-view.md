A React component that provides a detailed view for dialog conversations with real-time messaging, approval management, and dual chat interfaces (client and admin).

## Key Components

- **DialogDetailsView** - Main component handling dialog display and interactions
- **Real-time Processing** - NATS subscription and chunk processing for live updates
- **Message Management** - Historical message processing and approval status tracking
- **Dual Chat Interface** - Separate client and admin chat streams
- **Status Management** - Dialog state updates (hold, resolve) with optimistic UI

## Usage Example

```typescript
import { DialogDetailsView } from './dialog-details-view'

// In a page component
export default function DialogPage({ params }: { params: { id: string } }) {
  return (
    <div className="h-screen">
      <DialogDetailsView dialogId={params.id} />
    </div>
  )
}

// With error boundary
function SafeDialogView({ dialogId }: { dialogId: string }) {
  if (!dialogId) {
    return <div>Dialog ID required</div>
  }
  
  return <DialogDetailsView dialogId={dialogId} />
}
```

The component integrates with multiple stores and hooks to manage dialog state, real-time updates, and user interactions. It features approval request handling, typing indicators, and message catchup mechanisms for reliable chat functionality.
