A comprehensive dialog management view component that provides real-time chat interface with administrative controls for OpenFrame's dialog system. It handles both client and admin chat streams, approval workflows, and dialog status management.

## Key Components

- **DialogDetailsView** - Main component managing dialog display and interactions
- **Real-time Processing** - NATS subscription for live message streaming
- **Chat Management** - Dual chat interface (client/admin) with typing indicators
- **Approval System** - Request approval/rejection workflow with status tracking
- **Status Controls** - Dialog lifecycle management (hold, resolve)
- **Message Processing** - Historical message processing with error handling

## Usage Example

```typescript
import { DialogDetailsView } from './dialog-details-view'

function DialogPage({ params }: { params: { id: string } }) {
  return (
    <div className="dialog-container">
      <DialogDetailsView dialogId={params.id} />
    </div>
  )
}

// The component handles:
// - Loading dialog data and message history
// - Real-time message streaming via NATS
// - Admin message sending and approval workflows
// - Dialog status updates (hold/resolve)
// - Chunk catch-up for missed real-time events
```

The component integrates multiple custom hooks for dialog state management, real-time subscriptions, and approval workflows, providing a complete dialog management interface with device information display and dual-chat functionality.
