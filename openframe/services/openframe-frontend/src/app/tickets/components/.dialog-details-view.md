This React component provides a comprehensive interface for viewing and managing individual dialog/chat sessions in the OpenFrame MSP platform.

## Key Components

- **DialogDetailsView**: Main component that displays dialog details, messages, and admin controls
- **Real-time Message Processing**: Handles live message streaming via NATS with chunk processing and catchup mechanisms
- **Dual Chat System**: Manages both client chat (with Fae AI) and admin chat (with Mingo AI) interfaces
- **Approval System**: Processes and manages approval requests within conversations
- **Status Management**: Provides controls to put dialogs on hold or resolve them
- **Message History**: Displays formatted conversation history with error handling

## Usage Example

```typescript
import { DialogDetailsView } from './dialog-details-view'

// Used in dialog detail page
function DialogPage({ params }: { params: { id: string } }) {
  return (
    <div className="h-screen">
      <DialogDetailsView dialogId={params.id} />
    </div>
  )
}

// The component handles:
// - Loading dialog and message data
// - Real-time message updates via NATS
// - Admin actions (hold/resolve)
// - Approval request processing
// - Dual chat interfaces for client and admin
```

The component integrates with OpenFrame's store management system, real-time messaging infrastructure, and provides a unified interface for MSP technicians to manage customer support conversations with AI assistance.
