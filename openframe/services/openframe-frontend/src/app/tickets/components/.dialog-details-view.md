A React component that provides a detailed view for dialog/ticket management with real-time chat capabilities, status updates, and approval workflows in the Flamingo OpenFrame platform.

## Key Components

- **DialogDetailsView**: Main component managing dialog state, real-time messaging, and user interactions
- **Real-time Processing**: Handles NATS subscriptions, chunk catchup, and streaming message processing
- **Message Processing**: Converts raw messages to UI-friendly format with approval handling
- **Status Management**: Provides controls for putting dialogs on hold or resolving them
- **Chat Interface**: Dual-chat system for client and admin communications
- **Approval System**: Handles approval requests with status tracking

## Usage Example

```typescript
import { DialogDetailsView } from './dialog-details-view'

// Render dialog details page
function DialogPage({ params }: { params: { id: string } }) {
  return (
    <div className="container mx-auto">
      <DialogDetailsView dialogId={params.id} />
    </div>
  )
}

// The component automatically handles:
// - Loading dialog data and message history
// - Real-time message streaming via NATS
// - Approval request processing
// - Status updates (hold/resolve)
// - Typing indicators for both client and admin chats
```

The component integrates multiple custom hooks for state management, real-time subscriptions, and API interactions, providing a comprehensive interface for MSP technicians to manage client support dialogs with AI-assisted workflows.
