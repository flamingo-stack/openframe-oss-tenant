A React hook for handling approval request mutations with approve/reject functionality, providing a clean interface for managing approval workflows.

## Key Components

- **`ApprovalRequestAction`** - Type defining the structure for approval actions with request ID and approval boolean
- **`approveRequest`** - Async function that sends approval/rejection requests to the API endpoint
- **`useApprovalRequests`** - Main hook providing approval mutation functionality and status tracking
- **`handleApproveRequest`/`handleRejectRequest`** - Convenience methods for approving or rejecting requests with optional callbacks

## Usage Example

```typescript
import { useApprovalRequests } from './use-approval-requests'

function ApprovalPanel({ requestId }: { requestId: string }) {
  const { 
    handleApproveRequest, 
    handleRejectRequest, 
    isLoading, 
    error 
  } = useApprovalRequests()

  const onApprove = () => {
    handleApproveRequest(requestId, {
      onSuccess: (status) => console.log('Request approved:', status),
      onError: (error) => console.error('Approval failed:', error)
    })
  }

  const onReject = () => {
    handleRejectRequest(requestId, {
      onSuccess: (status) => console.log('Request rejected:', status),
      onError: (error) => console.error('Rejection failed:', error)
    })
  }

  return (
    <div>
      <button onClick={onApprove} disabled={isLoading}>
        Approve
      </button>
      <button onClick={onReject} disabled={isLoading}>
        Reject
      </button>
      {error && <p>Error: {error}</p>}
    </div>
  )
}
```

The hook leverages React Query's `useMutation` for optimistic updates and automatic error handling, while providing both high-level convenience methods and access to the raw mutation for advanced use cases.
