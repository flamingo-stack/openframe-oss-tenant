A React hook that provides optimistic mutation functionality for archiving resolved dialogs in bulk, with comprehensive error handling and user feedback.

## Key Components

- **`useArchiveResolvedMutation()`** - Main hook that returns a TanStack Query mutation
- **`mutationFn`** - Filters resolved dialogs and makes parallel API calls to archive them
- **`onMutate`** - Implements optimistic updates by removing dialogs from cache immediately
- **`onError`** - Handles rollback of optimistic updates and shows appropriate error messages
- **`onSuccess`** - Displays success toast with count of archived dialogs
- **`onSettled`** - Invalidates all dialog queries to refresh data

## Usage Example

```typescript
import { useArchiveResolvedMutation } from './hooks/use-archive-resolved-mutation'

function DialogManager() {
  const archiveResolvedMutation = useArchiveResolvedMutation()

  const handleArchiveResolved = (selectedDialogs: Dialog[]) => {
    archiveResolvedMutation.mutate(selectedDialogs)
  }

  return (
    <button 
      onClick={() => handleArchiveResolved(dialogs)}
      disabled={archiveResolvedMutation.isPending}
    >
      {archiveResolvedMutation.isPending ? 'Archiving...' : 'Archive Resolved'}
    </button>
  )
}
```

The hook automatically filters for resolved dialogs, provides optimistic UI updates, handles partial failures, and shows appropriate toast notifications based on the operation results.
