A React hook that provides optimistic mutation functionality for bulk archiving resolved dialogs in the chat system.

## Key Components

- **useArchiveResolvedMutation** - Main hook that returns a TanStack Query mutation for archiving multiple resolved dialogs
- **mutationFn** - Filters dialogs by RESOLVED status, sends PATCH requests to update status to ARCHIVED, and returns success/fail counts
- **onMutate** - Optimistically removes resolved dialogs from UI before API calls complete
- **onError** - Reverts optimistic updates and displays appropriate error toasts
- **onSuccess** - Shows success notification with counts of archived/failed dialogs
- **onSettled** - Invalidates all dialog queries to refresh data

## Usage Example

```typescript
import { useArchiveResolvedMutation } from './hooks/use-archive-resolved-mutation'

function DialogManager() {
  const archiveResolvedMutation = useArchiveResolvedMutation()
  const selectedDialogs = [
    { id: '1', status: 'RESOLVED' },
    { id: '2', status: 'PENDING' },
    { id: '3', status: 'RESOLVED' }
  ]

  const handleArchiveResolved = () => {
    archiveResolvedMutation.mutate(selectedDialogs)
    // Only dialogs with status 'RESOLVED' will be archived
    // UI will optimistically update, then revert on error
  }

  return (
    <button 
      onClick={handleArchiveResolved}
      disabled={archiveResolvedMutation.isPending}
    >
      Archive Resolved ({archiveResolvedMutation.isPending ? 'Processing...' : 'Ready'})
    </button>
  )
}
```
