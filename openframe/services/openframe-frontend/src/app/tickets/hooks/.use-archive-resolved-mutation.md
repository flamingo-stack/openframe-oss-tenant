A React Query mutation hook for bulk archiving dialogs that have been resolved, with optimistic updates and comprehensive error handling.

## Key Components

- **useArchiveResolvedMutation**: Main hook that returns a mutation for archiving resolved dialogs
- **mutationFn**: Filters resolved dialogs and performs batch archive operations using `Promise.allSettled`
- **onMutate**: Implements optimistic updates by removing dialogs from the UI before API calls complete
- **Error handling**: Comprehensive error management with rollback functionality and user-friendly toast notifications
- **Success feedback**: Detailed success messages showing counts of archived and failed operations

## Usage Example

```typescript
import { useArchiveResolvedMutation } from './use-archive-resolved-mutation'

function DialogManager() {
  const archiveResolvedMutation = useArchiveResolvedMutation()

  const handleArchiveResolved = (selectedDialogs: Dialog[]) => {
    archiveResolvedMutation.mutate(selectedDialogs, {
      onSuccess: ({ successCount, failCount }) => {
        console.log(`Archived ${successCount} dialogs, ${failCount} failed`)
      }
    })
  }

  return (
    <button 
      onClick={() => handleArchiveResolved(dialogList)}
      disabled={archiveResolvedMutation.isPending}
    >
      {archiveResolvedMutation.isPending ? 'Archiving...' : 'Archive Resolved'}
    </button>
  )
}
```

The hook automatically filters for resolved dialogs, provides optimistic UI updates, handles partial failures gracefully, and ensures query cache consistency through proper invalidation.
