A React hook that manages bulk archiving of resolved dialogs using TanStack Query mutations with optimistic updates and error handling.

## Key Components

- **useArchiveResolvedMutation()** - Main hook that returns a mutation for archiving multiple resolved dialogs
- **mutationFn** - Filters resolved dialogs and executes parallel PATCH requests to update status to 'ARCHIVED'
- **onMutate** - Implements optimistic updates by removing dialogs from cache before API calls
- **onError/onSuccess/onSettled** - Comprehensive error handling, success feedback, and cache invalidation

## Usage Example

```typescript
import { useArchiveResolvedMutation } from './use-archive-resolved-mutation'

function DialogsManagement() {
  const archiveResolvedMutation = useArchiveResolvedMutation()

  const handleArchiveResolved = async (selectedDialogs: Dialog[]) => {
    try {
      const result = await archiveResolvedMutation.mutateAsync(selectedDialogs)
      console.log(`Archived ${result.successCount} dialogs`)
    } catch (error) {
      // Error handling is managed by the hook's onError callback
      console.error('Archive operation failed:', error)
    }
  }

  return (
    <button 
      onClick={() => handleArchiveResolved(dialogs)}
      disabled={archiveResolvedMutation.isPending}
    >
      {archiveResolvedMutation.isPending ? 'Archiving...' : 'Archive Resolved'}
    </button>
  )
}
```

The hook provides automatic toast notifications, optimistic UI updates, rollback on failure, and intelligent success/error messaging based on operation results.
