A React Query mutation hook that handles bulk archiving of resolved dialogs with optimistic updates and comprehensive error handling.

## Key Components

- **`useArchiveResolvedMutation()`** - Main hook that returns a configured mutation for archiving resolved dialogs
- **`mutationFn`** - Filters dialogs by RESOLVED status and makes parallel API calls to archive them
- **`onMutate`** - Implements optimistic updates by removing dialogs from cache before API calls complete
- **`onError`** - Rolls back optimistic changes and displays appropriate error toasts
- **`onSuccess`** - Shows success notifications with counts of archived dialogs
- **`onSettled`** - Invalidates all dialog queries to ensure fresh data

## Usage Example

```typescript
import { useArchiveResolvedMutation } from './hooks/use-archive-resolved-mutation'

function DialogManagement() {
  const archiveResolvedMutation = useArchiveResolvedMutation()

  const handleArchiveResolved = (selectedDialogs: Dialog[]) => {
    archiveResolvedMutation.mutate(selectedDialogs, {
      onSuccess: ({ successCount, failCount }) => {
        console.log(`Archived ${successCount} dialogs, ${failCount} failed`)
      }
    })
  }

  return (
    <button 
      onClick={() => handleArchiveResolved(dialogs)}
      disabled={archiveResolvedMutation.isPending}
    >
      {archiveResolvedMutation.isPending ? 'Archiving...' : 'Archive Resolved'}
    </button>
  )
}
```

The hook automatically filters for resolved dialogs, provides optimistic UI updates, handles partial failures gracefully, and maintains cache consistency through query invalidation.
