A React Query mutation hook for archiving resolved dialogs in the Flamingo OpenFrame platform. This hook handles bulk archiving operations with optimistic updates, error handling, and comprehensive user feedback via toast notifications.

## Key Components

- **`useArchiveResolvedMutation`** - Main mutation hook that archives dialogs with "RESOLVED" status
- **Mutation function** - Filters resolved dialogs and performs parallel API calls to archive them
- **Optimistic updates** - Immediately removes dialogs from the UI before API confirmation
- **Error handling** - Restores previous state on failure and shows appropriate error messages
- **Success feedback** - Displays success/failure counts with detailed toast notifications

## Usage Example

```typescript
import { useArchiveResolvedMutation } from './hooks/use-archive-resolved-mutation'

function DialogManager() {
  const archiveResolvedMutation = useArchiveResolvedMutation()
  
  const handleArchiveResolved = (selectedDialogs: Dialog[]) => {
    archiveResolvedMutation.mutate(selectedDialogs)
  }

  return (
    <button 
      onClick={() => handleArchiveResolved(dialogs)}
      disabled={archiveResolvedMutation.isPending}
    >
      {archiveResolvedMutation.isPending ? 'Archiving...' : 'Archive Resolved'}
    </button>
  )
}
```

The hook automatically filters for resolved dialogs, provides optimistic UI updates for better UX, handles partial failures gracefully, and invalidates relevant queries to keep the UI synchronized.
