A React Query mutation hook that batch archives all dialogs with "RESOLVED" status to "ARCHIVED" status, providing optimistic updates and comprehensive error handling with toast notifications.

## Key Components

- **`useArchiveResolvedMutation`** - Main hook that returns a TanStack Query mutation
- **`mutationFn`** - Batch archives resolved dialogs using Promise.allSettled for partial success handling
- **`onMutate`** - Implements optimistic updates by immediately filtering out resolved dialogs from cache
- **`onError`** - Rollback mechanism that restores previous cache state and shows appropriate error toasts
- **`onSuccess`** - Success handler with detailed toast messages for success/failure counts
- **`onSettled`** - Cache invalidation to ensure data consistency after mutation completes

## Usage Example

```typescript
import { useArchiveResolvedMutation } from './use-archive-resolved-mutation'

function DialogBulkActions({ selectedDialogs }: { selectedDialogs: Dialog[] }) {
  const archiveResolvedMutation = useArchiveResolvedMutation()

  const handleArchiveResolved = () => {
    archiveResolvedMutation.mutate(selectedDialogs)
  }

  return (
    <button 
      onClick={handleArchiveResolved}
      disabled={archiveResolvedMutation.isPending}
    >
      {archiveResolvedMutation.isPending ? 'Archiving...' : 'Archive Resolved'}
    </button>
  )
}
```

The hook automatically filters for resolved dialogs, provides detailed success/failure feedback, and maintains cache consistency through optimistic updates and proper rollback handling.
