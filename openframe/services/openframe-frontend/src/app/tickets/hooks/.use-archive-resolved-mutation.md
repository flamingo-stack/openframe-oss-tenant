A React Query mutation hook that archives multiple resolved dialogs in bulk, providing optimistic updates and comprehensive error handling with toast notifications.

## Key Components

- **`useArchiveResolvedMutation()`** - Main hook that returns a TanStack Query mutation for archiving resolved dialogs
- **`mutationFn`** - Filters resolved dialogs and makes parallel API calls to archive them, returning success/failure counts
- **`onMutate`** - Implements optimistic updates by removing dialogs from cache before API calls complete
- **Error handling** - Rolls back optimistic updates on failure and shows appropriate toast messages
- **Success handling** - Displays success/failure counts in toast notifications

## Usage Example

```typescript
import { useArchiveResolvedMutation } from './use-archive-resolved-mutation'

function DialogManager() {
  const archiveResolvedMutation = useArchiveResolvedMutation()

  const handleArchiveResolved = async (selectedDialogs: Dialog[]) => {
    try {
      await archiveResolvedMutation.mutateAsync(selectedDialogs)
    } catch (error) {
      // Error handling is done automatically via onError callback
      console.log('Archive operation completed with errors')
    }
  }

  return (
    <button 
      onClick={() => handleArchiveResolved(dialogs)}
      disabled={archiveResolvedMutation.isPending}
    >
      {archiveResolvedMutation.isPending ? 'Archiving...' : 'Archive Resolved'}
    </button>
  )
}
```

The hook automatically handles filtering non-resolved dialogs, provides real-time UI feedback through optimistic updates, and ensures data consistency by invalidating related queries after completion.
