A React hook that provides mutation functionality for archiving multiple resolved dialogs with optimistic updates and comprehensive error handling.

## Key Components

- **useArchiveResolvedMutation()** - Main hook that returns a TanStack Query mutation
- **mutationFn** - Filters resolved dialogs and performs batch archive operations via API
- **onMutate** - Optimistic updates that immediately remove dialogs from UI
- **onError/onSuccess** - Toast notifications with detailed success/failure feedback
- **onSettled** - Cache invalidation to ensure data consistency

## Usage Example

```typescript
import { useArchiveResolvedMutation } from './use-archive-resolved-mutation'

function DialogManager() {
  const archiveResolvedMutation = useArchiveResolvedMutation()

  const handleArchiveResolved = async (selectedDialogs: Dialog[]) => {
    try {
      const result = await archiveResolvedMutation.mutateAsync(selectedDialogs)
      console.log(`Archived ${result.successCount} dialogs`)
    } catch (error) {
      // Error handling is done automatically via onError
    }
  }

  return (
    <button 
      onClick={() => handleArchiveResolved(dialogs)}
      disabled={archiveResolvedMutation.isPending}
    >
      {archiveResolvedMutation.isPending ? 'Archiving...' : 'Archive Resolved'}
    </button>
  )
}
```

The hook automatically filters for resolved dialogs, provides optimistic UI updates, handles partial failures, and displays appropriate toast messages based on operation results.
