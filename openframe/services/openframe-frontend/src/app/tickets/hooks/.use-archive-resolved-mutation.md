A React Query mutation hook that handles archiving resolved dialogs in bulk with optimistic updates and comprehensive error handling.

## Key Components

- **`useArchiveResolvedMutation`** - Main hook that returns a TanStack Query mutation
- **Mutation Function** - Filters resolved dialogs and patches their status to 'ARCHIVED' via API calls
- **Optimistic Updates** - Immediately removes dialogs from UI before API confirmation
- **Error Recovery** - Restores previous state if mutations fail
- **Toast Notifications** - Provides user feedback for success/error scenarios

## Usage Example

```typescript
import { useArchiveResolvedMutation } from './use-archive-resolved-mutation'

function DialogManager() {
  const archiveResolvedMutation = useArchiveResolvedMutation()
  
  const handleArchiveResolved = (selectedDialogs: Dialog[]) => {
    archiveResolvedMutation.mutate(selectedDialogs, {
      onSuccess: ({ successCount, failCount }) => {
        console.log(`Archived ${successCount} dialogs, ${failCount} failed`)
      }
    })
  }

  return (
    <button 
      onClick={() => handleArchiveResolved(dialogs)}
      disabled={archiveResolvedMutation.isPending}
    >
      {archiveResolvedMutation.isPending ? 'Archiving...' : 'Archive Resolved'}
    </button>
  )
}
```

The hook automatically filters for resolved dialogs, handles partial failures gracefully, and maintains UI consistency through optimistic updates and rollback mechanisms.
