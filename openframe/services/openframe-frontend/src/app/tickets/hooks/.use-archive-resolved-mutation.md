A React Query mutation hook that archives resolved dialogs in the Flamingo OpenFrame platform, providing optimistic updates and comprehensive error handling with user feedback through toast notifications.

## Key Components

- **useArchiveResolvedMutation()** - Main hook that returns a mutation for archiving resolved dialogs
- **mutationFn** - Filters resolved dialogs and makes parallel API calls to archive them
- **onMutate** - Optimistic update that removes dialogs from cache before API calls
- **onError** - Reverts optimistic updates and shows appropriate error messages
- **onSuccess** - Shows success toast with count of archived dialogs
- **onSettled** - Invalidates dialog queries to refresh data

## Usage Example

```typescript
import { useArchiveResolvedMutation } from './hooks/use-archive-resolved-mutation'

function DialogManagement() {
  const archiveResolvedMutation = useArchiveResolvedMutation()
  
  const handleArchiveResolved = (dialogs: Dialog[]) => {
    archiveResolvedMutation.mutate(dialogs, {
      onSuccess: ({ successCount, failCount }) => {
        console.log(`Archived ${successCount} dialogs, ${failCount} failures`)
      }
    })
  }

  return (
    <button 
      onClick={() => handleArchiveResolved(selectedDialogs)}
      disabled={archiveResolvedMutation.isPending}
    >
      {archiveResolvedMutation.isPending ? 'Archiving...' : 'Archive Resolved'}
    </button>
  )
}
```

The hook automatically filters for resolved dialogs, provides batch processing with parallel API calls, and includes optimistic UI updates for immediate user feedback while maintaining data consistency through proper error handling and cache invalidation.
