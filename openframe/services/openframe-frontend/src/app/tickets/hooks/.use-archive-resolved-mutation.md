A React Query mutation hook that archives resolved dialogs with optimistic updates and comprehensive error handling.

## Key Components

- **useArchiveResolvedMutation()** - Main hook that returns a mutation for archiving resolved dialogs
- **mutationFn** - Filters resolved dialogs and performs batch archival via API calls
- **onMutate** - Implements optimistic updates by immediately removing dialogs from the UI
- **onError** - Rolls back optimistic updates and displays appropriate error toasts
- **onSuccess** - Shows success notifications with counts of archived/failed dialogs
- **onSettled** - Invalidates dialog queries to ensure data consistency

## Usage Example

```typescript
import { useArchiveResolvedMutation } from './use-archive-resolved-mutation'

function DialogActions({ selectedDialogs }: { selectedDialogs: Dialog[] }) {
  const archiveResolvedMutation = useArchiveResolvedMutation()

  const handleArchiveResolved = () => {
    archiveResolvedMutation.mutate(selectedDialogs)
  }

  return (
    <button 
      onClick={handleArchiveResolved}
      disabled={archiveResolvedMutation.isPending}
    >
      {archiveResolvedMutation.isPending ? 'Archiving...' : 'Archive Resolved'}
    </button>
  )
}
```

The hook automatically filters for resolved dialogs, provides real-time UI feedback through optimistic updates, handles partial failures gracefully, and ensures the dialog list stays synchronized with the backend state.
