A React hook that provides mutation functionality for archiving dialogs that have been resolved, with optimistic updates and comprehensive error handling.

## Key Components

- **`useArchiveResolvedMutation`** - Main hook that returns a TanStack Query mutation for archiving resolved dialogs
- **Batch Processing** - Filters and processes only dialogs with 'RESOLVED' status
- **Promise Settlement Handling** - Uses `Promise.allSettled` to track success/failure counts for bulk operations
- **Optimistic Updates** - Immediately removes dialogs from the UI before API confirmation
- **Error Recovery** - Restores previous query state if the mutation fails
- **Toast Notifications** - Provides user feedback for success, error, and edge case scenarios

## Usage Example

```typescript
import { useArchiveResolvedMutation } from './use-archive-resolved-mutation'

function DialogManager() {
  const archiveResolvedMutation = useArchiveResolvedMutation()

  const handleArchiveResolved = (selectedDialogs: Dialog[]) => {
    archiveResolvedMutation.mutate(selectedDialogs)
  }

  return (
    <button 
      onClick={() => handleArchiveResolved(dialogs)}
      disabled={archiveResolvedMutation.isPending}
    >
      {archiveResolvedMutation.isPending ? 'Archiving...' : 'Archive Resolved'}
    </button>
  )
}
```

The hook automatically handles filtering for resolved dialogs, provides optimistic UI updates, and shows appropriate toast messages based on operation results.
