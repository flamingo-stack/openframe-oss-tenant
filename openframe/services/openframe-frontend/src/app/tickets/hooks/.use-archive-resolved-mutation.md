A React Query mutation hook that handles archiving resolved dialogs in bulk, with optimistic updates and comprehensive error handling.

## Key Components

- **`useArchiveResolvedMutation()`** - Main hook that returns a TanStack Query mutation
- **Mutation Function** - Filters resolved dialogs and patches their status to 'ARCHIVED' using Promise.allSettled
- **Optimistic Updates** - Immediately removes dialogs from UI before API confirmation
- **Error Recovery** - Restores previous query state on failure
- **Toast Notifications** - Provides user feedback for success, error, and edge cases

## Usage Example

```typescript
import { useArchiveResolvedMutation } from './use-archive-resolved-mutation'

function DialogActions({ selectedDialogs }) {
  const archiveResolvedMutation = useArchiveResolvedMutation()

  const handleArchiveResolved = () => {
    archiveResolvedMutation.mutate(selectedDialogs)
  }

  return (
    <button 
      onClick={handleArchiveResolved}
      disabled={archiveResolvedMutation.isPending}
    >
      {archiveResolvedMutation.isPending ? 'Archiving...' : 'Archive Resolved'}
    </button>
  )
}
```

The hook automatically handles filtering to only archive dialogs with 'RESOLVED' status, provides detailed success/failure counts, and maintains UI consistency through optimistic updates with rollback capability.
