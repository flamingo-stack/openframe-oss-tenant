A React hook that provides mutation functionality for archiving resolved dialogs in bulk operations with optimistic updates and comprehensive error handling.

## Key Components

- **useArchiveResolvedMutation** - Main hook that returns a TanStack Query mutation for archiving resolved dialogs
- **mutationFn** - Core mutation function that filters resolved dialogs and performs batch archive operations
- **Optimistic Updates** - Implements optimistic UI updates via `onMutate` callback
- **Error Recovery** - Rollback mechanism in `onError` to restore previous state on failure
- **Toast Notifications** - Success/error feedback with different variants and durations
- **Query Invalidation** - Automatic cache invalidation after mutation completion

## Usage Example

```typescript
import { useArchiveResolvedMutation } from './hooks/use-archive-resolved-mutation'

function DialogActions({ selectedDialogs }: { selectedDialogs: Dialog[] }) {
  const archiveResolvedMutation = useArchiveResolvedMutation()

  const handleArchiveResolved = () => {
    archiveResolvedMutation.mutate(selectedDialogs)
  }

  return (
    <button 
      onClick={handleArchiveResolved}
      disabled={archiveResolvedMutation.isPending}
    >
      {archiveResolvedMutation.isPending ? 'Archiving...' : 'Archive Resolved'}
    </button>
  )
}
```

The hook automatically handles filtering for resolved dialogs, provides optimistic UI updates by removing archived dialogs from the cache immediately, and shows appropriate toast messages based on success/failure rates of the batch operation.
