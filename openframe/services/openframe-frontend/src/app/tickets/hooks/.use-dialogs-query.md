A React Query hook that fetches and manages dialog/conversation data with filtering, search, and cursor-based pagination capabilities. It handles GraphQL API communication and provides comprehensive loading states and pagination helpers.

## Key Components

- **useDialogsQuery**: Main hook function that accepts filtering parameters and returns paginated dialog data
- **DialogsQueryParams**: Type interface for query parameters (archived, search, statusFilters, cursor)
- **DialogsResponse**: GraphQL response structure containing dialog connection data
- **Query Configuration**: Includes caching (1min stale time), retry logic, and error handling
- **Status Filtering**: Automatically maps archived/active states to appropriate dialog statuses
- **Pagination**: Cursor-based pagination with hasNextPage/hasPreviousPage support

## Usage Example

```typescript
import { useDialogsQuery } from './hooks/use-dialogs-query'

function DialogsList() {
  const {
    dialogs,
    pageInfo,
    isLoading,
    isError,
    error,
    hasNextPage,
    endCursor,
    refetch
  } = useDialogsQuery({
    archived: false,
    search: 'urgent',
    statusFilters: ['ACTIVE', 'ACTION_REQUIRED'],
    cursor: undefined // First page
  })

  if (isLoading) return <div>Loading dialogs...</div>
  if (isError) return <div>Error: {error}</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>{dialog.subject}</div>
      ))}
      {hasNextPage && (
        <button onClick={() => refetch()}>
          Load More
        </button>
      )}
    </div>
  )
}
```
