A React hook that fetches dialogs (conversations/tickets) using TanStack Query with GraphQL, supporting pagination, filtering, and real-time updates for the Flamingo MSP platform.

## Key Components

- **useDialogsQuery** - Main hook that manages dialog fetching with filtering and pagination
- **DialogsQueryParams** - Input parameters for archived status, search terms, status filters, and cursor
- **DialogsResponse/GraphQLResponse** - Type definitions for API responses
- **Query Configuration** - Optimized caching with 1-minute stale time and 5-minute garbage collection
- **Status Logic** - Automatically determines dialog statuses based on archived state and filters
- **Pagination Support** - Cursor-based pagination with `hasNextPage` and cursor management
- **Error Handling** - Comprehensive GraphQL and HTTP error handling

## Usage Example

```typescript
import { useDialogsQuery } from './hooks/use-dialogs-query'

function DialogsList() {
  const {
    dialogs,
    pageInfo,
    isLoading,
    isError,
    error,
    hasNextPage,
    endCursor,
    refetch
  } = useDialogsQuery({
    archived: false,
    search: 'urgent',
    statusFilters: ['ACTIVE', 'ACTION_REQUIRED'],
    cursor: null
  })

  if (isLoading) return <div>Loading dialogs...</div>
  if (isError) return <div>Error: {error}</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>{dialog.title}</div>
      ))}
      {hasNextPage && (
        <button onClick={() => loadMore(endCursor)}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically handles status filtering logic - when `archived: true`, it fetches archived dialogs; otherwise it fetches active dialogs with various states. It includes comprehensive error handling for both HTTP and GraphQL errors, and provides convenient pagination helpers for implementing infinite scroll or load-more functionality.
