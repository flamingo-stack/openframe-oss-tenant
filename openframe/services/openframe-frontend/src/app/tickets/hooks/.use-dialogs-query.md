A React Query hook for fetching paginated dialogs with support for filtering, search, and cursor-based pagination. Handles GraphQL API communication and error management for the chat dialog system.

## Key Components

- **useDialogsQuery**: Main hook that accepts filtering parameters (archived, search, statusFilters, cursor)
- **Status filtering logic**: Automatically sets appropriate statuses based on archived state or custom filters
- **GraphQL integration**: Executes `GET_DIALOGS_QUERY` with proper variable mapping
- **Error handling**: Comprehensive GraphQL and HTTP error detection
- **Pagination support**: Cursor-based pagination with page info extraction
- **Query optimization**: Configured with stale time, garbage collection, and retry policies

## Usage Example

```typescript
import { useDialogsQuery } from './use-dialogs-query'

function DialogsList() {
  const {
    dialogs,
    pageInfo,
    isLoading,
    isError,
    error,
    hasNextPage,
    endCursor,
    refetch
  } = useDialogsQuery({
    archived: false,
    search: 'customer inquiry',
    statusFilters: ['ACTIVE', 'ACTION_REQUIRED'],
    cursor: null
  })

  if (isLoading) return <div>Loading dialogs...</div>
  if (isError) return <div>Error: {error}</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <DialogItem key={dialog.id} dialog={dialog} />
      ))}
      {hasNextPage && (
        <button onClick={() => refetch()}>
          Load More
        </button>
      )}
    </div>
  )
}
```
