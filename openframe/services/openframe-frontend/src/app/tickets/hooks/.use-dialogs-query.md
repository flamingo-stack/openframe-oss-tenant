Custom React Query hook for fetching paginated dialogs with filtering, search, and status management capabilities from the Flamingo chat GraphQL API.

## Key Components

- **useDialogsQuery**: Main hook that wraps React Query's `useQuery` with dialog-specific logic
- **DialogsQueryParams**: Interface for query parameters (archived, search, statusFilters, cursor)
- **GraphQL Integration**: Handles GraphQL queries with error handling and response transformation
- **Status Logic**: Automatically maps archived flag to appropriate dialog statuses
- **Cursor Pagination**: Implements cursor-based pagination with page info tracking

## Usage Example

```typescript
import { useDialogsQuery } from './use-dialogs-query'

function DialogsList() {
  const {
    dialogs,
    pageInfo,
    isLoading,
    isError,
    error,
    hasNextPage,
    endCursor,
    refetch
  } = useDialogsQuery({
    archived: false,
    search: 'customer issue',
    statusFilters: ['ACTIVE', 'ACTION_REQUIRED'],
    cursor: null
  })

  if (isLoading) return <div>Loading dialogs...</div>
  if (isError) return <div>Error: {error}</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>{dialog.title}</div>
      ))}
      
      {hasNextPage && (
        <button onClick={() => loadNextPage(endCursor)}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically handles GraphQL error responses, implements smart status filtering (archived vs active dialogs), and provides comprehensive pagination state management with 1-minute stale time and 2-retry error recovery.
