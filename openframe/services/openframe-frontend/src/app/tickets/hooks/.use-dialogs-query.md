A React hook that provides paginated dialog data fetching with filtering capabilities using TanStack Query for caching and state management.

## Key Components

- **useDialogsQuery**: Main hook that accepts filtering parameters and returns paginated dialog data
- **DialogsQueryParams**: Interface for filtering options (archived, search, statusFilters, cursor)
- **GraphQL Integration**: Executes dialog queries with proper error handling and response parsing
- **Status Filtering Logic**: Automatically sets appropriate status filters based on archived state
- **Cursor-based Pagination**: Implements GraphQL connection pattern with page info

## Usage Example

```typescript
import { useDialogsQuery } from './use-dialogs-query'

function DialogList() {
  const {
    dialogs,
    pageInfo,
    isLoading,
    isError,
    error,
    hasNextPage,
    endCursor,
    refetch
  } = useDialogsQuery({
    archived: false,
    search: 'customer inquiry',
    statusFilters: ['ACTIVE', 'ACTION_REQUIRED'],
    cursor: null
  })

  if (isLoading) return <div>Loading dialogs...</div>
  if (isError) return <div>Error: {error}</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>{dialog.title}</div>
      ))}
      {hasNextPage && (
        <button onClick={() => refetch()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook provides comprehensive dialog management with built-in caching (1-minute stale time), error handling, and pagination state management for efficient data fetching in chat/dialog interfaces.
