A React Query hook for fetching and managing dialogs data with filtering, search, and cursor-based pagination support. It handles GraphQL API communication and provides comprehensive loading states and error handling.

## Key Components

- **`useDialogsQuery`** - Main hook that accepts filtering parameters and returns dialogs data with pagination
- **`DialogsQueryParams`** - Interface for query parameters (archived, search, statusFilters, cursor)
- **`GraphQLResponse<T>`** - Generic interface for GraphQL API responses with error handling
- **Status filtering logic** - Automatically sets appropriate status filters based on archived state
- **Cursor pagination** - Implements cursor-based pagination with page info management

## Usage Example

```typescript
import { useDialogsQuery } from './use-dialogs-query'

function DialogsList() {
  const {
    dialogs,
    pageInfo,
    isLoading,
    isError,
    error,
    hasNextPage,
    endCursor,
    refetch
  } = useDialogsQuery({
    archived: false,
    search: 'support ticket',
    statusFilters: ['ACTIVE', 'ACTION_REQUIRED'],
    cursor: null
  })

  if (isLoading) return <div>Loading dialogs...</div>
  if (isError) return <div>Error: {error}</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>{dialog.title}</div>
      ))}
      {hasNextPage && (
        <button onClick={() => loadMore(endCursor)}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically manages query caching with 1-minute stale time and includes retry logic for failed requests. It transforms the GraphQL connection structure into a simpler array format while preserving pagination metadata.
