A React Query hook that fetches paginated dialogs (conversations) from the Flamingo/OpenFrame GraphQL API with support for filtering, searching, and cursor-based pagination.

## Key Components

- **`useDialogsQuery`** - Main hook that accepts query parameters and returns dialogs data with loading states
- **`DialogsQueryParams`** - Interface for filtering parameters (archived, search, statusFilters, cursor)
- **GraphQL Integration** - Uses `GET_DIALOGS_QUERY` to fetch dialog connections with proper error handling
- **Automatic Status Mapping** - Intelligently maps archived flag to appropriate dialog statuses
- **Pagination Support** - Implements cursor-based pagination with page info helpers

## Usage Example

```typescript
import { useDialogsQuery } from './hooks/use-dialogs-query'

function DialogsList() {
  const {
    dialogs,
    pageInfo,
    isLoading,
    isError,
    error,
    hasNextPage,
    endCursor,
    refetch
  } = useDialogsQuery({
    archived: false,
    search: 'support ticket',
    statusFilters: ['ACTIVE', 'ACTION_REQUIRED'],
    cursor: null
  })

  if (isLoading) return <div>Loading dialogs...</div>
  if (isError) return <div>Error: {error}</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>{dialog.title}</div>
      ))}
      
      {hasNextPage && (
        <button onClick={() => refetch()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook provides comprehensive state management with React Query caching (1 minute stale time, 5 minute garbage collection) and automatic retry logic for robust dialog data fetching in MSP workflow interfaces.
