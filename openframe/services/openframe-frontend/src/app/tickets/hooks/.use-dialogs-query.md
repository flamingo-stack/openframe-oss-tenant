React hook that fetches and manages dialog data using TanStack Query, providing pagination support and filtering capabilities for chat dialogs in the Flamingo platform.

## Key Components

- **`useDialogsQuery`** - Main hook that accepts filter parameters and returns paginated dialog data
- **`DialogsQueryParams`** - Interface defining filter options (archived, search, statusFilters, cursor)
- **`DialogsResponse`** - GraphQL response structure containing dialog connections
- **Status filtering logic** - Automatically maps archived state to appropriate status filters
- **Cursor-based pagination** - Handles GraphQL cursor pagination with configurable limits
- **Error handling** - Comprehensive GraphQL and HTTP error management

## Usage Example

```typescript
import { useDialogsQuery } from './use-dialogs-query'

function DialogsList() {
  const {
    dialogs,
    pageInfo,
    isLoading,
    hasNextPage,
    endCursor,
    refetch
  } = useDialogsQuery({
    archived: false,
    search: 'urgent',
    statusFilters: ['ACTIVE', 'ACTION_REQUIRED'],
    cursor: null
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>{dialog.title}</div>
      ))}
      {hasNextPage && (
        <button onClick={() => refetch({ cursor: endCursor })}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically manages query caching with 1-minute stale time and includes retry logic for failed requests. Status filters default to active states when not archived, or 'ARCHIVED' when archived flag is true.
