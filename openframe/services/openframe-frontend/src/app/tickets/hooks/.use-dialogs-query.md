A React Query hook that fetches and manages dialogs (conversations/tickets) with filtering, search, and cursor-based pagination capabilities through a GraphQL API.

## Key Components

- **`useDialogsQuery`** - Main hook that accepts filtering parameters (`archived`, `search`, `statusFilters`, `cursor`) and returns dialog data with pagination info
- **Status filtering logic** - Automatically applies appropriate status filters based on archived state or custom filters
- **Cursor pagination** - Implements GraphQL cursor-based pagination with configurable limit (10 items per page)
- **Error handling** - Comprehensive error handling for network failures and GraphQL errors
- **Query optimization** - Configured with 1-minute stale time and 5-minute garbage collection time

## Usage Example

```typescript
import { useDialogsQuery } from './hooks/use-dialogs-query'

function DialogsList() {
  const {
    dialogs,
    pageInfo,
    isLoading,
    isError,
    error,
    hasNextPage,
    endCursor,
    refetch
  } = useDialogsQuery({
    archived: false,
    search: 'urgent ticket',
    statusFilters: ['ACTIVE', 'ACTION_REQUIRED'],
    cursor: null // First page
  })

  if (isLoading) return <div>Loading dialogs...</div>
  if (isError) return <div>Error: {error}</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>{dialog.title}</div>
      ))}
      {hasNextPage && (
        <button onClick={() => refetch()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook returns dialogs array, pagination info, loading states, and helper functions for implementing infinite scroll or paginated interfaces.
