A custom React Query hook for fetching paginated dialog conversations with filtering and cursor-based pagination support. Transforms GraphQL responses into a simplified format with comprehensive error handling and pagination helpers.

## Key Components

- **`useDialogsQuery`** - Main hook that accepts filtering parameters and returns dialog data with loading states
- **`DialogsQueryParams`** - Interface defining available filter options (archived, search, statusFilters, cursor)
- **Status filtering logic** - Automatically maps archived flag and custom status filters to appropriate dialog states
- **GraphQL integration** - Handles GraphQL query execution with error parsing and response transformation
- **Cursor pagination** - Implements forward pagination using GraphQL connection pattern
- **Query optimization** - Configured with 1-minute stale time and retry logic for reliability

## Usage Example

```typescript
import { useDialogsQuery } from './hooks/use-dialogs-query'

function DialogsList() {
  const {
    dialogs,
    pageInfo,
    isLoading,
    isError,
    error,
    hasNextPage,
    endCursor,
    refetch
  } = useDialogsQuery({
    archived: false,
    search: 'urgent',
    statusFilters: ['ACTIVE', 'ACTION_REQUIRED'],
    cursor: null
  })

  if (isLoading) return <div>Loading dialogs...</div>
  if (isError) return <div>Error: {error}</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <DialogCard key={dialog.id} dialog={dialog} />
      ))}
      {hasNextPage && (
        <button onClick={() => loadMore(endCursor)}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically handles status filtering logic, transforming the `archived` boolean into appropriate status arrays, and provides cursor-based pagination with `hasNextPage` and `endCursor` helpers for infinite scrolling implementations.
