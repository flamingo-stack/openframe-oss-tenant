A React Query hook that manages dialogs fetching with filtering, search, and cursor-based pagination capabilities. Handles GraphQL queries to retrieve dialogs with various filter states including archived, active, and custom status filters.

## Key Components

- **useDialogsQuery**: Main hook function that accepts filtering and pagination parameters
- **DialogsQueryParams**: Interface defining query parameters (archived, search, statusFilters, cursor)
- **DialogsResponse**: Response interface for the GraphQL dialogs connection
- **GraphQLResponse**: Generic wrapper for GraphQL API responses with error handling

## Usage Example

```typescript
import { useDialogsQuery } from './use-dialogs-query'

function DialogsList() {
  const { 
    dialogs, 
    pageInfo,
    isLoading, 
    hasNextPage,
    endCursor,
    refetch 
  } = useDialogsQuery({
    archived: false,
    search: 'urgent',
    statusFilters: ['ACTIVE', 'ACTION_REQUIRED'],
    cursor: undefined
  })

  const loadMore = () => {
    if (hasNextPage) {
      // Trigger new query with endCursor for pagination
      refetch()
    }
  }

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <DialogItem key={dialog.id} dialog={dialog} />
      ))}
      {hasNextPage && (
        <button onClick={loadMore}>Load More</button>
      )}
    </div>
  )
}
```

The hook automatically handles status filtering logic, converts GraphQL connection format to flat arrays, and provides comprehensive loading states and error handling for robust dialog management.
