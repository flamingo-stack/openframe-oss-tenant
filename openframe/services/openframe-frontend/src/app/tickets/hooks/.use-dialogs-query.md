Custom React Query hook for fetching and managing paginated dialog conversations with filtering, search, and caching capabilities. Integrates with TanStack Query to provide optimized data fetching for the Flamingo chat system.

## Key Components

- **`useDialogsQuery`** - Main hook that accepts query parameters and returns paginated dialog data
- **`DialogsQueryParams`** - Parameters interface for filtering (archived, search, statusFilters, cursor)
- **`DialogsResponse`** - GraphQL response structure containing dialog connections
- **`GraphQLResponse`** - Generic GraphQL response wrapper with error handling
- **Query Configuration** - Built-in caching (1min stale, 5min garbage collection) and retry logic

## Usage Example

```typescript
import { useDialogsQuery } from './use-dialogs-query'

function DialogsList() {
  const {
    dialogs,
    pageInfo,
    isLoading,
    isError,
    error,
    hasNextPage,
    endCursor,
    refetch
  } = useDialogsQuery({
    archived: false,
    search: 'customer issue',
    statusFilters: ['ACTIVE', 'ACTION_REQUIRED'],
    cursor: null
  })

  if (isLoading) return <div>Loading dialogs...</div>
  if (isError) return <div>Error: {error}</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>{dialog.title}</div>
      ))}
      
      {hasNextPage && (
        <button onClick={() => 
          useDialogsQuery({ cursor: endCursor })
        }>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically handles status filtering logic, transforms GraphQL connection data into a flat array, and provides comprehensive loading states and pagination helpers for building responsive dialog interfaces.
