A React hook that provides GraphQL-based querying for dialog/conversation data with pagination, filtering, and real-time updates using TanStack Query. This hook manages the complexity of fetching dialogs with various filters like archived status, search terms, and status filters.

## Key Components

- **`useDialogsQuery`** - Main hook that accepts filtering parameters and returns paginated dialog data
- **`DialogsQueryParams`** - Interface defining available filter options (archived, search, statusFilters, cursor)
- **`DialogsResponse`** - Type for the GraphQL response containing dialog connection data
- **Status Logic** - Automatically determines which dialog statuses to fetch based on filters
- **Error Handling** - Comprehensive GraphQL and HTTP error management
- **Pagination Support** - Cursor-based pagination with page info helpers

## Usage Example

```typescript
import { useDialogsQuery } from './use-dialogs-query'

function DialogsList() {
  const { 
    dialogs, 
    pageInfo, 
    isLoading, 
    hasNextPage, 
    endCursor, 
    refetch 
  } = useDialogsQuery({
    archived: false,
    search: 'customer issue',
    statusFilters: ['ACTIVE', 'ACTION_REQUIRED'],
    cursor: null
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>{dialog.title}</div>
      ))}
      
      {hasNextPage && (
        <button onClick={() => refetch({ cursor: endCursor })}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically handles status filtering logic - defaulting to active statuses for normal views, archived status for archived views, or custom status filters when provided. It includes built-in caching (1 minute stale time) and retry logic for reliability.
