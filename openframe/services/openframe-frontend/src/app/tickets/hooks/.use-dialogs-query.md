A React Query hook for fetching and managing dialogs (conversations) data with pagination, filtering, and search capabilities. This client-side hook handles GraphQL API communication for the chat dialog system.

## Key Components

- **`useDialogsQuery`** - Main hook that accepts filtering parameters and returns dialogs data with pagination info
- **`DialogsQueryParams`** - Interface for query parameters including archived state, search terms, status filters, and cursor
- **`DialogsResponse`** - GraphQL response structure containing dialog connections
- **Query Configuration** - Configured with 1-minute stale time, 5-minute garbage collection, and retry logic

## Usage Example

```typescript
import { useDialogsQuery } from './use-dialogs-query'

function DialogsList() {
  const {
    dialogs,
    pageInfo,
    isLoading,
    isError,
    error,
    hasNextPage,
    endCursor,
    refetch
  } = useDialogsQuery({
    archived: false,
    search: 'customer inquiry',
    statusFilters: ['ACTIVE', 'ACTION_REQUIRED'],
    cursor: null
  })

  if (isLoading) return <div>Loading dialogs...</div>
  if (isError) return <div>Error: {error}</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <DialogItem key={dialog.id} dialog={dialog} />
      ))}
      {hasNextPage && (
        <button onClick={() => loadMore(endCursor)}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically handles status filtering logic, transforming GraphQL connection responses into a flattened array of dialogs with cursor-based pagination metadata.
