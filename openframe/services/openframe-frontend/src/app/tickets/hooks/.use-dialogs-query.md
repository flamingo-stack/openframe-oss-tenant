A React Query hook that fetches paginated dialog data from a GraphQL API with support for filtering, searching, and cursor-based pagination. Handles status filtering logic and provides comprehensive error handling for GraphQL responses.

## Key Components

- **useDialogsQuery**: Main hook function that accepts query parameters for filtering and pagination
- **DialogsQueryParams**: Interface defining search, status filters, archived state, and cursor parameters
- **GraphQLResponse**: Generic interface for handling GraphQL API responses with error support
- **DialogsResponse**: Specific response type for dialog connection data
- **Status filtering logic**: Automatically sets appropriate statuses based on archived state and filters
- **Pagination handling**: Implements cursor-based pagination with configurable limits

## Usage Example

```typescript
import { useDialogsQuery } from './use-dialogs-query'

function DialogsList() {
  const {
    dialogs,
    pageInfo,
    isLoading,
    isError,
    error,
    hasNextPage,
    endCursor,
    refetch
  } = useDialogsQuery({
    archived: false,
    search: 'customer issue',
    statusFilters: ['ACTIVE', 'ACTION_REQUIRED'],
    cursor: null // For first page
  })

  if (isLoading) return <div>Loading dialogs...</div>
  if (isError) return <div>Error: {error}</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>{dialog.title}</div>
      ))}
      {hasNextPage && (
        <button onClick={() => refetch({ cursor: endCursor })}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook provides automatic caching (1 minute stale time), retry logic, and comprehensive pagination state management for building responsive dialog interfaces.
