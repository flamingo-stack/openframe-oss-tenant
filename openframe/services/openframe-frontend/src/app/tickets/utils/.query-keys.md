A centralized query key factory for managing React Query cache keys and invalidation logic for dialog/ticket-related queries in the Flamingo platform.

## Key Components

- **`DialogsQueryParams`** - Interface defining query parameters including archived status, search terms, status filters, and pagination cursor
- **`dialogsQueryKeys`** - Hierarchical query key factory with methods for generating type-safe cache keys:
  - `all` - Base key for all dialog queries
  - `lists()` - Key for all paginated list queries
  - `list(params)` - Specific list query key with normalized parameters
- **`invalidateAllDialogs()`** - Utility function to invalidate all dialog-related queries in the React Query cache

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query'
import { dialogsQueryKeys, invalidateAllDialogs } from './query-keys'

// Using query keys for data fetching
const { data } = useQuery({
  queryKey: dialogsQueryKeys.list({ 
    archived: false, 
    search: 'urgent',
    statusFilters: ['open', 'pending']
  }),
  queryFn: fetchDialogs
})

// Invalidating queries after mutations
const queryClient = useQueryClient()
await invalidateAllDialogs(queryClient)

// Invalidating specific list queries
queryClient.invalidateQueries({ 
  queryKey: dialogsQueryKeys.lists() 
})
```

This factory pattern ensures consistent cache key generation and provides efficient query invalidation strategies for the dialog management system.
