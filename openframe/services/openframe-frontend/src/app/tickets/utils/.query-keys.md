A TypeScript module that defines React Query key patterns and utilities for managing ticket/dialog queries with consistent caching and invalidation strategies.

## Key Components

- **`DialogsQueryParams`** - Interface defining the parameters for dialog queries (archived status, search, filters, pagination cursor)
- **`dialogsQueryKeys`** - Hierarchical query key factory providing structured keys for different dialog query types
- **`invalidateAllDialogs`** - Utility function to invalidate all dialog-related queries in the React Query cache

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query'
import { dialogsQueryKeys, invalidateAllDialogs, DialogsQueryParams } from './query-keys'

// Using structured query keys for caching
const useDialogs = (params: DialogsQueryParams) => {
  return useQuery({
    queryKey: dialogsQueryKeys.list(params),
    queryFn: () => fetchDialogs(params)
  })
}

// Invalidating all dialog queries after an update
const updateDialog = async (dialogId: string, data: any) => {
  const queryClient = useQueryClient()
  
  await updateDialogAPI(dialogId, data)
  
  // Invalidate all dialog queries to refresh data
  await invalidateAllDialogs(queryClient)
}

// Example query parameters
const queryParams: DialogsQueryParams = {
  archived: false,
  search: 'urgent',
  statusFilters: ['open', 'pending'],
  cursor: 'next_page_token'
}
```

The hierarchical structure allows for fine-grained cache invalidation - you can invalidate all dialogs, all list queries, or specific parameterized queries as needed.
