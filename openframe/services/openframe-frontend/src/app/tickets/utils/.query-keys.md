Provides standardized query keys for React Query hooks managing ticket/dialog data, implementing a hierarchical key structure for efficient cache management and invalidation.

## Key Components

- **`DialogsQueryParams`** - Interface defining parameters for dialog queries (archived status, search, filters, cursor)
- **`dialogsQueryKeys`** - Hierarchical query key factory with base keys (`all`, `lists`) and parameterized keys (`list`)
- **`invalidateAllDialogs`** - Utility function for bulk cache invalidation of all dialog-related queries

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query'
import { dialogsQueryKeys, invalidateAllDialogs } from './query-keys'

// Using query keys in a hook
const useDialogs = (params: DialogsQueryParams) => {
  return useQuery({
    queryKey: dialogsQueryKeys.list(params),
    queryFn: () => fetchDialogs(params)
  })
}

// Invalidating cache after mutations
const queryClient = useQueryClient()

// Invalidate specific query
queryClient.invalidateQueries({ 
  queryKey: dialogsQueryKeys.list({ archived: false }) 
})

// Invalidate all dialog queries
invalidateAllDialogs(queryClient)
```

The hierarchical structure enables granular cache control - you can invalidate all dialogs, all list queries, or specific parameterized queries while maintaining type safety with TypeScript's `as const` assertions.
