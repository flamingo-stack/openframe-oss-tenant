A TypeScript module that defines standardized query keys for managing React Query cache invalidation and data fetching in a tickets/dialogs system.

## Key Components

- **`DialogsQueryParams`** - Interface defining query parameters for dialog filters (archived status, search, status filters, cursor pagination)
- **`dialogsQueryKeys`** - Hierarchical query key factory with methods for different query scopes:
  - `all` - Base key for all dialog queries
  - `lists()` - Key for paginated list queries
  - `list(params)` - Specific parameterized list query key
- **`invalidateAllDialogs()`** - Utility function to invalidate all dialog-related queries in React Query cache

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query'
import { dialogsQueryKeys, invalidateAllDialogs } from './query-keys'

// Using query keys in a hook
const useDialogs = (params: DialogsQueryParams) => {
  return useQuery({
    queryKey: dialogsQueryKeys.list(params),
    queryFn: () => fetchDialogs(params),
  })
}

// Invalidating queries after a mutation
const queryClient = useQueryClient()
await createDialog(newDialog)
invalidateAllDialogs(queryClient)

// Invalidating specific parameterized query
queryClient.invalidateQueries({ 
  queryKey: dialogsQueryKeys.list({ archived: false, search: 'bug' }) 
})
```

This pattern ensures consistent cache management and enables precise query invalidation strategies across the application.
