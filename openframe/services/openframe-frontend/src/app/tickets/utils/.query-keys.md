Defines standardized query keys for React Query caching and invalidation of ticket/dialog data. This follows React Query best practices by creating hierarchical, type-safe keys that enable efficient cache management.

## Key Components

- **DialogsQueryParams**: Interface defining filtering parameters for dialog queries (archived status, search, status filters, cursor)
- **dialogsQueryKeys**: Hierarchical query key factory with base, list, and parameterized query keys
- **invalidateAllDialogs**: Utility function to invalidate all dialog-related queries at once

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query'
import { dialogsQueryKeys, invalidateAllDialogs, DialogsQueryParams } from './query-keys'

// Using query keys in a hook
const useDialogs = (params: DialogsQueryParams) => {
  return useQuery({
    queryKey: dialogsQueryKeys.list(params),
    queryFn: () => fetchDialogs(params),
  })
}

// Invalidating queries after mutation
const queryClient = useQueryClient()

// Invalidate all dialogs queries
await invalidateAllDialogs(queryClient)

// Or invalidate specific list queries only
await queryClient.invalidateQueries({ 
  queryKey: dialogsQueryKeys.lists() 
})
```

The hierarchical structure allows for granular cache invalidation - you can invalidate all dialogs, all list queries, or specific parameterized queries based on your needs.
