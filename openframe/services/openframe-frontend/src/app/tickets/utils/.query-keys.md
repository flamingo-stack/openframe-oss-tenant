Centralized query key factory for React Query dialog/ticket management with type-safe parameter handling and cache invalidation utilities.

## Key Components

- **DialogsQueryParams**: Interface defining query parameters including archived status, search terms, status filters, and pagination cursor
- **dialogsQueryKeys**: Hierarchical query key factory with nested structure for efficient cache management
  - `all`: Base key for all dialog queries
  - `lists()`: Key for paginated list queries
  - `list(params)`: Specific parameterized list query keys
- **invalidateAllDialogs**: Utility function to invalidate all dialog-related queries in the React Query cache

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query'
import { dialogsQueryKeys, invalidateAllDialogs, DialogsQueryParams } from './query-keys'

// Using query keys in a React Query hook
const useDialogs = (params: DialogsQueryParams) => {
  return useQuery({
    queryKey: dialogsQueryKeys.list(params),
    queryFn: () => fetchDialogs(params)
  })
}

// Invalidating queries after mutation
const queryClient = useQueryClient()
await invalidateAllDialogs(queryClient)

// Example query parameters
const params: DialogsQueryParams = {
  archived: false,
  search: 'urgent',
  statusFilters: ['open', 'pending'],
  cursor: 'next_page_token'
}
```
