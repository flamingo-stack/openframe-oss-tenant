A centralized query key management system for tickets/dialogs React Query hooks, providing type-safe caching and invalidation patterns.

## Key Components

- **`DialogsQueryParams`** - Interface defining query parameters for dialogs (archived status, search, filters, cursor)
- **`dialogsQueryKeys`** - Hierarchical query key factory with base keys, list queries, and parameterized keys
- **`invalidateAllDialogs`** - Utility function for invalidating all dialog-related queries at once

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query'
import { dialogsQueryKeys, invalidateAllDialogs, DialogsQueryParams } from './query-keys'

// Use query keys in React Query hooks
const params: DialogsQueryParams = {
  archived: false,
  search: 'urgent',
  statusFilters: ['open', 'in-progress']
}

const { data } = useQuery({
  queryKey: dialogsQueryKeys.list(params),
  queryFn: () => fetchDialogs(params)
})

// Invalidate all dialogs queries after mutation
const queryClient = useQueryClient()
const handleUpdateDialog = async () => {
  await updateDialog(dialogId, updates)
  await invalidateAllDialogs(queryClient)
}

// Invalidate specific list queries
queryClient.invalidateQueries({ 
  queryKey: dialogsQueryKeys.lists() 
})
```

The hierarchical structure enables efficient cache invalidation - you can invalidate all dialogs, all lists, or specific parameterized queries as needed.
