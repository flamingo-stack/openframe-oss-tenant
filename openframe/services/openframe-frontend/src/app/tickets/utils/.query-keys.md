A centralized query key factory for managing React Query cache keys and invalidation for dialog/ticket data fetching.

## Key Components

- **`DialogsQueryParams`** - Interface defining parameters for dialog queries including archived status, search terms, status filters, and pagination cursor
- **`dialogsQueryKeys`** - Hierarchical query key factory with methods for generating consistent cache keys:
  - `all` - Base key for all dialog queries
  - `lists()` - Key for all list-type queries
  - `list(params)` - Specific parameterized list query key
- **`invalidateAllDialogs()`** - Utility function to invalidate all dialog-related queries in the React Query cache

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query'
import { dialogsQueryKeys, invalidateAllDialogs, DialogsQueryParams } from './query-keys'

// Using query keys in a hook
const useDialogs = (params: DialogsQueryParams) => {
  return useQuery({
    queryKey: dialogsQueryKeys.list(params),
    queryFn: () => fetchDialogs(params)
  })
}

// Invalidating queries after mutation
const queryClient = useQueryClient()
const mutation = useMutation({
  mutationFn: updateDialog,
  onSuccess: () => {
    // Invalidate all dialog queries
    invalidateAllDialogs(queryClient)
    
    // Or invalidate specific list queries
    queryClient.invalidateQueries({ 
      queryKey: dialogsQueryKeys.lists() 
    })
  }
})
```

This pattern ensures consistent cache key generation and enables efficient query invalidation across the application when dialog data changes.
