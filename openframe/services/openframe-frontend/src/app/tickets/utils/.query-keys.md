Defines standardized query keys and parameters for React Query hooks managing ticket/dialog data operations.

## Key Components

- **`DialogsQueryParams`** - Interface defining parameters for dialog queries including archive status, search terms, status filters, and pagination cursor
- **`dialogsQueryKeys`** - Hierarchical query key factory with methods for generating consistent cache keys:
  - `all` - Base key for all dialog queries
  - `lists()` - Key for paginated list queries
  - `list(params)` - Specific list query key with normalized parameters
- **`invalidateAllDialogs`** - Utility function to invalidate all dialog-related queries in the React Query cache

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query'
import { dialogsQueryKeys, invalidateAllDialogs, DialogsQueryParams } from './query-keys'

// Query dialogs with specific parameters
const params: DialogsQueryParams = {
  archived: false,
  search: 'bug report',
  statusFilters: ['open', 'in-progress']
}

const { data } = useQuery({
  queryKey: dialogsQueryKeys.list(params),
  queryFn: () => fetchDialogs(params)
})

// Invalidate all dialog queries after an update
const queryClient = useQueryClient()
await invalidateAllDialogs(queryClient)
```
