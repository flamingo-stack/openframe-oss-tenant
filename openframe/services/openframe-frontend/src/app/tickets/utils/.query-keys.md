Provides standardized query keys and cache management utilities for React Query operations on tickets/dialogs data. This factory pattern ensures consistent cache invalidation and prevents stale data issues.

## Key Components

- **`DialogsQueryParams`** - TypeScript interface defining filter parameters (archived status, search, status filters, cursor for pagination)
- **`dialogsQueryKeys`** - Hierarchical query key factory with nested structure for different query types
- **`invalidateAllDialogs`** - Utility function to invalidate entire dialogs query cache

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query'
import { dialogsQueryKeys, invalidateAllDialogs } from './query-keys'

// Using structured query keys
const { data } = useQuery({
  queryKey: dialogsQueryKeys.list({
    archived: false,
    search: 'urgent',
    statusFilters: ['open', 'pending']
  }),
  queryFn: fetchDialogs
})

// Cache invalidation after mutations
const queryClient = useQueryClient()
const mutation = useMutation({
  mutationFn: updateDialog,
  onSuccess: () => {
    // Invalidates all dialog-related queries
    invalidateAllDialogs(queryClient)
    
    // Or invalidate specific list queries only
    queryClient.invalidateQueries({ 
      queryKey: dialogsQueryKeys.lists() 
    })
  }
})
```

The hierarchical structure (`all` → `lists` → `list(params)`) enables granular cache control, allowing invalidation at any level of specificity.
