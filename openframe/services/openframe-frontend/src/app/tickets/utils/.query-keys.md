A centralized query key factory for React Query hooks managing tickets/dialogs data with hierarchical cache invalidation patterns.

## Key Components

- **`DialogsQueryParams`** - Interface defining parameters for dialog list queries including archive status, search terms, status filters, and pagination cursor
- **`dialogsQueryKeys`** - Hierarchical query key factory with base keys, list queries, and parameterized queries for organized cache management
- **`invalidateAllDialogs()`** - Utility function to invalidate all dialog-related queries at once using the base query key

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query'
import { dialogsQueryKeys, invalidateAllDialogs, DialogsQueryParams } from './query-keys'

// Using query keys in a hook
function useDialogs(params: DialogsQueryParams) {
  return useQuery({
    queryKey: dialogsQueryKeys.list(params),
    queryFn: () => fetchDialogs(params)
  })
}

// Invalidating queries after mutations
function useCreateDialog() {
  const queryClient = useQueryClient()
  
  return useMutation({
    mutationFn: createDialog,
    onSuccess: () => {
      // Invalidate all dialog queries
      invalidateAllDialogs(queryClient)
    }
  })
}

// Example query parameters
const params: DialogsQueryParams = {
  archived: false,
  search: 'urgent',
  statusFilters: ['open', 'pending'],
  cursor: 'next_page_token'
}
```

The hierarchical structure enables granular cache control - you can invalidate all dialogs queries with `dialogsQueryKeys.all`, just list queries with `dialogsQueryKeys.lists()`, or specific parameterized queries.
