Client-side 404 Not Found page component that renders a user-friendly error message when a route cannot be matched.

## Key Components

- **`NotFound`** — Default export; a React component that displays a "Page Not Found" message using the shared `ContentPageContainer` UI wrapper.
- **`dynamic = 'force-dynamic'`** — Next.js route config that opts this page out of static generation, ensuring it is always rendered dynamically.

## Usage Example

This component is automatically used by Next.js when a route is not matched. Place the file at `app/not-found.tsx`:

```typescript
// app/not-found.tsx
// Next.js automatically renders this component for unmatched routes.
// No manual invocation required.

export { default } from './not-found';
```

To trigger it programmatically from a server component or route:

```typescript
import { notFound } from 'next/navigation';

export default async function Page({ params }: { params: { id: string } }) {
  const data = await fetchData(params.id);
  if (!data) notFound(); // renders not-found.tsx
  return <div>{data.name}</div>;
}
```
