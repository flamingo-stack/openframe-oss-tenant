Client-side 404 Not Found page component that renders a user-friendly error message when a route cannot be matched.

## Key Components

- **`NotFound`** — Default export; a React component that displays a "Page Not Found" message using the shared `ContentPageContainer` layout wrapper
- **`dynamic = 'force-dynamic'`** — Next.js route segment config that opts out of static rendering, ensuring the page is always server-rendered dynamically

## Usage Example

```typescript
// Next.js automatically renders this component for unmatched routes
// when placed at app/not-found.tsx

// ContentPageContainer receives:
// - title: "Page Not Found"
// - subtitle: "The page you're looking for doesn't exist."
```

> This file follows Next.js App Router conventions — placing `not-found.tsx` at any route segment level causes Next.js to render it automatically when [`notFound()`](https://nextjs.org/docs/app/api-reference/functions/not-found) is called or no route matches.
