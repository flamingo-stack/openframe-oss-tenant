Client-side 404 error page component that renders a "Page Not Found" message using the shared `ContentPageContainer` UI wrapper.

## Key Components

- **`NotFound`** — Default export; a React component that displays a styled not-found page with a title and subtitle
- **`dynamic = 'force-dynamic'`** — Next.js export that disables static generation, ensuring the page is always server-rendered at request time
- **`ContentPageContainer`** — Shared UI component from `@flamingo-stack/openframe-frontend-core` used to wrap page content with consistent layout, title, and subtitle

## Usage Example

This component is automatically used by Next.js when a route is not matched. No manual invocation is needed — place the file at `app/not-found.tsx` in a Next.js App Router project:

```typescript
// app/not-found.tsx
'use client';

export const dynamic = 'force-dynamic';

import { ContentPageContainer } from '@flamingo-stack/openframe-frontend-core/components/ui';

export default function NotFound() {
  return (
    <ContentPageContainer
      title="Page Not Found"
      subtitle="The page you're looking for doesn't exist."
    >
      <div />
    </ContentPageContainer>
  );
}
```

Next.js will automatically render this component for any unmatched route within its scope. To customize the message, update the `title` or `subtitle` props on `ContentPageContainer`.
