A React component that renders a paginated, filterable table of organizations with search functionality and navigation capabilities.

## Key Components

- **OrganizationsTable** - Main table component with cursor pagination, search, and filtering
- **OrganizationNameCell** - Custom cell component displaying organization name with optional icon and website URL
- **UIOrganizationEntry** - TypeScript interface defining the transformed organization data structure
- **Table columns configuration** - Defines name, tier, MRR, and last activity columns with responsive behavior

## Usage Example

```typescript
// Basic usage in a page component
import { OrganizationsTable } from './organizations-table'

export default function OrganizationsPage() {
  return (
    <div>
      <OrganizationsTable />
    </div>
  )
}

// The component handles all state management internally including:
// - URL-based search and pagination parameters
// - Filter state for tier and industry
// - Organization data fetching via useOrganizations hook
// - Navigation to organization details and edit pages
```

The component integrates with the OpenFrame UI system, provides real-time search with debouncing, supports tier and industry filtering via URL parameters, and includes responsive design that hides the "Last Activity" column on medium screens. Click handlers enable navigation to individual organization details and a floating action button allows adding new organizations.
