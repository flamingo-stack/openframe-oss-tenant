A React table component that displays organization data with filtering, search, and cursor-based pagination functionality.

## Key Components

- **OrganizationNameCell**: Custom table cell rendering organization names with optional images and website URLs
- **OrganizationsTable**: Main table component managing organization data display, filtering by tier/industry, search functionality, and server-side cursor pagination
- **UIOrganizationEntry**: TypeScript interface defining the structure of organization data displayed in the table

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

// Basic usage - renders complete organizations table with all features
function OrganizationsPage() {
  return (
    <div>
      <OrganizationsTable />
    </div>
  )
}

// The component automatically handles:
// - URL-based search and cursor pagination
// - Tier and industry filtering via URL parameters
// - Navigation to organization details on row click
// - Add organization functionality via header action
```

The component integrates with the OpenFrame design system and uses custom hooks for API data fetching (`useOrganizations`) and pagination state management (`useCursorPaginationState`, `useTablePagination`). It supports responsive design with column hiding on smaller screens and includes feature flag integration for organization images.
