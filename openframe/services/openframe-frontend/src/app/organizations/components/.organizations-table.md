A table component for displaying and managing organizations with search, filtering, and pagination capabilities built on the OpenFrame frontend framework.

## Key Components

- **OrganizationsTable** - Main table component with search, filtering, and pagination
- **OrganizationNameCell** - Custom cell renderer for organization name and logo display
- **UIOrganizationEntry** - Type interface for transformed organization data
- **useOrganizations** - Custom hook for organization data management
- **useCursorPaginationState** - Hook for handling cursor-based pagination state

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

function OrganizationsPage() {
  return (
    <div>
      <OrganizationsTable />
    </div>
  )
}
```

The component automatically handles:
- Real-time search across organization data
- URL-based tier and industry filtering
- Cursor-based pagination with server-side data fetching
- Navigation to organization details and edit pages
- Responsive column hiding on mobile devices
- Feature flag-controlled organization image display

The table displays organization name, tier/industry, MRR (Monthly Recurring Revenue), and last activity with custom cell renderers for rich formatting. Users can click rows to navigate to organization details or use the "Add Organization" action button.
