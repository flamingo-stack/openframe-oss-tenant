A React table component for displaying and managing organizations with search, filtering, and pagination capabilities in the OpenFrame platform.

## Key Components

- **OrganizationsTable** - Main component that renders a paginated table of organizations with search and filter functionality
- **OrganizationNameCell** - Custom cell component for displaying organization name and website with optional image icon
- **UIOrganizationEntry** - TypeScript interface defining the structure of organization data for table display

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

// Basic usage - renders complete organizations management interface
export default function OrganizationsPage() {
  return (
    <div className="container mx-auto">
      <OrganizationsTable />
    </div>
  )
}

// The component automatically handles:
// - URL-based search and filtering
// - Cursor-based pagination
// - Organization image display (if feature flag enabled)
// - Navigation to organization details on row click
// - Add new organization action
```

The component integrates with the OpenFrame design system and includes advanced features like:
- Real-time search with debounced API calls
- Client and server-side filtering by tier and industry
- Responsive column hiding for mobile devices
- MRR (Monthly Recurring Revenue) formatting
- Relative time display for last activity
- Feature flag support for organization images
