A React component that renders a paginated, searchable, and filterable table of organizations with comprehensive data display and navigation capabilities.

## Key Components

- **OrganizationsTable**: Main table component with search, filtering, and cursor pagination
- **OrganizationNameCell**: Custom cell renderer for organization names with optional icons
- **UIOrganizationEntry**: TypeScript interface defining the table row data structure
- **Column Configuration**: Responsive table columns for name, tier, MRR, and last activity
- **Filter Management**: URL-based filter state for tier and industry filtering
- **Pagination**: Server-side cursor pagination with "Load More" functionality

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

// Basic usage - renders full table with all features
function OrganizationsPage() {
  return <OrganizationsTable />
}

// The component handles:
// - URL state management for search and filters
// - Server-side pagination with cursor-based navigation
// - Real-time search with debouncing
// - Row click navigation to organization details
// - Responsive column hiding on mobile devices
```

**Key Features:**
- **Search & Filter**: Real-time search with tier/industry filtering via URL params
- **Responsive Design**: Columns adapt to screen size (hides "Last Activity" on mobile)
- **Image Support**: Optional organization icons with feature flag control
- **Navigation**: Click rows to view organization details, add button for new organizations
- **Data Formatting**: Automatic currency formatting for MRR and relative time display
- **Error Handling**: Displays error states and empty messages appropriately
