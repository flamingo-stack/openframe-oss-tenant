A React table component that displays and manages organization data with search, filtering, and cursor-based pagination. This is a feature-rich data table specifically designed for managing MSP client organizations in the OpenFrame platform.

## Key Components

- **`OrganizationNameCell`** - Custom cell renderer for organization names with optional logo images
- **`OrganizationsTable`** - Main table component with comprehensive data management
- **`UIOrganizationEntry`** - TypeScript interface defining the table row data structure

## Key Features

- **Search & Filtering**: Real-time search with tier and industry filters
- **Cursor Pagination**: Server-side pagination with proper state management
- **Image Display**: Optional organization logos with feature flag support
- **Responsive Design**: Columns hide on smaller screens (hideAt: 'md')
- **Data Transformation**: Converts raw API data to display-friendly format
- **Row Actions**: Click to navigate to organization details

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

export default function OrganizationsPage() {
  return (
    <div>
      <OrganizationsTable />
    </div>
  )
}
```

The component integrates with the OpenFrame design system, uses custom hooks for data fetching (`useOrganizations`), and provides a complete CRUD interface for organization management. It handles both client-side filtering for immediate UI updates and server-side filtering for efficient data loading.
