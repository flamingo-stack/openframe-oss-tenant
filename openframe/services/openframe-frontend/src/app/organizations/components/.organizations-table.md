A Next.js client component that renders a paginated table view for managing organizations with search, filtering, and navigation capabilities.

## Key Components

- **OrganizationsTable** - Main table component with cursor pagination, search, and filtering
- **OrganizationNameCell** - Custom cell renderer for organization name and logo display
- **UIOrganizationEntry** - TypeScript interface defining the table row data structure
- **useOrganizations** - Custom hook for data fetching and state management
- **useCursorPaginationState** - Hook for managing pagination state and URL synchronization
- **useTablePagination** - Hook for table pagination controls

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

// Basic usage in a page component
export default function OrganizationsPage() {
  return (
    <div>
      <OrganizationsTable />
    </div>
  )
}

// The table automatically handles:
// - URL state for search, pagination, and filters
// - Organization data fetching with backend filters
// - Row click navigation to organization details
// - Add organization button routing
```

The component integrates with the OpenFrame UI system, supports feature flag-controlled organization images, and provides responsive design with mobile-optimized column hiding. It transforms raw organization data into display-friendly formats including currency formatting and relative time display for last activity.
