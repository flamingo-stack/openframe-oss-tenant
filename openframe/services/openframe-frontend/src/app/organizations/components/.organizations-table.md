A React component that renders a paginated table displaying organization data with filtering, search, and navigation capabilities.

## Key Components

**Main Export:**
- `OrganizationsTable` - The primary table component with full pagination and filtering functionality

**Sub-Components:**
- `OrganizationNameCell` - Custom cell renderer displaying organization name with optional logo and website URL

**Data Interface:**
- `UIOrganizationEntry` - TypeScript interface defining the structure for transformed organization data

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

function OrganizationsPage() {
  return (
    <div>
      <OrganizationsTable />
    </div>
  )
}
```

The component automatically handles:
- **Search functionality** - Real-time organization search via URL params
- **Cursor-based pagination** - Server-side pagination with next/previous navigation  
- **Multi-column filtering** - Filter by tier and industry with URL persistence
- **Row navigation** - Click any row to navigate to organization details
- **Responsive design** - Hides certain columns on smaller screens
- **Data transformation** - Converts raw organization data to display format with MRR formatting and relative timestamps

The table integrates with the OpenFrame design system and uses the `useOrganizations` hook for data fetching. Filter state and pagination are synchronized with URL parameters for shareable links and browser navigation.
