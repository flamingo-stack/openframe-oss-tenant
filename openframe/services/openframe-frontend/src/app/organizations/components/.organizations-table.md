A Next.js client component that renders a comprehensive organizations table with search, filtering, and cursor-based pagination functionality. It integrates with the OpenFrame frontend core components to provide a complete data management interface.

## Key Components

- **OrganizationsTable** - Main component that manages the organizations list view with full CRUD capabilities
- **OrganizationNameCell** - Specialized cell renderer for displaying organization names with optional profile images
- **UIOrganizationEntry** - TypeScript interface defining the transformed data structure for table display
- Custom hooks integration: `useOrganizations`, `useCursorPaginationState`, `useTablePagination`, `useApiParams`

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

// Basic implementation in a page component
export default function OrganizationsPage() {
  return (
    <div className="container mx-auto">
      <OrganizationsTable />
    </div>
  )
}

// The component automatically handles:
// - URL-based search and pagination state
// - Server-side filtering by tier and industry
// - Navigation to organization details and edit pages
// - Real-time data transformations (MRR formatting, time ago calculations)
```

The component features responsive design with mobile-friendly column hiding, server-side pagination with cursor-based navigation, and integrated filter management through URL parameters. It supports organization profile images when enabled via feature flags and provides seamless navigation to detail and edit views.
