A React component that renders a comprehensive organizations table with search, filtering, and pagination capabilities for managing MSP client organizations.

## Key Components

- **OrganizationsTable** - Main table component with cursor-based pagination, search, and filtering
- **OrganizationNameCell** - Custom cell renderer displaying organization icon, name, and website
- **UIOrganizationEntry** - TypeScript interface defining the table row data structure
- **useOrganizations** - Custom hook for fetching and managing organization data
- **useCursorPaginationState** - Hook for managing URL-based pagination state
- **useTablePagination** - Hook for table pagination controls

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

// Basic usage in a page component
function OrganizationsPage() {
  return (
    <div>
      <OrganizationsTable />
    </div>
  )
}

// The component automatically handles:
// - URL-based search parameters (?search=term)
// - Cursor pagination (?cursor=abc123)
// - Filter parameters (?tier[]=enterprise&industry[]=tech)
// - Navigation to organization details and edit pages
```

The table includes columns for organization name with logo, tier/industry, MRR (Monthly Recurring Revenue), and last activity timestamp. It supports responsive design, client-side filtering, server-side pagination, and row-level navigation to detailed views. The component integrates with OpenFrame's design system and includes feature flag support for organization images.
