A comprehensive React table component for displaying and managing organizations with advanced filtering, search, and pagination capabilities.

## Key Components

- **OrganizationsTable** - Main table component with cursor-based pagination and filtering
- **OrganizationNameCell** - Custom cell renderer displaying organization name and website with optional image
- **UIOrganizationEntry** - TypeScript interface defining the table row data structure

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

// Basic usage - renders full organizations management interface
function OrganizationsPage() {
  return (
    <div>
      <OrganizationsTable />
    </div>
  )
}

// The component handles all state management internally including:
// - Search functionality
// - Tier and industry filtering via URL params
// - Cursor-based pagination
// - Navigation to organization details/edit pages
```

## Features

- **Advanced Search**: Real-time search across organization data
- **URL-Based Filtering**: Tier and industry filters persisted in URL parameters
- **Cursor Pagination**: Server-side pagination with cursor-based navigation
- **Responsive Design**: Adaptive column visibility and mobile-friendly layout
- **Image Display**: Optional organization logos with feature flag support
- **Data Formatting**: Automatic formatting for MRR values and relative time display
- **Navigation Integration**: Click-to-navigate to organization details and add new organization workflow

The component integrates with the OpenFrame frontend core library and uses the `useOrganizations` hook for data management, providing a complete organizations management interface with enterprise-grade features.
