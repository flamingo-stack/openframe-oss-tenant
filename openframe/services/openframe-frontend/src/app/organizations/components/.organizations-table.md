A React component that renders a paginated, searchable, and filterable table of organizations with detailed information including MRR, tiers, and activity data.

## Key Components

- **OrganizationNameCell**: Custom cell component displaying organization name and website with optional image icon
- **OrganizationsTable**: Main table component with search, filtering, cursor-based pagination, and navigation
- **UIOrganizationEntry**: Interface defining the transformed data structure for table display
- **Column definitions**: Configures table columns for name, tier/industry, MRR, and last activity

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

// Use in a page component
export default function OrganizationsPage() {
  return <OrganizationsTable />
}
```

The component integrates with:
- **useOrganizations** hook for data fetching with backend filters
- **useCursorPaginationState** for search and pagination state management  
- **useTablePagination** for server-side pagination controls
- **useApiParams** for URL-based filter parameters (tier, industry)

Features include real-time search, client-side filtering after server fetch, click-to-navigate to organization details, and an "Add Organization" action button. The table is responsive with columns that hide on smaller screens.
