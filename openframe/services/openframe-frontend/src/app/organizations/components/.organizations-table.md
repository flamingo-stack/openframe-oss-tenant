A React table component that displays and manages organization data with search, filtering, and pagination capabilities for the OpenFrame platform.

## Key Components

- **OrganizationsTable** - Main component that renders a paginated, searchable table of organizations with client-side filtering
- **OrganizationNameCell** - Custom cell component that displays organization name with optional logo/avatar
- **UIOrganizationEntry** - TypeScript interface defining the transformed organization data structure
- **useOrganizations** - Custom hook for fetching organization data with backend filters
- **useCursorPaginationState** - Hook for managing search and cursor-based pagination state
- **useTablePagination** - Hook for table-specific pagination controls

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

// Basic usage - renders a complete organizations management interface
function OrganizationsPage() {
  return <OrganizationsTable />
}

// The component automatically handles:
// - URL parameter sync for search, filters, and pagination
// - Backend data fetching with proper error handling
// - Client-side filtering by tier and industry
// - Navigation to organization details and creation pages
```

The component integrates with the OpenFrame design system, supports responsive layouts, and includes features like organization logos (when enabled via feature flags), MRR display formatting, and relative time calculations for last activity tracking.
