A React component that renders a paginated table of organizations with search, filtering, and navigation capabilities.

## Key Components

- **OrganizationNameCell**: Custom cell component displaying organization name with optional image icon
- **OrganizationsTable**: Main table component with search, filters, and cursor-based pagination
- **UIOrganizationEntry**: TypeScript interface defining the transformed organization data structure
- **Column definitions**: Table columns for name, tier, MRR, and last activity with responsive layouts

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

// Use in a page or layout component
export default function OrganizationsPage() {
  return (
    <div>
      <OrganizationsTable />
    </div>
  )
}
```

The component integrates with:
- **URL state management** for search queries and filters (tier, industry)
- **Cursor pagination** for efficient data loading
- **Organization images** via feature flags
- **Navigation** to organization details and edit pages
- **Real-time search** with debounced API calls

Features include responsive column hiding, custom cell rendering for formatted data (MRR, timestamps), client-side filtering after server fetch, and skeleton loading states. The table supports row click navigation and includes an "Add Organization" action button.
