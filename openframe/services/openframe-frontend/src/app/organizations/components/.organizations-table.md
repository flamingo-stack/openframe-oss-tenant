A React component that displays a filterable, searchable table of organizations with cursor-based pagination. Built using OpenFrame's core UI components, it provides organization management functionality with real-time filtering and responsive design.

## Key Components

- **OrganizationsTable** - Main table component with search, filtering, and pagination
- **OrganizationNameCell** - Custom cell renderer for organization names with optional images
- **UIOrganizationEntry** - TypeScript interface defining the table row data structure

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

export default function OrganizationsPage() {
  return (
    <div className="container mx-auto">
      <OrganizationsTable />
    </div>
  )
}
```

The component automatically handles:
- URL-based search and filter state management
- Server-side data fetching with the `useOrganizations` hook
- Cursor pagination for large datasets
- Responsive column visibility (hides "Last Activity" on mobile)
- Click-to-navigate functionality for organization details
- Add organization button with navigation to edit form

Column data includes organization name, tier/industry, MRR (Monthly Recurring Revenue), and last activity with human-readable timestamps. The table supports both server-side filtering through URL parameters and client-side filtering for tier and industry categories.
