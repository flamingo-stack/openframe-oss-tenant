A React table component that displays organizations with filtering, search, and pagination capabilities using OpenFrame's design system.

## Key Components

- **OrganizationNameCell** - Custom cell renderer that displays organization name, website URL, and optional logo image
- **OrganizationsTable** - Main table component with search, filtering by tier/industry, cursor-based pagination, and row navigation
- **UIOrganizationEntry** - TypeScript interface defining the transformed organization data structure for display

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

// Basic usage in a page component
export default function OrganizationsPage() {
  return (
    <div className="container mx-auto">
      <OrganizationsTable />
    </div>
  )
}
```

The component automatically handles:
- URL-based search and filter parameters (`?search=...&tier[]=enterprise&industry[]=technology`)
- Cursor pagination with "Load More" and "Reset" functionality  
- Row clicks navigating to `/organizations/details/{id}`
- Add button routing to `/organizations/edit/new`
- Responsive design hiding last activity column on mobile (`hideAt: 'md'`)
- Feature flag integration for organization images display
- Real-time search with debounced API calls

The table transforms raw organization data into a user-friendly format with formatted MRR values, relative timestamps, and truncated text for optimal display across different screen sizes.
