A React component that displays a paginated, filterable table of organizations with search functionality and cursor-based navigation for MSP management.

## Key Components

- **OrganizationsTable** - Main component managing state and rendering the organizations list
- **OrganizationNameCell** - Specialized cell renderer displaying organization name with optional image
- **UIOrganizationEntry** - TypeScript interface defining the table data structure
- **useOrganizations** - Custom hook for data fetching and state management
- **useCursorPaginationState** - Hook for managing pagination state and URL params
- **useTablePagination** - Hook for table-specific pagination logic

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

// Use in a page component
export default function OrganizationsPage() {
  return (
    <div className="p-6">
      <OrganizationsTable />
    </div>
  )
}
```

The component provides:
- **Real-time search** with URL state persistence
- **Multi-field filtering** by tier and industry
- **Cursor-based pagination** for large datasets  
- **Responsive design** with column hiding on mobile
- **Row click navigation** to organization details
- **Add organization** action button
- **Loading states** and error handling

Key features include tier/industry filtering, MRR display formatting, relative time calculations for last activity, and optional organization image display controlled by feature flags.
