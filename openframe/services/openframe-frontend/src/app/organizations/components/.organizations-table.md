A React component that renders a paginated table view for managing organizations with search and filtering capabilities.

## Key Components

- **`OrganizationNameCell`** - Custom cell component displaying organization name, image, and website URL
- **`OrganizationsTable`** - Main table component with search, filtering, and cursor-based pagination
- **`UIOrganizationEntry`** - TypeScript interface defining the data structure for table rows

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

export default function OrganizationsPage() {
  return <OrganizationsTable />
}
```

The component provides a complete organizations management interface featuring:

- **Search functionality** with real-time filtering
- **Column-based filtering** by tier and industry (URL parameter-based)
- **Cursor pagination** for efficient data loading
- **Responsive design** with conditional column visibility
- **Row click navigation** to organization detail pages
- **Add organization action** with routing to edit form

Key features include server-side data fetching with client-side filtering, URL parameter synchronization for bookmarkable filters, and optimized re-renders through memoized transformations. The table displays organization details including name, tier, industry, MRR, and last activity with custom formatting and responsive behavior.
