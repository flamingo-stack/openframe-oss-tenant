A React table component for displaying and managing organizations with search, filtering, and cursor-based pagination functionality.

## Key Components

- **OrganizationsTable** - Main component that renders a paginated table of organizations with search and filter capabilities
- **OrganizationNameCell** - Custom cell component for rendering organization names with optional icons
- **UIOrganizationEntry** - TypeScript interface defining the structure of organization data displayed in the table

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

function OrganizationsPage() {
  return (
    <div>
      <OrganizationsTable />
    </div>
  )
}
```

The component automatically handles:
- **Search functionality** - Real-time organization search
- **Filtering** - By tier and industry with URL parameter persistence
- **Cursor pagination** - Server-side pagination with next/previous navigation
- **Navigation** - Click rows to view organization details, add new organizations
- **Responsive design** - Columns adapt to different screen sizes
- **Loading states** - Skeleton rows during data fetching

The table displays organization name with optional icon, tier/industry, MRR (Monthly Recurring Revenue), and last activity timestamp. Filter state and search terms are persisted in URL parameters for bookmarking and sharing.
