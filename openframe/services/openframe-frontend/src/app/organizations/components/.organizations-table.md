A React component that renders a paginated, searchable table of organizations with filtering capabilities and navigation to detail pages.

## Key Components

**Main Component:**
- `OrganizationsTable` - Main table component with search, filtering, and pagination
- `OrganizationNameCell` - Custom cell renderer for organization name with optional image

**Key Hooks:**
- `useOrganizations` - Manages organization data fetching and state
- `useCursorPaginationState` - Handles pagination state and URL synchronization
- `useApiParams` - Manages filter parameters in URL
- `useTablePagination` - Configures table pagination behavior

**Data Transformation:**
- Transforms raw organization data into `UIOrganizationEntry` format
- Applies client-side filtering for tier and industry
- Formats currency and relative time displays

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

function OrganizationsPage() {
  return (
    <div>
      <OrganizationsTable />
    </div>
  )
}
```

The component automatically handles:
- Server-side search and pagination with cursor-based navigation
- URL parameter synchronization for filters and search state
- Row click navigation to organization detail pages (`/organizations/details/{id}`)
- Add organization action routing to edit form (`/organizations/edit/new`)
- Responsive column hiding and skeleton loading states
- Feature-flagged organization image display
