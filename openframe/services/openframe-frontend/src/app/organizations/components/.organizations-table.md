A React table component for displaying and managing organizations in the Flamingo/OpenFrame platform. This component provides a comprehensive interface with search, filtering, pagination, and row-level navigation capabilities.

## Key Components

- **`OrganizationsTable`** - Main table component with full CRUD operations
- **`OrganizationNameCell`** - Custom cell renderer for organization names with optional images
- **`UIOrganizationEntry`** - TypeScript interface for transformed organization data
- **Hook integrations** - Uses `useOrganizations`, `useCursorPaginationState`, and `useTablePagination`

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

// Basic usage in a page component
export default function OrganizationsPage() {
  return (
    <div>
      <OrganizationsTable />
    </div>
  )
}

// The table automatically handles:
// - URL-based search and filtering parameters
// - Cursor-based pagination
// - Row clicks navigate to /organizations/details/{id}
// - Add button navigates to /organizations/edit/new
```

The component features responsive design with columns that hide on smaller screens, server-side pagination with cursor support, client-side filtering for tiers and industries, and automatic URL parameter synchronization. It displays organization details including name, website, tier, industry, MRR, and last activity with proper formatting and time calculations.
