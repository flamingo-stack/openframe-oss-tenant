A React component that renders a paginated table of organizations with filtering, search, and navigation capabilities in the OpenFrame MSP platform.

## Key Components

- **OrganizationsTable**: Main table component with cursor-based pagination, search functionality, and filtering
- **OrganizationNameCell**: Custom cell renderer that displays organization name with optional icon and website URL
- **UIOrganizationEntry**: TypeScript interface defining the transformed organization data structure for table display

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

// Use in a page component
export default function OrganizationsPage() {
  return (
    <div>
      <OrganizationsTable />
    </div>
  )
}
```

The component integrates with:
- URL-based filter parameters for tier and industry filtering
- Cursor pagination for efficient data loading
- Organization image display (when feature flag enabled)
- Navigation to organization details and editing pages
- Real-time search with backend API integration

The table displays organization name, tier/industry, MRR (Monthly Recurring Revenue), and last activity timestamp with relative time formatting. Rows are clickable for navigation to detailed views.
