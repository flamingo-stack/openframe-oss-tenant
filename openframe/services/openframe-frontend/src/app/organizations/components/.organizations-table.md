A comprehensive React table component for displaying and managing organization data with advanced filtering, search, and cursor-based pagination capabilities.

## Key Components

- **OrganizationsTable**: Main component providing full table functionality with search, filters, and pagination
- **OrganizationNameCell**: Custom cell renderer for displaying organization names with optional logos
- **UIOrganizationEntry**: TypeScript interface defining the transformed organization data structure
- **Advanced State Management**: Integration of cursor pagination, API parameters, and organization data hooks

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

// Basic usage - renders a complete organizations management interface
function OrganizationsPage() {
  return (
    <div className="container mx-auto">
      <OrganizationsTable />
    </div>
  )
}

// The table automatically handles:
// - Search functionality with debounced input
// - Tier and industry filtering via URL parameters
// - Cursor-based pagination with server-side data fetching
// - Row navigation to organization detail pages
// - Add organization action button
```

**Features:**
- **Server-side search and filtering** with URL state persistence
- **Cursor pagination** for efficient large dataset handling  
- **Responsive design** with mobile-optimized column visibility
- **Organization logos** with feature flag support
- **Real-time data formatting** for MRR amounts and activity timestamps
- **Integrated navigation** to organization details and creation forms
