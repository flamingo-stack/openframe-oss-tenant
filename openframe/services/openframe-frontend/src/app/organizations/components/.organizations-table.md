A React table component that displays and manages a paginated list of organizations with filtering, search, and navigation capabilities.

## Key Components

- **OrganizationNameCell**: Custom cell component that renders organization name and website with optional logo
- **OrganizationsTable**: Main table component with search, filtering, pagination, and row click navigation
- **UIOrganizationEntry**: TypeScript interface defining the transformed organization data structure for display
- **Table columns**: Name (with logo), Tier/Industry, MRR, and Last Activity columns with responsive design

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

// Basic usage in a page component
export default function OrganizationsPage() {
  return (
    <div>
      <OrganizationsTable />
    </div>
  )
}

// The component handles its own state including:
// - Search functionality via URL params
// - Cursor-based pagination
// - Tier and industry filtering
// - Navigation to organization details
// - Add new organization action
```

The component integrates with the OpenFrame design system and uses cursor pagination for performance. It transforms raw organization data into display-friendly formats including currency formatting and relative time display. Features include client-side filtering, server-side search, and responsive column hiding on mobile devices.
