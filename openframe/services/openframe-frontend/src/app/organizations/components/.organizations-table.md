A client-side React component that renders a paginated table interface for managing organizations with search, filtering, and navigation capabilities.

## Key Components

- **OrganizationNameCell** - Cell component displaying organization name and website with optional image icon
- **OrganizationsTable** - Main table component with integrated search, filters, and cursor-based pagination
- **UIOrganizationEntry** - Interface defining the transformed organization data structure for display
- **Column Configuration** - Responsive table columns for name, tier/industry, MRR, and last activity

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

export default function OrganizationsPage() {
  return (
    <div className="container">
      <OrganizationsTable />
    </div>
  )
}
```

The component automatically handles:
- URL-based search and filter state management
- Server-side data fetching with cursor pagination
- Client-side filtering for tier and industry
- Navigation to organization details and creation pages
- Responsive design with column hiding on mobile devices

Key features include real-time search, persistent URL state, loading skeletons, and integrated "Add Organization" action button. The table transforms raw organization data into a user-friendly format with formatted MRR values and relative time displays for last activity.
