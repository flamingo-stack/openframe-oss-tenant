A React component that renders a paginated, searchable table of organizations with filtering capabilities and navigation to organization details.

## Key Components

- **OrganizationsTable** - Main table component with cursor pagination, search, and filtering
- **OrganizationNameCell** - Custom cell renderer displaying organization name with optional logo
- **UIOrganizationEntry** - TypeScript interface defining the table row data structure
- **useOrganizations** - Custom hook for managing organization data fetching and state
- **useCursorPaginationState** - Hook for managing pagination state and URL parameters

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

function OrganizationsPage() {
  return (
    <div className="container mx-auto">
      <OrganizationsTable />
    </div>
  )
}

// The component automatically handles:
// - URL-based search and pagination parameters
// - Tier and industry filtering via URL params
// - Navigation to organization details on row click
// - Adding new organizations via the action button
```

## Table Features

- **Responsive columns** with name, tier/industry, MRR, and last activity
- **Server-side search** with URL parameter persistence
- **Cursor-based pagination** for efficient data loading
- **Client-side filtering** by tier and industry after server fetch
- **Feature flag support** for conditional organization image display
- **Row click navigation** to organization detail pages
- **Add organization** action button in the header

The component integrates with the OpenFrame UI system and uses the organization images feature flag to conditionally display organization logos in the name column.
