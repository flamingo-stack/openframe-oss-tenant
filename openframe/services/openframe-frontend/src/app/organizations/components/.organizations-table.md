A table component for displaying and managing organizations with advanced filtering, search, and cursor-based pagination. This component provides a full-featured organization list interface with real-time data updates and responsive design.

## Key Components

- **OrganizationsTable**: Main table component with search, filtering, and pagination
- **OrganizationNameCell**: Custom cell renderer for organization names with optional images
- **UIOrganizationEntry**: Interface defining the table data structure
- **useOrganizations**: Custom hook for data fetching and state management
- **useCursorPaginationState**: Hook for managing cursor-based pagination
- **useTablePagination**: Hook for table pagination controls

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

// Simple usage - component handles all state internally
export default function OrganizationsPage() {
  return <OrganizationsTable />
}

// The component automatically:
// - Fetches organizations data with cursor pagination
// - Handles search with URL state persistence
// - Manages tier/industry filters via URL params
// - Provides add organization functionality
// - Shows organization details on row click
```

The component features server-side pagination with client-side filtering, search functionality with URL state management, responsive column hiding, and integrated image support with feature flags. It uses the OpenFrame design system components and follows modern React patterns with proper state management.
