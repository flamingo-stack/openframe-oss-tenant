A React component that renders a table of organizations with search, filtering, and pagination capabilities for MSP client management.

## Key Components

- **OrganizationsTable**: Main table component with cursor-based pagination, real-time search, and tier/industry filtering
- **OrganizationNameCell**: Custom cell component displaying organization name, logo, and website URL
- **UIOrganizationEntry**: TypeScript interface defining the transformed data structure for table rows
- **useOrganizations**: Custom hook for data fetching with backend filters
- **useCursorPaginationState**: Hook managing search and pagination state via URL parameters

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

// Basic usage in a page component
export default function OrganizationsPage() {
  return (
    <div className="h-full">
      <OrganizationsTable />
    </div>
  )
}

// The component automatically handles:
// - URL-based search: ?search=acme
// - Cursor pagination: ?cursor=xyz123
// - Multi-select filters: ?tier[]=enterprise&industry[]=tech
```

The table displays organization data including name with logo, tier/industry, monthly recurring revenue (MRR), and last activity. Users can search, filter by tier/industry, navigate through paginated results, and click rows to view organization details. The "Add Organization" action navigates to the creation form.
