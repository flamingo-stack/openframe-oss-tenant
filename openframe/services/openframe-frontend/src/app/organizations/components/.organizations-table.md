A React component that renders a data table for managing organizations within the Flamingo OpenFrame platform, featuring search, filtering, pagination, and navigation capabilities.

## Key Components

- **OrganizationsTable**: Main component providing the complete organizations listing interface
- **OrganizationNameCell**: Custom cell component that renders organization names with optional icons and website URLs
- **UIOrganizationEntry**: TypeScript interface defining the structure of organization data displayed in the table
- **Table columns configuration**: Defines name, tier/industry, MRR, and last activity columns with responsive behavior

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

function OrganizationsPage() {
  return (
    <div>
      {/* Renders complete organizations management interface */}
      <OrganizationsTable />
    </div>
  )
}

// The component automatically handles:
// - URL-based search and filtering parameters
// - Cursor-based pagination with server-side data fetching
// - Navigation to organization details and creation pages
// - Responsive table layout with conditional column visibility
```

The component integrates with the OpenFrame design system and includes features like organization image display (when enabled via feature flags), monetary formatting for MRR values, relative time display for last activity, and seamless navigation to organization detail and edit pages through Next.js routing.
