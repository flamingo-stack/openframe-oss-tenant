A comprehensive React table component for displaying and managing organization data with filtering, search, and pagination capabilities.

## Key Components

- **OrganizationsTable** - Main table component with cursor pagination, search, and filtering
- **OrganizationNameCell** - Custom cell renderer for organization names with optional icons
- **UIOrganizationEntry** - TypeScript interface defining the table row data structure
- **Table columns** - Configurable column definitions for name, tier, MRR, and last activity

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

export default function OrganizationsPage() {
  return (
    <div className="container mx-auto">
      <OrganizationsTable />
    </div>
  )
}
```

The component automatically handles:
- Server-side pagination with cursor-based navigation
- Real-time search across organization data
- URL-based filtering by tier and industry
- Responsive design with column hiding on mobile
- Row click navigation to organization details
- Add organization action with routing to edit form

The table integrates with the OpenFrame UI system and uses feature flags for conditional rendering of organization images. It transforms raw organization data into a user-friendly display format with formatted MRR values and relative time displays for last activity.
