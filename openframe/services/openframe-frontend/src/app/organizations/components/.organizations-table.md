A React table component that displays and manages organizations with advanced filtering, search, and cursor-based pagination functionality within the OpenFrame platform.

## Key Components

- **OrganizationsTable** - Main table component with search, filters, and pagination
- **OrganizationNameCell** - Custom cell renderer displaying organization logo, name, and website
- **UIOrganizationEntry** - TypeScript interface defining the transformed organization data structure
- **useOrganizations** - Custom hook for managing organization data and API calls
- **useCursorPaginationState** - Hook for handling URL-based pagination state
- **useTablePagination** - Hook for server-side pagination logic

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

// Basic usage in a page component
export default function OrganizationsPage() {
  return <OrganizationsTable />
}

// The component handles all state management internally:
// - URL-based search and cursor pagination
// - Tier and industry filtering via URL params
// - Organization data fetching and caching
// - Navigation to organization details and edit pages
```

The component integrates with the OpenFrame design system, supports responsive layouts, handles loading states, and provides seamless navigation between organization views. It automatically syncs filter and search state with URL parameters for shareable links and browser history support.
