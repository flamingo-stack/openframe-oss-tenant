A React component that renders a data table displaying organizations with search, filtering, and pagination capabilities. It provides a comprehensive interface for managing and viewing organization data in a tabular format.

## Key Components

- **`OrganizationNameCell`** - Custom cell component that displays organization name with optional image icon
- **`OrganizationsTable`** - Main table component with full CRUD interface
- **`UIOrganizationEntry`** - TypeScript interface defining the data structure for table rows

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

export function OrganizationsPage() {
  return (
    <div>
      <OrganizationsTable />
    </div>
  )
}
```

The component integrates several key features:

- **Search & Filtering**: Real-time search with tier and industry filters via URL parameters
- **Pagination**: Cursor-based pagination with server-side data fetching
- **Data Transformation**: Formats monetary values, timestamps, and relative time displays
- **Navigation**: Click handlers for row selection and "Add Organization" action
- **Responsive Design**: Adaptive column visibility and mobile-optimized layout

The table displays organization name (with optional image), tier/industry, monthly recurring revenue (MRR), and last activity timestamp. It uses the OpenFrame UI component library and integrates with the organizations data hook for state management.
