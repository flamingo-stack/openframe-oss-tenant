A React component that displays organizations in a paginated, searchable, and filterable table with detailed organization information and navigation capabilities.

## Key Components

- **OrganizationsTable**: Main component providing complete organization management interface
- **OrganizationNameCell**: Custom cell renderer displaying organization name, website, and optional logo
- **UIOrganizationEntry**: TypeScript interface defining the transformed data structure for table display
- **Table columns**: Configurable column definitions for name, tier/industry, MRR, and last activity

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

function OrganizationsPage() {
  return (
    <div className="p-4">
      <OrganizationsTable />
    </div>
  )
}
```

The component integrates with:
- **Cursor-based pagination** with server-side data fetching
- **Real-time search** functionality
- **Multi-filter support** for tier and industry
- **URL state management** for filters and pagination
- **Navigation routing** to organization details and creation forms

Features include responsive design with mobile column hiding, skeleton loading states, custom organization icons (when feature flag enabled), and formatted MRR display with relative time calculations for last activity.
