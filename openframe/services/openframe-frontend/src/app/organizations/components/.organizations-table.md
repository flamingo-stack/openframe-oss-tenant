This React component renders a searchable, filterable table of organizations with cursor-based pagination and client-side data transformation. It provides a full-page layout with search, filtering, and navigation capabilities for managing organizational data.

## Key Components

- **OrganizationNameCell**: Custom cell component that displays organization name, logo (if enabled), and website URL
- **OrganizationsTable**: Main table component with search, filtering, pagination, and row click navigation
- **UIOrganizationEntry**: TypeScript interface defining the transformed organization data structure
- **Pagination Hooks**: Uses `useCursorPaginationState` and `useTablePagination` for server-side cursor pagination
- **Filter Management**: Handles tier and industry filters via URL parameters with `useApiParams`

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

// Use in a page component
export default function OrganizationsPage() {
  return <OrganizationsTable />
}
```

The component automatically:
- Fetches organizations data with the `useOrganizations` hook
- Transforms raw organization data into display format with MRR formatting and relative timestamps
- Handles search queries and filter changes with automatic refetching
- Provides navigation to organization details pages and creation flow
- Supports responsive design with column hiding on mobile devices
- Maintains filter and pagination state in URL parameters for bookmarking/sharing

The table includes columns for organization name/logo, tier/industry, MRR, and last activity, with client-side filtering applied after server-side data fetching.
