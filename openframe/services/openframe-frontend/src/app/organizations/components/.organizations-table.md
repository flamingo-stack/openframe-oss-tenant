A client-side React component that renders a paginated, searchable table of organizations with filtering capabilities and navigation integration.

## Key Components

**Main Component:**
- `OrganizationsTable` - Primary table component with search, filters, and pagination
- `OrganizationNameCell` - Custom cell renderer for organization name with optional image icon

**Key Features:**
- Cursor-based pagination with server-side data fetching
- Real-time search functionality
- Client-side filtering by tier and industry
- URL parameter synchronization for filters and search state
- Responsive design with column hiding on mobile devices
- Row click navigation to organization details

**Data Transformation:**
- Converts raw organization data to UI-friendly format
- Formats monetary values (MRR) with locale-specific formatting
- Calculates relative time displays for last activity

## Usage Example

```typescript
// Basic usage in a page component
import { OrganizationsTable } from './organizations-table'

export default function OrganizationsPage() {
  return (
    <div>
      <OrganizationsTable />
    </div>
  )
}

// The component automatically handles:
// - URL params like ?search=acme&tier[]=enterprise&industry[]=tech
// - Pagination with cursor-based loading
// - Navigation to /organizations/details/{id} on row click
// - Add organization button routing to /organizations/edit/new
```

The component integrates with the OpenFrame UI system and uses custom hooks for API state management, providing a complete organizations management interface with search, filtering, and CRUD navigation.
