React component that renders a data table for managing and viewing organizations in the MSP platform. Provides search, filtering, and pagination capabilities with cursor-based navigation.

## Key Components

- **OrganizationNameCell**: Custom cell renderer displaying organization name, icon, and website URL
- **OrganizationsTable**: Main table component with full CRUD operations and filtering
- **UIOrganizationEntry**: TypeScript interface defining the table row data structure
- **Hooks Integration**: Uses `useOrganizations`, `useCursorPaginationState`, and `useTablePagination` for data management

## Usage Example

```typescript
import { OrganizationsTable } from './organizations-table'

// Render the complete organizations management interface
function OrganizationsPage() {
  return <OrganizationsTable />
}

// The table automatically handles:
// - Server-side pagination with cursor navigation
// - Search functionality across organization fields
// - Tier and industry filtering via URL parameters
// - Row click navigation to organization details
// - Add new organization action button
```

## Features

- **Responsive Design**: Columns hide on mobile devices for optimal viewing
- **Real-time Search**: Debounced search with URL parameter synchronization
- **Multi-level Filtering**: Tier and industry filters with client and server-side support
- **Cursor Pagination**: Efficient navigation through large datasets
- **Feature Flags**: Conditional organization image display
- **Data Formatting**: Currency formatting for MRR and relative time display for activity
- **Navigation Integration**: Click-to-view details and add organization routing

The component integrates with the OpenFrame design system and follows MSP platform conventions for data presentation and user interaction patterns.
