A React component that displays comprehensive details for a specific organization in the OpenFrame MSP platform, including contact information, service configuration, and management actions.

## Key Components

- **OrganizationDetailsView**: Main component that renders organization details with edit/delete functionality
- **useOrganizationDetails**: Custom hook for fetching organization data by ID
- **useDeleteOrganization**: Custom hook for organization deletion operations
- **DetailPageContainer**: Layout wrapper providing standard page structure with header actions
- **InfoCard**: Reusable component for displaying structured contact and configuration data

## Usage Example

```typescript
import { OrganizationDetailsView } from './organization-details-view'

// In a page component or route handler
export default function OrganizationPage({ params }: { params: { id: string } }) {
  return <OrganizationDetailsView id={params.id} />
}

// The component automatically handles:
// - Loading states with skeleton loaders
// - Error states for failed requests or missing organizations
// - Organization data fetching on mount
// - Navigation to edit form and back to organizations list
// - Delete confirmation with toast notifications
```

The component features a responsive grid layout displaying organization summary info (industry, website, employees, addresses), three contact cards (primary, billing, technical), service configuration details (MRR, contract dates), and notes section. Edit and delete actions are available via header buttons, with delete protection for default organizations.
