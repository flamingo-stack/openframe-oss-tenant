A React component that displays comprehensive details for a specific organization in a detailed view layout with edit/delete capabilities and organized contact information.

## Key Components

- **OrganizationDetailsView**: Main component that renders organization details with summary cards, contact information sections, and management actions
- **Custom hooks integration**: Uses `useOrganizationDetails` for data fetching and `useDeleteOrganization` for deletion operations
- **Navigation actions**: Back button, edit button, and conditional delete functionality
- **Responsive layout**: Grid-based design that adapts to different screen sizes
- **Contact sections**: Displays primary, billing, and technical contact information in separate cards
- **Service configuration**: Shows MRR, contract dates, and notes sections

## Usage Example

```typescript
import { OrganizationDetailsView } from './organization-details-view'

// In a page component or route handler
function OrganizationDetailPage({ params }: { params: { id: string } }) {
  return (
    <OrganizationDetailsView id={params.id} />
  )
}

// The component handles all internal state management including:
// - Loading states with CardLoader
// - Error handling with LoadError/NotFoundError 
// - Edit navigation to /organizations/edit/${id}
// - Delete operations with confirmation toast messages
// - Back navigation to /organizations list
```

The component provides a complete organization detail view with proper error handling, loading states, and user-friendly actions for organization management within the OpenFrame platform.
