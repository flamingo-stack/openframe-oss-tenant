A React component that displays comprehensive details for a single organization in the OpenFrame platform, featuring organization information, contacts, and service configuration.

## Key Components

- **OrganizationDetailsView** - Main component that renders organization details with edit/delete functionality
- **useOrganizationDetails** - Custom hook for fetching organization data
- **useDeleteOrganization** - Custom hook for organization deletion
- **DetailPageContainer** - Layout wrapper with header actions and navigation
- **InfoCard** - Displays structured contact and service information
- **OrganizationIcon** - Organization avatar/logo display (feature-flagged)

## Usage Example

```typescript
import { OrganizationDetailsView } from './organization-details-view'

// In a page component
export default function OrganizationPage({ params }: { params: { id: string } }) {
  return <OrganizationDetailsView id={params.id} />
}

// The component automatically:
// - Fetches organization data on mount
// - Displays loading states and error handling
// - Provides edit/delete actions with toast notifications
// - Shows organization summary, contacts, and service config
// - Prevents deletion of default organizations
```

The component includes responsive layout with organization summary metrics, three contact types (primary, billing, technical), service configuration details, and notes section. Navigation includes back button to organizations list and action buttons for editing/deleting with proper error handling and user feedback.
