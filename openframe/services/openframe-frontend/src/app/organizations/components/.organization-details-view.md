A React component that renders a detailed view of an organization, displaying comprehensive information including contacts, service configuration, and management actions.

## Key Components

- **OrganizationDetailsView** - Main component that fetches and displays organization details
- **useOrganizationDetails** - Custom hook for fetching organization data
- **useDeleteOrganization** - Custom hook for organization deletion
- **DetailPageContainer** - Layout wrapper with header and navigation
- **InfoCard** - Reusable card component for displaying structured data
- **OrganizationIcon** - Displays organization logo/avatar

## Usage Example

```typescript
import { OrganizationDetailsView } from './organization-details-view'

export default function OrganizationPage({ params }: { params: { id: string } }) {
  return <OrganizationDetailsView id={params.id} />
}
```

The component automatically handles loading states with `CardLoader`, error states with `LoadError` and `NotFoundError`, and provides edit/delete functionality. It displays organization information in a structured layout including industry details, contact information for primary/billing/technical contacts, service configuration with MRR and contract dates, and any associated notes. The delete action is disabled for default organizations and includes toast notifications for user feedback.
