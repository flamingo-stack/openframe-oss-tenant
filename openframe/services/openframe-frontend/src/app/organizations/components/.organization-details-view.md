A React component that displays detailed information about a specific organization in a comprehensive view with editing and deletion capabilities.

## Key Components

- **OrganizationDetailsView** - Main component that renders organization details in a structured layout
- **useOrganizationDetails** - Custom hook for fetching organization data
- **useDeleteOrganization** - Custom hook for organization deletion
- **DetailPageContainer** - Layout wrapper with header actions and navigation
- **InfoCard** - Component for displaying contact and service information in cards

## Usage Example

```typescript
import { OrganizationDetailsView } from './organization-details-view'

export default function OrganizationPage({ params }: { params: { id: string } }) {
  return <OrganizationDetailsView id={params.id} />
}
```

The component automatically fetches organization data on mount, displays loading states, and handles errors gracefully. It renders organization information in sections including basic details, contact information (primary, billing, technical), service configuration, and notes. Users can edit organizations via the edit button or delete them (unless it's a default organization). The interface includes proper error handling with toast notifications and responsive design for mobile and desktop views.
