A React component that displays detailed information about an organization in a comprehensive view with edit/delete functionality. This component fetches organization data by ID and presents it in a structured layout with contact information, service configuration, and notes.

## Key Components

- **OrganizationDetailsView**: Main component that renders organization details
- **useOrganizationDetails**: Custom hook for fetching organization data
- **useDeleteOrganization**: Custom hook for organization deletion
- **DetailPageContainer**: Layout wrapper with header actions
- **InfoCard**: Card component for displaying structured data
- **OrganizationIcon**: Organization avatar/icon component

## Usage Example

```typescript
import { OrganizationDetailsView } from './organization-details-view'

// In a page component
export default function OrganizationPage({ params }: { params: { id: string } }) {
  return <OrganizationDetailsView id={params.id} />
}

// The component handles:
// - Loading states with CardLoader
// - Error states with LoadError/NotFoundError
// - Organization data display in structured sections
// - Edit/delete actions with navigation and toast notifications
```

The component features a responsive grid layout showing organization metadata, three contact types (primary, billing, technical), service configuration details, and notes section. It includes feature flag support for organization images and prevents deletion of default organizations.
