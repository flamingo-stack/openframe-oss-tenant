A React component that displays comprehensive details for a specific organization in the Flamingo OpenFrame MSP platform. This view provides a complete overview of organization information including contacts, service configuration, and management actions.

## Key Components

- **OrganizationDetailsView** - Main component that renders organization details with edit/delete functionality
- **useOrganizationDetails** - Custom hook for fetching organization data
- **useDeleteOrganization** - Custom hook for organization deletion
- **DetailPageContainer** - Layout wrapper with header actions and navigation
- **InfoCard** - Reusable component for displaying structured data sections

## Usage Example

```typescript
import { OrganizationDetailsView } from './organization-details-view'

// In a page component
export default function OrganizationPage({ params }: { params: { id: string } }) {
  return <OrganizationDetailsView id={params.id} />
}

// The component automatically:
// - Fetches organization data on mount
// - Displays loading/error states
// - Renders organization summary with industry, website, employees
// - Shows primary, billing, and technical contacts
// - Displays service configuration and notes
// - Provides edit/delete actions (delete disabled for default org)
```

The component uses OpenFrame's design system for consistent styling and includes comprehensive error handling, loading states, and responsive layout for mobile and desktop viewports.
