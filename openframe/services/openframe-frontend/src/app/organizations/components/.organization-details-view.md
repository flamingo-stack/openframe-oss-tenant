A React component for displaying detailed organization information in a read-only view with edit and delete capabilities. This component fetches and renders comprehensive organization data including contacts, service configuration, and administrative details.

## Key Components

- **OrganizationDetailsView**: Main component that displays organization details with edit/delete actions
- **useOrganizationDetails**: Hook for fetching organization data by ID
- **useDeleteOrganization**: Hook for handling organization deletion
- **DetailPageContainer**: Layout wrapper with header actions and navigation
- **InfoCard**: Displays structured information in cards for contacts and service details

## Usage Example

```typescript
import { OrganizationDetailsView } from './organization-details-view'

// In a page component
export default function OrganizationPage({ params }: { params: { id: string } }) {
  return <OrganizationDetailsView id={params.id} />
}

// The component handles:
// - Loading states with CardLoader
// - Error states with LoadError/NotFoundError
// - Edit navigation to /organizations/edit/${id}
// - Delete confirmation with toast notifications
// - Feature flag controlled organization images
```

The component displays organization information in sections: summary stats, contact details (primary, billing, technical), service configuration with MRR and contract dates, and notes. Default organizations cannot be deleted, and all actions include proper error handling with toast notifications.
