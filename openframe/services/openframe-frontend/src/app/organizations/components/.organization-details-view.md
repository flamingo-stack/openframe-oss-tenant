A React component that displays detailed information about an organization in a comprehensive view layout with edit/delete functionality.

## Key Components

- **OrganizationDetailsView** - Main component that renders organization details in a structured layout
- **useOrganizationDetails** - Custom hook for fetching organization data
- **useDeleteOrganization** - Custom hook for organization deletion with toast notifications
- **DetailPageContainer** - Layout wrapper with back navigation and header actions
- **InfoCard** - Component for displaying structured contact and service information

## Usage Example

```typescript
import { OrganizationDetailsView } from './organization-details-view'

export default function OrganizationPage({ params }: { params: { id: string } }) {
  return <OrganizationDetailsView id={params.id} />
}

// Renders a comprehensive organization view with:
// - Organization summary (industry, website, employees, last updated)
// - Physical and mailing addresses
// - Three contact sections (primary, billing, technical)
// - Service configuration (MRR, contract dates)
// - Notes section
// - Edit/Delete action buttons (delete disabled for default orgs)
```

The component handles loading states, error scenarios, and not-found cases with appropriate UI feedback. It integrates with OpenFrame's design system and includes conditional organization image display based on feature flags.
