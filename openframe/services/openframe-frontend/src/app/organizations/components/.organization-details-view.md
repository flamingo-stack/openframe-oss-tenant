A React component that displays detailed information about an organization with edit and delete functionality. It fetches organization data by ID and presents it in a structured layout with contact information, service configuration, and notes sections.

## Key Components

- **OrganizationDetailsView** - Main component that renders the complete organization details page
- **useOrganizationDetails** - Custom hook for fetching organization data
- **useDeleteOrganization** - Custom hook for handling organization deletion
- **DetailPageContainer** - Layout wrapper with navigation and header actions
- **InfoCard** - Reusable card component for displaying structured data
- **OrganizationIcon** - Organization-specific icon/avatar component

## Usage Example

```typescript
import { OrganizationDetailsView } from './organization-details-view'

// In a Next.js page or parent component
function OrganizationPage() {
  return (
    <OrganizationDetailsView id="org-123" />
  )
}

// The component will:
// 1. Fetch organization data using the provided ID
// 2. Display loading state while fetching
// 3. Show error or not found states if needed
// 4. Render complete organization details with actions
```

The component handles loading states, error handling, and provides edit/delete actions. It prevents deletion of default organizations and shows toast notifications for user feedback. The layout is responsive with a grid-based design for contact information and service details.
