A comprehensive organization detail view component that displays full organization information including contacts, service configuration, and management actions within the OpenFrame MSP platform.

## Key Components

- **OrganizationDetailsView** - Main component that renders organization details with edit/delete functionality
- **useOrganizationDetails** - Custom hook for fetching organization data
- **useDeleteOrganization** - Custom hook for organization deletion
- **DetailPageContainer** - Layout wrapper with navigation and header actions
- **InfoCard** - Reusable card component for displaying structured data
- **OrganizationIcon** - Organization logo/avatar display (feature-flagged)

## Usage Example

```typescript
import { OrganizationDetailsView } from './organization-details-view'

export default function OrganizationPage({ params }: { params: { id: string } }) {
  return (
    <div className="container mx-auto">
      <OrganizationDetailsView id={params.id} />
    </div>
  )
}

// Route usage: /organizations/[id]
// Displays comprehensive organization info with:
// - Basic details (industry, website, employees, addresses)
// - Three contact types (primary, billing, technical)
// - Service configuration (MRR, contract dates)
// - Notes section
// - Edit/delete actions (delete disabled for default org)
```

The component handles loading states, error scenarios, and provides seamless navigation back to the organizations list. It integrates with the OpenFrame design system using ODS (OpenFrame Design System) CSS variables and includes feature flag support for conditional UI elements.
