A React component that displays comprehensive organization details in a structured, card-based layout with edit and delete capabilities.

## Key Components

- **OrganizationDetailsView** - Main component that renders organization information with sections for summary, contacts, and service configuration
- **useOrganizationDetails** - Hook for fetching organization data by ID
- **useDeleteOrganization** - Hook for handling organization deletion
- **DetailPageContainer** - Layout wrapper with header actions and navigation
- **InfoCard** - Displays structured data in labeled sections
- **OrganizationIcon** - Avatar component for organization branding

## Usage Example

```typescript
import { OrganizationDetailsView } from './organization-details-view'

// Display organization details page
function OrganizationPage({ params }: { params: { id: string } }) {
  return <OrganizationDetailsView id={params.id} />
}

// The component automatically handles:
// - Loading states with skeleton UI
// - Error handling for missing organizations
// - Organization deletion with confirmation
// - Navigation back to organizations list
// - Edit organization routing

export default OrganizationPage
```

The component features a responsive layout with organization summary metrics, three contact sections (primary, billing, technical), service configuration details, and notes. It includes proper error boundaries, loading states, and prevents deletion of default organizations while providing toast notifications for user feedback.
