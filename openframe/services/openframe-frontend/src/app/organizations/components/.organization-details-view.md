A React component that displays comprehensive organization details in a structured layout with edit and delete functionality.

## Key Components

- **OrganizationDetailsView** - Main component that fetches and displays organization data
- **useOrganizationDetails** - Hook for fetching organization data by ID
- **useDeleteOrganization** - Hook for organization deletion with confirmation
- **DetailPageContainer** - Layout wrapper with header actions and navigation
- **InfoCard** - Reusable component for displaying contact and service information
- **OrganizationIcon** - Feature-flagged organization image display

## Usage Example

```typescript
import { OrganizationDetailsView } from './organization-details-view'

// In a Next.js page or parent component
export default function OrganizationPage({ params }: { params: { id: string } }) {
  return <OrganizationDetailsView id={params.id} />
}

// The component handles:
// - Loading states with CardLoader
// - Error handling with LoadError/NotFoundError
// - Organization data display in structured sections
// - Edit/delete actions with proper validation
// - Responsive grid layouts for contact information
```

The component renders organization details in sections: summary row with key metrics, three contact cards (primary, billing, technical), service configuration, and notes. It includes proper error handling, loading states, and prevents deletion of default organizations.
