A React component that displays detailed information about a single organization, including contact details, service configuration, and management actions.

## Key Components

- **OrganizationDetailsView** - Main component that renders organization details with edit/delete functionality
- **useOrganizationDetails** - Custom hook for fetching organization data
- **useDeleteOrganization** - Custom hook for organization deletion
- **DetailPageContainer** - Layout wrapper with header actions and navigation
- **InfoCard** - Displays structured contact and service information

## Usage Example

```typescript
import { OrganizationDetailsView } from './organization-details-view'

// Display organization details page
function OrganizationPage({ params }: { params: { id: string } }) {
  return <OrganizationDetailsView id={params.id} />
}

// The component handles:
// - Loading states with CardLoader
// - Error states with LoadError/NotFoundError  
// - Organization data display with contact cards
// - Edit/delete actions with toast notifications
// - Feature flag-controlled organization images
// - Default organization protection (prevents deletion)
```

The component provides a comprehensive view of organization data including primary/billing/technical contacts, service configuration, contract details, and administrative notes. It integrates with the OpenFrame design system and handles all standard CRUD operations with proper error handling and user feedback.
