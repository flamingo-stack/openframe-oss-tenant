Utility functions for organizing and managing AI policy settings within the OpenFrame frontend, including grouping, cloning, and data transformation operations.

## Key Components

- **`buildPolicyGroups`** - Transforms an array of PolicyRule objects into a hierarchical Map structure grouped by policy group and category
- **`clonePolicyGroups`** - Creates a deep copy of policy group data to prevent mutation issues
- **`mapToObject`** - Converts Map instances to plain JavaScript objects
- **`slugify`** - Internal helper that converts strings to URL-safe slugs for consistent identifiers

## Usage Example

```typescript
import { buildPolicyGroups, clonePolicyGroups } from './ai-settings.utils'
import type { PolicyRule } from '../types/ai-policies'

// Transform policy rules into grouped structure
const policyRules: PolicyRule[] = [
  {
    naturalKey: 'user-management-create',
    operation: 'Create User',
    category: 'User Management',
    policyGroup: 'Administration',
    tool: 'user-service',
    approvalLevel: 'manager',
    commandPattern: 'create user *'
  }
]

const groupedPolicies = buildPolicyGroups(policyRules)
// Returns: Map<"Administration", [PermissionCategory]>

// Create a safe copy for state management
const policiesCopy = clonePolicyGroups(groupedPolicies)

// Convert to object for serialization
const policiesObject = mapToObject(groupedPolicies)
```

The utilities handle the complex task of organizing flat policy rule arrays into the nested category structure required by the AI settings interface, with proper sorting and fallback handling for missing data.
