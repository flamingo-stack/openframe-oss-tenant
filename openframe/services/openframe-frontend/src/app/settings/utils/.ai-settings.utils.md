Utility functions for processing and organizing AI policy settings into structured permission categories for the OpenFrame interface.

## Key Components

- **`buildPolicyGroups`** - Main function that transforms policy rules into a hierarchical Map structure grouped by policy groups and categories
- **`clonePolicyGroups`** - Creates a deep clone of policy group Map to prevent mutation
- **`mapToObject`** - Generic utility to convert Map entries to plain JavaScript objects
- **`slugify`** - Internal helper that creates URL-safe identifiers from strings

## Usage Example

```typescript
import { buildPolicyGroups, clonePolicyGroups } from './ai-settings.utils'

// Transform policy rules into grouped categories
const policyRules: PolicyRule[] = [
  {
    naturalKey: 'file-access',
    policyGroup: 'Security',
    category: 'File Operations',
    operation: 'Access Files',
    commandPattern: 'read_file',
    tool: 'filesystem',
    approvalLevel: 'medium'
  }
]

const groupedPolicies = buildPolicyGroups(policyRules)
// Returns Map with structure: "Security" -> [PermissionCategory with file policies]

// Create a safe copy for mutations
const clonedGroups = clonePolicyGroups(groupedPolicies)

// Convert to plain object if needed for serialization
const plainObject = mapToObject(groupedPolicies)
```

The utilities handle policy organization with automatic categorization, slugified identifiers, sorting by name, and consistent Shield icons for all categories.
