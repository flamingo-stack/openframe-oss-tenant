Utility functions for organizing and managing AI policy rules into structured permission categories and groups for the AI settings interface.

## Key Components

- **`slugify()`** - Converts strings to URL-friendly slugs by normalizing case and special characters
- **`buildPolicyGroups()`** - Transforms flat policy rule arrays into hierarchical permission category maps grouped by policy group
- **`clonePolicyGroups()`** - Creates deep copies of policy group maps for immutable updates
- **`mapToObject()`** - Converts Map instances to plain JavaScript objects

## Usage Example

```typescript
import { buildPolicyGroups, clonePolicyGroups } from './ai-settings.utils'

// Transform policy rules into organized groups
const policyRules: PolicyRule[] = [
  {
    naturalKey: 'file-access',
    operation: 'File Access',
    policyGroup: 'Security',
    category: 'File Operations',
    tool: 'file-manager',
    approvalLevel: 'auto',
    commandPattern: 'access file *'
  }
]

const policyGroups = buildPolicyGroups(policyRules)
// Returns: Map<string, PermissionCategory[]> with organized categories

// Clone for editing without mutation
const editableGroups = clonePolicyGroups(policyGroups)

// Convert to object for serialization
const serializable = mapToObject(policyGroups)
```

The utilities handle the complex task of organizing policy rules by group and category, with proper sorting and icon assignment, while maintaining immutability patterns for React state management.
