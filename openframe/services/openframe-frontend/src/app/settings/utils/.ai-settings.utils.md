Utility functions for organizing and manipulating AI policy settings data structures in the OpenFrame frontend.

## Key Components

- **`buildPolicyGroups`** - Transforms flat policy rules array into hierarchical grouped structure organized by policy group and category
- **`clonePolicyGroups`** - Creates deep clone of policy groups Map to prevent mutation of original data
- **`mapToObject`** - Converts Map data structure to plain object format
- **`slugify`** - Internal helper that converts strings to URL-friendly slugs

## Usage Example

```typescript
import { buildPolicyGroups, clonePolicyGroups } from './ai-settings.utils'
import type { PolicyRule } from '../types/ai-policies'

// Transform policy rules into grouped structure
const policyRules: PolicyRule[] = [
  {
    naturalKey: 'file-read',
    operation: 'Read Files',
    policyGroup: 'File Operations',
    category: 'System Access',
    tool: 'filesystem',
    approvalLevel: 'medium',
    commandPattern: 'read *'
  }
]

const policyGroups = buildPolicyGroups(policyRules)
// Result: Map with "File Operations" -> [{ id: "file-operations:system-access", name: "System Access", policies: [...] }]

// Clone for safe manipulation
const clonedGroups = clonePolicyGroups(policyGroups)

// Convert to object if needed for serialization
const groupsObject = mapToObject(policyGroups)
```

The utilities handle the complex data transformation needed for the AI settings UI, organizing policies into expandable categories with proper metadata and ensuring data immutability.
