Utility functions for transforming and managing AI policy settings and permission categories within the OpenFrame platform.

## Key Components

- **`slugify()`** - Converts strings to URL-friendly slugs by normalizing case and special characters
- **`buildPolicyGroups()`** - Transforms policy rules into hierarchical permission categories grouped by policy groups
- **`clonePolicyGroups()`** - Creates deep copies of policy group structures for state management
- **`mapToObject()`** - Generic utility to convert Map instances to plain JavaScript objects

## Usage Example

```typescript
import { buildPolicyGroups, clonePolicyGroups } from './ai-settings.utils'

// Transform policy rules into grouped categories
const policyRules: PolicyRule[] = [
  {
    naturalKey: 'file-read',
    operation: 'Read Files',
    category: 'File Operations',
    policyGroup: 'System',
    tool: 'filesystem',
    approvalLevel: 'auto',
    commandPattern: 'read-*'
  }
]

const groups = buildPolicyGroups(policyRules)
// Returns: Map with 'System' group containing 'File Operations' category

// Clone for safe state mutations
const clonedGroups = clonePolicyGroups(groups)

// Convert to object for serialization
const groupsObject = mapToObject(groups)
```

The utilities handle the complex transformation of flat policy rules into nested permission structures, including automatic categorization, sorting, and metadata enrichment with icons and configuration counts.
