Utility functions for organizing and manipulating AI policy settings data structures in the OpenFrame frontend, including policy grouping, cloning, and data transformation operations.

## Key Components

- **`slugify()`** - Converts strings to URL-friendly slugs by normalizing case and special characters
- **`buildPolicyGroups()`** - Transforms flat policy rule arrays into hierarchical permission category groups organized by policy group and category
- **`clonePolicyGroups()`** - Creates deep copies of policy group maps to prevent mutation of original data
- **`mapToObject()`** - Converts Map instances to plain JavaScript objects for serialization or API calls

## Usage Example

```typescript
import { buildPolicyGroups, clonePolicyGroups } from './ai-settings.utils'
import type { PolicyRule } from '../types/ai-policies'

// Transform policy rules into organized groups
const policyRules: PolicyRule[] = [
  {
    naturalKey: 'file-read',
    operation: 'Read Files',
    category: 'File System',
    policyGroup: 'Security',
    tool: 'filesystem',
    approvalLevel: 'manual',
    commandPattern: 'read *'
  }
]

const policyGroups = buildPolicyGroups(policyRules)
// Returns: Map<'Security', [{ id: 'security:file-system', name: 'File System', policies: [...] }]>

// Create editable copy
const editableGroups = clonePolicyGroups(policyGroups)

// Convert to object for API submission
const groupsObject = mapToObject(editableGroups)
```

The utilities handle the complex data transformations needed for AI policy management interfaces, ensuring proper categorization and safe data manipulation.
