Utility functions for organizing and managing AI policy settings in the OpenFrame platform, specifically handling the transformation of policy rules into structured permission categories.

## Key Components

- **`slugify(value: string)`** - Converts strings to URL-friendly slugs by normalizing to lowercase and replacing special characters
- **`buildPolicyGroups(rules: PolicyRule[])`** - Primary function that transforms an array of policy rules into a structured map of permission categories grouped by policy groups
- **`clonePolicyGroups(groups: Map<string, PermissionCategory[]>)`** - Creates a deep clone of policy groups to prevent mutation of original data
- **`mapToObject<T>(entries: Map<string, T>)`** - Generic utility to convert Map instances to plain objects

## Usage Example

```typescript
import { buildPolicyGroups, clonePolicyGroups } from './ai-settings.utils'
import type { PolicyRule } from '../types/ai-policies'

// Transform policy rules into structured groups
const policyRules: PolicyRule[] = [
  {
    naturalKey: 'user-management',
    operation: 'Create User',
    tool: 'admin-panel',
    approvalLevel: 'manager',
    policyGroup: 'User Management',
    category: 'Account Operations',
    commandPattern: '/create-user'
  }
]

const policyGroups = buildPolicyGroups(policyRules)
// Result: Map with "User Management" -> [PermissionCategory with Account Operations]

// Clone for safe manipulation
const clonedGroups = clonePolicyGroups(policyGroups)

// Convert to plain object if needed
const groupsObject = mapToObject(policyGroups)
```

The utility handles automatic categorization, sorting, and includes fallbacks for missing policy groups ("General") and categories ("Other").
