Utility functions for organizing and managing AI policy settings in the OpenFrame frontend. Handles policy rule grouping, category organization, and data transformation for AI approval workflows.

## Key Components

- **`buildPolicyGroups`** - Transforms flat policy rules into hierarchical groups organized by policy group and category
- **`clonePolicyGroups`** - Creates deep copies of policy group structures for safe mutation
- **`mapToObject`** - Converts Map instances to plain JavaScript objects
- **`slugify`** - Internal helper that converts strings to URL-safe slugs for consistent IDs

## Usage Example

```typescript
import { buildPolicyGroups, clonePolicyGroups } from './ai-settings.utils'

// Transform policy rules into organized groups
const policyRules: PolicyRule[] = [
  {
    naturalKey: 'file-read',
    operation: 'Read Files',
    policyGroup: 'File Operations',
    category: 'File System',
    tool: 'file-manager',
    approvalLevel: 'auto',
    commandPattern: 'read file *'
  }
]

const organizedGroups = buildPolicyGroups(policyRules)
// Returns: Map<string, PermissionCategory[]> with hierarchical structure

// Clone for safe editing
const editableGroups = clonePolicyGroups(organizedGroups)

// Access specific policy group
const fileOperations = organizedGroups.get('File Operations')
// Returns array of PermissionCategory objects with nested policies
```

The utility automatically groups policies by their `policyGroup` and `category` fields, creates consistent IDs using slugification, and maintains proper typing for the OpenFrame permission system.
