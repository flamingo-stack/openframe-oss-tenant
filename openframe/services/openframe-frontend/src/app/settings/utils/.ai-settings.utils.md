Utility functions for organizing and managing AI policy settings, transforming raw policy rules into hierarchical permission categories and groups.

## Key Components

- **`buildPolicyGroups`** - Transforms an array of policy rules into a hierarchical Map structure organized by policy groups and categories
- **`clonePolicyGroups`** - Creates a deep clone of policy groups Map to prevent mutation of original data
- **`mapToObject`** - Converts a Map to a plain object for serialization or external API consumption
- **`slugify`** - Internal helper that converts strings to URL-safe slugs for consistent IDs

## Usage Example

```typescript
import { buildPolicyGroups, clonePolicyGroups, mapToObject } from './ai-settings.utils'
import type { PolicyRule } from '../types/ai-policies'

// Transform raw policy rules into organized groups
const policyRules: PolicyRule[] = [
  {
    naturalKey: 'file-access',
    operation: 'File Access',
    policyGroup: 'Security',
    category: 'File System',
    tool: 'filesystem',
    approvalLevel: 'MEDIUM',
    commandPattern: 'fs.*'
  }
]

// Build hierarchical structure
const policyGroups = buildPolicyGroups(policyRules)
// Result: Map with "Security" group containing "File System" category

// Clone for safe mutation
const clonedGroups = clonePolicyGroups(policyGroups)

// Convert to object for API payload
const groupsObject = mapToObject(policyGroups)
```

The utility handles grouping policies by their `policyGroup` and `category` fields, generates consistent IDs using slugification, and provides tools for safe data manipulation in React components managing AI permission settings.
