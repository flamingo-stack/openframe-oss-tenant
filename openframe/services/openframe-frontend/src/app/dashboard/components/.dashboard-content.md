A client-side React component that renders the main dashboard layout with conditional sections based on the application mode.

## Key Components

- **DashboardContent**: Default export component that orchestrates all dashboard sections
- **isSaasTenantMode**: Utility function to determine if chats should be displayed
- **OnboardingSection**: User onboarding interface
- **DevicesOverviewSection**: Device management overview
- **ChatsOverviewSection**: Chat functionality (SaaS mode only)
- **OrganizationsOverviewSection**: Organization management interface

## Usage Example

```typescript
import { Suspense } from 'react'
import DashboardContent from './dashboard-content'

// Typical usage with loading skeleton
function DashboardPage() {
  return (
    <div className="container mx-auto">
      <Suspense fallback={<DashboardSkeleton />}>
        <DashboardContent />
      </Suspense>
    </div>
  )
}

// The component automatically handles SaaS vs non-SaaS modes
// In SaaS mode: Shows Onboarding → Devices → Chats → Organizations
// In non-SaaS mode: Shows Onboarding → Devices → Organizations
```

The component is designed for dynamic importing with loading states, providing a clean separation between the dashboard shell and its content sections. The conditional rendering of `ChatsOverviewSection` allows the same component to work across different deployment modes.
