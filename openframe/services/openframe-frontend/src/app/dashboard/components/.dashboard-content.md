Main dashboard content component that renders all dashboard sections in a structured layout, with conditional chat features for SaaS tenants.

## Key Components

- **DashboardContent** - Default export client component that orchestrates dashboard sections
- **OnboardingSection** - User onboarding and setup guidance
- **DevicesOverviewSection** - Device management and monitoring overview
- **ChatsOverviewSection** - Chat functionality (SaaS tenant mode only)
- **OrganizationsOverviewSection** - Organization management interface
- **isSaasTenantMode** - Utility function to determine if chat features should be enabled

## Usage Example

```typescript
import { Suspense } from 'react'
import DashboardContent from './dashboard-content'
import DashboardSkeleton from './dashboard-skeleton'

export default function DashboardPage() {
  return (
    <div className="container mx-auto">
      <Suspense fallback={<DashboardSkeleton />}>
        <DashboardContent />
      </Suspense>
    </div>
  )
}
```

This component is designed for dynamic import with loading states, providing a clean separation between the dashboard shell and its content sections. The conditional chat section allows the same component to work across different Flamingo deployment modes (SaaS vs self-hosted).
