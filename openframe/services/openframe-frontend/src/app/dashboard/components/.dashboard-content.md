Main dashboard content component that renders all dashboard sections with conditional SaaS tenant functionality.

## Key Components

- **`DashboardContent`** - Default export component that renders the complete dashboard layout
- **Section Components** - Imports and renders modular dashboard sections:
  - `OnboardingSection` - User onboarding flow
  - `DevicesOverviewSection` - Device management overview
  - `ChatsOverviewSection` - Chat functionality (SaaS only)
  - `OrganizationsOverviewSection` - Organization management

## Usage Example

```typescript
import dynamic from 'next/dynamic'
import DashboardSkeleton from './dashboard-skeleton'

// Dynamic import with loading skeleton
const DashboardContent = dynamic(() => import('./dashboard-content'), {
  loading: () => <DashboardSkeleton />
})

export default function DashboardPage() {
  return (
    <div className="container mx-auto">
      <h1>Dashboard</h1>
      <DashboardContent />
    </div>
  )
}
```

The component uses `isSaasTenantMode()` to conditionally show the chats section only in SaaS tenant deployments. It's designed as a client component with `'use client'` directive and structured for dynamic importing with loading states.
