A client-side React component that renders the main dashboard content with conditional sections based on the application mode.

## Key Components

- **DashboardContent**: Default export component that orchestrates all dashboard sections
- **isSaasTenantMode**: Utility function to determine if the app is running in SaaS tenant mode
- **OnboardingSection**: Component for user onboarding flows
- **DevicesOverviewSection**: Device management and overview interface
- **ChatsOverviewSection**: Chat functionality (SaaS-only feature)
- **OrganizationsOverviewSection**: Organization management interface

## Usage Example

```typescript
import { Suspense } from 'react'
import DashboardContent from './dashboard-content'

// Used with dynamic import and loading skeleton
function DashboardPage() {
  return (
    <div className="container mx-auto">
      <h1>Dashboard</h1>
      <Suspense fallback={<DashboardSkeleton />}>
        <DashboardContent />
      </Suspense>
    </div>
  )
}

// The component conditionally shows sections based on app mode
// In SaaS mode: Onboarding + Devices + Chats + Organizations  
// In non-SaaS mode: Onboarding + Devices + Organizations
```

The component uses Tailwind CSS for styling with vertical spacing (`space-y-10`) and top padding (`pt-6`). It's designed to be dynamically imported to support loading states and code splitting.
