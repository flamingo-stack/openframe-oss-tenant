Dashboard content component that renders the main sections of the OpenFrame dashboard interface, with conditional SaaS tenant features. This component is extracted for dynamic importing with loading skeleton support.

## Key Components

- **DashboardContent** - Default export component that orchestrates all dashboard sections
- **Section Components** - Imports specialized overview sections for different dashboard areas
- **App Mode Detection** - Uses `isSaasTenantMode()` to conditionally render SaaS-specific features

## Usage Example

```typescript
// Dynamic import with loading skeleton
import dynamic from 'next/dynamic'
import { DashboardSkeleton } from '@/components/skeletons'

const DashboardContent = dynamic(
  () => import('@/components/dashboard/dashboard-content'),
  {
    loading: () => <DashboardSkeleton />,
    ssr: false
  }
)

export default function DashboardPage() {
  return (
    <div className="container mx-auto">
      <DashboardContent />
    </div>
  )
}
```

The component renders sections in a specific order: onboarding guidance, device management overview, chat functionality (SaaS only), and organization management. The conditional chat section demonstrates OpenFrame's multi-tenant architecture support.
