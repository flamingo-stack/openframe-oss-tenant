Dashboard content component that renders the main dashboard sections with conditional visibility based on deployment mode. This component is extracted for dynamic import with loading skeleton support.

## Key Components

- **DashboardContent** - Main export that conditionally renders dashboard sections
- **OnboardingSection** - Displays user onboarding guidance
- **DevicesOverviewSection** - Shows device management overview
- **ChatsOverviewSection** - Chat functionality (SaaS tenant mode only)
- **OrganizationsOverviewSection** - Organization management overview
- **isSaasTenantMode()** - Utility function to check deployment mode

## Usage Example

```typescript
import { Suspense } from 'react'
import DashboardContent from './dashboard-content'

// Dynamic import with loading skeleton
const DashboardPage = () => {
  return (
    <div className="container mx-auto">
      <Suspense fallback={<DashboardSkeleton />}>
        <DashboardContent />
      </Suspense>
    </div>
  )
}

// The component automatically handles SaaS vs self-hosted mode
// In SaaS mode: Shows Onboarding, Devices, Chats, Organizations
// In self-hosted mode: Shows Onboarding, Devices, Organizations (no Chats)
```

The component uses responsive spacing (`space-y-10 pt-6`) and conditionally includes the chats section only when running in SaaS tenant mode, making it adaptable across different Flamingo deployment configurations.
