A React component that serves as the main dashboard content container, dynamically rendering different overview sections based on the application mode (SaaS vs self-hosted).

## Key Components

- **DashboardContent** - Default export component that renders all dashboard sections
- **isSaasTenantMode()** - Utility function to determine if app is running in SaaS tenant mode
- **Overview Sections** - Four imported section components:
  - `OnboardingSection` - User onboarding flow
  - `DevicesOverviewSection` - Device management overview
  - `ChatsOverviewSection` - Chat functionality (SaaS only)
  - `OrganizationsOverviewSection` - Organization management

## Usage Example

This component is typically used as a dynamically imported dashboard page to enable loading skeletons:

```typescript
// In a dashboard page component
import dynamic from 'next/dynamic'

const DashboardContent = dynamic(() => import('./dashboard-content'), {
  loading: () => <DashboardSkeleton />
})

export default function DashboardPage() {
  return (
    <div className="container mx-auto">
      <h1>Dashboard</h1>
      <DashboardContent />
    </div>
  )
}
```

The component automatically shows/hides the chats section based on whether the application is running in SaaS tenant mode, making it adaptable for different deployment scenarios.
