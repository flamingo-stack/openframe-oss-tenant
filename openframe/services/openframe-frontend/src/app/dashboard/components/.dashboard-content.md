A client-side dashboard component that renders the main dashboard sections with conditional content based on the application mode.

## Key Components

- **DashboardContent**: Main dashboard component that dynamically imports and renders all dashboard sections
- **isSaasTenantMode**: Utility function to determine if the app is running in SaaS tenant mode
- **Dashboard Sections**:
  - `OnboardingSection` - User onboarding flow
  - `DevicesOverviewSection` - Device management overview
  - `ChatsOverviewSection` - Chat functionality (SaaS only)
  - `OrganizationsOverviewSection` - Organization management

## Usage Example

```typescript
import { Suspense } from 'react'
import DashboardContent from './dashboard-content'
import DashboardSkeleton from './dashboard-skeleton'

export default function DashboardPage() {
  return (
    <Suspense fallback={<DashboardSkeleton />}>
      <DashboardContent />
    </Suspense>
  )
}
```

The component uses dynamic imports with loading skeletons for better performance and conditionally shows the chats section only in SaaS tenant mode. All sections are vertically spaced using Tailwind's `space-y-10` utility.
