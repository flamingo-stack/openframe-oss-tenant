Main dashboard content component that renders overview sections for devices, organizations, chats, and onboarding based on the current tenant mode.

## Key Components

- **DashboardContent**: Default export component that conditionally renders dashboard sections
- **Section imports**: OnboardingSection, DevicesOverviewSection, ChatsOverviewSection, OrganizationsOverviewSection
- **App mode detection**: Uses `isSaasTenantMode()` to conditionally show SaaS-specific features

## Usage Example

```typescript
import { Suspense } from 'react'
import DashboardContent from './dashboard-content'
import DashboardSkeleton from './dashboard-skeleton'

export default function DashboardPage() {
  return (
    <Suspense fallback={<DashboardSkeleton />}>
      <DashboardContent />
    </Suspense>
  )
}
```

The component is designed for dynamic imports with loading states, allowing the dashboard to show a skeleton while content loads. It automatically adapts the UI based on tenant mode - SaaS tenants see chat functionality while other modes hide it. All sections are arranged in a vertical layout with consistent spacing.
