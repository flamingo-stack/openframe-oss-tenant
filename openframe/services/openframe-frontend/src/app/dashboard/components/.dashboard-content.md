Main dashboard content component that renders all dashboard sections based on the application's deployment mode (SaaS vs self-hosted).

## Key Components

- **`DashboardContent`** - Default export component that orchestrates the dashboard layout
- **Section Components** - Imports and renders modular dashboard sections:
  - `OnboardingSection` - User onboarding flow
  - `DevicesOverviewSection` - Device management overview
  - `ChatsOverviewSection` - Chat interface (SaaS tenant mode only)
  - `OrganizationsOverviewSection` - Organization management
- **`isSaasTenantMode()`** - Utility function to determine deployment mode

## Usage Example

```typescript
import { Suspense } from 'react'
import DashboardContent from './dashboard-content'
import DashboardSkeleton from './dashboard-skeleton'

function DashboardPage() {
  return (
    <Suspense fallback={<DashboardSkeleton />}>
      <DashboardContent />
    </Suspense>
  )
}
```

The component is designed for dynamic imports with loading states, using the `'use client'` directive for client-side rendering. It conditionally shows the chats section only in SaaS tenant mode, making it adaptable for different deployment scenarios in the Flamingo MSP platform.
