Main dashboard content component that renders all dashboard sections in a responsive layout, with conditional rendering based on application mode.

## Key Components

- **DashboardContent** - Default export component that orchestrates the dashboard layout
- **Conditional Rendering** - Shows ChatsOverviewSection only in SaaS tenant mode
- **Section Components** - Imports and renders OnboardingSection, DevicesOverviewSection, ChatsOverviewSection, and OrganizationsOverviewSection

## Usage Example

```typescript
// Typically used with dynamic import for loading optimization
import dynamic from 'next/dynamic'

const DashboardContent = dynamic(() => import('./dashboard-content'), {
  loading: () => <DashboardSkeleton />
})

export default function DashboardPage() {
  return (
    <div className="container mx-auto">
      <DashboardContent />
    </div>
  )
}
```

The component uses `isSaasTenantMode()` to conditionally show the chats section, making it adaptable for different deployment configurations. The sections are arranged in a vertical stack with consistent spacing using Tailwind's `space-y-10` utility.
