A React component that renders the main dashboard content with dynamic sections based on the application mode.

## Key Components

- **DashboardContent** - Default export component that orchestrates dashboard layout
- **Conditional rendering** - Shows/hides ChatsOverviewSection based on SaaS tenant mode
- **Section imports** - Modular dashboard sections for different data types

## Usage Example

```typescript
// Typically used with dynamic import for performance
import dynamic from 'next/dynamic'

const DashboardContent = dynamic(() => import('./dashboard-content'), {
  loading: () => <DashboardSkeleton />,
  ssr: false
})

export default function DashboardPage() {
  return (
    <div className="container mx-auto">
      <h1>Dashboard</h1>
      <DashboardContent />
    </div>
  )
}
```

The component renders four main sections in a vertical layout with spacing: onboarding guidance, device management overview, chat management (SaaS mode only), and organization management. The conditional chat section demonstrates how Flamingo adapts its interface based on deployment configuration.
