A client-side React component that renders the main dashboard content with conditional sections based on the application mode.

## Key Components

- **DashboardContent**: Default export component that orchestrates all dashboard sections
- **isSaasTenantMode**: Utility function to determine if the app is running in SaaS tenant mode
- **Section Components**: 
  - `OnboardingSection` - User onboarding workflow
  - `DevicesOverviewSection` - Device management overview
  - `ChatsOverviewSection` - Chat functionality (SaaS only)
  - `OrganizationsOverviewSection` - Organization management

## Usage Example

```typescript
import { Suspense } from 'react'
import DashboardContent from './dashboard-content'
import DashboardSkeleton from './dashboard-skeleton'

export default function DashboardPage() {
  return (
    <div className="container mx-auto p-6">
      <h1 className="text-2xl font-bold mb-6">Dashboard</h1>
      <Suspense fallback={<DashboardSkeleton />}>
        <DashboardContent />
      </Suspense>
    </div>
  )
}
```

The component uses conditional rendering to show the `ChatsOverviewSection` only in SaaS tenant mode, making it adaptable for different deployment scenarios. The sections are arranged vertically with consistent spacing using Tailwind CSS classes.
