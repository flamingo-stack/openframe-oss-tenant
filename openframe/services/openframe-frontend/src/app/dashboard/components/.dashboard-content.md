Main dashboard content component that orchestrates all dashboard sections with conditional SaaS tenant mode features.

## Key Components

- **DashboardContent** - Client-side component that renders dashboard sections in a structured layout
- **Section Imports** - Imports for OnboardingSection, DevicesOverviewSection, ChatsOverviewSection, and OrganizationsOverviewSection
- **isSaasTenantMode** - App mode utility for conditional feature rendering

## Usage Example

```typescript
import dynamic from 'next/dynamic'
import DashboardContent from './dashboard-content'

// Used with dynamic import for performance
const DynamicDashboard = dynamic(() => import('./dashboard-content'), {
  loading: () => <DashboardSkeleton />
})

export default function DashboardPage() {
  return (
    <div className="container mx-auto">
      <h1 className="text-2xl font-bold mb-6">Dashboard</h1>
      <DashboardContent />
    </div>
  )
}
```

The component uses conditional rendering to show the ChatsOverviewSection only in SaaS tenant mode, making it adaptable for different deployment configurations. All sections are wrapped in a responsive layout with consistent spacing.
