A client-side React component that renders the main dashboard content with conditional sections based on the application mode.

## Key Components

- **`DashboardContent`** - Main dashboard component that orchestrates all overview sections
- **`isSaasTenantMode`** - Utility function to determine if the app is running in SaaS tenant mode
- **Section Components** - Individual overview sections for different dashboard areas:
  - `OnboardingSection` - User onboarding guidance
  - `DevicesOverviewSection` - Device management overview
  - `ChatsOverviewSection` - Chat functionality (SaaS only)
  - `OrganizationsOverviewSection` - Organization management overview

## Usage Example

```typescript
import { Suspense } from 'react'
import DashboardContent from './dashboard-content'

// Typically used with dynamic import for code splitting
export default function DashboardPage() {
  return (
    <div className="dashboard-container">
      <Suspense fallback={<DashboardSkeleton />}>
        <DashboardContent />
      </Suspense>
    </div>
  )
}
```

The component conditionally renders the chats section only in SaaS tenant mode, making it adaptable for different deployment configurations. It's designed to be dynamically imported to enable code splitting and loading states for better performance.
