A client-side React component that renders the main dashboard layout with conditional sections based on the application mode.

## Key Components

- **DashboardContent** - Default export component that orchestrates dashboard sections
- **OnboardingSection** - User onboarding interface component
- **DevicesOverviewSection** - Device management overview display
- **ChatsOverviewSection** - Chat functionality overview (SaaS mode only)
- **OrganizationsOverviewSection** - Organization management interface
- **isSaasTenantMode** - Utility function to determine if app is running in SaaS tenant mode

## Usage Example

```typescript
import { Suspense } from 'react'
import DashboardContent from './dashboard-content'

// Use with dynamic import for code splitting
const Dashboard = () => {
  return (
    <Suspense fallback={<div>Loading dashboard...</div>}>
      <DashboardContent />
    </Suspense>
  )
}

// Or import directly
export default function DashboardPage() {
  return (
    <div className="container mx-auto">
      <h1>MSP Dashboard</h1>
      <DashboardContent />
    </div>
  )
}
```

The component conditionally renders the chat overview section only in SaaS tenant mode, making it suitable for both self-hosted and SaaS deployments of the Flamingo MSP platform.
