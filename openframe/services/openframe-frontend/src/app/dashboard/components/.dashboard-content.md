Dashboard content component that renders the main dashboard sections with conditional SaaS-specific functionality. This component is extracted for dynamic importing with loading skeleton support in the OpenFrame MSP platform.

## Key Components

- **DashboardContent** - Main component that orchestrates dashboard layout
- **isSaasTenantMode** - Utility function to check if running in SaaS mode
- **OnboardingSection** - User onboarding guidance section
- **DevicesOverviewSection** - Device management overview widget
- **ChatsOverviewSection** - Chat management section (SaaS-only)
- **OrganizationsOverviewSection** - Organization management overview

## Usage Example

```typescript
import { Suspense } from 'react'
import dynamic from 'next/dynamic'

// Dynamic import for code splitting
const DashboardContent = dynamic(() => import('./dashboard-content'), {
  ssr: false,
  loading: () => <DashboardSkeleton />
})

export function DashboardPage() {
  return (
    <div className="container mx-auto px-4">
      <h1>OpenFrame Dashboard</h1>
      <Suspense fallback={<DashboardSkeleton />}>
        <DashboardContent />
      </Suspense>
    </div>
  )
}
```

The component automatically detects the deployment mode and conditionally renders the chats section only in SaaS tenant environments, providing a consistent experience across different OpenFrame deployment types.
