Main dashboard content component that renders all dashboard sections with conditional SaaS-mode features. This component is extracted for dynamic importing with loading skeleton support.

## Key Components

- **DashboardContent**: Main component that orchestrates dashboard layout
- **OnboardingSection**: User onboarding and setup guidance
- **DevicesOverviewSection**: Connected devices summary and status
- **ChatsOverviewSection**: Chat functionality (SaaS mode only)
- **OrganizationsOverviewSection**: Organization management and overview
- **isSaasTenantMode**: Utility function to determine if SaaS features should be displayed

## Usage Example

```typescript
import { Suspense } from 'react'
import dynamic from 'next/dynamic'
import DashboardSkeleton from './dashboard-skeleton'

// Dynamically import dashboard content for better performance
const DashboardContent = dynamic(() => import('./dashboard-content'), {
  loading: () => <DashboardSkeleton />
})

export default function Dashboard() {
  return (
    <div className="container mx-auto px-4">
      <h1 className="text-2xl font-bold mb-6">MSP Dashboard</h1>
      <Suspense fallback={<DashboardSkeleton />}>
        <DashboardContent />
      </Suspense>
    </div>
  )
}
```

The component uses vertical spacing (`space-y-10`) and conditionally renders the chats section based on the current deployment mode, making it suitable for both self-hosted and SaaS environments.
