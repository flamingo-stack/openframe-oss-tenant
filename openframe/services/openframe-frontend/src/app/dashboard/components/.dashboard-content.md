Main dashboard content component that dynamically imports all dashboard sections based on application mode, optimized for loading states and tenant-specific features.

## Key Components

- **`DashboardContent`** - Default export component that renders the complete dashboard layout
- **Dynamic imports** - `ChatsOverviewSection`, `DevicesOverviewSection`, `OnboardingSection`, `OrganizationsOverviewSection`
- **Mode detection** - Uses `isSaasTenantMode()` to conditionally show SaaS-specific features

## Usage Example

```typescript
import { Suspense } from 'react'
import DashboardContent from './dashboard-content'
import DashboardSkeleton from './dashboard-skeleton'

// In your dashboard page
export default function DashboardPage() {
  return (
    <Suspense fallback={<DashboardSkeleton />}>
      <DashboardContent />
    </Suspense>
  )
}
```

The component is designed to be dynamically imported with a loading skeleton, providing a smooth user experience while dashboard sections load. The SaaS chat functionality is conditionally rendered based on the tenant mode configuration, making it adaptable for different deployment scenarios.
