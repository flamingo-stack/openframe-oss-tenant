Main dashboard content component that conditionally renders different overview sections based on the application mode. This component is extracted as a separate module to enable dynamic imports with loading skeletons.

## Key Components

- **`DashboardContent`** - Default export component that orchestrates dashboard sections
- **`isSaasTenantMode()`** - Utility function to determine if chats section should be displayed
- **Section Components**:
  - `OnboardingSection` - User onboarding interface
  - `DevicesOverviewSection` - Device management overview
  - `ChatsOverviewSection` - Chat functionality (SaaS mode only)
  - `OrganizationsOverviewSection` - Organization management

## Usage Example

```typescript
// Dynamic import with loading state
import { Suspense } from 'react'
import dynamic from 'next/dynamic'

const DashboardContent = dynamic(() => import('./dashboard-content'), {
  loading: () => <DashboardSkeleton />
})

export default function DashboardPage() {
  return (
    <Suspense fallback={<DashboardSkeleton />}>
      <DashboardContent />
    </Suspense>
  )
}
```

The component uses conditional rendering to show the chats section only in SaaS tenant mode, making it adaptable to different deployment configurations. All sections are wrapped in a container with consistent spacing using Tailwind's `space-y-10` utility class.
