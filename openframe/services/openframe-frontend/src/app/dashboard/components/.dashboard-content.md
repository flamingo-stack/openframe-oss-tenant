Main dashboard content component that dynamically renders overview sections based on application mode, designed for lazy loading with skeleton states.

## Key Components

- **DashboardContent**: Default export component that orchestrates dashboard layout
- **OnboardingSection**: User onboarding guidance component
- **DevicesOverviewSection**: Device management overview display
- **ChatsOverviewSection**: Chat functionality overview (SaaS tenant mode only)
- **OrganizationsOverviewSection**: Organization management overview
- **isSaasTenantMode**: Utility function to determine application deployment mode

## Usage Example

```typescript
import { Suspense } from 'react'
import DashboardContent from './dashboard-content'
import DashboardSkeleton from './dashboard-skeleton'

export default function DashboardPage() {
  return (
    <div className="container mx-auto">
      <h1 className="text-2xl font-bold mb-6">Dashboard</h1>
      <Suspense fallback={<DashboardSkeleton />}>
        <DashboardContent />
      </Suspense>
    </div>
  )
}
```

The component conditionally shows the chats section only in SaaS tenant mode, making it adaptable for different Flamingo deployment configurations. The `'use client'` directive enables client-side rendering for dynamic mode detection, while the extracted structure supports code splitting and loading states.
