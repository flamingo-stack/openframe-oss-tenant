Main dashboard content component that renders different overview sections based on the application mode, extracted for dynamic loading with skeleton support.

## Key Components

- **`DashboardContent`** - Default export React component that orchestrates the dashboard layout
- **`isSaasTenantMode`** - Utility function to determine if chats section should be displayed
- **Section Components** - Imported overview sections for onboarding, devices, chats, and organizations

## Usage Example

```typescript
import { lazy, Suspense } from 'react'
import DashboardSkeleton from './dashboard-skeleton'

// Dynamic import for code splitting
const DashboardContent = lazy(() => import('./dashboard-content'))

export default function DashboardPage() {
  return (
    <Suspense fallback={<DashboardSkeleton />}>
      <DashboardContent />
    </Suspense>
  )
}
```

The component conditionally renders the `ChatsOverviewSection` only in SaaS tenant mode, while always showing onboarding, devices, and organizations sections. The extracted structure enables lazy loading with proper loading states for better performance and user experience.
