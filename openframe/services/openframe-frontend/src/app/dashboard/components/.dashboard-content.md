A React component that renders the main dashboard content with conditional sections based on the application mode.

## Key Components

- **DashboardContent** - Main component that orchestrates dashboard sections
- **OnboardingSection** - User onboarding guidance section
- **DevicesOverviewSection** - Device management overview
- **ChatsOverviewSection** - Chat functionality (SaaS mode only)
- **OrganizationsOverviewSection** - Organization management overview
- **isSaasTenantMode** - Utility function to check application mode

## Usage Example

```typescript
import DashboardContent from './dashboard-content'

// In a dashboard page component
export default function DashboardPage() {
  return (
    <div className="container mx-auto">
      <h1 className="text-2xl font-bold mb-6">Dashboard</h1>
      <DashboardContent />
    </div>
  )
}

// With loading state (recommended for dynamic imports)
import { Suspense } from 'react'
import { Skeleton } from '@/components/ui/skeleton'

export default function DashboardPage() {
  return (
    <Suspense fallback={<Skeleton className="h-96 w-full" />}>
      <DashboardContent />
    </Suspense>
  )
}
```

The component uses client-side rendering and conditionally displays the chats section only in SaaS tenant mode. Each section is vertically spaced with consistent padding for a clean dashboard layout.
