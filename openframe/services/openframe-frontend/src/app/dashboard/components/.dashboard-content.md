A React client component that renders the main dashboard content with conditional sections based on the application mode (SaaS vs self-hosted).

## Key Components

- **`DashboardContent`** - Default export component that orchestrates all dashboard sections
- **`isSaasTenantMode()`** - Utility function to determine if the app is running in SaaS tenant mode
- **Section Components**:
  - `OnboardingSection` - User onboarding guidance
  - `DevicesOverviewSection` - Device management overview
  - `ChatsOverviewSection` - Chat functionality (SaaS only)
  - `OrganizationsOverviewSection` - Organization management

## Usage Example

```typescript
import { Suspense } from 'react'
import DashboardContent from './dashboard-content'
import DashboardSkeleton from './dashboard-skeleton'

export default function DashboardPage() {
  return (
    <div className="container mx-auto px-4">
      <h1 className="text-3xl font-bold mb-6">Dashboard</h1>
      <Suspense fallback={<DashboardSkeleton />}>
        <DashboardContent />
      </Suspense>
    </div>
  )
}
```

The component is designed for dynamic import with loading skeletons, providing a smooth user experience while dashboard sections load. The conditional rendering of `ChatsOverviewSection` ensures SaaS-specific features are only displayed in the appropriate deployment mode.
