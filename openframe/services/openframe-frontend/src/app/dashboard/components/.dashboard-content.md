Main dashboard content component that renders different overview sections based on the application's tenant mode configuration.

## Key Components

- **DashboardContent**: Default export component that conditionally renders dashboard sections
- **Section Components**: Imports and renders `OnboardingSection`, `DevicesOverviewSection`, `ChatsOverviewSection`, and `OrganizationsOverviewSection`
- **Conditional Rendering**: Uses `isSaasTenantMode()` to show/hide SaaS-specific features like chats

## Usage Example

```typescript
import { Suspense } from 'react'
import DashboardContent from './dashboard-content'

export default function DashboardPage() {
  return (
    <Suspense fallback={<DashboardSkeleton />}>
      <DashboardContent />
    </Suspense>
  )
}

// Component is designed for dynamic import with loading skeleton
const DashboardContent = dynamic(() => import('./dashboard-content'), {
  loading: () => <DashboardSkeleton />
})
```

The component uses client-side rendering (`'use client'`) and applies conditional logic to display different sections based on the tenant mode. The chats section only appears in SaaS tenant mode, while other sections (onboarding, devices, organizations) are always displayed. The layout uses Tailwind's `space-y-10 pt-6` classes for consistent vertical spacing.
