A client-side React component that renders the main dashboard layout with conditional sections based on the app deployment mode.

## Key Components

- **DashboardContent** - Main dashboard component that orchestrates all dashboard sections
- **isSaasTenantMode()** - Utility function to determine if the app is running in SaaS tenant mode
- **OnboardingSection** - User onboarding guidance and setup
- **DevicesOverviewSection** - Device management and monitoring overview
- **ChatsOverviewSection** - Chat/communication features (SaaS-only)
- **OrganizationsOverviewSection** - Organization management interface

## Usage Example

This component is designed to be dynamically imported with a loading skeleton for better performance:

```typescript
import dynamic from 'next/dynamic'

const DashboardContent = dynamic(() => import('./dashboard-content'), {
  loading: () => <DashboardSkeleton />,
  ssr: false
})

export default function DashboardPage() {
  return (
    <div className="container mx-auto">
      <DashboardContent />
    </div>
  )
}
```

The component automatically adapts its layout based on the deployment mode - SaaS tenants get additional chat functionality while self-hosted instances focus on core MSP features. All sections are vertically stacked with consistent spacing for a clean dashboard layout.
