Main dashboard content component that dynamically renders different overview sections based on the application's deployment mode.

## Key Components

- **DashboardContent** - Default export component that orchestrates all dashboard sections
- **Section Components** - Imports and conditionally renders:
  - `OnboardingSection` - User onboarding interface
  - `DevicesOverviewSection` - Device management overview
  - `ChatsOverviewSection` - Chat functionality (SaaS mode only)
  - `OrganizationsOverviewSection` - Organization management
- **Mode Detection** - Uses `isSaasTenantMode()` to conditionally show SaaS-specific features

## Usage Example

```typescript
import DashboardContent from './dashboard-content'

// Used with dynamic import for loading optimization
function DashboardPage() {
  return (
    <div>
      <h1>MSP Dashboard</h1>
      <DashboardContent />
    </div>
  )
}

// Or with dynamic loading
const DashboardContent = dynamic(() => import('./dashboard-content'), {
  loading: () => <DashboardSkeleton />
})
```

The component is designed for dynamic imports to enable code splitting and loading states. The SaaS tenant mode detection ensures that chat features are only available in multi-tenant deployments, while core device and organization management remains available across all deployment modes.
