A React client component that renders the main dashboard content with conditional sections based on tenant mode configuration.

## Key Components

- **`DashboardContent`** - Default exported component that orchestrates all dashboard sections
- **`isSaasTenantMode()`** - Utility function to determine if SaaS features should be displayed
- **Section Components** - Modular dashboard sections:
  - `OnboardingSection` - User onboarding interface
  - `DevicesOverviewSection` - Device management overview
  - `ChatsOverviewSection` - Chat functionality (SaaS only)
  - `OrganizationsOverviewSection` - Organization management

## Usage Example

```typescript
import { Suspense } from 'react'
import DashboardContent from './dashboard-content'
import DashboardSkeleton from './dashboard-skeleton'

export default function DashboardPage() {
  return (
    <div className="container mx-auto">
      <Suspense fallback={<DashboardSkeleton />}>
        <DashboardContent />
      </Suspense>
    </div>
  )
}
```

The component uses conditional rendering to show chat features only in SaaS tenant mode, making it adaptable for different deployment configurations. Each section is imported as a separate component for better code organization and potential lazy loading.
