Client-side dashboard component that conditionally renders different overview sections based on the application mode, optimized for dynamic imports with loading states.

## Key Components

- **DashboardContent**: Main dashboard component that orchestrates multiple overview sections
- **Conditional Rendering**: Shows/hides ChatsOverviewSection based on SaaS tenant mode
- **Section Components**: 
  - `OnboardingSection` - User onboarding interface
  - `DevicesOverviewSection` - Device management overview
  - `ChatsOverviewSection` - Chat functionality (SaaS only)
  - `OrganizationsOverviewSection` - Organization management

## Usage Example

```typescript
import { Suspense } from 'react'
import dynamic from 'next/dynamic'

// Dynamic import with loading skeleton
const DashboardContent = dynamic(() => import('./dashboard-content'), {
  loading: () => <DashboardSkeleton />
})

export default function DashboardPage() {
  return (
    <Suspense fallback={<DashboardSkeleton />}>
      <DashboardContent />
    </Suspense>
  )
}
```

The component uses `isSaasTenantMode()` to determine feature availability, ensuring the chat functionality only appears in SaaS environments. The `'use client'` directive indicates this runs on the client side, making it suitable for dynamic imports to reduce initial bundle size.
