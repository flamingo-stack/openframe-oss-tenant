A client-side dashboard component that renders the main dashboard content with dynamic sections based on app mode configuration.

## Key Components

- **`DashboardContent`** - Main dashboard component that orchestrates overview sections
- **`isSaasTenantMode()`** - Utility function to check if app is in SaaS tenant mode
- **Section Components**:
  - `OnboardingSection` - User onboarding guidance
  - `DevicesOverviewSection` - Device management overview
  - `ChatsOverviewSection` - Chat functionality (SaaS only)
  - `OrganizationsOverviewSection` - Organization management

## Usage Example

```typescript
import DashboardContent from './dashboard-content'

export default function DashboardPage() {
  return (
    <div className="container">
      <h1>Dashboard</h1>
      <DashboardContent />
    </div>
  )
}
```

The component conditionally renders the chats section only in SaaS tenant mode, making it suitable for both multi-tenant SaaS and self-hosted deployments. It's designed for dynamic import with loading skeleton support, providing a clean separation of concerns for the dashboard layout.
