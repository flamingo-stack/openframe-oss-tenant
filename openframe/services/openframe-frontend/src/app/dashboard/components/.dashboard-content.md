Dashboard content component that orchestrates and renders the main sections of the OpenFrame dashboard interface. It conditionally displays different overview sections based on the application's deployment mode.

## Key Components

- **DashboardContent**: Main component that renders dashboard sections in a structured layout
- **OnboardingSection**: User onboarding interface and setup guidance
- **DevicesOverviewSection**: Device management and monitoring overview
- **ChatsOverviewSection**: AI chat interface (SaaS tenant mode only)
- **OrganizationsOverviewSection**: Multi-tenant organization management

## Usage Example

This component is typically used as a dynamic import to enable loading states:

```typescript
import dynamic from 'next/dynamic'

const DashboardContent = dynamic(
  () => import('./dashboard-content'), 
  { 
    loading: () => <DashboardSkeleton />,
    ssr: false 
  }
)

export default function DashboardPage() {
  return (
    <div className="container mx-auto">
      <DashboardContent />
    </div>
  )
}
```

The component automatically detects the deployment mode and shows chat functionality only in SaaS tenant environments, making it adaptable for both self-hosted and cloud deployments of the OpenFrame platform.
