A client-side dashboard component that conditionally renders overview sections based on the application mode, optimized for dynamic loading with skeleton states.

## Key Components

- **DashboardContent** - Main dashboard component that orchestrates multiple overview sections
- **Conditional Rendering** - SaaS-specific chat section display logic using `isSaasTenantMode()`
- **Section Components** - Imports for onboarding, devices, chats, and organizations overview sections

## Usage Example

```typescript
import { Suspense } from 'react'
import DashboardContent from './dashboard-content'
import DashboardSkeleton from './dashboard-skeleton'

function DashboardPage() {
  return (
    <div className="container mx-auto px-4">
      <h1 className="text-2xl font-bold mb-6">Dashboard</h1>
      <Suspense fallback={<DashboardSkeleton />}>
        <DashboardContent />
      </Suspense>
    </div>
  )
}

// The component automatically handles SaaS vs non-SaaS mode
// In SaaS mode: Shows Onboarding → Devices → Chats → Organizations
// In non-SaaS mode: Shows Onboarding → Devices → Organizations
```

The component uses a vertical spacing layout (`space-y-10`) and conditionally includes the chats overview section only when running in SaaS tenant mode, making it adaptable to different deployment configurations.
