A React component that renders the main dashboard content with different sections based on the application mode, designed for dynamic import with loading skeleton support.

## Key Components

- **DashboardContent** - Main dashboard component that conditionally renders sections
- **OnboardingSection** - User onboarding guidance and setup
- **DevicesOverviewSection** - Device management and monitoring overview
- **ChatsOverviewSection** - Chat functionality overview (SaaS mode only)
- **OrganizationsOverviewSection** - Organization management interface
- **isSaasTenantMode()** - Utility function to determine if app is in SaaS tenant mode

## Usage Example

```typescript
import dynamic from 'next/dynamic'
import DashboardContent from './dashboard-content'

// Dynamic import with loading skeleton
const DashboardContent = dynamic(() => import('./dashboard-content'), {
  loading: () => <DashboardSkeleton />,
  ssr: false
})

export default function DashboardPage() {
  return (
    <div className="container mx-auto">
      <h1>Dashboard</h1>
      <DashboardContent />
    </div>
  )
}
```

The component uses conditional rendering to show chat functionality only in SaaS tenant mode, making it adaptable to different deployment configurations. All sections are vertically spaced with consistent padding for optimal visual hierarchy.
