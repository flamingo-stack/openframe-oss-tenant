Dashboard content component that renders the main dashboard sections with conditional SaaS-specific features.

## Key Components

- **DashboardContent** - Main component that orchestrates dashboard sections based on app mode
- **OnboardingSection** - User guidance and setup component
- **DevicesOverviewSection** - Device management overview
- **ChatsOverviewSection** - AI chat interface (SaaS mode only)
- **OrganizationsOverviewSection** - Multi-tenant organization management
- **isSaasTenantMode** - Utility function to determine if SaaS features should be enabled

## Usage Example

```typescript
import { Suspense } from 'react'
import DashboardContent from './dashboard-content'
import DashboardSkeleton from './dashboard-skeleton'

// Lazy load dashboard with loading state
export default function DashboardPage() {
  return (
    <div className="container mx-auto px-4">
      <h1 className="text-2xl font-bold mb-6">OpenFrame Dashboard</h1>
      <Suspense fallback={<DashboardSkeleton />}>
        <DashboardContent />
      </Suspense>
    </div>
  )
}
```

The component is designed for dynamic imports to enable code splitting and loading states, improving initial page load performance. It conditionally renders the chats section only in SaaS tenant mode, making it suitable for both self-hosted and cloud deployments.
