Main dashboard content component that renders all dashboard sections in a responsive layout with conditional chat functionality based on deployment mode.

## Key Components

- **DashboardContent**: Default export component that orchestrates the complete dashboard layout
- **isSaasTenantMode()**: Utility function to detect SaaS deployment mode for conditional rendering
- **OnboardingSection**: User onboarding and setup guidance component
- **DevicesOverviewSection**: Device monitoring and management overview
- **ChatsOverviewSection**: Chat/communication features (SaaS tenant mode only)
- **OrganizationsOverviewSection**: Organization management and overview

## Usage Example

```typescript
import { Suspense } from 'react'
import DashboardContent from './dashboard-content'
import DashboardSkeleton from './dashboard-skeleton'

// Dynamic import with loading state
function DashboardPage() {
  return (
    <div className="container mx-auto p-4">
      <h1 className="text-2xl font-bold mb-6">OpenFrame Dashboard</h1>
      <Suspense fallback={<DashboardSkeleton />}>
        <DashboardContent />
      </Suspense>
    </div>
  )
}
```

The component uses client-side rendering and applies conditional logic to show chat functionality only in SaaS tenant deployments. The sections are arranged with consistent spacing (`space-y-10`) and include top padding for proper layout alignment with the main dashboard container.
