Main dashboard content component that renders all dashboard sections with conditional SaaS tenant support for chat features.

## Key Components

- **DashboardContent**: Main component that orchestrates dashboard sections
- **OnboardingSection**: User onboarding guidance and setup
- **DevicesOverviewSection**: Device management overview
- **ChatsOverviewSection**: Chat interface overview (SaaS tenants only)
- **OrganizationsOverviewSection**: Organization management overview
- **isSaasTenantMode()**: Utility to determine if SaaS tenant features should be enabled

## Usage Example

This component is designed for dynamic import with loading skeletons in dashboard pages:

```typescript
import { lazy, Suspense } from 'react'

const DashboardContent = lazy(() => import('./dashboard-content'))

export default function DashboardPage() {
  return (
    <Suspense fallback={<DashboardSkeleton />}>
      <DashboardContent />
    </Suspense>
  )
}
```

The component automatically adapts its layout based on the deployment mode - SaaS tenants see chat functionality while standard deployments show core MSP tools only. All sections are rendered in a vertical layout with consistent spacing.
