React component that displays an overview of organizations with their device statistics in a responsive grid layout. It provides navigation to filtered device views and includes comprehensive loading states.

## Key Components

- **OrganizationsSkeleton** - Loading placeholder component that mimics the grid structure with skeleton cards
- **OrganizationsOverviewSection** - Main component that renders organization cards with device metrics (online/offline counts and percentages)
- **handleOrgClick** - Navigation handler that routes to filtered device view for a specific organization
- **organizationRows** - Memoized rendering logic that handles loading, error, and data states

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

function DashboardPage() {
  return (
    <div className="dashboard-container">
      <OrganizationsOverviewSection />
    </div>
  )
}

// The component automatically:
// - Fetches organization data with device counts
// - Shows loading skeletons during data fetch
// - Renders clickable organization cards with device metrics
// - Provides navigation to filtered device views
// - Displays total organization count
```

The component uses a custom hook `useOrganizationsOverview` to fetch data and renders each organization in a three-column grid: organization info, online devices, and offline devices. Each card is clickable and navigates to the devices page with appropriate filters applied.
