A React component that displays an overview of organizations with their device statistics in a dashboard grid layout. This component renders organization cards alongside active and inactive device metrics with loading states and navigation functionality.

## Key Components

- **OrganizationsSkeleton**: Loading skeleton component that renders placeholder cards during data fetching
- **OrganizationsOverviewSection**: Main component that displays organizations in a responsive grid with device statistics
- **useOrganizationsOverview**: Custom hook for fetching organization data
- **OrganizationCard**: Reusable card component for displaying organization details
- **DashboardInfoCard**: Card component for showing device metrics with progress indicators

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

function Dashboard() {
  return (
    <div className="dashboard">
      <OrganizationsOverviewSection />
    </div>
  )
}

// The component automatically handles:
// - Loading states with skeleton placeholders
// - Error handling with error messages
// - Navigation to filtered device views
// - Responsive grid layout (1 column mobile, 2 tablet, 3 desktop)
```

The component features a responsive three-column layout showing organization details, online devices with green progress bars, and offline devices. Each card is clickable and navigates to filtered device views. Loading states are handled with skeleton components, and the total organization count is displayed at the top.
