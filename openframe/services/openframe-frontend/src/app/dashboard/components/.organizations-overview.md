A React client component that displays an overview of organizations with their device statistics in a responsive grid layout, featuring loading skeletons and navigation to filtered device views.

## Key Components

- **`OrganizationsOverviewSection`** - Main component that renders the organizations overview dashboard
- **`OrganizationsSkeleton`** - Loading state component that displays placeholder cards while data is fetching
- **Grid Layout** - Responsive 3-column layout (organization info, active devices, inactive devices)
- **Navigation Integration** - Clickable cards that route to filtered device pages

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

// Display organizations overview in a dashboard
function Dashboard() {
  return (
    <div className="container mx-auto p-6">
      <OrganizationsOverviewSection />
    </div>
  )
}

// The component automatically:
// - Fetches organization data using useOrganizationsOverview hook
// - Shows loading skeletons while data loads
// - Displays error states if data fetching fails
// - Renders clickable organization and device statistics cards
// - Navigates to filtered device views when cards are clicked
```

The component leverages reusable UI components from the OpenFrame frontend core library (`OrganizationCard`, `DashboardInfoCard`, `Skeleton`) and provides a complete dashboard experience with proper loading states, error handling, and interactive navigation to detailed device views filtered by organization and status.
