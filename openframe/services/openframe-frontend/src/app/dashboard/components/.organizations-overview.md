A React component that renders an overview section displaying organizations with their device statistics in a responsive card-based layout, including loading states and error handling.

## Key Components

- **OrganizationsSkeleton**: Loading skeleton component that displays placeholder cards while data is being fetched
- **OrganizationsOverviewSection**: Main component that renders organization cards alongside active/inactive device statistics
- **handleOrgClick**: Navigation handler that routes to the devices page filtered by organization
- **organizationRows**: Memoized rendering logic for organization data with responsive grid layout

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

export default function Dashboard() {
  return (
    <div className="container mx-auto p-6">
      <OrganizationsOverviewSection />
    </div>
  )
}

// The component automatically handles:
// - Loading states with skeleton placeholders
// - Error display for failed data fetching
// - Click navigation to filtered device views
// - Responsive layout (1 column mobile, 2 tablet, 3 desktop)
```

The component uses the `useOrganizationsOverview` hook to fetch data and displays each organization in a three-column grid: organization info, online devices, and offline devices. Each card is clickable and navigates to relevant filtered views. The layout is fully responsive and includes comprehensive loading and error states.
