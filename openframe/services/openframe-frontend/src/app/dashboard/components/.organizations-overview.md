A React component that displays a paginated overview of organizations with their device statistics in a responsive grid layout.

## Key Components

- **OrganizationsSkeleton** - Loading state component that renders placeholder cards while data is fetching
- **OrganizationsOverviewSection** - Main component that displays organizations with their active/inactive device counts
- **handleOrgClick** - Navigation callback that routes to the devices page filtered by organization
- **organizationRows** - Memoized rendering logic that displays organization cards with device statistics

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

export default function DashboardPage() {
  return (
    <div className="p-6">
      <OrganizationsOverviewSection />
    </div>
  )
}
```

The component uses the `useOrganizationsOverview` hook to fetch data and renders each organization in a three-column grid layout: organization info, online devices count with percentage, and offline devices count with percentage. Each card is clickable and navigates to filtered device views. The component includes comprehensive loading states, error handling, and responsive design that adapts from single column on mobile to three columns on desktop.
