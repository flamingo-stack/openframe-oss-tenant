A React client component that displays an overview section of organizations with their device statistics. The component renders organization cards alongside their active/inactive device counts in a responsive grid layout with loading states and error handling.

## Key Components

**Main Export:**
- `OrganizationsOverviewSection` - Primary component that renders the organizations overview with device statistics

**Helper Components:**
- `OrganizationsSkeleton` - Loading skeleton component that mimics the final layout structure

**External Dependencies:**
- `useOrganizationsOverview` - Custom hook for fetching organization data
- `DashboardInfoCard` - Card component for displaying device statistics
- `OrganizationCard` - Card component for organization display
- `getFullImageUrl` - Utility for processing image URLs

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

// Basic usage in a dashboard page
export default function DashboardPage() {
  return (
    <div className="container mx-auto p-6">
      <OrganizationsOverviewSection />
    </div>
  )
}

// The component automatically handles:
// - Loading states with skeleton placeholders
// - Error states with error messages
// - Navigation to filtered device views
// - Responsive grid layout (1 col mobile, 2 col tablet, 3 col desktop)
```

The component fetches up to 100 organizations and displays each with three cards: the organization info, online devices count with percentage, and offline devices count with percentage. Cards are clickable and navigate to filtered device views based on organization and device status.
