A React component that displays an overview of organizations with their device statistics in a responsive grid layout, featuring loading states and navigation to filtered device views.

## Key Components

- **OrganizationsSkeleton** - Loading skeleton component that renders placeholder cards during data fetching
- **OrganizationsOverviewSection** - Main component that displays organization cards with active/inactive device metrics
- **useOrganizationsOverview** - Custom hook for fetching organization data (imported from hooks)
- **handleOrgClick** - Navigation handler that routes to devices page filtered by organization

## Usage Example

```typescript
import { OrganizationsOverviewSection } from '@/components/organizations-overview'

export function DashboardPage() {
  return (
    <div className="container mx-auto p-6">
      <OrganizationsOverviewSection />
    </div>
  )
}
```

The component renders each organization as a three-column grid showing:
1. Organization details (name, image, total devices)
2. Online devices count with percentage and progress bar
3. Offline devices count with percentage and progress bar

Each card is clickable and navigates to the devices page with appropriate filters applied. The component includes comprehensive loading states, error handling, and responsive design that adapts from single column on mobile to three columns on desktop.
