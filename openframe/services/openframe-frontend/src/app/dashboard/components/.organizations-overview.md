A React component that displays an overview dashboard of organizations with device statistics including active/inactive counts and navigation capabilities.

## Key Components

- **OrganizationsSkeleton**: Loading skeleton component that displays placeholder content during data fetching
- **OrganizationsOverviewSection**: Main component that renders organization cards with device metrics, statistics, and interactive navigation
- **useOrganizationsOverview**: Custom hook for fetching organizations data with loading and error states
- **OrganizationCard**: Displays organization information with clickable navigation to device listings
- **DashboardInfoCard**: Shows device statistics (online/offline) with progress bars and navigation links

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

export default function DashboardPage() {
  return (
    <div className="container mx-auto p-6">
      <OrganizationsOverviewSection />
    </div>
  )
}
```

The component automatically handles loading states with skeleton placeholders, error display, and provides interactive navigation to filtered device views. Each organization row displays the organization card alongside active and inactive device statistics with progress indicators. Users can click on any card to navigate to relevant device listings with appropriate filters applied.
