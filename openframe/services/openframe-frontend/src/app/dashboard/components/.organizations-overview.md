A React component that displays an overview of organizations with device statistics in a grid layout.

## Key Components

- **OrganizationsSkeleton**: Loading state component that shows placeholder cards while data is being fetched
- **OrganizationsOverviewSection**: Main component that renders organization cards alongside device status information
- **handleOrgClick**: Navigation handler that routes to devices page filtered by organization
- **organizationRows**: Memoized rendering of organization data in a responsive grid

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

export function DashboardPage() {
  return (
    <div className="dashboard">
      <OrganizationsOverviewSection />
    </div>
  )
}
```

The component automatically fetches organization data using the `useOrganizationsOverview` hook and displays each organization in a three-column grid:
1. Organization details card with logo and name
2. Active/online devices card with progress indicator
3. Inactive/offline devices card with progress indicator

Each card is clickable and navigates to the devices page with appropriate filters applied. The component handles loading states with skeleton placeholders and error states with error messages.
