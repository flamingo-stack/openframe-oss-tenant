A React component that displays an overview dashboard for organizations with their device statistics and status information.

## Key Components

- **OrganizationsSkeleton** - Loading skeleton component with placeholder cards
- **OrganizationsOverviewSection** - Main component that renders organization cards with device metrics
- **useOrganizationsOverview** - Custom hook for fetching organization data
- **OrganizationCard** - Reusable card component for displaying organization info
- **DashboardInfoCard** - Metric cards for active/inactive device counts

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

export default function Dashboard() {
  return (
    <div className="p-6">
      <OrganizationsOverviewSection />
    </div>
  )
}
```

The component fetches up to 100 organizations and displays them in a responsive grid layout. Each organization row shows:
- Organization details with logo and device count
- Online devices with percentage and green progress bar
- Offline devices with percentage and progress bar

All cards are clickable and navigate to filtered device views. The component handles loading states with skeleton placeholders and error states with error messages. It uses Next.js router for navigation and includes proper responsive design with Tailwind CSS classes.
