A React component that displays an overview of organizations with their device statistics in a responsive grid layout. The component shows organization details, active/online device counts, and offline device counts with visual progress indicators.

## Key Components

- **OrganizationsSkeleton** - Loading skeleton component that mimics the layout structure
- **OrganizationsOverviewSection** - Main component that renders organization cards with device statistics
- **useOrganizationsOverview** - Custom hook for fetching organization data
- **OrganizationCard** - Reusable card component for displaying organization information
- **DashboardInfoCard** - Reusable card component for displaying device statistics with progress bars

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

// Use in a dashboard page
export default function DashboardPage() {
  return (
    <div className="p-6">
      <OrganizationsOverviewSection />
    </div>
  )
}

// The component automatically handles:
// - Loading states with skeleton UI
// - Error states with error messages  
// - Navigation to filtered device views
// - Responsive grid layout (1/2/3 columns)
```

The component uses Tailwind CSS for styling and integrates with Next.js router for navigation. Each organization row displays the organization card alongside active/inactive device statistics, with clickable cards that navigate to filtered device listings. Loading and error states are handled gracefully with appropriate UI feedback.
