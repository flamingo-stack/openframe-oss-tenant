A React component that displays a comprehensive overview of organizations with their device statistics, including online/offline device counts and visual progress indicators.

## Key Components

- **OrganizationsOverviewSection** - Main component that renders organization cards with device metrics
- **OrganizationsSkeleton** - Loading skeleton component for better UX during data fetching
- **useOrganizationsOverview** - Custom hook for fetching organization data
- **DashboardInfoCard** - Reusable card component for displaying device statistics
- **OrganizationCard** - Component for rendering organization information

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

// Use in a dashboard page
function DashboardPage() {
  return (
    <div className="dashboard-container">
      <OrganizationsOverviewSection />
    </div>
  )
}

// The component automatically:
// - Fetches up to 100 organizations
// - Shows loading skeletons while data loads
// - Displays total organization count
// - Renders interactive cards for each organization
// - Provides navigation to filtered device views
```

The component uses a responsive grid layout that adapts from single column on mobile to three columns on desktop. Each organization row displays the organization card alongside active/inactive device metrics with progress bars and clickable navigation to filtered device listings.
