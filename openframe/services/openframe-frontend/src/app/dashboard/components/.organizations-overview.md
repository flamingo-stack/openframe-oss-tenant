A React component that displays an overview of organizations with their device statistics in a grid layout, featuring skeleton loading states and navigation to device views.

## Key Components

- **OrganizationsSkeleton** - Loading placeholder component that renders skeleton cards during data fetching
- **OrganizationsOverviewSection** - Main component that displays organization cards with device statistics
- **useOrganizationsOverview** - Custom hook for fetching organization data (imported)
- **Grid Layout** - Responsive 3-column layout showing organization info, online devices, and offline devices

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

export default function DashboardPage() {
  return (
    <div className="p-6">
      <OrganizationsOverviewSection />
    </div>
  )
}
```

The component fetches up to 10 organizations and displays each in a row with three cards:
1. Organization details with logo and total device count
2. Online devices count with percentage and progress bar
3. Offline devices count with percentage and progress bar

Each card is clickable and navigates to filtered device views. The component includes comprehensive loading states, error handling, and responsive design that adapts from single-column on mobile to three-column on larger screens.
