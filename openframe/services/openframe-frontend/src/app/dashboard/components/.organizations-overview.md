A React client-side component that displays an overview of organizations with their device status metrics in a responsive grid layout.

## Key Components

- **`OrganizationsSkeleton`** - Loading skeleton component that renders placeholder cards during data fetch
- **`OrganizationsOverviewSection`** - Main component that renders organization cards with device statistics
- **Grid Layout** - Responsive 3-column layout showing organization info, active devices, and offline devices per row
- **Navigation Integration** - Handles routing to filtered device views when cards are clicked

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

export function DashboardPage() {
  return (
    <div className="dashboard-container">
      <OrganizationsOverviewSection />
    </div>
  )
}
```

The component automatically fetches organization data using the `useOrganizationsOverview` hook and displays:
- Organization cards with logos and basic info
- Active/online device counts with progress indicators  
- Inactive/offline device counts with progress indicators
- Loading skeletons during data fetch
- Error states with user-friendly messages

Each card is clickable and navigates to filtered device views. The layout is fully responsive, collapsing from 3 columns on desktop to single column on mobile devices.
