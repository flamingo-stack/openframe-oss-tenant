A React component that displays an overview of organizations with their device statistics, featuring a responsive grid layout with organization cards and device status information.

## Key Components

- **`OrganizationsOverviewSection`** - Main component that renders the organizations overview dashboard
- **`OrganizationsSkeleton`** - Loading skeleton component that mimics the layout structure
- **`useOrganizationsOverview`** - Custom hook for fetching organization data (imported)
- **`getFullImageUrl`** - Utility function for processing organization image URLs

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

function Dashboard() {
  return (
    <div className="dashboard">
      <OrganizationsOverviewSection />
    </div>
  )
}

// The component automatically handles:
// - Loading states with skeleton UI
// - Error states with error messages  
// - Navigation to device views when clicking cards
// - Responsive grid layout (1 col mobile, 2 col tablet, 3 col desktop)
```

The component displays each organization in a three-column grid showing:
1. **Organization Card** - Organization details with logo and total device count
2. **Online Devices Card** - Active device count with percentage and progress indicator
3. **Offline Devices Card** - Inactive device count with percentage and progress indicator

Each card is clickable and navigates to filtered device views based on organization and status. The component uses OpenFrame's design system components (`DashboardInfoCard`, `OrganizationCard`, `Skeleton`) and follows the ODS styling conventions.
