A React component that renders a comprehensive overview of organizations with device statistics, including loading states and responsive grid layouts for MSP dashboard interfaces.

## Key Components

- **OrganizationsOverviewSection** - Main component displaying organization cards with device metrics
- **OrganizationsSkeleton** - Loading skeleton component with placeholder cards
- **useOrganizationsOverview** - Custom hook for fetching organization data
- **OrganizationCard** - Reusable card component for organization display
- **DashboardInfoCard** - Card component for device statistics with progress indicators

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

export function Dashboard() {
  return (
    <div className="p-6">
      <OrganizationsOverviewSection />
    </div>
  )
}
```

The component fetches up to 100 organizations and displays them in a responsive grid layout. Each row contains three cards: an organization card showing basic info and device count, an "Online Devices" card with green progress indicator, and an "Offline Devices" card. All cards are clickable and navigate to filtered device views. The component handles loading states with skeleton placeholders and error states with appropriate messaging. It uses Flamingo's design system with custom fonts (Azeret Mono for headings, DM Sans for body text) and ODS color tokens for consistent theming.
