A React component that displays a comprehensive overview of organizations with their device statistics in a responsive grid layout. This component provides MSP administrators with at-a-glance insights into organization status and device health metrics.

## Key Components

- **OrganizationsOverviewSection** - Main component that renders organization cards with device statistics
- **OrganizationsSkeleton** - Loading skeleton component with placeholder cards
- **useOrganizationsOverview** - Custom hook for fetching organization data (imported)
- **handleOrgClick** - Navigation handler that routes to filtered device views

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

function Dashboard() {
  return (
    <div className="dashboard">
      <OrganizationsOverviewSection />
    </div>
  )
}

// The component automatically handles:
// - Loading states with skeleton placeholders
// - Error handling with error messages
// - Responsive grid layout (1/2/3 columns)
// - Navigation to filtered device views on click
// - Progress indicators for device status percentages
```

The component fetches up to 10 organizations and displays them in a three-column grid format: organization details, online devices, and offline devices. Each card is clickable and navigates to filtered device views based on organization and device status. Loading states are handled with skeleton placeholders that match the final layout structure.
