A React component that displays an overview of organizations with their device statistics in a responsive grid layout, featuring loading states and navigation capabilities.

## Key Components

- **OrganizationsOverviewSection** - Main component that renders organization cards with device metrics
- **OrganizationsSkeleton** - Loading state component showing placeholder cards
- **useOrganizationsOverview** - Custom hook for fetching organization data
- **OrganizationCard** - Reusable card component for displaying organization info
- **DashboardInfoCard** - Card component for displaying device statistics with progress bars

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

export default function DashboardPage() {
  return (
    <div className="p-6">
      <OrganizationsOverviewSection />
    </div>
  )
}
```

The component automatically handles:
- Loading states with skeleton placeholders
- Error handling and display
- Responsive grid layout (1 column on mobile, 2 on tablet, 3 on desktop)
- Navigation to device listings filtered by organization and status
- Image URL processing for organization logos
- Progress visualization for active/inactive device percentages

Each organization row displays the organization card alongside active and inactive device metrics, with clickable navigation to filtered device views.
