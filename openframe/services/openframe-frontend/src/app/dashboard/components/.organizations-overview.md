A React component that displays an overview of all organizations with their device statistics in a card-based layout. This component provides a comprehensive dashboard view showing organization details alongside online and offline device counts with interactive navigation to filtered device views.

## Key Components

- **`OrganizationsSkeleton`** - Loading skeleton component that displays placeholder cards while data is being fetched
- **`OrganizationsOverviewSection`** - Main component that renders the organizations overview with interactive cards for navigation
- **Card Grid Layout** - Three-column responsive grid displaying organization info, active devices, and inactive devices per row

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

function Dashboard() {
  return (
    <div className="dashboard">
      <OrganizationsOverviewSection />
    </div>
  )
}

// The component automatically handles:
// - Loading states with skeleton placeholders
// - Error display for failed data fetches
// - Navigation to filtered device views on card clicks
// - Responsive grid layout (1 col mobile, 2 col tablet, 3 col desktop)
```

The component integrates with the organizations data hook to fetch up to 100 organizations and displays each with clickable cards that navigate to device listings filtered by organization and device status. It includes proper loading states, error handling, and responsive design with Tailwind CSS classes following the ODS design system.
