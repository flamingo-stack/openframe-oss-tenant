A React component that displays an overview of organizations with their device statistics in a dashboard layout, featuring skeleton loading states and interactive navigation.

## Key Components

- **`OrganizationsSkeleton`** - Loading skeleton component that mimics the layout structure
- **`OrganizationsOverviewSection`** - Main component that renders organization cards with device metrics
- **Custom hooks integration** - Uses `useOrganizationsOverview` for data fetching and state management
- **Responsive grid layout** - Adapts from single column on mobile to three columns on desktop

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

export default function DashboardPage() {
  return (
    <div className="p-6">
      <OrganizationsOverviewSection />
    </div>
  )
}
```

The component automatically handles loading states, error display, and navigation to filtered device views. Each organization row displays the organization card alongside active/inactive device statistics with clickable links to detailed device listings. The layout uses OpenFrame design system styling with responsive breakpoints and skeleton loading for optimal user experience.
