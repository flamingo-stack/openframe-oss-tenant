A Next.js client component that renders an overview dashboard showing organizations and their device statistics in a grid layout.

## Key Components

- **`OrganizationsSkeleton`** - Loading state component displaying skeleton placeholders for organization cards
- **`OrganizationsOverviewSection`** - Main component that fetches and displays organization data with device metrics
- **Grid Layout** - Responsive 3-column grid showing organization card, online devices, and offline devices per row

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

export default function DashboardPage() {
  return (
    <div className="container mx-auto p-4">
      <OrganizationsOverviewSection />
    </div>
  )
}
```

The component uses the `useOrganizationsOverview` hook to fetch data and displays:
- Organization cards with logos and basic info (clickable to filter devices)
- Active/online device counts with progress indicators
- Inactive/offline device counts with progress indicators
- Loading skeletons and error states
- Navigation to filtered device views when cards are clicked

Each organization row contains three cards in a responsive grid that adapts from single column on mobile to three columns on desktop. The component handles loading states gracefully and provides meaningful navigation to device management screens.
