A React component that displays a comprehensive overview of organizations with their device statistics in a responsive grid layout. Built using Next.js client-side navigation and the Flamingo Stack's OpenFrame frontend core components.

## Key Components

- **OrganizationsOverviewSection** - Main component that renders the complete organizations overview
- **OrganizationsSkeleton** - Loading skeleton component with placeholder cards matching the actual layout
- **useOrganizationsOverview** - Custom hook for fetching organization data (imported)
- **OrganizationCard** - Displays organization info with device count and navigation
- **DashboardInfoCard** - Shows device statistics (online/offline) with progress indicators

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

function DashboardPage() {
  return (
    <div className="p-6">
      <OrganizationsOverviewSection />
    </div>
  )
}

// The component automatically handles:
// - Loading states with skeleton placeholders
// - Error handling and display
// - Navigation to filtered device views
// - Responsive grid layout (1 col mobile, 2 col tablet, 3 col desktop)

// Each organization row contains:
// 1. Organization card (name, image, total devices)
// 2. Online devices card (count, percentage, progress bar)
// 3. Offline devices card (count, percentage, progress bar)
```

The component integrates with Next.js routing to provide filtered device views when cards are clicked, using query parameters to maintain organization and status filters. It displays a total organization count and handles loading/error states gracefully.
