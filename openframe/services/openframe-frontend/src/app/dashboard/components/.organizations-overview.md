A React component that displays an overview dashboard of organizations with their device statistics, including online/offline device counts and interactive navigation.

## Key Components

- **OrganizationsOverviewSection**: Main component that renders the organizations overview dashboard
- **OrganizationsSkeleton**: Loading state component that displays skeleton placeholders during data fetching
- **useOrganizationsOverview**: Custom hook for fetching organizations data (imported)
- **DashboardInfoCard**: Reusable card component for displaying device statistics
- **OrganizationCard**: Card component for displaying organization information

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

export function DashboardPage() {
  return (
    <div className="container mx-auto p-6">
      <OrganizationsOverviewSection />
    </div>
  )
}

// The component automatically handles:
// - Loading states with skeleton UI
// - Error handling with error messages
// - Navigation to filtered device views
// - Responsive grid layout (1 col mobile, 2 col tablet, 3 col desktop)
```

The component features a responsive three-column grid layout showing organization cards alongside active and inactive device statistics. Each card is clickable and navigates to filtered device views. It includes comprehensive loading states and error handling, with the total organization count displayed at the top of the section.
