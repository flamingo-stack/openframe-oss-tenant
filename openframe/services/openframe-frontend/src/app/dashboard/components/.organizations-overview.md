A React component that renders an overview dashboard section displaying organizations with their online/offline device statistics in a responsive grid layout.

## Key Components

- **OrganizationsSkeleton**: Loading skeleton component with placeholder cards
- **OrganizationsOverviewSection**: Main dashboard component that displays organization cards with device metrics
- **useOrganizationsOverview**: Custom hook for fetching organizations data
- **OrganizationCard**: Card component for displaying organization information
- **DashboardInfoCard**: Card component for displaying device statistics with progress bars

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

function Dashboard() {
  return (
    <div className="dashboard">
      <OrganizationsOverviewSection />
    </div>
  )
}

// The component automatically handles:
// - Loading states with skeleton placeholders
// - Error handling with error messages
// - Responsive grid layout (1 column on mobile, 2 on tablet, 3 on desktop)
// - Navigation to filtered device views when clicking cards
// - Organization count display with proper formatting
```

The component fetches up to 100 organizations and displays each in a three-column grid showing the organization details, active devices count with percentage, and inactive devices count with percentage. Cards are clickable and navigate to filtered device views based on organization and device status.
