A React component that displays an overview of organizations with their device statistics in a responsive grid layout. It shows organization cards alongside their active/inactive device counts with loading states and error handling.

## Key Components

- `OrganizationsOverviewSection` - Main component that renders the organizations overview dashboard
- `OrganizationsSkeleton` - Loading skeleton component with placeholder cards
- `useOrganizationsOverview` - Custom hook for fetching organization data
- `OrganizationCard` - Displays organization information with device count
- `DashboardInfoCard` - Shows device statistics with progress indicators

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

// Basic usage in a dashboard
export function Dashboard() {
  return (
    <div className="p-6">
      <OrganizationsOverviewSection />
    </div>
  )
}

// The component automatically handles:
// - Loading states with skeleton placeholders
// - Error states with error messages
// - Navigation to filtered device views
// - Responsive grid layout (1/2/3 columns)
```

The component creates a three-column layout for each organization showing the organization card, active devices count, and inactive devices count. Each card is clickable and navigates to filtered device views. It uses the Flamingo design system with ODS (OpenFrame Design System) styling classes.
