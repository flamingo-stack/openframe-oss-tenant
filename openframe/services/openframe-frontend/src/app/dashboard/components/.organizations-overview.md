A React component that displays an overview dashboard of organizations with their device statistics, including online/offline device counts and interactive navigation to filtered device views.

## Key Components

- **OrganizationsSkeleton**: Loading skeleton component that shows placeholder cards while data is being fetched
- **OrganizationsOverviewSection**: Main component that renders the organizations dashboard with:
  - Organization cards showing basic info and total device count
  - Active/online device statistics with progress indicators
  - Inactive/offline device statistics
  - Click navigation to filtered device views

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

function DashboardPage() {
  return (
    <div className="p-6">
      <OrganizationsOverviewSection />
    </div>
  )
}

// The component automatically fetches organization data and displays:
// - Organization name, image, and total devices
// - Online devices count with percentage and green progress bar
// - Offline devices count with percentage
// - Clickable navigation to filtered device lists
```

The component uses responsive grid layouts (1 column on mobile, 2 on tablet, 3 on desktop) and integrates with the routing system to provide seamless navigation to device management views with pre-applied filters based on organization and device status.
