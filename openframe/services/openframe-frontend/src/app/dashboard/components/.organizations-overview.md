A client-side React component that displays an overview of all organizations with their device statistics, including online/offline device counts and interactive navigation.

## Key Components

- **OrganizationsSkeleton** - Loading state component that displays placeholder cards while data is being fetched
- **OrganizationsOverviewSection** - Main component that renders organization cards with device metrics in a responsive grid layout
- **useOrganizationsOverview** - Custom hook for fetching organization data and statistics
- **OrganizationCard** - Displays organization information with logo, name, and total device count
- **DashboardInfoCard** - Shows device metrics (online/offline) with progress bars and percentages

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

export default function DashboardPage() {
  return (
    <div className="p-6">
      <OrganizationsOverviewSection />
    </div>
  )
}

// The component automatically handles:
// - Loading states with skeleton placeholders
// - Error display
// - Responsive grid layout (1 col mobile, 2 col tablet, 3 col desktop)
// - Navigation to filtered device views when cards are clicked
// - Progress visualization for device status percentages
```

The component creates an interactive dashboard where users can view all organizations and click on any card to navigate to filtered device views, such as seeing only online devices for a specific organization.
