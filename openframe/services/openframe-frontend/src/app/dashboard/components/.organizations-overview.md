A React component that displays an overview of organizations with their device statistics in a responsive grid layout. It shows organization cards alongside active and inactive device counts with navigation capabilities.

## Key Components

- **OrganizationsOverviewSection** - Main component that renders the organizations overview dashboard
- **OrganizationsSkeleton** - Loading state component that displays placeholder cards
- **useOrganizationsOverview** - Custom hook for fetching organization data
- **OrganizationCard** - Reusable card component for displaying organization information
- **DashboardInfoCard** - Card component for displaying device statistics with progress indicators

## Usage Example

```typescript
import OrganizationsOverviewSection from './organizations-overview'

export default function DashboardPage() {
  return (
    <div className="p-6">
      <OrganizationsOverviewSection />
    </div>
  )
}

// The component automatically handles:
// - Loading states with skeleton placeholders
// - Error handling and display
// - Navigation to filtered device views
// - Responsive grid layout (1 col mobile, 2 col tablet, 3 col desktop)
// - Organization image URL processing
```

The component uses a three-column layout per organization row: the organization card on the left, followed by active devices count and inactive devices count. Each card is clickable and navigates to filtered device views with appropriate query parameters.
