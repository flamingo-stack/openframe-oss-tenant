A React component that displays an overview of organizations with their device statistics, featuring responsive grid layouts and interactive navigation to filtered device views.

## Key Components

- **OrganizationsOverviewSection** - Main component rendering organization cards with device metrics
- **OrganizationsSkeleton** - Loading skeleton component with placeholder cards
- **useOrganizationsOverview** - Custom hook for fetching organization data
- **OrganizationCard** - Individual organization display card
- **DashboardInfoCard** - Device statistics cards (online/offline metrics)

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

export default function Dashboard() {
  return (
    <div className="p-6">
      <OrganizationsOverviewSection />
    </div>
  )
}
```

The component automatically handles:
- Loading states with skeleton placeholders
- Error handling with error messages
- Responsive grid layouts (1 column mobile, 2 tablet, 3 desktop)
- Navigation to filtered device views when cards are clicked
- Image URL processing for organization logos
- Real-time device count and percentage calculations

Each organization row displays the organization card alongside active and inactive device metrics, with clickable navigation to relevant device filtered views.
