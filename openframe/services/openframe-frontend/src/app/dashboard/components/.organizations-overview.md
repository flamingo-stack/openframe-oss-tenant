A React component that displays an organizations overview dashboard with detailed metrics for each organization including device status information.

## Key Components

- **OrganizationsSkeleton** - Loading skeleton component with placeholder cards
- **OrganizationsOverviewSection** - Main component that renders organizations grid with device metrics
- **useOrganizationsOverview** - Custom hook for fetching organization data
- **OrganizationCard** - Displays organization info with logo and device count
- **DashboardInfoCard** - Shows device metrics (online/offline) with progress bars

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

function DashboardPage() {
  return (
    <div className="p-6">
      <OrganizationsOverviewSection />
    </div>
  )
}
```

The component automatically handles loading states, error states, and navigation to filtered device views when cards are clicked. Each organization row displays three cards: organization info, online devices count with percentage, and offline devices count with percentage. The cards link to filtered device lists based on organization and device status.
