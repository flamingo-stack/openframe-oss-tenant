A React component that renders an organizations overview dashboard section displaying organizations with their device statistics in a responsive grid layout.

## Key Components

- **OrganizationsSkeleton** - Loading skeleton component showing placeholder cards during data fetching
- **OrganizationsOverviewSection** - Main component that displays organization cards with device metrics (online/offline counts and percentages)
- **handleOrgClick** - Navigation handler that routes to devices filtered by organization
- **organizationRows** - Memoized rendering logic for organization data with error handling

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

export default function DashboardPage() {
  return (
    <div className="p-6">
      <OrganizationsOverviewSection />
    </div>
  )
}

// The component automatically handles:
// - Data fetching via useOrganizationsOverview hook
// - Loading states with skeleton UI
// - Navigation to filtered device views
// - Responsive grid layout (1 col mobile, 2 col tablet, 3 col desktop)
```

The component fetches organization data and renders each organization as a three-column row containing: an organization card with logo and basic info, an "Online Devices" metrics card, and an "Offline Devices" metrics card. All cards are clickable and navigate to filtered device views. The layout is fully responsive and includes proper loading states and error handling.
