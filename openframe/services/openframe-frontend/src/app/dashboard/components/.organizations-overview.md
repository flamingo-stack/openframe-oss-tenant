A React component that displays an overview of organizations with their device statistics in a dashboard grid layout.

## Key Components

- **OrganizationsSkeleton** - Loading skeleton component that displays placeholder cards while data is fetching
- **OrganizationsOverviewSection** - Main component that renders organization cards with device metrics in a responsive grid
- **useOrganizationsOverview** - Custom hook for fetching organization data and statistics
- **handleOrgClick** - Navigation handler that routes to the devices page filtered by organization

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

export function DashboardPage() {
  return (
    <div className="dashboard-container">
      <OrganizationsOverviewSection />
    </div>
  )
}
```

The component automatically handles loading states with skeleton placeholders, error states with user-friendly messages, and renders each organization as a three-column grid showing:
1. Organization details card with logo and name
2. Online devices count with percentage and progress indicator  
3. Offline devices count with percentage and progress indicator

Each card is clickable and navigates to a filtered devices view. The layout is responsive, adapting from single column on mobile to three columns on desktop displays.
