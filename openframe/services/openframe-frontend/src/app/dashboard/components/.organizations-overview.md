A React component that displays an overview of organizations with their device statistics in a responsive grid layout. It shows organization cards alongside active/inactive device counts with progress indicators and navigation links.

## Key Components

- `OrganizationsSkeleton` - Loading state component with skeleton placeholders
- `OrganizationsOverviewSection` - Main component that renders organization overview with device statistics
- **Hooks Used**: `useOrganizationsOverview`, `useRouter`
- **UI Components**: `DashboardInfoCard`, `OrganizationCard`, `Skeleton` from OpenFrame frontend core

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

// Display organizations overview in dashboard
function DashboardPage() {
  return (
    <div className="dashboard-container">
      <OrganizationsOverviewSection />
    </div>
  )
}

// The component automatically handles:
// - Loading states with skeleton UI
// - Error handling and display
// - Navigation to filtered device views
// - Responsive grid layout (1 col mobile, 2 col tablet, 3 col desktop)
```

The component fetches up to 100 organizations and displays each with three cards: organization info, online devices count, and offline devices count. Each card is clickable and navigates to filtered device views with appropriate query parameters for organization and device status filtering.
