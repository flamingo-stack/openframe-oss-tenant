A React component that displays an overview dashboard of organizations with their device statistics, including online/offline device counts and interactive navigation.

## Key Components

- **OrganizationsSkeleton**: Loading state component that renders placeholder cards while data is fetching
- **OrganizationsOverviewSection**: Main dashboard component that displays organization cards with device metrics
- **useOrganizationsOverview**: Custom hook for fetching organization data and statistics
- **OrganizationCard**: Reusable card component for displaying organization information
- **DashboardInfoCard**: Metric cards showing active/inactive device counts with progress bars

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

export default function DashboardPage() {
  return (
    <div className="p-6">
      <OrganizationsOverviewSection />
    </div>
  )
}
```

The component automatically handles loading states, error handling, and navigation to filtered device views. Each organization row displays three cards: the organization details with total device count, online devices with percentage and green progress bar, and offline devices with their respective metrics. Clicking on cards navigates to filtered device lists based on organization and status.
