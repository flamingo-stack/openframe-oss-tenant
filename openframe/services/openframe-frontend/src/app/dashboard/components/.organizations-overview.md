A React client-side component that displays an overview of organizations with their device statistics in a responsive grid layout.

## Key Components

- **OrganizationsOverviewSection** - Main component that renders organization cards with device metrics
- **OrganizationsSkeleton** - Loading skeleton component that displays placeholder cards during data fetching
- **handleOrgClick** - Navigation callback that routes to devices filtered by organization
- **organizationRows** - Memoized rendering of organization data with three-column layout

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

function Dashboard() {
  return (
    <div className="dashboard">
      <OrganizationsOverviewSection />
    </div>
  )
}

// The component automatically:
// - Fetches organization data using useOrganizationsOverview hook
// - Displays loading skeletons while data loads
// - Shows organization cards with device counts
// - Provides clickable navigation to filtered device views
// - Handles responsive layout (1 column mobile, 2 tablet, 3 desktop)
```

The component creates a three-column grid for each organization showing: the organization card with logo and basic info, active/online device count with percentage, and inactive/offline device count with percentage. All cards are clickable and navigate to relevant filtered device views.
