A React component that renders an organizations overview dashboard with device statistics and interactive organization cards for navigation to filtered device views.

## Key Components

- **OrganizationsOverviewSection** - Main component displaying organizations with device metrics
- **OrganizationsSkeleton** - Loading state component with skeleton placeholders
- **useOrganizationsOverview** - Custom hook for fetching organization data (external dependency)
- **OrganizationCard** - Reusable card component for displaying organization info
- **DashboardInfoCard** - Info cards showing active/offline device counts with progress bars

## Usage Example

```typescript
import { OrganizationsOverviewSection } from './organizations-overview'

function Dashboard() {
  return (
    <div className="dashboard">
      <OrganizationsOverviewSection />
    </div>
  )
}
```

The component displays a responsive grid layout where each organization row contains three cards:
1. Organization details card (name, image, total devices) - clickable to filter devices
2. Active/online devices card with percentage and progress bar
3. Inactive/offline devices card with percentage and progress bar

Each card links to filtered device views using query parameters for organization IDs and device statuses. The component handles loading states with skeleton UI and displays error messages when data fetching fails.
