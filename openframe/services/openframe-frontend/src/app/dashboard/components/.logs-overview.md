A React dashboard component that displays a comprehensive logs overview with severity statistics and recent log entries.

## Key Components

- **LogsOverviewSection**: Main component rendering logs statistics cards and recent logs list
- **ExtendedLogEntry**: Type extending LogEntry with navigation data
- **useLogsOverview**: Hook for fetching dashboard statistics (info, warning, critical counts)
- **useLogs**: Hook for fetching raw log entries
- **DashboardInfoCard**: Displays severity-based log counts with progress indicators
- **LogsList**: Shows recent log entries with click navigation

## Usage Example

```typescript
import { LogsOverviewSection } from './logs-overview'

function DashboardPage() {
  return (
    <div className="dashboard">
      <LogsOverviewSection />
    </div>
  )
}

// The component automatically:
// - Fetches logs statistics on mount
// - Displays top 10 recent log entries
// - Handles log entry navigation on click
// - Shows loading states during data fetch
```

The component uses a responsive grid layout with severity statistics cards on the left and a scrollable recent logs list on the right. Each log entry click navigates to detailed log view using the `navigateToLogDetails` utility function.
