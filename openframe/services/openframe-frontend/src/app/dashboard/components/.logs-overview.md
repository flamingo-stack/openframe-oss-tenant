A React component that provides a dashboard overview of system logs, displaying severity statistics and a list of recent log entries with navigation capabilities.

## Key Components

- **LogsOverviewSection**: Main component that renders the logs overview dashboard
- **ExtendedLogEntry**: Type extension of LogEntry that includes original log data for navigation
- **useLogsOverview**: Custom hook for fetching log statistics and counts
- **useLogs**: Custom hook for fetching raw log entries
- **navigateToLogDetails**: Navigation utility for routing to detailed log views

## Usage Example

```typescript
import { LogsOverviewSection } from './logs-overview'

// Basic usage in a dashboard
function Dashboard() {
  return (
    <div className="dashboard">
      <LogsOverviewSection />
    </div>
  )
}

// The component automatically:
// - Fetches and displays log statistics (info, warning, critical counts)
// - Shows recent 10 log entries in a scrollable list
// - Handles click navigation to detailed log views
// - Provides responsive layout with info cards and logs list
```

The component features a two-column responsive layout with severity-based info cards on the left (showing counts and percentages for INFO, WARNING, and CRITICAL logs) and a scrollable list of the 10 most recent log entries on the right. Each log entry is clickable and navigates to a detailed view using the stored original log data.
