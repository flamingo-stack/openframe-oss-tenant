A React component that displays a comprehensive logs overview dashboard with statistics cards and a recent logs list for the OpenFrame platform.

## Key Components

- **LogsOverviewSection**: Main dashboard component displaying logs statistics and recent entries
- **ExtendedLogEntry**: Type extension adding navigation metadata to log entries
- **DashboardInfoCard**: Statistics cards showing Info, Warning, and Critical log counts with progress bars
- **LogsList**: Interactive list displaying the 10 most recent log entries
- **Navigation Integration**: Handles log detail navigation and routing

## Usage Example

```typescript
import { LogsOverviewSection } from './logs-overview'

// Use in a dashboard layout
function Dashboard() {
  return (
    <div className="dashboard-grid">
      <LogsOverviewSection />
      {/* Other dashboard sections */}
    </div>
  )
}

// The component automatically:
// - Fetches logs data on mount
// - Displays categorized log statistics with percentages
// - Shows recent logs with click navigation
// - Handles loading states and responsive layout
```

The component provides a complete logs monitoring interface with real-time statistics, visual progress indicators for different severity levels, and quick access to recent log entries with full navigation support to detailed log views.
