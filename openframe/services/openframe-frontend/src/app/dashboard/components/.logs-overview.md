A React component that provides a dashboard overview of system logs, displaying statistics cards and a list of recent log entries with navigation capabilities.

## Key Components

- **LogsOverviewSection** - Main component rendering logs overview with statistics and recent entries
- **ExtendedLogEntry** - Type extending LogEntry with originalLogEntry for navigation context
- **useLogs** - Hook for fetching raw log data from the logs page
- **useLogsOverview** - Hook providing aggregated log statistics (totals, percentages by severity)
- **DashboardInfoCard** - Cards displaying log counts by severity (Info, Warning, Critical) with progress bars
- **LogsList** - Component rendering the 10 most recent log entries

## Usage Example

```typescript
import { LogsOverviewSection } from './logs-overview'

function DashboardPage() {
  return (
    <div className="dashboard-container">
      <LogsOverviewSection />
    </div>
  )
}

// The component automatically:
// - Fetches logs on mount
// - Displays severity-based statistics with color-coded progress bars
// - Shows recent logs with click navigation to detailed views
// - Handles loading states and responsive grid layout
```

The component transforms raw log data into a user-friendly overview format, normalizing tool types and providing click handlers for detailed log navigation using the `navigateToLogDetails` utility.
