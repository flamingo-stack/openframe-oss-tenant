A React component that displays a comprehensive logs overview dashboard with severity statistics and recent log entries for the OpenFrame platform.

## Key Components

- **LogsOverviewSection**: Main dashboard component displaying logs statistics and recent entries
- **ExtendedLogEntry**: Type extension of LogEntry that includes original log data for navigation
- **Dashboard Cards**: Info cards showing counts and percentages for different log severities (Info, Warning, Critical)
- **Recent Logs List**: Displays the 10 most recent log entries with click navigation
- **Grid Layout**: Responsive layout with statistics cards on left and logs list on right

## Usage Example

```typescript
import { LogsOverviewSection } from './logs-overview'

function DashboardPage() {
  return (
    <div className="dashboard-container">
      <LogsOverviewSection />
    </div>
  )
}

// The component automatically:
// - Fetches logs data using useLogsOverview and useLogs hooks
// - Displays total log count with severity breakdown
// - Shows clickable recent logs that navigate to details
// - Provides responsive grid layout for desktop/mobile
```

The component integrates with OpenFrame's logging system to provide real-time dashboard insights, featuring severity-based color coding (green for info, yellow for warnings, red for critical) and seamless navigation to detailed log views.
