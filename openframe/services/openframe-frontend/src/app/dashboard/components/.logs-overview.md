Dashboard component that displays a comprehensive logs overview with summary statistics and recent log entries for the OpenFrame platform.

## Key Components

- **LogsOverviewSection** - Main component that renders logs overview with statistics cards and recent logs list
- **ExtendedLogEntry** - Type extension that adds `originalLogEntry` property to the base `LogEntry` type for navigation purposes
- **useLogs** - Hook for fetching raw log data from the logs page
- **useLogsOverview** - Hook for retrieving dashboard-specific log statistics
- **navigateToLogDetails** - Utility function for navigating to individual log detail pages

## Usage Example

```typescript
import { LogsOverviewSection } from './logs-overview'

// Use in dashboard layout
function Dashboard() {
  return (
    <div className="dashboard-container">
      <LogsOverviewSection />
    </div>
  )
}
```

The component automatically fetches and displays:
- Total log count with categorized statistics (Info, Warning, Critical)
- Progress indicators showing percentage distribution by severity
- Recent 10 logs list with click-to-navigate functionality
- Responsive grid layout optimized for desktop and mobile viewing
