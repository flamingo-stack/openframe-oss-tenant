A React dashboard component that displays a comprehensive logs overview with severity-based statistics cards and a real-time logs list, integrating with the OpenFrame platform's logging system for MSP monitoring.

## Key Components

- **LogsOverviewSection**: Main dashboard component combining logs statistics and recent logs display
- **ExtendedLogEntry**: Type extension adding navigation metadata to standard log entries
- **useLogs/useLogsOverview**: Custom hooks for fetching logs data and dashboard statistics
- **DashboardInfoCard**: Displays severity-based log counts with progress indicators
- **LogsList**: Renders recent logs with click-to-navigate functionality
- **navigateToLogDetails**: Navigation utility for log detail routing

## Usage Example

```typescript
import { LogsOverviewSection } from './logs-overview'

// Dashboard page implementation
export default function DashboardPage() {
  return (
    <div className="dashboard-container">
      <LogsOverviewSection />
      {/* Other dashboard sections */}
    </div>
  )
}

// The component automatically:
// - Fetches and displays log statistics (info, warning, critical)
// - Shows recent 10 logs with severity indicators
// - Enables navigation to detailed log views
// - Updates data in real-time via hooks
```

The component features a responsive grid layout with severity-based info cards on the left and a scrollable logs list on the right, providing MSP technicians with immediate visibility into system health and recent events.
