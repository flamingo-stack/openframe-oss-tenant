A React component that displays a comprehensive logs overview dashboard with severity breakdown cards and recent logs list.

## Key Components

- **LogsOverviewSection** - Main dashboard component that renders logs statistics and recent activity
- **ExtendedLogEntry** - Type extension that includes original log entry data for navigation
- **useLogsOverview** - Custom hook for fetching logs overview statistics
- **useLogs** - Custom hook for fetching detailed logs data
- **normalizeToolTypeWithFallback** - Utility function for standardizing tool type display
- **navigateToLogDetails** - Navigation helper for log detail pages

## Usage Example

```typescript
import { LogsOverviewSection } from './logs-overview'

function DashboardPage() {
  return (
    <div className="dashboard-container">
      <LogsOverviewSection />
    </div>
  )
}

// The component automatically:
// - Fetches logs overview statistics on mount
// - Displays info, warning, and critical log counts with percentages
// - Shows recent 10 logs in an interactive list
// - Handles navigation to individual log details
// - Provides responsive grid layout for desktop/mobile
```

The component features a two-column responsive layout with severity-based info cards on the left and a scrollable recent logs list on the right. It integrates with the OpenFrame frontend core components and provides seamless navigation to detailed log views.
