A React component that displays a comprehensive logs overview section for the OpenFrame dashboard, featuring log statistics and a list of recent log entries.

## Key Components

- **LogsOverviewSection** - Main component that renders logs overview with statistics cards and recent logs list
- **ExtendedLogEntry** - Type extending LogEntry with originalLogEntry for navigation purposes
- **useLogs** - Hook for fetching and managing logs data
- **useLogsOverview** - Hook for retrieving logs overview statistics
- **DashboardInfoCard** - Component for displaying log statistics with progress indicators
- **LogsList** - Component for rendering a scrollable list of recent logs

## Usage Example

```typescript
import { LogsOverviewSection } from './logs-overview'

function DashboardPage() {
  return (
    <div className="dashboard">
      <LogsOverviewSection />
    </div>
  )
}
```

The component automatically fetches logs data on mount, displays statistics for info/warning/critical logs with color-coded progress bars, and shows the 10 most recent log entries. Users can click on individual logs to navigate to detailed views using the integrated log navigation system. The layout is responsive with a two-column grid that stacks on mobile devices.
