A React dashboard component that provides guided onboarding for new OpenFrame users, with step-by-step configuration tasks and completion tracking.

## Key Components

- **OnboardingSection**: Main component that renders the onboarding walkthrough
- **useOnboardingCompletion**: Hook that tracks completion status of onboarding steps
- **OnboardingWalkthrough**: Core walkthrough component from the frontend library
- **Navigation handlers**: Callback functions for routing to different configuration pages

## Usage Example

```typescript
import { OnboardingSection } from './onboarding-section'

function Dashboard() {
  return (
    <div className="dashboard">
      <h1>Welcome to OpenFrame</h1>
      <OnboardingSection />
    </div>
  )
}
```

The component automatically handles:
- **Organizations Setup**: Routes to `/organizations/edit/new`
- **Device Management**: Routes to `/devices/new` 
- **Company & Team**: Routes to `/settings?tab=company-and-users`
- **SSO Configuration**: Routes to `/settings?tab=sso-configuration`
- **Knowledge Base**: Opens external documentation

Completion status is managed through the `useOnboardingCompletion` hook, which eliminates duplicate API calls by leveraging existing dashboard state. The walkthrough persists progress using the storage key `openframe-dashboard-onboarding`.
