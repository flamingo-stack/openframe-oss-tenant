A Next.js dashboard component that renders an interactive onboarding walkthrough for new OpenFrame users, guiding them through essential setup tasks like organization creation, device management, team setup, SSO configuration, and knowledge base access.

## Key Components

- **OnboardingSection** - Main component that orchestrates the onboarding experience
- **useOnboardingCompletion** - Custom hook for tracking completion status across steps
- **OnboardingWalkthrough** - Core walkthrough component from the design system
- **Navigation handlers** - Router-based actions for each onboarding step
- **Step configuration** - Structured definitions for each onboarding task

## Usage Example

```typescript
import { OnboardingSection } from './onboarding-section'

export function Dashboard() {
  return (
    <div className="dashboard">
      <h1>Welcome to OpenFrame</h1>
      <OnboardingSection />
      {/* Other dashboard content */}
    </div>
  )
}
```

The component automatically tracks completion status and provides appropriate actions for each step. Steps navigate to relevant pages except for the knowledge base, which opens in a new tab. The walkthrough persists its state using the `openframe-dashboard-onboarding` storage key and integrates seamlessly with the existing dashboard hooks to avoid duplicate API calls.
