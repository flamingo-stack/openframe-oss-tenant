A React component that provides a guided onboarding experience for new OpenFrame users, featuring step-by-step configuration of organizations, devices, team settings, SSO, and knowledge base access.

## Key Components

- **OnboardingSection** - Main component that orchestrates the onboarding flow
- **onboardingSteps** - Configuration array defining each onboarding step with icons, descriptions, and actions
- **Navigation handlers** - Callback functions that route users to appropriate configuration pages
- **useOnboardingCompletion** - Custom hook for tracking completion status across steps

## Usage Example

```typescript
import { OnboardingSection } from './onboarding-section'

export function DashboardPage() {
  return (
    <div className="dashboard-container">
      <h1>Welcome to OpenFrame</h1>
      <OnboardingSection />
    </div>
  )
}
```

The component automatically tracks completion status and provides visual feedback as users progress through setup tasks. Each step includes contextual icons from the OpenFrame design system and smart routing to relevant configuration pages. The knowledge base step opens externally to Flamingo's documentation, while other steps navigate within the application using Next.js routing.
