A React component that renders a customizable onboarding walkthrough for the OpenFrame dashboard, guiding users through essential setup steps like organization creation, device management, team setup, and SSO configuration.

## Key Components

- **OnboardingSection** - Main component that renders the onboarding walkthrough
- **onboardingSteps** - Configuration array defining 5 onboarding steps with icons, descriptions, and actions
- **useOnboardingCompletion** - Custom hook for tracking completion status
- **Navigation handlers** - Callback functions for routing to different setup pages

## Usage Example

```typescript
import { OnboardingSection } from './onboarding-section'

export function Dashboard() {
  return (
    <div className="dashboard">
      <h1>Welcome to OpenFrame</h1>
      <OnboardingSection />
    </div>
  )
}
```

The component automatically tracks completion status through the `useOnboardingCompletion` hook and provides smooth navigation to setup pages. Each step includes appropriate icons from the OpenFrame design system and handles both internal routing (organizations, devices, settings) and external links (knowledge base). The walkthrough persists progress using the storage key `openframe-dashboard-onboarding`.
