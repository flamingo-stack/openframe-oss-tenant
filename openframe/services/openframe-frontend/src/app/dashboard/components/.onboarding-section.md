A React component that renders the main onboarding walkthrough for OpenFrame's dashboard, guiding users through essential setup tasks using the existing onboarding completion hook to avoid duplicate API calls.

## Key Components

- **OnboardingSection** - Main component that configures and renders the onboarding walkthrough
- **Navigation handlers** - Callback functions for routing to different setup pages
- **onboardingSteps** - Configuration array defining the 5-step onboarding flow:
  - Organizations Setup
  - Device Management  
  - Company & Team
  - SSO Configuration
  - Knowledge Base

## Usage Example

```typescript
import { OnboardingSection } from './onboarding-section'

export default function DashboardPage() {
  return (
    <div className="dashboard-container">
      <h1>Welcome to OpenFrame</h1>
      <OnboardingSection />
    </div>
  )
}
```

The component leverages the `useOnboardingCompletion` hook for state management and uses Next.js router for navigation. Each step includes appropriate icons from the design system and either navigates to internal routes or opens external documentation. The knowledge base step auto-completes when clicked, while other steps track completion status through the backend API.
