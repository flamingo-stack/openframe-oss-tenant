A React component that renders an onboarding walkthrough for the OpenFrame dashboard, guiding users through essential setup steps like organization configuration, device management, team setup, SSO configuration, and knowledge base access.

## Key Components

- **OnboardingSection** - Main component that renders the complete onboarding experience
- **useOnboardingCompletion** - Custom hook for tracking completion status of onboarding steps
- **OnboardingWalkthrough** - Core walkthrough component from the frontend library
- **Step Configuration** - Predefined steps with actions, icons, and navigation handlers

## Usage Example

```typescript
import { OnboardingSection } from './components/onboarding-section'

export function DashboardPage() {
  return (
    <div className="dashboard">
      <OnboardingSection />
      {/* Other dashboard content */}
    </div>
  )
}
```

The component automatically handles:
- Step completion tracking via `useOnboardingCompletion` hook
- Navigation to appropriate pages for each onboarding action
- External link handling for knowledge base access
- Responsive loading states and completion indicators

Each step includes relevant icons, descriptions, and action buttons that route users to the correct configuration pages or external resources.
