A React component that renders an interactive onboarding walkthrough for the OpenFrame dashboard, guiding users through essential setup steps like organizations, device management, team setup, SSO configuration, and knowledge base access.

## Key Components

- **OnboardingSection** - Main component that orchestrates the onboarding experience
- **OnboardingWalkthrough** - Core walkthrough component from `@flamingo-stack/openframe-frontend-core`
- **useOnboardingCompletion** - Custom hook for tracking completion status
- **OnboardingStepConfig[]** - Configuration array defining each onboarding step
- **Navigation handlers** - Callback functions for routing to different setup pages

## Usage Example

```typescript
import { OnboardingSection } from './onboarding-section'

export function Dashboard() {
  return (
    <div className="dashboard">
      <h1>Welcome to OpenFrame</h1>
      <OnboardingSection />
      {/* Other dashboard content */}
    </div>
  )
}
```

The component automatically tracks completion status through the `useOnboardingCompletion` hook and provides navigation to:
- `/organizations/edit/new` for organization setup
- `/devices/new` for device management
- `/settings?tab=company-and-users` for team management
- `/settings?tab=sso-configuration` for SSO setup
- External knowledge base link

Each step includes custom icons, descriptions, and action buttons that guide users through the platform setup process.
