A React component that renders an interactive onboarding walkthrough for the OpenFrame dashboard, guiding users through essential setup tasks like organization configuration, device management, team setup, SSO configuration, and knowledge base access.

## Key Components

- **OnboardingSection**: Main functional component that manages onboarding flow
- **useOnboardingCompletion**: Custom hook for tracking completion status
- **OnboardingWalkthrough**: Core walkthrough component from Flamingo Stack
- **Navigation handlers**: Callback functions for routing to different setup sections
- **Step configuration**: Array of onboarding steps with icons, descriptions, and actions

## Usage Example

```typescript
import { OnboardingSection } from './components/onboarding-section'

export default function DashboardPage() {
  return (
    <div className="dashboard">
      <h1>Welcome to OpenFrame</h1>
      <OnboardingSection />
    </div>
  )
}
```

The component automatically tracks completion status and provides navigation to:
- Organizations setup (`/organizations/edit/new`)
- Device management (`/devices/new`) 
- Team configuration (`/settings?tab=company-and-users`)
- SSO setup (`/settings?tab=sso-configuration`)
- External knowledge base (opens in new tab)

Each step includes appropriate icons from the Flamingo Stack design system and maintains completion state through the dashboard's existing hooks, eliminating duplicate API calls.
