A client-side React component that provides a guided onboarding walkthrough for new users, helping them complete essential setup tasks in the OpenFrame dashboard. The component leverages reusable hooks to track completion status and navigate users through key configuration steps.

## Key Components

- **OnboardingSection** - Main component that renders the onboarding walkthrough with predefined steps
- **useOnboardingCompletion** - Custom hook for tracking step completion status without duplicate API calls
- **OnboardingStepConfig[]** - Configuration array defining five onboarding steps with navigation handlers
- **Navigation handlers** - Callback functions for routing users to specific configuration pages

## Onboarding Steps

The component guides users through these essential setup tasks:

1. **Organizations Setup** - Create organizational structure (`/organizations/edit/new`)
2. **Device Management** - Connect and monitor devices (`/devices/new`) 
3. **Company & Team** - Invite team members (`/settings?tab=company-and-users`)
4. **SSO Configuration** - Link identity providers (`/settings?tab=sso-configuration`)
5. **Knowledge Base** - Access documentation (external link to flamingo.run)

## Usage Example

```typescript
import { OnboardingSection } from './onboarding-section'

export function Dashboard() {
  return (
    <div className="dashboard">
      <OnboardingSection />
      {/* Other dashboard content */}
    </div>
  )
}
```

The component automatically tracks completion status using the dashboard's existing hooks, eliminating duplicate API calls while providing users with a clear path to get started with the platform.
