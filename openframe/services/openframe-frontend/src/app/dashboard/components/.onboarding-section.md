A React component that provides a guided onboarding experience for new users in the OpenFrame dashboard, featuring step-by-step setup tasks with completion tracking.

## Key Components

- **OnboardingSection** - Main component that renders the onboarding walkthrough
- **OnboardingStepConfig[]** - Configuration array defining 5 onboarding steps:
  - Organizations Setup - Navigate to create new organizations
  - Device Management - Add and monitor devices
  - Company & Team - Invite users and manage roles  
  - SSO Configuration - Set up identity providers
  - Knowledge Base - Access external documentation
- **useOnboardingCompletion** - Custom hook for tracking step completion status
- **Navigation handlers** - Callback functions for routing to different sections

## Usage Example

```typescript
import { OnboardingSection } from './onboarding-section'

function Dashboard() {
  return (
    <div className="dashboard">
      <h1>Welcome to OpenFrame</h1>
      <OnboardingSection />
    </div>
  )
}
```

The component automatically tracks completion status through the dashboard hooks, eliminating duplicate API calls. Each step includes an icon, title, description, and action button that routes users to the appropriate configuration page. The knowledge base step opens externally to the Flamingo documentation site.
