A React component that provides an interactive onboarding walkthrough for new users on the OpenFrame dashboard, guiding them through essential setup steps like organization creation, device management, and team configuration.

## Key Components

- **OnboardingSection**: Main component that renders the onboarding walkthrough with navigation handlers
- **OnboardingStepConfig[]**: Configuration array defining 5 onboarding steps with icons, descriptions, and actions
- **Navigation handlers**: Callback functions for routing to different setup pages (organizations, devices, settings)
- **useOnboardingCompletion**: Custom hook for tracking completion status and loading states
- **OnboardingWalkthrough**: Core component from the Flamingo frontend library

## Usage Example

```typescript
import { OnboardingSection } from './onboarding-section'

function DashboardPage() {
  return (
    <div className="dashboard-container">
      <h1>Welcome to OpenFrame</h1>
      <OnboardingSection />
      {/* Rest of dashboard content */}
    </div>
  )
}
```

The component automatically tracks completion status through the dashboard hooks system, eliminating duplicate API calls. Each step navigates to the appropriate setup page or opens the knowledge base in a new tab. The walkthrough persists state using the `openframe-dashboard-onboarding` storage key and displays completion status with loading states.
