A React component that renders an interactive onboarding walkthrough for OpenFrame's dashboard, guiding users through essential setup steps like organizations, devices, team management, SSO configuration, and knowledge base access.

## Key Components

- **OnboardingSection**: Main component that configures and displays the onboarding walkthrough
- **useOnboardingCompletion**: Custom hook for tracking completion status and loading states
- **OnboardingWalkthrough**: Core walkthrough component from the design system
- **Navigation handlers**: Callback functions for routing to different setup pages
- **Step configurations**: Array of onboarding steps with icons, descriptions, and actions

## Usage Example

```typescript
import { OnboardingSection } from './onboarding-section'

function Dashboard() {
  return (
    <div className="dashboard">
      <h1>Welcome to OpenFrame</h1>
      <OnboardingSection />
    </div>
  )
}
```

The component automatically tracks completion status through the `useOnboardingCompletion` hook and provides navigation to relevant configuration pages. Each step includes contextual icons from the design system and appropriate action handlers that either navigate to internal pages or open external resources like the knowledge base.
