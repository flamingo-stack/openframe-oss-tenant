A React component that renders the main dashboard onboarding walkthrough, guiding users through essential setup steps for the OpenFrame platform including organizations, devices, team management, SSO configuration, and knowledge base access.

## Key Components

- **OnboardingSection**: Main component that orchestrates the onboarding flow
- **useOnboardingCompletion**: Hook for tracking completion status across steps
- **OnboardingWalkthrough**: Core walkthrough component from the design system
- **Navigation handlers**: Callback functions for routing to different setup pages
- **Step configuration**: Array defining each onboarding step with icons, descriptions, and actions

## Usage Example

```typescript
import { OnboardingSection } from './components/onboarding-section'

export default function DashboardPage() {
  return (
    <div className="dashboard">
      <h1>Welcome to OpenFrame</h1>
      <OnboardingSection />
    </div>
  )
}
```

The component automatically tracks completion status and provides navigation to:
- `/organizations/edit/new` for organization setup
- `/devices/new` for device management
- `/settings?tab=company-and-users` for team configuration
- `/settings?tab=sso-configuration` for SSO setup
- External knowledge base at `flamingo.run/knowledge-base`

Each step includes contextual icons from the design system and maintains completion state through the `storageKey` "openframe-dashboard-onboarding".
