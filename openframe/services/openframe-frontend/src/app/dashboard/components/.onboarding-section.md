A React component that provides an interactive onboarding walkthrough for new users in the OpenFrame dashboard, guiding them through essential setup steps like organizations, device management, team configuration, SSO setup, and knowledge base access.

## Key Components

- **OnboardingSection**: Main component that renders the onboarding walkthrough
- **OnboardingWalkthrough**: Core walkthrough component from `@flamingo-stack/openframe-frontend-core`
- **useOnboardingCompletion**: Custom hook for tracking completion status
- **Navigation handlers**: Callback functions for each onboarding step action

## Key Features

- **Five onboarding steps**: Organizations setup, device management, team configuration, SSO configuration, and knowledge base access
- **Smart completion tracking**: Uses existing dashboard hooks to avoid duplicate API calls
- **Seamless navigation**: Routes users to appropriate pages or external resources
- **Consistent UI**: Leverages shared icons and components from the core library

## Usage Example

```typescript
import { OnboardingSection } from './onboarding-section'

export default function DashboardPage() {
  return (
    <div className="dashboard">
      <h1>Welcome to OpenFrame</h1>
      <OnboardingSection />
    </div>
  )
}
```

The component automatically tracks completion status and provides interactive buttons that navigate users to the appropriate configuration pages or external resources like the knowledge base.
