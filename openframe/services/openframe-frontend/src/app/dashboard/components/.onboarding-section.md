A React component that provides an interactive onboarding walkthrough for the OpenFrame dashboard, guiding users through key setup tasks including organizations, devices, team management, SSO configuration, and knowledge base access.

## Key Components

- **OnboardingSection**: Main component that renders the onboarding walkthrough
- **onboardingSteps**: Configuration array defining each onboarding step with icons, descriptions, and actions
- **Navigation handlers**: Callback functions for routing to different setup pages
- **useOnboardingCompletion**: Custom hook for tracking completion status across steps

## Usage Example

```typescript
import { OnboardingSection } from './onboarding-section'

export default function DashboardPage() {
  return (
    <div className="dashboard">
      <h1>Welcome to OpenFrame</h1>
      <OnboardingSection />
    </div>
  )
}
```

The component automatically handles:
- Step completion tracking via the `useOnboardingCompletion` hook
- Navigation to appropriate pages for each setup task
- External link opening for the knowledge base
- Loading states during completion status checks
- Persistent storage of onboarding progress using the "openframe-dashboard-onboarding" key

Each step includes contextual icons from the OpenFrame design system and routes users to the relevant configuration pages within the application.
