A React dashboard component that displays an overview of device statistics with online/offline status cards and loading states.

## Key Components

- **DevicesOverviewSection** - Main component that renders device overview statistics
- **useDevicesOverview** - Custom hook for fetching device data
- **DashboardInfoCard** - Reusable card component for displaying metrics
- **Skeleton** - Loading placeholder component

## Usage Example

```typescript
import { DevicesOverviewSection } from './devices-overview'

export function Dashboard() {
  return (
    <div className="dashboard">
      <DevicesOverviewSection />
    </div>
  )
}
```

The component fetches device statistics through the `useDevicesOverview` hook and displays:
- Total device count
- Online devices with percentage and link to filtered view
- Offline devices with percentage and link to filtered view

During loading, skeleton placeholders maintain the layout structure. The component uses responsive grid layouts (1 column on mobile, 2 on tablet, 3 on desktop) and includes navigation links to filtered device views via query parameters.
