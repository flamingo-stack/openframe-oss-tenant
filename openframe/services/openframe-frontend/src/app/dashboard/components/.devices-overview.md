A React component that displays a comprehensive devices overview dashboard section with online/offline statistics and navigation links.

## Key Components

- **DevicesOverviewSection** - Main component that renders the devices overview dashboard
- **useDevicesOverview** - Custom hook for fetching device statistics data
- **DashboardInfoCard** - Reusable card component for displaying device metrics
- **Skeleton** - Loading state component for better UX

## Usage Example

```typescript
import { DevicesOverviewSection } from './devices-overview'

function DashboardPage() {
  return (
    <div className="dashboard">
      <DevicesOverviewSection />
    </div>
  )
}
```

The component automatically handles loading states with skeleton placeholders and displays:
- Total device count with formatted numbers
- Online devices with percentage and progress indicator
- Offline devices with percentage and progress indicator
- Clickable cards that navigate to filtered device lists

Each info card includes a `href` prop that links to the devices page with appropriate status filters (`/devices?statuses=ONLINE` or `/devices?statuses=OFFLINE`), enabling seamless navigation to detailed device views.
