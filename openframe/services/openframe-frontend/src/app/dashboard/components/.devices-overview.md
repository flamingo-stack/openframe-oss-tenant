A React component that displays a comprehensive devices overview dashboard section with online/offline statistics and navigation links.

## Key Components

- **DevicesOverviewSection** - Main component that renders the devices overview dashboard
- **useDevicesOverview** - Custom hook for fetching device statistics data
- **DashboardInfoCard** - Reusable card component for displaying metrics with progress indicators
- **Skeleton** - Loading state component for better user experience

## Usage Example

```typescript
import { DevicesOverviewSection } from './devices-overview'

// Basic usage in a dashboard
export function Dashboard() {
  return (
    <div className="dashboard">
      <DevicesOverviewSection />
    </div>
  )
}
```

The component automatically handles loading states with skeleton placeholders and displays device metrics in a responsive grid layout. Each metric card includes clickable navigation to filtered device views (online/offline) and shows percentage-based progress indicators. The design uses the Flamingo design system with Azeret Mono and DM Sans fonts, featuring responsive breakpoints for mobile, tablet, and desktop layouts.
