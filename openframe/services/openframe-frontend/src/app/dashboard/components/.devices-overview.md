A React component that displays a comprehensive devices overview section with online/offline statistics for the OpenFrame MSP platform dashboard.

## Key Components

- **DevicesOverviewSection** - Main export component that renders device statistics with loading states
- **useDevicesOverview** - Custom hook for fetching device overview data
- **DashboardInfoCard** - Reusable card component for displaying device metrics
- **Skeleton** - Loading placeholder component from the core UI library

## Usage Example

```typescript
import { DevicesOverviewSection } from './devices-overview'

export function DashboardPage() {
  return (
    <div className="dashboard-container">
      <DevicesOverviewSection />
    </div>
  )
}
```

The component automatically handles loading states with skeleton placeholders and displays device statistics in a responsive grid layout. It shows total device count, online/offline breakdowns with percentages, and includes navigation links to filtered device views. The component uses Flamingo's design system with Azeret Mono font for headings and DM Sans for body text, following the OpenFrame visual identity.
