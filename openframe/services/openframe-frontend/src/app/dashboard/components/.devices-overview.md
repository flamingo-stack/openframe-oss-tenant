A React component that renders a dashboard section displaying device statistics overview with online/offline status cards and loading states.

## Key Components

- **DevicesOverviewSection** - Main component that displays device overview statistics
- **useDevicesOverview** - Custom hook for fetching device statistics data
- **DashboardInfoCard** - Reusable card component for displaying metrics with progress indicators
- **Skeleton** - Loading placeholder component for better UX

## Usage Example

```typescript
import { DevicesOverviewSection } from './devices-overview'

function DashboardPage() {
  return (
    <div className="dashboard">
      <DevicesOverviewSection />
    </div>
  )
}
```

The component features:
- **Loading State**: Shows skeleton placeholders while data loads
- **Responsive Grid**: Cards adapt from 1 column on mobile to 3 on desktop
- **Interactive Cards**: Each status card links to filtered device views
- **Progress Indicators**: Visual percentage bars for online/offline ratios
- **Typography**: Uses Flamingo's design system fonts (Azeret Mono, DM Sans)

The hook provides `devices.total`, `devices.active/inactive` counts, and calculated percentages for the progress indicators.
