A React component that displays an overview of device statistics with online/offline counts and percentages on the OpenFrame dashboard.

## Key Components

- **DevicesOverviewSection**: Main component that renders device statistics with loading states
- **useDevicesOverview**: Custom hook for fetching device overview data
- **DashboardInfoCard**: Reusable card component for displaying metrics with progress indicators
- **Skeleton**: Loading placeholder component from the OpenFrame core library

## Usage Example

```typescript
import { DevicesOverviewSection } from './devices-overview'

function DashboardPage() {
  return (
    <div className="dashboard-container">
      <DevicesOverviewSection />
    </div>
  )
}
```

The component handles three states:
1. **Loading**: Shows skeleton placeholders while data is being fetched
2. **Loaded**: Displays total device count and two cards showing online/offline statistics with clickable links to filtered device lists
3. **Responsive Layout**: Uses CSS Grid to adapt from single column on mobile to three columns on larger screens

Each device status card includes a percentage calculation and links to filtered device views (`/devices?statuses=ONLINE` or `/devices?statuses=OFFLINE`), making it easy for MSP technicians to quickly navigate to specific device categories.
