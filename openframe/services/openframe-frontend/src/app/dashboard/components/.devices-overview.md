A React component that displays a comprehensive devices overview dashboard section with online/offline statistics and loading states.

## Key Components

- **DevicesOverviewSection** - Main component that renders devices statistics with responsive grid layout
- **useDevicesOverview** - Custom hook for fetching device statistics data
- **DashboardInfoCard** - Reusable card component for displaying device metrics with progress indicators
- **Skeleton** - Loading placeholder component for improved UX during data fetching

## Usage Example

```typescript
import { DevicesOverviewSection } from './devices-overview'

export function DashboardPage() {
  return (
    <div className="dashboard-container">
      <DevicesOverviewSection />
      {/* Other dashboard sections */}
    </div>
  )
}

// The component automatically handles:
// - Loading states with skeleton placeholders
// - Device count totals with proper formatting
// - Online/offline statistics with percentages
// - Clickable cards that navigate to filtered device lists
```

The component features a responsive grid layout (1 column on mobile, 2 on tablet, 3 on desktop) and uses Flamingo's design system with Azeret Mono font for headings and DM Sans for body text. Each statistics card includes progress bars and links to filtered device views for deeper exploration.
