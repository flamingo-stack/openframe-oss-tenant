A React component that displays a dashboard section showing device statistics with online/offline counts, loading states, and navigation links to filtered device views.

## Key Components

- **DevicesOverviewSection**: Main component that renders device overview statistics
- **useDevicesOverview**: Custom hook for fetching device statistics data
- **DashboardInfoCard**: Reusable card component displaying metrics with progress indicators
- **Skeleton**: Loading placeholder component for improved UX during data fetching

## Usage Example

```typescript
import { DevicesOverviewSection } from './devices-overview'

// Use in a dashboard layout
function Dashboard() {
  return (
    <div className="dashboard-grid">
      <DevicesOverviewSection />
      {/* Other dashboard sections */}
    </div>
  )
}

// The component automatically handles:
// - Loading states with skeleton placeholders
// - Device count display with proper formatting
// - Clickable cards that navigate to filtered device lists
// - Responsive grid layout (1 col mobile, 2 col tablet, 3 col desktop)
```

The component uses Flamingo's design system with custom typography (Azeret Mono for headings, DM Sans for body text) and provides an intuitive overview of device status distribution with direct navigation to detailed views.
