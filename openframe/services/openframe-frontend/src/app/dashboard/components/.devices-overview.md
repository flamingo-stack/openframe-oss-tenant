A React component that displays an overview section of device statistics with online/offline status cards and loading states.

## Key Components

- **DevicesOverviewSection** - Main component that renders device statistics overview
- **useDevicesOverview** - Custom hook for fetching device statistics data
- **DashboardInfoCard** - Reusable card component for displaying key metrics
- **Skeleton** - Loading placeholder component from the core UI library

## Usage Example

```typescript
import { DevicesOverviewSection } from './devices-overview'

export function Dashboard() {
  return (
    <div className="dashboard">
      <DevicesOverviewSection />
    </div>
  )
}
```

The component automatically handles loading states with skeleton placeholders and displays device statistics in a responsive grid layout. It shows total device count, online devices with percentage, and offline devices with percentage. Each status card is clickable and navigates to filtered device lists. The component uses Flamingo's design system with custom fonts (Azeret Mono, DM Sans) and semantic color tokens.
