A React component that displays an overview dashboard section showing device statistics including total count, online/offline status, and percentage breakdowns.

## Key Components

- **DevicesOverviewSection** - Main component that renders the devices overview dashboard
- **useDevicesOverview** - Custom hook that fetches device statistics data
- **DashboardInfoCard** - Reusable card component for displaying metrics with progress indicators
- **Skeleton** - Loading placeholder component for better UX during data fetching

## Usage Example

```typescript
import { DevicesOverviewSection } from './devices-overview'

export function Dashboard() {
  return (
    <div className="dashboard-container">
      <DevicesOverviewSection />
      {/* Other dashboard sections */}
    </div>
  )
}
```

The component automatically handles loading states with skeleton placeholders and displays device metrics in a responsive grid layout. Each metric card links to filtered device views (e.g., `/devices?statuses=ONLINE`) for detailed exploration. The component uses Flamingo's design system with custom fonts (Azeret Mono, DM Sans) and OpenFrame design tokens for consistent styling.
