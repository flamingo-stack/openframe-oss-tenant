A React component that displays an overview section for devices in a dashboard, showing total device count and status breakdown with loading states.

## Key Components

- **DevicesOverviewSection** - Main component that renders device statistics with online/offline status cards
- **useDevicesOverview** - Custom hook for fetching device overview data
- **DashboardInfoCard** - Reusable card component for displaying device metrics with progress indicators
- **Skeleton** - Loading placeholder component from the core UI library

## Usage Example

```typescript
import { DevicesOverviewSection } from './devices-overview'

export function Dashboard() {
  return (
    <div className="dashboard">
      <DevicesOverviewSection />
      {/* Other dashboard sections */}
    </div>
  )
}
```

The component automatically handles loading states with skeleton placeholders and displays device statistics in a responsive grid layout. Each status card includes the device count, percentage, and links to filtered device views (e.g., `/devices?statuses=ONLINE`). The component uses the Flamingo Stack design system with Azeret Mono font for headings and proper spacing utilities.
