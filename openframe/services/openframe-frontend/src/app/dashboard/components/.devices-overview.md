A React component that displays a comprehensive devices overview dashboard section with online/offline statistics and navigation capabilities.

## Key Components

- **`DevicesOverviewSection`** - Main component that renders device statistics overview
- **Loading State** - Skeleton components displayed during data fetching
- **Statistics Display** - Total device count with formatted numbers
- **Interactive Cards** - Clickable cards showing online/offline device counts with percentages

## Usage Example

```typescript
import { DevicesOverviewSection } from './devices-overview'

function DashboardPage() {
  return (
    <div className="dashboard">
      <DevicesOverviewSection />
    </div>
  )
}
```

The component automatically fetches device data using the `useDevicesOverview` hook and displays:
- Total device count with proper number formatting
- Online devices with percentage and progress indicator
- Offline devices with percentage and progress indicator
- Clickable cards that navigate to filtered device lists
- Loading skeletons while data is being fetched

Each device status card includes a `href` prop that navigates to the devices page with appropriate status filters applied.
