A React component that displays an overview of device statistics in a dashboard layout, showing total devices with online/offline breakdowns and loading states.

## Key Components

- **DevicesOverviewSection** - Main component that renders device statistics with responsive grid layout
- **useDevicesOverview** - Custom hook that provides device statistics and loading state
- **DashboardInfoCard** - Reusable card component for displaying metrics with optional progress indicators
- **Skeleton** - Loading placeholder component for better UX during data fetching

## Usage Example

```typescript
import { DevicesOverviewSection } from './devices-overview'

// Use in a dashboard page
export function Dashboard() {
  return (
    <div className="p-6">
      <DevicesOverviewSection />
    </div>
  )
}

// The component automatically handles loading states and renders:
// - Section title with device count
// - Grid of cards showing online/offline statistics
// - Clickable cards that navigate to filtered device views
```

The component uses Tailwind CSS for responsive design (1 column on mobile, 2 on tablet, 3 on desktop) and implements the Flamingo design system typography with Azeret Mono and DM Sans fonts. Each metric card includes a progress indicator and links to filtered device lists for deeper exploration.
