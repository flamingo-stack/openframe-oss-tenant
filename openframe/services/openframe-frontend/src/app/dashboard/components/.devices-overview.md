A React component that displays a dashboard overview of device statistics with online/offline status cards and loading states.

## Key Components

- **DevicesOverviewSection** - Main component that renders device overview statistics
- **useDevicesOverview** - Custom hook for fetching device statistics data
- **DashboardInfoCard** - Reusable card component for displaying device metrics
- **Skeleton** - Loading placeholder component for improved UX

## Features

- **Responsive Grid Layout** - Adapts from 1 column on mobile to 3 columns on large screens
- **Loading States** - Shows skeleton placeholders while data is being fetched
- **Navigation Links** - Cards link to filtered device views (`/devices?statuses=ONLINE/OFFLINE`)
- **Percentage Indicators** - Displays progress bars showing online/offline percentages
- **Formatted Numbers** - Uses locale-specific number formatting for device counts

## Usage Example

```typescript
import { DevicesOverviewSection } from './devices-overview'

function Dashboard() {
  return (
    <div className="dashboard">
      <DevicesOverviewSection />
    </div>
  )
}
```

The component automatically handles loading states and provides clickable cards that navigate to filtered device lists, making it ideal for MSP dashboards where technicians need quick access to device status information.
