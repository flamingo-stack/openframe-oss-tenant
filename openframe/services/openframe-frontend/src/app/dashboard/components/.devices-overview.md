A React component that displays an overview of device statistics in a dashboard layout, showing total device count and status breakdowns with loading states.

## Key Components

- **`DevicesOverviewSection`** - Main component that renders device overview statistics with responsive grid layout
- **Loading State** - Skeleton placeholders during data fetching
- **Device Statistics Display** - Shows total devices count and status-based breakdowns (online/offline)
- **Interactive Cards** - Clickable cards that navigate to filtered device views

## Usage Example

```typescript
import { DevicesOverviewSection } from './devices-overview'

export function Dashboard() {
  return (
    <div className="dashboard">
      <DevicesOverviewSection />
    </div>
  )
}
```

The component uses the `useDevicesOverview` hook to fetch device statistics and renders them using `DashboardInfoCard` components from the OpenFrame frontend core library. It includes responsive design with different grid layouts for mobile, tablet, and desktop viewports. During loading, skeleton components provide visual feedback to users.
