A React component that displays a comprehensive overview of chat statistics in a dashboard layout with loading states and interactive cards.

## Key Components

- **`ChatsOverviewSection`** - Main component that renders chat metrics in a responsive grid layout
- **`useChatsOverview`** - Custom hook that provides chat statistics and loading state
- **`DashboardInfoCard`** - Reusable card component for displaying individual metrics
- **`Skeleton`** - Loading placeholder component for improved UX

## Usage Example

```typescript
import { ChatsOverviewSection } from './components/chats-overview'

function Dashboard() {
  return (
    <div className="dashboard">
      <ChatsOverviewSection />
    </div>
  )
}
```

The component automatically handles loading states with skeleton placeholders and displays four key metrics:
- Active chats with percentage and progress bar
- Resolved chats with percentage and progress bar  
- Average resolution time
- Average Fae rating (out of 5)

All cards link to `/mingo` for detailed chat management. The layout is fully responsive, adapting from single column on mobile to 4 columns on large screens.
