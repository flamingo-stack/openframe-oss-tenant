A React component that displays a comprehensive overview of chat statistics for the Flamingo MSP platform, showing active chats, resolution metrics, and AI assistant performance data in a responsive dashboard layout.

## Key Components

- **ChatsOverviewSection** - Main export component that renders the complete chats overview dashboard
- **useChatsOverview** - Custom hook for fetching chat statistics and metrics data
- **DashboardInfoCard** - Reusable card component for displaying individual metrics with optional progress indicators
- **Skeleton** - Loading state components that maintain layout during data fetching

## Usage Example

```typescript
import { ChatsOverviewSection } from './chats-overview'

export function DashboardPage() {
  return (
    <div className="dashboard-container">
      <ChatsOverviewSection />
    </div>
  )
}

// The component automatically handles:
// - Loading states with skeleton placeholders
// - Responsive grid layout (1 col mobile, 2 col tablet, 4 col desktop)
// - Navigation to /mingo route on card interactions
// - Percentage calculations for active/resolved chat ratios
```

The component features a clean loading state with skeleton placeholders and renders four key metrics: active chats, resolved chats, average resolution time, and average Fae AI rating. All metric cards link to the main Mingo AI interface for detailed chat management.
