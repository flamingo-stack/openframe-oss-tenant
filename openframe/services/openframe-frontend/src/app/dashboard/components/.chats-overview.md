A React component that renders a dashboard section displaying chat analytics and metrics overview for the Flamingo MSP platform.

## Key Components

- **ChatsOverviewSection** - Main component that displays chat statistics in a grid layout
- **useChatsOverview** - Custom hook for fetching chat analytics data
- **DashboardInfoCard** - Reusable card component for displaying individual metrics
- **Skeleton** - Loading placeholder components for better UX

## Usage Example

```typescript
import { ChatsOverviewSection } from './chats-overview'

export function Dashboard() {
  return (
    <div className="dashboard">
      <ChatsOverviewSection />
    </div>
  )
}
```

The component automatically handles loading states with skeleton placeholders and renders a 4-column grid (responsive) showing:
- Active chats count with percentage
- Resolved chats with percentage  
- Average resolution time
- Average Fae (AI assistant) rating

All metrics cards link to the `/mingo` route for detailed chat management. The component uses the OpenFrame design system with Azeret Mono font for headings and includes proper loading states for optimal user experience.
