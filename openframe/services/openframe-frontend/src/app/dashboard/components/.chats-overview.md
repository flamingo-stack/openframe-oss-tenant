A React component that displays a comprehensive chat analytics dashboard with key metrics and statistics for the Flamingo MSP platform's chat system.

## Key Components

- **`ChatsOverviewSection`** - Main component that renders chat statistics in a responsive grid layout
- **Loading State Handler** - Shows skeleton placeholders while data is fetching
- **Dashboard Cards** - Displays active chats, resolved chats, average resolve time, and Fae rating metrics
- **Custom Hook Integration** - Uses `useChatsOverview()` for data management

## Usage Example

```typescript
import { ChatsOverviewSection } from './chats-overview'

// Display chat analytics dashboard
function DashboardPage() {
  return (
    <div className="p-6">
      <ChatsOverviewSection />
    </div>
  )
}

// The component automatically handles:
// - Loading states with skeleton UI
// - Responsive grid layout (1 col mobile, 2 col tablet, 4 col desktop)
// - Formatted metrics display with percentages and progress bars
// - Navigation links to /mingo for detailed views
```

The component provides a clean overview of chat system performance with metrics like active/resolved chat counts, average resolution time, and Fae AI assistant ratings, all styled with the Flamingo design system using Azeret Mono and DM Sans fonts.
