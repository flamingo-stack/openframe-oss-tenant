React component that displays a comprehensive dashboard overview of chat statistics for the Mingo AI support system, including active chats, resolution metrics, and performance indicators with loading states.

## Key Components

- **ChatsOverviewSection** - Main component that renders chat statistics in a grid layout with conditional loading states
- **useChatsOverview** - Custom hook for fetching chat overview data
- **DashboardInfoCard** - Reusable card component for displaying individual metrics
- **Skeleton** - Loading placeholder component

## Usage Example

```typescript
import { ChatsOverviewSection } from './chats-overview'

function DashboardPage() {
  return (
    <div className="dashboard-container">
      <ChatsOverviewSection />
    </div>
  )
}

// The component automatically handles:
// - Loading states with skeleton placeholders
// - Responsive grid layout (1-4 columns)
// - Formatted statistics display
// - Navigation links to /mingo for detailed views
```

The component displays four key metrics: active chats count with percentage, resolved chats with completion rate, average resolution time, and average Fae (AI assistant) rating. All cards link to the `/mingo` route for detailed chat management. The layout is fully responsive and includes proper loading states with skeleton animations while data is being fetched.
