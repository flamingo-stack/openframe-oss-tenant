A React component that displays a comprehensive overview of chat statistics and metrics in a dashboard layout with loading states and responsive design.

## Key Components

- **ChatsOverviewSection** - Main component that renders chat statistics dashboard
- **useChatsOverview** - Custom hook for fetching chat overview data
- **DashboardInfoCard** - Reusable card component for displaying metrics
- **Skeleton** - Loading placeholder component

## Usage Example

```typescript
import { ChatsOverviewSection } from './chats-overview'

function Dashboard() {
  return (
    <div className="dashboard">
      <ChatsOverviewSection />
    </div>
  )
}
```

The component fetches chat data using the `useChatsOverview` hook and displays:
- Total chat count with localized formatting
- Active chats with percentage and progress indicator
- Resolved chats with percentage and progress indicator
- Average resolution time
- Average Fae rating (out of 5)

During loading states, it shows skeleton placeholders matching the final layout. All metric cards link to the `/mingo` route and use responsive grid layouts (1 column on mobile, 2 on tablet, 4 on desktop). The component follows Flamingo's design system with Azeret Mono font for headings and DM Sans for body text.
