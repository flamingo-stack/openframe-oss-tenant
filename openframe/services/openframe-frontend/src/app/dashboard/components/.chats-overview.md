A React component that displays a comprehensive dashboard overview of chat statistics with loading states and responsive grid layout.

## Key Components

- **`ChatsOverviewSection`** - Main component that renders chat statistics dashboard
- **Loading State** - Skeleton placeholders during data fetching
- **Statistics Grid** - Responsive layout displaying key chat metrics
- **Data Hook Integration** - Uses `useChatsOverview` for real-time data

## Usage Example

```typescript
import { ChatsOverviewSection } from './chats-overview'

function Dashboard() {
  return (
    <div className="dashboard">
      <ChatsOverviewSection />
    </div>
  )
}
```

The component displays four key metrics in `DashboardInfoCard` components:
- **Active Chats** - Current ongoing conversations with percentage
- **Resolved Chats** - Completed conversations with resolution rate
- **Average Resolve Time** - Mean time to resolution
- **Average Fae Rate** - Customer satisfaction rating out of 5

Each card links to `/mingo` for detailed views. The layout is responsive, showing 1 column on mobile, 2 on tablets, and 4 on desktop. During loading, skeleton components maintain visual consistency while data fetches.
