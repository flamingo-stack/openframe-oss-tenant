A React component that displays a comprehensive overview of chat statistics in the Flamingo dashboard, including active/resolved chats, resolution times, and Fae AI ratings with loading states and responsive layout.

## Key Components

- **ChatsOverviewSection** - Main component that renders the chat statistics dashboard
- **useChatsOverview** - Custom hook for fetching chat overview data
- **DashboardInfoCard** - Reusable card component for displaying metrics
- **Skeleton** - Loading placeholder component

## Key Features

- **Loading States** - Displays skeleton placeholders while data loads
- **Responsive Grid** - Adapts from single column on mobile to 4 columns on large screens
- **Interactive Cards** - All metric cards link to `/mingo` for detailed views
- **Progress Indicators** - Shows percentage progress for active and resolved chats
- **Custom Typography** - Uses Azeret Mono and DM Sans fonts matching OpenFrame design system

## Usage Example

```typescript
import { ChatsOverviewSection } from './chats-overview'

export function DashboardPage() {
  return (
    <div className="dashboard">
      <ChatsOverviewSection />
      {/* Other dashboard sections */}
    </div>
  )
}
```

The component automatically handles data fetching, loading states, and error handling through the `useChatsOverview` hook. It displays key metrics like total chats, active/resolved counts with percentages, average resolution time, and average Fae AI rating out of 5.
