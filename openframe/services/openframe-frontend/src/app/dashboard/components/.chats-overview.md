A React component that displays an overview of chat statistics in the OpenFrame dashboard, showing key metrics like active chats, resolved chats, and performance indicators.

## Key Components

- **ChatsOverviewSection** - Main component that renders the chats overview dashboard section
- **useChatsOverview** - Custom hook for fetching chat statistics data
- **DashboardInfoCard** - Reusable card component for displaying individual metrics
- **Skeleton** - Loading state component from the OpenFrame core library

## Usage Example

```typescript
import { ChatsOverviewSection } from './chats-overview'

export function Dashboard() {
  return (
    <div className="dashboard">
      <ChatsOverviewSection />
      {/* Other dashboard sections */}
    </div>
  )
}
```

The component automatically handles loading states with skeleton placeholders and displays a responsive grid of metric cards. Each card shows different chat-related statistics including active chats, resolved chats, average resolve time, and average Fae rating. All cards link to the `/mingo` route for detailed views. The component uses OpenFrame's design system with custom typography (Azeret Mono, DM Sans) and responsive grid layouts.
