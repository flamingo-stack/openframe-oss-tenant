A React component that displays a comprehensive dashboard overview of chat statistics and metrics for the Flamingo/OpenFrame MSP platform.

## Key Components

- **`ChatsOverviewSection`** - Main component that renders chat statistics dashboard
- **Loading State** - Skeleton placeholders while data loads
- **Stats Grid** - Four-card layout showing key chat metrics
- **`useChatsOverview`** - Custom hook for fetching chat data
- **`DashboardInfoCard`** - Reusable card component for displaying metrics

## Usage Example

```typescript
import { ChatsOverviewSection } from './chats-overview'

function Dashboard() {
  return (
    <div className="dashboard">
      <ChatsOverviewSection />
    </div>
  )
}

// The component displays:
// - Total chat count with summary text
// - Active chats with percentage and progress indicator
// - Resolved chats with percentage and progress indicator  
// - Average resolution time metric
// - Average Fae (AI assistant) rating out of 5
```

The component uses the OpenFrame design system with custom typography (Azeret Mono, DM Sans) and provides responsive grid layout that adapts from single column on mobile to 4 columns on large screens. Each metric card links to the `/mingo` route for detailed chat management.
