A React component that displays a comprehensive overview of chat statistics in a dashboard format, presenting key metrics like active chats, resolved chats, average resolution time, and Fae ratings in an organized grid layout.

## Key Components

- **ChatsOverviewSection** - Main component that renders chat statistics dashboard
- **useChatsOverview** - Custom hook for fetching chat overview data
- **DashboardInfoCard** - Reusable card component for displaying individual metrics
- **Skeleton** - Loading state component from the OpenFrame core library

## Usage Example

```typescript
import { ChatsOverviewSection } from './chats-overview'

export default function DashboardPage() {
  return (
    <div className="dashboard-container">
      <ChatsOverviewSection />
    </div>
  )
}
```

The component automatically handles loading states with skeleton placeholders and displays four key metrics in responsive grid cards:
- Active chats count with percentage progress
- Resolved chats count with percentage progress  
- Average resolution time
- Average Fae rating (out of 5)

All metric cards are clickable and navigate to the `/mingo` route for detailed chat management.
