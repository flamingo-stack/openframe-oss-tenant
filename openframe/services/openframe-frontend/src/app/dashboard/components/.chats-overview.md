A React component that displays a comprehensive overview of chat statistics and metrics in a dashboard format, featuring loading states and responsive grid layout.

## Key Components

- **ChatsOverviewSection**: Main component that renders chat statistics with loading skeleton and data visualization
- **useChatsOverview**: Custom hook for fetching chat overview data (imported from hooks)
- **DashboardInfoCard**: Reusable card component for displaying individual metrics
- **Skeleton**: Loading placeholder component for improved UX

## Usage Example

```typescript
import { ChatsOverviewSection } from './chats-overview'

function Dashboard() {
  return (
    <div className="dashboard">
      <ChatsOverviewSection />
    </div>
  )
}

// The component automatically handles:
// - Loading states with skeleton placeholders
// - Responsive grid layout (1/2/4 columns)
// - Chat metrics display (active, resolved, avg times, ratings)
// - Navigation links to /mingo for detailed views
```

The component provides a clean interface for monitoring chat performance metrics including active chats, resolution rates, average resolve times, and Fae AI ratings. It uses Tailwind CSS for styling and includes proper loading states for optimal user experience.
