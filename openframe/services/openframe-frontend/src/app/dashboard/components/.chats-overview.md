A client-side React component that displays a comprehensive overview of chat statistics in a dashboard layout with loading states and responsive grid cards.

## Key Components

- **ChatsOverviewSection**: Main component that renders chat statistics overview
- **useChatsOverview**: Custom hook for fetching chat overview data
- **DashboardInfoCard**: Reusable card component for displaying metrics
- **Skeleton**: Loading placeholder component

## Usage Example

```typescript
import { ChatsOverviewSection } from './chats-overview'

export function Dashboard() {
  return (
    <div className="dashboard-container">
      <ChatsOverviewSection />
    </div>
  )
}
```

The component automatically handles loading states with skeleton placeholders and displays four key metrics in a responsive grid:
- Active chats count with percentage and progress indicator
- Resolved chats count with percentage and progress indicator  
- Average resolution time
- Average Fae rating score

All metric cards link to `/mingo` for detailed views. The layout adapts from single column on mobile to 4 columns on large screens, with typography using the Azeret Mono and DM Sans font families consistent with the OpenFrame design system.
