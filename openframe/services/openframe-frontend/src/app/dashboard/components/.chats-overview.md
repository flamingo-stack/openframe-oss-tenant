A React client component that displays a comprehensive dashboard overview of chat statistics for the Flamingo MSP platform, including active and resolved chat metrics with loading states.

## Key Components

- **ChatsOverviewSection**: Main component that renders chat statistics in a responsive grid layout
- **useChatsOverview**: Custom hook for fetching and managing chat statistics data
- **DashboardInfoCard**: Reusable card component for displaying individual metrics
- **Skeleton**: Loading placeholder component for improved user experience

## Usage Example

```typescript
import { ChatsOverviewSection } from './chats-overview'

export function DashboardPage() {
  return (
    <div className="p-6">
      <ChatsOverviewSection />
    </div>
  )
}

// The component automatically handles loading states and displays:
// - Total chats count
// - Active chats with percentage
// - Resolved chats with percentage  
// - Average resolve time
// - Average Fae rating
```

The component features responsive design (1-4 columns based on screen size), proper loading skeletons, and navigational links to the `/mingo` interface. It uses Flamingo's design system with Azeret Mono typography for headings and DM Sans for body text.
