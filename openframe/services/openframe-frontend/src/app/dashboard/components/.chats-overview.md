A dashboard component that displays comprehensive chat statistics in a responsive card grid layout, featuring active chats, resolution metrics, and performance indicators with loading states and navigation links.

## Key Components

- **ChatsOverviewSection** - Main React component that renders chat statistics dashboard
- **useChatsOverview** - Custom hook for fetching chat overview data (imported from hooks)
- **DashboardInfoCard** - Reusable card component for displaying individual metrics
- **Skeleton** - Loading placeholder component for improved UX

## Usage Example

```typescript
import { ChatsOverviewSection } from './chats-overview'

// Use in dashboard layout
export function MainDashboard() {
  return (
    <div className="dashboard-container">
      <ChatsOverviewSection />
      {/* Other dashboard sections */}
    </div>
  )
}

// The component automatically handles:
// - Loading states with skeleton placeholders
// - Responsive grid layout (1-2-4 columns)
// - Navigation to /mingo route on card clicks
// - Percentage calculations and progress indicators
```

The component provides a complete chat analytics overview with four key metrics: active chats with percentage, resolved chats with percentage, average resolution time, and average Fae (AI assistant) rating. It includes proper loading states and responsive design that adapts from single column on mobile to four columns on desktop.
