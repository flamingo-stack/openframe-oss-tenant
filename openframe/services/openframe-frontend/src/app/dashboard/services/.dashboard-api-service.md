A singleton service that provides centralized API operations for fetching dashboard statistics including device status metrics and chat analytics for the Flamingo MSP platform.

## Key Components

- **DashboardApiService**: Singleton class managing all dashboard data operations
- **dashboardApiService**: Exported singleton instance for application-wide use
- **fetchDeviceStats()**: Retrieves device counts and online/offline status breakdowns
- **fetchChatStats()**: Fetches chat dialog statistics including resolution times and ratings
- **DashboardDeviceStats**: Interface defining device metrics structure
- **DashboardChatStats**: Interface defining chat analytics structure

## Usage Example

```typescript
import { dashboardApiService } from '@/dashboard-api-service'

// Fetch device statistics
const deviceStats = await dashboardApiService.fetchDeviceStats()
console.log(`Total devices: ${deviceStats.total}`)
console.log(`Active: ${deviceStats.active} (${deviceStats.activePercentage}%)`)
console.log(`Inactive: ${deviceStats.inactive} (${deviceStats.inactivePercentage}%)`)

// Fetch chat statistics (SaaS mode)
const chatStats = await dashboardApiService.fetchChatStats()
console.log(`Total conversations: ${chatStats.total}`)
console.log(`Average resolve time: ${chatStats.avgResolveTime}`)
console.log(`Average Fae rating: ${chatStats.avgFaeRate}`)
```

The service uses GraphQL queries through the `apiClient` and includes comprehensive error handling with descriptive error messages for debugging dashboard data issues.
