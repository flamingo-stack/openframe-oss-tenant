A singleton service class that provides centralized API access for fetching dashboard statistics including device status counts and chat analytics for the Flamingo MSP platform.

## Key Components

- **DashboardApiService**: Singleton class with instance management and error handling
- **fetchDeviceStats()**: Retrieves device counts, online/offline status breakdown, and percentage calculations
- **fetchChatStats()**: Fetches chat dialog statistics including resolution times and Fae ratings for SaaS mode
- **DashboardDeviceStats**: Interface defining device statistics structure with totals and percentages
- **DashboardChatStats**: Interface for chat analytics including resolution metrics and rating data

## Usage Example

```typescript
import { dashboardApiService } from './dashboard-api-service'

// Fetch device statistics
const deviceStats = await dashboardApiService.fetchDeviceStats()
console.log(`${deviceStats.active}/${deviceStats.total} devices online (${deviceStats.activePercentage}%)`)

// Fetch chat statistics (SaaS mode)
const chatStats = await dashboardApiService.fetchChatStats()
console.log(`Average resolution time: ${chatStats.avgResolveTime}`)
console.log(`Fae rating: ${chatStats.avgFaeRate}/5.0`)

// Error handling
try {
  const stats = await dashboardApiService.fetchDeviceStats()
} catch (error) {
  console.error('Dashboard stats failed:', error.message)
}
```

The service uses GraphQL queries to efficiently fetch aggregated data and automatically calculates percentages for dashboard visualization components.
