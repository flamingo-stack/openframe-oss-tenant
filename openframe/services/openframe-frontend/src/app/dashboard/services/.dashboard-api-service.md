A singleton service that provides standardized API methods for fetching dashboard statistics including device and chat metrics through GraphQL queries.

## Key Components

### **DashboardApiService (Singleton)**
- `fetchDeviceStats()` - Retrieves device statistics with online/offline counts and percentages
- `fetchChatStats()` - Fetches chat statistics including resolution times and ratings for SaaS mode
- `handleApiError()` - Private error handling utility with context-aware messages

### **Type Definitions**
- `DashboardDeviceStats` - Device metrics with total, active/inactive counts and percentages
- `DashboardChatStats` - Chat metrics with dialog counts, resolution time, and FAE ratings
- Response interfaces for GraphQL data structure validation

### **Constants Integration**
- Uses `DEVICE_STATUS`, `DIALOG_STATUS` for status filtering
- Integrates with existing GraphQL queries from feature modules

## Usage Example

```typescript
import { dashboardApiService } from './dashboard-api-service'

// Fetch device statistics
const deviceStats = await dashboardApiService.fetchDeviceStats()
console.log(`${deviceStats.active}/${deviceStats.total} devices online (${deviceStats.activePercentage}%)`)

// Fetch chat statistics (SaaS mode)
const chatStats = await dashboardApiService.fetchChatStats()
console.log(`Average resolution time: ${chatStats.avgResolveTime}`)
console.log(`FAE rating: ${chatStats.avgFaeRate}/5`)

// Error handling
try {
  const stats = await dashboardApiService.fetchDeviceStats()
} catch (error) {
  console.error('Dashboard stats failed:', error.message)
}
```

The service uses the singleton pattern to ensure consistent API client usage and provides error handling with descriptive context for debugging dashboard data issues.
