A singleton service that fetches and processes dashboard statistics for devices and chat dialogs through GraphQL API calls, providing formatted metrics with percentage calculations for dashboard displays.

## Key Components

- **DashboardApiService** - Singleton class handling API requests for dashboard data
- **fetchDeviceStats()** - Retrieves device online/offline statistics with percentages
- **fetchChatStats()** - Fetches chat dialog statistics including resolution times and ratings
- **DashboardDeviceStats** - Interface for device metrics (total, active, inactive counts)
- **DashboardChatStats** - Interface for chat metrics (total, active, resolved, averages)
- **handleApiError()** - Private method for consistent error handling

## Usage Example

```typescript
import { dashboardApiService } from './dashboard-api-service'

// Fetch device statistics
try {
  const deviceStats = await dashboardApiService.fetchDeviceStats()
  console.log(`${deviceStats.active}/${deviceStats.total} devices online (${deviceStats.activePercentage}%)`)
} catch (error) {
  console.error('Failed to load device stats:', error.message)
}

// Fetch chat statistics (SaaS mode)
try {
  const chatStats = await dashboardApiService.fetchChatStats()
  console.log(`${chatStats.resolved} resolved tickets, avg time: ${chatStats.avgResolveTime}`)
} catch (error) {
  console.error('Failed to load chat stats:', error.message)
}
```

The service uses GraphQL queries to fetch data from `/api/graphql` for devices and `/chat/graphql` for chat statistics, automatically calculating percentages and handling API errors with descriptive messages.
