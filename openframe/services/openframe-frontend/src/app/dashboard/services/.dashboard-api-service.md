A singleton service class that provides API methods for fetching dashboard statistics including device status counts and chat/ticket metrics for the Flamingo MSP platform.

## Key Components

- **DashboardApiService** - Singleton service class for dashboard data fetching
- **DashboardDeviceStats** - Interface for device statistics with counts and percentages
- **DashboardChatStats** - Interface for chat/ticket statistics with resolution metrics
- **fetchDeviceStats()** - Method to get device online/offline counts via GraphQL
- **fetchChatStats()** - Method to get chat dialog statistics and resolution times
- **handleApiError()** - Private method for consistent error handling across API calls

## Usage Example

```typescript
import { dashboardApiService } from './dashboard-api-service'

// Fetch device statistics
const deviceStats = await dashboardApiService.fetchDeviceStats()
console.log(`Total devices: ${deviceStats.total}`)
console.log(`Active: ${deviceStats.active} (${deviceStats.activePercentage}%)`)

// Fetch chat statistics  
const chatStats = await dashboardApiService.fetchChatStats()
console.log(`Active chats: ${chatStats.active}`)
console.log(`Average resolve time: ${chatStats.avgResolveTime}`)
console.log(`Average FAE rating: ${chatStats.avgFaeRate}`)

// Error handling
try {
  const stats = await dashboardApiService.fetchDeviceStats()
} catch (error) {
  console.error('Failed to fetch dashboard stats:', error.message)
}
```

The service uses GraphQL queries to fetch aggregated statistics and calculates percentage values for dashboard display widgets.
