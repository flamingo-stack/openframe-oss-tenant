A singleton service that provides dashboard statistics by fetching device metrics and chat analytics through GraphQL queries. It centralizes data access for dashboard widgets and handles error management with type-safe responses.

## Key Components

- **`DashboardApiService`** - Singleton service class for dashboard data operations
- **`fetchDeviceStats()`** - Retrieves device counts and online/offline status breakdown
- **`fetchChatStats()`** - Fetches chat dialog statistics including resolution times and ratings
- **`DashboardDeviceStats`** - Interface for device metrics with calculated percentages
- **`DashboardChatStats`** - Interface for chat analytics including Fae ratings
- **`dashboardApiService`** - Exported singleton instance for application use

## Usage Example

```typescript
import { dashboardApiService } from './dashboard-api-service'

// Fetch device statistics
const deviceStats = await dashboardApiService.fetchDeviceStats()
console.log(`Active devices: ${deviceStats.active}/${deviceStats.total} (${deviceStats.activePercentage}%)`)

// Fetch chat statistics for SaaS mode
const chatStats = await dashboardApiService.fetchChatStats()
console.log(`Active chats: ${chatStats.active}, Avg resolve time: ${chatStats.avgResolveTime}`)
console.log(`Average Fae rating: ${chatStats.avgFaeRate}/5.0`)

// Error handling
try {
  const stats = await dashboardApiService.fetchDeviceStats()
  // Process stats...
} catch (error) {
  console.error('Dashboard stats failed:', error.message)
}
```

The service uses GraphQL queries to fetch data from `/api/graphql` for devices and `/chat/graphql` for chat statistics, providing structured responses with calculated percentages and formatted metrics for dashboard display.
