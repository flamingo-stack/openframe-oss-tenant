A singleton service that provides dashboard statistics by fetching device metrics and chat analytics from GraphQL endpoints. This service aggregates data from multiple sources to provide unified dashboard metrics with calculated percentages and formatted statistics.

## Key Components

- **DashboardApiService** - Singleton class handling dashboard data fetching
- **fetchDeviceStats()** - Retrieves device counts and calculates active/inactive percentages
- **fetchChatStats()** - Fetches chat dialog statistics with resolution times and ratings
- **DashboardDeviceStats** - Interface for device metric data structure
- **DashboardChatStats** - Interface for chat analytics data structure
- **handleApiError()** - Private error handling utility for consistent error formatting

## Usage Example

```typescript
import { dashboardApiService } from './dashboard-api-service'

// Fetch device statistics
const deviceStats = await dashboardApiService.fetchDeviceStats()
console.log(`${deviceStats.active} of ${deviceStats.total} devices online (${deviceStats.activePercentage}%)`)

// Fetch chat statistics (SaaS mode)
const chatStats = await dashboardApiService.fetchChatStats()
console.log(`${chatStats.resolved} dialogs resolved, avg time: ${chatStats.avgResolveTime}`)

// Error handling
try {
  const stats = await dashboardApiService.fetchDeviceStats()
} catch (error) {
  console.error('Dashboard stats failed:', error.message)
}
```

The service uses GraphQL queries to fetch filtered device counts by status and dialog statistics, then calculates percentages and formats the data for dashboard consumption. All API calls include proper error handling with descriptive error messages.
