A client-side service that provides dashboard statistics by fetching device and chat metrics through GraphQL API calls. It implements a singleton pattern to ensure consistent API access across the application.

## Key Components

**Main Service:**
- `DashboardApiService` - Singleton service class with error handling and GraphQL query execution
- `dashboardApiService` - Exported singleton instance

**Core Methods:**
- `fetchDeviceStats()` - Retrieves device counts and online/offline status breakdown
- `fetchChatStats()` - Fetches chat statistics including resolution times and ratings (SaaS mode)

**Type Definitions:**
- `DashboardDeviceStats` - Device metrics with total counts and percentages
- `DashboardChatStats` - Chat metrics with resolution data and Fae AI ratings

## Usage Example

```typescript
import { dashboardApiService } from './dashboard-api-service'

// Fetch device statistics
const deviceStats = await dashboardApiService.fetchDeviceStats()
console.log(`${deviceStats.active} of ${deviceStats.total} devices online (${deviceStats.activePercentage}%)`)

// Fetch chat statistics (SaaS mode)
const chatStats = await dashboardApiService.fetchChatStats()
console.log(`Average resolution time: ${chatStats.avgResolveTime}`)
console.log(`Fae AI rating: ${chatStats.avgFaeRate}/5`)

// Error handling
try {
  const stats = await dashboardApiService.fetchDeviceStats()
  // Handle successful response
} catch (error) {
  console.error('Failed to load dashboard stats:', error.message)
}
```

The service automatically calculates percentages, handles API errors with descriptive messages, and provides fallback values for missing data.
