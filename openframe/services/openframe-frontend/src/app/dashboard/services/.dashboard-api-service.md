A singleton service that handles dashboard statistics API calls for device and chat metrics in the Flamingo platform. It provides standardized interfaces for fetching device status counts and chat dialog statistics with proper error handling.

## Key Components

- **DashboardApiService**: Singleton class managing all dashboard-related API operations
- **fetchDeviceStats()**: Retrieves device counts and status breakdown (online/offline)
- **fetchChatStats()**: Fetches chat dialog statistics including resolution times and ratings
- **DashboardDeviceStats**: Interface for device metrics with percentages
- **DashboardChatStats**: Interface for chat metrics including Fae ratings

## Usage Example

```typescript
import { dashboardApiService } from './dashboard-api-service'

// Fetch device statistics
async function loadDeviceMetrics() {
  try {
    const deviceStats = await dashboardApiService.fetchDeviceStats()
    console.log(`Total devices: ${deviceStats.total}`)
    console.log(`Active: ${deviceStats.active} (${deviceStats.activePercentage}%)`)
    console.log(`Inactive: ${deviceStats.inactive} (${deviceStats.inactivePercentage}%)`)
  } catch (error) {
    console.error('Failed to load device stats:', error.message)
  }
}

// Fetch chat statistics (SaaS mode)
async function loadChatMetrics() {
  try {
    const chatStats = await dashboardApiService.fetchChatStats()
    console.log(`Total chats: ${chatStats.total}`)
    console.log(`Average Fae rating: ${chatStats.avgFaeRate}`)
    console.log(`Resolution time: ${chatStats.avgResolveTime}`)
  } catch (error) {
    console.error('Failed to load chat stats:', error.message)
  }
}
```

The service uses GraphQL queries to fetch data from both the main API (`/api/graphql`) for device statistics and the chat API (`/chat/graphql`) for dialog statistics, providing a unified interface for dashboard data consumption.
