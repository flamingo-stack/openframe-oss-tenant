A singleton service class that fetches and processes dashboard statistics for devices and chat dialogs using GraphQL queries through the Flamingo platform's API client.

## Key Components

**Main Service:**
- `DashboardApiService` - Singleton class with error handling and GraphQL operations
- `dashboardApiService` - Exported singleton instance

**Core Methods:**
- `fetchDeviceStats()` - Retrieves device counts and calculates online/offline percentages
- `fetchChatStats()` - Fetches chat dialog statistics including resolution times and ratings

**Types:**
- `DashboardDeviceStats` - Device statistics with totals and percentages
- `DashboardChatStats` - Chat statistics including Fae AI ratings and resolution metrics

## Usage Example

```typescript
import { dashboardApiService } from './dashboard-api-service'

// Fetch device statistics
const deviceStats = await dashboardApiService.fetchDeviceStats()
console.log(`${deviceStats.active} of ${deviceStats.total} devices online (${deviceStats.activePercentage}%)`)

// Fetch chat statistics for SaaS mode
const chatStats = await dashboardApiService.fetchChatStats()
console.log(`Average resolution time: ${chatStats.avgResolveTime}`)
console.log(`Fae AI rating: ${chatStats.avgFaeRate}/5.0`)

// Handle errors
try {
  const stats = await dashboardApiService.fetchDeviceStats()
} catch (error) {
  console.error('Dashboard stats failed:', error.message)
}
```

The service automatically calculates percentages, handles API errors with descriptive messages, and processes GraphQL responses into clean, typed data structures for dashboard display components.
