A singleton service class that provides API methods for fetching dashboard statistics including device status metrics and chat/dialog analytics for the MSP platform dashboard.

## Key Components

**Main Service:**
- `DashboardApiService` - Singleton service class with error handling
- `dashboardApiService` - Exported singleton instance

**Core Methods:**
- `fetchDeviceStats()` - Retrieves device counts and online/offline status breakdown
- `fetchChatStats()` - Fetches dialog statistics including resolution times and Fae ratings

**Type Definitions:**
- `DashboardDeviceStats` - Device metrics with counts and percentages
- `DashboardChatStats` - Chat statistics with resolution metrics

## Usage Example

```typescript
import { dashboardApiService } from './dashboard-api-service'

// Fetch device statistics
const deviceStats = await dashboardApiService.fetchDeviceStats()
console.log(`${deviceStats.active}/${deviceStats.total} devices online (${deviceStats.activePercentage}%)`)

// Fetch chat statistics (SaaS mode)
const chatStats = await dashboardApiService.fetchChatStats()
console.log(`Average Fae rating: ${chatStats.avgFaeRate}/5`)
console.log(`Average resolution time: ${chatStats.avgResolveTime}`)

// Handle errors
try {
  const stats = await dashboardApiService.fetchDeviceStats()
} catch (error) {
  console.error('Dashboard stats failed:', error.message)
}
```

The service integrates with GraphQL endpoints and provides formatted statistics with percentage calculations and error handling for dashboard widgets.
