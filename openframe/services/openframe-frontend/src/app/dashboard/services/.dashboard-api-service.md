A client-side API service that provides unified access to dashboard statistics for devices and chat dialogs in the Flamingo MSP platform. It implements the singleton pattern to ensure consistent data fetching across the application.

## Key Components

- **DashboardApiService**: Singleton service class that handles all dashboard-related API requests
- **fetchDeviceStats()**: Retrieves device statistics including online/offline counts and percentages
- **fetchChatStats()**: Fetches chat dialog statistics with resolution times and ratings
- **DashboardDeviceStats**: Interface for device statistics data structure
- **DashboardChatStats**: Interface for chat statistics data structure
- **handleApiError()**: Private method for consistent error handling across API calls

## Usage Example

```typescript
import { dashboardApiService } from './dashboard-api-service'

// Fetch device statistics
const deviceStats = await dashboardApiService.fetchDeviceStats()
console.log(`Total devices: ${deviceStats.total}`)
console.log(`Active: ${deviceStats.active} (${deviceStats.activePercentage}%)`)
console.log(`Inactive: ${deviceStats.inactive} (${deviceStats.inactivePercentage}%)`)

// Fetch chat statistics (SaaS mode)
const chatStats = await dashboardApiService.fetchChatStats()
console.log(`Total chats: ${chatStats.total}`)
console.log(`Average resolution time: ${chatStats.avgResolveTime}`)
console.log(`Average Fae rating: ${chatStats.avgFaeRate}`)
```

The service makes GraphQL requests to `/api/graphql` for device data and `/chat/graphql` for chat statistics, handling response validation and error scenarios consistently.
