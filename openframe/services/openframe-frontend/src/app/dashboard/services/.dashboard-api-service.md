A singleton service class that provides dashboard analytics data by fetching device statistics and chat metrics through GraphQL APIs. It aggregates device status counts (online/offline) and chat dialog statistics with resolution times and ratings.

## Key Components

- **DashboardApiService** - Singleton class managing dashboard data fetching
- **fetchDeviceStats()** - Retrieves device counts and calculates active/inactive percentages
- **fetchChatStats()** - Gets chat dialog statistics including resolution times and ratings
- **DashboardDeviceStats** - Interface for device analytics (total, active, inactive counts)
- **DashboardChatStats** - Interface for chat metrics (dialogs, resolution time, Fae ratings)
- **handleApiError()** - Private error handling utility for consistent error messages

## Usage Example

```typescript
import { dashboardApiService } from './dashboard-api-service'

// Fetch device statistics
const deviceStats = await dashboardApiService.fetchDeviceStats()
console.log(`${deviceStats.active}/${deviceStats.total} devices online (${deviceStats.activePercentage}%)`)

// Fetch chat statistics for SaaS mode
const chatStats = await dashboardApiService.fetchChatStats()
console.log(`${chatStats.resolved} dialogs resolved, avg time: ${chatStats.avgResolveTime}`)
console.log(`Average Fae rating: ${chatStats.avgFaeRate}/5.0`)

// Handle errors
try {
  const stats = await dashboardApiService.fetchDeviceStats()
} catch (error) {
  console.error('Dashboard stats failed:', error.message)
}
```

The service uses GraphQL queries to aggregate data from devices and chat dialogs, providing a unified interface for dashboard components to display real-time analytics and KPIs.
