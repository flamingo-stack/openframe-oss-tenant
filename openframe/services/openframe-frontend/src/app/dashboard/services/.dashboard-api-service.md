A singleton service class that handles GraphQL API calls to fetch dashboard statistics for devices and chat support tickets, providing processed metrics with calculated percentages.

## Key Components

- **DashboardApiService** - Singleton service class with two main methods:
  - `fetchDeviceStats()` - Retrieves device counts and status breakdown (online/offline)
  - `fetchChatStats()` - Fetches chat support statistics including resolution metrics
- **Type Definitions** - `DashboardDeviceStats` and `DashboardChatStats` interfaces for strongly typed responses
- **Error Handling** - Centralized error processing with descriptive messages
- **API Integration** - Uses GraphQL queries for device filters and dialog statistics

## Usage Example

```typescript
import { dashboardApiService } from './dashboard-api-service'

// Fetch device statistics
const deviceStats = await dashboardApiService.fetchDeviceStats()
console.log(`${deviceStats.active}/${deviceStats.total} devices online (${deviceStats.activePercentage}%)`)

// Fetch chat support statistics  
const chatStats = await dashboardApiService.fetchChatStats()
console.log(`${chatStats.resolved} tickets resolved, avg time: ${chatStats.avgResolveTime}`)

// Handle errors
try {
  const stats = await dashboardApiService.fetchDeviceStats()
} catch (error) {
  console.error('Dashboard stats failed:', error.message)
}
```

The service processes raw GraphQL responses into clean dashboard metrics with calculated percentages and formatted data, making it easy to display key performance indicators in the UI.
