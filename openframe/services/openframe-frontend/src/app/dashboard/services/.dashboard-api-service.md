A singleton service class that provides dashboard statistics by fetching device and chat data through GraphQL queries, calculating key metrics like device status percentages and chat resolution statistics.

## Key Components

- **`DashboardApiService`** - Singleton service class handling dashboard data operations
- **`fetchDeviceStats()`** - Retrieves device counts and calculates online/offline percentages
- **`fetchChatStats()`** - Fetches chat statistics including resolution times and ratings
- **`DashboardDeviceStats`** - Interface for device statistics with counts and percentages
- **`DashboardChatStats`** - Interface for chat statistics with resolution metrics
- **`dashboardApiService`** - Exported singleton instance for application use

## Usage Example

```typescript
import { dashboardApiService } from './dashboard-api-service'

// Fetch device statistics
const deviceStats = await dashboardApiService.fetchDeviceStats()
console.log(`${deviceStats.active}/${deviceStats.total} devices online (${deviceStats.activePercentage}%)`)

// Fetch chat statistics  
const chatStats = await dashboardApiService.fetchChatStats()
console.log(`Average resolution time: ${chatStats.avgResolveTime}`)
console.log(`FAE rating: ${chatStats.avgFaeRate}/5`)

// Handle errors
try {
  const stats = await dashboardApiService.fetchDeviceStats()
  // Use stats...
} catch (error) {
  console.error('Dashboard stats error:', error.message)
}
```

The service uses the `apiClient` for GraphQL requests to `/api/graphql` (devices) and `/chat/graphql` (chat), with robust error handling and data validation for dashboard displays.
