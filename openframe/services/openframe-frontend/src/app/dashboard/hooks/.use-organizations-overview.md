A React Query hook that fetches organization overview data with device statistics for dashboard display.

## Key Components

- **`useOrganizationsOverview`** - Main hook that returns organization data with device counts and status percentages
- **`fetchOrganizationsOverview`** - Async function that queries GraphQL API for organizations and their device statistics
- **`OrganizationOverviewRow`** - TypeScript interface defining the structure of organization data with device metrics
- **`OrganizationNode`** - Type for raw organization data from GraphQL response
- **`OrganizationsResponse`** - Type for the complete GraphQL organizations query response

## Usage Example

```typescript
import { useOrganizationsOverview } from './use-organizations-overview'

function OrganizationsTable() {
  const { 
    rows, 
    loading, 
    error, 
    totalOrganizations,
    refresh 
  } = useOrganizationsOverview(20)

  if (loading) return <div>Loading organizations...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <h2>Organizations ({totalOrganizations})</h2>
      <table>
        <thead>
          <tr>
            <th>Name</th>
            <th>Total Devices</th>
            <th>Active</th>
            <th>Inactive</th>
            <th>Active %</th>
          </tr>
        </thead>
        <tbody>
          {rows.map(org => (
            <tr key={org.id}>
              <td>{org.name}</td>
              <td>{org.total}</td>
              <td>{org.active}</td>
              <td>{org.inactive}</td>
              <td>{org.activePct}%</td>
            </tr>
          ))}
        </tbody>
      </table>
      <button onClick={() => refresh()}>Refresh</button>
    </div>
  )
}
```

The hook fetches organization data and enriches it with device statistics by making parallel GraphQL queries. Results are cached for 3 minutes and sorted by total device count descending.
