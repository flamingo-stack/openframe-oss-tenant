A React Query hook that fetches organization overview data with device statistics for dashboard display, combining organization information with associated device counts and status percentages.

## Key Components

- **`OrganizationOverviewRow`** - Interface defining the structure of organization data with device statistics
- **`fetchOrganizationsOverview()`** - Async function that fetches organizations and their device statistics via GraphQL
- **`useOrganizationsOverview()`** - Custom React Query hook with caching, error handling, and data transformation

## Usage Example

```typescript
import { useOrganizationsOverview } from './use-organizations-overview'

function OrganizationsDashboard() {
  const { 
    rows, 
    loading, 
    error, 
    totalOrganizations,
    refresh 
  } = useOrganizationsOverview(20)

  if (loading) return <div>Loading organizations...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <h2>Organizations ({totalOrganizations} total)</h2>
      {rows.map(org => (
        <div key={org.id}>
          <h3>{org.name}</h3>
          <p>Devices: {org.total} ({org.activePct}% active)</p>
        </div>
      ))}
      <button onClick={() => refresh()}>Refresh</button>
    </div>
  )
}
```

The hook automatically combines organization data with device statistics, calculating active/inactive percentages and sorting by total device count. It includes robust error handling and caching with 3-minute stale time.
