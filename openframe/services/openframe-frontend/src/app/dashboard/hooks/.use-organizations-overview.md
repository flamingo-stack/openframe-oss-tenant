A React hook that fetches and manages organization overview data including device statistics and health metrics for dashboard display.

## Key Components

**Types:**
- `OrganizationNode` - GraphQL organization entity structure
- `OrganizationsResponse` - GraphQL response wrapper for organizations
- `OrganizationOverviewRow` - Processed organization data with device metrics

**Functions:**
- `fetchOrganizationsOverview()` - Async function that fetches organizations and their device statistics
- `useOrganizationsOverview()` - React Query hook for managing organization overview state

**Constants:**
- `ACTIVE_STATUSES` - Defines which device statuses are considered active
- Query configuration with 3-minute stale time and 10-minute garbage collection

## Usage Example

```typescript
import { useOrganizationsOverview } from './use-organizations-overview'

function OrganizationsDashboard() {
  const { 
    rows, 
    loading, 
    error, 
    totalOrganizations,
    refresh 
  } = useOrganizationsOverview(20)

  if (loading) return <div>Loading organizations...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <h2>Organizations ({totalOrganizations})</h2>
      {rows.map(org => (
        <div key={org.id}>
          <h3>{org.name}</h3>
          <p>Devices: {org.active}/{org.total} active ({org.activePct}%)</p>
        </div>
      ))}
      <button onClick={refresh}>Refresh</button>
    </div>
  )
}
```

The hook fetches organizations via GraphQL, then enriches each with device statistics by querying device counts and status distribution. Results are sorted by total device count and include percentage calculations for active/inactive devices. Error handling gracefully skips organizations with failed device queries while logging warnings.
