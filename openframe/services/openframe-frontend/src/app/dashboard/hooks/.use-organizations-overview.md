A React Query hook that fetches organizations with their device statistics for dashboard overview displays. It combines organization data with device counts to provide insights into active vs inactive devices per organization.

## Key Components

- **`useOrganizationsOverview`** - Main hook that returns organization overview data with device statistics
- **`fetchOrganizationsOverview`** - Async function that fetches organizations and their device counts via GraphQL
- **`OrganizationOverviewRow`** - Interface defining the structure of organization data with device metrics
- **`OrganizationNode`** - Type for raw organization data from GraphQL response
- **`OrganizationsResponse`** - Type for the organizations GraphQL query response

## Usage Example

```typescript
import { useOrganizationsOverview } from './hooks/use-organizations-overview'

function OrganizationsDashboard() {
  const { 
    rows, 
    loading, 
    error, 
    totalOrganizations, 
    refresh 
  } = useOrganizationsOverview(20)

  if (loading) return <div>Loading organizations...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <h2>Organizations Overview ({totalOrganizations} total)</h2>
      {rows.map(org => (
        <div key={org.id}>
          <h3>{org.name}</h3>
          <p>Total devices: {org.total}</p>
          <p>Active: {org.active} ({org.activePct}%)</p>
          <p>Inactive: {org.inactive} ({org.inactivePct}%)</p>
        </div>
      ))}
      <button onClick={() => refresh()}>Refresh Data</button>
    </div>
  )
}
```

The hook automatically handles error scenarios, sorts organizations by total device count, and provides caching with a 3-minute stale time for optimal performance.
