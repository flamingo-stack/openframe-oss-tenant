A React Query hook that fetches organizations overview data with device statistics for dashboard display. It retrieves organization information and aggregates device counts (active/inactive) for each organization.

## Key Components

- **`OrganizationOverviewRow`** - Interface defining the structure of organization overview data including device statistics
- **`fetchOrganizationsOverview()`** - Async function that fetches organizations and their device counts via GraphQL queries
- **`useOrganizationsOverview()`** - React Query hook that manages the organizations overview data with caching and error handling
- **Type definitions** - `OrganizationNode` and `OrganizationsResponse` for GraphQL response typing

## Usage Example

```typescript
import { useOrganizationsOverview } from './use-organizations-overview'

function OrganizationsDashboard() {
  const {
    rows,
    loading,
    error,
    totalOrganizations,
    refresh
  } = useOrganizationsOverview(10)

  if (loading) return <div>Loading organizations...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <h2>Organizations Overview ({totalOrganizations} total)</h2>
      {rows.map(org => (
        <div key={org.id}>
          <h3>{org.name}</h3>
          <p>Total Devices: {org.total}</p>
          <p>Active: {org.active} ({org.activePct}%)</p>
          <p>Inactive: {org.inactive} ({org.inactivePct}%)</p>
        </div>
      ))}
    </div>
  )
}
```

The hook fetches organizations data, then makes parallel device count queries for each organization, combining the results into a sorted array of organization overview rows with comprehensive device statistics.
