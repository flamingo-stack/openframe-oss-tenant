A React Query hook that fetches organization overview data with device statistics for dashboard display. It retrieves organizations and their associated device counts (active/inactive) to provide comprehensive organizational insights.

## Key Components

- **`OrganizationOverviewRow`** - TypeScript interface defining the structure of organization data with device statistics
- **`fetchOrganizationsOverview()`** - Async function that executes GraphQL queries to fetch organizations and their device counts
- **`useOrganizationsOverview()`** - Custom React Query hook that manages the data fetching, caching, and state for organization overview

## Usage Example

```typescript
import { useOrganizationsOverview } from './use-organizations-overview'

function OrganizationsDashboard() {
  const { 
    rows, 
    loading, 
    totalOrganizations, 
    error, 
    refresh 
  } = useOrganizationsOverview(20)

  if (loading) return <div>Loading organizations...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <h2>Organizations Overview ({totalOrganizations} total)</h2>
      {rows.map(org => (
        <div key={org.id}>
          <h3>{org.name}</h3>
          <p>Devices: {org.total} total, {org.active} active ({org.activePct}%)</p>
        </div>
      ))}
      <button onClick={() => refresh()}>Refresh Data</button>
    </div>
  )
}
```

The hook provides automatic caching (3-minute stale time), error handling, and sorting by total device count. It fetches organization data and enriches it with device statistics by making parallel GraphQL requests for each organization.
