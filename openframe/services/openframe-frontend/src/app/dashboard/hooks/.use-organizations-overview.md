A React Query hook for fetching organization overview data with device statistics in the Flamingo MSP platform dashboard.

## Key Components

### Types
- **`OrganizationOverviewRow`** - Interface defining the structure of organization data with device counts and percentages
- **`OrganizationNode`** - GraphQL response type for organization basic information
- **`OrganizationsResponse`** - Complete GraphQL response structure for organizations query

### Functions
- **`fetchOrganizationsOverview()`** - Async function that fetches organizations and their associated device statistics
- **`useOrganizationsOverview()`** - React Query hook providing cached organization overview data with loading states

## Usage Example

```typescript
import { useOrganizationsOverview } from './use-organizations-overview'

function OrganizationsDashboard() {
  const { 
    rows, 
    loading, 
    error, 
    totalOrganizations,
    refresh 
  } = useOrganizationsOverview(20)

  if (loading) return <div>Loading organizations...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <h2>Organizations Overview ({totalOrganizations} total)</h2>
      {rows.map(org => (
        <div key={org.id}>
          <h3>{org.name}</h3>
          <p>Devices: {org.total} ({org.activePct}% active)</p>
        </div>
      ))}
      <button onClick={() => refresh()}>Refresh Data</button>
    </div>
  )
}
```

The hook combines organization data with device statistics, providing active/inactive device counts and percentages for each organization. It includes robust error handling and caching with a 3-minute stale time.
