A React Query hook that fetches organization overview data with device counts and status metrics for dashboard displays.

## Key Components

- **`useOrganizationsOverview`** - Main hook that returns organization data with device statistics
- **`fetchOrganizationsOverview`** - Async function that fetches organizations and their device counts via GraphQL
- **`OrganizationOverviewRow`** - Interface defining the structure of organization data with device metrics
- **Type definitions** - `OrganizationNode` and `OrganizationsResponse` for GraphQL response typing

## Usage Example

```typescript
import { useOrganizationsOverview } from './use-organizations-overview'

function OrganizationsDashboard() {
  const { 
    rows, 
    loading, 
    error, 
    totalOrganizations, 
    refresh 
  } = useOrganizationsOverview(25)

  if (loading) return <div>Loading organizations...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <h2>Organizations ({totalOrganizations})</h2>
      {rows.map(org => (
        <div key={org.id}>
          <h3>{org.name}</h3>
          <p>Devices: {org.total} total, {org.active} active ({org.activePct}%)</p>
        </div>
      ))}
      <button onClick={() => refresh()}>Refresh Data</button>
    </div>
  )
}
```

The hook fetches organization data, then makes parallel requests to get device counts for each organization. It calculates active/inactive percentages based on device online/offline status and sorts results by total device count. Data is cached for 3 minutes with automatic error handling and retry logic.
