A React Query hook that fetches organization overview data with device statistics, combining organization details with their associated device counts and status breakdowns for dashboard display.

## Key Components

- **`useOrganizationsOverview`** - Main hook that fetches and manages organization overview data with caching
- **`fetchOrganizationsOverview`** - Core function that retrieves organizations and their device statistics
- **`OrganizationOverviewRow`** - Interface defining the complete organization data structure with device metrics
- **`OrganizationNode`** - Type for basic organization data from GraphQL API
- **`OrganizationsResponse`** - Type for the paginated organizations GraphQL response

## Usage Example

```typescript
import { useOrganizationsOverview } from './use-organizations-overview'

function OrganizationDashboard() {
  const { 
    rows, 
    loading, 
    error, 
    totalOrganizations, 
    refresh 
  } = useOrganizationsOverview(25)

  if (loading) return <div>Loading organizations...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <h2>Organizations Overview ({totalOrganizations} total)</h2>
      {rows.map(org => (
        <div key={org.id}>
          <h3>{org.name}</h3>
          <p>Total Devices: {org.total}</p>
          <p>Active: {org.active} ({org.activePct}%)</p>
          <p>Inactive: {org.inactive} ({org.inactivePct}%)</p>
        </div>
      ))}
      <button onClick={() => refresh()}>Refresh Data</button>
    </div>
  )
}
```

The hook automatically handles error states, provides 3-minute caching, and sorts organizations by total device count in descending order.
