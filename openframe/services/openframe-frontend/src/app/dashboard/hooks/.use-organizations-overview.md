A React Query hook for fetching organization overview data with device statistics, providing aggregated metrics including active/inactive device counts and percentages per organization.

## Key Components

- **`OrganizationOverviewRow`** - TypeScript interface defining the structure of organization data with device statistics
- **`fetchOrganizationsOverview()`** - Async function that fetches organizations and their associated device counts via GraphQL queries
- **`useOrganizationsOverview()`** - Main React Query hook that manages the data fetching, caching, and state for organization overview data

## Usage Example

```typescript
import { useOrganizationsOverview } from './use-organizations-overview'

function OrganizationsTable() {
  const { 
    rows, 
    loading, 
    error, 
    totalOrganizations,
    refresh 
  } = useOrganizationsOverview(20) // Limit to 20 organizations

  if (loading) return <div>Loading organizations...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <h2>Organizations Overview ({totalOrganizations} total)</h2>
      <button onClick={() => refresh()}>Refresh Data</button>
      <table>
        <thead>
          <tr>
            <th>Organization</th>
            <th>Total Devices</th>
            <th>Active</th>
            <th>Inactive</th>
            <th>Active %</th>
          </tr>
        </thead>
        <tbody>
          {rows.map(org => (
            <tr key={org.id}>
              <td>{org.name}</td>
              <td>{org.total}</td>
              <td>{org.active}</td>
              <td>{org.inactive}</td>
              <td>{org.activePct}%</td>
            </tr>
          ))}
        </tbody>
      </table>
    </div>
  )
}
```

The hook includes built-in caching (3-minute stale time), error handling, and automatic retry logic. Data is sorted by total device count in descending order.
