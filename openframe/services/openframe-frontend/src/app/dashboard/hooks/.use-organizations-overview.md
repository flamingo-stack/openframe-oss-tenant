A custom React Query hook that fetches organization overview data with device statistics for dashboard display.

## Key Components

- **`useOrganizationsOverview`** - Main hook that fetches and manages organization overview data
- **`fetchOrganizationsOverview`** - Async function that retrieves organizations and their device counts via GraphQL
- **`OrganizationOverviewRow`** - Type interface defining the structure of organization data with device metrics
- **GraphQL Queries** - Embedded queries for organizations and device filters

## Usage Example

```typescript
import { useOrganizationsOverview } from './use-organizations-overview'

function OrganizationsTable() {
  const { 
    rows, 
    loading, 
    error, 
    totalOrganizations, 
    refresh 
  } = useOrganizationsOverview(20)

  if (loading) return <div>Loading organizations...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <h2>Organizations ({totalOrganizations})</h2>
      <table>
        <thead>
          <tr>
            <th>Organization</th>
            <th>Total Devices</th>
            <th>Active</th>
            <th>Inactive</th>
          </tr>
        </thead>
        <tbody>
          {rows.map((org) => (
            <tr key={org.id}>
              <td>{org.name}</td>
              <td>{org.total}</td>
              <td>{org.active} ({org.activePct}%)</td>
              <td>{org.inactive} ({org.inactivePct}%)</td>
            </tr>
          ))}
        </tbody>
      </table>
      <button onClick={() => refresh()}>Refresh</button>
    </div>
  )
}
```

The hook fetches organization data, then makes parallel requests to get device counts for each organization, calculating active/inactive percentages and sorting by total device count. It includes error handling and caching with a 3-minute stale time.
