A React hook that fetches organizational overview data with device statistics, combining organization details with active/inactive device counts for dashboard displays.

## Key Components

- **`OrganizationOverviewRow`** - Interface defining the structured data for each organization with device metrics
- **`fetchOrganizationsOverview`** - Async function that queries organizations and their associated device statistics
- **`useOrganizationsOverview`** - Main hook that manages the query state and provides organization overview data
- **GraphQL queries** - Fetches organization list and device filters with status counts
- **Error handling** - Graceful fallbacks for failed API calls with detailed logging

## Usage Example

```typescript
import { useOrganizationsOverview } from './use-organizations-overview'

function OrganizationsDashboard() {
  const { 
    rows, 
    loading, 
    error, 
    totalOrganizations,
    refresh 
  } = useOrganizationsOverview(20)

  if (loading) return <div>Loading organizations...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <h2>Organizations Overview ({totalOrganizations} total)</h2>
      {rows.map(org => (
        <div key={org.id}>
          <h3>{org.name}</h3>
          <p>Devices: {org.total} total, {org.active} active ({org.activePct}%)</p>
        </div>
      ))}
      <button onClick={() => refresh()}>Refresh Data</button>
    </div>
  )
}
```

The hook automatically handles caching (3-minute stale time), sorting by device count, and provides loading states for optimal user experience.
