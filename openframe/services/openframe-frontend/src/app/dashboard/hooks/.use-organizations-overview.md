A React Query hook that fetches organizations overview data with device statistics, providing aggregated metrics for dashboard visualization.

## Key Components

- **`useOrganizationsOverview`** - Main hook that fetches and manages organizations with device counts
- **`fetchOrganizationsOverview`** - Async function that queries organizations and their device statistics
- **`OrganizationOverviewRow`** - Interface defining the structure of organization data with device metrics
- **GraphQL Queries** - Fetches organizations list and device filters for each organization

## Usage Example

```typescript
import { useOrganizationsOverview } from './use-organizations-overview'

function OrganizationsDashboard() {
  const { 
    rows, 
    loading, 
    error, 
    totalOrganizations,
    refresh 
  } = useOrganizationsOverview(20)

  if (loading) return <div>Loading organizations...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <h2>Organizations Overview ({totalOrganizations} total)</h2>
      {rows.map(org => (
        <div key={org.id}>
          <h3>{org.name}</h3>
          <p>Devices: {org.total} ({org.activePct}% active)</p>
          <p>Active: {org.active} | Inactive: {org.inactive}</p>
        </div>
      ))}
      <button onClick={() => refresh()}>Refresh Data</button>
    </div>
  )
}
```

The hook automatically fetches device statistics for each organization, calculates active/inactive percentages, and sorts results by total device count. Data is cached for 3 minutes with automatic error handling and retry logic.
