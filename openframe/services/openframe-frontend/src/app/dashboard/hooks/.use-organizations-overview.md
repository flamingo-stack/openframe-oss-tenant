A React Query hook for fetching organization overview data with device statistics for dashboard displays. It retrieves organizations and their associated device counts (active/inactive) with calculated percentages.

## Key Components

- **`useOrganizationsOverview`** - Main hook that returns organization overview data with device statistics
- **`fetchOrganizationsOverview`** - Async function that fetches organizations and enriches them with device count data
- **`OrganizationOverviewRow`** - TypeScript interface defining the structure of organization overview data
- **`OrganizationNode`** - Type definition for raw organization data from GraphQL
- **`OrganizationsResponse`** - Type definition for the GraphQL organizations response structure

## Usage Example

```typescript
import { useOrganizationsOverview } from './use-organizations-overview'

function OrganizationsDashboard() {
  const { 
    rows, 
    loading, 
    error, 
    totalOrganizations, 
    refresh 
  } = useOrganizationsOverview(25)

  if (loading) return <div>Loading organizations...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <h2>Organizations ({totalOrganizations})</h2>
      {rows.map(org => (
        <div key={org.id}>
          <h3>{org.name}</h3>
          <p>Total devices: {org.total}</p>
          <p>Active: {org.active} ({org.activePct}%)</p>
          <p>Inactive: {org.inactive} ({org.inactivePct}%)</p>
        </div>
      ))}
      <button onClick={() => refresh()}>Refresh</button>
    </div>
  )
}
```

The hook automatically fetches device statistics for each organization and sorts results by total device count. It includes built-in error handling, caching (3-minute stale time), and provides loading states for better UX.
