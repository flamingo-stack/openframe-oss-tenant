A React Query hook that fetches organization overview data with aggregated device statistics for dashboard display.

## Key Components

### Types
- `OrganizationOverviewRow` - Interface defining the complete organization data structure with device metrics
- `OrganizationNode` - GraphQL organization node type
- `OrganizationsResponse` - GraphQL response structure for organizations query

### Functions
- `fetchOrganizationsOverview()` - Async function that fetches organizations and their device counts via GraphQL
- `useOrganizationsOverview()` - React Query hook that manages the organizations overview data with caching

### Constants
- `ACTIVE_STATUSES` - Defines which device statuses are considered "active" (currently just 'ONLINE')

## Usage Example

```typescript
import { useOrganizationsOverview } from './use-organizations-overview'

function OrganizationsDashboard() {
  const { 
    rows, 
    loading, 
    totalOrganizations, 
    refresh 
  } = useOrganizationsOverview(25)

  if (loading) return <div>Loading organizations...</div>

  return (
    <div>
      <h2>Organizations ({totalOrganizations})</h2>
      {rows.map(org => (
        <div key={org.id}>
          <h3>{org.name}</h3>
          <p>Devices: {org.total} ({org.activePct}% active)</p>
        </div>
      ))}
      <button onClick={() => refresh()}>Refresh Data</button>
    </div>
  )
}
```

The hook fetches organizations from GraphQL, then makes parallel requests to get device statistics for each organization, combining the data into sortable rows with device counts and percentages. Results are cached for 3 minutes with a 10-minute garbage collection time.
