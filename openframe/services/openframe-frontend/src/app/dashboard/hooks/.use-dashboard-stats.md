Custom React hooks for fetching and managing dashboard statistics across devices, chats, and logs with real-time data aggregation and percentage calculations.

## Key Components

- **`useDevicesOverview()`** - Fetches device statistics including total, active/inactive counts and percentages
- **`useChatsOverview()`** - Retrieves chat dialog statistics with resolution metrics and Fae AI ratings
- **`useLogsOverview()`** - Aggregates log severity counts across paginated results with safety limits

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useLogsOverview } from './use-dashboard-stats'

function DashboardPage() {
  const devices = useDevicesOverview()
  const chats = useChatsOverview()  
  const logs = useLogsOverview()

  if (devices.isLoading) {
    return <div>Loading dashboard...</div>
  }

  return (
    <div>
      <div>
        <h3>Devices: {devices.total}</h3>
        <p>Active: {devices.active} ({devices.activePercentage}%)</p>
        <p>Inactive: {devices.inactive} ({devices.inactivePercentage}%)</p>
      </div>
      
      <div>
        <h3>Support Chats: {chats.total}</h3>
        <p>Average Fae Rating: {chats.avgFaeRate}/5</p>
        <p>Avg Resolution Time: {chats.avgResolveTime}</p>
      </div>

      <div>
        <h3>System Logs: {logs.total}</h3>
        <p>Critical: {logs.critical} ({logs.criticalPercentage}%)</p>
        <p>Warning: {logs.warning} ({logs.warningPercentage}%)</p>
      </div>
    </div>
  )
}
```

Each hook includes error handling, cleanup on unmount, and graceful fallbacks to maintain dashboard functionality even when API requests fail.
