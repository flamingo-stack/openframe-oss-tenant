Custom React hooks for fetching and managing dashboard statistics across devices, chat dialogs, and system logs in the Flamingo MSP platform.

## Key Components

- **useDevicesOverview()** - Fetches device status statistics (active/inactive counts and percentages)
- **useChatsOverview()** - Retrieves chat dialog metrics including resolution times and Fae AI ratings  
- **useLogsOverview()** - Aggregates system log severity counts (info, warning, critical) with pagination

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useLogsOverview } from './use-dashboard-stats'

function DashboardOverview() {
  const devices = useDevicesOverview()
  const chats = useChatsOverview()  
  const logs = useLogsOverview()

  if (devices.isLoading) {
    return <div>Loading device stats...</div>
  }

  return (
    <div className="dashboard-grid">
      <div className="devices-card">
        <h3>Devices</h3>
        <p>{devices.active}/{devices.total} online ({devices.activePercentage}%)</p>
      </div>
      
      <div className="chats-card">
        <h3>Support Chats</h3>
        <p>{chats.resolved} resolved, Avg: {chats.avgResolveTime}</p>
        <p>Fae Rating: {chats.avgFaeRate}/5</p>
      </div>

      <div className="logs-card">
        <h3>System Logs</h3>
        <p>Critical: {logs.critical} ({logs.criticalPercentage}%)</p>
        <p>Warnings: {logs.warning} ({logs.warningPercentage}%)</p>
      </div>
    </div>
  )
}
```

Each hook handles GraphQL API calls with proper error handling, loading states, and cleanup on component unmount. The hooks provide real-time statistics for MSP dashboard widgets, supporting the unified OpenFrame interface.
