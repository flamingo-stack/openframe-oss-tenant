A React hook module that provides dashboard statistics for devices and chat data using React Query for caching and state management. The hooks handle data fetching with optimized caching strategies and conditional queries based on application mode.

## Key Components

- **`useDevicesOverview()`** - Fetches and returns device statistics including total, active/inactive counts and percentages
- **`useChatsOverview()`** - Fetches chat statistics with SaaS mode detection, including resolution times and Fae AI rates  
- **`useSharedDashboardData()`** - Combines both device and chat data with unified loading states and refetch functionality

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useSharedDashboardData } from './use-dashboard-stats'

// Individual hook usage
function DeviceStats() {
  const { total, active, activePercentage, isLoading } = useDevicesOverview()
  
  if (isLoading) return <div>Loading...</div>
  
  return (
    <div>
      <p>Total Devices: {total}</p>
      <p>Active: {active} ({activePercentage}%)</p>
    </div>
  )
}

// Combined dashboard data
function Dashboard() {
  const { devices, chats, isAnyLoading, refetchAll } = useSharedDashboardData()
  
  return (
    <div>
      <button onClick={refetchAll}>Refresh All</button>
      {isAnyLoading && <div>Loading...</div>}
      <DeviceOverview data={devices.data} />
      <ChatOverview data={chats.data} />
    </div>
  )
}
```

The hooks implement smart caching with 1-3 minute stale times and automatic retry logic for robust data fetching.
