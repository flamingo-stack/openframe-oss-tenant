React hooks that provide dashboard statistics for devices, chats, and system logs by fetching and aggregating data from GraphQL APIs.

## Key Components

### `useDevicesOverview()`
- Fetches device status counts and calculates active/inactive percentages
- Returns device statistics with loading state
- Filters devices by default dashboard statuses

### `useChatsOverview()`
- Retrieves chat dialog statistics including total, active, and resolved counts
- Provides average resolution time and Fae rating metrics
- Calculates status distribution percentages

### `useLogsOverview()`
- Aggregates system logs by severity levels (info, warning, critical)
- Uses paginated fetching to count all log entries
- Returns severity distribution statistics and percentages

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useLogsOverview } from './use-dashboard-stats'

function DashboardComponent() {
  const deviceStats = useDevicesOverview()
  const chatStats = useChatsOverview()
  const logStats = useLogsOverview()

  if (deviceStats.isLoading) {
    return <div>Loading device statistics...</div>
  }

  return (
    <div className="dashboard-stats">
      <div className="devices-overview">
        <h3>Devices</h3>
        <p>Total: {deviceStats.total}</p>
        <p>Active: {deviceStats.active} ({deviceStats.activePercentage}%)</p>
        <p>Inactive: {deviceStats.inactive} ({deviceStats.inactivePercentage}%)</p>
      </div>

      <div className="chats-overview">
        <h3>Support Chats</h3>
        <p>Total: {chatStats.total}</p>
        <p>Active: {chatStats.active} ({chatStats.activePercentage}%)</p>
        <p>Average Resolution: {chatStats.avgResolveTime}</p>
        <p>Average Fae Rating: {chatStats.avgFaeRate}</p>
      </div>

      <div className="logs-overview">
        <h3>System Logs</h3>
        <p>Total: {logStats.total}</p>
        <p>Info: {logStats.info} ({logStats.infoPercentage}%)</p>
        <p>Warning: {logStats.warning} ({logStats.warningPercentage}%)</p>
        <p>Critical: {logStats.critical} ({logStats.criticalPercentage}%)</p>
      </div>
    </div>
  )
}
```

Each hook automatically fetches data on mount and handles cleanup to prevent memory leaks. Error handling is implemented to gracefully maintain default values when API calls fail.
