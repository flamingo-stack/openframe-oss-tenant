Custom React hooks for fetching and managing dashboard statistics across devices, chats, and logs with real-time data aggregation and percentage calculations.

## Key Components

- **`useDevicesOverview`** - Fetches device status statistics (online/offline counts and percentages)
- **`useChatsOverview`** - Retrieves chat/ticket statistics including resolution metrics and Fae ratings
- **`useLogsOverview`** - Aggregates log entries by severity levels with pagination support

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useLogsOverview } from './use-dashboard-stats'

function DashboardOverview() {
  const deviceStats = useDevicesOverview()
  const chatStats = useChatsOverview()
  const logStats = useLogsOverview()

  if (deviceStats.isLoading) {
    return <div>Loading device statistics...</div>
  }

  return (
    <div className="dashboard-grid">
      <div className="device-stats">
        <h3>Devices ({deviceStats.total})</h3>
        <p>Active: {deviceStats.active} ({deviceStats.activePercentage}%)</p>
        <p>Inactive: {deviceStats.inactive} ({deviceStats.inactivePercentage}%)</p>
      </div>

      <div className="chat-stats">
        <h3>Support Tickets ({chatStats.total})</h3>
        <p>Active: {chatStats.active} ({chatStats.activePercentage}%)</p>
        <p>Resolved: {chatStats.resolved} ({chatStats.resolvedPercentage}%)</p>
        <p>Avg Resolution: {chatStats.avgResolveTime}</p>
        <p>Fae Rating: {chatStats.avgFaeRate}/5</p>
      </div>

      <div className="log-stats">
        <h3>System Logs ({logStats.total})</h3>
        <p>Info: {logStats.info} ({logStats.infoPercentage}%)</p>
        <p>Warnings: {logStats.warning} ({logStats.warningPercentage}%)</p>
        <p>Critical: {logStats.critical} ({logStats.criticalPercentage}%)</p>
      </div>
    </div>
  )
}
```

Each hook handles GraphQL API calls with proper error handling and cleanup, returning computed statistics with percentages for dashboard visualization. The hooks use `useState` for local state management and `useEffect` for data fetching with mount status tracking to prevent memory leaks.
