Custom React hooks for fetching and managing dashboard statistics data using TanStack Query, including device metrics and chat analytics with optimized caching and error handling.

## Key Components

- **`useDevicesOverview`** - Fetches device statistics (total, active, inactive) with 1-minute cache
- **`useChatsOverview`** - Retrieves chat analytics (total, active, resolved, response times) with SaaS mode checking
- **`useSharedDashboardData`** - Combines both device and chat data with unified loading states and refetch functionality

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useSharedDashboardData } from './use-dashboard-stats'

// Individual hook usage
function DevicesWidget() {
  const { total, active, activePercentage, isLoading, error } = useDevicesOverview()
  
  if (isLoading) return <div>Loading devices...</div>
  if (error) return <div>Error: {error}</div>
  
  return (
    <div>
      <h3>Devices: {total}</h3>
      <p>Active: {active} ({activePercentage}%)</p>
    </div>
  )
}

// Combined dashboard usage
function DashboardOverview() {
  const { devices, chats, isAnyLoading, refetchAll } = useSharedDashboardData()
  
  return (
    <div>
      <button onClick={refetchAll} disabled={isAnyLoading}>
        Refresh All Data
      </button>
      <div>Devices: {devices.data.total}</div>
      <div>Chats: {chats.data.total}</div>
    </div>
  )
}
```

The hooks include automatic retry logic, optimized caching strategies, and SaaS tenant mode detection for conditional data fetching.
