A React hook collection providing statistical data for dashboard components, fetching device status, chat dialog, and log severity metrics via GraphQL APIs.

## Key Components

- **`useDevicesOverview()`** - Fetches device statistics including total count, online/offline status, and calculates percentages
- **`useChatsOverview()`** - Retrieves chat dialog metrics including total conversations, active/resolved status, average resolution time, and Fae rating
- **`useLogsOverview()`** - Aggregates log severity statistics (info, warning, critical) with pagination support

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useLogsOverview } from './use-dashboard-stats'

function DashboardComponent() {
  const { 
    total: deviceTotal, 
    active: activeDevices, 
    activePercentage,
    isLoading: devicesLoading 
  } = useDevicesOverview()
  
  const { 
    total: chatTotal, 
    avgResolveTime, 
    avgFaeRate 
  } = useChatsOverview()
  
  const { 
    total: logTotal, 
    critical: criticalLogs,
    criticalPercentage 
  } = useLogsOverview()

  if (devicesLoading) {
    return <div>Loading dashboard stats...</div>
  }

  return (
    <div>
      <div>Devices: {activeDevices}/{deviceTotal} ({activePercentage}% online)</div>
      <div>Chats: {chatTotal} total, avg resolve: {avgResolveTime}</div>
      <div>Logs: {criticalLogs} critical ({criticalPercentage}%)</div>
    </div>
  )
}
```

Each hook manages its own loading state and error handling, providing real-time dashboard metrics through GraphQL queries to different API endpoints.
