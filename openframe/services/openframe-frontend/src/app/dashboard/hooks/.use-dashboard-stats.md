A custom React hook collection that provides dashboard statistics for devices, chats, and logs with real-time data fetching and percentage calculations.

## Key Components

- **`useDevicesOverview()`** - Fetches device statistics including total count, active/inactive devices, and percentage breakdowns
- **`useChatsOverview()`** - Retrieves chat/dialog statistics with status counts, resolution metrics, and Fae rating averages  
- **`useLogsOverview()`** - Aggregates log data by severity levels (info, warning, critical) with pagination support

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useLogsOverview } from './use-dashboard-stats'

function DashboardStats() {
  const devices = useDevicesOverview()
  const chats = useChatsOverview() 
  const logs = useLogsOverview()

  if (devices.isLoading) return <div>Loading...</div>

  return (
    <div>
      <div>Devices: {devices.total} ({devices.activePercentage}% active)</div>
      <div>Chats: {chats.total} (Avg resolve: {chats.avgResolveTime})</div>
      <div>Logs: {logs.total} ({logs.criticalPercentage}% critical)</div>
    </div>
  )
}
```

Each hook manages its own loading state and error handling, providing fallback values when API requests fail. The hooks use GraphQL queries to fetch data from different endpoints and calculate relevant percentages for dashboard display.
