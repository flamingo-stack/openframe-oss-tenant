A React hook collection that provides dashboard statistics for devices, chats, and logs with real-time data fetching and percentage calculations.

## Key Components

- **`useDevicesOverview()`** - Fetches device statistics including total, active/inactive counts and percentages
- **`useChatsOverview()`** - Retrieves chat dialog statistics with resolution metrics and Fae ratings
- **`useLogsOverview()`** - Aggregates log data by severity levels (info, warning, critical) with pagination support

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useLogsOverview } from './use-dashboard-stats'

function DashboardComponent() {
  const deviceStats = useDevicesOverview()
  const chatStats = useChatsOverview()
  const logStats = useLogsOverview()

  return (
    <div className="dashboard">
      <div className="devices-panel">
        <h3>Devices ({deviceStats.total})</h3>
        {deviceStats.isLoading ? (
          <div>Loading...</div>
        ) : (
          <div>
            <span>Active: {deviceStats.active} ({deviceStats.activePercentage}%)</span>
            <span>Inactive: {deviceStats.inactive} ({deviceStats.inactivePercentage}%)</span>
          </div>
        )}
      </div>

      <div className="chats-panel">
        <h3>Support Tickets</h3>
        <div>Total: {chatStats.total}</div>
        <div>Avg Resolve Time: {chatStats.avgResolveTime}</div>
        <div>Fae Rating: {chatStats.avgFaeRate}/5</div>
      </div>

      <div className="logs-panel">
        <h3>System Logs ({logStats.total})</h3>
        <div>Critical: {logStats.critical} ({logStats.criticalPercentage}%)</div>
        <div>Warning: {logStats.warning} ({logStats.warningPercentage}%)</div>
        <div>Info: {logStats.info} ({logStats.infoPercentage}%)</div>
      </div>
    </div>
  )
}
```

Each hook handles GraphQL API calls, error handling, and cleanup automatically. The hooks return structured data with computed percentages and maintain loading states where applicable.
