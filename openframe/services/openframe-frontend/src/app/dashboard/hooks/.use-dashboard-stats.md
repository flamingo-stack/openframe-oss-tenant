A collection of React hooks that fetch and manage dashboard statistics for devices, chats, and logs in the Flamingo platform. Each hook provides real-time overview data with loading states and error handling.

## Key Components

- **`useDevicesOverview()`** - Fetches device statistics including total count, active/inactive devices, and percentage breakdowns
- **`useChatsOverview()`** - Retrieves chat dialog statistics with resolution times, ratings, and status distributions
- **`useLogsOverview()`** - Aggregates log data by severity levels (info, warning, critical) with pagination handling

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useLogsOverview } from './use-dashboard-stats'

function DashboardComponent() {
  const { total, active, inactive, activePercentage, isLoading } = useDevicesOverview()
  const { total: chatTotal, avgResolveTime, avgFaeRate } = useChatsOverview()
  const { total: logTotal, critical, criticalPercentage } = useLogsOverview()

  if (isLoading) return <div>Loading dashboard stats...</div>

  return (
    <div className="dashboard-grid">
      <div className="device-stats">
        <h3>Devices: {total}</h3>
        <p>Active: {active} ({activePercentage}%)</p>
        <p>Inactive: {inactive}</p>
      </div>
      
      <div className="chat-stats">
        <h3>Chats: {chatTotal}</h3>
        <p>Avg Resolve Time: {avgResolveTime}</p>
        <p>Fae Rating: {avgFaeRate}/5</p>
      </div>
      
      <div className="log-stats">
        <h3>Logs: {logTotal}</h3>
        <p>Critical: {critical} ({criticalPercentage}%)</p>
      </div>
    </div>
  )
}
```

The hooks automatically handle API errors gracefully, maintaining default values when requests fail to ensure the dashboard remains functional even during partial service outages.
