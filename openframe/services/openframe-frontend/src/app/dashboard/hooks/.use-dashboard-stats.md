A React hook collection that provides dashboard statistics for devices, chats, and logs with real-time data fetching and percentage calculations for the OpenFrame MSP platform.

## Key Components

- **`useDevicesOverview`** - Fetches device statistics including total count, active/inactive devices, and status percentages
- **`useChatsOverview`** - Retrieves chat/ticket statistics with resolution metrics and Fae AI ratings
- **`useLogsOverview`** - Provides log severity statistics with info/warning/critical breakdowns and percentages

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useLogsOverview } from './use-dashboard-stats'

function DashboardOverview() {
  const { total, active, inactive, activePercentage, isLoading } = useDevicesOverview()
  const { total: chatTotal, avgResolveTime, avgFaeRate } = useChatsOverview()
  const { total: logTotal, critical, criticalPercentage } = useLogsOverview()

  if (isLoading) return <div>Loading dashboard stats...</div>

  return (
    <div className="dashboard-stats">
      <div className="devices-card">
        <h3>Devices ({total})</h3>
        <p>{active} active ({activePercentage}%)</p>
      </div>
      
      <div className="chats-card">
        <h3>Support Chats ({chatTotal})</h3>
        <p>Avg resolve: {avgResolveTime}</p>
        <p>Fae rating: {avgFaeRate}/5</p>
      </div>

      <div className="logs-card">
        <h3>System Logs ({logTotal})</h3>
        <p>{critical} critical ({criticalPercentage}%)</p>
      </div>
    </div>
  )
}
```

Each hook implements proper cleanup with mounted state checks, error handling that maintains default values, and automatic percentage calculations for dashboard visualization.
