A React Query hook collection for managing dashboard statistics data, providing device and chat overview metrics with optimized caching and error handling.

## Key Components

**Core Hooks:**
- `useDevicesOverview()` - Fetches device statistics (total, active, inactive counts and percentages)
- `useChatsOverview()` - Fetches chat statistics with SaaS tenant mode detection
- `useSharedDashboardData()` - Combines both hooks for unified dashboard data access

**Features:**
- Automatic data normalization with fallback values
- Conditional querying based on app mode
- Configurable stale time and garbage collection
- Built-in retry logic with exponential backoff
- Error handling with user-friendly messages

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useSharedDashboardData } from './use-dashboard-stats'

// Individual hook usage
function DeviceMetrics() {
  const { total, active, activePercentage, isLoading, error, refetch } = useDevicesOverview()
  
  if (isLoading) return <div>Loading devices...</div>
  if (error) return <div>Error: {error}</div>
  
  return (
    <div>
      <h3>Devices: {total} ({activePercentage}% active)</h3>
      <button onClick={() => refetch()}>Refresh</button>
    </div>
  )
}

// Combined dashboard usage
function Dashboard() {
  const { devices, chats, isAnyLoading, refetchAll } = useSharedDashboardData()
  
  return (
    <div>
      <div>Active Devices: {devices.data.active}</div>
      <div>Total Chats: {chats.data.total}</div>
      <button onClick={refetchAll} disabled={isAnyLoading}>
        Refresh All Data
      </button>
    </div>
  )
}
```
