Custom React hooks that provide dashboard statistics data with intelligent caching and error handling. These hooks manage device metrics, chat analytics, and combined dashboard state using TanStack Query.

## Key Components

- **`useDevicesOverview()`** - Fetches device statistics including total count, active/inactive devices, and percentages
- **`useChatsOverview()`** - Retrieves chat metrics with SaaS mode detection, including resolution times and Fae AI rates
- **`useSharedDashboardData()`** - Combines both device and chat data with unified loading states and bulk refresh functionality

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useSharedDashboardData } from './use-dashboard-stats'

// Individual hook usage
function DevicesWidget() {
  const { total, active, activePercentage, isLoading, error } = useDevicesOverview()
  
  if (isLoading) return <div>Loading devices...</div>
  if (error) return <div>Error: {error}</div>
  
  return (
    <div>
      <h3>Devices: {total}</h3>
      <p>Active: {active} ({activePercentage}%)</p>
    </div>
  )
}

// Combined dashboard usage
function DashboardOverview() {
  const { devices, chats, isAnyLoading, refetchAll } = useSharedDashboardData()
  
  return (
    <div>
      <button onClick={refetchAll}>Refresh All</button>
      {isAnyLoading && <div>Loading dashboard...</div>}
      <DeviceStats data={devices.data} />
      <ChatStats data={chats.data} />
    </div>
  )
}
```

The hooks include optimized caching with 1-3 minute stale times, automatic retries, and conditional enabling based on application mode (SaaS vs self-hosted).
