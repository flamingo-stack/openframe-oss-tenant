Custom React hooks for fetching and managing dashboard statistics across devices, chats, and logs with real-time data aggregation and percentage calculations.

## Key Components

- **`useDevicesOverview()`** - Fetches device statistics including total count, active/inactive devices, and status percentages
- **`useChatsOverview()`** - Retrieves chat dialog statistics with resolution metrics and FAE ratings
- **`useLogsOverview()`** - Aggregates log data by severity levels (info, warning, critical) with pagination support

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useLogsOverview } from './use-dashboard-stats'

function DashboardComponent() {
  const deviceStats = useDevicesOverview()
  const chatStats = useChatsOverview()
  const logStats = useLogsOverview()

  if (deviceStats.isLoading) {
    return <div>Loading device statistics...</div>
  }

  return (
    <div className="dashboard-grid">
      <div className="devices-card">
        <h3>Devices</h3>
        <p>Total: {deviceStats.total}</p>
        <p>Active: {deviceStats.active} ({deviceStats.activePercentage}%)</p>
        <p>Inactive: {deviceStats.inactive} ({deviceStats.inactivePercentage}%)</p>
      </div>

      <div className="chats-card">
        <h3>Support Chats</h3>
        <p>Total: {chatStats.total}</p>
        <p>Active: {chatStats.active} ({chatStats.activePercentage}%)</p>
        <p>Avg Resolution: {chatStats.avgResolveTime}</p>
        <p>FAE Rating: {chatStats.avgFaeRate}</p>
      </div>

      <div className="logs-card">
        <h3>System Logs</h3>
        <p>Total: {logStats.total}</p>
        <p>Info: {logStats.info} ({logStats.infoPercentage}%)</p>
        <p>Warning: {logStats.warning} ({logStats.warningPercentage}%)</p>
        <p>Critical: {logStats.critical} ({logStats.criticalPercentage}%)</p>
      </div>
    </div>
  )
}
```

The hooks automatically handle loading states, error recovery, and cleanup to prevent memory leaks. All statistics include calculated percentages and implement pagination where necessary for large datasets.
