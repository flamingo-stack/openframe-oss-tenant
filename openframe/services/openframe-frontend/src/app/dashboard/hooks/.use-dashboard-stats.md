Custom React hooks for fetching and managing dashboard statistics data using TanStack Query with optimized caching and error handling.

## Key Components

- **`useDevicesOverview()`** - Fetches device statistics (total, active, inactive) with 1-minute stale time and percentage calculations
- **`useChatsOverview()`** - Fetches chat statistics (total, active, resolved) with SaaS mode conditional enabling and 3-minute stale time
- **`useSharedDashboardData()`** - Combines both device and chat data queries with unified loading states and batch refetch functionality

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useSharedDashboardData } from './use-dashboard-stats'

// Individual hook usage
function DevicesCard() {
  const { 
    total, 
    active, 
    activePercentage, 
    isLoading, 
    error 
  } = useDevicesOverview()

  if (isLoading) return <div>Loading devices...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <h3>Devices: {total}</h3>
      <p>Active: {active} ({activePercentage}%)</p>
    </div>
  )
}

// Combined data usage
function DashboardOverview() {
  const { devices, chats, isAnyLoading, refetchAll } = useSharedDashboardData()

  return (
    <div>
      <button onClick={refetchAll}>Refresh All</button>
      {isAnyLoading ? (
        <div>Loading dashboard...</div>
      ) : (
        <>
          <DeviceStats data={devices.data} />
          <ChatStats data={chats.data} />
        </>
      )}
    </div>
  )
}
```

The hooks provide automatic retry logic, optimized caching strategies, and normalized data structures with fallback values for reliable dashboard rendering.
