A custom React hook collection that provides statistical data for dashboard overview components, fetching device status counts, chat dialog statistics, and log severity breakdowns.

## Key Components

- **`useDevicesOverview`** - Fetches device statistics including total count, active/inactive devices with percentages
- **`useChatsOverview`** - Retrieves chat dialog statistics with resolution metrics and Fae AI ratings
- **`useLogsOverview`** - Aggregates log entries by severity levels (info, warning, critical) with pagination support

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useLogsOverview } from './use-dashboard-stats'

function DashboardOverview() {
  const deviceStats = useDevicesOverview()
  const chatStats = useChatsOverview() 
  const logStats = useLogsOverview()

  if (deviceStats.isLoading) return <div>Loading devices...</div>

  return (
    <div>
      <div>Devices: {deviceStats.total} ({deviceStats.activePercentage}% active)</div>
      <div>Chats: {chatStats.total} (Avg Fae rate: {chatStats.avgFaeRate})</div>
      <div>Logs: {logStats.total} ({logStats.criticalPercentage}% critical)</div>
    </div>
  )
}
```

Each hook returns structured statistics objects with computed percentages and handles loading states gracefully. The hooks use GraphQL queries to fetch data from different API endpoints and include safety measures like cleanup functions and pagination limits.
