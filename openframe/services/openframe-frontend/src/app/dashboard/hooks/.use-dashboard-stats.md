Custom React hooks for managing Flamingo dashboard statistics using React Query. Provides device metrics, chat analytics, and shared dashboard data with intelligent caching and SaaS-aware functionality.

## Key Components

- **useDevicesOverview()** - Fetches and manages device statistics with 1-minute stale time
- **useChatsOverview()** - Retrieves chat metrics, conditionally enabled in SaaS tenant mode  
- **useSharedDashboardData()** - Combines device and chat data with unified loading states and refetch functionality

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useSharedDashboardData } from './use-dashboard-stats'

// Individual hook usage
function DevicesCard() {
  const { 
    total, 
    active, 
    activePercentage, 
    isLoading, 
    error 
  } = useDevicesOverview()

  if (isLoading) return <div>Loading devices...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <h3>Devices: {total}</h3>
      <p>Active: {active} ({activePercentage}%)</p>
    </div>
  )
}

// Combined dashboard usage
function Dashboard() {
  const { 
    devices, 
    chats, 
    isAnyLoading, 
    refetchAll 
  } = useSharedDashboardData()

  return (
    <div>
      <button onClick={refetchAll}>Refresh All</button>
      {isAnyLoading && <div>Loading dashboard...</div>}
      <DeviceStats data={devices.data} />
      <ChatStats data={chats.data} />
    </div>
  )
}
```

The hooks automatically handle SaaS mode detection for chat features and provide optimized caching with 1-2 minute stale times and retry logic.
