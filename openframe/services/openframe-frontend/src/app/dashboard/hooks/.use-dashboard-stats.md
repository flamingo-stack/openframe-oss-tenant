Custom React hooks for fetching and managing dashboard statistics data using React Query, providing optimized caching and error handling for device and chat metrics in the Flamingo MSP platform.

## Key Components

- **`useDevicesOverview()`** - Fetches device statistics with 1-minute stale time and 2 retry attempts
- **`useChatsOverview()`** - Fetches chat statistics, only enabled in SaaS tenant mode with 3-minute stale time
- **`useSharedDashboardData()`** - Combines both device and chat data with unified loading states and refetch functionality

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useSharedDashboardData } from './use-dashboard-stats'

// Individual hook usage
function DeviceStatsCard() {
  const { total, active, activePercentage, isLoading, error } = useDevicesOverview()
  
  if (isLoading) return <div>Loading device stats...</div>
  if (error) return <div>Error: {error}</div>
  
  return (
    <div>
      <h3>Device Overview</h3>
      <p>Total: {total} | Active: {active} ({activePercentage}%)</p>
    </div>
  )
}

// Combined data usage
function DashboardOverview() {
  const { devices, chats, isAnyLoading, refetchAll } = useSharedDashboardData()
  
  return (
    <div>
      <button onClick={refetchAll} disabled={isAnyLoading}>
        {isAnyLoading ? 'Refreshing...' : 'Refresh All Stats'}
      </button>
      <DeviceStats data={devices.data} />
      <ChatStats data={chats.data} />
    </div>
  )
}
```

The hooks automatically handle caching with React Query, provide fallback values for missing data, and include error handling with user-friendly error messages.
