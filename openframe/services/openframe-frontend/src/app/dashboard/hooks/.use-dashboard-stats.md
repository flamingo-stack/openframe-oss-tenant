React hooks that fetch and aggregate dashboard statistics for devices, chats, and logs from multiple GraphQL endpoints. These hooks provide real-time counts, percentages, and performance metrics for dashboard overview components.

## Key Components

- **`useDevicesOverview()`** - Fetches device statistics including total count, active/inactive devices, and status percentages
- **`useChatsOverview()`** - Retrieves chat dialog statistics with resolution metrics and AI rating averages
- **`useLogsOverview()`** - Aggregates log entry counts by severity level (info, warning, critical) with pagination

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useLogsOverview } from './use-dashboard-stats'

function DashboardOverview() {
  const devices = useDevicesOverview()
  const chats = useChatsOverview()
  const logs = useLogsOverview()

  if (devices.isLoading) {
    return <div>Loading dashboard statistics...</div>
  }

  return (
    <div className="dashboard-stats">
      <div className="device-stats">
        <h3>Devices: {devices.total}</h3>
        <p>Active: {devices.active} ({devices.activePercentage}%)</p>
        <p>Inactive: {devices.inactive} ({devices.inactivePercentage}%)</p>
      </div>

      <div className="chat-stats">
        <h3>Support Chats: {chats.total}</h3>
        <p>Active: {chats.active} ({chats.activePercentage}%)</p>
        <p>Avg Resolution: {chats.avgResolveTime}</p>
        <p>Fae AI Rating: {chats.avgFaeRate}/5</p>
      </div>

      <div className="log-stats">
        <h3>System Logs: {logs.total}</h3>
        <p>Critical: {logs.critical} ({logs.criticalPercentage}%)</p>
        <p>Warnings: {logs.warning} ({logs.warningPercentage}%)</p>
        <p>Info: {logs.info} ({logs.infoPercentage}%)</p>
      </div>
    </div>
  )
}
```

Each hook handles loading states, error handling, and cleanup to prevent memory leaks when components unmount.
