A React Query-based hook module that provides dashboard statistics for device and chat data with intelligent caching and SaaS mode detection.

## Key Components

- **`useDevicesOverview`** - Fetches and manages device statistics (total, active, inactive counts and percentages)
- **`useChatsOverview`** - Fetches chat statistics with SaaS mode conditional loading (total, active, resolved, response times)
- **`useSharedDashboardData`** - Combines both device and chat data queries with unified loading states and refetch capabilities

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useSharedDashboardData } from './use-dashboard-stats'

// Individual device stats
function DeviceStatsComponent() {
  const { total, active, activePercentage, isLoading, error, refetch } = useDevicesOverview()
  
  if (isLoading) return <div>Loading device stats...</div>
  if (error) return <div>Error: {error}</div>
  
  return (
    <div>
      <h3>Devices: {total} total ({activePercentage}% active)</h3>
      <button onClick={() => refetch()}>Refresh</button>
    </div>
  )
}

// Combined dashboard data
function DashboardComponent() {
  const { devices, chats, isAnyLoading, refetchAll } = useSharedDashboardData()
  
  return (
    <div>
      <DeviceStats data={devices.data} />
      <ChatStats data={chats.data} />
      {isAnyLoading && <div>Loading...</div>}
      <button onClick={refetchAll}>Refresh All</button>
    </div>
  )
}
```

The hooks feature optimized caching (1-3 minute stale times), automatic retry logic, and conditional execution based on SaaS tenant mode for chat statistics.
