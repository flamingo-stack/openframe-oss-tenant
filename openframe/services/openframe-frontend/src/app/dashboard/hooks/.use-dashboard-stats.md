A React Query-based hook library for managing dashboard statistics data with optimized caching and error handling for both device and chat metrics in the Flamingo platform.

## Key Components

- **`useDevicesOverview()`** - Fetches device statistics including total counts, active/inactive devices, and percentage distributions
- **`useChatsOverview()`** - Retrieves chat metrics with SaaS mode detection, including resolution times and Fae AI rates
- **`useSharedDashboardData()`** - Combines both device and chat data into a unified interface with collective loading states

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useSharedDashboardData } from './use-dashboard-stats'

// Individual hook usage
function DeviceMetrics() {
  const { total, active, activePercentage, isLoading, error } = useDevicesOverview()
  
  if (isLoading) return <div>Loading device stats...</div>
  if (error) return <div>Error: {error}</div>
  
  return (
    <div>
      <h3>Devices: {total}</h3>
      <p>Active: {active} ({activePercentage}%)</p>
    </div>
  )
}

// Combined dashboard usage
function DashboardOverview() {
  const { devices, chats, isAnyLoading, refetchAll } = useSharedDashboardData()
  
  return (
    <div>
      <button onClick={refetchAll}>Refresh All</button>
      {isAnyLoading ? (
        <div>Loading dashboard...</div>
      ) : (
        <>
          <div>Total Devices: {devices.data.total}</div>
          <div>Active Chats: {chats.data.active}</div>
        </>
      )}
    </div>
  )
}
```

The hooks implement intelligent caching with 1-3 minute stale times and include SaaS tenant mode detection for conditional chat statistics fetching.
