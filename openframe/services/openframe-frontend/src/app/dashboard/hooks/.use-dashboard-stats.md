React Query hooks for fetching and managing OpenFrame dashboard statistics with built-in caching, error handling, and SaaS mode support.

## Key Components

- **`useDevicesOverview()`** - Fetches device statistics including total, active/inactive counts and percentages
- **`useChatsOverview()`** - Fetches chat statistics with SaaS mode detection, including resolution metrics and Fae AI rates
- **`useSharedDashboardData()`** - Combines both device and chat data with unified loading states and batch refetch capabilities

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useSharedDashboardData } from './use-dashboard-stats'

// Individual hook usage
function DevicesDashboard() {
  const { total, active, activePercentage, isLoading, error } = useDevicesOverview()
  
  if (isLoading) return <div>Loading devices...</div>
  if (error) return <div>Error: {error}</div>
  
  return (
    <div>
      <h2>Devices: {total}</h2>
      <p>Active: {active} ({activePercentage}%)</p>
    </div>
  )
}

// Combined dashboard usage
function Dashboard() {
  const { devices, chats, isAnyLoading, refetchAll } = useSharedDashboardData()
  
  return (
    <div>
      <button onClick={refetchAll}>Refresh All</button>
      {isAnyLoading ? (
        <div>Loading dashboard...</div>
      ) : (
        <>
          <DeviceStats data={devices.data} />
          <ChatStats data={chats.data} />
        </>
      )}
    </div>
  )
}
```

The hooks implement React Query best practices with appropriate caching strategies (1-3 minute stale times), retry logic, and automatic garbage collection. Chat statistics are conditionally enabled based on SaaS tenant mode detection.
