A React hook module that provides data fetching functionality for dashboard statistics in the Flamingo/OpenFrame platform. It manages device overview data and chat statistics with optimized caching and conditional loading based on application mode.

## Key Components

- **`useDevicesOverview()`** - Hook for fetching device statistics including total, active, inactive counts and percentages
- **`useChatsOverview()`** - Hook for fetching chat statistics with SaaS mode conditional loading
- **`useSharedDashboardData()`** - Composite hook that combines both device and chat data with unified loading states

The hooks use TanStack Query for efficient data fetching with built-in caching (1-3 minute stale time), retry logic, and garbage collection strategies.

## Usage Example

```typescript
import { useDevicesOverview, useSharedDashboardData } from './use-dashboard-stats'

// Single data source
function DeviceStatsCard() {
  const { total, active, activePercentage, isLoading, error } = useDevicesOverview()
  
  if (isLoading) return <div>Loading devices...</div>
  if (error) return <div>Error: {error}</div>
  
  return (
    <div>
      <h3>Devices: {total}</h3>
      <p>Active: {active} ({activePercentage}%)</p>
    </div>
  )
}

// Combined dashboard data
function DashboardOverview() {
  const { devices, chats, isAnyLoading, refetchAll } = useSharedDashboardData()
  
  return (
    <div>
      <button onClick={refetchAll} disabled={isAnyLoading}>
        Refresh All Data
      </button>
      {/* Use devices.data and chats.data */}
    </div>
  )
}
```
