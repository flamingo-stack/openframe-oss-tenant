A React hook collection that provides dashboard statistics for devices, chats, and logs through GraphQL API calls, managing loading states and calculating percentage distributions for OpenFrame dashboard components.

## Key Components

- **useDevicesOverview()** - Fetches device statistics including total count, active/inactive devices, and their percentages
- **useChatsOverview()** - Retrieves chat dialog statistics with active/resolved counts, average resolution time, and Fae ratings
- **useLogsOverview()** - Collects log statistics by severity (info, warning, critical) with pagination support

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useLogsOverview } from './use-dashboard-stats'

function DashboardStats() {
  const deviceStats = useDevicesOverview()
  const chatStats = useChatsOverview()
  const logStats = useLogsOverview()

  if (deviceStats.isLoading) return <div>Loading...</div>

  return (
    <div>
      <div>
        Devices: {deviceStats.total} total, {deviceStats.activePercentage}% active
      </div>
      <div>
        Chats: {chatStats.total} total, avg resolve time: {chatStats.avgResolveTime}
      </div>
      <div>
        Logs: {logStats.total} total ({logStats.criticalPercentage}% critical)
      </div>
    </div>
  )
}
```

Each hook returns calculated statistics with percentages, handles GraphQL errors gracefully by maintaining default values, and includes proper cleanup with mounted state checks to prevent memory leaks.
