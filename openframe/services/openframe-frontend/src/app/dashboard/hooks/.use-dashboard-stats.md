Custom React hooks for fetching and managing dashboard statistics across devices, chats, and logs with real-time data aggregation and percentage calculations.

## Key Components

- **`useDevicesOverview()`** - Fetches device statistics including total count, active/inactive devices with percentages
- **`useChatsOverview()`** - Retrieves chat dialog statistics including total, active, resolved counts, average resolution time, and Fae ratings  
- **`useLogsOverview()`** - Aggregates log statistics by severity levels (info, warning, critical) with percentage breakdowns
- **State Management** - Each hook maintains loading states and handles errors gracefully by preserving default values
- **Memory Leak Prevention** - Uses `isMounted` flags to prevent state updates after component unmounting

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useLogsOverview } from './use-dashboard-stats'

function DashboardPage() {
  const deviceStats = useDevicesOverview()
  const chatStats = useChatsOverview() 
  const logStats = useLogsOverview()

  if (deviceStats.isLoading) {
    return <div>Loading dashboard...</div>
  }

  return (
    <div className="dashboard-grid">
      <DeviceCard 
        total={deviceStats.total}
        active={deviceStats.active}
        activePercentage={deviceStats.activePercentage}
      />
      <ChatCard
        total={chatStats.total}
        resolved={chatStats.resolved}
        avgResolveTime={chatStats.avgResolveTime}
        avgFaeRate={chatStats.avgFaeRate}
      />
      <LogsCard
        total={logStats.total}
        critical={logStats.critical}
        criticalPercentage={logStats.criticalPercentage}
      />
    </div>
  )
}
```

The hooks automatically fetch data on mount and provide structured statistics objects with computed percentages, making it easy to display comprehensive dashboard metrics across the OpenFrame platform.
