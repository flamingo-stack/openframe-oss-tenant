React Query hooks for fetching and managing dashboard statistics in the Flamingo MSP platform. Provides device overview, chat analytics, and combined dashboard data with optimized caching and error handling.

## Key Components

- **`useDevicesOverview()`** - Fetches device statistics including total, active/inactive counts and percentages
- **`useChatsOverview()`** - Retrieves chat analytics with SaaS mode detection, resolution metrics, and Fae AI performance rates
- **`useSharedDashboardData()`** - Combines both device and chat data with unified loading states and batch refetch capability

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useSharedDashboardData } from './use-dashboard-stats'

function DashboardComponent() {
  // Individual hook usage
  const devices = useDevicesOverview()
  const chats = useChatsOverview()
  
  // Combined usage for full dashboard
  const dashboard = useSharedDashboardData()
  
  if (dashboard.isAnyLoading) {
    return <div>Loading dashboard...</div>
  }
  
  return (
    <div>
      <div>Active Devices: {devices.active} ({devices.activePercentage}%)</div>
      <div>Chat Resolution Time: {chats.avgResolveTime}</div>
      <div>Fae AI Success Rate: {chats.avgFaeRate}%</div>
      <button onClick={dashboard.refetchAll}>
        Refresh All Data
      </button>
    </div>
  )
}
```

The hooks include automatic caching (1-3 minute stale time), error handling with retries, and conditional querying based on app mode. Chat statistics are only fetched in SaaS tenant mode for multi-tenant deployments.
