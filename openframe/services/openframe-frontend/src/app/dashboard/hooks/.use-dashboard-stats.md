A React hooks module that provides dashboard statistics for devices, chats, and logs in the Flamingo MSP platform. Each hook fetches real-time data and calculates performance metrics and percentages.

## Key Components

- **`useDevicesOverview`** - Fetches device statistics including total count, active/inactive devices, and status percentages
- **`useChatsOverview`** - Retrieves chat dialog statistics with resolution metrics, ratings, and status breakdowns  
- **`useLogsOverview`** - Aggregates log data by severity levels (info, warning, critical) with distribution percentages

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useLogsOverview } from './use-dashboard-stats'

function DashboardSummary() {
  const devices = useDevicesOverview()
  const chats = useChatsOverview()
  const logs = useLogsOverview()

  if (devices.isLoading) {
    return <div>Loading device stats...</div>
  }

  return (
    <div className="dashboard-grid">
      <div className="stat-card">
        <h3>Devices</h3>
        <p>Total: {devices.total}</p>
        <p>Active: {devices.activePercentage}%</p>
      </div>
      
      <div className="stat-card">
        <h3>Support Chats</h3>
        <p>Total: {chats.total}</p>
        <p>Avg Resolution: {chats.avgResolveTime}</p>
        <p>Fae Rating: {chats.avgFaeRate}/5</p>
      </div>
      
      <div className="stat-card">
        <h3>System Logs</h3>
        <p>Total: {logs.total}</p>
        <p>Critical: {logs.criticalPercentage}%</p>
      </div>
    </div>
  )
}
```
