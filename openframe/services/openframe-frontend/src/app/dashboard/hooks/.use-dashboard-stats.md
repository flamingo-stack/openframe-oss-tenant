A React Query hook collection that provides dashboard statistics for device and chat data with optimized caching and error handling. The hooks include device overview metrics, chat statistics (SaaS mode only), and a combined data fetcher.

## Key Components

- **`useDevicesOverview()`** - Fetches device statistics including total, active/inactive counts and percentages
- **`useChatsOverview()`** - Retrieves chat metrics like resolution times and Fae AI rates (SaaS tenant mode only)
- **`useSharedDashboardData()`** - Combines both device and chat queries with unified loading states and refresh functionality

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useSharedDashboardData } from './use-dashboard-stats'

// Individual device stats
function DeviceMetrics() {
  const { total, active, activePercentage, isLoading, error } = useDevicesOverview()
  
  if (isLoading) return <div>Loading devices...</div>
  if (error) return <div>Error: {error}</div>
  
  return (
    <div>
      <h3>Devices: {total}</h3>
      <p>Active: {active} ({activePercentage}%)</p>
    </div>
  )
}

// Combined dashboard data
function DashboardOverview() {
  const { devices, chats, isAnyLoading, refetchAll } = useSharedDashboardData()
  
  return (
    <div>
      <button onClick={refetchAll} disabled={isAnyLoading}>
        Refresh All Stats
      </button>
      <DeviceStats data={devices.data} />
      <ChatStats data={chats.data} />
    </div>
  )
}
```

The hooks implement intelligent caching with 1-3 minute stale times, automatic retries, and conditional fetching based on application mode (SaaS vs self-hosted).
