Custom React hooks for fetching and managing dashboard statistics data across devices, chats, and logs in the Flamingo MSP platform. Provides real-time overview metrics with loading states and error handling.

## Key Components

- **`useDevicesOverview()`** - Fetches device statistics including total count, active/inactive devices with percentages
- **`useChatsOverview()`** - Retrieves chat dialog statistics with resolution metrics and Fae AI ratings  
- **`useLogsOverview()`** - Aggregates log data by severity levels (info, warning, critical) with pagination support

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useLogsOverview } from './use-dashboard-stats'

function DashboardOverview() {
  const { 
    total: deviceTotal, 
    active, 
    inactive, 
    activePercentage,
    isLoading: devicesLoading 
  } = useDevicesOverview()
  
  const { 
    total: chatTotal,
    resolved,
    avgResolveTime,
    avgFaeRate 
  } = useChatsOverview()
  
  const {
    total: logTotal,
    critical,
    warning,
    criticalPercentage
  } = useLogsOverview()

  if (devicesLoading) return <div>Loading...</div>

  return (
    <div>
      <div>Devices: {active}/{deviceTotal} online ({activePercentage}%)</div>
      <div>Chats: {resolved} resolved, avg {avgResolveTime}, Fae rating {avgFaeRate}</div>
      <div>Logs: {critical} critical ({criticalPercentage}%)</div>
    </div>
  )
}
```

Each hook handles GraphQL API calls with proper error handling, cleanup on unmount, and provides structured statistics objects for dashboard visualization components.
