Custom React hooks for fetching and managing dashboard statistics data with optimized caching and error handling. Provides device metrics, chat analytics, and combined dashboard data management.

## Key Components

- **useDevicesOverview()** - Hook for device statistics with 1-minute cache and device activity percentages
- **useChatsOverview()** - Hook for chat metrics with SaaS mode detection and Fae AI performance data
- **useSharedDashboardData()** - Composite hook that combines device and chat data with unified loading states

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useSharedDashboardData } from './use-dashboard-stats'

function DashboardPage() {
  // Individual hooks for specific data
  const devices = useDevicesOverview()
  const chats = useChatsOverview()
  
  // Combined hook for dashboard overview
  const dashboard = useSharedDashboardData()

  return (
    <div>
      {/* Device Statistics */}
      <div>
        <h2>Devices: {devices.total}</h2>
        <p>Active: {devices.activePercentage}%</p>
        {devices.isLoading && <span>Loading...</span>}
      </div>

      {/* Chat Analytics (SaaS only) */}
      <div>
        <h2>Chats: {chats.total}</h2>
        <p>Avg Fae Rate: {chats.avgFaeRate}%</p>
        <p>Resolve Time: {chats.avgResolveTime}</p>
      </div>

      {/* Refresh all data */}
      <button onClick={dashboard.refetchAll}>
        Refresh Dashboard
      </button>
    </div>
  )
}
```

The hooks automatically handle caching (1-3 minute stale times), retries, and provide normalized data structures with fallback values for reliable UI rendering.
