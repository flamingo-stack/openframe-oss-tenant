Custom React hooks for fetching and managing dashboard statistics across devices, chat dialogs, and system logs with real-time data aggregation.

## Key Components

- **useDevicesOverview()** - Fetches device status counts and calculates active/inactive percentages
- **useChatsOverview()** - Retrieves chat dialog statistics including resolution times and Fae AI ratings
- **useLogsOverview()** - Aggregates system log counts by severity level with pagination support

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useLogsOverview } from './use-dashboard-stats'

function DashboardStats() {
  const { total, active, inactive, activePercentage, isLoading } = useDevicesOverview()
  const { total: chatTotal, avgResolveTime, avgFaeRate } = useChatsOverview()
  const { total: logTotal, critical, criticalPercentage } = useLogsOverview()

  if (isLoading) return <div>Loading...</div>

  return (
    <div className="dashboard-grid">
      <div>
        <h3>Devices</h3>
        <p>{active}/{total} active ({activePercentage}%)</p>
      </div>
      <div>
        <h3>Support Chats</h3>
        <p>Avg resolve: {avgResolveTime} | Fae rating: {avgFaeRate}</p>
      </div>
      <div>
        <h3>System Logs</h3>
        <p>{critical} critical ({criticalPercentage}%)</p>
      </div>
    </div>
  )
}
```

Each hook handles GraphQL API calls with proper error handling and cleanup, returning calculated statistics and loading states for dashboard widgets.
