A React hook collection that provides dashboard statistics for devices, chats, and logs through GraphQL API integration.

## Key Components

- **`useDevicesOverview()`** - Fetches device status counts and calculates active/inactive percentages with loading state
- **`useChatsOverview()`** - Retrieves chat dialog statistics including resolution times and Fae ratings
- **`useLogsOverview()`** - Aggregates log severity counts across multiple paginated requests

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useLogsOverview } from './use-dashboard-stats'

function DashboardPage() {
  const { total, active, inactive, activePercentage, isLoading } = useDevicesOverview()
  const { total: chatTotal, avgResolveTime, avgFaeRate } = useChatsOverview()
  const { info, warning, critical, infoPercentage } = useLogsOverview()

  if (isLoading) return <div>Loading device stats...</div>

  return (
    <div>
      <div>Devices: {active}/{total} active ({activePercentage}%)</div>
      <div>Avg Resolution: {avgResolveTime}, Fae Rating: {avgFaeRate}</div>
      <div>Logs: {info} info, {warning} warnings, {critical} critical</div>
    </div>
  )
}
```

Each hook includes error handling that maintains default values on failure, cleanup functions to prevent memory leaks, and percentage calculations for dashboard visualization. The logs hook implements cursor-based pagination to aggregate data across multiple API calls.
