A custom React hooks module that provides dashboard statistics for devices, chat dialogs, and logs by fetching data from GraphQL APIs and computing percentage distributions.

## Key Components

- **`useDevicesOverview`** - Fetches device status statistics (total, active/inactive counts and percentages)
- **`useChatsOverview`** - Retrieves chat dialog statistics including resolution metrics and AI ratings
- **`useLogsOverview`** - Collects log severity counts (info/warning/critical) with percentage breakdowns

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useLogsOverview } from './use-dashboard-stats'

function DashboardStatsComponent() {
  const { total, active, inactive, activePercentage, isLoading } = useDevicesOverview()
  const { total: chatTotal, avgResolveTime, avgFaeRate } = useChatsOverview()
  const { total: logsTotal, critical, criticalPercentage } = useLogsOverview()

  if (isLoading) return <div>Loading...</div>

  return (
    <div className="dashboard-stats">
      <div className="device-stats">
        <h3>Devices: {total}</h3>
        <p>Active: {active} ({activePercentage}%)</p>
      </div>
      <div className="chat-stats">
        <h3>Chats: {chatTotal}</h3>
        <p>Avg Resolve Time: {avgResolveTime}</p>
        <p>Avg FAE Rating: {avgFaeRate}</p>
      </div>
      <div className="logs-stats">
        <h3>Logs: {logsTotal}</h3>
        <p>Critical: {critical} ({criticalPercentage}%)</p>
      </div>
    </div>
  )
}
```

Each hook handles error states gracefully by maintaining default values, includes proper cleanup with `isMounted` flags, and automatically calculates percentage distributions for dashboard visualization.
