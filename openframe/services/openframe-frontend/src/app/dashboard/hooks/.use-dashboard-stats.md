A custom React hooks file that provides real-time dashboard statistics for devices, chats, and logs with GraphQL data fetching and error handling.

## Key Components

- **`useDevicesOverview()`** - Fetches device statistics including total, active, inactive counts with percentages
- **`useChatsOverview()`** - Retrieves chat dialog statistics including resolution metrics and Fae ratings
- **`useLogsOverview()`** - Aggregates log data by severity levels (info, warning, critical) with pagination handling

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useLogsOverview } from './use-dashboard-stats'

function DashboardComponent() {
  const deviceStats = useDevicesOverview()
  const chatStats = useChatsOverview()
  const logStats = useLogsOverview()

  if (deviceStats.isLoading) {
    return <div>Loading device statistics...</div>
  }

  return (
    <div>
      <div>
        <h3>Devices: {deviceStats.total}</h3>
        <p>Active: {deviceStats.activePercentage}%</p>
      </div>
      
      <div>
        <h3>Chats: {chatStats.total}</h3>
        <p>Average Fae Rating: {chatStats.avgFaeRate}</p>
        <p>Avg Resolution: {chatStats.avgResolveTime}</p>
      </div>
      
      <div>
        <h3>Logs: {logStats.total}</h3>
        <p>Critical: {logStats.criticalPercentage}%</p>
      </div>
    </div>
  )
}
```

Each hook implements proper cleanup with `isMounted` flags to prevent memory leaks and handles API errors gracefully by maintaining default values.
