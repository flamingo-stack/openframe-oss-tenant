A React hook module that provides dashboard statistics for devices, chats, and logs with real-time data fetching and percentage calculations.

## Key Components

- **useDevicesOverview()** - Fetches device statistics including total count, active/inactive devices with percentages
- **useChatsOverview()** - Retrieves chat dialog statistics including resolution metrics and Fae ratings
- **useLogsOverview()** - Aggregates log entries by severity levels (info, warning, critical) with distribution percentages

## Usage Example

```typescript
import { useDevicesOverview, useChatsOverview, useLogsOverview } from './use-dashboard-stats'

export function DashboardStats() {
  const devices = useDevicesOverview()
  const chats = useChatsOverview()
  const logs = useLogsOverview()

  if (devices.isLoading) {
    return <div>Loading dashboard stats...</div>
  }

  return (
    <div className="dashboard-grid">
      <div className="stat-card">
        <h3>Devices Overview</h3>
        <p>Total: {devices.total}</p>
        <p>Active: {devices.active} ({devices.activePercentage}%)</p>
        <p>Inactive: {devices.inactive} ({devices.inactivePercentage}%)</p>
      </div>
      
      <div className="stat-card">
        <h3>Support Chats</h3>
        <p>Total: {chats.total}</p>
        <p>Avg Resolution: {chats.avgResolveTime}</p>
        <p>Fae Rating: {chats.avgFaeRate}</p>
      </div>
      
      <div className="stat-card">
        <h3>System Logs</h3>
        <p>Total: {logs.total}</p>
        <p>Critical: {logs.critical} ({logs.criticalPercentage}%)</p>
        <p>Warning: {logs.warning} ({logs.warningPercentage}%)</p>
      </div>
    </div>
  )
}
```

The hooks handle error states gracefully by maintaining default values and include cleanup mechanisms to prevent memory leaks from unmounted components.
