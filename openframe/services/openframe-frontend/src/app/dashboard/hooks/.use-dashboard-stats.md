Custom React hooks for managing dashboard statistics with optimized caching and tenant mode awareness. Provides device metrics, chat analytics, and combined data access with automatic retry logic and performance optimization.

## Key Components

### Core Hooks
- **`useDevicesOverview()`** - Fetches and manages device statistics (total, active, inactive, percentages)
- **`useChatsOverview()`** - Retrieves chat metrics with SaaS tenant mode validation
- **`useSharedDashboardData()`** - Combines device and chat data with unified loading states

### Key Features
- **Smart Caching** - 1-minute stale time for devices, 3-minute for chats
- **Tenant Awareness** - Chat stats only enabled in SaaS mode
- **Error Handling** - Automatic retries with exponential backoff
- **Normalized Data** - Consistent fallback values and error states

## Usage Example

```typescript
import { useDevicesOverview, useSharedDashboardData } from './use-dashboard-stats'

// Individual hook usage
function DeviceStatsCard() {
  const { total, active, activePercentage, isLoading, error } = useDevicesOverview()
  
  if (isLoading) return <Spinner />
  if (error) return <Error message={error} />
  
  return (
    <div>
      <h3>Devices: {total}</h3>
      <p>Active: {active} ({activePercentage}%)</p>
    </div>
  )
}

// Combined data usage
function DashboardOverview() {
  const { devices, chats, isAnyLoading, refetchAll } = useSharedDashboardData()
  
  return (
    <div>
      <DeviceMetrics data={devices.data} />
      <ChatMetrics data={chats.data} />
      <button onClick={refetchAll}>Refresh All</button>
    </div>
  )
}
```
