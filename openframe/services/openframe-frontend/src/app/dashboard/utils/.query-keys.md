A centralized query key factory for managing React Query cache keys across dashboard components, providing type-safe and hierarchical key structure for data fetching operations.

## Key Components

- **`dashboardQueryKeys`** - Main factory object containing all query key generators
- **`all`** - Root key for all dashboard-related queries
- **`deviceStats()`** - Query keys for device statistics data
- **`chatStats()`** - Query keys for chat statistics (SaaS mode only)
- **`orgStats(limit)`** - Parameterized query keys for organization statistics
- **`invalidateAll()`** - Utility for invalidating all dashboard queries

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query'
import { dashboardQueryKeys } from './query-keys'

// Using query keys in hooks
const { data: deviceStats } = useQuery({
  queryKey: dashboardQueryKeys.deviceStats(),
  queryFn: fetchDeviceStats
})

const { data: orgStats } = useQuery({
  queryKey: dashboardQueryKeys.orgStats(10),
  queryFn: () => fetchOrgStats(10)
})

// Invalidating queries
const queryClient = useQueryClient()
queryClient.invalidateQueries({
  queryKey: dashboardQueryKeys.invalidateAll()
})

// Invalidating specific query types
queryClient.invalidateQueries({
  queryKey: dashboardQueryKeys.deviceStats()
})
```

The hierarchical structure enables efficient cache management and selective invalidation of related queries throughout the dashboard application.
