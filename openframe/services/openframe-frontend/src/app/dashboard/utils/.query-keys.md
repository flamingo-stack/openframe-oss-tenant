Centralized query key factory for React Query hooks in the Flamingo dashboard, providing consistent cache key management for dashboard statistics and data invalidation.

## Key Components

- **dashboardQueryKeys** - Main query key factory with hierarchical key structure
- **all** - Root dashboard cache key for broad invalidation
- **deviceStats** - Query keys for device statistics data
- **chatStats** - Query keys for SaaS chat statistics (subscription-dependent)
- **orgStats** - Parameterized query keys for organization statistics with limit filtering
- **invalidateAll** - Helper method for invalidating all dashboard-related queries

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query'
import { dashboardQueryKeys } from './query-keys'

// Using query keys in React Query hooks
const { data: deviceStats } = useQuery({
  queryKey: dashboardQueryKeys.deviceStats(),
  queryFn: fetchDeviceStatistics,
})

const { data: orgStats } = useQuery({
  queryKey: dashboardQueryKeys.orgStats(10),
  queryFn: () => fetchOrgStatistics(10),
})

// Invalidating dashboard data
const queryClient = useQueryClient()
queryClient.invalidateQueries({
  queryKey: dashboardQueryKeys.invalidateAll()
})

// Invalidating specific statistics
queryClient.invalidateQueries({
  queryKey: dashboardQueryKeys.chatStats()
})
```

This pattern ensures consistent cache management across the dashboard, enables selective data invalidation, and provides type-safe query keys for React Query operations in the Flamingo MSP platform.
