A centralized query key factory that provides consistent, hierarchical cache keys for dashboard-related React Query operations, supporting device statistics, chat analytics, and organization metrics.

## Key Components

- **`dashboardQueryKeys`** - Main factory object exporting standardized query key patterns
- **`all`** - Root-level cache key for all dashboard queries
- **`deviceStats()`** - Query key for device statistics data
- **`chatStats()`** - Query key for chat statistics (SaaS mode only)
- **`orgStats(limit)`** - Parameterized query key for organization statistics with pagination
- **`invalidateAll()`** - Helper for bulk cache invalidation

## Usage Example

```typescript
import { useQuery } from '@tanstack/react-query'
import { dashboardQueryKeys } from './query-keys'

// Device statistics query
const { data: deviceStats } = useQuery({
  queryKey: dashboardQueryKeys.deviceStats(),
  queryFn: fetchDeviceStats,
})

// Organization stats with pagination
const { data: orgStats } = useQuery({
  queryKey: dashboardQueryKeys.orgStats(10),
  queryFn: () => fetchOrgStats({ limit: 10 }),
})

// Bulk invalidation
queryClient.invalidateQueries({
  queryKey: dashboardQueryKeys.invalidateAll()
})
```

This factory ensures consistent cache key naming and enables efficient query invalidation patterns across the dashboard module.
