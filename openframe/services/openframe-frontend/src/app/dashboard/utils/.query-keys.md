A centralized query key factory for React Query hooks used throughout the dashboard, providing consistent cache key generation for device statistics, chat statistics, and organization data.

## Key Components

- **`dashboardQueryKeys.all`** - Base key array for all dashboard-related queries
- **`deviceStats()`** - Query key factory for device statistics data
- **`chatStats()`** - Query key factory for chat statistics (SaaS mode only)
- **`orgStats(limit)`** - Parameterized query key factory for organization statistics with pagination
- **`invalidateAll()`** - Helper method to invalidate all dashboard queries

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query'
import { dashboardQueryKeys } from './query-keys'

// Using query keys in hooks
const { data: deviceStats } = useQuery({
  queryKey: dashboardQueryKeys.deviceStats(),
  queryFn: fetchDeviceStats,
})

const { data: orgStats } = useQuery({
  queryKey: dashboardQueryKeys.orgStats(10),
  queryFn: () => fetchOrgStats(10),
})

// Invalidating queries
const queryClient = useQueryClient()
const handleRefresh = () => {
  queryClient.invalidateQueries({
    queryKey: dashboardQueryKeys.invalidateAll()
  })
}
```
