Centralized query key factory for React Query cache management in dashboard components, providing type-safe keys for device statistics, chat statistics, and organization data.

## Key Components

- **`dashboardQueryKeys`** - Main factory object containing all dashboard-related query keys
- **`all`** - Root key for all dashboard queries (`['dashboard']`)
- **`deviceStats()`** - Query key for device statistics data
- **`chatStats()`** - Query key for chat statistics (SaaS mode only)
- **`orgStats(limit)`** - Parameterized query key for organization statistics with limit
- **`invalidateAll()`** - Helper for invalidating all dashboard queries

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query'
import { dashboardQueryKeys } from './query-keys'

// Use in React Query hooks
const { data: deviceStats } = useQuery({
  queryKey: dashboardQueryKeys.deviceStats(),
  queryFn: fetchDeviceStats,
})

const { data: orgStats } = useQuery({
  queryKey: dashboardQueryKeys.orgStats(10),
  queryFn: () => fetchOrgStats(10),
})

// Invalidate all dashboard queries
const queryClient = useQueryClient()
queryClient.invalidateQueries({
  queryKey: dashboardQueryKeys.invalidateAll()
})
```

This pattern ensures consistent query key structure and enables efficient cache invalidation across dashboard components while maintaining TypeScript type safety with `as const` assertions.
