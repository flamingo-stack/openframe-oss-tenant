A centralized query key factory that provides consistent, hierarchical cache keys for dashboard-related React Query operations in the Flamingo platform.

## Key Components

- **`dashboardQueryKeys`** - Main factory object containing all dashboard query key generators
- **`all`** - Root dashboard key used as base for all dashboard queries
- **`deviceStats()`** - Generates keys for device statistics queries
- **`chatStats()`** - Generates keys for chat statistics queries (SaaS mode only)
- **`orgStats(limit)`** - Generates parameterized keys for organization statistics with limit parameter
- **`invalidateAll()`** - Provides the root key for invalidating all dashboard queries

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query'
import { dashboardQueryKeys } from './query-keys'

// Using query keys in hooks
const { data: deviceStats } = useQuery({
  queryKey: dashboardQueryKeys.deviceStats(),
  queryFn: fetchDeviceStats,
})

const { data: orgStats } = useQuery({
  queryKey: dashboardQueryKeys.orgStats(10),
  queryFn: () => fetchOrgStats({ limit: 10 }),
})

// Invalidating all dashboard queries
const queryClient = useQueryClient()
queryClient.invalidateQueries({
  queryKey: dashboardQueryKeys.invalidateAll()
})
```

This factory pattern ensures consistent cache key naming, enables efficient query invalidation, and provides type safety for React Query operations across the dashboard components.
