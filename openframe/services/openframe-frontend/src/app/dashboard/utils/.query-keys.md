A centralized query key factory for React Query that provides standardized cache keys for dashboard-related data fetching and invalidation operations.

## Key Components

- **`dashboardQueryKeys`** - Main factory object containing hierarchical query key generators
- **`all`** - Root key for all dashboard queries (`['dashboard']`)
- **`deviceStats()`** - Query key for device statistics data
- **`chatStats()`** - Query key for SaaS mode chat statistics
- **`orgStats(limit)`** - Parameterized query key for organization statistics with limit
- **`invalidateAll()`** - Utility method returning the root key for cache invalidation

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query'
import { dashboardQueryKeys } from './query-keys'

// Using query keys in hooks
const deviceStatsQuery = useQuery({
  queryKey: dashboardQueryKeys.deviceStats(),
  queryFn: fetchDeviceStats,
})

const orgStatsQuery = useQuery({
  queryKey: dashboardQueryKeys.orgStats(10),
  queryFn: () => fetchOrgStats(10),
})

// Invalidating all dashboard queries
const queryClient = useQueryClient()
queryClient.invalidateQueries({
  queryKey: dashboardQueryKeys.invalidateAll()
})

// Invalidating specific query
queryClient.invalidateQueries({
  queryKey: dashboardQueryKeys.deviceStats()
})
```

This pattern ensures consistent cache key naming across the application and simplifies query invalidation by providing a hierarchical structure where invalidating the root key affects all related queries.
