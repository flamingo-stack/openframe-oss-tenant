Centralized query key factory for React Query caching in the Flamingo dashboard, providing consistent cache key management for all dashboard-related data queries.

## Key Components

- **`dashboardQueryKeys`** - Main query key factory object with hierarchical key structure
- **`all`** - Root dashboard key for invalidating all dashboard queries
- **`deviceStats()`** - Query keys for device statistics data
- **`chatStats()`** - Query keys for chat statistics (SaaS mode only)
- **`orgStats(limit)`** - Parameterized query keys for organization statistics with limit
- **`invalidateAll()`** - Helper method to get root key for cache invalidation

## Usage Example

```typescript
import { dashboardQueryKeys } from './query-keys'
import { useQuery } from '@tanstack/react-query'

// Use in React Query hooks
const { data: deviceStats } = useQuery({
  queryKey: dashboardQueryKeys.deviceStats(),
  queryFn: fetchDeviceStats,
})

const { data: orgStats } = useQuery({
  queryKey: dashboardQueryKeys.orgStats(10),
  queryFn: () => fetchOrgStats(10),
})

// Invalidate all dashboard queries
queryClient.invalidateQueries({
  queryKey: dashboardQueryKeys.invalidateAll()
})
```

This pattern ensures consistent query key management across the dashboard, enabling efficient caching, invalidation, and data synchronization in the React Query cache hierarchy.
