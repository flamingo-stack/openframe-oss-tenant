Centralized query key factory that provides standardized cache keys for React Query hooks used throughout the dashboard components.

## Key Components

- **`dashboardQueryKeys`** - Main query key factory object with hierarchical key structure
  - **`all`** - Root key for all dashboard queries
  - **`deviceStats()`** - Keys for device statistics queries
  - **`chatStats()`** - Keys for chat statistics (SaaS mode only)
  - **`orgStats(limit)`** - Keys for organization statistics with limit parameter
  - **`invalidateAll()`** - Helper for invalidating all dashboard queries

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query'
import { dashboardQueryKeys } from './query-keys'

// Use query keys in hooks
const { data: deviceStats } = useQuery({
  queryKey: dashboardQueryKeys.deviceStats(),
  queryFn: fetchDeviceStats,
})

const { data: orgStats } = useQuery({
  queryKey: dashboardQueryKeys.orgStats(10),
  queryFn: () => fetchOrgStats(10),
})

// Invalidate all dashboard queries
const queryClient = useQueryClient()
queryClient.invalidateQueries({
  queryKey: dashboardQueryKeys.invalidateAll()
})
```

This factory ensures consistent query key naming across the dashboard, enabling efficient cache management and invalidation patterns for React Query.
