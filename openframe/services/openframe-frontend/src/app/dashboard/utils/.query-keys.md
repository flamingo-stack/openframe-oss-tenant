A centralized factory for generating consistent query keys used by React Query hooks in the dashboard module, following React Query best practices for cache invalidation and data fetching.

## Key Components

- **`dashboardQueryKeys`** - Main query key factory object with hierarchical key structure
- **`all`** - Root key for all dashboard queries (`['dashboard']`)
- **`deviceStats()`** - Query key for device statistics data
- **`chatStats()`** - Query key for chat statistics (SaaS mode specific)
- **`orgStats(limit)`** - Parameterized query key for organization statistics with limit
- **`invalidateAll()`** - Utility for bulk cache invalidation

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query'
import { dashboardQueryKeys } from './query-keys'

// Using query keys in hooks
const { data: deviceStats } = useQuery({
  queryKey: dashboardQueryKeys.deviceStats(),
  queryFn: fetchDeviceStats,
})

const { data: orgStats } = useQuery({
  queryKey: dashboardQueryKeys.orgStats(10),
  queryFn: () => fetchOrgStats(10),
})

// Invalidating queries
const queryClient = useQueryClient()
queryClient.invalidateQueries({ 
  queryKey: dashboardQueryKeys.invalidateAll() 
})

// Invalidating specific queries
queryClient.invalidateQueries({ 
  queryKey: dashboardQueryKeys.chatStats() 
})
```

The hierarchical structure enables precise cache control - you can invalidate all dashboard queries or target specific data types while maintaining type safety with TypeScript's `const` assertions.
