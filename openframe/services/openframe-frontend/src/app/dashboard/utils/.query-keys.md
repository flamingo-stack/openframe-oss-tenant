A centralized query key factory that provides consistent cache keys for React Query hooks in the dashboard module, following hierarchical key patterns for efficient cache invalidation.

## Key Components

- **`dashboardQueryKeys`** - Main factory object containing all dashboard-related query keys
- **`all`** - Root key for all dashboard queries, used as base for hierarchical keys
- **`deviceStats()`** - Query key for device statistics data
- **`chatStats()`** - Query key for chat statistics (SaaS mode specific)
- **`orgStats(limit)`** - Parameterized query key for organization statistics with limit parameter
- **`invalidateAll()`** - Utility method that returns the root key for bulk cache invalidation

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query'
import { dashboardQueryKeys } from './query-keys'

// Using query keys in hooks
const { data: deviceStats } = useQuery({
  queryKey: dashboardQueryKeys.deviceStats(),
  queryFn: fetchDeviceStatistics
})

const { data: orgStats } = useQuery({
  queryKey: dashboardQueryKeys.orgStats(10),
  queryFn: () => fetchOrgStatistics(10)
})

// Invalidating all dashboard queries
const queryClient = useQueryClient()
queryClient.invalidateQueries({
  queryKey: dashboardQueryKeys.invalidateAll()
})

// Invalidating specific nested queries
queryClient.invalidateQueries({
  queryKey: dashboardQueryKeys.deviceStats()
})
```
