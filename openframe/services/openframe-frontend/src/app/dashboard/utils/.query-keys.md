A centralized query key factory that provides structured, hierarchical cache keys for React Query hooks used in the dashboard module, following React Query best practices for cache invalidation.

## Key Components

- **`all`** - Root namespace for all dashboard-related queries
- **`deviceStats()`** - Query key for device statistics data
- **`chatStats()`** - Query key for SaaS-specific chat statistics  
- **`orgStats(limit)`** - Parameterized query key for organization statistics with pagination
- **`invalidateAll()`** - Helper method to invalidate all dashboard queries at once

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query'
import { dashboardQueryKeys } from './query-keys'

// Using query keys in hooks
const { data: deviceStats } = useQuery({
  queryKey: dashboardQueryKeys.deviceStats(),
  queryFn: fetchDeviceStats,
})

const { data: orgStats } = useQuery({
  queryKey: dashboardQueryKeys.orgStats(10),
  queryFn: () => fetchOrgStats({ limit: 10 }),
})

// Cache invalidation
const queryClient = useQueryClient()
queryClient.invalidateQueries({ 
  queryKey: dashboardQueryKeys.invalidateAll() 
})

// Invalidate specific queries
queryClient.invalidateQueries({ 
  queryKey: dashboardQueryKeys.deviceStats() 
})
```
