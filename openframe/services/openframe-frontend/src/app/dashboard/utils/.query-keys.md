Centralized query key factory for React Query operations in the dashboard module, providing type-safe query key generation and cache invalidation utilities.

## Key Components

- **`dashboardQueryKeys`** - Main factory object containing all dashboard-related query key generators
- **`all`** - Root query key array for dashboard namespace
- **`deviceStats()`** - Generates query keys for device statistics
- **`chatStats()`** - Generates query keys for chat statistics (SaaS mode)
- **`orgStats(limit)`** - Generates parameterized query keys for organization statistics
- **`invalidateAll()`** - Returns root key for bulk cache invalidation

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query'
import { dashboardQueryKeys } from './query-keys'

// Using query keys in hooks
const { data: deviceStats } = useQuery({
  queryKey: dashboardQueryKeys.deviceStats(),
  queryFn: fetchDeviceStats,
})

const { data: orgStats } = useQuery({
  queryKey: dashboardQueryKeys.orgStats(10),
  queryFn: () => fetchOrgStats(10),
})

// Invalidating all dashboard queries
const queryClient = useQueryClient()
await queryClient.invalidateQueries({
  queryKey: dashboardQueryKeys.invalidateAll()
})
```

The factory ensures consistent, hierarchical query keys that enable efficient caching, prefetching, and selective invalidation across the dashboard's data layer.
