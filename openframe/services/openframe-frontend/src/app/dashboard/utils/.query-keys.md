Centralized query key factory for dashboard-related React Query operations, providing consistent cache key generation and invalidation patterns for dashboard statistics.

## Key Components

**`dashboardQueryKeys`** - Main factory object containing:
- `all` - Base query key array for all dashboard queries
- `deviceStats()` - Query keys for device statistics
- `chatStats()` - Query keys for chat statistics (SaaS mode)
- `orgStats(limit)` - Parameterized query keys for organization statistics
- `invalidateAll()` - Utility for invalidating all dashboard queries

## Usage Example

```typescript
import { useQuery, useQueryClient } from '@tanstack/react-query'
import { dashboardQueryKeys } from './query-keys'

// Using query keys in hooks
const { data: deviceStats } = useQuery({
  queryKey: dashboardQueryKeys.deviceStats(),
  queryFn: fetchDeviceStats,
})

const { data: orgStats } = useQuery({
  queryKey: dashboardQueryKeys.orgStats(10),
  queryFn: () => fetchOrgStats(10),
})

// Invalidating dashboard queries
const queryClient = useQueryClient()
queryClient.invalidateQueries({
  queryKey: dashboardQueryKeys.invalidateAll()
})

// Invalidating specific queries
queryClient.invalidateQueries({
  queryKey: dashboardQueryKeys.deviceStats()
})
```

The hierarchical structure ensures proper cache invalidation - invalidating `dashboardQueryKeys.all` will invalidate all related dashboard queries, while specific query keys allow targeted cache updates.
