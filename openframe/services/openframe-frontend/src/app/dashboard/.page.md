A Next.js 14+ client-side dashboard page component that uses dynamic imports for optimized loading and enforces dynamic rendering.

## Key Components

- **Dashboard** - Default exported page component that renders the main dashboard interface
- **DashboardContent** - Dynamically imported component with SSR disabled and custom loading state
- **AppLayout** - Layout wrapper component for consistent page structure
- **DashboardLoading** - Loading component displayed during dynamic import

## Usage Example

This page component is automatically rendered by Next.js when users navigate to the dashboard route:

```typescript
// The component structure provides:
// 1. Client-side rendering with 'use client' directive
// 2. Dynamic import with SSR disabled for performance
// 3. Custom loading state during component loading
// 4. Force dynamic rendering for real-time data

// Navigation example (in other components):
import { useRouter } from 'next/navigation'

function NavigateToDashboard() {
  const router = useRouter()
  
  const handleNavigate = () => {
    router.push('/dashboard') // Loads this page.tsx
  }
  
  return <button onClick={handleNavigate}>Go to Dashboard</button>
}
```

The `dynamic = 'force-dynamic'` export ensures the page is never statically generated and always renders fresh data on each request, making it ideal for dashboards that display real-time information.
