A Next.js dashboard page component that dynamically loads dashboard content with client-side rendering and loading states. This page serves as the main dashboard entry point with optimized loading behavior.

## Key Components

- **Dashboard** - Default exported page component that renders the dashboard layout
- **DashboardContent** - Dynamically imported component for the main dashboard content
- **AppLayout** - Wrapper component providing consistent app layout structure
- **DashboardLoading** - Loading component displayed during dashboard content loading

## Configuration

- `dynamic = 'force-dynamic'` - Forces dynamic rendering to ensure fresh data on each request
- `ssr: false` - Disables server-side rendering for the dashboard content to improve initial page load
- Client-side only rendering with `'use client'` directive

## Usage Example

```typescript
// This page is automatically rendered when accessing /dashboard route
// The component structure provides:
// 1. Immediate layout render via AppLayout
// 2. Loading state via DashboardLoading
// 3. Lazy-loaded content via DashboardContent

// Example of similar dynamic import pattern:
const MyDynamicComponent = nextDynamic(
  () => import('./my-component'),
  { 
    ssr: false, 
    loading: () => <div>Loading...</div> 
  }
)

function MyPage() {
  return (
    <AppLayout>
      <MyDynamicComponent />
    </AppLayout>
  )
}
```
