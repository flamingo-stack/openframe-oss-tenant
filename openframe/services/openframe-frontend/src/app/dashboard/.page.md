A Next.js client-side dashboard page component that dynamically imports dashboard content with loading states and disables server-side rendering for the main content.

## Key Components

- **Dashboard**: Main page component that renders the dashboard layout
- **DynamicContent**: Lazy-loaded dashboard content component with loading fallback
- **AppLayout**: Wrapper component providing consistent page structure
- **DashboardLoading**: Loading component displayed during content import

## Configuration

- `'use client'`: Enables client-side rendering
- `dynamic = 'force-dynamic'`: Forces dynamic rendering, preventing static optimization
- `ssr: false`: Disables server-side rendering for the dashboard content
- Custom loading component handles the import delay

## Usage Example

```typescript
// The dashboard automatically handles:
// 1. Client-side rendering
// 2. Dynamic content loading
// 3. Loading state management
// 4. Consistent layout structure

// When users navigate to /dashboard:
// 1. AppLayout renders immediately
// 2. DashboardLoading shows while importing content
// 3. DashboardContent renders once loaded
```

This pattern is commonly used for dashboard pages that contain heavy client-side components, charts, or real-time data that don't benefit from server-side rendering.
