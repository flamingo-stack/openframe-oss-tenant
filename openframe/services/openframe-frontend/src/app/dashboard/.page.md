A Next.js dashboard page component that implements client-side rendering with dynamic loading and enforced dynamic behavior for real-time data updates.

## Key Components

- **Dashboard**: Main page component that renders the dashboard layout
- **DashboardContent**: Dynamically imported dashboard content component with SSR disabled
- **AppLayout**: Wrapper component providing consistent application layout
- **DashboardLoading**: Loading component displayed during content import
- **dynamic export**: Next.js configuration forcing dynamic rendering

## Usage Example

```typescript
// The page automatically handles dynamic loading
// When users navigate to /dashboard, they see:

// 1. AppLayout renders immediately
// 2. DashboardLoading shows while DashboardContent imports
// 3. DashboardContent renders client-side only (no SSR)
// 4. Page always regenerates on each request (force-dynamic)

// Example of the loading state component
export default function DashboardLoading() {
  return (
    <div className="flex justify-center items-center min-h-screen">
      <div className="animate-spin rounded-full h-12 w-12 border-b-2 border-gray-900" />
    </div>
  )
}
```

This implementation ensures the dashboard loads efficiently on the client side while maintaining consistent layout and providing user feedback during the loading process. The `force-dynamic` export prevents static generation, making it suitable for dashboards that display frequently changing data.
