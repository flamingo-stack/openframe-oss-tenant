A client-side rendered Next.js dashboard page that uses dynamic imports for optimized loading and ensures real-time data updates.

## Key Components

- **Dashboard**: Main page component that renders the dashboard layout
- **DashboardContent**: Dynamically imported component with SSR disabled
- **AppLayout**: Wrapper component providing consistent page structure
- **DashboardLoading**: Loading component displayed during dynamic import

## Usage Example

```typescript
// The page automatically handles dynamic loading
// Navigate to /dashboard route to see the component in action

// Dynamic import configuration
const DynamicComponent = nextDynamic(
  () => import('./components/dashboard-content'),
  { 
    ssr: false,           // Disable server-side rendering
    loading: () => <Loading />  // Show loading component
  }
)

// Force dynamic rendering for real-time data
export const dynamic = 'force-dynamic'
```

The component uses `'use client'` directive for client-side rendering, `nextDynamic` with `ssr: false` to prevent server-side rendering of the dashboard content (likely for real-time data or client-only features), and `dynamic = 'force-dynamic'` to ensure the page is never cached and always renders fresh data. The loading component provides visual feedback during the dynamic import process.
