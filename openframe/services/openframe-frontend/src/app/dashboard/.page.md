A client-side rendered dashboard page component that uses dynamic imports for optimal performance and loading states.

## Key Components

- **Dashboard**: Main page component that renders the dashboard layout
- **DashboardContent**: Dynamically imported dashboard content component with SSR disabled
- **AppLayout**: Wrapper component providing consistent application layout
- **DashboardLoading**: Loading component displayed while content loads
- **dynamic**: Next.js export configuration forcing dynamic rendering

## Usage Example

```typescript
// This page automatically handles:
// - Client-side rendering with 'use client'
// - Dynamic import with loading state
// - Consistent app layout wrapping

// The component structure:
<AppLayout>
  <DashboardContent /> {/* Loaded dynamically */}
</AppLayout>

// Configuration exports:
export const dynamic = 'force-dynamic' // Ensures fresh data on each request
```

The component leverages Next.js dynamic imports to code-split the dashboard content, improving initial page load performance. The `ssr: false` option ensures the content only renders client-side, while the loading component provides immediate user feedback during the import process. The `force-dynamic` export prevents static optimization, ensuring the dashboard always fetches fresh data.
