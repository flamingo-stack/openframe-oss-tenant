A Next.js page component that renders the main dashboard interface with dynamic loading and client-side rendering optimizations.

## Key Components

- **Dashboard** - Default export component that renders the main dashboard page
- **DashboardContent** - Dynamically imported dashboard content component with SSR disabled
- **AppLayout** - Layout wrapper component providing consistent page structure
- **DashboardLoading** - Loading component displayed during dynamic import

## Usage Example

```typescript
// This page is automatically routed in Next.js App Router
// Access via: /dashboard

// The dynamic import configuration:
const DynamicComponent = nextDynamic(
  () => import('./components/dashboard-content'),
  { 
    ssr: false,           // Disable server-side rendering
    loading: () => <LoadingComponent />  // Show while loading
  }
)

// Force dynamic rendering for this route
export const dynamic = 'force-dynamic'
```

The component uses Next.js dynamic imports to code-split the dashboard content, improving initial page load performance. The `ssr: false` option ensures the dashboard content only renders on the client side, while `force-dynamic` prevents static generation and ensures fresh data on each request.
