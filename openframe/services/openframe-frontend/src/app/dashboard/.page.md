A client-side dashboard page component that implements dynamic loading and server-side rendering configuration for optimal performance.

## Key Components

- **Dashboard** - Main page component that renders the dashboard layout
- **DashboardContent** - Dynamically imported dashboard content with SSR disabled
- **AppLayout** - Wrapper component providing consistent page structure
- **DashboardLoading** - Loading component displayed during dynamic import
- **dynamic** - Next.js configuration forcing dynamic rendering

## Usage Example

This is a Next.js page component that automatically renders when navigating to the dashboard route:

```typescript
// The page renders with this structure:
// <AppLayout>
//   <DashboardContent /> // Loaded dynamically on client-side
// </AppLayout>

// Dynamic import configuration
const DashboardContent = nextDynamic(
  () => import('./components/dashboard-content'),
  { 
    ssr: false,           // Disable server-side rendering
    loading: () => <DashboardLoading /> // Show loading state
  }
)
```

The component uses `'use client'` directive for client-side execution, disables SSR for the dashboard content to improve initial page load, and exports `dynamic = 'force-dynamic'` to ensure the page is always dynamically rendered rather than statically generated. This configuration is ideal for dashboard pages that contain user-specific data or require client-side interactivity.
