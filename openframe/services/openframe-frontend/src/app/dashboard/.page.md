A Next.js dashboard page component that implements client-side rendering with dynamic imports for optimal performance and loading states.

## Key Components

- **Dashboard**: Main page component that renders the dashboard layout
- **DashboardContent**: Dynamically imported dashboard content component
- **AppLayout**: Wrapper component providing the application layout structure
- **DashboardLoading**: Loading component displayed while content loads

## Configuration

The component uses several Next.js optimizations:
- `'use client'` directive for client-side rendering
- `nextDynamic` import with SSR disabled for code splitting
- `dynamic = 'force-dynamic'` export to prevent static generation

## Usage Example

This is a Next.js app router page component that should be placed in the `/dashboard` route:

```typescript
// app/dashboard/page.tsx
'use client'

import nextDynamic from 'next/dynamic'
import { AppLayout } from '../components/app-layout'
import DashboardLoading from './loading'

const DashboardContent = nextDynamic(
  () => import('./components/dashboard-content'),
  { ssr: false, loading: () => <DashboardLoading /> }
)

export default function Dashboard() {
  return (
    <AppLayout>
      <DashboardContent />
    </AppLayout>
  )
}
```

The dynamic import ensures the dashboard content is only loaded client-side, improving initial page load performance while showing a loading state during component hydration.
