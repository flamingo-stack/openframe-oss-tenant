A Next.js dashboard page component that implements dynamic loading with client-side rendering for optimal performance and loading states.

## Key Components

- **Dashboard** - Main page component that wraps dashboard content in app layout
- **DashboardContent** - Dynamically imported dashboard content component with SSR disabled
- **AppLayout** - Layout wrapper component for consistent page structure
- **DashboardLoading** - Loading component displayed during dynamic import

## Usage Example

```typescript
// This page automatically handles:
// 1. Client-side rendering with 'use client'
// 2. Dynamic loading of dashboard content
// 3. Loading state during component import
// 4. Force dynamic rendering for real-time data

// The component structure:
export default function Dashboard() {
  return (
    <AppLayout>
      <DashboardContent /> {/* Loaded dynamically */}
    </AppLayout>
  )
}

// Force dynamic ensures fresh data on each request
export const dynamic = 'force-dynamic'
```

The `force-dynamic` export ensures the page is rendered dynamically on each request, making it ideal for dashboards that need real-time data. The dynamic import with `ssr: false` prevents server-side rendering of the dashboard content, which is useful for components that rely on browser APIs or need to be hydrated client-side.
