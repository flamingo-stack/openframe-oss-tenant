This is a Next.js client-side dashboard page that implements dynamic loading for performance optimization. It serves as the main entry point for the dashboard interface, wrapping the dashboard content in the application layout with client-side rendering and loading states.

## Key Components

- **Dashboard**: Default exported React component that renders the main dashboard page
- **DashboardContent**: Dynamically imported component that contains the actual dashboard functionality
- **AppLayout**: Layout wrapper component for consistent page structure
- **DashboardLoading**: Loading component displayed while dashboard content loads
- **dynamic**: Export configuration forcing dynamic rendering

## Usage Example

```typescript
// This page automatically renders at /dashboard route
// The component structure provides:

// 1. Client-side rendering with 'use client' directive
// 2. Dynamic import with loading fallback
const DashboardContent = nextDynamic(
  () => import('./components/dashboard-content'),
  { 
    ssr: false,  // Disable server-side rendering
    loading: () => <DashboardLoading />  // Show loading component
  }
)

// 3. Wrapped in app layout for consistent UI
<AppLayout>
  <DashboardContent />
</AppLayout>

// 4. Force dynamic rendering for real-time data
export const dynamic = 'force-dynamic'
```

The `force-dynamic` export ensures the page always renders at request time, making it suitable for dashboards that need fresh data on each visit. The dynamic import with SSR disabled optimizes initial page load while providing a smooth loading experience.
