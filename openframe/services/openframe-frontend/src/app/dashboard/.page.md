Main dashboard page component that renders the core dashboard interface with dynamic loading and client-side rendering optimization.

## Key Components

- **Dashboard** - Default exported page component that wraps dashboard content in the app layout
- **DashboardContent** - Dynamically imported dashboard content component with SSR disabled
- **AppLayout** - Wrapper component providing consistent page structure
- **DashboardLoading** - Loading component displayed during dynamic import

## Usage Example

```typescript
// This page is automatically rendered at the dashboard route
// The dynamic import ensures client-side only rendering for dashboard content

import { AppLayout } from '../components/app-layout'
import DashboardLoading from './loading'

// Dynamic import with loading state
const DashboardContent = nextDynamic(
  () => import('./components/dashboard-content'),
  { 
    ssr: false,  // Client-side only rendering
    loading: () => <DashboardLoading /> 
  }
)

export default function Dashboard() {
  return (
    <AppLayout>
      <DashboardContent />
    </AppLayout>
  )
}

// Force dynamic rendering for this route
export const dynamic = 'force-dynamic'
```

The component uses Next.js dynamic imports to defer loading of dashboard content until client-side, improving initial page load performance while showing a loading state during the import process.
