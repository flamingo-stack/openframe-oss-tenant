A client-side rendered dashboard page component that implements dynamic loading for optimal performance and user experience.

## Key Components

- **Dashboard**: Main page component that wraps the dashboard content in an application layout
- **DashboardContent**: Dynamically imported component with SSR disabled and loading state
- **Dynamic Import Configuration**: Uses Next.js dynamic imports with custom loading component
- **Force Dynamic Export**: Ensures the page is always rendered dynamically at request time

## Usage Example

This page component is typically used as a route handler in Next.js App Router:

```typescript
// app/dashboard/page.tsx
'use client'

import nextDynamic from 'next/dynamic'
import { AppLayout } from '../components/app-layout'
import DashboardLoading from './loading'

// Dynamic import with loading fallback
const DashboardContent = nextDynamic(
  () => import('./components/dashboard-content'),
  { 
    ssr: false,  // Disable server-side rendering
    loading: () => <DashboardLoading />  // Show loading component
  }
)

export default function Dashboard() {
  return (
    <AppLayout>
      <DashboardContent />
    </AppLayout>
  )
}

// Force dynamic rendering for real-time data
export const dynamic = 'force-dynamic'
```

The component structure ensures fast initial page loads while providing smooth loading states for dynamic content. The `force-dynamic` export prevents static generation, making it suitable for dashboards that display real-time or user-specific data.
