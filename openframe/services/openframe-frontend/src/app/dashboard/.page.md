A Next.js dashboard page component that implements client-side rendering with dynamic imports and loading states for optimal performance and user experience.

## Key Components

- **Dashboard** - Main page component that renders the dashboard layout
- **DashboardContent** - Dynamically imported dashboard content component
- **AppLayout** - Wrapper layout component for consistent page structure
- **DashboardLoading** - Loading component displayed during dynamic import

## Usage Example

This component serves as the main dashboard route in a Next.js application:

```typescript
// The component automatically handles:
// - Client-side only rendering ('use client')
// - Dynamic loading with fallback UI
// - Force dynamic routing for real-time data

// Layout structure:
<AppLayout>
  <DashboardContent /> // Loaded dynamically
</AppLayout>

// When DashboardContent is loading:
<AppLayout>
  <DashboardLoading /> // Shows loading state
</AppLayout>
```

The component uses `nextDynamic` with `ssr: false` to ensure the dashboard content only renders on the client side, which is useful for components that depend on browser APIs or require real-time data. The `dynamic = 'force-dynamic'` export ensures the page is always dynamically rendered, bypassing Next.js static optimization for up-to-date dashboard data.
