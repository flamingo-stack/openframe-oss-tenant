A Next.js page component that renders the main dashboard with dynamic loading and client-side rendering for optimal performance.

## Key Components

- **Dashboard**: Default exported page component that combines layout and content
- **DashboardContent**: Dynamically imported component with SSR disabled
- **AppLayout**: Wrapper component providing consistent page structure
- **DashboardLoading**: Loading component shown during dynamic import

## Usage Example

This is a Next.js app router page that automatically renders when users navigate to the dashboard route:

```typescript
// The page is automatically accessible at /dashboard
// Uses client-side rendering with dynamic imports for better performance

// Loading sequence:
// 1. Dashboard component mounts
// 2. DashboardLoading shows while DashboardContent imports
// 3. DashboardContent renders once loaded

// Configuration ensures:
// - No server-side rendering (ssr: false)
// - Force dynamic rendering (export const dynamic = 'force-dynamic')
// - Graceful loading states during component import
```

The component uses Next.js dynamic imports to code-split the dashboard content, improving initial page load performance by loading the main dashboard functionality only when needed. The `force-dynamic` export ensures the page is always rendered dynamically rather than being statically optimized.
