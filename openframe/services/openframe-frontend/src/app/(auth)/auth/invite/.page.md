Renders the invitation acceptance page, allowing new users to complete registration via email/password form or SSO providers using a token from their invitation link.

## Key Components

- **`InvitePage`** — Default export; full-page React component handling the invitation acceptance flow
- **`useInviteProviders`** — Custom hook that fetches available SSO providers for the given invitation ID
- **`handleSubmit`** — Validates form fields and calls `authApiClient.acceptInvitation`, with tenant-switch conflict handling
- **`handleSsoSignup`** — Initiates SSO-based registration via `authApiClient.acceptInvitationSso`
- **`handleTenantSwitch`** — Re-submits acceptance with `switchTenant: true` after user confirms the tenant switch dialog
- **`ConfirmDialog`** — Shown when the user already belongs to another tenant (`USER_IS_ACTIVE_IN_ANOTHER_TENANT`)

## Render States

| State | Behavior |
|---|---|
| `loadingProviders` | Animated skeleton card |
| `invitationNotFound` | Error card with "Back to Login" button |
| Valid invitation | Registration form with optional SSO providers |

## Usage Example

```typescript
// Accessed via URL: /auth/invite?id=<invitationId>
// Next.js App Router — no manual instantiation required.

// Query param consumed internally:
const invitationId = searchParams.get('id');

// Form submission triggers:
await authApiClient.acceptInvitation({
  invitationId,
  firstName,
  lastName,
  password,
  switchTenant: false,
});

// SSO path triggers:
await authApiClient.acceptInvitationSso({
  invitationId,
  provider: 'google',
  switchTenant: true,
  redirectTo: '/auth/login',
});
```

> **Validation rules:** All name fields required, passwords must match and be at least 8 characters. Invalid or missing `id` params redirect immediately to `/auth`.
