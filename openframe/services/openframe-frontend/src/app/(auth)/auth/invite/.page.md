Invitation acceptance page that allows new users to complete their registration via an email invitation link, supporting both email/password form signup and SSO provider authentication.

## Key Components

- **`InvitePage`** — Default export; full-page React component handling the invitation acceptance flow
- **`useInviteProviders`** — Custom hook that fetches available SSO providers for the given invitation ID
- **`handleSubmit`** — Validates form fields, calls `authApiClient.acceptInvitation`, and handles tenant-switch conflicts
- **`handleSsoSignup`** — Initiates SSO-based signup via `authApiClient.acceptInvitationSso`
- **`handleTenantSwitch`** — Confirms and retries submission with `switchTenant: true` when the user already belongs to another tenant
- **`ConfirmDialog`** — Modal shown when a `USER_IS_ACTIVE_IN_ANOTHER_TENANT` error is returned

## Render States

| State | Rendered UI |
|---|---|
| `loadingProviders` | Animated skeleton card |
| `invitationNotFound` | Error card with "Back to Login" button |
| Valid invitation | Full registration form with optional SSO providers |

## Usage Example

```typescript
// Accessed via invitation email link:
// /auth/invite?id=<invitationId>

// The page reads `id` from search params automatically:
const invitationId = searchParams.get('id');

// Form signup flow:
await authApiClient.acceptInvitation({
  invitationId,
  firstName,
  lastName,
  password,
  switchTenant: false,
});

// SSO signup flow:
await authApiClient.acceptInvitationSso({
  invitationId,
  provider: 'google',
  switchTenant: true,
  redirectTo: '/auth/login',
});
```

> **Validation rules:** All name fields are required, passwords must match and be at least 8 characters. Invalid or missing invitation IDs redirect to `/auth`.
