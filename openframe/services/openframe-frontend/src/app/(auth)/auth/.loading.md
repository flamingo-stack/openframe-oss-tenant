A Next.js streaming loading UI component that renders a pixel-accurate skeleton placeholder for the authentication page, preventing layout shift while auth content loads.

## Key Components

- **`AuthLoading`** — Default export; a `'use client'` skeleton screen that mirrors the `AuthLayout` structure with two-column responsive layout (stacked on mobile, side-by-side on `lg+`)

**Skeleton regions:**
- **Left side** — Two cards mimicking `AuthChoiceSection`:
  - *Create Organization* card: heading, two-column form fields, single action button
  - *Already Have an Account* card: heading, email field, two action buttons
- **Right side** — Benefits panel mimicking `AuthBenefitsSection`: logo row + three `BenefitCard` rows with icon and text lines

## Usage Example

```typescript
// app/(auth)/loading.tsx
// Next.js automatically renders this file during page-level Suspense boundaries.
// No manual import needed — just co-locate with the auth route segment.

export { default } from './loading';
```

```typescript
// If used manually inside a Suspense boundary:
import { Suspense } from 'react';
import AuthLoading from './loading';
import AuthPage from './page';

export default function AuthRoute() {
  return (
    <Suspense fallback={<AuthLoading />}>
      <AuthPage />
    </Suspense>
  );
}
```

> **Note:** Skeleton dimensions (e.g. `h-10`, `h-[60px]`, `h-12`) are intentionally matched to the actual auth page's typography and input sizes to eliminate cumulative layout shift (CLS) when the real content hydrates.
