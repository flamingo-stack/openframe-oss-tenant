Standalone utility for performing a complete user logout flow outside of the `useAuth` hook context.

## Key Components

- **`performLogout()`** — Async function that executes the full logout sequence:
  1. Reads current auth state directly from `useAuthStore`
  2. Calls the remote logout endpoint via `authApiClient.logoutAsync()`
  3. Clears local auth store state
  4. Optionally clears stored tokens (dev/ticket observer mode)
  5. Redirects to `/auth` (or `sharedHostUrl/auth` in multi-tenant setups)

## Usage Example

```typescript
import { performLogout } from '@/features/auth/actions/auth-actions';

// In a component that only needs logout (e.g. AppShell, nav bar)
function LogoutButton() {
  return (
    <button onClick={performLogout}>
      Sign Out
    </button>
  );
}
```

## Notes

- Reads tenant context from `tenantId`, `user.tenantId`, or `user.organizationId` — whichever is available
- Skips the remote API call if no tenant ID is resolved
- Token cleanup via `clearStoredTokens()` only runs when `enableDevTicketObserver` is active
- Redirect target is controlled by `runtimeEnv.sharedHostUrl()` to support shared-host multi-tenant deployments
