Standalone async function that handles the full logout flow: calling the auth API, clearing the store, optionally wiping stored tokens (dev mode), and redirecting to the auth page.

## Key Components

- **`performLogout()`** — Exported async function that orchestrates the complete logout sequence:
  - Resolves the effective tenant ID from the auth store (`tenantId`, `user.tenantId`, or `user.organizationId`)
  - Calls `authApiClient.logoutAsync()` if a tenant ID is available
  - Clears the auth store via `storeLogout()`
  - Clears stored tokens when `enableDevTicketObserver` is active
  - Redirects to `/auth` (or `sharedHostUrl/auth` in multi-tenant environments)

## Usage Example

```typescript
import { performLogout } from '@/auth/actions/auth-actions';

// In a component that only needs logout — no full useAuth hook required
function LogoutButton() {
  return (
    <button onClick={performLogout}>
      Sign Out
    </button>
  );
}
```

> **Note:** This function reads auth state directly from `useAuthStore.getState()`, making it safe to call outside of React's render cycle (e.g., in event handlers, `AppShell`, or utility layers) without needing the full `useAuth` hook.
