Client-side authentication page entry point that dynamically imports the main auth page component with SSR disabled.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Auth` | Default export | Root auth page wrapper component |
| `AuthPage` | Dynamic component | Lazy-loaded auth page, SSR disabled |
| `dynamic` | Config export | Forces dynamic rendering on every request |

## Usage Example

```typescript
// Rendered automatically by Next.js at the /auth route.
// The dynamic import defers loading until client-side hydration,
// showing <AuthLoading /> as a fallback spinner during the import.

import Auth from '@/app/(auth)/auth/page';

// Next.js resolves this automatically — no manual instantiation needed.
export default Auth;
```

## Notes

- `ssr: false` ensures the auth page is never rendered on the server, avoiding hydration issues with auth state.
- `force-dynamic` prevents static caching, ensuring fresh renders on every request.
- The `loading` fallback renders `<AuthLoading />` while the dynamic chunk is being fetched.
