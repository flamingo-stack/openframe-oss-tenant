Renders the authentication landing page with two forms: **Create Organization** and **Sign In**, handling org registration (with optional SaaS-mode domain availability checks and access code validation) and email-based sign-in initiation.

## Key Components

### `AuthChoiceSection`

Main exported component accepting:

| Prop | Type | Description |
|------|------|-------------|
| `onCreateOrganization` | `(orgName, domain, accessCode, email) => void` | Callback fired after successful org creation validation |
| `onSignIn` | `(email) => Promise<void>` | Callback for email sign-in flow |
| `isLoading` | `boolean?` | Disables all inputs/buttons during async operations |

### Internal State

| State | Purpose |
|-------|---------|
| `orgName`, `orgEmail`, `domain` | Create org form fields |
| `signInEmail` | Sign-in form field |
| `accessCode` / `accessCodeError` | SaaS shared mode access code + validation error |
| `suggestedDomains` | Alternative subdomains shown when chosen domain is taken |
| `isSigningIn`, `isCheckingDomain`, `isValidatingAccessCode` | Individual loading states per async operation |

### Key Handlers

- **`handleCreateOrganization`** — Validates org name and email regex, then (in SaaS shared mode) validates the access code via `authApiClient.validateAccessCode`, checks subdomain availability via `authApiClient.checkDomainAvailability`, and surfaces domain suggestions on conflict before invoking `onCreateOrganization`.
- **`handleSignIn`** — Guards against double-submit, delegates to `onSignIn` prop.

## Usage Example

```typescript
import { AuthChoiceSection } from './choice-section';

<AuthChoiceSection
  onCreateOrganization={(orgName, domain, accessCode, email) => {
    console.log('Creating org:', { orgName, domain, accessCode, email });
  }}
  onSignIn={async (email) => {
    await sendMagicLink(email);
  }}
  isLoading={isPending}
/>
```

> **SaaS shared mode** is detected via `isSaasSharedMode()`. When active, the domain field appends `.${SAAS_DOMAIN_SUFFIX}` and an **Access Code** input is rendered, requiring validation before org creation proceeds.
