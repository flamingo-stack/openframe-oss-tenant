A client-side React component that renders the authentication page's benefits sidebar, displaying either a waitlist registration form (in `saas-shared` mode) or a static benefits overview depending on the app mode.

## Key Components

- **`AuthBenefitsSection`** — Main exported component with two rendering modes:
  - **`saas-shared` mode**: Renders an early access waitlist form with email/phone capture, Reddit click ID tracking, and duplicate email handling
  - **Default mode**: Renders three static `BenefitCard` entries (Cut Vendor Costs, Automate Everything, Reclaim Your Profits)

- **`handleRegister`** — Async callback that POSTs to `https://content-api.openframe.ai/api/waitlist`, handles `DUPLICATE_EMAIL` gracefully, tracks Reddit click IDs (`rdt_cid`), and fires toast notifications on success/failure

## Usage Example

```typescript
// Typically used as the right-side panel on auth pages
import { AuthBenefitsSection } from '@/components/auth/benefits-section';

export default function LoginPage() {
  return (
    <div className="flex min-h-screen">
      {/* Left: Login form */}
      <main className="flex-1">
        <LoginForm />
      </main>

      {/* Right: Benefits / waitlist sidebar */}
      <aside className="hidden lg:block w-[480px]">
        <AuthBenefitsSection />
      </aside>
    </div>
  );
}
```

> The component reads `appMode` from `runtimeEnv` at render time — no props required. Reddit click IDs stored via `getStoredRedditClickId()` are automatically cleared after a successful waitlist submission.
