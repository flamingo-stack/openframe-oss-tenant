Client-side React component that renders the login section for registered users, supporting OpenFrame SSO as a primary option alongside standard OAuth providers (Google, Microsoft, Slack, GitHub).

## Key Components

**`AuthLoginSection`** — Main exported component accepting:
- `availableProviders` — Array of provider strings to render
- `onSso` — Async callback triggered on SSO provider selection
- `onBack` — Navigation callback for the back button
- `isLoading` — Loading state for button feedback
- `onEmailPasswordLogin` *(optional)* — Email/password login handler (defined in props but not yet wired into UI)

**Internal Logic:**
- Splits `openframe-sso` from standard providers, rendering it as a primary `accent` button
- Maps provider strings to display names with capitalization fallback
- Tracks `loginMethod` state (`'sso' | 'email'`) for targeted loading indicators

## Usage Example

```typescript
<AuthLoginSection
  email="user@company.com"
  tenantInfo={{ tenantName: 'Acme Corp', tenantDomain: 'acme.com' }}
  hasDiscoveredTenants={true}
  availableProviders={['openframe-sso', 'google', 'microsoft']}
  onSso={async (provider) => {
    await signInWithProvider(provider);
  }}
  onBack={() => setStep('email')}
  isLoading={false}
/>
```

## Notes

- Requires the `useDeployment` hook import (imported but unused in current render logic)
- Several UI imports (`ArrowLeft`, `Building`, `Cloud`, `Lock`, `Mail`, `User`, `Input`, `Label`) are imported but reserved for future email/password form expansion
- `AuthProvidersList` from `openframe-frontend-core` handles rendering of standard OAuth buttons with vertical orientation
