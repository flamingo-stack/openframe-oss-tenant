Monitors the URL search parameters across the application for a `devTicket` query parameter, triggering a ticket exchange process when detected. Can be toggled via the `NEXT_PUBLIC_ENABLE_DEV_TICKET_OBSERVER` environment variable.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `DevTicketObserver` | React Component | Headless observer component that renders `null` and reacts to URL changes |
| `lastTicket` | `useRef` | Tracks the previously processed ticket to prevent duplicate exchange calls |
| `isEnabled` | `boolean` | Runtime flag sourced from `runtimeEnv.enableDevTicketObserver()` |

## Usage Example

Mount once at the app layout level (e.g., root layout or global providers) so it observes all route changes:

```typescript
// app/layout.tsx
import { DevTicketObserver } from '@/components/dev-ticket-observer';
import { Suspense } from 'react';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html>
      <body>
        {/* Wrap in Suspense — required for useSearchParams */}
        <Suspense fallback={null}>
          <DevTicketObserver />
        </Suspense>
        {children}
      </body>
    </html>
  );
}
```

Any URL containing `?devTicket=<token>` will trigger `exchangeTicket()` from `useDevTicketExchange`. The `lastTicket` ref ensures the same ticket is not exchanged more than once per session, even across re-renders.

## Behavior Notes

- Returns `null` — no DOM output, purely side-effect driven
- Skips execution entirely when `NEXT_PUBLIC_ENABLE_DEV_TICKET_OBSERVER` is disabled
- Resets `lastTicket` ref when the `devTicket` param is removed from the URL
- Exchange is only triggered when the ticket value **changes**
