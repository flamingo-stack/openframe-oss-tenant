A client-side observer component that watches URL search parameters for a `devTicket` value and triggers the ticket exchange flow when one is detected.

## Key Components

- **`DevTicketObserver`** — Renderless React component (`return null`) that monitors `searchParams` for the `devTicket` query parameter and calls `exchangeTicket()` when a new, unseen ticket is found
- **`lastTicket` ref** — Deduplication guard preventing re-exchange of the same ticket across re-renders
- **`runtimeEnv.enableDevTicketObserver()`** — Feature flag controlled via `NEXT_PUBLIC_ENABLE_DEV_TICKET_OBSERVER` environment variable; no-ops the effect when disabled
- **`useDevTicketExchange`** — Hook responsible for the actual ticket exchange logic (imported from auth hooks)

## Usage Example

Mount once at the application root (e.g., layout or providers):

```typescript
import { DevTicketObserver } from '@/components/dev-ticket-observer';
import { Suspense } from 'react';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html>
      <body>
        {/* Wrap in Suspense — required for useSearchParams in Next.js App Router */}
        <Suspense fallback={null}>
          <DevTicketObserver />
        </Suspense>
        {children}
      </body>
    </html>
  );
}
```

With the observer mounted, navigating to any route with `?devTicket=<token>` will automatically trigger the exchange:

```text
https://app.example.com/dashboard?devTicket=abc123
```

> **Note:** This component is intended for development/internal authentication flows. Ensure `NEXT_PUBLIC_ENABLE_DEV_TICKET_OBSERVER` is **not** enabled in production unless explicitly required.
