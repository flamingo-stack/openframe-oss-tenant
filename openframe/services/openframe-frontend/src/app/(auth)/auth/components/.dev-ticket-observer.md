Monitors URL search parameters globally for a `devTicket` query parameter and triggers the ticket exchange flow when detected, preventing duplicate exchanges via a ref-based deduplication check.

## Key Components

- **`DevTicketObserver`** — A renderless React component (`return null`) that observes `searchParams` for `devTicket` changes and calls `exchangeTicket()` when a new, unique ticket value is found
- **`lastTicket` ref** — Tracks the previously processed ticket to avoid re-triggering the exchange on re-renders
- **`runtimeEnv.enableDevTicketObserver()`** — Feature flag controlled by `NEXT_PUBLIC_ENABLE_DEV_TICKET_OBSERVER`; short-circuits all logic when disabled

## Usage Example

```typescript
// app/layout.tsx — Mount once at the root layout to observe globally
import { DevTicketObserver } from '@/components/dev-ticket-observer';
import { Suspense } from 'react';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html>
      <body>
        <Suspense>
          <DevTicketObserver />
        </Suspense>
        {children}
      </body>
    </html>
  );
}
```

Then navigate to any route with `?devTicket=<token>` to trigger the exchange:

```text
https://app.example.com/dashboard?devTicket=abc123
```

## Notes

- Requires wrapping in `<Suspense>` because it calls `useSearchParams()` (Next.js App Router requirement)
- Enable/disable via environment variable — safe to mount in production with the flag off
- Clears `lastTicket` when the `devTicket` param is removed from the URL
