Registration form component for completing new organization and user account creation during the OpenFrame onboarding flow.

## Key Components

### `AuthSignupSection`

Main exported component that renders the multi-field signup form with the following capabilities:

- **Organization fields** — Pre-filled, read-only `Organization Name` and `Domain` inputs
- **Personal fields** — Editable `First Name`, `Last Name`, `Email`, `Password`, and `Confirm Password` inputs
- **SSO support** — Conditionally renders `AuthProvidersList` when SSO providers are available via `useRegistrationProviders`
- **SaaS mode awareness** — Adapts button label and validation (e.g., "Start Free Trial" vs "Create Organization") based on `isSaasSharedMode()`
- **Inline validation** — Email format check, password length (min 8 chars), and password match errors rendered inline

### `RegisterRequest`

Interface describing the payload submitted via `onSubmit`:

```typescript
interface RegisterRequest {
  tenantName: string;
  tenantDomain: string;
  firstName: string;
  lastName: string;
  email: string;
  password: string;
  accessCode: string;
}
```

## Usage Example

```typescript
<AuthSignupSection
  orgName="Acme IT"
  domain="acme.openframe.ai"
  accessCode="ABC123"
  email="admin@acme.com"
  isLoading={isSubmitting}
  onSubmit={(data) => registerTenant(data)}
  onSso={(provider) => handleSsoSignup(provider)}
  onBack={() => goToPreviousStep()}
/>
```

## Props

| Prop | Type | Description |
|------|------|-------------|
| `orgName` | `string` | Pre-filled organization name (read-only) |
| `domain` | `string` | Pre-filled tenant domain (read-only) |
| `accessCode` | `string` | Invite/access code passed to the submit payload |
| `email` | `string?` | Optional pre-filled email (disables the email field) |
| `onSubmit` | `(data: RegisterRequest) => void` | Called with validated form data |
| `onSso` | `(provider: string) => void` | Optional SSO provider click handler |
| `onBack` | `() => void` | Navigates to the previous step |
| `isLoading` | `boolean` | Disables inputs and shows loading state on submit button |
