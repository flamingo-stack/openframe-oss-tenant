A React client component that renders the user registration form for completing organization setup in the OpenFrame auth flow, supporting both email/password signup and SSO provider options.

## Key Components

**`AuthSignupSection`** — Main exported component that handles new user registration with the following props:

| Prop | Type | Description |
|------|------|-------------|
| `orgName` | `string` | Pre-filled organization name (read-only) |
| `domain` | `string` | Pre-filled tenant domain (read-only) |
| `accessCode` | `string` | Registration access code passed to submit |
| `email` | `string?` | Optional pre-filled email (locks field if provided) |
| `onSubmit` | `(data: RegisterRequest) => void` | Callback with full registration payload |
| `onSso` | `(provider: string) => void?` | Optional SSO provider callback |
| `onBack` | `() => void` | Navigates back to previous step |
| `isLoading` | `boolean` | Disables inputs and shows loading state |

**`RegisterRequest`** — Interface defining the registration payload:

```typescript
interface RegisterRequest {
  tenantName: string;
  tenantDomain: string;
  firstName: string;
  lastName: string;
  email: string;
  password: string;
  accessCode: string;
}
```

## Key Behaviors

- Displays SSO providers (via `AuthProvidersList`) when available and `onSso` is provided
- Adapts button label based on `isSaasSharedMode()` — shows `"Start Free Trial"` vs `"Create Organization"`
- Inline validation: email format check, password minimum length (SaaS mode), password confirmation match
- Submit triggers on `Enter` key or button click; blocked until all fields are valid

## Usage Example

```typescript
<AuthSignupSection
  orgName="Acme Corp"
  domain="acme.openframe.ai"
  accessCode="INVITE-XYZ"
  email="user@acme.com"
  isLoading={isSubmitting}
  onSubmit={(data) => registerTenant(data)}
  onSso={(provider) => handleSsoRedirect(provider)}
  onBack={() => setStep('org-setup')}
/>
```
