A modal dialog component that handles the "forgot password" flow, allowing users to submit their email address to receive a password reset link via the auth API.

## Key Components

- **`ForgotPasswordModal`** — Client-side React component rendering an `AlertDialog` with email input, submit/cancel actions, loading state, and toast notifications for success/error feedback.

### Props (`ForgotPasswordModalProps`)

| Prop | Type | Description |
|------|------|-------------|
| `open` | `boolean` | Controls dialog visibility |
| `onOpenChange` | `(open: boolean) => void` | Callback for open state changes |
| `defaultEmail` | `string` (optional) | Pre-fills the email input field |

### Behavior

- Blocks dismissal while a reset request is in-flight (`isSubmitting`)
- Resets email field to `defaultEmail` on close
- Supports `Enter` key submission
- Calls `authApiClient.requestPasswordReset` and displays a success or destructive toast accordingly

## Usage Example

```typescript
import { ForgotPasswordModal } from '@/components/forgot-password-modal';
import { useState } from 'react';

export function LoginPage() {
  const [showReset, setShowReset] = useState(false);
  const [email, setEmail] = useState('');

  return (
    <>
      <button onClick={() => setShowReset(true)}>Forgot password?</button>

      <ForgotPasswordModal
        open={showReset}
        onOpenChange={setShowReset}
        defaultEmail={email}
      />
    </>
  );
}
```
