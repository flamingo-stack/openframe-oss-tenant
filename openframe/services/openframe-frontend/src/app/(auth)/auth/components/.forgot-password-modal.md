A modal dialog component for initiating password reset flows, allowing users to submit their email address to receive a password reset link.

## Key Components

- **`ForgotPasswordModal`** — Main exported component rendering an `AlertDialog` with email input and submission logic
- **`ForgotPasswordModalProps`** — Interface defining `open`, `onOpenChange`, and optional `defaultEmail` props
- **`handleSubmit`** — Async handler that calls `authApiClient.requestPasswordReset`, shows success/error toasts, and resets state
- **`handleOpenChange`** — Guards modal close actions while a submission is in progress, resetting email to `defaultEmail` on close

## Usage Example

```typescript
import { ForgotPasswordModal } from '@/components/forgot-password-modal';
import { useState } from 'react';

export function LoginPage() {
  const [showReset, setShowReset] = useState(false);
  const [email, setEmail] = useState('');

  return (
    <>
      <button onClick={() => setShowReset(true)}>Forgot Password?</button>

      <ForgotPasswordModal
        open={showReset}
        onOpenChange={setShowReset}
        defaultEmail={email}
      />
    </>
  );
}
```

## Behavior Notes

- Validates that email is non-empty before submitting; shows a destructive toast otherwise
- Disables all controls and shows a loading state on the submit button during the API call
- Closes the modal and clears the email field on successful reset request
- Supports `Enter` key submission via `onKeyDown` handler on the input
- Prevents accidental closure while a request is in-flight by blocking `onOpenChange` during submission
