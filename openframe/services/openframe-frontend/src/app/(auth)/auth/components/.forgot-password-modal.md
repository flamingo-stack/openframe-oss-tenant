A modal dialog component for initiating password reset flows, allowing users to submit their email address to receive a reset link via the auth API.

## Key Components

- **`ForgotPasswordModal`** — Main exported component that renders an `AlertDialog` with email input and submission logic
- **`ForgotPasswordModalProps`** — Interface defining `open`, `onOpenChange`, and optional `defaultEmail` props
- **`handleSubmit`** — Async handler that calls `authApiClient.requestPasswordReset`, shows success/error toasts, and closes the modal on success
- **`handleOpenChange`** — Guards modal close interactions, preventing dismissal while a submission is in progress, and resets email state on close

## Usage Example

```typescript
import { ForgotPasswordModal } from '@/components/forgot-password-modal';
import { useState } from 'react';

export function LoginPage() {
  const [showForgotPassword, setShowForgotPassword] = useState(false);
  const [userEmail, setUserEmail] = useState('');

  return (
    <>
      <button onClick={() => setShowForgotPassword(true)}>
        Forgot Password?
      </button>

      <ForgotPasswordModal
        open={showForgotPassword}
        onOpenChange={setShowForgotPassword}
        defaultEmail={userEmail}
      />
    </>
  );
}
```

## Behavior Notes

- Submitting is blocked if the email field is empty or only whitespace
- The modal cannot be dismissed while a request is in progress (`isSubmitting`)
- On successful reset request, the modal closes and email field resets to `defaultEmail`
- Supports `Enter` key submission via `onKeyDown` handler on the input
- Displays contextual toast notifications for validation errors, success, and API failures
