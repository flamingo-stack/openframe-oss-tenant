Renders the login page for authenticated tenant discovery and SSO provider selection, redirecting unauthenticated users without an email back to `/auth` and authenticated users to `/dashboard`.

## Key Components

- **`LoginPage`** — Default export page component that orchestrates login flow state, tenant discovery, and SSO handling
- **`useAuth`** — Hook providing tenant discovery, SSO login, provider list, and loading state
- **`useAuthStore`** — Zustand store accessor for `isAuthenticated` session state
- **`AuthLoginSection`** — Presentational component rendering the login UI with tenant/provider data
- **`AuthLayout`** — Wrapping layout component for auth-scoped pages
- **`useSafeBack`** — Hook for safe back navigation with a fallback route
- **`isAuthOnlyMode`** — Utility flag that bypasses dashboard redirect in auth-only deployments

## Usage Example

```typescript
// Rendered automatically by Next.js at /auth/login
// Navigation flow:
// 1. User enters email on /auth → stored in auth state
// 2. LoginPage loads → triggers discoverTenants(email)
// 3. SSO providers rendered via AuthLoginSection
// 4. On SSO click → loginWithSso(provider) called

const handleSso = async (provider: string) => {
  await loginWithSso(provider); // e.g., 'google', 'microsoft'
};

// Back navigation falls back to /auth/ if no history
const handleBack = useSafeBack('/auth/');
```

## Navigation Guards

| Condition | Redirect |
|-----------|----------|
| Authenticated + not auth-only mode | `/dashboard` |
| No email in state + not loading | `/auth` |
| Email present + discovery not attempted | Triggers `discoverTenants(email)` |
