Client-side Next.js page component that renders the organization signup flow, handling both standard credential-based registration and SSO-based organization registration.

## Key Components

- **`SignupPage`** — Default export page component that orchestrates the signup flow
- **`useAuth`** — Provides `registerOrganization`, `registerOrganizationSso`, and `loginWithSso` actions
- **`useAuthStore`** — Reads `isAuthenticated` state to redirect already-authenticated users
- **`isAuthOnlyMode`** — Guards the dashboard redirect when the app runs in auth-only mode
- **Session Storage Keys** — Pre-populates form fields from `auth:org_name`, `auth:domain`, `auth:access_code`, and `auth:email`

## Behavior

- Redirects authenticated users to `/dashboard` unless `isAuthOnlyMode()` is active
- Reads pre-filled organization data from `sessionStorage` (set during earlier onboarding steps)
- SSO signup: if stored org context exists, calls `registerOrganizationSso` directly; otherwise persists org data and initiates `loginWithSso`

## Usage Example

```typescript
// Rendered automatically by Next.js at /auth/signup
// Session storage keys expected upstream:
sessionStorage.setItem('auth:org_name', 'Acme Corp');
sessionStorage.setItem('auth:domain', 'acme.com');
sessionStorage.setItem('auth:access_code', 'ABC123');
sessionStorage.setItem('auth:email', 'admin@acme.com');

// SSO signup flow with pre-filled context
await handleSsoSignup('google');
// → calls registerOrganizationSso({ tenantName, tenantDomain, email, provider, ... })

// Credential signup
handleSignupSubmit({ orgName, email, password });
// → calls registerOrganization(data)
```
