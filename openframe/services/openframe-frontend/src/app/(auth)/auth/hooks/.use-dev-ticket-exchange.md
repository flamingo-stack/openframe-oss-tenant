Exchanges a developer ticket for auth tokens via the API, stores the resulting tokens, invalidates the auth session query, and redirects to the dashboard on success.

## Key Components

- **`useDevTicketExchange`** — Main hook returning the `exchangeTicket` callback
- **`exchangeTicket(ticket: string)`** — Async function that calls `authApiClient.devExchange`, stores tokens from response headers, invalidates `authSessionQueryKey`, and navigates to `/dashboard`

## Usage Example

```typescript
import { useDevTicketExchange } from './use-dev-ticket-exchange';

function DevLoginPage() {
  const { exchangeTicket } = useDevTicketExchange();

  const handleExchange = async (ticket: string) => {
    const { success, status, tokens } = await exchangeTicket(ticket);

    if (!success) {
      console.error(`Exchange failed with status ${status}`);
    }
  };

  return <button onClick={() => handleExchange('dev-ticket-abc123')}>Sign In</button>;
}
```

## Return Value

```typescript
{
  success: boolean;
  status: number;
  tokens: {
    accessToken: string | null;
    refreshToken: string | null;
  };
}
```

On failure, returns `{ success: false, status: 0, tokens: { accessToken: null, refreshToken: null } }` and displays a destructive toast. On success, displays a `"Welcome!"` toast and redirects to `/dashboard`.
