Exchanges a developer ticket for authentication tokens via the auth API, then syncs session state and redirects to the dashboard on success.

## Key Components

- **`useDevTicketExchange`** — Primary hook that returns an `exchangeTicket` callback
- **`exchangeTicket(ticket: string)`** — Async function that calls `authApiClient.devExchange`, stores returned tokens from response headers, invalidates the auth session query, and navigates to `/dashboard`

**Dependencies:**
- `useTokenStorage` — Persists access/refresh tokens extracted from response headers
- `authSessionQueryKey` / `queryClient.invalidateQueries` — Forces `useAuthSession` to revalidate after token storage
- `useToast` — Displays success or error feedback
- `useRouter` — Redirects to `/dashboard` on successful exchange

## Usage Example

```typescript
import { useDevTicketExchange } from '@/hooks/use-dev-ticket-exchange';

function DevLoginPage() {
  const { exchangeTicket } = useDevTicketExchange();

  const handleTicketSubmit = async (ticket: string) => {
    const result = await exchangeTicket(ticket);

    if (!result.success) {
      console.error('Exchange failed with status:', result.status);
    }
    // On success: tokens stored, session invalidated, redirected to /dashboard
  };

  return <button onClick={() => handleTicketSubmit('dev-ticket-abc123')}>Sign In</button>;
}
```

## Return Value

```typescript
{
  success: boolean;   // Whether the exchange and token storage succeeded
  status: number;     // HTTP status code (0 on network/catch error)
  tokens: {
    accessToken: string | null;
    refreshToken: string | null;
  };
}
```
