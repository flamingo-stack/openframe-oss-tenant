Exchanges a developer ticket for authentication tokens via the auth API, then syncs session state and redirects to the dashboard on success.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `useDevTicketExchange` | Hook | Returns `exchangeTicket` callback for dev-mode ticket-based auth |
| `exchangeTicket` | `async (ticket: string) => object` | Calls `authApiClient.devExchange`, stores tokens, invalidates auth session query, and redirects |

## Usage Example

```typescript
import { useDevTicketExchange } from './use-dev-ticket-exchange';

function DevLoginPage() {
  const { exchangeTicket } = useDevTicketExchange();

  const handleDevLogin = async (ticket: string) => {
    const result = await exchangeTicket(ticket);

    if (!result.success) {
      console.error('Exchange failed with status:', result.status);
    }
  };

  return <button onClick={() => handleDevLogin('dev-ticket-abc123')}>Dev Login</button>;
}
```

## Return Shape

```typescript
{
  success: boolean;       // Whether the HTTP response was ok
  status: number;         // HTTP status code (0 on caught error)
  tokens: {
    accessToken: string | null;
    refreshToken: string | null;
  };
}
```

## Behavior Notes

- On success: stores tokens from response headers → invalidates `authSessionQueryKey` → shows a success toast → navigates to `/dashboard`
- On failure: shows a destructive toast with the error message and returns a safe default object
- Tokens are only considered valid if at least one of `accessToken` or `refreshToken` is present in the response headers
