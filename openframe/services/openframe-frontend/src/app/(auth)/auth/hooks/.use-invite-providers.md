React hook that fetches and manages available SSO providers for a given invitation ID, returning provider list, loading, and error states.

## Key Components

- **`SsoProvider`** — Exported interface representing a single SSO provider with `provider` (name string) and `enabled` (boolean) fields
- **`useInviteProviders(invitationId)`** — Custom hook that calls `authApiClient.getInviteProviders` and maps the raw string array response into `SsoProvider` objects

## Behavior

- Initializes `loading` to `true` only when an `invitationId` is provided
- Clears providers and skips the fetch when `invitationId` is `null`
- Re-fetches automatically whenever `invitationId` changes
- Normalizes the API response by setting `enabled: true` on all returned providers

## Usage Example

```typescript
import { useInviteProviders } from '@/hooks/use-invite-providers';

function InviteSignInPage({ invitationId }: { invitationId: string }) {
  const { providers, loading, error } = useInviteProviders(invitationId);

  if (loading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;

  return (
    <ul>
      {providers.map(({ provider, enabled }) => (
        <li key={provider}>
          {provider} — {enabled ? 'Available' : 'Disabled'}
        </li>
      ))}
    </ul>
  );
}
```

## Return Value

| Field | Type | Description |
|-------|------|-------------|
| `providers` | `SsoProvider[]` | List of available SSO providers for the invitation |
| `loading` | `boolean` | `true` while the API request is in-flight |
| `error` | `string \| null` | Error message if the fetch failed, otherwise `null` |
