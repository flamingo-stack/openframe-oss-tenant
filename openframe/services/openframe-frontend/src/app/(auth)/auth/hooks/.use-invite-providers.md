Fetches and manages the available SSO providers for a given invitation, exposing loading and error state for use in invite/authentication flows.

## Key Components

- **`SsoProvider`** — Interface representing a single SSO provider with `provider` (name string) and `enabled` (boolean) fields.
- **`useInviteProviders(invitationId)`** — Custom React hook that calls `authApiClient.getInviteProviders` when an `invitationId` is provided, then formats the response into `SsoProvider[]`.

### Return Value

| Field | Type | Description |
|-------|------|-------------|
| `providers` | `SsoProvider[]` | List of available SSO providers for the invitation |
| `loading` | `boolean` | `true` while the request is in-flight |
| `error` | `string \| null` | Error message if the fetch failed, otherwise `null` |

## Usage Example

```typescript
import { useInviteProviders } from '@/hooks/use-invite-providers';

function InviteLoginPage({ invitationId }: { invitationId: string }) {
  const { providers, loading, error } = useInviteProviders(invitationId);

  if (loading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;

  return (
    <ul>
      {providers.map(({ provider, enabled }) => (
        <li key={provider}>
          {provider} — {enabled ? 'Available' : 'Disabled'}
        </li>
      ))}
    </ul>
  );
}
```

> **Note:** Passing `null` as `invitationId` skips the fetch entirely — `providers` will be an empty array and `loading` will be `false`.
