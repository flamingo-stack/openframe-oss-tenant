Fetches and manages the list of SSO providers available for a given invitation, exposing loading and error states for use in invite acceptance flows.

## Key Components

- **`SsoProvider`** — Exported interface representing a single SSO provider with `provider` (name string) and `enabled` (boolean) fields
- **`useInviteProviders(invitationId)`** — React hook that calls `authApiClient.getInviteProviders` when an `invitationId` is provided, maps the raw string array response into `SsoProvider` objects, and returns `{ providers, loading, error }`

## Behavior Notes

- If `invitationId` is `null`, the hook short-circuits: `providers` is set to `[]`, `loading` to `false`, and no API call is made
- `loading` initialises to `true` only when `invitationId` is truthy, avoiding a flash of loading state when no ID is present
- Re-fetches automatically when `invitationId` changes (via `useEffect` dependency)

## Usage Example

```typescript
import { useInviteProviders } from '@/hooks/use-invite-providers';

function InviteSignInPage({ invitationId }: { invitationId: string }) {
  const { providers, loading, error } = useInviteProviders(invitationId);

  if (loading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;

  return (
    <>
      {providers.map(({ provider, enabled }) => (
        <SsoButton key={provider} provider={provider} disabled={!enabled} />
      ))}
    </>
  );
}
```
