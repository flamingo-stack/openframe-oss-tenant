React Query-based hook that serves as the single source of truth for authentication state, polling the `/me` endpoint and syncing results to the Zustand auth store.

## Key Components

- **`authSessionQueryKey`** — Stable query key constant `['auth', 'session']` for cache targeting
- **`MeResponse`** — Interface describing the `/me` endpoint response shape
- **`useAuthSession()`** — Primary hook managing session polling, error handling, and store synchronization
- **`invalidateAuthSession()`** — Utility to force a session recheck from outside React components (e.g., post-login handlers)

## Usage Example

```typescript
// In a layout or auth guard component
import { useAuthSession } from '@/features/auth/hooks/use-auth-session';

function AuthGuard({ children }: { children: React.ReactNode }) {
  const { isReady, isAuthenticated, user, recheck } = useAuthSession();

  if (!isReady) return <LoadingSpinner />;
  if (!isAuthenticated) return <Redirect to="/login" />;

  return <>{children}</>;
}

// Force recheck after login (outside React tree)
import { invalidateAuthSession } from '@/features/auth/hooks/use-auth-session';

async function handleLoginSuccess(queryClient: QueryClient) {
  invalidateAuthSession(queryClient);
}
```

## Behavior Notes

- **Polling** — Refetches at the interval defined by `runtimeEnv.authCheckIntervalMs()` while authenticated; stops polling when unauthenticated
- **Stale time** — 4-minute cache window prevents redundant requests
- **Error handling** — Transient 5xx/network errors throw (preserving previous state via React Query retry); `401` returns `null` triggering a clean logout
- **Store sync** — A `useEffect` watches query data changes to call `storeLogin` / `storeLogout` on the Zustand auth store, including tenant/org ID resolution and a background `fetchFullProfile()` call
- **`isReady`** — `true` only when loading is complete and data is defined, preventing premature redirects during initial hydration
