Provides the single source of truth for authentication session state by combining React Query polling with Zustand store synchronization.

## Key Components

- **`authSessionQueryKey`** — Stable query key constant `['auth', 'session']` used to reference or invalidate the session query across the app
- **`useAuthSession()`** — Primary hook that fetches `/me`, syncs auth state to the Zustand store, and handles session expiry vs. transient errors
- **`invalidateAuthSession(queryClient)`** — Utility to trigger a session recheck from outside React components (e.g., after a login success handler)
- **`MeResponse`** — Interface describing the expected shape of the `/me` API response

## Behavior Notes

- **Polling**: Refetches on a configurable interval (`runtimeEnv.authCheckIntervalMs()`) only while authenticated; polling stops when unauthenticated
- **Error handling**: Transient errors (5xx, network failures) throw to trigger React Query retries without wiping cached auth state; `401` returns `null` and triggers logout only when query is idle and not errored
- **Store sync**: On successful auth, maps user fields to the Zustand store and triggers a background `fetchFullProfile()` call (non-blocking)
- **`isReady`**: `true` once initial loading completes, even if an error occurred with existing data

## Usage Example

```typescript
function AppShell() {
  const { isReady, isAuthenticated, user, recheck } = useAuthSession();

  if (!isReady) return <Spinner />;
  if (!isAuthenticated) return <LoginPage />;

  return <Dashboard user={user} onSessionExpired={recheck} />;
}

// Outside a component (e.g., after login API call):
invalidateAuthSession(queryClient);
```
