Single source of truth for authentication session verification, combining React Query for server-state fetching/caching with Zustand store synchronization.

## Key Components

- **`authSessionQueryKey`** — Shared query key constant `['auth', 'session']` for cache targeting
- **`useAuthSession()`** — Primary hook that polls `/me` endpoint, syncs result to Zustand auth store, and exposes auth state
- **`invalidateAuthSession()`** — Utility for forcing a session recheck from outside React components (e.g., post-login handlers)
- **`MeResponse`** — Interface describing the `/me` API response shape

## Behavior Notes

- **Stale time:** 4 minutes; refetches on a configurable interval (`runtimeEnv.authCheckIntervalMs()`) only when authenticated
- **Transient errors:** 500s and network failures throw (preserving cached data) rather than returning `null`, triggering React Query's retry logic (2 retries, 1s delay)
- **Logout guard:** Only clears Zustand state on definitive `401` responses (`data === null`), not on error states, preventing false logouts during network blips
- **Background profile fetch:** Calls `fetchFullProfile()` non-blocking after login sync

## Usage Example

```typescript
// In a layout or root component
function AppShell() {
  const { isReady, isAuthenticated, user, recheck } = useAuthSession();

  if (!isReady) return <Spinner />;
  if (!isAuthenticated) return <LoginPage />;

  return <Dashboard user={user} />;
}

// Outside React (e.g., after form-based login)
function handleLoginSuccess(queryClient: QueryClient) {
  invalidateAuthSession(queryClient);
}
```
