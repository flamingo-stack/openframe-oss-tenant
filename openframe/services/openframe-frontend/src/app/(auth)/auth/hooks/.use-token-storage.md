React hook for managing OpenFrame authentication token persistence in `localStorage`, using the `of_` prefix namespace for access and refresh tokens.

## Key Components

**Constants**
- `ACCESS_TOKEN_KEY` — `localStorage` key `of_access_token`
- `REFRESH_TOKEN_KEY` — `localStorage` key `of_refresh_token`

**Hook: `useTokenStorage()`**

| Method | Description |
|---|---|
| `storeAccessToken(token)` | Persists access token, returns `boolean` |
| `storeRefreshToken(token)` | Persists refresh token, returns `boolean` |
| `storeTokensFromHeaders(headers)` | Extracts `Access-Token` / `Refresh-Token` from response headers and stores both |
| `getAccessToken()` | Retrieves access token or `null` |
| `getRefreshToken()` | Retrieves refresh token or `null` |
| `clearTokens()` | Removes both tokens, returns `boolean` |

All methods are memoized via `useCallback` and include `try/catch` error handling.

## Usage Example

```typescript
import { useTokenStorage } from './use-token-storage';

function AuthHandler() {
  const {
    storeTokensFromHeaders,
    getAccessToken,
    clearTokens,
  } = useTokenStorage();

  // Store tokens after login response
  const handleLogin = async () => {
    const response = await fetch('/api/auth/login', { method: 'POST' });
    storeTokensFromHeaders(response.headers);
  };

  // Attach token to outgoing requests
  const fetchProtectedData = async () => {
    const token = getAccessToken();
    return fetch('/api/data', {
      headers: { Authorization: `Bearer ${token}` },
    });
  };

  // Clear on logout
  const handleLogout = () => clearTokens();
}
```

> **Note:** All storage operations are wrapped in `try/catch` to safely handle environments where `localStorage` is unavailable (e.g., SSR, private browsing restrictions).
