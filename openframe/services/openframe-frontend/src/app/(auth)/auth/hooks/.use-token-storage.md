React hook for managing OpenFrame authentication token persistence in `localStorage`, using the `of_` prefix namespace for access and refresh tokens.

## Key Components

**Constants**
- `ACCESS_TOKEN_KEY` — `'of_access_token'` localStorage key for the access token
- `REFRESH_TOKEN_KEY` — `'of_refresh_token'` localStorage key for the refresh token

**Hook: `useTokenStorage()`**

| Method | Description |
|---|---|
| `storeAccessToken(token)` | Persists access token, returns `boolean` |
| `storeRefreshToken(token)` | Persists refresh token, returns `boolean` |
| `storeTokensFromHeaders(headers)` | Extracts and stores tokens from `Access-Token` / `Refresh-Token` response headers |
| `getAccessToken()` | Retrieves access token or `null` |
| `getRefreshToken()` | Retrieves refresh token or `null` |
| `clearTokens()` | Removes both tokens, returns `boolean` |

All methods are memoized with `useCallback` and wrap `localStorage` calls in try/catch to safely handle restricted environments (e.g., private browsing).

## Usage Example

```typescript
import { useTokenStorage } from '@/hooks/use-token-storage';

function useAuth() {
  const {
    storeTokensFromHeaders,
    getAccessToken,
    clearTokens,
  } = useTokenStorage();

  const login = async (credentials: LoginPayload) => {
    const response = await fetch('/api/auth/login', {
      method: 'POST',
      body: JSON.stringify(credentials),
    });

    // Automatically extracts Access-Token and Refresh-Token headers
    storeTokensFromHeaders(response.headers);
  };

  const logout = () => clearTokens();

  const authHeader = () => {
    const token = getAccessToken();
    return token ? { Authorization: `Bearer ${token}` } : {};
  };

  return { login, logout, authHeader };
}
```
