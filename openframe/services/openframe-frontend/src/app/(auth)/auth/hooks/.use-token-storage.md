React hook for managing OpenFrame authentication token persistence in `localStorage`, using the `of_` namespace prefix.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `ACCESS_TOKEN_KEY` | `const` | localStorage key `of_access_token` |
| `REFRESH_TOKEN_KEY` | `const` | localStorage key `of_refresh_token` |
| `useTokenStorage` | `hook` | Returns token CRUD operations |

### Hook Returns

| Method | Signature | Description |
|--------|-----------|-------------|
| `storeAccessToken` | `(token: string) => boolean` | Persists access token |
| `storeRefreshToken` | `(token: string) => boolean` | Persists refresh token |
| `storeTokensFromHeaders` | `(headers: Headers) => { accessToken, refreshToken }` | Extracts and stores both tokens from HTTP response headers |
| `getAccessToken` | `() => string \| null` | Retrieves access token |
| `getRefreshToken` | `() => string \| null` | Retrieves refresh token |
| `clearTokens` | `() => boolean` | Removes both tokens |

## Usage Example

```typescript
import { useTokenStorage } from './use-token-storage';

function useAuth() {
  const {
    storeTokensFromHeaders,
    getAccessToken,
    clearTokens,
  } = useTokenStorage();

  const login = async (credentials: Credentials) => {
    const response = await fetch('/api/auth/login', {
      method: 'POST',
      body: JSON.stringify(credentials),
    });

    // Automatically extracts Access-Token and Refresh-Token headers
    const { accessToken } = storeTokensFromHeaders(response.headers);
    return !!accessToken;
  };

  const logout = () => clearTokens();

  const getAuthHeader = () => {
    const token = getAccessToken();
    return token ? { Authorization: `Bearer ${token}` } : {};
  };

  return { login, logout, getAuthHeader };
}
```

> All methods are wrapped in `useCallback` with no dependencies (except `storeTokensFromHeaders`, which depends on the two store methods), ensuring stable references across renders. All localStorage operations are wrapped in `try/catch` to handle restricted environments gracefully.
