React hook that provides authentication actions including login, registration, logout, and tenant discovery. Does not handle auth session checking — use `useAuthSession` for that.

## Key Components

- **`discoverTenants(email)`** — Looks up existing tenant accounts for a given email, populates tenant info and available auth providers in localStorage
- **`registerOrganization(data)`** — Registers a new org with email/password credentials; handles access code validation error codes
- **`registerOrganizationSso(data)`** — Registers a new org via Google or Microsoft SSO provider
- **`loginWithSso(provider)`** — Redirects to the SSO login URL for the discovered tenant
- **`logout()`** — Clears auth store, React Query cache, tokens, and localStorage state; redirects to auth page
- **`triggerAuthRecheck()`** — Invalidates the `authSessionQueryKey` query to force a session revalidation
- **`reset()`** — Clears all local auth state without affecting the session

**State returned:**

| Field | Type | Description |
|---|---|---|
| `email` | `string` | Last used email (persisted in localStorage) |
| `tenantInfo` | `TenantInfo \| null` | Discovered tenant details |
| `hasDiscoveredTenants` | `boolean` | Whether discovery found existing accounts |
| `availableProviders` | `string[]` | Auth providers for the tenant (e.g. `google`, `openframe-sso`) |
| `isLoading` | `boolean` | Async operation in progress |
| `isInitialized` | `boolean` | localStorage hooks have hydrated |

## Usage Example

```typescript
import { useAuth } from '@/features/auth/hooks/use-auth';

function LoginForm() {
  const {
    email,
    discoverTenants,
    loginWithSso,
    hasDiscoveredTenants,
    availableProviders,
    isLoading,
  } = useAuth();

  const handleEmailSubmit = async (inputEmail: string) => {
    const result = await discoverTenants(inputEmail);
    if (result?.has_existing_accounts) {
      // Tenant found — show SSO or password options
    }
  };

  return (
    <button
      disabled={isLoading}
      onClick={() => loginWithSso('google')}
    >
      Sign in with Google
    </button>
  );
}
```

> **Note:** Auth state (`email`, `tenantInfo`, `availableProviders`) is persisted via `localStorage` across page reloads. Calling `logout()` or `reset()` clears all persisted state.
