React hook that provides authentication actions including login, registration, logout, and tenant discovery. Does not handle auth session checking — use `useAuthSession` for that.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `useAuth` | Hook | Main auth actions hook |
| `TenantDiscoveryResponse` | Interface | Response shape from tenant discovery API |

### Returned State

| Field | Type | Description |
|-------|------|-------------|
| `email` | `string` | Last used email, persisted in localStorage |
| `tenantInfo` | `TenantInfo \| null` | Discovered tenant metadata |
| `hasDiscoveredTenants` | `boolean` | Whether tenant lookup found existing accounts |
| `discoveryAttempted` | `boolean` | Whether discovery has run for current email |
| `availableProviders` | `string[]` | Auth providers available for the tenant |
| `isLoading` | `boolean` | Async operation in progress |
| `isInitialized` | `boolean` | localStorage hooks ready |

### Returned Actions

| Action | Description |
|--------|-------------|
| `discoverTenants(email)` | Looks up tenant and auth providers for a given email |
| `registerOrganization(data)` | Registers a new org with email/password credentials |
| `registerOrganizationSso(data)` | Registers a new org via Google or Microsoft SSO |
| `loginWithSso(provider)` | Redirects to SSO login URL for the discovered tenant |
| `logout()` | Clears all auth state, tokens, and query cache |
| `reset()` | Resets local form/discovery state without logging out |
| `triggerAuthRecheck()` | Invalidates React Query auth session cache |

## Usage Example

```typescript
import { useAuth } from '@/features/auth/hooks/use-auth';

function LoginPage() {
  const {
    email,
    isLoading,
    hasDiscoveredTenants,
    availableProviders,
    discoverTenants,
    loginWithSso,
    logout,
  } = useAuth();

  const handleEmailSubmit = async (inputEmail: string) => {
    const result = await discoverTenants(inputEmail);
    if (result?.has_existing_accounts) {
      // Providers are now available in `availableProviders`
    }
  };

  const handleSsoLogin = () => loginWithSso('google');

  return (/* ... */);
}
```

> **Note:** Auth state (email, tenantInfo, providers) is persisted to localStorage under the `auth:*` namespace. Calling `reset()` or `logout()` clears all persisted values.
