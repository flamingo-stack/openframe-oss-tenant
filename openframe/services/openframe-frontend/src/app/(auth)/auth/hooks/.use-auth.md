React hook that provides authentication actions including tenant discovery, organization registration, SSO login, and logout. It does **not** handle session checking — use `useAuthSession` for that.

## Key Components

- **`useAuth()`** — Main exported hook returning auth state and action functions
- **`discoverTenants(email)`** — Queries the backend for existing tenant accounts associated with an email
- **`registerOrganization(data)`** — Creates a new org with email/password credentials, handles access code validation errors
- **`registerOrganizationSso(data)`** — Registers a new org via Google or Microsoft SSO
- **`loginWithSso(provider)`** — Redirects to the SSO login URL for the discovered tenant
- **`logout()`** — Clears auth store, React Query cache, tokens, and localStorage state before redirecting
- **`triggerAuthRecheck()`** — Invalidates the `authSessionQueryKey` query to force a session recheck
- **`reset()`** — Resets all local auth state without logging out

### Persisted State (localStorage)
| Key | Description |
|-----|-------------|
| `auth:email` | Last entered email |
| `auth:tenantInfo` | Discovered tenant metadata |
| `auth:hasDiscoveredTenants` | Whether discovery returned results |
| `auth:availableProviders` | SSO providers available for the tenant |

## Usage Example

```typescript
import { useAuth } from '@/features/auth/hooks/use-auth';

function LoginPage() {
  const {
    email,
    tenantInfo,
    hasDiscoveredTenants,
    availableProviders,
    isLoading,
    discoverTenants,
    loginWithSso,
    logout,
  } = useAuth();

  const handleEmailSubmit = async (inputEmail: string) => {
    const result = await discoverTenants(inputEmail);
    if (result?.has_existing_accounts) {
      // tenantInfo and availableProviders are now populated
    }
  };

  const handleSsoLogin = () => loginWithSso('google');

  return (
    <button onClick={() => handleEmailSubmit('user@example.com')} disabled={isLoading}>
      Discover Tenant
    </button>
  );
}
```

> **Note:** After a successful login or registration, call `triggerAuthRecheck()` to sync session state across the app via React Query invalidation.
