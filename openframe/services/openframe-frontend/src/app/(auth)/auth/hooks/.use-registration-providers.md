A React hook that fetches and manages the list of available SSO registration providers from the auth API, exposing loading and error states.

## Key Components

**`SsoProvider`** — Exported interface representing a single SSO provider:
- `provider: string` — Provider identifier (e.g., `"google"`, `"github"`)
- `enabled: boolean` — Whether the provider is active

**`useRegistrationProviders()`** — Custom hook that:
- Calls `authApiClient.getRegistrationProviders()` on mount
- Maps raw provider strings into `SsoProvider` objects with `enabled: true`
- Returns `{ providers, loading, error }`

## Usage Example

```typescript
import { useRegistrationProviders } from '@/hooks/use-registration-providers';

export function SsoLoginButtons() {
  const { providers, loading, error } = useRegistrationProviders();

  if (loading) return <Spinner />;
  if (error) return <p>Error: {error}</p>;

  return (
    <>
      {providers
        .filter(p => p.enabled)
        .map(p => (
          <SsoButton key={p.provider} provider={p.provider} />
        ))}
    </>
  );
}
```

## Behavior Notes

- Runs once on mount (`[]` dependency array) — no refetch on re-render
- On API failure or empty response, `providers` is reset to `[]` and `error` is populated
- Errors from thrown exceptions are normalized to a string message before being set in state
