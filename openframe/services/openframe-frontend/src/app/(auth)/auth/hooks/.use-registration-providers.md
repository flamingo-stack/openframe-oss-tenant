A React hook that fetches and manages available SSO registration providers from the authentication API on component mount.

## Key Components

- **`SsoProvider`** — Interface representing a single SSO provider with `provider` (name string) and `enabled` (boolean) fields.
- **`useRegistrationProviders`** — Custom hook that calls `authApiClient.getRegistrationProviders()`, maps the raw string array into `SsoProvider[]` objects, and exposes loading/error state.

## Usage Example

```typescript
import { useRegistrationProviders } from '@/hooks/use-registration-providers';

function SsoLoginOptions() {
  const { providers, loading, error } = useRegistrationProviders();

  if (loading) return <Spinner />;
  if (error) return <ErrorMessage message={error} />;

  return (
    <ul>
      {providers.map(({ provider, enabled }) => (
        <li key={provider}>
          <SsoButton provider={provider} disabled={!enabled} />
        </li>
      ))}
    </ul>
  );
}
```

## Return Values

| Field | Type | Description |
|-------|------|-------------|
| `providers` | `SsoProvider[]` | List of available SSO providers, each marked `enabled: true` |
| `loading` | `boolean` | `true` while the API request is in flight |
| `error` | `string \| null` | Error message if the request failed, otherwise `null` |

> Fetch runs once on mount via `useEffect([], [])`. On failure, `providers` resets to an empty array and `error` is populated with the response error or caught exception message.
