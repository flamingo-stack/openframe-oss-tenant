A React hook that fetches available SSO registration providers from the auth API and exposes loading/error state for use in registration UI components.

## Key Components

**`SsoProvider`** — Exported interface representing a single SSO provider with `provider` (name string) and `enabled` (boolean) fields.

**`useRegistrationProviders()`** — Custom hook that calls `authApiClient.getRegistrationProviders()` on mount, normalizes the raw string array response into `SsoProvider[]` objects (all marked `enabled: true`), and returns reactive state.

**Returns:**

| Field | Type | Description |
|-------|------|-------------|
| `providers` | `SsoProvider[]` | List of available SSO providers |
| `loading` | `boolean` | `true` while the request is in-flight |
| `error` | `string \| null` | Error message if the request failed |

## Usage Example

```typescript
import { useRegistrationProviders } from '@/hooks/use-registration-providers';

export function SsoProviderList() {
  const { providers, loading, error } = useRegistrationProviders();

  if (loading) return <p>Loading providers...</p>;
  if (error) return <p>Error: {error}</p>;

  return (
    <ul>
      {providers.map(({ provider, enabled }) => (
        <li key={provider}>
          {provider} — {enabled ? 'Available' : 'Disabled'}
        </li>
      ))}
    </ul>
  );
}
```

> **Note:** This is a client-only hook (`'use client'`). Do not use it in React Server Components. The fetch runs once on mount with no refetch logic; wrap in a parent with a key reset if re-fetching is needed.
