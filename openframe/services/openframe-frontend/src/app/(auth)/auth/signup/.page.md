A Next.js route entry point that renders the signup page as a client-side-only component by disabling server-side rendering (SSR).

## Key Components

- **`Signup`** — Default export; a thin wrapper that delegates rendering to the dynamically imported `SignupPage`.
- **`SignupPage`** — Dynamically imported from `@/app/(auth)/auth/pages/signup-page` with `ssr: false`, ensuring the component is only rendered in the browser.

## Usage Example

```typescript
// This file acts as the /signup route handler.
// Next.js automatically maps it to the corresponding URL segment.
// No direct invocation needed — the framework renders <Signup /> for the route.

export default function Signup() {
  return <SignupPage />; // Loaded client-side only
}
```

> The `ssr: false` flag is typically used when the signup page relies on browser-only APIs (e.g., `window`, `localStorage`) or auth SDKs that are incompatible with server-side rendering.
