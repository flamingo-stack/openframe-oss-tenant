Client-side signup route entry point that dynamically imports the signup page component with SSR disabled.

## Key Components

- **`Signup`** — Default export; a thin wrapper that renders the dynamically loaded `SignupPage`
- **`SignupPage`** — Lazily imported from `@/app/(auth)/auth/pages/signup-page` with `ssr: false` to ensure it only renders in the browser

## Usage Example

This file is a Next.js App Router page. It is automatically served at the `/auth/signup` (or equivalent) route. No direct invocation is needed.

```typescript
// Accessing the page via navigation
import { useRouter } from 'next/navigation';

const router = useRouter();
router.push('/auth/signup');
```

> The `ssr: false` flag prevents the signup form from being server-rendered, which is common when the component relies on browser-only APIs (e.g., `window`, auth SDKs, or client-side session state).
