Client-side signup page route that dynamically imports the signup UI component with SSR disabled.

## Key Components

- **`Signup`** — Default export; Next.js page component that renders the dynamically loaded `SignupPage`.
- **`SignupPage`** — Dynamically imported from `@/app/(auth)/auth/pages/signup-page` with `ssr: false` to ensure client-only rendering.

## Usage Example

```typescript
// Accessed via the /signup route in Next.js App Router
// No direct import needed — Next.js resolves this automatically
export default function Signup() {
  return <SignupPage />;
}
```

> `ssr: false` ensures the signup form is only rendered on the client, preventing hydration issues with auth-sensitive UI.
