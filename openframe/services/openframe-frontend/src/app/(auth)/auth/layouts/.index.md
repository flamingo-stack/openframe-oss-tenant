Unified layout wrapper for all OpenFrame authentication pages, providing a responsive 50/50 split between auth form content and a benefits panel.

## Key Components

- **`AuthLayout`** — Client-side layout component that renders a two-column structure:
  - **Left panel** (50% on desktop, full-width on mobile): Scrollable area with vertically centered `children`
  - **Right panel** (50% on desktop, full-width on mobile): Renders `AuthBenefitsSection`

## Usage Example

```typescript
import { AuthLayout } from './index';

export default function LoginPage() {
  return (
    <AuthLayout>
      <LoginForm />
    </AuthLayout>
  );
}
```

## Notes

- Marked `'use client'` — runs on the client side in Next.js App Router
- Responsive behavior: stacks vertically on mobile (`flex-col`), splits horizontally on `lg+` (`flex-row`)
- Left panel uses `overflow-y-auto` on desktop to handle tall form content without affecting the fixed viewport layout (`lg:h-screen lg:overflow-hidden`)
- Intended as the shared wrapper for all auth routes (login, register, forgot password, etc.)
