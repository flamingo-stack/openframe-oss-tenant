Reusable layout wrapper for OpenFrame authentication pages, rendering a responsive 50/50 split between auth form content and a benefits panel.

## Key Components

- **`AuthLayout`** — Client component that wraps auth page children in a two-column layout:
  - **Left panel** (50%): Scrollable column with vertically centered `children` (login, signup, etc.)
  - **Right panel** (50%): Renders `AuthBenefitsSection` with marketing/feature highlights
- **`AuthLayoutProps`** — Interface accepting `children: React.ReactNode`

## Usage Example

```typescript
import { AuthLayout } from './index';

export default function LoginPage() {
  return (
    <AuthLayout>
      <LoginForm />
    </AuthLayout>
  );
}
```

## Responsive Behavior

| Breakpoint | Layout |
|---|---|
| Mobile (`< lg`) | Single column, stacked vertically |
| Desktop (`lg+`) | Fixed-height viewport, 50/50 horizontal split with independent scroll on the left panel |
