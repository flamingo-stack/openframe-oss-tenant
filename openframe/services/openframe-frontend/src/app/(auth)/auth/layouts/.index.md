Reusable layout wrapper for OpenFrame authentication pages, providing a responsive 50/50 split between auth form content and a benefits panel.

## Key Components

- **`AuthLayout`** — Client component that wraps auth page children in a two-column layout. Left column renders the `children` (login/signup forms, etc.) with vertical centering; right column renders `AuthBenefitsSection`.
- **`AuthBenefitsSection`** — Imported side panel component displayed on the right half of the screen.

## Usage Example

```typescript
import { AuthLayout } from '@/app/auth/layout';

export default function LoginPage() {
  return (
    <AuthLayout>
      <LoginForm />
    </AuthLayout>
  );
}
```

## Layout Behavior

| Breakpoint | Behavior |
|------------|----------|
| Mobile (`< lg`) | Single column, full width, stacked vertically |
| Desktop (`lg+`) | 50/50 horizontal split, each side fills viewport height with independent scroll |

The left panel uses `overflow-y-auto` to allow scrolling on tall auth forms without affecting the right benefits panel, while `justify-center` keeps short forms vertically centered on large screens.
