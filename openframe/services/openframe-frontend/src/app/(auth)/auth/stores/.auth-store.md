Zustand-based authentication store managing user session state, including login/logout, profile fetching, and tenant tracking, with persistence and DevTools support.

## Key Components

**Interfaces**
- `User` — Core user model with fields from `/me` endpoint and full profile fetch
- `UserImage` — Avatar metadata (`imageUrl`, `hash`)
- `AuthState` — Combined state + actions interface exported for external typing

**Store: `useAuthStore`**
Built with `zustand` + `immer` + `persist` + `devtools` middleware stack:

| Action | Description |
|---|---|
| `login(user)` | Sets user; merges fields if same user ID already exists |
| `logout()` | Clears user, auth flag, error, and `tenantId` |
| `updateUser(partial)` | Shallow-merges partial user data |
| `setLoading(bool)` | Toggles `isLoading` flag |
| `setError(msg)` | Sets error string and clears `isLoading` |
| `clearError()` | Resets error to `null` |
| `setTenantId(id)` | Stores tenant ID in memory and persistence |
| `fetchFullProfile()` | Fetches full user from `api/users/:id`, merges into state (skips if already loading) |

**Persistence** — Only `user`, `isAuthenticated`, and `tenantId` are persisted via `localStorage` key `auth-storage`.

**Selectors** — Pre-built selectors to prevent unnecessary re-renders:
- `selectUser`, `selectIsAuthenticated`, `selectIsLoading`, `selectError`

## Usage Example

```typescript
import { useAuthStore, selectIsAuthenticated, selectUser } from '@/stores/auth-store';

// Access state with selectors
const user = useAuthStore(selectUser);
const isAuthenticated = useAuthStore(selectIsAuthenticated);

// Login after /me response
const { login, fetchFullProfile, logout } = useAuthStore.getState();

login({
  id: 'usr_123',
  email: 'tech@example.com',
  tenantId: 'tenant_abc',
});

// Enrich with full profile data
await fetchFullProfile();

// On session end
logout();
```

> **Note:** `tenantId` is cleared on `logout()` but persisted across page reloads. The `fetchFullProfile` action guards against concurrent calls via the `isLoadingProfile` flag and only updates `image` if `imageUrl` or `hash` has changed.
