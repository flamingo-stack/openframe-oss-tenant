Zustand-based authentication store that manages user session state, including login/logout actions, profile fetching, and tenant context — persisted to storage with DevTools support.

## Key Components

### Interfaces

| Type | Description |
|------|-------------|
| `User` | Core user shape with fields from `/me` endpoint and full profile fetch |
| `UserImage` | Image metadata (`imageUrl`, `hash`) |
| `AuthState` | Full store shape combining state fields and action methods |

### Store — `useAuthStore`

Built with Zustand + `immer` + `persist` + `devtools` middleware stack.

**State fields:**

| Field | Type | Persisted |
|-------|------|-----------|
| `user` | `User \| null` | ✅ |
| `isAuthenticated` | `boolean` | ✅ |
| `tenantId` | `string \| null` | ✅ |
| `isLoading` | `boolean` | ❌ |
| `isLoadingProfile` | `boolean` | ❌ |
| `error` | `string \| null` | ❌ |

**Actions:** `login`, `logout`, `updateUser`, `setLoading`, `setError`, `clearError`, `setTenantId`, `fetchFullProfile`

### Selectors

Pre-built selectors to prevent unnecessary re-renders: `selectUser`, `selectIsAuthenticated`, `selectIsLoading`, `selectError`

## Usage Example

```typescript
import { useAuthStore, selectUser, selectIsAuthenticated } from '@/stores/auth-store';

// In a React component
function UserMenu() {
  const user = useAuthStore(selectUser);
  const isAuthenticated = useAuthStore(selectIsAuthenticated);
  const { login, logout, fetchFullProfile } = useAuthStore();

  // Login with user from /me endpoint
  const handleLogin = (meResponse: User) => {
    login(meResponse);
    fetchFullProfile(); // Enriches user with full profile data
  };

  return isAuthenticated ? (
    <span>{user?.firstName} <button onClick={logout}>Sign out</button></span>
  ) : null;
}

// Outside React (e.g. API interceptors)
const { tenantId, setTenantId } = useAuthStore.getState();
setTenantId('tenant_abc123');
```

> **Note:** Only `user`, `isAuthenticated`, and `tenantId` are persisted to `localStorage` under the key `auth-storage`. Transient fields like `isLoading` and `error` reset on page reload.
