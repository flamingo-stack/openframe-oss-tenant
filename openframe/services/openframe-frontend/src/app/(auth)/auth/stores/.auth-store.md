Zustand-based authentication store managing user session state, persistence, and profile fetching for the OpenFrame platform.

## Key Components

**Interfaces**
- `User` — Core user model with fields from `/me` endpoint and full profile fetch (roles, tenant, image, etc.)
- `UserImage` — User avatar with URL and hash for change detection
- `AuthState` — Combined state + actions interface exported for external typing

**Store: `useAuthStore`**
Built with `zustand` + `immer` + `persist` + `devtools` middleware stack.

| Action | Description |
|---|---|
| `login(user)` | Sets authenticated state; merges if same user ID, replaces otherwise |
| `logout()` | Clears user, auth flag, error, and tenantId |
| `updateUser(partial)` | Shallow-merges partial user data |
| `fetchFullProfile()` | Async fetch from `api/users/:id`; smart image diff to avoid unnecessary updates |
| `setTenantId` / `setLoading` / `setError` / `clearError` | Utility state setters |

**Persistence** — Only `user`, `isAuthenticated`, and `tenantId` are persisted to `localStorage` under key `auth-storage`. Transient flags (`isLoading`, `isLoadingProfile`, `error`) are excluded.

**Selectors** — Pre-defined selectors for optimized component re-renders:
`selectUser`, `selectIsAuthenticated`, `selectIsLoading`, `selectError`

## Usage Example

```typescript
import { useAuthStore, selectUser, selectIsAuthenticated } from '@/stores/auth-store';

// In a component
const user = useAuthStore(selectUser);
const isAuthenticated = useAuthStore(selectIsAuthenticated);
const { login, logout, fetchFullProfile } = useAuthStore();

// Login after /me response
login({ id: '123', email: 'tech@example.com', tenantId: 'acme' });

// Hydrate full profile post-login
await fetchFullProfile();

// Logout and clear persisted state
logout();
```

> **Note:** `tenantId` is stored in-memory and persisted separately from the user object to support tenant switching without a full re-authentication flow.
