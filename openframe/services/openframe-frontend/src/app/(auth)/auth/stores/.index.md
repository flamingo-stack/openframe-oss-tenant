Barrel export file for the authentication store module, re-exporting all public types and state selectors from `auth-store`.

## Key Components

**Types**
- `AuthState` — Shape of the authentication state object
- `User` — Authenticated user data structure
- `UserImage` — User profile image type

**Selectors & Store**
- `selectAuthError` — Selects authentication error state
- `selectIsAuthenticated` — Selects boolean authentication status
- `selectAuthLoading` — Selects loading state during auth operations
- `selectUser` — Selects the current authenticated user object
- `useAuthStore` — Zustand/store hook for accessing auth state

## Usage Example

```typescript
import {
  useAuthStore,
  selectUser,
  selectIsAuthenticated,
  selectAuthLoading,
  selectAuthError,
} from '@/store/auth';

function ProfileComponent() {
  const user = useAuthStore(selectUser);
  const isAuthenticated = useAuthStore(selectIsAuthenticated);
  const isLoading = useAuthStore(selectAuthLoading);
  const error = useAuthStore(selectAuthError);

  if (isLoading) return <Spinner />;
  if (!isAuthenticated) return <Redirect to="/login" />;

  return <div>{user?.name}</div>;
}
```
