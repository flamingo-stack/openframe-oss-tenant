Public API barrel file for the auth store module, re-exporting all types and selectors from `auth-store` with consistent naming conventions.

## Key Components

**Types**
- `AuthState` — Shape of the authentication state
- `User` — Authenticated user model
- `UserImage` — User avatar/image data

**Selectors & Store**
- `selectAuthError` — Selects authentication error state (aliased from `selectError`)
- `selectIsAuthenticated` — Selects boolean authentication status
- `selectAuthLoading` — Selects loading state (aliased from `selectIsLoading`)
- `selectUser` — Selects the current user object
- `useAuthStore` — Zustand/Pinia store hook for auth state

## Usage Example

```typescript
import {
  useAuthStore,
  selectIsAuthenticated,
  selectUser,
  selectAuthError,
  selectAuthLoading,
} from '@/stores/auth';

function ProfileWidget() {
  const isAuthenticated = useAuthStore(selectIsAuthenticated);
  const user = useAuthStore(selectUser);
  const isLoading = useAuthStore(selectAuthLoading);
  const error = useAuthStore(selectAuthError);

  if (isLoading) return 'Loading...';
  if (!isAuthenticated) return 'Not logged in';

  return `Hello, ${user?.name}`;
}
```

> **Note:** Aliases (`selectAuthError`, `selectAuthLoading`) provide a namespace-safe naming convention, preventing collisions when composing multiple store modules in the same scope.
