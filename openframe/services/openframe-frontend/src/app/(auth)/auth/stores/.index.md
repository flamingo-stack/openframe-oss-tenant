Barrel export file for the authentication store module, re-exporting all public types and state selectors from `auth-store`.

## Key Components

**Types**
- `AuthState` — Shape of the authentication state object
- `User` — User entity type
- `UserImage` — User profile image type

**Selectors & Store**
- `selectAuthError` — Selects authentication error state
- `selectIsAuthenticated` — Selects boolean authentication status
- `selectAuthLoading` — Selects loading state during auth operations
- `selectUser` — Selects the current authenticated user
- `useAuthStore` — Composable/hook for accessing the full auth store

## Usage Example

```typescript
import {
  useAuthStore,
  selectIsAuthenticated,
  selectUser,
  selectAuthError,
  selectAuthLoading,
} from '@/stores/auth';

const store = useAuthStore();
const isAuthenticated = selectIsAuthenticated(store);
const currentUser = selectUser(store);
```
