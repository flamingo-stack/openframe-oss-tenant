Authentication error boundary page that displays user-friendly error messages when auth flows fail, with options to contact support or return to login.

## Key Components

- **`AuthErrorPage`** — Default export; a Next.js client component that reads an optional `?error=` query param and renders a branded error screen
- **`DEFAULT_ERROR`** — Fallback title/description constants used when no error code is present in the URL
- **OpenFrame / Flamingo branding** — `OpenFrameLogo`, `OpenFrameText`, and `FlamingoLogo` icons from the shared component library

## Usage Example

```typescript
// Triggered automatically by NextAuth or custom auth middleware redirects, e.g.:
// /auth/error?error=OAuthCallbackError
// /auth/error?error=AccessDenied

// Manual navigation example:
router.push('/auth/error?error=SessionExpired');
```

## Behavior

| Scenario | Result |
|----------|--------|
| `?error=<message>` present | Displays the raw error string as the description |
| No query param | Shows the generic `DEFAULT_ERROR` description |
| "Contact Support" | Opens `https://www.flamingo.run/contact` in a new tab |
| "Go to Login" | Navigates to `/auth` via `router.push` |

> The footer link always points to `https://flamingo.run` and is rendered as a branded "Powered by Flamingo" attribution.
