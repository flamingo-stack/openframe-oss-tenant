Client-side authentication error page that displays a user-friendly error message with support and login navigation options when auth failures occur.

## Key Components

- **`AuthErrorPage`** — Default export; a Next.js client component that reads an optional `error` query parameter and renders a branded error screen
- **`DEFAULT_ERROR`** — Fallback title/description constants used when no `error` query param is present
- **`errorCode`** — Extracted from `searchParams.get('error')`; used directly as the error description if provided

## Usage Example

```typescript
// Triggered by redirecting to /auth/error?error=<message>
// e.g. from an auth callback or middleware:
router.push('/auth/error?error=SessionExpired');

// With no query param, renders the default fallback message:
router.push('/auth/error');
```

## Behavior

| Scenario | Title | Description |
|----------|-------|-------------|
| `?error=<message>` | Default title | Uses `errorCode` as description |
| No query param | Default title | Uses `DEFAULT_ERROR.description` |

## UI Structure

- **Header** — `OpenFrameLogo` + `OpenFrameText` branding
- **Body** — Dynamic `title` / `description` + two action buttons:
  - `Contact Support` → opens `https://www.flamingo.run/contact` in a new tab
  - `Go to Login` → routes to `/auth`
- **Footer** — "Powered by Flamingo" link back to `https://flamingo.run`
