A Next.js client-side page that displays a user-friendly authentication error screen with contextual error messaging, support contact options, and navigation back to login.

## Key Components

- **`AuthErrorPage`** — Default export; a full-page error display component that reads an optional `error` query parameter to surface specific error messages
- **`DEFAULT_ERROR`** — Fallback title and description shown when no `error` search param is present
- **OpenFrame branding** — Renders `OpenFrameLogo` and `OpenFrameText` in the header, and a `FlamingoLogo` footer link to `flamingo.run`

## Usage Example

```typescript
// Accessed via Next.js routing, e.g. /auth/error
// Optionally pass an error message via query string:
router.push('/auth/error?error=Session+expired+or+invalid+credentials');

// Without a query param, the default fallback message is shown:
// → "An unexpected error occurred. Please try again..."
```

## Behavior Notes

- **Error param** — The `error` query param value is used directly as the description text; if absent, `DEFAULT_ERROR.description` is used as the fallback
- **"Contact Support"** button — Opens `https://www.flamingo.run/contact` in a new tab with `noopener,noreferrer`
- **"Go to Login"** button — Uses `useRouter` to push the user back to `/auth`
- **Footer** — A branded link to `https://flamingo.run` styled with hover feedback using ODS (OpenDesignSystem) tokens
