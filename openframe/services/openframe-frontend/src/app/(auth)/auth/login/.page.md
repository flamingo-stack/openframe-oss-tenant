Thin client-side wrapper that lazy-loads the `LoginPage` component with SSR disabled, serving as the Next.js route entry point for `/auth/login`.

## Key Components

- **`Login`** — Default export; a Next.js page component that renders the dynamically imported `LoginPage`.
- **`LoginPage`** — Dynamically imported from `@/app/(auth)/auth/pages/login-page` with `ssr: false` to ensure it only renders on the client.

## Usage Example

```typescript
// Automatically rendered by Next.js when navigating to /auth/login
// No manual usage required — Next.js picks this up as a route handler

// To navigate programmatically:
import { useRouter } from 'next/navigation';

const router = useRouter();
router.push('/auth/login');
```

> **Note:** The `ssr: false` flag prevents server-side rendering of the login page, which is typical for auth flows that depend on browser-only APIs (e.g., `localStorage`, OAuth redirects).
