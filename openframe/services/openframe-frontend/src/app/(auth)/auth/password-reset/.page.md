Password reset page component that handles token-validated password updates, including form validation, error handling, and post-reset redirection.

## Key Components

- **`PasswordResetPage`** — Default export; a client-side Next.js page component rendered inside `AuthLayout`
- **Token guard** — `useEffect` checks for a `token` query param on mount; redirects to `/auth` with a destructive toast if missing
- **`handleSubmit`** — Async form handler performing client-side validation (empty fields, password match, minimum length) before calling `authApiClient.confirmPasswordReset`
- **Inline validation hints** — Real-time feedback below each input for length and mismatch errors before submission

## Usage Example

```typescript
// Accessed via URL: /auth/password-reset?token=<reset_token>
// No props required — token is read from query params via useSearchParams()

// authApiClient.confirmPasswordReset is called with:
{
  token: string,      // from ?token= query param
  newPassword: string // validated: min 8 chars, must match confirm field
}

// On success: toasts and redirects to /auth after 2 seconds
// On missing token: immediate redirect to /auth
```

## Validation Rules

| Condition | Behavior |
|---|---|
| No `token` in URL | Redirect to `/auth` immediately |
| Empty fields | Destructive toast, no API call |
| Password mismatch | Destructive toast, no API call |
| Password `< 8` chars | Destructive toast + inline error hint |
| API error | Displays `error.message` or fallback text |
| Success | Success toast + redirect to `/auth` after 2s |
