Password reset page component that handles token-based password reset flow, validating the reset token from URL params and allowing users to set a new password with client-side validation.

## Key Components

- **`PasswordResetPage`** — Default export; a Next.js client page component that:
  - Reads the `token` query parameter from the URL and redirects to `/auth` if missing
  - Validates password length (≥ 8 chars) and confirmation match before submission
  - Calls `authApiClient.confirmPasswordReset()` with the token and new password
  - Shows success/error toast notifications and redirects to `/auth` on success

## Usage Example

```typescript
// Rendered automatically by Next.js when navigating to:
// /auth/reset-password?token=<reset_token>

// The token is typically provided via a password reset email link.
// Example URL structure:
// https://your-app.com/auth/reset-password?token=eyJhbGciOiJIUzI1NiJ9...
```

## Validation Rules

| Rule | Condition |
|------|-----------|
| Both fields required | Empty fields blocked before submit |
| Passwords must match | Inline error shown on mismatch |
| Minimum length | ≥ 8 characters enforced inline and on submit |
| Token presence | Missing token redirects immediately to `/auth` |

## Dependencies

- `authApiClient.confirmPasswordReset` — Sends `{ token, newPassword }` to the auth API
- `AuthLayout` — Wraps the form in the shared authentication page layout
- `useToast` — Provides user feedback for validation errors and API responses
- `useSearchParams` / `useRouter` — Next.js hooks for token extraction and navigation
