Root layout component for the OpenFrame authentication section, setting page metadata and wrapping auth pages with Reddit click ID tracking.

## Key Components

- **`AuthLayout`** — Default export layout wrapping all `/auth/*` routes with the `RedditClickIdCapture` component
- **`metadata`** — Next.js page metadata object defining the auth section title and description
- **`RedditClickIdCapture`** — Injected tracking component that captures Reddit click IDs for ad attribution

## Usage Example

```typescript
// Automatically applied to all routes under /auth/
// e.g. /auth/login, /auth/register

export default function LoginPage() {
  return <form>...</form>; // Rendered as `children` inside AuthLayout
}
```
