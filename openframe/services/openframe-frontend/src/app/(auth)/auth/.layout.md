Root layout for the OpenFrame authentication section, setting page metadata and wrapping auth pages with Reddit click ID capture for ad conversion tracking.

## Key Components

- **`AuthLayout`** — Default export; wraps all `/auth/*` pages with the `RedditClickIdCapture` component and renders child routes
- **`metadata`** — Next.js static metadata object defining the page `title` and `description` for the auth section
- **`RedditClickIdCapture`** — Imported component that captures Reddit click IDs (`rdt_cid`) from URL params for ad attribution

## Usage Example

```typescript
// This layout is automatically applied by Next.js to all routes
// under the /auth directory (e.g. /auth/login, /auth/register)

// Next.js picks up the exported metadata automatically:
export const metadata = {
  title: 'OpenFrame - Authentication',
  description: 'Sign in to your OpenFrame account',
};

// Child pages render inside AuthLayout:
export default function LoginPage() {
  return <LoginForm />;
}
```

> **Note:** This is a Next.js App Router layout file. It is not imported directly — Next.js automatically applies it to all nested routes within the `auth` segment.
