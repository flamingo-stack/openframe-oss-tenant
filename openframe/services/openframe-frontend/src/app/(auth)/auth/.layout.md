Root layout component for the OpenFrame authentication section, wrapping all auth pages with Reddit click ID tracking and shared metadata.

## Key Components

- **`AuthLayout`** — Default layout wrapper applied to all routes under the auth directory; renders `RedditClickIdCapture` alongside child page content
- **`metadata`** — Next.js static metadata export setting the page title and description for all auth routes
- **`RedditClickIdCapture`** — Injected tracking component that captures Reddit click IDs for ad attribution

## Usage Example

```typescript
// Automatically applied to all pages under /auth/*
// Example: /auth/login, /auth/register

export default function LoginPage() {
  return <form>{/* login form */}</form>;
}
// AuthLayout wraps this, injecting RedditClickIdCapture + metadata
```

> This layout is a [Next.js App Router layout](https://nextjs.org/docs/app/building-your-application/routing/layouts-and-templates). It is automatically composed by the framework — no manual wrapping is needed.
