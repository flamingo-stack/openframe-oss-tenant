A React hook for managing Mingo AI dialog interactions, providing seamless chat creation and message sending capabilities with built-in error handling and state management.

## Key Components

**Main Hook:**
- `useMingoDialog()` - Primary hook exposing dialog management functionality

**Core Functions:**
- `createDialog()` - Creates a new ADMIN agent dialog and returns the dialog ID
- `sendMessage()` - Sends messages to existing or new dialogs with automatic dialog creation
- `resetDialog()` - Clears current dialog state and resets mutations

**State Management:**
- `currentDialogId` - Active dialog identifier with ref backup for persistence
- `isCreatingDialog` / `isSendingMessage` - Loading states for UI feedback
- `hasDialog` - Boolean flag indicating if a dialog is active

## Usage Example

```typescript
import { useMingoDialog } from './hooks/use-mingo-dialog'

function MingoChat() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    createDialog,
    sendMessage,
    resetDialog,
    hasDialog,
    error
  } = useMingoDialog()

  const handleSendMessage = async (content: string) => {
    const success = await sendMessage(content)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleNewChat = async () => {
    const dialogId = await createDialog()
    if (dialogId) {
      console.log('New dialog created:', dialogId)
    }
  }

  return (
    <div>
      {hasDialog ? (
        <p>Active dialog: {currentDialogId}</p>
      ) : (
        <button onClick={handleNewChat} disabled={isCreatingDialog}>
          Start New Chat
        </button>
      )}
      
      <button 
        onClick={() => handleSendMessage('Hello Mingo!')}
        disabled={isSendingMessage}
      >
        Send Message
      </button>
      
      <button onClick={resetDialog}>Reset Chat</button>
    </div>
  )
}
```

The hook automatically handles dialog creation when sending messages to non-existent dialogs, includes comprehensive error handling with toast notifications, and maintains dialog state persistence across component re-renders using both state and refs.
