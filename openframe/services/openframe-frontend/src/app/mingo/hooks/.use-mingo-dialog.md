Custom React hook for managing Mingo AI chat dialogs, providing dialog creation, message sending, and state management functionality within the Flamingo/OpenFrame platform.

## Key Components

- **useMingoDialog()** - Main hook that returns dialog management utilities
- **createDialogMutation** - TanStack Query mutation for creating new admin chat dialogs
- **sendMessageMutation** - TanStack Query mutation for sending messages to dialogs
- **createDialog()** - Creates a new dialog and returns the dialog ID
- **sendMessage()** - Sends a message to an active or new dialog
- **resetDialog()** - Clears current dialog state and resets mutations
- **getActiveDialogId()** - Utility to resolve the current active dialog ID

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function ChatComponent() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    createDialog,
    sendMessage,
    resetDialog,
    hasDialog,
    error
  } = useMingoDialog()

  const handleSendMessage = async (content: string) => {
    const success = await sendMessage(content)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleNewChat = async () => {
    const dialogId = await createDialog()
    if (dialogId) {
      console.log('New dialog created:', dialogId)
    }
  }

  return (
    <div>
      {hasDialog && <p>Active Dialog: {currentDialogId}</p>}
      <button onClick={handleNewChat} disabled={isCreatingDialog}>
        New Chat
      </button>
      <button 
        onClick={() => handleSendMessage('Hello Mingo!')} 
        disabled={isSendingMessage}
      >
        Send Message
      </button>
      {error && <p>Error: {error.message}</p>}
    </div>
  )
}
```
