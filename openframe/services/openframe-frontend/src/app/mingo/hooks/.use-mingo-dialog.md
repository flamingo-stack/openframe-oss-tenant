A React hook for managing Mingo AI dialog interactions within the Flamingo/OpenFrame platform, providing functionality to create chat dialogs and send messages to admin agents.

## Key Components

- **useMingoDialog**: Main hook that manages dialog state and API interactions
- **createDialog**: Creates a new admin chat dialog and returns the dialog ID
- **sendMessage**: Sends messages to existing or new dialogs with automatic dialog creation
- **resetDialog**: Clears current dialog state and resets mutations
- **State Management**: Tracks current dialog ID with both state and ref for persistence

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function ChatInterface() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    createDialog,
    sendMessage,
    resetDialog,
    hasDialog
  } = useMingoDialog()

  const handleSendMessage = async (message: string) => {
    const success = await sendMessage(message)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleNewChat = async () => {
    const dialogId = await createDialog()
    if (dialogId) {
      console.log('New dialog created:', dialogId)
    }
  }

  return (
    <div>
      <button onClick={handleNewChat} disabled={isCreatingDialog}>
        {hasDialog ? 'Current Dialog' : 'Start New Chat'}
      </button>
      <button 
        onClick={() => handleSendMessage('Hello Mingo!')}
        disabled={isSendingMessage}
      >
        Send Message
      </button>
      <button onClick={resetDialog}>Reset Chat</button>
    </div>
  )
}
```

The hook automatically handles error states with toast notifications and invalidates React Query cache when dialogs are created. It supports both creating new dialogs and sending messages to existing ones, with automatic dialog creation if none exists.
