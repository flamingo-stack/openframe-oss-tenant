A React hook that manages Mingo AI dialog creation and messaging functionality, providing a unified interface for chat operations with automatic dialog management and error handling.

## Key Components

**Main Hook Export:**
- `useMingoDialog()` - Primary hook for managing AI chat dialogs

**Core Functions:**
- `createDialog()` - Creates a new admin-type dialog and returns its ID
- `sendMessage(content, dialogId?)` - Sends messages to dialogs, auto-creating if needed
- `resetDialog()` - Clears current dialog state and resets mutations

**State Management:**
- Dialog ID tracking with both state and ref for persistence
- Mutation states for creation and messaging operations
- Automatic query invalidation for dialog lists

**Type Definitions:**
- `CreateDialogResponse` - Dialog creation API response structure
- `CreateDialogRequest/SendMessageRequest` - API request interfaces

## Usage Example

```typescript
import { useMingoDialog } from '@/hooks/use-mingo-dialog'

function ChatComponent() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    sendMessage,
    createDialog,
    resetDialog,
    hasDialog
  } = useMingoDialog()

  const handleSendMessage = async (message: string) => {
    const success = await sendMessage(message)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleNewChat = async () => {
    resetDialog()
    const dialogId = await createDialog()
    console.log('New dialog created:', dialogId)
  }

  return (
    <div>
      <p>Current Dialog: {currentDialogId || 'None'}</p>
      <button 
        onClick={handleNewChat}
        disabled={isCreatingDialog}
      >
        {isCreatingDialog ? 'Creating...' : 'New Chat'}
      </button>
    </div>
  )
}
```

The hook automatically handles dialog creation when sending messages without an active dialog, provides loading states for UI feedback, and includes comprehensive error handling with toast notifications.
