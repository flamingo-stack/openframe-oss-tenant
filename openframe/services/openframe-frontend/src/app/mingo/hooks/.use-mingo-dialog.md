A React hook for managing AI chat dialog operations in Flamingo's Mingo AI system, providing functionality to create new dialogs and send messages with proper error handling.

## Key Components

- **useMingoDialog()** - Main hook that manages dialog state and operations
- **createDialog()** - Creates a new ADMIN-type dialog and returns the dialog ID
- **sendMessage()** - Sends messages to existing dialogs, auto-creating one if needed
- **resetDialog()** - Clears current dialog state and resets mutations
- **State tracking** - Manages current dialog ID with both state and ref for persistence

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function ChatInterface() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    createDialog,
    sendMessage,
    resetDialog,
    hasDialog
  } = useMingoDialog()

  const handleSendMessage = async (content: string) => {
    const success = await sendMessage(content)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleNewChat = async () => {
    resetDialog()
    const dialogId = await createDialog()
    if (dialogId) {
      console.log(`New dialog created: ${dialogId}`)
    }
  }

  return (
    <div>
      <button onClick={handleNewChat} disabled={isCreatingDialog}>
        {isCreatingDialog ? 'Creating...' : 'New Chat'}
      </button>
      <input 
        onKeyPress={(e) => {
          if (e.key === 'Enter') {
            handleSendMessage(e.target.value)
            e.target.value = ''
          }
        }}
        disabled={isSendingMessage}
        placeholder="Type your message..."
      />
      {hasDialog && <p>Dialog ID: {currentDialogId}</p>}
    </div>
  )
}
```

The hook automatically handles dialog creation when sending messages if no dialog exists, uses React Query for caching and error management, and provides toast notifications for user feedback.
