A React hook for managing Mingo AI chat dialogs, providing functionality to create new dialog sessions and send messages with automatic error handling and loading states.

## Key Components

- **useMingoDialog**: Main hook that manages dialog state and provides CRUD operations
- **createDialog**: Creates a new admin-type dialog session and returns the dialog ID
- **sendMessage**: Sends messages to existing dialogs or creates a new dialog if none exists
- **resetDialog**: Clears current dialog state and resets mutations
- **State management**: Tracks current dialog ID, loading states, and errors using React Query

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function ChatInterface() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    createDialog,
    sendMessage,
    resetDialog,
    hasDialog
  } = useMingoDialog()

  const handleSendMessage = async (message: string) => {
    const success = await sendMessage(message)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleNewChat = async () => {
    resetDialog()
    const newDialogId = await createDialog()
    console.log('New dialog created:', newDialogId)
  }

  return (
    <div>
      <p>Dialog ID: {currentDialogId || 'None'}</p>
      <button onClick={handleNewChat} disabled={isCreatingDialog}>
        {isCreatingDialog ? 'Creating...' : 'New Chat'}
      </button>
      <button 
        onClick={() => handleSendMessage('Hello Mingo!')} 
        disabled={isSendingMessage}
      >
        {isSendingMessage ? 'Sending...' : 'Send Message'}
      </button>
    </div>
  )
}
```

The hook automatically handles dialog creation when sending messages to non-existent dialogs and provides comprehensive error handling with toast notifications for user feedback.
