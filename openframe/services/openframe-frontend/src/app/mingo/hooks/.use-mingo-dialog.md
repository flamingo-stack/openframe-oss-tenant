A React hook for managing Mingo AI dialog interactions, providing functionality to create new admin dialogs and send messages with automatic state management and error handling.

## Key Components

**Main Hook:**
- `useMingoDialog()` - Primary hook that manages dialog lifecycle and messaging

**State Management:**
- `currentDialogId` - Tracks the active dialog session
- `dialogIdRef` - Persistent reference to dialog ID across renders
- Loading states for dialog creation and message sending

**Core Operations:**
- `createDialog()` - Creates new admin-type dialog with ADMIN agent
- `sendMessage()` - Sends messages to existing or new dialogs
- `resetDialog()` - Clears current dialog state and resets mutations

**API Integration:**
- Uses TanStack Query for server state management
- Integrates with chat API endpoints (`/chat/api/v1/dialogs`, `/chat/api/v1/messages`)
- Automatic query invalidation for dialog lists

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function ChatInterface() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    sendMessage,
    resetDialog,
    hasDialog
  } = useMingoDialog()

  const handleSendMessage = async (content: string) => {
    const success = await sendMessage(content)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleNewChat = () => {
    resetDialog()
  }

  return (
    <div>
      {hasDialog && <p>Dialog ID: {currentDialogId}</p>}
      <button 
        onClick={() => handleSendMessage("Hello Mingo!")}
        disabled={isSendingMessage}
      >
        {isSendingMessage ? 'Sending...' : 'Send Message'}
      </button>
      <button onClick={handleNewChat}>New Chat</button>
    </div>
  )
}
```

The hook automatically handles dialog creation when sending messages to non-existent dialogs, includes comprehensive error handling with toast notifications, and maintains dialog state persistence across component re-renders.
