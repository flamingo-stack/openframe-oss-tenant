A React hook that manages Mingo AI dialog interactions, providing functionality for creating chat dialogs and sending messages to the Mingo AI assistant with automatic error handling and state management.

## Key Components

**Main Hook:**
- `useMingoDialog()` - Primary hook that manages dialog lifecycle and messaging

**State Management:**
- `currentDialogId` - Tracks the active dialog ID
- `dialogIdRef` - Persistent reference to dialog ID
- Loading states for dialog creation and message sending

**API Operations:**
- `createDialog()` - Creates a new admin-type dialog with Mingo AI
- `sendMessage()` - Sends messages to an existing or new dialog
- `resetDialog()` - Clears dialog state and resets mutations

**TypeScript Interfaces:**
- `CreateDialogResponse` - API response structure for dialog creation
- `CreateDialogRequest` - Request payload for creating dialogs
- `SendMessageRequest` - Request payload for sending messages

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function ChatComponent() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    sendMessage,
    resetDialog,
    hasDialog
  } = useMingoDialog()

  const handleSendMessage = async (message: string) => {
    const success = await sendMessage(message)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleNewChat = () => {
    resetDialog() // Clear current dialog to start fresh
  }

  return (
    <div>
      <p>Dialog ID: {currentDialogId || 'No active dialog'}</p>
      <button 
        onClick={() => handleSendMessage('Hello Mingo!')}
        disabled={isSendingMessage}
      >
        {isSendingMessage ? 'Sending...' : 'Send Message'}
      </button>
      <button onClick={handleNewChat}>New Chat</button>
    </div>
  )
}
```

The hook automatically creates a new dialog if one doesn't exist when sending a message, handles API errors with toast notifications, and maintains React Query cache invalidation for optimal data synchronization.
