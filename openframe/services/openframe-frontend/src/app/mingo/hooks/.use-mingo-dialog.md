A React hook that manages Mingo AI dialog creation and message sending functionality, providing a streamlined interface for chat interactions with the ADMIN agent type.

## Key Components

### Main Hook: `useMingoDialog`
- **Dialog Management**: Creates and tracks active dialog sessions
- **Message Handling**: Sends messages to existing or new dialogs  
- **State Management**: Manages dialog ID state with both useState and useRef for persistence
- **Error Handling**: Provides user-friendly error messages via toast notifications
- **Loading States**: Tracks pending operations for UI feedback

### Core Functions
- **`createDialog()`**: Creates a new ADMIN agent dialog session
- **`sendMessage(content, dialogId?)`**: Sends messages with automatic dialog creation if needed
- **`resetDialog()`**: Clears current dialog state and resets mutations
- **`getActiveDialogId()`**: Resolves the active dialog ID from multiple sources

### API Interfaces
- **`CreateDialogResponse`**: Dialog creation response structure
- **`SendMessageRequest`**: Message sending payload format

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function ChatComponent() {
  const { 
    sendMessage, 
    createDialog, 
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    hasDialog,
    resetDialog 
  } = useMingoDialog()

  const handleSendMessage = async (message: string) => {
    const success = await sendMessage(message)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const startNewChat = async () => {
    const dialogId = await createDialog()
    if (dialogId) {
      console.log(`New dialog created: ${dialogId}`)
    }
  }

  return (
    <div>
      <button 
        onClick={startNewChat} 
        disabled={isCreatingDialog}
      >
        {isCreatingDialog ? 'Creating...' : 'New Chat'}
      </button>
      
      <button 
        onClick={() => handleSendMessage('Hello Mingo!')}
        disabled={isSendingMessage}
      >
        Send Message
      </button>
      
      {hasDialog && (
        <p>Active Dialog: {currentDialogId}</p>
      )}
    </div>
  )
}
```
