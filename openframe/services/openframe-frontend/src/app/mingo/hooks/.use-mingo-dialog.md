A React hook for managing Mingo AI chat dialogs, providing functionality to create new chat sessions and send messages to the Mingo AI assistant.

## Key Components

- **useMingoDialog()** - Main hook that manages chat dialog state and operations
- **createDialog()** - Creates a new admin-type chat dialog with Mingo AI
- **sendMessage()** - Sends messages to an existing or new dialog
- **resetDialog()** - Clears current dialog state and resets mutations
- **State management** - Tracks current dialog ID, loading states, and errors

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function ChatInterface() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    createDialog,
    sendMessage,
    resetDialog,
    hasDialog
  } = useMingoDialog()

  const handleSendMessage = async (message: string) => {
    const success = await sendMessage(message)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleNewChat = async () => {
    const dialogId = await createDialog()
    if (dialogId) {
      console.log('New dialog created:', dialogId)
    }
  }

  return (
    <div>
      <button onClick={handleNewChat} disabled={isCreatingDialog}>
        {hasDialog ? 'New Chat' : 'Start Chat'}
      </button>
      <button 
        onClick={() => handleSendMessage('Hello Mingo!')}
        disabled={isSendingMessage}
      >
        Send Message
      </button>
    </div>
  )
}
```

The hook automatically handles dialog creation when sending messages to non-existent dialogs, manages loading states, displays error toasts, and invalidates relevant queries for real-time updates.
