A React hook for managing Mingo AI dialog creation and messaging operations with automatic dialog management and error handling.

## Key Components

**Main Hook**: `useMingoDialog()` - Primary hook export providing dialog management functionality

**Core Functions**:
- `createDialog()` - Creates new admin dialog and returns dialog ID
- `sendMessage(content, dialogId?)` - Sends message to dialog, auto-creates if needed
- `resetDialog()` - Clears current dialog state and resets mutations

**State Management**:
- `currentDialogId` - Active dialog identifier
- `isCreatingDialog` - Loading state for dialog creation
- `isSendingMessage` - Loading state for message sending
- `hasDialog` - Boolean indicating if dialog exists

**Internal Helpers**:
- `getActiveDialogId()` - Resolves dialog ID from multiple sources
- Mutation handlers for API operations with toast notifications

## Usage Example

```typescript
import { useMingoDialog } from '@/hooks/use-mingo-dialog'

function ChatComponent() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    createDialog,
    sendMessage,
    resetDialog,
    hasDialog
  } = useMingoDialog()

  const handleSendMessage = async (message: string) => {
    const success = await sendMessage(message)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleNewChat = async () => {
    resetDialog()
    await createDialog()
  }

  return (
    <div>
      <button onClick={handleNewChat} disabled={isCreatingDialog}>
        New Chat
      </button>
      <button 
        onClick={() => handleSendMessage("Hello Mingo!")}
        disabled={isSendingMessage}
      >
        Send Message
      </button>
      {hasDialog && <p>Active Dialog: {currentDialogId}</p>}
    </div>
  )
}
```

The hook automatically handles dialog creation when sending messages to non-existent dialogs, provides loading states, and shows error toasts for failed operations. It integrates with TanStack Query for caching and the Flamingo toast system for user feedback.
