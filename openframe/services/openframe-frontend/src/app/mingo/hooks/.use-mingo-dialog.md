A React hook for managing Mingo AI assistant dialog creation and message sending within the OpenFrame platform. Provides a streamlined interface for creating admin-type chat dialogs and sending messages with proper error handling and state management.

## Key Components

- **useMingoDialog()** - Main hook that returns dialog management functions and state
- **createDialog()** - Creates a new admin-type dialog and returns the dialog ID
- **sendMessage()** - Sends a message to an active dialog, creating one if none exists
- **resetDialog()** - Clears current dialog state and resets mutations
- **State tracking** - Manages current dialog ID with both state and ref for reliability

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function MingoChat() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    sendMessage,
    resetDialog,
    hasDialog
  } = useMingoDialog()

  const handleSendMessage = async () => {
    const success = await sendMessage("Help me troubleshoot this issue")
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleNewChat = () => {
    resetDialog()
  }

  return (
    <div>
      <p>Dialog ID: {currentDialogId}</p>
      <p>Has Dialog: {hasDialog}</p>
      <button 
        onClick={handleSendMessage}
        disabled={isSendingMessage}
      >
        Send Message
      </button>
      <button onClick={handleNewChat}>
        New Chat
      </button>
    </div>
  )
}
```
