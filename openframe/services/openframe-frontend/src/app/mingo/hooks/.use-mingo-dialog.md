A React hook for managing Mingo AI chat dialogs, providing functionality to create new admin chat sessions and send messages with automatic dialog creation and error handling.

## Key Components

- **useMingoDialog()** - Main hook that manages chat dialog state and operations
- **createDialog()** - Creates a new admin chat dialog and returns the dialog ID
- **sendMessage()** - Sends a message to a dialog, automatically creating one if needed
- **resetDialog()** - Clears current dialog state and resets mutations
- **State Management** - Tracks current dialog ID, loading states, and errors using React Query mutations

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function ChatComponent() {
  const { 
    currentDialogId, 
    isCreatingDialog, 
    isSendingMessage, 
    sendMessage, 
    createDialog,
    resetDialog,
    hasDialog 
  } = useMingoDialog()

  const handleSendMessage = async (content: string) => {
    const success = await sendMessage(content)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleNewChat = async () => {
    const dialogId = await createDialog()
    if (dialogId) {
      console.log('New dialog created:', dialogId)
    }
  }

  return (
    <div>
      <p>Dialog ID: {currentDialogId}</p>
      <button 
        onClick={handleNewChat} 
        disabled={isCreatingDialog}
      >
        New Chat
      </button>
      <button 
        onClick={() => handleSendMessage('Hello Mingo!')} 
        disabled={isSendingMessage}
      >
        Send Message
      </button>
    </div>
  )
}
```

The hook automatically handles dialog creation when sending messages to non-existent dialogs, provides toast notifications for errors, and manages React Query cache invalidation for dialog lists.
