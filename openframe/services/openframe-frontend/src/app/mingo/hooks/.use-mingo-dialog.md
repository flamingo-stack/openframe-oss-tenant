A React hook that manages Mingo AI dialog creation and message sending with automatic error handling and state management.

## Key Components

- **useMingoDialog()** - Main hook providing dialog management functionality
- **createDialogMutation** - TanStack Query mutation for creating new admin dialogs
- **sendMessageMutation** - TanStack Query mutation for sending messages to dialogs
- **createDialog()** - Creates a new dialog and returns the dialog ID
- **sendMessage()** - Sends a message to the active or specified dialog
- **resetDialog()** - Clears current dialog state and resets mutations

## Usage Example

```typescript
import { useMingoDialog } from './hooks/use-mingo-dialog'

function ChatInterface() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    createDialog,
    sendMessage,
    resetDialog,
    hasDialog
  } = useMingoDialog()

  const handleSendMessage = async (content: string) => {
    const success = await sendMessage(content)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleNewChat = () => {
    resetDialog()
    createDialog()
  }

  return (
    <div>
      <button 
        onClick={handleNewChat}
        disabled={isCreatingDialog}
      >
        {hasDialog ? 'New Chat' : 'Start Chat'}
      </button>
      <input
        onKeyPress={(e) => {
          if (e.key === 'Enter') {
            handleSendMessage(e.currentTarget.value)
          }
        }}
        disabled={isSendingMessage}
      />
    </div>
  )
}
```

The hook automatically handles dialog creation when sending the first message, manages loading states, displays error toasts, and maintains query cache invalidation for real-time updates.
