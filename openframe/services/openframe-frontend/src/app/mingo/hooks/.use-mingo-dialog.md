A React hook that manages Mingo AI dialog creation and message sending within the Flamingo platform, providing state management for chat interactions between users and the AI assistant.

## Key Components

- **useMingoDialog()** - Main hook that returns dialog management functions and state
- **createDialog()** - Creates a new admin-type dialog with the Mingo AI agent
- **sendMessage()** - Sends messages to an existing dialog, auto-creating one if needed
- **resetDialog()** - Clears current dialog state and resets mutations
- **State Management** - Tracks current dialog ID, loading states, and errors using React Query

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function ChatComponent() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    createDialog,
    sendMessage,
    resetDialog,
    hasDialog
  } = useMingoDialog()

  const handleSendMessage = async (message: string) => {
    const success = await sendMessage(message)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleNewChat = async () => {
    resetDialog()
    const dialogId = await createDialog()
    console.log('New dialog created:', dialogId)
  }

  return (
    <div>
      <button onClick={handleNewChat} disabled={isCreatingDialog}>
        {hasDialog ? 'New Chat' : 'Start Chat'}
      </button>
      <input 
        onKeyPress={(e) => {
          if (e.key === 'Enter') handleSendMessage(e.target.value)
        }}
        disabled={isSendingMessage}
      />
    </div>
  )
}
```

The hook automatically handles error states with toast notifications and manages dialog lifecycle through React Query for optimal caching and synchronization.
