A React hook that manages Mingo AI chat dialogs, providing functionality to create new dialogs and send messages with automatic error handling and state management.

## Key Components

- **useMingoDialog()** - Main hook that returns dialog management functions and state
- **createDialog()** - Creates a new admin-type dialog and returns the dialog ID
- **sendMessage()** - Sends a message to a dialog, creating one if needed
- **resetDialog()** - Clears current dialog state and resets mutations
- **State Management** - Tracks current dialog ID, loading states, and errors

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function ChatComponent() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    createDialog,
    sendMessage,
    resetDialog,
    hasDialog
  } = useMingoDialog()

  const handleSendMessage = async (message: string) => {
    const success = await sendMessage(message)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleNewChat = async () => {
    resetDialog()
    const dialogId = await createDialog()
    console.log('New dialog created:', dialogId)
  }

  return (
    <div>
      <p>Dialog ID: {currentDialogId}</p>
      <p>Has Dialog: {hasDialog ? 'Yes' : 'No'}</p>
      <p>Creating: {isCreatingDialog ? 'Yes' : 'No'}</p>
      <p>Sending: {isSendingMessage ? 'Yes' : 'No'}</p>
      
      <button onClick={handleNewChat}>New Chat</button>
      <button onClick={() => handleSendMessage('Hello Mingo!')}>
        Send Message
      </button>
    </div>
  )
}
```

The hook automatically handles dialog creation when sending messages, provides loading states for UI feedback, and includes comprehensive error handling with toast notifications.
