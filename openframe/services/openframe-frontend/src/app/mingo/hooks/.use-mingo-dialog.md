A React hook for managing Mingo AI dialog creation and message sending, with automatic dialog creation when needed and comprehensive error handling.

## Key Components

### Main Hook Function
- **`useMingoDialog()`** - Primary hook that manages dialog state and provides dialog operations

### Core Operations
- **`createDialog()`** - Creates a new admin dialog with Mingo AI
- **`sendMessage(content, dialogId?)`** - Sends a message to an existing or new dialog
- **`resetDialog()`** - Clears current dialog state and resets mutations
- **`getActiveDialogId()`** - Resolves the active dialog ID from various sources

### State Properties
- **`currentDialogId`** - Currently active dialog identifier
- **`isCreatingDialog`** - Loading state for dialog creation
- **`isSendingMessage`** - Loading state for message sending
- **`hasDialog`** - Boolean indicating if a dialog exists
- **`error`** - Any errors from dialog or message operations

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function ChatComponent() {
  const { 
    sendMessage, 
    isCreatingDialog, 
    isSendingMessage, 
    hasDialog,
    resetDialog 
  } = useMingoDialog()

  const handleSendMessage = async (content: string) => {
    const success = await sendMessage(content)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const startNewChat = () => {
    resetDialog()
  }

  return (
    <div>
      <button onClick={() => handleSendMessage('Hello Mingo!')}>
        {isSendingMessage ? 'Sending...' : 'Send Message'}
      </button>
      {hasDialog && (
        <button onClick={startNewChat}>New Chat</button>
      )}
    </div>
  )
}
```

The hook automatically creates a dialog when sending the first message and handles all error states with toast notifications.
