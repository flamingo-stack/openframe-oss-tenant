A React hook for managing Mingo AI chat dialogs, providing functionality to create new conversations with the AI assistant and send messages within those dialogs.

## Key Components

- **useMingoDialog()**: Main hook that manages dialog state and provides dialog operations
- **createDialogMutation**: TanStack Query mutation for creating new ADMIN-type dialogs 
- **sendMessageMutation**: TanStack Query mutation for sending messages to existing dialogs
- **Dialog State Management**: Tracks current dialog ID using both state and ref for persistence
- **Error Handling**: Comprehensive error handling with toast notifications for user feedback

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function ChatInterface() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    sendMessage,
    createDialog,
    resetDialog,
    hasDialog
  } = useMingoDialog()

  const handleSendMessage = async (message: string) => {
    const success = await sendMessage(message)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleNewChat = async () => {
    resetDialog() // Clear current dialog
    const dialogId = await createDialog()
    if (dialogId) {
      console.log(`New dialog created: ${dialogId}`)
    }
  }

  return (
    <div>
      <p>Current Dialog: {currentDialogId || 'None'}</p>
      <button onClick={handleNewChat} disabled={isCreatingDialog}>
        {isCreatingDialog ? 'Creating...' : 'New Chat'}
      </button>
      <button 
        onClick={() => handleSendMessage('Hello Mingo!')}
        disabled={isSendingMessage}
      >
        {isSendingMessage ? 'Sending...' : 'Send Message'}
      </button>
    </div>
  )
}
```

The hook automatically creates a dialog if one doesn't exist when sending a message, and provides loading states and error handling for all operations.
