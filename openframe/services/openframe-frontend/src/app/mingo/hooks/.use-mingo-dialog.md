A React hook that manages Mingo (AI technician assistant) chat dialog creation and message sending with automatic dialog management and error handling.

## Key Components

- **useMingoDialog**: Main hook that provides dialog management functionality
- **createDialog**: Creates a new admin-type chat dialog and returns the dialog ID
- **sendMessage**: Sends a message to a specific or current dialog, creating one if needed
- **resetDialog**: Clears current dialog state and resets mutations
- **State Management**: Tracks current dialog ID using both state and ref for persistence

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function ChatComponent() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    sendMessage,
    createDialog,
    resetDialog,
    hasDialog
  } = useMingoDialog()

  const handleSendMessage = async () => {
    const success = await sendMessage("Hello Mingo, I need help with server issues")
    if (success) {
      console.log("Message sent successfully")
    }
  }

  const handleNewChat = async () => {
    await resetDialog()
    const dialogId = await createDialog()
    console.log("New dialog created:", dialogId)
  }

  return (
    <div>
      <p>Current Dialog: {currentDialogId || "None"}</p>
      <button 
        onClick={handleSendMessage}
        disabled={isSendingMessage}
      >
        Send Message
      </button>
      <button onClick={handleNewChat}>
        New Chat
      </button>
    </div>
  )
}
```

The hook automatically handles dialog creation when sending messages, provides loading states, displays error toasts, and maintains dialog state across component renders using both React state and refs for reliability.
