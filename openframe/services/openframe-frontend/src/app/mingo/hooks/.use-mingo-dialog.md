A React hook that manages Mingo AI dialog creation and message sending functionality, providing a complete interface for chat operations with error handling and state management.

## Key Components

- **useMingoDialog()** - Main hook that returns dialog management functions and state
- **createDialogMutation** - TanStack Query mutation for creating new AI dialogs
- **sendMessageMutation** - TanStack Query mutation for sending messages to dialogs
- **createDialog()** - Creates a new dialog and returns the dialog ID
- **sendMessage()** - Sends a message to an existing or new dialog
- **resetDialog()** - Clears current dialog state and resets mutations

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function ChatComponent() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    createDialog,
    sendMessage,
    resetDialog,
    hasDialog
  } = useMingoDialog()

  const handleSendMessage = async (message: string) => {
    const success = await sendMessage(message)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleNewChat = async () => {
    resetDialog()
    const dialogId = await createDialog()
    if (dialogId) {
      console.log(`New dialog created: ${dialogId}`)
    }
  }

  return (
    <div>
      {hasDialog && <p>Current Dialog: {currentDialogId}</p>}
      <button 
        onClick={handleNewChat} 
        disabled={isCreatingDialog}
      >
        {isCreatingDialog ? 'Creating...' : 'New Chat'}
      </button>
      <button 
        onClick={() => handleSendMessage('Hello Mingo!')}
        disabled={isSendingMessage}
      >
        {isSendingMessage ? 'Sending...' : 'Send Message'}
      </button>
    </div>
  )
}
```
