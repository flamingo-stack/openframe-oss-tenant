Custom React hook for managing Mingo AI chat dialog interactions, providing state management for creating dialogs and sending messages with the admin agent type.

## Key Components

- **useMingoDialog()** - Main hook that manages dialog lifecycle and message sending
- **createDialogMutation** - TanStack Query mutation for creating new admin chat dialogs
- **sendMessageMutation** - TanStack Query mutation for sending messages to existing dialogs
- **createDialog()** - Creates a new dialog and returns the dialog ID
- **sendMessage()** - Sends a message to a dialog (creates one if needed)
- **resetDialog()** - Clears current dialog state and resets mutations

## Usage Example

```typescript
import { useMingoDialog } from '@/hooks/use-mingo-dialog'

export function ChatInterface() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    createDialog,
    sendMessage,
    resetDialog,
    hasDialog
  } = useMingoDialog()

  const handleSendMessage = async (content: string) => {
    const success = await sendMessage(content)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleNewChat = async () => {
    resetDialog() // Clear current dialog
    const dialogId = await createDialog()
    console.log('Created new dialog:', dialogId)
  }

  return (
    <div>
      <p>Current Dialog: {currentDialogId || 'None'}</p>
      <p>Loading: {isCreatingDialog || isSendingMessage}</p>
      <button onClick={handleNewChat}>New Chat</button>
    </div>
  )
}
```

The hook automatically handles error states with toast notifications and maintains dialog state using both React state and refs for persistence across re-renders.
