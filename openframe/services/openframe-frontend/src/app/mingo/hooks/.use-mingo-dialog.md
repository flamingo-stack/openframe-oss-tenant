A React hook that manages Mingo AI chat dialogs, providing functionality to create new dialogs and send messages with automatic error handling and state management.

## Key Components

- **`useMingoDialog`** - Main hook that orchestrates dialog creation and message sending
- **`CreateDialogResponse`** - TypeScript interface for dialog creation API response
- **`CreateDialogRequest`** - Request payload for creating new dialogs
- **`SendMessageRequest`** - Request payload for sending messages to dialogs
- **State Management** - Tracks current dialog ID using both state and ref for reliability
- **Mutations** - TanStack Query mutations for API operations with error handling

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function ChatComponent() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    createDialog,
    sendMessage,
    resetDialog,
    hasDialog
  } = useMingoDialog()

  const handleSendMessage = async (message: string) => {
    const success = await sendMessage(message)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleNewChat = async () => {
    resetDialog() // Clear current dialog
    const dialogId = await createDialog()
    if (dialogId) {
      console.log('New dialog created:', dialogId)
    }
  }

  return (
    <div>
      <button onClick={handleNewChat} disabled={isCreatingDialog}>
        {hasDialog ? 'New Chat' : 'Start Chat'}
      </button>
      <input 
        onKeyPress={(e) => {
          if (e.key === 'Enter') {
            handleSendMessage(e.currentTarget.value)
          }
        }}
        disabled={isSendingMessage}
      />
    </div>
  )
}
```

The hook automatically handles dialog creation when sending the first message, provides loading states, and displays user-friendly error toasts for failed operations.
