Custom React hook for managing Mingo AI assistant dialog interactions, providing functionality to create chat dialogs and send messages with automatic error handling and state management.

## Key Components

- **useMingoDialog** - Main hook that manages dialog state and provides methods for chat operations
- **createDialog** - Creates a new admin-type dialog and returns the dialog ID
- **sendMessage** - Sends messages to existing dialogs with automatic dialog creation fallback
- **resetDialog** - Clears current dialog state and resets mutations
- **State Management** - Tracks current dialog ID, loading states, and errors

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function ChatInterface() {
  const { 
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    sendMessage,
    createDialog,
    resetDialog,
    hasDialog,
    error
  } = useMingoDialog()

  const handleSendMessage = async (content: string) => {
    const success = await sendMessage(content)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleStartNewChat = async () => {
    const dialogId = await createDialog()
    if (dialogId) {
      console.log('New dialog created:', dialogId)
    }
  }

  return (
    <div>
      {hasDialog ? (
        <p>Active dialog: {currentDialogId}</p>
      ) : (
        <button onClick={handleStartNewChat}>Start Chat</button>
      )}
      
      {(isCreatingDialog || isSendingMessage) && <p>Loading...</p>}
      {error && <p>Error: {error.message}</p>}
    </div>
  )
}
```

The hook automatically handles dialog creation when sending messages to non-existent dialogs, provides comprehensive error handling with toast notifications, and maintains dialog state across component re-renders using both state and refs for persistence.
