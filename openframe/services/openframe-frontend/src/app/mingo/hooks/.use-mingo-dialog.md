React hook for managing Mingo AI dialog creation and messaging functionality within the Flamingo platform. It handles dialog lifecycle, message sending with automatic dialog creation, and error management.

## Key Components

**Main Hook**: `useMingoDialog()` - Returns dialog state and management functions
- `currentDialogId` - Active dialog identifier
- `isCreatingDialog/isSendingMessage` - Loading states
- `createDialog()` - Creates new admin chat dialog
- `sendMessage()` - Sends message with auto-dialog creation
- `resetDialog()` - Clears current dialog state
- `hasDialog` - Boolean indicating if dialog exists

**Internal Mutations**:
- `createDialogMutation` - TanStack Query mutation for dialog creation
- `sendMessageMutation` - TanStack Query mutation for message sending

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function ChatInterface() {
  const { 
    currentDialogId, 
    isCreatingDialog, 
    isSendingMessage, 
    sendMessage, 
    createDialog,
    resetDialog 
  } = useMingoDialog()

  const handleSendMessage = async (content: string) => {
    const success = await sendMessage(content)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const startNewChat = async () => {
    const dialogId = await createDialog()
    if (dialogId) {
      console.log('New dialog created:', dialogId)
    }
  }

  return (
    <div>
      <p>Current Dialog: {currentDialogId || 'None'}</p>
      <button onClick={startNewChat} disabled={isCreatingDialog}>
        New Chat
      </button>
      <button onClick={() => handleSendMessage('Hello Mingo!')} disabled={isSendingMessage}>
        Send Message
      </button>
      <button onClick={resetDialog}>Reset</button>
    </div>
  )
}
```

The hook automatically creates dialogs when sending messages if none exists, includes comprehensive error handling with toast notifications, and integrates with TanStack Query for caching and invalidation.
