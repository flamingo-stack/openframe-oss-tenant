A React hook for managing Mingo AI admin chat dialogs, providing functionality to create new conversations and send messages through the chat API.

## Key Components

- **State Management**: Tracks current dialog ID using both state and ref for persistence
- **Dialog Creation**: `createDialogMutation` - Creates new admin-type chat dialogs
- **Message Sending**: `sendMessageMutation` - Sends messages to existing dialogs with validation
- **Auto-Creation**: Automatically creates a dialog if none exists when sending messages
- **Error Handling**: Displays toast notifications for API failures and validation errors
- **Query Invalidation**: Updates cached dialog data after successful operations

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function ChatComponent() {
  const { 
    currentDialogId, 
    isCreatingDialog, 
    isSendingMessage, 
    sendMessage, 
    resetDialog,
    hasDialog 
  } = useMingoDialog()

  const handleSendMessage = async () => {
    const success = await sendMessage("Help me troubleshoot this issue")
    if (success) {
      console.log("Message sent successfully")
    }
  }

  const handleNewChat = () => {
    resetDialog()
  }

  return (
    <div>
      <p>Current Dialog: {currentDialogId || 'None'}</p>
      <button 
        onClick={handleSendMessage} 
        disabled={isSendingMessage}
      >
        Send Message
      </button>
      <button onClick={handleNewChat}>New Chat</button>
    </div>
  )
}
```

The hook automatically handles dialog creation, message validation, error states, and maintains dialog persistence across component re-renders.
