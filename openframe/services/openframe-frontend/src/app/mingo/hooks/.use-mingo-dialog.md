A React hook that manages dialog creation and messaging interactions with the Mingo AI assistant, handling state management, API calls, and error handling for chat functionality.

## Key Components

- **`useMingoDialog`** - Main hook that provides dialog management functionality
- **`CreateDialogResponse`** - Interface defining the structure of dialog creation API responses
- **`CreateDialogRequest/SendMessageRequest`** - Interfaces for API request payloads
- **State Management** - Tracks current dialog ID using both state and ref for persistence
- **API Mutations** - Handles dialog creation and message sending with React Query
- **Error Handling** - Provides toast notifications and error recovery

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function ChatComponent() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    sendMessage,
    createDialog,
    resetDialog,
    hasDialog
  } = useMingoDialog()

  const handleSendMessage = async (content: string) => {
    const success = await sendMessage(content)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleNewChat = async () => {
    resetDialog()
    const dialogId = await createDialog()
    console.log('New dialog created:', dialogId)
  }

  return (
    <div>
      <button onClick={handleNewChat} disabled={isCreatingDialog}>
        {hasDialog ? 'New Chat' : 'Start Chat'}
      </button>
      <button 
        onClick={() => handleSendMessage('Hello Mingo!')} 
        disabled={isSendingMessage}
      >
        Send Message
      </button>
    </div>
  )
}
```

The hook automatically handles dialog creation when needed, provides loading states, and manages error scenarios with user-friendly toast notifications.
