A React hook that manages Mingo AI dialog creation and message sending functionality for the Flamingo platform's admin chat interface.

## Key Components

**Main Hook: `useMingoDialog`**
- `createDialog()` - Creates a new admin-type dialog with Mingo AI
- `sendMessage(content, dialogId?)` - Sends messages to active or specified dialog
- `resetDialog()` - Clears current dialog state and resets mutations
- `currentDialogId` - Currently active dialog identifier
- Loading states: `isCreatingDialog`, `isSendingMessage`
- Error handling with toast notifications

**Interfaces:**
- `CreateDialogResponse` - Dialog creation API response structure
- `CreateDialogRequest` - Dialog creation payload (admin agent type)
- `SendMessageRequest` - Message sending payload with chat type

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function ChatInterface() {
  const { 
    sendMessage, 
    createDialog, 
    currentDialogId, 
    isCreatingDialog, 
    isSendingMessage 
  } = useMingoDialog()

  const handleSendMessage = async () => {
    const success = await sendMessage("Help me troubleshoot this issue")
    if (success) {
      console.log("Message sent successfully")
    }
  }

  const handleNewChat = async () => {
    const dialogId = await createDialog()
    if (dialogId) {
      console.log("New dialog created:", dialogId)
    }
  }

  return (
    <div>
      <button onClick={handleNewChat} disabled={isCreatingDialog}>
        New Chat
      </button>
      <button onClick={handleSendMessage} disabled={isSendingMessage}>
        Send Message
      </button>
      {currentDialogId && <p>Active Dialog: {currentDialogId}</p>}
    </div>
  )
}
```
