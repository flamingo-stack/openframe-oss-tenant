A custom React hook that manages Mingo AI chat dialog creation and message sending functionality with automatic dialog creation and comprehensive error handling.

## Key Components

- **useMingoDialog()** - Main hook export that provides dialog management functionality
- **createDialogMutation** - TanStack Query mutation for creating new chat dialogs with ADMIN agent type
- **sendMessageMutation** - TanStack Query mutation for sending messages to existing dialogs
- **createDialog()** - Function to create a new dialog and return its ID
- **sendMessage()** - Function to send messages with automatic dialog creation if needed
- **resetDialog()** - Function to clear current dialog state and reset mutations

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function ChatInterface() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    sendMessage,
    createDialog,
    resetDialog,
    hasDialog
  } = useMingoDialog()

  const handleSendMessage = async () => {
    const success = await sendMessage("Hello Mingo AI!")
    if (success) {
      console.log("Message sent successfully")
    }
  }

  const handleNewChat = async () => {
    resetDialog()
    const dialogId = await createDialog()
    if (dialogId) {
      console.log("New dialog created:", dialogId)
    }
  }

  return (
    <div>
      <button onClick={handleSendMessage} disabled={isSendingMessage}>
        Send Message
      </button>
      <button onClick={handleNewChat} disabled={isCreatingDialog}>
        New Chat
      </button>
    </div>
  )
}
```

The hook automatically handles dialog creation when sending messages to non-existent dialogs and provides comprehensive loading states and error handling through toast notifications.
