A custom React hook that manages Mingo AI chat dialog creation and messaging functionality, handling both dialog lifecycle and message sending with error handling and state management.

## Key Components

- **useMingoDialog()** - Main hook that provides dialog management functionality
- **createDialogMutation** - TanStack Query mutation for creating new admin chat dialogs
- **sendMessageMutation** - TanStack Query mutation for sending messages to existing dialogs
- **createDialog()** - Async function to create a new dialog and return its ID
- **sendMessage()** - Async function to send messages with automatic dialog creation
- **resetDialog()** - Function to clear current dialog state and reset mutations

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function ChatInterface() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    sendMessage,
    createDialog,
    resetDialog,
    hasDialog
  } = useMingoDialog()

  const handleSendMessage = async (message: string) => {
    const success = await sendMessage(message)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleNewChat = async () => {
    resetDialog()
    const newDialogId = await createDialog()
    console.log('New dialog created:', newDialogId)
  }

  return (
    <div>
      {hasDialog && <p>Current Dialog: {currentDialogId}</p>}
      {isCreatingDialog && <p>Creating new dialog...</p>}
      {isSendingMessage && <p>Sending message...</p>}
    </div>
  )
}
```

The hook automatically handles dialog creation when sending messages to non-existent dialogs, provides loading states, and includes comprehensive error handling with toast notifications.
