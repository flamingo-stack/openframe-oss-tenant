A React hook that manages Mingo AI chat dialog creation and message sending with error handling and state management.

## Key Components

- **useMingoDialog hook**: Main hook that provides dialog management functionality
- **createDialogMutation**: TanStack Query mutation for creating new ADMIN agent dialogs
- **sendMessageMutation**: TanStack Query mutation for sending messages to dialogs
- **Dialog state management**: Tracks current dialog ID using both state and ref for reliability
- **Error handling**: Comprehensive error handling with toast notifications for user feedback

## Key Features

- **Automatic dialog creation**: Creates a new dialog if one doesn't exist when sending a message
- **State persistence**: Uses both `useState` and `useRef` to maintain dialog ID across renders
- **Message validation**: Validates message content before sending (non-empty, trimmed)
- **Loading states**: Provides loading indicators for dialog creation and message sending
- **Error recovery**: Includes reset functionality to clear state and mutations
- **Query invalidation**: Automatically refreshes dialog lists after creation

## Usage Example

```typescript
import { useMingoDialog } from './hooks/use-mingo-dialog'

function ChatComponent() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    sendMessage,
    resetDialog,
    hasDialog
  } = useMingoDialog()

  const handleSendMessage = async (content: string) => {
    const success = await sendMessage(content)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleNewChat = () => {
    resetDialog() // Clear current dialog to start fresh
  }

  return (
    <div>
      <p>Dialog ID: {currentDialogId || 'No active dialog'}</p>
      <p>Status: {isCreatingDialog ? 'Creating...' : isSendingMessage ? 'Sending...' : 'Ready'}</p>
      <button onClick={() => handleSendMessage('Hello Mingo!')} disabled={isSendingMessage}>
        Send Message
      </button>
      <button onClick={handleNewChat}>New Chat</button>
    </div>
  )
}
```
