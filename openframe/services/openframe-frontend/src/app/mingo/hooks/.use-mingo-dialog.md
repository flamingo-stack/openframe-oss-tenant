A React hook for managing Mingo AI dialog interactions, providing functionality to create dialogs with the ADMIN agent type and send messages within those conversations.

## Key Components

- **useMingoDialog()** - Main hook that manages dialog state and operations
- **createDialog()** - Creates a new dialog with ADMIN agent type
- **sendMessage()** - Sends messages to existing or new dialogs with automatic dialog creation
- **resetDialog()** - Clears current dialog state and resets mutations
- **State management** - Tracks current dialog ID using both state and ref for persistence
- **Error handling** - Displays toast notifications for creation and messaging failures

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function MingoChat() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    createDialog,
    sendMessage,
    resetDialog,
    hasDialog
  } = useMingoDialog()

  const handleSendMessage = async (content: string) => {
    const success = await sendMessage(content)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleStartNewChat = async () => {
    resetDialog()
    const dialogId = await createDialog()
    if (dialogId) {
      console.log('New dialog created:', dialogId)
    }
  }

  return (
    <div>
      {hasDialog && <p>Active Dialog: {currentDialogId}</p>}
      <button 
        onClick={handleStartNewChat} 
        disabled={isCreatingDialog}
      >
        {isCreatingDialog ? 'Creating...' : 'New Chat'}
      </button>
      <button 
        onClick={() => handleSendMessage('Hello Mingo!')}
        disabled={isSendingMessage}
      >
        {isSendingMessage ? 'Sending...' : 'Send Message'}
      </button>
    </div>
  )
}
```
