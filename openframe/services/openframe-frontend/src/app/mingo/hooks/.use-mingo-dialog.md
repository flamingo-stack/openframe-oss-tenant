A React hook that manages Mingo AI dialog creation and messaging functionality, providing a clean interface for chat operations with automatic dialog management and error handling.

## Key Components

- **useMingoDialog** - Main hook that encapsulates dialog state and operations
- **createDialogMutation** - TanStack Query mutation for creating new admin chat dialogs
- **sendMessageMutation** - TanStack Query mutation for sending messages to existing dialogs
- **Dialog Management** - Automatic dialog ID tracking with ref-based persistence
- **Error Handling** - Comprehensive error handling with toast notifications

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function MingoChat() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    sendMessage,
    createDialog,
    resetDialog,
    hasDialog
  } = useMingoDialog()

  const handleSendMessage = async (message: string) => {
    const success = await sendMessage(message)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleNewChat = async () => {
    await resetDialog()
    const newDialogId = await createDialog()
    console.log('New dialog created:', newDialogId)
  }

  return (
    <div>
      <p>Dialog ID: {currentDialogId}</p>
      <p>Has Dialog: {hasDialog}</p>
      <button 
        onClick={() => handleSendMessage('Hello Mingo!')}
        disabled={isSendingMessage}
      >
        Send Message
      </button>
    </div>
  )
}
```

The hook automatically creates dialogs when needed, manages loading states, and provides comprehensive error handling through toast notifications and React Query integration.
