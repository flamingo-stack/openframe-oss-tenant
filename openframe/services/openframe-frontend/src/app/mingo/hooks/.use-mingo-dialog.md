A React hook for managing Mingo AI assistant dialog sessions, providing functionality to create chat dialogs and send messages through the chat API.

## Key Components

- **State Management**: Tracks current dialog ID using both state and ref for persistence
- **Mutations**: Two TanStack Query mutations for creating dialogs and sending messages
- **Dialog Creation**: `createDialogMutation` handles ADMIN-type dialog initialization
- **Message Sending**: `sendMessageMutation` posts messages to existing dialogs
- **Error Handling**: Toast notifications for creation and sending failures
- **Auto-creation**: Automatically creates dialogs when sending messages without an active session

## Main Exports

- **currentDialogId**: The active dialog session identifier
- **createDialog()**: Creates a new ADMIN chat dialog
- **sendMessage(content, dialogId?)**: Sends message to specified or current dialog
- **resetDialog()**: Clears current session and resets mutation state
- **Loading states**: `isCreatingDialog`, `isSendingMessage`
- **hasDialog**: Boolean indicating if an active dialog exists

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function ChatInterface() {
  const { 
    sendMessage, 
    createDialog, 
    currentDialogId, 
    isSendingMessage,
    hasDialog 
  } = useMingoDialog()

  const handleSendMessage = async (content: string) => {
    const success = await sendMessage(content)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const startNewChat = async () => {
    const dialogId = await createDialog()
    if (dialogId) {
      console.log('New chat created:', dialogId)
    }
  }

  return (
    <div>
      {hasDialog && <p>Active chat: {currentDialogId}</p>}
      <button onClick={startNewChat}>New Chat</button>
      <button 
        onClick={() => handleSendMessage('Hello Mingo')}
        disabled={isSendingMessage}
      >
        Send Message
      </button>
    </div>
  )
}
```

The hook automatically handles dialog creation when sending messages without an active session, making it simple to implement chat interfaces with the Mingo AI assistant.
