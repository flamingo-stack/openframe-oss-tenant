A React hook that manages Mingo AI chat dialog operations including creating new dialogs and sending messages with automatic error handling and state management.

## Key Components

- **useMingoDialog()** - Main hook that provides dialog management functionality
- **createDialogMutation** - TanStack Query mutation for creating new chat dialogs with ADMIN agent type
- **sendMessageMutation** - TanStack Query mutation for sending messages to existing dialogs
- **State Management** - Tracks current dialog ID using both state and ref for persistence
- **Error Handling** - Automatic toast notifications for failed operations
- **Query Invalidation** - Refreshes dialog lists after successful operations

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function ChatComponent() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    createDialog,
    sendMessage,
    resetDialog,
    hasDialog
  } = useMingoDialog()

  const handleSendMessage = async () => {
    const success = await sendMessage("Hello Mingo AI!")
    if (success) {
      console.log("Message sent successfully")
    }
  }

  const handleNewChat = async () => {
    const dialogId = await createDialog()
    if (dialogId) {
      console.log(`Created dialog: ${dialogId}`)
    }
  }

  return (
    <div>
      {hasDialog ? (
        <button onClick={handleSendMessage} disabled={isSendingMessage}>
          Send Message
        </button>
      ) : (
        <button onClick={handleNewChat} disabled={isCreatingDialog}>
          Start New Chat
        </button>
      )}
      <button onClick={resetDialog}>Reset Chat</button>
    </div>
  )
}
```

The hook automatically creates a dialog if one doesn't exist when sending a message, and provides loading states and error handling for all operations.
