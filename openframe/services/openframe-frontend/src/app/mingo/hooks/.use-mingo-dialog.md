A React hook for managing Mingo AI chat dialog operations, including creating new dialogs and sending messages with automatic error handling and state management.

## Key Components

- **useMingoDialog**: Main hook that provides dialog management functionality
- **createDialogMutation**: TanStack Query mutation for creating new ADMIN-type dialogs
- **sendMessageMutation**: TanStack Query mutation for sending messages to existing dialogs
- **Dialog State Management**: Tracks current dialog ID using both state and ref for persistence
- **Error Handling**: Comprehensive error handling with toast notifications for user feedback

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function ChatInterface() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    createDialog,
    sendMessage,
    resetDialog,
    hasDialog
  } = useMingoDialog()

  const handleSendMessage = async (message: string) => {
    const success = await sendMessage(message)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleNewChat = async () => {
    const dialogId = await createDialog()
    if (dialogId) {
      console.log(`New dialog created: ${dialogId}`)
    }
  }

  return (
    <div>
      <button 
        onClick={handleNewChat} 
        disabled={isCreatingDialog}
      >
        {hasDialog ? 'New Chat' : 'Start Chat'}
      </button>
      <input 
        onKeyDown={(e) => {
          if (e.key === 'Enter') {
            handleSendMessage(e.currentTarget.value)
            e.currentTarget.value = ''
          }
        }}
        disabled={isSendingMessage}
        placeholder="Type your message..."
      />
    </div>
  )
}
```

The hook automatically handles dialog creation when sending messages if no dialog exists, provides loading states for UI feedback, and includes comprehensive error handling with toast notifications.
