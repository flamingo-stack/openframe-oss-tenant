A React hook that manages dialog creation and messaging functionality for Mingo AI chat interactions, providing a unified interface for chat operations with error handling and loading states.

## Key Components

- **useMingoDialog()** - Main hook that returns dialog management functions and state
- **createDialogMutation** - TanStack Query mutation for creating new chat dialogs
- **sendMessageMutation** - TanStack Query mutation for sending messages to dialogs
- **createDialog()** - Function to create a new dialog and return its ID
- **sendMessage()** - Function to send a message, creating a dialog if needed
- **resetDialog()** - Function to clear current dialog state

## Usage Example

```typescript
import { useMingoDialog } from './hooks/use-mingo-dialog'

function ChatInterface() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    sendMessage,
    resetDialog,
    hasDialog
  } = useMingoDialog()

  const handleSendMessage = async () => {
    const success = await sendMessage("Hello, I need help with my tickets")
    
    if (success) {
      console.log('Message sent successfully')
    }
  }

  return (
    <div>
      {hasDialog && <p>Active Dialog: {currentDialogId}</p>}
      <button 
        onClick={handleSendMessage}
        disabled={isSendingMessage}
      >
        {isCreatingDialog ? 'Creating Chat...' : 'Send Message'}
      </button>
      <button onClick={resetDialog}>Reset Chat</button>
    </div>
  )
}
```

The hook automatically handles dialog creation when sending the first message, includes comprehensive error handling with toast notifications, and maintains dialog state using both React state and refs for persistence.
