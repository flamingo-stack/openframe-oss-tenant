A custom React hook for managing chat dialogs with Mingo AI, providing functionality to create new dialogs, send messages, and handle dialog state with automatic error handling and toast notifications.

## Key Components

- **`useMingoDialog`** - Main hook that manages dialog lifecycle and messaging
- **`CreateDialogResponse`** - Interface for dialog creation API response
- **`CreateDialogRequest`** - Interface for dialog creation request payload
- **`SendMessageRequest`** - Interface for message sending request payload

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function ChatComponent() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    createDialog,
    sendMessage,
    resetDialog,
    hasDialog
  } = useMingoDialog()

  const handleSendMessage = async () => {
    const success = await sendMessage("Hello Mingo!")
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleNewChat = async () => {
    const dialogId = await createDialog()
    if (dialogId) {
      console.log('New dialog created:', dialogId)
    }
  }

  return (
    <div>
      <button 
        onClick={handleNewChat}
        disabled={isCreatingDialog}
      >
        {isCreatingDialog ? 'Creating...' : 'New Chat'}
      </button>
      
      <button 
        onClick={handleSendMessage}
        disabled={isSendingMessage || !hasDialog}
      >
        {isSendingMessage ? 'Sending...' : 'Send Message'}
      </button>

      <button onClick={resetDialog}>Reset Dialog</button>
    </div>
  )
}
```

The hook automatically handles dialog creation when sending messages to non-existent dialogs, provides loading states, and displays error notifications via toast messages. It maintains dialog state both in React state and refs for persistence across re-renders.
