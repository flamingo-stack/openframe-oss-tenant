A React hook that manages Mingo AI chat dialog creation and message sending functionality with automatic dialog management and error handling.

## Key Components

- **useMingoDialog()** - Main hook that provides dialog management functionality
- **createDialog()** - Creates a new ADMIN-type chat dialog and returns the dialog ID
- **sendMessage()** - Sends messages to existing dialogs or creates new ones automatically
- **resetDialog()** - Clears current dialog state and resets mutations
- **State Management** - Tracks current dialog ID using both useState and useRef for persistence
- **Error Handling** - Displays toast notifications for creation and sending failures

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function ChatComponent() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    hasDialog,
    createDialog,
    sendMessage,
    resetDialog
  } = useMingoDialog()

  const handleSendMessage = async (message: string) => {
    const success = await sendMessage(message)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleNewChat = async () => {
    resetDialog()
    const dialogId = await createDialog()
    console.log('New dialog created:', dialogId)
  }

  return (
    <div>
      <button onClick={handleNewChat} disabled={isCreatingDialog}>
        New Chat
      </button>
      <input 
        onKeyPress={(e) => {
          if (e.key === 'Enter') {
            handleSendMessage(e.currentTarget.value)
          }
        }}
        disabled={isSendingMessage}
      />
      {hasDialog && <p>Active dialog: {currentDialogId}</p>}
    </div>
  )
}
```
