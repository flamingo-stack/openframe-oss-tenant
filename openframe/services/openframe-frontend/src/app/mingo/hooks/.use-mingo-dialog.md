A React hook that manages Mingo AI chat dialog creation and messaging functionality, handling API communication and state management for admin chat interactions.

## Key Components

- **useMingoDialog**: Main hook providing dialog management functionality
- **createDialog**: Creates new admin chat dialogs with error handling
- **sendMessage**: Sends messages to existing or newly created dialogs
- **resetDialog**: Resets dialog state and clears mutations
- **State Management**: Tracks current dialog ID using both state and ref for persistence

## Usage Example

```typescript
import { useMingoDialog } from '@/hooks/use-mingo-dialog'

function ChatComponent() {
  const { 
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    createDialog,
    sendMessage,
    resetDialog,
    hasDialog
  } = useMingoDialog()

  const handleSendMessage = async () => {
    const success = await sendMessage("Hello Mingo AI")
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleNewChat = async () => {
    const dialogId = await createDialog()
    if (dialogId) {
      console.log('New dialog created:', dialogId)
    }
  }

  return (
    <div>
      {hasDialog && <p>Active Dialog: {currentDialogId}</p>}
      <button onClick={handleSendMessage} disabled={isSendingMessage}>
        Send Message
      </button>
      <button onClick={handleNewChat} disabled={isCreatingDialog}>
        New Chat
      </button>
      <button onClick={resetDialog}>Reset</button>
    </div>
  )
}
```

The hook automatically handles dialog creation if none exists when sending messages, includes comprehensive error handling with toast notifications, and maintains dialog state across component re-renders using both useState and useRef.
