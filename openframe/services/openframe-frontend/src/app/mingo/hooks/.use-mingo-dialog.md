A React hook for managing Mingo AI chat dialogs, providing functionality to create new conversations and send messages with automatic error handling and state management.

## Key Components

- **`useMingoDialog`** - Main hook that manages dialog state and provides dialog operations
- **`createDialog`** - Creates a new admin-type dialog and returns the dialog ID
- **`sendMessage`** - Sends a message to an existing dialog or creates one if needed
- **`resetDialog`** - Clears current dialog state and resets mutations
- **Dialog State Management** - Tracks current dialog ID using both state and ref for persistence

## Usage Example

```typescript
import { useMingoDialog } from './use-mingo-dialog'

function ChatComponent() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    sendMessage,
    createDialog,
    resetDialog,
    hasDialog
  } = useMingoDialog()

  const handleSendMessage = async (content: string) => {
    const success = await sendMessage(content)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleNewChat = async () => {
    resetDialog() // Clear current dialog
    const dialogId = await createDialog()
    console.log('New dialog created:', dialogId)
  }

  return (
    <div>
      <button onClick={handleNewChat} disabled={isCreatingDialog}>
        {isCreatingDialog ? 'Creating...' : 'New Chat'}
      </button>
      <button 
        onClick={() => handleSendMessage('Hello Mingo')}
        disabled={isSendingMessage}
      >
        {isSendingMessage ? 'Sending...' : 'Send Message'}
      </button>
      {hasDialog && <p>Active dialog: {currentDialogId}</p>}
    </div>
  )
}
```

The hook automatically handles dialog creation when sending messages, provides loading states, and shows toast notifications for errors.
