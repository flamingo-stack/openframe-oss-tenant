A React hook for managing Mingo AI dialog creation and messaging functionality within the Flamingo MSP platform. This hook provides state management and API integration for creating admin dialogs and sending messages through the chat system.

## Key Components

**State Management:**
- `currentDialogId` - Tracks the active dialog session
- `dialogIdRef` - Reference for dialog ID persistence
- Loading states for dialog creation and message sending

**Core Functions:**
- `createDialog()` - Creates new admin dialog sessions
- `sendMessage()` - Sends messages to existing or new dialogs
- `resetDialog()` - Clears current dialog state
- `getActiveDialogId()` - Resolves the active dialog ID

**Mutations:**
- `createDialogMutation` - TanStack Query mutation for dialog creation
- `sendMessageMutation` - TanStack Query mutation for message sending

## Usage Example

```typescript
import { useMingoDialog } from './hooks/use-mingo-dialog'

function ChatInterface() {
  const { 
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    sendMessage,
    createDialog,
    resetDialog,
    hasDialog
  } = useMingoDialog()

  const handleSendMessage = async (content: string) => {
    const success = await sendMessage(content)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const startNewChat = async () => {
    const dialogId = await createDialog()
    if (dialogId) {
      console.log('New dialog created:', dialogId)
    }
  }

  return (
    <div>
      {hasDialog ? (
        <p>Active dialog: {currentDialogId}</p>
      ) : (
        <button onClick={startNewChat} disabled={isCreatingDialog}>
          Start Chat
        </button>
      )}
      
      <button 
        onClick={() => handleSendMessage('Hello Mingo!')}
        disabled={isSendingMessage}
      >
        Send Message
      </button>
      
      <button onClick={resetDialog}>Reset Chat</button>
    </div>
  )
}
```

The hook automatically handles error states with toast notifications, query cache invalidation, and provides boolean return values for success/failure handling in components.
