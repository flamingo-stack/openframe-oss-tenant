Custom React hook for managing Mingo AI chat dialogs with automated dialog creation and message sending capabilities.

## Key Components

- **useMingoDialog()** - Main hook providing dialog management functionality
- **createDialog()** - Creates a new admin chat dialog with Mingo AI
- **sendMessage()** - Sends messages to existing or newly created dialogs
- **resetDialog()** - Clears dialog state and resets mutations
- **State Management** - Tracks current dialog ID, loading states, and errors

## Usage Example

```typescript
import { useMingoDialog } from './hooks/use-mingo-dialog'

function ChatInterface() {
  const {
    currentDialogId,
    isCreatingDialog,
    isSendingMessage,
    sendMessage,
    resetDialog,
    hasDialog,
    error
  } = useMingoDialog()

  const handleSendMessage = async (content: string) => {
    const success = await sendMessage(content)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleNewChat = () => {
    resetDialog()
  }

  return (
    <div>
      <div>Dialog ID: {currentDialogId || 'No active dialog'}</div>
      <button 
        onClick={() => handleSendMessage('Hello Mingo')}
        disabled={isSendingMessage}
      >
        Send Message
      </button>
      <button onClick={handleNewChat}>
        New Chat
      </button>
      {error && <div>Error: {error.message}</div>}
    </div>
  )
}
```

The hook automatically creates dialogs when needed, handles API errors with toast notifications, and maintains dialog state across component re-renders using both state and refs for persistence.
