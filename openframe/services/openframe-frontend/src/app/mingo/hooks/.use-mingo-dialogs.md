A React hook that fetches and manages Mingo AI assistant dialogs with infinite scrolling and unread message tracking.

## Key Components

- **`useMingoDialogs`** - Main hook for fetching paginated dialogs with search and filtering
- **`transformToDialogItem`** - Helper function converting DialogNode to DialogItem with unread counts
- **Query Configuration** - TanStack Query setup with automatic refetching and caching
- **Unread Integration** - Connects with MingoMessagesStore to track unread message counts

## Usage Example

```typescript
import { useMingoDialogs } from './use-mingo-dialogs'

function DialogsList() {
  const {
    dialogs,
    isLoading,
    hasNextPage,
    fetchNextPage,
    isFetchingNextPage
  } = useMingoDialogs({
    search: 'customer support',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          {dialog.unreadMessagesCount > 0 && (
            <span>({dialog.unreadMessagesCount} unread)</span>
          )}
        </div>
      ))}
      {hasNextPage && (
        <button 
          onClick={() => fetchNextPage()}
          disabled={isFetchingNextPage}
        >
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically filters for ADMIN agent types, implements 30-second stale time with 60-second refetch intervals, and combines dialog data with unread message counts from the messages store.
