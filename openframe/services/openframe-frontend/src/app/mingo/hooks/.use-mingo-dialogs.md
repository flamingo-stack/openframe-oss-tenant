A React hook that manages infinite pagination of Mingo AI dialog conversations with unread message tracking and real-time updates.

## Key Components

- **useMingoDialogs**: Main hook that fetches and manages dialog conversations with infinite scrolling
- **transformToDialogItem**: Utility function that converts raw dialog nodes to UI-compatible dialog items
- **DialogNode/DialogItem types**: TypeScript interfaces for dialog data structures
- **Integration with**: TanStack Query for caching, Mingo messages store for unread counts, and GraphQL API

## Usage Example

```typescript
import { useMingoDialogs } from './hooks/use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage 
  } = useMingoDialogs({
    search: 'urgent tickets',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
          <time>{dialog.timestamp.toLocaleDateString()}</time>
        </div>
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically refetches every 60 seconds and caches data for 30 seconds, making it ideal for real-time chat interfaces where dialog status changes frequently.
