A React hook for managing Mingo AI dialog data with infinite pagination, search capabilities, and unread message tracking. It transforms GraphQL dialog responses into UI-ready dialog items.

## Key Components

- **useMingoDialogs**: Main hook that fetches and manages dialog data
- **transformToDialogItem**: Helper function that converts DialogNode to DialogItem format
- **UseMingoDialogsOptions**: Configuration interface for search, pagination, and enabled state
- **DialogsResponse**: GraphQL response type for paginated dialog data

The hook integrates with React Query for caching and background updates, and uses the Mingo messages store for unread count tracking.

## Usage Example

```typescript
import { useMingoDialogs } from './hooks/use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage 
  } = useMingoDialogs({
    search: 'customer support',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
        </div>
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```
