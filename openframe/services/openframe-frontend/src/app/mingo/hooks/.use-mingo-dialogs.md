Custom React hook that fetches and manages Mingo AI chat dialogs with infinite scroll pagination and real-time unread message counts. Part of the Flamingo OpenFrame chat system.

## Key Components

- **`useMingoDialogs`** - Main hook that provides paginated dialogs with unread counts
- **`transformToDialogItem`** - Helper function that converts DialogNode to DialogItem format
- **Infinite Query Integration** - Uses TanStack Query for efficient data fetching and caching
- **Unread Messages Integration** - Connects with the Mingo messages store for real-time unread counts

## Usage Example

```typescript
import { useMingoDialogs } from './hooks/use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage,
    refetch 
  } = useMingoDialogs({
    search: 'customer issue',
    limit: 10
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id} className="dialog-item">
          <h3>{dialog.title}</h3>
          <span>{dialog.unreadMessagesCount} unread</span>
          <time>{dialog.timestamp.toLocaleString()}</time>
        </div>
      ))}
      
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically refreshes every 60 seconds and maintains a 30-second stale time for optimal performance. It filters for ADMIN agent types and transforms the data structure to match the OpenFrame DialogItem interface.
