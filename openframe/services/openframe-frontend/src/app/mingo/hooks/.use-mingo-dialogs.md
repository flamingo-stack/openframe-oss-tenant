A React hook for managing Mingo AI chat dialogs with infinite scrolling, search functionality, and unread message tracking through TanStack Query.

## Key Components

- **`useMingoDialogs`** - Main hook that provides infinite query for dialogs with search and pagination
- **`transformToDialogItem`** - Utility function that converts API dialog nodes to standardized DialogItem format
- **Query Configuration** - Uses TanStack Query with 30s stale time and 60s refetch interval for real-time updates
- **Unread Message Integration** - Integrates with Mingo messages store to track unread counts per dialog

## Usage Example

```typescript
import { useMingoDialogs } from './hooks/use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage,
    error 
  } = useMingoDialogs({
    search: 'support tickets',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
          <time>{dialog.timestamp.toLocaleString()}</time>
        </div>
      ))}
      
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically filters for ADMIN agent types and maintains real-time synchronization with the messages store for accurate unread counts.
