A React Query-based hook for managing Mingo AI dialogs with infinite scrolling, search, and unread message tracking. Transforms backend dialog data into UI-compatible format with real-time updates.

## Key Components

- **useMingoDialogs** - Main hook providing paginated dialog data with search and filtering
- **transformToDialogItem** - Utility function converting backend DialogNode to frontend DialogItem format
- **Infinite Query Integration** - Uses @tanstack/react-query for efficient pagination and caching
- **Unread Messages** - Integrates with Mingo messages store to track unread counts per dialog

## Usage Example

```typescript
import { useMingoDialogs } from '@hooks/use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage,
    refetch 
  } = useMingoDialogs({
    search: 'urgent',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
          <time>{dialog.timestamp.toLocaleDateString()}</time>
        </div>
      ))}
      
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically handles ADMIN agent filtering, caches data for 30 seconds, and refreshes every minute to maintain real-time dialog updates.
