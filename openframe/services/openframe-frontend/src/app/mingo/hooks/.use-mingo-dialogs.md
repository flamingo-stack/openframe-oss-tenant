A React hook that fetches and manages Mingo dialogs with infinite pagination and unread message tracking.

## Key Components

- **`useMingoDialogs`** - Main hook that fetches dialogs with infinite scroll support
- **`transformToDialogItem`** - Utility function that converts raw dialog data to standardized dialog items
- **Integration Points** - Uses TanStack Query for data fetching and Zustand store for unread counts

## Usage Example

```typescript
import { useMingoDialogs } from './hooks/use-mingo-dialogs'

function DialogsList() {
  const {
    dialogs,
    isLoading,
    hasNextPage,
    fetchNextPage,
    isFetchingNextPage
  } = useMingoDialogs({
    search: 'support',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
          <time>{dialog.timestamp.toLocaleDateString()}</time>
        </div>
      ))}
      
      {hasNextPage && (
        <button 
          onClick={() => fetchNextPage()}
          disabled={isFetchingNextPage}
        >
          {isFetchingNextPage ? 'Loading...' : 'Load More'}
        </button>
      )}
    </div>
  )
}
```

The hook automatically refreshes every 60 seconds and integrates with the Mingo messages store to track unread message counts per dialog.
