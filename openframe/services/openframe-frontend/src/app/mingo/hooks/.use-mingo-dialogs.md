A React hook for managing Mingo AI dialogs with infinite pagination, search functionality, and real-time unread message tracking. Integrates with the Mingo messages store to display accurate unread counts for each dialog.

## Key Components

- **`useMingoDialogs`** - Main hook that fetches and manages dialog data with infinite scrolling
- **`transformToDialogItem`** - Utility function that converts raw dialog nodes to UI-friendly dialog items
- **Infinite Query Integration** - Uses TanStack Query for efficient pagination and caching
- **Unread Message Tracking** - Combines dialog data with unread counts from the messages store

## Usage Example

```typescript
import { useMingoDialogs } from './use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage,
    refetch 
  } = useMingoDialogs({
    search: 'support tickets',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id} className="dialog-item">
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
          <time>{dialog.timestamp.toLocaleDateString()}</time>
        </div>
      ))}
      
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically refreshes data every 60 seconds and provides optimistic caching with a 30-second stale time for improved performance.
