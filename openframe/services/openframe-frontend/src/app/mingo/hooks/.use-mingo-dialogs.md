Custom React hook for managing Mingo AI assistant dialogs with infinite scrolling, search functionality, and real-time unread message tracking.

## Key Components

- **`useMingoDialogs`** - Main hook that fetches and manages dialog data using React Query's infinite query pattern
- **`transformToDialogItem`** - Utility function that converts raw dialog nodes into standardized `DialogItem` format
- **Integration with `useMingoMessagesStore`** - Provides unread message counts for each dialog
- **Pagination support** - Handles cursor-based pagination for loading more dialogs
- **Real-time updates** - Auto-refreshes data every 60 seconds with 30-second stale time

## Usage Example

```typescript
import { useMingoDialogs } from './hooks/use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage,
    error 
  } = useMingoDialogs({
    search: 'troubleshooting',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
          <time>{dialog.timestamp.toLocaleDateString()}</time>
        </div>
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically filters for ADMIN agent types and provides a clean interface for dialog management with built-in error handling and loading states.
