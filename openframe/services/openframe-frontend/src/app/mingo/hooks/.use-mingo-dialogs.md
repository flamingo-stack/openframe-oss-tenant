A React hook that manages infinite pagination for Mingo AI agent dialogs with real-time unread message tracking and search functionality.

## Key Components

- **`useMingoDialogs`** - Main hook that fetches and manages dialog lists with infinite scrolling
- **`transformToDialogItem`** - Utility function that converts API dialog nodes to standardized `DialogItem` format
- **Integration with `useMingoMessagesStore`** - Tracks unread message counts per dialog
- **GraphQL query execution** - Uses TanStack Query for caching and pagination

## Usage Example

```typescript
import { useMingoDialogs } from './hooks/use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage,
    refetch 
  } = useMingoDialogs({
    search: 'urgent tickets',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
          <time>{dialog.timestamp.toLocaleDateString()}</time>
        </div>
      ))}
      
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically refetches data every 60 seconds and provides built-in error handling, making it ideal for real-time chat interfaces in the Mingo AI system.
