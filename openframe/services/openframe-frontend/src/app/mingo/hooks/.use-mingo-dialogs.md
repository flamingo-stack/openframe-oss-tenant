React hook for fetching and managing Mingo AI assistant dialogs with infinite scrolling, search, and unread message tracking.

## Key Components

- **`useMingoDialogs`** - Main hook that fetches paginated dialogs using React Query's infinite query
- **`transformToDialogItem`** - Utility function that converts dialog nodes to standardized dialog items
- **Integration with `useMingoMessagesStore`** - Provides unread message counts for each dialog
- **Automatic refetching** - Configured for 60-second intervals with 30-second stale time

## Usage Example

```typescript
import { useMingoDialogs } from './hooks/use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage,
    refetch 
  } = useMingoDialogs({
    enabled: true,
    search: 'support ticket',
    limit: 10
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
          <time>{dialog.timestamp.toLocaleDateString()}</time>
        </div>
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically filters for ADMIN agent types and provides real-time unread counts through the messages store integration.
