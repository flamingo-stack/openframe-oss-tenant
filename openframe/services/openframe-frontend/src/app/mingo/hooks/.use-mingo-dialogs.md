A React Query hook for fetching and managing Mingo AI dialogs with infinite scrolling, search functionality, and real-time unread message counts.

## Key Components

- **`useMingoDialogs`** - Main hook that manages dialog fetching with infinite pagination
- **`transformToDialogItem`** - Utility function that converts dialog nodes to frontend-compatible items
- **Integration with `useMingoMessagesStore`** - Provides unread message counts for each dialog
- **GraphQL Query Execution** - Handles API requests with proper error handling and response validation

## Usage Example

```typescript
import { useMingoDialogs } from './hooks/use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage,
    refetch 
  } = useMingoDialogs({
    search: 'urgent tickets',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>{dialog.unreadMessagesCount} unread</span>
          <time>{dialog.timestamp.toLocaleDateString()}</time>
        </div>
      ))}
      
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically filters for ADMIN agent types, provides 30-second stale time caching, and refreshes data every 60 seconds. It transforms raw GraphQL responses into `DialogItem` objects compatible with the OpenFrame frontend core components.
