Custom React hook that fetches and manages Mingo AI dialog conversations with infinite scrolling and real-time unread message tracking.

## Key Components

- **`useMingoDialogs`** - Main hook that fetches paginated dialogs with search and filtering capabilities
- **`transformToDialogItem`** - Utility function that converts raw dialog data to the standardized DialogItem format
- **Infinite Query Integration** - Uses TanStack Query for efficient pagination and caching
- **Unread Message Tracking** - Integrates with Mingo messages store to display unread counts per dialog

## Usage Example

```typescript
import { useMingoDialogs } from './hooks/use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage,
    refetch 
  } = useMingoDialogs({
    search: 'customer support',
    limit: 10
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>{dialog.unreadMessagesCount} unread</span>
          <time>{dialog.timestamp.toLocaleDateString()}</time>
        </div>
      ))}
      
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically refreshes every 60 seconds and provides real-time unread message counts by integrating with the Mingo messages store.
