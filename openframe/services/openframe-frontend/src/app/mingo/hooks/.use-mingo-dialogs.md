A React Query-powered hook for fetching and managing Mingo AI dialogs with infinite scroll pagination and unread message tracking. It transforms raw dialog data into standardized `DialogItem` format for consistent UI rendering.

## Key Components

- **`useMingoDialogs`** - Main hook that fetches dialogs with infinite pagination and unread counts
- **`transformToDialogItem`** - Transforms `DialogNode` objects into standardized `DialogItem` format
- **Integration with `useMingoMessagesStore`** - Retrieves unread message counts per dialog
- **GraphQL query execution** - Uses `GET_MINGO_DIALOGS_QUERY` for data fetching

## Usage Example

```typescript
import { useMingoDialogs } from './use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage,
    isFetchingNextPage 
  } = useMingoDialogs({
    search: 'support tickets',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
          <time>{dialog.timestamp.toLocaleDateString()}</time>
        </div>
      ))}
      
      {hasNextPage && (
        <button 
          onClick={() => fetchNextPage()}
          disabled={isFetchingNextPage}
        >
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically refreshes data every 60 seconds and provides real-time unread message counts by integrating with the Mingo messages store.
