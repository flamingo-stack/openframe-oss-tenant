A React hook that manages infinite loading and display of Mingo AI dialogs with unread message tracking. It transforms GraphQL dialog data into UI-friendly format and integrates with the messages store for real-time unread counts.

## Key Components

- **`useMingoDialogs`** - Main hook for fetching paginated dialog lists with search and filtering
- **`transformToDialogItem`** - Utility function that converts API dialog data to UI dialog items
- **Infinite Query Integration** - Uses TanStack Query for efficient pagination and caching
- **Unread Message Tracking** - Integrates with Mingo messages store for unread counts

## Usage Example

```typescript
import { useMingoDialogs } from './hooks/use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage,
    refetch 
  } = useMingoDialogs({
    search: 'urgent',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
          <time>{dialog.timestamp.toLocaleString()}</time>
        </div>
      ))}
      
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically refreshes every 60 seconds and provides real-time unread message counts by combining API data with local store state.
