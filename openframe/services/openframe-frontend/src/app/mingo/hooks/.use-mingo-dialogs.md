Custom React hook for managing Mingo dialog data with infinite scroll pagination and real-time unread message counts integration.

## Key Components

- **`useMingoDialogs(options)`** - Main hook that fetches and manages dialog list data
- **`transformToDialogItem(dialog, unreadCount)`** - Helper function that converts API dialog nodes to standardized dialog items
- **Infinite Query Integration** - Uses React Query's `useInfiniteQuery` for efficient pagination
- **Unread Messages Integration** - Connects with `useMingoMessagesStore` to display unread counts

## Usage Example

```typescript
import { useMingoDialogs } from './hooks/use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage 
  } = useMingoDialogs({
    search: 'customer support',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
          <time>{dialog.timestamp.toLocaleString()}</time>
        </div>
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically refreshes data every 60 seconds and maintains a 30-second stale time for optimal performance. It filters for ADMIN agent types and transforms raw API responses into standardized `DialogItem` format with unread message counts.
