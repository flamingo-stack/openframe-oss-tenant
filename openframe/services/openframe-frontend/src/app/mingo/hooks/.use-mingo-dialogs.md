A React hook that manages Mingo AI chat dialogs with infinite scrolling, search functionality, and real-time unread message counts. Uses TanStack Query for caching and the Mingo messages store for unread state management.

## Key Components

- **useMingoDialogs**: Main hook for fetching and managing dialog data
- **transformToDialogItem**: Utility function that converts DialogNode to DialogItem format
- **Infinite Query Integration**: Implements cursor-based pagination for large dialog lists
- **Unread Message Tracking**: Integrates with message store for real-time unread counts
- **Search & Filtering**: Supports dialog search with admin agent filtering

## Usage Example

```typescript
import { useMingoDialogs } from './hooks/use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage,
    isError 
  } = useMingoDialogs({
    search: 'customer support',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>
  if (isError) return <div>Error loading dialogs</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
          <time>{dialog.timestamp.toLocaleDateString()}</time>
        </div>
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically handles caching (30s stale time), background refetching (60s intervals), and transforms raw dialog data into a consistent format with unread message counts from the messages store.
