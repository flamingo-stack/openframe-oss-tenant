Custom React hook for managing Mingo AI dialog conversations with infinite scrolling, search capabilities, and real-time unread message tracking.

## Key Components

- **`useMingoDialogs`** - Main hook that fetches and manages dialog conversations
- **`transformToDialogItem`** - Utility function that converts backend dialog nodes to frontend dialog items
- **Infinite Query Integration** - Uses `@tanstack/react-query` for efficient pagination and caching
- **Unread Message Tracking** - Integrates with Mingo messages store to display unread counts
- **Real-time Updates** - Automatic refetching every 60 seconds with 30-second stale time

## Usage Example

```typescript
import { useMingoDialogs } from './use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage 
  } = useMingoDialogs({
    search: 'customer support',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          {dialog.unreadMessagesCount > 0 && (
            <span>({dialog.unreadMessagesCount} unread)</span>
          )}
        </div>
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook filters for ADMIN agent types and provides comprehensive loading states, error handling, and pagination controls for building responsive dialog interfaces.
