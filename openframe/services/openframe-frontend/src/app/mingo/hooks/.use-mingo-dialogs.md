Custom React hook for managing Mingo AI dialogs with infinite scrolling and unread message tracking. Provides paginated dialog loading with real-time unread counts from the messages store.

## Key Components

- **`transformToDialogItem`** - Transforms raw dialog nodes into standardized DialogItem format
- **`useMingoDialogs`** - Main hook that fetches dialogs with infinite scrolling capabilities
- **GraphQL Integration** - Uses TanStack Query for efficient data fetching and caching
- **Unread Message Tracking** - Integrates with Mingo messages store for real-time unread counts

## Usage Example

```typescript
import { useMingoDialogs } from './use-mingo-dialogs'

function DialogsList() {
  const {
    dialogs,
    isLoading,
    hasNextPage,
    fetchNextPage,
    isFetchingNextPage
  } = useMingoDialogs({
    search: 'support',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
          <time>{dialog.timestamp.toLocaleString()}</time>
        </div>
      ))}
      
      {hasNextPage && (
        <button 
          onClick={() => fetchNextPage()}
          disabled={isFetchingNextPage}
        >
          {isFetchingNextPage ? 'Loading...' : 'Load More'}
        </button>
      )}
    </div>
  )
}
```

The hook automatically refreshes every 60 seconds and includes built-in error handling and loading states for seamless dialog management in the Mingo AI interface.
