Custom React hook for fetching and managing paginated Mingo AI dialogs with real-time unread message tracking and infinite scrolling capabilities.

## Key Components

- **`useMingoDialogs`** - Main hook that fetches paginated dialogs using React Query's `useInfiniteQuery`
- **`transformToDialogItem`** - Utility function that converts backend `DialogNode` objects to frontend `DialogItem` format
- **Infinite Query Configuration** - Handles pagination with cursor-based navigation and automatic refetching
- **Unread Message Integration** - Combines dialog data with unread counts from the Mingo messages store

## Usage Example

```typescript
import { useMingoDialogs } from './hooks/use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage,
    isFetchingNextPage 
  } = useMingoDialogs({
    search: 'support tickets',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
          <time>{dialog.timestamp.toLocaleString()}</time>
        </div>
      ))}
      
      {hasNextPage && (
        <button 
          onClick={() => fetchNextPage()}
          disabled={isFetchingNextPage}
        >
          {isFetchingNextPage ? 'Loading...' : 'Load More'}
        </button>
      )}
    </div>
  )
}
```

The hook automatically polls for updates every 60 seconds and filters for ADMIN agent types, providing a complete solution for displaying Mingo AI conversation dialogs.
