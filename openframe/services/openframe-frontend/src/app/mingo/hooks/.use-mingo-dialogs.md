A React hook that manages infinite loading and real-time updates for Mingo AI assistant dialogs with unread message tracking.

## Key Components

- **`useMingoDialogs`** - Main hook that fetches and manages dialog data with infinite scrolling
- **`transformToDialogItem`** - Helper function that converts raw dialog nodes to standardized dialog items
- **Infinite Query Integration** - Uses TanStack Query for efficient pagination and caching
- **Unread Message Tracking** - Integrates with Mingo messages store to show unread counts
- **Real-time Updates** - Auto-refreshes every 60 seconds with 30-second stale time

## Usage Example

```typescript
import { useMingoDialogs } from './use-mingo-dialogs'

function MingoDialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage 
  } = useMingoDialogs({
    search: 'urgent',
    limit: 50,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
          <time>{dialog.timestamp.toLocaleDateString()}</time>
        </div>
      ))}
      
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically filters for ADMIN agent types and provides optimistic caching with background refetching for a smooth user experience.
