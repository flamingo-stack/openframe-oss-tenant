A React Query hook for fetching and managing Mingo AI dialogs with infinite pagination and unread message counts.

## Key Components

**Main Hook:**
- `useMingoDialogs(options)` - Fetches dialogs with infinite scroll pagination and real-time unread counts

**Helper Functions:**
- `transformToDialogItem()` - Converts raw dialog data to standardized `DialogItem` format

**Key Features:**
- Infinite pagination with cursor-based navigation
- Search filtering support
- Automatic refetching (60s intervals)
- Integration with unread messages store
- Admin agent type filtering

## Usage Example

```typescript
import { useMingoDialogs } from './hooks/use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage,
    refetch 
  } = useMingoDialogs({
    search: 'support',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
          <time>{dialog.timestamp.toLocaleDateString()}</time>
        </div>
      ))}
      
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically combines data from multiple pages, applies unread counts from the messages store, and provides standard loading states for building responsive dialog interfaces.
