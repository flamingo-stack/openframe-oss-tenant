A custom React hook that fetches and manages Mingo AI dialogs with infinite scrolling, search functionality, and unread message tracking.

## Key Components

- **`useMingoDialogs`** - Main hook that provides dialog list management with pagination
- **`transformToDialogItem`** - Utility function that converts DialogNode to DialogItem format
- **Infinite Query Integration** - Uses TanStack Query for efficient data fetching and caching
- **Unread Message Integration** - Combines dialog data with unread counts from the messages store

## Usage Example

```typescript
import { useMingoDialogs } from './hooks/use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage,
    refetch 
  } = useMingoDialogs({
    search: 'urgent tickets',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
          <time>{dialog.timestamp.toLocaleDateString()}</time>
        </div>
      ))}
      
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically filters for ADMIN agent types, provides real-time updates every 60 seconds, and maintains a 30-second stale time for optimal performance.
