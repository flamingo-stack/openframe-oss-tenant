A React hook that manages paginated dialog data for the Mingo AI assistant, handling infinite scrolling, real-time updates, and unread message tracking through React Query and Zustand store integration.

## Key Components

- **`useMingoDialogs`** - Main hook for fetching and managing dialog lists with pagination
- **`transformToDialogItem`** - Utility function that converts API dialog nodes to frontend dialog items
- **Query Configuration** - Infinite query setup with 30s stale time and 60s refetch interval
- **Unread Integration** - Combines dialog data with unread message counts from the messages store

## Usage Example

```typescript
import { useMingoDialogs } from './use-mingo-dialogs'

function DialogList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage,
    isError 
  } = useMingoDialogs({
    search: 'support ticket',
    limit: 10
  })

  if (isLoading) return <div>Loading dialogs...</div>
  if (isError) return <div>Failed to load dialogs</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
        </div>
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically filters for ADMIN agent types and provides real-time unread counts by integrating with the Mingo messages store.
