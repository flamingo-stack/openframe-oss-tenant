A React hook that manages fetching and transforming Mingo dialog data with infinite scrolling pagination and unread message tracking. It integrates with TanStack Query for data management and the Mingo messages store for unread counts.

## Key Components

- `transformToDialogItem()` - Transforms raw dialog nodes into standardized dialog items with unread counts
- `useMingoDialogs()` - Main hook providing infinite query functionality for dialog lists
- **Options**: `enabled`, `search`, `limit` parameters for query customization
- **Returns**: Transformed dialogs array, loading states, error handling, and pagination controls

## Usage Example

```typescript
import { useMingoDialogs } from './hooks/use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage,
    isError,
    error 
  } = useMingoDialogs({
    search: 'support',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>
  if (isError) return <div>Error: {error}</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
          <time>{dialog.timestamp.toLocaleDateString()}</time>
        </div>
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically refreshes every 60 seconds and filters for ADMIN agent types, making it ideal for administrative dialog management interfaces.
