Custom React hook for fetching and managing Mingo AI chat dialogs with infinite pagination and unread message tracking.

## Key Components

- **`useMingoDialogs`** - Main hook that fetches dialogs with infinite scroll support
- **`transformToDialogItem`** - Helper function that converts DialogNode to DialogItem format
- **Infinite Query** - Uses TanStack Query for efficient data fetching and caching
- **Unread Integration** - Combines dialog data with unread message counts from store

## Usage Example

```typescript
import { useMingoDialogs } from './use-mingo-dialogs'

function DialogList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage 
  } = useMingoDialogs({
    search: 'support',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          {dialog.unreadMessagesCount > 0 && (
            <span>{dialog.unreadMessagesCount} unread</span>
          )}
        </div>
      ))}
      
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically refetches data every 60 seconds and includes built-in error handling, making it ideal for real-time chat interfaces in the Flamingo MSP platform.
