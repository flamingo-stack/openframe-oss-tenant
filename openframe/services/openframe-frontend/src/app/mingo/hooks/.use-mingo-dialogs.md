A React hook that fetches and manages Mingo AI chat dialogs with infinite scrolling pagination, search filtering, and unread message tracking.

## Key Components

- **`useMingoDialogs`** - Main hook that returns paginated dialog data with unread counts
- **`transformToDialogItem`** - Utility function that converts API dialog nodes to standardized DialogItem format
- **Infinite Query Integration** - Uses TanStack Query for efficient data fetching with cursor-based pagination
- **Unread Message Tracking** - Integrates with Mingo messages store to show unread counts per dialog

## Usage Example

```typescript
import { useMingoDialogs } from './use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage,
    refetch 
  } = useMingoDialogs({
    search: 'bug report',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
          <time>{dialog.timestamp.toLocaleDateString()}</time>
        </div>
      ))}
      
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically refetches data every 60 seconds and filters dialogs by ADMIN agent types, providing real-time updates for active conversations.
