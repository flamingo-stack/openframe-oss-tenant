A React hook for fetching and managing Mingo AI dialog conversations with infinite scrolling and unread message tracking. This hook integrates with TanStack Query for data fetching and a Zustand store for message state management.

## Key Components

- **`useMingoDialogs`** - Main hook that fetches paginated dialog data with search and filtering capabilities
- **`transformToDialogItem`** - Transforms API dialog nodes into standardized DialogItem format
- **Infinite Query** - Implements cursor-based pagination for loading dialog lists
- **Unread Integration** - Combines dialog data with unread message counts from the messages store

## Usage Example

```typescript
import { useMingoDialogs } from './hooks/use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage,
    refetch 
  } = useMingoDialogs({
    search: 'customer support',
    limit: 10,
    enabled: true
  })

  return (
    <div>
      {isLoading && <div>Loading dialogs...</div>}
      
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>{dialog.unreadMessagesCount} unread</span>
          <time>{dialog.timestamp.toLocaleString()}</time>
        </div>
      ))}
      
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically filters for ADMIN agent types, refreshes data every 60 seconds, and maintains a 30-second stale time for optimal performance.
