Custom React hook for fetching and managing Mingo AI dialog conversations with pagination, search, and real-time unread message tracking.

## Key Components

- **`useMingoDialogs`** - Main hook that fetches dialogs with infinite scroll pagination
- **`transformToDialogItem`** - Utility function that converts API dialog nodes to UI dialog items
- **Dialog State Management** - Integrates with Mingo messages store for unread counts
- **Auto-refresh Logic** - Implements 30s stale time and 60s refetch intervals

## Usage Example

```typescript
import { useMingoDialogs } from './hooks/use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage,
    refetch 
  } = useMingoDialogs({
    search: 'support',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>{dialog.unreadMessagesCount} unread</span>
          <time>{dialog.timestamp.toLocaleDateString()}</time>
        </div>
      ))}
      
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook filters for ADMIN agent types and automatically merges unread message counts from the Mingo messages store, providing a complete dialog management solution for the Mingo AI chat interface.
