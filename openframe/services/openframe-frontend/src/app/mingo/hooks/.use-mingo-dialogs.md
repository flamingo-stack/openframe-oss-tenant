A React hook for fetching and managing Mingo AI agent dialogs with infinite scrolling, search functionality, and real-time unread message counts.

## Key Components

- **`useMingoDialogs`** - Main hook that fetches dialogs with pagination and integrates unread counts
- **`transformToDialogItem`** - Utility function that converts API dialog nodes to UI-compatible dialog items
- **Infinite Query Integration** - Uses TanStack Query for efficient data fetching with automatic pagination
- **Unread Message Integration** - Combines dialog data with unread counts from the messages store

## Usage Example

```typescript
import { useMingoDialogs } from './hooks/use-mingo-dialogs'

function DialogsList() {
  const {
    dialogs,
    isLoading,
    hasNextPage,
    fetchNextPage,
    refetch
  } = useMingoDialogs({
    search: 'support tickets',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
          <time>{dialog.timestamp.toLocaleDateString()}</time>
        </div>
      ))}
      
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically refetches data every 60 seconds and maintains a 30-second stale time for optimal performance. It filters for ADMIN agent types and transforms raw dialog nodes into UI-ready items with unread message counts.
