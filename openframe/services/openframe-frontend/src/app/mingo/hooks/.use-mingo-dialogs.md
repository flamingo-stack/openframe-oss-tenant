A React hook that provides infinite scrolling functionality for fetching and managing Mingo AI chat dialogs with unread message counts and real-time updates.

## Key Components

- **`useMingoDialogs`** - Main hook that fetches paginated dialogs with search and filtering capabilities
- **`transformToDialogItem`** - Utility function that converts raw dialog data to standardized `DialogItem` format
- **Infinite Query Integration** - Uses TanStack Query for efficient data fetching with automatic pagination
- **Unread Messages** - Integrates with message store to display unread counts per dialog

## Usage Example

```typescript
import { useMingoDialogs } from './hooks/use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage,
    refetch 
  } = useMingoDialogs({
    search: 'support tickets',
    limit: 15,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
          <time>{dialog.timestamp.toLocaleDateString()}</time>
        </div>
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically refetches every 60 seconds to keep dialog lists current and provides built-in error handling and loading states for robust UI integration.
