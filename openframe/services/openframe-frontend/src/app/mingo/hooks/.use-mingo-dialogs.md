A React hook that manages Mingo AI assistant dialogs with infinite scrolling, search capabilities, and real-time unread message tracking integration.

## Key Components

- **`useMingoDialogs`** - Main hook for fetching and managing dialog data
- **`transformToDialogItem`** - Utility function that converts API dialog nodes to UI dialog items
- **Dialog Management** - Infinite query with pagination, search filtering, and automatic refetching
- **Unread Integration** - Connects with Mingo messages store to track unread counts per dialog

## Usage Example

```typescript
import { useMingoDialogs } from './use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage,
    refetch 
  } = useMingoDialogs({
    search: 'support ticket',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
          <time>{dialog.timestamp.toISOString()}</time>
        </div>
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically fetches ADMIN agent type dialogs, transforms them into UI-compatible format, and maintains real-time unread message counts through the Mingo messages store integration.
