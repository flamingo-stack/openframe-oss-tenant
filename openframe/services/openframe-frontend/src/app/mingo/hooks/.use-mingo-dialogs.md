Custom React hook for fetching and managing Mingo AI chat dialogs with infinite scrolling, search functionality, and real-time unread message tracking.

## Key Components

- **`useMingoDialogs`** - Main hook that fetches dialogs using infinite query with pagination
- **`transformToDialogItem`** - Utility function that converts API dialog nodes to frontend dialog items
- **Infinite Query Integration** - Uses TanStack Query for efficient pagination and caching
- **Unread Messages Tracking** - Integrates with Mingo messages store to display unread counts
- **Search & Filtering** - Supports dialog search and filters by ADMIN agent types

## Usage Example

```typescript
import { useMingoDialogs } from './hooks/use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage,
    refetch 
  } = useMingoDialogs({
    search: 'support',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
          <time>{dialog.timestamp.toLocaleDateString()}</time>
        </div>
      ))}
      
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically refreshes every 60 seconds and caches data for 30 seconds to balance real-time updates with performance.
