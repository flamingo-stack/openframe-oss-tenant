A React hook for fetching and managing Mingo AI dialogs with infinite scroll pagination, search filtering, and real-time unread message counts. Built on TanStack Query for efficient caching and background updates.

## Key Components

- **`useMingoDialogs`** - Main hook that provides paginated dialog data with unread counts
- **`transformToDialogItem`** - Utility function that converts API dialog nodes to UI-compatible dialog items
- **Integration with `useMingoMessagesStore`** - Combines dialog data with unread message counts from local store
- **Infinite Query Configuration** - Handles pagination with cursor-based navigation and automatic refetching

## Usage Example

```typescript
import { useMingoDialogs } from './hooks/use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage,
    refetch 
  } = useMingoDialogs({
    search: 'urgent tickets',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
          <small>{dialog.timestamp.toLocaleDateString()}</small>
        </div>
      ))}
      
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically refetches data every 60 seconds and maintains a 30-second stale time for optimal performance. It filters for ADMIN agent types and supports real-time unread count updates through the Mingo messages store.
