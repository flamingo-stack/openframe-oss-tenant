A React hook that fetches and manages Mingo dialogs with infinite scrolling, search functionality, and unread message tracking using TanStack Query.

## Key Components

- **`useMingoDialogs`** - Main hook that fetches paginated dialogs with filtering options
- **`transformToDialogItem`** - Utility function that converts `DialogNode` to `DialogItem` format with unread counts
- **Infinite Query Integration** - Uses `useInfiniteQuery` for efficient pagination and caching
- **Store Integration** - Connects with `useMingoMessagesStore` for real-time unread message counts

## Usage Example

```typescript
import { useMingoDialogs } from './hooks/use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage,
    refetch 
  } = useMingoDialogs({
    search: 'urgent',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
          <time>{dialog.timestamp.toLocaleString()}</time>
        </div>
      ))}
      
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically refreshes every 60 seconds and maintains a 30-second stale time for optimal performance while keeping data fresh.
