React hook for managing Mingo AI chat dialogs with infinite scrolling, search functionality, and real-time unread message tracking.

## Key Components

- **`useMingoDialogs`** - Main hook that fetches and manages dialog data with pagination
- **`transformToDialogItem`** - Transforms raw dialog nodes into standardized DialogItem format
- **Infinite Query Integration** - Uses React Query for efficient data fetching and caching
- **Unread Message Tracking** - Integrates with Mingo messages store to display unread counts

## Usage Example

```typescript
import { useMingoDialogs } from './use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage,
    isError 
  } = useMingoDialogs({
    search: 'troubleshooting',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>
  if (isError) return <div>Failed to load dialogs</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
          <time>{dialog.timestamp.toLocaleDateString()}</time>
        </div>
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically refreshes data every 60 seconds and maintains a 30-second stale time for optimal performance. It filters for ADMIN agent types and transforms server responses into the standardized DialogItem interface used across the OpenFrame platform.
