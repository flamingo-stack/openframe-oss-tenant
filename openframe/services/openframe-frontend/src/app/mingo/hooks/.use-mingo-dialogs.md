A React hook for managing Mingo dialogs with infinite scrolling, search functionality, and real-time unread message tracking using React Query.

## Key Components

- **`useMingoDialogs`** - Main hook that fetches and manages dialog data with pagination
- **`transformToDialogItem`** - Utility function that converts `DialogNode` objects to `DialogItem` format
- **Infinite Query Integration** - Uses `@tanstack/react-query` for efficient data fetching and caching
- **Unread Messages Store** - Integrates with `useMingoMessagesStore` for unread count tracking

## Usage Example

```typescript
import { useMingoDialogs } from './use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage,
    refetch 
  } = useMingoDialogs({
    search: 'technical support',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
          <time>{dialog.timestamp.toLocaleDateString()}</time>
        </div>
      ))}
      
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically refetches data every 60 seconds and includes a 30-second stale time for optimal performance. It filters dialogs by ADMIN agent type and provides comprehensive loading states for UI feedback.
