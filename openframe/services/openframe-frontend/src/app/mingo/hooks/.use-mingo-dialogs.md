Custom React hook for managing Mingo AI agent dialogs with infinite scrolling, search capabilities, and real-time unread message tracking.

## Key Components

- **`useMingoDialogs`**: Main hook that fetches and manages dialog data with pagination
- **`transformToDialogItem`**: Utility function that converts API dialog data to frontend-compatible format
- **Infinite Query Integration**: Uses `@tanstack/react-query` for efficient data fetching and caching
- **Unread Messages**: Integrates with Mingo messages store to track unread message counts
- **Real-time Updates**: Automatically refetches dialog data every 60 seconds

## Usage Example

```typescript
import { useMingoDialogs } from './hooks/use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage,
    refetch 
  } = useMingoDialogs({
    search: 'urgent tickets',
    limit: 10,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
          <time>{dialog.timestamp.toLocaleDateString()}</time>
        </div>
      ))}
      
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically handles pagination, caching, and integrates unread message counts from the Mingo messages store for a complete dialog management solution.
