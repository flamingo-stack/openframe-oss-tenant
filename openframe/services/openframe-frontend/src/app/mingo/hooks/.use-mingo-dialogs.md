A React hook that manages infinite pagination and real-time updates for Mingo AI assistant dialog conversations, with built-in unread message tracking and search capabilities.

## Key Components

- **`useMingoDialogs`** - Main hook providing paginated dialog fetching with infinite scroll
- **`transformToDialogItem`** - Utility function converting API response data to frontend dialog format
- **GraphQL Integration** - Uses TanStack Query for efficient data fetching and caching
- **Unread Messages** - Integrates with Mingo messages store to track unread counts per dialog

## Usage Example

```typescript
import { useMingoDialogs } from './hooks/use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage,
    refetch 
  } = useMingoDialogs({
    search: 'customer issue',
    limit: 50,
    enabled: true
  })

  if (isLoading) return <div>Loading dialogs...</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          <span>Unread: {dialog.unreadMessagesCount}</span>
          <time>{dialog.timestamp.toLocaleString()}</time>
        </div>
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```

The hook automatically refreshes every 60 seconds and filters for admin agent types, making it ideal for MSP technician interfaces where real-time dialog monitoring is essential.
