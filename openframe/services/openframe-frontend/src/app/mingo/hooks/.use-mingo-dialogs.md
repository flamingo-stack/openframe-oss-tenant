A React hook for fetching and managing Mingo AI chat dialogs with infinite scrolling, unread message tracking, and search capabilities.

## Key Components

**Main Hook:**
- `useMingoDialogs()` - Fetches paginated dialogs with search and unread counts

**Helper Functions:**
- `transformToDialogItem()` - Converts dialog nodes to UI-friendly format

**Integration:**
- Uses `@tanstack/react-query` for data fetching and caching
- Integrates with `useMingoMessagesStore` for unread message counts
- Connects to GraphQL endpoint via API client

## Features

- **Infinite Scrolling** - Automatic pagination with `useInfiniteQuery`
- **Real-time Updates** - Auto-refetch every 60 seconds
- **Search Support** - Optional dialog filtering by search terms
- **Unread Tracking** - Shows unread message counts per dialog
- **Caching** - 30-second stale time for performance
- **Error Handling** - Comprehensive error states and messages

## Usage Example

```typescript
import { useMingoDialogs } from './use-mingo-dialogs'

function DialogsList() {
  const { 
    dialogs, 
    isLoading, 
    hasNextPage, 
    fetchNextPage,
    error 
  } = useMingoDialogs({
    search: 'support',
    limit: 10
  })

  if (isLoading) return <div>Loading dialogs...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      {dialogs.map(dialog => (
        <div key={dialog.id}>
          <h3>{dialog.title}</h3>
          {dialog.unreadMessagesCount > 0 && (
            <span>({dialog.unreadMessagesCount} unread)</span>
          )}
        </div>
      ))}
      {hasNextPage && (
        <button onClick={() => fetchNextPage()}>
          Load More
        </button>
      )}
    </div>
  )
}
```
