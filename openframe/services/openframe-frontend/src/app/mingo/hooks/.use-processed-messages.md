React hook for processing and managing admin chat messages in the Flamingo Mingo AI dialog system. Handles message processing, approval workflows, and message filtering for the chat interface.

## Key Components

- **useProcessedMessages**: Main hook that processes admin messages with approval functionality
- **handleApprove**: Callback for approving pending requests with success/error handling
- **handleReject**: Callback for rejecting pending requests with toast notifications
- **processedData**: Memoized computed data containing filtered messages and pending approvals

## Usage Example

```typescript
function MingoDialog() {
  const {
    messages,
    pendingApprovals,
    assistantType,
    assistantName,
    handleApprove,
    handleReject
  } = useProcessedMessages()

  return (
    <div>
      {messages.map(message => (
        <MessageComponent
          key={message.id}
          message={message}
          assistantType={assistantType}
        />
      ))}
      
      {pendingApprovals.map(approval => (
        <ApprovalRequest
          key={approval.id}
          request={approval}
          onApprove={() => handleApprove(approval.requestId)}
          onReject={() => handleReject(approval.requestId)}
        />
      ))}
    </div>
  )
}
```

The hook automatically filters out empty assistant messages, processes historical messages with error handling, and separates pending approval requests from the main message flow for specialized UI treatment.
