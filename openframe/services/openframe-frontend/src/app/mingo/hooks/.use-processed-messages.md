A React hook for processing and managing chat messages in the Mingo AI assistant dialog, handling message filtering, approval workflows, and real-time status updates.

## Key Components

- **useProcessedMessages()** - Main hook that processes historical messages, filters by dialog ID, and manages approval states
- **handleApprove/handleReject** - Callbacks for managing approval request workflows with toast notifications
- **processedData** - Memoized computation that transforms raw admin messages into formatted chat messages
- **approvalStatuses** - State management for tracking approval request statuses
- **pendingApprovals** - Filtered collection of messages awaiting approval

## Usage Example

```typescript
import { useProcessedMessages } from './hooks/use-processed-messages'

function ChatDialog() {
  const { 
    messages, 
    pendingApprovals, 
    handleApprove, 
    handleReject,
    assistantType,
    assistantName 
  } = useProcessedMessages()

  return (
    <div>
      {messages.map(message => (
        <div key={message.id}>
          <strong>{message.name}:</strong> {message.content}
        </div>
      ))}
      
      {pendingApprovals.map(approval => (
        <div key={approval.requestId}>
          <button onClick={() => handleApprove(approval.requestId)}>
            Approve
          </button>
          <button onClick={() => handleReject(approval.requestId)}>
            Reject
          </button>
        </div>
      ))}
    </div>
  )
}
```
