A React hook that processes chat messages for the Mingo AI assistant, handling message transformation, approval workflows, and empty message filtering for admin dialogs.

## Key Components

- **useProcessedMessages()** - Main hook that processes admin messages with approval handling
- **handleApprove()** - Callback for approving pending requests with success/error handling
- **handleReject()** - Callback for rejecting pending requests with success/error handling
- **processedData** - Memoized computation that filters, processes, and formats messages
- **approvalStatuses** - State management for tracking approval request statuses

## Usage Example

```typescript
import { useProcessedMessages } from './hooks/use-processed-messages'

function MingoChat() {
  const { 
    messages, 
    pendingApprovals, 
    assistantType,
    handleApprove, 
    handleReject 
  } = useProcessedMessages()

  return (
    <div>
      {messages.map(message => (
        <ChatMessage 
          key={message.id} 
          content={message.content}
          role={message.role}
          assistantType={message.assistantType}
        />
      ))}
      
      {pendingApprovals.map(approval => (
        <ApprovalButton
          key={approval.requestId}
          onApprove={() => handleApprove(approval.requestId)}
          onReject={() => handleReject(approval.requestId)}
        />
      ))}
    </div>
  )
}
```

The hook automatically filters empty assistant messages, processes historical messages with error handling, extracts pending approval requests, and provides sorted message lists with proper timestamps and role assignments.
