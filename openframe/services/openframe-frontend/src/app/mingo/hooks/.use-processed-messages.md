A React hook that processes chat messages for the Mingo AI assistant dialog interface, handling message formatting, approval workflows, and empty message filtering.

## Key Components

- **useProcessedMessages**: Main hook that processes admin messages for display in chat interface
- **handleApprove/handleReject**: Callback functions for managing approval request workflows
- **processedData**: Memoized computation that transforms raw messages into display-ready format
- **approvalStatuses**: State management for tracking approval request statuses

## Usage Example

```typescript
import { useProcessedMessages } from './use-processed-messages'

function ChatInterface() {
  const { 
    messages, 
    pendingApprovals, 
    assistantType, 
    assistantName,
    handleApprove,
    handleReject 
  } = useProcessedMessages()

  return (
    <div>
      {messages.map(message => (
        <ChatMessage 
          key={message.id}
          content={message.content}
          role={message.role}
          assistantType={message.assistantType}
        />
      ))}
      
      {pendingApprovals.map(approval => (
        <ApprovalRequest
          key={approval.requestId}
          onApprove={() => handleApprove(approval.requestId)}
          onReject={() => handleReject(approval.requestId)}
        />
      ))}
    </div>
  )
}
```

The hook automatically filters empty assistant messages, processes approval requests, sorts messages chronologically, and provides handlers for approval workflows with error handling and toast notifications.
