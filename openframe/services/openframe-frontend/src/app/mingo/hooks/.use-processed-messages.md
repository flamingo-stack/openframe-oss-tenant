A React hook that processes and filters chat messages from Mingo (AI assistant) dialogs, handling approval workflows and message formatting for the admin interface.

## Key Components

**Main Hook:**
- `useProcessedMessages()` - Processes historical messages, manages approval states, and formats them for display

**Message Processing:**
- Filters messages by current dialog ID
- Separates empty assistant messages from completed ones
- Converts raw messages to standardized format with error handling
- Sorts messages chronologically by timestamp

**Approval Management:**
- `handleApprove()` - Approves pending requests with success/error callbacks
- `handleReject()` - Rejects pending requests with toast notifications
- Tracks approval statuses in local state

**Data Transformation:**
- Extracts pending approval segments from processed messages
- Formats messages with role, content, and assistant type information
- Combines processed and empty messages into unified timeline

## Usage Example

```typescript
import { useProcessedMessages } from './use-processed-messages'

function ChatInterface() {
  const { 
    messages, 
    pendingApprovals, 
    assistantName,
    handleApprove, 
    handleReject 
  } = useProcessedMessages()

  return (
    <div>
      {messages.map(message => (
        <div key={message.id} className={`message-${message.role}`}>
          <span>{message.name}: </span>
          {Array.isArray(message.content) ? 
            <MessageSegments content={message.content} /> :
            <span>{message.content}</span>
          }
        </div>
      ))}
      
      {pendingApprovals.length > 0 && (
        <div className="pending-approvals">
          {pendingApprovals.map(approval => (
            <button 
              key={approval.requestId}
              onClick={() => handleApprove(approval.requestId)}
            >
              Approve Request
            </button>
          ))}
        </div>
      )}
    </div>
  )
}
```
