A React hook that processes and manages chat messages from Mingo AI dialogs, handling message filtering, approval workflows, and real-time status updates.

## Key Components

- **`useProcessedMessages`** - Main hook that processes historical messages and manages approval states
- **Message Processing** - Filters messages by dialog ID, removes empty assistant messages, and formats for display
- **Approval Management** - Handles approve/reject actions with optimistic updates and error handling
- **State Management** - Tracks approval statuses and integrates with Mingo dialog store
- **Pending Approvals** - Extracts and manages approval request segments separately from regular messages

## Usage Example

```typescript
import { useProcessedMessages } from './hooks/use-processed-messages'

function ChatInterface() {
  const { 
    messages, 
    pendingApprovals, 
    handleApprove, 
    handleReject,
    assistantType,
    assistantName 
  } = useProcessedMessages()

  return (
    <div>
      {/* Render processed messages */}
      {messages.map(message => (
        <MessageComponent 
          key={message.id} 
          content={message.content}
          role={message.role}
          timestamp={message.timestamp}
        />
      ))}
      
      {/* Handle pending approvals */}
      {pendingApprovals.map(approval => (
        <ApprovalRequest
          key={approval.requestId}
          onApprove={() => handleApprove(approval.requestId)}
          onReject={() => handleReject(approval.requestId)}
        />
      ))}
    </div>
  )
}
```

The hook automatically filters messages for the current dialog, processes approval workflows, and provides sorted messages with proper role assignments and timestamps for chat UI rendering.
