Custom React hook that manages dialog selection, message loading, and approval workflows for Mingo AI assistant conversations.

## Key Components

- **Dialog Selection**: Handles switching between different Mingo dialog conversations
- **Message Loading**: Implements infinite scroll pagination for dialog messages using GraphQL queries
- **Approval Workflow**: Manages approval/rejection of Mingo requests with real-time status updates
- **State Management**: Integrates with Zustand store for persistent dialog and message state
- **Error Handling**: Provides comprehensive error handling with toast notifications

## Usage Example

```typescript
import { useMingoDialogSelection } from './use-mingo-dialog-selection'

function MingoDialogInterface() {
  const {
    selectDialog,
    isSelectingDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    dialogError,
    refetchMessages
  } = useMingoDialogSelection()

  const handleDialogSelect = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const handleRequestApproval = (requestId: string) => {
    handleApprove(requestId)
  }

  return (
    <div>
      {isLoadingMessages && <div>Loading messages...</div>}
      {dialogError && <div>Error: {dialogError}</div>}
      
      <button onClick={() => handleRequestApproval('req_123')}>
        Approve Request
      </button>
      
      <div>
        Status: {approvalStatuses['req_123'] || 'PENDING'}
      </div>
    </div>
  )
}
```

The hook automatically handles message pagination, converts GraphQL responses to the core message format, and maintains approval states across dialog switches. It uses React Query for efficient data fetching and caching.
