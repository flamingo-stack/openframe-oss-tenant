A React hook that manages dialog selection and message fetching for the Mingo AI chat interface, handling real-time message synchronization and pagination.

## Key Components

- **useMingoDialogSelection**: Main hook that orchestrates dialog selection and message loading
- **dialogQuery**: TanStack Query for fetching dialog metadata
- **messagesQuery**: Infinite query for paginated message loading with automatic pagination
- **selectDialogMutation**: Mutation for switching between dialogs with proper state cleanup
- **Message Synchronization**: Merges background messages with fetched messages, handling typing indicators and real-time updates

## Usage Example

```typescript
import { useMingoDialogSelection } from './hooks/use-mingo-dialog-selection'

function MingoChat() {
  const {
    selectDialog,
    isSelectingDialog,
    isLoadingDialog,
    isLoadingMessages,
    dialogError,
    messagesError,
    rawMessagesCount,
    refetchDialog
  } = useMingoDialogSelection()

  const handleDialogSelect = (dialogId: string) => {
    selectDialog(dialogId)
  }

  if (isLoadingDialog) {
    return <div>Loading dialog...</div>
  }

  return (
    <div>
      <button onClick={() => handleDialogSelect('dialog-123')}>
        Select Dialog
      </button>
      {isLoadingMessages && <div>Loading messages...</div>}
      {dialogError && <div>Error: {dialogError}</div>}
      <div>Messages loaded: {rawMessagesCount}</div>
    </div>
  )
}
```

The hook automatically handles message deduplication, real-time updates from background processes, and maintains chronological message ordering while filtering for admin-type messages only.
