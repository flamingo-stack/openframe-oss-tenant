A React hook that manages Mingo dialog selection, message loading, and approval workflows. It provides functionality for selecting dialogs, fetching messages with infinite scrolling, and handling real-time approval/rejection of requests within dialog contexts.

## Key Components

- **useMingoDialogSelection**: Main hook that orchestrates dialog selection and message management
- **Dialog Query**: Fetches individual dialog data using React Query
- **Messages Query**: Implements infinite scrolling for dialog messages with GraphQL pagination
- **Approval Mutations**: Handles approve/reject operations with optimistic updates
- **Message Processing**: Converts GraphQL messages to historical message format for UI rendering
- **State Management**: Integrates with Mingo messages store for centralized state

## Usage Example

```typescript
import { useMingoDialogSelection } from './hooks/use-mingo-dialog-selection'

function MingoDialogInterface() {
  const {
    selectDialog,
    isSelectingDialog,
    isLoadingDialog,
    isLoadingMessages,
    rawMessagesCount,
    dialogError,
    messagesError,
    handleApprove,
    handleReject,
    approvalStatuses,
    refetchDialog,
    refetchMessages
  } = useMingoDialogSelection()

  const handleDialogClick = async (dialogId: string) => {
    try {
      await selectDialog(dialogId)
    } catch (error) {
      console.error('Failed to select dialog:', error)
    }
  }

  const handleApproveRequest = (requestId: string) => {
    handleApprove(requestId)
  }

  return (
    <div>
      {isLoadingDialog && <div>Loading dialog...</div>}
      {isLoadingMessages && <div>Loading messages...</div>}
      {dialogError && <div>Error: {dialogError}</div>}
      
      <div>Messages loaded: {rawMessagesCount}</div>
      
      <button 
        onClick={() => handleDialogClick('dialog-123')}
        disabled={isSelectingDialog}
      >
        Select Dialog
      </button>
    </div>
  )
}
```

The hook automatically handles message pagination, approval status synchronization, and provides error handling with toast notifications for approval operations.
