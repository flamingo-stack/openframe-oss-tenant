A React hook for managing Mingo AI assistant dialog selection, message loading, and approval workflow interactions with real-time state management.

## Key Components

- **`useMingoDialogSelection`** - Main hook providing dialog selection and message management
- **Dialog Query** - Fetches single dialog details using React Query
- **Messages Query** - Infinite query for paginated dialog messages with auto-loading
- **Approval Mutations** - Handles approve/reject operations for AI requests
- **State Management** - Integrates with Zustand store for persistent UI state
- **Message Processing** - Converts GraphQL responses to core message format

## Usage Example

```typescript
import { useMingoDialogSelection } from './hooks/use-mingo-dialog-selection'

function MingoChat() {
  const {
    selectDialog,
    isSelectingDialog,
    isLoadingMessages,
    rawMessagesCount,
    handleApprove,
    handleReject,
    approvalStatuses,
    dialogError,
    refetchMessages
  } = useMingoDialogSelection()

  const handleDialogClick = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const handleApproveRequest = (requestId: string) => {
    handleApprove(requestId)
  }

  return (
    <div>
      {isLoadingMessages && <LoadingSpinner />}
      {dialogError && <ErrorMessage error={dialogError} />}
      <MessageList 
        onApprove={handleApproveRequest}
        onReject={handleReject}
        approvalStatuses={approvalStatuses}
      />
      <div>Messages loaded: {rawMessagesCount}</div>
    </div>
  )
}
```

The hook automatically handles infinite scrolling for message history, maintains approval states across dialog switches, and provides real-time approval/rejection capabilities with toast notifications for user feedback.
