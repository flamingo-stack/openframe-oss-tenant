React hook for managing dialog selection, message loading, and approval workflows in the Mingo AI assistant interface. Handles fetching dialog data, loading message history with infinite scrolling, and processing approval/rejection requests.

## Key Components

- **Dialog Management**: Fetches and caches dialog details using React Query
- **Message Loading**: Infinite scrolling with pagination for message history
- **Approval System**: Handles approve/reject mutations with optimistic updates
- **State Synchronization**: Coordinates between React Query cache and Zustand store
- **Error Handling**: Toast notifications for failed operations

## Usage Example

```typescript
import { useMingoDialogSelection } from './hooks/use-mingo-dialog-selection'

function MingoDialogInterface() {
  const {
    selectDialog,
    isLoadingDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    rawMessagesCount,
    dialogError
  } = useMingoDialogSelection()

  const handleDialogClick = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const handleApprovalClick = (requestId: string) => {
    handleApprove(requestId)
  }

  return (
    <div>
      {isLoadingDialog && <DialogSkeleton />}
      {isLoadingMessages && <MessagesSkeleton />}
      {dialogError && <ErrorDisplay error={dialogError} />}
      <MessageCount count={rawMessagesCount} />
    </div>
  )
}
```

The hook automatically loads all available message pages and converts GraphQL responses to the standardized `HistoricalMessage` format used by the frontend core library. Approval statuses are tracked both locally and synchronized with the global store for real-time UI updates.
