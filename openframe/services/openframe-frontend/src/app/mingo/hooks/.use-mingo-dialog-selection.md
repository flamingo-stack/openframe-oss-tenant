A React hook that manages dialog selection, message loading, and approval workflows for the Mingo AI assistant interface, providing real-time chat functionality with infinite scrolling and state management.

## Key Components

- **Dialog Management**: Handles active dialog selection with optimistic UI updates
- **Message Loading**: Implements infinite scrolling with GraphQL queries and pagination
- **Approval System**: Manages request approval/rejection with real-time status updates
- **State Integration**: Connects with Zustand store for centralized message state
- **Error Handling**: Provides comprehensive error states and toast notifications

## Usage Example

```typescript
import { useMingoDialogSelection } from './use-mingo-dialog-selection'

function MingoChat() {
  const {
    selectDialog,
    isSelectingDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    dialogError,
    refetchMessages
  } = useMingoDialogSelection()

  const handleDialogClick = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const handleApprovalAction = (requestId: string, approved: boolean) => {
    if (approved) {
      handleApprove(requestId)
    } else {
      handleReject(requestId)
    }
  }

  return (
    <div>
      {isLoadingMessages && <LoadingSpinner />}
      {dialogError && <ErrorMessage error={dialogError} />}
      
      <ApprovalButton 
        onClick={() => handleApprovalAction('req-123', true)}
        disabled={isSelectingDialog}
      />
    </div>
  )
}
```

The hook automatically handles message processing, approval status tracking, and provides real-time updates through the Mingo messages store integration.
