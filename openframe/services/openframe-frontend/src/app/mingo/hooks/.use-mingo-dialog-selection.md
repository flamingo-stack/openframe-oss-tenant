A React hook that manages dialog selection and message loading for the Mingo AI assistant interface, providing real-time approval/rejection capabilities for technician requests.

## Key Components

- **Dialog Selection**: `selectDialog` mutation for switching between active dialogs
- **Message Management**: Infinite query pagination for loading historical messages  
- **Approval System**: `handleApprove`/`handleReject` functions for processing technician requests
- **State Synchronization**: Integrates with Zustand store for dialog and message state
- **Error Handling**: Toast notifications and error state management

## Usage Example

```typescript
import { useMingoDialogSelection } from './hooks/use-mingo-dialog-selection'

function MingoInterface() {
  const {
    selectDialog,
    isLoadingDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    dialogError,
    refetchMessages
  } = useMingoDialogSelection()

  const handleDialogClick = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const onApproveRequest = (requestId: string) => {
    handleApprove(requestId)
  }

  return (
    <div>
      {isLoadingDialog && <div>Loading dialog...</div>}
      {dialogError && <div>Error: {dialogError}</div>}
      
      <button onClick={() => refetchMessages()}>
        Refresh Messages
      </button>
    </div>
  )
}
```

The hook automatically handles message conversion from GraphQL format to the core message format, extracts approval statuses from historical data, and provides real-time updates when technicians approve or reject requests through the Mingo AI interface.
