React hook for managing Mingo dialog selection, message fetching, and approval workflows with real-time state synchronization and infinite pagination.

## Key Components

- **Dialog Selection**: `selectDialog` mutation for switching between dialogs with loading states
- **Message Fetching**: `useInfiniteQuery` with automatic pagination for dialog messages  
- **Approval System**: `handleApprove`/`handleReject` callbacks with optimistic updates
- **State Management**: Integration with `useMingoMessagesStore` for centralized state
- **Error Handling**: Toast notifications and error state management
- **Message Processing**: Conversion from GraphQL format to `HistoricalMessage` format

## Usage Example

```typescript
import { useMingoDialogSelection } from './hooks/use-mingo-dialog-selection'

function MingoDialog() {
  const {
    selectDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    rawMessagesCount
  } = useMingoDialogSelection()

  const handleDialogSelect = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const onApproveRequest = (requestId: string) => {
    handleApprove(requestId)
  }

  return (
    <div>
      <button onClick={() => handleDialogSelect('dialog-123')}>
        Load Dialog
      </button>
      {isLoadingMessages && <div>Loading messages...</div>}
      <div>Total messages: {rawMessagesCount}</div>
    </div>
  )
}
```

The hook automatically handles infinite scrolling, approval status tracking, and message state synchronization across the application.
