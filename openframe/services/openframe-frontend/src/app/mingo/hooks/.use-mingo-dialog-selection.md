A React hook for managing Mingo dialog selection and message processing with approval workflows. Handles dialog switching, paginated message loading, and real-time approval status updates.

## Key Components

- **useMingoDialogSelection**: Main hook providing dialog selection and message management functionality
- **Dialog Query**: Fetches individual dialog details using GraphQL
- **Messages Query**: Infinite query for paginated message loading with admin chat filtering
- **Approval Mutations**: Handles approve/reject operations for Mingo requests
- **State Management**: Integrates with Zustand store for dialog and message state
- **Message Processing**: Converts GraphQL messages to HistoricalMessage format with error handling

## Usage Example

```typescript
import { useMingoDialogSelection } from './use-mingo-dialog-selection'

function MingoDialogPanel() {
  const {
    selectDialog,
    isLoadingDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    dialogError,
    messagesError
  } = useMingoDialogSelection()
  
  const handleDialogClick = (dialogId: string) => {
    selectDialog(dialogId)
  }
  
  const handleRequestApproval = (requestId: string) => {
    handleApprove(requestId)
  }
  
  return (
    <div>
      {isLoadingDialog && <div>Loading dialog...</div>}
      {isLoadingMessages && <div>Loading messages...</div>}
      {dialogError && <div>Error: {dialogError}</div>}
      
      <button onClick={() => handleDialogClick('dialog-123')}>
        Select Dialog
      </button>
      
      <button onClick={() => handleRequestApproval('request-456')}>
        Approve Request
      </button>
    </div>
  )
}
```

The hook automatically manages infinite scrolling for messages, extracts approval statuses from message data, and provides optimistic UI updates for approval actions. It integrates with the Mingo messages store for persistent state management across component re-renders.
