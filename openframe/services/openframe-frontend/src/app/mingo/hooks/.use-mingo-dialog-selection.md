React hook that manages Mingo dialog selection and message processing with approval workflows. Handles dialog switching, infinite message loading, and real-time approval status updates using React Query and Zustand store.

## Key Components

- **useMingoDialogSelection()** - Main hook providing dialog selection and message management
- **Dialog Query** - Fetches dialog data using React Query with GraphQL
- **Infinite Messages Query** - Loads messages with pagination and real-time updates
- **Approval Handlers** - `handleApprove()` and `handleReject()` for request approval workflows
- **State Management** - Integration with Zustand store for message and dialog state
- **Error Handling** - Toast notifications and error state management

## Usage Example

```typescript
import { useMingoDialogSelection } from './use-mingo-dialog-selection'

function MingoDialogComponent() {
  const {
    selectDialog,
    isSelectingDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    dialogError,
    messagesError
  } = useMingoDialogSelection()

  const handleDialogSelect = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const handleApproveRequest = (requestId: string) => {
    handleApprove(requestId)
  }

  return (
    <div>
      {isLoadingMessages && <div>Loading messages...</div>}
      {dialogError && <div>Error: {dialogError}</div>}
      
      <button 
        onClick={() => handleDialogSelect('dialog-123')}
        disabled={isSelectingDialog}
      >
        Select Dialog
      </button>
      
      <button 
        onClick={() => handleApproveRequest('request-456')}
        disabled={approvalStatuses['request-456'] === 'approved'}
      >
        Approve Request
      </button>
    </div>
  )
}
```

The hook automatically handles message pagination, processes historical messages with error handling, maintains approval status synchronization, and provides real-time updates through the Mingo messages store.
