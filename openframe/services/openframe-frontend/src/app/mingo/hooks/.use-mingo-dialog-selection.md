A React hook that manages dialog selection and message handling for the Mingo AI assistant, providing functionality for switching between conversations, loading messages with pagination, and handling approval/rejection workflows.

## Key Components

- **Dialog Selection**: `selectDialog` mutation for switching between Mingo conversations
- **Message Management**: Infinite query for paginated message loading with auto-fetching
- **Approval System**: `handleApprove`/`handleReject` handlers for request approval workflows
- **State Management**: Integration with `useMingoMessagesStore` for centralized state
- **Error Handling**: Toast notifications and error state management
- **Real-time Updates**: Approval status tracking and message state synchronization

## Usage Example

```typescript
import { useMingoDialogSelection } from './use-mingo-dialog-selection'

function MingoDialogInterface() {
  const {
    selectDialog,
    isSelectingDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    dialogError,
    messagesError
  } = useMingoDialogSelection()

  const handleDialogClick = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const handleApprovalAction = (requestId: string, approved: boolean) => {
    if (approved) {
      handleApprove(requestId)
    } else {
      handleReject(requestId)
    }
  }

  return (
    <div>
      <button 
        onClick={() => handleDialogClick('dialog-123')}
        disabled={isSelectingDialog}
      >
        Load Dialog
      </button>
      {isLoadingMessages && <div>Loading messages...</div>}
      {dialogError && <div>Error: {dialogError}</div>}
    </div>
  )
}
```

The hook automatically handles message pagination, processes historical messages into the correct format, and maintains approval status state across dialog switches.
