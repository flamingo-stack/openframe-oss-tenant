React hook that manages Mingo dialog selection, message loading, and approval workflows. It provides comprehensive dialog state management with pagination, real-time approval processing, and error handling for the Mingo AI assistant interface.

## Key Components

- **Dialog Management**: Handles active dialog selection and caching
- **Message Loading**: Implements infinite scrolling with cursor-based pagination
- **Approval Workflow**: Processes approval/rejection requests with real-time UI updates
- **State Synchronization**: Integrates with Zustand store for global state management
- **Error Handling**: Provides comprehensive error states and toast notifications

## Usage Example

```typescript
import { useMingoDialogSelection } from './hooks/use-mingo-dialog-selection'

function MingoDialogInterface() {
  const {
    selectDialog,
    isLoadingDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    rawMessagesCount,
    dialogError
  } = useMingoDialogSelection()

  const handleDialogClick = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const handleApprovalAction = (requestId: string, action: 'approve' | 'reject') => {
    if (action === 'approve') {
      handleApprove(requestId)
    } else {
      handleReject(requestId)
    }
  }

  if (dialogError) {
    return <ErrorMessage error={dialogError} />
  }

  return (
    <div className="mingo-dialog-interface">
      <DialogList onDialogSelect={handleDialogClick} />
      
      {isLoadingMessages ? (
        <LoadingSpinner />
      ) : (
        <MessagesList 
          onApprove={handleApprove}
          onReject={handleReject}
          approvalStatuses={approvalStatuses}
        />
      )}
      
      <div className="message-count">
        Total messages: {rawMessagesCount}
      </div>
    </div>
  )
}
```

The hook automatically handles message processing, approval status tracking, and pagination while maintaining optimal performance through strategic caching and state management.
