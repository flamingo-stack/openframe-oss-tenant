A React hook that manages dialog selection and message loading in the Mingo AI chat system, handling both real-time and paginated message fetching with background message integration.

## Key Components

- **useMingoDialogSelection()** - Main hook for dialog selection and message management
- **dialogQuery** - React Query for fetching dialog metadata
- **messagesQuery** - Infinite query for paginated message loading
- **selectDialogMutation** - Mutation for switching between dialogs
- **Message merging logic** - Combines background messages with paginated results

## Usage Example

```typescript
import { useMingoDialogSelection } from './use-mingo-dialog-selection'

function ChatInterface() {
  const {
    selectDialog,
    isSelectingDialog,
    isLoadingDialog,
    isLoadingMessages,
    rawMessagesCount,
    dialogError,
    messagesError,
    refetchDialog,
    refetchMessages
  } = useMingoDialogSelection()

  const handleDialogSelect = (dialogId: string) => {
    selectDialog(dialogId) // Loads dialog and messages
  }

  if (isLoadingDialog) return <div>Loading dialog...</div>
  if (dialogError) return <div>Error: {dialogError}</div>

  return (
    <div>
      <p>Messages loaded: {rawMessagesCount}</p>
      {isLoadingMessages && <div>Loading messages...</div>}
      <button onClick={() => refetchMessages()}>
        Refresh Messages
      </button>
    </div>
  )
}
```

The hook automatically handles pagination by fetching additional message pages when available, merges background messages with server data, and filters for admin-type messages only. It provides comprehensive loading states and error handling for both dialog and message operations.
