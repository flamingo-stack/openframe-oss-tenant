React hook that manages Mingo dialog selection with real-time message loading, pagination, and approval workflow handling for the Flamingo Stack AI assistant interface.

## Key Components

- **Dialog Selection**: `selectDialog` mutation to switch between conversations
- **Message Loading**: Infinite query with pagination for dialog message history  
- **Approval Workflow**: `handleApprove`/`handleReject` functions for processing AI assistant requests
- **State Management**: Integration with Zustand store for message persistence
- **Error Handling**: Toast notifications and error state management
- **Data Processing**: Converts GraphQL messages to core format with approval status tracking
