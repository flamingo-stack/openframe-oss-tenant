A React hook that manages dialog selection and message fetching for the Mingo AI chat system, coordinating between background and active message stores.

## Key Components

- **Dialog Selection**: `selectDialog` mutation that switches active dialogs and resets state
- **Dialog Query**: Fetches current dialog details using React Query
- **Messages Query**: Infinite query for paginated message loading with automatic next page fetching
- **Message Merging**: Combines background messages with fetched messages, handling typing indicators and partial updates
- **State Management**: Integrates with Zustand stores for dialog details and background messages

## Usage Example

```typescript
import { useMingoDialogSelection } from './use-mingo-dialog-selection'

function DialogSelector({ dialogId }: { dialogId: string }) {
  const {
    selectDialog,
    isSelectingDialog,
    isLoadingDialog,
    isLoadingMessages,
    rawMessagesCount,
    dialogError,
    refetchDialog
  } = useMingoDialogSelection()

  const handleSelectDialog = () => {
    selectDialog(dialogId)
  }

  if (dialogError) {
    return <div>Error: {dialogError}</div>
  }

  return (
    <div>
      <button 
        onClick={handleSelectDialog}
        disabled={isSelectingDialog}
      >
        {isSelectingDialog ? 'Selecting...' : 'Select Dialog'}
      </button>
      
      {isLoadingDialog && <div>Loading dialog...</div>}
      {isLoadingMessages && <div>Loading messages...</div>}
      
      <div>Messages loaded: {rawMessagesCount}</div>
    </div>
  )
}
```

The hook automatically handles infinite scrolling for messages, merges background messages with fetched data, and filters for admin-type messages only. It provides comprehensive loading states and error handling for robust dialog management.
