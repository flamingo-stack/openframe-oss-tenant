A React hook that manages dialog selection and message loading for the Mingo AI chat system, handling background message merging and pagination.

## Key Components

- **`useMingoDialogSelection()`** - Main hook that orchestrates dialog selection and message retrieval
- **`dialogQuery`** - TanStack Query for fetching dialog details with 30s cache
- **`messagesQuery`** - Infinite query for paginated message loading (100 per page)
- **`selectDialogMutation`** - Mutation for switching between dialogs with loading states
- **Message merging logic** - Combines background and active messages with conflict resolution

## Usage Example

```typescript
import { useMingoDialogSelection } from './hooks/use-mingo-dialog-selection'

function ChatDialog() {
  const {
    selectDialog,
    isSelectingDialog,
    isLoadingDialog,
    isLoadingMessages,
    rawMessagesCount,
    dialogError,
    refetchMessages
  } = useMingoDialogSelection()

  const handleDialogChange = (dialogId: string) => {
    selectDialog(dialogId)
  }

  if (dialogError) {
    return <div>Error loading dialog: {dialogError}</div>
  }

  return (
    <div>
      {isLoadingDialog && <div>Loading dialog...</div>}
      {isLoadingMessages && <div>Loading messages...</div>}
      <div>Messages loaded: {rawMessagesCount}</div>
      <button onClick={() => refetchMessages()}>
        Refresh Messages
      </button>
    </div>
  )
}
```

The hook automatically handles infinite scroll pagination, merges background streaming messages with persisted messages, and maintains proper loading states during dialog transitions.
