A React hook for managing Mingo dialog selection, message loading, and approval workflows in the OpenFrame platform. Handles pagination, real-time updates, and GraphQL data fetching for AI assistant conversations.

## Key Components

- **Dialog Selection**: `selectDialog` mutation for switching between dialog conversations
- **Message Management**: Infinite query pagination with automatic fetching of historical messages
- **Approval System**: `handleApprove` and `handleReject` functions for processing AI requests
- **State Management**: Integration with Zustand store for persistent dialog state
- **Error Handling**: Toast notifications and error state management for failed operations

## Usage Example

```typescript
import { useMingoDialogSelection } from './use-mingo-dialog-selection'

function DialogInterface() {
  const {
    selectDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    messagesError
  } = useMingoDialogSelection()

  const handleDialogClick = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const handleApproveRequest = (requestId: string) => {
    handleApprove(requestId)
  }

  return (
    <div>
      {isLoadingMessages && <div>Loading messages...</div>}
      {messagesError && <div>Error: {messagesError}</div>}
      
      <button onClick={() => handleDialogClick('dialog-123')}>
        Select Dialog
      </button>
      
      <button onClick={() => handleApproveRequest('request-456')}>
        Approve Request
      </button>
    </div>
  )
}
```

The hook automatically handles message pagination, approval status tracking, and converts GraphQL responses to the frontend's message format for seamless AI assistant interactions.
