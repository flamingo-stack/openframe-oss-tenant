A React hook that manages dialog selection, message loading, and approval workflows for the Mingo AI assistant interface. It handles infinite scrolling of messages, real-time approval status updates, and seamless dialog switching with persistent state management.

## Key Components

- **Dialog Management**: `selectDialog` mutation for switching between conversations
- **Message Loading**: Infinite query with cursor-based pagination for chat history
- **Approval System**: `handleApprove`/`handleReject` functions for AI request approvals
- **State Integration**: Connects with `useMingoMessagesStore` for centralized message state
- **Error Handling**: Toast notifications and error state management for failed operations

## Usage Example

```typescript
import { useMingoDialogSelection } from './hooks/use-mingo-dialog-selection'

function MingoDialog() {
  const {
    selectDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    messagesError
  } = useMingoDialogSelection()

  const handleDialogSelect = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const handleApprovalAction = (requestId: string, approve: boolean) => {
    if (approve) {
      handleApprove(requestId)
    } else {
      handleReject(requestId)
    }
  }

  if (messagesError) {
    return <div>Error loading messages: {messagesError}</div>
  }

  return (
    <div>
      {isLoadingMessages && <div>Loading messages...</div>}
      {/* Render messages with approval buttons */}
    </div>
  )
}
```

The hook automatically handles infinite scrolling, processes historical messages into the correct format, and maintains approval statuses across dialog switches for a seamless user experience.
