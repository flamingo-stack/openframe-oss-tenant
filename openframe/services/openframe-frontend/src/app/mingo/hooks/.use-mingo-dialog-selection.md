A React hook that manages dialog selection and message retrieval for the Mingo AI chat interface, combining real-time background messages with paginated chat history.

## Key Components

- **`useMingoDialogSelection()`** - Main hook that orchestrates dialog selection, message fetching, and state management
- **Dialog Query** - Fetches current dialog details using React Query with 30-second stale time
- **Messages Query** - Infinite query for paginated message loading with cursor-based pagination
- **Select Dialog Mutation** - Handles dialog switching with proper state cleanup and loading states
- **Message Merging Logic** - Combines background messages with fetched messages, handling duplicates and streaming updates

## Usage Example

```typescript
import { useMingoDialogSelection } from './hooks/use-mingo-dialog-selection'

function ChatInterface() {
  const {
    selectDialog,
    isSelectingDialog,
    isLoadingDialog,
    isLoadingMessages,
    rawMessagesCount,
    dialogError,
    refetchDialog
  } = useMingoDialogSelection()

  const handleDialogSelect = (dialogId: string) => {
    selectDialog(dialogId) // Switches to new dialog with loading states
  }

  if (isLoadingDialog) return <div>Loading dialog...</div>
  if (dialogError) return <div>Error: {dialogError}</div>

  return (
    <div>
      <button onClick={() => handleDialogSelect('dialog-123')}>
        Select Dialog {isSelectingDialog && '(Loading...)'}
      </button>
      <div>Messages loaded: {rawMessagesCount}</div>
    </div>
  )
}
```

The hook automatically handles message deduplication, streaming updates from background processes, and maintains chronological order while providing comprehensive loading and error states for the UI.
