React hook that manages dialog selection and message loading for the Mingo AI chat interface, handling real-time message synchronization between background and active states.

## Key Components

- **useMingoDialogSelection** - Main hook that orchestrates dialog selection and message management
- **dialogQuery** - TanStack Query for fetching dialog metadata
- **messagesQuery** - Infinite query for paginated message loading with admin message filtering
- **selectDialogMutation** - Mutation for switching between dialogs with state cleanup
- **Message synchronization logic** - Merges background messages with fetched messages, handling typing indicators and real-time updates

## Usage Example

```typescript
import { useMingoDialogSelection } from './hooks/use-mingo-dialog-selection'

function ChatInterface() {
  const {
    selectDialog,
    isSelectingDialog,
    isLoadingDialog,
    isLoadingMessages,
    rawMessagesCount,
    dialogError,
    refetchDialog
  } = useMingoDialogSelection()

  const handleDialogSelect = (dialogId: string) => {
    selectDialog(dialogId)
  }

  if (isLoadingDialog) return <div>Loading dialog...</div>
  if (dialogError) return <div>Error: {dialogError}</div>

  return (
    <div>
      <button 
        onClick={() => handleDialogSelect('dialog-123')}
        disabled={isSelectingDialog}
      >
        Select Dialog
      </button>
      <div>Messages loaded: {rawMessagesCount}</div>
    </div>
  )
}
```

The hook automatically handles infinite scrolling for messages, merges real-time background messages with fetched data, and maintains proper chronological ordering while filtering for admin-type messages only.
