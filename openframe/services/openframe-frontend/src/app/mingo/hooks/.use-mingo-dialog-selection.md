A React hook that manages Mingo dialog selection, message loading, and approval workflows. It handles switching between dialogs, fetching messages with infinite pagination, and processing approval requests with real-time status updates.

## Key Components

- **Dialog Selection**: `selectDialog` mutation for switching between dialogs
- **Message Loading**: Infinite query that loads and processes historical messages
- **Approval Handlers**: `handleApprove` and `handleReject` for managing request approvals
- **State Management**: Integrates with `useMingoMessagesStore` for centralized state
- **Error Handling**: Toast notifications for approval failures and query errors

## Usage Example

```typescript
import { useMingoDialogSelection } from './use-mingo-dialog-selection'

function MingoDialogViewer() {
  const {
    selectDialog,
    isSelectingDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    messagesError
  } = useMingoDialogSelection()

  const handleDialogClick = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const onApproveRequest = (requestId: string) => {
    handleApprove(requestId)
  }

  return (
    <div>
      {isLoadingMessages && <div>Loading messages...</div>}
      {messagesError && <div>Error: {messagesError}</div>}
      
      <button 
        onClick={() => handleDialogClick('dialog-123')}
        disabled={isSelectingDialog}
      >
        Select Dialog
      </button>
      
      <button 
        onClick={() => onApproveRequest('request-456')}
        disabled={approvalStatuses['request-456'] === 'approved'}
      >
        Approve Request
      </button>
    </div>
  )
}
```

The hook automatically processes GraphQL messages, extracts approval statuses, and maintains real-time synchronization between the UI and backend state. It supports infinite scrolling for large message histories and provides optimistic updates for approval actions.
