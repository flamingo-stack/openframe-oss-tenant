A React hook that manages dialog selection and message loading for the Mingo AI assistant interface, providing real-time approval handling and infinite scrolling for chat messages.

## Key Components

- **Dialog Management**: Handles active dialog selection and switching between conversations
- **Message Loading**: Implements infinite query pagination for loading chat messages efficiently
- **Approval System**: Manages approval/rejection workflows for Mingo AI requests with real-time updates
- **State Synchronization**: Coordinates between GraphQL data and local Zustand store state
- **Error Handling**: Provides comprehensive error handling with toast notifications

## Usage Example

```typescript
import { useMingoDialogSelection } from './use-mingo-dialog-selection'

function MingoDialogInterface() {
  const {
    selectDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    messagesError
  } = useMingoDialogSelection()

  const handleDialogSelect = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const handleRequestApproval = (requestId: string) => {
    handleApprove(requestId)
  }

  return (
    <div>
      {isLoadingMessages && <div>Loading messages...</div>}
      {messagesError && <div>Error: {messagesError}</div>}
      
      <button onClick={() => handleDialogSelect('dialog-123')}>
        Select Dialog
      </button>
      
      <button onClick={() => handleRequestApproval('request-456')}>
        Approve Request
      </button>
      
      {approvalStatuses['request-456'] && (
        <span>Status: {approvalStatuses['request-456']}</span>
      )}
    </div>
  )
}
```

The hook automatically handles message pagination, approval status tracking, and provides optimistic UI updates for better user experience during approval workflows.
