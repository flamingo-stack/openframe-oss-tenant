A React hook that manages Mingo dialog selection, message fetching, and approval handling with infinite scroll pagination and real-time status updates.

## Key Components

- **Dialog Selection**: Manages switching between different Mingo dialogs with loading states
- **Message Fetching**: Uses infinite queries to load and paginate dialog messages
- **Approval System**: Handles approve/reject actions for requests within dialog messages
- **Status Management**: Tracks and updates approval statuses across messages
- **Store Integration**: Syncs with Zustand store for centralized state management

## Usage Example

```typescript
import { useMingoDialogSelection } from './hooks/use-mingo-dialog-selection'

function MingoDialogView() {
  const {
    selectDialog,
    isLoadingDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    dialogError,
    messagesError
  } = useMingoDialogSelection()

  const handleDialogClick = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const onApproveRequest = (requestId: string) => {
    handleApprove(requestId)
  }

  return (
    <div>
      {isLoadingDialog && <div>Loading dialog...</div>}
      {dialogError && <div>Error: {dialogError}</div>}
      
      <button onClick={() => handleDialogClick('dialog-123')}>
        Select Dialog
      </button>
      
      <button 
        onClick={() => onApproveRequest('request-456')}
        disabled={approvalStatuses['request-456'] === 'APPROVED'}
      >
        Approve Request
      </button>
    </div>
  )
}
```

The hook automatically handles infinite scroll pagination, processes historical messages into the core format, and maintains approval status synchronization between the UI and backend.
