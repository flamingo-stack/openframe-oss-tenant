Custom React hook that provides dialog selection and message management functionality for the Mingo AI assistant interface. Handles loading conversations, processing message approval/rejection workflows, and maintaining real-time state synchronization.

## Key Components

- **Dialog Selection**: `selectDialog` mutation for switching between conversation dialogs
- **Message Queries**: Infinite query system for loading paginated message history
- **Approval Workflow**: `handleApprove` and `handleReject` functions for managing admin approval requests
- **State Management**: Integration with Zustand store for persistent message state
- **Error Handling**: Toast notifications for failed operations with proper error propagation

## Usage Example

```typescript
import { useMingoDialogSelection } from './hooks/use-mingo-dialog-selection'

function MingoDialogInterface() {
  const {
    selectDialog,
    isLoadingDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    dialogError
  } = useMingoDialogSelection()

  const handleDialogClick = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const onApproveRequest = (requestId: string) => {
    handleApprove(requestId)
  }

  return (
    <div>
      {isLoadingDialog && <div>Loading dialog...</div>}
      {dialogError && <div>Error: {dialogError}</div>}
      <button onClick={() => handleDialogClick('dialog-123')}>
        Select Dialog
      </button>
    </div>
  )
}
```

The hook automatically manages message pagination, processes historical messages through the core processing pipeline, and maintains approval status synchronization across the interface.
