A React hook that manages dialog selection and message loading for Mingo dialogs, combining GraphQL queries with background message synchronization and infinite pagination.

## Key Components

- **useMingoDialogSelection()** - Main hook that orchestrates dialog selection, fetching, and message management
- **dialogQuery** - React Query for fetching dialog details with caching (30s stale time)
- **messagesQuery** - Infinite query for paginated message loading (100 messages per page)
- **selectDialogMutation** - Mutation for switching between dialogs with loading state management
- **Message merging logic** - Combines background messages with fetched messages, prioritizing longer text content and handling typing indicators

## Usage Example

```typescript
import { useMingoDialogSelection } from './use-mingo-dialog-selection'

function DialogInterface() {
  const {
    selectDialog,
    isSelectingDialog,
    isLoadingDialog,
    isLoadingMessages,
    rawMessagesCount,
    dialogError,
    refetchDialog
  } = useMingoDialogSelection()

  const handleDialogSelect = (dialogId: string) => {
    selectDialog(dialogId)
  }

  if (isLoadingDialog) return <div>Loading dialog...</div>
  if (dialogError) return <div>Error: {dialogError}</div>

  return (
    <div>
      <button 
        onClick={() => handleDialogSelect('dialog-123')}
        disabled={isSelectingDialog}
      >
        Select Dialog
      </button>
      {isLoadingMessages && <div>Loading messages...</div>}
      <div>Messages loaded: {rawMessagesCount}</div>
    </div>
  )
}
```

The hook automatically handles infinite scrolling, message deduplication, and synchronization between background and active message stores. It filters for admin messages only and maintains proper chronological ordering.
