React hook that manages Mingo dialog selection and message processing, handling dialog switching, infinite message loading, and approval workflow management for AI assistant conversations.

## Key Components

- **Dialog Management**: Handles active dialog selection and switching with persistence
- **Message Loading**: Implements infinite scrolling for dialog messages with pagination
- **Approval Workflow**: Provides approve/reject functionality for AI assistant requests
- **State Synchronization**: Coordinates between GraphQL queries and Zustand store
- **Error Handling**: Comprehensive error handling with toast notifications

## Usage Example

```typescript
import { useMingoDialogSelection } from './use-mingo-dialog-selection'

function MingoDialogPanel() {
  const {
    selectDialog,
    isSelectingDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    dialogError,
    messagesError,
    rawMessagesCount
  } = useMingoDialogSelection()

  const handleDialogSelect = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const handleRequestApproval = async (requestId: string) => {
    await handleApprove(requestId)
  }

  if (dialogError || messagesError) {
    return <div>Error: {dialogError || messagesError}</div>
  }

  return (
    <div>
      <button 
        onClick={() => handleDialogSelect('dialog-123')}
        disabled={isSelectingDialog}
      >
        Select Dialog
      </button>
      
      {isLoadingMessages && <div>Loading messages...</div>}
      
      <div>Messages loaded: {rawMessagesCount}</div>
      
      <button onClick={() => handleRequestApproval('request-456')}>
        Approve Request
      </button>
    </div>
  )
}
```

The hook automatically handles infinite message loading, processes historical messages into the correct format, and maintains approval states across dialog switches. It integrates with the Mingo messages store for state persistence and provides real-time approval workflow capabilities.
