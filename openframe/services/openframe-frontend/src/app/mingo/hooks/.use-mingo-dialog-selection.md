A React hook that manages dialog selection and message loading for the Mingo AI assistant, providing approval workflow capabilities and infinite scrolling through chat messages.

## Key Components

- **Dialog Management**: Handles active dialog selection and state management via `useMingoMessagesStore`
- **Message Loading**: Implements infinite query for paginated message fetching with GraphQL API
- **Approval System**: Provides handlers for approving/rejecting requests with real-time status updates
- **Data Processing**: Converts GraphQL messages to `HistoricalMessage` format using core processing utilities
- **Error Handling**: Comprehensive error management with toast notifications and query error states

## Usage Example

```typescript
import { useMingoDialogSelection } from './hooks/use-mingo-dialog-selection'

function MingoChat() {
  const {
    selectDialog,
    isSelectingDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    dialogError,
    refetchMessages
  } = useMingoDialogSelection()

  const handleDialogClick = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const handleRequestApproval = (requestId: string) => {
    handleApprove(requestId)
  }

  return (
    <div>
      {isLoadingMessages ? (
        <div>Loading messages...</div>
      ) : (
        <MessagesList 
          onApprove={handleRequestApproval}
          onReject={handleReject}
          approvalStatuses={approvalStatuses}
        />
      )}
    </div>
  )
}
```

The hook automatically manages message pagination, fetching additional pages as needed, and maintains approval status synchronization between local state and the message store.
