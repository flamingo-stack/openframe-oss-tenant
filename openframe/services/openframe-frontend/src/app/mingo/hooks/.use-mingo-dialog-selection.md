A custom React hook that manages Mingo dialog selection, message loading, and approval workflows within the Flamingo platform's OpenFrame chat interface.

## Key Components

### Main Hook Export
- **`useMingoDialogSelection`** - Primary hook providing dialog selection and message management functionality

### Core Features
- **Dialog Selection** - Manages active dialog switching with optimized state persistence
- **Message Loading** - Implements infinite scroll pagination for chat messages
- **Approval Workflow** - Handles approval/rejection of requests with real-time updates
- **State Management** - Integrates with Zustand store for centralized message state
- **Error Handling** - Provides comprehensive error reporting with toast notifications

### Query Operations
- **`dialogQuery`** - Fetches individual dialog data using React Query
- **`messagesQuery`** - Implements infinite query for paginated message loading
- **`selectDialogMutation`** - Handles dialog selection with loading states

### Approval Handlers
- **`handleApprove`** - Processes approval requests and updates UI state
- **`handleReject`** - Processes rejection requests and updates UI state

## Usage Example

```typescript
import { useMingoDialogSelection } from './hooks/use-mingo-dialog-selection'

function MingoDialogInterface() {
  const {
    selectDialog,
    isSelectingDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    rawMessagesCount
  } = useMingoDialogSelection()

  const handleDialogClick = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const onApproveRequest = (requestId: string) => {
    handleApprove(requestId)
  }

  return (
    <div>
      {isLoadingMessages ? (
        <div>Loading messages...</div>
      ) : (
        <div>Messages loaded: {rawMessagesCount}</div>
      )}
      
      <button 
        onClick={() => onApproveRequest('req-123')}
        disabled={approvalStatuses['req-123'] === 'approved'}
      >
        {approvalStatuses['req-123'] === 'approved' ? 'Approved' : 'Approve'}
      </button>
    </div>
  )
}
```

The hook automatically handles message processing, approval status tracking, and provides optimized dialog switching with persistent state management.
