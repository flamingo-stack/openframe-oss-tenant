Custom React hook that manages Mingo dialog selection, message loading, and approval workflows with infinite scrolling and real-time state synchronization.

## Key Components

- **Dialog Selection**: `selectDialog` mutation for switching between conversations
- **Message Management**: Infinite query with automatic pagination for dialog messages
- **Approval System**: `handleApprove`/`handleReject` functions for processing user requests
- **State Synchronization**: Integration with Zustand store for persistent message state
- **Error Handling**: Toast notifications and error state management

## Usage Example

```typescript
import { useMingoDialogSelection } from './use-mingo-dialog-selection'

function MingoDialogInterface() {
  const {
    selectDialog,
    isLoadingDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    dialogError,
    refetchMessages
  } = useMingoDialogSelection()

  const switchToDialog = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const approveRequest = (requestId: string) => {
    handleApprove(requestId)
  }

  if (dialogError) {
    return <div>Error: {dialogError}</div>
  }

  return (
    <div>
      {isLoadingDialog && <div>Loading dialog...</div>}
      {isLoadingMessages && <div>Loading messages...</div>}
      {/* Dialog interface components */}
    </div>
  )
}
```

The hook automatically handles message pagination, approval status tracking, and converts GraphQL responses to the core message format used by the Flamingo frontend system.
