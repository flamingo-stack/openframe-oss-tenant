Custom React hook for managing Mingo AI dialog selection, message fetching, and approval workflows with infinite scroll pagination and real-time state synchronization.

## Key Components

- **useMingoDialogSelection()** - Main hook providing dialog selection and message management
- **Dialog Selection** - Mutation for switching between dialogs with optimized loading
- **Message Fetching** - Infinite query for paginated message loading with GraphQL
- **Approval System** - Handlers for approving/rejecting AI requests with status tracking
- **State Management** - Integration with Zustand store for dialog and message state
- **Error Handling** - Toast notifications and error state management

## Usage Example

```typescript
import { useMingoDialogSelection } from './hooks/use-mingo-dialog-selection'

function MingoChat() {
  const {
    selectDialog,
    isSelectingDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    dialogError,
    refetchMessages
  } = useMingoDialogSelection()

  const handleDialogClick = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const onApproveRequest = (requestId: string) => {
    handleApprove(requestId)
  }

  return (
    <div>
      {isLoadingMessages && <LoadingSpinner />}
      {dialogError && <ErrorMessage error={dialogError} />}
      
      <button onClick={() => handleDialogClick('dialog-123')}>
        Select Dialog
      </button>
      
      <ApprovalButton 
        requestId="req-456"
        onApprove={onApproveRequest}
        status={approvalStatuses['req-456']}
      />
    </div>
  )
}
```

The hook handles complex GraphQL message processing, converts historical messages to the core format, manages approval workflows, and provides optimized dialog switching with persistent state management.
