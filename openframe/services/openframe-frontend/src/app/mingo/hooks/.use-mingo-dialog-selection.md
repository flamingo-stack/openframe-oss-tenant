A React hook that manages dialog selection, message loading, and approval workflows for the Mingo AI assistant interface. It orchestrates GraphQL queries for dialog data and messages while handling real-time approval status updates.

## Key Components

**Main Hook**: `useMingoDialogSelection()` - Returns dialog selection utilities and approval handlers

**Core Functions**:
- `selectDialog` - Mutation to switch between dialogs
- `handleApprove/handleReject` - Process approval requests with optimistic updates
- `refetchDialog/refetchMessages` - Manual query refresh functions

**State Management**:
- Integrates with `useMingoMessagesStore` for global state
- Manages local approval statuses with real-time synchronization
- Handles pagination and loading states

**Query Operations**:
- `dialogQuery` - Fetches single dialog metadata
- `messagesQuery` - Infinite query for paginated message history
- Auto-fetches next pages and processes historical messages

## Usage Example

```typescript
import { useMingoDialogSelection } from './hooks/use-mingo-dialog-selection'

function MingoChat() {
  const {
    selectDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    messagesError
  } = useMingoDialogSelection()

  const switchToDialog = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const approveRequest = (requestId: string) => {
    handleApprove(requestId)
  }

  return (
    <div>
      {isLoadingMessages && <LoadingSpinner />}
      {messagesError && <ErrorAlert message={messagesError} />}
      <ApprovalButton 
        onClick={() => approveRequest('req-123')}
        status={approvalStatuses['req-123']}
      />
    </div>
  )
}
```
