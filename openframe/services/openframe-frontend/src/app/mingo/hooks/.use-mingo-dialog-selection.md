React hook that manages dialog selection and message loading for Mingo chat conversations with real-time approval/rejection capabilities for administrative requests.

## Key Components

- **useMingoDialogSelection()** - Main hook that provides dialog selection and message management
- **selectDialog()** - Function to switch between different chat dialogs
- **handleApprove/handleReject()** - Real-time approval handlers for administrative requests
- **Query Management** - Uses React Query for efficient data fetching and caching
- **State Synchronization** - Integrates with Zustand store for global state management

## Usage Example

```typescript
import { useMingoDialogSelection } from './use-mingo-dialog-selection'

function MingoDialogManager() {
  const {
    selectDialog,
    isSelectingDialog,
    isLoadingDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    dialogError,
    messagesError
  } = useMingoDialogSelection()

  const handleDialogSelection = async (dialogId: string) => {
    try {
      selectDialog(dialogId)
    } catch (error) {
      console.error('Failed to select dialog:', error)
    }
  }

  const handleRequestApproval = (requestId: string) => {
    handleApprove(requestId)
  }

  return (
    <div>
      {isLoadingDialog && <div>Loading dialog...</div>}
      {isLoadingMessages && <div>Loading messages...</div>}
      {dialogError && <div>Error: {dialogError}</div>}
      
      <button onClick={() => handleDialogSelection('dialog-123')}>
        Select Dialog
      </button>
    </div>
  )
}
```

The hook automatically handles message pagination, approval status tracking, and error handling while maintaining smooth dialog switching with optimistic updates.
