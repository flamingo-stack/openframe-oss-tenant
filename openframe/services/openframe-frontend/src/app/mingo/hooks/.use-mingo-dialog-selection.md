Custom React hook for managing Mingo dialog selection, message loading, and approval request handling with optimistic updates and infinite pagination.

## Key Components

- **useMingoDialogSelection** - Main hook providing dialog selection and message management functionality
- **selectDialog** - Function to switch between dialogs with optimistic loading states
- **handleApprove/handleReject** - Callback functions for processing approval requests with toast notifications
- **dialogQuery/messagesQuery** - React Query hooks for fetching dialog data and messages with infinite pagination
- **Approval Status Management** - State management for tracking approval/rejection status of requests

## Usage Example

```typescript
import { useMingoDialogSelection } from './use-mingo-dialog-selection'

function MingoDialogInterface() {
  const {
    selectDialog,
    isSelectingDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    rawMessagesCount,
    dialogError,
    messagesError
  } = useMingoDialogSelection()

  const handleDialogClick = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const handleApproveRequest = (requestId: string) => {
    handleApprove(requestId)
  }

  return (
    <div>
      <button onClick={() => handleDialogClick('dialog-123')}>
        Select Dialog
      </button>
      
      {isLoadingMessages && <div>Loading messages...</div>}
      
      <div>Messages loaded: {rawMessagesCount}</div>
      
      <button onClick={() => handleApproveRequest('request-456')}>
        Approve Request
      </button>
    </div>
  )
}
```

This hook integrates with the Mingo messages store, handles GraphQL queries for dialog data, processes historical messages with error handling, and provides real-time approval/rejection functionality with optimistic UI updates.
