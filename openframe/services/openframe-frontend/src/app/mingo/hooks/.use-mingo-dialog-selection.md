A custom React hook for managing Mingo AI dialog selection and message loading with intelligent background message integration and pagination support.

## Key Components

- **useMingoDialogSelection()** - Main hook that orchestrates dialog selection and message fetching
- **dialogQuery** - React Query for fetching dialog details using GraphQL
- **messagesQuery** - Infinite query for loading paginated dialog messages
- **selectDialogMutation** - Mutation for handling dialog selection state changes
- **Message integration logic** - Merges background messages with fetched messages, handling typing indicators and real-time updates

## Usage Example

```typescript
import { useMingoDialogSelection } from './use-mingo-dialog-selection'

function DialogViewer() {
  const {
    selectDialog,
    isSelectingDialog,
    isLoadingDialog,
    isLoadingMessages,
    rawMessagesCount,
    dialogError,
    refetchDialog
  } = useMingoDialogSelection()

  const handleDialogSelect = (dialogId: string) => {
    selectDialog(dialogId)
  }

  if (isLoadingDialog) return <div>Loading dialog...</div>
  if (dialogError) return <div>Error: {dialogError}</div>

  return (
    <div>
      <button onClick={() => handleDialogSelect('dialog-123')}>
        Select Dialog
      </button>
      <p>Messages loaded: {rawMessagesCount}</p>
      {isLoadingMessages && <div>Loading messages...</div>}
    </div>
  )
}
```

The hook automatically handles infinite scrolling, background message synchronization, and maintains proper chronological message ordering while filtering for admin-type messages only.
