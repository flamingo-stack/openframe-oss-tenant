A React hook that manages Mingo dialog selection, message fetching, and approval workflows for AI assistant conversations. It handles GraphQL queries for dialog data, infinite message loading, and approval/rejection of requests with state synchronization.

## Key Components

- **useMingoDialogSelection()** - Main hook providing dialog selection and message management
- **selectDialog** - Function to switch between dialog conversations
- **handleApprove/handleReject** - Approval workflow handlers for assistant requests
- **dialogQuery** - React Query for fetching individual dialog metadata
- **messagesQuery** - Infinite query for paginated message loading
- **approvalStatuses** - Local state tracking approval/rejection status

## Usage Example

```typescript
import { useMingoDialogSelection } from './use-mingo-dialog-selection'

function MingoDialogInterface() {
  const {
    selectDialog,
    isLoadingDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    rawMessagesCount,
    dialogError,
    messagesError
  } = useMingoDialogSelection()

  const switchToDialog = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const approveRequest = (requestId: string) => {
    handleApprove(requestId)
  }

  if (dialogError || messagesError) {
    return <div>Error loading dialog: {dialogError || messagesError}</div>
  }

  return (
    <div>
      {isLoadingDialog && <div>Loading dialog...</div>}
      {isLoadingMessages && <div>Loading messages...</div>}
      <div>Total messages: {rawMessagesCount}</div>
      
      <button onClick={() => approveRequest('request-123')}>
        Approve Request
      </button>
    </div>
  )
}
```

The hook integrates with Zustand state management, processes historical messages for display, and provides real-time approval status updates through GraphQL mutations and optimistic UI updates.
