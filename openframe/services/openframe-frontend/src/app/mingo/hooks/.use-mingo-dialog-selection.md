A React hook that manages Mingo AI dialog selection, message loading, and approval workflow for the OpenFrame platform. This hook integrates dialog fetching with infinite scrolling messages and provides approval/rejection functionality for admin requests.

## Key Components

**Main Hook Export:**
- `useMingoDialogSelection()` - Primary hook for dialog management

**Core Functionality:**
- Dialog selection and state management
- Infinite scroll message loading with GraphQL
- Approval/rejection request handling
- Message format conversion and processing
- Error handling with toast notifications

**Key Features:**
- Automatic pagination and message fetching
- Real-time approval status tracking
- Historical message processing
- Optimized state updates for fast dialog switching

## Usage Example

```typescript
import { useMingoDialogSelection } from './use-mingo-dialog-selection'

function MingoDialogInterface() {
  const {
    selectDialog,
    isSelectingDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    rawMessagesCount,
    dialogError,
    messagesError
  } = useMingoDialogSelection()

  const handleDialogClick = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const handleApprovalAction = (requestId: string, approved: boolean) => {
    if (approved) {
      handleApprove(requestId)
    } else {
      handleReject(requestId)
    }
  }

  if (dialogError || messagesError) {
    return <div>Error: {dialogError || messagesError}</div>
  }

  return (
    <div>
      <button 
        onClick={() => handleDialogClick('dialog-123')}
        disabled={isSelectingDialog}
      >
        {isSelectingDialog ? 'Loading...' : 'Select Dialog'}
      </button>
      
      {isLoadingMessages && <div>Loading messages...</div>}
      <div>Total messages: {rawMessagesCount}</div>
      
      {/* Approval interface would use handleApprovalAction */}
    </div>
  )
}
```

The hook automatically handles message pagination, approval status synchronization, and integrates with the Mingo messages store for global state management across the OpenFrame application.
