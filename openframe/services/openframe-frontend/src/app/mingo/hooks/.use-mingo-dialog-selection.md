A React hook that manages dialog selection and message loading for Mingo AI assistant conversations, handling approval workflows and real-time message processing.

## Key Components

- **Dialog Management**: Handles active dialog selection and fetching dialog details
- **Message Processing**: Loads and processes historical messages with infinite scrolling
- **Approval System**: Manages approval/rejection of AI assistant requests
- **Store Integration**: Syncs with Zustand store for state management
- **Error Handling**: Provides comprehensive error states and toast notifications

## Usage Example

```typescript
import { useMingoDialogSelection } from './hooks/use-mingo-dialog-selection'

function MingoChat() {
  const {
    selectDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    dialogError,
    rawMessagesCount
  } = useMingoDialogSelection()

  const handleDialogSelect = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const handleApproveRequest = (requestId: string) => {
    handleApprove(requestId)
  }

  return (
    <div>
      {isLoadingMessages && <div>Loading messages...</div>}
      {dialogError && <div>Error: {dialogError}</div>}
      <div>Messages loaded: {rawMessagesCount}</div>
      
      <button onClick={() => handleApproveRequest('req-123')}>
        Approve Request
      </button>
    </div>
  )
}
```

The hook automatically handles infinite scrolling for message history, processes approval statuses from historical data, and maintains real-time synchronization between the UI and backend state.
