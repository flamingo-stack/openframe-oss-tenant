A React hook that manages dialog selection and message handling for Mingo AI assistant conversations, providing approval/rejection workflows and real-time message processing capabilities.

## Key Components

- **Dialog Selection**: `selectDialog()` mutation for switching between conversation dialogs
- **Message Management**: Infinite query system for loading and processing historical messages
- **Approval System**: `handleApprove()` and `handleReject()` functions for managing approval workflows
- **State Integration**: Connects with `useMingoMessagesStore` for centralized message state management
- **Error Handling**: Toast notifications and error state management for failed operations

## Usage Example

```typescript
import { useMingoDialogSelection } from './use-mingo-dialog-selection'

function MingoDialogInterface() {
  const {
    selectDialog,
    isSelectingDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    rawMessagesCount
  } = useMingoDialogSelection()

  const handleDialogSelect = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const handleRequestApproval = async (requestId: string) => {
    await handleApprove(requestId)
  }

  return (
    <div>
      <button 
        onClick={() => handleDialogSelect('dialog-123')}
        disabled={isSelectingDialog}
      >
        Select Dialog
      </button>
      
      {isLoadingMessages && <div>Loading messages...</div>}
      <div>Messages loaded: {rawMessagesCount}</div>
      
      <button onClick={() => handleRequestApproval('request-456')}>
        Approve Request
      </button>
    </div>
  )
}
```

The hook automatically handles message pagination, approval status tracking, and integration with GraphQL queries for seamless dialog management in the Mingo AI interface.
