A React hook that manages dialog selection and message loading for the Mingo AI assistant, handling real-time message processing, pagination, and approval workflows.

## Key Components

- **Dialog Selection**: `selectDialog` mutation for switching between different conversation threads
- **Message Loading**: Infinite query system for paginated message retrieval with automatic fetching
- **Approval System**: `handleApprove` and `handleReject` functions for processing AI requests requiring human approval
- **State Management**: Integration with Zustand store for managing active dialogs, messages, and approval statuses
- **Error Handling**: Toast notifications and error state management for API failures

## Usage Example

```typescript
import { useMingoDialogSelection } from './hooks/use-mingo-dialog-selection'

function MingoDialogInterface() {
  const {
    selectDialog,
    isSelectingDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    dialogError,
    refetchMessages
  } = useMingoDialogSelection()

  const switchToDialog = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const approveRequest = (requestId: string) => {
    handleApprove(requestId)
  }

  return (
    <div>
      {isLoadingMessages && <LoadingSpinner />}
      {dialogError && <ErrorMessage error={dialogError} />}
      
      <ApprovalButton 
        onClick={() => approveRequest('req-123')}
        status={approvalStatuses['req-123']}
      />
    </div>
  )
}
```

The hook automatically processes historical messages, extracts approval statuses, and maintains real-time synchronization between the UI and backend state through GraphQL queries and mutations.
