A React hook that manages Mingo dialog selection and message handling, providing functionality for dialog switching, message loading with infinite pagination, and approval request processing.

## Key Components

**State Management:**
- `approvalStatuses` - Local tracking of approval request states
- Integration with `useMingoMessagesStore` for global dialog state

**Core Queries:**
- `dialogQuery` - Fetches single dialog details with caching
- `messagesQuery` - Infinite query for paginated message loading
- `selectDialogMutation` - Handles dialog switching logic

**Approval System:**
- `handleApprove` / `handleReject` - Process approval requests with optimistic updates
- Real-time approval status extraction from GraphQL messages

## Usage Example

```typescript
function MingoDialogComponent() {
  const {
    selectDialog,
    isLoadingDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    dialogError
  } = useMingoDialogSelection()

  const handleDialogClick = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const handleApprovalAction = (requestId: string, approved: boolean) => {
    if (approved) {
      handleApprove(requestId)
    } else {
      handleReject(requestId)
    }
  }

  return (
    <div>
      {isLoadingDialog ? (
        <div>Loading dialog...</div>
      ) : (
        <DialogMessages 
          onApprove={handleApprove}
          onReject={handleReject}
          approvalStatuses={approvalStatuses}
        />
      )}
    </div>
  )
}
```

The hook automatically handles message pagination, converts GraphQL responses to core message format, and maintains approval state synchronization between local UI and server updates.
