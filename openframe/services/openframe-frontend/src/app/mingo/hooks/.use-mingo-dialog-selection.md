Custom React hook for managing Mingo dialog selection, message loading, and approval workflows with infinite scrolling and real-time status updates.

## Key Components

- **Dialog Selection**: Handles switching between different Mingo dialogs with state persistence
- **Message Loading**: Implements infinite query for paginated message fetching with GraphQL
- **Approval System**: Manages approval/rejection workflows for requests with optimistic updates
- **State Management**: Integrates with Zustand store for global message and dialog state
- **Error Handling**: Comprehensive error handling with toast notifications for user feedback

## Usage Example

```typescript
import { useMingoDialogSelection } from './hooks/use-mingo-dialog-selection'

function MingoDialogInterface() {
  const {
    selectDialog,
    isSelectingDialog,
    isLoadingDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    dialogError,
    messagesError,
    refetchMessages
  } = useMingoDialogSelection()

  const handleDialogSelect = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const handleApprovalAction = (requestId: string, approve: boolean) => {
    if (approve) {
      handleApprove(requestId)
    } else {
      handleReject(requestId)
    }
  }

  if (dialogError || messagesError) {
    return <ErrorDisplay error={dialogError || messagesError} onRetry={refetchMessages} />
  }

  return (
    <div>
      {isLoadingDialog && <DialogSkeleton />}
      {isLoadingMessages && <MessagesSkeleton />}
      {/* Dialog and messages UI */}
    </div>
  )
}
```

The hook automatically handles message pagination, converts GraphQL responses to the required format, and maintains approval states across dialog switches.
