Custom React hook for managing Mingo AI assistant dialog selection, message loading, and approval workflows with infinite pagination support.

## Key Components

- **Dialog Management**: Handles active dialog selection and switching with optimistic UI updates
- **Message Loading**: Implements infinite scroll pagination for dialog messages with GraphQL queries
- **Approval System**: Manages request approval/rejection workflows with real-time status updates
- **State Integration**: Synchronizes with `useMingoMessagesStore` for centralized state management
- **Error Handling**: Provides comprehensive error states and toast notifications

## Usage Example

```typescript
import { useMingoDialogSelection } from './use-mingo-dialog-selection'

function MingoDialogInterface() {
  const {
    selectDialog,
    isSelectingDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    rawMessagesCount,
    dialogError
  } = useMingoDialogSelection()

  const handleDialogClick = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const handleApprovalAction = (requestId: string, action: 'approve' | 'reject') => {
    if (action === 'approve') {
      handleApprove(requestId)
    } else {
      handleReject(requestId)
    }
  }

  return (
    <div>
      {isLoadingMessages && <LoadingSpinner />}
      {dialogError && <ErrorMessage error={dialogError} />}
      <MessagesList 
        messageCount={rawMessagesCount}
        onApprove={handleApprove}
        onReject={handleReject}
        approvalStatuses={approvalStatuses}
      />
    </div>
  )
}
```

The hook automatically handles message pagination, processes historical messages into the correct format for the Mingo assistant, and maintains approval status synchronization across the application.
