A React hook that manages Mingo dialog selection, message loading, and approval workflows for the AI assistant interface.

## Key Components

**Main Hook**: `useMingoDialogSelection()`
- Manages active dialog state and message pagination
- Handles approval/rejection of assistant requests
- Processes historical messages into chat format
- Provides loading states and error handling

**Core Features**:
- **Dialog Selection**: Switch between different conversation threads
- **Message Loading**: Infinite scroll pagination for chat history
- **Approval System**: Approve/reject AI assistant requests with optimistic updates
- **State Management**: Integration with Zustand store for persistent state

**API Integration**:
- GraphQL queries for dialog and message data
- REST endpoints for approval/rejection actions
- Real-time status updates with local state synchronization

## Usage Example

```typescript
import { useMingoDialogSelection } from './use-mingo-dialog-selection'

function MingoChat() {
  const {
    selectDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    messagesError
  } = useMingoDialogSelection()

  const handleDialogClick = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const handleApprovalRequest = (requestId: string, approved: boolean) => {
    if (approved) {
      handleApprove(requestId)
    } else {
      handleReject(requestId)
    }
  }

  if (messagesError) {
    return <div>Error loading messages: {messagesError}</div>
  }

  return (
    <div>
      {isLoadingMessages ? (
        <div>Loading messages...</div>
      ) : (
        <ChatMessages 
          onApprove={handleApprove}
          onReject={handleReject}
          approvalStatuses={approvalStatuses}
        />
      )}
    </div>
  )
}
```

The hook automatically handles message pagination, processes approval statuses from historical data, and maintains consistent state across dialog switches with optimistic UI updates for better user experience.
