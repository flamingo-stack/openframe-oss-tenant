A React hook that manages dialog selection and message handling for the Mingo AI assistant interface, providing functionality to switch between dialogs, fetch messages with pagination, and handle approval workflows for AI-generated actions.

## Key Components

**Main Hook**: `useMingoDialogSelection`
- **Dialog Management**: Handles active dialog selection and state management
- **Message Fetching**: Infinite query implementation for paginated message loading
- **Approval System**: Mutation handlers for approving/rejecting AI requests
- **Data Processing**: Converts GraphQL messages to frontend-compatible format
- **Error Handling**: Toast notifications and error state management

**Key Exports**:
- `selectDialog` - Function to switch to a different dialog
- `handleApprove/handleReject` - Approval workflow handlers
- Loading states (`isLoadingDialog`, `isLoadingMessages`)
- Error states and refetch functions

## Usage Example

```typescript
import { useMingoDialogSelection } from './hooks/use-mingo-dialog-selection'

function MingoDialogInterface() {
  const {
    selectDialog,
    isLoadingDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    dialogError,
    refetchMessages
  } = useMingoDialogSelection()

  const handleDialogSelect = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const approveRequest = (requestId: string) => {
    handleApprove(requestId)
  }

  return (
    <div>
      <button onClick={() => handleDialogSelect('dialog-123')}>
        Switch Dialog
      </button>
      
      {isLoadingMessages && <div>Loading messages...</div>}
      {dialogError && <div>Error: {dialogError}</div>}
      
      <button onClick={() => approveRequest('req-456')}>
        Approve AI Request
      </button>
    </div>
  )
}
```

The hook integrates with TanStack Query for efficient data fetching and caching, automatically handles message pagination, and maintains approval statuses across dialog switches for seamless user experience.
