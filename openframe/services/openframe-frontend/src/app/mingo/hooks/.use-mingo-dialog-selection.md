Custom React hook for managing Mingo dialog selection, fetching dialog details and messages with infinite pagination, and integrating background messages from the store.

## Key Components

- **Dialog Query**: Fetches current dialog details using React Query with 30-second cache
- **Messages Query**: Implements infinite pagination for dialog messages, filtering for admin chat type only
- **Select Dialog Mutation**: Handles dialog selection with loading state management and store updates
- **Background Message Integration**: Merges background messages with fetched messages, handling typing indicators and optimistic updates
- **Message Deduplication**: Prevents duplicate messages using Map-based deduplication with preference for longer text content

## Usage Example

```typescript
import { useMingoDialogSelection } from './use-mingo-dialog-selection'

function DialogComponent() {
  const {
    selectDialog,
    isSelectingDialog,
    isLoadingDialog,
    isLoadingMessages,
    rawMessagesCount,
    dialogError,
    refetchDialog
  } = useMingoDialogSelection()

  const handleSelectDialog = (dialogId: string) => {
    selectDialog(dialogId)
  }

  if (isLoadingDialog) return <div>Loading dialog...</div>
  if (dialogError) return <div>Error: {dialogError}</div>

  return (
    <div>
      <button 
        onClick={() => handleSelectDialog('dialog-123')}
        disabled={isSelectingDialog}
      >
        Select Dialog
      </button>
      <p>Messages loaded: {rawMessagesCount}</p>
    </div>
  )
}
```

The hook automatically manages pagination, merges background messages, and provides comprehensive loading/error states for the dialog selection workflow.
