A React hook that manages dialog selection, message loading, and approval workflows for the Mingo AI assistant interface in OpenFrame. It integrates with TanStack Query for data fetching and Zustand for state management.

## Key Components

- **Dialog Selection**: `selectDialog` mutation for switching between conversations
- **Message Loading**: Infinite query system that loads messages in pages with pagination
- **Approval System**: `handleApprove` and `handleReject` for managing request approvals
- **Data Processing**: Converts GraphQL messages to core message format with error handling
- **State Management**: Integrates with `useMingoMessagesStore` for persistent state

## Usage Example

```typescript
import { useMingoDialogSelection } from './hooks/use-mingo-dialog-selection'

function MingoInterface() {
  const {
    selectDialog,
    isSelectingDialog,
    isLoadingDialog,
    isLoadingMessages,
    handleApprove,
    handleReject,
    approvalStatuses,
    rawMessagesCount,
    dialogError,
    messagesError
  } = useMingoDialogSelection()

  const handleDialogClick = (dialogId: string) => {
    selectDialog(dialogId)
  }

  const handleApproveRequest = (requestId: string) => {
    handleApprove(requestId)
  }

  return (
    <div>
      {isLoadingDialog && <div>Loading dialog...</div>}
      {isLoadingMessages && <div>Loading messages...</div>}
      {dialogError && <div>Error: {dialogError}</div>}
      <div>Messages loaded: {rawMessagesCount}</div>
    </div>
  )
}
```

The hook automatically handles message pagination, fetching all available pages, and maintains approval status state across dialog switches. It provides comprehensive loading states and error handling for robust UI integration.
