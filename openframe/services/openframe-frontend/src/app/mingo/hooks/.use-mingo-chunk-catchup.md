A React hook that provides Mingo-specific chunk catchup functionality by wrapping the core chunk catchup hook with API client integration for fetching chat chunks.

## Key Components

- **`useMingoChunkCatchup`** - Main hook that handles chunk catchup for Mingo chat dialogs
- **`fetchChunks`** - Callback function that fetches chunks from the API using the configured client
- **Type exports** - Re-exports core types: `ChunkData`, `NatsMessageType`, `UseChunkCatchupReturn`

## Usage Example

```typescript
import { useMingoChunkCatchup } from './use-mingo-chunk-catchup'

function ChatComponent() {
  const { isConnected, error } = useMingoChunkCatchup({
    dialogId: "dialog-123",
    onChunkReceived: (chunk, messageType) => {
      console.log('Received chunk:', chunk)
      // Handle incoming chunk data
    }
  })

  if (error) {
    return <div>Error: {error}</div>
  }

  return (
    <div>
      Status: {isConnected ? 'Connected' : 'Disconnected'}
    </div>
  )
}
```

The hook automatically fetches chunks for admin chat types and handles real-time updates through the core chunk catchup system, making it easy to stay synchronized with chat data in Mingo dialogs.
