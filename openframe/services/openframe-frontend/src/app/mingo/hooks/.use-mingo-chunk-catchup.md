A custom React hook that provides Mingo-specific chunk catchup functionality for real-time chat dialogs, wrapping the core chunk catchup logic with API client integration.

## Key Components

- **useMingoChunkCatchup**: Main hook that handles chunk synchronization for Mingo chat dialogs
- **fetchChunks**: Callback function that fetches chunks from the Mingo API endpoint
- **UseMingoChunkCatchupOptions**: Interface defining required dialog ID and chunk handler
- **Type exports**: Re-exports core types for external usage (`ChunkData`, `NatsMessageType`, `UseChunkCatchupReturn`)

## Usage Example

```typescript
import { useMingoChunkCatchup, type ChunkData, type NatsMessageType } from './use-mingo-chunk-catchup'

function ChatDialog({ dialogId }: { dialogId: string }) {
  const handleChunkReceived = useCallback((
    chunk: ChunkData, 
    messageType: NatsMessageType
  ) => {
    console.log('Received chunk:', chunk)
    // Process incoming chunk data
  }, [])

  const { 
    isConnected, 
    error, 
    reconnect 
  } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: handleChunkReceived
  })

  if (error) {
    return <div>Error: {error} <button onClick={reconnect}>Retry</button></div>
  }

  return (
    <div>
      Status: {isConnected ? 'Connected' : 'Disconnected'}
      {/* Chat UI components */}
    </div>
  )
}
```

The hook automatically handles chunk fetching from the `/chat/api/v1/dialogs/{dialogId}/chunks` endpoint with support for sequence-based pagination and focuses specifically on admin chat types.
