A React hook that provides chunk catchup functionality for Mingo AI dialogs, enabling retrieval and real-time handling of chat chunks with proper error handling and API integration.

## Key Components

- **`useMingoChunkCatchup`** - Main hook that wraps the core chunk catchup functionality with Mingo-specific API integration
- **`fetchChunks`** - Memoized callback function that retrieves chunks from the chat API with optional sequence filtering
- **Type exports** - Re-exports core types (`ChunkData`, `NatsMessageType`, `UseChunkCatchupReturn`) for consumer convenience
- **`UseMingoChunkCatchupOptions`** - Interface defining required dialog ID and chunk received callback

## Usage Example

```typescript
import { useMingoChunkCatchup } from './use-mingo-chunk-catchup'

function ChatDialog({ dialogId }: { dialogId: string }) {
  const handleChunkReceived = useCallback((chunk: ChunkData, messageType: NatsMessageType) => {
    console.log('Received chunk:', chunk)
    // Process the received chunk (update UI, store in state, etc.)
  }, [])

  const { 
    isConnected, 
    isLoading, 
    error, 
    reconnect 
  } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: handleChunkReceived
  })

  if (error) {
    return <div>Error: {error.message}</div>
  }

  return (
    <div>
      <div>Status: {isConnected ? 'Connected' : 'Disconnected'}</div>
      {isLoading && <div>Loading chunks...</div>}
      {!isConnected && <button onClick={reconnect}>Reconnect</button>}
    </div>
  )
}
```

The hook automatically handles chunk catchup for ADMIN chat types and provides real-time updates through the configured callback function.
