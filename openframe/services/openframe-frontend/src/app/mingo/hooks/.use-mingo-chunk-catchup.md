A React hook that provides Mingo-specific chunk catchup functionality for retrieving missed chat messages in real-time conversations.

## Key Components

- **useMingoChunkCatchup**: Main hook that wraps the core chunk catchup functionality with Mingo-specific API integration
- **fetchChunks**: Callback function that fetches chunk data from the Mingo chat API
- **UseMingoChunkCatchupOptions**: Interface defining required options (dialogId and chunk received handler)
- **Re-exported types**: ChunkData, NatsMessageType, UseChunkCatchupReturn for consistent typing

## Usage Example

```typescript
import { useMingoChunkCatchup } from './use-mingo-chunk-catchup'

function ChatComponent({ dialogId }: { dialogId: string }) {
  const { isConnected, lastSequenceId, error } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: (chunk, messageType) => {
      console.log('Received chunk:', chunk)
      // Handle incoming chunk data (e.g., update chat messages)
    }
  })

  if (error) {
    return <div>Error: {error}</div>
  }

  return (
    <div>
      <p>Connection status: {isConnected ? 'Connected' : 'Disconnected'}</p>
      <p>Last sequence ID: {lastSequenceId}</p>
    </div>
  )
}
```

The hook automatically handles ADMIN chat type messages and uses the Mingo API client to fetch chunks from the `/chat/api/v1/dialogs/{dialogId}/chunks` endpoint with proper error handling and sequence ID management.
