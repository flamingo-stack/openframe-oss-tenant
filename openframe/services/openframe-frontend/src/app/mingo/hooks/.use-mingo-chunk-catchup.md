A React hook that provides chunk catchup functionality for Mingo admin chat dialogs, wrapping the core chunk catchup system with API client integration for fetching missed message chunks.

## Key Components

- **useMingoChunkCatchup**: Main hook that manages chunk synchronization for admin chat dialogs
- **fetchChunks**: Callback function that retrieves chunks from the chat API endpoint
- **UseMingoChunkCatchupOptions**: Interface defining required parameters (dialogId, onChunkReceived)
- **Re-exported types**: ChunkData, NatsMessageType, UseChunkCatchupReturn from core library

## Usage Example

```typescript
import { useMingoChunkCatchup, type ChunkData, type NatsMessageType } from './use-mingo-chunk-catchup'

function AdminChatComponent({ dialogId }: { dialogId: string }) {
  const handleChunkReceived = (chunk: ChunkData, messageType: NatsMessageType) => {
    // Process received chunk (new message, update, etc.)
    console.log('Received chunk:', chunk, 'Type:', messageType)
    // Update chat state, UI, etc.
  }

  const { 
    isLoading, 
    error, 
    retryFailedChunks 
  } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: handleChunkReceived
  })

  if (error) {
    return <div>Error loading chat: {error}</div>
  }

  return (
    <div>
      {isLoading && <div>Syncing chat...</div>}
      {/* Chat UI components */}
    </div>
  )
}
```

The hook automatically handles fetching missed chunks for admin chat types and provides error handling with retry capabilities.
