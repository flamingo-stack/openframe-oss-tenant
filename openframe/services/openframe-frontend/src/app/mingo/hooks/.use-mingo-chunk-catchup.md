A React hook that provides chunk catchup functionality for Mingo chat dialogs, extending the core chunk catchup system with API integration.

## Key Components

- **`useMingoChunkCatchup`** - Main hook that manages chunk retrieval and real-time updates for Mingo dialogs
- **`UseMingoChunkCatchupOptions`** - Configuration interface requiring dialog ID and chunk handler
- **`fetchChunks`** - Internal callback that retrieves chunks from the chat API with optional sequence filtering
- **Re-exported types** - `ChunkData`, `NatsMessageType`, `UseChunkCatchupReturn` from the core module

## Usage Example

```typescript
import { useMingoChunkCatchup, type ChunkData, type NatsMessageType } from './use-mingo-chunk-catchup'

function ChatComponent({ dialogId }: { dialogId: string }) {
  const handleChunkReceived = useCallback((chunk: ChunkData, messageType: NatsMessageType) => {
    console.log('New chunk received:', chunk)
    // Process the chunk data (update UI, store in state, etc.)
  }, [])

  const { 
    isConnected, 
    lastSequenceId, 
    catchUpInProgress 
  } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: handleChunkReceived
  })

  return (
    <div>
      <div>Connection: {isConnected ? 'Connected' : 'Disconnected'}</div>
      <div>Last Sequence: {lastSequenceId}</div>
      {catchUpInProgress && <div>Catching up...</div>}
    </div>
  )
}
```

The hook automatically handles chunk retrieval from `/chat/api/v1/dialogs/{dialogId}/chunks` and processes ADMIN chat type messages, providing real-time synchronization for Mingo chat interfaces.
