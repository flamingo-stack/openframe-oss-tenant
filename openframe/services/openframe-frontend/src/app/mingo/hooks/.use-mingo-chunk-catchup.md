A React hook that provides chunk catchup functionality for Mingo (admin chat) dialogs, wrapping the core chunk catchup hook with Mingo-specific API integration.

## Key Components

- **`useMingoChunkCatchup`** - Main hook that manages chunk catchup for admin chat dialogs
- **`fetchChunks`** - Callback function that fetches chunks from the Mingo API endpoint
- **Type exports** - Re-exports core types (`ChunkData`, `NatsMessageType`, `UseChunkCatchupReturn`)
- **`UseMingoChunkCatchupOptions`** - Interface defining required dialog ID and chunk received callback

## Usage Example

```typescript
import { useMingoChunkCatchup } from './use-mingo-chunk-catchup'

function MingoChat({ dialogId }: { dialogId: string }) {
  const { isConnected, catchupComplete, error } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: (chunk, messageType) => {
      console.log('Received chunk:', chunk)
      // Process the received chunk data
      updateChatUI(chunk)
    }
  })

  if (error) return <div>Error: {error}</div>
  if (!isConnected) return <div>Connecting...</div>
  if (!catchupComplete) return <div>Catching up...</div>

  return <div>Chat ready!</div>
}
```

The hook automatically handles fetching missed chunks from the `/chat/api/v1/dialogs/{dialogId}/chunks` endpoint and processes them through the core chunk catchup system, specifically configured for admin chat type communications.
