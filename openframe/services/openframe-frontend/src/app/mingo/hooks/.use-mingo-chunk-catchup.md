A React hook that provides chunk catchup functionality specifically for Mingo chat dialogs, wrapping the core chunk catchup logic with API client integration for fetching chat chunks.

## Key Components

- **useMingoChunkCatchup**: Main hook that handles chunk catchup for Mingo dialogs
- **fetchChunks**: Callback function that fetches chunks from the chat API endpoint
- **UseMingoChunkCatchupOptions**: Interface defining required options (dialogId, onChunkReceived)
- **Re-exported types**: ChunkData, NatsMessageType, UseChunkCatchupReturn from core library

## Usage Example

```typescript
import { useMingoChunkCatchup } from './use-mingo-chunk-catchup'

function ChatComponent({ dialogId }: { dialogId: string }) {
  const { isConnected, isLoading, error } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: (chunk, messageType) => {
      console.log('Received chunk:', chunk)
      // Handle incoming chunk data
      updateChatHistory(chunk)
    }
  })

  if (isLoading) return <div>Loading chat history...</div>
  if (error) return <div>Error: {error}</div>

  return (
    <div>
      <div>Connection: {isConnected ? 'Connected' : 'Disconnected'}</div>
      {/* Chat interface */}
    </div>
  )
}
```

The hook automatically manages WebSocket connections for real-time updates and handles catchup scenarios where chunks might be missing, specifically configured for ADMIN chat type dialogs.
