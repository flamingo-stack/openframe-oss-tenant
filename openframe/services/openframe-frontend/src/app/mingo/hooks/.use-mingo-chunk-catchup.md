A React hook that provides chunk catchup functionality for Mingo AI chat dialogs, wrapping the core chunk catchup logic with Mingo-specific API integration.

## Key Components

- **`useMingoChunkCatchup`** - Main hook that manages chunk catchup for Mingo chat dialogs
- **`fetchChunks`** - Callback function that retrieves chat chunks from the Mingo API
- **Type exports** - Re-exports core types (`ChunkData`, `NatsMessageType`, `UseChunkCatchupReturn`)
- **`UseMingoChunkCatchupOptions`** - Interface defining the hook's configuration options

## Usage Example

```typescript
import { useMingoChunkCatchup } from './use-mingo-chunk-catchup'

function MingoChatDialog() {
  const handleChunkReceived = useCallback((chunk: ChunkData, messageType: NatsMessageType) => {
    console.log('Received chunk:', chunk)
    // Process the chunk (update UI, store in state, etc.)
  }, [])

  const { 
    isConnected, 
    isLoading, 
    error 
  } = useMingoChunkCatchup({
    dialogId: 'dialog-123',
    onChunkReceived: handleChunkReceived
  })

  if (error) return <div>Error: {error}</div>
  if (isLoading) return <div>Loading chunks...</div>
  
  return (
    <div>
      Status: {isConnected ? 'Connected' : 'Disconnected'}
      {/* Chat interface */}
    </div>
  )
}
```

The hook automatically fetches missing chunks for admin chat types and handles real-time updates through the OpenFrame core chunk catchup system.
