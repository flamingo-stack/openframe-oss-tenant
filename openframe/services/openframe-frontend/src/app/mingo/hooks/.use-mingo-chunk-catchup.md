A React hook that provides Mingo-specific chunk catchup functionality for chat dialogs, wrapping the core chunk catchup logic with API client integration.

## Key Components

- **`useMingoChunkCatchup`** - Main hook that manages chunk synchronization for Mingo chat dialogs
- **`fetchChunks`** - Callback function that retrieves chat chunks from the API with optional sequence filtering
- **Type exports** - Re-exports core types (`ChunkData`, `NatsMessageType`, `UseChunkCatchupReturn`)

## Usage Example

```typescript
import { useMingoChunkCatchup } from './use-mingo-chunk-catchup'
import type { ChunkData, NatsMessageType } from './use-mingo-chunk-catchup'

function ChatDialog({ dialogId }: { dialogId: string }) {
  const { isConnected, lastChunk, error } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: (chunk: ChunkData, messageType: NatsMessageType) => {
      console.log('Received chunk:', chunk)
      // Handle incoming chat chunks
      updateChatHistory(chunk)
    }
  })

  if (error) {
    return <div>Error: {error}</div>
  }

  return (
    <div>
      <div>Status: {isConnected ? 'Connected' : 'Disconnected'}</div>
      {lastChunk && <div>Last message: {lastChunk.content}</div>}
    </div>
  )
}
```

The hook automatically handles chunk synchronization for admin chat types and provides real-time updates through the NATS messaging system. It includes error handling for failed API requests and maintains connection status.
