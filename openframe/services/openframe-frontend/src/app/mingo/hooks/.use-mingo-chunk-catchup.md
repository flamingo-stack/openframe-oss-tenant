A React hook that provides Mingo-specific chunk catchup functionality for real-time chat dialogs, wrapping the core chunk catchup logic with API client integration.

## Key Components

- **`useMingoChunkCatchup`** - Main hook that manages chunk synchronization for Mingo chat dialogs
- **`fetchChunks`** - Callback function that retrieves chunks from the chat API with sequence-based pagination
- **Type exports** - Re-exports core types like `ChunkData`, `NatsMessageType`, and `UseChunkCatchupReturn`

## Usage Example

```typescript
import { useMingoChunkCatchup } from './use-mingo-chunk-catchup'

function ChatDialog({ dialogId }: { dialogId: string }) {
  const { isConnected, lastChunk, error } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: (chunk, messageType) => {
      console.log('New chunk received:', chunk)
      // Handle chunk data (e.g., update UI, process message)
    }
  })

  if (error) {
    return <div>Error: {error}</div>
  }

  return (
    <div>
      <div>Status: {isConnected ? 'Connected' : 'Disconnected'}</div>
      {lastChunk && <div>Last chunk: {lastChunk.content}</div>}
    </div>
  )
}
```

The hook automatically handles chunk synchronization for admin chat types, fetching missed chunks based on sequence IDs and providing real-time updates through the NATS messaging system.
