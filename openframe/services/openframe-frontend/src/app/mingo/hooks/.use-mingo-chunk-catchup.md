A React hook that provides chunk catchup functionality for Mingo AI chat dialogs, wrapping the core chunk catchup logic with Mingo-specific API integration.

## Key Components

- **`useMingoChunkCatchup`** - Main hook that handles fetching missed chat chunks for a dialog
- **`fetchChunks`** - Callback function that retrieves chunks from the Mingo API endpoint
- **Type exports** - Re-exports core types (`ChunkData`, `NatsMessageType`, `UseChunkCatchupReturn`)
- **`UseMingoChunkCatchupOptions`** - Interface defining required dialog ID and chunk received callback

## Usage Example

```typescript
import { useMingoChunkCatchup, type ChunkData, type NatsMessageType } from './use-mingo-chunk-catchup'

function ChatDialog({ dialogId }: { dialogId: string }) {
  const handleChunkReceived = useCallback((chunk: ChunkData, messageType: NatsMessageType) => {
    console.log('Received chunk:', chunk)
    // Process the chunk data (e.g., update UI, store in state)
  }, [])

  const { 
    isConnected, 
    lastSequenceId, 
    startCatchup, 
    stopCatchup 
  } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: handleChunkReceived
  })

  // Hook automatically handles fetching missed chunks when dialog changes
  // and manages real-time chunk streaming via NATS
}
```

The hook automatically fetches chunks from `/chat/api/v1/dialogs/{dialogId}/chunks` and integrates with the core OpenFrame chunk catchup system for ADMIN chat types.
