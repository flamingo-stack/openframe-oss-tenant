A React hook that provides Mingo-specific chunk catchup functionality for dialog synchronization, wrapping the core chunk catchup logic with API client integration.

## Key Components

- **useMingoChunkCatchup** - Main hook that manages chunk synchronization for Mingo dialogs
- **fetchChunks** - Callback function that retrieves chunks from the API using the configured client
- **UseMingoChunkCatchupOptions** - Interface defining the required dialog ID and chunk received handler
- **Type exports** - Re-exports core types (ChunkData, NatsMessageType, UseChunkCatchupReturn)

## Usage Example

```typescript
import { useMingoChunkCatchup, type ChunkData, type NatsMessageType } from './use-mingo-chunk-catchup'

function ChatDialog({ dialogId }: { dialogId: string | null }) {
  const handleChunkReceived = (chunk: ChunkData, messageType: NatsMessageType) => {
    console.log('Received chunk:', chunk)
    // Process the received chunk data
  }

  const { 
    isConnected, 
    lastError, 
    reconnect 
  } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: handleChunkReceived
  })

  return (
    <div>
      <p>Status: {isConnected ? 'Connected' : 'Disconnected'}</p>
      {lastError && <p>Error: {lastError}</p>}
      <button onClick={reconnect}>Reconnect</button>
    </div>
  )
}
```

The hook automatically handles ADMIN chat type filtering and provides error handling for chunk retrieval operations.
