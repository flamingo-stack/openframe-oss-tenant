A React hook that provides chunk catchup functionality for Mingo AI chat dialogs, wrapping the core chunk catchup logic with Flamingo-specific API client integration.

## Key Components

- **useMingoChunkCatchup**: Main hook that manages chunk synchronization for Mingo dialogs
- **fetchChunks**: Callback function that retrieves chat chunks from the API endpoint
- **UseMingoChunkCatchupOptions**: Interface defining dialog ID and chunk received callback
- **Re-exported types**: ChunkData, NatsMessageType, UseChunkCatchupReturn for type safety

## Usage Example

```typescript
import { useMingoChunkCatchup, type ChunkData, type NatsMessageType } from './use-mingo-chunk-catchup'

function ChatComponent({ dialogId }: { dialogId: string }) {
  const handleChunkReceived = useCallback((chunk: ChunkData, messageType: NatsMessageType) => {
    console.log('Received chunk:', chunk)
    // Process the received chunk (update UI, store in state, etc.)
  }, [])

  const { 
    isConnected, 
    lastError, 
    retryConnection 
  } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: handleChunkReceived
  })

  if (lastError) {
    return <button onClick={retryConnection}>Retry Connection</button>
  }

  return (
    <div>
      Connection status: {isConnected ? 'Connected' : 'Disconnected'}
    </div>
  )
}
```

The hook automatically handles reconnection logic and focuses on ADMIN chat type chunks for Mingo AI technician interactions.
