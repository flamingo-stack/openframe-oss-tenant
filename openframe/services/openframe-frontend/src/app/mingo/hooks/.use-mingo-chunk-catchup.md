A React hook that provides chunk catchup functionality specifically for Mingo chat dialogs, wrapping the core chunk catchup logic with Mingo-specific API integration.

## Key Components

- **`useMingoChunkCatchup`** - Main hook that manages chunk synchronization for Mingo dialogs
- **`fetchChunks`** - Callback function that retrieves chunks from the Mingo chat API
- **Type exports** - Re-exports core types (`ChunkData`, `NatsMessageType`, `UseChunkCatchupReturn`)
- **`UseMingoChunkCatchupOptions`** - Interface defining required dialog ID and chunk handler

## Usage Example

```typescript
import { useMingoChunkCatchup } from './use-mingo-chunk-catchup'

function ChatComponent({ dialogId }: { dialogId: string }) {
  const handleChunkReceived = useCallback((chunk, messageType) => {
    console.log('Received chunk:', chunk.content)
    // Process the chunk data
  }, [])

  const { 
    isConnected, 
    connectionError, 
    lastSequenceId 
  } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: handleChunkReceived
  })

  return (
    <div>
      <p>Status: {isConnected ? 'Connected' : 'Disconnected'}</p>
      {connectionError && <p>Error: {connectionError}</p>}
    </div>
  )
}
```

The hook automatically handles API calls to fetch missing chunks and maintains real-time synchronization for admin chat types in Mingo dialogs.
