A client-side React hook that provides chunk catchup functionality for Mingo AI chat dialogs, wrapping the core chunk catchup logic with Mingo-specific API integration.

## Key Components

- **useMingoChunkCatchup**: Main hook that manages chunk synchronization for chat dialogs
- **fetchChunks**: Internal callback function that retrieves chunks from the Mingo chat API
- **UseMingoChunkCatchupOptions**: Configuration interface requiring dialog ID and chunk handler
- **Re-exported types**: ChunkData, NatsMessageType, and UseChunkCatchupReturn from core library

## Usage Example

```typescript
import { useMingoChunkCatchup, type ChunkData, type NatsMessageType } from './use-mingo-chunk-catchup'

function ChatComponent() {
  const [dialogId, setDialogId] = useState<string | null>('dialog-123')

  const handleChunkReceived = (chunk: ChunkData, messageType: NatsMessageType) => {
    console.log('Received chunk:', chunk)
    // Process incoming chat chunks
  }

  const { isConnected, error, lastSequenceId } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: handleChunkReceived,
  })

  return (
    <div>
      <p>Connection status: {isConnected ? 'Connected' : 'Disconnected'}</p>
      {error && <p>Error: {error}</p>}
      <p>Last sequence ID: {lastSequenceId}</p>
    </div>
  )
}
```

The hook automatically handles API calls to fetch missed chunks and maintains real-time synchronization for admin chat types in Mingo AI dialogs.
