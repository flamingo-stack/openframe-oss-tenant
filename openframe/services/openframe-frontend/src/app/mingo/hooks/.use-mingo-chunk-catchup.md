A React hook that provides chunk catchup functionality for Mingo AI assistant conversations, wrapping the core chunk catchup logic with Mingo-specific API integration.

## Key Components

- **`useMingoChunkCatchup`** - Main hook that manages chunk synchronization for dialog conversations
- **`fetchChunks`** - Async function that retrieves missing chunks from the chat API endpoint
- **Type exports** - Re-exports core types (`ChunkData`, `NatsMessageType`, `UseChunkCatchupReturn`)

## Usage Example

```typescript
import { useMingoChunkCatchup, type ChunkData, type NatsMessageType } from './use-mingo-chunk-catchup'

function ChatComponent({ dialogId }: { dialogId: string }) {
  const handleChunkReceived = (chunk: ChunkData, messageType: NatsMessageType) => {
    console.log('Received chunk:', chunk.content)
    // Update UI with new chunk data
  }

  const { 
    isConnected, 
    connectionError, 
    startCatchup, 
    stopCatchup 
  } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: handleChunkReceived
  })

  return (
    <div>
      <p>Connection status: {isConnected ? 'Connected' : 'Disconnected'}</p>
      <button onClick={startCatchup}>Start Sync</button>
      <button onClick={stopCatchup}>Stop Sync</button>
    </div>
  )
}
```

The hook automatically fetches missing chunks for admin chat types and handles real-time synchronization through the core chunk catchup system.
