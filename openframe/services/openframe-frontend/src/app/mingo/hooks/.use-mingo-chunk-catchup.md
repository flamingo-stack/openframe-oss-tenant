A React hook that provides chunk catchup functionality specifically for Mingo dialogs, fetching missed chunks from the chat API and handling real-time updates.

## Key Components

- **`useMingoChunkCatchup`** - Main hook that wraps the core chunk catchup functionality with Mingo-specific API integration
- **`fetchChunks`** - Callback function that retrieves chunks from the chat API with optional sequence ID filtering
- **Type exports** - Re-exports `ChunkData`, `NatsMessageType`, and `UseChunkCatchupReturn` from the core library

## Usage Example

```typescript
import { useMingoChunkCatchup, type ChunkData, type NatsMessageType } from './use-mingo-chunk-catchup'

function ChatComponent({ dialogId }: { dialogId: string }) {
  const handleChunkReceived = useCallback((chunk: ChunkData, messageType: NatsMessageType) => {
    console.log('Received chunk:', chunk)
    // Process the chunk (update UI, store in state, etc.)
  }, [])

  const { 
    isConnected, 
    isLoading, 
    error, 
    startCatchup, 
    stopCatchup 
  } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: handleChunkReceived
  })

  // Hook automatically handles ADMIN chat type and fetches from /chat/api/v1/dialogs/:id/chunks
  return (
    <div>
      <p>Status: {isConnected ? 'Connected' : 'Disconnected'}</p>
      {error && <p>Error: {error}</p>}
    </div>
  )
}
```
