A React hook that provides chat chunk catchup functionality for Mingo admin dialogs, extending the core chunk catchup system with MSP-specific API integration.

## Key Components

- **`useMingoChunkCatchup`** - Main hook that wraps the core chunk catchup functionality with Mingo-specific configuration
- **`fetchChunks`** - Callback function that retrieves chat chunks from the MSP API endpoint
- **Type exports** - Re-exports core types (`ChunkData`, `NatsMessageType`, `UseChunkCatchupReturn`) for convenience

## Usage Example

```typescript
import { useMingoChunkCatchup } from './use-mingo-chunk-catchup'

function ChatComponent() {
  const { isConnected, lastChunk, error } = useMingoChunkCatchup({
    dialogId: 'dialog-123',
    onChunkReceived: (chunk, messageType) => {
      console.log('Received chunk:', chunk)
      // Handle incoming chat chunks
      updateChatHistory(chunk)
    }
  })

  return (
    <div>
      <div>Status: {isConnected ? 'Connected' : 'Disconnected'}</div>
      {error && <div>Error: {error}</div>}
      {lastChunk && <div>Last message: {lastChunk.content}</div>}
    </div>
  )
}
```

The hook automatically manages NATS connections for real-time updates and provides fallback API fetching for missed chunks in admin chat contexts.
