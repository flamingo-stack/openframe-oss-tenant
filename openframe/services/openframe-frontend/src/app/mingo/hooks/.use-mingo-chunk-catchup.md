A React hook that provides chunk catchup functionality for Mingo admin chat dialogs, wrapping the core chunk catchup implementation with Mingo-specific API integration.

## Key Components

- **`useMingoChunkCatchup`** - Main hook that manages chunk synchronization for admin dialogs
- **`fetchChunks`** - Internal callback that retrieves chat chunks from the Mingo API
- **Type exports** - Re-exports core chunk-related TypeScript types (`ChunkData`, `NatsMessageType`, `UseChunkCatchupReturn`)

## Usage Example

```typescript
import { useMingoChunkCatchup, type ChunkData, type NatsMessageType } from './use-mingo-chunk-catchup'

function MingoAdminChat({ dialogId }: { dialogId: string }) {
  const handleChunkReceived = (chunk: ChunkData, messageType: NatsMessageType) => {
    console.log('Received chunk:', chunk)
    // Process the received chunk (e.g., update UI, store in state)
  }

  const { 
    isConnected, 
    catchupStatus, 
    retryConnection 
  } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: handleChunkReceived
  })

  if (!isConnected) {
    return <div>Connecting to admin chat...</div>
  }

  return (
    <div>
      <div>Status: {catchupStatus}</div>
      {/* Chat UI components */}
    </div>
  )
}
```

The hook automatically handles fetching missing chunks from the `/chat/api/v1/dialogs/{dialogId}/chunks` endpoint and processes them through the core chunk catchup system, specifically configured for admin chat types.
