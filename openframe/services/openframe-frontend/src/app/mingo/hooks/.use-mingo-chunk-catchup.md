A React hook that provides Mingo-specific chunk catchup functionality for dialog synchronization by wrapping the core chunk catchup hook with Mingo's API client and admin chat type configuration.

## Key Components

- **`useMingoChunkCatchup`** - Main hook that handles chunk synchronization for Mingo dialogs
- **`fetchChunks`** - Callback function that retrieves chunks from the Mingo API with optional sequence filtering
- **Type exports** - Re-exports core types (`ChunkData`, `NatsMessageType`, `UseChunkCatchupReturn`) for convenience
- **API integration** - Uses Mingo's `apiClient` for HTTP requests to the chat API

## Usage Example

```typescript
import { useMingoChunkCatchup } from './use-mingo-chunk-catchup'

function ChatComponent({ dialogId }: { dialogId: string }) {
  const { isLoading, error, retryFailed } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: (chunk, messageType) => {
      console.log('Received chunk:', chunk)
      // Handle incoming chunk data
      updateChatHistory(chunk)
    }
  })

  if (isLoading) return <div>Syncing messages...</div>
  if (error) return <button onClick={retryFailed}>Retry</button>
  
  return <div>Chat synchronized</div>
}
```

The hook automatically configures the core chunk catchup system to use admin chat types and Mingo's API endpoints for retrieving missing chat chunks during dialog synchronization.
