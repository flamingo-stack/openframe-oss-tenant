A React hook for catching up on missed chat chunks in Mingo conversations, specifically handling ADMIN chat type messages through the OpenFrame chat API.

## Key Components

- **`useMingoChunkCatchup`** - Main hook that wraps the core chunk catchup functionality with Mingo-specific API integration
- **`fetchChunks`** - Internal callback function that retrieves chat chunks from the `/chat/api/v1/dialogs/{dialogId}/chunks` endpoint
- **Type exports** - Re-exports `ChunkData`, `NatsMessageType`, and `UseChunkCatchupReturn` from the core library

## Usage Example

```typescript
import { useMingoChunkCatchup } from './use-mingo-chunk-catchup'

function ChatComponent() {
  const dialogId = 'dialog-123'
  
  const handleChunkReceived = (chunk: ChunkData, messageType: NatsMessageType) => {
    console.log('New chunk received:', chunk)
    // Process the chunk data and update UI
  }

  const { 
    isConnected, 
    connectionStatus, 
    error 
  } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: handleChunkReceived
  })

  return (
    <div>
      <p>Connection Status: {connectionStatus}</p>
      {error && <p>Error: {error}</p>}
    </div>
  )
}
```

The hook automatically handles reconnection, message ordering, and focuses specifically on ADMIN chat type messages for Mingo's AI assistant functionality.
