React hook for catching up on missed chat chunks in Mingo dialogs. Provides a specialized wrapper around the core chunk catchup functionality with dialog-specific API integration.

## Key Components

- **useMingoChunkCatchup** - Main hook that manages chunk synchronization for a specific dialog
- **fetchChunks** - Callback function that retrieves chunks from the chat API endpoint
- **UseMingoChunkCatchupOptions** - Interface defining required dialog ID and chunk handler
- **Type exports** - Re-exported types from the core library (ChunkData, NatsMessageType, UseChunkCatchupReturn)

## Usage Example

```typescript
import { useMingoChunkCatchup, type ChunkData, type NatsMessageType } from './use-mingo-chunk-catchup'

function ChatDialog({ dialogId }: { dialogId: string }) {
  const { isConnected, isCatchingUp, error } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: (chunk: ChunkData, messageType: NatsMessageType) => {
      console.log('Received chunk:', chunk)
      // Handle the received chunk (update UI, store in state, etc.)
    }
  })

  if (error) {
    return <div>Error: {error}</div>
  }

  return (
    <div>
      <div>Status: {isConnected ? 'Connected' : 'Disconnected'}</div>
      {isCatchingUp && <div>Catching up on missed messages...</div>}
      {/* Chat interface */}
    </div>
  )
}
```

The hook automatically handles fetching missed chunks from the `/chat/api/v1/dialogs/{dialogId}/chunks` endpoint and integrates with the real-time messaging system for seamless chat synchronization.
