A React hook that provides chunk catchup functionality for Mingo AI conversations, allowing components to fetch and receive real-time chat message chunks from dialogs.

## Key Components

**Main Export:**
- `useMingoChunkCatchup` - Custom hook that wraps the core chunk catchup functionality with Mingo-specific API integration

**Type Exports:**
- `ChunkData` - Interface for chat message chunk data
- `NatsMessageType` - Type for NATS messaging system message types
- `UseChunkCatchupReturn` - Return type of the hook containing catchup state and controls

**Options Interface:**
- `UseMingoChunkCatchupOptions` - Configuration object requiring dialog ID and chunk received callback

## Usage Example

```typescript
import { useMingoChunkCatchup, type ChunkData, type NatsMessageType } from './use-mingo-chunk-catchup'

function ChatComponent({ dialogId }: { dialogId: string }) {
  const { isActive, startCatchup, stopCatchup } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: (chunk: ChunkData, messageType: NatsMessageType) => {
      console.log('Received chunk:', chunk)
      // Handle incoming chat chunk (update UI, store message, etc.)
    }
  })

  return (
    <div>
      <button onClick={startCatchup} disabled={isActive}>
        Start Catching Up
      </button>
      <button onClick={stopCatchup} disabled={!isActive}>
        Stop Catchup
      </button>
    </div>
  )
}
```

The hook automatically fetches chunks from the `/chat/api/v1/dialogs/{dialogId}/chunks` endpoint and handles real-time updates for ADMIN chat types through the OpenFrame core chunk catchup system.
