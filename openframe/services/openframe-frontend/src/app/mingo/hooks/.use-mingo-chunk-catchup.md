A React hook wrapper that provides Mingo-specific chunk catchup functionality for real-time chat message synchronization, specifically configured for admin chat types.

## Key Components

- **`useMingoChunkCatchup`** - Main hook that wraps the core chunk catchup functionality with Mingo-specific API configuration
- **`fetchChunks`** - Callback function that retrieves chat chunks from the Mingo API endpoints
- **Type exports** - Re-exports core types (`ChunkData`, `NatsMessageType`, `UseChunkCatchupReturn`) for convenience
- **`UseMingoChunkCatchupOptions`** - Interface defining required options for dialog ID and chunk reception handling

## Usage Example

```typescript
import { useMingoChunkCatchup } from './use-mingo-chunk-catchup'

function ChatDialog({ dialogId }: { dialogId: string }) {
  const { isConnected, lastChunk, error } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: (chunk, messageType) => {
      console.log('Received chunk:', chunk)
      // Handle incoming chat chunk data
      updateChatMessages(chunk)
    }
  })

  if (error) {
    return <div>Error loading chat: {error}</div>
  }

  return (
    <div>
      <div>Connection: {isConnected ? 'Connected' : 'Disconnected'}</div>
      {/* Render chat messages */}
    </div>
  )
}
```

The hook automatically handles fetching missing chunks from the `/chat/api/v1/dialogs/{dialogId}/chunks` endpoint and is pre-configured for admin chat types only.
