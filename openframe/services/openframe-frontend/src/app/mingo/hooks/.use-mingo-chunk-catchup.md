A React hook that provides chunk catchup functionality for Mingo (admin) chat dialogs, fetching missed chunks and handling real-time updates through the OpenFrame core system.

## Key Components

- **`useMingoChunkCatchup`** - Main hook that wraps the core chunk catchup functionality with Mingo-specific configuration
- **`fetchChunks`** - Async function that retrieves chat chunks from the API with optional sequence filtering
- **Type exports** - Re-exports core types (`ChunkData`, `NatsMessageType`, `UseChunkCatchupReturn`) for convenience
- **`UseMingoChunkCatchupOptions`** - Interface defining the hook's required parameters

## Usage Example

```typescript
import { useMingoChunkCatchup } from './use-mingo-chunk-catchup'

function MingoChat({ dialogId }: { dialogId: string }) {
  const handleChunkReceived = (chunk, messageType) => {
    console.log('Received chunk:', chunk.content)
    // Process the chunk data (update UI, store in state, etc.)
  }

  const { 
    isConnected, 
    isLoading, 
    error 
  } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: handleChunkReceived
  })

  if (error) return <div>Error: {error}</div>
  if (isLoading) return <div>Loading chat...</div>
  
  return (
    <div>
      <div>Status: {isConnected ? 'Connected' : 'Disconnected'}</div>
      {/* Chat UI components */}
    </div>
  )
}
```

The hook automatically handles reconnection, chunk ordering, and integrates with the NATS messaging system for real-time updates in admin chat contexts.
