Custom hook for catching up on Mingo AI chat message chunks, extending the core chunk catchup functionality with Mingo-specific API integration.

## Key Components

- **useMingoChunkCatchup**: Main hook that provides chunk catchup functionality for Mingo AI dialogs
- **fetchChunks**: Callback function that fetches chunk data from the Mingo chat API
- **UseMingoChunkCatchupOptions**: Configuration interface requiring dialog ID and chunk received handler
- **Type exports**: Re-exports core chunk catchup types for external use

## Usage Example

```typescript
import { useMingoChunkCatchup, type ChunkData, type NatsMessageType } from './use-mingo-chunk-catchup'

function MingoChatComponent({ dialogId }: { dialogId: string }) {
  const handleChunkReceived = useCallback((chunk: ChunkData, messageType: NatsMessageType) => {
    console.log('Received chunk:', chunk)
    // Process the chunk data (e.g., update chat messages)
  }, [])

  const { 
    isConnected, 
    error, 
    lastChunk 
  } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: handleChunkReceived
  })

  if (error) {
    return <div>Error: {error.message}</div>
  }

  return (
    <div>
      <div>Status: {isConnected ? 'Connected' : 'Disconnected'}</div>
      {lastChunk && <div>Last chunk: {lastChunk.content}</div>}
    </div>
  )
}
```

This hook automatically handles fetching chunks from the `/chat/api/v1/dialogs/{dialogId}/chunks` endpoint and configures the core chunk catchup system specifically for admin chat types in Mingo AI dialogs.
