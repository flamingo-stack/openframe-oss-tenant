A custom React hook that provides chunk catchup functionality for Mingo AI dialogs, built on top of the OpenFrame core chunk system. It fetches and synchronizes chat chunks from the API for admin-type conversations.

## Key Components

**Main Export:**
- `useMingoChunkCatchup` - React hook for catching up on missed chunks in Mingo dialogs

**Types:**
- `UseMingoChunkCatchupOptions` - Configuration interface requiring `dialogId` and `onChunkReceived` callback
- Re-exported types: `ChunkData`, `NatsMessageType`, `UseChunkCatchupReturn`

**Core Features:**
- Fetches chunks from REST API endpoint with optional sequence ID filtering
- Configured for `CHAT_TYPE.ADMIN` conversations only
- Handles API errors gracefully with fallback to empty arrays
- Memoized options and fetch function for performance optimization

## Usage Example

```typescript
import { useMingoChunkCatchup, type ChunkData, type NatsMessageType } from './use-mingo-chunk-catchup'

function MingoChat({ dialogId }: { dialogId: string }) {
  const handleChunkReceived = useCallback((chunk: ChunkData, messageType: NatsMessageType) => {
    console.log('Received chunk:', chunk)
    // Process the chunk (update UI, store in state, etc.)
  }, [])

  const { isLoading, error, lastSequenceId } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: handleChunkReceived
  })

  if (isLoading) return <div>Loading chunks...</div>
  if (error) return <div>Error: {error}</div>

  return <div>Chat ready with latest chunks</div>
}
```

The hook automatically fetches chunks from `/chat/api/v1/dialogs/{dialogId}/chunks` and calls the provided callback for each received chunk, enabling real-time synchronization of chat data.
