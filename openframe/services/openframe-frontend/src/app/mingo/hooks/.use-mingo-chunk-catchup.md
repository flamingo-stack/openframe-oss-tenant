A React hook that provides Mingo-specific chunk catchup functionality for real-time chat synchronization, wrapping the core chunk catchup logic with API client integration.

## Key Components

- **useMingoChunkCatchup**: Main hook that orchestrates chunk synchronization for admin chat types
- **fetchChunks**: Callback function that retrieves chat chunks from the API with optional sequence filtering
- **UseMingoChunkCatchupOptions**: Configuration interface requiring dialog ID and chunk received callback
- **Type exports**: Re-exports core chunk-related types for consumer convenience

## Usage Example

```typescript
import { useMingoChunkCatchup } from './use-mingo-chunk-catchup'

function ChatComponent() {
  const { isLoading, error, lastSequenceId } = useMingoChunkCatchup({
    dialogId: 'dialog-123',
    onChunkReceived: (chunk, messageType) => {
      console.log('Received chunk:', chunk.content)
      // Update chat state with new chunk
    }
  })

  if (isLoading) return <div>Syncing messages...</div>
  if (error) return <div>Error: {error}</div>

  return <div>Chat synchronized up to sequence: {lastSequenceId}</div>
}
```

The hook automatically handles admin chat type filtering and provides robust error handling for chunk retrieval operations. It integrates seamlessly with the Flamingo stack's real-time messaging system through the core chunk catchup functionality.
