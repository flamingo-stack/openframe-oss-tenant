A React hook that provides chunk catchup functionality for Mingo (admin) chat dialogs, extending the core chunk catchup system with Flamingo API integration.

## Key Components

- **`useMingoChunkCatchup`** - Main hook that wraps the core chunk catchup functionality with Mingo-specific configuration
- **`fetchChunks`** - Callback function that handles API calls to retrieve chat chunks from the Flamingo backend
- **Type exports** - Re-exports core types (`ChunkData`, `NatsMessageType`, `UseChunkCatchupReturn`) for convenience

## Usage Example

```typescript
import { useMingoChunkCatchup } from './use-mingo-chunk-catchup'

function MingoChat({ dialogId }: { dialogId: string }) {
  const handleChunkReceived = useCallback((chunk: ChunkData, messageType: NatsMessageType) => {
    // Process received chunk (new message, update, etc.)
    console.log('Received chunk:', chunk, messageType)
  }, [])

  const { 
    isConnected, 
    reconnect, 
    disconnect 
  } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: handleChunkReceived
  })

  return (
    <div>
      <div>Status: {isConnected ? 'Connected' : 'Disconnected'}</div>
      <button onClick={reconnect}>Reconnect</button>
    </div>
  )
}
```

The hook automatically handles fetching missed chunks from the API and maintains real-time synchronization for admin chat types only.
