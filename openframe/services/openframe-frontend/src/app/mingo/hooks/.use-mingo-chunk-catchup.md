A React hook that provides Mingo-specific chunk catchup functionality for retrieving missed chat chunks from dialog conversations. It wraps the core chunk catchup logic with Mingo's API client and focuses on admin chat types.

## Key Components

- **`useMingoChunkCatchup`** - Main hook that manages chunk retrieval and catchup logic
- **`fetchChunks`** - Callback function that fetches chunks from the Mingo chat API
- **Type exports** - Re-exports core types (`ChunkData`, `NatsMessageType`, `UseChunkCatchupReturn`)
- **`UseMingoChunkCatchupOptions`** - Configuration interface for dialog ID and chunk handling

## Usage Example

```typescript
import { useMingoChunkCatchup } from './use-mingo-chunk-catchup'

function ChatComponent() {
  const { isActive, start, stop, lastSequenceId } = useMingoChunkCatchup({
    dialogId: 'dialog-123',
    onChunkReceived: (chunk, messageType) => {
      console.log('Received chunk:', chunk.content)
      // Handle incoming chunk data
      updateChatMessages(chunk)
    }
  })

  // Start catching up on missed chunks
  const handleStartCatchup = () => {
    start()
  }

  return (
    <div>
      <button onClick={handleStartCatchup} disabled={isActive}>
        {isActive ? 'Catching up...' : 'Start Catchup'}
      </button>
      <p>Last sequence ID: {lastSequenceId}</p>
    </div>
  )
}
```

The hook automatically handles API errors and returns empty arrays on failure, ensuring robust chunk retrieval for admin chat conversations.
