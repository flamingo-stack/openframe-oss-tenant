A React hook that provides Mingo-specific chunk catchup functionality for synchronizing chat data chunks in dialogs. It wraps the core chunk catchup logic with API client integration for fetching missing chunks from the Mingo chat service.

## Key Components

- **`useMingoChunkCatchup`** - Main hook that manages chunk synchronization for Mingo dialogs
- **`fetchChunks`** - Callback function that retrieves chunks from the chat API endpoint
- **Type exports** - Re-exports core types (`ChunkData`, `NatsMessageType`, `UseChunkCatchupReturn`) for convenience
- **`UseMingoChunkCatchupOptions`** - Configuration interface requiring dialog ID and chunk handler

## Usage Example

```typescript
import { useMingoChunkCatchup, type ChunkData, type NatsMessageType } from './use-mingo-chunk-catchup'

function ChatDialog({ dialogId }: { dialogId: string }) {
  const handleChunkReceived = useCallback((chunk: ChunkData, messageType: NatsMessageType) => {
    console.log('Received chunk:', chunk)
    // Process the chunk data (update UI, store in state, etc.)
  }, [])

  const { isConnected, lastSequenceId, error } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: handleChunkReceived
  })

  if (error) {
    return <div>Error: {error}</div>
  }

  return (
    <div>
      <div>Connection status: {isConnected ? 'Connected' : 'Disconnected'}</div>
      <div>Last sequence: {lastSequenceId}</div>
    </div>
  )
}
```
