A React hook that provides chunk catchup functionality specifically for Mingo (technician chat) dialogs, wrapping the core chunk catchup logic with Mingo-specific API integration and chat type configuration.

## Key Components

- **`useMingoChunkCatchup`** - Main hook that manages chunk synchronization for Mingo dialogs
- **`fetchChunks`** - Memoized callback that retrieves chat chunks via API client
- **Type exports** - Re-exports core types (`ChunkData`, `NatsMessageType`, `UseChunkCatchupReturn`)
- **`UseMingoChunkCatchupOptions`** - Interface defining required dialog ID and chunk handler

## Usage Example

```typescript
import { useMingoChunkCatchup } from './hooks/use-mingo-chunk-catchup'

function MingoChat({ dialogId }: { dialogId: string }) {
  const { isLoading, error, lastProcessedSequenceId } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: (chunk, messageType) => {
      // Handle incoming chunks from technician chat
      console.log('Received chunk:', chunk)
      // Update chat UI, store messages, etc.
    }
  })

  if (isLoading) return <div>Syncing messages...</div>
  if (error) return <div>Error: {error}</div>

  return <div>Chat synchronized up to sequence {lastProcessedSequenceId}</div>
}
```

The hook automatically configures the core chunk catchup functionality for `CHAT_TYPE.ADMIN` (technician chat) and handles API requests through the configured API client, providing real-time message synchronization for Mingo dialogs.
