A React hook that provides Mingo-specific chunk catchup functionality for real-time chat message synchronization, wrapping the core chunk catchup logic with API client integration.

## Key Components

- **useMingoChunkCatchup**: Main hook that manages chunk catchup for Mingo dialogs
- **fetchChunks**: Callback function that retrieves chunks from the chat API endpoint
- **UseMingoChunkCatchupOptions**: Interface defining required dialog ID and chunk handler
- **Type exports**: Re-exports core types (ChunkData, NatsMessageType, UseChunkCatchupReturn)

## Usage Example

```typescript
import { useMingoChunkCatchup } from './use-mingo-chunk-catchup'

function ChatDialog({ dialogId }: { dialogId: string }) {
  const handleChunkReceived = useCallback((chunk: ChunkData, messageType: NatsMessageType) => {
    // Process received chunk data
    console.log('Received chunk:', chunk)
    updateChatMessages(chunk)
  }, [])

  const { 
    isConnected, 
    connectionState, 
    retryConnection 
  } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: handleChunkReceived
  })

  return (
    <div>
      <div>Connection: {connectionState}</div>
      {!isConnected && (
        <button onClick={retryConnection}>Retry Connection</button>
      )}
    </div>
  )
}
```

The hook automatically handles NATS real-time subscriptions, API fallback for missed chunks, and focuses specifically on admin chat types within the Mingo ecosystem.
