A React hook that provides chunk catchup functionality for Mingo AI chat dialogs, wrapping the core OpenFrame chunk catchup system with API client integration.

## Key Components

- **`useMingoChunkCatchup`** - Main hook that manages chunk synchronization for Mingo dialogs
- **`fetchChunks`** - Async function that retrieves chat chunks from the API with optional sequence filtering
- **Type exports** - Re-exports core types (`ChunkData`, `NatsMessageType`, `UseChunkCatchupReturn`) for consumer convenience

## Usage Example

```typescript
import { useMingoChunkCatchup, type ChunkData, type NatsMessageType } from './use-mingo-chunk-catchup'

function ChatDialog({ dialogId }: { dialogId: string }) {
  const handleChunkReceived = useCallback((chunk: ChunkData, messageType: NatsMessageType) => {
    console.log('Received chunk:', chunk)
    // Update UI with new chunk data
  }, [])

  const { isConnected, lastSequenceId, error } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: handleChunkReceived
  })

  return (
    <div>
      <div>Status: {isConnected ? 'Connected' : 'Disconnected'}</div>
      <div>Last sequence: {lastSequenceId}</div>
      {error && <div>Error: {error}</div>}
    </div>
  )
}
```

The hook automatically handles connection management, chunk synchronization, and error handling for admin chat types in Mingo AI conversations.
