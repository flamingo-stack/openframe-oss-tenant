A React hook that provides chunk catchup functionality specifically for Mingo admin chat dialogs, wrapping the core chunk catchup system with API client integration for fetching historical chat chunks.

## Key Components

- **`useMingoChunkCatchup`**: Main hook that manages chunk catchup for admin chat dialogs
- **`fetchChunks`**: Callback function that retrieves chunks from the API with optional sequence ID filtering
- **Type exports**: Re-exports core chunk catchup types (`ChunkData`, `NatsMessageType`, `UseChunkCatchupReturn`)
- **`UseMingoChunkCatchupOptions`**: Configuration interface requiring dialog ID and chunk received callback

## Usage Example

```typescript
import { useMingoChunkCatchup } from './use-mingo-chunk-catchup'

function AdminChatDialog({ dialogId }: { dialogId: string }) {
  const handleChunkReceived = useCallback((chunk: ChunkData, messageType: NatsMessageType) => {
    console.log('Received chunk:', chunk)
    // Process the chunk data for UI updates
  }, [])

  const { 
    isConnected, 
    isLoading, 
    error, 
    reconnect 
  } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: handleChunkReceived
  })

  if (error) return <div>Error: {error}</div>
  if (isLoading) return <div>Loading chunks...</div>
  
  return (
    <div>
      Connection: {isConnected ? 'Connected' : 'Disconnected'}
      <button onClick={reconnect}>Reconnect</button>
    </div>
  )
}
```

The hook automatically handles fetching historical chunks from the `/chat/api/v1/dialogs/{id}/chunks` endpoint and manages real-time chunk streaming for admin chat types, providing a seamless chat synchronization experience.
