A React hook that provides chunk catchup functionality for Mingo chat dialogs, wrapping the core chunk catchup system with API-specific configuration for admin chat types.

## Key Components

- **`useMingoChunkCatchup`** - Main hook that configures and returns chunk catchup functionality
- **`fetchChunks`** - Async callback that retrieves chat chunks from the API endpoint
- **Type exports** - Re-exports core types (`ChunkData`, `NatsMessageType`, `UseChunkCatchupReturn`)
- **`UseMingoChunkCatchupOptions`** - Interface defining required dialog ID and chunk handler

## Usage Example

```typescript
import { useMingoChunkCatchup } from './use-mingo-chunk-catchup'

function ChatDialog({ dialogId }: { dialogId: string }) {
  const handleChunkReceived = (chunk: ChunkData, messageType: NatsMessageType) => {
    console.log('Received chunk:', chunk)
    // Process incoming chat chunk
  }

  const { 
    isConnected, 
    connectionError, 
    lastReceivedSequenceId 
  } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: handleChunkReceived
  })

  return (
    <div>
      <p>Connection status: {isConnected ? 'Connected' : 'Disconnected'}</p>
      {connectionError && <p>Error: {connectionError}</p>}
    </div>
  )
}
```

The hook automatically configures the core chunk catchup system to fetch admin chat chunks from `/chat/api/v1/dialogs/{dialogId}/chunks` and handles real-time message synchronization.
