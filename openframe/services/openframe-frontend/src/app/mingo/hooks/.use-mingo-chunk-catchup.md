A React hook that provides chunk catchup functionality specifically for Mingo AI admin chat interactions, built on top of the OpenFrame core chunk catchup system.

## Key Components

- **`useMingoChunkCatchup`** - Main hook that wraps the core chunk catchup functionality with Mingo-specific configuration
- **`fetchChunks`** - Callback function that retrieves chat chunks from the API with optional sequence ID filtering
- **Type exports** - Re-exports core types (`ChunkData`, `NatsMessageType`, `UseChunkCatchupReturn`) for convenience

## Usage Example

```typescript
import { useMingoChunkCatchup } from './use-mingo-chunk-catchup'
import type { ChunkData, NatsMessageType } from './use-mingo-chunk-catchup'

function MingoChat({ dialogId }: { dialogId: string }) {
  const handleChunkReceived = (chunk: ChunkData, messageType: NatsMessageType) => {
    console.log('Received chunk:', chunk)
    // Process the chunk data (e.g., update UI, store messages)
  }

  const { 
    isConnected, 
    connectionError, 
    catchupStatus 
  } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: handleChunkReceived
  })

  if (!isConnected) {
    return <div>Connecting to Mingo AI...</div>
  }

  return <div>Chat interface ready</div>
}
```

The hook automatically handles API communication, chunk sequencing, and real-time updates for Mingo AI admin chat sessions through the configured API client endpoint.
