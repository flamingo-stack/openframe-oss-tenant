A React hook that provides chunk catchup functionality for Mingo AI conversations by fetching missing chat chunks from the API and handling real-time message synchronization.

## Key Components

- **`useMingoChunkCatchup`** - Main hook that wraps the core chunk catchup functionality with Mingo-specific API integration
- **`fetchChunks`** - Callback function that retrieves chat chunks from the `/chat/api/v1/dialogs/{dialogId}/chunks` endpoint
- **Type exports** - Re-exports core types including `ChunkData`, `NatsMessageType`, and `UseChunkCatchupReturn`

## Usage Example

```typescript
import { useMingoChunkCatchup, type ChunkData, type NatsMessageType } from './use-mingo-chunk-catchup'

function ChatDialog({ dialogId }: { dialogId: string }) {
  const handleChunkReceived = useCallback((chunk: ChunkData, messageType: NatsMessageType) => {
    console.log('Received chunk:', chunk)
    // Process the chunk data for display
  }, [])

  const { 
    isConnected, 
    connectionStatus, 
    error 
  } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: handleChunkReceived
  })

  return (
    <div>
      <div>Status: {connectionStatus}</div>
      {error && <div>Error: {error}</div>}
    </div>
  )
}
```

The hook automatically handles fetching chunks for ADMIN chat type conversations and manages real-time synchronization through the core OpenFrame infrastructure.
