A React hook that provides Mingo-specific chunk catchup functionality for real-time chat dialogs, wrapping the core chunk catchup logic with API client integration.

## Key Components

- **`useMingoChunkCatchup`** - Main hook that handles fetching and processing chat chunks for a specific dialog
- **`fetchChunks`** - Callback function that retrieves chunks from the chat API with optional sequence filtering
- **Type exports** - Re-exports core types including `ChunkData`, `NatsMessageType`, and `UseChunkCatchupReturn`

## Usage Example

```typescript
import { useMingoChunkCatchup } from './use-mingo-chunk-catchup'

function ChatDialog({ dialogId }: { dialogId: string }) {
  const { isConnected, lastChunk, error } = useMingoChunkCatchup({
    dialogId,
    onChunkReceived: (chunk, messageType) => {
      console.log('Received chunk:', chunk)
      // Process the chunk data for display
    }
  })

  if (error) {
    return <div>Error: {error}</div>
  }

  return (
    <div>
      <div>Status: {isConnected ? 'Connected' : 'Disconnected'}</div>
      {lastChunk && <div>Last message: {lastChunk.content}</div>}
    </div>
  )
}
```

The hook automatically handles chunk fetching from the `/chat/api/v1/dialogs/{dialogId}/chunks` endpoint and integrates with the core chunk catchup system for real-time updates.
