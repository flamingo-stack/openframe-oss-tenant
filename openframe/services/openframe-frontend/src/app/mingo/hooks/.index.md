Entry point module that exports React hooks for integrating Mingo AI functionality into client applications. This barrel export provides a clean API surface for all Mingo-related React hooks.

## Key Components

- **`useMingoDialog`** - Hook for managing individual AI dialog interactions
- **`useMingoDialogs`** - Hook for handling multiple concurrent AI dialogs
- **`useMingoDialogSelection`** - Hook for managing dialog selection state
- **`useMingoChat`** - Hook for implementing AI chat functionality
- **`useMingoRealtimeSubscription`** - Hook for real-time AI response subscriptions

## Usage Example

```typescript
import { 
  useMingoChat, 
  useMingoDialog, 
  useMingoRealtimeSubscription 
} from '@mingo/hooks'

function AIAssistant() {
  const { sendMessage, messages, isLoading } = useMingoChat()
  const { openDialog, closeDialog } = useMingoDialog()
  const subscription = useMingoRealtimeSubscription({
    onMessage: (data) => console.log('Real-time update:', data)
  })

  return (
    <div>
      <button onClick={() => openDialog('help')}>
        Get AI Help
      </button>
      {/* Chat interface implementation */}
    </div>
  )
}
```

This module serves as the main entry point for consuming Mingo AI hooks in React applications, providing a centralized import location for all AI-related functionality.
