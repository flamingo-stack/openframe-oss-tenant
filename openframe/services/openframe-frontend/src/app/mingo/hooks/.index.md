A TypeScript module that exports React hooks for the Mingo AI assistant functionality, providing dialog management, chat interactions, and real-time communication capabilities within the Flamingo platform.

## Key Components

- **`useMingoDialog`** - Hook for managing individual Mingo dialog instances
- **`useMingoDialogs`** - Hook for managing multiple Mingo dialogs simultaneously  
- **`useMingoDialogSelection`** - Hook for handling dialog selection and navigation
- **`useMingoChat`** - Hook for Mingo chat functionality and message handling
- **`useMingoRealtimeSubscription`** - Hook for real-time updates and live communication with Mingo AI

## Usage Example

```typescript
import { 
  useMingoDialog, 
  useMingoChat, 
  useMingoRealtimeSubscription 
} from '@/hooks/mingo'

function MingoAssistant() {
  // Manage a single dialog instance
  const { dialog, openDialog, closeDialog } = useMingoDialog()
  
  // Handle chat interactions
  const { messages, sendMessage, isLoading } = useMingoChat()
  
  // Subscribe to real-time updates
  const { isConnected, subscription } = useMingoRealtimeSubscription({
    onMessage: (message) => console.log('Received:', message)
  })

  return (
    <div>
      <button onClick={openDialog}>Open Mingo</button>
      {/* Chat interface implementation */}
    </div>
  )
}
```

This module serves as the central export point for all Mingo AI-related React hooks, enabling developers to easily import and use Mingo's intelligent automation features throughout the OpenFrame platform.
