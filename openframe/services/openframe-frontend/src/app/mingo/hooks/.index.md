This file serves as the main export barrel for Mingo AI dialog and chat-related React hooks, providing a centralized entry point for importing all dialog management functionality.

## Key Components

- **`useMingoDialog`** - Hook for managing individual AI dialog instances
- **`useMingoDialogs`** - Hook for managing multiple AI dialogs simultaneously
- **`useMingoDialogSelection`** - Hook for handling dialog selection and switching between dialogs
- **`useMingoChat`** - Hook for AI chat functionality and message handling
- **`useMingoRealtimeSubscription`** - Hook for real-time updates and subscriptions to AI conversations

## Usage Example

```typescript
import { 
  useMingoDialog, 
  useMingoChat, 
  useMingoDialogs 
} from './index'

// Single dialog management
const { dialog, openDialog, closeDialog } = useMingoDialog()

// Multiple dialogs
const { dialogs, createDialog, removeDialog } = useMingoDialogs()

// Chat functionality
const { messages, sendMessage, isLoading } = useMingoChat(dialogId)
```

This barrel export pattern allows consumers to import all Mingo dialog hooks from a single location, improving developer experience and maintaining clean import statements across the OpenFrame platform.
