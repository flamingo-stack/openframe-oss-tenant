A barrel file that exports all custom hooks for the Mingo dialog system, providing a centralized entry point for dialog management, chat functionality, and real-time subscriptions.

## Key Components

- **`useMingoDialog`** - Hook for managing individual dialog instances
- **`useMingoDialogs`** - Hook for managing multiple dialogs simultaneously  
- **`useMingoDialogSelection`** - Hook for handling dialog selection state
- **`useMingoChat`** - Hook for chat functionality within dialogs
- **`useMingoRealtimeSubscription`** - Hook for real-time data subscriptions

## Usage Example

```typescript
import { 
  useMingoDialog, 
  useMingoDialogs, 
  useMingoChat 
} from './hooks'

function MyComponent() {
  // Manage a single dialog
  const { openDialog, closeDialog } = useMingoDialog()
  
  // Manage multiple dialogs
  const { dialogs, addDialog, removeDialog } = useMingoDialogs()
  
  // Handle chat functionality
  const { sendMessage, messages } = useMingoChat()
  
  return (
    <div>
      <button onClick={() => openDialog('support')}>
        Open Support Dialog
      </button>
    </div>
  )
}
```

This centralized export pattern allows developers to import any combination of Mingo dialog hooks from a single location, simplifying dependency management and providing a clean API surface for the dialog system.
