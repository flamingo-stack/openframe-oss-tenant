A TypeScript barrel file that provides centralized exports for all Mingo-related React hooks and utilities, simplifying imports throughout the application.

## Key Components

This index file exports the following composables and hooks:

- **`useMingoDialog`** - Hook for managing individual dialog interactions with Mingo AI
- **`useMingoDialogs`** - Hook for handling multiple simultaneous dialogs
- **`useMingoDialogSelection`** - Hook for managing dialog selection state and operations
- **`useMingoChat`** - Hook for chat functionality and message handling with Mingo AI
- **`useMingoRealtimeSubscription`** - Hook for managing real-time subscriptions to Mingo services

## Usage Example

```typescript
// Import individual hooks as needed
import { 
  useMingoChat, 
  useMingoDialog, 
  useMingoRealtimeSubscription 
} from './hooks'

// Use in a React component
function TechnicianAssistant() {
  const { messages, sendMessage } = useMingoChat()
  const { openDialog, closeDialog } = useMingoDialog()
  const { subscribe, unsubscribe } = useMingoRealtimeSubscription()
  
  // Component logic here
  return <div>...</div>
}
```

This barrel export pattern allows for clean, organized imports and better maintainability of the Mingo AI integration hooks across the OpenFrame platform.
