A TypeScript barrel file that exports Vue 3 composables for Mingo AI dialog and chat functionality within the Flamingo MSP platform.

## Key Components

- **`useMingoDialog`** - Single dialog management composable
- **`useMingoDialogs`** - Multiple dialog management composable  
- **`useMingoDialogSelection`** - Dialog selection state management
- **`useMingoChat`** - Chat interface and messaging functionality
- **`useMingoRealtimeSubscription`** - Real-time updates and subscriptions

## Usage Example

```typescript
import { 
  useMingoDialog, 
  useMingoDialogs, 
  useMingoChat 
} from '@/composables/mingo'

// Single dialog management
const { dialog, openDialog, closeDialog } = useMingoDialog()

// Multiple dialogs
const { dialogs, addDialog, removeDialog } = useMingoDialogs()

// Chat functionality
const { messages, sendMessage, isTyping } = useMingoChat()

// Real-time subscription
const { subscribe, unsubscribe, isConnected } = useMingoRealtimeSubscription()
```

This barrel export pattern provides a clean API for consuming Mingo AI features across Vue components in the OpenFrame platform, centralizing AI-powered technician assistance and chat capabilities.
