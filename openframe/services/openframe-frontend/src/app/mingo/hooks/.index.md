A barrel export file that provides centralized access to all Mingo AI-related React hooks for the Flamingo platform, simplifying imports across the application.

## Key Components

The file exports five core hooks for Mingo AI functionality:

- **`useMingoDialog`** - Manages individual AI dialog interactions
- **`useMingoDialogs`** - Handles multiple dialog instances and dialog management
- **`useMingoDialogSelection`** - Manages dialog selection state and user interactions
- **`useMingoChat`** - Provides AI chat functionality and message handling
- **`useMingoRealtimeSubscription`** - Manages real-time subscriptions for live AI updates

## Usage Example

Instead of importing from individual files, developers can import all Mingo hooks from this single entry point:

```typescript
import { 
  useMingoDialog, 
  useMingoChat, 
  useMingoRealtimeSubscription 
} from '@/hooks/mingo'

function AIAssistant() {
  const dialog = useMingoDialog()
  const chat = useMingoChat()
  const subscription = useMingoRealtimeSubscription()
  
  // Use the hooks for AI interactions
  return <div>AI Assistant Interface</div>
}
```

This barrel export pattern promotes cleaner imports and better code organization by providing a single source for all Mingo AI-related hooks in the OpenFrame platform.
