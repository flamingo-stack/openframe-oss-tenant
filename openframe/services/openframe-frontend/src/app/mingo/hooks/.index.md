A TypeScript module that serves as the main entry point for Mingo AI dialog and chat composables, providing a centralized export interface for Vue.js reactive utilities used in AI-powered conversations and real-time interactions.

## Key Components

- **useMingoDialog** - Composable for managing individual AI dialog instances
- **useMingoDialogs** - Composable for handling multiple dialog sessions simultaneously
- **useMingoDialogSelection** - Composable for managing dialog selection and switching between conversations
- **useMingoChat** - Core chat functionality composable for AI interactions
- **useMingoRealtimeSubscription** - Composable for real-time updates and live data synchronization

## Usage Example

```typescript
import { 
  useMingoDialog, 
  useMingoDialogs, 
  useMingoChat,
  useMingoRealtimeSubscription 
} from './index'

// Use individual dialog management
const { dialog, createDialog, closeDialog } = useMingoDialog()

// Handle multiple dialogs
const { dialogs, activeDialog, switchDialog } = useMingoDialogs()

// Set up chat functionality
const { messages, sendMessage, isLoading } = useMingoChat()

// Subscribe to real-time updates
const { subscribe, unsubscribe, data } = useMingoRealtimeSubscription()
```

This barrel export pattern provides a clean API surface for consuming Mingo AI dialog functionality throughout the Flamingo/OpenFrame platform, enabling developers to import only the composables they need while maintaining consistent interfaces across the application.
