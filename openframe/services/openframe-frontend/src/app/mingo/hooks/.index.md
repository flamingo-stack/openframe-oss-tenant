A module index file that provides centralized access to all Mingo-related React hooks for dialog management, chat functionality, and real-time subscriptions in the Flamingo platform.

## Key Components

This index file exports the following hooks:

- **`useMingoDialog`** - Hook for managing individual dialog instances
- **`useMingoDialogs`** - Hook for managing multiple dialogs simultaneously 
- **`useMingoDialogSelection`** - Hook for handling dialog selection state
- **`useMingoChat`** - Hook for Mingo AI chat functionality
- **`useMingoRealtimeSubscription`** - Hook for real-time data subscriptions

## Usage Example

Import any of the Mingo hooks directly from this module:

```typescript
import { 
  useMingoDialog, 
  useMingoChat, 
  useMingoRealtimeSubscription 
} from './mingo-hooks'

function TechnicianDashboard() {
  const dialog = useMingoDialog('ticket-analysis')
  const chat = useMingoChat()
  const subscription = useMingoRealtimeSubscription('ticket-updates')
  
  // Use the hooks for AI-powered MSP operations
  return (
    <div>
      {/* Your component implementation */}
    </div>
  )
}
```

This barrel export pattern simplifies imports and provides a clean API surface for consuming Mingo AI functionality throughout the OpenFrame platform.
