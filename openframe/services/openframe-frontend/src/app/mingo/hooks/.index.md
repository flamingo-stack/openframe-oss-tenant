A centralized export module that provides access to all Mingo AI-related Vue composables for the Flamingo platform. This barrel export simplifies imports by allowing consumers to access all Mingo functionality from a single entry point.

## Key Components

- **useMingoDialog** - Composable for managing individual Mingo AI dialog interactions
- **useMingoDialogs** - Composable for handling multiple concurrent Mingo dialogs
- **useMingoDialogSelection** - Composable for managing dialog selection state and operations
- **useMingoChat** - Composable for Mingo AI chat functionality and message handling
- **useMingoRealtimeSubscription** - Composable for real-time subscription management with Mingo services

## Usage Example

```typescript
// Import specific composables
import { useMingoChat, useMingoDialog } from '@/composables/mingo'

// Or import multiple composables at once
import { 
  useMingoDialogs, 
  useMingoRealtimeSubscription 
} from '@/composables/mingo'

// Use in Vue component
export default defineComponent({
  setup() {
    const { sendMessage, messages } = useMingoChat()
    const { openDialog, closeDialog } = useMingoDialog()
    
    return {
      sendMessage,
      messages,
      openDialog,
      closeDialog
    }
  }
})
```

This module serves as the main interface for integrating Mingo AI capabilities into Vue applications within the OpenFrame platform.
