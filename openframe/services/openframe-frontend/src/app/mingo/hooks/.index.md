A TypeScript module that serves as the main entry point for Mingo AI-related React hooks, providing a centralized export interface for dialog management, chat functionality, and real-time subscriptions within the Flamingo platform.

## Key Components

- **useMingoDialog** - Hook for managing individual AI dialog interactions
- **useMingoDialogs** - Hook for handling multiple concurrent AI dialogs
- **useMingoDialogSelection** - Hook for managing dialog selection and navigation
- **useMingoChat** - Hook for AI chat functionality and message handling
- **useMingoRealtimeSubscription** - Hook for real-time data subscriptions and updates

## Usage Example

```typescript
import { 
  useMingoDialog, 
  useMingoChat, 
  useMingoRealtimeSubscription 
} from '@/hooks/mingo'

function AIAssistant() {
  const { openDialog, closeDialog } = useMingoDialog()
  const { sendMessage, messages } = useMingoChat()
  const { subscribe, data } = useMingoRealtimeSubscription()

  const handleAIQuery = async (query: string) => {
    const response = await sendMessage(query)
    openDialog({ content: response })
  }

  return (
    <div>
      <button onClick={() => handleAIQuery("Help with MSP setup")}>
        Ask Mingo AI
      </button>
    </div>
  )
}
```

This barrel export pattern provides a clean API surface for consuming Mingo AI functionality throughout the Flamingo/OpenFrame application, enabling developers to import multiple related hooks from a single location.
