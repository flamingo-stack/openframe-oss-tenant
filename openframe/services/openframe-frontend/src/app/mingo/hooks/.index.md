A collection of React hooks for integrating Mingo AI functionality into client applications. This module serves as the main entry point for dialog management, chat interfaces, and real-time subscription capabilities.

## Key Components

- **useMingoDialog** - Hook for managing individual dialog instances with Mingo AI
- **useMingoDialogs** - Hook for handling multiple dialog sessions simultaneously
- **useMingoDialogSelection** - Hook for managing dialog selection and navigation
- **useMingoChat** - Hook for implementing chat interfaces with Mingo AI
- **useMingoRealtimeSubscription** - Hook for real-time data subscriptions and updates

## Usage Example

```typescript
import { 
  useMingoDialog, 
  useMingoChat, 
  useMingoRealtimeSubscription 
} from '@flamingo/mingo-hooks';

function MyComponent() {
  // Start a dialog session
  const { dialog, isLoading } = useMingoDialog({
    context: 'support-ticket',
    userId: 'user123'
  });
  
  // Handle chat interactions
  const { messages, sendMessage } = useMingoChat({
    sessionId: dialog?.id
  });
  
  // Subscribe to real-time updates
  useMingoRealtimeSubscription({
    channel: 'notifications',
    onUpdate: (data) => console.log('New update:', data)
  });
  
  return (
    <div>
      {/* Chat interface implementation */}
    </div>
  );
}
```
