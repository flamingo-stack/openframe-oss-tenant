A centralized export module that provides access to all Mingo AI-related React hooks for dialog management, chat functionality, and realtime subscriptions in the OpenFrame platform.

## Key Components

- **useMingoDialog** - Hook for managing individual AI dialog interactions
- **useMingoDialogs** - Hook for handling multiple dialog sessions
- **useMingoDialogSelection** - Hook for managing dialog selection state
- **useMingoChat** - Hook for chat functionality with Mingo AI
- **useMingoRealtimeSubscription** - Hook for real-time subscription management

## Usage Example

```typescript
import { 
  useMingoDialog, 
  useMingoChat, 
  useMingoDialogs 
} from '@/hooks/mingo'

function MingoInterface() {
  const { dialog, openDialog } = useMingoDialog()
  const { messages, sendMessage } = useMingoChat()
  const { dialogs, createDialog } = useMingoDialogs()

  return (
    <div>
      <button onClick={() => openDialog('support')}>
        Open Support Dialog
      </button>
      <button onClick={() => createDialog('analysis')}>
        New Analysis Dialog
      </button>
    </div>
  )
}
```

This barrel export pattern provides a clean import interface for all Mingo AI hooks, enabling developers to import multiple related hooks from a single module path.
