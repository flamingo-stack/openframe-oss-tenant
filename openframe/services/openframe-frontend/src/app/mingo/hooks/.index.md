Main entry point for Mingo AI composables, providing access to dialog management, chat functionality, and realtime subscription hooks for Vue 3 applications.

## Key Components

### Dialog Management
- `useMingoDialog` - Single dialog instance management
- `useMingoDialogs` - Multiple dialog orchestration  
- `useMingoDialogSelection` - Dialog selection and filtering utilities

### Communication & Data
- `useMingoChat` - Chat interface and message handling
- `useMingoRealtimeSubscription` - WebSocket/SSE subscription management

## Usage Example

```typescript
import { 
  useMingoDialog, 
  useMingoDialogs, 
  useMingoChat,
  useMingoRealtimeSubscription 
} from '@flamingo/mingo-composables'

// Single dialog management
const { openDialog, closeDialog, isOpen } = useMingoDialog()

// Multiple dialogs
const { dialogs, createDialog, removeDialog } = useMingoDialogs()

// Chat functionality
const { messages, sendMessage, isTyping } = useMingoChat()

// Realtime updates
const { subscribe, unsubscribe, connectionStatus } = useMingoRealtimeSubscription()
```

This barrel export simplifies imports and provides a clean API surface for integrating Mingo AI capabilities into Vue applications across the Flamingo/OpenFrame ecosystem.
