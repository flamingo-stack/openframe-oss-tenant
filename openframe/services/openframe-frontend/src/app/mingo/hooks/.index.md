A centralized export module that provides access to all Mingo AI-related React hooks for the Flamingo platform. This barrel export simplifies imports by consolidating all Mingo hooks into a single entry point.

## Key Components

- **useMingoDialog** - Hook for managing individual Mingo AI dialog interactions
- **useMingoDialogs** - Hook for handling multiple concurrent Mingo AI dialogs
- **useMingoDialogSelection** - Hook for managing dialog selection and navigation
- **useMingoChat** - Hook for Mingo AI chat functionality and message handling
- **useMingoRealtimeSubscription** - Hook for real-time subscription management with Mingo AI

## Usage Example

```typescript
import { 
  useMingoDialog, 
  useMingoChat, 
  useMingoRealtimeSubscription 
} from './path/to/mingo-hooks'

function MingoComponent() {
  const dialog = useMingoDialog()
  const chat = useMingoChat()
  const subscription = useMingoRealtimeSubscription()

  // Use the hooks for AI-powered MSP operations
  return <div>Mingo AI Interface</div>
}
```

This module serves as the main interface for integrating Mingo AI capabilities into Flamingo's MSP platform components, providing technicians with intelligent automation tools through a unified hook-based API.
