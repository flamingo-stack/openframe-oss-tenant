This file serves as the main entry point for the Mingo AI hooks module, providing a centralized export of all custom React hooks used for AI-powered interactions in the Flamingo platform.

## Key Components

- **`useMingoDialog`** - Hook for managing individual AI dialog interactions
- **`useMingoDialogs`** - Hook for handling multiple concurrent AI dialogs
- **`useMingoDialogSelection`** - Hook for managing dialog selection and switching
- **`useMingoChat`** - Hook for AI chat functionality and message handling
- **`useMingoRealtimeSubscription`** - Hook for real-time AI response subscriptions

## Usage Example

```typescript
import { 
  useMingoDialog, 
  useMingoChat, 
  useMingoRealtimeSubscription 
} from './hooks'

function AIAssistant() {
  const { openDialog, closeDialog } = useMingoDialog()
  const { sendMessage, messages } = useMingoChat()
  const { subscribe } = useMingoRealtimeSubscription()

  const handleAIRequest = async () => {
    const dialog = await openDialog('technical-support')
    await sendMessage('Help me troubleshoot this issue')
    subscribe(dialog.id, (response) => {
      console.log('AI response:', response)
    })
  }

  return (
    <button onClick={handleAIRequest}>
      Ask Mingo AI
    </button>
  )
}
```

This barrel export pattern allows consumers to import any Mingo AI hook from a single location, simplifying the import statements throughout the application.
