A centralized export module that provides access to all Mingo AI dialog and chat composables for Vue.js applications. This barrel export simplifies imports and maintains a clean public API for the Mingo AI integration layer.

## Key Components

- **useMingoDialog** - Single dialog management composable
- **useMingoDialogs** - Multiple dialogs management composable  
- **useMingoDialogSelection** - Dialog selection and filtering composable
- **useMingoChat** - Chat interface and messaging composable
- **useMingoRealtimeSubscription** - Real-time updates subscription composable

## Usage Example

```typescript
// Import individual composables as needed
import { 
  useMingoDialog, 
  useMingoChat, 
  useMingoRealtimeSubscription 
} from '@/composables/mingo'

// In your Vue component
export default {
  setup() {
    const { openDialog, closeDialog } = useMingoDialog()
    const { sendMessage, messages } = useMingoChat()
    const { subscribe, unsubscribe } = useMingoRealtimeSubscription()
    
    return {
      openDialog,
      sendMessage,
      messages,
      subscribe
    }
  }
}
```

This module serves as the main entry point for all Mingo AI-related composables, enabling clean imports and better code organization across the OpenFrame platform.
