A TypeScript module that provides centralized exports for Mingo AI dialog and chat functionality hooks. This serves as the main entry point for consuming Mingo dialog management composables throughout the OpenFrame platform.

## Key Components

- **useMingoDialog** - Single dialog instance management hook
- **useMingoDialogs** - Multiple dialog instances management hook  
- **useMingoDialogSelection** - Dialog selection and filtering utilities
- **useMingoChat** - Chat interface and message handling hook
- **useMingoRealtimeSubscription** - Real-time subscription management for live updates

## Usage Example

```typescript
import { 
  useMingoDialog, 
  useMingoDialogs, 
  useMingoChat,
  useMingoRealtimeSubscription 
} from './mingo-hooks'

// Single dialog management
const { dialog, openDialog, closeDialog } = useMingoDialog()

// Multiple dialogs with selection
const { dialogs, selectedDialogs } = useMingoDialogs()
const { selectDialog, clearSelection } = useMingoDialogSelection()

// Chat functionality
const { messages, sendMessage, isTyping } = useMingoChat()

// Real-time updates
const { subscribe, unsubscribe, isConnected } = useMingoRealtimeSubscription()
```

This barrel export pattern ensures clean imports and maintains a consistent API surface for Mingo AI dialog interactions across the Flamingo MSP platform.
