This module serves as the main entry point for Flamingo's Mingo AI hooks library, providing a centralized export interface for all AI-powered dialog and chat functionality.

## Key Components

- **`useMingoDialog`** - Hook for managing individual AI dialog interactions
- **`useMingoDialogs`** - Hook for handling multiple concurrent AI dialogs
- **`useMingoDialogSelection`** - Hook for managing dialog selection state and operations
- **`useMingoChat`** - Hook for real-time AI chat functionality with Mingo
- **`useMingoRealtimeSubscription`** - Hook for managing real-time data subscriptions in AI contexts

## Usage Example

```typescript
import { 
  useMingoDialog, 
  useMingoChat, 
  useMingoDialogs,
  useMingoDialogSelection,
  useMingoRealtimeSubscription 
} from '@flamingo/mingo-hooks'

function AIAssistantComponent() {
  // Single dialog interaction
  const { openDialog, closeDialog } = useMingoDialog()
  
  // Multiple dialog management
  const { dialogs, createDialog } = useMingoDialogs()
  
  // Chat with Mingo AI
  const { sendMessage, messages } = useMingoChat()
  
  // Real-time AI updates
  const { subscribe, data } = useMingoRealtimeSubscription()
  
  // Dialog selection management
  const { selectedDialog, selectDialog } = useMingoDialogSelection()
  
  return (
    <div>
      {/* AI assistant UI components */}
    </div>
  )
}
```

This barrel export pattern enables clean imports and consistent API access across the Flamingo platform's AI-powered MSP tools.
