A centralized export module that exposes all Mingo AI-related React hooks for dialog management, chat functionality, and real-time communication within the Flamingo platform.

## Key Components

- **`useMingoDialog`** - Hook for managing individual AI dialog instances
- **`useMingoDialogs`** - Hook for managing multiple AI dialogs and dialog state
- **`useMingoDialogSelection`** - Hook for handling dialog selection and focus management
- **`useMingoChat`** - Hook for AI chat interactions and message handling
- **`useMingoRealtimeSubscription`** - Hook for real-time subscription management with Mingo AI

## Usage Example

```typescript
import { 
  useMingoDialog, 
  useMingoDialogs, 
  useMingoChat 
} from '@/hooks/mingo'

function MingoInterface() {
  // Manage multiple dialogs
  const { dialogs, createDialog, closeDialog } = useMingoDialogs()
  
  // Handle chat functionality
  const { messages, sendMessage, isLoading } = useMingoChat()
  
  // Manage individual dialog
  const { dialog, isOpen, open, close } = useMingoDialog('support-chat')
  
  return (
    <div>
      {/* Your Mingo AI interface components */}
    </div>
  )
}
```

This barrel export pattern simplifies imports and provides a clean API surface for integrating Mingo AI capabilities across the OpenFrame platform.
