A centralized export module that provides access to all Mingo AI-related React hooks for the Flamingo MSP platform. This barrel export simplifies imports by allowing developers to access all Mingo functionality from a single entry point.

## Key Components

- **useMingoDialog** - Hook for managing individual AI dialog interactions
- **useMingoDialogs** - Hook for handling multiple concurrent AI dialogs
- **useMingoDialogSelection** - Hook for managing dialog selection and navigation
- **useMingoChat** - Hook for AI chat functionality and message handling
- **useMingoRealtimeSubscription** - Hook for real-time AI updates and subscriptions

## Usage Example

```typescript
// Import all hooks from the main entry point
import {
  useMingoDialog,
  useMingoDialogs,
  useMingoChat,
  useMingoRealtimeSubscription
} from '@/hooks/mingo'

function AIAssistantComponent() {
  const { startDialog, closeDialog } = useMingoDialog()
  const { activeDialogs } = useMingoDialogs()
  const { sendMessage, messages } = useMingoChat()
  const { subscribe } = useMingoRealtimeSubscription()

  // Use hooks for AI interactions
  const handleTechnicianAssist = () => {
    startDialog('technician-support')
  }

  return (
    <div>
      <button onClick={handleTechnicianAssist}>
        Get Mingo AI Help
      </button>
    </div>
  )
}
```

This barrel export pattern follows OpenFrame's modular architecture, making it easy to import and use Mingo AI capabilities throughout the MSP platform.
