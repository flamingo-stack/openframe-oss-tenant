This file serves as the main entry point for exporting React hooks related to Mingo AI functionality in the Flamingo platform.

## Key Components

The module exports the following custom React hooks:

- **`useMingoDialog`** - Manages individual dialog interactions with Mingo AI
- **`useMingoDialogs`** - Handles multiple dialog instances and dialog management  
- **`useMingoDialogSelection`** - Manages dialog selection state and operations
- **`useMingoChat`** - Provides chat interface functionality with Mingo AI
- **`useMingoRealtimeSubscription`** - Manages real-time subscriptions for live updates

## Usage Example

```typescript
import { 
  useMingoDialog, 
  useMingoChat, 
  useMingoRealtimeSubscription 
} from '@/hooks/mingo'

function MingoAssistant() {
  const { openDialog, closeDialog } = useMingoDialog()
  const { messages, sendMessage } = useMingoChat()
  const { subscribe, unsubscribe } = useMingoRealtimeSubscription()

  // Use hooks to interact with Mingo AI
  const handleStartChat = () => {
    openDialog('support-chat')
    subscribe('chat-updates')
  }

  return (
    <div>
      <button onClick={handleStartChat}>
        Start Mingo Chat
      </button>
    </div>
  )
}
```

This barrel export pattern allows consumers to import all Mingo-related hooks from a single location, improving developer experience and maintaining clean import statements throughout the application.
