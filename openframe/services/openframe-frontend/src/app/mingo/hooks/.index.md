This file serves as the main entry point for Flamingo's Mingo AI dialog and chat hooks, providing a centralized export interface for React components that need AI-powered conversation functionality.

## Key Components

- **`useMingoDialog`** - Hook for managing individual AI dialog instances
- **`useMingoDialogs`** - Hook for managing multiple AI dialog sessions 
- **`useMingoDialogSelection`** - Hook for handling dialog selection and navigation
- **`useMingoChat`** - Hook for AI chat functionality and message handling
- **`useMingoRealtimeSubscription`** - Hook for real-time updates and subscriptions to AI conversations

## Usage Example

```typescript
import { 
  useMingoDialog, 
  useMingoChat, 
  useMingoRealtimeSubscription 
} from '@flamingo/mingo-hooks'

function AIAssistant() {
  const { dialog, openDialog, closeDialog } = useMingoDialog()
  const { messages, sendMessage, isLoading } = useMingoChat()
  const { isConnected } = useMingoRealtimeSubscription()

  const handleUserMessage = async (content: string) => {
    await sendMessage({
      content,
      type: 'user'
    })
  }

  return (
    <div>
      <MingoChat 
        messages={messages}
        onSendMessage={handleUserMessage}
        isLoading={isLoading}
        isConnected={isConnected}
      />
    </div>
  )
}
```

This barrel export pattern allows developers to import all Mingo AI hooks from a single location, simplifying integration with Flamingo's AI-powered MSP platform features.
