A barrel export file that provides centralized access to Mingo AI-related React hooks for the OpenFrame platform. This file serves as the main entry point for importing various Mingo functionality including dialogs, chat, and real-time subscriptions.

## Key Components

- **`useMingoDialog`** - Hook for managing individual Mingo AI dialog interactions
- **`useMingoDialogs`** - Hook for handling multiple dialog instances or dialog management
- **`useMingoDialogSelection`** - Hook for managing dialog selection state and operations
- **`useMingoChat`** - Hook for Mingo AI chat functionality and message handling
- **`useMingoRealtimeSubscription`** - Hook for real-time data subscriptions and updates

## Usage Example

```typescript
// Import specific hooks as needed
import { 
  useMingoDialog, 
  useMingoChat, 
  useMingoRealtimeSubscription 
} from './index'

// Use in a React component
function MingoInterface() {
  const dialog = useMingoDialog()
  const chat = useMingoChat()
  const subscription = useMingoRealtimeSubscription()
  
  // Component implementation
  return (
    <div>
      {/* Mingo AI interface components */}
    </div>
  )
}

// Or import all at once
import * as MingoHooks from './index'
```

This barrel export pattern allows for clean imports and better organization of the Mingo AI hook ecosystem within the OpenFrame MSP platform.
