Centralized export module for Mingo AI dialog and chat functionality hooks. This file provides a single import point for all Mingo-related React hooks used throughout the application.

## Key Components

- **useMingoDialog** - Hook for managing individual dialog interactions
- **useMingoDialogs** - Hook for managing multiple dialogs and dialog state
- **useMingoDialogSelection** - Hook for handling dialog selection logic
- **useMingoChat** - Hook for chat functionality and message management
- **useMingoRealtimeSubscription** - Hook for real-time data subscriptions and updates

## Usage Example

```typescript
import { 
  useMingoDialog, 
  useMingoChat, 
  useMingoRealtimeSubscription 
} from './hooks'

function ChatComponent() {
  const dialog = useMingoDialog()
  const { messages, sendMessage } = useMingoChat()
  const subscription = useMingoRealtimeSubscription()
  
  return (
    <div>
      {/* Chat implementation */}
    </div>
  )
}
```

This barrel export pattern simplifies imports and provides better organization for the Mingo AI integration layer within the Flamingo platform.
