Main export barrel for Mingo AI composables, providing centralized access to dialog management, chat functionality, and realtime subscription hooks for Vue applications.

## Key Components

- **`useMingoDialog`** - Individual dialog management composable
- **`useMingoDialogs`** - Multiple dialogs management composable  
- **`useMingoDialogSelection`** - Dialog selection state management
- **`useMingoChat`** - Chat interface composable for Mingo AI interactions
- **`useMingoRealtimeSubscription`** - Real-time data subscription management

## Usage Example

```typescript
// Import individual composables as needed
import { 
  useMingoDialog, 
  useMingoChat, 
  useMingoRealtimeSubscription 
} from '@/composables/mingo'

// In your Vue component
export default defineComponent({
  setup() {
    const { openDialog, closeDialog } = useMingoDialog()
    const { sendMessage, messages } = useMingoChat()
    const { subscribe, unsubscribe } = useMingoRealtimeSubscription()
    
    return {
      openDialog,
      sendMessage,
      messages,
      subscribe
    }
  }
})
```

This barrel export pattern simplifies imports and provides a clean API surface for Mingo AI functionality throughout the OpenFrame platform.
