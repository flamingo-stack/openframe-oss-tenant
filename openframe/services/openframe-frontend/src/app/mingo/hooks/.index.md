Main entry point for the Mingo AI composables library, providing a unified export interface for all dialog and chat-related Vue composables used in the Flamingo platform.

## Key Components

- **`useMingoDialog`** - Single dialog management composable for individual AI conversations
- **`useMingoDialogs`** - Multi-dialog state management for handling multiple concurrent AI sessions
- **`useMingoDialogSelection`** - Dialog selection and navigation utilities for switching between conversations
- **`useMingoChat`** - Core chat functionality composable for AI message handling and conversation flow
- **`useMingoRealtimeSubscription`** - Real-time subscription management for live AI responses and updates

## Usage Example

```typescript
// Import individual composables
import { useMingoChat, useMingoDialog } from '@flamingo/mingo-composables'

// Or import multiple composables
import { 
  useMingoDialogs, 
  useMingoDialogSelection,
  useMingoRealtimeSubscription 
} from '@flamingo/mingo-composables'

// Use in Vue component
export default defineComponent({
  setup() {
    const { sendMessage, messages } = useMingoChat()
    const { activeDialog } = useMingoDialog()
    
    return {
      sendMessage,
      messages,
      activeDialog
    }
  }
})
```

This barrel export pattern provides a clean, organized API surface for consuming Mingo AI functionality across Vue applications in the Flamingo ecosystem.
