Index file that serves as the main entry point for Mingo-related React hooks, providing a centralized export for dialog management, chat functionality, and real-time subscription features.

## Key Components

**Dialog Management Hooks:**
- `useMingoDialog` - Single dialog state management
- `useMingoDialogs` - Multiple dialogs orchestration  
- `useMingoDialogSelection` - Dialog selection handling

**Chat & Real-time Hooks:**
- `useMingoChat` - Chat interface integration
- `useMingoRealtimeSubscription` - Real-time data subscriptions

## Usage Example

```typescript
import { 
  useMingoDialog, 
  useMingoDialogs, 
  useMingoChat,
  useMingoRealtimeSubscription 
} from './mingo-hooks'

function MyComponent() {
  // Single dialog management
  const { isOpen, open, close } = useMingoDialog()
  
  // Multiple dialogs coordination
  const { dialogs, openDialog, closeAll } = useMingoDialogs()
  
  // Chat functionality
  const { messages, sendMessage, isConnected } = useMingoChat()
  
  // Real-time updates
  const { data, subscribe, unsubscribe } = useMingoRealtimeSubscription()
  
  return (
    <div>
      <button onClick={() => open()}>Open Dialog</button>
      <button onClick={() => sendMessage('Hello Mingo!')}>Send Chat</button>
    </div>
  )
}
```

This barrel export pattern enables clean imports and better tree-shaking while maintaining a consistent API surface for Mingo's AI-powered MSP platform integrations.
