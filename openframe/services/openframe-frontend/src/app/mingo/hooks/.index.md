A centralized export module that provides access to all Mingo AI-related React hooks for dialog management, chat functionality, and real-time subscriptions in the Flamingo platform.

## Key Components

- **`useMingoDialog`** - Hook for managing individual AI dialog instances
- **`useMingoDialogs`** - Hook for handling multiple AI dialogs simultaneously  
- **`useMingoDialogSelection`** - Hook for managing dialog selection state
- **`useMingoChat`** - Hook for AI chat interactions and message handling
- **`useMingoRealtimeSubscription`** - Hook for real-time AI event subscriptions

## Usage Example

```typescript
import { 
  useMingoDialog, 
  useMingoChat, 
  useMingoRealtimeSubscription 
} from './hooks'

function AIAssistant() {
  const { dialog, openDialog, closeDialog } = useMingoDialog()
  const { messages, sendMessage } = useMingoChat()
  const { isConnected } = useMingoRealtimeSubscription()

  return (
    <div>
      <button onClick={openDialog}>
        Open Mingo AI {isConnected ? '🟢' : '🔴'}
      </button>
      {dialog && (
        <ChatInterface 
          messages={messages}
          onSend={sendMessage}
        />
      )}
    </div>
  )
}
```

This barrel export pattern simplifies importing Mingo AI hooks throughout the OpenFrame platform while maintaining clean separation of concerns for different AI interaction patterns.
