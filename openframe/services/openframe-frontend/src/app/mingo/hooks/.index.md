A central export hub that provides access to all Mingo AI dialog and chat-related composables for Vue.js applications. This file consolidates the main reactive utilities for managing AI conversations, real-time subscriptions, and dialog interactions within the Flamingo platform.

## Key Components

- **`useMingoDialog`** - Core composable for managing individual AI dialog interactions
- **`useMingoDialogs`** - Manages multiple concurrent AI dialogs and their state
- **`useMingoDialogSelection`** - Handles dialog selection and navigation between conversations
- **`useMingoChat`** - Provides chat interface functionality and message handling
- **`useMingoRealtimeSubscription`** - Manages real-time updates and live data synchronization for AI interactions

## Usage Example

```typescript
// Import specific composables as needed
import { useMingoChat, useMingoDialog } from '@/composables'

// In a Vue component
export default {
  setup() {
    const { sendMessage, messages } = useMingoChat()
    const { openDialog, closeDialog } = useMingoDialog()
    
    const handleAiQuery = async (query: string) => {
      const dialog = await openDialog()
      await sendMessage(query, dialog.id)
    }
    
    return {
      sendMessage,
      messages,
      handleAiQuery
    }
  }
}
```

This index file follows the common pattern of barrel exports, making it easy to import multiple Mingo AI utilities from a single location while maintaining clean separation of concerns across individual composable files.
