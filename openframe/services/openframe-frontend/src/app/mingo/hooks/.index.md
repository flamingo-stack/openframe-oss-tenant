This file serves as the main export entry point for Mingo AI React hooks, providing a centralized interface for dialog management, chat functionality, and real-time subscription capabilities within the Flamingo platform.

## Key Components

- **`useMingoDialog`** - Hook for managing individual AI dialog instances
- **`useMingoDialogs`** - Hook for managing multiple AI dialogs simultaneously
- **`useMingoDialogSelection`** - Hook for handling dialog selection state and interactions
- **`useMingoChat`** - Hook for AI chat functionality and message handling
- **`useMingoRealtimeSubscription`** - Hook for real-time event subscriptions and updates

## Usage Example

```typescript
import { 
  useMingoDialog, 
  useMingoChat, 
  useMingoRealtimeSubscription 
} from '@flamingo/mingo-hooks'

function AIAssistantComponent() {
  // Manage a single dialog instance
  const { dialog, openDialog, closeDialog } = useMingoDialog('support-ticket')
  
  // Handle chat interactions
  const { messages, sendMessage, isLoading } = useMingoChat()
  
  // Subscribe to real-time updates
  useMingoRealtimeSubscription('ticket-updates', (update) => {
    console.log('Received update:', update)
  })
  
  return (
    <div>
      <button onClick={() => openDialog()}>
        Open AI Assistant
      </button>
      {/* Chat interface components */}
    </div>
  )
}
```

This barrel export pattern allows developers to import multiple Mingo AI hooks from a single location while maintaining clean module organization.
