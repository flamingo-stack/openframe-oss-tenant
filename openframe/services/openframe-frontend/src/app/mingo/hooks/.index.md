Main entry point for Mingo AI dialog and chat composables, providing a unified interface for AI-powered user interactions and real-time communication features.

## Key Components

This barrel export module provides access to five core composables:

- **`useMingoDialog`** - Manages individual AI dialog instances
- **`useMingoDialogs`** - Handles multiple dialog sessions and state management
- **`useMingoDialogSelection`** - Manages dialog selection and navigation
- **`useMingoChat`** - Provides AI chat functionality and message handling
- **`useMingoRealtimeSubscription`** - Enables real-time updates and live data synchronization

## Usage Example

```typescript
import { 
  useMingoDialog, 
  useMingoChat, 
  useMingoRealtimeSubscription 
} from './composables'

// Initialize AI chat functionality
const { sendMessage, messages, isLoading } = useMingoChat()

// Set up real-time subscription for live updates
const { subscribe, unsubscribe, isConnected } = useMingoRealtimeSubscription()

// Create a new dialog instance
const { openDialog, closeDialog } = useMingoDialog()

// Send a message to Mingo AI
await sendMessage('Help me troubleshoot this network issue')

// Subscribe to real-time technician updates
subscribe('technician-updates', (data) => {
  console.log('New update:', data)
})
```

These composables work together to power the Mingo AI assistant experience, enabling technicians to interact with AI-driven support tools and receive real-time updates across the Flamingo platform.
