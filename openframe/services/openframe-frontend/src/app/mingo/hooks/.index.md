This file serves as the main entry point for Mingo AI React hooks, providing a centralized export interface for dialog management, chat functionality, and realtime subscriptions.

## Key Components

- **`useMingoDialog`** - Hook for managing individual dialog instances
- **`useMingoDialogs`** - Hook for managing multiple dialogs simultaneously
- **`useMingoDialogSelection`** - Hook for handling dialog selection and navigation
- **`useMingoChat`** - Hook for integrating Mingo AI chat functionality
- **`useMingoRealtimeSubscription`** - Hook for managing realtime data subscriptions

## Usage Example

```typescript
import { 
  useMingoDialog, 
  useMingoDialogs, 
  useMingoChat,
  useMingoRealtimeSubscription 
} from '@flamingo/mingo-hooks'

function MyComponent() {
  // Single dialog management
  const { open, close, isOpen } = useMingoDialog()
  
  // Multiple dialogs
  const { dialogs, createDialog, removeDialog } = useMingoDialogs()
  
  // Chat integration
  const { messages, sendMessage, isTyping } = useMingoChat()
  
  // Realtime updates
  const { data, isConnected } = useMingoRealtimeSubscription('tickets')
  
  return (
    <div>
      <button onClick={() => open()}>Open Mingo Dialog</button>
      <button onClick={() => sendMessage('Hello Mingo!')}>Send Message</button>
    </div>
  )
}
```

This package provides the essential React hooks for integrating Mingo AI's intelligent automation capabilities into MSP platform interfaces.
