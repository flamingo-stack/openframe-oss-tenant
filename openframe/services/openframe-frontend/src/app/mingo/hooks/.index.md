A centralized export module that provides access to all Mingo AI dialog and chat system hooks for the Flamingo MSP platform.

## Key Components

This barrel export file exposes the following React hooks:

- **`useMingoDialog`** - Manages individual AI dialog interactions
- **`useMingoDialogs`** - Handles multiple dialog instances and state management
- **`useMingoDialogSelection`** - Controls dialog selection and navigation
- **`useMingoChat`** - Provides chat functionality with Mingo AI assistant
- **`useMingoRealtimeSubscription`** - Enables real-time updates and notifications

## Usage Example

Import any of the Mingo AI hooks from this central module:

```typescript
import { 
  useMingoChat, 
  useMingoDialog,
  useMingoRealtimeSubscription 
} from './hooks'

// In your component
function TechnicianDashboard() {
  const { sendMessage, messages, isLoading } = useMingoChat()
  const { openDialog } = useMingoDialog()
  const { subscribe } = useMingoRealtimeSubscription()

  // Use Mingo AI for intelligent automation
  const handleTicketQuery = async (query: string) => {
    await sendMessage(query)
  }

  return (
    // Your component JSX
  )
}
```

This module serves as the main entry point for integrating Mingo AI capabilities into MSP workflows, enabling technicians to leverage AI-powered automation across the OpenFrame platform.
