A centralized export module that provides React hooks for integrating Mingo AI functionality into Flamingo applications. This file serves as the main entry point for accessing dialog management, chat interactions, and real-time subscription capabilities.

## Key Components

- **`useMingoDialog`** - Hook for managing individual AI dialog interactions
- **`useMingoDialogs`** - Hook for handling multiple concurrent AI dialogs
- **`useMingoDialogSelection`** - Hook for managing dialog selection state
- **`useMingoChat`** - Hook for AI chat functionality and message handling
- **`useMingoRealtimeSubscription`** - Hook for real-time AI updates and subscriptions

## Usage Example

```typescript
import { 
  useMingoDialog, 
  useMingoChat, 
  useMingoRealtimeSubscription 
} from '@flamingo/mingo-hooks'

function AIAssistant() {
  const { openDialog, closeDialog } = useMingoDialog()
  const { sendMessage, messages } = useMingoChat()
  const { subscribe, data } = useMingoRealtimeSubscription()

  const handleAskMingo = async () => {
    const response = await sendMessage("Help me troubleshoot this server issue")
    openDialog({ type: 'ai-response', content: response })
  }

  return (
    <button onClick={handleAskMingo}>
      Ask Mingo AI
    </button>
  )
}
```

This module enables seamless integration of Mingo AI's technician assistance features throughout the OpenFrame platform, providing hooks for dialog management, chat interactions, and real-time AI updates.
