This file serves as the main export barrel for Mingo AI composables, providing a centralized entry point for all dialog, chat, and real-time functionality within the Flamingo platform.

## Key Components

The module exports five core composables for Mingo AI integration:

- **`useMingoDialog`** - Manages individual dialog interactions with Mingo AI
- **`useMingoDialogs`** - Handles multiple concurrent dialog sessions
- **`useMingoDialogSelection`** - Manages dialog selection and switching logic
- **`useMingoChat`** - Provides chat interface functionality for Mingo conversations
- **`useMingoRealtimeSubscription`** - Handles real-time updates and live data synchronization

## Usage Example

```typescript
// Import individual composables as needed
import { useMingoChat, useMingoDialog, useMingoRealtimeSubscription } from '@/composables/mingo'

// Use in Vue component
export default {
  setup() {
    const { sendMessage, messages } = useMingoChat()
    const { openDialog } = useMingoDialog()
    const { subscribe } = useMingoRealtimeSubscription()

    return {
      sendMessage,
      messages,
      openDialog,
      subscribe
    }
  }
}
```

This barrel export pattern allows consumers to import only the specific Mingo AI functionality they need while maintaining a clean, organized API surface for the composables library.
