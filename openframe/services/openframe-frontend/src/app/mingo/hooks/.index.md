A TypeScript index file that exports Vue composables for Mingo AI dialog management and real-time communication features in the Flamingo platform.

## Key Components

- **`useMingoDialog`** - Manages individual Mingo AI dialog interactions
- **`useMingoDialogs`** - Handles multiple dialog instances and dialog state management
- **`useMingoDialogSelection`** - Provides dialog selection functionality for multi-dialog workflows
- **`useMingoChat`** - Enables chat functionality with Mingo AI assistant
- **`useMingoRealtimeSubscription`** - Manages real-time subscriptions for live updates and notifications

## Usage Example

```typescript
import { 
  useMingoDialog, 
  useMingoDialogs, 
  useMingoChat,
  useMingoRealtimeSubscription 
} from '@/composables/mingo'

// In a Vue component
export default defineComponent({
  setup() {
    // Single dialog management
    const { openDialog, closeDialog } = useMingoDialog()
    
    // Multiple dialogs
    const { dialogs, activeDialog } = useMingoDialogs()
    
    // Chat functionality
    const { sendMessage, messages } = useMingoChat()
    
    // Real-time updates
    const { subscribe, unsubscribe } = useMingoRealtimeSubscription()
    
    return {
      openDialog,
      dialogs,
      sendMessage,
      subscribe
    }
  }
})
```

This barrel export pattern provides a clean API for importing Mingo AI-related composables throughout the OpenFrame platform.
