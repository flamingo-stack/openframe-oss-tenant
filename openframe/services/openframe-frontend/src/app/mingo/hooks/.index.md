A centralized export module that provides access to all Mingo-related React hooks for dialog management, chat functionality, and real-time subscriptions in the Flamingo platform.

## Key Components

**Dialog Management:**
- `useMingoDialog` - Manages individual dialog state and operations
- `useMingoDialogs` - Handles multiple dialog instances and coordination
- `useMingoDialogSelection` - Manages selection state within dialog contexts

**Chat & Real-time:**
- `useMingoChat` - Provides chat interface and messaging functionality with Mingo AI
- `useMingoRealtimeSubscription` - Manages real-time data subscriptions and updates

## Usage Example

```typescript
import { 
  useMingoDialog, 
  useMingoChat, 
  useMingoRealtimeSubscription 
} from './hooks'

function TechnicianPanel() {
  const { openDialog, closeDialog } = useMingoDialog()
  const { sendMessage, messages, isTyping } = useMingoChat()
  const { subscribe, data } = useMingoRealtimeSubscription()

  // Open Mingo AI assistance dialog
  const handleMingoAssist = () => {
    openDialog('mingo-assist', { context: 'ticket-analysis' })
  }

  // Send message to Mingo AI
  const askMingo = (question: string) => {
    sendMessage(question, { type: 'technician-query' })
  }

  return (
    <div>
      <button onClick={handleMingoAssist}>Get Mingo Help</button>
      {/* Chat interface and real-time updates */}
    </div>
  )
}
```

This module serves as the main entry point for all Mingo AI integration hooks, enabling technicians to interact with AI assistance, manage dialog flows, and receive real-time updates across the OpenFrame platform.
