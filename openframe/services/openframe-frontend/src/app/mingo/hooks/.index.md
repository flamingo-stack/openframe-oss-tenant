A module that exports custom React hooks for integrating with the Mingo AI assistant system, providing dialog management, chat functionality, and real-time subscription capabilities.

## Key Components

- **`useMingoDialog`** - Hook for managing individual Mingo AI dialog instances
- **`useMingoDialogs`** - Hook for handling multiple Mingo dialogs and their state
- **`useMingoDialogSelection`** - Hook for managing dialog selection and active dialog states
- **`useMingoChat`** - Hook for implementing Mingo AI chat functionality
- **`useMingoRealtimeSubscription`** - Hook for managing real-time data subscriptions with Mingo

## Usage Example

```typescript
import { 
  useMingoDialog, 
  useMingoChat, 
  useMingoRealtimeSubscription 
} from './hooks'

function MingoAssistant() {
  // Manage a single dialog instance
  const { dialog, openDialog, closeDialog } = useMingoDialog()
  
  // Handle chat interactions
  const { messages, sendMessage, isLoading } = useMingoChat()
  
  // Subscribe to real-time updates
  const { data, isConnected } = useMingoRealtimeSubscription('tickets')
  
  return (
    <div>
      <button onClick={() => openDialog('support')}>
        Open Mingo Support
      </button>
      {/* Chat interface implementation */}
    </div>
  )
}
```

This hook collection enables seamless integration with Flamingo's Mingo AI assistant, supporting both single and multi-dialog workflows with real-time capabilities for enhanced user experience.
