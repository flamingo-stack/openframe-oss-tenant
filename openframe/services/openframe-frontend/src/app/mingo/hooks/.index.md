A TypeScript barrel file that exports React hooks for the Mingo AI dialog system, providing a centralized entry point for all Mingo-related dialog and chat functionality.

## Key Components

- **`useMingoDialog`** - Hook for managing individual Mingo AI dialog instances
- **`useMingoDialogs`** - Hook for managing multiple dialog instances and state
- **`useMingoDialogSelection`** - Hook for handling dialog selection and navigation
- **`useMingoChat`** - Hook for Mingo AI chat functionality and message handling
- **`useMingoRealtimeSubscription`** - Hook for real-time updates and subscriptions in Mingo dialogs

## Usage Example

```typescript
import { 
  useMingoDialog, 
  useMingoChat, 
  useMingoRealtimeSubscription 
} from './path-to-mingo-hooks'

function MingoAIComponent() {
  const { dialog, openDialog, closeDialog } = useMingoDialog()
  const { messages, sendMessage, isLoading } = useMingoChat()
  const { isConnected, subscribe } = useMingoRealtimeSubscription()

  const handleOpenAI = async () => {
    await openDialog()
    subscribe('chat-updates')
  }

  return (
    <div>
      <button onClick={handleOpenAI}>
        Open Mingo AI {isConnected ? '🟢' : '🔴'}
      </button>
      {dialog && (
        <div>
          {messages.map(msg => (
            <div key={msg.id}>{msg.content}</div>
          ))}
        </div>
      )}
    </div>
  )
}
```

This barrel export pattern enables clean imports and better tree-shaking for the Mingo AI dialog system components.
