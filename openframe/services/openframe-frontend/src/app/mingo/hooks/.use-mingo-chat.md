A React hook that provides comprehensive chat functionality for Mingo AI conversations, including real-time message streaming, approval workflows, and dialog management.

## Key Components

- **useMingoChat**: Main hook for managing Mingo AI chat sessions
- **ProcessedMessage**: Interface for formatted chat messages with role, content, and metadata
- **ApprovalHandlers**: Interface for handling approval/rejection actions
- **Real-time processing**: Integration with WebSocket streams for live message updates
- **State management**: Integration with Zustand store for message persistence

## Usage Example

```typescript
import { useMingoChat } from './hooks/use-mingo-chat'

function ChatComponent() {
  const [dialogId, setDialogId] = useState<string | null>(null)
  
  const approvalHandlers = {
    handleApprove: (requestId?: string) => {
      console.log('Approved:', requestId)
    },
    handleReject: (requestId?: string) => {
      console.log('Rejected:', requestId)
    },
    approvalStatuses: {}
  }
  
  const {
    messages,
    isLoading,
    createDialog,
    sendMessage,
    approvals,
    isTyping,
    processChunk
  } = useMingoChat(dialogId, approvalHandlers)
  
  const handleCreateChat = async () => {
    const newDialogId = await createDialog()
    if (newDialogId) {
      setDialogId(newDialogId)
    }
  }
  
  const handleSendMessage = async (content: string) => {
    const success = await sendMessage(content)
    if (!success) {
      console.error('Failed to send message')
    }
  }
  
  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>
          <strong>{msg.name}:</strong> {msg.content}
        </div>
      ))}
      {isTyping && <div>Mingo is typing...</div>}
    </div>
  )
}
```

The hook handles message streaming, approval workflows, optimistic updates, error handling, and automatic welcome message display for new conversations.
