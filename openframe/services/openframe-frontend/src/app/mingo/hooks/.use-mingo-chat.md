A React hook that provides complete chat functionality for interacting with Mingo AI, including real-time message streaming, approval handling, and dialog management.

## Key Components

- **useMingoChat**: Main hook that returns chat state and actions
- **ProcessedMessage**: Interface for formatted chat messages
- **ApprovalHandlers**: Interface for handling approval requests
- **Real-time processing**: Integration with chunk processor for streaming responses
- **Message state management**: Handles optimistic updates and error states

## Usage Example

```typescript
import { useMingoChat } from './hooks/use-mingo-chat'

function ChatComponent({ dialogId }: { dialogId: string | null }) {
  const approvalHandlers = {
    handleApprove: (requestId?: string) => console.log('Approved:', requestId),
    handleReject: (requestId?: string) => console.log('Rejected:', requestId),
    approvalStatuses: {}
  }

  const {
    messages,
    isLoading,
    isTyping,
    createDialog,
    sendMessage,
    approvals,
    processChunk
  } = useMingoChat(dialogId, approvalHandlers)

  const handleSend = async (content: string) => {
    const success = await sendMessage(content)
    if (!success) console.error('Failed to send message')
  }

  const handleCreateDialog = async () => {
    const newDialogId = await createDialog()
    if (newDialogId) {
      // Navigate to new dialog
    }
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>
          <strong>{msg.name}:</strong> {msg.content}
        </div>
      ))}
      {isTyping && <div>Mingo is typing...</div>}
      {approvals.length > 0 && <div>Pending approvals: {approvals.length}</div>}
    </div>
  )
}
```

The hook automatically handles welcome messages, error states, optimistic updates, and integrates with the real-time streaming system for live AI responses.
