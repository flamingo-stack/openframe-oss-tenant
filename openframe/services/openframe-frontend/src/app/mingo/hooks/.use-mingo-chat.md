Hook for managing Mingo chat functionality including message handling, real-time streaming, and approval workflows. Provides comprehensive state management for chat dialogs with support for optimistic updates and error handling.

## Key Components

- **useMingoChat**: Main hook that returns chat state and actions
- **ProcessedMessage**: Interface for formatted chat messages with metadata
- **UseMingoChat**: Return type interface defining available chat functionality
- **ApprovalHandlers**: Interface for handling approval/rejection workflows
