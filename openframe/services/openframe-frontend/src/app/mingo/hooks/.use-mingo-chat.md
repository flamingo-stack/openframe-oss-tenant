A React hook that manages Mingo AI chat functionality including real-time message processing, approval handling, and dialog management with optimistic UI updates.

## Key Components

- **useMingoChat**: Main hook that orchestrates chat state and operations
- **ProcessedMessage**: Interface defining the structure of processed chat messages
- **UseMingoChat**: Return type interface with messages, actions, and state
- **ApprovalHandlers**: Interface for handling approval workflows

## Usage Example

```typescript
import { useMingoChat } from './use-mingo-chat'

function ChatComponent() {
  const dialogId = "chat-123"
  
  const approvalHandlers = {
    handleApprove: (requestId?: string) => {
      // Handle approval logic
    },
    handleReject: (requestId?: string) => {
      // Handle rejection logic
    },
    approvalStatuses: {}
  }
  
  const {
    messages,
    isLoading,
    createDialog,
    sendMessage,
    approvals,
    processChunk,
    isTyping,
    assistantType
  } = useMingoChat(dialogId, approvalHandlers)
  
  const handleSendMessage = async () => {
    const success = await sendMessage("Hello Mingo!")
    if (!success) {
      console.error("Failed to send message")
    }
  }
  
  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Mingo is typing...</div>}
      <button onClick={handleSendMessage}>Send</button>
    </div>
  )
}
```

The hook integrates with the Mingo messages store, handles real-time chunk processing via NATS, manages approval workflows, and provides optimistic UI updates for a seamless chat experience.
