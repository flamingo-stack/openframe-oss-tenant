A React hook that manages Mingo AI chat functionality, providing real-time messaging, dialog management, and approval workflows with automatic state synchronization.

## Key Components

- **useMingoChat** - Main hook that returns chat state and actions
- **ProcessedMessage** - Type for formatted chat messages with role and metadata
- **ApprovalHandlers** - Interface for handling approval/rejection workflows
- **Real-time processing** - Integration with NATS streaming for live message updates
- **State management** - Uses Zustand store for message persistence and typing indicators

## Usage Example

```typescript
import { useMingoChat } from './hooks/use-mingo-chat'

function ChatComponent() {
  const approvalHandlers = {
    handleApprove: (requestId) => console.log('Approved:', requestId),
    handleReject: (requestId) => console.log('Rejected:', requestId),
    approvalStatuses: {}
  }

  const {
    messages,
    isLoading,
    createDialog,
    sendMessage,
    approvals,
    isTyping
  } = useMingoChat('dialog-123', approvalHandlers)

  const handleSend = async () => {
    const success = await sendMessage('Hello Mingo!')
    if (success) {
      console.log('Message sent successfully')
    }
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Mingo is typing...</div>}
    </div>
  )
}
```

The hook automatically handles message streaming, error states, welcome messages, and real-time updates through the OpenFrame core system.
