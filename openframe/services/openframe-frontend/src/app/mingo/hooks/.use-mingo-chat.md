A React hook that manages Mingo AI chat functionality, providing message handling, real-time streaming, and approval workflows for AI assistant interactions.

## Key Components

- **useMingoChat** - Main hook for managing chat state and operations
- **ProcessedMessage** - Filtered message interface for UI display
- **ApprovalHandlers** - Interface for handling approval requests
- **Real-time processing** - Chunk-based streaming message updates
- **Dialog management** - Creating and managing chat sessions
- **Message store integration** - Uses Zustand store for state management

## Usage Example

```typescript
import { useMingoChat } from './hooks/use-mingo-chat'

function ChatInterface({ dialogId }: { dialogId: string | null }) {
  const approvalHandlers = {
    handleApprove: (requestId?: string) => console.log('Approved:', requestId),
    handleReject: (requestId?: string) => console.log('Rejected:', requestId),
    approvalStatuses: {}
  }

  const {
    messages,
    isLoading,
    isTyping,
    createDialog,
    sendMessage,
    approvals,
    processChunk
  } = useMingoChat(dialogId, approvalHandlers)

  const handleSend = async (content: string) => {
    const success = await sendMessage(content)
    if (!success) {
      console.error('Failed to send message')
    }
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>
          <strong>{msg.name}:</strong> {msg.content}
        </div>
      ))}
      {isTyping && <div>Mingo is typing...</div>}
    </div>
  )
}
```

The hook handles optimistic UI updates, error states, welcome messages, and integrates with the real-time chunk processor for streaming responses. It automatically manages typing indicators and message state synchronization.
