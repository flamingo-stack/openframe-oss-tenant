A React hook that provides a unified interface for managing Mingo AI chat functionality, including dialog creation, message handling, and approval workflows within the OpenFrame MSP platform.

## Key Components

**Main Hook:**
- `useMingoChat(dialogId)` - Primary hook that manages chat state and operations

**Core Functions:**
- `createDialog()` - Creates new chat dialogs with the Mingo assistant
- `sendMessage(content, targetDialogId)` - Sends messages with optimistic updates
- Message processing and filtering logic for approval requests

**State Management:**
- `messages` - Processed chat messages with filtered approval content
- `approvals` - Pending approval requests extracted from messages
- `isTyping`, `isLoading`, `isCreatingDialog` - UI state indicators

**Integration:**
- Uses Zustand store (`useMingoMessagesStore`) for state persistence
- Integrates with React Query for server synchronization
- Handles toast notifications for error states

## Usage Example

```typescript
import { useMingoChat } from './hooks/use-mingo-chat'

function ChatInterface() {
  const [currentDialogId, setCurrentDialogId] = useState<string | null>(null)
  
  const {
    messages,
    sendMessage,
    createDialog,
    approvals,
    isTyping,
    isCreatingDialog
  } = useMingoChat(currentDialogId)

  const handleCreateChat = async () => {
    const dialogId = await createDialog()
    if (dialogId) {
      setCurrentDialogId(dialogId)
    }
  }

  const handleSendMessage = async (content: string) => {
    const success = await sendMessage(content)
    if (!success) {
      console.error('Failed to send message')
    }
  }

  return (
    <div>
      {!currentDialogId && (
        <button onClick={handleCreateChat} disabled={isCreatingDialog}>
          Start Chat with Mingo
        </button>
      )}
      
      {messages.map(msg => (
        <div key={msg.id} className={`message ${msg.role}`}>
          <strong>{msg.name}:</strong> {msg.content}
        </div>
      ))}
      
      {approvals.length > 0 && (
        <div>Pending approvals: {approvals.length}</div>
      )}
      
      {isTyping && <div>Mingo is typing...</div>}
    </div>
  )
}
```
