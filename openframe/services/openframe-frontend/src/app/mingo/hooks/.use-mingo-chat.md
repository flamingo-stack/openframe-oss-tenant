A React hook that manages Mingo AI chat functionality, including real-time message processing, dialog creation, and approval handling. This hook provides a complete interface for chat operations with state management, streaming capabilities, and error handling.

## Key Components

- **useMingoChat** - Main hook function that returns chat state and actions
- **ProcessedMessage** - Interface for formatted chat messages
- **UseMingoChat** - Return type with messages, loading states, and action functions
- **ApprovalHandlers** - Interface for handling approval requests and rejections
- **Real-time processing** - Integration with chunk processor for streaming responses
- **Message state management** - Handles optimistic updates, streaming states, and error messages

## Usage Example

```typescript
import { useMingoChat } from './hooks/use-mingo-chat'

function ChatComponent({ dialogId }: { dialogId: string | null }) {
  const approvalHandlers = {
    handleApprove: (requestId?: string) => {
      console.log('Approved:', requestId)
    },
    handleReject: (requestId?: string) => {
      console.log('Rejected:', requestId)
    },
    approvalStatuses: {}
  }

  const {
    messages,
    isLoading,
    isTyping,
    sendMessage,
    createDialog,
    approvals,
    processChunk
  } = useMingoChat(dialogId, approvalHandlers)

  const handleSendMessage = async (content: string) => {
    const success = await sendMessage(content)
    if (!success) {
      console.error('Failed to send message')
    }
  }

  const handleCreateDialog = async () => {
    const newDialogId = await createDialog()
    console.log('New dialog created:', newDialogId)
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>
          <strong>{msg.name}:</strong> {msg.content}
        </div>
      ))}
      {isTyping && <div>Mingo is typing...</div>}
    </div>
  )
}
```
