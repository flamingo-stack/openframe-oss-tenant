A React hook for managing real-time AI chat conversations with the Mingo assistant, including message streaming, approval workflows, and dialog management.

## Key Components

### Main Hook
- **`useMingoChat()`** - Primary hook for Mingo chat functionality

### Core Types
- **`ProcessedMessage`** - Formatted message structure for UI display
- **`UseMingoChat`** - Return interface with messages, actions, and state
- **`ApprovalHandlers`** - Interface for handling approval requests

### Key Features
- Real-time message streaming and chunk processing
- Dialog creation and management
- Message approval system for sensitive operations
- Automatic welcome message handling
- Error state management
- Typing indicators

## Usage Example

```typescript
import { useMingoChat } from './use-mingo-chat'

function ChatInterface() {
  const approvalHandlers = {
    handleApprove: (requestId?: string) => {
      console.log('Approved:', requestId)
    },
    handleReject: (requestId?: string) => {
      console.log('Rejected:', requestId)
    },
    approvalStatuses: {}
  }

  const {
    messages,
    isLoading,
    isTyping,
    createDialog,
    sendMessage,
    approvals,
    processChunk
  } = useMingoChat('dialog-123', approvalHandlers)

  const handleSend = async (message: string) => {
    const success = await sendMessage(message)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>
          <strong>{msg.name}:</strong> {msg.content}
        </div>
      ))}
      {isTyping && <div>Mingo is typing...</div>}
    </div>
  )
}
```

The hook integrates with the Mingo API service, real-time streaming, and message store to provide a complete chat experience with AI assistant capabilities.
