A React hook that manages the Mingo AI assistant chat functionality, providing message handling, dialog creation, and approval system integration for the Flamingo platform's AI-powered MSP operations.

## Key Components

- **useMingoChat** - Main hook that returns chat state and actions
- **ProcessedMessage** - Interface for formatted chat messages with role, content, and metadata
- **UseMingoChat** - Return type interface defining available properties and methods
- **Message filtering** - Filters out pending approval segments from display
- **Approval extraction** - Separates pending approval requests for specialized handling

## Usage Example

```typescript
import { useMingoChat } from './hooks/use-mingo-chat'

function MingoChatComponent() {
  const {
    messages,
    isLoading,
    createDialog,
    sendMessage,
    approvals,
    isTyping
  } = useMingoChat(dialogId)

  const handleSendMessage = async (content: string) => {
    const success = await sendMessage(content)
    if (!success) {
      console.error('Failed to send message')
    }
  }

  const handleCreateDialog = async () => {
    const newDialogId = await createDialog()
    if (newDialogId) {
      // Navigate to new dialog
    }
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>
          <strong>{msg.name}:</strong> {msg.content}
        </div>
      ))}
      {approvals.length > 0 && (
        <ApprovalPanel approvals={approvals} />
      )}
      {isTyping && <TypingIndicator />}
    </div>
  )
}
```

The hook integrates with Zustand store for state management and React Query for API operations, providing optimistic updates and error handling for seamless chat experiences.
