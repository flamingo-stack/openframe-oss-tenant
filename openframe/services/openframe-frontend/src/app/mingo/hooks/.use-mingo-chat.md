A React hook for managing chat interactions with Mingo AI assistant, providing message handling, dialog creation, and approval system integration. This hook serves as the primary interface for Mingo chat functionality in the OpenFrame platform.

## Key Components

- **useMingoChat** - Main hook that manages chat state and operations
- **ProcessedMessage** - Interface for formatted chat messages with metadata
- **UseMingoChat** - Return type interface defining hook's public API
- **Message Processing** - Logic to filter and format messages, separating approvals from regular content
- **Dialog Management** - Functions for creating new chat dialogs
- **Message Sending** - Optimistic message handling with error recovery
- **Approval System** - Extraction and management of pending approval requests

## Usage Example

```typescript
import { useMingoChat } from './hooks/use-mingo-chat'

function ChatInterface({ dialogId }: { dialogId: string | null }) {
  const {
    messages,
    isLoading,
    isTyping,
    approvals,
    createDialog,
    sendMessage
  } = useMingoChat(dialogId)

  const handleSendMessage = async (content: string) => {
    if (!dialogId) {
      const newDialogId = await createDialog()
      if (newDialogId) {
        await sendMessage(content, newDialogId)
      }
    } else {
      await sendMessage(content)
    }
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>
          <strong>{msg.name}:</strong> {msg.content}
        </div>
      ))}
      {approvals.length > 0 && (
        <div>Pending approvals: {approvals.length}</div>
      )}
      {isTyping && <div>Mingo is typing...</div>}
    </div>
  )
}
```
