A React hook that provides comprehensive chat functionality for the Mingo AI assistant, managing message state, dialog creation, and message sending with optimistic updates and approval system integration.

## Key Components

- **ProcessedMessage Interface**: Defines the structure for chat messages with content, role, timestamp, and assistant type
- **UseMingoChat Interface**: Comprehensive return type including messages, loading states, actions, and approval system
- **useMingoChat Hook**: Main hook that orchestrates chat functionality using Zustand store and React Query mutations
- **Message Processing**: Filters and transforms messages, separating regular content from pending approvals
- **Optimistic Updates**: Immediately adds user messages to UI before server confirmation

## Usage Example

```typescript
import { useMingoChat } from './hooks/use-mingo-chat'

function ChatComponent() {
  const dialogId = "dialog-123"
  const {
    messages,
    isLoading,
    isTyping,
    approvals,
    createDialog,
    sendMessage
  } = useMingoChat(dialogId)

  const handleSendMessage = async (content: string) => {
    const success = await sendMessage(content)
    if (!success) {
      console.error('Failed to send message')
    }
  }

  const handleCreateDialog = async () => {
    const newDialogId = await createDialog()
    if (newDialogId) {
      // Navigate to new dialog
    }
  }

  return (
    <div>
      {messages.map(message => (
        <div key={message.id}>
          <strong>{message.name}:</strong> {message.content}
        </div>
      ))}
      {isTyping && <div>Mingo is typing...</div>}
      {approvals.length > 0 && (
        <div>Pending approvals: {approvals.length}</div>
      )}
    </div>
  )
}
```
