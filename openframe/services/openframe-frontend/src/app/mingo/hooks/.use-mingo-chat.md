A React hook that manages Mingo AI assistant chat interactions, providing message handling, dialog creation, and approval system integration for the OpenFrame platform.

## Key Components

**Main Hook**
- `useMingoChat(dialogId)` - Primary hook for managing Mingo chat state and operations

**Core Functions**
- `createDialog()` - Creates a new chat dialog with Mingo
- `sendMessage(content, targetDialogId?)` - Sends messages to the assistant with optimistic updates
- Message filtering and processing for approval requests
- Real-time typing state management

**State Management**
- `messages` - Processed chat messages with filtered content
- `approvals` - Pending approval requests from assistant
- `isLoading`, `isCreatingDialog`, `isTyping` - Loading states

**Data Types**
- `ProcessedMessage` - Formatted chat message with metadata
- `UseMingoChat` - Hook return interface

## Usage Example

```typescript
import { useMingoChat } from './hooks/use-mingo-chat'

function MingoChatComponent({ dialogId }: { dialogId: string | null }) {
  const {
    messages,
    isTyping,
    isCreatingDialog,
    approvals,
    createDialog,
    sendMessage
  } = useMingoChat(dialogId)

  const handleSendMessage = async (content: string) => {
    const success = await sendMessage(content)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleCreateDialog = async () => {
    const newDialogId = await createDialog()
    if (newDialogId) {
      console.log('Created dialog:', newDialogId)
    }
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {approvals.length > 0 && (
        <div>Pending approvals: {approvals.length}</div>
      )}
    </div>
  )
}
```
