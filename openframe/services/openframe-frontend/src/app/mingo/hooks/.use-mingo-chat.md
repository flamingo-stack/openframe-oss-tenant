A React hook that provides comprehensive Mingo AI chat functionality including message management, dialog creation, and real-time typing indicators. Part of the Flamingo Stack's AI assistant integration system.

## Key Components

- **useMingoChat** - Main hook returning chat state and actions
- **ProcessedMessage** - Interface for formatted chat messages with content segments
- **UseMingoChat** - Return type interface defining available methods and state
- **Message Processing** - Filters and transforms messages, handling approval requests separately
- **Dialog Management** - Creates new chat dialogs and manages conversation state
- **Typing Indicators** - Real-time typing state management for better UX
