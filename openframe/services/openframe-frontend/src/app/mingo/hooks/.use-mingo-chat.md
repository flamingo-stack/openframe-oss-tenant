A React hook that manages Mingo AI chat functionality, providing message handling, dialog creation, and real-time typing states for the Flamingo AI assistant interface.

## Key Components

- **`useMingoChat`** - Main hook that manages chat state and operations
- **`ProcessedMessage`** - Interface for formatted chat messages with role, content, and metadata
- **`UseMingoChat`** - Return type interface defining available chat operations and state
- **Message Processing** - Filters and transforms raw messages, handling approval requests separately
- **Dialog Management** - Creates new chat dialogs and manages conversation state
- **Optimistic Updates** - Adds messages immediately to UI before server confirmation

## Usage Example

```typescript
function ChatComponent({ dialogId }: { dialogId: string | null }) {
  const {
    messages,
    isLoading,
    isTyping,
    approvals,
    createDialog,
    sendMessage
  } = useMingoChat(dialogId)

  const handleSendMessage = async (content: string) => {
    const success = await sendMessage(content)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleCreateDialog = async () => {
    const newDialogId = await createDialog()
    if (newDialogId) {
      // Navigate to new dialog
      router.push(`/chat/${newDialogId}`)
    }
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>
          <strong>{msg.name}:</strong> {msg.content}
        </div>
      ))}
      {isTyping && <div>Mingo is typing...</div>}
      {approvals.length > 0 && <ApprovalComponent approvals={approvals} />}
    </div>
  )
}
```
