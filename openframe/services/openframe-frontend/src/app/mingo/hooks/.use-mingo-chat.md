A React hook that manages Mingo AI chat functionality with real-time message processing, dialog creation, and approval system integration.

## Key Components

- **`useMingoChat`** - Main hook providing chat state management and actions
- **`ProcessedMessage`** - Interface for formatted chat messages
- **`UseMingoChat`** - Return type interface with messages, actions, and state
- **`ApprovalHandlers`** - Interface for handling approval workflows
- **Real-time processing** - Chunk processing for streaming AI responses
- **Message management** - Add, update, and filter messages
- **Dialog lifecycle** - Create dialogs and manage welcome messages

## Usage Example

```typescript
import { useMingoChat } from './use-mingo-chat'

function ChatComponent() {
  const approvalHandlers = {
    handleApprove: (requestId?: string) => console.log('Approved:', requestId),
    handleReject: (requestId?: string) => console.log('Rejected:', requestId),
    approvalStatuses: {}
  }

  const {
    messages,
    isLoading,
    createDialog,
    sendMessage,
    approvals,
    processChunk,
    isCreatingDialog,
    isTyping
  } = useMingoChat('dialog-123', approvalHandlers)

  const handleSendMessage = async () => {
    const success = await sendMessage('Hello Mingo!')
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleCreateDialog = async () => {
    const dialogId = await createDialog()
    if (dialogId) {
      console.log('New dialog created:', dialogId)
    }
  }

  return (
    <div>
      <div>Messages: {messages.length}</div>
      <div>Typing: {isTyping ? 'Yes' : 'No'}</div>
      <div>Pending Approvals: {approvals.length}</div>
    </div>
  )
}
```
