A React hook that manages Mingo AI chat functionality, providing real-time messaging, streaming responses, approval workflows, and state management for chat dialogs.

## Key Components

- **useMingoChat**: Main hook for chat management with real-time processing
- **ProcessedMessage**: Interface for formatted chat messages with role, content, and metadata
- **UseMingoChat**: Return type with messages, actions, and state management
- **ApprovalHandlers**: Interface for handling approval/rejection workflows
- **Real-time processing**: Streaming message chunks with segment updates
- **State management**: Integration with Zustand store for persistent chat state
