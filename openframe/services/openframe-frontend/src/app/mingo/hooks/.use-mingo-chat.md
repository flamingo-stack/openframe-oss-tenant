A React hook that manages real-time chat interactions with Mingo AI, handling message streaming, approvals, and dialog management with optimistic updates and error handling.

## Key Components

- **useMingoChat** - Main hook managing chat state and interactions
- **ProcessedMessage** - Interface for filtered message display
- **UseMingoChat** - Return type interface with actions and state
- **ApprovalHandlers** - Interface for approval system callbacks

## Usage Example

```typescript
import { useMingoChat } from './use-mingo-chat'

function ChatComponent({ dialogId }: { dialogId: string | null }) {
  const approvalHandlers = {
    handleApprove: (requestId?: string) => {
      console.log('Approved:', requestId)
    },
    handleReject: (requestId?: string) => {
      console.log('Rejected:', requestId)
    },
    approvalStatuses: {}
  }

  const {
    messages,
    isLoading,
    isTyping,
    approvals,
    createDialog,
    sendMessage,
    processChunk
  } = useMingoChat(dialogId, approvalHandlers)

  const handleSend = async (content: string) => {
    const success = await sendMessage(content)
    if (!success) {
      console.error('Failed to send message')
    }
  }

  const handleCreateChat = async () => {
    const newDialogId = await createDialog()
    if (newDialogId) {
      // Navigate to new dialog
    }
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>
          <strong>{msg.name}:</strong> {msg.content}
        </div>
      ))}
      {isTyping && <div>Mingo is typing...</div>}
      {approvals.length > 0 && (
        <div>Pending approvals: {approvals.length}</div>
      )}
    </div>
  )
}
```

The hook integrates with Zustand stores, React Query for API calls, and real-time NATS messaging for seamless chat experiences.
