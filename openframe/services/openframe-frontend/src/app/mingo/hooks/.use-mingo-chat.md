A React hook that provides a complete interface for interacting with Mingo AI chat functionality, including message management, dialog creation, and approval workflows. This hook integrates with Zustand stores and TanStack Query for state management and API operations.

## Key Components

- **`useMingoChat`** - Main hook that returns chat interface with messages, actions, and state
- **`ProcessedMessage`** - Interface for formatted chat messages with metadata
- **`UseMingoChat`** - Return type interface defining the complete hook API
- **Message filtering** - Automatically filters out pending approvals from display
- **Optimistic updates** - Immediately shows user messages before server confirmation
- **Error handling** - Toast notifications for failed operations

## Usage Example

```typescript
import { useMingoChat } from './hooks/use-mingo-chat'

function ChatInterface({ dialogId }: { dialogId: string | null }) {
  const {
    messages,
    sendMessage,
    createDialog,
    isTyping,
    approvals,
    isCreatingDialog
  } = useMingoChat(dialogId)

  const handleSend = async (content: string) => {
    const success = await sendMessage(content)
    if (!success) {
      console.error('Failed to send message')
    }
  }

  const handleCreateDialog = async () => {
    const newDialogId = await createDialog()
    if (newDialogId) {
      // Navigate to new dialog
    }
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>
          <strong>{msg.name}:</strong> {msg.content}
        </div>
      ))}
      {approvals.length > 0 && (
        <div>Pending approvals: {approvals.length}</div>
      )}
      {isTyping && <div>Mingo is typing...</div>}
    </div>
  )
}
```
