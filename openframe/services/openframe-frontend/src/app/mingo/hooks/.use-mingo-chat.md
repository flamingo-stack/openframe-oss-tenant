A React hook that provides comprehensive chat functionality for the Mingo AI assistant, managing real-time message streaming, approval workflows, and dialog state.

## Key Components

- **`useMingoChat`** - Main hook providing chat interface with real-time processing
- **`ProcessedMessage`** - Interface for formatted chat messages with metadata
- **`UseMingoChat`** - Return type interface defining available actions and state
- **`ApprovalHandlers`** - Interface for handling approval request workflows

## Usage Example

```typescript
import { useMingoChat } from './hooks/use-mingo-chat'

function ChatComponent({ dialogId }: { dialogId: string | null }) {
  const approvalHandlers = {
    handleApprove: (requestId?: string) => {
      console.log('Approved:', requestId)
    },
    handleReject: (requestId?: string) => {
      console.log('Rejected:', requestId)
    },
    approvalStatuses: {}
  }

  const {
    messages,
    isLoading,
    createDialog,
    sendMessage,
    approvals,
    processChunk,
    isTyping
  } = useMingoChat(dialogId, approvalHandlers)

  const handleSend = async (content: string) => {
    const success = await sendMessage(content)
    if (!success) {
      console.error('Failed to send message')
    }
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>
          <strong>{msg.name}:</strong> {msg.content}
        </div>
      ))}
      {isTyping && <div>Mingo is typing...</div>}
      {approvals.length > 0 && (
        <div>Pending approvals: {approvals.length}</div>
      )}
    </div>
  )
}
```

The hook integrates with Zustand stores for state management, TanStack Query for API calls, and provides real-time chunk processing for streaming responses. It automatically handles welcome messages, error states, optimistic updates, and approval workflows.
