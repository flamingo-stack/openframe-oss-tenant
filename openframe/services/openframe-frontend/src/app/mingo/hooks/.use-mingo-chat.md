A React hook that provides complete chat functionality for Mingo AI assistant interactions, managing message state, dialog creation, and approval workflows through a centralized store and API service.

## Key Components

- **`useMingoChat(dialogId)`** - Main hook that returns chat interface and controls
- **`ProcessedMessage`** - Type for filtered and formatted chat messages
- **`UseMingoChat`** - Return type interface with messages, actions, and state
- **Message filtering** - Removes pending approval requests from display
- **Optimistic updates** - Adds messages immediately before API confirmation
- **Approval system** - Extracts and manages pending approval requests separately

## Usage Example

```typescript
import { useMingoChat } from './hooks/use-mingo-chat'

function ChatComponent({ dialogId }: { dialogId: string | null }) {
  const {
    messages,
    isLoading,
    isTyping,
    approvals,
    createDialog,
    sendMessage
  } = useMingoChat(dialogId)

  const handleSendMessage = async (content: string) => {
    const success = await sendMessage(content)
    if (!success) {
      console.error('Failed to send message')
    }
  }

  const handleCreateNewDialog = async () => {
    const newDialogId = await createDialog()
    if (newDialogId) {
      // Navigate to new dialog
    }
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {approvals.length > 0 && (
        <div>Pending approvals: {approvals.length}</div>
      )}
      {isTyping && <div>Mingo is typing...</div>}
    </div>
  )
}
```

The hook integrates with the Mingo messages store and API service to provide real-time chat functionality with built-in error handling and loading states.
