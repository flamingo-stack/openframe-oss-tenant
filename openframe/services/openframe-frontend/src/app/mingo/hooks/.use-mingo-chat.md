This React hook provides a complete interface for managing AI chat interactions with Mingo, including real-time message processing, approval workflows, and WebSocket streaming capabilities.

## Key Components

**Main Hook Interface:**
- `useMingoChat(dialogId, approvalHandlers)` - Primary hook for Mingo chat functionality
- `ProcessedMessage` - Normalized message format for UI consumption
- `ApprovalHandlers` - Interface for handling approval request callbacks

**Core Features:**
- **Message Management** - Create, send, and process messages with real-time streaming
- **Dialog Operations** - Create new chat dialogs and manage dialog state
- **Approval System** - Handle approval requests with approve/reject functionality
- **Real-time Processing** - WebSocket chunk processing for streaming responses
- **Error Handling** - Automatic error message generation and display

**Store Integration:**
- Uses `useMingoMessagesStore` for centralized message state management
- Integrates with `MingoApiService` for backend communication
- Leverages `useRealtimeChunkProcessor` for WebSocket message handling

## Usage Example

```typescript
import { useMingoChat } from './hooks/use-mingo-chat'

function ChatInterface({ dialogId }: { dialogId: string | null }) {
  const approvalHandlers = {
    handleApprove: (requestId?: string) => {
      console.log('Approved request:', requestId)
    },
    handleReject: (requestId?: string) => {
      console.log('Rejected request:', requestId)
    },
    approvalStatuses: {}
  }

  const {
    messages,
    isLoading,
    isTyping,
    createDialog,
    sendMessage,
    approvals,
    processChunk
  } = useMingoChat(dialogId, approvalHandlers)

  const handleSendMessage = async (content: string) => {
    const success = await sendMessage(content)
    if (!success) {
      console.error('Failed to send message')
    }
  }

  const handleCreateDialog = async () => {
    const newDialogId = await createDialog()
    if (newDialogId) {
      // Navigate to new dialog
      console.log('Created dialog:', newDialogId)
    }
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>
          <strong>{msg.name}:</strong> {msg.content}
        </div>
      ))}
      {isTyping && <div>Mingo is typing...</div>}
      {approvals.length > 0 && (
        <div>Pending approvals: {approvals.length}</div>
      )}
    </div>
  )
}
```

The hook automatically manages welcome messages, optimistic UI updates, typing indicators, and real-time streaming responses from the Mingo AI assistant.
