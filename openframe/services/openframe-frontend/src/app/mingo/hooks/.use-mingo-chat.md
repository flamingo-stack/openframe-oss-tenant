A React hook that provides complete chat functionality for interacting with the Mingo AI assistant, including message handling, dialog management, and approval system integration.

## Key Components

- **useMingoChat**: Main hook that manages chat state and operations
- **ProcessedMessage**: Interface for formatted chat messages with metadata
- **UseMingoChat**: Return type interface defining all available chat methods and state
- **Message Processing**: Filters and transforms raw messages for display
- **Approval System**: Extracts and manages pending approval requests
- **Dialog Management**: Handles chat session creation and lifecycle

## Usage Example

```typescript
import { useMingoChat } from './hooks/use-mingo-chat'

function ChatComponent() {
  const {
    messages,
    sendMessage,
    createDialog,
    isTyping,
    approvals,
    isCreatingDialog
  } = useMingoChat('dialog-123')

  const handleSendMessage = async () => {
    const success = await sendMessage('Help me troubleshoot this server issue')
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleCreateNewDialog = async () => {
    const dialogId = await createDialog()
    if (dialogId) {
      console.log('New dialog created:', dialogId)
    }
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>
          <strong>{msg.name}:</strong> {msg.content}
        </div>
      ))}
      {isTyping && <div>Mingo is typing...</div>}
      {approvals.length > 0 && (
        <div>Pending approvals: {approvals.length}</div>
      )}
    </div>
  )
}
```
