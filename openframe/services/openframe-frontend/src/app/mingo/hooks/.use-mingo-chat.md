React hook for managing Mingo AI chat functionality with real-time message processing, approval workflows, and streaming responses. Integrates with OpenFrame's real-time infrastructure and provides complete chat state management.

## Key Components

### Main Hook
- **`useMingoChat`** - Primary hook managing chat state, real-time processing, and user interactions

### Core Features
- **Dialog Management** - Create new chat sessions and manage dialog state
- **Message Processing** - Handle user messages, streaming responses, and error states
- **Approval System** - Manage approval requests with approve/reject handlers
- **Real-time Updates** - Process streaming chunks from Mingo AI assistant
- **Welcome Messages** - Auto-add welcome messages for new dialogs

### State Management
- **Messages Array** - Filtered and processed chat messages
- **Typing Indicators** - Real-time typing state management
- **Streaming Messages** - Handle incomplete/streaming message content
- **Approval Tracking** - Extract and manage pending approval requests

## Usage Example

```typescript
import { useMingoChat } from './hooks/use-mingo-chat'

function ChatComponent({ dialogId }: { dialogId: string | null }) {
  const approvalHandlers = {
    handleApprove: (requestId?: string) => {
      console.log('Approved:', requestId)
    },
    handleReject: (requestId?: string) => {
      console.log('Rejected:', requestId)
    },
    approvalStatuses: {}
  }

  const {
    messages,
    isLoading,
    isTyping,
    createDialog,
    sendMessage,
    approvals,
    processChunk
  } = useMingoChat(dialogId, approvalHandlers)

  const handleSend = async (content: string) => {
    const success = await sendMessage(content)
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleNewChat = async () => {
    const newDialogId = await createDialog()
    if (newDialogId) {
      // Navigate to new chat
      console.log('Created dialog:', newDialogId)
    }
  }

  return (
    <div>
      <div>
        {messages.map(msg => (
          <div key={msg.id}>
            <strong>{msg.name}:</strong> {msg.content}
          </div>
        ))}
        {isTyping && <div>Mingo is typing...</div>}
      </div>
      
      {approvals.length > 0 && (
        <div>
          <h4>Pending Approvals:</h4>
          {/* Render approval UI */}
        </div>
      )}
      
      <input
        onKeyPress={(e) => {
          if (e.key === 'Enter') {
            handleSend(e.currentTarget.value)
            e.currentTarget.value = ''
          }
        }}
        disabled={isLoading || isTyping}
        placeholder="Type your message..."
      />
    </div>
  )
}
```
