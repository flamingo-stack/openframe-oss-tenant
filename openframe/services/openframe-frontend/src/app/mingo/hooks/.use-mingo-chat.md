A React hook that manages Mingo AI chat functionality, providing real-time messaging, dialog management, and approval workflows with comprehensive state management and error handling.

## Key Components

- **useMingoChat** - Main hook that orchestrates chat functionality
- **ProcessedMessage** - Interface for formatted chat messages with metadata
- **ApprovalHandlers** - Interface for managing approval request workflows
- **Real-time Processing** - Handles streaming message chunks and updates
- **Dialog Management** - Creates and manages chat sessions
- **Message State** - Manages optimistic updates and streaming content

## Usage Example

```typescript
import { useMingoChat } from './hooks/use-mingo-chat'

function ChatComponent() {
  const [dialogId, setDialogId] = useState<string | null>(null)
  
  const approvalHandlers = {
    handleApprove: (requestId?: string) => {
      console.log('Approved:', requestId)
    },
    handleReject: (requestId?: string) => {
      console.log('Rejected:', requestId)
    },
    approvalStatuses: {}
  }
  
  const {
    messages,
    isLoading,
    isTyping,
    approvals,
    createDialog,
    sendMessage,
    processChunk
  } = useMingoChat(dialogId, approvalHandlers)
  
  const handleCreateChat = async () => {
    const newDialogId = await createDialog()
    if (newDialogId) setDialogId(newDialogId)
  }
  
  const handleSendMessage = async (content: string) => {
    const success = await sendMessage(content)
    if (!success) console.error('Failed to send message')
  }
  
  return (
    <div>
      <button onClick={handleCreateChat}>New Chat</button>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {isTyping && <div>Mingo is typing...</div>}
    </div>
  )
}
```

The hook integrates with the Mingo messages store, handles real-time chunk processing for streaming responses, manages approval workflows, and provides optimistic message updates for a responsive chat experience.
