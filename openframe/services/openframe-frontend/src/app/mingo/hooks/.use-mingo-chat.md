A React hook that manages real-time chat functionality with Mingo AI, providing message handling, streaming responses, and approval workflows.

## Key Components

### Main Hook
- **`useMingoChat`** - Central hook managing chat state, real-time processing, and API interactions
- **`ProcessedMessage`** - Type for processed chat messages with role, content, and metadata
- **`UseMingoChat`** - Return type interface with messages, actions, and state
- **`ApprovalHandlers`** - Interface for handling approval requests in chat flows

### Core Features
- Real-time message streaming and chunk processing
- Dialog creation and message sending
- Approval system integration with pending request management
- Typing indicators and loading states
- Error handling and toast notifications
- Welcome message management
