A React hook that provides comprehensive chat functionality for the Mingo AI assistant, including real-time message streaming, approval workflows, and state management. It integrates with the Mingo API service and handles both user interactions and assistant responses with typing indicators and error handling.

## Key Components

**Main Hook:**
- `useMingoChat` - Primary hook providing complete chat interface

**Core State Management:**
- `messages` - Processed chat messages with filtering
- `isLoading/isTyping` - Loading and typing state indicators
- `approvals` - Pending approval requests from assistant

**Message Operations:**
- `createDialog` - Creates new chat sessions
- `sendMessage` - Sends user messages to assistant
- `processChunk` - Handles real-time streaming data

**Real-time Processing:**
- Integration with `useRealtimeChunkProcessor` for live updates
- Automatic typing state management during streaming
- Error handling and recovery mechanisms

## Usage Example

```typescript
import { useMingoChat } from './hooks/use-mingo-chat'

function ChatInterface() {
  const dialogId = 'chat-123'
  
  const approvalHandlers = {
    handleApprove: (requestId?: string) => {
      console.log('Approved:', requestId)
    },
    handleReject: (requestId?: string) => {
      console.log('Rejected:', requestId)
    },
    approvalStatuses: {}
  }

  const {
    messages,
    isLoading,
    sendMessage,
    createDialog,
    approvals,
    isTyping,
    processChunk
  } = useMingoChat(dialogId, approvalHandlers)

  const handleSendMessage = async () => {
    const success = await sendMessage("Help me deploy my application")
    if (success) {
      console.log('Message sent successfully')
    }
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>
          <strong>{msg.name}:</strong> {msg.content}
        </div>
      ))}
      {isTyping && <div>Mingo is typing...</div>}
      {approvals.length > 0 && <div>Pending approvals: {approvals.length}</div>}
    </div>
  )
}
```
