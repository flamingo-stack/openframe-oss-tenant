A React hook that provides complete chat functionality for interacting with Mingo AI assistant, including message management, dialog creation, and approval handling.

## Key Components

**Main Hook:**
- `useMingoChat(dialogId)` - Primary hook that manages chat state and operations

**Core Functions:**
- `createDialog()` - Creates new chat dialog and returns dialog ID
- `sendMessage(content, targetDialogId?)` - Sends message to Mingo with optimistic updates
- Message filtering and processing for display
- Approval system extraction from message segments

**State Management:**
- Messages with role-based filtering (user/assistant/error)
- Typing indicators and loading states
- Pending approval requests extraction
- Dialog creation state tracking

## Usage Example

```typescript
import { useMingoChat } from './hooks/use-mingo-chat'

function MingoChatComponent({ dialogId }: { dialogId: string | null }) {
  const {
    messages,
    sendMessage,
    createDialog,
    isTyping,
    approvals,
    isCreatingDialog
  } = useMingoChat(dialogId)

  const handleSendMessage = async (content: string) => {
    const success = await sendMessage(content)
    if (!success) {
      console.error('Failed to send message')
    }
  }

  const handleCreateDialog = async () => {
    const newDialogId = await createDialog()
    if (newDialogId) {
      // Navigate to new dialog
      router.push(`/chat/${newDialogId}`)
    }
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id} className={msg.role}>
          {msg.content}
        </div>
      ))}
      {approvals.length > 0 && (
        <div>Pending approvals: {approvals.length}</div>
      )}
      {isTyping && <div>Mingo is typing...</div>}
    </div>
  )
}
```

The hook integrates with Zustand store for state management and TanStack Query for server communication, providing optimistic updates and error handling for a smooth chat experience.
