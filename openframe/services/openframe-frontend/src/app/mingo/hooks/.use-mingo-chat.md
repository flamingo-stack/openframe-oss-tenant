This hook provides a complete chat interface for interacting with the Mingo AI assistant, handling real-time message streaming, approvals, and dialog management.

## Key Components

- **Message Management**: Processes and filters chat messages, handling different content types and roles
- **Real-time Processing**: Integrates with chunk processor for streaming responses and live updates
- **Dialog Operations**: Creates new chat sessions and sends messages with optimistic updates
- **Approval System**: Manages pending approval requests from the assistant
- **State Management**: Tracks typing indicators, loading states, and message history
- **Error Handling**: Displays error messages and handles failed operations gracefully

## Usage Example

```typescript

  const approvalHandlers = {
    handleApprove: (requestId?: string) => {

    isTyping,

    const success = await sendMessage(content)
    if (!success) {
      console.error('Failed to send message')
    }
  }

  const handleCreateDialog = async () => {
    const newDialogId = await createDialog()
    if (newDialogId) {
      // Navigate to new dialog
    }
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>
          <strong>{msg.name}:</strong> {msg.content}
        </div>

        <div>Pending approvals: {approvals.length}</div>
      )}
    </div>
  )
}
```
