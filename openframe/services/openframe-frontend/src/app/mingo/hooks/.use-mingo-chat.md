A React hook that manages chat interactions with the Mingo AI assistant, handling real-time message streaming, approvals, and dialog management.

## Key Components

- **useMingoChat**: Main hook providing complete chat functionality
- **ProcessedMessage**: Interface for rendered chat messages
- **ApprovalHandlers**: Interface for handling approval requests
- **Real-time processing**: Integration with NATS streaming for live message updates
- **Message state management**: Uses Zustand store for persistent chat state
- **Dialog lifecycle**: Create, send messages, and manage chat sessions

## Usage Example

```typescript
import { useMingoChat } from './hooks/use-mingo-chat'

function ChatInterface({ dialogId }: { dialogId: string | null }) {
  const approvalHandlers = {
    handleApprove: (requestId?: string) => {
      console.log('Approved:', requestId)
    },
    handleReject: (requestId?: string) => {
      console.log('Rejected:', requestId)
    },
    approvalStatuses: {}
  }

  const {
    messages,
    isLoading,
    isTyping,
    approvals,
    createDialog,
    sendMessage,
    processChunk
  } = useMingoChat(dialogId, approvalHandlers)

  const handleSend = async (content: string) => {
    const success = await sendMessage(content)
    if (!success) {
      console.error('Failed to send message')
    }
  }

  const handleCreateDialog = async () => {
    const newDialogId = await createDialog()
    if (newDialogId) {
      // Navigate to new dialog
    }
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>
          <strong>{msg.name}:</strong> {msg.content}
        </div>
      ))}
      {isTyping && <div>Mingo is typing...</div>}
      {approvals.length > 0 && (
        <div>Pending approvals: {approvals.length}</div>
      )}
    </div>
  )
}
```

The hook automatically handles welcome messages, error states, real-time chunk processing, and integrates with the broader Flamingo messaging system for seamless AI assistant interactions.
