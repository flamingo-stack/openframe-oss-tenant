A React hook that manages Mingo AI chat functionality, providing real-time messaging, approval workflows, and streaming response processing.

## Key Components

**Main Hook:**
- `useMingoChat` - Complete chat management with real-time processing

**Core Features:**
- Message state management with optimistic updates
- Real-time chunk processing for streaming responses
- Approval request handling for administrative actions
- Dialog creation and message sending
- Typing indicators and loading states
- Error handling with user feedback

**Types:**
- `ProcessedMessage` - Formatted message for UI display
- `UseMingoChat` - Hook return interface
- `ApprovalHandlers` - Approval workflow callbacks

## Usage Example

```typescript
      console.error('Failed to send message')
    }

    <div>
      {messages.map(message => (
        <div key={message.id}>
          <strong>{message.name}:</strong> {message.content}
        </div>

      {approvals.map(approval => (
        <ApprovalComponent key={approval.id} approval={approval} />
      ))}
    </div>
  )
}
```

The hook integrates with Zustand stores for state management, React Query for API operations, and the OpenFrame real-time system for streaming responses. It automatically handles welcome messages, error states, and maintains chat continuity across sessions.
