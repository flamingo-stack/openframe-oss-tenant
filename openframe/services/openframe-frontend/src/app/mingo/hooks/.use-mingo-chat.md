A React hook for managing real-time chat interactions with Mingo AI assistant, providing message handling, streaming responses, approval workflows, and dialog management.

## Key Components

### Main Hook
- `useMingoChat` - Core hook for chat functionality with dialog management and real-time processing

### Core Features
- **Message Management** - Send/receive messages with optimistic updates
- **Real-time Streaming** - Process chunks and display typing indicators
- **Approval System** - Handle approval requests with callbacks
- **Dialog Creation** - Create new chat sessions
- **Error Handling** - Display error messages and toast notifications

### Types
- `ProcessedMessage` - Formatted message structure for UI display
- `UseMingoChat` - Hook return interface
- `ApprovalHandlers` - Approval callback configuration

## Usage Example

```typescript
import { useMingoChat } from './use-mingo-chat'

function ChatComponent({ dialogId }: { dialogId: string | null }) {
  const {
    messages,
    isLoading,
    sendMessage,
    createDialog,
    approvals,
    isTyping,
    processChunk
  } = useMingoChat(dialogId, {
    handleApprove: (requestId) => {
      console.log('Approved:', requestId)
    },
    handleReject: (requestId) => {
      console.log('Rejected:', requestId)
    },
    approvalStatuses: {}
  })

  const handleSend = async (message: string) => {
    const success = await sendMessage(message)
    if (!success) {
      console.error('Failed to send message')
    }
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>
          <strong>{msg.name}:</strong> {msg.content}
        </div>
      ))}
      {isTyping && <div>Mingo is typing...</div>}
    </div>
  )
}
```
