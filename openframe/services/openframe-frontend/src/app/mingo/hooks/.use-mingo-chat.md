A React hook for managing Mingo AI chat functionality within the OpenFrame platform, providing message handling, dialog creation, and approval system management.

## Key Components

- **ProcessedMessage**: Interface defining the structure of chat messages with content, role, and metadata
- **UseMingoChat**: Interface defining the hook's return type with messages, actions, and state
- **useMingoChat**: Main hook function that manages chat state and operations
- **Message Processing**: Logic to filter and transform raw messages for UI consumption
- **Approval System**: Extraction and management of pending approval requests from message content

## Usage Example

```typescript
import { useMingoChat } from './hooks/use-mingo-chat'

function MingoChat() {
  const { 
    messages, 
    sendMessage, 
    createDialog, 
    isTyping,
    approvals 
  } = useMingoChat('dialog-123')

  const handleSendMessage = async () => {
    const success = await sendMessage('Help me troubleshoot this issue')
    if (success) {
      console.log('Message sent successfully')
    }
  }

  const handleCreateNewDialog = async () => {
    const newDialogId = await createDialog()
    if (newDialogId) {
      console.log('New dialog created:', newDialogId)
    }
  }

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{msg.content}</div>
      ))}
      {approvals.length > 0 && (
        <div>Pending approvals: {approvals.length}</div>
      )}
    </div>
  )
}
```

The hook integrates with Zustand store for state management, React Query for server operations, and provides optimistic updates for better user experience.
