A React hook that processes real-time streaming messages from NATS for Mingo AI chat dialogs, handling message chunks, tool executions, and approval workflows with separate processing for active and background conversations.

## Key Components

- **`useMingoRealtimeProcessor`** - Main hook that manages real-time message processing
- **`DialogState`** - Interface tracking streaming state per dialog
- **`processChunk`** - Processes incoming NATS message chunks and routes to appropriate dialog
- **`processDialogChunk`** - Handles different chunk types (text, tools, approvals) for a specific dialog
- **`getDialogState`** - Retrieves or creates dialog state management
- **Message processors** - Handle various message types including streaming text, tool execution, and approval requests

## Usage Example

```typescript
import { useMingoRealtimeProcessor } from './hooks/use-mingo-realtime-processor'

function MingoChat() {
  const processor = useMingoRealtimeProcessor({
    activeDialogId: currentDialogId,
    onActiveStreamStart: () => setIsStreaming(true),
    onActiveStreamEnd: () => setIsStreaming(false),
    onActiveError: (error) => showError(error),
    onBackgroundStreamStart: (dialogId) => markAsActive(dialogId),
    onBackgroundStreamEnd: (dialogId) => markAsComplete(dialogId),
    onBackgroundUnreadIncrement: (dialogId) => incrementUnread(dialogId),
  })

  // Process incoming NATS chunks
  useEffect(() => {
    const subscription = natsClient.subscribe('mingo.chat.*', (chunk, messageType) => {
      processor.processChunk(chunk, messageType)
    })
    
    return () => subscription.unsubscribe()
  }, [processor])

  return <ChatInterface />
}
```

The hook manages streaming states across multiple dialogs, differentiates between active and background conversations, and handles various message types including text streaming, tool execution results, and approval workflows through the Mingo AI system.
