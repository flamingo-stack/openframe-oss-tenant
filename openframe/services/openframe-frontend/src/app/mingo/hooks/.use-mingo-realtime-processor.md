A React hook that manages real-time message processing for Mingo AI chat dialogs, handling streaming messages, tool executions, approval requests, and background message updates across multiple dialog sessions.

## Key Components

- **useMingoRealtimeProcessor** - Main hook that processes streaming chunks from NATS messages into dialog messages
- **DialogState** - Interface tracking streaming state per dialog (isStreaming, currentStreamingMessage, hasReceivedFirstTextChunk)
- **processChunk** - Core processor that routes chunks to appropriate dialog handlers
- **processDialogChunk** - Handles different message types (text, tool_execution, approval_request, etc.)
- **Dialog state management** - Maintains per-dialog streaming state with automatic cleanup

## Usage Example

```typescript
import { useMingoRealtimeProcessor } from './use-mingo-realtime-processor'

function ChatComponent() {
  const processor = useMingoRealtimeProcessor({
    activeDialogId: 'dialog-123',
    onActiveStreamStart: () => console.log('Stream started'),
    onActiveStreamEnd: () => console.log('Stream ended'),
    onActiveError: (error) => console.error('Stream error:', error),
    onBackgroundStreamStart: (dialogId) => console.log(`Background stream started: ${dialogId}`),
    onBackgroundStreamEnd: (dialogId) => console.log(`Background stream ended: ${dialogId}`),
    onBackgroundUnreadIncrement: (dialogId) => updateUnreadCount(dialogId),
  })

  // Process incoming NATS chunks
  useEffect(() => {
    const handleChunk = (chunk: ChunkData) => {
      processor.processChunk(chunk, 'CHAT', 'dialog-123')
    }
    
    natsSubscription.on('message', handleChunk)
    return () => processor.cleanup()
  }, [processor])

  return <div>Chat Interface</div>
}
```

The hook automatically differentiates between active and background dialogs, managing streaming states independently and triggering appropriate callbacks for UI updates and unread message tracking.
