A React hook that processes real-time streaming messages from the Mingo AI assistant, handling both active and background dialog states with proper message routing and streaming coordination.

## Key Components

- **useMingoRealtimeProcessor**: Main hook that manages streaming message processing across multiple dialogs
- **processChunk**: Processes incoming NATS message chunks and routes them to appropriate dialog handlers
- **processDialogChunk**: Handles message processing for individual dialogs with streaming state management
- **DialogState**: Tracks streaming status and current message for each dialog
- **Message handling**: Supports text streaming, tool execution, approval requests/results, and admin messages

## Usage Example

```typescript
import { useMingoRealtimeProcessor } from './use-mingo-realtime-processor'

function ChatInterface() {
  const [activeDialogId, setActiveDialogId] = useState<string | null>(null)

  const processor = useMingoRealtimeProcessor({
    activeDialogId,
    onActiveStreamStart: () => console.log('Active stream started'),
    onActiveStreamEnd: () => console.log('Active stream ended'),
    onActiveError: (error) => console.error('Stream error:', error),
    onBackgroundStreamStart: (dialogId) => console.log('Background stream started:', dialogId),
    onBackgroundStreamEnd: (dialogId) => console.log('Background stream ended:', dialogId),
    onBackgroundUnreadIncrement: (dialogId) => updateUnreadCount(dialogId),
  })

  // Process incoming NATS messages
  const handleIncomingChunk = (chunk: ChunkData, messageType: NatsMessageType) => {
    processor.processChunk(chunk, messageType)
  }

  // Clean up on unmount
  useEffect(() => {
    return () => processor.cleanup()
  }, [processor])

  return <div>Chat interface content</div>
}
```

The hook differentiates between active dialogs (visible to user) and background dialogs, providing appropriate callbacks for UI updates and unread message tracking. It maintains streaming state per dialog and handles various message types including text chunks, tool executions, and approval workflows.
