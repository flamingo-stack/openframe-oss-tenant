A React hook that processes real-time streaming messages from Mingo AI, handling both active dialog messages and background messages across multiple dialogs simultaneously.

## Key Components

- **useMingoRealtimeProcessor**: Main hook that processes streaming chunks from NATS messages
- **DialogState**: Interface tracking streaming state for each dialog
- **processDialogChunk**: Core processor that handles different message actions (text, tools, approvals)
- **processChunk**: Entry point that routes chunks to appropriate dialog processors
- **getDialogStreamingMessage**: Retrieves current streaming message for a dialog

## Usage Example

```typescript
import { useMingoRealtimeProcessor } from './use-mingo-realtime-processor'

function ChatInterface() {
  const processor = useMingoRealtimeProcessor({
    activeDialogId: 'dialog-123',
    onActiveStreamStart: () => setIsStreaming(true),
    onActiveStreamEnd: () => setIsStreaming(false),
    onActiveError: (error) => showError(error),
    onBackgroundStreamStart: (dialogId) => markDialogActive(dialogId),
    onBackgroundStreamEnd: (dialogId) => markDialogComplete(dialogId),
    onBackgroundUnreadIncrement: (dialogId) => incrementUnread(dialogId),
  })

  // Process incoming NATS chunks
  const handleNatsMessage = (chunk: ChunkData, messageType: NatsMessageType) => {
    processor.processChunk(chunk, messageType)
  }

  // Get current streaming message for dialog
  const streamingMessage = processor.getDialogStreamingMessage('dialog-123')

  return <div>{/* Chat UI */}</div>
}
```

The hook manages complex streaming scenarios including text streaming, tool execution messages, approval requests/results, and maintains separate state for active vs background dialogs with proper unread message tracking.
