A React hook that processes real-time streaming messages for Mingo AI chat dialogs, handling message parsing, state management, and routing between active and background conversations.

## Key Components

- **`useMingoRealtimeProcessor`** - Main hook that manages real-time message processing
- **`processChunk`** - Parses incoming NATS message chunks and routes them to appropriate dialogs
- **`processDialogChunk`** - Handles different message types (text, tool execution, approval requests)
- **`DialogState`** - Interface tracking streaming state for individual dialogs
- **Message routing** - Differentiates between active dialog and background dialog message handling

## Usage Example

```typescript
import { useMingoRealtimeProcessor } from './use-mingo-realtime-processor'

function ChatComponent() {
  const processor = useMingoRealtimeProcessor({
    activeDialogId: 'dialog-123',
    onActiveStreamStart: () => setIsStreaming(true),
    onActiveStreamEnd: () => setIsStreaming(false),
    onActiveError: (error) => showError(error),
    onBackgroundStreamStart: (dialogId) => updateBadge(dialogId),
    onBackgroundStreamEnd: (dialogId) => finalizeBadge(dialogId),
    onBackgroundUnreadIncrement: (dialogId) => incrementUnread(dialogId),
  })

  // Process incoming NATS messages
  useEffect(() => {
    natsConnection.subscribe('chat.stream', (chunk) => {
      processor.processChunk(chunk, 'CHAT_STREAM')
    })
  }, [processor])

  return <ChatInterface />
}
```

The hook manages streaming state for multiple dialogs simultaneously, automatically creating and updating messages as chunks arrive, and provides cleanup utilities for dialog management.
