A React hook that processes real-time streaming messages from NATS for Mingo AI assistant dialogs, handling both active (foreground) and background dialog states with message streaming, tool execution, and approval workflows.

## Key Components

- **`useMingoRealtimeProcessor`** - Main hook that manages real-time message processing for multiple dialogs
- **`DialogState`** - Interface tracking streaming state for individual dialogs 
- **`processDialogChunk`** - Core function that processes different types of message chunks (text, tools, approvals)
- **State Management** - Integrates with Zustand stores for dialog details and background messages
- **Message Types** - Handles TEXT, TOOL_EXECUTION, APPROVAL_REQUEST, and APPROVAL_RESULT message types

## Usage Example

```typescript
const MingoChat = () => {
  const [activeDialogId, setActiveDialogId] = useState<string | null>(null)
  
  const processor = useMingoRealtimeProcessor({
    activeDialogId,
    onActiveStreamStart: () => setIsStreaming(true),
    onActiveStreamEnd: () => setIsStreaming(false),
    onActiveError: (error) => toast.error(error),
    onBackgroundStreamStart: (dialogId) => markDialogAsActive(dialogId),
    onBackgroundStreamEnd: (dialogId) => markDialogAsComplete(dialogId),
    onBackgroundUnreadIncrement: (dialogId) => incrementUnreadCount(dialogId),
  })

  // Process incoming NATS messages
  useEffect(() => {
    const subscription = natsClient.subscribe('mingo.dialog.*', (chunk, messageType) => {
      processor.processChunk(chunk, messageType)
    })
    
    return () => subscription.unsubscribe()
  }, [processor])

  return <ChatInterface />
}
```

The hook automatically handles message streaming state, creates appropriate message objects, and routes them to the correct stores based on whether the dialog is currently active or running in the background.
