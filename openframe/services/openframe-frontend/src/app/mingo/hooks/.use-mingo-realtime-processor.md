A React hook that processes real-time streaming data chunks from NATS for Mingo AI chat dialogs, managing both active and background message streams with proper state tracking and store updates.

## Key Components

- **Main Hook**: `useMingoRealtimeProcessor` - Processes incoming NATS message chunks
- **Dialog State Management**: Tracks streaming state per dialog using refs
- **Message Processing**: Handles different action types (text, tool execution, approval requests)
- **Active vs Background**: Differentiates between currently viewed and background dialogs
- **Store Integration**: Updates both dialog details and background messages stores

## Usage Example

```typescript
import { useMingoRealtimeProcessor } from './use-mingo-realtime-processor'

function MingoChat({ activeDialogId }: { activeDialogId: string | null }) {
  const processor = useMingoRealtimeProcessor({
    activeDialogId,
    onActiveStreamStart: () => setIsStreaming(true),
    onActiveStreamEnd: () => setIsStreaming(false),
    onActiveError: (error) => showError(error),
    onBackgroundStreamStart: (dialogId) => markAsStreaming(dialogId),
    onBackgroundStreamEnd: (dialogId) => markAsComplete(dialogId),
    onBackgroundUnreadIncrement: (dialogId) => incrementUnread(dialogId),
  })

  // Process incoming NATS messages
  const handleNatsMessage = (chunk: ChunkData, messageType: NatsMessageType) => {
    processor.processChunk(chunk, messageType)
  }

  // Get current streaming message for a dialog
  const streamingMessage = processor.getDialogStreamingMessage(activeDialogId!)

  return (
    <div>
      {/* Chat UI components */}
    </div>
  )
}
```

The hook handles streaming text updates, tool executions, approval workflows, and maintains separate state for active vs background conversations, ensuring smooth real-time chat experiences.
