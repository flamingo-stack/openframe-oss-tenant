A React hook that processes real-time message chunks from the Mingo AI assistant, managing streaming states for both active and background dialogs while handling different message types including text, tool executions, and approval requests.

## Key Components

- **useMingoRealtimeProcessor**: Main hook that processes real-time NATS message chunks
- **DialogState**: Interface tracking streaming state per dialog
- **processDialogChunk**: Processes individual chunks based on action type (message_start, text, tool_execution, etc.)
- **processChunk**: Entry point that routes chunks to appropriate dialog processors
- **Dialog management utilities**: Functions for resetting dialogs, getting streaming messages, and cleanup

## Usage Example

```typescript
import { useMingoRealtimeProcessor } from './use-mingo-realtime-processor'

function MingoChat() {
  const processor = useMingoRealtimeProcessor({
    activeDialogId: 'dialog-123',
    onActiveStreamStart: () => setIsStreaming(true),
    onActiveStreamEnd: () => setIsStreaming(false),
    onActiveError: (error) => showError(error),
    onBackgroundStreamStart: (dialogId) => markAsActive(dialogId),
    onBackgroundStreamEnd: (dialogId) => markAsComplete(dialogId),
    onBackgroundUnreadIncrement: (dialogId) => incrementUnread(dialogId)
  })

  // Process incoming NATS chunks
  const handleNatsMessage = (chunk: ChunkData, messageType: NatsMessageType) => {
    processor.processChunk(chunk, messageType)
  }

  // Reset dialog when switching conversations
  const switchDialog = (newDialogId: string) => {
    processor.resetDialog(currentDialogId)
    setCurrentDialogId(newDialogId)
  }

  return <div>/* Chat UI */</div>
}
```

The hook manages complex real-time message streaming with support for text streaming, tool execution results, approval workflows, and background dialog handling with unread message tracking.
