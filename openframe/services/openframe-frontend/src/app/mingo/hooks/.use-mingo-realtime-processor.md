A React hook that processes real-time NATS message chunks for Mingo AI chat dialogs, handling streaming text, tool executions, approval requests, and background message updates.

## Key Components

- **`useMingoRealtimeProcessor`** - Main hook that processes streaming chunks and manages dialog states
- **`processChunk`** - Processes incoming NATS chunks and routes them to appropriate dialogs
- **`processDialogChunk`** - Handles different chunk types (message_start, text, tool_execution, etc.)
- **`DialogState`** - Interface tracking streaming status and current message for each dialog
- **`resetDialog`** - Clears state for a specific dialog
- **`getDialogStreamingMessage`** - Retrieves current streaming message for a dialog

## Usage Example

```typescript
import { useMingoRealtimeProcessor } from './use-mingo-realtime-processor'

function ChatInterface() {
  const processor = useMingoRealtimeProcessor({
    activeDialogId: 'dialog-123',
    onActiveStreamStart: () => setIsStreaming(true),
    onActiveStreamEnd: () => setIsStreaming(false),
    onActiveError: (error) => showError(error),
    onBackgroundStreamStart: (dialogId) => markDialogActive(dialogId),
    onBackgroundStreamEnd: (dialogId) => markDialogComplete(dialogId),
    onBackgroundUnreadIncrement: (dialogId) => incrementUnread(dialogId),
  })

  // Process incoming NATS chunks
  useEffect(() => {
    const handleChunk = (chunk: ChunkData, messageType: NatsMessageType) => {
      processor.processChunk(chunk, messageType)
    }
    
    // Subscribe to NATS stream
    return subscribeToNatsStream(handleChunk)
  }, [processor])

  return <div>Chat UI</div>
}
```

The hook manages streaming state for multiple dialogs simultaneously, differentiating between active (foreground) and background dialogs, and handles various message types including text streaming, tool executions, and approval workflows.
