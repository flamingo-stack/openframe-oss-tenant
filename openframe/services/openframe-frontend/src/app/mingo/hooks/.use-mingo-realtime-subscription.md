A React hook and component for managing real-time NATS subscriptions for Mingo chat dialogs, with support for multiple concurrent subscriptions and message catchup functionality.

## Key Components

- **`useMingoRealtimeSubscription`** - Main hook that manages subscription state for multiple dialogs
- **`DialogSubscription`** - Component that handles individual dialog subscriptions via NATS WebSocket
- **`getApiBaseUrl`** - Helper to determine API base URL from runtime environment or window location
- **`getAccessToken`** - Helper to retrieve access token from localStorage for dev environments

## Usage Example

```typescript
// Main component managing multiple dialog subscriptions
function MingoChat() {
  const [activeDialogId, setActiveDialogId] = useState<string | null>(null)
  
  const {
    subscribeToDialog,
    unsubscribeFromDialog,
    subscribedDialogs,
    connectionState
  } = useMingoRealtimeSubscription(activeDialogId, {
    onChunkReceived: (dialogId, chunk, messageType) => {
      console.log(`Received chunk for dialog ${dialogId}:`, chunk)
    }
  })

  // Subscribe to a new dialog
  const handleSelectDialog = (dialogId: string) => {
    setActiveDialogId(dialogId)
    subscribeToDialog(dialogId) // Automatically subscribes if not already
  }

  return (
    <div>
      {Array.from(subscribedDialogs).map(dialogId => (
        <DialogSubscription
          key={dialogId}
          dialogId={dialogId}
          isActive={dialogId === activeDialogId}
          processChunk={(targetDialogId, chunk, messageType) => {
            // Handle incoming chunks for this specific dialog
            updateMessagesForDialog(targetDialogId, chunk)
          }}
        />
      ))}
    </div>
  )
}
```

The hook automatically handles subscription lifecycle, connection state tracking, and integrates with the Mingo messages store for unread message management.
