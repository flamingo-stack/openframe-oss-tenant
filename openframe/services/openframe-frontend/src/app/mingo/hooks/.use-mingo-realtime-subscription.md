A React hook and component for managing real-time NATS subscriptions in the Mingo chat system, providing unified subscription management across multiple dialogs with automatic catchup and token-based authentication.

## Key Components

**Main Hook:**
- `useMingoRealtimeSubscription` - Primary hook for managing multiple dialog subscriptions
- `DialogSubscription` - Component that handles individual dialog NATS connections

**Core Functions:**
- `subscribeToDialog()` - Adds a dialog to active subscriptions
- `unsubscribeFromDialog()` - Removes a dialog from subscriptions  
- `getSubscriptionState()` - Returns connection/subscription status for a dialog
- `getApiBaseUrl()` - Resolves tenant API base URL
- `getAccessToken()` - Retrieves authentication token from localStorage

**State Management:**
- Tracks subscribed dialogs, connection states, and catchup status
- Integrates with Zustand store for message management
- Handles token refresh via storage events

## Usage Example

```typescript
import { useMingoRealtimeSubscription, DialogSubscription } from './use-mingo-realtime-subscription'

function ChatInterface() {
  const activeDialogId = "dialog-123"
  
  const {
    subscribeToDialog,
    unsubscribeFromDialog,
    getSubscriptionState,
    subscribedDialogs,
    connectionState
  } = useMingoRealtimeSubscription(activeDialogId, {
    onChunkReceived: (dialogId, chunk, messageType) => {
      console.log('Received chunk for dialog:', dialogId)
    }
  })

  const handleJoinDialog = (dialogId: string) => {
    subscribeToDialog(dialogId)
  }

  return (
    <div>
      <div>Connection: {connectionState}</div>
      
      {Array.from(subscribedDialogs).map(dialogId => (
        <DialogSubscription
          key={dialogId}
          dialogId={dialogId}
          isActive={dialogId === activeDialogId}
          processChunk={(targetDialogId, chunk, messageType) => {
            // Handle incoming message chunks
          }}
        />
      ))}
    </div>
  )
}
```

The hook automatically manages subscriptions for the active dialog and provides fine-grained control over multiple concurrent chat connections with proper cleanup and error handling.
