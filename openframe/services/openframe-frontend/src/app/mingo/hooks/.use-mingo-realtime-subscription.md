A React hook for managing realtime NATS subscriptions to Mingo AI chat dialogs with automatic message catchup and multi-dialog support.

## Key Components

- **`useMingoRealtimeSubscription`** - Main hook for managing multiple dialog subscriptions with connection state tracking
- **`DialogSubscription`** - Component for individual dialog NATS subscriptions with chunk processing
- **`getApiBaseUrl`** / **`getAccessToken`** - Utility functions for environment configuration and authentication
- **`DialogSubscriptionState`** - Interface defining subscription status including connection and catchup state

## Usage Example

```typescript
import { useMingoRealtimeSubscription, DialogSubscription } from './use-mingo-realtime-subscription'

function ChatComponent() {
  const activeDialogId = "dialog-123"
  
  const {
    subscribeToDialog,
    unsubscribeFromDialog,
    subscribedDialogs,
    connectionState
  } = useMingoRealtimeSubscription(activeDialogId, {
    onChunkReceived: (dialogId, chunk, messageType) => {
      console.log('Received chunk for dialog:', dialogId)
    }
  })
  
  const handleProcessChunk = (dialogId: string, chunk: ChunkData, messageType: NatsMessageType) => {
    // Process incoming chat chunks
  }
  
  return (
    <>
      {Array.from(subscribedDialogs).map(dialogId => (
        <DialogSubscription
          key={dialogId}
          dialogId={dialogId}
          isActive={dialogId === activeDialogId}
          processChunk={handleProcessChunk}
        />
      ))}
      
      <div>Connection: {connectionState}</div>
    </>
  )
}
```

The hook provides methods to dynamically subscribe/unsubscribe from dialogs and tracks connection state across all subscriptions. Each `DialogSubscription` component handles NATS messaging and automatic message history catchup for its specific dialog.
