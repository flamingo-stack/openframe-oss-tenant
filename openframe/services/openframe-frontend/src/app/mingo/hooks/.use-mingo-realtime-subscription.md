A React hook that manages real-time NATS WebSocket subscriptions for Mingo chat dialogs, enabling live message streaming with automatic catchup functionality.

## Key Components

- **`useMingoRealtimeSubscription`** - Main hook for managing multiple dialog subscriptions with connection state tracking
- **`DialogSubscription`** - Component that handles individual dialog NATS subscriptions and chunk processing
- **`getApiBaseUrl`** - Utility to resolve the API base URL from environment or window location
- **`getAccessToken`** - Helper to retrieve authentication token from localStorage

## Usage Example

```typescript
import { useMingoRealtimeSubscription, DialogSubscription } from './use-mingo-realtime-subscription'
import type { ChunkData, NatsMessageType } from '@flamingo-stack/openframe-frontend-core'

function ChatComponent() {
  const {
    subscribeToDialog,
    unsubscribeFromDialog,
    subscribedDialogs,
    connectionState
  } = useMingoRealtimeSubscription('dialog-123', {
    onChunkReceived: (dialogId, chunk, messageType) => {
      console.log(`Received chunk for ${dialogId}:`, chunk)
    }
  })

  const processChunk = (targetDialogId: string, chunk: ChunkData, messageType: NatsMessageType) => {
    // Handle incoming message chunks
    console.log('Processing chunk:', chunk)
  }

  return (
    <div>
      <p>Connection: {connectionState}</p>
      {Array.from(subscribedDialogs).map(dialogId => (
        <DialogSubscription
          key={dialogId}
          dialogId={dialogId}
          isActive={dialogId === 'dialog-123'}
          processChunk={processChunk}
        />
      ))}
    </div>
  )
}
```

The hook automatically subscribes to the active dialog, handles token-based authentication for development environments, and provides methods to manage dialog subscriptions with proper cleanup.
