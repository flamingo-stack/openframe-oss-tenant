A React hook for managing real-time subscriptions to Mingo AI chat dialogs using NATS WebSocket connections. Provides unified subscription management across multiple dialogs with automatic catchup and state tracking.

## Key Components

- **`useMingoRealtimeSubscription`** - Main hook for managing multiple dialog subscriptions
- **`DialogSubscription`** - Component for individual dialog subscription management
- **`DialogSubscriptionState`** - Interface defining subscription status and connection state
- **`UseMingoRealtimeSubscriptionOptions`** - Configuration options for chunk processing callbacks
- **`getApiBaseUrl`** / **`getAccessToken`** - Utility functions for environment configuration

## Usage Example

```typescript
    <>

      ))}
    </>
  )
}
```

The hook automatically manages NATS connections, handles catchup for missed messages, and provides real-time streaming of admin messages across multiple chat dialogs with proper state management and cleanup.
