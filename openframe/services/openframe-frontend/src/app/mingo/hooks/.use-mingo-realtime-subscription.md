A React hook and component system that manages realtime NATS WebSocket subscriptions for Mingo AI chat dialogs with automatic chunk catchup and multi-topic support.

## Key Components

### Main Hook
- **`useMingoRealtimeSubscription`** - Core hook managing multiple dialog subscriptions with connection state
- **`DialogSubscription`** - Component handling individual dialog NATS subscriptions

### Supporting Functions
- **`getApiBaseUrl`** - Resolves tenant host URL for WebSocket connections
- **`getAccessToken`** - Retrieves authentication token from localStorage

### State Management
- **`DialogSubscriptionState`** - Interface tracking subscription status and catchup progress
- **`subscribedDialogs`** - Set of active dialog subscriptions
- **`connectionState`** - Global connection status tracking

## Usage Example

```typescript
function MingoChat() {
  const [activeDialogId, setActiveDialogId] = useState<string | null>(null)
  
  const {

    onChunkReceived: (dialogId, chunk, messageType) => {
      console.log('Received chunk:', { dialogId, chunk, messageType })
    }
  })

  const processChunk = (dialogId: string, chunk: ChunkData, messageType: NatsMessageType) => {
    // Handle incoming chat chunks
    updateChatMessages(dialogId, chunk)
  }

  return (
    <div>
      <div>Status: {connectionState}</div>
      {Array.from(subscribedDialogs).map(dialogId => (
        <DialogSubscription
          key={dialogId}
          dialogId={dialogId}
          isActive={dialogId === activeDialogId}
          processChunk={processChunk}
        />
      ))}
    </div>
  )
}
```

The hook provides subscription management while individual `DialogSubscription` components handle the actual NATS connections and chunk processing for each dialog.
