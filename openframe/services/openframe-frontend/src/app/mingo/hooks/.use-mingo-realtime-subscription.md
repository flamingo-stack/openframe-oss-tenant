A React hook that manages real-time WebSocket subscriptions for Mingo chat dialogs using NATS messaging, providing unified subscription management across multiple conversations.

## Key Components

**Main Hook:**
- `useMingoRealtimeSubscription` - Primary hook for managing multiple dialog subscriptions
- `DialogSubscription` - Component for individual dialog subscription handling

**Core Functions:**
- `subscribeToDialog()` - Subscribe to a specific dialog's real-time updates
- `unsubscribeFromDialog()` - Remove subscription from a dialog
- `getSubscriptionState()` - Get current subscription status for a dialog

**State Management:**
- Tracks subscribed dialogs, connection states, and catchup status
- Integrates with Zustand store for message management
- Handles authentication token changes via localStorage events

## Usage Example

```typescript
import { useMingoRealtimeSubscription, DialogSubscription } from './use-mingo-realtime-subscription'

function ChatContainer() {
  const { 
    subscribeToDialog, 
    unsubscribeFromDialog, 
    subscribedDialogs,
    connectionState 
  } = useMingoRealtimeSubscription(
    activeDialogId,
    {
      onChunkReceived: (dialogId, chunk, messageType) => {
        console.log(`Received chunk for dialog ${dialogId}:`, chunk)
      }
    }
  )

  const handleJoinDialog = (dialogId: string) => {
    subscribeToDialog(dialogId)
  }

  return (
    <div>
      <div>Connection: {connectionState}</div>
      
      {/* Render subscription components for each active dialog */}
      {Array.from(subscribedDialogs).map(dialogId => (
        <DialogSubscription
          key={dialogId}
          dialogId={dialogId}
          isActive={dialogId === activeDialogId}
          processChunk={(targetDialogId, chunk, messageType) => {
            // Handle incoming message chunks
            processMessage(targetDialogId, chunk, messageType)
          }}
        />
      ))}
    </div>
  )
}
```

The hook automatically handles NATS WebSocket connections, chunk catchup for message history, and maintains subscription state across component re-renders. It supports development mode with token-based authentication and integrates with the broader OpenFrame messaging infrastructure.
