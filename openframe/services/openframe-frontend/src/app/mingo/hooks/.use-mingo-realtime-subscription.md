A React hook for managing real-time NATS subscriptions to Mingo chat dialogs with catchup functionality and multi-topic support.

## Key Components

**Main Hook:**
- `useMingoRealtimeSubscription` - Primary hook for managing dialog subscriptions and connection state
- `DialogSubscription` - React component that handles individual dialog NATS subscriptions

**Core Interfaces:**
- `UseMingoRealtimeSubscriptionOptions` - Configuration options for chunk reception callbacks
- `DialogSubscriptionState` - Tracks subscription, connection, and catchup status per dialog
- `DialogSubscriptionProps` - Props for the subscription component

**Helper Functions:**
- `getApiBaseUrl()` - Retrieves API base URL from environment or window location
- `getAccessToken()` - Gets access token from localStorage for authenticated connections

## Usage Example

```typescript
// In a chat component
function MingoChat() {
  const { 
    subscribeToDialog, 
    unsubscribeFromDialog, 
    subscribedDialogs,
    connectionState 
  } = useMingoRealtimeSubscription(
    activeDialogId,
    {
      onChunkReceived: (dialogId, chunk, messageType) => {
        console.log('Received chunk:', chunk)
        // Process incoming message chunks
      }
    }
  )

  // Subscribe to a new dialog
  const handleOpenDialog = (dialogId: string) => {
    subscribeToDialog(dialogId)
  }

  // Render subscription components for each active dialog
  return (
    <>
      {Array.from(subscribedDialogs).map(dialogId => (
        <DialogSubscription
          key={dialogId}
          dialogId={dialogId}
          isActive={dialogId === activeDialogId}
          processChunk={handleChunkProcessing}
        />
      ))}
    </>
  )
}
```

The hook manages connection state, handles token refresh for authenticated environments, and integrates with the Mingo messages store for unread message tracking.
