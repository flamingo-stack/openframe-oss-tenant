A React hook for managing real-time NATS subscriptions for Mingo chat dialogs with chunked message handling and catchup functionality.

## Key Components

- **useMingoRealtimeSubscription** - Main hook for managing multiple dialog subscriptions with connection state tracking
- **DialogSubscription** - Component that handles individual dialog NATS subscriptions with chunk processing
- **getApiBaseUrl** - Utility function to resolve the tenant API base URL from environment or browser
- **getAccessToken** - Utility function to retrieve authentication token from localStorage

## Usage Example

```typescript
import { useMingoRealtimeSubscription, DialogSubscription } from './use-mingo-realtime-subscription'

function ChatComponent() {
  const activeDialogId = 'dialog-123'
  
  // Main subscription manager
  const {
    subscribeToDialog,
    unsubscribeFromDialog,
    subscribedDialogs,
    connectionState,
    getSubscriptionState
  } = useMingoRealtimeSubscription(activeDialogId, {
    onChunkReceived: (dialogId, chunk, messageType) => {
      console.log(`Received chunk for dialog ${dialogId}:`, chunk)
    }
  })

  // Handle chunk processing
  const processChunk = (dialogId: string, chunk: ChunkData, messageType: NatsMessageType) => {
    // Process incoming message chunks
    updateChatMessages(dialogId, chunk)
  }

  return (
    <div>
      {Array.from(subscribedDialogs).map(dialogId => (
        <DialogSubscription
          key={dialogId}
          dialogId={dialogId}
          isActive={dialogId === activeDialogId}
          processChunk={processChunk}
        />
      ))}
    </div>
  )
}
```

The hook automatically manages NATS WebSocket connections, handles authentication tokens, and provides real-time message streaming with proper catchup mechanisms for missed messages.
