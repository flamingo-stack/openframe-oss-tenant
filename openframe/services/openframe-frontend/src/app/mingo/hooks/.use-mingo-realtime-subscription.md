A React hook that manages real-time NATS subscriptions for Mingo chat dialogs, providing centralized subscription management and message handling across multiple active conversations.

## Key Components

- **useMingoRealtimeSubscription** - Main hook for managing dialog subscriptions and connection state
- **DialogSubscription** - React component for individual dialog NATS subscriptions  
- **getApiBaseUrl/getAccessToken** - Utility functions for configuration and authentication
- **DialogSubscriptionState** - Interface tracking subscription, connection, and catchup status
- **MINGO_TOPICS** - Supported NATS message types (`admin-message`)

## Usage Example

```typescript
  const handleJoinDialog = (dialogId: string) => {
    setActiveDialogId(dialogId)
    subscribeToDialog(dialogId)
  }
  
  const processChunk = (dialogId: string, chunk: ChunkData, messageType: NatsMessageType) => {
    // Handle incoming message chunk
    updateChatMessages(dialogId, chunk)
  }
  
  return (
    <div>
      <div>Connection: {connectionState}</div>
      {Array.from(subscribedDialogs).map(dialogId => (
        <DialogSubscription
          key={dialogId}
          dialogId={dialogId}
          isActive={dialogId === activeDialogId}
          processChunk={processChunk}
        />
      ))}
    </div>
  )
}
```

The hook integrates with chunk catchup functionality, manages authentication tokens for dev environments, and provides automatic subscription management for active dialogs. Each subscribed dialog gets its own NATS connection through the `DialogSubscription` component.
