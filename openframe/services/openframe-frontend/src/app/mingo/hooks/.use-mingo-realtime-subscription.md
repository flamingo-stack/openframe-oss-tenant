A React hook for managing real-time Mingo chat subscriptions via NATS WebSocket connections. Provides multi-dialog subscription management with chunk catchup functionality and automatic token-based authentication.

## Key Components

- **`useMingoRealtimeSubscription`** - Main hook managing multiple dialog subscriptions and connection states
- **`DialogSubscription`** - Component for individual dialog subscription handling
- **`getApiBaseUrl`/`getAccessToken`** - Utility functions for configuration and authentication
- **Types**: `UseMingoRealtimeSubscriptionOptions`, `DialogSubscriptionState`, `UseMingoRealtimeSubscription`
- **Constants**: `MINGO_TOPICS` - predefined NATS message types for subscriptions

## Usage Example

```typescript
import { useMingoRealtimeSubscription, DialogSubscription } from './use-mingo-realtime-subscription'

function MingoChat() {
  const {
    subscribeToDialog,
    unsubscribeFromDialog,
    subscribedDialogs,
    connectionState
  } = useMingoRealtimeSubscription(activeDialogId, {
    onChunkReceived: (dialogId, chunk, messageType) => {
      console.log('Received chunk for dialog:', dialogId, chunk)
    }
  })

  const handleJoinDialog = (dialogId: string) => {
    subscribeToDialog(dialogId)
  }

  return (
    <div>
      <p>Connection: {connectionState}</p>
      {Array.from(subscribedDialogs).map(dialogId => (
        <DialogSubscription
          key={dialogId}
          dialogId={dialogId}
          isActive={dialogId === activeDialogId}
          processChunk={handleChunkReceived}
        />
      ))}
    </div>
  )
}
```

The hook integrates with Mingo messages store for unread management and supports development ticket observer mode with token-based authentication.
