A React hook that manages real-time NATS subscriptions for Mingo chat dialogs, handling streaming messages, chunk processing, and connection state management.

## Key Components

- **`useMingoRealtimeSubscription`** - Main hook for managing multiple dialog subscriptions
- **`useDialogChunkProcessor`** - Per-dialog chunk processing with streaming message handling
- **`DialogSubscription`** - Component for individual dialog subscriptions with catchup logic
- **Helper functions** - Token management, URL building, and error handling utilities

## Usage Example

```typescript
// Basic subscription management
const { 
  subscribeToDialog, 
  unsubscribeFromDialog, 
  getSubscriptionState,
  connectionState 
} = useMingoRealtimeSubscription('dialog-123', {
  onChunkReceived: (dialogId, chunk, messageType) => {
    console.log(`Received chunk for ${dialogId}:`, chunk)
  }
})

// Subscribe to a dialog
subscribeToDialog('dialog-456')

// Individual dialog subscription with approval handlers
function ChatDialog({ dialogId }: { dialogId: string }) {
  return (
    <DialogSubscription
      dialogId={dialogId}
      isActive={true}
      onApprove={(requestId) => console.log('Approved:', requestId)}
      onReject={(requestId) => console.log('Rejected:', requestId)}
      approvalStatuses={{}}
    />
  )
}
```

The hook integrates with NATS WebSocket connections, manages streaming message state through Zustand stores, and provides real-time chunk processing for AI chat interactions with support for tool approvals and error handling.
