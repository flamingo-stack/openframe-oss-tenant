React hook that manages realtime NATS subscriptions for Mingo chat dialogs. Provides functionality to subscribe to multiple dialogs simultaneously with message catchup capabilities.

## Key Components

- **`useMingoRealtimeSubscription`** - Main hook for managing subscriptions across multiple dialogs
- **`DialogSubscription`** - Component that handles individual dialog NATS connections  
- **`getApiBaseUrl`** - Utility to resolve tenant host URL from environment or window location
- **`getAccessToken`** - Retrieves authentication token from localStorage
- **Subscription state management** - Tracks connection status and catchup state per dialog

## Usage Example

```typescript
// Main subscription hook usage
const {
  subscribeToDialog,
  unsubscribeFromDialog, 
  getSubscriptionState,
  subscribedDialogs,
  connectionState
} = useMingoRealtimeSubscription(activeDialogId, {
  onChunkReceived: (dialogId, chunk, messageType) => {
    console.log('Received chunk:', chunk)
  }
})

// Subscribe to a dialog
useEffect(() => {
  if (dialogId) {
    subscribeToDialog(dialogId)
  }
  return () => unsubscribeFromDialog(dialogId)
}, [dialogId])

// Individual dialog subscription component
function ChatContainer({ dialogId }: { dialogId: string }) {
  const processChunk = (targetDialogId: string, chunk: ChunkData, messageType: NatsMessageType) => {
    // Handle incoming message chunk
    updateChatMessages(targetDialogId, chunk)
  }

  return (
    <div>
      <DialogSubscription 
        dialogId={dialogId}
        isActive={true}
        processChunk={processChunk}
      />
      {/* Chat UI components */}
    </div>
  )
}
```
