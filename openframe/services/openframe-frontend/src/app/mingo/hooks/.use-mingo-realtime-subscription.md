This React hook provides unified realtime subscription management for Mingo chat dialogs using NATS WebSocket connections. It handles multi-dialog subscriptions with automatic catchup and state management.

## Key Components

### Main Hook
- **`useMingoRealtimeSubscription`** - Primary hook for managing realtime subscriptions across multiple dialogs
- **`DialogSubscription`** - Component for individual dialog subscription management
- **`DialogSubscriptionState`** - Interface defining subscription state (connected, subscribed, caught up)

### Core Functions
- **`subscribeToDialog`** - Adds a dialog to active subscriptions
- **`unsubscribeFromDialog`** - Removes dialog from subscriptions  
- **`getSubscriptionState`** - Returns current state for a specific dialog
- **Helper functions** - `getApiBaseUrl()`, `getAccessToken()` for configuration

### Integration Points
- **NATS WebSocket** - Uses `@flamingo-stack/openframe-frontend-core` for messaging
- **Chunk Catchup** - Integrates with `useMingoChunkCatchup` for message history
- **Store Integration** - Connects to `useMingoMessagesStore` for state management

## Usage Example

```typescript
import { useMingoRealtimeSubscription, DialogSubscription } from './use-mingo-realtime-subscription'

function ChatInterface() {
  const {
    subscribeToDialog,
    unsubscribeFromDialog,
    getSubscriptionState,
    subscribedDialogs,
    connectionState
  } = useMingoRealtimeSubscription(activeDialogId, {
    onChunkReceived: (dialogId, chunk, messageType) => {
      console.log('New message:', { dialogId, chunk, messageType })
    }
  })

  // Subscribe to a dialog
  useEffect(() => {
    subscribeToDialog('dialog-123')
    return () => unsubscribeFromDialog('dialog-123')
  }, [])

  return (
    <div>
      <div>Connection: {connectionState}</div>
      {Array.from(subscribedDialogs).map(dialogId => (
        <DialogSubscription
          key={dialogId}
          dialogId={dialogId}
          isActive={dialogId === activeDialogId}
          processChunk={handleChunkReceived}
        />
      ))}
    </div>
  )
}
```
