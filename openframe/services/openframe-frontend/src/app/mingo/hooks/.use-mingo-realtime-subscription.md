A unified React hook for managing realtime NATS subscriptions to Mingo chat dialogs. This hook handles WebSocket connections, message streaming, chunk processing, and maintains subscription state for multiple dialogs.

## Key Components

**Main Hook:**
- `useMingoRealtimeSubscription()` - Primary hook for managing dialog subscriptions
- `useDialogChunkProcessor()` - Processes streaming chunks for individual dialogs
- `DialogSubscription` - React component for individual dialog subscriptions

**Core Functions:**
- `subscribeToDialog()` - Subscribe to a specific dialog
- `unsubscribeFromDialog()` - Remove subscription from a dialog
- `getSubscriptionState()` - Get current subscription status
- `processChunk()` - Handle incoming message chunks
- `ensureAssistantMessage()` - Create assistant message for streaming

**State Management:**
- `subscribedDialogs` - Set of currently subscribed dialog IDs
- `dialogStates` - Map of dialog subscription states
- `connectionState` - Overall NATS connection status

## Usage Example

```typescript
import { useMingoRealtimeSubscription, DialogSubscription } from './use-mingo-realtime-subscription'

function ChatInterface() {
  const activeDialogId = 'dialog-123'
  
  // Main subscription manager
  const {
    subscribeToDialog,
    unsubscribeFromDialog,
    getSubscriptionState,
    subscribedDialogs,
    connectionState
  } = useMingoRealtimeSubscription(activeDialogId, {
    onChunkReceived: (dialogId, chunk, messageType) => {
      console.log('Received chunk for dialog:', dialogId)
    }
  })

  // Subscribe to a dialog
  const handleSubscribe = () => {
    subscribeToDialog('dialog-456')
  }

  // Individual dialog subscription component
  return (
    <div>
      <DialogSubscription
        dialogId={activeDialogId}
        isActive={true}
        onApprove={(requestId) => console.log('Approved:', requestId)}
        onReject={(requestId) => console.log('Rejected:', requestId)}
        approvalStatuses={{}}
      />
      
      <div>Connection: {connectionState}</div>
      <div>Subscribed dialogs: {subscribedDialogs.size}</div>
    </div>
  )
}
```
