A React hook for managing real-time Mingo chat subscriptions through NATS WebSocket connections. It provides unified subscription management across multiple dialog instances with chunk processing and message state synchronization.

## Key Components

**Main Hook:**
- `useMingoRealtimeSubscription` - Primary hook for managing dialog subscriptions
- `useDialogChunkProcessor` - Per-dialog chunk processing and message state management
- `DialogSubscription` - Individual dialog subscription component

**Core Functions:**
- `subscribeToDialog()` - Subscribe to a specific dialog's real-time updates
- `unsubscribeFromDialog()` - Remove subscription for a dialog
- `getSubscriptionState()` - Get current subscription status for a dialog
- `processChunk()` - Process incoming NATS message chunks

**State Management:**
- Tracks subscription states across multiple dialogs
- Manages connection status and catchup states
- Integrates with Mingo messages store for UI updates

## Usage Example

```typescript
import { useMingoRealtimeSubscription, DialogSubscription } from './use-mingo-realtime-subscription'

// Main subscription manager
function ChatManager() {
  const {
    subscribeToDialog,
    unsubscribeFromDialog,
    getSubscriptionState,
    subscribedDialogs,
    connectionState
  } = useMingoRealtimeSubscription('dialog-123', {
    onChunkReceived: (dialogId, chunk, messageType) => {
      console.log('Chunk received:', { dialogId, chunk, messageType })
    }
  })

  // Subscribe to a dialog
  const handleJoinDialog = (dialogId: string) => {
    subscribeToDialog(dialogId)
  }

  return (
    <div>
      <p>Connection: {connectionState}</p>
      <p>Subscribed dialogs: {subscribedDialogs.size}</p>
      
      {Array.from(subscribedDialogs).map(dialogId => (
        <DialogSubscription
          key={dialogId}
          dialogId={dialogId}
          isActive={true}
          onApprove={(requestId) => console.log('Approved:', requestId)}
          onReject={(requestId) => console.log('Rejected:', requestId)}
        />
      ))}
    </div>
  )
}
```
