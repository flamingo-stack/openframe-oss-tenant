A React hook for managing real-time NATS subscriptions to Mingo chat dialogs, providing WebSocket-based message streaming with automatic catchup and chunk processing capabilities.

## Key Components

- **useMingoRealtimeSubscription** - Main hook for managing multiple dialog subscriptions with connection state tracking
- **useDialogChunkProcessor** - Processes incoming message chunks and handles streaming states
- **DialogSubscription** - Component for individual dialog WebSocket connections
- **getApiBaseUrl/getAccessToken** - Utility functions for authentication and endpoint resolution

## Usage Example

```typescript
import { useMingoRealtimeSubscription } from './use-mingo-realtime-subscription'

function ChatComponent() {
  const activeDialogId = "dialog-123"
  
  const {
    subscribeToDialog,
    unsubscribeFromDialog,
    getSubscriptionState,
    subscribedDialogs,
    connectionState
  } = useMingoRealtimeSubscription(activeDialogId, {
    onChunkReceived: (dialogId, chunk, messageType) => {
      console.log('Received chunk for dialog:', dialogId)
    }
  })

  // Subscribe to a dialog
  const handleSubscribe = () => {
    subscribeToDialog("dialog-456")
  }

  // Check subscription state
  const state = getSubscriptionState("dialog-123")
  
  return (
    <div>
      <p>Connection: {connectionState}</p>
      <p>Subscribed dialogs: {subscribedDialogs.size}</p>
      <DialogSubscription 
        dialogId={activeDialogId}
        isActive={true}
        onApprove={(requestId) => console.log('Approved:', requestId)}
        onReject={(requestId) => console.log('Rejected:', requestId)}
      />
    </div>
  )
}
```

The hook integrates with the Mingo messages store and provides automatic message chunking, error handling, and typing indicators for real-time chat functionality.
