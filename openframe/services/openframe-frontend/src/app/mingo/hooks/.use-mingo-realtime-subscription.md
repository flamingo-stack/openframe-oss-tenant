A React hook for managing real-time Mingo chat subscriptions with NATS WebSocket connections. Provides unified subscription management for multiple chat dialogs with catchup, typing indicators, and message streaming.

## Key Components

**Main Hook**
- `useMingoRealtimeSubscription` - Core subscription manager for multiple dialogs
- `DialogSubscription` - Individual dialog subscription component
- `useDialogChunkProcessor` - Per-dialog message processing hook

**Core Functionality**
- Multi-dialog subscription state management
- NATS WebSocket connection handling
- Real-time message chunk processing
- Catchup mechanism for missed messages
- Typing indicator and streaming state management

**State Management**
- Connection state tracking (`connected`/`disconnected`/`connecting`)
- Per-dialog subscription states
- Access token and authentication handling
- Integration with Mingo messages store

  const handleApprove = (requestId?: string) => {
    // Handle approval action
  }

      />
    </div>
  )
}
