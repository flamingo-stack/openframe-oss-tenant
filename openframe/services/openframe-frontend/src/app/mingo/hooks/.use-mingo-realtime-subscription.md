A React hook for managing realtime NATS subscriptions to Mingo chat dialogs, providing unified multi-dialog support with chunk processing and catchup capabilities.

## Key Components

### Core Hook
- `useMingoRealtimeSubscription` - Main hook for managing multiple dialog subscriptions
- `useDialogChunkProcessor` - Processes incoming message chunks for a specific dialog
- `DialogSubscription` - Component for individual dialog NATS subscriptions

### Types
- `UseMingoRealtimeSubscriptionOptions` - Configuration options for the main hook
- `DialogSubscriptionState` - Tracks subscription, connection, and catchup status
- `UseMingoRealtimeSubscription` - Return type with subscription management functions
- `DialogSubscriptionProps` - Props for the DialogSubscription component

### State Management
- Dialog subscription tracking with `Set<string>`
- Connection state monitoring ('connected' | 'disconnected' | 'connecting')
- Integration with Mingo messages store for message handling
- Automatic unread message reset for active dialogs

## Usage Example

```typescript
import { useMingoRealtimeSubscription, DialogSubscription } from './use-mingo-realtime-subscription'

function ChatInterface({ activeDialogId }: { activeDialogId: string }) {
  const {
    subscribeToDialog,
    unsubscribeFromDialog,
    getSubscriptionState,
    subscribedDialogs,
    connectionState
  } = useMingoRealtimeSubscription(activeDialogId, {
    onChunkReceived: (dialogId, chunk, messageType) => {
      console.log('Received chunk for dialog:', dialogId)
    }
  })

  const handleSubscribe = (dialogId: string) => {
    subscribeToDialog(dialogId)
  }

  return (
    <div>
      <div>Connection: {connectionState}</div>
      {Array.from(subscribedDialogs).map(dialogId => (
        <DialogSubscription
          key={dialogId}
          dialogId={dialogId}
          isActive={dialogId === activeDialogId}
          onApprove={(requestId) => console.log('Approved:', requestId)}
          onReject={(requestId) => console.log('Rejected:', requestId)}
        />
      ))}
    </div>
  )
}
```

The hook automatically manages NATS WebSocket connections, handles token-based authentication for development environments, and provides seamless integration with the Mingo messages store for realtime chat functionality.
