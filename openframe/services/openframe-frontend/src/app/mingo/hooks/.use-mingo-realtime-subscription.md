A React hook for managing real-time Mingo chat subscriptions using NATS messaging protocol. It provides unified subscription management for multiple dialogs with chunk processing, catch-up mechanisms, and typing indicators.

## Key Components

- **useMingoRealtimeSubscription** - Main hook for managing multiple dialog subscriptions
- **useDialogChunkProcessor** - Processes incoming message chunks and updates store state
- **DialogSubscription** - Component for individual dialog subscription management
- **MINGO_TOPICS** - Supported NATS message types (`admin-message`)

## Usage Example

```typescript
import { useMingoRealtimeSubscription } from './use-mingo-realtime-subscription'

function ChatComponent() {
  const subscription = useMingoRealtimeSubscription('dialog-123', {
    onChunkReceived: (dialogId, chunk, messageType) => {
      console.log('Received chunk for', dialogId)
    }
  })

  const handleSubscribe = () => {
    subscription.subscribeToDialog('dialog-456')
  }

  const dialogState = subscription.getSubscriptionState('dialog-123')

  return (
    <div>
      <p>Connection: {subscription.connectionState}</p>
      <p>Subscribed dialogs: {subscription.subscribedDialogs.size}</p>
      <p>Is connected: {dialogState.isConnected}</p>
      <button onClick={handleSubscribe}>Subscribe to Dialog</button>
    </div>
  )
}
```

The hook handles authentication tokens, WebSocket connections, message chunking, and provides real-time updates to the Mingo messages store with automatic catch-up for missed messages.
