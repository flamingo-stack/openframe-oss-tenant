A React hook for managing real-time NATS subscriptions for Mingo chat dialogs, providing WebSocket connections, chunk processing, and state synchronization across multiple concurrent conversations.

## Key Components

- **`useMingoRealtimeSubscription`** - Main hook for managing multiple dialog subscriptions with connection state tracking
- **`useDialogChunkProcessor`** - Processes incoming message chunks and manages streaming state for individual dialogs
- **`DialogSubscription`** - Component wrapper for individual dialog subscriptions with catch-up functionality
- **Connection management utilities** - Functions for API base URL resolution and access token retrieval
- **State interfaces** - TypeScript definitions for subscription states and configuration options

## Usage Example

```typescript
import { useMingoRealtimeSubscription, DialogSubscription } from './use-mingo-realtime-subscription'

function ChatInterface() {
  const [activeDialogId, setActiveDialogId] = useState<string | null>(null)
  
  // Main subscription management
  const {
    subscribeToDialog,
    unsubscribeFromDialog,
    getSubscriptionState,
    subscribedDialogs,
    connectionState
  } = useMingoRealtimeSubscription(activeDialogId, {
    onChunkReceived: (dialogId, chunk, messageType) => {
      console.log(`Received chunk for ${dialogId}:`, chunk)
    }
  })

  // Subscribe to a new dialog
  const handleNewDialog = (dialogId: string) => {
    subscribeToDialog(dialogId)
    setActiveDialogId(dialogId)
  }

  return (
    <div>
      <div>Connection: {connectionState}</div>
      {Array.from(subscribedDialogs).map(dialogId => (
        <DialogSubscription
          key={dialogId}
          dialogId={dialogId}
          isActive={dialogId === activeDialogId}
          onApprove={(requestId) => console.log('Approved:', requestId)}
          onReject={(requestId) => console.log('Rejected:', requestId)}
          approvalStatuses={{}}
        />
      ))}
    </div>
  )
}
```

The hook integrates with the Mingo messages store and provides automatic catch-up functionality for missed messages when reconnecting to dialogs.
