Unified realtime subscription hook that manages NATS WebSocket connections for Mingo AI chat functionality. Handles multiple dialog subscriptions with chunk processing, message streaming, and state synchronization.

## Key Components

- **useMingoRealtimeSubscription** - Main hook managing dialog subscriptions and connection state
- **useDialogChunkProcessor** - Processes incoming message chunks and updates chat state
- **DialogSubscription** - Component for individual dialog NATS subscriptions
- **Helper functions** - Token management and API URL configuration utilities

## Usage Example

```typescript
import { useMingoRealtimeSubscription, DialogSubscription } from './use-mingo-realtime-subscription'

// Basic subscription management
const {
  subscribeToDialog,
  unsubscribeFromDialog,
  getSubscriptionState,
  subscribedDialogs,
  connectionState
} = useMingoRealtimeSubscription('dialog-123', {
  onChunkReceived: (dialogId, chunk, messageType) => {
    console.log('Received chunk for dialog:', dialogId)
  }
})

// Subscribe to a dialog
subscribeToDialog('dialog-456')

// Individual dialog subscription component
<DialogSubscription
  dialogId="dialog-123"
  isActive={true}
  onApprove={(requestId) => handleApproval(requestId)}
  onReject={(requestId) => handleRejection(requestId)}
  approvalStatuses={approvalStatuses}
/>
```

The hook automatically manages NATS connections, handles message streaming with typing indicators, processes tool approvals, and maintains subscription state across multiple chat dialogs. It integrates with the Mingo messages store for centralized state management.
