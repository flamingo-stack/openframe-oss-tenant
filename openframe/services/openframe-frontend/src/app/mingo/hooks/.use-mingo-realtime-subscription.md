A React hook and component for managing real-time NATS subscriptions to Mingo chat dialogs, providing unified subscription management with automatic catchup for missed messages.

## Key Components

- **`useMingoRealtimeSubscription`** - Main hook for managing multiple dialog subscriptions with connection state tracking
- **`DialogSubscription`** - Component that handles individual dialog NATS subscriptions with chunk catchup
- **`DialogSubscriptionState`** - Interface tracking subscription, connection, and catchup status
- **Utility functions** - `getApiBaseUrl()`, `getAccessToken()` for runtime configuration

## Usage Example

```typescript
import { useMingoRealtimeSubscription, DialogSubscription } from './use-mingo-realtime-subscription'

function ChatInterface() {
  const {
    subscribeToDialog,
    unsubscribeFromDialog,
    subscribedDialogs,
    connectionState
  } = useMingoRealtimeSubscription(activeDialogId, {
    onChunkReceived: (dialogId, chunk, messageType) => {
      console.log('Received chunk for dialog:', dialogId, chunk)
    }
  })

  return (
    <div>
      <div>Connection: {connectionState}</div>
      
      {/* Render subscription components for each dialog */}
      {Array.from(subscribedDialogs).map(dialogId => (
        <DialogSubscription
          key={dialogId}
          dialogId={dialogId}
          isActive={dialogId === activeDialogId}
          processChunk={(targetDialogId, chunk, messageType) => {
            // Handle incoming chunks
            updateMessages(targetDialogId, chunk)
          }}
        />
      ))}
    </div>
  )
}
```

The hook automatically subscribes to the active dialog and provides methods to manage subscriptions for multiple dialogs simultaneously. Each `DialogSubscription` component handles the NATS connection and message catchup for its specific dialog.
