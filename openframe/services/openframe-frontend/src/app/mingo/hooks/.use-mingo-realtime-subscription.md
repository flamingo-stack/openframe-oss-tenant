A React hook that manages realtime NATS subscriptions for Mingo AI chat dialogs, providing live message streaming, chunk processing, and multi-dialog subscription management with automatic catch-up capabilities.

## Key Components

- `useMingoRealtimeSubscription` - Main hook for managing multiple dialog subscriptions
- `DialogSubscription` - Component for individual dialog realtime connections  
- `useDialogChunkProcessor` - Processes streaming message chunks and handles approvals
- Helper functions for API configuration (`getApiBaseUrl`, `getAccessToken`)
- Constants: `MINGO_TOPICS` for supported NATS message types

## Usage Example

```typescript
import { useMingoRealtimeSubscription, DialogSubscription } from './use-mingo-realtime-subscription'

function ChatComponent() {
  const {
    subscribeToDialog,
    unsubscribeFromDialog,
    getSubscriptionState,
    subscribedDialogs,
    connectionState
  } = useMingoRealtimeSubscription('dialog-123', {
    onChunkReceived: (dialogId, chunk, messageType) => {
      console.log('Received chunk for dialog:', dialogId)
    }
  })

  const handleApprove = async (requestId?: string) => {
    // Handle approval logic
    console.log('Approved request:', requestId)
  }

  return (
    <div>
      <p>Connection: {connectionState}</p>
      {Array.from(subscribedDialogs).map(dialogId => (
        <DialogSubscription
          key={dialogId}
          dialogId={dialogId}
          isActive={true}
          onApprove={handleApprove}
          approvalStatuses={{}}
        />
      ))}
    </div>
  )
}
```

The hook integrates with the Mingo messages store and provides automatic subscription management, error handling, and streaming message processing for realtime AI chat functionality.
