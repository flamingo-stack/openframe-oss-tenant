A React hook that manages realtime NATS subscriptions for Mingo chat dialogs, providing unified subscription management for multiple dialogs with automatic catchup handling.

## Key Components

**`useMingoRealtimeSubscription`** - Main hook that manages subscription state for multiple dialogs
- `subscribeToDialog(dialogId)` - Subscribes to a specific dialog
- `unsubscribeFromDialog(dialogId)` - Removes subscription from a dialog
- `getSubscriptionState(dialogId)` - Returns connection/subscription status
- `subscribedDialogs` - Set of currently subscribed dialog IDs
- `connectionState` - Overall NATS connection status

**`DialogSubscription`** - Component that handles individual dialog subscriptions with NATS WebSocket connections

**Helper Functions**
- `getApiBaseUrl()` - Resolves API base URL from environment or window location
- `getAccessToken()` - Retrieves access token from localStorage for authenticated connections

## Usage Example

```typescript
import { useMingoRealtimeSubscription, DialogSubscription } from './use-mingo-realtime-subscription'

function MingoChat() {
  const {
    subscribeToDialog,
    unsubscribeFromDialog,
    subscribedDialogs,
    connectionState
  } = useMingoRealtimeSubscription('dialog-123', {
    onChunkReceived: (dialogId, chunk, messageType) => {
      console.log(`Received chunk for ${dialogId}:`, chunk)
    }
  })

  const handleJoinDialog = (dialogId: string) => {
    subscribeToDialog(dialogId)
  }

  return (
    <div>
      <div>Status: {connectionState}</div>
      {Array.from(subscribedDialogs).map(dialogId => (
        <DialogSubscription
          key={dialogId}
          dialogId={dialogId}
          isActive={dialogId === 'dialog-123'}
          processChunk={(targetDialogId, chunk, messageType) => {
            // Handle incoming chunks
          }}
        />
      ))}
    </div>
  )
}
```

The hook automatically subscribes to the active dialog and handles token-based authentication for development environments.
