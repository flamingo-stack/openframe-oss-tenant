A React hook and component for managing real-time NATS subscriptions to Mingo AI chat dialogs with automatic message catchup and multi-dialog support.

## Key Components

- **`useMingoRealtimeSubscription`** - Main hook for managing multiple dialog subscriptions with connection state tracking
- **`DialogSubscription`** - Component that handles individual dialog NATS connections and message processing
- **`getApiBaseUrl`** - Utility to determine the API base URL from environment or window location
- **`getAccessToken`** - Utility to retrieve authentication token from localStorage

## Usage Example

```typescript
import { useMingoRealtimeSubscription, DialogSubscription } from './use-mingo-realtime-subscription'

function MingoChat() {
  const [activeDialogId, setActiveDialogId] = useState<string | null>(null)
  
  const {
    subscribeToDialog,
    unsubscribeFromDialog,
    subscribedDialogs,
    connectionState
  } = useMingoRealtimeSubscription(activeDialogId, {
    onChunkReceived: (dialogId, chunk, messageType) => {
      console.log('Received chunk for dialog:', dialogId, chunk)
    }
  })
  
  const handleJoinDialog = (dialogId: string) => {
    subscribeToDialog(dialogId)
    setActiveDialogId(dialogId)
  }
  
  return (
    <div>
      <div>Connection: {connectionState}</div>
      
      {/* Render subscription components for each subscribed dialog */}
      {Array.from(subscribedDialogs).map(dialogId => (
        <DialogSubscription
          key={dialogId}
          dialogId={dialogId}
          isActive={dialogId === activeDialogId}
          processChunk={(targetDialogId, chunk, messageType) => {
            // Handle incoming message chunks
            console.log('Processing chunk:', chunk)
          }}
        />
      ))}
    </div>
  )
}
```

The hook provides subscription management for multiple dialogs simultaneously, handling NATS WebSocket connections, message catchup on subscription, and automatic cleanup. Each `DialogSubscription` component manages its own connection lifecycle and integrates with the chunk catchup system for reliable message delivery.
