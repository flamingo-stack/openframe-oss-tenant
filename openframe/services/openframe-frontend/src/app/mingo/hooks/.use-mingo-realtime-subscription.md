A unified realtime subscription hook for managing NATS WebSocket connections to Mingo AI chat dialogs, handling multi-topic subscriptions with automatic catchup and state management.

## Key Components

- **`useMingoRealtimeSubscription`** - Main hook for managing multiple dialog subscriptions with connection state tracking
- **`DialogSubscription`** - React component for individual dialog NATS subscriptions with automatic catchup
- **`UseMingoRealtimeSubscription`** - Return type interface providing subscription management methods
- **Helper functions** - `getApiBaseUrl()` and `getAccessToken()` for configuration retrieval

## Usage Example

```typescript
    <div>

      ))}
    </div>
  )
}
```

The hook manages NATS subscriptions for admin messages, handles token-based authentication in development mode, and provides automatic dialog subscription when an active dialog is set. Each dialog gets its own subscription component for isolated state management and catchup handling.
