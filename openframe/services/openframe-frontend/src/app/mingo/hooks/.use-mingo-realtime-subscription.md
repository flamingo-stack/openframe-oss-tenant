A React hook that manages real-time NATS subscriptions for Mingo chat dialogs, providing unified subscription management across multiple dialogs with chunk processing and message synchronization.

## Key Components

### Main Hook
- **`useMingoRealtimeSubscription`** - Primary hook for managing dialog subscriptions with connection state tracking
- **`useDialogChunkProcessor`** - Processes incoming message chunks and manages streaming message states
- **`DialogSubscription`** - Component wrapper for individual dialog subscriptions

### Core Functions
- **`subscribeToDialog`** / **`unsubscribeFromDialog`** - Manage dialog subscription lifecycle
- **`getSubscriptionState`** - Returns subscription status for a dialog
- **`ensureAssistantMessage`** / **`addErrorMessage`** - Message state management utilities

### State Management
- **`subscribedDialogs`** - Set of currently subscribed dialog IDs
- **`dialogStates`** - Map of dialog subscription states (connected, caught up, etc.)
- **`connectionState`** - Overall NATS connection status

## Usage Example

```typescript
import { useMingoRealtimeSubscription } from './use-mingo-realtime-subscription'

function MingoChat() {
  const {
    subscribeToDialog,
    unsubscribeFromDialog,
    getSubscriptionState,
    connectionState
  } = useMingoRealtimeSubscription('dialog-123', {
    onChunkReceived: (dialogId, chunk, messageType) => {
      console.log('Received chunk for dialog:', dialogId)
    }
  })

  // Subscribe to a new dialog
  const handleJoinDialog = (dialogId: string) => {
    subscribeToDialog(dialogId)
  }

  // Check subscription status
  const dialogState = getSubscriptionState('dialog-123')
  
  return (
    <div>
      <p>Connection: {connectionState}</p>
      <p>Dialog connected: {dialogState.isConnected}</p>
    </div>
  )
}
```

The hook integrates with the Flamingo Stack's OpenFrame core for NATS messaging, Zustand stores for message persistence, and TanStack Query for cache invalidation.
