A React hook for managing realtime NATS subscriptions to Mingo chat dialogs, handling message streaming, chunk processing, and connection state management across multiple conversations.

## Key Components

**Main Hook:**
- `useMingoRealtimeSubscription` - Core hook managing multi-dialog NATS subscriptions
- `DialogSubscription` - Individual dialog subscription component with chunk processing

**Helper Functions:**
- `useDialogChunkProcessor` - Processes incoming message chunks and manages streaming state
- `getApiBaseUrl()` - Extracts API base URL from environment or window location
- `getAccessToken()` - Retrieves authentication token from localStorage

**Types:**
- `DialogSubscriptionState` - Tracks subscription, connection, and catchup status
- `UseMingoRealtimeSubscriptionOptions` - Configuration options for chunk callbacks

## Usage Example

```typescript
}
```

The hook integrates with the Mingo messages store for state management and uses NATS WebSocket connections for realtime message streaming with automatic reconnection and catchup functionality.
