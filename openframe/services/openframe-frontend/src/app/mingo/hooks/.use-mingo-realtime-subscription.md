A React hook and component for managing real-time NATS subscriptions to Mingo chat dialogs. Provides unified subscription management with automatic message catching up and chunk processing.

## Key Components

- **`useMingoRealtimeSubscription`** - Main hook for managing multiple dialog subscriptions with connection state tracking
- **`DialogSubscription`** - React component that handles individual dialog NATS subscriptions
- **`getApiBaseUrl()`** - Utility function to determine the API base URL from environment or window
- **`getAccessToken()`** - Utility function to retrieve access token from localStorage
- **MINGO_TOPICS** - Constant defining supported NATS message types (`['admin-message']`)

## Usage Example

```typescript
import { useMingoRealtimeSubscription, DialogSubscription } from './use-mingo-realtime-subscription'

function MingoChat() {
  const activeDialogId = 'dialog-123'
  
  const {
    subscribeToDialog,
    unsubscribeFromDialog,
    getSubscriptionState,
    subscribedDialogs,
    connectionState
  } = useMingoRealtimeSubscription(activeDialogId, {
    onChunkReceived: (dialogId, chunk, messageType) => {
      console.log('Received chunk:', { dialogId, chunk, messageType })
    }
  })

  const handleProcessChunk = (dialogId: string, chunk: ChunkData, messageType: NatsMessageType) => {
    // Process incoming message chunks
    updateMessages(dialogId, chunk)
  }

  return (
    <div>
      <div>Connection: {connectionState}</div>
      {Array.from(subscribedDialogs).map(dialogId => (
        <DialogSubscription
          key={dialogId}
          dialogId={dialogId}
          isActive={dialogId === activeDialogId}
          processChunk={handleProcessChunk}
        />
      ))}
    </div>
  )
}
```

The hook automatically manages subscription lifecycle, handles reconnections, and integrates with the Mingo message store for unread message tracking.
