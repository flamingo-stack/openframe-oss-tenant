Hook for managing realtime chat subscriptions in Mingo AI assistant. Provides dialog subscription management, connection state tracking, and message chunk handling for NATS-based communication.

## Key Components

- **`useMingoRealtimeSubscription`** - Main hook for managing multiple dialog subscriptions with connection state
- **`DialogSubscription`** - React component that handles individual dialog NATS subscriptions
- **`DialogSubscriptionState`** - Interface tracking subscription, connection, and catchup status
- **`MINGO_TOPICS`** - Defines supported NATS message types (`admin-message`)
