A React hook and component for managing realtime NATS subscriptions to Mingo chat dialogs with automatic message catchup and multi-topic support.

## Key Components

- **useMingoRealtimeSubscription** - Main hook that manages subscription state across multiple dialogs
- **DialogSubscription** - React component that handles individual dialog NATS connections
- **DialogSubscriptionState** - Interface defining subscription status (subscribed, connected, caught up)
- **MINGO_TOPICS** - Configured NATS message types for admin messages

## Usage Example

```typescript
import { useMingoRealtimeSubscription, DialogSubscription } from './use-mingo-realtime-subscription'

function MingoChat() {
  const activeDialogId = "dialog-123"
  
  // Main subscription management
  const {
    subscribeToDialog,
    unsubscribeFromDialog,
    subscribedDialogs,
    connectionState
  } = useMingoRealtimeSubscription(activeDialogId, {
    onChunkReceived: (dialogId, chunk, messageType) => {
      console.log(`Received chunk for ${dialogId}:`, chunk)
    }
  })

  const handleProcessChunk = (dialogId: string, chunk: ChunkData, messageType: NatsMessageType) => {
    // Handle incoming message chunks
    updateChatMessages(dialogId, chunk)
  }

  return (
    <>
      {/* Render subscription components for each dialog */}
      {Array.from(subscribedDialogs).map(dialogId => (
        <DialogSubscription
          key={dialogId}
          dialogId={dialogId}
          isActive={dialogId === activeDialogId}
          processChunk={handleProcessChunk}
        />
      ))}
      <div>Connection: {connectionState}</div>
    </>
  )
}
```

The hook automatically subscribes to the active dialog and provides methods to manage subscriptions for multiple dialogs simultaneously. Each dialog gets its own NATS connection through the DialogSubscription component, which handles message catchup and real-time streaming.
