A React hook for managing real-time NATS subscriptions to Mingo chat dialogs with multi-topic support and chunk processing capabilities.

## Key Components

- **`useMingoRealtimeSubscription`** - Main hook managing multiple dialog subscriptions with connection state tracking
- **`useDialogChunkProcessor`** - Processes incoming message chunks and manages streaming state
- **`DialogSubscription`** - Component handling individual dialog subscription lifecycle
- **`getApiBaseUrl`**, **`getAccessToken`** - Utility functions for environment configuration
- **Helper interfaces** - `DialogSubscriptionState`, `UseMingoRealtimeSubscriptionOptions` for type safety

## Usage Example

```typescript
import { useMingoRealtimeSubscription, DialogSubscription } from './use-mingo-realtime-subscription'

function ChatComponent() {
  const {
    subscribeToDialog,
    unsubscribeFromDialog,
    getSubscriptionState,
    subscribedDialogs,
    connectionState
  } = useMingoRealtimeSubscription(activeDialogId, {
    onChunkReceived: (dialogId, chunk, messageType) => {
      console.log('Received chunk for dialog:', dialogId)
    }
  })

  const handleSubscribe = () => {
    subscribeToDialog('dialog-123')
  }

  return (
    <div>
      <button onClick={handleSubscribe}>Subscribe to Dialog</button>
      {Array.from(subscribedDialogs).map(dialogId => (
        <DialogSubscription
          key={dialogId}
          dialogId={dialogId}
          isActive={dialogId === activeDialogId}
          onApprove={(requestId) => handleApproval(requestId)}
          onReject={(requestId) => handleRejection(requestId)}
        />
      ))}
    </div>
  )
}
```

The hook integrates with the Mingo messages store and provides real-time streaming capabilities for chat applications with approval workflows and error handling.
