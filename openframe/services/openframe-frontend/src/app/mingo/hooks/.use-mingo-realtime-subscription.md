A React hook for managing realtime NATS subscriptions for Mingo chat dialogs with multi-topic support, chunk processing, and automatic catch-up functionality.

## Key Components

- **useMingoRealtimeSubscription** - Main hook for managing multiple dialog subscriptions with state tracking
- **DialogSubscription** - Component for handling individual dialog subscriptions with NATS WebSocket connections
- **DialogSubscriptionState** - Interface defining subscription state (subscribed, connected, caught up)
- **UseMingoRealtimeSubscriptionOptions** - Configuration options for chunk processing callbacks

## Usage Example

```typescript
import { useMingoRealtimeSubscription, DialogSubscription } from './use-mingo-realtime-subscription'

function MingoChat() {
  const {
    subscribeToDialog,
    unsubscribeFromDialog,
    subscribedDialogs,
    connectionState
  } = useMingoRealtimeSubscription(activeDialogId, {
    onChunkReceived: (dialogId, chunk, messageType) => {
      console.log('New chunk received:', { dialogId, chunk, messageType })
    }
  })

  const handleJoinDialog = (dialogId: string) => {
    subscribeToDialog(dialogId)
  }

  return (
    <div>
      {Array.from(subscribedDialogs).map(dialogId => (
        <DialogSubscription
          key={dialogId}
          dialogId={dialogId}
          isActive={dialogId === activeDialogId}
          processChunk={handleProcessChunk}
        />
      ))}
    </div>
  )
}
```

The hook automatically manages NATS WebSocket connections, handles authentication tokens, performs message catch-up on subscription, and maintains dialog state across reconnections. It integrates with the Mingo messages store for unread message management.
