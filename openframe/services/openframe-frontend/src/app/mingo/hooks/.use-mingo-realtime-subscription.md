A React hook that provides unified realtime subscription management for Mingo chat dialogs using NATS WebSocket connections. It handles multiple dialog subscriptions with chunk catchup and connection state tracking.

## Key Components

**Main Hook:**
- `useMingoRealtimeSubscription` - Core hook for managing multiple dialog subscriptions
- Returns subscription controls, state getters, and connection status

**Component:**
- `DialogSubscription` - Individual dialog subscription component for rendering active subscriptions

**Key Functions:**
- `subscribeToDialog` - Subscribe to a specific dialog's realtime updates
- `unsubscribeFromDialog` - Remove subscription from a dialog
- `getSubscriptionState` - Get current state of a dialog subscription

**Interfaces:**
- `UseMingoRealtimeSubscriptionOptions` - Hook configuration options
- `DialogSubscriptionState` - State tracking for individual dialogs
- `DialogSubscriptionProps` - Props for subscription component

## Usage Example

```typescript
import { useMingoRealtimeSubscription, DialogSubscription } from './use-mingo-realtime-subscription'

function ChatContainer({ activeDialogId }: { activeDialogId: string | null }) {
  const {
    subscribeToDialog,
    unsubscribeFromDialog,
    getSubscriptionState,
    subscribedDialogs,
    connectionState
  } = useMingoRealtimeSubscription(activeDialogId, {
    onChunkReceived: (dialogId, chunk, messageType) => {
      console.log('Received chunk for dialog:', dialogId)
    }
  })

  const handleProcessChunk = (dialogId: string, chunk: ChunkData, messageType: NatsMessageType) => {
    // Process incoming message chunks
    console.log('Processing chunk:', chunk)
  }

  return (
    <div>
      <div>Connection: {connectionState}</div>
      
      {/* Render subscription components for each subscribed dialog */}
      {Array.from(subscribedDialogs).map(dialogId => (
        <DialogSubscription
          key={dialogId}
          dialogId={dialogId}
          isActive={dialogId === activeDialogId}
          processChunk={handleProcessChunk}
        />
      ))}
    </div>
  )
}
```
