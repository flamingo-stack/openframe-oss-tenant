A Next.js client component that implements the main Mingo AI chat interface, providing a complete chat experience with real-time messaging, dialog management, and multi-tenant support.

## Key Components

- **Mingo**: Main component rendering the chat interface with sidebar and message area
- **State Management**: Integrates multiple custom hooks for dialog, chat, and real-time functionality
- **Real-time Subscriptions**: Manages NATS message subscriptions with multi-topic support
- **URL Synchronization**: Syncs active dialog state with URL search parameters
- **SaaS Mode Guard**: Restricts access to SaaS tenant environments only

## Usage Example

```typescript
// Used as a page component in Next.js app router
export default function MingoPage() {
  return <Mingo />
}

// The component handles:
// - URL routing: /mingo?dialogId=123
// - Real-time messaging via NATS subscriptions
// - Dialog creation and selection
// - Message sending and approval workflows
// - Keyboard shortcuts (ESC to close dialog)
```

The component provides a complete chat interface with:
- **Sidebar**: Dialog list with infinite scroll and unread counts
- **Chat Area**: Message display with typing indicators and approval controls
- **Input**: Message composition with send functionality
- **Welcome Screen**: Displayed when no dialog is selected
- **Real-time Updates**: Background message processing with unread notifications
