Main page component for the Mingo AI chat interface, handling real-time conversations with background message processing and NATS subscription management.

## Key Components

- **Real-time Chat Interface**: Complete chat experience with sidebar, message list, and input
- **Multi-dialog Management**: Support for multiple concurrent chat dialogs with background updates
- **NATS Subscriptions**: Per-dialog real-time message subscriptions that persist when switching dialogs
- **URL State Management**: Dialog selection synchronized with browser URL parameters
- **Optimistic Updates**: Immediate UI feedback with optimistic message rendering
- **Welcome Messages**: Automatic welcome message injection for new empty dialogs
