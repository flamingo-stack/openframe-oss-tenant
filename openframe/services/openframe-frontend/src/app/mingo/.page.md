This is the main Mingo AI chat interface component that provides a complete conversational AI experience with real-time messaging, dialog management, and multi-topic subscription handling.

## Key Components

- **Dialog Management**: Handles chat session creation, selection, and navigation with URL state synchronization
- **Real-time Messaging**: NATS-based subscription system for live message streaming across multiple dialogs
- **Message Processing**: Chunk-based message handling with approval workflows and typing indicators
- **Chat Interface**: Split-pane layout with sidebar for dialog list and main area for conversation
- **State Management**: Zustand store integration for message state, unread counts, and active dialog tracking
- **Keyboard Navigation**: ESC key support to clear active dialog selection

## Usage Example

```typescript
// This component is used as a Next.js page component
// URL structure: /mingo?dialogId=123

// Key URL states:
// /mingo - Welcome screen, no active dialog
// /mingo?dialogId=abc123 - Active conversation with dialog abc123

// Keyboard shortcuts:
// ESC - Clear active dialog and return to welcome screen

// Real-time features:
// - Live message streaming via NATS
// - Typing indicators
// - Unread message counts for background dialogs
// - Multi-topic subscription (message + admin-message)
```

The component enforces SaaS tenant mode and redirects to dashboard if not in the correct environment. It uses force-dynamic rendering to ensure real-time functionality works properly in production deployments.
