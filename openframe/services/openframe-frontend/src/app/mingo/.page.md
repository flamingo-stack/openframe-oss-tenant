This is the main page component for Mingo AI, Flamingo's AI assistant interface that provides a chat-based technical support system with real-time messaging and dialog management.

## Key Components

- **Main Chat Interface**: Full-screen chat layout with sidebar for dialog list and main area for messages
- **Dialog Management**: Handles creation, selection, and navigation between chat conversations
- **Real-time Messaging**: NATS-based subscription system for live message updates
- **URL State Management**: Syncs active dialog with URL parameters for bookmarking/sharing
- **Message Processing**: Handles message sending, chunked responses, and approval workflows
- **SaaS Mode Enforcement**: Redirects to dashboard if not in SaaS tenant mode

## Usage Example

```typescript
// The component is automatically rendered at the /mingo route
// URL structure: /mingo?dialogId=abc123

// Key user interactions:
// - Create new dialog via "New Chat" button
// - Select existing dialog from sidebar
// - Send messages via chat input
// - Approve/reject AI actions
// - Navigate with Escape key to clear dialog selection
```

## Architecture Features

- **Real-time Subscriptions**: Multi-topic NATS messaging with automatic connection sharing
- **Unread Message Tracking**: Background dialog monitoring with unread counters
- **Keyboard Navigation**: Escape key support for quick dialog deselection
- **Responsive Design**: Mobile-friendly layout with collapsible sidebar
- **State Persistence**: URL-based state management for dialog selection
- **Loading States**: Comprehensive loading indicators for all async operations

The component integrates multiple custom hooks for dialog management, chat functionality, and real-time messaging, providing a seamless AI assistant experience within the OpenFrame platform.
