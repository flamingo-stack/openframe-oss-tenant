A Next.js page component that implements the Mingo AI chat interface, providing a complete chat experience with dialog management, real-time messaging, and AI assistant interactions within the Flamingo platform.

## Key Components

- **Mingo** - Main page component with chat interface and sidebar
- **Dialog Management** - Create, select, and navigate between chat conversations
- **Real-time Messaging** - NATS-based live message streaming with background updates
- **Message Processing** - Handle chunked responses, approvals, and typing indicators
- **State Management** - Zustand store for messages, dialogs, and UI state
- **URL Synchronization** - Dialog selection persisted in search parameters

## Usage Example

```typescript
// This page is automatically mounted at /mingo route
// URL navigation examples:

// Base chat interface
// GET /mingo

// Open specific dialog
// GET /mingo?dialogId=dialog-123

// Key interactions handled:
const handleNewChat = async () => {
  const dialogId = await createDialog()
  // Automatically navigates to new dialog
}

const handleSendMessage = async (message: string) => {
  await sendMessage(message)
  // Real-time response processing via NATS
}

// Keyboard shortcuts
// ESC key - Close active dialog and return to welcome screen
```

The component integrates multiple custom hooks for chat functionality, provides SaaS tenant mode validation, and includes comprehensive real-time subscription management for seamless multi-dialog communication.
