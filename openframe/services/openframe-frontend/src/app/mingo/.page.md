This Next.js client component implements the main Mingo AI chat interface, providing a comprehensive chat application with dialog management, real-time messaging, and URL-based navigation. It serves as the primary page for the Mingo AI assistant within the OpenFrame platform.

## Key Components

- **State Management**: Uses multiple custom hooks for dialog management, chat functionality, and real-time subscriptions
- **URL Synchronization**: Maintains active dialog state in URL search parameters for shareable chat sessions
- **Draft Chat Mode**: Supports temporary chat sessions before dialog creation
- **Real-time Updates**: Implements NATS subscriptions for live message updates across dialogs
- **Message Processing**: Handles message approvals, rejections, and typing indicators
- **Responsive Layout**: Uses `ChatSidebar` for dialog list and main chat area with message list and input
