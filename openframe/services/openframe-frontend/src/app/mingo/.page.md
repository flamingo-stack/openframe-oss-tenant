This is the main Mingo AI chat interface component for the Flamingo OpenFrame platform, providing a full-featured chat experience with dialog management, real-time subscriptions, and message handling.

## Key Components

### State Management
- `useMingoMessagesStore` - Central store for active dialog and message state
- `useMingoDialogs` - Manages dialog list with pagination
- `useMingoDialogSelection` - Handles dialog selection and message approval
- `useMingoChat` - Manages message sending and processing
- `useMingoRealtimeSubscription` - Real-time NATS subscription management

### Core Features
- **Draft Chat Mode** - New conversation state before dialog creation
- **Dialog Management** - Browse, select, and create chat dialogs
- **Real-time Messaging** - Live updates via NATS subscriptions
- **URL State Sync** - Dialog selection synced with URL parameters
- **Keyboard Navigation** - ESC key handling for navigation
- **Message Approvals** - Pending approval system for AI responses

### UI Layout
- Two-panel interface with sidebar and main chat area
- Responsive design with proper flex layouts
- Empty state with Mingo AI branding
- Auto-scrolling message list

## Usage Example

```typescript
// The component automatically handles routing and state
// URL: /mingo?dialogId=123 will load dialog 123
// URL: /mingo will show empty state

// Key interactions:
// - Click "New Chat" → enters draft mode
// - Send first message → creates new dialog
// - ESC key → exits current dialog/draft
// - Dialog selection → updates URL and loads messages
```

The component integrates with the broader OpenFrame ecosystem, requiring SaaS tenant mode and providing seamless AI chat functionality with full state persistence and real-time capabilities.
