This is the main page component for the Mingo AI chat interface, providing a complete chat experience with realtime messaging, dialog management, and conversation history within the Flamingo OpenFrame platform.

## Key Components

- **Mingo()** - Main page component that renders the complete chat interface
- **State Management Hooks** - Multiple custom hooks for dialog management, chat functionality, and realtime subscriptions
- **Chat Interface** - Sidebar for conversations, main message area, and input component
- **Realtime Subscriptions** - NATS-based messaging with background dialog handling and unread counts
- **URL State Management** - Dialog selection synchronized with browser URL parameters

## Architecture

The component uses a hub-and-spoke pattern with specialized hooks:
- `useMingoMessagesStore` - Central state for active dialogs and unread counts
- `useMingoChat` - Message processing and sending functionality  
- `useMingoDialogs` - Dialog list management with infinite scroll
- `useMingoRealtimeSubscription` - NATS subscription management for live updates

The interface is restricted to SaaS tenant mode and automatically redirects to dashboard for other deployment types.
