This Next.js page component implements the main Mingo AI chat interface for the Flamingo platform, providing a real-time AI assistant chat experience with dialog management, message streaming, and NATS-based real-time communication.

## Key Components

- **Main Chat Interface**: Full-featured AI chat with sidebar, message list, and input
- **Dialog Management**: Create, select, and manage multiple chat conversations
- **Real-time Messaging**: NATS websocket subscriptions for live message streaming
- **State Management**: Multiple Zustand stores for dialog details and background messages
- **URL State Sync**: Dialog selection synchronized with browser URL parameters
- **Welcome Messages**: Automatic greeting messages for new conversations

## Usage Example

```typescript
// The component automatically handles:
// - Dialog creation and selection
// - Real-time message streaming via NATS
// - Background dialog subscriptions
// - Optimistic message updates
// - Keyboard shortcuts (ESC to clear selection)

// URL patterns:
// /mingo - No dialog selected (welcome screen)
// /mingo?dialogId=123 - Dialog 123 selected

// Key user interactions:
// - Click sidebar dialog → Select and load conversation
// - Click "New Chat" → Create new dialog and select it
// - Type message + Enter → Send with optimistic updates
// - Press ESC → Clear dialog selection, return to welcome
```

The component ensures SaaS tenant mode is enabled and provides a comprehensive chat experience with persistent background subscriptions, optimistic UI updates, and seamless dialog switching while maintaining real-time connectivity to all active conversations.
