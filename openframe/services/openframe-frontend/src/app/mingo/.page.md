A Next.js client-side page component that renders the main Mingo AI chat interface, providing a full-featured chat application with dialog management, real-time messaging, and multi-pane layout.

## Key Components

- **Main Chat Interface**: Split-pane layout with sidebar for dialog list and main area for messages
- **Dialog Management**: Handles dialog selection, creation, URL synchronization, and navigation
- **Real-time Messaging**: Integrates WebSocket subscriptions for live message updates via NATS
- **Draft Chat Mode**: Allows users to start conversations before creating a dialog
- **Message Approval System**: Handles pending approvals for AI-generated actions
- **Keyboard Navigation**: ESC key support for closing dialogs and draft chats
