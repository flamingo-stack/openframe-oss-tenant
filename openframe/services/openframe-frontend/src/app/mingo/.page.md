This is the main Mingo AI chat interface page component that provides a complete chat application with sidebar navigation, message handling, and real-time subscriptions.

## Key Components

- **Dialog Management**: Handles dialog selection, creation, and URL synchronization via `useMingoDialogs` and `useMingoDialogSelection`
- **Chat Interface**: Renders `ChatSidebar` for navigation and `ChatMessageList` for message display
- **Real-time Communication**: Manages NATS subscriptions through `DialogSubscription` components for live message updates
- **Message Processing**: Processes chat chunks and handles approvals via `useMingoChat` hook
- **State Management**: Uses `useMingoMessagesStore` for active dialog state and unread counts
- **Routing Integration**: Syncs dialog selection with URL search parameters

## Usage Example

```typescript
// The component is used as a Next.js page route
// Automatically handles SaaS tenant mode validation
export default function MingoPage() {
  // Component manages its own state internally
  // URL format: /mingo?dialogId=dialog-123
  return <Mingo />
}

// Key user interactions:
// - ESC key closes active dialog
// - Sidebar allows dialog selection and creation
// - Message input sends to active dialog
// - Real-time updates via NATS subscriptions
```

The component includes comprehensive error handling, loading states, and responsive design. It only renders in SaaS tenant mode and redirects to dashboard otherwise. The interface supports both dialog-based conversations and a welcome screen when no dialog is selected.
