A Next.js client-side page component that implements Mingo AI's conversational interface for technical support, featuring real-time chat functionality, dialog management, and approval workflows.

## Key Components

- **Main Component**: `Mingo()` - The primary page component with client-side rendering
- **State Management**: 
  - `useMingoMessagesStore` - Global message state management
  - `isDraftChat` - Local state for new conversation drafts
- **Custom Hooks**:
  - `useMingoDialog` - Individual dialog operations
  - `useMingoDialogs` - Dialog list management with pagination
  - `useMingoDialogSelection` - Dialog selection and message loading
  - `useMingoChat` - Message processing and AI interactions
  - `useMingoRealtimeSubscription` - NATS real-time subscriptions
- **UI Components**: `ChatSidebar`, `ChatMessageList`, `ChatInput`, `MingoIcon`
