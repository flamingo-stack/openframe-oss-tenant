A Next.js client-side page component that provides the main Mingo AI chat interface with real-time messaging, dialog management, and NATS-based communication.

## Key Components

- **Main Page Component**: `Mingo` - The primary chat interface with sidebar and message area
- **Custom Hooks**: Multiple specialized hooks for dialog management, message processing, and real-time updates
- **State Management**: Zustand stores for dialog details and background messages
- **Real-time Communication**: NATS subscription components for live message streaming
- **Layout Components**: Sidebar, message list, and input components from the core library

## Usage Example

```typescript
// This is a Next.js page component - no direct import needed
// Access via navigation to the route where this page.tsx is located

// The component handles:
// 1. Dialog creation and selection
// 2. Real-time message streaming via NATS
// 3. Message sending and receiving
// 4. URL-based dialog state management
// 5. Keyboard shortcuts (ESC to close dialog)

// Key user interactions:
const handleNewChat = async () => {
  // Creates new dialog and navigates to it

  handleDialogSelect(newDialogId)

const handleSendMessage = async (message: string) => {
  // Adds optimistic message, creates empty assistant response, sends to backend
  addRealtimeMessage(optimisticMessage)

}
```

The component features a responsive layout with a collapsible sidebar for dialog history, a main chat area with message bubbles, and real-time typing indicators. It includes welcome messages for new dialogs and maintains persistent NATS subscriptions for background message updates.
