Main page component for the Mingo AI chat interface, providing a full-featured chat application with real-time messaging, dialog management, and SaaS tenant validation.

## Key Components

- **Main Layout**: `AppLayout` with `ContentPageContainer` for full-height chat interface
- **Chat Management**: `ChatSidebar` for dialog selection and `ChatInput` for message composition
- **Real-time Messaging**: `DialogSubscription` components for NATS-based live updates
- **State Management**: Multiple custom hooks for dialogs, messages, and real-time subscriptions
- **Message Display**: `ChatMessageList` with typing indicators and approval handling
- **Navigation**: URL-based dialog selection with keyboard shortcuts (Escape key)

## Usage Example

```typescript
// This is a Next.js page component - accessed via routing
// URL: /mingo or /mingo?dialogId=abc123

// Key features:
// 1. Select/create chat dialogs via sidebar
// 2. Real-time message streaming via NATS
// 3. URL-based dialog state management
// 4. Keyboard shortcuts (Esc to close dialog)
// 5. SaaS tenant mode validation

// The component automatically:
// - Redirects non-SaaS users to dashboard
// - Manages dialog subscriptions for real-time updates
// - Handles unread message counts
// - Provides approval workflows for AI responses
```

The component integrates multiple specialized hooks (`useMingoDialog`, `useMingoChat`, `useMingoRealtimeSubscription`) to create a cohesive chat experience with proper state synchronization and error handling.
