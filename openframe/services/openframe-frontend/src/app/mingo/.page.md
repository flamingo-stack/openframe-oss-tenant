This is the main Mingo AI chat interface component that provides a complete conversational AI experience with dialog management, real-time messaging, and multi-topic NATS subscriptions.

## Key Components

- **useMingoMessagesStore** - Zustand store for managing active dialogs and unread counts
- **useMingoDialog/useMingoDialogs** - Hooks for dialog CRUD operations and pagination
- **useMingoDialogSelection** - Manages dialog selection state and message approval workflows
- **useMingoChat** - Core chat functionality including message processing and dialog creation
- **useMingoRealtimeSubscription** - WebSocket-based real-time messaging via NATS
- **DialogSubscription** - Multi-topic NATS subscription component for background dialog updates
- **ChatSidebar** - Dialog list with infinite scrolling and new chat creation
- **ChatMessageList** - Message display with typing indicators and approval handling
- **ChatInput** - Message composition interface

## Usage Example

```typescript
// The component handles URL-based dialog routing
// Navigate to: /mingo?dialogId=abc123 to open a specific dialog

// Key user interactions:
// 1. Create new dialog
const handleNewChat = useCallback(async () => {
  const newDialogId = await createDialog()
  // Automatically navigates to new dialog
}, [])

// 2. Send message in active dialog
const handleSendMessage = useCallback(async (message: string) => {
  if (activeDialogId) {
    await sendMessage(message.trim())
  }
}, [activeDialogId])

// 3. Real-time message processing
const createDialogChunkProcessor = useCallback((targetDialogId, chunk, messageType) => {
  // Updates unread counts for background dialogs
  if (targetDialogId !== activeDialogId) {
    incrementUnread(targetDialogId)
  }
  processChunk(targetDialogId, chunk, messageType)
}, [activeDialogId])
```

The component enforces SaaS tenant mode and provides keyboard shortcuts (Escape to close dialogs). It maintains URL synchronization for dialog state and handles real-time updates through NATS subscriptions with automatic background dialog management.
