This is the main Mingo AI chat interface component that provides a complete chat experience with real-time messaging, dialog management, and AI assistant interactions within the Flamingo OpenFrame platform.

## Key Components

- **useMingoChat**: Core chat functionality for creating dialogs, sending messages, and processing approvals
- **useMingoRealtimeSubscription**: WebSocket-based real-time messaging via NATS
- **useMingoMessagesStore**: Global state management for active dialogs and unread counts
- **ChatSidebar**: Left panel displaying dialog list with pagination and new chat creation
- **ChatMessageList**: Main chat area showing message history with typing indicators
- **ChatInput**: Message composition interface with send functionality
- **DialogSubscription**: Real-time subscription component for background dialog updates

## Usage Example

```typescript
// This component is used as a page route in Next.js
// Access via: /mingo?dialogId=123

export default function MingoPage() {
  return <Mingo />
}

// Key features:
// - URL-based dialog selection via searchParams
// - Real-time messaging with NATS subscriptions  
// - Background dialog updates with unread counts
// - Keyboard shortcuts (ESC to close dialog)
// - SaaS tenant mode validation
// - Responsive layout with sidebar and main chat area
```

The component orchestrates multiple custom hooks to provide a seamless chat experience, handling everything from dialog creation and selection to real-time message delivery and approval workflows. It includes comprehensive error handling, loading states, and accessibility features like keyboard navigation.
