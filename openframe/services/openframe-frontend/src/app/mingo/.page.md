A Next.js client component that renders the main Mingo AI chat interface, managing multiple chat dialogs with real-time messaging, approval workflows, and URL-based navigation.

## Key Components

- **Main Chat Interface**: Sidebar for dialog management and main chat area for active conversations
- **Real-time Subscriptions**: NATS-based messaging with multi-topic support for live updates
- **Dialog Management**: Create, select, and navigate between chat dialogs with URL state sync
- **Message Processing**: Handles chunked message delivery, approvals, and typing indicators
- **Keyboard Navigation**: ESC key to close dialogs, URL parameter management

## Usage Example

```typescript
// The component is used as a page route in Next.js
// URL: /mingo?dialogId=abc123

// Key state management hooks:
const {
  activeDialogId,
  setActiveDialogId,
  resetUnread,
  incrementUnread,
} = useMingoMessagesStore()

// Dialog selection with URL sync:
const handleDialogSelect = async (dialogId: string) => {
  const currentUrl = new URL(window.location.href)
  currentUrl.searchParams.set('dialogId', dialogId)
  router.replace(currentUrl.pathname + currentUrl.search)
  
  setActiveDialogId(dialogId)
  subscribeToDialog(dialogId)
}

// Real-time message processing:
const createDialogChunkProcessor = (targetDialogId: string, chunk: ChunkData) => {
  if (targetDialogId !== activeDialogId) {
    incrementUnread(targetDialogId)
  }
  processChunk(targetDialogId, chunk, messageType)
}
```

The component includes sophisticated real-time messaging with background dialog support, automatic unread count management, and seamless URL-based navigation between chat sessions.
