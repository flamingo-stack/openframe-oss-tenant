A Next.js client page component that renders the Mingo AI chat interface, providing a complete conversational AI experience with dialog management, real-time messaging, and SaaS tenant validation.

## Key Components

- **Dialog Management**: Handles multiple conversation threads with selection, creation, and URL synchronization
- **Real-time Messaging**: NATS-based subscription system for live message updates and notifications
- **Chat Interface**: Integrated sidebar for dialog navigation and main chat area with message history
- **State Management**: Zustand store for message state with unread counters and active dialog tracking
- **Approval System**: Message approval workflow with pending actions and status management
- **SaaS Mode Validation**: Restricts access to SaaS tenant environments only

## Usage Example

```typescript
// This is a Next.js page component - no direct imports needed
// Access via route: /mingo

// URL parameters supported:
// - ?dialogId=123 - Opens specific dialog
// - ESC key closes current dialog

// Key interactions:
// - Click sidebar dialog to switch conversations
// - Create new chat from sidebar
// - Send messages with Enter key
// - Automatic real-time message sync
```

[![Mingo AI Demo](https://img.youtube.com/vi/example-video/maxresdefault.jpg)](https://www.youtube.com/watch?v=example-video)

The component leverages multiple custom hooks for separation of concerns: dialog management (`useMingoDialogs`), message handling (`useMingoChat`), real-time subscriptions (`useMingoRealtimeSubscription`), and selection logic (`useMingoDialogSelection`). It provides a complete chat experience with keyboard shortcuts, URL state management, and responsive design.
