Main page component for Mingo AI chat interface, providing a complete chat experience with real-time messaging, dialog management, and NATS-based subscriptions for multi-user collaboration.

## Key Components

- **Mingo**: Main page component with chat interface layout
- **Dialog Management**: Handles dialog selection, creation, and URL state sync
- **Real-time Subscriptions**: NATS-based messaging with multi-topic support
- **Message Processing**: Handles approvals, typing indicators, and message flow
- **UI Layout**: Sidebar for dialogs, main chat area, and input controls

## Usage Example

```typescript
// This is a Next.js page component - used automatically by Next.js routing
// Place in app/mingo/page.tsx for /mingo route

// Key features demonstrated:
// - URL state management with dialogId parameter
// - Real-time message subscriptions per dialog
// - ESC key handling for dialog deselection
// - SaaS tenant mode validation

// Example URL patterns:
// /mingo - Shows welcome screen
// /mingo?dialogId=123 - Opens specific dialog

// The component handles:
// - Dialog creation and selection
// - Message sending and receiving
// - Unread message tracking
// - Approval/rejection workflows
// - Keyboard shortcuts (ESC to close)
```

The component integrates multiple custom hooks for state management and provides a full-featured AI chat interface with sidebar navigation, real-time updates, and message approval workflows. Only renders in SaaS tenant mode, redirecting to dashboard otherwise.
