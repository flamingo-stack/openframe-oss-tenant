A Next.js page component that implements Mingo AI, Flamingo's intelligent assistant interface for technicians, featuring real-time chat functionality with dialog management and NATS messaging integration.

## Key Components

- **Main Chat Interface**: Split-pane layout with sidebar for dialog list and main chat area
- **State Management**: Integrates multiple custom hooks for dialog management, chat functionality, and real-time subscriptions
- **Real-time Messaging**: Uses NATS subscriptions with `DialogSubscription` components for live message updates
- **URL State Sync**: Synchronizes active dialog with URL parameters for deep linking
- **SaaS Mode Enforcement**: Redirects non-SaaS tenants to dashboard

## Usage Example

```typescript
// The component automatically handles routing and state
// URL: /mingo?dialogId=123 will open dialog 123
// Keyboard: ESC key closes active dialog

// Key user interactions:
// - Click "New Chat" to create dialog
// - Select dialog from sidebar 
// - Send messages via ChatInput
// - Real-time updates via NATS subscriptions

// Component integrates with OpenFrame frontend core:
import { 
  ChatMessageList, 
  ChatSidebar,
  ChatInput 
} from '@flamingo-stack/openframe-frontend-core'
```

The component provides a complete AI assistant experience with persistent conversations, background message handling with unread counts, and seamless real-time collaboration features.
