A Next.js page component implementing the Mingo AI chat interface with real-time messaging, dialog management, and URL state synchronization.

## Key Components

- **Mingo** - Main chat interface component with sidebar and message area
- **State Management** - Multiple custom hooks for dialog management, chat functionality, and real-time subscriptions
- **URL Integration** - Synchronizes active dialog with URL search parameters for deep linking
- **Real-time Messaging** - NATS subscription system for live message updates across dialogs
- **Message Processing** - Handles chunk-based message streaming and approval workflows

## Usage Example

```typescript
// This is a Next.js page component - no direct instantiation needed
// Access via: /mingo route in the application

// URL structure examples:
// /mingo - Shows welcome screen
// /mingo?dialogId=123 - Opens specific dialog

// Key features:
// - ESC key to clear active dialog
// - Real-time message sync across dialogs
// - Unread message counters
// - Infinite scroll for dialog history
// - Message approval/rejection workflow
```

The component orchestrates multiple specialized hooks to provide a complete chat experience, including dialog creation, message sending, real-time updates, and approval workflows. It only renders in SaaS tenant mode and redirects to dashboard otherwise.
