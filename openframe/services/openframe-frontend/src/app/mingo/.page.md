A Next.js client component that renders the Mingo AI chat interface, providing a complete chat experience with sidebar navigation, real-time messaging, and dialog management.

## Key Components

- **State Management**: Uses multiple custom hooks for dialog management, chat functionality, and real-time subscriptions
- **Router Integration**: Syncs dialog selection with URL parameters for deep linking and navigation
- **Real-time Messaging**: Implements NATS-based subscriptions for live message updates across dialogs
- **Chat Interface**: Renders a sidebar with dialog list and main chat area with message history
- **SaaS Mode Guard**: Restricts access to SaaS tenant mode only, redirecting to dashboard otherwise
