A Next.js page component implementing the Mingo AI chat interface with real-time messaging capabilities, dialog management, and URL-based routing for the OpenFrame platform.

## Key Components

- **Mingo**: Main page component with chat interface, sidebar, and message handling
- **State Management**: Multiple custom hooks for dialogs, messages, and real-time subscriptions
- **Real-time Subscriptions**: NATS-based messaging with background dialog support and unread counters
- **Routing Integration**: URL parameter synchronization for dialog selection with escape key navigation
- **SaaS Mode Protection**: Automatically redirects non-SaaS tenants to dashboard
