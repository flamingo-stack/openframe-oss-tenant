A Next.js client component that implements the Mingo AI chat interface, providing a full-featured chat application with real-time messaging, dialog management, and AI assistant interactions.

## Key Components

- **Main Chat Interface**: Split layout with sidebar for dialog list and main area for active conversation
- **State Management**: Multiple custom hooks for dialog selection, chat functionality, and real-time subscriptions
- **Real-time Updates**: NATS-based subscription system for live message updates across dialogs
- **Dialog Management**: Create new conversations, select existing dialogs, and handle URL-based navigation
- **Message Processing**: Handles message sending, chunk processing, and approval workflows
- **Responsive Design**: Mobile-friendly layout with proper keyboard shortcuts (Escape to close dialog)

## Usage Example

```typescript
// This is a Next.js page component, typically used at /mingo route
// Automatically handles:
// - URL params for dialog selection (?dialogId=123)
// - Real-time message subscriptions
// - Dialog creation and navigation
// - SaaS tenant mode validation

// Key features:
// - Press Escape to close active dialog
// - Real-time message updates with unread counts
// - Infinite scroll for dialog history
// - Automatic message approval handling
```

The component integrates multiple OpenFrame frontend core components and implements a complete chat experience with proper state management, real-time updates, and responsive design patterns.
