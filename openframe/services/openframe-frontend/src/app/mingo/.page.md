This file implements the main Mingo AI chat interface page, providing a complete chat experience with dialog management, real-time messaging, and approval workflows for the Flamingo platform.

## Key Components

- **Main Page Component**: `Mingo()` - The primary chat interface with sidebar and message area
- **Dialog Management**: Integration with multiple hooks for dialog creation, selection, and state management
- **Real-time Messaging**: NATS subscription system for live message updates across dialogs
- **Chat Interface**: Split layout with dialog sidebar and main chat area
- **Keyboard Navigation**: Escape key support for dialog deselection
- **URL State Management**: Syncs active dialog with URL parameters
- **SaaS Mode Protection**: Redirects non-SaaS tenants to dashboard

## Usage Example

```typescript

// Key features demonstrated:

// Dialog selection with URL sync
const handleDialogSelect = useCallback(async (dialogId: string) => {
  const currentUrl = new URL(window.location.href)
  currentUrl.searchParams.set('dialogId', dialogId)
  router.replace(currentUrl.pathname + currentUrl.search)
  setActiveDialogId(dialogId)
  selectDialog(dialogId)
}, [])

// Real-time message processing
```
