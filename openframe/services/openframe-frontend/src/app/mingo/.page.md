A Next.js client-side page component that provides the main Mingo AI chat interface, combining dialog management, real-time messaging, and user interactions into a unified chat experience.

## Key Components

- **State Management**: Uses multiple custom hooks for dialog management (`useMingoDialogs`, `useMingoDialog`), chat functionality (`useMingoChat`), and real-time subscriptions (`useMingoRealtimeSubscription`)
- **Draft Chat Mode**: Handles new conversations with a temporary draft state before creating actual dialogs
- **Message Processing**: Manages message display, typing indicators, and approval workflows
- **URL Synchronization**: Syncs active dialog state with URL parameters for deep linking
- **Keyboard Navigation**: Implements Escape key handling for navigation
- **Real-time Updates**: Subscribes to dialog updates via NATS messaging

## Usage Example

```typescript
// This is a page component, typically accessed via routing
// URL examples:
// /mingo - Shows empty state
// /mingo?dialogId=abc123 - Opens specific dialog

// Key interactions:
const handleNewChat = () => {
  // Creates draft mode for new conversations
  setIsDraftChat(true)
  // Clears URL parameters
}

const handleSendMessage = async (message: string) => {
  if (isDraftChat) {
    // Creates new dialog and sends first message
    const newDialogId = await createDialog()
    await sendMessage(message, newDialogId)
  } else {
    // Sends message to active dialog
    await sendMessage(message)
  }
}
```

The component renders a two-panel layout with a sidebar for dialog selection and a main chat area for message display and input, with support for both draft conversations and persistent dialogs.
