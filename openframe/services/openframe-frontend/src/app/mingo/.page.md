Mingo AI chat interface component that provides a complete conversational AI experience within the OpenFrame platform. Handles dialog management, real-time messaging, and NATS-based subscriptions for live updates.

## Key Components

- **Dialog Management**: Creates, selects, and manages multiple chat dialogs with URL state synchronization
- **Real-time Messaging**: Processes streaming responses and maintains background subscriptions for inactive dialogs
- **Message Processing**: Handles optimistic updates, welcome messages, and typing indicators
- **State Management**: Uses multiple Zustand stores for dialog details, background messages, and UI state
- **NATS Integration**: Manages WebSocket subscriptions for real-time chunk processing across dialogs

## Usage Example

```typescript
// Component is used as a Next.js page route
// URL: /mingo?dialogId=abc123

// Automatic dialog selection from URL
const urlDialogId = searchParams.get('dialogId')
if (urlDialogId) {
  selectDialogInternal(urlDialogId) // Loads dialog and subscribes to updates
}

// Send a message with optimistic updates
const handleSendMessage = async (message: string) => {
  // Add optimistic user message immediately
  addRealtimeMessage(optimisticMessage)
  // Add empty assistant message for streaming
  addRealtimeMessage(emptyAssistantMessage)
  // Send to backend and stream response via NATS
  await sendMessage(message, currentDialogId)
}

// Background dialog updates maintain unread counts
onBackgroundUnreadIncrement: (dialogId: string) => {
  incrementUnreadCount(dialogId)
}
```

The component integrates ChatSidebar for dialog navigation, ChatMessageList for message display, and ChatInput for user interaction, while managing complex state synchronization across multiple active dialog subscriptions.
