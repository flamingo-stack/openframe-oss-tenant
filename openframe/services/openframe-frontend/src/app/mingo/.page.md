This Next.js page component implements the main Mingo AI chat interface, providing a conversational AI experience with dialog management, real-time messaging, and persistent NATS subscriptions for background message handling.

## Key Components

- **Dialog Management**: Handles creating, selecting, and switching between chat dialogs with URL synchronization
- **Real-time Messaging**: Processes streaming chunks via NATS subscriptions with background dialog support
- **Message Processing**: Manages optimistic updates, welcome messages, and typing indicators
- **State Management**: Coordinates multiple Zustand stores for dialog details and background messages
- **Chat Interface**: Renders sidebar with dialog list and main chat area with message history

## Usage Example

```typescript
// URL-based dialog selection
// Navigate to: /mingo?dialogId=abc123
const searchParams = useSearchParams()
const dialogId = searchParams.get('dialogId')

// Creating a new dialog
const handleNewChat = async () => {
  const newDialogId = await createDialog()
  if (newDialogId) {
    router.push(`/mingo?dialogId=${newDialogId}`)
  }
}

// Sending a message with optimistic updates
const handleSendMessage = async (message: string) => {
  const optimisticMessage = {
    id: `optimistic-${Date.now()}`,
    text: message,
    owner: { type: 'ADMIN' }
  }
  addRealtimeMessage(optimisticMessage)
  await sendMessage(message, currentDialogId)
}
```

The component features SaaS tenant mode validation, keyboard shortcuts (Escape to deselect), and maintains persistent NATS subscriptions for all accessed dialogs to handle background message updates.
