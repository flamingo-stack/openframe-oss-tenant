This is a React component that implements the main Mingo AI chat interface, providing a full-featured chat experience with dialog management, real-time messaging, and message approval workflows.

## Key Components

- **Mingo**: Main page component that renders the complete Mingo AI chat interface
- **State Management**: Uses multiple custom hooks for dialog management, chat functionality, and real-time subscriptions
- **Message Handling**: Supports draft chats, existing dialog selection, and message approval workflows
- **Routing**: Integrates with Next.js routing to handle dialog selection via URL parameters
- **Real-time Features**: Implements NATS subscriptions for live message updates

## Usage Example

```typescript
// This component is typically used as a Next.js page
// URL structure: /mingo?dialogId=12345

// The component handles:
// - Creating new chat dialogs
// - Selecting existing dialogs from sidebar
// - Sending messages with real-time updates
// - Managing message approvals
// - Keyboard shortcuts (ESC to close)

// Key user interactions:
// 1. Start new chat -> Creates draft state
// 2. Send first message -> Creates new dialog
// 3. Select existing dialog -> Loads chat history
// 4. Real-time message updates via NATS subscriptions
```

The component provides a complete chat interface with sidebar navigation, message display, input handling, and integrates with the broader OpenFrame platform. It's designed specifically for SaaS tenant mode and includes comprehensive state management for dialogs, messages, and user interactions.
