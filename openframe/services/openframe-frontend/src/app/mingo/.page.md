Main page component for the Mingo AI chat interface that manages dialog-based conversations with real-time messaging capabilities and NATS subscription handling.

## Key Components

- **useMingoDialog** - Handles dialog creation and message sending operations
- **useMingoDialogs** - Manages dialog list fetching with pagination
- **useMingoDialogSelection** - Handles dialog selection and message loading
- **useProcessedMessages** - Processes raw messages for display with approval states
- **useMingoRealtimeProcessor** - Manages real-time message streaming and chunk processing
- **DialogNatsSubscription** - Persistent NATS subscriptions for each dialog
- **ChatSidebar** - Dialog list with creation and selection capabilities
- **ChatMessageList** - Message display with typing indicators and approval states
- **ChatInput** - Message composition and sending interface

## Usage Example

```typescript
// The component automatically handles URL-based dialog routing
// Access via: /mingo?dialogId=123

// Key interaction flows:
const handleDialogSelect = useCallback(async (dialogId: string) => {
  // Updates URL and initializes dialog state
  const currentUrl = new URL(window.location.href)
  currentUrl.searchParams.set('dialogId', dialogId)
  router.replace(currentUrl.pathname + currentUrl.search)
  selectDialogInternal(dialogId)
}, [currentDialogId, router, selectDialogInternal])

// Real-time message processing
const handleChunkReceived = useCallback((dialogId: string, chunk: ChunkData, messageType: NatsMessageType) => {
  processChunk(chunk, messageType, dialogId)
}, [processChunk])

// Optimistic message sending
const handleSendMessage = useCallback(async (message: string) => {
  // Immediately adds user message to UI
  const optimisticMessage: Message = {
    id: `optimistic-${Date.now()}`,
    dialogId: currentDialogId,
    owner: { type: 'ADMIN' },
    messageData: { type: 'TEXT', text: message.trim() }
  }
  addRealtimeMessage(optimisticMessage)
}, [sendMessage, currentDialogId])
```
