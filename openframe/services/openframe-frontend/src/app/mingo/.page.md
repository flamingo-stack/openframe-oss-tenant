Main chat interface page for Mingo AI, integrating chat functionality with real-time messaging, dialog management, and approval workflows within the OpenFrame platform.

## Key Components

- **Dialog Management**: Handles dialog selection, creation, and URL synchronization
- **Real-time Messaging**: NATS subscriptions for live message streaming
- **Chat Interface**: Message list, input, and sidebar with dialog history
- **Approval System**: Message approval/rejection workflow integration
- **Store Integration**: Connects to Zustand stores for state management

## Usage Example

```typescript
// This page is automatically rendered at the Mingo route
// Key features include:

// Dialog selection with URL sync
const handleDialogSelect = useCallback(async (dialogId: string) => {
  const currentUrl = new URL(window.location.href)
  currentUrl.searchParams.set('dialogId', dialogId)
  router.replace(currentUrl.pathname + currentUrl.search, { scroll: false })
  
  setActiveDialogId(dialogId)
  resetUnread(dialogId)
  subscribeToDialog(dialogId)
  selectDialog(dialogId)
}, [activeDialogId, router, setActiveDialogId])

// Real-time message processing
const createDialogChunkProcessor = useCallback((targetDialogId: string, chunk: ChunkData, messageType: NatsMessageType) => {
  if (targetDialogId !== activeDialogId) {
    incrementUnread(targetDialogId)
  }
  processChunk(targetDialogId, chunk, messageType)
}, [activeDialogId, incrementUnread, processChunk])

// Message sending
const handleSendMessage = useCallback(async (message: string) => {
  if (!activeDialogId || !message.trim()) return
  
  const success = await sendMessage(message.trim())
  if (!success) {
    console.warn('[Mingo] Failed to send message')
  }
}, [activeDialogId, sendMessage])
```

The component enforces SaaS tenant mode and provides keyboard shortcuts (ESC to clear dialog selection). It manages real-time subscriptions through DialogSubscription components and maintains unread counts for background dialogs.
