A Next.js page component that implements the Mingo AI chat interface with real-time messaging, dialog management, and subscription handling for the Flamingo platform's AI assistant.

## Key Components

- **Mingo**: Main page component with chat UI, sidebar navigation, and message handling
- **State Management**: Integrates multiple custom hooks for dialogs, messages, and real-time subscriptions
- **Dialog System**: Manages chat conversations with create, select, and navigation functionality
- **Real-time Features**: NATS subscriptions for live message updates and approvals
- **Draft Mode**: Temporary chat state before creating actual dialogs

## Usage Example

```typescript
// This is a Next.js page component - accessed via routing
// Located at /mingo route in the application

// Key features demonstrated:
import { useMingoChat } from './hooks/use-mingo-chat'
import { useMingoMessagesStore } from './stores/mingo-messages-store'

// Real-time message handling
const { messages, sendMessage, isTyping } = useMingoChat(activeDialogId)

// Dialog subscription for live updates
const { subscribeToDialog } = useMingoRealtimeSubscription(activeDialogId)

// Send message with dialog creation
const handleSendMessage = async (message: string) => {
  if (isDraftChat) {
    const newDialogId = await createDialog()
    await sendMessage(message, newDialogId)
  } else {
    await sendMessage(message)
  }
}
```

The component provides a complete chat interface with sidebar navigation, message history, real-time updates, and seamless dialog management for the Mingo AI assistant experience.
