The main page component for Mingo AI chat interface, providing a complete chat experience with real-time messaging, dialog management, and AI assistant interactions.

## Key Components

**Main Exports:**
- `Mingo` (default) - Complete chat interface with sidebar, message list, and input

**Core Features:**
- **Real-time Chat** - WebSocket-based messaging with typing indicators
- **Dialog Management** - Create, select, and manage chat conversations
- **Draft Mode** - Start new conversations with welcome messages
- **URL State Sync** - Dialog selection synced with URL parameters
- **Keyboard Navigation** - Escape key to close dialogs/drafts
- **SaaS Mode Gating** - Only available in SaaS tenant mode

**Custom Hooks Used:**
- `useMingoDialog` - Dialog creation and management
- `useMingoDialogs` - Dialog list with pagination
- `useMingoDialogSelection` - Dialog selection and message loading
- `useMingoChat` - Message sending and real-time updates
- `useMingoRealtimeSubscription` - NATS-based real-time subscriptions
- `useMingoMessagesStore` - Global message state management

## Usage Example

```typescript
// Rendered as the main Mingo AI page
export default function Mingo() {
  // URL parameter handling
  const router = useRouter()
  const searchParams = useSearchParams()
  
  // Dialog selection with URL sync
  const handleDialogSelect = useCallback(async (dialogId: string) => {
    const currentUrl = new URL(window.location.href)
    currentUrl.searchParams.set('dialogId', dialogId)
    router.replace(currentUrl.pathname + currentUrl.search)
    
    setActiveDialogId(dialogId)
    selectDialog(dialogId)
  }, [])
  
  // Message sending with draft chat creation
  const handleSendMessage = useCallback(async (message: string) => {
    if (isDraftChat) {
      const newDialogId = await createDialog()
      // Convert draft to real dialog
    } else {
      await sendMessage(message.trim())
    }
  }, [isDraftChat, createDialog, sendMessage])
}
```

The component provides a three-panel layout: dialog sidebar, message list, and input area, with comprehensive state management for chat operations and real-time updates.
