A Next.js page component that implements the main Mingo AI chat interface, providing a complete chat experience with real-time messaging, dialog management, and NATS-based communication.

## Key Components

- **Main Chat Interface**: Full-screen chat layout with sidebar and message area
- **Dialog Management**: Create, select, and manage multiple chat conversations
- **Real-time Messaging**: NATS subscription system for live message streaming
- **State Management**: Multiple stores for dialog details and background messages
- **Message Processing**: Handles streaming responses, optimistic updates, and typing indicators
- **URL State Sync**: Keeps dialog selection in sync with browser URL parameters

## Usage Example

This is a page component that should be placed in the Next.js app router structure:

```typescript
// File: app/mingo/page.tsx
// Accessed via: /mingo

// The component handles:
// 1. Dialog creation and selection
// 2. Real-time message streaming via NATS
// 3. URL parameter synchronization
// 4. Keyboard shortcuts (Escape to clear dialog)

// Key user interactions:
// - Click "New Chat" to create a dialog
// - Select existing dialogs from sidebar
// - Send messages via chat input
// - Navigate with URL: /mingo?dialogId=123
```

**Features:**
- **SaaS Mode Only**: Redirects to dashboard if not in SaaS tenant mode
- **Multiple NATS Subscriptions**: Maintains persistent connections to all visited dialogs
- **Optimistic Updates**: Shows messages immediately while sending to backend
- **Welcome Messages**: Auto-generates greeting messages for new empty dialogs
- **Keyboard Navigation**: ESC key clears current dialog selection
- **Background Notifications**: Tracks unread counts for inactive dialogs
