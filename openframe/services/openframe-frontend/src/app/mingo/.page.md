This React page component provides the main interface for the Mingo AI chat assistant in SaaS tenant mode, handling dialog management, real-time messaging, and NATS-based communication.

## Key Components

- **Main Chat Interface**: Full-screen chat layout with sidebar and message area
- **Real-time Communication**: NATS subscription management for live message streaming
- **Dialog Management**: Create, select, and manage multiple chat conversations
- **URL State Sync**: Synchronizes dialog selection with browser URL parameters
- **Background Message Handling**: Manages messages from non-active dialogs with unread counts
- **Welcome Messages**: Automatically adds greeting messages to new conversations
- **Keyboard Navigation**: ESC key support for dialog deselection

## Usage Example

```typescript
// The component is used as a Next.js page route
// Automatically redirects non-SaaS tenants to dashboard
// Manages multiple chat dialogs with persistent NATS subscriptions

// Key hooks integration:
const { dialogs, isLoading } = useMingoDialogs()
const { selectDialog, isLoadingDialog } = useMingoDialogSelection()
const { processedMessages, assistantType } = useProcessedMessages()

// URL-based dialog selection:
// /mingo?dialogId=123 -> selects dialog 123
// /mingo -> shows welcome screen

// Real-time message handling:
handleChunkReceived(dialogId, chunk, messageType) // Processes incoming NATS chunks
handleSendMessage(message) // Sends user messages with optimistic updates
```

The component uses a sophisticated state management system with multiple Zustand stores and custom hooks to handle the complexity of real-time chat with multiple simultaneous dialog subscriptions.
