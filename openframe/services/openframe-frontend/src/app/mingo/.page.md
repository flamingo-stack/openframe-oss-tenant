Main page component for the Mingo AI chat interface, providing a complete conversational experience with real-time messaging, dialog management, and multi-dialog support.

## Key Components

- **Mingo()** - Main component orchestrating the entire chat interface
- **Dialog Management** - Handles creation, selection, and navigation of chat dialogs
- **Real-time Subscriptions** - NATS-based live message streaming with unread counters
- **Message Processing** - Handles sending, receiving, and approval workflows
- **Keyboard Navigation** - ESC key support for dialog navigation
- **URL State Management** - Syncs active dialog with browser URL parameters

## Usage Example

```typescript
import Mingo from './page'

// Deployed as a Next.js page component
// Automatically handles:
// - Dialog creation and selection via sidebar
// - Real-time message streaming
// - URL state synchronization
// - Keyboard shortcuts (ESC to close dialog)
// - SaaS tenant mode validation

// Example URL patterns:
// /mingo - Shows welcome screen
// /mingo?dialogId=123 - Opens specific dialog

// Key interactions:
// - Click sidebar dialog → selects and loads messages
// - Click "New Chat" → creates dialog and navigates
// - Type message → sends via ChatInput
// - ESC key → clears dialog selection
```

The component integrates multiple custom hooks for state management, real-time subscriptions, and chat functionality, providing a seamless AI assistant experience within the OpenFrame platform.
