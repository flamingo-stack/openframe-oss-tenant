Main page component for the Mingo AI chat interface in the OpenFrame platform, providing a complete chat experience with dialog management, real-time messaging, and AI assistance.

## Key Components

- **Dialog Management**: Uses multiple hooks (`useMingoDialogs`, `useMingoDialog`, `useMingoDialogSelection`) to handle chat dialog lifecycle
- **Real-time Chat**: Implements `useMingoChat` for message processing and `useMingoRealtimeSubscription` for live updates via NATS
- **Message Store**: Integrates `useMingoMessagesStore` for state management of active dialogs and unread counts  
- **UI Layout**: Combines `ChatSidebar` for dialog list and `ChatMessageList` + `ChatInput` for the main chat interface
- **URL State Sync**: Synchronizes active dialog with URL parameters using Next.js navigation hooks

## Usage Example

```typescript
// The component handles routing and dialog selection automatically
// URL structure: /mingo?dialogId=abc123

// Key interactions:
// - Click dialog in sidebar -> Updates URL and loads messages
// - Press Escape -> Clears active dialog from URL
// - Send message -> Processes through useMingoChat hook
// - Real-time updates -> Handled via DialogSubscription components

// SaaS tenant mode check prevents access in self-hosted mode
if (!isSaasTenantMode()) {
  return null // Redirects to /dashboard
}
```

The component features a responsive layout with a collapsible sidebar for dialog navigation and a main area displaying either the welcome screen or active chat conversation. Real-time message synchronization is handled through NATS subscriptions with proper unread count management for background dialogs.
