A Next.js page component that implements the main Mingo AI chat interface, providing a complete chat experience with dialog management, real-time messaging, and SaaS tenant mode validation.

## Key Components

- **Main Page Component** (`Mingo`) - The primary chat interface with sidebar and message area
- **Dialog Management** - Handles chat dialog selection, creation, and URL synchronization
- **Real-time Communication** - NATS subscriptions for live message updates
- **Draft Chat Mode** - Temporary chat state before creating actual dialogs
- **Message Processing** - Chat input handling and message sending logic
- **Approval System** - Message approval workflow integration
- **Keyboard Navigation** - Escape key handling for dialog navigation
