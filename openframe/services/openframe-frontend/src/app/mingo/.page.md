A Next.js page component that implements the main Mingo AI chat interface, providing a complete chat application with real-time messaging, dialog management, and AI assistant interactions.

## Key Components

- **Mingo()** - Main page component with chat sidebar and message area
- **Dialog Management** - Handles creating, selecting, and managing chat dialogs
- **Real-time Subscriptions** - NATS-based messaging with multi-topic support
- **Message Processing** - Handles sending messages and processing AI responses
- **URL State Management** - Syncs active dialog with URL parameters
- **Keyboard Navigation** - ESC key to clear dialog selection

## Usage Example

```typescript
// This is a Next.js page component - typically accessed via routing
// URL: /mingo?dialogId=abc123

// The component automatically handles:
// - Loading existing dialogs from the sidebar
// - Creating new chat dialogs
// - Real-time message updates via NATS subscriptions
// - URL synchronization with active dialog

// Key user interactions:
// 1. Click "New Chat" to create a dialog
// 2. Select dialog from sidebar to view messages
// 3. Type and send messages in the chat input
// 4. Press ESC to deselect current dialog
```

The component requires SaaS tenant mode and redirects to dashboard if not available. It integrates multiple custom hooks for chat functionality, real-time updates, and state management, providing a complete AI chat experience within the OpenFrame platform.
