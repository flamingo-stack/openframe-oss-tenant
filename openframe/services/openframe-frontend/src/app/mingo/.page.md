A Next.js client-side page component that provides the main Mingo AI chat interface, handling real-time conversations, dialog management, and message processing within the Flamingo platform.

## Key Components

- **Component**: `Mingo` - Main chat interface with sidebar and message area
- **State Management**: Multiple custom hooks for chat functionality
- **Real-time Features**: NATS subscriptions for live message updates
- **Navigation**: URL-based dialog selection with browser history support

## Usage Example

```typescript
// This is a Next.js page component that renders automatically at the /mingo route
// Key features include:

// 1. Dialog Selection
const handleDialogSelect = useCallback(async (dialogId: string) => {
  setActiveDialogId(dialogId)
  router.replace(`/mingo?dialogId=${dialogId}`)
}, [])

// 2. Message Sending
const handleSendMessage = useCallback(async (message: string) => {
  if (isDraftChat) {
    const newDialogId = await createDialog()
    await sendMessage(message, newDialogId)
  } else {
    await sendMessage(message)
  }
}, [isDraftChat, createDialog, sendMessage])

// 3. Keyboard Navigation
useEffect(() => {
  const handleKeyDown = (event: KeyboardEvent) => {
    if (event.key === 'Escape') {
      // Close current dialog or draft
    }
  }
}, [])
```

The component integrates with the Flamingo stack's core UI components and provides a full-featured chat experience with dialog persistence, real-time updates, and approval workflows for AI assistant interactions.
