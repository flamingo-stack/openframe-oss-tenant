Main page component for the Mingo AI chat interface in the Flamingo/OpenFrame platform. Provides a complete chat experience with dialog management, real-time messaging, and draft chat functionality for technical assistance.

## Key Components

- **Main Chat Interface** - Full-featured chat UI with sidebar, message list, and input
- **Dialog Management** - Handles chat dialog selection, creation, and URL synchronization
- **Real-time Messaging** - NATS subscription-based live message updates
- **Draft Chat Mode** - Allows users to start conversations before creating dialogs
- **Custom Hooks Integration** - Leverages multiple specialized hooks for chat functionality
- **Keyboard Shortcuts** - ESC key support for navigation and draft mode exit

## Usage Example

```typescript
// This is the main route component for /mingo
// Accessed through Next.js app router structure

// Key state management:
const {
  activeDialogId,
  setActiveDialogId,
  resetUnread,
  addMessage,
} = useMingoMessagesStore()

// Dialog selection with URL sync:
const handleDialogSelect = useCallback(async (dialogId: string) => {
  setActiveDialogId(dialogId)
  // Updates URL params automatically
  router.replace(`/mingo?dialogId=${dialogId}`)
}, [])

// Draft chat to dialog conversion:
const handleSendMessage = useCallback(async (message: string) => {
  if (isDraftChat) {
    const newDialogId = await createDialog()
    setActiveDialogId(newDialogId)
    // Converts draft to real dialog
  }
  await sendMessage(message)
}, [isDraftChat])
```

The component enforces SaaS tenant mode and redirects non-SaaS users to the dashboard. Features responsive design with collapsible sidebar and full-height chat interface.
