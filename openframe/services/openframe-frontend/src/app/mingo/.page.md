This React component implements the main Mingo AI chat interface page, providing a complete chat experience with real-time messaging, dialog management, and NATS-based subscriptions for live updates.

## Key Components

**Main Features:**
- **Dialog Management**: Create, select, and switch between chat dialogs with URL-based routing
- **Real-time Messaging**: NATS WebSocket subscriptions for live message streaming and typing indicators
- **Message Processing**: Handles optimistic updates, welcome messages, and assistant responses
- **Background Updates**: Manages unread counts and typing states for inactive dialogs
- **Chat Interface**: Split-pane layout with sidebar and main chat area

**Custom Hooks:**
- `useMingoDialog` - Dialog creation and message sending
- `useMingoDialogs` - Dialog list management with pagination
- `useMingoDialogSelection` - Dialog selection and loading states
- `useProcessedMessages` - Message processing and approval handling
- `useMingoRealtimeProcessor` - Real-time chunk processing for streaming responses

**Store Integration:**
- `useMingoDialogDetailsStore` - Current dialog state and typing indicators
- `useMingoBackgroundMessagesStore` - Background dialog management and unread counts

## Usage Example

```typescript
// Component is used as a Next.js page component
// URL structure: /mingo?dialogId=123

// Key interactions:
// 1. Create new dialog
await createDialog() // Returns new dialog ID

// 2. Select existing dialog
handleDialogSelect(dialogId) // Updates URL and loads dialog

// 3. Send message with optimistic updates
handleSendMessage("Hello Mingo") // Shows message immediately, streams response

// 4. Real-time subscription management
// Each dialog gets persistent NATS subscription for live updates
<DialogNatsSubscription 
  dialogId={dialogId}
  isActive={dialogId === currentDialogId}
  onChunkReceived={handleChunkReceived}
/>
```

The component enforces SaaS tenant mode and includes keyboard shortcuts (Escape to close dialog), URL synchronization, and comprehensive error handling for the chat experience.
