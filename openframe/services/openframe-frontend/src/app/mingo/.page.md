A Next.js page component that provides the main Mingo AI chat interface for SaaS tenant mode, managing dialog selection, message handling, and real-time subscriptions.

## Key Components

- **State Management**: Uses multiple custom hooks for dialog management, chat functionality, and real-time subscriptions
- **Dialog Management**: Handles dialog selection via URL parameters with `useMingoDialogs` and `useMingoDialog` hooks
- **Message Processing**: Manages chat messages and real-time updates through `useMingoChat` and `useMingoRealtimeSubscription`
- **Realtime Subscriptions**: Implements NATS subscriptions for background dialog updates and unread counts
- **Route Protection**: Enforces SaaS tenant mode requirement, redirecting to dashboard otherwise
- **UI Layout**: Combines sidebar for dialog list and main chat area with conditional message input

## Usage Example

```typescript
// This is a Next.js page component that renders automatically at /mingo
// URL structure: /mingo?dialogId=abc123

// Key URL interactions:
const currentUrl = new URL(window.location.href)
currentUrl.searchParams.set('dialogId', dialogId)
router.replace(currentUrl.pathname + currentUrl.search)

// Dialog selection with state sync:
const handleDialogSelect = useCallback(async (dialogId: string) => {
  setActiveDialogId(dialogId)
  resetUnread(dialogId)
  subscribeToDialog(dialogId)
  selectDialog(dialogId)
}, [dependencies])

// Message sending:
const handleSendMessage = useCallback(async (message: string) => {
  const success = await sendMessage(message.trim())
}, [activeDialogId, sendMessage])
```

The component features keyboard shortcuts (Escape to close dialogs), automatic unread count management for background dialogs, and a welcome screen when no dialog is selected.
