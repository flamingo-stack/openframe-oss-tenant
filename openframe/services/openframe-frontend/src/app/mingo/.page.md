A Next.js page component that implements the main Mingo AI chat interface with real-time messaging, dialog management, and NATS-based message streaming.

## Key Components

- **Dialog Management**: Handles creation, selection, and navigation of chat dialogs
- **Real-time Messaging**: Processes streaming messages via NATS subscriptions
- **State Management**: Uses Zustand stores for dialog details and background messages
- **Custom Hooks**: Integrates multiple specialized hooks for dialog operations
- **Optimistic Updates**: Provides immediate UI feedback for user messages

## Core Features

- **Multi-dialog Support**: Maintains subscriptions to multiple dialogs simultaneously
- **Background Message Handling**: Updates unread counts for non-active dialogs
- **Keyboard Navigation**: ESC key to clear dialog selection
- **Welcome Message System**: Auto-adds greeting messages to new dialogs
- **Responsive Layout**: Sidebar with dialog list and main chat area

## Usage Example

```typescript
// The component automatically handles:
// 1. URL-based dialog selection via searchParams
// 2. Real-time message streaming
// 3. Optimistic message updates
// 4. Background dialog notifications

// Key user interactions:
handleDialogSelect('dialog-123') // Switch to specific dialog
handleNewChat() // Create new dialog
handleSendMessage('Hello Mingo') // Send message with optimistic update
```

The component renders a complete chat interface with sidebar navigation and maintains persistent NATS subscriptions for real-time updates across all active dialogs.
