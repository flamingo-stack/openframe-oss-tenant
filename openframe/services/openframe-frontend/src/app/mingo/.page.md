This is the main page component for the Mingo AI chat interface, implementing a real-time chat system with dialog management, NATS messaging, and AI assistant interactions.

## Key Components

**Main Exports:**
- `Mingo` - Default export React component for the complete chat interface

**Core Functionality:**
- **Dialog Management** - Create, select, and manage chat conversations
- **Real-time Messaging** - NATS-based WebSocket communication for live updates
- **Message Processing** - Handles streaming responses and optimistic updates
- **Background Subscriptions** - Maintains connections to all active dialogs
- **URL State Management** - Syncs selected dialog with URL parameters

**Key Hooks Used:**
- `useMingoDialog` - Dialog CRUD operations
- `useMingoDialogs` - Dialog list management with pagination
- `useMingoDialogSelection` - Dialog switching and message loading
- `useProcessedMessages` - Message formatting and approval handling
- `useMingoRealtimeProcessor` - Real-time chunk processing

## Usage Example

```typescript
// This is a Next.js page component - usage through routing
// URL: /mingo?dialogId=123 (optional dialog parameter)

// The component automatically:
// 1. Redirects non-SaaS tenants to dashboard
// 2. Creates NATS subscriptions for active dialogs
// 3. Manages welcome messages for new conversations
// 4. Handles optimistic message updates

// Key user interactions:
// - ESC key: Clear dialog selection
// - New chat button: Create and select new dialog
// - Send message: Optimistic update + real-time streaming
```

The component implements a sophisticated chat interface with persistent background subscriptions, ensuring users receive real-time updates from all their conversations while maintaining smooth navigation between dialogs.
