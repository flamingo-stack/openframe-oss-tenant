This is the main Mingo AI chat interface page component that provides a comprehensive chat experience with dialog management, real-time messaging, and approval workflows.

## Key Components

- **useMingoMessagesStore** - Global state management for active dialogs and unread counts
- **useMingoDialogs** - Handles fetching and pagination of dialog list
- **useMingoDialogSelection** - Manages dialog selection and message loading
- **useMingoChat** - Core chat functionality including message processing and approvals
- **useMingoRealtimeSubscription** - WebSocket subscriptions for real-time updates
- **ChatSidebar** - Dialog list and navigation sidebar
- **ChatMessageList** - Main message display area with typing indicators
- **ChatInput** - Message composition interface
- **DialogSubscription** - Real-time NATS message subscription components

## Usage Example

```typescript
import MingoPage from './page'

// The component is automatically rendered as a Next.js page
// Handles URL state with ?dialogId parameter for deep linking
// Example URLs:
// /mingo - Shows welcome screen
// /mingo?dialogId=123 - Opens specific dialog

// Key features:
// - ESC key closes active dialog
// - Automatic unread count management
// - Real-time message synchronization
// - SaaS tenant mode validation
// - Approval workflow integration
```

The component implements a complete chat interface with sidebar navigation, real-time messaging, keyboard shortcuts, and seamless URL-based dialog routing. It includes sophisticated state management for handling multiple concurrent dialogs with unread indicators and background message processing.
