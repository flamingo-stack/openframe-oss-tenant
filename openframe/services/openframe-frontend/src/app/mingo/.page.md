Main page component for the Mingo AI chat interface that provides a conversational assistant for technical support. Handles dialog management, real-time messaging, and SaaS tenant mode routing.

## Key Components

- **Mingo()** - Main page component that renders the chat interface
- **Dialog Management** - Handles selecting, creating, and managing chat dialogs
- **Message Processing** - Processes and displays chat messages with typing indicators
- **Real-time Subscriptions** - Manages NATS subscriptions for live message updates
- **URL State Management** - Syncs active dialog with URL parameters
- **Draft Chat Mode** - Allows composing messages before creating a dialog

## Usage Example

```typescript
// This is a Next.js page component that handles routing automatically
// Access via: /mingo or /mingo?dialogId=123

// Key state management:
const {
  activeDialogId,
  setActiveDialogId,
  resetUnread,
  addMessage,
} = useMingoMessagesStore()

// Handle dialog selection:
const handleDialogSelect = useCallback(async (dialogId: string) => {
  setActiveDialogId(dialogId)
  resetUnread(dialogId)
  subscribeToDialog(dialogId)
}, [])

// Send messages in draft or existing dialogs:
const handleSendMessage = useCallback(async (message: string) => {
  if (isDraftChat) {
    const newDialogId = await createDialog()
    await sendMessage(message, newDialogId)
  } else {
    await sendMessage(message)
  }
}, [isDraftChat, activeDialogId])
```

The component requires SaaS tenant mode and redirects to dashboard if not available. It provides keyboard shortcuts (Escape to close dialogs) and maintains real-time synchronization with the message backend.
