A Next.js chat interface page for Mingo AI assistant, featuring a two-pane layout with conversation sidebar and main chat area. This component handles real-time messaging, dialog management, URL state synchronization, and provides both draft and active conversation modes.

## Key Components

- **Mingo** - Main page component with sidebar and chat interface
- **State Management** - Multiple custom hooks for dialogs, messages, chat functionality, and real-time subscriptions
- **Chat Interface** - Message list, input field, and typing indicators
- **URL Synchronization** - Dialog selection synced with browser URL parameters
- **Real-time Features** - NATS subscriptions for live message updates and approval workflows
