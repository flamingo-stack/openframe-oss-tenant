Main chat interface component for Mingo AI assistant in OpenFrame. Provides a complete chat experience with dialog management, real-time messaging, and approval workflows for AI-assisted technical support.

## Key Components

- **MingoChat** - Main page component with sidebar and chat area
- **Dialog Management** - Create, select, and navigate between chat sessions
- **Real-time Messaging** - NATS subscriptions for live chat updates
- **Message Processing** - Handles streaming responses and user approvals
- **URL State Management** - Syncs active dialog with browser URL
- **Custom Hooks Integration** - Uses specialized hooks for chat state, dialogs, and real-time updates
