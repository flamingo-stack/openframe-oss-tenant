A Next.js client page component that implements the main Mingo AI chat interface with dialog management, real-time messaging, and NATS-based subscriptions. This page handles chat dialog creation, selection, message sending, and maintains persistent connections for background updates.

## Key Components

- **Chat Layout**: Sidebar with dialog list and main chat area using `ChatSidebar` and `ChatMessageList`
- **Dialog Management**: Creates, selects, and switches between chat dialogs with URL synchronization
- **Real-time Processing**: Handles streaming message chunks via NATS subscriptions with `useMingoRealtimeProcessor`
- **State Management**: Multiple Zustand stores for dialog details and background messages
- **Message Handling**: Optimistic UI updates, welcome messages, and typing indicators
- **URL Integration**: Syncs selected dialog with URL search parameters

// Access via: /mingo?dialogId=abc123
