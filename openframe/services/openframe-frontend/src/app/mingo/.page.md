A Next.js page component that implements the Mingo AI chat interface, providing a complete chat experience with dialog management, real-time messaging, and AI assistant interactions within the OpenFrame platform.

## Key Components

- **Main Chat Interface** - Full-featured chat UI with sidebar navigation and message display
- **Dialog Management** - Create, select, and manage chat conversations with URL state synchronization
- **Real-time Messaging** - NATS-based real-time message streaming and subscription handling
- **AI Assistant Integration** - Mingo AI chat functionality with typing indicators and approval workflows
- **State Management** - Zustand store integration for messages, dialogs, and UI state
- **URL Routing** - Deep-linkable dialog selection via URL parameters

## Usage Example

```typescript
// This is a Next.js page component - no direct instantiation needed
// Access via: /mingo route in the application

// URL patterns supported:
// /mingo - Shows welcome screen
// /mingo?dialogId=123 - Opens specific dialog

// Key keyboard shortcuts:
// ESC - Close active dialog and return to welcome screen
```

The component orchestrates multiple custom hooks for chat functionality, handles SaaS tenant mode restrictions, and provides a responsive chat interface with real-time updates. It automatically subscribes to dialog events and manages unread message counts for background conversations.
