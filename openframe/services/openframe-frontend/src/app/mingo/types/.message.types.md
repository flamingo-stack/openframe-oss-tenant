TypeScript type definitions and utilities for message data structures in the OpenFrame chat system, supporting both GraphQL and core message formats.

## Key Components

- **GraphQLMessage**: Raw message data from GraphQL API with dialog context and owner information
- **CoreMessage**: Frontend-optimized message structure with role-based typing and display metadata
- **MessageConnection**: GraphQL connection pattern for paginated message queries
- **MessagesResponse**: API response wrapper for message data
- **MessagePage**: Simplified page structure for message pagination
- **Type Guards**: `isGraphQLMessage()` and `isCoreMessage()` for runtime type checking

  if (isGraphQLMessage(message)) {

    // Handle core message format
    console.log(`Role: ${message.role}, Content: ${message.content}`)
