This file defines TypeScript types and interfaces for message handling in the Flamingo/OpenFrame messaging system, providing type definitions for both GraphQL and core message formats along with pagination and response structures.

## Key Components

- **`GraphQLMessage`** - Interface for messages retrieved from GraphQL API with dialog context
- **`CoreMessage`** - Interface for frontend message representation with role-based structure
- **`Message`** - Type alias for CoreMessage (unified message type)
- **`MessageConnection`** - GraphQL connection pattern for paginated message results
- **`MessagesResponse`** - API response wrapper for message queries
- **`MessagePage`** - Simplified pagination structure for message lists
- **`isGraphQLMessage()`** - Type guard function to identify GraphQL message objects
- **`isCoreMessage()`** - Type guard function to identify core message objects

## Usage Example

```typescript
import { Message, isGraphQLMessage, isCoreMessage } from './message.types'
import type { MessageContent } from '@flamingo-stack/openframe-frontend-core'

// Create a core message
const userMessage: Message = {
  id: 'msg-123',
  role: 'user',
  content: { text: 'Hello, how can I help?' } as MessageContent,
  timestamp: new Date(),
  avatar: null
}

// Type checking with guards
function processMessage(message: unknown) {
  if (isGraphQLMessage(message)) {
    console.log('GraphQL message from dialog:', message.dialogId)
    console.log('Chat type:', message.chatType)
  } else if (isCoreMessage(message)) {
    console.log('Core message role:', message.role)
    console.log('Assistant type:', message.assistantType)
  }
}

// Handle paginated response
function handleMessagesResponse(response: MessagesResponse) {
  const { messages } = response.data
  messages.edges.forEach(edge => {
    const message = edge.node
    console.log('Processing message:', message.id)
  })
}
```
