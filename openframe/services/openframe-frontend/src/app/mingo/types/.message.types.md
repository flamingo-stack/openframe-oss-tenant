This file defines TypeScript interfaces and utility functions for handling different message formats in the OpenFrame messaging system, supporting both GraphQL-based server responses and core frontend message structures.

## Key Components

### Core Interfaces
- **`GraphQLMessage`** - Server-side message format with dialog metadata and owner information
- **`CoreMessage`** - Frontend message format with role, content, and display properties
- **`Message`** - Type alias for CoreMessage (primary message type)
- **`MessageConnection`** - GraphQL connection pattern for paginated message queries
- **`MessagesResponse`** - GraphQL response wrapper for message queries
- **`MessagePage`** - Simplified paginated message structure

### Utility Functions
- **`isGraphQLMessage()`** - Type guard to identify GraphQL message format
- **`isCoreMessage()`** - Type guard to identify core message format

## Usage Example

```typescript
import { Message, isGraphQLMessage, isCoreMessage } from './message.types'

// Handle different message formats
function processMessage(message: unknown): Message | null {
  if (isGraphQLMessage(message)) {
    // Transform GraphQL message to core format
    return {
      id: message.id,
      role: message.owner.type === 'user' ? 'user' : 'assistant',
      content: message.messageData.content,
      timestamp: new Date(message.createdAt)
    }
  }
  
  if (isCoreMessage(message)) {
    // Already in core format
    return message
  }
  
  return null
}

// Working with paginated responses
function extractMessages(response: MessagesResponse): GraphQLMessage[] {
  return response.data.messages.edges.map(edge => edge.node)
}
```
