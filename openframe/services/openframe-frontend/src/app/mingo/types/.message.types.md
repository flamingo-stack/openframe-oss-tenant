TypeScript interface definitions for message data structures used in the Flamingo Stack messaging system, providing type safety for both GraphQL responses and core message objects.

## Key Components

- **GraphQLMessage** - Interface for messages returned from GraphQL API with dialog metadata
- **CoreMessage** - Interface for processed messages with role-based structure (user/assistant/error)
- **Message** - Type alias for CoreMessage, representing the primary message format
- **MessageConnection** - GraphQL connection pattern for paginated message results
- **MessagesResponse** - Complete GraphQL response wrapper for message queries
- **MessagePage** - Simplified pagination structure for message lists
- **Type Guards** - `isGraphQLMessage()` and `isCoreMessage()` for runtime type checking

## Usage Example

```typescript
import { Message, GraphQLMessage, isGraphQLMessage } from './message.types'

// Working with core messages
const userMessage: Message = {
  id: 'msg_123',
  role: 'user',
  content: { text: 'Hello AI assistant' },
  timestamp: new Date()
}

// Type guard usage
function processMessage(message: GraphQLMessage | Message) {
  if (isGraphQLMessage(message)) {
    // Handle GraphQL message with dialog metadata
    console.log(`Dialog: ${message.dialogId}, Type: ${message.chatType}`)
  } else {
    // Handle core message
    console.log(`Role: ${message.role}, Content: ${message.content}`)
  }
}

// Pagination handling
const handleMessagesResponse = (response: MessagesResponse) => {
  const { messages, pageInfo } = response.data.messages
  return {
    messages: messages.edges.map(edge => edge.node),
    hasMore: pageInfo.hasNextPage
  }
}
```
