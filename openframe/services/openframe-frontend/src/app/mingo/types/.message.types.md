TypeScript type definitions for message data structures in the Flamingo platform, supporting both GraphQL-based backend messages and frontend core message formats with transformation utilities.

## Key Components

- **GraphQLMessage** - Backend message structure with dialog metadata and owner information
- **CoreMessage** - Frontend message format with role-based typing and content structure  
- **Message** - Type alias for CoreMessage used throughout the application
- **MessageConnection** - GraphQL connection pattern for paginated message queries
- **MessagesResponse** - API response wrapper for message connection data
- **MessagePage** - Simplified page structure for message pagination
- **Type Guards** - `isGraphQLMessage()` and `isCoreMessage()` for runtime type checking
