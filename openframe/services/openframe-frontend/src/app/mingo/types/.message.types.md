This TypeScript file defines the core message types and interfaces used throughout the chat/messaging system, including both GraphQL responses and frontend message structures.

## Key Components

### Core Interfaces
- **`GraphQLMessage`** - Server-side message format with dialog metadata and owner information
- **`CoreMessage`** - Frontend message format with role-based structure and display properties
- **`Message`** - Type alias for CoreMessage (main message type used in components)
- **`MessageConnection`** - GraphQL connection format with cursor-based pagination
- **`MessagesResponse`** - Complete GraphQL response wrapper
- **`MessagePage`** - Simplified page format for frontend state management

### Type Guards
- **`isGraphQLMessage()`** - Runtime type checking for server messages
- **`isCoreMessage()`** - Runtime type checking for frontend messages

## Usage Example

```typescript
import { Message, isGraphQLMessage, MessagePage } from './message.types'

// Transform GraphQL messages to frontend format
function transformMessages(graphqlMessages: GraphQLMessage[]): Message[] {
  return graphqlMessages.map(msg => ({
    id: msg.id,
    role: msg.owner.type === 'user' ? 'user' : 'assistant',
    content: msg.messageData.content,
    timestamp: new Date(msg.createdAt)
  }))
}

// Type-safe message handling
function handleMessage(message: unknown) {
  if (isGraphQLMessage(message)) {
    // Handle server message format
    console.log(`Dialog: ${message.dialogId}`)
  } else if (isCoreMessage(message)) {
    // Handle frontend message format
    console.log(`Role: ${message.role}`)
  }
}

// Working with paginated messages
const messagePage: MessagePage = {
  messages: [],
  pageInfo: {
    hasNextPage: true,
    hasPreviousPage: false,
    startCursor: 'cursor1',
    endCursor: 'cursor2'
  }
}
```
