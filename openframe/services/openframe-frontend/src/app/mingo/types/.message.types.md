Type definitions and utilities for message handling in the Flamingo chat system, supporting both GraphQL and core message formats with pagination.

## Key Components

- **GraphQLMessage** - Message structure from GraphQL API with dialog metadata
- **CoreMessage** - Simplified message format for UI components
- **MessageConnection** - GraphQL connection pattern for paginated messages
- **MessagesResponse** - API response wrapper for message queries
- **MessagePage** - Transformed pagination structure for frontend use
- **Type Guards** - `isGraphQLMessage()` and `isCoreMessage()` for runtime type checking

## Usage Example

```typescript
import type { Message, GraphQLMessage, MessagePage } from './message.types'
import { isGraphQLMessage, isCoreMessage } from './message.types'

// Handle different message types
function processMessage(message: GraphQLMessage | Message) {
  if (isGraphQLMessage(message)) {
    console.log(`GraphQL message from ${message.owner.type}`)
    return message.messageData
  }
  
  if (isCoreMessage(message)) {
    console.log(`Core message: ${message.role}`)
    return message.content
  }
}

// Transform GraphQL response to page format
function transformToPage(response: MessagesResponse): MessagePage {
  return {
    messages: response.data.messages.edges.map(edge => edge.node),
    pageInfo: response.data.messages.pageInfo
  }
}

// Create core message for UI
const userMessage: Message = {
  id: '123',
  role: 'user',
  content: { text: 'Hello Mingo!' },
  timestamp: new Date()
}
```

The types support Flamingo's dual-format messaging system where GraphQL messages from the backend are transformed into CoreMessage format for consistent UI rendering, with built-in pagination support for chat history.
