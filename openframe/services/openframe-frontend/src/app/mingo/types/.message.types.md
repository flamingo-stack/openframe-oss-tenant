Defines TypeScript interfaces and type guards for message data structures used in the Flamingo chat system, bridging GraphQL responses and frontend message formats.

## Key Components

- **GraphQLMessage**: Server-side message format with dialog metadata and owner information
- **CoreMessage**: Frontend message format with role-based structure and content data
- **MessageConnection**: GraphQL connection pattern for paginated message lists
- **MessagesResponse**: Complete GraphQL response wrapper for message queries
- **MessagePage**: Simplified pagination structure for frontend consumption
- **Type Guards**: `isGraphQLMessage()` and `isCoreMessage()` for runtime type checking

## Usage Example

```typescript
import { Message, isGraphQLMessage, isCoreMessage } from './message.types'

// Handle messages from different sources
function processMessage(message: unknown) {
  if (isGraphQLMessage(message)) {
    // Handle GraphQL message from server
    console.log(`Message ${message.id} from ${message.owner.type}`)
    return transformToCore(message)
  }
  
  if (isCoreMessage(message)) {
    // Handle frontend message format
    console.log(`${message.role}: ${message.content}`)
    return message
  }
}

// Create a new core message
const userMessage: Message = {
  id: 'msg-123',
  role: 'user',
  content: 'Hello, how can I help?',
  timestamp: new Date(),
  avatar: null
}
```

The type system ensures proper handling of messages throughout the chat pipeline, from GraphQL queries to UI rendering, with clear separation between server and client data formats.
