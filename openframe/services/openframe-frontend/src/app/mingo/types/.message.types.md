Defines TypeScript type definitions for message handling across GraphQL and core message systems in the Flamingo chat interface.

## Key Components

- **GraphQLMessage** - Server-side message format with dialog context and owner metadata
- **CoreMessage** - Frontend message format with role-based content and assistant typing
- **Message** - Type alias for CoreMessage (primary message interface)
- **MessageConnection** - GraphQL connection pattern for paginated message queries
- **MessagesResponse** - API response wrapper for message connections
- **MessagePage** - Simplified paginated message container
- **Type Guards** - `isGraphQLMessage()` and `isCoreMessage()` for runtime type checking

## Usage Example

```typescript
import { Message, isGraphQLMessage, MessageConnection } from './message.types'
import { MessageContent } from '@flamingo-stack/openframe-frontend-core'

// Creating a user message
const userMessage: Message = {
  id: 'msg-123',
  role: 'user',
  content: { text: 'Hello, how can you help me?' },
  timestamp: new Date()
}

// Creating an assistant message
const assistantMessage: Message = {
  id: 'msg-124',
  role: 'assistant',
  content: { text: 'I can help you with IT support tasks!' },
  assistantType: 'mingo',
  avatar: '/avatars/mingo.png',
  timestamp: new Date()
}

// Type checking messages
function processMessage(message: unknown) {
  if (isGraphQLMessage(message)) {
    // Handle server message format
    console.log(`Dialog: ${message.dialogId}, Owner: ${message.owner.type}`)
  } else if (isCoreMessage(message)) {
    // Handle frontend message format
    console.log(`Role: ${message.role}, Content: ${message.content}`)
  }
}
```
