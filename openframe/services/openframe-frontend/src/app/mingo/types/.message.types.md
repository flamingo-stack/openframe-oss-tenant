This TypeScript file defines type interfaces and utilities for handling different message formats in the Flamingo platform's chat system, supporting both GraphQL API responses and internal core message structures.

## Key Components

### Core Interfaces
- **`GraphQLMessage`** - Message format from GraphQL API responses with dialog metadata
- **`CoreMessage`** - Internal message format with role-based structure (user/assistant/error)
- **`Message`** - Type alias for CoreMessage used throughout the application
- **`MessageConnection`** - GraphQL connection pattern for paginated message queries
- **`MessagesResponse`** - Top-level response wrapper for GraphQL message queries
- **`MessagePage`** - Simplified page structure for message pagination

### Type Guards
- **`isGraphQLMessage()`** - Runtime check to identify GraphQL message objects
- **`isCoreMessage()`** - Runtime check to identify core message objects

## Usage Example

```typescript
import { Message, isGraphQLMessage, isCoreMessage } from './message.types'

// Handle different message formats
function processMessage(message: unknown): Message | null {
  if (isGraphQLMessage(message)) {
    // Convert GraphQL message to core format
    return {
      id: message.id,
      role: message.owner.type === 'user' ? 'user' : 'assistant',
      content: message.messageData,
      timestamp: new Date(message.createdAt)
    }
  }
  
  if (isCoreMessage(message)) {
    // Already in core format
    return message
  }
  
  return null
}

// Working with paginated messages
function handleMessagesResponse(response: MessagesResponse) {
  const { messages, pageInfo } = response.data.messages
  
  return {
    messages: messages.edges.map(edge => edge.node),
    hasMore: pageInfo.hasNextPage,
    cursor: pageInfo.endCursor
  }
}
```
