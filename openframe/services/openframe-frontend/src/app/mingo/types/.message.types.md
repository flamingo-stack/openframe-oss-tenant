This file defines TypeScript interfaces and type guards for message handling in the Flamingo OpenFrame platform, supporting both GraphQL API responses and core application message formats.

## Key Components

### Main Interfaces
- **`GraphQLMessage`** - Raw message format from GraphQL API with dialog context and ownership metadata
- **`CoreMessage`** - Application-level message format with role-based typing and assistant integration
- **`MessageConnection`** - GraphQL connection pattern for paginated message queries
- **`MessagesResponse`** - Top-level GraphQL response wrapper for message queries
- **`MessagePage`** - Simplified pagination structure for processed messages

### Type Guards
- **`isGraphQLMessage()`** - Runtime type checking for GraphQL message format
- **`isCoreMessage()`** - Runtime type checking for core application message format

### Type Aliases
- **`Message`** - Currently aliased to `CoreMessage` for application use

## Usage Example

```typescript
import { Message, isGraphQLMessage, isCoreMessage } from './message.types'

// Type guard usage for message processing
function processMessage(message: unknown): Message | null {
  if (isGraphQLMessage(message)) {
    // Convert GraphQL format to core format
    return {
      id: message.id,
      role: message.owner.type === 'user' ? 'user' : 'assistant',
      content: message.messageData.content,
      timestamp: new Date(message.createdAt)
    }
  }
  
  if (isCoreMessage(message)) {
    // Already in core format
    return message
  }
  
  return null
}

// Working with paginated message responses
function handleMessagesResponse(response: MessagesResponse) {
  const { messages } = response.data
  
  return {
    messages: messages.edges.map(edge => edge.node),
    hasMore: messages.pageInfo.hasNextPage
  }
}
```
