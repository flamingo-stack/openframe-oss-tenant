Type definitions and utilities for managing messages in the Flamingo chat system, supporting both GraphQL API responses and frontend core message formats.

## Key Components

- **GraphQLMessage**: Interface for messages retrieved from the GraphQL API, containing dialog metadata and raw message data
- **CoreMessage**: Simplified frontend message format with role-based typing and content structure
- **MessageConnection**: GraphQL relay-style pagination wrapper for message collections
- **MessagesResponse**: Complete API response structure for message queries
- **MessagePage**: Processed page of messages with pagination info
- **Type Guards**: `isGraphQLMessage()` and `isCoreMessage()` utilities for runtime type checking

## Usage Example

```typescript
import { CoreMessage, GraphQLMessage, isGraphQLMessage } from './message.types'

// Creating a core message for the frontend
const userMessage: CoreMessage = {
  id: 'msg-123',
  role: 'user',
  content: { text: 'Hello, how can I help?' },
  timestamp: new Date(),
  assistantType: 'mingo'
}

// Type guard usage for message processing
function processMessage(message: GraphQLMessage | CoreMessage) {
  if (isGraphQLMessage(message)) {
    // Handle GraphQL format
    return transformGraphQLMessage(message)
  } else {
    // Handle core message format
    return message
  }
}

// Working with paginated messages
function handleMessagesResponse(response: MessagesResponse) {
  const { messages, pageInfo } = response.data.messages
  const messageList = messages.edges.map(edge => edge.node)
  
  return {
    messages: messageList,
    hasMore: pageInfo.hasNextPage
  }
}
```
