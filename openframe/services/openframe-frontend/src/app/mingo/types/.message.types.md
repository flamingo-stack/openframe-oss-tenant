TypeScript interface definitions and type guards for message handling in the OpenFrame chat system, providing type safety for both GraphQL responses and core message objects.

## Key Components

- **`GraphQLMessage`** - Interface for messages received from GraphQL API with dialog context and metadata
- **`CoreMessage`** - Simplified message interface used internally with role-based typing
- **`MessageConnection`** - GraphQL connection pattern for paginated message queries
- **`MessagesResponse`** - Response wrapper for GraphQL message queries
- **`MessagePage`** - Processed page of messages with pagination metadata
- **`isGraphQLMessage()`** - Type guard to differentiate GraphQL messages from core messages
- **`isCoreMessage()`** - Type guard to identify core message objects

## Usage Example

```typescript
import { CoreMessage, GraphQLMessage, isGraphQLMessage, isCoreMessage } from './message.types'

// Creating a core message
const userMessage: CoreMessage = {
  id: 'msg-123',
  role: 'user',
  content: { text: 'Hello, how can I help?' },
  timestamp: new Date(),
  assistantType: 'mingo'
}

// Type guarding messages
function processMessage(message: unknown) {
  if (isGraphQLMessage(message)) {
    // Handle GraphQL message with full metadata
    console.log(`Dialog ${message.dialogId}: ${message.chatType}`)
  } else if (isCoreMessage(message)) {
    // Handle simplified core message
    console.log(`${message.role}: ${message.content}`)
  }
}

// Working with paginated responses
const response: MessagesResponse = await fetchMessages()
const page: MessagePage = {
  messages: response.data.messages.edges.map(edge => edge.node),
  pageInfo: response.data.messages.pageInfo
}
```
