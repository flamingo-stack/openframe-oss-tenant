TypeScript type definitions for message data structures in the Flamingo platform's chat and dialog system, supporting both GraphQL and core message formats.

## Key Components

- **GraphQLMessage** - Message format returned from GraphQL API with metadata like dialog ID, chat type, and owner information
- **CoreMessage** - Simplified message format used in the frontend with role-based structure (user/assistant/error)
- **MessageConnection** - GraphQL connection pattern for paginated message queries with cursor-based pagination
- **MessagesResponse** - Wrapper type for GraphQL query responses containing message connections
- **MessagePage** - Processed page of messages with extracted pagination info
- **Type Guards** - `isGraphQLMessage()` and `isCoreMessage()` functions for runtime type checking

## Usage Example

```typescript
import { GraphQLMessage, CoreMessage, isGraphQLMessage } from './message.types'

// Process messages from GraphQL response
function processMessage(message: GraphQLMessage | CoreMessage) {
  if (isGraphQLMessage(message)) {
    // Handle GraphQL format with dialogId, chatType, etc.
    console.log(`Dialog: ${message.dialogId}, Type: ${message.chatType}`)
    return transformToCore(message)
  } else {
    // Handle core format with role and content
    console.log(`Role: ${message.role}, Content: ${message.content}`)
    return message
  }
}

// Working with paginated responses
function handleMessagesResponse(response: MessagesResponse) {
  const { messages, pageInfo } = response.data.messages
  
  if (pageInfo.hasNextPage) {
    // Load more messages using endCursor
    loadMoreMessages(pageInfo.endCursor)
  }
}
```
