This file defines TypeScript interfaces and type guards for message handling in the Flamingo OpenFrame platform, providing type safety for both GraphQL API responses and core application message structures.

## Key Components

- **GraphQLMessage** - Interface for messages from the GraphQL API with dialog context and metadata
- **CoreMessage** - Interface for processed messages used throughout the application core
- **MessageConnection** - GraphQL connection pattern with edges and pagination info
- **MessagesResponse** - Complete GraphQL query response wrapper
- **MessagePage** - Simplified pagination structure for message lists
- **Type Guards** - `isGraphQLMessage()` and `isCoreMessage()` for runtime type checking
