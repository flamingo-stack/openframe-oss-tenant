TypeScript type definitions and utility functions for handling messages in both GraphQL and core chat interfaces.

## Key Components

### Types
- **`GraphQLMessage`** - Server-side message structure with dialog metadata, chat type, and owner information
- **`CoreMessage`** - Client-side message format with role, content, and optional assistant details
- **`Message`** - Type alias for CoreMessage (current standard)
- **`MessageConnection`** - GraphQL connection wrapper with cursor-based pagination
- **`MessagesResponse`** - Complete GraphQL response structure
- **`MessagePage`** - Processed page of messages with pagination info

### Type Guards
- **`isGraphQLMessage()`** - Runtime type checking for GraphQL message format
- **`isCoreMessage()`** - Runtime type checking for core message format
