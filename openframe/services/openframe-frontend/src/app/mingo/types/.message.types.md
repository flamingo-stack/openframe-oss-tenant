Type definitions for message data structures used in chat and dialog systems within the OpenFrame platform.

## Key Components

### Core Interfaces
- **`GraphQLMessage`** - Raw message structure from GraphQL API with dialog metadata
- **`CoreMessage`** - Standardized message format for UI components with role-based typing
- **`Message`** - Type alias for CoreMessage (current standard)
- **`MessageConnection`** - GraphQL connection pattern for paginated message queries
- **`MessagesResponse`** - API response wrapper for message connections
- **`MessagePage`** - Simplified page structure for message pagination

### Type Guards
- **`isGraphQLMessage()`** - Runtime type checking for GraphQL message format
- **`isCoreMessage()`** - Runtime type checking for Core message format

## Usage Example

```typescript
import { Message, isGraphQLMessage, isCoreMessage } from './message.types'
import { MessageContent } from '@flamingo-stack/openframe-frontend-core'

// Creating a core message for chat UI
const userMessage: Message = {
  id: 'msg-123',
  role: 'user',
  content: { text: 'Hello, I need help with my server' },
  timestamp: new Date(),
  avatar: 'https://example.com/avatar.jpg'
}

// Type-safe message processing
function processMessage(message: unknown) {
  if (isGraphQLMessage(message)) {
    // Handle raw GraphQL data
    console.log(`Dialog ${message.dialogId}: ${message.chatType}`)
  } else if (isCoreMessage(message)) {
    // Handle UI-ready message
    console.log(`${message.role}: ${message.content}`)
  }
}
```

The types support both GraphQL API responses and standardized UI message formats, with pagination support for chat history and type guards for runtime validation.
