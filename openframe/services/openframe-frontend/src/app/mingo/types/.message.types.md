TypeScript type definitions and utilities for message handling in the Flamingo/OpenFrame chat system, providing interfaces for both GraphQL API responses and client-side message representation.

## Key Components

- **GraphQLMessage** - Interface for messages from the GraphQL API with metadata like dialog ID, chat type, and owner information
- **CoreMessage** - Simplified client-side message interface with role, content, and optional assistant metadata
- **MessageConnection** - GraphQL connection pattern interface for paginated message queries
- **MessagesResponse** - Wrapper for GraphQL message query responses
- **MessagePage** - Processed message page data with extracted messages and pagination info
- **Type Guards** - `isGraphQLMessage()` and `isCoreMessage()` functions for runtime type checking

## Usage Example

```typescript
import { GraphQLMessage, CoreMessage, isGraphQLMessage } from './message.types'

// Type-safe message handling
function processMessage(message: GraphQLMessage | CoreMessage) {
  if (isGraphQLMessage(message)) {
    // Handle GraphQL message with full metadata
    console.log(`Message from ${message.owner.type} in dialog ${message.dialogId}`)
    return transformToCore(message)
  } else {
    // Handle core message for UI rendering
    return message
  }
}

// Pagination handling
function handleMessagePage(response: MessagesResponse) {
  const { messages, pageInfo } = response.data.messages
  
  return {
    messages: messages.edges.map(edge => edge.node),
    hasMore: pageInfo.hasNextPage,
    cursor: pageInfo.endCursor
  }
}
```
