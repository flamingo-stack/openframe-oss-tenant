TypeScript type definitions and utilities for handling messages in both GraphQL and Core message formats within the Flamingo platform's chat system.

## Key Components

### Interface Definitions
- **`GraphQLMessage`** - Message format from GraphQL API with dialog context and metadata
- **`CoreMessage`** - Simplified message format for UI components with role-based structure
- **`Message`** - Type alias for CoreMessage (primary message type)
- **`MessageConnection`** - GraphQL connection pattern for paginated message queries
- **`MessagesResponse`** - API response wrapper for message queries
- **`MessagePage`** - Processed page of messages with pagination info

### Type Guards
- **`isGraphQLMessage()`** - Runtime type checking for GraphQL message format
- **`isCoreMessage()`** - Runtime type checking for Core message format

### External Dependencies
Imports `ChatType`, `OwnerType` from tickets module and `MessageContent`, `AssistantType` from OpenFrame core library.

## Usage Example

```typescript
import type { Message, GraphQLMessage } from './message.types'
import { isGraphQLMessage, isCoreMessage } from './message.types'

// Type-safe message handling
function processMessage(message: Message | GraphQLMessage) {
  if (isGraphQLMessage(message)) {
    // Handle GraphQL format
    console.log(`Dialog: ${message.dialogId}, Type: ${message.chatType}`)
    return message.messageData
  }
  
  if (isCoreMessage(message)) {
    // Handle Core format
    console.log(`Role: ${message.role}, Content: ${message.content}`)
    return message.content
  }
}

// Creating a Core message
const userMessage: Message = {
  id: 'msg-123',
  role: 'user',
  content: { text: 'Hello Mingo!' },
  timestamp: new Date(),
  avatar: null
}
```
