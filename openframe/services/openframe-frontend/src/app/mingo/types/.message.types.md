This TypeScript file defines the core message types and type guards for the Flamingo OpenFrame chat system, supporting both GraphQL and core message formats with pagination capabilities.

## Key Components

### **Core Types**
- `GraphQLMessage` - Server-side message format with dialog metadata and owner information
- `CoreMessage` - Client-side message format with role-based content and assistant details
- `Message` - Type alias for CoreMessage (main message type used throughout the app)

### **Pagination Types**
- `MessageConnection` - GraphQL connection pattern for paginated message queries
- `MessagesResponse` - Complete GraphQL response wrapper for message queries
- `MessagePage` - Simplified pagination format for client-side message handling

### **Type Guards**
- `isGraphQLMessage()` - Runtime type checking for GraphQL message format
- `isCoreMessage()` - Runtime type checking for core message format

## Usage Example

```typescript
import { Message, isGraphQLMessage, MessagePage } from './message.types'

// Creating a core message
const userMessage: Message = {
  id: 'msg-123',
  role: 'user',
  content: { type: 'text', text: 'Hello, Mingo!' },
  timestamp: new Date(),
  avatar: '/user-avatar.png'
}

// Type guard usage
function processMessage(message: unknown) {
  if (isGraphQLMessage(message)) {
    console.log('GraphQL message from dialog:', message.dialogId)
    return message.messageData
  } else if (isCoreMessage(message)) {
    console.log('Core message with role:', message.role)
    return message.content
  }
}

// Working with paginated messages
const messagePage: MessagePage = {
  messages: [/* GraphQL messages */],
  pageInfo: {
    hasNextPage: true,
    hasPreviousPage: false,
    endCursor: 'cursor-123'
  }
}
```
