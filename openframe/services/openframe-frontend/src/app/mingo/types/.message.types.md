Defines TypeScript interfaces and type guards for managing chat messages in Flamingo's MSP platform, supporting both GraphQL and core message formats.

## Key Components

- **GraphQLMessage** - Server-side message format with dialog metadata and owner information
- **CoreMessage** - Client-side message format with role-based content and assistant types
- **MessageConnection** - GraphQL connection pattern for paginated message queries
- **MessagesResponse** - API response wrapper for message data
- **MessagePage** - Simplified pagination structure for message lists
- **Type Guards** - Runtime type checking functions for message discrimination

## Usage Example

```typescript
import { GraphQLMessage, CoreMessage, isGraphQLMessage } from './message.types'

// Handle different message formats
function processMessage(message: GraphQLMessage | CoreMessage) {
  if (isGraphQLMessage(message)) {
    // Handle server format
    console.log(`Dialog ${message.dialogId}: ${message.chatType}`)
    return message.messageData
  } else {
    // Handle client format
    console.log(`${message.role}: ${message.content}`)
    return message.content
  }
}

// Paginated message handling
function loadMessages(response: MessagesResponse) {
  const { messages, pageInfo } = response.data.messages
  
  return {
    items: messages.edges.map(edge => edge.node),
    hasMore: pageInfo.hasNextPage,
    cursor: pageInfo.endCursor
  }
}
```

The types support Flamingo's chat system integration with Mingo AI (technician assistant) and Fae (client assistant), enabling seamless message handling across different contexts and formats.
