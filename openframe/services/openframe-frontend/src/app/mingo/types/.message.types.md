TypeScript type definitions and utilities for handling messages in the Flamingo platform's chat system, providing interfaces for both GraphQL API responses and core application message formats.

## Key Components

- **`GraphQLMessage`** - Interface for messages received from GraphQL API with dialog metadata
- **`CoreMessage`** - Interface for normalized messages used in the application UI
- **`MessageConnection`** - GraphQL connection pattern interface for paginated message queries
- **`MessagesResponse`** - Complete GraphQL response wrapper for message queries
- **`MessagePage`** - Simplified pagination interface for processed messages
- **`isGraphQLMessage()`** - Type guard function to identify GraphQL message format
- **`isCoreMessage()`** - Type guard function to identify core message format

    // Handle GraphQL format
    console.log(`Dialog: ${message.dialogId}, Chat Type: ${message.chatType}`)
