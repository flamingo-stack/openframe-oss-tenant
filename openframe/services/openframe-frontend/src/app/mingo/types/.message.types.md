Core TypeScript definitions for message handling in the Flamingo chat system, providing interfaces for both GraphQL API responses and frontend message representation.

## Key Components

- **`GraphQLMessage`** - Interface for messages received from GraphQL API with dialog context and owner information
- **`CoreMessage`** - Frontend message format with role-based typing (user/assistant/error) and content structure
- **`MessageConnection`** - GraphQL connection pattern for paginated message results with cursor-based navigation
- **`MessagesResponse`** - Top-level GraphQL query response wrapper
- **`MessagePage`** - Simplified pagination interface for frontend state management
- **Type Guards** - Runtime type checking utilities (`isGraphQLMessage`, `isCoreMessage`)

## Usage Example

```typescript
import { GraphQLMessage, CoreMessage, isGraphQLMessage } from './message.types'

// Transform GraphQL message to frontend format
function transformMessage(gqlMessage: GraphQLMessage): CoreMessage {
  return {
    id: gqlMessage.id,
    role: gqlMessage.owner.type === 'USER' ? 'user' : 'assistant',
    content: gqlMessage.messageData.content,
    timestamp: new Date(gqlMessage.createdAt),
    assistantType: gqlMessage.owner.model as AssistantType
  }
}

// Type-safe message processing
function processMessage(message: unknown) {
  if (isGraphQLMessage(message)) {
    // Handle GraphQL format
    return transformMessage(message)
  } else if (isCoreMessage(message)) {
    // Already in frontend format
    return message
  }
  throw new Error('Invalid message format')
}
```
