TypeScript type definitions for messaging functionality in the OpenFrame platform, providing interfaces for both GraphQL API responses and core application message structures.

## Key Components

- **GraphQLMessage** - Server-side message structure with dialog context and owner information
- **CoreMessage** - Client-side message structure with role-based content and metadata
- **MessageConnection** - GraphQL connection pattern for paginated message lists
- **MessagesResponse** - API response wrapper for message queries
- **MessagePage** - Simplified pagination structure for message collections
- **Type Guards** - `isGraphQLMessage()` and `isCoreMessage()` for runtime type checking

## Usage Example

```typescript
import { type Message, isGraphQLMessage, isCoreMessage } from './message.types'

// Working with different message types
function processMessage(message: GraphQLMessage | CoreMessage) {
  if (isGraphQLMessage(message)) {
    // Handle GraphQL message from API
    console.log(`Dialog: ${message.dialogId}, Type: ${message.chatType}`)
    return transformToCore(message)
  } else if (isCoreMessage(message)) {
    // Handle core message in UI
    console.log(`Role: ${message.role}, Content: ${message.content}`)
    return renderMessage(message)
  }
}

// Creating a core message
const userMessage: Message = {
  id: '123',
  role: 'user',
  content: 'Hello, how can I help?',
  timestamp: new Date(),
  assistantType: 'mingo'
}
```

The module bridges the gap between GraphQL API responses and the application's internal message representation, with type guards enabling safe runtime type checking and transformation between formats.
