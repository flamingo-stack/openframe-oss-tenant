Defines TypeScript interfaces and type guards for message handling in the Flamingo chat system, supporting both GraphQL and core message formats with pagination.

## Key Components

- **`GraphQLMessage`** - Interface for messages from GraphQL API with dialog metadata and owner information
- **`CoreMessage`** - Simplified message interface for frontend components with role-based structure
- **`Message`** - Type alias for CoreMessage (current default message type)
- **`MessageConnection`** - GraphQL connection pattern for paginated message lists with cursors
- **`MessagesResponse`** - Wrapper for GraphQL query responses containing message connections
- **`MessagePage`** - Simplified pagination structure for processed message data
- **`isGraphQLMessage()`** - Type guard function to identify GraphQL message objects
- **`isCoreMessage()`** - Type guard function to identify core message objects

## Usage Example

```typescript
import { Message, isGraphQLMessage, isCoreMessage } from './message.types'

// Type guard usage for message processing
function processMessage(message: unknown) {
  if (isGraphQLMessage(message)) {
    console.log(`GraphQL message from ${message.owner.type}:`, message.messageData)
    return transformToCore(message)
  }
  
  if (isCoreMessage(message)) {
    console.log(`Core message (${message.role}):`, message.content)
    return message
  }
  
  throw new Error('Unknown message format')
}

// Working with paginated messages
function handleMessagesResponse(response: MessagesResponse) {
  const { messages, pageInfo } = response.data.messages
  
  return {
    messages: messages.edges.map(edge => edge.node),
    hasMore: pageInfo.hasNextPage,
    cursor: pageInfo.endCursor
  }
}
```
