TypeScript type definitions and utilities for handling message data structures in the Flamingo Stack messaging system, supporting both GraphQL responses and core message formats.

## Key Components

- **`GraphQLMessage`** - Interface for messages returned from GraphQL API with dialog metadata
- **`CoreMessage`** - Simplified message structure for frontend components with role-based content
- **`Message`** - Type alias for CoreMessage (main message type used in UI)
- **`MessageConnection`** - GraphQL connection pattern with cursor-based pagination
- **`MessagesResponse`** - Complete GraphQL response wrapper for message queries
- **`MessagePage`** - Processed page of messages with pagination info
- **Type Guards** - `isGraphQLMessage()` and `isCoreMessage()` for runtime type checking

## Usage Example

```typescript
import type { Message, GraphQLMessage } from './message.types'
import { isGraphQLMessage, isCoreMessage } from './message.types'

// Working with core messages in UI components
const displayMessage: Message = {
  id: 'msg-123',
  role: 'assistant',
  content: { text: 'Hello! How can I help?' },
  assistantType: 'mingo',
  timestamp: new Date(),
  avatar: '/avatars/mingo.png'
}

// Type checking messages from different sources
function processMessage(msg: GraphQLMessage | Message) {
  if (isGraphQLMessage(msg)) {
    // Handle GraphQL format with dialog metadata
    console.log(`Dialog: ${msg.dialogId}, Chat: ${msg.chatType}`)
  } else if (isCoreMessage(msg)) {
    // Handle UI format with content
    console.log(`Role: ${msg.role}, Content: ${msg.content}`)
  }
}
```
