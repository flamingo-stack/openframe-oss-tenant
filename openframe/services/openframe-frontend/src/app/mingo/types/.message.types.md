This file defines TypeScript interfaces and utility functions for message handling in the OpenFrame messaging system, providing type definitions for both GraphQL responses and core message structures.

## Key Components

**Main Interfaces:**
- `GraphQLMessage` - Server-side message structure with dialog context and owner metadata
- `CoreMessage` - Frontend message structure with role-based content and assistant information
- `MessageConnection` - GraphQL connection pattern for paginated message queries
- `MessagesResponse` - Complete GraphQL query response wrapper
- `MessagePage` - Transformed message page structure for frontend consumption

**Type Guards:**
- `isGraphQLMessage()` - Runtime type checking for GraphQL message objects
- `isCoreMessage()` - Runtime type checking for core message objects

**Type Aliases:**
- `Message` - Currently aliases to `CoreMessage` for simplified usage

## Usage Example

```typescript
import { Message, isGraphQLMessage, isCoreMessage } from './message.types'

// Type-safe message handling
function processMessage(message: unknown) {
  if (isGraphQLMessage(message)) {
    // Handle server message with dialog context
    console.log(`Message ${message.id} in dialog ${message.dialogId}`)
    return transformToCore(message)
  }
  
  if (isCoreMessage(message)) {
    // Handle frontend message
    console.log(`${message.role}: ${message.content}`)
    return message
  }
  
  throw new Error('Invalid message format')
}

// Working with paginated messages
function handleMessagesResponse(response: MessagesResponse) {
  const { messages, pageInfo } = response.data.messages
  
  return {
    messages: messages.edges.map(edge => edge.node),
    hasMore: pageInfo.hasNextPage,
    cursor: pageInfo.endCursor
  }
}
```
