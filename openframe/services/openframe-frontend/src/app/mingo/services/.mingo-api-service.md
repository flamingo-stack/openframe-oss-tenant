API service class that provides React Query mutations for Mingo AI chat operations including dialog management, messaging, and approval workflows.

## Key Components

- **MingoApiService** - Static service class with mutation factory methods
- **createDialogMutation()** - Creates new admin chat dialogs
- **sendMessageMutation()** - Sends messages to existing dialogs
- **approveRequestMutation()** - Approves pending requests with toast notifications
- **rejectRequestMutation()** - Rejects pending requests with toast notifications
- **TypeScript interfaces** - Request/response types for API operations

## Usage Example

```typescript
import { MingoApiService } from '@/services/mingo-api-service'

// In a React component
function ChatComponent() {
  const createDialog = MingoApiService.createDialogMutation()
  const sendMessage = MingoApiService.sendMessageMutation()
  const approveRequest = MingoApiService.approveRequestMutation()

  const handleStartChat = async () => {
    const dialog = await createDialog.mutateAsync()
    console.log('Dialog created:', dialog.id)
    
    await sendMessage.mutateAsync({
      dialogId: dialog.id,
      content: 'Hello, I need help with server configuration'
    })
  }

  const handleApproval = (requestId: string) => {
    approveRequest.mutate(requestId) // Auto-shows success/error toast
  }

  return (
    <div>
      <button onClick={handleStartChat}>Start New Chat</button>
      <button onClick={() => handleApproval('req-123')}>Approve Request</button>
    </div>
  )
}
```

The service uses the centralized `apiClient` for HTTP operations and integrates with React Query for state management and the OpenFrame toast system for user feedback.
