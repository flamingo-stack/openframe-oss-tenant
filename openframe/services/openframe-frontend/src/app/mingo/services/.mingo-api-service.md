A comprehensive API service for Mingo AI technician chat operations, providing React Query mutations for dialog management, messaging, and approval workflows within the Flamingo MSP platform.

## Key Components

### TypeScript Interfaces
- **`CreateDialogResponse`** - Response structure for new dialog creation
- **`SendMessageResponse`** - Response structure for message sending
- **`ApprovalResponse`** - Response structure for approval/rejection actions
- **`CreateDialogRequest`** - Request payload for dialog creation
- **`SendMessageRequest`** - Request payload for message sending

### MingoApiService Class
- **`createDialogMutation()`** - Creates new ADMIN type dialogs for Mingo AI interactions
- **`sendMessageMutation()`** - Sends messages to existing dialogs with ADMIN_AI_CHAT type
- **`approveRequestMutation()`** - Approves pending approval requests with toast notifications
- **`rejectRequestMutation()`** - Rejects approval requests with error handling and user feedback

## Usage Example

```typescript
import { MingoApiService } from './mingo-api-service'

function MingoChatComponent() {
  // Initialize mutations
  const createDialog = MingoApiService.createDialogMutation()
  const sendMessage = MingoApiService.sendMessageMutation()
  const approveRequest = MingoApiService.approveRequestMutation()

  const handleStartChat = async () => {
    try {
      // Create new dialog
      const dialog = await createDialog.mutateAsync()
      
      // Send initial message
      await sendMessage.mutateAsync({
        dialogId: dialog.id,
        content: "Hello Mingo, I need help with server monitoring"
      })
    } catch (error) {
      console.error('Failed to start chat:', error)
    }
  }

  const handleApproval = async (requestId: string) => {
    await approveRequest.mutateAsync(requestId)
  }

  return (
    <div>
      <button onClick={handleStartChat}>Start Mingo Chat</button>
      <button onClick={() => handleApproval('req-123')}>Approve Request</button>
    </div>
  )
}
```

The service integrates with the centralized `apiClient` and provides built-in error handling, toast notifications for approval operations, and proper TypeScript typing for all API interactions.
