API service class for Mingo AI chat operations, providing React Query mutations for dialog management, messaging, and approval workflows within the Flamingo/OpenFrame platform.

## Key Components

**Interfaces:**
- `CreateDialogResponse` - Response structure for new dialog creation
- `SendMessageResponse` - Response for message sending operations
- `ApprovalResponse` - Response for approval/rejection requests
- `CreateDialogRequest` - Request payload for dialog creation
- `SendMessageRequest` - Request payload for message sending

**Main Class:**
- `MingoApiService` - Static service class with mutation factory methods
- `createDialogMutation()` - Creates new ADMIN agent dialogs
- `sendMessageMutation()` - Sends messages to existing dialogs
- `approveRequestMutation()` - Approves approval requests with toast notifications
- `rejectRequestMutation()` - Rejects approval requests with error handling

## Usage Example

```typescript
import { MingoApiService } from './mingo-api-service'

function ChatComponent() {
  const createDialog = MingoApiService.createDialogMutation()
  const sendMessage = MingoApiService.sendMessageMutation()
  const approveRequest = MingoApiService.approveRequestMutation()

  const handleCreateDialog = async () => {
    const dialog = await createDialog.mutateAsync()
    console.log('Dialog created:', dialog.id)
  }

  const handleSendMessage = async (dialogId: string) => {
    await sendMessage.mutateAsync({
      dialogId,
      content: 'Hello Mingo AI'
    })
  }

  const handleApprove = async (requestId: string) => {
    await approveRequest.mutateAsync(requestId)
  }

  return (
    <div>
      <button onClick={handleCreateDialog}>Create Dialog</button>
      <button onClick={() => handleSendMessage('dialog-id')}>Send Message</button>
      <button onClick={() => handleApprove('request-id')}>Approve Request</button>
    </div>
  )
}
```
