API service for Mingo AI chat operations, providing React Query mutations for dialog management, message sending, and approval workflows with integrated error handling and toast notifications.

## Key Components

- **MingoApiService**: Static class containing mutation factory methods
- **Type Definitions**: TypeScript interfaces for API requests and responses
- **Mutation Methods**:
  - `createDialogMutation()` - Creates new ADMIN agent dialogs
  - `sendMessageMutation()` - Sends messages to existing dialogs  
  - `approveRequestMutation()` - Approves approval requests with success/error handling
  - `rejectRequestMutation()` - Rejects approval requests with success/error handling

## Usage Example

```typescript
import { MingoApiService } from '@/services/mingo-api-service'

function ChatComponent() {
  const createDialog = MingoApiService.createDialogMutation()
  const sendMessage = MingoApiService.sendMessageMutation()
  const approveRequest = MingoApiService.approveRequestMutation()

  const handleStartChat = async () => {
    try {
      const dialog = await createDialog.mutateAsync()
      await sendMessage.mutateAsync({
        dialogId: dialog.id,
        content: "Hello Mingo AI!"
      })
    } catch (error) {
      console.error('Chat failed:', error)
    }
  }

  const handleApproval = (requestId: string) => {
    approveRequest.mutate(requestId) // Auto-handles toast notifications
  }

  return (
    <div>
      <button onClick={handleStartChat}>Start Chat</button>
      <button onClick={() => handleApproval('req-123')}>Approve</button>
    </div>
  )
}
```

The service uses the centralized `apiClient` and integrates with React Query for caching, error handling, and optimistic updates. Approval mutations automatically display toast notifications on success/failure.
