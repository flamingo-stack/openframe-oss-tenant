API service layer for Mingo AI chat operations, providing React Query mutations for dialog management, messaging, and approval workflows with centralized error handling.

## Key Components

- **MingoApiService**: Static service class providing mutation functions for all Mingo chat operations
- **createDialogMutation()**: Creates new ADMIN agent dialogs with error validation
- **sendMessageMutation()**: Sends messages to existing dialogs with proper typing
- **approveRequestMutation()**: Approves pending requests with toast notifications
- **rejectRequestMutation()**: Rejects pending requests with toast error handling
- **TypeScript Interfaces**: Comprehensive type definitions for requests and responses

## Usage Example

```typescript
import { MingoApiService } from '@/services/mingo-api-service'

function ChatComponent() {
  // Create dialog mutation
  const createDialog = MingoApiService.createDialogMutation()
  
  // Send message mutation
  const sendMessage = MingoApiService.sendMessageMutation()
  
  // Approval mutations
  const approveRequest = MingoApiService.approveRequestMutation()
  const rejectRequest = MingoApiService.rejectRequestMutation()

  const handleCreateDialog = async () => {
    try {
      const dialog = await createDialog.mutateAsync()
      console.log('Created dialog:', dialog.id)
      
      // Send a message to the new dialog
      await sendMessage.mutateAsync({
        dialogId: dialog.id,
        content: 'Hello Mingo AI!'
      })
    } catch (error) {
      console.error('Dialog creation failed:', error)
    }
  }

  const handleApproval = async (requestId: string) => {
    await approveRequest.mutateAsync(requestId)
    // Toast notification handled automatically
  }

  return (
    <div>
      <button onClick={handleCreateDialog}>Start Chat</button>
      <button onClick={() => handleApproval('req-123')}>Approve Request</button>
    </div>
  )
}
```

The service leverages the centralized `apiClient` for consistent HTTP handling and integrates React Query mutations for optimal caching and error management. All mutations include proper TypeScript typing and error boundaries with user-friendly toast notifications for approval operations.
