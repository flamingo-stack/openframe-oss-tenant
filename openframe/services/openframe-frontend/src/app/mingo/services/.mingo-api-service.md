API service class providing react-query mutations for Mingo AI chat operations including dialog management, messaging, and approval workflows.

## Key Components

**Interfaces:**
- `CreateDialogResponse` - Dialog creation response with ID, status, and timestamps
- `SendMessageResponse` - Message sending response with message ID
- `ApprovalResponse` - Approval request response with status and timestamp
- `CreateDialogRequest` - Dialog creation payload (admin agent type)
- `SendMessageRequest` - Message payload with dialog ID and content

**MingoApiService Class:**
- `createDialogMutation()` - Creates new admin chat dialogs
- `sendMessageMutation()` - Sends messages to existing dialogs  
- `approveRequestMutation()` - Approves approval requests with toast notifications
- `rejectRequestMutation()` - Rejects approval requests with error handling

## Usage Example

```typescript
import { MingoApiService } from '@/services/mingo-api-service'

function ChatComponent() {
  const createDialog = MingoApiService.createDialogMutation()
  const sendMessage = MingoApiService.sendMessageMutation() 
  const approveRequest = MingoApiService.approveRequestMutation()

  const handleStartChat = async () => {
    try {
      const dialog = await createDialog.mutateAsync()
      console.log('Dialog created:', dialog.id)
      
      await sendMessage.mutateAsync({
        dialogId: dialog.id,
        content: 'Hello Mingo!'
      })
    } catch (error) {
      console.error('Chat error:', error)
    }
  }

  const handleApprove = (requestId: string) => {
    approveRequest.mutate(requestId) // Auto-handles toast notifications
  }

  return (
    <button onClick={handleStartChat}>
      Start Mingo Chat
    </button>
  )
}
```
