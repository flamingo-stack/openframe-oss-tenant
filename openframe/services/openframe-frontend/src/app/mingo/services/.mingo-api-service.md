API service providing React Query mutations for Mingo AI chat operations, including dialog creation, message sending, and approval workflows with integrated error handling and toast notifications.

## Key Components

- **MingoApiService**: Static class containing mutation factory methods
- **createDialogMutation()**: Creates new ADMIN agent dialogs
- **sendMessageMutation()**: Sends messages to existing dialogs  
- **approveRequestMutation()**: Approves pending approval requests
- **rejectRequestMutation()**: Rejects pending approval requests
- **TypeScript Interfaces**: Complete type definitions for requests/responses

## Usage Example

```typescript
import { MingoApiService } from './mingo-api-service'

function ChatComponent() {
  const createDialog = MingoApiService.createDialogMutation()
  const sendMessage = MingoApiService.sendMessageMutation()
  const approveRequest = MingoApiService.approveRequestMutation()

  const handleCreateChat = async () => {
    try {
      const dialog = await createDialog.mutateAsync()
      console.log('Created dialog:', dialog.id)
      
      await sendMessage.mutateAsync({
        dialogId: dialog.id,
        content: 'Hello Mingo AI!'
      })
    } catch (error) {
      console.error('Chat operation failed:', error)
    }
  }

  const handleApproval = (requestId: string) => {
    approveRequest.mutate(requestId) // Auto-handles success/error toasts
  }

  return (
    <div>
      <button onClick={handleCreateChat}>Start Chat</button>
      <button onClick={() => handleApproval('req-123')}>Approve</button>
    </div>
  )
}
```
