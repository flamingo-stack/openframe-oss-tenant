API service for managing Mingo AI chat operations, providing React Query mutations for dialog creation, message handling, and approval workflows within the Flamingo OpenFrame platform.

## Key Components

### MingoApiService Class
Static service class that provides mutation functions for:
- **createDialogMutation()** - Creates new admin chat dialogs
- **sendMessageMutation()** - Sends messages to existing dialogs  
- **approveRequestMutation()** - Approves pending requests with toast notifications
- **rejectRequestMutation()** - Rejects pending requests with toast notifications

### TypeScript Interfaces
- **CreateDialogResponse/Request** - Dialog creation data structures
- **SendMessageRequest/Response** - Message handling interfaces
- **ApprovalResponse** - Approval workflow response structure

## Usage Example

```typescript
import { MingoApiService } from './mingo-api-service'

function ChatComponent() {
  // Create dialog mutation
  const createDialog = MingoApiService.createDialogMutation()
  
  // Send message mutation
  const sendMessage = MingoApiService.sendMessageMutation()
  
  // Approval mutations with built-in error handling
  const approveRequest = MingoApiService.approveRequestMutation()
  const rejectRequest = MingoApiService.rejectRequestMutation()

  const handleCreateChat = async () => {
    try {
      const dialog = await createDialog.mutateAsync()
      await sendMessage.mutateAsync({
        dialogId: dialog.id,
        content: 'Hello Mingo!'
      })
    } catch (error) {
      console.error('Chat operation failed:', error)
    }
  }

  const handleApproval = (requestId: string, approve: boolean) => {
    if (approve) {
      approveRequest.mutate(requestId)
    } else {
      rejectRequest.mutate(requestId)
    }
  }
}
```
