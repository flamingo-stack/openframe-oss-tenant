API service layer for Mingo AI chat operations within the OpenFrame platform. Provides React Query mutations for managing chat dialogs, sending messages, and handling approval workflows with built-in error handling and toast notifications.

## Key Components

- **MingoApiService** - Static class providing React Query mutation hooks for chat operations
- **Dialog Management** - `createDialogMutation()` for creating new ADMIN agent dialogs
- **Message Handling** - `sendMessageMutation()` for sending chat messages to dialogs
- **Approval Workflow** - `approveRequestMutation()` and `rejectRequestMutation()` for handling approval requests
- **Type Definitions** - Comprehensive TypeScript interfaces for all request/response objects

## Usage Example

```typescript
import MingoApiService from './mingo-api-service'

function ChatComponent() {
  // Create dialog mutation
  const createDialog = MingoApiService.createDialogMutation()
  
  // Send message mutation
  const sendMessage = MingoApiService.sendMessageMutation()
  
  // Approval mutations
  const approveRequest = MingoApiService.approveRequestMutation()
  const rejectRequest = MingoApiService.rejectRequestMutation()

  const handleCreateDialog = async () => {
    const dialog = await createDialog.mutateAsync()
    console.log('Created dialog:', dialog.id)
  }

  const handleSendMessage = async (dialogId: string) => {
    await sendMessage.mutateAsync({
      dialogId,
      content: 'Hello Mingo AI!'
    })
  }

  const handleApproval = async (requestId: string) => {
    await approveRequest.mutateAsync(requestId)
    // Success toast automatically shown
  }

  return (
    <div>
      <button onClick={handleCreateDialog}>Create Dialog</button>
      <button onClick={() => handleSendMessage('dialog-123')}>Send Message</button>
      <button onClick={() => handleApproval('req-456')}>Approve Request</button>
    </div>
  )
}
```
