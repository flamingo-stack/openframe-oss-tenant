API service class for managing Mingo AI chat operations including dialog creation, message sending, and approval workflows using React Query mutations.

## Key Components

- **MingoApiService** - Static class providing React Query mutation factories for Mingo chat operations
- **createDialogMutation()** - Creates new admin chat dialogs with automatic error handling
- **sendMessageMutation()** - Sends messages to existing dialogs with content validation
- **approveRequestMutation()** - Approves admin requests with success/error toast notifications
- **rejectRequestMutation()** - Rejects admin requests with user feedback via toasts
- **Type Interfaces** - Complete TypeScript definitions for all request/response payloads

## Usage Example

```typescript
import { MingoApiService } from '@/services/mingo-api-service'

function ChatComponent() {
  // Create dialog mutation
  const createDialog = MingoApiService.createDialogMutation()
  
  // Send message mutation  
  const sendMessage = MingoApiService.sendMessageMutation()
  
  // Approval mutations
  const approveRequest = MingoApiService.approveRequestMutation()
  const rejectRequest = MingoApiService.rejectRequestMutation()

  const handleStartChat = async () => {
    try {
      const dialog = await createDialog.mutateAsync()
      console.log('Dialog created:', dialog.id)
      
      await sendMessage.mutateAsync({
        dialogId: dialog.id,
        content: 'Hello Mingo!'
      })
    } catch (error) {
      console.error('Chat error:', error)
    }
  }

  const handleApproval = (requestId: string, approve: boolean) => {
    if (approve) {
      approveRequest.mutate(requestId)
    } else {
      rejectRequest.mutate(requestId)
    }
  }

  return (
    <div>
      <button onClick={handleStartChat}>Start Chat</button>
      <button onClick={() => handleApproval('req-123', true)}>
        Approve Request
      </button>
    </div>
  )
}
```
