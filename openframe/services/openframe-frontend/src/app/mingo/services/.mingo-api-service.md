A React Query-based API service for Mingo chat operations, providing type-safe mutations for dialog management, messaging, and approval workflows in the Flamingo OpenFrame platform.

## Key Components

### TypeScript Interfaces
- **`CreateDialogResponse`** - Dialog creation response with ID, agent type, status, and timestamps
- **`SendMessageResponse`** - Message sending response with message ID
- **`ApprovalResponse`** - Approval request response with status and timestamp
- **`CreateDialogRequest`** - Dialog creation payload (agent type)
- **`SendMessageRequest`** - Message sending payload (dialog ID, content, chat type)

### Static Methods
- **`createDialogMutation()`** - Creates a new admin chat dialog
- **`sendMessageMutation()`** - Sends messages to existing dialogs
- **`approveRequestMutation()`** - Approves pending approval requests with toast notifications
- **`rejectRequestMutation()`** - Rejects pending approval requests with toast notifications

## Usage Example

```typescript
import { MingoApiService } from './mingo-api-service'

function ChatComponent() {
  const createDialog = MingoApiService.createDialogMutation()
  const sendMessage = MingoApiService.sendMessageMutation()
  const approveRequest = MingoApiService.approveRequestMutation()

  const handleCreateChat = async () => {
    const dialog = await createDialog.mutateAsync()
    console.log('Created dialog:', dialog.id)
  }

  const handleSendMessage = async (dialogId: string, message: string) => {
    await sendMessage.mutateAsync({ dialogId, content: message })
  }

  const handleApproval = async (requestId: string) => {
    await approveRequest.mutateAsync(requestId)
    // Toast notification automatically shown on error
  }

  return (
    <div>
      <button onClick={handleCreateChat} disabled={createDialog.isPending}>
        Create Dialog
      </button>
    </div>
  )
}
```

The service integrates with the centralized `apiClient` and provides built-in error handling with toast notifications for approval operations.
