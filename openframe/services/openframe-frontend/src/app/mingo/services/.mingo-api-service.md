This service provides React Query mutations for interacting with Mingo AI chat operations, including dialog creation, message sending, and approval request handling with built-in error management.

## Key Components

- **MingoApiService**: Static class providing mutation factory methods
- **Type Definitions**: TypeScript interfaces for API requests and responses
- **createDialogMutation()**: Creates new admin chat dialogs
- **sendMessageMutation()**: Sends messages to existing dialogs
- **approveRequestMutation()**: Approves pending approval requests with toast notifications
- **rejectRequestMutation()**: Rejects approval requests with error handling

## Usage Example

```typescript
import { MingoApiService } from './mingo-api-service'

function ChatComponent() {
  // Create dialog mutation
  const createDialog = MingoApiService.createDialogMutation()
  
  // Send message mutation
  const sendMessage = MingoApiService.sendMessageMutation()
  
  // Approval mutations
  const approveRequest = MingoApiService.approveRequestMutation()
  const rejectRequest = MingoApiService.rejectRequestMutation()

  const handleStartChat = async () => {
    const dialog = await createDialog.mutateAsync()
    
    await sendMessage.mutateAsync({
      dialogId: dialog.id,
      content: "Hello Mingo AI"
    })
  }

  const handleApproval = async (requestId: string) => {
    await approveRequest.mutateAsync(requestId)
  }

  return (
    <div>
      <button onClick={handleStartChat} disabled={createDialog.isPending}>
        Start Chat
      </button>
      <button onClick={() => handleApproval('req-123')}>
        Approve Request
      </button>
    </div>
  )
}
```

The service integrates with the centralized `apiClient` and provides automatic error handling with toast notifications for approval operations.
