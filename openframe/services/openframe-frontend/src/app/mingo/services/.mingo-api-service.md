API service class that provides React Query mutations for Mingo AI chat operations, including dialog management, messaging, and approval workflows with built-in error handling and toast notifications.

## Key Components

- **MingoApiService** - Static class containing mutation factory methods
- **createDialogMutation()** - Creates new ADMIN agent dialogs
- **sendMessageMutation()** - Sends messages to existing dialogs
- **approveRequestMutation()** - Approves pending requests with toast feedback
- **rejectRequestMutation()** - Rejects pending requests with toast feedback
- **TypeScript Interfaces** - Type definitions for requests and responses

## Usage Example

```typescript
import { MingoApiService } from '@/services/mingo-api-service'

function ChatComponent() {
  // Create dialog mutation
  const createDialog = MingoApiService.createDialogMutation()
  
  // Send message mutation  
  const sendMessage = MingoApiService.sendMessageMutation()
  
  // Approval mutations
  const approveRequest = MingoApiService.approveRequestMutation()
  const rejectRequest = MingoApiService.rejectRequestMutation()

  const handleCreateDialog = async () => {
    try {
      const dialog = await createDialog.mutateAsync()
      console.log('Dialog created:', dialog.id)
    } catch (error) {
      console.error('Failed to create dialog:', error)
    }
  }

  const handleSendMessage = async (dialogId: string, content: string) => {
    await sendMessage.mutateAsync({ dialogId, content })
  }

  const handleApprove = async (requestId: string) => {
    await approveRequest.mutateAsync(requestId)
    // Toast notification shown automatically
  }

  return (
    <div>
      <button onClick={handleCreateDialog}>Create Dialog</button>
      {/* UI components */}
    </div>
  )
}
```

The service integrates with the centralized API client and provides consistent error handling across all Mingo chat operations, with automatic toast notifications for approval actions.
