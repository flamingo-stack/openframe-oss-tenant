A TypeScript service class that provides React Query mutations for interacting with the Mingo AI chat API, including dialog management, messaging, and approval workflows with built-in error handling and toast notifications.

## Key Components

**Interfaces:**
- `CreateDialogResponse` - Response structure for new dialog creation
- `SendMessageResponse` - Response structure for sent messages  
- `ApprovalResponse` - Response structure for approval/rejection actions
- `CreateDialogRequest` - Request payload for dialog creation
- `SendMessageRequest` - Request payload for sending messages

**MingoApiService Class:**
- `createDialogMutation()` - Creates new admin chat dialogs
- `sendMessageMutation()` - Sends messages to existing dialogs
- `approveRequestMutation()` - Approves pending requests with toast feedback
- `rejectRequestMutation()` - Rejects pending requests with toast feedback

## Usage Example

```typescript
import { MingoApiService } from './mingo-api-service'

function ChatComponent() {
  const createDialog = MingoApiService.createDialogMutation()
  const sendMessage = MingoApiService.sendMessageMutation()
  const approveRequest = MingoApiService.approveRequestMutation()

  const handleStartChat = async () => {
    try {
      const dialog = await createDialog.mutateAsync()
      console.log('Created dialog:', dialog.id)
      
      await sendMessage.mutateAsync({
        dialogId: dialog.id,
        content: 'Hello Mingo AI!'
      })
    } catch (error) {
      console.error('Chat creation failed:', error)
    }
  }

  const handleApproval = async (requestId: string) => {
    await approveRequest.mutateAsync(requestId)
  }

  return (
    <button onClick={handleStartChat} disabled={createDialog.isPending}>
      {createDialog.isPending ? 'Creating...' : 'Start Chat'}
    </button>
  )
}
```
