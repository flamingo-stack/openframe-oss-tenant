Service layer for Mingo AI assistant operations, providing React Query mutations for dialog management, messaging, and approval workflows with integrated error handling and toast notifications.

## Key Components

### Interfaces
- **`CreateDialogResponse`** - Response structure for new dialog creation
- **`SendMessageResponse`** - Response structure for message sending
- **`ApprovalResponse`** - Response structure for approval/rejection actions
- **`CreateDialogRequest`** - Request payload for dialog creation
- **`SendMessageRequest`** - Request payload for message sending

### MingoApiService Class
- **`createDialogMutation()`** - Creates new admin-type dialogs
- **`sendMessageMutation()`** - Sends messages to existing dialogs  
- **`approveRequestMutation()`** - Approves pending requests with success/error handling
- **`rejectRequestMutation()`** - Rejects pending requests with success/error handling

## Usage Example

```typescript
import { MingoApiService } from '@/services/mingo-api-service'

function ChatComponent() {
  const createDialog = MingoApiService.createDialogMutation()
  const sendMessage = MingoApiService.sendMessageMutation()
  const approveRequest = MingoApiService.approveRequestMutation()

  const handleCreateDialog = async () => {
    try {
      const dialog = await createDialog.mutateAsync()
      console.log('Created dialog:', dialog.id)
      
      // Send initial message
      await sendMessage.mutateAsync({
        dialogId: dialog.id,
        content: 'Hello Mingo!'
      })
    } catch (error) {
      console.error('Dialog creation failed:', error)
    }
  }

  const handleApproval = (requestId: string) => {
    approveRequest.mutate(requestId) // Auto-handles toast notifications
  }

  return (
    <button onClick={handleCreateDialog} disabled={createDialog.isPending}>
      Start New Chat
    </button>
  )
}
```

The service integrates with Flamingo's centralized `apiClient` and provides built-in error handling with toast notifications for approval operations.
