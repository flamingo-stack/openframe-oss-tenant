API service class for Mingo AI chat operations, providing React Query mutations for dialog management, message handling, and approval workflows within the Flamingo platform.

## Key Components

- **MingoApiService** - Static class providing mutation factory methods
- **Type Interfaces** - Request/response types for API operations:
  - `CreateDialogResponse` - Dialog creation response with metadata
  - `SendMessageResponse` - Message sending confirmation
  - `ApprovalResponse` - Approval request status response
  - `CreateDialogRequest` - Dialog creation parameters
  - `SendMessageRequest` - Message sending parameters

## Key Methods

- **`createDialogMutation()`** - Creates new ADMIN agent dialogs
- **`sendMessageMutation()`** - Sends messages to existing dialogs
- **`approveRequestMutation()`** - Approves pending requests with toast notifications
- **`rejectRequestMutation()`** - Rejects pending requests with error handling

## Usage Example

```typescript
import { MingoApiService } from '@/services/mingo-api-service'

function ChatComponent() {
  // Create dialog mutation
  const createDialog = MingoApiService.createDialogMutation()
  
  // Send message mutation
  const sendMessage = MingoApiService.sendMessageMutation()
  
  // Approval mutations
  const approveRequest = MingoApiService.approveRequestMutation()
  const rejectRequest = MingoApiService.rejectRequestMutation()

  const handleStartChat = async () => {
    try {
      const dialog = await createDialog.mutateAsync()
      await sendMessage.mutateAsync({
        dialogId: dialog.id,
        content: 'Hello Mingo!'
      })
    } catch (error) {
      console.error('Chat operation failed:', error)
    }
  }

  const handleApproval = (requestId: string, approved: boolean) => {
    if (approved) {
      approveRequest.mutate(requestId)
    } else {
      rejectRequest.mutate(requestId)
    }
  }

  return (
    <div>
      <button onClick={handleStartChat}>Start Chat</button>
      {/* Chat UI components */}
    </div>
  )
}
```

The service integrates with the centralized `apiClient` and includes built-in error handling with toast notifications for approval operations.
