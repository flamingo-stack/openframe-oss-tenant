A centralized API service class that provides react-query mutation hooks for Mingo AI chat operations, including dialog management, message handling, and approval workflows with built-in error handling and toast notifications.

## Key Components

- **MingoApiService** - Static service class providing mutation factories for Mingo chat operations
- **TypeScript Interfaces** - Comprehensive type definitions for API requests and responses
- **createDialogMutation()** - Creates new ADMIN agent dialogs
- **sendMessageMutation()** - Sends messages to existing dialogs
- **approveRequestMutation()** - Approves approval requests with toast feedback
- **rejectRequestMutation()** - Rejects approval requests with toast feedback

## Usage Example

```typescript
import { MingoApiService } from './mingo-api-service'

function ChatComponent() {
  const createDialog = MingoApiService.createDialogMutation()
  const sendMessage = MingoApiService.sendMessageMutation()
  const approveRequest = MingoApiService.approveRequestMutation()

  const handleStartChat = async () => {
    try {
      const dialog = await createDialog.mutateAsync()
      console.log('Dialog created:', dialog.id)
      
      await sendMessage.mutateAsync({
        dialogId: dialog.id,
        content: 'Hello Mingo!'
      })
    } catch (error) {
      console.error('Chat operation failed:', error)
    }
  }

  const handleApproval = (requestId: string) => {
    approveRequest.mutate(requestId)
  }

  return (
    <div>
      <button onClick={handleStartChat}>Start Chat</button>
      <button onClick={() => handleApproval('req-123')}>Approve</button>
    </div>
  )
}
```

The service leverages the centralized `apiClient` for consistent API communication and integrates with react-query for optimal state management and caching of chat operations.
