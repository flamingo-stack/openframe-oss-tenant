API service layer for Mingo AI assistant chat operations, providing React Query mutations for dialog management, message handling, and approval workflow operations.

## Key Components

- **MingoApiService** - Static class providing mutation factories for Mingo chat operations
- **createDialogMutation()** - Creates new ADMIN agent dialogs with error handling
- **sendMessageMutation()** - Sends messages to existing dialogs with validation
- **approveRequestMutation()** - Approves pending requests with toast notifications
- **rejectRequestMutation()** - Rejects pending requests with error feedback
- **TypeScript interfaces** - Comprehensive type definitions for all API request/response objects

## Usage Example

```typescript
import { MingoApiService } from './mingo-api-service'

function ChatComponent() {
  // Create mutations using the service
  const createDialog = MingoApiService.createDialogMutation()
  const sendMessage = MingoApiService.sendMessageMutation()
  const approveRequest = MingoApiService.approveRequestMutation()

  const handleStartChat = async () => {
    try {
      // Create a new dialog
      const dialog = await createDialog.mutateAsync()
      
      // Send initial message
      await sendMessage.mutateAsync({
        dialogId: dialog.id,
        content: "Hello Mingo, I need help with server deployment"
      })
    } catch (error) {
      console.error('Chat initialization failed:', error)
    }
  }

  const handleApproval = (requestId: string) => {
    approveRequest.mutate(requestId)
  }

  return (
    <div>
      <button onClick={handleStartChat} disabled={createDialog.isPending}>
        Start Chat with Mingo
      </button>
    </div>
  )
}
```
