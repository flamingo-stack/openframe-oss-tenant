API service for Mingo AI chat operations, providing React Query mutations for dialog management, messaging, and approval workflows in the OpenFrame platform.

## Key Components

**Types & Interfaces:**
- `CreateDialogResponse` - Response structure for new dialog creation
- `SendMessageResponse` - Response structure for message operations
- `ApprovalResponse` - Response structure for approval/rejection actions
- `CreateDialogRequest` & `SendMessageRequest` - Request payload types

**MingoApiService Class:**
- `createDialogMutation()` - Creates new ADMIN agent dialogs
- `sendMessageMutation()` - Sends messages to existing dialogs
- `approveRequestMutation()` - Approves approval requests with toast notifications
- `rejectRequestMutation()` - Rejects approval requests with error handling

## Usage Example

```typescript
import { MingoApiService } from './mingo-api-service'

function ChatComponent() {
  // Create dialog mutation
  const createDialog = MingoApiService.createDialogMutation()
  
  // Send message mutation
  const sendMessage = MingoApiService.sendMessageMutation()
  
  // Approval mutations
  const approveRequest = MingoApiService.approveRequestMutation()
  const rejectRequest = MingoApiService.rejectRequestMutation()

  const handleStartChat = async () => {
    const dialog = await createDialog.mutateAsync()
    console.log('Dialog created:', dialog.id)
    
    await sendMessage.mutateAsync({
      dialogId: dialog.id,
      content: "Hello Mingo AI!"
    })
  }

  const handleApproval = async (requestId: string) => {
    await approveRequest.mutateAsync(requestId)
    // Toast notification handled automatically
  }

  return (
    <div>
      <button onClick={handleStartChat}>Start Chat</button>
      <button onClick={() => handleApproval('req-123')}>Approve</button>
    </div>
  )
}
```
