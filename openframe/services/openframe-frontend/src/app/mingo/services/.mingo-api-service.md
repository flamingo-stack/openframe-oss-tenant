A TypeScript service class that provides React Query mutations for interacting with Mingo AI chat operations, including dialog management, message sending, and approval workflows.

## Key Components

- **MingoApiService** - Static service class with mutation factory methods
- **Type Interfaces** - Request/response types for dialog, message, and approval operations
- **createDialogMutation()** - Creates new admin AI chat dialogs
- **sendMessageMutation()** - Sends messages to existing dialogs
- **approveRequestMutation()** - Approves pending approval requests with toast notifications
- **rejectRequestMutation()** - Rejects pending approval requests with toast notifications

## Usage Example

```typescript
import { MingoApiService } from '@/services/mingo-api-service'

function ChatComponent() {
  // Create dialog mutation
  const createDialog = MingoApiService.createDialogMutation()
  
  // Send message mutation
  const sendMessage = MingoApiService.sendMessageMutation()
  
  // Approval mutations with built-in error handling
  const approveRequest = MingoApiService.approveRequestMutation()
  const rejectRequest = MingoApiService.rejectRequestMutation()

  const handleStartChat = async () => {
    const dialog = await createDialog.mutateAsync()
    await sendMessage.mutateAsync({
      dialogId: dialog.id,
      content: "Hello Mingo!"
    })
  }

  const handleApproval = (requestId: string, approve: boolean) => {
    if (approve) {
      approveRequest.mutate(requestId)
    } else {
      rejectRequest.mutate(requestId)
    }
  }

  return (
    <div>
      <button onClick={handleStartChat}>Start Chat</button>
      {/* Chat interface */}
    </div>
  )
}
```

The service integrates with the centralized API client and includes automatic error handling with toast notifications for approval operations.
