A TypeScript service class that provides React Query mutations for Mingo AI chat operations, including dialog creation, message sending, and approval request handling.

## Key Components

- **MingoApiService** - Static service class with mutation factory methods
- **Interface Types** - Request/response type definitions for all API operations
- **createDialogMutation()** - Creates new ADMIN agent dialogs
- **sendMessageMutation()** - Sends messages to existing dialogs
- **approveRequestMutation()** - Approves approval requests with toast notifications
- **rejectRequestMutation()** - Rejects approval requests with toast notifications

## Usage Example

```typescript
import { MingoApiService } from './mingo-api-service'

function ChatComponent() {
  // Create dialog mutation
  const createDialog = MingoApiService.createDialogMutation()
  
  // Send message mutation
  const sendMessage = MingoApiService.sendMessageMutation()
  
  // Approval mutations
  const approveRequest = MingoApiService.approveRequestMutation()
  const rejectRequest = MingoApiService.rejectRequestMutation()
  
  const handleCreateDialog = async () => {
    try {
      const dialog = await createDialog.mutateAsync()
      console.log('Created dialog:', dialog.id)
    } catch (error) {
      console.error('Failed to create dialog:', error)
    }
  }
  
  const handleSendMessage = async (dialogId: string, content: string) => {
    await sendMessage.mutateAsync({ dialogId, content })
  }
  
  const handleApproval = async (requestId: string, approve: boolean) => {
    if (approve) {
      await approveRequest.mutateAsync(requestId)
    } else {
      await rejectRequest.mutateAsync(requestId)
    }
  }
  
  // Component JSX...
}
```

The service uses the centralized `apiClient` for HTTP requests and integrates with React Query for state management and error handling. Approval operations include automatic toast notifications for user feedback.
