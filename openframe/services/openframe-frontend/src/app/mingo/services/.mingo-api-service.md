A React Query-based API service that provides type-safe mutations for Mingo AI chat operations including dialog creation, message sending, and approval request handling.

## Key Components

- **MingoApiService** - Static class providing mutation factory methods
- **createDialogMutation()** - Creates new admin chat dialogs
- **sendMessageMutation()** - Sends messages to existing dialogs
- **approveRequestMutation()** - Approves approval requests with toast notifications
- **rejectRequestMutation()** - Rejects approval requests with toast notifications
- **TypeScript Interfaces** - Request/response type definitions for all operations

## Usage Example

```typescript
import { MingoApiService } from './mingo-api-service'

function ChatComponent() {
  // Create dialog mutation
  const createDialog = MingoApiService.createDialogMutation()
  
  // Send message mutation
  const sendMessage = MingoApiService.sendMessageMutation()
  
  // Approval mutations
  const approveRequest = MingoApiService.approveRequestMutation()
  const rejectRequest = MingoApiService.rejectRequestMutation()

  const handleCreateDialog = async () => {
    const dialog = await createDialog.mutateAsync()
    console.log('Created dialog:', dialog.id)
  }

  const handleSendMessage = async (dialogId: string) => {
    await sendMessage.mutateAsync({
      dialogId,
      content: 'Hello Mingo AI!'
    })
  }

  const handleApproval = async (requestId: string) => {
    await approveRequest.mutateAsync(requestId)
    // Toast notification shown automatically on error
  }
}
```
