API service for Mingo chat operations, providing React Query mutations for dialog management, message sending, and approval workflows using the centralized API client.

## Key Components

**Interfaces:**
- `CreateDialogResponse` - Response structure for new dialog creation with status tracking
- `SendMessageResponse` - Response containing message ID for sent messages
- `ApprovalResponse` - Response for approval/rejection operations with status and timestamp
- `CreateDialogRequest`/`SendMessageRequest` - Request payload structures

**MingoApiService Class:**
- `createDialogMutation()` - Creates admin-type dialogs with error handling
- `sendMessageMutation()` - Sends messages to existing dialogs with chat type specification
- `approveRequestMutation()` - Approves approval requests with toast notifications
- `rejectRequestMutation()` - Rejects approval requests with error feedback

## Usage Example

```typescript
import { MingoApiService } from '@/services/mingo-api-service'

function ChatComponent() {
  const createDialog = MingoApiService.createDialogMutation()
  const sendMessage = MingoApiService.sendMessageMutation()
  const approveRequest = MingoApiService.approveRequestMutation()

  const handleStartChat = async () => {
    try {
      const dialog = await createDialog.mutateAsync()
      console.log('Dialog created:', dialog.id)
      
      await sendMessage.mutateAsync({
        dialogId: dialog.id,
        content: 'Hello Mingo!'
      })
    } catch (error) {
      console.error('Chat operation failed:', error)
    }
  }

  const handleApproval = async (requestId: string) => {
    await approveRequest.mutateAsync(requestId)
    // Toast notification handled automatically
  }

  return (
    <div>
      <button onClick={handleStartChat}>Start Chat</button>
      <button onClick={() => handleApproval('req-123')}>Approve</button>
    </div>
  )
}
```
