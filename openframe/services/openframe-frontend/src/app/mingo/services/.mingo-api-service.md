Service for Mingo AI chat operations, providing react-query mutations for dialog management, messaging, and approval workflows within the Flamingo platform.

## Key Components

- **MingoApiService**: Static class providing mutation factories for all Mingo chat operations
- **createDialogMutation()**: Creates new admin chat dialogs
- **sendMessageMutation()**: Sends messages to existing dialogs
- **approveRequestMutation()**: Approves pending requests with error handling
- **rejectRequestMutation()**: Rejects pending requests with error handling

### TypeScript Interfaces

- **CreateDialogResponse**: Dialog creation response structure
- **SendMessageResponse**: Message sending response structure  
- **ApprovalResponse**: Approval action response structure
- **CreateDialogRequest/SendMessageRequest**: Request payload types

## Usage Example

```typescript
import MingoApiService from '@/services/mingo-api-service'

function ChatComponent() {
  const createDialog = MingoApiService.createDialogMutation()
  const sendMessage = MingoApiService.sendMessageMutation()
  const approveRequest = MingoApiService.approveRequestMutation()

  const handleCreateDialog = async () => {
    try {
      const dialog = await createDialog.mutateAsync()
      console.log('Dialog created:', dialog.id)
    } catch (error) {
      console.error('Failed to create dialog:', error)
    }
  }

  const handleSendMessage = async (dialogId: string, content: string) => {
    await sendMessage.mutateAsync({ dialogId, content })
  }

  const handleApproval = async (requestId: string) => {
    await approveRequest.mutateAsync(requestId)
    // Toast notification handled automatically
  }

  return (
    <div>
      <button onClick={handleCreateDialog}>Start Chat</button>
    </div>
  )
}
```
