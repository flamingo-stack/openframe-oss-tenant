A TypeScript service class providing API methods for Mingo AI chat operations including dialog creation, message sending, and approval management using React Query mutations.

## Key Components

- **MingoApiService** - Static service class with factory methods for React Query mutations
- **Interface Definitions** - TypeScript interfaces for API requests and responses:
  - `CreateDialogResponse` - Dialog creation response with id, status, and timestamps
  - `SendMessageResponse` - Message sending response with messageId
  - `ApprovalResponse` - Approval request response with status and timestamp
  - `CreateDialogRequest` & `SendMessageRequest` - Request payload interfaces
- **Mutation Methods** - Factory functions returning configured React Query mutations:
  - `createDialogMutation()` - Creates new admin chat dialogs
  - `sendMessageMutation()` - Sends messages to existing dialogs
  - `approveRequestMutation()` & `rejectRequestMutation()` - Handle approval workflows

## Usage Example

```typescript
import { MingoApiService } from './mingo-api-service'

// In a React component
const CreateChatButton = () => {
  const createDialog = MingoApiService.createDialogMutation()
  const sendMessage = MingoApiService.sendMessageMutation()
  const approveRequest = MingoApiService.approveRequestMutation()

  const handleCreateChat = async () => {
    try {
      const dialog = await createDialog.mutateAsync()
      console.log(`Created dialog: ${dialog.id}`)
      
      // Send initial message
      await sendMessage.mutateAsync({
        dialogId: dialog.id,
        content: "Hello Mingo AI"
      })
    } catch (error) {
      console.error('Chat creation failed:', error)
    }
  }

  const handleApproval = (requestId: string) => {
    approveRequest.mutate(requestId)
  }

  return (
    <button onClick={handleCreateChat}>
      Start Mingo Chat
    </button>
  )
}
```

The service uses the centralized `apiClient` for HTTP requests and includes automatic error handling with toast notifications for approval operations.
