A TypeScript service class that provides React Query mutations for interacting with the Mingo AI chat API, handling dialog creation, message sending, and approval request management with integrated error handling and toast notifications.

## Key Components

**Interfaces:**
- `CreateDialogResponse` - Response structure for new dialog creation
- `SendMessageResponse` - Response structure for sent messages
- `ApprovalResponse` - Response structure for approval operations
- `CreateDialogRequest` - Request payload for dialog creation
- `SendMessageRequest` - Request payload for message sending

**Main Service:**
- `MingoApiService` - Static class providing mutation factory methods
- `createDialogMutation()` - Creates new ADMIN agent dialogs
- `sendMessageMutation()` - Sends messages to existing dialogs
- `approveRequestMutation()` - Approves approval requests with error toast handling
- `rejectRequestMutation()` - Rejects approval requests with error toast handling

## Usage Example

```typescript
import { MingoApiService } from './mingo-api-service'

function ChatComponent() {
  const createDialog = MingoApiService.createDialogMutation()
  const sendMessage = MingoApiService.sendMessageMutation()
  const approveRequest = MingoApiService.approveRequestMutation()

  const handleCreateDialog = async () => {
    const dialog = await createDialog.mutateAsync()
    console.log('Created dialog:', dialog.id)
  }

  const handleSendMessage = async (dialogId: string) => {
    await sendMessage.mutateAsync({
      dialogId,
      content: 'Hello Mingo AI assistant'
    })
  }

  const handleApproval = async (requestId: string) => {
    await approveRequest.mutateAsync(requestId)
  }

  return (
    <div>
      <button onClick={handleCreateDialog}>Create Dialog</button>
      <button onClick={() => handleApproval('req_123')}>Approve Request</button>
    </div>
  )
}
```
