API service providing React Query mutations for Mingo AI assistant chat operations, including dialog management, messaging, and approval workflows with integrated error handling and toast notifications.

## Key Components

- **MingoApiService** - Static class providing mutation factory methods for Mingo chat operations
- **createDialogMutation()** - Creates new admin-type chat dialogs
- **sendMessageMutation()** - Sends messages to existing dialogs
- **approveRequestMutation()** - Approves pending approval requests with success/error handling
- **rejectRequestMutation()** - Rejects pending approval requests with toast notifications
- **TypeScript Interfaces** - Type definitions for API requests and responses

## Usage Example

```typescript
import { MingoApiService } from '@/services/mingo-api-service'

function ChatComponent() {
  // Create dialog mutation
  const createDialog = MingoApiService.createDialogMutation()
  
  // Send message mutation
  const sendMessage = MingoApiService.sendMessageMutation()
  
  // Approval mutations with built-in toast notifications
  const approveRequest = MingoApiService.approveRequestMutation()
  const rejectRequest = MingoApiService.rejectRequestMutation()

  const handleCreateChat = async () => {
    try {
      const dialog = await createDialog.mutateAsync()
      console.log('Created dialog:', dialog.id)
      
      // Send initial message
      await sendMessage.mutateAsync({
        dialogId: dialog.id,
        content: 'Hello Mingo!'
      })
    } catch (error) {
      console.error('Chat creation failed:', error)
    }
  }

  const handleApproval = (requestId: string, approved: boolean) => {
    if (approved) {
      approveRequest.mutate(requestId)
    } else {
      rejectRequest.mutate(requestId)
    }
  }

  return (
    <div>
      <button onClick={handleCreateChat}>Start Chat</button>
      {/* UI components */}
    </div>
  )
}
```

All mutations include proper error handling and integrate with the centralized API client. Approval operations automatically display toast notifications for user feedback.
