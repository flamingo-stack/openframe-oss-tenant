A service class providing React Query mutations for interacting with the Mingo AI chat system, including dialog management, messaging, and approval workflows.

## Key Components

- **MingoApiService** - Static service class with mutation factory methods
- **createDialogMutation()** - Creates new admin-type chat dialogs
- **sendMessageMutation()** - Sends messages to existing dialogs
- **approveRequestMutation()** - Approves pending approval requests with toast notifications
- **rejectRequestMutation()** - Rejects pending approval requests with toast notifications

## TypeScript Interfaces

- **CreateDialogResponse** - Dialog creation response with metadata
- **SendMessageResponse** - Message sending response
- **ApprovalResponse** - Approval action response with status
- **CreateDialogRequest/SendMessageRequest** - Request payload types

## Usage Example

```typescript
import { MingoApiService } from './mingo-api-service'

function ChatComponent() {
  const createDialog = MingoApiService.createDialogMutation()
  const sendMessage = MingoApiService.sendMessageMutation()
  const approveRequest = MingoApiService.approveRequestMutation()

  const handleCreateDialog = async () => {
    try {
      const dialog = await createDialog.mutateAsync()
      console.log('Dialog created:', dialog.id)
    } catch (error) {
      console.error('Failed to create dialog:', error)
    }
  }

  const handleSendMessage = async (dialogId: string, content: string) => {
    await sendMessage.mutateAsync({ dialogId, content })
  }

  const handleApprove = async (requestId: string) => {
    await approveRequest.mutateAsync(requestId)
    // Toast notification handled automatically
  }

  return (
    <div>
      <button onClick={handleCreateDialog}>Create Dialog</button>
      {/* UI components */}
    </div>
  )
}
```

This service centralizes all Mingo AI chat API interactions with built-in error handling and user feedback through toast notifications.
