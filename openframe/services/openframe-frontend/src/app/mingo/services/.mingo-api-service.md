API service for Mingo AI chat operations, providing React Query mutations for dialog management, message handling, and approval workflows within the Flamingo OpenFrame platform.

## Key Components

- **MingoApiService**: Static class containing mutation factory methods for Mingo chat operations
- **Dialog Management**: Create new AI chat dialogs with ADMIN agent type
- **Message Operations**: Send messages to existing dialogs with proper chat type classification
- **Approval System**: Approve or reject requests with integrated toast notifications
- **TypeScript Interfaces**: Comprehensive type definitions for all API requests and responses

## Usage Example

```typescript
import { MingoApiService } from './mingo-api-service'

// Create a new dialog
const createDialog = MingoApiService.createDialogMutation()
const newDialog = await createDialog.mutateAsync()

// Send a message to the dialog
const sendMessage = MingoApiService.sendMessageMutation()
await sendMessage.mutateAsync({
  dialogId: newDialog.id,
  content: "Hello, I need assistance with server monitoring"
})

// Handle approval requests
const approveRequest = MingoApiService.approveRequestMutation()
const rejectRequest = MingoApiService.rejectRequestMutation()

await approveRequest.mutateAsync("request-123")
await rejectRequest.mutateAsync("request-456")
```

The service integrates with the centralized `apiClient` and includes automatic error handling with toast notifications for approval operations. All methods return React Query mutations for seamless integration with component state management.
