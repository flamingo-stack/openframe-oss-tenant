Service class providing React Query mutations for Mingo AI chat operations including dialog management, messaging, and approval workflows.

## Key Components

- **MingoApiService**: Static service class with mutation factory methods
- **createDialogMutation()**: Creates new admin chat dialogs
- **sendMessageMutation()**: Sends messages to existing dialogs  
- **approveRequestMutation()**: Approves pending requests with toast notifications
- **rejectRequestMutation()**: Rejects pending requests with error handling
- **TypeScript Interfaces**: Comprehensive type definitions for all API requests/responses

## Usage Example

```typescript
import { MingoApiService } from './mingo-api-service'

function ChatComponent() {
  // Create dialog mutation
  const createDialog = MingoApiService.createDialogMutation()
  
  // Send message mutation
  const sendMessage = MingoApiService.sendMessageMutation()
  
  // Approval mutations
  const approveRequest = MingoApiService.approveRequestMutation()
  const rejectRequest = MingoApiService.rejectRequestMutation()

  const handleStartChat = async () => {
    try {
      const dialog = await createDialog.mutateAsync()
      await sendMessage.mutateAsync({
        dialogId: dialog.id,
        content: "Hello Mingo AI"
      })
    } catch (error) {
      console.error('Chat error:', error)
    }
  }

  const handleApproval = (requestId: string, approve: boolean) => {
    if (approve) {
      approveRequest.mutate(requestId)
    } else {
      rejectRequest.mutate(requestId)
    }
  }

  return (
    <div>
      <button onClick={handleStartChat}>Start Chat</button>
      <button onClick={() => handleApproval('req-123', true)}>Approve</button>
    </div>
  )
}
```

The service integrates with Flamingo's centralized API client and provides built-in error handling with toast notifications for approval operations.
