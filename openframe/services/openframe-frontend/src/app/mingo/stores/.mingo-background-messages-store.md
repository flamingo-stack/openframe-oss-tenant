Zustand store for managing Mingo AI chat messages across multiple background dialogs, handling message persistence, unread counts, and typing indicators when users switch between conversations.

## Key Components

### State Properties
- **`dialogMessages`** - Per-dialog message storage with automatic cleanup (max 50 messages)
- **`unreadCounts`** - Tracks unread message counts for each dialog
- **`backgroundTypingIndicators`** - Manages typing states for background dialogs
- **`activeDialogId`** - Currently active dialog for display

### Core Actions
- **Message Management**: `addBackgroundMessage()`, `setDialogMessages()`, `mergeDialogMessages()`
- **Unread Tracking**: `incrementUnreadCount()`, `resetUnreadCount()`
- **Dialog Lifecycle**: `initializeDialog()`, `clearDialogData()`, `moveBackgroundToActive()`
- **Typing Indicators**: `setBackgroundTyping()`, `isBackgroundTyping()`
- **Stream Handling**: `preserveStreamingMessage()` for real-time updates

## Usage Example

```typescript
import { useMingoBackgroundMessagesStore } from './mingo-background-messages-store'

function ChatComponent() {
  const {
    activeDialogId,
    setActiveDialogId,
    addBackgroundMessage,
    getUnreadCount,
    moveBackgroundToActive
  } = useMingoBackgroundMessagesStore()

  const switchDialog = (dialogId: string) => {
    // Move background messages to active dialog
    const backgroundMessages = moveBackgroundToActive(dialogId)
    setActiveDialogId(dialogId)
    
    // backgroundMessages now contains all stored messages for the dialog
    console.log(`Switched to dialog with ${backgroundMessages.length} messages`)
  }

  const handleBackgroundMessage = (dialogId: string, message: Message) => {
    if (dialogId !== activeDialogId) {
      addBackgroundMessage(dialogId, message)
      incrementUnreadCount(dialogId)
    }
  }

  return (
    <div>
      {/* Dialog selector with unread counts */}
      <DialogTabs unreadCount={getUnreadCount('dialog-1')} />
    </div>
  )
}
```

The store automatically limits background messages to 50 per dialog and provides seamless switching between conversations while preserving message history and unread states.
