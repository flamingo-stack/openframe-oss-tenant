A Zustand store that manages message state for multiple chat dialogs running in the background within Mingo AI, handling message persistence, unread counts, and typing indicators when users switch between conversations.

## Key Components

### State Properties
- **`dialogMessages`** - Per-dialog message storage with automatic size limiting (50 messages max)
- **`unreadCounts`** - Tracks unread message counts for each background dialog
- **`backgroundTypingIndicators`** - Shows typing status for non-active dialogs
- **`activeDialogId`** - Currently displayed dialog identifier

### Core Actions
- **Message Management**: `addBackgroundMessage()`, `setDialogMessages()`, `mergeDialogMessages()`
- **Dialog Lifecycle**: `initializeDialog()`, `clearDialogData()`, `moveBackgroundToActive()`
- **Unread Tracking**: `incrementUnreadCount()`, `resetUnreadCount()`
- **Typing Indicators**: `setBackgroundTyping()`, `isBackgroundTyping()`
- **Streaming Support**: `preserveStreamingMessage()` for real-time message updates

### Utility Methods
- **Getters**: `getDialogMessages()`, `getUnreadCount()`, `isBackgroundTyping()`
- **Dialog State**: `setActiveDialogId()` for switching between conversations

## Usage Example

```typescript
import { useMingoBackgroundMessagesStore } from './mingo-background-messages-store'

function ChatManager() {
  const {
    addBackgroundMessage,
    setActiveDialogId,
    getUnreadCount,
    moveBackgroundToActive
  } = useMingoBackgroundMessagesStore()

  // Add message to background dialog
  const handleBackgroundMessage = (dialogId: string, message: Message) => {
    addBackgroundMessage(dialogId, message)
  }

  // Switch to dialog and get its messages
  const switchToDialog = (dialogId: string) => {
    setActiveDialogId(dialogId)
    const messages = moveBackgroundToActive(dialogId) // Clears unread count
    return messages
  }

  // Check unread count for dialog indicator
  const unreadCount = getUnreadCount('dialog-123')

  return (
    <div>
      <DialogSwitcher unreadCount={unreadCount} />
    </div>
  )
}
```
