A Zustand store that manages background chat dialog state for the Mingo AI assistant, handling message storage, unread counts, and typing indicators for multiple concurrent conversations.

## Key Components

**State Properties:**
- `dialogMessages` - Per-dialog message storage with 50 message limit
- `unreadCounts` - Tracks unread message counts for each dialog
- `backgroundTypingIndicators` - Shows typing status for background dialogs
- `activeDialogId` - Currently active/visible dialog identifier

**Core Actions:**
- `addBackgroundMessage()` - Adds or updates messages in background dialogs
- `setActiveDialogId()` - Switches between active dialogs
- `incrementUnreadCount()` / `resetUnreadCount()` - Manages unread message counters
- `setBackgroundTyping()` - Controls typing indicators
- `moveBackgroundToActive()` - Transfers background messages to active state

**Utility Functions:**
- `initializeDialog()` - Sets up new dialog with default state
- `mergeDialogMessages()` - Combines new messages with existing ones
- `preserveStreamingMessage()` - Handles real-time message updates
- `clearDialogData()` - Removes all data for a dialog

## Usage Example

  const {

    addBackgroundMessage,

    const backgroundMessages = moveBackgroundToActive(dialogId)

        </button>
      ))}
    </div>
  )
}
