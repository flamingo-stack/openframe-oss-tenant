Zustand store for managing background dialog messages, unread counts, and typing indicators across multiple AI chat conversations in the Mingo platform.

## Key Components

### Store State
- **`dialogMessages`** - Per-dialog message storage with max 50 messages per dialog
- **`unreadCounts`** - Track unread message counts for each background dialog
- **`backgroundTypingIndicators`** - Show typing status for non-active dialogs
- **`activeDialogId`** - Currently displayed dialog identifier

### Core Actions
- **`addBackgroundMessage()`** - Add/update messages in background dialogs
- **`setActiveDialogId()`** - Switch between dialog contexts
- **`incrementUnreadCount()`** / **`resetUnreadCount()`** - Manage notification badges
- **`setBackgroundTyping()`** - Update typing indicators for background conversations
- **`moveBackgroundToActive()`** - Transfer background messages when dialog becomes active

### Utility Functions
- **`initializeDialog()`** - Set up new dialog with default state
- **`mergeDialogMessages()`** - Combine messages while avoiding duplicates
- **`preserveStreamingMessage()`** - Handle real-time streaming message updates
- **`clearDialogData()`** - Clean up dialog when closed

    setActiveDialogId(dialogId)

  }

  // Handle incoming message for background dialog
  const handleBackgroundMessage = (dialogId: string, message: Message) => {
    if (dialogId !== activeDialogId) {
      addBackgroundMessage(dialogId, message)
      // Show notification badge with unread count
    }
  }

    <div>
      {dialogIds.map(id => (

          key={id}

          unreadCount={getUnreadCount(id)}
          onClick={() => switchDialog(id)}
        />
      ))}
    </div>
  )
}
