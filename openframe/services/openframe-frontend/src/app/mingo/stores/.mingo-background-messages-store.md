A Zustand store for managing background message state in Mingo AI chat dialogs, handling message persistence, unread counts, and typing indicators when dialogs are not actively displayed.

## Key Components

### State Properties
- `dialogMessages` - Per-dialog message storage with automatic cleanup at 50 messages max
- `unreadCounts` - Track unread message counts for each dialog
- `backgroundTypingIndicators` - Monitor AI typing status for background dialogs
- `activeDialogId` - Currently displayed dialog identifier

### Core Actions
- `addBackgroundMessage()` - Add/update messages with deduplication
- `setActiveDialogId()` - Switch between active dialogs
- `incrementUnreadCount()` / `resetUnreadCount()` - Manage notification badges
- `setBackgroundTyping()` - Update AI typing status
- `mergeDialogMessages()` - Combine new messages with existing ones
- `moveBackgroundToActive()` - Transfer background messages to active view

### Utility Functions
- `initializeDialog()` - Setup new dialog state
- `clearDialogData()` - Cleanup dialog on closure
- `preserveStreamingMessage()` - Handle real-time message updates

## Usage Example

```typescript
import { useMingoBackgroundMessagesStore } from './mingo-background-messages-store'

function ChatManager() {
  const {
    addBackgroundMessage,
    getUnreadCount,
    moveBackgroundToActive,
    setActiveDialogId
  } = useMingoBackgroundMessagesStore()

  // Add message to background dialog
  const handleBackgroundMessage = (dialogId: string, message: Message) => {
    addBackgroundMessage(dialogId, message)
  }

  // Switch to dialog and get all messages
  const activateDialog = (dialogId: string) => {
    setActiveDialogId(dialogId)
    const messages = moveBackgroundToActive(dialogId)
    return messages // Contains all background messages
  }

  // Show unread badge
  const unreadCount = getUnreadCount('dialog-123')
  
  return (
    <div>
      {unreadCount > 0 && <span className="badge">{unreadCount}</span>}
    </div>
  )
}
```

The store uses Immer middleware for immutable state updates and maintains a maximum of 50 messages per dialog to prevent memory issues during long conversations.
