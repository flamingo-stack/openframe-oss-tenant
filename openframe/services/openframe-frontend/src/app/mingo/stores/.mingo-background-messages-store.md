A Zustand store managing background chat dialogs for Mingo AI, handling message storage, unread counts, and typing indicators for conversations that aren't currently active.

## Key Components

- **dialogMessages** - Per-dialog message storage with automatic message limit enforcement
- **unreadCounts** - Tracks unread message counts for each background dialog
- **backgroundTypingIndicators** - Shows typing status for background conversations
- **activeDialogId** - Currently displayed dialog identifier
- **Message Management Actions** - Add, merge, clear, and move messages between dialogs
- **State Utilities** - Initialize dialogs, preserve streaming messages, and manage active state

## Usage Example

```typescript
import { useMingoBackgroundMessagesStore } from './stores/mingo-background-messages-store'

function ChatSidebar() {
  const { 
    unreadCounts, 
    setActiveDialogId, 
    addBackgroundMessage,
    resetUnreadCount,
    isBackgroundTyping 
  } = useMingoBackgroundMessagesStore()

  const handleDialogSwitch = (dialogId: string) => {
    setActiveDialogId(dialogId)
    resetUnreadCount(dialogId)
  }

  const addMessageToBackground = (dialogId: string, message: Message) => {
    addBackgroundMessage(dialogId, message)
  }

  return (
    <div className="chat-sidebar">
      {Object.entries(unreadCounts).map(([dialogId, count]) => (
        <div key={dialogId} onClick={() => handleDialogSwitch(dialogId)}>
          Dialog {dialogId}
          {count > 0 && <span className="badge">{count}</span>}
          {isBackgroundTyping(dialogId) && <span>typing...</span>}
        </div>
      ))}
    </div>
  )
}
```

The store automatically limits background messages to 50 per dialog and provides utilities for seamless dialog switching with preserved conversation state.
