A Zustand store that manages message storage and state for background dialogs in the Mingo AI chat system, handling multi-dialog conversations with unread counts and typing indicators.

## Key Components

### State Properties
- `dialogMessages` - Per-dialog message storage with message history
- `unreadCounts` - Tracks unread message counts for each dialog
- `backgroundTypingIndicators` - Shows typing status for background dialogs
- `activeDialogId` - Currently active/visible dialog identifier

### Core Actions
- `addBackgroundMessage()` - Adds or updates messages with automatic deduplication
- `setDialogMessages()` / `getDialogMessages()` - Message collection management
- `incrementUnreadCount()` / `resetUnreadCount()` - Unread badge tracking
- `setBackgroundTyping()` / `isBackgroundTyping()` - Typing indicator management
- `moveBackgroundToActive()` - Transfers background messages to active dialog

### Utility Functions
- `initializeDialog()` - Sets up initial state for new dialogs
- `mergeDialogMessages()` - Intelligently merges message arrays without duplicates
- `preserveStreamingMessage()` - Handles real-time message streaming updates
- `clearDialogData()` - Cleanup for closed dialogs

## Usage Example

```typescript
import { useMingoBackgroundMessagesStore } from './mingo-background-messages-store'

function ChatManager() {
  const {
    addBackgroundMessage,
    setActiveDialogId,
    getUnreadCount,
    moveBackgroundToActive
  } = useMingoBackgroundMessagesStore()

  // Switch to dialog and move background messages
  const openDialog = (dialogId: string) => {
    setActiveDialogId(dialogId)
    const backgroundMessages = moveBackgroundToActive(dialogId)
    // Apply messages to active chat UI
    console.log(`Loaded ${backgroundMessages.length} background messages`)
  }

  // Handle incoming message for inactive dialog
  const handleBackgroundMessage = (dialogId: string, message: Message) => {
    addBackgroundMessage(dialogId, message)
    const unreadCount = getUnreadCount(dialogId)
    // Update UI badge with unread count
  }
}
```

The store implements a 50-message limit per dialog to prevent memory issues and provides seamless message synchronization between active and background conversation states.
