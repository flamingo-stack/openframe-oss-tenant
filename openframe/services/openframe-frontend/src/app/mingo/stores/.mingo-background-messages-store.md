A Zustand store managing background message state for multiple dialog conversations in Mingo AI, handling message storage, unread counts, and typing indicators for non-active dialogs.

## Key Components

- **State Management**: Per-dialog message storage with automatic message limit enforcement (50 messages max)
- **Unread Tracking**: Individual unread counters for each background dialog
- **Typing Indicators**: Background typing status tracking for inactive conversations
- **Active Dialog**: Current dialog selection with seamless switching capabilities
- **Message Operations**: Add, merge, preserve streaming messages with duplicate handling
- **Dialog Lifecycle**: Initialize, clear, and transfer data between background/active states

## Usage Example

}
