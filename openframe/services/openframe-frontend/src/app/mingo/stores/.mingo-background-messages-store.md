A Zustand store that manages message state and UI indicators for background dialogs in Mingo AI, handling per-dialog message storage, unread counts, and typing indicators when dialogs are not actively displayed.

## Key Components

**State Properties:**
- `dialogMessages` - Per-dialog message storage with automatic cleanup (max 50 messages)
- `unreadCounts` - Tracks unread message counts per dialog
- `backgroundTypingIndicators` - Typing status for background dialogs
- `activeDialogId` - Currently active/displayed dialog

**Core Actions:**
- `addBackgroundMessage()` - Adds or updates messages with deduplication
- `setActiveDialogId()` - Sets the currently active dialog
- `incrementUnreadCount()` / `resetUnreadCount()` - Manages unread message counts
- `setBackgroundTyping()` - Updates typing indicators
- `moveBackgroundToActive()` - Transfers background messages to active view
- `preserveStreamingMessage()` - Handles real-time streaming message updates

**Utility Methods:**
- `initializeDialog()` - Sets up new dialog state
- `mergeDialogMessages()` - Merges new messages with existing ones
- `clearDialogData()` - Removes all data for a dialog

## Usage Example

```typescript
import { useMingoBackgroundMessagesStore } from './mingo-background-messages-store'

// Component for managing dialog state
function DialogManager() {
  const {
    activeDialogId,
    setActiveDialogId,
    addBackgroundMessage,
    getUnreadCount,
    moveBackgroundToActive,
    resetUnreadCount
  } = useMingoBackgroundMessagesStore()

  // Switch to a background dialog
  const switchToDialog = (dialogId: string) => {
    // Get background messages before switching
    const backgroundMessages = moveBackgroundToActive(dialogId)
    
    // Reset unread count
    resetUnreadCount(dialogId)
    
    // Set as active
    setActiveDialogId(dialogId)
    
    // Use backgroundMessages to populate active dialog
    return backgroundMessages
  }

  // Add message to background dialog
  const handleBackgroundMessage = (dialogId: string, message: Message) => {
    if (dialogId !== activeDialogId) {
      addBackgroundMessage(dialogId, message)
    }
  }

  return (
    <div>
      {/* Dialog UI with unread indicators */}
      <DialogList 
        unreadCount={getUnreadCount(dialogId)}
        onSwitchDialog={switchToDialog}
      />
    </div>
  )
}
```
