A Zustand store that manages chat messages, dialogs, and real-time communication state for the Mingo AI assistant interface. It provides centralized state management for message storage, streaming updates, approval workflows, and UI states.

## Key Components

**Core State:**
- `messagesByDialog` - Map storing messages organized by dialog ID
- `activeDialogId` - Currently selected dialog
- `dialogs` - Array of available dialog nodes
- `typingStates` - Real-time typing indicators per dialog
- `streamingMessages` - Messages being streamed in real-time
- `segmentAccumulators` - Accumulate message segments for streaming responses

**Message Management Actions:**
- `setMessages`, `addMessage`, `updateMessage`, `removeMessage` - CRUD operations
- `updateApprovalStatusInMessages` - Handle approval workflow updates
- `getMessages` - Retrieve messages for a specific dialog

**Real-time Features:**
- `setTyping`, `getTyping` - Manage typing indicators
- `incrementUnread`, `resetUnread` - Handle unread message counts
- `setStreamingMessage`, `updateStreamingMessageSegments` - Stream message updates
- `getOrCreateAccumulator` - Manage message segment accumulation

**State Management:**
- Loading states for dialogs, messages, and creation operations
- Error handling for dialog and message operations
- Pagination support with cursors

## Usage Example

```typescript
import { useMingoMessagesStore } from './stores/mingo-messages-store'

function ChatComponent() {
  const {
    activeDialogId,
    getMessages,
    addMessage,
    setTyping,
    getUnread
  } = useMingoMessagesStore()

  // Get messages for current dialog
  const messages = activeDialogId ? getMessages(activeDialogId) : []

  // Add a new message
  const sendMessage = (content: string) => {
    if (!activeDialogId) return
    
    const message = {
      id: Date.now().toString(),
      role: 'user' as const,
      content,
      timestamp: new Date().toISOString()
    }
    
    addMessage(activeDialogId, message)
  }

  // Handle typing indicator
  const handleTyping = () => {
    if (activeDialogId) {
      setTyping(activeDialogId, true)
      setTimeout(() => setTyping(activeDialogId, false), 3000)
    }
  }

  return (
    <div>
      {messages.map(msg => <div key={msg.id}>{msg.content}</div>)}
    </div>
  )
}
```
