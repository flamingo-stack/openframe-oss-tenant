A Zustand store that manages the complete state for Mingo's messaging system, handling messages, dialogs, real-time streaming, and user interactions across multiple dialog sessions.

## Key Components

- **MingoMessagesStore Interface** - Complete type definition for the store's state and actions
- **useMingoMessagesStore** - Main Zustand hook with devtools middleware for state management
- **Message Management** - CRUD operations for messages across different dialogs
- **Real-time State** - Typing indicators, unread counts, and streaming message handling
- **Segment Accumulators** - Processing and accumulation of streaming message segments
- **Dialog Management** - Active dialog tracking and dialog list management
- **Loading & Error States** - UI state management for async operations
- **Pagination Support** - Cursor-based pagination for message history
