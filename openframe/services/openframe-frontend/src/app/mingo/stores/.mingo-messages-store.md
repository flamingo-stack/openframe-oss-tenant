Zustand store for managing Mingo AI assistant messages, dialogs, and real-time chat state across multiple conversation threads with support for streaming messages and approval workflows.

## Key Components

**State Management:**
- `messagesByDialog` - Map storing messages for each dialog
- `activeDialogId` - Currently selected conversation
- `dialogs` - Array of available dialog nodes
- `typingStates` - Real-time typing indicators per dialog
- `unreadCounts` - Unread message counters
- `streamingMessages` - Active streaming messages
- `segmentAccumulators` - Message segment processors for streaming content

**Core Actions:**
- `setMessages/addMessage/updateMessage` - Message CRUD operations
- `setTyping/getTyping` - Typing state management
- `incrementUnread/resetUnread` - Unread count tracking
- `setStreamingMessage/updateStreamingMessageSegments` - Streaming message handling
- `getOrCreateAccumulator` - Message segment accumulator management

## Usage Example

```typescript
import { useMingoMessagesStore } from './mingo-messages-store'

function ChatComponent() {
  const {
    activeDialogId,
    getMessages,
    addMessage,
    setTyping,
    getStreamingMessage,
    updateStreamingMessageSegments
  } = useMingoMessagesStore()

  // Get messages for active dialog
  const messages = activeDialogId ? getMessages(activeDialogId) : []

  // Add a new message
  const sendMessage = (content: string) => {
    if (activeDialogId) {
      addMessage(activeDialogId, {
        id: crypto.randomUUID(),
        role: 'user',
        content,
        timestamp: Date.now()
      })
    }
  }

  // Handle streaming message updates
  const handleStreamingSegments = (segments: MessageSegment[]) => {
    if (activeDialogId) {
      updateStreamingMessageSegments(activeDialogId, segments)
    }
  }

  return (
    <div>
      {messages.map(message => (
        <div key={message.id}>{message.content}</div>
      ))}
    </div>
  )
}
```
