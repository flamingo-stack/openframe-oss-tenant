A Zustand state management store for handling Mingo chat messages, dialogs, and real-time messaging features. This store manages the complete messaging lifecycle including streaming messages, approval workflows, and dialog state.

## Key Components

**Core State:**
- `messagesByDialog` - Map storing messages organized by dialog ID
- `activeDialogId` - Currently selected dialog
- `dialogs` - Array of available dialog nodes
- `typingStates` - Real-time typing indicators per dialog
- `streamingMessages` - Active streaming messages per dialog
- `segmentAccumulators` - Message segment processors for streaming content

**Message Management:**
- `setMessages()` / `addMessage()` / `updateMessage()` - CRUD operations for messages
- `updateApprovalStatusInMessages()` - Handle approval request status updates
- `removeWelcomeMessages()` - Clean up initial system messages

**Real-time Features:**
- `setTyping()` / `getTyping()` - Manage typing indicators
- `incrementUnread()` / `resetUnread()` - Handle unread message counts
- `updateStreamingMessageSegments()` - Process streaming message content

**Streaming & Approval System:**
- `getOrCreateAccumulator()` - Create/retrieve message segment accumulators
- `updateAccumulatorApprovalStatus()` - Update approval request statuses
- Integration with `@flamingo-stack/openframe-frontend-core` for segment processing

## Usage Example

```typescript
import { useMingoMessagesStore } from './mingo-messages-store'

function ChatComponent() {
  const {
    messagesByDialog,
    activeDialogId,
    addMessage,
    setTyping,
    getOrCreateAccumulator
  } = useMingoMessagesStore()

  // Add a new message to active dialog
  const sendMessage = (content: string) => {
    if (activeDialogId) {
      addMessage(activeDialogId, {
        id: crypto.randomUUID(),
        role: 'user',
        content,
        timestamp: Date.now()
      })
    }
  }

  // Handle streaming message with approval requests
  const handleStreamingSegments = (segments: MessageSegment[]) => {
    if (activeDialogId) {
      const accumulator = getOrCreateAccumulator(activeDialogId, {
        onApprove: (requestId) => console.log('Approved:', requestId),
        onReject: (requestId) => console.log('Rejected:', requestId)
      })
      
      updateStreamingMessageSegments(activeDialogId, segments)
    }
  }

  // Get messages for active dialog
  const messages = activeDialogId ? messagesByDialog.get(activeDialogId) || [] : []

  return <div>{/* Chat UI */}</div>
}
```
