This file manages the global state for Mingo chat messages using Zustand, providing comprehensive storage and real-time management for multi-dialog conversations.

## Key Components

- **MingoMessagesStore Interface** - Comprehensive state management interface for chat dialogs
- **useMingoMessagesStore** - Zustand store hook with devtools integration
- **Map-based Storage** - Efficient storage using Maps for messages, typing states, and streaming data
- **Message Segment Accumulators** - Real-time message processing for streaming content
- **Approval System Integration** - Built-in approval request handling for tool executions

## Usage Example

```typescript
import { useMingoMessagesStore } from './mingo-messages-store'

// Basic message management
const MessagesComponent = () => {
  const { 
    activeDialogId, 
    setActiveDialogId, 
    addMessage, 
    getMessages,
    setTyping 
  } = useMingoMessagesStore()
  
  // Get messages for active dialog
  const messages = activeDialogId ? getMessages(activeDialogId) : []
  
  // Add new message
  const handleSendMessage = (content: string) => {
    if (!activeDialogId) return
    
    const message = {
      id: crypto.randomUUID(),
      role: 'user' as const,
      content,
      timestamp: new Date().toISOString()
    }
    
    addMessage(activeDialogId, message)
  }
  
  return <div>{/* Chat UI */}</div>
}

// Real-time streaming
const StreamingHandler = () => {
  const { 
    getOrCreateAccumulator,
    updateStreamingMessageSegments,
    setStreamingMessage 
  } = useMingoMessagesStore()
  
  const handleStreamUpdate = (dialogId: string, segments: MessageSegment[]) => {
    // Get accumulator with approval handlers
    const accumulator = getOrCreateAccumulator(dialogId, {
      onApprove: (requestId) => console.log('Approved:', requestId),
      onReject: (requestId) => console.log('Rejected:', requestId)
    })
    
    // Update streaming message with processed segments
    updateStreamingMessageSegments(dialogId, segments)
  }
  
  return null
}
```

The store handles dialog switching, message persistence, typing indicators, unread counts, streaming message updates, and approval request workflows with automatic state synchronization across the application.
