A Zustand store that manages Mingo AI chat messages, dialogs, and real-time communication state across multiple conversations with comprehensive streaming and approval workflow support.

## Key Components

- **MingoMessagesStore Interface**: Comprehensive store interface defining message management, dialog state, real-time features, and streaming capabilities
- **useMingoMessagesStore Hook**: Zustand store implementation with devtools support for state debugging
- **Message Management**: CRUD operations for messages across multiple dialogs with Map-based storage
- **Real-time State**: Typing indicators, unread counts, and streaming message handling
- **Segment Accumulators**: Integration with OpenFrame's message segment processing for tool executions and approval requests
- **Approval Workflows**: Built-in support for command approval/rejection with status tracking

## Usage Example

```typescript
import { useMingoMessagesStore } from './mingo-messages-store'

// Basic message operations
const {
  activeDialogId,
  setActiveDialogId,
  addMessage,
  getMessages,
  setTyping,
  incrementUnread
} = useMingoMessagesStore()

// Switch to a dialog
setActiveDialogId('dialog-123')

// Add a new message
addMessage('dialog-123', {
  id: 'msg-456',
  role: 'user',
  content: 'Hello Mingo!',
  timestamp: new Date().toISOString()
})

// Handle streaming message with segments
const accumulator = getOrCreateAccumulator('dialog-123', {
  onApprove: (requestId) => console.log('Approved:', requestId),
  onReject: (requestId) => console.log('Rejected:', requestId)
})

// Update streaming message segments
updateStreamingMessageSegments('dialog-123', [
  { type: 'text', text: 'Processing...' },
  { type: 'tool_execution', data: { tool: 'deploy', status: 'running' } }
])

// Handle typing and unread states
setTyping('dialog-123', true)
incrementUnread('dialog-456')
```
