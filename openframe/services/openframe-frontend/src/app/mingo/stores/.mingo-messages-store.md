A Zustand store managing messages, dialogs, and real-time chat state for the Mingo AI assistant interface. It handles message streaming, typing indicators, approval workflows, and message segment accumulation across multiple dialog sessions.

## Key Components

**Store Interface:**
- `MingoMessagesStore` - Complete type definition for the store state and actions
- `useMingoMessagesStore` - Main Zustand hook for accessing the store

**Core State Maps:**
- `messagesByDialog` - Messages organized by dialog ID
- `typingStates` - Real-time typing indicators per dialog
- `streamingMessages` - Currently streaming messages
- `segmentAccumulators` - Message segment processors for real-time content

**Key Actions:**
- `addMessage()` / `updateMessage()` - Message CRUD operations
- `setTyping()` / `incrementUnread()` - Real-time state management
- `updateStreamingMessageSegments()` - Process streaming message content
- `updateApprovalStatusInMessages()` - Handle approval workflow responses

## Usage Example

```typescript
import { useMingoMessagesStore } from './mingo-messages-store'

function ChatComponent({ dialogId }: { dialogId: string }) {
  const {
    getMessages,
    addMessage,
    setTyping,
    getStreamingMessage,
    updateStreamingMessageSegments
  } = useMingoMessagesStore()

  const messages = getMessages(dialogId)
  const streamingMessage = getStreamingMessage(dialogId)

  // Add a new message
  const handleSendMessage = (content: string) => {
    addMessage(dialogId, {
      id: 'msg-123',
      role: 'user',
      content: [{ type: 'text', text: content }],
      timestamp: new Date().toISOString()
    })
  }

  // Handle streaming updates
  const handleStreamUpdate = (segments: MessageSegment[]) => {
    updateStreamingMessageSegments(dialogId, segments)
  }

  return (
    <div>
      {messages.map(msg => <MessageItem key={msg.id} message={msg} />)}
      {streamingMessage && <StreamingMessage message={streamingMessage} />}
    </div>
  )
}
```

The store integrates with OpenFrame's message segment system to handle complex message types including tool executions, approval requests, and real-time streaming content with proper state synchronization across dialog sessions.
