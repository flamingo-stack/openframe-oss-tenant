This TypeScript file implements a comprehensive Zustand store for managing messages and dialogs in the Mingo AI chat interface, handling real-time messaging, streaming responses, and approval workflows.

## Key Components

### Store State
- **messagesByDialog**: Map storing messages organized by dialog ID
- **activeDialogId**: Currently active dialog identifier
- **dialogs**: Array of available dialog nodes
- **typingStates**: Real-time typing indicators per dialog
- **unreadCounts**: Unread message counters per dialog
- **streamingMessages**: Active streaming message state per dialog
- **segmentAccumulators**: Message segment processors for streaming content
- **Loading/Error States**: UI state management for async operations
- **Pagination**: Cursor-based message pagination support

### Core Actions
- **Message Management**: CRUD operations for messages with dialog isolation
- **Real-time State**: Typing indicators, unread counts, streaming message handling
- **Segment Processing**: Advanced message content accumulation with approval request handling
- **Dialog Management**: Active dialog switching and state management
- **Utility Functions**: Cleanup, reset, and maintenance operations

## Usage Example

```typescript
import { useMingoMessagesStore } from './mingo-messages-store'

function ChatComponent() {
  const {
    activeDialogId,
    getMessages,
    addMessage,
    setTyping,
    getOrCreateAccumulator,
    updateStreamingMessageSegments
  } = useMingoMessagesStore()

  // Get messages for active dialog
  const messages = activeDialogId ? getMessages(activeDialogId) : []

  // Add a new message
  const sendMessage = (content: string) => {
    if (activeDialogId) {
      const message = {
        id: crypto.randomUUID(),
        role: 'user',
        content,
        timestamp: new Date().toISOString()
      }
      addMessage(activeDialogId, message)
    }
  }

  // Handle streaming response with approval handlers
  const handleStreamingResponse = (segments: MessageSegment[]) => {
    if (activeDialogId) {
      const accumulator = getOrCreateAccumulator(activeDialogId, {
        onApprove: (requestId) => console.log('Approved:', requestId),
        onReject: (requestId) => console.log('Rejected:', requestId)
      })
      updateStreamingMessageSegments(activeDialogId, segments)
    }
  }

  return (
    <div>
      {messages.map(message => (
        <div key={message.id}>{message.content}</div>
      ))}
    </div>
  )
}
```
