A centralized Zustand store for managing Mingo AI chat messages, dialogs, and real-time streaming states across the OpenFrame platform.

## Key Components

### Core State
- **messagesByDialog** - Map storing messages organized by dialog ID
- **activeDialogId** - Currently selected dialog
- **dialogs** - Array of available dialog nodes
- **streamingMessages** - Real-time message streaming state per dialog
- **segmentAccumulators** - Message segment processors for streaming content

### Real-time Features
- **typingStates** - Track typing indicators per dialog
- **unreadCounts** - Unread message counters
- **Streaming support** - Handle real-time message segments and tool executions
- **Approval requests** - Manage command approval workflows

### State Management Actions
- Message CRUD operations (add, update, remove, get)
- Dialog management (set active, clear, reset)
- Real-time state updates (typing, unread counts)
- Streaming message processing with segment accumulation
- Loading and error state management
- Pagination support for message history

## Usage Example

```typescript
import { useMingoMessagesStore } from './mingo-messages-store'

function ChatComponent() {
  const {
    activeDialogId,
    getMessages,
    addMessage,
    setTyping,
    getStreamingMessage,
    updateStreamingMessageSegments
  } = useMingoMessagesStore()

  // Get messages for current dialog
  const messages = activeDialogId ? getMessages(activeDialogId) : []

  // Add new message
  const handleNewMessage = (message: Message) => {
    if (activeDialogId) {
      addMessage(activeDialogId, message)
    }
  }

  // Handle streaming updates
  const handleStreamingUpdate = (segments: MessageSegment[]) => {
    if (activeDialogId) {
      updateStreamingMessageSegments(activeDialogId, segments)
    }
  }

  return (
    <div>
      {messages.map(message => (
        <MessageComponent key={message.id} message={message} />
      ))}
    </div>
  )
}
```
