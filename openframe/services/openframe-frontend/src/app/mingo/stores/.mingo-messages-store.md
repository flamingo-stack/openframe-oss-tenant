This TypeScript file creates a Zustand store for managing Mingo chat dialog messages, providing centralized state management for real-time messaging, streaming responses, and user interactions in the Flamingo AI platform.

## Key Components

**Core State Management:**
- `messagesByDialog` - Map storing messages organized by dialog ID
- `activeDialogId` - Currently selected dialog identifier
- `dialogs` - Array of available dialog nodes
- `typingStates` - Real-time typing indicators per dialog
- `streamingMessages` - Active streaming message state
- `segmentAccumulators` - Message segment processors for structured content

**Message Operations:**
- `addMessage()` - Add new message to dialog
- `updateMessage()` - Modify existing message content
- `setMessages()` - Replace entire message collection
- `updateApprovalStatusInMessages()` - Handle approval workflow updates

**Real-time Features:**
- `setTyping()` / `getTyping()` - Manage typing indicators
- `incrementUnread()` / `resetUnread()` - Track unread message counts
- `updateStreamingMessageSegments()` - Process streaming AI responses

## Usage Example

```typescript
import { useMingoMessagesStore } from './mingo-messages-store'

function ChatComponent() {
  const {
    messages,
    activeDialogId,
    addMessage,
    setTyping,
    getOrCreateAccumulator
  } = useMingoMessagesStore()

  // Add a new user message
  const sendMessage = (text: string) => {
    if (!activeDialogId) return
    
    const message = {
      id: crypto.randomUUID(),
      role: 'user' as const,
      content: text,
      timestamp: new Date()
    }
    
    addMessage(activeDialogId, message)
  }

  // Handle streaming AI responses
  const handleStreamingResponse = (segments: MessageSegment[]) => {
    if (!activeDialogId) return
    
    const accumulator = getOrCreateAccumulator(activeDialogId, {
      onApprove: (requestId) => console.log('Approved:', requestId),
      onReject: (requestId) => console.log('Rejected:', requestId)
    })
    
    updateStreamingMessageSegments(activeDialogId, segments)
  }

  return (
    <div>
      {/* Chat interface */}
    </div>
  )
}
```
