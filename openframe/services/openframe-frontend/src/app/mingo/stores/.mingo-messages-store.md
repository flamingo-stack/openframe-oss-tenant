This file provides a comprehensive Zustand store for managing Mingo AI chat messages, dialogs, and real-time communication state. It handles message persistence per dialog, streaming message updates, approval workflows, and UI state management.

## Key Components

**Core State**
- `messagesByDialog` - Map storing messages organized by dialog ID
- `activeDialogId` - Currently selected dialog
- `dialogs` - Array of available dialog nodes
- `typingStates` - Real-time typing indicators per dialog
- `unreadCounts` - Unread message counts per dialog
- `streamingMessages` - Currently streaming messages per dialog
- `segmentAccumulators` - Message segment processors for real-time updates

**State Management Actions**
- `setMessages()`, `addMessage()`, `updateMessage()` - Message CRUD operations
- `setTyping()`, `incrementUnread()`, `resetUnread()` - Real-time state updates
- `setStreamingMessage()`, `updateStreamingMessageSegments()` - Streaming message handling
- `getOrCreateAccumulator()` - Segment accumulator management for approval workflows
- `updateApprovalStatusInMessages()` - Handle approval request status updates

**Loading & Error States**
- `isLoadingDialog`, `isLoadingMessages`, `isCreatingDialog` - Loading indicators
- `dialogError`, `messagesError` - Error state management
- `hasMoreMessages`, `messagesCursor` - Pagination support

## Usage Example

```typescript
import { useMingoMessagesStore } from './mingo-messages-store'

// Component usage
const ChatComponent = () => {
  const { 
    messages, 
    activeDialogId, 
    addMessage, 
    setTyping,
    getOrCreateAccumulator
  } = useMingoMessagesStore()

  // Add new message
  const handleSendMessage = (content: string) => {
    if (activeDialogId) {
      addMessage(activeDialogId, {
        id: generateId(),
        role: 'user',
        content,
        timestamp: new Date()
      })
    }
  }

  // Handle streaming updates with approval workflow
  const handleStreamingUpdate = (segments: MessageSegment[]) => {
    if (activeDialogId) {
      const accumulator = getOrCreateAccumulator(activeDialogId, {
        onApprove: (requestId) => handleApproval(requestId, 'approved'),
        onReject: (requestId) => handleApproval(requestId, 'rejected')
      })
      updateStreamingMessageSegments(activeDialogId, segments)
    }
  }
}
```
