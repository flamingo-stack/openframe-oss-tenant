A Zustand store for managing real-time chat messages and dialog state in the Mingo AI assistant interface. Provides centralized state management for multi-dialog conversations with streaming message support, typing indicators, and approval workflows.

## Key Components

### Core State
- **messagesByDialog**: Map storing messages indexed by dialog ID
- **activeDialogId**: Currently active dialog identifier
- **dialogs**: Array of available dialog nodes
- **typingStates**: Real-time typing indicators per dialog
- **unreadCounts**: Unread message counts per dialog
- **streamingMessages**: Active streaming messages per dialog
- **segmentAccumulators**: Message segment processors for real-time updates

### Message Management Actions
- **setMessages/addMessage/updateMessage**: CRUD operations for messages
- **updateApprovalStatusInMessages**: Handle approval request status updates
- **removeWelcomeMessages**: Clean up onboarding messages
- **getMessages**: Retrieve messages for a specific dialog

### Real-time Features
- **setTyping/getTyping**: Manage typing indicators
- **incrementUnread/resetUnread**: Handle unread message counts
- **setStreamingMessage**: Track actively streaming messages
- **updateStreamingMessageSegments**: Process streaming message segments in real-time

### Segment Accumulator Management
- **getOrCreateAccumulator**: Create or retrieve message segment processors
- **resetAccumulator**: Clear accumulator state
- **updateAccumulatorApprovalStatus**: Update approval states in accumulators

## Usage Example

```typescript
import { useMingoMessagesStore } from './mingo-messages-store'

function ChatComponent() {
  const {
    activeDialogId,
    setActiveDialogId,
    addMessage,
    getMessages,
    setTyping,
    getOrCreateAccumulator
  } = useMingoMessagesStore()

  // Switch to a dialog
  const switchDialog = (dialogId: string) => {
    setActiveDialogId(dialogId)
    resetUnread(dialogId)
  }

  // Add a new message
  const sendMessage = (content: string) => {
    if (!activeDialogId) return
    
    const message = {
      id: crypto.randomUUID(),
      role: 'user' as const,
      content: [{ type: 'text' as const, text: content }],
      timestamp: new Date().toISOString()
    }
    
    addMessage(activeDialogId, message)
  }

  // Handle streaming messages
  const handleStreamingResponse = () => {
    if (!activeDialogId) return
    
    const accumulator = getOrCreateAccumulator(activeDialogId, {
      onApprove: (requestId) => console.log('Approved:', requestId),
      onReject: (requestId) => console.log('Rejected:', requestId)
    })
    
    setTyping(activeDialogId, true)
    // Process streaming segments...
  }

  const messages = activeDialogId ? getMessages(activeDialogId) : []
  
  return (
    <div>
      {messages.map(message => (
        <MessageComponent key={message.id} message={message} />
      ))}
    </div>
  )
}
```
