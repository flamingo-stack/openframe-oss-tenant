A Zustand store that manages chat conversations and real-time messaging state for the Mingo AI assistant. It handles message storage per dialog, streaming message updates, typing indicators, and approval request workflows.

## Key Components

- **Message Storage**: `messagesByDialog` Map storing messages organized by dialog ID
- **Dialog Management**: `activeDialogId`, `dialogs` array for conversation threads
- **Real-time State**: `typingStates`, `unreadCounts`, `streamingMessages` for live updates
- **Segment Processing**: `segmentAccumulators` for handling streaming message segments
- **Loading/Error States**: Boolean flags and error messages for UI feedback
- **Pagination**: Cursor-based message loading with `hasMoreMessages`, `messagesCursor`

## Usage Example

```typescript
import { useMingoMessagesStore } from './mingo-messages-store'

function ChatComponent() {
  const {
    activeDialogId,
    getMessages,
    addMessage,
    setTyping,
    getStreamingMessage,
    updateStreamingMessageSegments
  } = useMingoMessagesStore()

  // Get messages for current dialog
  const messages = activeDialogId ? getMessages(activeDialogId) : []

  // Add a new message
  const sendMessage = (content: string) => {
    if (activeDialogId) {
      addMessage(activeDialogId, {
        id: crypto.randomUUID(),
        role: 'user',
        content,
        timestamp: new Date().toISOString()
      })
    }
  }

  // Handle streaming updates
  const handleStreamingSegments = (segments: MessageSegment[]) => {
    if (activeDialogId) {
      updateStreamingMessageSegments(activeDialogId, segments)
    }
  }

  // Set typing indicator
  const handleTyping = (isTyping: boolean) => {
    if (activeDialogId) {
      setTyping(activeDialogId, isTyping)
    }
  }
}
```

The store integrates with OpenFrame's message segment system for handling complex AI responses including tool executions and approval requests.
