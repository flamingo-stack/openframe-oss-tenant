This TypeScript file implements a centralized Zustand store for managing chat messages and dialog state in the Mingo AI assistant interface. It provides comprehensive state management for real-time messaging, streaming responses, approval workflows, and multi-dialog conversations.

## Key Components

### State Management
- **messagesByDialog**: Map storing messages organized by dialog ID
- **activeDialogId**: Currently selected dialog identifier
- **dialogs**: Array of available dialog nodes
- **typingStates**: Real-time typing indicators per dialog
- **unreadCounts**: Unread message counters per dialog
- **streamingMessages**: Active streaming message state per dialog
- **segmentAccumulators**: Message segment processors for streaming content

### Core Actions
- **Message CRUD**: `addMessage`, `updateMessage`, `removeMessage`, `setMessages`
- **Dialog Management**: `setActiveDialogId`, `setDialogs`, `clearDialog`
- **Real-time State**: `setTyping`, `incrementUnread`, `resetUnread`
- **Streaming**: `setStreamingMessage`, `updateStreamingMessageSegments`
- **Approval Workflow**: `updateApprovalStatusInMessages`, `updateAccumulatorApprovalStatus`

### Loading & Error States
- Loading indicators for dialogs, messages, and dialog creation
- Error state management for both dialogs and messages
- Pagination support with cursors and `hasMoreMessages`

## Usage Example

```typescript
import { useMingoMessagesStore } from './mingo-messages-store'

function ChatComponent() {
  const {
    activeDialogId,
    getMessages,
    addMessage,
    setTyping,
    getStreamingMessage,
    incrementUnread
  } = useMingoMessagesStore()

  // Get messages for active dialog
  const messages = activeDialogId ? getMessages(activeDialogId) : []

  // Add a new message
  const sendMessage = (content: string) => {
    if (!activeDialogId) return
    
    const message = {
      id: crypto.randomUUID(),
      role: 'user' as const,
      content,
      timestamp: new Date().toISOString()
    }
    
    addMessage(activeDialogId, message)
  }

  // Handle streaming message updates
  const streamingMessage = activeDialogId ? getStreamingMessage(activeDialogId) : null

  return (
    <div>
      {messages.map(msg => <Message key={msg.id} message={msg} />)}
      {streamingMessage && <StreamingMessage message={streamingMessage} />}
    </div>
  )
}
```
