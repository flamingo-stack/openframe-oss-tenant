This TypeScript file implements a comprehensive Zustand store for managing Mingo (AI assistant) chat messages and dialog states. It provides centralized state management for real-time messaging, streaming responses, approval workflows, and multi-dialog conversations.

## Key Components

**Store Interface (`MingoMessagesStore`):**
- **Message Management**: Unified storage with dialog-based message organization
- **Dialog State**: Active dialog tracking and dialog tree management
- **Real-time Features**: Typing indicators, unread counts, and streaming message handling
- **Segment Processing**: Message segment accumulators for processing streamed content
- **Loading/Error States**: Comprehensive state management for async operations
- **Pagination**: Cursor-based message pagination support

**Core Store (`useMingoMessagesStore`):**
- **Message CRUD**: Add, update, remove, and retrieve messages by dialog
- **Streaming Support**: Real-time message streaming with segment accumulation
- **Approval Workflow**: Handle approval requests within message segments
- **State Utilities**: Typing states, unread counters, and dialog management

## Usage Example

```typescript
import { useMingoMessagesStore } from './mingo-messages-store'

// In a React component
function ChatInterface() {
  const {
    activeDialogId,
    getMessages,
    addMessage,
    setTyping,
    getStreamingMessage,
    updateStreamingMessageSegments
  } = useMingoMessagesStore()
  
  // Get messages for active dialog
  const messages = activeDialogId ? getMessages(activeDialogId) : []
  
  // Handle incoming streaming segments
  const handleStreamSegments = (dialogId: string, segments: MessageSegment[]) => {
    updateStreamingMessageSegments(dialogId, segments)
  }
  
  // Add a new user message
  const sendMessage = (text: string) => {
    if (!activeDialogId) return
    
    const newMessage: Message = {
      id: crypto.randomUUID(),
      role: 'user',
      content: text,
      timestamp: new Date().toISOString()
    }
    
    addMessage(activeDialogId, newMessage)
  }
  
  return (
    <div>
      {messages.map(message => (
        <MessageComponent key={message.id} message={message} />
      ))}
    </div>
  )
}
```
