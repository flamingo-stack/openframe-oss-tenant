A Zustand store that manages comprehensive chat message state for the Mingo AI assistant interface, including real-time messaging, streaming responses, approval workflows, and dialog management.

## Key Components

- **MingoMessagesStore**: Main store interface with complete message and dialog state management
- **useMingoMessagesStore**: Zustand store hook with devtools integration
- **Message Management**: CRUD operations for messages across multiple dialogs
- **Real-time Features**: Typing indicators, unread counts, and streaming message handling
- **Segment Accumulators**: Advanced message processing for tool executions and approval requests
- **State Management**: Loading states, error handling, and pagination support
