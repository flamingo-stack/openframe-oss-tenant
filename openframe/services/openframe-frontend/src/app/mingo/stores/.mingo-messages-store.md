A Zustand store for managing Mingo AI chat messages, dialogs, and real-time streaming state. This store provides centralized state management for the AI assistant interface with support for multi-dialog conversations, streaming messages, and approval workflows.

## Key Components

### Core State
- **messagesByDialog**: Map storing messages organized by dialog ID
- **activeDialogId**: Currently selected dialog
- **dialogs**: Array of available dialog nodes
- **typingStates**: Real-time typing indicators per dialog
- **unreadCounts**: Unread message counts per dialog
- **streamingMessages**: Active streaming messages per dialog
- **segmentAccumulators**: Message segment processors for real-time updates

### Message Management Actions
- **setMessages/addMessage/updateMessage**: CRUD operations for messages
- **updateApprovalStatusInMessages**: Handle approval workflow updates
- **removeWelcomeMessages**: Clean up initial messages

### Real-time Features
- **setTyping/getTyping**: Manage typing indicators
- **incrementUnread/resetUnread**: Handle unread counts
- **setStreamingMessage/updateStreamingMessageSegments**: Process streaming AI responses

### Segment Accumulator Management
- **getOrCreateAccumulator**: Create or retrieve message segment processors
- **updateAccumulatorApprovalStatus**: Handle approval status changes in real-time streams

## Usage Example

```typescript
import { useMingoMessagesStore } from './mingo-messages-store'

function ChatComponent() {
  const {
    activeDialogId,
    getMessages,
    addMessage,
    setStreamingMessage,
    getOrCreateAccumulator
  } = useMingoMessagesStore()

  // Get messages for active dialog
  const messages = activeDialogId ? getMessages(activeDialogId) : []

  // Add new user message
  const sendMessage = (content: string) => {
    if (!activeDialogId) return
    
    const message = {
      id: crypto.randomUUID(),
      role: 'user' as const,
      content,
      timestamp: new Date().toISOString()
    }
    
    addMessage(activeDialogId, message)
  }

  // Handle streaming AI response
  const handleStreamingResponse = (segments: MessageSegment[]) => {
    if (!activeDialogId) return
    
    const accumulator = getOrCreateAccumulator(activeDialogId, {
      onApprove: (requestId) => console.log('Approved:', requestId),
      onReject: (requestId) => console.log('Rejected:', requestId)
    })
    
    // Process segments and update streaming message
    updateStreamingMessageSegments(activeDialogId, segments)
  }

  return (
    <div>
      {messages.map(message => (
        <MessageComponent key={message.id} message={message} />
      ))}
    </div>
  )
}
```
