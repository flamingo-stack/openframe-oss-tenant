This TypeScript file implements a centralized Zustand store for managing messages and dialog state in the Mingo AI chat interface. It provides comprehensive state management for real-time messaging, streaming responses, user approval workflows, and multi-dialog conversation handling.

## Key Components

- **MingoMessagesStore Interface**: Defines the complete state structure and actions for message management
- **useMingoMessagesStore**: Main Zustand store hook with devtools integration
- **Message Management**: CRUD operations for messages across multiple dialogs
- **Real-time Features**: Typing indicators, unread counts, and streaming message handling
- **Approval System**: Manages user approval workflows for AI-suggested actions
- **Segment Accumulators**: Processes streaming message segments from the OpenFrame core

## Usage Example

```typescript
import { useMingoMessagesStore } from './mingo-messages-store'

function ChatComponent() {
  const {
    activeDialogId,
    getMessages,
    addMessage,
    setTyping,
    getStreamingMessage,
    getOrCreateAccumulator
  } = useMingoMessagesStore()

  // Get messages for current dialog
  const messages = getMessages(activeDialogId || '')

  // Add a new message
  const handleSendMessage = (content: string) => {
    addMessage(activeDialogId!, {
      id: crypto.randomUUID(),
      role: 'user',
      content: [{ type: 'text', text: content }],
      timestamp: new Date().toISOString()
    })
  }

  // Handle streaming responses
  const accumulator = getOrCreateAccumulator(activeDialogId!, {
    onApprove: (requestId) => console.log('Approved:', requestId),
    onReject: (requestId) => console.log('Rejected:', requestId)
  })

  return (
    <div>
      {messages.map(msg => (
        <div key={msg.id}>{/* Render message */}</div>
      ))}
    </div>
  )
}
```
