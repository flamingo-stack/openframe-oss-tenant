A centralized Zustand store for managing Mingo AI chat messages, dialogs, and real-time streaming state across the application. Handles message persistence, typing indicators, unread counts, and streaming message accumulation with approval workflows.

## Key Components

- **MingoMessagesStore Interface**: Complete type definitions for store state and actions
- **useMingoMessagesStore**: Main Zustand store hook with devtools integration
- **Message Management**: CRUD operations for messages across multiple dialogs
- **Real-time State**: Typing indicators, unread counts, and streaming message handling
- **Segment Accumulators**: Process streaming message segments with approval request handling
- **Dialog Management**: Active dialog tracking and dialog tree navigation
- **Error & Loading States**: Comprehensive state management for async operations

      ))}
    </div>
  )
}
