This Zustand store manages chat dialog state for Mingo AI, providing centralized message storage, real-time streaming, and approval workflow management across multiple conversations.

## Key Components

**Main Store Interface:**
- `MingoMessagesStore` - Complete store interface with state and actions
- `useMingoMessagesStore` - Zustand store hook with devtools integration

**Core State Management:**
- `messagesByDialog` - Map storing messages per dialog ID
- `activeDialogId` - Currently selected conversation
- `dialogs` - Available dialog nodes
- `streamingMessages` - Real-time message streaming state
- `segmentAccumulators` - Message segment processing for streaming

**Real-time Features:**
- `typingStates` - Track typing indicators per dialog
- `unreadCounts` - Unread message counters
- Loading and error states for async operations
- Pagination support with cursors

## Usage Example

```typescript
import { useMingoMessagesStore } from './stores/mingo-messages-store'

function ChatComponent() {
  const {
    activeDialogId,
    getMessages,
    addMessage,
    setTyping,
    getStreamingMessage,
    updateStreamingMessageSegments
  } = useMingoMessagesStore()

  // Get messages for current dialog
  const messages = activeDialogId ? getMessages(activeDialogId) : []
  
  // Add new message
  const handleNewMessage = (message: Message) => {
    if (activeDialogId) {
      addMessage(activeDialogId, message)
    }
  }

  // Handle streaming updates
  const handleStreamUpdate = (segments: MessageSegment[]) => {
    if (activeDialogId) {
      updateStreamingMessageSegments(activeDialogId, segments)
    }
  }

  return (
    <div>
      {messages.map(msg => (
        <MessageComponent key={msg.id} message={msg} />
      ))}
    </div>
  )
}
```

The store integrates with OpenFrame's message segment system for handling complex streaming responses with tool executions and approval requests.
