This TypeScript file defines a comprehensive Zustand store for managing Mingo AI messages, dialogs, and real-time chat functionality. It provides centralized state management for chat conversations, streaming messages, user interactions, and approval workflows.

## Key Components

- **MingoMessagesStore Interface**: Defines the complete store structure with message management, dialog state, real-time features, and UI states
- **useMingoMessagesStore**: Main Zustand store hook with devtools integration
- **Message Management**: CRUD operations for messages across multiple dialogs
- **Real-time Features**: Typing indicators, unread counts, and streaming message support
- **Approval Workflow**: Handles approval requests with status tracking
- **MessageSegmentAccumulator**: Integration with OpenFrame core for processing message segments
- **Pagination Support**: Cursor-based pagination for message history
- **Loading & Error States**: Comprehensive state management for async operations

## Usage Example

```typescript
import { useMingoMessagesStore } from './mingo-messages-store'

// In a React component
function ChatDialog({ dialogId }: { dialogId: string }) {
  const {
    getMessages,
    addMessage,
    setTyping,
    getTyping,
    setStreamingMessage,
    getOrCreateAccumulator
  } = useMingoMessagesStore()
  
  const messages = getMessages(dialogId)
  const isTyping = getTyping(dialogId)
  
  // Add a new message
  const sendMessage = (content: string) => {
    addMessage(dialogId, {
      id: crypto.randomUUID(),
      role: 'user',
      content: [{ type: 'text', text: content }],
      timestamp: new Date().toISOString()
    })
  }
  
  // Handle streaming with approval support
  const accumulator = getOrCreateAccumulator(dialogId, {
    onApprove: (requestId) => console.log('Approved:', requestId),
    onReject: (requestId) => console.log('Rejected:', requestId)
  })
  
  return (
    <div>
      {messages.map(msg => <MessageComponent key={msg.id} message={msg} />)}
      {isTyping && <TypingIndicator />}
    </div>
  )
}
```
