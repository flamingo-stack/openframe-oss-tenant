A Zustand-based store for managing chat messages, dialogs, and real-time interactions in the Mingo AI assistant interface. This store handles message streaming, approval workflows, typing indicators, and unread counts across multiple dialog sessions.

## Key Components

**State Management:**
- `messagesByDialog` - Map storing messages indexed by dialog ID
- `activeDialogId` - Currently selected dialog
- `dialogs` - Available dialog sessions
- `streamingMessages` - Real-time message updates during AI responses
- `segmentAccumulators` - Process message segments for tool executions and approvals

**Real-time Features:**
- `typingStates` - Track typing indicators per dialog
- `unreadCounts` - Manage unread message counts
- `updateStreamingMessageSegments` - Handle live message updates with tool execution and approval requests

**Core Actions:**
- Message CRUD operations (`addMessage`, `updateMessage`, `removeMessage`)
- Dialog management (`setActiveDialogId`, `setDialogs`)
- Approval workflow handling (`updateApprovalStatusInMessages`)
- Loading and error state management
