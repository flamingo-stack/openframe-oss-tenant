A Zustand store for managing chat messages, dialogs, and real-time messaging state in the Mingo AI assistant interface. Handles message streaming, approval workflows, and multi-dialog communication.

## Key Components

- **MingoMessagesStore**: Main store interface with comprehensive message and dialog state management
- **Message Storage**: Map-based storage for messages organized by dialog ID
- **Real-time Features**: Typing indicators, unread counts, and message streaming
- **Segment Accumulators**: Handles streaming message content with tool executions and approval requests
- **State Management**: Loading states, error handling, and pagination support

## Usage Example

```typescript
import { useMingoMessagesStore } from './mingo-messages-store'

// In a React component
function ChatInterface() {
  const {
    activeDialogId,
    getMessages,
    addMessage,
    setActiveDialogId,
    getTyping,
    getUnread,
    updateStreamingMessageSegments
  } = useMingoMessagesStore()

  // Get messages for active dialog
  const messages = activeDialogId ? getMessages(activeDialogId) : []
  
  // Add new message
  const handleSendMessage = (content: string) => {
    if (!activeDialogId) return
    
    const newMessage = {
      id: crypto.randomUUID(),
      role: 'user' as const,
      content,
      timestamp: new Date().toISOString()
    }
    
    addMessage(activeDialogId, newMessage)
  }

  // Handle streaming updates
  const handleStreamUpdate = (segments: MessageSegment[]) => {
    if (activeDialogId) {
      updateStreamingMessageSegments(activeDialogId, segments)
    }
  }

  return (
    <div>
      {messages.map(msg => (
        <MessageComponent key={msg.id} message={msg} />
      ))}
      {getTyping(activeDialogId || '') && <TypingIndicator />}
    </div>
  )
}
```

The store provides a complete solution for managing complex chat interactions with support for approval workflows, real-time streaming, and multi-dialog conversations typical in AI assistant applications.
