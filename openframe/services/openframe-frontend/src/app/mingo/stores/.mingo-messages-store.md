This TypeScript file implements a comprehensive Zustand store for managing Mingo (AI assistant) chat messages, dialogs, and real-time communication state. It provides centralized state management for the chat interface with support for message streaming, typing indicators, and approval workflows.

## Key Components

**Store Interface:**
- `MingoMessagesStore` - Main store interface defining all state and actions
- `useMingoMessagesStore` - Zustand store hook with devtools integration

**Core State Management:**
- `messagesByDialog` - Map storing messages by dialog ID
- `activeDialogId` - Currently active chat dialog
- `dialogs` - Array of available dialog nodes
- `streamingMessages` - Real-time message streaming state
- `segmentAccumulators` - Message segment processors for streaming content

**Real-time Features:**
- `typingStates` - Typing indicators per dialog
- `unreadCounts` - Unread message counters
- Loading and error states for UI feedback
- Pagination support with cursors

## Usage Example

```typescript
import { useMingoMessagesStore } from './mingo-messages-store'

function ChatComponent() {
  const {
    activeDialogId,
    getMessages,
    addMessage,
    setTyping,
    getStreamingMessage,
    setActiveDialogId
  } = useMingoMessagesStore()

  // Get messages for active dialog
  const messages = activeDialogId ? getMessages(activeDialogId) : []
  
  // Add new message
  const handleSendMessage = (content: string) => {
    if (activeDialogId) {
      addMessage(activeDialogId, {
        id: crypto.randomUUID(),
        role: 'user',
        content,
        timestamp: new Date().toISOString()
      })
    }
  }

  // Handle streaming message updates
  const streamingMessage = activeDialogId ? getStreamingMessage(activeDialogId) : null

  return (
    <div>
      {messages.map(message => (
        <MessageComponent key={message.id} message={message} />
      ))}
      {streamingMessage && <StreamingMessage message={streamingMessage} />}
    </div>
  )
}
```

The store integrates with OpenFrame's message segment system for handling complex AI responses including tool executions and approval requests, making it ideal for AI-powered MSP platforms.
