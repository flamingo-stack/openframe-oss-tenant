This Zustand store manages unified message state for the Mingo AI chat interface within the OpenFrame platform, handling real-time messaging, dialog management, streaming responses, and approval workflows across multiple chat dialogs.

## Key Components

- **Message Storage**: `messagesByDialog` - Centralized storage for all dialog messages
- **Dialog Management**: Active dialog tracking and dialog list management
- **Real-time Features**: Typing indicators, unread counts, and streaming message handling
- **Segment Processing**: Message segment accumulators for handling tool executions and approval requests
- **State Management**: Loading states, error handling, and pagination support
- **Approval Workflow**: Integration with approval request system for AI actions

## Usage Example

```typescript
import { useMingoMessagesStore } from './mingo-messages-store'

// Basic message operations
const {
  setActiveDialogId,
  addMessage,
  getMessages,
  setTyping,
  incrementUnread
} = useMingoMessagesStore()

// Switch to a dialog and load messages
setActiveDialogId('dialog-123')
const messages = getMessages('dialog-123')

// Add a new message
addMessage('dialog-123', {
  id: 'msg-456',
  role: 'user',
  content: 'Hello Mingo AI',
  timestamp: Date.now()
})

// Handle streaming message with segments
const accumulator = getOrCreateAccumulator('dialog-123', {
```
