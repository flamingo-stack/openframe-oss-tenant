A Zustand store managing chat messages, dialogs, and real-time streaming state for the Mingo AI assistant interface. It provides centralized state management for multi-dialog conversations with support for streaming responses, approval workflows, and message segment processing.

## Key Components

### Core State
- **messagesByDialog**: Map storing messages keyed by dialog ID
- **activeDialogId**: Currently selected dialog
- **dialogs**: Array of available dialog nodes
- **streamingMessages**: Real-time message streaming state
- **segmentAccumulators**: Message segment processors for streaming content

### Real-time Features
- **typingStates**: Typing indicators per dialog
- **unreadCounts**: Unread message counters
- **Streaming support**: Live message updates with segment accumulation
- **Approval workflows**: Handle command approval requests

### Loading & Error States
- Loading states for dialogs, messages, and dialog creation
- Error handling for dialog and message operations
- Pagination support with cursors
