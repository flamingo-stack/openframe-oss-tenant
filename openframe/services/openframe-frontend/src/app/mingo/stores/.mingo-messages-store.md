A Zustand store managing message state and real-time interactions for the Mingo AI chat interface. It handles dialog management, message streaming, approval workflows, and message segment accumulation across multiple conversation threads.

## Key Components

**State Management:**
- `messagesByDialog` - Map storing messages per dialog thread
- `activeDialogId` - Currently selected conversation
- `dialogs` - List of available dialog nodes
- `streamingMessages` - Real-time message updates during streaming
- `segmentAccumulators` - Message segment processors for complex content

**Real-time Features:**
- `typingStates` - Typing indicators per dialog
- `unreadCounts` - Unread message counters
- Loading states for dialogs, messages, and creation
- Error handling for dialog and message operations

**Core Actions:**
- Message CRUD operations (`addMessage`, `updateMessage`, `removeMessage`)
- Real-time state management (`setTyping`, `incrementUnread`)
- Streaming message handling with segment accumulation
- Approval status updates for interactive workflows

## Usage Example

```typescript
import { useMingoMessagesStore } from './mingo-messages-store'

function ChatComponent() {
  const {
    messagesByDialog,
    activeDialogId,
    addMessage,
    setActiveDialogId,
    getStreamingMessage,
    updateStreamingMessageSegments
  } = useMingoMessagesStore()

  // Switch to a dialog
  const selectDialog = (dialogId: string) => {
    setActiveDialogId(dialogId)
  }

  // Add a new message
  const sendMessage = (message: Message) => {
    if (activeDialogId) {
      addMessage(activeDialogId, message)
    }
  }

  // Handle streaming updates
  const handleStreamingSegments = (segments: MessageSegment[]) => {
    if (activeDialogId) {
      updateStreamingMessageSegments(activeDialogId, segments)
    }
  }

  return (
    <div>
      {/* Render messages for active dialog */}
    </div>
  )
}
```
