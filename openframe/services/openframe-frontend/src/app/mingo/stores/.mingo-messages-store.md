A centralized Zustand store managing Mingo AI chat dialogs, messages, and real-time streaming states across the OpenFrame platform. Provides unified state management for multi-dialog conversations with support for message streaming, approval workflows, and real-time updates.

## Key Components

- **MingoMessagesStore Interface**: Comprehensive store definition with dialog management, message CRUD operations, streaming states, and approval workflows
- **useMingoMessagesStore Hook**: Zustand store implementation with devtools integration
- **Message Management**: Dialog-scoped message storage with CRUD operations and approval status tracking
- **Streaming Support**: Real-time message streaming with segment accumulation and live updates
- **Dialog State**: Active dialog tracking, typing indicators, unread counts, and pagination
- **Approval Workflow**: Integration with OpenFrame's approval request system for AI actions

      )}
    </div>
  )
}
