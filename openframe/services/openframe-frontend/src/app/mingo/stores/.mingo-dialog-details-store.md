A Zustand store that manages the detailed state for individual dialog conversations in the Mingo AI chat system, handling messages, loading states, real-time updates, and typing indicators.

## Key Components

**State Management:**
- `currentDialogId` / `currentDialog` - Currently selected dialog and its metadata
- `adminMessages` - Array of messages for the current dialog
- `isLoadingDialog` / `isLoadingMessages` - Loading states for UI feedback
- `dialogError` / `messagesError` - Error handling for different operations
- `hasMoreMessages` / `messagesCursor` - Pagination support for message history
- `dialogTypingStates` - Per-dialog typing indicators

**Core Actions:**
- `setCurrentDialog()` - Sets the active dialog
- `addRealtimeMessage()` - Handles incoming real-time messages with deduplication
- `ensureTypingMessage()` / `removeTypingMessage()` - Manages typing indicators
- `updateLastAssistantMessage()` - Accumulates streaming text content
- `addAdminMessages()` - Adds new messages while preventing duplicates

## Usage Example

```typescript
import { useMingoDialogDetailsStore } from './mingo-dialog-details-store'

function ChatDialog({ dialogId }: { dialogId: string }) {
  const {
    currentDialog,
    adminMessages,
    isLoadingMessages,
    setCurrentDialogId,
    ensureTypingMessage,
    updateLastAssistantMessage
  } = useMingoDialogDetailsStore()

  // Set active dialog
  useEffect(() => {
    setCurrentDialogId(dialogId)
  }, [dialogId, setCurrentDialogId])

  // Handle streaming AI response
  const handleStreamingResponse = (chunk: string) => {
    ensureTypingMessage(dialogId)
    updateLastAssistantMessage(dialogId, chunk)
  }

  return (
    <div>
      {adminMessages
        .filter(msg => msg.dialogId === dialogId)
        .map(message => (
          <MessageBubble key={message.id} message={message} />
        ))}
      {isLoadingMessages && <LoadingSpinner />}
    </div>
  )
}
```
