A Zustand store managing state for Mingo AI dialog details, including current dialog information, message history, real-time updates, and typing indicators for the chat interface.

## Key Components

**State Properties:**
- `currentDialogId` / `currentDialog` - Active dialog and its metadata
- `adminMessages` - Array of messages for the current dialog
- `isLoadingDialog` / `isLoadingMessages` - Loading states for async operations
- `dialogError` / `messagesError` - Error states for dialog and message operations
- `hasMoreMessages` / `messagesCursor` - Pagination state for message history
- `dialogTypingStates` - Per-dialog typing indicators

**Core Actions:**
- `setCurrentDialogId()` / `setCurrentDialog()` - Set active dialog
- `setAdminMessages()` / `addAdminMessages()` - Manage message collection
- `addRealtimeMessage()` - Handle real-time message updates
- `ensureTypingMessage()` / `removeTypingMessage()` - Manage typing indicators
- `updateLastAssistantMessage()` - Accumulate streaming AI responses
- `clearCurrent()` - Reset store state

## Usage Example

```typescript
import { useMingoDialogDetailsStore } from './stores/mingo-dialog-details-store'

function DialogDetails({ dialogId }: { dialogId: string }) {
  const {
    currentDialog,
    adminMessages,
    isLoadingMessages,
    setCurrentDialogId,
    addRealtimeMessage,
    ensureTypingMessage
  } = useMingoDialogDetailsStore()

  useEffect(() => {
    setCurrentDialogId(dialogId)
    
    // Set up real-time message listener
    const handleNewMessage = (message: Message) => {
      addRealtimeMessage(message)
    }
    
    // Show typing indicator for AI responses
    const handleAITyping = () => {
      ensureTypingMessage(dialogId)
    }
  }, [dialogId])

  return (
    <div>
      <h2>{currentDialog?.title}</h2>
      {adminMessages.map(message => (
        <MessageBubble key={message.id} message={message} />
      ))}
      {isLoadingMessages && <LoadingSpinner />}
    </div>
  )
}
```
