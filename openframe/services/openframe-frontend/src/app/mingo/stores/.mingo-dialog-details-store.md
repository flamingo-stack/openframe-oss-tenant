Zustand store managing dialog details state for the Mingo AI chat system, handling current dialog data, messages, loading states, and real-time message streaming with typing indicators.

## Key Components

- **Dialog State**: `currentDialogId`, `currentDialog`, `adminMessages` - Core dialog and message data
- **Loading States**: `isLoadingDialog`, `isLoadingMessages` - UI loading indicators  
- **Error Handling**: `dialogError`, `messagesError` - Error state management
- **Real-time Features**: `dialogTypingStates`, typing message management - Live chat functionality
- **Pagination**: `hasMoreMessages`, `messagesCursor` - Message history loading
- **Message Actions**: Add, update, remove messages with deduplication logic

## Usage Example

```typescript
import { useMingoDialogDetailsStore } from './mingo-dialog-details-store'

function DialogComponent() {
  const {
    currentDialog,
    adminMessages,
    isLoadingMessages,
    setCurrentDialogId,
    addRealtimeMessage,
    ensureTypingMessage,
    updateLastAssistantMessage
  } = useMingoDialogDetailsStore()

  // Load a dialog
  const loadDialog = (dialogId: string) => {
    setCurrentDialogId(dialogId)
  }

  // Handle streaming AI response
  const handleStreamingResponse = (dialogId: string, chunk: string) => {
    ensureTypingMessage(dialogId) // Create typing placeholder
    updateLastAssistantMessage(dialogId, chunk) // Append text
  }

  // Add new message from real-time updates
  const handleNewMessage = (message: Message) => {
    addRealtimeMessage(message)
  }

  return (
    <div>
      {adminMessages.map(message => (
        <MessageBubble key={message.id} message={message} />
      ))}
    </div>
  )
}
```
