Zustand store for managing Mingo AI dialog details state, including current dialog data, admin messages, loading states, and real-time messaging functionality. This store handles dialog selection, message management with pagination, typing indicators, and streaming message updates.

## Key Components

### State Properties
- **Dialog State**: `currentDialogId`, `currentDialog`, `adminMessages`
- **Loading States**: `isLoadingDialog`, `isLoadingMessages`
- **Error Handling**: `dialogError`, `messagesError`
- **Pagination**: `hasMoreMessages`, `messagesCursor`, `newestMessageCursor`
- **Typing Indicators**: `dialogTypingStates` (per-dialog typing states)

### Core Actions
- **Dialog Management**: `setCurrentDialogId()`, `setCurrentDialog()`, `clearCurrent()`
- **Message Operations**: `setAdminMessages()`, `addAdminMessages()`, `addRealtimeMessage()`
- **Streaming Support**: `ensureTypingMessage()`, `updateLastAssistantMessage()`, `removeTypingMessage()`
- **Utility Functions**: `removeWelcomeMessages()`, `getLastEmptyAssistantMessage()`
- **State Management**: Loading, error, and pagination setters

## Usage Example

```typescript
import { useMingoDialogDetailsStore } from './mingo-dialog-details-store'

function DialogDetails({ dialogId }: { dialogId: string }) {
  const {
    currentDialog,
    adminMessages,
    isLoadingMessages,
    setCurrentDialogId,
    ensureTypingMessage,
    updateLastAssistantMessage
  } = useMingoDialogDetailsStore()

  // Set active dialog
  useEffect(() => {
    setCurrentDialogId(dialogId)
  }, [dialogId, setCurrentDialogId])

  // Handle streaming AI responses
  const handleStreamingResponse = (content: string) => {
    ensureTypingMessage(dialogId)
    updateLastAssistantMessage(dialogId, content)
  }

  return (
    <div>
      {isLoadingMessages ? (
        <div>Loading messages...</div>
      ) : (
        adminMessages.map(msg => (
          <MessageComponent key={msg.id} message={msg} />
        ))
      )}
    </div>
  )
}
```
