A Zustand store for managing Mingo AI dialog details including current dialog state, admin messages, loading states, and real-time message handling with typing indicators.

## Key Components

**State Properties:**
- `currentDialogId` / `currentDialog` - Active dialog tracking
- `adminMessages` - Message array for current dialog
- `isLoadingDialog` / `isLoadingMessages` - Loading state flags
- `dialogTypingStates` - Per-dialog typing indicator states
- Pagination cursors for message history

**Core Actions:**
- `setCurrentDialog()` - Switch active dialog
- `addRealtimeMessage()` - Handle incoming messages
- `ensureTypingMessage()` / `removeTypingMessage()` - Manage typing indicators
- `updateLastAssistantMessage()` - Accumulate streaming text content
- `clearCurrent()` - Reset store state

## Usage Example

```typescript
import { useMingoDialogDetailsStore } from './mingo-dialog-details-store'

function DialogComponent() {
  const {
    currentDialog,
    adminMessages,
    isLoadingMessages,
    setCurrentDialogId,
    addRealtimeMessage,
    ensureTypingMessage
  } = useMingoDialogDetailsStore()

  // Switch to a dialog
  const openDialog = (dialogId: string) => {
    setCurrentDialogId(dialogId)
  }

  // Handle streaming AI response
  const handleAIStream = (dialogId: string, chunk: string) => {
    ensureTypingMessage(dialogId)
    updateLastAssistantMessage(dialogId, chunk)
  }

  return (
    <div>
      {adminMessages.map(msg => (
        <div key={msg.id}>{msg.messageData?.text}</div>
      ))}
    </div>
  )
}
```

The store handles complex real-time messaging scenarios including message deduplication, typing indicators, and streaming text accumulation for AI responses.
