A Zustand store that manages state for Mingo AI chat dialog details, including current dialog context, admin messages, loading states, and real-time message handling with typing indicators.

## Key Components

### State Properties
- **Dialog State**: `currentDialogId`, `currentDialog`, `adminMessages` - tracks active dialog and its messages
- **Loading States**: `isLoadingDialog`, `isLoadingMessages` - manages async operation states
- **Error Handling**: `dialogError`, `messagesError` - stores error messages for UI feedback
- **Pagination**: `hasMoreMessages`, `messagesCursor`, `newestMessageCursor` - handles message pagination
- **Typing Indicators**: `dialogTypingStates` - tracks typing state per dialog for UI behavior

### Key Actions
- **Dialog Management**: `setCurrentDialog()`, `clearCurrent()` - manages active dialog context
- **Message Operations**: `addRealtimeMessage()`, `updateLastAssistantMessage()` - handles real-time message updates
- **Typing System**: `ensureTypingMessage()`, `removeTypingMessage()` - manages AI response typing indicators
- **State Management**: `setLoadingDialog()`, `setDialogError()` - updates loading and error states

## Usage Example

```typescript
import { useMingoDialogDetailsStore } from './mingo-dialog-details-store'

function ChatInterface() {
  const {
    currentDialog,
    adminMessages,
    isLoadingMessages,
    setCurrentDialogId,
    addRealtimeMessage,
    ensureTypingMessage,
    updateLastAssistantMessage
  } = useMingoDialogDetailsStore()

  const handleSelectDialog = (dialogId: string) => {
    setCurrentDialogId(dialogId)
    // Trigger message loading...
  }

  const handleNewMessage = (message: Message) => {
    addRealtimeMessage(message)
  }

  const handleTypingStart = (dialogId: string) => {
    ensureTypingMessage(dialogId)
  }

  return (
    <div>
      {isLoadingMessages ? (
        <div>Loading messages...</div>
      ) : (
        adminMessages.map(message => (
          <MessageComponent key={message.id} message={message} />
        ))
      )}
    </div>
  )
}
```
