A Zustand store for managing the detailed view of Mingo AI chat dialogs, handling messages, typing states, and real-time updates in the admin interface.

## Key Components

- **Dialog State**: Manages current dialog selection and metadata (`currentDialog`, `currentDialogId`)
- **Message Management**: Handles admin messages with deduplication and real-time updates (`adminMessages`, `addRealtimeMessage`)
- **Typing Indicators**: Creates and manages typing messages for smooth UI feedback (`ensureTypingMessage`, `hasTypingMessage`)
- **Loading & Error States**: Tracks async operations and error handling for dialogs and messages
- **Pagination**: Manages message history pagination with cursors (`hasMoreMessages`, `messagesCursor`)
- **Real-time Features**: Supports streaming message updates and typing state management

## Usage Example

```typescript
import { useMingoDialogDetailsStore } from './mingo-dialog-details-store'

function DialogDetails({ dialogId }: { dialogId: string }) {
  const {
    currentDialog,
    adminMessages,
    isLoadingMessages,
    setCurrentDialogId,
    ensureTypingMessage,
    updateLastAssistantMessage,
    addRealtimeMessage
  } = useMingoDialogDetailsStore()

  // Select a dialog for viewing
  useEffect(() => {
    setCurrentDialogId(dialogId)
  }, [dialogId, setCurrentDialogId])

  // Handle streaming AI responses
  const handleStreamingResponse = (chunk: string) => {
    ensureTypingMessage(dialogId)
    updateLastAssistantMessage(dialogId, chunk)
  }

  // Add new messages from websocket
  const handleNewMessage = (message: Message) => {
    addRealtimeMessage(message)
  }

  return (
    <div>
      {adminMessages.map(message => (
        <MessageBubble key={message.id} message={message} />
      ))}
      {isLoadingMessages && <LoadingSpinner />}
    </div>
  )
}
```
