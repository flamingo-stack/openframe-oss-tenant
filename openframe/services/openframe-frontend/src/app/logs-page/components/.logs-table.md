This React component renders a comprehensive logs table with filtering, pagination, and modal support for viewing detailed log information.

## Key Components

- **LogsTable** - Main component that displays logs in a filterable, paginated table
- **LogsTableRef** - Ref interface exposing refresh functionality
- **UILogEntry** - Interface defining the transformed log data structure
- **LogInfoModal** - Modal component for displaying detailed log information
- **Table with cursor pagination** - Server-side paginated table with sorting and filtering
- **Device-specific filtering** - Optional filtering by device ID for embedded usage

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table'

// Standalone logs table
function LogsPage() {
  const tableRef = useRef<LogsTableRef>(null)
  
  const handleRefresh = () => {
    tableRef.current?.refresh()
  }
  
  return (
    <div>
      <button onClick={handleRefresh}>Refresh Logs</button>
      <LogsTable ref={tableRef} />
    </div>
  )
}

// Device-specific embedded logs
function DeviceDetails({ deviceId }: { deviceId: string }) {
  return (
    <div>
      <h2>Device Logs</h2>
      <LogsTable deviceId={deviceId} embedded={true} />
    </div>
  )
}
```

The component supports real-time filtering by severity, tool type, and organization, with URL parameter persistence and responsive column hiding for different screen sizes.
