A comprehensive React table component for displaying and managing system logs with filtering, search, and pagination capabilities.

## Key Components

- **LogsTable** - Main table component with forwardRef for external control
- **UILogEntry** - Interface defining the transformed log data structure
- **LogsTableRef** - Reference interface exposing refresh functionality
- **LogInfoModal** - Modal for viewing detailed log information
- **Table filters** - Status, tool type, and organization filtering
- **Cursor pagination** - Server-side pagination with navigation controls

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table'
import { useRef } from 'react'

// Standalone logs table
function LogsPage() {
  const tableRef = useRef<LogsTableRef>(null)
  
  const handleRefresh = () => {
    tableRef.current?.refresh()
  }
  
  return (
    <div>
      <button onClick={handleRefresh}>Refresh Logs</button>
      <LogsTable ref={tableRef} />
    </div>
  )
}

// Embedded device-specific logs
function DeviceLogsSection({ deviceId }: { deviceId: string }) {
  return (
    <LogsTable 
      deviceId={deviceId} 
      embedded={true}
    />
  )
}
```

The component transforms raw log entries into a UI-friendly format with status variants, tool badges, and device information. It supports both standalone and embedded modes, with the embedded version hiding device columns and pagination for focused device-specific log viewing.
