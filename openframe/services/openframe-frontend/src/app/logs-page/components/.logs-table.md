A React component that displays system logs in a filterable, paginated table with detailed modal views.

## Key Components

- **LogsTable** - Main component with device filtering, search, and pagination capabilities
- **UILogEntry** - Interface defining the transformed log data structure  
- **LogsTableRef** - Ref interface exposing refresh functionality
- **Log transformation** - Converts API log entries to UI-friendly format
- **Modal integration** - Shows detailed log information in a side panel

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table'

// Standalone logs page
function LogsPage() {
  const logsTableRef = useRef<LogsTableRef>(null)
  
  const handleRefresh = () => {
    logsTableRef.current?.refresh()
  }
  
  return (
    <div>
      <button onClick={handleRefresh}>Refresh Logs</button>
      <LogsTable ref={logsTableRef} />
    </div>
  )
}

// Device-specific logs (embedded mode)
function DevicePage({ deviceId }: { deviceId: string }) {
  return (
    <div>
      <h2>Device Logs</h2>
      <LogsTable deviceId={deviceId} embedded={true} />
    </div>
  )
}
```

The component supports filtering by severity, tool type, and organization, with cursor-based pagination and real-time search. It can operate in standalone mode with full page layout or embedded mode for device-specific log viewing.
