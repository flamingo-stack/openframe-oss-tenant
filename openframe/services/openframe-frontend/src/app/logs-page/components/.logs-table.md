A React component that displays and manages IT operations logs in a filterable, paginated table format with detailed modal views and external navigation capabilities.

## Key Components

- **LogsTable**: Main component rendering logs with filtering, search, and pagination
- **LogsTableRef**: Imperative handle interface exposing refresh functionality  
- **UILogEntry**: Transformed log data interface for UI display
- **Table Integration**: Uses OpenFrame UI table with custom columns and filtering
- **LogInfoModal**: Side panel modal for displaying detailed log information
- **Cursor Pagination**: Server-side pagination with next/previous navigation

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table'
import { useRef } from 'react'

function LogsPage() {
  const tableRef = useRef<LogsTableRef>(null)

  const handleRefreshLogs = () => {
    tableRef.current?.refresh()
  }

  return (
    <div>
      <button onClick={handleRefreshLogs}>
        Refresh Logs
      </button>
      
      {/* Full page logs table */}
      <LogsTable ref={tableRef} />
      
      {/* Device-specific embedded logs */}
      <LogsTable 
        deviceId="device-123" 
        embedded={true} 
      />
    </div>
  )
}
```

The component supports both full-page and embedded modes, with comprehensive filtering by severity, tool type, and organization. It transforms raw log entries into a consistent UI format with proper status indicators, device information, and clickable details navigation.
