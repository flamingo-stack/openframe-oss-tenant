A table component for displaying and managing system logs with filtering, pagination, and detailed log views.

## Key Components

- **LogsTable**: Main table component with filtering, search, and pagination
- **LogsTableRef**: Ref interface exposing refresh functionality
- **UILogEntry**: Transformed log entry interface for UI display
- **LogInfoModal**: Modal component for displaying detailed log information

## Usage Example

```typescript
import { LogsTable } from './logs-table'

// Basic usage - all logs
function LogsPage() {
  return <LogsTable />
}

// Device-specific logs (embedded mode)
function DeviceLogsTab({ deviceId }: { deviceId: string }) {
  return (
    <LogsTable 
      deviceId={deviceId} 
      embedded={true} 
    />
  )
}

// With ref for external refresh control
function LogsWithRefresh() {
  const logsTableRef = useRef<LogsTableRef>(null)
  
  return (
    <div>
      <button onClick={() => logsTableRef.current?.refresh()}>
        Refresh Logs
      </button>
      <LogsTable ref={logsTableRef} />
    </div>
  )
}
```

The component supports filtering by severity, tool type, and organization, cursor-based pagination, and opens detailed views in modals or new tabs. It can be embedded within device views or used as a standalone page with full navigation controls.
