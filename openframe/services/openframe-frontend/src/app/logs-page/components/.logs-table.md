A React component that displays system logs in a filterable, paginated table format with support for both standalone and embedded modes.

## Key Components

- **LogsTable**: Main component with forwardRef support for external refresh control
- **UILogEntry**: Interface defining the structure of log entries for display
- **LogsTableRef**: Interface for imperative handle methods
- **Column configuration**: Dynamic columns that adapt based on embedded mode
- **Filter system**: Multi-faceted filtering by severity, tool type, and organization
- **Cursor pagination**: Server-side pagination with URL state management
- **Log details modal**: Side panel for viewing detailed log information

## Usage Example

```typescript
// Standalone mode
const logsRef = useRef<LogsTableRef>(null);

function LogsPage() {
  return (
    <LogsTable 
      ref={logsRef}
      onRefresh={() => logsRef.current?.refresh()}
    />
  );
}

// Embedded mode for device-specific logs
function DevicePage({ deviceId }: { deviceId: string }) {
  return (
    <LogsTable 
      deviceId={deviceId}
      embedded={true}
    />
  );
}

// Programmatic refresh
function handleRefreshClick() {
  logsRef.current?.refresh();
}
```

The component handles log data transformation, filtering by severity/tool/organization, search functionality, and provides both modal and external link options for viewing log details. It uses cursor-based pagination for efficient large dataset handling.
