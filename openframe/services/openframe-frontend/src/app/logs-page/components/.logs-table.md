A React table component that displays system logs with filtering, pagination, and detailed log viewing capabilities. Built using OpenFrame UI components with support for both standalone and embedded modes.

## Key Components

- **LogsTable** - Main component with forwardRef for external refresh control
- **LogsTableRef** - Ref interface exposing refresh functionality
- **UILogEntry** - Interface defining transformed log data structure
- **LogsTableProps** - Component props supporting device-specific filtering and embedded mode

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table'
import { useRef } from 'react'

// Standalone logs table
function LogsPage() {
  const tableRef = useRef<LogsTableRef>(null)
  
  const handleRefresh = () => {
    tableRef.current?.refresh()
  }

  return (
    <div>
      <button onClick={handleRefresh}>Refresh Logs</button>
      <LogsTable ref={tableRef} />
    </div>
  )
}

// Embedded device-specific logs
function DeviceDetails({ deviceId }: { deviceId: string }) {
  return (
    <div>
      <h2>Device Logs</h2>
      <LogsTable deviceId={deviceId} embedded={true} />
    </div>
  )
}
```

The component features:
- **Cursor-based pagination** with server-side filtering
- **Multi-column filtering** by status, tool type, and organization
- **Responsive design** with adaptive column visibility
- **Log detail modal** for viewing complete log information
- **External link navigation** to detailed log pages
- **Real-time search** with debounced API calls
- **Loading states and error handling** with skeleton rows
