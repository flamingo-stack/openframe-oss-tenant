A React component that provides a comprehensive logs table interface with filtering, pagination, and modal details view for log entries.

## Key Components

- **LogsTable**: Main forwardRef component with search, filtering, and pagination
- **UILogEntry**: TypeScript interface defining the transformed log data structure
- **LogsTableRef**: Ref interface exposing refresh functionality
- **LogInfoModal**: Modal component for detailed log information
- **Table**: Core table component with column definitions and row actions

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table'
import { useRef } from 'react'

function LogsPage() {
  const logsTableRef = useRef<LogsTableRef>(null)

  const handleRefreshLogs = () => {
    logsTableRef.current?.refresh()
  }

  return (
    <div>
      <button onClick={handleRefreshLogs}>Refresh Logs</button>
      
      {/* Full page logs table */}
      <LogsTable ref={logsTableRef} />
      
      {/* Device-specific embedded logs */}
      <LogsTable 
        deviceId="device-123" 
        embedded={true}
      />
    </div>
  )
}
```

The component features cursor-based pagination, real-time filtering by severity/tool type/organization, responsive column hiding, and integrates with OpenFrame's design system. It supports both full-page and embedded modes, with the embedded version hiding certain columns and pagination controls for device-specific log views.
