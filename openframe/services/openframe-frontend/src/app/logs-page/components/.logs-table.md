A comprehensive React table component for displaying and managing system logs with advanced filtering, pagination, and modal interactions.

## Key Components

- **LogsTable**: Main component with forwardRef support for external refresh control
- **UILogEntry**: TypeScript interface defining the transformed log data structure
- **LogsTableRef**: Ref interface exposing refresh functionality
- **Table Integration**: Uses OpenFrame's Table component with custom columns and filtering
- **LogInfoModal**: Side panel for detailed log information
- **Cursor Pagination**: Server-side pagination with navigation controls

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table'
import { useRef } from 'react'

// Basic usage
function LogsPage() {
  return <LogsTable />
}

// Device-specific logs (embedded mode)
function DevicePage({ deviceId }: { deviceId: string }) {
  return <LogsTable deviceId={deviceId} embedded={true} />
}

// With ref for external refresh control
function LogsWithRefresh() {
  const logsTableRef = useRef<LogsTableRef>(null)
  
  const handleRefreshLogs = () => {
    logsTableRef.current?.refresh()
  }
  
  return (
    <div>
      <button onClick={handleRefreshLogs}>Refresh Logs</button>
      <LogsTable ref={logsTableRef} />
    </div>
  )
}
```

The component handles log data transformation, multi-column filtering (status, tool type, organization), cursor-based pagination, and provides both standalone and embedded display modes. It integrates with the OpenFrame design system and includes responsive breakpoints for mobile optimization.
