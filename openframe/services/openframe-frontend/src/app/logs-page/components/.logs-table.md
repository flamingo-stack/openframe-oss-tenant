A comprehensive log viewing component that displays system logs in a filterable, paginated table format with modal details.

## Key Components

- **LogsTable**: Main table component with search, filtering, and cursor pagination
- **LogsTableRef**: Reference interface exposing refresh functionality
- **UILogEntry**: Interface for transformed log data with status, source, device, and description info
- **LogInfoModal**: Side panel modal for viewing detailed log information
- **Table columns**: Configurable columns for log ID, status, tool, source, and description
- **Filter integration**: Supports filtering by severity, tool types, and organizations

## Usage Example

```typescript
import { LogsTable, LogsTableRef } from './logs-table'
import { useRef } from 'react'

function LogsPage() {
  const tableRef = useRef<LogsTableRef>(null)
  
  const handleRefresh = () => {
    tableRef.current?.refresh()
  }
  
  return (
    <div>
      <button onClick={handleRefresh}>Refresh Logs</button>
      {/* Full page layout with all features */}
      <LogsTable ref={tableRef} />
      
      {/* Embedded mode for device-specific logs */}
      <LogsTable deviceId="device-123" embedded={true} />
    </div>
  )
}
```

The component transforms raw log entries into a structured UI format, handles cursor-based pagination, and provides filtering capabilities. In embedded mode, it removes device-specific columns and pagination controls for use within device detail pages.
