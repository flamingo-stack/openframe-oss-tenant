A React component that renders a comprehensive logs table with filtering, pagination, and detailed view capabilities for monitoring system events.

## Key Components

**Main Exports:**
- `LogsTable` - Forwardref component that displays logs in a table format
- `LogsTableRef` - Interface exposing refresh functionality
- `UILogEntry` - TypeScript interface defining the table row data structure

**Core Features:**
- Server-side cursor pagination with search functionality
- Multi-column filtering (status, tool type, organization)
- Real-time log data fetching and transformation
- Modal detail view for individual log entries
- Responsive design with column hiding on smaller screens
- Embedded mode for device-specific log display

## Usage Example

```typescript
// Basic usage
import { LogsTable, type LogsTableRef } from './logs-table'

function LogsPage() {
  const tableRef = useRef<LogsTableRef>(null)

  const handleRefresh = () => {
    tableRef.current?.refresh()
  }

  return (
    <div>
      <LogsTable ref={tableRef} />
      <button onClick={handleRefresh}>Refresh Logs</button>
    </div>
  )
}

// Device-specific embedded usage
function DeviceDetails({ deviceId }: { deviceId: string }) {
  return (
    <LogsTable 
      deviceId={deviceId} 
      embedded={true} 
    />
  )
}
```

The component transforms raw log data into a user-friendly format with status badges, tool icons, device information, and clickable rows that open detailed modals. It supports both standalone page layouts and embedded contexts within other components.
