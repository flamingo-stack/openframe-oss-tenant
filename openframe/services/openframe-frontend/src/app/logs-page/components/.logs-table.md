A React table component that displays and manages log entries with filtering, search, and pagination capabilities.

## Key Components

- **LogsTable**: Main component displaying log entries in a tabular format with filtering and pagination
- **LogsTableRef**: Ref interface exposing refresh functionality
- **UILogEntry**: Interface defining the transformed log entry structure for UI display
- **LogInfoModal**: Modal component for displaying detailed log information

## Usage Example

```typescript
// Basic usage
<LogsTable />

// Embedded mode for device-specific logs
<LogsTable deviceId="device-123" embedded />

// With ref for programmatic control
const logsTableRef = useRef<LogsTableRef>(null)

<LogsTable ref={logsTableRef} />

// Refresh logs programmatically
logsTableRef.current?.refresh()
```

The component supports multiple filter types (severity, tool types, organizations), cursor-based pagination, search functionality, and can operate in both standalone and embedded modes. When embedded, it removes device-specific columns and pagination for cleaner display within device detail views.
