A React component that renders a data table for displaying system logs with advanced filtering, pagination, and detailed log viewing capabilities.

## Key Components

- **LogsTable**: Main forwardRef component that renders logs in a responsive table format
- **LogsTableRef**: Interface exposing refresh functionality via ref
- **UILogEntry**: Type definition for transformed log entries with status, source, device, and description information
- **LogInfoModal**: Modal component for viewing detailed log information
- **Table Columns**: Configurable columns including Log ID, Status, Tool, Source, and Description
- **Filter Integration**: Multi-dimensional filtering by severity, tool types, and organizations
- **Cursor Pagination**: Server-side pagination with navigation controls

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table'

// Basic usage
function LogsPage() {
  const tableRef = useRef<LogsTableRef>(null)
  
  const handleRefresh = () => {
    tableRef.current?.refresh()
  }
  
  return (
    <div>
      <LogsTable ref={tableRef} />
      <button onClick={handleRefresh}>Refresh Logs</button>
    </div>
  )
}

// Embedded mode for device-specific logs
function DeviceLogsSection({ deviceId }: { deviceId: string }) {
  return (
    <LogsTable 
      deviceId={deviceId} 
      embedded={true} 
    />
  )
}
```

The component supports both standalone and embedded modes, with the embedded version optimized for device-specific log displays. It includes real-time filtering, search functionality, and detailed log inspection through a side modal interface.
