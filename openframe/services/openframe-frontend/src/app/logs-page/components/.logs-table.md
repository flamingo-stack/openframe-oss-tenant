React component for displaying and managing system logs in a filterable, paginated table format.

## Key Components

- **LogsTable** - Main component with search, filtering, pagination, and detailed log viewing
- **UILogEntry** interface - Type definition for transformed log data display
- **LogsTableRef** interface - Exposes refresh method for parent components
- **Column configuration** - Defines table structure with conditional device column for embedded mode
- **Filter integration** - Handles severity, tool type, and organization filtering
- **Modal integration** - Shows detailed log information in a side panel

## Usage Example

```typescript
// Standalone logs page
function LogsPage() {
  const logsTableRef = useRef<LogsTableRef>(null)

  const handleRefresh = () => {
    logsTableRef.current?.refresh()
  }

  return (
    <div>
      <Button onClick={handleRefresh}>Refresh Logs</Button>
      <LogsTable ref={logsTableRef} />
    </div>
  )
}

// Embedded in device details
function DeviceDetails({ deviceId }: { deviceId: string }) {
  return (
    <div>
      <h2>Device Logs</h2>
      <LogsTable deviceId={deviceId} embedded={true} />
    </div>
  )
}

// Filter by specific parameters
function FilteredLogs() {
  return (
    <LogsTable 
      // Filters handled internally via URL params
    />
  )
}
```

The component transforms raw log data into a user-friendly format with status indicators, tool badges, device information, and timestamp formatting. It supports both full-page and embedded modes, with the embedded version hiding organization filters and pagination controls.
