A React component that renders a comprehensive logs table with filtering, search, and pagination capabilities for the OpenFrame platform.

## Key Components

- **LogsTable**: Main table component with cursor pagination and filtering
- **UILogEntry**: Interface defining the transformed log data structure
- **LogsTableRef**: Ref interface exposing refresh functionality
- **Column Configuration**: Dynamic columns based on embedded mode
- **Filter Integration**: Multi-level filtering by severity, tool type, and organization
- **Modal Integration**: Log details modal for expanded view

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table'

// Basic usage
function LogsPage() {
  return <LogsTable />
}

// Device-specific logs (embedded mode)
function DeviceDetailsPage({ deviceId }: { deviceId: string }) {
  return (
    <LogsTable 
      deviceId={deviceId} 
      embedded={true} 
    />
  )
}

// With ref for programmatic refresh
function LogsWithRefresh() {
  const tableRef = useRef<LogsTableRef>(null)
  
  const handleRefresh = () => {
    tableRef.current?.refresh()
  }
  
  return (
    <>
      <button onClick={handleRefresh}>Refresh Logs</button>
      <LogsTable ref={tableRef} />
    </>
  )
}
```

The component supports both standalone and embedded modes, with automatic URL parameter synchronization for filters and search state. It transforms raw log entries into a UI-friendly format with status badges, tool labels, and device information display.
