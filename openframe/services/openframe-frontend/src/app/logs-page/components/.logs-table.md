A comprehensive React component for displaying and managing system logs in a table format with filtering, pagination, and detailed log viewing capabilities.

## Key Components

**Main Export:**
- `LogsTable` - Forwardable table component with search, filtering, and pagination
- `LogsTableRef` - Reference interface exposing refresh functionality

**Core Features:**
- Cursor-based pagination for large datasets
- Multi-column filtering (severity, tool type, organization)
- Real-time search capabilities
- Log detail modal with external link navigation
- Device-specific log filtering
- Embedded mode for use within other components

**Data Transformation:**
- Converts API log entries to UI-friendly format
- Handles device and organization display logic
- Maps severity levels to status tag variants

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table'
import { useRef } from 'react'

function LogsPage() {
  const logsTableRef = useRef<LogsTableRef>(null)

  const handleRefreshLogs = () => {
    logsTableRef.current?.refresh()
  }

  return (
    <div>
      <button onClick={handleRefreshLogs}>
        Refresh Logs
      </button>
      
      {/* Full-featured logs table */}
      <LogsTable ref={logsTableRef} />
      
      {/* Device-specific embedded table */}
      <LogsTable 
        deviceId="device-123" 
        embedded={true}
      />
    </div>
  )
}
```

The component integrates with the OpenFrame frontend core for consistent UI patterns and provides both standalone and embedded usage modes for different contexts within the MSP platform.
