A React table component that displays system logs with filtering, pagination, and detailed views, supporting both standalone and embedded display modes.

## Key Components

**Main Export:**
- `LogsTable` - Forwarded ref component with filtering, search, and cursor pagination
- `LogsTableRef` - Interface exposing refresh method for parent components

**Key Features:**
- Search and filter by severity, tool type, and organization
- Cursor-based pagination with server-side data fetching
- Row click to open detailed log modal
- Responsive column hiding based on screen size
- External link navigation to detailed log views

**UI Elements:**
- Status badges with color-coded severity levels
- Tool type badges with normalized display names
- Device cards showing hostname and organization
- Timestamp cells with formatted display

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table'

// Standalone usage with full controls
function LogsPage() {
  const tableRef = useRef<LogsTableRef>(null)
  
  const handleRefresh = () => {
    tableRef.current?.refresh()
  }

  return (
    <div>
      <button onClick={handleRefresh}>Refresh Logs</button>
      <LogsTable ref={tableRef} />
    </div>
  )
}

// Embedded usage for device-specific logs
function DeviceDetailsPage({ deviceId }: { deviceId: string }) {
  return (
    <div>
      <h2>Device Logs</h2>
      <LogsTable deviceId={deviceId} embedded />
    </div>
  )
}
```

The component integrates with OpenFrame's design system and provides comprehensive log management functionality with real-time filtering and detailed log inspection capabilities.
