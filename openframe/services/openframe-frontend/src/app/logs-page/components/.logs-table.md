A React component that displays logs in a paginated table format with filtering, search, and detail view capabilities.

## Key Components

**Main Export:**
- `LogsTable` - Forwardable component with filtering, pagination, and modal support

**Key Interfaces:**
- `UILogEntry` - Transformed log data structure for display
- `LogsTableProps` - Component props including deviceId and embedded mode
- `LogsTableRef` - Ref interface exposing refresh method

**Core Features:**
- Server-side pagination with cursor-based navigation
- Column-based filtering (status, tool type, organization)
- Real-time search functionality
- Modal detail view for individual logs
- Embedded mode for device-specific display
- External link navigation to detailed log pages

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table'

// Basic usage
function LogsPage() {
  return <LogsTable />
}

// Device-specific embedded view
function DeviceLogsSection({ deviceId }: { deviceId: string }) {
  const logsRef = useRef<LogsTableRef>(null)
  
  const refreshLogs = () => {
    logsRef.current?.refresh()
  }
  
  return (
    <div>
      <LogsTable 
        ref={logsRef}
        deviceId={deviceId} 
        embedded={true} 
      />
      <button onClick={refreshLogs}>Refresh</button>
    </div>
  )
}
```

The component transforms raw log entries into a UI-friendly format with proper status variants, tool badges, and device information. It supports both standalone and embedded modes, with the embedded version hiding certain columns and layout elements for integration into device detail pages.
