A React component that displays log entries in a table format with filtering, search, pagination, and modal details view capabilities.

## Key Components

- **LogsTable** - Main forwardRef component that renders logs in a table with filtering and pagination
- **UILogEntry** - TypeScript interface defining the transformed log data structure
- **LogsTableProps** - Props interface supporting deviceId filtering and embedded mode
- **LogsTableRef** - Ref interface exposing refresh functionality
- **Table columns** - Configurable columns for Log ID, Status, Tool, Source, and Description
- **LogInfoModal** - Modal component for displaying detailed log information
- **Filter system** - Multi-column filtering for severities, tool types, and organizations

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table'
import { useRef } from 'react'

function LogsPage() {
  const tableRef = useRef<LogsTableRef>(null)

  const handleRefresh = () => {
    tableRef.current?.refresh()
  }

  return (
    <div>
      <button onClick={handleRefresh}>Refresh Logs</button>
      
      {/* Full-page logs table */}
      <LogsTable ref={tableRef} />
      
      {/* Embedded device-specific logs */}
      <LogsTable 
        deviceId="device-123" 
        embedded={true}
      />
    </div>
  )
}
```

The component transforms raw log data into a UI-friendly format, supports cursor-based pagination, and provides both full-page and embedded viewing modes. It integrates with the OpenFrame UI library for consistent styling and behavior.
