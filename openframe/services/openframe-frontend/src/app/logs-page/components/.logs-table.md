A React table component for displaying and managing system logs with filtering, pagination, and detailed views.

## Key Components

- **LogsTable**: Main table component with cursor pagination, filtering, and modal integration
- **LogsTableRef**: Interface exposing refresh functionality for parent components
- **UILogEntry**: TypeScript interface defining the transformed log data structure
- **Column Configuration**: Dynamic columns with responsive behavior and filtering options
- **Modal Integration**: LogInfoModal for detailed log inspection

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table'
import { useRef } from 'react'

// Basic usage
function LogsPage() {
  const tableRef = useRef<LogsTableRef>(null)
  
  const handleRefresh = () => {
    tableRef.current?.refresh()
  }
  
  return (
    <div>
      <button onClick={handleRefresh}>Refresh Logs</button>
      <LogsTable ref={tableRef} />
    </div>
  )
}

// Device-specific embedded view
function DeviceLogsSection({ deviceId }: { deviceId: string }) {
  return (
    <LogsTable 
      deviceId={deviceId} 
      embedded={true} 
    />
  )
}
```

The component supports both full-page and embedded modes, with configurable filtering by severity, tool type, and organization. It transforms API log entries into a user-friendly format with proper status indicators, tool badges, and device information. The table includes infinite scroll pagination, real-time filtering, and opens detailed log views in new tabs or modal dialogs.
