This file implements a comprehensive logs table component for the OpenFrame platform, displaying IT system logs with filtering, pagination, and detailed view capabilities.

## Key Components

- **`LogsTable`** - Main table component with filtering, search, and cursor pagination
- **`LogsTableRef`** - Interface for imperative refresh functionality  
- **`UILogEntry`** - Transformed log data structure for display
- **`LogInfoModal`** - Side modal for detailed log information
- **Column definitions** - Configurable table columns with responsive breakpoints
- **Filter integration** - Multi-dimensional filtering by severity, tool type, and organization

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table'

// Basic usage
function LogsPage() {
  return <LogsTable />
}

// Device-specific logs (embedded mode)
function DeviceLogsSection({ deviceId }: { deviceId: string }) {
  return (
    <LogsTable 
      deviceId={deviceId} 
      embedded={true} 
    />
  )
}

// With imperative refresh control
function LogsWithRefresh() {
  const logsTableRef = useRef<LogsTableRef>(null)
  
  const handleRefreshLogs = () => {
    logsTableRef.current?.refresh()
  }
  
  return (
    <div>
      <button onClick={handleRefreshLogs}>Refresh Logs</button>
      <LogsTable ref={logsTableRef} />
    </div>
  )
}
```

The component supports both standalone and embedded modes, transforms raw log data into a user-friendly format, and provides comprehensive filtering capabilities across severity levels, tool types, and organizations. It uses cursor-based pagination for efficient data loading and includes responsive design that adapts column visibility based on screen size.
