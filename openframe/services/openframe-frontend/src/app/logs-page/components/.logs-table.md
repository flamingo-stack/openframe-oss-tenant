A React component that displays a paginated table of log entries with filtering, search, and detailed view capabilities for the OpenFrame platform.

## Key Components

- **LogsTable**: Main component with forwardRef support for refresh functionality
- **LogsTableRef**: Interface exposing refresh method for parent components
- **UILogEntry**: Type definition for transformed log data structure
- **LogInfoModal**: Modal component for detailed log information display
- **Table Integration**: Uses OpenFrame UI components with cursor-based pagination
- **Filter Management**: Multi-column filtering by severity, tool type, and organization
- **Search & Pagination**: Real-time search with cursor-based pagination state management

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table'
import { useRef } from 'react'

function LogsPage() {
  const tableRef = useRef<LogsTableRef>(null)

  const handleRefresh = () => {
    tableRef.current?.refresh()
  }

  return (
    <div>
      <button onClick={handleRefresh}>Refresh Logs</button>
      
      {/* Full page mode */}
      <LogsTable ref={tableRef} />
      
      {/* Embedded mode for specific device */}
      <LogsTable 
        ref={tableRef}
        deviceId="device-123"
        embedded={true}
      />
    </div>
  )
}
```

The component supports both standalone and embedded modes, automatically transforms API data to UI format, and provides rich filtering capabilities with external link navigation to detailed log views.
