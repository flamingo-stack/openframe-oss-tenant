A React component that displays system logs in a paginated table format with filtering, search, and detailed view capabilities.

## Key Components

- **LogsTable**: Main table component with cursor pagination and real-time filtering
- **LogsTableRef**: Imperative handle interface exposing refresh functionality
- **UILogEntry**: Type definition for transformed log entries with status, device, and source information
- **LogInfoModal**: Side modal for displaying detailed log information
- **Filter Integration**: Multi-dimensional filtering by severity, tool type, and organization
- **Cursor Pagination**: Server-side pagination with navigation controls

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table'
import { useRef } from 'react'

// Basic usage
function LogsPage() {
  return <LogsTable />
}

// Device-specific embedded usage
function DeviceLogsSection({ deviceId }: { deviceId: string }) {
  const tableRef = useRef<LogsTableRef>(null)
  
  const handleRefresh = () => {
    tableRef.current?.refresh()
  }
  
  return (
    <div>
      <button onClick={handleRefresh}>Refresh Logs</button>
      <LogsTable 
        ref={tableRef}
        deviceId={deviceId} 
        embedded={true} 
      />
    </div>
  )
}

// Access log details programmatically
const logDetailsUrl = `/log-details?id=${logId}&ingestDay=${ingestDay}&toolType=${toolType}`
```

The component supports both standalone and embedded modes, automatically handles URL state management for filters and pagination, and provides external navigation to detailed log views.
