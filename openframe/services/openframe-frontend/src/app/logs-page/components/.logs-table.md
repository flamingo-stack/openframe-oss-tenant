A React component that renders a comprehensive logs table with search, filtering, pagination, and modal details for system/device logs.

## Key Components

- **LogsTable** - Main forwardRef component with optional device-specific or embedded modes
- **LogsTableRef** - Interface exposing refresh method for parent components
- **UILogEntry** - Type definition for transformed log entries with status, device, and description info
- **LogInfoModal** - Side panel modal for detailed log information
- **Table Component** - Core table with filtering, pagination, and row actions

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table'
import { useRef } from 'react'

// General logs table with full layout
function LogsPage() {
  const tableRef = useRef<LogsTableRef>(null)
  
  return (
    <div>
      <button onClick={() => tableRef.current?.refresh()}>
        Refresh Logs
      </button>
      <LogsTable ref={tableRef} />
    </div>
  )
}

// Device-specific embedded table
function DeviceDetails() {
  return (
    <div>
      <h2>Device Logs</h2>
      <LogsTable 
        deviceId="device-123" 
        embedded={true} 
      />
    </div>
  )
}
```

The component features cursor-based pagination, multi-column filtering (status, tool type, organization), real-time search, and transforms API log entries into a user-friendly format with status badges, tool icons, and device information. In embedded mode, it removes the device column and layout wrapper for integration into other views.
