A React table component for displaying and managing system logs with filtering, pagination, and detailed log viewing capabilities.

## Key Components

- **LogsTable** - Main table component with forwardRef for external control
- **LogsTableRef** - Interface exposing refresh method for parent components
- **UILogEntry** - Transformed log entry interface for UI display
- **LogInfoModal** - Modal component for viewing detailed log information
- **Table columns** - Configurable columns with filtering and responsive design
- **Cursor pagination** - Server-side pagination with next/previous navigation
- **Filter system** - Multi-dimensional filtering by severity, tool type, and organization

## Usage Example

```typescript
import { LogsTable, LogsTableRef } from './logs-table'
import { useRef } from 'react'

function LogsPage() {
  const logsTableRef = useRef<LogsTableRef>(null)

  const handleRefreshLogs = () => {
    logsTableRef.current?.refresh()
  }

  return (
    <div>
      <button onClick={handleRefreshLogs}>
        Refresh Logs
      </button>
      
      {/* Full page logs table */}
      <LogsTable ref={logsTableRef} />
      
      {/* Device-specific embedded table */}
      <LogsTable 
        deviceId="device-123" 
        embedded={true} 
      />
    </div>
  )
}
```

The component supports both full-page and embedded modes, with the embedded version hiding certain columns and actions for device-specific log displays. It includes real-time filtering, search functionality, and detailed log inspection through a modal interface.
