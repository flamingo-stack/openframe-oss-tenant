A React component that displays logs in a filterable, paginated table format with support for both standalone and embedded modes.

## Key Components

**Exports:**
- `LogsTable` - Main table component with forwarded ref
- `LogsTableRef` - Interface for imperative refresh method
- `UILogEntry` - Interface defining the transformed log data structure

**Core Features:**
- Server-side cursor pagination with URL state management
- Multi-column filtering (severity, tool type, organization)
- Responsive design with conditional column hiding
- Modal detail view and external link navigation
- Real-time search with debounced API calls

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table'
import { useRef } from 'react'

function LogsPage() {
  const tableRef = useRef<LogsTableRef>(null)

  const handleRefresh = () => {
    tableRef.current?.refresh()
  }

  return (
    <div>
      <button onClick={handleRefresh}>Refresh Logs</button>
      
      {/* Standalone mode with full layout */}
      <LogsTable ref={tableRef} />
      
      {/* Embedded mode for device-specific logs */}
      <LogsTable 
        deviceId="device-123" 
        embedded={true} 
      />
    </div>
  )
}
```

The component transforms raw log entries into a UI-friendly format with status badges, tool labels, and device information. It handles complex state management for filters, pagination, and search while providing both embedded and full-page layouts.
