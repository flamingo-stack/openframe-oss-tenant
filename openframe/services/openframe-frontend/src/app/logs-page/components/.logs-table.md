A React component that displays a comprehensive logs table with filtering, search, and pagination capabilities for the Flamingo platform.

## Key Components

- **LogsTable**: Main table component that displays system logs with status, source, device, and description information
- **LogsTableRef**: Interface exposing refresh functionality
- **UILogEntry**: Interface defining the transformed log data structure for display
- **LogInfoModal**: Modal component for viewing detailed log information
- **Filter System**: Multi-level filtering by severities, tool types, and organizations
- **Cursor Pagination**: Server-side pagination with next/reset functionality

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table'
import { useRef } from 'react'

// Basic usage
function LogsPage() {
  return (
    <div>
      <LogsTable />
    </div>
  )
}

// Device-specific logs
function DeviceLogsTab({ deviceId }: { deviceId: string }) {
  return (
    <LogsTable 
      deviceId={deviceId} 
      embedded={true} 
    />
  )
}

// With ref for programmatic refresh
function LogsWithRefresh() {
  const logsRef = useRef<LogsTableRef>(null)
  
  const handleRefresh = () => {
    logsRef.current?.refresh()
  }
  
  return (
    <div>
      <button onClick={handleRefresh}>Refresh Logs</button>
      <LogsTable ref={logsRef} />
    </div>
  )
}
```

The component supports both full-page display and embedded mode, with automatic data transformation from backend log entries to UI-friendly format. Features include real-time filtering, search functionality, and detailed log inspection through modals.
