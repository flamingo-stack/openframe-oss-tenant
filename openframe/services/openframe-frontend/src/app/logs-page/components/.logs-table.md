A React table component for displaying and managing IT logs with comprehensive filtering, pagination, and detail viewing capabilities.

## Key Components

### Main Exports
- **`LogsTable`** - Forwardable React component with filtering, search, and pagination
- **`LogsTableRef`** - Interface exposing refresh functionality via ref
- **`LogsTableProps`** - Props interface supporting device-specific and embedded modes
- **`UILogEntry`** - Transformed log entry interface optimized for table display

### Core Features
- **Server-side pagination** with cursor-based navigation
- **Multi-column filtering** by severity, tool type, and organization
- **Real-time search** with debounced API calls
- **Modal detail view** for individual log entries
- **Responsive design** with column hiding on smaller screens
- **External navigation** to detailed log pages

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table'
import { useRef } from 'react'

// Basic usage
function LogsPage() {
  const tableRef = useRef<LogsTableRef>(null)
  
  return (
    <LogsTable 
      ref={tableRef}
      onRefresh={() => tableRef.current?.refresh()}
    />
  )
}

// Device-specific embedded mode
function DeviceDetail({ deviceId }: { deviceId: string }) {
  return (
    <LogsTable 
      deviceId={deviceId}
      embedded={true}
    />
  )
}
```

The component integrates with OpenFrame's design system and provides comprehensive log management functionality including status badges, tool identification, and device information display.
