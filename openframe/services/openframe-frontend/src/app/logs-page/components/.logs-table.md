A React table component for displaying and managing system logs with filtering, search, and pagination capabilities. It transforms raw log data into a user-friendly format and provides both embedded and full-page views.

## Key Components

- **LogsTable** - Main component with forwardRef for external refresh control
- **UILogEntry** - Transformed log data interface for UI display
- **LogsTableRef** - Reference interface exposing refresh method
- **Column Configuration** - Dynamic table columns based on context (embedded vs full view)
- **Filter Integration** - Severity, tool type, and organization filtering
- **Cursor Pagination** - Server-side pagination with navigation controls
- **Modal Integration** - Log details modal for expanded information

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table'
import { useRef } from 'react'

// Full-featured logs table
function LogsPage() {
  const tableRef = useRef<LogsTableRef>(null)
  
  const handleRefresh = () => {
    tableRef.current?.refresh()
  }

  return (
    <div>
      <button onClick={handleRefresh}>Refresh Logs</button>
      <LogsTable ref={tableRef} />
    </div>
  )
}

// Device-specific embedded logs
function DeviceDetailsPanel({ deviceId }: { deviceId: string }) {
  return (
    <LogsTable 
      deviceId={deviceId} 
      embedded={true} 
    />
  )
}
```

The component handles log data transformation, applies consistent styling with status badges and tool icons, and integrates with the OpenFrame design system. It supports both standalone usage and embedding within device detail views.
