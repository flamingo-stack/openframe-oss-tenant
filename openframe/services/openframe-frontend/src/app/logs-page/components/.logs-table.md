A React table component for displaying system logs with filtering, pagination, and modal details view.

## Key Components

- **LogsTable** - Main table component with forwardRef for external control
- **LogsTableRef** - Interface exposing refresh method to parent components
- **UILogEntry** - Type definition for transformed log data structure
- **LogsTableProps** - Component props supporting device-specific and embedded modes
- **LogInfoModal** - Side panel for displaying detailed log information
- **Table** - Core table with sortable columns, filters, and cursor pagination

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table'
import { useRef } from 'react'

// Basic usage - all logs
function AllLogsPage() {
  const tableRef = useRef<LogsTableRef>(null)
  
  return (
    <div>
      <button onClick={() => tableRef.current?.refresh()}>
        Refresh Logs
      </button>
      <LogsTable ref={tableRef} />
    </div>
  )
}

// Device-specific embedded mode
function DeviceLogsSection({ deviceId }: { deviceId: string }) {
  return (
    <LogsTable 
      deviceId={deviceId} 
      embedded={true} 
    />
  )
}
```

The component transforms backend log entries into a standardized UI format, supports multi-column filtering (severity, tool type, organization), implements cursor-based pagination, and provides both full-page and embedded display modes. Row clicks open detailed log information in a side modal.
