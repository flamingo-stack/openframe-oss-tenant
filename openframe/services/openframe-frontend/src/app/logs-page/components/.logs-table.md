A React table component for displaying and managing system logs with filtering, pagination, and detailed views.

## Key Components

- **LogsTable**: Main forwardRef component with search, filtering, and cursor pagination
- **LogsTableRef**: Interface exposing refresh method for parent components  
- **UILogEntry**: Internal interface transforming API log data for table display
- **LogInfoModal**: Side panel modal for viewing detailed log information

## Usage Example

```typescript
import { LogsTable, LogsTableRef } from './logs-table'
import { useRef } from 'react'

// Standalone logs page
function LogsPage() {
  const tableRef = useRef<LogsTableRef>(null)
  
  const handleRefresh = () => {
    tableRef.current?.refresh()
  }

  return (
    <LogsTable 
      ref={tableRef}
      embedded={false} 
    />
  )
}

// Embedded in device details
function DeviceLogsTab({ deviceId }: { deviceId: string }) {
  return (
    <LogsTable 
      deviceId={deviceId}
      embedded={true}
    />
  )
}
```

The component supports:
- **Multi-column filtering** by status, tool type, and organization
- **Real-time search** with debounced API calls
- **Cursor-based pagination** for efficient large dataset handling
- **Responsive design** with column hiding at different breakpoints
- **Row actions** for external log detail navigation
- **Modal details view** with expandable log information

Uses OpenFrame UI components and integrates with the logs API hooks for data fetching and state management.
