A React component that displays system logs in a responsive, paginated table format with filtering, search, and modal detail views.

## Key Components

**Main Component:**
- `LogsTable` - Primary table component with forwardRef for external refresh control
- `UILogEntry` - TypeScript interface defining the transformed log data structure
- `LogsTableRef` - Ref interface exposing refresh functionality

**Core Features:**
- Cursor-based pagination with server-side data fetching
- Multi-column filtering (status, tool type, organization)
- Real-time search with debounced input
- Modal detail view for individual log entries
- Responsive design with column hiding at different breakpoints
- Embedded mode for device-specific log display

## Usage Example

```typescript
import { LogsTable, LogsTableRef } from './logs-table'
import { useRef } from 'react'

// Basic usage
function LogsPage() {
  return <LogsTable />
}

// Device-specific embedded view
function DeviceDetails({ deviceId }: { deviceId: string }) {
  return <LogsTable deviceId={deviceId} embedded />
}

// With ref for external refresh control
function LogsWithRefresh() {
  const logsTableRef = useRef<LogsTableRef>(null)
  
  const handleRefresh = () => {
    logsTableRef.current?.refresh()
  }
  
  return (
    <div>
      <button onClick={handleRefresh}>Refresh Logs</button>
      <LogsTable ref={logsTableRef} />
    </div>
  )
}
```

The component integrates with OpenFrame's design system and uses custom hooks for state management, API calls, and pagination. It transforms raw log entries into a consistent UI format with proper status indicators, tool badges, and device information display.
