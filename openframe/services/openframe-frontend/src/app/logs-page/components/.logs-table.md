A React table component for displaying and managing system logs with advanced filtering, pagination, and detail views.

## Key Components

- **LogsTable** - Main table component with cursor pagination and filter management
- **LogsTableRef** - Forward ref interface exposing refresh functionality
- **UILogEntry** - Transformed log data structure for display purposes
- **LogInfoModal** - Side panel modal for detailed log information

## Usage Example

```typescript
import { LogsTable, LogsTableRef } from './logs-table'
import { useRef } from 'react'

// Basic usage
function LogsPage() {
  const tableRef = useRef<LogsTableRef>(null)
  
  const handleRefresh = () => {
    tableRef.current?.refresh()
  }

  return (
    <div>
      <button onClick={handleRefresh}>Refresh Logs</button>
      <LogsTable ref={tableRef} />
    </div>
  )
}

// Device-specific logs (embedded mode)
function DeviceLogsSection({ deviceId }: { deviceId: string }) {
  return (
    <LogsTable 
      deviceId={deviceId} 
      embedded={true} 
    />
  )
}
```

The component provides comprehensive log management with real-time filtering by severity, tool type, and organization. It supports both standalone and embedded modes, includes cursor-based pagination for efficient data loading, and offers detailed log inspection through modal dialogs. The table automatically transforms API log entries into a UI-friendly format with proper status indicators, tool badges, and device information.
