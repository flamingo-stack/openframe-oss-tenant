A React component that displays logs in a table format with filtering, pagination, and detailed views. Supports both standalone and embedded modes with real-time log refresh capabilities.

## Key Components

- **LogsTable** - Main table component with cursor-based pagination and filtering
- **LogsTableRef** - Imperative handle exposing refresh functionality
- **UILogEntry** - Transformed log data interface for UI display
- **LogInfoModal** - Modal component for detailed log information
- **Filter system** - Multi-column filtering by severity, tool type, and organization
- **Row actions** - External link button for detailed log views

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table'
import { useRef } from 'react'

function LogsPage() {
  const logsTableRef = useRef<LogsTableRef>(null)

  const handleRefreshLogs = () => {
    logsTableRef.current?.refresh()
  }

  return (
    <div>
      <button onClick={handleRefreshLogs}>
        Refresh Logs
      </button>
      
      {/* Standalone mode with full layout */}
      <LogsTable ref={logsTableRef} />
      
      {/* Embedded mode for device-specific logs */}
      <LogsTable 
        deviceId="device-123" 
        embedded={true} 
        ref={logsTableRef}
      />
    </div>
  )
}
```

The component features cursor-based pagination, real-time filtering by severity/tool type/organization, clickable rows for detailed views, and supports both standalone pages and embedded device-specific displays. It automatically transforms API log entries into UI-friendly format with proper status badges and tool labels.
