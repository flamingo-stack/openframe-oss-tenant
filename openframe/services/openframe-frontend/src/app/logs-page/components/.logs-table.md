A React component that renders a comprehensive logs table with filtering, search, pagination, and modal details. Supports both standalone and embedded modes for displaying system logs from various tools and devices.

## Key Components

- **LogsTable**: Main component with forwardRef support for external refresh control
- **UILogEntry**: Interface for transformed log data with status, source, device, and description
- **LogsTableRef**: Exposed ref interface with refresh method
- **Table Integration**: Uses OpenFrame's Table component with custom columns and filtering
- **LogInfoModal**: Side panel modal for detailed log information
- **Cursor Pagination**: Server-side pagination with cursor-based navigation

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table'
import { useRef } from 'react'

// Standalone logs table
function LogsPage() {
  const logsTableRef = useRef<LogsTableRef>(null)
  
  const handleRefresh = () => {
    logsTableRef.current?.refresh()
  }

  return (
    <div>
      <button onClick={handleRefresh}>Refresh Logs</button>
      <LogsTable ref={logsTableRef} />
    </div>
  )
}

// Embedded device-specific logs
function DeviceDetails({ deviceId }: { deviceId: string }) {
  return (
    <div>
      <h2>Device Logs</h2>
      <LogsTable deviceId={deviceId} embedded={true} />
    </div>
  )
}
```

The component transforms raw log entries into a structured UI format, provides multi-column filtering (severity, tool type, organization), and handles both search and cursor-based pagination. In embedded mode, it hides the organization column and pagination controls for focused device log viewing.
