A comprehensive React table component for displaying and managing system logs with advanced filtering, search, and pagination capabilities.

## Key Components

- **LogsTable**: Main table component with forwardRef support for external control
- **LogsTableRef**: Interface exposing refresh functionality
- **UILogEntry**: TypeScript interface for transformed log data structure
- **LogInfoModal**: Side panel modal for detailed log information
- **Filter system**: Multi-column filtering for status, tools, and organizations
- **Cursor pagination**: Server-side pagination with state management
- **Search functionality**: Real-time log search with debouncing

## Usage Example

```typescript
import { LogsTable, LogsTableRef } from './logs-table'
import { useRef } from 'react'

// Basic usage
function LogsPage() {
  return <LogsTable />
}

// Device-specific logs in embedded mode
function DeviceLogsSection({ deviceId }: { deviceId: string }) {
  const tableRef = useRef<LogsTableRef>(null)
  
  const handleRefresh = () => {
    tableRef.current?.refresh()
  }

  return (
    <div>
      <button onClick={handleRefresh}>Refresh Logs</button>
      <LogsTable 
        ref={tableRef}
        deviceId={deviceId} 
        embedded={true} 
      />
    </div>
  )
}

// With external filter control
function AdvancedLogsPage() {
  return (
    <LogsTable 
      deviceId="device-123"
      embedded={false}
    />
  )
}
```

The component supports both standalone and embedded modes, with automatic data transformation from API responses to UI-friendly formats. It includes responsive design with column hiding at different breakpoints and comprehensive error handling.
