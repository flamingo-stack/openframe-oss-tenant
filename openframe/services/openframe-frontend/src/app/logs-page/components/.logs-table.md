A React component that displays logs in a sortable, filterable table with pagination and modal details view.

## Key Components

- **LogsTable** - Main component with forwardRef for external control
- **LogsTableRef** - Interface exposing refresh functionality  
- **UILogEntry** - Transformed log entry interface for UI display
- **LogInfoModal** - Modal for viewing detailed log information
- **Cursor pagination** - Server-side pagination with next/previous navigation
- **Filter system** - Multi-column filtering by status, tool type, and organization
- **Embedded mode** - Simplified view for device-specific log display

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table'
import { useRef } from 'react'

function LogsPage() {
  const logsTableRef = useRef<LogsTableRef>(null)

  const handleRefresh = () => {
    logsTableRef.current?.refresh()
  }

  return (
    <div>
      <button onClick={handleRefresh}>Refresh Logs</button>
      
      {/* Full page logs table */}
      <LogsTable ref={logsTableRef} />
      
      {/* Device-specific embedded view */}
      <LogsTable 
        deviceId="device-123" 
        embedded={true}
      />
    </div>
  )
}
```

The component transforms API log entries into a UI-friendly format with status badges, tool icons, device information, and timestamps. It supports both standalone and embedded modes, with the embedded version removing organization filters and pagination for device-specific views. External log detail pages open in new tabs via the Details button.
