This React component provides a comprehensive logs table interface for displaying and managing system logs with advanced filtering and pagination capabilities.

## Key Components

- **LogsTable**: Main component with embedded mode support for device-specific views
- **UILogEntry**: Interface defining the transformed log data structure 
- **LogsTableRef**: Ref interface exposing refresh functionality
- **Column Configuration**: Dynamic table columns with responsive hiding and filtering
- **Filter Management**: Multi-dimensional filtering by severity, tool type, and organization
- **Cursor Pagination**: Server-side pagination with infinite scroll capabilities
- **LogInfoModal Integration**: Modal for detailed log viewing

## Usage Example

```typescript
import { LogsTable, LogsTableRef } from './logs-table'

// Basic usage
function LogsPage() {
  return <LogsTable />
}

// Embedded mode for device-specific logs
function DeviceLogsSection({ deviceId }: { deviceId: string }) {
  return <LogsTable deviceId={deviceId} embedded />
}

// With ref for manual refresh
function LogsWithRefresh() {
  const logsRef = useRef<LogsTableRef>(null)
  
  const handleRefresh = () => {
    logsRef.current?.refresh()
  }
  
  return (
    <div>
      <button onClick={handleRefresh}>Refresh Logs</button>
      <LogsTable ref={logsRef} />
    </div>
  )
}
```

The component handles log transformation from backend format to UI-friendly structure, implements responsive column management, and provides both standalone and embedded viewing modes with comprehensive filtering and search capabilities.
