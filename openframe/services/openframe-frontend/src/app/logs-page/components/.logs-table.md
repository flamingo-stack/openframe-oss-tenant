A React component that displays logs in a paginated table format with filtering, search, and detailed log viewing capabilities.

## Key Components

- **LogsTable** - Main table component with forwardRef for external refresh control
- **LogsTableRef** - Interface exposing refresh method to parent components
- **UILogEntry** - Type definition for transformed log entries with UI-friendly properties
- **LogInfoModal** - Side panel modal for viewing detailed log information
- **Filter Management** - Handles severity, tool type, and organization filtering
- **Cursor Pagination** - Server-side pagination with next/previous navigation

## Usage Example

```typescript
// Basic usage
<LogsTable />

// Embedded mode for device-specific logs
<LogsTable deviceId="device-123" embedded={true} />

// With ref for external refresh control
const tableRef = useRef<LogsTableRef>(null);

const handleRefresh = () => {
  tableRef.current?.refresh();
};

<LogsTable ref={tableRef} />
```

## Key Features

- **Multi-level Filtering** - Filter by severity, tool type, and organization
- **Real-time Search** - Search across log descriptions and metadata
- **Responsive Design** - Columns hide/show based on screen size
- **External Link Navigation** - Opens detailed log views in new tabs
- **Modal Details** - Quick preview of log information in side panel
- **Cursor Pagination** - Efficient server-side pagination for large datasets
- **Auto-refresh** - Supports programmatic refresh via ref interface

The component transforms raw log data into a user-friendly format with proper status badges, tool icons, and device information cards. It integrates with the broader OpenFrame UI system for consistent styling and behavior.
