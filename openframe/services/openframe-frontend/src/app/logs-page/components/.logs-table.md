A comprehensive React table component for displaying and managing OpenFrame log entries with filtering, pagination, and embedded mode support.

## Key Components

- **LogsTable**: Main table component with cursor pagination, filtering, and search functionality
- **UILogEntry**: Type definition for transformed log entries with status, source, device, and description data
- **LogsTableRef**: Imperative API for external refresh control
- **Column Configuration**: Responsive column setup with conditional rendering for embedded mode
- **Filter System**: Multi-dimensional filtering by severity, tool type, and organization
- **Modal Integration**: Log details modal for expanded log information

## Usage Example

```typescript
// Standard logs table with full features
import { LogsTable, type LogsTableRef } from './logs-table'

function LogsPage() {
  const logsTableRef = useRef<LogsTableRef>(null)
  
  const handleRefresh = () => {
    logsTableRef.current?.refresh()
  }

  return (
    <div>
      <button onClick={handleRefresh}>Refresh Logs</button>
      <LogsTable ref={logsTableRef} />
    </div>
  )
}

// Embedded mode for device-specific logs
function DeviceDetails({ deviceId }: { deviceId: string }) {
  return (
    <div>
      <h2>Device Logs</h2>
      <LogsTable 
        deviceId={deviceId} 
        embedded={true} 
      />
    </div>
  )
}
```

The component supports both standalone and embedded modes, with the embedded version hiding certain columns and pagination controls while filtering logs by device ID. It integrates with OpenFrame's design system and provides real-time log monitoring with advanced filtering capabilities.
