A React component that displays and manages log entries in a paginated table format with filtering, search, and modal capabilities for OpenFrame.

## Key Components

- **LogsTable**: Main component that renders log entries with server-side pagination, filtering by severity/tool type/organization, and search functionality
- **LogsTableRef**: Ref interface exposing a `refresh()` method for external control
- **UILogEntry**: Interface defining the transformed log entry structure for display
- **LogInfoModal**: Modal component for displaying detailed log information
- **Table Columns**: Configurable columns including log ID, status, tool, source, and description

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table'
import { useRef } from 'react'

// Standalone logs table
function LogsPage() {
  const tableRef = useRef<LogsTableRef>(null)
  
  const handleRefresh = () => {
    tableRef.current?.refresh()
  }
  
  return (
    <div>
      <button onClick={handleRefresh}>Refresh Logs</button>
      <LogsTable ref={tableRef} />
    </div>
  )
}

// Device-specific embedded logs
function DeviceDetails({ deviceId }: { deviceId: string }) {
  return (
    <div>
      <h2>Device Details</h2>
      <LogsTable deviceId={deviceId} embedded={true} />
    </div>
  )
}
```

The component transforms raw log data into a user-friendly format, handles cursor-based pagination, supports column filtering, and provides modal views for detailed log inspection. It can operate in embedded mode for device-specific logs or as a standalone page component.
