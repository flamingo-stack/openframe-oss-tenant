A React table component for displaying system logs with filtering, pagination, and detailed views.

## Key Components

- **LogsTable**: Main component that displays logs in a table format with filtering and pagination
- **LogsTableRef**: Ref interface exposing refresh method
- **UILogEntry**: Type definition for transformed log data optimized for UI display
- **LogInfoModal**: Modal component for displaying detailed log information

The component supports both standalone and embedded modes, with cursor-based pagination and real-time filtering by severity, tool type, and organization.

## Usage Example

```typescript
import { LogsTable, LogsTableRef } from './logs-table'
import { useRef } from 'react'

// Standalone logs table
function LogsPage() {
  const tableRef = useRef<LogsTableRef>(null)
  
  const handleRefresh = () => {
    tableRef.current?.refresh()
  }
  
  return (
    <div>
      <button onClick={handleRefresh}>Refresh Logs</button>
      <LogsTable ref={tableRef} />
    </div>
  )
}

// Embedded in device view
function DevicePage({ deviceId }: { deviceId: string }) {
  return (
    <LogsTable 
      deviceId={deviceId} 
      embedded={true} 
    />
  )
}
```

The component integrates with OpenFrame's data fetching hooks and UI components, providing comprehensive log management with search, filtering, and detailed inspection capabilities.
