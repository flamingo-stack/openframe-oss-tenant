React component that displays logs in a paginated table format with filtering, searching, and modal details view.

## Key Components

- **LogsTable** - Main table component with cursor pagination and filtering capabilities
- **LogsTableRef** - Interface exposing refresh method for external control
- **UILogEntry** - Interface defining the transformed log entry structure used in the UI
- **LogInfoModal** - Modal component for viewing detailed log information
- **Table/ListPageLayout** - Core UI components for data display and page structure

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table'
import { useRef } from 'react'

// Basic usage
function LogsPage() {
  return <LogsTable />
}

// Device-specific logs (embedded mode)
function DeviceLogsSection({ deviceId }: { deviceId: string }) {
  return <LogsTable deviceId={deviceId} embedded />
}

// With ref for manual refresh
function LogsDashboard() {
  const logsRef = useRef<LogsTableRef>(null)

  const handleRefreshLogs = () => {
    logsRef.current?.refresh()
  }

  return (
    <div>
      <button onClick={handleRefreshLogs}>Refresh Logs</button>
      <LogsTable ref={logsRef} />
    </div>
  )
}
```

The component supports filtering by severity, tool type, and organization, with real-time search and cursor-based pagination. It can operate in embedded mode for device-specific log views or as a full-page layout for system-wide log management. Log entries are transformed from the API format to a UI-friendly structure with status badges, tool identification, and device information.
