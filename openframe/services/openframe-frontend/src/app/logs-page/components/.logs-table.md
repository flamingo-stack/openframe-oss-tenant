A React component that displays a table of log entries with filtering, pagination, and detailed log viewing capabilities.

## Key Components

### Main Export
- **`LogsTable`** - Forwardable ref component that renders log data in a table format

### Key Features
- **Filtering** - Supports filtering by severity, tool types, and organizations
- **Search** - Real-time search through log entries
- **Pagination** - Cursor-based pagination for large datasets
- **Modal Details** - Click-to-view detailed log information
- **Device Embedding** - Can be embedded in device-specific views

### Props Interface
- **`LogsTableProps`** - Configuration for device-specific filtering and embedded mode
- **`LogsTableRef`** - Exposed refresh method for external control

### Data Transformation
- **`UILogEntry`** - Transforms raw API log data into UI-friendly format
- **Column Configuration** - Dynamic column setup based on embedded mode

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table'
import { useRef } from 'react'

function LogsPage() {
  const logsTableRef = useRef<LogsTableRef>(null)
  
  const handleRefreshLogs = () => {
    logsTableRef.current?.refresh()
  }
  
  return (
    <div>
      {/* Standalone logs table */}
      <LogsTable ref={logsTableRef} />
      
      {/* Device-specific embedded table */}
      <LogsTable 
        deviceId="device-123" 
        embedded={true} 
      />
      
      <button onClick={handleRefreshLogs}>
        Refresh Logs
      </button>
    </div>
  )
}
```

The component handles complex state management for filters, search, and pagination while providing a clean interface for viewing system logs across different tools and devices.
