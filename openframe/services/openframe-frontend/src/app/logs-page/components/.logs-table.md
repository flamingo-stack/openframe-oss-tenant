A React table component for displaying and managing system logs with filtering, pagination, and detailed views.

## Key Components

- **LogsTable** - Main table component with forwardRef for external control
- **LogsTableRef** - Interface exposing refresh method for parent components
- **UILogEntry** - Type definition for transformed log entries with UI-friendly properties
- **LogInfoModal** - Side panel modal for detailed log information

## Usage Example

```typescript
import { LogsTable, type LogsTableRef } from './logs-table'
import { useRef } from 'react'

// Basic usage
function LogsPage() {
  return <LogsTable />
}

// Device-specific logs (embedded mode)
function DeviceLogsSection({ deviceId }: { deviceId: string }) {
  return (
    <LogsTable 
      deviceId={deviceId}
      embedded={true}
    />
  )
}

// With ref for external control
function LogsManagement() {
  const logsTableRef = useRef<LogsTableRef>(null)

  const handleRefresh = () => {
    logsTableRef.current?.refresh()
  }

  return (
    <div>
      <button onClick={handleRefresh}>Refresh Logs</button>
      <LogsTable ref={logsTableRef} />
    </div>
  )
}
```

The component features server-side cursor pagination, real-time filtering by severity/tool type/organization, row click handlers for detailed views, and responsive design with column hiding at different breakpoints. It transforms raw log data into UI-friendly format with status badges, tool labels, and device cards.
