A comprehensive table component for displaying and managing system logs with filtering, pagination, and modal details view.

## Key Components

**Main Export:**
- `LogsTable` - React component with `LogsTableRef` for external refresh control

**Core Features:**
- Server-side filtering by severity, tool type, and organization
- Cursor-based pagination with search functionality
- Row click to open detailed log modal
- Device-specific embedded mode
- External link to full log details page

**Key Interfaces:**
- `UILogEntry` - Transformed log data structure for UI display
- `LogsTableProps` - Component configuration (deviceId, embedded mode)
- `LogsTableRef` - Imperative handle for refresh functionality

## Usage Example

```typescript
import { LogsTable, LogsTableRef } from './logs-table'

// Basic usage
function LogsPage() {
  return <LogsTable />
}

// Device-specific embedded view
function DeviceDashboard({ deviceId }: { deviceId: string }) {
  const logsTableRef = useRef<LogsTableRef>(null)
  
  const handleRefresh = () => {
    logsTableRef.current?.refresh()
  }
  
  return (
    <div>
      <button onClick={handleRefresh}>Refresh Logs</button>
      <LogsTable 
        ref={logsTableRef}
        deviceId={deviceId} 
        embedded={true} 
      />
    </div>
  )
}
```

The component transforms raw log entries into a structured format with timestamp, status badges, tool badges, device information, and description. It supports both full-page and embedded modes, with the embedded version hiding certain columns and pagination controls for cleaner integration into dashboards.
