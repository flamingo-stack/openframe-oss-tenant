A modal component that displays detailed information about system logs, including source details, device information, and raw log data in a sliding panel interface.

## Key Components

- **LogInfoModal** - Main modal component with slide-in animation from the right
- **InfoField** - Reusable component for displaying labeled key-value pairs
- **LogInfoModalProps** - TypeScript interface defining the log data structure and callbacks
- **DetailedLogData** - Interface for enhanced log details fetched asynchronously

## Usage Example

```typescript
import { LogInfoModal } from './log-info-modal'

function LogsPage() {
  const [selectedLog, setSelectedLog] = useState(null)
  const [isModalOpen, setIsModalOpen] = useState(false)

  const fetchLogDetails = async (logEntry: any) => {
    // Fetch additional log details from API
    const response = await api.getLogDetails(logEntry.toolEventId)
    return response.data
  }

  return (
    <>
      <LogInfoModal
        isOpen={isModalOpen}
        onClose={() => {
          setIsModalOpen(false)
          setSelectedLog(null)
        }}
        log={selectedLog}
        fetchLogDetails={fetchLogDetails}
      />
    </>
  )
}
```

The modal features automatic device details fetching, keyboard navigation (ESC to close), click-outside-to-close functionality, and displays formatted log data with source badges, status tags, and device cards when available.
