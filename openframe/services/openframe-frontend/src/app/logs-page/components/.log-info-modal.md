A modal component that displays detailed information about a log entry, including device details, raw data, and metadata in a slide-out panel format.

## Key Components

- **LogInfoModal** - Main modal component with slide-in animation from the right
- **InfoField** - Helper component for displaying label-value pairs with consistent styling
- **LogInfoModalProps** - Interface defining the modal's props including log data and fetch functions
- **DetailedLogData** - Interface for structured log details fetched from the API

## Usage Example

The modal features automatic device detail fetching, keyboard shortcuts (ESC to close), click-outside closing, and displays structured log information including status badges, timestamps, and formatted raw data. It integrates with the device management system to show relevant device cards when available.
