A React modal component that displays detailed information about log entries, including device details, raw data, and interactive elements for MSP log management.

## Key Components

- **LogInfoModal**: Main modal component that slides in from the right side
- **InfoField**: Reusable component for displaying labeled information fields
- **LogInfoModalProps**: Interface defining the modal's props including log data structure
- **DetailedLogData**: Interface for enhanced log data fetched from the API

## Usage Example

```typescript
import { LogInfoModal } from './log-info-modal'

function LogsPage() {
  const [selectedLog, setSelectedLog] = useState(null)
  const [isModalOpen, setIsModalOpen] = useState(false)

  const handleLogClick = (log) => {
    setSelectedLog(log)
    setIsModalOpen(true)
  }

  const fetchLogDetails = async (logEntry) => {
    // Fetch detailed log information from API
    const response = await api.getLogDetails(logEntry.toolEventId)
    return response.data
  }

  return (
    <>
      {/* Log list component */}
      <LogInfoModal
        isOpen={isModalOpen}
        onClose={() => setIsModalOpen(false)}
        log={selectedLog}
        fetchLogDetails={fetchLogDetails}
      />
    </>
  )
}
```

The modal features keyboard navigation (ESC to close), click-outside-to-close functionality, device information integration, and displays both basic log data and detailed raw information in a structured format. It automatically fetches device details when available and provides loading states for better user experience.
