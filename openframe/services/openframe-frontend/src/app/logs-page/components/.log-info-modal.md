A modal component that displays detailed information about log entries in the OpenFrame logging system, featuring device context and raw data visualization.

## Key Components

### Main Component
- **LogInfoModal** - Primary modal component with sliding panel UI from the right side

### Supporting Components
- **InfoField** - Reusable field display component for label-value pairs
- **LogInfoModalProps** - TypeScript interface defining modal props and log data structure
- **DetailedLogData** - Interface for enriched log data fetched from API

### Key Features
- **Device Integration** - Fetches and displays associated device information using `useDeviceDetails` hook
- **Dynamic Data Loading** - Loads detailed log information on modal open
- **Interactive UI** - Supports keyboard (Escape) and click-outside interactions for closing
- **Raw Data Display** - Shows formatted JSON data in a code block with monospace font

## Usage Example

```typescript
import { LogInfoModal } from './log-info-modal'

function LogsPage() {
  const [selectedLog, setSelectedLog] = useState(null)
  const [isModalOpen, setIsModalOpen] = useState(false)

  const fetchLogDetails = async (logEntry: any) => {
    // Implement API call to fetch detailed log data
    const response = await api.getLogDetails({
      toolEventId: logEntry.toolEventId,
      ingestDay: logEntry.ingestDay,
      toolType: logEntry.toolType,
      eventType: logEntry.eventType,
      timestamp: logEntry.timestamp
    })
    return response.data
  }

  return (
    <>
      {/* Log list with click handlers */}
      <LogInfoModal
        isOpen={isModalOpen}
        onClose={() => setIsModalOpen(false)}
        log={selectedLog}
        fetchLogDetails={fetchLogDetails}
      />
    </>
  )
}
```

The component automatically handles device data fetching, keyboard interactions, and displays comprehensive log information including status badges, tool badges, and formatted raw data.
