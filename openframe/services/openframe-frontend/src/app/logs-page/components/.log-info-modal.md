Modal component that displays detailed information for system logs with device context and raw data visualization.

## Key Components

- **LogInfoModal** - Main modal component that slides in from the right side to display log details
- **InfoField** - Reusable component for displaying labeled key-value pairs in the modal
- **LogInfoModalProps** - Interface defining the modal's props including log data and fetch function
- **DetailedLogData** - Interface for enriched log data fetched from the API

## Features

- **Responsive slide-out modal** with backdrop overlay and smooth animations
- **Progressive data loading** - displays initial log data while fetching detailed information
- **Device integration** - automatically fetches and displays associated device details when available
- **Raw data visualization** - shows formatted JSON data in a monospace code block
- **Keyboard navigation** - closes on Escape key press
- **Click-outside handling** - closes when clicking the backdrop
- **Loading states** - visual indicators during data fetching operations

## Usage Example

```typescript
import { LogInfoModal } from './log-info-modal'

function LogsPage() {
  const [selectedLog, setSelectedLog] = useState(null)
  const [isModalOpen, setIsModalOpen] = useState(false)

  const handleLogClick = (log) => {
    setSelectedLog(log)
    setIsModalOpen(true)
  }

  const fetchLogDetails = async (logEntry) => {
    // API call to fetch detailed log information
    return await api.getLogDetails(logEntry.toolEventId)
  }

  return (
    <>
      <LogTable onLogClick={handleLogClick} />
      <LogInfoModal
        isOpen={isModalOpen}
        onClose={() => setIsModalOpen(false)}
        log={selectedLog}
        fetchLogDetails={fetchLogDetails}
      />
    </>
  )
}
```

The component integrates with OpenFrame's design system and provides a comprehensive view of log entries with contextual device information and technical details for troubleshooting.
