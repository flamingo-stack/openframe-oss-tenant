A React modal component for displaying detailed log information with device context, featuring side-panel design and integrated device details.

## Key Components

- **LogInfoModal**: Main modal component that slides in from the right side
- **InfoField**: Helper component for displaying label-value pairs
- **LogInfoModalProps**: TypeScript interface defining the modal's props including log data and fetch functions
- **DetailedLogData**: Interface for enhanced log information fetched from API

## Usage Example

```typescript
import { LogInfoModal } from './log-info-modal'

function LogsView() {
  const [selectedLog, setSelectedLog] = useState(null)
  const [isModalOpen, setIsModalOpen] = useState(false)

  const fetchLogDetails = async (logEntry: any) => {
    // API call to fetch detailed log information
    return await logService.getLogDetails(logEntry)
  }

  return (
    <div>
      {/* Log list */}
      <LogInfoModal
        isOpen={isModalOpen}
        onClose={() => setIsModalOpen(false)}
        log={selectedLog}
        fetchLogDetails={fetchLogDetails}
      />
    </div>
  )
}
```

The modal provides a comprehensive view of log entries including status badges, device information, raw data display, and integrated device card with details button. It features keyboard navigation (ESC to close), click-outside handling, and loading states for both log details and device information fetching.
