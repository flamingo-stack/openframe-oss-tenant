A modal component that displays detailed information about system logs, including source tool details, device information, and raw data with expandable device context.

## Key Components

- **LogInfoModal**: Main modal component with slide-in animation from the right
- **InfoField**: Utility component for displaying label-value pairs
- **LogInfoModalProps**: Interface defining the log data structure and event handlers
- **DetailedLogData**: Interface for enriched log information fetched asynchronously

## Usage Example

```typescript
import { LogInfoModal } from './log-info-modal'

function LogsView() {
  const [selectedLog, setSelectedLog] = useState(null)
  const [modalOpen, setModalOpen] = useState(false)

  const fetchLogDetails = async (logEntry: any) => {
    // Fetch detailed log information from API
    return await api.getLogDetails(logEntry.toolEventId)
  }

  return (
    <>
      <LogList onLogClick={(log) => {
        setSelectedLog(log)
        setModalOpen(true)
      }} />
      
      <LogInfoModal
        isOpen={modalOpen}
        onClose={() => setModalOpen(false)}
        log={selectedLog}
        fetchLogDetails={fetchLogDetails}
      />
    </>
  )
}
```

The modal features:
- **Responsive layout** with fixed right-side positioning
- **Asynchronous data loading** for detailed log information and device details
- **Interactive device cards** with status indicators and navigation buttons  
- **Raw data display** in formatted JSON with monospace font
- **Keyboard navigation** (Escape to close) and click-outside handling
- **Tool badges** and status tags for visual categorization
