Modal component that displays detailed information about a log entry, including device details and raw data in a slide-out panel.

## Key Components

- **LogInfoModal** - Main modal component with slide-out animation from the right
- **InfoField** - Reusable component for displaying label-value pairs
- **LogInfoModalProps** - TypeScript interface defining modal props and log data structure
- **DetailedLogData** - Interface for enriched log data fetched from API

The modal features:
- **Slide-out animation** from the right side
- **Device details integration** with automatic fetching
- **Raw data display** with syntax highlighting
- **Status badges** and tool type indicators
- **Keyboard navigation** (ESC to close)
- **Click-outside-to-close** functionality
- **Loading states** for asynchronous data fetching
