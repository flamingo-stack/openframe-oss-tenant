A side-panel modal component that displays detailed information about log entries with device context and raw data visualization.

## Key Components

- **LogInfoModal**: Main modal component with slide-in animation from the right
- **InfoField**: Utility component for displaying label-value pairs with consistent styling
- **LogInfoModalProps**: Interface defining modal props including log data and fetch functions
- **DetailedLogData**: Interface for enhanced log information fetched from API

## Usage Example

```typescript
import { LogInfoModal } from './log-info-modal'

  }

  const fetchLogDetails = async (logEntry) => {
    // Fetch detailed log information from API
    return await api.getLogDetails(logEntry.toolEventId)
  }

  return (
    <>
      <LogInfoModal

        onClose={() => setIsModalOpen(false)}

        fetchLogDetails={fetchLogDetails}
      />
    </>
  )
}
```

The modal features keyboard navigation (ESC to close), click-outside handling, and automatically fetches both detailed log information and associated device data. It displays structured log details, raw JSON data, and an interactive device card when device information is available.
