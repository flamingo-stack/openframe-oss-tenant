A React authentication component that provides forms for creating organizations and signing in to existing accounts, with domain validation and access code verification for SaaS mode.

## Key Components

- **AuthChoiceSection** - Main component with dual auth options (create org / sign in)
- **State Management** - Handles form validation, loading states, and error messages
- **Domain Validation** - Checks subdomain availability in SaaS mode with suggestions
- **Access Code Validation** - Verifies access codes for organization creation
- **Email Validation** - Validates email format for both forms
- **Organization Name Validation** - Supports international characters with length limits

## Usage Example

```typescript
import { AuthChoiceSection } from './choice-section'

function AuthPage() {
  const handleCreateOrganization = async (
    orgName: string, 
    domain: string, 
    accessCode: string, 
    email: string
  ) => {
    // Create organization logic
    console.log('Creating org:', { orgName, domain, accessCode, email })
  }

  const handleSignIn = async (email: string) => {
    // Sign in logic
    console.log('Signing in:', email)
  }

  return (
    <AuthChoiceSection
      onCreateOrganization={handleCreateOrganization}
      onSignIn={handleSignIn}
      isLoading={false}
    />
  )
}
```

The component adapts behavior based on SaaS mode, showing domain suggestions when subdomains are unavailable and validating access codes for organization creation. Includes proper error handling and toast notifications for user feedback.
