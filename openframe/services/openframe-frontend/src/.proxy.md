Middleware utility that enforces route access control based on the application's deployment mode (`oss-tenant`, `saas-tenant`, or `saas-shared`), redirecting unauthorized requests to the appropriate default path.

## Key Components

- **`getMode()`** — Reads `NEXT_PUBLIC_APP_MODE` env var and returns the current `AppMode`, defaulting to `'oss-tenant'`
- **`isAllowed(pathname)`** — Evaluates whether a given route is accessible in the current mode; static assets are always permitted
- **`defaultRedirect()`** — Returns the fallback redirect path (`/auth` or `/dashboard`) based on the active mode
- **`proxy(request)`** — Main middleware handler; redirects blocked requests or passes them through via `NextResponse`
- **`config.matcher`** — Next.js middleware matcher that excludes static/asset paths from processing

## Mode Behavior

| Mode | Allowed Routes | Redirect |
|---|---|---|
| `oss-tenant` | All routes | `/auth` |
| `saas-tenant` | All except `/auth` | `/dashboard` |
| `saas-shared` | `/` and `/auth` only | `/auth` |

## Usage Example

```typescript
// middleware.ts (Next.js root)
import { proxy } from './proxy';
import { NextRequest } from 'next/server';

export function middleware(request: NextRequest) {
  return proxy(request);
}

export { config } from './proxy';
```

```bash
# Set deployment mode via environment variable
NEXT_PUBLIC_APP_MODE=saas-tenant
```
