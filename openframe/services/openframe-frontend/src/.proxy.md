Middleware utility that enforces route-level access control based on the application's deployment mode (`oss-tenant`, `saas-tenant`, or `saas-shared`), redirecting unauthorized path access to the appropriate default route.

## Key Components

- **`getMode()`** — Reads `NEXT_PUBLIC_APP_MODE` env var and falls back to `'oss-tenant'`
- **`isAllowed(pathname)`** — Determines if a route is accessible in the current app mode; always permits static asset paths
- **`defaultRedirect()`** — Returns the mode-appropriate redirect target (`/auth` or `/dashboard`)
- **`proxy(request)`** — Main exported middleware function; redirects disallowed routes or passes the request through
- **`config`** — Next.js matcher config that excludes static asset paths from middleware processing

### Mode Behavior Summary

| Mode | Allowed Routes | Redirect |
|---|---|---|
| `oss-tenant` | All routes | `/auth` |
| `saas-tenant` | All except `/auth/*` | `/dashboard` |
| `saas-shared` | `/` and `/auth/*` only | `/auth` |

## Usage Example

```typescript
// middleware.ts (Next.js root)
import { proxy } from './proxy';
import { NextRequest } from 'next/server';

export function middleware(request: NextRequest) {
  return proxy(request);
}

export { config } from './proxy';
```

```bash
# .env.local — set deployment mode
NEXT_PUBLIC_APP_MODE=saas-tenant
```

> **Note:** Static paths (`/_next`, `/static`, `/favicon`, `/assets`, `/icons`) are always permitted regardless of mode and are also excluded via the `config` matcher to avoid unnecessary middleware invocations.
