Middleware utility that enforces route access rules based on the app's deployment mode (`oss-tenant`, `saas-tenant`, or `saas-shared`), redirecting unauthorized requests to appropriate default routes.

## Key Components

- **`getMode()`** — Reads `NEXT_PUBLIC_APP_MODE` env var and defaults to `'oss-tenant'`
- **`isAllowed(pathname)`** — Evaluates whether a given pathname is accessible in the current app mode; always permits static assets
- **`defaultRedirect()`** — Returns the fallback redirect path based on mode (`/auth` or `/dashboard`)
- **`proxy(request)`** — Main middleware function; redirects disallowed requests or passes them through
- **`config`** — Next.js matcher config that excludes static/asset paths from middleware processing

## Mode Behavior

| Mode | Allowed Routes | Redirect |
|------|---------------|----------|
| `oss-tenant` | All routes | `/auth` |
| `saas-tenant` | All except `/auth` | `/dashboard` |
| `saas-shared` | `/` and `/auth` only | `/auth` |

## Usage Example

```typescript
// middleware.ts (Next.js root)
import { proxy } from './proxy';
import { NextRequest } from 'next/server';

export function middleware(request: NextRequest) {
  return proxy(request);
}

export { config } from './proxy';
```

```bash
# .env.local — set deployment mode
NEXT_PUBLIC_APP_MODE=saas-tenant
```

> **Note:** Static paths (`/_next`, `/static`, `/favicon`, `/assets`, `/icons`) are always permitted regardless of mode and are excluded from the matcher via `config`.
