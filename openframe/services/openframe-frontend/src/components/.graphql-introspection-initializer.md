React component that initializes GraphQL schema introspection once a user is server-verified as authenticated, and resets the initialization state on logout.

## Key Components

- **`GraphQlIntrospectionInitializer`** — Headless React component (`returns null`) that orchestrates the one-time call to `initializeGraphQlIntrospection` using `useAuthSession` for auth state and a `useRef` guard to prevent duplicate calls.
- **`useAuthSession`** — Hook providing `isAuthenticated` and `isReady` flags derived from server-verified session data (not stale `localStorage`).
- **`initializeGraphQlIntrospection`** — Async function that fetches and caches the GraphQL schema from the remote endpoint.
- **`hasInitialized` ref** — Guards against re-running introspection on re-renders; reset to `false` when the user logs out.

## Usage Example

Mount once near the root of the authenticated layout tree:

```typescript
// app/(authenticated)/layout.tsx
import { GraphQlIntrospectionInitializer } from '@/components/graphql-introspection-initializer';

export default function AuthenticatedLayout({ children }: { children: React.ReactNode }) {
  return (
    <>
      <GraphQlIntrospectionInitializer />
      {children}
    </>
  );
}
```

## Behavior

| State | Action |
|-------|--------|
| `isReady && isAuthenticated` (first time) | Runs `initializeGraphQlIntrospection()` |
| Re-render while still authenticated | Skipped via `hasInitialized` ref guard |
| User logs out (`!isAuthenticated`) | Resets `hasInitialized` to `false` |
| Next login | Introspection runs again |
