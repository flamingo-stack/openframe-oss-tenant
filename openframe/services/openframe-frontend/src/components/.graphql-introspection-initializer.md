Client-side React component that triggers GraphQL schema introspection once a user session is server-verified as authenticated, ensuring introspection runs only once per authenticated session and resets on logout.

## Key Components

- **`GraphQlIntrospectionInitializer`** — Headless React component (`return null`) that manages the lifecycle of GraphQL introspection initialization
- **`useAuthSession`** — Hook providing `isAuthenticated` and `isReady` flags from a server-verified auth session
- **`initializeGraphQlIntrospection`** — Async function that performs the GraphQL schema introspection against the API
- **`hasInitialized` ref** — Guards against duplicate introspection calls across re-renders or effect re-runs; resets to `false` on logout

## Behavior

```text
isReady=true + isAuthenticated=true + hasInitialized=false
    → runs introspection once, sets hasInitialized=true

isAuthenticated=false (logout)
    → resets hasInitialized=false for next login
```

## Usage Example

Mount once near the root of the authenticated layout tree:

```typescript
// app/(dashboard)/layout.tsx
import { GraphQlIntrospectionInitializer } from '@/components/graphql-introspection-initializer';

export default function DashboardLayout({ children }: { children: React.ReactNode }) {
  return (
    <>
      <GraphQlIntrospectionInitializer />
      {children}
    </>
  );
}
```

> The component renders nothing to the DOM — it exists solely for its side effect. Placing it in an authenticated layout ensures introspection only fires for verified sessions, avoiding stale `localStorage` token reads.
