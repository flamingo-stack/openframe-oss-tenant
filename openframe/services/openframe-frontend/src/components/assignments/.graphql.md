Thin wrapper around the internal GraphQL endpoint that handles HTTP and GraphQL-level error extraction, returning typed response data directly.

## Key Components

- **`GraphQlEnvelope<T>`** — Internal interface modelling the standard GraphQL response shape (`data` + `errors`)
- **`postGraphQl<T>`** — Async function that sends a query/variables payload to `/api/graphql` and unwraps the response

## Usage Example

```typescript
import { postGraphQl } from '@/lib/graphql';

interface TicketsResult {
  tickets: { id: string; title: string }[];
}

const data = await postGraphQl<TicketsResult>(
  `query GetTickets($status: String!) {
    tickets(status: $status) { id title }
  }`,
  { status: 'open' }
);

console.log(data.tickets);
```

## Error Handling

Throws an `Error` in three cases:

1. **HTTP failure** — non-OK response from `apiClient`
2. **GraphQL errors** — `errors` array present in the envelope (first message surfaced)
3. **Empty data** — response succeeded but `data` is absent
