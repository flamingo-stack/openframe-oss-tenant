Thin GraphQL client wrapper that sends queries/mutations to the internal `/api/graphql` endpoint and handles response envelope unwrapping and error surfacing.

## Key Components

- **`GraphQlEnvelope<T>`** — Internal interface modeling the standard GraphQL response shape (`data` + `errors` array)
- **`postGraphQl<T>`** — Generic async function that executes a GraphQL operation, unwraps the envelope, and returns typed data or throws on HTTP errors, GraphQL errors, or empty payloads

## Usage Example

```typescript
import { postGraphQl } from '@/lib/graphql';

const GET_USER = `
  query GetUser($id: ID!) {
    user(id: $id) {
      id
      name
      email
    }
  }
`;

interface GetUserData {
  user: { id: string; name: string; email: string };
}

const data = await postGraphQl<GetUserData>(GET_USER, { id: '123' });
console.log(data.user.name);
```

## Error Handling

The function throws in three distinct cases:

| Scenario | Error Message |
|---|---|
| Non-2xx HTTP response | `response.error` or `Request failed with status {status}` |
| GraphQL `errors` array present | First error's `message` field |
| Empty `data` payload | `No data received from server` |
