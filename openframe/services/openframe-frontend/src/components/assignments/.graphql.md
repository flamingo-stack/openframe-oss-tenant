Thin wrapper around the shared `apiClient` for executing GraphQL queries and mutations, handling envelope-level error extraction and type-safe response unwrapping.

## Key Components

- **`GraphQlEnvelope<T>`** — Internal interface modeling the standard GraphQL response shape (`data`, `errors`).
- **`postGraphQl<T>`** — Async function that POSTs a GraphQL query/variables pair to `/api/graphql`, unwraps the envelope, and throws on HTTP errors, GraphQL errors, or missing data.

## Usage Example

```typescript
import { postGraphQl } from '@/lib/graphql';

interface TicketData {
  ticket: { id: string; title: string };
}

const query = `
  query GetTicket($id: ID!) {
    ticket(id: $id) {
      id
      title
    }
  }
`;

const { ticket } = await postGraphQl<TicketData>(query, { id: '123' });
console.log(ticket.title);
```

## Error Handling

Errors are thrown in three scenarios:

| Scenario | Thrown Error |
|---|---|
| Non-2xx HTTP response | HTTP error message or status code |
| GraphQL `errors` array present | First error's `message` field |
| Response `data` is null/undefined | `'No data received from server'` |
