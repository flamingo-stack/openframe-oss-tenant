Fetches and aggregates all items assigned to a given entity (customer, device, knowledge article, or ticket) by running parallel GraphQL queries across every `AssignmentTargetType` and merging the results into a single normalized structure.

## Key Components

### `useAssignedItems(options)` _(primary export)_
React Query hook that fires one query per `AssignmentTargetType` in parallel via `useQueries`. Returns a combined `AssignedItemsResult` with loading state and typed entity arrays.

| Option | Type | Description |
|--------|------|-------------|
| `itemId` | `string \| null` | ID of the source entity. Normalized to a Relay global ID internally. |
| `itemType` | `AssignmentItemType` | Type of the source entity (e.g. `TICKET`, `DEVICE`). |
| `enabled` | `boolean` | Disables all queries when `false` (default `true`). |

### `AssignedItemsResult` _(exported interface)_
The combined result shape returned by the hook.

| Field | Type | Description |
|-------|------|-------------|
| `value` | `AssignmentsValue` | Map of `targetType → AssignmentRef[]` for UI binding. |
| `customers` | `Customer[]` | Mapped organization nodes. |
| `devices` | `Device[]` | Mapped machine nodes. |
| `articles` | `KnowledgeBaseRow[]` | Knowledge base items. |
| `tickets` | `Dialog[]` | Ticket/dialog objects. |
| `isLoading` | `boolean` | `true` while any query is in flight. |
| `isReady` | `boolean` | `false` until all queries have resolved. |

### Internal helpers
- **`fetchAssignedItems`** — executes the `ASSIGNED_ITEMS_QUERY` GraphQL request and maps each typed `__typename` node into its domain model.
- **`unaliasFields`** — resolves aliased GraphQL fields (e.g. `machineStatus` → `status`) before type casting.
- **`toDialog`** — converts a raw `Ticket` GraphQL node into a `Dialog` object.
- **`combineAssignedItems`** — `useQueries` combiner that merges all parallel results into one `AssignedItemsResult`.

## Usage Example

```typescript
import { useAssignedItems } from '@/hooks/use-assigned-items';

function AssignedPanel({ ticketId }: { ticketId: string }) {
  const { value, customers, devices, articles, tickets, isLoading, isReady } =
    useAssignedItems({ itemId: ticketId, itemType: 'TICKET' });

  if (isLoading) return <Spinner />;
  if (!isReady) return null;

  return (
    <>
      <CustomerList customers={customers} />
      <DeviceList devices={devices} />
    </>
  );
}
```

> Queries are cached for 30 seconds (`staleTime: 30_000`) and keyed by `['assignments', 'assigned-items', itemType, itemId, targetType]`, so each target type is independently invalidatable.
