Fetches and aggregates all items assigned to a given entity (customer, device, knowledge article, or ticket) by executing parallel GraphQL queries for each assignment target type.

## Key Components

### `useAssignedItems(options)` *(exported hook)*
Primary hook that fires one query per `AssignmentTargetType` in parallel using `useQueries`, then merges results into a single `AssignedItemsResult`.

| Option | Type | Description |
|--------|------|-------------|
| `itemId` | `string \| null` | ID of the source entity |
| `itemType` | `AssignmentItemType` | Type of the source entity (used for Relay ID normalization) |
| `enabled` | `boolean` | Whether queries should run (default: `true`) |

### `AssignedItemsResult` *(exported interface)*
Merged result shape returned by the hook, containing:
- `value` — `AssignmentsValue` map of `targetType → AssignmentRef[]`
- `customers`, `devices`, `articles`, `tickets` — typed entity arrays
- `isLoading` / `isReady` — aggregated loading state

### `fetchAssignedItems(itemId, targetType)`
Async function that executes `ASSIGNED_ITEMS_QUERY` via `postGraphQl` and maps raw GraphQL nodes to typed domain models (`Customer`, `Device`, `KnowledgeBaseRow`, `Dialog`).

### `unaliasFields(target)`
Resolves GraphQL aliased fields (e.g. `machineStatus`, `articleStatus`) back to their canonical names before passing data to domain mappers.

### `toDialog(target)`
Converts a raw `Ticket` GraphQL node to a `Dialog` domain object.

## Usage Example

```typescript
import { useAssignedItems } from '@/lib/use-assigned-items';

function AssignedPanel({ ticketId }: { ticketId: string }) {
  const { value, customers, devices, isLoading, isReady } = useAssignedItems({
    itemId: ticketId,
    itemType: 'TICKET',
    enabled: true,
  });

  if (isLoading || !isReady) return <Spinner />;

  return (
    <>
      <CustomerList items={customers ?? []} />
      <DeviceList items={devices ?? []} />
    </>
  );
}
```

> **Note:** `itemId` is automatically normalized to a Relay global ID via `ensureGlobalId` before being sent to the API. Queries are cached for 30 seconds (`staleTime: 30_000`).
