Fetches and combines all assigned items (customers, devices, knowledge articles, tickets) for a given assignment item across all target types using parallel GraphQL queries.

## Key Components

### `useAssignedItems(options)` *(exported hook)*
Primary hook that fires one query per `AssignmentTargetType` in parallel and merges results into a single `AssignedItemsResult`.

| Option | Type | Description |
|--------|------|-------------|
| `itemId` | `string \| null` | The source item's ID (normalized to a Relay global ID) |
| `itemType` | `AssignmentItemType` | Type of the item owning the assignments |
| `enabled` | `boolean` | Optionally suppress queries (default: `true`) |

### `AssignedItemsResult` *(exported interface)*
Merged output shape containing typed arrays per target category plus loading state flags.

### `fetchAssignedItems(itemId, targetType)`
Internal async function that POSTs the `AssignmentsAssignedItems` GraphQL query and maps raw nodes to domain types (`Customer`, `Device`, `KnowledgeBaseRow`, `Dialog`).

### `combineAssignedItems(results)`
Reducer passed to `useQueries` — collapses the per-target-type query results into one `AssignedItemsResult`, aggregating refs and typed entity arrays.

### `unaliasFields(target)` / `toDialog(target)`
Field normalizers that resolve GraphQL query aliases (`machineStatus`, `articleTags`, etc.) back to canonical property names before handing off to domain mappers.

## Usage Example

```typescript
import { useAssignedItems } from '@/lib/use-assigned-items';

function AssignmentPanel({ ticketId }: { ticketId: string }) {
  const { customers, devices, articles, tickets, isLoading, isReady } =
    useAssignedItems({
      itemId: ticketId,
      itemType: 'TICKET',
    });

  if (!isReady || isLoading) return <Spinner />;

  return (
    <>
      <CustomerList items={customers ?? []} />
      <DeviceList items={devices ?? []} />
    </>
  );
}
```

> **Note:** `itemId` is automatically normalized to a Relay-compliant global ID via `ensureGlobalId`. Pass the raw ID — no pre-transformation needed at the call site.
