Provides debounced, type-aware search options for assignment targets (organizations, devices, tickets, and knowledge articles) by querying GraphQL or REST endpoints via React Query.

## Key Components

- **`useAssignmentSearch`** — Primary exported hook. Accepts an `AssignmentTargetType` and a search string, returns `{ options, isLoading }` routed to the correct internal strategy.
- **`useServerSearchOptions`** — Debounced React Query hook for server-side searches against `ORGANIZATION`, `DEVICE`, and `TICKET` targets (300ms debounce, 30s stale time, page size of 20).
- **`useKnowledgeArticleOptions`** — Fetches the full knowledge article tree once (client-side filtered), then applies debounced substring filtering in-memory via `useMemo`.
- **`AssignmentSearchOption`** — Shared `{ label: string; value: string }` interface used as the common option shape across all target types.
- **`SERVER_SEARCH_FETCHERS`** — Map of `AssignmentTargetType` → async fetch function, enabling easy extension of supported target types.

## Usage Example

```typescript
import { useAssignmentSearch } from './use-assignment-search';

function AssignmentCombobox({ targetType }) {
  const [search, setSearch] = useState('');

  const { options, isLoading } = useAssignmentSearch(targetType, search);

  return (
    <Combobox
      options={options}
      loading={isLoading}
      onSearchChange={setSearch}
    />
  );
}
```

> **Note:** `KNOWLEDGE_ARTICLE` targets are fetched once and filtered client-side. All other target types (`ORGANIZATION`, `DEVICE`, `TICKET`) hit the server on each debounced search change.
