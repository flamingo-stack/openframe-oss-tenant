Provides a React hook for searching and retrieving assignment target options (organizations, devices, tickets, and knowledge articles) based on a given target type and search string.

## Key Components

### `useAssignmentSearch(targetType, search)`
Primary exported hook. Routes to the appropriate internal search strategy based on `AssignmentTargetType`.

### `useServerSearchOptions(targetType, search)`
Internal hook for server-side searched types (`ORGANIZATION`, `DEVICE`, `TICKET`). Applies a 300ms debounce before firing a React Query request.

### `useKnowledgeArticleOptions(search)`
Internal hook for `KNOWLEDGE_ARTICLE` targets. Fetches the full article tree once (cached), then filters client-side using a debounced search string.

### `AssignmentSearchOption`
Shared option shape used across all fetchers:
```typescript
interface AssignmentSearchOption {
  label: string;
  value: string; // entity ID
}
```

### Private Fetchers
| Fetcher | Target | Source |
|---|---|---|
| `fetchCustomers` | `ORGANIZATION` | GraphQL `organizations` query |
| `fetchDevices` | `DEVICE` | GraphQL `devices` query |
| `fetchTickets` | `TICKET` | `ticketService.fetchDialogs` |
| `fetchKnowledgeArticles` | `KNOWLEDGE_ARTICLE` | GraphQL `knowledgeBaseArticleTree` |

## Usage Example

```typescript
import { useAssignmentSearch } from './use-assignment-search';
import type { AssignmentTargetType } from './types';

function AssignmentCombobox({ targetType }: { targetType: AssignmentTargetType }) {
  const [search, setSearch] = useState('');
  const { options, isLoading } = useAssignmentSearch(targetType, search);

  return (
    <Combobox
      options={options}
      loading={isLoading}
      onSearchChange={setSearch}
    />
  );
}
```

> Results are cached for 30 seconds (`staleTime: 30_000`). Knowledge articles are fetched once and filtered locally; all other types query the server on each debounced input change. Page size is capped at 20 results.
