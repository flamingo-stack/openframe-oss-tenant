Provides debounced search functionality for assignment targets (organizations, devices, tickets, and knowledge articles), returning paginated `AssignmentSearchOption` lists via React Query.

## Key Components

- **`AssignmentSearchOption`** — Interface with `label` and `value` string fields representing a selectable search result
- **`useServerSearchOptions`** — Internal hook that debounces the search string (300ms) and fetches paginated results from the GraphQL API for `ORGANIZATION`, `DEVICE`, and `TICKET` target types
- **`useKnowledgeArticleOptions`** — Internal hook that fetches the full knowledge article tree once (client-side filtered), applying debounced local string matching against `label`
- **`useAssignmentSearch`** — Primary exported hook that delegates to either `useKnowledgeArticleOptions` or `useServerSearchOptions` based on the provided `AssignmentTargetType`

## Usage Example

```typescript
import { useAssignmentSearch } from './use-assignment-search';

function AssignmentCombobox({ targetType }) {
  const [search, setSearch] = useState('');
  const { options, isLoading } = useAssignmentSearch(targetType, search);

  return (
    <Combobox
      options={options}
      loading={isLoading}
      onSearchChange={setSearch}
    />
  );
}
```

## Notes

- Results are cached for **30 seconds** (`staleTime: 30_000`) via React Query
- Server-side fetchers use a page size of **20** (`PAGE_SIZE`)
- Knowledge articles are fetched once in full and filtered client-side; all other target types query the server on each debounced change
- Device labels fall back through `displayName → hostname → id`
- Ticket labels fall back through `title → #ticketNumber → id`
