Normalizes entity identifiers to Relay-compliant global IDs, bridging a compatibility gap where `ai-agent`'s `Ticket` type returns raw MongoDB ObjectIds instead of Relay global IDs like all other `AssignableTarget` implementations.

## Key Components

| Export / Function | Description |
|---|---|
| `ensureGlobalId(type, value)` | **Primary export.** Returns a Relay global ID — passes through values already Relay-encoded, encodes raw IDs otherwise |
| `toGlobalId(type, rawId)` | Encodes `TypeName:rawId` as base64 to produce a Relay global ID |
| `decodeGlobalId(value)` | Decodes a base64 string and validates it against known Relay types; returns `null` if invalid |
| `RELAY_TYPE_NAME` | Maps `AssignmentItemType`/`AssignmentTargetType` enum values to their GraphQL type names |
| `btoaUtf8` / `atobUtf8` | Isomorphic base64 encode/decode (browser `btoa`/`atob` with Node.js `Buffer` fallback) |

## Usage Example

```typescript
import { ensureGlobalId } from './relay-id';

// Raw MongoDB ObjectId — gets encoded to a Relay global ID
ensureGlobalId('TICKET', '507f1f77bcf86cd799439011');
// → "VGlja2V0OjUwN2YxZjc3YmNmODZjZDc5OTQzOTAxMQ=="

// Already a valid Relay global ID — returned unchanged
ensureGlobalId('TICKET', 'VGlja2V0OjUwN2YxZjc3YmNmODZjZDc5OTQzOTAxMQ==');
// → "VGlja2V0OjUwN2YxZjc3YmNmODZjZDc5OTQzOTAxMQ=="

// Other entity types work the same way
ensureGlobalId('ORGANIZATION', 'org-raw-id-123');
ensureGlobalId('DEVICE', 'machine-raw-id-456');
```
