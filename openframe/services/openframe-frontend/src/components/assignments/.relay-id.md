Utility module that normalizes raw MongoDB ObjectIds into Relay-compliant global IDs, working around a known gap in `ai-agent`'s `Ticket` type which returns raw IDs instead of encoded Relay globals.

## Key Components

- **`RELAY_TYPE_NAME`** — Maps internal `AssignmentItemType`/`AssignmentTargetType` enum values to their Relay type name strings (e.g. `DEVICE → "Machine"`, `TICKET → "Ticket"`)
- **`btoaUtf8` / `atobUtf8`** — Cross-environment base64 encode/decode helpers that work in both browser (`window.btoa`/`window.atob`) and Node.js (`Buffer`)
- **`decodeGlobalId`** — Attempts to decode a string as a Relay global ID; returns `{ type, id }` if valid and the type is a known Relay type, otherwise `null`
- **`toGlobalId`** — Encodes a raw ID into a Relay global ID using the format `base64("TypeName:rawId")`
- **`ensureGlobalId`** *(exported)* — Idempotent normalizer: returns the value unchanged if it already decodes as a valid Relay global ID, otherwise encodes it

## Usage Example

```typescript
import { ensureGlobalId } from './relay-id';

// Raw MongoDB ObjectId from ai-agent Ticket response
const rawTicketId = '507f1f77bcf86cd799439011';

// Safe to call regardless of whether the ID is already a Relay global
const relayId = ensureGlobalId('TICKET', rawTicketId);
// → "VGlja2V0OjUwN2YxZjc3YmNmODZjZDc5OTQzOTAxMQ=="

// Already-encoded ID passes through unchanged (idempotent)
const alreadyEncoded = ensureGlobalId('TICKET', relayId);
// → "VGlja2V0OjUwN2YxZjc3YmNmODZjZDc5OTQzOTAxMQ=="
```

> **Note:** This module is a **temporary shim**. Once `ai-agent`'s `TicketDataFetcher` is updated to return proper Relay global IDs natively, this entire module should be removed.
