Renders a searchable, filtered table of knowledge base articles assigned to a specific context (e.g., a ticket or asset), with debounced search across article name and summary fields.

## Key Components

- **`KnowledgeBaseAssignedTable`** — Main exported component that wraps a search input and a filtered article table
- **`KnowledgeBaseAssignedTableProps`** — Interface accepting `articles: KnowledgeBaseRow[]` and optional `isLoading?: boolean`
- **`useDebounce`** — 300ms debounce applied to the search string to avoid excessive filtering on rapid keystrokes
- **`filtered` (memo)** — Derived list filtering articles by name or summary against the debounced search needle

## Usage Example

```typescript
import { KnowledgeBaseAssignedTable } from './knowledge-base-assigned-table';
import type { KnowledgeBaseRow } from '@/app/(app)/knowledge-base/components/knowledge-base-table-columns';

const articles: KnowledgeBaseRow[] = [
  { id: '1', name: 'VPN Setup Guide', summary: 'How to configure VPN access.' },
  { id: '2', name: 'Password Reset', summary: 'Steps to reset your password.' },
];

export function TicketSidebar() {
  return (
    <KnowledgeBaseAssignedTable
      articles={articles}
      isLoading={false}
    />
  );
}
```

## Notes

- Filtering is case-insensitive and matches partial strings in both `name` and `summary`
- `summary` is treated as optional (`?? ''`) to safely handle missing values
- Displays `"No articles assigned."` when the filtered result is empty
- Skeleton rows (3) are shown during loading via `KnowledgeBaseTableBody`
