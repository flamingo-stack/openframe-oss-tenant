A read-only table component that displays knowledge base articles assigned to a resource, with live client-side search filtering.

## Key Components

**`KnowledgeBaseAssignedTable`** — Main exported component that renders a searchable list of assigned knowledge articles.

| Prop | Type | Description |
|------|------|-------------|
| `articles` | `KnowledgeBaseRow[]` | Array of knowledge base article rows to display |
| `isLoading` | `boolean` (optional) | Shows skeleton rows while data is loading |

**Internal state & logic:**
- `search` / `debouncedSearch` — Debounced (300ms) search string to avoid excessive filtering on each keystroke
- `filtered` — Memoized array filtering articles by `name` or `summary` against the debounced search needle

## Usage Example

```typescript
import { KnowledgeBaseAssignedTable } from './knowledge-base-assigned-table';

const assignedArticles = [
  { id: '1', name: 'VPN Setup Guide', summary: 'How to configure VPN access' },
  { id: '2', name: 'Password Policy', summary: 'Reset and complexity requirements' },
];

export function AssignedArticlesPanel() {
  return (
    <KnowledgeBaseAssignedTable
      articles={assignedArticles}
      isLoading={false}
    />
  );
}
```

> **Note:** Filtering is case-insensitive and matches against both `name` and `summary` fields. When `isLoading` is `true`, the table renders 3 skeleton placeholder rows via `KnowledgeBaseTableBody`.
