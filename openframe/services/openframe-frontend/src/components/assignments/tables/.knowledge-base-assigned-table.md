Displays a searchable, filterable table of knowledge base articles assigned to a specific context (e.g., a ticket or asset), with debounced client-side search across article name and summary fields.

## Key Components

- **`KnowledgeBaseAssignedTable`** — Main exported component rendering a search input and filtered article table
- **`KnowledgeBaseAssignedTableProps`** — Interface accepting `articles: KnowledgeBaseRow[]` and optional `isLoading?: boolean`
- **Debounced search** — 300ms debounce via `useDebounce` filters articles by `name` and `summary` fields client-side
- **`KnowledgeBaseTableBody`** — Reusable table renderer used in `standard` mode with a 3-row skeleton loader and empty state message

## Usage Example

```typescript
import { KnowledgeBaseAssignedTable } from './knowledge-base-assigned-table';

const assignedArticles = [
  { id: '1', name: 'VPN Setup Guide', summary: 'Steps to configure VPN access.' },
  { id: '2', name: 'Password Reset', summary: 'How to reset your password.' },
];

<KnowledgeBaseAssignedTable
  articles={assignedArticles}
  isLoading={false}
/>
```

## Behavior Notes

- Search is **case-insensitive** and matches against both `name` and `summary`
- Returns all articles when the search input is empty or whitespace-only
- `summary` field is treated as optional (`?? ''`) to avoid null-match errors
- Skeleton rows (`skeletonRows={3}`) display during loading state
