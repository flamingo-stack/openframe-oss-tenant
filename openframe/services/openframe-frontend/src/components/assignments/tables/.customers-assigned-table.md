Displays a filterable table of pre-assigned customers, combining a debounced search input with a filtered table body for real-time client-side search.

## Key Components

- **`CustomersAssignedTable`** — Main exported component accepting a `customers` array and optional `isLoading` flag
- **`useDebounce`** — Debounces the search input by 300ms to avoid excessive re-filtering
- **`filtered` (memo)** — Filters customers by `name` or `contact.email` against the debounced search term
- **`CustomersSearchInput`** — Reused search input component from the shared customers table columns module
- **`CustomersTableBody`** — Reused table body component, rendered with `emptyMessage="No customers assigned."` and `skeletonRows={3}`

## Usage Example

```typescript
import { CustomersAssignedTable } from './customers-assigned-table';
import type { Customer } from '@/app/(app)/customers/hooks/use-customers';

const assignedCustomers: Customer[] = [
  { name: 'Acme Corp', contact: { email: 'admin@acme.com' } },
  { name: 'Globex Inc', contact: { email: 'it@globex.com' } },
];

export function TechnicianPanel() {
  return (
    <CustomersAssignedTable
      customers={assignedCustomers}
      isLoading={false}
    />
  );
}
```

## Notes

- Filtering is purely client-side — the full `customers` list must be passed in as a prop
- Search matches are case-insensitive and check both `name` and `contact.email` fields
- The 300ms debounce prevents layout thrash during fast typing
