A filterable table component that displays customers assigned to a specific context (e.g., a technician or group), with debounced search filtering by name or email.

## Key Components

- **`CustomersAssignedTable`** — Main exported component accepting a `customers` array and optional `isLoading` flag
- **`search` / `debouncedSearch`** — Local state with 300ms debounce to avoid filtering on every keystroke
- **`filtered`** — Memoized derived list filtering customers by `name` or `contact.email` against the debounced query
- **`CustomersSearchInput`** — Reused search input from the shared customers table columns module
- **`CustomersTableBody`** — Reused table body renderer, configured with `emptyMessage="No customers assigned."` and `skeletonRows={3}`

## Usage Example

```typescript
import { CustomersAssignedTable } from './customers-assigned-table';
import type { Customer } from '@/app/(app)/customers/hooks/use-customers';

const assignedCustomers: Customer[] = [
  { name: 'Acme Corp', contact: { email: 'admin@acme.com' } },
  { name: 'Globex', contact: { email: 'it@globex.com' } },
];

export function TechnicianDetail() {
  return (
    <CustomersAssignedTable
      customers={assignedCustomers}
      isLoading={false}
    />
  );
}
```

## Notes

- Filtering is case-insensitive and trims leading/trailing whitespace
- When `debouncedSearch` is empty, the full `customers` array is returned unfiltered
- Skeleton loading state is handled internally by `CustomersTableBody` via the `isLoading` prop
