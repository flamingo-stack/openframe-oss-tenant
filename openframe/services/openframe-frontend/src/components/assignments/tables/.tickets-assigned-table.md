Filterable table component for displaying tickets assigned to the current user, with debounced search across ticket title and organization name.

## Key Components

- **`TicketsAssignedTable`** — Main exported component that renders a search input and a filtered ticket table
- **`TicketsAssignedTableProps`** — Interface accepting a `tickets: Dialog[]` array and optional `isLoading` boolean
- **Debounced search** — Uses `useDebounce` (300ms) to filter tickets by `title` or `organizationName` without excessive re-renders
- **`TicketTableBody`** — Underlying table renderer receiving the filtered ticket list, loading state, and an empty state message

## Usage Example

```typescript
import { TicketsAssignedTable } from './tickets-assigned-table';

const assignedTickets: Dialog[] = [
  { id: '1', title: 'VPN not connecting', organizationName: 'Acme Corp' },
  { id: '2', title: 'Printer offline', organizationName: 'Beta LLC' },
];

export function AssignedTicketsPage() {
  return (
    <TicketsAssignedTable
      tickets={assignedTickets}
      isLoading={false}
    />
  );
}
```

## Filtering Behavior

| Input | Matched fields |
|-------|---------------|
| Partial text | `title` (case-insensitive) |
| Partial text | `organizationName` (case-insensitive) |
| Empty string | Returns all tickets unfiltered |
