A client-side table component that renders a filterable list of tickets assigned to the current user, with debounced search across ticket title and organization name.

## Key Components

- **`TicketsAssignedTable`** — Main exported component accepting a `tickets` array and optional `isLoading` flag
- **`TicketsAssignedTableProps`** — Interface defining `tickets: Dialog[]` and `isLoading?: boolean`
- **Debounced search** — 300ms debounce via `useDebounce` prevents excessive filtering on rapid keystrokes
- **`filtered` memo** — Filters tickets by `title` or `organizationName` using the debounced search needle
- **`TicketTableBody`** — Renders the filtered ticket rows with skeleton loading and an empty state message

## Usage Example

```typescript
import { TicketsAssignedTable } from './tickets-assigned-table';
import type { Dialog } from '@/app/(app)/tickets/types/dialog.types';

const assignedTickets: Dialog[] = [
  { id: '1', title: 'VPN not connecting', organizationName: 'Acme Corp' },
  { id: '2', title: 'Printer offline',    organizationName: 'Globex Inc'  },
];

export function AssignedTicketsSection() {
  return (
    <TicketsAssignedTable
      tickets={assignedTickets}
      isLoading={false}
    />
  );
}
```

> **Search behavior:** Filtering is case-insensitive and matches any substring in `title` or `organizationName`. If the search field is empty or whitespace-only, all tickets are returned unfiltered.
