Renders a searchable, filtered table of tickets assigned to the current user, with debounced search across ticket title and organization name.

## Key Components

### `TicketsAssignedTable`
A client component that accepts a list of `Dialog` tickets and renders a live-filtered table view.

**Props:**

| Prop | Type | Description |
|------|------|-------------|
| `tickets` | `Dialog[]` | Array of ticket dialog objects to display |
| `isLoading` | `boolean` | Optional loading state passed to the table body |

**Internal behavior:**
- `search` / `debouncedSearch` — Local state with 300ms debounce to avoid filtering on every keystroke
- `filtered` — Memoized result filtering tickets by `title` or `organizationName` (case-insensitive)
- Renders an `Input` with a `SearchIcon` adornment and delegates rendering to `TicketTableBody`

## Usage Example

```typescript
import { TicketsAssignedTable } from './tickets-assigned-table';
import type { Dialog } from '@/app/(app)/tickets/types/dialog.types';

const assignedTickets: Dialog[] = [
  { id: '1', title: 'VPN not connecting', organizationName: 'Acme Corp' },
  { id: '2', title: 'Printer offline', organizationName: 'Beta LLC' },
];

export function AssignedTicketsView() {
  return (
    <TicketsAssignedTable
      tickets={assignedTickets}
      isLoading={false}
    />
  );
}
```

## Notes

- Filtering is purely client-side — no API calls on search input
- Empty state displays `"No tickets assigned."` via `TicketTableBody`'s `emptyMessage` prop
- Skeleton loading shows 3 placeholder rows while `isLoading` is `true`
