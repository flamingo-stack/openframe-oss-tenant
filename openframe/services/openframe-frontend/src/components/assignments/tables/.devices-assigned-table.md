Filterable table component for displaying devices assigned to a specific entity (e.g., user or group), with debounced search across device name and organization fields.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `DevicesAssignedTable` | React Component | Renders a searchable, filtered list of assigned devices |
| `DevicesAssignedTableProps` | Interface | Props: `devices: Device[]`, `isLoading?: boolean` |

**Internal logic:**
- `search` / `debouncedSearch` — 300ms debounced input state to avoid excessive filtering on keystroke
- `filtered` — `useMemo` derived list matching `displayName`, `hostname`, or `organization` against the search needle
- `DevicesTableBody` — shared table renderer with skeleton loading and empty state support

## Usage Example

```typescript
import { DevicesAssignedTable } from './devices-assigned-table';
import type { Device } from '@/app/(app)/devices/types/device.types';

const assignedDevices: Device[] = [
  { displayName: 'Laptop-001', hostname: 'laptop-001', organization: 'Acme Corp' },
  { displayName: 'Desktop-002', hostname: 'desktop-002', organization: 'Globex' },
];

export function UserDevicesPanel() {
  return (
    <DevicesAssignedTable
      devices={assignedDevices}
      isLoading={false}
    />
  );
}
```

> **Search behavior:** Filters on `displayName`, `hostname`, and `organization` fields. Search is case-insensitive and debounced at 300ms. When the search field is empty, all devices are shown. Empty state renders `"No devices assigned."` with 3 skeleton rows during loading.
