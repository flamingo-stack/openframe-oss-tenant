A client-side React component that renders a filterable table of devices assigned to a specific entity (e.g., a user or group), with debounced search across device name and organization fields.

## Key Components

- **`DevicesAssignedTable`** — Main exported component that accepts a list of `Device` objects and an optional loading state
- **`DevicesAssignedTableProps`** — Interface defining `devices: Device[]` and optional `isLoading?: boolean`
- **Debounced search** — Uses `useDebounce` (300ms) to filter devices by `displayName`, `hostname`, or `organization` without excessive re-renders
- **`DevicesTableBody`** — Shared table body component reused from the devices module, configured with `skeletonRows={3}` and a custom empty message

## Usage Example

```typescript
import { DevicesAssignedTable } from './devices-assigned-table';
import type { Device } from '@/app/(app)/devices/types/device.types';

const assignedDevices: Device[] = [
  { displayName: 'Workstation-01', hostname: 'ws-01', organization: 'Acme Corp' },
  { displayName: 'Laptop-02', hostname: 'lp-02', organization: 'Beta LLC' },
];

export function UserDetailPanel() {
  return (
    <DevicesAssignedTable
      devices={assignedDevices}
      isLoading={false}
    />
  );
}
```

## Notes

- Filtering is case-insensitive and falls back gracefully when `displayName` or `hostname` are absent
- The search input renders a `SearchIcon` as a start adornment for visual clarity
- Passes `emptyMessage="No devices assigned."` to `DevicesTableBody` to distinguish this context from the main devices list
