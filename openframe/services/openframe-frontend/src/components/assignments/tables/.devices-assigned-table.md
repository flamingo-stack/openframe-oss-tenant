A client-side React component that renders a filterable table of devices assigned to a specific context (e.g., a user or group), with debounced search across device name and organization.

## Key Components

- **`DevicesAssignedTable`** — Main exported component accepting a `devices` array and optional `isLoading` flag
- **`DevicesAssignedTableProps`** — Interface defining `devices: Device[]` and `isLoading?: boolean`
- **Debounced search** — 300ms debounce via `useDebounce` filters by `displayName`, `hostname`, or `organization`
- **`DevicesTableBody`** — Reused table rendering component from the shared devices module

## Usage Example

```typescript
import { DevicesAssignedTable } from './devices-assigned-table';
import type { Device } from '@/app/(app)/devices/types/device.types';

const assignedDevices: Device[] = [
  { displayName: 'Workstation-01', hostname: 'ws-01', organization: 'Acme Corp' },
  { displayName: 'Laptop-02', hostname: 'lt-02', organization: 'Globex' },
];

export function UserDetailPanel() {
  return (
    <DevicesAssignedTable
      devices={assignedDevices}
      isLoading={false}
    />
  );
}
```

## Behavior Notes

- Returns all devices when search input is empty
- Matching is case-insensitive and substring-based
- Falls back gracefully: uses `hostname` if `displayName` is absent
- Displays `"No devices assigned."` when the filtered result is empty
- Shows 3 skeleton rows during loading state
