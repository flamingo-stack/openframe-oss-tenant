A single-row UI component for managing a typed assignment target, combining a multi-select autocomplete with a remove button.

## Key Components

**`AssignmentRow`** — The exported React component accepting:
- `targetType` — determines display labels via `TARGET_CONFIG`
- `value` / `onChange` — controlled list of `AssignmentRef` objects (`{ id, label }`)
- `onRemoveRow` — callback to delete the entire row
- `disabled` — optional flag to disable all interactions

**Internal logic:**
- `mergedOptions` — deduplicates currently selected refs with live search results so selected items always appear in the dropdown even if not returned by the current query
- `useAssignmentSearch` — drives async search options based on `targetType` and user input
- `handleChange` — maps selected IDs back to `AssignmentRef` objects using the merged options map

## Usage Example

```typescript
import { AssignmentRow } from './assignment-row';

<AssignmentRow
  targetType="user"
  value={[{ id: 'u1', label: 'Alice' }]}
  onChange={(refs) => setAssignments(refs)}
  onRemoveRow={() => removeRow(index)}
  disabled={isSaving}
/>
```

## Notes

- Search input updates are filtered to `'input'` and `'clear'` reasons to avoid redundant queries on programmatic selection changes
- `disableClientFilter` is passed to `Autocomplete` so filtering is handled server-side via `useAssignmentSearch`
- The remove button uses `TrashIcon` styled with `text-ods-error` and carries an accessible `aria-label` derived from `meta.menuLabel`
