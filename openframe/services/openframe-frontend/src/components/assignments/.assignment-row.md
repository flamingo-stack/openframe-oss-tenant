A controlled row component for managing multi-select assignments of a specific target type (e.g., users, groups, devices), combining a search-powered autocomplete with a remove action.

## Key Components

- **`AssignmentRow`** — Primary export. Renders a labeled row containing a multi-select `Autocomplete` and a trash `Button` for row removal.
- **`AssignmentRowProps`** — Interface defining:
  - `targetType` — Determines label metadata and search behavior via `TARGET_CONFIG`
  - `value` — Current array of `AssignmentRef` (id + label pairs)
  - `onChange` — Callback receiving updated `AssignmentRef[]` on selection change
  - `onRemoveRow` — Callback triggered when the trash button is clicked
  - `disabled` — Optional flag to disable all interactive elements
- **`mergedOptions`** — Deduped union of currently selected values and live search results, ensuring selected items remain visible even when not in the current search page
- **`useAssignmentSearch`** — Hook providing debounced/async search options based on `targetType` and input string

## Usage Example

```typescript
import { AssignmentRow } from './assignment-row';
import type { AssignmentRef } from './types';

const [assignments, setAssignments] = useState<AssignmentRef[]>([]);

<AssignmentRow
  targetType="user"
  value={assignments}
  onChange={setAssignments}
  onRemoveRow={() => removeRow('user')}
  disabled={isSubmitting}
/>
```

> **Note:** `disableClientFilter` is passed to `Autocomplete`, meaning all filtering is delegated to the server-side search hook. Ensure `useAssignmentSearch` handles debouncing to avoid excessive API calls on rapid input changes.
