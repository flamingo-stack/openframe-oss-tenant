A single-row UI component for managing entity assignments, combining a multi-select autocomplete with a remove button for a given assignment target type.

## Key Components

- **`AssignmentRow`** — Main exported component that renders a labeled row with:
  - A multi-select `Autocomplete` for searching and selecting assignment targets
  - A `TrashIcon` button to remove the entire assignment row
- **`mergedOptions`** — Deduplicates currently selected values with live search results to prevent option loss during async fetches
- **`useAssignmentSearch`** — Hook that provides debounced/async search options for the given `targetType`
- **`TARGET_CONFIG`** — Config map used to derive display labels per target type

## Props

| Prop | Type | Description |
|------|------|-------------|
| `targetType` | `AssignmentTargetType` | Determines search behavior and labels |
| `value` | `AssignmentRef[]` | Currently selected assignments |
| `onChange` | `(next: AssignmentRef[]) => void` | Called with updated selection |
| `onRemoveRow` | `() => void` | Called when trash button is clicked |
| `disabled` | `boolean?` | Disables all inputs |

## Usage Example

```typescript
import { AssignmentRow } from './assignment-row';

<AssignmentRow
  targetType="user"
  value={[{ id: 'u1', label: 'Alice' }]}
  onChange={(refs) => setAssignments(refs)}
  onRemoveRow={() => removeRow('user')}
  disabled={isSubmitting}
/>
```

> **Note:** `disableClientFilter` is set on the `Autocomplete` — filtering is handled server-side via `useAssignmentSearch`. Ensure the search hook handles debouncing to avoid excessive API calls.
