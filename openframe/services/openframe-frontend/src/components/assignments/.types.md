Defines TypeScript types and constants for the assignment system, mapping items to targets like organizations, devices, tickets, and knowledge articles.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `AssignmentTargetType` | Union type | Valid targets an item can be assigned to: `ORGANIZATION`, `DEVICE`, `TICKET`, or `KNOWLEDGE_ARTICLE` |
| `AssignmentItemType` | Union type | Valid assignable item types: `TICKET` or `KNOWLEDGE_ARTICLE` |
| `AssignmentRef` | Interface | Reference object with `id` and `label` for identifying an assignment |
| `AssignmentsValue` | Type | Partial record mapping each `AssignmentTargetType` to an array of `AssignmentRef` |
| `ASSIGNMENT_TARGET_TYPES` | Constant | Readonly array of all valid `AssignmentTargetType` values, useful for iteration/validation |

## Usage Example

```typescript
import {
  AssignmentsValue,
  AssignmentRef,
  ASSIGNMENT_TARGET_TYPES,
} from './types';

// Build an assignments map
const assignments: AssignmentsValue = {
  ORGANIZATION: [{ id: 'org-1', label: 'Acme Corp' }],
  TICKET: [{ id: 'tkt-42', label: 'Network Outage' }],
};

// Iterate over all valid target types
ASSIGNMENT_TARGET_TYPES.forEach((target) => {
  const refs: AssignmentRef[] = assignments[target] ?? [];
  console.log(`${target}:`, refs);
});
```
