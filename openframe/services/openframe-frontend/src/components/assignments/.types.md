Defines types and constants for the assignment system, mapping items to target entities like organizations, devices, tickets, and knowledge articles.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `AssignmentTargetType` | `type` | Union of valid assignment targets: `ORGANIZATION`, `DEVICE`, `TICKET`, `KNOWLEDGE_ARTICLE` |
| `AssignmentItemType` | `type` | Union of assignable item types: `TICKET`, `KNOWLEDGE_ARTICLE` |
| `AssignmentRef` | `interface` | Minimal reference object with `id` and `label` for an assignment entity |
| `AssignmentsValue` | `type` | Partial record mapping each `AssignmentTargetType` to an array of `AssignmentRef` |
| `ASSIGNMENT_TARGET_TYPES` | `const` | Readonly array of all valid `AssignmentTargetType` values, useful for iteration and validation |

## Usage Example

```typescript
import {
  AssignmentsValue,
  AssignmentRef,
  ASSIGNMENT_TARGET_TYPES,
} from './types';

// Build an assignments map for a ticket linked to an org and a device
const assignments: AssignmentsValue = {
  ORGANIZATION: [{ id: 'org-123', label: 'Acme Corp' }],
  DEVICE: [{ id: 'dev-456', label: 'Workstation-07' }],
};

// Iterate over all target types to render assignment UI
ASSIGNMENT_TARGET_TYPES.forEach((target) => {
  const refs: AssignmentRef[] = assignments[target] ?? [];
  console.log(`${target}:`, refs.map((r) => r.label));
});
```
