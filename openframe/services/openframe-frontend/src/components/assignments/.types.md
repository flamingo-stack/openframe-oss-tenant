Defines shared types and constants for the assignment system, mapping items (tickets, knowledge articles) to various target entities.

## Key Components

- **`AssignmentTargetType`** — Union type of valid assignment targets: `'ORGANIZATION'`, `'DEVICE'`, `'TICKET'`, `'KNOWLEDGE_ARTICLE'`
- **`AssignmentItemType`** — Union type of assignable item kinds: `'TICKET'` or `'KNOWLEDGE_ARTICLE'`
- **`AssignmentRef`** — Reference object with `id` and `label` identifying a target entity
- **`AssignmentsValue`** — Partial record mapping each `AssignmentTargetType` to an array of `AssignmentRef` entries
- **`ASSIGNMENT_TARGET_TYPES`** — Readonly array of all valid `AssignmentTargetType` values, useful for iteration and validation

## Usage Example

```typescript
import {
  AssignmentsValue,
  AssignmentRef,
  ASSIGNMENT_TARGET_TYPES,
} from './types';

const assignments: AssignmentsValue = {
  ORGANIZATION: [{ id: 'org-123', label: 'Acme Corp' }],
  DEVICE: [{ id: 'dev-456', label: 'Workstation-01' }],
};

// Iterate all target types
ASSIGNMENT_TARGET_TYPES.forEach((target) => {
  const refs: AssignmentRef[] = assignments[target] ?? [];
  console.log(`${target}:`, refs);
});
```
