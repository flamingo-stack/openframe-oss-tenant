Computes and applies a diff between two assignment states by issuing GraphQL `assignItem`/`unassignItem` mutations only for the changes, then invalidates relevant React Query caches on success.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `useApplyAssignmentsDiff` | React hook | TanStack `useMutation` wrapper that applies an assignment diff and invalidates `['assignments', 'assigned-items']` queries |
| `applyAssignmentsDiff` | async function | Core diff logic — compares `prev` vs `next` assignment sets per target type and fires parallel GraphQL mutations |
| `ASSIGN_ITEM_MUTATION` | GraphQL string | Mutation to add a new assignment |
| `UNASSIGN_ITEM_MUTATION` | GraphQL string | Mutation to remove an existing assignment |

## Usage Example

```typescript
import { useApplyAssignmentsDiff } from './apply-assignments-diff';

function AssignmentEditor({ ticketId, currentAssignments }) {
  const { mutate, isPending } = useApplyAssignmentsDiff();

  const handleSave = (updatedAssignments) => {
    mutate({
      itemId: ticketId,
      itemType: 'Ticket',
      prev: currentAssignments,
      next: updatedAssignments,
    });
  };

  return <button onClick={handleSave} disabled={isPending}>Save</button>;
}
```

## Behavior Notes

- All `assign` and `unassign` mutations are dispatched **in parallel** via `Promise.all` — items added in `next` but absent in `prev` are assigned; items present in `prev` but absent in `next` are unassigned.
- Both `itemId` and `targetId` values are normalized to Relay global IDs via `ensureGlobalId` before being sent.
- Iterates over every entry in `ASSIGNMENT_TARGET_TYPES` (e.g. users, teams) to handle all target categories in a single call.
