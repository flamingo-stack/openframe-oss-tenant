Computes and applies a diff between two assignment states, issuing GraphQL `assignItem`/`unassignItem` mutations only for changed targets, then invalidates relevant React Query caches on success.

## Key Components

- **`applyAssignmentsDiff`** — Core async function that compares `prev` and `next` `AssignmentsValue` maps, fires parallel GraphQL mutations for added/removed assignments across all `ASSIGNMENT_TARGET_TYPES`
- **`useApplyAssignmentsDiff`** — React hook wrapping the above in a TanStack `useMutation`, auto-invalidating `['assignments', 'assigned-items']` queries on success
- **`ASSIGN_ITEM_MUTATION`** — GraphQL mutation to assign an item to a target
- **`UNASSIGN_ITEM_MUTATION`** — GraphQL mutation to remove an assignment

## Usage Example

```typescript
import { useApplyAssignmentsDiff } from './apply-assignments-diff';

function AssignmentEditor({ ticket }) {
  const { mutate, isPending } = useApplyAssignmentsDiff();

  const handleSave = (prevAssignments, nextAssignments) => {
    mutate({
      itemId: ticket.id,
      itemType: 'Ticket',
      prev: prevAssignments,
      next: nextAssignments,
    });
  };

  return <SaveButton onClick={handleSave} loading={isPending} />;
}
```

> **Note:** All IDs are normalized to Relay global IDs via `ensureGlobalId` before being sent. Mutations for all changed targets are dispatched in parallel via `Promise.all`.
