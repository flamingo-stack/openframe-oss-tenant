Computes and applies the diff between two assignment states by dispatching `assignItem` / `unassignItem` GraphQL mutations in parallel, then invalidates related React Query caches on success.

## Key Components

- **`applyAssignmentsDiff`** — Core async function that compares `prev` and `next` `AssignmentsValue` maps across all target types, builds a set of add/remove tasks, and executes them concurrently via `Promise.all`
- **`useApplyAssignmentsDiff`** — React hook wrapping the above in a TanStack Query `useMutation`, automatically invalidating `['assignments', 'assigned-items']` queries on success
- **`ASSIGN_ITEM_MUTATION`** / **`UNASSIGN_ITEM_MUTATION`** — GraphQL mutations for adding and removing individual assignments
- **`ApplyAssignmentsDiffInput`** — Input shape: `itemId`, `itemType`, and the `prev`/`next` assignment snapshots to diff

## Usage Example

```typescript
import { useApplyAssignmentsDiff } from './apply-assignments-diff';

function AssignmentEditor({ ticketId }: { ticketId: string }) {
  const { mutate, isPending } = useApplyAssignmentsDiff();

  const handleSave = (prev: AssignmentsValue, next: AssignmentsValue) => {
    mutate({
      itemId: ticketId,
      itemType: 'Ticket',
      prev,
      next,
    });
  };

  return <button disabled={isPending} onClick={() => handleSave(prev, next)}>Save</button>;
}
```

> **Note:** IDs are automatically normalized to Relay global IDs via `ensureGlobalId` before being sent to the API — pass raw local IDs safely.
