Barrel export file for the assignments feature module, consolidating all public-facing hooks, components, and schema definitions into a single import path.

## Key Components

- **`useApplyAssignmentsDiff`** — Hook for applying a diff to current assignment state
- **`AssignedItemsView`** — Component for displaying a list of assigned items
- **`AssignmentsField`** — Form field component for managing assignments
- **`ASSIGNMENTS_DEFAULT`** — Default value constant for assignments data
- **`assignmentsSchema`** — Zod/validation schema for assignments
- **`useAssignedItems`** — Hook for retrieving and managing assigned items

## Usage Example

```typescript
import {
  useApplyAssignmentsDiff,
  AssignedItemsView,
  AssignmentsField,
  ASSIGNMENTS_DEFAULT,
  assignmentsSchema,
  useAssignedItems,
} from '@/features/assignments';

const MyComponent = () => {
  const { assignedItems } = useAssignedItems();
  const applyDiff = useApplyAssignmentsDiff();

  return (
    <AssignmentsField defaultValue={ASSIGNMENTS_DEFAULT}>
      <AssignedItemsView items={assignedItems} />
    </AssignmentsField>
  );
};
```
