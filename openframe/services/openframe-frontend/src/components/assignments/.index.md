Barrel export file for the assignments feature module, re-exporting all public API components, hooks, and utilities from their respective submodules.

## Key Components

- **`useApplyAssignmentsDiff`** — Hook for applying diffs to assignment state
- **`AssignedItemsView`** — Component for rendering assigned items
- **`AssignmentsField`** — Form field component for managing assignments
- **`ASSIGNMENTS_DEFAULT`** — Default value constant for assignments
- **`assignmentsSchema`** — Zod/validation schema for assignments data
- **`useAssignedItems`** — Hook for accessing and managing assigned items

## Usage Example

```typescript
import {
  useApplyAssignmentsDiff,
  AssignedItemsView,
  AssignmentsField,
  ASSIGNMENTS_DEFAULT,
  assignmentsSchema,
  useAssignedItems,
} from '@/features/assignments';

const MyComponent = () => {
  const assignedItems = useAssignedItems();
  const applyDiff = useApplyAssignmentsDiff();

  return (
    <AssignmentsField defaultValue={ASSIGNMENTS_DEFAULT}>
      <AssignedItemsView items={assignedItems} />
    </AssignmentsField>
  );
};
```
