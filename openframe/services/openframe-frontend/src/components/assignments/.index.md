Barrel export file for the assignments feature module, re-exporting all public APIs from their respective sub-modules.

## Key Components

| Export | Source Module | Description |
|--------|--------------|-------------|
| `useApplyAssignmentsDiff` | `apply-assignments-diff` | Hook for applying diff changes to assignments |
| `AssignedItemsView` | `assigned-items-view` | View component for displaying assigned items |
| `AssignmentsField` | `assignments-field` | Form field component for managing assignments |
| `ASSIGNMENTS_DEFAULT` | `schema` | Default values constant for assignments |
| `assignmentsSchema` | `schema` | Validation schema for assignments data |
| `useAssignedItems` | `use-assigned-items` | Hook for retrieving and managing assigned items |

## Usage Example

```typescript
import {
  useApplyAssignmentsDiff,
  AssignedItemsView,
  AssignmentsField,
  ASSIGNMENTS_DEFAULT,
  assignmentsSchema,
  useAssignedItems,
} from './assignments';

// Use the schema for form validation
const form = useForm({
  defaultValues: ASSIGNMENTS_DEFAULT,
  resolver: zodResolver(assignmentsSchema),
});

// Retrieve assigned items in a component
const { assignedItems } = useAssignedItems(entityId);
```
