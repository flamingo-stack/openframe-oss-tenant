Maps each `AssignmentTargetType` to its display metadata (labels and icon component) for use in assignment UI elements like tabs, menus, and rows.

## Key Components

### `TargetMeta` interface
Defines the shape of display metadata for a target type:
- `rowLabel` — label for assignment row headers
- `menuLabel` — singular label used in dropdown menus
- `tabLabel` — plural label used in tab navigation
- `icon` — React SVG icon component

### `TARGET_CONFIG`
A record mapping each `AssignmentTargetType` to its `TargetMeta`. Supported target types:

| Key | Row Label | Menu Label | Tab Label |
|---|---|---|---|
| `ORGANIZATION` | Assigned Customers | Customer | Customers |
| `DEVICE` | Assigned Devices | Device | Devices |
| `TICKET` | Assigned Tickets | Ticket | Tickets |
| `KNOWLEDGE_ARTICLE` | Assigned Knowledge Articles | Knowledge Article | Knowledge Articles |

## Usage Example

```typescript
import { TARGET_CONFIG } from './target-config';

const meta = TARGET_CONFIG['DEVICE'];
const Icon = meta.icon;

// In a tab header
<Icon size={16} />
<span>{meta.tabLabel}</span> // "Devices"

// In a dropdown menu
<span>{meta.menuLabel}</span> // "Device"
```
