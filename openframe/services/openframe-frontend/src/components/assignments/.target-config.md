Maps each `AssignmentTargetType` to its display metadata (labels and icon component) for use in assignment UI elements like rows, menus, and tabs.

## Key Components

- **`TargetMeta`** — Interface defining display properties for a target type:
  - `rowLabel` — Label used in list/table rows
  - `menuLabel` — Label used in dropdown menus
  - `tabLabel` — Label used in tab navigation
  - `icon` — Associated icon component

- **`TARGET_CONFIG`** — A record mapping each `AssignmentTargetType` to its `TargetMeta`, covering four target types: `ORGANIZATION`, `DEVICE`, `TICKET`, and `KNOWLEDGE_ARTICLE`.

## Usage Example

```typescript
import { TARGET_CONFIG } from './target-config';

const meta = TARGET_CONFIG['DEVICE'];

console.log(meta.rowLabel);   // "Assigned Devices"
console.log(meta.menuLabel);  // "Device"
console.log(meta.tabLabel);   // "Devices"

const Icon = meta.icon;
// <Icon size={16} className="text-amber-400" />
```
