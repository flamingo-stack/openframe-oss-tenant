Maps each `AssignmentTargetType` to its display metadata (labels and icon component) for use in assignment UI elements like rows, menus, and tabs.

## Key Components

### `TargetMeta` interface
Defines the shape of display metadata for each target type:
- `rowLabel` — label shown in assignment row context
- `menuLabel` — label shown in dropdown/context menus
- `tabLabel` — label shown in tab navigation
- `icon` — React SVG icon component

### `TARGET_CONFIG`
A `Record<AssignmentTargetType, TargetMeta>` mapping all four supported target types to their respective metadata:

| Key | Row Label | Icon |
|-----|-----------|------|
| `ORGANIZATION` | Assigned Customers | `IdCardIcon` |
| `DEVICE` | Assigned Devices | `MonitorIcon` |
| `TICKET` | Assigned Tickets | `TagIcon` |
| `KNOWLEDGE_ARTICLE` | Assigned Knowledge Articles | `FileContentIcon` |

## Usage Example

```typescript
import { TARGET_CONFIG } from './target-config';

const meta = TARGET_CONFIG['DEVICE'];
const Icon = meta.icon;

// Render tab label with icon
return (
  <Tab>
    <Icon size={16} />
    {meta.tabLabel} {/* "Devices" */}
  </Tab>
);

// Render menu item
<MenuItem>{meta.menuLabel}</MenuItem> {/* "Device" */}
```
