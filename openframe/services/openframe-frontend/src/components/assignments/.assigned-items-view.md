Renders a tabbed view of items assigned to a given entity (e.g., a user, team, or policy), displaying related customers, devices, knowledge base articles, and tickets in separate filterable tabs.

## Key Components

- **`AssignedItemsView`** — Main exported component that orchestrates the assigned items display
- **`AssignedItemsViewProps`** — Interface accepting `itemId`, `itemType`, and optional `className`
- **`useAssignedItems`** — Hook that fetches and returns categorized assignment data and loading state
- **`TabNavigation`** — UI component used when multiple assignment target types are active
- **`renderTabBody`** — Internal switch-based renderer mapping `AssignmentTargetType` to its corresponding table component

## Behavior

- Filters out empty assignment categories; only tabs with at least one item are shown
- Displays a single table (no tabs) when only one category has data
- Falls back to a `Skeleton` loader while data is loading and no active types are resolved yet
- Returns `null` if loading completes with no assigned items
- Tracks the selected tab via `pinnedTab` state, falling back to the first active tab if the pinned tab becomes inactive

## Usage Example

```typescript
import { AssignedItemsView } from './assigned-items-view';

// Inside a detail page for a user or team
<AssignedItemsView
  itemId="usr_abc123"
  itemType="USER"
  className="mt-6"
/>
```
