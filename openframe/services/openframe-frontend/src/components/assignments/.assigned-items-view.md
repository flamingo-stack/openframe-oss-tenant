Renders a tabbed view of items assigned to a given entity, dynamically showing only tabs for assignment target types that have data (organizations, devices, knowledge articles, or tickets).

## Key Components

- **`AssignedItemsView`** — Main exported component that orchestrates the assigned items display
- **`AssignedItemsViewProps`** — Props interface accepting `itemId`, `itemType`, and optional `className`
- **`useAssignedItems`** — Custom hook providing fetched assignment data and loading state
- **`renderTabBody`** — Internal switch-based renderer mapping `AssignmentTargetType` to the appropriate table component
- **`TabNavigation`** — UI component used when multiple assignment types are active; collapses to a flat view for single types

## Usage Example

```typescript
import { AssignedItemsView } from './assigned-items-view';

// Render assigned items for a specific user or entity
<AssignedItemsView
  itemId="user-123"
  itemType="USER"
  className="mt-4"
/>
```

## Behavior Notes

- **Loading state**: Displays a `Skeleton` placeholder while data loads and no active types are resolved yet
- **Empty state**: Returns `null` if no assignment targets have data after loading
- **Tab pinning**: Tracks the user's active tab selection via `pinnedTab` state; falls back to the first available tab if the pinned tab is no longer active
- **Single type**: Skips `TabNavigation` entirely and renders the table directly when only one assignment target type has data
