A React field component for managing multi-type assignment collections, allowing users to add, update, and remove assignment rows by target type.

## Key Components

**`AssignmentsField`** — Main exported component that renders a list of active assignment rows and a dropdown button to add new assignment types.

**Props (`AssignmentsFieldProps`):**

| Prop | Type | Description |
|------|------|-------------|
| `value` | `AssignmentsValue` | Current assignments keyed by target type |
| `onChange` | `(next: AssignmentsValue) => void` | Callback fired on any assignment change |
| `enabledTypes` | `AssignmentTargetType[]` | Allowed target types (defaults to all) |
| `disabled` | `boolean` | Disables all interactions |
| `className` | `string` | Optional wrapper class |

**Internal logic:**
- `activeTypes` — types present in the current value (rendered as rows)
- `availableTypes` — enabled types not yet added (shown in the "Assign Item" dropdown)
- `setRow` / `removeRow` / `addRow` — immutable update helpers for the `value` map

## Usage Example

```typescript
import { AssignmentsField } from './assignments-field';
import type { AssignmentsValue } from './types';

function MyForm() {
  const [assignments, setAssignments] = useState<AssignmentsValue>({});

  return (
    <AssignmentsField
      value={assignments}
      onChange={setAssignments}
      enabledTypes={['user', 'team']}
    />
  );
}
```

> The dropdown only surfaces target types not already present in `value`, preventing duplicate rows. Removing a row deletes the key entirely from the value object rather than setting it to an empty array.
