A form field component for managing multi-target assignment selections, allowing users to add, update, and remove assignment rows grouped by target type (e.g., users, teams, companies).

## Key Components

- **`AssignmentsField`** — Main exported component that renders a list of active assignment rows and a dropdown to add new target types
- **`activeTypes`** — Memoized list of target types that already have entries in the current value
- **`availableTypes`** — Memoized list of target types not yet added, used to populate the "Assign Item" dropdown
- **`setRow`** / **`removeRow`** / **`addRow`** — Internal handlers that produce immutable updates to `AssignmentsValue`

## Props

| Prop | Type | Description |
|------|------|-------------|
| `value` | `AssignmentsValue` | Current assignments state keyed by target type |
| `onChange` | `(next: AssignmentsValue) => void` | Callback fired on any change |
| `enabledTypes` | `AssignmentTargetType[]` | Target types to expose; defaults to all |
| `disabled` | `boolean` | Disables all interactive controls |
| `className` | `string` | Optional wrapper class override |

## Usage Example

```typescript
import { AssignmentsField } from './assignments-field';
import type { AssignmentsValue } from './types';

function MyForm() {
  const [assignments, setAssignments] = useState<AssignmentsValue>({});

  return (
    <AssignmentsField
      value={assignments}
      onChange={setAssignments}
      enabledTypes={['user', 'team']}
    />
  );
}
```
