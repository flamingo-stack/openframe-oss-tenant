A controlled form field component for managing multi-type assignment selections, allowing users to add, update, and remove assignment rows grouped by target type.

## Key Components

- **`AssignmentsField`** — Main exported component that renders active assignment rows and an "Assign Item" dropdown button for adding new assignment types
- **`AssignmentsFieldProps`** — Interface defining the component's contract:
  - `value` / `onChange` — Controlled field pattern
  - `enabledTypes` — Restricts which assignment target types are available (defaults to all)
  - `disabled` / `className` — Standard UI props
- **`isPresent`** — Type guard utility that checks whether an assignment type has been initialized in the current value

## Usage Example

```typescript
import { AssignmentsField } from './assignments-field';
import type { AssignmentsValue } from './types';

function MyForm() {
  const [assignments, setAssignments] = useState<AssignmentsValue>({});

  return (
    <AssignmentsField
      value={assignments}
      onChange={setAssignments}
      enabledTypes={['user', 'team']}
    />
  );
}
```

## Behavior Notes

- **`activeTypes`** — Derived list of types that have been added (key exists in `value`)
- **`availableTypes`** — Derived list of types not yet added; drives the dropdown menu items
- Adding a type initializes it with an empty `[]` refs array; removing a type deletes its key from the value object entirely
- The "Assign Item" dropdown is hidden once all enabled types have been added
