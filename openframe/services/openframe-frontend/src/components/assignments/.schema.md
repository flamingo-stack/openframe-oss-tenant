Defines Zod validation schemas for assignment references used across organizational entities (devices, tickets, knowledge articles).

## Key Components

- **`assignmentRefSchema`** — Internal schema for a single assignment reference, requiring an `id` and `label` string.
- **`assignmentsSchema`** — Exported schema validating an optional map of assignment arrays grouped by entity type (`ORGANIZATION`, `DEVICE`, `TICKET`, `KNOWLEDGE_ARTICLE`). Satisfies the `AssignmentsValue` type contract.
- **`ASSIGNMENTS_DEFAULT`** — Exported default value for assignments, initialized as an empty object.

## Usage Example

```typescript
import { assignmentsSchema, ASSIGNMENTS_DEFAULT } from './schema';

// Validate incoming assignments payload
const result = assignmentsSchema.safeParse({
  DEVICE: [{ id: 'dev-123', label: 'Workstation A' }],
  TICKET: [{ id: 'tkt-456', label: 'Printer Issue' }],
});

if (result.success) {
  console.log(result.data); // typed as AssignmentsValue | undefined
}

// Use default value as initial state
const assignments = ASSIGNMENTS_DEFAULT; // {}
```
