Defines Zod validation schemas for assignment references used across organizational entities (devices, tickets, knowledge articles).

## Key Components

- **`assignmentRefSchema`** — Internal schema validating individual assignment references with `id` (string) and `label` (string) fields.
- **`assignmentsSchema`** — Exported schema validating an optional map of entity-type keys (`ORGANIZATION`, `DEVICE`, `TICKET`, `KNOWLEDGE_ARTICLE`) to arrays of assignment references. Satisfies the `AssignmentsValue` type contract.
- **`ASSIGNMENTS_DEFAULT`** — Exported constant providing an empty object as the default `AssignmentsValue`.

## Usage Example

```typescript
import { assignmentsSchema, ASSIGNMENTS_DEFAULT } from './schema';

// Validate incoming assignments payload
const result = assignmentsSchema.safeParse({
  DEVICE: [{ id: 'dev-001', label: 'Workstation A' }],
  TICKET: [{ id: 'tkt-042', label: 'Network Issue' }],
});

if (result.success) {
  console.log(result.data);
}

// Use default when no assignments are provided
const assignments = userInput ?? ASSIGNMENTS_DEFAULT;
```
