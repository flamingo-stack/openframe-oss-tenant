Defines Zod validation schemas for assignment references used across organizational entities (organizations, devices, tickets, and knowledge articles).

## Key Components

- **`assignmentRefSchema`** — Internal schema validating a single assignment reference with `id` (string) and `label` (string) fields.
- **`assignmentsSchema`** — Exported schema validating an optional map of entity-type keys to arrays of assignment references. Satisfies the `AssignmentsValue` type contract.
- **`ASSIGNMENTS_DEFAULT`** — Exported default value for assignments, initialized as an empty object.

## Usage Example

```typescript
import { assignmentsSchema, ASSIGNMENTS_DEFAULT } from './schema';

// Validate incoming assignments payload
const result = assignmentsSchema.safeParse({
  DEVICE: [{ id: 'dev-123', label: 'Workstation A' }],
  TICKET: [{ id: 'tkt-456', label: 'Issue #456' }],
});

if (result.success) {
  console.log(result.data); // { DEVICE: [...], TICKET: [...] }
}

// Use default when no assignments are provided
const assignments = userInput ?? ASSIGNMENTS_DEFAULT;
```
