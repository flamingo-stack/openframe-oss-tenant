Client-side route guard component that restricts access to pages based on the current application mode (e.g., static export vs. full server mode), rendering a styled "Access restricted" message for disallowed routes.

## Key Components

- **`RouteGuard`** — Wrapper component that checks the current pathname against `isRouteAllowedInCurrentMode` and either renders children or a styled access-denied screen.

## Usage Example

```typescript
// app/layout.tsx
import { RouteGuard } from '@/components/route-guard';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html>
      <body>
        <RouteGuard>
          {children}
        </RouteGuard>
      </body>
    </html>
  );
}
```

## Behavior

| Condition | Result |
|-----------|--------|
| Route allowed in current mode | Renders `children` normally |
| Route not allowed | Renders full-screen "Access restricted" message |

The access check is delegated entirely to `isRouteAllowedInCurrentMode` from `../lib/app-mode`, making this component a thin, presentation-layer enforcement point. No redirects are performed — blocked routes simply render the restriction UI in place.
