Client-side route guard component that checks whether the current route is permitted in the active app mode, rendering an "Access restricted" message if not.

## Key Components

- **`RouteGuard`** — Wrapper component that uses `usePathname` to detect the current route and calls `isRouteAllowedInCurrentMode` to determine access. Renders children if allowed, or a centered restricted-access screen if not.
- **`RouteGuardProps`** — Interface accepting `children: React.ReactNode`.

## Usage Example

```typescript
// app/layout.tsx
import { RouteGuard } from '@/components/route-guard';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html>
      <body>
        <RouteGuard>
          {children}
        </RouteGuard>
      </body>
    </html>
  );
}
```

> Route access logic is delegated entirely to `isRouteAllowedInCurrentMode` from `lib/app-mode`, making this component stateless and easy to test or swap out per deployment mode (e.g. static export vs. full server).
