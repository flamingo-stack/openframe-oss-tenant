Client-side route protection component that checks whether the current pathname is permitted in the active app mode (e.g., static export vs. full server mode), rendering an "Access restricted" screen if not.

## Key Components

- **`RouteGuard`** — Wrapper component that reads the current route via `usePathname` and delegates permission checks to `isRouteAllowedInCurrentMode`. Renders children if allowed; otherwise displays a centered access-denied message.

## Usage Example

```typescript
// Wrap page content or layout to enforce route-level access control
import { RouteGuard } from './route-guard';

export default function Layout({ children }: { children: React.ReactNode }) {
  return (
    <RouteGuard>
      {children}
    </RouteGuard>
  );
}
```

> Access control logic is delegated entirely to `isRouteAllowedInCurrentMode` from `lib/app-mode` — update that utility to change which routes are restricted per mode.
