Utility functions for the OpenFrame frontend, providing environment-aware base URL resolution and asset URL generation.

## Key Components

- **`getBaseUrl()`** — Returns the application base URL based on context: empty string (relative) in browser, or a configured/fallback URL (`http://localhost:4000`) in server-side contexts using `runtimeEnv`
- **`getAssetUrl(path)`** — Generates an absolute URL for a given asset path, normalizing leading slashes

## Usage Example

```typescript
import { getBaseUrl, getAssetUrl } from './utils';

// In a server-side context (e.g., SSR or API handler)
const base = getBaseUrl();
// → 'https://app.example.com' (production)
// → 'http://localhost:4000' (development fallback)

// Generate a full asset URL
const logo = getAssetUrl('images/logo.png');
// → '/images/logo.png' (browser)
// → 'http://localhost:4000/images/logo.png' (server)

const favicon = getAssetUrl('/favicon.ico');
// → '/favicon.ico' (browser)
// → 'http://localhost:4000/favicon.ico' (server)
```

> **Note:** `getBaseUrl()` returns an empty string in browser environments, producing relative URLs — this is intentional to support deployments behind reverse proxies or CDNs without hardcoding origins.
