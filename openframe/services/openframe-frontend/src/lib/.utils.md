Utility functions for the OpenFrame frontend, providing environment-aware URL resolution for server-side and browser contexts.

## Key Components

- **`getBaseUrl()`** — Returns the application's base URL based on the current environment. Returns an empty string in browser contexts (enabling relative URLs), and falls back through configured runtime URLs (`appUrl`, `devUrl`) to `http://localhost:4000` in non-browser contexts.
- **`getAssetUrl(path)`** — Generates an absolute URL for a given asset path by prepending the base URL and ensuring proper leading slash normalization.

## Usage Example

```typescript
import { getBaseUrl, getAssetUrl } from './utils';

// Server-side: returns configured URL or fallback
const base = getBaseUrl();
// → 'https://app.example.com' (production)
// → 'http://localhost:4000' (development fallback)
// → '' (in browser)

// Generate absolute asset URL
const logoUrl = getAssetUrl('images/logo.png');
// → 'https://app.example.com/images/logo.png' (server)
// → '/images/logo.png' (browser)

const iconUrl = getAssetUrl('/icons/favicon.ico');
// → 'https://app.example.com/icons/favicon.ico' (server)
// → '/icons/favicon.ico' (browser)
```

## Notes

- Browser detection uses `typeof window !== 'undefined'`, making it safe for SSR environments.
- Runtime configuration is sourced from `./runtime-config` via `runtimeEnv`, which abstracts environment variable access for both build-time and runtime scenarios.
