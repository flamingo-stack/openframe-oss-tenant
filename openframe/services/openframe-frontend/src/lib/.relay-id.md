Utilities for encoding and decoding Relay-style Global IDs — base64-encoded strings of the form `typename:rawId` — with cross-environment support for both browser and Node.js.

## Key Components

| Export | Description |
|--------|-------------|
| `DecodedGlobalId` | Interface with `typename` and `rawId` string fields |
| `toGlobalId` | Encodes a typename + rawId pair into a base64 Global ID |
| `decodeGlobalId` | Decodes a Global ID back to `DecodedGlobalId`, returns `null` on failure |
| `ensureGlobalIdForType` | Returns a valid Global ID for the given type, encoding only if not already encoded |
| `notificationGlobalId` | Convenience wrapper for `ensureGlobalIdForType('Notification', rawId)` |

## Usage Example

```typescript
import {
  toGlobalId,
  decodeGlobalId,
  ensureGlobalIdForType,
  notificationGlobalId,
} from './relay-id';

// Encode a raw ID
const globalId = toGlobalId('Ticket', '42');
// → "VGlja2V0OjQy"

// Decode it back
const decoded = decodeGlobalId(globalId);
// → { typename: 'Ticket', rawId: '42' }

// Idempotent — already a Global ID, returns as-is
const safe = ensureGlobalIdForType('Ticket', globalId);
// → "VGlja2V0OjQy"

// Raw ID passed in — gets encoded
const safe2 = ensureGlobalIdForType('Ticket', '42');
// → "VGlja2V0OjQy"

// Shorthand for Notification type
const notifId = notificationGlobalId('99');
// → "Tm90aWZpY2F0aW9uOjk5"
```

> `decodeGlobalId` returns `null` for any input that is not valid base64 or does not contain the expected `typename:rawId` format, making it safe to call without a try/catch.
