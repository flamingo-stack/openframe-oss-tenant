Utilities for encoding and decoding Relay-style Global IDs — base64-encoded strings in the format `typename:rawId` — with cross-environment support for both browser and Node.js.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `DecodedGlobalId` | Interface | Shape of a decoded global ID: `{ typename, rawId }` |
| `toGlobalId` | Function | Encodes a typename + rawId into a base64 global ID |
| `decodeGlobalId` | Function | Decodes a global ID string, returns `DecodedGlobalId` or `null` on failure |
| `ensureGlobalIdForType` | Function | Returns a valid global ID for the given typename, encoding only if needed |
| `notificationGlobalId` | Function | Shorthand to produce a global ID scoped to the `Notification` typename |

## Usage Example

```typescript
import {
  toGlobalId,
  decodeGlobalId,
  ensureGlobalIdForType,
  notificationGlobalId,
} from './relay-id';

// Encode a raw ID
const globalId = toGlobalId('Ticket', '42');
// → "VGlja2V0OjQy"

// Decode it back
const decoded = decodeGlobalId(globalId);
// → { typename: 'Ticket', rawId: '42' }

// Safely ensure the correct type without double-encoding
const id1 = ensureGlobalIdForType('Ticket', '42');         // encodes
const id2 = ensureGlobalIdForType('Ticket', globalId);     // already encoded, returns as-is

// Notification-specific shorthand
const notifId = notificationGlobalId('99');
// → toGlobalId('Notification', '99')
```

> `decodeGlobalId` returns `null` for invalid or malformed input, making it safe to use without try/catch.
