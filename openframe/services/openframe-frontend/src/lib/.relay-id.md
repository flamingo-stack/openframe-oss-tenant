Utility for encoding and decoding Relay-style Global IDs — base64-encoded strings in the format `typename:rawId` — with cross-environment support for both browser and Node.js.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `DecodedGlobalId` | Interface | Shape of a decoded global ID: `{ typename, rawId }` |
| `toGlobalId` | Function | Encodes a typename + rawId into a base64 global ID |
| `decodeGlobalId` | Function | Decodes a global ID string; returns `null` if invalid |
| `ensureGlobalIdForType` | Function | Returns the value as-is if already a valid global ID for the given type, otherwise encodes it |
| `notificationGlobalId` | Function | Convenience wrapper that ensures a `Notification`-typed global ID |

## Usage Example

```typescript
import {
  toGlobalId,
  decodeGlobalId,
  ensureGlobalIdForType,
  notificationGlobalId,
} from './relay-id';

// Encode a raw database ID
const globalId = toGlobalId('Ticket', '42');
// => "VGlja2V0OjQy"

// Decode back
const decoded = decodeGlobalId(globalId);
// => { typename: 'Ticket', rawId: '42' }

// Safe to call repeatedly — won't double-encode
const id = ensureGlobalIdForType('Ticket', '42');        // encodes
const id2 = ensureGlobalIdForType('Ticket', globalId);   // passthrough

// Notification shorthand
const notifId = notificationGlobalId('99');
// => toGlobalId('Notification', '99')
```

> **Note:** Encoding uses `window.btoa` in browser environments and `Buffer` in Node.js, making this safe to import in both client and server contexts.
