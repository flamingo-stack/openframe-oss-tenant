Registers Next.js-specific implementations of core navigation, link, image, and dynamic import primitives with the OpenFrame embed shim system, bridging the framework-agnostic `@flamingo-stack/openframe-frontend-core` with Next.js APIs.

## Key Components

- **`registerEmbedShims()`** — Main registration function (idempotent via `registered` guard) that binds Next.js primitives to the embed shim layer
- **Navigation shims** — Wires `useRouter`, `usePathname`, `useSearchParams`, `useParams`, `redirect`, `permanentRedirect`, and `notFound` from `next/navigation`
- **Link/Image/Dynamic shims** — Registers `NextLink`, `NextImage`, and `nextDynamic` as the framework-level implementations
- **Auto-invocation** — Called immediately on module load to ensure shims are registered at import time

## Usage Example

```typescript
// Typically imported once at the app entry point (e.g., layout.tsx or _app.tsx)
import '@/lib/register-embed-shims';

// Or explicitly called if needed
import { registerEmbedShims } from '@/lib/register-embed-shims';

registerEmbedShims(); // Safe to call multiple times — runs only once
```

> **Note:** The `'use client'` directive ensures this runs in the browser/client context, as Next.js navigation hooks are client-side only. The singleton `registered` flag prevents duplicate registration if the module is imported from multiple locations.
