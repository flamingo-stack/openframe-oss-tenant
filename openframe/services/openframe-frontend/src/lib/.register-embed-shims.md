Registers Next.js-specific implementations for the OpenFrame embed shim layer, bridging Next.js primitives (routing, image, link, dynamic imports) into the framework-agnostic `@flamingo-stack/openframe-frontend-core` embed system. Executes once on module load via a guard flag.

## Key Components

| Export | Description |
|--------|-------------|
| `registerEmbedShims()` | One-time registration function that binds Next.js implementations to the embed shim registry |

**Registered shims:**

| Shim | Next.js Implementation |
|------|------------------------|
| Navigation | `useRouter`, `usePathname`, `useSearchParams`, `useParams`, `redirect`, `permanentRedirect`, `notFound` |
| Link | `next/link` |
| Image | `next/image` |
| Dynamic | `next/dynamic` |

## Usage Example

```typescript
// Import early in your app entry point (e.g., layout.tsx or _app.tsx)
// The shims auto-register on import — no manual call needed
import '@/lib/register-embed-shims';

// Or call explicitly if lazy registration is preferred
import { registerEmbedShims } from '@/lib/register-embed-shims';

registerEmbedShims(); // Safe to call multiple times — runs only once
```

## Notes

- Marked `'use client'` — must run in a browser/client context (Next.js App Router).
- Uses a `registered` guard to prevent duplicate registration across hot-reloads or multiple imports.
- Designed to be imported as a side-effect module at the application root to ensure shims are available before any embed components render.
