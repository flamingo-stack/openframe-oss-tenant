Registers Next.js-specific implementations for the OpenFrame embed shim system, bridging Next.js primitives (routing, images, links, dynamic imports) into the framework-agnostic `@flamingo-stack/openframe-frontend-core` embed layer.

## Key Components

- **`registerEmbedShims()`** — One-time initialization function (guarded by `registered` flag) that wires up all Next.js implementations into the core embed shim registry
- **`registered` flag** — Module-level singleton guard preventing double-registration on re-renders or hot reloads

### Registered Shims

| Shim | Next.js Implementation |
|------|----------------------|
| Navigation | `useRouter`, `usePathname`, `useSearchParams`, `useParams`, `redirect`, `permanentRedirect`, `notFound` |
| Link | `NextLink` (`next/link`) |
| Image | `NextImage` (`next/image`) |
| Dynamic | `nextDynamic` (`next/dynamic`) |

## Usage Example

```typescript
// Typically called once at the app entry point (e.g., layout.tsx or _app.tsx)
import { registerEmbedShims } from './register-embed-shims';

// Auto-executes on import — no manual call needed
// But can also be called explicitly for clarity:
registerEmbedShims();
```

> **Note:** The file is marked `'use client'` and self-invokes `registerEmbedShims()` at module load time, so simply importing this file is sufficient to bootstrap all shims. Subsequent calls are no-ops due to the singleton guard.
