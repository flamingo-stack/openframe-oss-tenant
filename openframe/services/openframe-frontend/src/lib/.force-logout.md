Handles forced user logout by clearing authentication tokens from localStorage, resetting the auth store state, and optionally redirecting to a login page.

## Key Components

### `forceLogout(options?)`
Main async function that performs a complete logout sequence:
- Removes `ACCESS_TOKEN_KEY` and `REFRESH_TOKEN_KEY` from `localStorage`
- Dynamically imports and calls `logout()` from the auth store
- Redirects to the default auth path unless already on an auth page or in SaaS tenant mode
- No-ops in non-browser (SSR) environments

### `hasStoredTokens()`
Returns `true` if either an access or refresh token exists in `localStorage`. Safe for SSR — returns `false` when `window` is undefined.

### `clearStoredTokens()`
Removes both token keys from `localStorage` without triggering store updates or redirects. Useful for lightweight token cleanup outside a full logout flow.

### `ForceLogoutOptions` (interface)

| Property | Type | Default | Description |
|---|---|---|---|
| `reason` | `string` | — | Optional logout reason (informational) |
| `shouldRedirect` | `boolean` | `true` | Whether to redirect after logout |
| `redirectPath` | `string` | — | Override the default redirect target |

## Usage Example

```typescript
// Full force logout with redirect
await forceLogout({ reason: 'session_expired' });

// Logout without redirect (e.g. silent token invalidation)
await forceLogout({ shouldRedirect: false });

// Logout and redirect to a specific path
await forceLogout({ redirectPath: '/auth/login' });

// Check if tokens exist before making an authenticated request
if (!hasStoredTokens()) {
  await forceLogout();
}

// Lightweight token clear only
clearStoredTokens();
```

> **Note:** `forceLogout` skips the redirect when running in SaaS tenant mode (`isSaasTenantMode() === true`) or when the current path already starts with `/auth`.
