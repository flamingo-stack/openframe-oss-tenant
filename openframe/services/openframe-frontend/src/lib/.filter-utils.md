Shared utility functions for normalizing and deduplicating table filter options across screens (devices, logs, organizations, etc.).

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `FilterOption` | Interface | Base structure for filter items (`id`, `label`, `value`) |
| `deduplicateFilterOptions<T>` | Function | Removes duplicate filter entries by `id` using a `Map` |
| `transformOrganizationFilters` | Function | Normalizes multi-format org data into `FilterOption[]` with deduplication |

## Usage Example

```typescript
import { deduplicateFilterOptions, transformOrganizationFilters, FilterOption } from './filter-utils';

// Deduplicate raw filter options
const raw: FilterOption[] = [
  { id: 'uuid-1', label: 'Acme', value: 'uuid-1' },
  { id: 'uuid-1', label: 'Acme', value: 'uuid-1' }, // duplicate
  { id: 'uuid-2', label: 'Other Corp', value: 'uuid-2' },
];
const unique = deduplicateFilterOptions(raw);
// [{ id: 'uuid-1', ... }, { id: 'uuid-2', ... }]

// Normalize orgs from logs backend (id + name format)
const fromLogs = transformOrganizationFilters([
  { id: 'uuid-1', name: 'Acme' },
  { id: 'uuid-1', name: 'Acme' }, // backend duplicate
]);

// Normalize orgs from devices backend (value + label format)
const fromDevices = transformOrganizationFilters([
  { value: 'uuid-2', label: 'Other Corp' },
]);

// Handles null/undefined safely
const safe = deduplicateFilterOptions(null); // []
```

## Notes

- `deduplicateFilterOptions` is generic — accepts any type extending `FilterOption`, preserving the original shape.
- `transformOrganizationFilters` maps `name: 'null'` strings to the label `'System'` and falls back to `'system'` for missing IDs.
- Both functions return empty arrays for `null`, `undefined`, or non-array inputs — safe to call without guards.
