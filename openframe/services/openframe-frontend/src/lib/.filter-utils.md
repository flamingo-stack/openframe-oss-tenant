Shared utilities for normalizing and deduplicating table filter options across screens (devices, logs, organizations, etc.).

## Key Components

- **`FilterOption`** — Base interface for filter entries with `id`, `label`, and `value` fields
- **`deduplicateFilterOptions<T>`** — Generic function that removes duplicate filter options by `id` using a `Map`
- **`transformOrganizationFilters`** — Normalizes organization data from multiple backend response shapes into a consistent `FilterOption[]`

## Usage Example

```typescript
import { deduplicateFilterOptions, transformOrganizationFilters, FilterOption } from './filter-utils';

// Deduplicate raw filter options
const raw: FilterOption[] = [
  { id: 'uuid-1', label: 'Acme', value: 'uuid-1' },
  { id: 'uuid-1', label: 'Acme', value: 'uuid-1' }, // duplicate
  { id: 'uuid-2', label: 'Other', value: 'uuid-2' },
];
const unique = deduplicateFilterOptions(raw);
// [{ id: 'uuid-1', ... }, { id: 'uuid-2', ... }]

// Normalize org data from logs endpoint (id/name shape)
const logsOrgs = [{ id: 'org-1', name: 'Flamingo MSP' }];
transformOrganizationFilters(logsOrgs);
// [{ id: 'org-1', label: 'Flamingo MSP', value: 'org-1' }]

// Normalize org data from devices endpoint (value/label shape)
const deviceOrgs = [{ value: 'org-2', label: 'Acme Corp' }];
transformOrganizationFilters(deviceOrgs);
// [{ id: 'org-2', label: 'Acme Corp', value: 'org-2' }]
```

> **Note:** `transformOrganizationFilters` maps `name: 'null'` (a string null from the backend) to `'System'`, and falls back to `'Unknown'` when no label is resolvable.
