Shared utilities for building and normalizing table filter options across screens (devices, logs, organizations, etc.), with deduplication and multi-format normalization support.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `FilterOption` | Interface | Base shape for filter items: `id`, `label`, `value` |
| `deduplicateFilterOptions<T>` | Function | Removes duplicate entries by `id` using a `Map` |
| `transformOrganizationFilters` | Function | Normalizes org data from multiple backend formats into `FilterOption[]` |

## Usage Example

```typescript
import { deduplicateFilterOptions, transformOrganizationFilters, FilterOption } from './filter-utils';

// Deduplicate raw filter options
const raw: FilterOption[] = [
  { id: 'uuid-1', label: 'Acme', value: 'uuid-1' },
  { id: 'uuid-1', label: 'Acme', value: 'uuid-1' }, // duplicate
  { id: 'uuid-2', label: 'Other', value: 'uuid-2' },
];
const unique = deduplicateFilterOptions(raw);
// [{ id: 'uuid-1', ... }, { id: 'uuid-2', ... }]

// Normalize mixed backend org formats
const orgs = [
  { id: 'abc', name: 'Flamingo MSP' },       // logs format
  { value: 'def', label: 'Acme Corp' },       // devices format
  { id: 'xyz', name: 'null' },               // system tenant
];
const filters = transformOrganizationFilters(orgs);
// [
//   { id: 'abc', label: 'Flamingo MSP', value: 'abc' },
//   { id: 'def', label: 'Acme Corp',    value: 'def' },
//   { id: 'xyz', label: 'System',       value: 'xyz' },
// ]
```

## Notes

- `deduplicateFilterOptions` is generic (`T extends FilterOption`), preserving any extra fields on extended types.
- `transformOrganizationFilters` maps the string `"null"` name to `"System"` to handle unassigned tenants gracefully.
- Both functions safely return `[]` for `null`, `undefined`, or non-array inputs.
