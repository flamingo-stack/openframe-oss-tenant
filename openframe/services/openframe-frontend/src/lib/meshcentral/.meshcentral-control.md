WebSocket client for controlling MeshCentral devices through the control channel. Handles authentication, tunneling, and power management operations with automatic reconnection and message queuing capabilities.

## Key Components

**MeshControlClient** - Main client class that manages WebSocket connections to MeshCentral's control endpoint
- `openSession()` - Establishes authenticated connection and retrieves auth cookies
- `getAuthCookies()` - Requests and returns authentication cookies for relay operations
- `sendDesktopTunnel()` / `sendFileTunnel()` - Creates tunnels for remote desktop (protocol 2) and file access (protocol 5)
- `powerAction()` - Executes power management commands (wake, sleep, reset, poweroff) on target nodes
- `reconnect()` - Re-establishes connection with fresh authentication

**ControlAuthCookies** - Type defining authentication cookies structure with main auth cookie and optional relay cookie

## Usage Example

```typescript
import { MeshControlClient } from './meshcentral-control'

// Initialize with credentials or auth cookie
const client = new MeshControlClient(
  { user: 'admin', pass: 'password' }, 
  'optional-auth-cookie'
)

// Establish session and get auth cookies
await client.openSession()
const cookies = await client.getAuthCookies()

// Create desktop tunnel for remote access
client.sendDesktopTunnel(
  'node123', 
  'relay456', 
  cookies.relayCookie
)

// Execute power action on device
await client.powerAction('node123', 'reset', 10000)

// Clean up connection
client.close()
```

The client automatically handles WebSocket reconnection, message queuing during disconnects, and maintains active tunnel state for seamless reconnection scenarios.
