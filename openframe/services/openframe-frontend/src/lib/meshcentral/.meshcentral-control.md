A WebSocket client for MeshCentral control operations, providing authentication, tunnel management, and power actions for remote device management. The client handles automatic reconnection, cookie-based authentication, and maintains active tunnel sessions.

## Key Components

- **MeshControlClient** - Main client class for MeshCentral control operations
- **ControlAuthCookies** - Type definition for authentication cookies
- **WebSocketManager** - Underlying WebSocket connection management
- **Tunnel Management** - Methods for desktop and file tunnels
- **Power Actions** - Remote power control (wake, sleep, reset, poweroff)

## Usage Example

```typescript
import { MeshControlClient } from './meshcentral-control'

// Create client with credentials
const client = new MeshControlClient({ 
  user: 'admin', 
  pass: 'password' 
})

// Establish connection and authenticate
await client.openSession()

// Get authentication cookies
const cookies = await client.getAuthCookies()

// Send desktop tunnel for remote access
client.sendDesktopTunnel(
  'node123', 
  'relay456', 
  cookies.relayCookie
)

// Execute power action
await client.powerAction('node123', 'wake')

// Clean up
client.close()
```

The client automatically handles WebSocket reconnection, cookie refresh, and maintains active tunnels across connection drops. It supports both credential-based and token-based authentication depending on the runtime environment.
