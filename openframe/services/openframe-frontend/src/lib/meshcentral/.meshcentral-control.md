MeshCentral WebSocket control client that manages authentication, remote desktop/file tunnels, and power actions for devices managed by a MeshCentral server.

## Key Components

- **MeshControlClient** - Main client class for MeshCentral control operations
- **ControlAuthCookies** - Type definition for authentication cookies (authCookie, relayCookie)
- **WebSocket Management** - Handles connection lifecycle with automatic reconnection
- **Tunnel Management** - Creates and maintains desktop/file access tunnels to remote devices
- **Power Actions** - Executes wake, sleep, reset, and poweroff commands on remote devices
- **Authentication** - Manages auth cookies and token-based authentication

## Usage Example

```typescript
import { MeshControlClient } from './meshcentral-control'

// Initialize client with credentials
const client = new MeshControlClient({
  user: 'admin',
  pass: 'password'
})

// Open connection and get auth cookies
await client.openSession()
const cookies = await client.getAuthCookies()

// Create desktop tunnel to a device
client.sendDesktopTunnel(
  'node//device123', 
  'relay456',
  cookies.relayCookie
)

// Execute power action
await client.powerAction('device123', 'wake')

// Create file access tunnel
client.sendFileTunnel(
  'node//device123',
  'relay789', 
  cookies.relayCookie
)

// Clean up
client.close()
```

The client automatically handles WebSocket reconnection, maintains active tunnels across reconnects, and provides promise-based APIs for power actions with configurable timeouts.
