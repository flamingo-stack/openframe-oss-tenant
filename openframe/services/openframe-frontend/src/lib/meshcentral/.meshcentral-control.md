WebSocket client for controlling MeshCentral devices and managing secure tunnels for remote desktop, file transfers, and power management operations.

## Key Components

**MeshControlClient Class**
- `openSession()` - Establishes WebSocket connection and authenticates
- `getAuthCookies()` - Retrieves authentication cookies for secure operations
- `sendDesktopTunnel()` - Creates remote desktop tunnel to specified device
- `sendFileTunnel()` - Establishes file transfer tunnel with usage tracking
- `powerAction()` - Executes power commands (wake, sleep, reset, poweroff)
- `reconnect()` - Handles connection recovery with tunnel restoration

**Core Features**
- Automatic authentication with credentials or tokens
- Tunnel management with active tunnel tracking and restoration
- Promise-based power actions with timeout handling
- WebSocket connection management with reconnection logic

## Usage Example

```typescript
// Initialize client with credentials
const client = new MeshControlClient({
  user: 'admin',
  pass: 'password'
})

// Open session and authenticate
await client.openSession()

// Create remote desktop tunnel
client.sendDesktopTunnel(
  'node123',
  'relay456',
  undefined,
  'domain1'
)

// Execute power action
await client.powerAction('node123', 'wake', 5000)

// Get auth cookies for other operations
const cookies = await client.getAuthCookies()

// Clean up
client.close()
```
