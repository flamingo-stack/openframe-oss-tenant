A WebSocket-based client for controlling MeshCentral devices remotely. Provides authentication, tunnel management, and power control operations through a persistent WebSocket connection.

## Key Components

**MeshControlClient** - Main client class that manages the WebSocket connection and provides device control methods
- `openSession()` - Establishes connection and handles authentication
- `getAuthCookies()` - Retrieves authentication cookies for session management
- `sendRelayTunnel()` - Creates relay tunnels for remote access protocols
- `sendDesktopTunnel()` - Establishes remote desktop connections
- `sendFileTunnel()` - Creates file transfer tunnels
- `powerAction()` - Executes power management commands (wake, sleep, reset, poweroff)
- `reconnect()` - Re-establishes connection after disconnection
- `close()` - Cleanly closes the connection and clears resources

**ControlAuthCookies** - Type definition for authentication cookies containing authCookie and optional relayCookie

## Usage Example

```typescript
import { MeshControlClient } from './meshcentral-control'

// Initialize client with credentials
const meshClient = new MeshControlClient({
  user: 'admin',
  pass: 'password123'
})

// Open connection and authenticate
await meshClient.openSession()

// Create remote desktop tunnel
meshClient.sendDesktopTunnel(
  'node123456789', 
  'relay-id-abc', 
  undefined, 
  'domain-prefix'
)

// Execute power actions
await meshClient.powerAction('node123456789', 'wake')
await meshClient.powerAction('node123456789', 'reset')

// Clean up
meshClient.close()
```

The client automatically handles reconnection, maintains active tunnel state, and provides timeout management for all operations.
