WebSocket client for controlling MeshCentral devices through the control API, handling authentication, tunneling, and power management operations.

## Key Components

- **MeshControlClient** - Main client class for MeshCentral control operations
- **ControlAuthCookies** - Type for authentication and relay cookies
- **openSession()** - Establishes connection and handles authentication
- **sendRelayTunnel()** - Creates tunnels for desktop/file access
- **powerAction()** - Executes power commands (wake, sleep, reset, poweroff)
- **getAuthCookies()** - Retrieves authentication cookies from server

## Usage Example

```typescript
import { MeshControlClient } from './meshcentral-control'

// Initialize client with credentials
const client = new MeshControlClient(
  { user: 'admin', pass: 'password' }
)

// Open session and authenticate
await client.openSession()

// Create desktop tunnel
client.sendDesktopTunnel(
  'node123', 
  'relay456', 
  undefined, 
  'domain1'
)

// Execute power action
await client.powerAction('node123', 'wake')

// Check connection status
if (client.isConnected()) {
  console.log('Client is connected')
}

// Clean up
client.close()
```

The client automatically handles WebSocket reconnection, message queuing, authentication cookie management, and maintains active tunnel state for recovery after disconnections.
