A WebSocket-based client for controlling MeshCentral devices and managing secure tunnel connections. This client handles authentication, power management, and relay tunnel establishment for remote device access.

## Key Components

**MeshControlClient** - Main class providing:
- `openSession()` - Establishes authenticated WebSocket connection
- `getAuthCookies()` - Retrieves authentication cookies for secure operations
- `powerAction()` - Sends power commands (wake, sleep, reset, poweroff) to devices
- `sendDesktopTunnel()` - Creates desktop sharing tunnels
- `sendFileTunnel()` - Creates file transfer tunnels
- `sendRelayTunnel()` - Generic tunnel creation with custom protocols
- `reconnect()` - Handles connection recovery with credential refresh
- `close()` - Clean shutdown of connections and pending requests

**Internal Features:**
- Automatic reconnection with authentication retry logic
- Pending request management with timeout handling
- Active tunnel state tracking and restoration
- OpenFrame token integration for development environments

## Usage Example

```typescript
import { MeshControlClient } from './meshcentral-control'

// Initialize with credentials or auth cookie
const client = new MeshControlClient(
  { user: 'admin', pass: 'password' }, 
  'auth_cookie_string'
)

// Open authenticated session
await client.openSession()

// Send power commands to devices
await client.powerAction('device123', 'wake')
await client.powerAction('device456', 'reset', 10000) // 10s timeout

// Create secure tunnels for remote access
client.sendDesktopTunnel('device123', 'relay_id_123')
client.sendFileTunnel('device456', 'relay_id_456')

// Check connection status
if (client.isConnected()) {
  console.log('MeshCentral control connection active')
}

// Clean shutdown
client.close()
```
