Manages a persistent WebSocket connection to the MeshCentral control channel (`/control.ashx`), handling authentication, tunnel signaling, power actions, and clipboard operations for remote node management.

## Key Components

- **`MeshControlClient`** — Main class that wraps `WebSocketManager` to communicate with MeshCentral's control endpoint
- **`ControlAuthCookies`** — Type holding `authCookie` and optional `relayCookie` used to authenticate relay tunnels
- **`pendingRequests`** — Internal `Map` tracking in-flight async requests with resolve/reject/timeout handles
- **`activeTunnels`** — Tracks open relay tunnels so they can be automatically re-established on reconnect

## Key Methods

| Method | Description |
|--------|-------------|
| `openSession()` | Connects the WebSocket and waits for auth cookies |
| `getAuthCookies()` | Returns cached cookies or waits for the `authcookie` handshake |
| `sendRelayTunnel()` | Sends a generic relay tunnel message (protocol-agnostic) |
| `sendDesktopTunnel()` | Shorthand for protocol `2` (desktop/RDP relay) |
| `sendFileTunnel()` | Shorthand for protocol `5` (file transfer relay) |
| `powerAction()` | Sends wake/sleep/reset/poweroff to a node with promise-based response |
| `setClipboard()` | Pushes clipboard text to a remote node |
| `getClipboard()` | Retrieves clipboard text from a remote node |
| `close()` / `reconnect()` | Lifecycle management |

## Usage Example

```typescript
const client = new MeshControlClient(
  { user: 'admin', pass: 'secret' }
);

// Open session and retrieve auth cookies
await client.openSession();
const cookies = await client.getAuthCookies();

// Start a desktop relay tunnel
client.sendDesktopTunnel(
  'node//abc123',
  'relay-id-xyz',
  cookies.relayCookie,
);

// Send a power action
await client.powerAction('node//abc123', 'reset');

// Clipboard operations
await client.setClipboard('node//abc123', 'Hello from OpenFrame');
const text = await client.getClipboard('node//abc123');

// Clean up
client.close();
```
