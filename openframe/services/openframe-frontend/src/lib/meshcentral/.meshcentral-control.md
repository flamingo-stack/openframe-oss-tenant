WebSocket client for controlling MeshCentral devices with authentication, tunnel management, and power actions. Handles session management, cookie authentication, and maintains active tunnel connections with automatic reconnection.

## Key Components

**MeshControlClient**
- Main client class for MeshCentral control operations
- Manages WebSocket connection lifecycle and authentication
- Handles tunnel creation for desktop/file access
- Provides power management actions (wake, sleep, reset, poweroff)

**Key Methods:**
- `openSession()` - Establishes authenticated WebSocket connection
- `getAuthCookies()` - Retrieves authentication cookies from server
- `sendDesktopTunnel()` - Creates desktop remote access tunnel
- `sendFileTunnel()` - Creates file transfer tunnel
- `powerAction()` - Executes power commands on remote devices

**Internal State:**
- `activeTunnels` - Tracks active tunnel connections for reconnection
- `pendingRequests` - Manages async request/response pairs
- `cookies` - Stores authentication and relay cookies

## Usage Example

```typescript
// Initialize with credentials
const client = new MeshControlClient(
  { user: 'admin', pass: 'password' }
)

// Open authenticated session
await client.openSession()

// Create desktop tunnel for remote access
client.sendDesktopTunnel('node123', 'relay456', undefined, 'domain')

// Execute power actions
await client.powerAction('node123', 'wake')
await client.powerAction('node123', 'reset')

// File transfer tunnel
client.sendFileTunnel('node123', 'relay789')

// Check connection status
if (client.isConnected()) {
  console.log('Client is connected and ready')
}

// Cleanup
client.close()
```
