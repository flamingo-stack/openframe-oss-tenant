WebSocket client for controlling MeshCentral devices, providing remote power management, desktop access, and file transfer capabilities through authenticated tunnel connections.

## Key Components

**Core Classes:**
- `MeshControlClient` - Main client for MeshCentral control operations
- `ControlAuthCookies` - Type definition for authentication cookies

**Primary Methods:**
- `openSession()` - Establishes authenticated WebSocket connection
- `powerAction()` - Sends power commands (wake, sleep, reset, poweroff) to devices
- `sendDesktopTunnel()` - Creates remote desktop tunnel connections
- `sendFileTunnel()` - Establishes file transfer tunnels
- `getAuthCookies()` - Retrieves authentication cookies for session management

**Connection Management:**
- `connect()`/`disconnect()` - WebSocket lifecycle management
- `reconnect()` - Reconnects with fresh authentication
- `isConnected()` - Connection status checking

## Usage Example

```typescript
import { MeshControlClient } from './meshcentral-control'

// Initialize client with credentials
const client = new MeshControlClient({
  user: 'admin',
  pass: 'password'
})

// Establish session and perform power action
await client.openSession()

// Wake up a device
await client.powerAction('device-node-id', 'wake')

// Create desktop tunnel for remote access
client.sendDesktopTunnel('device-node-id', 'relay-session-id')

// Create file transfer tunnel
client.sendFileTunnel('device-node-id', 'file-relay-id')

// Check connection status
if (client.isConnected()) {
  console.log('Control session active')
}

// Clean up
client.close()
```
