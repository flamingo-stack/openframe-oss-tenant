A TypeScript client that manages WebSocket connections to MeshCentral's control interface, providing authentication, tunnel management, and power control operations for remote device management.

## Key Components

**Main Class:**
- `MeshControlClient` - Primary client for MeshCentral control operations with auto-reconnection and session management

**Key Methods:**
- `openSession()` - Establishes WebSocket connection and retrieves authentication cookies
- `getAuthCookies()` - Retrieves authentication cookies required for MeshCentral operations
- `sendDesktopTunnel()` / `sendFileTunnel()` - Creates tunnels for remote desktop and file access
- `powerAction()` - Executes power management commands (wake, sleep, reset, poweroff) on remote devices
- `reconnect()` - Handles connection recovery with fresh authentication

**Internal Features:**
- Promise-based request/response handling with timeout management
- Active tunnel tracking and automatic re-establishment after reconnection
- Integrated WebSocketManager for reliable connection management

## Usage Example

```typescript
import { MeshControlClient } from './meshcentral-control'

// Initialize with credentials
const client = new MeshControlClient({ 
  user: 'admin', 
  pass: 'password' 
})

// Open session and authenticate
await client.openSession()

// Create desktop tunnel for remote access
client.sendDesktopTunnel('node123', 'relay456', undefined, 'domain1')

// Execute power actions
await client.powerAction('node123', 'wake')
await client.powerAction('node123', 'reset')

// Check connection status
if (client.isConnected()) {
  console.log('Client is ready for operations')
}

// Clean up
client.close()
```
