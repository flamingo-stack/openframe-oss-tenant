MeshCentral control WebSocket client for managing device connections, tunneling, and power actions through the MeshCentral server API.

## Key Components

- **MeshControlClient** - Main class handling WebSocket connection to MeshCentral control endpoint
- **ControlAuthCookies** - Type definition for authentication and relay cookies
- **WebSocket Management** - Connection lifecycle, message handling, and reconnection logic
- **Tunnel Management** - Desktop and file tunneling with relay protocol support
- **Power Actions** - Remote device power control (wake, sleep, reset, poweroff)
- **Authentication** - Cookie-based auth with automatic token refresh

## Usage Example

```typescript
import { MeshControlClient } from './meshcentral-control'

// Initialize with credentials or auth cookie
const client = new MeshControlClient(
  { user: 'admin', pass: 'password' },
  'optional-auth-cookie'
)

// Open connection and authenticate
await client.openSession()

// Get authentication cookies
const cookies = await client.getAuthCookies()

// Create desktop tunnel to device
client.sendDesktopTunnel(
  'node123', 
  'relay456', 
  cookies.relayCookie
)

// Execute power actions
await client.powerAction('node123', 'wake')
await client.powerAction('node123', 'reset')

// Clean up
client.close()
```

The client automatically handles reconnection, maintains active tunnels across reconnects, and manages pending requests with timeout handling. It integrates with the broader MeshCentral infrastructure for remote device management.
