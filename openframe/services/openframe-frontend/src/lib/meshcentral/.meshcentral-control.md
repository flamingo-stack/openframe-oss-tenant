Manages a persistent WebSocket control connection to a MeshCentral server, handling authentication, tunnel creation, power actions, and clipboard operations for remote node management.

## Key Components

**`MeshControlClient`** — Main class that wraps `WebSocketManager` to interface with MeshCentral's `/control.ashx` endpoint.

| Member | Description |
|--------|-------------|
| `constructor(credentials?, authCookie?)` | Initializes the WebSocket with credentials or cookie auth; supports dev token injection |
| `openSession()` | Connects the WebSocket and waits for auth cookies to be established |
| `getAuthCookies(timeoutMs?)` | Returns cached auth/relay cookies or waits for them with a configurable timeout |
| `sendRelayTunnel(...)` | Sends a relay tunnel message with protocol, relay ID, and optional domain prefix |
| `sendDesktopTunnel(...)` | Shorthand for protocol `2` (desktop relay) |
| `sendFileTunnel(...)` | Shorthand for protocol `5` (file relay) |
| `powerAction(nodeId, action, timeoutMs?)` | Sends wake/sleep/reset/poweroff commands to a remote node |
| `setClipboard(nodeId, data)` | Pushes clipboard data to a remote node |
| `getClipboard(nodeId)` | Retrieves clipboard content from a remote node |
| `close()` | Disconnects and clears all state |
| `reconnect()` | Reconnects the WebSocket and re-establishes auth |

**Internal mechanics:**
- `pendingRequests` — Promise map keyed by `responseid` for async request/response correlation
- `activeTunnels` — Tracked tunnel list that is automatically replayed on reconnect via `resendActiveTunnels()`

## Usage Example

```typescript
const client = new MeshControlClient(
  { user: 'admin', pass: 'secret' }
);

// Open session and authenticate
await client.openSession();

// Send a desktop tunnel for remote control
client.sendDesktopTunnel(
  'node//abc123',
  'relay-uuid-001',
  undefined,
  'domain-prefix'
);

// Trigger a remote power action
await client.powerAction('node//abc123', 'reset');

// Clipboard operations
await client.setClipboard('node//abc123', 'Hello from OpenFrame!');
const text = await client.getClipboard('node//abc123');

// Clean up
client.close();
```
