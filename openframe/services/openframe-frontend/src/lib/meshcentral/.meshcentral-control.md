WebSocket client for controlling MeshCentral devices with authentication, tunneling, and power management capabilities. Provides a high-level interface for establishing secure connections and managing remote desktop, file transfer, and power operations.

## Key Components

**MeshControlClient** - Main client class that manages WebSocket connections to MeshCentral control endpoints

**Core Methods:**
- `openSession()` - Establishes authenticated WebSocket connection
- `getAuthCookies()` - Retrieves authentication cookies for secure operations
- `sendDesktopTunnel()` - Creates remote desktop tunnels
- `sendFileTunnel()` - Creates file transfer tunnels
- `powerAction()` - Executes power operations (wake, sleep, reset, poweroff)
- `reconnect()` - Handles connection recovery

**Authentication Types:**
- `ControlAuthCookies` - Contains auth and relay cookies for session management

## Usage Example

```typescript
// Initialize with credentials
const client = new MeshControlClient(
  { user: 'admin', pass: 'password' }
);

// Establish connection and authenticate
await client.openSession();

// Create desktop tunnel for remote access
client.sendDesktopTunnel(
  'node123',
  'relay456',
  undefined,
  'domain1'
);

// Execute power action on device
await client.powerAction('node123', 'wake', 10000);

// Create file transfer tunnel
client.sendFileTunnel('node123', 'relay789');

// Clean up connection
client.close();
```

The client automatically handles WebSocket reconnection, maintains active tunnel state, and manages authentication cookies for seamless MeshCentral integration.
