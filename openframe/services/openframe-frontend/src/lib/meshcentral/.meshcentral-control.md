WebSocket-based control client for MeshCentral's `control.ashx` endpoint, managing authentication cookies, tunnel establishment, power actions, and clipboard operations over a persistent connection.

## Key Components

### `MeshControlClient`
Main class that wraps a `WebSocketManager` to communicate with MeshCentral's control channel.

| Method | Description |
|--------|-------------|
| `openSession()` | Connects the WebSocket and waits for auth cookies |
| `getAuthCookies(timeoutMs?)` | Returns cached or newly fetched `authCookie`/`relayCookie` |
| `sendRelayTunnel(...)` | Sends a relay tunnel request with protocol, node, and relay IDs |
| `sendDesktopTunnel(...)` | Shorthand for protocol `2` (desktop/RDP relay) |
| `sendFileTunnel(...)` | Shorthand for protocol `5` (file transfer relay) |
| `powerAction(nodeId, action)` | Sends wake/sleep/reset/poweroff commands to a node |
| `setClipboard(nodeId, data)` | Pushes clipboard text to a remote node |
| `getClipboard(nodeId)` | Retrieves clipboard text from a remote node |
| `reconnect()` | Re-establishes the WebSocket and re-registers active tunnels |
| `close()` | Tears down the connection and clears all pending state |

**Internal mechanisms:**
- `pendingRequests` map — correlates responses by `responseid` with timeout/resolve/reject
- `activeTunnels` list — persists tunnel state for automatic re-registration after reconnect
- Heartbeat via `ping`/`pong` messages every 29 seconds

## Usage Example

```typescript
import { MeshControlClient } from './meshcentral-control';

const client = new MeshControlClient(
  { user: 'admin', pass: 'secret' },
);

// Open session and get auth cookies
await client.openSession();

// Establish a desktop relay tunnel
client.sendDesktopTunnel(
  'node//abc123',
  'relay-id-xyz',
  undefined,       // relayCookie (auto-resolved from session)
  '',              // domainPrefix
);

// Power actions
await client.powerAction('abc123', 'reset');

// Clipboard operations
await client.setClipboard('abc123', 'Hello from OpenFrame');
const text = await client.getClipboard('abc123');

// Cleanup
client.close();
```

> **Note:** Active tunnels are automatically re-registered on reconnect via `resendActiveTunnels()`, making the client resilient to transient WebSocket drops.
