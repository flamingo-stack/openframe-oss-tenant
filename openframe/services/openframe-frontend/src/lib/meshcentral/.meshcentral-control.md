Client for establishing WebSocket control connections to MeshCentral servers, handling authentication, tunnel management, and remote power actions on managed devices.

## Key Components

### `MeshControlClient`
The main client class that manages WebSocket connections to MeshCentral control endpoints with the following capabilities:

- **Authentication Management**: Handles credential-based auth and auth cookie retrieval
- **Tunnel Management**: Creates and manages relay tunnels for desktop and file access
- **Power Control**: Sends power actions (wake, sleep, reset, poweroff) to remote devices
- **Connection State**: Manages WebSocket connection lifecycle with automatic reconnection
- **Request Tracking**: Handles asynchronous request/response patterns with timeouts

### Key Methods
- `openSession()` - Establishes connection and authenticates
- `getAuthCookies()` - Retrieves authentication cookies for relay sessions
- `sendDesktopTunnel()` - Creates desktop remote access tunnel
- `sendFileTunnel()` - Creates file transfer tunnel
- `powerAction()` - Executes power commands on target devices

### Types
- `ControlAuthCookies` - Authentication cookie structure for MeshCentral sessions

## Usage Example

```typescript
import { MeshControlClient } from './meshcentral-control'

// Initialize with credentials
const client = new MeshControlClient({
  user: 'admin',
  pass: 'password'
})

// Open connection and authenticate
await client.openSession()

// Create desktop tunnel for remote access
client.sendDesktopTunnel(
  'node123',      // MeshCentral node ID
  'relay456',     // Relay session ID
  undefined,      // Use default relay cookie
  'domain1'       // Domain prefix
)

// Execute power action
await client.powerAction('node123', 'reset')

// Clean up
client.close()
```
