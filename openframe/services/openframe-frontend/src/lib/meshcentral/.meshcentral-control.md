WebSocket client for controlling MeshCentral server operations including authentication, tunneling, and remote power management.

## Key Components

**MeshControlClient** - Main class managing WebSocket connection to MeshCentral control endpoint
- **Authentication Management** - Handles auth cookies and credential passing
- **Tunnel Management** - Creates and manages relay tunnels for desktop/file access
- **Power Control** - Remote power actions (wake, sleep, reset, poweroff)
- **Connection Management** - WebSocket lifecycle with auto-reconnection

**Key Methods:**
- `openSession()` - Establishes authenticated WebSocket connection
- `sendDesktopTunnel()` / `sendFileTunnel()` - Creates remote access tunnels
- `powerAction()` - Executes power commands on remote nodes
- `getAuthCookies()` - Retrieves authentication cookies for relay operations

## Usage Example

```typescript
import { MeshControlClient } from './meshcentral-control'

// Initialize with credentials
const client = new MeshControlClient(
  { user: 'admin', pass: 'password' }
)

// Establish connection and get auth cookies
await client.openSession()
const cookies = await client.getAuthCookies()

// Create desktop tunnel for remote access
client.sendDesktopTunnel(
  'node123', 
  'relay456', 
  cookies.relayCookie
)

// Execute power action
await client.powerAction('node123', 'reset')

// Cleanup
client.close()
```

The client handles authentication token injection for OpenFrame integration and maintains tunnel state for reconnection scenarios. All operations are promise-based with configurable timeouts.
