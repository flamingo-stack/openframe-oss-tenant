Entry point for the MeshCentral integration library, re-exporting all modules for file management, WebSocket communication, and protocol handling, plus a utility for checking file access permissions.

## Key Components

**Re-exports**
- `FileBinaryProtocol` — Binary protocol parser for MeshCentral file transfers
- `FileDownloader` / `DownloadTask` — Handles file download operations
- `FileErrorHandler` / `FileError` / `FileErrorType` — Centralized file error management
- `MeshCentralFileManager` — Primary file manager class with full type set (`FileEntry`, `DirectoryListing`, `FileTransferProgress`, etc.)
- `FileOperations` — Low-level file operation primitives
- `FileUploader` / `UploadTask` — Handles file upload operations
- `MeshControlClient` — Control-plane client for MeshCentral
- `WebSocketManager` / `WebSocketManagerOptions` / `WebSocketState` — WebSocket lifecycle management
- `buildWsUrl`, `MESH_USER`, `MESH_PASS` — Configuration helpers

**Exported Function**
- `canAccessFiles(userRights)` — Evaluates bitmask-based permissions to determine if a user has file access rights

## Usage Example

```typescript
import {
  MeshCentralFileManager,
  MeshControlClient,
  canAccessFiles,
  buildWsUrl,
} from './index';

// Check permissions before initializing file manager
const userRights = { mesh: 0x00000020, site: 0x00000008 };

if (canAccessFiles(userRights)) {
  const wsUrl = buildWsUrl('meshcentral.example.com', 'node123');

  const manager = new MeshCentralFileManager({
    url: wsUrl,
    username: 'admin',
    password: 's3cr3t',
  });

  await manager.connect();
  const listing = await manager.listDirectory('/');
  console.log(listing.entries);
}
```
