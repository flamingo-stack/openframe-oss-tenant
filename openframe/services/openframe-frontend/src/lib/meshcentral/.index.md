Entry point for the MeshCentral integration library, re-exporting all modules for file management, WebSocket communication, and protocol handling, plus a utility for checking file access permissions.

## Key Components

**Re-exported Modules**
- `FileBinaryProtocol` — Binary protocol encoding/decoding for file transfers
- `FileDownloader` / `DownloadTask` — Handles file download operations
- `FileErrorHandler` / `FileError` / `FileErrorType` — Centralized error handling for file operations
- `MeshCentralFileManager` — Primary file manager class with full type exports (`FileEntry`, `DirectoryListing`, `FileTransferProgress`, etc.)
- `FileOperations` — Low-level file operation primitives
- `FileUploader` / `UploadTask` — Handles file upload operations
- `MeshControlClient` — MeshCentral control plane client
- `WebSocketManager` / `WebSocketManagerOptions` / `WebSocketState` — WebSocket lifecycle management
- `buildWsUrl`, `MESH_USER`, `MESH_PASS` — Configuration utilities and credentials

**Exported Function**
- `canAccessFiles(userRights)` — Checks whether a user has sufficient rights to access files by evaluating `SERVERFILES`, `NOFILES`, and `FILEACCESS` bitmask flags

## Usage Example

```typescript
import {
  MeshCentralFileManager,
  MeshControlClient,
  canAccessFiles,
  buildWsUrl,
  MESH_USER,
  MESH_PASS,
} from './index';

// Check permissions before initializing file manager
const userRights = { mesh: 0x00000020, site: 0x00000008 };

if (canAccessFiles(userRights)) {
  const wsUrl = buildWsUrl('meshcentral.example.com');

  const client = new MeshControlClient({
    url: wsUrl,
    username: MESH_USER,
    password: MESH_PASS,
  });

  const fileManager = new MeshCentralFileManager(client);
  await fileManager.listDirectory('/');
}
```
