Main entry point for the MeshCentral integration library, exporting all file management, transfer, and WebSocket connectivity functionality, plus a utility for checking file access permissions.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `MeshCentralFileManager` | Class | Core file manager for MeshCentral operations |
| `MeshControlClient` | Class | Client for MeshCentral control-plane interactions |
| `WebSocketManager` | Class | Manages WebSocket connections to MeshCentral |
| `FileBinaryProtocol` | Class | Handles binary protocol encoding/decoding |
| `FileDownloader` | Class | Manages file download tasks |
| `FileUploader` | Class | Manages file upload tasks |
| `FileOperations` | Class | High-level file operation helpers |
| `FileErrorHandler` | Class | Centralized error handling for file operations |
| `canAccessFiles` | Function | Checks mesh/site permission bits for file access |
| `buildWsUrl`, `MESH_USER`, `MESH_PASS` | Config | WebSocket URL builder and credentials |

## Usage Example

```typescript
import {
  MeshCentralFileManager,
  WebSocketManager,
  canAccessFiles,
  buildWsUrl,
} from './index';

// Check permissions before initializing
const userRights = { mesh: 0x00000020, site: 0x00000008 };

if (canAccessFiles(userRights)) {
  const wsUrl = buildWsUrl('https://meshcentral.example.com');

  const wsManager = new WebSocketManager({ url: wsUrl });
  const fileManager = new MeshCentralFileManager(wsManager);

  // List files on a remote node
  await fileManager.listDirectory('/home/user');
}
```

## Permission Flags

```text
MeshRights.SERVERFILES = 0x00000020  // Can access server files
MeshRights.NOFILES     = 0x00000400  // Blocked from file access
SiteRights.FILEACCESS  = 0x00000008  // Site-level file permission
```

`canAccessFiles` returns `true` only when all three conditions are satisfied: `SERVERFILES` is set, `NOFILES` is not set, and `FILEACCESS` is granted.
