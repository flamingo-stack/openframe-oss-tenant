Handles error classification, message formatting, and history tracking for the MeshCentral File Manager. Maps raw error strings to typed `FileError` objects and supports pluggable per-type handlers.

## Key Components

- **`FileErrorType`** — Union type of 15 recognized error categories (e.g. `autherror`, `diskfull`, `uploadfailed`)
- **`FileError`** — Interface describing a normalized error with `type`, `message`, `details`, `timestamp`, and `retryable` flag
- **`FileErrorHandler`** — Main class providing error parsing, routing, and history management

### Key Methods

| Method | Description |
|--------|-------------|
| `parseError(message)` | Parses a raw MeshCentral message into a `FileError` |
| `createError(str, details?)` | Constructs a `FileError` from a plain error string |
| `handleError(error)` | Dispatches to registered handlers and global `onError` callback |
| `registerHandler(type, fn)` | Registers a custom handler for a specific error type |
| `isRetryable(type)` | Returns `true` for transient errors worth retrying |
| `getErrorHistory()` | Returns a copy of up to 100 recent errors |
| `getErrorCounts()` | Returns a frequency map of error types from history |

## Usage Example

```typescript
import { FileErrorHandler } from './file-error-handler';

const handler = new FileErrorHandler((error) => {
  if (error.retryable) {
    console.warn('Retryable error:', error.message);
    scheduleRetry();
  } else {
    showUserAlert(error.message);
  }
});

// Override default handler for a specific type
handler.registerHandler('diskfull', (error) => {
  notifyAdmin('Disk space critical on remote device');
});

// Parse a raw MeshCentral protocol message
const error = handler.parseError({ error: 'permission denied', details: '/etc/shadow' });
// → { type: 'permissiondenied', message: 'Permission denied...', retryable: false }

handler.handleError(error!);

// Inspect history
const counts = handler.getErrorCounts();
// Map { 'permissiondenied' => 1 }
```
