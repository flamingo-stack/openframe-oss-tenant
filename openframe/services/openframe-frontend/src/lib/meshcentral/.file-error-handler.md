Centralized error handling utility for the MeshCentral File Manager, providing typed error classification, message normalization, retry logic, and error history tracking.

## Key Components

- **`FileErrorType`** — Union type covering 15 distinct file operation error categories (auth, session, connection, permissions, disk, transfer, etc.)
- **`FileError`** — Interface describing a structured error with type, message, optional details, timestamp, and retryability flag
- **`FileErrorHandler`** — Main class orchestrating error parsing, dispatching, and history management

### Key Methods

| Method | Description |
|---|---|
| `parseError(message)` | Parses raw MeshCentral protocol messages into typed `FileError` objects |
| `handleError(error)` | Dispatches to registered handlers and fires the global `onError` callback |
| `createError(string, details?)` | Constructs a `FileError` from a raw error string |
| `registerHandler(type, fn)` | Registers a custom handler for a specific error type |
| `isRetryable(type)` | Returns `true` for transient errors (connection, timeout, transfer failures) |
| `getErrorCounts()` | Returns a frequency map of error types from history |

## Usage Example

```typescript
const handler = new FileErrorHandler((error) => {
  if (error.retryable) {
    scheduleRetry();
  } else {
    showToast(error.message, 'error');
  }
});

// Override default handler for a specific type
handler.registerHandler('permissiondenied', (error) => {
  redirectToLogin();
});

// Parse a raw protocol message
const error = handler.parseError({ error: 'disk full', details: '/mnt/data' });
if (error) {
  handler.handleError(error);
}

// Inspect history
const counts = handler.getErrorCounts();
console.log('Connection errors:', counts.get('connectionerror') ?? 0);
```
