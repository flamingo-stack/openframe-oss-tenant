Centralized error handling utility for MeshCentral File Manager operations, providing error classification, message mapping, history tracking, and retry logic for 15 distinct file operation error types.

## Key Components

**`FileErrorType`** — Union type enumerating all recognized error categories (auth, session, connection, permission, disk, transfer, and path errors).

**`FileError`** — Interface representing a structured error with type, message, optional details, timestamp, and retryability flag.

**`FileErrorHandler`** — Main class providing:
- `registerHandler(errorType, handler)` — Register custom callbacks per error type
- `handleError(error)` — Dispatch a `FileError` to its handler and append to history
- `parseError(message)` — Parse raw MeshCentral protocol messages into structured `FileError` objects
- `createError(errorString, details?)` — Construct a `FileError` from a raw error string
- `getErrorMessage(errorType, originalError?)` — Retrieve a user-friendly message for a given type
- `isRetryable(errorType)` — Check if an error type supports retry logic
- `getErrorHistory()` / `getLastError()` / `clearHistory()` — Manage error history (capped at 100 entries)
- `getErrorCounts()` — Return a frequency map of error types from history

## Usage Example

```typescript
import { FileErrorHandler } from './file-error-handler';

const handler = new FileErrorHandler((error) => {
  console.warn(`[${error.type}] ${error.message}`, error.details);
});

// Override default handler for connection errors
handler.registerHandler('connectionerror', (error) => {
  triggerReconnect();
});

// Parse a raw protocol message
const error = handler.parseError({ error: 'permission denied', details: '/etc/shadow' });
if (error?.retryable) {
  retryOperation();
}

// Directly create and dispatch an error
const uploadErr = handler.createError('upload failed', 'largefile.zip');
handler.handleError(uploadErr);

// Audit error frequency
const counts = handler.getErrorCounts();
counts.forEach((count, type) => console.log(`${type}: ${count}`));
```
