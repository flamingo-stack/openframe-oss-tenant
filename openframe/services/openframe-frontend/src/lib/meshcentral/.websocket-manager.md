A robust WebSocket management class that provides automatic reconnection, token refresh, and message queueing for real-time communication in the Flamingo/OpenFrame platform.

## Key Components

- **WebSocketManager**: Main class handling WebSocket lifecycle with intelligent reconnection
- **WebSocketState**: Type union for connection states (`'disconnected' | 'connecting' | 'connected' | 'reconnecting' | 'failed'`)
- **WebSocketManagerOptions**: Configuration interface with callbacks, reconnection settings, and authentication options
- **Token Management**: Automatic token refresh before reconnection attempts
- **Message Queue**: Buffers messages when disconnected and flushes on reconnection
- **Browser Integration**: Handles visibility changes and network status events

## Usage Example

```typescript
import { WebSocketManager } from './websocket-manager'

// Create WebSocket manager with authentication
const wsManager = new WebSocketManager({
  url: () => `wss://api.flamingo.run/ws?token=${getAuthToken()}`,
  maxReconnectAttempts: 5,
  reconnectBackoff: [1000, 2000, 4000, 8000],
  refreshTokenBeforeReconnect: true,
  onStateChange: (state) => console.log('WebSocket state:', state),
  onMessage: (event) => handleMessage(JSON.parse(event.data)),
  onError: (event) => console.error('WebSocket error:', event)
})

// Connect and send messages
await wsManager.connect()
wsManager.send(JSON.stringify({ type: 'ping', data: 'hello' }))

// Cleanup when done
wsManager.dispose()
```

The manager automatically handles authentication failures, network interruptions, and browser tab visibility changes to maintain reliable real-time connections.
