A comprehensive WebSocket client manager that provides automatic reconnection, token refresh, and message queuing capabilities for Flamingo's real-time communication needs.

## Key Components

### Types & Interfaces
- **`WebSocketState`** - Connection state enum: `'disconnected' | 'connecting' | 'connected' | 'reconnecting' | 'failed'`
- **`WebSocketManagerOptions`** - Configuration interface for connection behavior, callbacks, and reconnection strategy

### Main Class
- **`WebSocketManager`** - Core class managing WebSocket lifecycle with intelligent reconnection logic
- **Connection Management** - Handles connect/disconnect/reconnect with exponential backoff
- **Token Refresh** - Automatic authentication token validation before reconnection attempts
- **Message Queuing** - Buffers messages when disconnected and flushes on reconnection
- **Browser Integration** - Responds to visibility changes and network status events

## Usage Example

```typescript
import { WebSocketManager } from './websocket-manager'

// Basic connection
const wsManager = new WebSocketManager({
  url: 'wss://api.flamingo.run/ws',
  onMessage: (event) => {
    console.log('Received:', event.data)
  },
  onStateChange: (state) => {
    console.log('Connection state:', state)
  }
})

// Connect and send messages
await wsManager.connect()
wsManager.send(JSON.stringify({ type: 'ping' }))

// Advanced configuration with custom reconnection
const advancedWs = new WebSocketManager({
  url: () => `wss://api.flamingo.run/ws?token=${getAuthToken()}`,
  maxReconnectAttempts: 15,
  reconnectBackoff: [1000, 2000, 5000, 10000],
  refreshTokenBeforeReconnect: true,
  shouldReconnect: (closeEvent) => closeEvent.code !== 1000,
  enableMessageQueue: true
})

// Cleanup when done
wsManager.dispose()
```

The manager automatically handles authentication failures, network interruptions, and browser tab visibility changes to maintain reliable real-time connections.
