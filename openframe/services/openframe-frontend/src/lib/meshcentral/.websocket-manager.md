A robust WebSocket connection manager that handles automatic reconnection, token refresh, message queuing, and browser state management for reliable real-time communication.

## Key Components

**Types & Interfaces:**
- `WebSocketState` - Connection states: disconnected, connecting, connected, reconnecting, failed
- `WebSocketManagerOptions` - Configuration interface with callbacks, reconnection settings, and behavior options

**Main Class:**
- `WebSocketManager` - Core manager with intelligent reconnection logic, exponential backoff, and message queuing

**Key Methods:**
- `connect()` - Establish WebSocket connection with automatic token refresh
- `send()` - Send messages with automatic queuing when disconnected
- `reconnect()` - Manual reconnection with state reset
- `disconnect()/dispose()` - Clean shutdown and resource cleanup

## Usage Example

```typescript
import { WebSocketManager } from './websocket-manager'

const wsManager = new WebSocketManager({
  url: () => `wss://api.example.com/ws?token=${getAuthToken()}`,
  maxReconnectAttempts: 5,
  reconnectBackoff: [1000, 2000, 4000, 8000, 16000],
  onStateChange: (state) => console.log('WebSocket state:', state),
  onMessage: (event) => handleMessage(JSON.parse(event.data)),
  onError: (error) => console.error('WebSocket error:', error),
  refreshTokenBeforeReconnect: true,
  enableMessageQueue: true
})

// Connect and send messages
await wsManager.connect()
wsManager.send(JSON.stringify({ type: 'ping', timestamp: Date.now() }))

// Check connection state
if (wsManager.isConnected()) {
  console.log('Ready to send real-time data')
}

// Clean shutdown
wsManager.dispose()
```

The manager automatically handles auth failures, network changes, tab visibility, and provides exponential backoff with jitter for reconnection attempts.
