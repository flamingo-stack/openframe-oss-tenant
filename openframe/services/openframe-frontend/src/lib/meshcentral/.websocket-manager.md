A robust WebSocket client with automatic reconnection, authentication token refresh, and message queuing for reliable real-time communication in web applications.

## Key Components

### Types & Interfaces
- **`WebSocketState`** - Connection state enum: `'disconnected' | 'connecting' | 'connected' | 'reconnecting' | 'failed'`
- **`WebSocketManagerOptions`** - Configuration interface with connection URL, retry settings, event handlers, and feature flags

### Main Class
- **`WebSocketManager`** - Primary class managing WebSocket lifecycle with intelligent reconnection logic
- **Connection Management** - Handles connect/disconnect with exponential backoff and jitter
- **Token Refresh** - Automatically refreshes authentication tokens before reconnection attempts
- **Message Queuing** - Buffers messages when disconnected and flushes on reconnection
- **Browser Integration** - Responds to online/offline events and tab visibility changes

## Usage Example

```typescript
import { WebSocketManager } from './websocket-manager'

const wsManager = new WebSocketManager({
  url: () => `wss://api.example.com/ws?token=${getAuthToken()}`,
  maxReconnectAttempts: 10,
  reconnectBackoff: [1000, 2000, 4000, 8000],
  onStateChange: (state) => console.log(`WebSocket state: ${state}`),
  onMessage: (event) => handleIncomingMessage(JSON.parse(event.data)),
  onError: (error) => console.error('WebSocket error:', error),
  shouldReconnect: (closeEvent) => closeEvent.code !== 1000,
  refreshTokenBeforeReconnect: true,
  enableMessageQueue: true
})

// Connect and start listening
await wsManager.connect()

// Send messages (queued if disconnected)
wsManager.send(JSON.stringify({ type: 'ping', data: 'hello' }))

// Check connection status
if (wsManager.isConnected()) {
  console.log('Ready to send real-time data')
}

// Clean up when done
wsManager.dispose()
```

The manager automatically handles network interruptions, authentication failures, and browser state changes to maintain persistent connections.
