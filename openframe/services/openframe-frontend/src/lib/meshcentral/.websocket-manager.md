A robust WebSocket manager that handles connections, reconnection with exponential backoff, token refresh, and message queuing. Provides comprehensive state management and browser event handling for reliable real-time communication.

## Key Components

**WebSocketState** - Type union defining connection states: `'disconnected' | 'connecting' | 'connected' | 'reconnecting' | 'failed'`

**WebSocketManagerOptions** - Configuration interface with customizable callbacks, reconnection settings, and connection parameters

**WebSocketManager** - Main class providing:
- `connect()` - Establishes WebSocket connection with token refresh
- `send()` - Sends messages with automatic queuing when disconnected
- `reconnect()` - Forces reconnection with reset attempt counter
- `disconnect()` - Gracefully closes connection and stops reconnection
- `getState()` - Returns current connection state
- `isConnected()` - Boolean check for active connection
- `dispose()` - Cleanup method for proper resource management

## Usage Example

```typescript
import { WebSocketManager } from './websocket-manager'

const wsManager = new WebSocketManager({
  url: () => `wss://api.example.com/ws?token=${getAuthToken()}`,
  maxReconnectAttempts: 10,
  onStateChange: (state) => console.log('WebSocket state:', state),
  onMessage: (event) => handleMessage(JSON.parse(event.data)),
  onError: (error) => console.error('WebSocket error:', error),
  shouldReconnect: (closeEvent) => closeEvent.code !== 1000,
  refreshTokenBeforeReconnect: true,
  enableMessageQueue: true
})

// Connect and start receiving messages
await wsManager.connect()

// Send message (queued if not connected)
wsManager.send(JSON.stringify({ type: 'ping' }))

// Clean up when done
wsManager.dispose()
```

The manager automatically handles browser events (online/offline, visibility changes), implements exponential backoff for reconnections, and maintains a message queue to prevent data loss during connection interruptions.
