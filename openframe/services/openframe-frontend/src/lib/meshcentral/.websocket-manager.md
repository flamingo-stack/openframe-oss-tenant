A robust WebSocket client manager that provides automatic reconnection, token refresh, message queuing, and intelligent connection state management for real-time applications. Handles network failures, authentication issues, and browser visibility changes gracefully.

## Key Components

### Types & Interfaces
- **`WebSocketState`** - Connection states: `disconnected`, `connecting`, `connected`, `reconnecting`, `failed`
- **`WebSocketManagerOptions`** - Configuration interface with connection URL, reconnection settings, event handlers, and feature toggles

### Main Class
- **`WebSocketManager`** - Primary class managing WebSocket connections with auto-reconnection, message queuing, and browser event handling
- **Connection Management** - `connect()`, `reconnect()`, `disconnect()`, and `dispose()` methods
- **Message Handling** - `send()` method with automatic queuing when disconnected
- **State Monitoring** - `getState()`, `isConnected()`, and `getReadyState()` for connection status

### Key Features
- **Automatic Reconnection** - Exponential backoff with jitter and configurable max attempts
- **Token Refresh** - Automatic authentication token refresh before reconnecting
- **Message Queuing** - Buffers messages when disconnected and flushes on reconnection
- **Browser Integration** - Responds to online/offline events and tab visibility changes

## Usage Example

```typescript
import { WebSocketManager } from './websocket-manager'

// Create WebSocket manager
const wsManager = new WebSocketManager({
  url: () => `wss://api.example.com/ws?token=${getAuthToken()}`,
  maxReconnectAttempts: 5,
  reconnectBackoff: [1000, 2000, 4000, 8000],
  onStateChange: (state) => console.log('WebSocket state:', state),
  onMessage: (event) => handleMessage(JSON.parse(event.data)),
  onError: (error) => console.error('WebSocket error:', error),
  refreshTokenBeforeReconnect: true,
  enableMessageQueue: true
})

// Connect and send messages
await wsManager.connect()
wsManager.send(JSON.stringify({ type: 'ping' }))

// Check connection status
if (wsManager.isConnected()) {
  console.log('Ready to send messages')
}

// Clean up when done
wsManager.dispose()
```
