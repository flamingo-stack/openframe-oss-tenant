A robust WebSocket client manager that provides automatic reconnection, authentication token refresh, message queuing, and browser-aware connection handling for real-time communication needs.

## Key Components

- **WebSocketManager Class**: Main class providing managed WebSocket connections with automatic reconnection logic
- **WebSocketState Type**: Union type defining connection states ('disconnected' | 'connecting' | 'connected' | 'reconnecting' | 'failed')
- **WebSocketManagerOptions Interface**: Configuration interface supporting custom URLs, reconnection strategies, event handlers, and authentication
- **Authentication Integration**: Automatic token refresh via API client before reconnection attempts
- **Message Queuing**: Optional message buffering when connection is unavailable
- **Browser Event Handling**: Responds to online/offline and visibility change events for optimal connection management

## Usage Example

```typescript
import { WebSocketManager } from './websocket-manager'

// Create WebSocket manager with custom options
const wsManager = new WebSocketManager({
  url: () => `wss://api.example.com/ws?token=${getAuthToken()}`,
  maxReconnectAttempts: 5,
  reconnectBackoff: [1000, 2000, 5000, 10000],
  onStateChange: (state) => console.log('WebSocket state:', state),
  onMessage: (event) => {
    const data = JSON.parse(event.data)
    console.log('Received:', data)
  },
  onError: (event) => console.error('WebSocket error:', event),
  enableMessageQueue: true,
  refreshTokenBeforeReconnect: true
})

// Connect and send messages
await wsManager.connect()

// Send data (queued if not connected)
wsManager.send(JSON.stringify({ type: 'ping', timestamp: Date.now() }))

// Check connection status
if (wsManager.isConnected()) {
  console.log('WebSocket is ready')
}

// Clean up when done
wsManager.dispose()
```

The manager handles authentication failures, network interruptions, and browser lifecycle events automatically, making it ideal for production applications requiring reliable real-time connectivity.
