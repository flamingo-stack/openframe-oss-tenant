A robust WebSocket connection manager that provides automatic reconnection, message queuing, and intelligent connection handling with authentication token refresh capabilities.

## Key Components

**Types & Interfaces:**
- `WebSocketState` - Connection state enum ('disconnected' | 'connecting' | 'connected' | 'reconnecting' | 'failed')
- `WebSocketManagerOptions` - Configuration interface with callbacks, reconnection settings, and advanced options

**Main Class:**
- `WebSocketManager` - Primary class managing WebSocket lifecycle, reconnection logic, and message handling

**Core Features:**
- Automatic reconnection with exponential backoff and jitter
- Message queuing when disconnected
- Token refresh before reconnection attempts
- Browser visibility and network status awareness
- Configurable reconnection strategies and auth failure handling

## Usage Example

```typescript
import { WebSocketManager } from './websocket-manager'

// Basic usage
const wsManager = new WebSocketManager({
  url: () => `wss://api.example.com/ws?token=${getAuthToken()}`,
  maxReconnectAttempts: 5,
  onMessage: (event) => {
    console.log('Received:', event.data)
  },
  onStateChange: (state) => {
    console.log('Connection state:', state)
  }
})

// Connect and send messages
await wsManager.connect()
wsManager.send(JSON.stringify({ type: 'ping', data: 'hello' }))

// Advanced configuration with custom reconnection logic
const advancedWsManager = new WebSocketManager({
  url: 'wss://api.example.com/ws',
  reconnectBackoff: [1000, 3000, 10000],
  shouldReconnect: (closeEvent) => closeEvent.code !== 4000,
  refreshTokenBeforeReconnect: true,
  enableMessageQueue: true
})
```
