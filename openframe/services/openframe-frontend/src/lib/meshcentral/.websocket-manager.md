Manages a WebSocket connection lifecycle with automatic reconnection, token refresh integration, message queuing, heartbeat monitoring, and browser visibility/online-status awareness.

## Key Components

**`WebSocketState`** — Union type representing connection states: `'disconnected' | 'connecting' | 'connected' | 'reconnecting' | 'failed'`

**`WebSocketManagerOptions`** — Configuration interface supporting:
- `url` — Static string or dynamic factory function
- `maxReconnectAttempts` / `reconnectBackoff` — Retry limits and exponential backoff delays (±25% jitter)
- `refreshTokenBeforeReconnect` — Integrates with `token-refresh-manager` before each reconnect
- `onBeforeReconnect` — Async hook executed before each reconnect attempt
- `heartbeatInterval` / `heartbeatMessage` / `heartbeatTimeout` — Keep-alive ping configuration
- `enableMessageQueue` — Buffers outbound messages while disconnected
- `shouldReconnect` — Predicate to gate automatic reconnection

**`WebSocketManager`** — Main class with public methods:
- `connect()` — Initiates connection (idempotent)
- `send(data)` — Sends immediately or queues if disconnected; triggers reconnect if needed
- `reconnect()` — Resets state and forces a fresh connection
- `disconnect()` — Permanently closes and cleans up the socket

Internally handles browser `visibilitychange`, `online`, and `offline` events to pause/resume reconnection intelligently, and detects auth failures (close codes `1008`/`4401`) to force a token refresh.

## Usage Example

```typescript
const ws = new WebSocketManager({
  url: () => `wss://api.example.com/ws?token=${getToken()}`,
  maxReconnectAttempts: 5,
  reconnectBackoff: [1000, 2000, 4000, 8000, 16000],
  refreshTokenBeforeReconnect: true,
  enableMessageQueue: true,
  heartbeatInterval: 30_000,
  heartbeatMessage: 'ping',
  heartbeatTimeout: 10_000,
  onStateChange: (state) => console.log('WS state:', state),
  onMessage: (event) => console.log('Received:', event.data),
  onBeforeReconnect: async () => {
    await syncSessionState();
  },
  shouldReconnect: (closeEvent) => closeEvent.code !== 1000,
});

ws.connect();
ws.send(JSON.stringify({ type: 'subscribe', channel: 'alerts' }));

// Later
ws.disconnect();
```
