A robust WebSocket manager that handles connection lifecycle, automatic reconnection with exponential backoff, and token refresh for authenticated connections in the Flamingo platform.

## Key Components

- **WebSocketManager**: Main class providing connection management with configurable options
- **WebSocketState**: Type union defining connection states (`'disconnected' | 'connecting' | 'connected' | 'reconnecting' | 'failed'`)
- **WebSocketManagerOptions**: Configuration interface for customizing behavior including reconnection strategy, event handlers, and authentication settings
- **Token Refresh System**: Automatic token validation and refresh before reconnection attempts
- **Message Queue**: Optional queuing system for messages sent while disconnected
- **Browser Integration**: Handles browser visibility changes and online/offline events

## Usage Example

```typescript
import { WebSocketManager } from './websocket-manager'

const wsManager = new WebSocketManager({
  url: () => `wss://api.example.com/ws?token=${getAuthToken()}`,
  maxReconnectAttempts: 5,
  reconnectBackoff: [1000, 2000, 4000, 8000, 16000],
  enableMessageQueue: true,
  onStateChange: (state) => console.log('WebSocket state:', state),
  onMessage: (event) => console.log('Received:', event.data),
  shouldReconnect: (closeEvent) => closeEvent.code !== 1000
})

// Connect and send messages
await wsManager.connect()
wsManager.send(JSON.stringify({ type: 'ping' }))

// Cleanup when done
wsManager.dispose()
```

The manager automatically handles authentication failures, network connectivity changes, and browser tab visibility to maintain reliable real-time connections.
