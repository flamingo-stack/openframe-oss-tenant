A robust WebSocket connection manager that handles automatic reconnection, authentication refresh, message queueing, and browser lifecycle events for reliable real-time communication in web applications.

## Key Components

- **WebSocketManager**: Main class providing connection management with configurable reconnection strategies
- **WebSocketState**: Type union defining connection states (`disconnected`, `connecting`, `connected`, `reconnecting`, `failed`)
- **WebSocketManagerOptions**: Configuration interface for customizing behavior, callbacks, and connection parameters
- **Authentication Integration**: Automatic token refresh before reconnection attempts using the API client
- **Message Queue**: Optional buffering system for messages sent while disconnected
- **Browser Event Handling**: Automatic reconnection on visibility change and network status events

## Usage Example

```typescript
import { WebSocketManager } from './websocket-manager'

const wsManager = new WebSocketManager({
  url: () => `wss://api.example.com/ws?token=${getAuthToken()}`,
  maxReconnectAttempts: 5,
  reconnectBackoff: [1000, 2000, 5000],
  enableMessageQueue: true,
  onStateChange: (state) => {
    console.log(`WebSocket state: ${state}`)
  },
  onMessage: (event) => {
    const data = JSON.parse(event.data)
    handleIncomingMessage(data)
  },
  shouldReconnect: (closeEvent) => {
    // Custom reconnection logic
    return closeEvent.code !== 1000
  }
})

// Connect and send messages
await wsManager.connect()
wsManager.send(JSON.stringify({ type: 'ping' }))

// Clean up when done
wsManager.dispose()
```

The manager automatically handles connection failures, implements exponential backoff with jitter for reconnections, refreshes authentication tokens when needed, and queues messages during disconnections for reliable message delivery.
