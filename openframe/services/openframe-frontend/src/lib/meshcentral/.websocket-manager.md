Manages WebSocket connections with automatic reconnection, token refresh integration, message queuing, heartbeat monitoring, and browser lifecycle awareness.

## Key Components

**`WebSocketState`** — Union type representing connection lifecycle: `'disconnected' | 'connecting' | 'connected' | 'reconnecting' | 'failed'`

**`WebSocketManagerOptions`** — Configuration interface supporting:
- `url` — Static string or dynamic factory function
- `maxReconnectAttempts` / `reconnectBackoff` — Reconnection limits and exponential backoff delays (±25% jitter)
- `refreshTokenBeforeReconnect` — Integrates with `token-refresh-manager` before each reconnect
- `enableMessageQueue` — Buffers outbound messages while disconnected, flushed on reconnect
- `heartbeatInterval` / `heartbeatMessage` / `heartbeatTimeout` — Configurable ping/pong liveness detection
- `onStateChange`, `onMessage`, `onOpen`, `onClose`, `onError`, `shouldReconnect`, `onBeforeReconnect` — Full lifecycle hooks

**`WebSocketManager`** — Core class exposing:
- `connect()` — Initiates connection, attaches browser event listeners (visibility, online/offline)
- `send(data)` — Sends immediately or queues if disconnected; triggers reconnect if needed
- `reconnect()` — Forces a fresh connection cycle
- `disconnect()` — Cleanly tears down the socket and stops all timers

## Usage Example

```typescript
const ws = new WebSocketManager({
  url: () => `wss://api.example.com/ws?token=${getToken()}`,
  maxReconnectAttempts: 8,
  reconnectBackoff: [1000, 2000, 4000, 8000],
  refreshTokenBeforeReconnect: true,
  enableMessageQueue: true,
  heartbeatInterval: 30_000,
  heartbeatMessage: 'ping',
  heartbeatTimeout: 10_000,
  onStateChange: (state) => console.log('WS state:', state),
  onMessage: (event) => console.log('Received:', event.data),
  shouldReconnect: (closeEvent) => closeEvent.code !== 1000,
  onBeforeReconnect: async () => {
    await syncLocalState();
  },
});

ws.connect();

// Send (auto-queued if not yet connected)
ws.send(JSON.stringify({ type: 'subscribe', channel: 'alerts' }));

// Clean teardown
ws.disconnect();
```
