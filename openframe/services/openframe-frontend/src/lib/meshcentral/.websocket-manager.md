A robust WebSocket connection manager that handles automatic reconnection, authentication refresh, and message queuing with comprehensive error recovery mechanisms.

## Key Components

**WebSocketManager Class**
- `connect()` - Establishes WebSocket connection with token validation
- `send()` - Sends messages with automatic queuing when disconnected
- `reconnect()` - Forces reconnection attempt
- `disconnect()` - Cleanly closes connection and stops reconnection
- `dispose()` - Complete cleanup including browser event listeners

**Configuration Options (WebSocketManagerOptions)**
- Connection URL (static or dynamic function)
- Reconnection strategy with exponential backoff and jitter
- Message queuing and token refresh capabilities
- Comprehensive event callbacks for all connection states

**State Management**
- Five connection states: `disconnected`, `connecting`, `connected`, `reconnecting`, `failed`
- Automatic authentication token refresh before reconnection attempts
- Browser visibility and network status integration for smart reconnection

## Usage Example

```typescript
import { WebSocketManager } from './websocket-manager'

const wsManager = new WebSocketManager({
  url: () => `wss://api.example.com/ws?token=${getAuthToken()}`,
  maxReconnectAttempts: 10,
  reconnectBackoff: [1000, 2000, 4000, 8000, 16000, 30000],
  onStateChange: (state) => console.log('WebSocket state:', state),
  onMessage: (event) => handleMessage(JSON.parse(event.data)),
  onError: (error) => console.error('WebSocket error:', error),
  shouldReconnect: (closeEvent) => closeEvent.code !== 1000,
  refreshTokenBeforeReconnect: true,
  enableMessageQueue: true
})

// Connect and send messages
await wsManager.connect()
wsManager.send(JSON.stringify({ type: 'ping' }))

// Clean up when done
wsManager.dispose()
```

The manager automatically handles network interruptions, tab visibility changes, authentication failures, and provides intelligent reconnection with exponential backoff and jitter to prevent thundering herd problems.
