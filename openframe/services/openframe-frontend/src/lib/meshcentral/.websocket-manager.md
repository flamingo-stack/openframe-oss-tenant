A robust WebSocket client manager that handles connection state, automatic reconnection with exponential backoff, token refresh, and message queuing for reliable real-time communication.

## Key Components

**Types & Interfaces:**
- `WebSocketState` - Connection states: 'disconnected', 'connecting', 'connected', 'reconnecting', 'failed'
- `WebSocketManagerOptions` - Configuration interface with callbacks, reconnection settings, and authentication options

**Main Class:**
- `WebSocketManager` - Core manager with intelligent reconnection, message queuing, and browser event handling
- `connect()` - Establishes WebSocket connection with token refresh
- `send()` - Sends messages with automatic queuing when disconnected
- `reconnect()` - Manual reconnection trigger
- `disconnect()` - Clean disconnection with cleanup

**Key Features:**
- Exponential backoff with jitter for reconnection attempts
- Automatic token refresh before reconnection attempts
- Message queuing when disconnected (optional)
- Browser event listeners for visibility/network changes
- Configurable reconnection logic based on close codes

## Usage Example

```typescript
import { WebSocketManager } from './websocket-manager'

const wsManager = new WebSocketManager({
  url: () => `wss://api.example.com/ws?token=${getAuthToken()}`,
  maxReconnectAttempts: 5,
  reconnectBackoff: [1000, 2000, 5000],
  onStateChange: (state) => console.log('WS State:', state),
  onMessage: (event) => handleMessage(JSON.parse(event.data)),
  refreshTokenBeforeReconnect: true,
  enableMessageQueue: true
})

// Connect and send messages
await wsManager.connect()
wsManager.send(JSON.stringify({ type: 'ping' }))

// Clean up when done
wsManager.dispose()
```
