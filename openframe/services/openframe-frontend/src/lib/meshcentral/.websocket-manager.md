Manages a WebSocket connection lifecycle with automatic reconnection, token refresh integration, message queuing, heartbeat monitoring, and browser network/visibility event handling.

## Key Components

### `WebSocketState`
Union type representing connection states: `'disconnected'` | `'connecting'` | `'connected'` | `'reconnecting'` | `'failed'`

### `WebSocketManagerOptions`
Configuration interface supporting:
- **`url`** — Static string or dynamic factory function
- **`maxReconnectAttempts`** — Default `10`
- **`reconnectBackoff`** — Array of delay ms with ±25% jitter applied
- **`refreshTokenBeforeReconnect`** — Integrates with `token-refresh-manager` before each reconnect attempt
- **`enableMessageQueue`** — Buffers messages sent while disconnected; flushes on reconnect
- **`heartbeatInterval/Message/Timeout`** — Optional keep-alive ping with stale connection detection
- **`shouldReconnect`** — Predicate to conditionally suppress reconnection
- **`onBeforeReconnect`** — Async hook executed before each reconnect attempt

### `WebSocketManager`
Core class encapsulating the full connection lifecycle:

| Method | Description |
|---|---|
| `connect()` | Opens the WebSocket, guards against duplicate connections |
| `send(data)` | Sends immediately or queues if disconnected; triggers reconnect if needed |
| `reconnect()` | Resets state and forces a fresh connection |
| `disconnect()` | Closes cleanly and marks instance as disposed |

**Internal behaviors:**
- Detects auth failures via close codes `1008`/`4401` or reason strings, forcing a token refresh
- Listens to `visibilitychange`, `online`, and `offline` browser events for network-aware reconnection
- Heartbeat timer closes stale connections and triggers reconnect on timeout

## Usage Example

```typescript
const ws = new WebSocketManager({
  url: () => `wss://api.example.com/ws?token=${getToken()}`,
  maxReconnectAttempts: 5,
  reconnectBackoff: [1000, 2000, 4000, 8000],
  refreshTokenBeforeReconnect: true,
  enableMessageQueue: true,
  heartbeatInterval: 30_000,
  heartbeatMessage: 'ping',
  heartbeatTimeout: 10_000,
  onStateChange: (state) => console.log('WS state:', state),
  onMessage: (event) => console.log('Received:', event.data),
  shouldReconnect: (closeEvent) => closeEvent.code !== 1000,
});

ws.connect();
ws.send(JSON.stringify({ type: 'subscribe', channel: 'alerts' }));

// Later
ws.disconnect();
```
