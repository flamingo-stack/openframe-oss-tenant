A robust WebSocket connection manager that handles automatic reconnection, message queuing, and token refresh for real-time communication with intelligent backoff strategies and browser visibility awareness.

## Key Components

**WebSocketManager Class**: Main connection manager with state management, automatic reconnection logic, and message queuing capabilities.

**WebSocketState Type**: Connection state enumeration (`disconnected`, `connecting`, `connected`, `reconnecting`, `failed`).

**WebSocketManagerOptions Interface**: Configuration object supporting custom URLs, reconnection settings, event handlers, and authentication refresh.

**Core Methods**:
- `connect()` - Establishes WebSocket connection with token refresh
- `send()` - Sends messages with automatic queuing when disconnected
- `reconnect()` - Forces immediate reconnection attempt
- `disconnect()` - Gracefully closes connection and stops reconnection

## Usage Example

```typescript
import { WebSocketManager } from './websocket-manager'

const wsManager = new WebSocketManager({
  url: () => `wss://api.example.com/ws?token=${getAuthToken()}`,
  maxReconnectAttempts: 10,
  reconnectBackoff: [1000, 2000, 4000, 8000],
  onStateChange: (state) => {
    console.log('WebSocket state:', state)
  },
  onMessage: (event) => {
    const data = JSON.parse(event.data)
    handleIncomingMessage(data)
  },
  shouldReconnect: (closeEvent) => {
    // Reconnect on auth failures or abnormal closures
    return !closeEvent.wasClean || [1008, 1006, 4401].includes(closeEvent.code)
  },
  refreshTokenBeforeReconnect: true,
  enableMessageQueue: true
})

// Connect and send messages
await wsManager.connect()
wsManager.send(JSON.stringify({ type: 'ping' }))

// Messages sent while disconnected are queued and sent on reconnection
wsManager.send(JSON.stringify({ type: 'important-data', payload: data }))

// Clean up when done
wsManager.dispose()
```

The manager automatically handles browser visibility changes, network status events, and implements exponential backoff with jitter for reconnection attempts. Token refresh occurs before reconnection attempts to handle authentication failures gracefully.
