A robust WebSocket connection manager that provides automatic reconnection, token refresh, and message queuing capabilities for real-time applications. It handles connection states, browser lifecycle events, and authentication failures gracefully.

## Key Components

- **WebSocketState** - Connection state type (`'disconnected' | 'connecting' | 'connected' | 'reconnecting' | 'failed'`)
- **WebSocketManagerOptions** - Configuration interface with reconnection settings, callbacks, and auth options
- **WebSocketManager** - Main class providing connection management with automatic reconnection and token refresh

## Usage Example

```typescript
import { WebSocketManager } from './websocket-manager'

// Create WebSocket manager with auto-reconnection
const wsManager = new WebSocketManager({
  url: () => `wss://api.example.com/ws?token=${getAuthToken()}`,
  maxReconnectAttempts: 10,
  reconnectBackoff: [1000, 2000, 4000, 8000],
  refreshTokenBeforeReconnect: true,
  enableMessageQueue: true,
  onStateChange: (state) => {
    console.log('WebSocket state:', state)
  },
  onMessage: (event) => {
    const data = JSON.parse(event.data)
    handleIncomingMessage(data)
  },
  shouldReconnect: (closeEvent) => {
    // Reconnect on abnormal closures or auth failures
    return !closeEvent.wasClean || [1008, 1006, 4401].includes(closeEvent.code)
  }
})

// Connect and send messages
await wsManager.connect()
wsManager.send(JSON.stringify({ type: 'ping' }))

// The manager automatically handles:
// - Token refresh before reconnection attempts
// - Message queuing when disconnected
// - Browser visibility/network state changes
// - Exponential backoff with jitter
```
