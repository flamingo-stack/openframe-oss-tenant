Helpers for interacting with the MeshCentral REST API, providing device status retrieval and parsing utilities for node connectivity information.

## Key Components

**Interface**
- `MeshCentralDeviceInfo` — Shape of the MeshCentral `deviceStatus` API response, including `nodeId`, `online` flag, `lastConnectTime` (Unix ms), and `lastConnectAddr`

**Functions**
- `getMeshCentralDeviceInfo(nodeId)` — Fetches device status from `tools/meshcentral-server/api/deviceStatus?id={nodeId}`; returns `null` on any network, HTTP, or parse failure
- `parseMeshCentralDeviceStatus(info)` — Derives `'online'` or `'offline'` string from a device info object; returns `'offline'` for `null` or malformed input
- `parseMeshCentralLastSeen(info)` — Returns a formatted last-seen timestamp string for offline devices; returns `null` when the device is online or data is unavailable

## Usage Example

```typescript
import {
  getMeshCentralDeviceInfo,
  parseMeshCentralDeviceStatus,
  parseMeshCentralLastSeen,
} from './meshcentral-api';

const nodeId = 'node://abc123';
const info = await getMeshCentralDeviceInfo(nodeId);

const status = parseMeshCentralDeviceStatus(info);
// → 'online' | 'offline'

const lastSeen = parseMeshCentralLastSeen(info);
// → 'Jan 15, 2025 10:32 AM' (offline devices only) | null
```

## Notes

- `getMeshCentralDeviceInfo` treats all failure modes (network errors, 4xx/5xx, gateway errors, unexpected response shapes) uniformly as `null` — callers should assume the device is offline with no last-seen data when `null` is returned
- `parseMeshCentralLastSeen` intentionally returns `null` for online devices since a "last seen" timestamp is not meaningful when the agent is currently connected
