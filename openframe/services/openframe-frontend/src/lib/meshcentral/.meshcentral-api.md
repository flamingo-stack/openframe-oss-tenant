Thin client helpers for querying the MeshCentral REST API to retrieve device status and parse connection metadata.

## Key Components

### Interface

| Name | Description |
|------|-------------|
| `MeshCentralDeviceInfo` | Shape of the MeshCentral `deviceStatus` API response — includes `nodeId`, `online` flag, `lastConnectTime` (Unix ms), and `lastConnectAddr` |

### Functions

| Name | Signature | Description |
|------|-----------|-------------|
| `getMeshCentralDeviceInfo` | `(nodeId: string) => Promise<MeshCentralDeviceInfo \| null>` | Fetches raw device status from the MeshCentral API; returns `null` on any failure |
| `parseMeshCentralDeviceStatus` | `(info: MeshCentralDeviceInfo \| null) => 'online' \| 'offline'` | Derives a status string from a device info object; defaults to `'offline'` on null/malformed data |
| `parseMeshCentralLastSeen` | `(info: MeshCentralDeviceInfo \| null) => string \| null` | Returns a formatted last-seen timestamp; returns `null` when the device is currently online or data is missing |

## Usage Example

```typescript
import {
  getMeshCentralDeviceInfo,
  parseMeshCentralDeviceStatus,
  parseMeshCentralLastSeen,
} from './meshcentral-api';

const nodeId = 'node//AbCdEf123456';

const info = await getMeshCentralDeviceInfo(nodeId);

const status = parseMeshCentralDeviceStatus(info);
// → 'online' | 'offline'

const lastSeen = parseMeshCentralLastSeen(info);
// → 'Jan 15, 2025, 10:32 AM' when offline, null when online or unavailable
```

## Notes

- `getMeshCentralDeviceInfo` hits `tools/meshcentral-server/api/deviceStatus?id={nodeId}` via the shared `apiClient`.
- All three helpers are **null-safe** — callers can treat a `null` return as "device offline / no data" without additional guards.
- `lastConnectTime` is a Unix timestamp in **milliseconds**, formatted via the shared `formatDateTime` utility.
