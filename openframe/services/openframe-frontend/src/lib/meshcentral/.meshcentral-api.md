Helpers for interacting with the MeshCentral REST API, providing device status retrieval and parsing utilities for node connectivity information.

## Key Components

**Interface**
- `MeshCentralDeviceInfo` — Shape of the MeshCentral `deviceStatus` API response, including `nodeId`, `online` flag, `lastConnectTime` (Unix ms), and `lastConnectAddr`

**Functions**
- `getMeshCentralDeviceInfo(nodeId)` — Fetches device status from `tools/meshcentral-server/api/deviceStatus?id={nodeId}`; returns `null` on any failure (network, 4xx/5xx, malformed response)
- `parseMeshCentralDeviceStatus(info)` — Derives `'online'` or `'offline'` string from a `MeshCentralDeviceInfo` object; safely returns `'offline'` on `null` or malformed input
- `parseMeshCentralLastSeen(info)` — Returns a formatted last-seen timestamp string for offline devices, or `null` when online or data is unavailable

## Usage Example

```typescript
import {
  getMeshCentralDeviceInfo,
  parseMeshCentralDeviceStatus,
  parseMeshCentralLastSeen,
} from './meshcentral-api';

const nodeId = 'node//AbCdEf123456';

const info = await getMeshCentralDeviceInfo(nodeId);

const status = parseMeshCentralDeviceStatus(info);
// → 'online' | 'offline'

const lastSeen = parseMeshCentralLastSeen(info);
// → 'Jan 15, 2025 10:32 AM' (offline devices only) | null
```

## Notes

- `getMeshCentralDeviceInfo` treats all failure modes (network errors, non-2xx responses, arrays, primitives) uniformly as `null` — callers should interpret `null` as offline with no last-seen data
- `parseMeshCentralLastSeen` intentionally returns `null` for online devices since a last-seen timestamp is not meaningful when the device is currently connected
