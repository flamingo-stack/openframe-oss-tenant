Manages file downloads over a MeshCentral WebSocket connection, handling the full download lifecycle from request initiation through binary chunk reassembly to browser file saving.

## Key Components

**`DownloadTask` interface** — Tracks state for an individual download: chunks buffer, transfer progress, status lifecycle (`pending` → `negotiating` → `downloading` → `completed`/`failed`/`cancelled`).

**`FileDownloader` class** — Core download manager with these primary methods:

| Method | Description |
|---|---|
| `downloadFile(remotePath, fileName?, fileSize?)` | Initiates a download request, returns a unique `downloadId` |
| `handleControlMessage(message)` | Routes JSON control messages (`start`, `cancel`, `error`) from the server |
| `handleBinaryChunk(data, isFinal)` | Processes incoming binary chunks; reads 4-byte big-endian header for final-chunk flag, sends ACKs |
| `cancelDownload(downloadId)` | Cancels an in-progress download and notifies the server |
| `saveFile(downloadId)` | Triggers a browser download via a temporary anchor element and object URL |
| `resetActiveDownload()` | Unsticks a timed-out or stalled active download |
| `clearAll()` | Resets all tracked downloads and active state |

## Usage Example

```typescript
const downloader = new FileDownloader(
  (data) => socket.send(data),           // sendMessage
  (progress) => console.log(progress),   // onProgress
  (fileName, reason) => console.warn(`Server cancelled ${fileName}: ${reason}`)
);

// Start a download
const downloadId = downloader.downloadFile('/remote/path/report.pdf', 'report.pdf');

// Wire up WebSocket message handlers
socket.onmessage = (event) => {
  if (typeof event.data === 'string') {
    downloader.handleControlMessage(JSON.parse(event.data));
  } else {
    const buffer = new Uint8Array(event.data);
    downloader.handleBinaryChunk(buffer, false);
  }
};

// Cancel if needed
downloader.cancelDownload(downloadId);
```

> **Protocol note:** Each binary chunk begins with a 4-byte big-endian header; bit 0 of that integer signals the final chunk, after which the assembled `Blob` is saved to the browser automatically.
