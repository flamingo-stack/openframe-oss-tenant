Manages file downloads over the MeshCentral WebSocket protocol, handling chunked binary transfer, progress tracking, and browser-side file saving.

## Key Components

### `DownloadTask` Interface
Tracks the state of an in-progress download including chunk accumulation, size tracking, and lifecycle status (`pending` → `negotiating` → `downloading` → `completed` / `failed` / `cancelled`).

### `FileDownloader` Class
Core download manager with the following methods:

| Method | Description |
|---|---|
| `downloadFile(remotePath, fileName?, fileSize?)` | Initiates a download request, returns a `downloadId` |
| `handleControlMessage(message)` | Dispatches JSON control frames (`start`, `cancel`, `error`) |
| `handleBinaryChunk(data, isFinal)` | Processes binary chunks; reads 4-byte big-endian header to detect final chunk |
| `cancelDownload(downloadId)` | Sends cancel signal to server and cleans up task |
| `saveFile(downloadId)` | Triggers browser download via temporary `<a>` element |
| `getFileBlob(downloadId)` | Assembles accumulated chunks into a `Blob` |
| `resetActiveDownload()` | Unsticks a hung download in `requested`/`negotiating`/`downloading` state |
| `clearAll()` | Purges all tracked downloads and resets active state |

## Usage Example

```typescript
const downloader = new FileDownloader(
  (data) => websocket.send(data),           // sendMessage
  (progress) => console.log(progress),      // onProgress
  (fileName, reason) => alert(`Server cancelled ${fileName}: ${reason}`) // onServerCancel
);

// Start a download
const downloadId = downloader.downloadFile('/remote/path/report.pdf', 'report.pdf', 204800);

// Wire into WebSocket message handler
websocket.onmessage = (event) => {
  if (typeof event.data === 'string') {
    downloader.handleControlMessage(JSON.parse(event.data));
  } else {
    const buffer = new Uint8Array(await event.data.arrayBuffer());
    downloader.handleBinaryChunk(buffer, false);
  }
};
```

> **Protocol note:** Each binary frame carries a 4-byte big-endian header; bit 0 of that integer signals the final chunk, after which the assembled `Blob` is saved to the browser automatically.
