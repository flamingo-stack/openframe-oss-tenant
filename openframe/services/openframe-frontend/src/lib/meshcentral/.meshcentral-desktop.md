TypeScript implementation of a MeshCentral desktop protocol client that handles remote desktop input/output through HTML5 Canvas, providing mouse and keyboard event encoding, tile-based image rendering, and multi-display support.

## Key Components

- **`DisplayInfo`** - Interface for multi-monitor display information (id, position, dimensions, primary flag)
- **`DesktopInputHandlers`** - Type definition for required desktop control methods (attach, detach, input handling)
- **`MeshDesktop`** - Main class implementing the MeshCentral desktop protocol with:
  - Canvas-based rendering with tile queue and image decode management
  - Mouse/keyboard input capture and binary protocol encoding
  - Display switching and multi-monitor support
  - View-only mode and input configuration options

## Usage Example

```typescript
import { MeshDesktop } from './meshcentral-desktop'

// Create desktop instance
const desktop = new MeshDesktop()

// Set up data sender (typically WebSocket)
desktop.setSender((data: Uint8Array) => {
  websocket.send(data)
})

// Attach to canvas element
const canvas = document.getElementById('desktop-canvas') as HTMLCanvasElement
desktop.attach(canvas)

// Configure options
desktop.setViewOnly(false)
desktop.setSwapMouseButtons(false)

// Handle display changes
desktop.onDisplayListChange?.((displays) => {
  console.log('Available displays:', displays)
})

// Send special key combinations
desktop.sendCtrlAltDel?.()
desktop.sendKeyCombo?.('ctrl+alt+delete')

// Clean up when done
desktop.detach()
```

The class handles the complete MeshCentral KVM protocol including initialization commands, compression settings, and real-time input event encoding for seamless remote desktop control.
