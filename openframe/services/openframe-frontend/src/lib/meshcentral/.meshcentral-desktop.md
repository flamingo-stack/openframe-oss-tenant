A MeshCentral desktop remote control implementation that handles real-time screen rendering and input events over WebSocket connections.

## Key Components

- **`DisplayInfo`** - Interface defining multi-monitor display properties (id, position, dimensions)
- **`DesktopInputHandlers`** - Interface for desktop interaction methods (attach, detach, input handling)
- **`MeshDesktop`** - Main class implementing remote desktop functionality with canvas rendering and input capture
- **Input Methods** - Mouse, keyboard, and scroll event encoding for MeshCentral protocol
- **Display Management** - Multi-monitor support with display switching capabilities
- **Tile Processing** - Asynchronous image tile decoding and rendering queue system

## Usage Example

```typescript
// Initialize desktop connection
const desktop = new MeshDesktop()
const canvas = document.getElementById('desktop-canvas') as HTMLCanvasElement

// Setup WebSocket sender for MeshCentral protocol
desktop.setSender((data: Uint8Array) => {
  websocket.send(data)
})

// Attach to canvas and enable input
desktop.attach(canvas)
desktop.setViewOnly(false)

// Handle multi-monitor setup
desktop.onDisplayListChange?.((displays) => {
  console.log('Available displays:', displays)
  // Switch to primary display
  const primary = displays.find(d => d.primary)
  if (primary) desktop.switchDisplay?.(primary.id)
})

// Process incoming screen data
websocket.onmessage = (event) => {
  const data = new Uint8Array(event.data)
  desktop.processMessage(data) // Implementation handles tile updates
}

// Send special key combinations
desktop.sendCtrlAltDel?.()
desktop.sendKeyCombo?.('ctrl+alt+t')
```
