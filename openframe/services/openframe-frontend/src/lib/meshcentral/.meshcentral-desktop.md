A TypeScript class that implements remote desktop functionality for MeshCentral, handling mouse/keyboard input capture, screen rendering, and binary protocol communication for remote desktop sessions.

## Key Components

**Interfaces:**
- `DisplayInfo` - Represents display metadata (position, size, primary status)
- `DesktopInputHandlers` - Contract for desktop input management operations

**Main Class:**
- `MeshDesktop` - Core remote desktop client implementation with canvas-based rendering, input event capture, binary protocol encoding, and multi-display support

**Key Features:**
- Mouse/keyboard event capture and encoding
- Canvas-based screen rendering with tile-based updates
- Binary protocol communication for MeshCentral desktop sessions
- Multi-display support with display switching
- Configurable input options (view-only mode, button swapping, scroll inversion)
- Asynchronous image decoding with concurrency limits

## Usage Example

```typescript
import { MeshDesktop, DisplayInfo } from './meshcentral-desktop'

// Create desktop instance
const desktop = new MeshDesktop()

// Set up WebSocket sender for binary protocol
desktop.setSender((data: Uint8Array) => {
  websocket.send(data)
})

// Attach to canvas element
const canvas = document.getElementById('desktop-canvas') as HTMLCanvasElement
desktop.attach(canvas)

// Configure input settings
desktop.setViewOnly(false)
desktop.setSwapMouseButtons(false)
desktop.setInvertScrollDirection(true)

// Handle display changes
desktop.onDisplayListChange?.((displays: DisplayInfo[]) => {
  console.log('Available displays:', displays)
  if (displays.length > 1) {
    desktop.switchDisplay?.(displays[1].id) // Switch to second display
  }
})

// Process incoming desktop data
websocket.onmessage = (event) => {
  const data = new Uint8Array(event.data)
  desktop.processMessage(data) // Handle screen updates
}

// Clean up when done
desktop.detach()
```
