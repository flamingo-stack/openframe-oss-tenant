A TypeScript class that implements the MeshCentral desktop streaming protocol, providing remote desktop capabilities with mouse and keyboard input handling over WebSockets.

## Key Components

- **DisplayInfo Interface**: Defines display properties including position, size, and primary display status
- **DesktopInputHandlers Interface**: Contract for desktop input handling with attachment, input control, and display management
- **MeshDesktop Class**: Core implementation handling canvas rendering, input events, binary protocol encoding, and tile-based streaming
- **Binary Protocol Methods**: Encode mouse movements, clicks, keyboard events, and wheel actions according to MeshCentral's KVM protocol
- **Tile Queue System**: Manages concurrent image decoding and drawing operations for optimal performance

## Usage Example

```typescript
import { MeshDesktop } from './meshcentral-desktop'

// Create desktop instance
const desktop = new MeshDesktop()

// Set up WebSocket sender
desktop.setSender((data: Uint8Array) => {
  webSocket.send(data)
})

// Attach to canvas element
const canvas = document.getElementById('desktop-canvas') as HTMLCanvasElement
desktop.attach(canvas)

// Configure input options
desktop.setViewOnly(false)
desktop.setSwapMouseButtons(false)
desktop.setUseRemoteKeyboardMap(true)

// Handle display changes
desktop.onDisplayListChange?.((displays) => {
  console.log('Available displays:', displays)
})

// Process incoming desktop data
webSocket.onmessage = (event) => {
  const data = new Uint8Array(event.data)
  desktop.processDesktopData(data)
}

// Special key combinations
desktop.sendCtrlAltDel?.()
desktop.sendKeyCombo?.('ctrl+shift+esc')
```
