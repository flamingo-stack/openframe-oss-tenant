Implements the MeshCentral desktop remote control client, handling binary protocol encoding, canvas rendering, and full keyboard/mouse input translation for remote desktop sessions.

## Key Components

**`DisplayInfo`** — Interface describing a remote monitor's geometry and identity.

**`DesktopInputHandlers`** — Contract interface for attaching/detaching desktop input, toggling view-only mode, sending key combos, and managing display switching callbacks.

**`MeshDesktop`** — Core class implementing `DesktopInputHandlers` with:
- `attach(canvas)` / `detach()` — Binds/unbinds all mouse, wheel, keyboard, and window-blur event listeners to a canvas element
- `setViewOnly(viewOnly)` — Suppresses all input forwarding when enabled
- `sendCtrlAltDel()` / `sendKeyCombo(combo)` — Sends special key sequences to the remote host
- `requestRefresh()` / `requestDisplayList()` / `switchDisplay(id)` — Protocol-level display management commands
- Meta key buffering — Delays `Meta/Win` key transmission by 50ms to distinguish lone taps from chords, preventing accidental Start Menu triggers
- Clipboard interceptor — Intercepts `Ctrl+C/X/V` and `Cmd+C/X/V` before forwarding, enabling custom paste workflows
- Tile decode queue — Limits concurrent `ImageBitmap` decodes to 3 and batches canvas draw calls via `requestAnimationFrame`
- Key tracking — Maintains `pressedKeys` and `suppressedKeys` sets to ensure correct key-up events on window blur or modifier-chord cancellation

## Usage Example

```typescript
import { MeshDesktop } from './meshcentral-desktop';

const desktop = new MeshDesktop();

// Wire up a data sender (e.g., WebSocket)
desktop.setSender((data: Uint8Array) => ws.send(data));

// Attach to a canvas element
const canvas = document.getElementById('remote-screen') as HTMLCanvasElement;
desktop.attach(canvas);

// Toggle view-only mode
desktop.setViewOnly(true);

// Intercept clipboard operations
desktop.setClipboardInterceptor((type, sendKeys) => {
  if (type === 'paste') {
    navigator.clipboard.readText().then(text => {
      desktop.setClipboard(text);
      sendKeys(); // forward Ctrl+V to remote
    });
  } else {
    sendKeys();
  }
});

// Switch to a secondary monitor
desktop.onDisplayListChange((displays) => {
  const secondary = displays.find(d => !d.primary);
  if (secondary) desktop.switchDisplay(secondary.id);
});

// Clean up
desktop.detach();
```
