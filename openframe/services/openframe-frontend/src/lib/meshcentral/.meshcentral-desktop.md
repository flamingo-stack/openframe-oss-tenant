MeshCentral desktop remote access handler that manages canvas-based desktop streaming, input capture, and multi-display support with binary protocol encoding for real-time desktop sharing.

## Key Components

**Interfaces:**
- `DisplayInfo` - Multi-monitor display configuration (id, position, dimensions, primary flag)
- `DesktopInputHandlers` - Interface for desktop interaction methods (attach, detach, input handling)

**Main Class:**
- `MeshDesktop` - Core desktop streaming implementation with canvas rendering, input encoding, and display management

**Key Methods:**
- `attach(canvas)` - Binds desktop to HTML canvas with mouse/keyboard listeners
- `detach()` - Cleans up resources and removes event listeners
- `setSender()` - Configures binary data transmission channel
- `setViewOnly()` - Toggles input capture on/off
- `requestDisplayList()` - Queries available displays for multi-monitor setups

## Usage Example

```typescript
// Initialize desktop connection
const desktop = new MeshDesktop()
const canvas = document.getElementById('desktop-canvas') as HTMLCanvasElement

// Configure data sender (WebSocket/WebRTC channel)
desktop.setSender((data: Uint8Array) => {
  websocket.send(data)
})

// Attach to canvas for rendering and input
desktop.attach(canvas)

// Configure settings
desktop.setViewOnly(false)  // Enable input
desktop.setSwapMouseButtons(true)  // Left-handed mode

// Handle multi-display scenarios
desktop.onDisplayListChange?.((displays) => {
  console.log(`Available displays: ${displays.length}`)
  displays.forEach(display => {
    console.log(`Display ${display.id}: ${display.w}x${display.h}`)
  })
})

// Switch to different display
desktop.switchDisplay?.(1)

// Clean up when done
desktop.detach()
```

The class handles MeshCentral's binary protocol for desktop streaming, including initialization commands, compression settings, and real-time input encoding for seamless remote desktop experiences.
