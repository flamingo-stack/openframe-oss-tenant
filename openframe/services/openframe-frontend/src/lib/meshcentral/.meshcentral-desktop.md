TypeScript interface and class implementation for MeshCentral desktop remote control functionality. Provides a complete client-side implementation for capturing user input (mouse and keyboard) and rendering remote desktop frames.

## Key Components

### Interfaces
- **`DisplayInfo`** - Represents display configuration with position, dimensions, and primary status
- **`DesktopInputHandlers`** - Interface defining desktop control methods (attach, detach, input handling)

### Main Class
- **`MeshDesktop`** - Core implementation handling canvas rendering, input capture, and MeshCentral protocol communication
- **Input Management** - Mouse/keyboard event listeners with proper coordinate mapping and button handling
- **Protocol Encoding** - Binary message encoders for MeshCentral desktop protocol commands
- **Display Management** - Multi-monitor support with display switching capabilities
- **Frame Processing** - Tile-based rendering with queued decoding for smooth performance

## Usage Example

```typescript
import { MeshDesktop, DesktopInputHandlers } from './meshcentral-desktop'

// Create desktop instance
const desktop = new MeshDesktop()

// Set up communication
desktop.setSender((data: Uint8Array) => {
  // Send binary data to MeshCentral server
  websocket.send(data)
})

// Attach to canvas element
const canvas = document.getElementById('desktop-canvas') as HTMLCanvasElement
desktop.attach(canvas)

// Configure settings
desktop.setViewOnly(false) // Enable input
desktop.setSwapMouseButtons(false)
desktop.setUseRemoteKeyboardMap(true)

// Handle display changes
desktop.onDisplayListChange?.((displays) => {
  console.log('Available displays:', displays)
})

// Switch to specific display
desktop.switchDisplay?.(1)

// Send special key combinations
desktop.sendCtrlAltDel?.()
desktop.sendKeyCombo?.('ctrl+alt+t')
```

The class automatically handles MeshCentral protocol initialization, compression settings, and maintains proper input state tracking for reliable remote desktop control.
