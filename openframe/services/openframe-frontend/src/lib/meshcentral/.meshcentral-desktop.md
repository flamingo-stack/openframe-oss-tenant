TypeScript interface and class implementation for MeshCentral desktop remote control functionality, handling mouse/keyboard input capture, screen rendering, and binary protocol communication.

## Key Components

- **DisplayInfo**: Interface defining multi-monitor display properties (position, size, primary status)
- **DesktopInputHandlers**: Type defining the contract for desktop input handling capabilities
- **MeshDesktop**: Main class implementing remote desktop client with:
  - Canvas-based screen rendering with tile-based updates
  - Mouse/keyboard input capture and encoding
  - Binary protocol communication for MeshCentral KVM
  - Multi-display support and management
  - View-only mode and input customization options

## Usage Example

```typescript
// Initialize desktop client
const desktop = new MeshDesktop()

// Set up WebSocket sender for binary protocol
desktop.setSender((data: Uint8Array) => {
  websocket.send(data)
})

// Attach to canvas element
const canvas = document.getElementById('desktop-canvas') as HTMLCanvasElement
desktop.attach(canvas)

// Configure input options
desktop.setViewOnly(false)
desktop.setSwapMouseButtons(false)
desktop.setUseRemoteKeyboardMap(true)

// Handle multi-display scenarios
desktop.onDisplayListChange?.((displays) => {
  console.log(`Available displays: ${displays.length}`)
  displays.forEach(d => console.log(`Display ${d.id}: ${d.w}x${d.h}`))
})

// Process incoming screen data
websocket.onmessage = (event) => {
  const data = new Uint8Array(event.data)
  desktop.processMessage(data)
}
```
