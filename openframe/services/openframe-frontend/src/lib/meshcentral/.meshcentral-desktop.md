MeshCentral desktop remote control client that handles real-time screen rendering, input capture, and multi-display support through binary protocol communication.

## Key Components

**Core Classes & Interfaces:**
- `MeshDesktop` - Main desktop client implementing input handlers and screen rendering
- `DesktopInputHandlers` - Interface defining remote desktop interaction methods
- `DisplayInfo` - Multi-monitor display configuration structure

**Key Methods:**
- `attach(canvas)` - Binds input listeners to HTML canvas element
- `setSender(sender)` - Configures binary protocol message sender
- `processMessage(data)` - Handles incoming desktop protocol messages
- `setViewOnly(viewOnly)` - Toggles read-only mode for screen viewing

**Protocol Features:**
- Binary message encoding for mouse/keyboard events
- JPEG tile-based screen updates with async decoding
- Multi-display support with display switching
- Compression settings and frame rate control

## Usage Example

```typescript
import { MeshDesktop, DesktopInputHandlers } from './meshcentral-desktop'

// Initialize desktop client
const desktop = new MeshDesktop()
const canvas = document.getElementById('remoteScreen') as HTMLCanvasElement

// Set up WebSocket sender for binary protocol
desktop.setSender((data: Uint8Array) => {
  websocket.send(data.buffer)
})

// Attach to canvas for input capture
desktop.attach(canvas)

// Handle incoming screen updates
websocket.onmessage = (event) => {
  const data = new Uint8Array(event.data)
  desktop.processMessage(data)
}

// Configure display options
desktop.setViewOnly(false)  // Enable input
desktop.setSwapMouseButtons(true)  // Left-handed mode

// Handle multi-display scenarios
desktop.onDisplayListChange((displays) => {
  console.log(`Available displays: ${displays.length}`)
  if (displays.length > 1) {
    desktop.switchDisplay(displays[1].id)
  }
})
```
