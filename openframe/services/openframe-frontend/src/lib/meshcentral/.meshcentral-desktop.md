Implements the MeshCentral remote desktop client for browser-based KVM sessions, handling binary protocol encoding/decoding, canvas rendering, and full input event mapping (mouse, keyboard, scroll) over a WebSocket-like data channel.

## Key Components

### `DisplayInfo`
Interface describing a remote monitor: position (`x`, `y`), dimensions (`w`, `h`), and whether it is the primary display.

### `DesktopInputHandlers`
Interface contract for remote desktop input implementations, covering canvas lifecycle, view-only mode, Ctrl+Alt+Del, key combos, display switching, and clipboard interception.

### `MeshDesktop`
Main class implementing `DesktopInputHandlers`. Manages:

- **Canvas & rendering** — decodes JPEG tile queue with concurrent `ImageBitmap` decoding (max 3 parallel), batches draws via `requestAnimationFrame`.
- **Binary protocol encoding** — mouse move/button/wheel events, key events (VK codes), Unicode key events, and Ctrl+Alt+Del sequences per the MeshCentral KVM protocol.
- **Keyboard handling** — tracks pressed keys, buffers Meta/Cmd key (50 ms) to suppress accidental Windows Start menu, handles CapsLock toggle, maps browser key codes to Windows Virtual Key codes, and supports Unicode-eligible characters.
- **Clipboard interception** — optional interceptor callback for `copy`/`cut`/`paste` combos to allow host-side clipboard integration.
- **Display management** — maintains a list of remote monitors and fires callbacks on changes.

## Usage Example

```typescript
import { MeshDesktop } from './meshcentral-desktop';

const desktop = new MeshDesktop();

// Wire up the data sender (e.g. from a WebSocket)
desktop.setSender((data: Uint8Array) => ws.send(data));

// Feed incoming binary frames from the remote agent
ws.onmessage = (event) => {
  const buffer = new Uint8Array(event.data);
  desktop.processData(buffer);
};

// Attach to a canvas element
const canvas = document.getElementById('remote-screen') as HTMLCanvasElement;
desktop.attach(canvas);

// Optionally intercept clipboard operations
desktop.setClipboardInterceptor((type, sendKeys) => {
  if (type === 'paste') {
    navigator.clipboard.readText().then(text => {
      desktop.sendClipboardText(text);
    });
  } else {
    sendKeys(); // fall through to remote keystrokes
  }
});

// Clean up on component unmount
desktop.detach();
```
