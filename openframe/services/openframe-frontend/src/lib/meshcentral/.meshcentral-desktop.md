A TypeScript implementation of a MeshCentral desktop remote control client that handles real-time screen streaming, input capture, and multi-display management through WebSocket binary protocols.

## Key Components

### Interfaces
- **`DisplayInfo`** - Represents display configuration with dimensions and position data
- **`DesktopInputHandlers`** - Interface defining remote desktop input management methods

### Main Class
- **`MeshDesktop`** - Core implementation providing canvas-based remote desktop functionality with:
  - Binary protocol encoding for mouse/keyboard events
  - Asynchronous tile-based screen rendering with decode queuing
  - Multi-display support with display switching capabilities
  - Input event handling with configurable mouse button swapping
  - Keyboard mapping with extended key support and pressed key tracking

### Key Features
- **Protocol Initialization** - Automated desktop stream setup with compression settings
- **Input Encoding** - Binary message encoding for MeshCentral KVM protocol
- **Render Pipeline** - Concurrent tile decoding with draw scheduling
- **Event Management** - Complete mouse/keyboard event capture with view-only mode

## Usage Example

```typescript
import { MeshDesktop } from './meshcentral-desktop'

// Initialize desktop client
const desktop = new MeshDesktop()
const canvas = document.getElementById('desktop-canvas') as HTMLCanvasElement

// Set up WebSocket sender for binary protocol
desktop.setSender((data: Uint8Array) => {
  websocket.send(data)
})

// Attach to canvas and configure
desktop.attach(canvas)
desktop.setViewOnly(false)
desktop.setSwapMouseButtons(false)

// Handle multi-display scenarios
desktop.onDisplayListChange?.((displays) => {
  console.log('Available displays:', displays)
  if (displays.length > 1) {
    desktop.switchDisplay?.(displays[1].id)
  }
})

// Process incoming screen data
websocket.onmessage = (event) => {
  const data = new Uint8Array(event.data)
  desktop.processMessage(data) // Process screen updates
}
```
