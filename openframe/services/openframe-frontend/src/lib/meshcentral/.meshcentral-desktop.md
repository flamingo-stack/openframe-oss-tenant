A TypeScript implementation of a MeshCentral desktop client that handles remote desktop connections through HTML5 canvas, providing mouse/keyboard input handling and screen rendering capabilities.

## Key Components

**Interfaces:**
- `DisplayInfo` - Represents display configuration (position, size, primary status)
- `DesktopInputHandlers` - Contract for desktop input management with optional multi-display support

**Main Class:**
- `MeshDesktop` - Core desktop client implementation with binary protocol encoding for MeshCentral communication

**Key Methods:**
- `attach(canvas)` / `detach()` - Canvas lifecycle management with event listeners
- `setSender()` - Establishes binary communication channel and initializes desktop session
- Input encoders (`encodeMouseButton`, `encodeKeyEvent`, etc.) - Convert DOM events to MeshCentral protocol
- Display management (`requestDisplayList`, `switchDisplay`) - Multi-monitor support

## Usage Example

```typescript
// Initialize desktop client
const desktop = new MeshDesktop()

// Attach to canvas element
const canvas = document.getElementById('desktop-canvas') as HTMLCanvasElement
desktop.attach(canvas)

// Set up WebSocket communication
const ws = new WebSocket('ws://meshcentral-server')
desktop.setSender((data: Uint8Array) => {
  if (ws.readyState === WebSocket.OPEN) {
    ws.send(data)
  }
})

// Configure options
desktop.setViewOnly(false)
desktop.setSwapMouseButtons(false)

// Handle multi-display scenarios
desktop.onDisplayListChange?.((displays) => {
  console.log('Available displays:', displays)
  // Switch to primary display
  const primary = displays.find(d => d.primary)
  if (primary) desktop.switchDisplay?.(primary.id)
})

// Send special key combinations
desktop.sendCtrlAltDel?.()
desktop.sendKeyCombo?.('ctrl+alt+delete')

// Clean up when done
desktop.detach()
```

The class handles MeshCentral's binary protocol for desktop streaming, including initialization commands, compression settings, and input event encoding. It supports advanced features like extended key handling, mouse button swapping, and multi-display environments.
