TypeScript implementation of a MeshCentral desktop remote control client that provides real-time screen sharing and input handling capabilities through canvas-based rendering and binary protocol communication.

## Key Components

**Interfaces:**
- `DisplayInfo` - Multi-monitor display configuration with dimensions and positioning
- `DesktopInputHandlers` - Contract for desktop control operations (attach, input handling, display management)

**Main Class:**
- `MeshDesktop` - Core desktop client implementing canvas rendering, input capture, tile-based screen updates, and MeshCentral binary protocol encoding

**Key Features:**
- Mouse and keyboard input encoding with button swapping and extended key support
- Tile-based screen rendering with concurrent decode queuing
- Multi-display support with display switching capabilities
- View-only mode for screen sharing without input control
- Binary protocol communication for MeshCentral server integration

## Usage Example

```typescript
// Initialize desktop client
const desktop = new MeshDesktop();
const canvas = document.getElementById('desktop-canvas') as HTMLCanvasElement;

// Set up communication channel
desktop.setSender((data: Uint8Array) => {
  // Send binary data to MeshCentral server
  websocket.send(data);
});

// Attach to canvas and start input handling
desktop.attach(canvas);

// Configure desktop settings
desktop.setViewOnly(false); // Enable input control
desktop.setSwapMouseButtons(true); // Left-handed mode

// Handle multi-display scenarios
desktop.onDisplayListChange?.((displays) => {
  console.log('Available displays:', displays);
  if (displays.length > 1) {
    desktop.switchDisplay?.(displays[1].id); // Switch to second monitor
  }
});

// Clean up when done
desktop.detach();
```
