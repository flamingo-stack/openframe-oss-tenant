A browser-based remote desktop client implementation that provides MeshCentral-compatible KVM (keyboard, video, mouse) functionality with multi-display support and efficient tile-based rendering.

## Key Components

- **`DisplayInfo`** - Interface defining display properties (id, dimensions, position, primary status)
- **`DesktopInputHandlers`** - Type defining the contract for desktop input handling methods
- **`MeshDesktop`** - Main class implementing remote desktop functionality with:
  - Canvas-based rendering with tile queue management
  - Mouse/keyboard input capture and encoding
  - Multi-display support with display switching
  - Binary protocol encoding for MeshCentral communication
  - View-only mode and input customization options

## Usage Example

```typescript
import { MeshDesktop, DisplayInfo } from './meshcentral-desktop'

// Create desktop instance
const desktop = new MeshDesktop()

// Set up data sender (WebSocket, etc.)
desktop.setSender((data: Uint8Array) => {
  websocket.send(data)
})

// Attach to canvas element
const canvas = document.getElementById('desktop-canvas') as HTMLCanvasElement
desktop.attach(canvas)

// Handle display changes
desktop.onDisplayListChange?.((displays: DisplayInfo[]) => {
  console.log('Available displays:', displays)
  if (displays.length > 1) {
    desktop.switchDisplay?.(displays[1].id) // Switch to second display
  }
})

// Enable view-only mode
desktop.setViewOnly(true)

// Handle special key combinations
desktop.sendCtrlAltDel?.()
```

The class handles the complete MeshCentral desktop protocol including initialization commands, compression settings, input encoding, and multi-display coordination for seamless remote desktop experiences.
