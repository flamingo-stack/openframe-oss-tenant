MeshCentral Desktop client implementation that provides remote desktop control functionality through HTML5 canvas, handling mouse/keyboard input, screen rendering, and multi-display support via binary protocol communication.

## Key Components

- **`DisplayInfo`** - Interface defining display properties (id, position, dimensions, primary status)
- **`DesktopInputHandlers`** - Type defining the contract for desktop input handling methods
- **`MeshDesktop`** - Main class implementing remote desktop functionality with:
  - Canvas-based rendering with tile-based image decoding
  - Mouse/keyboard event capture and protocol encoding
  - Multi-display support and display switching
  - View-only mode and input configuration options
  - Binary message protocol for MeshCentral communication

## Usage Example

```typescript
import { MeshDesktop, DisplayInfo } from './meshcentral-desktop'

// Initialize desktop client
const desktop = new MeshDesktop()
const canvas = document.getElementById('desktop-canvas') as HTMLCanvasElement

// Set up sender function for WebSocket communication
desktop.setSender((data: Uint8Array) => {
  websocket.send(data)
})

// Attach to canvas and configure
desktop.attach(canvas)
desktop.setViewOnly(false)
desktop.setSwapMouseButtons(false)

// Handle display changes
desktop.onDisplayListChange?.((displays: DisplayInfo[]) => {
  console.log('Available displays:', displays)
  // Switch to first non-primary display if available
  const secondDisplay = displays.find(d => !d.primary)
  if (secondDisplay) {
    desktop.switchDisplay?.(secondDisplay.id)
  }
})

// Send special key combinations
desktop.sendCtrlAltDel?.()
desktop.sendKeyCombo?.('ctrl+alt+t') // Open terminal
```
