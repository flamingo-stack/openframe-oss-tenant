A MeshCentral desktop protocol client implementation that provides remote desktop control capabilities through HTML5 Canvas, handling mouse/keyboard input, screen rendering, and multi-display support.

## Key Components

- **`DisplayInfo`** - Interface defining display properties (id, position, dimensions, primary status)
- **`DesktopInputHandlers`** - Type definition for desktop control interface methods
- **`MeshDesktop`** - Main class implementing remote desktop functionality with:
  - Canvas-based screen rendering with tile-based updates
  - Mouse and keyboard input capture and encoding
  - Multi-display support and switching
  - View-only mode and input customization
  - Binary protocol encoding for MeshCentral communication

## Usage Example

```typescript
import { MeshDesktop, DisplayInfo } from './meshcentral-desktop'

// Create desktop instance
const desktop = new MeshDesktop()

// Set up data sender (typically WebSocket)
desktop.setSender((data: Uint8Array) => {
  websocket.send(data)
})

// Attach to canvas element
const canvas = document.getElementById('desktop-canvas') as HTMLCanvasElement
desktop.attach(canvas)

// Handle display changes
desktop.onDisplayListChange?.((displays: DisplayInfo[]) => {
  console.log('Available displays:', displays)
  // Switch to secondary display
  if (displays.length > 1) {
    desktop.switchDisplay?.(displays[1].id)
  }
})

// Configure input settings
desktop.setViewOnly(false)
desktop.setSwapMouseButtons(false)

// Send special key combinations
desktop.sendCtrlAltDel?.()
desktop.sendKeyCombo?.('ctrl+alt+t')
```

The class handles the complete MeshCentral desktop protocol including initialization commands, compression settings, and real-time input/output processing for seamless remote desktop control.
