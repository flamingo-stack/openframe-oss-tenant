A comprehensive TypeScript client implementation for MeshCentral's desktop remote control protocol, providing real-time screen viewing and input forwarding with support for multi-display setups.

## Key Components

- **DisplayInfo**: Interface defining display properties (id, position, dimensions, primary status)
- **DesktopInputHandlers**: Type defining the contract for desktop input management methods
- **MeshDesktop**: Main class implementing desktop remote control functionality with:
  - Canvas-based screen rendering with tile-based updates
  - Mouse and keyboard input capture and encoding
  - Multi-display support and switching
  - View-only mode and input customization options
  - Binary protocol communication with MeshCentral server

## Usage Example

```typescript
import { MeshDesktop } from './meshcentral-desktop'

// Create desktop instance
const desktop = new MeshDesktop()
const canvas = document.getElementById('desktop-canvas') as HTMLCanvasElement

// Set up communication channel
desktop.setSender((data: Uint8Array) => {
  // Send binary data to MeshCentral server via WebSocket
  websocket.send(data)
})

// Attach to canvas and start capturing input
desktop.attach(canvas)

// Configure options
desktop.setViewOnly(false)  // Allow input
desktop.setSwapMouseButtons(true)  // Swap left/right buttons

// Handle display changes
desktop.onDisplayListChange?.((displays) => {
  console.log(`Available displays: ${displays.length}`)
  displays.forEach(d => console.log(`Display ${d.id}: ${d.w}x${d.h}`))
})

// Process incoming screen data
websocket.onmessage = (event) => {
  const data = new Uint8Array(event.data)
  desktop.processData(data)  // Method would handle screen updates
}

// Clean up
desktop.detach()
```

The class handles MeshCentral's binary protocol for desktop control, including initialization commands, compression settings, and real-time input event encoding for seamless remote desktop functionality.
