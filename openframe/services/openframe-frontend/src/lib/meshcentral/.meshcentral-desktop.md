Implements the MeshCentral desktop remote control client, handling binary protocol encoding/decoding, canvas rendering of remote display tiles, and full keyboard/mouse input translation for browser-based remote desktop sessions.

## Key Components

- **`DisplayInfo`** — Interface describing a remote monitor (id, position, dimensions, primary flag)
- **`DesktopInputHandlers`** — Interface contract for attach/detach lifecycle, input controls, display switching, clipboard interception, and event callbacks
- **`MeshDesktop`** — Primary class implementing `DesktopInputHandlers` with:
  - Canvas attachment and event listener management
  - JPEG tile queue with concurrent `ImageBitmap` decode limiting (`maxConcurrentDecodes: 3`)
  - Binary protocol encoders for mouse (move, button, wheel, double-click) and keyboard (VK codes, Unicode, extended keys)
  - Meta/Win key buffering to suppress accidental Start menu triggers via Ctrl+Win chord trick
  - Clipboard interceptor hook (`setClipboardInterceptor`) for `copy`/`cut`/`paste` interception before sending key combos
  - `pressedKeys` tracking and `suppressedKeys` set for reliable key-up release on window blur

## Usage Example

```typescript
import { MeshDesktop } from './meshcentral-desktop';

const desktop = new MeshDesktop();

// Wire up the binary sender (e.g. WebSocket)
desktop.setSender((data: Uint8Array) => ws.send(data));

// Attach to a canvas element
const canvas = document.getElementById('remote-screen') as HTMLCanvasElement;
desktop.attach(canvas);

// Optional: intercept clipboard operations
desktop.setClipboardInterceptor((type, sendKeys) => {
  if (type === 'paste') {
    navigator.clipboard.readText().then(text => {
      desktop.sendClipboardText(text);
    });
  } else {
    sendKeys(); // fall through for copy/cut
  }
});

// Switch to a secondary display
desktop.onDisplayListChange((displays) => {
  const secondary = displays.find(d => !d.primary);
  if (secondary) desktop.switchDisplay(secondary.id);
});

// Clean up
desktop.detach();
```
