MeshTunnel provides a WebSocket-based communication layer for establishing secure tunnels to MeshCentral nodes, handling authentication, protocol negotiation, and bidirectional data transfer with automatic reconnection capabilities.

## Key Components

### Types
- **`TunnelState`**: Connection state enumeration (0=stopped, 1=connecting, 2=open, 3=connected)
- **`TunnelOptions`**: Configuration options including terminal dimensions and login requirements
- **`TunnelCallbacks`**: Event handlers for data, state changes, and control messages

### Main Class
- **`MeshTunnel`**: Core tunnel management class with connection lifecycle, message handling, and data transmission methods

## Key Features

- **Automatic Reconnection**: Handles connection failures and authentication errors with intelligent retry logic
- **Protocol Handshake**: Manages MeshCentral protocol negotiation and initialization
- **Binary/Text Support**: Handles both string and binary data transmission
- **Latency Monitoring**: Built-in RTT (round-trip time) measurement with periodic pings
- **Control Channel**: Dedicated channel (102938) for tunnel control messages and console output

## Usage Example

```typescript
import { MeshTunnel, TunnelOptions } from './meshcentral-tunnel'

// Terminal tunnel configuration
const options: TunnelOptions = {
  cols: 80,
  rows: 24,
  requireLogin: true
}

// Create and start tunnel
const tunnel = new MeshTunnel({
  authCookie: 'your-auth-cookie',
  nodeId: 'target-node-id',
  protocol: 1, // Terminal protocol
  options,
  onData: (data) => console.log('Received:', data),
  onStateChange: (state) => console.log('State:', state),
  onConsoleMessage: (msg) => console.log('Console:', msg),
  onRequestPairing: (relayId) => establishPairing(relayId)
})

tunnel.start()

// Send terminal input
tunnel.sendText('ls -la\r')

// Send binary data
tunnel.sendBinary(new Uint8Array([0x1b, 0x5b, 0x41])) // Up arrow

// Check connection status
if (tunnel.isConnected()) {
  tunnel.sendText('echo "Connected!"\r')
}

// Cleanup
tunnel.stop()
```
