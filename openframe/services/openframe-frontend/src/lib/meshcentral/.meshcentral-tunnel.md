Manages secure tunneling connections to MeshCentral devices through WebSocket communication. Handles the tunnel lifecycle including handshake, authentication, reconnection, and bidirectional data transfer for remote access protocols.

## Key Components

- **MeshTunnel**: Main tunnel management class with connection lifecycle control
- **TunnelState**: Connection state enum (0: stopped, 1: connecting, 2: open, 3: connected)
- **TunnelOptions**: Configuration options for terminal dimensions and login requirements
- **TunnelCallbacks**: Event handlers for data, state changes, and control messages

## Usage Example

```typescript
import { MeshTunnel } from './meshcentral-tunnel'

// Create a tunnel for remote terminal access
const tunnel = new MeshTunnel({
  authCookie: 'session_cookie_value',
  nodeId: 'device_node_id',
  protocol: 1, // Terminal protocol
  options: {
    cols: 80,
    rows: 24,
    requireLogin: true
  },
  onData: (data) => {
    // Handle incoming terminal data
    console.log('Received:', data)
  },
  onStateChange: (state) => {
    console.log('Tunnel state:', state)
  },
  onConsoleMessage: (msg) => {
    console.log('Console:', msg)
  },
  onRequestPairing: (relayId) => {
    // Send pairing request via control connection
    sendPairingRequest(relayId)
  }
})

// Start the tunnel connection
tunnel.start()

// Send commands to remote device
tunnel.sendText('ls -la\n')

// Clean up when done
tunnel.stop()
```

The tunnel automatically handles reconnection, authentication, and maintains a persistent connection for real-time communication with remote devices through the MeshCentral infrastructure.
