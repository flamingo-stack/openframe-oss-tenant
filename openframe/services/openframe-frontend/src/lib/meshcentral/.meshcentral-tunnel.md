Provides a WebSocket-based tunnel client for establishing secure remote connections through MeshCentral's relay infrastructure. The class manages connection states, handles authentication, and provides callbacks for data processing and state changes.

## Key Components

**Types:**
- `TunnelState` - Connection state enumeration (0-3: stopped, connecting, open, connected)
- `TunnelOptions` - Configuration options including terminal dimensions and login requirements
- `TunnelCallbacks` - Event handlers for data, state changes, and control messages

**Main Class:**
- `MeshTunnel` - Core tunnel client with connection management, protocol handling, and data transmission

**Key Methods:**
- `start()` - Initiates tunnel connection with authentication and protocol negotiation
- `stop()` - Gracefully closes tunnel and cleans up resources
- `sendText()/sendBinary()` - Send data through the tunnel
- `sendCtrl()` - Send control messages for tunnel management

## Usage Example

```typescript
import { MeshTunnel } from './meshcentral-tunnel'

const tunnel = new MeshTunnel({
  authCookie: 'session-cookie',
  nodeId: 'target-device-id',
  protocol: 1, // Terminal protocol
  options: {
    cols: 80,
    rows: 24,
    requireLogin: true
  },
  onData: (data) => {
    console.log('Received:', data)
  },
  onStateChange: (state) => {
    console.log('Tunnel state:', state)
  },
  onConsoleMessage: (msg) => {
    console.log('Console:', msg)
  },
  onRequestPairing: (relayId) => {
    // Handle pairing request for reconnection
  }
})

// Start the tunnel connection
tunnel.start()

// Send commands
tunnel.sendText('ls -la\n')

// Check connection status
if (tunnel.isConnected()) {
  tunnel.sendText('echo "Hello World"\n')
}

// Clean shutdown
tunnel.stop()
```

The class automatically handles WebSocket reconnection, authentication token refresh, and maintains a heartbeat for connection monitoring.
