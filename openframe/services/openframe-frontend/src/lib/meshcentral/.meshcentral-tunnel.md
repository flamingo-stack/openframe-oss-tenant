Manages secure WebSocket tunnels to MeshCentral remote devices for terminal/desktop connections. Handles connection lifecycle, authentication, protocol negotiation, and bidirectional data streaming with automatic reconnection capabilities.

## Key Components

**Types:**
- `TunnelState` - Connection state enum (0=stopped, 1=connecting, 2=open, 3=connected)
- `TunnelOptions` - Configuration for tunnel features (terminal dimensions, login requirements)
- `TunnelCallbacks` - Event handlers for data, state changes, and control messages

**Main Class:**
- `MeshTunnel` - Primary tunnel management class with connection handling, message routing, and protocol negotiation

**Key Methods:**
- `start()` - Initiates WebSocket connection with authentication
- `stop()` - Cleanly closes tunnel and clears resources
- `sendText()/sendBinary()` - Send data through the tunnel
- `sendCtrl()` - Send control/management messages
- `reconnect()` - Force reconnection attempt

## Usage Example

```typescript
import { MeshTunnel, TunnelOptions } from './meshcentral-tunnel'

// Terminal connection
const terminalOptions: TunnelOptions = {
  cols: 80,
  rows: 24,
  requireLogin: true
}

const tunnel = new MeshTunnel({
  authCookie: 'session_cookie_value',
  nodeId: 'target_device_id',
  protocol: 1, // Terminal protocol
  options: terminalOptions,
  onData: (data) => {
    // Handle incoming terminal data
    console.log('Received:', data)
  },
  onStateChange: (state) => {
    console.log('Tunnel state:', state) // 0-3
  },
  onConsoleMessage: (msg) => {
    console.log('Console:', msg)
  },
  onRequestPairing: (relayId) => {
    // Handle pairing request on reconnect
    console.log('Pairing requested for:', relayId)
  }
})

// Start connection
tunnel.start()

// Send commands
tunnel.sendText('ls -la\n')

// Check status
if (tunnel.isConnected()) {
  console.log('Tunnel ready')
}

// Clean shutdown
tunnel.stop()
```
