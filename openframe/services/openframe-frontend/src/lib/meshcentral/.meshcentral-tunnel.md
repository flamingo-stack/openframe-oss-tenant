WebSocket-based tunnel implementation for establishing secure connections to MeshCentral remote nodes. Manages connection lifecycle, authentication, handshake protocols, and bidirectional data transmission with automatic reconnection capabilities.

## Key Components

**Types:**
- `TunnelState` - Connection state enumeration (0: stopped, 1: connecting, 2: open, 3: connected)
- `TunnelOptions` - Optional configuration for terminal dimensions and login requirements
- `TunnelCallbacks` - Event handlers for data, state changes, and control messages

**Main Class:**
- `MeshTunnel` - Core tunnel management class with connection handling and message routing

## Usage Example

```typescript
import { MeshTunnel } from './meshcentral-tunnel'

const tunnel = new MeshTunnel({
  authCookie: 'session_cookie_value',
  nodeId: 'device_node_id',
  protocol: 1,
  options: { cols: 80, rows: 24 },
  onData: (data) => console.log('Received:', data),
  onStateChange: (state) => console.log('State:', state),
  onConsoleMessage: (msg) => console.log('Console:', msg),
  onRequestPairing: (relayId) => console.log('Pair with:', relayId)
})

// Start the tunnel connection
tunnel.start()

// Send text data
tunnel.sendText('ls -la\n')

// Send binary data
tunnel.sendBinary(new Uint8Array([1, 2, 3]))

// Check connection status
if (tunnel.isConnected()) {
  console.log('Tunnel is ready')
}

// Clean shutdown
tunnel.stop()
```

The class handles WebSocket lifecycle management, authentication token injection, handshake negotiation, latency monitoring, and automatic reconnection with exponential backoff.
