Manages a WebSocket-based relay tunnel to a MeshCentral node, handling the full connection lifecycle including handshake, protocol negotiation, latency probing, and message routing.

## Key Components

**Types**
- `TunnelState` — Numeric union `0–3` representing `stopped`, `connecting`, `open`, and `connected`
- `TunnelOptions` — Optional terminal dimensions (`cols`, `rows`) and login requirements
- `TunnelCallbacks` — Event hooks for data, state changes, binary frames, control messages, and pairing requests

**Class: `MeshTunnel`**
| Method | Description |
|---|---|
| `start()` | Builds the relay WebSocket URL and initiates connection via `WebSocketManager` |
| `stop()` | Sends a close control frame, disconnects, and resets state |
| `reconnect()` | Triggers reconnection if not already connected |
| `sendText(text)` | Sends a UTF-8 text frame |
| `sendBinary(data)` | Sends a binary frame |
| `sendCtrl(obj)` | Serialises and sends a JSON control-channel message |
| `getState()` | Returns current `TunnelState` |
| `isConnected()` | Returns `true` when state is `3` (fully handshaked) |
| `updateAuthCookie(cookie)` | Replaces the auth credential used on reconnect |
| `getRelayId()` | Returns the random relay session ID |

**Private internals**
- `initializeHandshake()` — Sends an RTT probe on open and starts a 10-second latency interval
- `onMessage()` — Routes incoming frames: handshake tokens (`c`/`cr`), tilde-prefixed data, JSON control messages, and raw binary

## Usage Example

```typescript
const tunnel = new MeshTunnel({
  authCookie: 'abc123',
  nodeId: 'node//abc',
  protocol: 2,
  options: { cols: 220, rows: 50 },
  onData: (data) => terminal.write(data),
  onStateChange: (state) => console.log('Tunnel state:', state),
  onBinaryData: (buf) => handleBinary(buf),
  onCtrlMessage: (msg) => console.log('Ctrl:', msg),
  onBeforeReconnect: async () => await refreshSession(),
});

tunnel.start();

// Later — clean up
tunnel.stop();
```
