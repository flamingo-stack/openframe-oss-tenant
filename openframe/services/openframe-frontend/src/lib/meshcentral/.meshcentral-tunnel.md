WebSocket-based tunnel interface for MeshCentral remote access connections, providing state management, authentication, and protocol handling for terminal/desktop sessions.

## Key Components

- **`TunnelState`** - Enum type defining connection states (0: stopped, 1: connecting, 2: open, 3: connected)
- **`TunnelOptions`** - Configuration interface for terminal dimensions and login requirements
- **`MeshTunnel`** - Main class managing WebSocket connections, handshakes, and data transmission
- **Connection Management** - Automatic reconnection, authentication token handling, and state transitions
- **Protocol Support** - Binary/text data handling with control message processing

## Usage Example

```typescript
import { MeshTunnel } from './meshcentral-tunnel'

const tunnel = new MeshTunnel({
  authCookie: 'session-cookie',
  nodeId: 'device-node-id',
  protocol: 1, // Terminal protocol
  options: { cols: 80, rows: 24 },
  onData: (data) => {
    // Handle terminal output or binary data
    console.log('Received:', data)
  },
  onStateChange: (state) => {
    console.log('Tunnel state:', state)
  },
  onConsoleMessage: (msg) => {
    console.log('Console:', msg)
  },
  onRequestPairing: (relayId) => {
    // Re-establish pairing after reconnection
    sendPairingCommand(relayId)
  }
})

// Start the tunnel connection
tunnel.start()

// Send terminal input
tunnel.sendText('ls -la\n')

// Send binary data
tunnel.sendBinary(new Uint8Array([0x1b, 0x5b, 0x41])) // Up arrow

// Check connection status
if (tunnel.isConnected()) {
  console.log('Tunnel ready')
}

// Clean shutdown
tunnel.stop()
```
