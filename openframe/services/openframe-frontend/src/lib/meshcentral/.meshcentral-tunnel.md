Manages a WebSocket tunnel connection to a MeshCentral relay endpoint, handling the full lifecycle of connection, handshake, message routing, and latency monitoring for terminal or desktop protocol sessions.

## Key Components

**Types**
- `TunnelState` — Numeric union (`0`–`3`) representing `stopped`, `connecting`, `open`, and `connected` states
- `TunnelOptions` — Optional terminal dimensions (`cols`, `rows`) and `requireLogin` flag
- `TunnelCallbacks` — Event hooks for data, state changes, binary frames, control messages, pairing requests, and reconnect lifecycle

**`MeshTunnel` class**
- `start()` — Builds the `meshrelay.ashx` WebSocket URL (with auth cookie and optional dev token), instantiates `WebSocketManager`, and begins connection
- `stop()` — Sends a close control frame, disconnects the WebSocket, and resets state
- `reconnect()` — Triggers reconnection if the tunnel is not currently connected
- `onMessage()` *(private)* — Routes incoming messages: handles handshake (`c`/`cr`), tilde-prefixed data frames, JSON control channel (`102938`) messages (ping/pong, console, RTT), and binary `ArrayBuffer` frames
- `initializeHandshake()` *(private)* — Sends an initial RTT probe and starts a 10-second latency timer
- `sendText()` / `sendBinary()` / `sendCtrl()` — Public send methods for text frames, binary frames, and JSON control objects
- `updateAuthCookie()` — Refreshes the auth credential without restarting the tunnel

## Usage Example

```typescript
const tunnel = new MeshTunnel({
  authCookie: 'abc123',
  nodeId: 'node//abc...',
  protocol: 1, // SSH terminal
  options: { cols: 220, rows: 50 },
  onData: (data) => terminal.write(data),
  onStateChange: (state) => console.log('Tunnel state:', state),
  onBinaryData: (buf) => handleBinary(buf),
  onCtrlMessage: (msg) => console.log('Ctrl:', msg),
  onRequestPairing: (relayId) => controlChannel.sendPairing(relayId),
  onBeforeReconnect: async () => await refreshSession(),
});

tunnel.start();

// Later...
tunnel.sendText('ls -la\r');
console.log(tunnel.isConnected()); // true when state === 3

tunnel.stop();
```
