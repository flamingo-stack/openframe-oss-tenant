A WebSocket tunnel implementation for MeshCentral remote access that manages bidirectional communication with automatic reconnection, authentication, and protocol handling for terminal and desktop connections.

## Key Components

**Types:**
- `TunnelState` - Connection state enum (0: stopped, 1: connecting, 2: open, 3: connected)
- `TunnelOptions` - Configuration options for terminal dimensions and login requirements
- `TunnelCallbacks` - Event handlers for data, state changes, and control messages

**Main Class:**
- `MeshTunnel` - Core tunnel class managing WebSocket connection, handshake protocol, and message routing

**Key Methods:**
- `start()` - Establishes WebSocket connection with authentication
- `stop()` - Cleanly closes connection and clears timers
- `sendText()` / `sendBinary()` - Send data through the tunnel
- `sendCtrl()` - Send JSON control messages
- `reconnect()` - Manually trigger reconnection

## Usage Example

```typescript
import { MeshTunnel, TunnelOptions } from './meshcentral-tunnel'

const options: TunnelOptions = {
  cols: 80,
  rows: 24,
  requireLogin: false
}

const tunnel = new MeshTunnel({
  authCookie: 'your-auth-cookie',
  nodeId: 'target-node-id',
  protocol: 1, // 1 for terminal, 2 for desktop
  options,
  onData: (data) => {
    console.log('Received:', data)
  },
  onStateChange: (state) => {
    console.log('State changed:', state)
  },
  onConsoleMessage: (msg) => {
    console.log('Console:', msg)
  },
  onRequestPairing: (relayId) => {
    // Handle pairing request on reconnect
    console.log('Pairing requested for:', relayId)
  }
})

// Start the tunnel
tunnel.start()

// Send terminal commands
tunnel.sendText('ls -la\n')

// Send binary data
const binaryData = new Uint8Array([1, 2, 3, 4])
tunnel.sendBinary(binaryData)

// Check connection status
if (tunnel.isConnected()) {
  console.log('Tunnel is ready')
}

// Clean shutdown
tunnel.stop()
```

The tunnel automatically handles MeshCentral's handshake protocol, maintains keep-alive pings, and provides robust reconnection with authentication token refresh for seamless remote access sessions.
