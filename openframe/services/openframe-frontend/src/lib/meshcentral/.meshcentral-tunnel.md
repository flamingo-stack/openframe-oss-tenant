Manages WebSocket-based tunneling connections to MeshCentral devices for remote access protocols like terminal sessions and desktop sharing. The tunnel handles connection state management, authentication, handshaking, and bidirectional data transfer with automatic reconnection capabilities.

## Key Components

- **`MeshTunnel`** - Main tunnel class that manages WebSocket connections to MeshCentral relay endpoints
- **`TunnelState`** - State enumeration (0=stopped, 1=connecting, 2=open, 3=connected)
- **`TunnelOptions`** - Configuration options for terminal dimensions and authentication requirements
- **`TunnelCallbacks`** - Event handlers for data, state changes, and control messages

## Usage Example

```typescript
import { MeshTunnel } from './meshcentral-tunnel'

// Create a terminal tunnel to a MeshCentral node
const tunnel = new MeshTunnel({
  authCookie: 'session_cookie',
  nodeId: 'mesh_node_id',
  protocol: 1, // Terminal protocol
  options: {
    cols: 80,
    rows: 24,
    requireLogin: true
  },
  onData: (data) => {
    // Handle terminal output
    console.log('Received:', data)
  },
  onStateChange: (state) => {
    console.log('Tunnel state:', state)
  },
  onConsoleMessage: (msg) => {
    console.log('Console:', msg)
  }
})

// Start the tunnel connection
tunnel.start()

// Send terminal input
tunnel.sendText('ls -la\n')

// Check connection status
if (tunnel.isConnected()) {
  tunnel.sendBinary(new Uint8Array([13, 10])) // Send CRLF
}

// Clean shutdown
tunnel.stop()
```

The tunnel automatically handles authentication token injection, WebSocket reconnection with exponential backoff, and protocol-specific handshaking with the MeshCentral relay service.
