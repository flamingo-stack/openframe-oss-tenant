Manages a MeshCentral relay tunnel (`meshrelay.ashx`) over WebSocket, handling the connection lifecycle, protocol handshake, latency pinging, and bidirectional data transfer for terminal and desktop sessions.

## Key Components

**`TunnelState`** — Numeric union type representing tunnel lifecycle stages:
- `0` stopped · `1` connecting · `2` open (WebSocket up, handshake pending) · `3` connected (handshake complete, data flowing)

**`TunnelOptions`** — Optional terminal hints (`cols`, `rows`, `requireLogin`) sent to the relay during handshake.

**`TunnelCallbacks`** — Event hooks for data, binary frames, control channel messages, state changes, pairing requests, and pre-reconnect async logic.

**`MeshTunnel`** — Primary class encapsulating the full tunnel lifecycle.

| Method | Description |
|---|---|
| `start()` | Builds the relay URL, creates a `WebSocketManager`, initiates connection |
| `stop()` | Sends a close control frame, tears down the WebSocket, resets state |
| `reconnect()` | Re-initiates the WebSocket if currently disconnected |
| `sendText(text)` | Sends a UTF-8 text frame |
| `sendBinary(data)` | Sends a binary frame |
| `sendCtrl(obj)` | Serializes and sends a JSON control-channel message (`ctrlChannel: 102938`) |
| `getState()` | Returns the current `TunnelState` |
| `isConnected()` | Returns `true` only when state is `3` (handshake complete) |
| `updateAuthCookie(cookie)` | Hot-swaps the auth credential without reconnecting |

## Usage Example

```typescript
const tunnel = new MeshTunnel({
  authCookie: 'abc123',
  nodeId: 'node//...',
  protocol: 1, // 1 = terminal, 2 = desktop
  options: { cols: 220, rows: 50 },
  onData: (data) => terminal.write(data as string),
  onBinaryData: (buf) => terminal.write(buf),
  onStateChange: (state) => console.log('Tunnel state:', state),
  onConsoleMessage: (msg) => console.warn('[relay]', msg),
  onRequestPairing: (relayId) => controlChannel.pair(relayId),
  onBeforeReconnect: async () => await refreshAuthToken(),
});

tunnel.start();

// Later — send terminal input
tunnel.sendText('ls -la\r');

// Teardown
tunnel.stop();
```

> **Handshake flow:** On WebSocket open, the relay sends `'c'` or `'cr'`. The tunnel responds with optional `type: 'options'` control message then the protocol number as a plain string, advancing state to `3`.
