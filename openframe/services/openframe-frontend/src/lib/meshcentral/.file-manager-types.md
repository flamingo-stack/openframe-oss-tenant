Type definitions for the MeshCentral file manager module, covering connection states, file entries, transfer operations, and manager configuration.

## Key Components

- **`FileConnectionState`** — Union type for WebSocket tunnel lifecycle states (`disconnected` → `connecting` → `connected_to_server` → `connected_end_to_end` | `failed`)
- **`FileEntry`** — Represents a remote filesystem entry (file, directory, or link) with MeshCentral's compact single-letter field names
- **`DirectoryListing`** — Server response shape for `ls` (list directory) actions
- **`FileOperationRequest` / `FileOperationResponse`** — Generic request/response envelopes for file operations (rename, delete, mkdir, etc.)
- **`UploadRequest` / `DownloadRequest`** — Typed payloads for binary transfer operations, including hash-based deduplication (`uploadhash`) and chunked download ACK protocol
- **`FileTransferProgress`** — Progress tracking payload for upload/download UI updates
- **`BinaryHeader` / `BinaryAccumulator`** — Low-level binary protocol structures for reassembling chunked binary WebSocket frames
- **`FileManagerOptions`** — Configuration and callback interface for instantiating a file manager session
- **`MeshRights` / `SiteRights`** — Bitmask constants for MeshCentral permission checks (file access, block access)

## Usage Example

```typescript
import type {
  FileManagerOptions,
  FileEntry,
  FileConnectionState,
  FileTransferProgress,
} from './file-manager-types';

const options: FileManagerOptions = {
  nodeId: 'node//abc123',
  isRemote: true,
  onStateChange: (state: FileConnectionState) => {
    if (state === 'connected_end_to_end') console.log('Tunnel ready');
  },
  onDirectoryChange: (files: FileEntry[]) => {
    const dirs = files.filter(f => f.t === 2);
    console.log('Directories:', dirs.map(d => d.n));
  },
  onTransferProgress: (progress: FileTransferProgress) => {
    console.log(`${progress.file}: ${progress.progress}%`);
  },
};

// Check permissions before rendering file UI
import { MeshRights, SiteRights } from './file-manager-types';

const canAccessFiles = (meshRights: number, siteRights: number): boolean =>
  !(meshRights & MeshRights.NOFILES) &&
  ((meshRights & MeshRights.SERVERFILES) !== 0 ||
   (siteRights & SiteRights.FILEACCESS) !== 0);
```
