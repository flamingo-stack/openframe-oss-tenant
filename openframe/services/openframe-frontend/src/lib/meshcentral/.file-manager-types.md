Type definitions for the MeshCentral File Manager module, covering connection states, file entries, transfer operations, and manager configuration options.

## Key Components

### Types & Enums

| Name | Description |
|------|-------------|
| `FileConnectionState` | Union type representing WebSocket tunnel states: `disconnected`, `connecting`, `connected_to_server`, `connected_end_to_end`, `failed` |
| `FileEntry` | Represents a remote file/directory with metadata (name, type, size, modified date, path) |
| `DirectoryListing` | Server response payload for `ls` actions |
| `FileTransferProgress` | Progress snapshot for in-flight uploads or downloads |
| `BinaryHeader` / `BinaryAccumulator` | Low-level structures for parsing MeshCentral binary protocol frames |
| `FileManagerOptions` | Full configuration interface for instantiating a file manager session |

### Constants

| Name | Value | Description |
|------|-------|-------------|
| `MeshRights.SERVERFILES` | `0x20` | Grants server-level file access |
| `MeshRights.NOFILES` | `0x400` | Blocks file access (negative permission) |
| `SiteRights.FILEACCESS` | `0x08` | Grants site-level file access |

## Usage Example

```typescript
import type {
  FileManagerOptions,
  FileEntry,
  FileConnectionState,
  FileTransferProgress,
} from './file-manager-types';
import { MeshRights, SiteRights } from './file-manager-types';

const options: FileManagerOptions = {
  nodeId: 'node//abc123',
  isRemote: true,
  onStateChange: (state: FileConnectionState) => {
    console.log('Connection state:', state);
  },
  onDirectoryChange: (files: FileEntry[]) => {
    const dirs = files.filter(f => f.t === 2);
    console.log('Directories:', dirs.map(d => d.n));
  },
  onTransferProgress: (progress: FileTransferProgress) => {
    console.log(`${progress.file}: ${progress.progress}%`);
  },
};

// Check permissions before initializing
const hasAccess =
  (userMeshRights & MeshRights.SERVERFILES) !== 0 &&
  (userMeshRights & MeshRights.NOFILES) === 0 &&
  (userSiteRights & SiteRights.FILEACCESS) !== 0;
```
