Type definitions and constants for the MeshCentral File Manager module, covering connection states, file entries, transfer operations, and manager configuration.

## Key Components

- **`FileConnectionState`** — Union type representing WebSocket tunnel lifecycle: `disconnected` → `connecting` → `connected_to_server` → `connected_end_to_end` → `failed`
- **`FileEntry`** — Remote filesystem node with name, type (link/directory/file), size, modified date, and optional metadata
- **`DirectoryListing`** — Server response shape for `ls` actions containing an array of `FileEntry` objects
- **`FileOperationRequest / Response`** — Generic envelope types for file system commands with extensible extra fields
- **`UploadRequest / DownloadRequest`** — Typed payloads for initiating file transfers, including hash-based deduplication support
- **`FileTransferProgress`** — Progress tracking structure with byte counters and direction flag
- **`BinaryHeader / BinaryAccumulator`** — Low-level structures for parsing raw binary protocol frames
- **`FileManagerOptions`** — Configuration and callback interface passed when constructing a file manager instance
- **`MeshRights / SiteRights`** — Bitmask constants controlling file access permissions at node and site level

## Usage Example

```typescript
import type {
  FileManagerOptions,
  FileConnectionState,
  FileEntry,
  FileTransferProgress,
} from './file-manager-types';

const options: FileManagerOptions = {
  nodeId: 'node//abc123',
  isRemote: true,
  onStateChange: (state: FileConnectionState) => {
    console.log('Connection state:', state);
  },
  onDirectoryChange: (files: FileEntry[]) => {
    const dirs = files.filter(f => f.t === 2);
    console.log('Directories:', dirs.map(d => d.n));
  },
  onTransferProgress: (progress: FileTransferProgress) => {
    console.log(`${progress.file}: ${progress.progress}%`);
  },
};

// Check permission before allowing file operations
const canAccessFiles = (meshRights: number): boolean =>
  !(meshRights & MeshRights.NOFILES) &&
  Boolean(meshRights & MeshRights.SERVERFILES);
```
