Manages chunked file uploads to MeshCentral, handling hash-based deduplication, resume support, and progress reporting over a WebSocket-style message channel.

## Key Components

### `UploadTask`
Interface representing an in-progress or completed upload, tracking offset, status, hash, and byte counters.

**Status lifecycle:** `pending` → `hashing` → `uploading` → `completed` | `failed` | `cancelled`

### `FileUploader`
Main class managing the full upload lifecycle with a 64KB chunk size.

| Method | Description |
|--------|-------------|
| `uploadFile(file, remotePath, checkHash?)` | Initiates an upload; computes SHA-384 hash for files ≤ 100MB when `checkHash` is `true` |
| `handleHashResponse(id, exists, resumeOffset?)` | Skips upload if file already exists on remote; resumes from offset otherwise |
| `handleUploadStart(id, offset?)` | Begins chunk transmission from a given byte offset |
| `handleUploadAck(id, confirmedOffset?)` | Advances progress and sends the next chunk on ACK |
| `handleUploadDone / handleUploadError` | Marks task as completed or failed |
| `cancelUpload(id)` | Cancels and removes a task |
| `clearCompleted / clearAll` | Cleanup helpers for finished tasks |
| `hasActiveUpload / getActiveUploadId` | Query active upload state |

## Usage Example

```typescript
const uploader = new FileUploader(
  (data) => socket.send(data),          // sendMessage
  (progress) => console.log(progress),  // onProgress
);

// Start upload (hash check enabled by default)
const uploadId = await uploader.uploadFile(file, '/remote/path/');

// Wire up incoming MeshCentral messages
uploader.handleHashResponse(uploadId, false);         // file not found, begin upload
uploader.handleUploadStart(uploadId, 0);              // server ready at offset 0
uploader.handleUploadAck(uploadId, 65536);            // chunk confirmed, next chunk sent
uploader.handleUploadDone(uploadId);                  // server signals completion

// Clean up after transfers
uploader.clearCompleted();
```

> **Note:** `sendMessage` is expected to return `false` when the send buffer is full; the uploader will retry after a 25ms back-off automatically.
