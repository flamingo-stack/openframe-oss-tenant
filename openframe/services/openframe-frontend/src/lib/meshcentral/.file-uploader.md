Manages file uploads to MeshCentral, handling chunked transfers, SHA-384 hash verification, resume support, and progress reporting.

## Key Components

### `UploadTask` Interface
Represents a single upload job with fields for tracking state (`status`), byte offsets (`nextOffset`, `bytesUploaded`, `pendingBytes`), optional hash, and append/resume metadata.

### `FileUploader` Class
Core upload manager with a 64 KB chunk size and an internal `Map<string, UploadTask>` store.

| Method | Description |
|---|---|
| `uploadFile(file, remotePath, checkHash?)` | Initiates an upload; computes SHA-384 hash for files ≤ 100 MB before sending |
| `calculateFileHash(file)` | Returns hex-encoded SHA-384 digest via `crypto.subtle` |
| `handleHashResponse(id, exists, offset?)` | Skips upload if file already exists remotely, or resumes from offset |
| `handleUploadStart(id, offset?)` | Called when server acknowledges upload initiation; begins chunk stream |
| `handleUploadAck(id, confirmedOffset?)` | Advances progress and sends next chunk after server acknowledgment |
| `handleUploadDone / handleUploadError` | Marks task as completed or failed |
| `cancelUpload(id)` | Cancels and removes a task |
| `clearCompleted / clearAll` | Housekeeping helpers |

## Usage Example

```typescript
const uploader = new FileUploader(
  (data) => websocket.send(data) ?? true,
  (progress) => console.log(`${progress.file}: ${progress.progress}%`)
);

// Start upload (hash-checked by default)
const uploadId = await uploader.uploadFile(file, '/remote/path/');

// Wire server responses to the uploader
onServerMessage((msg) => {
  if (msg.action === 'uploadstart') uploader.handleUploadStart(msg.reqid, msg.offset);
  if (msg.action === 'uploadack')   uploader.handleUploadAck(msg.reqid, msg.offset);
  if (msg.action === 'uploadhash')  uploader.handleHashResponse(msg.reqid, msg.exists, msg.offset);
  if (msg.action === 'uploaddone')  uploader.handleUploadDone(msg.reqid);
});
```

> Chunk payloads are prefixed with a `0x00` byte when the first byte is `0x00` or `0x7b` (`{`) to prevent the binary frame from being misinterpreted as a JSON message by MeshCentral.
