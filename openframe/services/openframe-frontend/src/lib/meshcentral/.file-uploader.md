Handles chunked file uploads to MeshCentral agents, including SHA-384 hash-based deduplication, resume support, and progress reporting over a WebSocket-style message channel.

## Key Components

### `UploadTask` interface
Tracks per-upload state including byte offsets, chunk progress, status lifecycle (`pending` → `hashing` → `uploading` → `completed` | `failed` | `cancelled`), and optional hash/error metadata.

### `FileUploader` class
- **`uploadFile(file, remotePath, checkHash?)`** — Initiates an upload. For files ≤ 100 MB, computes a SHA-384 hash first and sends an `uploadhash` request to detect duplicates or resume points before transferring data.
- **`calculateFileHash(file)`** — Computes a hex-encoded SHA-384 digest using the Web Crypto API.
- **`handleHashResponse(uploadId, exists, resumeOffset?)`** — Skips upload if file already exists remotely; otherwise begins chunked transfer, optionally resuming at `resumeOffset`.
- **`handleUploadAck(uploadId, confirmedOffset?)`** — Advances byte-tracking after each acknowledged chunk and triggers the next chunk send.
- **`sendNextChunk(uploadId)`** — Slices the `File` into 64 KB chunks and sends each as an `ArrayBuffer`, retrying with a 25 ms delay if the transport is busy.
- **`prepareChunkPayload(chunk)`** — Prefixes chunks starting with `0x00` or `0x7b` (`{`) with a null byte to avoid MeshCentral protocol ambiguity.
- **`cancelUpload / clearCompleted / clearAll`** — Lifecycle management for upload tasks.

## Usage Example

```typescript
const uploader = new FileUploader(
  (data) => ws.send(data),       // sendMessage
  (progress) => console.log(progress) // onProgress
);

// Start upload with hash deduplication
const uploadId = await uploader.uploadFile(file, '/remote/path/');

// Wire up WebSocket message handler responses
uploader.handleHashResponse(uploadId, false);       // not a duplicate
uploader.handleUploadStart(uploadId, 0);             // server ready
uploader.handleUploadAck(uploadId, 65536);           // chunk confirmed
uploader.handleUploadDone(uploadId);                 // server finalized
```
