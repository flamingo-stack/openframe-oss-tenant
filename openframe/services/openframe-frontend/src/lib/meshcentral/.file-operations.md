Utility class for constructing MeshCentral file operation request objects and handling cross-platform (Windows/Unix) path manipulation.

## Key Components

**`FileOperations`** — Main class with the following methods:

| Method | Description |
|--------|-------------|
| `generateRequestId()` | Generates a unique request ID using timestamp + counter |
| `detectSeparator(path)` | Detects path separator (`\` or `/`) from path string |
| `joinPath(base, segment)` | Joins path segments respecting OS separator |
| `parsePath(path)` | Splits a path string into segments array |
| `buildPath(segments)` | Reconstructs a Unix path from segments |
| `getParentPath(path)` | Returns the parent directory of a given path |
| `sanitizeName(name)` | Strips invalid filesystem characters from a name |
| `validatePath(path)` | Rejects paths containing `..` or `.` traversal |
| `createListDirectoryRequest(path)` | Builds an `ls` request |
| `createMakeDirRequest(path, folderName)` | Builds a `mkdir` request |
| `createRenameRequest(...)` | Builds a `rename` request |
| `createDeleteRequest(...)` | Builds an `rm` request with optional recursive flag |
| `createCopyRequest(...)` | Builds a `copy` request |
| `createMoveRequest(...)` | Builds a `move` request |
| `createZipRequest(...)` | Builds a `zip` request |
| `createUnzipRequest(...)` | Builds an `unzip` request |
| `createSearchRequest(path, filter)` | Builds a `findfile` request with wildcard wrapping |
| `createCancelSearchRequest(reqid)` | Builds a `cancelfindfile` request |
| `createGetFileRequest(...)` | Builds a `get` (read file) request |
| `createSetFileRequest(...)` | Builds a `set` (write file) request with base64 encoding |

## Usage Example

```typescript
const ops = new FileOperations();

// List directory contents
const listReq = ops.createListDirectoryRequest('C:\\Users\\Admin');

// Create a folder
const mkdirReq = ops.createMakeDirRequest('C:\\Users\\Admin', 'NewFolder');

// Search for files with a filter
const searchReq = ops.createSearchRequest('/var/log', '.log');

// Delete multiple files recursively
const deleteReq = ops.createDeleteRequest('/tmp', ['file1.txt', 'file2.txt'], true);

// Write a file (content is base64-encoded internally)
const writeReq = ops.createSetFileRequest('/etc', 'config.json', '{"key":"value"}');

// Navigate to parent
const parent = ops.getParentPath('C:\\Users\\Admin\\Documents');
// → 'C:\\Users\\Admin'
```
