Constructs and manages `FileOperationRequest` objects for MeshCentral remote file system interactions, handling cross-platform path logic for both Windows and Unix-style paths.

## Key Components

**`FileOperations` class**

| Method | Description |
|--------|-------------|
| `generateRequestId()` | Creates unique request IDs using timestamp + counter |
| `joinPath(base, segment)` | Joins path segments with OS-aware separator detection |
| `parsePath(path)` | Splits a path string into an array of segments |
| `buildPath(segments)` | Reconstructs a Unix-style path from segments |
| `getParentPath(path)` | Returns the parent directory, handles Windows drive roots |
| `sanitizeName(name)` | Strips invalid filesystem characters from file/folder names |
| `validatePath(path)` | Rejects paths containing `..` or `.` traversal segments |
| `createListDirectoryRequest()` | Builds an `ls` action request |
| `createMakeDirRequest()` | Builds a `mkdir` action request |
| `createRenameRequest()` | Builds a `rename` action request |
| `createDeleteRequest()` | Builds an `rm` action request, supports recursive deletion |
| `createCopyRequest()` | Builds a `copy` action request |
| `createMoveRequest()` | Builds a `move` action request |
| `createZipRequest()` | Builds a `zip` action request |
| `createUnzipRequest()` | Builds an `unzip` action request |
| `createSearchRequest()` | Builds a `findfile` request with wildcard wrapping |
| `createCancelSearchRequest()` | Cancels an in-progress search by request ID |
| `createGetFileRequest()` | Builds a `get` action to retrieve file content |
| `createSetFileRequest()` | Builds a `set` action with base64-encoded file content |

## Usage Example

```typescript
const ops = new FileOperations();

// List a remote directory
const listReq = ops.createListDirectoryRequest('C:\\Users\\Admin\\Documents');

// Create a subfolder
const mkdirReq = ops.createMakeDirRequest('C:\\Users\\Admin', 'NewFolder');

// Move files between directories
const moveReq = ops.createMoveRequest(
  'C:\\Users\\Admin\\Downloads',
  'C:\\Users\\Admin\\Documents',
  ['report.pdf', 'notes.txt']
);

// Search with filter (auto-wraps as *query*)
const searchReq = ops.createSearchRequest('/home/user', 'config');

// Navigate to parent path
const parent = ops.getParentPath('C:\\Users\\Admin\\Documents');
// → 'C:\Users\Admin'
```
