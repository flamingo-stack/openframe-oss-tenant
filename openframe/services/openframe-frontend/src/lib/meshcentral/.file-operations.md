Constructs and manages `FileOperationRequest` objects for MeshCentral file system interactions, handling cross-platform path manipulation for both Unix (`/`) and Windows (`\`) path formats.

## Key Components

**`FileOperations` class**

- `generateRequestId()` — Produces unique request IDs using timestamp + counter
- `joinPath(base, segment)` — Cross-platform path joining with auto-detected separator
- `detectSeparator(path)` — Infers `\` or `/` from path format (supports Windows drive letters)
- `parsePath(path)` / `buildPath(segments)` — Converts between path strings and segment arrays
- `getParentPath(path)` — Navigates up one directory level, handles drive roots
- `sanitizeName(name)` — Strips illegal filesystem characters
- `validatePath(path)` — Rejects traversal attempts (`..`, `.`)

**Request factory methods**

| Method | MeshCentral action |
|---|---|
| `createListDirectoryRequest` | `ls` |
| `createMakeDirRequest` | `mkdir` |
| `createRenameRequest` | `rename` |
| `createDeleteRequest` | `rm` |
| `createCopyRequest` / `createMoveRequest` | `copy` / `move` |
| `createZipRequest` / `createUnzipRequest` | `zip` / `unzip` |
| `createSearchRequest` / `createCancelSearchRequest` | `findfile` / `cancelfindfile` |
| `createGetFileRequest` / `createSetFileRequest` | `get` / `set` (base64 encoded) |

## Usage Example

```typescript
const ops = new FileOperations();

// List a remote directory
const listReq = ops.createListDirectoryRequest('C:\\Users\\Admin\\Documents');
// { action: 'ls', reqid: 'req-1234567890-1', path: 'C:\\Users\\Admin\\Documents' }

// Create a subfolder
const mkdirReq = ops.createMakeDirRequest('/var/log', 'app-logs');
// { action: 'mkdir', reqid: 'req-...', path: '/var/log/app-logs' }

// Search with wildcard expansion
const searchReq = ops.createSearchRequest('/home/user', '.log');
// { action: 'findfile', ..., filter: '*.log*' }

// Navigate to parent
const parent = ops.getParentPath('C:\\Users\\Admin\\Documents');
// 'C:\Users\Admin'

// Safe filename
const safe = ops.sanitizeName('file<name>:test');
// 'filenametest'
```
