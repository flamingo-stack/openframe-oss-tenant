Handles streaming binary data from the MeshCentral File Manager protocol by accumulating incoming chunks and parsing framed payloads based on a 4-byte length/final-flag header.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `FileBinaryProtocol` | `class` | Stateful binary frame accumulator and parser |
| `push()` | `method` | Appends incoming `ArrayBuffer` data and triggers chunk callbacks |
| `consume()` | `method` (private) | Drains the internal buffer, emitting complete frames |
| `readHeader()` | `method` (private) | Decodes a 4-byte frame header — bits 1–31 as payload length, bit 0 as final flag |
| `reset()` | `method` | Clears the internal accumulation buffer |
| `isBinaryData()` | `method` | Utility to detect `ArrayBuffer` or `Uint8Array` instances |

## Protocol Header Format

```text
Bits 31–1  → Payload length (right-shifted uint32)
Bit 0      → Final flag (1 = last chunk in transfer)
```

## Usage Example

```typescript
const protocol = new FileBinaryProtocol();

// Called on each WebSocket binary message
websocket.onmessage = (event: MessageEvent) => {
  if (protocol.isBinaryData(event.data)) {
    protocol.push(event.data, (payload, isFinal) => {
      processFileChunk(payload);

      if (isFinal) {
        console.log('File transfer complete');
        protocol.reset();
      }
    });
  }
};
```

> **Note:** `push()` is safe to call with partial or concatenated frames — the internal buffer accumulates data until a complete frame is available before invoking the callback.
