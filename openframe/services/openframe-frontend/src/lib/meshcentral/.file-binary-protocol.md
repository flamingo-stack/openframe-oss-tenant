Handles accumulation and framing of binary data chunks for the MeshCentral File Manager protocol, parsing a 4-byte little-endian header to extract payload length and a "final chunk" flag.

## Key Components

- **`FileBinaryProtocol`** — Stateful class that buffers incoming binary data and emits complete framed chunks via callback
- **`push(data, onChunk)`** — Appends new `ArrayBuffer` data to the internal buffer, triggering chunk extraction for each complete frame
- **`consume(onChunk)`** — Internal loop that reads frames while enough buffered bytes exist; invokes `onChunk(payload, isFinal)` per frame
- **`readHeader(headerBytes)`** — Decodes the 4-byte little-endian header: bits 1–31 = payload length, bit 0 = final-chunk flag
- **`reset()`** — Clears the internal accumulation buffer
- **`isBinaryData(data)`** — Utility to detect whether a value is an `ArrayBuffer` or `Uint8Array`

## Wire Format

```text
[4-byte LE header][payload bytes...]
 └─ bits 31..1: payload length
 └─ bit 0:      1 = final chunk, 0 = more follows
```

## Usage Example

```typescript
const protocol = new FileBinaryProtocol();

websocket.onmessage = (event) => {
  if (protocol.isBinaryData(event.data)) {
    protocol.push(event.data as ArrayBuffer, (payload, isFinal) => {
      // Process each complete frame
      handleFileChunk(payload);

      if (isFinal) {
        console.log('File transfer complete');
        protocol.reset();
      }
    });
  }
};
```

> **Note:** The protocol is fully streaming — partial frames are held in the internal buffer until enough bytes arrive to complete a frame, making it safe to use with fragmented WebSocket messages.
