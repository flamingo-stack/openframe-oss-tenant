Handles streaming binary data from the MeshCentral File Manager protocol by accumulating incoming chunks and parsing length-prefixed frames.

## Key Components

### `FileBinaryProtocol` class

- **`push(data, onChunk)`** — Appends incoming `ArrayBuffer` data to an internal accumulator, then attempts to parse and emit complete frames via the `onChunk` callback
- **`consume(onChunk)`** *(private)* — Drains the internal buffer in a loop, extracting frames as long as enough bytes are available
- **`readHeader(headerBytes)`** *(private)* — Decodes a 4-byte little-endian header; bits 1–31 encode the payload length, bit 0 is the `final` flag
- **`reset()`** — Clears the internal buffer, useful when reinitializing a connection
- **`isBinaryData(data)`** — Type-guard utility that detects `ArrayBuffer` and `Uint8Array` instances

## Frame Format

```text
[ 4-byte header ][ payload bytes... ]
  └─ bits[31:1] = payload length
  └─ bit[0]     = final frame flag (1 = last chunk)
```

## Usage Example

```typescript
const protocol = new FileBinaryProtocol();

websocket.onmessage = (event) => {
  if (protocol.isBinaryData(event.data)) {
    protocol.push(event.data, (payload, isFinal) => {
      processFileChunk(payload);
      if (isFinal) {
        console.log('File transfer complete');
        protocol.reset();
      }
    });
  }
};
```
