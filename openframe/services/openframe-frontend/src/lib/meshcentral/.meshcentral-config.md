Provides MeshCentral WebSocket connection configuration by resolving base URLs, schemes, and credentials from the runtime environment.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `MeshUrlParts` | Type | Shape for base host/port and WebSocket scheme (`ws` / `wss`) |
| `getMeshBaseHostPort()` | Function | Resolves and strips protocol prefixes from the tenant host URL, returning a clean `host:port/path` string or `null` |
| `getMeshWsScheme()` | Function | Returns `wss` (always; browser `https:` check defaults to `wss`) |
| `buildWsUrl(path)` | Function | Constructs a full WebSocket URL by combining scheme, base host, and path — falls back to `window.location.host` or `localhost` |
| `MESH_USER` | Constant | MeshCentral login user, sourced from `NEXT_PUBLIC_MESH_USER` |
| `MESH_PASS` | Constant | MeshCentral login password, sourced from `NEXT_PUBLIC_MESH_PASS` |

## Usage Example

```typescript
import { buildWsUrl, getMeshBaseHostPort, MESH_USER, MESH_PASS } from './meshcentral-config';

// Build a WebSocket URL for a MeshCentral relay path
const wsUrl = buildWsUrl('/control.ashx');
// → "wss://tenant.example.com/ws/tools/meshcentral-server/control.ashx"

// Inspect the resolved base host
const base = getMeshBaseHostPort();
// → "tenant.example.com/ws/tools/meshcentral-server"

// Use credentials for MeshCentral authentication
console.log(MESH_USER); // "mesh@openframe.io" (or env override)
console.log(MESH_PASS); // "meshpass@1234"    (or env override)
```

> **Note:** `MESH_USER` and `MESH_PASS` are exposed via `NEXT_PUBLIC_*` env vars. Ensure these are set appropriately in production — the hardcoded defaults are for local/development use only.
