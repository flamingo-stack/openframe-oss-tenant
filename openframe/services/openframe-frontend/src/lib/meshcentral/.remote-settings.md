Configuration management for MeshCentral remote desktop sessions, providing type-safe settings for quality, scaling, frame rate, and input behavior with WebSocket-based communication.

## Key Components

- **`RemoteSettingsConfig`** - TypeScript interface defining all remote desktop configuration options
- **`QUALITY_OPTIONS`** - Predefined JPEG quality levels from 10% to 100% (lossless)
- **`SCALING_OPTIONS`** - Display scaling percentages mapped to MeshCentral's internal values (256-2048)
- **`FRAME_RATE_OPTIONS`** - Frame rate presets from 2 FPS to 30 FPS with corresponding millisecond intervals
- **`RemoteDesktopSettings`** - Main class handling settings application via WebSocket binary protocol
- **`DEFAULT_SETTINGS`** - Balanced configuration preset (50% quality, 100% scaling, 10 FPS)

## Usage Example

```typescript
// Initialize with default settings
const remoteSettings = new RemoteDesktopSettings()

// Configure custom settings
const customConfig: RemoteSettingsConfig = {
  quality: 80,           // High quality
  scaling: 1024,         // 100% scaling
  frameRate: 'fast',     // 20 FPS
  swapMouseButtons: true,
  useRemoteKeyboardMap: false,
  invertScrollDirection: true
}

// Apply settings through WebSocket
remoteSettings.setWebSocket(websocketConnection)
remoteSettings.applySettings(customConfig)

// Estimate bandwidth usage
const estimatedKbps = remoteSettings.estimateBandwidth()
console.log(`Estimated bandwidth: ${estimatedKbps} KB/s`)
```

The class automatically encodes settings into MeshCentral's binary protocol format, using big-endian encoding for multi-byte values and proper command structure for real-time settings updates.
