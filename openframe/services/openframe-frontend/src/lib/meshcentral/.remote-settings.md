Configuration types, constants, and management class for MeshCentral Remote Desktop session settings, including image quality, display scaling, frame rate, and input behavior options.

## Key Components

- **`RemoteSettingsConfig`** — Interface defining all configurable session parameters: quality, scaling, frameRate, swapMouseButtons, useRemoteKeyboardMap, and invertScrollDirection
- **`QUALITY_OPTIONS`** — JPEG quality presets (10–100) mapped to human-readable labels
- **`SCALING_OPTIONS`** — MeshCentral display scaling values (256–2048) where `1024` = 100%
- **`FRAME_RATE_OPTIONS`** — FPS presets mapped to millisecond intervals (33ms–500ms)
- **`DEFAULT_SETTINGS`** — Sensible defaults: 50% quality, 100% scaling, 10 FPS
- **`RemoteDesktopSettings`** — Stateful class that manages settings and applies them over a WebSocket connection using MeshCentral's binary protocol (command `0x0005`)

## Usage Example

```typescript
import { RemoteDesktopSettings, DEFAULT_SETTINGS } from './remote-settings';

const remoteSettings = new RemoteDesktopSettings({
  ...DEFAULT_SETTINGS,
  quality: 80,
  frameRate: 'fast',
  scaling: 1024,
});

// Attach an active MeshCentral WebSocket
remoteSettings.setWebSocket(ws);

// Apply settings — sends a 10-byte binary command to MeshCentral
remoteSettings.applySettings();

// Estimate current bandwidth consumption in KB/s
const bandwidth = remoteSettings.estimateBandwidth();
console.log(`Estimated bandwidth: ${bandwidth} KB/s`);

// Retrieve current config snapshot
const config = remoteSettings.getSettings();

// Resolve frame interval for a given frame rate label
const ms = RemoteDesktopSettings.getFrameRateMs('smooth'); // → 33
```

## Binary Protocol Notes

`applySettings()` sends a 10-byte big-endian `ArrayBuffer` over the WebSocket:

```text
Offset  Size  Description
------  ----  -----------
0       2     Command: 0x0005 (COMPRESSION)
2       2     Message size: 0x000A (10 bytes)
4       1     Encoding type: 1 (JPEG)
5       1     Quality: 1–100
6       2     Scaling factor (e.g. 1024 = 100%)
8       2     Frame timer in ms (e.g. 33 = 30 FPS)
```
