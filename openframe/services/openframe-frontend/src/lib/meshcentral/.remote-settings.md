Defines configuration types, constants, and the `RemoteDesktopSettings` class for managing MeshCentral remote desktop session parameters including image quality, scaling, and frame rate.

## Key Components

- **`RemoteSettingsConfig`** — Interface describing all configurable session parameters
- **`QUALITY_OPTIONS`** — JPEG quality presets mapped to percentage values (10–100)
- **`SCALING_OPTIONS`** — Display scaling presets mapped to MeshCentral internal values (256–2048)
- **`FRAME_RATE_OPTIONS`** — FPS presets mapped to frame interval in milliseconds (33–500ms)
- **`DEFAULT_SETTINGS`** — Baseline config: 50% quality, 100% scaling, 10 FPS
- **`RemoteDesktopSettings`** — Class that serializes settings into a 10-byte binary MeshCentral `COMPRESSION` command and sends it over WebSocket

## Usage Example

```typescript
import { RemoteDesktopSettings, DEFAULT_SETTINGS } from './remote-settings';

const remoteSettings = new RemoteDesktopSettings({
  ...DEFAULT_SETTINGS,
  quality: 80,
  scaling: 1024,
  frameRate: 'fast',
  swapMouseButtons: false,
  useRemoteKeyboardMap: false,
  invertScrollDirection: false,
});

// Attach an active MeshCentral WebSocket before applying
remoteSettings.setWebSocket(meshWebSocket);
remoteSettings.applySettings();

// Estimate current bandwidth usage
const kbps = remoteSettings.estimateBandwidth();
console.log(`Estimated bandwidth: ${kbps} KB/s`);

// Retrieve current settings snapshot
const current = remoteSettings.getSettings();

// Resolve frame interval for a given rate
const ms = RemoteDesktopSettings.getFrameRateMs('smooth'); // 33
```

## Notes

- `applySettings()` encodes settings as a big-endian `ArrayBuffer` per the MeshCentral protocol: command `0x0005`, 10 bytes total, with JPEG encoding type hardcoded to `1`
- `estimateBandwidth()` provides a rough KB/s estimate based on quality, scaling, and FPS — useful for UI feedback
- `swapMouseButtons`, `useRemoteKeyboardMap`, and `invertScrollDirection` are stored in config but applied client-side only (not sent in the binary frame)
