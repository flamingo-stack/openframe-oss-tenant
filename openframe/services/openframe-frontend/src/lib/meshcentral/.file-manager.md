Orchestrates MeshCentral remote file management operations by coordinating tunnel connections, directory listings, file transfers (upload/download), and search functionality through a WebSocket-based binary/JSON protocol.

## Key Components

| Export | Description |
|--------|-------------|
| `MeshCentralFileManager` | Main class managing file system operations over MeshCentral tunnels |

### Core State & Properties

| Property | Type | Description |
|----------|------|-------------|
| `state` | `FileConnectionState` | Current connection state: `disconnected` → `connecting` → `connected_to_server` → `connected_end_to_end` |
| `tunnel` | `MeshTunnel` | WebSocket tunnel to the remote node |
| `uploader` / `downloader` | `FileUploader` / `FileDownloader` | Handles chunked file transfers with progress callbacks |
| `pendingRequests` | `Map` | Tracks in-flight requests with resolve/reject/timeout entries |

### Key Methods

| Method | Description |
|--------|-------------|
| `connect()` | Initiates a remote tunnel session |
| `startRemoteTunnel()` | Establishes MeshTunnel with pairing, auth, and state handlers |
| `handleJsonMessage()` | Routes incoming JSON protocol messages (`ls`, `findfile`, `upload*`, etc.) |
| `handleBinaryMessage()` | Processes binary download chunks or fallback JSON payloads |
| `handleTunnelStateChange()` | Drives connection state machine and triggers initial directory load |
| `normalizeRequestedPath()` | Normalizes Unix-style paths to Windows-style (e.g., `/C:/` → `C:\`) |

## Usage Example

```typescript
import { MeshCentralFileManager } from './file-manager';

const manager = new MeshCentralFileManager({
  isRemote: true,
  nodeId: 'node123',
  controlClient: meshControlClient,
  onStateChange: (state) => console.log('State:', state),
  onTransferProgress: (progress) => console.log('Progress:', progress),
  onError: (err) => console.error('File error:', err),
});

await manager.connect();
// Tunnel reaches 'connected_end_to_end' → automatically loads root directory
```
