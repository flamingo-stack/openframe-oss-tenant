Orchestrates MeshCentral file management over WebSocket tunnels, coordinating directory listings, file uploads, downloads, and search operations for remote nodes.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `MeshCentralFileManager` | `class` | Main file manager class managing tunnel lifecycle, file operations, and protocol handling |

### Core Private Members

| Member | Description |
|--------|-------------|
| `tunnel` | `MeshTunnel` WebSocket tunnel for end-to-end communication |
| `fileOps` | `FileOperations` — rename, delete, mkdir, etc. |
| `uploader` | `FileUploader` — chunked upload with progress and hash verification |
| `downloader` | `FileDownloader` — binary chunk download with cancellation support |
| `binaryProtocol` | `FileBinaryProtocol` — binary frame parsing |
| `errorHandler` | `FileErrorHandler` — normalizes and forwards errors |

### Key Methods

| Method | Description |
|--------|-------------|
| `connect()` | Initiates remote tunnel session via `MeshControlClient` |
| `loadDirectory(path)` | Requests directory listing for a given path |
| `handleJsonMessage(data)` | Routes JSON protocol messages (`ls`, `findfile`, `upload*`, etc.) |
| `handleBinaryMessage(data)` | Routes binary frames to active downloader |
| `handleTunnelStateChange(state)` | Manages connection state transitions and initial directory load |
| `normalizeRequestedPath(path)` | Normalizes Unix-style paths to Windows backslash format |

## Usage Example

```typescript
import { MeshCentralFileManager } from './file-manager';
import { MeshControlClient } from './meshcentral-control';

const controlClient = new MeshControlClient({ /* config */ });

const fm = new MeshCentralFileManager({
  isRemote: true,
  nodeId: 'node123',
  controlClient,
  onStateChange: state => console.log('State:', state),
  onTransferProgress: progress => console.log('Progress:', progress),
  onError: err => console.error('Error:', err),
});

await fm.connect();
// Tunnel is now live; initial directory load fires automatically
// on 'connected_end_to_end' state
```
