Defines and returns the sidebar navigation items for the OpenFrame application, conditionally including items based on app mode and feature flags.

## Key Components

### `getNavigationItems(pathname: string): NavigationSidebarItem[]`

The sole export. Accepts the current `pathname` and returns an ordered array of `NavigationSidebarItem` objects used to render the sidebar.

**Always included (non-auth-only mode):**

| ID | Label | Path |
|----|-------|------|
| `dashboard` | Dashboard | `/dashboard` |
| `organizations` | Customers | `/customers` |
| `devices` | Devices | `/devices` |
| `scripts` | Scripts | `/scripts` |
| `monitoring` | Monitoring | `/monitoring` |
| `logs` | Logs | `/logs-page` |

**SaaS tenant mode only** (`isSaasTenantMode()`): Tickets, Mingo

**Feature flagged** (`featureFlags.knowledgeBase.enabled()`): Knowledge Base (`section: 'secondary'`)

**Always appended last:** Settings (`section: 'secondary'`)

Returns `[]` when `isAuthOnlyMode()` is `true`.

## Usage Example

```typescript
import { getNavigationItems } from './navigation-config';

// Inside a layout or sidebar component
const items = getNavigationItems(window.location.pathname);

// Items with section: 'secondary' render in the bottom sidebar area
const primaryItems = items.filter(item => !item.section);
const secondaryItems = items.filter(item => item.section === 'secondary');
```

## Notes

- `isActive` is derived from `pathname.startsWith(item.path)`, with `logs` also matching `/log-details`
- App mode helpers (`isAuthOnlyMode`, `isSaasTenantMode`) and `featureFlags` are imported from local config — update those to control visibility
