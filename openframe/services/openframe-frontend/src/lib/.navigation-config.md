Defines and returns the sidebar navigation item configuration for the OpenFrame frontend, conditionally including items based on app mode and feature flags.

## Key Components

### `getNavigationItems(pathname: string): NavigationSidebarItem[]`
The sole export — builds and returns an ordered array of `NavigationSidebarItem` objects, each with an `id`, `label`, `icon`, `path`, `isActive` state derived from the current `pathname`, and an optional `section` (`'secondary'`).

**Always included** (when not in auth-only mode):
| ID | Label | Path |
|----|-------|------|
| `dashboard` | Dashboard | `/dashboard` |
| `organizations` | Customers | `/customers` |
| `devices` | Devices | `/devices` |
| `scripts` | Scripts | `/scripts` |
| `monitoring` | Monitoring | `/monitoring` |
| `logs` | Logs | `/logs-page` |

**SaaS tenant mode only** (`isSaasTenantMode()`): `tickets`, `mingo`

**Feature-flagged** (`featureFlags.knowledgeBase.enabled()`): `knowledge-base` (secondary section)

**Always appended last**: `settings` (secondary section)

> Returns `[]` immediately when `isAuthOnlyMode()` is `true`.

## Usage Example

```typescript
import { getNavigationItems } from './navigation-config';

// In a sidebar component
const items = getNavigationItems(router.pathname);

items.forEach(({ id, label, path, isActive, section }) => {
  console.log(`[${section ?? 'primary'}] ${label} → ${path} (active: ${isActive})`);
});
// [primary] Dashboard → /dashboard (active: false)
// [primary] Customers → /customers (active: true)
// ...
// [secondary] Settings → /settings (active: false)
```
