Defines and returns the sidebar navigation items for the OpenFrame frontend, conditionally including items based on app mode and feature flags.

## Key Components

**`getNavigationItems(pathname: string): NavigationSidebarItem[]`**
The sole export. Accepts the current `pathname` to derive `isActive` state for each item, then builds and returns the navigation array. Returns an empty array when running in auth-only mode.

**Navigation Sections**

| Section | Items | Condition |
|---|---|---|
| Primary (always) | Dashboard, Customers, Devices, Scripts, Monitoring, Logs | Non-auth mode |
| Primary (SaaS only) | Tickets, Mingo | `isSaasTenantMode()` |
| Secondary (feature flag) | Knowledge Base | `featureFlags.knowledgeBase.enabled()` |
| Secondary (always) | Settings | Non-auth mode |

## Usage Example

```typescript
import { getNavigationItems } from './navigation-config';

// Inside a sidebar/layout component
const pathname = usePathname(); // e.g. Next.js hook
const navItems = getNavigationItems(pathname);

// Render primary and secondary sections separately
const primaryItems = navItems.filter(item => item.section !== 'secondary');
const secondaryItems = navItems.filter(item => item.section === 'secondary');
```

## Notes

- Items without an explicit `section` property default to the primary nav section
- Active state is resolved via `pathname.startsWith(item.path)` — the Logs item additionally matches `/log-details` sub-routes
- SaaS-tenant-only items (`tickets`, `mingo`) are appended after the core items, preserving display order
