A client-side Zustand store and utility functions for detecting and signaling when a user's subscription trial has expired via GraphQL error classifications.

## Key Components

- **`useSubscriptionLockSignal`** — Zustand store managing trial expiry state with two actions:
  - `trialExpiredFromErrors` — boolean flag indicating trial expiry was detected
  - `markTrialExpired()` — sets the flag to `true`
  - `reset()` — clears the flag back to `false`

- **`hasTrialExpiredClassification(errors)`** — Pure helper that returns `true` if any GraphQL error in the array carries the `SUBSCRIPTION_TRIAL_EXPIRED` classification extension.

- **`detectTrialExpiredFromGraphqlErrors(errors)`** — Side-effectful helper that calls `markTrialExpired()` on the store when trial expiry is detected in a GraphQL error response.

## Usage Example

```typescript
// Detecting trial expiry after a GraphQL mutation/query
import {
  detectTrialExpiredFromGraphqlErrors,
  useSubscriptionLockSignal,
} from './subscription-lock-signal';

// In a GraphQL response handler
const { errors } = await client.query({ query: MY_QUERY });
detectTrialExpiredFromGraphqlErrors(errors);

// In a React component — react to the lock signal
function AppShell() {
  const trialExpired = useSubscriptionLockSignal(s => s.trialExpiredFromErrors);
  const reset = useSubscriptionLockSignal(s => s.reset);

  if (trialExpired) {
    return <SubscriptionExpiredModal onDismiss={reset} />;
  }

  return <MainLayout />;
}
```

> **Note:** `detectTrialExpiredFromGraphqlErrors` uses `getState()` directly, making it safe to call outside of React components (e.g., in Apollo error links or fetch interceptors).
