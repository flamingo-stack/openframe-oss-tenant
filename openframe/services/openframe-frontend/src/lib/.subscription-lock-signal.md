A client-side Zustand store and utility functions for detecting and signaling subscription trial expiration based on GraphQL error classifications.

## Key Components

- **`useSubscriptionLockSignal`** — Zustand store tracking whether a trial-expired state has been detected, exposing `trialExpiredFromErrors`, `markTrialExpired()`, and `reset()` actions
- **`hasTrialExpiredClassification`** — Pure function that checks if any GraphQL error in an array carries the `SUBSCRIPTION_TRIAL_EXPIRED` classification extension
- **`detectTrialExpiredFromGraphqlErrors`** — Side-effectful function that inspects GraphQL errors and automatically triggers `markTrialExpired()` on the store when the classification is found
- **`TRIAL_EXPIRED_CLASSIFICATION`** — Internal constant (`"SUBSCRIPTION_TRIAL_EXPIRED"`) used to match against GraphQL error extensions

## Usage Example

```typescript
import {
  useSubscriptionLockSignal,
  detectTrialExpiredFromGraphqlErrors,
  hasTrialExpiredClassification,
} from './subscription-lock-signal';

// In a GraphQL response handler
const { data, errors } = await client.query({ query: MY_QUERY });
detectTrialExpiredFromGraphqlErrors(errors); // auto-signals if trial expired

// In a React component
function MyComponent() {
  const trialExpired = useSubscriptionLockSignal(s => s.trialExpiredFromErrors);
  const reset = useSubscriptionLockSignal(s => s.reset);

  if (trialExpired) {
    return <SubscriptionExpiredBanner onDismiss={reset} />;
  }

  return <MainContent />;
}

// Manual check without triggering store
if (hasTrialExpiredClassification(errors)) {
  console.warn('Trial has expired');
}
```

> **Note:** `detectTrialExpiredFromGraphqlErrors` uses `getState()` for imperative access, making it safe to call outside React components (e.g., in Apollo links or fetch middleware).
