Utility module providing locale-aware date and time formatting functions using the `Intl.DateTimeFormat` API.

## Key Components

| Export | Returns | Format |
|---|---|---|
| `formatDate` | `string` | `MM/DD/YY` (en-US) |
| `formatTime` | `string` | Locale-aware short time (e.g. `2:30 PM`) |
| `formatDateTime` | `string` | Combined date + time |
| `splitDateAndTimeWithSeconds` | `{ date, time }` | Date + 24-hour time with seconds (`HH:MM:SS`) |

**Type:** `DateInput = string | number | Date` — all functions accept any of these input forms.

## Usage Example

```typescript
import {
  formatDate,
  formatTime,
  formatDateTime,
  splitDateAndTimeWithSeconds,
} from './format-date';

const ts = '2024-06-15T14:35:10Z';

formatDate(ts);                   // "06/15/24"
formatTime(ts);                   // "2:35 PM"
formatDateTime(ts);               // "06/15/24 2:35 PM"
formatDateTime(Date.now());       // works with numeric timestamps too

const { date, time } = splitDateAndTimeWithSeconds(ts);
// date → "06/15/24"
// time → "14:35:10"
```

> **Note:** `formatTime` uses the runtime's default locale for short time style, so the AM/PM vs 24-hour rendering may vary by environment. Use `splitDateAndTimeWithSeconds` when a consistent 24-hour HH:MM:SS output is required.
