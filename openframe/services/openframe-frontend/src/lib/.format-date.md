Utility module for formatting dates and times using the `Intl.DateTimeFormat` API. Accepts flexible `DateInput` types and returns locale-aware formatted strings.

## Key Components

| Export | Returns | Format |
|--------|---------|--------|
| `formatDate` | `string` | `MM/DD/YY` (en-US) |
| `formatTime` | `string` | Locale short time (e.g. `3:45 PM`) |
| `formatDateTime` | `string` | Combined date + time |
| `splitDateAndTimeWithSeconds` | `{ date, time }` | Date + 24h time with seconds (`HH:mm:ss`) |

**Type:** `DateInput = string | number | Date` — all formatters accept any of these input forms.

## Usage Example

```typescript
import {
  formatDate,
  formatTime,
  formatDateTime,
  splitDateAndTimeWithSeconds,
} from './format-date';

const now = new Date();

formatDate(now);                    // "01/15/25"
formatTime(now);                    // "3:45 PM"
formatDateTime(now);                // "01/15/25 3:45 PM"
formatDateTime('2025-01-15T15:45:00Z'); // accepts ISO string
formatDateTime(1737000000000);          // accepts Unix timestamp (ms)

const { date, time } = splitDateAndTimeWithSeconds(now);
// date → "01/15/25"
// time → "15:45:30"
```

> **Note:** `formatTime` uses the runtime's default locale for time display (e.g. `3:45 PM` in en-US, `15:45` in en-GB). All other formatters use explicit locale/format settings for consistent output across environments.
