Utility module providing locale-aware date and time formatting functions using the native `Intl.DateTimeFormat` API.

## Key Components

- **`DateInput`** — Type alias accepting `string`, `number`, or `Date` as input
- **`formatDate`** — Formats a date as `MM/DD/YY` (en-US locale)
- **`formatTime`** — Formats a time as a short string using the system locale (e.g., `3:45 PM`)
- **`formatDateTime`** — Combines `formatDate` and `formatTime` into a single string
- **`splitDateAndTimeWithSeconds`** — Returns a `{ date, time }` object where `time` is 24-hour format with seconds (e.g., `14:30:05`)

## Usage Example

```typescript
import {
  formatDate,
  formatTime,
  formatDateTime,
  splitDateAndTimeWithSeconds,
} from './format-date';

const input = new Date('2024-07-15T14:30:05');

formatDate(input);
// → "07/15/24"

formatTime(input);
// → "2:30 PM"  (varies by system locale)

formatDateTime(input);
// → "07/15/24 2:30 PM"

splitDateAndTimeWithSeconds(input);
// → { date: "07/15/24", time: "14:30:05" }

// Also accepts strings and timestamps
formatDate('2024-07-15');
formatDate(1720000000000);
```

> **Note:** `formatTime` uses the system/browser locale (`undefined`), so the output may vary across environments. All other formatters use fixed locales (`en-US` / `en-GB`) for consistent output.
