Utility function for building absolute image URLs from relative paths, handling various URL formats and automatically adding API prefixes for the current tenant host.

## Key Components

- **`getFullImageUrl()`** - Main utility function that converts relative image paths to absolute URLs with proper API prefixes

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Convert relative path to full URL
const fullUrl = getFullImageUrl('/uploads/avatar.jpg')
// Returns: "https://tenant.flamingo.run/api/uploads/avatar.jpg"

// Handle various input formats
getFullImageUrl('avatar.jpg')           // "https://tenant.flamingo.run/api/avatar.jpg"
getFullImageUrl('/api/uploads/avatar')  // "https://tenant.flamingo.run/api/uploads/avatar"
getFullImageUrl('https://cdn.example.com/image.jpg') // "https://cdn.example.com/image.jpg" (unchanged)
getFullImageUrl(null)                   // undefined

// Commonly used for image src attributes
const imageElement = `<img src="${getFullImageUrl(user.avatar)}" alt="User avatar" />`
```

The function handles null/undefined inputs gracefully, preserves existing absolute URLs, and automatically constructs proper API URLs for relative paths using the current tenant host configuration.
