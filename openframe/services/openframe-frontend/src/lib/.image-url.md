Utility function for constructing complete image URLs by combining relative paths with the tenant host API base URL.

## Key Components

- **`getFullImageUrl`** - Main export that converts relative image paths to absolute URLs with proper API prefix handling

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Returns undefined for null/undefined
const noImage = getFullImageUrl(null) // undefined

// Preserves full URLs
const fullUrl = getFullImageUrl('https://example.com/image.jpg')
// Returns: 'https://example.com/image.jpg'

// Adds tenant host to API paths
const apiPath = getFullImageUrl('/api/uploads/image.png')
// Returns: 'https://tenant.flamingo.run/api/uploads/image.png'

// Adds API prefix to absolute paths
const absolutePath = getFullImageUrl('/uploads/image.png')
// Returns: 'https://tenant.flamingo.run/api/uploads/image.png'

// Adds API prefix and leading slash to relative paths
const relativePath = getFullImageUrl('uploads/image.png')
// Returns: 'https://tenant.flamingo.run/api/uploads/image.png'
```

The function intelligently handles different URL formats: it preserves existing full URLs, adds the tenant host to API-prefixed paths, and automatically adds both the API prefix and tenant host to relative paths. This ensures consistent image URL formatting across the Flamingo platform.
