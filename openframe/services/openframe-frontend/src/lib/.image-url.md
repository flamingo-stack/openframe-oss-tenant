A utility function that converts relative image URLs to absolute URLs with proper API base URL prefixes for the Flamingo platform.

## Key Components

- **`getFullImageUrl(imageUrl)`** - Main export function that intelligently handles URL conversion based on input format
- **Runtime Environment Integration** - Uses `runtimeEnv.tenantHostUrl()` to get the current tenant's base URL
- **Smart URL Detection** - Automatically detects if URLs are already absolute or need API prefix addition

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Convert relative paths to full URLs
const avatarUrl = getFullImageUrl('/uploads/avatar.jpg')
// Returns: "https://tenant.flamingo.run/api/uploads/avatar.jpg"

const profileImage = getFullImageUrl('images/profile.png')
// Returns: "https://tenant.flamingo.run/api/images/profile.png"

// Already absolute URLs pass through unchanged
const externalImage = getFullImageUrl('https://example.com/logo.png')
// Returns: "https://example.com/logo.png"

// Handle null/undefined gracefully
const missingImage = getFullImageUrl(null)
// Returns: undefined

// API prefixed paths get tenant host added
const apiImage = getFullImageUrl('/api/files/document.pdf')
// Returns: "https://tenant.flamingo.run/api/files/document.pdf"
```

This utility ensures consistent image URL formatting across the Flamingo platform, handling various input formats while maintaining compatibility with both relative paths and absolute URLs.
