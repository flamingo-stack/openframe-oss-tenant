Utility function for converting relative image paths to fully qualified URLs using the tenant's API base URL.

## Key Components

- **`getFullImageUrl`** - Main export function that normalizes image URLs by adding the tenant host and API prefix when needed

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Convert relative paths to full URLs
const avatarUrl = getFullImageUrl('/uploads/avatar.jpg')
// Returns: "https://tenant.flamingo.run/api/uploads/avatar.jpg"

const imageUrl = getFullImageUrl('images/logo.png')
// Returns: "https://tenant.flamingo.run/api/images/logo.png"

// Already full URLs are returned unchanged
const externalUrl = getFullImageUrl('https://example.com/image.jpg')
// Returns: "https://example.com/image.jpg"

// API prefixed paths get tenant host added
const apiUrl = getFullImageUrl('/api/files/document.pdf')
// Returns: "https://tenant.flamingo.run/api/files/document.pdf"

// Handles null/undefined gracefully
const noUrl = getFullImageUrl(null)
// Returns: undefined
```

The function intelligently handles different URL formats: absolute URLs are returned as-is, paths with `/api/` prefix get the tenant host prepended, and relative paths get both the tenant host and `/api/` prefix added automatically.
