A utility function for converting relative image paths to fully qualified URLs using the tenant's host configuration from the runtime environment.

## Key Components

- **`getFullImageUrl(imageUrl)`** - Main export that transforms image URLs by adding the appropriate API base URL prefix based on the input format

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Handle various URL formats
const relativeUrl = getFullImageUrl('/uploads/avatar.jpg')
// Returns: "https://tenant.example.com/api/uploads/avatar.jpg"

const apiUrl = getFullImageUrl('/api/files/image.png') 
// Returns: "https://tenant.example.com/api/files/image.png"

const absoluteUrl = getFullImageUrl('https://external.com/image.jpg')
// Returns: "https://external.com/image.jpg" (unchanged)

const noSlashUrl = getFullImageUrl('assets/logo.svg')
// Returns: "https://tenant.example.com/api/assets/logo.svg"

const nullUrl = getFullImageUrl(null)
// Returns: undefined
```

The function intelligently handles different URL formats:
- Returns `undefined` for null/empty inputs
- Preserves absolute URLs (http/https) unchanged  
- Adds tenant host prefix for relative URLs
- Ensures proper `/api/` path formatting based on input structure

This is commonly used in OpenFrame for normalizing image URLs across different components while maintaining compatibility with both local development and production tenant environments.
