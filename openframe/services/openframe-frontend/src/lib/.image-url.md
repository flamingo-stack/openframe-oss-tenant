A utility function that converts relative image paths to fully qualified URLs using the tenant's host configuration, ensuring proper API routing for image resources.

## Key Components

- **`getFullImageUrl()`** - Main export function that transforms image URLs into fully qualified URLs with proper API prefixing

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Relative path without leading slash
const relativeUrl = getFullImageUrl('images/profile.jpg')
// Returns: "https://tenant.example.com/api/images/profile.jpg"

// Path with leading slash but no API prefix
const rootPath = getFullImageUrl('/uploads/avatar.png')
// Returns: "https://tenant.example.com/api/uploads/avatar.png"

// Already has API prefix
const apiPath = getFullImageUrl('/api/files/logo.svg')
// Returns: "https://tenant.example.com/api/files/logo.svg"

// Already a full URL (passthrough)
const fullUrl = getFullImageUrl('https://external.com/image.jpg')
// Returns: "https://external.com/image.jpg"

// Null/undefined input
const noImage = getFullImageUrl(null)
// Returns: undefined
```

The function handles various URL formats and automatically adds the tenant host and API prefix when needed, while preserving existing full URLs and gracefully handling null/undefined inputs.
