Utility function for converting relative image URLs to fully qualified URLs with proper API base prefixes based on tenant configuration.

## Key Components

- **`getFullImageUrl(imageUrl)`** - Main export that transforms relative image paths into complete URLs
- **Runtime Environment Integration** - Uses `runtimeEnv.tenantHostUrl()` for dynamic base URL resolution
- **Smart URL Detection** - Handles various input formats (absolute URLs, API-prefixed paths, relative paths)

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Convert relative path to full URL
const profileImage = getFullImageUrl('/uploads/profile.jpg')
// Returns: "https://tenant.flamingo.run/api/uploads/profile.jpg"

// Handle API-prefixed paths
const apiImage = getFullImageUrl('/api/images/logo.png')
// Returns: "https://tenant.flamingo.run/api/images/logo.png"

// Pass through absolute URLs unchanged
const externalImage = getFullImageUrl('https://example.com/image.jpg')
// Returns: "https://example.com/image.jpg"

// Handle null/undefined gracefully
const missingImage = getFullImageUrl(null)
// Returns: undefined
```

The function intelligently handles different URL formats:
- **Absolute URLs** (`http://`, `https://`) are returned unchanged
- **API-prefixed paths** (`/api/...`) get the tenant host prepended
- **Relative paths** with leading slash get both tenant host and `/api/` prefix
- **Relative paths** without leading slash get full prefix with proper slash handling
- **Null/undefined** inputs return `undefined` for safe chaining
