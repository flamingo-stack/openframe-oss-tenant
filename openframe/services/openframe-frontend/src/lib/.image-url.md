A utility function for normalizing image URLs to work with the Flamingo platform's API endpoints, handling various URL formats and ensuring proper tenant-aware URL construction.

## Key Components

- **getFullImageUrl()** - Main utility function that converts relative image paths to fully qualified URLs using the tenant's host configuration

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Relative path without leading slash
const url1 = getFullImageUrl('uploads/avatar.jpg')
// Returns: 'https://tenant.flamingo.run/api/uploads/avatar.jpg'

// Path with leading slash but no /api/ prefix
const url2 = getFullImageUrl('/images/logo.png') 
// Returns: 'https://tenant.flamingo.run/api/images/logo.png'

// Already has /api/ prefix
const url3 = getFullImageUrl('/api/files/document.pdf')
// Returns: 'https://tenant.flamingo.run/api/files/document.pdf'

// Already a full URL (returned as-is)
const url4 = getFullImageUrl('https://external.com/image.jpg')
// Returns: 'https://external.com/image.jpg'

// Null/undefined handling
const url5 = getFullImageUrl(null)
// Returns: undefined
```

The function intelligently handles different URL formats and automatically prepends the tenant host URL and `/api/` prefix when needed, making it safe to use with any image URL format in the Flamingo ecosystem.
