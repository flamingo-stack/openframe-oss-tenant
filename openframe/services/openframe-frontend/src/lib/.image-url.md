Utility function for converting relative image paths to fully qualified URLs using the tenant's API base URL from runtime configuration.

## Key Components

- **`getFullImageUrl()`** - Main export that transforms image URLs by adding the tenant host and API prefix when needed

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Convert relative paths to full URLs
const avatarUrl = getFullImageUrl('/uploads/avatar.jpg')
// Returns: "https://tenant.flamingo.run/api/uploads/avatar.jpg"

const profileImage = getFullImageUrl('images/profile.png')
// Returns: "https://tenant.flamingo.run/api/images/profile.png"

// Already prefixed paths work correctly
const existingApiUrl = getFullImageUrl('/api/files/image.jpg')
// Returns: "https://tenant.flamingo.run/api/files/image.jpg"

// Full URLs pass through unchanged
const externalImage = getFullImageUrl('https://example.com/image.jpg')
// Returns: "https://example.com/image.jpg"

// Handles null/undefined gracefully
const noImage = getFullImageUrl(null)
// Returns: undefined
```

The function intelligently handles different URL formats, ensuring consistent API routing while preserving external URLs and handling edge cases like missing values.
