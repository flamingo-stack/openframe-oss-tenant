Utility function for building complete image URLs by combining relative paths with the tenant API base URL.

## Key Components

- **`getFullImageUrl(imageUrl)`** - Main export that converts relative image paths to absolute URLs using the tenant host configuration

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Convert relative path to full URL
const fullUrl = getFullImageUrl('/uploads/avatar.jpg')
// Returns: "https://tenant.flamingo.run/api/uploads/avatar.jpg"

// Handle already absolute URLs
const absoluteUrl = getFullImageUrl('https://cdn.example.com/image.png')
// Returns: "https://cdn.example.com/image.png" (unchanged)

// Handle paths with existing /api/ prefix
const apiUrl = getFullImageUrl('/api/files/document.pdf')
// Returns: "https://tenant.flamingo.run/api/files/document.pdf"

// Handle null/undefined values
const emptyUrl = getFullImageUrl(null)
// Returns: undefined
```

The function intelligently handles various URL formats - absolute URLs are returned unchanged, while relative paths are properly prefixed with the tenant host and `/api/` path. This ensures consistent URL formatting across the Flamingo platform's multi-tenant architecture.
