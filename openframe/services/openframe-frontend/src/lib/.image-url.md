Resolves relative or absolute image URLs into fully-qualified URLs by prepending the configured tenant host and API base path as needed.

## Key Components

- **`getFullImageUrl(imageUrl)`** — Main export. Accepts a relative or absolute image URL (or `null`/`undefined`) and returns a normalized full URL string.

## Resolution Logic

| Input | Output |
|---|---|
| `null` / `undefined` / empty | `undefined` |
| `https://cdn.example.com/img.png` | Returned as-is |
| `/api/images/logo.png` | `{tenantHost}/api/images/logo.png` |
| `/images/logo.png` | `{tenantHost}/api/images/logo.png` |
| `images/logo.png` | `{tenantHost}/api/images/logo.png` |

## Usage Example

```typescript
import { getFullImageUrl } from './image-url';

// Relative path — resolves against tenant host
getFullImageUrl('avatars/user-123.png');
// → "https://tenant.flamingo.run/api/avatars/user-123.png"

// Already has /api/ prefix
getFullImageUrl('/api/uploads/logo.svg');
// → "https://tenant.flamingo.run/api/uploads/logo.svg"

// Absolute URL — returned unchanged
getFullImageUrl('https://cdn.example.com/banner.jpg');
// → "https://cdn.example.com/banner.jpg"

// Null/undefined — safe no-op
getFullImageUrl(null); // → undefined
getFullImageUrl(undefined); // → undefined
```

## Dependencies

- **`runtimeEnv.tenantHostUrl()`** — Sourced from `runtime-config`, provides the base URL for the current tenant (e.g., `https://tenant.flamingo.run`).
