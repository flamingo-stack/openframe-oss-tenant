Utility for constructing full image URLs with proper API base URL prefixing for multi-tenant applications. Handles various URL formats including relative paths, absolute URLs, and URLs with existing API prefixes.

## Key Components

- **`getFullImageUrl(imageUrl)`** - Main function that normalizes image URLs by adding tenant host and API prefix when needed

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Relative path - adds tenant host and API prefix
const fullUrl1 = getFullImageUrl('uploads/avatar.jpg')
// Returns: 'https://tenant.example.com/api/uploads/avatar.jpg'

// Path with leading slash - adds tenant host and API prefix
const fullUrl2 = getFullImageUrl('/uploads/avatar.jpg') 
// Returns: 'https://tenant.example.com/api/uploads/avatar.jpg'

// Already has API prefix - only adds tenant host
const fullUrl3 = getFullImageUrl('/api/uploads/avatar.jpg')
// Returns: 'https://tenant.example.com/api/uploads/avatar.jpg'

// Already full URL - returns unchanged
const fullUrl4 = getFullImageUrl('https://cdn.example.com/image.jpg')
// Returns: 'https://cdn.example.com/image.jpg'

// Null/undefined handling
const fullUrl5 = getFullImageUrl(null)
// Returns: undefined
```

The function intelligently detects URL formats and applies the appropriate transformation, ensuring consistent image URL handling across the application while supporting external CDN URLs.
