A utility function that normalizes image URLs by ensuring they have the proper API base URL prefix for the current tenant.

## Key Components

- **`getFullImageUrl()`** - Main export function that converts relative image URLs to absolute URLs with proper API prefix

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Relative URL without leading slash
const url1 = getFullImageUrl('uploads/avatar.jpg')
// Returns: "https://tenant.flamingo.run/api/uploads/avatar.jpg"

// Relative URL with leading slash
const url2 = getFullImageUrl('/uploads/avatar.jpg') 
// Returns: "https://tenant.flamingo.run/api/uploads/avatar.jpg"

// Already has /api/ prefix
const url3 = getFullImageUrl('/api/uploads/avatar.jpg')
// Returns: "https://tenant.flamingo.run/api/uploads/avatar.jpg"

// Already absolute URL
const url4 = getFullImageUrl('https://external.com/image.jpg')
// Returns: "https://external.com/image.jpg" (unchanged)

// Handle null/undefined
const url5 = getFullImageUrl(null)
// Returns: undefined
```

The function intelligently handles various URL formats, preventing duplicate prefixes while ensuring all relative paths are properly resolved against the tenant's API base URL from the runtime configuration.
