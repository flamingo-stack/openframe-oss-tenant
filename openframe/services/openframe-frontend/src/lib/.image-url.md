A utility function for converting relative image paths to fully qualified URLs using the tenant host configuration.

## Key Components

- **`getFullImageUrl(imageUrl: string | null | undefined): string | undefined`** - Converts relative or partial image URLs to complete URLs with proper API prefix routing

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Returns undefined for null/empty values
const noUrl = getFullImageUrl(null) // undefined

// Preserves already complete URLs
const fullUrl = getFullImageUrl('https://example.com/image.jpg')
// Returns: 'https://example.com/image.jpg'

// Adds tenant host to API paths
const apiUrl = getFullImageUrl('/api/uploads/avatar.png')
// Returns: 'https://tenant.flamingo.run/api/uploads/avatar.png'

// Adds both tenant host and API prefix
const relativeUrl = getFullImageUrl('/uploads/photo.jpg')
// Returns: 'https://tenant.flamingo.run/api/uploads/photo.jpg'

// Handles paths without leading slash
const simplePath = getFullImageUrl('profile/avatar.png')
// Returns: 'https://tenant.flamingo.run/api/profile/avatar.png'
```

This utility ensures consistent image URL formatting across the Flamingo platform by automatically prepending the tenant host and API path prefix when needed, while preserving external URLs and handling various input formats gracefully.
