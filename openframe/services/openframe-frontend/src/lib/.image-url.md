A utility function that constructs full image URLs by combining relative paths with the appropriate API base URL and tenant host.

## Key Components

- **`getFullImageUrl()`** - Main export that transforms relative image paths into absolute URLs with proper API prefixing

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Transform relative paths to full URLs
const avatarUrl = getFullImageUrl('/uploads/avatar.jpg')
// Returns: "https://tenant.flamingo.run/api/uploads/avatar.jpg"

const thumbnailUrl = getFullImageUrl('images/thumbnail.png')
// Returns: "https://tenant.flamingo.run/api/images/thumbnail.png"

// Already full URLs pass through unchanged
const externalUrl = getFullImageUrl('https://external.com/image.jpg')
// Returns: "https://external.com/image.jpg"

// Handles null/undefined gracefully
const emptyUrl = getFullImageUrl(null)
// Returns: undefined
```

The function intelligently handles different URL formats:
- Full URLs (http/https) are returned unchanged
- Paths starting with `/api/` get tenant host prepended
- Paths with leading slash get `/api` inserted
- Relative paths get full `/api/` prefix added
- Null/undefined values return undefined

This ensures consistent image URL formatting across the Flamingo platform while supporting both internal API-served images and external image sources.
