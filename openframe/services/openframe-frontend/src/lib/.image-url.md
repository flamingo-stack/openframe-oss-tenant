A utility function that converts relative image paths to fully qualified URLs using the tenant host configuration, ensuring proper API endpoint prefixing.

## Key Components

- **`getFullImageUrl()`** - Main export that transforms image URLs by adding the appropriate tenant host and API prefix

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Transform relative paths to full URLs
const relativeUrl = '/uploads/avatar.jpg'
const fullUrl = getFullImageUrl(relativeUrl)
// Result: "https://tenant.flamingo.run/api/uploads/avatar.jpg"

// Handle various input formats
getFullImageUrl('uploads/profile.png')        // Adds host + /api/
getFullImageUrl('/api/images/logo.svg')       // Adds host only
getFullImageUrl('https://cdn.example.com/img') // Returns unchanged
getFullImageUrl(null)                         // Returns undefined

// Common use case in components
const imageUrl = getFullImageUrl(user?.avatarUrl)
if (imageUrl) {
  return <img src={imageUrl} alt="User avatar" />
}
```

The function intelligently handles different URL formats: absolute URLs are returned unchanged, paths with `/api/` prefix get only the host prepended, and relative paths get both host and `/api/` prefix added. Returns `undefined` for null/empty inputs, making it safe for conditional rendering.
