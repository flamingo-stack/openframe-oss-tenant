Utility function for converting relative image paths to full URLs with proper API base URL prefixing. Handles various URL formats and automatically applies the tenant host configuration.

## Key Components

- **`getFullImageUrl(imageUrl)`** - Main function that converts relative/absolute image URLs to fully qualified URLs with proper API prefixing

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Relative path without leading slash
const url1 = getFullImageUrl('uploads/avatar.jpg')
// Returns: "https://tenant.flamingo.run/api/uploads/avatar.jpg"

// Relative path with leading slash
const url2 = getFullImageUrl('/uploads/avatar.jpg') 
// Returns: "https://tenant.flamingo.run/api/uploads/avatar.jpg"

// Already has API prefix
const url3 = getFullImageUrl('/api/uploads/avatar.jpg')
// Returns: "https://tenant.flamingo.run/api/uploads/avatar.jpg"

// Already a full URL (passthrough)
const url4 = getFullImageUrl('https://external.com/image.jpg')
// Returns: "https://external.com/image.jpg"

// Null/undefined handling
const url5 = getFullImageUrl(null)
// Returns: undefined
```

The function intelligently detects the URL format and applies the appropriate transformations, ensuring consistent API endpoint URLs while preserving external URLs unchanged.
