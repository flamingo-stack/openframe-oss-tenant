Utility function for normalizing image URLs to include the proper API base URL prefix, handling various input formats from relative paths to absolute URLs.

## Key Components

- **`getFullImageUrl()`** - Main export that converts relative image URLs to full URLs with tenant host and API prefix

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Returns undefined for null/empty values
const noUrl = getFullImageUrl(null) // undefined

// Passes through absolute URLs unchanged
const external = getFullImageUrl('https://example.com/image.jpg')
// Returns: 'https://example.com/image.jpg'

// Adds tenant host to API paths
const apiPath = getFullImageUrl('/api/uploads/image.jpg')
// Returns: 'https://tenant.flamingo.run/api/uploads/image.jpg'

// Normalizes paths without API prefix
const relativePath = getFullImageUrl('/uploads/image.jpg')
// Returns: 'https://tenant.flamingo.run/api/uploads/image.jpg'

// Handles paths without leading slash
const bareFileName = getFullImageUrl('image.jpg')
// Returns: 'https://tenant.flamingo.run/api/image.jpg'
```

The function intelligently handles different URL formats, ensuring consistent API endpoint URLs while preserving external absolute URLs. It relies on the runtime environment configuration to determine the tenant host URL for building complete URLs.
