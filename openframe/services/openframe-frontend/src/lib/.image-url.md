Utility function for normalizing image URLs by ensuring they include the proper API base URL prefix for the current tenant environment.

## Key Components

- **getFullImageUrl()** - Main export that converts relative image paths to fully qualified URLs with tenant host and API prefix

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Convert relative paths to full URLs
const profilePic = getFullImageUrl('/uploads/avatar.jpg')
// Returns: "https://tenant.example.com/api/uploads/avatar.jpg"

const logoUrl = getFullImageUrl('images/logo.png')
// Returns: "https://tenant.example.com/api/images/logo.png"

// Already full URLs pass through unchanged
const externalImage = getFullImageUrl('https://cdn.example.com/image.jpg')
// Returns: "https://cdn.example.com/image.jpg"

// API paths are handled correctly
const apiImage = getFullImageUrl('/api/files/document.pdf')
// Returns: "https://tenant.example.com/api/files/document.pdf"

// Null/undefined safety
const noImage = getFullImageUrl(null)
// Returns: undefined
```

The function intelligently handles various URL formats including relative paths, absolute paths with/without API prefixes, and external URLs, making it safe to use with any image URL source in the application.
