Utility function for constructing full image URLs by combining relative paths with the tenant's API base URL.

## Key Components

- **`getFullImageUrl()`** - Main export that converts relative image paths to absolute URLs using the tenant's host configuration

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Relative path gets API prefix and tenant host
const fullUrl = getFullImageUrl('/uploads/avatar.jpg')
// Returns: "https://tenant.example.com/api/uploads/avatar.jpg"

// Already absolute URLs are returned unchanged
const absoluteUrl = getFullImageUrl('https://cdn.example.com/image.png')
// Returns: "https://cdn.example.com/image.png"

// Paths with /api/ prefix only get tenant host
const apiUrl = getFullImageUrl('/api/files/image.jpg')
// Returns: "https://tenant.example.com/api/files/image.jpg"

// Null/undefined returns undefined
const noUrl = getFullImageUrl(null)
// Returns: undefined
```

The function intelligently handles different URL formats: absolute URLs are passed through unchanged, relative paths get the appropriate API prefix, and paths already containing `/api/` only receive the tenant host prefix. This ensures consistent URL formatting across the application while supporting various image source types.
