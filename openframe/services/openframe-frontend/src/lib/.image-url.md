A utility function for normalizing image URLs by adding the appropriate API base URL prefix based on tenant configuration.

## Key Components

- **`getFullImageUrl`** - Main export function that converts relative image paths to full URLs using the tenant host configuration

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Relative path without leading slash
const url1 = getFullImageUrl('uploads/profile.jpg')
// Returns: "https://tenant.flamingo.run/api/uploads/profile.jpg"

// Relative path with leading slash
const url2 = getFullImageUrl('/uploads/avatar.png')
// Returns: "https://tenant.flamingo.run/api/uploads/avatar.png"

// Already prefixed with /api/
const url3 = getFullImageUrl('/api/images/logo.svg')
// Returns: "https://tenant.flamingo.run/api/images/logo.svg"

// Already a full URL (passed through unchanged)
const url4 = getFullImageUrl('https://external.com/image.jpg')
// Returns: "https://external.com/image.jpg"

// Handle null/undefined inputs
const url5 = getFullImageUrl(null)
// Returns: undefined
```

The function handles various URL formats and intelligently prepends the tenant host URL and `/api/` prefix only when needed, making it safe to use with mixed URL types throughout the application.
