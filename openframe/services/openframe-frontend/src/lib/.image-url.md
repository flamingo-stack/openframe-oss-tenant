A utility function that converts relative image URLs to fully-qualified URLs using the tenant's API base URL, handling various URL formats and edge cases.

## Key Components

- **`getFullImageUrl()`** - Main export that transforms image URLs into complete URLs with proper API prefixing

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Returns undefined for null/empty values
getFullImageUrl(null) // → undefined
getFullImageUrl('') // → undefined

// Passes through absolute URLs unchanged
getFullImageUrl('https://example.com/image.jpg') // → 'https://example.com/image.jpg'

// Adds tenant host to API-prefixed paths
getFullImageUrl('/api/uploads/avatar.png') // → 'https://tenant.com/api/uploads/avatar.png'

// Adds both tenant host and API prefix to absolute paths
getFullImageUrl('/uploads/avatar.png') // → 'https://tenant.com/api/uploads/avatar.png'

// Handles relative paths by adding tenant host and API prefix
getFullImageUrl('uploads/avatar.png') // → 'https://tenant.com/api/uploads/avatar.png'
```

The function intelligently handles different URL formats:
- Returns `undefined` for null/empty inputs
- Preserves existing absolute URLs (http/https)
- Adds tenant host to paths already containing `/api/`
- Prepends both tenant host and `/api/` to other paths
- Ensures consistent URL formatting regardless of input format
