Utility function for building full image URLs by automatically prefixing relative paths with the tenant's API base URL.

## Key Components

- **`getFullImageUrl()`** - Main function that converts relative image paths to absolute URLs using the tenant host configuration

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Convert relative path to full URL
const avatarUrl = getFullImageUrl('/uploads/avatar.jpg')
// Returns: "https://tenant.flamingo.run/api/uploads/avatar.jpg"

// Handle already absolute URLs
const externalUrl = getFullImageUrl('https://cdn.example.com/image.png')
// Returns: "https://cdn.example.com/image.png" (unchanged)

// Handle API paths
const apiImageUrl = getFullImageUrl('/api/files/image.jpg')
// Returns: "https://tenant.flamingo.run/api/files/image.jpg"

// Handle null/undefined values
const missingUrl = getFullImageUrl(null)
// Returns: undefined
```

The function intelligently handles different URL formats - absolute URLs are returned unchanged, paths with `/api/` prefix are combined with the tenant host, and relative paths get both the tenant host and `/api/` prefix automatically added.
