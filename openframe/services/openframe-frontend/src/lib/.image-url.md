A utility function for converting relative image URLs to fully-qualified URLs using the tenant host configuration. This ensures consistent image URL handling across the application.

## Key Components

- **`getFullImageUrl()`** - Main export function that converts relative image paths to absolute URLs with proper API base path

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Convert relative path to full URL
const relativeUrl = '/uploads/avatar.jpg'
const fullUrl = getFullImageUrl(relativeUrl)
// Returns: 'https://tenant.example.com/api/uploads/avatar.jpg'

// Handle already absolute URLs
const absoluteUrl = 'https://cdn.example.com/image.jpg'
const unchanged = getFullImageUrl(absoluteUrl)
// Returns: 'https://cdn.example.com/image.jpg'

// Handle null/undefined gracefully
const emptyUrl = getFullImageUrl(null)
// Returns: undefined

// API paths are preserved
const apiPath = '/api/files/document.pdf'
const apiUrl = getFullImageUrl(apiPath)
// Returns: 'https://tenant.example.com/api/files/document.pdf'
```

The function intelligently handles various URL formats:
- Null/undefined values return undefined
- Absolute URLs (http/https) are returned unchanged
- Paths starting with `/api/` are prefixed with tenant host
- Other relative paths get both tenant host and `/api/` prefix
