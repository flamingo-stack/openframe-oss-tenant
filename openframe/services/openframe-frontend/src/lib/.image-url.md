Utility function for converting relative image paths to absolute URLs using the tenant host configuration.

## Key Components

- **`getFullImageUrl()`** - Main export that converts relative image URLs to full URLs with proper API base path prefixing
- **Runtime environment integration** - Uses `runtimeEnv.tenantHostUrl()` to get the base tenant URL
- **URL validation** - Checks for existing full URLs to avoid double-prefixing

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Convert relative path to full URL
const avatarUrl = getFullImageUrl('/uploads/avatar.jpg')
// Returns: "https://tenant.flamingo.run/api/uploads/avatar.jpg"

// Handle API prefixed paths  
const imageUrl = getFullImageUrl('/api/files/image.png')
// Returns: "https://tenant.flamingo.run/api/files/image.png"

// Pass through full URLs unchanged
const externalUrl = getFullImageUrl('https://cdn.example.com/image.jpg')
// Returns: "https://cdn.example.com/image.jpg"

// Handle null/undefined safely
const missingUrl = getFullImageUrl(null)
// Returns: undefined
```

The function intelligently handles various URL formats - full URLs are returned as-is, while relative paths are prefixed with the tenant host and `/api/` path. This ensures consistent image URL formatting across the Flamingo platform while supporting both internal API endpoints and external CDN resources.
