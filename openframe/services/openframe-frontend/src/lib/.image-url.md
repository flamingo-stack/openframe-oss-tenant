Utility function for normalizing image URLs with proper API base URL prefixes in the Flamingo platform.

## Key Components

- **`getFullImageUrl(imageUrl)`** - Transforms relative image URLs into fully qualified URLs using the tenant's host configuration

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Relative URL without leading slash
const profileImage = getFullImageUrl('uploads/user-avatar.jpg')
// Returns: "https://tenant.flamingo.run/api/uploads/user-avatar.jpg"

// Relative URL with leading slash
const logoImage = getFullImageUrl('/images/company-logo.png')
// Returns: "https://tenant.flamingo.run/api/images/company-logo.png"

// Already prefixed with /api/
const apiImage = getFullImageUrl('/api/assets/banner.jpg')
// Returns: "https://tenant.flamingo.run/api/assets/banner.jpg"

// Absolute URLs remain unchanged
const externalImage = getFullImageUrl('https://example.com/image.jpg')
// Returns: "https://example.com/image.jpg"

// Null/undefined handling
const missingImage = getFullImageUrl(null)
// Returns: undefined
```

The function intelligently handles various URL formats and automatically prepends the tenant's API base URL when needed, ensuring consistent image URL resolution across the platform.
