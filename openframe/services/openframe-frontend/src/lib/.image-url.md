Utility function for building full image URLs with proper API base URL prefixes for the Flamingo platform.

## Key Components

- **`getFullImageUrl`** - Main utility function that converts relative image paths to full URLs with tenant host and API prefix

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Convert relative paths to full URLs
const avatarUrl = getFullImageUrl('/uploads/avatar.jpg')
// Result: "https://tenant.flamingo.run/api/uploads/avatar.jpg"

const thumbnailUrl = getFullImageUrl('images/thumb.png')
// Result: "https://tenant.flamingo.run/api/images/thumb.png"

// Pass through absolute URLs unchanged
const externalUrl = getFullImageUrl('https://example.com/image.jpg')
// Result: "https://example.com/image.jpg"

// Handle null/undefined gracefully
const noImage = getFullImageUrl(null)
// Result: undefined
```

The function intelligently handles different URL formats:
- Returns `undefined` for null/undefined inputs
- Passes through absolute URLs (http/https) unchanged  
- Adds `/api/` prefix for paths with leading slash
- Preserves existing `/api/` prefixes
- Prepends tenant host URL from runtime configuration

This ensures consistent image URL formatting across the Flamingo platform while supporting both relative assets and external images.
