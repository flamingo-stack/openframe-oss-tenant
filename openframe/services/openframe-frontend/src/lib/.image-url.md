A utility function for building full image URLs by properly prefixing relative paths with the API base URL from runtime configuration. It handles various URL formats and ensures consistent API endpoint formatting.

## Key Components

- **`getFullImageUrl(imageUrl)`** - Main export function that converts relative image paths to full URLs with proper API prefixing

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Convert relative paths to full URLs
const avatarUrl = getFullImageUrl('/uploads/avatar.jpg')
// Returns: "https://tenant.flamingo.run/api/uploads/avatar.jpg"

const thumbnailUrl = getFullImageUrl('images/thumb.png')
// Returns: "https://tenant.flamingo.run/api/images/thumb.png"

// Already full URLs pass through unchanged
const externalUrl = getFullImageUrl('https://example.com/image.jpg')
// Returns: "https://example.com/image.jpg"

// API paths are handled correctly
const apiUrl = getFullImageUrl('/api/files/image.png')
// Returns: "https://tenant.flamingo.run/api/files/image.png"

// Null/undefined inputs return undefined
const noUrl = getFullImageUrl(null)
// Returns: undefined
```

The function intelligently detects whether the input is already a full URL, has API prefixing, or needs path normalization, making it safe to use with various image URL formats throughout the application.
