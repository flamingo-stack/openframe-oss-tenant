Resolves relative image paths to fully-qualified URLs by prepending the configured tenant host and `/api/` prefix as needed.

## Key Components

- **`getFullImageUrl(imageUrl)`** — Transforms a relative or absolute image URL into a complete URL using the runtime tenant host configuration. Returns `undefined` if the input is falsy.

## URL Resolution Logic

| Input | Output |
|---|---|
| `null` / `undefined` / `""` | `undefined` |
| `https://cdn.example.com/img.png` | unchanged (already absolute) |
| `/api/files/img.png` | `{tenantHost}/api/files/img.png` |
| `/files/img.png` | `{tenantHost}/api/files/img.png` |
| `files/img.png` | `{tenantHost}/api/files/img.png` |

## Usage Example

```typescript
import { getFullImageUrl } from './image-url';

// Relative path — no leading slash
getFullImageUrl('avatars/user-123.png');
// → "https://tenant.example.com/api/avatars/user-123.png"

// Relative path — with leading slash
getFullImageUrl('/avatars/user-123.png');
// → "https://tenant.example.com/api/avatars/user-123.png"

// Already has /api/ prefix
getFullImageUrl('/api/avatars/user-123.png');
// → "https://tenant.example.com/api/avatars/user-123.png"

// Absolute URL — passed through unchanged
getFullImageUrl('https://cdn.example.com/logo.png');
// → "https://cdn.example.com/logo.png"

// Falsy input
getFullImageUrl(null); // → undefined
```

## Dependencies

- **`runtimeEnv.tenantHostUrl()`** — Provides the base host (e.g. `https://tenant.example.com`) from [`runtime-config`](./runtime-config.ts) at call time, supporting dynamic multi-tenant environments.
