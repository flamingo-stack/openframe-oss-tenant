Utility function for converting relative image URLs to absolute URLs using the tenant's API base URL, with intelligent handling of various URL formats.

## Key Components

- **`getFullImageUrl`** - Main function that converts relative image URLs to absolute URLs by prepending the tenant host and API path
- **Runtime Environment Integration** - Uses `runtimeEnv.tenantHostUrl()` to get the current tenant's base URL
- **URL Format Detection** - Intelligently handles different input formats (absolute URLs, API-prefixed paths, relative paths)

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Convert relative path to full URL
const avatarUrl = getFullImageUrl('/uploads/avatar.jpg')
// Returns: "https://tenant.flamingo.run/api/uploads/avatar.jpg"

// Handle API-prefixed paths
const logoUrl = getFullImageUrl('/api/assets/logo.png')
// Returns: "https://tenant.flamingo.run/api/assets/logo.png"

// Pass through absolute URLs unchanged
const externalUrl = getFullImageUrl('https://example.com/image.jpg')
// Returns: "https://example.com/image.jpg"

// Handle null/undefined gracefully
const missingUrl = getFullImageUrl(null)
// Returns: undefined
```

This utility ensures consistent image URL handling across the Flamingo platform, automatically converting relative paths to tenant-specific absolute URLs while preserving existing absolute URLs and handling edge cases gracefully.
