Utility function for normalizing image URLs to full absolute URLs with proper API endpoint prefixes in the Flamingo platform.

## Key Components

- **`getFullImageUrl(imageUrl)`** - Main function that converts relative image URLs to absolute URLs with tenant host and API prefix

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Returns undefined for null/empty values
const noUrl = getFullImageUrl(null) // undefined

// Already absolute URLs pass through unchanged
const absoluteUrl = getFullImageUrl('https://example.com/image.jpg')
// Returns: 'https://example.com/image.jpg'

// Relative URLs with /api/ prefix get tenant host prepended
const apiUrl = getFullImageUrl('/api/uploads/image.jpg')
// Returns: 'https://tenant.flamingo.run/api/uploads/image.jpg'

// Absolute paths get both tenant host and /api/ prefix
const absolutePath = getFullImageUrl('/uploads/image.jpg')
// Returns: 'https://tenant.flamingo.run/api/uploads/image.jpg'

// Relative paths get tenant host, /api/ prefix, and leading slash
const relativePath = getFullImageUrl('uploads/image.jpg')
// Returns: 'https://tenant.flamingo.run/api/uploads/image.jpg'
```

This function ensures consistent image URL formatting across the platform by automatically adding the tenant-specific host and API endpoint prefix when needed, while preserving already-formatted absolute URLs.
