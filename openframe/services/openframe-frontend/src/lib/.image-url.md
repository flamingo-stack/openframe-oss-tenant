Utility function that converts relative image paths to fully qualified URLs using the tenant's API base URL.

## Key Components

- **`getFullImageUrl()`** - Main function that normalizes image URLs by prepending the appropriate API base URL and path structure

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Convert relative paths to full URLs
const avatarUrl = getFullImageUrl('/uploads/avatar.jpg')
// Returns: "https://tenant.flamingo.run/api/uploads/avatar.jpg"

const logoUrl = getFullImageUrl('images/logo.png')
// Returns: "https://tenant.flamingo.run/api/images/logo.png"

// Already prefixed paths are handled correctly
const existingUrl = getFullImageUrl('/api/files/image.png')
// Returns: "https://tenant.flamingo.run/api/files/image.png"

// Full URLs are returned unchanged
const externalUrl = getFullImageUrl('https://example.com/image.jpg')
// Returns: "https://example.com/image.jpg"

// Handles null/undefined gracefully
const emptyUrl = getFullImageUrl(null)
// Returns: undefined
```

The function intelligently handles various URL formats - full URLs are passed through unchanged, while relative paths are properly prefixed with the tenant host and `/api/` path structure.
