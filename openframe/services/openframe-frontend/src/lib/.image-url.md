Utility function for converting relative image paths to fully qualified URLs using the tenant host configuration from the runtime environment.

## Key Components

- **`getFullImageUrl`** - Main export function that transforms relative or partial image URLs into complete URLs with proper API base path prefixes

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Convert relative paths to full URLs
const profileImage = getFullImageUrl('/uploads/profile.jpg')
// Returns: "https://tenant.flamingo.run/api/uploads/profile.jpg"

const avatar = getFullImageUrl('avatars/user123.png')
// Returns: "https://tenant.flamingo.run/api/avatars/user123.png"

// Handle already complete URLs
const externalImage = getFullImageUrl('https://example.com/image.jpg')
// Returns: "https://example.com/image.jpg"

// Handle null/undefined values
const missingImage = getFullImageUrl(null)
// Returns: undefined
```

The function intelligently handles different URL formats: complete URLs are returned unchanged, paths with `/api/` prefix get only the tenant host prepended, paths with leading slashes get `/api` inserted, and relative paths get both leading slash and `/api` prefix added. This ensures consistent image URL formatting across the Flamingo platform while maintaining compatibility with external image sources.
