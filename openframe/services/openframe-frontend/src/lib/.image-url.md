A utility function that normalizes image URLs by converting relative paths to absolute URLs using the tenant host configuration.

## Key Components

- **`getFullImageUrl`** - Main export function that transforms relative image URLs into absolute URLs with proper API base path prefixing

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Convert relative path to full URL
const fullUrl = getFullImageUrl('/uploads/avatar.jpg')
// Returns: "https://tenant.flamingo.run/api/uploads/avatar.jpg"

// Handle already absolute URLs
const existingUrl = getFullImageUrl('https://external.com/image.png')
// Returns: "https://external.com/image.png" (unchanged)

// Handle API-prefixed paths
const apiUrl = getFullImageUrl('/api/files/document.pdf')
// Returns: "https://tenant.flamingo.run/api/files/document.pdf"

// Handle null/undefined gracefully
const noUrl = getFullImageUrl(null)
// Returns: undefined
```

The function intelligently handles various URL formats:
- **Absolute URLs** (http/https) are returned unchanged
- **API-prefixed paths** (`/api/...`) get tenant host prepended
- **Root paths** (`/...`) get both tenant host and `/api/` prepended  
- **Relative paths** get full tenant host + `/api/` prefix
- **Null/undefined** inputs return `undefined`

This ensures consistent URL formatting across the Flamingo platform while maintaining compatibility with external image sources.
