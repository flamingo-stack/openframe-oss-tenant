Utility function for converting relative image paths to full URLs with proper API base prefixes for multi-tenant environments.

## Key Components

- **`getFullImageUrl(imageUrl)`** - Main export that transforms image URLs by adding tenant host and API prefix when needed

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Transform relative paths
const relativeUrl = getFullImageUrl('/images/avatar.jpg')
// Returns: "https://tenant.example.com/api/images/avatar.jpg"

// Handle API-prefixed paths  
const apiUrl = getFullImageUrl('/api/uploads/photo.png')
// Returns: "https://tenant.example.com/api/uploads/photo.png"

// Pass through absolute URLs unchanged
const absoluteUrl = getFullImageUrl('https://cdn.example.com/image.jpg')
// Returns: "https://cdn.example.com/image.jpg"

// Handle null/undefined safely
const nullUrl = getFullImageUrl(null)
// Returns: undefined
```

The function intelligently handles different URL formats:
- Absolute URLs (http/https) are returned unchanged
- Paths with `/api/` prefix get tenant host prepended
- Paths with leading slash get both tenant host and `/api/` prefix
- Paths without leading slash get tenant host, `/api/`, and leading slash added
- Returns `undefined` for null/empty inputs
