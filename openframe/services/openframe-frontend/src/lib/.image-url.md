Utility for converting relative image paths to full URLs with proper API base URL prefixes based on tenant configuration.

## Key Components

- **`getFullImageUrl(imageUrl)`** - Main function that transforms relative or partial image URLs into complete URLs by adding the tenant host and API prefix when needed

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Returns undefined for null/undefined input
const noUrl = getFullImageUrl(null) // undefined

// Returns full URLs unchanged
const fullUrl = getFullImageUrl('https://example.com/image.jpg') 
// Returns: 'https://example.com/image.jpg'

// Adds tenant host to API paths
const apiUrl = getFullImageUrl('/api/uploads/image.jpg')
// Returns: 'https://tenant.example.com/api/uploads/image.jpg'

// Adds both API prefix and tenant host to relative paths
const relativePath = getFullImageUrl('/uploads/image.jpg')
// Returns: 'https://tenant.example.com/api/uploads/image.jpg'

// Handles paths without leading slash
const simpleUrl = getFullImageUrl('uploads/image.jpg')
// Returns: 'https://tenant.example.com/api/uploads/image.jpg'
```

The function intelligently handles different URL formats by checking prefixes and applying the appropriate transformations to ensure consistent API endpoint routing across the multi-tenant platform.
