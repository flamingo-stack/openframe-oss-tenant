A utility function that converts relative image URLs to absolute URLs by prefixing them with the appropriate API base URL and tenant host configuration.

## Key Components

- **`getFullImageUrl(imageUrl)`** - Main export function that handles URL transformation with multiple path scenarios

## Usage Example

```typescript
import { getFullImageUrl } from './image-url'

// Returns undefined for null/empty inputs
const emptyResult = getFullImageUrl(null) // undefined

// Preserves existing full URLs
const fullUrl = getFullImageUrl('https://example.com/image.jpg') 
// Returns: 'https://example.com/image.jpg'

// Adds API prefix to relative paths
const relativePath = getFullImageUrl('/uploads/image.jpg')
// Returns: '{tenantHost}/api/uploads/image.jpg'

// Handles paths that already have /api/ prefix
const apiPath = getFullImageUrl('/api/v1/images/photo.png')
// Returns: '{tenantHost}/api/v1/images/photo.png'

// Adds both leading slash and API prefix
const fileName = getFullImageUrl('avatar.png')
// Returns: '{tenantHost}/api/avatar.png'
```

The function intelligently handles different URL formats:
- Returns `undefined` for null/empty inputs
- Preserves existing absolute URLs (http/https)
- Adds tenant host prefix to paths starting with `/api/`
- Adds both tenant host and `/api/` prefix to other relative paths
- Ensures proper slash handling for all path variations
