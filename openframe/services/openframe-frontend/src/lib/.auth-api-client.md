Dedicated HTTP client for all authentication-related API endpoints, handling OAuth flows, token refresh, SaaS tenant management, and user registration with automatic retry logic on 401 responses.

## Key Components

**Exports**
- `SAAS_DOMAIN_SUFFIX` — Computed domain suffix derived from `SHARED_HOST_URL` or the current browser hostname, used for tenant domain availability checks
- `AuthApiResponse<T>` — Typed response wrapper with `data`, `error`, `status`, and `ok` fields
- `authApiClient` — Singleton instance of `AuthApiClient`

**`AuthApiClient` Methods**

| Method | Description |
|--------|-------------|
| `handleUnauthorized()` | Attempts token refresh on 401, retries original request, or forces logout |
| `refresh()` | Calls `POST /oauth/refresh` with optional `tenantId` |
| `devExchange()` | Dev-only ticket-based token exchange |
| `oauth()` | Generic `/oauth/*` request wrapper |
| `discoverTenants()` | Looks up tenants by email (`/sas/tenant/discover`) |
| `checkDomainAvailability()` | Validates subdomain + org name uniqueness |
| `validateAccessCode()` | Verifies email + access code pair |
| `registerOrganization()` | Creates new org with credentials |
| `registerOrganizationSso()` | Redirects to SSO-based org registration |
| `acceptInvitation()` | Accepts user invitation with credentials |
| `acceptInvitationSso()` | Redirects to SSO-based invitation acceptance |
| `requestPasswordReset()` / `confirmPasswordReset()` | Password reset flow |
| `loginUrl()` | Builds the OAuth login redirect URL |
| `logout()` / `logoutAsync()` | Redirects to or fetches the logout endpoint |

**Internal Request Helpers**
- `request()` — Authenticated fetch with 401 retry via `handleUnauthorized`
- `requestRefresh()` — Token-refresh-specific fetch; injects `Refresh-Token` header in dev mode
- `requestPublic()` — Unauthenticated fetch (`credentials: 'omit'`) for public endpoints

## Usage Example

```typescript
import { authApiClient } from '@/lib/auth-api-client';

// Discover tenants for SSO login
const { data, ok } = await authApiClient.discoverTenants('user@example.com');

// Register a new organization
const result = await authApiClient.registerOrganization({
  email: 'admin@acme.com',
  firstName: 'Jane',
  lastName: 'Doe',
  password: 'secure-pass',
  tenantName: 'Acme Corp',
  tenantDomain: 'acme.flamingo.run',
  accessCode: 'BETA123',
});

if (!result.ok) {
  console.error(result.error);
}

// Trigger logout
authApiClient.logout('tenant-uuid-123');
```
