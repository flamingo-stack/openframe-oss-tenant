Dedicated HTTP client for all authentication-related API endpoints, handling OAuth flows, token refresh, SaaS tenant management, and user registration with automatic retry logic on 401 responses.

## Key Components

### Exports
- **`AuthApiResponse<T>`** — Generic response wrapper with `data`, `error`, `status`, and `ok` fields
- **`SAAS_DOMAIN_SUFFIX`** — Computed domain suffix derived from `SHARED_HOST_URL` or current `window.location`
- **`authApiClient`** — Singleton instance of `AuthApiClient`

### Internal Helpers
- **`buildAuthUrl(path)`** — Prepends `SHARED_HOST_URL` when available; falls back to relative paths
- **`request<T>`** — Authenticated fetch with 401 auto-retry via `refreshAccessToken`
- **`requestRefresh<T>`** — Dedicated fetch for token refresh, injects `Refresh-Token` header in dev ticket mode
- **`requestPublic<T>`** — Unauthenticated fetch (`credentials: 'omit'`) for public endpoints

### `AuthApiClient` Methods

| Method | Description |
|---|---|
| `refresh(tenantId?)` | POST `/oauth/refresh` |
| `oauth(path, body?, init?)` | Generic OAuth endpoint wrapper |
| `loginUrl(tenantId, redirectTo, provider?)` | Builds the login redirect URL |
| `logout(tenantId?)` / `logoutAsync(tenantId?)` | Redirect or fetch-based logout |
| `discoverTenants(email)` | Tenant discovery for SaaS mode |
| `checkDomainAvailability(subdomain, org)` | Subdomain availability check |
| `registerOrganization(payload)` | Email/password org registration |
| `registerOrganizationSso(payload)` | SSO org registration (redirects) |
| `acceptInvitation(payload)` / `acceptInvitationSso(payload)` | Invitation acceptance |
| `requestPasswordReset` / `confirmPasswordReset` | Password reset flow |
| `validateAccessCode` / `resendVerificationEmail` | Email verification helpers |

## Usage Example

```typescript
import { authApiClient } from '@/lib/auth-api-client';

// Discover tenants by email (public, no auth required)
const { data, ok, error } = await authApiClient.discoverTenants('user@example.com');

// Trigger a token refresh for a specific tenant
const refreshResult = await authApiClient.refresh('tenant-uuid-123');

// Register a new organization
const result = await authApiClient.registerOrganization({
  email: 'admin@acme.com',
  firstName: 'Jane',
  lastName: 'Doe',
  password: 'securepass',
  tenantName: 'Acme Corp',
  tenantDomain: 'acme.openframe.ai',
});

// Redirect to login
window.location.href = authApiClient.loginUrl('tenant-id', '/dashboard', 'google');
```
