Dedicated HTTP client for all authentication-related API endpoints, handling token refresh, OAuth flows, SaaS tenant operations, and session management. Supports both shared-host (SaaS) and relative URL modes.

## Key Components

### `AuthApiResponse<T>`
Standardized response envelope returned by all auth requests.

```typescript
interface AuthApiResponse<T = any> {
  data?: T;
  error?: string;
  status: number;
  ok: boolean;
}
```

### `SAAS_DOMAIN_SUFFIX`
Exported string derived from `SHARED_HOST_URL` or the current browser hostname — used for tenant domain availability checks.

### `AuthApiClient` (singleton: `authApiClient`)
Central class exposing all auth operations:

| Method | Description |
|---|---|
| `refresh(tenantId?)` | POST `/oauth/refresh` — rotates access token |
| `oauth(path, body?, init?)` | Generic authenticated OAuth endpoint proxy |
| `devExchange(ticket)` | Dev-mode ticket exchange for local token injection |
| `discoverTenants(email)` | SaaS tenant discovery by email (public) |
| `checkDomainAvailability(sub, org)` | Validates subdomain + org name availability (public) |
| `validateAccessCode(email, code)` | Validates invite/access codes (public) |
| `registerOrganization(payload)` | Creates a new tenant with credentials |
| `registerOrganizationSso(payload)` | Redirects to SSO-based org registration |
| `acceptInvitation(payload)` | Accepts a user invitation with password |
| `acceptInvitationSso(payload)` | Redirects to SSO-based invitation acceptance |
| `confirmPasswordReset(payload)` | Completes a password reset flow |
| `requestPasswordReset(payload)` | Initiates password reset by email |
| `loginUrl(tenantId, redirectTo, provider?)` | Builds the OAuth login redirect URL |
| `logout(tenantId?)` | Hard redirect to logout endpoint |
| `logoutAsync(tenantId?)` | Fetch-based logout (no redirect) |
| `handleUnauthorized(url, headers, init)` | Retries a 401 request after token refresh; calls `forceLogout` on failure |

### Internal Request Helpers

| Function | Description |
|---|---|
| `request<T>` | Authenticated fetch with 401-retry logic |
| `requestRefresh<T>` | Fetch used exclusively for token refresh; injects `Refresh-Token` header in dev mode |
| `requestPublic<T>` | Unauthenticated fetch (`credentials: 'omit'`) for public endpoints |

## Usage Example

```typescript
import { authApiClient } from '@/lib/auth-api-client';

// Discover tenants for a given email
const { data, ok, error } = await authApiClient.discoverTenants('user@acme.com');

// Register a new organization
const result = await authApiClient.registerOrganization({
  email: 'admin@acme.com',
  firstName: 'Jane',
  lastName: 'Doe',
  password: 'secret',
  tenantName: 'Acme IT',
  tenantDomain: 'acme.openframe.ai',
  accessCode: 'BETA123',
});

// Build login URL and navigate
const loginUrl = authApiClient.loginUrl('tenant-uuid', '/dashboard', 'google');
window.location.href = loginUrl;

// Async logout without hard redirect
await authApiClient.logoutAsync('tenant-uuid');
```

> **Dev mode note:** When `enableDevTicketObserver` is active, `request` and `requestRefresh` read/write tokens from `localStorage` (keys `of_access_token` and the `REFRESH_TOKEN_KEY` constant) to support local development without cookie-based sessions.
