Centralized configuration module for the OpenFrame platform, defining app-level settings, navigation structure, UI behavior, SEO metadata, and structured data generation for `openframe-auth` and `openframe-dashboard` app types.

## Key Components

### Types & Interfaces
- **`AppType`** — Union type: `'openframe-auth' | 'openframe-dashboard'`
- **`AppConfig`** — Root config shape covering branding, SEO, layout, navigation, UI, footer, contact, and social
- **`NavigationMenuItem` / `NavigationSection`** — Recursive nav tree structures with support for icons, badges, dropdowns, and mobile visibility
- **`FooterConfig`** — Footer layout with sections, CTA, logo, and custom component slots

### Core Functions

| Function | Description |
|---|---|
| `getAppConfig(appType?)` | Returns `AppConfig` for the current or specified app type |
| `getCurrentAppType()` | Reads app type from `runtimeEnv` with `'openframe-dashboard'` fallback |
| `getMetadataBaseUrl()` | Resolves base URL from runtime env, browser-safe |
| `getPlatformAssetPaths(appType?)` | Returns absolute paths for favicon, OG image, manifest, etc. |
| `generateStructuredData(config)` | Produces Schema.org `WebSite` + `Organization` JSON-LD objects |
| `isRouteAllowed(pathname)` | Evaluates allowed/restricted route rules from config |
| `shouldShowComponent(component)` | Guards UI component visibility via config flags |
| `shouldShowAdminMenu(userRole?)` | Returns `true` only for `super_admin` when config enables admin menu |
| `getHeaderStyle()` | Returns `'default' | 'minimal' | 'admin'` from current config |

## Usage Example

```typescript
import {
  getAppConfig,
  isRouteAllowed,
  shouldShowComponent,
  getPlatformAssetPaths,
  generateStructuredData,
} from './app-config';

// Retrieve current app config
const config = getAppConfig();
console.log(config.name); // "OpenFrame"

// Guard a route
if (!isRouteAllowed('/admin/settings')) {
  redirect('/');
}

// Check UI visibility
if (shouldShowComponent('searchBar')) {
  renderSearchBar();
}

// Generate SEO structured data
const { schemaLd, organizationLd } = generateStructuredData(config);

// Resolve asset paths
const { favicon, ogImage } = getPlatformAssetPaths();
```
