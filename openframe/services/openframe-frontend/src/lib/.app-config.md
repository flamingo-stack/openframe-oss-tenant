Centralized app configuration module for the OpenFrame platform, providing typed config interfaces, environment-aware app resolution, and UI/navigation utility helpers.

## Key Components

### Types & Interfaces
- **`AppType`** — Union type for supported app variants (`openframe-auth` | `openframe-dashboard`)
- **`AppConfig`** — Root configuration interface covering branding, SEO, layout, navigation, UI, footer, and social links
- **`NavigationSection`** / **`NavigationMenuItem`** — Typed navigation tree structures supporting headers, mobile menus, and dropdowns
- **`FooterConfig`** / **`FooterSection`** / **`FooterCta`** — Footer layout and content configuration

### Core Functions
- **`getAppConfig(appType?)`** — Returns the `AppConfig` for the current or specified app type
- **`getCurrentAppType()`** — Resolves app type from `runtimeEnv`; defaults to `openframe-dashboard`
- **`getAllAppConfigs()`** — Returns the full `APP_CONFIGS` record
- **`getCurrentPlatform()`** — Always returns `'openframe'`
- **`getMetadataBaseUrl()`** — Returns base URL from runtime env, browser-safe
- **`getPlatformAssetPaths(appType?)`** — Generates absolute paths for favicon, OG image, manifest, etc.
- **`generateStructuredData(config)`** — Produces JSON-LD `WebSite` and `Organization` schema objects

### UI Utility Functions
- **`shouldShowAdminMenu(userRole?)`** — Checks admin nav visibility against user role
- **`shouldShowComponent(component)`** — Toggle check for `userMenu`, `mobileNav`, `searchBar`, `platformNav`, `adminNav`
- **`isRouteAllowed(pathname)`** — Evaluates allowed/restricted route rules from config
- **`getHeaderStyle()`** — Returns the current header style variant

## Usage Example

```typescript
import { getAppConfig, isRouteAllowed, shouldShowComponent, generateStructuredData } from './app-config';

// Retrieve current app configuration
const config = getAppConfig();
console.log(config.name); // "OpenFrame"

// Check route access
if (!isRouteAllowed('/admin/settings')) {
  redirect('/');
}

// Conditionally render nav elements
const showSearch = shouldShowComponent('searchBar');

// Generate structured data for SEO
const { schemaLd, organizationLd } = generateStructuredData(config);
```
