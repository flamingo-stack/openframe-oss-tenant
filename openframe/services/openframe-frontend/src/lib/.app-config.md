Centralizes application configuration for the OpenFrame platform, providing typed config structures, environment-aware app type resolution, and utility functions for UI/navigation/SEO decisions.

## Key Components

**Types & Interfaces**
- `AppType` — Union type for supported app variants (`openframe-auth` | `openframe-dashboard`)
- `AppConfig` — Master config interface covering branding, SEO, layout, navigation, UI, footer, and social
- `NavigationSection` / `NavigationMenuItem` — Typed structures for header/mobile/sidebar nav
- `FooterConfig` / `FooterSection` / `FooterCta` — Footer layout and content configuration

**Config Accessors**
- `getAppConfig(appType?)` — Returns the `AppConfig` for the current or specified app
- `getCurrentAppType()` — Resolves app type from runtime environment, defaults to `openframe-dashboard`
- `getAllAppConfigs()` — Returns the full `APP_CONFIGS` record

**SEO & Assets**
- `generateStructuredData(config)` — Produces `schema.org` `WebSite` and `Organization` JSON-LD objects
- `getPlatformAssetPaths(appType?)` — Resolves absolute URLs for favicon, OG image, manifest, etc.
- `getMetadataBaseUrl()` — Returns base URL from runtime env, browser-safe

**UI Decision Helpers**
- `shouldShowComponent(component)` — Guards visibility of `userMenu`, `mobileNav`, `searchBar`, `platformNav`, `adminNav`
- `shouldShowAdminMenu(userRole?)` — Returns `true` only for `super_admin` when config enables admin header menu
- `isRouteAllowed(pathname)` — Evaluates allowed/restricted route rules from config
- `getHeaderStyle()` — Returns the active header style variant

## Usage Example

```typescript
import { getAppConfig, isRouteAllowed, shouldShowComponent } from './app-config';

const config = getAppConfig();
console.log(config.name); // "OpenFrame"

// Guard a nav component
if (shouldShowComponent('userMenu')) {
  renderUserMenu();
}

// Restrict access to a route
if (!isRouteAllowed('/admin/settings')) {
  redirect('/');
}

// Generate structured data for SEO
const { schemaLd, organizationLd } = generateStructuredData(config);
```
