Re-exports two Relay-related modules — the environment utilities and the provider component — as a unified public API entry point for the Relay integration package.

## Key Components

- **`getRelayEnvironment`** — retrieves the current Relay environment instance
- **`resetRelayEnvironment`** — resets/reinitializes the Relay environment
- **`RelayProvider`** — React component that provides the Relay environment to the component tree via context

## Usage Example

```typescript
import {
  getRelayEnvironment,
  resetRelayEnvironment,
  RelayProvider,
} from './relay'; // or wherever this index is rooted

// Wrap your app with the provider
function App() {
  return (
    <RelayProvider environment={getRelayEnvironment()}>
      <YourAppTree />
    </RelayProvider>
  );
}

// Reset the environment (e.g., on logout)
function handleLogout() {
  resetRelayEnvironment();
}
```
