Barrel export file for the Relay integration module, re-exporting the core environment utilities and provider component from their respective submodules.

## Key Components

- **`getRelayEnvironment`** — retrieves the current Relay environment instance
- **`resetRelayEnvironment`** — resets/reinitializes the Relay environment (useful for logout or tenant switching)
- **`RelayProvider`** — React component that wraps the application (or a subtree) with the Relay environment context

## Usage Example

```typescript
import {
  getRelayEnvironment,
  resetRelayEnvironment,
  RelayProvider,
} from '@/relay';

// Wrap your app with the Relay context
function App() {
  return (
    <RelayProvider>
      <MyApp />
    </RelayProvider>
  );
}

// Access the environment directly (e.g., for imperative fetches)
const environment = getRelayEnvironment();

// Reset after logout or tenant switch
resetRelayEnvironment();
```
