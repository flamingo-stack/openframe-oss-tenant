Brief re-export barrel file that surfaces the core Relay environment utilities and provider component from their respective modules.

## Key Components

| Export | Source Module | Description |
|--------|--------------|-------------|
| `getRelayEnvironment` | `./environment` | Returns the current Relay environment instance |
| `resetRelayEnvironment` | `./environment` | Resets/reinitializes the Relay environment |
| `RelayProvider` | `./provider` | React context provider for injecting the Relay environment into the component tree |

## Usage Example

```typescript
import {
  getRelayEnvironment,
  resetRelayEnvironment,
  RelayProvider,
} from '@/relay';

// Wrap your app with the Relay provider
function App() {
  return (
    <RelayProvider environment={getRelayEnvironment()}>
      <MyApp />
    </RelayProvider>
  );
}

// Reset the environment (e.g., on logout)
function handleLogout() {
  resetRelayEnvironment();
}
```
