Wraps the React component tree with a singleton Relay environment, enabling GraphQL data fetching via `react-relay` throughout the application.

## Key Components

- **`RelayProvider`** — Client component that initializes and memoizes the Relay environment once, then provides it to all child components via `ReactRelayProvider`.

## Usage Example

```typescript
// app/layout.tsx
import { RelayProvider } from '@/relay/provider';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html>
      <body>
        <RelayProvider>
          {children}
        </RelayProvider>
      </body>
    </html>
  );
}
```

> The environment is memoized with an empty dependency array, ensuring `getRelayEnvironment()` is called only once per provider mount — preventing redundant network/store initialization on re-renders.
