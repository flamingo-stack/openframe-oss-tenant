Wraps the React component tree with a singleton Relay environment, enabling GraphQL data fetching via `react-relay` throughout the application.

## Key Components

- **`RelayProvider`** — Client component that initializes and memoizes the Relay environment using `getRelayEnvironment()`, then injects it via `ReactRelayProvider`.

## Usage Example

```typescript
import { RelayProvider } from './provider';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <RelayProvider>
      {children}
    </RelayProvider>
  );
}
```

> The environment is memoized with `useMemo` to ensure a stable singleton across renders, preventing unnecessary re-initialization of the Relay store.
