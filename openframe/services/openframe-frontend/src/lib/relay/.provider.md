Wraps the React component tree with a singleton Relay environment, enabling GraphQL data fetching throughout the application via React Relay.

## Key Components

- **`RelayProvider`** — Client-side context provider that initializes and memoizes the Relay environment once, then passes it to all child components via `ReactRelayProvider`.

## Usage Example

```typescript
// app/layout.tsx
import { RelayProvider } from '@/relay/provider';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html>
      <body>
        <RelayProvider>
          {children}
        </RelayProvider>
      </body>
    </html>
  );
}
```

> The environment is memoized with `useMemo` and an empty dependency array, ensuring the singleton Relay store and network layer are created only once per client session.
