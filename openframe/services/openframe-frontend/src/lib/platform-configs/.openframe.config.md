Configuration object that defines the OpenFrame platform's app-wide settings, including branding, SEO metadata, navigation structure, UI behavior, header/footer layout, and social links.

## Key Components

- **`openframeConfig`** — The main exported `AppConfig` object containing all platform configuration
- **`brandColors`** — Metadata-only color palette (actual UI relies on ODS CSS tokens)
- **`seo`** — SEO/OG metadata with dynamic URL resolution via `getBaseUrl()`
- **`layout`** — Controls visibility of header, footer, sidebar, and announcement bar
- **`navigation`** — Defines logo element, allowed/restricted routes, and nav visibility flags
- **`ui.getHeaderActions`** — Dynamic header action resolver that renders Profile, Sign Up, or Get Started buttons based on auth state
- **`footer.sections`** — Static footer link groups (Resources, Company)

## Usage Example

```typescript
import { openframeConfig } from './openframe.config';

// Access platform metadata
console.log(openframeConfig.name);        // 'OpenFrame'
console.log(openframeConfig.seo.title);   // 'OpenFrame - Open Source Framework'

// Resolve dynamic header actions based on auth state
const { left, right } = openframeConfig.ui.getHeaderActions({
  user: currentUser,
  router,
  pathname: '/docs',
  onSignUp: handleSignUp,
});

// Check navigation restrictions
const restricted = openframeConfig.navigation.restrictedRoutes;
// ['/admin', '/vendors', '/margin-increase']
```

> **Note:** `brandColors` and SEO image URLs are metadata-only values. All runtime UI styling is governed by the OpenFrame Design System (ODS) CSS tokens, not these color values.
