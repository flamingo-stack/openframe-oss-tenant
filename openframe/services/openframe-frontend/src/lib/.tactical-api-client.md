A specialized API client for interacting with Tactical RMM (Remote Monitoring and Management) systems, extending the base API client with Tactical-specific endpoints and functionality.

## Key Components

- **TacticalApiClient**: Main class that handles Tactical RMM API requests with automatic URL construction
- **HTTP Methods**: Standard REST methods (GET, POST, PUT, PATCH, DELETE) with JSON serialization
- **Agent Management**: Methods for retrieving agent information, logs, checks, tasks, and system data
- **Script Operations**: Functions to create, update, and execute scripts on managed agents
- **Task Scheduling**: Support for creating and managing scheduled tasks with complex timing configurations
- **tacticalApiClient**: Singleton instance exported for immediate use

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all managed agents
const agents = await tacticalApiClient.getAgents()

// Get specific agent details
const agent = await tacticalApiClient.getAgent('agent-123')

// Run a script on an agent
await tacticalApiClient.runScript('agent-123', {
  output: 'wait',
  emails: ['admin@company.com'],
  emailMode: 'on_failure',
  custom_field: null,
  save_all_output: true,
  script: 456,
  args: ['--verbose'],
  env_vars: [],
  timeout: 300,
  run_as_user: false,
  run_on_server: false
})

// Create a scheduled daily task
await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Daily Backup',
  task_type: 'daily',
  daily_interval: 1,
  run_time_date: '02:00:00',
  actions: [{
    type: 'script',
    name: 'Backup Script',
    script: 789,
    timeout: 600,
    script_args: [],
    env_vars: [],
    run_as_user: false
  }]
})
```
