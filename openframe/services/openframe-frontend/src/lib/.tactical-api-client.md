A specialized HTTP client that extends the base API functionality to interact with Tactical RMM (Remote Monitoring & Management) systems. It provides a comprehensive interface for managing agents, scripts, tasks, and system monitoring through Tactical RMM's REST API.

## Key Components

- **TacticalApiClient**: Main class that extends base API client with Tactical RMM-specific methods
- **HTTP Methods**: Standard REST operations (GET, POST, PUT, PATCH, DELETE) with automatic JSON handling
- **Agent Management**: Methods for retrieving agent information, logs, checks, and system details
- **Script Operations**: Create, update, retrieve, and execute scripts on remote agents
- **Task Scheduling**: Manage scheduled tasks with support for various recurrence patterns
- **System Monitoring**: Access agent services, processes, software, event logs, and network information

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all managed agents
const agentsResponse = await tacticalApiClient.getAgents()
const agents = agentsResponse.data

// Run a script on a specific agent
const scriptResult = await tacticalApiClient.runScript('agent-123', {
  output: 'wait',
  emails: ['admin@example.com'],
  emailMode: 'default',
  custom_field: null,
  save_all_output: true,
  script: 42,
  args: ['--verbose'],
  env_vars: [],
  timeout: 300,
  run_as_user: false,
  run_on_server: false
})

// Get agent system information
const systemInfo = await tacticalApiClient.getAgentSystemInfo('agent-123')

// Create a scheduled task
const task = await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Daily Backup',
  task_type: 'daily',
  run_time_date: '2024-01-01T02:00:00Z',
  daily_interval: 1,
  actions: [{
    type: 'script',
    name: 'backup-script',
    script: 15,
    timeout: 1800,
    script_args: ['--full'],
    env_vars: [],
    run_as_user: false
  }]
})
```
