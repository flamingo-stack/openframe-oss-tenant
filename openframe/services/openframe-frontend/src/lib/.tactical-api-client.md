A specialized API client for interacting with Tactical RMM endpoints, extending the base API client with MSP-specific functionality for agent management, script execution, and system monitoring.

## Key Components

**TacticalApiClient Class:**
- `constructor()` - Builds base URL from tenant host configuration
- `buildTacticalUrl()` - Constructs proper Tactical RMM endpoint URLs
- HTTP methods (`get`, `post`, `put`, `patch`, `delete`) - Standard REST operations
- Agent management methods (`getAgents`, `getAgent`, `runScript`, `runBulkAction`)
- Script management (`getScripts`, `createScript`, `updateScript`)
- System monitoring (`getAgentLogs`, `getAgentServices`, `getAgentProcesses`)
- Task scheduling (`createScheduledTask`, `getScheduledTask`, `deleteScheduledTask`)

**Exports:**
- `tacticalApiClient` - Singleton instance ready for use
- `TacticalApiClient` - Class for creating custom instances
- Type exports for `ApiRequestOptions` and `ApiResponse`

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agents = await tacticalApiClient.getAgents()

// Run a script on specific agent
const scriptResult = await tacticalApiClient.runScript('agent-123', {
  script: 42,
  timeout: 300,
  args: ['--verbose'],
  env_vars: [],
  output: 'wait',
  emails: ['admin@example.com'],
  emailMode: 'default',
  custom_field: null,
  save_all_output: true,
  run_as_user: false,
  run_on_server: false
})

// Create scheduled task
const task = await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Daily Backup',
  task_type: 'daily',
  run_time_date: '2024-01-01T02:00:00Z',
  daily_interval: 1,
  actions: [{
    type: 'script',
    name: 'Backup Script',
    script: 15,
    timeout: 1800,
    script_args: [],
    env_vars: [],
    run_as_user: false
  }]
})
```
