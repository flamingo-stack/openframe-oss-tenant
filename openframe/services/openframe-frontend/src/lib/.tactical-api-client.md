A specialized API client that extends the base API client to provide comprehensive functionality for interacting with Tactical RMM endpoints, including agent management, script execution, and system monitoring.

## Key Components

- **TacticalApiClient** - Main class that handles URL construction and request routing
- **HTTP Methods** - Standard REST operations (GET, POST, PUT, PATCH, DELETE)
- **Agent Management** - Methods for retrieving and managing Tactical RMM agents
- **Script Operations** - Functions for running, creating, and updating scripts
- **System Monitoring** - Endpoints for logs, services, processes, and system information
- **Task Scheduling** - Methods for managing scheduled tasks and automation

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agents = await tacticalApiClient.getAgents()

// Run a script on a specific agent
const scriptResult = await tacticalApiClient.runScript('agent-123', {
  output: 'wait',
  emails: ['admin@company.com'],
  emailMode: 'default',
  custom_field: null,
  save_all_output: true,
  script: 456,
  args: ['--verbose'],
  env_vars: [],
  timeout: 300,
  run_as_user: false,
  run_on_server: false
})

// Get agent system information
const systemInfo = await tacticalApiClient.getAgentSystemInfo('agent-123')

// Create a scheduled task
const task = await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Daily Backup',
  task_type: 'daily',
  daily_interval: 1,
  run_time_date: '2024-01-01T02:00:00Z',
  actions: [{
    type: 'script',
    name: 'Backup Script',
    script: 789,
    timeout: 600,
    script_args: [],
    env_vars: [],
    run_as_user: false
  }]
})
```
