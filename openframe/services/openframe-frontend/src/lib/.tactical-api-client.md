A specialized API client that extends the base API client functionality to provide seamless integration with Tactical RMM (Remote Monitoring and Management) endpoints, handling URL construction and providing typed methods for all Tactical RMM operations.

## Key Components

- **TacticalApiClient class** - Main client class with tenant-aware URL building
- **buildTacticalUrl()** - Private method for constructing proper Tactical RMM URLs
- **HTTP methods** - Standard REST operations (GET, POST, PUT, PATCH, DELETE)
- **Tactical-specific methods** - Agent management, script execution, monitoring, and system information
- **tacticalApiClient instance** - Pre-configured singleton instance

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agents = await tacticalApiClient.getAgents()

// Get specific agent details
const agent = await tacticalApiClient.getAgent('agent-123')

// Run a script on an agent
const scriptResult = await tacticalApiClient.runScript('agent-123', {
  output: 'email',
  emails: ['admin@company.com'],
  emailMode: 'default',
  custom_field: null,
  save_all_output: true,
  script: 42,
  args: ['--verbose'],
  env_vars: [],
  timeout: 300,
  run_as_user: false,
  run_on_server: false
})

// Create a new scheduled task
const task = await tacticalApiClient.createScheduledTask('agent-123', {
  actions: [{
    type: 'script',
    name: 'System Check',
    script: 15,
    timeout: 120,
    script_args: [],
    env_vars: [],
    run_as_user: false
  }],
  name: 'Daily System Check',
  task_type: 'daily',
  run_time_date: '09:00',
  daily_interval: 1
})

// Get agent logs with pagination
const logs = await tacticalApiClient.getAgentLogs('agent-123', {
  limit: 50,
  offset: 0,
  search: 'error'
})
```
