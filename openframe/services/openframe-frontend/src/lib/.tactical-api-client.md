A specialized API client that extends the base API functionality with comprehensive Tactical RMM integration capabilities. This client handles all communications with Tactical RMM endpoints including agent management, script execution, scheduling, and system monitoring.

## Key Components

- **TacticalApiClient** - Main client class extending base API functionality
- **HTTP Methods** - Standard REST operations (GET, POST, PUT, PATCH, DELETE)
- **Agent Operations** - Complete agent lifecycle management and monitoring
- **Script Management** - Script creation, execution, and scheduling
- **System Information** - Hardware, software, and service monitoring
- **Schedule Management** - Task scheduling and execution history

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agents = await tacticalApiClient.getAgents()

// Execute a script on a specific agent
const scriptResult = await tacticalApiClient.runScript('agent-123', {
  output: 'console',
  emails: ['admin@example.com'],
  emailMode: 'always',
  custom_field: null,
  save_all_output: true,
  script: 456,
  args: ['--verbose'],
  env_vars: ['NODE_ENV=production'],
  timeout: 300,
  run_as_user: false,
  run_on_server: false
})

// Create a scheduled task
const task = await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Daily Backup',
  task_type: 'daily',
  daily_interval: 1,
  run_time_date: '2024-01-01T02:00:00Z',
  actions: [{
    type: 'script',
    name: 'Backup Script',
    script: 789,
    timeout: 1800,
    script_args: ['--full'],
    env_vars: [],
    run_as_user: false
  }]
})

// Monitor agent system information
const systemInfo = await tacticalApiClient.getAgentSystemInfo('agent-123')
const diskInfo = await tacticalApiClient.getAgentDiskInfo('agent-123')
```
