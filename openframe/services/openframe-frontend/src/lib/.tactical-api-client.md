A specialized API client wrapper for Tactical RMM (Remote Monitoring and Management) integration, providing typed methods for agent management, script execution, and system monitoring operations.

## Key Components

- **TacticalApiClient** - Main class extending base API functionality with Tactical RMM-specific endpoints
- **HTTP Methods** - Standard REST operations (GET, POST, PUT, PATCH, DELETE) with automatic JSON serialization
- **Agent Management** - Methods for retrieving agent data, logs, checks, and system information
- **Script Operations** - Functions for creating, updating, and executing scripts on remote agents
- **Task Scheduling** - Support for creating and managing scheduled tasks with various recurrence patterns
- **System Monitoring** - Access to agent processes, services, disk info, network data, and event logs

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agents = await tacticalApiClient.getAgents()

// Execute a script on a specific agent
const scriptResult = await tacticalApiClient.runScript('agent-123', {
  script: 456,
  args: ['--verbose'],
  timeout: 300,
  output: 'wait',
  emails: ['admin@company.com'],
  emailMode: 'default',
  custom_field: null,
  save_all_output: true,
  env_vars: [],
  run_as_user: false,
  run_on_server: false
})

// Create a scheduled task
const task = await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Daily System Check',
  task_type: 'daily',
  daily_interval: 1,
  run_time_date: '2024-01-01T09:00:00Z',
  actions: [{
    type: 'script',
    name: 'Health Check',
    script: 789,
    timeout: 600,
    script_args: [],
    env_vars: [],
    run_as_user: false
  }]
})
```
