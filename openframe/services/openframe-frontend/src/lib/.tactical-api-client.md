A specialized API client that extends the base API client with Tactical RMM-specific functionality, providing comprehensive methods for managing RMM agents, scripts, tasks, and system information.

## Key Components

- **TacticalApiClient**: Main class extending base API functionality with Tactical RMM endpoints
- **HTTP Methods**: Standard REST operations (GET, POST, PUT, PATCH, DELETE)
- **Agent Management**: Methods for retrieving and managing RMM agents
- **Script Operations**: Create, update, and execute scripts on remote agents
- **System Information**: Access agent logs, services, processes, and system details
- **Task Scheduling**: Manage automated and scheduled tasks
- **URL Building**: Automatic URL construction based on tenant configuration

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agents = await tacticalApiClient.getAgents()

// Get specific agent details
const agent = await tacticalApiClient.getAgent('agent-123')

// Run a script on an agent
const scriptResult = await tacticalApiClient.runScript('agent-123', {
  script: 45,
  args: ['--verbose'],
  timeout: 300,
  output: 'wait',
  emails: ['admin@company.com'],
  emailMode: 'always',
  custom_field: null,
  save_all_output: true,
  env_vars: [],
  run_as_user: false,
  run_on_server: false
})

// Get agent system information
const systemInfo = await tacticalApiClient.getAgentSystemInfo('agent-123')

// Create a scheduled task
const task = await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Daily Backup Check',
  task_type: 'daily',
  daily_interval: 1,
  run_time_date: '02:00:00',
  actions: [{
    type: 'script',
    name: 'Backup Verification',
    script: 10,
    timeout: 600,
    script_args: ['--check-integrity'],
    env_vars: [],
    run_as_user: false
  }]
})
```
