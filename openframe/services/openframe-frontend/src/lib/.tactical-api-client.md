A specialized API client for Tactical RMM integration that extends the base API client with Tactical-specific endpoints and functionality. It provides a comprehensive interface for managing agents, scripts, tasks, and system monitoring within the Tactical RMM platform.

## Key Components

- **TacticalApiClient**: Main client class that wraps the base API client with Tactical RMM-specific methods
- **HTTP Methods**: Standard REST operations (get, post, put, patch, delete) with automatic URL construction
- **Agent Management**: Methods for retrieving agents, running scripts, and accessing agent-specific data
- **Script Operations**: Create, update, and manage scripts with full CRUD functionality
- **System Monitoring**: Access to logs, checks, services, processes, and system information
- **Task Scheduling**: Create and manage scheduled tasks with comprehensive configuration options

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agentsResponse = await tacticalApiClient.getAgents()

// Run a script on a specific agent
const scriptResult = await tacticalApiClient.runScript('agent-123', {
  output: 'wait',
  emails: ['admin@company.com'],
  emailMode: 'default',
  custom_field: null,
  save_all_output: true,
  script: 45,
  args: ['--verbose'],
  env_vars: [],
  timeout: 300,
  run_as_user: false,
  run_on_server: false
})

// Create a scheduled task
const taskResponse = await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Daily Backup',
  task_type: 'daily',
  run_time_date: '2024-01-01T02:00:00',
  daily_interval: 1,
  actions: [{
    type: 'script',
    name: 'Backup Script',
    script: 10,
    timeout: 3600,
    script_args: ['--full'],
    env_vars: [],
    run_as_user: false
  }]
})

// Get agent system information
const systemInfo = await tacticalApiClient.getAgentSystemInfo('agent-123')
```
