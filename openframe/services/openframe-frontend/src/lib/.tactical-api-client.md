Specialized API client for Tactical RMM integration within the Flamingo MSP platform. Extends the base API client with comprehensive Tactical RMM endpoints for agent management, script execution, monitoring, and system information retrieval.

## Key Components

- **TacticalApiClient** - Main client class that wraps the base API client with Tactical-specific functionality
- **HTTP Methods** - Standard REST methods (get, post, put, patch, delete) with automatic JSON serialization
- **Agent Management** - Methods for retrieving agent information, running scripts, and bulk operations
- **Script Management** - CRUD operations for scripts with support for various shells and platforms
- **Monitoring Endpoints** - Access to logs, checks, tasks, services, and system information
- **Scheduled Tasks** - Create and manage automated tasks with flexible scheduling options

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agents = await tacticalApiClient.getAgents()

// Run a script on an agent
await tacticalApiClient.runScript('agent-123', {
  script: 456,
  args: ['--verbose'],
  timeout: 300,
  output: 'console',
  emails: ['admin@example.com'],
  emailMode: 'on_failure',
  custom_field: null,
  save_all_output: true,
  env_vars: [],
  run_as_user: false,
  run_on_server: false
})

// Create a scheduled task
await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Daily Health Check',
  task_type: 'daily',
  daily_interval: 1,
  run_time_date: '09:00',
  actions: [{
    type: 'script',
    name: 'Health Check Script',
    script: 789,
    timeout: 180,
    script_args: [],
    env_vars: [],
    run_as_user: false
  }]
})

// Get agent system information
const systemInfo = await tacticalApiClient.getAgentSystemInfo('agent-123')
```
