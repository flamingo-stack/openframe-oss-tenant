A specialized API client for interacting with Tactical RMM endpoints, extending the base API client with tenant-aware URL construction and comprehensive agent management functionality.

## Key Components

- **TacticalApiClient** - Main class that extends base API client functionality
- **buildTacticalUrl()** - Constructs Tactical RMM-specific URLs with tenant host support
- **HTTP Methods** - Standard REST operations (GET, POST, PUT, PATCH, DELETE)
- **Agent Management** - Methods for managing agents, running scripts, and bulk actions
- **Script Operations** - CRUD operations for Tactical RMM scripts
- **System Information** - Agent logs, checks, tasks, services, processes, and system data
- **Scheduled Tasks** - Task management and scheduling functionality

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agents = await tacticalApiClient.getAgents()

// Run a script on an agent
await tacticalApiClient.runScript('agent-123', {
  output: 'email',
  emails: ['admin@example.com'],
  emailMode: 'default',
  custom_field: null,
  save_all_output: true,
  script: 456,
  args: ['--verbose'],
  env_vars: [],
  timeout: 300,
  run_as_user: false,
  run_on_server: false
})

// Get agent system information
const systemInfo = await tacticalApiClient.getAgentSystemInfo('agent-123')

// Create a scheduled task
await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Daily Backup',
  task_type: 'daily',
  run_time_date: '02:00',
  daily_interval: 1,
  actions: [{
    type: 'script',
    name: 'Backup Script',
    script: 789,
    timeout: 1800,
    script_args: [],
    env_vars: [],
    run_as_user: false
  }]
})
```

The client automatically handles tenant-specific URL construction and provides type-safe interfaces for all Tactical RMM API operations.
