Provides a specialized HTTP client for interacting with the Tactical RMM API, extending the base API client with Tactical-specific endpoints and functionality for managing agents, scripts, tasks, and system monitoring.

## Key Components

- **TacticalApiClient**: Main class extending base API client functionality
- **HTTP Methods**: Standard REST operations (GET, POST, PUT, PATCH, DELETE)
- **Agent Management**: Methods for retrieving and managing Tactical RMM agents
- **Script Operations**: Create, update, and execute scripts on remote agents
- **System Monitoring**: Access to logs, services, processes, and system information
- **Task Scheduling**: Create and manage scheduled tasks across agents

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agentsResponse = await tacticalApiClient.getAgents()
if (agentsResponse.success) {
  console.log('Agents:', agentsResponse.data)
}

// Run a script on a specific agent
const scriptResult = await tacticalApiClient.runScript('agent-123', {
  script: 1,
  timeout: 300,
  args: ['--verbose'],
  env_vars: [],
  output: 'wait',
  emails: ['admin@company.com'],
  emailMode: 'default',
  custom_field: null,
  save_all_output: true,
  run_as_user: false,
  run_on_server: false
})

// Create a scheduled task
const taskResponse = await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Daily System Check',
  task_type: 'daily',
  run_time_date: '2024-01-01T09:00:00Z',
  daily_interval: 1,
  actions: [{
    type: 'script',
    name: 'System Health Check',
    script: 5,
    timeout: 600,
    script_args: [],
    env_vars: [],
    run_as_user: false
  }],
  alert_severity: 'warning',
  collector_all_output: true
})

// Get system information for an agent
const systemInfo = await tacticalApiClient.getAgentSystemInfo('agent-123')
```
