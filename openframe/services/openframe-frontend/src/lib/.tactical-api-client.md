A specialized HTTP client for interacting with Tactical RMM (Remote Monitoring & Management) API endpoints. This client extends the base API functionality with Tactical-specific methods for managing agents, scripts, tasks, and system monitoring data.

## Key Components

- **TacticalApiClient class** - Main client with URL building and HTTP method wrappers
- **Agent Management Methods** - `getAgents()`, `getAgent()`, `runScript()`, `runBulkAction()`
- **Script Management Methods** - `getScripts()`, `createScript()`, `updateScript()`
- **System Information Methods** - `getAgentLogs()`, `getAgentSystemInfo()`, `getAgentServices()`
- **Task Management Methods** - `getScheduledTasks()`, `createScheduledTask()`, `deleteScheduledTask()`
- **Monitoring Methods** - `getAgentChecks()`, `getAgentEventLogs()`, `getAgentProcesses()`

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agents = await tacticalApiClient.getAgents()
console.log('Agents:', agents.data)

// Run a script on specific agent
const scriptResult = await tacticalApiClient.runScript('agent-123', {
  script: 456,
  timeout: 300,
  args: ['--verbose'],
  env_vars: [],
  output: 'json',
  emails: ['admin@example.com'],
  emailMode: 'on_failure',
  custom_field: null,
  save_all_output: true,
  run_as_user: false,
  run_on_server: false
})

// Create a scheduled task
const task = await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Daily Backup',
  task_type: 'daily',
  run_time_date: '2024-01-01 02:00:00',
  daily_interval: 1,
  actions: [{
    type: 'script',
    name: 'Backup Script',
    script: 789,
    timeout: 600,
    script_args: [],
    env_vars: [],
    run_as_user: false
  }]
})
```

The client automatically handles URL construction using tenant configuration and provides comprehensive coverage of Tactical RMM's API endpoints for complete remote management capabilities.
