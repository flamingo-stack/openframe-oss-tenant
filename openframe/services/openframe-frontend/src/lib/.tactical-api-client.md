HTTP client for interacting with the Tactical RMM API endpoints. Extends the base API client with Tactical-specific URL routing and comprehensive methods for managing agents, scripts, tasks, and system monitoring.

## Key Components

- **TacticalApiClient**: Main class that extends base API client functionality
- **HTTP Methods**: Standard REST operations (GET, POST, PUT, PATCH, DELETE)
- **Agent Management**: Methods for retrieving and managing RMM agents
- **Script Operations**: Create, update, and execute scripts on remote agents
- **System Monitoring**: Access logs, processes, services, and system information
- **Task Scheduling**: Create and manage scheduled tasks across agents
- **URL Builder**: Constructs proper URLs using tenant host configuration

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agents = await tacticalApiClient.getAgents()

// Run a script on a specific agent
await tacticalApiClient.runScript('agent-123', {
  output: 'wait',
  emails: ['admin@company.com'],
  emailMode: 'default',
  custom_field: null,
  save_all_output: true,
  script: 45,
  args: ['--verbose'],
  env_vars: [],
  timeout: 300,
  run_as_user: false,
  run_on_server: false
})

// Create a scheduled task
await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Daily Backup',
  task_type: 'daily',
  daily_interval: 1,
  run_time_date: '02:00:00',
  actions: [{
    type: 'script',
    name: 'Backup Script',
    script: 12,
    timeout: 600,
    script_args: [],
    env_vars: [],
    run_as_user: false
  }]
})

// Get agent system information
const systemInfo = await tacticalApiClient.getAgentSystemInfo('agent-123')
```
