A specialized API client for Tactical RMM that extends the base API client with remote monitoring and management functionality. It provides methods for managing agents, scripts, scheduled tasks, and system monitoring data within the Tactical RMM ecosystem.

## Key Components

### TacticalApiClient Class
- **Constructor**: Automatically configures the base URL using tenant host configuration
- **HTTP Methods**: Standard REST operations (GET, POST, PUT, PATCH, DELETE) with automatic URL building
- **Agent Management**: Methods for retrieving, monitoring, and managing remote agents
- **Script Operations**: Functions for creating, updating, and executing scripts on agents
- **Scheduled Tasks**: Task creation, deletion, and management capabilities
- **System Information**: Comprehensive system data retrieval (logs, services, processes, etc.)

### Key Methods
- `getAgents()`, `getAgent()` - Agent discovery and details
- `runScript()`, `runBulkAction()` - Script execution and bulk operations
- `createScheduledTask()`, `deleteScheduledTask()` - Task scheduling management
- `getAgentLogs()`, `getAgentEventLogs()` - Monitoring and logging data
- Various system info methods (disk, network, users, services, etc.)

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agents = await tacticalApiClient.getAgents()

// Run a script on a specific agent
const scriptResult = await tacticalApiClient.runScript('agent-123', {
  output: 'wait',
  emails: ['admin@example.com'],
  emailMode: 'default',
  custom_field: null,
  save_all_output: true,
  script: 456,
  args: ['--verbose'],
  env_vars: [],
  timeout: 300,
  run_as_user: false,
  run_on_server: false
})

// Create a scheduled task
const task = await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Daily System Check',
  task_type: 'daily',
  run_time_date: '2024-01-01T09:00:00Z',
  daily_interval: 1,
  actions: [{
    type: 'script',
    name: 'System Health Check',
    script: 789,
    timeout: 600,
    script_args: [],
    env_vars: [],
    run_as_user: false
  }]
})

// Get agent system information
const systemInfo = await tacticalApiClient.getAgentSystemInfo('agent-123')
const diskInfo = await tacticalApiClient.getAgentDiskInfo('agent-123')
```
