A specialized API client that extends the base client with comprehensive Tactical RMM functionality, providing methods for managing agents, scripts, scheduled tasks, and system monitoring data.

## Key Components

- **TacticalApiClient** - Main class extending base API functionality
- **URL Building** - `buildTacticalUrl()` constructs tenant-specific Tactical RMM endpoints
- **HTTP Methods** - Standard REST operations (GET, POST, PUT, PATCH, DELETE)
- **Agent Management** - Methods for retrieving and managing Tactical RMM agents
- **Script Operations** - Create, update, run scripts on agents
- **System Monitoring** - Access logs, processes, services, and system information
- **Task Management** - Create and manage scheduled tasks

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agents = await tacticalApiClient.getAgents()

// Get specific agent details
const agent = await tacticalApiClient.getAgent('agent-id-123')

// Run a script on an agent
const scriptResult = await tacticalApiClient.runScript('agent-id-123', {
  script: 42,
  args: ['--verbose'],
  timeout: 300,
  output: 'wait',
  emails: ['admin@example.com'],
  emailMode: 'default',
  custom_field: null,
  save_all_output: true,
  env_vars: [],
  run_as_user: false,
  run_on_server: false
})

// Create a scheduled task
const task = await tacticalApiClient.createScheduledTask('agent-id-123', {
  name: 'Daily Maintenance',
  task_type: 'daily',
  run_time_date: '2024-01-01T02:00:00Z',
  daily_interval: 1,
  actions: [{
    type: 'script',
    name: 'System Cleanup',
    script: 15,
    timeout: 600,
    script_args: [],
    env_vars: [],
    run_as_user: false
  }]
})

// Get agent system information
const systemInfo = await tacticalApiClient.getAgentSystemInfo('agent-id-123')
```
