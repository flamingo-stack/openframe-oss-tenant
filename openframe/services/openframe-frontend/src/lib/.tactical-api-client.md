A specialized API client that provides typed access to Tactical RMM (Remote Monitoring and Management) endpoints. Extends the base API client with Tactical-specific URL handling and comprehensive methods for managing agents, scripts, and monitoring operations.

## Key Components

- **TacticalApiClient** - Main client class with tenant-aware URL construction
- **Standard HTTP Methods** - `get()`, `post()`, `put()`, `patch()`, `delete()` with JSON serialization
- **Agent Management** - Methods for retrieving agents, running scripts, and bulk operations
- **Script Management** - CRUD operations for automation scripts
- **Monitoring Data** - Access to logs, checks, tasks, system info, and performance metrics
- **Task Scheduling** - Create and manage scheduled automation tasks

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all managed agents
const agentsResponse = await tacticalApiClient.getAgents()
const agents = agentsResponse.data

// Run a script on a specific agent
const scriptResult = await tacticalApiClient.runScript('agent-123', {
  output: 'wait',
  emails: ['admin@example.com'],
  emailMode: 'default',
  custom_field: null,
  save_all_output: true,
  script: 456,
  args: ['--verbose'],
  env_vars: [],
  timeout: 300,
  run_as_user: false,
  run_on_server: false
})

// Get system information for monitoring
const systemInfo = await tacticalApiClient.getAgentSystemInfo('agent-123')
const diskInfo = await tacticalApiClient.getAgentDiskInfo('agent-123')

// Create a scheduled maintenance task
const task = await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Weekly Cleanup',
  task_type: 'weekly',
  run_time_date: '2024-01-15T02:00:00Z',
  weekly_interval: 1,
  actions: [{
    type: 'script',
    name: 'Cleanup Script',
    script: 789,
    timeout: 600,
    script_args: [],
    env_vars: [],
    run_as_user: false
  }]
})
```
