A specialized API client that extends base API functionality to interact with Tactical RMM's comprehensive endpoint suite. It handles URL construction for multi-tenant environments and provides typed methods for agent management, script execution, monitoring, and system administration.

## Key Components

- **TacticalApiClient**: Main class that wraps the base API client with Tactical RMM-specific functionality
- **HTTP Methods**: Standard REST operations (GET, POST, PUT, PATCH, DELETE) with automatic URL building
- **Agent Operations**: Complete agent lifecycle management including retrieval, script execution, and bulk actions
- **Script Management**: CRUD operations for Tactical RMM scripts with full configuration support
- **System Monitoring**: Comprehensive system information retrieval (logs, services, processes, network, etc.)
- **Task Scheduling**: Automated task creation and management with flexible scheduling options

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agents = await tacticalApiClient.getAgents()

// Run a script on a specific agent
const scriptResult = await tacticalApiClient.runScript('agent-123', {
  output: 'wait',
  emails: ['admin@company.com'],
  emailMode: 'onfail',
  custom_field: null,
  save_all_output: true,
  script: 42,
  args: ['--verbose'],
  env_vars: [],
  timeout: 300,
  run_as_user: false,
  run_on_server: false
})

// Create a scheduled task
const task = await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Daily System Check',
  task_type: 'daily',
  run_time_date: '2024-01-01T09:00:00',
  daily_interval: 1,
  actions: [{
    type: 'script',
    name: 'System Health Check',
    script: 15,
    timeout: 600,
    script_args: [],
    env_vars: [],
    run_as_user: false
  }],
  alert_severity: 'warning'
})

// Get system information for monitoring
const systemInfo = await tacticalApiClient.getAgentSystemInfo('agent-123')
const diskInfo = await tacticalApiClient.getAgentDiskInfo('agent-123')
const logs = await tacticalApiClient.getAgentLogs('agent-123', {
  limit: 50,
  search: 'error'
})
```
