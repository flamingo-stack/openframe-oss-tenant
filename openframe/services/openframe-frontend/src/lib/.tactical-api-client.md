A specialized API client that extends the base API functionality to interact with Tactical RMM (Remote Monitoring and Management) services, providing comprehensive methods for agent management, script execution, and system monitoring.

## Key Components

- **`TacticalApiClient`** - Main class that handles Tactical RMM-specific API operations
- **`tacticalApiClient`** - Singleton instance ready for use throughout the application
- **HTTP Methods** - Standard REST methods (GET, POST, PUT, PATCH, DELETE) with Tactical URL handling
- **Agent Management** - Methods for retrieving and managing RMM agents
- **Script Operations** - Functions for creating, updating, and executing scripts on agents
- **System Monitoring** - Endpoints for logs, services, processes, and system information
- **Task Scheduling** - Methods for creating and managing scheduled tasks

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agents = await tacticalApiClient.getAgents()

// Run a script on a specific agent
const scriptResult = await tacticalApiClient.runScript('agent-123', {
  output: 'console',
  emails: ['admin@company.com'],
  emailMode: 'default',
  custom_field: null,
  save_all_output: true,
  script: 456,
  args: ['--verbose'],
  env_vars: [],
  timeout: 300,
  run_as_user: false,
  run_on_server: false
})

// Create a scheduled task
const task = await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Daily Health Check',
  task_type: 'daily',
  run_time_date: '09:00',
  daily_interval: 1,
  actions: [{
    type: 'script',
    name: 'Health Check Script',
    script: 789,
    timeout: 120,
    script_args: [],
    env_vars: [],
    run_as_user: false
  }]
})

// Get system information for an agent
const systemInfo = await tacticalApiClient.getAgentSystemInfo('agent-123')
```
