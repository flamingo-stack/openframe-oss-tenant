A specialized API client for Tactical RMM that extends the base API client with Tactical-specific endpoints and functionality. It handles URL construction for tenant-aware routing and provides comprehensive methods for managing agents, scripts, tasks, and system monitoring.

## Key Components

- **TacticalApiClient** - Main class extending base API functionality with Tactical RMM-specific methods
- **HTTP Methods** - Standard REST operations (GET, POST, PUT, PATCH, DELETE) with JSON body handling
- **Agent Management** - Methods for retrieving agents, running scripts, and bulk operations
- **Script Management** - CRUD operations for managing Tactical RMM scripts
- **System Monitoring** - Methods for accessing logs, services, processes, and system information
- **Task Scheduling** - Operations for managing scheduled tasks with complex configuration options
- **tacticalApiClient** - Singleton instance ready for use throughout the application

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agents = await tacticalApiClient.getAgents()

// Run a script on a specific agent
await tacticalApiClient.runScript('agent-123', {
  output: 'wait',
  emails: ['admin@example.com'],
  emailMode: 'default',
  custom_field: null,
  save_all_output: true,
  script: 42,
  args: ['--verbose'],
  env_vars: [],
  timeout: 300,
  run_as_user: false,
  run_on_server: false
})

// Create a scheduled task
await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Daily Backup',
  task_type: 'daily',
  daily_interval: 1,
  run_time_date: '2024-01-01T02:00:00Z',
  actions: [{
    type: 'script',
    name: 'Backup Script',
    script: 15,
    timeout: 1800,
    script_args: ['--full'],
    env_vars: [],
    run_as_user: false
  }]
})

// Get system information for an agent
const systemInfo = await tacticalApiClient.getAgentSystemInfo('agent-123')
```
