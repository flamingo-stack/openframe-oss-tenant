A specialized HTTP client for interacting with Tactical RMM API endpoints, extending the base API client with Tactical-specific functionality for managing agents, scripts, tasks, and system monitoring.

## Key Components

- **TacticalApiClient**: Main class that provides methods for all Tactical RMM operations
- **HTTP Methods**: Standard REST methods (GET, POST, PUT, PATCH, DELETE) with automatic JSON handling
- **Agent Management**: Methods for retrieving agent data, running scripts, and bulk operations
- **Script Operations**: CRUD operations for managing automation scripts
- **System Monitoring**: Methods for accessing logs, services, processes, and system information
- **Task Scheduling**: Interface for creating and managing scheduled tasks

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agentsResponse = await tacticalApiClient.getAgents()
console.log('Agents:', agentsResponse.data)

// Run a script on a specific agent
const scriptResult = await tacticalApiClient.runScript('agent-123', {
  output: 'wait',
  emails: ['admin@example.com'],
  emailMode: 'default',
  custom_field: null,
  save_all_output: true,
  script: 42,
  args: ['--verbose'],
  env_vars: [],
  timeout: 300,
  run_as_user: false,
  run_on_server: false
})

// Create a new scheduled task
const taskData = {
  actions: [{
    type: 'script',
    name: 'System Check',
    script: 1,
    timeout: 60,
    script_args: [],
    env_vars: [],
    run_as_user: false
  }],
  name: 'Daily System Check',
  task_type: 'daily',
  run_time_date: '2024-01-01T09:00:00Z',
  daily_interval: 1
}

const newTask = await tacticalApiClient.createScheduledTask('agent-123', taskData)
```
