A typed HTTP client for interacting with the Tactical RMM API, routing requests through the base `apiClient` with tenant-aware URL construction.

## Key Components

**`TacticalApiClient` class** — Wraps the shared `apiClient` with Tactical RMM-specific base URL resolution and domain methods.

**Core HTTP methods**
- `request()` — Low-level method; builds the full Tactical URL and delegates to `apiClient`
- `get()`, `post()`, `put()`, `patch()`, `delete()` — Convenience wrappers with JSON body serialization

**Agent methods**
- `getAgents()` / `getAgent(agentId)` — List or fetch a single agent
- `runScript(agentId, scriptData)` — Execute a script on a specific agent
- `runBulkAction(payload)` — Run actions across multiple agents
- `getAgentLogs()`, `getAgentChecks()`, `getAgentTasks()`, `getAgentServices()`, `getAgentProcesses()`, `getAgentSoftware()`, `getAgentWindowsServices()`, `getAgentEventLogs()`, `getAgentSystemInfo()`, `getAgentDiskInfo()`, `getAgentNetworkInfo()`, `getAgentUsers()`, `getAgentGroups()`, `getAgentPolicies()`, `getAgentChecksHistory()` — Agent telemetry and inventory queries

**Script methods**
- `getScripts()` / `getScriptsV2(params)` — List scripts; v2 supports cursor pagination and platform filtering
- `getScript(scriptId)` — Fetch a single script
- `createScript(scriptData)` / `updateScript(scriptId, scriptData)` — Manage script definitions

**Script Schedule methods**
- CRUD: `getScriptSchedules()`, `getScriptSchedule()`, `createScriptSchedule()`, `updateScriptSchedule()`, `deleteScriptSchedule()`
- Agent assignment: `getScriptScheduleAgents()`, `replaceScriptScheduleAgents()`, `addScriptScheduleAgents()`, `removeScriptScheduleAgents()`
- `getScriptScheduleHistory()` — Paginated execution history

**Scheduled Task methods**
- `getScheduledTasks()`, `getScheduledTask()`, `deleteScheduledTask()`, `createScheduledTask()` — Full lifecycle for agent-bound scheduled tasks (supports daily, weekly, monthly, runonce types)

**Singleton export** — `tacticalApiClient` is the pre-instantiated instance for direct import.

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client';

// Fetch all agents
const { data: agents } = await tacticalApiClient.getAgents();

// Run a script on a specific agent
const result = await tacticalApiClient.runScript('agent-123', {
  script: 42,
  args: [],
  env_vars: [],
  timeout: 90,
  output: 'forget',
  emails: [],
  emailMode: 'default',
  custom_field: null,
  save_all_output: false,
  run_as_user: false,
  run_on_server: false,
});

// Paginated script listing with platform filter
const { data } = await tacticalApiClient.getScriptsV2({
  search: 'disk cleanup',
  page_size: 20,
  supported_platforms: 'windows',
});
```
