A TypeScript API client specifically designed for interacting with Tactical RMM endpoints, extending the base API client with Tactical-specific functionality including agent management, script execution, and system monitoring capabilities.

## Key Components

- **TacticalApiClient** - Main client class extending base API functionality
- **HTTP Methods** - Standard REST operations (GET, POST, PUT, PATCH, DELETE)
- **Agent Operations** - Methods for managing and querying Tactical RMM agents
- **Script Management** - Create, update, and execute scripts on agents
- **System Monitoring** - Access logs, processes, services, and system information
- **Task Scheduling** - Create and manage scheduled tasks on agents

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agents = await tacticalApiClient.getAgents()

// Get specific agent details
const agent = await tacticalApiClient.getAgent('agent-123')

// Execute a script on an agent
const scriptResult = await tacticalApiClient.runScript('agent-123', {
  output: 'wait',
  emails: ['admin@example.com'],
  emailMode: 'onfail',
  custom_field: null,
  save_all_output: true,
  script: 456,
  args: ['--verbose'],
  env_vars: [],
  timeout: 300,
  run_as_user: false,
  run_on_server: false
})

// Create a new script
const newScript = await tacticalApiClient.createScript({
  name: 'System Check',
  shell: 'powershell',
  default_timeout: 300,
  args: [],
  script_body: 'Get-ComputerInfo | Select-Object TotalPhysicalMemory',
  run_as_user: false,
  env_vars: [],
  description: 'Check system memory',
  supported_platforms: ['windows'],
  category: 'system'
})

// Schedule a task
const task = await tacticalApiClient.createScheduledTask('agent-123', {
  actions: [{
    type: 'script',
    name: 'Daily Check',
    script: 789,
    timeout: 60,
    script_args: [],
    env_vars: [],
    run_as_user: false
  }],
  name: 'Daily System Check',
  task_type: 'daily',
  run_time_date: '2024-01-01T09:00:00Z',
  daily_interval: 1
})
```
