Specialized API client for Tactical RMM integration that extends the base API client with MSP-specific functionality for managing agents, scripts, and system monitoring tasks.

## Key Components

- **TacticalApiClient** - Main client class providing HTTP methods and Tactical-specific operations
- **buildTacticalUrl()** - URL construction method that handles tenant-specific routing
- **Agent Management** - Methods for retrieving, monitoring, and managing RMM agents
- **Script Operations** - Complete CRUD operations for automation scripts
- **System Information** - Methods for accessing logs, services, processes, and system data
- **Task Scheduling** - Automated task creation and management functionality

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all managed agents
const agentsResponse = await tacticalApiClient.getAgents()

// Execute script on specific agent
await tacticalApiClient.runScript('agent-123', {
  script: 456,
  args: ['--verbose'],
  timeout: 300,
  run_as_user: false,
  output: 'wait',
  emails: ['admin@example.com'],
  emailMode: 'default'
})

// Create scheduled maintenance task
await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Weekly System Update',
  task_type: 'weekly',
  run_time_date: '2024-01-15T02:00:00Z',
  actions: [{
    type: 'script',
    name: 'Update Script',
    script: 789,
    timeout: 1800
  }]
})

// Monitor agent system information
const systemInfo = await tacticalApiClient.getAgentSystemInfo('agent-123')
const diskInfo = await tacticalApiClient.getAgentDiskInfo('agent-123')
```
