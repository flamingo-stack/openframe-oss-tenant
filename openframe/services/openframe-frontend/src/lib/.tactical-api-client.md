A specialized API client for integrating with Tactical RMM, providing type-safe methods for agent management, script execution, and system monitoring operations. It extends the base API client with Tactical-specific functionality and URL routing.

## Key Components

- **TacticalApiClient**: Main class that provides HTTP methods (GET, POST, PUT, PATCH, DELETE) and Tactical-specific endpoints
- **tacticalApiClient**: Singleton instance ready for use throughout the application
- **URL Management**: Builds proper URLs from tenant host configuration with `/tools/tactical-rmm` prefix
- **Agent Operations**: Methods for retrieving agents, running scripts, and managing bulk actions
- **Script Management**: CRUD operations for script templates and execution
- **System Information**: Methods for accessing logs, services, processes, and system details
- **Task Scheduling**: Operations for managing scheduled tasks with various timing options

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agents = await tacticalApiClient.getAgents()

// Run a script on a specific agent
await tacticalApiClient.runScript('agent-123', {
  script: 456,
  timeout: 300,
  args: ['--verbose'],
  env_vars: [],
  output: 'wait',
  emails: ['admin@example.com'],
  emailMode: 'default',
  custom_field: null,
  save_all_output: true,
  run_as_user: false,
  run_on_server: false
})

// Create a scheduled task
await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Daily Backup',
  task_type: 'daily',
  run_time_date: '2024-01-01T02:00:00Z',
  daily_interval: 1,
  actions: [{
    type: 'script',
    name: 'Backup Script',
    script: 789,
    timeout: 600,
    script_args: ['--full'],
    env_vars: [],
    run_as_user: false
  }]
})
```
