Specialized API client for interacting with Tactical RMM endpoints, extending the base API client with RMM-specific methods for agents, scripts, tasks, and system monitoring.

## Key Components

- **TacticalApiClient**: Main class that wraps the base API client with Tactical RMM-specific functionality
- **HTTP Methods**: Standard REST methods (get, post, put, patch, delete) with automatic URL building
- **Agent Management**: Methods for retrieving agent data, system info, logs, and running scripts
- **Script Operations**: CRUD operations for managing Tactical RMM scripts
- **Task Scheduling**: Methods for creating and managing scheduled tasks
- **System Monitoring**: Access to agent services, processes, software, and event logs

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agents = await tacticalApiClient.getAgents()

// Get specific agent details
const agent = await tacticalApiClient.getAgent('agent-123')

// Run a script on an agent
const scriptResult = await tacticalApiClient.runScript('agent-123', {
  script: 1,
  output: 'both',
  emails: ['admin@company.com'],
  emailMode: 'success',
  custom_field: null,
  save_all_output: true,
  args: ['--verbose'],
  env_vars: [],
  timeout: 300,
  run_as_user: false,
  run_on_server: false
})

// Create a new scheduled task
const task = await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Daily System Check',
  task_type: 'daily',
  run_time_date: '2024-01-01 09:00:00',
  daily_interval: 1,
  actions: [{
    type: 'script',
    name: 'System Health Check',
    script: 5,
    timeout: 300,
    script_args: [],
    env_vars: [],
    run_as_user: false
  }]
})

// Get agent system information
const systemInfo = await tacticalApiClient.getAgentSystemInfo('agent-123')
```
