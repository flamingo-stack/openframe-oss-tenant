Specialized API client for Tactical RMM that extends the base client with endpoints for managing agents, scripts, logs, and system monitoring within the Tactical RMM platform.

## Key Components

**TacticalApiClient**: Main class providing Tactical RMM-specific API methods
- Constructor builds base URL from tenant host configuration
- HTTP methods: `get()`, `post()`, `put()`, `patch()`, `delete()`
- Agent management: `getAgents()`, `getAgent()`, `runScript()`, `runBulkAction()`
- Script operations: `getScripts()`, `createScript()`, `updateScript()`
- System monitoring: `getAgentLogs()`, `getAgentChecks()`, `getAgentServices()`
- Task scheduling: `createScheduledTask()`, `getScheduledTasks()`

**tacticalApiClient**: Pre-configured singleton instance ready for use

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agentsResponse = await tacticalApiClient.getAgents()
const agents = agentsResponse.data

// Run a script on specific agent
await tacticalApiClient.runScript('agent-123', {
  output: 'wait',
  emails: ['admin@example.com'],
  emailMode: 'failure',
  custom_field: null,
  save_all_output: true,
  script: 456,
  args: ['--verbose'],
  env_vars: [],
  timeout: 300,
  run_as_user: false,
  run_on_server: false
})

// Create scheduled task
await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Daily Backup',
  task_type: 'daily',
  daily_interval: 1,
  run_time_date: '2024-01-01 02:00:00',
  actions: [{
    type: 'script',
    name: 'Backup Script',
    script: 789,
    timeout: 3600,
    script_args: ['--full'],
    env_vars: [],
    run_as_user: false
  }]
})
```
