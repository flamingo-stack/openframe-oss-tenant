A specialized API client that extends the base API functionality to provide comprehensive access to Tactical RMM (Remote Monitoring and Management) services, including agent management, script execution, and system monitoring operations.

## Key Components

**TacticalApiClient Class:**
- `constructor()` - Initializes client with tenant-specific base URL
- `buildTacticalUrl()` - Handles URL construction for Tactical RMM endpoints
- HTTP methods: `get()`, `post()`, `put()`, `patch()`, `delete()`
- **Agent Operations:** `getAgents()`, `getAgent()`, `runScript()`, `runBulkAction()`
- **Script Management:** `getScripts()`, `createScript()`, `updateScript()`
- **System Information:** `getAgentSystemInfo()`, `getAgentDiskInfo()`, `getAgentNetworkInfo()`
- **Monitoring:** `getAgentLogs()`, `getAgentChecks()`, `getAgentEventLogs()`
- **Task Management:** `getScheduledTasks()`, `createScheduledTask()`, `deleteScheduledTask()`

**Exports:**
- `tacticalApiClient` - Pre-configured singleton instance
- `TacticalApiClient` - Class for creating custom instances
- Type exports: `ApiRequestOptions`, `ApiResponse`

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all managed agents
const agentsResponse = await tacticalApiClient.getAgents()
console.log('Agents:', agentsResponse.data)

// Run a script on a specific agent
const scriptResult = await tacticalApiClient.runScript('agent-123', {
  output: 'console',
  emails: ['admin@company.com'],
  emailMode: 'error',
  custom_field: null,
  save_all_output: true,
  script: 456,
  args: ['--verbose'],
  env_vars: [],
  timeout: 300,
  run_as_user: false,
  run_on_server: false
})

// Get system information for an agent
const systemInfo = await tacticalApiClient.getAgentSystemInfo('agent-123')
console.log('System Info:', systemInfo.data)

// Create a scheduled task
await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Daily Backup',
  task_type: 'daily',
  run_time_date: '02:00',
  daily_interval: 1,
  actions: [{
    type: 'script',
    name: 'Backup Script',
    script: 789,
    timeout: 3600,
    script_args: ['--full'],
    env_vars: [],
    run_as_user: false
  }]
})
```
