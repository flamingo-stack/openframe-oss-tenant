A specialized API client for Tactical RMM (Remote Monitoring and Management) that extends the base API client with Tactical-specific endpoints and functionality. It handles URL construction for tenant-based routing and provides type-safe methods for managing agents, scripts, tasks, and system monitoring.

## Key Components

- **TacticalApiClient** - Main class extending base API functionality with Tactical RMM specific methods
- **HTTP Methods** - Standard REST methods (`get`, `post`, `put`, `patch`, `delete`) with automatic JSON serialization
- **Agent Management** - Methods for retrieving agent data, logs, system info, and running scripts
- **Script Operations** - CRUD operations for managing and executing scripts on agents
- **Task Scheduling** - Methods for creating and managing scheduled tasks
- **System Monitoring** - Endpoints for accessing services, processes, event logs, and hardware info

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agents = await tacticalApiClient.getAgents()

// Run a script on a specific agent
const scriptResult = await tacticalApiClient.runScript('agent-123', {
  output: 'wait',
  emails: ['admin@company.com'],
  emailMode: 'always',
  custom_field: null,
  save_all_output: true,
  script: 42,
  args: ['--verbose'],
  env_vars: [],
  timeout: 300,
  run_as_user: false,
  run_on_server: false
})

// Create a scheduled task
const task = await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Daily Backup',
  task_type: 'daily',
  run_time_date: '2024-01-01T02:00:00',
  daily_interval: 1,
  actions: [{
    type: 'script',
    name: 'Backup Script',
    script: 15,
    timeout: 1800,
    script_args: ['--full'],
    env_vars: [],
    run_as_user: true
  }]
})

// Get system information for an agent
const systemInfo = await tacticalApiClient.getAgentSystemInfo('agent-123')
```
