Specialized HTTP client that extends the base API client with Tactical RMM-specific endpoints and functionality. Automatically handles URL construction for Tactical RMM API routes using tenant host configuration.

## Key Components

- **`TacticalApiClient`** - Main class providing Tactical RMM API methods
- **HTTP Methods** - `get`, `post`, `put`, `patch`, `delete` with automatic JSON handling
- **Agent Operations** - Methods for managing agents, running scripts, and bulk actions
- **Script Management** - CRUD operations for Tactical RMM scripts
- **System Information** - Endpoints for logs, checks, tasks, services, and system data
- **Scheduled Tasks** - Create and manage automated tasks on agents
- **`tacticalApiClient`** - Pre-configured singleton instance

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agentsResponse = await tacticalApiClient.getAgents()
console.log('Agents:', agentsResponse.data)

// Get specific agent details
const agent = await tacticalApiClient.getAgent('agent-123')

// Run a script on an agent
const scriptResult = await tacticalApiClient.runScript('agent-123', {
  output: 'wait',
  emails: ['admin@example.com'],
  emailMode: 'onfail',
  custom_field: null,
  save_all_output: true,
  script: 42,
  args: ['--verbose'],
  env_vars: [],
  timeout: 300,
  run_as_user: false,
  run_on_server: false
})

// Create a scheduled task
const task = await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Daily Backup',
  task_type: 'daily',
  run_time_date: '2024-01-01T02:00:00Z',
  daily_interval: 1,
  actions: [{
    type: 'script',
    name: 'Backup Script',
    script: 15,
    timeout: 600,
    script_args: ['--full'],
    env_vars: [],
    run_as_user: false
  }]
})
```
