A specialized API client for interacting with Tactical RMM endpoints, extending the base API client with RMM-specific functionality for managing agents, scripts, tasks, and system monitoring.

## Key Components

- **TacticalApiClient**: Main client class that handles Tactical RMM API requests
- **Base HTTP Methods**: `get`, `post`, `put`, `patch`, `delete` with automatic JSON serialization
- **Agent Management**: Methods for retrieving agent information, logs, checks, and system details
- **Script Operations**: Create, update, and execute scripts on managed endpoints
- **Task Scheduling**: Create and manage scheduled tasks with various timing options
- **System Monitoring**: Access agent services, processes, software, and event logs
- **Bulk Actions**: Execute operations across multiple agents simultaneously

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all managed agents
const agentsResponse = await tacticalApiClient.getAgents()
const agents = agentsResponse.data

// Run a script on a specific agent
await tacticalApiClient.runScript('agent-123', {
  script: 456,
  args: ['--verbose'],
  timeout: 300,
  output: 'wait',
  emails: ['admin@company.com'],
  emailMode: 'onfail',
  custom_field: null,
  save_all_output: true,
  env_vars: [],
  run_as_user: false,
  run_on_server: false
})

// Create a scheduled task
await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Daily Backup Check',
  task_type: 'daily',
  daily_interval: 1,
  run_time_date: '2024-01-01T02:00:00Z',
  actions: [{
    type: 'script',
    name: 'backup-verification',
    script: 789,
    timeout: 600,
    script_args: ['--check-integrity'],
    env_vars: [],
    run_as_user: false
  }]
})

// Get system information for an agent
const systemInfo = await tacticalApiClient.getAgentSystemInfo('agent-123')
const diskInfo = await tacticalApiClient.getAgentDiskInfo('agent-123')
```
