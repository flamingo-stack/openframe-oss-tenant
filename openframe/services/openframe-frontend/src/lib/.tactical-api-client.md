A specialized API client for Tactical RMM that extends the base API functionality with comprehensive endpoint coverage for agent management, monitoring, and automation tasks.

## Key Components

- **TacticalApiClient class** - Main client with URL building and HTTP methods
- **tacticalApiClient singleton** - Pre-configured instance ready for use
- **Agent Management** - Methods for retrieving and managing RMM agents
- **Script Operations** - Execute, create, and update scripts on managed endpoints
- **Monitoring APIs** - Access logs, checks, services, and system information
- **Task Scheduling** - Create and manage scheduled automation tasks

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all managed agents
const agents = await tacticalApiClient.getAgents()

// Execute a script on a specific agent
const scriptResult = await tacticalApiClient.runScript('agent-123', {
  script: 456,
  args: ['--verbose'],
  timeout: 300,
  run_as_user: false,
  emails: ['admin@company.com'],
  emailMode: 'always',
  output: 'console',
  save_all_output: true,
  custom_field: null,
  env_vars: [],
  run_on_server: false
})

// Monitor agent system information
const systemInfo = await tacticalApiClient.getAgentSystemInfo('agent-123')
const diskInfo = await tacticalApiClient.getAgentDiskInfo('agent-123')

// Create a scheduled maintenance task
const task = await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Weekly System Cleanup',
  task_type: 'weekly',
  run_time_date: '2024-01-01T02:00:00Z',
  actions: [{
    type: 'script',
    name: 'Cleanup Script',
    script: 789,
    timeout: 600,
    script_args: ['--deep-clean'],
    env_vars: [],
    run_as_user: false
  }]
})
```
