A specialized API client that extends base HTTP functionality with methods specifically designed for interacting with Tactical RMM (Remote Monitoring and Management) systems, providing complete access to agents, scripts, tasks, and system monitoring endpoints.

## Key Components

- **TacticalApiClient**: Main class providing Tactical RMM-specific API methods
- **HTTP Methods**: Standard REST operations (GET, POST, PUT, PATCH, DELETE) with automatic JSON serialization
- **Agent Management**: Methods for retrieving agent information, logs, checks, and system details
- **Script Operations**: Create, update, and execute scripts on remote agents
- **Task Scheduling**: Manage scheduled tasks with various timing options
- **System Monitoring**: Access system info, processes, services, and event logs
- **Bulk Actions**: Execute operations across multiple agents simultaneously

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agents = await tacticalApiClient.getAgents()
console.log(agents.data)

// Run a script on a specific agent
const scriptResult = await tacticalApiClient.runScript('agent-123', {
  output: 'wait',
  emails: ['admin@company.com'],
  emailMode: 'default',
  custom_field: null,
  save_all_output: true,
  script: 456,
  args: ['--verbose'],
  env_vars: [],
  timeout: 300,
  run_as_user: false,
  run_on_server: false
})

// Create a daily scheduled task
const task = await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Daily System Check',
  task_type: 'daily',
  run_time_date: '2024-01-01 09:00:00',
  daily_interval: 1,
  actions: [{
    type: 'script',
    name: 'System Health Check',
    script: 789,
    timeout: 600,
    script_args: [],
    env_vars: [],
    run_as_user: false
  }]
})

// Get system information for an agent
const systemInfo = await tacticalApiClient.getAgentSystemInfo('agent-123')
const diskInfo = await tacticalApiClient.getAgentDiskInfo('agent-123')
const processes = await tacticalApiClient.getAgentProcesses('agent-123')
```
