A specialized API client for interacting with Tactical RMM (Remote Monitoring and Management) endpoints, extending the base API client with Tactical-specific functionality and agent management capabilities.

## Key Components

- **TacticalApiClient**: Main class providing Tactical RMM-specific API methods
- **buildTacticalUrl()**: Private method for constructing Tactical RMM endpoints using tenant host configuration
- **Standard HTTP methods**: `get()`, `post()`, `put()`, `patch()`, `delete()` with Tactical RMM URL prefixing
- **Agent management methods**: Methods for retrieving, managing, and executing scripts on agents
- **Script management**: CRUD operations for managing automation scripts
- **System monitoring**: Methods for accessing logs, checks, tasks, services, and system information
- **Scheduled tasks**: Creation and management of automated task scheduling

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agentsResponse = await tacticalApiClient.getAgents()

// Get specific agent details
const agentResponse = await tacticalApiClient.getAgent('agent-id-123')

// Run a script on an agent
const scriptResult = await tacticalApiClient.runScript('agent-id-123', {
  script: 42,
  timeout: 300,
  args: ['--verbose'],
  env_vars: [],
  output: 'collect',
  emails: ['admin@example.com'],
  emailMode: 'onfail',
  custom_field: null,
  save_all_output: true,
  run_as_user: false,
  run_on_server: false
})

// Create a new scheduled task
const taskResponse = await tacticalApiClient.createScheduledTask('agent-id-123', {
  name: 'Daily Backup',
  task_type: 'daily',
  run_time_date: '02:00:00',
  daily_interval: 1,
  actions: [{
    type: 'script',
    name: 'Backup Script',
    script: 15,
    timeout: 1800,
    script_args: ['--full'],
    env_vars: [],
    run_as_user: false
  }]
})

// Get agent system information
const systemInfo = await tacticalApiClient.getAgentSystemInfo('agent-id-123')
```
