A specialized API client for Tactical RMM integration that extends the base API client with MSP-specific functionality including agent management, script execution, and system monitoring capabilities.

## Key Components

### **TacticalApiClient Class**
- **Constructor**: Builds base URL from tenant host configuration
- **HTTP Methods**: `get()`, `post()`, `put()`, `patch()`, `delete()` - Standard REST operations
- **Agent Management**: `getAgents()`, `getAgent()`, `runScript()`, `runBulkAction()`
- **Script Operations**: `getScripts()`, `createScript()`, `updateScript()`
- **System Monitoring**: `getAgentLogs()`, `getAgentServices()`, `getAgentProcesses()`
- **Task Management**: `getScheduledTasks()`, `createScheduledTask()`, `deleteScheduledTask()`

### **Exports**
- `tacticalApiClient` - Singleton instance ready for use
- `TacticalApiClient` - Class for custom instances
- Type exports: `ApiRequestOptions`, `ApiResponse`

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agents = await tacticalApiClient.getAgents()

// Run a script on specific agent
await tacticalApiClient.runScript('agent-123', {
  script: 42,
  args: ['--verbose'],
  timeout: 300,
  output: 'wait',
  emails: ['admin@company.com'],
  emailMode: 'onfail',
  custom_field: null,
  save_all_output: true,
  env_vars: [],
  run_as_user: false,
  run_on_server: false
})

// Create scheduled maintenance task
await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Weekly System Check',
  task_type: 'weekly',
  run_time_date: '2024-01-15T02:00:00Z',
  actions: [{
    type: 'script',
    name: 'System Health Check',
    script: 15,
    timeout: 600,
    script_args: [],
    env_vars: [],
    run_as_user: false
  }]
})
```
