A specialized API client that provides Tactical RMM-specific functionality by extending the base API client with pre-configured endpoints and methods for managing agents, scripts, tasks, and system monitoring.

## Key Components

- **TacticalApiClient** - Main class extending base API functionality with Tactical RMM endpoints
- **buildTacticalUrl()** - Private method for constructing Tactical-specific URLs
- **HTTP Methods** - Standard REST methods (GET, POST, PUT, PATCH, DELETE) with JSON serialization
- **Agent Management** - Methods for retrieving and managing Tactical RMM agents
- **Script Operations** - Creating, updating, and executing scripts on remote agents
- **System Monitoring** - Accessing logs, services, processes, and system information
- **Task Scheduling** - Creating and managing scheduled tasks on agents

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agentsResponse = await tacticalApiClient.getAgents()
const agents = agentsResponse.data

// Run a script on a specific agent
const scriptResult = await tacticalApiClient.runScript('agent-123', {
  output: 'both',
  emails: ['admin@company.com'],
  emailMode: 'default',
  custom_field: null,
  save_all_output: true,
  script: 456,
  args: ['--verbose'],
  env_vars: [],
  timeout: 300,
  run_as_user: false,
  run_on_server: false
})

// Create a scheduled task
const newTask = await tacticalApiClient.createScheduledTask('agent-123', {
  actions: [{
    type: 'script',
    name: 'Daily Maintenance',
    script: 789,
    timeout: 600,
    script_args: [],
    env_vars: [],
    run_as_user: false
  }],
  name: 'Daily System Check',
  task_type: 'daily',
  run_time_date: '2024-01-01T09:00:00Z',
  daily_interval: 1
})
```
