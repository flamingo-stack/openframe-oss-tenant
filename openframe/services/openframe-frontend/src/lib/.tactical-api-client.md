A TypeScript client library that provides a specialized interface for interacting with Tactical RMM API endpoints, extending the base API client with RMM-specific functionality and automatic URL construction.

## Key Components

- **TacticalApiClient** - Main class that extends base API functionality with Tactical RMM-specific methods
- **HTTP Methods** - Standard REST operations (`get`, `post`, `put`, `patch`, `delete`) with automatic JSON serialization
- **Agent Management** - Methods for managing RMM agents (`getAgents`, `getAgent`, `runScript`)
- **Script Operations** - CRUD operations for RMM scripts (`getScripts`, `createScript`, `updateScript`)
- **System Information** - Methods to retrieve agent system data (logs, processes, services, disk info)
- **Task Scheduling** - Operations for managing scheduled tasks on agents
- **URL Building** - Automatic construction of Tactical RMM API URLs from tenant configuration

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agents = await tacticalApiClient.getAgents()

// Run a script on a specific agent
const scriptResult = await tacticalApiClient.runScript('agent-123', {
  script: 456,
  args: ['--verbose'],
  timeout: 300,
  run_as_user: false,
  output: 'wait',
  emails: ['admin@example.com'],
  emailMode: 'default',
  custom_field: null,
  save_all_output: true,
  env_vars: [],
  run_on_server: false
})

// Create a scheduled task
const task = await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Daily Backup',
  task_type: 'daily',
  daily_interval: 1,
  run_time_date: '2024-01-01T02:00:00',
  actions: [{
    type: 'script',
    name: 'Backup Script',
    script: 789,
    timeout: 1800,
    script_args: [],
    env_vars: [],
    run_as_user: false
  }]
})

// Get agent system information
const systemInfo = await tacticalApiClient.getAgentSystemInfo('agent-123')
const diskInfo = await tacticalApiClient.getAgentDiskInfo('agent-123')
```
