A specialized API client for Tactical RMM integration that extends the base API client with comprehensive endpoint coverage for remote monitoring and management operations.

## Key Components

- **TacticalApiClient** - Main class providing Tactical RMM-specific API methods
- **buildTacticalUrl()** - URL construction helper that handles absolute/relative paths
- **HTTP Methods** - Standard REST operations (GET, POST, PUT, PATCH, DELETE)
- **Agent Management** - Methods for managing remote agents and their data
- **Script Operations** - Script execution, creation, and management endpoints
- **System Information** - Hardware, software, and system data retrieval
- **Task Scheduling** - Automated task creation and management

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all managed agents
const agents = await tacticalApiClient.getAgents()

// Execute a script on a specific agent
const scriptResult = await tacticalApiClient.runScript('agent-123', {
  script: 45,
  args: ['--verbose'],
  timeout: 300,
  output: 'both',
  emails: ['admin@company.com'],
  emailMode: 'always',
  custom_field: null,
  save_all_output: true,
  env_vars: [],
  run_as_user: false,
  run_on_server: false
})

// Get system information for an agent
const systemInfo = await tacticalApiClient.getAgentSystemInfo('agent-123')

// Create a scheduled task
const task = await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Daily Cleanup',
  task_type: 'daily',
  run_time_date: '2024-01-01T02:00:00',
  daily_interval: 1,
  actions: [{
    type: 'script',
    name: 'System Cleanup',
    script: 10,
    timeout: 600,
    script_args: ['--deep'],
    env_vars: [],
    run_as_user: false
  }]
})
```
