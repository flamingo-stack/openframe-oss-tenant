A specialized API client for Tactical RMM that extends the base API client with comprehensive endpoint coverage for agents, scripts, tasks, and system monitoring functionality.

## Key Components

- **TacticalApiClient class** - Main client that builds Tactical-specific URLs and provides HTTP methods
- **buildTacticalUrl()** - Private method that constructs full URLs from relative paths
- **HTTP methods** - Standard REST operations (GET, POST, PUT, PATCH, DELETE) with JSON serialization
- **Agent operations** - Methods for managing and querying Tactical RMM agents
- **Script management** - CRUD operations for scripts and script execution
- **System monitoring** - Methods for logs, services, processes, and system information
- **Scheduled tasks** - Task creation, querying, and management functionality

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agents = await tacticalApiClient.getAgents()

// Run a script on a specific agent
const scriptResult = await tacticalApiClient.runScript('agent-123', {
  output: 'console',
  emails: ['admin@example.com'],
  emailMode: 'success',
  custom_field: null,
  save_all_output: true,
  script: 456,
  args: ['--verbose'],
  env_vars: [],
  timeout: 300,
  run_as_user: false,
  run_on_server: false
})

// Get agent system information
const systemInfo = await tacticalApiClient.getAgentSystemInfo('agent-123')

// Create a scheduled task
const task = await tacticalApiClient.createScheduledTask('agent-123', {
  actions: [{
    type: 'script',
    name: 'Daily Backup',
    script: 789,
    timeout: 600,
    script_args: [],
    env_vars: [],
    run_as_user: false
  }],
  name: 'Daily System Backup',
  task_type: 'daily',
  run_time_date: '2024-01-01T02:00:00Z',
  daily_interval: 1
})
```
