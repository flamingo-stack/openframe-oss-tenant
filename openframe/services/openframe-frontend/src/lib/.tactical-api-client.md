Tactical RMM API client that wraps the base `apiClient` with Tactical-specific URL routing and domain-oriented helper methods for agents, scripts, tasks, and schedules.

## Key Components

### `TacticalApiClient` class

Builds requests against the `/tools/tactical-rmm` proxy path (prefixed with the tenant host when configured) and exposes typed methods grouped by resource:

| Group | Methods |
|---|---|
| **HTTP verbs** | `request`, `get`, `post`, `put`, `patch`, `delete` |
| **Agents** | `getAgents`, `getAgent`, `runScript`, `runBulkAction` |
| **Agent detail** | `getAgentLogs`, `getAgentChecks`, `getAgentTasks`, `getAgentServices`, `getAgentProcesses`, `getAgentSoftware`, `getAgentWindowsServices`, `getAgentEventLogs`, `getAgentSystemInfo`, `getAgentDiskInfo`, `getAgentNetworkInfo`, `getAgentUsers`, `getAgentGroups`, `getAgentPolicies`, `getAgentChecksHistory` |
| **Scripts** | `getScripts`, `getScriptsV2`, `getScript`, `createScript`, `updateScript` |
| **Script schedules** | `getScriptSchedules`, `createScriptSchedule`, `updateScriptSchedule`, `deleteScriptSchedule`, `getScriptScheduleAgents`, `replaceScriptScheduleAgents`, `addScriptScheduleAgents`, `removeScriptScheduleAgents`, `getScriptScheduleHistory` |
| **Scheduled tasks** | `getScheduledTasks`, `getScheduledTask`, `createScheduledTask`, `deleteScheduledTask` |

### Singleton export

`tacticalApiClient` — pre-instantiated instance for direct import.

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client';

// Fetch all agents
const { data: agents } = await tacticalApiClient.getAgents();

// Run a script on a specific agent
const result = await tacticalApiClient.runScript('agent-123', {
  script: 42,
  timeout: 90,
  args: [],
  env_vars: [],
  emails: [],
  emailMode: 'default',
  output: 'console',
  custom_field: null,
  save_all_output: false,
  run_as_user: false,
  run_on_server: false,
});

// Paginated script listing (v2)
const page = await tacticalApiClient.getScriptsV2({
  search: 'backup',
  page_size: 25,
  supported_platforms: 'windows',
});
```
