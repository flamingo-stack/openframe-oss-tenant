A specialized API client for interacting with Tactical RMM endpoints, providing type-safe methods for managing agents, scripts, tasks, and system monitoring within the Flamingo/OpenFrame platform.

## Key Components

- **TacticalApiClient** - Main client class extending base API functionality
- **HTTP Methods** - Standard REST methods (get, post, put, patch, delete)
- **Agent Management** - Methods for retrieving and managing Tactical RMM agents
- **Script Operations** - Create, update, and execute scripts on remote agents
- **System Monitoring** - Access logs, services, processes, and system information
- **Task Scheduling** - Create and manage scheduled tasks across agents

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agents = await tacticalApiClient.getAgents()

// Run a script on a specific agent
await tacticalApiClient.runScript('agent-123', {
  output: 'wait',
  emails: ['admin@company.com'],
  emailMode: 'default',
  custom_field: null,
  save_all_output: true,
  script: 42,
  args: ['--verbose'],
  env_vars: [],
  timeout: 300,
  run_as_user: false,
  run_on_server: false
})

// Get agent system information
const systemInfo = await tacticalApiClient.getAgentSystemInfo('agent-123')

// Create a scheduled task
await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Daily Backup',
  task_type: 'daily',
  run_time_date: '02:00',
  daily_interval: 1,
  actions: [{
    type: 'script',
    name: 'Backup Script',
    script: 15,
    timeout: 1800,
    script_args: ['--incremental'],
    env_vars: [],
    run_as_user: false
  }]
})
```
