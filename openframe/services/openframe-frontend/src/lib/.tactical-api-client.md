Specialized API client for Tactical RMM integration that extends the base API client with RMM-specific endpoints for agent management, script execution, monitoring, and system information retrieval.

## Key Components

- **TacticalApiClient**: Main class extending base API functionality with Tactical RMM endpoints
- **tacticalApiClient**: Singleton instance ready for use
- **HTTP Methods**: Standard REST methods (GET, POST, PUT, PATCH, DELETE) with automatic URL building
- **Agent Management**: Methods for retrieving, managing, and monitoring RMM agents
- **Script Operations**: Execute scripts, manage script library, and handle bulk actions
- **System Monitoring**: Access logs, services, processes, system info, and performance data
- **Task Scheduling**: Create and manage scheduled tasks on agents

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all RMM agents
const agents = await tacticalApiClient.getAgents()

// Get specific agent details
const agent = await tacticalApiClient.getAgent('agent-123')

// Execute a script on an agent
const scriptResult = await tacticalApiClient.runScript('agent-123', {
  script: 42,
  args: ['--verbose'],
  timeout: 300,
  output: 'wait',
  emails: ['admin@company.com'],
  emailMode: 'on_error',
  custom_field: null,
  save_all_output: true,
  env_vars: [],
  run_as_user: false,
  run_on_server: false
})

// Get agent system information
const systemInfo = await tacticalApiClient.getAgentSystemInfo('agent-123')

// Create a scheduled task
const task = await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Daily Backup',
  task_type: 'daily',
  run_time_date: '2024-01-01 02:00:00',
  daily_interval: 1,
  actions: [{
    type: 'script',
    name: 'Backup Script',
    script: 15,
    timeout: 1800,
    script_args: [],
    env_vars: [],
    run_as_user: false
  }]
})
```

The client automatically handles URL construction based on tenant configuration and provides comprehensive access to all Tactical RMM API endpoints with proper TypeScript typing.
