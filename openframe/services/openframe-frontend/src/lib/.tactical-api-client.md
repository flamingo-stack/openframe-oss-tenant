A typed HTTP client for the Tactical RMM integration, wrapping the base `apiClient` with Tactical-specific URL routing and domain methods for agents, scripts, scheduled tasks, and script schedules.

## Key Components

**`TacticalApiClient` class**
- **Constructor** — resolves the base URL from `runtimeEnv.tenantHostUrl()`, prefixing all paths with `/tools/tactical-rmm`
- **`buildTacticalUrl(path)`** — normalizes relative paths; passes through absolute URLs unchanged
- **`request / get / post / put / patch / delete`** — generic HTTP methods delegating to `apiClient`

**Domain Methods**

| Group | Methods |
|-------|---------|
| Agents | `getAgents`, `getAgent`, `runScript`, `runBulkAction` |
| Agent Details | `getAgentLogs`, `getAgentChecks`, `getAgentTasks`, `getAgentServices`, `getAgentProcesses`, `getAgentSoftware`, `getAgentWindowsServices`, `getAgentEventLogs`, `getAgentSystemInfo`, `getAgentDiskInfo`, `getAgentNetworkInfo`, `getAgentUsers`, `getAgentGroups`, `getAgentPolicies`, `getAgentChecksHistory` |
| Scripts | `getScripts`, `getScriptsV2`, `getScript`, `createScript`, `updateScript` |
| Script Schedules | `getScriptSchedules`, `createScriptSchedule`, `updateScriptSchedule`, `deleteScriptSchedule`, `getScriptScheduleAgents`, `replaceScriptScheduleAgents`, `addScriptScheduleAgents`, `removeScriptScheduleAgents`, `getScriptScheduleHistory` |
| Scheduled Tasks | `getScheduledTasks`, `getScheduledTask`, `createScheduledTask`, `deleteScheduledTask` |

**Singleton export** — `tacticalApiClient` (pre-instantiated, ready to import)

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client';

// Fetch all agents
const { data: agents } = await tacticalApiClient.getAgents();

// Run a script on a specific agent
const result = await tacticalApiClient.runScript('agent-123', {
  script: 42,
  timeout: 90,
  args: [],
  env_vars: [],
  output: 'web',
  emails: [],
  emailMode: 'always',
  custom_field: null,
  save_all_output: false,
  run_as_user: false,
  run_on_server: false,
});

// Paginated script listing (v2)
const { data } = await tacticalApiClient.getScriptsV2({
  search: 'cleanup',
  page_size: 25,
  supported_platforms: 'windows',
});
```
