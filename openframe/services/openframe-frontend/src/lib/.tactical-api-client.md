A specialized API client that extends the base Flamingo API client with Tactical RMM specific functionality for managing agents, scripts, tasks, and system information.

## Key Components

- **TacticalApiClient**: Main class that wraps HTTP methods with Tactical RMM-specific endpoints
- **tacticalApiClient**: Singleton instance for immediate use
- **HTTP Methods**: Standard REST operations (GET, POST, PUT, PATCH, DELETE) with JSON serialization
- **Agent Management**: Methods for retrieving agents, running scripts, and bulk actions
- **Script Management**: CRUD operations for automation scripts
- **System Information**: Methods for accessing logs, services, processes, and system details
- **Task Scheduling**: Creation and management of scheduled tasks with complex timing configurations

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agents = await tacticalApiClient.getAgents()

// Run a script on a specific agent
const scriptResult = await tacticalApiClient.runScript('agent-123', {
  output: 'wait',
  emails: ['admin@example.com'],
  emailMode: 'default',
  custom_field: null,
  save_all_output: true,
  script: 42,
  args: ['--verbose'],
  env_vars: [],
  timeout: 300,
  run_as_user: false,
  run_on_server: false
})

// Create a daily scheduled task
const task = await tacticalApiClient.createScheduledTask('agent-123', {
  actions: [{
    type: 'script',
    name: 'Daily Backup',
    script: 15,
    timeout: 600,
    script_args: [],
    env_vars: [],
    run_as_user: false
  }],
  name: 'Daily System Backup',
  task_type: 'daily',
  run_time_date: '02:00:00',
  daily_interval: 1
})

// Get agent system information
const systemInfo = await tacticalApiClient.getAgentSystemInfo('agent-123')
```
