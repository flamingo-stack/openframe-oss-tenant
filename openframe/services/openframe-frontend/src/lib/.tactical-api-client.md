A TypeScript client for interacting with the Tactical RMM API, extending the base API client with specialized methods for managing agents, scripts, tasks, and system monitoring.

## Key Components

- **TacticalApiClient**: Main class providing comprehensive Tactical RMM API integration
- **HTTP Methods**: Standard REST operations (`get`, `post`, `put`, `patch`, `delete`)
- **Agent Management**: Methods for retrieving agent data, logs, checks, and system information
- **Script Operations**: Creating, updating, and executing scripts on agents
- **Task Scheduling**: Managing scheduled tasks with various timing options
- **System Monitoring**: Accessing agent services, processes, disk info, and network data

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agents = await tacticalApiClient.getAgents()

// Run a script on a specific agent
const scriptResult = await tacticalApiClient.runScript('agent-123', {
  output: 'save',
  emails: ['admin@example.com'],
  emailMode: 'failure',
  custom_field: null,
  save_all_output: true,
  script: 456,
  args: ['--verbose'],
  env_vars: [],
  timeout: 300,
  run_as_user: false,
  run_on_server: false
})

// Create a scheduled task
const task = await tacticalApiClient.createScheduledTask('agent-123', {
  actions: [{
    type: 'script',
    name: 'System Cleanup',
    script: 789,
    timeout: 600,
    script_args: [],
    env_vars: [],
    run_as_user: false
  }],
  name: 'Daily Cleanup',
  task_type: 'daily',
  run_time_date: '2024-01-01T02:00:00Z',
  daily_interval: 1
})

// Get agent system information
const systemInfo = await tacticalApiClient.getAgentSystemInfo('agent-123')
```
