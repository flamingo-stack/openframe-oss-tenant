A specialized API client that extends the base API client to provide comprehensive integration with Tactical RMM's remote monitoring and management platform. It handles URL construction, authentication, and provides strongly-typed methods for all Tactical RMM endpoints.

## Key Components

- **TacticalApiClient**: Main class extending base API functionality with Tactical RMM-specific methods
- **HTTP Methods**: `get`, `post`, `put`, `patch`, `delete` - Standard REST operations with automatic JSON handling
- **Agent Management**: Methods for retrieving, monitoring, and managing remote agents
- **Script Operations**: Create, update, and execute scripts on remote agents
- **System Information**: Access to logs, services, processes, disk info, network details, and user data
- **Task Scheduling**: Create and manage scheduled tasks with complex scheduling options
- **URL Builder**: Automatic URL construction based on tenant configuration

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all agents
const agentsResponse = await tacticalApiClient.getAgents()
const agents = agentsResponse.data

// Run a script on a specific agent
await tacticalApiClient.runScript('agent-123', {
  output: 'wait',
  emails: ['admin@company.com'],
  emailMode: 'onfail',
  custom_field: null,
  save_all_output: true,
  script: 42,
  args: ['--verbose'],
  env_vars: [],
  timeout: 300,
  run_as_user: false,
  run_on_server: false
})

// Create a daily scheduled task
await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Daily Health Check',
  task_type: 'daily',
  daily_interval: 1,
  run_time_date: '09:00',
  actions: [{
    type: 'script',
    name: 'System Health',
    script: 15,
    timeout: 120,
    script_args: [],
    env_vars: [],
    run_as_user: false
  }],
  alert_severity: 'warning',
  collector_all_output: true
})
```
