A specialized API client that extends the base HTTP client to provide Tactical RMM-specific functionality for managing remote monitoring and management operations.

## Key Components

**TacticalApiClient Class**
- `constructor()` - Initializes client with tenant-specific base URL
- `buildTacticalUrl()` - Constructs proper URLs for Tactical RMM endpoints
- HTTP methods (`get`, `post`, `put`, `patch`, `delete`) - Standard REST operations
- Agent management methods (`getAgents`, `getAgent`, `runScript`)
- Script operations (`getScripts`, `createScript`, `updateScript`)
- System monitoring (`getAgentLogs`, `getAgentChecks`, `getAgentServices`)
- Task scheduling (`createScheduledTask`, `getScheduledTasks`)

**Exports**
- `tacticalApiClient` - Pre-configured singleton instance
- `TacticalApiClient` - Class for creating custom instances
- Type exports for `ApiRequestOptions` and `ApiResponse`

## Usage Example

```typescript
import { tacticalApiClient } from './tactical-api-client'

// Get all managed agents
const agents = await tacticalApiClient.getAgents()

// Run a script on a specific agent
await tacticalApiClient.runScript('agent-123', {
  script: 45,
  args: ['--verbose'],
  timeout: 300,
  output: 'wait',
  emails: ['admin@company.com'],
  emailMode: 'success',
  custom_field: null,
  save_all_output: true,
  env_vars: [],
  run_as_user: false,
  run_on_server: false
})

// Create a scheduled maintenance task
await tacticalApiClient.createScheduledTask('agent-123', {
  name: 'Weekly Disk Cleanup',
  task_type: 'weekly',
  run_time_date: '2024-01-15T02:00:00Z',
  actions: [{
    type: 'script',
    name: 'Cleanup Script',
    script: 12,
    timeout: 600,
    script_args: ['--force'],
    env_vars: [],
    run_as_user: true
  }]
})
```
