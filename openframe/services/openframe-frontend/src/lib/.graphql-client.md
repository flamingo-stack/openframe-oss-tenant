Configures and manages GraphQL schema introspection for URL state management hooks in the OpenFrame frontend, providing utilities to initialize, cache, and clear the GraphQL schema after authentication.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `GRAPHQL_ENDPOINT` | `const` | Resolves the GraphQL endpoint URL using `window.location.origin` client-side or falls back to `/api/graphql` |
| `initializeGraphQlIntrospection()` | `async function` | Fetches and caches the GraphQL schema via introspection; skips if already loaded unless `force = true` |
| `clearGraphQlCache()` | `function` | Clears the cached GraphQL schema, useful for debugging or after schema changes |
| `isGraphQlSchemaLoaded()` | `function` | Returns whether the GraphQL schema is currently loaded in the introspector cache |

## Usage Example

```typescript
// Initialize after authentication (e.g., in an auth provider)
useEffect(() => {
  if (isAuthenticated) {
    initializeGraphQlIntrospection();
  }
}, [isAuthenticated]);

// Force a fresh schema fetch (e.g., after a schema migration)
await initializeGraphQlIntrospection(true);

// Check schema status before relying on URL state hooks
if (!isGraphQlSchemaLoaded()) {
  await initializeGraphQlIntrospection();
}

// Clear cache for debugging
clearGraphQlCache();
```

## Notes

- **Auth headers**: In `DevTicketObserver` mode, automatically reads `of_access_token` from `localStorage` and attaches it as a `Bearer` token.
- **Non-blocking failure**: Errors during introspection are caught and logged — URL state hooks remain functional without the schema, though nested type flattening will be unavailable.
- **SSR safe**: `GRAPHQL_ENDPOINT` guards against `window` access in server-side rendering environments.
