Configures and manages GraphQL schema introspection for URL state management hooks in the OpenFrame frontend, including cache control and auth-header injection for DevTicket mode.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `GRAPHQL_ENDPOINT` | `string` | Resolves the GraphQL endpoint URL from `window.location.origin` (SSR-safe fallback to `/api/graphql`) |
| `initializeGraphQlIntrospection` | `async function` | Fetches and caches the GraphQL schema; injects a Bearer token when DevTicket mode is enabled |
| `clearGraphQlCache` | `function` | Clears the cached introspection schema (useful for debugging or after schema changes) |
| `isGraphQlSchemaLoaded` | `function` | Returns whether the schema has been successfully loaded into the introspector cache |

## Usage Example

```typescript
// In your auth provider or app initialization
import {
  initializeGraphQlIntrospection,
  clearGraphQlCache,
  isGraphQlSchemaLoaded,
} from './graphql-client';

// Initialize after authentication
useEffect(() => {
  if (isAuthenticated) {
    initializeGraphQlIntrospection();
  }
}, [isAuthenticated]);

// Force a fresh schema fetch (e.g., after a schema migration)
await initializeGraphQlIntrospection(true);

// Check schema status before using URL state hooks
if (isGraphQlSchemaLoaded()) {
  // Nested types will be automatically flattened in URL state
}

// Clear cache during debugging
clearGraphQlCache();
```

## Notes

- **Call order matters:** `initializeGraphQlIntrospection` must be invoked _after_ authentication is complete to ensure auth headers are available.
- **Non-blocking on failure:** Errors during introspection are caught and logged — URL state hooks remain functional, but nested type flattening will be disabled.
- **DevTicket mode:** When `runtimeEnv.enableDevTicketObserver()` is `true`, a Bearer token is read from `localStorage` under the key `of_access_token` and attached to the introspection request.
