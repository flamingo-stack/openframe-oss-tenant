Configures and manages GraphQL schema introspection for URL state management hooks in the OpenFrame frontend, handling auth headers and schema caching lifecycle.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `GRAPHQL_ENDPOINT` | `const` | Resolves the GraphQL endpoint URL dynamically from `window.location.origin` (SSR-safe fallback to `/api/graphql`) |
| `initializeGraphQlIntrospection` | `async function` | Fetches and caches the GraphQL schema; attaches a Bearer token when DevTicket mode is active |
| `clearGraphQlCache` | `function` | Clears the cached schema — useful after schema changes or during debugging |
| `isGraphQlSchemaLoaded` | `function` | Returns `true` if the schema has already been loaded and cached |

## Usage Example

Call `initializeGraphQlIntrospection` after authentication completes. Errors are swallowed intentionally — URL state hooks degrade gracefully without introspection.

```typescript
// In your auth provider or app root
useEffect(() => {
  if (isAuthenticated) {
    initializeGraphQlIntrospection();
  }
}, [isAuthenticated]);

// Force a fresh schema fetch (e.g. after a schema migration)
await initializeGraphQlIntrospection(true);

// Guard against redundant calls
if (!isGraphQlSchemaLoaded()) {
  await initializeGraphQlIntrospection();
}

// Reset during development/debugging
clearGraphQlCache();
```

> **Note:** This module must be initialized **after** authentication is complete. In DevTicket mode, it reads `of_access_token` from `localStorage` to attach an `Authorization` header to the introspection request. Failures are non-fatal — URL state hooks remain functional, but nested type flattening will be disabled.
