Client boundary wrapper that re-exports all UI components from `@flamingo-stack/openframe-frontend-core/components/ui`, ensuring hook-dependent components are only imported in client contexts.

## Key Components

- **Re-exports** — Passes through the entire `components/ui` barrel from `@flamingo-stack/openframe-frontend-core`
- **`'use client'` directive** — Establishes a client boundary, preventing RSC (React Server Component) environments from directly importing hook-reliant UI primitives

## Usage Example

Import UI components through this wrapper instead of the core barrel directly:

```typescript
// ✅ Use this wrapper in any component (server or client)
import { Button, Input, Modal } from '@/openframe-core-ui';

// ❌ Avoid importing core barrel directly in server components
import { Button } from '@flamingo-stack/openframe-frontend-core/components/ui';
```

## Notes

- This file exists solely as a **Next.js client boundary shim** — it contains no logic of its own
- Any component in this barrel that uses React hooks (`useState`, `useEffect`, etc.) is safe to consume once imported through this wrapper
- If new UI components are added to the core barrel, they are automatically available here — no changes needed
