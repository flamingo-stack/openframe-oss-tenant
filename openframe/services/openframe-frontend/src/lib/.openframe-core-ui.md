Client boundary wrapper that re-exports all UI components from `@flamingo-stack/openframe-frontend-core/components/ui`, preventing Server Components from directly importing the core UI barrel (which uses React hooks).

## Key Components

- **Re-exports**: All UI components from `@flamingo-stack/openframe-frontend-core/components/ui`
- **`'use client'` directive**: Marks this module as a Client Component boundary, ensuring hook-dependent UI components are only loaded in client contexts

## Usage Example

```typescript
// Import UI components via this wrapper instead of the core barrel directly
import { Button, Modal, Input } from '@/components/openframe-core-ui';

export default function MyServerComponent() {
  return <Button>Click me</Button>;
}
```

> **Why this exists:** Next.js Server Components cannot import modules that use React hooks. By placing `'use client'` here, this file acts as a safe boundary — server-side code can reference it without triggering hook-related build errors.
