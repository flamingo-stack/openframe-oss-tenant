Provides two mouse-event click handler factories for navigating from action buttons nested inside DataTable row `<Link>` elements, where `<a>`-in-`<a>` nesting is invalid HTML.

## Key Components

- **`openInNewTab(href)`** — Returns a `MouseEvent` handler that calls `window.open` with `_blank` and `noopener,noreferrer` security attributes, preventing parent link navigation via `preventDefault`.
- **`navigateTo(router, href)`** — Returns a `MouseEvent` handler that delegates to the Next.js `router.push()` for same-tab navigation, symmetric to `openInNewTab`.
- **`Router`** — Minimal interface requiring only a `push(href: string)` method, compatible with the object returned by `useRouter()` from `next/navigation`.

## Usage Example

```typescript
import { openInNewTab, navigateTo } from './open-in-new-tab';
import { useRouter } from 'next/navigation';

function RowActions({ ticketId }: { ticketId: string }) {
  const router = useRouter();
  const href = `/tickets/${ticketId}`;

  return (
    <>
      {/* Opens ticket detail in a new tab */}
      <button onClick={openInNewTab(href)}>
        Open in new tab
      </button>

      {/* Navigates in the same tab via Next.js router */}
      <button onClick={navigateTo(router, href)}>
        View ticket
      </button>
    </>
  );
}
```

> Both handlers call `e.preventDefault()` to suppress any parent `<Link>` navigation. The `data-no-row-click` attribute on the row already short-circuits row-level click propagation — these handlers provide an additional safety layer.
