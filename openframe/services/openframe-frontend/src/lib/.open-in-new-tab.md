Provides two click-handler factory functions for navigating from action buttons nested inside DataTable row `<Link>` elements, where `<a>`-in-`<a>` nesting is invalid HTML.

## Key Components

- **`openInNewTab(href)`** — Returns a `MouseEvent` handler that calls `window.open` with `_blank` and `noopener,noreferrer` security flags, preventing parent link navigation via `preventDefault`.
- **`navigateTo(router, href)`** — Returns a `MouseEvent` handler that delegates to the Next.js `router.push()` for same-tab navigation, symmetric to `openInNewTab`.
- **`Router`** — Minimal interface requiring only a `push(href)` method, compatible with the object returned by `useRouter()` from `next/navigation`.

## Usage Example

```typescript
import { openInNewTab, navigateTo } from './open-in-new-tab';
import { useRouter } from 'next/navigation';

function TicketRowActions({ ticketId }: { ticketId: string }) {
  const router = useRouter();
  const href = `/tickets/${ticketId}`;

  return (
    <>
      {/* Opens ticket detail in a new tab */}
      <button onClick={openInNewTab(href)}>
        Open in new tab
      </button>

      {/* Navigates in the same tab without triggering the parent <Link> */}
      <button onClick={navigateTo(router, href)}>
        Go to ticket
      </button>
    </>
  );
}
```

> **Why not just use `<a href="...">`?** These buttons live inside a DataTable row rendered as a `<Link>` (`<a>`). Nesting `<a>` inside `<a>` is invalid HTML — these handlers provide the programmatic equivalent for `<button>` elements.
