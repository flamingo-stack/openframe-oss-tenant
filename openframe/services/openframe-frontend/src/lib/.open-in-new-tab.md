Utility providing click handler factories for navigation inside DataTable rows where nested `<a>` elements are invalid HTML.

## Key Components

- **`openInNewTab(href)`** — Returns a `MouseEvent` handler that calls `window.open` with `_blank` and `noopener,noreferrer` security flags, preventing default link behavior on the parent row.
- **`navigateTo(router, href)`** — Returns a `MouseEvent` handler that delegates to the Next.js router's `push` method for same-tab navigation, symmetric to `openInNewTab`.
- **`Router`** — Minimal interface expecting a `push(href: string)` method, compatible with the object returned by `useRouter()` from `next/navigation`.

## Usage Example

```typescript
import { openInNewTab, navigateTo } from './open-in-new-tab';
import { useRouter } from 'next/navigation';

function TicketRowActions({ ticketId }: { ticketId: string }) {
  const router = useRouter();
  const href = `/tickets/${ticketId}`;

  return (
    <>
      {/* Opens ticket detail in a new tab */}
      <button onClick={openInNewTab(href)}>
        Open in new tab
      </button>

      {/* Navigates in the same tab without a nested <a> */}
      <button onClick={navigateTo(router, href)}>
        View ticket
      </button>
    </>
  );
}
```

> **Why not use `<a href>`?** These buttons live inside a DataTable row rendered as a `<Link>` (`<a>`). Nesting `<a>` inside `<a>` is invalid HTML, so buttons use programmatic navigation instead.
