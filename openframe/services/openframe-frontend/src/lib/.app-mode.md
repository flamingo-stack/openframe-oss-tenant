Configures and exposes utilities for determining the application's deployment mode (`oss-tenant`, `saas-tenant`, or `saas-shared`), controlling which routes, auth flows, and UI elements are available at runtime.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `AppMode` | `type` | Union type: `'oss-tenant' \| 'saas-tenant' \| 'saas-shared'` |
| `getAppMode()` | function | Reads current mode from runtime env, defaults to `'oss-tenant'` |
| `isAuthOnlyMode()` | function | `true` when mode is `saas-shared` (auth pages only) |
| `isFullAppMode()` | function | `true` when mode is `oss-tenant` or `saas-tenant` (app pages enabled) |
| `isAuthEnabled()` | function | `true` for `oss-tenant` and `saas-shared` |
| `isAppEnabled()` | function | `true` for `oss-tenant` and `saas-tenant` |
| `isRouteAllowedInCurrentMode()` | function | Guards route access based on current mode |
| `getDefaultRedirectPath()` | function | Returns landing path based on mode and auth state |
| `shouldShowNavigationSidebar()` | function | Controls sidebar visibility |

## Mode Behavior Matrix

| Mode | Auth Pages | App Pages | Notes |
|------|-----------|-----------|-------|
| `oss-tenant` | ✅ | ✅ | Default; blocks `/mingo` routes |
| `saas-tenant` | ❌ | ✅ | App-only; blocks all `/auth` routes |
| `saas-shared` | ✅ | ❌ | Auth-only; allows `/auth` and `/` only |

## Usage Example

```typescript
import {
  getAppMode,
  isRouteAllowedInCurrentMode,
  getDefaultRedirectPath,
  shouldShowNavigationSidebar,
} from './app-mode';

// Check current deployment mode
const mode = getAppMode(); // 'oss-tenant' | 'saas-tenant' | 'saas-shared'

// Middleware route guard
if (!isRouteAllowedInCurrentMode(req.nextUrl.pathname)) {
  const redirect = getDefaultRedirectPath(isAuthenticated);
  return NextResponse.redirect(new URL(redirect, req.url));
}

// Conditionally render sidebar
if (shouldShowNavigationSidebar()) {
  renderSidebar();
}
```
