Configures and exposes utilities for determining the current application deployment mode (`oss-tenant`, `saas-tenant`, or `saas-shared`), controlling route access, feature availability, and navigation behavior.

## Key Components

**Type**
- `AppMode` — Union type: `'oss-tenant' | 'saas-tenant' | 'saas-shared'`

**Mode Detection**
- `getAppMode()` — Reads mode from runtime env, defaults to `'oss-tenant'`
- `isOssTenantMode()` / `isSaasTenantMode()` / `isSaasSharedMode()` — Specific mode checks
- `isAuthOnlyMode()` — Alias for `saas-shared` (auth pages only, no app)
- `isFullAppMode()` — True when app pages are enabled (`oss-tenant` or `saas-tenant`)

**Feature Flags**
- `isAuthEnabled()` — Auth flows active in `oss-tenant` and `saas-shared`
- `isAppEnabled()` — App pages active in `oss-tenant` and `saas-tenant`
- `shouldShowNavigationSidebar()` / `shouldShowAppPages()` — UI visibility helpers

**Routing**
- `isRouteAllowedInCurrentMode(pathname)` — Guards routes per mode; `/mingo` blocked in OSS
- `getDefaultRedirectPath(isAuthenticated)` — Returns landing path based on mode and auth state

## Usage Example

```typescript
import {
  getAppMode,
  isRouteAllowedInCurrentMode,
  getDefaultRedirectPath,
} from './app-mode';

// Middleware route guard
if (!isRouteAllowedInCurrentMode(req.nextUrl.pathname)) {
  const redirect = getDefaultRedirectPath(false);
  return NextResponse.redirect(new URL(redirect, req.url));
}

// Conditional UI rendering
if (isAppEnabled()) {
  renderSidebar();
}

// Current mode: 'oss-tenant' | 'saas-tenant' | 'saas-shared'
console.log(getAppMode());
```

## Mode Behavior Matrix

| Mode | Auth Routes | App Routes | `/mingo` |
|---|---|---|---|
| `oss-tenant` | ✅ | ✅ | ❌ |
| `saas-tenant` | ❌ | ✅ | ✅ |
| `saas-shared` | ✅ | ❌ | ❌ |
