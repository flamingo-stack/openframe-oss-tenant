Configures and exposes utilities for determining the current application deployment mode (`oss-tenant`, `saas-tenant`, or `saas-shared`), controlling route access, redirect behavior, and UI visibility accordingly.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `AppMode` | `type` | Union type: `'oss-tenant' \| 'saas-tenant' \| 'saas-shared'` |
| `getAppMode()` | function | Reads mode from runtime env, defaults to `'oss-tenant'` |
| `isAuthOnlyMode()` | function | `true` when mode is `saas-shared` |
| `isFullAppMode()` | function | `true` when mode is `oss-tenant` or `saas-tenant` |
| `isAuthEnabled()` | function | `true` when auth pages/flows are active |
| `isAppEnabled()` | function | `true` when app pages are active |
| `isRouteAllowedInCurrentMode()` | function | Guards route access based on current mode |
| `getDefaultRedirectPath()` | function | Returns appropriate redirect path per mode + auth state |
| `shouldShowNavigationSidebar()` | function | Controls sidebar visibility |

## Mode Behavior Matrix

| Mode | Auth Pages | App Pages | Notes |
|------|-----------|-----------|-------|
| `oss-tenant` | ✅ | ✅ | Full app; `/mingo` routes blocked |
| `saas-tenant` | ❌ | ✅ | App only; auth routes blocked |
| `saas-shared` | ✅ | ❌ | Auth only; only `/auth` and `/` allowed |

## Usage Example

```typescript
import {
  getAppMode,
  isRouteAllowedInCurrentMode,
  getDefaultRedirectPath,
  isAuthEnabled,
  isAppEnabled,
} from './app-mode';

// Check current mode
const mode = getAppMode(); // 'oss-tenant' | 'saas-tenant' | 'saas-shared'

// Middleware route guard
if (!isRouteAllowedInCurrentMode(req.nextUrl.pathname)) {
  const redirectTo = getDefaultRedirectPath(isAuthenticated);
  return NextResponse.redirect(new URL(redirectTo, req.url));
}

// Conditionally render auth or app features
if (isAuthEnabled()) {
  // Show login/signup flows
}

if (isAppEnabled()) {
  // Show dashboard and app pages
}
```
