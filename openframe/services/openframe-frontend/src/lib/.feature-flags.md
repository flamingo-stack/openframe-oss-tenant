Provides a centralized feature flag system to control feature availability across the OpenFrame platform. The system dynamically enables or disables features based on runtime configuration settings.

## Key Components

- **`featureFlags`** - Main feature flags configuration object containing all available feature toggles
- **`organizationImages`** - Controls organization logo/image upload and display functionality
- **`ssoAutoAllow`** - Manages automatic SSO domain allowlist feature
- **`scriptSchedule`** - Controls script scheduling feature availability
- **`FeatureFlagKey`** - TypeScript type for all available feature flag keys

## Usage Example

```typescript
import { featureFlags } from './feature-flags'

// Check if organization images are enabled
if (featureFlags.organizationImages.enabled()) {
  // Show image upload UI
  renderImageUploadComponent()
}

// Check multiple image-related capabilities
if (featureFlags.organizationImages.uploadEnabled()) {
  enableUploadButton()
}

if (featureFlags.organizationImages.displayEnabled()) {
  showOrganizationLogos()
}

// Check SSO auto-allow feature
if (featureFlags.ssoAutoAllow.enabled()) {
  enableAutomaticDomainAllowlist()
}

// Conditional script scheduling
if (featureFlags.scriptSchedule.enabled()) {
  renderSchedulingInterface()
}
```

The feature flags automatically reflect runtime environment configuration, allowing features to be toggled without code changes across different deployment environments.
