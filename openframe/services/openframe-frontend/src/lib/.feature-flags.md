Provides centralized feature flag management for controlling application functionality based on runtime environment configuration.

## Key Components

- **featureFlags** - Main configuration object containing all feature flags
- **organizationImages** - Controls organization image display and upload capabilities
- **ssoAutoAllow** - Manages SSO domain auto-allow functionality 
- **scriptSchedule** - Controls script scheduling feature availability
- **FeatureFlagKey** - Type definition for available feature flag keys

## Usage Example

```typescript
import { featureFlags } from './feature-flags'

// Check if organization images are enabled
if (featureFlags.organizationImages.enabled()) {
  // Show image upload UI
  renderImageUpload()
}

// Check specific organization image capabilities
if (featureFlags.organizationImages.uploadEnabled()) {
  enableImageUpload()
}

if (featureFlags.organizationImages.displayEnabled()) {
  showOrganizationLogo()
}

// Check SSO auto-allow feature
if (featureFlags.ssoAutoAllow.enabled()) {
  enableDomainAutoApproval()
}

// Check script scheduling
if (featureFlags.scriptSchedule.enabled()) {
  renderScheduleInterface()
}
```

Each feature flag provides granular control over functionality, with some features like `organizationImages` offering sub-features for upload and display capabilities. All flags are backed by runtime environment configuration for dynamic feature toggling.
