A centralized feature flag management system that controls the availability of features across the Flamingo/OpenFrame application based on runtime environment configuration.

## Key Components

- **`featureFlags`** - Main feature flags object containing all available features
- **`organizationImages`** - Controls organization logo/image display and upload functionality
- **`ssoAutoAllow`** - Manages SSO domain auto-allow feature availability
- **`scriptSchedule`** - Controls script scheduling feature availability
- **`FeatureFlagKey`** - TypeScript type for feature flag keys

## Usage Example

```typescript
import { featureFlags } from './feature-flags'

// Check if organization images are enabled
if (featureFlags.organizationImages.enabled()) {
  console.log('Organization images feature is available')
}

// Check specific organization image capabilities
if (featureFlags.organizationImages.uploadEnabled()) {
  // Show upload UI
}

if (featureFlags.organizationImages.displayEnabled()) {
  // Display organization logos
}

// Check SSO auto-allow feature
if (featureFlags.ssoAutoAllow.enabled()) {
  // Enable SSO domain auto-allow functionality
}

// Check script scheduling
if (featureFlags.scriptSchedule.enabled()) {
  // Show script scheduling interface
}

// Type-safe feature flag key usage
type FlagKey = FeatureFlagKey // 'organizationImages' | 'ssoAutoAllow' | 'scriptSchedule'
```

The feature flags are backed by runtime environment configuration, allowing features to be enabled or disabled without code changes by modifying environment variables or configuration files.
