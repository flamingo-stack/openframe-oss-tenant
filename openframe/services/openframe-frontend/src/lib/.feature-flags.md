A centralized feature flags management system that controls the availability of features across the OpenFrame platform based on runtime environment configuration.

## Key Components

- **`featureFlags`** - Main feature flags object containing all available feature toggles
- **`organizationImages`** - Controls organization image/logo display and upload functionality with granular sub-flags
- **`ssoAutoAllow`** - Manages SSO domain auto-allowlist feature availability
- **`scriptSchedule`** - Controls script scheduling feature availability
- **`FeatureFlagKey`** - TypeScript type for type-safe feature flag key access

## Usage Example

```typescript
import { featureFlags, FeatureFlagKey } from './feature-flags'

// Check if organization images are enabled
if (featureFlags.organizationImages.enabled()) {
  // Show organization image upload UI
  renderImageUpload()
}

// Check specific organization image sub-features
if (featureFlags.organizationImages.uploadEnabled()) {
  enableUploadButton()
}

// Check other features
if (featureFlags.ssoAutoAllow.enabled()) {
  configureAutoSSO()
}

// Type-safe feature flag key usage
const checkFeature = (key: FeatureFlagKey) => {
  return featureFlags[key].enabled()
}
```

The system provides a clean abstraction over runtime environment variables, allowing features to be toggled without code changes through environment configuration.
