A centralized feature flags management system that controls feature availability across the Flamingo/OpenFrame application using runtime environment configuration.

## Key Components

- **`featureFlags`** - Main feature flags object containing all available features
- **`organizationImages`** - Controls organization image/logo functionality with upload and display sub-features
- **`ssoAutoAllow`** - Manages SSO domain auto-allow feature
- **`scriptSchedule`** - Controls script scheduling functionality availability
- **`FeatureFlagKey`** - TypeScript type for all available feature flag keys

Each feature flag provides an `enabled()` method that checks the corresponding runtime environment configuration.

## Usage Example

```typescript
import { featureFlags } from './feature-flags'

// Check if organization images are enabled
if (featureFlags.organizationImages.enabled()) {
  // Show organization image upload UI
  renderImageUpload()
}

// Check specific organization image sub-features
if (featureFlags.organizationImages.uploadEnabled()) {
  enableUploadButton()
}

// Check SSO auto-allow feature
if (featureFlags.ssoAutoAllow.enabled()) {
  enableDomainAutoAllow()
}

// Check script scheduling
if (featureFlags.scriptSchedule.enabled()) {
  showScheduleOptions()
}

// Type-safe feature flag key usage
type FlagKey = FeatureFlagKey // 'organizationImages' | 'ssoAutoAllow' | 'scriptSchedule'
```
