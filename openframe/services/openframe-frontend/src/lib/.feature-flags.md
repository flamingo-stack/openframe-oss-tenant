A centralized feature flag management system that controls feature availability across the Flamingo platform by reading from runtime environment configuration.

## Key Components

- **`featureFlags`** - Main feature flags object containing all available features
- **`organizationImages`** - Controls organization image/logo display and upload functionality
- **`ssoAutoAllow`** - Manages SSO domain auto-allow feature
- **`scriptSchedule`** - Controls script scheduling feature availability
- **`FeatureFlagKey`** - TypeScript type for all available feature flag keys

## Usage Example

```typescript
import { featureFlags } from './feature-flags'

// Check if organization images feature is enabled
if (featureFlags.organizationImages.enabled()) {
  // Show organization image upload UI
  renderImageUpload()
}

// Check specific sub-features
if (featureFlags.organizationImages.uploadEnabled()) {
  // Enable image upload functionality
  enableUploadButton()
}

// Check SSO auto-allow feature
if (featureFlags.ssoAutoAllow.enabled()) {
  // Enable automatic domain allowlisting for SSO
  configureAutoAllowDomains()
}

// Check script scheduling availability
if (featureFlags.scriptSchedule.enabled()) {
  // Show script scheduling interface
  renderScheduleUI()
}
```

The feature flags are backed by runtime environment configuration, allowing features to be toggled without code changes. Each feature provides granular control methods where applicable (e.g., separate upload and display controls for organization images).
