A centralized feature flag management system that controls feature availability across the Flamingo platform using runtime environment configuration.

## Key Components

- **`featureFlags`** - Main configuration object containing all feature toggles
- **`organizationImages`** - Controls organization logo/image functionality with granular upload and display permissions
- **`ssoAutoAllow`** - Manages SSO domain auto-allow feature availability
- **`scriptSchedule`** - Controls script scheduling feature access
- **`FeatureFlagKey`** - TypeScript type for available feature flag keys

## Usage Example

```typescript
import { featureFlags } from './feature-flags'

// Check if organization images are enabled
if (featureFlags.organizationImages.enabled()) {
  // Show organization image upload UI
  renderImageUpload()
}

// Conditionally enable SSO auto-allow
if (featureFlags.ssoAutoAllow.enabled()) {
  enableAutoSSO()
}

// Check script scheduling availability
const canScheduleScripts = featureFlags.scriptSchedule.enabled()

// Type-safe feature flag access
function checkFeature(flagKey: FeatureFlagKey) {
  return featureFlags[flagKey].enabled()
}
```

The system provides a clean abstraction over runtime environment variables, allowing features to be toggled without code changes and enabling gradual feature rollouts across different environments.
