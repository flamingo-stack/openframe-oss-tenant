A centralized feature flags system that controls feature availability across the application based on runtime environment configuration.

## Key Components

- **`featureFlags`** - Main feature flags object with nested feature configurations
- **`organizationImages`** - Controls organization image/logo display and upload functionality with granular enabled/upload/display permissions
- **`ssoAutoAllow`** - Controls SSO domain auto-allow functionality
- **`scriptSchedule`** - Controls script scheduling feature availability
- **`FeatureFlagKey`** - TypeScript type for feature flag keys, ensuring type safety when referencing flags

## Usage Example

```typescript
import { featureFlags, FeatureFlagKey } from './feature-flags'

// Check if organization images are enabled
if (featureFlags.organizationImages.enabled()) {
  // Show organization logo upload UI
  renderImageUpload()
}

// Check specific organization image capabilities
if (featureFlags.organizationImages.uploadEnabled()) {
  enableUploadButton()
}

// Check SSO auto-allow feature
if (featureFlags.ssoAutoAllow.enabled()) {
  // Enable automatic SSO domain allowlist
  setupAutoSSO()
}

// Type-safe feature flag key usage
const checkFeature = (key: FeatureFlagKey) => {
  return featureFlags[key].enabled()
}
```

The system provides a clean abstraction over runtime environment configuration, allowing features to be toggled without code changes and enabling gradual feature rollouts.
