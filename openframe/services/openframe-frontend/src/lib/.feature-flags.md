Centralized feature flag management system that controls feature availability across the application based on runtime environment configuration.

## Key Components

- **`featureFlags`** - Main feature flags object containing all available feature toggles
- **`organizationImages`** - Controls organization image/logo display and upload functionality
- **`ssoAutoAllow`** - Manages SSO auto-allow domain feature availability
- **`scriptSchedule`** - Controls script scheduling functionality
- **`FeatureFlagKey`** - Type definition for all available feature flag keys

## Usage Example

```typescript
import { featureFlags, FeatureFlagKey } from './feature-flags'

// Check if organization images are enabled
if (featureFlags.organizationImages.enabled()) {
  // Show organization image upload UI
  console.log('Organization images feature is available')
}

// Check specific organization image capabilities
const canUpload = featureFlags.organizationImages.uploadEnabled()
const canDisplay = featureFlags.organizationImages.displayEnabled()

// Check other features
const ssoAllowed = featureFlags.ssoAutoAllow.enabled()
const scheduleEnabled = featureFlags.scriptSchedule.enabled()

// Use feature flag key type for dynamic access
const checkFeature = (key: FeatureFlagKey) => {
  return featureFlags[key].enabled()
}
```

Each feature flag provides an `enabled()` method that checks the corresponding runtime environment configuration, allowing for consistent feature toggling throughout the application.
