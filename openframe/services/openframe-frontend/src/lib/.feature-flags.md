A centralized feature flags management system that controls the availability of features across the Flamingo application based on runtime environment configuration.

## Key Components

- **`featureFlags`** - Main feature flags configuration object containing all available feature toggles
- **`organizationImages`** - Controls organization image/logo display and upload capabilities
- **`ssoAutoAllow`** - Manages SSO domain auto-allow functionality
- **`scriptSchedule`** - Controls script scheduling feature availability
- **`FeatureFlagKey`** - TypeScript type for all available feature flag keys

## Usage Example

```typescript
import { featureFlags } from './feature-flags'

// Check if organization images are enabled
if (featureFlags.organizationImages.enabled()) {
  // Show organization logo upload UI
  showImageUploadButton()
}

// Check multiple organization image capabilities
if (featureFlags.organizationImages.uploadEnabled()) {
  enableImageUpload()
}

if (featureFlags.organizationImages.displayEnabled()) {
  renderOrganizationLogo()
}

// Check SSO auto-allow feature
if (featureFlags.ssoAutoAllow.enabled()) {
  enableDomainAutoAllow()
}

// Check script scheduling
if (featureFlags.scriptSchedule.enabled()) {
  showSchedulingOptions()
}
```

Each feature flag provides boolean methods to check availability, with the system reading configuration from the runtime environment to determine which features should be active.
