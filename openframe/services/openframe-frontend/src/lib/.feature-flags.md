A TypeScript module that provides centralized feature flag management to control feature availability across the application based on runtime environment configuration.

## Key Components

- **`featureFlags`** - Main configuration object containing all feature flag definitions
- **`organizationImages`** - Feature flag controlling organization image/logo functionality with granular upload and display controls
- **`ssoAutoAllow`** - Feature flag for SSO domain auto-allow functionality
- **`FeatureFlagKey`** - Type definition for all available feature flag keys

## Usage Example

```typescript
import { featureFlags, type FeatureFlagKey } from './feature-flags'

// Check if organization images feature is enabled
if (featureFlags.organizationImages.enabled()) {
  // Show organization image upload UI
}

// Check specific organization image capabilities
const canUpload = featureFlags.organizationImages.uploadEnabled()
const canDisplay = featureFlags.organizationImages.displayEnabled()

// Check SSO auto-allow feature
if (featureFlags.ssoAutoAllow.enabled()) {
  // Enable automatic domain allowlist for SSO
}

// Type-safe feature flag key usage
const flagKey: FeatureFlagKey = 'organizationImages'
const isEnabled = featureFlags[flagKey].enabled()
```

The feature flags are controlled by runtime environment variables through the `runtimeEnv` configuration, allowing for dynamic feature toggling without code changes.
