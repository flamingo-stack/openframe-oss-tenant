A centralized feature flag management system that controls feature availability across the application based on runtime environment configuration.

## Key Components

- **featureFlags** - Main configuration object containing all feature flag definitions
- **organizationImages** - Controls organization image/logo display and upload functionality
- **ssoAutoAllow** - Manages SSO domain auto-allow feature availability
- **scriptSchedule** - Controls script scheduling functionality
- **FeatureFlagKey** - Type definition for available feature flag keys

## Usage Example

```typescript
import { featureFlags } from './feature-flags'

// Check if organization images are enabled
if (featureFlags.organizationImages.enabled()) {
  // Show image upload UI
  renderImageUpload()
}

// Check specific organization image capabilities
if (featureFlags.organizationImages.uploadEnabled()) {
  // Enable upload functionality
  enableImageUpload()
}

// Check SSO auto-allow feature
if (featureFlags.ssoAutoAllow.enabled()) {
  // Enable SSO domain auto-allow
  configureSSOAutoAllow()
}

// Check script scheduling availability
if (featureFlags.scriptSchedule.enabled()) {
  // Show scheduling options
  renderScheduleOptions()
}
```

The system provides a clean abstraction over runtime environment configuration, allowing features to be toggled without code changes and enabling gradual feature rollouts.
