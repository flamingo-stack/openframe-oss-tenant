Centralized feature flag management system that controls feature availability across the OpenFrame application based on runtime environment configuration.

## Key Components

- **`featureFlags`** - Main feature flags object containing all available features
- **`organizationImages`** - Controls organization logo/image upload and display functionality
- **`ssoAutoAllow`** - Manages SSO domain auto-allow feature
- **`scriptSchedule`** - Controls script scheduling feature availability
- **`FeatureFlagKey`** - Type definition for feature flag keys

## Usage Example

```typescript
import { featureFlags } from './feature-flags'

// Check if organization images are enabled
if (featureFlags.organizationImages.enabled()) {
  // Show organization image upload UI
  renderImageUploader()
}

// Check specific organization image capabilities
if (featureFlags.organizationImages.uploadEnabled()) {
  enableImageUpload()
}

if (featureFlags.organizationImages.displayEnabled()) {
  showOrganizationLogo()
}

// Check SSO auto-allow feature
if (featureFlags.ssoAutoAllow.enabled()) {
  enableDomainAutoAllow()
}

// Check script scheduling
if (featureFlags.scriptSchedule.enabled()) {
  showSchedulingOptions()
}
```

Each feature flag provides an `enabled()` method that queries the runtime environment configuration to determine if the feature should be available. The organization images feature additionally provides granular control over upload and display capabilities.
