Centralized feature flag management system that controls feature availability across the application based on runtime environment configuration.

## Key Components

- **featureFlags** - Main feature flags object containing all feature controls
- **organizationImages** - Controls organization image/logo display and upload functionality
- **ssoAutoAllow** - Controls SSO automatic domain allowance feature
- **scriptSchedule** - Controls script scheduling functionality availability
- **FeatureFlagKey** - Type definition for available feature flag keys

## Usage Example

```typescript
import { featureFlags } from './feature-flags'

// Check if organization images are enabled
if (featureFlags.organizationImages.enabled()) {
  // Show organization image upload UI
  renderImageUpload()
}

// Check specific organization image capabilities
const canUpload = featureFlags.organizationImages.uploadEnabled()
const canDisplay = featureFlags.organizationImages.displayEnabled()

// Check other features
const ssoEnabled = featureFlags.ssoAutoAllow.enabled()
const scheduleEnabled = featureFlags.scriptSchedule.enabled()

// Use with conditional rendering
{featureFlags.scriptSchedule.enabled() && <ScheduleComponent />}
```

The feature flags are dynamically determined by the runtime environment configuration, allowing features to be enabled or disabled without code changes. Each feature flag provides boolean methods to check availability, with some features offering granular sub-controls like upload vs display capabilities.
