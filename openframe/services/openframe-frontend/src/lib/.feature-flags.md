A centralized feature flags management system that controls feature availability across the Flamingo application using runtime environment configuration.

## Key Components

- **`featureFlags`** - Main feature flags object containing all available features
- **`organizationImages`** - Controls organization logo/image display and upload functionality
- **`ssoAutoAllow`** - Manages SSO domain auto-allow feature
- **`scriptSchedule`** - Controls script scheduling feature availability
- **`FeatureFlagKey`** - Type definition for all available feature flag keys

Each feature flag provides an `enabled()` method that checks the corresponding runtime environment configuration. The organization images feature includes additional granular controls for upload and display functionality.

## Usage Example

```typescript
import { featureFlags } from './feature-flags'

// Check if organization images are enabled
if (featureFlags.organizationImages.enabled()) {
  // Show organization image upload UI
  renderImageUpload()
}

// Check specific image functionality
if (featureFlags.organizationImages.uploadEnabled()) {
  enableImageUploadButton()
}

// Check script scheduling availability
if (featureFlags.scriptSchedule.enabled()) {
  showScheduleOptions()
}

// Type-safe feature flag key usage
function isFeatureEnabled(key: FeatureFlagKey): boolean {
  return featureFlags[key].enabled()
}
```

The feature flags system provides a clean abstraction layer over runtime configuration, allowing for consistent feature toggling throughout the application while maintaining type safety.
