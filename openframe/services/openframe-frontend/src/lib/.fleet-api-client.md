Extends the base API client with Fleet MDM-specific functionality, providing typed methods for managing hosts, policies, queries, and their host assignments through the FleetDM API.

## Key Components

**Exported Interfaces**
- `PolicyHost` — Minimal host reference (`id`, `hostname`) used in policy/query assignment responses
- `FleetLabel` — Fleet label descriptor with type and membership metadata

**Internal Types**
- `Host` — Full host record including platform, OS version, IP, hardware info, and agent details

**`FleetApiClient` Class**
- Constructs Fleet-proxied URLs via tenant host and `/tools/fleetmdm-server` prefix
- Wraps `apiClient` with HTTP verb helpers: `get`, `post`, `put`, `patch`, `delete`

**Policy Methods**
- `getPolicies`, `getPolicy`, `createPolicy`, `updatePolicy`, `deletePolicy`, `runPolicyOnHost`
- `getPolicyHosts`, `addHostsToPolicy`, `removeHostsFromPolicy`, `replacePolicyHosts`

**Query Methods**
- `getQueries`, `getQuery`, `createQuery`, `updateQuery`, `deleteQuery`
- `runQuery`, `runLiveQuery`, `getQueryReport`
- `getQueryHosts`, `addHostsToQuery`, `removeHostsFromQuery`, `replaceQueryHosts`

**Host Methods**
- `getHosts` — supports filtering by team, status, policy response, pagination, and device mapping

## Usage Example

```typescript
import { fleetApiClient } from '@/lib/fleet-api-client';

// Fetch policies for a team
const { data } = await fleetApiClient.getPolicies({ team_id: 1 });
console.log(data?.policies);

// Create and run a live query
const { data: campaign } = await fleetApiClient.runLiveQuery({
  query: 'SELECT * FROM os_version;',
  selected: { hosts: [42], labels: [], teams: [] },
});

// Assign hosts to a policy
await fleetApiClient.addHostsToPolicy(5, [1, 2, 3]);

// Get paginated hosts
const { data: hostList } = await fleetApiClient.getHosts({
  status: 'online',
  per_page: 50,
  page: 0,
  policy_response: 'failing',
});
```
