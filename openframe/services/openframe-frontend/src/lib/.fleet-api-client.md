Extends the base API client with Fleet MDM-specific functionality, providing typed methods for managing hosts, policies, queries, and their host assignments through the FleetDM API.

## Key Components

### Interfaces

| Interface | Description |
|-----------|-------------|
| `PolicyHost` | Minimal host reference (id + hostname) used in policy/query assignments |
| `FleetLabel` | Fleet label metadata including type and membership type |
| `Host` | Full host record with hardware, OS, agent, and status details |

### `FleetApiClient` Class

**Core HTTP Methods:**
- `request<T>()` — Base method that resolves the Fleet URL and delegates to `apiClient`
- `get()`, `post()`, `put()`, `patch()`, `delete()` — Typed HTTP verb wrappers

**Policy Methods:**
- `getPolicies()`, `getPolicy()`, `createPolicy()`, `updatePolicy()`, `deletePolicy()`, `runPolicyOnHost()`

**Policy Host Assignment Methods:**
- `getPolicyHosts()`, `addHostsToPolicy()`, `removeHostsFromPolicy()`, `replacePolicyHosts()`

**Query Methods:**
- `getQueries()`, `getQuery()`, `createQuery()`, `updateQuery()`, `deleteQuery()`, `runQuery()`, `runLiveQuery()`, `getQueryReport()`

**Query Host Assignment Methods:**
- `getQueryHosts()`, `addHostsToQuery()`, `removeHostsFromQuery()`, `replaceQueryHosts()`

**Host Methods:**
- `getHosts()` — Paginated host list with filtering by team, status, policy response, and more

## Usage Example

```typescript
import { fleetApiClient } from './fleet-api-client';

// Fetch all policies for a team
const { data } = await fleetApiClient.getPolicies({ team_id: 1 });

// Create a new policy
await fleetApiClient.createPolicy({
  name: 'Disk Encryption Enabled',
  query: 'SELECT 1 FROM disk_encryption WHERE encrypted = 1;',
  description: 'Ensures disk encryption is active',
  platform: 'darwin',
  critical: true,
});

// Run a live query against specific hosts
await fleetApiClient.runLiveQuery({
  query: 'SELECT * FROM os_version;',
  selected: { hosts: [101, 102], labels: [], teams: [] },
});
```

> **Note:** URL routing prefixes all paths with `/tools/fleetmdm-server` via the tenant host URL from `runtimeEnv`. The singleton export `fleetApiClient` should be used rather than instantiating `FleetApiClient` directly.
