Extends the base API client with Fleet MDM-specific functionality, providing typed methods for managing policies, queries, hosts, and their assignments through the FleetDM API.

## Key Components

**`FleetApiClient` class** — Core client that wraps the base `apiClient` with Fleet-specific URL construction and domain methods.

**Exported Interfaces:**
- `PolicyHost` — Minimal host representation (`id`, `hostname`) used in policy/query assignments
- `FleetLabel` — Fleet label metadata including type and membership info

**HTTP Methods:** `get`, `post`, `put`, `patch`, `delete`, `request` — All route through `buildFleetUrl()` to prepend the tenant-scoped Fleet proxy base path.

**Domain Method Groups:**
- **Policies** — `getPolicies`, `getPolicy`, `createPolicy`, `updatePolicy`, `deletePolicy`, `runPolicyOnHost`
- **Policy Host Assignments** — `getPolicyHosts`, `addHostsToPolicy`, `removeHostsFromPolicy`, `replacePolicyHosts`
- **Queries** — `getQueries`, `getQuery`, `createQuery`, `updateQuery`, `deleteQuery`, `runQuery`, `runLiveQuery`, `getQueryReport`
- **Query Host Assignments** — `getQueryHosts`, `addHostsToQuery`, `removeHostsFromQuery`, `replaceQueryHosts`
- **Hosts** — `getHosts` with rich filtering (team, status, policy response, pagination)

## Usage Example

```typescript
import { fleetApiClient } from './fleet-api-client';

// Fetch all policies for a team
const { data } = await fleetApiClient.getPolicies({ team_id: 1 });

// Create a new osquery policy
await fleetApiClient.createPolicy({
  name: 'Disk Encryption Check',
  query: 'SELECT 1 FROM disk_encryption WHERE encrypted = 1;',
  description: 'Ensures disk encryption is enabled',
  platform: 'darwin',
  critical: true,
});

// Run a live query against specific hosts
await fleetApiClient.runLiveQuery({
  query: 'SELECT * FROM os_version;',
  selected: { hosts: [42, 43], labels: [], teams: [] },
});

// Assign hosts to a policy
await fleetApiClient.addHostsToPolicy(5, [101, 102, 103]);
```
