Provides authenticated file upload and deletion utilities for the OpenFrame platform, supporting both cookie-based and Bearer token authentication with a React hook wrapper for stateful upload management.

## Key Components

- **`uploadWithAuth(endpoint, file, fieldName?)`** — POSTs a file as `multipart/form-data` to the given endpoint. Automatically resolves relative paths against the tenant host URL and injects a Bearer token from `localStorage` (`of_access_token`) when dev mode is enabled. Returns the uploaded file URL extracted from various common response shapes (`url`, `imageUrl`, `file_url`, `data.url`, etc.).

- **`deleteWithAuth(endpoint)`** — Sends an authenticated `DELETE` request to the given endpoint using the same auth and URL resolution logic as `uploadWithAuth`.

- **`useAuthenticatedUpload()`** — React hook wrapping `uploadWithAuth` with `isUploading` and `error` state. Returns `{ upload, isUploading, error }` for use in components.

## URL Resolution

| Endpoint format | Resolved as |
|---|---|
| Starts with `http` | Used as-is |
| Starts with `/api` | `{tenantHostUrl}{endpoint}` |
| Anything else | `{tenantHostUrl}/api{endpoint}` |

## Usage Example

```typescript
// Standalone function
const imageUrl = await uploadWithAuth('/images/upload', file, 'image');

// React hook
function AvatarUploader() {
  const { upload, isUploading, error } = useAuthenticatedUpload();

  const handleChange = async (e: React.ChangeEvent<HTMLInputElement>) => {
    const file = e.target.files?.[0];
    if (!file) return;
    const url = await upload('/attachments/upload', file);
    if (url) console.log('Uploaded:', url);
  };

  return (
    <>
      <input type="file" onChange={handleChange} disabled={isUploading} />
      {error && <p>{error}</p>}
    </>
  );
}
```
