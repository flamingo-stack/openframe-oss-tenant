Provides authenticated file upload and deletion utilities for the OpenFrame platform, supporting both cookie-based and Bearer token authentication with a React hook wrapper for stateful upload management.

## Key Components

### `uploadWithAuth(endpoint, file, fieldName?)`
Uploads a file via `multipart/form-data` POST request with authentication. Resolves relative endpoints against the tenant host URL and extracts the uploaded file URL from multiple possible response shapes (`url`, `imageUrl`, `file_url`, `data.url`, etc.).

### `deleteWithAuth(endpoint)`
Sends an authenticated DELETE request to remove a previously uploaded file. Shares the same URL resolution and auth header logic as `uploadWithAuth`.

### `useAuthenticatedUpload()` *(React Hook)*
Wraps `uploadWithAuth` with React state, exposing `isUploading` and `error` flags alongside an `upload` callback. Returns `null` on failure instead of throwing.

---

**Auth strategy:** Includes `credentials: 'include'` for cookie-based auth. When `enableDevTicketObserver` is active, also injects a `Bearer` token from `localStorage` key `of_access_token`.

**Endpoint resolution:**
- Absolute URLs (`http...`) → used as-is
- `/api/...` paths → prefixed with tenant host URL
- All other paths → prefixed with `{tenantHostUrl}/api`

## Usage Example

```typescript
// Standalone function
const fileUrl = await uploadWithAuth('/attachments', file, 'attachment');

// Delete a file
await deleteWithAuth('/attachments/123');

// React hook with loading state
function AvatarUploader() {
  const { upload, isUploading, error } = useAuthenticatedUpload();

  const handleChange = async (e: React.ChangeEvent<HTMLInputElement>) => {
    const file = e.target.files?.[0];
    if (!file) return;
    const url = await upload('/user/avatar', file, 'avatar');
    if (url) console.log('Uploaded to:', url);
  };

  return (
    <>
      <input type="file" onChange={handleChange} disabled={isUploading} />
      {error && <p>{error}</p>}
    </>
  );
}
```
