Detects and classifies the current deployment environment (cloud, self-hosted, or development) based on hostname patterns, providing a consistent runtime context for conditional feature logic.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `DeploymentType` | Type | Union type: `'self-hosted' \| 'cloud' \| 'development'` |
| `DeploymentInfo` | Interface | Full deployment context including flags and hostname |
| `detectDeployment()` | Function | Core detection logic; returns a `DeploymentInfo` object |
| `isCloud()` | Function | Quick boolean check for cloud environment |
| `isSelfHosted()` | Function | Quick boolean check for self-hosted environment |
| `isDevelopment()` | Function | Quick boolean check for development environment |
| `getDeploymentType()` | Function | Returns the `DeploymentType` string |

**Detection logic:**
- **Cloud** — hostname matches `openframe.ai`, `auth.openframe.ai`, or `app.openframe`
- **Development** — hostname matches `localhost`, `127.0.0.1`, `0.0.0.0`, or `.local`
- **Self-hosted** — any other custom domain (default fallback)

SSR-safe: falls back to `'localhost'` when `window` is unavailable.

## Usage Example

```typescript
import {
  detectDeployment,
  isCloud,
  isSelfHosted,
  getDeploymentType,
} from './deployment-detector';

// Full context object
const deployment = detectDeployment();
console.log(deployment.type);     // 'cloud' | 'self-hosted' | 'development'
console.log(deployment.hostname); // e.g. 'app.openframe.ai'

// Quick boolean guards
if (isCloud()) {
  // Enable cloud-only features (e.g. managed auth, SaaS billing)
}

if (isSelfHosted()) {
  // Show self-hosted configuration options
}

// Switch on deployment type
switch (getDeploymentType()) {
  case 'cloud':       /* ... */ break;
  case 'self-hosted': /* ... */ break;
  case 'development': /* ... */ break;
}
```
