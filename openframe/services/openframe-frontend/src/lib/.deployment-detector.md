Detects and classifies the current deployment environment (cloud, self-hosted, or development) using browser hostname patterns, providing both full inspection and quick boolean helpers.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `DeploymentType` | Type alias | Union: `'self-hosted' \| 'cloud' \| 'development'` |
| `DeploymentInfo` | Interface | Full deployment context including hostname and boolean flags |
| `detectDeployment()` | Function | Core detector — returns a complete `DeploymentInfo` object |
| `isCloud()` | Function | Quick boolean — matches `openframe.ai` / `app.openframe` patterns |
| `isSelfHosted()` | Function | Quick boolean — any custom domain not matching cloud or dev patterns |
| `isDevelopment()` | Function | Quick boolean — matches `localhost`, `127.0.0.1`, `.local`, etc. |
| `getDeploymentType()` | Function | Returns the `DeploymentType` string directly |

## Usage Example

```typescript
import {
  detectDeployment,
  isCloud,
  isSelfHosted,
  getDeploymentType,
} from './deployment-detector';

// Full inspection
const info = detectDeployment();
console.log(info.type);     // 'cloud' | 'self-hosted' | 'development'
console.log(info.hostname); // e.g. 'app.openframe.ai'

// Feature flagging based on deployment
if (isCloud()) {
  enableCloudBilling();
} else if (isSelfHosted()) {
  enableLocalLicenseCheck();
}

// Type-safe switch
switch (getDeploymentType()) {
  case 'cloud':       return <CloudBanner />;
  case 'self-hosted': return <SelfHostedBanner />;
  case 'development': return <DevToolbar />;
}
```

> **Note:** Hostname detection relies on `window.location.hostname`. In SSR or Node.js contexts, it safely falls back to `'localhost'`, which resolves as `development`.
