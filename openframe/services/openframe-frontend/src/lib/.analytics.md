Thin analytics wrapper that tracks high-signal user activation events on the dashboard via fire-and-forget POST requests, ensuring tracking never blocks or breaks the UX.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `EVENT_TYPE` | `const` | Fixed value `'DASHBOARD_ACTIVITY'` sent with every event |
| `REPEAT_MODE` | `const` | Enum-like object: `SINGULAR` (once per user) or `MULTI` (every occurrence) |
| `EVENT_SUBTYPE` | `const` | Single source of truth for all valid event subtypes, grouped by surface (`main_dashboard`, `mingo`, `ticket_detail`) |
| `trackDashboardActivity` | `function` | Fire-and-forget tracker — posts to `/api/events`, swallows all errors |
| `RepeatMode` | `type` | Derived union type from `REPEAT_MODE` values |
| `EventSubtype` | `type` | Derived union type from `EVENT_SUBTYPE` values |

**Internal:** `SINGULAR_SUBTYPES` and `repeatModeFor()` are private — call sites never pass a repeat mode, it is inferred automatically from the subtype.

## Usage Example

```typescript
import { trackDashboardActivity, EVENT_SUBTYPE } from '@/lib/analytics';

// Inside an event handler or mutation success callback:
function handleTicketResolved() {
  resolveTicket(ticketId);

  // Fire-and-forget — no await, no try/catch needed at call site
  trackDashboardActivity(EVENT_SUBTYPE.RESOLVE_TICKET);
}

// One-time onboarding skip (automatically tracked as SINGULAR):
function handleSkipOnboarding() {
  trackDashboardActivity(EVENT_SUBTYPE.SKIP_ONBOARDING);
}
```

> **Never pass raw strings** — always use `EVENT_SUBTYPE` constants. The `repeatMode` is derived automatically; `SKIP_ONBOARDING` and `ADD_SSO_IDP` are `SINGULAR`, all others are `MULTI`.
