Wraps the TanStack `QueryClient` in a React state-safe provider for Next.js client components, ensuring a single `QueryClient` instance is created per component mount.

## Key Components

- **`QueryClientProvider`** — Client component that instantiates and provides a `QueryClient` with opinionated defaults:
  - `staleTime`: 60 seconds (reduces redundant background refetches)
  - `refetchOnWindowFocus`: disabled (prevents noisy refetches on tab switch)

## Usage Example

```typescript
// app/layout.tsx
import { QueryClientProvider } from '@/providers/query-client-provider';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html>
      <body>
        <QueryClientProvider>
          {children}
        </QueryClientProvider>
      </body>
    </html>
  );
}
```

> `useState` is used to initialize `QueryClient` so the instance is stable across re-renders and not recreated on every render cycle — a requirement for Next.js App Router client components.
