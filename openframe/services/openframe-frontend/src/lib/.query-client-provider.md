Wraps the TanStack `QueryClientProvider` with a pre-configured `QueryClient` instance, scoped to a React client component for use in Next.js App Router layouts.

## Key Components

- **`QueryClientProvider`** — A client-side wrapper component that initializes and memoizes a `QueryClient` with sensible defaults:
  - `staleTime`: 60 seconds — prevents redundant refetches for recently fetched data.
  - `refetchOnWindowFocus`: disabled — avoids unexpected background refetches on tab/window focus.

## Usage Example

```typescript
// app/layout.tsx
import { QueryClientProvider } from '@/providers/query-client-provider';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html>
      <body>
        <QueryClientProvider>
          {children}
        </QueryClientProvider>
      </body>
    </html>
  );
}
```

## Notes

- The `QueryClient` is created inside `useState` to ensure each request gets its own instance in SSR environments, following the [TanStack Query Next.js App Router recommendation](https://tanstack.com/query/latest/docs/framework/react/guides/advanced-ssr).
- The `'use client'` directive ensures this runs only on the client, compatible with Next.js App Router.
