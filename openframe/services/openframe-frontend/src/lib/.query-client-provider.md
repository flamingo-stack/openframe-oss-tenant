Wraps the TanStack `QueryClientProvider` with a pre-configured `QueryClient` instance, scoped to client-side rendering in a Next.js App Router context.

## Key Components

- **`QueryClientProvider`** — A React component that initializes a singleton `QueryClient` (via `useState`) and provides it to the component tree through TanStack Query's context.

**Default Query Options:**

| Option | Value |
|--------|-------|
| `staleTime` | 60 seconds |
| `refetchOnWindowFocus` | `false` |

## Usage Example

```typescript
// app/layout.tsx
import { QueryClientProvider } from '@/providers/query-client-provider';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html>
      <body>
        <QueryClientProvider>
          {children}
        </QueryClientProvider>
      </body>
    </html>
  );
}
```

> **Note:** The `QueryClient` is instantiated inside `useState` to ensure each request gets a fresh client in SSR environments, while still being stable across re-renders on the client.
