Utility functions for managing chat message history with a focus on approval workflow state — finding, folding, extracting, and stripping approval segments from message arrays without triggering UI flicker.

## Key Components

| Export | Signature | Description |
|--------|-----------|-------------|
| `findLatestPendingApprovalId` | `(messages: M[]) => string \| undefined` | Scans newest-to-oldest for the latest pending `approval_request` or `approval_batch` segment, returns its ID |
| `foldPendingApprovalsEnvelope` | `(messages: M[]) => M[]` | Merges `pending-approvals-*` envelope messages back into their preceding assistant turn |
| `extractPendingApprovals` | `(messages: M[], resolvedStatuses?) => MessageSegment[]` | Collects all still-pending approval segments, filtering out any resolved by status map or inline segment state |
| `stripPendingApprovals` | `(messages: M[]) => M[]` | Removes pending approval segments from inline content for sticky rendering; deduplicates by `requestId` and drops empty assistant bubbles |

## Usage Example

```typescript
import {
  findLatestPendingApprovalId,
  foldPendingApprovalsEnvelope,
  extractPendingApprovals,
  stripPendingApprovals,
} from './chat-history';

// Optimistically reject the active approval gate when the user interrupts
const approvalId = findLatestPendingApprovalId(messages);

// Fold envelope messages back into assistant turns before streaming resumes
const foldedMessages = foldPendingApprovalsEnvelope(messages);

// Collect pending approvals for the sticky approval card prop,
// skipping any already resolved via realtime status updates
const pendingApprovals = extractPendingApprovals(
  foldedMessages,
  { 'req-abc': 'approved', 'req-xyz': undefined },
);

// Strip pending approvals from inline bubbles (they render via pendingApprovals prop)
// Dedupes retried approval requests; drops empty assistant bubbles
const renderableMessages = stripPendingApprovals(foldedMessages);
```

## Notes

- All functions are generic over `M extends ChatMessage`, preserving message subtypes through transformations
- `extractPendingApprovals` and `stripPendingApprovals` work in tandem — extract feeds the sticky card, strip cleans the inline chat flow
- Deduplication in `stripPendingApprovals` uses first-occurrence-wins to prevent a single rejected approval rendering in every retry bubble
