Utilities for managing approval segments within a chat message history — scanning, folding, extracting, and deduplicating pending approval cards across message bubbles.

## Key Components

### `findLatestPendingApprovalId(messages)`
Scans messages newest-to-oldest to find the most recent pending `approval_request` or `approval_batch` segment. Returns its `requestId` / `approvalRequestId`, or `undefined` if none exists. Used by send-message handlers to optimistically reject the active approval gate when the user interrupts, preventing UI flicker.

### `foldPendingApprovalsEnvelope(messages)`
Merges `pending-approvals-*` envelope messages (created by the core lib) back into the preceding assistant turn. This restores the assistant message to a normal in-progress state so streaming chunks can resume cleanly.

### `extractPendingApprovals(messages, resolvedStatuses?)`
Collects all still-pending `approval_request` segments across the message history into a flat array, filtering out any that have been resolved — either via the consumer's realtime status map or as resolved copies anywhere in history. Prevents stale duplicates from surfacing as sticky pending cards.

### `stripPendingApprovals(messages)`
Filters pending approval segments out of inline message content (they render via the sticky `pendingApprovals` prop instead). Also deduplicates `approval_request` / `approval_batch` segments by ID across bubbles (first occurrence wins), preventing repeated approval cards when the agent re-asks after an interruption. Empty assistant bubbles produced by filtering are dropped entirely.

## Usage Example

```typescript
import {
  findLatestPendingApprovalId,
  foldPendingApprovalsEnvelope,
  extractPendingApprovals,
  stripPendingApprovals,
} from './chat-history';

// Find the latest approval gate to optimistically reject on interrupt
const pendingId = findLatestPendingApprovalId(messages);

// Merge envelope messages back into assistant turns before rendering
const folded = foldPendingApprovalsEnvelope(messages);

// Extract pending approvals for the sticky approval UI
const pendingApprovals = extractPendingApprovals(folded, resolvedStatuses);

// Strip pending approvals from inline bubbles to avoid duplicates
const displayMessages = stripPendingApprovals(folded);
```
