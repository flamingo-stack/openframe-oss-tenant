Utility functions for managing chat message history, focusing on approval segment lifecycle — finding, folding, extracting, and stripping pending approval cards within a message stream.

## Key Components

### `findLatestPendingApprovalId`
Scans messages newest-to-oldest and returns the `requestId` or `approvalRequestId` of the most recent pending `approval_request` or `approval_batch` segment. Used to optimistically reject the active approval gate when a user interrupts, preventing UI flicker.

### `foldPendingApprovalsEnvelope`
Merges `pending-approvals-*` envelope messages (created by the core library) back into the preceding assistant turn. This allows streaming chunks to resume correctly against a single in-progress message rather than a detached envelope.

### `extractPendingApprovals`
Collects all pending `approval_request` segments from the message list, deduplicating by `requestId` and skipping any request already resolved — either via a `resolvedStatuses` map or a resolved segment found elsewhere in history.

### `stripPendingApprovals`
Filters message content to remove pending approval segments (which render via the sticky `pendingApprovals` prop instead of inline). Resolved approvals remain in the chat flow so outcomes are visible. Also deduplicates `approval_request` and `approval_batch` segments by ID across bubbles, and drops empty assistant messages left behind after filtering.

## Usage Example

```typescript
import {
  findLatestPendingApprovalId,
  foldPendingApprovalsEnvelope,
  extractPendingApprovals,
  stripPendingApprovals,
} from './chat-history';

// Resolve the active approval gate when the user sends a new message
const pendingId = findLatestPendingApprovalId(messages);

// Merge core-lib envelopes back into assistant turns before rendering
const folded = foldPendingApprovalsEnvelope(messages);

// Extract pending cards for the sticky approval UI
const pendingApprovals = extractPendingApprovals(folded, resolvedStatuses);

// Strip pending segments from the inline message stream
const displayMessages = stripPendingApprovals(folded);
```
