Provides a React context that manages NATS WebSocket connection configuration, including URL generation, authentication state, and token refresh logic for the Flamingo dashboard.

## Key Components

- **`NatsAppConfig`** — Interface exposing `getWsUrl`, `onBeforeReconnect`, `urlRevision`, `isAuthenticated`, and `userId`
- **`useNatsAppConfigState`** — Internal hook that computes NATS config from auth store, runtime env, and localStorage token state
- **`NatsAppConfigProvider`** — Context provider wrapping the app (or subtree) to supply NATS config downstream
- **`useNatsAppConfig`** — Consumer hook for accessing the NATS config; throws if used outside the provider
- **`getApiBaseUrl`** — Resolves the tenant host URL from runtime env or `window.location.origin`
- **`getAccessToken`** — Reads the access token from `localStorage` using the defined storage key
- **`urlRevision`** — Memoized string derived from all connection-affecting values; used to detect when the WebSocket URL needs to change

## Usage Example

```typescript
// Wrap your app or layout
import { NatsAppConfigProvider } from './nats-app-config';

export default function Layout({ children }: { children: React.ReactNode }) {
  return (
    <NatsAppConfigProvider>
      {children}
    </NatsAppConfigProvider>
  );
}

// Consume in a child component
import { useNatsAppConfig } from './nats-app-config';

function NatsConnection() {
  const { getWsUrl, onBeforeReconnect, urlRevision, isAuthenticated } = useNatsAppConfig();

  useEffect(() => {
    const url = getWsUrl();
    if (!url) return;
    // initialize NATS WebSocket connection with `url`
  }, [urlRevision]);

  return <div>Authenticated: {String(isAuthenticated)}</div>;
}
```

> **Note:** The `urlRevision` string changes whenever auth state, user ID, base URL, or token changes — use it as a dependency (instead of `getWsUrl` itself) to trigger reconnections efficiently.
