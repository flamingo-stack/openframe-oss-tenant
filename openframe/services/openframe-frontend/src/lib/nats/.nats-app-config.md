Provides React context and hooks for managing NATS WebSocket connection configuration, wiring together authentication state, API base URL resolution, and token management for the real-time messaging layer.

## Key Components

### `NatsAppConfig` (interface)
Describes the shape of the context value:

| Property | Type | Description |
|---|---|---|
| `getWsUrl` | `() => string \| null` | Builds the WebSocket URL; returns `null` if not ready |
| `onBeforeReconnect` | `() => Promise<void>` | Refreshes auth state before a NATS reconnect attempt |
| `urlRevision` | `string` | Stable cache key that changes when any connection dependency changes |
| `isAuthenticated` | `boolean` | Current auth state from the auth store |
| `userId` | `string \| null` | Current user ID from the auth store |

### `NatsAppConfigProvider`
Wraps the subtree and provides the computed `NatsAppConfig` via context. Must be an ancestor of any component calling `useNatsAppConfig`.

### `useNatsAppConfig`
Consumer hook — throws if called outside `<NatsAppConfigProvider>`.

### Internal helpers
- **`getApiBaseUrl()`** — resolves base URL from runtime env or `window.location.origin`
- **`getAccessToken()`** — reads the access token from `localStorage` (SSR-safe)
- **`useNatsAppConfigState()`** — internal hook that owns all state and memoization logic; listens for `storage` events to keep the token in sync across tabs when dev-ticket observer mode is enabled

## Usage Example

```typescript
// 1. Mount the provider near the top of your authenticated layout
import { NatsAppConfigProvider } from './nats-app-config';

export default function AppLayout({ children }: { children: ReactNode }) {
  return (
    <NatsAppConfigProvider>
      {children}
    </NatsAppConfigProvider>
  );
}

// 2. Consume in any child component
import { useNatsAppConfig } from './nats-app-config';

function NatsConsumer() {
  const { getWsUrl, onBeforeReconnect, urlRevision } = useNatsAppConfig();

  // urlRevision as a stable dependency key for reconnect effects
  useEffect(() => {
    const url = getWsUrl();
    if (!url) return;
    // pass url to your NATS WebSocket client
  }, [urlRevision]);
}
```

> **Note:** `getWsUrl()` returns `null` when the user is unauthenticated, the base URL is unavailable, or (in dev-ticket mode) no access token is present — guard accordingly before opening a connection.
