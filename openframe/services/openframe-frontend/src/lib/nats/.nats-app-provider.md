Composes the NATS messaging provider for the OpenFrame frontend app by wiring together configuration and connection logic into a single React context tree.

## Key Components

- **`NatsAppProvider`** — Top-level exported provider. Wraps children with `NatsAppConfigProvider` and the internal `NatsProviderWiring` component.
- **`NatsProviderWiring`** — Internal component that consumes `useNatsAppConfig()` to supply dynamic WebSocket URL, reconnection callbacks, and URL revision tracking to the underlying `NatsProvider`.
- **`RECONNECTION_BACKOFF`** — Reconnection strategy: 3 fast retries with 200ms delay before falling back to standard backoff.
- **`CLIENT_CONFIG`** — Static NATS client identity (`openframe-frontend-app`, `machine` user).

## Usage Example

```typescript
// Wrap your application root (e.g., layout.tsx) with NatsAppProvider
import { NatsAppProvider } from '@/providers/nats-app-provider';

export default function RootLayout({ children }: { children: ReactNode }) {
  return (
    <NatsAppProvider>
      {children}
    </NatsAppProvider>
  );
}
```

Once mounted, any component in the tree can consume the NATS connection via hooks exposed by `@flamingo-stack/openframe-frontend-core/nats` (e.g., `useNatsClient`).

> **Note:** The `pass` field in `CLIENT_CONFIG` is intentionally empty — authentication tokens are supplied dynamically via `onBeforeReconnect` from `useNatsAppConfig`, allowing credentials to be refreshed on each reconnection attempt without remounting the provider.
