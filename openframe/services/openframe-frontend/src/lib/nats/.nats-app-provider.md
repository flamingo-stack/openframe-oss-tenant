Composes the NATS messaging provider for the OpenFrame frontend app by wiring together configuration and connection management into a single React context tree.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `NatsAppProvider` | React Component | Top-level provider that wraps children with both config and NATS connection contexts |
| `NatsProviderWiring` | React Component (internal) | Reads config via `useNatsAppConfig` and passes resolved values to `NatsProvider` |
| `RECONNECTION_BACKOFF` | Constant | Reconnection strategy: 3 fast retries at 200ms intervals |
| `CLIENT_CONFIG` | Constant | Static NATS client identity (`openframe-frontend-app`, `machine` user) |

## Usage Example

```typescript
// Wrap your app root with NatsAppProvider to enable NATS messaging
import { NatsAppProvider } from './nats-app-provider';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <NatsAppProvider>
      {children}
    </NatsAppProvider>
  );
}
```

## Notes

- Marked `'use client'` — must be rendered in the browser context (Next.js App Router).
- `NatsProviderWiring` is intentionally split from `NatsAppProvider` so that `useNatsAppConfig` can be called after its provider mounts, avoiding context read-before-mount issues.
- WebSocket URL resolution and pre-reconnect logic are delegated to `useNatsAppConfig`, keeping this component focused on connection wiring only.
