Composes the NATS messaging provider for the OpenFrame frontend app by wiring together configuration and connection management into a single React context tree.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `NatsAppProvider` | `React.FC` | Top-level provider that wraps children with both config and NATS connection context |
| `NatsProviderWiring` | Internal `React.FC` | Reads resolved config via `useNatsAppConfig` and passes it to the underlying `NatsProvider` |
| `RECONNECTION_BACKOFF` | `const` | Reconnection strategy — 3 fast retries at 200ms intervals |
| `CLIENT_CONFIG` | `const` | Static NATS client identity (`openframe-frontend-app`, `machine` user) |

## Usage Example

Wrap your application root (or a subtree that needs NATS messaging) with `NatsAppProvider`:

```typescript
import { NatsAppProvider } from '@/providers/nats-app-provider';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <NatsAppProvider>
      {children}
    </NatsAppProvider>
  );
}
```

Child components can then consume NATS subscriptions and publishing hooks provided by `@flamingo-stack/openframe-frontend-core/nats` directly, with connection lifecycle (WebSocket URL resolution, pre-reconnect hooks, URL revision tracking) handled transparently by the `NatsAppConfigProvider`.
