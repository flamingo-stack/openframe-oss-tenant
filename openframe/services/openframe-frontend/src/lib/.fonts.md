Configures and exports Google Fonts for the application using Next.js font optimization, providing CSS variable bindings for `Azeret Mono` (monospace) and `DM Sans` (sans-serif).

## Key Components

| Export | Font | CSS Variable | Weights |
|--------|------|-------------|---------|
| `azeretMono` | Azeret Mono | `--font-azeret-mono` | 400, 500, 600, 700 |
| `dmSans` | DM Sans | `--font-dm-sans` | 400, 500, 700 |

Both fonts use `latin` subset and `swap` display strategy to prevent invisible text during load.

## Usage Example

```typescript
// layout.tsx
import { azeretMono, dmSans } from '@/lib/fonts';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html className={`${azeretMono.variable} ${dmSans.variable}`}>
      <body>{children}</body>
    </html>
  );
}
```

```css
/* globals.css — reference via CSS variables */
body {
  font-family: var(--font-dm-sans), sans-serif;
}

code {
  font-family: var(--font-azeret-mono), monospace;
}
```
