Configures and exports the two Google Fonts used across the application via Next.js's built-in font optimization system.

## Key Components

| Export | Font | CSS Variable | Weights |
|--------|------|-------------|---------|
| `azeretMono` | Azeret Mono | `--font-azeret-mono` | 400, 500, 600, 700 |
| `dmSans` | DM Sans | `--font-dm-sans` | 400, 500, 700 |

Both fonts use `display: 'swap'` for improved CLS (Cumulative Layout Shift) performance and are scoped to the `latin` subset.

## Usage Example

Apply the CSS variables to the root layout, then reference them in Tailwind or CSS:

```typescript
// layout.tsx
import { azeretMono, dmSans } from '@/styles/fonts';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html className={`${dmSans.variable} ${azeretMono.variable}`}>
      <body>{children}</body>
    </html>
  );
}
```

```css
/* globals.css */
body {
  font-family: var(--font-dm-sans), sans-serif;
}

code {
  font-family: var(--font-azeret-mono), monospace;
}
```

> Next.js requires font loader calls to be statically assigned to a `const` — dynamic initialization is not supported.
