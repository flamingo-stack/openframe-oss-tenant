Configures and exports Google Font instances for use across the Next.js application using the built-in `next/font/google` loader.

## Key Components

| Export | Font | CSS Variable | Weights |
|--------|------|--------------|---------|
| `azeretMono` | Azeret Mono | `--font-azeret-mono` | 400, 500, 600, 700 |
| `dmSans` | DM Sans | `--font-dm-sans` | 400, 500, 700 |

Both fonts use `latin` subset and `swap` display strategy for optimal loading performance.

## Usage Example

Apply the CSS variables to your root layout, then reference them in Tailwind or CSS:

```typescript
// layout.tsx
import { azeretMono, dmSans } from '@/styles/fonts';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html className={`${dmSans.variable} ${azeretMono.variable}`}>
      <body>{children}</body>
    </html>
  );
}
```

```css
/* globals.css */
body {
  font-family: var(--font-dm-sans), sans-serif;
}

code {
  font-family: var(--font-azeret-mono), monospace;
}
```

> **Note:** Next.js requires font loader calls to be assigned to `const` at the module level — they cannot be called conditionally or inside functions.
