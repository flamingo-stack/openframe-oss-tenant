Utility functions for extracting and displaying API error messages in a consistent, user-friendly way across the application.

## Key Components

- **`getErrorMessage(error)`** — Extracts a readable string from an unknown error value. Handles `Error` instances, plain strings, and falls back to a generic message.
- **`handleApiError(error, toast, defaultMessage?)`** — Combines error extraction with a destructive toast notification. Designed for use in React Query `onError` mutation callbacks.

## Usage Example

```typescript
import { handleApiError, getErrorMessage } from './handle-api-error';

// In a React Query mutation
const mutation = useMutation({
  mutationFn: updateTicket,
  onError: (error) => {
    handleApiError(error, toast, 'Failed to update ticket');
  },
});

// Extracting a message manually
try {
  await riskyOperation();
} catch (error) {
  const message = getErrorMessage(error);
  console.error('Operation failed:', message);
}
```
