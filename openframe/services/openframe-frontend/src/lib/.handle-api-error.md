Utility module for extracting error messages from unknown error types and displaying standardized destructive toast notifications for API failures.

## Key Components

- **`getErrorMessage(error)`** — Normalizes an `unknown` error into a readable string; handles `Error` instances, plain strings, and falls back to a generic message.
- **`handleApiError(error, toast, defaultMessage?)`** — Combines error extraction with a toast notification call, designed for use in React Query `onError` callbacks.

## Usage Example

```typescript
import { handleApiError, getErrorMessage } from './handle-api-error';

// In a React Query mutation
const mutation = useMutation({
  mutationFn: createTicket,
  onError: (error) => {
    handleApiError(error, toast, 'Failed to create ticket');
  },
});

// Standalone message extraction
try {
  await fetchData();
} catch (error) {
  const message = getErrorMessage(error);
  console.error('API error:', message);
}

// Custom toast integration (e.g. shadcn/ui useToast)
const { toast } = useToast();

handleApiError(error, toast); // Uses default "Operation failed" title
handleApiError(error, toast, 'Could not save changes'); // Custom title
```

> **Note:** `handleApiError` expects a `toast` function matching the shadcn/ui `useToast` signature. The `defaultMessage` parameter sets the toast **title**, while the extracted error string becomes the **description**.
