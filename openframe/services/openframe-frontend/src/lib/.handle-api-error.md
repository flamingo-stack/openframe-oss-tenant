Utility functions for extracting and displaying API error messages in a consistent format across the application.

## Key Components

- **`getErrorMessage(error)`** — Extracts a human-readable string from an unknown error value. Handles `Error` instances, plain strings, and falls back to a generic message.
- **`handleApiError(error, toast, defaultMessage?)`** — Combines error extraction with a destructive toast notification. Designed for use in React Query `onError` mutation callbacks.

## Usage Example

```typescript
import { handleApiError, getErrorMessage } from './handle-api-error';

// In a React Query mutation
const mutation = useMutation({
  mutationFn: createTicket,
  onError: (error) => {
    handleApiError(error, toast, 'Failed to create ticket');
  },
});

// Extract message only (e.g. for logging or custom UI)
try {
  await riskyOperation();
} catch (error) {
  const message = getErrorMessage(error);
  console.error('Operation failed:', message);
}
```

> `defaultMessage` becomes the toast **title**, while the extracted error detail appears as the **description** — keeping notifications informative without exposing raw stack traces.
