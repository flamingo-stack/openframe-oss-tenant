A centralized runtime environment configuration manager that safely retrieves and validates environment variables for the OpenFrame application, with fallback mechanisms for both server and client environments.

## Key Components

- **getEnvVar()** - Internal utility function that safely retrieves environment variables with fallback handling
- **runtimeEnv** - Main configuration object exposing typed methods for accessing specific environment variables
- **URL Configuration** - Methods for tenant, shared, app, and dev URLs
- **Feature Flags** - Boolean methods for toggling application features
- **Auth Configuration** - Authentication-related settings and intervals

The configuration supports both Next.js runtime environment variables and fallback to standard process.env, with client-side compatibility.

## Usage Example

```typescript
import { runtimeEnv } from './runtime-config'

// Get application URLs
const tenantUrl = runtimeEnv.tenantHostUrl()
const appUrl = runtimeEnv.appUrl()

// Check feature flags
if (runtimeEnv.featureOrganizationImages()) {
  // Enable organization images feature
}

// Get authentication settings
const authInterval = runtimeEnv.authCheckIntervalMs() // Returns number
const loginUrl = runtimeEnv.authLoginUrl()

// App configuration
const mode = runtimeEnv.appMode() // Defaults to 'oss-tenant'
const type = runtimeEnv.appType() // Defaults to 'openframe-dashboard'

// Development features
if (runtimeEnv.enableDevTicketObserver()) {
  // Enable development ticket observer
}
```
