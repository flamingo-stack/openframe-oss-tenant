A centralized configuration utility that provides type-safe access to Next.js runtime environment variables with fallback handling and cross-platform compatibility. Uses `next-runtime-env` for reliable environment variable access in both server and client contexts.

## Key Components

- **`getEnvVar()`** - Internal helper function that safely retrieves environment variables with fallback mechanisms
- **`runtimeEnv`** - Main configuration object containing typed accessor methods for all environment variables
- **Configuration Methods** - Typed getters for URLs, feature flags, authentication settings, and application modes

## Usage Example

```typescript
import { runtimeEnv } from './runtime-config'

// Get application configuration
const appMode = runtimeEnv.appMode() // Returns 'oss-tenant' by default
const appUrl = runtimeEnv.appUrl() // Returns configured URL or default
const tenantUrl = runtimeEnv.tenantHostUrl()

// Check feature flags
const hasOrgImages = runtimeEnv.featureOrganizationImages() // Boolean
const allowSSO = runtimeEnv.featureSSOAllowDomain()

// Get optional configurations
const gtmId = runtimeEnv.gtmContainerId() // May return undefined
const authInterval = runtimeEnv.authCheckIntervalMs() // Returns parsed number with fallback

// Development settings
if (runtimeEnv.enableDevTicketObserver()) {
  console.log('Development ticket observer enabled')
}
```

The configuration handles type conversion (string to boolean/number) and provides sensible defaults for all required settings, ensuring the application works even with minimal environment configuration.
