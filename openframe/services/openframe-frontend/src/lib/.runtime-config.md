A runtime configuration utility that safely retrieves and parses environment variables for the OpenFrame Next.js application, providing fallback mechanisms and type-safe accessors.

## Key Components

- **`getEnvVar()`** - Core helper function that safely retrieves environment variables with fallback mechanisms
- **`runtimeEnv`** - Main configuration object exposing typed methods for all application environment variables
- **Environment variable categories:**
  - Host URLs (tenant, shared, app, dev)
  - Feature flags (organization images, SSO, script scheduling)
  - Application settings (mode, type, auth intervals)
  - Analytics configuration (GTM container ID)

## Usage Example

```typescript
import { runtimeEnv } from './runtime-config'

// Get application URLs
const appUrl = runtimeEnv.appUrl() // Returns configured app URL or default
const tenantUrl = runtimeEnv.tenantHostUrl() // Returns tenant host URL

// Check feature flags
const hasOrgImages = runtimeEnv.featureOrganizationImages() // boolean
const enableSSO = runtimeEnv.featureSSOAllowDomain() // boolean

// Get application mode and type
const mode = runtimeEnv.appMode() // 'oss-tenant' by default
const appType = runtimeEnv.appType() // 'openframe-dashboard' by default

// Get numeric configurations with parsing
const authInterval = runtimeEnv.authCheckIntervalMs() // Parsed integer, defaults to 300000

// Optional values
const gtmId = runtimeEnv.gtmContainerId() // May return undefined if not set
```

The utility handles edge cases like missing variables, parsing failures, and provides sensible defaults for critical configuration values.
