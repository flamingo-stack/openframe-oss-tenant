Runtime configuration utility that provides a centralized interface for accessing Next.js environment variables with fallback handling and type-safe defaults. Uses `next-runtime-env` for runtime environment variable access with graceful fallbacks to browser and Node.js process environments.

## Key Components

- **`getEnvVar()`** - Internal helper function that safely retrieves environment variables with multiple fallback strategies
- **`runtimeEnv`** - Main export object containing typed getter methods for all application configuration values
- **Configuration Methods** - Dedicated methods for URLs, feature flags, intervals, and application settings with sensible defaults

## Usage Example

```typescript
import { runtimeEnv } from './runtime-config'

// Get application URLs
const appUrl = runtimeEnv.appUrl() // Returns configured URL or default
const tenantHost = runtimeEnv.tenantHostUrl()

// Check feature flags
const orgImagesEnabled = runtimeEnv.featureOrganizationImages()
const ssoEnabled = runtimeEnv.featureSSOAllowDomain()

// Get application mode and type
const mode = runtimeEnv.appMode() // Defaults to 'oss-tenant'
const type = runtimeEnv.appType() // Defaults to 'openframe-dashboard'

// Get numeric configurations
const authInterval = runtimeEnv.authCheckIntervalMs() // Defaults to 300000ms

// Optional values
const gtmId = runtimeEnv.gtmContainerId() // May return undefined
```

The utility handles environment variable parsing, type conversion, and provides consistent defaults across the OpenFrame application stack.
