Provides a unified, runtime-safe accessor for `NEXT_PUBLIC_*` environment variables, supporting both server-side and client-side (browser) contexts via `next-runtime-env`.

## Key Components

### `getEnvVar(key)`
Internal helper that resolves an environment variable with a three-tier fallback:
1. `next-runtime-env`'s `env()` (primary, supports runtime injection)
2. `window.process.env` (browser fallback)
3. `process.env` (Node.js fallback)

Returns `undefined` for missing, empty, or null values.

### `runtimeEnv`
Exported configuration object exposing typed accessors for all `NEXT_PUBLIC_*` variables:

| Method | Variable | Default |
|--------|----------|---------|
| `tenantHostUrl()` | `NEXT_PUBLIC_TENANT_HOST_URL` | `''` |
| `sharedHostUrl()` | `NEXT_PUBLIC_SHARED_HOST_URL` | `''` |
| `gtmContainerId()` | `NEXT_PUBLIC_GTM_CONTAINER_ID` | `undefined` |
| `appMode()` | `NEXT_PUBLIC_APP_MODE` | `'oss-tenant'` |
| `appType()` | `NEXT_PUBLIC_APP_TYPE` | `'openframe-dashboard'` |
| `appUrl()` | `NEXT_PUBLIC_APP_URL` | `'https://openframe.dev'` |
| `devUrl()` | `NEXT_PUBLIC_DEV_URL` | `'http://localhost:4000'` |
| `enableDevTicketObserver()` | `NEXT_PUBLIC_ENABLE_DEV_TICKET_OBSERVER` | `false` |
| `authCheckIntervalMs()` | `NEXT_PUBLIC_AUTH_CHECK_INTERVAL` | `300000` |
| `authLoginUrl()` | `NEXT_PUBLIC_SHARED_HOST_URL` | `''` |

## Usage Example

```typescript
import { runtimeEnv } from '@/config/runtime-config';

// Access typed config values at runtime
const apiBase = runtimeEnv.tenantHostUrl();
const mode    = runtimeEnv.appMode();          // 'oss-tenant' | custom
const pollMs  = runtimeEnv.authCheckIntervalMs(); // number (ms)

if (runtimeEnv.enableDevTicketObserver()) {
  startTicketObserver(runtimeEnv.devUrl());
}
```
