A centralized runtime configuration utility that safely retrieves and transforms environment variables for the OpenFrame application, with fallback mechanisms for client-side and server-side environments.

## Key Components

- **`getEnvVar()`** - Internal helper function that safely retrieves environment variables using `next-runtime-env` with fallback strategies
- **`runtimeEnv`** - Main configuration object providing typed getters for all application environment variables
- **URL Configuration** - Methods for tenant, shared, app, and dev URLs
- **Feature Flags** - Boolean toggles for organization images, SSO domain allowlist, and script scheduling
- **Auth Settings** - Authentication check interval and login URL configuration
- **App Metadata** - Application mode, type, and GTM container ID retrieval

## Usage Example

```typescript
import { runtimeEnv } from './runtime-config'

// Get application URLs
const appUrl = runtimeEnv.appUrl() // 'https://openframe.dev' (default)
const tenantUrl = runtimeEnv.tenantHostUrl()

// Check feature flags
const hasOrgImages = runtimeEnv.featureOrganizationImages() // true (default)
const enableSSO = runtimeEnv.featureSSOAllowDomain() // true (default)

// Get auth configuration
const authInterval = runtimeEnv.authCheckIntervalMs() // 300000ms (5 min default)
const loginUrl = runtimeEnv.authLoginUrl()

// App metadata
const appMode = runtimeEnv.appMode() // 'oss-tenant' (default)
const gtmId = runtimeEnv.gtmContainerId() // undefined if not set
```
