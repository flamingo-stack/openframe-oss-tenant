A centralized runtime environment configuration utility for OpenFrame that provides safe access to Next.js public environment variables with fallback handling and type conversion.

## Key Components

- **`getEnvVar(key: string)`** - Internal helper function that safely retrieves environment variables with fallback mechanisms for client and server environments
- **`runtimeEnv`** - Main exported object containing typed accessor methods for all application environment variables

The configuration includes methods for:
- **Host URLs** - `tenantHostUrl()`, `sharedHostUrl()`, `appUrl()`, `devUrl()`
- **Application Settings** - `appMode()`, `appType()`, `gtmContainerId()`
- **Feature Flags** - `featureOrganizationImages()`, `featureSSOAllowDomain()`, `featureScriptSchedule()`
- **Authentication** - `authLoginUrl()`, `authCheckIntervalMs()`
- **Development** - `enableDevTicketObserver()`

## Usage Example

```typescript
import { runtimeEnv } from './runtime-config'

// Get application configuration
const appMode = runtimeEnv.appMode() // Returns 'oss-tenant' by default
const tenantUrl = runtimeEnv.tenantHostUrl()

// Check feature flags
if (runtimeEnv.featureOrganizationImages()) {
  // Enable organization image uploads
}

// Get typed values with defaults
const authInterval = runtimeEnv.authCheckIntervalMs() // Returns number, defaults to 300000
const devMode = runtimeEnv.enableDevTicketObserver() // Returns boolean

// Use in authentication flow
const loginUrl = runtimeEnv.authLoginUrl()
```

The utility handles environment variable parsing, type conversion, and provides sensible defaults for all OpenFrame configuration options.
