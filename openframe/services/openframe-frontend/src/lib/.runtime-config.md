A unified runtime configuration utility for managing environment variables in Next.js applications, providing type-safe access to public environment variables with fallback handling.

## Key Components

- **getEnvVar()** - Internal helper function that safely retrieves environment variables using `next-runtime-env` with fallback mechanisms for both client and server environments
- **runtimeEnv** - Main configuration object exposing typed methods for accessing application settings including:
  - Host URLs (tenant, shared, app, dev)
  - Google Tag Manager configuration
  - Application mode and type settings
  - Feature flags for organizations, SSO, and script scheduling
  - Authentication configuration (check intervals, login URLs)

## Usage Example

```typescript
import { runtimeEnv } from './runtime-config'

// Get application URLs
const tenantUrl = runtimeEnv.tenantHostUrl()
const appUrl = runtimeEnv.appUrl()

// Check feature flags
const hasOrgImages = runtimeEnv.featureOrganizationImages()
const ssoEnabled = runtimeEnv.featureSSOAllowDomain()

// Get authentication settings
const authInterval = runtimeEnv.authCheckIntervalMs() // Returns number
const loginUrl = runtimeEnv.authLoginUrl()

// Application configuration
const mode = runtimeEnv.appMode() // Default: 'oss-tenant'
const type = runtimeEnv.appType() // Default: 'openframe-dashboard'
```

The configuration provides sensible defaults for all values and handles both client-side and server-side environment access, making it suitable for universal Next.js applications in the Flamingo/OpenFrame ecosystem.
