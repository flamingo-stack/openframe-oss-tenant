A centralized runtime configuration utility that provides type-safe access to Next.js environment variables with fallback handling and cross-environment compatibility for both client and server-side execution.

## Key Components

- **`getEnvVar(key: string)`** - Internal helper function that safely retrieves environment variables using `next-runtime-env` with fallback to browser/Node.js environment access
- **`runtimeEnv`** - Exported configuration object containing typed accessor methods for all application environment variables
- **Configuration Methods** - Type-safe getters for URLs (`tenantHostUrl`, `sharedHostUrl`, `appUrl`), feature flags (`featureOrganizationImages`, `featureSSOAllowDomain`), and application settings (`appMode`, `appType`)

## Usage Example

```typescript
import { runtimeEnv } from './runtime-config'

// Get application URLs
const tenantUrl = runtimeEnv.tenantHostUrl()
const appUrl = runtimeEnv.appUrl() // defaults to 'https://openframe.dev'

// Check feature flags
const orgImagesEnabled = runtimeEnv.featureOrganizationImages() // boolean
const ssoEnabled = runtimeEnv.featureSSOAllowDomain() // boolean

// Get application mode
const mode = runtimeEnv.appMode() // defaults to 'oss-tenant'
const type = runtimeEnv.appType() // defaults to 'openframe-dashboard'

// Get numeric configurations
const authInterval = runtimeEnv.authCheckIntervalMs() // defaults to 300000
```

The utility handles environment variable parsing, type conversion, and provides sensible defaults for OpenFrame dashboard configuration across different deployment environments.
