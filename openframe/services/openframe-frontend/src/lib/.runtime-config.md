Centralized runtime environment configuration utility for Next.js applications that safely retrieves and parses environment variables with fallback handling for both server-side and client-side contexts.

## Key Components

- **`getEnvVar(key: string)`** - Internal helper function that safely retrieves environment variables with multiple fallback strategies
- **`runtimeEnv`** - Exported configuration object containing typed accessor methods for all application environment variables

## Configuration Methods

The `runtimeEnv` object provides the following configuration accessors:

- **URL Configuration**: `tenantHostUrl()`, `sharedHostUrl()`, `appUrl()`, `devUrl()`, `authLoginUrl()`
- **Application Settings**: `appMode()`, `appType()`, `gtmContainerId()`
- **Feature Flags**: `featureOrganizationImages()`, `featureSSOAllowDomain()`, `featureScriptSchedule()`
- **Development Tools**: `enableDevTicketObserver()`, `authCheckIntervalMs()`

## Usage Example

```typescript
import { runtimeEnv } from './runtime-config'

// Get application configuration
const appMode = runtimeEnv.appMode() // Returns 'oss-tenant' by default
const tenantUrl = runtimeEnv.tenantHostUrl() // Returns configured tenant URL

// Check feature flags
const orgImagesEnabled = runtimeEnv.featureOrganizationImages() // Returns boolean
const ssoEnabled = runtimeEnv.featureSSOAllowDomain() // Returns boolean

// Get numeric configurations with parsing
const authInterval = runtimeEnv.authCheckIntervalMs() // Returns parsed integer with 300000ms default

// Conditional logic based on environment
if (runtimeEnv.enableDevTicketObserver()) {
  // Enable development features
}
```

The utility handles parsing for different data types (strings, booleans, numbers) and provides sensible defaults for OpenFrame applications.
