A centralized runtime configuration utility that provides type-safe access to Next.js environment variables for the OpenFrame dashboard application. It handles fallback logic and type conversion for various application settings.

## Key Components

- **getEnvVar()** - Internal helper function that safely retrieves environment variables with fallback mechanisms
- **runtimeEnv** - Main configuration object exposing typed methods for all application environment variables
- **URL Configuration** - Methods for tenant, shared, app, and dev URLs
- **Feature Flags** - Boolean methods for toggling application features
- **Authentication Settings** - Auth-related configuration including check intervals and login URLs
- **Application Metadata** - App mode, type, and development settings

## Usage Example

```typescript
import { runtimeEnv } from './runtime-config'

// Get application URLs
const tenantUrl = runtimeEnv.tenantHostUrl()
const appUrl = runtimeEnv.appUrl()

// Check feature flags
const orgImagesEnabled = runtimeEnv.featureOrganizationImages()
const ssoEnabled = runtimeEnv.featureSSOAllowDomain()

// Get app configuration
const appMode = runtimeEnv.appMode() // defaults to 'oss-tenant'
const authInterval = runtimeEnv.authCheckIntervalMs() // defaults to 300000ms

// Optional values
const gtmId = runtimeEnv.gtmContainerId() // may return undefined
```

The configuration automatically handles missing environment variables with sensible defaults and provides type-safe access to all OpenFrame application settings.
