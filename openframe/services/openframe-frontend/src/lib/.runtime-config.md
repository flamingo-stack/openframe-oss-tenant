Provides a unified, runtime-safe accessor layer for Next.js public environment variables, with fallbacks for both server-side and client-side (`window.process.env`) execution contexts.

## Key Components

**`getEnvVar(key)`** *(internal)*
Resolves an env var using `next-runtime-env`, falling back to `window.process.env` then `process.env`. Returns `undefined` for empty/null/missing values.

**`runtimeEnv`** *(exported)*
Accessor object exposing typed getters for all runtime config values:

| Method | Env Var | Default |
|---|---|---|
| `tenantHostUrl()` | `NEXT_PUBLIC_TENANT_HOST_URL` | `''` |
| `sharedHostUrl()` | `NEXT_PUBLIC_SHARED_HOST_URL` | `''` |
| `gtmContainerId()` | `NEXT_PUBLIC_GTM_CONTAINER_ID` | `undefined` |
| `appMode()` | `NEXT_PUBLIC_APP_MODE` | `'oss-tenant'` |
| `appType()` | `NEXT_PUBLIC_APP_TYPE` | `'openframe-dashboard'` |
| `appUrl()` | `NEXT_PUBLIC_APP_URL` | `'https://openframe.dev'` |
| `devUrl()` | `NEXT_PUBLIC_DEV_URL` | `'http://localhost:4000'` |
| `enableDevTicketObserver()` | `NEXT_PUBLIC_ENABLE_DEV_TICKET_OBSERVER` | `false` |
| `authCheckIntervalMs()` | `NEXT_PUBLIC_AUTH_CHECK_INTERVAL` | `300000` |
| `authLoginUrl()` | `NEXT_PUBLIC_SHARED_HOST_URL` | `''` |

## Usage Example

```typescript
import { runtimeEnv } from '@/lib/runtime-config';

// Read app URL at runtime (safe on client and server)
const baseUrl = runtimeEnv.appUrl();

// Conditional feature flag
if (runtimeEnv.enableDevTicketObserver()) {
  startTicketObserver();
}

// Auth polling interval
setInterval(checkAuth, runtimeEnv.authCheckIntervalMs());
```

> **Note:** All values are resolved at call time, not at module load, making this safe for dynamic runtime injection without requiring a build step.
