A centralized runtime configuration module that provides type-safe access to Next.js environment variables with fallback support and runtime environment detection.

## Key Components

- **`getEnvVar()`** - Internal utility function that safely retrieves environment variables using `next-runtime-env` with fallbacks to browser and Node.js environments
- **`runtimeEnv`** - Main configuration object providing typed methods for accessing all application environment variables including URLs, feature flags, and authentication settings

## Usage Example

```typescript
import { runtimeEnv } from './runtime-config'

// Get application configuration
const appMode = runtimeEnv.appMode() // Returns 'oss-tenant' by default
const tenantUrl = runtimeEnv.tenantHostUrl()
const isDevMode = runtimeEnv.appUrl().includes('localhost')

// Check feature flags
if (runtimeEnv.featureScriptSchedule()) {
  // Enable script scheduling functionality
  initializeScheduler()
}

// Configure authentication
const authInterval = runtimeEnv.authCheckIntervalMs() // Returns 300000ms by default
setInterval(checkAuthStatus, authInterval)

// GTM integration
const gtmId = runtimeEnv.gtmContainerId()
if (gtmId) {
  initializeGTM(gtmId)
}
```

The module handles environment variable parsing with sensible defaults and type conversion for boolean and numeric values, making it safe to use across both server and client-side Next.js applications.
