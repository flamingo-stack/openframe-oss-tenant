Centralized runtime environment configuration utility for Next.js applications with fallback support for client and server-side environment variable access. Provides type-safe access to OpenFrame-specific configuration values with sensible defaults.

## Key Components

- **`getEnvVar(key: string)`** - Internal helper function that safely retrieves environment variables with fallback mechanisms
- **`runtimeEnv`** - Main configuration object exposing typed methods for all environment variables
- **URL Configuration** - Methods for tenant, shared, app, and dev URLs
- **Feature Flags** - Boolean toggles for organization images, SSO domain allowlist, and script scheduling
- **Authentication Settings** - Login URL and auth check interval configuration
- **Analytics Integration** - Google Tag Manager container ID support

## Usage Example

```typescript
import { runtimeEnv } from './runtime-config'

// Get application URLs
const tenantUrl = runtimeEnv.tenantHostUrl()
const appMode = runtimeEnv.appMode() // defaults to 'oss-tenant'

// Check feature flags
if (runtimeEnv.featureOrganizationImages()) {
  // Enable organization image uploads
}

// Configure authentication
const authInterval = runtimeEnv.authCheckIntervalMs() // defaults to 300000ms
const loginUrl = runtimeEnv.authLoginUrl()

// Analytics setup
const gtmId = runtimeEnv.gtmContainerId()
if (gtmId) {
  // Initialize Google Tag Manager
}
```

The utility gracefully handles missing environment variables by providing sensible defaults and works in both browser and server contexts through the `next-runtime-env` integration.
