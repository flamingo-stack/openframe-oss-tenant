A centralized runtime configuration manager for OpenFrame that provides type-safe access to environment variables with fallback mechanisms and proper client-side handling.

## Key Components

- **`getEnvVar(key: string)`** - Internal utility function that safely retrieves environment variables using `next-runtime-env` with fallbacks to browser and Node.js environments
- **`runtimeEnv`** - Main configuration object exposing typed methods for all application environment variables
- **URL Configuration** - Methods for tenant URLs, shared host URLs, and application URLs
- **Feature Flags** - Boolean methods for controlling feature availability (organization images, SSO, script scheduling)
- **Application Settings** - Configuration for app mode, type, authentication intervals, and development tools

## Usage Example

```typescript
import { runtimeEnv } from './runtime-config'

// Get application URLs
const tenantUrl = runtimeEnv.tenantHostUrl()
const sharedUrl = runtimeEnv.sharedHostUrl()

// Check feature flags
if (runtimeEnv.featureOrganizationImages()) {
  console.log('Organization images feature is enabled')
}

// Get application configuration
const appMode = runtimeEnv.appMode() // defaults to 'oss-tenant'
const authInterval = runtimeEnv.authCheckIntervalMs() // defaults to 300000ms

// Development settings
if (runtimeEnv.enableDevTicketObserver()) {
  // Enable development ticket observer
}
```

The configuration automatically handles missing environment variables by providing sensible defaults and gracefully falling back to alternative environment access methods when `next-runtime-env` is unavailable.
