Universal runtime configuration utility for Next.js applications that safely retrieves environment variables in both server and client environments. It provides a centralized access point for all OpenFrame application configuration with built-in fallbacks and type safety.

## Key Components

- **`getEnvVar(key: string)`** - Safe environment variable retrieval with fallback mechanisms
- **`runtimeEnv`** - Configuration object with methods for specific environment variables:
  - `tenantHostUrl()` - Multi-tenant host URL configuration
  - `sharedHostUrl()` - Shared services host URL
  - `gtmContainerId()` - Google Tag Manager container ID
  - `appMode()` - Application mode (defaults to 'oss-tenant')
  - `appType()` - Application type identifier
  - `appUrl()` - Production application URL
  - `devUrl()` - Development server URL
  - `enableDevTicketObserver()` - Development ticket observer feature flag
  - `authCheckIntervalMs()` - Authentication check interval in milliseconds
  - `featureOrganizationImages()` - Organization images feature flag
  - `featureSSOAllowDomain()` - SSO domain allowlist feature flag
  - `featureScriptSchedule()` - Script scheduling feature flag

## Usage Example

```typescript
import { runtimeEnv } from './runtime-config'

// Get application configuration
const appUrl = runtimeEnv.appUrl()
const isDevMode = runtimeEnv.appMode() === 'development'

// Check feature flags
if (runtimeEnv.featureScriptSchedule()) {
  // Enable script scheduling UI
}

// Configure authentication
const authInterval = runtimeEnv.authCheckIntervalMs()
setInterval(checkAuthStatus, authInterval)

// Get GTM container for analytics
const gtmId = runtimeEnv.gtmContainerId()
if (gtmId) {
  initializeGTM(gtmId)
}
```
