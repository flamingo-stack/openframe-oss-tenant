A unified runtime configuration utility for OpenFrame that safely retrieves environment variables in both client and server contexts, with fallback handling for various deployment scenarios.

## Key Components

- **`getEnvVar(key: string)`** - Internal helper function that safely retrieves environment variables with multiple fallback strategies using `next-runtime-env`
- **`runtimeEnv`** - Main configuration object exposing typed methods for all application environment variables
- **URL Configuration** - Methods for tenant/shared host URLs, app URLs, and development URLs
- **Feature Flags** - Boolean methods for enabling/disabling features like SSO, organization images, and script scheduling
- **Auth Configuration** - Authentication-related settings including login URLs and check intervals

## Usage Example

```typescript
import { runtimeEnv } from './runtime-config'

// Get application URLs
const appUrl = runtimeEnv.appUrl() // Returns NEXT_PUBLIC_APP_URL or default
const tenantUrl = runtimeEnv.tenantHostUrl() // Returns tenant host URL

// Check feature flags
if (runtimeEnv.featureOrganizationImages()) {
  // Enable organization image uploads
}

// Get authentication settings
const authInterval = runtimeEnv.authCheckIntervalMs() // Returns parsed number or 300000
const loginUrl = runtimeEnv.authLoginUrl()

// Application mode and type
const mode = runtimeEnv.appMode() // 'oss-tenant' by default
const appType = runtimeEnv.appType() // 'openframe-dashboard' by default
```

The configuration provides safe defaults and handles edge cases where environment variables might be undefined or malformed, ensuring the application runs reliably across different environments.
