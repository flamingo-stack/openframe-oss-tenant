Centralized manager for OAuth access token refresh operations, providing deduplication of concurrent refresh requests so multiple callers share a single in-flight refresh promise.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `refreshAccessToken()` | `async function` | Primary entry point — triggers a token refresh, deduplicating concurrent calls by returning the existing promise if one is in flight |
| `isTokenRefreshing()` | `function` | Returns `true` if a refresh is currently in progress |
| `waitForRefresh()` | `async function` | Resolves with the result of any in-progress refresh, or `false` if none is active |
| `buildRefreshUrl()` | internal | Constructs the `/oauth/refresh` URL with optional `tenantId` query param |
| `executeRefresh()` | internal | Performs the actual `POST /oauth/refresh` fetch, handling token storage for dev-ticket environments and clearing tokens on `401` |

## Behavior Notes

- **Dev ticket mode** (`enableDevTicketObserver`): sends `Refresh-Token` header and stores new tokens returned via headers or JSON body into `localStorage`
- **On 401**: calls `clearStoredTokens()` to force a logout
- **Tenant resolution**: lazily imports `useAuthStore` to extract `tenantId`/`organizationId` at refresh time

## Usage Example

```typescript
import { refreshAccessToken, isTokenRefreshing, waitForRefresh } from '@/lib/token-refresh-manager';

// Trigger a refresh (safe to call concurrently — deduplicated)
const success = await refreshAccessToken();
if (!success) {
  // redirect to login
}

// In an interceptor: wait for an in-progress refresh before retrying
if (isTokenRefreshing()) {
  const refreshed = await waitForRefresh();
  if (refreshed) {
    return retryRequest();
  }
}
```
