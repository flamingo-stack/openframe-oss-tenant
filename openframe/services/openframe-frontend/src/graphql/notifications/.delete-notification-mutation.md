Defines a Relay GraphQL mutation for deleting a single notification by ID.

## Key Components

- **`deleteNotificationMutation`** — A compiled Relay `graphql` mutation tag that calls the `deleteNotification` resolver, accepting a notification's `ID` and returning a boolean/acknowledgment.

## Usage Example

```typescript
import { deleteNotificationMutation } from './delete-notification-mutation';
import { useMutation } from 'react-relay';

const [commitDelete] = useMutation(deleteNotificationMutation);

commitDelete({
  variables: { id: notificationId },
  onCompleted: () => console.log('Notification deleted'),
  onError: (error) => console.error(error),
});
```

## Notes

- The mutation variable `$id` maps to the `notificationId` argument on the server resolver.
- No selection set is returned — the mutation is fire-and-forget (returns a scalar).
