Defines a Relay GraphQL mutation for deleting a single notification by ID.

## Key Components

- **`deleteNotificationMutation`** — A compiled Relay `graphql` mutation that calls the `deleteNotification` resolver, accepting a required `notificationId` argument.

## Usage Example

```typescript
import { deleteNotificationMutation } from './delete-notification-mutation';
import { useMutation } from 'react-relay';

const [commitDelete, isInFlight] = useMutation(deleteNotificationMutation);

commitDelete({
  variables: { id: 'notification-id-123' },
  onCompleted: () => console.log('Notification deleted'),
  onError: (error) => console.error(error),
});
```

## Variables

| Variable | Type | Required | Description |
|----------|------|----------|-------------|
| `id` | `ID` | ✅ | The unique identifier of the notification to delete |
