Defines a Relay GraphQL mutation for deleting a single notification by its ID.

## Key Components

- **`deleteNotificationMutation`** — A compiled Relay `graphql` mutation that calls the `deleteNotification` resolver, accepting a required `$id` argument of type `ID!`.

## Usage Example

```typescript
import { deleteNotificationMutation } from './delete-notification-mutation';
import { useMutation } from 'react-relay';

const [commitDelete] = useMutation(deleteNotificationMutation);

commitDelete({
  variables: { id: notificationId },
  onCompleted: () => console.log('Notification deleted'),
  onError: (error) => console.error(error),
});
```

## Notes

- The mutation returns a scalar (boolean or ID) confirming deletion — no nested selection set is required.
- The `$id` variable maps to `notificationId` on the server-side resolver.
