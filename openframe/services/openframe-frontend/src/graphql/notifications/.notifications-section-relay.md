Defines the Relay GraphQL query and paginated fragment for fetching notifications in the notifications section UI.

## Key Components

- **`notificationsSectionRelayQuery`** — Root GraphQL query that accepts pagination (`$first`, `$after`), filtering (`$filter`), and search (`$search`) arguments, spreading the refetchable fragment.
- **`notificationsSectionRelayFragment`** — Refetchable, paginated fragment on `Query` that fetches a cursor-based `notifications` connection with fields: `id`, `severity`, `title`, `description`, `createdAt`, `read`, and `context` (`__typename`, `type`).

## Key Details

- Uses `@refetchable` with `notificationsSectionRelayPaginationQuery` to enable infinite scroll / load-more patterns.
- The `@connection` directive keys the paginated list as `NotificationsList_notifications`, with `filter` and `search` as cache-busting filters.
- Default page size is `50` items.

## Usage Example

```typescript
import { usePreloadedQuery, useFragment } from 'react-relay';
import {
  notificationsSectionRelayQuery,
  notificationsSectionRelayFragment,
} from './notifications-section-relay';

// Preload the query at the route level
const queryRef = loadQuery(environment, notificationsSectionRelayQuery, {
  first: 50,
  filter: { read: false },
  search: '',
});

// Inside your component
const queryData = usePreloadedQuery(notificationsSectionRelayQuery, queryRef);
const data = useFragment(notificationsSectionRelayFragment, queryData);

const notifications = data.notifications.edges.map(({ node }) => node);
```
