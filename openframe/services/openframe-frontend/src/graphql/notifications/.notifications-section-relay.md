Defines the React Relay GraphQL query and paginated fragment for fetching notifications in the notifications section UI.

## Key Components

- **`notificationsSectionRelayQuery`** — Root query that accepts `$first`, `$after`, `$filter`, and `$search` variables, spreading the fragment with forwarded arguments.
- **`notificationsSectionRelayFragment`** — Refetchable, paginated fragment on `Query` using `@connection` for cursor-based pagination. Fetches notification fields: `id`, `severity`, `title`, `description`, `createdAt`, `read`, and `context` (with `__typename` and `type`).

## Usage Example

```typescript
import {
  notificationsSectionRelayQuery,
  notificationsSectionRelayFragment,
} from './notifications-section-relay';
import { useQueryLoader, usePreloadedQuery, usePaginationFragment } from 'react-relay';

// Load the root query
const [queryRef, loadQuery] = useQueryLoader(notificationsSectionRelayQuery);

loadQuery({ first: 50, filter: { read: false }, search: 'disk' });

// In the component, use the fragment for pagination
const { data, loadNext, hasNext } = usePaginationFragment(
  notificationsSectionRelayFragment,
  queryRef
);

const notifications = data.notifications.edges.map(({ node }) => node);
```

## Notes

- Pagination key is `NotificationsList_notifications`; `filter` and `search` are declared as connection filters so changing them triggers a fresh fetch rather than appending.
- Default page size is `50`; pass a smaller `$first` to override.
- The `context.__typename` field supports polymorphic notification contexts.
