Utility module for managing notification state in the Relay store and transforming GraphQL notification data into UI-ready `Notification` objects.

## Key Components

**Constants**
- `NOTIFICATIONS_CONNECTION_KEY` — Relay connection key used across all notification pagination queries
- `UNFILTERED_NOTIFICATION_PAIR` — Pre-built read/unread filter pair with no search term

**Types**
- `NotificationsConnectionFilters` — Filter shape passed to `ConnectionHandler.getConnection`
- `NotificationConnectionPair` — Paired read/unread filter set for optimistic store updates

**Store Updater Factories**
- `makeMarkReadUpdater(id, pairs)` — Moves a single notification from unread → read connections
- `makeMarkAllReadUpdater(pairs)` — Drains all unread edges into read connections and resets pagination
- `makeDeleteAllReadUpdater(pairs)` — Clears all edges from read connections and resets pagination
- `makeDeleteNotificationUpdater(id, pairs)` — Removes a single notification from all connections

**Mapping & Parsing Utilities**
- `mapNotificationNode(node)` — Converts a raw GraphQL `NotificationNode` to a typed `Notification` UI object
- `severityToVariant(severity)` — Maps `INFO | WARNING | DANGER` → `NotificationVariant` string
- `parseSeverity(input)` — Case-insensitive normalization of severity strings
- `parseCreatedAt(value)` — Accepts epoch seconds, epoch milliseconds, or ISO date strings; always returns epoch ms

## Usage Example

```typescript
import {
  makeMarkReadUpdater,
  makeMarkAllReadUpdater,
  makeDeleteNotificationUpdater,
  UNFILTERED_NOTIFICATION_PAIR,
  mapNotificationNode,
} from './notifications-helpers';

// Optimistic Relay updater: mark one notification as read
commitMutation(environment, {
  mutation: MarkReadMutation,
  variables: { id: notificationId },
  updater: makeMarkReadUpdater(notificationId, [UNFILTERED_NOTIFICATION_PAIR]),
});

// Optimistic Relay updater: delete a notification from all connections
commitMutation(environment, {
  mutation: DeleteNotificationMutation,
  variables: { id: notificationId },
  updater: makeDeleteNotificationUpdater(notificationId, [UNFILTERED_NOTIFICATION_PAIR]),
});

// Transform a raw GraphQL node into a UI Notification
const notification = mapNotificationNode(edge.node);
// → { id, title, description, createdAt (ms), read, severity, variant, meta }
```

> **Note:** All updater factories deduplicate connection IDs via an internal `Set` to avoid double-processing when the same physical connection appears under multiple filter pairs.
