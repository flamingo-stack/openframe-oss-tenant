Utility module for managing notifications in the Relay store and mapping GraphQL notification data to frontend display models.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `NOTIFICATIONS_CONNECTION_KEY` | `const` | Relay connection key for `NotificationsList_notifications` |
| `NotificationsConnectionFilters` | `interface` | Filter shape used to scope Relay connections by read state and search |
| `NotificationConnectionPair` | `interface` | Paired `unread`/`read` filter sets for a single connection context |
| `notificationsConnectionFilters` | `function` | Builds a `NotificationsConnectionFilters` object, trimming empty searches to `null` |
| `UNFILTERED_NOTIFICATION_PAIR` | `const` | Default unfiltered connection pair (no search, both read states) |
| `makeMarkReadUpdater` | `function` | Returns a Relay store updater that moves a single notification from unread → read connections |
| `makeMarkAllReadUpdater` | `function` | Returns a Relay store updater that bulk-moves all unread edges to read connections and resets pagination |
| `makeDeleteNotificationUpdater` | `function` | Returns a Relay store updater that removes a notification from all matching connections |
| `severityToVariant` | `function` | Maps `INFO`/`WARNING`/`DANGER` severity to a `NotificationVariant` display token |
| `parseSeverity` | `function` | Normalizes case-insensitive severity strings to the typed `KnownSeverity` union |
| `parseCreatedAt` | `function` | Safely coerces a timestamp value (number, ISO string, or unknown) to a Unix ms number |
| `mapNotificationNode` | `function` | Transforms a raw GraphQL `NotificationNode` into a typed frontend `Notification` model |

## Usage Example

```typescript
import {
  makeMarkReadUpdater,
  mapNotificationNode,
  UNFILTERED_NOTIFICATION_PAIR,
} from './notifications-helpers';

// Build a Relay updater for marking a single notification as read
const updater = makeMarkReadUpdater(notificationId, [UNFILTERED_NOTIFICATION_PAIR]);
commitMutation(environment, { mutation, variables, updater });

// Map a raw GraphQL node to a frontend Notification model
const notification = mapNotificationNode(rawNode);
// → { id, title, description, createdAt, read, severity, variant, meta }
```
