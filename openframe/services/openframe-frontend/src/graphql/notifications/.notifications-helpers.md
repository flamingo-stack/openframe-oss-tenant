Utility module providing Relay store updaters and data-mapping helpers for the notifications drawer feature.

## Key Components

### Constants & Types

- **`NOTIFICATIONS_CONNECTION_KEY`** — Relay connection key used to locate notification connections in the store
- **`NotificationsConnectionFilters`** — Filter shape (`read` flag + optional `search` string) passed to `ConnectionHandler.getConnection`
- **`NotificationConnectionPair`** — Pairs unread/read filter sets together for bulk updater operations

### Relay Store Updaters

- **`makeMarkReadUpdater(id, pairs)`** — Returns an updater that marks a single notification as read, removes it from unread connections, and prepends it to read connections
- **`makeMarkAllReadUpdater(pairs)`** — Returns an updater that moves all edges from unread connections into read connections and resets unread pagination state
- **`makeDeleteAllReadUpdater(pairs)`** — Returns an updater that clears all edges from read connections and resets their pagination state
- **`makeDeleteNotificationUpdater(id, pairs)`** — Returns an updater that removes a single notification node from both unread and read connections

### Data Helpers

- **`notificationsConnectionFilters(read, search)`** — Builds a `NotificationsConnectionFilters` object, trimming the search string and coercing empty strings to `null`
- **`severityToVariant(severity)`** — Maps `INFO | WARNING | DANGER` to the UI `NotificationVariant` (`info | warning | error | default`)
- **`parseSeverity(input)`** — Normalizes a case-insensitive severity string to the canonical `KnownSeverity` union
- **`parseCreatedAt(value)`** — Converts a numeric (seconds or milliseconds epoch) or ISO string timestamp to a millisecond epoch number, falling back to `Date.now()`
- **`mapNotificationNode(node)`** — Maps a raw GraphQL notification node to the frontend `Notification` model

## Usage Example

```typescript
import {
  makeMarkReadUpdater,
  UNFILTERED_NOTIFICATION_PAIR,
  mapNotificationNode,
} from './notifications-helpers';

// Relay mutation optimistic/updater usage
commitMutation(environment, {
  mutation: MarkReadMutation,
  variables: { id: notificationId },
  updater: makeMarkReadUpdater(notificationId, [UNFILTERED_NOTIFICATION_PAIR]),
});

// Map a raw GraphQL node for the UI
const notification = mapNotificationNode(rawNode);
// { id, title, severity: 'WARNING', variant: 'warning', createdAt: 1718000000000, ... }
```
