Defines a Relay GraphQL mutation that marks all notifications as read for the current user in a single operation.

## Key Components

- **`markAllNotificationsReadMutation`** — Relay `graphql` tagged template literal defining the `markAllNotificationsAsRead` mutation with no input variables required.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { markAllNotificationsReadMutation } from './mark-all-notifications-read-mutation';

function NotificationsBell() {
  const [commit, isInFlight] = useMutation(markAllNotificationsReadMutation);

  const handleMarkAllRead = () => {
    commit({
      variables: {},
      onCompleted: () => console.log('All notifications marked as read'),
      onError: (error) => console.error(error),
    });
  };

  return <button onClick={handleMarkAllRead} disabled={isInFlight}>Mark all read</button>;
}
```
