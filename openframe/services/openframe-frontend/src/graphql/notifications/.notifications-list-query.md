Defines a Relay GraphQL query for fetching a paginated, filterable list of notifications with connection-based cursor pagination.

## Key Components

- **`notificationsListQuery`** — A `graphql` tagged template literal query that fetches paginated notifications with support for filtering, searching, and cursor-based pagination via Relay's `@connection` directive.

### Query Variables

| Variable | Type | Description |
|----------|------|-------------|
| `$first` | `Int!` | Number of records to fetch |
| `$after` | `String` | Cursor for pagination |
| `$filter` | `NotificationFilterInput` | Filter criteria |
| `$search` | `String` | Search term |

### Returned Fields

Each notification node includes `id`, `severity`, `title`, `description`, `createdAt`, `read`, and a `context` object with `__typename` and `type`.

## Usage Example

```typescript
import { notificationsListQuery } from './notifications-list-query';
import { useLazyLoadQuery } from 'react-relay';
import type { notificationsListQuery as NotificationsListQueryType } from './__generated__/notificationsListQuery.graphql';

const NotificationsList = () => {
  const data = useLazyLoadQuery<NotificationsListQueryType>(
    notificationsListQuery,
    {
      first: 20,
      filter: { read: false },
      search: 'alert',
    }
  );

  return data.notifications.edges.map(({ node }) => (
    <div key={node.id}>{node.title}</div>
  ));
};
```

> The `@connection` key `NotificationsList_notifications` with `["filter", "search"]` filters enables Relay's store-based pagination and automatic cache invalidation when filter or search values change.
