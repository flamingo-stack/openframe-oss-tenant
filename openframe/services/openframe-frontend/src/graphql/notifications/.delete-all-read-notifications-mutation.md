Defines a Relay GraphQL mutation for deleting all read notifications in a single operation.

## Key Components

- **`deleteAllReadNotificationsMutation`** — A `graphql` tagged template literal that declares the `deleteAllReadNotifications` mutation, returning a scalar result (no sub-selection required).

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { deleteAllReadNotificationsMutation } from './delete-all-read-notifications-mutation';

const [commitMutation, isInFlight] = useMutation(deleteAllReadNotificationsMutation);

commitMutation({
  variables: {},
  onCompleted: () => console.log('All read notifications deleted'),
  onError: (error) => console.error(error),
});
```
