Defines a Relay GraphQL mutation for bulk-deleting all read notifications in a single operation.

## Key Components

- **`deleteAllReadNotificationsMutation`** — A compiled Relay `graphql` mutation that triggers the `deleteAllReadNotifications` resolver on the server, returning no payload beyond a success signal.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { deleteAllReadNotificationsMutation } from './delete-all-read-notifications-mutation';

const [commitMutation, isInFlight] = useMutation(deleteAllReadNotificationsMutation);

commitMutation({
  variables: {},
  onCompleted: () => console.log('All read notifications deleted'),
  onError: (error) => console.error(error),
});
```
