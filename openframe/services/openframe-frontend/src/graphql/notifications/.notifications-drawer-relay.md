Defines the Relay GraphQL query and paginated fragment for the notifications drawer, fetching unread notifications with cursor-based pagination.

## Key Components

- **`notificationsDrawerRelayQuery`** — Root query that spreads the drawer fragment, accepting `$first` (Int, required) and `$after` (String) pagination arguments.
- **`notificationsDrawerRelayFragment`** — Refetchable fragment on `Query` with `@argumentDefinitions` (defaults: `first: 30`). Uses `@connection` for Relay pagination under the key `NotificationsList_notifications`.

### Fetched Fields per Notification Node

| Field | Description |
|---|---|
| `id` | Unique identifier |
| `severity` | Alert level |
| `title` / `description` | Display content |
| `createdAt` | Timestamp |
| `read` | Read state (filtered to `false`) |
| `context.__typename` / `context.type` | Linked resource context |

## Usage Example

```typescript
import {
  notificationsDrawerRelayQuery,
  notificationsDrawerRelayFragment,
} from './notifications-drawer-relay';
import { usePreloadedQuery, useFragment } from 'react-relay';

// Preload the root query
const queryRef = loadQuery(environment, notificationsDrawerRelayQuery, {
  first: 30,
});

// Inside a component, resolve the fragment
const data = usePreloadedQuery(notificationsDrawerRelayQuery, queryRef);
const { notifications } = useFragment(notificationsDrawerRelayFragment, data);
```

> **Note:** The fragment is `@refetchable`, enabling `usePaginationFragment` for infinite-scroll or "load more" patterns via the auto-generated `notificationsDrawerRelayPaginationQuery`.
