Defines a Relay GraphQL mutation for marking a single notification as read by its ID.

## Key Components

- **`markNotificationReadMutation`** — A compiled Relay `graphql` mutation that calls `markNotificationAsRead` on the server, accepting a notification `id` as a required `ID!` variable.

## Usage Example

```typescript
import { useMutation } from 'react-relay';
import { markNotificationReadMutation } from './mark-notification-read-mutation';

const [commitMutation] = useMutation(markNotificationReadMutation);

commitMutation({
  variables: { id: 'notification-123' },
  onCompleted: () => console.log('Notification marked as read'),
  onError: (error) => console.error(error),
});
```
