React hook that encapsulates all notification-related GraphQL mutations with optimistic updates and toast error feedback.

## Key Components

**`useNotificationMutations(options)`** — Primary hook exposing four mutation handlers:

| Export | Type | Description |
|--------|------|-------------|
| `markRead` | `(id: string) => void` | Marks a single notification as read |
| `markAllRead` | `() => void` | Marks all notifications as read |
| `removeNotification` | `(id: string) => void` | Deletes a single notification |
| `removeAllRead` | `() => void` | Deletes all read notifications |
| `isMarkingAllRead` | `boolean` | In-flight state for mark-all-read |
| `isDeletingAllRead` | `boolean` | In-flight state for delete-all-read |

**`NotificationMutation`** — Union type `'markRead' | 'markAllRead' | 'delete' | 'deleteAllRead'` identifying each operation, passed to the optional `onError` callback.

**`UseNotificationMutationsOptions`** — Configuration interface:
- `filterPairs` — `NotificationConnectionPair[]` used by Relay store updaters to target the correct connections
- `onError?` — Called with the operation name and error after a toast is shown
- `onMarkAllReadCompleted?` / `onDeleteAllReadCompleted?` — Success callbacks for bulk operations

All mutations apply the same function as both `optimisticUpdater` and `updater`, reading `filterPairs` via a `useRef` to avoid stale closures.

## Usage Example

```typescript
const {
  markRead,
  markAllRead,
  removeNotification,
  removeAllRead,
  isMarkingAllRead,
  isDeletingAllRead,
} = useNotificationMutations({
  filterPairs: [{ connectionId: 'client:root:notifications', filter: 'unread' }],
  onError: (operation, err) => console.error(`[${operation}]`, err),
  onMarkAllReadCompleted: () => refetchCount(),
  onDeleteAllReadCompleted: () => refetchCount(),
});

// Mark one notification read
markRead(notification.id);

// Bulk clear
<button disabled={isMarkingAllRead} onClick={markAllRead}>Mark all read</button>
<button disabled={isDeletingAllRead} onClick={removeAllRead}>Clear read</button>
```
