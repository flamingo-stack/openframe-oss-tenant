React hook that consolidates four Relay GraphQL mutations for notification management — mark read, mark all read, delete, and delete all read — with optimistic UI updates and toast error feedback.

## Key Components

- **`useNotificationMutations`** — Primary hook returning all mutation handlers and loading states
- **`NotificationMutation`** — Union type identifying each mutation operation (`'markRead' | 'markAllRead' | 'delete' | 'deleteAllRead'`)
- **`UseNotificationMutationsOptions`** — Configuration interface accepting `filterPairs`, optional `onError`, and completion callbacks

## Returned Values

| Value | Type | Description |
|-------|------|-------------|
| `markRead` | `(id: string) => void` | Marks a single notification as read |
| `markAllRead` | `() => void` | Marks all notifications as read |
| `removeNotification` | `(id: string) => void` | Deletes a single notification |
| `removeAllRead` | `() => void` | Deletes all read notifications |
| `isMarkingAllRead` | `boolean` | In-flight state for bulk mark-read |
| `isDeletingAllRead` | `boolean` | In-flight state for bulk delete |

## Usage Example

```typescript
const { markRead, markAllRead, removeNotification, removeAllRead, isMarkingAllRead, isDeletingAllRead } =
  useNotificationMutations({
    filterPairs,
    onError: (operation, err) => console.error(`[${operation}]`, err),
    onMarkAllReadCompleted: () => refetch(),
    onDeleteAllReadCompleted: () => refetch(),
  });

// Mark a single notification read
markRead(notification.id);

// Bulk actions
markAllRead();
removeAllRead();
```

> All mutations apply **optimistic updates** to the Relay store immediately via `filterPairs`-scoped connection updaters, rolling back automatically on error with a destructive toast notification.
