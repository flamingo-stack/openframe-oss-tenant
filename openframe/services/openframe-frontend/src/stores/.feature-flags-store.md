Zustand store for managing feature flags state across the application, tracking which features are enabled/disabled and whether flags have been loaded.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `FeatureFlag` | Interface | Represents a single flag with `name` and `enabled` boolean |
| `FeatureFlagsState` | Interface | Full store shape including flags map, load state, and actions |
| `useFeatureFlagsStore` | Zustand Store | Primary hook to access and mutate feature flag state |

### Actions

| Action | Description |
|--------|-------------|
| `setFlags(flags)` | Replaces all flags from a `FeatureFlag[]` array and marks store as loaded |
| `setLoaded()` | Manually marks the store as loaded without modifying flags |
| `reset()` | Clears all flags and resets `isLoaded` to `false` |

## Usage Example

```typescript
import { useFeatureFlagsStore } from './feature-flags-store';

// Initialize flags (e.g., after fetching from API)
const { setFlags, flags, isLoaded } = useFeatureFlagsStore.getState();

setFlags([
  { name: 'new-dashboard', enabled: true },
  { name: 'beta-ai-chat', enabled: false },
]);

// In a React component
function MyComponent() {
  const flags = useFeatureFlagsStore(state => state.flags);
  const isLoaded = useFeatureFlagsStore(state => state.isLoaded);

  if (!isLoaded) return null;

  return flags['new-dashboard'] ? <NewDashboard /> : <OldDashboard />;
}
```

> Flags are stored as a flat `Record<string, boolean>` for O(1) lookups by name. The store uses `immer` for immutable updates and `devtools` for Redux DevTools inspection under the name `feature-flags-store`.
