Zustand store for managing feature flags state across the application, tracking which features are enabled/disabled and whether the flags have been loaded.

## Key Components

**Interfaces**
- `FeatureFlag` — shape of a single flag with `name` and `enabled` boolean
- `FeatureFlagsState` — full store shape including state and actions

**Store: `useFeatureFlagsStore`**
Built with `zustand` + `immer` middleware for immutable updates and `devtools` for debugging.

| Action | Description |
|--------|-------------|
| `setFlags(flags)` | Replaces all flags and marks store as loaded |
| `setLoaded()` | Marks the store as loaded without changing flags |
| `reset()` | Clears all flags and resets `isLoaded` to `false` |

**State**
- `flags` — `Record<string, boolean>` map of flag name → enabled status
- `isLoaded` — tracks whether flags have been fetched/initialized

## Usage Example

```typescript
import { useFeatureFlagsStore } from './feature-flags-store';

// Initialize flags from API response
const { setFlags, flags, isLoaded } = useFeatureFlagsStore.getState();

setFlags([
  { name: 'new-dashboard', enabled: true },
  { name: 'ai-assistant',  enabled: false },
]);

// In a React component
function MyComponent() {
  const isEnabled = useFeatureFlagsStore(s => s.flags['new-dashboard']);
  const isLoaded  = useFeatureFlagsStore(s => s.isLoaded);

  if (!isLoaded) return <Spinner />;
  return isEnabled ? <NewDashboard /> : <LegacyDashboard />;
}
```
