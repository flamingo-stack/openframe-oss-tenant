Zustand store for managing feature flags state across the application, tracking which flags are enabled and whether the flags have been loaded.

## Key Components

**Interfaces**
- `FeatureFlag` — Shape of a single feature flag with `name` and `enabled` boolean
- `FeatureFlagsState` — Full store shape including state and action definitions

**Store: `useFeatureFlagsStore`**

| Member | Type | Description |
|--------|------|-------------|
| `flags` | `Record<string, boolean>` | Map of flag name → enabled state |
| `isLoaded` | `boolean` | Whether flags have been fetched/initialized |
| `setFlags(flags)` | Action | Replaces all flags and marks store as loaded |
| `setLoaded()` | Action | Marks store as loaded without modifying flags |
| `reset()` | Action | Clears all flags and resets `isLoaded` to `false` |

Built with `immer` for immutable updates and `devtools` for Redux DevTools inspection under the name `feature-flags-store`.

## Usage Example

```typescript
import { useFeatureFlagsStore } from './feature-flags-store';

// Initialize flags from API response
const { setFlags, flags, isLoaded } = useFeatureFlagsStore.getState();

setFlags([
  { name: 'new-dashboard', enabled: true },
  { name: 'beta-ai-chat',  enabled: false },
]);

// React component usage
function MyComponent() {
  const flags    = useFeatureFlagsStore(s => s.flags);
  const isLoaded = useFeatureFlagsStore(s => s.isLoaded);

  if (!isLoaded) return <Spinner />;

  return flags['new-dashboard'] ? <NewDashboard /> : <LegacyDashboard />;
}

// Reset on logout
useFeatureFlagsStore.getState().reset();
```
