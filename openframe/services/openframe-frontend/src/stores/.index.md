Central export barrel file for all Zustand stores, aggregating auth, devices, and feature flags state management into a single import path.

## Key Components

### Re-exported Stores

| Store | Hook | Purpose |
|-------|------|---------|
| Auth | `useAuthStore` | User authentication state |
| Devices | `useDevicesStore` | Device list, filtering, and selection |
| Feature Flags | `useFeatureFlagsStore` | Runtime feature flag management |

### Auth Selectors
- `selectIsAuthenticated` — boolean auth status
- `selectUser` — current user object
- `selectAuthError` — auth error state
- `selectAuthLoading` — auth loading state

### Devices Selectors
- `selectDevices` — full device list
- `selectFilteredDevices` — devices after filter applied
- `selectDeviceStats` — aggregated device statistics
- `selectSelectedDevice` — currently selected device
- `selectFilter` — active filter config
- `selectDevicesError` / `selectDevicesLoading` — async state

### Exported Types
`AuthState` · `Device` · `DeviceFilter` · `DevicesState` · `FeatureFlag` · `FeatureFlagsState`

## Usage Example

```typescript
// Single import path for all stores and selectors
import {
  useAuthStore,
  useDevicesStore,
  useFeatureFlagsStore,
  selectIsAuthenticated,
  selectFilteredDevices,
  selectDeviceStats,
} from '@/stores';

function DeviceDashboard() {
  const isAuthenticated = useAuthStore(selectIsAuthenticated);
  const devices = useDevicesStore(selectFilteredDevices);
  const stats = useDevicesStore(selectDeviceStats);

  return isAuthenticated ? <DeviceList devices={devices} stats={stats} /> : null;
}
```

> Using named selectors (e.g. `selectFilteredDevices`) instead of inline callbacks prevents unnecessary re-renders by ensuring stable selector references across component cycles.
