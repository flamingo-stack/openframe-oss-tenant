Central export barrel file for all Zustand stores, providing unified imports for authentication, devices, and feature flags state management.

## Key Components

**Auth Store Exports**
- `useAuthStore` — Zustand hook for authentication state
- `selectIsAuthenticated`, `selectUser`, `selectAuthError`, `selectAuthLoading` — Memoized selectors for auth state slices
- `AuthState` — TypeScript type for auth store shape

**Devices Store Exports**
- `useDevicesStore` — Zustand hook for device management state
- `selectDevices`, `selectFilteredDevices`, `selectSelectedDevice`, `selectDeviceStats`, `selectFilter`, `selectDevicesError`, `selectDevicesLoading` — Memoized selectors for device state slices
- `Device`, `DeviceFilter`, `DevicesState` — TypeScript types for device store shape

**Feature Flags Store Exports**
- `useFeatureFlagsStore` — Zustand hook for feature flag state
- `FeatureFlag`, `FeatureFlagsState` — TypeScript types for feature flags store shape

## Usage Example

```typescript
// Import stores and selectors from a single path
import {
  useAuthStore,
  useDevicesStore,
  useFeatureFlagsStore,
  selectIsAuthenticated,
  selectFilteredDevices,
} from '@/stores';

function MyComponent() {
  // Use selectors for optimized re-renders
  const isAuthenticated = useAuthStore(selectIsAuthenticated);
  const filteredDevices = useDevicesStore(selectFilteredDevices);
  const { flags } = useFeatureFlagsStore();

  return <>{isAuthenticated && <DeviceList devices={filteredDevices} />}</>;
}
```

> Selectors (e.g. `selectFilteredDevices`) should be preferred over full store subscriptions to prevent unnecessary re-renders when unrelated state changes.
