Central barrel export for all Zustand stores, providing a unified import path for store hooks, selectors, and TypeScript types across the application.

## Key Components

**Auth Store exports:**
- `useAuthStore` — authentication state hook
- `selectIsAuthenticated`, `selectUser`, `selectAuthError`, `selectAuthLoading` — memoized selectors
- `AuthState` — TypeScript type

**Devices Store exports:**
- `useDevicesStore` — devices state hook
- `selectDevices`, `selectFilteredDevices`, `selectSelectedDevice`, `selectDeviceStats`, `selectFilter`, `selectDevicesError`, `selectDevicesLoading` — memoized selectors
- `Device`, `DeviceFilter`, `DevicesState` — TypeScript types

**Feature Flags Store exports:**
- `useFeatureFlagsStore` — feature flags state hook
- `FeatureFlag`, `FeatureFlagsState` — TypeScript types

## Usage Example

```typescript
// Single unified import instead of per-store paths
import {
  useAuthStore,
  useDevicesStore,
  useFeatureFlagsStore,
  selectIsAuthenticated,
  selectFilteredDevices,
} from '@/stores';

function MyComponent() {
  const isAuthenticated = useAuthStore(selectIsAuthenticated);
  const devices = useDevicesStore(selectFilteredDevices);
  const { flags } = useFeatureFlagsStore();

  return <>{isAuthenticated && <DeviceList devices={devices} />}</>;
}
```

> **Performance tip:** Always prefer the named selectors (e.g. `selectFilteredDevices`) over destructuring the full store state. Zustand selectors prevent unnecessary re-renders by subscribing only to the specific slice of state your component needs.
