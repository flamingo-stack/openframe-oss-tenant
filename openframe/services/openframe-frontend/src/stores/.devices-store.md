Zustand store for managing device state in the OpenFrame platform, including device CRUD operations, filtering, sorting, and computed selectors.

## Key Components

### Interfaces

| Interface | Description |
|-----------|-------------|
| `Device` | Core device model with type, status, metrics, and metadata |
| `DeviceFilter` | Filter criteria for status, type, tags, and search query |
| `DevicesState` | Full store shape combining state fields and action methods |

### Store

**`useDevicesStore`** — Zustand store with `immer` and `devtools` middleware providing:

| Action | Description |
|--------|-------------|
| `setDevices` | Replace full device list, updates `lastFetch` timestamp |
| `addDevice` | Append a new device |
| `updateDevice` | Partial update by ID, syncs `selectedDevice` if matched |
| `removeDevice` | Remove by ID, clears `selectedDevice` if matched |
| `selectDevice` | Set the active/selected device |
| `setFilter` / `clearFilters` | Apply or reset device filters |
| `setSorting` | Set sort field; toggles order if same field is re-selected |
| `refreshDevices` | Sets loading state to trigger external refetch |
| `reset` | Restore initial state |

### Selectors

| Selector | Description |
|----------|-------------|
| `selectFilteredDevices` | Returns devices after applying all active filters and sorting |
| `selectDeviceStats` | Returns counts grouped by status (online/offline/idle/error) |
| `selectFilter`, `selectIsLoading`, `selectError` | Simple state accessors |

## Usage Example

```typescript
import {
  useDevicesStore,
  selectFilteredDevices,
  selectDeviceStats,
} from './devices-store';

// Read filtered devices
const devices = useDevicesStore(selectFilteredDevices);

// Read status summary
const stats = useDevicesStore(selectDeviceStats);

// Apply a filter
const { setFilter, setSorting, selectDevice } = useDevicesStore.getState();

setFilter({ status: ['online'], searchQuery: 'web-srv' });
setSorting('lastSeen', 'desc');

// Select a device
selectDevice(devices[0]);

// Update a device
useDevicesStore.getState().updateDevice('device-123', {
  status: 'offline',
  metrics: { cpuUsage: 0 },
});
```
