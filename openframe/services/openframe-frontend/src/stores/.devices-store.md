Zustand store managing device inventory state for the OpenFrame platform, including CRUD operations, filtering, sorting, and computed selectors for device lists and statistics.

## Key Components

### Interfaces
- **`Device`** — Core device model with type, status, metrics, OS info, and network details
- **`DeviceFilter`** — Filter shape supporting status, type, tags, and free-text search
- **`DevicesState`** — Combined state + actions interface for the store

### Store
- **`useDevicesStore`** — Primary Zustand store with `devtools` and `immer` middleware

### Actions
| Action | Description |
|---|---|
| `setDevices` | Replaces full device list, updates `lastFetch` |
| `addDevice` | Appends a single device |
| `updateDevice` | Partial update by ID, syncs `selectedDevice` if active |
| `removeDevice` | Removes by ID, clears selection if active |
| `selectDevice` | Sets the active device |
| `setFilter` / `clearFilters` | Applies or resets device filters |
| `setSorting` | Sets sort field; toggles order if same field is re-selected |
| `refreshDevices` | Sets loading state to trigger upstream refetch |
| `reset` | Restores full initial state |

### Selectors
- **`selectFilteredDevices`** — Applies status/type/tag/search filters then sorts results
- **`selectDeviceStats`** — Returns counts for total, online, offline, idle, and error states
- `selectDevices`, `selectSelectedDevice`, `selectFilter`, `selectIsLoading`, `selectError`

## Usage Example

```typescript
import { useDevicesStore, selectFilteredDevices, selectDeviceStats } from './devices-store';

function DeviceList() {
  const filteredDevices = useDevicesStore(selectFilteredDevices);
  const stats = useDevicesStore(selectDeviceStats);
  const { setFilter, setSorting, selectDevice } = useDevicesStore();

  // Filter to online desktops only
  setFilter({ status: ['online'], type: ['desktop'] });

  // Sort by last seen, descending
  setSorting('lastSeen', 'desc');

  return (
    <>
      <p>Online: {stats.online} / {stats.total}</p>
      {filteredDevices.map(device => (
        <div key={device.id} onClick={() => selectDevice(device)}>
          {device.name} — {device.status}
        </div>
      ))}
    </>
  );
}
```
