Zustand store for managing device state in the OpenFrame platform, providing CRUD operations, filtering, sorting, and computed selectors for device inventory management.

## Key Components

### Interfaces
- **`Device`** — Device entity with fields for type, status, OS info, metrics, tags, and location
- **`DeviceFilter`** — Filter criteria supporting status, type, tags, and text search
- **`DevicesState`** — Combined state + actions interface for the store

### Store
- **`useDevicesStore`** — Zustand store with `immer` (immutable updates) and `devtools` middleware

### Actions
| Action | Description |
|---|---|
| `setDevices` | Replace full device list, updates `lastFetch` timestamp |
| `addDevice` | Append a new device |
| `updateDevice` | Partial update by ID; syncs `selectedDevice` if active |
| `removeDevice` | Remove by ID; clears selection if active |
| `selectDevice` | Set the active/selected device |
| `setFilter` / `clearFilters` | Apply or reset filter criteria |
| `setSorting` | Set sort field; toggles order if same field is re-selected |
| `refreshDevices` | Sets loading state to trigger a refetch |
| `reset` | Restore full initial state |

### Selectors
- **`selectFilteredDevices`** — Applies status/type/tag/text filters then sorts by `name`, `lastSeen`, `status`, or `type`
- **`selectDeviceStats`** — Returns counts for `total`, `online`, `offline`, `idle`, and `error` statuses

## Usage Example

```typescript
import { useDevicesStore, selectFilteredDevices, selectDeviceStats } from './devices-store';

function DeviceList() {
  const filteredDevices = useDevicesStore(selectFilteredDevices);
  const stats = useDevicesStore(selectDeviceStats);
  const { setFilter, setSorting, selectDevice } = useDevicesStore();

  // Filter to online desktops only
  setFilter({ status: ['online'], type: ['desktop'] });

  // Sort by last seen, descending
  setSorting('lastSeen', 'desc');

  return (
    <>
      <p>Online: {stats.online} / {stats.total}</p>
      {filteredDevices.map(device => (
        <div key={device.id} onClick={() => selectDevice(device)}>
          {device.name} — {device.status}
        </div>
      ))}
    </>
  );
}
```
