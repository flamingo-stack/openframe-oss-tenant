Utility class that logs JUnit 5 test execution summaries and test plan listings using SLF4J.

## Key Components

| Method | Description |
|--------|-------------|
| `logSummary(TestExecutionSummary)` | Logs found/succeeded/failed counts and details of any failures including test name and exception message |
| `logTestList(List<Test>)` | Logs the display names of all planned tests |

## Usage Example

```java
// After running a test suite via JUnit Platform Launcher
TestExecutionSummary summary = listener.getSummary();
SummaryLogger.logSummary(summary);

// Before execution, log the planned tests
List<Test> tests = testLoader.loadTests();
SummaryLogger.logTestList(tests);
```

**Sample output:**

```text
INFO  - Found: 12
INFO  - Succeeded: 10
INFO  - Failed: 2
ERROR - Failures:
ERROR -   shouldReturnUserById: Expected 200 but was 404
ERROR -   shouldCreateOrder: NullPointerException
```

> **Note:** Failure details are only emitted when `summary.getFailures()` is non-empty, keeping logs clean on full-pass runs.
