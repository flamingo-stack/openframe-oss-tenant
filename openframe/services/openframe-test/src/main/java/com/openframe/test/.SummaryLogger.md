A utility class for logging JUnit test execution summaries in a structured format using SLF4J logging.

## Key Components

- **`logSummary(TestExecutionSummary summary)`** - Static method that logs test execution statistics including tests found, succeeded, and failed counts

## Usage Example

```java
// In a test runner or listener
@Test
void runTestSuite() {
    LauncherDiscoveryRequest request = LauncherDiscoveryRequestBuilder.request()
        .selectors(selectPackage("com.openframe.test"))
        .build();
    
    Launcher launcher = LauncherFactory.create();
    TestExecutionSummary summary = launcher.execute(request)
        .getTestExecutionSummary();
    
    // Log the test results
    SummaryLogger.logSummary(summary);
    // Output:
    // INFO - Found: 25
    // INFO - Succeeded: 23  
    // INFO - Failed: 2
}
```

This utility is particularly useful in CI/CD pipelines or automated test runners where you need clear visibility into test execution results without verbose output.
