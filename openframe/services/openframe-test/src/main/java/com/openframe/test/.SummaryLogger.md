Utility class that logs JUnit test execution summaries and test plan listings using SLF4J.

## Key Components

| Method | Description |
|--------|-------------|
| `logSummary(TestExecutionSummary)` | Logs found/succeeded/failed counts and details of any failures |
| `logTestList(List<Test>)` | Logs the display names of all planned tests |

## Usage Example

```java
// Log results after test execution
TestExecutionSummary summary = launcher.execute(...);
SummaryLogger.logSummary(summary);

// Log planned tests before execution
List<Test> tests = testLoader.getTests();
SummaryLogger.logTestList(tests);
```
