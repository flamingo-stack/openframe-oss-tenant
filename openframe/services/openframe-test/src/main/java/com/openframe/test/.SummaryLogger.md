A utility class that logs JUnit test execution summary information in a structured format using SLF4J logging.

## Key Components

- **`logSummary(TestExecutionSummary)`** - Static method that logs test execution statistics including found, succeeded, and failed test counts

## Usage Example

```java
import org.junit.platform.launcher.listeners.TestExecutionSummary;
import com.openframe.test.SummaryLogger;

// After test execution completes
TestExecutionSummary summary = launcher.execute(request);
SummaryLogger.logSummary(summary);

// Output logs:
// INFO - Found: 15
// INFO - Succeeded: 13  
// INFO - Failed: 2
```

The class provides a clean way to output test results to logs, making it easy to track test execution outcomes in CI/CD pipelines or during development. Since it uses Lombok's `@Slf4j` annotation, it automatically provides a logger instance without boilerplate code.
