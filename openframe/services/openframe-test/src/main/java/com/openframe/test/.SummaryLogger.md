A utility class that provides structured logging of JUnit test execution summaries, offering a clean way to output test run statistics.

## Key Components

- **`logSummary(TestExecutionSummary)`** - Static method that logs test execution statistics including total tests found, succeeded, and failed counts

## Usage Example

```java
// In a test runner or JUnit platform listener
import org.junit.platform.launcher.listeners.TestExecutionSummary;

public class TestRunner {
    
    public void runTests() {
        // After test execution completes
        TestExecutionSummary summary = launcher.execute(request);
        
        // Log the summary statistics
        SummaryLogger.logSummary(summary);
        
        // Output example:
        // INFO - Found: 25
        // INFO - Succeeded: 22  
        // INFO - Failed: 3
    }
}
```

This logger is particularly useful in CI/CD pipelines or test automation frameworks where you need clear visibility into test execution results without parsing verbose test output.
