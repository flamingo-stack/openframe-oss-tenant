A utility class for logging JUnit test execution summaries in a structured format, providing clear visibility into test results during CI/CD pipelines and development workflows.

## Key Components

- **logSummary()** - Static method that logs test execution statistics including found, succeeded, and failed test counts
- **@Slf4j** - Lombok annotation providing SLF4J logger instance for consistent logging
- **TestExecutionSummary** - JUnit Platform summary object containing test execution metrics

## Usage Example

This utility is typically used with JUnit Platform's programmatic test execution to log summary results:

```java
import org.junit.platform.launcher.Launcher;
import org.junit.platform.launcher.LauncherDiscoveryRequest;
import org.junit.platform.launcher.core.LauncherFactory;
import org.junit.platform.launcher.listeners.SummaryGeneratingListener;

// Create launcher and summary listener
Launcher launcher = LauncherFactory.create();
SummaryGeneratingListener listener = new SummaryGeneratingListener();

// Execute tests
launcher.execute(request, listener);

// Log the summary
SummaryLogger.logSummary(listener.getSummary());
```

Example output:
```
INFO  - Found: 25
INFO  - Succeeded: 23  
INFO  - Failed: 2
```

This provides immediate feedback on test execution results, making it easier to identify issues in automated testing environments and track test suite health across OpenFrame components.
