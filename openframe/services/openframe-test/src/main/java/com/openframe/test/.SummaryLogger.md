A utility class for logging JUnit test execution summaries in a standardized format for the OpenFrame testing framework.

## Key Components

- **`logSummary(TestExecutionSummary summary)`** - Static method that logs test execution statistics including tests found, succeeded, and failed counts using SLF4J logging

## Usage Example

```java
import com.openframe.test.SummaryLogger;
import org.junit.platform.launcher.listeners.TestExecutionSummary;

// After test execution completes
TestExecutionSummary summary = launcher.execute(request);
SummaryLogger.logSummary(summary);

// Output logs will show:
// Found: 15
// Succeeded: 13  
// Failed: 2
```

This logger provides consistent test result reporting across the OpenFrame test suite, making it easy to track test execution metrics in CI/CD pipelines and development workflows. The class uses Lombok's `@Slf4j` annotation for clean logging integration.
