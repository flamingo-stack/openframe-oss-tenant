Utility class that logs JUnit 5 test execution summaries and test plan listings using SLF4J.

## Key Components

| Method | Description |
|--------|-------------|
| `logSummary(TestExecutionSummary)` | Logs found/succeeded/failed counts and details of any failures including test name and exception message |
| `logTestList(List<Test>)` | Logs the display names of all tests in a planned test run |

## Usage Example

```java
// After executing a test suite via the JUnit launcher
TestExecutionSummary summary = launcher.execute(...);
SummaryLogger.logSummary(summary);

// Before running, log the planned tests
List<Test> plannedTests = testPlan.getTests();
SummaryLogger.logTestList(plannedTests);
```
