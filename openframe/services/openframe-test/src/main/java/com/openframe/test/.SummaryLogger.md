A utility class for logging JUnit 5 test execution summaries with structured output using SLF4J logging.

## Key Components

- **`logSummary(TestExecutionSummary summary)`** - Static method that logs test execution statistics including tests found, succeeded, and failed counts

## Usage Example

```java
// In a test listener or test runner
TestExecutionSummary summary = launcher.execute(request);
SummaryLogger.logSummary(summary);

// Example output:
// INFO - Found: 25
// INFO - Succeeded: 23  
// INFO - Failed: 2
```

This class is typically used in conjunction with JUnit Platform test listeners to provide clean, formatted logging of test results. The Lombok `@Slf4j` annotation automatically provides the logger instance, making it easy to integrate into existing logging configurations.
