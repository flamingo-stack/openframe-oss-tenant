Utility class that logs JUnit test execution summaries and test plan listings using SLF4J.

## Key Components

- **`logSummary(TestExecutionSummary summary)`** — Logs test counts (found, succeeded, failed) and prints individual failure details including test display name and exception message.
- **`logTestList(List<Test> tests)`** — Logs the planned test suite by printing each test's display name.

## Usage Example

```java
// Log results after test execution
TestExecutionSummary summary = launcher.execute(...);
SummaryLogger.logSummary(summary);

// Log the planned tests before execution
List<Test> tests = testLoader.getTests();
SummaryLogger.logTestList(tests);
```

> Output is routed through SLF4J (`@Slf4j`), so log levels and appenders are controlled by your logging configuration (e.g., Logback, Log4j2).
