A utility class for logging JUnit 5 test execution summaries with formatted output showing test counts and results.

## Key Components

- **`logSummary(TestExecutionSummary)`** - Static method that logs test execution statistics including found, succeeded, and failed test counts
- Uses **Lombok's @Slf4j** annotation for logging capabilities
- Integrates with **JUnit Platform's TestExecutionSummary** for comprehensive test result reporting

## Usage Example

```java
// In a test listener or test runner
import org.junit.platform.launcher.LauncherSession;
import org.junit.platform.launcher.core.LauncherFactory;
import org.junit.platform.launcher.listeners.SummaryGeneratingListener;

public class TestRunner {
    public static void main(String[] args) {
        try (LauncherSession session = LauncherFactory.openSession()) {
            var launcher = session.getLauncher();
            var summaryListener = new SummaryGeneratingListener();
            
            // Execute tests
            launcher.execute(request, summaryListener);
            
            // Log the summary
            SummaryLogger.logSummary(summaryListener.getSummary());
        }
    }
}
```

The logger outputs structured information about test execution results, making it easy to track test suite performance and identify failures during automated testing processes.
