A utility class that provides structured logging of JUnit test execution summaries, displaying key metrics like test counts and results.

## Key Components

- **`logSummary(TestExecutionSummary summary)`** - Static method that logs test execution statistics including found, succeeded, and failed test counts

## Usage Example

```java
import com.openframe.test.SummaryLogger;
import org.junit.platform.launcher.listeners.TestExecutionSummary;

// In a test listener or after test execution
public void onTestExecutionFinished(TestExecutionSummary summary) {
    SummaryLogger.logSummary(summary);
}

// Example output:
// INFO - Found: 15
// INFO - Succeeded: 13  
// INFO - Failed: 2
```

The class leverages Lombok's `@Slf4j` annotation for clean logging and is designed to work with JUnit Platform's test execution summary reporting system, making it useful for CI/CD pipelines and test result monitoring.
