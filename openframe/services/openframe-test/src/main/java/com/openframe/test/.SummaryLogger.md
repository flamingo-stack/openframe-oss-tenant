A utility class for logging JUnit 5 test execution summaries in a structured format. This class provides a simple way to output key test metrics including found, succeeded, and failed test counts.

## Key Components

- **`logSummary(TestExecutionSummary summary)`** - Static method that logs test execution statistics using SLF4J
- **`@Slf4j`** - Lombok annotation providing automatic logger instance creation
- **Test metrics logging** - Outputs counts for tests found, succeeded, and failed

## Usage Example

```java
// In a test listener or after test execution
TestExecutionSummary summary = launcher.execute(request);
SummaryLogger.logSummary(summary);

// Example output:
// INFO - Found: 25
// INFO - Succeeded: 23  
// INFO - Failed: 2
```

The class integrates with JUnit 5's `TestExecutionSummary` to provide consistent logging across OpenFrame's test infrastructure, making it easy to track test results in CI/CD pipelines and development environments.
