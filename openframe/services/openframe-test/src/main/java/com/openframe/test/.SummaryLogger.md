A utility class that provides formatted logging for JUnit test execution summaries, helping developers quickly understand test results in their OpenFrame test suite.

## Key Components

- **`logSummary(TestExecutionSummary summary)`** - Static method that logs test execution statistics including found, succeeded, and failed test counts

## Usage Example

```java
import com.openframe.test.SummaryLogger;
import org.junit.platform.launcher.listeners.TestExecutionSummary;

// Log test results after test execution
TestExecutionSummary summary = launcher.execute(request);
SummaryLogger.logSummary(summary);

// Example output:
// INFO - Found: 25
// INFO - Succeeded: 23  
// INFO - Failed: 2
```

The class uses Lombok's `@Slf4j` annotation for logging and integrates with JUnit Platform's test execution framework to provide clear, structured output of test results for debugging and monitoring purposes.
