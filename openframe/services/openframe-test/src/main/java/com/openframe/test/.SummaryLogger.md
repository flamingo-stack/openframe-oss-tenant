A utility class that provides structured logging for JUnit 5 test execution summaries, helping track test results in a consistent format across the OpenFrame testing framework.

## Key Components

- **`logSummary(TestExecutionSummary)`** - Static method that logs test execution statistics including found, succeeded, and failed test counts
- **Lombok `@Slf4j`** - Provides logging capabilities through SLF4J framework
- **JUnit Platform Integration** - Works with JUnit 5's `TestExecutionSummary` for comprehensive test reporting

## Usage Example

```java
import com.openframe.test.SummaryLogger;
import org.junit.platform.launcher.listeners.TestExecutionSummary;

// After test execution completes
TestExecutionSummary summary = launcher.execute(request);
SummaryLogger.logSummary(summary);

// Output will be:
// INFO - Found: 15
// INFO - Succeeded: 13
// INFO - Failed: 2
```

This logger is typically used in test runners or CI/CD pipelines to provide clear visibility into test execution results, making it easier to monitor test suite health and identify failures quickly.
