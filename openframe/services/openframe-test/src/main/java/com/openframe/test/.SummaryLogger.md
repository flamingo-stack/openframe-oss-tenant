A utility class for logging JUnit 5 test execution summary information in a structured format using SLF4J logging.

## Key Components

- **`logSummary(TestExecutionSummary summary)`** - Static method that logs test execution statistics including found, succeeded, and failed test counts

## Usage Example

```java
// In a test listener or after test execution
TestExecutionSummary summary = launcher.execute(request);
SummaryLogger.logSummary(summary);

// Example output:
// INFO - Found: 15
// INFO - Succeeded: 12  
// INFO - Failed: 3
```

This logger is typically used in JUnit 5 test runners or custom test execution listeners to provide clear visibility into test results. The structured logging format makes it easy to parse test metrics for CI/CD reporting or monitoring systems.
