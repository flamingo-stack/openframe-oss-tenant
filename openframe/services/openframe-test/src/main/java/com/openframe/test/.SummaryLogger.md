A utility class that provides structured logging of JUnit test execution summaries for OpenFrame's test suite diagnostics.

## Key Components

- **logSummary()** - Static method that logs test execution metrics including found, succeeded, and failed test counts
- Uses Lombok's `@Slf4j` annotation for simplified logging
- Integrates with JUnit Platform's `TestExecutionSummary` for comprehensive test reporting

## Usage Example

```java
import com.openframe.test.SummaryLogger;
import org.junit.platform.launcher.listeners.TestExecutionSummary;

// After test execution completes
public void onExecutionFinished(TestExecutionSummary summary) {
    SummaryLogger.logSummary(summary);
    // Output:
    // INFO - Found: 25
    // INFO - Succeeded: 23
    // INFO - Failed: 2
}

// Typical integration in test launcher
LauncherFactory.create()
    .execute(request, new TestExecutionListener() {
        @Override
        public void executionFinished(TestExecutionSummary summary) {
            SummaryLogger.logSummary(summary);
        }
    });
```

This logger is particularly useful for CI/CD pipelines and test reporting where you need clear visibility into test execution results without verbose output.
