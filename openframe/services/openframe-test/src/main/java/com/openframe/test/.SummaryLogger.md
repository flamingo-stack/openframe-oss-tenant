A utility class for logging JUnit Platform test execution summaries in a standardized format. This class provides a static method to output key test metrics including found, succeeded, and failed test counts.

## Key Components

- **`logSummary(TestExecutionSummary summary)`** - Static method that logs test execution statistics using SLF4J logging framework

## Usage Example

```java
import com.openframe.test.SummaryLogger;
import org.junit.platform.launcher.listeners.TestExecutionSummary;

// In your test runner or listener
public void afterTestExecution(TestExecutionSummary summary) {
    SummaryLogger.logSummary(summary);
}

// Output example:
// INFO - Found: 15
// INFO - Succeeded: 13  
// INFO - Failed: 2
```

This utility is typically used in test execution listeners or custom test runners to provide consistent logging of test results across the OpenFrame testing infrastructure.
