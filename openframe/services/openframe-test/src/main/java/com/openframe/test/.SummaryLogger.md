A utility class for logging test execution summaries in a structured format, providing clear visibility into test results with success/failure counts.

## Key Components

- **`logSummary(TestExecutionSummary summary)`** - Static method that logs test execution statistics including total tests found, succeeded, and failed counts
- Uses SLF4J logging framework via Lombok's `@Slf4j` annotation for consistent logging output

## Usage Example

```java
import org.junit.platform.launcher.listeners.TestExecutionSummary;
import com.openframe.test.SummaryLogger;

// After test execution completes
TestExecutionSummary summary = // obtained from test launcher
SummaryLogger.logSummary(summary);

// Example output:
// INFO - Found: 15
// INFO - Succeeded: 13  
// INFO - Failed: 2
```

This logger is typically used in test runners or CI/CD pipelines to provide immediate feedback on test suite execution results, making it easy to quickly assess overall test health and identify when failures occur.
