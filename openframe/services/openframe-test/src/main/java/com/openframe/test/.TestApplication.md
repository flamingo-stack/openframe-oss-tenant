A main application class that orchestrates the execution of OpenFrame test suites in a specific order, with optional registration test skipping functionality.

## Key Components

- **TEST_PACKAGE**: Static constant defining the base package for test discovery (`com.openframe.test.tests`)
- **main()**: Entry point that executes test suites sequentially and handles command-line arguments
- **TestRunner integration**: Uses TestRunner to execute different test categories
- **SummaryLogger integration**: Logs test execution summaries for each test suite

## Usage Example

```java
// Run all test suites including registration tests
public static void main(String[] args) {
    // Normal execution - runs registration, OSS, and password reset tests
    java -cp classpath com.openframe.test.TestApplication
}

// Skip registration tests and run only OSS and password reset tests
public static void main(String[] args) {
    // Skip registration tests
    java -cp classpath com.openframe.test.TestApplication skipRegistration
}
```

The application follows a fail-fast approach where registration test failures prevent subsequent test execution. It exits with code 0 on success or 1 on failure, making it suitable for CI/CD pipelines. Test categories include "registration", "oss", and "reset" which are executed using tag-based filtering through the TestRunner.
