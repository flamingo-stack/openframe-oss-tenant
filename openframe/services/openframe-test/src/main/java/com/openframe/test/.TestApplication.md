A test application entry point that orchestrates the execution of OpenFrame test suites, including registration, OSS, and password reset tests, with conditional execution based on command-line arguments.

## Key Components

- **TEST_PACKAGE**: Constant defining the base package (`com.openframe.test.tests`) containing test classes
- **main()**: Entry point that handles test orchestration with optional `skipRegistration` argument
- **TestRunner**: Core testing engine that executes specific test categories
- **Conditional execution**: Registration tests act as a prerequisite - if they fail, subsequent tests are skipped
- **Exit codes**: Returns 0 for success, 1 for any test failures

## Usage Example

```java
// Run all tests in sequence (registration → OSS → password reset)
public static void main(String[] args) {
    java TestApplication
}

// Skip registration tests and run only OSS and password reset tests  
public static void main(String[] args) {
    java TestApplication skipRegistration
}

// Example test execution flow
TestRunner testRunner = new TestRunner("com.openframe.test.tests");
TestExecutionSummary summary = testRunner.runTests("registration");
logSummary(summary);
boolean success = summary.getTestsFailedCount() == 0;
```

The application provides a structured approach to running OpenFrame's test suites with proper logging, summary reporting, and fail-fast behavior for critical registration tests. It integrates with JUnit Platform for test execution and uses SLF4J for consistent logging throughout the testing process.
