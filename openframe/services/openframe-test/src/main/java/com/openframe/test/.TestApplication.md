A test orchestrator application that executes different test suites sequentially for the OpenFrame platform, with conditional execution based on command-line arguments and early termination on failures.

## Key Components

- **TestApplication** - Main application class with static execution entry point
- **TestRunner** - Executes test suites by category with JUnit Platform integration
- **TEST_PACKAGE** - Constant defining the base package for all test classes
- **Sequential Test Execution** - Runs registration, OSS, and password reset test suites in order
- **Conditional Execution Logic** - Supports skipping registration tests via command-line argument
- **Exit Code Management** - Returns appropriate system exit codes based on test results

## Usage Example

```java
// Run all test suites including registration tests
public static void main(String[] args) {
    // Default execution - runs all test suites
    java -cp classpath com.openframe.test.TestApplication
}

// Skip registration tests and run only OSS and password reset tests
public static void main(String[] args) {
    // With skipRegistration argument
    java -cp classpath com.openframe.test.TestApplication skipRegistration
}

// Example of test execution flow
TestRunner testRunner = new TestRunner("com.openframe.test.tests");
TestExecutionSummary summary = testRunner.runTests("registration");
boolean success = summary.getTestsFailedCount() == 0;
logSummary(summary);
```

The application automatically terminates with exit code 0 on success or 1 on failure, making it suitable for CI/CD pipeline integration. Registration tests act as a prerequisite - if they fail, subsequent test suites are skipped to prevent cascading failures.
