Main entry point for the OpenFrame test suite that orchestrates the execution of different test categories in a specific sequence. The application runs registration, OSS, and password reset tests with conditional execution based on test results and command-line arguments.

## Key Components

- **TEST_PACKAGE**: Constant defining the base package for test classes (`com.openframe.test.tests`)
- **main()**: Entry method that creates a TestRunner instance and executes test suites
- **TestRunner**: Utility class for running JUnit tests by category/tag
- **SummaryLogger**: Helper for logging test execution summaries

## Usage Example

```java
// Run all tests in sequence (default behavior)
java -cp target/classes com.openframe.test.TestApplication

// Skip registration tests and run only OSS and password reset tests
java -cp target/classes com.openframe.test.TestApplication skipRegistration
```

The application follows a fail-fast approach where registration test failures prevent subsequent test execution. It uses JUnit Platform's TestExecutionSummary to track results and exits with appropriate status codes (0 for success, 1 for failure) for CI/CD integration.

The test execution flow:
1. **Registration tests** (unless skipped) - must pass to continue
2. **OSS tests** - core functionality tests
3. **Password reset tests** - authentication flow tests

Each test category is logged individually with detailed summaries for debugging and monitoring purposes.
