Main entry point for the OpenFrame test suite that orchestrates execution of different test categories including registration, OSS, and password reset tests.

## Key Components

- **`main(String[] args)`** - Entry point that runs test suites in sequence with conditional execution based on results
- **`TEST_PACKAGE`** - Constant defining the base package for test discovery (`com.openframe.test.tests`)
- **Test execution flow** - Sequential execution of registration, OSS, and password reset test suites with early termination on failures
- **Command line argument support** - Accepts `skipRegistration` parameter to bypass registration tests

## Usage Example

```java
// Run all test suites in sequence (registration → OSS → password reset)
java com.openframe.test.TestApplication

// Skip registration tests and run only OSS and password reset tests
java com.openframe.test.TestApplication skipRegistration
```

The application uses a fail-fast approach where registration test failures prevent subsequent test execution, ensuring proper test dependencies are met. Each test suite's results are logged via `SummaryLogger.logSummary()` and the application exits with status code 0 for success or 1 for any test failures.
