A standalone test runner application that orchestrates the execution of OpenFrame test suites in a specific sequence, with optional registration test skipping and comprehensive result logging.

## Key Components

- **TestRunner Integration**: Utilizes `com.openframe.test.runner.TestRunner` to execute test suites within the `com.openframe.test.tests` package
- **Sequential Test Execution**: Runs three test categories in order: registration, OSS, and password reset tests
- **Failure Handling**: Stops execution if registration tests fail (unless skipped), preventing dependent test runs
- **Summary Logging**: Uses `SummaryLogger.logSummary()` to output detailed test execution results
- **Exit Code Management**: Returns appropriate exit codes (0 for success, 1 for failure) for CI/CD integration

## Usage Example

```java
// Run all tests including registration
java com.openframe.test.TestApplication

// Skip registration tests and run only OSS and password reset tests
java com.openframe.test.TestApplication skipRegistration
```

The application follows a fail-fast approach where registration test failures prevent subsequent test execution, ensuring system integrity before running dependent test suites. Each test category's results are logged with detailed summaries, making it ideal for automated testing pipelines and manual test verification.
