Main application class that orchestrates OpenFrame test execution across different test suites (registration, OSS, and password reset) using a custom TestRunner implementation.

## Key Components

- **TEST_PACKAGE**: Static constant defining the base package for test classes (`com.openframe.test.tests`)
- **main()**: Entry point that handles test execution flow based on command-line arguments
- **TestRunner**: Custom test runner instance for executing JUnit Platform tests
- **SummaryLogger**: Utility for logging test execution summaries

## Usage Example

```java
// Run all test suites in sequence (default behavior)
java com.openframe.test.TestApplication

// Skip registration tests and run only OSS and password reset tests
java com.openframe.test.TestApplication skipRegistration
```

The application executes tests in a specific order:
1. **Registration tests** (can be skipped with `skipRegistration` argument)
2. **OSS tests** (only runs if registration tests pass or are skipped)
3. **Password reset tests** (runs after OSS tests)

Each test suite execution is logged with detailed summaries, and the application exits with status code 0 for success or 1 for failure. Registration test failures will interrupt the execution flow to prevent running dependent test suites.
