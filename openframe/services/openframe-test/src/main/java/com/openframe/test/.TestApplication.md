Main application entry point for the OpenFrame test suite that orchestrates test execution across different test categories (registration, OSS, and password reset) with conditional execution flow based on registration test results.

## Key Components

- **TestRunner**: Executes test suites from the `com.openframe.test.tests` package
- **Test Categories**: Manages three distinct test suites - registration, OSS, and password reset
- **Conditional Execution**: Supports skipping registration tests via command-line argument
- **Summary Logging**: Integrates with `SummaryLogger` to provide detailed test execution reports
- **Exit Code Handling**: Returns appropriate exit codes based on overall test success/failure

## Usage Example

```java
// Run all tests in sequence (default behavior)
public class TestRunner {
    public static void main(String[] args) {
        // This will run: registration → OSS → password reset
        TestApplication.main(new String[]{});
    }
}

// Skip registration tests and run only OSS and password reset
public class TestRunner {
    public static void main(String[] args) {
        // This will run: OSS → password reset (skipping registration)
        TestApplication.main(new String[]{"skipRegistration"});
    }
}
```

The application provides fail-fast behavior where registration test failures prevent subsequent test execution, ensuring reliable test dependency management in the OpenFrame testing pipeline.
