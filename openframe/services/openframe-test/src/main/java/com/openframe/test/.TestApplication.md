Main application entry point for the OpenFrame test suite that orchestrates the execution of different test categories in a specific order. The application runs registration, OSS, and password reset tests sequentially, with the ability to skip registration tests via command line arguments.

## Key Components

- **main()** - Entry point that handles test execution flow and command line argument processing
- **TestRunner** - Manages test execution for specific test packages and categories
- **TEST_PACKAGE** - Static constant defining the base package for all test classes
- **Command line support** - Accepts "skipRegistration" argument to bypass registration tests

## Usage Example

```java
// Run all tests in sequence (registration -> OSS -> password reset)
public static void main(String[] args) {
    java TestApplication
}

// Skip registration tests and run only OSS and password reset tests
public static void main(String[] args) {
    java TestApplication skipRegistration
}

// Example of how the TestRunner is configured
TestRunner testRunner = new TestRunner("com.openframe.test.tests");
TestExecutionSummary summary = testRunner.runTests("registration");
boolean passed = summary.getTestsFailedCount() == 0;
```

The application follows a fail-fast approach where registration test failures prevent subsequent test execution, ensuring proper test dependency management. Each test category's results are logged via `SummaryLogger.logSummary()`, and the application exits with status code 0 for success or 1 for failure.
