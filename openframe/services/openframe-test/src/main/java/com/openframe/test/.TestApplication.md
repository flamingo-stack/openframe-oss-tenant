Main entry point for the OpenFrame test suite that orchestrates the execution of different test categories including registration, OSS, and password reset tests.

## Key Components

**Main Class:**
- `TestApplication` - CLI application that runs test suites in sequence with conditional execution

**Constants:**
- `TEST_PACKAGE` - Base package path for test discovery (`com.openframe.test.tests`)

**Dependencies:**
- `TestRunner` - Executes JUnit Platform tests with tag-based filtering
- `SummaryLogger` - Logs test execution summaries and results

## Usage Example

```java
// Run all tests in sequence (default behavior)
public static void main(String[] args) {
    java TestApplication
}

// Skip registration tests and run only OSS and password reset tests
public static void main(String[] args) {
    java TestApplication skipRegistration
}

// Example test execution flow
TestRunner testRunner = new TestRunner("com.openframe.test.tests");

// Run registration tests first (required for subsequent tests)
TestExecutionSummary registrationSummary = testRunner.runTests("registration");
logSummary(registrationSummary);

// Only proceed if registration tests pass
if (registrationSummary.getTestsFailedCount() == 0) {
    // Run OSS tests
    TestExecutionSummary ossSummary = testRunner.runTests("oss");
    logSummary(ossSummary);
}
```

The application implements fail-fast behavior where registration test failures prevent execution of subsequent test suites, ensuring proper test dependency management. Exit codes indicate overall test success (0) or failure (1).
