Main entry point for the OpenFrame test suite that orchestrates test execution across multiple test categories with conditional flow control and comprehensive logging.

## Key Components

- **TEST_PACKAGE**: Static constant defining the base package for test discovery (`com.openframe.test.tests`)
- **main()**: Primary execution method that handles test orchestration with optional registration test skipping
- **TestRunner**: Utilized for executing categorized test suites (registration, OSS, password reset)
- **Conditional Execution**: Registration tests act as a gatekeeper - failure prevents subsequent test execution
- **Exit Code Handling**: Returns appropriate system exit codes based on overall test results

## Usage Example

```java
// Standard execution - runs all test categories in sequence
// Registration → OSS → Password Reset (if previous passes)
java com.openframe.test.TestApplication

// Skip registration tests and run OSS + Password Reset only
java com.openframe.test.TestApplication skipRegistration
```

The application follows a fail-fast approach where registration test failures prevent execution of subsequent test suites, ensuring system integrity before running advanced test scenarios. All test results are logged using SLF4J with detailed summaries for each test category.
