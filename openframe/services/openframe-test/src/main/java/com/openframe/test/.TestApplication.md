Main entry point for the OpenFrame test suite that orchestrates the execution of different test categories in a specific order. The application runs registration tests first (unless skipped), followed by OSS and password reset tests, terminating early if critical tests fail.

## Key Components

- **TestRunner**: Core test execution engine that runs tests from the `com.openframe.test.tests` package
- **TestExecutionSummary**: JUnit Platform summary object containing test results and statistics
- **SummaryLogger**: Utility class for logging test execution summaries
- **Sequential Test Execution**: Runs tests in order: registration → OSS → password reset

## Usage Example

```java
// Run all tests (default behavior)
java -cp ... com.openframe.test.TestApplication

// Skip registration tests and run only OSS + password reset tests
java -cp ... com.openframe.test.TestApplication skipRegistration
```

The application uses a fail-fast approach where registration test failures prevent subsequent test execution, while OSS and password reset tests always run together. Exit codes follow standard conventions (0 for success, 1 for failure), making it suitable for CI/CD pipeline integration.

Test execution is logged using SLF4J with detailed summaries for each test category, providing visibility into test results and failure counts.
