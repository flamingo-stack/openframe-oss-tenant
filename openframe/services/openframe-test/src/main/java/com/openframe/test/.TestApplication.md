Main entry point for the OpenFrame test suite that orchestrates the execution of different test categories including registration, OSS (Open Source Software), and password reset tests using a custom TestRunner.

## Key Components

- **TEST_PACKAGE** - Static constant defining the base package for test classes (`com.openframe.test.tests`)
- **main()** - Entry point that handles test execution flow with optional argument processing
- **TestRunner** - Custom test runner instance for executing JUnit tests by category
- **SummaryLogger** - Utility for logging test execution summaries

## Usage Example

```java
// Run all test suites in sequence (default behavior)
java -cp classpath com.openframe.test.TestApplication

// Skip registration tests and run only OSS and password reset tests
java -cp classpath com.openframe.test.TestApplication skipRegistration
```

The application follows a conditional execution pattern where registration tests must pass before proceeding to subsequent test suites. If any test category fails, the application exits with a non-zero status code, making it suitable for CI/CD pipeline integration. The `skipRegistration` argument allows bypassing registration tests for scenarios where they're not required or have already been validated separately.
