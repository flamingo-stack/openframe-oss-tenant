Main entry point for the OpenFrame test suite that orchestrates the execution of different test categories in a specific sequence. The application runs registration tests first (unless skipped), followed by OSS tests and password reset tests, with early termination on failures.

## Key Components

- **`TestApplication`** - Main class containing the test execution logic
- **`TestRunner`** - Handles test execution for specific test categories
- **`SummaryLogger.logSummary()`** - Static method for logging test execution summaries
- **Test Categories**:
  - `registration` - User registration functionality tests
  - `oss` - Open source specific tests
  - `reset` - Password reset functionality tests

## Usage Example

```java
// Run all test suites in sequence (default behavior)
public static void main(String[] args) {
    java TestApplication
}

// Skip registration tests and run only OSS and reset tests
public static void main(String[] args) {
    java TestApplication skipRegistration
}

// Example of how the TestRunner is used internally
TestRunner testRunner = new TestRunner("com.openframe.test.tests");
TestExecutionSummary summary = testRunner.runTests("registration");
logSummary(summary);
boolean passed = summary.getTestsFailedCount() == 0;
```

The application exits with code 0 on success or 1 on failure, making it suitable for CI/CD pipeline integration. Registration tests act as a prerequisite - if they fail, subsequent test suites are skipped to prevent cascading failures.
