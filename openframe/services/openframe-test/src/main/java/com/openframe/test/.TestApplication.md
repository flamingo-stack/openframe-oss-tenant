Main entry point for the OpenFrame test suite that orchestrates execution of different test categories with conditional flow control and comprehensive result logging.

## Key Components

- **TEST_PACKAGE**: Static constant defining the base package for test discovery (`com.openframe.test.tests`)
- **main()**: Entry point method that manages test execution flow based on command-line arguments
- **TestRunner**: Utilized for executing categorized test suites
- **Conditional execution**: Registration tests act as a gate for subsequent test execution
- **Exit code handling**: Returns appropriate system exit codes based on test results

## Usage Example

```java
// Run all tests (default behavior)
java -cp classpath com.openframe.test.TestApplication

// Skip registration tests and run remaining suites
java -cp classpath com.openframe.test.TestApplication skipRegistration
```

The application executes tests in a specific sequence:
1. **Registration tests** (unless skipped) - must pass for execution to continue
2. **OSS tests** - executed if registration tests pass or are skipped  
3. **Password Reset tests** - executed alongside OSS tests

Each test category generates a `TestExecutionSummary` that gets logged via `SummaryLogger.logSummary()`. The application exits with code 0 for success or 1 for failure, making it suitable for CI/CD pipeline integration.
