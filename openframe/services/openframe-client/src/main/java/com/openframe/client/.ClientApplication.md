Spring Boot application entry point for the OpenFrame **Client** service, bootstrapping the application context with a curated component scan across core platform packages while explicitly excluding the Cassandra health indicator.

## Key Components

| Element | Description |
|---|---|
| `@SpringBootApplication` | Enables auto-configuration, component scanning, and property support |
| `@ComponentScan` | Scopes bean discovery to five OpenFrame packages |
| `CassandraHealthIndicator` exclusion | Prevents the Cassandra health check from being registered in this service context |
| `main()` | Standard Spring Boot launcher via `SpringApplication.run()` |

### Scanned Packages

- `com.openframe.data` — data access layer
- `com.openframe.client` — client service beans
- `com.openframe.core` — shared platform core
- `com.openframe.security` — security configuration
- `com.openframe.kafka.producer` — Kafka producer components

## Usage Example

```java
// Standard Spring Boot launch — no additional setup required
public static void main(String[] args) {
    SpringApplication.run(ClientApplication.class, args);
}
```

To run from the command line:

```bash
./mvnw spring-boot:run
# or with a specific profile
java -jar target/client-service.jar --spring.profiles.active=prod
```

> **Note:** `CassandraHealthIndicator` is excluded via `FilterType.ASSIGNABLE_TYPE` to avoid unwanted health endpoint registration in this service. If Cassandra health monitoring is needed, wire a custom indicator within `com.openframe.client` instead.
