Spring Boot application entry point for the OpenFrame **Client** service. Bootstraps the application context and configures component scanning across all relevant OpenFrame modules while explicitly excluding the `CassandraHealthIndicator` to prevent unwanted health check registration.

## Key Components

| Element | Description |
|---|---|
| `@SpringBootApplication` | Enables auto-configuration, component scanning, and configuration properties |
| `@ComponentScan` | Scans across five OpenFrame base packages for Spring-managed beans |
| `excludeFilters` | Suppresses `CassandraHealthIndicator` from being registered as a Spring bean |
| `main()` | Standard Spring Boot launcher via `SpringApplication.run()` |

**Scanned Packages:**

- `com.openframe.data` — Data access layer
- `com.openframe.client` — Client-specific beans and controllers
- `com.openframe.core` — Shared core utilities
- `com.openframe.security` — Authentication and authorization
- `com.openframe.kafka.producer` — Kafka event publishing

## Usage Example

```java
// Standard Spring Boot startup — run from CLI or IDE
public class ClientApplication {
    public static void main(String[] args) {
        SpringApplication.run(ClientApplication.class, args);
    }
}
```

```bash
# Build and run the Client service
./mvnw spring-boot:run -pl client

# Or with a specific profile
java -jar client.jar --spring.profiles.active=production
```

> **Note:** `CassandraHealthIndicator` is excluded here because the Client service manages its own health strategy. If you need Cassandra health checks re-enabled, remove the `excludeFilters` block and ensure the appropriate actuator endpoint is configured.
