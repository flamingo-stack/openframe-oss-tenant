# TestUtils.java

A utility class providing shared helper methods for OAuth-related unit and integration tests, including JSON serialization, reflection-based field injection, and factory methods for test fixtures.

## Key Components

- **`asJsonString(Object obj)`** - Serializes an object to its JSON string representation using Jackson's `ObjectMapper`; wraps checked exceptions in a `RuntimeException`.
- **`setPrivateField(Object target, String fieldName, Object value)`** - Uses reflection to set the value of a private field on a target object, bypassing normal access modifiers. Useful for injecting test state without exposing setters.
- **`createTestClient()`** - Builds a sample `OAuthClient` populated with test client ID, secret, redirect URIs, grant types, and scopes.
- **`createTestToken()`** - Builds a sample `OAuthToken` with access/refresh tokens, expiry timestamps, and scopes for use in token-related test scenarios.
- **`createTestTokenResponse()`** - Builds a sample `TokenResponse` DTO (Bearer token, 1-hour expiry) for simulating OAuth token endpoint responses.
- **`createTestAuthResponse()`** - Builds a sample `AuthorizationResponse` DTO representing an OAuth authorization code grant response.

## Usage Example

```java
import static com.openframe.api.TestUtils.*;

@Test
void shouldSerializeTokenResponse() {
    TokenResponse response = createTestTokenResponse();
    String json = asJsonString(response);

    assertThat(json).contains("Bearer");
}

@Test
void shouldInjectPrivateFieldForTesting() {
    OAuthToken token = createTestToken();
    setPrivateField(token, "userId", "custom_user_id");

    assertThat(token.getUserId()).isEqualTo("custom_user_id");
}

@Test
void shouldCreateTestClientFixture() {
    OAuthClient client = createTestClient();

    assertThat(client.getClientId()).isEqualTo(TestConstants.TEST_CLIENT_ID);
    assertThat(client.getScopes()).contains("read", "write");
}
```

**Note:** This class is final with a private constructor and is intended solely as a static utility holder—it should not be instantiated.
