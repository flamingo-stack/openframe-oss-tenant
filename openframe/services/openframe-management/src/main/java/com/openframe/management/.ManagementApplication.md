Spring Boot application entry point for the OpenFrame Management service. Bootstraps the application context and configures component scanning across core packages while explicitly excluding the Cassandra health indicator.

## Key Components

- **`@SpringBootApplication`** — Enables auto-configuration, component scanning, and Spring Boot defaults
- **`@ComponentScan`** — Scans three base packages: `com.openframe.management`, `com.openframe.data`, and `com.openframe.core`
- **`CassandraHealthIndicator` exclusion** — Prevents the Cassandra health bean from being registered, likely to avoid startup failures when Cassandra is unavailable or managed externally
- **`main()`** — Standard Spring Boot launcher via `SpringApplication.run()`

## Usage Example

```bash
# Build and run the Management service
./mvnw spring-boot:run -pl management

# Or run the packaged JAR directly
java -jar management/target/management.jar
```

```java
// The application bootstraps all beans from scanned packages
// except CassandraHealthIndicator, e.g.:
@Service // picked up from com.openframe.management.*
public class DeviceManagementService { ... }

@Repository // picked up from com.openframe.data.*
public class DeviceRepository { ... }
```

> **Note:** If you need to re-enable Cassandra health checks, remove `CassandraHealthIndicator.class` from the `excludeFilters` block and ensure a reachable Cassandra instance is configured in `application.yml`.
