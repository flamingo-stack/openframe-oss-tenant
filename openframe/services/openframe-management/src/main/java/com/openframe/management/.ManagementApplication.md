Spring Boot application entry point for the OpenFrame Management service. Bootstraps the application context and configures component scanning across core packages while explicitly excluding the Cassandra health indicator.

## Key Components

| Element | Description |
|---------|-------------|
| `@SpringBootApplication` | Enables auto-configuration, component scanning, and Spring Boot defaults |
| `@ComponentScan` | Scans `com.openframe.management`, `com.openframe.data`, and `com.openframe.core` packages |
| `excludeFilters` | Suppresses `CassandraHealthIndicator` from being registered as a Spring bean |
| `main()` | Standard Spring Boot launcher via `SpringApplication.run()` |

## Usage Example

```java
// Standard Spring Boot startup — run directly or via Maven/Gradle
public static void main(String[] args) {
    SpringApplication.run(ManagementApplication.class, args);
}
```

```bash
# Run with Maven
mvn spring-boot:run

# Or with a built JAR
java -jar management-service.jar
```

## Notes

- The exclusion of `CassandraHealthIndicator` suggests the Management service either uses a custom health check strategy or Cassandra connectivity is managed externally — preventing duplicate or conflicting health endpoint registration.
- The multi-package scan (`management`, `data`, `core`) indicates a modular monorepo structure shared across OpenFrame services.
