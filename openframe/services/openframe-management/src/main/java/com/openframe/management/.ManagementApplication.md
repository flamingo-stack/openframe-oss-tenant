Entry point for the OpenFrame Management Spring Boot service. Bootstraps the application context and configures component scanning across core packages while explicitly excluding the Cassandra health indicator.

## Key Components

- **`@SpringBootApplication`** — Enables auto-configuration, component scanning, and configuration properties for the Management service.
- **`@ComponentScan`** — Scans three base packages:
  - `com.openframe.management` — Management-specific beans
  - `com.openframe.data` — Data layer components
  - `com.openframe.core` — Shared core utilities
- **`CassandraHealthIndicator` exclusion** — Prevents the Cassandra health check bean from being registered (e.g., when Cassandra is not used or managed separately in this service context).
- **`main()`** — Standard Spring Boot launcher via `SpringApplication.run()`.

## Usage Example

```bash
# Build and run the Management service
./mvnw spring-boot:run -pl management

# Or run the packaged JAR directly
java -jar management/target/management.jar
```

```java
// No direct instantiation needed — Spring Boot manages the lifecycle.
// To customize startup behavior, add an ApplicationRunner bean:
@Component
public class ManagementStartupRunner implements ApplicationRunner {
    @Override
    public void run(ApplicationArguments args) {
        // Custom initialization logic after context loads
    }
}
```

> **Note:** The exclusion of `CassandraHealthIndicator` means Cassandra health checks will not appear in the `/actuator/health` endpoint for this service. If Cassandra connectivity monitoring is required, re-enable it via a custom `HealthIndicator` bean within the `com.openframe.management` package.
