A no-op implementation of `AdditionalStreamConfigurationProvider` that supplies no extra NATS JetStream configurations, used in distributions that do not include AI chat functionality.

## Key Components

- **`NoAdditionalStreamConfigurationProvider`** - Spring-managed component implementing `AdditionalStreamConfigurationProvider`.
- **`provide()`** - Returns an empty `List<StreamConfiguration>`, indicating that no additional JetStream streams are required beyond those created by `NatsStreamConfigurationInitializer`.

## Usage Example

This class is automatically picked up by Spring's component scanning and injected wherever `AdditionalStreamConfigurationProvider` is required, typically during application startup to initialize NATS JetStream streams.

```java
@Component
public class NatsStreamConfigurationInitializer {

    private final AdditionalStreamConfigurationProvider additionalStreamConfigurationProvider;

    public NatsStreamConfigurationInitializer(
            AdditionalStreamConfigurationProvider additionalStreamConfigurationProvider) {
        this.additionalStreamConfigurationProvider = additionalStreamConfigurationProvider;
    }

    public void initialize() {
        List<StreamConfiguration> coreStreams = createCoreStreams();
        List<StreamConfiguration> extraStreams = additionalStreamConfigurationProvider.provide();

        List<StreamConfiguration> allStreams = Stream.concat(
                coreStreams.stream(), extraStreams.stream())
                .toList();

        allStreams.forEach(this::createJetStream);
    }
}
```

In distributions without AI chat capabilities, Spring injects `NoAdditionalStreamConfigurationProvider`, resulting in only the core streams being created. Distributions that include AI chat would instead provide an alternative bean implementing `AdditionalStreamConfigurationProvider` with the required additional stream definitions.
