# OpenFrame OSS Tenant Documentation

Welcome to the documentation for **OpenFrame OSS Tenant** ([flamingo-stack/openframe-oss-tenant](https://github.com/flamingo-stack/openframe-oss-tenant)) — the deployable, tenant-oriented distribution of the [OpenFrame](https://openframe.ai) MSP platform. It assembles nine Spring Boot services and a Rust endpoint agent from the [OpenFrame OSS Library](https://github.com/flamingo-stack/openframe-oss-lib) into a runnable, deployable tenant stack.
