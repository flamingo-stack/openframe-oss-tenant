Configures REST Assured HTTP client settings for API testing in the OpenFrame platform, including SSL validation, timeouts, and logging configuration.

## Key Components

- **configure()** - Static method that configures REST Assured with default base URL from ApiConfig
- **configure(String baseUrl)** - Overloaded method allowing custom base URL configuration
- **DEFAULT_TIMEOUT** - 60-second timeout constant for HTTP connections and socket operations

The configuration includes:
- **SSL Config** - Relaxed HTTPS validation for testing environments
- **Log Config** - Automatic logging when validation fails
- **HTTP Client Config** - Connection and socket timeout settings

## Usage Example

```java
// Configure with default base URL
RestAssuredConfig.configure();

// Configure with custom base URL
RestAssuredConfig.configure("https://api.staging.openframe.ai");

// After configuration, use REST Assured normally
given()
    .when()
    .get("/health")
    .then()
    .statusCode(200);
```

This configuration class centralizes REST Assured setup for consistent API testing across the OpenFrame test suite, ensuring proper timeouts, SSL handling, and debug logging capabilities.
