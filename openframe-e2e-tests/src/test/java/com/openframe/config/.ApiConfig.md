Configuration class that manages API endpoint URLs for the OpenFrame platform, providing flexible base URL configuration through system properties and environment variables.

## Key Components

- **DEFAULT_BASE_URL**: Default localhost endpoint constant
- **GRAPHQL**: GraphQL API path constant
- **getBaseUrl()**: Static method that resolves base URL from multiple sources with fallback logic
- **Lazy initialization**: Base URL is resolved only once on first access

## Configuration Priority

The base URL is resolved in the following order:
1. System property: `api.base.url`
2. Environment variable: `API_BASE_URL`
3. Default fallback: `https://localhost/`

## Usage Example

```java
// Get the configured base URL
String apiBase = ApiConfig.getBaseUrl();

// Build GraphQL endpoint
String graphqlEndpoint = ApiConfig.getBaseUrl() + ApiConfig.GRAPHQL;
// Results in: "https://your-domain.com/api/graphql"

// Set base URL via system property
System.setProperty("api.base.url", "https://api.flamingo.run");

// Or via environment variable
// export API_BASE_URL=https://api.flamingo.run

// URL normalization ensures trailing slash
ApiConfig.getBaseUrl(); // Always ends with "/"
```

The class automatically normalizes URLs by ensuring they end with a trailing slash and provides debug logging for troubleshooting configuration issues.
