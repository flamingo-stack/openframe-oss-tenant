Comprehensive test suite for the OpenFrame logging API, validating log retrieval, filtering, searching, and details functionality across various tool types and severities.

## Key Components

- **LogsTest** - Main test class extending `AuthorizedTest` for authenticated log operations
- **testGetLogFilters()** - Validates retrieval of available filter options (tool types, event types, severities)
- **testListLogs()** - Tests basic log listing and validates required log event properties
- **testGetLogDetails()** - Verifies detailed log information retrieval for specific events
- **testSearchLogs()** - Tests log search functionality by tool type
- **testFilterLogs()** - Validates filtering logs by severity and tool type combinations

## Usage Example

```java
// Run all log tests
@Test
public void validateLoggingSystem() {
    // Get available filters
    LogFilters filters = getLogFilters();
    assertThat(filters.getToolTypes()).isNotEmpty();
    
    // List and validate logs
    List<LogEvent> logs = getLogs();
    assertThat(logs).allSatisfy(log -> {
        assertThat(log.getToolEventId()).isNotNull();
        assertThat(log.getEventType()).isNotEmpty();
    });
    
    // Filter by specific criteria
    List<LogEvent> filteredLogs = getLogs(
        severityAndToolFilter("ERROR", "MONITORING")
    );
    assertThat(filteredLogs).isNotEmpty();
}
```
