Integration test suite for device management operations in OpenFrame's MSP platform. Tests device filtering, search, retrieval, archiving, and deletion functionalities through API interactions.

## Key Components

- **DevicesTest**: Main test class extending `AuthorizedTest` for authenticated device operations
- **testGetDeviceFilters()**: Validates device filter metadata (statuses, OS types, organizations)
- **testGetDevice()**: Tests device retrieval by machine ID from online devices
- **testSearchDevices()**: Validates device search functionality by hostname
- **testFilterDevices()**: Tests filtering devices by status and operating system
- **testArchiveDevice()**: Tests device archival process for offline devices
- **testDeleteDevice()**: Tests permanent device deletion for offline devices

## Usage Example

```java
// Run device filter validation
@Test
public void testGetDeviceFilters() {
    DeviceFilters filters = getDeviceFilters();
    assertThat(filters.getStatuses()).isNotEmpty();
    assertThat(filters.getOsTypes()).isNotEmpty();
}

// Filter devices by specific criteria
@Test 
public void testFilterDevices() {
    List<Machine> devices = getDevices(
        statusAndOSDevicesFilter(DeviceStatus.ONLINE, "WINDOWS")
    );
    assertThat(devices).allSatisfy(device -> {
        assertThat(device.getStatus()).isEqualTo(DeviceStatus.ONLINE);
        assertThat(device.getOsType()).isEqualTo("WINDOWS");
    });
}

// Archive offline device
@Test
public void testArchiveDevice() {
    List<Machine> devices = getDevices(offlineDevicesFilter());
    archiveDevice(devices.getFirst());
    // Verify device no longer appears in active listings
}
```
