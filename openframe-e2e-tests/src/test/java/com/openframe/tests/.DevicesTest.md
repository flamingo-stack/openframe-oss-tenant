Comprehensive test suite for device management functionality in the OpenFrame MSP platform, validating device filtering, retrieval, search, archival, and deletion operations.

## Key Components

- **DevicesTest** - Main test class extending `AuthorizedTest` for authenticated device operations
- **testGetDeviceFilters()** - Validates device filter metadata including statuses, OS types, and organization IDs
- **testGetDevice()** - Tests device retrieval by machine ID using online devices
- **testSearchDevices()** - Verifies device search functionality by hostname
- **testFilterDevices()** - Tests device filtering by status and operating system
- **testArchiveDevice()** - Validates device archival functionality using offline devices
- **testDeleteDevice()** - Tests permanent device deletion for offline devices

## Usage Example

```java
// Run device filter validation
@Test
@DisplayName("Verify device filters")
public void testGetDeviceFilters() {
    DeviceFilters filters = getDeviceFilters();
    assertThat(filters).isNotNull();
    assertThat(filters.getStatuses()).isNotEmpty();
    assertThat(filters.getFilteredCount()).isNotZero();
}

// Test device search by hostname
@Test
@DisplayName("Search device by hostname")
public void testSearchDevices() {
    List<String> hostnames = getDeviceHostnames(listedDevicesFilter());
    Machine device = searchDevice(listedDevicesFilter(), hostnames.getFirst());
    assertThat(device.getHostname()).isEqualTo(hostnames.getFirst());
}

// Filter devices by specific criteria
@Test
public void testFilterDevices() {
    List<Machine> devices = getDevices(statusAndOSDevicesFilter(DeviceStatus.ONLINE, "WINDOWS"));
    assertThat(devices).allSatisfy(device -> {
        assertThat(device.getStatus()).isEqualTo(DeviceStatus.ONLINE);
        assertThat(device.getOsType()).isEqualTo("WINDOWS");
    });
}
```

**Note:** All tests are currently disabled pending device availability, using `@Disabled("Tests disabled - waiting for devices")` annotation.
