Test suite for device management functionality in the OpenFrame platform. This class contains comprehensive tests for device operations including filtering, searching, archiving, and deletion.

## Key Components

- **DevicesTest** - Main test class extending `AuthorizedTest` for authenticated API testing
- **testGetDeviceFilters()** - Validates device filter configuration and metadata
- **testGetDevice()** - Tests device retrieval by machine ID
- **testSearchDevices()** - Tests hostname-based device search functionality
- **testFilterDevices()** - Tests filtering devices by status and operating system
- **testArchiveDevice()** - Tests device archiving operation
- **testDeleteDevice()** - Tests device deletion operation

## Usage Example

```java
// Running device filter validation test
@Test
@DisplayName("Verify device filters")
public void testGetDeviceFilters() {
    DeviceFilters filters = getDeviceFilters();
    assertThat(filters).isNotNull();
    assertThat(filters.getStatuses()).isNotEmpty();
    assertThat(filters.getFilteredCount()).isNotZero();
}

// Testing device search by hostname
@Test
public void testSearchDevices() {
    List<String> hostnames = getDeviceHostnames(listedDevicesFilter());
    Machine device = searchDevice(listedDevicesFilter(), hostnames.getFirst());
    assertThat(device.getHostname()).isEqualTo(hostnames.getFirst());
}
```

**Note:** The entire test class is currently disabled (`@Disabled("Tests disabled - waiting for devices")`) pending device availability in the test environment.
