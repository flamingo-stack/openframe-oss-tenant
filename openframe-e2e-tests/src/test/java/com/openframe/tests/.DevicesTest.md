JUnit test suite that validates device management functionality within the OpenFrame MSP platform, including device filtering, searching, archiving, and deletion operations.

## Key Components

- **testGetDeviceFilters()** - Validates device filter metadata including statuses, OS types, and organization counts
- **testGetDevice()** - Tests device retrieval by machine ID using online devices
- **testSearchDevices()** - Verifies device search functionality by hostname
- **testFilterDevices()** - Tests filtering devices by status and operating system
- **testArchiveDevice()** - Validates device archiving for offline devices
- **testDeleteDevice()** - Tests device deletion functionality for offline devices

## Usage Example

```java
// Run specific device test
@Test
@DisplayName("Verify device filters work correctly")
public void testGetDeviceFilters() {
    DeviceFilters filters = getDeviceFilters();
    assertThat(filters).isNotNull();
    assertThat(filters.getStatuses()).isNotEmpty();
    assertThat(filters.getFilteredCount()).isNotZero();
}

// Search for device by hostname
@Test
public void testSearchDevices() {
    List<String> hostnames = getDeviceHostnames(listedDevicesFilter());
    Machine device = searchDevice(listedDevicesFilter(), hostnames.getFirst());
    assertThat(device.getHostname()).isEqualTo(hostnames.getFirst());
}
```

**Note:** This test class is currently disabled (`@Disabled`) and extends `AuthorizedTest` for authentication handling. Tests use static imports from `DeviceApi` and `DeviceGenerator` for API operations and test data generation.
