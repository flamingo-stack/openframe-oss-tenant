Comprehensive test class for validating script management operations in the OpenFrame MSP platform. Extends `AuthorizedTest` to test CRUD operations on scripts including listing, retrieving, adding, and editing script entities.

## Key Components

- **Test Methods**: 
  - `testListScripts()` - Validates script retrieval and basic properties
  - `testGetScript()` - Tests individual script fetching with body content
  - `testAddScript()` - Verifies script creation functionality  
  - `testEditScript()` - Tests script modification operations
- **Test Configuration**: Uses `@Disabled` annotation (tests currently disabled pending fixes)
- **Dependencies**: Integrates with `ScriptApi` for operations and `ScriptGenerator` for test data

## Usage Example

```java
// Example of how the test validates script listing
@Test
public void testListScripts() {
    List<Script> scripts = listScripts();
    assertThat(scripts).isNotEmpty();
    assertThat(scripts).allSatisfy(script -> {
        assertThat(script.getId()).isNotNull();
        assertThat(script.getName()).isNotEmpty();
        assertThat(script.getDescription()).isNotEmpty();
    });
}

// Example of script editing validation
@Test  
public void testEditScript() {
    Script script = scripts.getFirst();
    script.setDescription("Updated description");
    String response = editScript(script);
    assertThat(response).isEqualTo(editScriptResponse(script));
}
```

The test class follows JUnit 5 conventions with descriptive display names and uses AssertJ for fluent assertions. Currently disabled with `@Disabled("Tests disabled - waiting for fix")` annotation.
