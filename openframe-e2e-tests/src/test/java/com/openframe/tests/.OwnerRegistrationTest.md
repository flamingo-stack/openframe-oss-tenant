Test class for verifying the complete owner user registration and initialization flow in the OpenFrame MSP platform.

## Key Components

- **`testRegisterNewUser()`** - Tests new owner user registration with validation of response fields and data persistence
- **`testResetPassword()`** - Verifies password reset functionality using Redis-stored tokens and confirmation flow
- **`testLoginNewUser()`** - Tests user authentication and session establishment after registration
- **`testDefaultOrganizationCreated()`** - Validates that a default organization is automatically created for new owners

## Usage Example

```java
// This test class runs first due to @Tag("start") annotation
// Tests are executed in order to simulate complete registration flow

// 1. Register new owner user
UserRegistrationRequest request = newUserRegistrationRequest();
UserRegistrationResponse response = registerUser(request);
// Validates response contains required fields (id, ownerId, timestamps)

// 2. Test password reset capability
resetPassword(user);
String token = getResetToken(user.getEmail());
ResetConfirmRequest confirmRequest = resetConfirmRequest(token);
confirmReset(confirmRequest);

// 3. Login with new credentials
setCookies(login(getUser()));
MeResponse me = me();
// Verifies authentication status

// 4. Verify default organization exists
List<String> orgNames = getOrganizationNames();
// Should contain exactly one organization named "Default"
```

The test extends `UnauthorizedTest` and uses ordered execution to ensure proper registration workflow testing, validating user creation, authentication, and default organization setup for OpenFrame's MSP platform.
