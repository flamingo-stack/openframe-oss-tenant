API client for interacting with the OpenFrame logging system through GraphQL endpoints. Provides methods to retrieve, filter, and search log events and their detailed information.

## Key Components

- **`getLogFilters()`** - Retrieves available log filter options
- **`getLogs()`** - Fetches all log events (overloaded with filter support)
- **`getLogs(LogFilterInput filter)`** - Retrieves filtered log events
- **`searchLogs(String search)`** - Searches log events by text query
- **`getLogDetails(LogEvent logEvent)`** - Gets detailed information for a specific log event

## Usage Example

```java
// Get available log filters
LogFilters filters = LogsApi.getLogFilters();

// Retrieve all logs
List<LogEvent> allLogs = LogsApi.getLogs();

// Filter logs by specific criteria
LogFilterInput filter = new LogFilterInput();
// Configure filter parameters...
List<LogEvent> filteredLogs = LogsApi.getLogs(filter);

// Search logs by text
List<LogEvent> searchResults = LogsApi.searchLogs("error");

// Get detailed information for a specific log event
LogEvent logEvent = allLogs.get(0);
LogDetails details = LogsApi.getLogDetails(logEvent);
```

The API uses GraphQL queries defined in `LogQueries` and requires authorized requests through `RequestSpecHelper`. All methods return structured DTOs for type-safe log data handling within the OpenFrame platform.
