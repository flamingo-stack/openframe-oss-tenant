API client for device management operations in the OpenFrame platform. Provides methods for querying, filtering, updating, and managing device lifecycle through GraphQL and REST endpoints.

## Key Components

**Static Methods:**
- `getDeviceHostnames()` - Retrieves device hostnames using filters
- `getDeviceIds()` - Fetches device IDs based on filter criteria
- `getDevice()` - Gets complete device information by machine ID
- `getDevices()` - Returns filtered list of devices
- `updateDeviceStatus()` - Updates device status via REST API
- `archiveDevice()` - Sets device status to archived
- `deleteDevice()` - Sets device status to deleted
- `searchDevice()` - Searches for devices with text query
- `getDeviceFilters()` - Retrieves available device filter options

**Constants:**
- `GRAPHQL` - GraphQL endpoint path
- `DEVICES` - REST API endpoint for device operations

## Usage Example

```java
// Get all device hostnames with a filter
DeviceFilterInput filter = new DeviceFilterInput();
List<String> hostnames = DeviceApi.getDeviceHostnames(filter);

// Retrieve a specific device
Machine device = DeviceApi.getDevice("machine-123");

// Search for devices
Machine foundDevice = DeviceApi.searchDevice(filter, "server01");

// Archive a device
DeviceApi.archiveDevice(device);

// Get available filters for the UI
DeviceFilters availableFilters = DeviceApi.getDeviceFilters();

// Update device status directly
DeviceApi.updateDeviceStatus(device, DeviceStatus.OFFLINE);
```

The API handles authentication automatically through `RequestSpecHelper.getAuthorizedSpec()` and uses both GraphQL queries for data retrieval and REST endpoints for state modifications.
