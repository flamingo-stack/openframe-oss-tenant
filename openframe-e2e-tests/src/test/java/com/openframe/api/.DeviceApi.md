A REST/GraphQL API client for managing devices in the OpenFrame platform, providing methods to query, filter, search, and update device information with authorized access.

## Key Components

- **getDeviceHostnames()** - Retrieves filtered list of device hostnames
- **getDeviceIds()** - Fetches device machine IDs based on filters
- **getDevice()** - Gets full device details by machine ID
- **getDevices()** - Returns filtered list of complete device objects
- **updateDeviceStatus()** - Updates device status via PATCH request
- **archiveDevice() / deleteDevice()** - Convenience methods for status updates
- **searchDevice()** - Searches for devices matching filter and search criteria
- **getDeviceFilters()** - Retrieves available device filter options

## Usage Example

```java
// Get all active devices
DeviceFilterInput filter = new DeviceFilterInput();
List<Machine> devices = DeviceApi.getDevices(filter);

// Get specific device details
Machine device = DeviceApi.getDevice("machine-123");

// Archive a device
DeviceApi.archiveDevice(device);

// Search for devices by hostname
Machine foundDevice = DeviceApi.searchDevice(filter, "web-server-01");

// Get available filter options
DeviceFilters availableFilters = DeviceApi.getDeviceFilters();

// Get just the hostnames for display
List<String> hostnames = DeviceApi.getDeviceHostnames(filter);
```

The API uses GraphQL queries for data retrieval and REST endpoints for device updates, with all requests automatically authorized through the RequestSpecHelper utility.
