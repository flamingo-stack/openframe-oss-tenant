API wrapper for OpenFrame device management operations, providing methods to query, filter, and manage devices through GraphQL and REST endpoints.

## Key Components

### Static Methods
- **`getDeviceHostnames(DeviceFilterInput)`** - Retrieves device hostnames using GraphQL filtering
- **`getDeviceIds(DeviceFilterInput)`** - Returns device machine IDs based on filter criteria
- **`getDevice(String)`** - Fetches complete device details by machine ID
- **`getDevices(DeviceFilterInput)`** - Returns filtered list of devices
- **`updateDeviceStatus(Machine, DeviceStatus)`** - Updates device status via REST API
- **`archiveDevice(Machine)`** - Convenience method to archive a device
- **`deleteDevice(Machine)`** - Convenience method to mark device as deleted
- **`searchDevice(DeviceFilterInput, String)`** - Searches for specific device with text query
- **`getDeviceFilters()`** - Retrieves available device filter options

### Dependencies
- Uses RestAssured for HTTP requests
- Integrates with GraphQL queries from `DeviceQueries` class
- Requires authorized request specification for authentication

## Usage Example

```java
// Get all devices for a specific filter
DeviceFilterInput filter = new DeviceFilterInput();
List<Machine> devices = DeviceApi.getDevices(filter);

// Get specific device details
Machine device = DeviceApi.getDevice("machine-123");

// Archive a device
DeviceApi.archiveDevice(device);

// Search for devices
Machine foundDevice = DeviceApi.searchDevice(filter, "hostname-pattern");

// Get available filter options
DeviceFilters filters = DeviceApi.getDeviceFilters();
```
