API client for managing device operations in the OpenFrame platform. Provides methods to query, filter, and manage device status through both GraphQL and REST endpoints.

## Key Components

- **Device Retrieval**: `getDevice()`, `getDevices()` - Fetch individual devices or collections with filtering
- **Device Querying**: `getDeviceHostnames()`, `getDeviceIds()` - Extract specific device properties
- **Device Search**: `searchDevice()` - Find devices using text search with filters
- **Status Management**: `updateDeviceStatus()`, `archiveDevice()`, `deleteDevice()` - Modify device lifecycle status
- **Filter Operations**: `getDeviceFilters()` - Retrieve available filter options

## Usage Example

```java
// Get all devices with a specific filter
DeviceFilterInput filter = new DeviceFilterInput();
List<Machine> devices = DeviceApi.getDevices(filter);

// Retrieve a specific device by ID
Machine device = DeviceApi.getDevice("machine-123");

// Archive a device (change status to ARCHIVED)
DeviceApi.archiveDevice(device);

// Search for devices matching criteria
Machine foundDevice = DeviceApi.searchDevice(filter, "server-name");

// Get available filter options
DeviceFilters availableFilters = DeviceApi.getDeviceFilters();

// Extract just hostnames from filtered devices
List<String> hostnames = DeviceApi.getDeviceHostnames(filter);
```
