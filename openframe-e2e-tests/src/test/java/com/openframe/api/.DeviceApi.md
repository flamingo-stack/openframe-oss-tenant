API wrapper class that provides static methods for device management operations through GraphQL and REST endpoints in the OpenFrame MSP platform.

## Key Components

- **Device Retrieval Methods**: `getDevice()`, `getDevices()`, `getDeviceHostnames()`, `getDeviceIds()` - fetch device information with optional filtering
- **Device Search**: `searchDevice()` - find devices using search criteria and filters
- **Device Status Management**: `updateDeviceStatus()`, `archiveDevice()`, `deleteDevice()` - modify device lifecycle states
- **Filter Support**: `getDeviceFilters()` - retrieve available filter options for device queries
- **GraphQL Integration**: Uses predefined queries from `DeviceQueries` class for consistent API communication
- **REST Endpoints**: Direct PATCH operations for device status updates

## Usage Example

```java
// Get all devices with a filter
DeviceFilterInput filter = new DeviceFilterInput();
List<Machine> devices = DeviceApi.getDevices(filter);

// Find a specific device
Machine device = DeviceApi.getDevice("machine-123");

// Search for devices by hostname
Machine foundDevice = DeviceApi.searchDevice(filter, "web-server");

// Archive a device
DeviceApi.archiveDevice(device);

// Get available filter options
DeviceFilters filters = DeviceApi.getDeviceFilters();

// Get just device hostnames for lightweight operations
List<String> hostnames = DeviceApi.getDeviceHostnames(filter);
```

The class uses RestAssured for HTTP operations and automatically handles authorization through `RequestSpecHelper.getAuthorizedSpec()`.
