API client for managing device operations through GraphQL and REST endpoints in the OpenFrame platform. Provides methods for querying, filtering, updating, and managing device lifecycle operations.

## Key Components

- **Device Querying**: `getDeviceHostnames()`, `getDeviceIds()`, `getDevice()`, `getDevices()` - Retrieve device information with filtering support
- **Device Search**: `searchDevice()` - Find devices using search criteria and filters
- **Status Management**: `updateDeviceStatus()`, `archiveDevice()`, `deleteDevice()` - Manage device lifecycle states
- **Filter Operations**: `getDeviceFilters()` - Retrieve available filtering options
- **GraphQL Integration**: All query operations use GraphQL endpoint with predefined queries
- **REST Operations**: Device status updates use REST PATCH endpoint

## Usage Example

```java
// Get all device hostnames with filter
DeviceFilterInput filter = new DeviceFilterInput();
List<String> hostnames = DeviceApi.getDeviceHostnames(filter);

// Retrieve specific device details
Machine device = DeviceApi.getDevice("machine-123");

// Update device status
DeviceApi.updateDeviceStatus(device, DeviceStatus.ACTIVE);

// Archive a device (convenience method)
DeviceApi.archiveDevice(device);

// Search for devices
Machine foundDevice = DeviceApi.searchDevice(filter, "hostname-search");

// Get available filter options
DeviceFilters availableFilters = DeviceApi.getDeviceFilters();
```
