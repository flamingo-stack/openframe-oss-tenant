A utility class containing GraphQL query constants for device management operations in the OpenFrame API, providing standardized queries for retrieving device information, metadata, and filtering capabilities.

## Key Components

- **DEVICE_IDS** - Query for retrieving just machine IDs with optional filtering
- **DEVICE_HOSTNAMES** - Query for fetching device hostnames with filtering support
- **FULL_DEVICE** - Comprehensive query for complete device details including tags, tool connections, and installed agents
- **DEVICES_WITH_FILTER** - Query for device lists with filtering and pagination support
- **SEARCH_DEVICE** - Query combining filtering and text search capabilities
- **DEVICE_FILTERS** - Query for retrieving available filter options and counts

## Usage Example

```java
import com.openframe.api.graphql.DeviceQueries;

// Using the full device query to get complete device information
String query = DeviceQueries.FULL_DEVICE;
Map<String, Object> variables = Map.of("machineId", "device-123");

// Using filtered device query with search
String searchQuery = DeviceQueries.SEARCH_DEVICE;
Map<String, Object> searchVars = Map.of(
    "filter", Map.of("status", "ONLINE"),
    "search", "production-server"
);

// Getting available filter options
String filtersQuery = DeviceQueries.DEVICE_FILTERS;
```

These queries support the OpenFrame platform's device management functionality, enabling efficient retrieval of device data with various levels of detail and filtering options for MSP operations.
