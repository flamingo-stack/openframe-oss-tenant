A utility class containing predefined GraphQL query strings for device-related operations in the OpenFrame API system.

## Key Components

- **DEVICE_IDS** - Query to retrieve machine IDs for devices matching a filter
- **DEVICE_HOSTNAMES** - Query to fetch hostnames for filtered devices
- **FULL_DEVICE** - Comprehensive query to get complete device details by machine ID, including tags, tool connections, and installed agents
- **DEVICES_WITH_FILTER** - Query to retrieve filtered device list with basic information and count
- **SEARCH_DEVICE** - Query combining filtering and text search for devices
- **DEVICE_FILTERS** - Query to get available filter options with counts for device management interfaces

## Usage Example

```java
// Execute a device search query
GraphQLQuery query = new GraphQLQuery(DeviceQueries.SEARCH_DEVICE);
query.setVariable("filter", filterInput);
query.setVariable("search", "web-server");
GraphQLResponse response = graphqlClient.execute(query);

// Get full device details
GraphQLQuery deviceQuery = new GraphQLQuery(DeviceQueries.FULL_DEVICE);
deviceQuery.setVariable("machineId", "machine-123");
Device device = graphqlClient.execute(deviceQuery).getData("device");

// Retrieve available filter options
GraphQLQuery filtersQuery = new GraphQLQuery(DeviceQueries.DEVICE_FILTERS);
DeviceFilters filters = graphqlClient.execute(filtersQuery).getData("deviceFilters");
```

These queries support the OpenFrame platform's device management capabilities, enabling efficient retrieval of device information, filtering, and search functionality across MSP environments.
