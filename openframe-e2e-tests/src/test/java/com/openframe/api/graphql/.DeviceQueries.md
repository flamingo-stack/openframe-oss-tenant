This utility class provides static GraphQL query definitions for device-related operations in the OpenFrame API, including device retrieval, filtering, and search functionality.

## Key Components

- **DEVICE_IDS** - Retrieves machine IDs for filtered devices
- **DEVICE_HOSTNAMES** - Fetches hostnames for filtered devices  
- **FULL_DEVICE** - Comprehensive device query including tags, tool connections, and installed agents
- **DEVICES_WITH_FILTER** - Returns filtered device list with basic information and count
- **SEARCH_DEVICE** - Combines filtering with text search capabilities
- **DEVICE_FILTERS** - Retrieves available filter options and their counts

## Usage Example

```java
// Query for all device IDs with a specific filter
Map<String, Object> variables = Map.of(
    "filter", Map.of(
        "status", "ONLINE",
        "organizationId", "org-123"
    )
);

GraphQLRequest request = new GraphQLRequest(
    DeviceQueries.DEVICE_IDS,
    variables
);

// Search for devices by hostname
Map<String, Object> searchVars = Map.of(
    "filter", Map.of("osType", "WINDOWS"),
    "search", "server"
);

GraphQLRequest searchRequest = new GraphQLRequest(
    DeviceQueries.SEARCH_DEVICE,
    searchVars
);

// Get complete device information
GraphQLRequest fullDeviceRequest = new GraphQLRequest(
    DeviceQueries.FULL_DEVICE,
    Map.of("machineId", "device-456")
);
```
