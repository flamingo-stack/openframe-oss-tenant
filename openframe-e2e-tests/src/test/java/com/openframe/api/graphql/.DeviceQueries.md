A collection of GraphQL query constants for device-related operations in the OpenFrame API, providing pre-defined queries for retrieving device information with various levels of detail and filtering options.

## Key Components

- **DEVICE_IDS** - Retrieves only machine IDs for filtered devices
- **DEVICE_HOSTNAMES** - Fetches hostnames for filtered devices
- **FULL_DEVICE** - Complete device information including tags, tool connections, and installed agents
- **DEVICES_WITH_FILTER** - Paginated device list with essential fields and filtered count
- **SEARCH_DEVICE** - Device search functionality with text search parameter
- **DEVICE_FILTERS** - Available filter options with counts for each category

## Usage Example

```java
// Query for specific device details
String query = DeviceQueries.FULL_DEVICE;
Map<String, Object> variables = Map.of("machineId", "device-123");

// Search devices by hostname
String searchQuery = DeviceQueries.SEARCH_DEVICE;
Map<String, Object> searchVars = Map.of(
    "search", "server",
    "filter", Map.of("status", "ONLINE")
);

// Get filtered device list with pagination
String listQuery = DeviceQueries.DEVICES_WITH_FILTER;
Map<String, Object> filterVars = Map.of(
    "filter", Map.of(
        "osType", "WINDOWS",
        "organizationId", "org-456"
    )
);
```
