A utility class containing predefined GraphQL query strings for device-related operations in the OpenFrame API.

## Key Components

- **DEVICE_IDS** - Query to retrieve machine IDs from devices with optional filtering
- **DEVICE_HOSTNAMES** - Query to fetch hostnames from devices with filtering support
- **FULL_DEVICE** - Comprehensive query to get complete device information by machine ID, including tags, tool connections, and installed agents
- **DEVICES_WITH_FILTER** - Query to retrieve filtered device list with essential metadata and count information
- **SEARCH_DEVICE** - Query to search devices by text with filtering capabilities
- **DEVICE_FILTERS** - Query to retrieve available filter options and counts for device queries

## Usage Example

```java
// Execute a query to get device IDs
String query = DeviceQueries.DEVICE_IDS;
Map<String, Object> variables = Map.of(
    "filter", Map.of(
        "status", "ONLINE",
        "organizationId", "org-123"
    )
);
GraphQLResponse response = graphQLClient.execute(query, variables);

// Get full device details
String deviceQuery = DeviceQueries.FULL_DEVICE;
Map<String, Object> deviceVars = Map.of("machineId", "machine-456");
GraphQLResponse deviceResponse = graphQLClient.execute(deviceQuery, deviceVars);

// Search devices with text query
String searchQuery = DeviceQueries.SEARCH_DEVICE;
Map<String, Object> searchVars = Map.of(
    "search", "laptop",
    "filter", Map.of("osType", "WINDOWS")
);
```
