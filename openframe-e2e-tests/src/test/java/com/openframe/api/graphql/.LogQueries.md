Contains predefined GraphQL query strings for accessing log data in the OpenFrame API. This class serves as a centralized repository for log-related queries used throughout the application.

## Key Components

- **LOG_FILTERS** - Query to retrieve available filter options including tool types, event types, severities, and organizations
- **LOGS** - Paginated query to fetch log entries with filtering and search capabilities, returning edges with cursor-based pagination
- **LOG_DETAILS** - Query to retrieve detailed information for a specific log entry using composite identifiers

## Usage Example

```java
// Using the log queries with GraphQL client
String query = LogQueries.LOGS;
Map<String, Object> variables = new HashMap<>();
variables.put("filter", logFilterInput);
variables.put("search", "error");

GraphQLResponse response = graphqlClient.execute(query, variables);

// Accessing log details
String detailsQuery = LogQueries.LOG_DETAILS;
Map<String, Object> detailsVars = new HashMap<>();
detailsVars.put("ingestDay", "2024-01-15");
detailsVars.put("toolType", "monitoring");
detailsVars.put("eventType", "alert");
detailsVars.put("timestamp", Instant.now());
detailsVars.put("toolEventId", "evt_123");

GraphQLResponse detailsResponse = graphqlClient.execute(detailsQuery, detailsVars);
```

The queries support comprehensive log management including filtering by organization, tool type, severity levels, and full-text search capabilities with cursor-based pagination for efficient data retrieval.
