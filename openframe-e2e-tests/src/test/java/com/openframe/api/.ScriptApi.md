A REST API client for managing scripts in the OpenFrame Tactical RMM integration, providing CRUD operations for script resources through authenticated HTTP requests.

## Key Components

- **`listScripts()`** - Retrieves all available scripts as a list
- **`getScript(Integer id)`** - Fetches a specific script by its ID
- **`editScript(Script script)`** - Updates an existing script using PUT request
- **`addScript(Script script)`** - Creates a new script using POST request
- **Constants** - `SCRIPTS` and `SCRIPT` endpoint paths for the tactical-rmm API

## Usage Example

```java
// List all scripts
List<Script> allScripts = ScriptApi.listScripts();

// Get a specific script
Script script = ScriptApi.getScript(123);

// Create a new script
Script newScript = new Script();
newScript.setName("Backup Script");
newScript.setContent("#!/bin/bash\necho 'Backup started'");
String createResponse = ScriptApi.addScript(newScript);

// Update existing script
script.setContent("#!/bin/bash\necho 'Updated backup script'");
String updateResponse = ScriptApi.editScript(script);
```

The API uses RestAssured for HTTP client functionality with automatic authorization handling through `getAuthorizedSpec()`, targeting the Tactical RMM scripts endpoint at `tools/tactical-rmm/scripts/`. All methods expect 200 status codes and return either parsed Script objects or raw response strings for modification operations.
