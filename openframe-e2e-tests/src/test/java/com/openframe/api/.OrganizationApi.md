A REST API client for organization management operations in the OpenFrame platform, providing methods for CRUD operations through both GraphQL and REST endpoints.

## Key Components

**Static Methods:**
- `getOrganizationNames()` - Fetches all organization names via GraphQL
- `getOrganizationIds()` - Retrieves all organization IDs via GraphQL  
- `retrieveOrganization(String id)` - Gets complete organization details by ID
- `createOrganization(CreateOrganizationRequest)` - Creates new organization via REST
- `updateOrganization(String, CreateOrganizationRequest)` - Updates existing organization
- `deleteOrganization(Organization)` - Removes organization by ID

**Dependencies:**
- Uses RestAssured for HTTP requests with authorized specifications
- Integrates GraphQL queries from `OrganizationQueries` class
- Handles JSON serialization/deserialization for Organization DTOs

## Usage Example

```java
// Get all organization names
List<String> orgNames = OrganizationApi.getOrganizationNames();

// Create a new organization
CreateOrganizationRequest request = new CreateOrganizationRequest();
request.setName("Acme Corp");
request.setDescription("Technology company");
Organization newOrg = OrganizationApi.createOrganization(request);

// Retrieve full organization details
Organization fullOrg = OrganizationApi.retrieveOrganization(newOrg.getId());

// Update organization
request.setDescription("Updated description");
Organization updatedOrg = OrganizationApi.updateOrganization(newOrg.getId(), request);

// Delete organization
OrganizationApi.deleteOrganization(updatedOrg);
```
