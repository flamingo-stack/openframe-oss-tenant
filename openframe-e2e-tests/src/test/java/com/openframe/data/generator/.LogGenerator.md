A utility class for generating log filter configurations in the OpenFrame data layer, providing convenient methods to create LogFilterInput objects with predefined filter combinations.

## Key Components

- **`severityAndToolFilter(String severity, String toolType)`** - Static method that creates a LogFilterInput with both severity and tool type filters applied

## Usage Example

```java
// Create a filter for error logs from monitoring tools
LogFilterInput errorFilter = LogGenerator.severityAndToolFilter("ERROR", "MONITORING");

// Create a filter for warning logs from backup tools  
LogFilterInput warningFilter = LogGenerator.severityAndToolFilter("WARNING", "BACKUP");

// Create a filter for info logs from security tools
LogFilterInput infoFilter = LogGenerator.severityAndToolFilter("INFO", "SECURITY");
```

The LogGenerator simplifies the creation of common log filter combinations by providing a builder pattern wrapper. This is particularly useful for MSP operations where filtering logs by both severity level and tool type is a frequent requirement for troubleshooting and monitoring workflows.
