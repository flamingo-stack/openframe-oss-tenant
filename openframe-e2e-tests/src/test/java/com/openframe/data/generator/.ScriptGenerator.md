A utility class that generates mock Script objects and response messages for testing and development purposes in the OpenFrame MSP platform.

## Key Components

- **`addScriptRequest()`** - Creates a sample PowerShell script object with predefined configuration for listing directory contents
- **`addScriptResponse(Script)`** - Generates a formatted success message when a script is added
- **`editScriptResponse(Script)`** - Generates a formatted success message when a script is edited

## Usage Example

```java
// Generate a sample script for testing
Script sampleScript = ScriptGenerator.addScriptRequest();

// Create response messages
String addMessage = ScriptGenerator.addScriptResponse(sampleScript);
// Returns: "Dir was added!"

String editMessage = ScriptGenerator.editScriptResponse(sampleScript);
// Returns: "Dir was edited!"

// The generated script includes:
// - Name: "Dir"
// - PowerShell command: "dir"
// - Windows platform support
// - 90-second timeout
// - Custom category classification
```

This generator is particularly useful for creating consistent test data and mock responses in unit tests, API demonstrations, and development environments where sample script configurations are needed.
