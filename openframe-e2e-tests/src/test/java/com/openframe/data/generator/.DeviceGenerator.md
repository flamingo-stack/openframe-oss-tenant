A utility class that provides factory methods for creating pre-configured `DeviceFilterInput` objects to filter devices by various criteria such as status, operating system, and combinations thereof.

## Key Components

- **onlineDevicesFilter()** - Creates filter for devices with ONLINE status
- **offlineDevicesFilter()** - Creates filter for devices with OFFLINE status  
- **statusAndOSDevicesFilter()** - Creates filter combining specific device status and OS type
- **listedDevicesFilter()** - Creates filter for all standard device statuses
- **filterDevicesByStatus()** - Creates filter for multiple specified device statuses

## Usage Example

```java
// Filter for online devices only
DeviceFilterInput onlineFilter = DeviceGenerator.onlineDevicesFilter();

// Filter for offline devices only
DeviceFilterInput offlineFilter = DeviceGenerator.offlineDevicesFilter();

// Filter for active Windows devices
DeviceFilterInput windowsActiveFilter = DeviceGenerator.statusAndOSDevicesFilter(
    DeviceStatus.ACTIVE, 
    "Windows"
);

// Filter for devices with specific statuses
DeviceFilterInput customFilter = DeviceGenerator.filterDevicesByStatus(
    DeviceStatus.ONLINE,
    DeviceStatus.ACTIVE,
    DeviceStatus.MAINTENANCE
);

// Filter for all standard device statuses
DeviceFilterInput allListedFilter = DeviceGenerator.listedDevicesFilter();
```

This generator simplifies the creation of common device filters used throughout the OpenFrame platform, providing a centralized way to build consistent filter criteria for device queries.
