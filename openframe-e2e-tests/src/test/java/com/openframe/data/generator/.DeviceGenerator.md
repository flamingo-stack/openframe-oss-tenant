A utility class that provides pre-configured device filter builders for common device querying scenarios in the OpenFrame platform.

## Key Components

- **`onlineDevicesFilter()`** - Creates a filter for devices with ONLINE status
- **`offlineDevicesFilter()`** - Creates a filter for devices with OFFLINE status  
- **`statusAndOSDevicesFilter(DeviceStatus, String)`** - Creates a filter combining device status and operating system type
- **`listedDevicesFilter()`** - Creates a filter for all standard device statuses (excludes edge cases)
- **`filterDevicesByStatus(DeviceStatus...)`** - Creates a flexible filter accepting multiple device statuses

## Usage Example

```java
// Filter for online devices only
DeviceFilterInput onlineFilter = DeviceGenerator.onlineDevicesFilter();

// Filter for offline Windows devices
DeviceFilterInput windowsOfflineFilter = DeviceGenerator.statusAndOSDevicesFilter(
    DeviceStatus.OFFLINE, "Windows"
);

// Filter for devices in maintenance or decommissioned status
DeviceFilterInput maintenanceFilter = DeviceGenerator.filterDevicesByStatus(
    DeviceStatus.MAINTENANCE, 
    DeviceStatus.DECOMMISSIONED
);

// Filter for all standard listed devices
DeviceFilterInput allListedFilter = DeviceGenerator.listedDevicesFilter();
```

This generator simplifies device filtering operations by providing commonly-used filter configurations, reducing boilerplate code when querying devices by status, operating system, or combinations thereof.
