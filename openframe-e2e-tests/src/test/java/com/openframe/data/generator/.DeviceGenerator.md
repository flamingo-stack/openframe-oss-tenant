A utility class that provides pre-configured device filter builders for common device querying scenarios in the OpenFrame platform. This generator simplifies the creation of DeviceFilterInput objects with commonly used filter combinations.

## Key Components

- **onlineDevicesFilter()** - Creates a filter for devices with ONLINE status
- **offlineDevicesFilter()** - Creates a filter for devices with OFFLINE status  
- **statusAndOSDevicesFilter()** - Creates a filter combining device status and operating system type
- **listedDevicesFilter()** - Creates a comprehensive filter including all standard device statuses
- **filterDevicesByStatus()** - Creates a filter for multiple device statuses using varargs

## Usage Example

```java
// Filter for online devices only
DeviceFilterInput onlineFilter = DeviceGenerator.onlineDevicesFilter();

// Filter for offline Windows devices
DeviceFilterInput windowsOfflineFilter = DeviceGenerator.statusAndOSDevicesFilter(
    DeviceStatus.OFFLINE, 
    "Windows"
);

// Filter for multiple specific statuses
DeviceFilterInput multiStatusFilter = DeviceGenerator.filterDevicesByStatus(
    DeviceStatus.ONLINE,
    DeviceStatus.MAINTENANCE,
    DeviceStatus.ACTIVE
);

// Get all listed devices (excludes unlisted/unknown statuses)
DeviceFilterInput allListedFilter = DeviceGenerator.listedDevicesFilter();
```

This class eliminates repetitive filter construction code and provides a centralized location for common device filtering patterns used throughout the OpenFrame MSP platform.
