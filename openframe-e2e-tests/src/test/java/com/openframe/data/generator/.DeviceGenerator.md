A utility class that provides factory methods for creating common `DeviceFilterInput` objects used to filter devices by status, operating system, and other criteria in the OpenFrame platform.

## Key Components

**Static Factory Methods:**
- `onlineDevicesFilter()` - Creates filter for devices with ONLINE status
- `offlineDevicesFilter()` - Creates filter for devices with OFFLINE status
- `statusAndOSDevicesFilter(DeviceStatus, String)` - Creates filter combining device status and OS type
- `listedDevicesFilter()` - Creates filter for all standard device statuses
- `filterDevicesByStatus(DeviceStatus...)` - Creates filter for multiple specified statuses

**Dependencies:**
- `DeviceFilterInput` - DTO for device filtering criteria
- `DeviceStatus` - Enum representing device status values

## Usage Example

```java
// Filter for online devices only
DeviceFilterInput onlineFilter = DeviceGenerator.onlineDevicesFilter();

// Filter for Windows devices that are offline
DeviceFilterInput windowsOfflineFilter = DeviceGenerator.statusAndOSDevicesFilter(
    DeviceStatus.OFFLINE, "Windows"
);

// Filter for devices in maintenance or decommissioned status
DeviceFilterInput maintenanceFilter = DeviceGenerator.filterDevicesByStatus(
    DeviceStatus.MAINTENANCE, 
    DeviceStatus.DECOMMISSIONED
);

// Filter for all listed devices (excludes unlisted statuses)
DeviceFilterInput allListedFilter = DeviceGenerator.listedDevicesFilter();
```

This generator simplifies the creation of commonly used device filters throughout the OpenFrame application, promoting code reuse and consistency in device querying operations.
