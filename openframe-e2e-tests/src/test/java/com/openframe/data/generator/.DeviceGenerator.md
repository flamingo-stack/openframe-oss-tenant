A utility class that provides convenient factory methods for creating pre-configured device filter objects used in device queries and filtering operations.

## Key Components

- **onlineDevicesFilter()** - Creates filter for devices with ONLINE status
- **offlineDevicesFilter()** - Creates filter for devices with OFFLINE status  
- **statusAndOSDevicesFilter()** - Creates filter combining device status and operating system type
- **listedDevicesFilter()** - Creates filter for all standard device statuses (excluding edge cases)
- **filterDevicesByStatus()** - Creates filter for multiple specified device statuses using varargs

## Usage Example

```java
// Filter for online devices only
DeviceFilterInput onlineFilter = DeviceGenerator.onlineDevicesFilter();

// Filter for offline devices only  
DeviceFilterInput offlineFilter = DeviceGenerator.offlineDevicesFilter();

// Filter for active Windows devices
DeviceFilterInput windowsActiveFilter = DeviceGenerator.statusAndOSDevicesFilter(
    DeviceStatus.ACTIVE, "Windows"
);

// Filter for devices in maintenance or decommissioned status
DeviceFilterInput multiStatusFilter = DeviceGenerator.filterDevicesByStatus(
    DeviceStatus.MAINTENANCE, 
    DeviceStatus.DECOMMISSIONED
);

// Filter for all standard listed devices
DeviceFilterInput allListedFilter = DeviceGenerator.listedDevicesFilter();
```

The class simplifies device filtering by providing readable, reusable filter configurations that can be passed to device query services or repositories.
