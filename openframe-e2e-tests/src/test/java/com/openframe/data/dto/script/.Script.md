A data transfer object (DTO) representing a script configuration in the OpenFrame platform, containing script metadata, execution parameters, and platform compatibility settings.

## Key Components

- **Script Identification**: `id`, `name`, `description`, `category`
- **Execution Configuration**: `shell`, `args`, `scriptBody`, `defaultTimeout`
- **Platform Support**: `supportedPlatforms`, `runAsUser`, `envVars`
- **Metadata Fields**: `scriptType`, `scriptHash`, `syntax`, `filename`
- **User Preferences**: `favorite`, `hidden`

## Usage Example

```java
Script script = Script.builder()
    .name("System Health Check")
    .description("Monitors system resources and performance")
    .shell("bash")
    .args(List.of("-v", "--detailed"))
    .category("monitoring")
    .scriptType("system")
    .scriptBody("#!/bin/bash\necho 'Checking system health...'")
    .defaultTimeout(300)
    .supportedPlatforms(List.of("linux", "darwin"))
    .runAsUser(false)
    .envVars(List.of("PATH=/usr/bin", "LOG_LEVEL=INFO"))
    .favorite(true)
    .hidden(false)
    .build();

// Access script properties
String shellCommand = script.getShell(); // "bash"
List<String> platforms = script.getSupportedPlatforms(); // ["linux", "darwin"]
```

The class uses Lombok annotations for automatic getter/setter generation and Jackson annotations for JSON serialization with snake_case field mapping.
