A data transfer object that encapsulates filtering criteria for log queries, supporting multi-dimensional filtering across tool types, event categories, severity levels, and organizational boundaries.

## Key Components

- **toolTypes** - List of tool/application identifiers to filter logs by source system
- **eventTypes** - List of event categories to filter by log event classification  
- **severities** - List of severity levels (e.g., INFO, WARN, ERROR) for log filtering
- **organizations** - List of `OrganizationFilterOption` objects for multi-tenant log access control

## Usage Example

```java
// Create comprehensive log filters for dashboard queries
LogFilters filters = LogFilters.builder()
    .toolTypes(List.of("mingo-ai", "openframe-core", "fae-client"))
    .eventTypes(List.of("user-login", "system-error", "api-request"))
    .severities(List.of("ERROR", "WARN"))
    .organizations(List.of(
        OrganizationFilterOption.builder()
            .id("org-123")
            .name("Acme Corp")
            .build()
    ))
    .build();

// Use in log service query
LogQueryRequest request = LogQueryRequest.builder()
    .filters(filters)
    .dateRange(DateRange.LAST_24_HOURS)
    .build();
```

The class uses Lombok annotations for automatic generation of constructors, getters, setters, and builder pattern implementation, making it ideal for REST API request bodies and service layer filtering operations.
