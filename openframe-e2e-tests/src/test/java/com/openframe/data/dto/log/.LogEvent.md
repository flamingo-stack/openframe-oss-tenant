A data transfer object (DTO) representing a structured log event within the OpenFrame AI-powered MSP platform, designed to capture and transport log information across system components.

## Key Components

- **LogEvent class**: Main DTO with Lombok annotations for automatic getter/setter generation
- **Core identifiers**: `toolEventId`, `userId`, `deviceId`, `organizationId` for tracking and correlation
- **Event metadata**: `eventType`, `toolType`, `severity`, `timestamp` for categorization and filtering
- **Contextual data**: `hostname`, `organizationName`, `summary`, `ingestDay` for enriched log information

## Usage Example

```java
// Creating a new log event
LogEvent logEvent = LogEvent.builder()
    .toolEventId("evt-123456")
    .eventType("SECURITY_ALERT")
    .toolType("ANTIVIRUS")
    .severity("HIGH")
    .userId("user-789")
    .deviceId("device-456")
    .hostname("workstation-01")
    .organizationId("org-123")
    .organizationName("Acme Corp")
    .summary("Malware detected and quarantined")
    .timestamp("2024-01-15T10:30:00Z")
    .ingestDay("2024-01-15")
    .build();

// Accessing properties
String severity = logEvent.getSeverity();
String summary = logEvent.getSummary();
```

This DTO is commonly used in the OpenFrame platform's logging pipeline to standardize log event data structure across different MSP tools and services, enabling consistent monitoring and analysis through Mingo AI.
