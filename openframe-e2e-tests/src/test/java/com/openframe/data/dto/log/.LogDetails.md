A Data Transfer Object (DTO) class that represents structured log entry details for the OpenFrame AI-powered MSP platform. This class encapsulates all essential log information including tool events, user context, device details, and organizational metadata.

## Key Components

**Main Class:**
- `LogDetails` - Primary DTO with comprehensive log data fields

**Key Fields:**
- `toolEventId` - Unique identifier for tool-generated events
- `eventType` - Classification of the log event
- `severity` - Log level (error, warning, info, etc.)
- `userId` / `deviceId` / `hostname` - Source identification
- `organizationId` / `organizationName` - Multi-tenant context
- `message` / `details` - Log content and extended information
- `timestamp` / `ingestDay` - Temporal data for log processing

**Lombok Annotations:**
- `@Data` - Generates getters, setters, toString, equals, and hashCode
- `@Builder` - Provides builder pattern for object construction
- `@NoArgsConstructor` / `@AllArgsConstructor` - Constructor generation

## Usage Example

```java
// Creating a log entry using builder pattern
LogDetails logEntry = LogDetails.builder()
    .toolEventId("evt-12345")
    .eventType("SYSTEM_ALERT")
    .severity("ERROR")
    .userId("user-789")
    .deviceId("device-456")
    .hostname("server-01.flamingo.run")
    .organizationId("org-123")
    .organizationName("ACME Corp")
    .message("Database connection timeout")
    .timestamp("2024-01-15T10:30:00Z")
    .ingestDay("2024-01-15")
    .details("Connection pool exhausted after 30 seconds")
    .build();

// Using in log processing pipeline
String eventId = logEntry.getToolEventId();
String severity = logEntry.getSeverity();
```
