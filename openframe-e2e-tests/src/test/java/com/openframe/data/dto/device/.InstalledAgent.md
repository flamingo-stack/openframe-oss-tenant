A data transfer object representing an installed monitoring agent on a device, used for tracking agent deployments and versions across the OpenFrame platform.

## Key Components

- **id** - Unique identifier for the installed agent record
- **machineId** - Reference to the device/machine where the agent is installed
- **agentType** - Type or category of the monitoring agent (e.g., "system", "network", "security")
- **version** - Current version of the installed agent
- **createdAt** - Timestamp when the agent was initially installed
- **updatedAt** - Timestamp of the last agent update or modification

## Usage Example

```java
// Create a new installed agent record
InstalledAgent agent = InstalledAgent.builder()
    .id("agent-123")
    .machineId("machine-456")
    .agentType("system-monitor")
    .version("2.1.0")
    .createdAt("2024-01-15T10:30:00Z")
    .updatedAt("2024-01-15T10:30:00Z")
    .build();

// Update agent version
InstalledAgent updatedAgent = agent.toBuilder()
    .version("2.1.1")
    .updatedAt("2024-01-20T14:45:00Z")
    .build();

// Access agent information
String currentVersion = agent.getVersion();
String installDate = agent.getCreatedAt();
```

This DTO is typically used in REST API responses, database mappings, and internal service communications for managing agent lifecycle across monitored devices in the OpenFrame MSP platform.
