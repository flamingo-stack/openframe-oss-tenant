This DTO class represents an installed monitoring or management agent on a device within the OpenFrame MSP platform.

## Key Components

- **Data Fields**: Complete agent installation details including unique identifiers, version tracking, and timestamps
- **Lombok Annotations**: Provides automatic generation of getters, setters, constructors, and builder pattern
- **Builder Pattern**: Enables fluent object construction for complex agent configurations

## Usage Example

```java
// Create an installed agent record
InstalledAgent agent = InstalledAgent.builder()
    .id("agent-123")
    .machineId("machine-456")
    .agentType("monitoring")
    .version("2.1.3")
    .createdAt("2024-01-15T10:30:00Z")
    .updatedAt("2024-01-15T10:30:00Z")
    .build();

// Access agent information
String agentVersion = agent.getVersion();
String machineId = agent.getMachineId();

// Update agent details
agent.setVersion("2.1.4");
agent.setUpdatedAt("2024-01-20T14:25:00Z");
```

This class is typically used for tracking agent deployments, version management, and maintaining audit trails of agent installations across managed devices in the MSP environment.
