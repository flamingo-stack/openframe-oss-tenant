A data transfer object (DTO) representing an installed agent on a device within the OpenFrame platform, containing metadata about agent deployment and versioning.

## Key Components

- **id** - Unique identifier for the installed agent instance
- **machineId** - Reference to the device/machine where the agent is installed
- **agentType** - Type classification of the agent (e.g., monitoring, security, backup)
- **version** - Current version of the installed agent
- **createdAt** - Timestamp when the agent was initially installed
- **updatedAt** - Timestamp of the last agent update or modification

## Usage Example

```java
// Create a new installed agent record
InstalledAgent agent = InstalledAgent.builder()
    .id("agent-123")
    .machineId("machine-456")
    .agentType("monitoring")
    .version("2.1.0")
    .createdAt("2024-01-15T10:30:00Z")
    .updatedAt("2024-01-20T14:45:00Z")
    .build();

// Access agent information
String agentVersion = agent.getVersion();
String deviceId = agent.getMachineId();

// Update agent version
agent.setVersion("2.1.1");
agent.setUpdatedAt("2024-01-25T09:15:00Z");
```

This DTO is typically used in device management operations, agent deployment tracking, and version control within the OpenFrame MSP platform's device monitoring infrastructure.
