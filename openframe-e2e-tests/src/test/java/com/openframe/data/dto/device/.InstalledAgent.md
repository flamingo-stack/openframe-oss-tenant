A data transfer object representing an installed agent on a device within the OpenFrame platform, tracking agent deployment details and metadata.

## Key Components

- **InstalledAgent** - Main DTO class with Lombok annotations for automatic getter/setter generation
- **id** - Unique identifier for the installed agent instance
- **machineId** - Reference to the device/machine where the agent is installed
- **agentType** - Type or category of the installed agent
- **version** - Version string of the installed agent
- **createdAt/updatedAt** - Timestamp fields for tracking installation and modification dates

## Usage Example

```java
// Create a new installed agent record
InstalledAgent agent = InstalledAgent.builder()
    .id("agent-123")
    .machineId("machine-456")
    .agentType("monitoring")
    .version("1.2.3")
    .createdAt("2024-01-15T10:30:00Z")
    .updatedAt("2024-01-15T10:30:00Z")
    .build();

// Access agent information
String agentType = agent.getAgentType();
String version = agent.getVersion();

// Update version
agent.setVersion("1.2.4");
agent.setUpdatedAt("2024-01-16T09:15:00Z");
```

The class uses Lombok annotations to automatically generate boilerplate code including constructors, getters, setters, and builder pattern implementation for clean object creation and manipulation.
