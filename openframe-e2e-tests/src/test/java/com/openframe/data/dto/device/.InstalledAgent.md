A data transfer object (DTO) that represents an installed software agent on a device within the OpenFrame platform, tracking agent metadata and installation details.

## Key Components

**Class Annotations:**
- `@Data` - Generates getters, setters, equals, hashCode, and toString methods
- `@Builder` - Enables fluent builder pattern for object construction
- `@NoArgsConstructor` - Creates default constructor
- `@AllArgsConstructor` - Creates constructor with all fields

**Fields:**
- `id` - Unique identifier for the installed agent
- `machineId` - Reference to the host machine/device
- `agentType` - Type or category of the installed agent
- `version` - Version number of the installed agent
- `createdAt` - Timestamp when the agent was installed
- `updatedAt` - Timestamp when the agent information was last modified

## Usage Example

```java
// Create using builder pattern
InstalledAgent agent = InstalledAgent.builder()
    .id("agent-001")
    .machineId("machine-123")
    .agentType("monitoring")
    .version("2.1.4")
    .createdAt("2024-01-15T10:30:00Z")
    .updatedAt("2024-01-15T10:30:00Z")
    .build();

// Create using constructor
InstalledAgent agent2 = new InstalledAgent(
    "agent-002", 
    "machine-456", 
    "backup", 
    "1.5.2",
    "2024-01-16T14:20:00Z",
    "2024-01-16T14:20:00Z"
);

// Access properties
String agentVersion = agent.getVersion();
agent.setUpdatedAt("2024-01-17T09:15:00Z");
```
