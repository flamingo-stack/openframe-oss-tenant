A DTO class representing a paginated connection of device data, following GraphQL connection patterns for efficient device listing with filtering capabilities.

## Key Components

- **`edges`** - List of `DeviceEdge` objects containing device nodes and cursor information
- **`filteredCount`** - Integer representing the total number of devices after applying filters
- **Lombok annotations** - Provides automatic generation of getters, setters, constructors, and builder pattern

## Usage Example

```java
// Building a device connection response
DeviceConnection connection = DeviceConnection.builder()
    .edges(deviceEdges)
    .filteredCount(totalFilteredDevices)
    .build();

// Accessing connection data
List<DeviceEdge> edges = connection.getEdges();
Integer totalCount = connection.getFilteredCount();

// Typical usage in GraphQL resolver
@QueryMapping
public DeviceConnection getDevices(@Argument DeviceFilter filter) {
    List<DeviceEdge> edges = deviceService.getDeviceEdges(filter);
    Integer filteredCount = deviceService.getFilteredDeviceCount(filter);
    
    return DeviceConnection.builder()
        .edges(edges)
        .filteredCount(filteredCount)
        .build();
}
```

This class is typically used in GraphQL APIs to return paginated device results with metadata about the total filtered count, enabling efficient client-side pagination and result management.
