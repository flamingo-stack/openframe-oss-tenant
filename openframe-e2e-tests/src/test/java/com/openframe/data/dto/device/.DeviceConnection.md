A GraphQL connection wrapper for paginated device data, providing edges and metadata for device query results.

## Key Components

- **edges** - List of `DeviceEdge` objects containing the actual device data and cursor information
- **filteredCount** - Integer representing the total number of devices matching the current filter criteria
- Uses Lombok annotations for automatic generation of getters, setters, constructors, and builder pattern

## Usage Example

```java
// Building a device connection response
DeviceConnection connection = DeviceConnection.builder()
    .edges(deviceEdges)
    .filteredCount(totalDeviceCount)
    .build();

// Accessing connection data
List<DeviceEdge> deviceEdges = connection.getEdges();
Integer totalCount = connection.getFilteredCount();

// Typical usage in GraphQL resolver
public DeviceConnection getDevices(DeviceFilter filter, PaginationInput pagination) {
    List<DeviceEdge> edges = deviceService.getDeviceEdges(filter, pagination);
    Integer count = deviceService.countDevices(filter);
    
    return DeviceConnection.builder()
        .edges(edges)
        .filteredCount(count)
        .build();
}
```

This DTO follows GraphQL connection patterns for consistent pagination across the OpenFrame platform, enabling efficient device data retrieval with proper metadata for UI components.
