A data transfer object representing a paginated connection of device edges, providing both the result set and metadata about filtered results.

## Key Components

- **`edges`** - List of `DeviceEdge` objects containing the actual device data
- **`filteredCount`** - Integer representing the total number of devices matching the applied filters
- **Lombok annotations** - Provides automatic generation of getters, setters, constructors, and builder pattern

## Usage Example

```java
// Creating a device connection with builder pattern
DeviceConnection connection = DeviceConnection.builder()
    .edges(deviceEdges)
    .filteredCount(150)
    .build();

// Accessing connection data
List<DeviceEdge> devices = connection.getEdges();
Integer totalFiltered = connection.getFilteredCount();

// Using in pagination scenarios
if (connection.getFilteredCount() > connection.getEdges().size()) {
    // More results available
    System.out.println("Showing " + connection.getEdges().size() + 
                      " of " + connection.getFilteredCount() + " devices");
}
```

This DTO follows GraphQL connection patterns, enabling efficient pagination and filtering of device collections in the OpenFrame platform while providing clients with both the current page data and total result metadata.
