A data transfer object that represents a paginated connection of device edges with filtering metadata, commonly used in GraphQL-style pagination patterns.

## Key Components

- **edges** - List of `DeviceEdge` objects containing the actual device data and cursor information
- **filteredCount** - Integer representing the total number of items after applying filters
- **Lombok annotations** - Provides automatic generation of getters, setters, constructors, and builder pattern

## Usage Example

```java
// Creating a device connection with filtered results
DeviceConnection connection = DeviceConnection.builder()
    .edges(deviceEdgeList)
    .filteredCount(25)
    .build();

// Accessing connection data
List<DeviceEdge> devices = connection.getEdges();
Integer totalFiltered = connection.getFilteredCount();

// Using in a pagination response
return ResponseEntity.ok(connection);
```

This DTO follows the GraphQL Connection specification pattern, enabling efficient pagination and filtering of device collections in API responses. The `filteredCount` helps clients understand the total available results when implementing pagination controls.
