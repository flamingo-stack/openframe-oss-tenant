Data Transfer Object for paginated device query results with connection-based pagination support.

## Key Components

- **edges** - List of `DeviceEdge` objects containing device data and cursor information for pagination
- **filteredCount** - Total number of devices matching the current filter criteria
- **Lombok annotations** - `@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor` for automatic code generation

## Usage Example

```java
// Creating a device connection response
DeviceConnection connection = DeviceConnection.builder()
    .edges(deviceEdges)
    .filteredCount(totalFilteredDevices)
    .build();

// Accessing connection data
List<DeviceEdge> devices = connection.getEdges();
Integer totalCount = connection.getFilteredCount();

// Typical GraphQL-style pagination usage
public DeviceConnection getDevices(String filter, String cursor, int limit) {
    List<DeviceEdge> edges = deviceService.findDevicesWithCursor(filter, cursor, limit);
    Integer filteredCount = deviceService.countFilteredDevices(filter);
    
    return DeviceConnection.builder()
        .edges(edges)
        .filteredCount(filteredCount)
        .build();
}
```

This class follows the GraphQL Connection specification pattern, commonly used in OpenFrame's device management APIs for efficient pagination and filtering of device collections.
