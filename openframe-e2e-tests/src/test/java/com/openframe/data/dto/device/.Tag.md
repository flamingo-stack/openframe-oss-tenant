A data transfer object (DTO) representing a tag entity used for categorizing and organizing devices within the OpenFrame platform. Tags provide a flexible way to group and identify devices with custom metadata including visual color coding.

## Key Components

- **Core Properties**: `id`, `name`, `description` for basic tag identification
- **Visual Customization**: `color` field for UI representation and categorization
- **Organization Context**: `organizationId` for multi-tenant data isolation
- **Audit Fields**: `createdAt` and `createdBy` for tracking tag creation metadata
- **Lombok Annotations**: `@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor` for automatic code generation

## Usage Example

```java
// Create a new tag using builder pattern
Tag deviceTag = Tag.builder()
    .id("tag_123")
    .name("Production Servers")
    .description("Mission-critical production environment servers")
    .color("#FF5722")
    .organizationId("org_456")
    .createdAt("2024-01-15T10:30:00Z")
    .createdBy("admin@company.com")
    .build();

// Access tag properties
String tagName = deviceTag.getName();
String tagColor = deviceTag.getColor();

// Use in device categorization
if (deviceTag.getName().equals("Production Servers")) {
    // Apply production-specific policies
}
```

This DTO integrates with OpenFrame's device management system to provide flexible tagging capabilities for MSP operations and device organization.
