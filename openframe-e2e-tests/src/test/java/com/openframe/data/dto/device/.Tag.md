A data transfer object (DTO) representing device tags used for categorizing and organizing devices within the OpenFrame platform.

## Key Components

- **Core Fields**: `id`, `name`, `description` for basic tag information
- **Visual Properties**: `color` field for UI display customization
- **Organization Context**: `organizationId` for multi-tenant support
- **Audit Trail**: `createdAt` and `createdBy` fields for tracking tag creation
- **Lombok Annotations**: `@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor` for automatic code generation

## Usage Example

```java
// Creating a new tag with builder pattern
Tag deviceTag = Tag.builder()
    .id("tag-123")
    .name("Production Server")
    .description("Servers running in production environment")
    .color("#ff5722")
    .organizationId("org-456")
    .createdAt("2024-01-15T10:30:00Z")
    .createdBy("admin@company.com")
    .build();

// Using default constructor
Tag tag = new Tag();
tag.setName("Development");
tag.setColor("#2196f3");
tag.setOrganizationId("org-456");
```

This DTO supports the OpenFrame device management system by providing a flexible tagging mechanism for device categorization, with built-in support for multi-tenancy and audit tracking.
