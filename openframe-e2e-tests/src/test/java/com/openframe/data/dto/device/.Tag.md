A Data Transfer Object (DTO) representing a tag entity used for categorizing and organizing devices within the OpenFrame platform. This class uses Lombok annotations for automatic generation of boilerplate code.

## Key Components

- **Fields**: `id`, `name`, `description`, `color`, `organizationId`, `createdAt`, `createdBy`
- **Lombok Annotations**: `@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor` for automatic code generation
- **Builder Pattern**: Enables fluent object construction
- **Organization Scope**: Tags are scoped to specific organizations via `organizationId`

## Usage Example

```java
// Create a new tag using builder pattern
Tag deviceTag = Tag.builder()
    .id("tag-001")
    .name("Critical Infrastructure")
    .description("Devices essential for business operations")
    .color("#FF0000")
    .organizationId("org-123")
    .createdAt("2024-01-15T10:30:00Z")
    .createdBy("admin@company.com")
    .build();

// Access tag properties
String tagName = deviceTag.getName();
String tagColor = deviceTag.getColor();

// Update tag description
deviceTag.setDescription("Updated description for critical devices");
```

This DTO is typically used in device management workflows to apply categorical labels with visual indicators (colors) for better organization and filtering of IT assets within the OpenFrame MSP platform.
