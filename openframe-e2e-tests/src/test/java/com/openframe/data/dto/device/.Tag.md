A Data Transfer Object (DTO) representing a tag entity used for labeling and categorizing devices within the OpenFrame platform. This class provides a simple structure for tag metadata with organizational context.

## Key Components

- **Tag Properties**: Core tag attributes including `id`, `name`, `description`, and `color` for visual identification
- **Organization Context**: `organizationId` field for multi-tenant tag management
- **Audit Fields**: Creation tracking with `createdAt` and `createdBy` timestamps
- **Lombok Annotations**: Auto-generated constructors, getters, setters, and builder pattern support

## Usage Example

```java
// Create a new tag using builder pattern
Tag serverTag = Tag.builder()
    .id("tag-001")
    .name("Production Server")
    .description("Critical production infrastructure")
    .color("#FF5722")
    .organizationId("org-123")
    .createdAt("2024-01-15T10:30:00Z")
    .createdBy("admin@company.com")
    .build();

// Access tag properties
String tagName = serverTag.getName();
String tagColor = serverTag.getColor();

// Create using all-args constructor
Tag networkTag = new Tag("tag-002", "Network Equipment", 
    "Switches and routers", "#2196F3", "org-123",
    "2024-01-15T10:35:00Z", "admin@company.com");
```

This DTO is typically used in device management APIs to associate tags with IT infrastructure components for improved organization and filtering capabilities.
