Data Transfer Object (DTO) representing a tag entity used for categorizing and organizing devices within the OpenFrame platform. This class provides a simple structure for tag metadata including identification, visual properties, and audit information.

## Key Components

- **id** - Unique identifier for the tag
- **name** - Display name of the tag
- **description** - Optional detailed description
- **color** - Visual color representation for UI display
- **organizationId** - Links tag to specific organization
- **createdAt** - Timestamp of tag creation
- **createdBy** - User identifier who created the tag

## Usage Example

```java
// Create a new tag for categorizing devices
Tag serverTag = Tag.builder()
    .name("Production Server")
    .description("Critical production infrastructure")
    .color("#FF5733")
    .organizationId("org-12345")
    .createdBy("admin@company.com")
    .build();

// Use in device management
List<Tag> deviceTags = Arrays.asList(serverTag);
```

The class uses Lombok annotations (`@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`) to automatically generate getters, setters, constructors, and builder pattern methods, reducing boilerplate code while providing a clean API for tag management operations.
