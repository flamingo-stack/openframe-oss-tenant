A simple data transfer object (DTO) that represents a filter option for device queries, containing a value-label pair with an optional count for UI display purposes.

## Key Components

- **value** - The actual filter value used in queries or data processing
- **label** - Human-readable display text for the filter option
- **count** - Optional count indicating how many items match this filter option

## Usage Example

```java
// Create a device type filter option
DeviceFilterOption typeFilter = DeviceFilterOption.builder()
    .value("laptop")
    .label("Laptop Computers")
    .count(25)
    .build();

// Create a status filter option
DeviceFilterOption statusFilter = new DeviceFilterOption("active", "Active Devices", 142);

// Use in a filter dropdown or search interface
List<DeviceFilterOption> deviceTypes = Arrays.asList(
    new DeviceFilterOption("laptop", "Laptops", 25),
    new DeviceFilterOption("desktop", "Desktops", 18),
    new DeviceFilterOption("mobile", "Mobile Devices", 67)
);
```

This DTO is typically used in device management interfaces where users need to filter devices by various criteria like type, status, or location. The count field helps users understand how many results each filter option will return.
