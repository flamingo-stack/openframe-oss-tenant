A data transfer object representing a filter option for device filtering operations, containing the option value, display label, and count of matching items.

## Key Components

- **value** - The actual filter value used in queries
- **label** - Human-readable display text for the filter option
- **count** - Number of items that match this filter option

The class uses Lombok annotations for automatic generation of:
- Getters and setters (`@Data`)
- Builder pattern (`@Builder`)
- Default and all-args constructors (`@NoArgsConstructor`, `@AllArgsConstructor`)

## Usage Example

```java
// Creating a device type filter option
DeviceFilterOption deviceTypeFilter = DeviceFilterOption.builder()
    .value("LAPTOP")
    .label("Laptop Computers")
    .count(25)
    .build();

// Creating a status filter option
DeviceFilterOption statusFilter = DeviceFilterOption.builder()
    .value("ACTIVE")
    .label("Active Devices")
    .count(142)
    .build();

// Using in a filter dropdown
List<DeviceFilterOption> statusOptions = Arrays.asList(
    new DeviceFilterOption("ACTIVE", "Active", 142),
    new DeviceFilterOption("INACTIVE", "Inactive", 23),
    new DeviceFilterOption("MAINTENANCE", "Under Maintenance", 5)
);
```

This DTO is typically used in UI components to populate filter dropdowns with options that show both the display name and the count of available items for each filter choice.
