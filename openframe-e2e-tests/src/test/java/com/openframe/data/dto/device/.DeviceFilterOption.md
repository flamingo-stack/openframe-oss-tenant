A data transfer object representing a filter option for device filtering operations, containing the option value, display label, and count of matching devices.

## Key Components

- **value** - The actual filter value used in queries
- **label** - Human-readable display text for the filter option
- **count** - Number of devices that match this filter option

## Usage Example

```java
// Create filter options for device status
DeviceFilterOption activeOption = DeviceFilterOption.builder()
    .value("active")
    .label("Active Devices")
    .count(25)
    .build();

DeviceFilterOption inactiveOption = DeviceFilterOption.builder()
    .value("inactive") 
    .label("Inactive Devices")
    .count(5)
    .build();

// Use in device filtering UI
List<DeviceFilterOption> statusFilters = Arrays.asList(
    activeOption,
    inactiveOption
);

// Display filter options with counts
statusFilters.forEach(option -> 
    System.out.println(option.getLabel() + " (" + option.getCount() + ")")
);
```

This DTO is typically used in device management interfaces where users need to filter devices by various criteria like status, type, or location, with each option showing how many devices match that filter.
