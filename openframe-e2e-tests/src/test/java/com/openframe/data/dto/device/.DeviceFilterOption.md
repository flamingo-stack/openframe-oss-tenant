A simple data transfer object (DTO) that represents a filter option for device filtering operations, containing a value-label pair with an associated count for UI display purposes.

## Key Components

- **value** - The actual filter value used in queries or operations
- **label** - Human-readable display text for the filter option
- **count** - Number indicating how many items match this filter option

The class uses Lombok annotations for automatic generation of constructors, getters, setters, and builder pattern support.

## Usage Example

```java
// Create a filter option using builder pattern
DeviceFilterOption filterOption = DeviceFilterOption.builder()
    .value("windows")
    .label("Windows Devices")
    .count(25)
    .build();

// Use in device filtering UI
List<DeviceFilterOption> osFilters = Arrays.asList(
    DeviceFilterOption.builder()
        .value("windows")
        .label("Windows")
        .count(150)
        .build(),
    DeviceFilterOption.builder()
        .value("macos")
        .label("macOS")
        .count(75)
        .build(),
    DeviceFilterOption.builder()
        .value("linux")
        .label("Linux")
        .count(30)
        .build()
);

// Display in UI: "Windows (150)", "macOS (75)", "Linux (30)"
```

This DTO is commonly used in dropdown filters, search facets, or category selections where you need to show both the display name and the count of matching items.
