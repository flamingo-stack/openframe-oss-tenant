A data transfer object representing a filter option for device filtering operations, containing the option value, display label, and item count.

## Key Components

- **value**: The actual filter value used in queries
- **label**: Human-readable display text for the filter option
- **count**: Number of devices matching this filter option
- **Lombok annotations**: `@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor` for automatic getter/setter generation and builder pattern support

## Usage Example

```java
// Create a device filter option using builder pattern
DeviceFilterOption option = DeviceFilterOption.builder()
    .value("windows")
    .label("Windows Devices")
    .count(42)
    .build();

// Use in a filter dropdown
List<DeviceFilterOption> osOptions = Arrays.asList(
    DeviceFilterOption.builder()
        .value("windows")
        .label("Windows")
        .count(150)
        .build(),
    DeviceFilterOption.builder()
        .value("macos")
        .label("macOS")
        .count(75)
        .build()
);

// Access properties
String filterValue = option.getValue();    // "windows"
String displayText = option.getLabel();    // "Windows Devices"
Integer deviceCount = option.getCount();   // 42
```

This DTO is typically used to populate filter dropdowns or option lists in device management interfaces, providing both the technical filter value and user-friendly display information.
