Data Transfer Object (DTO) representing a paginated edge connection for device queries, containing a device node and its pagination cursor for GraphQL-style pagination.

## Key Components

**Fields:**
- `node` - The actual `Machine` device object
- `cursor` - String cursor for pagination positioning

**Annotations:**
- `@Data` - Generates getters, setters, equals, hashCode, and toString
- `@Builder` - Enables fluent builder pattern for object creation
- `@NoArgsConstructor` - Creates default constructor
- `@AllArgsConstructor` - Creates constructor with all fields

## Usage Example

```java
// Create using builder pattern
DeviceEdge edge = DeviceEdge.builder()
    .node(machine)
    .cursor("encoded_cursor_string")
    .build();

// Access device and cursor
Machine device = edge.getNode();
String cursor = edge.getCursor();

// Use in pagination response
List<DeviceEdge> edges = Arrays.asList(
    DeviceEdge.builder().node(device1).cursor("cursor1").build(),
    DeviceEdge.builder().node(device2).cursor("cursor2").build()
);
```

This DTO follows the GraphQL Relay specification for cursor-based pagination, where edges contain both the data node and its position cursor for efficient page navigation.
