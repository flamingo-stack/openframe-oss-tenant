A data transfer object representing an edge in a paginated device query, containing a device node and its pagination cursor for GraphQL-style pagination.

## Key Components

- **`Machine node`** - The actual device/machine object at this edge position
- **`cursor`** - String identifier used for cursor-based pagination to determine position in the result set
- **Lombok annotations** - Provides automatic generation of getters, setters, constructors, and builder pattern

## Usage Example

```java
// Create a device edge for pagination
DeviceEdge edge = DeviceEdge.builder()
    .node(machine)
    .cursor("eyJpZCI6IjEyMyJ9")
    .build();

// Use in a paginated response
List<DeviceEdge> edges = deviceService.getDevicesAfter(cursor, limit)
    .stream()
    .map(device -> DeviceEdge.builder()
        .node(device)
        .cursor(encodeCursor(device.getId()))
        .build())
    .collect(Collectors.toList());

// Extract the actual devices from edges
List<Machine> devices = edges.stream()
    .map(DeviceEdge::getNode)
    .collect(Collectors.toList());
```

This pattern follows GraphQL connection specifications for implementing efficient pagination over large device datasets, allowing clients to navigate through results using cursors rather than traditional offset-based pagination.
