A GraphQL edge object that wraps device/machine data with pagination cursor information for implementing cursor-based pagination in device queries.

## Key Components

- **node**: `Machine` object containing the actual device/machine data
- **cursor**: `String` pagination cursor for identifying the position of this edge in the result set
- **Lombok annotations**: Provides automatic generation of getters, setters, constructors, and builder pattern

## Usage Example

```java
// Building a DeviceEdge for pagination response
DeviceEdge deviceEdge = DeviceEdge.builder()
    .node(machine)
    .cursor("base64-encoded-cursor-string")
    .build();

// Using in a GraphQL connection pattern
public class DeviceConnection {
    private List<DeviceEdge> edges;
    private PageInfo pageInfo;
    
    // Methods to handle pagination...
}

// Extracting machine data from edge
Machine device = deviceEdge.getNode();
String nextCursor = deviceEdge.getCursor();
```

This DTO follows the GraphQL Relay specification for cursor-based pagination, allowing clients to efficiently navigate through large sets of device records while maintaining stable pagination positions.
