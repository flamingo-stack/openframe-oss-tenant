A GraphQL edge wrapper that pairs a Machine device node with pagination cursor information, following the Relay connection specification for paginated device queries.

## Key Components

- **node**: Machine object containing the actual device data
- **cursor**: String identifier for pagination positioning within device result sets

## Usage Example

```java
// Creating a device edge for pagination
DeviceEdge edge = DeviceEdge.builder()
    .node(machineDevice)
    .cursor("eyJpZCI6IjEyMzQ1In0=")
    .build();

// Accessing device data from edge
Machine device = edge.getNode();
String position = edge.getCursor();

// Typical usage in paginated responses
List<DeviceEdge> edges = deviceConnection.getEdges();
for (DeviceEdge edge : edges) {
    Machine device = edge.getNode();
    // Process device...
}
```

This DTO enables efficient cursor-based pagination through device collections while maintaining GraphQL Relay connection standards. The cursor typically contains encoded position data for stateless pagination operations.
