A simple data transfer object (DTO) that represents an edge in a paginated device query result, containing a device node and pagination cursor for GraphQL-style pagination.

## Key Components

- **Machine node** - The actual device/machine object being returned
- **String cursor** - Pagination cursor for implementing cursor-based pagination
- **Lombok annotations** - Provides automatic generation of getters, setters, constructors, and builder pattern

## Usage Example

```java
// Creating a device edge for pagination results
DeviceEdge edge = DeviceEdge.builder()
    .node(machine)
    .cursor("eyJpZCI6MTIzfQ==")
    .build();

// Using in a paginated response
List<DeviceEdge> edges = devices.stream()
    .map(device -> DeviceEdge.builder()
        .node(device)
        .cursor(Base64.getEncoder().encodeToString(device.getId().toString().getBytes()))
        .build())
    .collect(Collectors.toList());

// Accessing the data
Machine device = edge.getNode();
String nextCursor = edge.getCursor();
```

This DTO is typically used in GraphQL connection patterns or REST APIs that implement cursor-based pagination, where each result item needs both the actual data (node) and a cursor for fetching subsequent pages.
