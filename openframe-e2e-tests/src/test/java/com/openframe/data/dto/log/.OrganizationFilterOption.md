A simple data transfer object (DTO) that represents an organization filter option for log filtering operations in the OpenFrame platform.

## Key Components

- **OrganizationFilterOption** - Main DTO class with Lombok annotations
- **id** - String field representing the unique organization identifier
- **name** - String field containing the human-readable organization name

## Usage Example

```java
// Create using builder pattern
OrganizationFilterOption option = OrganizationFilterOption.builder()
    .id("org-123")
    .name("Acme Corporation")
    .build();

// Create using constructor
OrganizationFilterOption option2 = new OrganizationFilterOption("org-456", "TechCorp LLC");

// Access data
String orgId = option.getId();
String orgName = option.getName();

// Use in filter collections
List<OrganizationFilterOption> filterOptions = Arrays.asList(
    OrganizationFilterOption.builder().id("org-1").name("Company A").build(),
    OrganizationFilterOption.builder().id("org-2").name("Company B").build()
);
```

The class leverages Lombok annotations to automatically generate getters, setters, constructors, and builder methods, making it ideal for use in dropdown filters or API responses where organization selection is required.
