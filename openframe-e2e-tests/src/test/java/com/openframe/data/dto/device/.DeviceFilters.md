A data transfer object that encapsulates filtering options and metadata for device queries in the OpenFrame platform. This class provides structured filter criteria for device listings and search operations.

## Key Components

- **statuses** - List of device status filter options (active, inactive, etc.)
- **deviceTypes** - List of device type filter options (desktop, laptop, server, etc.)
- **osTypes** - List of operating system filter options (Windows, Linux, macOS, etc.)
- **organizationIds** - List of organization-based filter options for multi-tenant filtering
- **tags** - List of tag-based filter options for custom categorization
- **filteredCount** - Total count of devices matching the current filter criteria

## Usage Example

```java
// Building comprehensive device filters
DeviceFilters filters = DeviceFilters.builder()
    .statuses(List.of(
        new DeviceFilterOption("active", "Active Devices"),
        new DeviceFilterOption("offline", "Offline Devices")
    ))
    .deviceTypes(List.of(
        new DeviceFilterOption("desktop", "Desktop Computers"),
        new DeviceFilterOption("laptop", "Laptops")
    ))
    .osTypes(List.of(
        new DeviceFilterOption("windows", "Windows"),
        new DeviceFilterOption("linux", "Linux")
    ))
    .organizationIds(List.of(
        new DeviceFilterOption("org-123", "Acme Corp"),
        new DeviceFilterOption("org-456", "Tech Solutions")
    ))
    .tags(List.of(
        new TagFilterOption("production", "Production Environment"),
        new TagFilterOption("critical", "Critical Systems")
    ))
    .filteredCount(245)
    .build();

// Using in filter operations
if (filters.getStatuses() != null && !filters.getStatuses().isEmpty()) {
    // Apply status filtering
    deviceQuery.filterByStatuses(filters.getStatuses());
}

System.out.println("Total filtered devices: " + filters.getFilteredCount());
```
