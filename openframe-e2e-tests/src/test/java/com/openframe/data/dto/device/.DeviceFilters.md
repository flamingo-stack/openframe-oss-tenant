A data transfer object (DTO) that encapsulates all available filter options and metadata for device filtering operations in the OpenFrame platform. This class provides structured filter criteria for querying devices based on various attributes.

## Key Components

- **statuses** - List of available device status filter options (e.g., active, inactive, maintenance)
- **deviceTypes** - List of device type filter options (e.g., server, workstation, mobile)
- **osTypes** - List of operating system filter options (e.g., Windows, Linux, macOS)
- **organizationIds** - List of organization-based filter options for multi-tenant filtering
- **tags** - List of tag-based filter options for custom device categorization
- **filteredCount** - Total count of devices matching current filter criteria

## Usage Example

```java
// Build device filters for UI display
DeviceFilters filters = DeviceFilters.builder()
    .statuses(List.of(
        new DeviceFilterOption("ACTIVE", "Active Devices", 150),
        new DeviceFilterOption("INACTIVE", "Inactive Devices", 25)
    ))
    .deviceTypes(List.of(
        new DeviceFilterOption("SERVER", "Servers", 45),
        new DeviceFilterOption("WORKSTATION", "Workstations", 130)
    ))
    .osTypes(List.of(
        new DeviceFilterOption("WINDOWS", "Windows", 120),
        new DeviceFilterOption("LINUX", "Linux", 55)
    ))
    .filteredCount(175)
    .build();

// Use in device search/filter operations
int totalDevices = filters.getFilteredCount();
List<DeviceFilterOption> availableStatuses = filters.getStatuses();
```

This DTO is typically used by frontend components to render filter dropdowns and display available filtering options with their respective counts.
