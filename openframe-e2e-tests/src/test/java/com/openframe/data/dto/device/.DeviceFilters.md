A DTO class that encapsulates all available filter options and metadata for device queries in the OpenFrame platform. This class provides a comprehensive set of filter criteria including device status, type, operating system, organization, and tags, along with result count information.

## Key Components

- **statuses** - List of available device status filter options (e.g., online, offline, maintenance)
- **deviceTypes** - List of device type filter options (e.g., laptop, server, mobile)
- **osTypes** - List of operating system filter options (e.g., Windows, Linux, macOS)
- **organizationIds** - List of organization-based filter options for multi-tenant filtering
- **tags** - List of tag-based filter options using specialized TagFilterOption type
- **filteredCount** - Integer representing the total count of devices matching current filters

## Usage Example

```java
// Building comprehensive device filters
DeviceFilters filters = DeviceFilters.builder()
    .statuses(Arrays.asList(
        DeviceFilterOption.builder().value("online").count(150).build(),
        DeviceFilterOption.builder().value("offline").count(25).build()
    ))
    .deviceTypes(Arrays.asList(
        DeviceFilterOption.builder().value("laptop").count(100).build(),
        DeviceFilterOption.builder().value("server").count(50).build()
    ))
    .osTypes(Arrays.asList(
        DeviceFilterOption.builder().value("windows").count(120).build(),
        DeviceFilterOption.builder().value("linux").count(55).build()
    ))
    .organizationIds(Arrays.asList(
        DeviceFilterOption.builder().value("org-123").count(80).build()
    ))
    .tags(Arrays.asList(
        TagFilterOption.builder().tagName("production").count(75).build()
    ))
    .filteredCount(175)
    .build();

// Accessing filter counts
int onlineDevices = filters.getStatuses().stream()
    .filter(status -> "online".equals(status.getValue()))
    .mapToInt(DeviceFilterOption::getCount)
    .findFirst()
    .orElse(0);
```
