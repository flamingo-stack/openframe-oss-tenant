A data transfer object (DTO) that encapsulates filter criteria and metadata for device queries in the OpenFrame platform. This class provides structured filtering options for device listings with count tracking.

## Key Components

- **statuses** - List of device status filter options (active, inactive, etc.)
- **deviceTypes** - List of device type filter options (desktop, laptop, mobile, etc.)
- **osTypes** - List of operating system filter options (Windows, macOS, Linux, etc.)
- **organizationIds** - List of organization identifier filter options for multi-tenant filtering
- **tags** - List of tag-based filter options for custom device categorization
- **filteredCount** - Integer count of devices matching the applied filters

## Usage Example

```java
DeviceFilters filters = DeviceFilters.builder()
    .statuses(List.of(
        DeviceFilterOption.builder().value("active").label("Active").build(),
        DeviceFilterOption.builder().value("maintenance").label("Maintenance").build()
    ))
    .deviceTypes(List.of(
        DeviceFilterOption.builder().value("desktop").label("Desktop").build()
    ))
    .osTypes(List.of(
        DeviceFilterOption.builder().value("windows").label("Windows").build()
    ))
    .filteredCount(42)
    .build();

// Use in API response or service layer
return deviceService.getDevicesWithFilters(filters);
```

The class leverages Lombok annotations for automatic generation of getters, setters, constructors, and builder pattern implementation, making it ideal for API responses that need to provide both filtering options and result metadata to frontend clients.
