A data transfer object that encapsulates filter options and metadata for device queries in the OpenFrame platform. This class provides structured filtering capabilities for device management operations.

## Key Components

- **statuses** - List of `DeviceFilterOption` objects for filtering by device status
- **deviceTypes** - List of `DeviceFilterOption` objects for filtering by device type categories
- **osTypes** - List of `DeviceFilterOption` objects for filtering by operating system types
- **organizationIds** - List of `DeviceFilterOption` objects for filtering by organization membership
- **tags** - List of `TagFilterOption` objects for filtering by device tags
- **filteredCount** - Integer representing the total count of devices matching current filters

## Usage Example

```java
// Building device filters for a query
DeviceFilters filters = DeviceFilters.builder()
    .statuses(List.of(
        DeviceFilterOption.builder().value("online").count(45).build(),
        DeviceFilterOption.builder().value("offline").count(12).build()
    ))
    .deviceTypes(List.of(
        DeviceFilterOption.builder().value("laptop").count(30).build(),
        DeviceFilterOption.builder().value("desktop").count(20).build()
    ))
    .osTypes(List.of(
        DeviceFilterOption.builder().value("windows").count(35).build(),
        DeviceFilterOption.builder().value("macos").count(15).build()
    ))
    .filteredCount(57)
    .build();

// Accessing filter options
List<DeviceFilterOption> availableStatuses = filters.getStatuses();
Integer totalFiltered = filters.getFilteredCount();
```
