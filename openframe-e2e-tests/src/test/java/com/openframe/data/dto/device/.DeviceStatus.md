Enumeration defining the lifecycle and operational states of devices within the OpenFrame MSP platform, supporting comprehensive device management workflows.

## Key Components

- **PENDING** - Device registered but not yet activated
- **ACTIVE** - Device in normal operational state
- **INACTIVE** - Device temporarily disabled but not deleted
- **MAINTENANCE** - Device undergoing scheduled maintenance
- **DECOMMISSIONED** - Device permanently removed from service
- **ONLINE** - Device currently connected and responsive
- **OFFLINE** - Device not responding or disconnected
- **DELETED** - Device marked for deletion (soft delete)
- **ARCHIVED** - Device moved to archival storage

## Usage Example

```java
// Setting device status during lifecycle management
Device device = new Device();
device.setStatus(DeviceStatus.PENDING);

// Checking device operational state
if (device.getStatus() == DeviceStatus.ONLINE) {
    performMonitoring(device);
} else if (device.getStatus() == DeviceStatus.MAINTENANCE) {
    skipHealthChecks(device);
}

// Status transitions in device management workflow
public void activateDevice(Device device) {
    if (device.getStatus() == DeviceStatus.PENDING) {
        device.setStatus(DeviceStatus.ACTIVE);
        device.setConnectivityStatus(DeviceStatus.ONLINE);
    }
}

// Filtering devices by status
List<Device> activeDevices = deviceRepository
    .findByStatus(DeviceStatus.ACTIVE);
```

The enum supports both lifecycle states (PENDING → ACTIVE → DECOMMISSIONED) and real-time connectivity states (ONLINE/OFFLINE) for comprehensive device tracking in MSP operations.
