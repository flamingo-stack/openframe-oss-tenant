An enumeration that defines all possible states for managed devices in the OpenFrame MSP platform, covering both lifecycle and connectivity statuses.

## Key Components

- **PENDING** - Device awaiting initial setup or approval
- **ACTIVE** - Device is operational and available for management
- **INACTIVE** - Device is temporarily disabled but still managed
- **MAINTENANCE** - Device is undergoing scheduled or emergency maintenance
- **DECOMMISSIONED** - Device has been permanently removed from service
- **ONLINE** - Device is currently connected and communicating
- **OFFLINE** - Device is not responding or disconnected
- **DELETED** - Device record marked for deletion
- **ARCHIVED** - Device record preserved for historical purposes

## Usage Example

```java
// Check device operational state
if (device.getStatus() == DeviceStatus.ACTIVE || 
    device.getStatus() == DeviceStatus.MAINTENANCE) {
    // Device is managed and trackable
    monitoringService.trackDevice(device);
}

// Filter devices by connectivity
List<Device> connectedDevices = deviceList.stream()
    .filter(d -> d.getStatus() == DeviceStatus.ONLINE)
    .collect(Collectors.toList());

// Handle device lifecycle transitions
switch (device.getStatus()) {
    case PENDING:
        provisioningService.setupDevice(device);
        break;
    case DECOMMISSIONED:
        cleanupService.removeDevice(device);
        break;
    case OFFLINE:
        alertService.notifyDisconnection(device);
        break;
}
```
