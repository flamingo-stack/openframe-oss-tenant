An enumeration that defines the possible operational and lifecycle states for devices managed within the OpenFrame platform.

## Key Components

- **PENDING** - Device awaiting initial setup or activation
- **ACTIVE** - Device is operational and available for use
- **INACTIVE** - Device is temporarily disabled but remains in system
- **MAINTENANCE** - Device is undergoing maintenance or repairs
- **DECOMMISSIONED** - Device has been permanently removed from service
- **ONLINE** - Device is currently connected and responding
- **OFFLINE** - Device is not currently reachable or connected
- **DELETED** - Device record marked for deletion
- **ARCHIVED** - Device record preserved for historical purposes

## Usage Example

```java
// Set device status during lifecycle management
Device device = new Device();
device.setStatus(DeviceStatus.PENDING);

// Check if device is operational
if (device.getStatus() == DeviceStatus.ACTIVE || 
    device.getStatus() == DeviceStatus.ONLINE) {
    // Process device operations
}

// Handle maintenance scenarios
switch (device.getStatus()) {
    case MAINTENANCE:
        scheduleMaintenanceCheck(device);
        break;
    case OFFLINE:
        triggerConnectivityAlert(device);
        break;
    case DECOMMISSIONED:
        removeFromActiveInventory(device);
        break;
}
```

This enum supports both operational states (ONLINE/OFFLINE) and lifecycle management (PENDING through ARCHIVED), enabling comprehensive device state tracking in MSP environments.
