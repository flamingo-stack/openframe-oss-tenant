Enumeration that defines the various lifecycle and operational states a device can have within the OpenFrame platform. This enum provides a standardized way to track device status across the MSP platform.

## Key Components

- **PENDING** - Device is registered but not yet activated
- **ACTIVE** - Device is operational and available for use
- **INACTIVE** - Device is temporarily disabled or not in service
- **MAINTENANCE** - Device is undergoing maintenance or repairs
- **DECOMMISSIONED** - Device has been permanently retired from service
- **ONLINE** - Device is currently connected and communicating
- **OFFLINE** - Device is not currently reachable or responding
- **DELETED** - Device record has been marked for deletion
- **ARCHIVED** - Device record has been moved to archive storage

## Usage Example

```java
import com.openframe.data.dto.device.DeviceStatus;

// Set device status during onboarding
DeviceStatus status = DeviceStatus.PENDING;

// Update status when device comes online
if (deviceConnected) {
    status = DeviceStatus.ONLINE;
} else {
    status = DeviceStatus.OFFLINE;
}

// Check if device is operational
boolean isOperational = status == DeviceStatus.ACTIVE || 
                       status == DeviceStatus.ONLINE;

// Handle maintenance scenarios
if (maintenanceRequired) {
    status = DeviceStatus.MAINTENANCE;
}
```

This enum is commonly used in device management workflows, monitoring dashboards, and automated IT support operations within the OpenFrame MSP platform.
