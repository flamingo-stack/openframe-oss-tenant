Enum defining the possible operational and lifecycle states for devices within the OpenFrame platform. This provides standardized status values for device management and monitoring operations.

## Key Components

- **PENDING** - Device registration initiated but not yet activated
- **ACTIVE** - Device is operational and available for use
- **INACTIVE** - Device is temporarily disabled or not in use
- **MAINTENANCE** - Device is undergoing maintenance or repairs
- **DECOMMISSIONED** - Device has been permanently retired from service
- **ONLINE** - Device is currently connected and responsive
- **OFFLINE** - Device is not currently reachable or connected
- **DELETED** - Device record has been marked for deletion
- **ARCHIVED** - Device data has been archived for historical purposes

## Usage Example

```java
// Setting device status during lifecycle management
Device device = new Device();
device.setStatus(DeviceStatus.PENDING);

// Updating status based on connectivity
if (deviceConnection.isReachable()) {
    device.setStatus(DeviceStatus.ONLINE);
} else {
    device.setStatus(DeviceStatus.OFFLINE);
}

// Conditional logic based on device state
switch (device.getStatus()) {
    case ACTIVE:
        performDeviceOperations(device);
        break;
    case MAINTENANCE:
        scheduleMaintenanceCheck(device);
        break;
    case DECOMMISSIONED:
        archiveDeviceData(device);
        break;
}
```
