A data transfer object (DTO) for filtering log entries in the OpenFrame platform, providing comprehensive filtering criteria for log queries.

## Key Components

- **Date Range Filtering**: `startDate` and `endDate` for temporal log filtering
- **Event Classification**: `eventTypes` and `toolTypes` for categorizing log entries
- **Severity Levels**: `severities` for filtering by log importance/urgency
- **Organization Scope**: `organizationIds` for multi-tenant log filtering
- **Device Targeting**: `deviceId` for device-specific log queries
- **Lombok Annotations**: `@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor` for boilerplate code generation

## Usage Example

```java
// Create a log filter for critical errors in the last 24 hours
LogFilterInput filter = LogFilterInput.builder()
    .startDate("2024-01-15T00:00:00Z")
    .endDate("2024-01-16T00:00:00Z")
    .eventTypes(List.of("ERROR", "EXCEPTION"))
    .toolTypes(List.of("MONITORING", "ALERTING"))
    .severities(List.of("CRITICAL", "HIGH"))
    .organizationIds(List.of("org-123", "org-456"))
    .deviceId("device-789")
    .build();

// Use with log service
List<LogEntry> filteredLogs = logService.filterLogs(filter);
```

This DTO supports the OpenFrame MSP platform's centralized logging system, enabling technicians and administrators to efficiently query and analyze system events across multiple organizations and devices.
