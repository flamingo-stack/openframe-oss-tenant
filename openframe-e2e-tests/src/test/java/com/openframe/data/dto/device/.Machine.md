A comprehensive data transfer object representing a managed device/machine within the OpenFrame MSP platform, containing hardware details, software information, and management metadata.

## Key Components

**Core Machine Properties:**
- **Identity Fields**: `id`, `machineId`, `ip`, `macAddress`, `osUuid` - Unique identifiers and network information
- **System Information**: `hostname`, `displayName`, `serialNumber`, `manufacturer`, `model` - Hardware and naming details
- **Operating System**: `osType`, `osVersion`, `osBuild`, `timezone` - OS-specific configuration data
- **Management Data**: `organizationId`, `agentVersion`, `status`, `lastSeen` - Administrative and monitoring fields
- **Relationships**: `tags`, `toolConnections`, `installedAgents` - Associated resources and integrations

**Lombok Annotations:**
- `@Data` - Generates getters, setters, toString, equals, and hashCode
- `@Builder` - Enables fluent object construction
- `@NoArgsConstructor/@AllArgsConstructor` - Default and full constructors

## Usage Example

```java
// Building a new machine record
Machine machine = Machine.builder()
    .machineId("MSP-WS-001")
    .hostname("workstation-001")
    .displayName("John's Workstation")
    .ip("192.168.1.100")
    .macAddress("00:11:22:33:44:55")
    .osType("Windows")
    .osVersion("11 Pro")
    .status(DeviceStatus.ONLINE)
    .organizationId("org-123")
    .agentVersion("2.1.0")
    .type(DeviceType.WORKSTATION)
    .build();

// Updating machine status
machine.setStatus(DeviceStatus.OFFLINE);
machine.setLastSeen("2024-01-15T14:30:00Z");
```
