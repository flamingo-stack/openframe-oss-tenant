This DTO represents a machine/device in the OpenFrame platform, containing comprehensive device identification, configuration, and management information.

## Key Components

- **Device Identification**: `id`, `machineId`, `ip`, `macAddress`, `osUuid` for unique device tracking
- **Device Details**: `hostname`, `displayName`, `serialNumber`, `manufacturer`, `model` for device information
- **Operating System**: `osType`, `osVersion`, `osBuild`, `timezone` for system details
- **Management Data**: `status`, `lastSeen`, `agentVersion`, `organizationId` for operational tracking
- **Associations**: `tags`, `toolConnections`, `installedAgents` for device relationships
- **Timestamps**: `registeredAt`, `updatedAt` for audit tracking

## Usage Example

```java
Machine machine = Machine.builder()
    .machineId("DESKTOP-ABC123")
    .ip("192.168.1.100")
    .macAddress("00:1B:44:11:3A:B7")
    .hostname("workstation-01")
    .displayName("John's Workstation")
    .osType("Windows")
    .osVersion("11")
    .status(DeviceStatus.ONLINE)
    .organizationId("org-123")
    .agentVersion("2.1.0")
    .type(DeviceType.WORKSTATION)
    .build();

// Access device information
String deviceName = machine.getDisplayName();
boolean isOnline = machine.getStatus() == DeviceStatus.ONLINE;
List<Tag> deviceTags = machine.getTags();
```

The class uses Lombok annotations for automatic generation of getters, setters, constructors, and builder pattern implementation.
