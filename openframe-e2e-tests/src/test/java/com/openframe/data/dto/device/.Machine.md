A comprehensive DTO class representing a machine/device entity in the OpenFrame platform, containing hardware specifications, network information, operating system details, and associated management tools.

## Key Components

- **Core Identifiers**: `id`, `machineId`, `ip`, `macAddress`, `osUuid` for unique machine identification
- **Device Metadata**: `hostname`, `displayName`, `serialNumber`, `manufacturer`, `model` for device information
- **Status & Monitoring**: `status` (DeviceStatus enum), `lastSeen`, `agentVersion` for health tracking
- **Operating System**: `osType`, `osVersion`, `osBuild` for OS classification
- **Management Data**: `organizationId`, `timezone`, timestamp fields for organizational context
- **Associated Collections**: `tags`, `toolConnections`, `installedAgents` for extensible machine management

## Usage Example

```java
// Create a new machine record
Machine machine = Machine.builder()
    .machineId("DESK-WIN-001")
    .ip("192.168.1.100")
    .hostname("john-workstation")
    .displayName("John's Workstation")
    .manufacturer("Dell")
    .model("OptiPlex 7090")
    .osType("Windows")
    .osVersion("11")
    .status(DeviceStatus.ONLINE)
    .organizationId("org-123")
    .agentVersion("2.1.0")
    .build();

// Access device information
String deviceInfo = String.format("Device: %s (%s) - %s %s", 
    machine.getDisplayName(), 
    machine.getIp(),
    machine.getManufacturer(),
    machine.getModel());
```
