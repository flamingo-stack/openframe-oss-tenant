A data transfer object representing a managed device/machine within the OpenFrame platform, containing comprehensive device identification, system information, and connectivity details.

## Key Components

- **Device Identification**: `id`, `machineId`, `ip`, `macAddress`, `osUuid` for unique machine identification
- **System Information**: `hostname`, `displayName`, `serialNumber`, `manufacturer`, `model` for device details
- **Operating System**: `osType`, `osVersion`, `osBuild`, `timezone` for OS-specific information
- **Status & Monitoring**: `status`, `lastSeen`, `agentVersion` for tracking device health and connectivity
- **Organization Context**: `organizationId` for multi-tenant device management
- **Timestamps**: `registeredAt`, `updatedAt` for audit and lifecycle tracking
- **Extensions**: `tags`, `toolConnections`, `installedAgents` for categorization and integration management

## Usage Example

```java
Machine device = Machine.builder()
    .machineId("WIN-DESKTOP-001")
    .ip("192.168.1.100")
    .hostname("john-laptop")
    .displayName("John's Work Laptop")
    .osType("Windows")
    .osVersion("11")
    .status(DeviceStatus.ONLINE)
    .organizationId("org-123")
    .agentVersion("2.1.0")
    .type(DeviceType.WORKSTATION)
    .tags(List.of(
        Tag.builder().name("department").value("engineering").build(),
        Tag.builder().name("location").value("office").build()
    ))
    .build();
```

This DTO supports the complete device lifecycle in MSP environments, from initial registration through ongoing monitoring and management.
