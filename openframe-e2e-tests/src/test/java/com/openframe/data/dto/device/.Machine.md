A comprehensive data transfer object that represents a managed device/machine within the OpenFrame platform, containing detailed hardware, software, and operational metadata.

## Key Components

**Core Properties:**
- `id`, `machineId` - Unique identifiers for the machine
- `ip`, `macAddress`, `osUuid` - Network and system identifiers
- `hostname`, `displayName`, `serialNumber` - Human-readable identifiers
- `status` - Current operational status (DeviceStatus enum)
- `lastSeen`, `registeredAt`, `updatedAt` - Timestamp tracking

**Device Information:**
- `manufacturer`, `model`, `type` - Hardware specifications
- `osType`, `osVersion`, `osBuild` - Operating system details
- `timezone` - System timezone configuration

**Management Data:**
- `agentVersion` - Version of installed OpenFrame agent
- `organizationId` - Associated organization identifier
- `tags` - Custom labeling for categorization
- `toolConnections` - Integrated MSP tools and their connection status
- `installedAgents` - List of agents deployed on the machine

## Usage Example

```java
Machine machine = Machine.builder()
    .machineId("MACHINE-001")
    .hostname("workstation-01")
    .displayName("John's Workstation")
    .ip("192.168.1.100")
    .macAddress("AA:BB:CC:DD:EE:FF")
    .status(DeviceStatus.ONLINE)
    .type(DeviceType.WORKSTATION)
    .osType("Windows")
    .osVersion("10")
    .manufacturer("Dell")
    .model("OptiPlex 7090")
    .organizationId("org-123")
    .agentVersion("2.1.0")
    .tags(List.of(new Tag("department", "IT")))
    .build();
```

This DTO is typically used in REST APIs for device management operations, reporting dashboards, and system integration workflows within the OpenFrame MSP platform.
