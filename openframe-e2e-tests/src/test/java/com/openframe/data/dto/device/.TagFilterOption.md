A data transfer object representing filter options for device tags, containing display information and occurrence counts for tag-based filtering operations.

## Key Components

- **value** - The actual tag value used for filtering operations
- **label** - Human-readable display name for the tag option
- **count** - Number of devices/items that have this tag (optional)

The class uses Lombok annotations for automatic generation of getters, setters, constructors, and builder pattern implementation.

## Usage Example

```java
// Create a tag filter option using builder pattern
TagFilterOption tagOption = TagFilterOption.builder()
    .value("production")
    .label("Production Environment") 
    .count(25)
    .build();

// Use in a filtering UI component
List<TagFilterOption> availableTags = Arrays.asList(
    TagFilterOption.builder()
        .value("prod")
        .label("Production")
        .count(12)
        .build(),
    TagFilterOption.builder()
        .value("dev")
        .label("Development")
        .count(8)
        .build()
);

// Display format: "Development (8)"
String displayText = tagOption.getLabel() + " (" + tagOption.getCount() + ")";
```

This DTO is typically used in device management interfaces to provide users with available tag options along with usage statistics for better filtering decisions.
