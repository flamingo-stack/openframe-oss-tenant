A data transfer object representing a filter option for device tags, including the tag value, display label, and count of associated devices.

## Key Components

- **value** - The actual tag value used for filtering
- **label** - Human-readable display text for the tag
- **count** - Number of devices associated with this tag

## Usage Example

```java
// Create a tag filter option for a specific device type
TagFilterOption serverTag = TagFilterOption.builder()
    .value("server")
    .label("Server Devices")
    .count(25)
    .build();

// Use in a filter dropdown or search interface
List<TagFilterOption> availableFilters = Arrays.asList(
    TagFilterOption.builder().value("workstation").label("Workstations").count(150).build(),
    TagFilterOption.builder().value("printer").label("Printers").count(30).build(),
    serverTag
);

// Access properties
String filterValue = serverTag.getValue(); // "server"
String displayText = serverTag.getLabel(); // "Server Devices"
Integer deviceCount = serverTag.getCount(); // 25
```

This DTO is typically used in device management interfaces to provide users with filterable tag options along with counts showing how many devices match each filter criterion.
