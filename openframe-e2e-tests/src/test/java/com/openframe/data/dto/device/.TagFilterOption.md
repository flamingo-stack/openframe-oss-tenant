A data transfer object (DTO) representing a filter option for device tags, containing the option value, display label, and count of items matching that option.

## Key Components

- **value** - The actual filter value used for querying
- **label** - Human-readable display text for the filter option
- **count** - Number of devices/items that match this filter option

This class uses Lombok annotations for automatic generation of:
- Getters and setters (`@Data`)
- Builder pattern (`@Builder`)
- Default and all-args constructors (`@NoArgsConstructor`, `@AllArgsConstructor`)

## Usage Example

```java
// Create a tag filter option using the builder pattern
TagFilterOption filterOption = TagFilterOption.builder()
    .value("production")
    .label("Production Environment")
    .count(25)
    .build();

// Use in a filter dropdown or selection component
List<TagFilterOption> filterOptions = Arrays.asList(
    TagFilterOption.builder()
        .value("prod")
        .label("Production")
        .count(15)
        .build(),
    TagFilterOption.builder()
        .value("staging")
        .label("Staging")
        .count(8)
        .build()
);
```

This DTO is typically used in UI components to populate filter dropdowns, showing users available tag options along with the count of devices for each tag.
