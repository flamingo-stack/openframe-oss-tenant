A data transfer object representing a filter option for device tags, containing the option value, display label, and count of items matching that tag.

## Key Components

- **value**: The actual filter value used in queries
- **label**: Human-readable display text for the UI
- **count**: Number of devices or items that match this tag filter

## Usage Example

```java
// Create a tag filter option for a device category
TagFilterOption serverFilter = TagFilterOption.builder()
    .value("server")
    .label("Servers")
    .count(25)
    .build();

// Use in a filter dropdown
List<TagFilterOption> filterOptions = Arrays.asList(
    TagFilterOption.builder()
        .value("workstation")
        .label("Workstations")
        .count(45)
        .build(),
    TagFilterOption.builder()
        .value("laptop")
        .label("Laptops")
        .count(32)
        .build()
);

// Access properties
String displayText = serverFilter.getLabel(); // "Servers"
Integer deviceCount = serverFilter.getCount(); // 25
```

This DTO is typically used in OpenFrame's device management interface to populate filter dropdowns with tag-based options, showing both the display name and count of matching devices for each tag category.
