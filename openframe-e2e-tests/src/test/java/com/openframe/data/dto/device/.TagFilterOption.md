A simple data transfer object representing a tag filter option with display information and usage count.

## Key Components

- **TagFilterOption**: A DTO class with Lombok annotations for automatic getter/setter generation
- **value**: The actual tag value used for filtering
- **label**: Human-readable display text for the tag
- **count**: Number of items associated with this tag (optional)

## Usage Example

```java
// Create a tag filter option for device categorization
TagFilterOption serverTag = TagFilterOption.builder()
    .value("server")
    .label("Server Devices")
    .count(15)
    .build();

// Use in a filter dropdown or search interface
List<TagFilterOption> deviceTags = Arrays.asList(
    TagFilterOption.builder()
        .value("laptop")
        .label("Laptops")
        .count(8)
        .build(),
    TagFilterOption.builder()
        .value("printer")
        .label("Printers")
        .count(3)
        .build()
);

// Access properties
String filterValue = serverTag.getValue(); // "server"
String displayText = serverTag.getLabel(); // "Server Devices"
Integer itemCount = serverTag.getCount();   // 15
```

This DTO is typically used in device management interfaces where users need to filter devices by tags, showing both the filter criteria and the number of matching items.
