An enumeration that defines the various types of devices that can be managed within the OpenFrame platform, providing standardized device classification for IT asset management and monitoring.

## Key Components

- **DESKTOP** - Desktop computer workstations
- **LAPTOP** - Portable laptop computers
- **SERVER** - Server hardware and systems
- **MOBILE_DEVICE** - Smartphones and mobile devices
- **TABLET** - Tablet devices
- **NETWORK_DEVICE** - Routers, switches, and networking equipment
- **IOT_DEVICE** - Internet of Things devices and sensors
- **VIRTUAL_MACHINE** - Virtual machine instances
- **CONTAINER_HOST** - Container hosting systems
- **OTHER** - Fallback for unclassified device types

## Usage Example

```java
// Categorize a device during asset discovery
public class Device {
    private String name;
    private DeviceType type;
    
    public Device(String name, DeviceType type) {
        this.name = name;
        this.type = type;
    }
    
    // Check if device is infrastructure-related
    public boolean isInfrastructure() {
        return type == DeviceType.SERVER || 
               type == DeviceType.NETWORK_DEVICE || 
               type == DeviceType.VIRTUAL_MACHINE;
    }
}

// Example usage
Device webServer = new Device("web-01", DeviceType.SERVER);
Device userLaptop = new Device("john-laptop", DeviceType.LAPTOP);
Device router = new Device("core-router", DeviceType.NETWORK_DEVICE);
```

This enum enables consistent device classification across the OpenFrame platform, supporting inventory management, monitoring policies, and automated IT operations based on device categories.
