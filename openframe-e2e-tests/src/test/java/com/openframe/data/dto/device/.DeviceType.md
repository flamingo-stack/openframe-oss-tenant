Enumeration that defines standardized device categories for the OpenFrame MSP platform's device management system.

## Key Components

- **DESKTOP** - Desktop computer workstations
- **LAPTOP** - Portable laptop computers
- **SERVER** - Server hardware and systems
- **MOBILE_DEVICE** - Smartphones and mobile devices
- **TABLET** - Tablet devices and iPads
- **NETWORK_DEVICE** - Routers, switches, and network equipment
- **IOT_DEVICE** - Internet of Things and smart devices
- **VIRTUAL_MACHINE** - Virtualized server instances
- **CONTAINER_HOST** - Docker and container hosting systems
- **OTHER** - Fallback category for uncategorized devices

## Usage Example

```java
// Device classification in service layer
public class DeviceService {
    
    public void categorizeDevice(Device device) {
        if (device.hasKeyboard() && !device.isPortable()) {
            device.setType(DeviceType.DESKTOP);
        } else if (device.isVirtualized()) {
            device.setType(DeviceType.VIRTUAL_MACHINE);
        } else if (device.isNetworkEquipment()) {
            device.setType(DeviceType.NETWORK_DEVICE);
        } else {
            device.setType(DeviceType.OTHER);
        }
    }
    
    // Filter devices by type
    public List<Device> getDevicesByType(DeviceType type) {
        return deviceRepository.findByType(type);
    }
}
```

This enum enables consistent device categorization across the OpenFrame platform, supporting inventory management, monitoring policies, and automated IT operations based on device characteristics.
