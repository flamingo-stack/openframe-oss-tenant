An enumeration defining the supported device types within the OpenFrame platform for device categorization and management across IT infrastructure.

## Key Components

- **DESKTOP** - Desktop workstations and personal computers
- **LAPTOP** - Portable laptop computers
- **SERVER** - Physical and virtual servers
- **MOBILE_DEVICE** - Smartphones and mobile devices
- **TABLET** - Tablet devices and hybrid systems
- **NETWORK_DEVICE** - Routers, switches, firewalls, and network equipment
- **IOT_DEVICE** - Internet of Things devices and sensors
- **VIRTUAL_MACHINE** - Virtual machine instances
- **CONTAINER_HOST** - Container orchestration platforms and hosts
- **OTHER** - Fallback category for unclassified devices

## Usage Example

```java

        DeviceType type;

            type = DeviceType.VIRTUAL_MACHINE;
        } else if (deviceModel.contains("router")) {
            type = DeviceType.NETWORK_DEVICE;
        } else if (capabilities.contains("mobile")) {
            type = DeviceType.MOBILE_DEVICE;
        } else {
            type = DeviceType.OTHER;
        }
        
        // Process device based on type
        handleDeviceByType(type);
    }

        switch (type) {

                break;
            case NETWORK_DEVICE:
                // Configure SNMP monitoring
                break;
            default:
                // Standard device handling
                break;
        }
    }
}
```
