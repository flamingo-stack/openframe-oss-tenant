An enumeration defining the various types of devices that can be managed within the OpenFrame platform, providing standardized categorization for IT asset management and device tracking.

## Key Components

- **DESKTOP** - Desktop computer workstations
- **LAPTOP** - Portable laptop computers  
- **SERVER** - Physical server hardware
- **MOBILE_DEVICE** - Smartphones and mobile devices
- **TABLET** - Tablet devices and iPads
- **NETWORK_DEVICE** - Routers, switches, and network infrastructure
- **IOT_DEVICE** - Internet of Things and smart devices
- **VIRTUAL_MACHINE** - Virtual machine instances
- **CONTAINER_HOST** - Docker/container hosting systems
- **OTHER** - Fallback for unspecified device types

## Usage Example

```java
import com.openframe.data.dto.device.DeviceType;

// Categorizing different devices in inventory
DeviceType workstation = DeviceType.DESKTOP;
DeviceType webServer = DeviceType.SERVER;
DeviceType router = DeviceType.NETWORK_DEVICE;

// Using in device management logic
public void assignDevice(String deviceId, DeviceType type) {
    switch (type) {
        case SERVER:
            // Apply server-specific configurations
            configureServerMonitoring(deviceId);
            break;
        case NETWORK_DEVICE:
            // Setup network device monitoring
            configureNetworkMonitoring(deviceId);
            break;
        default:
            // Standard device setup
            configureBasicMonitoring(deviceId);
    }
}
```

This enum is commonly used in device DTOs, inventory management systems, and monitoring configurations to ensure consistent device classification across the OpenFrame platform.
