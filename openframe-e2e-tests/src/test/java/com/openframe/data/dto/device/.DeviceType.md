An enumeration that defines the standard device types supported by the OpenFrame platform for IT asset management and categorization.

## Key Components

- **DESKTOP** - Traditional desktop workstations
- **LAPTOP** - Portable laptop computers  
- **SERVER** - Physical server hardware
- **MOBILE_DEVICE** - Smartphones and mobile devices
- **TABLET** - Tablet computers and devices
- **NETWORK_DEVICE** - Routers, switches, firewalls, and networking equipment
- **IOT_DEVICE** - Internet of Things devices and sensors
- **VIRTUAL_MACHINE** - Virtualized computing instances
- **CONTAINER_HOST** - Systems running containerized applications
- **OTHER** - Fallback category for unclassified devices

## Usage Example

```java
// Categorizing different device types in inventory management
DeviceType workstation = DeviceType.DESKTOP;
DeviceType mobilePhone = DeviceType.MOBILE_DEVICE;
DeviceType webServer = DeviceType.SERVER;

// Using in conditional logic
if (device.getType() == DeviceType.NETWORK_DEVICE) {
    // Apply network-specific monitoring rules
    enableNetworkMonitoring(device);
} else if (device.getType() == DeviceType.VIRTUAL_MACHINE) {
    // Configure virtualization-specific settings
    configureVMSettings(device);
}

// Switch statement for device-specific operations
switch (deviceType) {
    case DESKTOP:
    case LAPTOP:
        setupEndpointSecurity();
        break;
    case SERVER:
        configureServerMonitoring();
        break;
    case IOT_DEVICE:
        enableIoTProtocols();
        break;
    default:
        applyDefaultConfiguration();
}
```
