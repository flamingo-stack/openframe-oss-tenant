A data transfer object (DTO) that defines filtering criteria for device queries, supporting multiple filter dimensions including status, type, operating system, organization, and tags.

## Key Components

- **statuses** - List of `DeviceStatus` enums to filter by device operational status
- **deviceTypes** - List of `DeviceType` enums to filter by hardware/device category
- **osTypes** - List of operating system type strings for OS-based filtering
- **organizationIds** - List of organization identifier strings for multi-tenant filtering
- **tagNames** - List of tag name strings for custom label-based filtering

## Usage Example

```java
// Create comprehensive device filter
DeviceFilterInput filter = DeviceFilterInput.builder()
    .statuses(List.of(DeviceStatus.ACTIVE, DeviceStatus.MAINTENANCE))
    .deviceTypes(List.of(DeviceType.SERVER, DeviceType.WORKSTATION))
    .osTypes(List.of("Windows 11", "Ubuntu 22.04"))
    .organizationIds(List.of("org-123", "org-456"))
    .tagNames(List.of("production", "critical"))
    .build();

// Create simple status filter
DeviceFilterInput statusFilter = DeviceFilterInput.builder()
    .statuses(List.of(DeviceStatus.OFFLINE))
    .build();
```

This filter input enables flexible device querying across the OpenFrame platform, supporting both simple single-criteria filters and complex multi-dimensional searches for MSP device management operations.
