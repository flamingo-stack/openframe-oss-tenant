A data transfer object (DTO) that encapsulates filtering criteria for device queries, supporting multiple filter dimensions including status, type, operating system, organization, and tags.

## Key Components

- **statuses** - List of `DeviceStatus` enums to filter devices by their current status
- **deviceTypes** - List of `DeviceType` enums to filter by device categories  
- **osTypes** - List of operating system type strings for OS-based filtering
- **organizationIds** - List of organization identifier strings for multi-tenant filtering
- **tagNames** - List of tag name strings for tag-based device categorization
- **Lombok annotations** - `@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor` for automatic generation of getters, setters, constructors, and builder pattern

## Usage Example

```java
// Create a filter for active Windows workstations in specific organizations
DeviceFilterInput filter = DeviceFilterInput.builder()
    .statuses(List.of(DeviceStatus.ACTIVE, DeviceStatus.ONLINE))
    .deviceTypes(List.of(DeviceType.WORKSTATION, DeviceType.LAPTOP))
    .osTypes(List.of("Windows 10", "Windows 11"))
    .organizationIds(List.of("org-123", "org-456"))
    .tagNames(List.of("production", "critical"))
    .build();

// Use with a service or repository
List<Device> filteredDevices = deviceService.findDevices(filter);
```

This filter input enables flexible device querying by combining multiple criteria, making it ideal for complex device management scenarios in MSP environments where devices need to be filtered across multiple dimensions simultaneously.
