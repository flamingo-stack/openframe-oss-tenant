A filter input DTO for querying devices with multiple criteria including status, type, operating system, organization, and tags.

## Key Components

- **statuses** - List of `DeviceStatus` enums to filter by device operational status
- **deviceTypes** - List of `DeviceType` enums to filter by hardware/device categories  
- **osTypes** - List of operating system type strings for OS-based filtering
- **organizationIds** - List of organization identifier strings for multi-tenant filtering
- **tagNames** - List of tag name strings for label-based device categorization

The class uses Lombok annotations for automatic generation of getters, setters, constructors, and builder pattern implementation.

## Usage Example

```java
// Filter for active Windows workstations in specific organizations
DeviceFilterInput filter = DeviceFilterInput.builder()
    .statuses(List.of(DeviceStatus.ACTIVE, DeviceStatus.ONLINE))
    .deviceTypes(List.of(DeviceType.WORKSTATION, DeviceType.LAPTOP))
    .osTypes(List.of("Windows 10", "Windows 11"))
    .organizationIds(List.of("org-123", "org-456"))
    .tagNames(List.of("production", "finance-dept"))
    .build();

// Use in device service query
List<Device> filteredDevices = deviceService.findDevices(filter);
```

This filter object would typically be passed to repository or service methods to construct dynamic database queries with WHERE clauses matching the specified criteria.
