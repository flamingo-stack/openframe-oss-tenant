A data transfer object (DTO) that defines filtering criteria for querying devices in the OpenFrame MSP platform, supporting filters by status, type, OS, organization, and tags.

## Key Components

- **statuses** - Filter by device operational states (DeviceStatus enum values)
- **deviceTypes** - Filter by hardware/device categories (DeviceType enum values)  
- **osTypes** - Filter by operating system types (Windows, Linux, macOS, etc.)
- **organizationIds** - Filter by specific client organization identifiers
- **tagNames** - Filter by custom device tags for categorization

## Usage Example

```java
// Create filter for active Windows workstations in specific organizations
DeviceFilterInput filter = DeviceFilterInput.builder()
    .statuses(List.of(DeviceStatus.ONLINE, DeviceStatus.IDLE))
    .deviceTypes(List.of(DeviceType.WORKSTATION, DeviceType.LAPTOP))
    .osTypes(List.of("Windows 10", "Windows 11"))
    .organizationIds(List.of("org-123", "org-456"))
    .tagNames(List.of("critical", "finance-dept"))
    .build();

// Use in device service query
List<Device> filteredDevices = deviceService.findDevices(filter);
```

This filter input is typically used with device management APIs to retrieve specific subsets of managed endpoints based on multiple criteria, enabling MSP technicians to quickly locate and manage relevant devices across their client base.
