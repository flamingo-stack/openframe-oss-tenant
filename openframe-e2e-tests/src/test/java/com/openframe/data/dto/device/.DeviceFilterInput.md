A data transfer object (DTO) that encapsulates filtering criteria for device queries in the OpenFrame platform. This class provides a structured way to pass multiple filter parameters when searching or retrieving devices.

## Key Components

| Component | Type | Description |
|-----------|------|-------------|
| **statuses** | `List<DeviceStatus>` | Filter devices by their operational status |
| **deviceTypes** | `List<DeviceType>` | Filter by device type categories |
| **osTypes** | `List<String>` | Filter by operating system types |
| **organizationIds** | `List<String>` | Filter devices belonging to specific organizations |
| **tagNames** | `List<String>` | Filter devices by associated tag names |

## Usage Example

```java
// Create a filter for Windows servers that are online
DeviceFilterInput filter = DeviceFilterInput.builder()
    .statuses(List.of(DeviceStatus.ONLINE, DeviceStatus.WARNING))
    .deviceTypes(List.of(DeviceType.SERVER))
    .osTypes(List.of("Windows Server 2019", "Windows Server 2022"))
    .organizationIds(List.of("org-123", "org-456"))
    .tagNames(List.of("production", "critical"))
    .build();

// Use with repository or service
List<Device> devices = deviceRepository.findByFilter(filter);
```

The builder pattern provided by Lombok allows for flexible filter construction, where you can specify only the criteria you need. Empty or null lists are typically treated as "no filter applied" for that criteria.
