Enumeration representing the connection state of devices within the OpenFrame MSP platform, providing three distinct status values for device connectivity monitoring.

## Key Components

- **CONNECTED** - Device is successfully connected and communicating
- **DISCONNECTED** - Device is offline or unreachable  
- **ERROR** - Connection is in an error state requiring attention

## Usage Example

```java
// Check device connection status
public void handleDeviceStatus(Device device) {
    ConnectionStatus status = device.getConnectionStatus();
    
    switch (status) {
        case CONNECTED:
            logger.info("Device {} is online and ready", device.getId());
            break;
        case DISCONNECTED:
            logger.warn("Device {} is offline", device.getId());
            triggerReconnectionAttempt(device);
            break;
        case ERROR:
            logger.error("Device {} connection error", device.getId());
            escalateToTechnician(device);
            break;
    }
}

// Update device status
device.setConnectionStatus(ConnectionStatus.CONNECTED);
```

This enum is typically used in device management workflows, monitoring dashboards, and automated alert systems within the OpenFrame platform to track and respond to device connectivity changes.
