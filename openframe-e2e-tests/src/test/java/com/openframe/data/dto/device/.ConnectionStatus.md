A simple enumeration defining the possible connection states for devices in the OpenFrame platform, used throughout the device management system to track and communicate device connectivity status.

## Key Components

- **CONNECTED** - Device is online and communicating properly
- **DISCONNECTED** - Device is offline or unreachable
- **ERROR** - Device connection has encountered an error state

## Usage Example

```java
// In a device service or controller
public class DeviceService {
    
    public void updateDeviceStatus(String deviceId, ConnectionStatus status) {
        switch (status) {
            case CONNECTED:
                log.info("Device {} is now online", deviceId);
                enableMonitoring(deviceId);
                break;
            case DISCONNECTED:
                log.warn("Device {} has gone offline", deviceId);
                disableMonitoring(deviceId);
                break;
            case ERROR:
                log.error("Device {} connection error", deviceId);
                triggerAlert(deviceId);
                break;
        }
    }
    
    public boolean isDeviceOnline(ConnectionStatus status) {
        return status == ConnectionStatus.CONNECTED;
    }
}
```

This enum provides type safety and clear semantics for device connectivity states across the OpenFrame MSP platform, ensuring consistent status handling in device monitoring, alerting, and management workflows.
