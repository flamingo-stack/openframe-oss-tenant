An enumeration that defines the possible connection states for devices in the OpenFrame system, providing a standardized way to represent device connectivity status.

## Key Components

- **CONNECTED** - Device is successfully connected and operational
- **DISCONNECTED** - Device is not connected or has lost connection
- **ERROR** - Device connection is in an error state

## Usage Example

```java
// Setting device connection status
Device device = new Device();
device.setConnectionStatus(ConnectionStatus.CONNECTED);

// Checking connection status
if (device.getConnectionStatus() == ConnectionStatus.CONNECTED) {
    // Proceed with device operations
    performDeviceAction(device);
} else if (device.getConnectionStatus() == ConnectionStatus.ERROR) {
    // Handle error state
    logConnectionError(device);
}

// Using in switch statement for status handling
switch (device.getConnectionStatus()) {
    case CONNECTED:
        updateDeviceMetrics(device);
        break;
    case DISCONNECTED:
        scheduleReconnection(device);
        break;
    case ERROR:
        triggerErrorAlert(device);
        break;
}
```

This enum is typically used in device DTOs and monitoring systems to track and respond to changes in device connectivity states across the OpenFrame platform.
