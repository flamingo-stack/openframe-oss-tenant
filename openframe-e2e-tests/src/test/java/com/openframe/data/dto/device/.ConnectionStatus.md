An enumeration that defines the possible connection states for devices within the OpenFrame platform, providing a standardized way to represent network connectivity status.

## Key Components

- **CONNECTED** - Device is successfully connected and communicating
- **DISCONNECTED** - Device is not connected or unreachable
- **ERROR** - Device connection is in an error state requiring attention

## Usage Example

```java
// Check device connection status
ConnectionStatus status = device.getConnectionStatus();

switch (status) {
    case CONNECTED:
        logger.info("Device is online and ready");
        break;
    case DISCONNECTED:
        logger.warn("Device is offline");
        triggerReconnectionAttempt(device);
        break;
    case ERROR:
        logger.error("Device connection error detected");
        sendAlertToTechnician(device);
        break;
}

// Update device status
device.setConnectionStatus(ConnectionStatus.CONNECTED);
```

This enum is typically used in device management systems to track and respond to connectivity changes, enabling the MSP platform to provide real-time monitoring and automated response capabilities through Mingo AI.
