An enumeration that defines the possible connection states for devices within the OpenFrame platform, providing standardized status values for network connectivity monitoring.

## Key Components

- **CONNECTED**: Device is successfully connected and communicating
- **DISCONNECTED**: Device is not connected or unreachable
- **ERROR**: Connection attempt failed or encountered an error state

## Usage Example

```java
// Setting device connection status
ConnectionStatus status = ConnectionStatus.CONNECTED;

// Checking connection state in conditional logic
if (device.getConnectionStatus() == ConnectionStatus.CONNECTED) {
    // Process device data
    handleDeviceData(device);
} else if (device.getConnectionStatus() == ConnectionStatus.ERROR) {
    // Log error and attempt reconnection
    logger.error("Device connection error: " + device.getId());
    reconnectDevice(device);
}

// Switch statement for status handling
switch (device.getConnectionStatus()) {
    case CONNECTED:
        updateDeviceMetrics(device);
        break;
    case DISCONNECTED:
        scheduleReconnection(device);
        break;
    case ERROR:
        alertAdministrator(device);
        break;
}
```

This enum is typically used in device DTOs and service classes throughout the OpenFrame system to maintain consistent connection state representation across different components and APIs.
