A data transfer object that represents the connection between a monitoring agent and external MSP tools in the OpenFrame platform, tracking connection state and synchronization status.

## Key Components

- **Connection Identifiers**: `id`, `machineId`, `agentToolId` for tracking specific tool connections
- **Tool Information**: `toolType` to categorize the connected MSP tool
- **Connection Status**: `status` field using `ConnectionStatus` enum to track current state
- **Metadata Storage**: `metadata` field for storing tool-specific configuration or connection parameters
- **Timestamp Tracking**: `connectedAt`, `lastSyncAt`, `disconnectedAt` for connection lifecycle monitoring
- **Lombok Annotations**: `@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor` for automatic code generation

## Usage Example

```java
// Creating a new tool connection
ToolConnection connection = ToolConnection.builder()
    .id("conn-123")
    .machineId("machine-456")
    .toolType("RMM")
    .agentToolId("rmm-agent-789")
    .status(ConnectionStatus.CONNECTED)
    .metadata("{\"endpoint\": \"https://rmm.example.com\", \"version\": \"2.1\"}")
    .connectedAt("2024-01-15T10:30:00Z")
    .lastSyncAt("2024-01-15T11:00:00Z")
    .build();

// Updating connection status
connection.setStatus(ConnectionStatus.DISCONNECTED);
connection.setDisconnectedAt("2024-01-15T12:00:00Z");
```

This DTO is essential for managing the integration between OpenFrame agents and various MSP tools, enabling the platform to track which tools are available and their current connectivity status for automated IT operations.
