Data Transfer Object representing the connection state between OpenFrame agents and external MSP tools like RMM, PSA, or documentation systems.

## Key Components

- **Connection Identifiers**: `id` (unique connection identifier), `machineId` (target machine), `agentToolId` (external tool reference)
- **Tool Classification**: `toolType` field to categorize the connected tool (RMM, PSA, ticketing, etc.)
- **Connection Status**: `status` field using `ConnectionStatus` enum to track active, disconnected, or error states
- **Metadata Storage**: `metadata` field for storing tool-specific configuration or connection parameters
- **Timestamp Tracking**: `connectedAt`, `lastSyncAt`, and `disconnectedAt` for connection lifecycle monitoring

## Usage Example

```java
// Create a new RMM tool connection
ToolConnection rmmConnection = ToolConnection.builder()
    .id("conn_12345")
    .machineId("machine_abc")
    .toolType("RMM")
    .agentToolId("rmm_tool_456")
    .status(ConnectionStatus.ACTIVE)
    .metadata("{\"endpoint\":\"https://rmm.example.com\",\"version\":\"v2.1\"}")
    .connectedAt("2024-01-15T10:30:00Z")
    .lastSyncAt("2024-01-15T12:45:00Z")
    .build();

// Update connection status after sync failure
rmmConnection.setStatus(ConnectionStatus.ERROR);
rmmConnection.setDisconnectedAt("2024-01-15T13:00:00Z");
```
