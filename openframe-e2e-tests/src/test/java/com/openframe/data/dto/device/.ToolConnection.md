A data transfer object representing the connection between MSP tools and devices in the OpenFrame platform, tracking connection status and synchronization details.

## Key Components

- **Connection Identifiers**: `id`, `machineId`, `toolType`, and `agentToolId` for unique identification
- **Status Management**: `ConnectionStatus` enum to track current connection state
- **Timing Data**: `connectedAt`, `lastSyncAt`, and `disconnectedAt` timestamps for connection lifecycle
- **Metadata Storage**: Generic `metadata` field for additional connection-specific information
- **Lombok Annotations**: `@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor` for automatic code generation

## Usage Example

```java
// Create a new tool connection
ToolConnection connection = ToolConnection.builder()
    .id("conn-123")
    .machineId("machine-456")
    .toolType("RMM")
    .agentToolId("agent-789")
    .status(ConnectionStatus.CONNECTED)
    .metadata("{\"version\":\"1.2.3\"}")
    .connectedAt("2024-01-15T10:30:00Z")
    .lastSyncAt("2024-01-15T11:00:00Z")
    .build();

// Update connection status
connection.setStatus(ConnectionStatus.DISCONNECTED);
connection.setDisconnectedAt("2024-01-15T12:00:00Z");
```

This DTO is typically used in the OpenFrame platform to maintain connection state between various MSP tools (RMM, PSA, backup solutions) and managed devices, enabling the AI-powered automation features to track tool availability and synchronization status.
