A data transfer object (DTO) that represents the connection state between a device/machine and external MSP tools within the OpenFrame AI platform.

## Key Components

- **Connection Identifiers**: `id`, `machineId`, and `agentToolId` for unique identification
- **Tool Classification**: `toolType` field to categorize the connected MSP tool
- **Connection Tracking**: `status` enum for current connection state
- **Metadata Storage**: Generic `metadata` field for tool-specific configuration data
- **Timestamp Management**: Connection lifecycle timestamps (`connectedAt`, `lastSyncAt`, `disconnectedAt`)
- **Lombok Annotations**: Automatic generation of getters, setters, constructors, and builder pattern

## Usage Example

```java
// Create a new tool connection for RMM integration
ToolConnection connection = ToolConnection.builder()
    .id("conn-123")
    .machineId("machine-456")
    .toolType("RMM")
    .agentToolId("agent-789")
    .status(ConnectionStatus.CONNECTED)
    .metadata("{\"endpoint\": \"https://rmm.example.com\", \"version\": \"2.1\"}")
    .connectedAt("2024-01-15T10:30:00Z")
    .lastSyncAt("2024-01-15T11:00:00Z")
    .build();

// Check connection status
if (connection.getStatus() == ConnectionStatus.CONNECTED) {
    // Process sync data
    String lastSync = connection.getLastSyncAt();
}
```
