Data Transfer Object (DTO) representing a connection between a tool/agent and a machine in the OpenFrame platform, tracking connection status and synchronization information.

## Key Components

- **Connection Identifiers**: `id`, `machineId`, `agentToolId` for tracking relationships
- **Tool Information**: `toolType` specifies the type of connected tool
- **Status Management**: `status` field using `ConnectionStatus` enum to track connection state
- **Metadata Storage**: `metadata` field for additional connection-specific information
- **Timestamp Tracking**: `connectedAt`, `lastSyncAt`, `disconnectedAt` for connection lifecycle monitoring

## Usage Example

```java
// Create a new tool connection
ToolConnection connection = ToolConnection.builder()
    .id("conn-123")
    .machineId("machine-456")
    .toolType("MONITORING_AGENT")
    .agentToolId("agent-789")
    .status(ConnectionStatus.CONNECTED)
    .metadata("{\"version\": \"1.2.3\", \"features\": [\"monitoring\", \"alerts\"]}")
    .connectedAt("2024-01-15T10:30:00Z")
    .lastSyncAt("2024-01-15T11:45:00Z")
    .build();

// Update connection status
connection.setStatus(ConnectionStatus.DISCONNECTED);
connection.setDisconnectedAt("2024-01-15T12:00:00Z");
```

This DTO is commonly used in device management operations to track which tools are connected to specific machines and their synchronization status within the OpenFrame MSP platform.
