Django settings configuration file for local development environment with security protections disabled for container deployment.

## Key Components

- **Database Configuration**: PostgreSQL connection settings using environment variables
- **Security Settings**: Disabled CSRF, CORS, and SSL protections for development
- **Service Integrations**: Redis cache, NATS messaging, and MeshCentral configurations
- **File System Paths**: Executable, log, and script directory mappings
- **Feature Flags**: Controls for web terminal, server scripts, SSO, and 2FA
- **API Settings**: Swagger documentation and beta API enablement

## Usage Example

```python
# This file is typically imported by Django's main settings.py
# Environment variables must be set before Django starts:

# Required environment variables:
# DJANGO_SEKRET - Secret key for Django
# TACTICAL_DIR - Base directory for Tactical RMM
# POSTGRES_DB, POSTGRES_USER, POSTGRES_PASSWORD - Database credentials
# REDIS_HOST - Redis server hostname
# APP_HOST - Application host for frontend URLs

# The settings automatically configure:
# - PostgreSQL database connection
# - Redis caching backend
# - Disabled security for development
# - Directory paths for executables and logs
# - CORS settings allowing all origins
```

**⚠️ Security Note**: This configuration disables critical security features (CSRF, secure cookies, SSL) and should only be used in isolated development environments, not production deployments.
