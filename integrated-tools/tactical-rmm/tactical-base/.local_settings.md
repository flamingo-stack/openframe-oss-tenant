Django local development settings configuration file for Flamingo's AI-powered MSP platform. This file extends custom settings and configures a permissive development environment with disabled security features for local testing.

## Key Components

- **Security Settings** - Disabled CSRF/session protections for development
- **Database Configuration** - PostgreSQL connection with environment variables
- **MeshCentral Integration** - Disabled remote management features
- **NATS/Redis** - Message broker and caching configuration
- **Development Flags** - Debug mode, CORS allowances, and API enablement
- **File System Paths** - Directories for executables, logs, and scripts

## Usage Example

```python
# This file is automatically loaded by Django's settings system
# Environment variables are substituted at runtime:

# Database connection uses environment variables
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.postgresql',
        'NAME': '${POSTGRES_DB}',          # e.g., 'tacticalrmm'
        'USER': '${POSTGRES_USER}',        # e.g., 'tactical'
        'PASSWORD': '${POSTGRES_PASSWORD}', # e.g., 'password123'
        'HOST': '${POSTGRES_HOST}',        # e.g., 'localhost'
        'PORT': '${POSTGRES_PORT}',        # e.g., '5432'
    }
}

# Redis caching with dynamic configuration
CACHES = {
    'default': {
        'BACKEND': 'django_redis.cache.RedisCache',
        'LOCATION': f'redis://{REDIS_HOST}:{REDIS_PORT}/{REDIS_DB}',
    }
}
```

**⚠️ Warning**: This configuration disables critical security features and should only be used in local development environments. Production deployments require proper CSRF protection, secure cookies, and restricted CORS policies.
